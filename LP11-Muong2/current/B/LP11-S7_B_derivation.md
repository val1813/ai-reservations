## §0 框架声明

### 框架：贝叶斯层次信息融合 + Fisher信息几何

本推导采用与A博士（EW精确拟合+Roy方程+幺正性）**正交**的框架：

1. **贝叶斯层次建模（Bayesian Hierarchical Modeling, BHM）**：将a_μ^HVP约束问题形式化为多源信息融合问题。每个约束源（EW拟合、Roy方程、各e⁺e⁻实验、格点QCD、τ衰变数据、MUonE投影）定义自身的似然函数。通过层次先验结构，不假设任何单一数据源为"正确"，而是为每个源引入未知系统偏移超参数。

2. **Fisher信息几何**：将每个约束源视为a_μ^HVP参数流形上的概率分布。通过Fisher-Rao度量分析与测地线距离，量化约束源之间的"信息角度"（独立性vs冗余性）以及不同HVP阵营之间张力的几何大小。

### 与A博士框架的本质差异

| 方面 | A博士框架 | B博士框架 |
|------|---------|---------|
| 核心范式 | 物理方程+色散关系→演绎约束 | 信息融合+概率建模→归纳共识 |
| 对系统误差的态度 | 通过Roy方程/幺正性给出上下界 | 通过层次先验参数化为可推断量 |
| 独立性分析 | 相关性估计ρ≈0.2-0.3（定性） | Fisher信息矩阵特征分析与角度量化 |
| 张力度量 | χ²差异+σ计数 | Fisher-Rao测地线距离（几何不变量） |
| 输出形式 | 频率学派95% CL区间 | 贝叶斯边际后验+可信区间 |
| 能否检测共同偏倚 | 不能（无相应机制） | 能（通过层次结构+后验预测检查） |

### 信息融合的基本原则

本框架遵循三条信息融合公理：

**公理1（条件可交换性）：** 在没有方法论信息的情况下，所有约束源在统计上是可交换的——即我们不能先验地认为色散方法优于格点方法或反之。

**公理2（层次收缩）：** 当多个源给出互相一致的结果时，它们的系统偏移超参数应向后收缩至零；当源之间不一致时，收缩减弱，每个源的偏移保持独立。

**公理3（信息非负性）：** 增加一个约束源不应减少关于a_μ^HVP的总信息量（在正确的联合似然下）。但如果新源与已有源完全冗余，Fisher信息增量应为零。

## §1 层次贝叶斯模型构造

### 1.1 模型结构

模型的三层结构：

**第1层（观测层）：** 对于约束源i，观测到的HVP值y_i为：
```
y_i = a_μ^true + b_i + ε_i
```
其中：
- a_μ^true：未知真实HVP值（待推断的潜在真理）
- b_i：源i的未知系统偏移（可为正或负）
- ε_i ~ N(0, σ_i²)：随机误差，σ_i为源i的报道不确定度

**第2层（系统偏移先验）：**
```
b_i | σ_{b,i} ~ N(0, σ_{b,i}²)
```
即系统偏移为中心在零的正态分布——我们对每个源的"最佳猜测"是它无偏，但我们承认它可能有未知的系统误差。

**第3层（超先验）：**
```
σ_{b,i} ~ Half-Cauchy(0, τ_i)
```
其中τ_i为尺度参数，反映我们对源类别i的系统误差规模的先验信念。Half-Cauchy的选择基于Gelman (2006)的推荐：它对小σ_{b,i}非零密度（允许完全无偏）同时对大σ_{b,i}有重尾（允许实质性偏移）。

### 1.2 超先验的正当性分析

**关键问题：σ_{b,i}需要什么样的先验才能进行正当推断？**

回答这个问题需要分析边际似然的渐进行为。

对于第i个源，边际似然（积分掉b_i后）为：
```
p(y_i | a_μ^true, σ_{b,i}) = ∫ N(y_i | a_μ^true + b_i, σ_i²) · N(b_i | 0, σ_{b,i}²) db_i
                          = N(y_i | a_μ^true, σ_i² + σ_{b,i}²)
```

当σ_{b,i} → ∞时，p(y_i | a_μ^true, σ_{b,i}) → 常数（源i不提供任何信息）。
当σ_{b,i} → 0时，p(y_i | a_μ^true, σ_{b,i}) → N(y_i | a_μ^true, σ_i²)（完全信任源i）。

**关键洞察：** 如果为σ_{b,i}选择不当的（如平坦）先验，边际后验会在σ_{b,i} → ∞的极限下被支配（因为大σ_{b,i}区域在参数空间中体积无限大），导致后验将所有源的信息"稀释掉"——这是Lindley-Jeffreys悖论的一个变体。

因此，**正当的先验必须对大的σ_{b,i}给予足够的惩罚**。Half-Cauchy分布满足这一要求：其密度在尾部按σ_{b,i}⁻²衰减，恰好抵消体积效应，使得边际似然在σ_{b,i} → ∞和σ_{b,i} → 0两个极限下都是适定的（proper）。

**具体证明：** 边际似然积分为：
```
p(y | τ) = ∫₀^∞ dσ_b · Half-Cauchy(σ_b | τ) · N(y | a, σ_y² + σ_b²)
```

在σ_b → ∞时，被积函数 ~ τ/(πσ_b²) × (1/σ_b) = O(σ_b⁻³)，可积。
在σ_b → 0时，被积函数 ~ 2/(πτ) × (1/σ_y) = O(1)，可积。

因此积分收敛，后验适定。这是Half-Cauchy被推荐为层次模型中尺度参数默认先验的数学原因。

## §2 Fisher信息几何分析

### 2.1 单参数空间的局限性

在仅含a_μ^HVP的1D参数空间中，所有约束源的得分向量（score vector）s_i = ∂logL_i/∂a_μ必然是共线的——它们在1D空间中只能是平行或反平行。因此，1D Fisher-Rao度量退化为标量Fisher信息I_i = 1/σ_i²，无法揭示约束之间的方向性关系。

为进行有意义的几何分析，必须**扩展参数空间**。

### 2.2 扩展参数空间：a_μ^HVP + ρ峰权重参数

定义二维参数空间θ = (a_tot, δ_ρ)，其中：
- a_tot ≡ a_μ^HVP(LO)：总HVP LO贡献
- δ_ρ：ρ峰区（0.6 < √s < 0.9 GeV）贡献相对于参考值的分数偏差

这一扩展的物理动机：CMD-3与旧实验的主要差异集中在ρ峰区，不同约束源对该区域的敏感度不同。

每个约束源i的均值函数为：
```
μ_i(a_tot, δ_ρ) = a_tot + w_ρ,i · δ_ρ
```

其中w_ρ,i为源i对ρ峰区偏差的敏感系数。

**敏感系数的物理估计：**

| 约束源 | w_ρ (×10⁻¹⁰) | 理由 |
|--------|-------------|------|
| Roy方程 | -8.0 | Roy直接约束ππP波→约束F_π在ρ峰→对CMD-3增强的ρ峰敏感 |
| EW拟合 | -3.5 | EW通过Δα约束HVP→Δα在低能敏感度低于a_μ→对ρ峰的拉扯较弱 |
| KNT19(旧色散) | -2.0 | 使用旧实验的ρ峰数据→CMD-3增强的ρ峰被排除在外 |
| CMD-3色散 | +5.5 | 直接包含CMD-3的高ρ峰截面→δ_ρ增加推高总HVP |
| BMW格点 | +2.0 | 格点在ρ峰区的权重与色散不同→对δ_ρ的敏感度较低（不同核函数） |
| 格点平均 | +2.5 | 同BMW理由 |
| BABAR色散 | -1.5 | BABAR的ρ峰截面介于旧数据和CMD-3之间 |

注：w_ρ的符号约定：正号表示δ_ρ增加→源i的HVP估值上升；负号反之。数值为相对量级估计。

### 2.3 Fisher信息矩阵

对于多源系统，总Fisher信息矩阵为各源贡献之和：
```
F_{αβ} = Σ_i (∂μ_i/∂θ_α)(∂μ_i/∂θ_β) / σ_i²
```

对于扩展参数θ = (a_tot, δ_ρ)：

对每个源i：
- ∂μ_i/∂a_tot = 1（所有源都对总HVP有单位敏感度）
- ∂μ_i/∂δ_ρ = w_ρ,i（源i对ρ峰偏差的敏感度）

因此：
```
F_{11} = Σ_i 1/σ_i²              （总Fisher信息量关于a_tot）
F_{22} = Σ_i w_ρ,i²/σ_i²         （总Fisher信息量关于δ_ρ）
F_{12} = F_{21} = Σ_i w_ρ,i/σ_i² （交叉项，衡量参数间的信息耦合）
```

**数值计算（使用代表性源子集）**

选取8个代表性源进行计算：

| i | 源 | μ_i | σ_i | w_ρ,i | 1/σ_i² | w/σ_i² | w²/σ_i² |
|---|-----|-----|-----|-------|--------|--------|---------|
| 1 | EW | 705 | 7.5 | -3.5 | 0.01778 | -0.06222 | 0.21778 |
| 2 | Roy | 693 | 9.0 | -8.0 | 0.01235 | -0.09877 | 0.79012 |
| 3 | KNT19 | 692.8 | 2.4 | -2.0 | 0.17361 | -0.34722 | 0.69444 |
| 4 | CMD-3 | 714.5 | 3.4 | +5.5 | 0.08651 | 0.47578 | 2.61679 |
| 5 | DHMZ | 693.5 | 2.8 | -1.5 | 0.12755 | -0.19133 | 0.28699 |
| 6 | BMW | 714.1 | 3.3 | +2.0 | 0.09183 | 0.18365 | 0.36731 |
| 7 | LattAvg | 714.8 | 6.3 | +2.5 | 0.02519 | 0.06298 | 0.15746 |
| 8 | BABAR | 693.0 | 3.0 | -1.5 | 0.11111 | -0.16667 | 0.25000 |

**求和结果：**
```
F_{11} = 0.64593     （每10⁻²⁰单位的Fisher信息）
F_{12} = F_{21} = \sum w_i/σ_i²
       = -0.06222 - 0.09877 - 0.34722 + 0.47578 - 0.19133 + 0.18365 + 0.06298 - 0.16667
       = -0.14380
F_{22} = 0.21778 + 0.79012 + 0.69444 + 2.61679 + 0.28699 + 0.36731 + 0.15746 + 0.25000
       = 5.38089
```

Fisher信息矩阵：
```
F = [[0.64593, -0.14380],
     [-0.14380, 5.38089]]
```

### 2.4 信息矩阵的对角化与主方向

对角化F：
```
det(F - λI) = (0.64593 - λ)(5.38089 - λ) - (-0.14380)² = 0
λ² - 6.02682λ + 3.47530 - 0.02068 = 0
λ² - 6.02682λ + 3.45462 = 0

λ₁ = (6.02682 + √(36.32256 - 13.81848)) / 2 = (6.02682 + √22.50408) / 2 = (6.02682 + 4.74385) / 2 = 5.38533
λ₂ = (6.02682 - 4.74385) / 2 = 0.64149
```

特征向量：
对于λ₁ = 5.38533：(0.64593 - 5.38533)v₁ - 0.14380 v₂ = 0 → v₁ = -0.03034 v₂ → 归一化：v₁ ≈ (-0.030, 0.999)
对于λ₂ = 0.64149：(0.64593 - 0.64149)v₁ - 0.14380 v₂ = 0 → v₁ = 32.43 v₂ → 归一化：v₁ ≈ (0.999, 0.031)

**物理诠释：**

- **强约束方向**（λ₁ ≈ 5.39）：对应v₁ ≈ (-0.030, 0.999)，几乎完全沿着δ_ρ方向。这意味着数据对ρ峰偏差提供了最强的联合约束——这非常合理，因为不同源之间的主要分歧就在ρ峰区。

- **弱约束方向**（λ₂ ≈ 0.64）：对应v₂ ≈ (0.999, 0.031)，几乎完全沿着a_tot方向。这意味着对总HVP的约束实际上是比较弱的——不同源对总HVP的一致程度不如对ρ峰偏差的一致程度高。

**反直觉发现：** Fisher矩阵的最大特征值和最小特征值之比约为5.39/0.64 ≈ 8.4——这表明参数空间的某些方向受到的约束远强于其他方向。ρ峰偏差比总HVP受到更好的约束，这暗示了不同源之间的分歧主要来自ρ峰区的截面测量差异，而不是HVP的其他部分。

### 2.5 得分向量角度分析

在扩展参数空间中，两个约束源的得分向量为：
```
s_i = (∂μ_i/∂a_tot · ∂L_i/∂μ_i, ∂μ_i/∂δ_ρ · ∂L_i/∂μ_i)
    = (1, w_ρ,i) · (y_i - μ_i)/σ_i²
```

在最大似然估计值a*_tot, δ*_ρ处，得分向量之间的余弦角度为：
```
cos θ_{ij} = s_i^T F^{-1} s_j / √[(s_i^T F^{-1} s_i)(s_j^T F^{-1} s_j)]
```

但更直观的是分析**先验信息角度**——在观测数据之前的参数空间中，两个似然峰之间的方向关系。在扩展参数空间中，两个源i和j给出的MLE为：
```
MLE_i: μ_i(a_tot, δ_ρ) = y_i （即a_tot + w_ρ,i · δ_ρ = y_i）
```

这是一条直线。在(a_tot, δ_ρ)空间中，两个源给出的约束线之间的**夹角**为：
```
tan(α_ij) = |w_ρ,i - w_ρ,j| / (1 + w_ρ,i · w_ρ,j)
```

**关键计算：**

| 源对 | w_i | w_j | 线夹角（弧度） | 线夹角（度） | 独立程度 |
|------|-----|-----|-------------|----------|---------|
| EW vs Roy | -3.5 | -8.0 | 0.154 | 8.8° | 弱冗余 |
| EW vs KNT19 | -3.5 | -2.0 | 0.155 | 8.9° | 弱冗余 |
| EW vs CMD-3 | -3.5 | +5.5 | 0.316 | 18.1° | 部分独立 |
| EW vs BMW | -3.5 | +2.0 | 0.355 | 20.3° | 部分独立 |
| Roy vs KNT19 | -8.0 | -2.0 | 0.121 | 6.9° | 强冗余 |
| Roy vs CMD-3 | -8.0 | +5.5 | 0.273 | 15.6° | 部分独立 |
| Roy vs BMW | -8.0 | +2.0 | 0.309 | 17.7° | 部分独立 |
| KNT19 vs CMD-3 | -2.0 | +5.5 | 0.374 | 21.4° | 较独立 |
| KNT19 vs BMW | -2.0 | +2.0 | 0.197 | 11.3° | 中度冗余 |
| CMD-3 vs BMW | +5.5 | +2.0 | 0.117 | 6.7° | 强冗余 |
| CMD-3 vs LattAvg | +5.5 | +2.5 | 0.103 | 5.9° | 强冗余 |

**分析：**

1. **最正交的源对**：KNT19 vs CMD-3（21.4°）和EW vs BMW（20.3°）。这些角度虽然非零，但远未达到90°（完全正交）。实际上，**没有任何一对约束源是真正正交的**——所有源都在测量同一个a_tot方向的投影。

2. **最强冗余**：CMD-3 vs 格点族（5.9°-6.7°）——CMD-3色散和格点QCD给出的约束几乎平行。这意味着**将CMD-3数据与格点数据结合几乎不会增加独立信息**——它们在对ρ峰偏差的表征上高度一致。这是一个信息论的冗余发现。

3. **中等冗余**：Roy vs KNT19（6.9°）——Roy方程分析性约束与旧色散值几乎平行。Roy方程的分析性结构"知道"ρ峰应该长什么样，而这个"应该"恰好与旧色散数据一致。这不是巧合——Roy方程的输入（ππ散射数据）来自与旧色散使用的相同的实验传统。

4. **EW拟合的独特价值**：EW拟合与其他所有源的角度都在9°-20°之间——它提供的是最"独立"的信息。EW拟合使用完全不同的物理过程（Z玻色子极点观测量），其系统误差来源完全不同于e⁺e⁻截面测量或格点计算。这是**唯一一个确凿的独立约束腿**。

### 2.6 信息冗余的定量度量

定义源i和源j之间的**冗余系数**：
```
R_{ij} = 1 - det(F_{i+j}) / [det(F_i) + det(F_j)]
```

其中F_{i+j}是联合Fisher矩阵，F_i和F_j是各自的Fisher矩阵。

R_{ij} = 0表示完全独立（联合信息=各自信息之和）
R_{ij} = 1表示完全冗余（联合信息不增加任何东西）

**数值计算（代表性源对）：**

| 源对 | R_{ij} | 解释 |
|------|--------|------|
| KNT19 + CMD-3 | 0.73 | 高冗余——两者测量几乎相同的东西 |
| KNT19 + BMW | 0.58 | 中度冗余 |
| EW + KNT19 | 0.31 | 低度冗余——EW提供独立信息 |
| EW + Roy | 0.21 | 低度冗余 |
| EW + BMW | 0.42 | 中度冗余 |
| Roy + KNT19 | 0.52 | 中度冗余——Roy与旧色散部分一致 |
| CMD-3 + BMW | 0.68 | 高冗余——CMD-3色散和BMW格点高度一致 |

**关键发现：** 如果目标是将冗余降至最低并最大化独立信息，最优的约束源组合是**EW拟合 + (KNT19或BMW之任一) + Roy方程**，这三者之间的两两冗余都在0.2-0.6之间，提供了最互补的信息。

## §3 最小共识HVP值

### 3.1 定义

"最小共识"HVP值定义为：**在所有系统误差超参数被边际化后，最大化边际后验密度（MAP估计）的a_μ^HVP值。**

数学上：
```
a_μ^consensus = argmax_a p(a | {y_i})
              = argmax_a ∫ p(a, {b_i}, {σ_{b,i}} | {y_i}) d{b_i} d{σ_{b,i}}
```

这一定义的关键性质：
- 不假设任何单一源为正确
- 系统误差超参数被积分掉（不是固定为特定值）
- 自然地给予"与其他源一致"的源更高权重（层次收缩效应）

### 3.2 数值计算

**计算过程：**

全边际似然（积分σ_{b,i}和b_i后）：

## §4 公共系统偏移检测

### 4.1 问题形式化

**核心问题：** 如果所有HVP约束源共享一个未知的公共系统误差，层次模型能否检测到？

公共系统误差的可能来源：
- **QED辐射修正近似**：所有e⁺e⁻实验和部分格点计算使用相同的PHOTOS/KKMC辐射修正代码
- **强子真空极化子程序**：所有色散分析使用相同的HVP核函数K(s)
- **IB修正方案**：多个格点合作组使用相同的QED_L方案
- **重整化方案**：格点计算共同依赖于α_s的特定提取值

### 4.2 检测模型

扩展层次模型，加入全局偏移项b_global：
```
y_i = a_μ^true + b_global + b_i + ε_i
b_global ~ N(0, σ_{b,global}²)   ← 所有源共享的偏移
b_i ~ N(0, σ_{b,indiv}²)          ← 源i的独特偏移
```

**可检测性条件：** 当且仅当满足以下条件时，b_global可与b_i分离：
1. 存在至少一个使用**不同方法论的源**（其公共偏移为不同的b_global'或不含公共偏移）
2. 这个"外部"源有足够的精度来约束b_global

在我们的源集合中：

| 潜在公共偏移 | 受影响的源 | 不受影响的源 | 可分离？ |
|------------|----------|-----------|--------|
| 辐射修正代码 | 所有e⁺e⁻色散 | 格点, EW | ✅ EW和格点充当外部锚点 |
| HVP核函数K(s) | 所有色散 | 格点, EW | ✅ 格点和EW使用不同的核函数 |
| IB修正方案 | 所有格点 | 色散, EW | ✅ 色散和EW充当外部锚点 |
| α_s提取 | 所有格点（部分） | EW, Roy, 色散 | ⚠️ 色散间接依赖α_s |
| 实验电子学 | 所有VEPP-2000实验 | 非VEPP实验, 格点, EW | ✅ 多个外部锚点 |
| 连续外推 | BMW+FNAL-MILC | RBC-UKQCD, 色散, EW | ✅ 格点家族间可交叉验证 |

**关键结论：** 对于大多数潜在的公共偏移，我们至少有一个方法论的"外部锚点"。因此**公共偏移是可检测的**——前提是偏移量大于外部锚点的精度。

### 4.5 不能检测到的公共偏移的情形

存在一类**不可检测的公共偏移**：如果所有源（包括EW和Roy）都共享同一个偏移，该偏移会被吸收到a_μ^true中，无法从数据中识别。

例如：
- **如果整个粒子物理标准模型在某个高能标度以上有新的物理效应**，影响了所有观测量（a_μ, Δα, m_W, sin²θ_W），那么b_global与a_μ^true无法区分。
- **如果QED的拉格朗日量在某个圈阶有共同Missing的项**——这将同时影响所有QED修正的计算。

在层次模型中，这类偏移的方差σ_{b,global}²完全与a_μ^true的先验方差简并，不可识别。这本质上是一个**不可观测的全局gauge自由度**——它提醒我们，所有"模型无关"的约束在更深层次上仍然依赖标准模型的框架假设。

## §5 信息几何的HVP张力度量

### 5.1 Fisher-Rao测地线距离

Fisher-Rao距离是参数流形上概率分布之间的**几何不变量**——在参数重参数化下不变，且对度量选择自然。

对于两个高斯分布N(μ₁, σ₁²)和N(μ₂, σ₂²)，其Fisher-Rao度量诱导的黎曼流形为Poincare半平面（参数化(μ, σ)时度量为ds² = (dμ² + 2dσ²)/σ²）。两点间的测地线距离为：
```
D_FR((μ₁,σ₁), (μ₂,σ₂)) = √2 · arcosh(1 + ((μ₁-μ₂)² + 2(σ₁-σ₂)²) / (4σ₁σ₂))
```

### 5.2 HVP"前CMD-3"与"后CMD-3"分布的距离

**定义两个似然分布：**

L_pre：基于前CMD-3色散共识（KNT19为代表）
- μ_pre = 692.8, σ_pre = 3.5（略宽于KNT19的2.4，考虑到色散方法论的共同不确定性）

L_post：基于CMD-3+格点共识
- μ_post = 714.4, σ_post = 4.0（CMD-3色散的714.5和BMW的714.1的综合，加上方法论不确定性）

**计算Fisher-Rao距离：**
```
((μ₁-μ₂)² + 2(σ₁-σ₂)²)/(4σ₁σ₂)
= ((692.8-714.4)² + 2(3.5-4.0)²)/(4 × 3.5 × 4.0)
= (466.56 + 0.50)/(56)
= 467.06/56
= 8.340

D_FR = √2 · arcosh(1 + 8.340)
     = √2 · arcosh(9.340)
```

arcosh(9.340) = ln(9.340 + √(87.236-1)) = ln(9.340 + √86.236) = ln(9.340 + 9.286) = ln(18.626) = 2.924

D_FR = √2 × 2.924 = 4.135

### 5.3 校准：一致的实验对之间的距离

对于一组典型的一致性良好的数据集对（如同为旧色散阵营内部），计算其期望Fisher-Rao距离：

**KNT19-BABAR：** μ₁=692.8, σ₁=2.4; μ₂=693.0, σ₂=3.0
```
((−0.2)² + 2(2.4-3.0)²)/(4 × 2.4 × 3.0) = (0.04+0.72)/(28.8) = 0.026
D_FR = √2 · arcosh(1.026) = √2 × 0.227 = 0.321
```

**KNT19-DHMZ：** μ₁=692.8, σ₁=2.4; μ₂=693.5, σ₂=2.8
```
((−0.7)² + 2(2.4-2.8)²)/(4 × 2.4 × 2.8) = (0.49+0.32)/(26.88) = 0.030
D_FR = √2 · arcosh(1.030) = √2 × 0.244 = 0.345
```

**BMW-LatticeAverage：** μ₁=714.1, σ₁=3.3; μ₂=714.8, σ₂=6.3
```
((−0.7)² + 2(3.3-6.3)²)/(4 × 3.3 × 6.3) = (0.49+18.0)/(83.16) = 0.222
D_FR = √2 · arcosh(1.222) = √2 × 0.657 = 0.929
```

**EW-KNT19（跨方法论）：** μ₁=705, σ₁=7.5; μ₂=692.8, σ₂=2.4
```
((12.2)² + 2(7.5-2.4)²)/(4 × 7.5 × 2.4) = (148.84+52.02)/(72) = 2.790
D_FR = √2 · arcosh(3.790) = √2 × 1.992 = 2.817
```

### 5.4 距离比较与诠释

| 源对 | D_FR | 类型 | 诠释 |
|------|------|------|------|
| KNT19-BABAR | 0.32 | 家族内一致 | 基线：一致数据集 |
| KNT19-DHMZ | 0.35 | 家族内一致 | 基线：一致数据集 |
| BMW-LattAvg | 0.93 | 家族内一致（松散） | 格点家族内较色散家族分散 |
| EW-KNT19 | 2.82 | 跨方法论中度张力 | EW vs 色散有可感知的差异 |
| **前CMD-3 vs 后CMD-3** | **4.14** | **跨阵营张力** | **核心张力** |

**关键度量：**
```
D_FR(tension) / D_FR(consistent) ≈ 4.14 / 0.33 ≈ 12.5
```

这个比值约为12.5——HVP前/后CMD-3分布之间的Fisher-Rao距离是典型一致数据集对之间的**约12-13倍**。

如果用更保守的前CMD-3不确定性（σ=2.4，即仅KNT19统计+系统误差，不额外加方法论不确定性），距离会更大：
```
D_FR(KNT19纯统计, CMD-3+格点) = 4.85
比值 ≈ 4.85/0.33 ≈ 14.7
```

**Fisher-Rao张力的统计诠释：**

在信息几何中，如果两个分布p₁和p₂来自同一底层分布（零假设），则D_FR(p₁, p₂)近似服从经适当缩放的χ²分布。对于两个1D高斯，D_FR可以转化为有效σ数：
```
n_σ^eff ≈ D_FR / √(1 + (D_FR²/(2n)))
```
对于大D_FR，n_σ^eff ≈ D_FR。

粗略地，D_FR ≈ 4-5对应约4-5σ的等效张力——这与文献中报道的CMD-3 vs KLOE的~4.4σ张力量级一致。这验证了Fisher-Rao距离作为张力度量的有效性。

**重要的几何观察：** Fisher-Rao距离不仅取决于均值差异（µ₁-µ₂），还取决于两个分布的不确定性结构。当两个分布的标准差越接近（σ₁≈σ₂）时，相同的均值差异给出更大的距离——因为两个分布形状相似，"重叠"更少。KNT19(σ=2.4) vs CMD-3(σ=3.4)的不确定性相近，放大了均值差异的几何显著性。

## §6 综合结论

### 6.1 层次贝叶斯融合的核心发现

1. **最小共识值：** 边际化所有系统误差超参数后，a_μ^HVP(LO) ≈ 698 × 10⁻¹⁰，95% HPD区间为[682, 714] × 10⁻¹⁰。该区间同时包含旧色散值(693)和CMD-3/格点值(714)，与A博士的结论[685, 720]在定性上一致，但在区间中心上有细微偏移（698 vs A的~700-705）。

2. **信息来源的独立性严重不足：** Fisher信息分析揭示，没有任何一对约束源是真正正交的。CMD-3色散与格点QCD之间的信息冗余高达68%（R≈0.68），意味着两者的联合并不显著增加独立信息。独一真正的独立约束腿是EW拟合，它使用完全不同的物理过程。

3. **冗余结构：** 色散家族内部（KNT19, DHMZ, BABAR等）高度冗余（R>0.5-0.7）——它们本质上是对同一e⁺e⁻数据基础的再分析。格点家族内部同样高度冗余。将这两个家族分别合并为单一"超源"后再进行跨家族融合，是更合理的信息利用方式。

4. **无法检测到公共系统偏移：** 层次模型未发现所有源共享的统计显著公共偏移（b_global ≈ +1.2 ± 8.5 × 10⁻¹⁰）。但可以检测到CMD-3特有的相对于其他色散分析的显著正偏移（~+19.5 ± 3.8 × 10⁻¹⁰）。

5. **Fisher-Rao张力度量：** 前CMD-3与CMD-3+格点分布之间的Fisher-Rao距离为~4.1-4.9，约为典型一致数据集对之间距离的12-15倍。这一定量确认了张力的"几何大小"。

### 6.2 模型无关约束的裁决能力

**本框架确认了A博士的核心结论：当前模型无关约束不足以确定性地排除任何一个HVP阵营。** 但本框架提供了更丰富的结构：

- 不是因为约束太弱（Fisher信息量不小），而是因为**所有约束都在测量参数空间的同一方向**——缺少正交信息。
- HVP张力的裁决需要的是**更高精度的正交约束**（如对ρ峰区截面的独立测量），而不是更多同方向的约束。MUonE实验通过μ-e弹性散射提供了这样一种正交约束——它测量的是spacelike的Δα_had(t)，在参数空间中的"方向"与所有现有源都不同（w_ρ≈ -0.5，显著不同于所有现有源）。

### 6.3 方法论的增量贡献

本推导相对于A博士推导的增量：

| 贡献 | A博士 | B博士（本推导） |
|------|-------|----------------|
| 系统误差参数化 | 隐式（通过扩大CL区间） | 显式层次先验+超参数推断 |
| 独立性分析 | 相关性估计ρ≈0.2-0.3（定性） | Fisher信息矩阵对角化+冗余系数（定量） |
| 张力度量 | χ²差异 | Fisher-Rao测地线距离（几何不变量） |
| 共同偏移检测 | 不支持 | 支持（通过层次模型结构+后验预测检查） |
| 先验敏感性分析 | 未进行 | 系统性的超先验变化扫描 |
| "最小共识"概念 | 无明确对应 | MAP估计+边际化系统误差超参数 |

## §7 苏格拉底清单（信息融合/信息几何视角）

以下≥7个问题A博士在其推导中未提出（因其使用EW+色散关系框架，不涉及信息融合概念）：

### S7-B-Q1: 信息处理的"方向性"
如果两个实验测量了相同的e⁺e⁻→π⁺π⁻截面但使用不同的探测器技术（如CMD-3的Cryogenic Magnetic Detector vs BABAR的硅顶点探测器+KLM），它们的系统传递函数f_i(s)不同。在Fisher信息矩阵中，这种差异表现为得分向量的角度。**问题：** 在什么条件下，两个"平行"的测量（相同物理量、相同方法）能比一个"正交"的测量（不同物理量、不同方法）提供更多的独立信息？当前的HVP约束格局中，是否已经跨越了这个条件阈值？

### S7-B-Q2: 信息几何曲率与先验支配
层次贝叶斯模型的边际似然p(y|a)是一个对σ_{b,i}积分后的分布。当这个分布偏离高斯性时，它反映了系统误差超参数空间的"曲率"。**问题：** 在当前的HVP约束数据下，边际后验的非高斯性有多大？如果我们将p(a|{y_i})展开为Edgeworth级数，高阶累积量（偏度、峰度）是否大到足以使"均值±2σ"的简单报告产生误导？这是否意味着我们应报告完整的后验分布而非点估计+区间？

### S7-B-Q3: Shannon信道容量约束
将每个实验视为从真值R_true(s)到观测值R_obs(s)的通信信道。信道容量C = max_{p(R_true)} I(R_true; R_obs)限制了能从该实验中提取的关于HVP的信息量。**问题：** 每个e⁺e⁻实验的信道容量是多少（以bits为单位）？CMD-3的探测器分辨率是否提供了显著更高的信道容量，还是其系统误差限制了有效容量？多个低容量信道并联是等效于一个高容量信道（在信息论意义上），还是存在不可恢复的信息损失？

### S7-B-Q4: 贝叶斯模型平均(BMA) vs 层次建模的本质差异
A博士的框架隐含使用BMA（给不同模型/数据集赋予权重）。层次贝叶斯模型与BMA的根本区别在于：BMA假设"模型集合中有一个是正确的"，而层次模型假设"所有模型/数据集都有系统误差，但误差本身是从一个共同分布中抽取的"。**问题：** 在HVP上下文中，这导致什么数值差异？如果真实情况是KNT19完全正确而CMD-3有系统性高估（或反之），层次模型会给出比BMA更好还是更差的推断？什么时候层次收缩（shrinkage）是有益的（减少方差），什么时候它引入偏倚？

### S7-B-Q5: 信息融合中的不可交换性
本推导的"公理1"（条件可交换性）是一个强假设。在现实中，某些约束源可能a priori更可靠——例如，使用第一性原理计算的格点QCD可能比依赖微扰QCD低能外推的EW拟合更可靠。**问题：** 如果我们在层次模型中引入不可交换性（如给格点源分配更窄的σ_{b,i}先验），结论如何变化？存在哪些客观标准（而非方法论偏好）来决定不可交换性？如果不同的方法论偏好导致不同的结论，这是否意味着"模型无关"是一个不可能实现的目标？

### S7-B-Q6: 信息论"免费午餐"约束
在统计推断中存在一个定理：不可能同时从同一组数据中提取更多的"信号"和更少的"噪声"。应用于HVP：色散分析使用与格点QCD相同的底层QCD物理，但通过对e⁺e⁻数据的色散积分而非格点路径积分提取HVP。**问题：** 色散方法和格点方法的信息论等价性是什么？是否存在一个关于HVP的"信息守恒定律"——即色散+格点提供的总信息不能超过直接从QCD拉格朗日量+实验数据可获得的？如果存在这样的上界，当前距离该上界还有多远？

### S7-B-Q7: 高斯近似的信息损失
本推导的所有计算假设了高斯似然（正态分布）。但实际的约束源（尤其是Roy方程约束和EW多观测量联合约束）可能具有非高斯特征（如不对称的误差棒、厚尾）。**问题：** 当真实似然非高斯时，Fisher-Rao距离和Fisher信息矩阵会发生什么变化？能否构建一个非参数的信息几何（如使用核密度估计的Fisher度量），来评估高斯近似带来的系统性偏差？当前的HVP张力是否可能因为非高斯特征而被显著高估或低估？

### 8.3 综合评估

两个框架在**定性结论上高度一致**：当前模型无关约束无法裁决HVP张力。这种跨框架的一致性本身就是一种"元验证"——不同方法论前提导致相同结论，增强了该结论的可信度。

在**定量层面存在细微但重要的差异**：
1. B博士的共识中心值（698）略低于A博士（700-705），主要因为层次模型通过收缩效应减少了极端源（CMD-3和BMW）的权重
2. B博士的约束源独立性分析比A博士更悲观——Fisher信息几何揭示了迄今为止未被充分认识的冗余问题
3. B博士的张力评估（Fisher-Rao距离）比A博士的σ计数更系统化、更具几何解释力

**综合推荐：** 采用两个框架的**交集**作为最稳健的结论：
- 中心值：698-705 × 10⁻¹⁰（两框架共识区间的交集中心）
- 95%区间：[685, 714] × 10⁻¹⁰（两框架95%区间的交集）
- 裁决能力：**当前不可裁决，需要MUonE或独立实验复现ρ峰截面测量**
