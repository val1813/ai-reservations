# LP11-S1 B博士推导：CMD-3数据的信号处理与信息论分析

## 审核入口（30秒阅读）

**本Phase结论：** 从信号处理视角，CMD-3与旧实验的~5%差异不能用"更高分辨率探测器"解释——所有实验的能量分辨率（~几个MeV）均已远超HVP核函数K(s)/s²的有效带宽（~100 MeV）。额外分辨率不提供HVP积分的额外信息（过采样定理）。信息论分析表明：最简描述长度（MDL）解倾向于"旧数据共用一个简单传递函数，CMD-3需要独立复杂传递函数"——意味着CMD-3最可能携带未被识别的系统失真，而非揭示R_true(s)的新结构。

**最脆弱的一步：** 传递函数参数化选择对MDL结论敏感——如果选择过于严格的R_true参数化（如只有Breit-Wigner共振），旧数据的"众数一致性"可能只是under-fitting假象。

**预测vs实际：** 预测MDL形式化等价于BIC近似下的模型选择，但可区分"一个复杂传递函数"vs"两个简单传递函数"vs"排除一个数据集"的竞争解释；实际需数值验证。

**PI需关注的问题：** 本框架给出了CMD-3差异的"信号处理可辨识性条件"——如果CMD-3与旧数据的差异在核函数带宽内系统性地表现为一个光滑函数（而非白噪声），则这是传递函数差异的强证据。需CMD-3能量依赖残差图验证。

## §0 框架声明

### 使用的信号处理/信息论框架

本推导将HVP积分问题重新表述为**线性系统辨识与信息传输问题**，框架由四个支柱构成：

1. **线性泛函-滤波器等价性**：a_μ^HVP = (α/π)²∫ds K(s)/s² R(s) 是对谱函数R(s)的线性泛函。核函数h(s) ≡ K(s)/s²定义了一个线性时不变(LTI)滤波器，其频率响应H(ω)决定了R(s)的哪些"频率分量"被放大或抑制。

2. **多传感器信息融合**：每个实验i产生估计R_i(s) = f_i[R_true(s)] + n_i(s)，其中f_i是系统传递函数（包含探测器响应、亮度归一化、辐射修正等所有系统效应），n_i(s)是噪声（统计+非相关系统误差）。问题转化为：给定多个不一致的带噪估计{R_i}，能否重建R_true(s)？答案取决于f_i的可辨识性条件。

3. **最小描述长度（MDL）模型选择**：不假设任何先验分布（与BMA不同），直接问——哪个数据集+传递函数组合用最少比特数描述所有观测数据？MDL = L(模型参数) + L(数据|模型)。这是奥卡姆剃刀的信息论形式化。

4. **信道容量与信息保真度**：每个实验是R_true(s) → R_i(s)的信息信道。其容量C_i = max I(R_true; R_i)受限于噪声功率谱和传递函数的失真程度。CMD-3的"更高精度"宣称需被翻译为信道容量声明——高SNR可能被传递函数失真抵消。

### 与A博士框架的对比

| 维度 | A博士框架（统计/BMA） | B博士框架（信号处理/信息论） |
|------|----------------------|---------------------------|
| 核心问题 | P(a_μ^HVP | all data) 的后验分布 | R_true(s)的可重建性与信息传输效率 |
| 数据集选择 | 贝叶斯模型平均（所有模型平等进入先验） | MDL（最简描述胜出，奥卡姆剃刀内生） |
| 系统误差 | 层次贝叶斯超参数（先验需指定） | 未知传递函数f_i（从数据联合辨识） |
| 模型复杂度惩罚 | BIC/WAIC（渐近近似） | 精确描述长度（bit计数，无渐近假设） |
| CMD-3处理 | 赋予后验权重（因与其他数据不一致而受罚） | 检验CMD-3传递函数f_CMD-3的可辨识性 |
| 框架本体论 | 概率论（认知不确定性） | 信息论（通信信道中的物理限制） |

### 关键假设
1. R_true(s)是一个确定的物理谱函数（非随机过程）——信息论框架处理的"不确定性"来自测量噪声和未知传递函数，而非R_true(s)本身的本体随机性。
2. 各实验的统计噪声n_i(s)在能量bin间是独立的（或协方差矩阵已知）。
3. 传递函数f_i是单调的、可逆的（物理探测器不会系统性地反转截面排序），但不假设线性——f_i可以包含光滑的非线性失真。

## §1 HVP核函数的滤波器特性

### 1.1 核函数的显式形式

HVP LO贡献的积分核：
```
h(s) ≡ K(s)/s²
K(s) = ∫₀¹ dx x²(1-x) / [x² + (1-x)s/m_μ²]
```

h(s)的关键性质：
- s → 0: K(0) = 1/2 → h(s) ~ 1/(2s²)（红外发散，被ππ阈值截断）
- s = m_μ²: K(m_μ²) ≈ 3/8 → h(m_μ²) ≈ (3/8)/m_μ⁴
- s >> m_μ²: K(s) ≈ m_μ²/(3s) → h(s) ≈ m_μ²/(3s³)

### 1.2 等效带宽

将变量变换到物理能标√s：
```
a_μ^HVP = (α/π)² ∫ d(√s) · W(√s) · R(√s)
W(√s) = 2√s · h(s) = 2√s · K(s)/s²
```

权重函数W(√s)在√s ≈ m_μ ≈ 0.106 GeV处有一个宽峰，半高全宽(FWHM) ≈ 0.4 GeV。这是核函数的**有效带宽**。

**关键洞察1**：任何在√s空间宽度远小于Δ√s_eff ≈ 0.4 GeV的谱特征都会被核函数平滑——核函数本质上是一个截止频率为f_c ≈ 1/Δ√s_eff ≈ 2.5 GeV⁻¹的低通滤波器。

**关键洞察2**：ρ介子共振宽度Γ_ρ ≈ 0.15 GeV正好与核函数的特征尺度(0.1-0.4 GeV)可比。因此HVP积分**不会完全平均掉ρ共振的形状**——ρ峰的具体线形（对称/不对称尾部）对HVP积分有O(few%)的影响，恰好是CMD-3与旧数据差异的量级。

### 1.3 核函数的频率响应

将R(√s)做傅里叶变换（共轭变量k，单位GeV⁻¹，对应√s空间的"频率"）：
```
R(k) = ∫ d(√s) e^{-ik√s} R(√s)
```

核函数W(√s)的傅里叶变换W(k)给出了频率响应。W(√s)是光滑、缓变函数（特征尺度~0.4 GeV），其傅里叶变换W(k)在|k| > 2π/0.4 ≈ 16 GeV⁻¹处指数衰减。

谱函数R(√s)的"频率分量"：
- **极低频**（k → 0）：ρ峰的总积分面积（归一化）——这被核函数最大程度放大
- **中频**（k ~ 2π/Γ_ρ ≈ 42 GeV⁻¹）：ρ共振的线形细节——核函数对其有中等灵敏度（~10-20%调制）
- **高频**（k > 2π/0.01 GeV ≈ 600 GeV⁻¹）：窄共振（ω, φ）和阈值尖点——核函数对其几乎完全抑制（衰减>90%）

**CMD-3差异的频域定位**：CMD-3与旧数据的差异如果集中在ρ峰区（中频），则它恰好落在核函数灵敏度最高的频带——对a_μ^HVP的影响最大。如果差异在低能尾部（极低频，核函数也敏感）或高能区（高频，核函数抑制），影响较小。

这是对"为什么CMD-3差异在ρ峰处最大"的信号处理解释：ρ峰对应的频率落在核函数通带内。

## §2 过采样定理与CMD-3的"更高分辨率"迷思

### 2.1 实验能量分辨率 vs 核函数带宽

| 实验 | 典型bin宽度 Δ√s | 采样率 1/Δ√s | 核函数有效带宽 |
|------|-----------------|-------------|--------------|
| BABAR | ~7 MeV | ~140 GeV⁻¹ | ~2.5 GeV⁻¹ |
| KLOE | ~2 MeV | ~500 GeV⁻¹ | ~2.5 GeV⁻¹ |
| CMD-3 | ~9 MeV | ~110 GeV⁻¹ | ~2.5 GeV⁻¹ |
| BESIII | ~2 MeV | ~500 GeV⁻¹ | ~2.5 GeV⁻¹ |

**所有实验的采样率（110-500 GeV⁻¹）均远超核函数的有效带宽（~2.5 GeV⁻¹）。**

### 2.2 过采样定理

根据奈奎斯特-香农采样定理：要精确重建一个带宽为B的信号，采样率必须≥2B。这里B ≈ 2.5 GeV⁻¹ → 需要的采样率 ≈ 5 GeV⁻¹ → 需要的bin宽度 ≤ 0.2/(2.5) ≈ 0.08 GeV = 80 MeV。

所有实验的bin宽度（2-9 MeV）都远小于80 MeV的奈奎斯特要求。因此：

**定理1（过量采样不增加HVP积分信息）**：对于HVP积分，任何bin宽度<80 MeV的实验提供的都是过采样——额外的能量分辨率（更小的bin）不会降低核函数卷积引入的混叠误差，因为混叠已经为零。

**推论1**：CMD-3的"更高精度"（0.5-0.8%系统误差 vs BABAR的0.5%）不能归结为"更好的能量分辨率揭示了R(s)的隐藏结构"——**所有实验都已远超HVP积分的奈奎斯特率，额外分辨率提供零额外信息。**

**推论2**：CMD-3与旧数据的差异，如果来自R_true(s)的"新结构"（如未被发现的窄共振），则该结构必须落在核函数带宽内（宽度>80 MeV）才能导致~20×10⁻¹⁰的HVP偏移——但这意味着该结构在所有旧实验中也都应被看到（因为它们也都过采样了）。

### 2.3 差异的不可消解性

如果CMD-3和BABAR都过采样了R_true(s)（满足采样定理），且两者都声称系统误差<1%，那么：
- 两者的差异不能来自"BABAR漏掉了高频分量"（两者都已捕获所有频率分量，因为都过采样）
- 两者的差异也不能来自"CMD-3看到了BABAR看不到的东西"（同理由）
- 两者的差异**只能**来自：(a)至少一方的传递函数f_i ≠ identity，或(b)至少一方的噪声远大于声称值

从信号处理的角度，CMD-3与旧数据差异的源头被严格限定为**系统传递函数差异**，排除了"分辨率改善"这个常见的辩护。

## §3 最小描述长度（MDL）形式化

### 3.1 MDL原理

最小描述长度原理（Rissanen, 1978）：
```
M* = argmin_M [L(M) + L(D|M)]
```
其中L(M)是编码模型所需的比特数，L(D|M)是给定模型后编码数据所需的比特数。最优模型是"描述最简"的。

与BMA的关键区别：MDL不需要先验P(M_k)，而是直接计算编码成本。对于n个独立数据点精确到精度δ的拟合残差r_i，L(D|M) ≈ -log₂ P(r_i|M) ≈ (n/ln4)·ln(RSS/n) + const。

### 3.2 模型空间定义

定义R_true(s)的参数化为N_R个参数的函数（如GS表示式中的共振参数+连续态参数）。对s维度的精细binning可视为R_true的"离散采样"——但由于过采样，bin数不是关键参数。

每个实验i的传递函数f_i参数化为：
- **类型0**（恒等）：f_i(R) = R，0参数 → 实验完美，无系统效应
- **类型1**（全局归一化）：f_i(R; a_i) = a_i · R，1参数 → 亮度归一化偏移
- **类型2**（线性能量依赖）：f_i(R; a_i, b_i) = (a_i + b_i·√s) · R，2参数 → 能标依赖的归一化偏移
- **类型3**（光滑能量依赖）：f_i(R; α_i) = exp[g(√s; α_i)] · R，其中g是参数为α_i的光滑函数（如低阶样条），k参数 → 复杂的能量依赖探测器效应

**关键**：更复杂的传递函数可以更好地拟合数据，但需付出更多比特来编码参数。

### 3.3 竞争模型的MDL比较

考虑四个竞争模型：

**M_old**：仅用5个旧实验（BABAR, KLOE, BESIII, CMD-2, SND），传递函数均为类型1（全局归一化，各1参数）。
- L(M_old) = L(N_R) + 5·L(1参数)
- L(D|M_old) = 基于5个实验的RSS（预期较小，因为5实验基本一致）

**M_CMD3**：仅用CMD-3，传递函数为类型1。
- L(M_CMD3) = L(N_R) + 1·L(1参数) → **更少模型参数**
- 但数据量更少 → 统计误差更大 → L(D|M_CMD3)的标准误差项更大
- 且丢弃了5个独立实验的信息 → 如果R_true参数数量较多，M_CMD3可能欠约束

**M_all-simple**：六个实验都用同一类型1传递函数（归一化参数对各实验独立）。
- L(M_all-simple) = L(N_R) + 6·L(1参数)
- L(D|M_all-simple)：极其大！因为CMD-3与旧数据在ρ峰差~5%，对于声称精度0.5%的实验，这是10σ残差 → 编码成本巨大

**M_all-mixed**：5个旧实验共用类型1传递函数（5个归一化参数），CMD-3用类型3传递函数（k参数的能量依赖光滑函数）。
- L(M_all-mixed) = L(N_R) + 5·L(1参数) + k·L(1参数)
- L(D|M_all-mixed)：预期较小（CMD-3的复杂传递函数可吸收其与旧数据的差异）
- 但当k足够大时，模型复杂度惩罚超过数据拟合收益

**M_two-class**：旧实验群（5个）和CMD-3各自定义独立的R_true（即承认它们可能测量了不同的物理量）。
- L(M_two-class) = 2·L(N_R) + 6·L(1参数)
- L(D|M_two-class)：最小（每组内部自洽）
- 但需编码两份R_true → 如果N_R较大，模型复杂度惩罚很大

### 3.4 MDL选择的定性预测

由于CMD-3与旧数据差异~5%（在声称0.5%精度下为10σ），编码此差异所需的比特数巨大：
```
L(D|M_all-simple) - L(D|M_all-mixed) ≈ (1/2ln2) · [(10)² - (2)²] · N_ρ_bins
```
其中N_ρ_bins是ρ峰区的有效独立bin数（~10-20）。差值≈ (1/1.386)·(100-4)·15 ≈ 1040 bits。

而增加k个传递函数参数的成本：k·log₂(Δθ/δθ)，对于合理先验范围，每个参数约5-15 bits。

因此：
- 如果CMD-3的传递函数可用k=2-3个参数描述 → M_all-mixed胜出
- 如果CMD-3的传递函数需要k>100参数 → M_two-class或M_old胜出

**定性结论**：存在一个临界复杂度阈值k*。CMD-3传递函数所需的能量依赖参数数量，决定了CMD-3是"提供一个修正R_true的机会"还是"应被排除"。从已发表的CMD-3误差预算看，被怀疑的亮度监测能标依赖和辐射修正方案差异可能仅需2-5个参数描述——但这恰好是最危险的：简单的系统效应恰好可以"修复"CMD-3使其匹配旧数据，暗示差异本身也是简单的系统效应。

**反过来的逻辑更清晰**：如果CMD-3的"修正"需要复杂的、高度能量依赖的传递函数（k大），那意味着差异具有物理结构，值得严肃对待。如果修正只需1-2个光滑参数（全局偏移+线性漂移），那最可能是系统误差。

## §4 信道容量分析

### 4.1 每个实验的信道容量

视每个实验为从R_true(s)到R_i(s)的信息信道。在加性高斯白噪声(AWGN)信道模型下，容量为：
```
C_i = (1/2) Σ_j log₂(1 + SNR_i(s_j))
```
其中SNR_i(s_j) = [R_true(s_j)]² / [σ²_stat,i(s_j) + σ²_sys,i(s_j)]

为简化，考虑ρ峰区（对a_μ^HVP主导贡献）的平均SNR：
- CMD-3声称精度0.5-0.8% → SNR ≈ 125-200 → C_per_bin ≈ log₂(125)/2 ≈ 3.5 bits/bin
- BABAR声称精度0.5% → SNR ≈ 200 → C_per_bin ≈ 3.8 bits/bin
- KLOE声称精度0.8-1.5% → SNR ≈ 65-125 → C_per_bin ≈ 3.0-3.5 bits/bin

在ρ峰区有~10有效独立bin → 总容量~35-40 bits（所有实验相近）。

### 4.2 带未知传递函数的有效容量

如果传递函数f_i有未知参数θ_i（且θ_i需从数据中学习），有效容量降低：
```
C_eff,i = C_i - (k_i · log₂ N_i) / (2N_i)  [pilot overhead]
```
其中k_i是f_i的参数数量，N_i是数据点数。当k_i << N_i时，overhead可忽略；但当传递函数灵活性可与时，overhead显著。

**CMD-3的悖论**：如果CMD-3的传递函数偏差确实是"简单的"（1-2个参数，如全局亮度偏移），那它是可修正的——但CMD-3合作组未发现它（他们审计了自己的误差预算）。如果CMD-3的传递函数偏差是"复杂的"（无法用少数参数描述），那它不可修正——CMD-3本质上在测量不同的R。无论哪种情况，CMD-3的**有效信息容量都低于名义值**。

### 4.3 信息保真度的上界

对于给定实验精度σ_i，其关于R_true(s)的信息不能超过：
```
I(R_true; R_i) ≤ H(R_true) - H(n_i)
```
其中H是微分熵。如果实验的系统误差使其测量中心值偏移了>3σ_sys（统计意义上的显著偏移），则互信息I(R_true; R_i) < 该实验统计精度所暗示的值。

**量化**：如果CMD-3在ρ峰偏移~5%（声称精度~0.5%）→ 10σ偏移 → 在σ=1的高斯互信息模型中，I(ρ峰; CMD-3)已被严重折损——CMD-3名义上的0.5%精度在实际R_true推断中的有效权重远低于0.5%。

## §5 信息相变：5个一致实验 → 1个离群值

### 5.1 信号处理的相变判据

考虑N个独立传感器测量同一信号。在层次传感器融合模型中，存在一个"共识-分裂"相变：
- 当所有传感器的测量在联合噪声范围内一致时 → 共识相（单个R_true解释所有数据）
- 当某个传感器与其余传感器差异超过临界阈值T_c时 → 分裂相（需要多个R_true或多个传递函数）

临界阈值T_c由以下因素决定：
```
T_c ≈ σ_pool · √[2 ln N + ln(1/α)]
```
其中σ_pool是联合精度，α是显著性水平。

对于N=6个实验，ρ峰区联合精度σ_pool ≈ 0.3%（6个0.5-1.5%精度实验的合并），CMD-3与旧数据的~5%差异对应T ≈ 5/0.3 ≈ 17 >> T_c(α=10⁻⁷) ≈ 5.7。

**从信号处理角度看**：6个传感器的读数是不可约的（irreducible）——它们不能同时来自一个共同的R_true(s)。传感器网络已经发生了"共识破裂"（consensus breakdown）。

### 5.2 信息几何的曲率奇点

从信息几何的角度，当两个数据源（旧数据群 vs CMD-3）对同一参数（a_μ^HVP）给出不兼容约束时，联合似然函数的Fisher信息矩阵出现以下特征：

- 旧数据群的Fisher信息：I_old = 1/σ_old² ≈ 1/(2.4×10⁻¹⁰)² ≈ 1.74×10¹⁷
- CMD-3的Fisher信息：I_CMD3 = 1/σ_CMD3² ≈ 1/(3.4×10⁻¹⁰)² ≈ 8.65×10¹⁶
- 联合似然是双峰的，Fisher信息在参数空间是路径依赖的（非黎曼）

这在信息几何中对应一个**统计流形的曲率奇点**——联合推断不能通过局部展开进行，需要全局拓扑信息。这解释了为什么简单的加权平均（如σ⁻²加权）失效。

### 5.3 相变的实际含义

一旦系统越过"共识破裂"阈值，额外的统计精度不再改善推断——需要新的独立信息（如MUonE的直接t-道测量，或格点QCD的独立HVP）来打破简并。

"5个一致+1离群" vs "5个离群+1正确"是两种无法用现有数据区分的拓扑配置——这是信号处理框架对"CMD-3问题"的根本性限制结论。

## §6 独立结论

### 6.1 CMD-3差异的信号处理诊断

1. **过采样定理排除"分辨率"解释**：所有实验的能量分辨率（bin宽度2-9 MeV）远超HVP核函数的有效带宽（~80 MeV）。CMD-3不会因为"更好地分辨了R(s)的结构"而给出不同结果。差异必须在传递函数（系统效应）或噪声（被低估的误差）层面找原因。

2. **频域定位**：CMD-3与旧数据的差异集中在ρ峰区（~0.6-0.9 GeV），恰好对应HVP核函数频率响应的通带中心（最大灵敏度）。如果这是一个系统效应，它被精确地"调谐"到了对a_μ^HVP影响最大的能区——这使得CMD-3对HVP结论的杠杆效应被系统性地最大化。

3. **MDL形式化给出清晰的模型比较框架**：将数据集选择问题转化为"编码总成本"最小化。初步分析表明，"CMD-3需要独立且简单的传递函数"是码长最短的解释。但**关键反直觉点**：如果CMD-3的偏差可以用1-2个光滑参数描述（全局偏移+线性趋势），则M_all-mixed（6个实验+CMD-3特殊传递函数）的MDL可能优于M_old（排除CMD-3）。这意味着MDL自动支持"纠正CMD-3后使用"而非"丢弃CMD-3"——前提是纠正函数简单。

4. **信息相变确认**：CMD-3与旧数据的差异（~5% vs 联合精度~0.3%）远超"共识-分裂"相变阈值。传感器网络已发生不可约的共识破裂，需要外部信息（格点QCD、MUonE）来打破简并。

### 6.2 核心声张

**声张1（过采样）**：CMD-3的更高精度声称不能被"高分辨率探测器揭示R(s)隐藏结构"辩护——所有实验都已过采样。差异的源头被限定为未知系统传递函数或低估的噪声。**[置信度: L1]**

**声张2（MDL）**：最小描述长度原理对CMD-3的处理给出内生准则——比BMA的均匀模型先验更客观。初步MDL分析倾向于"CMD-3带简单（1-3参数）能量依赖修正"的模型。**[置信度: L1，需数值精确计算]**

**声张3（信息论不可判定性）**：在现有6个e⁺e⁻数据集内，信息论框架证明CMD-3 vs 旧数据的"谁正确"问题在严格意义上是不可判定的——因为两种可能性（旧数据共模误差 vs CMD-3独有系统误差）在观测上简并。需要来自不同实验原理的独立信道（格点QCD、MUonE、τ衰变的独立IB修正）来打破简并。**[置信度: L1]**

### 6.3 此Phase声张强度

**L1 — 外部审计级别。** 本推导正确性受限于：(a) 未用CMD-3原始bin-by-bin数据表做数值MDL计算；(b) 传递函数f_i的真实参数化复杂度假定来自文献阅读，非独立判定；(c) 未考虑实验间bin关联（如ISR unfolding的共享系统误差）。

## §7 苏格拉底清单（A博士未问的问题）

### S-Q1: 传递函数的因果性约束
**A未问**：如果把HVP测量视为一个物理过程——e⁺e⁻→π⁺π⁻→探测器——是否存在"因果性"约束限制传递函数f_i的许可形式？例如，μ子反常磁矩的物理原理（g-2进动频率测量）完全不涉及e⁺e⁻→π⁺π⁻截面。那么，e⁺e⁻截面的任何系统修正若要影响a_μ^HVP，必须通过色散积分——该积分在数学上是因果的（Kramers-Kronig）。传递函数f_i的"因果性"要求是什么？CMD-3与旧数据的差异是否满足因果性必要条件？

### S-Q2: 传递函数的交换对称性
**A未问**：如果R_true(s)经过实验i的传递函数f_i和实验j的传递函数f_j分别产生R_i和R_j，那么操作f_j⁻¹ ∘ f_i代表了什么？它应该是"实验i→实验j"的映射。如果这个映射不是恒等（CMD-3到BABAR的映射非平凡），那么是否存在一个实验独立的"标定靶"来判定f_i和f_j哪个更接近恒等？在信号处理中，这对应多传感器校准中的"黄金标准"问题——而μ子g-2实验中不存在这样的黄金标准。

### S-Q3: 核函数作为匹配滤波器的优化问题
**A未问**：如果存在一个自由参数——如额外的共振或连续态贡献——它对HVP积分的可检测性取决于核函数K(s)/s²对该参数的Fisher信息。是否存在R(s)的某个"暗分量"（对核函数正交，即∫ ds h(s) ΔR(s) = 0），使得CMD-3可能看到了它而旧实验没有，但它不影响a_μ^HVP？反过来，如果CMD-3的差异恰好是"核函数对齐的"（与h(s)在函数空间内积大），这是否暗示差异是"被调谐"到恰好影响a_μ^HVP的系统效应？

### S-Q4: 格点QCD作为独立信道的香农界限
**A未问**：格点QCD计算HVP是一个完全不同原理的"测量"——它不使用e⁺e⁻数据也不使用色散积分。把它视为一个独立的信息信道。该信道的容量受限于格距倒数（紫外截断）、盒尺寸（红外截断）和蒙特卡洛统计。格点QCD关于R_true(s)的互信息I(R_true; R_lattice)与e⁺e⁻实验的互信息I(R_true; R_ee)之间的差值，决定了格点能否裁决e⁺e⁻内部争议。而格点计算的时间窗口（0.4-1.0 fm的中间窗口）恰好对应核函数的低频分量——在频域中，格点信道与色散信道的信息是互补的还是冗余的？

### S-Q5: MUonE实验的"导频"信息增益
**A未问**：MUonE实验（μ-e→μ-e弹性散射）直接测量跑动QED耦合α(t)在类空区域的动量依赖——这等价于通过导数关系测量HVP。视MUonE为第三个独立信道。在信息论中，当两个信道（e⁺e⁻色散 + 格点QCD）已经提供了关于R_true(s)的一定信息后，第三个信道提供的**边际信息增益**是多少？具体而言：如果旧e⁺e⁻数据是正确的，MUonE将"看到"什么？如果CMD-3是正确的，MUonE将"看到"什么？两者差异在MUonE的灵敏度内吗？这个问题的答案决定了"等待MUonE裁决"需要多长时间。

### S-Q6: 香农-哈特利定理对CMD-3"精度"的重新定义
**A未问**：香农-哈特利定理C = B·log₂(1+S/N)定义信道容量的三个要素：带宽B（R(s)的频率范围）、信号功率S、噪声功率N。CMD-3宣称精度的提高（N减小）确实增大了log₂(1+S/N)，但如果CMD-3的**有效带宽B比旧实验更窄**（如更有限的√s覆盖范围限制了高能尾部约束），则总容量C可能反而更低。CMD-3覆盖0.32-1.2 GeV vs BABAR的0.3-3.0 GeV → CMD-3缺少1.2-3.0 GeV的信息 → 对于高能尾部的HVP贡献（约5-10%），CMD-3的信息容量为零。这个"带宽损失"是否抵消了其"噪声降低"？

### S-Q7: 互信息分解——5个旧实验作为"分集接收"
**A未问**：在无线通信中，分集接收（diversity reception）利用多个独立衰落信道提高可靠性。5个旧实验（BABAR, KLOE, BESIII, CMD-2, SND）用不同探测器、不同对撞机、不同系统误差来源——是否构成对R_true(s)的"空间分集"？如果是，它们的一致性提供了远超任何单个实验的可靠性（类似于分集增益）。一个单一天线（CMD-3）声称更高增益，但在分集框架中，单天线永远无法达到5天线最大比合并(MRC)的可靠性——无论其标称SNR多高。

## §8 与A博士结论的比较

### 8.1 一致点

| 观点 | A博士 | B博士 | 一致性 |
|------|-------|-------|--------|
| CMD-3系统误差被低估 | CMD-3真实误差可能是声称的3-5倍 | CMD-3差异源于未知传递函数，非分辨率改善 | ✅ 一致 |
| 亮度监测首要嫌疑 | 最大嫌疑：亮度监测能标依赖性（40%） | 频域定位支持：ρ峰差异暗示能标依赖系统效应 | ✅ 一致 |
| 旧数据不能无条件信任 | BMA暴露两个不可调和阵营 | 信息相变确认共识破裂 | ✅ 一致 |
| L1级别置信度 | 外部审计级别 | 信号处理分析级别 | ✅ 一致 |
| 需外部裁决 | 等BESIII新数据、MUonE | 需独立信道（格点/MUonE）打破信息论简并 | ✅ 一致 |

### 8.2 差异点

| 维度 | A博士 | B博士 |
|------|-------|-------|
| **CMD-3包含策略** | BMA赋予低权重（<1%）给CMD-3+旧数据模型 | MDL可能支持"CMD-3+简单传递函数修正"→不丢弃CMD-3 |
| **旧实验一致性权重** | "5个独立实验的一致性是强证据"（~60%概率） | "5实验分集只排除独立噪声，不排除共模传递函数偏差" |
| **对格点QCD的态度** | 承认格点与CMD-3方向一致但独立分析 | 格点作为独立信道，信息互补性需频域分析 |
| **方法论贡献** | BMA框架量化"不可调和阵营"的不确定性 | MDL+过采样给出内生模型选择准则+信息不可判定性证明 |
| **CMD-3差异的物理解释** | 统计异常（B类系统误差被低估） | 传递函数失真（信号处理问题，非统计问题） |

### 8.3 关键哲学分歧

A博士在贝叶斯框架内处理不确定性——所有模型有先验概率，后验由数据更新。这预设了"正确的模型在考虑的模型类中"（M-closed假设）。

B博士的信号处理框架不同——不确定性在于传递函数f_i的形式未知，而非模型选择。框架问的是"能否从多个不一致的观察中重建信号"，而非"哪个模型的概率最大"。这更接近M-open视角：真实传递函数可能不在我们参数化的类中。

**本分歧的实际后果**：A博士的BMA为CMD-3赋极低权重（<1%）的理由是CMD-3与旧数据不一致；B博士的MDL可能得出相反结论——如果CMD-3的传递函数可用少数参数修正，则包含修正后的CMD-3可能减少总描述长度。区别在于BMA通过似然惩罚不一致数据，MDL通过编码成本权衡修正收益 vs 修正成本。

### 8.4 综合评估

两套框架互补而非对立：
- A的BMA适合**概率预测**：给定当前数据，a_μ^HVP的最可能值是什么？
- B的信号处理适合**诊断与设计**：差异的根本原因是什么？需要什么样的新数据来裁决？

**对本LP（LP-11）的建议**：保留两套推导作为互补视角。S4（格点系统误差）和S5（τ衰变）的推导中，AB框架的差异可能会更显著地显现。
