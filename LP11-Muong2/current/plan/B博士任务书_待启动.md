## B-S1: CMD-3重分析（信号处理/信息论框架）

**禁止使用A的框架**：统计方法(BMA)和现象学
**必须使用**：将HVP积分视为信号处理问题（反卷积+低通滤波），CMD-3 vs 旧数据差异视为不同"探测器"的系统传递函数差异

### 推导方向
1. 将色散关系积分 a_μ^HVP = (α/π)²∫ds K(s)/s² R(s) 视为对谱函数R(s)的线性泛函
2. 分析K(s)/s²核函数对不同能区的频率选择性放大/压缩
3. 将每个实验视为R_true(s)的带系统误差的估计器：R_i(s) = f_i(R_true(s)) + n_i，其中f_i是系统传递函数
4. 问题转化：能否从多个不一致的估计器{R_i}中重建R_true(s)？
5. 关键定理：当f_i未知且可能非线性的情况下，估计器不一致性的可辨识性条件
6. 导出：CMD-3 vs 旧数据差异的"信号处理"解释——是f_CMD-3不同还是n_CMD-3异常？

### 苏格拉底清单（必须生成≥5个A没有问的问题）
示例问题类型：
- 如果HVP核函数是一个"低通滤波器"，不同能区的系统误差在滤波后是被放大还是压缩了？
- CMD-3的"分辨率"（bin宽度、能量校准精度）与旧实验有本质差异吗？
- 能否将"数据集选择"问题形式化为信息论中的模型选择问题（MDL/BIC）？

## B-S2: IB修正系统化（格点QCD/EFT matching框架）

**禁止使用A的框架**：ChPT+色散关系
**必须使用**：从格点QCD的角度出发，将IB修正视为"格点世界→真实世界"的匹配问题

### 推导方向
1. 格点QCD在m_u=m_d, α_QED=0的iso-symmetric世界中计算
2. IB修正 = 将iso-symmetric结果matched到物理点(m_u≠m_d, α_QED≠0)的EFT matching
3. 色散方法的IB修正 = 从e⁺e⁻数据（物理点）subtract IB效应回到iso-symmetric极限
4. 论证：两种"IB修正"实际上做的是相反方向的matching → 它们应该互为逆操作
5. 如果两者不自洽 → 意味着至少一方的matching procedure有gap
6. 使用Symanzik有效场论框架分析格点离散化误差如何与IB修正耦合

### 苏格拉底清单（必须生成≥5个A没有问的问题）
示例：
- 格点QCD计算在m_u=m_d时使用的"参考理论"与色散方法subtract IB后到达的"iso-symmetric极限"是同一个理论吗？
- 如果格点使用staggered费米子→taste-breaking产生额外的IB-like效应，这个效应在色散方法中有对应物吗？
- RM123展开的截断误差在哪些项上与ChPT的圈展开截断误差可比？

## B-S7: 模型无关HVP约束（贝叶斯层次建模/信息几何框架）

**禁止使用A的框架**：EW精密拟合+Roy方程
**必须使用**：将HVP约束问题视为"多源信息的贝叶斯融合"问题，用信息几何分析约束的独立性

### 推导方向
1. 每个HVP约束来源（EW fit, Roy方程, 格点, 每个e⁺e⁻实验, τ衰变, MUonE）定义likelihood函数
2. 用层次贝叶斯模型融合所有信息源，显式参数化源间相关性
3. 关键：不假设任何单一数据源是"正确的"——每个源有未知系统误差超参数
4. 用Fisher信息矩阵分析：哪些观测量对HVP提供最多独立信息？
5. 信息几何：计算每个约束在a_μ^HVP参数空间中的"方向"——它们是否都在测量同一个自由度？
6. 导出：即使不信任色散或格点任何一方，融合所有信息的"最小共识"HVP值

### 苏格拉底清单（必须生成≥5个A没有问的问题）
示例：
- EW fit和Roy方程对HVP的约束是否是"正交"的——它们在参数空间中的梯度方向是否独立？
- 如果所有数据源共享同一个未知系统误差（如QED辐射修正的特定近似），层次模型能否检测到？
- 层次贝叶斯模型的超先验选择对最终HVP约束的敏感性——是否存在先验支配结论的风险？
