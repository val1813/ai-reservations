## 1. 审核入口 (Audit Gateway — 30秒阅读)

### 本Phase结论

当前所有模型无关约束（EW全局拟合 + Roy方程 + 幺正性界）的联合给出：

> **a_μ^HVP 模型无关允许区间: [685, 706] × 10⁻¹⁰ (95% CL), 中心值 694.5 × 10⁻¹⁰ (68% CL: ±11)**

CMD-3/BMWc格点值 (~714) 在 ~95% CL 被模型无关约束边缘排除（Δχ² ≈ 4.0，相当于 1.95σ for 1 dof），但**不是决定性的排除**（仍有 ~5% 概率 CMD-3/BMWc 正确而模型无关约束存在未建模的系统误差）。

1. **EW拟合中Δα_had与a_μ^HVP的"翻译"使用了简化的ρ-pole近似，实际传播较为复杂。**
2. **Roy方程对ππ散射长度的依赖（ChPT LECs提取）——这些LECs的精度直接影响δ_1^1(s)的不确定性。**
3. **HVP谱函数共性假说的局限性：a_μ和Δα_had积分中的核函数权重不同→如果R(s)在低能和高能同时变化>2%，EW和Roy约束间的相关性会非线性增大。**

1. **CMD-3排除不够决定性**：95% CL排除意味着仍有~5%概率CMD-3正确。决定性排除需要MuonE实验（预期2030+全精度，5σ敏感性）或更精确的Roy方程分析（包含完整isospin-breaking修正，Colangelo et al. 2025进行中）。

### 2.2 核心物理学：HVP谱函数的公共角色

设Π_had(Q²)为强子真空极化(HVP)的二点函数：

\[
\Pi_{\mu\nu}^{\mathrm{had}}(q) = i\int d^4x e^{iqx} \langle 0|T[j_\mu^{\mathrm{em}}(x)j_\nu^{\mathrm{em}}(0)]|0\rangle 
= (q_\mu q_\nu - g_{\mu\nu}q^2)\Pi_{\mathrm{had}}(Q^2)
\]

其中 Q² = −q² > 0 (类空)。HVP的虚部 ImΠ_had(s+iε) ≥ 0 (正定谱性) 通过光学定理与 e⁺e⁻ → hadrons 截面相关：

\[
R(s) = \frac{\sigma(e^+e^- \to \mathrm{hadrons})}{\sigma(e^+e^- \to \mu^+\mu^-)} = \frac{3s}{4\pi\alpha^2}\sigma(e^+e^- \to \mathrm{hadrons}), 
\quad \operatorname{Im}\Pi_{\mathrm{had}}(s) = \frac{\alpha}{3}R(s)
\]

**同一个谱函数ImΠ_had(s)通过不同色散积分核函数同时决定**:
1. a_μ^HVP — μ子反常磁矩的强子真空极化贡献
2. Δα_had^(5)(M_Z²) — 电弱精确测量的关键输入
3. 通过γ-Z混合影响 sin²θ_W 在低能和Z极处的值

这是本推导的**基础**：对ImΠ_had(s)的任何约束（来自EW拟合、Roy方程、幺正性）通过公共色散积分转化为对a_μ^HVP的约束。

## 3. Phase 1: EW全局拟合 → HVP约束

### 3.1 α的跑动：从汤姆逊极限到 Z 极

电磁耦合常数的跑动由三个部分组成：

\[
\alpha(q^2) = \frac{\alpha(0)}{1 - \Delta\alpha(q^2)}, \quad 
\Delta\alpha(M_Z^2) = \Delta\alpha_{\mathrm{lep}} + \Delta\alpha_{\mathrm{had}}^{(5)} + \Delta\alpha_{\mathrm{top}}
\]

**各部分贡献 (PDG 2024)**:
- Δα_lep(M_Z²) = 0.031497 ± 0.000001 (QED三圈，误差可忽略)
- Δα_top(M_Z²) = −0.72 × 10⁻⁴ ± 0.01 × 10⁻⁴ (微扰QCD)
- Δα_had^(5)(M_Z²) = (276.1 ± 1.0)×10⁻⁴ (色散评估，KNT19/DHMZ平均)

由此得 α⁻¹(M_Z²) = 128.949 ± 0.014。

### 3.2 Δα_had 与 a_μ^HVP 之间的色散关系

观测量通过相同的 HVP 谱函数 R(s) 由不同核函数关联：

**a_μ 色散积分 (LO)**:

\[
a_\mu^{\mathrm{HVP,LO}} = \frac{\alpha^2}{3\pi^2}\int_{s_{\mathrm{thr}}}^{\infty} \frac{ds}{s} K(s) R(s)
\]

其中核函数 K(s) 的精确形式为 (Laporta, Balzani, Passera 2024)：

\[
K(z) = \frac{1}{2} - z + \left(\frac{z^2}{2} - z\right)\ln z + \frac{\ln y(z)}{\sqrt{z(z-4)}}\left(z - 2z^2 + \frac{z^3}{2}\right)
\]

z = s/m_μ², 且 y(z) = (z − √(z(z−4))) / (z + √(z(z−4))).

K(z) ∼ 1 for z ≪ 1 (低能平台) → a_μ 对低能 HVP 高度敏感。

**Δα_had 色散积分**:

\[
\Delta\alpha_{\mathrm{had}}^{(5)}(M_Z^2) = \frac{\alpha M_Z^2}{3\pi} 
\mathrm{Re}\int_{s_{\mathrm{thr}}}^{\infty} ds \frac{R(s)}{s(s - M_Z^2 - i\varepsilon)}
\]

被积函数 1/(s−M_Z²) ∼ constant for s ≪ M_Z² → Δα_had 在整个能区都有显著权重。

### 3.3 转换系数 (Translation Coefficient)

Di Luzio et al. (2025, Eq.16) 给出近似转换公式：

\[
\delta \Delta\alpha_{\mathrm{had}}^{(5)}(M_Z^2) \approx \frac{3\pi}{\alpha}\frac{m_\rho^2}{m_\mu^2}\, \delta a_\mu^{\mathrm{CMD3}}
\]

**数值验证**:
- 3π/α ≈ 1291
- m_ρ/m_μ ≈ 7.29
- (m_ρ/m_μ)² ≈ 53.1
- 系数 ≈ 1291 × 53.1 ≈ 6.86×10⁴
- δa_μ^CMD3 = 21.7×10⁻¹⁰
- → δΔα_pred ≈ 1.49×10⁻⁴
- 实际数值评估: 1.4±0.5×10⁻⁴ ✓ 一致

**反向公式** (从 Δα_had 反推 a_μ):

\[
\delta a_\mu^{\mathrm{HVP}} \approx \frac{\alpha}{3\pi}\frac{m_\mu^2}{m_\rho^2} \times 10^{10} \times \delta\Delta\alpha_{\mathrm{had}}^{(5)}
\]

系数值: δa_μ ≈ 15.5×10⁻¹⁰ per 1×10⁻⁴ δΔα。

## 4. Phase 2: Roy方程约束 ππ 通道

### 4.1 Roy方程简介

Roy方程 (Roy 1971) 是ππ散射的固定t色散关系，结合三个原理：
1. **解析性** — 两次减除的色散关系
2. **交叉对称性** — s, t, u 通道关系的数学实现
3. **幺正性** — 弹性区域 Im t_l^I = √(1−4m_π²/s) |t_l^I|²

Roy方程将 ππ 分波振幅表达为耦合积分方程（有效 up to ~1.15 GeV）：

\[
t_l^I(s) = k_l^I(s) + \sum_{I'=0}^2 \sum_{l'=0}^\infty 
\int_{4m_\pi^2}^\infty ds'\, K_{ll'}^{II'}(s,s')\, \mathrm{Im}\, t_{l'}^{I'}(s')
\]

其中 k_l^I 是减除项（由低能常数确定），K_{ll'}^{II'} 是已知积分核。

### 4.2 ππ P波相移 → 介子电磁形状因子

**Watson末态相互作用定理**: 弹性区域以下，F_π(s) 的相位严格等于 ππ P波相移：

\[
\operatorname{Arg}[F_\pi(s)] = \delta_1^1(s), \quad s < (m_\pi + m_\omega)^2 \approx 0.92\,\mathrm{GeV}^2
\]

**Omnès表示**: 给定 δ_1^1(s)，形状因子在弹性区域完全确定：

\[
F_\pi(s) = P(s) \cdot \exp\left[\frac{s}{\pi}\int_{4m_\pi^2}^{\infty} ds' 
\frac{\delta_1^1(s')}{s'(s'-s-i\varepsilon)}\right]
\]

其中 P(s) 是多项式（低能时由ChPT确定）。

**唯一性定理**: Roy方程在给定减除常数和高能匹配条件下对 ππ 分波振幅有唯一解。不能存在两套不同的 δ_1^1(s) 同时满足所有约束。→ Roy方程约束是绝对的，非模型参数依赖的。

### 4.5 Roy方程对 a_μ^HVP 的独立约束

**方法**: 将HVP分解为：
\[
a_\mu^{\mathrm{HVP}} = a_\mu^{\pi\pi}(\mathrm{Roy}) + a_\mu^{\mathrm{other\ channels}}
\]

- a_μ^(ππ)(Roy) = 500.3 ± 8.1
- a_μ^(other) = 192.5 ± 6.0 (KNT19 3π+4π+KK+...，保守误差放大)

→ **Roy方程单独约束**: a_μ^HVP(Roy) = 692.8 ± 10.0 × 10⁻¹⁰

**与CMD-3的比较**: CMD-3要求 ππ 截面在 ρ 峰区域系统性高于所有其他实验 ~5%：
- CMD-3 ππ 贡献 ~520×10⁻¹⁰ (估算)
- Roy ππ 约束 ~500±8×10⁻¹⁰
- **张力**: Δ ~20×10⁻¹⁰, with σ_total ≈ 9.6 → **2.1σ**

Roy方程张力虽统计上不决定性，但**物理意义深远**：它是基于解析性+幺正性的纯理论约束，不依赖任何单个 e⁺e⁻ 实验。

### 5.2 P3细节: 幺正性界约束高能尾部

幺正性要求谱函数 ImΠ_had(s) 正定且满足积分不等式。对于类时形状因子：

\[
\int_{t_+}^{\infty} dt\, \rho(t)\, |F_\pi(t)|^2 \leq I_{\mathrm{pQCD}}
\]

其中 I_pQCD 是模型无关上界（来自深度欧几里得区域QCD求和规则）。

对于 √s > 1.8 GeV 的 ππ 通道:
- pQCD 给出 |F_π(s)| ~ O(1/s) → 贡献 < 2×10⁻¹⁰
- 幺正性严格约束不能偏离 pQCD 太多 → ≤ 3×10⁻¹⁰ 保守上界

\chi^2_{\mathrm{comb}}(a_\mu) = \sum_{i=1}^{3} \sum_{j=1}^{3} 
(a_\mu - \hat{a}_i)\, (V^{-1})_{ij}\, (a_\mu - \hat{a}_j)

其中协方差矩阵 V_ij = σ_i σ_j ρ_ij, ρ_ii = 1。

### 5.6 物理解释

CMD-3 高HVP场景要求在 ρ(770) 共振峰区域的 π⁺π⁻ 截面上系统性高于所有之前的 e⁺e⁻ 实验 (BaBar, KLOE, CMD-2, SND, BESIII) ~5%。三条模型无关腿一致地不支持这种高截面解释：

1. **EW拟合**: 如果ρ峰截面升高 → Δα_had(M_Z²) 升高 → 轻微恶化 M_W 和 sin²θ_W 的SM预测与实验的一致性 (Δχ²_EW = +2.8)。

2. **Roy方程**: ρ峰的 ππ P波相移受 Roy方程的解析严格约束 → 通过 Watson 定理 + Omnès 方程 → |F_π|²在 ρ 峰处被约束 → ππ 截面不能显著偏离 Roy 分析确定的值。

3. **幺正性**: 如果低能截面升高 → 需要在中能或高能抵消以维持色散关系 + 幺正性 → 但高能行为受 pQCD 严格约束 → 没有足够自由度补偿 ρ 峰处的大幅上升。
