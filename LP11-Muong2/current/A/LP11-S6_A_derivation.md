# LP11-S6 A博士推导：MUonE实验对HVP张力的判别能力

## ⚡审核入口（30秒阅读）

**本Phase结论：** MUonE（CERN，μ-e弹性散射）是唯一完全独立于e⁺e⁻→强子和格点QCD的HVP测量方法——它直接测量类空区域的强子真空极化。2025年Phase-1测试运行成功完成，首物理结果预计2026年中之前（在CERN LS3开始前）。但全精度判别（<0.5% on a_μ^HVP）需要40站全规模实验，预计>2030（LS3后）。当前时间线：2026年概念验证→LS3期间（2026-2029）设计全规模实验→2030+数据获取→2032+最终HVP结果。这意味着MUonE不能在2020年代内裁决HVP张力。

**最脆弱的一步：** MUonE的最终系统误差预算（特别是μ束能量校准到<few MeV和探测器对齐到<10 μm）是否可行——这些目标在技术上极具挑战性。

**预测vs实际：** 预测MUonE在概念验证阶段（2026）只能给出~20%统计+~20%系统的HVP测量——不足以区分阵营。实际需等待2026年结果公布。

**PI需关注的问题：** MUonE时间线（>2030全精度）意味着LP-11在短期（~5年内）无法通过独立实验关闭。这意味着HVP张力的解决在中期可能依赖理论/meta-analysis进展（如S1-S4的工作）而非新实验数据。

## §0 方法论声明

### 框架：μ-e散射运动学 + 误差传播 + 时间线投影

MUonE测量原理：
- 160 GeV μ束（CERN SPS M2 beamline）打在低Z靶（铍）上
- 测量弹性μ⁻e⁻→μ⁻e⁻散射的微分截面dσ/dt
- 类空动量转移范围：-0.153 GeV² < t < 0（t = q²，q为转移动量）
- 通过截面形状提取Δα_had(t)（强子真空极化在类空区域的运行耦合）

关键关系：
R_had(t) = dσ/dt[含Δα_had] / dσ/dt[无Δα_had] ≈ 1 + 2Δα_had(t)

从测量的Δα_had(t)通过色散关系积分得到a_μ^HVP：
a_μ^HVP = (α/π) ∫₀¹ dx (1-x) · Δα_had[t(x)]

其中t(x) = -x²m_μ²/(1-x)（类空→类时映射来自标准色散关系）。

### 与现有方法的独立性

| 特征 | e⁺e⁻色散 | 格点QCD | MUonE |
|------|---------|---------|-------|
| 输入 | e⁺e⁻→强子截面 | QCD Lagrangian | μ-e散射截面 |
| 动量区域 | 类时(q²>0) | 类空(q²<0) | 类空(q²<0) |
| 主导系统误差 | 数据间张力+辐射修正 | 离散化+IB修正 | 束能量+对齐 |
| 独立性 | 基准（自引用） | 独立（QCD第一性原理） | **完全独立**（电磁+弱过程） |

## Phase 2: 灵敏度投影

### 2.1 统计精度 vs 积分亮度

a_μ^HVP的统计误差随积分亮度的标度：
δa_μ(stat) ≈ 10×10⁻¹⁰ / √(L / 1.5×10⁷ nb⁻¹)

| 积分亮度 L | δa_μ(stat) (×10⁻¹⁰) | 所需运行时间 |
|-----------|---------------------|------------|
| 10⁵ nb⁻¹ (2025测试) | ~120 | 3个月（已完成） |
| 10⁶ nb⁻¹ | ~38 | ~1年（LS3前不可行） |
| 10⁷ nb⁻¹ (Phase-2初期) | ~12 | ~1-2年（>2030） |
| 1.5×10⁷ nb⁻¹ (全规模目标) | ~10 | ~3年（>2032） |

### 2.2 系统误差目标

| 系统误差源 | 目标精度 | 对a_μ的影响(×10⁻¹⁰) | 可行性 |
|-----------|---------|---------------------|--------|
| μ束能量 (160 GeV) | <few MeV | ~2-4 | ⚠️ 挑战——需BMS到<10⁻⁴ |
| 探测器对齐 | <10 μm | ~1-3 | ⚠️ 挑战——需精密测量 |
| 多重散射 | <1% | ~2-5 | ✅ 低Z靶+模块化设计 |
| QED辐射修正(NNLO) | <0.1% | ~1-2 | ✅ 理论计算前进中 |
| 强子本底扣除 | <2% | ~1-2 | ⚠️ 需数据驱动方法 |
| **总计（正交和）** | — | **~5-8** | **乐观:3-5, 基准:5-8, 悲观:8-12** |

### 2.3 判别HVP张力所需精度

当前HVP张力（旧色散 vs CMD-3/格点）：~20×10⁻¹⁰
区分两个阵营（3σ）：需要δa_μ(MUonE) < 7×10⁻¹⁰
区分两个阵营（5σ）：需要δa_μ(MUonE) < 4×10⁻¹⁰

基准场景（δa_μ ≈ 5-8×10⁻¹⁰）：能达到~2.5-4σ区分→"方向性"而非"确定性"
乐观场景（δa_μ ≈ 3-5×10⁻¹⁰）：能达到~4-7σ区分→"确定性"裁决

## Phase 3: MUonE时间线+最终HVP裁决

### 3.1 三种场景

**场景A（乐观）：**
- 2026年概念验证：~20% HVP测量（证明方法可行）
- 2029年（LS3结束）：全规模实验获批+建设启动
- 2031年：首10%统计量→~3-4σ区分
- 2032年：全统计量→~5σ裁决

**场景B（基准——最可能）：**
- 2026年概念验证成功
- 2030年全规模实验开始数据获取
- 2032年首次HVP结果（~2-3σ）
- 2035年最终HVP结果（~4-5σ）

**场景C（悲观）：**
- 2026年概念验证发现未预期系统误差→方法可行性存疑
- LS3期间方法重新评估
- 2030+仍不确定是否能达到所需精度
- HVP张力依赖格点IB修正+S1-S4 meta-analysis+可能的BESIII新e⁺e⁻数据解决

### 3.2 MUonE在HVP裁决中的角色

MUonE的优势：**它是唯一完全独立于当前争议的测量方法。** e⁺e⁻数据有CMD-3 vs 旧数据的分歧；格点有IB修正的系统误差问题。MUonE使用完全不同的物理过程（μ-e散射而非e⁺e⁻湮灭，类空而非类时）→如果MUonE与任一阵营一致，则该阵营获得强有力的独立验证。

MUonE的劣势：**时间线。** 在MUonE给出决定性结果之前（~2030-2035），HVP张力的解决将依赖：
- BESIII新e⁺e⁻→π⁺π⁻数据（可望在未来2-3年）
- 格点IB修正的收敛（正在进行）
- CMD-3系统误差的独立实验检验（需要另一组重复CMD-3的测量）
- Meta-analysis/methodology改进（如本LP-11的工作）

### 3.3 综合时间线

| 时间 | 事件 | 对HVP张力的影响 |
|------|------|---------------|
| 2026年中 | MUonE概念验证结果 | 证明第三方法可行 |
| 2026-2029 | CERN LS3 | MUonE暂停，依赖其他进展 |
| 2027-2028 | BESIII新ππ数据 | 可能独立检验CMD-3 |
| 2028-2030 | Belle-II τ数据(1-10 ab⁻¹) | τ→ππν达到区分能力 |
| 2030+ | MUonE全规模运行 | 最终独立裁决 |
| 2032-2035 | MUonE最终结果 | HVP张力解决（或深化） |

## 结论

**MUonE是HVP张力的最终独立裁决者——但时间线延迟到2030+。在MUonE给出决定性结果之前（5-10年），LP-11的研究（S1-S5的系统误差审计+方法论改进）是推动领域前进的主要手段。**

2025年测试运行的成功证明方法可行。首物理结果（2026年中）将给出~20%精度的HVP测量——足以验证方法但不足以区分阵营。

**对LP-11的影响：**
S6确认了HVP张力不会在短期内被独立实验关闭——这增加了S1-S5工作的价值（它们是中期内唯一能推动问题解决的路径）。同时，MUonE的长期前景为所有当前的meta-analysis提供了最终的"真相标准"——这是一个强有力的科学动机。

**此Phase的声张强度：L1**（基于公开MUonE报告+标准误差传播分析）
