# 研究计划 — FlatBand-TopoBound (LP10-S1) v1

## 北极星（来自候选池 LP10-S1）
多轨道孤立平带超导中是否存在超流权重 D_s 的拓扑下界？即 D_s ≥ f(C, N_flat/N_orb) 这类仅由量子几何/拓扑量决定、不依赖轨道嵌入细节的正下界，能否被严格证明，还是可被构造性反例推翻？

## 驱动矛盾
**命题A（拓扑下界存在）：** 对 N_flat 个孤立平带组成的复合带（总带数 N_orb），在均匀配对（uniform pairing，序参量在轨道空间正比于单位算符的投影）下，超流权重张量满足
  D_s ≥ (常数) × [BZ 上量子度量张量积分的下界] ≥ (常数') × |C|（或更一般的拓扑不变量），
其中量子度量 g_{μν}(k) 由平带 Bloch 态的 Fubini-Study 度规给出，且 ∫_BZ √det g ≥ π|C| / (2π)² （Marzari-Vanderbilt / Roy 型不等式）。该下界是拓扑保护的：Chern 数 C≠0 ⟹ 量子度量不可处处为零 ⟹ D_s 有正下界。对无序和多轨道混合，下界以可控方式存活。

**命题B（下界不存在，几何贡献非普适）：** 超流权重的"几何贡献"分解依赖最小量子度量（minimal quantum metric，相对轨道位置的规范）。轨道嵌入位置（Wannier 中心 / 轨道坐标 r_α）进入 D_s 表达式：存在轨道构型使所谓"晶格几何项"（lattice geometric term）与带间量子度量项部分相消，从而 D_s → 0 即使 Tr[g] 的 naive 积分有限。因此不存在仅由 (C, N_flat/N_orb) 决定的普适正下界——下界（若有）必须显式包含轨道嵌入信息，即非拓扑。

> 两者不能同时为真：A 主张下界是嵌入无关的拓扑量；B 主张任何真实下界必须嵌入依赖，故"拓扑下界"作为普适陈述为伪。**判别焦点 = 超流权重表达式中"量子度量的规范依赖性 / 轨道位置依赖性"是否可被均匀配对+孤立平带条件消除。**

## 合法性确认（三问）
1. 命题A vs 命题B，不能同时为真？→ **是**（"存在嵌入无关的正下界" 是一个数学上二值的命题：要么可证，要么有反例）。
2. 解决后谁的工作会改变？→ 平带超导理论组（Törmä/Peotta/Iskin/Hyart 等）对"量子几何是 Tc 主宰参数"的信心；魔角石墨烯/kagome 金属实验组对几何贡献的解读；高温超导材料设计（若下界存在 → 几何驱动找高 Tc 的新范式）；本 LP 的 S2/S5/S7 全部依赖 S1 结论。
3. 新结构介入还是技术推广？→ **新结构介入**：把"几何贡献是否普适"重述为"超流权重张量在轨道嵌入规范群作用下的不变量结构"——引入纤维丛/规范不变量的判别结构，而非单纯在更多模型上数值堆砌。

## 关键路径地位
LP10-S1 是 LP-10 依赖图的根节点之一（与 S6 并行）。S2（DMFT 验证）、S5（非孤立平带修正）直接依赖 S1；综合推导触发条件 "S1+S2+S5" 含 S1。S1 的结论方向（下界存在/反例/有边界）决定整个 LP-10 是"几何主宰范式"还是"几何非普适"。

## 研究路径（候选池三步 + SOP 细化，待苏格拉底命题确定后修订）
### Phase 1：下界成立的充分条件 / 存在性 or 反例（解析）
- 综述现有几何下界文献：Peotta-Törmä 2015（原始下界 D_s ≥ 几何项）、Liang et al. 2017、Herzog-Ardizzone 2019、Huhtinen-Törmä 2022（minimal quantum metric / 轨道位置依赖）、Jiang-Barlas 2024（复合带公式）。
- 提取"下界成立"的充分条件清单：孤立平带？均匀配对？轨道数限制？规范选择（minimal metric）？
- 命题 A 路径：尝试严格化——用 Wannier 函数指数局域性 + 量子度量正定性 + Cauchy-Schwarz 给出 D_s ≥ c·∫√det g ≥ c'|C|。
- 命题 B 路径：若充分条件有漏洞 → 构造反例（特定轨道构型使 D_s^geom 在某规范下 →0）。这正是 Huhtinen-Törmä 2022 minimal metric 的核心张力。
- 产出：定理（带明确充分条件）或构造性反例（K条目）。

### Phase 2：数值验证最小模型（解析为主，2-3带最小模型 BdG + 线性响应）
- 在 2-3 带最小模型（Lieb / sawtooth / 修正 Lieb）上用 BdG + 线性响应验证 Phase1 的解析下界。
- 检验下界在改变轨道嵌入位置 r_α 时是否被违反（命题B的直接数值检验）。
- 产出：数值确认 + 解析公式的适用范围。

### Phase 3：拓扑不变量与下界的精确关系
- 若下界存在：它由 C 控制还是由更精细的量子几何量（如最小量子度量的迹下界、Euler 类）控制？
- 检验 C=0 但 Tr[g]≠0 的"obstructed atomic / fragile"平带的下界形态。
- 产出：拓扑量-下界对应（或"下界非拓扑"的精确表述）。

## 风险
- 自毁/重复造轮子风险：**高**。量子几何超流权重是 2015-2026 高度活跃领域，"是否存在拓扑下界"很可能已被 Peotta-Törmä / Huhtinen-Törmä / Tian et al. 等部分回答 → GATE 0 先发查重是第一优先级硬门。Huhtinen-Törmä 2022（minimal quantum metric）极可能已论证"naive 几何贡献规范依赖、真实下界用 minimal metric"——需精确定位本课题增量。
- 最脆弱假设：①"均匀配对"是否物理（实际配对由相互作用决定，不一定均匀）；②"孤立平带"在真实材料中从不严格（S5 处理），Phase1 必须显式声明孤立极限；③"几何项 vs 常规项"分解只在线性响应+特定规范下严格。
- 工具可达性：解析推导（带表示论 + 量子几何张量）可行，无需 GPU；最小模型 BdG 经典可算（小矩阵对角化）。Phase 2 不降级。
