## 第1轮 — 群论（对称性↔不变量）

**视角：** 轨道嵌入选择 {r_α}（把第 α 个轨道放在原胞内哪个位置）构成一个作用在 Bloch 哈密顿量上的规范群 G：
  H(k) → V(k) H(k) V(k)†，  V(k) = diag(e^{i k·r_α})。
物理可观测量（能谱、超流权重 D_s）在 G 下不变；但量子度量 g(k)（Fubini-Study 度规）**不是 G-不变的**——它随 r_α 改变。这正是命题B的火力点：用 G 可把 naive ∫Tr[g] 调大调小。

**追问（什么在 G 下不变？）：** Berry 曲率 Ω(k) = ∂_x A_y − ∂_y A_x 是 G-不变的（Berry 联络 A 在 G 下移动一个恰当形式 dχ，其旋度不变）。

**结构同构（非类比）：** 量子几何张量 QGT = g − (i/2)Ω 中，**实部 g 是 G-协变（gauge-covariant），虚部 Ω 是 G-不变（gauge-invariant）**。逐点不等式
  det g(k) ≥ (Ω(k)/2)²    （QGT 半正定性的直接推论）
左边 G-协变、右边 G-不变，但**该不等式在每个规范下都成立** → 它是 G-等变（G-equivariant）的。
⟹ 对 G-轨道取下确界：min_{g∈G·g₀} det g(k) ≥ (Ω(k)/2)²。
**这是判别的关键种子：下界的"嵌入无关性"不靠 g 本身不变，而靠不等式 G-等变 + 右边 G-不变量 Ω。**

本轮可见的东西：命题A若要成立，下界必须只用 G-不变量（Ω 及其积分 C），不能用 naive g。

## 第2轮 — 信息论（压缩↔损失↔信道容量）

**视角：** 量子度量 g(k) = (1/4)×量子 Fisher 信息（Provost-Vallée / 量子估计理论）——它度量"从 Bloch 态 |u(k)⟩ 估计参数 k 的可分辨性"。Tr[g] = 相邻 Bloch 态的局域可分辨度；∫_BZ Tr[g] = 平带在整个 BZ 上的"量子可分辨性预算"。超流权重 D_s^geom ∝ ∫Tr[g] = 这个预算（均匀配对、孤立平带极限）。

**追问（投影到平带损失了什么信息？）：** QGT 的反对称部分 Ω 是"辛/相位信道"。量子估计的不确定性关系（QGT 半正定 ⟹ Robertson-Schrödinger 型）给出矩阵不等式
  g ≥ |Ω|/2    （矩阵意义，本征值下界）。
即：Fisher 信息矩阵必须支配辛形式。

**结构同构（非类比）：** **QGT 行列式不等式 = 量子不确定性关系 = Cramér-Rao 型下界。** 三者是同一个数学事实在三个领域的化身。物理含义：**不可能有一个携带非零辛通量（Chern 数）的平带，而不付出最小的 Fisher 信息（量子度量）代价。** 而 Fisher 信息的"可分辨能力"是基/规范无关的（虽然其矩阵表示 G-协变），G-不变的内容正是由 Ω 设定的本征值下界。

本轮可见：命题A的下界 = 一个信息论必然性（携带拓扑荷必付信息代价）；命题B只能在"拓扑荷为零"时找到空隙。

## 第3轮 — 拓扑学/纤维丛（连续变形↔不变性质）

**视角：** 孤立平带 = BZ（2D 即 T²）上的复向量丛。Chern 数 C = 全局光滑规范的障碍 = (1/2π)∫Ω。

**追问（什么性质在 G 变形下保持？）：** Marzari-Vanderbilt 局域化理论：Wannier 扩展 Ω_spread = Ω_I + Ω̃，其中**规范不变部分** Ω_I = ∫Tr[g]（恰是量子度量积分），是任何规范选择都无法消除的局域化下限；而 ∫√det g ≥ π|C|（Peotta-Törmä）。

**结构同构（非类比，是两个社区的同一对象）：** 轨道嵌入 {r_α} 正是一种 Wannier 中心/试探规范的选择。Marzari-Vanderbilt 对规范**最小化**扩展，不可约最小值就是 Ω_I。
⟹ **Huhtinen-Törmä 的"最小量子度量 g_min" = Marzari-Vanderbilt 的"规范不变 Wannier 扩展密度"——同一数学对象，凝聚态两个子社区独立发现。**
且 ∫√det g_min ≥ π|C|。

**C=0 边界精确定位：** 当 C=0 且无其它障碍（可指数局域 Wannier 函数存在 ⟺ C=0），Ω_I 可→0（平凡原子带 Wannier 函数趋于 δ 函数）⟹ ∫√det g_min→0 ⟹ 几何地板可被轨道嵌入压到零。**这正是命题B成立的精确扇区。**

## 提炼命题（满足三验证条件）

### 形式化命题（LP10-S1 北极星，可推导版本）

设孤立平带子空间由 N_flat 个能带组成（与色散带能隙 Δ_gap ≫ 配对能标 Δ），采用均匀配对（序参量在平带子空间正比于投影算符）。其超流权重几何贡献由 G-不变的最小量子度量 g_min（= Marzari-Vanderbilt 规范不变 Wannier 扩展）控制：

  **D_s ≥ c · Δ · ∫_BZ √(det g_min) d²k ≥ c · Δ · π|C|**

判定三点：
- **(a) 嵌入不变性（命题A的合法核心）：** 该下界 G-不变，因为 g_min 与 C 都是 G-不变量，且逐点不等式 det g ≥ (Ω/2)² 是 G-等变的。naive g 的规范依赖**不**伪证下界——它只是没用对不变量。
- **(b) 非平凡条件：** 下界非空 ⟺ C≠0（或更一般地，平带有拓扑/fragile 障碍迫使 Ω_I>0）。
- **(c) 命题B的精确扇区：** C=0 且 Wannier 可局域时，∫√det g_min 可被轨道嵌入驱→0 ⟹ 不存在嵌入无关正下界。

**预期结论方向（不预设，A/B 独立推导裁决）：** "有边界"——拓扑下界存在且嵌入无关，但精确地限定在 C≠0、均匀配对、孤立平带扇区；边界 = C=0 / 非均匀配对 / 最小度量的微妙性。
