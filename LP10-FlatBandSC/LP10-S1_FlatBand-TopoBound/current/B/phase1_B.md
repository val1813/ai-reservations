## §1 独立结论预测（在阅读 A 摘要之前填写）

从纤维丛障碍论看：
- **结论方向**：**正**（下界存在且为真、嵌入无关）。理由：陈数是丛的拓扑障碍，与任何坐标/嵌入选择无关；校准不等式把它转成度量积分的下界，而校准不等式在**任意**度量表示下逐点成立。
- **量级**：`∫√det g ≥ π|C|`（det 版）；`∫Tr g ≥ 2π|C|`（trace 版，因 `Tr g ≥ 2√det g`）。`D_s ~ c·Δ·π|C|`，`c` 为 O(1) 常数（来自 BdG 投影的 `Δ` 标度，此处不展开 A 的推导）。
- **最可能出错环节**（我自查）：(i) 把"逐嵌入成立"误当成"g 本身 G-不变"——其实 g 是 G-**协变**的，floor 才不变；(ii) C=0 时草率宣称"下界=0"，忽略 obstructed/fragile 的非 Chern 下界；(iii) det 版 vs trace 版混用，且 `D_s` 是张量、`π|C|` 约束的是其行列式/迹而非单分量。

## §N 独立推导正文

> 全程用框架 [微分拓扑/校准 + 群表示]。不跳步、不"显然"、不中途评价 A。

### N.1 建立对象：Bloch 丛与分类映射

**步骤**：设 `N_orb` 个轨道、`N_flat` 个孤立平带。在每个 `k∈T²`，占据平带张成 `C^{N_orb}` 中一个 `N_flat` 维子空间，对应正交投影算符 `P(k)`，`P²=P=P†`，`Tr P = N_flat`。能隙 `Δ_gap≫Δ⟹P(k)` 对 `k` 光滑。

**工具/依据**：`P(k)` 光滑映射 `f: T² → Gr(N_flat, N_orb)`（Grassmann 流形为 `Gr = U(N_orb)/(U(N_flat)×U(N_orb−N_flat))`），`P = f*(P_taut)`。`E := f*(γ)`（γ=重言子丛）是 `T²` 上秩 `N_flat` 的 Hermite 向量丛。

**最易出错处**：必须假设带隙处处非零（孤立），否则 `P` 在带触点不光滑、`f` 无定义——这是 SQ-6 的根。

### N.2 拓扑障碍：陈数是唯一的全局规范障碍

**步骤**：定义第一陈数
```
C = ∫_{T²} c₁(E) = (1/2π) ∫_{T²} tr F = (i/2π) ∫_{T²} Tr[P ∂₁P ∂₂P − P ∂₂P ∂₁P] d²k,
```
其中 `F` 是 Berry 曲率（非 Abelian 联络的迹）。

**工具/依据**：**Panati 定理**（cond-mat/0606726；亦见 1601.02906 对称类推广）——`E` 容许全局光滑正交标架（等价：指数局域 Wannier 函数存在）`⟺ c₁(E)=0`。`C≠0` 时不存在全局光滑 Bloch 规范，障碍恰为 `c₁`。

**为何这是 G-不变量**：嵌入变换 `V(k)=diag(e^{ik·r_α})` 把 `P → P' = VPV†`。`V` 光滑可逆，`P'` 与 `P` 定义**同构**的丛（仅过渡函数/平凡化改变），故 `c₁(E') = c₁(E)`，`C` 不变。这是后面 floor 的锚。

**最易出错处**：`V(k)` 非 BZ-周期（`V(k+G)=V(k)e^{iG·r_α}`），看似改变拓扑；但同构类只看 `c₁`，相位扭转不改变积分陈数。需用"同构丛同 `c₁`"而非"周期规范变换"来论证。

### N.3 嵌入群 G 的逐点作用：g 协变、曲率密度移动恰当形式

**步骤**：计算 `V` 作用下的导数。`V` 对角且 `∂_μ V = i R_μ V`，`R_μ = diag((r_α)_μ)` 为常数对角矩阵。于是
```
∂_μ P' = V (∂_μ P + i[R_μ, P]) V† ≡ V (D_μ P) V†,   D_μ := ∂_μ + i[R_μ, ·].
```
代入量子几何张量 `Q_{μν} = Tr[P ∂_μP ∂_νP]`：
```
Q'_{μν} = Tr[P (D_μP)(D_νP)].   （∗）
```

**子步骤 N.3a（单带显式核验，N_flat=1）**：`|u_α⟩→e^{ik·r_α}u_α`。Berry 联络
```
A'_μ = A_μ + Σ_α (r_α)_μ |u_α(k)|² = A_μ + ⟨R_μ⟩(k),
```
`⟨R_μ⟩(k)=Σ_α(r_α)_μ|u_α|²` 是轨道位置期望（k-依赖、BZ-周期、规范不变）。故
```
F'_{μν} = F_{μν} + (∂_μ⟨R_ν⟩ − ∂_ν⟨R_μ⟩) = F_{μν} + (dβ)_{μν},   β = ⟨R⟩ 1-形式。
```
**Berry 曲率密度移动了一个恰当形式 dβ，逐点不变性不成立。**

**子步骤 N.3b（积分不变）**：`β=⟨R⟩` 在 `T²` 上全局良定且周期，`∫_{T²} dβ = 0`（闭流形上恰当形式积分为零 / Stokes，无边界）。故
```
∫F' = ∫F  ⟹  C 不变。
```
与 N.2 一致。

**子步骤 N.3c（g 协变）**：由（∗），`g'_{μν}=Re Q'_{μν}` 含 `D_μ=∂_μ+i[R_μ,·]` 的交叉项，**逐点依赖 `r_α`**。故量子度量 G-**协变**（随嵌入变），与曲率积分的不变性形成对照。

**工具/依据**：投影恒等式 `P²=P ⟹ P(∂P)P=0`；对角酉的导数代数。

**最易出错处（也是 SQ-4 的根）**：极易把"`∫F` 不变"口误成"`F` 不变"。下一步的不等式是**逐点**的，必须对**每个嵌入**单独应用，再用积分不变量收口——不能假定 F 逐点固定。

### N.4 核心不等式：Wirtinger 校准给出几何起源

**步骤（逐点）**：QGT 作为 `μ,ν∈{1,2}` 的 2×2 Hermite 矩阵半正定（`Q⪰0`，因 `Q_{μν}=Tr[(∂_μP)P(∂_νP)]` 是 Gram 型）。`⟹ det Q ≥ 0`：
```
det(g) − (F₁₂/2)² ≥ 0  ⟹  √det g(k) ≥ |F₁₂(k)|/2,  逐点，对任意嵌入成立。  （†）
```

**步骤（几何起源——我的独立增量）**：`g` = Grassmann 上 **Fubini–Study 度量**经 `f` 的拉回；`ω := F/2` = FS **Kähler 形式**的拉回。`√det g d²k` = 拉回度量的**黎曼面积元** `dA_g`。FS 是 Kähler 流形，其 Kähler 形式是**校准形式（calibration）**：对任意 2-平面，`ω|_{平面} ≤ dA|_{平面}`，等号 ⟺ 该平面是复（全纯）线。这就是 **Wirtinger 不等式**。逐点：
```
dA_g ≥ |ω| = |F₁₂|/2,   等号 ⟺ f 在该点 (反)全纯。
```
即（†）的内蕴几何来源——**不是"完成平方"（2511.07855 的 Bogomolny 路径），而是 Kähler 校准**。

**步骤（积分收口）**：
```
∫_{T²} √det g d²k = Area_g(f) = ∫ f*(dA_FS)
                 ≥ |∫ f*ω| = |∫ ω| = (1/2)|∫F| = π|C|.
```
中间 `∫√det g ≥ |∫ω|` 是"闭曲面映入 Kähler 流形，其像的（带重数）面积 ≥ 所携同调类的辛通量"——calibration 的标准推论（校准形式在同调类内取面积极小，全纯曲线达到）。辛通量 `=∫f*ω` 由 `[ω]=c₁` 与 `f_*[T²]` 决定，**纯拓扑、嵌入无关**。

**结论（†且积分）**：
```
∫_{BZ} √det g d²k ≥ π|C|   对每个嵌入成立。           (★det)
∫_{BZ} Tr g d²k  ≥ 2π|C|   （因 Tr g ≥ 2√det g ≥ |F₁₂|）。 (★tr)
```

**工具/依据**：Wirtinger 不等式（Harvey–Lawson calibration 理论）；FS 为 Kähler；`Q⪰0` 的 Gram 结构。

**最易出错处**：`Q⪰0` 用的是把 `μ` 当矩阵指标的"几何张量半正定"，不是把 `g` 当度量的正定——两者不同；前者才给 `det g ≥ (F/2)²`。另：trace 版与 det 版差一个 AM-GM 因子，物理 `D_s` 张量对应哪个见 SQ-5。

### N.5 Floor 论证：从"逐嵌入成立"到"g_min 成立"

**步骤**：（★det）对**每一个**轨道嵌入 `V∈G`（以及内部酉规范，注意：fiber 内 `U(N_flat)` 旋转不改 `P`、不改 `g`，只有 `V` 改 `g`）都成立，且右端 `π|C|` 与嵌入无关。对左端在合法嵌入集上取极小：
```
∫√det g_min d²k := min_{V∈G_phys} ∫√det g[V] d²k ≥ π|C|.   (★★)
```
**关键逻辑**：极小化作用在左端，右端是所有嵌入共有的同一个 floor，故极小亦 ≥ floor。**下界由 G-不变量（Chern 辛通量）锚定，而非由任何特定嵌入的度量锚定。** 这就是"嵌入无关"的精确含义——不是 g 不变，而是 floor 不变且对所有嵌入是同一个。

**最易出错处（SQ-3 的根）**：`G_phys`（物理允许嵌入集）是否 = 数学极小所在集？若 `g_min` 的极小在物理不允许的嵌入处取得，则（★★）的左端可能不是真实 `D_s`。需确认极小可达且落在 `G_phys` 内（紧致性 + 对称性相容）。

### N.6 C=0 扇区的三分类（我与 A 预期的分歧核心）
