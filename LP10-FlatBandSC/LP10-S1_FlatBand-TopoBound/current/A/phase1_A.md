## §2 强制撞墙（攻击 §0 声张本身的假设，不造弱反例）

**§0 声张的命门假设：** "下界嵌入无关"。最致命攻击直接打这一点：

**反例A（嵌入调零攻击）：** 取一个 C≠0 的孤立平带。naive 量子度量 g 依赖轨道嵌入 r_α（H4 承认这点）。**那我故意选一个荒唐的嵌入，把 naive ∫√det g 调到任意小，下界不就破了？**

> **为何不成立（必须正面回答）：** 攻击混淆了 naive g 与 g_min，且忽略了不变量钉扎。关键恒等式：对**任意**嵌入规范 V，
> ∫_BZ √(det g_V) d²k ≥ (1/2)∫|Ω_V| d²k ≥ (1/2)|∫Ω_V d²k| = (1/2)|2πC| = π|C|.
> 第二步右端的 C = (1/2π)∫Ω_V 对每个 V **相同**（H6：Chern 是拓扑不变量，∫Ω 与嵌入无关，尽管 Ω_V(k) 逐点变）。所以**没有任何嵌入**能把 ∫√det g_V 压到 π|C| 之下。min 操作只能逼近 π|C|，碰不破。攻击失败的根因：拓扑不变量把积分从下钉死，而下界活在积分（不是逐点）上。

**反例B（C≠0 但度量退化攻击）：** 取 C≠0，但让 det g(k) 在某些 k 点为 0（度量退化），∫√det g 不就能很小？

> **为何不成立：** det g(k) ≥ (Ω(k)/2)²（H2）。det g 在 k₀ 退化 ⇒ Ω(k₀)=0 在该点。但 ∫Ω = 2πC ≠ 0 要求 Ω 在 BZ 上净非零，局部退化杀不掉积分。∫√det g ≥ (1/2)∫|Ω| ≥ π|C| > 0 仍成立。攻击失败。

**反例C（命题B 的真实威胁，来自 2603.08791）：** two-band 模型 H(k_c)，存在 V_k=diag(1, e^{ik·δ}) 把非对角相位消掉，使 condensate metric det M^D = 0，禁止 2D 超流。这岂非反掉"C≠0 必有界"？

> **为何不威胁 §0 扇区：** 该构造的 two-band 模型对应 **C=0**（可被全局连续 V_k 平凡化的带必拓扑平凡）。它落在命题B 的成立扇区（C=0 原子极限），**不在 §0 的 C≠0 扇区**。它恰恰是判别点③要精确定位的"命题B 成立处"，不是对 C≠0 界的反例。撞墙反而帮我定位了失败扇区边界。

三个反例都不成立 ⇒ §0 声张的"嵌入无关下界"在 C≠0 扇区稳健。继续正文。

## §N 推导正文

### §N.1 超流权重的几何贡献（显式表达式，BdG + 线性响应）

均匀超流相位梯度 q：做规范变换 c_{kσ} → c_{k+σq/2,σ}，BdG 哈密顿量 H_BdG(q)。超流权重张量（Meissner 核 q→0 极限 / 大正则势二阶导）：

  D_s^{μν} = (1/V) ∂²Ω_grand/∂q_μ∂q_ν |_{q→0}.   …(N1)

孤立平带极限（Δ_gap ≫ Δ，T→0，TRS，轨道基均匀配对 Δ̂=ΔÎ_orb），投影到平带子空间后，单带几何贡献为（禁区引用 Peotta-Törmä 2015 + Huhtinen-Törmä 2022 修正）：

  D_s^{μν} = K · ∫_BZ g_min^{μν}(k) d²k,   K = (4e²/((2π)ℏ²N_orb))·|U|·f(1−f).   …(N2)

其中 f 平带填充，N_orb 携带平带权重的轨道数，g_min 是**最小量子度量**（min-trace metric，H4）。平带平均场关系 Δ = |U|√(f(1−f)) ⇒ |U|f(1−f) = Δ√(f(1−f))，故

  K = c·Δ,   c = (4e²/((2π)ℏ²N_orb))·√(f(1−f)) = O(1)×物理常数.   …(N3)

→ D_s^{μν} = cΔ ∫ g_min^{μν} d²k。**这一步全部是禁区引用，非本课题增量。**

### §N.2 QGT 半正定 ⇒ det g ≥ (Ω/2)²（判别点①的逐点部分）

单带 QGT（H1）：
  B_μν(k) = ⟨∂_μu_k|(1−P_k)|∂_νu_k⟩,  P_k=|u_k⟩⟨u_k|.   …(N4)
实部虚部分解：
  Re B_μν = g_μν（量子度量，对称）,  Im B_μν = −½Ω_μν（Berry 曲率，反对称）, Ω≡Ω_xy.   …(N5)
B 作为 μν 指标上的 2×2 Hermitian 矩阵半正定 ⇒ det B ≥ 0：
  det B = B_xx B_yy − B_xy B_yx = g_xx g_yy − |g_xy − (i/2)Ω|²
        = g_xx g_yy − g_xy² − (Ω/2)² = det g − (Ω/2)² ≥ 0.
∴ **det g(k) ≥ (Ω(k)/2)²。**   …(N6)
*反驳检验：* 有人质疑 B 是否真 PSD。B_μν = Σ_{m≠flat}⟨∂_μu|u_m⟩⟨u_m|∂_νu⟩ = Σ_m v_m^{μ*}v_m^ν，是 Gram 矩阵，对任意复矢 ξ_μ：ξ*Bξ = Σ_m|Σ_μξ_μ v_m^μ|² ≥ 0。PSD 无条件成立，与嵌入规范无关。✅

### §N.3 G-等变性：逐点 vs 积分（判别点①②的核心，本Phase主要澄清）

**轨道嵌入规范群** G = {V(k) = diag(e^{ik·r_α})}。轨道位置 r_α→r_α+δ_α 等价于 Bloch 态 |u_k⟩→V(k)|u_k⟩。

**(i) 逐点不等式 G-form-不变，但两边都动。**
在任意 V 下，g_V 与 Ω_V 仍是该规范下 QGT B_V 的实/虚部，B_V 仍 PSD（§N.2 与嵌入无关）。故
  det g_V(k) ≥ (Ω_V(k)/2)²  对**每个** V 成立。   …(N7)
但 g_V 与 Ω_V **都**随 V 逐点变化。具体地，Berry 连接
  A_V,μ(k) = A_0,μ(k) − Σ_α ρ_α(k) δ_α^μ,  ρ_α=|⟨α|u_k⟩|²,   …(N8)
其旋度给出 Ω_V(k) = Ω_0(k) − Σ_α[δ_α^y∂_xρ_α − δ_α^x∂_yρ_α]，**逐点非零变化**。

**∴ 写法 `min_G det g(k) ≥ (Ω(k)/2)²` 非法**：左边随 V 降，右边的 Ω 也随 V 变，固定右边取左边下确界是错误操作。**这是本Phase要钉死的易错点（与 §1 预测一致）。**

**(ii) 积分不等式才是 G-稳健的拓扑命题。**
对 (N7) 两边开方并对 BZ 积分（√det g_V ≥ |Ω_V|/2 ≥ 0）：
  ∫√(det g_V) d²k ≥ ½∫|Ω_V| d²k ≥ ½|∫Ω_V d²k|.   …(N9)
关键：(N8) 的修正项是全导数，∫_BZ Σ_α∂_μ(ρ_αδ_α^ν)d²k = 0（BZ 周期性）⇒
  ∫Ω_V d²k = ∫Ω_0 d²k = 2πC,  **对每个 V 相同**（H6）。   …(N10)
代入：
  ∫√(det g_V) d²k ≥ π|C|,  **对每个嵌入 V 成立**。   …(N11)
取下确界（minimal metric 即 G 上的 min-trace 代表，是 (N11) 约束下的一个 V*）：
  ∫√(det g_min) d²k ≥ π|C|.   …(N12)

**判别点①②同时解决：** 规范依赖被消除**不是**靠"逐点取 min 后不等式还成立"（那是非法的），**而是**靠拓扑不变量 C 把**积分**从下钉死——∫√det g 在所有嵌入下的下确界仍 ≥ π|C|。naive g 可被命题B 调小（trace 调到 0 甚至），但它调的是 trace；∫√det g 这个组合被 C 锁住，min 只能逼近 π|C|，不能突破。**g_min（G-不变的物理度量）替换 naive g，规范依赖即被消除——但消除机制在积分层、不在逐点层。**

### §N.4 各向同性最优的 √det 形式（本Phase的 √det 加细，判别点结合）

D_s 是张量。BKT 相关的标量刚度是几何平均 √det D_s。由 (N2): D_s^{μν}=cΔ∫g_min^{μν}d²k，用 **Minkowski 行列式不等式**（H7，2×2 PSD，对积分形式）：
  [det ∫g_min d²k]^{1/2} ≥ ∫[det g_min(k)]^{1/2} d²k.   …(N13)
故
  √(det D_s) = cΔ·[det∫g_min]^{1/2} ≥ cΔ∫√(det g_min)d²k ≥ cΔ·π|C|.   …(N14)

**∴ √det D_s ≥ cΔπ|C|。** 这是 §0 目标链 D_s ≳ cΔ∫√det g_min ≥ cΔπ|C| 的精确（各向同性最优）实现。trace 界 Tr D_s = cΔ∫Tr g_min ≥ cΔ∫|Ω| ≥ cΔ·2π|C| 是更弱的伴随结果（各向异性时 √det 更紧）。
*反驳检验：* Minkowski 行列式不等式要求被积矩阵逐点 PSD——g_min(k) 作为度量逐点 PSD，满足。✅ 但注意 √det D_s ≥ cΔπ|C| 给的是**几何平均**刚度的界；若某主轴方向 D_s 退化为 0，则 √det=0 与 C≠0 矛盾，反过来证明 C≠0 时**两个**主轴方向 D_s 都非零（无方向可被压平），物理上即超流在所有方向稳健。

### §N.5 复合（N_flat 带）非阿贝尔推广（禁区引用 + 复核）

### §N.6 均匀配对在轨道基 vs 能带基（判别点④，正面处理不绕过）

PI 预判这是最可能的叙事退让位置（G 把轨道基与能带基搅混）。正面处理：

**UPC 定义（轨道基）：** Δ̂ = Δ·Î_orb（轨道无关的单位配对矩阵，2405.11260 / 2308.08248 §4）。

**G 作用下 UPC 不变：** G 元 V(k)=diag(e^{ik·r_α}) 是对角幺正。
  V Δ̂ V† = V (ΔÎ_orb) V† = Δ·V Î_orb V† = Δ Î_orb = Δ̂.   …(N17)
**因为 Î_orb 与任意矩阵对易**，UPC 在轨道嵌入规范群下**严格不变**。这正是 §0"嵌入无关"成立的代数根基：UPC 用的是单位阵，不是某个偏好基里的特定结构，故不偷藏规范依赖。

**投影到能带基：** P_C Δ̂ P_C = Δ P_C（Î_orb 投影为平带子空间的单位算符）⇒ 能带基里也是"各带等配对"。轨道基 UPC ⇄ 能带基"投影后均匀"在 q=0 等价（Bloch 正交性使带间配对在 q=0 消失，q≠0 非零，这是几何贡献来源）。

**叙事退让风险点的诚实裁决：** 若只有**子集** N_orb^{flat} < N_orb 轨道携带平带权重，UPC 是"该子集上均匀"，min metric 对**这些**轨道的嵌入取下确界，N_flat/N_orb 比进入前因子 c（(N2)(N3) 的 1/N_orb）。这是**物理前因子**（依赖填充、轨道数、U），**不是**嵌入伪自由度——它不破坏拓扑下界 π|C|，只改 c。**故判别点④无叙事退让：UPC 因用单位阵而 G-不变，能带/轨道基等价，规范依赖未被偷藏。** ✅（此结论与 2405.11260 一致，非本课题增量。）

### §N.7 C=0 扇区：命题B 的精确成立/失败构造（判别点③）

**命题B（无普适下界）成立扇区 — 显式构造：**
C=0 且平带为**平凡原子极限**（无 Wannier 障碍，存在指数局域 Wannier 函数 w_α 中心在 R_α）。取嵌入 r_α = Wannier 中心，则在该规范下 Bloch 态 |u_k⟩ = const（k-无关），连接 A=0，曲率 Ω=0，度量 g=0：

**命题B 失败扇区（意外发现，超出 §0）：**

此时命题B（无普适下界）**失败**——有残余几何下界。

**∴ 命题B 的精确成立条件：C=0 且无 Wannier 障碍（平凡原子极限 / 可指数局域）。** 比"C=0"更窄。这是判别点③ 的精确答案，且修正了 §0/§1 的初始预测（不止 C=0）。
