# LP10-S1：多轨道孤立平带超流权重的拓扑下界

**所属长命题：** LP-10 量子几何平带超导：量子度量决定Tc？

**子命题北极星（候选池原文）：**
多轨道孤立平带中是否存在超流权重的拓扑下界？（严格证明或反例）

**驱动矛盾（候选池原文）：**
- 命题A（下界存在）：对 N_flat 个孤立平带组成的复合带（总带数 N_orb），若平带间配对均匀（uniform pairing），则 D_s ≥ min(Tr[g])×(N_flat/N_orb)×(Δ²/μ)，其中 g 为量子度量。几何下界拓扑保护，对无序和多轨道混合鲁棒。
- 命题B（下界不存在）：轨道位置依赖的晶格几何项可与带间量子度量项相消，构造性反例存在——某些轨道构型使 D_s→0 即使 Tr[g] 有限。

> 两者不能同时为真：要么存在一个仅由量子几何/拓扑不变量（C, N_flat/N_orb）决定的、不依赖轨道嵌入细节的正下界，要么可构造轨道构型使 D_s 任意小而几何张量积分有限。
