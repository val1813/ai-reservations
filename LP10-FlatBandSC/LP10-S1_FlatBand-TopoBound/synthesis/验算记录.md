### 第2步 · 逐步代数验算 (F1-F6)

**F1 — det g ≥ (Ω/2)²　✅ 正确**
B 作为 (μν) 指标上的 2×2 Hermitian 矩阵，分量：B_xx=g_xx，B_yy=g_yy（Ω_xx=Ω_yy=0），B_xy=g_xy−(i/2)Ω，B_yx=g_xy+(i/2)Ω。
- Hermitian 自洽：B_yx 应 = B_xy* = g_xy+(i/2)Ω ✓ 一致。
- 反对称部：Im B_xy = −Ω/2 ✓ 与 A 的 N5 约定 Im B_μν=−½Ω_μν 一致。
- det B = B_xx B_yy − B_xy B_yx = g_xx g_yy − (g_xy−(i/2)Ω)(g_xy+(i/2)Ω) = g_xx g_yy − [g_xy² + (Ω/2)²]。
  关键：(a−ib)(a+ib)=a²+b²，a=g_xy, b=Ω/2 → g_xy²+(Ω/2)²。
- det g = g_xx g_yy − g_xy²（g 对称，g_xy=g_yx）⇒ det B = det g − (Ω/2)²。
- B PSD（Gram 结构 B_μν=Σ_m v_m^{μ*}v_m^ν）⇒ det B≥0 ⇒ **det g ≥ (Ω/2)²**。
代数展开逐项核对无误。A 与 B 写法（A 用 Ω，B 用 F₁₂）等价。

**F2 — ∫√det g ≥ π|C|　✅ 正确**
逐步：(i) F1 开方 √det g ≥ |Ω|/2（两边非负，det g≥(Ω/2)²≥0，sqrt 单调）；(ii) 积分保序 ∫√det g ≥ ½∫|Ω|；(iii) 三角不等式 ∫|Ω| ≥ |∫Ω|；(iv) ∫Ω d²k = 2πC（约定 C=(1/2π)∫Ω）；(v) ½|2πC|=π|C|。四步链每步合法，无方向错误。

**F3 — √det D_s ≥ cΔπ|C|　✅ 正确（Minkowski 方向用对）**
- Minkowski 行列式不等式（n×n PSD 超可加，det^{1/n} 在 PSD 锥上凹）：积分形式 [det∫A d²k]^{1/2} ≥ ∫[det A]^{1/2}d²k（n=2）。需要 A(k)=g_min(k) 逐点 PSD ✓（量子度量逐点半正定）。
- 方向核对：目标是给 √det D_s（"积分的 det 开方"）一个**下界**，Minkowski 给的正是"积分的 det 开方 ≥ det 开方的积分"，方向**正确**（超可加方向）。
- 标量提取：det(cΔ·M)=(cΔ)²det M（2×2，cΔ>0）⇒ √det D_s = cΔ[det∫g_min]^{1/2} ≥ cΔ∫√det g_min ≥ cΔ·π|C|。
链条闭合，无误。

**F4 — 量纲　⚠️ 结构自洽，但 "c=O(1)" 表述不严（详见第3步）**

**F5 — Berry 连接/曲率变换　✅ 正确（结论稳健，含一处约定差异说明）**
- 显式重算（约定 A_μ=i⟨u|∂_μu⟩）：u'_α=e^{ik·r_α}u_α ⇒ A'_μ = A_μ − Σ_α(r_α)_μ|u_α|²。我得到的是**减号**。
  - **约定差异（非错误）：** A 文件 (N8) 用减号（且用位移 δ_α），B 文件 N.3a 用加号（用 r_α），任务书 F5 写加号。差异来源于 Berry 连接符号约定（i⟨u|∂u⟩ vs −i⟨u|∂u⟩）与嵌入相位符号约定。**对最终结论无影响**——见下。
- ⟨R_μ⟩=Σ_α(r_α)_μ|u_α|² 是规范不变、BZ 周期的实 1-形式（|u_α|² 是物理概率，周期）。β=⟨R⟩ 在 T² 上全局良定。
- 曲率：F'_μν = F_μν ± (∂_μ⟨R_ν⟩−∂_ν⟨R_μ⟩) = F_μν ± (dβ)_μν，移动一个**恰当形式**。
- ∫_{T²}dβ=0（闭流形无边界，Stokes）⇒ ∫F'=∫F ⇒ C 不变。**符号 ± 不影响此结论**（恰当形式积分恒为零）。
- A/B 共同的"逐点 vs 积分"核心论点（逐点不等式 F1 对每个嵌入单独成立，积分由不变量 C 钉死）在代数上成立。✅

**F6 — AM-GM 与不等式方向　✅ 正确（关键逻辑警示成立）**
- 2×2 PSD 本征值 λ₁,λ₂≥0：Tr g=λ₁+λ₂，det g=λ₁λ₂。AM-GM (λ₁+λ₂)/2≥√(λ₁λ₂) ⇒ **det g ≤ (Tr g/2)²** ✓ 方向正确。
- ⇒ Tr g ≥ 2√det g ≥ 2·(|Ω|/2) = |Ω| ✓。积分版 ∫Tr g ≥ ∫|Ω| ≥ 2π|C|（trace 界），与 A §N.4 一致。
- **REVIEWER 理由2 / AUDITOR 张力#2 的关键裁决（代数层）：** 由 Tr g ≥ 2√det g，"迹型下界 ⇏ 行列式型下界"**成立**——已知 Tr g ≥ b 推不出 √det g 有正下界（一个本征值可为 0，det=0 而 Tr 大）。反向"det 型 ⇒ trace 型"才合法。
  - 对主结论（C≠0）**无害**：A/B 的 C≠0 主界是**直接从 QGT 的 det Q≥0（F1）得到的真 det 型界**，不经由 trace 界，故合法。✓
  - 对 C=0 障碍扇区**有警示**：A §N.7 与 B N.6b/c 把文献中**迹型/Wilson-loop 型**的 RSI/Euler 残余界写成 **det 型** ∫√det g_min ≥ π|e|。由 F6，trace 型文献界**不能**自动推出这个 det 型界。见第6步⚠️。

### 第3步 · 量纲检查

记 k~1/length，∂_μ=∂/∂k_μ~length，量子度量 g_μν=Re⟨∂_μu|(1−P)|∂_νu⟩ ~ **length²** ✓（与任务约定一致）。∫d²k ~ 1/length²（BZ 面积量纲）。

- **几何积分 ∫g d²k ~ length²·(1/length²) = 无量纲**。⇒ 下界 ∫√det g ≥ π|C| **两边均无量纲**（C 为整数无量纲）✓ 主结构量纲自洽，这是核心一致性。
- **D_s = cΔ∫g_min**：∫g_min 无量纲，故 D_s 量纲 = cΔ 量纲。
- **c = (4e²/((2π)ℏ²N_orb))√(f(1-f))**：f、N_orb、√(f(1-f)) 均无量纲 ⇒ c 携带 **e²/ℏ²** 量纲（非无量纲）。
- **Δ = |U|√(f(1-f))** ~ energy ✓。
- ⇒ D_s ~ (e²/ℏ²)·energy。这与"超流权重作为电流响应(Meissner)核"的量纲一致（含电荷因子 e²）。结构上自洽。
- **代数子项核对：** Δ√(f(1-f)) = |U|√(f(1-f))·√(f(1-f)) = |U|f(1-f) ✓；故 K=(4e²/((2π)ℏ²N_orb))|U|f(1-f) = cΔ，c 提取正确 ✓。

**⚠️ 量纲结论：** 主下界（无量纲）量纲自洽，无问题。但文件称 "c = O(1)×物理常数 / c=O(1)" **不严谨**：c **带 e²/ℏ² 量纲**，不是无量纲常数。应表述为"c = O(0.1)×e²/ℏ²×(1/N_orb)"。这是表述精度问题，非致命错误（结构量纲链自洽）。
