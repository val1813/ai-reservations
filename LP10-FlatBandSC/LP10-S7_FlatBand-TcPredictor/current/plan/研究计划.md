# 研究计划 — FlatBand-TcPredictor (LP10-S7) v1

## 北极星（候选池 LP10-S7）
平带比 N_flat/N_orb + 量子度量是否是Tc的普适预测器？对已知平带SC候选系统验证Spearman秩相关。

## 驱动矛盾
**命题A（几何量普适预测Tc）：** 跨家族(TBG/kagome/Lieb/pyrochlore)，Tc与 N_flat/N_orb×∫g 的Spearman ρ_s>0.7，量子几何主宰Tc(LP-10核心成立)。
**命题B（非普适）：** (B1)S2的c'=c·Z·min_k w+S5的T_BKT脱钩→几何下界与真实Tc隔着Z、min_k w、k*三个家族依赖因子→秩相关被洗掉;(B2)同LP-2教训(Planckian跨家族不可判定)——几何量可能是处方依赖伪普适,ρ_s是选择性报告artifact。

## 苏格拉底形式化（PI主线程，3轮）
**第1轮·统计推断（秩相关↔因果 vs 混杂）：** Spearman ρ_s测单调关联非因果。追问：Tc与∫g的相关是几何驱动，还是二者共同被第三变量(如相互作用强度U、平带带宽)驱动的混杂相关？结构同构：S2的c'=c·Z·min_k w——若Z、min_k w跨家族变化大，则∫g与Tc的相关被它们调制。需偏相关(控制U、W_flat后∫g的偏ρ_s)。
**第2轮·跨LP同构（LP-2 Planckian的直接复用）：** **这是LP-2↔LP-10元判据(S1-AHA#2)的决定性检验。** LP-2 K2.3：两种m*处方不可调和(BF=8×10⁷)→Planckian跨家族不可判定。追问：几何量∫g是否也"处方依赖"(naive g vs minimal g_min,S1已证naive g规范依赖)？若各家族用不同g处方→ρ_s是处方artifact(命题B2,重蹈LP-2)。但S1-AHA#2给出**判据**：几何量有量子化锚(Chern数C)，m*没有→几何量的普适性可能为真(与LP-2相反)。S7正面检验这个元判据:用g_min(锚定版)算ρ_s vs naive g算ρ_s,若g_min版ρ_s稳健而naive版不稳→证实AHA#2(有锚则普适真)。
**第3轮·层次贝叶斯（家族内vs家族间方差，直接搬LP-2方法）：** LP-2用层次贝叶斯测τ²_between(家族间方差)。追问：Tc~几何量的关系，家族间方差τ²_between是否=0(普适)还是显著(非普适)？直接复用LP-2 K2.1方法(层次贝叶斯+GMM)。若τ²_between=0→普适(命题A);若显著多峰→家族特异(命题B)。

**提炼命题：** 用**锚定几何量**(g_min下界 √det下界∝π|C_tot|×N_flat/N_orb)算跨家族Spearman ρ_s与层次贝叶斯τ²_between。预期(基于S1-S5+AHA#2)："有边界"——几何下界π|C|×(N_flat/N_orb)给Tc的**上界趋势**(秩相关中等正,因均匀配对非泛性S1+关联重整S2+T_BKT脱钩S5使其非紧)，但**控制Z、min_k w、k*后偏相关显著(命题A的锚定版)**,优于naive g(支持AHA#2:Chern锚使几何普适性比Planckian真)。
**知识库连接（决定性）：** S1-AHA#2(LP-2↔LP-10元判据:量子化锚)+S1-K1.1(下界)+S2-K2.6(c'重整)+S5-K1.2(T_BKT脱钩)+LP-2 K2.1/K2.3(层次贝叶斯方法+处方不可调和教训)。S7是LP-10的预测器检验,也是AHA#2跨LP元判据的实证。

## 研究路径
### Phase 1：跨家族数据汇编 + 锚定vs naive几何量Spearman（解析+文献数据）
- 汇编TBG/kagome AV₃Sb₅/Lieb(冷原子)/pyrochlore的Tc、N_flat/N_orb、∫g(naive)、π|C|(锚定)、Z、min_k w。
- 算ρ_s(Tc, naive∫g) vs ρ_s(Tc, π|C|×N_flat/N_orb)。
- 产出：两种几何量的秩相关对比(检验AHA#2)。
### Phase 2：偏相关+层次贝叶斯（控制混杂，复用LP-2方法）
- 控制U、W_flat后的偏ρ_s；层次贝叶斯τ²_between；GMM测多峰。
- 产出：几何量Tc普适性的家族间方差判定。
### Phase 3：与LP-2对比 + AHA#2元判据裁决
- 对比LP-2(无锚→不可判定)与LP-10(有Chern锚→?)，裁决AHA#2元判据。
- 产出：LP-10核心论点("几何主宰Tc")的最终判定 + AHA#2实证。

## 风险
- 数据风险高：平带SC的Tc与几何量跨家族数据稀疏且测法不一(类似LP-2的m*处方问题)→秩相关样本小、噪声大。最可能"数据不足判不可判定"。
- 先发风险：Penttilä 2025(Comm.Phys.8,19)已做Lieb的平带比-量子度量-Tc关联。GATE0查"flat band ratio quantum metric Tc predictor universal"。
- 最脆弱假设：跨家族Tc可比性(TBG的Tc~1K vs kagome~3K vs 冷原子,机制不同)——苹果比橘子。叙事退让位置。
- 工具：文献数据汇编+统计,无需集群。数据不足时明确判"数据受限,给条件结论"。
