## §2 强制撞墙（自我攻击）

我先把 §1 的乐观结论往死里打。

**撞墙 1 · H1 崩塌（致命，苹果比橘子）。**
跨家族 Tc **不可比**，且**机制不同**：
- **kagome AV₃Sb₅**：检索确证"Fermi level close to Van Hove singularities / saddle points"，平带位于 **E_F 以下 ~1 eV**，超导被广泛归因于 **VHS nesting + 电子–声子**（arXiv:2505.19686 "phonon mediated SC in CsV₃Sb₅"）。→ **kagome 的平带几何对其超导是旁观者**，把它的 Tc 放进"几何预测器"回归是**机制错配**。
- **TBG**：D_s 比常规大一个量级（arXiv:2406.13740），几何主导，Tc~1 K（测量）。
- **Lieb / pyrochlore**：Tc 仅理论单位 t（DMFT / Hubbard MF），**无法换算到 Kelvin 与 TBG/kagome 同标尺**。

→ 在不可比标尺上，秩本身无定义。H1 = LP-2 的"m* 两处方不可调和（BF=8×10⁷）"在 LP-10 的转世：**Tc 测法/机制就是 LP-10 的"处方"**。

**撞墙 2 · 锚定版退化（推翻 §1 第 2 条）。**
Chern 锚 π|C_tot|×(N_flat/N_orb) 需要 |C|≠0。但：
- Lieb 平带 **C=0**（拓扑平庸，几何非零但 Chern 零）；
- kagome 平带 **C=0**；
- pyrochlore 平带 **C=0**（一般情形）；
- TBG 单带 |C|=1，**但时反对总 C=0**——取单带还是取对**本身是处方选择**。

→ π|C|×ratio 在 4 家族给出近似 {TBG: 0.63 或 0, 其余三家: 0, 0, 0}。**无秩方差 → Spearman 退化/无定义**。**锚不是"更稳"，而是"退化"**。§1 第 2 条死。
→ **唯一可救的锚是规范不变的 ∫g_min**（C=0 仍非零，源于能带接触/Euler 类）。这是 LP-10 真正区别于 LP-2 的点：g_min 规范不变（≠ naive g、≠ m* 处方依赖）。但 g_min 只解决"非伪影"，不解决"可比标尺"。

**撞墙 3 · 统计不可能性（§1 完全没料到，最冷酷）。**
平带 SC 家族 < 5。Spearman 在 **n=4** 时，**即便 ρ_s=1（完美秩对齐），双尾 p≈0.083 > 0.05**；n=3 时 ρ_s=1 → p≈0.33。
→ **无论几何量多好，现有家族数从根本上无法让 ρ_s>0.7 达到显著**。命题 A（"ρ_s>0.7"且隐含显著）**不可证**，不是因为几何不行，而是因为样本不够。这与 LP-2"τ²_between 不可判定"同构，但更硬——它不依赖数据精度。

**撞墙 4 · B1 结构脱钩（S2+S5）。**
S2-K2.6：c'=c·Z·min_k w；S5-K1.2：T_BKT 脱钩。几何下界与真实 Tc 隔着 **Z、min_k w、k\*** 三个家族依赖因子。即便 H1 成立、n 够大，这三因子的家族间方差会洗掉秩相关（H3 不成立）。arXiv:2601.12969 进一步指出几何量是 Tc 的**上界**而非紧下界 → 下界→Tc 的映射非单调可逆。

**撞墙幸存检验**：§1 哪条活下来？
- 第 1 条（naive 不可靠）✅ 活，且强化。
- 第 4 条（与 LP-2 对照）✅ 活，且是收官主线。

→ 撞墙后落点从 §1 的"有边界（锚定版普适成立）"**下修**为"**数据受限的条件结论 = 命题 B**"。

### N.2 两个 Spearman 对比（检验 S1-AHA#2 的关键步）

**ρ_s(Tc, naive∫g)**：naive g 规范依赖（S1 已证），各家族若用不同规范/填充取值 → 排序随规范漂移 → **处方 artifact**（重蹈 LP-2 K2.3"两处方不可调和"）。**无法给出稳定 ρ_s** → 报告为"不稳/不可判定"。

**ρ_s(Tc, ∫g_min)（修正锚定版，规范不变）**：这是唯一良定义的几何标尺。但
- 受限于 N.1 的 Tc 不可比（撞墙 1）→ 若强行排序，秩本身无物理意义；
- 即便取几何机制子集 {TBG, Lieb, pyrochlore}（剔除 kagome），n=3 → 即使 ρ_s=1，p≈0.33（撞墙 3）。

> **AHA#2 裁决（核心产出）**：S1-AHA#2 期望"Chern 锚使几何普适性比 Planckian 真"。本 Phase 给出**分裂裁决**：

### N.3 偏相关（控制 U、W_flat）

命题 A 锚定版要求"控制 U、W_flat 后 ∫g 偏 ρ_s 显著"。但偏相关至少需 n≥ (控制变量数+3)。控制 U、W_flat 两个变量后，n=4 的自由度 = 4−2−2 = 0 → **偏相关无定义**。geometric 子集 n=3 更不可能。→ **偏相关在现有样本下不可计算**，混杂无法排除。这正是 S2 c'=c·Z·min_k w 警告的实证：Z、min_k w 即家族依赖混杂，但无法被现有数据控制掉。

### N.4 处方依赖检验（命题 B2，重蹈 LP-2 的正面对照）

- **naive ∫g**：S1 已证规范依赖 → 各家族不同规范时 ρ_s 是 artifact。**与 LP-2 同病**。
