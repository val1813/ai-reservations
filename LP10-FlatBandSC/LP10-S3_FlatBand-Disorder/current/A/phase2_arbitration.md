## §2 物理基底：超流权重的 τ 标度——A/B 均未充分阐明但双方依赖的共同前提

在裁决三个张力之前，必须先建立一个 A/B 均接受、且被文献独立确认的物理事实。这个事实是双方论证的共同地基，也是理解"为什么几何权重鲁棒"的钥匙。

### §2.1 平带超流权重的 Kubo 公式与 τ 标度

零温超流权重 D_s = D_s^conv + D_s^geom。平带 D_s^conv = 0（v=0）。D_s^geom 的 Kubo 表达：

$$D_s^{\rm geom} = \frac{e^2}{\hbar^2 V} \sum_{\mathbf k} \sum_{m\neq n} \frac{|V_\mu^{mn}(\mathbf k)|^2}{E_m+E_n} \approx \frac{2\Delta_{sc}}{\hbar^2} \frac{1}{(2\pi)^d}\int d^d k\,{\rm Tr}\,g(\mathbf k)$$

其中 V_μ^{mn} = (ε_m−ε_n)⟨m|∂_μ|n⟩ 是带间速度矩阵元，g 是量子度量。

**关键结构事实（无争议）**：D_s^geom 不包含带内（intraband）速度 ∂_μ ε_n（平带下为零），全部来自带间（interband）矩阵元。这是 A 的"几何住裸顶点"和 B 的"几何是带间量"的共同正确内核。

### §2.2 τ 标度的图论结构（A/B 均同意，2510.05224 独立确认）

无序进入 D_s^geom 的路径有三：

1. **自能展宽**：传播子 G(iω_n) → G(iω_n − Σ)，谱函数展宽 ℏ/2τ。这给带间能量分母 (E_m+E_n)² → (E_m+E_n)² + (ℏ/τ)² 型修正 → **O((ℏ/τΔ)²)** 的二阶小量。

2. **电流顶点修正**（正常道）：无序杂质线连接电流顶点的两条腿。关键：**带间电流顶点 V_μ^{mn} 不落在粒子数扩散子（diffuson）极点上**——扩散子极点来自粒子-空穴对在费米面的低能激发（∝ 1/(−iω+Dq²)），而带间顶点的能量分母 ~ 2Δ_sc（Nambu 间隙），与化学势/费米面解耦。→ **无 1/(−iω+Dq²) 奇异增强 → 顶点修正为 O(1) 非奇异 → 不产生 ∝τ 或 ∝1/τ 的标度改变**。

3. **反常（配对）顶点修正**：相位模（Anderson-Bogoliubov/Goldstone）的规范不变性要求。平均场 BdG 已自动包含平均场级相位模；超越平均场的集体模修正（GRPA 型 D_s^(1)）在单点 DMFT/SCBA 层级不进入。

**结论（三方一致）**：几何超流权重的领头 τ 标度是 **∝τ⁰**（常数），既非 Drude 的 ∝τ，也非脏 BCS 的 ∝Δτ。这是"平带几何权重对无序鲁棒"的深层原因——不是因为它被拓扑"保护"免于无序，而是因为它**不耦合**到无序最危险的通道（扩散子）。

**与常规超导的对照（关键）**：常规超导的 D_s 在脏极限下 ∝ Δτ ∝ Δ·ℓ（ℓ = v_F τ，平均自由程），无序越强越小——因为常规刚度来自带内（Drude）通道，而带内电流顶点恰落在扩散子极点上，获得 ∝τ 的脏极限压低。平带几何刚度**完全避开这个通道**。这就是 2203.01058 "平带 SC 与常规 SC 同样抗无序"的真实物理内容——两者抗无序的原因不同（常规靠 Anderson 定理保护 Δ，平带靠 ∝τ⁰ 保护刚度），但净效果可比。

## §3 裁决一：能标错配——两个"W_c"的分离与物理归属

### §3.1 A 的"破坏" vs B 的"破坏"——定义追踪

A 的精确定义（§0.5）：**"破坏" ≡ 几何 marker 失去意义/失去量子化**（投影算符 P 跨能隙离域、⟨C(r)⟩ 偏离整数），而非 D_s 数值的连续下降。

B 的精确定义（§3.4）：**W_c ≡ ℏ/τ(W_c) = 2Δ_sc**（半衰判据），超流权重功能性下降至一半。

**发现：A 和 B 定义的"W_c"不是同一个物理事件。** A 的"破坏"是几何结构的形式死亡（P 离域），B 的"破坏"是超流权重的功能死亡（配对破坏）。这两个事件在物理上由不同能标控制，且发生的无序强度相差悬殊。

### §3.2 阈值分离定理

**定理（本仲裁）**：在弱耦合（Δ_sc ≪ Δ_gap）孤立平带超导体中，存在两个分离的无序阈值：
$$W_c^{(1)} \equiv W_c^{\rm (AG)} \simeq \sqrt{\Delta_{sc}\cdot\max(W_{\rm flat},\Delta_{sc})} \quad\text{（配对破坏/功能死亡）}$$
$$W_c^{(2)} \equiv W_c^{\rm (struct)} \simeq \Delta_{gap} \quad\text{（带合并/结构死亡）}$$
且 W_c^(1) ≪ W_c^(2)（因 Δ_sc ≪ Δ_gap）。

**证明（概要）**：

**W_c^(1) 的推导**（循 B 的 SCBA 逻辑，但区分 Δ_sc 与 Δ_gap）：
- 散射率 ℏ/τ = 2πγ ρ(ε_F)，γ ~ W²（高斯白噪声强度）
- 平带 DOS：宽带区 ρ ~ ν₀/W_flat，理想平带 ρ ~ ν₀/W（自洽展宽）
- 配对破坏判据 ℏ/τ = 2Δ_sc（类 AG：散射率等于能隙 → 对破坏）
- → 宽带区：2πc_d W²/W_flat = 2Δ_sc → W_c = √(W_flat Δ_sc / πc_d)
- → 理想平带：2πc_d W = 2Δ_sc → W_c = Δ_sc / πc_d
- → 统一闭式 W_c^(1) ~ √(Δ_sc · max(W_flat, Δ_sc))

**W_c^(2) 的推导**（循 A 的投影子离域逻辑）：
- 平带投影子 P 的空间衰减长度 ℓ_P ~ a·t/Δ_gap（弱耦合）或 ~a（深隙）
- 无序展宽 δW_dis ~ W（箱型无序半宽 W/2）
- P 谱隔离条件：δW_dis < Δ_gap（无序展宽不触及色散带边）
- → 箱型半宽触及带隙边：W/2 = Δ_gap → **W_c^(2) = 2Δ_gap**
- 此阈值与 W_flat 无关，与 Δ_sc 无关——纯粹的单粒子能带结构阈值

**分离性**：Δ_sc ≪ Δ_gap → W_c^(1)/W_c^(2) ~ √(Δ_sc/Δ_gap) ≪ 1（宽带）或 ~ Δ_sc/Δ_gap ≪ 1（理想平带）。

### §3.3 物理归属

- **W_c^(1)（B 的阈值）**：超导实验中的可见破坏。当 ℏ/τ 达到 2Δ_sc，配对振幅 Δ_sc(W) 被显著抑制（"反 Anderson 定理"：非磁无序虽不直接拆散 s-波对，但通过态密度展宽削弱配对自洽），D_s 随 Δ_sc 成比例下降。这在隧穿谱（能隙闭合）、超流密度（μSR/穿透深度）、Tc 抑制中可见。**这是"平带超导被无序杀死"的实验相关阈值。**

- **W_c^(2)（A 的阈值）**：超导已死后才发生的能带结构事件。在 W_c^(1) < W < W_c^(2) 区间，超导已死亡（Δ_sc → 0），但平带投影子 P 仍谱隔离，几何结构（Chern marker、量子度量）在**正常态**中仍可定义。此阈值在无序拓扑相（量子霍尔/陈绝缘体的无序稳定性）中独立有意义，但与超导电性无关。**A 的正确贡献在于识别了这个更高阈值的存在，但把它称为超导的"W_c"是范畴错误。**

### §3.4 REVIEWER 的"仅差因子 2"裁定为何错误

REVIEWER 特别裁定(二)称"真平带区 A 的 W_c~2Δ_gap 与 B 的窄带极限 W_c≃Δ 收敛一致（仅相差因子 2）"。AUDITOR 已指出这是能标混淆：A 的 Δ_gap 与 B 的 Δ 不是同一个量（Δ_gap = 单粒子带隙，B 的 Δ = Δ_sc = 配对能隙）。

本仲裁进一步确认：
- 在理想平带区（W_flat ≪ Δ_sc），B 的 W_c^(1) ~ Δ_sc / πc_d ~ O(Δ_sc)。A 的 W_c^(2) = 2Δ_gap。
- 两阈值之比 = (Δ_sc/πc_d) / (2Δ_gap) ≈ (1/2πc_d) · (Δ_sc/Δ_gap) ≪ 1。
- **这不是"因子 2"，是因子 Δ_sc/Δ_gap ≪ 1。REVIEWER 把 Δ_gap ≡ Δ_sc 的隐含假设嵌入裁定，恰抹掉了 A 的"双能标层级"的全部物理内容。**

### §3.5 裁决一结论

## §4 裁决二：机制对立——拓扑保护 vs 扩散子脱钩

### §4.1 把"机制"问题精确化

A 的核心机制主张（遍布 §N 步骤1/2/5）：**拓扑/Chern 数保护** → 几何权重抗无序。实空间 Chern marker ⟨C(r)⟩ 量子化 → 度量-曲率不等式 D_s ≥ (Δ_sc/πℏ²)|C| 在无序下存活 → 鲁棒性来自拓扑。

B 的核心机制主张（§3.3/§4）：**扩散子脱钩** → 带间电流顶点与粒子数扩散子正交 → 几何权重 ∝τ⁰ → 鲁棒来自顶点的张量结构，与 Chern 数无关。

**判别性设问**（AUDITOR Q2）：取一对 ∫Tr g 相同、但 C≠0 vs C=0 的平带。A 预测 C≠0 带更抗无序（W_c 更大），B 预测两者 W_c 相同。哪个对？

### §4.2 形式分析：几何权重的 τ 标度不依赖 C

从 Kubo 公式出发（§2.2），D_s^geom 的 τ 标度由以下结构决定：

$$D_s^{\rm geom} \propto \sum_{m\neq n} \frac{|V_\mu^{mn}|^2}{E_m+E_n} \xrightarrow{\text{disorder}} \sum_{m\neq n} \int d\omega d\omega' \frac{A_m(\omega)A_n(\omega')}{\omega+\omega'} |\tilde V_\mu^{mn}|^2$$

其中 A_m(ω) 是谱函数（展宽 ℏ/2τ），Ṽ_μ^{mn} 是重整流顶点。

**关键观察**：
1. D_s^geom 的分子是 |V_μ^{mn}|² = (ε_m−ε_n)²|⟨m|∂_μ|n⟩|²，正比于量子度量 g_μν。
2. Chern 数 C = (1/2π) ∫ d²k Ω_Berry(k)，其中 Ω_Berry = −2 Im⟨∂_x u|∂_y u⟩ 是度量的**反对称**部分。
3. 度量-曲率不等式 Tr g ≥ |Ω_Berry| 给出 ∫Tr g ≥ 2π|C|，但这是**积分不等式**，不是点态关系。
4. 无序下 D_s 的 τ 标度由谱函数展宽和顶点修正的**解析结构**决定（是否有扩散子极点增强），不由积分的下界值（C）决定。

**∴ 没有任何已知的图论机制使得 Chern 数 C 进入 D_s^geom 的 τ 标度。** C 给的是无序前的**初始值下界**，不是无序下的**衰减速率**。两个 ∫Tr g 相同但 C 不同的带，其 D_s^geom(0) 的**下界**不同（C≠0 的下界更高），但 D_s^geom(W)/D_s^geom(0) 的**衰减函数**相同——因为衰减函数由谱函数展宽 ℏ/τ 和顶点结构决定，两者均不感知 C。

### §4.3 文献独立证据

**2203.01058（Lau et al., SciPost 2022）** 的标题即"Universal suppression of superfluid weight by disorder **independent of quantum geometry** and band dispersion"。该文在多个模型（包括拓扑与非拓扑平带）上证明无序压制的函数形式普适——这直接支持 B 的"C 无关"主张，反对 A 的"拓扑保护→差分鲁棒"主张。

**A 的回应缺失**：A 在 §-1 引了 2203.01058 但未正面反驳其核心结论（"与几何无关"）。A 的"拓扑保护"叙事与该文正面冲突。如果 A 主张几何/拓扑提供**差分**保护（C≠0 比 C=0 更抗无序），则 2203.01058 构成直接反证。

### §4.4 A 的"拓扑保护"正确在哪里

A 并非全错。以下陈述是物理正确的：
- **下界存活**：D_s ≥ (Δ_sc/πℏ²)|⟨C(r)⟩| 在 W < W_c^(struct) 成立（实空间平均层）。
- **C 锚定**：非零 C 给非零下界，保证 D_s^geom > 0（即使度量被部分削弱）。
- **P 谱隔离是共同前提**：Chern marker 量子化与度量 marker 存活共享同一条件（P 谱隔离）。

但以下陈述是**错误或误导的**：
- **C 提供差分保护**（C≠0 比 C=0 更抗无序）：无机制支撑，被 2203.01058 反证。
- **拓扑保护是独立于度量的额外鲁棒性来源**：C 的下界是度量-曲率不等式的推论——没有独立于度量的"拓扑保护通道"。
- **"拓扑保护"暗示抗无序性来自拓扑不变性**（如量子霍尔边缘态的拓扑保护）：量子霍尔边缘态的抗无序来自手征边缘通道的拓扑禁止背散射——这在体超流权重中无对应机制。体 D_s 是无能隙 Goldstone 模的权重，不由边缘手征模保护。

### §4.5 裁决二结论

| 项目 | 裁决 |
|------|------|
| 鲁棒的微观机制 | **扩散子脱钩 ∝τ⁰（B 对）**。这是可证伪的：预言 D_s^geom ∝ (1 + (ℏ/2τΔ_sc)²)⁻¹，无 τ 的正幂或负幂增强 |
| C 是否提供差分保护 | **否（B 对）**。同 ∫Tr g、C≠0 vs C=0 → 相同 W_c。A 的"拓扑保护→差分鲁棒"被 2203.01058 证伪 |
| 下界 D_s ≥ (Δ_sc/πℏ²)|C| 是否存活 | **是（A 对）**，在 W < W_c^(struct) 以实空间平均形式存活。但这是**陈述**不是**机制**——它不解释 WHY 鲁棒，只给出鲁棒的下界值 |
| A 的"拓扑保护"术语 | **建议废弃**，改为"度量-曲率下界的无序存活"（精确）或"投影子隔离保护"（机制中立） |

## §5 裁决三：固定 Δ 直接几何劣化量级

### §5.1 两种计算的关系

**A/2510.05224 的公式**（固定 Δ）：
$$\delta D_s|_{\Delta} = \frac{2W^2}{N_f\Delta_{sc}}\big[\tilde\Omega(|BS\rangle) - \Omega_I(|BS\rangle)\big]$$

- Ω̃：intra-band（ disorder-enabled 带内电流），正贡献，∝ W²
- Ω_I：inter-band（= 积分量子度量），负贡献（无序削弱带间相干），∝ W²
- 对称轨道（Creutz: Ω̃=Ω_I=1/4, Lieb: 均≈0.35）：两者抵消 → δD_s ≈ 0
- 含义：固定 Δ 的直接几何劣化在领头 O(W²) 近抵消

**B 的 Lorentzian**（固定 Δ）：
$$D_s^{\rm geom}(\tau) \simeq D_s^{\rm geom}(0) \cdot \frac{\Delta_{sc}^2}{\Delta_{sc}^2 + (\hbar/2\tau)^2}$$

- 来自将展宽谱函数代入带间 Lehmann 表示的能量分母
- ℏ/τ ~ 2Δ_sc 时 D_s 半衰
- **不含 Ω̃−Ω_I 抵消结构**

### §5.2 B 的 Lorentzian 遗漏了什么

B 的 Lorentzian 推导（§3.3）的关键步骤：将干净极限的带间能量分母 (2Δ_sc)² 替换为 (2Δ_sc)² + (ℏ/τ)²。这是一个**只含自能展宽、不含电流顶点修正**的近似——等价于只计算了 Ω_I 的展宽削弱，完全遗漏了 Ω̃（disorder-enabled 带内电流正贡献）。

**更精确地说**：2510.05224 的 Ω̃ 来自**杂质散射诱导的带内电流**——在干净平带中 v=0 故带内电流为零，但无序打破平移对称后，原本禁戒的带内光学跃迁被激活（"disorder-enabled optical response"）。这是**电流顶点修正的实部**（杂质线连接电流顶点的梯形图），不是自能展宽。B 的"扩散子脱钩"论证正确地判定带间顶点不与扩散子耦合（从而无 τ 增强/压低），但**未计算**带内顶点的无序激活（Ω̃）——因为 B 的框架（§3.3）专注于带间几何通道的 τ 标度，未系统展开带内 disorder-enabled 贡献。

**∴ B 的 Lorentzian 描述的是"纯带间几何劣化"（只有 Ω_I 削弱），遗漏了 disorder-enabled 带内正贡献 Ω̃。** 在对称轨道上 Ω̃ ≈ Ω_I，B 的 Lorentzian 将**高估**净劣化（因只计入负贡献、未计入正贡献）。

### §5.3 对非对称轨道的修正

2510.05224 指出 Ω̃ ≈ Ω_I 的抵消对"对称相关平带轨道"普适（Wannier 中心位于最小量子度量位点时差为零）。对于**非对称轨道**，抵消不完全，Ω̃ − Ω_I ≠ 0。此时净劣化量级：
$$\frac{\delta D_s}{D_s(0)}\bigg|_{\Delta} \sim \frac{W^2}{\Delta_{sc}^2} \cdot \frac{|\tilde\Omega - \Omega_I|}{\int {\rm Tr}\,g}$$

其中 |Ω̃ − Ω_I| / ∫Tr g ≤ O(1)。对极度非对称的轨道（如某些 kagome 平带的非等价子格位点），此比值可达 O(1)，此时 B 的 Lorentzian 给出正确的量级估计（作为上界）。对高度对称的轨道（Creutz, Lieb, 某些 pyrochlore），比值 ≪ 1，B 显著高估。

### §5.4 裁决三结论

| 项目 | 裁决 |
|------|------|
| 对称轨道的固定Δ劣化 | **A/2510.05224 对**：近抵消，O(W²/Δ_sc²) × 小因子 ≪ 1 |
| 非对称轨道的固定Δ劣化 | B 的 Lorentzian 为**上界**；实际劣化在 0（全抵消）与 Lorentzian（零抵消）之间 |
| B 是否"错"了 | 否——B 的 Lorentzian 是正确的**最坏情况上界**（零抵消极限）。B 的疏漏是未讨论抵消机制，导致其声张（"ℏ/τ~2Δ 即半衰"）在对称轨道上过于悲观 |
| 对 W_c^(AG) 的影响 | 若固定Δ劣化可忽略（对称轨道），则 D_s(W) 下降**完全来自** Δ_sc(W) 抑制 → W_c^(AG) 由配对破坏判据 ℏ/τ=2Δ_sc 单独设定，不受固定Δ劣化的额外加速。B 的 W_c^(AG) 公式在两种情形均成立（因 W_c 判据是配对破坏，非几何劣化） |

## §6 自我攻击 + 网络交叉验证

**自攻 1：SCBA 自能 ℏ/τ ∝ W²/W_flat 在理想平带区（W_flat → 0）是否自洽？**
→ B 已处理：区(ii) 中自能自洽展宽 Γ ~ W 主导 DOS → ℏ/τ ∝ W（线性）。这从 W²/W_flat 的 1/W_flat 发散平滑过渡到 ~W——物理上合理。但 SCBA 在强无序（ℏ/τ ~ Δ_sc）的定量精度有限：它忽略 Anderson 局域化对谱函数的修正（多重分形、迁移率边），这些修正恰在 W → W_c 时重要——这正是"临界区"未被解决的原因。✓ 不影响 W_c 的量级估计，但影响精确前因子。

**自攻 2：2203.01058 的"普适压制、与几何无关"是否真的与 B 的"C 无关"一致？**
→ 细节层有差异。2203.01058 的核心结论是"无序压制 D_s 的函数形式在各类平带（拓扑/非拓扑、平/色散）中普适"——这是一个比 B 的"C 无关"更强的陈述（包含与带平度无关）。B 的 P3（反常脆性：越平越脆）似乎与"与带平度无关"冲突。但仔细区分：2203.01058 的"与带平度无关"指的是**规一化压制函数** f(W) = D_s(W)/D_s(0) 的函数形式普适；B 的 P3 指的是**绝对 W_c 值**随 W_flat 减小而减小（因为 ℏ/τ ∝ W²/W_flat → 更小的 W 达到同样的 ℏ/τ）。两者不矛盾：f(W) 可以普适（都是 Lorentzian 型），但自变量 ℏ/τ(W) 对 W 的依赖随 W_flat 变化——所以 W_c（使 ℏ/τ=2Δ_sc 的 W 值）随 W_flat 减小而减小。B 的 P3 与 2203.01058 兼容，但 B 应该更清楚地说明：P3 是关于 ℏ/τ(W) 对 W_flat 的依赖性，而非关于 f(ℏ/τ) 函数形式的非普适性。✓

**自攻 3：A 的"双能标层级"是否可能因 Δ_sc 在 W 接近 Δ_gap 前已被抑制到零而变成单能标？**
→ 这正是 §3 的要点。在物理现实中，Δ_sc(W) 在 W_c^(AG) ≪ W_c^(struct) 处已被严重抑制。所以"双能标"在超导问题中退化为"一个相关能标 Δ_sc + 一个不相关的更高能标 Δ_gap"。A 的层级 W_flat ≪ Δ_sc ≪ Δ_gap 在干净极限正确，但在无序下 Δ_sc 先塌缩，使 Δ_gap 变得不相关。A 把干净极限的能标层级直接映射为无序下的"双阈值"时，未考虑 Δ_sc 本身的 W 依赖性使第二阈值失去超导意义。✓

**自攻 4：如果 B 的扩散子脱钩是正确机制，为什么 2510.05224 能用完全不同的语言（局域化泛函 Ω̃−Ω_I）得到同一结论？**
