# 研究计划 — FlatBand-Disorder (LP10-S3) v1

## 北极星（候选池 LP10-S3）
非磁无序是否破坏平带超导的几何超流权重贡献？破坏临界强度W_c与平带带宽的关系？

## 驱动矛盾
**命题A（几何抗无序）：** 几何贡献根植Bloch拓扑，弱非磁无序(Anderson)拓扑保护下只重整不破坏，W_c~Δ_gap≫实验无序。
**命题B（几何脆于无序）：** (B1)平带动能淬灭→无动能屏蔽→无序在平带是强微扰(有效W/W_flat≫1)，几何相干被局域化摧毁，W_c~W_flat≪Δ_gap；(B2)无序破坏平移对称→C不良定义→拓扑保护失效(同S6准晶教训)。

## 苏格拉底形式化（PI主线程，3轮）
**第1轮·标度/局域化（无序↔Anderson局域化）：** 几何贡献∝量子度量∫g，无序使Bloch态局域化(局域长度ξ)。追问：几何贡献是否∝ξ²(像Drude权重)还是拓扑保护(不依赖ξ)？结构同构：S5的"k*≠k_0脱钩"——无序把动量k涂抹(Δk~1/ξ)，几何相干尺度ℓ_g vs 局域化长度ξ谁先到。若ℓ_g<ξ→几何贡献在局域化前存活(命题A)；ℓ_g>ξ→局域化先摧毁几何(命题B)。
**第2轮·拓扑（无序下的拓扑不变量）：** C只对平移不变定义。无序下用实空间Chern marker(Bianco-Resta)/Bott指数替代。追问：Porlles-Chen的超流权重marker与Bianco-Resta Chern marker是否同源？无序下实空间Chern marker的自平均值⟨C(r)⟩在W<W_c保持量子化(迁移率边以下)→几何下界以实空间marker形式存活。接S1-K1.2(下界活在积分/平均层)的无序版。
**第3轮·信息论/随机矩阵（无序系综↔普适性类）：** 无序系综的几何marker分布属哪个随机矩阵普适类？追问：⟨√det g⟩系综平均 vs 单样本涨落。自平均性(self-averaging)是几何下界在无序下存活的关键——若∫√det g自平均→下界对典型样本成立；若强涨落(非自平均,如临界点)→下界只对系综均值成立非典型样本。连接S1-AHA#1(Fisher信息)：无序=对哈密顿的不确定性，量子度量获random-matrix修正。

**提炼命题：** W_c由两尺度竞争决定——几何相干长度ℓ_g vs Anderson局域化长度ξ(W)。W<W_c(ℓ_g<ξ)：实空间Chern marker量子化+几何下界自平均存活(命题A条件版)；W>W_c：局域化摧毁几何相干(命题B)。W_c标度是W_flat(带宽,命题B1)还是Δ_gap(带隙,命题A)？关键判据：平带的无序展宽δW_dis~W是否超过Δ_gap(超过则带间混合+局域化双杀)。
**知识库连接：** S5-K1.2(k*≠k_0脱钩，无序是其无规版)+S1-K1.2(marker积分/平均层)+S2-K2.1(顶点修正,无序顶点vs关联顶点)。

## 研究路径
### Phase 1：两尺度竞争ℓ_g vs ξ(W) + 实空间Chern marker（解析+marker）
- BdG+Anderson无序，定义几何超流权重marker(Porlles-Chen)与Bianco-Resta Chern marker，证其同源性。
- 计算几何相干长度ℓ_g与局域化长度ξ(W)的标度，定W_c。
- 产出：W_c(W_flat, Δ_gap)关系式。
### Phase 2：自平均性 + 系综涨落（随机矩阵/系综平均）
- ⟨√det g⟩系综平均 vs 样本涨落，自平均性判据。
- 产出：几何下界对典型样本vs系综均值的存活性。
### Phase 3：文献无序平带数值交叉验证
- 与无序TBG/Lieb超流权重数值(若有)对照。产出：W_c验证+相图。
