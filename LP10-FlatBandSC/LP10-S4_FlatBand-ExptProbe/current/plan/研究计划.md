# 研究计划 — FlatBand-ExptProbe (LP10-S4) v1

## 北极星（候选池 LP10-S4）
是否存在干净可观测量，其值在"几何主导"vs"常规主导"假设下显著差异，且当前实验精度可测？

## 驱动矛盾
**命题A（存在干净判别探针）：** λ(T)低温标度+T_BKT/D_s普适比+无序响应三方面定量可分辨，TBG/AV₃Sb₅可测。
**命题B（探针被污染）：** (B1)S5已证T_BKT与几何数学下界脱钩(k*≠k_0)→T_BKT比判据被度量BZ分布污染;(B2)S2已证关联重整c'=c·Z·min_k w→λ(T)标度被Z+顶点修正污染→无模型无关判别量。

## 苏格拉底形式化（PI主线程，3轮）
**第1轮·测量论（可观测量↔可分辨性）：** 判别探针=区分两假设的统计检验。追问：几何/常规D_s之差ΔD_s相对实验误差棒σ_exp是否>分辨阈值？这是假设检验的功效问题。结构同构：S1-AHA#1的量子Fisher信息——判别探针的"功效"=对"几何分数f_geom"参数的Fisher信息。f_geom的Cramér-Rao下界(实验可达精度)决定能否判别。
**第2轮·对称性/普适性（什么是模型无关的）：** 常规D_s∝Δ(能隙)，几何D_s∝∫g(量子度量)。追问：有无量纲组合使模型依赖前因子抵消、只留几何/常规比值？候选：T_BKT/D_s(0)(Nelson-Kosterlitz普适比)、λ(0)²D_s关系、d ln D_s/d ln T低温幂次。哪个对Z重整(S2)和k*≠k_0(S5)免疫？接S2-K2.6(c'真空化)——若判据含c'则被关联污染,需找c'抵消的比值。
**第3轮·非平衡/动力学（响应函数的指纹）：** 几何贡献的指纹是否在动力学响应(光电导σ(ω)的Drude权重 vs 带间权重、抗磁响应的非局域性)更干净？追问：几何贡献来自带间相干→在有限频σ(ω)的带间峰留指纹，而常规是Drude(ω=0)。频率分辨可分离几何/常规,绕过S5的T_BKT脱钩问题。

**提炼命题：** 三候选探针(λ(T)标度/T_BKT普适比/σ(ω)带间权重)中，**σ(ω)有限频带间权重最干净**——它直接测∫g(几何)且在频域与Drude(常规)分离,对Z重整鲁棒(Z只标度整体不改带间/带内比);T_BKT比被S5的k*≠k_0污染(中等);λ(T)标度被S2的Z+顶点污染(最不干净)。预期"有边界"：存在干净探针(命题A)但需是频率分辨的光学/THz测量而非热力学量。
**知识库连接：** S1-AHA#1(Fisher信息=判别功效)+S2-K2.6(c'污染λ标度)+S5-K1.2(k*≠k_0污染T_BKT比)。S4整合S1/S2/S5的污染源来筛选干净探针。

## 研究路径
### Phase 1：三探针的几何/常规分辨度 + 污染源分析（解析）
- λ(T)低温标度(Bardeen-Stephen/量子度量控制)、T_BKT/D_s(0)普适比、σ(ω)带间/Drude权重比的几何vs常规预测。
- 用S2(Z重整)+S5(k*≠k_0)逐一检验哪个探针被污染。
- 产出：三探针的"干净度"排序+定量可分辨判据。
### Phase 2：实验精度可行性（功效分析）
- f_geom的Fisher信息/Cramér-Rao下界 vs TBG/AV₃Sb₅当前测量精度(λ的μSR、σ(ω)的THz)。
- 产出：可行探针清单+所需精度。
### Phase 3：具体材料预测
- 对魔角TBG、kagome AV₃Sb₅给σ(ω)带间权重的几何分数预测。产出：可证伪实验预测。
