## §N 独立推导

### §N.1 参数化与 Fisher 信息矩阵的搭建

超流权重的几何/常规配分（裸，去Z前）：
```
D_total^bare = D_conv^bare + D_geom^bare ,   f_geom ≡ D_geom^bare / D_total^bare ∈ [0,1]
```
关联重整(继承 B0.2, S2-K2.6)整体乘 Z：观测刚度 D_s = Z·D_total^bare（Z 为准粒子权重×顶点的有效标度因子；min_k w 吸收进 Z 的定义）。

设观测量矢量 {O_a}，每个 O_a = O_a(f_geom; θ)，冗余参数 θ = (Z, W, δ_bg, η_gap, ...)，分别为关联重整、带宽、光学本底误差、能隙各向异性。N 次独立测量、加性高斯噪声 σ_a。**Fisher 信息矩阵**：
```
F_ij = N · Σ_a (1/σ_a²) (∂O_a/∂φ_i)(∂O_a/∂φ_j) ,   φ = (f_geom, θ)
```
对 f_geom 的可达精度（边缘化 θ）由**逆矩阵对角元**给出 = **Schur 补**的倒数：
```
σ²(f_geom) ≥ [F⁻¹]_{ff} = 1 / ( F_ff − F_fθ F_θθ⁻¹ F_θf )
            ≡ 1 / I_eff(f_geom)
```
**这是"污染"的精确数学定义：** 当 ∂O/∂f_geom 与冗余方向 span{∂O/∂θ} 近**共线**时，Schur 补 I_eff→0，σ(f_geom)→∞。探针"被污染"⟺其得分向量几乎落在冗余子空间内。判别阈值：判别 Δf_geom=1 需 **I_eff·(Δf_geom)² > z²**（z=2为2σ，z=3为3σ）。

### §N.2 探针1 —— 绝对超流权重 λ(0)/D_s(0)：**Fisher 信息恒等于零**

观测量 O_λ = D_s(0) = Z·D_total^bare = Z·(D_conv^bare + D_geom^bare)。用 (f_geom, D_total^bare, Z) 重参数化：D_geom^bare = f_geom·D_total^bare, D_conv^bare = (1−f_geom)·D_total^bare。则
```
O_λ = Z · D_total^bare          ⟹   ∂O_λ/∂f_geom |_{D_total^bare, Z} = 0   (恒等)
```
**结论(L2级)：绝对超流权重对 f_geom 的 Fisher 信息严格为零。** 物理：f_geom 是一个**和的配分**，而绝对观测量只约束**和** D_total。和无法约束自身的内部比例。这比A的"被Z污染"强一个量级——A暗示精度够高或许可救，我证明**结构性退化，精度无限也无解**（除非独立输入 D_total^bare 的微观分解，即引入模型⟹不再模型无关）。⟹ **P1 成立。**

λ(T) 的**温度形状**确有 f_geom 依赖（几何平带给特定 D_s(T) 形状 vs 常规BCS）。但 ∂(shape)/∂f_geom 与 ∂(shape)/∂η_gap（能隙各向异性：节点vs无节点也改低温幂次）以及 ∂(shape)/∂Z(T) 高度共线 ⟹ F_fθ F_θθ⁻¹ F_θf ≈ F_ff ⟹ I_eff(shape)→小。**λ 探针整体最差，与A一致，但根因更深（绝对值零信息 + 形状共线）。**

### §N.3 探针2 —— Nelson-Kosterlitz 比 R = T_BKT/D_s(0)：Z 消、度量分布不消

R = T_BKT/D_s(0)。**Z 在分子分母同时出现**（T_BKT∝D_s(T_BKT)∝Z，分母∝Z）⟹ **Z 在 R 中精确抵消** ⟹ ⟨dR, dZ⟩=0。这是 R 优于 λ 的根本原因（A定性说"Z消"，我给出 ∂R/∂Z=0 的精确陈述）。

但 R 的 f_geom 依赖被两件事压制：
1. **普适跳变本身 geometry-blind：** 干净2D下 R→π/2 与 f_geom 无关；f_geom 信息只藏在 T=0→T_BKT 间 D_s(T) 的形状里。
2. **S5-K1.2 (B0.3) 的 k*≠k_0：** BKT 涡核动量标度 k* 与度量极小 k_0 脱钩 ⟹ T_BKT 采样的几何含量 ≠ T=0 处的，引入**度量BZ分布**这一新冗余方向 η_dist。∂R/∂f_geom 与 ∂R/∂η_dist 共线。
```
I_eff(R) = F_RR^{(f)} · sin²α ,  α = ∠(∂R/∂f_geom, ∂R/∂η_dist)
```
S5 使 α 小（共线）⟹ **中等污染**，与A的"T_BKT被S5污染(中等)"定性一致。**额外**：实样BKT跳变被有限尺寸/无序圆化(见⭐Q5)，σ(T_BKT) 被抬高，进一步吃掉残余 I_eff。

### §N.4 探针3 —— σ_s(ω) 带间峰权重：A的"最干净"主张被 Fisher 矩阵**反驳**

A的论点：σ_s(ω) 带间峰(有限ω~E_gap)∝D_geom，与 Drude(ω=0)频域分离，Z只整体标度。

**我的反驳（核心分歧）：** 频率 ω~E_gap 处的权重有**两个物理上不同、频域不可分**的来源：
- (i) 几何超流权重（Cooper对带间相干，会凝聚的部分）；
- (ii) **普通非超导带间吸收**（正常态就存在的带间跃迁，与是否超导无关）。

二者**共频** ⟹ 在 Fisher 矩阵中 ∂σ_s(E_gap)/∂f_geom 与 ∂σ_s(E_gap)/∂B_inter（B_inter=非SC带间振子强度，一个冗余参数）**共线**：
```
I_eff(σ_s带间) = I_naive · sin²β ,  β = ∠(∂σ_s/∂f_geom, ∂σ_s/∂B_inter) → 0
```
⟹ **有效Fisher信息近零。** 这正是A自己在研究计划§风险里标注的"叙事退让位置"（带间峰与非SC带间跃迁混叠）。**我把它从脚注提升为致命简并**：σ_s(ω) 单谱**原则上**无法分离 (i)(ii)，不是测量精度问题。⟹ **P2 成立**，且驳斥A的"最干净"定性。

并且 I_naive 本身 ∝ (E_gap/Δ)：能隙拉开时几何权重"借"自远处 ω~E_gap，频域分离好；E_gap~Δ（S5非孤立区）时 (i)(ii) 与 Drude 三者重叠，连 I_naive 都塌。

### §N.5 我的干净探针 —— FGT 差谱高频凝聚权重（与A不同的解）

**FGT/f-sum rule（模型无关）：**
```
∫_0^∞ σ_1(ω) dω = (π/2)(n e²/m)   [总权重，由总密度/裸质量定，模型无关]
```
凝聚权重 = 正常态减超导态差谱的积分（Ferrell-Glover-Tinkham）：
```
W_c = ∫_{0^+}^∞ [σ_n(ω) − σ_s(ω)] dω = (π/2) D_s      [δ(ω)凝聚峰=缺失面积]
```
**关键步骤——差谱扣掉了 f_geom-无关的非SC带间本底 (ii)**（若 (ii) 跨 T_c 稳定）。再按频率切分（ω_c 取 2Δ<ω_c<E_gap）：
```
W_c = W_c^low (ω<ω_c, 带内/常规借权) + W_c^high (ω>ω_c, 带间/几何借权)
f_geom ≈ W_c^high / W_c
```
**保护性论证：**
- **Z免疫：** W_c^high 与 W_c 同 ∝Z ⟹ 比值中 Z 消 ⟹ ⟨d(W_high/W_c), dZ⟩=0。
- **非SC带间免疫：** 差谱 σ_n−σ_s 一阶扣除 (ii)（前提 E_gap≫2Δ，高能带间跃迁是"旁观者"跨T_c不变）。这恰好补上 §N.4 的简并：A用单谱σ_s无法分(i)(ii)，**差谱用第二温度点(正常态)做了减法**。
- **sum-rule保护：** 总W_c由FGT锁定；W_high/W_low 的切分是**频率窗口**(实验定)而非微观顶点(理论定)——但⭐Q2警示 ω_c 选择仍可能偷渡模型，需正文核实切分是否observable-defined。

⟹ **P3**：差谱高频凝聚权重是 sum-rule 保护、Z 免疫的干净探针。代价：需**双温微分光学**(测 σ_n 与 σ_s 两态)，比A的单谱要求更苛刻、更具体。**这是与A的实质分歧：A说"测σ_s(ω)带间峰"，我说"测 σ_n−σ_s 差谱的高频凝聚分量"。**

### §N.6 差谱探针的 Fisher 信息与可行性（统计 vs 系统）—— 重构可行性判据

构造上 O = W_high/W_c ≈ f_geom ⟹ ∂O/∂f_geom = 1。设各谱权重积分相对误差 ε（THz/椭偏+KK 典型 ε~1–5%）。二项式型传播：
```
σ_O ≈ f_geom(1−f_geom) √2 · ε        [f=0.5: σ_O ≈ 0.7ε]
I_naive = 1/σ_O²
```
ε=2%, f=0.5 ⟹ σ_O≈0.014 ⟹ 单次 σ(f_geom)≈0.014≪1 ⟹ **统计上判别 H_conv vs H_geom 在 >>10σ**。统计precision远非瓶颈。

**真瓶颈——本底扣除的系统误差（Schur补地板）：** 设高频窗内非SC本底 B 的扣除存在分数误差 δ_bg（先验宽度 σ_δ）：W_high^meas = W_high^true + δ_bg·B。则 ∂O/∂δ_bg = B/W_c。边缘化高斯 δ_bg：
```
I_eff = I_naive / [1 + I_naive·(B/W_c)²·σ_δ²]   ⟶(σ_δ大)⟶  (W_c/B)² / σ_δ²
```
判别 Δf_geom=1 需 I_eff>z² ⟹ **判别可行 ⟺**
```
   σ_δ  <  (W_c / B) / z          【B框架的可行性判据】
```
即"非SC带间本底须扣到 优于 (凝聚权重/本底权重)/z"。

### 苏格拉底清单（前三⭐为最重要）

- **⭐Q1（最深，威胁全题）：f_geom 是否规范/轨道嵌入无关地良定义？** 几何/常规配分 D_s=D_conv+D_geom 可能依赖 Wannier 规范/轨道在原胞内的位置（Marzari-Vanderbilt式歧义）。若配分非规范不变，则**无任何观测量能估计 f_geom，全题病态**。倾向判断：几何贡献下界用的是**最小量子度量**（规范不变），但 conv/geom 的**分界**只在固定物理轨道嵌入（真实原子位置）后才良定义。⟹ **f_geom 须相对"物理嵌入"定义，否则估计论对象不存在。必须正文核实。**（接 B0.1, S1-AHA#1）
