## §2 强制撞墙（不绕过最脆弱步）

### 撞墙点 1：P3 的符号——带间混合"削弱"还是"增强"积分度量？

单条平带的量子几何张量（QGT，标准二阶微扰）：
```
G^f_{μν}(k) = Σ_{n≠f}  ⟨u_f|∂_μ H|u_n⟩⟨u_n|∂_ν H|u_f⟩ / (E_f − E_n)²
g_{μν} = Re G_{μν},   Ω = −2 Im G_{xy}.
```
关键观察：**单条平带的度量本身就完全由对"其它带"的虚跃迁构成**。把 n≠f 的求和按带隙拆分：
```
g_full = g_{intra}(平带流形内, 单带时=0) + g_{inter}(对色散带, 含 1/Δ_gap² 项).
```
"非孤立"修正项 g_inter^{(disp)}(k) = Σ_{n∈disp} Re[⟨u_f|∂_μH|u_n⟩⟨u_n|∂_νH|u_f⟩]/Δ_gap(k)² ~ (t⊥·a)²/Δ_gap² ~ λ_b²（a=晶格尺度，吸收进系数）。

**每一项 g_inter^{(n)} 是半正定**（形如 v†v/Δ_gap²，Re 部分为半正定 Gram 矩阵）。故：
```
∫_BZ tr g_full  =  ∫ tr g_isolated  +  ∫ tr g_inter^{(disp)}  ≥  ∫ tr g_isolated  ≥ 2π|C|.
```
**带间混合只能"增加"积分度量，不能减少。** P3 的 [1−O(λ²)] **符号错误**；正确是 [1+O(λ²)]≥1。

> 独立佐证（非循环）：2604.05994 数值——MATBG 加入 remote 带后几何占比 22–26%→55–58%，"remote bands contribute exclusively through interband coherence"。即带间相干**增加**几何贡献，与上式符号一致。

**撞墙结论 1**：研究计划 P3 写法错。下界的**数学形式与系数**因带间混合而**增强**：√det D_s ≥ c·Δ_sc·π|C|·[1+O(λ²)]。

### 撞墙点 2：那命题B2"破坏稳定性"的物理从哪来？——下界系数 ↑ 与 稳定性 ↓ 的解耦

若 ∫g 增加，命题B2"带间混合破坏稳定性"岂非自相矛盾？**不矛盾，因为二者是不同的物理量**：

2603.08791 的核心断言：稳定性不由 ∫g（全局）决定，而由**凝聚动量 k_0 处的局域度量 g(k_0)** 主导（"plays a disproportionately large role"）。BKT/涡旋解禁的有效刚度 ∝ g(k_0)，而非 ∫g。

带间混带项 δg(k) ∝ 1/Δ_gap(k)²。设带隙在 k\* 取极小 min_k Δ_gap，则 **δg(k) 在 k\* 处尖峰**——带间混合把新增几何权重**集中堆在 k\***。两情形：
- k\* = k_0（隙最小点恰是凝聚点）：g(k_0) 被增强 → **有利**稳定（局域几何变足）。
- k\* ≠ k_0：新增几何全堆在 k\*≠k_0，**只进 ∫g（全局），不进 g(k_0)（局域）** → 2603.08791 场景"∫g 大无用" → 对 T_BKT 的约束被稀释，退化 O(λ²)。

**撞墙结论 2**：**下界系数 ↑[1+O(λ²)]（数学，几何容量增加）与 T_BKT 物理约束的有效性 ↓[1−O(λ²)]（k\*≠k_0 时局域几何被旁路）解耦。** 命题A（数学下界存活且增强）与命题B2（物理意义退化）**同时为真，不矛盾**——这是本 Phase 的关键认识增量，纠正了研究计划把二者混为"下界减弱"的错误。

### 撞墙点 3（最脆弱，正面硬撞）："退化是平滑 O(λ²)"是错的——λ 是 k-依赖的

撞墙点 2 默认 δg(k\*) ~ λ² 全局小。**但 λ(k) ≡ t⊥/Δ_gap(k) 是逐点的。** 即使
```
全局平均   ⟨λ²⟩ = t⊥² ⟨1/Δ_gap²⟩  小（带看似孤立、带宽小、平均隙大），
```
只要 BZ 内某 k\* 有近简并 Δ_gap(k\*) → 参数化小，则
```
λ(k\*)² = t⊥²/Δ_gap(k\*)²  →  O(1) 甚至发散，
```
**微扰在 k\* 局域失效**，δg(k\*) 非 O(λ²) 小。"平滑 O(λ²)退化"在有近触带点时**假**。

**正确控制参数**：不是全局 λ，而是
```
   λ_max ≡ t⊥ / min_k Δ_gap(k).
```
命题A（微扰、下界形式存活、物理意义平滑退化）成立 **⟺ λ_max < 1**，即带隙**处处**不闭且非参数化小。

真实关联：TBG 偏离魔角或特定填充时，平带对 remote 带的隙 Δ_gap(k) 在 BZ 某些点变小（Xie-Bernevig 1906.02213 / Julku 1906.07152 的能带数据）→ λ_max 升向 1 → 边界对真材料**非纸面**。

**撞墙结论 3**：边界由 λ_max 而非 λ_avg 控制。这是命题A 失效、命题B 启动的精确判据。

## §N 正文（步骤 / 依据 / 反驳检验）

### 步骤 1：Schrieffer-Wolff 有效平带与有效度量 δg 的 (t⊥/Δ_gap)² 标度

**构造**：H(k)=H_0(k)+V(k)，H_0 在 P（平带，能量取 0）/ Q（色散带，能量 ~Δ_gap）分块对角，V=PVQ+QVP 为带间耦合，‖V‖~t⊥。SW 反厄米生成元 S 解 [H_0,S]=V_od，得块对角有效哈密顿：
```
H_eff = e^{S} H e^{−S} |_{P块}
      = PH_0P + (1/2)P[S,V]P + O(V³)
      = PH_0P − P V Q (QH_0Q − E_P)^{-1} Q V P + O(t⊥³/Δ_gap²).
```
**依据**：标准 SW（Schrieffer-Wolff, PR 149, 491 (1966)；Bravyi-DiVincenzo-Loss 2011 综述）。取 E_P=0、QH_0Q≈Δ_gap：
```
H_eff(k) ≈ PH_0P − (1/Δ_gap) P V Q V P  ⇒  诱导带宽 W ~ t⊥²/Δ_gap = λ_b² Δ_gap.
```
→ **平带获得 O(λ_b²) 色散**（不再严格平），即"非孤立"的第一后果。

**有效本征态**（一阶）：|ũ_f(k)⟩ = |u_f⟩ − Σ_{n∈disp} |u_n⟩ ⟨u_n|V|u_f⟩/Δ_gap，混入幅 α_n = ⟨u_n|V|u_f⟩/Δ_gap ~ λ_b。

**有效度量**：由步骤的 QGT 拆分（§2 撞墙点1），
```
δg_{μν}(k) = g_full − g_isolated = Σ_{n∈disp} Re[⟨u_f|∂_μH|u_n⟩⟨u_n|∂_νH|u_f⟩]/Δ_gap(k)²
           ~ (t⊥ a)²/Δ_gap(k)² = a² λ_b(k)²  （半正定）.
```
**标度判定**：δg ~ λ_b²，解析于 λ_b²（H1 隙开 ⇒ 分母不消失 ⇒ 级数收敛）。✔ 与研究计划 Phase1 预期一致，但**符号为正**（增加度量）。

**反驳检验**：若有人称 δg 可负（削弱度量）——反驳：g_inter^{(n)} = Re(v_μ† v_ν)/Δ_gap² 为 Gram 型半正定，tr 部恒 ≥0；削弱只能来自 g_isolated 自身随 t⊥ 改变其内禀结构，那是 O(λ_b²) 的二阶再修正，不改 ∫tr g 的下界 2π|C|（见步骤 2）。

### 步骤 2：∫√det g_eff 的修正 与 C 的整数性（拓扑保护，接 S1-K1.2）

**积分度量**：
```
∫_BZ tr g_eff = ∫ tr g_isolated + ∫ tr δg = ∫ tr g_isolated · [1 + O(λ_b²)],  且 ≥ 2π|C|.
```
**依据**：度量-曲率不等式 tr g(k) ≥ 2√det g(k) ≥ |Ω(k)|（QGT 正定性，不需 TRS，H4），逐点成立；积分 ∫tr g ≥ ∫|Ω| ≥ |∫Ω| = 2π|C|（Peotta-Törmä 1506.02815；Roy 2014）。δg 半正定只把左端抬高。

**C 仍整数？——是，且严格（拓扑保护的硬证据）**：
- P(k)=Σ_{f∈flat}|ũ_f(k)⟩⟨ũ_f(k)| 在 H1（min Δ_gap>0）下全 BZ 光滑、秩恒定。
- C = (i/2π)∫_BZ Tr[P(∂_x P)(∂_y P) − (x↔y)] d²k 是 P 的同伦不变量。
- **Avron-Seiler-Simon 定理**（PRL 51, 51 (1983)）：Chern 数在保持隙开（H1）的连续形变下**取常值整数**。把 t⊥ 从 0 连续开到任意值，只要隙不闭，C 不变。
- ⇒ 拓扑标度 **π|C| 对 (t⊥/Δ_gap)² 微扰严格免疫**——非"近似免疫"，是拓扑精确。✔ 这正是研究计划第2轮"C 受保护"的严格化，**直接续 S1-K1.2"C 锚定下界"**。

**下界修正公式（本 Phase 主产物，纠正研究计划符号）**：
```
   √det D_s  ≥  c · Δ_sc · π|C| · [1 + O((t⊥/Δ_gap)²)] ,     （c 含 ν(1−ν)·e²/ℏ²，沿用 S1 结构，未编造数值）
```
**π|C| 项拓扑精确不变；修正进入系数且 ≥1（增强，非削弱）。**

**反驳检验（命题B1 正面）**：B1 称"C 只对孤立带良定义，混合后不可分"。反驳：只要 H1 成立，P(k) 即良定义投影，C 即良定义整数——"孤立"在拓扑意义上**只需隙开，不需 t⊥=0**。B1 仅在 Δ_gap→0（步骤 4）时为真。故 B1 在微扰区伪、在触带处真——边界明确。

### 步骤 3：命题B2 正面处理（最脆弱，2603.08791 局域/全局判据，不绕过）

**B2 机制的严格化**（§2 撞墙点 2、3 的正文整合）：
1. 稳定性刚度（2603.08791）：D_s^stab ∝ g(k_0)（凝聚动量局域度量），**非** ∫g。BKT 转变 k_B T_BKT = (π/2) D_s^stab(T_BKT)，涡旋解禁判据依赖局域刚度。
2. 混带新增度量 δg(k) ∝ 1/Δ_gap(k)²，在带隙极小点 k\* 尖峰。
3. **分类结论**：
   - k\*=k_0：δg 增强 g(k_0) → **有利**，T_BKT 升，命题B2 反向（混带助稳）。
   - k\*≠k_0：δg 只入 ∫g 不入 g(k_0) → ∫g 增大但 T_BKT 约束被稀释 → **物理意义退化 O(λ²)**（k\* 非近简并时）/ 失效（k\* 近简并、λ(k\*)→1 时，撞墙点3）。
4. **逐点控制参数**：退化幅度由 λ(k\*)=t⊥/Δ_gap(k\*) 决定；命题A 物理意义成立 ⟺ λ_max<1。

**与 2603.08791 "≥3 带稳定"的接口（重要符号澄清）**：2603.08791 证 2D 内 Bogoliubov 理论下稳定平带超流需 **≥3 条带**。⇒ **孤立单平带的几何下界虽数学成立，但其描述的是边缘稳定/不稳定点**；色散带（非孤立性）提供稳定所需的额外带。**故"非孤立"在稳定性上可以是必要的助力，而非纯破坏**——这进一步反转命题B2 的朴素直觉：真正的约束是 g(k_0) 局域是否足够，而 k\* 与 k_0 的相对位置（材料/填充依赖）决定混带是助稳还是稀释。

**反驳检验**：若 B2 称"任何混带都破坏稳定"——反驳：上述分类给出助稳分支（k\*=k_0），2604.05994 数值（remote 带增几何占比、配对最强填充 ν=±2 处几何占比稳定）支持混带在真 TBG 不破坏稳定。B2 的破坏分支仅在 k\*≠k_0 且 λ(k\*)→1 时成立。

### 步骤 4：强混合极限 Δ_gap→t⊥（λ→1）与触带 Δ_gap→0——命题B 的真实地盘

**展开失效**：λ_max→1 时 δg~λ²,λ⁴,... 不收敛；W~λ²Δ_gap 与 Δ_gap 同阶，平带不再可辨。SW 截断 O(t⊥³/Δ_gap²) 不再小。命题A（微扰）失效。

**触带 Δ_gap→0（命题B1 真）**：隙闭，P(k) 在触点奇异，C **失定义**（ASS 定理前提破坏）。下界的拓扑标度 π|C| **失去意义**——这是命题B1 唯一为真的地方。

**但 D_s 不崩塌（反例候选2 辨明，关键）**：Huhtinen-Törmä **2203.11133** 证：band touching 处 minimal quantum metric 可**增大**，D_s 反而可被触带**增强**，而非削弱。故触带极限：
- 拓扑下界的**形式**（π|C|）失效（C 无定义）；
- 但 D_s 本身**不减反增**（minimal metric 主导）。

⇒ **命题B 在边界的真实表现 = B1（C/拓扑标度失定义），而非"D_s 崩塌/几何下界使超流消失"。** 研究计划与 PI 反例候选2 的担忧（"混带削弱 D_s"）被 2203.11133 反驳：触带助 D_s。这是命题B 朴素叙事的又一处纠正。

**反驳检验（自我攻击）**：是否存在 Δ_gap>0 但下界 π|C| 仍定性失效的反例？需 C 在隙开时改变——违反 ASS 定理，不存在。故拓扑标度的失效**严格只发生在隙闭**。命题A 在 λ_max<1 无反例（拓扑层面）；物理层面的反例（T_BKT 退化）只是定量退化，非下界形式失效。**声张 §0 的可证伪点未被触发 ⇒ 命题A 的拓扑部分存活。**
