# LP10-S5：非孤立平带带间混合对几何下界的修正

**所属长命题：** LP-10 量子几何平带超导

**子命题北极星（候选池原文）：** 所有真实材料平带非严格孤立，带间混合 δD_s~(t_interband/Δ_gap)² 是微小修正还是定性破坏几何下界？

**依赖：** S1（已收官-有边界）提供孤立极限下界 √det D_s≥cΔπ|C_tot|。

**驱动矛盾（PI苏格拉底精确化，见研究计划.md）：**
- 命题A（微扰修正）：有限带隙 Δ_gap 的带间混合是 (Δ/Δ_gap)² 量级的平滑微扰，S1下界以 √det D_s≥cΔπ|C|·[1−O((Δ/Δ_gap)²)] 形式存活，几何下界对真实材料近似成立。
- 命题B（定性破坏）：(B1) 带间混合使"孤立平带的Chern数C"不再良定义(C只对孤立带定义)，几何贡献与色散带的常规贡献纠缠不可分离→下界失去拓扑意义；(B2) 2603.08791指出"积分量子度量大不充分，BZ内分布关键"——带间混合改变g(k)的BZ分布，可能在Δ_gap有限时使下界定性失效，非(Δ/Δ_gap)²平滑。
