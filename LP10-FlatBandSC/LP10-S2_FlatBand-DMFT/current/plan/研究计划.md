# 研究计划 — FlatBand-DMFT (LP10-S2) v1

## 北极星（来自候选池 LP10-S2）
DMFT（包含全部局域关联效应）在有限温度下计算的 D_s(T) 是否满足 S1 的几何下界 √det D_s ≥ c·Δ·π|C_tot|？

## 驱动矛盾
**命题A（下界在关联下存活）：** 关联只重整化前因子 c 和能隙 Δ，不破坏拓扑标度 π|C|。DMFT 的 D_s(T) 在 T→0 仍 ≥ cΔπ|C|，Lieb/pyrochlore-Hubbard 验证。
**命题B（关联破坏下界）：** 两条独立机制——(B1) DMFT 自洽方程在非等价 Wyckoff 轨道给出非均匀 Δ_α（S1 反例D 的关联实现）→ 序参量落入非均匀配对扇区，S1 主定理前提失效；(B2) 关联诱导平带重整（自能 Σ(iω) 使有效带宽展宽/准粒子权重 Z<1）使"几何 vs 常规"分解失效 → 下界不再适用。

> 不能同时为真：要么 DMFT 的 D_s 在拓扑标度上仍被 π|C| 钉死（A），要么自洽关联把系统推出 S1 的适用扇区（B）。

## 苏格拉底形式化（PI 主线程，3轮视角切换）
**第1轮·相变/临界（局部有序↔全局）：** DMFT 的精髓是局域自能 Σ(iω) 捕获全部局域关联。平带的致命点：动能淬灭(带宽→0)使相互作用 U 成为唯一能标，DMFT 的"局域近似"在平带中反而可能更准(动量依赖弱)。追问：自能 Σ 是否携带轨道指标 Σ_α？若 Σ_α 轨道依赖 → 重整化的有效轨道能级 ε_α+ReΣ_α(0) 劈裂 → 即使裸均匀配对，关联也诱导非均匀有效配对。
**第2轮·对称性（什么被强制）：** S1 的 UPC(Δ̂=ΔÎ_orb)在 G 下不变靠"单位算符"。DMFT 自洽中，配对 Δ_α∝⟨c_α↓c_α↑⟩ 由局域格林函数决定。**结构同构**：若晶格点群对称把所有携带平带权重的轨道映为等价(同一Wyckoff轨道)→对称性强制 Σ_α、Δ_α 相等→UPC 被对称性保护，命题A；若轨道非等价(如修饰Lieb的边心vs角)→无对称保护→Δ_α 非均匀，命题B1。**判据=平带轨道的Wyckoff等价性。**
**第3轮·信息论（量子度量=Fisher信息）：** 关联使纯态→混合态(有限T+自能)，量子度量 g→关联推广的"Fisher度量"(Bures/Kubo度量)。追问：拓扑不变量C在混合态下是否仍量子化？(Uhlmann相位/Bures度规下C是否整数？)若C在DMFT格林函数的拓扑(由G(iω₀)的缠绕数定义)仍量子化→下界标度存活。

**提炼命题：** DMFT 自洽下，(i)若平带轨道Wyckoff等价→对称性强制均匀Δ_α→S1下界存活(重整c,Δ)；(ii)若轨道非等价→关联诱导非均匀Δ_α→落S1反例D扇区→几何下界一般不再紧(但夹逼退化下界√det D_s≥c·min_α(Δ_α)·π|C|可能存活，连接S1的K1.6)。
**知识库连接：** 直接接S1的K1.3(UPC的G-不变靠单位阵)+K1.6(非均匀配对校准失效)+反例D(均匀U给非均匀Δ)。S2是S1反例D的"关联动力学实现"检验。

## 研究路径
### Phase 1：DMFT自洽方程的轨道结构 + Wyckoff对称分析（解析，文献DMFT结果）
- 写出平带Hubbard的DMFT自洽：局域格林函数G_αα(iω)、自能Σ_α(iω)、配对自洽Δ_α∝T Σ_n F_αα(iω_n)。
- 用点群对称判定：哪些平带模型(Lieb/pyrochlore/sawtooth)的平带轨道Wyckoff等价(→强制均匀)，哪些非等价(→非均匀)。
- 引用 Iskin 2024(pyrochlore-Hubbard, PRB 109,174508)、Törmä组Lieb DMFT、Hofmann-Berg-Chubukov平带超导关联结果。
- 产出：Wyckoff等价性→均匀/非均匀Δ_α判据表；S1下界在各模型的适用性。

### Phase 2：混合态拓扑不变量 + 下界标度存活性（解析）
- 检验DMFT格林函数的拓扑(Volovik-Wang topological invariant from G(iω₀))是否仍量子化为C。
- 若量子化→下界标度π|C|存活，关联进c,Δ；若退量子化(关联诱导拓扑相变)→下界失效边界。
- 产出：关联下几何下界存活的条件。

### Phase 3：有限温度BKT + 文献数值交叉验证
- T_BKT vs 能带参数；检验几何下界是否约束T_BKT(Penttilä 2025 Lieb DMFT数据)。
- 产出：S1下界在有限T关联系统的验证/证伪 + 边界。
