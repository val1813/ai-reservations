## 反例栏

1. **非零 phase curvature 不推出 optical twist。** 可取恒定 null congruence `k=(1,0,0,1)`，同时在独立 `U(1)` 线丛上取 `A=(B/2)(xdy-ydx)`，则 `F=B dx∧dy !=0`，但 `dk=0`、optical twist 为零。

2. **Hopf/Berry 曲率非零不推出光锥 twist。** 标准未来光锥由方向球 `(chi,phi)` 标记，Hopf curvature `F_H=(1/2)sin chi dchi∧dphi` 非零；但标准光锥 hypersurface-orthogonal，optical twist 为零。

3. **`F_AB=chi omega_AB` 量纲不自然。** phase curvature `F_AB` 通常为 `m^-2`；optical twist `omega_AB` 为 `m^-1`。若设等式，必须引入尺度 `chi[m^-1]` 或长度 `L`，其来源不能手调。

4. **先发覆盖风险。** 如果 R1 的新意只是“null geodesic space 有 contact structure”或“spinor maps to null vector”，则被 Marín-Salvador/Rubio/Hedicke/Low/Budinich 覆盖。

5. **垂直/水平混同风险。** `U(1)` phase holonomy 是 vertical fiber observable；optical twist 是 base/screen horizontal distribution data。没有自然 connection identification 时，两者不可同一。
