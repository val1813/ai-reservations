## 反例栏

1. **圆柱螺旋不是光锥面。** 参数化 `x=R cos(ωt), y=R sin(ωt), z=vt` 给出单条曲线而非面；若嵌入 Minkowski `(-c^2dt^2+dx^2+dy^2+dz^2)`，其线元为 `ds^2 = (-c^2 + R^2ω^2 + v^2)dt^2`。只有满足 `R^2ω^2+v^2=c^2` 时曲线为 null；这不是“包络面等于光锥”。

2. **`(Re, Im, t)` 的量纲不自洽。** `Re/Im` 若是复相位平面坐标，本身无长度量纲；若强行作为空间坐标，需要引入尺度 `R`。该尺度是否为 Compton 长度、Planck 长度或任意规范选择，会决定物理含义。

3. **相位圆 `S^1` 与 Lorentz 光锥结构范畴不同。** `e^(iθ)` 是紧致内部相位，光锥是非紧致 Lorentzian 因果结构。S1 必须给出从内部相位到外部 null cone 的自然映射，不能只靠图像类比。

4. **twistor/spinor 传统已从 spinor 导出 null directions。** 如果 LP23 的 S1 只是“复二维对象生成光锥”，可能被 twistor 理论覆盖；必须证明螺旋参数化产生新的约束或新可观测量。
