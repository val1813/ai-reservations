# LP23-R3 文献库

## 先发检索栏

判定：R3 有强先发覆盖风险。候选原则“取商后仍非零的 obstruction class 才可能是新自由度”很可能落入 gauge orbit/moduli/cohomology/naturality 与统计 nuisance/model misspecification 的成熟语言。

### Gauge / orbit / quotient / moduli

- Orland, “Gauge-invariant coordinates on gauge-theory orbit space,” PRD 70, 045014 (2004), DOI: `10.1103/physrevd.70.045014`。
- “Gauge Theory and Moduli Space,” DOI: `10.1142/9789812706669_0005`。
- Fujiki, “Kähler Quotient and Equivariant Cohomology,” DOI: `10.1201/9781003419983-4`。

覆盖含义：物理对象应在 gauge orbit/quotient/moduli 上定义，而非代表元/截面上定义，是成熟框架。

### Cohomology / obstruction classes

- Norbury, “A new cohomology class on the moduli space of curves,” DOI: `10.2140/gt.2023.27.2695`。
- Andersen & Villemoes, “Cohomology of mapping class groups and the abelian moduli space,” DOI: `10.4171/qt/32`。

覆盖含义：用 cohomology class / obstruction class 表达“取商后仍非零”的量，是标准数学语言。

### Nuisance / model misspecification / residual diagnostics

- Richmond, “On Constraints in Parameter Estimation and Model Misspecification,” DOI: `10.23919/icif.2018.8455295`。
- Barber & Samworth, “Local continuity of log-concave projection, with applications to estimation under model misspecification,” DOI: `10.3150/20-bej1316`。

覆盖含义：相对模型族的投影残差/失配诊断，是标准统计与系统辨识问题。

## 反例栏

1. Gauge orbit space 反例：若 R3 只说“代表元不是不变量”，它被 gauge theory/orbit space 完全覆盖。
2. Cohomology 反例：若 R3 只说“取商后非零的是 obstruction class”，它被 cohomology/moduli 语言覆盖。
3. Nuisance 反例：若 R3 只说“模板空间外的残差才有意义”，它被 nuisance regression/model misspecification 覆盖。

## 活口栏

R3 只有一个可能活口：把 LP23 系列失败压成一个可操作的“选题/理论构造筛选定理”，能在物理提案早期自动杀死代表元误认不变量的命题。若只是哲学原则或已知数学语言重述，则硬停止。
