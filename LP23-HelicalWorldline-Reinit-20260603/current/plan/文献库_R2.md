# LP23-R2 文献库

## 先发检索栏

判定：R2 的“桥接结构存在”本身高度先发覆盖；正式推进只能检验标准商空间之外的 `I_bridge` 是否非空。

### 协变几何光学 / caustic

- Dolan, “Geometrical optics for scalar, electromagnetic and gravitational waves on curved spacetime,” IJMPD 27, 1843010 (2018), DOI: `10.1142/S0218271818430101`。
  - CrossRef 核验：存在；摘要明确讨论几何光学输运、polarization parallel transport、optical scalars、conjugate point 后的处理。
  - R2 作用：标准覆盖基线；同时给出 caustic/conjugate point 作为可能逃逸口。

### Spinoptics / helicity residual

- Frolov & Shoom, “Spinoptics in a stationary spacetime,” PRD 84, 044026 (2011), DOI: `10.1103/physrevd.84.044026`。
- Frolov, “Spinoptics in a curved spacetime,” PRD 110, 064020 (2024), DOI: `10.1103/physrevd.110.064020`。
- Frolov & Shoom, “Gravitational spinoptics in a curved space-time,” JCAP 2024, 039 (2024), DOI: `10.1088/1475-7516/2024/10/039`。
  - CrossRef 核验：存在；2024 JCAP 摘要明确为 `1/omega` helicity-sensitive correction / effective action。
  - R2 作用：任何 helicity-dependent residual 默认先发覆盖，除非 R2 给出不同可测项。

### Berry / Rytov / polarized light

- Bliokh, “Geometrodynamics of polarized light: Berry phase and spin Hall effect in a gradient-index medium,” J. Opt. A 11, 094009 (2009), DOI: `10.1088/1464-4258/11/9/094009`。
  - CrossRef 核验：存在。
  - R2 作用：medium / gradient-index / polarization Berry phase 的先发覆盖基线。

### Premetric / constitutive electrodynamics

- Hehl & Obukhov, *Foundations of Classical Electrodynamics* (2003), DOI: `10.1007/978-1-4612-0051-2`。
  - CrossRef 核验：存在；书籍和章节记录可查。
  - R2 作用：局域本构张量 `chi^{abcd}` 与介质响应分类基线。

## 反例栏

1. **真空 screen gauge 反例**：Minkowski 直线光线 `omega_optical=0`，人为旋转 screen frame 可得 `A'=A+dpsi`；端点 tetrad 固定后差异为校准项，不是传播 residual。
2. **标准覆盖反例**：若 residual 是 `O(1/omega)` helicity 项，默认进入 spinoptics 覆盖；不能作为 R2 新自由度。
3. **介质覆盖反例**：若 residual 只由局域线性 `chi^{abcd}` 决定，默认进入 premetric / constitutive electrodynamics 覆盖。

## 活口栏

1. caustic / conjugate point 后，beam-level congruence 与 single-ray polarization transport 的端点校准关系可能失效。
2. 多路径/强透镜中，不同路径的 screen/tetrad calibration 可能产生不可同时消去的相对残余。
3. 非局域、色散、历史依赖介质：`H^{ab}(x)= integral K^{abcd}(x,x') F_cd(x') d^4x'`，不一定被局域 `chi^{abcd}` 分类吸收。
