# 研究计划_R4

## Round1 目标

判断 LP23-R4 是否被既有“闭包/合法扩张/可辨识性”框架覆盖；若未覆盖，给出最小可计算闭包 toy。

## A 路

学院派查重与形式化：

1. 查 EFT operator basis / field redefinition / redundancy / RG closure。
2. 查 system identification identifiability、model set closure、residual model structure。
3. 查 causal model closure、measurement protocol、constitutive response causality/passivity。
4. 给出 R4 的最小数学对象 \(C(P)\) 及其失败边界。

## B 路

可执行压力测试：

1. 基于 `scripts/r3_qnp_lint_toy.py`，把“任意补列”替换为“由物理生成规则产生的补列”。
2. 给出至少两种闭包规则：开放闭包会吸收 residual；受限闭包可能保留 residual。
3. 明确哪些规则不是物理，只是人为限制。

## PI 判据

- 若 A/B 都显示 R4 已被成熟闭包理论覆盖，硬停止/再 Re-escalation。
- 若 B 的闭包规则无法阻止任意补列吸收，R4 判死。
- 若存在清晰、物理可辩护、可计算的闭包规则并保留非零类，进入 Round2。
