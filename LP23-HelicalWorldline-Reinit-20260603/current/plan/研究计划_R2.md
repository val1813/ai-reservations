# LP23-R2 研究计划

## 当前北极星

Bridge quotient invariant 生死检验：

`R_{beta beta'}[gamma] = C_beta F_beta(H[gamma]) - C_beta' F_beta'(H[gamma])`

是否存在标准 gauge / endpoint calibration / spinoptics / constitutive equivalence 吸收不了的非零 residual？

## Round1 目标

1. A 路：标准覆盖边界。证明或反证以下三簇是否穷尽：
   - 真空几何光学：NP/GHP + Berry/Rytov + endpoint tetrad calibration；
   - helicity residual：spinoptics `O(1/omega)`；
   - 局域介质：constitutive tensor `chi^{abcd}`。
2. B 路：构造一个非标准 readout residual toy model，要求能落到公共 observable 空间，避免类型错误。
3. PI 判定：是否存在至少一个标准商空间外的候选 `I_bridge`，优先 caustic / multipath / nonlocal medium。

## 本地计算策略

当前不需要 GPU。若进入 ray tracing / caustic propagation / nonlocal kernel 数值积分，先写本地 Python 脚本做最小模型；若 8G 显存或本机 CPU 不足，登记到“待VPS计算”。

## 判死条件

若 Round1 显示所有候选 residual 都分别被 endpoint tetrad calibration、NP/GHP、spinoptics 或局域/非局域本构理论吸收，R2 降级为分类性 no-go，继续 AHA 矩阵寻找下一北极星。
