# LP23 项目知识库

## K1 — 固定半径螺旋不生成光锥

固定半径单位螺旋或其相位平移族的自然集合是圆柱 `X^2+Y^2=ell^2`；光锥要求 `X^2+Y^2=c^2t^2`。即使单条螺旋满足 null 速度条件，也只得到 null 曲线，不得到 null cone 面。

来源：A round1 + B round1，INSPECTOR A/B 均通过。

## K2 — 相位 Re/Im 不能直接当物理坐标

`e^{iθ}` 的 `Re/Im` 无量纲。要嵌入 Minkowski 度规，必须给长度尺度和坐标解释。若相位作为 `U(1)` 纤维/holonomy，则整体相位通常不是可观测 spacetime 坐标。

来源：A round1 + B round1，INSPECTOR A/B 均通过。

## K3 — 可存活重表述

LP23-S1 的可存活版本不是“单位螺旋包络=光锥”，而是：

- 2+1 截面：`e^{i alpha}` 标记 null 方向，`rho=ct` 给径向尺度，像集为光锥。
- 3+1 协变语言：spinor bilinear `k^mu=xi^\dagger sigma^mu xi` 给未来 null cone；`U(1)` 相位是 Hopf 纤维/connection 变量。

来源：PI round1 综合。

## K4 — 下一核心卡点

量子动力学相位 `θ=(Et-p·x)/hbar` 是 Lorentz 标量；null 方向角 `alpha` 在 boost 下按 aberration 变换。LP23 若要识别二者，必须引入额外结构，例如 tetrad、momentum direction、spin frame、twistor incidence relation 或 connection holonomy。

来源：A round1 深挖 + B round1 Hopf/contact 路线。

## K5 — `theta=alpha` 不协变

强同一化 `θ=α` 被第2轮证伪。`θ=(Et-p·x)/hbar` 是 Lorentz 标量；observer celestial angle `alpha` 在 boost 下 obeys aberration。无额外结构的 `alpha=f(theta)` 会错误给出 `alpha'=alpha`。

来源：A round2，INSPECTOR A round2 通过。

## K6 — 可用的是相位梯度，不是相位值

有边界可存活形式为：`p_mu = hbar partial_mu theta` 给四动量；若 `p^2=0`，再由 observer tetrad/screen basis 读出 `alpha=atan2(p·e_2,p·e_1)`。这不支持“相位值本身生成光锥方向”。

来源：A round2 + PI round2。

## K7 — 整体 `U(1)` 相位不改变 null direction

spinor bilinear `k^mu=xi^dagger sigma^mu xi` 在 `xi -> e^{i psi}xi` 下不变。方向由 projective spinor `[xi]` 或相对相位/模比决定；整体相位只能作为纤维、联络或 holonomy 变量进入物理。

来源：B round2，INSPECTOR B round2 通过。

## K8 — “螺旋”若存活，必须变成 optical/contact/twistor 数据

spacetime 固定半径螺旋已经失败。若还保留“螺旋/扭转”，应检验 null congruence 的 twist optical scalar、spin connection curvature、或 contact/twistor holonomy，而不是单条光锥母线。

来源：PI round2。

## K9 — 标准光锥母线族 twist 为零

标准光锥是 null hypersurface，`k_a proportional nabla_a u`，满足 Frobenius 条件，因此 optical twist `omega_ab=0`。把角坐标写成旋转形式只是坐标效应。

来源：A round3，INSPECTOR A round3 通过。

## K10 — twist 属于 congruence，不属于单条 generator

单条平直 null generator 没有内禀 optical twist。非零 twist 必须属于某个非 hypersurface-orthogonal 的 null congruence，依赖邻近 ray 族的横向导数。

来源：A round3。

## K11 — `U(1)` holonomy 不蕴含 optical twist

非零相位联络曲率或 Hopf/Berry 曲率可以给干涉 holonomy，但不自动生成 spacetime null congruence 的 optical twist。二者分属内部相位 bundle 与 spacetime screen distribution。

来源：B round3，INSPECTOR B round3 通过。

## K12 — LP23 最小降级命题

LP23 可保留为：相位 holonomy 可影响干涉、偏振或 screen-frame 运输；null direction/光锥由 null vector、projective spinor、tetrad 或 twistor/contact lift 给出。若要声称统一，必须给出 spin/screen connection 到 null congruence optical data 的量纲正确、协变耦合。

来源：PI round3。

## K13 - R1 强式 `F=chi omega` 当前证伪

`phase curvature / vertical holonomy` 不能无条件等同于 `null congruence optical twist`。障碍包括：对象不在同一 bundle、整体 `U(1)` phase 不改变 `k^a`、常用 convention 下 `F` 与 `omega` 量纲不同、缺少自然 `chi`、缺少唯一 connection source。后续不得继续把 `F_AB=chi omega_AB` 当作主命题推进。

来源：A R1 round1 + B R1 round1 + INSPECTOR A/B + PI R1 round1。

## K14 - R1 弱式只剩分层命题

可保留的 R1 版本是：projective spinor/contact 框架可以同时容纳两套 connection data，一套落在 polarization/phase/Faraday/memory/screen-frame observables，另一套落在 horizontal screen/congruence optical data。二者只有在额外结构存在时才可能耦合，且不能直接称为 optical twist 等同。

来源：PI R1 round1。
