# LP23 研究计划

## 第1轮目标

只打 LP23-S1：平坦时空中“螺旋包络面等价于光锥”是否为严格命题。

## A博士任务

- 给出最小数学定义：螺旋、螺旋族、包络、Minkowski 嵌入、null cone。
- 检查 `x=R cos(ωt), y=R sin(ωt), z=vt` 的线元和 null 条件。
- 判断候选命题是否范畴错误、需要补充尺度、或可修正为严谨定理。

## B博士任务

- 不读 A 产出。
- 从 zitterbewegung、twistor/null spinor、Hopf fibration、contact geometry 中寻找等价先发或强反例。
- 给出一个更可能存活的重表述，如果原始 S1 被击穿。

## 本轮硬停止候选

- 如果 A/B 独立确认“螺旋包络=光锥”只是坐标图像，没有坐标无关定义，则原始 S1 触发数学障碍。
- 即使原始 S1 失败，也不直接收官；按 SOP 进入 Re-escalation/新候选注册的前置准备，但 N<3 时继续探索修正版。

## 第2轮目标

检验 round1 的可存活重表述是否能承接“量子相位演化”而不偷换概念。

### A博士第2轮

- 具体检验 `θ=(Et-p·x)/hbar` 的 Lorentz 标量性质与 null 方向角 `alpha` 的 aberration 变换是否兼容。
- 明确写出一个 boost 下 `alpha -> alpha'` 的公式或 spinor/tetrad 表述。
- 判定是否存在自然映射 `alpha=f(θ,p^mu,e_a^mu)`；如果需要额外结构，列出最小结构。

### B博士第2轮

- 从 twistor/null geodesic congruence/contact lift 路线推进。
- 检验“螺旋”是否可作为 null congruence 在相位/contact 总空间中的 lift，而不是 spacetime 曲线本体。
- 给出一个判据：整体 `U(1)` 相位不改变 null 方向，只有 holonomy/相对相位/spinor bilinear 改变可观测量。

## 第3轮目标

检验“螺旋/扭转”是否能以 null congruence 的 optical twist、contact holonomy 或 twistor 数据形式保留。

### A博士第3轮

- 写出 null congruence optical tensor `B_ab = q_a^c q_b^d nabla_d k_c` 的 expansion/shear/twist 分解。
- 判断平直时空单条 null generator 是否可有非零 twist；若必须是 congruence，说明最小结构。
- 给出 LP23 的“扭转”物理化条件：联络、曲率、congruence，还是纯坐标效应。

### B博士第3轮

- 从 contact/twistor holonomy 路线检验 `U(1)` 相位联络曲率是否能映射到 congruence optical twist。
- 若映射失败，给出最小降级命题：例如“相位 holonomy 是可观测干涉量，但不生成光锥扭转”。
- 保持非 A 路线，避免重复标准 optical scalar 推导。

# LP23-R1 新 Phase 研究计划

## 第1轮目标

只打 R1 的生死关口：是否存在非任意、非手调的 `F_AB=chi omega_AB` 或等价 screen/spin/contact connection 耦合，使 phase holonomy 与 null congruence optical data 发生协变、量纲正确、可观测的联系。

## A博士任务

- 以 Marín-Salvador/Rubio/Hedicke/Low 为先发基线，明确 R1 是否只是 null-geodesic contact structure 的改名。
- 检查 `F_AB=chi omega_AB` 的单位、screen gauge covariance、Lorentz covariance、connection 来源。
- 给出成立/证伪/有边界判定。

## B博士任务

- 从 holonomy/memory/Berry/Faraday/Pancharatnam 方向寻找可能桥接，或构造强反例。
- 不重复 A 的 contact/null-geodesic 标准推导。
- 判断 phase holonomy 是否只能给干涉/偏振/screen-frame observable，而不能给 optical twist。

## 本轮硬停止候选

- 如果 A/B 独立确认 `F_AB=chi omega_AB` 必须手调尺度或被先发完全覆盖，则 R1 强版本触发数学/先发硬障碍。
