# 文献库_R4 | Protocol-Closure Obstruction

## 北极星

LP23-R4：给定 residual 发现流程，构造由因果性、局域性、守恒律、能量/响应约束、测量协议和历史核生成的合法扩张闭包 \(C(P)\)。若 residual 在 \(C(P)\) 的所有有限生成扩张下仍保持非零 quotient class，则存在 protocol-closure obstruction；若存在满足物理生成规则的 template/nuisance/history 列吸收 residual，则声张死亡。

## 先发检索栏

待 A 路 Round1 系统检索。初始高风险关键词：

- `effective field theory operator basis closure redundancy field redefinition`
- `renormalization group closure operator mixing effective theory`
- `system identification identifiability model structure residuals nuisance`
- `causal model closure interventions model expansion`
- `constitutive response causality passivity Kramers Kronig closure`
- `protocol measurement theory nuisance model expansion residual`

初始先发判断（2026-06-03，paper-search-mcp 初筛）：

| 风险轴 | 初筛代表 | 对 R4 的威胁 |

初始判定：R4 的各组成模块先发风险高，但“跨 gauge/template/bridge/nuisance/history 的物理合法扩张闭包 \(C(P)\)，用于判定 residual discovery 是否可被事后补列吸收”尚未在初筛中见到同名或完全同构框架。Round1 必须证明它不是 EFT/operator-closure、系统辨识可辨识性、因果响应闭包和统计自然扩张的拼装换名。

## 反例/证伪栏

1. 若任一成熟框架已经给出“物理允许扩张闭包 \(C(P)\)”且能判定 residual 可吸收/不可吸收，则 R4 降级为换名。
2. 若闭包规则允许把任意 residual 方向作为合法 template/nuisance/history 列加入，则 R4 判死：闭包不限制事后补列。
3. 若闭包规则过窄到排除真实介质响应、边界条件或测量协议，则 R4 会误杀物理，不能作为基础原则。
4. 若 \(C(P)\) 不可计算、不可枚举、不可近似，R4 只能是哲学口号。
5. 若 EFT/RG/operator-basis 或 system-identification 已经能直接定义并枚举 \(C(P)\)，R4 降级为跨领域术语迁移。
