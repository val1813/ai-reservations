# LP23-R3 研究计划

## 北极星

Obstruction Class / Quotient Naturality Principle：

只有对允许的 gauge、template、bridge、nuisance、history 数据全部取商后仍非零的 obstruction class，才有资格成为新物理自由度；依赖截面、模板缺列或桥接选择的 residual 只是模型失配诊断。

## Round1 目标

1. A 路：查重与形式化。判断该原则是否完全被 gauge orbit/moduli/cohomology/naturality 与 nuisance projection 覆盖。
2. B 路：跨域构造一个“北极星筛选器”框架，尝试把原则变成可执行测试，而不是哲学句子。
3. PI 判定：若只能重述成熟框架，R3 立即硬停止；若能形成可操作筛选定理，继续 Round2。

## 判死条件

- 只得到“物理量应 gauge invariant”的重述；
- 只得到“cohomology obstruction class 非零”的重述；
- 只得到“nuisance projection residual”的重述；
- 没有新的可操作筛选算法/定理。
