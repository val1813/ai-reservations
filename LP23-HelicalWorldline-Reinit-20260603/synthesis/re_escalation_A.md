# Re-escalation A 草案

## 新声张草案（≤300字）

LP23 更大声张：光锥、相位、螺旋扭转不是同一物，而是同一 spin/contact 联络的三投影：`[k]` 给 null congruence，`U(1)` holonomy 记相位，screen 投影给光学量。X1-X4 死于把投影当本体；它们可由深层原则推出：fiber holonomy 不直接改变 base null direction，只能经曲率耦合 screen 运输。最小对象 `(M,g,[ξ],A,e_A)`；矛盾：整体相位不改 `k=ξξ†`，曲率可改运输。首算：证 `ξ->e^{iψ}ξ` 下 `k` 不变，再测 `F_AB=χω_AB` 的量纲与协变性。

## 简短验证框架

1. 固定符号：`k_{A dot A}=xi_A bar xi_dotA`，`B_AB=q_A^c q_B^d nabla_d k_c`，`omega_AB=B_[AB]`。
2. 先证 no-go：整体 `U(1)` 相位不改变 projective null direction。
3. 再测可存活耦合：是否存在自然 `chi` 使 `F_AB=chi omega_AB` 量纲一致、Lorentz/screen-gauge 协变。
