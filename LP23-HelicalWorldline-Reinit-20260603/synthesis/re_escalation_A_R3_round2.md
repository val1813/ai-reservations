# Re-escalation A R3 Round2

新声张草案：R3 被杀死后，更大的命题不是“残差代表新自由度”，而是：物理发现的最小对象应从 residual class 上移到“合法扩张合同”的闭合性。若由因果性、局域性、守恒律、测量协议与介质响应生成的扩张语法在有限步骤内闭合，则任何仍不可吸收的残差才是协议不变量；若不闭合，则所有 residual discovery 都只是模型补列自由度的函数。

是否足够注册为北极星：足够。它比 R3a 大，因为判定对象从单个 residual 升为“异常能否在物理允许的模型补全下保持不变量”的基础原则；可注册为 R4：Protocol-Closure Obstruction。
