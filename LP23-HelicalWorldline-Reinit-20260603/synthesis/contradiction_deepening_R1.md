# 矛盾图深化 | LP23-R1

## 核心矛盾

LP23-R1 希望把 causal cone、quantum phase、optical twist 放在同一个 projective spinor/contact 联络语言下。但三轮后发现：

- causal cone/null direction 属于 projective spinor/null geometry；
- optical twist 属于 null congruence 的 horizontal screen derivative；
- quantum/polarization phase holonomy 属于 internal `U(1)/SU(2)` transport；
- contact/null-geodesic structure 已有先发覆盖，且不自动提供 internal-to-twist bridge。

## 五个为什么

1. 为什么 `phase = twist` 失败？  
因为整体 phase 不改变 `k^a`，而 optical twist 由 `k^a` 的横向导数定义。

2. 为什么不能用 screen `SO(2)~U(1)` 救回来？  
因为 screen `U(1)` connection 需要 screen splitting/projector/observer/tetrad 等附加结构；没有这些时 quotient `H_K=K^\perp/K` 不给出全邻域唯一 connection。

3. 为什么有附加结构后仍不算 R1 增量？  
因为这正落入 NP/GHP、spin optics、Robinson/CR、Walker-Penrose、Faraday/Berry/Jones 等既有框架。

4. 为什么 contact/projective 语言也不能自动统一？  
因为 null geodesic/contact 结构定义在 ray/contact/leaf space 层；internal phase holonomy 与 spacetime screen twist 仍需要额外桥接映射，contact structure 本身不提供。

5. 为什么最终只能硬停止？  
因为剩余命题只是“不同 bundle 不可无条件等同”的 separation/no-go synthesis，正确但缺少新增量和可继续推进的北极星级声张。

## 基础原则层结论

LP23-R1 的根本失败点不是某个公式系数，而是对象层级错误：

> vertical/internal gauge holonomy 与 horizontal/congruence optical twist 没有同一来源；若引入桥接结构，桥接结构本身就是额外物理输入，并且已有成熟文献框架承载。

这解释了 S1 和 R1 的共同失败：单一“相位/螺旋/holonomy”对象不能同时承担 spacetime null geometry 与 quantum/polarization phase geometry。
