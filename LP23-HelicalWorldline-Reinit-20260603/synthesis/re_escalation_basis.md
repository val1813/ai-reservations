# Re-escalation 基础材料

## 被杀死的原声张

1. **原声张 X1：固定半径单位螺旋包络面严格等价光锥。**
   - 被杀原因：固定半径螺旋族给圆柱 `X^2+Y^2=ell^2`，光锥要求 `X^2+Y^2=c^2t^2`。单条 null 螺旋也只是曲线，不是 null cone 面。

2. **原声张 X2：量子相位值 `theta` 可直接等同 null 方向角 `alpha`。**
   - 被杀原因：`theta=(Et-p·x)/hbar` 是 Lorentz 标量；`alpha` 是 observer celestial angle，boost 下 obeys aberration。无额外结构的 `alpha=f(theta)` 不协变。

3. **原声张 X3：整体 `U(1)` 相位旋转改变光锥方向或生成光锥扭转。**
   - 被杀原因：spinor bilinear `k^mu=xi^dagger sigma^mu xi` 在整体相位下不变；整体相位是 fiber/holonomy 变量，不是 projective null direction。

4. **原声张 X4：相位联络曲率自然等同 null congruence optical twist。**
   - 被杀原因：非零 `U(1)` holonomy 可与零 optical twist 共存；Hopf/Berry 曲率非零也不推出 spacetime screen distribution twist。

## 当前可存活弱版

相位 holonomy 可影响干涉、偏振或 screen-frame 运输；null direction/光锥由 null vector、projective spinor、observer tetrad 或 twistor/contact lift 给出。若要声称统一，必须给出 spin/screen connection 到 null congruence optical data 的量纲正确、协变耦合。
