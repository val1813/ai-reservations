## 叙事退让 #1 [严重]
位置：`K14 / K20` 与 `project/北极星队列.md` 当前 Phase 命题、`current/plan/研究计划.md` R1 目标
原目标声张：R1 生死关口是“是否存在非任意、非手调的 `F_AB=chi omega_AB` 或等价 screen/spin/contact connection 耦合，使 phase holonomy 与 null congruence optical data 发生协变、量纲正确、可观测的联系”
实际写入：`K14` 将可保留版本降为“projective spinor/contact 框架可同时容纳两套 connection data”；`K20` 将最终结论降为“phase/polarization holonomy 只能作为 screen-frame/polarization observable，不能无条件等同 optical twist；加入附加结构后也只是既有框架特例”
退让方式：把“存在自然耦合/统一结构”的目标，退让为“二者可以分层共存”与“附加结构下的边界性联系”；这些附加条件不是任务书预先给定的成功条件
处理：`K14/K20` 不得作为 R1 收尾成功叙事；应明确记为“强命题证伪后留下的边界材料”，不能据此关闭“是否存在自然耦合”之外的推进价值判断
