# 矛盾深挖

## 表层矛盾

LP23 原始声张试图把三件事同一化：

1. 量子相位 `e^{i theta}`；
2. 相对论光锥/null direction；
3. “螺旋/扭转”的几何图像。

三轮结果显示：这三者不能直接同一化。相位值是 fiber/holonomy，null direction 是 projective/base 对象，twist 是 congruence/screen 横向导数。

## 五个为什么

**为什么固定半径螺旋不是光锥？**

因为固定半径螺旋族给圆柱 `X^2+Y^2=ell^2`，而光锥要求 `X^2+Y^2=c^2t^2`。缺失的是径向尺度 `rho=ct` 和 null direction 的 projective 结构。

**为什么缺失尺度会杀死声张？**

因为 `e^{i theta}` 的 `Re/Im` 是无量纲 fiber 坐标；Minkowski 光锥是有量纲的 base geometry。没有尺度/投影规则，就把 fiber 坐标偷换成 spacetime 坐标。

**为什么 `theta` 不能直接等于 null 方向角 `alpha`？**

因为 `theta=(Et-p·x)/hbar` 是 Lorentz 标量，而 `alpha` 是 observer-dependent celestial coordinate，boost 下 obeys aberration。二者属于不同 Lorentz 表示。

**为什么整体相位 holonomy 不能直接给 optical twist？**

因为整体 `U(1)` 相位在 `k^mu=xi^dagger sigma^mu xi` 中抵消；optical twist 是 null congruence 的 screen antisymmetric derivative。它们分别属于 vertical fiber connection 与 horizontal/base distribution。

**为什么这些失败指向同一个更深原则？**

因为所有失败都来自同一范畴错误：把 fiber variable 当作 base causal geometry，或把 quotient/projective data 当作垂直相位。真正的基础结构必须同时包含：

- base：null direction / congruence / light cone；
- fiber：phase / holonomy；
- connection：把 fiber transport 与 base/screen transport 关联；
- quotient/projective map：从 spinor/contact 总空间到 observable null geometry。

## 基础原理层矛盾

**命题A（fiber/base 分离原则）：** 量子相位是 fiber/holonomy 变量；整体相位不改变 projective null direction，不能直接成为 spacetime 因果结构。

**命题B（统一野心）：** 量子相位与因果结构若有共同来源，必须存在自然 connection，使 fiber holonomy 与 base/screen optical data 发生协变、量纲正确、可观测的耦合。

**不能同时无条件为真之处：** 若没有自然 connection，LP23 只能降级为可视化/解释；若存在自然 connection，LP23-R1 才可能成为真正的新北极星。

## 最深层“不知道”

是否存在一个非任意、非手调的 spin/screen/contact connection，使 phase holonomy 与 null congruence optical data 自然耦合？

这就是 LP23 收尾后的最大可注册问题，不是原始“螺旋=光锥”。
