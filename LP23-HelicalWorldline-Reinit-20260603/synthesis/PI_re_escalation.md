# PI Re-escalation 综合

## A/B 汇合

A 与 B 独立给出同一更大方向：LP23 不应再追“单相位螺旋轨迹=光锥”，而应转向带联络的 projective spinor/contact 主丛。

## 注册新候选

**新候选名称：** LP23-R1 Projective Spinor/Contact 联络统一

**一句话声张：** 因果光锥、量子相位与“螺旋/扭转”的共同来源不是时空中的单相位轨迹，而是带联络的 projective spinor/contact 主丛；null cone 是商-投影，phase holonomy 是垂直曲率，optical data 是水平/screen 分布曲率。

**深层原则：** fiber holonomy 不能直接充当 base null direction；只有自然的 screen/spin/contact connection 耦合才能把相位与因果几何锁成可观测结构。

**最小数学对象：** `(M,g,[xi],A,e_A)`，或等价地 projective spinor/contact 主丛 + Pauli/null bilinear `k^mu=xi^dagger sigma^mu xi` + screen/contact connection。

**驱动矛盾：**

- 命题A：整体 `U(1)` 相位是垂直纤维自由度，不改变 `k=xi xi^dagger`。
- 命题B：相位 holonomy 可观测；若存在自然 screen/spin connection 耦合，它可能调制 screen transport / optical data。
- 矛盾核心：垂直相位 holonomy 与水平 null congruence optical data 分属不同几何层；是否存在自然、协变、量纲正确的联络把二者耦合？

**第一步可验证计算：**

1. 证明 `xi -> e^{i psi}xi` 下 `k^mu` 不变。
2. 在标准光锥 congruence 上计算 Hopf/Berry 曲率 `F_H=(1/2)sin chi dchi wedge dphi` 非零而 optical twist 为零。
3. 检查是否存在自然 `chi` 或 screen/spin connection 使 `F_AB=chi omega_AB` 量纲一致、Lorentz/screen-gauge 协变。
