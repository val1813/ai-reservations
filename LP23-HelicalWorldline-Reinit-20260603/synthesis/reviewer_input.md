1. 固定半径单位螺旋或其相位平移族的自然集合是圆柱 `X^2+Y^2=ell^2`，不是光锥 `X^2+Y^2=c^2t^2`。
2. `e^{iθ}` 的 `Re/Im` 无量纲，不能直接当作 Minkowski 空间坐标；必须额外指定尺度和坐标解释。
3. `θ=(Et-p·x)/hbar` 是 Lorentz 标量；null 方向角 `alpha` 是 observer celestial coordinate，boost 下 obeys aberration。因此 `theta=alpha` 不协变。
4. spinor bilinear `k^mu=xi^dagger sigma^mu xi` 在整体 `U(1)` 相位下不变；整体相位是 fiber/holonomy 变量，不是 null direction。
5. 标准光锥 congruence 是 hypersurface-orthogonal，optical twist 为零。单条 null generator 没有内禀 twist。
6. 非零 `U(1)` holonomy 可与零 optical twist 共存；Hopf/Berry 曲率非零不推出 spacetime screen twist 非零。
7. 可保留版本：相位 holonomy 可影响干涉、偏振或 screen-frame 运输；null direction/光锥由 null vector、projective spinor、observer tetrad 或 twistor/contact lift 给出。
