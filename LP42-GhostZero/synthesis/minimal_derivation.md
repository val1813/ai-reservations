# 幽灵零点: 最小因果推导

> 从第一性原则。不依赖 Morse 理论、辫群、Berry 相。

---

## 前提

**P1 (局域门).** 信道由一系列 2-qubit 门构成。每个门 U_j 只耦合一个系统 qubit q_j 和一个环境 qubit e_j。不同门作用在不同环境 qubit 上。

**P2 (乘积初态).** 环境初始态是乘积态: |Ψ_E⟩ = ⊗_j |γ_j⟩。

**P3 (Cartan 门形式).** U_j = cos(c_j) I ⊗ I + i sin(c_j) σ ⊗ σ，其中两个 σ 是沿**同一轴** n̂_j 的 Pauli 矩阵: σ = n̂_j · σ⃗。

**P4 (最大混合系统).** 系统初始态是最大混合态。

---

## 步骤 1: 因式分解

P1 + P2 → 输出 Gram 矩阵可分解为边的乘积:

```
G_{ab} = ∏_j f_j(a,b)
```

其中 f_j(a,b) = ⟨γ_j| U_j(b)† U_j(a) |γ_j⟩，U_j(x) 是给定系统输入态 |x⟩ 时 U_j 对环境的作用。

**QCMI = 0 ⟺ G 的秩为 1。** 这要求存在 {v_a} 使得对一对 (a₀,b₀)，有 G_{ab} = v_a v_b*。且 G 半正定强制 G_{aa}=1。

---

## 步骤 2: Cartan 代数

在 |±_{n̂_j}⟩ 基 (σ_{n̂_j} 的本征基) 下，U_j 是对角的:

```
U_j(s) = diag(e^{i s c_j}, e^{-i s c_j})
```

其中 s = ±1 是系统 qubit 在 |±_{n̂_j}⟩ 基下的 σ_{n̂_j} 本征值。

设 |γ_j⟩ = √p_j |+⟩ + √(1-p_j) |-⟩，p_j ∈ [0,1]。

```
f_j(s_a, s_b) = p_j e^{i(s_a - s_b)c_j} + (1-p_j) e^{-i(s_a - s_b)c_j}
```

当 s_a = s_b: f_j = 1。当 s_a ≠ s_b: 令 Δ = s_a - s_b = ±2:

```
|f_j|² = 1 - 2p_j(1-p_j)[1 - cos(4c_j)]
```

---

## 步骤 3: |f_j|² = 1 的两条解支

```
2p_j(1-p_j)[1 - cos(4c_j)] = 0
```

**支 A (Clifford):** cos(4c_j) = 1 → c_j ∈ (π/2)ℤ。

**支 B (Ghost):** p_j ∈ {0,1} → |γ_j⟩ 是 σ_{n̂_j} 的本征态。

---

## 步骤 4: 平方丢失 ±

|f_j|² = 1 对 Ghost 支**不区分** p_j=1 和 p_j=0。两者都给出 |f_j|²=1。但 f_j 的**相位**不同:

| 分支 | p_j | f_j (s_a ≠ s_b) |
|------|-----|-----------------|
| |+⟩ 支 | 1 | e^{2i s_a c_j} |
| |-⟩ 支 | 0 | e^{-2i s_a c_j} |

这个 ± 差异来自平方运算消除的方向信息。

---

## 步骤 5: 所有 ± 组合都是合法零点

对任意 S ⊆ {1,...,|E|} (Clifford 边集合) 和任意 {p_j ∈ {0,1} | j∉S} (Ghost 边符号):

```
G_{ab} = ∏_{j∈S} (±1) × ∏_{j∉S} e^{±2i s_a c_j}
```

Clifford 边贡献 ±1 (常数相)。Ghost 边贡献 e^{±2i s_a c_j} = e^{i θ_j s_a}。

**关键:** 所有 Ghost 边对总相位的贡献是相加的: Σ_{j∉S} (±2c_j s_a^{(j)})。这因式分解为 θ_a - θ_b 形式（其中 θ_a 仅依赖于 |a⟩ 和 Ghost 边的 s_a^{(j)} 值）。

→ G_{ab} = e^{i(θ_a - θ_b)}。秩为 1。QCMI=0。

**2^{|E|} 个 Ghost 谷存在——每个边的 p_j 独立取 0 或 1。**

---

## 步骤 6: 维度谱

对每条边:
- Ghost (p_j ∈ {0,1}): c_j 自由 (1 维)，n̂_j = ±r⃗(p) 固定 → 1 个自由参数
- Clifford (c_j ∈ (π/2)ℤ): n̂_j 自由 (S², 2 维)，c_j 固定 → 2 个自由参数
- p 参数: 当 ALL 边为 Clifford 时 p 自由 (1 维)，否则固定 (=0.5)

→ dim(Z_S) = (|E|-|S|)×1 + |S|×2 = |E| + |S| (不含 p)

---

## 步骤 7: 嵌套

当 Ghost 边的 c_j → 0 或 π/2: c_j 进入 (π/2)ℤ → Ghost 边在边界上"变成" Clifford。

→ Z_S ⊂ ∂Z_{S∪{j}} (低维谷在高维谷的边界上)

---

## 这七个步骤就是全部

不需要 Morse 理论。不需要辫群。不需要 Berry 相。

**前提:** P1-P4 (局域门 + 乘积初态 + Cartan 形式 + 最大混合系统)

**推导:** 因式分解 → |f_j|²=1 → 两条支 → 平方丢失 ± → 2^{|E|} 简并 → 维度谱 → 嵌套

**如果前提不成立:**
- P1 不成立 (非局域门) → 无因式分解 → 零点结构根本不同
- P2 不成立 (纠缠初态) → 无因式分解 → p_eff ≠ p → Ghost 支不可能
- P3 不成立 (其他 2-qubit 门) → |f_j|² 公式改变 → 解支结构改变
