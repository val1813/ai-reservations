# 被否定声张的实际情况分析

## 1. c₁(N_{Z_B}) = |E|×2 → 为什么错了？

### 为什么错

Chern 类 c₁ 属于 H²(基空间)。法丛 N_{Z_B} 的纤维 = ⊕_j T_{r⃗(θ)}S²。这个丛**仅沿 S¹_θ 变化**——沿 Cartan 环面 T^{|E|} 方向是平凡的。

H²(S¹) = 0 → 拉回到 Z_B = T^{|E|} × S¹ 仍然为 0 → **c₁ = 0**。

### 实际情况

法丛 N_{Z_B} 是一个**平坦丛** (曲率 F=0)。原因是 ghost 生成元 [X_{s_j}, X_{s_k}] = 0 (Abel)。

平坦丛的 c₁ = 0 ——这不是意外，是必然。但平坦丛**不是平凡的**：它们由 **holonomy 表示** ρ: π₁(基空间) → O(2|E|) 分类。

N_{Z_B} 沿 S¹_θ 的 holonomy: r⃗(θ) 绕 S² 大圆一周 → 切空间旋转 2π → **平凡 holonomy** (identity in SO(2))。

**所以 N_{Z_B} 作为向量丛是平凡的。** 没有非平凡拓扑。

### 那 I(S) = |E|-|S| 是什么？

I(S) 不是法丛的拓扑——它是 **Cartan 环面上的 Berry 相 holonomy**。

每个 ghost 边 j: c_j: 0 → π → 系统 qubit 经历 2π 旋转 → Berry 相 = -π。

这是 **H¹(T^{|E|}; U(1)) 中的类**，不是 H² 中的 Chern 类。Berry 相是 H¹ 不变量——它们活在低一阶的上同调中。

**修正版本:** "I(S) 是 Cartan 环面上的 Berry-Wilson 环 holonomy，取值定理: I(S) = |E|-|S|。法丛本身是拓扑平凡的。"

## 2. "新临界普适类" → 为什么不是？

### 为什么不是

vN 熵 S(ρ) = -Σ λ_i log λ_i。纯态附近: S(1-ε, {ε_i}) = ε - Σ ε_i log ε_i + O(ε²)。

QCMI = S(AB)+S(BC)-S(B)-S(ABC) 是 vN 熵的线性组合 → 纯乘积态最小值附近必定继承 -ε log ε 形式。

**这不是相变——这是 x log x 在 x=0 的非解析性。** 就像 f(x)=x² 在最小值附近总是二次——不是新普适类，是 Taylor 展开的数学必然。

### 实际情况

**被强制的内容:**
- 函数形式: QCMI ~ -A ε log ε + B ε
- 有效指数 α_eff = 2 + 1/ln ε (有限距离效应)
- 各向同性 β_p = γ_θ (两者都是 ε ∝ (距离)²)

**不被强制的内容:**
- **系数 A, B 依赖于图拓扑** (vertex_chain ≠ path by 9.3σ)
- **系数比 B/A 依赖于具体的量子信息量** (QCMI vs 互信息 vs 纠缠熵)
- **拓扑依赖性来自 Gram 矩阵的多体干涉结构**

### 修正版本

不叫"新普适类"。叫"**vN 熵标度定理**":

> "任何 vN 熵基量子信息量在纯乘积态零点附近必定呈 Q ~ -A ε log ε + B ε。函数形式由 vN 熵的数学性质强制。非平凡物理信息编码在系数 (A,B) 中——它们反映 Gram 矩阵的谱响应，依赖于图拓扑和具体信息量。"

**真正的发现:**
1. vertex_chain 的系数 ≠ path 的系数 (9.3σ) → 闭合环增强干涉，改变谱响应
2. Renyi-2 恢复到 α=2 → **确认** vN 的对数修饰是 α≠2 的唯一来源(一致性验证，非发现)
3. 跨 |E| 的数据坍塌 → 标度形式对系统尺寸稳健

## 3. "DPGS = τ_ghost = ∞" → 为什么不完全对？

### 为什么不完全对

退相干由 Lindblad 算符 {L_k} 描述。DFS 条件: L_k|ψ⟩ = c_k|ψ⟩ ∀k, ∀|ψ⟩ ∈ H_protected。

- **T1 (振幅阻尼):** L = √γ |0⟩⟨1|。|0⟩ 是本征态(本征值 0)。|1⟩ **不是**本征态。
- **T2 (纯退相):** L = √γ Z。|0⟩ 和 |1⟩ 都是本征态。

**所以:** DPGS 对纯 T2 完整(两分支都保护)。对 T1 只有 |0⟩ 分支受保护。对 T1+T2 混合: 仅有 |0⟩ 分支。

### 实际情况

DPGS 是**信道依赖的部分保护**——不是全有或全无。

**但这不影响实验结论:** 幽灵零点检测主要用 p=0.5 附近，此时 |γ⟩ = |+⟩_x (σ_x 本征态)。在超导 transmon 上，退相干主要是 T1(振幅阻尼, ẑ 基)。σ_x 本征态在 ẑ 基下是等权重叠加 → 两个分支都参与 → T1 衰减起作用。

**真正重要的实验洞察** (不依赖 DPGS 的夸大版本):
- Δθ² 退化是稳健的: p_eff(Δθ) = cos²(Δθ/2) ≈ 1 - Δθ²/4 → QCMI 上升 ∝ Δθ²
- IBM Q 轴校准精度 0.01-0.06° vs 容差 10-18° → **67-300× 裕度**
- 即使没有完整 DPGS，轴校准的精度需求在现有硬件上**极其宽松**

### 修正版本

"DPGS: 当 Cartan 轴对齐退相干基时，幽灵零点获得**信道依赖的部分保护**。对纯退相(T2): 完整保护。对振幅阻尼(T1): |0⟩ 分支受保护。实验关键不是 τ=∞ 而是 Δθ² 退化 + 巨大校准裕度。"

## 4. Renyi-2 α=2 → 为什么不是 killshot？

### 为什么不是

Renyi-2 熵 S_2(ρ) = -log Tr(ρ²) 在纯态附近**解析**。Taylor 展开: S_2 ≈ 2ε + O(ε²)。最小值处线性项抵消 → 首项二次 → α=2 必然。

α=2.00004 ± 0.00000 不是"精确到小数点后五位的发现"——它只是验证了 Taylor 展开有效。

### 实际情况

这个结果的价值不在"发现 α=2"——而在**确认为什么 α≠2**:

> vN QCMI: α_eff ≈ 1.84 (对数修饰)
> Renyi-2 QCMI: α = 2.000 (纯二次)
> Δα 来自 vN 熵的 -x log x → **这是 α≠2 的唯一来源**

**修正版本:** 从 "Renyi-2 killshot 发现新普适类" 改为 "一致性验证: Renyi-2 的 α=2 确认 vN 的对数修饰是 QCMI 在幽灵零点附近非二次标度的唯一来源。"

## 5. 1/f 噪声改善 → 为什么不可靠？

### 为什么不可靠

效应大小 5-15%，N_idle* ≈ 2-4。在 IBM Q 的系统噪声背景下(CNOT 误差 ~0.6%，读取误差 ~2%)，这个量级的改善可能来自:
- 校准漂移(时间尺度 ~小时)
- qubit 弛豫的时间依赖性
- 拟合模型的选择偏差

没有 blind control experiment → 无法归因于 1/f 谱形。

### 实际情况

机制本身在理论上是合理的: 1/f 噪声的低频功率随积分时间**对数收敛**，而白噪声**线性增长**。对二次响应(ghost 的 Hessian 结构给出二阶噪声耦合)，存在一个最优电路深度。

**问题不是理论——是实验可行性。** 当前的超导硬件噪声太大，无法区分 5-15% 的改善。

### 修正版本

从"发现的机制"降级为"理论预测——需要更低噪声硬件或离子阱平台验证"。这不影响北极星#8 的核心(分离性定理 + DPGS 裕度 + NV 方案)。

## 6. p-边界 μ 跃变 → 实际情况是什么？

### 为什么是 artifact

有限差分 Hessian 在 p=0.001 需要 QCMI(p-ε)。p-ε < 0 → 物理域外 → 数值垃圾。

S¹ 紧致化 p → θ: r⃗(θ) = (sin θ, 0, cos θ) → 无边流形 → μ=0 处处。

### 实际情况

**真实的边界物理不是 μ 跃变——而是正常 Morse 数据的变化:**

- 内部点: 下半链环 L_x = N_x ∩ {QCMI ≤ 0} = ∅ (QCMI ≥ 0, QCMI=0 仅在 Z_B)
- p=0 边界: L_x ≈ interval (包含 p<0 解析延拓方向)
- H_*(L_x): 内部 = 0, 边界 = ℤ (度 0)

**这是真正的 Goresky-MacPherson 边界分层信号——只是不是通过 Morse 指数，而是通过正常 Morse 数据的同调变化。**

### 修正版本

"p-边界处 μ:0→1 跃变被证明是坐标 artifact (S¹ 紧致化修正)。真正的 GM 边界现象是正常 Morse 数据的同调变化: H_*(L_x) 从内部 ∅ 变为边界的 ℤ。这对应 QCMI 在 p 边界处丧失一个切方向(p 被固定)→ Z_B 在 ∂M 上的维数减 1。"
