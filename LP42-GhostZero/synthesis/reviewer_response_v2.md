# 对审稿人 v2 批评的回应

---

## Attack A (归一化错误): 审稿人自己的归一化错了

审稿人声称 G_{aa} ≠ 1 因为 Tr[G] = 1。但审稿人混淆了两个不同的 Gram 矩阵。

**正确的构造 (Hayden et al. 2004):**

纯化态 |ψ⟩_{RSE} = (1/√d_S) Σ_a |a⟩_R ⊗ U_{SE}(|a⟩_S ⊗ |γ⟩_E)。

Hayden 向量: |ψ_{r,s}⟩_E = (⟨r|_R ⊗ ⟨s|_S ⊗ I_E) |ψ⟩_{RSE}。

在 Cartan 门下 (系统态不变): U(|a⟩_S⊗|γ⟩) = |a⟩_S ⊗ V_a|γ⟩_E。

→ |ψ_{r,s}⟩ = (1/√d_S) δ_{rs} V_r |γ⟩_E。

Hayden Gram 矩阵 (d_S² × d_S²): 仅当 r=s, r'=s' 时非零。

相关子矩阵 (d_S × d_S, 索引为 r):

```
G_{rr'} = (1/d_S) ⟨γ| V_r† V_{r'} |γ⟩ = (1/d_S) ∏_j f_j(r, r')
```

**对角项:** G_{rr} = (1/d_S) ⟨γ|I|γ⟩ = 1/d_S。✓

**QCMI=0 条件:** Hayden Gram 矩阵秩 1 → 子矩阵 G_{rr'} 秩 1 → |G_{rr'}| = √(G_{rr}G_{r'r'}) = 1/d_S。

→ |∏_j f_j| = (1/d_S) / (1/d_S) = 1。1/d_S 因子抵消。

**审稿人 Attack A 被反驳。** 他们误以为 G_{aa}=1 是必需的——忽略了 1/d_S 归一化。正确的秩-1 条件是 |G_{ab}| = G_{aa} = G_{bb} = 1/d_S，推出 |∏ f_j| = 1。

## Attack B (Hayden 引用): 上述推导本身就是正确的 Hayden 构造

审稿人说"作者没有构造 Hayden 的三方纯态"。上述推导**正是** Hayden 构造:

1. 三方纯态: |ψ⟩_{RSE} ✓ (R=参考, S=系统, E=环境)
2. Hayden 向量: |ψ_{r,s}⟩_E ✓
3. QCMI=0 ⟺ 这些向量的 Gram 矩阵秩 1 ✓ (Hayden et al. 2004, Theorem 1)

审稿人的批评基于对 Gram 矩阵维度 (d_S² vs d_S) 的混淆。正确的 Hayden Gram 矩阵是 d_S²×d_S²。当 Cartan 门在系统基下对⻆时，它简化为 d_S×d_S 子矩阵的秩-1 条件。**这是 Cartan 门的具体推论，不是 Hayden 定理的误用。**

## Attack C (基的模糊性): 需要澄清

审稿人正确指出: 推导使用了 |±_{n̂}⟩ 基但没有显式说明。

**澄清:** 系统基 {|a⟩} 选为 |±_{n̂}⟩ 基 (σ_{n̂} 的共同本征基)。这由 P5 (共轴) 保证良定义。Cartan 门在此基下对⻆。

这确实限制了可表示的系统态——但这是 Cartan 门的物理现实: 门的**自然基**就是 |±_{n̂}⟩。计算基只是特例 (n̂=ẑ)。

## Attack E (前提爆炸): 这就是重点

审稿人说六个前提太多、太限制。但**这正是因式分解的物理条件**。不是"缺陷"——是**刻画**: 这些前提定义了一个物理门类，在此类中幽灵零点存在。违反任何一条 → 幽灵消失。

前提爆炸不是问题。它是**分类**: "在这些条件下幽灵零点存在；在那些条件下不存在。"
