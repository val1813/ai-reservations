# 幽灵零点: 最小因果推导 v2

> 审稿后修正版。新增显式前提: P5(共轴), P6(对易), P7(环境参数化)。标注每个平方丢失的信息。

---

## 前提

**P1 (局域门).** 信道由 2-qubit 门序列构成。每个门 U_j 耦合一个系统 qubit q_j 和一个环境 qubit e_j。不同门作用在**不同的环境 qubit** 上。

**P2 (乘积初态).** |Ψ_E⟩ = ⊗_j |γ_j⟩。

**P3 (Cartan-Ising 门形式).** U_j = cos(c_j) I⊗I + i sin(c_j) σ_{n̂_j} ⊗ σ_{n̂_j}。这是完整 SU(4) Cartan 分解 (c_x,c_y,c_z) 中 c_x=c_y=0 的单参数子族。**这是故意限制——我们分析的是这个特定门族，不是所有 2-qubit 门。**

**P4 (最大混合系统).** 系统以最大混合态输入。用于 Gram 矩阵定义: G_{ab} = Tr_E[⟨a|U(ρ_S⊗|Ψ⟩⟨Ψ|)U†|b⟩]，其中 ρ_S = I/d_S。当 G 秩为 1 时，信道输出与系统输入不相关 → QCMI=0 (这是强次可加性的已知推论，见 Hayden et al. 2004)。

**P5 (共轴).** 所有 Cartan 门共享同一轴 n̂_j = n̂ (或 ±n̂)。→ [σ_{n̂_j}, σ_{n̂_k}] = 0。→ 所有 U_j 对易。→ 门次序无关。

**P6 (环境 Bloch 参数化).** |γ_j⟩ 由 Bloch 球上的概率 p_j = |⟨+_{n̂}|γ_j⟩|² 参数化。相对相位 φ_j 在 Cartan-Ising 门下抵消 (见步骤 2)。p 是环境制备参数——p=0.5 对应 |+⟩_x 态。环境 Bloch 向量: r⃗(p) = (2√(p(1-p)), 0, 2p-1)。Ghost 条件 p_j∈{0,1} 等价于 n̂_j = ±r⃗(p) (见步骤 6)。

---

## 步骤 1: 因式分解

P1 + P2 + P4 → 对任意系统基 {|a⟩}:

```
G_{ab} = ∏_j f_j(a,b)
```

其中 f_j(a,b) = ⟨γ_j| U_j(b)† U_j(a) |γ_j⟩，U_j(x) 是从 ⟨x|_S U_j |x⟩_S 得到的有效环境算符。

**已知事实:** QCMI = 0 ⟺ G 秩为 1 (强次可加饱和 ⟺ Gram 矩阵秩崩塌，Hayden et al. 2004 SS4)。

---

## 步骤 2: 对角化

P3 + P5 → 在 |±_{n̂}⟩ 基 (σ_{n̂} 的共同本征基) 下:

```
U_j(s) = diag(e^{i s c_j}, e^{-i s c_j})
```

其中 s = ±1 是系统 qubit q_j 的 σ_{n̂} 本征值。P5 保证所有 U_j 在此基下同时对⻆化。

|γ_j⟩ = √p_j |+⟩ + √(1-p_j) |−⟩。相对相位 φ_j 省略——P3 的 Ising 形式保证 φ_j 在 f_j 中抵消 (仅 c_y≠0 的门才会引入 φ_j 依赖)。

```
f_j(s_a, s_b) = p_j e^{iΔc_j} + (1-p_j) e^{-iΔc_j}
```

其中 Δ = s_a - s_b。s_a = s_b → f_j = 1。s_a ≠ s_b → Δ = ±2 →:

```
|f_j|² = 1 - 2p_j(1-p_j)[1 - cos(4c_j)]
```

**此步使用的假设:** P3 (Ising 形式, c_y=0 → φ_j 抵消), P5 (共轴 → 共同本征基), P1 (不同环境 qubit → 乘积结构)。

---

## 步骤 3: 必要条件 (补充审稿意见 #4)

**断言:** QCMI=0 → |G_{ab}| = 1 对所有 a,b。

**证明:** G 秩为 1 → G_{ab} = v_a v_b*。G_{aa} = f_j(a,a)=1 对所有 a → |v_a|² = 1。→ |G_{ab}| = |v_a||v_b| = 1。

又 |G_{ab}| = ∏_j |f_j(a,b)|，且每个 |f_j| ≤ 1 (内积的 Cauchy-Schwarz 界)。

→ 每个 |f_j(a,b)| = 1 对所有 a≠b。

**因此:** |f_j|² = 1 是 QCMI=0 的**必要条件**。→

```
2p_j(1-p_j)[1 - cos(4c_j)] = 0
```

**两条解支:**

| 支 | 条件 | 物理含义 |
|----|------|---------|
| A (Clifford) | cos(4c_j)=1 → c_j∈(π/2)ℤ | 门变成 ±I⊗I — 代数消除 s 依赖性 |
| B (Ghost) | p_j∈{0,1} | 环境是本征态 — 本征态消除 s 依赖性的可观测后果 |

---

## 步骤 4: 平方丢失 ± 方向

|f_j|² 不区分 p_j=1 和 p_j=0。**这是推导中唯一一次信息丢失——来自平方运算。**

但 f_j 本身保留 ±:

| p_j | f_j (s_a≠s_b) | 方向 |
|-----|---------------|------|
| 1 | e^{2i s_a c_j} | + |
| 0 | e^{-2i s_a c_j} | − |

**平方丢失的是 p_j=1 ↔ p_j=0 的区分。** 这个丢失创建了简并: 两个不同的环境制备给出相同的 |f_j|²。

---

## 步骤 5: 2^{|E|} 个合法零点

**断言:** 对任意 S ⊆ {1,...,|E|} 和任意 {p_j ∈ {0,1} | j∉S}，Gram 矩阵秩为 1。

**证明:**

Clifford 边 (j∈S): f_j = ±1 (常数相，仅依赖 c_j mod π，不依赖 s_a,s_b)。

Ghost 边 (j∉S): f_j = e^{±2i s_a c_j} = e^{iθ_j s_a} (其中 θ_j = ±2c_j)。

```
G_{ab} = ∏_{j∈S} (±1) × ∏_{j∉S} e^{iθ_j(s_a - s_b)/?}
```

修复: Ghost 边贡献的相位是添性的: ∏_j e^{iθ_j s_a} = e^{i(Σ_j θ_j) s_a}。

对于多 qubit 系统 (P5 下每条边作用于不同系统 qubit): s_a 是一个向量 (s_a^{(1)}, ..., s_a^{(|E|)})。每条 Ghost 边 j 贡献 e^{iθ_j s_a^{(j)}}。Clifford 边贡献常数。

G_{ab} = (Π_{j∈S} ε_j) × Π_{j∉S} e^{iθ_j(s_a^{(j)} - s_b^{(j)})}

这有形式 e^{i(Θ_a - Θ_b)} 其中 Θ_a = Σ_{j∉S} θ_j s_a^{(j)} → 秩为 1。✓

**2^{|E|} 个零点。** 每个边独立选择 p_j ∈ {0,1}。

**退化的修正 (审稿意见 #7):** 当 Ghost 边的 c_j ∈ (π/2)ℤ 时，e^{2is_a c_j} = e^{-2is_a c_j} (= ±1)，p_j=1 和 p_j=0 给出相同的 f_j。此时 2^{|E|} 计数过度——两个"谷"合并。这是步骤 7 的嵌套: 谷在退化点相遇。

---

## 步骤 6: 维度谱

**Ghost 边 (p_j ∈ {0,1}):**
- n̂_j 固定: 由 P6，p_j = |⟨+_{n̂}|γ_j⟩|² = 1 → n̂_j = ±r⃗(p)。或 p_j = 0 → n̂_j = ∓r⃗(p)。在两种情况下，n̂_j 由 p 完全决定——不再自由。
- c_j 自由 → 1 个自由实参数。

**Clifford 边 (c_j ∈ (π/2)ℤ):**
- c_j 固定 → 0 个自由参数。
- n̂_j 自由在 S² 上 → 2 个自由实参数。

**p 参数:** 当 |S|=0 (纯 Ghost): p_j ∈ {0,1} 对所有 j。由 P6，n̂_j = ±r⃗(p) → p 可自由变化 (p∈(0,1))，因为 r⃗(p) 随 p 连续变化。→ 1 个额外自由参数。

当 |S|>0: Clifford 边的 n̂_j 不跟踪 r⃗(p) → p 被 Ghost 边的约束 n̂_j=±r⃗(p) 和 Clifford 边的 n̂_j 任意性之间的不一致固定。→ p 固定。

**→ dim(Z_S) = (|E|-|S|) + 2|S| + δ_{|S|,|E|} = |E| + |S| + δ_{|S|,|E|}**

(δ 项: p 仅在 ALL 边为 Clifford 时自由。)

---

## 步骤 7: 嵌套

Ghost 边的 c_j → 0 或 π/2: 进入 (π/2)ℤ → Ghost 支"变成" Clifford 支。低维谷在高维谷的边界上。

→ Z_S ⊂ ∂Z_{S∪{j}}

---

## 总结: 因和果

```
因                      果
────────────────────────────────────────
P1+P2+P4 (局域+乘积+混合) → Gram 因式分解
P3+P5 (Cartan-Ising+共轴) → 对⻆化 → |f_j|² 公式
|f_j|²=1 的必要性        → 两条解支
平方丢失 ± 方向          → 2^{|E|} 简并谷 (Ghost 支)
自由参数计数             → 维度谱 |E|+|S|
Ghost c_j→0,π/2 进入 Clifford → 嵌套 Z_S⊂∂Z_{S∪{j}}
```

**P1-P6 成立时的必然推论。不是"新物理"——是这些前提的代数必然。**

---

## 前提失效的后果

| 前提被违反 | 后果 |
|-----------|------|
| P1 (非局域门) | 无因式分解 → 零点结构根本不同 |
| P2 (纠缠初态) | G_{ab} ≠ ∏ f_j → Ghost 支消失 (已验证: Bell 态 → min QCMI=1.01 bits) |
| P3 (一般 SU(4) 门) | |f_j|² 公式改变 → 解支结构改变。需重新推导 |
| P5 (非共轴) | 无共同本征基 → s_a 不是良定义标签。因式分解仍存在但 f_j 形式改变 |
| P6 (环境非纯态) | p_j 不是单参数 → Ghost 支更复杂 |
