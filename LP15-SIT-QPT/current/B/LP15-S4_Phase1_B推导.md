# LP15-S4 Phase 1 B博士: 重整化群视角——一阶QPT中的有限尺寸标度

## §0 框架声明

**推导框架：** 重整化群(RG) + 有限尺寸标度(FSS)理论
**独立于A的方式：** A使用Landau理论的热展宽分析；B使用RG流图+危险无关变量(DIV)的FSS框架。两框架在极限下等价（Landau平均场↔RG树级），但B从RG本征值扰动出发，给出标度假定的普适类分类。
**框架局限：** RG分析在平均场层次（上临界维数以上），未包含ε展开的非经典涨落。

## §1 RG流图中的一阶相变

### 1.1 固定点的稳定性交换

在双序参量的RG流图中，存在三个固定点：
- **Gaussian FP:** Δ=q=0, 所有耦合无关→三临界行为
- **SC FP:** Δ≠0, q=0, Δ为相关方向→二阶SC相变
- **CPG FP:** q≠0, Δ=0, q为相关方向→二阶CPG相变

当biquadratic耦合γ>0时，RG流方程为（一阶ε展开）：
```
dγ/dl = (4-d-z)γ - 4(β+λ)γ + O(γ²)                            (1)
```

在d=2, z=1（量子相变有效维数D=d+z=3）:
```
dγ/dl = γ - 4(β+λ)γ = γ(1-4(β+λ))                               (2)
```

当β+λ > 1/4时，γ在红外不相关→流向γ=0→SC和CPG固定点解耦→两个独立的二阶相变。
当β+λ < 1/4时，γ在红外相关→流向大值→SC和CPG固定点交换稳定性→一阶相变。

### 1.2 固定点稳定性交换⟺一阶

RG框架中，一阶相变的特征是：两个固定点之间不存在红外稳定的分离线（separatrix）。系统从SC固定点流向CPG固定点（或反之），中间无可停留的临界点。

**定理B4.1（RG一阶判据）：**
γ在红外相关(dγ/dl>0)且β+λ<1/4⟺SC和CPG固定点交换稳定性⟺一阶QPT。

这个条件等价于A博士的r>1条件，但不依赖Landau自由能的显式形式——它是RG流拓扑的性质。

## §2 危险无关变量与有限尺寸标度

### 2.1 一阶QPT的FSS

在标准二阶QPT中，FSS由相关变量（relevant scaling variable）控制：
```
ξ/L = const → |x-x_c| ∝ L^{-1/ν}   [二阶]                        (3)
```

在一阶QPT中，关联长度ξ保持有限→不存在发散的关联长度来控制FSS。但这不意味着FSS完全不存在——系统中的**危险无关变量(DIV)**在一阶QPT中扮演关键角色。

DIV是那些在临界固定点处无关（流向0）但在有限系统中因为与系统尺寸的非平凡标度关系而产生可观测效应的变量。

在一阶QPT中，温度T本身是DIV：在T=0的QPT中T无关，但在有限T下，T以T∝L^{-z}的方式标度（z=1）。

### 2.2 一阶QPT的有效FSS形式

对于有限尺寸L和有限温度T的2D量子系统：
```
R(T, L, x) = f(L/ξ, T·L^z, (x-x_c)·L^{1/ν_eff})                 (4)
```

一阶QPT中：ξ<∞（固定），ν_eff由DIV决定（非普适）。

在热力学极限L→∞且T>0时：
```
R(T, x) = f(∞, T, (x-x_c)·∞) ≈ g((x-x_c)/T)                     (5)
```

最后一步使用了z=1和ξ有限的性质。这给出与A博士相同的zν_eff=1标度。

**但RG视角的关键差异：** zν_eff=1是DIV（温度）的标度维度在一阶QPT中的表现，**不是**关联长度的临界指数。区分两者的方式是检验FSS的L依赖性——二阶QPT中ξ随L变化，一阶QPT中ξ不随L变化。

## §3 实验判别：有限尺寸标度中的ξ

### 3.1 可检验预测

如果制备不同尺寸L的a-InO样品（例如通过改变薄膜面积），在一阶QPT中：
```
T_c(L) ≈ T_c(∞) · [1 - c/L]     [一阶: ξ有限, 边界效应]        (6)
```

在二阶QPT中：
```
T_c(L) ≈ T_c(∞) · [1 - c/L^{1/ν}]   [二阶: ξ~L at criticality] (7)
```

如果ν>1（二阶dirty boson的可能值），则二阶预测的有限尺寸修正(~1/L^{1/ν})比一阶(~1/L)弱。测量不同尺寸样品的T_c→提取有限尺寸修正指数→判断一阶vs二阶。

### 3.2 从现有数据提取约束

Charpentier的样品尺寸未系统变化，但不同样品的微小尺寸差异(~10-20%)可用于初步约束：
如果一阶（~1/L修正）：T_c变化~10-20%
如果二阶ν=0.67（~1/L^{1.5}修正）：T_c变化~5-10%
如果二阶ν=1（~1/L修正）：与一阶不可区分

现有数据精度不足以区分，但给出了明确的实验方向。

## §4 苏格拉底清单

### Q1: RG分析中的upper critical dimension是多少？
双序参量biquadratic耦合的upper critical dimension是d_c=4（每个序参量的d_c=4，耦合项γ|Δ|²q²的标度维度[γ]=4-d）。在d=2的量子相变中有效D=3<4→涨落修正重要→平均场可能定性正确但定量需ε=4-D=1展开。

### Q2: 危险无关变量在一阶QPT中是否总是温度？
不是。在无序系统中，disorder本身可以是DIV——在一阶QPT中disorder的Harris判据需要重新评估。如果disorder是DIV，则有限disorder下的标度行为可能与纯系统不同。

### Q3: 为什么B博士的RG判据和A博士的Landau判据数学上同构？
因为Landau理论是RG在树级（零圈）的固定点分析。γ在树级的RG流dγ/dl=(4-D)γ-4(β+λ)γ与Landau Hessian的det(H)=βλ-γ²通过线性化联系。这是预期内的，不是巧合。

## §5 结论

**独立确认A博士的核心结论：** 一阶QPT中不存在真正的量子临界标度，但存在DIV产生的表观标度（zν_eff=1），与二阶zν≈1不可区分。有限尺寸标度中ξ的L依赖性是可检验的判别性特征。

**B博士的独立贡献：**
1. RG流图视角——固定点稳定性交换作为一阶的拓扑判据
2. 危险无关变量在一阶FSS中的作用——zν_eff=1的RG起源
3. 有限尺寸标度中的ξ-L关系作为可检验的判别性预测
