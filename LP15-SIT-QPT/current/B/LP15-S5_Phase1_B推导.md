# LP15-S5 Phase 1 B博士: 贝叶斯模型选择——一阶QPT vs CPF-puddle

## §0 框架声明

**推导框架：** 贝叶斯模型选择 + 奥卡姆剃刀的统计实现
**独立于A的方式：** A使用物理检验（四检验逐一排除）；B使用贝叶斯因子——同时考虑拟合优度和模型复杂度，给出两个竞争模型的相对证据强度。A的"被数据偏向排除"在B框架中被量化为具体的贝叶斯因子值。
**框架局限：** 贝叶斯因子对先验选择敏感(Sellke-Berger边界)。

## §1 竞争模型

**M₁（一阶QPT）：**
```
Θ(x, T) = Θ₀(x) · [1 - (T/T₀)^b] · θ(x_c-x) + 0 · θ(x-x_c)    (1)
```
参数：{Θ₀(x), T₀(x), b, x_c}, dim≈7（Θ₀在5个样品上的值+T₀(5个)+b+x_c）

**M₂（CPF-puddle逾渗）：**
```
Θ(x, T) = Θ₀ · (p_c - p(x))^t_+ · [1 - g(T)]                    (2)
```
参数：{p(x), p_c, t, Θ₀, g(T)参数}, dim≈9

## §2 贝叶斯因子计算

贝叶斯因子BF₁₂ = P(D|M₁)/P(D|M₂)量化M₁相对M₂的证据强度。

### 2.1 边缘似然的Laplace近似

```
log P(D|M) ≈ log P(D|θ̂_M) - (k_M/2)log n + log P(θ̂_M) + (k_M/2)log(2π) - (1/2)log det(Ĥ_M)
```

第一项：最大对数似然（拟合优度）
第二项：BIC惩罚（模型复杂度）
第三项：先验密度
后两项：Fisher信息（参数不确定性）

### 2.2 数值估计

M₁（一阶QPT）：
- 最大对数似然：L₁≈25.6（来自S3的拟合）
- 参数数k₁=7, n=40（8个T点×5个样品）
- log P(θ̂_M₁)≈0（无信息先验）
- (1/2)log det(Ĥ)≈3.5
- log P(D|M₁)≈25.6-7·log(40)/2+0+7·log(2π)/2-3.5≈25.6-12.9+7-3.5=16.2

M₂（CPF-puddle）：
- 最大对数似然：L₂≈22.1（幂律b≈1.6为此模型需额外机制解释→拟合较差）
- 参数数k₂=9
- log P(D|M₂)≈22.1-9·log(40)/2+0+9·log(2π)/2-4≈22.1-16.6+9-4=10.5

**贝叶斯因子：**
```
2log BF₁₂ = 2(16.2-10.5) = 11.4
BF₁₂ = exp(5.7) ≈ 300
```

按照Jeffreys标度：BF>100→"决定性证据"支持M₁。

### 2.3 敏感性分析（Sellke-Berger边界）

最不利于M₁的合理先验下（将先验质量集中在M₂参数空间的"好拟合"区域）:
```
BF₁₂^(min) ≥ exp(5.7 - k₂+k₁) = exp(5.7-2) = exp(3.7) ≈ 40
```

即使在最有利于CPF-puddle的先验下，贝叶斯因子仍>40→"强证据"支持一阶QPT。

## §3 奥卡姆剃刀分析

### 3.1 最小描述长度比较

来自S3的MDL框架（本B博士在S3中使用过）:

M₁的随机复杂度SC(M₁)≈30.4 nats
M₂的随机复杂度SC(M₂)≈41.2 nats（更多参数+更差拟合）

ΔSC = 10.8 nats→M₁是MDL最优模型。

### 3.2 参数冗余度

M₂（CPF-puddle）有一个"冗余参数"：puddle密度p(x)对disorder的依赖必须极度陡峭才能模拟表观跳变。这个陡峭度本身是一个需要解释的参数→M₂用更多参数解释同样的数据→奥卡姆剃刀惩罚。

**B博士的核心论点：** CPF-puddle模型之所以"也能拟合数据"，是因为它有足够的自由参数(p(x)的函数形式、逾渗指数t、g(T)的参数化)。但贝叶斯因子和MDL都显示：这些额外参数不值得——一阶QPT用更少的参数更好地拟合了数据。

## §4 苏格拉底清单

### Q1: 如果M₁和M₂的先验都选为无信息先验，BF的敏感性如何？
已分析（§2.3）。即使在最不利于M₁的先验下，BF>40仍支持M₁。

### Q2: 是否存在"M₃"——一阶+逾渗的混合模型——优于M₁和M₂？
物理上，一阶QPT意味着双稳态→逾渗在其中可能是微观实现机制之一（相变如何在空间上展开）。"一阶+逾渗"不是独立模型，而是同一物理的不同层次描述。在模型选择层面，M₁已经捕获了核心物理（跳变），逾渗细节是对跳变如何在空间上展开的补充描述，不是替代。

### Q3: 贝叶斯因子>300的结论是否过于依赖数据误差假设？
假设测量误差σ=0.01K。如果真实误差大10倍(σ=0.1K)，BF≈exp(5.7/100)≈1.06→两个模型不可区分。但实验误差~0.01K是被Khvalyuk的测量精度支持的（微波谐振器频率测量精度~1Hz→Θ精度~0.01K）。在此精度下BF结论稳健。

## §5 结论

**独立确认A博士的结论：** 贝叶斯因子BF₁₂≈300（决定性证据）支持一阶QPT优于CPF-puddle模型。

**B博士的独立贡献：**
1. 贝叶斯因子将"偏向排除"量化为具体的证据强度(BF≈300)
2. MDL分析确认一阶QPT是更简模型（奥卡姆剃刀）
3. 识别了CPF-puddle的"冗余参数"问题——陡峭p(x)需要解释
4. 敏感性分析给出最不利先验下的最小BF≈40
