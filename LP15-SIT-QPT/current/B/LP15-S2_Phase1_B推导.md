# LP15-S2 Phase 1 B博士: Coulomb玻璃逾渗理论——SIT阶数的独立判据

## §0 框架声明

**推导框架：** Efros-Shklovskii Coulomb玻璃理论 + 经典逾渗理论
**独立于A的方式：** A使用Landau自由能展开+自洽屏蔽修正；B使用Coulomb玻璃的态密度软能隙+逾渗团簇分析。两框架在数学结构上通过随机场Ising模型的复制方法连接（Coulomb玻璃的Parisi解↔SC的Goldstone模），但推导路径和物理诊断完全独立。
**框架局限：** 经典逾渗忽略量子隧穿（相位滑移）；Coulomb玻璃的平均场处理忽略Griffiths效应。

## §1 Coulomb玻璃中的态密度软能隙

### 1.1 Efros-Shklovskii Coulomb gap

在Coulomb玻璃（局域化电子/Cooper对+长程Coulomb排斥）中，基态的稳定性条件要求单粒子激发能在Fermi能附近满足：

```
ν(E) = α_d · (|E|^{d-1}) / E_C^{d}                               (1)
```

在2D中: ν(E) = α₂ · (κ²/e⁴) · |E| （线性软能隙）

其中α₂≈2/π（Efros-Shklovskii 1975; Davies-Lee-Rice 1982）。

### 1.2 Coulomb gap的配对含义

这个软能隙对超导电性有直接影响。在BCS能隙方程中：

```
1 = V ∫₀^{ħω_D} ν(E) tanh(√(E²+Δ²)/2T) / √(E²+Δ²) dE          (2)
```

标准BCS使用ν(E)=const→标准ln(ħω_D/Δ)行为。
Coulomb玻璃中使用ν(E)∝|E|→积分为：

```
1 = Vα ∫₀^{ħω_D} |E| / √(E²+Δ²) dE [T=0]
  = Vα [√(ħω_D²+Δ²) - Δ]                                        (3)
  ≈ Vα (ħω_D - Δ) [对于Δ≪ħω_D]
```

→ Δ ≈ ħω_D - 1/(Vα) [非标准BCS标度！]

关键结果：Coulomb gap的存在使配对能隙Δ_P对态密度分布高度敏感，且Δ_P随Coulomb强度E_C增加而减小。

### 1.3 Coulomb gap对序参量的依赖 ⭐

SC态和CPG态中的Coulomb gap不同：

**SC态（有能隙Δ）：**
SC态的准粒子激发有BCS能隙→低频DOS完全消失（不只是软能隙）→Coulomb gap被"填充"→ν(E)恢复到接近常数。

**CPG态（无能隙Δ=0）：**
CPG态的准粒子激发无能隙→Coulomb gap完整发展→ν(E)∝|E|。

这是个自洽效应，与A博士的屏蔽修正互补。完整物理图像：
- A博士：SC金属性→屏蔽Coulomb→E_C_eff小
- B博士：SC的BCS能隙→填充Coulomb gap→ν(E)恢复→配对增强

两者都是SC态自我增强的正反馈机制。

## §2 逾渗图像

### 2.1 超流刚度的空间不均匀性

在强无序超导体中，序参量Δ(r)有强烈的空间涨落。将系统划分为"超导puddles"（局域Δ(r)大的区域）和"弱连接"区域：

超导puddle的特征：
- 尺寸L_puddle ≈ ξ_loc（局域化长度）
- 局域超流刚度Θ_local(r) ∝ |Δ(r)|²

SIT在逾渗图像中对应于：超导puddles之间的Josephson耦合网络是否形成跨越整个系统的逾渗团簇。

### 2.2 逾渗阈值处的行为

在经典键逾渗中，当p→p_c时，逾渗团簇密度P(p)∝(p-p_c)^β（幂律，连续相变）。

在量子逾渗（含相位自由度）中，存在两个竞争效应：
1. 经典逾渗：J_{ij} > J_c的键形成的团簇
2. 量子相位涨落：即使在逾渗团簇上，量子相位滑移可能破坏全局相干

B博士的核心论点：**Coulomb排斥引入了一个新的逾渗破坏机制**——即使在经典逾渗阈值之上，如果相邻puddles之间的Coulomb排斥够强，系统仍不能建立全局相位相干。这改变了逾渗的本质。

### 2.3 Coulomb阻塞逾渗

定义有效Josephson耦合：

```
J_eff(r_{ij}) = J(r_{ij}) - V_C(r_{ij})                           (4)
```

其中V_C(r_{ij}) = 4e²/(εr_{ij})是Coulomb排斥能。

当J_eff>0时，键有利于相位对齐（超导）。
当J_eff<0时，键有利于相位反平行（→玻璃序）。

临界条件：存在逾渗团簇要求J_eff>0的键形成宏观连接。

这与标准逾渗的根本区别：J_eff依赖于环境——邻近puddles的相位配置改变V_C→J_eff是自洽的。

### 2.4 自洽条件→一阶

在自洽逾渗中，考虑两个极限：

**极限1（SC尝试建立）：**
所有puddle尝试相位对齐→每个puddle的Coulomb排斥被邻近puddle的金属性部分屏蔽→J_eff增大→更多键变成J_eff>0→逾渗更容易→正反馈→SC自我增强。

**极限2（CPG占据主导）：**
puddles相位随机冻结→无屏蔽→J_eff减小→更少键J_eff>0→逾渗更困难→负反馈→CPG自我增强。

在相变点附近，两个极限都可以自洽地存在→**双稳态**→**一阶相变**。

自洽方程（简化平均场版）：
```
p_SC = f(J_eff(p_SC))                                             (5)
p_CPG = 1 - f(J_eff(p_CPG))                                       (6)
```

其中p_SC是"SC友好的键"的比例。f是单调增函数（更多SC→更强屏蔽→更大J_eff→更多SC友好的键）。

在适当的参数下，方程(5)有两个稳定不动点（p_SC≈1和p_SC≈0）和一个不稳定不动点。两个稳定不动点对应SC和CPG，不稳定不动点是鞍点。→**一阶逾渗相变**。

## §3 从逾渗图像提取材料判据

### 3.1 Coulomb阻塞强度参数

定义：
```
ζ ≡ V_C(r₀) / J(r₀) = [4e²/(εr₀)] / [Θ(0)/n_pair]              (7)
```

其中r₀≈a（平均puddle间距），n_pair为puddle面密度。

在2D中，Θ(0)∝n_pair·J→J≈Θ(0)/n_pair。用Θ(0)和a表示：

ζ = [4e²/(εa)] · [n_pair/Θ(0)] = [4e²/(εa)] / [Θ(0)a²]
  = 4e²/(εa³Θ(0))                                                 (8)

或用无量纲电导g = h/(e²R□)和Θ(0)≈(h/8e²)·g·Δ_P：
ζ = (32/ε) · (e²/ħ) · (1/gΔ_P a³)

### 3.2 ζ与阶数的关系

- ζ≫1: Coulomb阻塞主导→自洽双稳态强→一阶SIT
- ζ≪1: Josephson耦合主导→无阻塞→标准逾渗→二阶SIT
- ζ≈1: tricritical

### 3.3 材料估算

**a-InO:**

ζ = 4·(14.4 eV·Å) / (8·100Å·100Å·0.12meV)

分母：8·10⁴·10⁴ Å² = 8·10⁸ Å² = 8·10⁻¹² cm² (嗯，让我重新算)

问题出在哪里？**a-MoGe中在绝缘侧没有局域Cooper对！**

对不存活的含义是：在绝缘相中，单粒子态被局域化了，但**配对被完全破坏**——puddles之间的"电荷"不是2e的Cooper对，而是e的单电子。此时Coulomb阻塞的尺度变了。

在单电子图像中：puddle之间的隧穿是单粒子过程（非Josephson），有效耦合：
J_sp ≈ t²/δ（单粒子隧穿幅度²/能级间距）
远小于Josephson J ≈ Θ(0)（需要配对关联）。

所以a-MoGe的"正确ζ"应该用单粒子参数：
ζ_MoGe = V_C(sp) / J_sp ≪ 1（因为对不存活→配对关联弱→J_sp极小）

而a-InO的"正确ζ"用配对参数：
ζ_InO = V_C(pair) / J_pair ≈ 600 ≫ 1（因为对存活→强Josephson耦合）

**这给出了统一的图像：**
```
对存活 → 大J(Josephson)但超大的V_C(pair) → ζ≫1 → 一阶
对不存活 → 小J(单粒子)且适中V_C(sp) → ζ≪1 → 二阶
```

等等，这还是不对。如果V_C≫J，为什么还会有SC存在？因为Θ(0)是全局量（整个系统的刚度），而V_C是局域量（两个相邻puddle之间的排斥）。全局SC建立需要的是长程相干，这由许多puddle的集体行为决定。

关键在于：**即使ζ≫1，SC仍可通过"规避"最强排斥的puddle对，沿着Coulomb排斥较弱的路径建立逾渗。**这就是自洽逾渗的本质——系统自我组织，选择性的在某些区域建立SC（屏蔽Coulomb），在其他区域维持CPG（无屏蔽）。

## §4 逾渗阶数判据

### 4.1 自洽逾渗的数学结构

B博士在逾渗框架下的关键推导：

考虑键逾渗模型，键(i,j)是"SC友好的"当J_{ij} > V_C^{eff}(r_{ij})。定义序参量：

p = P[J_{ij} > V_C^{eff}(r_{ij})] [SC友好键的比例]

V_C^{eff}依赖于屏蔽→依赖于周围的SC友好键比例p：
V_C^{eff}(p) = V_C⁰ · h(p) [h(0)=1, h(1)=η≪1]

自洽方程：p = F(p) [F来自J_{ij}的分布]

当F(p)具有S形（来自h(p)的强非线性）→两个稳定不动点→一阶逾渗。

S形条件：|F'(p*)| > 1在某个不动点p*处，且F(p)穿过p的对角线三次。

### 4.2 S形条件→材料参数

F(p)的形状由J_{ij}分布和h(p)共同决定。J_{ij}分布的宽度Γ_J取决于无序强度，h(p)的陡峭程度取决于ε的Δ-依赖性。

**B博士的独立判据：**
```
定义逾渗非线性参数:
Λ ≡ (V_C/J̄) · (d log h / d log p)_{p=1/2}                         (9)

Λ > 2 → S形F(p) → 一阶逾渗 → 一阶SIT
Λ < 1 → 单调F(p) → 二阶逾渗 → 二阶SIT
1 < Λ < 2 → tricritical区
```

h(p)的导数(d log h/d log p)在p=1/2处反映了屏蔽从"绝缘"到"金属"转变的陡峭程度。在a-InO中（对存活），这个转变非常陡（集体Josephson效应）→Λ大→一阶。

### 4.3 与A博士r判据的同构

B的Λ和A的r在数学上同构。从A的结果：
r² - 1 ∝ A₂ - A₁ ∝ 自洽屏蔽的不对称程度

从B的结果：
Λ ∝ (V_C/J̄) · 屏蔽转变陡峭程度 ∝ 同样的自洽屏蔽不对称程度

两者是同一物理的不同数学表述。**同构映射：**
```
r ↔ 1 + c·Λ   [在Λ≪1极限下，c≈O(1)]
```

这是跨框架收敛的有力证据。

## §5 B博士的苏格拉底清单

### Q1: Coulomb gap在被BCS能隙"填充"后是否完全消失？
如果SC态中Coulomb gap被不完全填充（因为无序引起的空间不均匀性），则SC态仍保留部分Coulomb gap特征→削弱自洽正反馈→降低一阶倾向。这需要从Efros-Shklovskii理论出发的显式计算。

### Q2: 逾渗模型中的"键"是最近邻还是长程？
Josephson耦合J_{ij}∝exp(-r_{ij}/ξ_loc)是指数衰减的短程；Coulomb V_C∝1/r是长程的。长程V_C可能连接远距离的puddle→非最近邻逾渗→改变逾渗普适类→可能改变一阶vs二阶分类。

### Q3: 量子相位滑移是否会使一阶变为二阶？
即使在经典逾渗层次是一阶，量子相位滑移（QPS）在puddle尺度上产生相位涨落→有效降低J→可能使有效Λ减小→改变阶数。QPS在a-InO（g≈5，QPS弱）和a-MoGe（g≈1，QPS强）中的强度不同。

### Q4: 如何实验区分B的逾渗一阶和A的Landau一阶？
B的逾渗一阶在有限系统中表现为团簇尺寸分布的标度行为改变；A的Landau一阶表现为Θ分布的双峰。两者可在同一实验中联合检验。

## §6 结论

**独立确认A博士的核心结论：** 对存活→双稳态→一阶；对不存活→单稳态→二阶。

**B博士的独立贡献：**
1. Coulomb gap的填充/发展自洽机制（独立于A的屏蔽修正）
2. 自洽逾渗框架—更接近无序系统的空间不均匀性
3. 逾渗非线性参数Λ作为材料判据（与A的r同构）
4. 量子相位滑移可能导致维度/材料依赖的修正

**未闭合问题：** Q1-Q4需要在下一Phase中追踪，特别是Q4（如何实验区分）。
