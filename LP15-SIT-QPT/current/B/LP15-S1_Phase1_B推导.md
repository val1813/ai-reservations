# LP15-S1 Phase 1 B博士: 大偏差理论框架——SIT阶数的率函数判据

## §0 框架声明

**推导框架：** 大偏差理论（Large Deviation Theory, LDT），Gärtner-Ellis定理 + Freidlin-Wentzell随机动力系统
**独立于A框架的方式：** A使用Landau平均场（势函数的凸性分析），B使用大偏差率函数（随机变量分布的尾部渐进行为）。两者在数学结构上通过Legendre变换连接（Gärtner-Ellis ↔ Landau有效势），但推导路径和物理诠释独立。
**框架局限：** 大偏差框架需要定义"宏观变量"——在这里是空间平均的超流刚度。有限系统中率函数的经验估计受有限尺寸效应影响。

## §1 大偏差设定

### 1.1 将SIT映射为大偏差问题

考虑无序超导体在固定disorder强度x下的T=0基态。定义：

```
Θ_L(x) ≡ (1/L²) Σ_{r∈Λ_L} Θ_r(x)
```

其中Θ_r(x)是局域超流刚度（~ Josephson耦合J_r(x)），Λ_L是L×L格点。

在热力学极限L→∞：
- SC相: Θ_L → Θ_∞(x) > 0（几乎必然）
- CPG绝缘体: Θ_L → 0（几乎必然）

大偏差原理（LDP）描述的是有限L下Θ_L偏离其热力学极限的概率：

```
P(Θ_L ≈ θ) ≍ exp[-L² I_x(θ)]     (L → ∞)
```

其中I_x(θ)是率函数(rate function)，描述在disorder强度x下观测到超流刚度θ的大偏差代价。

≍ 表示对数等价：lim_{L→∞} -(1/L²) log P(Θ_L ≈ θ) = I_x(θ)。

### 1.2 率函数的物理来源

Θ_L(x)的分布来自无序构型的涨落。对于给定的无序实现{ε_i}（在位能），基态超流刚度Θ[{ε_i}]由量子多体基态决定。无序分布P({ε_i})在大偏差框架下诱导出Θ的分布。

关键假设（A1）：Θ_L满足大偏差原理。这在物理上是期望的——Θ是空间平均量，LDP是此类量的普适性质。

## §2 率函数的双谷结构与一阶相变

### 2.1 核心定理（大偏差版）

**定理 B1（率函数-相变阶数对应）：** 考虑无序调制的量子多体系统，其基态序参量Θ在热力学极限下的分布由率函数I_x(θ)描述。相变在disorder强度x_c处发生。那么：

- 如果I_{x_c}(θ)有唯一的全局最小值在θ=0或θ>0某处 → 二阶相变（或交叉）
- 如果I_{x_c}(θ)有两个深度相等的全局最小值，分别在θ=θ_SC>0和θ=0 → 一阶相变
- 两个最小值的深度差是化学势差（"驱动力"），相等条件定义了Maxwell点

**证明概要：** 在热力学极限L→∞下，exp[-L² I(θ)]的鞍点近似给出主导贡献来自argmin I(θ)。当I_x(θ)在x_c处有两个等深最小值时，宏观态在两者之间跳变——这正是"一阶"的含义。跳变幅度Δθ = θ_SC - 0 = θ_SC。

### 2.2 与Landau框架的连接

A博士的Landau自由能F(ρ,q)和B博士的率函数I_x(θ)通过约束最小化连接：

```
I_x(θ) = min_{q} F_x(ρ=√θ, q) - min_{ρ,q} F_x(ρ, q)
```

即：率函数是固定Θ=θ下约束最小化的超额自由能。A的Hessian分析等价于B的率函数曲率分析。

**但B独立推导的价值：** B可以直接从Θ的分布（实验上可从不同样品的Θ值直方图估计）判断相变阶数，无需先验知道Landau参数。

## §3 从率函数曲率导出一阶条件

### 3.1 率函数在极小值附近的行为

在极小值θ*附近展开：
```
I_x(θ) = I_x(θ*) + (1/2) I_x''(θ*) (θ-θ*)² + O((θ-θ*)³)
```

曲率I_x''(θ*)反映了该极小值的"刚度"——即系统在该相中的涨落幅度。

在相变点x_c，两个极小值竞争：
- θ_SC > 0: SC极小值，率函数值I_SC = I_{x_c}(θ_SC)
- θ_CPG = 0: CPG极小值，率函数值I_CPG = I_{x_c}(0)

一阶条件：I_SC = I_CPG（等深度）+ 两者之间存在势垒（即I_x在中间θ处高于两个极小值）

### 3.2 势垒存在条件 ↔ γ > √(βλ)

从A博士的Landau参数出发（仅用于建立连接，B的推导在率函数空间独立成立），在共存解处的率函数值：

```
I_x(θ_coex) - I_x(0) = F_coex - F_CPG
```

在等自由能线（Maxwell线）上，F_SC = F_CPG。共存解处的超额自由能为：

```
ΔF_coex = F_coex - F_SC = [推导见下]
```

当共存解是鞍点(det(H) < 0)时，沿某个方向自由能下降 → 势垒存在（两个极小值被鞍点分隔）。

当共存解是最小值(det(H) > 0)时 → 单一最小值 → 势垒不存在 → 二阶相变。

Hessian条件det(H) < 0 ↔ γ > √(βλ) 在A推导中给出（Eq. 4）。B框架的等价表述：

**定理 B2（率函数曲率判据）：**
```
在相变点x_c，计算:
  χ_SC ≡ I_{x_c}''(θ_SC)    [SC极小值的曲率]
  χ_CPG ≡ I_{x_c}''(0)      [CPG极小值的曲率]

定义"鞍点指数":
  σ ≡ sign[min_{θ∈(0,θ_SC)} I_{x_c}(θ) - I_{x_c}(0)]

σ = +1 → 无势垒（中间态比两端更稳定）→ 二阶
σ = -1 → 有势垒（两端比中间更稳定）→ 一阶
```

**定理 B3（B博士的独立判据——不依赖Landau参数）：**
```
一阶相变的充要条件（在大偏差框架中）:
  ∃ δ > 0 使得 ∀θ ∈ (δ, θ_SC-δ): I_{x_c}(θ) > I_{x_c}(0) = I_{x_c}(θ_SC)

即: 在两个全局最小值之间存在一段θ区间，其中率函数严格高于全局最小值。
```

这可以直接从实验数据中检验：对于临界disorder附近的样品，测量Θ的分布。如果分布是双峰的（在θ≈0和θ≈θ_SC>0处各有一个峰），则是一阶。如果是单峰的（在某个中间θ处），则是二阶。

### 3.3 有限尺寸标度

在有限L下，双峰分布的谷部深度为：
```
ΔI_L ≈ L² · min_{θ∈(0,θ_SC)} [I_{x_c}(θ) - I_{x_c}(0)]
```

在实验可达的L（~μm尺度），ΔI_L必须足够大（>~3-5 k_BT）才能在分布中看到清晰的双峰。这给出了实验上可区分一阶vs二阶的最小系统尺寸。

## §4 B博士的苏格拉底追问清单

### Q1: 率函数是否必然存在？
**问题：** 大偏差原理要求宏观变量满足一定的正则条件。对于无序量子系统，Θ的分布是否存在重尾（导致LDP失效）？在强无序极限下，Griffiths稀有区域可能导致分布的幂律尾部→LDP需要修正（速率函数变为L-dependent）。

### Q2: 双峰分布的谷部——有多少统计证据？
**问题：** Charpentier实验在临界disorder附近有多少个样品？能否从已发表的Θ分布数据中直接提取双峰（或单峰）特征？如果样品数<10，双峰vs单峰的统计区分是不确定的。

### Q3: 分布的双峰性是否一定是"真正一阶"？
**问题：** 逾渗型相变（如CPF-puddle模型，Maniv-Zhuravlev 2025）也可以在有限系统中产生表观双峰分布（来自逾渗团簇的有限尺寸效应）。如何干净地区分"真正一阶QPT的双峰"和"逾渗有限尺寸效应产生的双峰"？

**B的回答：** 真正一阶的双峰在L→∞时峰间距保持不变（Δθ不→0），而逾渗双峰的峰间距随L增大而缩小（Δθ~L^{-β/ν}）。这是可检验的预测。

### Q4: 大偏差框架能否独立验证r>1？
**问题：** 从率函数的实验估计中，能否提取等效的Landau参数ratio r=γ/√(βλ)？如果能，如何在不假设Landau模型的前提下做到这一点？

**B的建议：** 率函数在极小值附近的曲率比值：
```
r²_eff = 1 + [lim_{θ→0+} I''(θ) / I''(θ_SC) - 1] · [与模型无关的因子]
```
这提供了一种从Θ分布数据中提取等效r的方法，可作为与Landau拟合的独立交叉检验。

### Q5（最深追问）: 如果率函数在x_c处有三个极小值怎么办？
**问题：** A博士的Landau模型只考虑了Δ和q两个序参量。如果有第三个（隐藏的）序参量（例如：非均匀的超导puddles的空间关联长度ξ_puddle），三序参量竞争可能产生三谷率函数→更丰富的相变行为。排除三谷可能性需要什么证据？

## §5 结论

**独立确认A博士的核心结论：**
γ > √(βλ)作为一阶条件的物理解释在大偏差框架中得到独立支持——它等价于率函数在相变点存在两个被势垒分隔的等深全局最小值。

**B博士的独立贡献：**
1. 提供了不依赖Landau参数化的相变阶数诊断工具：直接从Θ分布的峰结构判断。这比A的方法更接近实验。
2. 识别了有限尺寸效应和逾渗双峰之间的关键区分判据：峰间距的L标度。
3. 提出了从Θ分布数据中模型独立地提取等效r的方法。

- Q1-Q5需要在Phase 2中至少部分回答
- 最重要的是Q1（LDP有效性）和Q3（逾渗vs真一阶的区分）
