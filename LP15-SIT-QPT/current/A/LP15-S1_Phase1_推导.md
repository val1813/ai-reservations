# LP15-S1 Phase 1: 双序参量Landau理论——一阶vs二阶SIT的完整判据

## §0 框架声明

**推导框架：** 标准Landau相变理论（平均场层次），双序参量biquadratic耦合
**不依赖的假设：** 无特定微观模型假设，仅在平均场层次推导相边界条件
**框架局限：** 平均场忽略涨落效应（在T=0的量子相变中涨落可能重要）；未考虑无序导致的Griffiths/McCoy-Wu效应
**差异化声明：** Poboiko & Feigel'man (2024)建立了双序参量框架但未系统推导γ>√(βλ)作为一阶的充要条件，也未给出完整相图在(α,κ,γ)参数空间中的分类。本推导填补此空白。

## §1 模型设定

### 1.1 序参量

在无序超导体中，存在两个竞争的序：
- **Δ**: 超导序参量（复标量），|Δ|² = 超流刚度的序参量平方
- **q**: Cooper对玻璃(CPG)序参量（实标量），q = Edwards-Anderson序参量，q = lim_{t→∞} ⟨S_i(0)S_i(t)⟩，描述局域Cooper对的自旋玻璃冻结

两者在物理上竞争：超导需要Cooper对的相位相干→需要"软"相位模式；CPG是Cooper对的局域冻结→需要"硬"相位模式。

### 1.2 Landau自由能

在T=0（量子相变），自由能泛函：

```
F(Δ, q) = α|Δ|² + (β/2)|Δ|⁴ + κq² + (λ/2)q⁴ - γ|Δ|²q²        (1)
```

参数物理意义：
- α(x) = a₀(x - x_SC): SC质量项，x为无序强度（例如R□），x_SC为SC失稳点
- β > 0: SC自耦合（保证稳定性）
- κ(x) = c₀(x_CPG - x): CPG质量项，x_CPG为CPG稳定点
- λ > 0: CPG自耦合（保证稳定性）
- γ > 0: SC-CPG竞争耦合强度（>0表示此消彼长）

在低无序端(x→0): α<0 (SC稳定), κ>0 (CPG不稳定) → 纯SC相
在高无序端(x→∞): α>0 (SC不稳定), κ<0 (CPG稳定) → 纯CPG相

### 1.3 无量纲化

定义无量纲参数：
```
r ≡ γ/√(βλ)    — 约化耦合强度（关键控制参数）
ā ≡ α/|α₀|     — 约化SC质量
k̄ ≡ κ/|κ₀|     — 约化CPG质量
```

其中α₀和κ₀为特征能标。相图拓扑由r唯一决定。

## §2 稳定性分析

### 2.1 稳态方程

∂F/∂Δ* = Δ(α + β|Δ|² - γq²) = 0
∂F/∂q = 2q(κ + λq² - γ|Δ|²) = 0

### 2.2 四类稳态解

| 解 | (|Δ|², q²) | 自由能 | 存在条件 |
|----|-----------|--------|---------|
| N (正常) | (0, 0) | 0 | 始终存在 |
| SC | (-α/β, 0) | -α²/(2β) | α < 0 |
| CPG | (0, -κ/λ) | -κ²/(2λ) | κ < 0 |
| Coex | (ρ²_co, q²_co) | 见下文 | 见下文 |

### 2.3 共存解

从稳态方程联立求解（§2.1），当γ² ≠ βλ时：

```
ρ²_co ≡ |Δ|²_co = (γκ + αλ)/(γ² - βλ)          (2)
q²_co = (γα + βκ)/(γ² - βλ)                     (3)
```

物理性要求ρ²_co > 0且q²_co > 0。

### 2.4 Hessian稳定性分析

在(ρ, q)空间（ρ=|Δ|），Hessian矩阵：

```
H = [[∂²F/∂ρ², ∂²F/∂ρ∂q],
     [∂²F/∂ρ∂q, ∂²F/∂q²]]
```

其中：
```
∂²F/∂ρ² = 2α + 6βρ² - 2γq²
∂²F/∂q² = 2κ + 6λq² - 2γρ²
∂²F/∂ρ∂q = -4γρq
```

Δ的相位是Goldstone模（在SC态中无质量），不影响稳定性判据。

### 2.5 纯相稳定性条件

**SC相（ρ²=-α/β, q=0）的局部稳定性：**

```
∂²F/∂ρ² = 2α + 6β(-α/β) = -4α > 0        (α<0时自动满足) ✓
∂²F/∂q² = 2κ - 2γ(-α/β) = 2(κ + γα/β)
∂²F/∂ρ∂q = 0

det(H_SC) = (-4α)·2(κ+γα/β)
```

SC局部稳定 ⟺ κ + γα/β > 0

即: **κ > γ|α|/β** (用|α| = -α, α<0) ... (SC-stability)

**CPG相（ρ=0, q²=-κ/λ）的局部稳定性：**

```
∂²F/∂ρ² = 2α - 2γ(-κ/λ) = 2(α + γκ/λ)
∂²F/∂q² = 2κ + 6λ(-κ/λ) = -4κ > 0        (κ<0时自动满足) ✓
∂²F/∂ρ∂q = 0

det(H_CPG) = 2(α+γκ/λ)·(-4κ)
```

CPG局部稳定 ⟺ α + γκ/λ > 0

即: **α > γ|κ|/λ** (用|κ| = -κ, κ<0) ... (CPG-stability)

### 2.6 共存解的Hessian行列式 ⭐核心

在共存点，利用稳态条件α+βρ²-γq²=0和κ+λq²-γρ²=0：

```
∂²F/∂ρ² = 2α + 6βρ² - 2γq² = 2(γq²-βρ²) + 6βρ² - 2γq² = 4βρ²  > 0
∂²F/∂q² = 2κ + 6λq² - 2γρ² = 2(γρ²-λq²) + 6λq² - 2γρ² = 4λq²  > 0
∂²F/∂ρ∂q = -4γρq

det(H_coex) = (4βρ²)(4λq²) - (4γρq)² = 16ρ²q²(βλ - γ²)         (4)
```

**关键结果：**
```
det(H_coex) > 0  ⟺  γ < √(βλ)    → 共存解是极小值（稳定）
det(H_coex) < 0  ⟺  γ > √(βλ)    → 共存解是鞍点（不稳定）
det(H_coex) = 0  ⟺  γ = √(βλ)    → tricritical点
```

## §3 相图分类

### 3.1 弱竞争区: r ≡ γ/√(βλ) < 1 (二阶相变)

当r < 1时，共存解是稳定的最小值。相变序列（随x增加）为：

```
纯SC → SC+CPG共存 → 纯CPG
```

两个相变都是二阶的：
- SC→共存：ρ连续→0（在α_eff=0处）
- 共存→CPG：q连续→0（在κ_eff=0处）

共存相中两个序参量共存——物理上对应"超导的Cooper对玻璃"（局部对存在且部分相位相干）。

### 3.2 强竞争区: r > 1 (一阶相变) ⭐

当r > 1时，共存解是鞍点。纯SC和纯CPG被自由能势垒分隔。

**Maxwell等自由能线：**
```
F_SC = F_CPG  →  -α²/(2β) = -κ²/(2λ)  →  |α|/√β = |κ|/√λ
```

在Maxwell线上：
```
SC稳定条件: κ > γ|α|/β → 用|κ| = |α|√(λ/β):
|α|√(λ/β) > γ|α|/β → √(λ/β) > γ/β → γ < √(βλ)  → r < 1  ❌矛盾!

即：在r > 1时，Maxwell线上两个稳定性条件不同时成立！
```

**实际上**：在r > 1时，Maxwell线的位置满足|α|/√β = |κ|/√λ。在此线上：
```
SC-stability: κ + γα/β > 0 → |κ| > γ|α|/β → 1 > γ/√(βλ) = r
CPG-stability: α + γκ/λ > 0 → |α| > γ|κ|/λ → 1 > γ/√(βλ) = r
```
两者都要求r < 1——矛盾！所以在r > 1时，Maxwell线上的点**既不在SC稳定域也不在CPG稳定域**。

这意味着：在r > 1时，相变发生在稳定性边界（spinodal线）上，而非等自由能线——这是一阶相变的特征。

**Spinodal线：**
- SC spinodal: κ + γα/β = 0 → κ = γ|α|/β
- CPG spinodal: α + γκ/λ = 0 → |α| = γ|κ|/λ

两spinodal之间的区域：SC和CPG**都**局部稳定 → 双稳区（滞后区）。

一阶相变发生在两条spinodal之间的等自由能线上（Maxwell线）。

**在T=0的量子极限：** 量子隧穿通过势垒→一阶QPT在Maxwell线上发生，无滞后。但势垒的存在使关联长度ξ保持有限。

### 3.3 完整相图

在(α, κ)参数空间中（固定r > 1）：

```
                  κ
                  ↑
    SC稳定域      |  双稳区       CPG稳定域
  (全局SC)       | (两相共存)   (全局CPG)
                  |
  α<0, κ>0       |  α<0, κ<0    α>0, κ<0
       SC稳定     |  SC+CPG      CPG稳定
                  |  均稳定
                  |
  ────────────────┼──────→ α = 0
       |          |         |
       |  SC      | Maxwell |  CPG
       |  spinodal|  line   |  spinodal
       |          |         |
  κ=γ|α|/β       |         α = γ|κ|/λ
```

**Tricritical点: r = 1, (α, κ) = (0, 0)**

### 3.4 序参量跳变的大小

在一阶相变处(Maxwell线)，序参量跳变：
```
Δρ² = ρ²_SC(Maxwell) - 0 = |α|/β
Δq² = q²_CPG(Maxwell) - 0 = |κ|/λ = |α|√(β/λ)·(1/λ) = |α|/√(βλ)
```

用实验可观测量表示：
- 超流刚度Θ ∝ ρ² = |Δ|² → Θ跳变 ΔΘ ∝ |α|/β
- 在临界点处: ΔΘ/Θ_SC = 1 (因为CPG侧Θ=0)

与Charpentier实验一致：Θ从有限值跳变到零。

## §4 结论与下一Phase

### 4.1 核心定理 ⭐✅

**定理1（一阶条件）：** 在双序参量biquadratic耦合Landau理论中，SIT是一阶的充要条件是γ > √(βλ)，即约化耦合强度r > 1。

**定理2（二阶条件）：** 当r < 1时，SIT通过一个稳定的共存相连续发生（两个二阶相变）。

**定理3（Tricritical点）：** r = 1定义了tricritical点，在此一阶线和二阶线交汇。

**定理4（双稳区宽度）：** r > 1时，双稳（滞后）区宽度在参数空间中为Δα = α_spinodal_CPG - α_spinodal_SC = (r²-1)·(γκ/λ - α) [在固定κ处]。

### 4.2 物理解释

γ > √(βλ)的物理含义：
- γ: biquadratic竞争强度 — SC试图建立相位相干，CPG试图冻结相位，两者冲突
- √(βλ): 各相的"刚度"几何平均 — 抵抗外扰的能力
- 当竞争(γ)超过刚度(√(βλ))时，系统无法通过中间态妥协 → 直接跳变

### 4.3 Phase 2 预览

Phase 2需回答的核心问题：在a-InO的实际微观参数下，r = γ/√(βλ)是大于1还是小于1？

从Poboiko & Feigel'man (2024)的微观模型：
- β ~ 1/(ν₀Δ₀²)（BCS刚度的倒数）
- λ ~ 1/(ν₀E_C²)（Coulomb玻璃刚度的倒数）
- γ ~ 1/(ν₀Δ₀E_C)（交叉项）

→ r² = γ²/(βλ) ~ [1/(ν₀²Δ₀²E_C²)] / [1/(ν₀²Δ₀²E_C²)] = 1

微观估算在领头阶给出r=1（恰在tricritical点）——这意味着次领头阶修正（无序分布的具体形式、准粒子修正、费米子符号等）决定了一阶vs二阶。这是Phase 2的关键问题。

### 4.4 已知局限
1. 平均场层次 — 涨落修正（~1/N或ε展开）未包含
2. 未考虑无序的空间不均匀性 — Griffiths/McCoy-Wu效应
3. 未与Poboiko-Feigel'man的Parisi replica计算严格对接
4. biquadratic耦合形式 -γ|Δ|²q²是允许的最低阶竞争项，高阶项在强耦合时可能修正相边界
