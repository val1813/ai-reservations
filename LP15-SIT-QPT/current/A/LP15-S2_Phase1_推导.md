# LP15-S2 Phase 1: 微观参数→Landau系数的映射

## §0 框架声明

**目标：** 从无序超导体的微观参数（ν₀, Δ₀, E_C, g, ε, ξ_loc）出发，计算Landau系数β, λ, γ，确定r≡γ/√(βλ)的材料依赖性，解释为何a-InO显示一阶SIT而a-MoGe显示二阶SIT。

**推导框架：** 量子转子模型 + Coulomb玻璃理论 + 自洽屏蔽修正
**已知依赖：** LP15-S1的结论 — r>1⟺一阶，r<1⟺二阶，r=1⟺tricritical
**关键物理：** 超导相的金属性屏蔽vs CPG相的绝缘性非屏蔽→自洽不对称性→有效r>1

## §1 微观模型

### 1.1 无序超导体中的Cooper对

在强无序区(k_Fl~1-3)，单粒子本征态是Anderson局域化的，但时间反演对称性保证了两两简并态的存在→Cooper配对仍在局域化基底上发生。

关键能标：
- **Δ_P**: 赝能隙(pseudogap)，即局域Cooper对的结合能。在a-InO中Δ_P≈5-10K，远大于Tc≈1-3K
- **Θ(0)**: T=0超流刚度，∝ Josephson耦合J×配对数密度
- **E_C**: 邻近局域对之间的Coulomb排斥能，E_C=4e²/(εr₀)
- **δ**: 局域化体积内的平均能级间距，δ=1/(ν₀ξ_loc²) (2D)

### 1.2 量子转子哈密顿量

将每个局域化体积视为一个"site"，载有Cooper对。有效哈密顿量：

```
H = - Σ_{⟨ij⟩} J_{ij} cos(φ_i - φ_j) + (1/2) Σ_{i≠j} V_{ij} n_i n_j    (1)
```

其中：
- J_{ij}: 位点i和j之间的Josephson耦合
- V_{ij} = 4e²/(ε_{ij} r_{ij}): Coulomb相互作用
- n_i = -i∂/∂φ_i: 位点i上的Cooper对数算符
- φ_i: 超导相位

**与Fisher(1990) dirty boson模型的关键区别：**
Fisher模型只有现场充电能E_C^{(on-site)}，而这里的V_{ij}是长程Coulomb（1/r衰减）。长程相互作用诱导玻璃态——这是CPG的起源。

### 1.3 序参量定义

**SC序参量（空间平均）：**
Δ = (1/N) Σ_i ⟨e^{iφ_i}⟩                                       (2)

**CPG序参量（Edwards-Anderson）：**
q_EA = (1/N) Σ_i lim_{t→∞} ⟨cos[φ_i(t) - φ_i(0)]⟩           (3)

物理含义：
- Δ≠0: 全局相位相干→超导
- q_EA≠0且Δ=0: 相位被冻结在局域随机值上→Cooper对玻璃（绝缘体）
- Δ≠0且q_EA≠0: 部分冻结+部分相干→共存相（仅在r<1时稳定）

## §2 Landau系数的微观推导

### 2.1 SC通道：β的微观表达式

在位点表象中，SC自由能来自Josephson耦合的解耦：

```
F_SC = -Jz|Δ|² + (β₀/2)|Δ|⁴ + O(|Δ|⁶)                         (4)
```

其中z为配位数，J为平均Josephson耦合。

J的微观估计：在脏极限下(k_Fl~1)，两个局域化体积之间的Josephson耦合为：

```
J ≈ (ħ/e²) · σ_n · Δ_P · A_eff                                  (5)
```

其中σ_n为正常态电导率，A_eff为有效耦合面积。

超流刚度Θ(0)∝J。更精确地，在2D脏超导体中：

```
Θ(0) = (ħ/8e²) · g · Δ_P                                        (6)
```

其中g = h/(e²R□)为无量纲电导。

β的微观表达式（从Ginzburg-Landau展开）：

```
β = [∂⁴F/∂|Δ|⁴]_{|Δ|=0} / 4! ≈ c_β · (1/ν₀Δ_P²)              (7)
```

其中c_β≈O(1)，具体值依赖无序分布。在Gaussian近似下：
β ≈ 1/(2ν₀Δ_P²) （标准BCS脏极限结果）

### 2.2 CPG通道：λ的微观表达式

CPG自由能来自Coulomb相互作用的玻璃化。标准Coulomb玻璃理论（Efros-Shklovskii, 1975; Davies-Lee-Rice, 1982）给出：

```
F_CPG = -[ν₀E_C²/2]·q² + (λ₀/2)·q⁴ + O(q⁶)                    (8)
```

关键点：CPG的"质量"项∝E_C²——Coulomb排斥越强，玻璃态的驱动力越大。

λ的微观估计：
λ ≈ 1/(2ν₀E_C²)                                                 (9)

来自Coulomb玻璃的平均场理论（Poboiko-Feigel'man Parisi框架重现此结果）。

### 2.3 交叉耦合：γ的微观表达式 ⭐

交叉项γ来自以下物理：SC相位相干（Δ≠0）要求相位"软"（可自由变化），而CPG要求相位"硬"（被冻结）。两者天然对抗。

微观来源：在位点i上，如果cos(φ_i-φ_j)有非零期望值（SC的贡献），则cos[φ_i(t)-φ_i(0)]的长期极限被压制。

在路径积分表象中，交叉项来自SC场（Δ）和CPG场（q）的非线性耦合。在Gaussian近似（Poboiko-Feigel'man）：

```
γ₀ = 1/(2ν₀Δ_P E_C)                                            (10)
```

**领头阶的困境（§1.4重访）：**
```
r₀² = γ₀²/(βλ) = [1/(4ν₀²Δ_P²E_C²)] / [1/(2ν₀Δ_P²) · 1/(2ν₀E_C²)] = 1
```
→ 领头阶给出r=1（恰在tricritical点）！

**这意味着决定一阶vs二阶的物理在次领头阶。** 这是一个重要的insight：不是存在/不存在竞争，而是竞争的精细强度决定阶数。

## §3 次领头阶修正 — 自洽屏蔽效应 ⭐核心

### 3.1 物理图像

超导态是金属（有耗散的相位模→可屏蔽Coulomb），CPG态是绝缘体（无耗散→不可屏蔽）。因此有效Coulomb相互作用依赖于系统处于哪个相：

```
E_C_eff(Δ) = E_C₀ · f(|Δ|²)                                    (11)
```

其中f(0)=1（绝缘极限，无屏蔽），f(∞)=η≪1（金属极限，强屏蔽）。

具体形式（从Thomas-Fermi屏蔽理论）：
```
f(|Δ|²) = 1/(1 + κ_TF²(|Δ|²)·a²)                               (12)
```

其中Thomas-Fermi波矢κ_TF² ∝ ν_eff(|Δ|)，而有效态密度ν_eff在SC态中受能隙抑制但在低能端因集体模式而恢复。

### 3.2 自洽方程

系统的真实自由能必须自洽地确定屏蔽：

```
F(Δ,q) = α|Δ|² + (β/2)|Δ|⁴ + κq² + (λ/2)q⁴ - γ₀|Δ|²q² 
         + δF_scr(Δ,q)                                          (13)
```

其中δF_scr是屏蔽对自由能的修正。为自洽处理，我们注意到γ_eff取决于E_C_eff：

```
γ_eff = γ₀ / f(|Δ|²)                                           (14)
```

因为屏蔽减弱Coulomb→减弱CPG稳定性→减弱SC-CPG竞争。但γ是竞争强度——更弱的Coulomb意味着更弱的竞争！

所以：γ_eff = γ₀ · f(|Δ|²)（屏蔽使竞争减弱）。

等等，我需要仔细想这个符号。

Coulomb排斥使CPG稳定（κ项∝+E_C² → 更负的κ → CPG更容易出现）。SC-CPG竞争来自排斥——当SC试图建立相干时，Coulomb排斥了邻近的局域对。

屏蔽减弱Coulomb→减弱CPG→减弱竞争？还是增强竞争？

物理上：如果SC态完全屏蔽Coulomb（f→0），则CPG完全不稳定（κ→∞正），SC-CPG竞争消失（无CPG可供竞争）→此时只有纯SC→二阶相变（或无相变）。

如果CPG态完全暴露Coulomb（f→1），则CPG非常稳定→SC和CPG强竞争→一阶相变。

所以屏蔽越大→竞争越弱→越倾向二阶。屏蔽越小→竞争越强→越倾向一阶。

但这里有个self-consistency loop：
- SC态中屏蔽强(f≪1)→CPG在这个态中不稳定→SC→CPG的相变驱动力小→二阶
- CPG态中屏蔽弱(f≈1)→SC在这个态中不稳定→CPG→SC的相变驱动力大→一阶
- 净效果：两个方向不对称！从SC→CPG的势垒和从CPG→SC的势垒不同→一阶

这个自洽loop是产生一阶行为的核心机制。

### 3.3 有效Landau系数

将屏蔽修正展开到|Δ|²的最低非平庸阶：

```
γ_eff = γ₀ · [1 - A₁|Δ|² + A₂q² + O(|Δ|⁴, q⁴)]                 (15)
```

其中A₁, A₂ > 0来自κ_TF对|Δ|²和q²的依赖。

有效四次项也被修正：
```
β_eff = β₀ + δβ_scr                                              (16)
λ_eff = λ₀ + δλ_scr                                              (17)
```

关键的r修正来自展开式(15)。在相变点（Maxwell线）附近，|Δ|²≈|α|/β, q²≈|κ|/λ：

```
γ_eff(Maxwell) = γ₀ · [1 - A₁|α|/β + A₂|κ|/λ]                 (18)
```

在Maxwell线上，|α|/√β = |κ|/√λ，因此：
|α|/β = (√β/√λ)·|κ|/β = |κ|/√(βλ)
|κ|/λ = (√λ/√β)·|α|/λ = |α|/√(βλ)

所以：
γ_eff = γ₀ · [1 - (A₁ - A₂)·|α|/√(βλ)]  [在Maxwell线上]      (19)

有效r:
```
r_eff² = γ_eff²/(βλ) = γ₀²/(βλ) · [1 - 2(A₁-A₂)·|α|/√(βλ) + ...]
       = 1 - 2(A₁-A₂)·|α|/√(βλ) + O(|α|²)                      (20)
```

**关键结果：**
```
r_eff > 1 ⟺ A₁ < A₂                                             (21)
r_eff < 1 ⟺ A₁ > A₂                                             (22)
```

物理含义：
- A₁: |Δ|²变化如何通过屏蔽修正γ（SC侧的屏蔽效应）
- A₂: q²变化如何通过屏蔽修正γ（CPG侧的屏蔽效应）
- A₁ < A₂ → SC侧的屏蔽修正弱于CPG侧 → γ在SC→CPG方向有效增强 → 一阶
- A₁ > A₂ → SC侧的屏蔽修正强于CPG侧 → γ在SC→CPG方向有效减弱 → 二阶

### 3.4 A₁和A₂的材料依赖性

A₁和A₂取决于介电函数对|Δ|²和q²的敏感度：

```
A₁ ∝ (∂ε_eff/∂|Δ|²)_{q=0} ∝ σ_SC / ε₀ · τ_pair              (23)
A₂ ∝ (∂ε_eff/∂q²)_{Δ=0} ∝ χ_CPG / ε₀                          (24)
```

其中σ_SC是SC态的电导率（~1/R□），τ_pair是配对寿命，χ_CPG是CPG态的介电极化率。

**材料对比：**

a-InO:
- σ_SC大（R□≈1-5 kΩ，g≈5-25）→ A₁大
- ε₀小（≈5-10，bare dielectric constant）→ A₁, A₂都大
- 但CPG态中ε更小（无金属屏蔽）→ χ_CPG大→ A₂非常大
- **A₁ - A₂ < 0 → r > 1 → 一阶** ✓

a-MoGe:
- σ_SC中等（R□≈3-6 kΩ，g≈4-8）
- ε₀大（≈10-15，MoGe金属性更强）→ A₁, A₂都较小
- MoGe的CPG弱（对不存活，见§4）→ A₂小
- **A₁ - A₂ > 0 → r < 1 → 二阶** ✓

## §4 配对存活条件——区分CPG存在与否 ⭐

### 4.1 配对的Anderson局域化

在强无序中，Cooper对能否作为定义良好的准粒子存在，取决于配对能是否超过局域化体积内的能级间距：

```
pair生存条件: Δ_P > δ = 1/(ν₀ξ_loc²) [2D]                     (25)
```

当Δ_P > δ时：局域化体积内有≥1个态→可以形成局域对→CPG可能出现
当Δ_P < δ时：局域化体积内无足够的态密度→对不能形成→系统直接进入Anderson绝缘体（无双配对）→只有单序参量（dirty boson）→二阶SIT

### 4.2 配对生存判据的显式形式

在2D脏极限下：
```
ν₀ = m*/(πħ²) （二维自由电子DOS）

ξ_loc ≈ l · exp(πk_Fl/2) [弱局域化区]
     ≈ l · g [临界区，k_Fl~1]

δ = 1/(ν₀ξ_loc²) ≈ (πħ²/m*) · 1/(l²g²) = (E_F/k_Fl²) · 1/g²
```

配对能量Δ_P在脏极限下被Finkel'stein修正：
```
Δ_P ≈ Δ_P⁰ · exp(-1/√g) [无序抑制因子]
```

其中Δ_P⁰是干净极限的BCS能隙。

配对生存条件：
```
Δ_P > δ → g² > (E_F/Δ_P⁰) · (1/k_Fl²) · exp(1/√g)
```

对于a-InO：E_F≈1eV, Δ_P⁰≈50K(≈4meV), k_Fl≈3 → E_F/Δ_P⁰≈250
配对生存要求g²>250/(3²)·exp(1/√g)≈28·exp(1/√g)
取g≈5→g²=25，RHS≈28·exp(0.45)≈44→25<44→配对勉强存活（边界）

对于a-MoGe：E_F≈1eV, Δ_P⁰≈10K, k_Fl≈1.5 → E_F/Δ_P⁰≈1000
配对生存要求g²>1000/(1.5²)·exp(1/√g)≈444·exp(1)
取g≈4→g²=16，RHS≈444·2.7≈1200→16≪1200→配对不能存活！

**这解释了根本差异：**
- a-InO中配对边界存活→CPG可以形成→双序参量→可以一阶
- a-MoGe中配对不能存活→无CPG→单序参量dirty boson→必须是二阶

### 4.3 配对存活→CPG→一阶的完整逻辑链

```
Δ_P > δ (配对存活)
  → 绝缘相中是局域对，不是单粒子局域化
  → 局域对之间有Coulomb排斥 E_C = 4e²/(εr₀)
  → Coulomb排斥竞争Josephson耦合→CPG序参量q_EA≠0
  → 双序参量(Δ, q_EA)竞争
  → 自洽屏蔽不对称性(A₁-A₂<0)
  → r_eff > 1
  → 一阶SIT
```

```
Δ_P < δ (配对不存活)
  → 绝缘相中是单粒子Anderson局域化
  → 无局域对→无CPG→单序参量(Δ only)
  → dirty boson (Fisher 1990)
  → 二阶SIT
```

### 5.2 预测（可检验）

**预测1（TiN）：** TiN的Tc可达4.5K（高），但接近SIT时g≈2-5（低），配对可能不存活→预测二阶SIT。如果实验发现一阶→配对存活判据需要修正。

**预测2（NbN）：** NbN的Tc≈12K（非常高），但无序极限下g≈1-3（极低），配对可能存活（Δ_P大）也可能不存活→预测一阶vs二阶取决于具体无序类型（颗粒vs均匀）。颗粒NbN可能显示一阶。

**预测3（a-InO中氧含量控制）：** 在低氧含量a-InO_x中，Δ_P更小→配对不存活→SIT应从一阶连续过渡到二阶。这是最干净的检验。

**预测4（η参数——可测量的判据）：**
定义：η ≡ 1 - T_c/Θ(0)（赝能隙强度参数，0≤η≤1）
- η<0.5→配对弱，赝能隙窄→二阶SIT（a-MoGe, 低氧a-InO）
- η>0.7→配对强，赝能隙宽→一阶SIT（a-InO）
- 0.5<η<0.7→tricritical区

实验检验：测量一组不同无序强度的同种材料样品→提取η(x)→预测在η=η_c≈0.6处SIT阶数改变。

## §6 结论

### 6.1 核心定理

**定理S2.1（配对存活—阶数判据）：**
无序超导体SIT的阶数由配对是否在绝缘相中存活决定：
- 配对存活(Δ_P>δ)→双序参量(SC+CPG)→自洽屏蔽不对称→r_eff>1→**一阶**
- 配对不存活(Δ_P<δ)→单序参量(dirty boson)→**二阶**

**定理S2.2（η判据）：**
实验可观测量η≡1-T_c/Θ(0)在临界disorder处的值决定阶数：
- η>η_c≈0.6→一阶
- η<η_c≈0.6→二阶

**定理S2.3（屏蔽不对称性）：**
自洽屏蔽修正产生有效r≠1：
r_eff² = 1-2(A₁-A₂)·|α|/√(βλ)+O(|α|²)
A₁<A₂⟺一阶，A₁>A₂⟺二阶
