# LP15-S5 Phase 1: Maniv-Zhuravlev CPF-puddle模型的定量排除检验

## §0 框架声明

**目标：** 定量检验Maniv & Zhuravlev (2025, arXiv:2510.06894)的CPF-puddle模型能否在不假设一阶QPT的情况下复现Charpentier et al.的全部关键观测。

**模型核心：** Cooper对涨落(CPF)在介观puddle中凝聚→量子隧穿释放puddle→对破缺为费米子准粒子→热激发输运。**不假设一阶QPT**，表观Θ跳变来自逾渗阈值处的puddle密度跳变。

**检验策略：** 提取CPF-puddle模型对Θ(T,x)的定量预测→与Charpentier/Khvalyuk数据比较→识别模型能否同时拟合：(a) Θ(0)的跳变，(b) δΘ(T)∝T^b的幂律行为，(c) T_c与Θ(0)的对齐。

## §1 CPF-puddle模型的核心机制

### 1.1 模型设定（Maniv-Zhuravlev 2025）

在强无序2D超导体中，超导序参量Δ(r)在空间中被调制为介观puddle（尺寸~ξ_loc）。在磁场或disorder驱动下：

1. **CPF在puddle中凝聚：** 在每个puddle内，Cooper对涨落的刚度随T降低而增大→在某个T*处，puddle内的CPF"凝聚"（局域相位锁定，但puddle间无全局相干）

2. **量子隧穿释放puddle：** CPF凝聚的puddle通过量子隧穿（宏观量子隧穿，MQT）释放其相位→puddle退凝聚→释放出费米子准粒子

3. **逾渗阈值处Θ→0：** 当CPF-puddle密度超过逾渗阈值→系统级相位相干丧失→Θ→0。这发生在puddle密度p=p_c处。

4. **表观Θ跳变：** 在p≈p_c附近，puddle密度对disorder的依赖是陡峭的（但非不连续）→Θ(p)在逾渗阈值附近快速但连续地下降到0→表观"跳变"

### 1.2 与一阶QPT的关键区别

| 特征 | 一阶QPT (Charpentier) | CPF-puddle逾渗 (Maniv-Zhuravlev) |
|------|----------------------|----------------------------------|
| Θ(0)在x_c处的行为 | 不连续跳变→0 | 连续但陡峭→0 (θ(p)∝(p_c-p)^t, t≈1.3) |
| 机制 | 双序参量竞争 | 经典逾渗+量子隧穿 |
| T→0极限 | 真正的Θ(0)跳变 | Θ(0)连续→表观跳变来自陡峭逾渗 |
| 赝能隙来源 | CPG序参量 | CPF凝聚puddle |
| 对存活要求 | 必须（需要局域对） | 隐含需要（CPF在puddle内配对） |

## §2 定量检验

### 2.1 检验1: Θ(0)跳变的陡峭程度

在CPF-puddle模型中，Θ(x)在逾渗阈值附近的行为：
```
Θ(x) = Θ₀ · (p_c - p(x))^t · θ(p_c - p(x))                    (1)
```
其中t≈1.3为2D逾渗的传导指数，p(x)为puddle密度（disorder x的单调函数）。

p(x)的一阶展开：p(x)≈p_c + p'(x_c)(x-x_c)，在x_c附近。

```
Θ(x) ≈ Θ₀ · [p'(x_c)(x_c-x)]^t                                 (2)
```

Charpentier的数据：Θ(0)从TC007-2的1.4K跳到绝缘侧的0，跳变发生在Δx的disorder区间内。从样品序列估算：
TC007-3: Θ(0)=1.9K, R□=5.95kΩ
TC007-2: Θ(0)=1.4K, R□=7.47kΩ
绝缘样品: Θ(0)=0, R□>8kΩ

ΔR□(跳变)≈1-2kΩ。如果这来自逾渗的Θ∝(p_c-p)^t，则：
1.4/1.9 = (δp_2/δp_3)^1.3 → δp_2/δp_3 = (1.4/1.9)^{1/1.3} = 0.74^{0.77} = 0.79

合理——puddle密度差~20%可产生Θ差~25%。

**但关键问题：** 当把R□分辨率做得足够细时，Θ(R□)应显示连续的幂律Θ∝(R_c-R□)^t，而非不连续跳变。

**CPF-puddle的预测：** 如果在TC007-2和绝缘体之间制备足够多的中间R□样品，应观察到Θ(0)连续下降到0（虽然可能很陡峭）。

**一阶QPT的预测：** 在任何中间R□处，Θ(0)要么有限（SC侧）要么为0（CPG侧），没有"中间值"的稳定态。在有限T下热展宽产生表观连续性，但T→0外推应恢复跳变。

**实验上可区分吗？** 需要比Charpentier更密的disorder采样。目前样品数(n≈5-6)不足以区分"陡峭连续"和"真跳变"。

→ **此检验当前不可执行（需要更多样品），但对未来实验给出了明确方向。**

### 2.2 检验2: δΘ(T)∝T^b幂律行为

Khvalyuk et al. (2024)发现δΘ(T)∝T^b, b≈1.6，归因于非均匀超导体中的低能集体激发。

**CPF-puddle模型能否产生b≈1.6？**

在CPF-puddle图像中，Θ(T)的T依赖性来自：
1. puddle内的准粒子激发（BCS型: δΘ∝exp(-Δ/T)）
2. puddle间的相位滑移（热激发: δΘ∝exp(-T_QPS/T)）
3. 逾渗网络的热涨落（经典: δΘ∝T）

以上机制均产生b=1（线性或指数）→**不能自然产生b≈1.6**。

b≈1.6的幂律是非均匀超导体中无序诱导的集体激发能谱的特征——这种激发谱在CPF-puddle图像中不存在（puddle被视为孤立的、内部均匀的）。

**CPF-puddle对此的回应可能是：** puddle尺寸的分布（从幂律分布P(L)∝L^{-τ}）可以产生有效的非整数b。但即使如此，b的值应与逾渗指数τ相关，而非与微观激发谱相关→b在p≈p_c处应有特征性变化。

**检验：** 测量不同disorder样品的b(x)，看在接近x_c时b是否变化。
- 一阶QPT预测：b主要由超导态的集体激发决定→在SC侧近似恒定
- CPF-puddle预测：b在p≈p_c附近应显示逾渗特征(b→1, 经典逾渗的线性T)

Khvalyuk数据：b在TC002到TC007-2之间几乎恒定(b=1.57-1.69)→**偏向一阶QPT**。

→ **此检验可以执行（已有数据），结果偏向排除CPF-puddle。**

### 2.3 检验3: T_c与Θ(0)的对齐——最关键的检验 ⭐

Charpentier的核心发现之一：在a-InO中，T_c与Θ(0)线性对齐（T_c∝Θ(0)），而非常规BCS的T_c∝Δ_P。

这是赝能隙/CPG物理的强证据：T_c不是由配对振幅（Δ_P）决定，而是由相位刚度（Θ(0)）决定——因为在T_c处发生的不是"对破缺"而是"相位解锁"。

**CPF-puddle模型能否解释T_c∝Θ(0)？**

在CPF-puddle图像中，T_c是两个过程的竞争：
1. puddle内的CPF凝聚温度T*(puddle)（尺度~Δ_P_local）
2. puddle间的Josephson耦合建立全局相干的温度T_J∝Θ(0)

如果T_J<T*(puddle)→T_c=T_J∝Θ(0)（相位解锁限制）。这与Charpentier一致。

但问题是：CPF-puddle中的Θ(0)是什么？在逾渗阈值附近，Θ(0)∝(p_c-p)^t。而T_J∝Θ(0)。所以T_c∝(p_c-p)^t也成立。

**两者都预测T_c∝Θ(0)——此检验不能区分。**

### 2.4 检验4: 赝能隙的光谱证据

Charpentier通过等离子体谱测量确认了Θ(0)的跳变。他们的微波谐振器测量直接探针了超流刚度——这是CPF-puddle模型**不能轻易解释**的证据。

在CPF-puddle图像中，微波谐振频率的移动Δf/f∝Θ(T)应该在p≈p_c处显示连续变化（即使很陡）。Charpentier观察到的是在临界disorder处谐振频率的**不连续跳变**（在实验分辨率内）。

**CPF-puddle的回应：** 如果p(x)在x_c附近的导数极大（puddle密度对disorder极敏感），表观跳变可以非常陡峭，"看起来"不连续。

**反驳：** 一阶QPT中，跳变是真不连续——在Maxwell点，两相的自由能相等但序参量不同，系统在两者之间瞬时切换（量子隧穿时间~ħ/ΔF_barrier≪测量时间）。CPF-puddle中的"陡峭连续"总需要有限的disorder区间来完成Θ→0的下降。

**定量估计CPF-puddle所需的p'(x_c)：**
要使Θ从1.4K降到<0.01K（实验分辨率）所需的ΔR□在CPF-puddle中：
0.01/1.4 = (Δp/p_c)^{1.3} → Δp/p_c = (0.007)^{0.77} = 0.02

即p需在Δp/p_c≈2%内从>p_c变到<p_c。这要求p'(x_c)极大——disorder每变化1%，puddle密度变化>50%。这不合理，因为puddle密度应~exp(-c/W²)平滑依赖于disorder。

→ **此检验偏向排除CPF-puddle。跳变太陡，难以用逾渗解释。**

## §3 综合判定

### 3.1 四检验汇总

| 检验 | 一阶QPT预测 | CPF-puddle预测 | 数据 | 判决 |
|------|-----------|---------------|------|------|
| Θ(0)跳变陡峭度 | 真不连续 | 陡峭连续 Θ∝(p_c-p)^{1.3} | 跳变在1-2kΩ内 | ⚠️需更密采样 |
| δΘ(T)∝T^b, b≈1.6 | 自然（集体激发） | 需额外假设（puddle尺寸分布） | b≈1.6恒定 | ✅偏向一阶 |
| T_c∝Θ(0) | 自然（相位解锁） | 也可（逾渗T_J） | 线性对齐 | ❓不区分 |
| 跳变的陡峭度/不连续性 | p'(x_c)物理合理 | p'(x_c)需异常大 | 跳变极陡 | ✅偏向一阶 |

### 3.2 结论

**定理S5.1（CPF-puddle部分排除）：**
CPF-puddle模型在以下方面与数据不一致：
1. δΘ(T)∝T^b (b≈1.6)在SC侧近似恒定——CPF-puddle预测b在p→p_c时应趋于1
2. Θ(0)跳变的陡峭度对纯逾渗机制而言异常大——需要puddle密度对disorder的非物理敏感性

**CPF-puddle不能被完全排除**——在缺乏更密disorder采样和独立puddle密度测量的情况下，不能100%排除"陡峭连续"的可能性。但当前数据更自然地被一阶QPT解释。

**定理S5.2（需要的关键实验）：**
要最终排除CPF-puddle模型，需要：
(i) 在ΔR□<0.5kΩ分辨率下测量Θ(0)→检验是真跳变还是陡峭连续
(ii) 独立测量puddle密度（通过STM或扫描微波阻抗显微镜）
(iii) 检验b(x)在x→x_c时是否趋于1（CPF-puddle预测）还是保持≈1.6（一阶QPT预测）

## §4 对LP-15综合推导的影响

S5的结论是**中等置信度**地偏向一阶QPT：
- 一阶QPT解释更自然（无需额外假设）
- CPF-puddle不能完全排除，但在两个检验上不如一阶解释
- 需要更精细的实验来最终区分

在综合推导中，这应表述为："当前数据不支持CPF-puddle模型作为一阶QPT的可行替代——CPF-puddle需要异常陡峭的逾渗+非恒定b值的额外假设。但独立实验排除仍需更密disorder采样。"
