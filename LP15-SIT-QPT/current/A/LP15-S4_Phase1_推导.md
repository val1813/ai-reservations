# LP15-S4 Phase 1: 一阶QPT中的量子临界标度假定

## §0 框架声明

**目标：** 分析一阶QPT（ξ保持有限）中是否仍存在可观测的"量子临界标度"行为，以及历史SIT标度分析能否区分一阶vs二阶。

**核心论点（预告）：** 一阶QPT在有限T下产生表观标度行为（zν_eff≈1），与二阶dirty boson的zν≈1-1.5在实验精度内不可区分。历史"标度证据支持二阶SIT"的逻辑是循环的——它同样支持一阶。真正的判别需要直接测量ξ或Θ分布。

## §1 二阶vs一阶QPT的标度假定

### 1.1 标准二阶QPT标度假定（Fisher 1990）

在连续QPT中，关联长度ξ在x→x_c时发散：ξ∝|x-x_c|^{-ν}。这导致量子临界扇内的标度行为：

```
R(T, x) = R_c · Φ(c_0 |x-x_c| / T^{1/zν})                    (1)
```

其中z为动力学指数，ν为关联长度指数，Φ为普适标度函数。

对于2D dirty boson SIT（Fisher 1990）：
- z = 1（动力学指数来自库仑相互作用）
- ν ≈ 2/3（关联长度指数，来自经典2D percolation + 量子修正）
- zν ≈ 0.67 → 标度变量 |x-x_c|/T^{1.5}

但实验上常拟合得到zν≈1-1.5。某些数值研究（如量子Monte Carlo）也给出ν≳1→zν≳1。

**关键：** zν的实验/数值不确定性已经大到无法排除zν=1（一阶热展宽）。

### 1.2 一阶QPT的有限T行为

在双序参量Landau理论中（r>1，一阶），T=0时两相在Maxwell线x=x_c处共存，自由能势垒ΔF_barrier分隔两相。

在T>0时，热激发越过势垒→一阶跳变被热展宽。在低温极限(T≪ΔF_barrier)：

两态系统的配分函数：
```
Z = exp(-F_SC/T) + exp(-F_CPG/T)                               (2)
```

SC的概率：
```
P_SC = 1 / [1 + exp(ΔF(x)/T)]                                   (3)
```

其中ΔF(x) = F_CPG(x) - F_SC(x) ≈ a₀(x-x_c)·V（V为系统体积）。

电阻（假设SC侧R=0，CPG侧R=R_CPG）：
```
R(x,T) = R_CPG · [1 - P_SC(x,T)]
       = R_CPG / [1 + exp(-a₀V(x-x_c)/T)]                     (4)
```

**标度形式：**
```
R(x,T) = R_CPG · f((x-x_c)/T)                                   (5)
```

其中f(z) = 1/[1+exp(-a₀Vz)]为logistic函数。

**这恰好是zν=1的标度形式！**

但与二阶QPT的本质区别：
1. "指数"zν=1来自热激发的Arrhenius形式exp(-ΔF/T)，不是来自量子临界固定点
2. 普适性不存在——f(z)依赖系统细节（a₀V），不同材料有不同的 crossover 宽度
3. 标度仅在T≪ΔF_barrier时成立，升温后失效（→多能级参与→非两态近似）

### 1.3 标度假定的物质性差异

| 特征 | 二阶QPT (dirty boson) | 一阶QPT (热展宽) |
|------|----------------------|-------------------|
| 标度变量 | \|x-x_c\|/T^{1/zν} | (x-x_c)/T |
| zν理论值 | ~0.67-2/3 | 1 (非普适) |
| zν实验值 | 1-1.5 | 1 |
| 标度函数 | 普适 (仅依赖对称性类) | 非普适 (依赖材料) |
| 标度范围 | 量子临界扇 (宽温区) | T≪ΔF_barrier |
| 关联长度 | 发散 (ξ→∞) | 有限 (ξ~ξ_loc) |
| T→0极限 | 连续→0 | 跳变→0 |

## §2 一阶热展宽标度假定的可检验推论

### 2.1 标度质量vs温度范围

一阶热展宽标度仅在T≪ΔF_barrier时精确。当T接近ΔF_barrier时，多能级激发（非两态）导致标度偏离。

ΔF_barrier可估计：从Landau理论，鞍点处的势垒高度
ΔF_barrier ≈ (r²-1) · α²/(2β) · V_coherence

对于a-InO（TC007-2）：
Θ(0)=1.4K，取相干体积V_coh≈ξ_loc²·d≈(10nm)²·20nm=2000nm³
r≈1.5（估计，从S1/S2的外推）
ΔF_barrier ≈ (1.5²-1)·Θ(0)·(V_coh/a³)
≈ 1.25·1.4K·2000nm³/(10nm)³
≈ 1.75K·2 = 3.5K

所以标度应在T<ΔF_barrier≈3.5K内成立——这覆盖了实验的整个温区(20mK-3K)！

**这意味着：在实验可达的全部温区内，一阶热展宽标度假定都成立。不可能通过T范围的标度质量来区分。**

### 2.2 标度函数的普适性——可检验的差异

一阶标度函数f(z)=1/[1+exp(-a₀Vz)]依赖于材料参数a₀V。
二阶标度函数Φ(z)是普适的（对给定的对称性类）。

**预测：**
- 如果SIT是二阶：不同材料（a-InO, a-MoGe, TiN...）应有相同的标度函数Φ(z)（在适当重标定后）
- 如果SIT是一阶：不同材料的标度函数f(z)应不同（a₀V不同）

**检验方法：** 收集≥3种材料的R(T,x)数据→做标度collapse→提取标度函数→检验是否在统计误差内一致。

### 2.3 关联长度——决定性诊断

```
一阶SIT: ξ(T=0, x→x_c) ≤ ξ_loc < ∞
二阶SIT: ξ(T=0, x→x_c) → ∞
```

直接测量ξ可通过：
- 有限尺寸标度（不同尺寸样品的Tc展宽）
- 磁输运的量子干涉（弱局域化修正的尺度依赖）
- 扫描探针（STM的准粒子干涉图案）

## §3 历史标度分析的重新解释

### 3.1 a-InO的早期标度分析

在Charpentier (2025)之前，a-InO的SIT被广泛接受为二阶QPT的典型例子。关键证据包括：
- Gantmakher et al. (1998-2005): R(T,x)的标度collapse，zν≈1-1.3
- Steiner & Kapitulnik (2005): 多种非晶超导体的标度分析

**重新审视：** 这些标度collapse的"成功"在zν≈1下并不区分一阶vs二阶。实验上拟合的zν≈1-1.3恰好覆盖了两种可能性。

### 3.2 Charpentier实验的独特之处

为什么Charpentier（2025）能看到一阶而早期实验不能？
- **探针不同：** 早期测量R(T)，Charpentier测量Θ(T)——超流刚度直接探针序参量，电阻是间接探针
- **Θ测量更敏感：** Θ跳变(1.4K→0)在R中表现为有限电阻跳变(R_c→R_CPG)，但R的跳变被热展宽掩盖得更严重

### 3.3 量子临界"标度"在一阶QPT中的命运——结论

**定理S4.1（标度假定）：**
一阶SIT在T≪ΔF_barrier下产生表观标度行为R(x,T)=f((x-x_c)/T)，与二阶QPT的zν=1情形在实验精度内不可区分。历史上视为"二阶QPT证据"的R(T,x)标度collapse不构成对一阶SIT的反证据。

**定理S4.2（标度假定的判别失效）：**
仅靠R(T,x)的标度分析不可能区分一阶vs二阶SIT。需要的判别信息：
(i) 直接测量ξ（有限尺寸标度或量子干涉）
(ii) 标度函数的跨材料普适性检验
(iii) Θ的分布双峰性（B博士S1提出）

## §4 结论

**核心结论：** 一阶QPT中不存在真正的量子临界标度（ξ有限→无可观测的发散长度），但存在热展宽产生的"表观标度"（zν_eff=1），与二阶dirty boson（zν≈1）在实验上不可区分。

**对LP-15的影响：**
- S4清除了"历史标度证据支持二阶"的反驳路径
- Charpentier的Θ跳变测量（非R标度分析）才是决定性证据
- 要最终判定，需要直接的ξ测量或跨材料标度函数比较
