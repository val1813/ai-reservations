# LP-15 L7分解 v1.0

## 核心障碍链

```
O1(理论框架) → O2(材料映射) → O4(实验预测)
     ↘ O3(标度假定命运) → O4
O5(TDGL替代) ─────────→ O4
```

**O1: 理论框架不完整** — Poboiko & Feigel'man (2024)建立了双序参量平均场理论，但未系统研究一阶vs二阶的完整相边界在Landau参数空间中的条件。核心问题：γ > √(βλ)是必要且充分条件吗？有限温度修正如何改变相边界？

**O2: 材料参数→Landau系数的微观映射缺失** — 为什么a-InO是一阶而a-MoGe是二阶？Landau系数β,λ,γ如何从微观参数（态密度ν₀, Coulomb赝势μ*, 无序强度W, 介电常数ε）计算？

**O3: T=0外推的稳健性未量化** — Charpentier实验在~20-300mK进行，T→0外推的函数形式选择可能影响Θ(0)跳变的统计显著性。

**O4: 量子临界标度假定被挑战** — 标准QPT教科书假定连续相变+发散关联长度。一阶QPT中ξ保持有限→所有基于ξ→∞的标度论证需要重新审视。

**O5: CPF-puddle模型(TDGL)未被排除** — Maniv & Zhuravlev (2025)声称其模型可在不假设一阶QPT下解释a-InO数据。需要定量检验。

## 子命题分解

### LP15-S1: 双序参量Landau理论的SIT相边界——一阶vs二阶的完整判据 ⭐关键路径

**命题表述：** 在双序参量Landau理论F(Δ,q)=α|Δ|²+β|Δ|⁴/2+κq²+λq⁴/2-γ|Δ|²q²中，SIT的一阶条件是γ>√(βλ)（强竞争），二阶条件是γ<√(βλ)（弱竞争），tricritical点在γ=√(βλ)。

**驱动矛盾：**
- 命题A: 双序参量SIT在一般参数下是二阶的——一阶需要精细调节参数
- 命题B: 双序参量SIT在物理参数下天然是一阶的——γ自然大于√(βλ)因为Coulomb排斥在无序超导体中固有地强

**依赖：** 无
**工具：** Landau理论稳定性分析 + 数值相图扫描 + Poboiko-Feigel'man微观模型对接
**三步推进：**
- Phase 1: 推导完整Landau相图——解析导出γ_c=√(βλ)判据，验证共存区边界，计算spinodal线
- Phase 2: 从Poboiko-Feigel'man微观模型估计β,λ,γ的典型值——确定物理参数是否自然落入一阶区
- Phase 3: 有限温度修正——T>0时的一阶线如何移动？与Charpentier实验的有限温数据比较

**预期产出：**
- 成立（一阶条件自然满足）→ SIT阶数由Coulomb排斥强度决定，为S2提供分类判据
- 证伪（一阶需要精细调节）→ a-InO的一阶行为是特例，需S5解释
- 有边界（仅部分参数区一阶）→ 精确划定一阶/二阶在参数空间中的分界线，为S2提供定量预测

**AB验证：** 待执行

### LP15-S2: 材料参数→Landau系数映射——预测哪些非晶超导体应显示一阶SIT

**命题表述：** 存在从微观材料参数(ν₀, μ*, W, ε)到Landau系数(β,λ,γ)的系统映射，使得可以在实验前预测SIT的阶数。

**驱动矛盾：**
- 命题A: γ/√(βλ)主要由介电常数ε决定——大ε抑制Coulomb→γ小→二阶；小ε增强Coulomb→γ大→一阶
- 命题B: γ/√(βλ)由无序微观结构（氧空位vs结构无序）决定——不可从体态参数预测

**依赖：** LP15-S1（需要γ_c=√(βλ)判据）
**工具：** Anderson局域化理论 + Coulomb玻璃理论 + 无序超导体微观模型
**三步推进：**
- Phase 1: 建立ν₀,μ*,W,ε→β,λ,γ的微观映射（从Poboiko-Feigel'man Parisi框架出发）
- Phase 2: 用已知材料(a-InO, a-MoGe, TiN, NbN)的参数检验映射——是否解释a-MoGe二阶/a-InO一阶？
- Phase 3: 预测下一个应显示一阶SIT的候选材料

**预期产出：**
- 成立→ 提供材料筛选判据，指导实验寻找一阶SIT
- 证伪→ 每个材料需单独测量→SIT阶数没有普适预测规则
- 有边界→ 部分参数可预测但无序微观结构引入不可约化不确定性

### LP15-S3: T→0外推的稳健性定量分析

**命题表述：** Charpentier et al.的T→0外推中Θ(0)跳变的统计显著性对外推函数形式的选择是否鲁棒？

**驱动矛盾：**
- 命题A: 外推鲁棒——幂律δΘ(T)∝T^b (b≈1.6, Khvalyuk 2024)和常数外推都给出统计显著的Θ(0)跳变
- 命题B: 外推不鲁棒——用不同外推函数（指数、对数修正）可使Θ(0)跳变消失或<2σ

**依赖：** 无（直接分析已发表数据）
**工具：** Khvalyuk et al. (2024)的δΘ(T)参数化 + 贝叶斯外推模型比较
**三步推进：**
- Phase 1: 从Charpentier+Khvalyuk已发表数据重建Θ(T) vs disorder数据集
- Phase 2: 用≥3种外推函数形式执行T→0外推，用WAIC/Bayes因子比较
- Phase 3: 确定"使跳变消失"所需的外推函数偏离已知T>0行为的程度

**预期产出：**
- 外推鲁棒→ 实验结论稳固
- 外推不鲁棒→ 实验结论需标注"依赖于外推假设"

### LP15-S4: 一阶QPT中的量子临界标度假定

**命题表述：** 一阶QPT中（ξ保持有限），是否仍存在可观测的量子临界标度行为？

**驱动矛盾：**
- 命题A: 完全不存在——ξ有限→所有标度函数在T→0时光滑，无可观测临界行为
- 命题B: 残留标度存在——一阶QPT附近有限T的crossover产生表观标度行为（非普适指数），与二阶QPT在有限精度数据中不可区分

**依赖：** LP15-S1（需要一阶条件的定量表述）
**工具：** 有限T的Landau理论 + crossover标度分析 + 与已知二阶SIT标度数据比较
**三步推进：**
- Phase 1: 在双序参量Landau理论中计算有限T的一阶相边界附近的响应函数（比热、压缩率）
- Phase 2: 推导表观标度指数作为γ/√(βλ)的函数，量化"看起来像标度"的参数范围
- Phase 3: 与a-InO实验数据比较——已发表的标度分析是否可能被一阶crossover误导？

**预期产出：**
- 完全不存在→ 二阶标度行为是一阶SIT的反证据
- 残留→ 仅凭标度分析不能区分一阶vs二阶→需要其他诊断

### LP15-S5: Maniv-Zhuravlev CPF-puddle模型的定量检验

**命题表述：** Maniv-Zhuravlev的CPF-puddle模型能否在不假设一阶QPT的情况下定量复现Charpentier et al.的全部关键观测？

**驱动矛盾：**
- 命题A: 能复现——CPF-puddle的逾渗+量子隧穿机制自然产生表观Θ跳变（逾渗阈值处密度跳变，非真正一阶QPT）
- 命题B: 不能复现——至少一个关键观测（Θ跳变的disorder宽度、赝能隙-T_c对齐、或Tc跳变的同时性）超出CPF-puddle模型能力

**依赖：** 无（使用独立理论框架）
**工具：** Maniv-Zhuravlev模型方程 + 与Charpentier数据定量比较
**三步推进：**
- Phase 1: 实现CPF-puddle模型的简化版→数值求解Θ(x,T)作为disorder x和T的函数
- Phase 2: 用Charpentier数据约束模型参数→检查是否能同时拟合Θ(0)跳变+赝能隙行为+Tc行为
- Phase 3: 找判别性可观测量——什么测量能在一阶QPT和CPF-puddle之间干净地区分？

**预期产出：**
- CPF-puddle能解释→ 一阶声张被削弱，重新表述为"表观一阶可能来自逾渗"
- CPF-puddle不能→ 一阶解释得到加强，S1-S4的理论基础更稳固

## 综合推导触发条件

当S1+S3+S5完成，且结论分别为：
- S1: 一阶条件γ>√(βλ)在物理参数区[成立/不成立/边界]
- S3: T→0外推[鲁棒/不鲁棒/依赖假设]
- S5: CPF-puddle[能/不能]解释Charpentier数据

→ 触发综合推导：
- 若S1成立+S3鲁棒+S5不能解释 → "a-InO的一阶SIT是稳健的物理发现，双序参量竞争是其微观起源"
- 若S1成立+S3不鲁棒 → "现有数据不足以确定T=0的阶数，需要更低温度测量"
- 若S5能解释 → "一阶声张需重新评估——表观Θ跳变可能是逾渗效应"
- 若S1不成立(一阶需精细调节) → "a-InO的一阶行为是材料特异性而非普适范式修改"
