## ✅ v1.0 Phase 1 新增结论

### K9: 一阶SIT的充要条件（Landau层次）
- 来源：LP15-S1 Phase 1 A+B双路径推导 (2026-06-02)
- 内容：在双序参量biquadratic耦合Landau理论中，SIT是一阶的充要条件为γ > √(βλ)，即约化耦合强度r ≡ γ/√(βλ) > 1。当r<1时存在稳定共存相→二阶；r=1为tricritical点。
- A推导：Landau自由能稳定性分析→共存解Hessian行列式det(H)=16ρ²q²(βλ-γ²)→γ>√(βλ)时det(H)<0→共存解为鞍点→一阶
- B推导：大偏差率函数I_x(θ)双谷结构→等深度全局最小值被势垒分隔→一阶。率函数曲率分析独立确认同一条件。提出模型独立的r提取方法（从Θ分布双峰间距）。
- 状态：✅L2（双框架独立确认）
- math_object: r ≡ γ/√(βλ), det(H_coex) = 16ρ²q²(βλ-γ²)

### K10: Landau相图拓扑分类
- 来源：LP15-S1 Phase 1 (2026-06-02)
- 内容：(α,κ,γ)参数空间中仅由r=γ/√(βλ)决定相图拓扑：
  - r<1: 两个二阶相变 SC→共存→CPG
  - r>1: 一个一阶相变 SC↔CPG，双稳区宽度Δ~r²-1
  - r=1: tricritical点
- 状态：✅L2
- math_object: phase diagram topology determined by single parameter r

### K11: 微观估算的tricritical困境
- 来源：Poboiko-Feigel'man (2024)微观模型领头阶估算
- 内容：β~1/(ν₀Δ₀²), λ~1/(ν₀E_C²), γ~1/(ν₀Δ₀E_C) → r²=γ²/(βλ)≈1（领头阶）。次领头阶修正（无序分布形式、准粒子修正、费米子符号）决定r>1还是r<1。
- 状态：⚠️待Phase 2确定（r在a-InO中的实际值）
- math_object: r² = 1 + δ, δ from subleading corrections

### K12: 配对存活—SIT阶数判据 ⭐核心（⚠️v1.1修订：数值矛盾待解决）
- 来源：LP15-S2 Phase 1 A+B双路径 (2026-06-02)
- 内容：SIT阶数的根本决定因素是Cooper对在绝缘相中是否存活：
  - 对存活(Δ_P > δ)→双序参量(SC+CPG)→自洽屏蔽不对称→r_eff>1→**一阶**
  - 对不存活(Δ_P < δ)→单序参量(dirty boson Fisher 1990)→**二阶**
  - δ = 1/(ν₀ξ_loc²)为局域化体积内的平均能级间距
- ⚠️ **数值矛盾（REVIEWER M4）：** a-InO的估算为g²=25 < RHS≈44→25<44→严格按判据应为配对**不**存活→二阶。当前数量级估算的输入参数各有因子2的不确定性→25和44在误差范围内可能重叠。需要更精确的配对存活条件计算来裁决。
- 状态：⚠️L1（定性判据方向合理，但定量估算不支撑a-InO结论——需要从第一性原理或数值计算获得更精确的判据值）
- math_object: pair_survival = Δ_P / δ, δ = 1/(ν₀ξ_loc²)

### K13: η判据——可实验测量的阶数诊断
- 来源：LP15-S2 Phase 1 (2026-06-02)
- 内容：η ≡ 1 - T_c/Θ(0)（赝能隙强度参数）在临界disorder处的值决定SIT阶数：
  - η > η_c ≈ 0.6 → 一阶SIT
  - η < η_c ≈ 0.6 → 二阶SIT
  - a-InO临界样品：η ≈ 1.0（T_c≈1.4K, Θ(0)≈1.4K）→ 一阶 ✓
  - a-MoGe临界样品：η ≈ 0.1-0.3 → 二阶 ✓
- 状态：⚠️L1（基于有限数据，需更多材料验证）
- math_object: η_c ≡ 1 - T_c/Θ(0)|_{x=x_c}

### K14: 自洽屏蔽不对称性机制
- 来源：LP15-S2 Phase 1 A推导 (2026-06-02)
- 内容：r_eff² = 1 - 2(A₁-A₂)·|α|/√(βλ) + O(|α|²)，其中A₁∝(∂ε_eff/∂|Δ|²)为SC侧屏蔽修正，A₂∝(∂ε_eff/∂q²)为CPG侧屏蔽修正。A₁<A₂→r_eff>1→一阶。
- 状态：✅L2
- math_object: r_eff² = 1 - 2(A₁-A₂)·|α|/√(βλ), A₁ = ∂ε_eff/∂|Δ|², A₂ = ∂ε_eff/∂q²

### K15: Coulomb玻璃逾渗判据（B博士独立框架）
- 来源：LP15-S2 Phase 1 B推导 (2026-06-02)
- 内容：自洽逾渗中S形F(p)⟺一阶的条件为Λ≡(V_C/J̄)·(d log h/d log p)>2。Λ与A的r同构：r↔1+c·Λ。
- 状态：✅L2（B独立推导逾渗判据，A通过r↔Λ同构映射部分支持；注意：双路径非完全独立——r↔Λ的同构性意味着部分重叠）
- math_object: Λ ≡ (V_C/J̄)·h'(1/2)/h(1/2)⋅p

### K16: 材料预测（可检验）

### K17: T→0外推鲁棒性定理 ⭐
- 来源：LP15-S3 Phase 1 A+B双路径 (2026-06-02)
- 内容：Charpentier/Khvalyuk实验的T→0外推极其鲁棒：
  - 所有合理外推模型(ΔAIC<5)给出的Θ(0)差异<1%
  - Θ(0)跳变的统计显著性≥200σ（1.400±0.005K → 0, 280σ）
  - QPS线性-T模型被数据以ΔAIC>40排除
  - Θ₀与其他参数(T₀,b)在低T端Fisher信息解耦→外推不依赖参数细节
  - MDL分析：Θ(0)有限是数据的最简描述
- 状态：✅L2（A路径贝叶斯模型平均，B路径MDL，双框架独立收敛）
- ⚠️ 280σ声张假设绝缘侧Θ=0的不确定性为零。实际绝缘侧的Θ测量更困难（高阻抗匹配），其不确定性未被量化。但即使保守假设绝缘侧Θ<0.1K，跳变显著性仍>10σ。
- math_object: |f(0)-Θ(0)| ≤ σ + Θ(0)·(T_max/T₀)^b
