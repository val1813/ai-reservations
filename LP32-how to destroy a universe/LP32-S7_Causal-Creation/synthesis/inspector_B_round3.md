## 2. Q1: 数值方法审计

### Q1.1 Gillespie算法实现

**整体正确。** 算法核心正确：指数等待时间 + 均匀随机边选择。但存在以下问题：

**(a) 非真正的O(1)步复杂度（minor，仅影响性能声明）**

`step()`方法第142行：`self.active_edges = list(self._active_edge_set)`。此操作每步将set转为list，复杂度O(N_active)，而非声称的O(1)。对于L=30（初始~900条活跃边），每步~900次操作。这不影响正确性，但使得"active-edge optimization"的NW5修复声称过于乐观。真正的O(1)实现应直接维护list（用swap-and-pop删除），或接受摊还O(1)（列表重建仅在需要时）。

**(b) 停止条件不够保守（minor）**

`stop_if_dead=50000`无跳转步数——这是合理的，确认死态（全|1⟩）。但随机游走中50000步无事件的可能性非零（即使有活跃边，如果步中所有边都被检查但跳转概率为0——在均匀速率γ₀=1.0下不会出现，但chi-dependent变体中可能出现）。

### Q1.2 Chi依赖速率模拟（场景4）— 关键缺陷

**发现：`_local_chi()`函数存在系统性负偏置，导致chi依赖速率模拟结果无效。**

**根源分析：**

对于活跃边(s_i=+1, s_j=-1)，有s_i * s_j = -1（恒成立）。局部χ估计为：

```
chi_local = s_i * s_j - s_mean² = -1 - s_mean² ≤ -1
```

由于s_mean² ≥ 0，chi_local永远≤ -1（对任意活跃边）。代入速率公式：

```
rate = γ₀ * max(0, q_j(1-q_i) - chi_local/4)
     = γ₀ * max(0, q_j(1-q_i) + |chi_local|/4)
     ≈ γ₀ * (0.25 + 0.25) = 0.5γ₀  [典型情况]
```

**chi_local的负值使得速率公式中的"刹车项"变成了"加速项"。** 场景4不是测试chi刹车，而是测试chi加速。

**JSON数据验证：** `local_chi_mean` 值为 [-1.03, -1.03, -1.03, ...]，确认系统性负偏置。

**后果：**
- 场景4的结果（Q→0，无刹车）不能作为"chi依赖速率不产生刹车"的证据
- 此bug使得§2.3场景4的分析、§3.1.3的讨论、和self-attack 3的回应中关于"local window太小"的诊断不完整——真正的问题是公式在单轨迹层面应用的范畴错误，而非仅噪声问题
- 公式 Γ_{i→j} = γ₀·[(1-q_i)q_j - χ_{ij}/4] 是系综层面的期望值关系，在单配置中直接使用需要：(i) 正确的局部χ估计（非s_i*s_j - s_mean²），(ii) 系综平均而非单配置值

**修复方向：** 如需正确的chi依赖速率模拟，需要：
1. 在Gillespie框架外，使用τ-leaping或直接使用BBGKY截断ODE（如B博士在失败跳跃7中尝试的）
2. 或在系综层面计算χ的期望值（而非单配置估计），然后用于指导跳转概率——这等价于平均场近似

### Q1.3 边界条件与格点拓扑

**PBC实现正确。** `_build_edges()`使用模运算实现周期边界：`((x+1)%L)*L + y`等。每个格点恰好4个邻居（2D正方格点，von Neumann邻域）。

边缘总数为 4 × 900 / 2 = 1,800条无向边，或3,600条有向边（`out_edges`按有向构建）。`chi_bar`测量遍历所有有向边（3,600条）后用`chi_sum/total_edges - s_mean²`计算——公式正确（协方差定义）。

### Q1.4 系综平均方法 — 系统性偏置

**发现：`run_ensemble()`中的插值方法引入系统性Q上偏。**

```python
idx = np.searchsorted(hj, j)  # 返回第一个 >= j 的索引
```

`searchsorted`将测量值向下取整到最近的>=j的测量点。例如，若某realization在jump 9测量，common_jump值为4，searchsorted返回idx=1（对应jump 9的测量），Q(9)被当作Q(4)使用。这系统性地高估了Q（因为Q随时间递减，更后面的测量Q更小——等等，这反而会低估Q？）。

**修正分析：** 由于Q递减，jump 9的Q < jump 4的Q（如果jump 4有测量的话）。使用jump 9的Q替代jump 4的Q → Q被系统性低估。但影响量级：common_jumps间距约4.5跳，每跳ΔQ ≈ 1/900 ≈ 0.0011，最大偏差约0.005（半格间距）。相对于Q值（0.03-0.90），相对误差约0.5%-17%。对于Q_final（~0.03），相对误差可达17%。

**建议：** 使用线性插值而非最近邻，或统一固定所有realization的测量跳数（而非各自独立测量后再插值）。

### Q1.5 局部q估计（measure_v）

`measure_v()`使用3×3窗口估计局部q_i。对于900格点系统，3×3=9格点窗口的限制是合理的（局部近似）。但V函数测量从根本上依赖这些局部估计的质量——报告中的V值（未出现在主文本中）不应被当作定量验证。

## 3. Q2: 结论可靠性

### Q2.1 "全部场景走向热寂"

**对于场景1-3（均匀速率）：数据支持此结论。** Q_final = 0.028, 0.018, 0.012（三场景），系统确实接近全|1⟩态。

### Q2.2 χ_max ~ 1/√N标度律

**此声称在方法论上不成立。** 理由：

1. **仅测试了单一L=30值。** 标度律需要至少3个不同L值（如L=10, 30, 100）才能拟合指数。

2. **"支持证据"来自错误对比。** B博士用场景1（p₀=0.5, χ_max=0.108）与场景2（p₀=0.9, χ_max=0.413）的比值来论证1/√N标度。但这两个场景的p₀不同——它们是不同的物理参数，不是不同的系统尺寸。正确的标度分析应固定p₀，仅改变L。

3. **自洽性矛盾。** B博士在§3.1.2说"χ的涨落尺度为~1/√N"，但在self-attack 2中推断"增大系统L χ_max反而减小"——这与场景2（高p₀→更大χ_max）的观察矛盾。如果χ来自有限尺寸涨落，更大p₀应产生更小χ（因为p₀→1时涨落消失），但场景2显示相反。

**判断：** χ_max ~ 1/√N是一个未经检验的假设，不是经过验证的标度律。P-R3-2（多L测试）是正确方向但尚待执行。

### Q2.3 "χ刹车在有限系统不成立"

**此结论需要重新表述。** 精确的表述应为：

> "在L=30、均匀跳转速率的DGF中，对于所测试的三种初始条件（随机p₀=0.5, 随机p₀=0.9, 反关联p₀=0.5），χ未达到Fréchet边界，系统在所有170次实现中走向接近全|1⟩（Q_final < 0.03）。"

不应声称"在有限系统不成立"——这是对L=30的过度外推。大偏差理论（§3.1.3）讨论的正是为什么有限N效应重要——那么就需要更多N值来验证这个效应本身。

**严格来说：** 模拟并未否定χ刹车在有限系统可能发生（如高χ初始态或更大L），仅证明在测试的参数范围内未发生。

### Q3.2 Q(t)误差棒

Q_std值在ensemble数据中存在，但在round3.md中仅以"±0.0000"形式报告——这是有问题的。JSON数据显示：

- **场景1 Q_std:** ~0.0169（整个衰减过程中几乎恒定）
- **场景2 Q_std:** ~0.0109（几乎恒定）
- **场景3 Q_std:** ~0.0094（几乎恒定）

Q_std在整个衰减过程中保持恒定这一点值得关注。理论上，Q_std应随Q减小而减小（std of binomial proportion ∝ √(Q(1-Q)/N)）。从Q=0.5到Q=0.03，期望的binomial std从0.0167降到0.0057。但观察到的Q_std始终在0.0169——说明系综成员间的轨迹差异主导了std（而非采样误差），但轨迹差异也应随Q→0而缩小。

**这不一定是问题，但缺乏解释。** R=0.0967的情形说明系统不是完全静止的——最终仍有活跃边和跳转。Q_std由各realization到达给定"jump number"时间的差异决定，而非由给定Q时各realization间的差异决定（因为measurement是按跳数对齐的，而非时间）。

## 5. Q4: 反向通道必要性

### Q4.1 独立验证A博士框架

B博士结论"需要反向通道（§3.3.2）"实质上等价于A博士的L₂创生算子：

- B博士方案：反向跳转|1⟩→|0⟩（速率γ₁），创建非平衡稳态
- A博士方案：L₂创生算子——在因果创造之外引入因果遗忘/退相干通道

**两者数学等价：都是引入与正向因果创造通道竞争的耗散通道。** 区别在于表述框架：B博士用KMC跳转语言，A博士用Liouvillian算子语言。

**这构成对A博士框架的独立验证**——通过完全不同的方法（数值KMC vs 解析Liouvillian）得出相同结论。但B博士的round3.md未显式建立此联系，也未引用A博士的工作。建议在synthesis中显式标注此对应关系。

### Q4.2 纯耗散vs竞争动力学的区分

B博士正确识别了关键区别：
- 纯耗散DGF：吸收马尔可夫链，唯一稳态为全|1⟩（热寂）。χ不能阻止吸收——因为无反向涨落机制
- 竞争动力学：正向+反向通道 → 非平衡稳态，χ在稳态中起结构性作用

此区分澄清了R1/R2中"χ刹车阻止热寂"声称的逻辑漏洞：χ刹车在纯耗散系统中即使在热力学极限下也不能完全阻止热寂——因为吸收态（全|1⟩）即使在χ→Fréchet边界时仍然可达，只是到达时间发散。真正需要的是反向通道创造非平凡稳态。
