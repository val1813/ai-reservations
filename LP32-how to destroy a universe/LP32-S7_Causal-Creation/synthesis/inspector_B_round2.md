## Q1 量纲检查

### 1.1 χ矩阵演化方程

**检查对象：** §1.6单边精确解 `dχ_{ij}/dt = γ₀ q_i [4q_j(1-q_i) - χ_{ij}]`

**逐项验证：**
- dχ/dt 量纲：[χ] / [T]。χ = ⟨s_i s_j⟩ - ⟨s_i⟩⟨s_j⟩，自旋s ∈ {±1}无量纲 → [χ] = 1 (dimensionless)，∴ [dχ/dt] = [T⁻¹]
- γ₀：[T⁻¹]（跃迁速率）
- q_i：[1]（概率）
- [4q_j(1-q_i) - χ]：[1]（概率/关联均无量纲）

→ 等式量纲 [T⁻¹] = [T⁻¹] × [1] × [1] **通过**。

**dq_k/dt方程验证（§1.3）：**
dq_k/dt = -γ₀ Σ[q_k(1-q_i) - χ_{ik}/4]
[dq_k/dt] = [T⁻¹], γ₀ = [T⁻¹], bracket = [1] **通过**。

### 1.2 单边精确解所有公式

- 守恒量：χ + 4q_i q_j = K₀ → 所有项无量纲，K₀无量纲 **通过**。
- q_j^f = K₀/4 = [χ(0) + 4q_i q_j(0)]/4 → 无量纲 **通过**。
- χ_f = (1-q_i)K₀ → 无量纲 **通过**。

**验证精算：** 从dχ/dq_j = -4q_i出发的推导是正确的。代入检验：
- dχ/dq_j = [dχ/dt] / [dq_j/dt] = [γ₀ q_i(4q_j(1-q_i)-χ)] / [-γ₀(q_j(1-q_i)-χ/4)]
- 分子 = 4γ₀ q_i [q_j(1-q_i) - χ/4]，分母 = -γ₀ [q_j(1-q_i) - χ/4]
- 比值为 -4q_i **正确**。

### 1.3 Fréchet边界条件

**B博士声称：** χ_{ij} = 4(1-q_i)q_j 是Fréchet上界

**精确验证：** 从联合概率非负性出发，完整的Fréchet边界的极值应为：
- 上界：χ ≤ 4·min[(1-q_i)q_j, q_i(1-q_j)]（两个正向联合概率边界）
- 下界：χ ≥ −4·min[(1-q_i)(1-q_j), q_i q_j]（两个负向联合概率边界）

B博士使用的4(1-q_i)q_j是min的**第一个参数**。当(1-q_i)q_j ≤ q_i(1-q_j)即q_j ≤ q_i时，该参数才是紧的上界。在DGF的有向边场景（i是跳转源，|1⟩; j是目标，|0⟩），通常q_i较小（源更可能|1⟩），此条件成立。但不加注释地写成"χ_{ij} = 4(1-q_i)q_j = Fréchet上界"是**简化表述**，建议标注域限制q_j ≤ q_i。

**量纲一致性：** 两边均无量纲 **通过**。

### 1.4 Lyapunov函数

V = Σ[4(1-q_i)q_j - χ_{ij}]，各项均为无量纲概率/关联 **通过**。

但有一个**深层次问题**：若V是"因果交易机会的总量"，其量纲应与"机会×速率"相关。但在当前定义中它是纯无量纲数之和。这不是量纲错误，而是物理解释与数学定义的对应关系需澄清——Lyapunov函数的物理意义（"未被利用的套利空间"）与数学定义（概率距离）之间缺少一个速率因子γ₀的联系。

## Q2 方向检查

### 2.1 单调性定理 dχ_{ij}/dt ≥ 0

**单边证明审查（§1.6）：**
- dχ/dt = 4γ₀ q_i P(+,−)
- P(+,−) ≥ 0 由概率公理保证
- 若q_i > 0, γ₀ > 0，则dχ/dt ≥ 0 **严格成立**。
- 等号当且仅当 P(+,−)=0（即χ = 4(1-q_i)q_j，上界饱和）**通过**。

**网络推广（§1.7）：** dχ_{ij}/dt ≥ 0 对每个边在网络中**未单独证明**。网络中dχ_{kl}/dt涉及三项期望（§1.4展开），符号不由单边简化控制。B博士的正确做法是不声称网络情形的逐边单调性，而是诉诸Lyapunov论证。

### 2.2 q_j^f边界检查：关键发现

**B博士声称：** "q_j^f > 0（系统不自发走向q=0）"

**精确分析：**
q_j^f = K₀/4 = [χ(0) + 4q_i q_j(0)]/4

从Fréchet下界：χ(0) ≥ -4 min[(1-q_i)(1-q_j(0)), q_i q_j(0)]

取最紧情形（χ(0) = -4q_i q_j(0)，对应P(--)=0）：
K₀ = -4q_i q_j(0) + 4q_i q_j(0) = 0 → **q_j^f = 0**

取另一情形（χ(0) = -4(1-q_i)(1-q_j(0))，对应P(++)=0）：
K₀ = -4(1-q_i)(1-q_j(0)) + 4q_i q_j(0) = -4 + 4q_i + 4q_j(0) 
这在q_i + q_j(0) < 1时可以为负 → q_j^f < 0 → **概率论禁止**。

**但q_j^f < 0意味着χ(0) < -4q_i q_j(0)，而Fréchet下界保证χ(0) ≥ -4q_i q_j(0)**（因为-4q_i q_j ≥ -4(1-q_i)(1-q_j)当q_i+q_j≥1时反转）。仔细检查：min[(1-q_i)(1-q_j), q_i q_j] ≤ q_i q_j总是成立（因为min ≤ 二者），所以 χ ≥ -4·min ≥ -4q_i q_j。这意味着K₀ ≥ 0总是成立，即q_j^f ≥ 0。

**结论：** q_j^f = 0在χ(0) = -4q_i q_j(0)时可以实现（虽然这是Fréchet下界的极端点，实际系统中是否可达是另一个问题）。q_j^f > 0的**普适性声称是不准确的**——应在该声张中加上"除Fréchet下界饱和的极端情形外"。

**严重性：** 中低。这不破坏主要结论（χ刹车机制不依赖q_j^f>0），但声称应精确化。

### 2.3 Fréchet-Pareto等价定理的双向证明

**(⇒)：** "若∃(i,j): χ_{ij} < 4(1-q_i)q_j，则P(+,-) > 0，跳转L_{ij}可执行，j获得因果确定化而不减少任何其他格点的C值——在成对独立性假设下——因此不在前沿上。"

**问题：** "不减少任何其他格点的C值"依赖于"成对独立性假设"（即χ是充分统计量）。在有向图上，单次跳转改变s_j，从而改变所有涉及j的二阶矩C_{kj}和高阶累积量。这些改变可能在成对独立性假设下被忽略，但在实际系统中，一次跳转可能降低某些C_{kj}（从而压低某些"因果确定化"）。"帕累托改进"的声明需要更强的论证，或明确限制在成对独立族中。

**(⇐)：** "若所有边上χ_{ij}=4(1-q_i)q_j，则P(+,-)=0，无跳转可能，无帕累托改进可能，在前沿上。"

**通过。** 这是平凡的事实：无跳转→无可达改进→在前沿（在当前动力学下）。注意"帕累托前沿"在此被定义为"通过DGF动力学可达的帕累托最优配置集合"——这是一个有意义的但狭窄的定义。任何在此动力学下不可达但仍满足χ=F的上界的配置按此定义都在前沿上。

**整体评价：** 双向证明逻辑自洽，但(⇒)方向需要在三阶以上相关不可忽略时更小心地陈述。

## Q3 循环论证检查

### 3.1 "单边精确可解"是否依赖孤立假设？

**B博士的做法：** 在§1.6中先解孤立边i→j（无其他边连接i或j），得到精确解；然后在§1.7中将洞察推广到网络。

**孤立假设是否正当：** 是。孤立边情形是一个**明确定义的简化模型**，其解为：
- 证明了dχ/dt ≥ 0（单边单调性）
- 推导了守恒量χ + 4q_i q_j = const
- 给出了终值公式

这些结果在孤立假设下是严格正确的。问题在于B博士**如何使用**这些结果：

**推广到网络时B博士的路径：**
1. 构造Lyapunov函数 V_{ij} = 4(1-q_i)q_j - χ_{ij}（受单边解启发）
2. 论证dV/dt ≤ 0在"主导阶"成立
3. 明确标注"这不能严格证明但可数值检验"

**评估：** 这不是循环论证——B博士没有说"单边成立所以网络成立"。他提供了独立的（尽管不完整的）Lyapunov分析，并诚实地标注了限制。推广路径是启发式的（单边洞察→猜想→数值检验），这一路径在方法论上可以接受。

### 3.2 Lyapunov函数构造是否预设了收敛结论？

**审查：** V的定义是V = Σ[4(1-q_i)q_j - χ_{ij}]，其中4(1-q_i)q_j是Fréchet上界的相关分量。这一定义来自概率论（Fréchet边界），而非来自动力学。它独立于任何收敛预设。

**深层验证——dV/dt的首阶分析：**

对单边(i,j)上一次跳转的直接效应（自己推演）：
- dV_{ij}^{direct} = 4(1-q_i) dq_j - dχ_{ij}
- = 4(1-q_i)(-γ₀ P dt) - (4γ₀ q_i P dt) = -4γ₀ P dt < 0 ✓

**间接效应**（跳转改变q_j → 影响出边V_{jk}）：
- dV_{jk} ≈ ∂V_{jk}/∂q_j · dq_j = (-4q_k)(-γ₀ P dt) = 4γ₀ P q_k dt > 0

净效应（对目标节点j的degree-d出度）：
- dV_{net} ≈ 4γ₀ P [Σ_{k∈∂^{out}_j} q_k - 1] dt

**关键发现：** 当Σ_{k} q_k > 1时，dV_{net} > 0（V增加而非减少）。在2D方格（度=4）上，若j的4个出邻居都有q_k ≈ 0.5，则Σq_k = 2 > 1，dV > 0。

**这不是严格分析**（忽略了χ_{jk}的二阶变化），但它揭示了：dV/dt ≤ 0在对q_k求和的约束条件下成立，而非无条件的。B博士在§1.7只说这是"主导阶论证"而未给出此量化分析。建议补充此分析，或至少标注"dV/dt ≤ 0的充分条件包括Σ_k q_k < 1"。

**结论：** Lyapunov构造本身未预设收敛（V的定义来自概率边界而非动力学），但dV/dt ≤ 0的论证目前是不完整的。B博士对此的透明标注（"不能严格证明但可数值检验"）是正确的处理方式。降级为"数值上可检验的猜想"是诚实的。

## Q4 替代解释检查

### 4.1 KMC能否区分χ刹车 vs 标准扩散弛豫？

**B博士的设计提供了三个测试层面：**

**(a) 定性层面（P1-A）：** Q(t_final) > 0 vs Q(t_final) → 0。标准DGF（无χ刹车）的最终状态是什么？由于无|1⟩→|0⟩逆过程，若所有|0⟩都有|1⟩邻居，系统终将消耗所有|0⟩（Q→0）。χ刹车预言Q停止在非零值。

**但有一个替代解释：** 若|0⟩区域在拓扑上被完全隔离（被|1⟩包围但无|1⟩邻居连接），也可出现Q_final > 0。这是"拓扑冻结"而非"χ刹车"。P1-A本身无法区分这两种机制。

**(b) 机制层面（P1-C）：** 这是关键的判别测试——直接测量P(+,-)并与χ比较。若Γ = γ₀[(1-q_i)q_j - χ_{ij}/4]成立且P(+,-)→0是因为χ→Fréchet边界（而非因为q_i→1或q_j→0），则χ刹车机制被验证。

**(c) 结构层面（P2, P3）：** 空间相关结构是额外证据。χ刹车预言了非平凡的χ(d)幂律衰减；标准扩散弛豫不产生此信号。

**评估：** 三层测试的设计可以区分χ刹车与替代机制。P1-C是最关键的。

### 4.2 P1-A阈值0.2的理论依据

**B博士未提供理论依据。** 阈值Q_final/Q_0 > 0.2的选择看起来是ad hoc的。

**审查推演：** 是否存在理论方法确定此阈值？

在单边情形中，q_j^f = (χ(0) + 4q_i q_j(0))/4。对初始无关联（χ(0)=0），q_j^f = q_i q_j(0)。若q_i ≈ 0.5（典型值），q_j^f = 0.5 q_j(0)，则Q_final/Q_0 ≈ 0.5。但这是单边情形——在网络中，多跳转和间接触发会改变此值。

在2D方格网络中，给定每个|0⟩有4个|1⟩邻居，每次跳转消耗一个|0⟩但可能生成新的|0⟩（通过非目标格点上的因果流动被挤出）。净效应取决于图拓扑和初始条件。

**建议：** 阈值0.2应标注为"经验性/启发式阈值，基于单边保守估计和2D度=4网络的数量级估计"，而非"理论上导出的判据"。理想的处理方式是在KMC中运行到真稳态（跳转率<10^{-6}R_0），然后报告Q_final，而非用固定阈值。

## Q5 落地计算

### 5.1 C_i "渐近守恒"的定量论证

**B博士的分析（§4.3）分四层：**

**(a) 无跳转极限：** 平凡。dq/dt=0 → C_i = const。这是已知的稳态性而非"渐近守恒"的证据。

**(b) 连续Noether对应：** B博士声称"全局C守恒来源于telegraph方程的Noether定理"。但附录A的尝试显示拉格朗日构造失败——Rayleigh耗散函数破坏时间平移不变性，导致dC/dt = -2R ≤ 0（递减而非守恒）。

**严重问题——内部矛盾：**
- §4.3(b)声称Noether定理**支持**C守恒
- 附录A结论是"连续拉格朗日量构造**不兼容**C守恒"

这两个声明直接矛盾。如果附录A是正确的（拉格朗日构造失败），则§4.3(b)中"全局C守恒来源于Noether"的说法没有数学基础。如果§4.3(b)是正确的（存在Noether推导），附录A应该能找到正确的拉格朗日量。

**这必须修正为：** 要么(i)删除§4.3(b)中关于Noether支持C守恒的声明，要么(ii)在附录A中给出正确的拉格朗日量，要么(iii)明确标注为"Noether推导的尝试尚未成功——C守恒目前是从微观主方程直接验证的全局性质，而非从对称性导出的守恒律"。

**(c) 单边极限：** 从§1.6精确解，dC_j/dt = -γ₀ q_i q̇_j/2 ≠ 0在过渡期。**这是C_i非守恒的正面证据，而非"可信性"证据。**

**(d) 诚实结论：** "C_i在过渡阶段不守恒"→定性正确。过渡阶段dC_j/dt ≠ 0已被严格证明。"渐近守恒"意味着lim_{t→∞} dC_j/dt = 0（在稳态），这是平凡的——任何达到稳态的量都"渐近守恒"。

**评估：** B博士的诚实标注值得赞赏，但论证结构有问题——(b)与附录A矛盾，(c)实际上削弱而非支持可信性。建议重组§4.3为：
1. 单边精确证明C_j在过渡期不守恒（严格结果）
2. 全局C守恒来自微观主方程的Σ求和而非Noether定理
3. C_i的"渐近守恒"仅在稳态定义下成立
4. 在R1论证中，真正起作用的是Fréchet边界（概率约束）而非C_i守恒

### 5.2 KMC伪代码审查

**算法逻辑正确性：**

Gillespie步骤（`step()`方法）：
1. `compute_rates()` → 枚举所有active edges，各赋γ₀速率。**正确**（等速率特殊情形）。
2. φ(Δt) = R_total·exp(-R_total·Δt) → `dt = rng.exponential(1.0/R_total)`. **正确**。
3. 按相对速率选择触发边 → `np.searchsorted(cumsum, rng.random()*R_total)`. **正确**。
4. `spins[j] = 1`. **正确**。

**问题1——效率：`compute_rates()`每次调用扫描所有N=10⁴个格点和4N条边 = 4×10⁴次检查。10⁷步 = 4×10¹¹次操作。纯Python下每操作约10⁻⁷秒 → 约4×10⁴秒 ≈ 11小时，这已超过"几小时"的乐观估计。而且早期阶段跳转频繁（R_total大），每步的dt很小（约10⁻⁴~10⁻³），10⁷步可能需要做。

**强烈建议：** 维护active edges的链表/集合，仅在跳转后局部更新（目标节点的4个出边+入邻居的出边）。可将复杂度从O(N)降至O(1)。

**问题2——`measure_observables()`中χ的瞬时估计：**
```python
chi_mean = chi_sum / n_edges  # spatial average of s_i*s_j
s_mean = np.mean(self.spins)
chi_bar = chi_mean - s_mean * s_mean
```
这用空间平均替代了时间系综平均，仅在平移不变条件下（IC-A）正确。对IC-C和IC-D（空间非均匀），此估计器有偏。B博士在docstring中标注了这一点，但**应在判据P1-B和P1-C的执行中使用滑动时间窗估计而非空间平均**——CorrelationAnalyzer类已经为此提供了基础但未在`measure_observables`中集成。

**问题3——死态检测效率：** `run()`方法在死态后每次仍调用`compute_rates()`（O(N)），直到`steps_since_last_jump > stop_if_dead`。建议在首次检测到无active edges后设置标志位，避免重复扫描。

**问题4——P1-C测试未在伪代码中体现：** 判据P1-C需要比较MC测量的P(+,-)与理论预测(1-q_i)q_j - χ/4。`CorrelationAnalyzer`未包含这一逻辑。应在伪代码框架中显式添加。
