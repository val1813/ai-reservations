# LP32-S7 研究计划

> 创建：2026-06-07
> 课题：因果创造项 — DGF框架热寂矛盾的解决

---

## 1. 核心矛盾（精确定义）

### 命题A：DGF动力学→确定化热寂

跳算子 L = |1⟩⟨1| ⊗ |1⟩⟨0| 只创造|1⟩，从不创造|0⟩。
Telegraph方程：∂²_t q + γ₀(1-q)∂_t q = c²∇²(ln q)

关键性质（telegraph_round3_final_report.txt已证明）：
- **质量不守恒**：d_t M + γ₀M - (γ₀/2)∫q²dx = C（守恒的是C，不是M）
- 当q<1：(1-q)>0 → 正阻尼 → 质量耗散
- 当q>1：(1-q)<0 → 反阻尼 → 质量注入
- q通常<1 → 净质量损失 → q终态<初始值
- H-theorem弱形式：时间平均dS/dt≥0，系统趋近均匀稳态
- **终态预言：q→q_eq<1，均匀分布→无结构→因果活动停止**

### 命题B：观测宇宙有持续非均匀结构

- 星系、恒星、行星→信息密度梯度极大且稳定维持
- 生命→局部极度非均匀信息密度，且能自复制创造新结构
- 宇宙膨胀→新时空区域持续进入因果视界
- 量子测量→|1⟩→|0⟩的坍缩（创造新的undetermined状态）

### 矛盾本质

DGF朴素框架的动力学方程描述的是一个**开放子系统**（质量流向隐藏库），但隐藏库的反馈机制未被建模。缺少的不是边界条件，而是一个**动力学创造项**。

## 2. 候选解决路径（5条）

### 路径P1：隐藏库反馈→创造项

telegraph方程中丢失的质量去了哪里？如果隐藏库有动力学，质量可以回流→创造新|0⟩。

∂_t q = D_0∇²(ln q)/(1-q) + **S(q, r, t)**

其中S(q, r, t)是源项，代表隐藏库→可见子系统的质量回流。

关键问题：S的形式能从A1+A2推出吗？还是需要新假设？

### 路径P2：因果层级+生成性

不是所有|0⟩→|1⟩等价。某些|1⟩是高势能的——触发后连锁释放多个因果事件，其中一些创造新|0⟩。

类型1（消耗型）：|1⟩_S |0⟩_E → |1⟩_S |1⟩_E（这就是L）
类型2（创造型）：某种过程把|1⟩变回|0⟩
  - 测量=波函数坍缩
  - 膨胀=新时空区域进入因果视界
  - 生命=局部熵减

类型3（层级型）：某些|1⟩触发级联，某些不触发

### 路径P3：局部因果守恒→非均匀稳态

守恒是局部的，不是全局的。局部守恒+拓扑约束→自然产生信息密度梯度。

L_{S→E}和L_{E→S}速率不对称 → 由因果结构本身（q场曲率）决定。
信息密度高处→因果事件成本高（阻塞多→阻尼大）→抑制进一步确定化。
信息密度低处→因果事件成本低→吸引因果流。

与GR质量弯曲时空同构——但对象是因果容量场，不是度规。

### 路径P4：帕累托前沿的拓扑结构

在因果守恒约束下，S和E之间的determination分配存在Pareto前沿。
前沿不是一条线——有拓扑结构。某些determination配置根本不可达。
前沿的非平凡拓扑→非均匀稳态自然涌现。

数学方向：用偏序集+序拓扑描述可达配置空间。

### 路径P5：创造项为A1+A2逻辑必然

最强声张：不引入新公理。A1（因果存在）+A2（容量有界）内在蕴含创造机制。

论证线索：
- A1说因果存在→不对称影响→方向性
- A2说容量有限→状态空间2^N→置换动力学
- CP^{N-1}+FS测地线偏离→telegraph方程
- 但CP^{N-1}的拓扑性质→某些置换路径回到已访问状态→等价于创造新|0⟩

## 3. 研究方法

遵循DGF路线图的方法论：
1. 用故事语言描述：如果DGF是真的，创造项应该是什么？
2. 找矛盾：现有推导和观测在哪里冲突？
3. 从A1+A2推：只用合法工具，不引入额外假设
4. 数值检验：修改telegraph方程→数值求解→验证无热寂稳态
5. 诚实标注：推出来的是定理，还是猜想，还是框架外

合法工具：Shannon信息论、Landauer原理、Cover定理、微分几何/偏微分方程、量纲分析、c/ħ/G作为实验校准常数。

禁用工具：薛定谔方程、爱因斯坦场方程、Lindblad方程、弗里德曼方程。
