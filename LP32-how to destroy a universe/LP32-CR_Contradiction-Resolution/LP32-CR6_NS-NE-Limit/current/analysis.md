## 1. 前提：S1 定理的已知形式

从 CR1 PI final ruling 重建的 S1 定理：

**最简形式（N_S = N_E）：**
```
P_reflux ≤ min(q_S/q_E, (1-q_E)/q_E)
```

**一般形式（任意 N_S, N_E）：**
```
P_reflux ≤ N_S * q_S / (N_E * q_E)
```

其中 N_S = S-系综格点数，N_E = E-系综格点数，q_S, q_E ∈ [0,1] 为各自未占用比例，P_reflux 为回流概率。

## 2. 显式计算：N_E >> N_S 极限

令 r = N_S/N_E << 1。一般形式化为：

```
P_reflux ≤ r * q_S / q_E
```

当 N_E → ∞（N_S 有限）：

```
lim_{N_E→∞} P_reflux ≤ 0
```

**Bound 趋近于 0，不是 ∞。**

### 物理参数下的数值

| N_S | N_E | q_S | q_E | r | Bound |
|:---:|:---:|:---:|:---:|:---:|:-----:|
| 1 | 10^8 | 0.5 | 0.1 | 10^-8 | 5e-8 |
| 10 | 10^12 | 0.5 | 0.1 | 10^-11 | 5e-11 |
| 100 | 10^23 | 0.9 | 0.01 | 10^-21 | 9e-19 |

在所有物理合理的参数下，bound << 1。回流在 N_E >> N_S 时几乎不可能。

## 3. 矛盾的诊断：方向反了

### SELECTOR_entry 记录的矛盾

> "一般形式在 N_E>>N_S（真实物理）极限下可能变得平凡（bound→∞，失去约束力）"

### 方向检查

```
bound = (N_S/N_E) * (q_S/q_E) = r * (q_S/q_E)
```

- N_E >> N_S ⇒ r << 1 ⇒ bound → 0（收紧！）
- N_E << N_S ⇒ r >> 1 ⇒ bound → ∞（平凡，才是失去约束力）

**SELECTOR_entry 的担心方向反了。** 物理真实情况 N_E >> N_S 对应 bound → 0——约束越来越紧。直觉错误的根源可能是将 r = N_S/N_E 误记为 N_E/N_S。

## 4. 物理含义验证

P_reflux → 0 as N_E → ∞ 在物理上正确且深刻：

1. **热力学对应：** 大环境 = 退相干不可逆。P_reflux → 0 表达"向环境不可逆丢失信息"——与标准开放量子系统理论一致。

2. **量子达尔文主义对应：** 环境作为信息汇，环境越大则信息冗余越多，逆转所需"集体反转"越不可能。

3. **N_S=N_E 假设的动机更清晰：** 最简形式 P_reflux ≤ q_S/q_E 只由容量比例决定，一般形式将规模因子 r 和容量因子 q_S/q_E 分开：r 控制渐近行为，q_S/q_E 控制有限规模修正。

## 5. 第二个 bound 的推广

最简形式有两个 bound：q_S/q_E 和 (1-q_E)/q_E。一般形式目前只有 N_S*q_S/(N_E*q_E)。

(1-q_E)/q_E 的推广形式 N_S*(1-q_E)/(N_E*q_E) 在 N_E → ∞ 时同样 → 0。但此推广是否成立需要独立验证——因为 (1-q_E)/q_E 来自 N_S=N_E 的对称性，在 N_S ≠ N_E 时可能需要独立的组合论证（低优先级）。
