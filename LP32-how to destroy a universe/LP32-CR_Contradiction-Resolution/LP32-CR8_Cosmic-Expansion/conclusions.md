## 一句话结论

新创造格点的初始q=1可以从q的定义（q=free_capacity/total_capacity）语义推论——不是循环。但宇宙膨胀本身（弗里德曼方程）尚未从DGF推导——这确实是输入而非推导。框架的诚实边界在此处：局部determination动力学是推导的，全局时空膨胀是输入的。

## 审稿人致命批评与修正

**审稿人指出:** 原文档声称"新空间=全|0⟩因为新格点尚未受因果影响"——但"全|0⟩"本身就是"新空间"这个概念的DGF翻译。如果"新空间"是指"所有格点都是|0⟩的空间"，那么"新空间=全|0⟩"是同义反复——"新空间"的定义中已经包含了"全|0⟩"。DGF声称自己是基础理论，但把需要推导的东西（为什么新空间是|0⟩）作为假设输入。

**修正:** 区分两个不同层面的问题。

## 问题分解

### 子问题1: 新创造格点在诞生时的q值是多少？

**回答:** q=1（全空，完全undetermined）。

**论证（非循环）:** 从q的语义定义出发：
- q = N_free / N_total = "未被占用的容量比例"
- "未被占用"的操作含义：该格点尚未被任何因果事件触及（其|0⟩→|1⟩转变尚未发生）
- 新创造的格点——在被创造的那个时刻——定义上尚未被任何因果事件触及
- 因此其初始状态必然是"未被占用"→ d_i=0 → 对总q的贡献是增加分母(N_total↑)而不增加分子(N_{|1⟩}不变)

这不是循环论证——这是q作为"未被占用容量比例"这个语义定义的直接推论。新格点的"新"意味着它在被创造前不存在，因此不可能在此前被占用过。这个推论的有效性等于q定义的语义一致性——不需要额外的物理假设。

**类比:** 在标准热力学中，如果一个系统的新增体积中没有粒子，那么新增区域的粒子数密度为0——这不是需要"推导"的物理发现，而是"粒子数密度"定义的语义推论。

### 子问题2: 宇宙膨胀本身（为什么有新格点被创造）从何而来？

**回答:** 尚未从DGF推导。当前输入广义相对论+暗能量。

**这是审稿人批评的正确核心：** DGF声称自己是基础理论框架，但"宇宙膨胀=新格点不断产生"这个动力学事实不是从DGF公理推导的——它是从标准宇宙学（弗里德曼方程+ΛCDM参数）输入的。

DGF当前的宇宙学架构：
```
外部输入（非推导）:            DGF推导:
广义相对论+暗能量              determination在格点间传播
→ 宇宙膨胀                     → q(t)演化
→ 新格点产生                   → 新格点的q=1（语义推论）
→ N_total(t)增加               → q被稀释
```

## 对q(t)单调性的影响

```
q(t) = N_{|1⟩}(t) / N_total(t)

dN_{|1⟩}/dt ≥ 0      (determination积累——由L_copy/L_swap驱动，DGF推导)
dN_total/dt > 0        (宇宙膨胀——新|0⟩格点加入，外部输入)

净效应: dq/dt 的符号取决于两项竞争
```

在ΛCDM参数下（H_0 ≈ 70 km/s/Mpc），新空间创造率远低于局部determination传播率→膨胀稀释效应小→q(t)单调递减仍近似成立。但严格来说，如果膨胀率足够大（极早期宇宙），q(t)可能暂时非单调——这不是bug，而是可计算的物理效应。

## 框架假设显式化（修订版）

在DGF框架中显式声明两个不同性质的假设：

> **宇宙学假设 C1（语义推论）:** 新创造的格点在诞生时的determination度为0（q_local=1）。此条从q的语义定义（未被占用容量比例）直接得出——新格点定义上尚未被任何因果事件触及。这不是独立物理假设，而是q定义在格点诞生这个事件上的应用。

> **宇宙学假设 C2（外部输入）:** 宇宙膨胀导致新格点不断产生，N_total(t)为增函数。DGF当前不推导宇宙膨胀的驱动机制——此条输入来自广义相对论+暗能量（ΛCDM）。如果DGF未来能推导出宇宙膨胀的驱动机制，C2将从外部输入变为推导结果。

### S2现象学模型中的处理（不变）
S2的DESI拟合（w_0w_a参数化）使用了观测宇宙学数据——这些数据天然包含了宇宙膨胀效应。S2的q(t)拟合结果已经隐含包含了膨胀对q的稀释。CR8的假设显式化是对S2已有处理的事后澄清——不需要修改S2的拟合结果。

## 诚实声明（修订版）

1. **"新格点q=1"不是循环——是q定义的语义推论。** 原文档的表述容易产生"循环论证"的印象，已修正为从q定义出发的显式推论。

2. **宇宙膨胀本身是输入，非推导。** 这是审稿人批评的正确核心。DGF当前的宇宙学是两层的：局部determination动力学（推导）+全局时空膨胀（输入）。声称"已从DGF推导宇宙膨胀"将是虚假的。

3. **极端宇宙学区域的定量预测缺失。** Inflation、Big Rip、bounce cosmology等场景中，新空间创造率可能极大——DGF在这些区域没有定量预测。这是诚实标注的限制。

4. **如果DGF未来能推导宇宙膨胀，C2将被消除。** 例如，如果determination积累的某种集体效应被证明等效于暗能量→弗里德曼方程，C2就从外部输入变成内部推导。这是长远目标——当前诚实标注。
