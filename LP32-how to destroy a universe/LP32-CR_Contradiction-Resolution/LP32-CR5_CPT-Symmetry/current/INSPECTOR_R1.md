## A博士 R1 检查

### Q1 量纲检查 — CPT破缺量级~10⁻²⁷的推导

**推导链:**
```
1-q ≈ GM/rc²（弱场近似）
实验室(1kg, 1m): 1-q = (6.67×10⁻¹¹ × 1) / (1 × 9×10¹⁶) = 7.4×10⁻²⁸ ≈ 10⁻²⁷ ✓
γ/γ₀ = 1-q
ε_CPT(DGF) ~ (1-q) × f(耦合强度) ~ 10⁻²⁷ × f
```

**量纲检验:**
- GM/rc²: [G]=m³/(kg·s²), [M]=kg, [r]=m, [c²]=m²/s² → (m³/(kg·s²) × kg) / (m × m²/s²) = m³/(kg·s²) × kg × s²/m³ = 1 → 无量纲 ✓
- γ₀ = c/ℓ_P: 1/时间 ✓
- γ(q) = γ₀(1-q): 1/时间 ✓
- 10⁻²⁷ vs 实验约束 10⁻¹⁸: 低9个数量级 → 远低于约束 ✓

**层级分离论证的量纲一致性:** γ→0 as q→1 直接来自 γ(q)=γ₀(1-q) 的定义——这是恒等式而非近似。在真空极限q=1时，γ精确为零。从q=1偏离→γ>0→T破缺。论证无近似漏洞。

**裁决: ✅ 量纲自洽。数值估计合理（实验室~10⁻²⁷，太阳表面~10⁻⁶）。与实验约束比较保守（最悲观假设下差9个数量级）。**

### Q2 方向检查 — "CPT定理不适用于Tier 0"的论证逻辑

**论证结构:**
```
大前提: CPT定理需要(A)洛伦兹不变性、(B)定域性、(C)自旋-统计、(D)厄米H、(E)谱条件
小前提: Tier 0运作在{0,1}^N上——无时空、无洛伦兹、无QFT结构
结论:   CPT定理不适用于Tier 0
```

**逻辑检验:**
- 大前提正确。CPT定理的前提列表准确（Pauli-Lüders-Jost）。
- 小前提正确。DGF的Tier 0公理（A1有向偏序 + A2容量上限）不涉及时空或QFT。
- 结论从前提有效推导。

**潜在反驳:** "如果Tier 0产生了涌现QFT，而涌现QFT必须满足CPT，那么Tier 0的T破缺如何不影响涌现QFT中的CPT？"

A博士在§3.3中正面回应了这个问题——"Tier 0 T破缺是否向涌现层级'泄漏'"——并将其标记为"核心定量问题"。论证分为四个通道（SRC机制、γ(q)阻尼、q场与标准模型场耦合、最诚实估计），最后结论是"即使在最悲观的假设下，不会与现有CPT实验约束冲突。"

**关键弱点标记:** §3.3(c)承认"q场如何与标准模型场耦合"是DGF目前最薄弱的环节。如果未来发现DGF的涌现机制必然要求q场-SM耦合，且此耦合必然传递T破缺而不被(1-q)压制——则当前论证需要修正。A博士将此标记为开放问题而非已决问题，诚实。

**裁决: ✅ 论证逻辑自洽。"泄漏"问题被诚实标记为开放问题。**

### Q3 循环检查 — 是否预设了层级分离来得出"不冲突"结论？

**检验:** 层级分离（Tier 0 vs Tier Effective）的来源是什么？

A博士的层级分离**不来自外部假设**——它来自DGF论文自身的分类：
- `two_rules_prd_final.tex` 明确区分 Tier 0 (Physical Axioms)、Tier 1 (Empirical Inputs)、Tier 2 (Modeling Choices)、Tier 3 (Derived Quantities)
- Lorentz Selection 机制（Sec. V）本身就是层级间的涌现：A2(容量限制)→γ∝(1-q)→真空q=1→γ=0→□(ln q)=0→洛伦兹不变

因此论证是：DGF**自己**区分了层级；CPT定理只适用于涌现QFT层级（因为只有那里有洛伦兹不变性）；因此Tier 0的T破缺不与CPT定理冲突。

**循环性检验:** 如果DGF的层级结构本身是任意的、为方便论证而设的——则有循环风险。但层级结构在DGF论文中有独立动机（Tier 0 = 不可还原的物理公理，Tier 2 = 建模选择，Tier 3 = 导出量）——不是为CPT论证特设的。因此非循环。

**是否存在更隐晦的循环:** A博士引用了DGF的Lorentz Selection论证（真空→洛伦兹恢复）来支撑"涌现层级有CPT"——但Lorentz Selection本身可能预设了CPT论证想要的结论（即层级间对称性传递可以发生而不会"污染"）。这并非严格循环（Lorentz Selection有独立物理动机），但两个论证互相强化可能掩盖各自的弱点。

**裁决: ⚠️ 非严格循环，但Lorentz Selection与CPT层级论证互相支撑——如果Lorentz Selection被后续攻击削弱，CPT论证也受影响。**

### Q5 Polonyi↔DGF映射表的形式正确性

**映射表（§2.3附近）:**

| Polonyi概念 | DGF对应物 | 检验 |
|------------|----------|:---:|
| 环境初始条件 | 全|0⟩初始条件 | ⚠️ 方向不同 |
| ε-处方的非均匀收敛 | γ(q)=γ₀(1-q): γ→0 as q→1 | ✅ 结构同构 |
| 基本方程的T对称 | Level 0对称因果(CP^{N-1}) | ❌ 方向相反 |
| 有效理论的T破缺 | Level 2 telegraph方程γ∂_t q阻尼 | ✅ 结构同构 |
| 真空中的对称恢复 | q=1真空: γ=0 → □(ln q)=0 | ✅ 结构同构 |

**核心问题: 映射方向相反。**

Polonyi的机制：
```
基本方程(T对称) → 环境初始条件 → 有效理论(T破缺)
                 ↓ 封闭系统极限
                T对称恢复
```

DGF的机制（按A博士重构）：
```
A1(T破缺) → 容量约束(γ∝1-q) → 物质区域(T破缺) / 真空(T对称恢复)
```

关键区别：在Polonyi中，**T对称是基本的，T破缺是涌现的**。在DGF中，按A1原始措辞，**T破缺是基本的，T对称在真空中涌现恢复**。两者方向相反。

A博士在§2.3末尾注意到了这个区别（"Polonyi: T对称在基本层面，T破缺在有效层面。DGF: T破缺在基本层面，T对称在涌现真空层面"），但映射表本身（上文引用的5行映射表）未充分标注这个方向差异。映射表中的"基本方程的T对称 → Level 0对称因果"尤其误导——因为DGF的Level 0按A1原始措辞不是T对称的。

**但:** 如果接受A博士的§2.4建议（将A1的"irreversible"改为"directed"），则Level 0变成"结构不对称但动力学中性"——更接近Polonyi的图景。此时映射表中的方向差异缩小。

**裁决: ⚠️ 映射表概念上有价值，但忽略了Polonyi和DGF之间"基本对称性方向相反"的关键差异。映射表中的"Level 0对称因果"条目与A1原始措辞("irreversible influence")有张力——除非接受A1措辞修改。**

## B博士 R1 检查

### Q2 方向检查 — Chomsky深层对称→表层不对称 ↔ DGF Level 0→Level 1

**B博士的映射方向:**

语言学: UG (深层对称Merge) → Linearization/Spell-Out (表层不对称)
DGF:    Level 0 (对称因果?) → Level 1 (涌现T破缺)

**方向一致性检验:**

B博士的映射预设DGF的Level 0是**对称的**（像UG的Merge一样）。但DGF的A1明文写着"asymmetric, irreversible influence"——Level 0在DGF自己的表述中是**不对称的**。

B博士对此的处理（隐式地）: 将A1的"不对称"重新解释为涌现属性（类似语言学的linearization不对称），认为"深层"（格点动力学）可能实际上是对称的，只是"表层"（有效理论）表现出不对称。

**这是重大概念跳跃。** B博士未在正文中充分标注这个跳跃：映射假设Level 0是对称的，而DGF自身声称Level 0是不对称的。如果Level 0确实不对称（按A1当前措辞），则深层对称+表层不对称的映射在起点就断裂了。

**裁决: ⚠️ 映射方向的一致外观依赖对A1的重新解释（Level 0对称→Level 1不对称）。如果DGF坚持A1的原始措辞（Level 0本身不对称），则Chomsky映射的方向与DGF的方向相反——语言学是"深层对称→表层不对称"，DGF按A1原始是"深层不对称→表层对称恢复"。此差异在正文中未被充分标注。**

### Q3 循环检查 — 是否预设了语言学框架的正确性来论证DGF？

**检验:** B博士是否以"语言学正确"为前提来论证"CPT兼容"？

B博士§7.3明确声明："这个类比是**启发式的，非推导性的。** 它不能证明DGF的T破缺与CPT兼容——它只能(a)指出逻辑可能性，(b)提出新的观测渠道，(c)为A博士的QFT推导提供概念蓝图。"

这表明B博士清楚认识到类比的局限性。类比的角色是：
1. 概念澄清（"深层与表层可以有不同的对称性"）
2. 假设生成（CPT破缺的edge-first模式）
3. 非推导性（不声称从语言学"推导"出了物理结论）

三处自我攻击（§7）进一步强化了诚实性：B博士明确否定了类比能证明任何东西。

**但有一处隐式循环:** §5.2论题1说"DGF的A1因果单向性不与标准模型CPT守恒直接冲突，因为它们操作在不同的'句法层级'上。"这里的"句法层级"概念来自Chomsky——但DGF的层级（Tier 0/1/2/3）是DGF自己的分类，不需要语言学来建立。B博士似乎在用语文学框架"重新发现"DGF已有的层级结构——这在概念上不增加新内容。

**裁决: ⚠️ 非严格循环（B博士有充足的自我限定），但语言学框架对"层级"的论证是冗余的——DGF已有自己的Tier分类。B博士的独特贡献是Phase Theory的边缘效应预测，而非层级分离本身。**

### Q6.4 替代解释 — "层级分离"是否是比Chomsky映射更简单的解释？

**A博士的层级分离:** 使用DGF内部的Tier结构 + CPT定理的适用范围 + 涌现对称恢复 → "不冲突"结论。零外部假设。

**B博士的Chomsky映射:** 使用语言学P&P+Phase Theory → 深层/表层层级独立性 → "不冲突"结论 + phase-edge预测。需要：语言学框架的映射有效性 + Phase Theory类比成立 + 多步类比翻译。

**Occam's Razor比较:**

| 维度 | A博士层级分离 | B博士Chomsky映射 |
|------|:---:|:---:|
| 外部假设数量 | 0 | 整个Chomsky框架 + 映射有效性 |
| 概念步骤 | 3步（层级识别→CPT前提检验→结论） | 10+步（UG映射→参数映射→Phase映射→PIC翻译→...） |
| 是否修改DGF | 建议修改A1措辞（删除"irreversible"） | 隐式要求重新解释A1（Level 0对称而非不对称） |
| 产生新预测 | 1个（引力势相关的CPT破缺） | 4个（BEC声学视界、CMB T-odd、edge-first模式、参数重置） |
| 数学严格性 | QFT公理 + EFT层级 | 无——纯类比 |

**裁决: A博士的层级分离是更简单的解释（更少假设、更直接、不依赖跨学科映射）。B博士的Chomsky映射不"更简单"——但它产生了A博士论证未产生的额外可检验预测（特别是edge-first CPT破缺模式和phase-edge CPT增强守恒）。**

**关键判断:** 层级分离是"为什么兼容"的**解释**；Chomsky映射是"兼容意味着什么可观测量"的**预测生成器**。两者在不同维度上竞争——简单性维度上A博士胜，预测丰富性维度上B博士胜。

**裁决: ✅ A博士的层级分离在简单性上更优。B博士的类比不替代而应补充——如果Phase-Edge预测被实验验证，类比的启发价值获得后验支持。**

## CR5 汇合检查

### A博士的"层级分离" vs B博士的"深层对称+表层不对称" — 是否收敛到同一核心洞察？

**核心洞察提取:**

- A博士: Tier 0(T破缺) 和 涌现QFT(CPT守恒) **运作在不同理论层级** → 不冲突
- B博士: 深层(对称/不对称) 和 表层(不对称/对称) **操作在不同"句法层级"** → 不冲突

**共享内核:** 层级分离/分层解耦 — 不同层级的对称性不必相同，互不"污染"。

**关键差异（对层级内容的相反假设）:**

| | A博士 | B博士 |
|---|-------|-------|
| Level 0的性质 | T破缺（按A1原始措辞） | T对称（按UG类比） |
| Level 1的性质 | T对称恢复（真空）/ T破缺（物质） | T破缺（涌现） |
| 方向 | 基本T破缺 → 涌现T对称 | 基本T对称 → 涌现T破缺 |

**这意味着:** 两人得出的"不冲突"结论共享相同的逻辑结构（层级分离），但对层级的**内容**有相反的理解。A博士接受DGF的A1原始措辞（Level 0不对称），B博士将A1重新解释为类似"linearization"的涌现属性（Level 0可能对称）。

**汇合判定:** **逻辑结构汇合（层级分离解耦），物理内容不汇合（对Level 0对称性的相反假设）。**

这是一个有趣的局面：
- 在**诊断**层面完全汇合 = "CPT兼容因为层级分离"
- 在**本体论**层面不汇合 = "Level 0究竟是对称还是不对称？"

**对PI的诚实标注:** 如果DGF坚持A1的原始措辞（"asymmetric, irreversible"），B博士的UG类比存在起点张力（UG=Merge对称，DGF Level 0=A1不对称）。如果DGF接受A博士的措辞修改建议（删除"irreversible"，"asymmetric"→"directed"），B博士的类比张力缩小但仍存在方向差异（语言学是深层对称→表层不对称；DGF即使修改后仍是深层有向→表层有时对称恢复）。

**裁决: ⚠️ 逻辑汇合（层级分离），本体论不汇合（Level 0对称性）。建议CR5 Round 2以此为核心争辩点。**
