## Q-1.1: 命题A (DGF的q场→γ_PPN=-1) 是否有独立推导证据？

### 推导链追溯

**DGF Level 0 (纯共形) 的推导链:**

```
telegraph方程 (∂²_t q + γ₀(1-q)∂_t q = c²∇²(ln q))
    ↓ 静态极限 (∂_t q = 0)
∇²(ln q) = 0
    ↓ 球对称边界条件 q(∞)=1
q(r) = e^{-GM/rc²}
    ↓ 度规假设: g_μν = q² η_μν (纯共形)
g_μν = e^{-2GM/rc²} η_μν
    ↓ 弱场展开
g_00 = -1 + 2GM/rc² - 2(GM/rc²)² + ...
g_ij = (1 - 2GM/rc² + ...) δ_ij
    ↓ PPN度规形式: g_ij = (1 + 2γU)δ_ij, U = GM/rc²
1 - 2U = 1 + 2γU → γ = -1
```

### 推导链的完整性检查

| 步骤 | 状态 | 漏洞评估 |
|------|------|---------|
| Telegraph方程→静态极限 | ✅ 数学精确 | 静态极限是∂_t q=0, 二阶时间项消失, 方程退化为∇²(ln q)=0 |
| ∇²(ln q)=0 → q(r)=e^{-GM/rc²} | ✅ 数学精确 | 球对称拉普拉斯方程的标准解, 边界条件正确 |
| q(r) → g_μν = q² η_μν | 🔴 **关键假设** | **这是DGF的早期假设, 不是推导结果。** DGF论文中, 从q场到度规的映射是: 引力加速度a=-c²∇q, 等效度规g_00=-(1+2Φ/c²)其中Φ来自q, 但g_μν=q²η_μν是**额外假设** |
| g_μν=q²η_μν → γ=-1 | ✅ 代数精确 | 纯共形度规的PPN展开唯一给出γ=-1 |

### 关键发现

**命题A的推导链中, "g_μν = q² η_μν" 这一步是假设, 不是推导。**

DGF论文(见DGF_complete_summary.md)中, 从q场导出的物理量是**引力加速度** a = -c²∇q → 牛顿极限。将q场"提升"为完整度规时, DGF论文做了纯共形假设 g_μν = q² η_μν。这个假设的来源是: q场控制信息容量, 信息容量决定"有效距离", 有效距离由度规描述 → 最简单的共形映射。

但这**不是唯一的选择**。q场可以提供引力势的信息论起源, 而完整的张量引力(h_μν)可以从其他原理(如作用量变分)获得。

**S3已经改变了这个局面。** S3的作用量变分路线产生的是完整场方程:
```
2F(q) G_μν + 2(g_μν□ - ∇_μ∇_ν)F = T_μν^(m) - T_μν^(q,kin) + g_μν V
```
其中度规g_μν由整个场方程求解, 不是人为设定为q²η_μν。在q→1极限下, F(1)=1/(16πG), 场方程退化为标准GR: G_μν = 8πG T_μν^(m) → γ=+1。

### Q-1.1判定

命题A (γ=-1) 的推导链在"g_μν = q²η_μν"这一步存在致命跳跃——这是**假设**而非**推导**。在S3建立完整场方程后, 这个假设被更根本的作用量变分原理替代。**命题A是pre-S3 DGF的产物, 不代表完整S3理论的预言。**

## Q-1.2: 命题B (Cassini测量排除γ=-1) 是否有独立实验证据？

### 核心实验

**Bertotti, Iess & Tortora (2003), Nature 425, 374-376**

- **方法:** Cassini航天器2002年太阳合期间的无线电多普勒跟踪
- **物理原理:** Shapiro时间延迟的频率导数(Doppler频移)
- **测量值:** γ = 1 + (2.1 ± 2.3) × 10⁻⁵
- **等效排除:** γ = -1 被排除到 > 10⁵ σ (因为γ=-1相对于γ=+1的差异是Δγ=-2, 而σ_γ=2.3×10⁻⁵, 所以|-2|/2.3×10⁻⁵ ≈ 8.7×10⁴ σ)

### 多信使补充约束

| 实验 | 约束 | 精度 | 来源 |
|------|------|------|------|
| Cassini 2002 | γ = 1 ± 2.3×10⁻⁵ | ~2.3×10⁻⁵ | Bertotti et al. (2003) |
| GW170817+GRB170817A | \|c_g/c - 1\| ≤ 10⁻¹⁵ | ~10⁻¹⁵ | LIGO/Virgo + Fermi (2017) |
| GW170817 γ_GW-γ_EM | -2.7×10⁻⁷ to 1.2×10⁻⁶ | ~10⁻⁶ | Shapiro delay comparison |
| Lunar Laser Ranging | 等效γ约束 | ~10⁻⁴ | 多年代激光测距 |
| BepiColombo (进行中) | 预期Δγ~10⁻⁶ | ~10⁻⁶ | Mercury orbiter |

### 可能的系统误差

1. **太阳质心运动 (Kopeikin et al.)** — 有争议, 若正确则Cassini约束可能放宽到~10⁻⁴水平。但主流认可原始Bertotti分析。
2. **等离子体色散** — 已通过Ka/X双频校准消除(这是Cassini实验的核心创新)。
3. **高阶层析修正** — Ashby & Bertotti (2010) 已处理O(m²R/b²)修正项。

### Q-1.2判定

**命题B有极其坚实的独立实验证据。** Cassini测量精度~2.3×10⁻⁵, 等效排除γ=-1到>10⁴σ。GW170817提供了大尺度独立验证。即使考虑Kopeikin的系统误差争议(Cassini可能放宽到~10⁻⁴), γ=-1仍然被排除到>10²σ。

**但S3已经改变了命题A的基础:**

### S3的f(q)R理论给出的γ_PPN

S3场方程的核心结构:
```
S = ∫ d⁴x √(-g) [F(q)R + (1/2κ)(∂q)²/q² + V(q)] + S_matter[ψ, g_μν]

F(q) = 1/(16πG) + ξ(q)
ξ(1) = 0 (真空恢复GR)
ξ'(1) = 0 (真空稳定 — 关键!)
```

**映射到标量-张量理论 (Brans-Dicke形式):**

定义 ϕ = 16π F(q) = 1/G + 16π ξ(q), 作用量化为:
```
S = (1/16π) ∫ d⁴x √(-g) [ϕR - (ω(ϕ)/ϕ)(∂ϕ)² - V(ϕ)] + S_matter
```

其中等效Brans-Dicke参数:
```
ω(ϕ) ∝ 1/[ξ'(q)]²
```

**在太阳系中 (r ~ 1 AU, q ≈ 1):**
- q偏离1的量级: 1-q ≈ GM_⊙/(c²·1AU) ≈ 10⁻⁸
- ξ'(q) ≈ ξ''(1)(1-q) + ... (因为ξ'(1)=0)
- 因此 1-q ~ 10⁻⁸ → ξ'(q) ~ 10⁻⁸ ξ''(1) → 非常小
- ω(ϕ) ∝ 1/(10⁻¹⁶) → **ω → ∞**
- B-D PPN公式: **γ = (1+ω)/(2+ω) → 1**

**在远离源处 (r → ∞, q → 1):**
- 理论精确恢复GR → γ = +1

**在强场区域 (q显著偏离1, r < 100 r_s):**
- ξ'(q) ≠ 0 → ω有限 → γ偏离+1
- 这正是B博士B3预言的内容: r=10-50 r_s处度规偏离Kerr 1-5%
- 但太阳系不是强场 — 太阳系在弱场极限, 此处理论自动给出γ=+1
