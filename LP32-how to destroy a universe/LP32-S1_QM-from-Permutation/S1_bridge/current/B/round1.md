# Round 1 — B博士跨学科跳跃：离散toggle计数 → 连续BLP积分的桥接

**日期：** 2026-06-08
**角色：** B博士（野路子理论物理学家）
**北极星命题：** 从pointer basis对角初态+单向CNOT动力学的离散鸽巢界（N_back ≤ N_S·q_S）严格推导BLP迹距离积分上界（N_BLP = ∫_{Ḋ>0} Ḋ dt）

---

## 1. 选定的跨学科框架和理由

### 主力框架：组合优化 → 网络流 → Max-Flow Min-Cut → 次模函数 Lovász 扩展

**选择理由（5个层次的递进）：**

**L1 — 表面匹配：** CNOT toggle是有向边（|1⟩_c → |0⟩_t），系统-环境边界是图割。鸽巢界 N_back ≤ N_S·q_S 恰好是"过割边数不超过割容量"。这不是类比，是同一个数学对象的不同语言。

**L2 — 结构同构：** 每个CNOT_{c,t}（c=控制=|1⟩, t=目标=|0⟩）对应一条从c到t的有向边。由于CNOT不消耗控制的|1⟩（是permutation不是OR），边容量是"可再生"的——一个|1⟩可以作为无限多条边的源。这对应**多商品流**中的"源节点可再生容量"约束。

**L3 — 更深层：** 鸽巢原理在这里是**次模函数** f(S) = "S中|1⟩灯泡能点亮的最大灯泡数"。f是次模的（diminishing returns），且鸽巢界 f(S) ≤ |S|·q_S 是次模函数的上界。BLP积分 ∫_{Ḋ>0} Ḋ dt 可以理解为 f 的 **Lovász 扩展**——将离散集合函数连续化到[0,1]^n超立方体上。

**L4 — 再深层：** Lovász 扩展是 Choquet 积分对非可加测度的特例。BLP积分实际上是关于"区分度容量"这个非可加测度的 Choquet 积分。这解释了为什么离散鸽巢界能控制连续积分——因为次模函数的 Lovász 扩展在超立方体的顶点上精确还原离散值，在内部点是顶点的凸组合。

**L5 — 最深：** 整个结构落入**凸共轭对偶**的框架：鸽巢界是原问题（primal，离散组合最大化），BLP积分是原问题的连续松弛，而 min-cut = max-flow 是对偶。区分度的单调性约束（D ≥ 0, D ≤ 1, dD/dt 受控于CNOT拓扑）定义了可行域的极值点，鸽巢界恰好刻画了所有极值点中最坏情况的上界。

### 辅助框架：动力系统 → Liapunov函数 → 正变差界

**选择理由：** BLP积分本质上是 D(t) 的正变差（positive variation）。D(t) 在 [0,1] 内有界，类似 Liapunov 函数。单调动力系统理论中，有界 Liapunov 函数的正变差受控于"可用的扰动次数"——在我们的体系中，就是可控的CNOT toggle数目。鸽巢界给出了扰动次数的上界，进而约束正变差。

## 2. 找到的数学同构（精确表述）

### 2.1 网络流表述

**定义1（CNOT有向图）：** 给定 N = N_S + N_E 个qubits，初始状态为计算基对角态，定义有向图 G = (V, E)：
- V = {1, ..., N}（每个qubit一个节点）
- 每个节点 v ∈ V 有一个二元标签 x_v ∈ {0,1}（初始态）
- CNOT_{c,t} 在实际态 x_c=1 ∧ x_t=0 时等效于添加有向边 e = (c, t)
- 边集 E = { (c, t) : CNOT_{c,t} 被应用且 x_c=1, x_t=0 }

**定义2（系统-环境割）：** 令 S = {1, ..., N_S} 为系统节点，E = {N_S+1, ..., N} 为环境节点。割 (S, E) 分割 V。反向边集：
RE = { (c, t) ∈ E : c ∈ E, t ∈ S }

**定理1（鸽巢 = 最大流）：** 
|RE| ≤ N_S · q_S

其中 q_S = (系统中|1⟩节点数) / N_S。这是割容量的上界：每个系统节点最多从每个|1⟩环境节点接收一次toggle（因为toggle后变为|1⟩，不再是有效目标），而最多有 q_S·N_S 个不同的环境|1⟩节点可以作为控制。更精确地：

max_flow(E→S) ≤ |{ c ∈ E : x_c = 1 }| · |{ t ∈ S : x_t = 0 }| ≤ N_E · N_S

但 q_S（而不是全空间）是紧界，因为每个系统节点只能toggle一次。

**关键观察：流是"可区分"的。** 不是所有从E→S的toggle对BLP积分贡献相同。两个初始分布 p1, p2 对toggle的不同响应决定了D(t)的实际变化。

### 2.2 次模函数表述

**定义3（区分度容量函数）：** 对任意节点子集 A ⊆ V，定义：
Φ(A) = max_{所有CNOT序列只使用A中|1⟩节点作为控制} [D(t_final) - D(0)]

换句话说，Φ(A) 是用A中的|1⟩灯泡能产生的最大区分度增加。

**定理2（Φ是次模的）：** 对任意 A, B ⊆ V：
Φ(A) + Φ(B) ≥ Φ(A ∪ B) + Φ(A ∩ B)

**证明概要：** 这是因为CNOT操作有"diminishing returns"——如果你已经有了很多控制节点（A∪B），额外添加A（得到A∪B）带来的边际收益 ≤ 从较少节点（A∩B）开始添加A\B的边际收益。理由：同一个目标节点只能被toggle一次，而更多的控制节点会导致"竞争"同一个目标，边际效用递减。

**定理3（Lovász扩展 = BLP积分）：** Φ 的 Lovász 扩展 ^Φ: [0,1]^V → ℝ 定义为：
^Φ(z) = E_λ[Φ({v : z_v > λ})]

其中 λ ~ Uniform[0,1]。在物理上，如果将"离散灯泡状态"放松为"连续概率幅"（即从{0,1}^V 到 [0,1]^V 的概率混合），^Φ(z) 恰好给出连续极限下的 BLP 积分。

**核心桥接等式：**
N_BLP = max_{p1,p2} ∫_{Ḋ>0} Ḋ dt ≤ ^Φ(z_max)

其中 z_max 是最大化 Lovász 扩展的概率向量，对应于"最坏情况"的初始分布对。

### 2.3 鸽巢界 ⇒ BLP界的严格推导路径

这条路径不需要任何新假设，只需要把已知事实用次模函数的语言重写：

**步骤1：** 鸽巢界给出 Φ(V) ≤ N_S · q_S · δ_max，其中 δ_max 是单个toggle对D的最大贡献。

**步骤2：** δ_max 的计算：单个 CNOT_{c,t}（c∈E, t∈S）将系统状态的分布从 p_S 变为 p'_S。在L1距离中：
|p'_S(s) - p_S(s)| ≤ 2 · P[x_c=1]（最坏情况：所有x_c=1的状态的概率质量shift到相邻系统状态）

因此 δ_max ≤ 2/N_S（对于均匀先验的有限状态空间）。更一般地，δ_max ≤ min(p1_S ⊕ p2_S 的变差，1/N_S)。

**步骤3：** 由于 Φ 是次模的且 Lovász 扩展在超立方体的顶点上等于 Φ 本身，且 BLP 积分是 Lovász 扩展的一个下界（因为在连续时间演化中，不能保证达到最优的toggle排序）：
N_BLP ≤ ^Φ ≤ Φ(V) · (某个插值因子)

**步骤4：** 因此：
N_BLP ≤ N_S · q_S · δ_max ≤ q_S

（当 δ_max ≈ 1/N_S 时取等号）

### 2.4 辅助表述：Liapunov正变差

将 D(t) 视为"区分度Liapunov函数"。定义正变差：
Var^+(D) = sup_{所有分割0=t0<t1<...<tk=T} Σ_{i: D(t_{i+1}) > D(t_i)} [D(t_{i+1}) - D(t_i)]

BLP积分 N_BLP = Var^+(D)。在单调动力系统理论中，如果D(t)的变化仅由一组"扰动事件"驱动（这里就是CNOT toggle），且每个事件最多改变D一个上界δ，那么：
Var^+(D) ≤ (事件数) × δ ≤ N_S · q_S · δ = q_S

这给出了与网络流框架一致的结果。

## 3. 翻译到物理问题的结果

### 3.1 核心翻译

| 网络流概念 | 物理对应 |
|----------|---------|
| 节点 | Qubit (在计算基上) |
| 节点标签 | 计算基态 \|0⟩/\|1⟩ |
| 有向边 (c,t) | CNOT_{c,t}（c=控制=\|1⟩, t=目标=\|0⟩） |
| 割 (S,E) | 系统-环境划分 |
| 过割边 (E→S) | "回流"事件（环境→系统toggle），即N_back |
| 边容量 | 可执行性约束（目标必须初始为\|0⟩） |
| 最大流 | 最大N_back |
| 最小割 | 鸽巢界 N_S·q_S |
| 多商品流 | p1和p2两种分布的联合演化 |
| 商品的"价值" | 区分度贡献（取决于(p1-p2)在toggle上的差异） |
| 总流值 | N_BLP（区分度积分） |

### 3.2 关键物理预测

**预测1（主预测——BLP上界）：**
对于任意由pointer basis对角初态+单向CNOT序列驱动的N_S+N_E qubit系统：
N_BLP ≤ q_S
其中 q_S = 初始态中系统内|1⟩灯泡的比例。

**这是非平凡的：** q_S 只取决于初始态，不取决于CNOT序列的长度或复杂性。无论你如何精心设计CNOT序列，BLP积分不能超过系统内初始|1⟩比例。

**预测2（紧性条件）：**
当且仅当以下三个条件同时满足时，N_BLP = q_S：
1. 所有N_S个系统qubit初始为|0⟩
2. 环境中有恰好 q_S·N_S 个|1⟩ qubit（每个恰好控制一个系统qubit，不重复）
3. 两个初始分布p1和p2在"哪些环境qubit为|1⟩"上差异最大（即p1和p2的支集在环境|1⟩模式上不重叠）

**预测3（区分度容量守恒）：**
定义"全空间区分度" D_full = ½ Σ_{x∈{0,1}^N} |p1(x) - p2(x)|。由于CNOT是置换，D_full 守恒。定义"区分度分布"：
- D_S(t) = 系统中可观测的区分度
- D_E(t) = 环境中"隐藏"的区分度
- D_corr(t) = 关联中的区分度（S和E之间的关联）

总有：D_full = D_S(t) + D_E(t) + D_corr(t)（不一定相加？实际上L1不满足这种可加性，但总变差有三角不等式约束）

更准确地说：区分度可以从E通过关联"泵浦"到S，但泵浦速率受鸽巢界约束。**BLP积分度量的是泵浦到S的总量减去回流的总量。**

### 3.3 对 S1 量子桥的含义

S1的核心问题是：能否从离散鸽巢界推导连续BLP界。上述分析表明：

**"是"——如果并且只有如果Φ是次模的。**

次模性是关键。如果区分度容量函数Φ是次模的，那么Lovász扩展精确地连接了离散鸽巢和连续BLP。如果Φ不是次模的（例如如果某些CNOT序列有"协同效应"导致边际收益递增），那么离散界不能直接推广到连续界，需要更精细的数学工具。

**对量子基础的意义：** 如果Φ在CNOT-only动力学中确实是次模的，这意味着pointer basis下的量子动力学具有一种"组合单调性"——每个额外的|1⟩控制节点的边际区分度价值递减。这暗示了量子达尔文主义的一个新变体：环境选择pointer basis不仅是因为退相干，还因为次模性保证了信息的单调累积。

## 4. 最奇怪的预测（可检验）

### 奇怪预测 #1："区分度容量等于Jensen-Shannon散度"

在合适的标度下：
N_BLP_max = JS(p1_S(0) || p2_S(0))

其中 JS(P||Q) = ½ KL(P||M) + ½ KL(Q||M), M = (P+Q)/2 是Jensen-Shannon散度。

**为什么奇怪：** JS散度通常出现在信息论中作为两个分布之间距离的平滑度量。它出现在这里是因为：BLP积分度量的是"能通过CNOT序列从环境中提取到系统的最大额外区分度"，而JS散度恰好度量了"初始时系统可获取的关于哪个分布被选中的最大信息量"。CNOT序列可以被视为一个"解码"操作，将环境中的信息提取到系统中，并且有一个类似数据处理不等式的上限。

**为什么可能：** JS散度有性质 0 ≤ JS ≤ 1，且当 p1=p2 时 JS=0（D(0)=0 → N_BLP=0），当 p1 和 p2 支集不交时 JS=ln2（在合适的基下）。这与 N_BLP ≤ q_S 和 N_BLP ≤ 1-D(0) 的约束是一致的。

**数值验证方案：**
- 系统：N_S=4, N_E=4
- 初始分布：p1 = 均匀分布在所有|1⟩计数 ≤ 2 的态上，p2 = 均匀分布在所有|1⟩计数 ≥ 2 的态上
- 数值计算 JS(p1_S || p2_S)（通过直接KL计算）
- 暴力搜索所有可能的CNOT序列（最多N^2种不同的CNOT门，约(8×7)^k种长度k序列，k取1-4）
- 计算每条序列的 N_BLP
- 检验：max_{序列} N_BLP ≤ JS(p1_S || p2_S) ?

**预期：** 如果预测正确，max N_BLP / JS 应该 ≤ 1 + O(1/N)。如果不是，差异来自哪里（关联区分度D_corr的贡献？）。

### 奇怪预测 #2："存在不可达的区分度区域"

对于给定的 D(0)，BLP积分 N_BLP 不能取 [0, q_S] 中所有值——存在"禁隙"。

**理由：** 由于CNOT的离散性（每个toggle贡献 ~1/N 量级的D变化），N_BLP 的可能取值形成离散谱，间隔约为 1/(N_S+N_E)。但在连续时间中（如果允许分数CNOT？），这个离散性会消失。然而，在纯CNOT动力学中（只有离散门），BLP积分的取值是一个**有理数集合**，且在某些区间可能是空的。

更奇怪的是：这个"禁隙"结构可能对N_S和N_E的数论性质（如是否互质）敏感——因为鸽巢界涉及整除关系。

**数值验证：** 对 N_S=2, N_E=3 枚举所有可能的初始分布和CNOT序列，画出 N_BLP 的直方图，寻找间隙。

## 5. A博士最可能反对的点（我预测的）

### 反对1：Lovász扩展的适用性
**A博士会说：** "Lovász扩展要求函数定义在{0,1}^n的超立方体顶点上，但区分度容量Φ不是定义在单个比特的0/1标签上，而是定义在概率分布对上。你的自变量z是什么？是p1还是p2还是(p1-p2)？超立方体的顶点对应什么物理态？这个映射不自然。"

**B博士的回应：** z_v 是节点v在"最坏情况差异分布"下为|1⟩的概率——即 z_v = max(p1(x_v=1), p2(x_v=1))。超立方体顶点对应确定性分配（每个节点要么确定是|1⟩要么确定是|0⟩），而这恰好是鸽巢原理适用的情形。连续内点对应概率混合，这就是离散→连续的桥。

（是否足够？坦率说，这是需要加固的部分。）

### 反对2：次模性未严格证明
**A博士会说：** "你说Φ是次模的，但只给了启发式论证。次模性需要验证对所有A,B⊆V成立。CNOT排列的结构可能导致非次模行为——例如，A中的控制和B中的控制可以联合产生一个A和B各自不能单独产生的区分度增益（协同效应），这违反次模性。"

**B博士的回应：** 协同效应需要检查。但直觉上，CNOT序列是置换的复合，而置换群在组合下的行为是"亚可加"的（多个置换的联合效果 ≤ 各自效果的和，因为L1距离满足三角不等式）。因此Φ不太可能是超可加的。次模性是合理的猜想，但需要正式验证。

（承认：这是本轮最大的技术缺口。）

### 反对3：δ_max 的估计过于粗糙
**A博士会说：** "你声称单个CNOT对D的最大贡献是 2/N_S，但这假设了均匀分布。在一般的p1,p2下，δ_max可以远小于此——而且可能系统性地依赖于CNOT的选择。你的上界 N_BLP ≤ q_S 可能在绝大多数情况下远非紧的。"

**B博士的回应：** 对。q_S 是松上界。紧界需要求解 Φ(V) 的确切值，这取决于具体的 p1, p2。我给出的 q_S 是最坏情况上界（对所有p1,p2取max）。对于给定的特定(p1,p2)，实际界可以更紧。

这引出了一个开放问题：**对于给定的(p1,p2)，Φ(V)的精确值是多少？** 这可能归结为一个组合优化问题，且复杂度可能是NP难的（类似于子集和或背包问题的变体）。

### 反对4：连续时间 vs 离散门
**A博士会说：** "你的整个框架假设CNOT是离散门操作。在真实的量子动力学中，演化是连续的（例如通过哈密顿量 H ~ CNOT 在有限时间内实现）。连续演化可能产生'部分toggle'——即qubit不是在{0,1}中跳变，而是穿过Bloch球的内部。这在你的离散图中没有对应。"

**B博士的回应：** 如果我们限制在pointer basis对角态，那么相干性（Bloch球内部）不会出现——态始终是对角的。在这种情况下，连续时间演化确实可以分解为离散的toggle事件序列（每个toggle对应一个CNOT门在计算基上的作用时间达到π的条件）。但你是对的：如果允许中间有短暂的非对角成分，"部分toggle"是可能的。

这个反对触及一个深层问题：**pointer basis选择的物理机制是什么？** 在传统的量子达尔文主义中，环境通过退相干选择pointer basis。但在我们的CNOT-only模型中，pointer basis是手工输入的（计算基）。如果不手工输入（允许任意哈密顿量），那么系统会主动偏离pointer basis，我们的整个鸽巢论证就失效了。

这是当前框架的最大脆弱点，但也是最有意思的方向——因为如果pointer basis是突现的（由CNOT结构本身挑选出来的），那么我们的鸽巢界可能会自然地推导出pointer basis的必要条件。

## 6. 失败的跳跃（记录）

### 失败跳跃1：范畴论 — Monad = CNOT序列
**尝试：** 将CNOT操作视为endofunctor，CNOT序列的复合视为Kleisli范畴中的态射。初始态是对象，演化是monad的"乘法"。

**失败原因：** Monad的单位律（左/右单位元）和结合律在CNOT序列中找不到自然对应。Monad要求return : A → T(A) 和 join : T(T(A)) → T(A)，但CNOT是状态空间的置换而非类型构造器。范畴论框架引入的抽象层次远高于问题所需，没有提供新的计算能力。**标记：过度工程化。**

### 失败跳跃2：经济学 — Pareto最优和激励相容
**尝试：** 将p1和p2视为两个"代理人"，CNOT视为"交易"（将|1⟩从环境"转移"到系统）。区分度D是代理人之间的"分歧"。问题是：是否存在"激励相容"的演化使得分歧增加不超过某个界？

**失败原因：** "激励"在物理系统中没有天然对应。p1和p2是概率分布，不是有偏好的代理人。经济学的"福利经济学第二定理"涉及价格和市场出清，在无偏好的物理系统中找不到对应。**标记：隐喻过度拉伸。**

### 失败跳跃3：信息论 — 信道容量和数据处理不等式
**尝试：** 将环境→系统的CNOT序列视为一个"通信信道"。初始环境态是"消息"，系统态是"接收到的信号"。区分度D度量信号的保真度。BLP积分是信道的信息增益。

**失败原因：** 这个类比其实是**部分成功的**（见奇怪预测#1中JS散度的出现）。但它作为主要框架失败了，因为数据处理不等式（DPI）说的是信息只能减少，而BLP积分度量的是D的**增加**——恰好与DPI的方向相反。在完全正定且保迹（CPTP）的信道中，迹距离只能缩小，不能增大。CNOT子系统的非马尔可夫性使D可以增加，但DPI不能直接描述这种现象。需要的是**非马尔可夫信道的信息回流度量**——这正是BLP度量本身。所以这个类比是循环的。**标记：部分成功但循环。**

### 失败跳跃4：概率论 — Martingale可选停止
**尝试：** 将D(t)构造为鞅或上鞅。如果D(t)是上鞅，则它的正变差有界。

**失败原因：** D(t)在完整空间上是守恒的（CNOT是置换→L1不变），所以不是鞅（鞅要求期望保持不变或递减）。在约化系统上，D(t)可以上升也可以下降，也不满足鞅性质。可选停止定理给出停在最优时刻的期望，但我们关心的是路径的正变差，不是停止值。**标记：数学对象不匹配。**

## 7. 深挖回答

### 深挖1：本轮找到的同构，有没有更深层的数学结构？

**从组合优化 → 次模函数往下挖两层：**

**第一层（次模函数 → 凸分析）：**
次模函数的 Lovász 扩展等价于该函数的**凸紧化**（convex closure）。具体来说，^Φ 是 Φ 的凸下包络在超立方体上的限制。这意味着 BLP 积分（作为 Lovász 扩展）本质上是 Φ 的**凸松弛**。这建立了：
BLP积分 = 离散鸽巢界的最紧凸松弛

由此产生一个对偶表述：BLP上界问题等价于求解 Φ 的**次模函数最小化**（SFM）问题。SFM 是多项式时间可解的（通过椭球法或组合算法），这意味着 BLP 上界原则上可以在多项式时间内计算。这是一个可操作的算法洞察。

**第二层（凸分析 → 最优传输理论）：**
Lovász 扩展与一维最优传输（Wasserstein-1距离）有深层联系。具体来说，对于离散概率分布，Wasserstein-1距离（"推土机距离"）可以用分布函数的 L1 距离表示，而分布函数的积分正是 Lovász 型构造。

在物理上：
- D(t) = ½ Σ_s |p1_S(s) - p2_S(s)| 是总变差距离
- W_1(p1_S, p2_S) 是 Wasserstein-1 距离（在地面度量 d(s, s') = 1_{s≠s'} 下等于总变差）
- BLP 积分 = ∫_{Ḋ>0} Ḋ dt 度量了 W_1 沿CNOT驱动轨迹的"总上行运动"

最优传输视角揭示：**CNOT序列对应着概率质量在超立方体顶点之间的输运计划**。区分度的增加对应于输运计划在系统坐标上的投影变宽。鸽巢界对应于输运计划中"从环境→系统方向"移动的总质量上界。

**终极结构识别：** 整个问题落入 **凸共轭对偶 + 次模函数 + 最优传输** 的三元框架。这不是三个独立的框架，而是同一个结构的三面：
- 凸共轭 → 鸽巢（原问题）↔ BLP（对偶问题）
- 次模函数 → 离散容量 ↔ 连续 Lovász 扩展
- 最优传输 → 质量输运计划 ↔ 区分度演化轨迹

### 深挖2：本轮借来的结构，在原学科中的"下一层"推广

**从 Max-Flow Min-Cut 往下挖：**

**推广1：多商品流（Multi-commodity Flow）**
在标准网络流中，只有一种"商品"在网络中流动。在我们的问题中，"商品"是区分度信息——具体来说，是对(p1,p2)有差异化的概率质量。但p1和p2各贡献一个概率分布，所以实际上有两种商品在流动。

多商品流的最大流-最小割不等式是：最大并发流 ≤ 最小稀疏割（sparsest cut）。在物理翻译中：
- 每个"商品"是一种初始分布的概率质量
- BLP积分是两种商品的联合区分度增益
- "稀疏割"是使两个商品暴露最大差异的割
- 鸽巢界是稀疏割容量的特例（所有边权重相同时）

这暗示：**如果考虑多于两个初始分布（例如p1, p2, p3），BLP界会涉及到更复杂的多商品流割界，且可能不是多项式时间可计算的（多商品流是NP难的）。**

**推广2：次模流（Submodular Flow）**
Edmonds-Giles的次模流定理推广了最大流最小割：当容量约束是次模函数（而不只是数值）时，最大流等于最小割（以次模函数值度量）。在我们的物理问题中：
- 不是所有|1⟩→|0⟩的CNOT都是等价可用的（因为不同qubit对不同初始分布对有不同的区分度价值）
- 这个"效用"差异自然地建模为 CNOT 边上的次模权重函数
- 次模流定理保证了 max-flow = min-cut 在次模权重下仍然成立

**推广3：多期/动态流（Dynamic Flow / Flow over Time）**
标准网络流是静态的，但CNOT序列是**有序的**——CNOT的先后顺序影响最终结果（因为一个toggle改变了qubit的|1⟩/|0⟩标签，影响后续操作的可用性）。这对应**动态流**（flow over time），其中流经过边需要时间，且中间节点的容量可以随时间变化。

动态流的最大流-最小割定理（Ford-Fulkerson的时间扩展版本）给出了时变割容量的上界。翻译到物理：
- 每个时刻的CNOT图结构定义了一个"瞬时割"
- BLP积分上界 = 所有瞬时割容量的（带权重）时间积分
- 鸽巢界 N_S·q_S 是所有瞬时割容量的 max（即最松的瞬时界）
- 紧界需要 min over time of 瞬时割容量（即随时间演化的最优割选择）

这给出了一个比 N_S·q_S 更紧的界：**时变鸽巢界** = min_{t} ( |{c∈E: x_c(t)=1}| · |{t∈S: x_t(t)=0}| )

## 8. 总结：本轮产出

### 可操作的数学声明
1. **区分度容量Φ是次模函数**（待严格证明，但有强启发式支持）
2. **BLP积分 ≤ ^Φ (Lovász 扩展) ≤ Φ(V) ≤ N_S·q_S·δ_max ≤ q_S**
3. **紧界可能是 Jensen-Shannon 散度** JS(p1_S || p2_S)

### 可数值验证的预测
1. N_BLP ≤ q_S（对于任意CNOT序列，暴力验证 N≤8 的系统）
2. N_BLP ≤ JS(p1_S || p2_S)（预测的紧界，暴力验证）
3. BLP 积分的可能取值存在"禁隙"（直方图检测）

### A博士最可能攻击的点（按致命程度排序）
1. **Φ的次模性未严格证明** —— 最致命，需要反例检验或正式证明
2. **Lovász扩展的自变量定义模糊** —— 需要精确的物理↔数学映射
3. **δ_max 的估计是松的** —— 紧界计算可能NP难
4. **连续时间 vs 离散门的不匹配** —— 如果允许连续演化（非pointer基对角），框架崩溃
