## §0: PI洞察的形式验证

### §0.1 D_S(t) ≤ D_S(0)的严格证明

PI在R1评审中指出了一条R1全文错过的约束：**D_S(t) ≤ D_S(0) 对所有 t 成立**。本节给出严格证明。

**Lemma 0.1 (CNOT置换性)**：CNOT门在计算基{0,1}^2上是一个置换（双射）。任意CNOT序列因此是{0,1}^{N_S+N_E}上的一个置换。置换作用于对角概率向量保持L1范数不变。

**证明**：CNOT将计算基态|c, t⟩映射到|c, t⊕c⟩。这是{00,01,10,11}上的一个置换（转置(10,11)并固定(00,01)）。多个置换的复合仍是置换。对角态由概率向量p(x) = ⟨x|ρ|x⟩完全刻画，置换π作用下p → p∘π^{-1}是概率向量的重排，L1距离不变。

**Lemma 0.2 (全空间守恒)**：
```
D_SE(t) = D_SE(0)  对所有 t                                [Eq. R2.1]
```

**证明**：Lemma 0.1保证D_SE是置换不变的：D_SE(t) = ½ Σ_x |p_SE^(1)(x,t) - p_SE^(2)(x,t)| = ½ Σ_x |p_SE^(1)(π^{-1}x,0) - p_SE^(2)(π^{-1}x,0)| = D_SE(0)。

**Lemma 0.3 (初态因子化)**：
```
D_SE(0) = D_S(0)                                              [Eq. R2.2]
```

**证明**：初始ρ_SE^(k)(0) = ρ_S^(k)(0) ⊗ ρ_E(0)，两个副本的ρ_E(0)相同。对角态下：
D_SE(0) = ½ Σ_{x∈{0,1}^{N_S}} Σ_{y∈{0,1}^{N_E}} |p_S^(1)(x)q(y) - p_S^(2)(x)q(y)|
= ½ Σ_x |p_S^(1)(x) - p_S^(2)(x)| · Σ_y q(y)
= D_S(0) · 1 = D_S(0)。

**Lemma 0.4 (部分迹收缩)**：
```
D_S(t) ≤ D_SE(t)  对所有 t                                   [Eq. R2.3]
```

**证明**：部分迹是CPTP映射，迹距离在CPTP映射下不增（标准结果，见Nielsen-Chuang Theorem 9.2）。

**定理0 (PI约束，严格版)**：
```
D_S(t) ≤ D_S(0)  对所有 t                                     [Eq. R2.4]
```

**证明**：联立Eq. R2.1-R2.3：D_S(t) ≤ D_SE(t) = D_SE(0) = D_S(0)。∎

**评论**：这个证明只用到了三个事实：(i) CNOT是计算基置换，(ii) 初态是S⊗E乘积且E因子相同，(iii) 部分迹是迹收缩。没有任何近似、没有假设编码效率、没有鸽巢原理。它是严格成立的。

### §0.2 对N_BLP的直接推论

N_BLP定义为D_S在所有严格增加区间上的积分之和。由于D_S(t) ≤ D_S(0)且D_S(t) ≥ 0：

```
N_BLP = Σ_{ℓ: Δ_ℓ>0} Δ_ℓ ≤ D_S(0) - D_S_min ≤ D_S(0) ≤ 1     [Eq. R2.5]
```

其中D_S_min ≡ min_{t∈[0,T]} D_S(t)，Δ_ℓ = D_S(t_ℓ^+) - D_S(t_ℓ^-)。

**这是一个平凡但严格的上界**。它告诉我们N_BLP永远不超过初始系统区分度。问题是：能否用q_S和q_E将这个界收紧到非平凡？

## §1: 任务1 — 闭合C^(k) + N_S标度（⛔阻断）

### §1.1 关键计算发现：D_S在纯正向CNOT下不变

考虑一个正向CNOT_{S_i→E_j}（S_i控制，E_j目标）。作用前态为对角乘积态。作用后：

联合分布：P_SE^(k)(s, e) = P_S^(k)(s_1,...,s_{N_S}) · Π_{ℓ≠j} q(e_ℓ) · q(e_j ⊕ s_i)

对E取边缘（对所有e求和）：
P_S^(k)(s) = Σ_e P_SE^(k)(s, e)
= P_S^(k)(s) · [Σ_{e_j} q(e_j ⊕ s_i)] · Π_{ℓ≠j} [Σ_{e_ℓ} q(e_ℓ)]
= P_S^(k)(s) · 1 · 1 = P_S^(k)(s)

**结论**：D_S在正向CNOT下严格不变。

### §1.2 信息流的重新分类

这个发现迫使我们重新分类CNOT门：

| 门类型 | 控制 | 目标 | D_S变化 | 物理含义 |
|--------|------|------|---------|----------|
| Type F | S | E | 0（不变） | 创建S-E关联，不改变S边缘 |
| Type R | E | S | 可正可负 | 将E中的信息"读入"或"混入"S |

**关键含义**：
- D_S只在Type R门（E→S CNOT）处发生改变。
- D_S的减小（"正向信息流"，混淆S区分度）发生在Type R门。
- D_S的增大（"回流/背流"，恢复S区分度）也发生在Type R门。
- Type F门只负责"编码"——将S信息复制到E关联中，但不改变D_S本身。

### §1.3 由此自然闭合C^(k)问题

C^(k)(s) = D(ρ_SE^(k)(s), ρ_S^(k)(s)⊗ρ_E^(k)(s))度量S-E关联的L1强度。R1的Eq. 3引用Megier框架：
D_S(t) - D_S(s) ≤ D_E(s) + C^(1)(s) + C^(2)(s)

该不等式始终成立（三角不等式），但在我们的具体模型中，C^(k)不是独立自由度。

**论证**：在仅含Type F和Type R门的演化中：

1. Type F门：D_S不变（ΔD_S = 0），Megier不等式退化为0 ≤ D_E + C^(1) + C^(2)，平凡成立。

2. Type R门：设CNOT_{E_j→S_i}在时刻s作用。D_S的改变量ΔD_S取决于E_j中存储的区分度。而E_j中的区分度唯一起源于之前的Type F CNOT_{S_k→E_j}（其中某个S_k作为控制，将δ_k·|1-2q_E|的区分度编码到E_j）。同时，正是这同一个Type F门创建了S_k↔E_j关联C^(k)。

因此，E_j的区分度（贡献给D_E）和S_k↔E_j的关联（贡献给C^(k)）具有**共同起源**。两者都正比于δ_k·|1-2q_E|，且当|1-2q_E|→0时两者同时消失。

**关键引理（待完整证明）**：
在仅含Type F→Type R的CNOT动力学中，C^(k)(s) ≤ (与D_E(s)同阶的上界)。
具体而言，C^(k)(s) / D_E(s) ≤ O(1)，极限|1-2q_E|→0下两者线性相关。

**物理直觉**：区分度以两种形式存储在E中：(a) E的边缘分布差异（D_E），(b) E与S的条件关联（C^(k)）。两者是同一信息的不同"投影"。Type R门读取E_j的控制比特时，访问的是联合信息（边缘+关联），但读取效率由|1-2q_E|决定——该因子同时调节D_E和C^(k)。

**结论**：Megier框架的C^(k)项不与D_E项独立，不需要单独上界。在定理0给出的D_S(0)约束下，Megier框架本身可以被更简洁的D_S轨迹直接分析所取代。详见§2。

### §1.4 N_S标度的闭合

R1的Eq. 15含(N_S)²因子，对所有N_S≥2退化为N_BLP≤1（平凡）。根本原因是R1将"回流区间数"N_S·q_S与"每区间I_out"中的N_S因子相乘，产生了虚假的二次方标度。

**修正**：利用§0的D_S(0)约束。

设每轮Type R门（回流事件）最多改变D_S |1-2q_E|（单个E qubit携带的最大区分度——该上界来自编码关系Eq. 7，已由INSPECTOR验算通过）。

在"至多一次|0⟩→|1⟩翻转"约束下，每个S qubit作为目标qubit的Type R门至多发生一次|0⟩→|1⟩翻转。该翻转是对D_S有影响的唯一操作（|1⟩→|0⟩翻转不消耗鸽巢容量）。因此，最多有N_S·q_S次"有效"Type R门（即能改变D_S的门）。

```
N_BLP ≤ N_S·q_S·|1-2q_E|                                  [Eq. R2.6]
```

同时，由Eq. R2.5：N_BLP ≤ D_S(0)。联立：

```
N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|)                    [Eq. R2.7]
```

**Eq. R2.7不再含有(N_S)²因子。** D_S(0)项保证了即使N_S很大，上界也不会超过1。N_S·q_S·|1-2q_E|项在N_S较小或q_S较小时提供更紧的约束。

**标度行为验证**：
- N_S→0：min(D_S(0), 0) = 0。平凡系统无回流。✓
- N_S→∞（q_S, |1-2q_E|固定）：min(D_S(0), ∞) = D_S(0) ≤ 1。上界由初始区分度饱和，不随N_S发散。✓
- q_S→0（所有S qubit处于|1⟩，无|0⟩→|1⟩翻转空间）：min(D_S(0), 0) = 0。✓
- q_E=1/2（环境最大混合）：|1-2q_E|=0，min(D_S(0), 0) = 0。✓
- q_E=0或1（环境纯态，最强编码）：|1-2q_E|=1，min(D_S(0), N_S·q_S)。可能达到N_S·q_S（若N_S·q_S < D_S(0)）或D_S(0)。✓

### §1.5 Eq. 17→Theorem A替换问题的解决

R1的Eq. 17给出N_BLP ≤ N_E·|1-2q_E|（环境总容量）。替换为N_S·q_S·|1-2q_E|的论据是鸽巢原理限制回流次数。

**精确论证**：

每次回流对应一个Type R门CNOT_{E_j→S_i}。该门改变D_S的量取决于E_j在此时的区分度，该区分度不超过|1-2q_E|（来自Eq. 7，因为E_j的区分度源于某个初始S qubit的δ ≤ 1）。

回流次数受到鸽巢约束：每次Type R门中S_i是目标，发生|0⟩→|1⟩翻转当且仅当E_j=|1⟩且S_i初态=|0⟩。每个S qubit至多翻转一次|0⟩→|1⟩。翻转速率的期望为q_S = ⟨0|ρ_S|0⟩（S qubit处于|0⟩的概率）。因此最多N_S·q_S次有效的|0⟩→|1⟩翻转。

**从N_E到N_S·q_S的替换不是"近似"，而是"收紧"**：N_E是环境qubit总数（可能很大），N_S·q_S是可用的鸽巢容量（通常远小于N_E）。因为每个Type R门消耗一个S qubit的|0⟩→|1⟩容量，而该容量只有N_S·q_S。

**形式化**：

设R为所有Type R门的指标集。对于每个r∈R，设S_i(r)为门r的目标S qubit。定义：
```
F(r) = 1 若S_i(r)在门r中经历|0⟩→|1⟩翻转，否则0
```

鸽巢原理：Σ_{r∈R} F(r) ≤ N_S·q_S（每个S qubit至多贡献一次|0⟩→|1⟩翻转）。

每个改变D_S的Type R门必须涉及具有非零区分度的E qubit（否则ΔD_S=0）。E qubit的区分度仅来源于之前的Type F门，最大值为|1-2q_E|。

```
N_BLP = Σ_{r: Δ_r>0} Δ_r ≤ Σ_{r: Δ_r>0} |1-2q_E|
= |1-2q_E| · |{r : Δ_r > 0}|
≤ |1-2q_E| · |{r : F(r) = 1}|  （每个正Δ_r的有效Type R门消耗鸽巢容量）
≤ |1-2q_E| · N_S · q_S
```

这里假设"每个Δ_r>0的门消耗鸽巢容量"。这是需要验证的环节：存在Δ_r>0但不消耗鸽巢容量的Type R门吗（即S_i从|1⟩→|0⟩翻转也能增加D_S）？

**反例检查**：若S_i在Type R门前处于|1⟩，E_j=|1⟩，则S_i翻转为|0⟩。这是|1⟩→|0⟩翻转（不消耗鸽巢容量），但D_S可以改变。我们需要确认|1⟩→|0⟩翻转是否也能产生正Δ_r。

**分析**：如果D_S的增加需要通过S_i从|1⟩→|0⟩实现，那么这个翻转消除了S_i中的|1⟩。原本两个副本在S_i=|1⟩和S_i=|0⟩上的概率不同，翻转后差异可能增大或减小。没有一般性的理由认为|1⟩→|0⟩翻转不能增加D_S。

**修正**：|1⟩→|0⟩翻转也可以改变D_S。因此，鸽巢约束（仅限制|0⟩→|1⟩翻转次数）不直接限制所有可能的D_S变化事件。

然而，在至多一次|0⟩→|1⟩翻转的约束下，每个S qubit的总翻转次数（|0⟩↔|1⟩）最多为2：一次|0⟩→|1⟩加一次|1⟩→|0⟩。所以总Type R门次数的上界为2N_S（在|0⟩→|1⟩发生前，S qubit可能已在|1⟩态并经历|1⟩→|0⟩翻转）。

**松上界**：N_BLP ≤ 2N_S·|1-2q_E|。

**紧上界**：在q_S→0极限下（大部分S qubit初始为|1⟩），|0⟩→|1⟩翻转几乎不可能（鸽巢容量接近0），但|1⟩→|0⟩翻转仍然可能。要得到包含q_S的紧上界，需要证明"不消耗鸽巢容量的|1⟩→|0⟩翻转对N_BLP的贡献有限"。

这是一个仍需闭合的缝隙。当前最安全的上界为：
```
N_BLP ≤ min(D_S(0), 2N_S·|1-2q_E|)                        [Eq. R2.8]
```

而限制型上界（需要额外假设）为：
```
N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|)                    [Eq. R2.7]
```

两个版本的区别在于因子2 vs q_S（当q_S<1/2时Eq. R2.7更紧）。在后续分析中，我们将Eq. R2.7标记为**需要额外验证**（见§5.2致命弱点）。

## §2: 任务2 — Megier框架去留决策（⛔阻断）

### §2.1 Megier框架回顾

Megier-Smirne-Vacchini (2021)给出的一般不等式（R1 Eq. 3）：
```
D_S(t) - D_S(s) ≤ D(ρ_E^(1)(s), ρ_E^(2)(s)) + C^(1)(s) + C^(2)(s)
```

Round 1试图利用此不等式，将I_out = D_E + C^(1) + C^(2)上界化，再将各回流区间的I_out求和。但R1：
- 只上界化了D_E（Eq. 10）
- 粗略上界化了C^(k)（Eq. 13），但未严格证明
- 最终扔掉了C^(k)直接跳转到Theorem A

### §2.2 决策：放弃Megier框架

**理由A（结构冗余）**：定理0（D_S(t) ≤ D_S(0)）给出的上界N_BLP ≤ D_S(0)比Megier框架更基础、更简洁、且不需要处理C^(k)。Megier不等式将D_S的变化分解为D_E + C^(1) + C^(2)三项，但定理0用一个全局约束取代了这三个局部贡献。

**理由B（C^(k)无法独立闭合）**：尽管§1.3论证了C^(k)与D_E同源于Type F门，但要将C^(k)量化为D_E的显式函数仍需额外假设（如"每个E qubit至多参与一个有信息含量的Type F门"）。在过度工程化的分析框架下，验证这些假设的工作量超过了框架本身带来的收益。

**理由C（框架替换更简洁）**：替代方案——直接用D_S轨迹分析——在数学上更透明：

```
定义：D_S(t)在[0,T]上的演化轨迹。
约束1：D_S(0) = D_S(0)（初始条件）
约束2：D_S(t) ≤ D_S(0)（定理0）
约束3：D_S仅在Type R门处改变（§1.1）
约束4：每次Type R门改变D_S的量 ≤ |1-2q_E|（编码关系）
约束5：有效Type R门次数 ≤ N_S·q_S（或 ≤ 2N_S）（鸽巢/保守界）
→ N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|)
```

这个推导不需要Decompose D_S(t)-D_S(s)为三项，不需要单独上界C^(k)，不需要担心三角不等式的松紧度。它是一个自包含的论证链。

**理由D（Megier框架的"沉没成本"风险）**：继续在Megier框架上投入会将分析锁死在外部信息三分法（D_E, C^(1), C^(2)）的范式中。该三分法对一般量子信道是有价值的，但在我们的具体模型（CNOT-only + 对角态）中，它引入了不必要的概念开销。及早切换到更适配的D_S轨迹框架可以避免后续轮次在这些概念上的无谓纠缠。

### §2.3 替代框架的形式化

**新框架**："D_S轨迹直接约束法"。

**定义1（事件）**：一个"事件"是单次CNOT门操作。设总事件序列为g_1, g_2, ..., g_T，每个g_t是CNOT_{c(t), tgt(t)}（c(t): 控制qubit，tgt(t): 目标qubit）。

**定义2（S-改变事件）**：事件g_t是"S-改变"的，若tgt(t) ∈ S（即目标qubit是系统qubit）。等价于Type R门。

**定义3（D_S增量）**：对于S-改变事件g_t，定义Δ_t = D_S(t^+) - D_S(t^-)。Δ_t可正可负可零。

**引理1（单事件上界）**：对于任意S-改变事件CNOT_{E_j→S_i}，
|Δ_t| ≤ |1-2q_E| · (E_j当前的最大区分度) ≤ |1-2q_E|

**证明概要**：E_j的区分度源于之前的Type F门，每次Type F门的编码效率为|1-2q_E|（Eq. 7）。在至多一次|0⟩→|1⟩翻转约束下，E_j从δ_i ≤ 1的S qubit最多获得|1-2q_E|的区分度。

**推论（N_BLP上界）**：
```
N_BLP = Σ_{t: Δ_t>0} Δ_t ≤ |{t : Δ_t > 0}| · |1-2q_E|
N_BLP ≤ D_S(0)  （定理0）
→ N_BLP ≤ min(D_S(0), K·|1-2q_E|)
```
其中K = |{t : Δ_t > 0}|是产生正D_S增量的事件数。

K的上界决定了上界的紧度。鸽巢原理给出K ≤ N_S·q_S（在"每个正Δ_t消耗一次|0⟩→|1⟩翻转"的假设下）。保守界为K ≤ 2N_S。

**这就是新框架的核心。** 没有D_E/C^(1)/C^(2)三分法，没有I_out，没有Megier。

## §3: 任务3 — 统一q_E约定（⚠️警告）

### §3.1 用户约定

用户定义：**q_E ≡ ⟨0|ρ_E|0⟩**，即环境qubit处于计算基|0⟩的概率。

沿用此约定至全文。

### §3.2 对编码关系的影响

编码关系（R1 Eq. 7，INSPECTOR验算通过）在此约定下：

正向CNOT_{S_i→E_j}后，E_j的边缘分布：
```
p_j^(k)(e=0) = (1-p_i^(k))·q_E + p_i^(k)·(1-q_E)            [Eq. R2.9]
p_j^(k)(e=1) = (1-p_i^(k))·(1-q_E) + p_i^(k)·q_E
```

两个副本下E_j的区分度：
```
Δp_j^E = |p_j^(1)(0) - p_j^(2)(0)|
       = |[(1-p_i^(1))q_E + p_i^(1)(1-q_E)] - [(1-p_i^(2))q_E + p_i^(2)(1-q_E)]|
       = |(p_i^(1)-p_i^(2))·(1-2q_E)|
       = δ_i · |1-2q_E|                                      [Eq. R2.10]
```

编码效率因子为|1-2q_E| = |⟨0|ρ_E|0⟩ - ⟨1|ρ_E|1⟩| = |2q_E-1|。

这是E的|0⟩和|1⟩之间的极化度（population inversion）。

**边界行为**：
- q_E=0（E全在|1⟩）：|1-2q_E|=1，编码效率最大
- q_E=1（E全在|0⟩）：|1-2q_E|=1，编码效率最大
- q_E=1/2（E最大混合）：|1-2q_E|=0，无法编码区分度
- q_E=1/4：|1-2q_E|=0.5，中等编码效率

### §3.3 R1与约定的一致性检查

R1中q_E的使用存在歧义：有时将q_E定义为⟨1|ρ_E|1⟩（Eq. 7的推导中q_E出现在(1-q_E)项），有时又似定义为⟨0|ρ_E|0⟩。在用户约定下，所有R1中涉及q_E的表达式应重新审计：

- R1 Eq. 7的编码关系：Δp_j^E = δ_i·|1-2q_E|。在q_E = ⟨0|ρ_E|0⟩约定下仍成立，因为|1-2q_E| = |1-2⟨0|ρ|0⟩| = |⟨1|ρ|1⟩-⟨0|ρ|0⟩|是对称的。
- R1 Theorem A：N_BLP ≤ N_S·q_S·|1-2q_E|。约定一致。
- R1 Eq. 18：同上。

**结论**：切换到用户约定不影响任何已建立的数学关系，因为关键因子|1-2q_E|在两种约定下是对称的（只是绝对值内的符号翻转）。

## §5: 深挖（强制）

### §5.1 深挖1：本轮结论的下一层后果

**第一层后果**：如果Eq. R2.7（N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|)）成立，则BLP非Markov度量在此模型中有一个"组合-信息"混合上界。D_S(0)来自信息论（初始可区分度），N_S·q_S·|1-2q_E|来自组合学（鸽巢容量乘以编码效率）。两者的min取法反映了两个独立的饱和机制：信息饱和（D_S(0)限制总回流量）和容量饱和（鸽巢容量限制回流次数）。

**第二层后果**：如果上界在极端参数下饱和（案例#2），则这些极端参数对应着"最大非Markov性"的物理条件。这意味着：
- q_E=0或1（纯环境态）对非Markov性最有利——环境"记得"所有编码信息。
- q_S=1（所有系统qubit可翻转）最大化回流事件数。
- 高初始区分度（δ→1）最大化每次回流的信息量。

这是可实验检验的：在超导qubit系统中，环境qubit的纯度和系统qubit的初始|0⟩比例应当正比于可观测的非Markov度量值。

**第三层后果（更深层）**：如果上界在一般参数下不紧（有3x+的冗余），则存在尚未识别的更紧约束。可能的来源：
1. 编码效率|1-2q_E|可能不是每次回流的精确最大值（Eq. 7仅适用于"首次"正向编码）。
2. 回流事件之间的信息冗余——多个Type R门可能"共享"同一份外部信息，导致实际回流小于事件数乘单次上限。
3. S-E关联的不可逆性——某些编码到E中的信息可能无法通过单步Type R门完整回收（类似于Landauer原理中的信息擦除）。

**第四层后果（最深）**：D_S(t) ≤ D_S(0)这一约束暗示**D_S的行为类似于物理熵**——它只能被"稀释"（通过Type F门创建关联，随后通过Type R门扩散到更大的Hilbert空间），但不能"凭空增加"。N_BLP度量的是D_S的"自发恢复"，但该恢复永远不能将D_S推过其初始值。这在结构上类似于Boltzmann H定理（H只能减小）和Poincare回归定理（H可以在有限系统中回升，但不能超过初始值）之间的张力。CNOT-only动力学的pointer basis对角约束消除了量子相干性，使系统退化为一个**经典随机置换系统**——在此系统中，D_S(0)扮演了"最大信息容量"的角色，而Type R门是仅有的"信息泵"。

### §5.2 深挖2：本轮依赖的前提中，哪一个本身最可能也是错的？

**最可疑前提**：**"每个改变D_S的Type R门消耗一次鸽巢容量|0⟩→|1⟩翻转"**。

**为什么可疑**：§1.5中已经识别出Type R门中|1⟩→|0⟩翻转也可以改变D_S。鸽巢原理只限制|0⟩→|1⟩翻转（消耗"翻转配额"），不限制|1⟩→|0⟩翻转。因此，D_S的改变次数可以超过N_S·q_S。

**具体场景**：考虑以下序列：
1. S1初始在|1⟩（不消耗|0⟩→|1⟩配额）。
2. Type F CNOT_{S1→E1}：创建S1-E1关联（D_S不变）。
3. Type R CNOT_{E1→S2}（S2初始在|1⟩）：S2经历|1⟩→|0⟩翻转（不消耗配额！），D_S改变。
4. Type F CNOT_{S2→E2}：S2现为|0⟩，创建S2-E2关联。
5. Type R CNOT_{E2→S2}：S2经历|0⟩→|1⟩翻转（这才消耗配额），D_S再次改变。

在此序列中，步骤3改变了D_S但不消耗鸽巢配额。如果|1⟩→|0⟩翻转也能有效改变D_S，则**实际D_S改变事件数可能高达2N_S（每个qubit最多翻转两次：|1⟩→|0⟩然后|0⟩→|1⟩或反之）**。

**这意味着Eq. R2.7中的N_S·q_S应替换为min(2N_S·q_S, N_S)或类似的更复杂表达式。** 目前的N_S·q_S因子可能**低估**了上界（给出了过于乐观的紧度）。

**第二个可疑前提**：**"每个E qubit的最大区分度恰好是|1-2q_E|"**（来自Eq. 7）。

R1的Eq. 7推导假设E_j在正向CNOT前处于初始态。在多次Type F→Type R→Type F的多轮演化中，E_j可能已被前面的操作修改过，其当前态不再是初始的q_E。此时编码效率可能偏离|1-2q_E|。

更精细的分析需要跟踪E_j的时变混合度。在最坏情况下，E_j可能已被极化（接近纯态），编码效率接近1而非|1-2q_E|。这意味着单次回流的区分度可能超过|1-2q_E|。

**缓解**：在"至多一次|0⟩→|1⟩翻转"约束下，E_j最多经历一次Type F（|0⟩→|1⟩翻转）和可能的后续Type R（如果E_j充当控制的话，E_j自身不变）。Type F翻转后的E_j混合度是p_S·q_E + (1-p_S)·(1-q_E)，这确实使E_j偏离初始q_E。但偏离量与|1-2q_E|同阶，不太可能使编码效率系统性超过1。

**第三个可疑前提**：**"最小化论证中N_BLP取最大值对应的初始态对与最小化D_S(0)的矛盾"**。BLP度量涉及在所有初始态对上最大化N_BLP。但D_S(0)约束说N_BLP ≤ D_S(0)，而大的D_S(0)有利于大的N_BLP（有更多初始区分度可以利用），但大的D_S(0)也使上界D_S(0)更松。这个张力在优化中如何解决？

**结论**：最可疑的是前提1（鸽巢配额 = 有效事件数）。这是R3中应优先攻击的环节。
