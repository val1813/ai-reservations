## Q2. 符号/方向校对

### Q2.1 "纯正向CNOT (Type F) 下D_S严格不变"

验证§1.1的计算:

联合分布: P_SE^(k)(s, e) = P_S^(k)(s_1,...,s_N_S) · Π_{ℓ≠j} q(e_ℓ) · q(e_j ⊕ s_i)

边缘化:
P_S^(k)(s) = Σ_e P_SE^(k)(s, e)
= P_S^(k)(s) · [Σ_{e_j} q(e_j ⊕ s_i)] · Π_{ℓ≠j} [Σ_{e_ℓ} q(e_ℓ)]
= P_S^(k)(s) · 1 · 1 = P_S^(k)(s)

验算: Σ_{e_j} q(e_j ⊕ s_i) = q(0⊕s_i) + q(1⊕s_i) = q(s_i) + q(¬s_i) = 1 ✓
Π_{ℓ≠j} Σ_{e_ℓ} q(e_ℓ) = Π 1 = 1 ✓

**数学事实**: CNOT_{S→E} (S为控制)保持S的约化态不变。这是CNOT的基本性质 — 控制qubit的边缘态在CNOT下不变。A博士的对角态计算与此标准结果一致。

**判定:** ✓ 通过。严格数学事实。

### Q2.2 N_BLP新界的极限检查

**关键问题**: Eq. R2.7是否能与这个反例共存?

A博士的回应空间:

#### 极限 q_S → 0

min(D_S(0), 0) = 0。但D_S(0)可能非零。

**检查** q_S=0 (所有S-qubit在|1⟩) 时D_S(0)是否总是0:

q_S = ⟨0|ρ_S|0⟩ 是所有S-qubit处于|0⟩的平均比例。q_S=0表示所有S-qubit初始都在|1⟩。但这不意味着两个副本的态相同 — 例如在N_S=2系统中, copy1可以是|00⟩ (在位置1,2的|0⟩比例) 和|11⟩不同。但q_S=0意味着所有qubit都是|1⟩ — 两个副本完全相同? 

不对。q_S是**平均**⟨0|概率。如果所有S-qubit都在|1⟩ (即|0⟩概率为0), 则p_S^(k)(x)只有在x全为|1⟩时为非零。对于两个副本, 如果它们都在|11...1⟩, 则D_S(0)=0。如果q_S=0, 所有qubit处于|0⟩的概率严格为零, 这强制p_S^(1)=p_S^(2)=(0,...,0,1) 在|11...1⟩上, 所以D_S(0)=0。

**判定:** ✓ q_S=0 → D_S(0)=0 → min(0,0)=0, 合理。

### Q2.3 自逆振荡与A博士界的兼容性

**用户关键上下文**: "B博士R2发现q_E=1/2时CNOT²=I可产生非零N_BLP — 这个自逆振荡是否在A博士的界中被正确捕获?"

**分析**:

A博士的Eq. R2.7给出: N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|)。在q_E=1/2时, |1-2q_E|=0, 所以N_BLP ≤ min(D_S(0), 0) = 0。

自逆振荡机制: CNOT(E_j→S_i)∘CNOT(E_j→S_i)=I。在q_E=1/2时:
1. 第一次CNOT(E_j→S_i): 由于E_j为最大混合态(控制=1概率=1/2), S_i有一半概率被翻转→D_S下降
2. 第二次CNOT(E_j→S_i): S_i再次翻转(因CNOT自逆), D_S回升

这个D_S回升被BLP积分计入N_BLP。

**A博士的界无法捕获此机制** — 它通过min(..., 0) = 0封死了q_E=1/2时的所有N_BLP。如果自逆振荡确实产生N_BLP>0 (如B博士声称的0.800), 界被违反。

**核心问题**: Eq. R2.7假定了所有正D_S增量都来自"编码-解码"循环 (信息先进入E后回流), 但自逆振荡来自"关联-释放" (S-E关联中被存储的区分度通过自逆CNOT释放到S边缘)。前者消耗鸽巢容量, 后者不消耗。

**判定:** ⛔ **A博士的界未覆盖自逆振荡机制。** 这是一个发现而非推导错误 — 但需要在最终定理中明确标注适用边界 (q_E≠1/2, 即非最大混合环境)。

## Q5. 代数验算

### Q5.1 ⛔ Eq. R2.5 的数学错误 (N_BLP ≤ D_S(0) - D_S_min)

**Eq. R2.5原文**: "N_BLP = Σ_{ℓ: Δ_ℓ>0} Δ_ℓ ≤ D_S(0) - D_S_min ≤ D_S(0) ≤ 1"

**验算**:

令 D_S 沿时间序列取值为 d_0, d_1, d_2, ..., d_T。
N_BLP = Σ_{i: d_i > d_{i-1}} (d_i - d_{i-1})  (所有正增量之和)
D_S_min = min_i d_i

**声张**: Σ_{i: d_i > d_{i-1}} (d_i - d_{i-1}) ≤ d_0 - min_i d_i

**反例**:
取 d = [0.8, 0.2, 0.6, 0.2, 0.8]
正增量: (0.6-0.2) + (0.8-0.2) = 0.4 + 0.6 = 1.0
D_S(0)-D_S_min = 0.8 - 0.2 = 0.6
N_BLP = 1.0 > 0.6

**结论: 不等式 Σ Δ_ℓ^+ ≤ D_S(0) - D_S_min 在数学上不成立。** 这是对"正增量之和不超过起点到最低点的总距离"的错误直觉 — 当D_S在下降-上升-再下降-再上升的循环中多次振荡时, 正增量之和可以远超D_S(0)-D_S_min。

**补充**: 即使加上D_S(t) ≤ D_S(0) (定理0)的约束, 该反例仍然有效 — 所有取值≤0.8。

**但是**: A博士的模型中有额外约束 — D_S只能在Type R门改变, 且Type R门的数量受限于鸽巢原理。对于N_S=2系统, 最多4次Type R事件。这限制了振荡次数。但在4次事件下:
d = [0.8, 0, 0.8, 0, 0.8] (down, up, down, up)
N_BLP = 0.8 + 0.8 = 1.6
D_S(0)-D_S_min = 0.8 - 0 = 0.8
仍有 N_BLP > D_S(0)-D_S_min 的可能。

**核心问题**: A博士是否将定理0 (D_S(t) ≤ D_S(0) ∀t) 误读为 N_BLP ≤ D_S(0)? 定理0只约束了D_S(t)的上界, 不约束正增量之和。

**影响**: Eq. R2.5是整个N_BLP ≤ D_S(0)约束的基础, 而后者又构成了min(D_S(0), ...)的一半。如果Eq. R2.5错误, 则:
- N_BLP ≤ D_S(0) 在此论证下不成立
- N_BLP ≤ min(D_S(0), N_S·q_S·|1-2q_E|) 中的D_S(0)部分失去支撑

**但**: N_BLP ≤ D_S(0) 可能通过其他途径证明, 或在这些特定模型约束下仍成立(尽管Eq. R2.5的证明是错误的)。A博士需要在R3中提供正确证明或撤回该声张。

**判定:** ⛔ **阻断级数学错误。** Σ Δ_ℓ^+ ≤ D_S(0) - D_S_min 在一般非单调路径上不成立。N_BLP ≤ D_S(0)的证明不成立。需要修正或另寻证明。

### Q5.2 Eq. R2.10 编码关系的验算

正向CNOT_{S_i→E_j}, E_j初始分布q(0)=q_E, q(1)=1-q_E, S_i激发概率=p_i^(k):

P^(k)(E_j=0 after) = P^(k)(S_i=0 ∧ E_j=0) + P^(k)(S_i=1 ∧ E_j=1)
= (1-p_i^(k))·q_E + p_i^(k)·(1-q_E)
= q_E - p_i^(k)·q_E + p_i^(k) - p_i^(k)·q_E
= q_E + p_i^(k)·(1 - 2q_E)

P^(k)(E_j=1 after) = 1 - [q_E + p_i^(k)·(1-2q_E)] = (1-q_E) - p_i^(k)·(1-2q_E)

Δp_j^E = |P^(1)(E_j=0) - P^(2)(E_j=0)|
= |[q_E + p_i^(1)(1-2q_E)] - [q_E + p_i^(2)(1-2q_E)]|
= |(p_i^(1) - p_i^(2))·(1-2q_E)|
= |p_i^(1) - p_i^(2)| · |1-2q_E|
= δ_i · |1-2q_E| ✓

**验算**: 代数无误。

**但在多轮演化中的适用性**: A博士在§5.2(第二个可疑前提)中承认, Eq. R2.10假设E_j在正向CNOT前处于初始态。多轮演化中E_j可能被前面的操作修改, 编码效率可能偏离|1-2q_E|。这是诚实的自我攻击。

**判定:** ✓ 编码关系在首次编码时严格成立, 在多轮场景中的偏差被标注但未量化。

### Q5.3 §4.3 数值演算验证 — g3门后的D_S计算

**设定**: N_S=2, N_E=2, q_S=0.5, q_E=0.3, |1-2q_E|=0.4, δ_1=0.8, δ_2=0

验证g3 (CNOT_{E1→S1})后的D_S = 0。

A博士计算:
门g3前联合分布:
P^(k)(s1,s2,e1,e2) = p_1^(k)(s1) · p_2^(k)(s2) · q(e1⊕s1) · q(e2⊕s1)

门g3后:
P'^(k)(s1',s2,e1,e2) = P^(k)(s1'⊕e1, s2, e1, e2) [门g3前]
= p_1^(k)(s1'⊕e1) · p_2^(k)(s2) · q(e1⊕(s1'⊕e1)) · q(e2⊕(s1'⊕e1))

### Q6.3 声张演变

**R1 → R2 声张变化:**

R1 Theorem A: N_BLP ≤ N_S · q_S · |1-2q_E|
R2 Theorem: N_BLP ≤ min(D_S(0), N_S · q_S · |1-2q_E|)

**是扩大还是缩水?**

加了 min(D_S(0), ...) 后, 声张是**缩水**(更紧)还是**扩大**(更松)?

min(D_S(0), X) ≤ X (其中X = N_S·q_S·|1-2q_E|)

所以 R2 的界 ≤ R1 的界。声张**缩水**了 — 通过引入D_S(0)约束, R2的界更紧(更小)。

**但**: 这取决于D_S(0) < N_S·q_S·|1-2q_E|。如果D_S(0)更大, min取X, 则R2=R1 (声张不变)。

**实际缩水量级:**

对于R1典型参数(N_S=4, q_S=0.5, |1-2q_E|=0.5):
R1: 4·0.5·0.5 = 1.0 → min(1, 1.0) = 1 (平凡)
R2: min(D_S(0), 1.0) — 若D_S(0)=0.8 → min(0.8, 1.0) = 0.8 (非平凡!)

R2通过D_S(0)项**在D_S(0)<1时产生非平凡界**, 这是相对于R1的实际改进。

**但这是以Eq. R2.5的错误(见⛔1)为代价的。** 如果N_BLP ≤ D_S(0)不成立, min(D_S(0), ...)形式的界就失去了这一半的支撑。

**判定:** ⚠️ 声张在形式上缩水(更紧), 但缩水依赖的D_S(0)约束本身有证明缺陷。
