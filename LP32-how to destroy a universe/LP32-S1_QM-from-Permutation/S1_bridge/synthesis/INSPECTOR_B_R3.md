### Q2.2 推导中是否隐含使用双向CNOT

逐一检查:

- **§1.2 单向跳L定义**: `L|x_c, x_t⟩ = |x_c, 1⟩` if x_c=1, x_t=0; otherwise unchanged。L不是酉CNOT（|11⟩→|10⟩被禁止），M3合规 ✓
- **§2.2 W_1收缩证明**: 使用L的确定性映射版本f，论证f的Lipschitz常数≤1（在地面度量下）。L作为f的定义与M3一致 ✓
- **§2.7 编码效率**: 明确说明"正向编码操作仍然使用完整CNOT（因为目标E_j初始为|0⟩，单向跳等同于酉CNOT在此情况下的作用）"。M3合规 ✓
- **§3.2 step 5 ⛔**: "每个E_j的W_1在一个回流中被'读空'——因为跳后E_j的区分度被混叠到S_i中，而E_j自身因跳的非双射性丢失了区分度。"

**这是M3一致性的关键问题。** L作为Type R跳（E_j控制，S_i目标）:
```
L(E_j=1, S_i=0) → (E_j=1, S_i=1)
L(E_j=1, S_i=1) → (E_j=1, S_i=1)  [恒等]
L(E_j=0, S_i=*) → (E_j=0, S_i=*)   [恒等]
```

**关键事实**: L保留控制qubit E_j的状态（在M3下，这是设计如此——|1⟩→|0⟩被禁止，所以E_j作为控制qubit不可能改变）。E_j的边缘分布（|1⟩概率）**不变**。如果两个副本中E_j的边缘区分度为δ_j^E = |p^(1)(E_j=1) - p^(2)(E_j=1)|，则经过Type R跳后，p'^(1)(E_j=1) = p^(1)(E_j=1)（质量在S_i子空间间转移但E_j边缘不变），E_j的区分度**不变**。

因此，E_j的W_1 NOT被"读空"。E_j的信息是**复制**到S_i而非**转移**到S_i。

**判定:** ⛔ §3.2 step 5 "E_j的W_1被读空"是数学错误。这与M3无关——即使在酉CNOT下，控制qubit也不改变。B博士误解了L的非双射性含义：非双射性消除的是（E_j=1, S_i=0）和（E_j=1, S_i=1）这两个不同输入态的**可区分性**（它们映射到同一输出态），但这不改变E_j的边缘分布。L的"信息擦除"发生在联合分布的**S_i子空间**上，而非E_j的边缘上。

## QB1. W_1收缩证明

### QB1.1 Lemma 1 (W_1收缩)

**声张** (§2.2): `W_1(L_#p, L_#q) ≤ W_1(p, q)`

**验证:**
B博士的证明: L实现为确定性映射f: {0,1}^N → {0,1}^N。则
W_1(f_#p, f_#q) = sup_{g:Lip≤1}[E_p[g∘f] - E_q[g∘f]]

由于地面度量d=1_{x≠y}取值为{0,1}，任意函数g的Lipschitz常数都不超过1，而g∘f也不超过1。因此上确界在更小的函数类上取得，W_1(f_#p, f_#q) ≤ W_1(p, q)。

**形式正确性**: 对任意满足Lip(f)≤1的确定性映射f，此不等式成立。在地面度量d=1_{x≠y}下，所有映射的Lipschitz常数自动≤1（因为d只取0或1，d(f(x),f(y))≤1恒成立）。

**判定:** ✓ Lemma 1证明在数学上成立。L是W_1收缩（非等距），与R2的"CNOT=W_1等距"形成正确对比。

### QB1.2 Lemma 2 (收缩量)

**声张** (§2.5): `W_1(p,q) - W_1(L_#p, L_#q) = |a-b|`，其中a=p(A), b=q(A), A={态: c=1, t=0}。

**验证:**

B博士将空间划分为三个子集: A（c=1,t=0，被擦除）、B（c=1,t=1，与A的输出重叠）、C（其余）。

问题在于"将所有部分求和后，总L1恰好减少|a-b|"这个结论。考虑具体反例:

取c=1,t=0（A集）和c=1,t=1（B集）两个态，其他qubit固定（即只考虑2qubit简化）。
- p(A)=0.3, p(B)=0.5; q(A)=0.1, q(B)=0
- L前L1 = |0.3-0.1| + |0.5-0| = 0.2 + 0.5 = 0.7
- L后: A消失，B接收A的质量: p'(B)=0.8, q'(B)=0.1
- L后L1 = 0 + |0.8-0.1| = 0.7
- 收缩量 = 0.7 - 0.7 = 0 ≠ |0.3-0.1| = 0.2

**此反例直接反驳了Lemma 2的等式形式。**

实际上，W_1收缩量取决于A和B中质量的符号关系:
- 若p(B)-q(B)与a-b同号: |p(B)+a-q(B)-b| = |p(B)-q(B)| + |a-b| → L1不减反增（但受限于其他约束）... 等等，A消失贡献-|a-b|，B贡献+|a-b|（若同号）。净变化取决于符号。

**更精确的分析**: L将A中的每个态映射到B中的对应态（相同rest比特）。对每对(A_state, B_state)：
- L前贡献: |p_A - q_A| + |p_B - q_B|
- L后贡献: |p_A+p_B - q_A-q_B|（A_state和B_state映射到B_state的输出）
- 差值 = |p_A - q_A| + |p_B - q_B| - |(p_A+p_B) - (q_A+q_B)|
- 由三角不等式: |p_A - q_A| + |p_B - q_B| ≥ |(p_A+p_B) - (q_A+q_B)|
- 差值 ≥ 0，等号当且仅当(p_A-q_A)与(p_B-q_B)同号。

因此收缩量 = Σ_{(A_state, B_state)} [|p_A-q_A| + |p_B-q_B| - |(p_A+p_B)-(q_A+q_B)|]。这是一个**非负和**，但一般来说 ≠ |a-b|。|a-b| = |Σ p_A - Σ q_A|，而收缩量涉及逐对贡献。

**判定:** ⚠️ Lemma 2的等式形式（收缩量=|a-b|）是**过度简化**。定性结论（W_1在L下收缩）正确，但定量公式不精确。这不影响主定理的成立（主定理不依赖精确收缩量），但影响B博士声称的"W_1框架独特洞察"——引理2的精确核算需要更细致的逐对分析。

### QB1.3 ⛔ 核心错误: E_j信息被"读空" (§3.2 step 5, step 3)

**§3.2 step 3**: "根据引理2，这个跳同时擦除W_1"

引理2讨论的是L将子空间A（c=1,t=0）的概率质量合并到B（c=1,t=1）时，**联合分布** W_1的收缩。这种收缩不影响E_j的边缘分布——E_j作为控制qubit，在L下其态不被修改。

E_j边缘区分度: δ_j^E = |p^(1)(E_j=1) - p^(2)(E_j=1)|
L后: p'^(1)(E_j=1) = p^(1)(E_j=1, S_i=0) + p^(1)(E_j=1, S_i=1) = p^(1)(E_j=1)
（质量从(E_j=1, S_i=0)移到(E_j=1, S_i=1)，E_j=1的总概率不变）

因此**E_j的边缘区分度不变**。B博士的"E_j的W_1被读空"混淆了联合W_1与边缘W_1。

**§3.2 step 5**: "每个E_j的W_1在一个回流中被'读空'——因为跳后E_j的区分度被混叠到S_i中，而E_j自身因跳的非双射性丢失了区分度" + "每个编码过的E-qubit至多支持一次有效回流"

这是**错误**的。E_j的边缘区分度在Type R跳后**保留**。同一个E_j可以作为多次Type R跳的控制（面向不同的S_i目标），每次都可能贡献D_S增量。这是**A博士§1.5识别的同一问题**——E信息可复用。

**后果**: N_E·q_E作为硬约束的前提不成立。Type R跳次数受限于S侧容量（每次消耗一个S-qubit的|0⟩→|1⟩配额），而非E侧容量。在纯M3下，min(N_S·q_S, N_E·q_E)中的N_E·q_E分支不构成独立硬约束——除非引入额外假设（E信息不可复用，或退相干在回流后抹除E_j信息）。

**判定:** ⛔ **阻断级错误。** B博士的N_E·q_E分支论证依赖一个不成立的前提（E_j信息在回流中消耗）。E-qubit作为控制qubit在CNOT/L下态不变是基本事实。此错误使Theorem B_v3的min形式失去一半的数学支撑。

## QB2. 吸收态相变框架

### QB2.1 UBP→DP普适类的映射

B博士§4.2定义"单向燃烧过程"（UBP）:
- 态空间: {0,1}^N
- 转移: 挑选(1,0)→(1,1)
- 吸收: 全|1⟩
- 总跳数: N_0_init = N_S·q_S + N_E·q_E（期望值）

B博士在§4.3中**自己承认**: "UBP（无恢复）下的吸收是平凡的（确定的N_0步）。"

B博士在§4.2中给出的"总跳数=N_0_init"使用了M3——没有|1⟩→|0⟩恢复，所以每个|0⟩恰好燃烧一次。这是对M3的正确使用。

### QB2.2 映射的严格性

**严格的部分**:
- UBP确实是一个吸收态马尔可夫链 ✓
- 吸收态（全|1⟩）是唯一的 ✓
- 吸收时间是确定性的（N_0步） ✓
- UBP是接触过程（CP）的"零恢复率极限"——这是正确的家族成员关系 ✓

**不严格的部分**:
- "UBP→DP普适类": DP（directed percolation）普适类要求存在非平凡的吸收态相变——即存在一个临界参数使得吸收概率在临界点附近连续变化。UBP无噪声（无|1⟩→|0⟩恢复），吸收概率恒为1（所有初始态最终到达吸收态），不存在相变。UBP不属于DP普适类——它属于**平凡吸收**类。
- B博士在§4.5承认: "虽然UBP（无恢复）下的吸收是平凡的（确定的N_0步），但如果我们引入退相干噪声...UBP就变成了真正的接触过程。" ——这说明B博士自己知道UBP本身不在DP普适类中。
- §4.4声称吸收态框架提供了"更结构化"的界，但最终界（min(N_S·q_S, N_E·q_E)·|1-2q_E|）与吸收态框架的分析独立——吸收态框架只是给出了"总跳数=N_0_init"，而最终界并未使用这个信息。

**判定:** ⚠️ 吸收态相变框架的**概念映射**成立（UBP ∈ 吸收态系统），但"DP普适类"声称不成立（UBP不在DP普适类中，因无相变）。B博士自己承认了这一点（§4.4, §9攻击3的回应）。框架的价值在于**未来推广**（含噪声的sUBP可能有真正的相变），而非收紧M3下当前系统的界。在B博士§9攻击3的自我回应中，坦率地标注了Task 3"更多是框架性的而非计算性的"——这是诚实的，但未改变框架对当前定理无新增约束力的事实。

## QB3. 自逆振荡定量边界

### QB3.1 声张 (§5.3)

`N_BLP ≤ min(N_S, N_E) · D_S(0)`（非M3, q_E=1/2）

### QB3.2 推导检查

B博士的推导:
1. D_SE守恒（酉CNOT） ✓
2. D_S在[D_S_min, D_S(0)]内振荡 ✓
3. 每次完整振荡贡献N_BLP = 回升量 ✓
4. 振荡次数 ≤ CNOT序列中的独立振荡环数
5. 每个振荡环消耗至少一个S-qubit和至少一个E-qubit的配对
6. 最多独立振荡环数 ≤ min(N_S, N_E)
7. 每个环贡献 ≤ D_S(0)
8. N_BLP ≤ min(N_S, N_E) · D_S(0)

### QB3.3 问题

**步骤5的"配对消耗"在非M3下不成立**: 在酉CNOT下（无M3），|1⟩→|0⟩翻转**允许**。一个S-qubit可以经历多次|0⟩↔|1⟩振荡（通过CNOT²=I）。同样，一个E-qubit也可以被多次使用（通过CNOT²=I恢复）。

在q_E=1/2时，E-qubit的最大混合态意味着CNOT_{E_j→S_i}的效果是以1/2概率翻转S_i。这本质上是一个随机翻转操作。两个CNOT_{E_j→S_i}连续作用恰好恢复原态（CNOT²=I）。

因此，**同一对(S_i, E_j)可以产生任意多次振荡**（只要序列中有足够多的CNOT门），每次振荡的回升量取决于中间态。振荡次数不受min(N_S, N_E)限制——它受限于序列长度和D_S振荡幅度的衰减（由于混叠效应）。

**修正**: 在非M3下，N_BLP的上界应基于总CNOT事件数和每次事件的平均回升量，而非简单的min(N_S, N_E)·D_S(0)。B博士的界可能低估了（若同一对(S,E)可多次振荡）或高估了（若衰减效应使后期振荡幅度远小于D_S(0)）。

**Case 5验证** (§5.3): N_S=2, N_E=1, min=1, D_S(0)=0.6 → N_BLP ≤ 0.6。但R2 Case 5报告0.800。B博士推测0.800可能是数值错误——这一推测是合理的（0.800 > D_S(0) 在有CNOT序列长度限制下需要检查），但未提供独立验证。

**判定:** ⚠️ 自逆振荡的定量边界推导有多个未验证的步骤（步骤5的配对消耗、步骤7的每环贡献≤D_S(0)在混叠效应下的保守性）。min(N_S, N_E)·D_S(0)是一个合理的**初始估计**但未被严格证明。这不影响M3下的主定理（自逆振荡在M3下被排除）。
