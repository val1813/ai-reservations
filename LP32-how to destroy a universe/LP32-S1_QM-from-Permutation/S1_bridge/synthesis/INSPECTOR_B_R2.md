## Q2. 符号/方向校对

### Q2.1 "delta_max_per_reverse_CNOT ≤ |1-2q_E|" — 验证

**来源链：**
1. A博士R1 Eq. 7: Δp_j^E = δ_i · |1-2q_E|（正向CNOT编码效率）
2. 反向CNOT(E_j → S_i)使用E_j作为控制，E_j的|1⟩概率差驱动S_i的翻转概率差

**判定：** ✓ 对标准"编码-解码"循环（正向CNOT编码到环境边缘，反向CNOT利用环境边缘区分度）而言成立。

### Q2.3 "自逆振荡q_E=1/2, CNOT²=I" — 验证

## Q5. 代数验算

### Q5.1 最优传输推导链逐步验证

**Step 1-3 (W_1初始值、置换等距、边缘收缩):** 数学恒等式，无问题。 ✓

**Step 4-5 (Benamou-Brenier速度场→BLP积分=正向动能):**
- BB表述: W_1(p,q) = inf_{(ρ_t,v_t)} ∫₀¹ ∫_X |v_t(x)| ρ_t(dx) dt, 约束 ∂_tρ + div(ρv) = 0.
- BLP积分定义为 ∫_{dD_S/dt > 0} (dD_S/dt) dt.
- BLP积分 = W_1沿CNOT轨道的"正向弧长": 概念上等价（BLP度量所有D_S增加区间的积分，BB度量所有速度正向分量的积分）。形式上有差异：BB使用W_1测地线的最小速度场（不是CNOT轨道本身的速度场），而BLP使用实际D_S变化率。CNOT轨道不是W_1测地线（Section 8深挖1正确指出）。
- 因此 "BLP积分 = ∫_{v_t正向} v_t dt" 中的v_t应该是**CNOT轨道的实际速度**而非BB最小速度。B博士在Step 5-7中的用法是合理的：v_t是实际演化速度（由CNOT toggle事件决定），BB框架提供的是W_1的可选表征形式，而非实际轨道必须沿BB测地线。此用法在以下意义上有效：W_1沿任意曲线的变化率被速度场的大小上界化。

**判定：** ✓ 基本正确。BB框架作为启发工具是合适的（提供W_1变化率的上界），而非作为轨道约束。

**Step 6-7 (鸽巢+最终界):**
- N_back ≤ N_S · q_S: 鸽巢原理——每个S qubit的|0⟩→|1⟩翻转至多一次。 ✓
- max|v| ≤ |1-2q_E|: 编码效率限制每个反向CNOT的W_1变化。⚠️ 在"编码-解码"机制下成立，在"关联-释放"机制（q_E=1/2）下不成立（见Q2.1）。

**判定：** 推导链在标准情形（q_E ≠ 1/2）下自洽。q_E=1/2构成奇点。

### Q5.2 D_S(0)作为N_BLP的界 — 类别错误 ⛔

**B博士声称（Section 5.1, Theorem B）：** N_BLP ≤ D_S(0)（"全空间守恒界"）。

**验证：**

D_S(t) ≤ D_S(0) 对所有t成立（Theorem 0，A博士和B博士均证明了）。这是**瞬时值**的界。

N_BLP = ∫_{dD_S/dt > 0} (dD_S/dt) dt 是**正增量积分**。

从D_S(t) ≤ D_S(0)不能推出N_BLP ≤ D_S(0)。反例：
- D_S(0) = 0.6
- 轨迹: 0.6 → 0.2 → 0.6 → 0.2 → 0.6
- D_S(t) ≤ 0.6 对所有t成立 ✓
- N_BLP = (0.6-0.2) + (0.6-0.2) = 0.4 + 0.4 = 0.8 > 0.6 = D_S(0) ✗

**B博士自己的Case 5证实了此类别错误：** N_BLP=0.8000 > D_S(0)=0.6000。B博士在Section 4.3正文中标注了此异常但不解决。

**N_BLP ≤ D_S(0)的正确推导应为：**
- 每个单独的ΔD_S增加 ≤ D_S(0)（从min到max的幅度受D_S(0)约束）— 这是对的
- 但多个增加区间的总和可以超过D_S(0) — 这是B博士遗漏的

**正确结论：** D_S(0)不是N_BLP的上界。它只是单次回升幅度的上界。总回升额由"回升次数 × 单次回升幅度"决定。

**判定：** ⛔ **阻断级逻辑错误。** 将瞬时值的界错误地应用于积分量。

### Q6.4 替代解释检查

#### Q6.5.2 自逆振荡手工验证（q_E=0.5, N_S=1, N_E=1）

**设定：** p_S^(1) = diag(a, 1-a), p_S^(2) = diag(b, 1-b)。p_E = diag(½, ½)。

- D_S(0) = |a-b|
- CNOT(E→S)_1: p_SE中各基矢被置换。D_S降至|½-½|某种组合（通常<D_S(0)）
- CNOT(E→S)_2: CNOT²=I → D_S恢复至D_S(0)
- N_BLP贡献(第2次CNOT) = D_S(0) - D_S_after_first

这证明q_E=1/2时N_BLP可以非零，且编码界|1-2q_E|=0不约束它。自逆振荡的描述（CNOT²=I→恢复机制）在数学上是正确的。

#### Q6.5.3 Case 5 (N_BLP=0.8 > D_S(0)=0.6)的可能性分析

**问题：** N_S=2下D_S(t)的最大振荡幅度是多少？

**初步分析：** 对N_S=2, N_E=1, q_E=0.5，单次CNOT(E→S_i)将D_S从0.6降至某个值d_min。CNOT(E→S_i)再次作用恢复至0.6。单次完整恢复 = 0.6 - d_min。

**需要d_min的值来判断0.8是否可能。** 如果d_min=0.2（两次CNOT后恢复0.4的D_S），则：
- 一次完整振荡: N_BLP += 0.4
- 两次振荡: N_BLP = 0.8（需要4次CNOT）
- 5次CNOT可容纳2次完整振荡+1次残余 → N_BLP可达0.8

所以0.8在数学上可能，前提是d_min可取到0.2。**但我无法在不运行完整枚举的情况下确认。** B博士标注"需要重新检查"是正确的谨慎。

**判定：** ⚠️ Case 5数值待独立验证。当前的记录状态（标注"需要重新检查"+定理未更新）是不完整的。
