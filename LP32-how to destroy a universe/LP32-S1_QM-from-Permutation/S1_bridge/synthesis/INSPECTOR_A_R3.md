## Q1. 汇合验证

### Q1.1 核心界的形式

A博士Theorem R3: `N_BLP ≤ N_S · q_S · |1-2q_E|`
Corollary R3.1: `N_BLP ≤ min(N_S·q_S, N_E·q_E) · |1-2q_E|`（带附加假设）

B博士Theorem B_v3: `N_BLP ≤ min(N_S·q_S, N_E·q_E) · |1-2q_E|`（作为主定理）

**表面上**: 两方都到达了PI决议中的S-E对称容量界。
**实质上**: 汇合是**不对称的**。

A博士对min(N_S·q_S, N_E·q_E)中N_E·q_E分支做了深入审查（§1.5-1.6），发现E-qubit的编码信息在Type R回流中不被消耗（CNOT控制qubit态不变），因此同一E-qubit可驱动多次回流。A博士据此将"安全"定理降级为`N_BLP ≤ N_S·q_S·|1-2q_E|`（无min），将min形式降为Corollary（需"E信息不可复用"的附加假设）。

B博士的min形式依赖§3.2 step 5中声称"E_j的W_1在一个回流中被'读空'"——这一声称在数学上不正确（控制qubit在CNOT/L下态不变）。详见INSPECTOR_B_R3 QB1。

**判定:** ⚠️ 部分汇合但不对称。A博士的版本更诚实——正确识别了N_E·q_E分支的物理限制度。B博士到达了相同表达式但基于一个有缺陷的论证。

### Q1.2 推导路径独立性

A博士路径: 组合方法（鸽巢原理 + Type F/R分类 + 编码关系）
B博士路径: W_1收缩半群方法（单向跳的W_1几何 + 投影分析）

**两条路径确实是独立的。** A博士使用离散事件计数，B博士使用连续W_1几何。两方都引用了共同的Fact F1（Type F不变D_S）和Fact F2（编码关系|1-2q_E|），但这些是R1-R2已建立的数学事实，不是推导中的依赖关系。

## QA1. Lemma 1的严格性

### 声张
"每个产生ΔD_S>0的Type R门必须消耗S侧鸽巢配额"（§1.2 Lemma 1）

### 验证

**Lemma 1证明结构:**
1. 门CNOT_{E_j→S_i}将S_i翻转为S_i⊕E_j。
2. 若E_j = |0⟩ → S_i不变 → D_S不变。考虑E_j = |1⟩。
3. 若S_i初始|1⟩ → |1⟩⊕|1⟩ = |0⟩ → |1⟩→|0⟩翻转。M3c禁止。
4. 因此S_i必须初始|0⟩。
5. |0⟩→|1⟩翻转消耗一次鸽巢配额（M3a）。
6. 若S_i初始|0⟩但δ_i=0（两副本边缘相同）→ 翻转不产生区分度变化 → ΔD_S=0。鸽巢被消耗但D_S不变——不计入K⁺。

### D_S变化机制覆盖检查

在CNOT-only模型（M4）下，D_S变化只能通过S-qubit状态的改变实现。影响S-qubit的门:
- **Type F (S→E)**: S为控制。CNOT不改变控制qubit → S-qubit不变 → D_S不变。Fact F1。覆盖 ✓
- **Type R (E→S)**: S为目标。S_i经历 S_i⊕E_j。这是**唯一**可能改变D_S的门类。覆盖 ✓

在Type R门下，Lemma 1覆盖了所有情况:
- E_j=|0⟩: 无效果 → ΔD_S=0 ✓
- E_j=|1⟩, S_i=|0⟩: |0⟩→|1⟩ → 消耗配额，可能ΔD_S>0 ✓
- E_j=|1⟩, S_i=|1⟩: |1⟩→|0⟩ → M3禁止 ✓

**所有可能的D_S变化机制均被覆盖。** 唯一需要注意的是"δ_i=0时消耗配额但ΔD_S=0"的边缘情况——Lemma 1的结语正确指出"仅计数产生正ΔD_S的事件"。

### 严格性结论

在M3下，Lemma 1是**演绎证明**——每一步都来自M3的逻辑推论或CNOT的基本属性，无未闭合假设。

**判定:** ✓ 通过。Lemma 1在M3下严格。

## QA2. N_E→N_S·q_S论证

### 声张
"物理约束主导权变更"——从环境信息池容量切换到系统接收容量。

### 验证

**第一步（R1 Eq. 17的局限）**: A博士正确识别R1 Eq. 17 (`N_BLP ≤ N_E·|1-2q_E|`) 的问题：(a) 未考虑E-qubit初始|1⟩态不能接收编码，(b) 假定了E侧是唯一约束。 ✓

**第二步（S侧约束优先）**: 在M3下，回流事件数受S侧鸽巢限制（Lemma 1, K⁺ ≤ N_S·q_S）。每次回流≤|1-2q_E| → N_BLP ≤ N_S·q_S·|1-2q_E|。这是严格推导。 ✓

**第三步（E侧约束分析）**: A博士§1.5-1.6详细分析了E侧容量是否构成独立硬约束。关键发现:
- CNOT下控制qubit不变 → E_j的编码信息可被多次读出
- 同一E_j可服务多个不同的S_i（每次消耗一个S侧配额）
- 因此E侧容量**不**独立限制回流次数（在纯M3下）
- N_E·q_E分支仅在"E信息不可复用"的附加假设下成立 ✓

**第四步（N_E·q_E < N_S·q_S的情况）**: A博士§1.6.1明确讨论了这一情况。"当N_S·q_S > N_E·q_E时（S资源大于E资源），E侧不限制回流次数——因为同一E的信息可复用。" 论证是完整的——E侧在此情况下确实是**非瓶颈**的。 ✓

### 完整度评估

A博士的论证**超预期地完整**。不是简单地从N_E替换到N_S·q_S，而是给出了一个物理上诚实的分析：为什么在M3下S侧比E侧更基本，以及N_E·q_E分支在什么条件下有效。

**判定:** ✓ 完全通过。论证比PI决议要求的更深入。
