## 一、汇合判断：极强 → 但汇合在一个有漏洞的界上

两个博士再次独立收敛到同一表达式 `min(D_S(0), N_S·q_S·|1-2q_E|)`。但两个 INSPECTOR **独立发现了同一个致命问题**：

### 核心错误：D_S(0) 不是 N_BLP 的上界

**D_S(t) ≤ D_S(0) ∀t 是正确的**（瞬时值约束）。但 **N_BLP 是积分量**：`N_BLP = Σ_{Δ>0} Δ`。多轮振荡可以使 N_BLP 超过 D_S(0)。

反例（INSPECTOR-A构造）：D_S路径 [0.8, 0.2, 0.6, 0.2, 0.8] → N_BLP=1.0 > D_S(0)=0.8。

**B博士自己的数据确认了这一点**：Case 5 (q_E=0.5) 中 N_BLP=0.800 > D_S(0)=0.600。

**结论：`min(D_S(0), ...)` 中的 D_S(0) 分支不是 N_BLP 的有效上界。需要移除或替换。**

## 二、需要替换 D_S(0) 的是什么？

两个博士都错过了一个更基本的约束。回到**严格单向模型**（Lindblad跳算符 `|1⟩⟨1|⊗|1⟩⟨0|`，无逆通道）：

### 模型澄清

CNOT 门在计算基上是双向置换（|10⟩↔|11⟩），技术上允许 |1⟩→|0⟩。原始论文用量子达尔文主义（Kac重现时间>宇宙年龄）论证 |1⟩→|0⟩ 在物理上被禁止。

**对BLP桥推导：我们必须显式假设严格单向性**——这是模型的一部分，不是漏洞。在这个假设下：
- |1⟩→|0⟩ 翻转永不发生
- 自逆振荡 (CNOT²=I, q_E=1/2) 被排除（它需要双向CNOT）
- 每个S-qubit至多经历一次 |0⟩→|1⟩ 翻转

### 真正有效的上界

在严格单向假设下，**每个正 ΔD_S 事件消耗一次鸽巢配额**（A博士的前提7变为模型假设而非需要证明的命题）：

```
N_BLP ≤ N_S · q_S · |1-2q_E|
```

这个界：
- 不使用 D_S(0)（D_S(0) 对积分量无约束力）
- 对 N_S 较大的系统可能 > 1（松但非平凡——对于 N_S ≤ 4 且适度参数下，给出 < 1 的非平凡约束）
- 在 q_E=1/2 时给出 N_BLP=0（|1-2q_E|=0，严格单向模型下不存在自逆振荡）

**如果需要更紧的界**：可以利用"总E区分度池"约束。在严格单向模型下，每个E-qubit至多经历一次正向编码（|0⟩→|1⟩），总E区分度 ≤ N_E·q_E·|1-2q_E|。结合鸽巢：

```
N_BLP ≤ min(N_S·q_S, N_E·q_E) · |1-2q_E|
```

这个界对称地处理S和E容量，当 N_E ≪ N_S 时给出更紧的约束。
