## 一、最终结论

### 被严格证明的（在M3下）

```
N_BLP ≤ N_S · q_S · |1-2q_E|
```

**证明链（A博士 R3，Lemma 1-3）：**
1. M3: 每个qubit至多一次|0⟩→|1⟩翻转，无逆通道
2. Type F门（S→E）不改变D_S（数学事实，R2 §1.1，INSPECTOR验算通过）
3. Type R门（E→S）是唯一改变D_S的操作
4. 每个产生ΔD_S>0的Type R门必然消耗S侧|0⟩→|1⟩配额（M3禁止|1⟩→|0⟩）
5. Type R门总数≤N_S·q_S（鸽巢原理）
6. 每次Type R门的ΔD_S≤|1-2q_E|（编码关系，R1 Eq. 7，双路径验算通过）
7. ∴ N_BLP ≤ N_S·q_S·|1-2q_E|

### 被推翻的

| 声张 | 状态 | 推翻原因 |
|------|:----:|---------|
| N_BLP ≤ min(N_S·q_S, N_E·q_E)·|1-2q_E| | ❌ N_E·q_E分支未证明（E信息可复用） |
| N_BLP ≤ D_S(0) | ❌ | 类别错误：D_S(0)约束瞬时值，不约束积分量 |
| N_BLP ≤ JS(p1||p2) | ❌ | R2数值证伪（B博士 Case 1-5） |
| 原始PRL A7编码关系 | ❌ | 错误：使用了平均q_S而非个体δ_i |

### 核心物理发现（保留价值，不因REJECT而消失）

1. **编码效率 |1-2q_E|**: 原始A7是错误的平均场近似。正确的严格编码关系是Δp=δ·|1-2q_E|。（A博士R1，双路径验证）
2. **Type F门D_S不变**: 纯正向CNOT不改变系统边缘分布——信息以S-E关联形式编码而非D_S变化。（A博士R2）
3. **CNOT编码的W_1几何**: 对角态下迹距离=W_1恒等式。编码效率是W_1传输容量的自然因子。（B博士R2-R3）
4. **Pointer basis = argmin_E[N_BLP]判据**: 量子达尔文主义的W_1几何表述——最优pointer basis最小化期望非马尔可夫回流。（B博士R3深挖1）

## 二、无法逾越的障碍

### 障碍1: N_S标度（FATAL，无法修复）

N_S·q_S·|1-2q_E|在N_S≥5（典型参数）下≥1，退化为平凡界N_BLP≤1。

| N_S | 典型g值(q_S=0.5, |1-2q_E|=0.5) | 有效界 |
|-----|----------------------------------|--------|
| 1 | 0.25 | 0.25 |
| 2 | 0.50 | 0.50 |
| 3 | 0.75 | 0.75 |
| 4 | 1.00 | 1.00 |
| 5 | 1.25 | 1.00（平凡） |
| 10 | 2.50 | 1.00（平凡） |

**根本原因**: 界∝N_S，但物理上N_BLP不应随系统规模线性增长——更大的系统意味着更强的稀释，而非更多的回流。REVIEWER正确指出这是"标度灾难"。三轮研究未能解决此问题。

**是否存在不随N_S增长的界？** 三轮探索后，答案似乎是"在M3假设下不存在更紧的界"。如果要突破：
- 需要放弃M3，考虑双向CNOT + 退相干抑制
- 或找到N_BLP的实际标度行为（可能∝√N_S而非∝N_S）
- 或接受此界只约束小系统（N_S≤4）并改变论文定位

### 障碍2: M3在小系统中的物理正当性（MAJOR，部分可修复）

量子达尔文主义需要N_red≈100才能保证Kac重现时间>宇宙年龄。将此应用于N_total=6的系统是范畴错误。

**A博士R3 §5.3的分析**（M3失效条件表）给出了诚实的物理边界：
- 超导qubit平台，T~15mK, N_total≳10：M3是良好近似（T1≫T2，热激发可忽略）
- 对N_total<10：CNOT²=I可在2个门步内实现|1⟩→|0⟩，远在T2时间内
- **结论**: M3对N_total≲10不成立。由于界只对N_S≤4有约束力（需要N_total≈8），M3的物理正当性与界的可用参数区间恰好不重叠。

### 障碍3: E-qubit信息复用（FATAL，已精确定位）

这是三轮研究中最深刻的物理发现。

**A博士发现**: E-qubit的CNOT控制不消耗其态——编码信息可被多次"读取"到不同S-qubit。因此N_E·q_E不构成回流次数的硬约束。

**B博士的错误**: 声称E-qubit在回流中"丢失区分度"（W_1被"读空"）。这被INSPECTOR和REVIEWER独立证伪——CNOT/Lindblad控制qubit不变。

**INSPECTOR-B R3独立验证**: "CNOT/L保留控制qubit的态。E_j作为Type R门的控制qubit，其边缘分布(以及两个副本间E_j的边缘区分度)在跳前后不变。"

**结论**: min(N_S·q_S, N_E·q_E)中的N_E·q_E分支不成立。正确界是N_S·q_S·|1-2q_E|。

## 三、三轮研究的演变轨迹

```
R1: N_BLP ≤ N_S·q_S·|1-2q_E|（A博士）
    N_BLP ≤ q_S（B博士，后修正为2q_S）
    发现: 编码效率=|1-2q_E|，原始A7错误
    问题: N_S标度灾难，C^(k)未闭合

    发现: Type F门下D_S不变，Megier框架放弃
    问题: D_S(0)不被N_BLP的积分量尊重→被推翻

R3: N_BLP ≤ min(N_S·q_S, N_E·q_E)·|1-2q_E|（声称）
    发现: E-qubit信息复用问题，M3物理边界被测绘
    问题: N_E·q_E分支不成立（B博士错误+A博士诚实分析）
    → 退回 N_BLP ≤ N_S·q_S·|1-2q_E|（R1的核心界）
```

**三轮研究最终回到了R1的界**——但这并非徒劳。R2-R3排除了D_S(0)、N_E·q_E、JS散度等误导性分支，将M3的物理边界测绘清楚，并发现了E-qubit信息复用这一深刻物理事实。
