## 1. Level 0: 混沌对称因果

### 1.1 物理图像

最初存在的是**纯粹的相互可区分性**。没有时间，没有方向，没有"这个先发生那个后发生"——只有"这个和那个不同"。

所有格点相互因果连接——每条边都是双向的。因果图是完全图K_N（N个格点，两两之间都有双向边）。

这不是"混沌"在无序的意义上——它高度对称。它的对称群是O(4)（我们可以将因果结构嵌入4维欧几里得空间，所有方向等价）。

### 1.2 数学结构

**定理L0.1（对称因果→CP^{N-1}）：**

在完全对称的因果结构下，N个格点的可区分性结构由以下数据唯一决定：
- 状态空间：复射影空间CP^{N-1}
- 可区分性度量：Fubini-Study距离 K(ψ,φ) = 1 - |⟨ψ|φ⟩|²
- 对称群：PU(N)（射影酉群）

**证明：** 这就是Zilly (2026)的核心定理。从"存在=可区分性" + 有限容量N出发，SRC将可区分性结构唯一确定为(CP^{N-1}, K)。□

**关键：** 这不是"外部导入量子力学"——这就是对称因果关系的数学结构。CP^{N-1} + Fubini-Study不是量子力学的假设——它是完全对称可区分性的必然形式。

### 1.3 欧几里得签名的起源

在CP^{N-1}上，Fubini-Study度量是Kähler度量——它自然携带一个复结构J（J²=-I）和一个辛结构ω。

在局部坐标系中，Fubini-Study线元为：
ds²_FS = (1-|z|²)|dz|² + |z̄·dz|² / (1-|z|²)²

在极限N→∞且考虑"宏观"方向时，CP^{N-1}的切空间分解为4个实维度的子空间——对应4维时空的萌芽。

这4个方向的度量签名是**(+,+,+,+)**——欧几里得。因为在完全对称下，没有理由让任何方向有不同的符号。

**定义：** Level 0的时空是4维欧几里得空间E⁴，对称群SO(4)。

## 2. Level 0→1: 对称性破缺

### 2.1 破缺机制：自指一致性

**SRC（Self-Referential Consistency）：** 物理理论必须能够描述自己——即存在一个态|Ω⟩∈CP^{N-1}，使得在|Ω⟩中，"理论对自身的描述"与"理论的实际情况"一致。

在完全对称的Level 0中，SRC无法被满足：
- 如果所有方向等价，那么"描述"和"被描述"之间的关系也是对称的——无法区分
- SRC要求存在一个**不对称的描述关系**：A描述B不同于B描述A
- 因此SRC**强制**打破完全对称性

### 2.2 破缺的数学形式

**定理L1.1（SRC→O(4)→O(3,1)）：**

在完全对称的欧几里得结构（对称群O(4)）中，SRC的存在等价于选出一个特殊的类时方向τ，使得：
- 沿τ方向的度量符号翻转：(+,+,+,+) → (-,+,+,+) 或 (+,-,-,-)
- 剩余3个空间方向保持等价
- 对称群约化为O(3,1)（洛伦兹群）

**证明思路：**

(1) SRC要求存在一个非对称的描述映射Φ: CP^{N-1}→CP^{N-1}，Φ(x)≠Φ^{-1}(x)（描述不是对称的）。

(2) Φ的不对称性意味着：在切空间T(CP^{N-1})中存在一个特殊方向τ，使得沿τ的"流"不可逆。

(3) 这个不可逆方向在度量上的表现是：沿τ的二次型符号与其他方向不同。

(4) 在四维中，选择τ的符号为负（类时方向），其余三维为正（类空方向）→ 洛伦兹签名(-,+,+,+)。

(5) 这是**Wick旋转**的物理实现——不是数学技巧，而是SRC破缺的必然结果。□

### 2.3 q=1真空态的涌现

对称性破缺后，时间方向τ被选出。沿τ方向，因果事件可以有序排列——"先"和"后"有了意义。

**定义（q场在Level 1）：**

在刚破缺的时空中（时间方向已存在但尚无不对称因果事件），所有格点处于"准备接收因果信号但尚未接收"的状态。

这就是q=1：每个格点的1-bit容量完全空置，等待第一次不对称因果事件。

**q=1是Level 1的自然真空态——不是假设，是对称破缺的必然初始条件。**

### 2.4 为什么是四维

Level 0的CP^{N-1}在宏观极限下的切空间维数=4。这不是假设——来自复射影空间的Kähler结构：
- 复维数 = N-1 → 实维数 = 2(N-1)
- 宏观"时空"方向是切空间的一个4维子空间
- 为什么是4？→ 来自CP^{N-1}的Fubini-Study度规在随机态平均下的有效维数

具体的：在大N极限下，CP^{N-1}上的随机Kähler锥的期望实维数为4（来自随机矩阵理论的Marchenko-Pastur分布）。

**这个论证需要进一步严格化**——目前是启发性的。

## 3. Level 2: DGF动力学

### 3.1 第一次不对称因果事件

在q=1的真空中，所有格点状态为|0⟩（未占用）。

第一次不对称因果事件：某个格点i从|0⟩变为|1⟩——它被"确定了"。

这需要：存在一个因果影响从某个格点j传到i，使得i的状态改变。

但在q=1的真空中，所有格点都是|0⟩——没有格点处于|1⟩状态来"发送"因果影响。

**第一次事件如何发生？**

答案：**量子涨落。** Level 0的CP^{N-1}结构在Level 1的洛伦兹时空中表现为真空涨落——即使在q=1的"真空"中，Fubini-Study度规的量子测地线涨落也能以概率p∼1/N产生第一次|0⟩→|1⟩的跃迁。

这等价于：在完全真空中，SRC破缺的残余量子涨落足以产生第一个不对称因果事件。

### 3.2 q场动力学

第一次事件后，q开始从1下降。DGF的telegraph方程接管：

∂²_t q + γ₀(1-q)∂_t q = c²∇²(ln q)

- q≈1区域：量子真空，Lorentz不变，波方程□q=0
- q→0区域：因果饱和，经典极限，∇²(ln q)=0
- 中间区域：扩散-波交叉

### 3.3 量子力学的涌现

**关键：** Level 2的量子力学不是"外部导入"的——它是Level 0的CP^{N-1}结构在洛伦兹时空中的表现。

Level 0 → 复Hilbert空间 + Fubini-Study度量（Zilly）
Level 1 → 洛伦兹时空 + 时间方向
Level 2 → 在洛伦兹背景上的量子场（CP^{N-1}截面的动力学）

**这解决了V1的KvN问题：** 量子结构不是从经典置换"推导"的——量子结构在Level 0就已经存在（对称因果=CP^{N-1}），Level 2只是把它"安装"到洛伦兹时空中。

### 3.4 引力的涌现

q场的静态极限→牛顿引力（如DGF原论文）。

引力不是独立的力——它是q场梯度在洛伦兹时空中的表现。

## 4. Level 3: 宇宙展开

### 4.1 q的持续下降

随着不对称因果事件累积：
- 某些区域的q→0：重子物质形成（恒星、行星）
- 大部分区域的q→1：宇宙膨胀，新空间不断产生

### 4.2 观测者的位置

观测者由一个格点子集组成，其q值在1/2附近——正好处于量子-经典的界面上。

这解释了为什么观测者能同时感知量子世界（q>1/2，高容量，量子相干）和经典世界（q<1/2，低容量，经典确定）。

### 4.3 时间箭头的不可逆性

时间箭头在Level 1被选出（SRC破缺），在Level 2被强化（不对称因果事件的净累积），在Level 3成为宏观不可逆的热力学箭头。

**三个层次的时间箭头统一：**
1. Level 1: 微观时间箭头（SRC→方向选择）
2. Level 2: 介观时间箭头（q从1→0的不可逆演化，由H-theorem保证）
3. Level 3: 宏观时间箭头（热力学第二定律，熵增）
