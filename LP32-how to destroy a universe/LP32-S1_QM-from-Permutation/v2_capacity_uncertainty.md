## 1. 核心定理：容量有界→互补性

### 定义1（格点的两种基本可观测量）

对单个格点i：

- **状态可观测量 S_i**：格点i现在处于什么状态？
  - 值域：{0,1}（未占用/已占用）
  - 区分能力需求：log₂(2) = 1 bit

- **变化可观测量 C_i**：格点i在下一个因果步中是否改变状态？
  - 值域：{0,1}（不变/改变）
  - 区分能力需求：log₂(2) = 1 bit

### 定理1（容量强制互补性）

S_i 和 C_i 不能同时拥有无歧义的联合值。即：不存在一个函数
J: {状态} → {(s, c) : s ∈ {0,1}, c ∈ {0,1}}
使得 (s, c) 在单个因果步内对格点i同时有定义。

**证明：**

(1) 格点i的容量 = 1 bit（A2）

(2) 同时指定S_i和C_i需要区分4种可能性：
(s=0,c=0), (s=0,c=1), (s=1,c=0), (s=1,c=1)
→ 需要 log₂(4) = 2 bits

(3) 2 bits > 1 bit → 超出格点容量

(4) 因此：(S_i, C_i)的联合值在物理上不能被同一格点同时承载。

(5) 这意味着：对S_i的测量必然扰动C_i，反之亦然。
→ S_i和C_i是互补可观测量。□

### 这为什么是真正的量子结构而非KvN

**KvN中：** x和p都有连续值，它们被表示为Hilbert空间上的算子，但[x,p]=0（对易！）。KvN中的"不确定性"来自初始条件的 ignorance，而非来自任何容量限制。x和p**可以**同时具有确定值——只是我们选择不用Hilbert空间中的"量子态"表示它们。

**DGF中：** S_i和C_i**物理上不能**同时被指定——这不是表示的选择，而是格点容量有界的物理事实。无论你用经典概率论还是Hilbert空间表示，联合概率分布P(S_i, C_i)在物理上不存在——因为没有物理系统能同时承载这两个比特。

**关键推论：** S_i和C_i不对易，这不是因为我们选择了某种表示——而是因为它们在物理上不可共存。任何数学表示都必须反映这一点：[S_i, C_i] ≠ 0。

## 2. 非交换代数的涌现

### 定理2（单格点代数）

S_i和C_i生成一个非交换代数A_i，满足：
S_i² = I（因为特征值±1重新标度后）
C_i² = I
[S_i, C_i] ≠ 0

具体的对易关系由"变化"的物理定义决定。在DGF中，格点的变化由因果动力学σ决定：
C_i = S_i(t+1) ⊕ S_i(t)（变化=下一时刻状态异或当前状态）

在连续极限下（Δt→0），C_i正比于S_i的时间导数→C_i是"广义动量"。

### 定理3（N格点代数）

N个格点的可观测量代数A_N由{S_i, C_i}_{i=1}^N生成。

由于A2（每格点1 bit）→每个(S_i, C_i)对互补→每对生成一个非交换子代数。

如果因果图连通（A1），不同格点的可观测量通过因果交互关联→不同(S_i, C_i)对之间也存在非平凡代数关系。

### 定理4（代数结构）

A_N同构于M_{2^N}(ℂ)——即2^N×2^N复矩阵的全代数。

**证明思路（有限维下的标准论证）：**

(1) {S_i}构成N个对合的完备集→它们生成一个2^N维交换子代数（对角矩阵，在某个基底下）

(2) 每个C_i与S_i不对易（定理1）→C_i将S_i的特征向量旋转到正交方向

(3) 对所有i，{S_i, C_i}共同生成的代数在有限维下闭合

(4) 由于A2（容量有界），该代数的不可约表示维数=2^N（每个格点贡献一个qubit的自由度）

(5) 在有限维下，M_{2^N}(ℂ)是唯一满足这些条件的C*-代数

→ A_N ≅ M_{2^N}(ℂ) □

**这就是真量子力学的标志：** 可观测量构成一个非交换C*-代数，同构于全矩阵代数。这与KvN完全不同——KvN的代数是对易的（所有可观测量对易），只是被表示在Hilbert空间上。

## 3. Hilbert空间作为表示（而非起点）

### 推论1（GNS构造→Hilbert空间）

A_N ≅ M_{2^N}(ℂ)是一个C*-代数。

在A_N上定义一个态（正线性泛函）ω: A_N → ℂ，ω(A*A) ≥ 0，ω(I) = 1。

由Gelfand-Naimark-Segal (GNS)构造：
- ω在A_N上诱导一个内积 ⟨A|B⟩ = ω(A*B)
- 通过GNS构造得到Hilbert空间H_ω = A_N / {A: ω(A*A)=0}
- A_N在H_ω上的表示是忠实的

**关键：** Hilbert空间不是起点——它是非交换代数A_N + 态ω的GNS表示的必然结果。态ω携带了"系统处于什么量子态"的信息——不同的ω给出不同的量子态。

### 推论2（纯态与混合态）

态ω是纯态 ⇔ H_ω上的表示是不可约的。
态ω是混合态 ⇔ ω = Σ λ_i ω_i（凸组合）。

遍历动力学（置换σ在状态空间上的均匀分布）对应一个特定的态：
ω_erg(A) = lim_{T→∞} (1/T) Σ_{t=1}^T ⟨s(t)|A|s(t)⟩

这是DGF的自然初始态。但不同于V1——V1要求ω_erg给出Born规则（这是不可能的，因为ω_erg是均匀混合态），V2的方案是：

**Born规则不由遍历测度给出。** Born规则由以下两者共同决定：
1. 代数结构A_N ≅ M_{2^N}(ℂ)（→谱定理→投影算子→可能的结果）
2. 态ω（→GNS→Hilbert空间→ω(A) = Tr(ρ_ω A)→概率）

不同的ω给出不同的量子态。遍历动力学产生的是其中一个特定的态（均匀混合态），但**动力学本身允许态空间中的任意ω**——因为ω是初始条件，不是动力学的结果。

## 4. Born规则的重新推导

### 定义（DGF测量）

DGF中的测量是一个物理过程，它把一个可观测量A∈A_N的值"记录"到一个指针格点上。

设A = Σ_a a·P_a是A的谱分解（P_a是特征投影，在代数A_N内）。

测量过程（来自G3的Σ_obs构造，但应用于代数框架内）：
- 初始态ω（系统）+ ω_0（指针就绪）
- 耦合动力学将联合态演化为：ω⊗ω_0 → Σ_a ω_a ⊗ ω_a^{pointer}
- 其中ω_a是系统在后选择到特征子空间P_a上的态
- ω_a^{pointer}是指针记录结果a的态

### 定理5（Born规则——最终版）

在A_N ≅ M_{2^N}(ℂ)的GNS表示中（dim ≥ 3时），测量A得到结果a的概率为：
P_ω(a) = ω(P_a) = Tr(ρ_ω P_a)

其中ρ_ω是态ω对应的密度矩阵。

**证明：**

(1) A_N的GNS表示给出Hilbert空间H_ω和表示π_ω: A_N → B(H_ω)

(2) 态ω在H_ω中表示为密度矩阵ρ_ω：ω(A) = Tr(ρ_ω π_ω(A))

(3) P_a是A_N中的投影算子→π_ω(P_a)是H_ω上的投影算子

(4) 对于dim(H_ω) ≥ 3：Gleason定理（现在适用了——因为代数A_N ≅ M_{2^N}(ℂ)的表示包含**所有**投影，不只是对角的）→概率测度必须满足μ(P) = Tr(σP)

(5) 该测度必须与态ω一致→σ = ρ_ω→P_ω(a) = Tr(ρ_ω P_a)

(6) 对纯态ρ_ω = |ψ⟩⟨ψ|→P_ω(a) = ⟨ψ|P_a|ψ⟩ = |⟨a|ψ⟩|² □

**注意：** 与V1的天壤之别在于——V1中Gleason不能应用因为测度只定义在对角投影上。V2中代数A_N ≅ M_{2^N}(ℂ)的GNS表示包含**全部**投影——Gleason的前提被满足。

## 5. 幺正演化

### 定理6（置换→幺正自同构）

DGF的因果动力学σ（置换）诱导A_N上的一个*自同构α：
α(A) = U_σ* A U_σ

其中U_σ是σ在H_ω上的诱导酉算子。

**证明：** 置换σ作用于格点状态→它改变可观测量S_i和C_i的定义（在σ下，S_i(t+1) = S_{σ(i)}(t)）。这在代数A_N上诱导一个保持所有代数关系的自同构。由于A_N ≅ M_{2^N}(ℂ)是单代数（无非平凡理想），每个*自同构都是内的→存在酉U_σ使得α(A) = U_σ* A U_σ。□

在连续极限下（格点间距a→0，时间步长Δt=a/c→0）：
U(t) = lim_{n→∞} U_σ^{⌊t/Δt⌋} = e^{-iHt}

给出Schrödinger方程i∂_t|ψ⟩ = H|ψ⟩。

## 6. V2的自我攻击

### 攻击1：A_N ≅ M_{2^N}(ℂ)的证明完整吗？

**担忧：** 定理4声称{S_i, C_i}生成全矩阵代数——但这依赖于C_i确切的形式。如果C_i与S_i有某种特殊的代数关系（比如它们生成的是Clifford代数而非全矩阵代数），结论可能不同。

**回应：** 对于N个格点，{S_i, C_i}确实生成一个Clifford代数（S_i²=I, C_i²=I, {S_i, C_i} = S_i C_i + C_i S_i取决于具体动力学）。在有限维下，Clifford代数的不可约表示就是2^N维的全矩阵代数——所以结论相同。需要补充Clifford→M_{2^N}的具体同构证明。

### 攻击2：态ω从哪来？

**担忧：** V2说"态ω是初始条件"。这听起来像是把量子态作为输入而非输出。

**回应：** 量子态确实是初始条件——就像经典力学中(x₀,p₀)是初始条件。动力学（置换σ）告诉我们态如何演化（U_σ），但不告诉我们初始态是什么。这不是bug——标准量子力学中|ψ(0)⟩也是输入。DGF的贡献是：解释了为什么态空间必须是Hilbert空间（因为代数A_N非交换+容量有界），而不是为什么宇宙处于某个特定态。

### 攻击3：C_i的物理定义依赖于σ？

**担忧：** C_i = S_i(t+1)⊕S_i(t)依赖于动力学σ。如果σ不同，C_i就不同→代数A_N不同→Hilbert空间表示不同？

**回应：** 是的——这正是物理的。不同的物理系统（不同的σ/哈密顿量）有不同的可观测量代数结构。但核心结论（非交换代数→Hilbert空间→Born规则→幺正演化）不依赖于σ的具体形式——只依赖于A2（容量有界）强制S_i和C_i互补这一事实。
