## 1. 单事件的记忆传播

### 1.1 设定

在t=0，格点i被确定: |0⟩_i → |1⟩_i（一次因果事件）。

DGF格点图: d维正则格点，格点间距a，因果传播速度c。

置换σ: 最近邻因果交互，每次因果步传播距离≤a。

### 1.2 信息扩散

经过τ步（时间t=τ·a/c=τ·t_P），该事件的信息在格点图上的分布:

**信息密度（格点层面）:**

事件信息在格点图上的传播由σ的混合性质决定。对于"通用"置换（最近邻+充分混合）:

ρ(r, τ) = (1/2) · (4πDτ)^{-d/2} · exp(-r²/4Dτ)

其中:
- D = a²/(2d·t_P) = a·c/(2d)（d维最近邻随机游走的扩散常数）
- 因子1/2来自: 每个受影响的格点以概率1/2继承事件的"记忆"

**总信息量守恒:**

∫ ρ(r,τ) d^d r = 1/2（对所有τ>0）

信息永远不消失——它只是扩散到越来越大的体积中（A1+A2→置换→信息守恒）。

### 1.3 对q场的影响

q场在宏观点x的值 = 在以x为中心、半径R_c的粗粒化块内，|0⟩态的平均占据率。

事件i（在x=0处）在时间τ后对q(x)的贡献:

Δq(x,τ) = -(1/N_b) · (事件信息到达x处的格点的概率)
         = -(1/N_b) · 2ρ(|x|, τ)
         = -(1/N_b) · (4πDτ)^{-d/2} · exp(-|x|²/4Dτ)

其中N_b = (R_c/a)^d是粗粒化块内的格点数。

## 2. 记忆核K(τ)的推导

### 2.1 定义

记忆核K(τ)衡量: 在时间τ前发生的一次事件，对当前时刻q场动力学的"恢复阻力"。

物理上: 事件产生的q场凹陷Δq < 0倾向于持续存在——因为扩散项∇²(ln q)只能平滑凹陷，不能填充它（信息守恒→凹陷的"信息内容"不能消失）。

### 2.2 推导

K(τ)正比于"事件信息在时间τ后仍留在其原始粗粒化块内的概率":

K(τ) = κ₀ · P(事件信息仍在|x| < R_c内 | 时间τ)

= κ₀ · ∫_{|x|<R_c} (4πDτ)^{-3/2} exp(-r²/4Dτ) d³r

= κ₀ · [erf(R_c/√(4Dτ)) - (2R_c/√(π·4Dτ))·exp(-R_c²/4Dτ)]

其中κ₀是耦合常数（记忆强度）。

### 2.3 渐近形式

**短时极限 (τ ≪ R_c²/4D):**
K(τ) ≈ κ₀ · [1 - O(exp(-R_c²/4Dτ))]
≈ κ₀

信息仍在粗粒化块内→记忆完整。

**长时极限 (τ ≫ R_c²/4D):**
K(τ) ≈ κ₀ · (4π/3)·(R_c/√(4πDτ))³

在d=3中: **K(τ) ∝ τ^{-3/2}**

### 2.4 记忆半衰期

定义τ_M: K(τ_M) = κ₀/2。

τ_M = R_c² / (4D · [erf^{-1}(1/2)]²) ≈ R_c² / (4D)

**数值估计:**

| 粗粒化尺度R_c | D (m²/s) | τ_M (秒) | τ_M (年) |
|-------------|----------|---------|---------|
| 1 μm | 10^{-26} | 2.5×10^{13} | 8×10^5 |
| 1 mm | 10^{-26} | 2.5×10^{19} | 8×10^{11} |
| 1 m | 10^{-26} | 2.5×10^{25} | 8×10^{17} |
| 1 km | 10^{-26} | 2.5×10^{31} | 8×10^{23} |

其中D = a·c/(2d) ≈ ℓ_P·c/6 ≈ 10^{-26} m²/s。

**关键发现:** 对于任何宏观粗粒化尺度(R_c ≥ 1 mm)，τ_M远超宇宙年龄(≈1.4×10^{10}年)。

**→ 宏观尺度上，记忆永不衰减。灰烬永久存在。**

## 3. κ₀的微观推导

### 3.1 κ₀的物理意义

κ₀ = 单次事件对q场动力学的最大恢复阻力。

从telegraph方程的阻尼项: γ₀(1-q)∂_t q。

当q被压低到q<1时，恢复力来自扩散项c²∇²(ln q)。记忆项抵抗这个恢复力。

κ₀应该和阻尼系数γ₀有相同的量纲([时间]^{-1})。

### 3.2 具体推导

单次事件产生的q场凹陷深度: |Δq| = 1/N_b = (a/R_c)^d。

这个凹陷产生的扩散恢复力: F_restore = c²∇²(ln q) ≈ c²/R_c² · |Δq|。

记忆抵抗力的最大值（当τ=0时）: F_memory = κ₀ · |Δq|。

在平衡时（记忆项恰好抵消恢复力）: F_memory = F_restore。

→ κ₀ ≈ c²/R_c² = (c/R_c)²。

对于R_c = 宏观尺度（如1 m）: κ₀ ≈ 10^{17} s^{-2} → 对应的特征频率≈3×10^8 Hz（光穿越R_c的频率）。

对于R_c = 微观尺度（如1 μm）: κ₀ ≈ 10^{26} s^{-2}。

### 3.3 完整的K(τ)

K(τ) = (c²/R_c²) · P(信息仍在粗粒化块内 | τ)

= (c²/R_c²) · [erf(R_c/√(4Dτ)) - (2R_c/√(4πDτ))·exp(-R_c²/4Dτ)]

在宏观极限(R_c → 大, τ → 宇宙学尺度 → τ ≪ R_c²/4D):

**K(τ) ≈ c²/R_c² = 常数**

记忆核在整个宇宙学时间尺度上是**平坦的**——所有历史事件对当前q场有同等强度的记忆效应。
