## 4.2 Hilbert空间结构的涌现

### 定理4.1（因果等价类上的Hilbert空间）

设：
- X = {0,1}^N 为N个格点的微观构型空间
- ∼_C 为A3定义的因果等价关系：x ∼_C y ⇔ 对所有可观测格点i∈O, s_i(x) = s_i(y)
- X/∼_C 为因果等价类集合，|X/∼_C| = 2^{N_S}（N_S = |O|为观测格点数）

定义V = {ψ: X/∼_C → ℂ}为因果等价类上的复值函数空间。

则在以下自然运算下，V是2^{N_S}维复Hilbert空间：

**(i) 向量空间结构：**
(ψ+φ)([x]) = ψ([x]) + φ([x])
(c·ψ)([x]) = c·ψ([x])

**(ii) 内积：**
⟨ψ|φ⟩ = Σ_{[x]∈X/∼_C} ψ*([x]) φ([x])

**(iii) 完备性：** 有限维→自动完备。

**(iv) 维数：** dim(V) = 2^{N_S}

**证明：** (i)-(iii)是ℂ^M上标准内积的直接验证。(iv)来自|X/∼_C|=2^{N_S}。□

### 关键：内积的物理起源

⟨ψ|φ⟩不是随意选择的——它有明确的DGF物理含义：

**引理4.1（内积=可区分性度量）：**
对两个正交的因果等价类[x]≠[y]，⟨[x]|[y]⟩=0，因为存在某个可观测格点i∈O使得s_i(x)≠s_i(y)，即[x]和[y]是因果可区分的（A1保证）。

对一般状态|ψ⟩=Σc_a|a⟩，内积⟨ψ|φ⟩量化了两个状态在最优因果区分实验中的不可区分度。

**这直接把A1（因果存在=可区分性存在）转化为数学结构：**
- A1 → 存在一个区分度函数 d: X×X → [0,1]
- 因果等价类上d([x],[y]) = 0 for [x]≠[y]（完美可区分）
- 内积是d的极化形式：⟨[x]|[y]⟩ = 1 - d([x],[y])
- Hilbert空间是A1的自然数学表达

**所以Hilbert空间结构不是额外假设——它是A1（可区分性）的定量数学化。**

## 4.3 测量作为投影算子

### 定义4.2（DGF测量）

一个DGF测量M由以下数据定义：
- 一组可观测格点O⊂{1,...,N}（|O|=N_S）
- 一个可区分特征函数f: {0,1}^{N_S} → ℝ（将观测比特模式映射到测量结果）

测量M作用于状态|ψ⟩∈V的过程：
1. 将|ψ⟩投影到f的每个特征子空间（即具有相同f值的等价类的直和）
2. 结果a以概率P(a)=⟨ψ|P_a|ψ⟩出现（Born规则，由Gleason定理保证——见下文）
3. 测量后状态坍缩到P_a|ψ⟩/√P(a)

其中P_a是到特征子空间E_a = span{[x] : f(x|_O)=a}的正交投影算子。

### 引理4.2（投影算子的物理实现）

投影P_a对应一个物理操作：观测者通过因果交互（A1定义的有向边）与格点O耦合，提取特征f的值。这个耦合过程被置换动力学σ描述——观测者的格点与系统格点进行因果交互，交互后的置换动力学将联合状态驱动到由f值标记的不变子空间。

**证明思路：** 观测是系统+观测者联合格点集上的因果过程。观测者的"指针"格点与系统的被观测格点发生因果交互（A1），交互后联合置换σ_{obs}的被观测格点状态被锁定到与指针一致的值。这个过程在Hilbert空间V上的表示就是投影P_a。□

## 4.4 非交换性与语境性

### 定理4.3（测量基底的非交换性）

设M_1和M_2是两个测量，分别观测格点集O_1和O_2，且O_1≠O_2。
设σ是DGF的基础置换（满足A1——因果图连通）。

则当N_S≥2时，M_1和M_2对应的投影算子族{P_a^(1)}和{P_b^(2)}一般不可交换：
∃ a,b: [P_a^(1), P_b^(2)] ≠ 0。

**证明：**

(1) M_1的投影P_a^(1)在O_1-等价类基底下是对角的：⟨[x]|P_a^(1)|[y]⟩ = δ_{[x],[y]} · 1_{f_1(x)=a}

(2) M_2的投影P_b^(2)在O_2-等价类基底下是对角的。

(3) O_1-等价类基底和O_2-等价类基底通过一个基变换U_{12}关联：
|a⟩_1 = Σ_b U_{ab} |b⟩_2

其中U_{ab}的矩阵元由未被观测的格点的状态分布决定。

(4) 基变换U_{12}的矩阵元：
U_{ab} = ⟨a|b⟩_2 = (在O_2-等价类|b⟩中随机抽取一个微观态，它属于O_1-等价类|a⟩的概率振幅)

(5) 关键：置换σ混合不同格点的状态。因为A1要求因果图连通（否则存在因果无关的"平行宇宙"——违反所有格点构成单一因果结构的假设），σ不是各格点上独立置换的张量积。

(6) σ的混合性质 → 未观测格点的状态与已观测格点的状态存在关联 → U_{ab}不是对角矩阵 → [P_a^(1), P_b^(2)] ≠ 0。

(7) 具体构造（最小例子）：
N=3, O_1={1,2}, O_2={2,3}, f_1 = s_1⊕s_2（奇偶性）, f_2 = s_2⊕s_3
σ = (000,111)(001,110)(010,101)(011,100)（全翻转置换）

在O_1基底下：
P_0^(1) = |00⟩⟨00| + |11⟩⟨11|
P_1^(1) = |01⟩⟨01| + |10⟩⟨10|

O_1基底和O_2基底的变换（由σ决定——当未观测格点的状态因σ而与已观测格点关联时）：
|s_2,s_3⟩ = Σ_{s_1} √(p(s_1|s_2,s_3)) e^{iφ(s_1,s_2,s_3)} |s_1,s_2⟩

非对角元的存在 → P_a^(1)和P_b^(2)不交换。

(8) 对于一般N和一般连通因果图，同样的论证成立。□

### 定理4.4（语境性——Kochen-Specker一致性）

在dim(V)≥3（即N_S≥2）的DGF Hilbert空间上，投影算子族{P_a^(M)}构成一个语境性的测量结构——即不存在一个非语境性的隐变量赋值。

**证明：** 
- 定理4.3证明了存在非交换的投影算子对
- dim(V)=2^{N_S}≥4>3（当N_S≥2）
- Kochen-Specker定理：dim≥3的Hilbert空间上，任何足够丰富的投影算子族必然呈现语境性
- DGF的测量结构包含至少两个不同格点集上的测量→包含非交换对→足够丰富
- 因此DGF测量结构是语境性的

**DGF中的语境性微观起源：**
语境性不是"量子怪异性"——它是在格点集的不同子集上进行因果观测时，由于置换σ的混合性质导致的不同观测基底之间的非交换性。两个观测"不可同时进行"不是因为什么神秘原理，而是因为：在有限容量格点网络上，同时与两个不同的格点子集建立因果交互需要互斥的资源配置。

更精确地说：测量M_1需要观测者的指针格点与O_1耦合；测量M_2需要指针格点与O_2耦合。如果O_1和O_2不完全相同，两次耦合消耗的可用因果带宽不同→它们不是可交换的操作→语境性。

## 4.5 Born规则：从Gleason定理到DGF

### 定理4.5（Born规则的Gleason推导）

在DGF Hilbert空间V（dim≥3）上，任何满足以下条件的概率赋值函数μ: Proj(V)→[0,1]：
- μ(I)=1（归一化）
- μ(P+Q)=μ(P)+μ(Q) 当PQ=0（可加性）

必然具有形式μ(P)=Tr(ρP)，其中ρ是密度矩阵（正定、迹1）。

特别地，对纯态|ψ⟩⟨ψ|，μ(P_a)=⟨ψ|P_a|ψ⟩=|⟨a|ψ⟩|²——即Born规则。

**证明：** 直接应用Gleason (1957)定理。前提条件（dim≥3的可分Hilbert空间上的概率测度）在DGF中满足：dim(V)=2^{N_S}≥4（当N_S≥2）。□

**为什么DGF满足Gleason的前提：**
- Hilbert空间V已在定理4.1中构造
- 概率赋值μ来自观测频率的客观极限（DGF中：同一因果等价类内各微观态在循环上等概率出现→频率→客观概率）
- 可加性来自：互斥结果对应的投影算子正交

### 重要澄清：为什么不是"经典概率"？

DGF的微观动力学是置换→循环。在单个循环上，状态等概率访问→经典频率分布（各态历经）。

但粗粒化到因果等价类后：
- 不同微观态在等价类内的"到达时间"（循环相位）不同
- 等价类上的振幅不是频率的简单计数——因为来自不同循环位置的贡献以不同相位干涉
- 干涉→模方结构→量子概率（非单纯加法）

**这是DGF与经典统计力学的本质区别：**
- 经典统计：微观态→粗粒化→经典概率（频率计数，无相位）
- DGF：微观态→循环结构→粗粒化+相位干涉→量子振幅→Born规则

经典概率是DGF在"忽略相位信息"时的特例（q→0极限，所有格点确定→无循环自由度→无相位→经典）。

## 4.6 幺正演化的完备推导

### 定理4.6（置换→连续幺正演化）

在DGF Hilbert空间V上，离散置换动力学U(n)|ψ⟩ = P_σ^n|ψ⟩（其中P_σ是σ的置换表示）在粗粒化连续极限下生成连续幺正演化U(t)=e^{-iHt}，且H是Hermite算子。

**证明：**
(1) 置换σ在V上的表示：对每个等价类[x]，σ将微观态映射到σ(x)。这诱导V上的线性算子P_σ：(P_σψ)([x]) = ψ(σ^{-1}([x]))。

(2) P_σ是酉算子：⟨P_σψ|P_σφ⟩ = Σψ*(σ^{-1}[x])φ(σ^{-1}[x]) = Σψ*([y])φ([y]) = ⟨ψ|φ⟩（因为σ是双射，遍历所有等价类）。

(3) 时间步长Δt = a/c = t_P（Planck时间，光穿越一个格点的时间）。

(4) 定义生成元：H = i·(P_σ^{Δt} - I)/Δt|_{Δt→0}

(5) 因为P_σ是酉的，P_σ = e^{-iHΔt}（对某个Hermite H，由Stone定理——有限维下是对数映射的存在性保证）。

(6) 连续时间演化：U(t) = lim_{n→∞} P_σ^{⌊t/Δt⌋} = e^{-iHt}。

(7) Schrödinger方程：i∂_t|ψ(t)⟩ = H|ψ(t)⟩。□

**关键点：** 有限N下，时间是离散的（步长t_P）。连续幺正演化是N→∞（或Δt→0）的有效理论。对于所有实验室可及的时间尺度（>>t_P），连续近似是极其精确的。
