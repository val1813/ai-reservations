## 2. 引力部分: q场作用量

### 2.1 从FS到q场

在宏观4维时空中，FS度规的粗粒化投影产生q场。

q场的作用量从CP^{N-1}的"体积"在粗粒化下的约化得到:

其中:
- (∂q)²/q² = |∇ln q|²是FS度规在q方向上的投影（来自Kähler势的梯度项）
- V(q)是q场的势能（来自FS的曲率项+粗粒化的有效势）

### 2.2 V(q)的形式

势能V(q)必须满足:
- V(1)=0（q=1真空，能量最低——FS度规的常数曲率态）
- V(0)→∞（q→0时容量饱和→无穷大能量代价）
- V'(1)=0（真空是稳定点）

最简单的形式（与DGF中的-Φ(q)=-(q ln q - q + 1)一致）:
V(q) = V₀ · (q ln q - q + 1)

### 2.3 运动方程

对q变分→运动方程:
□_M q - (1/q)(∂q)² + q V'(q) = 0

其中□_M是宏观4维d'Alembertian。

展开:
□_M q - |∇q|²/q + V₀ q ln q = 0

在q≈1附近（线性化）:
□_M δq + V₀·δq = 0 → Klein-Gordon方程，质量m²=V₀。

这**不是**telegraph方程——这是从作用量变分得到的二阶波动方程。

**关键差异:** DGF的telegraph方程包含一阶阻尼项γ₀(1-q)∂_t q。这个阻尼项不是从保守作用量变分来的——它是粗粒化的**耗散**效应（非保守）。

### 2.4 耗散修正: 从保守到telegraph

粗粒化投影Π_q不是等距的——它丢弃信息。这产生有效摩擦。

将耗散项作为非保守力加入（类似于将摩擦力加入Lagrange力学）:
□_M q + γ₀(1-q)∂_t q = c²∇²(ln q)

这正是DGF的telegraph方程。它在Level 2中是**有效的**描述——不是基本的。

**在Level 1（刚破缺）中，耗散项消失（q=1→γ₀(1-q)=0），作用量描述是保守的（纯Klein-Gordon）。**

**在Level 2（q<1）中，耗散出现，保守作用量S_q必须由非保守的telegraph方程替代。**
