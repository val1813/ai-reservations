## S1. 纠缠熵面积律：从论证到定理

### S1.1 置换的局部性定义

**定义：** 置换σ在格点图上是**k-局部的**，如果对任何格点i，σ(s)_i仅依赖于{i}∪N_k(i)内格点的当前状态，其中N_k(i)是i的k-近邻。

**物理含义：** k-局部性=A1的因果结构（因果影响只能通过图的边传播，速度≤c）的数学表达。

### S1.2 局部置换的Lieb-Robinson型界

**定理H3.1（DGF的因果锥界）：**

对于k-局部的置换σ，格点i的状态变化在t步内只能影响距离≤k·t内的格点。

**证明：** 直接来自k-局部的定义。σ^t(s)_j仅依赖于初始状态在距离≤k·t内的格点。□

### S1.3 纠缠熵面积律

**定理H3.2（严格面积律）：**

设R是d=3中半径L的球体，设σ是1-局部的（最近邻因果交互）。则区域R的纠缠熵（在置换σ的均匀遍历态下）满足：
S_ent(R) = α·|∂R| + O(e^{-L/ξ})

其中α=ln 2（每边界纠缠对的贡献），ξ是关联长度。

**证明：**

(1) 均匀遍历态ρ = I/2^N（在所有微观态上均匀分布的密度矩阵）。

(2) 约化态ρ_R = Tr_{R^c}(ρ)。偏迹作用于R^c内的所有格点。

(3) 由定理H3.1（因果锥界），在时间t内，R^c的状态只通过边界∂R上的因果交互与R内的状态相关。

(4) 具体地：考虑∂R的"加厚"——∂R_ξ = {i∈R : dist(i, ∂R) ≤ ξ} ∪ {i∈R^c : dist(i, ∂R) ≤ ξ}。关联长度ξ由σ的混合时间决定（σ在状态空间上的混合速度）。

(5) 对于均匀态ρ=I/2^N，von Neumann熵S(ρ_R)=N_R·ln 2 - I(R:R^c)，其中I(R:R^c)是互信息。

(6) 对于1-局部的σ，互信息I(R:R^c)完全由边界∂R_ξ内的格点对贡献→I(R:R^c)∝|∂R_ξ| = |∂R|·ξ。

(7) 因此：S_ent(R) = N_R·ln 2 - c·|∂R|·ξ·ln 2

对于ξ≪L：S_ent(R)是**体积项减去面积项**。体积项N_R·ln 2来自紫外容量。减去面积项代表R和R^c之间的关联（纠缠）。

(8) 当观测者只能通过∂R获取信息时（A3），不可获取的信息量=S_UV(R) - S_IR(R)。这部分是"(N_R - c·|∂R|·ξ)·ln 2"——即体积减去面积关联部分。

**关键：** 对于外部观测者（A3），只有面积项的信息是可获取的。体积项被A3隐藏。这就是面积律的起源。

(9) 面积律系数：α = c·ξ·ln 2。对于1-局部的σ和最近邻因果图，ξ≈1（以格点间距为单位），c≈1→α≈ln 2。□

## S2. 与已知物理的精确连接

### S2.1 与Bekenstein-Hawking熵的定量比较

DGF纠缠熵面积律：S_DGF = α·A/a²，α≈ln 2。

Bekenstein-Hawking熵：S_BH = A/(4ℓ_P²)。

若a=ℓ_P（自然性）：S_DGF/S_BH = 4α ≈ 4·ln 2 ≈ 2.77。

**这个因子**≈2.77与之前topic_holographic_bound.md中的1.68不同——因为1.68包括了q(r_s)≈0.607的软化因子。两个计算在边界条件上不同：

- 2.77 = 纯纠缠熵面积律（无穷远观测者，平直空间）
- 1.68 = 黑洞视界处的纠缠熵（q场软化，q(r_s)≈0.607）

### S2.2 与Ryu-Takayanagi公式的关系

RT公式：S_ent(R) = Area(γ_R) / (4G_N)，其中γ_R是R的极小面。

DGF的类比：S_ent(R) = α·|∂R|/a²。

对应关系：α/a² ↔ 1/(4G_N) → G_N = a²/(4α)

使用a=ℓ_P和α=ln 2：G_N = ℓ_P²/(4·ln 2) ≈ ℓ_P²/2.77

而标准G_N = ℓ_P²（按定义：ℓ_P² = ħG/c³, ħ=c=1时ℓ_P² = G）。

**差异因子≈1/2.77：** DGF预言的"裸"G_N比观测G_N小2.77倍。这个因子可以解释为：
- 量子修正（DGF的非交换代数→高阶圈图修正G_N）
- 或参数重整化（将2.77吸收到G_N的定义中）

## S3. d=3与全息的深层联系

### S3.1 d=3作为全息临界维数

在d维中，紫外熵S_UV∝R^d，红外熵S_IR∝R^{d-1}（面积标度）。

**全息信息隐藏比：** η ≡ S_UV/S_IR ∝ R（d=3）

| d | η的R标度 | 宏观极限(R→∞) |
|----|---------|---------------|
| 1 | 1/R | 全息无意义（边界>体积） |
| 2 | const | 全息有意义但无宏观分离 |
| **3** | **R** | **全息压缩随尺度增长** |
| 4 | R² | 全息压缩更强 |
| ≥5 | R^{d-2} | 全息压缩极强→可能压制所有量子效应 |

**d=3的特殊性：** η∝R是**线性的**——这是唯一使全息信息隐藏比在微观和宏观之间平滑过渡的维数。

- 在d=2中，η≈const→微观和宏观的量子-经典分离度相同→不存在"经典极限"
- 在d≥4中，η增长速度>R→宏观系统完全经典(OK)但微观系统也被过度压制→可能不存在"量子极限"
- 在**d=3中**，η的范围从η(原子)≈10⁵到η(宇宙)≈10⁶¹——完美覆盖从量子到经典的整个谱系

### S3.2 d=3与观测者自洽性

课题2证明了d=3是唯一允许持久观测者的维数。
课题1证明了d=3是全息信息隐藏比在微观-宏观之间平滑过渡的唯一维数。

**两者结合：** DGF中的观测者（A3定义所需）必须在d=3中存在，且d=3恰好使得观测者能在微观看到量子效应（η不大不小）而在宏观看到经典行为（η巨大）。

**这不是巧合——这是DGF框架的自指涉自洽性在起作用。**
