## 课题1: DGF全息原理——体积标度到面积标度的相变

### 隐藏假设识别

**H:** "DGF的1-bit/格点容量导致体积标度S~R³，与全息面积标度S~R²矛盾——这是框架的固有限制，无法内部解决。"

**¬H:** "DGF中的体积标度是'紫外'容量——仅当所有格点独立可访问时才成立。在A3（因果视界）下，观测者只能通过边界因果交互获取信息——这自动将红外熵标度从体积转为面积。"

### 核心矛盾

| 命题A（H成立） | 命题B（¬H成立） |
|---------------|----------------|
| S_max ~ (R/ℓ_P)³ → 体积 | S_ent(R) ~ (R/ℓ_P)² → 面积（A3下边界纠缠） |
| 与黑洞热力学S_BH=A/4ℓ_P²矛盾 | 自动与全息原理一致 |
| 需要外部修补 | 从公理内部涌现 |

### 推导路径

**(1) 区分两种熵：**
- 紫外容量熵 S_UV(R) = N_R = (R/a)³（A2直接给出，体积标度）
- 红外可及熵 S_IR(R) = 观测者通过边界∂R的因果交互能区分的状态数

**(2) A3对红外熵的约束：**
观测者只能通过边界格点与区域R内部因果交互。边界格点数N_∂R ~ (R/a)²。
每个边界格点1 bit → 边界最大信息传输率 = N_∂R bits/step。

**(3) 红外熵的边界面标度：**
在因果视界（A3）下，观测者可获取的区域R信息被边界因果带宽限制：
S_IR(R) ≤ N_∂R · (因果交互步数)

对于静态观测（测量时间有限），S_IR(R) ∝ N_∂R ∝ (R/a)²。

**(4) 与黑洞热力学的一致性：**
DGF中q(r)=e^{-GM/rc²}在r=r_s=2GM/c²处→q=e^{-1/2}≈0.607。
软边界处（无硬视界），信息仍然通过q>0的区域缓慢泄漏。
有效信息容量由软边界处的q值控制→S_eff ∝ A·f(q)|_{r_s}。

## 课题2: 从置换动力学推导q场telegraph方程

### 隐藏假设识别

**H:** "q场telegraph方程∂²_t q+γ₀(1-q)∂_t q=c²∇²(ln q)是'启发式ansatz'——从微观置换σ无法严格推导，只能通过物理论证motivate。"

**¬H:** "telegraph方程是置换σ在局部平衡假设下的流体力学极限——类似于从Boltzmann方程推导Navier-Stokes方程。γ(q)=γ₀(1-q)和ln q梯度的形式都是粗粒化展开的必然结果。"

### 核心矛盾

| A（ansatz） | B（Hydrodynamic limit） |
|------------|------------------------|
| 方程是假设的 | 方程是推导的 |
| γ₀(1-q)是"最简单的选择" | γ₀(1-q)是容量约束在平均场下的必然形式 |
| ln q的universality class是"被保护的" | ln q是置换统计的唯一自洽势函数 |

### 推导路径

**(1) 从σ定义微观q场：**
q_i(t) = (1/N_b) Σ_{k∈block(i)} (1-s_k(t))（块平均）
s(t+1) = σ(s(t))

**(2) 粗粒化时间演化：**
q_i(t+1)-q_i(t) = (1/N_b) Σ_{k∈block(i)} [s_k(t)-s_k(t+1)]

s_k(t+1)由σ决定——通过σ的局部因果结构（A1→近邻相互作用）。

**(3) 平均场闭合：**
假设局部平衡（块内格点的s分布近似均匀且无记忆）→q的二阶差分可用q的梯度表达→∂_t q方程。

**(4) γ(q)的形式从容量约束严格导出：**
J_{ij}的衰减率∝目标格点已占用的概率 = 1-q_j。
取边平均→γ(q̄)=γ₀(1-q̄)。

**(5) ln q势函数从Shannon自信息的粗粒化唯一性导出：**
每个格点的"惊喜度"=-ln(占用概率)的块平均→-ln q。
块间差异驱动信息流→梯度驱动力∝∇(-ln q)=∇ln(1/q)。

比原来的ansatz版本多出：对γ(q)的非线性修正（γ(q)=γ₀(1-q)+β(1-q)²+...）在q不接近0或1时的具体形式。

- A博士：2/3（统计力学粗粒化→流体力学是成熟方法，DGF只需适配到置换动力学）
- B博士：1/3（粗粒化闭合假设（局部平衡）是额外输入——需要验证在何种条件下自洽）
- **预估总分：3/6（有效但非革命性——属于框架巩固而非突破）**
