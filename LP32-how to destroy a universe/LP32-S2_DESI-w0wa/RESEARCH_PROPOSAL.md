## 1. 理论点

**核心主张：暗能量不是基本场，是量子多体系综的涌现集体现象。幻影穿越是系综的基态翻转——驱动量子相变。**

```
现有范式（三种）：
  ΛCDM:   w = -1 常数，无动力学
  精质:    基本标量场，w > -1
  修改引力: 几何自由度，等效w

本工作范式（第四种）：
  涌现暗能量: 量子多体系综的集体行为
  - 基本自由度：二能级系统（qubit）
  - 动力学：驱动-阻尼复Langevin方程
  - 幻影穿越：有效能级差ΔE改变符号 → 基态翻转
  - 驱动源：宇宙结构形成（以SFR为示踪物）
  - 不是拟合参数——是量子相变的临界现象
```

**一句话：暗能量不是"什么场"的问题——是"多少qubit被确定化了"的问题。**

## 2. 价值级别

**如果正确：范式级。** 把暗能量从"宇宙学常数问题"变成"量子多体物理的可检验预言"。

| 维度 | 评估 |
|------|------|
| 概念新颖性 | **高** — qubit系综+驱动相变+幻影穿越的组合无先例 |
| 观测支持 | **中（~2σ）** — DESI DR2偏好，但未到发现级别 |
| 可检验性 | **高** — 多通道独立检验（宇宙学、量子模拟、天体物理） |
| 理论自洽性 | **中高** — 平均场推导+数值验证，缺微观严格推导 |
| 与现有范式关系 | **互补** — 不排斥精质或修改引力，但提供了新机制 |

**诚实定位：** 目前是"有希望的候选者"（promising candidate），不是"发现"（detection）。需要DESI DR3或独立实验将其推到>5σ。

## 3. 论证路径

### 3.1 理论论证

**A. 从第一原理推导 $a_c^2$。** 
- 出发点：N个相互作用qubit的Hamiltonian
  $$H = \sum_i \frac{\Delta E_0}{2}\sigma_z^{(i)} + \frac{g}{N}\sum_{i<j}\sigma_z^{(i)}\sigma_z^{(j)} + \text{驱动项}$$
- 平均场近似 → Curie-Weiss自洽方程 → $a_c^2 = \frac{1}{2}(1 - \gamma/\sqrt{\gamma^2+\omega_0^2})$
- 这是严格可解的——不需要数值拟合

**B. 证明 $w+1 \propto a_c^2 - |\mathcal{A}|^2$ 在临界点附近是普适的。**
- 在平均场临界点附近，序参量的状态方程有普适形式
- $w+1 \propto (a_c^2 - |\mathcal{A}|^2)$ 是Landau理论的直接推论
- 临界指数由平均场理论给出——可被检验

**C. 证明复Langevin方程是一阶的（无振荡），区别于DGF的二阶电报方程。**
- 一阶复方程→弛豫+旋转→天然耗散
- 二阶实方程→惯性+恢复→谐振子赝像
- 这是数学结构上的本质区分

### 3.2 数值论证

**D. 完整MCMC分析。** 
- 当前：binned w(z) χ²比较（4个bin，dof=2）
- 升级：full DESI DR2 likelihood（BAO距离测量+CMB+SN）
- 参数：$(\omega_0, \gamma, \eta)$，$a_c^2$ 从理论推导
- 贝叶斯因子 vs ΛCDM
- 预报：DR3误差棒下需要的区分显著性

**E. w(z)形状的binned预测。**
- 给出4-7个红移bin的具体w(z)预测值
- 与DESI已发表的binned重建比较
- 高红移（z>2）的预测——Euclid/Roman可检验

### 3.3 观测论证

**F. SFR数据的独立性检验。**
- 当前：Madau-Dickinson (2014) SFR
- 替代：Behroozi+ (2019) UniverseMachine, Driver+ (2018) GAMA
- 检验：w(z)预测对SFR选择的敏感度
- 如果不同SFR数据给出定性一致的w(z)→模型稳健

**G. S₈张力的自然解释。**
- DGF/确定化场暗能量在高红移（z>1）处于幽灵态→w<-1→暗能量密度更高→膨胀更快→结构增长被更早抑制→σ₈更低
- 定量：计算 $S_8 = \sigma_8\sqrt{\Omega_m/0.3}$ 并与KiDS/DES观测比较
- 这是一个**独立于w(z)的检验**——不涉及暗能量状态方程
