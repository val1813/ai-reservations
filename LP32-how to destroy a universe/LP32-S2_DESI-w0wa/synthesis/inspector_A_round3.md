## 1. ODE实现正确性

**判定: PASS (带条件) ✓⚠**

### 1.1 代码-方程对应验证

代码`make_telegraph_ode` (line 119-151)逐项实现Sec.1.1 Eq.(1):

$$(\beta_0 + 2r\Delta)\dot{\Delta} + \gamma_0(\alpha-1)\Delta + \gamma_0\Delta^2 + H_0^2\int_0^t \Delta dt' = \tilde{\eta}\gamma_0 \cdot \frac{\text{SFR}(t)}{\text{SFR}_0}$$

逐项对照:

| 项 | 报告Eq.(1) | 代码 (line 140-146) | 量纲 | 匹配 |
|----|-----------|-------------------|------|:--:|
| 驱动 | $\tilde{\eta}\gamma_0 \cdot \text{SFR}/\text{SFR}_0$ | `eta_tilde * gamma0 * sfr_t / SFR0` | [Gyr⁻¹] | ✓ |
| 反应线性 | $\gamma_0(\alpha-1)\Delta$ | `gamma0 * (alpha - 1.0) * Delta` | [Gyr⁻¹] | ✓ |
| 反应非线性 | $\gamma_0\Delta^2$ | `gamma0 * Delta**2` | [Gyr⁻¹] | ✓ |
| 记忆 | $H_0^2\int\Delta dt'$ | `H0_Gyr**2 * I_mem` | [Gyr⁻¹] | ✓ |
| 阻尼 | $\beta_0 + 2r\Delta$ | `beta0 + 2.0 * r_c * Delta` | [1] | ✓ |

量纲一致性: 所有RHS项为[Gyr⁻¹]，除以无量纲damping得dDelta/dt [Gyr⁻¹]。✓

### 1.2 w(z)表达式验证

代码 (line 153-157): `w = -1.0 + dDelta_dt / (3.0 * H_val * max(1.0 - Delta, 1e-6))`

与R2 §R2-1修正后的定义一致（ρ_DE = ρ_Λ·q, Δ ≡ 1-q）:
$$w = -1 + \frac{\dot{\Delta}}{3H(1-\Delta)}$$

✓ 符号和分母(1-Δ而非Δ)均与R2修正版一致。

### 1.3 时间网格构建

`compute_time_grid` (line 51-70) 使用logspace z网格 + dt/dz积分:

- `dz = np.diff(z_arr)` 为负（z降序）
- `dtdz_mid` 为负
- `dt_steps = dz * dtdz_mid` = 负×负 = 正 ✓
- `t(z=0) = t0_Gyr` 通过锚定公式强制 ✓

验证: t_arr[0] = t(z_max), t_arr[-1] = t(z=0) = t0_Gyr。✓

### 1.4 ⚠️ 关键问题: 求解的不是完整Cattaneo方程

**报告标题声称"Cattaneo修正Telegraph方程"，但代码实际求解的是慢滚（一阶）近似。** 完整的Cattaneo修正telegraph方程包含惯性项τ_c·d²Δ/dt²:

$$\tau_c \frac{d^2\Delta}{dt^2} + (\beta_0 + 2r\Delta)\dot{\Delta} + \gamma_0(\alpha-1)\Delta + \gamma_0\Delta^2 + H_0^2\int_0^t \Delta dt' = \tilde{\eta}\gamma_0 \cdot \frac{\text{SFR}(t)}{\text{SFR}_0}$$

代码中的方程**缺少τ_c·d²Δ/dt²项**。这在Sec.5.1 A2中被诚实标注为"慢滚近似"，但**报告其余部分（特别是Sec.7.2的排除结论）的语言暗示已求解完整方程**。

在r=5的强Cattaneo区（所有5个精细模型都在此区域），慢滚近似可能严重不准确。报告中诚实地将此列为一级假设A2，但这意味着**"DGF当前版本"与DGF的真实telegraph方程之间有系统性差距**——排除的是慢滚近似，不一定排除完整方程。

### 1.5 参数映射的不透明性

R2推导的telegraph方程使用参数集{γ₀, c²/R_c², η}，R3代码使用{gamma0, alpha, r_c, eta_tilde}。**从R2参数到R3参数的推导链（特别是alpha = Γ/γ₀和r_c = τ_c·γ₀的定义，以及eta_tilde与R2的η之间的关系）未在报告或代码注释中给出。** 这使得独立验证参数物理范围的合理性变得困难。

### 1.6 数值鲁棒性未验证

- 未进行收敛性测试（变化rtol, atol, max_step）
- `damping`的硬地板`max(..., 1e-6)`可能mask刚度问题
- 未与独立积分器（如LSODA, Radau）交叉验证
- 初始条件Delta_init=1e-6的敏感性未量化（Sec.5.2 A5的"<5%"声称未附计算）

## 2. χ²计算的正确性

**判定: FAIL ✗ (严重缺陷)**

### 2.1 核心问题: 未使用DESI DR2协方差矩阵

代码`compare_DESI` (line 375-415) 使用硬编码的7个对角误差值:

```python
desi_bins = [
    (0.00, 0.25, 0.125, -0.87, 0.08),
    ...
    (2.50, 4.00, 3.250, -0.95, 0.25),
]
```

**这些不是DESI DR2的正式数据产品。** DESI DR2 (arXiv:2503.14738) 报告的是w₀-w_a约束，而非z-binned w值。报告称这些值来自"flexknot/GP非参数重构 DESI 2025 + Zhang 2026"，但:

1. **无明确引用:** "DESI 2025 + Zhang 2026"的组合是什么具体分析？哪个图/表产出了这些binned值？
2. **对角近似:** 真实的w(z)重构有显著的bin间协方差（相邻bin使用的数据重叠，重构平滑核引入关联）。忽略协方差会错误估计χ²的有效自由度。
3. **bin中心vs体积平均:** 代码使用`w_interp(z_c)`（bin中心的插值w），而DESI bin约束（如果有的话）通常是bin内的体积加权平均w。对于强演化w(z)（w+1在z~0.85达峰值0.6），这个差异可能显著。

### 2.2 对角近似的量化影响

报告Sec.5.3 A7声称:"DGF与LCDM的chi2差异（Delta_chi2 ~ 30-75）远大于任何合理的协方差修正（~5-10）。"

**此声称未经计算支撑。** 协方差修正的量级取决于bin间关联系数。如果相邻bin的关联系数ρ~0.5（w(z)重构的典型值），有效d.o.f.从7降至约4-5，χ²的期望值和方差都会改变。更重要的是，如果bin间存在正关联，当前的χ²可能同时高估或低估——方向不确定。

**建议的验证（未执行）:** 
- 从DESI DR2 chains中提取binned w的后验样本
- 计算样本协方差矩阵
- 用`(w_model - w_data)^T · C^{-1} · (w_model - w_data)`重新计算χ²

### 2.3 DESI binned值的来源追踪

INSPECTOR独立验证了这些binned值与CPL参数化(w₀=-0.785, w_a=-0.43)的一致性:

### 2.4 χ²_LCDM验证

LCDM的χ²=4.82（w=-1对所有bin）。INSPECTOR复算:

### 2.5 底线

**当前χ²计算不能支持"被DESI DR2数据在>4σ排除"的结论。** 它最多支持"DGF的慢滚近似+常数alpha版本与一组近似DESI binned约束不一致"——这是一个更弱且诚实的表述。要做出"DESI DR2排除"的声明，必须使用DESI DR2的实际似然函数（通过MCMC chains或官方likelihood code），而非对角近似的二次派生bins。

## 3. 1000参数网格扫描方法论

**判定: PASS (条件通过) ✓⚠**

### 3.1 网格设计

5×5×5×8 = 1000组合。参数范围:

| 参数 | 范围 | 点数 | 分辨率 |
|------|------|:--:|------|
| gamma0 | 0.02-0.50 | 5 | 非均匀: 0.02, 0.05, 0.10, 0.20, 0.50 |
| alpha | 1.2-10.0 | 5 | 1.2, 2.0, 3.0, 5.0, 10.0 |
| r_c | 0.1-5.0 | 5 | 0.1, 0.5, 1.0, 2.0, 5.0 |
| eta_tilde | 0.1-50.0 | 8 | 0.1, 0.5, 1.0, 2.0, 5.0, 10.0, 20.0, 50.0 |

### 3.2 方法论评估

**优点:**
- 对数式间距合理（在量级尺度上覆盖参数空间）
- 物理可行性标准明确（Delta0 ∈ [0.01, 0.95], w0 ∈ [-0.98, -0.60]）
- 19/1000 ≈ 1.9%的可行率表明物理约束是选择性的

**缺点:**
- 5-8点/维度对4D参数空间是粗网格。特别是gamma0=0.02-0.50（25倍范围仅5点）可能遗漏敏感区域
- **全部5个精细模型位于同一角落** (gamma0 ≤ 0.05, r_c ≥ 2, alpha ≤ 5.0)。这不是"19个可行→5个精细"的选择——这是所有存活者聚集在同一区域，表明网格可能漏掉了大部分可行空间
- eta_tilde的校准使用二分法（对w0），但gamma0/alpha/r_c保持网格固定值——**没有在这些维度上优化chi²**
- 因此"最佳chi²=37.56"不是全局最小值，只是网格上5个校准点的最佳值

### 3.3 更严重的问题: 校准目标与评估指标脱节

代码校准eta_tilde使w0≈-0.80（与DESI w0一致），然后**用同一数据的z-binned w来评估chi²**。如果校准目标改为直接最小化chi²（而非w0），chi²可能更低。当前37.56是"w0校准约束下的条件chi²"，不是全局最小chi²。

### 3.4 底线

1000点网格扫描作为探索性工具是充分的。但作为"排除"结论的基础，方法论的严格性不足——缺少在全部4个参数维度上的优化、未验证网格分辨率、未测试极端参数值（gamma0→0或r_c→∞）。

## 4. "DGF被>4σ排除"的统计基础

**判定: FAIL ✗ (统计基础不支撑结论)**

### 4.1 报告中的计算

报告Sec.3.1: p = 1 - F_χ²(37.56, 7) ≈ 9×10⁻⁶，声称对应">4σ"。

数值验证: χ²=37.56 with 7 d.o.f. → p ≈ 9.4×10⁻⁶。对应高斯单尾显著性约4.4σ。">4σ"在数字上成立，但**这个计算的每一个输入都有问题**。

### 4.2 问题链

**问题1: 数据未经官方验证。** 7个binned w值和误差来自非官方、非标准、未记录确切来源的派生数据（见§2.1-2.3）。如果实际DESI w(z)约束的误差比代码中的对角值大30%（计入重构平滑的系统误差），χ²会降到约22，对应约3.5σ——仍在"排除"区但边际不同。

**问题2: 参数自由度未正确处理。** DGF有4个参数（gamma0, alpha, r_c, eta_tilde）。其中eta_tilde通过二分法校准到w0目标，gamma0/alpha/r_c通过网格扫描隐式优化。恰当的d.o.f.应在3（7 bins - 4 params）到6（若参数优化效应弱）之间。将d.o.f.取为3: p(χ²=37.56, 3) ≈ 3.3×10⁻⁸ ——实际上更显著。但这也意味着模型被排除得更厉害——而参数的先验范围（特别是tau_c的61量级不确定性, Sec.5.4 U1）未被纳入，它们应该被边缘化而非固定。

**问题3: Look-elsewhere效应。** 1000个参数组合被扫描。在纯噪声假设下，1000次试验中观察到最小χ²=37.56的概率需要通过试运行因子(trials factor)修正。粗略估计: p_corrected ≈ 1 - (1 - 9.4×10⁻⁶)^1000 ≈ 0.0094 → 约2.3σ。这是过于保守的（因为1000次试验不独立），但它说明了报告中的统计显著性可能被高估了1-2σ。

**问题4: 数据-模型比较的循环性。** 校准使用w0≈-0.80（来自DESI），然后声称DGF被排除因为它在其他z bins中不匹配DESI。但如果w0校准本身来自DESI，整个比较不是独立的——DESI数据已经被用于"训练"模型（通过校准），然后同一数据被用于"测试"模型。

### 4.3 代码中的σ计算错误

代码`compare_DESI` (line 409):
```python
sigma_equiv = np.sqrt(max(delta_chi2, 0.0))
```

使用`delta_chi2 = chi2_LCDM - chi2_DGF = 4.82 - 37.56 = -32.74` → `max(-32.74, 0) = 0` → `sigma_equiv = 0.0`。

**这是一个代码bug。** `delta_chi2`被定义为LCDM减DGF，当DGF的χ²更大时delta_chi2为负。代码将其归零，导致sigma_equiv=0——这使得所有DGF模型的输出中sigma显示为0.00，报告无法从此值获得有意义的σ。报告中的">4σ"来自手工计算（p值），而非代码输出。代码本意可能是`delta_chi2 = chi2_DGF - chi2_LCDM`（正的）或取绝对值。

### 4.4 可支持的统计陈述

当前分析可支持的陈述: **"在所探索的参数范围内，DGF慢滚近似的binned w预测与从已发表文献中提取的近似DESI z-binned约束存在定性张力，χ²约为38-120（对角近似，7 bins），而相同数据下ΛCDM的χ²约为4.8。"**

不可支持的陈述: **"DGF被DESI DR2数据在>4σ水平排除。"**

## 5. "当前实现"vs"DGF原理"的区分诚实性

**判定: PASS (诚实但需标注) ✓⚠**

### 5.1 诚实要素

报告在多处明确区分:

- Sec.8.2: "这不是DGF框架的终结论，而是其当前实现（一阶慢滚+常数alpha）的排除"
- Sec.5.1 A1-A3: 三项一级假设被明确列为"可能改变结论的"
- Sec.5.4 U1-U3: 三项"致命的未解决问题"（tau_c不确定性、phantom crossing缺失、D0因子2）
- Sec.7.2: "逃生通道"被明确列举（phantom crossing、二阶惯性、未探索参数空间）

这些是负责任的学术实践。报告没有声称框架本身被排除。

### 5.2 ⚠️ 标注: 核心声明的语言与细节不匹配

尽管细节处诚实，但**报告的标题级声明使用了绝对化语言**:

- "DGF被DESI DR2数据在>4sigma水平上排除" (Sec.3.1)
- "P0作为DGF的'硬'独立预言被数值结果否定" (Sec.2.4)
- "DGF当前版本...在DESI DR2的z-binned w约束下被排除" (Sec.7.3)

这些声明在技术上对应"当前实现被排除"，但措辞（"DGF被排除"、"否定"）在日常语境中不区分"实现"和"框架"。Sec.8.2的诚实学术声明与这些标题之间存在语气落差。

### 5.3 缺失的概率评估

报告列举了"逃生通道"但未评估其贝叶斯先验概率。如果:
- P(phantom crossing能恢复与DESI的一致性) = 0.05
- P(二阶惯性项能实质性改变w(z)) = 0.10
- P(L2红移依赖能提供调节自由度) = 0.08

那么DGF框架存活的综合概率（假设独立）≈ 1 - 0.95×0.90×0.92 ≈ 0.21。这不是"排除"——这是"面临重大挑战但仍有约20%存活概率"。

**报告应提供这种粗粒度的存活概率估计，而非二元"排除/未排除"结论。** 当前未提供此估计。

### 5.4 "逃生通道"的不对称性

报告将所有未纳入的物理效应列为"可能改善拟合"的通道，但未讨论它们也可能**使拟合更差**的可能性:

- 完整二阶惯性项可能产生w(z)振荡，增加而非减少χ²
- L2红移依赖的alpha(z)如果导致反应在高z更强，会使早期Delta偏离更大
- 自洽Friedmann+telegraph耦合可能放大而非缩小w(z)的偏离

"逃生通道"的表述暗示方向性是已知的（只可能改善），但物理上方向不确定。这是诚实的疏忽而非故意的误导，但应被标注。

### S2. 与B博士R3的交叉验证

B博士的独立数值代码（`B/verify_wz.py`）使用完全不同方法（驱动主导形状函数，非ODE积分），得到定性一致但定量不同的结果:

### S3. 代码中的技术问题

**(a) sigma_equiv bug (line 409):** 如上所述，`delta_chi2`符号导致sigma始终为0。

**(b) 二分法方向假设 (line 306):**
