## Q1 量纲 — 1项阻断

### Q1.1 telegraph方程各项量纲（Eq 1）: 通过

Eq (1): $\tau_c \partial_t^2 q + [1 - \tau_c R'(q)] \partial_t q = D_0 \nabla^2(\ln q) + R(q)$

逐项验证:
- $\tau_c \partial_t^2 q$: $[T] \cdot [T]^{-2} = [T]^{-1}$ ✓
- $[1 - \tau_c R'(q)] \partial_t q$: 无量纲 $\cdot [T]^{-1} = [T]^{-1}$ ✓
- $D_0 \nabla^2(\ln q)$: $[L]^2[T]^{-1} \cdot [L]^{-2} = [T]^{-1}$ ✓
- $R(q)$: $[T]^{-1}$ ✓

Eq (1)的维度一致性和每条左右项均为$[T]^{-1}$，推导正确。

### Q1.2 FLRW背景方程各项量纲（Eq 7）: ⛔ 阻断

Eq (7): $\tau_c \ddot{q} + \beta(q) \dot{q} = R(q) + \kappa\int_0^t [1-q(t')]dt' - \eta \cdot \text{SFR}(t)$

- $\tau_c \ddot{q}$: $[T] \cdot [T]^{-2} = [T]^{-1}$ ✓
- $\beta(q) \dot{q}$: 无量纲 $\cdot [T]^{-1} = [T]^{-1}$ ✓
- $R(q)$: $[T]^{-1}$ ✓
- $\eta \cdot \text{SFR}$: $[M]^{-1}[L]^3 \cdot [M][L]^{-3}[T]^{-1} = [T]^{-1}$ ✓

**⛔ κ项量纲矛盾:**

手稿声明 $\kappa \equiv H_0 c^2/R_c^2$，量纲为 $[T]^{-2}$。实际计算:
$$H_0 \cdot c^2 / R_c^2 = [T]^{-1} \cdot [L]^2[T]^{-2} / [L]^2 = [T]^{-3}$$

$[T]^{-3} \neq [T]^{-2}$。且记忆积分$\int_0^t [1-q]dt'$量纲为$[T]$，因此$\kappa\int[1-q]dt'$的量纲为$[T]^{-3} \cdot [T] = [T]^{-2}$，与方程左侧的$[T]^{-1}$不匹配。

**诊断:** $H_0$因子是多余的。S1记忆核给出的 $K(\tau) \approx c^2/R_c^2$ 量纲为 $[T]^{-2}$，$\kappa$ 应直接等于 $c^2/R_c^2$，不应乘 $H_0$。

**阻断级别:** 阻断（必须修正）。方程(7)的κ项无法与其余项量纲匹配。修正方案: $\kappa = c^2/R_c^2$ 或 $\kappa = H_0^2$（如果 $R_c \sim c/H_0$）。需从S1原文确认κ的正确定义。

### Q1.3 w(z)公式的无量纲性: 通过

Eq (15): $w(t) = -1 + \dot{\Delta} / [3H(1-\Delta)]$

- $\dot{\Delta}$: $[T]^{-1}$
- $H$: $[T]^{-1}$
- $1-\Delta$: 无量纲
- $\dot{\Delta}/(3H(1-\Delta))$: 无量纲 ✓

推导链:
$$\dot{\rho}_{DE} + 3H(\rho_{DE} + P_{DE}) = 0$$
$$\rho_{DE} = \rho_\Lambda(1-\Delta) \Rightarrow \dot{\rho}_{DE} = -\rho_\Lambda\dot{\Delta}$$
$$P_{DE} = -\rho_\Lambda(1-\Delta) + \rho_\Lambda\dot{\Delta}/(3H)$$
$$w = P_{DE}/\rho_{DE} = -1 + \dot{\Delta}/[3H(1-\Delta)]$$

所有步骤量纲自洽。✓

### Q1.4 ρ_DE ∝ 1-q 的量纲自洽性: 通过

Eq (14): $\rho_{DE} = \rho_\Lambda \cdot q = \rho_\Lambda(1-\Delta)$

- $\rho_{DE}$: $[M][L]^{-1}[T]^{-2}$

量纲自洽 ✓。物理意义上 $q=1 \Rightarrow \rho_{DE}=\rho_\Lambda$（纯真空，最大能量）和 $q \to 0 \Rightarrow \rho_{DE} \to 0$（完全确定化，无剩余真空能）一致。
