## Q1 量纲审查

**结论: 存在维度缺陷，需要乘以τ_c因子修复。**

### 1A. 种群动力学→DGF翻译: 维度一致 ✓

种群方程:
- `dN/dt = r N (1 - N/K)`: 左边[N]/[T], 右边[1/T]×[N]×[1]=[N]/[T] — 一致。

DGF反应项:
- `R(q) = (1-q)(Γ - γ₀ q)`: (1-q)无量纲，(Γ-γ₀q)为[1/T], R(q)为[1/T]。
- 电文方程: `τ_c ∂²_t q + [1-τ_c R'(q)] ∂_t q = R(q)`。τ_c[T], ∂²_t q [1/T²], 第一项[1/T]; ∂_t q [1/T], 第二项[1/T]; R(q) [1/T]。每一项都是[1/T]，维度一致。✓

### 1B. w(z)表达式: 维度不一致 ✗

§1.4中w的定义:

```
w = (q̇²/2 - V_eff(q)) / (q̇²/2 + V_eff(q))
```

其中:
- `q̇²/2` 维度为 [1/T²] (q无量纲, d/dt 给出 [1/T])
- `V_eff(q) = -∫ R(q) dq`, R(q) 为 [1/T], q 无量纲 → V_eff 维度为 [1/T]

**分子和分母混合了 [1/T²] 和 [1/T]，维度不同，无法加减。** 这在物理上等价于将加速度和速度相加。

### 1C. z=0时的数值计算同样受影响

```
q̇²/(2 V_eff) = (1+w₀)/(1-w₀) = 0.11
```

此比值中 `q̇²` [1/T²] 除以 `V_eff` [1/T] 得到 [1/T] — 不能等于无量纲的0.11。

### 1D. 修复方案

最短路径: 在所有w表达式的动能项中引入τ_c因子:

```
w = (τ_c q̇²/2 - V_eff(q)) / (τ_c q̇²/2 + V_eff(q))
```

此时 `τ_c q̇²/2` 维度为 [T]×[1/T²]=[1/T]，与 V_eff(q) 匹配。数值关系修改为:

```
τ_c q̇²/(2 V_eff) = (1+w₀)/(1-w₀) = 0.11
```

此修复具有物理意义: τ_c是因果延迟时间，它作为惯性质量出现在有效动能中——正好对应电文方程中τ_c乘以二阶导数的角色。

> **或者**: 全文统一切换至无量纲系统（§2.2已开始但§1.4尚未），用 t̃=H₀t 和 Ṽ=V/H₀。目前两份系统混用，读者无法判断何时在哪个系统里。无论选择哪种方案，必须全文统一。

**判定: Q1不过。需在Round 2中注明修复。**

## Q2 "w(z)必须非单调"论证的坚实性

**结论: 论证方向正确，但被导数错误污染，修复后定性结论仍成立（阈值偏移了3倍）。**

### 2A. 核心不等式独立于导数错误

电文方程的二阶结构（τ_c q̈项）确实使振荡在数学上可能，而标准一阶滚降（3H φ̇主导）不可能。这个核心逻辑不依赖于R'(q)的具体形式——只需电文方程是二阶的。**方向正确。**

### 2B. R'(q)导数错误——关键发现 ⚠️

§2.1给出的导数是:

```
R'(q) = -Γ + γ₀ - 2γ₀ q   [文本声称]
```

正确导数（展开法或乘法法则均可验证）:

```
R(q) = Γ - (Γ+γ₀)q + γ₀ q²
R'(q) = -(Γ+γ₀) + 2γ₀ q     [正确]
```

**验证** (取Γ=2, γ₀=1):
- R(q) = 2 - 3q + q²
- R(0.1) = 1.710, R(0) = 2.000, 有限差分: (1.710-2.000)/0.1 = -2.90
- 正确R'(0) = -3.0 ≈ -2.9 ✓
- 文本R'(0) = -2+1 = -1.0 ✗

### 2C. 此错误的传播范围

**(a) q=1稳定性** (`§2.3 积点q=1`):

| | 正确 | 文本 |
|:--|:--|:--|
| R'(1) | -Γ+γ₀ | -Γ-γ₀ |
| 阻尼系数(分子) | 1+ε(Γ-γ₀) | 1+ε(Γ+γ₀) |
| 自然频率 ω₀ | √((Γ-γ₀)/ε) | 同(巧合OK) |
| 阻尼比 ζ | [1+ε(Γ-γ₀)]/[2√(ε(Γ-γ₀))] | [1+ε(Γ+γ₀)]/[2√(ε(Γ-γ₀))] |

**影响**:
- 文本的ζ系统性偏大（分子中γ₀贡献的符号相反）
- 文本看起来更难实现欠阻尼（需要更大ε补偿）
- 正确版较容易欠阻尼——这实际上**对B博士有利**: 振荡比文本声称的更容易发生

**(b) q_* = Γ/γ₀ 稳定性** (`§2.3 积点q_*`):

| | 正确 | 文本 |
|:--|:--|:--|
| R'(q_*) | Γ-γ₀ | γ₀-3Γ |
| 稳定性条件 | γ₀ > Γ 时稳定 | γ₀ < 3Γ 时稳定 |
| 相变阈值 | Γ = γ₀ | Γ = **γ₀/3** |

**影响**: 文本少算了3倍。§2.4(2)"起飞期"说阈值是Γ=γ₀/3，正确应为Γ=γ₀。物理图像（阈值触发相变）维持不变，但数值红移位置需重标。巧合性问题的解答仍成立，但定量细节改变。

**(c) 巧合性问题** (`§2.3末尾`):

文本写道: "达到阈值 Γ_eff = γ₀/3 时相变发生"。正确应为 Γ_eff = γ₀。数字改了，论证的定性力量不变，甚至更好——因为Γ=γ₀表示"解放率赶超重捕获率"，比"解放率达到重捕获率的1/3"更有直观物理意义。

**(d) §5.2(3) V_eff(1)符号分析**:

文本认为 q=1 在 Γ < γ₀/3 时是局部极大值（不稳定）。正确版本: q=1 在 γ₀ > Γ 时是鞍点（不稳定）。正确的稳定性交换发生在 Γ = γ₀，导致更清晰的transcritical分岔图:
- γ₀ > Γ: q_* 稳定吸引子, q=1 鞍点
- Γ > γ₀: q_* 鞍点, q=1 稳定吸引子
- 临界点 Γ=γ₀: 分岔

这比文本的双稳态方案（某区域两个吸引子共存）在动力系统上更优美。

### 2D. 物理可行性

"欠阻尼振荡在宇宙学中是否满足物理条件？"

- **正面**: κ-本质或DGP等模型确实允许w(z)的非单调演化。w(z)振荡在现有文献中并非禁忌——文献中已有Albrecht-Skordis势等可产生振荡的quintessence模型。B博士的贡献在于振荡来源于因果结构（Cattaneo延迟）而非势能形状，这个区分本身是新颖的。
- **反面**: τ_c作为因果延迟时间有下限（因果结构不能比光速慢无限多）。τ_c 如果远小于哈勃时间（ε ≪ 1），欠阻尼需要很精细的参数范围。§2.5表中"ε ∼ 0.1, ζ 略小于1"是最优区域但其存在性需要在参数空间中演示——当前纯定性。

**判定: Q2方向基本正确但受导数错误影响。修复导数后，所有不等式和稳定性条件需重写。建议Round 2完整重算§2.3。**

## Q3 循环论证审查

**结论: 中等风险，已被诚实声明部分缓解，但q→w的翻译规则缺乏唯一性辩护。**

### 3A. 循环路径分析

潜在的循环:
1. 假设q场动力学 = 暗能量动力学（§1.4: "基本假设（从S7继承）: ρ_DE ∝ q"）
2. 从q(t)解计算w(z)（通过动能-势能分解）
3. 宣布w(z)的预测行为是"暗能量的新特征"

如果步骤1被质疑，步骤3的"预测"就退化为"如果q是暗能量则暗能量有什么性质"——这是逻辑重言式，不是经验预测。

### 3B. 三条防线

| 防线 | 强度 | 备注 |
|:--|:--|:--|
| §0方法声明: "不声称种群动力学'解释'暗能量...仅使用数学同构" | ★★★ | 诚实划界，降低审查负担 |
| 预测独立于q↔DE假设: w(z)非单调性、CPL残差结构、fσ₈偏移都是可观测的w(z)行为 | ★★☆ | 即使拒绝q↔DE映射，预测仍可检验 |
| 同构先例: "静电学↔流体力学↔热传导的Laplace/Poisson同构" | ★★☆ | 论证同构映射本身是合理的物理操作 |

### 3C. q→w翻译的唯一性问题 ⚠️

核心弱点在§1.4:

```
w = (q̇²/2 - V_eff(q)) / (q̇²/2 + V_eff(q))
其中 V_eff(q) = -∫ R(q) dq
```

**问题**: 为什么V_eff采取此特定形式？在电文方程中R(q)是反应项（源汇项），不是保守力。`V = -∫ F dx`的类比适用于保守系统的力，而反应-扩散系统中的反应项本质上是耗散的。将R(q)积分定义"势能"是一个选择，而非唯一推导。

文献中反应-电文方程的能量函数通常取不同的形式（如Lyapunov泛函、自由能泛函），且这些泛函包含τ_c和扩散系数的因素。当前选择 `V_eff = -∫ R dq` 是合法的构建但不是唯一的，w(z)的定量行为会随V_eff定义而改变。

**建议**: Round 2增加一段辩护——为什么此特定V_eff构造在DGF框架中是最自然的（例如从作用量原理推导，或其他构造会破坏某对称性/产生非物理特征）。目前缺口使"预测"感觉像是特意为匹配DESI w₀≈-0.80而设计的。

### 3D. ρ_DE ∝ q 与"束缚DoF凝聚能提供负压"的内部张力

§1.4同时声称:
- "束缚DoF的'凝聚能'提供负压 → 暗能量"
- "ρ_DE ∝ q (自由DoF携带真空能密度)"

这产生了方向矛盾: 负压来自**束缚**DoF，但能量密度来自**自由**DoF。两句话可以调和（例如残留束缚DoF的凝聚能密度随q增大而增大），但文章未做调和。目前读起来像是: 暗能量既是束缚DoF的事（负压），又是自由DoF的事（能量密度）。需澄清。

**判定: Q3中等风险。循环边界被诚实声明守住，但q↔w的翻译需要唯一性辩护，ρ_DE归属需要澄清。**

## 附加发现（不在Q1–Q4范围内，但值得记录）

### A1. 符号冲突

§2.3中 ε 同时表示:
- τ_c H₀ (因果延迟与哈勃时间之比，约0.1)
- q偏离1的小量（"线性化 q = 1 - ε"）

这造成§2.3后续方程读起来像 `ε ε̈` ——无法判断哪个ε是参数哪个是变量。**必须给其中一个改符号**（建议小量改用δ或η）。

### A2. §1.3自查正确但未追到底

B博士自查发现 Γ_eff→0 当 q→1，与"目标移动"图像矛盾，并修正为"自抑制"图像。这是好的科学实践。但未检查: 如果 Γ_eff 在 q→1 时指数衰减为零，电文方程中的 R(q) = (1-q)(Γ_eff - γ₀ q) 在 q→1 时趋于 0·(0 - γ₀) = 0 —— 这没问题。但 §2 的稳定性分析假设 Γ 是常数（绝热近似），与 Γ_eff(q) 实际依赖q矛盾。这个非线性自洽问题在 §5.2(2) 被诚实记录但影响范围被低估: **所有需要 Γ 为常数的推导（整个 §2.3）都只是近似，在 q→1 附近可能定性错误。**

### A3. 高原期 w≈-1 的极限

§2.4(1): q≈0 时 V_eff(0)=0, q̇≈0。w表达式 0/0 不定型。需以极限处理:分子分母同除以q, 利用 V_eff(q)≈-Γq 对小q, 得 w→-1。当前文本未指出此极限操作。

### A4. 缺失项

- 对 DESI DR2 的实际z-binning能力缺乏讨论（DESI DR2目前主要用3-4个独立z-bin，探测w(z)振荡所需的bin数未评估）
- 对现有w(z)振荡模型文献的引用空白（如Albrecht-Skordis, 2002; Kaloper-Sorbo, 2006; 及其他ω(t)非单调暗能量模型），不能假装振荡预测在宇宙学文献中是全新的

### A5. §4 Layer 4的价值

过阻尼区的次要预测（w₀-w_a斜率与标准quintessence不同）是目前最有操作性的低垂果实——它不需要振荡检测，只要CPL参数空间中的不同允许区域。**建议将此提升为预测4（过阻尼可区分性）而非留在§4中。**
