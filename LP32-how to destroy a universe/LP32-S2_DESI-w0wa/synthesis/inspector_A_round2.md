## 4. P0形状比R≈2.8: 推导自洽性与量纲

**判定: PASS (带标注) ✓⚠**

**量纲验证:** R = (w+1)/(w+1), 无量纲比。✓

**推导结构验证:**

Eq(R2.15): R_DGF ≡ (w(1.2)+1)/(w(0.3)+1) ≈ 2.8 (2.1-3.5)

分子(w(z)+1)取自Eq(R2.18):
```
w(z)+1 = [η·SFR - γ₀(α-1)Δ - γ₀Δ² - H₀²∫Δdt'] / [3H(β₀+2τ_cγ₀Δ)(1-Δ)]
```

驱动主导假设: η·SFR >> 反应项 + 记忆项 → 约分后R ≈ SFR比 × H比 × 1-Δ修正

**数值路径自洽性检查:**

| 步骤 | 值 | 来源 |
|------|-----|------|
| SFR(1.2)/SFR(0.3) | 0.093/0.0185 = 5.03 | 文中声称Madau & Dickinson(2014) |
| H(0.3)/H(1.2) | 1.05/2.04 = 0.515 | 文中给定 |
| √(ρ_*(0.3)/ρ_*(1.2)) | √(3.38/2.35) = 1.20 | 文中给定 |
| 弱Cattaneo: R | 5.03 × 0.515 = 2.59 | ✓ |
| 强Cattaneo: R | 5.03 × 0.515 × 1.20 = 3.10 | ✓ |
| 总范围 | 2.1-3.5 | 包含额外参数不确定性 |
| 中心值 | ~2.8 | 2.59和3.10的中点=2.845≈2.8 ✓ |

**⚠ 标注1: SFR数值需交叉验证。**

Madau & Dickinson (2014)拟合公式: ψ(z) = 0.015(1+z)^2.7 / (1+((1+z)/2.9)^5.6) M⊙/yr/Mpc³

INSPECTOR独立计算:
- ψ(0.3) = 0.015 × (1.3)^2.7 / (1+(1.3/2.9)^5.6) ≈ 0.015 × 2.03 / 1.011 ≈ **0.0301**
- ψ(1.2) = 0.015 × (2.2)^2.7 / (1+(2.2/2.9)^5.6) ≈ 0.015 × 8.41 / 1.213 ≈ **0.104**
- 比值: 0.104/0.0301 = **3.46** (vs 文中5.03)

文中0.0185和0.093与Madau & Dickinson(2014)标准公式不一致。可能使用了不同的SFR编译、IMF修正或局部SFR密度(而非宇宙平均)。差值因子为5.03/3.46≈1.45, 直接影响P0中心值(2.8→约1.9)。

**缓解因素:**
- A博士已声明数值为"量级估计"(§6.2注释)
- 范围2.1-3.5已包含大幅不确定性
- P0的证伪条件(§9.4)仅依赖R>1或R≈1的定性区分, 不依赖精确值
- A博士在§9.1 O2中诚实标注此问题

**INSPECTOR建议:** Round 3中明确引用的SFR数据来源和确切数值, 与Madau & Dickinson(2014)标准公式的差异需文档化。

**⚠ 标注2: 驱动主导假设在z=0.3处可能不成立。**

在z=0.3处SFR≈0.019-0.030 M⊙/yr/Mpc³(低值), 而修正后记忆项H₀²∫Δdt' ≈ H₀²Δ·t₀ ~ 10⁻¹⁹ s⁻¹与反应项γ₀Δ ~ 10⁻¹⁹ s⁻¹等量级(§8)。驱动项η·SFR的竞争力取决于η值, 可能在三者中不占绝对优势。A博士在§9.1 O2中已诚实标注此问题。该标注使P0推导的可信度保持在合理水平——不是隐瞒假设缺陷, 而是声明了适用范围。
