## 1. Kerr度规下DGF修正的精确计算

### 1.1 q场在Kerr背景中的径向剖面

在Boyer-Lindquist坐标中，Kerr度规:

```
ds² = −(1 − 2GMr/ρ²) dt² − (4GMa r sin²θ/ρ²) dt dφ
      + (ρ²/Δ) dr² + ρ² dθ²
      + (r² + a² + 2GMa² r sin²θ/ρ²) sin²θ dφ²
```

其中 ρ² = r² + a² cos²θ, Δ = r² − 2GMr + a², a = J/M (自旋参数, 0 ≤ a ≤ GM)。

DGF中的q场在球对称静态背景下满足∇²(ln q) = 0（DGF牛顿极限），解为q(r) = e^{−GM/rc²}。在Kerr度规中，由于轴对称性，q场原则上可以依赖θ:

```
q(r, θ) = exp(−GM / (r c²) · f(θ; a))
```

其中f(θ; a)编码了旋转对有效引力势的修正。在赤道面(θ = π/2)，Kerr度规的径向结构由Δ和ρ²控制。对Sgr A* (a ≈ 0.5-0.94 GM)，我们考虑两种极限:

**Case S (慢转近似, a ≪ GM):** f(θ) ≈ 1，q仅依赖r，修正量级O(a²/r²)。
**Case F (快转, a ≈ 0.94 GM):** 在赤道面，Δ的零点（事件视界）从2GM移至GM + √(G²M²−a²) = 1.34 GM（a=0.94GM时）。f(π/2) ≈ 1 − 0.1×(GM/rc²)。

**关键结论:** 对r ≥ 10 r_s = 20 GM，自旋对q(r)的修正 ≲ 1% (a=0.94GM, θ=π/2)。在10-50 r_s的B3预言范围内，球对称近似q(r) = e^{−GM/rc²}足够精确。

### 1.4 完整场方程的度规偏离估计（物理形式）

- Schwarzschild半径: r_s = 2GM/c² ≈ 1.27×10¹⁰ m ≈ 0.085 AU
- r_s的角尺寸: θ_s ≈ 10.3 μas
- 光子球 (∼2.6 r_s): θ_ph ≈ 26.8 μas

DGF修正特征尺度:
- r = 10 r_s → 角尺度 ≈ 103 μas → 当前EHT分辨率(20 μas)下可分辨约5个beam

**结论:** 特征空间尺度假定在ngEHT/EHT分辨率内，不需要更高的角分辨率来**分辨**该区域。挑战不在于"能不能看到10r_s处的结构"，而在于**能不能从该结构提取出足够精度的度规信息**以区分2%的度规偏离。

### 2.3 信噪比与标准差异估计

检测DGF修正的观测途径有多个层级:

#### 2.3.1 层级1: 阴影尺寸偏移

黑影的角直径主要由光子轨道决定。对Kerr黑洞:
- 阴影半径R_sh ≈ √27 GM/c² (Schwarzschild)
- 阴影半径R_sh ≈ 4.5 GM/c² (Kerr, a=0.94, θ=90°, 顺行侧受压缩)

DGF通过G_eff(r)修改光子轨道处的有效引力势，从而移动阴影边界。效应量级:

```
ΔR_sh / R_sh ∼ (ΔG_eff/G) 在光子轨道处 × O(1) 几何因子
```

光子轨道在r≈2.6r_s (Schwarzschild)或r≈1.5-2r_s (Kerr prograde)。在该处:
- 弱场近似下: ζ(2.6r_s) = 2α (1−q)², 1−q = 1−e^{−1/2.6} ≈ 0.319
- ζ ≈ 2α × 0.102 ≈ 0.204α
- ΔG/G ≈ −17% (α=1)

**但此估计在强场区不可靠**——需要使用完整的耦合q-Einstein数值解。

即使在最保守情况下，若强场反馈压制修正10倍（有效ΔG/G ∼ −2%），阴影偏移∼2%。当前EHT对M87*阴影尺寸的测量精度约为±5%（Event Horizon Telescope Collaboration 2019, ApJL 875, L6）。ngEHT的动态范围改善(500:1 vs 100:1)和灵敏度提升(~5×)可以将阴影尺寸精度提升到约±1-2%。

**因此，若α∼1且强场修正未完全被屏蔽，ngEHT对阴影尺寸的测量精度(~1-2%)可能与DGF信号(~2%偏移)处于同一量级——可检但需要高S/N和良好的系统误差控制。**

#### 2.3.2 层级2: 亮度分布不对称性

这是**更强的检验**。在10-20r_s处，DGF修改引力势→改变吸积流/喷流发射区域的光线传播→改变EHT图像的亮度分布。

在10r_s处，Case A给出ΔG/G ≈ −1.8%。这个尺度的引力势变化改变光子轨迹的偏转角约:
```
Δφ_deflection / φ_deflection ∼ ½(ΔG/G) × (r/2r_s)^{−1}  (球对称近似)
```

在r=10r_s处: ∼½×0.018×0.2 ≈ 0.18%。

这似乎很小，但EHT通过VLBI闭合量和 visibility amplitudes 探测的是整个亮度分布——不是逐点测度规，而是测积分效应。**在10-15r_s处∼1-2%的度规修正，通过吸积流的整个辐射转移过程后，可能在EHT的闭合相位中产生显著的系统性偏离。**

**定量估计——ngEHT灵敏度:**

ngEHT在345 GHz的灵敏度（单基线, 10s积分）:
```
σ_visibility ∼ SEFD / √(2Δν t_int)
            ≈ 3000 Jy / √(2 × 16×10⁹ Hz × 10 s)
            ≈ 3000 / √(3.2×10¹¹) ≈ 0.005 Jy
```

Sgr A*在345 GHz的通量密度约为2-3 Jy，因此单基线S/N ∼ 400-600 (10s积分)。在数小时合成观测中，综合S/N可达>10⁴。在S/N ∼ 10⁴时，闭合相位精度约为10⁻⁴ rad量级。

DGF在r∼10r_s处∼2%的度规修正，通过辐射传输转化为可视度的变化量级预计为∼0.5-2%（取决于具体的吸积模型）。在10⁻⁴的闭合相位精度下，这对应**∼50-200σ**的信号。

**但这极度依赖于吸积模型的不确定性。** 主要系统误差来源:
1. 吸积流模型（MAD vs SANE, 电子加热模型）
2. 喷流/盘风几何
3. 星际散射的时变效应

在实际中，系统误差很可能主导统计误差，将有效σ降低到5-10σ量级。

#### 2.3.3 层级3: 光子环细结构 (BHEX)

BHEX（空间VLBI, 分辨率∼5 μas）可以分辨n=1光子环（宽度∼4 μas for M87*）。光子环的精确形状和亮度分布对度规高度敏感。DGF在光子轨道处的修正（若未被强场反馈压制）会直接改变光子环的直径和不对称性。

但这是2030s的能力，且需要确认DGF在强场(r∼2-3 r_s)的完整数值解。

## 3. 替代天文检验

### 3.1 S型恒星轨道 (S2, S29, S38, S55, S301)

- 施瓦西进动检测: **∼10σ** (基于S2, S29, S38, S55的多星轨道拟合)
- S2近心点距离: ∼1400 r_s ≈ 120 AU
- GRAVITY天体测量精度: ∼50 μas/历元 ≈ 5 r_s at 8.3 kpc
- GRAVITY+升级(进行中): 灵敏度提升→更暗恒星→更近轨道

**DGF效应估计:**

在S2近心点 (r=1400 r_s):
- 1−q ≈ 7.1×10⁻⁴
- ΔG/G ≈ 2α (1−q)² ≈ 1.0×10⁻⁶ α 

这是不可检测的——等效于在1400r_s处修改引力势约10⁻⁶量级。

**S301（新发现）:** 近心点距离仅∼120 r_s (MPE 2025科学报告)。在120 r_s:
- 1−q ≈ 0.0083
- ΔG/G ≈ 2α (0.0083)² ≈ 1.4×10⁻⁴ α
- 轨道进动修正Δφ/φ ∼ (ΔG/G) ∼ 1.4×10⁻⁴ α

当前Schwarzschild进动检测10σ，意味着进动精度约10%。若S301能达到类似的相对精度，检测1.4×10⁻⁴的进动修正需要σ_φ/φ < 10⁻⁴——需要将天体测量精度从50 μas提升到∼1 μas量级。

**这大大超出了GRAVITY+的能力，但可能在ELT/MICADO时代(2030s)达到。**

## 5. 自我攻击 (Round 3)

### 攻击1: 弱场近似在强场的外推

**问题:** §1.2-1.3的所有r≲6r_s数值基于q(r)=e^{−GM/rc²}，但这是从∇²(ln q)=0（DGF牛顿极限）导出的，仅在|Φ|≪c²成立。在r∼2-3r_s (光子轨道)，|Φ|/c²∼0.3——弱场近似不可靠。实际的q(r)可能因非最小耦合反馈（ξ'(q)R项驱动q场）而显著偏离e^{−GM/rc²}。

**回应:** 这是真实的限制。B3预言的强场端(r≲10r_s)的精确数值必须通过耦合的q-Einstein方程组的数值积分获得——这是LP32-S4的核心任务。但r≥15r_s的弱场端不受此限制。

### 攻击2: ngEHT可检性的模型依赖性

**问题:** §2.3中"50-200σ统计信号"的估计依赖于吸积流模型——将ΔG/G转化为可视度变化的传递函数未知。不同的吸积模型(MAD vs SANE, R-high vs R-low电子加热)给出不同的传递函数。而且EHT的图像重建过程自身使用GR假设——将DGF图像输入GR假设的重建管线会产生什么偏差？

**回应:** 这是一个重要的系统误差。最稳健的检验策略是**自洽分析**: (1) 用DGF修正的射线追踪代码生成模拟数据, (2) 通过标准GR假设立的数据管线处理, (3) 寻找残余闭合相位异常。这需要专门的天体物理建模——超出了理论推导的范畴，但与EHT合作组的联合工作是有价值的。

### 攻击3: 恒星轨道检验的量级评估过于悲观？

**问题:** §3.1断言S301的进动修正∼1.4×10⁻⁴α不可检测。但轨道进动对G_eff的沿轨道积分敏感——如果r=120r_s是最接近点（偏心轨道），则轨道大部分时间在更大的r处（效应更弱）。另一方面，DGF对近心点进动的修正来自整个轨道周期的∮G_eff(r)dr积分——可能比单点估计略有增强（约2-3倍）。重新评估: 有效Δφ/φ∼3×10⁻⁴α——仍然太小。

**回应:** 确实如此。即使考虑轨道积分增强因子2-3，Δφ/φ∼3×10⁻⁴α，α需>30才能在1σ检测——对应的ΔG/G在近心点∼0.4%——这在恒星级质量天体物理中是大效应，但S301进动10σ检测的误差棒∼10%仍然远大于DGF信号。

### 攻击4: q→1屏蔽作为"不可证伪性"的辩护

**问题:** 若太阳系约束要求ξ₀≪M_P²（即α,β≪1），则所有天体物理检验都看不到DGF效应。此时DGF是否变得不可证伪？

**回应:** 这是一个合理的担忧。但从DGF的角度，ξ₀的标度有上下两个极值:
- 上界(M_P²): α∼1 → 天体物理可检（ngEHT/GW边缘可检）
- 下界(H₀²): α∼10⁻¹²⁰ → 天体物理完全不可检 → 仅宇宙学尺度可检（DESI w₀-w_a）

DGF的独特性在于它同时有微观标度(CP^{N-1} FS曲率)和宏观标度(宇宙学常数)。如果ξ₀取中间值(如GUT标度∼10³² GeV²，α∼10⁻⁴)，天体物理效应在可检测的边缘之下——但宇宙学效应（修正Friedmann方程）仍可能存在。这使DGF成为**原则上可证伪的理论**: α是一个参数——要么被探测到（验证DGF），要么被排除到某个上界以下（约束DGF参数空间）。
