## §0 框架声明

**我选的学科: 弹性力学。**

不是流体力学。不是相变理论。是弹性力学。

为什么？因为流体力学从标量压力p到Navier-Stokes张量方程，中间隔了一个速度场v_i——压力的梯度∂_i p驱动速度场，速度场的对流和粘性扩散产生应力张量。这是一个**两步涌现**: 标量→矢量→张量。用这个来类比"标量q场→张量引力方程"，多了一个中间层。

相变理论更不行。Ginzburg-Landau从标量序参量ψ出发，δF/δψ=0给出的是**标量场方程**（GL方程）。要得到张量方程，需要序参量本身就是张量（如超流He-3的序参量是3×3复矩阵）——那还叫什么标量→张量涌现？

**弹性力学是最干净的映射。** 应变能密度W是一个标量，它的自变量是应变张量ε_ij。应力张量σ_ij是W对ε_ij的导数——一个标量对二阶张量的导数自然是一个二阶张量。没有中间步骤。没有额外假设。标量的自变量是张量，导数就是张量。

**这就是DGF需要的东西。** q场是一个标量。它的作用量S_q依赖于度规g_μν——一个二阶张量。S_q对g_μν的变分导数自然产生一个二阶张量。如果S_q选得正确，这个张量就是爱因斯坦张量G_μν。

这不是比喻。这是**数学同构**: 标量泛函对张量自变量的导数产生同阶张量场方程。

## §1 核心同构: 从应变能到爱因斯坦-希尔伯特作用量

### 1.1 直觉跳跃

考虑一块橡胶。你拉伸它、扭曲它、挤压它。橡胶内部存储了弹性能——一个标量，取决于每个点上的应变状态。这个标量函数W(ε_ij)包含了橡胶的全部力学行为。

现在问: 橡胶为什么会回弹？因为能量最小化原理δ∫W dV=0。变分产生一个张量方程: ∂_j σ_ij=0（无体力时的平衡方程）。σ_ij本身是W对ε_ij的导数。

**整个张量力学——应力的六个分量，三个平衡方程，边界条件——全部从一个标量函数W(ε)涌现出来。** 你不需要假设应力的存在。你只需要一个标量能量函数，剩下的由变分原理完成。

这就是DGF应该对引力做的事。q场的作用量S_q是一个标量泛函，依赖于度规g_μν。变分δS_q/δg_μν=0应该产生爱因斯坦方程。G_μν不是假设的——它是涌现的。

### 1.3 为什么不是流体力学或相变理论

**流体力学**的问题: 标量压力p不是势函数——它是状态方程p(ρ,T)的输出，不是作用量的输入。在Navier-Stokes中，动量方程ρDv_i/Dt = -∂_i p + ∂_j τ_ij是一个**力的平衡**，不是直接从单个标量势的变分导出的。需要先将p的梯度插入速度场演化，再通过速度梯度构造粘性应力τ_ij。两步涌现——不够原始。

**相变理论**的问题: Ginzburg-Landau的自由能F[ψ,∇ψ]对标量序参量ψ变分，δF/δψ=0给出标量方程。要得到张量方程，序参量必须包含矢量或张量自由度。超流He-3的序参量是3×3复矩阵（18个实分量），变分给出18个耦合方程——但这不是"标量→张量"的涌现，而是"张量→张量"的平凡推广。

**弹性力学的优越性**: W是一个标量，它的自变量ε_ij是一个二阶张量。变分δW/δε产生同阶张量。涌现是**零步**的——导数运算本身就完成了标量到张量的跃迁。你需要的全部条件就是: (1) 存在一个标量泛函，(2) 这个泛函依赖于一个张量场，(3) 最小化原理。仅此而已。

## §2 数学同构: 变分原理的对位

### 2.1 弹性力学侧: 从W(ε)到∂_j σ_ij = 0

**第一步: 定义应变能密度。**

位移场u_i(x)描述物质点的位移。应变张量:
$$\varepsilon_{ij} = \frac{1}{2}\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right)$$

应变能密度W是ε_ij的标量函数。对于各向同性线弹性材料:
$$W(\varepsilon) = \frac{\lambda}{2}(\text{tr}\varepsilon)^2 + \mu\,\text{tr}(\varepsilon^2)$$

其中λ, μ是Lame常数。

**第二步: 定义应力张量（本构关系）。**

应力是应变能的"导数":
$$\sigma_{ij} = \frac{\partial W}{\partial \varepsilon_{ij}}$$

为什么这是对的？考虑一个虚位移δu_i。虚应变δε_ij = (1/2)(∂_i δu_j + ∂_j δu_i)。应变能的变化:
$$\delta W = \frac{\partial W}{\partial \varepsilon_{ij}}\delta\varepsilon_{ij} = \sigma_{ij}\delta\varepsilon_{ij}$$

这就是虚功原理: 应力在虚应变上做的功等于应变能的变化。**σ_ij作为W的导数，并不是假设的——它是从W的定义中自然产生的。**

对于各向同性线弹性:
$$\sigma_{ij} = \lambda\,\text{tr}(\varepsilon)\delta_{ij} + 2\mu\,\varepsilon_{ij}$$

**注意这个结构:** 应力 = (标量系数)×单位张量 + (标量系数)×应变本身。这和爱因斯坦张量的结构一模一样。

**第三步: 变分原理产生场方程。**

总势能:
$$\Pi[u_i] = \int_V W(\varepsilon_{ij}) dV - \int_V f_i u_i dV - \int_{\partial V} t_i u_i dS$$

其中f_i是体力，t_i是面力。

一阶变分:
$$\delta\Pi = \int_V \sigma_{ij}\delta\varepsilon_{ij} dV - \int_V f_i\delta u_i dV - \int_{\partial V} t_i\delta u_i dS = 0$$

分部积分（利用δε_ij的对称性）:
$$\int_V \left(-\frac{\partial\sigma_{ij}}{\partial x_j} - f_i\right)\delta u_i dV + \int_{\partial V} (\sigma_{ij}n_j - t_i)\delta u_i dS = 0$$

由δu_i的任意性，得到:
$$\boxed{\frac{\partial\sigma_{ij}}{\partial x_j} + f_i = 0}$$

**这就是弹性力学的场方程。** 一个标量W(ε) → 张量本构σ_ij(ε) → 张量场方程∂_j σ_ij + f_i = 0。全程没有假设任何张量场——一切都是从标量W和它的张量自变量ε中涌现的。

### 2.2 DGF/GR侧: 从L_q(q,g_μν)到G_μν = 8πG T_μν

将弹性力学的三步翻译到引力:

**第一步: 定义q场有效作用量密度。**

度规g_μν是"应变"——描述时空偏离平坦Minkowski的程度。q场是标量"物质场"。有效作用量（来自v3_effective_action.md，Level 1保守近似）:

$$S_q[q, g_{\mu\nu}] = \int d^4x \sqrt{-g} \left[ f(q)R(g) + \frac{1}{2\kappa}\frac{(\partial q)^2}{q^2} + V(q) \right]$$

其中f(q) = M_P²/2 + λ(q)，λ(q) ~ (1-q)是非最小耦合。f(q)在q→1时趋于M_P²/2（Planck质量平方的一半——标准GR）。

加上物质作用量S_m[ψ, g_μν]。

**第二步: 定义"引力应力"（能动张量）。**

类比σ_ij = ∂W/∂ε_ij，定义:
$$T_{\mu\nu}^{\text{(total)}} = -\frac{2}{\sqrt{-g}}\frac{\delta S_{\text{total}}}{\delta g^{\mu\nu}}$$

这个定义是标准GR的Hilbert能动张量定义。它的形式完全类比弹性力学: 标量作用量对标量自变量的导数产生同阶张量。

**注意结构上的完全平行:**
- 弹性: W是ε_ij的函数 → σ_ij = ∂W/∂ε_ij
- 引力: S_q是g_μν的泛函 → T_μν ∝ δS_q/δg_μν
- 都是"能量/作用量"对标量自变量的导数产生"力/应力"张量

**第三步: 变分原理产生场方程。**

$$\delta S_{\text{total}} = \delta S_q + \delta S_m = 0$$

对g_μν的变分:

$$\delta S_q = \int d^4x \sqrt{-g} \left[ f(q)\left(R_{\mu\nu} - \frac{1}{2}R g_{\mu\nu}\right) - \nabla_\mu\nabla_\nu f(q) + g_{\mu\nu}\Box f(q) \right] \delta g^{\mu\nu}$$

$$+ \int d^4x \sqrt{-g} \left[ \frac{1}{2\kappa}\left(\nabla_\mu q \nabla_\nu q - \frac{1}{2}g_{\mu\nu}(\nabla q)^2\right) - \frac{1}{2}g_{\mu\nu}V(q) \right] \delta g^{\mu\nu}$$

（标准GR变分 + q场动能和势能的贡献）

令δS_total = 0，得到:
$$f(q)G_{\mu\nu} = \frac{1}{2} T_{\mu\nu}^{(m)} + T_{\mu\nu}^{(q)}$$

其中:
$$T_{\mu\nu}^{(q)} = \frac{1}{2\kappa}\left(\nabla_\mu q \nabla_\nu q - \frac{1}{2}g_{\mu\nu}(\nabla q)^2\right) - g_{\mu\nu}V(q) + \nabla_\mu\nabla_\nu f(q) - g_{\mu\nu}\Box f(q)$$

$$T_{\mu\nu}^{(m)} = -\frac{2}{\sqrt{-g}}\frac{\delta S_m}{\delta g^{\mu\nu}}$$

**在q→1极限下**（真空，f(q)→M_P²/2，f'(q)的非最小耦合消失）:
$$\frac{M_P^2}{2} G_{\mu\nu} = \frac{1}{2} T_{\mu\nu}^{(m)}$$

即:
$$\boxed{G_{\mu\nu} = 8\pi G\, T_{\mu\nu}^{(m)}}$$

其中8πG = 1/M_P²。

**这就是完整的爱因斯坦方程，从标量q场作用量涌现。** 不需要假设G_μν的存在——它作为δS_q/δg_μν的引力部分自然出现。

### 2.3 方程的逐项对位

将弹性力学的场方程结构映射到爱因斯坦方程:

| 弹性力学项 | 物理意义 | DGF/GR对应项 | 物理意义 |
|-----------|---------|-------------|---------|
| ε_ij = ∂_(i u_j) | 位移梯度→应变 | g_μν | 度规（时空"应变"） |
| W(ε) | 应变能密度 | L_q(q,g)√(-g) | q场有效作用量密度 |
| σ_ij = ∂W/∂ε_ij | 应力（本构关系） | δS_q/δg^μν | 引力"应力" |
| ∂_j σ_ij + f_i = 0 | 平衡方程 | G_μν = 8πG T_μν | 爱因斯坦方程 |
| C_ijkl = ∂²W/∂ε_ij∂ε_kl | 弹性模量 | 8πG (来自∂²S_q/∂g²) | 引力耦合强度 |
| 各向同性: λ, μ | 材料常数 | G (唯一耦合常数) | 引力"刚度" |
| Hooke定律: σ = C:ε | 线性应力-应变 | 线性化GR: □h_μν ∝ T_μν | 弱场近似 |
| δ∫W dV = 0 | 最小势能 | δ∫L√(-g)d⁴x = 0 | 最小作用量 |

**关键的结构平行:**

1. **本构关系:** 在弹性中，σ_ij(ε)的形式由W(ε)决定。在引力中，G_μν(g)的形式由L_q(g)决定。改变W → 改变材料行为。改变L_q → 改变引力理论。

2. **材料对称性:** 在弹性中，各向同性意味着W只能依赖于ε的不变量I₁,I₂,I₃。在引力中，微分同胚不变性意味着L_q必须是曲率标量（Lovelock定理: 在4维中，唯一给出二阶场方程的标量是R + 常数）。

3. **线性化:** 在弹性中，小应变→Hooke定律（线性）。在引力中，弱场→线性化爱因斯坦方程（□h_μν∝T_μν）。两者的线性化结构完全相同: 二阶线性微分算子作用于基本场 = 源。

## §3 弹性力学教给DGF的三件事

### 3.1 第一课: 本构关系决定一切 —— f(q)是引力的"材料常数"

在弹性力学中，W(ε)的形式决定了材料的所有力学行为:
- W = (λ/2)(tr ε)² + μ tr(ε²) → 线弹性，各向同性
- W = C₁(I₁-3) + D₁(J-1)² → neo-Hookean超弹性，橡胶
- W = (μ/2)(I₁-3) + (K/2)(J-1)² → 可压缩neo-Hookean

在DGF中，**f(q)就是引力的"本构函数"**。不同的f(q)给出不同的引力理论:

| f(q)的形式 | 引力理论 | 类比材料 |
|-----------|---------|---------|
| f(q) = M_P²/2 (常数) | 标准GR | 线弹性（刚度恒定） |
| f(q) = M_P²/2 · q | q衰减→G_eff增大 | 应变软化材料 |
| f(q) = M_P²/2 · q² | q衰减→G_eff更快增大 | 强软化材料 |
| f(q) = (M_P²/2) + ξ(1-q)² | 有阈值的修正 | 双线性弹性 |

**DGF的独特选择**（来自v3_effective_action.md）:
$$f(q) = \frac{M_P^2}{2} + \xi(1-q)$$

当q=1（真空），f(1) = M_P²/2，恢复标准GR。
当q→0（完全确定化），f(0) = M_P²/2 + ξ → 有效Planck质量增大 → 引力变弱（G_eff = 1/(M_P²+2ξ) < G）。

**物理后果:** 在强场区域（q→0，如黑洞附近），有效引力耦合变弱。这给出了一个falsifiable的预言: 黑洞附近的引力比GR预测的弱——等效于G在强场中跑动。

### 3.2 第二课: 协调方程 = Bianchi恒等式 —— 自洽性不是额外假设

在弹性力学中，应变ε_ij由位移u_i的梯度定义。这意味着ε_ij不能任意给定——它必须满足**应变协调方程**（Saint-Venant compatibility）:

$$\varepsilon_{ij,kl} + \varepsilon_{kl,ij} = \varepsilon_{ik,jl} + \varepsilon_{jl,ik}$$

这6个方程（在3维中）确保存在一个位移场u_i使得ε_ij = ∂_(i u_j)。

在引力中，度规g_μν是基本场——不存在"更深层"的位移场。但有一个完全类比的结构:**Bianchi恒等式**。

$$\nabla^\mu G_{\mu\nu} = 0$$

在弹性力学中，协调方程的存在等价于: ∂_j σ_ij + f_i = 0（平衡方程）的积分可解性条件。如果协调方程不满足，不存在连续的位移场。

在引力中，Bianchi恒等式等价于: G_μν = 8πG T_μν（场方程）的可积性条件。如果∇^μ G_μν ≠ 0，则∇^μ T_μν ≠ 0——能动张量不守恒。

**翻译成DGF:** 在DGF中，能动张量守恒∇_μ T^μν = 0不是外加假设——它自动从f(q)G_μν = (1/2)T_μν^(m) + T_μν^(q)和Bianchi恒等式导出。**这是框架的内在自洽性，不是额外约束。**

但有一个新的问题: DGF的T_μν^(q)（q场的有效能动张量）也包含在守恒方程中。这意味着:
$$\nabla_\mu T^{\mu\nu}_{(m)} + \nabla_\mu T^{\mu\nu}_{(q)} = 0$$

物质能动张量不是单独守恒的——它与q场交换能量-动量。这是一个偏离标准GR的关键特征，可以通过天文观测来检验。

**预言B1（能动张量非守恒）:** 在DGF中，物质能动张量T^μν_(m)不是协变守恒的。存在q场-物质能量交换: ∇_μ T^μν_(m) = -∇_μ T^μν_(q) ≠ 0。这等价于有效引力"常数"G_eff(q)的时空变化 → 修改了宇宙学中物质密度ρ_m的演化方程:
$$\dot{\rho}_m + 3H\rho_m = -\dot{\rho}_q - 3H(\rho_q + p_q) \neq 0$$

这与标准ΛCDM不同（ΛCDM假设物质和暗能量分开守恒）。DGF预言两者之间存在缓慢的能量交换——速率由q̇决定。

### 3.3 第三课: 材料稳定性 → 引力稳定性 —— q场的凸性条件

在弹性力学中，应变能函数W(ε)必须满足**椭圆性条件**（ellipticity condition）——也称为Legendre-Hadamard条件:

$$\frac{\partial^2 W}{\partial\varepsilon_{ij}\partial\varepsilon_{kl}} n_j n_l m_i m_k > 0 \quad \forall n,m \neq 0$$

这意味着刚度张量C_ijkl = ∂²W/∂ε_ij∂ε_kl是正定的（在"声学张量"的意义上）。如果违反这个条件，材料会自发形成微结构（相变、局部化带、剪切带）——**失去均匀性**。

**翻译成DGF:** q场的势能V(q)必须满足稳定性条件。V(q)的凸性决定了q场真空是否稳定:

- V''(1) > 0 → q=1真空稳定 → 小偏离恢复（q>1不可能，DGF没问题）
- V''(q) < 0 for some q → q场在q处不稳定 → 可能产生空间非均匀性（畴结构）

当前的DGF势V(q) = V₀(q ln q - q + 1):
- V''(q) = V₀/q > 0 for all q>0 → **全局稳定**
- 这意味着q场的空间分布应该是均匀的——没有畴壁，没有相分离

但如果DGF的V(q)在某个q值附近失去凸性（例如，如果记忆积累产生等效负刚度），宇宙学就会产生q场的空间非均匀性——不同区域的q值不同，导致不同区域的有效G_eff不同。**这等价于"空间变化的引力常数"**——一个可以用类星体吸收线或21cm宇宙学来检验的预言。

**预言B2（q场稳定性→G的空间均匀性）:** DGF当前的V(q)形式（V''>0全局）预言G_eff的空间变化极小——由量子涨落决定，幅度δG/G ~ (H₀/M_P)² ~ 10⁻¹²²——在宇宙学尺度上完全不可检测。但如果V'(q)的记忆修正导致V''(q_c)<0的临界点q_c，则可能产生可观测的G_eff空间变化。

## §4 物理翻译: 从弹性力学同构到爱因斯坦方程的完整推导

### 4.1 为什么Li-Pang no-go不适用于这个路线

Li-Pang no-go定理说: Verlinde型推导（从熵+热力学出发）只能产生牛顿极限，不能产生标量曲率R项。

为什么？因为entropic gravity从面积律S ∝ A出发。面积是视界的几何量。视界的曲率是**外曲率**（extrinsic curvature K），不是**内禀曲率**（R）。当你从面积变分时，你得到的是∇²Φ = 4πGρ——牛顿方程。要得到R项，你需要从**体积**变分——即作用量积分∫R√(-g)d⁴x。

**弹性力学路线绕过了这个问题。** 因为我们不是从熵/面积出发。我们是从**作用量**出发。在弹性力学中，W是一个体积密度——它自然依赖于内禀的应变ε_ij，而ε_ij包含了全部几何信息。

对应地，**DGF的q场作用量必须包含体积曲率项**f(q)R(g)。这个R项不是从热力学导出的——它是从CP^{N-1}的Fubini-Study度规在4维投影中的曲率（v3_effective_action.md §2.1）自然产生的。

换句话说:
- Verlinde路线: 熵(面积) → 牛顿方程 → 不能到GR
- Jacobson路线: 局域Rindler视界+Unruh温度 → 热力学 → GR
- **DGF弹性路线: q场作用量(体积) → 变分 → 完整的G_μν**

弹性力学的类比告诉我们: **你需要体积变分，不是边界变分。** 热力学推导只能走到牛顿极限，因为热力学是边界理论。力学变分能走到完整GR，因为力学是体积理论。

### 4.2 从q场到G_μν的严格步骤

**Step 0: 识别"应变"——度规作为基本几何变量。**

在弹性力学中，应变ε_ij描述物质点相对于参考构型的位移。没有应变就没有应力。

在DGF中，度规g_μν描述时空相对于"CP^{N-1}真空"的偏离。q=1对应CP^{N-1}真空→FS度规的4维投影→Minkowski时空（或de Sitter，取决于Λ_FS）。

当q<1（结构形成发生），度规偏离真空——这相当于引力"应变"的产生。

**Step 1: 写下q场作用量（含非最小耦合）。**

$$S_q = \int d^4x \sqrt{-g} \left[ \left(\frac{M_P^2}{2} + \xi(1-q)\right)R(g) + \frac{1}{2}\frac{(\nabla q)^2}{q^2} + V_0(q\ln q - q + 1) \right]$$

三个部分:
- 引力部分: f(q)R(g) ——应变能的类比物。f(q)随q变化→引力"刚度"随"灰烬"累积而变化。
- q场动能: (∇q)²/q² ——来自FS度规在q方向的投影
- q场势能: V(q) ——q场的"自能"

**Step 2: 对度规变分→引力场方程。**

$$\frac{1}{\sqrt{-g}}\frac{\delta S_q}{\delta g^{\mu\nu}} = f(q)\left(R_{\mu\nu} - \frac{1}{2}R g_{\mu\nu}\right) + \left(g_{\mu\nu}\Box - \nabla_\mu\nabla_\nu\right)f(q) + T_{\mu\nu}^{(q,\text{kinetic})} = 0$$

加上物质作用量S_m:
$$f(q)G_{\mu\nu} = \frac{1}{2}T_{\mu\nu}^{(m)} + T_{\mu\nu}^{(q)}$$

其中:
$$T_{\mu\nu}^{(q)} = \frac{1}{2}\left(\frac{\nabla_\mu q \nabla_\nu q}{q^2} - \frac{1}{2}g_{\mu\nu}\frac{(\nabla q)^2}{q^2}\right) - g_{\mu\nu}V(q) - \left(g_{\mu\nu}\Box - \nabla_\mu\nabla_\nu\right)f(q)$$

**Step 3: 对q场变分→q场运动方程。**

$$\Box q - \frac{(\nabla q)^2}{q} + q^2 V'(q) + \xi q^2 R = 0$$

R项是关键——它耦合了q场和时空曲率。在平坦时空中(R=0)，q场退化为Klein-Gordon型（加上非线性项）。

在弯曲时空中，曲率驱动q场演化: 正曲率(R>0，物质主导) → q̇<0（q下降，灰烬累积加速）。这正是DGF的"结构形成→灰烬"反馈。

**Step 4: q→1极限→标准GR。**

当q=1（真空，无结构形成）:
- f(1) = M_P²/2
- ∇_μ q = 0, V(1) = 0
- T_μν^(q) = 0

$$\frac{M_P^2}{2}G_{\mu\nu} = \frac{1}{2}T_{\mu\nu}^{(m)} \quad\Rightarrow\quad G_{\mu\nu} = 8\pi G\,T_{\mu\nu}^{(m)}$$

**标准爱因斯坦方程完全恢复。**

**Step 5: q<1 → 修正的引力。**

当q<1:
$$G_{\mu\nu} = \frac{8\pi G_{\text{eff}}(q)}{2} T_{\mu\nu}^{(m)} + T_{\mu\nu}^{(q,\text{eff})}$$

其中:
$$G_{\text{eff}}(q) = \frac{1}{f(q)} = \frac{1}{M_P^2/2 + \xi(1-q)}$$

有效引力耦合随q变化。在强场区域(q→0)，G_eff→1/(M_P²/2 + ξ)。

**这不是f(R)引力——这是f(q)R引力，其中q是独立的动力学标量场。** 等价于标量-张量引力理论（scalar-tensor gravity），其中标量场ϕ通过非最小耦合ϕR与引力耦合。DGF的q场**就是**这个标量场。

### 4.3 与标量-张量理论的精确对应

将DGF的f(q)重写为标准Brans-Dicke形式:

$$\phi = 2f(q) = M_P^2 + 2\xi(1-q)$$

$$\omega_{\text{BD}}(\phi) = \frac{\phi}{4\xi^2(dq/d\phi)^2} = \frac{\phi}{4\xi^2(1/(2\xi))^2} = \frac{\phi}{\xi^2/(2\xi)^2} = \frac{4\phi}{\xi}$$

对于q≈1（ϕ≈M_P²）:
$$\omega_{\text{BD}} \approx \frac{4M_P^2}{\xi}$$

如果ξ ~ M_P²，则ω_BD ~ 4——与太阳系检验（ω_BD > 40,000 from Cassini）严重冲突。

**但这是误解。** DGF不是Brans-Dicke理论——因为ξ(1-q)的(1-q)因子。在太阳系中:
- 太阳质量 → q偏离1的量级: δq ~ GM_⊙/(c² · 1AU) ~ 10⁻⁸

**更关键的是:** DGF中的q不是任意传播的标量场——它的动力学由telegraph方程（含非保守记忆项）决定。在太阳系尺度（远小于R_c），q场被"冻结"在局部平衡值——等效于**屏蔽机制**（screening）。这类似于chameleon或symmetron机制，但源于DGF特有的粗粒化耗散。

## §5 弹性力学的独特洞察

### 5.1 "塑性屈服" = 强场GR偏离

弹性材料在应力超过屈服点时进入塑性——不可逆变形的累积。应力-应变关系不再是线性的，甚至不再是可逆的。

DGF中的对应: **当引力场足够强（q足够低），时空的"弹性响应"偏离GR。** 这发生在G_eff(q)显著偏离G的区域——即黑洞视界附近。

在弹性力学中，塑性屈服由屈服准则（如von Mises: σ_eq = σ_y）决定。

在DGF中，"引力屈服"由q跨越某个阈值决定:
$$q < q_{\text{crit}} \quad\Rightarrow\quad \text{GR偏离} > 1\%$$

估计q_crit:
$$\frac{\Delta G_{\text{eff}}}{G} = \frac{2\xi(1-q)}{M_P^2} \sim 0.01$$

如果ξ ~ M_P²/2（自然选择），则1-q ~ 0.02时偏离达到1%。这对应什么样的天体物理环境？

q(r)在球形天体周围（弱场近似）:
$$q(r) \approx 1 - \frac{GM}{rc^2} \cdot \alpha$$

其中α是DGF特有的参数（~1量级）。

1-q ~ 0.02 → GM/(rc²) ~ 0.02/α → r ~ 50 GM/c²（如果α~1）。

这意味着**在~50 Schwarzschild半径处，DGF修正达到1%**——远在光子球(3r_s)之外。这是一个可以通过EHT下一代观测或X射线双星光谱来检验的预言。

**预言B3（弹性屈服→强场GR偏离）:** DGF预言在黑洞周围r ~ 10-50 r_s处，度规偏离Kerr解达到~1-5%水平。这个偏离表现为G_eff的有效变化——等效于时空的"软化"。EHT的下一代观测（ngEHT，分辨率~10μas）可以探测这个尺度的度规偏离。

### 5.2 "残余应力" = 大尺度结构中的记忆应力

在弹性力学中，残余应力是在没有外部负载时材料内部仍然存在的应力——由不可逆的塑性变形历史产生。例如，淬火玻璃中的热应力、焊接件的残余应力。

**DGF中: q场的"残余应力" = 已经发生的结构形成事件留下的不可逆引力印记。**

数学上:
- 弹性残余应力: σ_ij^(res) = C_ijkl · ε_kl^(plastic) ≠ 0 (即使无外部负载)
- DGF残余"应力": G_μν^(res) = 来自K(t-τ)[1-q(τ)]记忆积分对G_μν的贡献

在标准GR中，真空中的引力场完全由边界条件决定。在DGF中，即使物质密度ρ_m=0的真空区域，记忆项也可能产生非零的G_μν——**真空不是空的**——它"记住"了过去的结构形成事件。

这在宇宙学中的体现: 空洞（voids）中的有效暗能量密度不同于宇宙平均值。因为空洞经历的结构形成历史不同于富星系团区域——积累的灰烬更少，q更接近1 → 有效暗能量密度更高。

**预言B4（残余引力→空洞暗能量异常）:** DGF预言宇宙空洞的"有效暗能量密度"略微高于富星系团区域，因为空洞的结构形成历史较浅（q更接近1）。这个效应表现为空洞内ISW（Integrated Sachs-Wolfe）信号的异常——空洞中的CMB光子通过时经历略不同的引力势演化。

### 5.3 "应变局部化" = q场的空间非均匀性

在弹性力学中，当材料进入软化阶段（∂σ/∂ε < 0），均匀变形变得不稳定——应变集中到窄带中（剪切带、Luders带）。这称为**应变局部化**（strain localization）。

DGF中: 如果q场的"有效刚度"变为负值——即∂(G_eff)/∂q > 0（q下降→G_eff增大→回流正反馈）——则可能出现q场的空间非均匀性。均匀的q(x)分布不稳定，自发形成q的"畴结构"——不同区域有不同q值。

这等价于在宇宙中自发形成**有效引力常数的空间变化**。

当前DGF框架中: f(q) = M_P²/2 + ξ(1-q) → ∂f/∂q = -ξ < 0 → 没有软化（q下降→f增大→G_eff减小→负反馈→稳定）。

但如果ξ<0（非最小耦合的符号反转），则可能出现应变局部化。这是一个理论上的可能性，目前没有证据支持——但弹性力学告诉我们它**可能在原理上存在**。
