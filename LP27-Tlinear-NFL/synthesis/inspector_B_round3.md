## Q2. 符号/方向校对（极限验证）

### 2.1 α=n_constraint 方向

- n_constraint=0（杂质散射）→ α=0（剩余电阻）。方向正确：弹性散射无温度依赖。
- n_constraint=1（单约束散射）→ α=1（T-linear）。方向正确：随T线性增长。
- n_constraint=2（FL两电子散射）→ α=2（T²）。方向正确：更强的温度依赖来自更多约束。

方向单调性: n_constraint↑ → α↑。物理含义：更多温度敏感约束→更强的温度依赖。合理。

**但有一个方向模糊**: "玻色子约束被临界涨落润滑→有效约束<1"的"润滑"机制没有独立定义。如何判断某个约束是被"润滑"到0.7还是0.3？这使n_constraint从离散计数变为连续调节参数——失去了α取离散值的最强预测力。

### 2.2 SOC噪声尺寸标度方向

S_R/R² ∝ (ξ_K/L)^d

- L → ∞: (ξ_K/L)^d → 0 → 噪声抑制。正确方向：宏观平均化。
- L → ξ_K: 噪声 → O(1)。最大信号方向正确。
- L < ξ_K: 公式给出>1？但B博士说N_eff→1（物理截断）。方向自洽。

**ξ_K = ℏv_F/k_BT 的温度依赖方向**:
- T↑ → ξ_K↓ → N_eff↓ → 噪声↑。即温度升高→噪声增强。这与标准热噪声(T↑→噪声↑)方向一致，但机制不同（SOC雪崩vs Johnson-Nyquist）。

### 2.3 接触Reeb流退化方向

退化临界子流形上的"零模": 沿退化方向扰动→A变化但α不变。沿非退化方向扰动→A和α同时变化。

对应实验（Zn掺杂vs过掺杂的行为差异），方向定性自洽。但这是**事后解释**而非事前预测——Zn掺杂改变A不改变α的事实早在B博士框架之前已知。

**循环风险**: 如果任何观察到的α浮动都被解释为"退化方向"，而任何α变化都被解释为"离开退化子流形"，则接触几何解释变得不可证伪。

### 2.4 B-field噪声谱转变方向

B↑→SOC雪崩被抑制→1/f→Lorentzian转变。

方向: 磁场破坏时间反演对称性→改变散射通道连通性→截断雪崩级联→单个弛豫时间主导→Lorentzian谱。物理方向合理。

## Q3. 循环论证校对

### 3.1 α=n_constraint 是否是新的循环？

Round 1的循环: 预设α=1 → 选择参数 → "推导"α=1 → 三跳交叉验证。
Round 2已打破此循环: 每跳独立推导，部分收敛。

Round 3的新方案: α=n_constraint。需要检验: n_constraint是否被预设为1？

**检验路径**:
1. 对于FL（电子-电子散射）: 声明n_constraint=2 → α=2。这是独立推导（从泡利原理和联合相空间出发），非预设。
2. 对于杂质散射（弹性）: n_constraint=0 → α=0。独立推导。
3. 对于T-linear奇怪金属: n_constraint=1 → α=1。

**问题在第三步**: "临界涨落润滑玻色子约束→有效约束<1→n_constraint→1"。润滑程度是根据已知的α=1**反推**的。如果某个系统显示α=1.3，润滑程度可以调整为"约束=0.7"来解释。

**这不是标准循环论证（A→B, B→A）**，而是**"灵活框架"问题**——参数（润滑程度）有足够多的自由度来适配任何观测。这削弱了框架的证伪能力。

**判定**: 无形式循环论证。但n_constraint方案存在"灵活适配"问题，类似于Ptolemaic本轮——总可以添加/调整约束计数来事后解释任何α值。框架需要的是**独立于α的约束计数方法**（如ARPES自能分析），这在Round 3中仅被提及为方向而非实现。

### 3.2 接触几何"统一"的收敛风险

Round 3声称MaxCal、WBE、Solomonoff、SOC在接触几何层面统一。但：
- 四个框架各自使用接触几何的**不同方面**（MaxCal用接触哈密顿流、WBE用离散接触同胚、Solomonoff用前缀接触结构、SOC用雪崩接触动力学）
- 将它们都称为"接触几何"类似于说"它们都用了微积分"——技术层面为真，但不足以声称"深度统一"
- B博士在§6.2自行承认置信度仅30%

**判定**: 不是循环论证，但统一声张过度。四个框架"共享接触几何语言"不构成"它们是同一数学结构的不同实例"的证据。


### 5.2 联合相空间FL T²论证（§1.2）⚠️

B博士声明的积分:
$$P_{\text{scatter}} \propto \int d\varepsilon_1 d\varepsilon_2 d\varepsilon_3 d\varepsilon_4 \cdot f(\varepsilon_1)f(\varepsilon_2)[1-f(\varepsilon_3)][1-f(\varepsilon_4)] \cdot \delta(\varepsilon_1+\varepsilon_2-\varepsilon_3-\varepsilon_4)$$

**问题: 缺少动量守恒约束。**

标准FL推导中，电子-电子散射率∝T²来自:
1. 每个初态电子在k_BT能量窗内（2个T因子）
2. 能量守恒δ减少1个积分维度
3. **动量守恒** k_1+k_2=k_3+k_4 在球形势能面上额外约束相空间（减少额外的T/E_F因子）
4. 联合结果: 散射率∝(k_BT)²/E_F → ρ∝T²

B博士仅含能量守恒δ的积分实际给出:
- 4个费米函数 = 4个k_BT窗口 → (k_BT)⁴
- 1个能量δ → 减少1个T因子 → (k_BT)³
- 结果: T³，不是T²

**为什么FL实际给T²**: 动量守恒+球形势能面要求k₁,k₂,k₃,k₄同在一个能量壳层上+矢量求和闭合。这个额外的几何约束减少了一个有效T幂次（本质上是小角度散射的相空间坍缩）。

**影响**: B博士从"联合约束计数"得出n_constraint=2（声称两个初态费米子→2个T因子），但论证中的积分为T³而非T²。n_constraint计数方案的正确性依赖一个隐含的额外因子（动量守恒的相空间约束），这个因子在计数方案中没有被显式建模。

**判定**: 不是计算错误（最终结果T²是对的），但推导中缺少关键步骤（动量守恒约束如何将T³降至T²），使n_constraint=2→α=2的论证不完整。

> "B_c≈Φ₀/ξ_K²≈ℏ/eξ_K²≈11T @ ξ_K=76nm"

**使用ξ_K=76 nm验算**:
```
ℏ/(e · ξ_K²) = 1.0546×10⁻³⁴ / (1.6022×10⁻¹⁹ × (7.6×10⁻⁸)²)
            = 1.0546×10⁻³⁴ / (1.6022×10⁻¹⁹ × 5.776×10⁻¹⁵)
            = 1.0546×10⁻³⁴ / 9.253×10⁻³⁴
            = 0.114 T
```
**用ξ_K=76 nm得到B_c≈0.11T，不是11T。**

**使用ξ_K=7.6 nm验算**:
```
ℏ/(e · ξ_K²) = 1.0546×10⁻³⁴ / (1.6022×10⁻¹⁹ × (7.64×10⁻⁹)²)
            = 1.0546×10⁻³⁴ / (1.6022×10⁻¹⁹ × 5.84×10⁻¹⁷)
            = 1.0546×10⁻³⁴ / 9.356×10⁻³⁶
            = 11.3 T
```
**用ξ_K=7.6 nm得到B_c≈11T。** 与B博士的B_c声明一致。

**内部矛盾分析**:
- ξ_K声明: 76 nm（偏大10×）
- B_c声明: 11 T（与ξ_K=7.6 nm自洽）
- 这两个数字在同一个文档中**相互矛盾**。B_c的计算（隐式地）使用了正确的ξ_K~7.6nm，而显式声明的ξ_K=76nm与B_c不兼容。

### 5.6 Jensen 1998 SOC β关系验证

Round 3 §2.1引用: "β = 1 + (τ-2)/(γ)（Jensen 1998, Eq. 4.42）"

未能访问Jensen 1998原始文献进行独立验证。标记为"引用验证待定"。

逻辑一致性检查: 若τ≈1.1-1.3（2D BTW沙堆），需γ≈(τ-2)/(β-1)。当β→1时分母→0，需τ→2。对于SOC标准值τ≈1.1-1.3，此公式给出β≠1。需具体γ值来验证β≈1是否成立。

**标记**: 公式来源未独立验证。β≈1的结论需给定τ和γ的特定取值范围。

### 5.7 接触同调→α离散谱论证（§4.2）

声称: "如果不同α对应不同接触同调类→α只能取离散值"

数学事实: 接触同调（Eliashberg-Givental-Hofer）确实将Legendrian子流形划分为离散等价类。这一点数学正确。

**但物理识别未建立**: "α对应接触同调类"是一个**未被论证的前提**。它依赖于:
1. 证明电阻率标度α是某个Legendrian子流形的不变量
2. 证明该不变量在接触同胚下不变
3. 证明不同α对应不同同调类

这三步均未执行。论证的"如果"承担了全部论证重量。

**判定**: 数学引理正确，物理前提悬空。
