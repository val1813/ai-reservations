## Q1. 量纲校对（逐公式，纯机械）

### 公式 1: Boltzmann 电导率（第242行）

$$\rho^{-1} = \frac{e^2}{2\pi^2\hbar} \oint d\theta_k\, v_k^2\, \tau(\theta_k) \left(-\frac{\partial f^0}{\partial\varepsilon_k}\right)$$

**量纲检查（SI，2D系统）:**
- `e²/ħ`: C²/(J·s) = C²·s/J
- `v_k²`: m²/s²
- `τ`: s
- `(-∂f⁰/∂ε_k)`: 1/J
- `dθ_k`: 无量纲

乘积: (C²·s/J) × (m²/s²) × s × (1/J) = C²·m²/(J²·s)

二维电导率 ρ⁻¹ 的单位: Ω⁻¹ = C²/(J·s)。乘积缺 m⁻² 因子，需由相空间积分提供。标准处理中，`∮ dθ_k` 结合 Fermi 面态密度 `k_F/(2π)` 可补齐量纲: (k_F/(2π)) × v_F² ∝ E_F/ħ，正好给出正确的 Ω⁻¹ 量纲。

**结论:** 公式结构正确（系标准 Boltzmann 输运公式），但文中省略了态密度因子，`e²/(2π²ħ)` 前的系数在严格 2D 各向同性系统中应为 `e²/(2πħ)` 或更常见的 `e²/h`。这不影响后续定性结论（ρ ∝ 1/τ），但若被引用于定量估算时需修正。

**判定:** ⚠️ 无阻断影响，建议补全态密度系数。

## Q5. 代数验算

### 验算 1: Boltzmann 积分 → Drude 形式（逐步展开）

**起点:**
$$\rho^{-1} = \frac{e^2}{4\pi^2} \int d^2k\, v_k^2\, \tau_k \left(-\frac{\partial f^0}{\partial\varepsilon_k}\right)$$

这是标准 2D Boltzmann 电导率公式（因子 1/2 来自角度平均）。

**步骤 1:** 将积分从 k-空间转为能量-角度空间：
$$d^2k = k\,dk\,d\theta = \frac{k}{\hbar v_k} d\varepsilon_k\, d\theta$$

**步骤 2:** 在 Fermi 面上 (T → 0)，(-∂f⁰/∂ε_k) → δ(ε_k - E_F):
$$\rho^{-1} = \frac{e^2}{4\pi^2} \int d\theta\, \frac{k_F}{\hbar v_F} \cdot v_F^2 \cdot \tau(\theta) = \frac{e^2 k_F v_F}{4\pi^2\hbar} \int d\theta\, \tau(\theta)$$

**步骤 3:** 对于 2D 抛物带: k_F = √(2mE_F)/ħ, v_F = ħk_F/m = √(2E_F/m)
$$k_F v_F = \frac{\hbar k_F^2}{m} = \frac{2E_F}{\hbar}$$
$$\rho^{-1} = \frac{e^2}{4\pi^2\hbar} \cdot \frac{2E_F}{\hbar} \int d\theta\, \tau(\theta) = \frac{e^2 E_F}{2\pi^2\hbar^2} \int d\theta\, \tau(\theta)$$

**步骤 4:** 利用 2D 态密度 g_{2D} = m/(πħ²) 和载流子密度 n = g_{2D}E_F = mE_F/(πħ²):
$$\rho^{-1} = \frac{e^2}{2\pi\hbar^2} \cdot \frac{mE_F}{\pi\hbar^2} \cdot \frac{1}{m} \cdot \frac{1}{2\pi} \int d\theta\, \tau(\theta) = \frac{ne^2}{m} \cdot \frac{1}{2\pi} \int d\theta\, \tau(\theta)$$

**步骤 5:** 若 τ(θ) = τ（各向同性）:
$$\rho^{-1} = \frac{ne^2\tau}{m} \quad\Rightarrow\quad \rho = \frac{m}{ne^2\tau}$$

✓ Drude 形式正确导出。

**文中的简化式** (1/(2π²ħ)) 含系数偏差。标准结果应为 `e²/(4π²)` 或等价的 `e²/(2πħ)`（取决于积分测度的约定）。不阻断定性结论。

**判定:** ✓ 代数正确（定性结论健壮；定量系数需校准）。

### 验算 2: ImΣ ∝ T 的详细推导

**起点:**
$$I = \int_0^\infty d\nu\, [n(\nu)+f(\nu)]\, \frac{\nu}{\nu^2+\omega_0^2}$$

**分区积分 (T ≫ ω₀):**

区域 (a): 0 < ν < ω₀
- n(ν) ≈ T/ν, f(ν) ≈ 1/2 → n+f ≈ T/ν
- ν/(ν²+ω₀²) ≈ ν/ω₀²
- 贡献: ∫₀^{ω₀} dν (T/ν)(ν/ω₀²) = T/ω₀² · ω₀ = T/ω₀

区域 (b): ω₀ < ν < T
- n(ν) ≈ T/ν, f(ν) ≈ 1/2 → n+f ≈ T/ν
- ν/(ν²+ω₀²) ≈ ν/ν² = 1/ν
- 贡献: ∫_{ω₀}^T dν (T/ν)(1/ν) = T(1/ω₀ - 1/T) ≈ T/ω₀

区域 (c): ν > T
- n(ν) ≈ e^{-βν} (指数抑制)
- 贡献可忽略

**总计:** I ≈ 2T/ω₀ → ImΣ(0) ∝ T (因为 ω₀ 在给定温度范围内为常数)。✓

**数值量级验证:**
T = 100 K, ω₀ = 10 K → I ~ 2×100/10 = 20 (以能量为单位归一化后的值)
T = 100 K, ω₀ = 1 K → I ~ 200
比率 I(T)/I(T_ref) ∝ T — T-linear 依赖健壮。✓

**判定:** ✓ 代数推导正确，数值量级合理。

### 验算 3: Z > 0 的论证

**文中论证:**
"ImΣ(ω)~|ω|的 Kramers-Kronig 变换给出 ReΣ(ω)~ω ln|ω|/ω₀，其斜率对数发散但被 γ 有限截断，因此 Z>0"

**验算——分情形讨论:**

情形 A: ω₀ 严格→ 0 且 T → 0
- ImΣ(ω, T=0) ∝ |ω|（来自 ImD ∝ 1/ν 的卷积）
- Kramers-Kronig: ReΣ(ω) ∝ ω ln|ω| → ∂ReΣ/∂ω ∝ ln|ω| → 发散 (ω → 0)
- Z → 0。**Z = 0。准粒子破坏。**
- 这与文中 "Z>0" 的声明矛盾。⚠️

情形 B: ω₀ 有限（非零），T = 0
- ImΣ(ω) ∝ ω²（对于 ω ≪ ω₀，因为 ImD(ν) ∝ ν/ω₀² at ν ≪ ω₀）
- Kramers-Kronig: ReΣ(ω) ∝ ω → ∂ReΣ/∂ω = const → Z 有限且非零。✓
- 但此时 ρ ∝ T²（非 T-linear），因为 T ≪ ω₀ 的极限适用于此参数。

情形 C: ω₀ 有限，T ≫ ω₀（Caprara 实际工作区间）
- 电阻率: ρ ∝ T（来自 ImΣ(ω=0) ∝ T），已验算。✓
- 关于 Z: 需要 ImΣ 的 ω-依赖性。在 T ≫ ω₀ 时，热涨落施加了 T 尺度的截断。ImΣ 在 ω ≪ T 区间 ≈ 常数（由热贡献主导），仅当 ω ≫ T 时恢复 ∼ω 行为。
- Kramers-Kronig: 常数 ImΣ 在有限带宽 W ∼ E_F 上的积分给出 ReΣ(ω) ∝ ω（线性，非对数发散），因此 ∂ReΣ/∂ω 有限 → Z > 0。✓

**关键洞察:** 在 T ≫ ω₀ 的实际实验温区，热效应正则化了 Z 的奇异性。Z 是温度的函数 Z(T)，在 T ≫ ω₀ 时 Z(T) > 0（有限），仅在 T → 0 且 ω₀ → 0 的双重极限下 Z → 0。

**文中的 "被 γ 有限截断" 措辞不精确:** γ → ∞（Caprara 极限）时，ω₀ = m/γ → 0，此时截断来自温度 T（费米/玻色分布的热展宽），而非 γ。更准确的表述: "当 T ≫ ω₀ 时，热展宽正则化了 ∂ReΣ/∂ω 的低能行为，使 Z(T) 保持非零；Z 仅在绝对零度下趋于零，但实验在有限温度进行。"

**判定:** ⚠️ 文中 Z > 0 的论证在物理上对实际温区是正确的，但表述需修正: 应明确指出是 "Z(T) > 0 at finite T" 而非 "Z > 0 在任何条件下"。且 "γ 有限截断" 措辞不准确——γ 在 Caprara 极限恰恰是发散的，截断来自 T。
