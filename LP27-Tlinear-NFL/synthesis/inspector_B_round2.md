## Q1. 量纲校对（逐公式，纯机械）

### 1.1 MaxCal 约束→N_avail→α 推导（核心错误）⭐⭐⭐

**错误位置**: 行86-93

```
声明: N_avail(T) = ∫_{E_F - k_BT}^{E_F + k_BT} g(E) dE
计算: 对d=3: N_avail ∝ ∫₀^{k_BT} √E dE ∝ T^{3/2}
```

**问题**: 积分限与计算不一致。声明的积分在费米能附近(E_F±k_BT)，但实际执行的是从带底起的积分(0→k_BT)。

**正确的物理计算**（近费米面，如声明所述）:
- g(E_F+ε) ≈ g(E_F) + ε·g'(E_F) + ... （泰勒展开）
- ∫_{-k_BT}^{k_BT} g(E_F+ε) dε ≈ 2·g(E_F)·k_BT + O(T³) → **N_avail ∝ T¹（对任何维度d）**

**因为**: 近E_F处DOS的领头阶是常数g(E_F)，在宽度k_BT的窗口内积分给出T¹。

**若使用"带底起积分"(∫₀^{k_BT})**: N_avail ∝ T^{d/2} 确实成立。但这不描述近费米面的散射——金属散射发生在E_F附近，而非带底。

**为什么这是阻断级的**:
- 整个MaxCal推导的枢纽步骤是: N_avail ∝ T^{d/2} → ⟨τ⁻¹⟩ ∝ T^{d/2} → α=d/2
- 但正确的近费米面计数给出 N_avail ∝ T（所有维度），导致 α=1 **对所有d**——这意味着MaxCal预测所有d维金属都是T-linear，这显然是错的（3D FL给出T²）。
- 即使用带底积分得到 T^{d/2}，积分的物理意义也不对——k_BT远小于E_F时，从E_F到E_F+k_BT的热激发电子数与从0到k_BT的完全不同。

**修正方向**:
- (a) 若保留积分限 ∫_{E_F-k_BT}^{E_F+k_BT}: 结果应为 N_avail ∝ T（和d无关），α≡1——预测所有金属T-linear（与已知FL相矛盾）
- (b) 若改积分限为 ∫₀^{k_BT}: 需要有物理理由说明为什么散射涉及带底态而非费米面态（对金属不合理）
- (c) 将N_avail重新解释为某种"相空间体积"的d维积分（而非态密度积分），需要全新的物理理由

### 1.3 噪声公式量纲不匹配（核心错误）⭐⭐⭐

**错误位置**: 行520-521

$$S_R(f, T) / \langle R \rangle^2 = C \cdot \frac{k_B T}{E^*} \cdot \frac{1}{1 + (f/f_c(T))^{\beta}}$$

**量纲分析**:
- 左端: S_R 是电阻涨落的功率谱密度，量纲 [Ω²/Hz]；⟨R⟩²量纲 [Ω²]。故 S_R/⟨R⟩² 量纲为 **[1/Hz] = [T]**（时间）。

### 5.4 MaxCal Fisher信息矩阵的协方差符号

行166-168: "对于MaxCal分布（指数族），二阶累积量由Fisher信息矩阵给出：Cov(J_i, J_j) = [ℐ^{-1}]_{ij}"

指数族标准结果:
P(x|θ) ∝ exp(θ·T(x) - A(θ))
Cov(T_i, T_j) = ∂²A/∂θ_i∂θ_j = ℐ_{ij}（Fisher信息等于充分统计量的协方差）

而 [ℐ^{-1}]_{ij} 是精度矩阵（precision matrix），不是协方差。

**如果J_i是拉格朗日乘子（自然参数）的估计量**: 则 Cov(θ̂_i, θ̂_j) → ℐ^{-1}_{ij}（渐近正态性）。在这种情况下符号正确。
**如果J_i是约束量（充分统计量）**: 则 Cov(J_i, J_j) = ℐ_{ij}，非 ℐ^{-1}_{ij}。

文档未明确J_i的定义（是约束量还是乘子？），使得公式无法验证。**标记为符号歧义**。
