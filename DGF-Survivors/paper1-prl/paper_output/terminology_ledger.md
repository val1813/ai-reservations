# 术语分类账 (Terminology Ledger)

> ⛔ 后续所有Agent只使用规范形式。术语一致性优先于词汇多样性。

| 规范形式 | 首次展开 | 来源变体 |
|---------|---------|---------|
| QCMI | Quantum Conditional Mutual Information | I(R;E'|Q'), quantum conditional mutual info, conditional mutual information |
| CFOL | Causal Fermi-Lohe Operation Lemma | CFOL theorem, causal ring theorem |
| Cartan angle | Rotation angle of Cartan-parameterized unitary | c_j, θ, rotation angle, Cartan parameter |
| Cartan axis | Axis of Cartan subalgebra rotation | n̂, aligned axis, σ_n̂方向 |
| causal ring | Four-qubit cyclic causal graph | ring, cycle, causal cycle, four-qubit ring |
| Gram matrix | G_{a,b} = ⟨φ(a)|φ(b)⟩ | G, Gram matrix, overlap matrix |
| RZZ gate | exp(iθ Z⊗Z) two-qubit rotation | RZZ(θ), ZZ rotation, exp(iθ σ⊗σ) |
| Pauli subgroup | Discrete rotations at multiples of π/2 | gates with θ∈(π/2)ℤ, Clifford rotations |
| QCMI-zero condition | Condition for vanishing quantum memory | c_j ∈ (π/2)ℤ, zero-QCMI points |
| non-Markovianity | Quantum memory beyond Markov approximation | quantum memory, information backflow |
| Cartan-aligned configuration | All edge unitaries share same Cartan axis | aligned axes, aligned configuration, uniform axis |
| reference R | Maximally entangled reference system | reference, R system, ancilla |
| system qubits | Q_a, Q_b in causal ring | Q, system, data qubits |
| environment qubits | E_1, E_2 in causal ring | E, environment, bath qubits |
| environment purity | p parameter in initial env state | p, purity parameter, |γ⟩ weight |
| θ² ln(1/θ) scaling | Correct QCMI scaling law | small-θ expansion, logarithmic correction |
| θ⁴ scaling | Standard perturbative prediction (incorrect) | quartic suppression, standard prediction |
| temporal ring protocol | Two-qubit ring via sequential RZZ gates | temporal protocol, 2-qubit temporal ring |
| spatial ring | Four-qubit ring on four physical qubits | 4-qubit spatial ring, spatial protocol |
| Choi-Jamiołkowski bridge | Mapping between spatial and temporal protocols | CJ bridge, channel-state duality |
| differential noise floor | Residual noise in differential QCMI measurement | σ_Δ, correlated noise cancellation |
| shadow tomography | Classical shadow estimation protocol | classical shadows, randomized measurements |
| squashed entanglement | Original QCMI-based non-Markovianity measure | squashed quantum non-Markovianity |
| Fawzi-Renner bound | Lower bound I(A:C|B) ≥ −2 log₂ F² | FR bound, fidelity lower bound |
| η₀ | η₀ = 1/(8 ln 2) ≈ 0.180 bit/rad² | FR coefficient, Fawzi-Renner coefficient |
