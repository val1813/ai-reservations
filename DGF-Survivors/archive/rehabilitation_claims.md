## 第2件: CFOL是HJPW推论 → 承认, 但说清增量

**审稿人攻击:** "CFOL将HJPW的代数充要条件翻译为Cartan参数条件。推论不是定理。"

**穿回论证:**

HJPW (2004): QCMI=0 ⟺ 量子态是短量子马尔可夫链 ⟺ Hilbert空间有直和分解结构

CFOL: 对于具体的4-qubit因果环电路, HJPW的直和分解条件 ⇔ 所有Cartan参数∈(π/2)ℤ

**HJPW没有告诉你的 (CFOL的增量):**

1. **操作性:** HJPW告诉你"存在某个直和分解"——但不知道是什么。CFOL告诉你: "把门旋转角调到π/2的整数倍"。这是实验者可操作的指令。

2. **几何化:** HJPW的条件是代数的(直和分解)。CFOL的条件是几何的(Cartan参数在Clifford点)。几何条件→可视化→直觉→推广。

3. **参数化:** CFOL给出QCMI作为Cartan参数的连续函数——不仅仅是零点条件, 还包括零点附近的行为(θ²log(1/θ)标度)。HJPW只给出零点本身。

4. **拓扑翻译:** CFOL把"QCMI=0"翻译成了因果图语言: Cartan轴对齐+Clifford参数。这打开了从因果拓扑研究量子关联的大门。

**诚实定位:** CFOL不是新定理——它是HJPW定理的一个**操作上有用的特例化**。物理学中大量重要结果都是这种特例化: Kepler定律是Newton力学的特例, 但不是trivial推论——它给出了具体的轨道形状和周期。

## 第3件: sqrt(iSWAP)等价 → 撤回, 替换为正确的关系

**审稿人攻击:** exp(iπ/4 σ_z⊗σ_z) ≠ sqrt(iSWAP) = exp(iπ/8 (XX+YY))

**撤回等价的声称。** 它们是不同的门。

**替换为正确的关系:**

sqrt(iSWAP)的Cartan参数(在XX/YY/ZZ分解下): (c_x=c_y=π/8, c_z=0)
单轴π/4: (c_x=0, c_y=0, c_z=π/4)

两者在不同Cartan轴方向上。对于单轴DFS条件4c∈πℤ:
- 单轴π/4: c_z=π/4 → 4c_z=π ∈ πℤ → DFS ✓
- sqrt(iSWAP): c_x=π/8 → 4c_x=π/2 ∉ πℤ → DFS ✗

**sqrt(iSWAP)不产生集体Clifford保护。** 之前声称的联系是错误的。

**但这引出一个新问题:** 对于非对齐Cartan轴(如sqrt(iSWAP)有两个非零c分量), DFS条件是什么?

推广: 4边环在非对齐Cartan参数{c_j^k}(j=边编号, k=轴编号)下, 系统返回自身的条件是每个Cartan轴分量独立满足4c^k∈πℤ。因为不同轴方向的Cartan旋转对易(它们在Cartan子代数中)。

对于sqrt(iSWAP): 需要同时有4c_x∈πℤ和4c_y∈πℤ→c_x, c_y都是π/4的整数倍。sqrt(iSWAP)的c_x=c_y=π/8不满足→无DFS。

**所以sqrt(iSWAP)和DGF DFS无关。** 撤回这条连接。这是个诚实的错误。

## 第4件: 热力学吸引子 → 撤回, 替换为开放问题

**审稿人攻击:** 无动力学方程, 无Lyapunov函数, 无证明。

**撤回"吸引子"声称。**

**替换为诚实的开放问题:**

"DGF目前不包含Cartan参数c的动力学。c由基本相互作用的耦合常数决定, 而耦合常数在标准模型中是外部参数。DGF不能解释为什么c取特定值——这需要DGF之外的新物理(或许是未来的墙#11: Cartan参数动力学)。

在缺乏c的动力学的情况下, DGF能说的是: *如果* 某个物理系统的有效Cartan参数落在π/4附近, *那么* 该系统的退相干效率接近最大。DGF不能解释为什么π/4会出现——它只能描述π/4出现后的后果。"

## 第6件: |factor|=0处的数值方法 → 修复

**审稿人攻击:** ln(max(|factor|, 1e-15))在|factor|精确为零时floors到-34.5→偏差。

**修复:** 在c=π/4, p=0.5处, |factor|=|cos(πΔ/4)|。这有解析形式。不需要采样。

解析计算μ:
```
μ(c=π/4, p=0.5) = E_Δ[ln|cos(πΔ/4)|]
```

其中Δ的概率分布已知(4个独立{±2,0}变量的和)。

|cos(πΔ/4)|=0当Δ=±2, ±6。这些Δ值的总概率>0→E[ln|cos|]发散→μ=-∞。

**这是精确解析结果, 不需要数值采样。** 审稿人的数值批评是有效的——但我们可以绕过它。
