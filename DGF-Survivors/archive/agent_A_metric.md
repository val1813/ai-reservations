## 1. 路径一: 谱几何 — 从图Laplacian到度规

这是最严格的数学路径，利用热核展开和Varadhan渐近公式。

### 1.1 加权图Laplacian

定义 DGF 因果图上的加权对称 Laplacian 矩阵:

```
L_{ij} = δ_{ij} Σ_k w_{ik} - w_{ij}
```

其中 w_{ij} = q_{ij} (对因果边) 或 w_{ij} = q_{ji} (对逆向边)。在空间超曲面上的诱导图上，L 是半正定的。

**物理解释**: L 是图上扩散过程的生成元。一个测试粒子在因果图上的随机游走感受到的局部扩散速率由出射边的 q 值决定。

### 1.2 扩散方程与热核

热方程:
```
∂_t f = -L f
```

热核 (Heat Kernel):
```
K_t(i, j) = (e^{-tL})_{ij}
```

K_t(i,j) 表示在时间 t 内从顶点 i 扩散到顶点 j 的概率幅。

### 1.3 图上的Varadhan渐近公式

Steinerberger (2019) 证明了有限图上的离散模拟:

```
K_t(i,j) = N_{ij} · t^{d(i,j)} / d(i,j)! + O(t^{d(i,j)+1}),   (t → 0+)
```

其中:
- d(i,j) 是图距离 (最短路径长度)
- N_{ij} 是长度为 d(i,j) 的最短路径数
- **加权推广**: 对于带权图, N_{ij} = Σ_{paths π:|π|=d(i,j)} Π_{e∈π} q_e

**关键**: 路径权重由路径上所有边的 q 值乘积给出。在连续极限下，路径积分变为:
```
N_eff(x,y) ∝ exp(-∫_x^y φ(γ(s)) ds)
```
其中 γ 是 x 到 y 的测地线。

### 1.4 从离散到连续: 尺度极限

在 RG 阻断尺度 L 上考虑 blocked graph G_L。随着 L → ∞ (多次阻断):

1. 阻断图的顶点密度 ρ_L = N_L / V_L
2. 定义 "重整化时空坐标" x^μ = (block position)_μ · a_L, 其中 a_L 是阻断尺度
3. 阻断图 Laplacian 的连续极限:
   ```
   −L_L → a_L² [q(x) ∇² + (∇q(x))·∇] + O(a_L⁴)
   ```

### 1.5 与 Laplace-Beltrami 算符的比较

在连续 Riemann 流形 (M, g) 上，Laplace-Beltrami 算符:
```
Δ_g f = (1/√{g}) ∂_μ(√{g} g^{μν} ∂_ν f)
```

对于共形平坦度规 g_{μν} = Ω²(x) δ_{μν}, 在 d 欧几里得维下:
```
Δ_g f = Ω^{-d} ∂_μ(Ω^{d-2} ∂_μ f)
      = Ω^{-2}[∇² f + (d-2) Ω^{-1} (∂_μ Ω)(∂_μ f)]
```

将图 Laplacian 连续极限与 Δ_g 比较:
```
−a_L² q ∇² f − a_L² (∇q)·∇f = Ω^{-2} ∇² f + (d-2) Ω^{-3} (∇Ω)·∇f
```

逐项匹配给出 **度规- q 对应关系**:

```
Ω^{-2} = a_L² q                                    (1)
(d-2) Ω^{-3} ∇Ω = −a_L² ∇q                         (2)
```

### 1.6 求解共形因子

从 (1): Ω = a_L^{-1} q^{-1/2}

代入 (2):
```
(d-2) a_L³ q^{3/2} · (−½ a_L^{-1} q^{-3/2} ∇q) = −a_L² ∇q
−(d-2)/2 · a_L² ∇q = −a_L² ∇q
(d-2)/2 = 1
d = 4
```

**重要发现**: 两式自洽的条件是 d = 4 ！这意味着时空维度必须为 4 维，才能让图 Laplacian 的连续极限与共形平坦度规的自然几何 Laplacian 一致。

结果:
```
Ω(x) = a_L^{-1} q(x)^{-1/2} = a_L^{-1} exp(φ(x)/2)
```

因此，**空间部分的共形因子**为:
```
γ_{ij}(x) = Ω²(x) δ_{ij} = a_L^{-2} q(x)^{-1} δ_{ij} = a_L^{-2} exp(φ(x)) δ_{ij}
```

### 1.7 含时间分量的完整度规

因果图的有向边编码了因果结构。在连续极限下，类时方向对应图的主因果方向。对于静态球对称情形，自然拟设:

```
ds² = −N(r) c² dt² + A(r) [dr² + r² (dθ² + sin²θ dφ²)]
```

其中:
- N(r) 编码引力时间膨胀 (来自因果图的前向边密度)
- A(r) 编码空间弯曲 (来自谱几何推导)

时间分量来自因果图的"层级数"。在两次事件之间，如果因果路径上的 q 值乘积为 Q = Π q_e:
```
dτ² ∝ Q · (coordinate time interval)²
```

其中 dτ 是固有时。对于径向因果路径，每步的 q 累积给出:
```
dτ² ∝ q(r) · dt²
```

取 q(r) = exp(−GM/rc²):
```
N(r) = C · q(r) = C · exp(−GM/rc²)
```

在 r → ∞ 时 (q → 1): N(∞) = C = 1, 所以:
```
N(r) = exp(−GM/rc²)
```

弱场展开 (GM/rc² ≪ 1):
```
N(r) ≈ 1 − GM/rc² + (GM/rc²)²/2 + ...
g_{00} = −N(r) ≈ −(1 − GM/rc²)
```

这精确给出了牛顿极限 **Δg_{00} = −2Φ/c², 其中 Φ = −GM/r**。但是系数是 −GM/rc² 而不是 −2GM/rc²... 

### 1.8 系数的修正

重新审视: 如果固有时由 q 的平方根给出 (类似 Born 规则):
```
dτ = √q · dt → N(r) = q(r) = exp(−GM/rc²)
```
弱场: g_{00} ≈ −(1 − GM/rc²)

要恢复牛顿极限 g_{00} ≈ −(1 − 2GM/rc²)，需要:
```
N(r) = exp(−2GM/rc²) = q(r)²
```

或等价地:
```
q(r) = exp(−GM/rc²)  →  g_{00} = −q² = −exp(−2GM/rc²)
```

这意味着重力势 Φ 与 q 的关系应为 **q = exp(−Φ/2c²)** 而非 q = exp(−Φ/c²)。

**DGF修正建议**: q(r) = exp(−GM/2rc²) 或在 q 与 g_{00} 之间插入因子2。

## 2. 路径二: 因果集对应 — 离散因果序到连续度规

### 2.1 Myrheim 长度与 q 场

在因果集理论中 (Rideout & Sorkin), 时空体积和固有时由离散数据编码:

**Myrheim 长度**: 两个因果关联事件之间的固有时 τ(u,v) 由它们之间的因果集元素数量 N(u,v) 估计:
```
τ(u,v) = (N(u,v) / ρ)^{1/d}
```
其中 ρ 是基本密度。

**DGF推广**: 每个因果边有权重 q_e。有效因果元素数量为:
```
N_eff(u,v) = Σ_{causal paths u→v} Π_{e∈path} q_e
```

取主导路径 (最短路径, 即最类时的):
```
N_eff(u,v) ≈ Π_{i=1}^{d(u,v)} q_i
```

取对数:
```
ln N_eff(u,v) ≈ Σ_i ln q_i ≈ ∫_{u}^{v} ln q(x(τ)) dτ
```

对于 q(r) = exp(−GM/rc²):
```
ln N_eff ≈ −∫ (GM/rc²) dτ
```

**时空体积对应**: 在 DGF 中, 有效体积元:
```
dV_eff = dV_flat · ⟨q⟩_local^{-1}
```

因为在 q 值低的区域，有效因果连接更稀疏，同样的平直坐标体积对应更少的有效因果元素 → 更大的物理体积。

### 2.2 从因果集到度规的标准构造

因果集理论的标准度规重建:
1. 时空体积信息 → √{−g} (共形因子)

- q 权重的空间分布 → 体积信息 → 共形因子 Ω²

## 3. 路径三: 信息几何 — Fisher度规与Einstein方程

### 3.1 DGF上的概率分布

将 DGF 因果图视为统计系综:

```
P(G; θ) = (1/Z) exp(−S_eff[G; θ])
```

其中 "作用量" S_eff 编码了因果图的统计权重, θ 是参数集 (包括 q 值)。

对于局部区域, 最简模型是指数族分布:
```
p_local(C; q) = exp(q · F(C) − ψ(q))
```
其中 C 是因果配置, F(C) 是充分统计量 (例如, 出度), ψ(q) 是配分函数的对数。

### 3.2 Fisher信息度规

定义参数空间上的 Fisher 度规 (Matsueda 2013, Eq. 5):

```
g_{ab}(θ) = Σ_G P(G; θ) ∂_a ln P(G; θ) ∂_b ln P(G; θ)
```

对于指数族 (Matsueda Eq. 60):
```
g_{ab}(θ) = ∂_a ∂_b ψ(θ)
```

即 Fisher 度规具有 Hessian 结构; ψ(θ) 是 Kähler 势。

### 3.3 参数空间 = 时空的识别

**关键步骤**: 将参数坐标 θ^a 与时空坐标 x^μ 等同。

论证: DGF 中, q = q(x) 随空间位置变化。RG 阻断后, 每个块的平均 q 值 ⟨q⟩_block 是该块位置的函数。因此:
- 参数 θ^μ ↔ 块中心位置 x^μ
- q(x) = exp(−φ(x)) 是参数化的物理输入

取 ψ(q) = ψ(q(x)):
```
g_{μν}(x) = ∂_μ ∂_ν ψ(q(x))
          = ψ''(q) ∂_μ q ∂_ν q + ψ'(q) ∂_μ ∂_ν q
```

### 3.4 q 场的度规显式

对于静态球对称 q(r) = exp(−GM/rc²):

令 φ(r) = −ln q(r) = GM/rc²

```
∂_μ φ = φ'(r) · n_μ,   其中 n_μ = (0, x/r, y/r, z/r)
φ'(r) = −GM/r²c²
∂_μ ∂_ν φ = φ''(r) n_μ n_ν + (φ'(r)/r)(δ_{μν} − n_μ n_ν)
φ''(r) = 2GM/r³c²
```

对于最简单的选择 ψ(q) ∝ −ln q = φ (熵 ∝ φ):
```
g_{μν}(x) = ∂_μ ∂_ν φ(x)
```

但这样得到的度规不满足 Lorentz 符号。需要引入时间分量:
```
ds² = −∂_t ∂_t φ dt² + ∂_i ∂_j φ dx^i dx^j
```

而 φ 不依赖 t, 所以 g_{00} = 0... 这不行。

### 3.5 正确的信息几何构造

参考 Alshal (2023) 的处理: 在信息流形上构造 **pseudo-Riemannian** Fisher度规, 其中:
```
g_{μν} = E[∂_μ ℓ ∂_ν ℓ]
```
ℓ = ln P 是 log-likelihood。符号取决于参数类型 (类时 vs 类空)。

对于 DGF, 自然的选择是:
- 时间参数: τ (RG尺度方向)
- 空间参数: 块位置 x^i

时间分量来自 RG 流方向 (Kim 2026, Eq. 31):
```
G_{ττ} = ⟨∂_τ ln P ∂_τ ln P⟩ > 0  (空间-like, 欧几里得符号)
```

Wick 旋转 τ → it 后得到 Lorentz 符号。

### 3.6 Einstein方程的涌现

Matsueda (2013, Eq. 86) 的核心结果: 从 Fisher 度规构造的 Einstein 张量自动给出:
```
G_{μν} = κ T_{μν}^{(entropy)}
```

其中 T_{μν}^{(entropy)} 由熵密度的梯度构造:
```
T_{μν}^{(entropy)} = ∂_μ S ∂_ν S − ½ g_{μν} g^{αβ} ∂_α S ∂_β S
```

S = ⟨γ⟩ = −⟨ln p⟩ 是 von Neumann 熵。

在 DGF 中, 局部熵密度:
```
s(x) = −k_B Σ_{e∈block(x)} q_e ln q_e
```

对于 q(r) = exp(−GM/rc²):
```
s(r) = −k_B ρ_0 q(r) ln q(r) = k_B ρ_0 (GM/rc²) exp(−GM/rc²)
```

其中 ρ_0 是顶点密度。

**DGF-Einstein 方程**:
```
R_{μν} − ½ R g_{μν} = (8πG/c⁴) T_{μν}^{(matter)} + κ T_{μν}^{(entropy)}
```

其中熵贡献 T_{μν}^{(entropy)} 在弱场极限下约化为暗能量项。这是 DGF 的独特预测。

## 4. 路径四: RG流与Ricci流对应

### 4.1 Kim (2026) 的核心方程

Kim 证明了 Polchinski 精确 RG 方程 ⇒ Fokker-Planck 方程 ⇒ Fisher 度规演化:
```
d/d(ln Λ) G_{ab} = −2R_{ab} + 2∇_a ∇_b Φ
```
(Eq. 34 of Kim 2026)

其中:
- G_{ab} 是耦合常数空间上的 Fisher 信息度规
- R_{ab} 是此空间的 Ricci 曲率
- Φ 是信息势 (information potential)
- Λ 是 RG 截断尺度

### 4.2 应用于 DGF 阻断

DGF 的 RG 阻断: ln q_eff = ⟨ln q⟩_block

在每一阻断步:
1. 微观 q 值被平均化
2. 图拓扑被粗粒化 (边被重连)
3. 信息度规 G_{ab} 随尺度演化

利用 Kim 的等式, DGF 阻断下的度规演化:
```
∂_L g_{μν}(x; L) = −2R_{μν}(x; L) + 2∇_μ ∇_ν Φ(x; L)
```

其中 L = ln(Λ_0/Λ) 是 RG "时间"。

### 4.3 IR 固定点与 Einstein 方程

在红外固定点 (L → ∞):
```
∂_L g_{μν} → 0  ⇒  R_{μν} − ∇_μ ∇_ν Φ = 0
```

这是 **Ricci 孤立子** (Ricci soliton) 条件:
```
R_{μν} − ∇_μ ∇_ν Φ = 0
```

在没有任何物质的情况下, 这给出真空 Einstein 方程加上一个标量自由度:
```
R_{μν} = ∇_μ ∇_ν Φ
```

取迹: R = □ Φ

因此:
```
G_{μν} = R_{μν} − ½ R g_{μν} = ∇_μ ∇_ν Φ − ½ □ Φ g_{μν}
```

这精确是共形标量场 Φ 的能量-动量张量形式!

### 4.4 Φ 与 q 的关系

信息势 Φ 与 DGF 的 q 场的关系由信息几何给出:
```
Φ(x) ∝ −ln q(x) ≡ φ(x)
```

因为 Φ 出现在 Kim 的框架中作为"吸收坐标伪影的 gauge-fixing 势", 而 q 场在 DGF 中决定因果连通度。

因此:
```
Φ(x) = α · φ(x) = −α ln q(x) = α · GM/rc² (球对称情形)
```

其中 α 是无量纲常数, 由微观理论确定。

对于球对称真空:
```
G_{μν} = α [∇_μ ∇_ν φ − ½ □ φ g_{μν}]
```

这给出了由 q 场的梯度驱动的有效引力动力学。

## 5. 综合: DGF 有效度规公式

### 5.1 汇总四种路径

| 路径 | 核心机制 | 度规来源 | 适用范围 |
|------|---------|---------|---------|
| 谱几何 | L → Δ_g | g_{μν} 由 Laplacian 连续极限确定 | 全局几何 |
| 因果集 | 因果序 + 体积 | 共形类 + 共形因子 | 因果结构 |
| 信息几何 | Fisher 度规 | g_{μν} = ∂_μ ∂_ν ψ(q) | 度规动力学 |
| RG/Ricci流 | FRG ⇒ Ricci flow | ∂_L g_{μν} = −2R_{μν} + ... | 尺度演化 |

### 5.2 主定理 (综合结果)

**定理**: 给定 DGF 因果图 G = (V,E) 带 q 场 q(x) = exp(−φ(x)), 在 RG 阻断尺度 L → ∞ 的连续极限下, 涌现的有效时空度规为:

```
g_{μν}(x) = Ω²(x) · η_{μν} + δg_{μν}[φ]
```

其中:

**共形因子** (来自谱几何, 式(1)):
```
Ω²(x) = a_0² · q(x)^{-1} = a_0² · exp(φ(x))
```

**一阶修正** (来自信息几何):
```
δg_{00} = −α₁ φ + O(φ²)
δg_{ij} = α₂ φ δ_{ij} + α₃ ∂_i ∂_j φ/□ + O(φ²)
```

参数 a_0 (基本尺度), α₁, α₂, α₃ 由微观理论确定。

**弱场极限** (φ ≪ 1):
```
ds² = −(1 − 2α₁ φ) c² dt² + (1 + 2α₂ φ) δ_{ij} dx^i dx^j + O(φ²)
```

### 5.3 与标准 GR 的校准

标准 GR 弱场极限 (各向同性坐标):
```
ds²_GR = −(1 − 2GM/rc²) c² dt² + (1 + 2GM/rc²) δ_{ij} dx^i dx^j + O((GM/rc²)²)
```

其中 φ = GM/rc²。

为使 DGF 弱场极限匹配 GR, 需要:
```
2α₁ φ = 2φ    ⇒  α₁ = 1
2α₂ φ = 2φ    ⇒  α₂ = 1
```

因此:
```
g_{00}(x) = −exp(−2α₁ φ(x)) ≈ −(1 − 2φ(x))
g_{ij}(x) = exp(2α₂ φ(x)) δ_{ij} ≈ (1 + 2φ(x)) δ_{ij}
```

**完全非线性形式** (来自共形因子匹配):
```
ds² = −exp(−2φ) c² dt² + exp(2φ) [dr² + r² dΩ²]
```

其中 φ(r) = GM/rc²。

这就是 **DGF-Schwarzschild 度规**。展开:
```
g_{00} = −(1 − 2φ + 2φ² − 4φ³/3 + ...)
```

与标准 Schwarzschild (在 Schwarzschild 坐标下):
```
g_{00}^GR = −(1 − 2φ)
```
区别在二阶项 2φ² = 2(GM/rc²)²。

与各向同性 Schwarzschild:
```
g_{00}^{iso} = −(1 − φ/2)²/(1 + φ/2)² = −(1 − 2φ + 2φ² − 3φ³/2 + ...)
```
DGF 和 GR 在各向同性坐标下在二阶都给出 2φ², 一致到二阶！

### 5.4 最终公式

**DGF 有效度规 (球对称真空)**:
```
ds² = −q(r)² c² dt² + q(r)^{−2} [dr² + r² (dθ² + sin²θ dφ²)]

其中 q(r) = exp(−GM/rc²)
```

即:
```
g_{μν}^{DGF}(r) = diag(−q², q^{−2}, q^{−2} r², q^{−2} r² sin²θ)
```

**一般形式** (任意 q 场):
```
g_{μν}^{DGF}(x) = Ω²(x) η_{μν}

Ω²(x) = q(x)^{−1} = exp(φ(x))

g_{00} = −Ω²(x),   g_{ij} = Ω²(x) δ_{ij}
```

在 φ = 0 (q = 1) 时恢复 Minkowski: g_{μν} = η_{μν}。

## 6. DGF度规的物理检验

### 6.1 牛顿极限

弱场展开 g_{00} = −(1 − 2φ + ...) = −(1 − 2GM/rc² + ...)
→ 重力加速度 a = −∇Φ = −GM/r² ✓

### 6.2 光偏折

对各向同性度规 ds² = −B(r)c²dt² + A(r)(dr² + r²dΩ²):
```
光偏折角 Δθ = (4GM/bc²) · [B(r)A(r)]^{1/2} 积分修正
```

DGF: B = q², A = q^{−2} ⇒ (BA)^{1/2} = 1

### 6.4 黑洞与视界

DGF 视界条件: q(r) → 0 即 exp(−GM/rc²) → 0, 这发生在 r → 0 (必须 r > 0 时取极限)。对于宏观质量, GM/c² 很大, q(r) 在 r ∼ GM/c² 附近指数衰减。视界的精确定义需要解完整的 DGF-Einstein 方程 (包含熵源项)。
