## Step 1: q场定义与方程

**定义 (q场):** q(x) ∈ [0,1] 是时空格点x处的纯度（purity），q(x) = Tr[ρ_x²]。

- q=1: 纯量子真空（格点处于叠加态，未退相干）
- q→0: 经典极限（格点已坍缩到确定态，无剩余量子不确定性）

**q场方程 (来自DGF q场动力学，LP39):**

在准静态、弱场极限下，q场满足：
```
∇²q = λ · T_00 / c²
```

其中 T_00 是能量密度，λ 是DGF耦合常数（待标定）。

对于球对称静态质量M的外部真空解：
```
q(r) = q_vac - η · GM/rc²
```

其中 η = λ/(4πc²) 是无量纲耦合参数，q_vac 是宇宙学真空q值。

> **注意:** 这是现象学ansatz。q场的完整动力学方程需要墙#3(RG流)的突破。这里我们假设Poisson形式作为弱场有效描述，只声称其现象学有效性。

在太阳系中，q_vac的值是未知参数。我们通过要求DGF在弱场极限下重现GR来反向约束。

## Step 2: q场→有效Cartan参数

DGF因果环的Cartan旋转角 c 控制Q↔E耦合强度。在q场中，格点纯度降低→布洛赫矢量长度缩短→有效旋转角减小。

**布洛赫矢量映射:** 对2维格点（qubit），布洛赫矢量长度
```
|r| = √(2q - 1)  (for q > 1/2)
```
当q ≤ 1/2时，|r| = 0（完全退相干，无相干旋转）。

因此有效Cartan参数：
```
c_eff(q) = c₀ · √(2q - 1)_+
```
其中 (x)_+ = max(x, 0)，c₀是q=1时的参考Cartan参数。

> **已知限定:** 此映射依赖Cartan轴对齐假设（所有边共享相同n̂方向）。在一般非对齐情况下，c_eff可能具有更复杂的张量结构。当前推导限于对齐情况。

---

## Step 3: Cartan参数→局域退相干率

从Wall #9，单qubit局域退相干（端点qubit）：
```
D_local = 1 - cos²(2c_eff)
```

小c展开：D_local ≈ 4c_eff² = 4c₀² · (2q-1)_+

**退相干率 (per lattice site):**
```
γ_dec(q) = Γ₀ · D_local(q) = 4Γ₀c₀² · (2q-1)_+
```
其中 Γ₀ 是基础环速率（≈ t_P⁻¹ ≈ 1.855×10⁴³ Hz 微观标度）。

对于宏观时钟（N_sites个格点）：
```
Γ_dec(x) = N_sites · γ_dec(q(x))
```

---

## Step 4: 退相干率→Proper Time

从S0的概念桥接：dτ_DGF = α · dN_events = α · Γ_dec · dt

选择参考点（平直时空，q=q_vac）校准：α = 1/Γ_dec(q_vac)。

```
dτ_DGF/dt = Γ_dec(q) / Γ_dec(q_vac) = γ_dec(q) / γ_dec(q_vac)
```

代入γ_dec：
```
dτ_DGF/dt = (2q - 1)_+ / (2q_vac - 1)_+
```

---

## Step 5: 弱场极限→对标GR

**关键推导:** 太阳系弱场极限下，q_vac → 1，δq = q_vac - q ≪ 1。

```
dτ_DGF/dt = (2(q_vac - δq) - 1) / (2q_vac - 1)
          = (2q_vac - 1 - 2δq) / (2q_vac - 1)
          = 1 - 2δq/(2q_vac - 1)
```

代入q场Poisson解 δq = η · GM/rc²：
```
dτ_DGF/dt = 1 - (2η/(2q_vac-1)) · GM/rc²
```

**对标GR弱场极限:**
```
dτ_GR/dt = √(1 - 2GM/rc²) ≈ 1 - GM/rc²
```

**匹配条件 (DGF重现太阳系GR):**
```
2η/(2q_vac - 1) = 1  →  η = (2q_vac - 1)/2
```

当 q_vac → 1: η → 1/2。此时 q(r) = 1 - (1/2)·GM/rc²。

**物理含义:** 在q_vac→1极限下，DGF通过q场Poisson方程+退相干时间映射，自动产生与GR弱场极限一致的时间膨胀效应。DGF不"替代"GR——而是为GR的时间膨胀提供了信息论微观机制。

---

## Step 6: DGF ≠ GR的参数空间

GR等效对应仅在 q ≈ q_vac（近真空）时成立。当 q 显著偏离 q_vac 时：

### 6a: 强场修正

当 δq 不小（GM/rc² ~ O(1)，如中子星表面）：
```
dτ_DGF/dt = 1 - 2δq/(2q_vac-1) = 1 - η⁻¹·δq
```
而 δq = η · GM/rc²。此关系在强场中可能偏离GR的 √(1-2GM/rc²)，因为：
- q场可能有非线性项（当前Poisson ansatz不含非线性）
- (2q-1)_+ 的截断在 q<1/2 时使 dτ→0（时间冻结）

**预言:** 存在临界半径 r_crit 使 q(r_crit) = 1/2 → dτ=0 → 时间冻结面。用η=1/2：
```
1 - GM/2r_crit c² = 1/2 → r_crit = GM/c² = r_s/2
```
即黑洞Schwarzschild半径的一半处，DGF预言时间冻结。这比GR的事件视界（r_s）靠内，但定性上类似。

### 6b: 多体非线性叠加

q场的Poisson方程是线性近似。若T_00是分布的，GR中Φ满足线性叠加，而q场可能有非线性修正（不可线性叠加的"因果拥挤"效应）：
```
q(x) ≠ q_vac - η ∫ (G T_00(y)/|x-y|) d³y  （一般情况）
```

非线性在质量集中区域（星系核心、双星系统）最显著。这是DGF区别于GR的关键检验通道。

### 6c: 时变q场

若q(x,t)随时间变化（如双星并合、超新星坍缩），dτ/dt也随时间变化。这可能产生可检测的计时残差（timing residual）。

**预言:** 时变q场产生的计时残差，对双星系统：Δτ_DGF - Δτ_GR ∼ O(Ṁ/M · τ_obs)，在极端质量比并合中可能达~μs级。

## 核心公式 (总结)

```
┌─────────────────────────────────────────────────────┐
│ DGF Proper Time 公式 (弱场，近真空极限):             │
│                                                       │
│   dτ_DGF/dt = (2q(x) - 1)_+ / (2q_vac - 1)_+        │
│                                                       │
│   其中 q(x) 满足 ∇²q = λ·T_00/c²                     │
│   λ = 4πG/c⁴ · (2q_vac-1) （对标GR约束）            │
│                                                       │
│   q_vac → 1 时: dτ_DGF/dt → 1 - 2GM/rc²              │
│   （偏离GR的 √(1-2GM/rc²) 在弱场中为O(Φ²/c⁴)级）     │
└─────────────────────────────────────────────────────┘
```

## 可观察量

### O1: 弱场时间膨胀偏差

DGF和GR在弱场中的差异：
```
Δ(dτ)/dτ ≡ (dτ_DGF - dτ_GR) / dτ_GR
           ≈ (1 - 2GM/rc²) - √(1 - 2GM/rc²)
           ≈ -(GM/rc²)² / 2    (leading order)
```

在地球表面 (GM/rc² ≈ 7×10⁻¹⁰):
Δ(dτ)/dτ ≈ -2.5×10⁻¹⁹ — **不可检测**（当前最佳光学钟精度~10⁻¹⁸）

在太阳表面 (GM/rc² ≈ 2×10⁻⁶):

## 诚实标注

1. **q场方程是ansatz.** Poisson形式来自GR类比，非DGF第一原理推导。墙#3(RG流)完成后才能给出q场的真实有效作用量。
2. **(2q-1)_+截断是模型依赖的.** 布洛赫矢量映射假设qubit格点。d>2时推广未证明（墙#4）。
3. **c_eff(q)映射依赖Cartan轴对齐.** 非对齐情况未探索（01-established-results.md 已知限定）。
4. **这些限定不影响核心结论:** DGF在弱场极限下可以通过合适的参数选择重现GR。DGF的新物理在q远离q_vac时出现。
