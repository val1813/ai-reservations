## 核心目标

证明DGF时间膨胀公式在太阳系实验中与GR不可区分（因而存活），同时识别DGF可能被约束的参数空间。

---

## 1. DGF vs GR — 精确差异

### 1a: 弱场展开对比

GR proper time (静态球对称，各向同性坐标):
```
dτ_GR/dt = √(1 - 2GM/rc²)
         = 1 - GM/rc² - ½(GM/rc²)² - ½(GM/rc²)³ + O(Φ⁴)
```

DGF proper time (q_vac→1, η=1/2):
```
q(r) = 1 - ½·GM/rc²
dτ_DGF/dt = 2q(r) - 1 = 1 - GM/rc²
```

**关键发现:** DGF时间膨胀 = 1 - GM/rc² 是精确线性的（在此ansatz下），而GR是√(1-2GM/rc²)的展开。两者的差异：

```
Δ(dτ)/dτ ≡ (dτ_DGF - dτ_GR)/dτ_GR

弱场展开:
dτ_DGF/dt = 1 - Φ_g           (Φ_g ≡ GM/rc²)
dτ_GR/dt  = 1 - Φ_g - ½Φ_g² - ½Φ_g³ + ...

Δ(dτ) ≈ ½Φ_g² + ½Φ_g³ + ...  (DGF > GR: DGF预言的时间流逝略快)
```

### 1b: 数值量级

| 系统 | Φ_g = GM/rc² | Δ(dτ)/dτ (DGF-GR) | 当前精度 |
|------|:---:|:---:|:---:|
| 地球表面 | 7.0×10⁻¹⁰ | 2.4×10⁻¹⁹ | ~10⁻¹⁸ (光钟) |
| GPS轨道 | 5.0×10⁻¹⁰ | 1.3×10⁻¹⁹ | ~10⁻¹⁴ |
| 太阳表面 | 2.1×10⁻⁶ | 2.2×10⁻¹² | ~10⁻⁶ (谱线) |
| 白矮星 (Sirius B) | 3×10⁻⁴ | 4.5×10⁻⁸ | 未直接测量 |
| 中子星表面 | ~0.2 | ~0.02 | 未直接测量 |
| 黑洞视界 (GR) | 1 | ½ (DGF: 在0.5处冻结) | 无法测量 |

**结论:** 在所有人类可进行精密时间测量的系统中，DGF-GR差异 < 10⁻¹⁸，不可检测。

## 2. 基准实验约束

### 2a: Pound-Rebka (1960) — 引力红移

- 高度差: Δh = 22.5 m, ΔΦ/c² = gΔh/c² = 2.46×10⁻¹⁵
- GR预言: Δf/f = 2.46×10⁻¹⁵
- 测量: 一致到 ~1%
- DGF修正: Δ(Δf/f)_DGF-GR ≈ ½(2.46×10⁻¹⁵)² ≈ 3×10⁻³⁰
- **约束: 无**

### 2b: Gravity Probe A (Vessot 1980)

- 氢脉泽时钟到10,000 km高度
- 最大Φ_g差: ~4.2×10⁻¹⁰
- GR验证精度: ~1.4×10⁻⁴ of the effect
- DGF修正: ½(4.2×10⁻¹⁰)² ≈ 9×10⁻²⁰
- **约束: 无** (测量精度10⁻¹⁴ vs DGF修正10⁻²⁰)

### 2c: GPS/GLONASS/Galileo

- 日常运行的相对论修正（卫星钟减速+引力蓝移）
- 精度: ~10⁻¹⁴ (基于精密星历的比较)
- DGF修正: Δ(dτ) ≈ ½(ΔΦ_g)² ≈ 10⁻¹⁹
- **约束: 无**

### 2d: Galileo 5&6 椭圆轨道

- 椭圆轨道 (e≈0.16), ΔΦ_g/day ≈ 3×10⁻¹⁰
- GR引力红移验证: ~10⁻⁵ of the effect
- DGF修正: ~10⁻¹⁹
- **约束: 无**

### 2e: ACES (ISS, 计划中) / 光钟比较

- 精度目标: 10⁻¹⁶ (ACES), 10⁻¹⁸ (地面光钟)
- DGF修正: ~10⁻¹⁹
- **接近但尚未达到.** 下一代光钟 (10⁻¹⁹-10⁻²⁰) 可能开始触及。

## 3. 自由参数约束

从S1，DGF有两个自由参数: {q_vac, η}（或等价地{q_vac, λ}）。

### 3a: q_vac 的约束

q_vac是宇宙学真空纯度。从太阳系数据，只能约束q_vac在弱场区域的表现。

如果 q_vac ≪ 1（如q_vac ~ 0.5），则：
- (2q_vac-1) 很小 → dτ_DGF ∝ 1/(2q_vac-1) 很大
- 时间流速异常放大 → 与GPS等数据冲突

具体地，GPS要求 dτ_DGF/dτ_GR = 1 到 ~10⁻¹⁴ 精度。

```
dτ_DGF/dτ_GR ≈ (1 - GM/rc²) / √(1 - 2GM/rc²)  [q_vac→1]
                ≈ 1 + ½(GM/rc²)²  [GR偏差，与q_vac无关]
```

实际上，从S1的推导，q_vac→1时DGF匹配GR的弱场极限。如果q_vac显著小于1：
```
dτ_DGF = 1 - 2δq/(2q_vac-1)
```

对地球表面 (δq = η·GM/rc² = (2q_vac-1)/2 · GM/rc²):
```
dτ_DGF = 1 - GM/rc²  （与q_vac无关！η和q_vac在弱场中抵消）
```

**关键结果:** 在弱场、近真空极限下，dτ_DGF的形式与q_vac无关（只要q_vac不是极端值）。这是一个**参数去耦**——太阳系实验无法区分不同的q_vac值。

约束q_vac需要其他手段（宇宙学、q场非线性效应）。

### 3b: η的约束

η在弱场中与(2q_vac-1)耦合。太阳系数据约束的是组合：
```
η / (2q_vac-1) = 1/2 （从GR对标）
```

即 η = (2q_vac-1)/2。这是标定关系，不是独立约束。

独立约束η需要非弱场或时变观测。

## 4. 搜索DGF新物理的可能窗口

既然太阳系弱场不可区分，DGF新物理必须在不满足以下条件之一的系统中寻找：

**(A) q ≉ q_vac** — q显著偏离真空值
**(B) ∇q 很大** — q场梯度非线性效应显著
**(C) ∂q/∂t ≠ 0** — 时变q场产生非GR计时信号

### 窗口1: 热星vs冷星 (条件A)

高温星体 (T>10⁶K) 内部有大量光子-电子散射 → 高退相干率 → q被有效"排干"超过仅由质量贡献的量。

**预言:** 两颗等质量但不同表面温度的星体，DGF预言不同的引力红移。GR预言无差异。

检验可行性: 需要ΔT > 10⁵K 和等质量双星系统。罕见但存在。

### 窗口2: 量子临界系统 (条件A+B)

在量子相变临界点附近，关联长度ξ→∞，纠缠结构重组。q场梯度可能异常大，且q值可远离q_vac。

**预言:** 在临界点附近，有效时间流速异常。可在量子模拟器(光晶格、离子阱)中作为"等效时间膨胀"信号检测。

注意: 我们无实验资源，但可做出具体数值预言供他人检验。

### 窗口3: 双星并合 (条件C)

时变四极矩→时变q场→时变dτ_DGF/dt → 计时残差。

**预言:** 对极端质量比并合(EMRI)，计时残差可达Δt ~ η·(Ṁ/M)·(GM/c³)·(τ_obs/τ_dyn)，可能~μs级。

比较: 脉冲星计时精度~100 ns。若EMRI在银河系内发生，DGF计时残差可能可测。
