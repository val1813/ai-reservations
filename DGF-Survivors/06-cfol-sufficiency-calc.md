## §0 精确问题设定

**因果环:** Q_a → E₁ → Q_b → E₂ → Q_a, d=2 (qubits)

**Cartan对齐后:** 所有边酉共享同一Pauli方向 n̂。边i的Cartan参数 c_i = |c^(i)| ∈ ℝ（标量，因为方向相同）。

**环境态:** |γ⟩ = √p |+_n̂⟩ + √(1-p) e^{iφ} |-_n̂⟩（在σ_n̂本征基下）

不失一般性，取φ=0（全局相位可吸收），记：
α_+ = √p, α_- = √(1-p)

**酉演化:** U = Π_i u_i，其中 u_i = exp(i c_i σ_n̂⊗σ_n̂)（嵌入到4-qubit空间）

**QCMI:** I(R;E'|Q') 在输出态 ρ_{RE'Q'} 上。

**目标:** 找出所有 (c₁,c₂,c₃,c₄,p) 使 QCMI=0。

## §1 Kraus算子的显式形式

Cartan对齐后，4-qubit空间上的总生成元为：
$$H_{\text{tot}} = c_1 \sigma^{(1)}\sigma^{(2)} + c_2 \sigma^{(2)}\sigma^{(3)} + c_3 \sigma^{(3)}\sigma^{(4)} + c_4 \sigma^{(4)}\sigma^{(1)}$$

其中σ = σ_n̂为单一Pauli算符，上标表示qubit编号（1=Q_a, 2=E₁, 3=Q_b, 4=E₂）。

在σ_n̂本征基 |s₁s₂s₃s₄⟩（s_j = ±1）下，H_tot对角：
$$\lambda_{s_1 s_2 s_3 s_4} = c_1 s_1 s_2 + c_2 s_2 s_3 + c_3 s_3 s_4 + c_4 s_4 s_1$$

Kraus算子 K_{s₂,s₄} 作用在 Q_a⊗Q_b (qubits 1,3) 上，由环境投影得到：
$$K_{s_2,s_4} = \langle s_2|_{E_1} \langle s_4|_{E_2} \; U \; |\gamma\rangle_{E_1} |\gamma\rangle_{E_2}$$

因U在|s₁s₂s₃s₄⟩基下对角：
$$K_{s_2,s_4}[s_1,s_3] = \alpha_{s_2}\alpha_{s_4} \cdot \exp\!\big(i\lambda_{s_1 s_2 s_3 s_4}\big)$$

其中K_{s₂,s₄}[s₁,s₃] = ⟨s₁s₃|K_{s₂,s₄}|s₁s₃⟩（对角矩阵）。

## §2 Kraus算子的参数化

展开λ，整理K_{s₂,s₄}在|s₁s₃⟩基下的对角元：

### K_{++} (s₂=+1, s₄=+1)
$$\lambda = c_1 s_1 + c_2 s_3 + c_3 s_3 + c_4 s_1 = (c_1+c_4)s_1 + (c_2+c_3)s_3$$

| s₁,s₃ | K_{++}[s₁,s₃] |
|--------|---------------|
| +,+ | p · exp(i(c₁+c₂+c₃+c₄)) |
| +,- | p · exp(i(c₁-c₂-c₃+c₄)) |
| -,+ | p · exp(i(-c₁+c₂+c₃-c₄)) |
| -,- | p · exp(i(-c₁-c₂-c₃-c₄)) |

### K_{+-} (s₂=+1, s₄=-1)
$$\lambda = c_1 s_1 + c_2 s_3 - c_3 s_3 - c_4 s_1 = (c_1-c_4)s_1 + (c_2-c_3)s_3$$

| s₁,s₃ | K_{+-}[s₁,s₃] |
|--------|---------------|
| +,+ | √(p(1-p)) · exp(i(c₁+c₂-c₃-c₄)) |
| +,- | √(p(1-p)) · exp(i(c₁-c₂+c₃-c₄)) |
| -,+ | √(p(1-p)) · exp(i(-c₁+c₂-c₃+c₄)) |
| -,- | √(p(1-p)) · exp(i(-c₁-c₂+c₃+c₄)) |

### K_{-+} (s₂=-1, s₄=+1)
$$\lambda = -c_1 s_1 - c_2 s_3 + c_3 s_3 + c_4 s_1 = (-c_1+c_4)s_1 + (-c_2+c_3)s_3$$

| s₁,s₃ | K_{-+}[s₁,s₃] |
|--------|---------------|
| +,+ | √(p(1-p)) · exp(i(-c₁-c₂+c₃+c₄)) |
| +,- | √(p(1-p)) · exp(i(-c₁+c₂-c₃+c₄)) |
| -,+ | √(p(1-p)) · exp(i(c₁-c₂+c₃-c₄)) |
| -,- | √(p(1-p)) · exp(i(c₁+c₂-c₃-c₄)) |

### K_{--} (s₂=-1, s₄=-1)
$$\lambda = -c_1 s_1 - c_2 s_3 - c_3 s_3 - c_4 s_1 = -(c_1+c_4)s_1 - (c_2+c_3)s_3$$

| s₁,s₃ | K_{--}[s₁,s₃] |
|--------|---------------|
| +,+ | (1-p) · exp(i(-c₁-c₂-c₃-c₄)) |
| +,- | (1-p) · exp(i(-c₁+c₂+c₃-c₄)) |
| -,+ | (1-p) · exp(i(c₁-c₂-c₃+c₄)) |
| -,- | (1-p) · exp(i(c₁+c₂+c₃+c₄)) |

## §3 相位结构的简约化

定义四个独立相位组合：

$$\boxed{\begin{aligned}
A &= c_1 + c_2 + c_3 + c_4 \\
B &= c_1 + c_2 - c_3 - c_4 \\
C &= c_1 - c_2 + c_3 - c_4 \\
D &= c_1 - c_2 - c_3 + c_4
\end{aligned}}$$

注意 A+B = 2(c₁+c₂), A-B = 2(c₃+c₄), C+D = 2(c₁-c₂) 等等。

Kraus算子的紧凑形式：

$$\boxed{\begin{aligned}
K_{++} &= p \cdot \operatorname{diag}(e^{iA},\; e^{iD},\; e^{-iD},\; e^{-iA}) \\
K_{+-} &= \sqrt{p(1-p)} \cdot \operatorname{diag}(e^{iB},\; e^{iC},\; e^{-iC},\; e^{-iB}) \\
K_{-+} &= \sqrt{p(1-p)} \cdot \operatorname{diag}(e^{-iB},\; e^{-iC},\; e^{iC},\; e^{iB}) \\
K_{--} &= (1-p) \cdot \operatorname{diag}(e^{-iA},\; e^{-iD},\; e^{iD},\; e^{iA})
\end{aligned}}$$

对角线顺序为 (++, +-, -+, --)。

## §4 严格充要条件证明（审计修正版）

### 4.1 简化：S(EQ)=S(Q)=2 恒成立

**引理 4.1:** 对任意 (c₁,c₂,c₃,c₄,p)，S(ρ_{E'Q'}) = S(ρ_{Q'}) = log₂4 = 2 bits。

**证明:** |Ψ⟩ = (1/2) Σ_s |s⟩_R ⊗ |φ(s)⟩_E' ⊗ |s⟩_Q。因信道保迹，⟨φ(s)|φ(s)⟩ = 1 ∀s。ρ_{Q'} = I/4 → S=2。ρ_{E'Q'} = (1/4) Σ_s |φ(s)⟩⟨φ(s)| ⊗ |s⟩⟨s| — 每个 Q'-块贡献一个特征值 1/4 → S=2。∎

**推论:** QCMI = S(ρ_{RQ'}) + 2 - 2 - 0 = **S(ρ_{RQ'})**。

### 4.2 Gram 矩阵表示

ρ_{RQ'} 限制在相关子空间 {|s,s⟩_{RQ'}} 上的矩阵表示为 **G/4**，其中：
$$G_{s,t} = \langle\phi(s)|\phi(t)\rangle = \sum_{s_2,s_4} p_{s_2}p_{s_4}\; e^{i[\lambda(t,s_2,s_4) - \lambda(s,s_2,s_4)]}$$

且 G_{s,s} = 1 ∀s。

**QCMI=0 ⇔ ρ_{RQ'} 纯态 ⇔ G 的秩=1。**

### 4.3 必要性 (⇒): QCMI=0 ⇒ c_j ∈ (π/2)ℤ

若 QCMI=0，G 秩=1。G_{s,s}=1 ⇒ 所有 2×2 主子式为零 ⇒ |G_{s,t}| = 1 ∀s≠t。

G_{s,t} 是 exp(iΔλ) 的凸组合。|凸组合|=1 ⇒ 所有组合项的相位相等 (mod 2π)。

**关键计算:**
$$\Delta\lambda(s_2,s_4) = \lambda(t,s_2,s_4) - \lambda(s,s_2,s_4) = (t_1-s_1)(c_1s_2 + c_4s_4) + (t_3-s_3)(c_2s_2 + c_3s_4)$$

取 s=(+,+), t=(+,-): (t₁-s₁, t₃-s₃) = (0, -2)
$$\Delta\lambda = -2c_2 s_2 - 2c_3 s_4$$

对四种 (s₂,s₄) 组合，相位必须全部相等 (mod 2π):
$$e^{-2ic_2(+1)-2ic_3(+1)} = e^{-2ic_2(+1)-2ic_3(-1)} = e^{-2ic_2(-1)-2ic_3(+1)} = e^{-2ic_2(-1)-2ic_3(-1)}$$

第一个与第二个: e^{-4ic₃} = 1 ⇒ **c₃ ∈ (π/2)ℤ**。
第一个与第三个: e^{-4ic₂} = 1 ⇒ **c₂ ∈ (π/2)ℤ**。

取 s=(+,+), t=(-,+): (t₁-s₁, t₃-s₃) = (-2, 0)
$$\Delta\lambda = -2c_1 s_2 - 2c_4 s_4$$

同理得: **c₁ ∈ (π/2)ℤ**, **c₄ ∈ (π/2)ℤ**。

取 s=(+,+), t=(-,-) 给出 c₁+c₂ ∈ (π/2)ℤ 和 c₃+c₄ ∈ (π/2)ℤ，自动满足。

**必要性得证。** ∎

### 4.4 充分性 (⇐): c_j ∈ (π/2)ℤ ⇒ QCMI=0

设 c_j = n_j·π/2, n_j ∈ ℤ。对 s=(+,+), t=(+,-):
$$\Delta\lambda = -2c_2 s_2 - 2c_3 s_4 = -n_2\pi s_2 - n_3\pi s_4$$

$$e^{i\Delta\lambda} = e^{-in_2\pi s_2} \cdot e^{-in_3\pi s_4}$$

因 s₂,s₄ ∈ {±1}: e^{±in₂π} = (-1)^{n₂} = e^{∓in₂π}。**与 s₂ 符号无关!**
同理 e^{±in₃π} = (-1)^{n₃}。

∴ e^{iΔλ} = (-1)^{n₂+n₃}，对**所有四种** (s₂,s₄) 完全相同。

故所有 G_{s,t} 的相位在凸组合中一致，|G_{s,t}|=1 ∀s≠t。

由此 G 的秩=1。实际上:
$$G_{s,t} = \exp\!\big(i(\phi_s - \phi_t)\big)$$
对所有 s≠t，其中 φ_s 是与 s 无关的全局相因子（取决于所选的 s,t 对）。

G 秩=1 ⇒ ρ_{RQ'} 纯态 ⇒ QCMI=0。**p ∈ (0,1)**（因为因子 p_{s₂}p_{s₄} 的权重在 |G_{s,t}|=1 的条件下不影响结果 — 凸组合中所有相位相等，无论权重如何，幅值恒为 1。p=0,1时QCMI=0对所有cⱼ成立（单Kraus算子→酉信道），充要条件的必要性方向仅适用于开区间）。

**充分性得证。** ∎

### 4.5 注记：为什么不是 Kraus 秩=1

对一般 c_j ∈ (π/2)ℤ（不全部一致），Kraus 算子的秩可能为 2（如 (π/2,0,π/2,0) 例）。但两个 Kraus 算子的差异因子为 ±1，在信道组合中平方消去 → 信道等价于酉信道 → QCMI=0。正确的充要条件是 **Gram 矩阵秩=1**，它比 Kraus 秩=1 更一般。

## §6 完整解

**CFOL 充分性的充要条件：**

$$ \boxed{\text{QCMI} = 0 \iff c_j \in \tfrac{\pi}{2}\mathbb{Z} \quad \forall j \in \{1,2,3,4\}} $$

**p ∈ (0,1)。** p=0,1时QCMI=0对所有cⱼ成立（单Kraus算子→酉信道），充要条件的必要性方向仅适用于开区间。p的取值不影响QCMI=0的条件——它只影响非零点上的QCMI数值，不影响哪些c_j组合给出QCMI=0。

**等价表述：**
- 每个边酉的Cartan参数必须是 π/2 的整数倍
- c_j = n_j · π/2, n_j ∈ ℤ
- 边酉 u_j = exp(i c_j σ_n̂⊗σ_n̂) 是 Clifford 门 (up to global phase)

**物理图景：** QCMI=0 ⇔ 因果环上的每个边酉是**离散的Clifford操作**（旋转角为0, π/2, π, 3π/2...）。连续旋转（c_j ∉ (π/2)ℤ）必然产生非零QCMI——因果拓扑强制在输出态中留下量子非马尔可夫性的签名。
