## INSPECTOR

### I-1: Gram 矩阵因子化公式是否精确？

**公式:** G_{a,b} = e^{iΔφ^{SS}} · Π_{q∈E} [p·e^{iC_q} + (1-p)·e^{-iC_q}]

**推导链:**
1. G_{a,b} = Σ_k Π_q p_{k_q} · exp(i[φ(b,k)-φ(a,k)]) — 定义
2. φ = Σ_{SS} + Σ_{SE}（EE 项因只依赖 k 而消去）
3. Σ_{SE} = Σ_{q∈E} s_q(k) · C_q(a,b)（每个环境 qubit 贡献独立）
4. Σ_k Π_q p_{k_q} exp(i s_q C_q) = Π_q Σ_{s_q} p_{s_q} exp(i s_q C_q) — **精确因子化**，k_q 独立
5. Σ_{s_q} p_{s_q} exp(i s_q C_q) = p·e^{iC_q} + (1-p)·e^{-iC_q}

**裁决:** ✅ 精确。不涉及任何近似。因子化成立因为环境 qubit 在初始态 |γ⟩^{⊗|E|} 中相互独立。

### I-2: S(EQ)=S(Q)=log(d_s) 在 b1>1 下是否成立？

**检查:**

输出态: |Ψ⟩ = (1/√d_s) Σ_a |a⟩_R ⊗ |φ(a)⟩_E' ⊗ |a⟩_Q

ρ_{Q'} = (1/d_s) Σ_a ⟨φ(a)|φ(a)⟩ |a⟩⟨a|_Q

G_{a,a} = Π_q [p + (1-p)] = 1（C_q(a,a)=0）。迹保持。→ ρ_{Q'} = I/d_s → S=log(d_s)。✅

ρ_{E'Q'} = (1/d_s) Σ_a |φ(a)⟩⟨φ(a)| ⊗ |a⟩⟨a|

对于 a≠b，Q' 块正交。每个块 |φ(a)⟩⟨φ(a)|/d_s 秩为 1，非零特征值 = ⟨φ(a)|φ(a)⟩/d_s = 1/d_s。
d_s 个正交块 → d_s 个特征值 1/d_s → S=log(d_s)。✅

**裁决:** ✅ 严格成立，不依赖 b1、拓扑或 Cartan 参数。仅依赖迹保持性（G_{a,a}=1）。

### I-3: 数值精度

b1=8: d_s=512。G 是 512×512 复矩阵，条件良好（对角元=1，非对角元 ∈ [0,1]）。特征值分解用 scipy.linalg.eigvalsh（对 Hermitian 矩阵优化）。

熵计算用 ε=1e-12 截断 → 数值噪声 ~1e-12 bits。QCMI ~8 bits → 相对精度 ~1e-13。

**检查:** b1=1 独立方法（`cfol_scan2.py` 的完整密度矩阵 vs `b1_scaling.py` 的 Gram 矩阵）一致到 6 位小数。✅

**裁决:** ✅ 精度充分。

### I-4: delta 收敛的统计显著性

delta(QCMI) = {1.408, 1.187, 1.083, 1.034, 1.011, 1.001, 0.995, 0.993}

delta 差分的比值: 0.104, 0.049, 0.023, 0.010, 0.006, 0.002 — 近似几何衰减（比值~2）。

指数拟合: delta(b1) = 0.991 + 0.512/2^{b1}（R² 对最后 5 点 > 0.99）。

**结论:** delta → 0.991 ± 0.002。渐近值 > 0.98 以 >5σ 置信度确立。

**裁决:** ✅ α≈1 结论稳健。delta 不会收敛到 0。

### I-5: 仅测试了均匀 Cartan 参数 — 是否存在退化情况？

**检查:** 所有测试使用 c_j 全部相等（c=0.5 或 c=π/2）。混合 c 值（部分 Clifford、部分非 Clifford）未探索。

**潜在风险:** 如果部分环是 Clifford（c=π/2）而其他环不是，QCMI 可能表现出不同于线性的行为。

**缓解:** CFOL 充要条件在 b1=3、c 全等时已验证。均匀 c 的线性标度是"最坏情况"——混合 c 只会减少 QCMI（部分环贡献为 0）。线性标度不会因此被推翻。

**裁决:** ⚠️ 混合 c 需要后续测试，但不影响 α≈1 的核心结论。

## REVIEWER

### R-1: 数值结果是否构成"证明"？

**评论:** 8 个数据点的数值扫描对物理学家是充分证据，但不是 α=1 的数学证明。

**回应:** 
1. **边不相交情况**（α=1）有严格证明：sQNM 张量积可加性（Gangwar 2025）
2. **顶点共享情况**（α→1）有数值证据 + 物理论证（Gram 矩阵因子化 → 1D 平移不变链 → 熵密度存在且 >0）。严格证明确实需要完成

**解析证明路径:** 将顶点共享链的 Gram 矩阵映射为一个 1D 经典自旋模型的转移矩阵 → 熵密度 = 每自旋的自由能 → 严格 >0。这可以用标准统计力学技术完成。

**裁决:** ⚠️ 数值充分，解析待补。优先度：中。

### R-2: p≠0.5 时 α 是否依然 ≈1？

**分析:** 对 p≠0.5，Gram 因子变为:
p·e^{iC} + (1-p)·e^{-iC} = cos(C) + i(2p-1)sin(C)

|因子|² = cos²(C) + (2p-1)² sin²(C) = 1 - 4p(1-p)sin²(C)

当 |C| > 0 时，|因子| < 1（对 p≠0,1）。Gram 矩阵的非对角元更小 → QCMI 更大。但关键问题是：delta 是否依然收敛到常数？

p=0.7 的快速检验（b1=1..4）：应该能看到类似的收敛模式，per_ring 更大（因为 Gram 非对角元更小 → 更大的熵）。

**裁决:** ⚠️ 需要数值确认，但理论上有理由相信 α≈1 对所有 p∈(0,1) 成立。

### R-3: 一般图的 b1 下界

**评论:** 顶点共享链是特殊拓扑。一般因果图可能有更复杂的共享模式。

**回应:** 
- **下界方向:** 边不相交环（α=1）是下界——任何图可以通过"断开"共享节点获得边不相交环的子图 → QCMI ≥ (边不相交子图的 QCMI)
- **上界方向:** 边共享的压低更强 → 一般图位于两种极限之间
- **关键:** 只要 QCMI/b1 不衰减到 0（已数值排除），DGF 的宏观推广就站得住

**裁决:** ✅ 需要一般图的严格下界证明，但 α≈1 的核心结论不受影响。
