## I-1: insert_mass 预置了 exp(-M/r) [致命性: 致命]

**被审计代码 (rg_flow.py:100-103):**
```python
def insert_mass(self, M_pl):
    dist = self._bfs(self.n // 2)
    for i in range(self.n):
        d = max(dist.get(i, 1.0), 0.5)
        self.q[i] = np.exp(-M_pl / d)   # <-- exp(-M/r) 手动输入
```

**审计发现:** q = exp(-M/r) 是在 `insert_mass` 中**手动设置**的初始条件，不是从因果图动力学演化出来的。代码后续验证 "ln q可加性" 只是确认了 exp(-M/r) 在几何平均下的自洽性——你放进去的就是 exp 形式，当然会验证 exp 可加。

**这等同于:**
1. 假设 q = exp(-M/r)
2. 用RG blocking确认 ln q 可加
3. 声称 "q = exp(-Φ/c²) 被推导"

**但实际上:** 第1步已经预设了结论。RG blocking只是确认了几何平均对exp函数是自洽的——这是数学平凡事实，不是物理推导。

**裁决:** ❌ **致命。** 当前代码**没有**从因果图动力学推导出 q = exp(-Φ/c²)。它预设了这个形式，然后验证了它在RG blocking下的自洽性。这不是推导，是自洽性检查。

**修复需要:** 
- 不预设 q 的函数形式
- 从因果图的微观动力学（边连接、Cartan参数、退相干规则）**演化**出 q 的空间分布
- 然后验证该分布在连续极限下是否趋近 exp(-Φ/c²)
- 这才是真正的推导

## I-4: 谱维度为负 [致命性: 中]

**被审计数据:** d_s = -6.78, -11.99, -4.82

物理谱维度必须在 [0, d] 范围内（d是嵌入维度）。负谱维度表明 Laplacian 的 eigsh 计算失败——对小图(125节点、8节点)和小k值，`eigsh` 的 'SM' (smallest magnitude) 模式不稳定。

**影响:** 谱维度是因果图连通性的关键诊断量。当前无法从这些数据得出任何物理结论。

**裁决:** ⚠️ **严重但可修复。** 需要稳定的谱维度算法（或更大图使eigsh收敛）。

## I-5: b1 ~ L^{-5.88} 标度异常 [致命性: 中]

**被审计数据:** b1=8001 (L=10) → 1001 (L=5) → 17 (L=2), 拟合 b1 ~ L^{-5.88}

3D格点图的Betti数应满足 b1 ~ L³ (体积标度)。L^{-5.88} 意味着图**收缩**得比体积快——这是因为RG blocking在合并节点时**丢弃了内部边**。

**审计发现:** `rg_block` 函数创建了一个**全新的** `CausalGraph(ng)`，其边仅基于新格点的空间邻近性连接，而不是基于原始图的**因果连通性**。这意味着:
- 原始图中跨越block边界的因果边没有被正确传递
- 新图的b1仅取决于新格点间的空间连接，与原始图的因果拓扑无关
- b1的RG流被**完全重置**于每个层级

**裁决:** ⚠️ **严重。** RG blocking丢失了因果拓扑。有效图不能仅从空间格点重建——必须保留原始因果边的跨block连通信息。

## I-6: 梯度能量 (∇q)²/q² 函数形式未论证 [致命性: 低]

**被审计代码 (rg_flow.py:119-127):**
```python
def grad_energy(self):
    E += sum((self.q[i] - self.q[j])**2 for j in nbrs) / len(nbrs)
```

离散形式是 (Δq)²，连续极限是 (∇q)²。

但变分推导中使用的是 (∇q)²/q² = (∇ ln q)² = (∇ψ)²。

代码中计算的是 (∇q)²，而推导中使用的是 (∇ ln q)²。两者在 q→1 时等价，但在 q 远离 1 时不同。

**更根本的问题:** 为什么梯度能量是这个形式？DGF中能量的微观定义是什么？标准场论中 (∇φ)² 是最低阶梯度项——但DGF不是标准场论。这个能量泛函需要从因果图的微观哈密顿量推导。

**裁决:** ⚠️ **低-中。** 函数形式是合理的（最低阶梯度项），但缺少微观推导。在q≈1极限下，(∇q)² ≈ (∇ ln q)²，不影响弱场结论。

## I-7: λ 标定仍是手动匹配GR [致命性: 高]

**被审计推导 (rg_flow.py:344-346):**
```
nabla^2 psi = 1/lambda
For a point source M: nabla^2 psi = 4pi GM/c^2 delta^3(x)
```

**审计发现:** 等式 "1/λ = 4πGM/c²" 是将变分原理的Euler-Lagrange方程**强设**为Poisson方程（系数手动选为4πG/c²）。λ没有被计算——它被选为等于 c⁴/(4πG)。

这与旧框架中 η=(2q_vac-1)/2 的"标定"是同一类操作:
1. 推导出 ∇²ψ = 1/λ（形式）
2. 设 1/λ = 4πGρ/c²（手动匹配GR）
3. 声称"推导出GR"

**λ 应该如何被确定:** 从因果图的微观参数——格点间距 ℓ_P、基础环速率 Γ₀、Cartan参数分布——计算出有效耦合常数。只有这样才能声称它是"推导"。

**裁决:** ❌ **致命。** λ仍是手动标定参数。当前推导给出的是 q场方程的形式（Poisson），不是其系数。系数来自对标GR，不是来自DGF微观物理。

## I-8: dτ/dt = q/q_vac 缺少推导 [致命性: 高]

**被审计公式:** dτ/dt = q/q_vac

**审计发现:** 此公式替换了旧的 dτ/dt = (2q-1)_+/(2q_vac-1)_+，但替换的理由未被给出。

旧公式被INSPECTOR R1的I-1杀死（时钟tick≠退相干事件）。新公式 dτ/dt = q 同样面临这个问题: **为什么 proper time 等于局域纯度？**

如果这个公式成立，那么:
- 超冷原子 (q≈1): dτ/dt=1 (正常时间流速)
- 黑洞视界 (q≈0.607): dτ/dt=0.607 (时间慢40%)
- 中子星表面 (q≈0.842): dτ/dt=0.842 (时间慢16%)

这与GR定性一致，但DGF的微观推导在哪里？为什么 proper time ∝ q？

**可能的论证:**
- q = 局域因果格点处于叠加态的比例
- 物理过程需要"开放的量子通道"来进行
- 开放通道的比例 = q
- 因此所有物理过程的速率 ∝ q
- dτ/dt（时间流速）= 物理过程速率 / 参考速率 = q/q_vac

这个论证有逻辑，但仍未解决INSPECTOR R1 I-1的核心问题: **相干过程(时钟tick)和退相干过程(噪声)在q的什么比例中体现？** 如果两者都∝q，那么时钟信号和噪声的比例不随q变化——时钟精度不变，但tick速率变了。这或许可行，但需要更仔细的时钟量子模型。

**裁决:** ⚠️ **严重。** 公式简洁且与GR一致，但缺少从DGF时钟模型到 dτ/dt = q 的严格推导。需要证明所有物理时钟在q场中满足此关系（等效原理的DGF版本）。

## R2应该做的事

不是继续修补当前代码，而是直面I-1的核心挑战:

**从因果图微观动力学演化出 q 的时空分布，而非预设它。**

2. 给每条边赋Cartan参数，给每个节点赋初始q

6. 若是→提取const → 与G对比 → 真正的推导
