### 矛盾2: DGF的引力是"标量引力"还是"度规引力"？

| 文件 | 声称 |
|------|------|
| einstein_in_dgf.md | "DGF产生的是一个**标量引力理论**" — "DGF不是GR" |
| DGF_Unified_v3.md §IV | 度规 ds²=-q²dt²+q⁻²dx² — **度规理论** |
| 08-macro-extension-roadmap.md | "G_eff推导: f(q)=G/q" — 暗示GR修正 |

**分析**: 这不是真正的矛盾，但需要澄清术语。"标量引力"指理论只有一个自由度q(x)决定度规。"度规引力"指理论用度规g_μν描述引力。DGF**两者都是**：它用度规描述引力，但度规只有一个独立自由度q。相比之下GR有两个独立度规函数。

**判定**: 论文必须统一术语。建议用"标量-度规引力理论"（scalar-metric gravity）：度规g_μν[q]是q的泛函，只有一个独立自由度。

## 二、声张与证据不匹配

### 不匹配1: "F=ma被推导" vs 实际是校准

fma_d3_in_dgf.md声称F=ma是"导出"的（"已严格推导"）。但步骤4是：

> "通过牛顿极限校准（与GR的1PN匹配）确定比例常数为1"

**这不是推导——这是校准。** 推导和校准的区别：
- **推导**: F=ma的形式、比例关系、m和a的含义全部从DGF公理出发，常数1自动出现
- **校准**: F∝ma的形式从DGF出发，但比例常数通过匹配已知物理（牛顿引力）确定

当前F=ma的论证给出F ∝ m∇q和a ∝ ∇q → F ∝ ma。这是**比例关系**，不是等式。等式F=ma需要比例常数为1，这一步是校准的。

**判定**: 降级为"F ∝ ma从DGF导出，等式F=ma在牛顿极限下通过G的校准固定。"论文不能声称F=ma被完全推导。

### 不匹配2: 薛定谔方程"恢复" vs "推导"

schrodinger_in_dgf.md第0节诚实地说DGF"预设量子力学框架"，但推导链看起来像在"推导"薛定谔方程。

**核心问题**: Cartan门U=exp(ic σ⊗σ)已经**是**量子力学。Pauli矩阵、指数映射、作用于态矢量的幺正算子——这些全都预设了量子力学的数学形式。从Cartan门"推导"薛定谔方程相当于：假设了量子力学的全部代数结构，然后说"看，我们得到了薛定谔方程"。

**诚实版本**: "DGF使用Cartan参数化的幺正门作为因果交互的模型。在这个模型内，q→1极限下的动力学自然采取薛定谔方程的形式。DGF不声称推导量子力学——它解释了为什么在DGF框架中量子力学采取这个特定形式，以及ℏ和i在DGF本体论中的位置。"

**判定**: 论文只能说"恢复了薛定谔方程的形式"，不能说"推导了薛定谔方程"。

### 不匹配3: 有效度规的"推导"

einstein_in_dgf.md §1.1从t_AB = τ₀ Σ 1/q_v推导出ds² = -q²dt² + q⁻²dx²。

**问题**: t_AB = τ₀ Σ 1/q_v假设了信息传播延迟与1/q成正比。这是**手糊的**——一个合理但非唯一的假设。为什么不是1/q²？为什么不是ln(1/q)？

DGF的公理说溢出不可逆，但没有规定溢出速率与q的具体函数关系。1/q选择的唯一理由是它给出正确的牛顿极限。这是**逆向工程**——从已知引力反推q场的行为，然后声称q场"推导"了引力。

**判定**: 有效度规是DGF的**ansatz**（启发性假设），不是严格推导。论文必须显式标注这一点。

## 三、概念缺口

### 缺口1: 从离散信息图到连续q场的桥

DGF在离散图上定义q_v ∈ [0,1]，但所有宏观推导使用连续q(x)。两者之间有一个**未证明的连续极限**：

- 离散: q_v的更新规则是局部的、随机的
- 连续: ∂_τ q = D∇²q - Γ(q)

连续极限的存在性、∇²的出现、D和Γ的确定性形式——这些都没有从离散规则严格证明。LP40尝试了数值验证但**统计不显著**。

**影响**: 这是Wall #3（10⁶¹鸿沟）的子问题。q场方程是DGF与GR/GW/DESI一切接口的起点——如果连续极限不成立，整个宏观推导链悬空。

### 缺口2: Γ(q)函数形式的完全未知

q场方程的源项Γ(q)控制信息的本地归档率。DGF中Γ(q)的形式是：
- Γ₀(q): 真空归档率（可能对应暗能量）
- κρ_m: 物质源项（线性耦合假设）

但Γ(q)的具体函数形式从未从DGF公理推导。它是手糊的——调节Γ(q)的形式可以产生任意想要的引力行为。

**影响**: 在没有第一原理Γ(q)的情况下，任何"DGF预言GW 2PN偏差"的声称都依赖于Γ(q)的人为选择。改变Γ(q) → 改变2PN预言。

### 缺口3: 为什么SU(2)？为什么qubit？

整个DGF大厦——CFOL定理、QCMI标度律、Cartan参数化、薛定谔恢复——都依赖于"基本信息单元是qubit，因果交互是SU(2) Cartan门"这一选择。

如果是qutrit(SU(3))？如果是玻色子模式(无穷维)？如果是费米子模式(Grassmann)？

DGF从未论证为什么qubit是自然的。一个可能的论证路径：信息容量≤O(1) bit/格点 → 最小非平凡信息单元是2态系统 → qubit。但"最小"不意味着"唯一"——可以有更高维的基本单元。

**影响**: 论文必须将此标注为**框架选择**而非公理推论。

## 四、诚实评估：DGF论文可以说什么

### 可以说的（有证据支撑）

1. 三条公理 → θ(A)=πA, 恰好一个时间方向, 质量映射m(A), q场方程
2. CFOL充要条件: 因果拓扑↔量子非马尔可夫性(在Cartan/SU(2)框架内)
3. 有效度规ansatz → 牛顿引力（1次校准: G）
4. QCMI标度律θ²ln(1/θ) — 解析推导+数值验证+IBM Q硬件检验
5. GW 2PN偏差4% — 可检验预言

### 不能说（或必须标注为ansatz/校准/框架选择）

1. "推导了薛定谔方程" → "恢复了薛定谔方程的形式（在Cartan/SU(2)框架内）"
2. "推导了爱因斯坦方程" → "产生了标量引力理论，在弱场与GR一致"
3. "推导了F=ma" → "导出了F∝ma的比例关系，等式通过G校准固定"
4. "推导了d=3" → "d=3是各向同性普适类的假设，非推导"
5. "q场方程是严格推导的" → "q场方程是离散溢出规则的连续极限ansatz"

## 六、当前最诚实的框架陈述

> DGF是一个**信息论启发的有效框架**，从三条公理出发（信息存在、容量有界、溢出不可逆）。在SU(2) Cartan门和连续极限的工作假设下，框架严格证明了微观因果拓扑→量子非马尔可夫性的CFOL定理。在宏观侧，q场的有效度规ansatz给出与牛顿引力一致的静态极限，在2PN级预言了与GR有4%偏差的可检验信号，并在IBM Q硬件上获得了S/N>600的CFOL验证。框架的核心开放问题是离散→连续RG流和有效度规ansatz的第一原理推导。框架不声称推导量子力学或广义相对论——它提供了一个信息论视角来理解这两个理论如何从更基本的原理中涌现。
