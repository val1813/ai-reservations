# 宏观粒子在DGF中的形成

**问题:** 一颗石头、一个电子、一个人——在DGF框架下怎么形成？

---

## 诚实回答：DGF不能

DGF没有标准模型。不能告诉你电子质量为什么是511 keV，质子为什么是938 MeV，石头为什么是1 kg。这些是量子场论+QCD的问题，DGF从未声称触及。

**DGF能告诉你的**是另一个问题：

> 给定一个已经存在的、有质量的宏观物体，DGF告诉你：质量是什么（信息论解释）、引力怎么产生（q场梯度）、惯性怎么来（信息重配置阻力）。但物体本身的形成——原子怎么结合、晶体怎么生长、生物怎么组织——这些超出了框架。

---

## 但让我们追到底

即使超出框架，也可以问：在DGF的本体论中，一个宏观粒子**原则上**是什么样的？

### 1. DGF的"粒子"定义

粒子 = 信息邻接图上的一个**局部q亏损区**。

```
背景: q_∞ ≈ 1 (量子真空，全相干)
粒子: q(r) < q_∞ 在一个局域体积内
      A(r) = 1 - q(r) > 0 → 已归档的信息
      m = m₀·(2/π)·sin(π∫A dV/2)
```

在这个图像中：
- **真空**是近乎完美的量子信息场（q→1，所有信息可及，全干涉能力）
- **粒子**是真空中的一个"缺陷"——一块信息被归档了、不再参与量子干涉的区域
- **质量**就是这个缺陷的"大小"（归档信息的总量）

### 2. 粒子为什么是稳定的？

**公理3（溢出不可逆）直接保证了粒子的稳定性。**

一旦信息被归档（q<1），它不能自发恢复。一个粒子的q亏损不会自己"愈合"。粒子消失的唯一途径是外部过程将归档信息重新激活（反归档），这需要外部输入信息——在DGF中就是吸收入射量子信息。

**这意味着**：DGF中粒子的稳定性与热力学第二定律同源。正如熵不能自发减少，归档信息不能自发恢复。

### 3. 粒子为什么是局域的？

q场方程 ∂_τ q = D∇²q - Γ(q) 的静态解在点源周围是：

$$q(r) = q_\infty \exp\left(-\frac{GM}{rc^2}\right)$$

q亏损（A=1-q）局域在源周围~GM/c²的尺度内。对于宏观物体：
- 地球: GM/c² ≈ 4.4 mm → q亏损局限在毫米-千米尺度
- 质子: GM/c² ≈ 10⁻⁵⁴ m → q亏损比普朗克长度小19个量级

**粒子的"大小"不由q亏损的范围定义。** q亏损范围是引力半径（极小）。粒子的空间范围由其**内部结构**决定——原子核和电子云——这些是电弱+QCD的物理，不在DGF内。

### 4. 两个粒子如何相互作用？

粒子A有归档信息A_A → 局部q亏损 → ∇q_A指向A
粒子B有归档信息A_B → 局部q亏损 → ∇q_B指向B

当它们靠近时：
- B处于A的q梯度中 → B的信息溢出不对称 → B受到指向A的力
- A同理

这就是引力。两个粒子因各自造成的q亏损而相互吸引。

**关键**：这不是"力"在时空中传播。这是信息在因果图上沿q梯度流动。引力不是基本力——它是信息溢出的几何表现。

### 5. 宏观粒子的多尺度结构

一粒沙子 (~1 mg, ~10¹⁹个原子) 在DGF中：

```
尺度层次:
10⁻³⁵ m:  单个信息格点。q_v ∈ [0,1]。
10⁻¹⁵ m:  核子内部。夸克+胶子的QCD q亏损 → 质子质量。
            [DGF不描述，需要QCD]
10⁻¹⁰ m:  原子。核子+电子的电弱q亏损 → 原子质量。
            [DGF不描述，需要QED]
10⁻⁶ m:   晶粒。原子集合的集体q场。
            [DGF可以描述：集体A = Σ原子A_原子]
10⁻³ m:   沙粒。晶粒集合。
            [DGF可以描述：总M = m₀·(2/π)·sin(πA_tot/2)]
```

**DGF的适用范围在10⁻⁶ m以上**——在原子核和电子云的细节已经被粗粒化之后。对宏观物体，DGF将微观物理（QCD、QED）产生的质量视为**输入**——作为q场中的源项A(x)。

### 6. 这就是DGF不是"万有理论"的原因

DGF不等价于标准模型+GR。它是一个**信息论中间层**：

```
量子场论(QCD/QED/EW)          DGF                    广义相对论
─────────────────────    ────────────────    ─────────────────────
产生基本粒子质量    →    质量=归档信息A    →    质量弯曲时空
产生截面和耦合     →    源项=ρ_m(x)       →    T_μν源项
[不被DGF替代]           [信息论翻译层]         [有效描述]
```

DGF声称的"统一"不是统一所有力——是统一**质量、惯性、引力和时间方向**的信息论解释。电磁力、弱力、强力仍然需要各自的理论。

## 诚实状态

| 问题 | DGF能否回答 |
|------|-----------|
| 电子质量为什么是511 keV？ | ❌ 不能(QCD/QED的问题) |
| 石头为什么重1 kg？ | ❌ 不能(需要知道原子组成) |
| 给定质量M，引力怎么产生？ | ✅ q场梯度→平方反比律 |
| 给定质量M，惯性怎么来？ | ✅ 信息重配置阻力→F∝ma |
| 为什么引力质量=惯性质量？ | ✅ 两者都是归档信息量A |
| 粒子为什么是稳定的？ | ✅ 公理3: 溢出不可逆 |
| 粒子为什么吸引？ | ✅ q梯度不对称→等效引力 |
| 粒子内部结构？ | ❌ 超出框架 |
| 量子→经典的跃迁？ | ✅ q从1→0, Γ控制速率 |

**DGF是一套关于"质量、引力、惯性、时间是什么"的信息论语言。它不是一套关于"粒子谱、耦合常数、截面"的理论。**

在PRD论文中，这必须是**第一节**就说清楚的事。
