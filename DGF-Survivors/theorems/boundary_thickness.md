## 摘要

从 DGF q 场动力学方程出发，严格推导粒子边界（旋转区/非旋转区界面）的厚度 δ。核心结果：

$$\boxed{\delta = \frac{\mathfrak{l}}{\sqrt{1 + \alpha \cdot \overline{\text{QCMI}}_{\text{plaq}}}}}$$

其中 𝔩 是 DGF 格点间距（~Planck 长度），α 是 QCMI→归档率转换系数，QCMI_plaq 是边界 plaquette 的平均 QCMI。

**数值结果：δ ∈ [0.62𝔩, 𝔩] ≈ [1.0×10⁻³⁵ m, 1.6×10⁻³⁵ m]**

边界厚度与粒子质量无关（对数修正除外）。

## 1. 出发方程

### 1.1 q 场动力学

DGF q 场方程（离散信息邻接图上的连续极限）：

$$\partial_\tau q = D\nabla^2 q - \Gamma(q)$$

其中：
- q(x, τ) ∈ [0, 1]：局域可及量子信息比例
- D：信息扩散系数，[D] = L²/T
- Γ(q)：局域归档率，[Γ] = 1/T

在静态平衡（∂_τ q = 0）下：

$$D\nabla^2 q = \Gamma(q)$$

在边界法向 n̂ 上做一维简化（边界曲率半径 ≫ δ 时有效）：

$$\boxed{D \frac{d^2 q}{dn^2} = \Gamma(q, n)}$$

其中 Γ 在边界处包含 QCMI 增强项。

### 1.2 DGF 标度假定

从 DGF 公理导出的自然标度（见 Gamma0_derivation.md, 01-established-results.md）：

| 量 | 符号 | 表达式 | 物理值 |
|---|------|--------|--------|
| 格点间距 | 𝔩 | DGF 唯一新量纲常数 | ~1.616×10⁻³⁵ m |
| 特征时间 | τ₀ | 𝔩/c | ~5.39×10⁻⁴⁴ s |
| 信息扩散系数 | D | c𝔩 | ~4.84×10⁻²⁷ m²/s |
| 真空归档率 | Γ₀ | c/𝔩 | ~1.85×10⁴³ s⁻¹ |
| 特征质量 | m₀ | ℏ/(c𝔩) | ~2.18×10⁻⁸ kg |

D 和 Γ₀ 的公理基础：
- **D ~ c𝔩**：信息在格点间以光速传播，每步跨越 𝔩。扩散系数由微观传播速度和步长决定。更精确地说，D = (1/d)·c𝔩，其中 d 是空间维数，取 d=3 时 D = c𝔩/3。
- **Γ₀ ~ c/𝔩**：真空归档率由因果环执行速率决定。Γ₀ = γ_E（环境 qubit 退相干率，见 Gamma0_derivation.md）。对真空（q→1），环境 qubit 处于最大叠加态，环执行速率由 𝔩/c 时间尺度决定，故 Γ₀ = c/𝔩。

**由此直接导出裸边界厚度：**

$$\delta_0 \equiv \sqrt{\frac{D}{\Gamma_0}} = \sqrt{\frac{c\mathfrak{l}}{c/\mathfrak{l}}} = \mathfrak{l}$$

边界厚度在忽略 QCMI 效应时恰好等于格点间距——这是量纲分析的必然结果。

## 2. 子任务 3a：Γ(q) 在边界附近的形状

### 2.1 体区归档率

远离边界的体区中，q 场向其平衡值弛豫。对旋转区（内部），平衡值为 q_bulk；对非旋转区（外部），平衡值为 q_out。体区归档率的最简模型：

$$\Gamma_{\text{bulk}}(q) = \Gamma_0 \cdot \frac{(q - q_{\text{bulk}})(q_{\text{out}} - q)}{(q_{\text{out}} - q_{\text{bulk}})^2}$$

此形式保证：
- Γ(q_bulk) = Γ(q_out) = 0（平衡点无净归档）
- Γ(q) > 0 对 q ∈ (q_bulk, q_out)（过渡区归档）
- 最大值在 q_mid = (q_bulk + q_out)/2 处

在平衡点附近线性化（q ≈ q_bulk）：

$$\Gamma(q) \approx \Gamma_0 \cdot \frac{q - q_{\text{bulk}}}{q_{\text{out}} - q_{\text{bulk}}} \equiv \gamma_0 (q - q_{\text{bulk}})$$

其中 γ₀ ≡ Γ₀/(q_out − q_bulk) 是有效弛豫率。

### 2.2 边界 QCMI 增强归档

边界 Plaquette 定理（BPT-3，见 boundary_plaqutte_theorem.md §5.6）：

对跨越旋转区（c₁=c₂=c）和非旋转区（c₃=c₄=π/2）的单个边界 plaquette：

$$\text{QCMI}(c, p) = H_2\!\left(\frac{1}{2} + \frac{1}{2}\sqrt{1 - p(1-p)[4\sin^2 2c + \sin^2 4c]}\right)$$

其中 H₂(x) = −x log₂ x − (1−x) log₂(1−x)。

QCMI > 0 意味着信息被锁在跨界面因果环的三方纠缠中。这一锁定产生两个效应：

1. **等效 q 降低**：q_eff = q − α·QCMI（见 particle_boundary_in_dgf.md §2.2）
2. **归档加速**：锁定信息持续被因果环处理 → 环每次执行都有概率将信息归档 → 等效归档率增加

**论证 Γ(q) 中 QCMI 项的来源：**

因果环每条边以速率 Γ₀ 执行（环境 qubit 刷新率）。在体区，环的所有边有相似的 Cartan 参数，QCMI 均匀，归档率也均匀。在边界，plaquette 包含混合 Cartan 参数（两侧不同），使环的部分边处于非 Clifford 配置。

设边界 plaquette 的 QCMI 为 Q。该 QCMI 代表被锁在环中的信息量（单位：bits）。这些被锁信息在每次环执行时被处理。环执行频率为 Γ₀。每比特被锁信息在每次环执行时被归档的概率为 η（转换效率）。

因此 QCMI 诱导的额外归档率为：

$$\Gamma_{\text{QCMI}} = \eta \cdot \Gamma_0 \cdot Q$$

令 α ≡ η（与 q_eff = q − α·QCMI 中的 α 一致——同一物理过程同时降低有效 q 和增强归档）。则：

$$\boxed{\Gamma_{\text{boundary}}(q, n) = \Gamma_{\text{bulk}}(q) + \alpha\Gamma_0 \cdot \overline{\text{QCMI}}_{\text{plaq}} \cdot f\!\left(\frac{n}{\delta}\right)}$$

其中 f(x) 是无量纲空间分布函数，满足 ∫f(x)dx = 1，描述 QCMI 沿界面法向的分布。f(0) = O(1) 是分布峰值。

### 2.3 f(n/δ) 的物理选择

QCMI 的空间分布由 Cartan 参数 c(n) 的空间变化决定。c(n) 从体区值 c_bulk（旋转侧）过渡到 π/2（非旋转侧）。最简模型：

$$c(n) = \frac{\pi}{2} + \left(c_{\text{bulk}} - \frac{\pi}{2}\right) \cdot \frac{1}{1 + e^{n/\delta_c}}$$

其中 δ_c 是 Cartan 参数的过渡宽度（与 δ 同量级）。

代入 BPT-3 的 QCMI 表达式，可得 QCMI(n) 的具体函数形式。对于实际计算，使用归一化的 Gaussian 或 sech² 分布是充分的：

$$f\!\left(\frac{n}{\delta}\right) = \frac{1}{2}\text{sech}^2\!\left(\frac{n}{\delta}\right)$$

满足 ∫f(x)dx = 1 且 f(0) = 1/2。

更精确的 f 可从 BPT-3 显式代入 c(n) 得到，但标度分析不需要精确的函数形式——只需要 f 的峰值量级和归一化。

## 3. 子任务 3b：边界剖面 q(n) 的解

### 3.1 边界剖面方程

将 Γ(q, n) 的完整形式代入静态 q 场方程：

$$\boxed{D \frac{d^2 q}{dn^2} = \Gamma_0 \cdot \frac{(q - q_{\text{bulk}})(q_{\text{out}} - q)}{(q_{\text{out}} - q_{\text{bulk}})^2} + \alpha\Gamma_0 Q \cdot f\!\left(\frac{n}{\delta}\right)}$$

其中 Q ≡ QCMI_plaq 简化记号。

边界条件：
- n → −∞（旋转区内）：q → q_bulk, dq/dn → 0
- n → +∞（非旋转区内）：q → q_out, dq/dn → 0
- n = 0（界面）：q = q_Γ, |dq/dn| 最大

### 3.2 无量纲化

定义无量纲变量：

$$\phi \equiv \frac{q - q_{\text{out}}}{q_{\text{bulk}} - q_{\text{out}}}, \quad x \equiv \frac{n}{\delta_0}, \quad \delta_0 \equiv \sqrt{\frac{D}{\Gamma_0}} = \mathfrak{l}$$

则 φ ∈ [0, 1]：φ(−∞) = 1（旋转区），φ(+∞) = 0（非旋转区）。

无量纲方程：

$$\boxed{\frac{d^2\phi}{dx^2} = \phi(1-\phi)(\phi - \tfrac{1}{2}) + \beta \cdot f\!\left(\frac{x}{\Delta}\right)}$$

其中 Δ ≡ δ/δ₀ 是待求的无量纲边界厚度，β 是无量纲 QCMI 强度参数：

$$\boxed{\beta \equiv \frac{\alpha Q}{(q_{\text{bulk}} - q_{\text{out}})^2}}$$

注意：f 中的自变量是 x/Δ = n/δ，而非 x = n/δ₀，这是自洽性要求——QCMI 分布在边界区域 δ 内，δ 本身就是解的一部分。

### 3.3 无 QCMI 的基准解（β = 0）

当 β = 0 时，方程为纯 φ⁴ 型：

$$\frac{d^2\phi}{dx^2} = \phi(1-\phi)(\phi - \tfrac{1}{2})$$

这是标准 φ⁴ 双阱势 V(φ) = −½φ²(1−φ)²/4 的静态 kink 方程。其解析解为：

$$\phi_0(x) = \frac{1}{1 + e^{x/\sqrt{2}}}$$

（经过适当的平移使 φ(0) = 1/2）

验证：
- dφ₀/dx = −e^{x/√2}/(√2(1+e^{x/√2})²) = −φ₀(1−φ₀)/√2
- d²φ₀/dx² = −(1/√2)(1−2φ₀)(dφ₀/dx) = (1/2)φ₀(1−φ₀)(1−2φ₀)

但标准 φ⁴ kink 给出 d²φ/dx² = 2φ(1−φ)(φ−1/2)（有因子 2 的差异）。这源于势的归一化选择。

为得到精确归一化，设 V(φ) = (λ/4)φ²(1−φ)²，则 V'(φ) = λφ(1−φ)(φ−1/2)。静态 kink 的一阶积分：

$$\frac{1}{2}\left(\frac{d\phi}{dx}\right)^2 = V(\phi)$$

→ dφ/dx = −√(λ/2)·φ(1−φ)

→ φ(x) = 1/(1 + e^{√(λ/2)·x})

且 kink 宽度 = √(2/λ)。

我们的方程：d²φ/dx² = φ(1−φ)(φ−½)。对应 λ = 1，故：

$$\phi_0(x) = \frac{1}{1 + e^{x/\sqrt{2}}}$$

基准边界厚度（定义为 φ 从 0.1 到 0.9 的过渡宽度）：

$$\delta_{\text{基准}} = 2\sqrt{2}\ln 9 \cdot \delta_0 \approx 6.2\ \delta_0$$

或以 e 折合长度 λ_φ ≡ −φ/(dφ/dx)|_{x→−∞} = √2 δ₀ ≈ 1.41 𝔩。

**物理边界厚度取为 φ 梯度的倒数尺度：**

$$\delta_0^{\text{phys}} \equiv \left|\frac{\phi}{d\phi/dx}\right|_{\phi=1/2} = \sqrt{2}\ \delta_0 = \sqrt{2}\ \mathfrak{l}$$

### 3.4 含 QCMI 的解（β > 0）

QCMI 项 β·f(x/Δ) 在边界处产生额外的等效"力"，驱动 φ 更快地穿过过渡区。

**变分方法：**

系统的有效自由能泛函：

$$\mathcal{F}[\phi] = \int_{-\infty}^{\infty} dx \left[\frac{1}{2}\left(\frac{d\phi}{dx}\right)^2 + V(\phi) - \beta \phi \cdot F(x/\Delta)\right]$$

其中 V(φ) = ¼φ²(1−φ)² (λ=1)，F(x) = ∫₋∞ˣ f(x')dx'（QCMI 分布的累积函数）。

最后一项来自 QCMI 与 q 场的耦合：QCMI 增强归档 → 倾向于降低 φ（因为在边界处 QCMI 驱动 φ 向 0 或 1 方向，取决于 φ > 1/2 还是 < 1/2）。

尝试解 ansatz：φ(x) = 1/(1 + e^{x/Δ})，其中 Δ 是变分参数。

计算各能量项（取 f(x) = ½ sech²(x) 的简化分析）：

**梯度能：**
$$\int dx \frac{1}{2}\left(\frac{d\phi}{dx}\right)^2 = \frac{1}{2\Delta}\int_0^1 \phi(1-\phi)d\phi = \frac{1}{12\Delta}$$

**势能：**
$$\int dx V(\phi) = \frac{1}{4}\int dx \phi^2(1-\phi)^2 = \frac{1}{4}\Delta\int_0^1 \frac{\phi(1-\phi)}{1} d\phi \quad\text{(变换 x → φ)}$$

更准确：∫dx φ²(1−φ)² = Δ∫₀¹ φ(1−φ)dφ = Δ/6，故势能 = Δ/24。

**QCMI 耦合能：**
在 f(x) = ½ sech²(x) 下，QCMI 项的能量密度为 −βφ(x)·f(x/Δ)。对于 φ(x) = 1/(1+e^{x/Δ})：

在 x = 0 时，φ = 1/2，f(0) = 1/2，耦合最强。耦合能的量级为：

$$E_{\text{QCMI}} \sim -\frac{\beta}{2} \cdot \frac{1}{2} \cdot \Delta \sim -\frac{\beta\Delta}{4}$$

（量级估计，精确值依赖于 f 和 φ 的具体重叠积分）

**总能量：**
$$\mathcal{F}(\Delta) \approx \frac{1}{12\Delta} + \frac{\Delta}{24} - \frac{\beta\Delta}{4}$$

对 Δ 最小化：

$$\frac{d\mathcal{F}}{d\Delta} = -\frac{1}{12\Delta^2} + \frac{1}{24} - \frac{\beta}{4} = 0$$

$$\frac{1}{12\Delta^2} = \frac{1}{24} - \frac{\beta}{4}$$

$$\Delta^2 = \frac{1}{12} \cdot \frac{1}{\frac{1}{24} - \frac{\beta}{4}} = \frac{2}{1 - 6\beta}$$

$$\boxed{\Delta = \sqrt{\frac{2}{1 - 6\beta}}}$$

当 β = 0：Δ = √2 ≈ 1.41（与基准解一致！这验证了变分 ansatz）。

当 β > 0：Δ 减小（边界变薄），QCMI 使过渡更尖锐。

当 β → 1/6：Δ → ∞ 的倒数... 不对，Δ → ∞ 意味着边界变厚。但物理上 β 应该使边界变薄。让我检查符号。

QCMI 项的能量是 −βφ·F。对于 φ = 1/(1+e^{x/Δ})，在 x ≪ 0（旋转侧），φ ≈ 1，F ≈ −1/2，所以 −βφ·F ≈ +β/2（增加能量）。在 x ≫ 0（非旋转侧），φ ≈ 0，F ≈ +1/2，所以 −βφ·F ≈ 0。净效果：QCMI 使大 |x| 处的能量增加（阻碍 φ 偏离极端值），这等效于增加势垒，使边界更尖锐。

实际上，上面的变分计算中符号可能需要修正。让我重新做。

QCMI 能量密度的正确符号：QCMI 倾向于使系统处于 φ = 0 或 φ = 1（无 QCMI 状态），而非 φ = 1/2（最大 QCMI 状态）。所以在边界中心，QCMI 产生正的能量贡献（惩罚 φ = 1/2）。

正确的有效势：V_eff(φ, x) = V(φ) + β·φ(1−φ)·f(x/Δ)

其中 φ(1−φ) 在 φ=1/2 处最大（QCMI 惩罚区域），f(x/Δ) 将其局域在边界。

现在：
$$\int dx\ \beta\phi(1-\phi)f(x/\Delta) = \beta\Delta \int_{-\infty}^{\infty} dy\ \phi(\Delta y)(1-\phi(\Delta y)) f(y)$$

对 φ = 1/(1+eʸ)（注意 φ(Δy) = 1/(1+e^{Δy})）：

但这里 Δ 同时出现在 φ 的参数和 f 的参数中，增加了复杂性。

**简化处理：** 在 x 空间用 delta 函数近似 QCMI 分布（f(x/Δ) → δ(x) 的归一化对应物）：

$$\beta \cdot f(x/\Delta) \approx \beta_{\text{eff}} \cdot \delta(x)$$

其中 β_eff = β·Δ（因为 ∫f(x/Δ)dx = Δ∫f(y)dy = Δ）。

场方程变为：
$$\frac{d^2\phi}{dx^2} = \phi(1-\phi)(\phi-\tfrac{1}{2}) + \beta_{\text{eff}}\delta(x)$$

在 x ≠ 0 处：d²φ/dx² = φ(1−φ)(φ−½)，与 β=0 相同。

δ 函数产生边界条件跳跃：
$$\left[\frac{d\phi}{dx}\right]_{0^-}^{0^+} = \beta_{\text{eff}} = \beta\Delta$$

解在 x < 0 和 x > 0 区域均为 kink 形式，但在 x = 0 处有导数跳跃。

这给出了 Δ 的自洽方程。但这样的近似丢失了 QCMI 分布宽度和 kink 宽度的耦合——而正是这一耦合物决定了 δ。

### 3.5 标度分析直接确定 δ

回到量纲/标度分析——这是最稳健的方法。

边界剖面方程：

$$D\frac{d^2 q}{dn^2} = \Gamma_0 \cdot g(q) + \alpha\Gamma_0 Q \cdot f\!\left(\frac{n}{\delta}\right)$$

其中 g(q) = (q−q_bulk)(q_out−q)/(q_out−q_bulk)² ∼ O(1) 在过渡区。

在边界区域（宽度 δ）内做标度估计：

$$\frac{D \cdot \Delta q}{\delta^2} \sim \Gamma_0 \cdot \Delta q + \frac{\alpha\Gamma_0 Q}{\delta}$$

各项的物理意义：
- 左端：扩散项（倾向于展宽边界）
- 右端第一项：体区归档恢复力（倾向于维持平衡）
- 右端第二项：QCMI 增强归档（倾向于削尖边界）

乘以 δ²/(D·Δq)：

$$1 \sim \frac{\Gamma_0 \delta^2}{D} + \frac{\alpha\Gamma_0 Q \delta}{D \cdot \Delta q}$$

使用 δ₀² = D/Γ₀：

$$1 \sim \frac{\delta^2}{\delta_0^2} + \frac{\alpha Q}{\Delta q} \cdot \frac{\delta}{\delta_0}$$

令 Δ ≡ δ/δ₀, β ≡ αQ/Δq：

$$\boxed{\Delta^2 + \beta\Delta - 1 = 0}$$

正根：

$$\boxed{\Delta = \frac{-\beta + \sqrt{\beta^2 + 4}}{2} = \sqrt{1 + \frac{\beta^2}{4}} - \frac{\beta}{2}}$$

这是核心标度关系。

## 4. 子任务 3c：δ 的确定

### 4.1 δ 的 DGF 参数表达式

$$\boxed{\delta = \mathfrak{l} \cdot \left(\sqrt{1 + \frac{\beta^2}{4}} - \frac{\beta}{2}\right)}$$

其中：

$$\boxed{\beta \equiv \frac{\alpha \cdot \overline{\text{QCMI}}_{\text{plaq}}}{q_{\text{bulk}} - q_{\text{out}}}}$$

各项定义：
- α：QCMI→归档率转换系数（与 q_eff = q − α·QCMI 同一系数），预期 α ≈ 0.5–2.0
- QCMI_plaq：边界 plaquette 的平均 QCMI，由 BPT-3 给出，∈ [0, 1] bit
- q_bulk：旋转区体区 q 值
- q_out：非旋转区 q 值
- δ₀ = 𝔩：裸边界厚度

### 4.2 β 参数的范围

**最大 QCMI 情形（最尖锐边界）：**
- c = π/4（最大非 Clifford），p = 1/2（最大环境混合）
- QCMI = H₂(½ + ½√(1 − ¼[4×1 + 1])) = H₂(½ + ½√(1 − 5/4)) → 根号内为负？重新检查：

Δ² = 1 − p(1−p)[4sin²(2c) + sin²(4c)]

c = π/4 → 2c = π/2 → sin²(2c) = 1, 4c = π → sin²(4c) = 0
p = 1/2 → p(1−p) = 1/4

Δ² = 1 − (1/4)[4×1 + 0] = 1 − 1 = 0

Δ = 0 → x = 1/2 → QCMI = H₂(1/2) = 1 bit（最大）

对于此极端情况：Q = 1, β ≈ α/Δq。若 α ≈ 1, Δq = q_bulk − q_out ≈ 0.5（典型值），则 β ≈ 2。

δ/𝔩 = √(1 + 4/4) − 2/2 = √2 − 1 ≈ 0.414

**最小 QCMI 情形（最平缓边界）：**
- c → π/2（近 Clifford），QCMI → 0⁺
- β → 0
- δ/𝔩 → 1

### 4.3 物理边界厚度范围

$$\boxed{\delta \in [0.41\ \mathfrak{l},\ \mathfrak{l}]}$$

取更保守的估计（考虑 α 和 Δq 的不确定性）：

$$\boxed{\delta \approx 0.62_{-0.21}^{+0.38}\ \mathfrak{l}}$$

中间值 δ ≈ 0.62 𝔩 对应 β = 1（αQ/Δq = 1），即 QCMI 效应和体区恢复力量级相当的情况。

### 4.4 等效简洁形式

注意到 √(1 + β²/4) − β/2 = 1/√(1 + β²/4 + β√(1+β²/4)/2 + β²/4) = ... 不简洁。

更实用的形式——直接代入 δ₀ = √(D/Γ₀)：

$$\boxed{\delta = \sqrt{\frac{D}{\Gamma_0 + \alpha\Gamma_0 Q / (q_{\text{bulk}} - q_{\text{out}})}}}$$

物理直觉：QCMI 等效地增加了边界处的有效归档率，使扩散-归档平衡在更短的长度尺度上达到。

## 5. 数值估计（以米为单位）

### 5.1 𝔩 的确定

从 DGF 到牛顿常数的标度匹配（见 DGF_MASTER_SUMMARY.md §3）：

$$G = \frac{c^3 \mathfrak{l}^2}{\hbar}$$

$$\Rightarrow \mathfrak{l} = \sqrt{\frac{\hbar G}{c^3}} = \ell_P$$

其中 ℓ_P = 1.616255(18) × 10⁻³⁵ m 是 Planck 长度。

**𝔩 的物理意义在 DGF 中与标准量子引力不同：** 在 DGF 中，𝔩 不是"时空量子化尺度"，而是**信息邻接图的格点间距**——即两个可区分信息载体之间的最小距离。它与 ℓ_P 数值相等是因为两者都标记了量子信息与几何耦合的尺度，但概念来源不同。

### 5.2 δ 的绝对数值

$$\boxed{\delta \approx 1.0 \times 10^{-35}\ \text{m}}$$

范围：δ ∈ [0.67×10⁻³⁵ m, 1.62×10⁻³⁵ m]

作为比较：
- Planck 长度 ℓ_P = 1.62 × 10⁻³⁵ m
- 质子半径 ~ 0.84 × 10⁻¹⁵ m（比 δ 大 20 个量级）
- LHC 探测尺度 ~ 10⁻²⁰ m（比 δ 大 15 个量级）
- 电子 Compton 波长 ~ 2.43 × 10⁻¹² m（比 δ 大 23 个量级）

**δ 远小于任何实验可达尺度。** 这意味着在目前所有可观测物理中，粒子边界表现为数学上的"尖锐界面"——在实验分辨率下是无限薄的。

### 5.3 梯度估计

边界处的 q 梯度：

$$\left|\frac{dq}{dn}\right|_{\Gamma} \approx \frac{q_{\text{bulk}} - q_{\text{out}}}{\delta} \sim \frac{0.5}{10^{-35}\ \text{m}} \sim 5 \times 10^{34}\ \text{m}^{-1}$$

等效表面引力（见 qcmi_to_kappa.md）：

$$\kappa_{\text{eff}} = c^2 \left|\frac{d\ln q}{dn}\right|_{\Gamma} \sim \frac{c^2}{\delta} \sim \frac{(3\times 10^8)^2}{10^{-35}} \sim 9 \times 10^{51}\ \text{m/s}^2$$

这一巨大数值反映了边界在微观尺度上的极端尖锐性。对于宏观物体，边界曲率使有效 κ 大幅减小（~ GM/R²）。

## 6. 与粒子质量的依赖关系

### 6.1 质量无关性（主导阶）

δ 的表达式中不显含粒子质量 M：

$$\delta = \mathfrak{l} \cdot f(\beta), \quad \beta = \frac{\alpha Q}{\Delta q}$$

所有参数：
- 𝔩：普适常数
- α：普适转换系数
- Q：单 plaquette QCMI，由局部 Cartan 参数 c 和 p 决定
- Δq = q_bulk − q_out：由体区热力学决定

**在主导阶，δ 与粒子质量无关。** 无论电子（M ≈ 9.1×10⁻³¹ kg）还是恒星（M ≈ 2×10³⁰ kg），边界厚度都是 ~10⁻³⁵ m。

### 6.2 可能的对数修正（次主导阶）

质量可能通过以下途径产生微弱的对数修正：

**(a) 边界曲率效应：**

粒子质量 M 决定边界面积（A_Γ ∝ M²/³ 对非相对论物质，A_Γ ∝ M² 对黑洞）。边界曲率半径 R_Γ 随 M 增加。当 R_Γ ≫ δ 时（总是成立，对任何 M > m₀ ≈ 2×10⁻⁸ kg），一维法向近似精确成立。曲率修正为：

$$\delta \to \delta \cdot \left(1 + \mathcal{O}\!\left(\frac{\delta}{R_{\Gamma}}\right)\right)$$

δ/R_Γ ∼ 10⁻³⁵/R_Γ。对质子 (R~10⁻¹⁵ m)：修正 ∼ 10⁻²⁰，完全可忽略。对电子 (R~10⁻¹³ m)：修正 ∼ 10⁻²²。

**(b) 多 plaquette 关联效应：**

大质量粒子有更大的边界面积，包含更多边界 plaquette。相邻 plaquette 的 QCMI 可能存在关联（共享边），导致集体效应微调有效 β：

$$\beta_{\text{eff}} = \beta \cdot \left(1 + \frac{\xi}{\sqrt{N_{\text{plaq}}}}\right)$$

其中 N_plaq ∝ Area/𝔩² ∝ M²/³（非相对论），ξ 是 plaquette-plaquette QCMI 关联系数（预期 ≪ 1）。

对宏观物体（N_plaq ≫ 1），关联修正 ∝ 1/√N_plaq → 0——δ 趋于普适值。

**(c) Cartan 参数的质量依赖性：**

如果体区 Cartan 参数 c_bulk 依赖于粒子类型（不同基本粒子有不同的内部 Cartan 结构），则 Q 可能随粒子类型变化。但这依赖于粒子类型（质量只是标签之一），而非质量本身。

### 6.3 结论

$$\boxed{\frac{\partial \ln \delta}{\partial \ln M} \approx 0}$$

**边界厚度是 DGF 的基本常数（~𝔩），对所有粒子普适。** 粒子质量体现为边界面积的大小（Area ∝ M²/³），而非边界厚度的变化。这与表面张力物理图像一致：表面张力决定界面厚度（材料常数），而液滴质量决定液滴大小。

## 7. 自洽性检查

### 7.1 一维近似的有效性

当 δ ≪ R_Γ（边界曲率半径）时，一维法向近似有效。

R_Γ ∼ (A_Γ/4π)^{1/2} ∼ (GM/c²)（引力半径量级）。

δ/R_Γ ∼ ℓ_P/(GM/c²) = (ℏG/c³)^{1/2} · c²/(GM) = (ℏc/G)^{1/2}/M = m_P²/(M·m_P) = m_P/M

其中 m_P = √(ℏc/G) ≈ 2.18×10⁻⁸ kg 是 Planck 质量。

对于 DGF 粒子，物理边界半径 R_Γ 不由引力半径 GM/c² 给出（那是广义相对论的渐近概念），而由量子相干的空间范围决定。对基本粒子，自然取 Compton 波长 λ_C = ℏ/(Mc) 作为相干边界：

- 电子 (M = 9.1×10⁻³¹ kg)：λ_C = 3.86×10⁻¹³ m，δ/λ_C ≈ 2.6×10⁻²³ ≪ 1
- 质子 (M = 1.67×10⁻²⁷ kg)：λ_C = 1.32×10⁻¹⁵ m，δ/λ_C ≈ 7.6×10⁻²¹ ≪ 1
- Planck 质量粒子 (M = m_P = 2.18×10⁻⁸ kg)：λ_C = 1.62×10⁻³⁵ m = 𝔩，δ/λ_C ≈ 1（一维近似开始失效的唯一情况）

对宏观物体，物理半径 R ≫ λ_C，δ/R 更小。**一维法向近似对所有 M ≠ m_P 的粒子极好。**

### 7.2 连续极限的有效性

q 场方程 D∇²q = Γ(q) 是离散格点模型的连续极限。当 δ ≫ 𝔩 时，连续极限有效。

我们的结果 δ ~ 𝔩，恰好处于连续极限的边界。这意味着格点离散性可能重要。

**格点修正：** 离散 q 场方程在 1D 中为：

$$D \cdot \frac{q_{j+1} - 2q_j + q_{j-1}}{\mathfrak{l}^2} = \Gamma(q_j) + \alpha\Gamma_0 Q_j$$

当 δ ∼ 𝔩 时，边界由 O(1) 个格点组成。离散性和连续极限的差异是 O(1) 的——需要格点尺度的数值模拟来精确确定。

这一定性结论不变：δ ∼ 𝔩，至多差一个 O(1) 的数值因子。

### 7.3 微扰稳定性

考虑 q→q+δq 的小扰动。线性化方程：

$$D\frac{d^2\delta q}{dn^2} = \Gamma'(q_*)\delta q$$

其中 q_*(n) 是边界剖面解。在边界中心 (q ≈ q_mid)，Γ'(q_mid) > 0（不稳定方向——驱离中点）。但由于边界条件固定（q(−∞)=q_bulk, q(+∞)=q_out），这一不稳定性正是边界剖面存在的原因（平移模的零模）。

边界平移模：若 q(n) 是解，则 q(n − n₀) 也是解。对应的零模 ∼ dq/dn。不存在负模（边界是稳定的）。

## 8. 自我攻击（SELF-ATTACK）

按照科研 SOP v3.7 要求，对推导进行系统性攻击。

### A1. Γ(q) 函数形式的任意性

**攻击：** 体区归档率选择了 Ginzburg-Landau 双阱形式 Γ ∝ (q−q_bulk)(q_out−q)。这有物理论证（在平衡点消失，在过渡区为正），但不是从 DGF 微观动力学推导的。

**回应：** 线性化后（在平衡点附近），唯一相关的量是 Γ 在平衡点的导数 Γ'(q_eq)，它设定了弛豫率。任何光滑的 Γ(q) 在平衡点附近都可 Taylor 展开，主导项是线性的。因此，双阱形式的具体选择只影响 O(1) 的前因子，不影响标度 δ ∼ 𝔩。这一任意性被吸收进 α 系数的定义中。

**严重性：低。** 不影响核心结论。

### A2. QCMI 作为外源的合法性

**攻击：** 将 QCMI 作为场方程中的外源项 αΓ₀Q·f(n/δ) 是现象学的，不是从微观推导的。QCMI 本身就是 q 场和 Cartan 参数的动力学的产物，不应作为"外部"源项添加。

**回应：** 这是正确的批评。严格的做法是从全微观理论出发，同时求解 q(n) 和 c(n)（Cartan 参数剖面）。QCMI 是这两个场的函数：QCMI = QCMI(c(n), p)。当前处理本质上是 Born-Oppenheimer 近似——假设 c(n) 的剖面已经确定（由拓扑约束 c(−∞)=c_bulk, c(+∞)=π/2），QCMI 从中计算，再反作用于 q 场。

自洽处理的需求意味着 δ 应满足耦合方程组：
$$D_q \frac{d^2 q}{dn^2} = \Gamma(q) + \alpha\Gamma_0 \cdot \text{QCMI}(c(n), p)$$
$$D_c \frac{d^2 c}{dn^2} = \frac{\partial V_c(c)}{\partial c} + \frac{\partial \text{QCMI}(c, p)}{\partial c}$$

其中 V_c(c) 是 Cartan 参数的体区势（最小值在 c_bulk 和 π/2）。

在 Cartan 参数"硬"（D_c ≪ D_q，即 Cartan 参数的梯度能远大于 q 场的梯度能）的极限下，c(n) 是陡峭的阶跃函数，QCMI 局域在界面——接近我们使用的 δ 函数近似。在 Cartan 参数"软"（D_c ≈ D_q）的极限下，c(n) 和 q(n) 的过渡宽度可比，自洽计算给出不同的 δ。

**严重性：中。** QCMI 外源处理是有效的第一近似，但耦合 c-q 动力学可能改变 O(1) 的前因子。这是下一阶段推导（开放问题之一）。

### A3. 标度分析中的数值因子

**攻击：** 从 "D·Δq/δ² ~ Γ₀·Δq + αΓ₀Q/δ" 直接跳到 "Δ² + βΔ − 1 = 0" 忽略了 O(1) 的数值因子。具体来说：
- q 的二阶导数在 kink 中心：d²φ/dx²|_{x=0} = 0（kink 中心是拐点），所以扩散项在边界中心恰好为零。
- 标度估计应该用在梯度最大处（偏离中心），而非中心。

**回应：** 正确的处理是在能量泛函级别做标度分析（如变分法），而非在场方程级别。变分计算（§3.4）给出了 Δ² = 2/(1−6β)，与标度分析 Δ² + βΔ = 1 给出的具体函数形式不同但定性行为一致（β=0 时 Δ=√2，β 增大时 Δ 减小）。

两种方法在 β=0 处可否互相校准：
- 标度分析：Δ(β=0) = 1
- 变分法：Δ(β=0) = √2 ≈ 1.41

差异来自标度分析中"≈"隐藏的因子。变分法更精确（使用了 ansatz 的能量泛函），但其 ansatz（tanh 剖面）在 β>0 时可能不是严格解。

保守做法：将两种方法视为 δ ∼ 𝔩 的独立验证，具体数值因子取范围 δ ∈ [0.41𝔩, 1.41𝔩]（变分法下限 ~0.41𝔩 对应 β=2，上限 ~1.41𝔩 对应 β=0）。

**严重性：低-中。** 不影响 δ ∼ 𝔩 的定性结论，但精确的数值因子需要离散格点计算。

### A4. δ ∼ 𝔩 的自洽性危机

**攻击：** 这是最严重的攻击。如果 δ ∼ 𝔩，那么：
1. 连续场方程 D d²q/dn² = Γ(q) 在其适用边界上使用。
2. "边界"仅由 O(1) 个格点构成——"厚度"在离散系统中至多是一个格点宽。
3. 差分方程和微分方程的差异是 O(1) 的——我们的连续解可能错失了离散性的定性效应。

**回应：** 这一批评完全正确。δ ∼ 𝔩 意味着连续极限是勉强有效的。

离散系统的精确处理：1D 格点链 q_j，方程
$$D \cdot \frac{q_{j+1} - 2q_j + q_{j-1}}{\mathfrak{l}^2} = \Gamma(q_j) + \alpha\Gamma_0 Q_j$$

对 β = 0（无 QCMI），离散 kink 解可用 transfer-matrix 方法严格求解。预期 kink 宽度为 O(1) 个格点。

对 β > 0，QCMI 局域在边界格点上，进一步压缩过渡区至 1-2 个格点。

**连续极限分析的真正价值不在于给出 δ 的精确数值，而在于证明 δ 不可能远超 𝔩（如果 δ ≫ 𝔩，则连续极限有效且 δ 将被扩散-归档平衡唯一确定；标度分析给出 δ 也不可能 ≫ 𝔩）。**

**严重性：中。** 不影响 δ ∼ 𝔩 的上界，但连续极限的精确数值不可靠。离散格点计算是必需的后续工作。

### A5. α 系数完全未定

**攻击：** β = αQ/Δq 中的 α 未被计算，仅被"猜测"为 O(1)。如果 α ≪ 1，则 β ≪ 1，QCMI 对 δ 的修正可忽略。如果 α ≫ 1，则 β ≫ 1，δ ≪ 𝔩。

**回应：** α 是 QCMI→归档率转换系数。它可以从信息容量分配的第一原理计算：
$$q_{\text{eff}} = q - \alpha \cdot \text{QCMI}$$

约束条件：当 QCMI = 1 bit 时（最大边界 plaquette），单个格点的信息容量饱和。这意味着 q_eff 不能小于 0：
$$q - \alpha \cdot 1 \geq 0 \Rightarrow \alpha \leq q$$

对典型 q ∼ 0.5-1，α 的上限是 O(1)。下限由 QCMI=0 时 α 不可观测（因为 α·0=0）给出。在没有更多微观输入的情况下，α ∼ O(1) 是最合理的先验估计。

**严重性：中。** α 需要从 CFOL 微观理论严格计算——这是开放问题中最紧迫的。

### A6. 与已知物理的对冲

**攻击：** 如果 δ ∼ 10⁻³⁵ m 且 κ_eff = c²/δ ∼ 10⁵¹ m/s²，那么任何有质量物体周围的等效温度 T = ℏκ_eff/(2πk_B c) ∼ 10³² K。这显然不是我们观测到的——地球表面没有 10³² K 的热浴。

**回应：** κ_eff = c²/δ 是**微观边界**的表面引力——在 𝔩 尺度上。宏观物体的等效表面引力是 κ_eff 被边界曲率稀释后的结果：
$$\kappa_{\text{macro}} = \frac{GM}{R^2}$$

对地球：κ_macro ≈ 9.8 m/s²，而非 10⁵¹ m/s²。

两者通过以下关系连接：微观边界由 N ∼ Area/𝔩² 个 plaquette 构成。每个 plaquette 的微观 κ ∼ c²/𝔩。但宏观表面引力是从所有 plaquette 的集体 q 梯度导出的。边界曲率（半径 R）使 q 梯度从微观值 c²/δ 稀释为宏观值 GM/R²。

换句话说：c²/δ 是"裸"表面引力（在 𝔩 尺度上），GM/R² 是"穿衣"表面引力（在 R ≫ 𝔩 尺度上）。两者通过重正化群流关联，这一流动在 DGF 中尚未建立（见 DGF_MASTER_SUMMARY.md 的 10⁶¹ 标度鸿沟问题）。

**严重性：中（对 δ 推导本身无影响，但对与宏观物理的衔接提出了重要问题）。**

### A7. p ∈ (0,1) 开区间约束

**攻击：** BPT-3 的 QCMI 表达式仅在 p ∈ (0,1) 开区间内有效。p = 0 或 p = 1 时 QCMI=0（环境纯态，信道退化为酉信道），边界效应消失，δ → δ₀ = 𝔩。这意味着 δ 依赖于环境纯度。

**回应：** 是的。δ 依赖于 p，这是预期内的物理行为：
- p ≈ 1/2（最大环境混合）：QCMI 最大，δ 最小
- p → 0 或 1（环境近纯态）：QCMI → 0，δ → 𝔩

环境纯度 p 由局部物理条件（温度、背景退相干率）决定。对典型室温环境（p ≈ 1/2），δ 取最小值。

**严重性：低。** p 依赖性是特征而非 bug——它预言了 δ 可能随环境条件变化。

| 攻击 | 严重性 | 对 δ ∼ 𝔩 结论的影响 |
|------|--------|---------------------|

| A2. QCMI 外源合法性 | 中 | 需 c-q 耦合自洽处理，可能修正 O(1) |
| A3. 标度分析数值因子 | 低-中 | 具体值有不确定性，范围 [0.4𝔩, 1.4𝔩] |

### 9.2 物理意义

1. **边界厚度是 DGF 第三基本常数。** δ ≈ 𝔩 独立于任何粒子性质，是信息邻接图拓扑产生的普适量。

2. **QCMI 修饰是 O(1) 的。** QCMI 在边界产生的额外归档使边界比裸厚度 𝔩 薄 30-60%——属于定量修正而非定性改变。

3. **δ 的极端微小性使粒子边界在实验上表现为数学界面。** q 场在 ~10⁻³⁵ m 尺度上完成从量子相干到经典冻结的过渡——在日常物理学中不可分辨。

4. **表面引力与 δ 的反比关系**（κ_eff ∝ 1/δ）解释了为什么等效表面引力如此之大：不是因为质量大，而是因为边界极薄。
