# DGF有效场论：从对称性推导普适方程

## 1. 四个对称性（从墙3文档）

1. **信息守恒**: A1+A3 → 总归档信息A_tot守恒
2. **局域性**: 信息只在相邻节点间流动 → 动力学含导数展开，高阶项被l/L抑制
3. **各向同性**: 无优先空间方向 → 矢量项只能以标量组合出现
4. **q有界**: q∈[0,1] → Γ(q)在q→0,1时必须饱和

## 2. 推导

### 2.1 连续性方程

信息守恒 → 存在连续方程：

$$\partial_\tau q + \nabla \cdot \mathbf{J} = -\Gamma(q)$$

其中J是信息流，Γ(q)是归档率（信息从可访问态转为归档态）。

### 2.2 局域性 → 导数展开

信息仅在相邻节点间流动 → J可以展开为q的空间导数的幂级数：

$$\mathbf{J} = -D\nabla q + \mathcal{O}(\nabla^3 q)$$

（∇²q项是矢量，但∇q是唯一的一阶矢量。∇(∇²q)是三阶。）

局域性意味着高阶项被微观尺度l与宏观尺度L之比l/L抑制。

### 2.3 各向同性 → 形式约束

无优先方向 → 有效方程必须在SO(3)下不变。

- 标量q：允许
- 矢量∇q：只能以标量组合出现：|∇q|², ∇²q
- 在J的表达式中，∇q是唯一的SO(3)矢量（一阶）。∇²q是标量的梯度，也是矢量。

最一般的一阶J（忽略O(∇³)项）：
$$\mathbf{J} = -D(q)\nabla q$$

D(q)可以依赖q（因为q本身是标量）。

代入连续性方程：
$$\partial_\tau q = \nabla\cdot(D(q)\nabla q) - \Gamma(q)$$

对各向同性系统，D(q)退化为常数D（不同方向扩散率相同）：
$$\partial_\tau q = D\nabla^2 q - \Gamma(q)$$

### 2.4 q有界 → Γ(q)的形式

q∈[0,1]。Γ(q)在q→0和q→1时必须饱和（不能产生q<0或q>1）。

最简形式：Γ(q) = γ q(1-q)（逻辑函数型），或更一般地，任何在端点为零的光滑函数。

## 3. 为什么这是普适的

上述推导中，唯一的输入是四个对称性。**不依赖格点类型、连接数、微观细节。** 因此：

> 任何满足四个DGF对称性的微观图，在大尺度(L≫l)下，其有效动力学都收敛到∂_τ q = D∇²q - Γ(q)。D和Γ的具体数值依赖微观细节，但**方程形式是普适的**。

## 4. 什么需要枚举验证（而非推导）

- D和Γ(q)在不同图中的具体数值
- 有效维度d_eff（某些图可能不产生3D各向同性——如小世界图的长程连接改变谱维度）
- 高阶修正项O(l²/L²)的大小

**但方程形式本身不需要枚举——它是对称性的必然结果。**

## 5. 残余工作

1. 证明DGF信息图确实满足四个对称性（特别是各向同性——这是工作假设）
2. 确定有效维度d_eff（对DGF信息图，是否有长程连接？）
3. 数值确定D和Γ(q)的具体值
