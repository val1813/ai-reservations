# 粒子边界的信息论起源

**核心insight**: 旋转区和非旋转区之间不能线性过渡 → 过渡本身就是边界 → 边界处的QCMI积聚就是质量。

---

## 0. 从CFOL到粒子边界

### CFOL教了我们什么

$$I(R;E'|Q') = 0 \iff c_j \in \frac{\pi}{2}\mathbb{Z} \quad \forall j$$

- cⱼ∈(π/2)ℤ: Clifford点，QCMI=0，因果环不锁信息。
- cⱼ∉(π/2)ℤ: 非Clifford，QCMI>0，因果环锁住信息。

**Clifford和非Clifford之间没有连续桥。** CFOL充要条件是一个离散分界，不cⱼ多接近π/2——只要不是严格等于，QCMI就是非零。这个非解析性不是微扰展开的artifact——它是Gram矩阵秩在整数×π/2处从1跳到>1的拓扑跃变。

### 现在考虑空间中的q场

不只是一个因果环。考虑整个信息邻接图上的q(x)和Cartan参数c(x)。空间有区域：

- **旋转区**: c(x) ∉ (π/2)ℤ，Cartan参数在连续变化。信息在因果环中流动。**量子活跃**。
- **非旋转区**: c(x) ∈ (π/2)ℤ，Cartan参数锁定。因果环不锁信息。**经典冻结**。

**关键问题**: 从一个区域到另一个区域，c(x)能平滑过渡吗？

## 1. 边界不可避免定理

### 定理陈述（猜想级，待严格证明）

> **在DGF的信息图上，若存在两个连通区域R₁和R₂，其中R₁中的因果环有c∉(π/2)ℤ（非Clifford/旋转），R₂中有c∈(π/2)ℤ（Clifford/非旋转），则R₁和R₂的界面Γ上必然存在非零QCMI，且该QCMI与界面面积成正比。**

### 论证骨架

**Step 1: 界面上的因果环**

在界面Γ上取四个格点：两个在R₁侧（旋转），两个在R₂侧（非旋转）。这四个格点之间的因果边构成跨界面因果环。环上的Cartan参数是两侧值的混合——一侧是连续c，一侧是离散π/2。

**Step 2: 混合Cartan不能全在(π/2)ℤ**

假设界面上所有跨界面环的等效Cartan参数都在(π/2)ℤ。这意味着两侧的c值受到强约束——旋转侧的连续c必须与离散π/2满足特定的匹配条件。对于一般的连续c分布，这种匹配不可能在全局成立——除非旋转区整体被约束为离散值（与"旋转区"的定义矛盾）。

**Step 3: CFOL → 界面上QCMI>0**

既然界面上至少有一个跨界面环的等效Cartan参数不在(π/2)ℤ，CFOL充要条件 ⇒ 该环的QCMI>0。

**Step 4: 界面的QCMI密度**

界面上每个格点参与多个跨界面因果环。每个跨界面环贡献η₀|c_eff-π/2|²的QCMI。界面上N_Γ个格点，每个参与~O(1)个跨界面环。总界面QCMI：

$$I_{\Gamma} \propto \eta_0 \cdot N_{\Gamma} \cdot \langle |c_{\text{eff}} - \pi/2|^2 \rangle \propto \text{Area}(\Gamma)$$

**QCMI是面的函数，不是体积的函数。** 这是面积律——与黑洞熵/全息原理的结构一致。

## 2. 边界上的信息凹陷（质量起源）

### 2.1 QCMI消耗可及信息

在每个信息格点上，总信息容量为1 bit。这1 bit的分配是：

$$1 = q + (\text{归档信息}) + (\text{锁在QCMI中的信息})$$

严格说不是"锁在QCMI中"——QCMI是三方纠缠的度量。但QCMI>0意味着三方之间不可约的量子关联，这些关联占用了格点的信息处理容量。等效地，格点的一部分容量被用来维护因果环的量子相干，这部分容量不能用来处理外部信息。

**QCMI>0 → 等效q降低**：

$$q_{\text{eff}} = q - \alpha \cdot \text{QCMI}$$

其中α是转换系数（量级~O(1)，需精确确定）。

### 2.2 边界上的q凹陷

在界面Γ上，QCMI>0 → q_eff < q_bulk。

界面的q_eff低于两侧体区的q。这就是**信息密度凹陷**。

$$A_{\Gamma} = \int_{\Gamma} (q_{\text{bulk}} - q_{\text{eff}}) dS \propto \text{Area}(\Gamma) \times \langle \text{QCMI} \rangle$$

### 2.3 质量就是凹陷的总归档信息

$$M = m_0 \cdot \frac{2}{\pi} \sin\left(\frac{\pi A_{\Gamma}}{2}\right)$$

对小质量（A_Γ ≪ 1）：

$$\boxed{M \propto \text{Area}(\Gamma) \times \langle \text{QCMI} \rangle}$$

**质量正比于边界面积乘以界面QCMI密度。** 这不是类比——这是从DGF公理+CFOL的直接推论。

## 3. 旋转、自旋、和粒子分类

### 3.1 旋转区 = 量子相干的几何

"旋转"在DGF中具体指什么？Cartan参数c沿因果环累积——信息每走一圈，相位旋转c。c=0是恒等，c=π/2是Pauli（Clifford），c=π/4是T门（非Clifford魔法的来源）。

一个区域"旋转"意味着：
- 该区域内的因果环有非平凡的Cartan参数c∉(π/2)ℤ
- 信息在环中传播时持续获得相位
- QCMI>0 → 环锁住信息 → 该区域保持量子相干

"不旋转"意味着：
- c∈(π/2)ℤ
- 相位累积是平凡的（±1或±i）
- QCMI=0 → 不锁信息 → 经典化

### 3.2 旋转的内部结构 → 自旋

一个粒子内部旋转区的Cartan参数c不是标量——它是σ_n̂⊗σ_n̂中的向量。n̂是Cartan轴方向。

- **自旋0**: 旋转区的Cartan轴分布是**各向同性的**。在所有方向上c的统计相同 → 无优先方向 → 标量粒子。
- **自旋1/2**: 旋转区有一个**优先Cartan轴**n̂。这个轴在3D旋转下变换为SU(2)的二重覆盖 → 旋量粒子。
- **自旋1**: 旋转区有一个优先方向，但在3D旋转下变换为SO(3)的矢量表示 → 矢量粒子。

**自旋不是"内禀角动量"——是旋转区Cartan轴分布的对称性类型。**

### 3.3 为什么不能线性过渡

c(x)从体区值到边界值的变化必须满足：

$$\Delta c = c_{\text{bulk}} - c_{\Gamma}$$

如果c_bulk ∉ (π/2)ℤ且c_Γ ∈ (π/2)ℤ（或反之），那么沿着任何连接两点的路径，c(x)必须穿过(π/2)ℤ的补集。在穿过时：

- CFOL: 中间所有c值都产生QCMI>0
- QCMI>0 → q_eff降低 → 信息归档加速
- 这个"惩罚"使平滑过渡在能量上不利

**最小作用配置**：c(x)在体区保持其值，在尽可能薄的界面内跳跃到(π/2)ℤ。界面厚度由两个竞争效应决定：
- 使界面薄：减少QCMI惩罚的体积 → 表面张力
- 使界面厚：减少c的梯度 → 梯度能量

平衡给出界面厚度δ ∼ 𝔩（格点间距）——**边界是原子级薄的。**

## 4. 边界的稳定性

### 4.1 边界为什么不自发消失

假设界面Γ上的一个格点试图将c从非Clifford值变为π/2（经典化）。CFOL充要条件：该格点参与的所有因果环的c都必须在(π/2)ℤ才能使QCMI=0。但该格点连接着旋转区——旋转区内有其他格点有c∉(π/2)ℤ。只要旋转区存在，界面格点的等效c就不能全在(π/2)ℤ → QCMI>0必须维持。

**边界不能被"抚平"——因为旋转区的存在使边界不可避免。**

### 4.2 旋转区为什么不自发消失

旋转区内部有c∉(π/2)ℤ。要使它经典化，所有c必须同时跳至(π/2)ℤ。这需要全区所有格点同时进行离散跳跃——在信息图上，等效于一个全局量子操作。在DGF中，信息只能沿边局部更新 → 全局操作的概率指数级小（∝exp(-N²)，N是旋转区内格点数）。

**旋转区是亚稳态的——它不能通过局部溢出消失。**

### 4.3 粒子的寿命

粒子（旋转区+其边界）的寿命由两个过程竞争：
1. **表面蒸发**: 边界格点逐个经典化 → 边界向内收缩 → 粒子缩小。速率 ∝ exp(-ΔI/k_B)，ΔI是单个格点的信息势垒。
2. **内部去相干**: 旋转区内偶然的全局Clifford化 → 整个粒子消失。速率 ∝ exp(-N²)，宏观物体N≫1 → 寿命 > 宇宙年龄。

## 5. 多个粒子

### 5.1 两个边界之间的相互作用

粒子A有边界Γ_A，表面QCMI密度I_A。粒子B有边界Γ_B，表面QCMI密度I_B。

当它们靠近时，A边界上的格点和B边界上的格点之间的信息溢出产生不对称：
- A边界格点感受到B方向的q梯度
- 这个梯度驱动信息从A的边界流向B
- 等效于A感受到指向B的力

这个力的强度 ∝ I_A × I_B / r²（两个面的QCMI相互作用），正比于 M_A × M_B / r²。**牛顿引力自动出现。**

### 5.2 合并

当两个粒子足够近（距离∼边界厚度），它们的边界开始重叠。重叠区的因果环包含来自两个粒子的格点 → 新的QCMI结构 → 边界重组。

两个粒子合并成一个更大的旋转区，包裹在新的边界内。总质量（总边界QCMI）在合并前后不一定守恒——取决于内部Cartan结构如何重组。这类似于核聚变/裂变的质量亏损。

## 6. 从真空中产生粒子

真空: q(x)=q_∞≈1, c(x)∈(π/2)ℤ 全局。QCMI=0处处——完美量子Markov态。

**量子涨落**: 一个局部区域的c值偶然偏离(π/2)ℤ → 瞬间非零QCMI → 瞬时q凹陷。

大多数涨落立即恢复——c跳回(π/2)ℤ，QCMI归零。但偶尔，涨落激发了一个**因果环网络**——相邻格点的c值相互耦合，形成自持的旋转区。

**这个自持的旋转区+其边界 = 一个新粒子。**

产生概率 ∝ exp(-S_instanton)，其中S_instanton是形成最小自持旋转区所需的信息动作。最小自持旋转区的尺寸由因果环的渗透阈值决定——需要多少个格点才能形成贯穿的旋转网络。

## 7. 总结：DGF的粒子图像

```
真空: q(x)=q_∞, c(x)∈(π/2)ℤ, QCMI=0处处
  │
  └─ 量子涨落 → 局部 c∉(π/2)ℤ
       │
       ├─ 瞬时: QCMI>0, q_eff局部降低
       │
       ├─ 通常: 立即恢复 → 真空涨落
       │
       └─ 罕见: 自持旋转区形成
            │
            ├─ 旋转区: c(x)∉(π/2)ℤ, 量子相干持续
            ├─ 边界Γ: |c旋转 - c非旋转| → QCMI>0 → q凹陷
            ├─ 凹陷深度 ∝ 界面QCMI密度
            └─ 质量 M ∝ ∫_Γ (q_bulk - q_eff) ∝ Area(Γ) × ⟨QCMI⟩
```

**粒子 = 真空中的一个自持旋转区，其边界上的QCMI积聚就是它的质量。旋转区内部的Cartan结构（对称性、轴方向、环拓扑）决定了粒子的自旋和相互作用性质。边界是CFOL定理的直接产物——旋转/非旋转不能平滑过渡。**
