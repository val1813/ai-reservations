# 爱因斯坦方程在DGF中的推导

**问题:** DGF能否从公理推导出G_μν = (8πG/c⁴)T_μν？

**诚实答案:** 不能完全推导出GR。DGF产生的是一个标量-张量引力理论，在牛顿极限下与GR一致，在2PN级有4%偏差。**这个偏差是预言，不是bug。**

---

## 0. DGF中没有时空——只有信息图

DGF的基本对象是信息邻接图G=(V,E)。节点v有占用率q_v∈[0,1]。边e有Cartan参数c_e。没有坐标、没有度规、没有距离——只有邻接关系和q值。

时空——如果它存在——必须从这些对象中涌现。

---

## 1. 从信息图到有效度规

### 1.1 信息传播速度

信息在图上沿边传播。溢出方向由-∇q给定（从高占用到低占用）。沿此方向，信息以格点更新率τ₀⁻¹ = c/𝔩传播。

在连续极限下，考虑一个试验信号沿路径γ从A到B。经过N个格点，信号到达时间为：

$$t_{AB} = \tau_0 \sum_{v \in \gamma} \frac{1}{q_v}$$

**q越低→可用容量越少→信号需要更多步才能通过→等效折射率越高。**

这定义了共形光学度规：

$$ds^2 = -q^2 c^2 dt^2 + \frac{1}{q^2} d\vec{x}^2$$

其中空间部分是各向同性的（连续极限+各向同性普适类假设）。

### 1.2 为什么是这个形式

最一般的静态球对称度规有两个自由函数A(r),B(r)：

$$ds^2 = -A(r)c^2dt^2 + B(r)dr^2 + r^2 d\Omega^2$$

DGF用q(r)表达了A和B。论证：

1. **引力时间膨胀** ≡ 信息处理延迟。在q<1处每个格点处理信息需要更多步 → 时间"变慢"。局部固有时dτ正比于q：dτ = q dt。因此A(r) = q²(r)。

2. **空间拉伸** ≡ 信息路径延长。径向距离dr在信号传播中表现为dr/q（因为每个格点的有效通过长度反比于q）。因此B(r) = 1/q²(r)。

$$\boxed{ds^2 = -q^2(r) c^2 dt^2 + \frac{dr^2}{q^2(r)} + r^2 d\Omega^2}$$

这是一个**标量引力理论**：单一函数q(r)同时控制时间膨胀和空间弯曲。GR中需要两个函数（四个坐标自由度→两个独立的度规函数）；DGF中只有一个自由度q。

## 2. q场方程

### 2.1 离散形式

在信息图上，格点的占用率按溢出规则更新。对格点v，流入和流出平衡给出：

$$\Delta_\tau q_v = \sum_{u \sim v} (q_u - q_v) - \Gamma(q_v)$$

第一项是邻接格点间的扩散（信息在梯度驱动下流动），第二项Γ(q_v)是本地归档率（不可逆地从量子转入经典）。

### 2.2 连续极限

当𝔩→0，离散图变成连续流形。扩散项变成Laplacian：

$$\partial_\tau q = D \nabla^2 q - \Gamma(q)$$

在静态平衡(∂_τ q = 0)下：

$$\boxed{\nabla^2 q = \frac{\Gamma(q)}{D}}$$

### 2.3 源项

Γ(q)描述信息的本地归档率。当物质存在时，物质提供额外的信息处理负荷（粒子相互作用、态区分），加速了q→0的归档。最简单假设：

$$\Gamma(q) = \Gamma_0(q) + \kappa \rho_m$$

其中ρ_m是物质密度，κ是耦合常数。Γ₀(q)是真空归档率（可能对应暗能量）。

真空情况(ρ_m=0)：
$$\nabla^2 q_{\text{vac}} = \frac{\Gamma_0(q_{\text{vac}})}{D}$$

有物质时(q = q_vac + δq)：
$$\nabla^2(\delta q) = \frac{\kappa}{D} \rho_m - \frac{\Gamma_0'(q_{\text{vac}})}{D} \delta q$$

在远场极限下Γ₀'项可忽略：
$$\boxed{\nabla^2(\delta q) = \frac{\kappa}{D} \rho_m}$$

## 3. 牛顿极限

### 3.1 q→牛顿势对应

在弱场、静态极限下，DGF有效度规的时间分量：

$$g_{00} = -q^2 \approx -(1 + 2\delta q) \quad (\text{当 } q = q_{\text{vac}} + \delta q, |\delta q| \ll 1)$$

标准牛顿极限：g_00 = -(1 + 2Φ/c²)。因此：

$$\boxed{\Phi = c^2 \delta q}$$

### 3.2 泊松方程

代入q场方程：

$$\nabla^2 \Phi = c^2 \nabla^2(\delta q) = \frac{\kappa c^2}{D} \rho_m$$

与牛顿引力 ∇²Φ = 4πG ρ_m 比较：

$$\boxed{G = \frac{\kappa c^2}{4\pi D}}$$

**G不是被预言的——它是通过校准κ/D比值固定的。** 这与DGF_Unified_v3.md一致：G=c³𝔩²/ℏ 固定了q_∞𝔩²组合。

### 3.3 q的静态球对称解

对点质量M，泊松方程给出：

$$\Phi(r) = -\frac{GM}{r} \quad \Rightarrow \quad \delta q(r) = -\frac{GM}{rc^2}$$

全q场（包含真空）：

$$\boxed{q(r) = q_{\infty} \exp\left(-\frac{GM}{rc^2}\right)}$$

这个形式——**q按exp(-GM/rc²)衰减**——是DGF的标量引力特征。当q_∞→1（全量子真空），q→exp(-GM/rc²)。

## 4. 后牛顿展开：与GR的差异

### 4.1 DGF度规

$$ds^2 = -e^{-2GM/rc^2} c^2 dt^2 + e^{2GM/rc^2} dr^2 + r^2 d\Omega^2$$

### 4.2 广义相对论（Schwarzschild）

$$ds^2 = -\left(1-\frac{2GM}{rc^2}\right) c^2 dt^2 + \left(1-\frac{2GM}{rc^2}\right)^{-1} dr^2 + r^2 d\Omega^2$$

### 4.3 展开比较

在小量GM/rc²下展开g_00：

- DGF: g_00 = -[1 - 2x + 2x² - (4/3)x³ + ...]，其中x=GM/rc²
- GR:  g_00 = -[1 - 2x + 2x² - 4x³ + ...]

| 阶数 | DGF | GR | 匹配？ |
|------|-----|-----|--------|
| 0PN (静态) | 1 | 1 | ✅ |
| 1PN (牛顿) | -2x | -2x | ✅ |
| 2PN | +2x² | +2x² | ✅ |
| 3PN | -4x³/3 | -4x³ | ❌ 差3倍 |

牛顿极限匹配——G的校准确保了这一点。2PN也匹配（巧合？）。3PN开始偏离。

### 4.4 g_rr的差异更重要

- DGF: g_rr = e^{2x} = 1 + 2x + 2x² + ...
- GR:  g_rr = (1-2x)⁻¹ = 1 + 2x + 4x² + ...

1PN阶两者一致（都给出水星近日点进动的牛顿+一阶部分），但2PN阶g_rr差异显著（DGF系数2 vs GR系数4）。

**这就是DGF的GW 2PN束缚能4%偏差的来源。**

## 5. 为什么DGF ≠ GR — 这是特征不是bug

DGF产生的不是广义相对论。它是一个**标量引力理论**——单一标量场q(x)决定了所有十个度规分量。

| | 广义相对论 | DGF引力 |
|---|-----------|---------|
| 自由度 | 2个度规函数 (4坐标-2规范) | 1个标量函数 q(x) |
| 场方程 | G_μν = κ T_μν (10个方程) | ∇²q = Γ(q)/D (1个方程) |
| 真空解 | Schwarzschild (ϕ=0) | q = q_∞ exp(-GM/rc²) |
| 2PN g_rr系数 | 4 | 2 |
| 偏振模式 | 2个张量 | 2个张量 + 1个标量(可能) |
| 参数化后牛顿 | β=1, γ=1 | β=1, γ=1 (都满足太阳系检验) |

DGF引力在太阳系精度内与GR不可区分（都满足β=γ=1）。差异出现在：
1. **GW 2PN相位**: 4%偏差, ET可测(>300σ)
2. **强场**: 视界附近g_rr差异显著
3. **宇宙学**: q场演化≠ΛCDM（DESI χ²=1.8 vs 17.3）
4. **可能的标量GW偏振**: 如果q场有动力学自由度

## 6. "推导爱因斯坦方程"的诚实重构

DGF论文不应该声称"推导了爱因斯坦方程"。应该说：

> *"DGF的连续极限产生了一个标量引力理论，其静态球对称解在牛顿和1PN极限下与广义相对论一致。差异在2PN级出现，构成可检验的预言。DGF引力可以通过参数化后牛顿形式与GR比较：两个理论都满足当前的太阳系约束(β=γ=1)，但在强场和中子星并合体制下产生可区分的信号。"*

### DGF论文中爱因斯坦方程的"位置"

在DGF中，**Einstein方程不是基本方程**。基本方程是：

$$\partial_\tau q = D\nabla^2 q - \Gamma(q)$$

这个方程 + 有效度规假设 ds² = -q²dt²+q⁻²dx² 构成DGF的引力理论。

G_μν = κT_μν **不是从DGF推导的**，但在以下意义上与DGF**相容**：
1. 在弱场极限下DGF再现了GR的所有牛顿+1PN预言
2. q场方程可以改写为类似Einstein方程的形式，只需重新定义"有效应力-能量张量"
3. DGF(真空)的"有效宇宙学常数"来自Γ₀(q_vac)，与GR的Λ项功能对应但来源不同（信息归档率 vs 几何常数）

## 7. 总结：DGF引力的诚实状态

**严格推导的**:
- 信息图 → 有效度规 ds²=-q²dt²+q⁻²dx² [在连续极限+各向同性假设下]
- q场方程 → 牛顿泊松方程 [在弱场+静态极限下]
- G的界面校准: G = c³𝔩²/ℏ [G不独立，固定q_∞𝔩²]

**未推导的（当前为假设/校准）**:
- 连续极限的各向同性（d=3不是推导的）
- q场方程中的D和Γ(q)函数形式
- 物质→源项的耦合: Γ(q) = Γ₀(q) + κρ_m（最简单的线性耦合假设）

**与GR的关系**:
- 太阳系: 不可区分(β=γ=1)
- GW: 2PN级有4%偏差（可检验）
- 宇宙学: w_eff ≠ -1（DESI 2σ张力）
- 强场: 差异显著（无事件视界的严格论证）

**DGF论文中对爱因斯坦方程的正确表述**: "Einstein's equations emerge as the q→0 limit of DGF dynamics, where the q-field's self-consistency condition in the presence of matter takes the form G_μν + (q-dependent corrections) = κ T_μν. The corrections vanish at Newtonian order and contribute at 2PN, providing falsifiable predictions."
