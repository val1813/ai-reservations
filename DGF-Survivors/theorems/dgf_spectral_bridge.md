# DGF普适性的谱图理论基础

## 核心问题

数值枚举无法"证明"普适性——只能提供证据。有效场论论证提供了普适性的物理理由，但缺少数学严格性。

**桥接点：** 图Laplacian的谱收敛到连续Laplacian是普适性的充分条件。这个问题在谱图理论中有成熟研究。

## 1. 图Laplacian的连续极限

### 已知定理（谱图理论）

设G_N是n=N³个节点的图序列，L_N是其归一化图Laplacian。

**定理（von Luxburg et al., 2008; Trillos et al., 2016）：**
若G_N以"一致局部收敛"的方式逼近3D流形，且边权重适当归一化，则L_N的特征值和特征函数收敛到连续Laplace-Beltrami算子的特征值和特征函数。

**具体条件：**
1. 节点从3D流形上的均匀分布采样
2. 边连接半径r_N满足r_N → 0且N r_N³/log N → ∞
3. 边权重按高斯核w_ij = exp(−|x_i−x_j|²/r_N²)设置

在此条件下，谱收敛是**保证的**——不需要枚举6种图，只需要验证这3个条件。

### 对DGF的启示

DGF信息图不需要"恰好"满足这些条件。只需：
1. 时空在大尺度下近似3D各向同性流形
2. 因果连接的密度满足r_N标度条件
3. 信息流权重随距离衰减

→ 图Laplacian必然收敛到连续Laplacian
→ 有效方程必然是∂_τ q = D∇²q − Γ(q)

## 2. 对墙3的简化

原墙3：需要枚举6种图验证普适性。
新墙3：需要验证DGF信息图满足谱收敛的3个条件。

| 原方案 | 新方案 |
|--------|--------|
| 枚举6种图 → 数值验证收敛 | 检查DGF图是否满足谱收敛条件 |
| 只能提供证据，不能证明 | 条件满足→收敛被定理保证 |
| 每种图~1000节点 | 只需分析DGF图的连接结构 |

## 3. 残余问题

1. **有效维度d_eff**: 谱维度可能与几何维度不同（如分形图、小世界图）。需要测量DGF信息图的谱维度。
2. **有向性**: DGF因果图是有向的。标准谱图理论对无向图。需要推广到有向图——这可能是真正的技术贡献。
3. **动态演化**: 信息图的连接结构是否随时间演化？如果是，需要证明准静态近似有效。

## 4. 最小可行验证

不需要6种图。只需要：
1. 从DGF模拟中提取信息图的连接结构
2. 计算图Laplacian的谱（特征值分布）
3. 检查是否满足Weyl律（3D的签名：特征值~k², 态密度~√λ）
4. 如果满足 → 谱维度=3 → 连续极限是3D扩散方程 → 普适性得证

**这是DGF组做不了的事——需要谱图理论的专业知识。**
