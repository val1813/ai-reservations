# 高维干涉图案 — 关键发现

**日期:** 2026-06-10
**数据:** high_d_interference.py, b1=1..8, c=0.05..1.52

## 发现1: 峰值在π/4，不是边界

```
c-scan at b1=5:
c=0.05: PR=1.05  (trivial, 无相互作用)
c=0.44: PR=11.94 (快速上升)
c=0.75: PR=31.98 ← 峰值! (≈π/4)
c=1.06: PR=18.81 (下降)
c=π/2:  PR=1.22  (Clifford, 经典)
```

**PR (参与率) 度量Gram矩阵特征值的"民主程度"。PR=32=2^5意味着所有32个系统态被环境同等程度地区分。PR=1意味着只有1个态被区分→经典。**

峰值精确在c≈0.8 rad ≈ π/4 — 这是√iSWAP的角度。

## 发现2: 不是单调的

原来我以为:
```
c越远离Clifford → QCMI越大 → 越量子
```

数据显示:
```
c=0 (无耦合):    经典 (PR=1)
c=π/4 (√iSWAP): 最大量子 (PR=32, b1=5)
c=π/2 (Clifford): 经典 (PR=1)
c→π (SWAP):     再量子→再经典?
```

**量子性在中间最大，两端趋近经典。** 这和直观相反——不是"越非Clifford越量子"，而是"在π/4处最量子"。

## 发现3: b1放大效应

```
c=0.5 (固定, 非Clifford):
b1=1: PR=1.84, d_eff=1.9
b1=5: PR=17.4, d_eff=22.2
b1=8: PR=91.5, d_eff=134.1

d_eff ≈ 2^(0.88·b1)
```

PR随b1指数增长。在b1→∞极限，d_eff → 2^{b1+1}（系统Hilbert空间全部维度）。

```
c≈π/2-0.1 (近Clifford):
b1=1: d_eff=1.1
b1=8: d_eff=2.1

d_eff barely grows
```

**近Clifford时b1不放大量子性。** b1放大的是"离Clifford的距离"——距离越大，每个新环比前一个环贡献更多有效维度。

## 物理图像重绘

之前画的图:
```
经典 ←───────────→ 量子
c=0,π/2          c=π/4
```

现在看到的:
```
c=0:      无相互作用 → 平凡经典 (没有信息交换)
c=π/4:    最大干涉 → 深度量子 (环境区分所有态)
c=π/2:    Clifford → 干涉完美相消 → 结构经典 (信息恰好抵消)
```

两个"经典"有本质不同:
- c=0的经典: **空洞的经典** (没有发生过任何事)
- c=π/2的经典: **结构化的经典** (发生了很多事但全部抵消了)

**宏观物质的经典性来自c→π/2——无数因果环的干涉精确相消，把量子信息锁死。**

## 最重要的推论

**RG流的正确方向:**

不是"Cartan参数flow向0"——
而是"Cartan参数flow向π/2的整数倍(Clifford点)"。

在Clifford点:
- QCMI=0 (CFOL)
- PR=1 (Gram矩阵秩=1)  
- d_eff=1 (环境只区分一个系统态)
- 系统完全经典

宏观物质之所以经典，不是因为"没有因果环"（它有~10^80个），而是因为**在RG流的红外固定点，所有因果环的有效Cartan参数都被锁定在Clifford点**。

这解释了为什么宏观世界是经典的: 不是因为量子力学在某个尺度失效了，而是因果环网络在RG流下的固定点恰好是Clifford点的集合体。
