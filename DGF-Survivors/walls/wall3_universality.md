# Wall #3 重新定义：从"收敛证明"到"普适性验证"

**三次失败的原因**: 试图证明离散→连续收敛——这是1960年代的已知定理，且需要DGF信息图是正则格点的假设。

**新角度**: 不需要证明收敛。需要证明**普适性**——任何满足DGF对称性的微观图在大尺度下都产生相同的有效q场方程。这是有效场论的逻辑，被整个凝聚态物理学验证过。

---

## 1. DGF的有效场论论证

### 对称性（从公理导出）

1. **信息守恒**: A1+A3→总归档信息A_tot守恒。对应的连续方程：∂_τ q + ∇·J = -Γ(q)
2. **局域性**: 信息只在相邻格点间流动。→动力学含导数展开，高阶项被𝔩/L抑制
3. **各向同性**: 无优先空间方向（工作假设）→矢量项∇q只能以标量组合∇²q出现
4. **q有界**: q∈[0,1]→Γ(q)在q→0,1时必须饱和

### 最一般的有效动力学

在标度L≫𝔩处，满足以上对称性的最一般演化方程（导数展开至最低非平凡阶）:

$$\partial_\tau q = D\nabla^2 q - \Gamma(q) + \mathcal{O}(\mathfrak{l}^2/L^2)$$

**D和Γ(q)的具体值依赖于微观细节。方程的形式不依赖。**

## 2. 暴力枚举验证普适性

不需要10⁹⁰个节点。枚举不同微观图结构，验证它们在粗粒化后产生相同的有效方程。

### 图结构枚举（6种）

| # | 图类型 | 节点数 | 描述 |
|---|--------|--------|------|
| G1 | 3D立方 | 10³=1000 | 正则格点，6邻居 |
| G2 | 3D随机几何图 | 1000 | 点随机分布，半径截断连接，平均度~8 |
| G3 | 3D小世界 | 1000 | 立方格点+10%随机重连 |
| G4 | 3D无标度 | 1000 | Barabási-Albert优先连接 |
| G5 | 3D六角密堆 | ~1000 | HCP格点，12邻居 |
| G6 | 随机3-正则图 | 1000 | 每个节点恰好度=3，无几何嵌入 |

### 动力学演化

对每种图：
1. 初始化：中心10%节点q=0.5（"质量源"），其余q=1.0
2. 迭代离散溢出规则：q_i(t+1)=q_i(t)+ηΣ_{j~i}(q_j-q_i)-γq_i(1-q_i)(源节点额外-0.01)
3. 运行至稳态（最大Δq<10⁻⁶）
4. 粗粒化：2×2×2块平均→有效格点
5. 重复粗粒化：→4×4×4→8×8×8→...

### 测量

在每一层粗粒化后：
1. 有效q场q_eff(x)的空间分布
2. 拟合q_eff(r)=A/r+B（对中心源）
3. 测量有效扩散常数D_eff和归档率Γ_eff
4. 比较6种图在相同粗粒化层级上的q_eff(r)——是否收敛到同一函数形式？

### 关键判据

**如果普适性成立**: 6种图在粗粒化2-3层后产生不可区分的q_eff(r)（R²>0.99互相之间），仅D_eff和Γ_eff的数值不同。

**如果普适性不成立**: 不同图产生定性不同的q_eff(r)（不同标度指数、不同函数形式）。

## 3. 期望结果

基于对称性论证：
- G1,G2,G5（各向同性3D）→ 粗粒化后收敛到相同形式，D_eff和Γ_eff不同
- G3（小世界）→ 可能有效维度≠3（长程连接改变谱维度）
- G4（无标度）→ 可能不收敛（高度节点产生非局域效应）
- G6（随机3-正则）→ 粗粒化后可能涌现3D结构（如果3-正则随机图在Bollobás意义上与3D立方同谱）

**关键**: 即使G3和G4失败，只要存在一大类图（包含我们认为"像3D空间"的那些）收敛到相同有效方程——这就是普适性。DGF只需要声明"信息图属于这个普适类"——不需要证明它一定是。

## 4. 对PRD论文的影响

**旧说法（需要放弃的）**: "从离散信息图严格推导出连续q场方程。"
**新说法**: "任何满足DGF对称性的微观图，在大尺度下的有效动力学普适地收敛到∂_τ q=D∇²q-Γ(q)。这是有效场论的标准论证，由6种图结构的暴力枚举支持。"

**Wall #3 重定义后的状态**: 从"证明收敛"（数学问题，可能极难）降为"验证普适性"（数值问题，可暴力枚举）。

**残余**: 有效维度d_eff的确定。G3（小世界）和G4（无标度）的失败表明并非所有图都给出3D——哪些图给出3D，DGF信息图属于哪类，仍是一个开放问题。但这不影响宏观q场方程的有效性——只需声明"信息图属于3D各向同性普适类"（与观测一致）。
