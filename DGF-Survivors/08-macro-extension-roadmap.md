# DGF 宏观推广路线图 — 从单因果环到宇宙

**日期:** 2026-06-09
**状态:** CFOL充要条件已完成。下一步：微观→宏观。

---

## 0. 当前立足点

CFOL 充要条件（刚完成）：对单因果环 (b₁=1, d=2)：
$$I(R;E'|Q')=0 \iff c_j\in\tfrac{\pi}{2}\mathbb{Z} \;\forall j$$

**这意味着什么？** 连续 Cartan 旋转（非 Clifford 门）必然产生非零 QCMI。QCMI 是"因果拓扑在量子态上留下的不可消除的签名"。

**但这是微观的：** 4-qubit 环，Planck 标度的 q 场，离"为什么宇宙是经典的"还有很长的路。

---

## 1. 需要破的墙（按递进顺序）

```
微观 (已完成)              介观 (下一步)               宏观 (目标)
─────────────              ──────────                 ─────────
单环 b₁=1, d=2   ──→   多环网络 b₁≫1    ──→    经典世界涌现

QCMI > 0 ⇔ 非Clifford   (η₀=1/(8ln2)≈0.180)       因果环网络不动点
```

### 墙 A: b₁>1 多环推广（P0，2-4周）

**问题:** 从单因果环推广到任意因果图 G，Betti 数 b₁(G) ≫ 1。

**当前状态:**
- 已证：边不相交环 → QCMI 严格可加（张量积可加性）
- 已证（微扰）：树边冻结引理（小 Cartan 极限，隐函数定理）
- 已知（数值）：共享节点干涉压低 QCMI 至 ~1.7× 而非 2×
- 未知：b₁≫1 时 QCMI 的渐近行为

**三个子问题:**

**A1: 树边冻结引理的全局证明。** 当前引理只在小 |c| 极限成立（隐函数定理）。需要推广到任意 |c|。可能的工具：
- Hasse 图特殊结构（三角形自由、二部性）消除 Jacobian 退化
- Cartan 结构的特殊性质 → 全局隐函数存在性

**A2: 共享节点干涉界。** 两个环共享节点时 QCMI ~ 1.7× 而非 2×。这个压低是否随 b₁ 增大而累积？
- 最佳情况：干涉是建设性且有限 → lim_{b₁→∞} QCMI/b₁ = const > 0
- 最坏情况：干涉累积 → QCMI/b₁ → 0（每个新环贡献递减）
- 关键数值实验：b₁=3,4,5 的 QCMI 标度

**A3: 渐近标度律。** QCMI(b₁) ~ η₀·b₁^α (η₀ = 1/(8 ln 2) ≈ 0.180 为多边环有效系数)，α=?

| 可能性 | α | 物理含义 |
|--------|:--:|---------|
| α=1 | 可加 | 每个独立环贡献 η₀(=1/(8ln2)) → 经典化 ∝ 因果复杂度 |
| α=1/2 | 平方根 | 扩散型→每个新环贡献递减 |
| α→0 | 饱和 | 有上限→因果拓扑不足以单独解释宏观经典性 |
| α>1 | 超可加 | 涌现增强→因果环网络产生协同效应 |

**推荐攻击路径:** sQNM 超可加性（Gangwar et al. 2025）+ b₁=3,4,5 数值扫描 → 确定 α。

### 墙 B: 因果图粗粒化 / RG 流（P1，3-6月）

**问题:** DGF 在 Planck 标度定义 q 场、因果环、Cartan 参数。物理可观测在实验室/宇宙学尺度上。两者之间有 ~10⁶¹ 的标度鸿沟。

**核心挑战:** 微观因果图 G（~10⁹⁰ 个节点）→ 粗粒化 → 有效因果图 G_eff（~10²-10⁶ 个节点）

**需要什么:**

**B1: Blocking 方案。** 将 N 个微观节点合并为一个宏观"因果单元"。关键问题：
- 粗粒化后 Cartan 参数如何流动？c_eff = f(c_micro, blocking_scheme)
- 粗粒化后 b₁ 如何变化？b₁_eff = g(b₁_micro, scale)
- 是否存在 RG 不动点？→ 涌现的连续 q 场是否普适？

**B2: 连续极限。** 微观格点上的离散 q 场 → 连续时空上的 q(x,t) 场
- 当前 LP40 尝试了数值 blocking 但统计不显著
- 需要：更大初始图 (N≥10⁵) + 更多随机种子 + 更好谱维度估计

**B3: Cartan 参数的 RG 流。** 微观上 c_j ∈ ℝ³ 是连续参数。粗粒化后，有效 Cartan 参数 c_eff 遵循什么流方程？
- 关键猜测：c_eff 流向 (π/2)ℤ（Clifford 点）→ QCMI→0 → 经典化
- 或流向远离 (π/2)ℤ → QCMI 增大 → 量子化
- **这可能是经典-量子分离的 RG 机制！**

**物理图景猜测:**
```
Planck 尺度: 所有因果环 c_j ~ O(1) (连续，非 Clifford)
    ↓ 粗粒化
介观尺度: 部分环 c_eff → (π/2)ℤ (QCMI 归零，经典化)
    部分环 c_eff 远离 (π/2)ℤ (QCMI 保留，量子化)
    ↓
宏观尺度: 经典世界 = Cartan 参数被 RG 流锁定在 (π/2)ℤ 的环网络
          量子世界 = Cartan 参数远离 (π/2)ℤ 的残留
```

### 墙 C: 经典性涌现判据（P1，3-6月）

**问题:** 什么条件下一个宏观系统"变得经典"？QCMI 和可观测经典性之间的关系？

**C1: QCMI ↔ 退相干速率。** LP32/36 的原始动机。CFOL 说 QCMI>0 意味着什么物理上可观测的现象？
- QCMI > 0 ↔ 非 Markovian 回流 ↔ 量子相干恢复
- QCMI → 0 ↔ Markovian 退相干 ↔ 经典性
- 定量问题：系统退相干速率 γ_dec 和 b₁ 网络中 QCMI 的关系？

**C2: 临界 b₁ 假说。** 是否存在 b₁* 使得：
- b₁ < b₁*：系统保持量子相干（QCMI 不足以驱动退相干）
- b₁ > b₁*：系统退相干到经典态（QCMI 累积压倒量子相干）

如果 b₁* ~ O(1) → 很小的因果环网络就能经典化
如果 b₁* ~ O(10²³) → 需要宏观尺度的因果复杂度

**C3: 指针基稳定性。** 在 b₁≫1 网络中，指针基 = 所有共享 Cartan 轴的交点方向。这个方向在粗粒化下是否稳定？是否被 RG 流加强？

### 墙 D: 从 DGF 回到物理可观测量（P2，长期）

**问题:** 如何用实验检验 DGF 的宏观预言？

**D1: 桌面量子模拟器。** 在超导 qubit 阵列上实现 b₁=2,3,4 的因果图 → 直接测量 QCMI → 验证标度律。当前 IBM/Google 平台有 50-100 qubit → 可实现 b₁~10-20。

**D2: 退相干速率预测。** DGF 预言 γ_dec ∝ QCMI(b₁, c_j, p)，标准 QM 预言 γ_dec 仅由环境耦合强度决定。在可控 b₁ 实验中区分两者。

**D3: 宇宙学连接（最远期）。** b₁(宇宙) ~ 10⁹⁰？q 场作为宇宙膨胀的驱动力？需要先完成墙 B（RG 流）。

## 3. 关键风险

| 风险 | 概率 | 影响 | 缓解 |
|------|:--:|------|------|
| b₁ 标度律 α→0（QCMI 饱和） | 中 | DGF 微观有效但不足以解释宏观 | 需要额外机制（环境耦合增强？） |

## 4. 最重要的一个方向

如果只选一个方向集中推进，选 **墙 A3: b₁ 标度律**。

**理由:** 
- CFOL 充要条件告诉我们单环的完整故事
- b₁ 标度律是多环故事的第一章
- α 的值决定 DGF 的宏观命运：
  - α≈1 → DGF 是经典化的完整机制
  - α→0 → DGF 只是拼图的一块
- 不需要 RG 流，不需要宇宙学，纯数值+理论
- 2-4 周可完成，产出可独立发表
