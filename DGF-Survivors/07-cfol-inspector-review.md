## INSPECTOR 审计

### I-1: 数值扫描的网格步长是否足够？

**检查:** p=0.5, c_j ∈ {0, π/16, ..., π}, 17⁴=83521点网格。QCMI零点只在 c_j ∈ {0, π/2, π}。步长 π/16 ≈ 0.196 rad。

**离网零点风险:** QCMI(c_j) 是光滑实解析函数（有限维量子熵 → 指数函数的组合）。Test C 展示了 QCMI 随 c 的曲线是抛物线型，零点间极小值 ≈ 0.6 bits。一个离网零点需要 QCMI 在 <0.2 rad 内从 >0.5 跌到 0 再升回来。对解析函数且 ∂QCMI/∂c 有界，不可能。

**扰动检验:** c=π/2+ε: ε=10⁻³ → QCMI=7.7×10⁻⁵, ε=10⁻⁴ → QCMI=1.0×10⁻⁶, ε=10⁻⁶ → QCMI=1.2×10⁻⁹。平滑二次型行为 → 无窄谷。

**裁决:** ✅ PASS。网格足够。

### I-2: p独立性 — 所有p都满足c_j∈(π/2)ℤ⇒QCMI=0？

**检查:** 测试了 p=0.1, 0.3, 0.5, 0.7, 0.9, 0.99，覆盖多个c_j组合 (mixed π/2 multiples, sign varied, π/π/0/0...）。全部 QCMI ≈ 10⁻⁹。

**理论原因:** 对c_j∈(π/2)ℤ:
$$e^{i\Delta\lambda} = e^{-2ic_2s_2} \cdot e^{-2ic_3s_4} = (-1)^{n_2} \cdot (-1)^{n_3} = (-1)^{n_2+n_3}$$
独立于 (s₂,s₄)。因此 Gram 矩阵的秩-1 条件对**任意** p 成立。

**裁决:** ✅ PASS。p 独立性已理论证明。

### I-3: 原 §4 声称 "Kraus rank 1" 是否正确？

**检查:** 对于 (π/2, 0, π/2, 0) 这种情况：
- K_{++} ∝ diag(-1,1,1,-1), K_{+-} ∝ diag(1,-1,-1,1)
- 两者不成比例 → Kraus rank = 2, ≠ 1!

**但 QCMI 仍然 = 0。** 机制是 diag(1,-1,-1,1) = -diag(-1,1,1,-1)，±1 因子在信道组合中平方为 1，信道等价于酉信道。

**修正:** 正确的充要机制是 "Gram矩阵秩=1"，不要求Kraus秩=1。原 §4 的证明虽然结论正确，但中间推理有误。需要在最终稿件中修正。

**裁决:** ⚠️ WARNING — 原 §4 证明需要重写。结论不变。

### I-4: 边界情况 p=0 或 p=1

**检查:** p→0 时 α_+→0, α_-→1。两个环境qubit都被制备在|-⟩态。p→1 时相反。

p=0 或 1 的极限: QCMI 公式中 S(EQ) 和 S(Q) 是否仍等于 2？

p=0: |γ⟩ = |-⟩。K_{++} = 0（因为 α_+=0），只有 K_{--} ≠ 0。信道只有 1 个 Kraus 算子 → 酉信道 → QCMI=0 对所有 c_j。

但数值上 p=0.001 时 QCMI 应该怎样？如果只有 c_j∈(π/2)ℤ 是零，p→0 的极限能给出 QCMI=0 吗？

p=0.001 时: K_{--} 占主导 (权重≈0.999²)，其他 Kraus 算子权重 O(10⁻³ 或 10⁻⁶)。信道接近酉信道 → QCMI 对所有 c_j 都应接近 0，而不只是 (π/2)ℤ。

这是否与我们的充要条件矛盾？**不矛盾**——p→0 (或 p→1) 极限下，QCMI 对所有 c_j 连续趋于零，充要条件退化。C[0,1] 的开区间 (0,1) 上，充要条件严格成立。

**裁决:** ✅ PASS — p∈(0,1) 开区间上充要条件成立。边界 p=0,1 是退化极限。

### R-1: "数值证明" 够不够？

**评论:** 83521 点数值扫描对物理学家是足够的证据，但不是数学证明。

**回应:** 审计 I-1 后，新发现了一个**严格解析证明**（审计过程中推导）：

**解析必要性证明：**

1. QCMI=0 ⇔ S(ρ_{RQ'})=0 ⇔ ρ_{RQ'} 是纯态 ⇔ Gram 矩阵 G 的秩=1

2. G_{s,s}=1（信道保迹）。秩-1 Gram 矩阵 → 所有 2×2 主子式为零 → |G_{s,t}|=1 ∀s≠t

3. G_{s,t} = Σ_{s₂,s₄} p(s₂,s₄) exp(iΔλ) 是凸组合。|凸组合|=1 ⇔ 所有项的相位相等 (mod 2π)

4. 对 s=(+,+), t=(+,-): Δλ = -2c₂s₂ - 2c₃s₄
   所有 (s₂,s₄) 的 exp(iΔλ) 相等 ⇒ -2c₂·(+1) ≡ -2c₂·(-1) (mod 2π) ⇒ 4c₂ ≡ 0 ⇒ **c₂ ∈ (π/2)ℤ**
   类似地 ⇒ **c₃ ∈ (π/2)ℤ**

5. 对 s=(+,+), t=(-,+): Δλ = -2c₁s₂ - 2c₄s₄ ⇒ **c₁ ∈ (π/2)ℤ**, **c₄ ∈ (π/2)ℤ**

**严格解析证明完成。** 不再依赖数值。∎

**裁决:** ✅ 升级为 ACCEPT — 现在有解析证明。

### R-2: 充分性方向的严格证明

**解析充分性证明：**

若 c_j = n_j·π/2 ∀j:
Δλ = -2c₂s₂ - 2c₃s₄ = -n₂πs₂ - n₃πs₄
exp(iΔλ) = exp(-in₂πs₂) · exp(-in₃πs₄)

因 s₂,s₄ ∈ {±1}: exp(±in₂π) = (-1)^{n₂} = exp(∓in₂π)。与 s₂ 符号无关！
同理 exp(±in₃π) = (-1)^{n₃} 与 s₄ 符号无关。

∴ exp(iΔλ) = (-1)^{n₂+n₃}，对**所有** (s₂,s₄) 相同。

G_{s,t} = (-1)^{n₂+n₃}，|G_{s,t}|=1。G 秩=1。QCMI=0。∎

**裁决:** ✅ ACCEPT — 充要条件已严格证明。

### R-3: 这个结果是否有物理意义？

**评论:** "Clifford 门给出 QCMI=0" — 这听起来像是 "只有特殊离散门能让因果环不产生非马尔可夫性"。这有物理意义吗？

**回应:** 是的。原本 CFOL v4 声称 "QCMI=0 ⇔ 所有边酉因子化"。这个声称是错误的（被 INSPECTOR 反例推翻）。

新结果更强：**QCMI=0 ⇔ 所有边酉是离散的 Clifford 门**（旋转角 = π/2 的整数倍）。

物理图景：因果环像一台干涉仪。连续的 Cartan 旋转（任何角度不是 π/2 整数倍的门）在环中产生不可消除的量子干涉 → 非零 QCMI。只有当旋转角精确地是 π/2 整数倍时（exp(iλ) 取 ±1），干涉图案完美相消 → QCMI=0。

这升级了 CFOL 从 "Cartan 失配 ⇒ QCMI>0"（必要条件）到完整的 "QCMI>0 ⇔ 非 Clifford 门"，给因果拓扑-量子非马尔可夫性的关系提供了精确的代数刻画。

**裁决:** ✅ 物理意义清晰——比原 CFOL 声称更强且更精确。
