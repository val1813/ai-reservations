## 一、原始北极星

即使熵账（Page 曲线、岛屿公式）正确，信息编码进 Hawking 辐射的**动力学微观机制**是什么？

**驱动矛盾：**

- 命题B（机制未被给出）：岛屿公式只告诉你"熵在 Page time 之后下降"，不告诉你"信息如何从黑洞内部 unitary 地搬运到外部辐射"

## 二、核心发现

**Proposition 1（Boundary-algebra separation）：**

在 post-Page SYK/JT code subspace 中，M.B（Missing Bit）的 O(1) relative entropy gap 是**边界代数定义依赖**的：

- **窄边界代数**（仅 SYK single-trace，不含 bath/radiation decoder）：存在 O(1) Petz relative entropy gap → M.B 成立
- **宽边界代数**（SYK∪bath/radiation，含 EW reconstruction 资源）：0 ≤ Δ_wide ≤ f(ε(N))，gap 受 QEC/Petz approximate recovery error 控制，无独立 O(1) gap → M.B 不单独给出新的 Lorentzian transport mechanism

**核心主张：** 岛屿公式 + 复制虫洞在宽边界代数中构成 algebraic recovery/bookkeeping——Page 曲线正确，但不等于"新的 Lorentzian unitary transport mechanism"。论文不否定岛屿熵公式或 Page 曲线的正确性。

## 六、对长命题 LP-6 的影响

LP6-S3（信息编码微观机制）的结论是：
> Boundary-algebra separation proposition：岛屿公式在宽代数中是 recovery/bookkeeping。论文将 M.B 的"机制是否存在"压缩为代数定义依赖。这是 L1 proposition，不是 L2 theorem。

**对 LP-6 其他子命题的影响：**
- LP6-S1（无质量引力中岛屿）：**无直接依赖**，S1 问的是引力侧（有无岛屿），S3 问的是信息侧（岛屿给出什么）。S3 的结论（recovery/bookkeeping）不取决于 S1 的结论（岛屿是否存在）
- LP6-S2（闪烁岛效应）：依赖 S1，不依赖 S3
- LP6-S4（de Sitter 推广）：部分依赖 S3（若岛屿只是 bookkeeping，de Sitter 中的对应需重新理解）

**LP-6 综合推导状态：** LP6-S3 的结论不改变 LP-6 核心矛盾的状态——它提供了信息侧的一个边界命题，但未回答引力侧的 S1（无质量引力中岛屿是否存在）。
