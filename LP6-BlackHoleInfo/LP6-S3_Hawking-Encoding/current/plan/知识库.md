- 来源: A 博士 §6 + ACMP 摘要原文

**K1.2** ⚠️L1（文献条件检查）— ACMP 2025 例子均含 "no external reservoir" 约束，AEMM 设置（含 non-grav bath）违反此前提。
- math_object: ACMP 例子边界
- 来源: A 博士 §6

**K1.3** ⚠️L1（物理论证：半经典 EOM）— JT 半经典 R(x)=−2/L² 恒定 → 曲率 scalar 不能区分 bulk 点 → ACMP 用 R 做 localizer 失效。
- math_object: JT 曲率不变性
- 来源: B 博士 §4.2

**K1.4** ⚠️L1（物理论证：HKLL + Almheiri-Polchinski 1402.6334）— JT dilaton φ(x,t) 渐近发散 + Schwarzian 模可重构 → 用 dilaton 做 ACMP localizer 时算符仍在 A_bdy 内。
- math_object: dilaton HKLL 重构
- 来源: B 博士 §4.2

**K1.5** ⚠️L1（标准结果：CPW 2022 + Leutheusser-Liu）— A_bdy = SYK 单迹 + H_R 在 large N 极限是 Type III_1 factor；加 Schwarzian clock crossed product 后是 Type II_∞。
- math_object: von Neumann factor type
- 来源: A+B 共同 §4 / §2.2

**K1.6** ✅L2（数学定理：Petz 1986）— Petz 单调性：对 vN 代数 N ⊆ M 与态 ω, ω₀，S(ω∥ω₀)|_M ≥ S(ω∥ω₀)|_N。故 A_island ⊋ A_bdy ⟹ S_rel|A_island ≥ S_rel|A_bdy。M.B 非平凡 ⟺ ∃ 态 (ω, ω₀) 使 Δ_M.B := S_rel|A_island − S_rel|A_bdy > 0。
- math_object: Petz 单调性
- 来源: A 博士 §3（PI 笔误澄清后）
- **唯一 ✅L2**：纯数学定理，不依赖任何物理假设

**K1.7** ⚠️L1（标度论证：HP scrambling + typical state）— post-Page 阶段，infallen qubit 在窄 A_bdy（仅 SYK 单迹）下的可分辨度 ≲ e^{−S_BH/2}（待 SYK 数值核 → CP-005）。
- math_object: Hayden-Preskill 量级
- 来源: A 博士 §5

**K1.8** ⚠️L1（物理论证：半经典 bulk JLMS）— post-Page 阶段，infallen qubit 在 A_island 中由局域 bulk field 直接读出，可分辨度 = O(1) ~ log 2。
- math_object: semiclassical relative entropy
- 来源: A 博士 §5

**K1.9** ⚠️L1（物理论证：HKLL + EW reconstruction，Almheiri-Polchinski 1402.6334 + AEMM 1411.7041）— 在 SYK/JT 中，A_island 由 island 内 HKLL 重构的 bulk 算符生成 ⊂ single-trace algebra ⊂ A_bdy（宽定义=SYK ∪ bath）。
