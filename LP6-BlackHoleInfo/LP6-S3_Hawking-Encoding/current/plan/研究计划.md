## 一、北极星命题（来自候选池）

**原始表述：**
即使熵账（Page曲线、岛屿公式）正确，信息编码进 Hawking 辐射的**动力学微观机制**是什么？

**驱动矛盾（候选池版本AB 4.5/6）：**
- **命题A（机制已被给出）**：信息编码机制已经由"复制虫洞 + 量子极端面（QES）跃迁 + ER=EPR/Hayden-Preskill scrambling 协议"联合给出。岛屿公式不是孤立的熵公式，而是一个等价的 unitary 编码描述——Penington 2019, Almheiri-Hartman-Maldacena-Shaghoulian 2019 的复制虫洞计算"看见"了拓扑相变即编码相变。Susskind 的 Python's lunch / complexity 协议给出可解码的具体程序。
- **命题B（机制未被给出，岛屿是 bookkeeping）**：岛屿公式只告诉你"熵在 Page time 之后下降"，不告诉你"信息如何从黑洞内部 unitary 地搬运到外部辐射"。没有从 bulk Hamiltonian 到 radiation Hilbert space 的具体 unitary 映射；没有微观可验证的相关函数预言。Raju 2025、Geng-Karch-Randall-Tajdini 等指出：复制虫洞是 Euclidean off-shell 配置，并未给出真实的 Lorentzian 演化机制。

## 二、合法性确认（三问）

**Q1: 驱动矛盾能写成"命题A vs 命题B，不能同时为真"？**
是。
- A：熵账正确 ⟺ 信息编码机制存在且已被给出（即"熵公式 + 复制虫洞 + Hayden-Preskill"足以构成 unitary 机制描述）。
- B：熵账正确 ≠ 信息编码机制存在；岛屿仅是"哪个鞍点占主导"的 bookkeeping，与 Lorentzian 单位化机制之间存在"解释鸿沟"（explanatory gap）。
两者关于"机制被给出"的定义不可调和。

**Q2: 解决后谁的工作会改变？**
- 量子引力社区（Penington, Almheiri, Maldacena, Susskind, Bousso, Chandrasekaran 等）——若 B 成立，岛屿"解决"悖论的标准叙述需修正
- 黑洞信息批判派（Raju, Geng, Karch, Randall, Tajdini, Suvrat Raju, Donald Marolf 部分立场）——若 A 成立，"AdS 玩具模型论证不可推广"的批评需要量化收缩
- 量子信息社区（Hayden, Preskill, Yoshida, Kitaev）——scrambling 协议是否构成"机制"的判据将被重新审视
- 共形场论 + 全息社区：JT/SYK 中"恢复信息"的明确程度向高维的可推广性
- 实验上：模拟黑洞（声学/光学/冷原子）的"信息恢复"实验声明可被定标

**Q3: 是技术推广还是新结构介入？**
新结构介入。问题不是"把岛屿计算扩展到更多模型"，而是问：
- 什么算"机制被给出"？（哲学+物理双层判据）
- 复制虫洞 Euclidean 配置如何对应 Lorentzian 单位演化？
- "scrambling 协议 + 熵下降"是否在数学上等价于"显式 unitary"？
这要求建立"机制存在"的可证伪判据——这是新结构。

## 三、精确化驱动矛盾

**命题A（机制已被给出，强版本）：**
存在一个判据 `M`，使得对 SYK/JT/AdS_2 玩具模型，岛屿公式 + 复制虫洞 + Hayden-Preskill 协议联合满足 `M`，从而构成"动力学微观机制"。具体可操作版本：
- `M.1` *Unitary 等价*：存在一个映射 `U: H_BH ⊗ H_rad → H_BH ⊗ H_rad` 使得 Page time 后辐射约化态恢复 unitary 性，且该映射在 1/N 展开内可被 bulk EFT + replica saddle 构造。
- `M.2` *相关函数预言*：辐射两点函数 `<a_ω a_{ω'}^†>` 在 Page time 前后表现出非平庸非热相关——可由岛屿/QES 跳跃定量预言。
- `M.3` *解码协议*：存在 polynomial-time（Python's lunch 修正后 sub-exponential）解码算法，输入辐射密度矩阵，输出 infallen-bit 信息。

**命题B（机制未被给出，强版本）：**
判据 `M` 至少有一项不被现有岛屿框架满足：
- `B.1` *Euclidean-Lorentzian gap*：复制虫洞是 Euclidean 鞍点；至今没有 Lorentzian 时间演化的完整 unitary 实现（Raju 2025；Geng-Karch-Tajdini 2025）。
- `B.2` *规范不变算符不可局域化*：在无质量引力中，岛屿区域内"局域算符"实际上不规范不变——因此"信息搬运到岛屿"的语句是 gauge artifact（Geng-Karch-Randall-Tajdini, arXiv:2506.04311）。
- `B.3` *"闪烁岛"病理*：Ageev 2024 中岛屈在某些参数下间歇性消失/复现，机制描述与"稳定的信息搬运通道"不兼容。

**为什么不能同时为真：**
A 声称熵公式 + 复制虫洞 + scrambling 协议联合"已经构成机制"；B 声称至少存在一个判据漏洞（`B.1` 或 `B.2` 或 `B.3`）。两者关于"机制存在"的判定不可调和——A 把这套工具组合解读为"机制"，B 解读为"bookkeeping + 未完成的工作"。
