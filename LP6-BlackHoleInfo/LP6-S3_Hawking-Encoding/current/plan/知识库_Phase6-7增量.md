# 知识库 Phase 6-7 增量

**K6.1** ⚠️L1（边界代数分离） - M.B 的 `O(1)` gap 是窄代数现象；宽 radiation/bath 代数中 gap 受 recovery error 控制。  
**K6.2** ⚠️L1（机制解释） - `Delta_wide≈0` 只说明 algebraic/Petz recovery，不等于 Lorentzian unitary transport。  
**K6.3** ⚠️L1（适用域限制） - Phase 6 命题只能写在 code subspace + chosen ensemble/weight + recovery map 假设下。

**K7.1** ⚠️L1（论文主命题） - LP6-S3 的可投稿核心是“岛屿机制主张依赖边界代数选择”。  
**K7.2** ⚠️L1（主张降调） - 论文应宣称 conceptual proposition / diagnostic lemma，不应宣称全局 no-go theorem。  
**K7.3** ⚠️L1（审稿风险） - 最大风险是 tautology objection：宽代数把 decoder 放进去后无 gap 可能被认为是定义结果。
