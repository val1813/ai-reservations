# 可观测性检验 — Hawking-Encoding v1

> 每个结论必须可证伪 + 可（原则上）观测。

## 核心可观测量候选

| 可观测量 | 命题 A 预言 | 命题 B 预言 | 现实可及性 |
|---------|-----------|-----------|----------|
| 辐射 von Neumann 熵 S_rad(t) | Page 曲线（已被复制虫洞预言） | Page 曲线（也被预言，但解释为 bookkeeping） | 模拟黑洞实验：声学/光学/冷原子 ~ 已部分实现 |
| 辐射两点函数 ⟨a_ω a_{ω'}^†⟩ 的非热修正 | 在 Page time 后出现 1/N 修正，可由 island 跳跃计算 | A 的预言 *也对*，但解释为 entanglement bookkeeping artifact 而非 dynamical | JT/SYK 数值模拟可达 |
| Page time 之后 OTOC 衰减率 | 与 Lyapunov bound + island scrambling 一致 | A 的预言 *也对*，是 unitary 的*必要*而非*充分*条件 | SYK 数值已有 |
| Decoding complexity（Yoshida-Kitaev） | Polynomial（HP+ Python's lunch 修正） | Sub-exponential / 实践不可解（BFV 论证） | 量子算法理论分析 |
| Ageev "闪烁岛"参数依赖 | 应在严格控制参数下不出现 | 出现在物理可达参数 → 机制描述失败 | 模型计算 |

## 区分判据（Phase 1 末完善）

预期：单一可观测量无法区分 A 和 B（这正是问题难解的原因）。需联合 ≥2 个量。

候选联合判据：
- Decoding complexity scaling × Page-time 后两点函数 → 若 polynomial scaling × non-thermal correlator 同时成立 → A
- Lorentzian-Euclidean continuation failure 量化 + 闪烁岛存在性 → 若任一非零 → B 加强
