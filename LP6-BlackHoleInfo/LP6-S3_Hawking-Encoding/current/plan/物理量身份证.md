## 核心物理量

### S_rad(t)：辐射 von Neumann 熵
- 定义：tr(ρ_rad log ρ_rad) ，ρ_rad = tr_BH (|Ψ><Ψ|)
- 单位：无量纲（自然单位 ℏ=k_B=1）
- 适用域：Page 曲线本身
- 来源：标准 QFT in CBG

### S_gen(I)：广义熵
- 定义：S_gen(I) = Area(∂I)/4G_N + S_matter(I ∪ R)
- 来源：QES proposal, Engelhardt-Wall 2014
- 适用域：岛屿公式 LHS

### A_island：岛屈面积
- 定义：极小化 S_gen 后的岛屈边界面积
- 在 SYK/JT 中具体可算

### S_island(t)：岛屉公式给出的辐射熵
- = min_I S_gen(I)
- Page 曲线下降段对应非平庸 island 主导

### U_encoding：（命题 A 待构造）信息编码 unitary
- 定义：U: H_in_BH ⊗ H_rad → H_in_BH ⊗ H_rad，使得 Page time 后 ρ_rad 是 pure state purification 的合适部分
- 状态：**待 Phase 2 A 博士构造，或 B 博士证明不存在**

### G_explanatory：解释鸿沟度量
- 定义（待细化）：从 S_gen(I) 到 U_encoding 的"距离"——可用计算复杂性、信息论可重构性、或 Lorentzian-Euclidean continuation 失败程度量化
- 状态：**待 Phase 1 苏格拉底定义**
