# 知识库 — NESS-MerminWagner v1

## Mermin-Wagner-Hohenberg定理基础
- 定理内容：d≤2维系统中，连续对称性不能在有限温度下自发破缺（无LRO）
- 证明核心：Bogoliubov不等式 + Gibbs态假设ρ∝e^{-βH}
- 关键前提：(1)热平衡态 (2)短程相互作用 (3)连续对称性
- 物理机制：Goldstone模的热涨落在d≤2中对数发散→破坏LRO

## 非平衡稳态(NESS)中的对称性破缺
- NESS由Lindblad主方程描述：dρ/dt = -i[H,ρ] + Σ(L_α ρ L_α† - {L_α†L_α,ρ}/2)
- 稳态ρ_ss ≠ e^{-βH}/Z（非Gibbs态）
- Bogoliubov不等式的前提P（Gibbs态）失效→定理沉默
- "沉默"≠"被推翻"：P失效不保证结论C（无SSB）也失效

## 激子极化激元凝聚体
- 半导体微腔中光子+激子的混合准粒子
- 有限寿命（~ps级）→需要持续泵浦维持→本质非平衡
- 实验观测：BKT行为（准长程序，代数衰减关联函数）
- 关键问题：这是真正的SSB还是有限尺寸效应？

## Vicsek模型/Toner-Tu理论
- 2D经典非平衡极性集群（自驱动粒子）
- Toner-Tu (1995)证明：2D活性物质可以有真正的LRO（打破MW！）
- 机制：对流非线性v·∇v使Goldstone模的涨落被压制
- 关键：这是经典结果，量子对应不平凡

## Imry-Ma效应
- 在有随机场（无序）的系统中，d≤4维连续对称性的LRO被破坏
- Imry-Ma长度：L_IM ~ ξ exp(c J²/h²)，其中h是无序强度
- 若L_IM < L_system：无序破坏LRO（即使NESS允许SSB）
- 极化激元系统的无序来源：腔厚度涨落、量子阱界面粗糙度
