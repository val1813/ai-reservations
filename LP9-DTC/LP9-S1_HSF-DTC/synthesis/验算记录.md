## 第一步：逐步代数验算

### F-A1 — Wedderburn 分解与块计数 ✓（轻微：记号）

标准 Wedderburn–Artin / 双交换子定理：对 *-封闭代数 A 作用的 Hilbert 空间分解为
  H = ⊕_λ ( C^{d_λ} ⊗ C^{m_λ} )，
其中 d_λ 为不可约表示维数，m_λ 为其重数。在此分解下
  A   = ⊕_λ ( M_{d_λ}(C) ⊗ I_{m_λ} )      （在 d_λ 因子上满矩阵，重数因子上恒等）
  C=A' = ⊕_λ ( I_{d_λ}     ⊗ M_{m_λ}(C) )  （交换子：重数因子上满矩阵）
故 **dim C = Σ_λ m_λ²**。代数正确。✓

- **轻微（记号）**：任务原文写「H=⊕_λ(M_{d_λ}⊗I_{m_λ})」把*代数 A* 的分解写成了 H 的分解。H 应为 ⊕(C^{d_λ}⊗C^{m_λ})，⊕(M_{d_λ}⊗I_{m_λ}) 是 A 本身。结论 dim C=Σm_λ² 不受影响。
- **下界 dim C ≥ #Krylov块**：每个 Krylov（动力学不连通）扇区的投影算符均与全体动力学对易 ⟹ 属于 C，且彼此线性独立。又 dim C=Σm_λ² ≥ Σ_λ 1 = #{λ} = #块（因 m_λ²≥1）。故 dim C ≥ #块。✓
- **#块 ~ exp(sL)**：强 HSF 的定义性特征即不连通扇区数随系统尺度指数增长，s>0 为构型熵密度。标度形式合理。✓ s 的具体数值依赖模型 ⟹ **未验算（常数）**，但 exp(sL) 标度自洽。

### F-A2 — 周期倍化算符代数 ✓（已逐项确认）

X=∏_j σ^x_j：幺正且自伴（X²=I, X†=X，各 σ^x 自伴且互易）。X 翻转所有 σ^z 本征态 ⟹ 把构型类 K 映到翻转类 K̄。
  **X P_K X† = X P_K X = P_{K̄}**。✓（X 与 P_K 不对易，处理方式正确：用 X P_K X=P_{K̄}，未误设对易）

O⁻_K = P_K − P_{K̄}。U_F = X e^{−iHT}，U_F† = e^{+iHT} X。
逐步：
  U_F† O⁻_K U_F = e^{iHT} X (P_K−P_{K̄}) X e^{−iHT}
        = e^{iHT} (P_{K̄}−P_K) e^{−iHT}              [用 X P_K X=P_{K̄}, X P_{K̄} X=P_K]
        = −e^{iHT} O⁻_K e^{−iHT}
        = −O⁻_K                                       [用 [H,P_K]=[H,P_{K̄}]=0]
故 **U_F† O⁻_K U_F = −O⁻_K**，Heisenberg 演化 O⁻_K(nT)=(−1)ⁿ O⁻_K
  ⟹ **⟨O⁻_K(nT)⟩=(−1)ⁿ⟨O⁻_K(0)⟩**（2T 次谐响应 = DTC 签名）。✓

- **关键前提（须显式声明）**：上式用到 e^{iHT}O⁻_K e^{−iHT}=O⁻_K，即需 **[H,P_K]=0 与 [H,P_{K̄}]=0 同时成立**。前者因 K 为 H 的 Krylov 扇区自动成立；后者要求 K̄=XK 亦为 H 不变扇区，即「碎裂连通结构具翻转对称性」。当 H 中生成连通性的部分（关联跳跃等）翻转对称时成立（即使 H 含非对称场）。**该条件是否被模型满足属物理判断 ⟹ 未验算；在此条件下代数步骤完全正确。**

### F-A3 — Fermi 黄金规则速率 ✓（intensive 依赖物理假设）

标准 FGR（微扰 H'=λV，ℏ=1）：
  Γ = 2π Σ_f |⟨f|H'|i⟩|² δ(E_f−E_i) = **2πλ² Σ_f |⟨f|V|i⟩|² δ(E_f−E_i)**。形式正确。✓
- **intensive 声称**：V 为局域算符 ⟹ 与 |i⟩ 局域相连的终态数 f 为 O(1)，求和 Σ_f|⟨f|V|i⟩|²δ(·) 收敛到局域谱密度 ρ_loc(E)（intensive）。故 Γ~λ²ρ_loc 与 L 无关，τ~1/Γ~1/λ²。代数/标度自洽。✓
- **未验算（物理）**：「局域 DOS 为 intensive 且连续」要求存在准连续的浴谱。该假设属物理判断，本验算不裁决；仅确认在此假设下 Γ intensive、τ~1/λ² 的代数推导成立。

### F-A4 — 综合寿命量纲一致性 ⚠️（自然单位下自洽，复原单位需前因子）

τ ~ min( exp(cω/J), 1/(λ²+ε²), exp(c'L) )。逐项查量纲：
- exp(cω/J)：cω/J 无量纲（ω,J 同为能量）✓，但 **exp(·) 本身无量纲，非时间**。
- exp(c'L)：c'L 无量纲 ✓，**exp(·) 无量纲，非时间**。
- 1/(λ²+ε²)：欲为时间需 λ²,ε² 具能量量纲（ℏ=1 时 1/能量=时间）。但 F-A3 中 λ 作为无量纲耦合乘 V。

**⚠️ 偏差（量纲齐性）**：min() 内三项若按字面取，不同量纲（两项无量纲、一项时间），不能直接取 min。修正：指数项须配微观时间前因子 τ₀~1/J，且 λ,ε 视为能量/速率：
  τ ~ min( τ₀ e^{cω/J}, 1/(λ²+ε²), τ₀' e^{c'L} )。
这是 prethermalization 加热时间 t*~(1/J)e^{cω/J} 的标准写法。**在 ℏ=J=1 自然单位下三项均为「以 1/J 为单位的纯数」，彼此可比，结构正确（min = 加热/FGR/碎裂三通道取最短）。** 故为约定层面的量纲松弛，非实质错误。严重程度：轻微/⚠️。

### F-B1 — 对角能量与畴壁 ✓（具体构型已核）

H_zz=V Σ_j σ^z_j σ^z_{j+1}，σ^z=±1。设对齐键 s_j s_{j+1}=+1、畴壁键=−1，n_dw=畴壁数：
  Σ_j s_j s_{j+1} = (N_bonds−n_dw)·(+1) + n_dw·(−1) = **N_bonds − 2 n_dw**。
故 **ℰ_I=V(N_bonds−2 n_dw(I))**。✓

具体构型核验（开链 4 site，3 键）：
- ↑↑↓↓：键 (+,−,+) ⟹ n_dw=1，Σ=+1，N−2n=3−2=1 ⟹ ℰ=+V。✓
- ↑↓↑↓：键 (−,−,−) ⟹ n_dw=3，Σ=−3，N−2n=3−6=−3 ⟹ ℰ=−3V。✓
- **ΔE_zz = (−3V)−(+V) = −4V**。✓（亦可由 Δn_dw=+2、ΔE=−2V·Δn_dw=−4V 复核）

**F-B1 完全正确，ΔE_zz=−4V 验证通过。**

### F-B2 — 二阶简并耦合 ✓

二阶微扰：g_eff = Σ_m ⟨f|H_xy|m⟩⟨m|H_xy|i⟩ / (E_i−E_m)。H_xy~J（自旋翻转/跳跃），虚态 |m⟩ 违反畴壁约束，能量分母 ΔE~V。
  **g ~ J·J / V = J²/V**。✓
量纲：[J²/V]=能量²/能量=能量 ✓（g 为有效耦合，能量量纲正确）。

### F-B3 — Fock 空间渗流阈值 ✓（轻微：1/z vs 1/(z−1)）

Bethe 格（Cayley 树）配位数 z：标准渗流阈值 **p_c=1/(z−1)**。✓
巨分量判据 (分支数)×(占据概率)>1，即 z_leak·p_mix>1。
- z_leak~O(L)，p_mix~O(1) ⟹ z_leak·p_mix~L≫1（远超阈值）。
- p_c ~ 1/z_leak ~ 1/L → 0（L→∞）。✓
- **轻微**：严格阈值 1/(z_leak−1)，文中用 1/z_leak；z_leak~O(L) 大时二者渐近相等，标度结论 p_c~1/L→0 不变。✓

### F-B4 — 动力学寿命 (V/J)^(L/2) ✓（⚠️ 前因子；指数偏移属计数约定）

构造：跨系统漏跳需 ~L/2 步，每步离共振压制因子 (J/V)。设单步率 r~J/V，n=L/2 步级联：
  τ ~ 1/r^n = 1/(J/V)^(L/2) = **(V/J)^(L/2)**。✓ 指数构造代数自洽。
- **⚠️ 量纲**：(V/J)^(L/2) 无量纲，复原单位需前因子 τ₀~1/J（同 F-A4），自然单位下为「以 1/J 为单位的纯数」。
- **与源论文 (V/J)^(L/2−1) 偏差**：差一个因子 (V/J)¹，属端点/计数约定（site 计 vs bond 计、首尾跳是否计入）。**指数主阶 c=1/2 一致，(V/J)^{O(L)} 量级吻合**；精确偏移须模型细节 ⟹ 未验算（精确），主阶吻合成立。

## 第五步：交叉检查 —— τ~1/λ²（A）vs τ~(V/J)^(L/2)（B）变量对应分析

**问题**：两式函数形式不同（幂律 1/λ² vs 指数 (V/J)^{L/2}）、尺度依赖不同（intensive vs exp-in-L）、变量不同（λ vs V）。是描述不同扰动通道，还是真矛盾？（仅做变量对应 + 量纲，不做物理裁决）

**(1) λ 与 V 各对应什么（角色）**
- **λ（A）= 显式「运动学」约束破坏耦合**：H=H_frag+λV，λ 给扇区间外加矩阵元（动力学连接）。无微扰系统*精确*碎裂。清洁极限 **λ→0**。
- **V（B）= 「能量学」约束强制能标**：无独立 λ；约束违反就是 J-跳跃本身，被能隙 ~V 压制。清洁极限 **V→∞（J/V→0）**。
- 二者*角色相反*：小 λ ↔ 大 V 均 = 强约束。**它们不是同一参数，λ≠f(V) 不存在简单一一对应。**

**(2) V→∞ 与 λ→0 是否同一清洁极限**
- 同一*物理*清洁极限（完美约束、零弛豫、τ→∞），但经*不同微观参数*抵达：λ→0 给 τ_A→∞；V→∞ 给 τ_B→∞。**方向自洽。** 但 λ 与 V 是不同变量，非同一量。

**(3) 两式能否同时自洽 —— 关键观察**
注意 **F-A4 的 min() 本身就同时含 1/λ² 项与 exp(c'L) 项**。而
  (V/J)^(L/2) = exp[(L/2)·ln(V/J)] = exp(c'L)，   c' = ½ ln(V/J) > 0（V>J）。
即 **B 的 (V/J)^(L/2) 恰是 A 的 exp(c'L) 碎裂项**；A 的 1/λ² 是 FGR 项。真实寿命取最短：
  **τ ~ min( 1/λ² , (V/J)^(L/2) )**。
- 二者是*竞争通道*，非矛盾：
  - λ 可观时 → 局域 FGR 通道 τ_A=1/λ²（intensive）更短，主导 ⟹ L 无关的有限寿命；
  - λ=0（纯能量约束）时 → FGR 通道缺失（或有效 λ_eff 本身指数小）⟹ exp-in-L 通道 τ_B=(V/J)^(L/2) 主导。
- **「intensive vs exp-in-L」正是两个不同通道的预期行为**，不是冲突。

**(4) 二者是否同一通道（反向核验）**
若强行把能量学机制的系统贯穿隧穿幅当作有效运动学耦合 λ_eff~(J/V)^{L/2}，则 A 式给 1/λ_eff²~(V/J)^L ≠ (V/J)^{L/2}（指数差因子 2）。**说明 A 的 λ 是*裸局域*耦合、B 的是*集体*幅度，二者并非同一通道**，naive 等同会差因子 2，故不应等同。

**交叉检查结论**：**自洽，非矛盾。** 两式描述两条不同弛豫通道（局域-FGR vs 集体-能量），二者本就并列于 A 的 min() 公式中；真实寿命 = 二者取最短。共享同一物理清洁极限（λ→0 且 V→∞ 均 τ→∞），但 λ、V 为不同微观参数、不可简单相互识别（强行识别差指数因子 2）。
