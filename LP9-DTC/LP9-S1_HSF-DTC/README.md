# LP9-S1：无MBL的DTC——希尔伯特空间碎片化替代方案

**所属长命题：** LP-9 离散时间晶体：真正非平衡相还是Floquet微调赝象？

**子命题北极星（候选池原文）：**
传统DTC稳定性需要MBL。但MBL本身的热力学极限存在性受质疑(LP-1)。Tang & Li (2025)提出强希尔伯特空间碎片化（HSF）可替代MBL。碎片化-DTC在热力学极限下是否真正稳定？

**驱动矛盾（PI苏格拉底精确化后，见研究计划.md）：**
- 命题A：HSF的commutant守恒量代数等价于MBL的l-bit，在Floquet驱动下产生刚性的Z₂时间平移对称性破缺 → HSF-DTC是真正的非平衡相。
- 命题B：HSF守恒量在约束违反扰动下仅近似守恒，碎片以FGR速率~λ²连接 → HSF-DTC是预热瞬态；或HSF-DTC是初态依赖的scar-like现象，非相空间有限区域的相。
