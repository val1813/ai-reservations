# LP9-S3 Phase 1 推导作业（A博士 / 正规军）

**子命题 LP9-S3：** Prethermal DTC 的热化时间尺度。序参量存活时间 τ∝exp(ω/J) 是否普适？是否有非普适修正？τ 的解析下界对任意局域扰动是否成立？三类 DTC（MBL / prethermal / HSF）的 τ 标度能否统一？

**框架（本Phase规定，不更换）：** Floquet–Magnus 展开（最优截断）+ 严格预热定理（算符范数界 / quasi-local norm bound）。

## 【PI审核入口】

⚡**本Phase结论：** "τ∝exp(ω/J)" **不是普适等式，只是通用下界（floor）**。精确陈述分三层：

1. **下界普适、∝退为≥（D3核心）：** Abanin 严格预热定理给**能量加热寿命**下界 τ_E ≥ τ_0·exp(cω/J)（严格版准指数 exp(cν/log³ν)），c 依赖 ‖h_i‖/相互作用程/配位数，**对任意 k-局域有界扰动成立**——但这是**下界**（寿命≥），不是等式。文献(HSF反例)证真实 τ 可远长于此下界且与 ω 无关，故"∝"必须退为"≥"。
2. **三类天花板统一（D1核心novel）：** (a) **MBL-DTC**：l-bit 严格局域守恒 → τ 真∞（L→∞ 严格局域化）或 exp(cL)（有限局域化长度）；初态无关，本征态序。(b) **prethermal-DTC**：无需 MBL/HSF，纯高频 → τ~exp(cω/J)（Abanin 天花板）；初态依赖（须<T_c）。(c) **HSF-DTC**（S1）：τ~min(exp(cω/J),1/λ²,exp(c'L))，频率非主导。**统一命题：所有"非-MBL-本征态序"DTC 都被某个 exp(参数) 天花板限制，无一在 generic + 热力学极限 + 有限驱动下真∞。**
3. **序参量 vs 能量寿命的双向边界（D2）：** Else-Bauer-Nayak 证 τ_OP≥τ_E（初态<T_c，emergent Z_N 保护，序参量不更短）；本作业补反向边界：初态能量密度>T_c（落在 H_eff 的对称未破缺/平庸相）时序参量在能量加热前先退相，τ_OP<τ_E（pre-dephasing）。判定边界 = H_eff 的 SSB 临界温度 T_c。

⚡**最脆弱的一步：** §N步2的 **pre-dephasing 边界（T_c阈值）的"先死"方向**。我断言初态能量密度>T_c 时序参量寿命 τ_OP<τ_E（频率无关的 τ_pre 主导）。这依赖"H_eff 在该能量密度处不破缺次谐波对称 → 序参量无 emergent 保护 → 由 O(1) 阶平衡弛豫衰减"。但 τ_pre 的精确标度（是否真与 ω 无关、是否真短于 exp(cω/J)）我只给标度论证，未对具体模型数值确认 prethermal 平台高度。立为**卡点1**。F3/F5 实测暗示 trivial 相下 M(t) 快速衰减"significantly faster than τ*"，方向支持，但定量边界待数值。

⚡**预测vs实际：** 预测前(§1)：核心标度是先发定理（exp(ω/J)），本作业 novel 限于 D1–D4，"∝"应退为"≥"，HSF 是判决性反例。实际推导**一致**。**一个意外**：撞墙(§2)用 HSF-DTC 反例攻击"τ∝exp(ω/J)普适"时发现——HSF 的频率无关性不仅否证"∝普适"，还反向**强化** D1 统一天花板：它证明 exp(cω/J) 只是 prethermal 这**一类**的天花板，三类各有不同天花板恰是统一表的内容，故反例非削弱而是 D1 的支柱。记入§2。

⚡**PI需关注的问题：**
1. 卡点1（命门）：pre-dephasing 边界 T_c 阈值下"序参量先死"的 τ_pre 标度，需具体 prethermal 模型（如 F5 离子链或 kicked Ising）数值确认 τ_OP<τ_E 且 τ_pre 频率无关。
2. D1 统一表中 MBL-DTC 的"真∞"是理想极限——任意有限局域化长度 ξ 与相互作用尾部使 τ~exp(cL) 而非严格∞，PI 须裁定统一表用"理想∞"还是"exp(cL)"作 MBL 栏（本作业两者并列，标注条件）。
3. D3 共振短路（ω≈能隙整数倍 → Magnus 发散 → 天花板坍缩）是否被 DTC 的子谐波驱动设计天然排除——我断言是（π-脉冲把驱动放在子谐波而非局域能隙），但长程/多频驱动(F8双频)可能重开通道，留卡点2。
4. 真相 vs 预热判定：与 S1/S2 合并，prethermal-DTC 明确判为**预热赝象**（频率指数 L-无关 → 有限ω下 L→∞ 加热率不灭）。PI 须确认此判定与 LP-9 主命题（命题B方向）一致。

## §2 强制撞墙（攻击我自己的核心声张）

我的核心声张（§0-A/B）：prethermal-DTC 序参量寿命 ≥ exp(cω/J)，且三类 DTC 各有 exp(参数) 天花板。**最强反对直击"τ∝exp(ω/J) 普适"——但注意我已在 §0 把 ∝ 退为 ≥，故撞墙须攻击更深的核心：连"≥exp(cω/J)作为下界对所有 DTC 普适"也可被 HSF 证伪。**

**反例（HSF-DTC：判决性反例，τ 与 ω 无关）：**
> "S1 已证 HSF-DTC 寿命 τ~min(exp(cω/J),1/λ²,exp(c'L))，其中 1/λ² 与 exp(c'L) 两项**与 ω 完全无关**——HSF 文献(arXiv:2512.14182)明确'markedly differs from prethermal DTCs, where the lifetime typically exhibits an exponential dependence on the driving frequency'。在 λ→0 清洁极限，τ~exp(c'L) 由**穿越碎片壁的 (L/2) 阶虚跃迁**设定（有效耦合 V_eff~J^{L/2}/V^{L/2−1}），频率 ω 根本不进入。故'τ∝exp(ω/J)'作为**等式**被 HSF 单点证伪——HSF-DTC 在固定 ω 下改变 L 寿命指数变化，而 exp(cω/J) 预言寿命与 L 无关。这不是修正，是机制级别的判决性反例。"

这是真正有力的反对（不是弱反例）：它有 S1 自有推导 + arXiv:2512.14182 正面背书 + 明确的"与 prethermal 标度迥异"陈述。

**反例的命运（不是被反驳，而是被吸收为 D1 支柱）：**
1. **承认反例对"∝普适"成立。** HSF 确实证明"τ∝exp(ω/J)"作为**适用于所有 DTC 的等式**为假。这正是 §0 把 ∝ 退为 ≥ 的理由——但 HSF 走得更远：连"exp(cω/J)作为下界对所有 DTC 普适"也不对，因为 HSF 的天花板可以是 exp(c'L)（L-型）而非 exp(cω/J)（ω-型），两者在固定另一参数时标度不同。
2. **但反例不削弱本作业，反而是 D1 的支柱。** 本作业声张的**不是**"exp(cω/J) 普适"，而是 **D1 统一天花板命题：三类 DTC 各被某个 exp(参数) 限制，机制不同则天花板参数不同**。HSF 的 exp(c'L)/1/λ² 恰是"HSF 这一类的天花板参数 ≠ prethermal 类的 ω/J"——这正是统一表要陈述的内容。**反例否证的是错误的强声张（普适等式），证实的是本作业的正确声张（分类天花板）。**
3. **唯一真正威胁本作业的，是"存在某类 DTC 在 generic+热力学极限+有限驱动下真∞"。** 检查三类：MBL 的"真∞"仅在**理想严格局域化**（ξ 有限但相互作用尾部为零），任意 generic 扰动使尾部非零 → Imbrie 型论证给 τ~exp(cL) 而非∞（且热力学极限 L→∞ 才∞，有限驱动有限 L 下有限）；prethermal 有限(exp(cω/J))；HSF 有限(1/λ²)。**无一类在 generic+热力学极限+有限驱动三条件同时满足下真∞。** 统一命题存活。

**结论：** 撞墙成功暴露"∝普适"与"下界普适"两个错误强声张并已在 §0 规避；HSF 反例被正确吸收为 D1 统一天花板的支柱而非反证。**维持核心声张（D1–D4），但 §N 须显式把 exp(cω/J) 标注为"prethermal 类天花板"而非"普适律"。** 撞墙的一个收获（记入 PI 入口意外）：反例与声张的关系是"否证强版、证实弱版"，故 §N 步3的统一表必须**以机制分栏**呈现，不可合并为单一标度。

## §N 推导正文（Floquet-Magnus + 严格预热定理）

### 步骤1：能量加热的严格下界 τ_E ≥ τ_0·exp(cω/J)（陈述 Abanin 定理，明确 c 依赖）

**[步骤]** 设局域哈密顿量 H_0=∑_i h_i，单项算符范数 ‖h_i‖~J，k-局域、有界、相互作用程有限（配位数 z）。周期驱动 H(t)=H_0+V(t)，V(t+T)=V(t)，ω=2π/T≫局域带宽。问：系统从驱动场吸收能量并热化到无限温度需要多久？

**[框架工具：Floquet-Magnus 最优截断 + 算符范数界]** Floquet-Magnus（或 van Vleck）展开把单周期演化写成 U_F=e^{−iH_F T}，H_F=∑_{n≥0} Ω_n，Ω_n~J(J/ω)^n。该级数**渐近发散**（非收敛），但有**最优截断阶**：

  n* ≈ ω/(e·J_local).

截断到 n* 时，残差（无法用 H_F 描述的"加热算符"）的范数被指数压低（H-Magnus）：

  ‖V_{n*}‖ ~ J·exp(−ω/(e·J_local)).

**[依据：Abanin 加热界 F1']** Abanin–De Roeck–Huveneers（1507.01474）把这一最优截断升级为**严格的算符范数界**：单位时间能量吸收率（傅里叶分量上的加热率）满足

  σ([ω, ω+δω]) ≤ C·e^{−κω},   κ = 2/(ε·e),

其中 ε 是由 **‖h_i‖（=J）、相互作用程、配位数 z** 共同决定的局域能标（ε~zJ 量级，精确值见原文）。全局驱动情形多一个前因子 N(κω)^d（N=系统格点数，d=空间维数）；**d=1 时 commutator bound 进一步改进为超指数**（衰减比纯 exp 更快）。F2'（1509.05386）给出严格预热定理的算符版本：存在准守恒量 D（≈H_F 截断），‖[U_F, D]‖ 被指数压低，预热时间

  τ* ~ exp(c·ν/log³ν),  ν=ω/J_local（**准指数**，非纯 exp）。

**[关键结论]** 能量加热寿命下界：

  **τ_E ≥ τ_0·exp(c·ω/J),  c = c(‖h_i‖, 相互作用程 r, 配位数 z),  d=1 改进为准指数/超指数.**

分子 ω=单位驱动量子能量（须碎成局域激发的总能量）；分母 **J=局域能标 ‖h_i‖**（非总能标 LJ）；c 随配位数 z 增大而减小（更多近邻 → 更易碎能量 → 加热更快 → 天花板更低）。

**[依据]** F1'(1507.01474 加热率界) + F2'(1509.05386 严格预热 + 准守恒 D) + H-Magnus(最优截断)。
**[反驳检验]** 易质疑"这是上界（加热率≤）还是下界（寿命≥）？"——加热率上界 σ≤Ce^{−κω} **等价于**寿命下界 τ_E=1/σ ≥ e^{κω}/C。方向正确：定理给的是**寿命下界**，正是子命题问的"τ 的解析下界"。但它**只是下界**——不排除真实 τ_E 更长（见步3 HSF）。再质疑"分母为何是局域 J 不是总能标？"——加热是局域过程（局域共振注入能量再扩散），率与系统尺寸 L 无关，故分母是 intensive 的 ‖h_i‖。若误用 LJ 则 L→∞ 指数消失，与"高频加热被指数压制"的物理矛盾。

### 步骤2：序参量寿命 vs 能量寿命 + pre-dephasing 边界（D2）

**[步骤]** 步骤1给的是**能量**加热寿命 τ_E。次谐波**序参量**寿命 τ_OP（=⟨σ^z(nT)⟩ 的 2T-周期响应衰减时间）与 τ_E 是否相等？

**[框架工具：emergent 对称 + 算符范数界的通道分解]** Else-Bauer-Nayak（F3'，1607.05277）的机制：DTC 驱动含一个近似 X 大旋转（X^N=1，N=2 为 Ising π-脉冲），到旋转参考系后，H_F 的截断 D* 与 X **对易**——即驱动在预热时间尺度内**涌现出一个 Z_N 对称**。序参量是这个 emergent Z_N 的序参量。

**[依据：τ_OP ≥ τ_E，条件初态<T_c]** F3' 证明：只要初态能量密度（相对 D* 的有效温度）**低于 D* 的 SSB 临界温度 T_c**，emergent Z_N 在预热窗口内自发破缺，序参量被这个涌现对称**保护**——序参量退相**需要先加热出 SSB 相**，故

  **τ_OP ≥ τ_E ~ exp(c·ω/J)   （初态能量密度 < T_c）.**

即序参量寿命**不短于**能量寿命（受保护）。这是 F3' 的先发主结果。

**[本作业补：反向 pre-dephasing 边界（D2 novel）]** F3' 只覆盖<T_c。问：初态能量密度 **> T_c** 时如何？此时 D* 在该能量密度处**不破缺** emergent Z_N（高于临界温度，对称恢复）→ 序参量**无 emergent 保护**。序参量不再锁定于序，由普通（O(1)阶）平衡弛豫衰减到零，时间尺度 τ_pre = 平庸相内的局域退相时间，**与 ω 无关**（不是高阶共振，是低阶弛豫）。而能量加热仍需 exp(cω/J)。故

  **τ_OP ~ τ_pre  ≪  τ_E ~ exp(c·ω/J)   （初态能量密度 > T_c），即序参量先于能量退相（pre-dephasing）.**

**判定边界：** τ_OP 与 τ_E 的相对大小由初态能量密度相对 **H_eff(=D*) 的 SSB 临界温度 T_c** 决定：
- 初态 < T_c（落在 D* 的对称破缺相）→ τ_OP ≥ τ_E（两寿命同步，都 exp(cω/J)）。
- 初态 > T_c（落在 D* 的对称未破缺/平庸相）→ τ_OP = τ_pre ≪ τ_E（序参量先死，频率无关）。

**[结论]** "序参量寿命=能量寿命"**只在初态<T_c 时成立**（emergent 保护）。>T_c 时序参量先死且 exp(cω/J) 对序参量**根本不适用**。这是对"τ_DTC∝exp(ω/J)"的第一个非普适修正：**仅当 prethermal H_eff 在初态能量密度处自发破缺次谐波对称时，序参量才继承 exp(ω/J)**。

**[依据]** F3'(τ_OP≥τ_E，<T_c) + F5'(实验：trivial 相 M(t) 衰减"significantly faster than τ*") + 本作业 pre-dephasing 标度论证。
**[反驳检验]** 易质疑"τ_pre 真与 ω 无关、真短于 exp(cω/J) 吗？"——τ_pre 是平庸相局域弛豫，由局域能标 J 设定（~1/J 量级 × 平台增强），不含 ω 的高阶共振压低，故频率无关；只要 ω≫J，exp(cω/J)≫τ_pre。但 τ_pre 的**精确值**（prethermal 平台高度）我只给标度，未对具体模型数值确认 τ_OP<τ_E 的定量边界 → **立卡点1**。F5' 实测方向支持（"significantly faster"），但定量待数值。

### 步骤3：三类 DTC 统一天花板命题（D1，核心 novel）

**[步骤]** 把 MBL-DTC、prethermal-DTC、HSF-DTC(S1) 的 τ 标度统一对比，论证"所有非-MBL-本征态序 DTC 都被某 exp(参数) 天花板限制"。

**[框架工具：算符范数界的机制分类 + 守恒量代数类型]** 三类的区别在于"什么守恒结构保护次谐波"：MBL=l-bit（局域守恒，本征态级）；prethermal=emergent Z_N（准守恒，预热窗口级）；HSF=commutant/pattern（动力学约束，碎片级）。守恒结构的**鲁棒性**决定天花板。

**[依据 + 三类统一表]**

| 机制 | 保护结构 | 守恒鲁棒性 | τ 标度 | 关键参数 | 初态依赖 | 真∞? | 来源 |
|------|---------|-----------|--------|---------|---------|------|------|
| **MBL-DTC** | l-bit（局域守恒 τ^z_i） | 微扰稳定（Imbrie RG 不动点） | τ→∞（理想严格局域化）或 **exp(cL)**（有限 ξ + 相互作用尾部） | L（系统尺寸）、ξ | **无**（本征态序） | 仅理想极限 ξ=有限且尾部=0 + L→∞ | F6'(Nature601,531) |
| **prethermal-DTC** | emergent Z_N（准守恒 D*） | 预热窗口内近似（Abanin 天花板） | **exp(cω/J)**（准指数，d=1超指数） | ω/J | **有**（须<T_c，步2） | 否（有限ω下有限） | F1'/F2'/F3' |
| **HSF-DTC** | commutant/pattern（动力学约束） | fine-tuned（generic λ 使坍缩，S1） | **min(exp(cω/J), 1/λ², exp(c'L))** | λ（约束破坏）、L、ω | **有**（frozen 块 overlap~2^{−L}） | 否（generic λ>0 下 1/λ² 有限） | S1(H-S1)+2512.14182 |

**[统一命题]** 三类**不共享同一标度**：
- prethermal：天花板=ω-型 exp(cω/J)（**频率主导**）。
- MBL：天花板=L-型 exp(cL)（**尺寸主导**），理想极限真∞；但"真∞"要求 ξ 有限 + 相互作用尾部严格为零 + L→∞——任意 generic 扰动使尾部非零 → Imbrie 给 exp(cL)。
- HSF：天花板=三者取最小，**频率非主导**（1/λ²、exp(c'L) 与 ω 无关）；generic λ>0 下 1/λ² 封顶。

**统一陈述（D1）：** 把"天花板设定者"抽象为"破坏保护结构的最低阶过程的率的倒数"。**除 MBL 的理想严格局域化极限（ξ 有限、尾部为零、L→∞ 三条同时满足）外，所有 DTC——即所有"非-MBL-本征态序"机制——都被某个 exp(参数) 天花板限制：prethermal 被 exp(cω/J)、HSF 被 min(exp(cω/J),1/λ²,exp(c'L))。无一在 generic（有 generic 局域扰动）+ 热力学极限（L→∞）+ 有限驱动（ω 有限）三条件同时满足下真∞。** MBL 是唯一可能真∞者，但其"∞"是本征态级局域守恒的产物，不依赖驱动频率，且在任意有限 ξ + 有限 L 下退化为 exp(cL)。

**[结论]** 统一天花板表把三类 DTC 的寿命标度纳入单一"保护结构鲁棒性 → 天花板参数"框架，论证 exp(cω/J) 仅是 **prethermal 这一类**的天花板，非普适律。这是文献分别处理各类、未给统一表 + 未与 HSF 衔接的差异化贡献。

**[依据]** F1'/F2'/F3'(prethermal) + F6'(MBL) + H-S1/2512.14182(HSF) + 步2(prethermal 初态依赖)。
**[反驳检验]** 易质疑"MBL 的'真∞'是否真存在，使统一命题有例外？"——是，MBL 是唯一例外，但其∞需三条理想条件（ξ 有限、尾部为零、L→∞），物理上任意 generic 扰动破坏尾部为零 → exp(cL)。故统一命题的精确表述含"非-MBL-本征态序"限定词，且 MBL 栏并列"理想∞ / 实际 exp(cL)"两种读法（PI 须裁定用哪个，见 PI 入口问题2）。再质疑"HSF 的 exp(c'L) 与 MBL 的 exp(cL) 都是 L-型，是否可合并？"——不可：MBL 的 exp(cL) 来自局域化长度 ξ 的本征态级保护（初态无关），HSF 的 exp(c'L) 来自穿碎片壁的 (L/2) 阶虚跃迁（初态依赖、清洁点 λ=0 才显），机制不同，被 generic λ>0 压成 1/λ²。

### 步骤4：下界 τ_E ≥ exp(cω/J) 对任意局域扰动的严格性（D3）

**[步骤]** 子命题问"τ 的解析下界对任意局域扰动是否成立"。逐条检查 Abanin 定理(F1'/F2')的前提在 DTC 语境是否满足。

**[框架工具：Abanin 定理前提审计]** 严格预热定理的成立条件：
1. **高频：** ω ≫ 局域带宽（max_i ‖h_i‖ 的若干倍，含驱动项范数）。
2. **k-局域有界相互作用：** H_0 与 V(t) 都是有限程、算符范数有界的局域项之和。

**[依据]** 在 DTC 语境中：
- DTC 的 H_0（Ising/XXZ + 场）是 k-局域有界的 ✓；驱动 V(t)（π-脉冲列 + 周期场）是有界周期的 ✓。
- 高频条件 ω≫局域带宽：DTC 实验/理论的高频区满足 ✓（F5' 离子链即在此区）。

**∴ 在 ω≫局域带宽 + k-局域有界 的前提下，τ_E ≥ τ_0·exp(cω/J) 是 Abanin 定理对 DTC 的直接推论，对任意满足这两前提的局域扰动成立。** 加一个 generic 局域扰动 λW（W k-局域有界）不破坏前提——它只改变 H_0 的局域项（重定义 J、c），下界形式不变。**这正面回答子命题："下界对任意（k-局域有界、高频区）局域扰动成立。"**

**[结论]** 下界 τ_E ≥ exp(cω/J) 对任意 k-局域有界扰动严格成立（Abanin 直接推论），**前提是高频 + 局域有界**。两前提之一破坏（步5）则下界失效。

**[依据]** F1'/F2' 定理前提 + DTC 哈密顿量结构。
**[反驳检验]** 易质疑"任意局域扰动"是否包括破坏 emergent 对称的扰动？——是。注意区分：步4 的下界是**能量加热** τ_E（任意局域扰动下成立，因 Abanin 不要求任何对称）；**序参量** τ_OP 才依赖 emergent Z_N（破坏对称的扰动使 τ_OP<τ_E，步2）。即"τ_E 下界普适、τ_OP 下界条件化"。子命题问的"τ 的下界"——对能量寿命 τ_E 普适成立；对序参量 τ_OP 须加 emergent 保护条件（初态<T_c）。

### 步骤6：真相 vs 预热判定 —— exp(cω/J) 是 L-无关的预热签名

**[步骤]** 最终判据（与 LP-9 主命题对接）：prethermal-DTC 是热力学极限的真正非平衡相，还是高频预热赝象？

**[框架工具：天花板指数的尺寸依赖性]** 判据：L→∞ 时序参量寿命 τ(L) 是否发散。
- τ(L)→∞（任意有限 ω）→ 真正非平衡相。
- τ(L) 有限（任意有限 ω）→ 预热赝象（无限时间最终热化）。

**[依据]** prethermal 的天花板 τ~exp(cω/J) 是 **L-无关的频率指数**：
- 加热是**局域**过程（局域共振注入能量），率与系统尺寸 L 无关 → τ_E=exp(cω/J) **不含 L** → 任意有限 ω、L→∞ 下 τ 保持有限。
- **∴ prethermal-DTC 是预热赝象**：寿命指数长但有限（仅 ω→∞ 严格极限才∞），热力学极限下加热率不灭。

**对比三类（与 S1/S2 合并）：**
- **prethermal-DTC：** 天花板 exp(cω/J)，**ω-型、L-无关** → **预热赝象**（命题B方向）。
- **MBL-DTC：** 天花板 exp(cL)，**L-型** → L→∞ 真∞ → 理想极限真相（但需严格局域化）。
- **HSF-DTC（S1）：** min(exp(cω/J),1/λ²,exp(c'L))；λ=0 清洁极限 exp(c'L) 是 L-型（趋真相），但 generic λ>0 下 1/λ²（L-无关）封顶 → **预热赝象**（S1 结论）。

**[核心论断]** **指数里出现 ω/J（而非 L）这件事本身，就判定了 prethermal-DTC 是赝象。** 真正的非平衡相需要 **L-extensive 的压低（exp(cL)，尺寸主导）**，而非 **ω-extensive 的压低（exp(cω/J)，频率主导）**。频率指数 L-无关 → 有限 ω、有限系统下寿命有限 → 热力学极限不灭加热 → 赝象。这与 LP-9 主命题对 prethermal 类的回答一致：**prethermal-DTC 是高频预热赝象，不是热力学极限真相**（命题B方向）。唯一可能真相的是理想 MBL-DTC（L-型 exp(cL)，本征态序）。

**[结论]** prethermal-DTC 明确判为**预热**（命题B方向）。与 S1（HSF-DTC 赝象）、S2（封闭平衡 CTC no-go）合并：在闭合系统中，唯一可能真∞的 DTC 是理想 MBL-DTC（本征态序、L-型天花板）；prethermal 与 HSF 都是有限寿命预热（前者 ω-型、后者被 λ 封顶）。

**[依据]** F1'/F2'(τ_E L-无关) + S1(HSF 赝象) + 步3 统一表 + LP-9 主命题判据（L-型 vs ω-型）。
**[反驳检验]** 易质疑"指数长≠无限长，但实验上 exp(cω/J) 可达数万 cycle（F9），是否应算'可操作真相'？"——这是定义之争（同 S2 卡点3 的 mesoscopic 争议）：严格相定义要求 L→∞ 稳定，exp(cω/J) 不满足（L-无关）；但宏观有限系统内可观测。立为定义边界，与 LP-9 主线统一裁定（PI）。不改变定性判定：**严格热力学极限意义下 prethermal-DTC 是预热赝象。**
