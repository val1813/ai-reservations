## 第一步：代数验算

### F-A1（倒数关系 + κ表达式） — 通过
- 倒数关系：σ ~ e^{-κω} ⇒ τ* ~ τ₀/σ ~ τ₀ e^{+κω}。指数符号翻转 ✓，代数无误。
- 与 e^{cω/J} 的衔接：ε 为局域范数（‖h_i‖×配位数×相互作用程），ε ~ J·O(1)，故 κω = 2ω/(εe) ~ c·ω/J，与 F-A3 的预热天花板 e^{cω/J} 一致 ✓。
- **判定：通过**（仅 ⚠️ 偏差：ε 与 J 之间隐含一个 O(1) 晶格常数，不是严格相等，见第五步）。

### F-A2（准指数 vs 纯指数） — 通过
- ν/log³ν < ν（因 log³ν > 1 当 ν > e），故 exp(ν/log³ν) < exp(ν) = exp(cω/J)。即"略慢于纯指数"的表述 ✓。
- 仍为超多项式：ν/log³ν → ∞（线性比多项式对数快），故寿命增长快于任意多项式，"准指数 (quasi-exponential)"标签准确 ✓。
- **判定：通过**。

### F-A3（三类天花板 + min结构） — 通过
- MBL e^{cL}：体系尺寸 L 指数；preth e^{cω/J}：频率指数；HSF 取三者最小。
- min 结构逻辑：寿命受**最短**失效机制封顶 ⇒ 取 min ✓。三项分别对应 (i) 弱破碎散射 1/λ²，(ii) 频率预热 e^{cω/J}，(iii) 残余局域化 e^{c'L}，逻辑自洽。
- **判定：通过**（⚠️ 见量纲步对 1/λ² 的说明）。

### F-B1（鞍点推导） — **严重（致命级derivation错误，但终值正确）**

逐字复核 B 给出的鞍点方程：

```
f(n) = n·ln(J/ω) + ln(1/n!) = n·ln(J/ω) − ln(n!)
Stirling: ln(n!) ≈ n ln n − n
⇒ f(n) = n·ln(J/ω) − n ln n + n
⇒ f'(n) = ln(J/ω) − (ln n + 1) + 1 = ln(J/ω) − ln n
设 f'(n)=0 ⇒ ln(J/ω) = ln n ⇒ n* = J/ω
```

**这给出 n* = J/ω < 1（不物理），且绝不等于 ω/(eJ)。** B 自己写的方程 `ln(J/ω) − ln n = 0` 数值验证（第四步）确认鞍点在 n = J/ω = 0.1，非 ω/(eJ) = 3.68。

要得到带因子 e 的 n* = ω/(eJ)，**必须**有一个 n^n 型组合熵项（+n ln n，不带 −n）：
```
g(n) = n·ln(J/ω) + n ln n   (组合因子 ~ n^n)
g'(n) = ln(J/ω) + ln n + 1 = 0 ⇒ ln n = ln(ω/J) − 1 ⇒ n* = (ω/J)/e = ω/(eJ) ✓
```
而 B 实际写出的速率 `Γ ~ (J/ω)^n · n!`（n! 在**分子**）给出的鞍点是：
```
h(n) = n·ln(J/ω) + ln(n!) = n·ln(J/ω) + n ln n − n
h'(n) = ln(J/ω) + ln n = 0 ⇒ n* = ω/J   （无因子 e！）
```

**三套约定给出三个不同的 n*：J/ω（B写的方程）、ω/J（B写的速率Γ）、ω/(eJ)（B宣称的答案）。三者互不相同。**

- 终值 n* ≈ ω/(eJ) 本身是正确物理（与 Abanin 算符范数界 ε·e 一致），但 **B 写出的推导路径无法导出它**：写出的 f(n) 单调递减无内部鞍点，写出的 Γ 给出 ω/J（丢了 e）。属"对的答案、错/乱的推导"。
- **判定：严重**。需要 B 明确写出组合因子是 n^n（能量 ω 分配到 n 个局域模的多项式熵），并修正 f(n) 的符号，才能自洽导出 ω/(eJ)。

### F-B2（d=1 超指数 ln 修正） — 部分通过 / 部分未验算
- 代数自洽性：若 d=1 修正给出 Γ ~ exp(−c(ω/J)ln(ω/J))，则指数幅角 (ω/J)ln(ω/J) > ω/J（当 ω/J > 1），衰减更快 ⇒ 寿命更长，"超指数 improvement"方向 ✓。
- **是否精确匹配 Abanin 1507.01474 的 d=1 结果：未验算**（这是文献比对，超出纯代数范围）。代数仅能确认"加一个 ln(ω/J) 因子 ⇒ 比纯指数更强压低"这一方向正确。
- **判定：方向通过，文献匹配未验算**。

### F-B3（L-extensive vs ω-指数判据） — 通过
- 两个指数的变量不同：e^{−L·I(ε)} 以系统尺寸 L 为指数变量；e^{−cω/J} 以频率比 ω/J 为指数变量，**与 L 无关**。
- 逻辑：真正永久稳定（真相）需 L-extensive 压低（L→∞ 时速率→0，寿命→∞）；预热只是 ω-指数（L 无关，热力学极限下寿命**有限**）。判据正确 ✓。
- **判定：通过**（此条是 B 唯一与 A 真正不同维度的贡献，见独立性核查）。

## 第四步：数值验算（ω/J = 10）

```
n*(n^n约定) = ω/(eJ) = 10/2.71828 = 3.679   ← B宣称值
n*(n!分子)  = ω/J     = 10                    ← B写的Γ给出
n*(B写方程) = J/ω     = 0.100  (不物理 <1)    ← B写的f'(n)=0给出
```

数值最小化 T(n) = (J/ω)^n·n! 验证（B写的速率形式，取**最小**项找最优截断）：
```
T(3)=6.0e−3  T(4)=2.4e−3  T(9)=3.63e−4  T(10)=3.63e−4  T(11)=3.99e−4
⇒ 最小在 n=9~10 ≈ ω/J，不在 3.68
Stirling: min T ≈ e^{−ω/J}√(2πω/J) = 3.60e−4 ✓（与数值3.63e−4吻合）
```
⇒ **B 写的 Γ~(J/ω)^n·n! 的鞍点确实在 ω/J=10，不是 ω/(eJ)=3.68，数值证实 F-B1 推导内部矛盾。**

n^n 约定下的幅与速率（导出 ω/(eJ) 的唯一自洽约定）：
```
振幅 A(n*) = (J/ω)^{n*}·n*^{n*} = e^{−n*} = e^{−3.68} = 0.0253
速率 Γ = A² = e^{−2n*} = e^{−7.36} = 6.38e−4
寿命 τ ~ 1/Γ = e^{2n*} = e^{2ω/(eJ)} = e^{7.36} = 1568 周期
```

**A/B 数值交叉对照（关键）：**
```
A: κ=2/(eJ) ⇒ τ ~ e^{κω} = e^{2ω/(eJ)} = e^{7.36} = 1568 周期
B: Γ=振幅² ⇒ τ ~ e^{2ω/(eJ)}             = e^{7.36} = 1568 周期
                                              ↑ 完全相同
```
- A 的 κ 中的因子 **2** = B 的费米黄金律**振幅平方**（Γ~|A|²）。
- A 的 κ 中的 **1/e** = B 的 **n^n 组合熵**鞍点的 1/e。
- 两者数值预测**逐位相同**（1568 周期）。

对照（若用 B 写的 n! 约定）：n*=ω/J=10 ⇒ τ~e^{10}=22026，与 A 的 1568 **不符**——再次印证 B 写法的内部张力。

### 核心独立性判断：A 的 k* 与 B 的 n* 是否同一 Stirling 鞍点？

**结论：是同一个 Stirling 鞍点。A 与 B 在寿命标度上不是独立互证，而是同义反复（同一定理的两种语言）。**

代数对比——两者都是"阶乘/幂"竞争 x!/y^x（或 x^x·y^x）的鞍点，鞍点都在 **x* ≈ y/e**：

```
A（算符范数界 / Floquet-Magnus）：
  渐近级数项 a_k ~ k^k·(ε/ω)^k  （k阶嵌套对易子的范数增长）
  最优截断 d/dk[k ln k + k ln(ε/ω)] = ln k + 1 + ln(ε/ω) = 0
  ⇒ k* = ω/(εe)

B（大偏差 / 共振计数）：
  n阶过程 ~ n^n·(J/ω)^n      （ω碎成n个局域激发的多项式熵）
  最优阶数 d/dn[n ln n + n ln(J/ω)] = ln n + 1 + ln(J/ω) = 0
  ⇒ n* = ω/(eJ)
```

识别 ε ≈ J（A 的局域范数 ≈ B 的局域跳跃尺度，差 O(1) 晶格因子）后：

```
k* = ω/(εe)  ≡  n* = ω/(eJ)        （同一表达式）
```

物理上 **k ≡ n**：A 的"Magnus 展开的第 k 阶 / 第 k 重嵌套对易子"与 B 的"吸收 ω 所需创生的第 n 个局域激发"是**同一个计数**——微扰/Magnus 展开每升一阶就创生一个局域激发。两者：
1. 优化**同一形式**的竞争 x^x·y^x；
2. 鞍点**同一位置** x* ≈ y/e；
3. 第四步数值预测**逐位相同**（ω/J=10 时同为 1568 周期，连因子 2 与 1/e 都对应）。

因此 **A 的算符范数界与 B 的共振计数对"预热寿命 ~ e^{cω/(eJ)}"不构成两条独立证据，而是同一个"渐近级数最优截断 / n光子吸收大偏差鞍点"定理在算符范数语言（A）与组合-大偏差语言（B）下的两次书写。REVIEWER 的独立性质疑：代数确认成立。**

**唯一例外（B 的真正独立贡献）：** F-B3 的 L-extensive 速率函数 e^{−L·I(ε)} 引入了与 A 不同的变量（系统尺寸 L，而非频率比 ω/J）。但此项恰恰是说明"预热**不是**永久"的**反向限定**（L→∞ 寿命仍有限），而非对 ω-指数寿命的**正向互证**。即：B 中与 A 互证的部分（F-B1 鞍点）与 A 冗余；B 中独立于 A 的部分（F-B3）是 caveat 而非 corroboration。
