## 第一步 代数验算

### F-A1 — Mathieu 参数映射 ✅ 正确

起始方程：
```
E_k'' + ω₀²[1 - α cos(Ωt)] E_k = 0
```
（由 1/ε(t) ≈ (1/ε₀)[1 - α cos Ωt] 小α展开得，符号正确：ε 增大→ω² 减小。）

代入变量 τ = Ωt/2 ⟹ t = 2τ/Ω，d²/dt² = (Ω²/4) d²/dτ²。乘以 4/Ω²：
```
x'' + [ 4ω₀²/Ω² - (4αω₀²/Ω²) cos(2τ) ] x = 0
```
对照标准形 x'' + [a - 2q cos(2τ)]x = 0：

- **a = 4ω₀²/Ω²** ✅ 与 A博士一致
- 2q = 4αω₀²/Ω² ⟹ **q = 2αω₀²/Ω²** ✅ 与 A博士一致

### F-A2 — 第一舌物理增长率 ❌ A博士错，REVIEWER 对：Γ = α ω₀ / 4

这是 severity 判定关键，逐步厘清两个易错点。

**易错点①：Mathieu 第一舌中心的 Floquet 指数（以 τ 为单位）是 μ_τ = q/2，不是 q。**
标准 Mathieu 第一不稳定舌在 a∈[1-q, 1+q]（边界宽度 ∝q），而舌中心 a=1 处的特征指数为
```
μ_τ = q/2        （|x| ~ e^{μ_τ τ}）
```
（q 是舌"半宽"量级，增长率是其一半——A博士疑似把半宽 q 直接当成了增长率。）

**易错点②：τ→t 的换算因子是 dτ/dt = Ω/2。**
|x| ~ e^{μ_τ τ} = e^{μ_τ(Ω/2)t}，故物理时间增长率
```
Γ = μ_τ · (Ω/2) = (q/2)(Ω/2)
```

代入 q = 2αω₀²/Ω²：
```
Γ = (1/2)(2αω₀²/Ω²)(Ω/2) = α ω₀² / (2Ω)
```
在精确共振 Ω = 2ω₀：
```
Γ = α ω₀² / (2·2ω₀) = α ω₀ / 4   ✅
```

**厘清 ω 指代**：此处 ω 必须是固有频率 ω₀ = ω_{k,0}（不是调制频率 Ω）。在共振点 Ω=2ω₀ 时 Ω/2=ω₀，写 αΩ/8 亦等价，但物理上规范写法为 **Γ = αω₀/4**。

**判定**：REVIEWER 正确。A博士的 αω/2 大了一倍（factor 2）。错误来源为易错点①（用 q 而非 q/2）。

**文献交叉验证**（自我攻击）：Landau–Lifshitz《力学》§27 参量共振，对 x''+ω₀²[1+h cos γt]x=0、γ≈2ω₀，给出共振中心增长率 s = h ω₀/4（直接以物理时间 t 给出）。本问题调制幅度 |h|=α，故 s = αω₀/4 —— 与本独立推导完全一致，且无需 τ 换算即可佐证。两条独立路径同结论。

### F-A3 — k-gap 宽度 ✅ 正确：Δk ≃ (α/2)k_c

共振中心：a=1 ⟹ 4ω₀²/Ω²=1 ⟹ ω₀=Ω/2 ⟹ ck_c/√ε₀=Ω/2 ⟹
```
k_c = √ε₀ · Ω/(2c)   ✅ 与 A博士一致
```
第一舌在 a 中的全宽 Δa ≈ 2q（边界 a=1±q）。换算到 k：
```
a = 4c²k²/(ε₀Ω²) ⟹ da/dk = 8c²k/(ε₀Ω²)
da/dk |_{k_c} = (2/k_c)·[4c²k_c²/(ε₀Ω²)] = (2/k_c)·a|_{k_c} = 2/k_c
Δk = Δa / (da/dk) = 2q / (2/k_c) = q·k_c
```
共振处 q = 2αω₀²/Ω² = 2α(Ω/2)²/Ω² = α/2，故
```
Δk = (α/2) k_c   ✅ 与 A博士一致
```
注：A博士在 F-A3 用 q 正确（半宽×2=全宽），却在 F-A2 误用 q 当增长率——同一人前后不自洽，进一步印证 F-A2 是笔误级错误而非系统性误解。

### F-B1 — 共振条件一致性 ✅
B博士 Ω≈2ω_k 即 a=4ω₀²/Ω²≈1，与 F-A1 完全同一条件。一致。

### F-B2 — 压缩/光子数 ✅（量纲与结构正确）
- 不稳定模幅度 ~ e^{Γt}，双模压缩参量 r = Γt（r 为振幅增益的对数），量纲：Γ[1/t]·t=无量纲 ✅
- 双模压缩真空每模平均光子数 ⟨n⟩ = sinh²r，R=sinh²r 无量纲 ✅
- 结构正确。注意：r=Γt 中的 Γ 应取修正后的 αω₀/4，否则光子产率被高估 e^{2·(差值)t}。

### F-B3 — 无阈值 ✅
Γ = αω₀/4 ∝ α¹（线性）。α→0 ⟹ Γ→0 连续，无临界阈值。与有临界阈值的 SSB 形成对比，论证成立。

## 第二步 量纲核查
- [ω₀²]=1/t²，[α]无量纲 ⟹ 方程各项 1/t²·[E] ✅
- a=4ω₀²/Ω² 无量纲 ✅；q=2αω₀²/Ω² 无量纲 ✅
- Γ=αω₀/4：[1/t] ✅；Δk=(α/2)k_c：[1/length] ✅
- R=sinh²r、r=Γt 均无量纲 ✅
全部通过。

## 第三步 极限核查
- **α→0**：Γ→0、Δk→0、q→0，舌闭合，回到自由演化 ✅（无阈值）
- **Ω→2ω₀（精确共振）**：a→1，舌中心，Γ 取极大 αω₀/4 ✅
- **失谐 Ω≠2ω₀**：Γ=√[(αω₀/4)² − δ²] 型，δ 为失谐，带外 Γ→0 ✅（数值见下）

## 第四步 数值验证（ε₀=1, c=1, α=0.1, ω₀=1, Ω=2）

方法：直接对 E''+ω₀²[1-α cos Ωt]E=0 数值积分一个调制周期 T=2π/Ω，构造单值（monodromy）矩阵 M，取 Γ=ln(max|ρ|)/T。

**(1) 共振点增长率**
```
|ρ| = {0.9245, 1.0817},  det M = 1.000000 (校验✓)
Γ_数值 = 0.024993
预测 αω₀/4 = 0.025000   ✅  (A博士 αω₀/2 = 0.05  ✗)
```

**(2) α 线性标度（确认 ∝α 且系数 1/4）**
```
α=0.20  Γ=0.049942  Γ/α=0.2497
α=0.10  Γ=0.024993  Γ/α=0.2499
α=0.05  Γ=0.012499  Γ/α=0.2500
α=0.02  Γ=0.005000  Γ/α=0.2500
α=0.01  Γ=0.002500  Γ/α=0.2500   → Γ/α→1/4 ✅
```

**(3) k-gap 宽度（k_c=1）**
```
不稳定带 k∈[0.9758, 1.0258]
Δk_数值 = 0.04995
预测 (α/2)k_c = 0.05000   ✅
峰值 Γ = 0.025005 ≈ αω₀/4 ✅
```

三项数值与解析全部吻合。结论稳健。

## 第五步 独立性判定（REVIEWER 质疑核心）

**问题**：A-C2（线性 PTC 无 SSB，"参量赝象"）与 B-C1（misnomer，本质 Mathieu 参量共振）是否独立？

**代数事实**：
- A-C2 的依据：体系受**线性时变波动方程** E''+ω²(t)E=0 支配，无非线性回馈、无对称性自发选择 ⟹ 不是 SSB。
- B-C1 的依据：**同一** E''+ω²(t)E=0，周期系数 ⟹ Floquet/Mathieu 参量共振，故 "DTC" 是误称。

两者：
1. **出发方程同一**：均为 E''+ω₀²[1-α cos Ωt]E=0（线性、时间周期系数）。
2. **核心数学对象同一**：均为该方程的 Mathieu/Floquet 谱分析（第一参量舌）。
3. 仅措辞不同：A-C2 = "这不是 SSB"，B-C1 = "这是参量共振/误称"——是同一观察的两种否定式表述。

**判定：非独立。** A-C2 与 B-C1 不能作为两条相互独立的佐证；它们是同一线性时变方程、同一 Floquet 分析的同一结论的两种说法。若 synthesis 将其计为"两路独立互证"，则该互证论证无效（属重复计数）。

## 一句话结论
1. Mathieu 第一舌精确共振增长率 = **α ω₀/4**（ω₀=ω_{k,0}），解析+Landau §27+三组数值三重确认。**REVIEWER 正确，A博士的 αω/2 大了一倍**（错因：误把舌半宽 q 当增长率，应为 q/2，再乘 dτ/dt=Ω/2）。
2. A-C2 与 B-C1 **同出一条线性时变波动方程 E''+ω²(t)E=0、同一 Mathieu/Floquet 分析**，是同一观察的两种措辞，**非独立**，不能作两路互证。
