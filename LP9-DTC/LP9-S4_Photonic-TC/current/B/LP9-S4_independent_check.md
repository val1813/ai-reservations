具体工具链：

## §0.5 前置三问（真实 WebSearch，已执行）

**Q1. 核心前提"PTC 是时间晶体"有无文献否定 / 术语之争？**

有，而且是公开的、点名的术语之争。检索命中：

- **arXiv:2305.15243** "Photonic Time Crystals and Parametric Amplification"（同名 ACS Photonics 论文，标题"Similarity and Distinction"）。其摘要明确：**"the same physical mechanism underpins both PTC and OPA(光参量放大), the difference arises from the boundary conditions(差别仅来自边界条件)。"** 这是直接把 PTC 拉回到参量放大同源的判断。它区分 PTC 与 OPA 仅在于"只有 PTC 能在动量带隙里有传播+指数放大解"，但二者**共享同一参量机制**。
- **arXiv:2507.10862** "Time Crystal from Self-Amplification of Spontaneous Analog Hawking Radiation"：作者专门提出一个判据来区分"genuinely spontaneous(真正自发)"的时间晶体与普通参量放大——关键在于**放大的是量子真空噪声(spontaneous)而非注入的经典种子(stimulated)**，且每次实现拾取**随机相位**，使等时观测量(equal-time)对相位平均后时间无关。这反向证明：**普通参量放大(受迫、有确定相位、放大注入信号)默认不算"真正自发"的时间晶体。**
- DTC 的标准定义（Else/Yao/Nayak 综述类、Nature Phys "Classical Discrete Time Crystals" arXiv:1801.02628）反复强调三要素：**多体、自发破缺离散时间平移对称、subharmonic 响应 + 刚性(rigidity)**。

→ 结论：术语之争**真实存在且激烈**，且主流否定方与我的框架同源。这不是我编出来的对立。

**Q2. 有无先发用参量振荡 / squeezing 判定 PTC 与 DTC 对应？**

有，且非常贴近，我必须承认先发权而非声称原创：

## §1 独立结论预测（参量振荡视角）

**方向**：PTC 的次谐波/放大现象主体是**受迫参量响应**，非自发对称破缺。判定主体为术语混淆/范畴误标（参量放大被误称为时间晶体序）。

**量级 / 定量预测**：
- 均匀 PTC 中模 k 的不稳定带宽 ∝ 调制深度 m（一级 Mathieu 共振 Δ ∼ mΩ/4），增长率(Floquet exponent) μ ∝ m。这是**连续可调、随 m→0 平滑消失**的——没有阈值、没有序参量跳变。真 SSB 应有阈值与非解析行为。
- 响应周期：参量共振主带在 Ω≈2ω_k，模以 ~Ω/2 = ω_k 振荡(即"period-2"对应驱动周期的次谐波)，但这个 2T 周期是**Mathieu 主不稳定带的确定性结果**，不是从简并基态里自发选一个。
- 量子化后：双模压缩参数 r ∝ μt，光子对数 ∝ sinh²(r)，是 Gaussian 线性过程，**无相变、无序参量**。

**最易错处**：把"period-doubling/次谐波"本身当成 DTC 的充分标志。次谐波是**必要非充分**——任何 Mathieu 主共振都给次谐波，连单个经典参量摆都给。DTC 的判据在于**自发性+刚性+多体**，不在于"出现了 2T 周期"。

## §N 独立推导正文

### N.1 PTC = 参量振荡器的 Mathieu 方程表述

**步骤**：均匀(空间无结构)PTC，介电常数周期调制 ε(t)=ε₀[1+m·cos(Ωt)]，磁导率 μ 常数。Maxwell 方程对空间傅里叶模 k：从 ∇×E=−∂_tB, ∇×H=∂_tD, D=ε(t)ε₀E 出发，对横模消去得位移场或电场的二阶方程。用位移场 D_k(t)（D 在时间调制下连续，是恰当的"位置"变量）：

  d²D_k/dt² + ω_k²(t) D_k = 0,  ω_k²(t) = c²k² / [ε_r(t)] = c²k²/(ε₀ε_r(t))/... 

写成无量纲标准形（以 ε_r(t)=1+m cosΩt，ω_{k,0}²=c²k²/ε₀）：

  d²D_k/dτ² + [a − 2q cos(2τ)] D_k = 0,  τ=Ωt/2,

这是**Mathieu 方程**，a ≈ (2ω_{k,0}/Ω)², q ∝ m·a/2。（一般 ε(t) 非余弦时为 **Hill 方程**，结论不变。）

**框架工具**：Mathieu/Hill 方程，Floquet 定理。

**依据**：线性二阶 ODE，周期系数。Floquet 定理保证解 D_k(t)=e^{μt}P(t)，P 周期为调制周期 T=2π/Ω，μ 为 Floquet 指数(特征指数)。

**结果**：在 Mathieu 稳定图(Ince-Strutt 图)上，参数(a,q)落在不稳定舌(instability tongue)内时 Re(μ)>0 → 指数增长。**主不稳定舌在 a≈1，即 2ω_{k,0}≈Ω**，正是文献定义 PTC 的"调制频率≈两倍光频"。这个不稳定带在 k 空间投影出来就是**动量带隙(k-gap)**：带隙内 ω_k 变复，模指数增长。

**最易错处**：误把 D_k 与 E_k 混用。E_k=D_k/ε(t) 在 ε 跳变处不连续，用 E 写方程会引入伪奇异项；正确变量是 D（或矢势 A）。这是 PTC 文献里反复出错的点。

**N.1 关键判断**：k-gap = Mathieu/Hill 方程的参量共振不稳定带。这是纯线性、确定性的结果，不含任何"自发选择"。

### N.2 自发 vs 受迫的判据（核心）

我建立**三条可操作判据**，区分"参量不稳定性"与"时间平移对称自发破缺(DTC)"。

**判据 (a)：是否需相互作用/非线性。**
- SSB 的数学定义：哈密顿量具有对称性 G，但基态(或稳态)不具有 G，且存在**简并**的对称破缺态，系统自发选其一。简并 + 自发选择**必须**来自非线性/相互作用项——线性系统的解空间是叠加封闭的，任意两个解的线性组合仍是解，**不可能自发选出单一破缺态**。
- 裸 PTC：方程 N.1 完全线性。任意初态 D_k(0) 给出确定的、唯一的 e^{μt} 增长，无简并破缺态可选。
- → 裸 PTC **不满足 (a)**。对照 arXiv:2306.13652：要在参量振子里得到 DTC，必须**耦合**多个振子(引入相互作用)，使非线性锁定 period-doubling。

**判据 (b)：响应周期是驱动周期的自发倍数，还是受迫确定的？**
- DTC：驱动周期 T，系统**本可以**保持 T 周期响应(不破缺)，但相互作用使其**自发**选择 2T(或 nT)，且**哪个 2T 子格**(两个等价的相位)由初态/涨落随机选定——这是离散时间平移 ℤ → 2ℤ 的自发破缺。
- PTC：在主共振 Ω≈2ω_k，模以 ω_k≈Ω/2 振荡，表面是"2T 次谐波"。但这是 **Mathieu 主舌的确定性本征行为**——不是"本可不破缺却自发破缺"，而是"调制频率被调到 2ω_k 时必然如此"。没有两个等价相位供随机选择(增长解相位由初始条件连续决定，非离散二选一)。
- → PTC 的次谐波是**受迫**的(参量共振条件直接强加)，非自发。

**判据 (c)：是否有 Landau 序参量 + SSB + 阈值非解析性。**
- DTC：存在序参量(如 subharmonic 峰的谱权重、时序关联函数 lim C(t)≠0)，在相变点非解析，相内对参数有限区间鲁棒(锁相平台)。
- PTC：增长率 μ(m) 随调制深度 m **解析、连续**地从 0 长出(μ∝m 在主舌中心)，无阈值、无非解析跳变、无锁相平台。次谐波频率随 Ω 失谐**连续漂移**，不锁定。
- → PTC **无序参量、无 SSB 相变**。

**框架工具**：SSB 的群论定义、Landau 理论、Floquet 乘子解析性。

**判定**：PTC 的 k-gap 振荡在三条判据上**全部归入"受迫参量不稳定性"**，无一满足 DTC 的自发性要求。**裸 PTC 的"时间晶体序"是术语混淆——参量放大被误标为自发对称破缺。**

**最易错处**：把"离散时间平移对称"的破缺归因于 PTC 本身。事实上调制 ε(t) 已经把**连续**时间平移对称**显式(explicit)**破缺到离散群 ℤ_T——这是输入条件，不是自发结果。DTC 要破缺的是**剩下的离散** ℤ_T → 2ℤ_T，这才需自发性。PTC 没碰这一步。(此即苏格拉底 #2)

### N.3 经典-量子对应：squeezing

**步骤**：量子化 PTC。场展开为模 a_k, a_{−k}†。调制 ε(t)cos(Ωt) 在 Ω≈2ω_k 下产生耦合项 ∝ (a_k a_{−k} e^{iΩt} + h.c.)——这是**双模压缩(two-mode squeezing)哈密顿量**，signal(k)+idler(−k)配对。

**框架工具**：Bogoliubov 变换，SU(1,1) 群，双模压缩。

**依据**：参量下转换/参量放大的标准量子光学结果。经典 Floquet 指数 μ ↔ 量子压缩参数率 dr/dt=μ。Bogoliubov 变换
  b_k = cosh(r) a_k + sinh(r) a_{−k}†,  r=μt,
对角化。真空 |0⟩ 演化为双模压缩真空，光子对数 ⟨n_k⟩=sinh²(r)，**自发**从真空产生光子对(类动态 Casimir / Unruh / analog Hawking)。

**这个量子 PTC 是 DTC 吗？判定**：
- 这是 **Gaussian、线性(在 a 中二次)** 过程。SU(1,1) 群结构(arXiv:2601.17369 已明示 PTC=动量分辨的 SU(1,1) 参量放大器连续族)。
- Gaussian 态完全由一二阶矩描述，**无相变、无序参量、无多体关联结构**。压缩参数 r 连续增长，无非解析点。
- DTC 需要**相互作用诱导的多体 SSB + 局域化/预热**来获得刚性。Gaussian 双模压缩没有任何相互作用(光子-光子不耦合)。
- → **量子 PTC(裸) ≠ DTC**。除非加 Kerr 非线性等(χ⁽³⁾)使光子相互作用，进入非 Gaussian 多体区。

**自发性的一个微妙点**：量子 PTC 确实从**真空**自发产生光子对(这是"spontaneous"的，对应 arXiv:2405.05043 的 photon pair creation)。这比经典受迫放大"更自发"。但"自发产生粒子" ≠ "自发破缺时间平移对称"——动态 Casimir 效应也自发产生光子对，无人称其为时间晶体。每个 k 模的相位由压缩几何确定，**不是**多体系统在简并稳态间的自发选择。(此即苏格拉底 #6 的落点)

**最易错处**：把"从真空自发产生光子"与"自发破缺对称"混为一谈。前者是受迫哈密顿量作用于真空的确定性结果(确定的压缩轴)，后者需要简并 + 随机选择。arXiv:2507.10862 正是靠"**随机相位**+等时观测量时间无关"把前者升级为后者——裸 PTC 没有这个随机相位机制。

### N.4 与量子 DTC 的本质区别 / 联系

| 维度 | 裸 PTC | 量子 DTC |
|------|--------|----------|
| 哈密顿量 | 线性(场二次)，无相互作用 | 非线性多体，需相互作用 |
| 对称破缺类型 | 连续时间平移被调制**显式**破缺到 ℤ_T；ℤ_T 未再破缺 | 离散 ℤ_T → 2ℤ_T(或 nℤ_T)**自发**破缺 |
| 次谐波来源 | Mathieu 主共振(Ω≈2ω_k)受迫 | 多体 SSB 自发选周期 |
| k-gap/增长 | 参量不稳定带，μ∝m 连续无阈值 | subharmonic 锁定，有相变阈值 |
| 序参量 | 无 | 有(谱权重/时序长程关联) |
| 刚性 | 无；频率随失谐连续漂移 | 有；锁相平台，对扰动免疫 |
| 量子结构 | Gaussian 双模压缩(SU(1,1)) | 非 Gaussian 多体纠缠 |
| 稳态 | 无(指数发散，除非耗散/非线性饱和) | 有(预热/MBL 稳定的长寿命相) |
| 数学起源 | Floquet→Mathieu 不稳定 | Floquet→多体 SSB |

**共同点(联系)**：两者**都**起于 Floquet(周期驱动)框架，**都**涉及 period-doubling/subharmonic。这是为什么"PTC 是时间晶体"的叙事能传播——表面现象(2T 周期)相同。

**本质区别(判定)**：**数学起源不同**——PTC 是**线性参量不稳定性(Mathieu 不稳定带)**，DTC 是**非线性多体自发对称破缺**。"都是 Floquet"只是分类学的最外层共性，不构成同一物理。把它们等同，相当于因为"单摆和地震都满足某个 ODE"就说它们是同一现象。

### N.5 回到 LP-9 主矛盾

**LP-9 主命题**：DTC 是真正非平衡相还是 Floquet 微调赝象？

**S4 对主命题的贡献**：PTC 提供了一个**极端对照样本**。沿"赝象"光谱排列：

1. **真 DTC**（多体 SSB + 刚性 + 预热稳定）：真正非平衡相。
2. **Floquet 微调赝象**（需精调驱动、无刚性的 period-doubling）：LP-9 担心的"赝象"。
3. **PTC(裸)**：比"赝象"更靠外——它甚至不需要"被误认为相"，因为它从一开始就是**线性参量放大**，是**术语混淆(category confusion)**而非"赝象"。赝象至少在某参数点模仿了相的现象；PTC 连"试图成为相"都不是，它是另一类物理(确定性不稳定性)被借用了时间晶体的名字。

**精确定性**：
- **线性裸 PTC = 术语混淆/范畴误标**。k-gap 是 Mathieu 参量共振不稳定带，受迫、确定、无 SSB。称其"时间晶体序"是将参量放大误标为自发对称破缺——属术语混淆。文献(arXiv:2305.15243)已自承"与 OPA 同一机制，仅边界条件不同"（该文用"similarity and distinction"，未用"misnomer"，此处亦避免过度指控命名本身，聚焦于物理范畴的澄清）。
- **非线性/自发增益 PTC = 可成真 DTC 的候选**。一旦加 χ⁽³⁾相互作用(arXiv:2306.13652 路线：耦合参量振子)或真空种子+随机相位机制(arXiv:2507.10862)，可获得多体 SSB，升级为真 DTC。
- **故 S4 整体判定：混合，主体偏术语澄清/范畴纠正。** PTC 的"时间晶体"名号在其标准(线性、均匀)定义下犯了范畴错误（将参量放大误标为自发对称破缺）；只有特定增强(非线性/真空自发)才触及真 DTC。

**对 LP-9 的反馈**：PTC 案例**强化**了 LP-9 的核心警觉——"出现 period-doubling/subharmonic"远不足以判定时间晶体。判据必须落在**自发性(简并+随机选择)、相互作用(SSB 的数学必要条件)、刚性(锁相平台)**三者，而非表面的周期翻倍。这条判据同样可回头审视 S1-S3 里的 DTC 候选。
