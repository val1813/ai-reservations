## §0 检验的精确逻辑结构

### 0.1 两个互斥假说

| | 假说H₁（标准解读） | 假说H₂（LP-19投影几何） |
|---|---|---|
| **机制** | 增益诱导非线性分岔→谱空间对称性破缺→双峰 | ξ依赖增益→不同ξ孤子不同程度放大→η投影自然双峰 |
| **必要条件** | 需要非线性相互作用（碰撞） | 只需要增益的ξ选择性 + 二维→一维投影 |
| **对均匀增益的预测** | 如果增益足够强且均匀，仍应产生分岔→双峰 | 如果增益均匀（所有ξ同等放大），仅产生Weyl整体平移→无分裂 |
| **对增益带宽的依赖** | 带宽影响分岔阈值，但不影响定性 | 双峰间距直接由增益带宽决定 |
| **碰撞的角色** | 必需的（驱动分岔） | 非必需的（可加速但不产生定性效应） |

### 0.2 判决性检验的逻辑

```
如果 均匀增益 → 无双峰 → H₁被排除（因为H₁预测均匀增益也能分岔）
如果 ξ依赖增益 → 双峰间距∝增益带宽 → H₂的定量预测成立
如果 改变增益带宽中心 → 双峰间距按投影几何规律移动 → H₂被验证
如果 碰撞可关闭而双峰仍存在 → H₁的碰撞驱动机制被排除
```

### 0.3 A博士的反对称核否定定理作为前提

A博士（淬火半圆理论）已严格证明：反对称散射核 K ∝ (ξ-ξ')/|λ-λ'|² 在η方向的系综平均为零（⟨K_η⟩_φ = 0），因此碰撞积分在η方向不产生静态斑图——只能产生行波不稳定性。这意味着：**如果实验上观察到静态双峰谱结构，其起源不能是碰撞驱动的Turing分岔。** 这为投影几何解释提供了"排除竞争假说"的支持。

**但：** A博士的证明在无碰撞+纯阻尼前提下严格成立。增益（而非阻尼）情况下，反对称核在η方向的效应是否仍然平均为零？需要检验。这是本文档中"碰撞角色"数值检验的核心动机之一。

## §1 数值实验设计

### 1.1 物理系统的简化描述

考虑增益光纤中的孤子气体。每个孤子由ZS特征值 λ_j = ξ_j + iη_j 描述，其中：
- ξ_j = Re(λ_j)：孤子速度/频率参数
- η_j = Im(λ_j)：孤子振幅参数

在2D Coulomb气体映射下（B博士框架的可用部分），N个孤子的联合动力学近似为：

```
dλ_j/dt = -∇_j V_eff(λ_j) + g(ξ_j) · η_j · e_η + √(2D) · dW_j(t) + C_coll[{λ_k}]
```

其中：
- V_eff：限制势（保持特征值在有限区域内）
- g(ξ_j)：ξ依赖的增益系数——这是检验的核心变量
- e_η：η方向的单位向量
- D：有效扩散系数
- C_coll：碰撞积分（可选开关）

### 1.2 增益模型

#### 配置A：ξ依赖增益（模拟Fache喇曼增益）

喇曼增益有有限带宽。在频率空间（ξ ∝ ω-ω₀），增益剖面为：

```
g_A(ξ) = g₀ · exp(-(ξ - ξ_c)² / (2σ_g²))
```

其中：
- g₀ = 峰值增益系数（归一化，取值~0.05-0.1）
- ξ_c = 增益中心频率（由泵浦波长决定）
- σ_g = 增益带宽（Δλ ~10-20 nm 对应归一化σ_g ~0.05-0.15）

**物理依据：** Fache实验中喇曼增益的典型带宽Δλ~15 nm。在归一化ZS参数中（ξ归一到孤子谱宽Λ~2），σ_g ≈ 0.1。

#### 配置B：均匀增益（对照）

```
g_B(ξ) = g₀ = const（对所有ξ）
```

所有ξ位置的孤子被同等放大。这是H₁（分岔假说）和H₂（投影几何假说）给出不同预测的关键对照配置。

### 1.3 初始DOS

为匹配Fache实验的初始条件，初始DOS取为Weyl分布（等谱可积极限）：

**方案1（Weyl初始条件）：**
```
f₀(ξ,η) = (1/Z) · √(R² - ξ² - η²)  · 1_{ξ²+η² ≤ R²}
```
这是二维Weyl圆盘——(ξ,η)在圆盘内均匀（密度与径向坐标的几何因子有关）。

**方案2（更一般的椭圆初始条件）：**
```
f₀(ξ,η) = (1/Z) · √(1 - ξ²/Ξ² - η²/R²)  · 1_{ξ²/Ξ² + η²/R² ≤ 1}
```
其中Ξ是初始ξ半宽，R是初始η半宽。这可检验初始ξ-η关联对投影双峰的影响。

### 1.4 数值方法

**粒子模拟（推荐）：**
- N = 200-1000个粒子（孤子），每个携带λ_j(t)
- Euler-Maruyama积分：λ_j(t+Δt) = λ_j(t) + [增益漂移 + 限制势 + 碰撞（可选）]·Δt + √(2DΔt)·N(0,1)
- 时间步长：Δt = 0.001-0.01（归一化单位）
- 总传播时间：T_max = 10-50（对应Fache实验量级）

**连续场模拟（备选）：**
- 在ξ-η网格上求解Fokker-Planck方程
- ∂_t f(ξ,η,t) = -∂_η[g(ξ)·η·f] + D(∂²_ξ + ∂²_η)f + 边界条件 + 碰撞项
- 网格分辨率：200×200以上

**推荐粒子模拟：** 因为(i)更接近物理实际（有限N孤子气体），(ii)可直接与Fache的IST反演数据（离散{λ_j}集合）对比，(iii)碰撞项在粒子层面更容易实现。

### 1.5 诊断量

**(D1) η边缘分布（一维DOS）：**
```
f_η(η,t) = ∫ f(ξ,η,t) dξ
```
主要诊断：单峰 vs 双峰，峰位置η₁, η₂，峰间距Δη = |η₂-η₁|。

**(D2) ξ-η联合分布的椭圆度：**
```
e(t) = √(1 - σ_η²(t)/σ_ξ²(t))
```
其中σ_η², σ_ξ²是点云在η和ξ方向的方差。e=0→圆，e→1→高度扁平（η坍缩，ξ扩散）。

**(D3) 条件均值η̄(ξ)：**
```
η̄(ξ,t) = E[η | ξ, t]
```
如果投影几何假说成立，η̄(ξ)应与g(ξ)正相关——增益大的ξ位置，η均值更大。

**(D4) 峰间距Δη与增益带宽σ_g的关系：**
数值扫描σ_g ∈ [0.02, 0.30]，提取Δη(σ_g)。投影几何预测Δη ∝ σ_g（线性或幂律<1）。

## §2 预测：从理论到数值

### 2.1 定性预测（判决性）

| 预测 | 配置A（ξ依赖增益） | 配置B（均匀增益） | H₁（分岔）预测 | H₂（投影）预测 |
|------|-------------------|-------------------|---------------|---------------|
| η边缘双峰 | ✅预期出现 | ❌预期不出现 | A和B都出现 | A出现，B不出现 |
| η̄(ξ)与g(ξ)相关 | ✅正相关 | ❌平坦 | 不明确 | ✅正相关 |
| 碰撞关闭后双峰 | ✅仍存在（减弱但不消失） | ❌无双峰 | ❌消失 | ✅仍存在 |
| 双峰间距时间演化 | 先增大后稳定 | N/A | 阈值后突然出现 | 随增益逐渐显现 |

**判决性检验1（最强）：** 如果配置B（均匀增益）产生双峰，H₂（投影几何）被证伪——因为均匀增益没有ξ选择性，投影不能产生多峰。H₁（分岔）被支持。

**判决性检验2（次强）：** 如果配置A产生双峰而配置B不产生，H₂被支持。但需要额外排除"配置B的均匀增益恰好低于分岔阈值"的可能——通过在配置B中扫描增益强度g₀来排除。

**判决性检验3：** 如果在配置A中关闭碰撞（令C_coll=0）后双峰仍然存在，H₁（需要碰撞的分岔机制）被排除或至少严重削弱。

### 2.2 定量预测

#### P1：峰间距与增益带宽的关系

在投影几何框架下，考虑增益剖面g(ξ)作用于初始均匀二维点云。在时间t后，η(t|ξ) ≈ η₀ · exp(g(ξ)·t)。对于两个ξ值ξ₁, ξ₂，其η的差异为：

```
Δη(t) ≈ η₀ · [exp(g(ξ₁)·t) - exp(g(ξ₂)·t)]
     ≈ η₀ · exp(g₀·t) · [g(ξ₁) - g(ξ₂)] · t  (小t极限)
```

当g(ξ)为Gaussian型（带宽σ_g），增益最大处ξ=ξ_c的η增长最快，远离ξ_c处增长慢。在η投影中，增益峰值区域贡献的η值大于两侧→形成以η≈η₀·exp(g₀·t)为中心的峰，而远离增益中心的ξ贡献的η值形成第二个峰或展宽的肩部。

更精确地：如果初始ξ-η为半径为R的圆盘（均匀密度），增益g(ξ)作用Δt后，点(ξ,η)映射到(ξ, η·exp(g(ξ)·Δt))。ξ的支撑集不变（假设碰撞关闭），η的支撑集变为[η_min·exp(g_min·Δt), η_max·exp(g_max·Δt)]。η边缘分布为：

```
f(η) = (2/R) · ∫ dξ · δ(η - η₀(ξ)·exp(g(ξ)·Δt))
     = (2/R) · Σ_{ξ: η₀(ξ)·exp(g(ξ)·Δt) = η} [1/|∂(η₀·exp(g·Δt))/∂ξ|]
```

在η₀(ξ)=√(R²-ξ²)（圆盘边缘）时，雅可比行列式中的驻点导致van Hove奇点——这些奇点在η投影中表现为峰值。对于Gaussian g(ξ)，存在0, 1, 或2个驻点，分别对应0, 1, 或2个van Hove峰。

**数值预测（待计算验证）：**
- 若σ_g ≪ R（增益带宽远小于初始谱宽）：g(ξ)近似δ函数→仅增益中心附近ξ被放大→单个η峰（移位Weyl）
- 若σ_g ~ R/3到R/2：g(ξ)的变化尺度与圆盘几何特征匹配→两个驻点→双峰
- 若σ_g ≫ R（增益带宽远大于初始谱宽）：g(ξ)近似常数→回归均匀增益→单峰

**双峰出现条件：** σ_g/R ∈ [0.1, 0.5]（量级估计，需数值确认精确区间）。

#### P2：峰宽度与初始DOS谱宽的关系

在投影几何中，每个η峰的宽度Δη_peak由以下因素决定：
1. 增益剖面在驻点附近的曲率（越尖锐→峰越窄）
2. 初始DOS在对应ξ区域的η分布宽度
3. 扩散导致的展宽

定量估计：
```
Δη_peak ≈ η₀ · exp(g·Δt) · √[(σ_η⁰)² + (g'·σ_ξ·Δt)² + 2DΔt]
```
其中σ_η⁰是初始η分散，g'是增益梯度，σ_ξ是ξ方向的相关长度，D是扩散系数。

**数值预测：** 初始DOS的η半宽R越大→峰越宽。如果Fache实验改变初始脉冲能量（从而改变初始η谱宽），峰宽度应按√规律变化。

#### P3：传播距离依赖

定义归一化传播时间τ = g₀·t。

- τ < 0.5：增益效应弱，DOS维持近似Weyl单峰（或轻微展宽）
- τ ~ 1-2：双峰开始可分辨（峰值间距超过峰的半高宽）
- τ ~ 3-5：双峰完全分离，间距Δη持续增长
- τ ≫ 5：高η峰持续增长，低η峰相对减弱（因为增益差异的指数放大）

**Fache实验对应：** 在8 km光纤中，增益段的等效归一化τ依赖于增益系数和色散长度的乘积。如果τ ~ 2-4（合理估计），投影几何预测可分辨的双峰。

#### P4：初始DOS ξ-η关联的影响

如果初始DOS不是圆盘而是椭圆（Ξ ≠ R）或具有ξ-η相关性（如倾斜椭圆，cov(ξ,η) ≠ 0）：

- **Ξ ≫ R（ξ方向宽，η方向窄）：** 更多ξ值参与投影→双峰更明显（因为增益的ξ选择性作用于更宽的ξ范围）
- **Ξ ≪ R（ξ方向窄，η方向宽）：** ξ选择性有限→双峰减弱，趋近均匀增益情况
- **cov(ξ,η) > 0（正相关）：** ξ大的孤子初始η也大→可能抵消或增强增益效应（取决于g(ξ)的符号和形状）

### 2.3 与A博士淬火半圆理论的对接

A博士的淬火半圆理论给出的是**阻尼**方向的行为——η投影自然产生半圆（椭圆支撑集的边缘分布）。本检验关注的是**增益**方向的互补现象——增益的ξ选择性产生η投影的双峰。

两个理论在数学结构上是对偶的：
- 阻尼：η坍缩 + ξ扩散 → 准椭圆 → η投影 = 半圆（单峰，特定函数形式）
- 增益（ξ选择性）：η差异化增长 + ξ扩散 → 蝴蝶结形支撑集 → η投影 = 双峰

两者共用同一数学原理：**二维(ξ,η)支撑集的几何形状决定一维η投影的函数形式。耗散只负责改变支撑集形状——投影本身是纯几何的。**

## §3 判决性实验方案（可被Fache组直接使用）

### 3.1 方案A：改变喇曼泵浦波长

**原理：** 不同泵浦波长→喇曼增益的中心频率ξ_c移动→增益剖面在ξ空间平移→投影双峰的间距应相应变化。

**预测（投影几何）：**
```
Δη(λ_pump) ≈ Δη₀ + κ · (λ_pump - λ_pump⁰)
```
其中λ_pump是泵浦波长，κ是由增益剖面和投影几何确定的系数。

**预测（非线性分岔）：**
分岔阈值和双峰间距对泵浦波长不敏感（只要泵浦功率足够跨越阈值）——因为分岔由非线性动力学决定，泵浦波长仅影响增益强度，不改变分岔结构。

**实验要求：**
- 保持泵浦功率不变
- 扫描泵浦波长：λ_pump = 1440, 1450, 1460, 1470, 1480 nm（典型喇曼增益范围）
- 每个波长测量IST反演的{λ_j}并提取η边缘分布
- 约5-10次独立实验

**判决条件：**
- 若Δη随λ_pump单调变化且符合投影几何预测→H₂被支持
- 若Δη不随λ_pump变化（仅整体强度变化）→H₁（分岔）被支持

### 3.2 方案B：改变初始DOS的ξ-η关联

**原理：** 通过改变输入脉冲的啁啾（chirp）参数，控制初始ξ-η关联。

正啁啾（C>0）：频率随时间增加→ξ和η正相关（高ξ对应高η）
负啁啾（C<0）：频率随时间减少→ξ和η负相关（高ξ对应低η）
无啁啾（C=0）：ξ和η大致独立

**预测（投影几何）：**
- C>0（ξ-η正相关）：如果g(ξ)在低ξ处大，增益放大效应被初始条件抵消→双峰减弱
- C<0（ξ-η负相关）：如果g(ξ)在低ξ处大，增益放大效应被初始条件增强→双峰更明显
- C=0：中等双峰

具体符号取决于g(ξ)的中心位置和啁啾方向。

**预测（非线性分岔）：**
啁啾可能影响分岔阈值（通过改变初始条件的"距离"到分岔点），但不改变分岔后的双峰特征（吸引子结构由方程决定，不由初始条件决定）。

**实验要求：**
- 固定泵浦波长和功率
- 扫描输入啁啾：C = -0.5, -0.25, 0, +0.25, +0.5 ps²（典型值）
- 每个啁啾值测量IST
- 约5次独立实验

### 3.3 方案C：传播距离扫描（最费时但最强）

**原理：** 在多个传播距离处截断光纤并测量DOS。

**预测（投影几何）：**
- 双峰从单峰连续演化而来（无阈值行为）
- Δη(z)平滑增长，初始阶段近似线性（小增益），后期近似指数
- 在较短距离（z < z₁）无双峰，中间距离（z₁ < z < z₂）出现，长距离（z > z₂）完全分离

**预测（非线性分岔）：**
- 存在阈值距离z_c，z < z_c时无双峰，z > z_c时突然出现
- 双峰间距在阈值处跳跃（一阶相变）或连续但从零快速增长（二阶相变）

**实验要求：**
- 5-8个传播距离：1, 2, 4, 6, 8, 12, 16, 24 km（或对应归一化距离）
- 每个距离的IST测量
- 这是最费时的方案，但提供最强的区分力

### 3.4 方案D：对已发表数据的补充分析（零新增实验）

**P_II（边缘锐度）：** 从Fache已发表的DOS直方图提取边缘行为。投影几何预测软边缘（扩散平滑），非线性分岔预测尖锐边缘（相变特征）。

**P_VI（间距分布）：** 如果Fache实验组能提供原始{λ_j}数据，计算最紧邻间距分布P(s)。反对称碰撞核（A博士定理）预测特定的排斥范围（~0.5-1归一化η），可用于确认或否认碰撞的角色。

**ξ-η联合分布：** 从原始{λ_j}数据画f(ξ,η)的二维直方图。投影几何预测η̄(ξ)与g(ξ)正相关——这是一条不依赖任何模型参数的检验。

## §4 数值模拟的具体实现规范

### 4.1 粒子模拟伪代码

```python
# 增益投影双峰检验 — 粒子模拟
import numpy as np
from scipy.stats import gaussian_kde

class SolitonGasSimulation:
    def __init__(self, N=500, R_init=0.8, Xi_init=0.8,
                 g0=0.05, sigma_g=0.1, xi_c=0.0,
                 D=2e-4, dt=0.005, boundary_R=2.0):
        """
        N: 孤子数
        R_init: 初始η半宽
        Xi_init: 初始ξ半宽
        g0: 峰值增益系数
        sigma_g: 增益带宽
        xi_c: 增益中心ξ
        D: 扩散系数
        dt: 时间步长
        boundary_R: 限制势半径
        """
        self.N = N
        self.dt = dt
        self.D = D
        self.g0 = g0
        self.sigma_g = sigma_g
        self.xi_c = xi_c
        self.boundary_R = boundary_R

        # 初始化：Weyl圆盘
        self._init_weyl_disk(R_init, Xi_init)

    def _init_weyl_disk(self, R, Xi):
        """在椭圆内均匀采样"""
        # 使用rejection sampling
        xi = []
        eta = []
        while len(xi) < self.N:
            x = (np.random.random() * 2 - 1) * Xi * 1.1
            y = np.random.random() * R * 1.1
            if (x/Xi)**2 + (y/R)**2 <= 1:
                xi.append(x)
                eta.append(y)
        self.xi = np.array(xi[:self.N])
        self.eta = np.array(eta[:self.N])

    def gain_profile(self, xi, config='A'):
        """增益剖面"""
        if config == 'A':  # ξ依赖
            return self.g0 * np.exp(-(xi - self.xi_c)**2 / (2 * self.sigma_g**2))
        else:  # 均匀
            return self.g0 * np.ones_like(xi)

    def confinement_force(self, xi, eta):
        """限制势：软墙在boundary_R处"""
        r = np.sqrt(xi**2 + eta**2)
        # 谐振势：F = -k * (r - boundary_R) * r_hat for r > boundary_R
        k = 10.0
        mask = r > self.boundary_R
        F_xi = np.zeros_like(xi)
        F_eta = np.zeros_like(eta)
        F_xi[mask] = -k * (r[mask] - self.boundary_R) * xi[mask] / r[mask]
        F_eta[mask] = -k * (r[mask] - self.boundary_R) * eta[mask] / r[mask]
        return F_xi, F_eta

    def collision_kernel(self, xi, eta):
        """反对称碰撞核（A博士形式）"""
        N = len(xi)
        F_xi = np.zeros(N)
        F_eta = np.zeros(N)

        # 两体反对称散射核
        for i in range(N):
            for j in range(N):
                if i == j:
                    continue
                dxi = xi[i] - xi[j]
                deta = eta[i] - eta[j]
                dist2 = dxi**2 + deta**2
                if dist2 < 1e-8:
                    continue
                # 反对称核：∝ (ξ_i-ξ_j)/|λ_i-λ_j|²
                kernel = dxi / dist2
                F_xi[i] += kernel / dist2  # 1/|λ|² 长程
                # η方向：反对称→平均为零（系综平均）
                F_eta[i] += deta / dist2  # 此项在均匀系综下平均为零

        epsilon_coll = 0.01  # 碰撞强度（小参数）
        return epsilon_coll * F_xi / N, epsilon_coll * F_eta / N

    def step(self, config='A', collisions=True):
        """单步演化"""
        g = self.gain_profile(self.xi, config)

        # 增益漂移（仅η方向）
        drift_eta = g * self.eta

        # 限制势
        F_conf_xi, F_conf_eta = self.confinement_force(self.xi, self.eta)

        # 碰撞（可选）
        if collisions:
            F_coll_xi, F_coll_eta = self.collision_kernel(self.xi, self.eta)
        else:
            F_coll_xi = np.zeros(self.N)
            F_coll_eta = np.zeros(self.N)

        # 噪声
        noise_xi = np.sqrt(2 * self.D * self.dt) * np.random.randn(self.N)
        noise_eta = np.sqrt(2 * self.D * self.dt) * np.random.randn(self.N)

        # Euler-Maruyama更新
        self.xi += F_conf_xi * self.dt + F_coll_xi * self.dt + noise_xi
        self.eta += drift_eta * self.dt + F_conf_eta * self.dt + F_coll_eta * self.dt + noise_eta

        # 硬边界：η ≥ 0（孤子振幅非负）
        self.eta = np.maximum(self.eta, 1e-6)

    def eta_marginal(self, bins=50):
        """计算η边缘分布"""
        hist, edges = np.histogram(self.eta, bins=bins, density=True)
        centers = (edges[:-1] + edges[1:]) / 2
        return centers, hist

    def find_peaks(self, eta_vals, pdf_vals, min_height=0.05, min_separation=0.05):
        """检测η边缘分布中的峰"""
        from scipy.signal import find_peaks
        peaks, properties = find_peaks(
            pdf_vals,
            height=min_height,
            distance=int(min_separation / (eta_vals[1] - eta_vals[0]))
        )
        return eta_vals[peaks], pdf_vals[peaks]

    def conditional_mean_eta(self, xi_bins=20):
        """计算η̄(ξ) = E[η|ξ]"""
        bin_edges = np.linspace(self.xi.min(), self.xi.max(), xi_bins+1)
        bin_centers = (bin_edges[:-1] + bin_edges[1:]) / 2
        mean_eta = np.zeros(xi_bins)
        for i in range(xi_bins):
            mask = (self.xi >= bin_edges[i]) & (self.xi < bin_edges[i+1])
            if mask.sum() > 0:
                mean_eta[i] = self.eta[mask].mean()
        return bin_centers, mean_eta

    def correlation_gain_eta(self, config='A'):
        """计算η̄(ξ)与g(ξ)的相关系数"""
        g = self.gain_profile(self.xi, config)
        return np.corrcoef(self.xi, self.eta)[0, 1]  # 简化：ξ作为g的代理
```

## §6 自我攻击：投影几何的失效条件

### 6.1 攻击1：初始ξ分布太窄

**攻击：** 如果Fache实验中孤子气体的ξ分布初始就非常窄（Δξ ≪ σ_g），增益的ξ选择性没有"材料"可以利用——所有孤子的ξ几乎相同→增益效应几乎均匀→投影不能产生双峰。

**检验：** Fache的IST反演数据中，ξ的分布宽度是多少？如果Δξ < 0.05（归一化），投影几何预测失效——双峰必须来自其他机制。

**防御：** 典型孤子气体的ξ分布宽度通常与η分布宽度同量级（因为Weyl分布是近似各向同性的）。但需要Fache原始数据确认。如果Δξ确实很窄，投影几何假说需要被放弃或修正。

### 6.2 攻击2：强碰撞抹平ξ选择性

**攻击：** 如果碰撞驱动的ξ方向扩散非常快（D_ξ^eff很大），孤子在ξ方向快速混合→每个孤子经历所有ξ值的增益→有效增益被平均化→ξ选择性被抹平→不能产生投影双峰。

**定量条件：** 碰撞混合时间τ_mix ~ ⟨d⟩²/D_ξ^eff。如果τ_mix ≪ τ_gain（增益产生显著η差异的时间），ξ选择性被抹平。即：
```
⟨d⟩²/D_ξ^eff ≪ 1/g₀ → D_ξ^eff ≫ g₀·⟨d⟩²
```
对于Fache参数（g₀~0.05, ⟨d⟩~0.11）：D_ξ^eff ≫ 6×10⁻⁴时ξ选择性被抹平。

**防御：** A博士的淬火半圆理论中估计D_ξ^eff的范围从~2×10⁻⁴（纯热扩散）到~986（碰撞增强）。如果D_ξ^eff取高端值（碰撞增强显著），此攻击有效——投影几何在增益方向被强碰撞破坏。但：(i) D_ξ^eff的精确值未校准——这本身就是一个需要检验的量；(ii) 即使在强碰撞下，增益仍有ξ选择性（因为增益持续注入），碰撞驱动的是扩散而非漂移——扩散抹平梯度但不会完全消除。这是一个需要数值模拟来定量回答的问题——**正因如此，碰撞开关的数值实验是关键**。

### 6.3 攻击3：二维投影的一维权衡——η投影的双峰可能是假象

**攻击：** 投影几何产生双峰的前提是ξ-η支撑集有特定的蝴蝶结形状。但如果增益不仅放大η，还同时改变ξ（通过喇曼效应中的频率啁啾），演化后的(ξ,η)支撑集可能不是蝴蝶结形，而是倾斜或扭曲的形状→η投影可能不产生双峰，或产生多于两个的峰。

**防御：** 这实际上是投影几何框架的**扩展**而非反驳——如果增益同时影响ξ和η，只需将演化后的二维支撑集形状正确地做η边缘投影即可。双峰可能出现也可能不出现——但关键是**不需要非线性分岔来解释出现的任何峰结构**。投影几何的核心主张是"η边缘分布的多峰=二维支撑集几何的必然结果"，不是"必然出现双峰"。

### 6.4 攻击4：Fache实验的双峰可能来自测量伪迹

**攻击：** IST反演在有限信噪比下可能产生伪双峰——特别是当真实DOS是单峰但在低η处有测量噪声导致的伪计数时。

**防御：** 这是实验系统学问题，不涉及理论。解决方案是：在模拟数据上运行相同的IST反演管道，检验反演本身是否引入双峰。

### 6.5 攻击5：投影双峰与淬火半圆的张力

**攻击：** A博士的淬火半圆理论（同一LP-19合成中的理论！）讨论的是**阻尼**下二维投影产生半圆（单峰）。本文档的投影双峰讨论的是**增益**下二维投影产生双峰。两者在物理参数空间中是否相容？是否存在一个统一的(γ, g, D_ξ^eff)参数空间，其中单峰半圆和双峰分别是不同区域的特征？

**这是一个极好的问题——实际上是指向了LP-19的下一阶段方向：**

阻尼（γ>0, g=0）：η坍缩 → 椭圆(ξ宽η窄) → η投影 → 半圆（单峰，淬火瞬态）
增益（γ=0, g>0, ξ选择性）：η差异化增长 → 蝴蝶结 → η投影 → 双峰
增益+阻尼同时存在（γ>0, g>0）：η坍缩与差异化增长的竞争 → 复杂支撑集形状 → 可能是单峰/双峰/多峰/不对称峰

**防御（诚实回答）：** 当前LP-19理论的两部分（淬火半圆和投影双峰）尚未在统一的参数空间中整合。淬火半圆对应的是Fache实验的阻尼段，投影双峰对应的是增益段。它们回答的是同一个实验的不同阶段——增益段产生双峰，阻尼段将双峰转化为淬火半圆（如果阻尼段足够长使碰撞扩散抹平双峰结构）。它们之间不矛盾——它们是同一根光纤的增益段和阻尼段的各自描述。但统一描述需要确定增益段出口的DOS作为阻尼段入口的初始条件——这需要耦合增益-阻尼的全程模拟。

### 6.6 攻击6：可能根本不是投影——是真实的动力学相变

**攻击：** 如果配置B（均匀增益）也产生双峰，且双峰有阈值行为（突然出现而非连续演化），那么投影几何被排除，真实动力学相变被支持。此时，虽然A博士证明了反对称核不产生Turing斑图，但可能存在其他动力学机制——例如：

**候选替代机制1：增益诱导的谱凝聚（Bose-Einstein-like condensation in spectral space）。** 类似于2D随机生长中出现的凝聚现象——增益使粒子聚集到特定谱区域，形成宏观占据。

**候选替代机制2：辐射-孤子耦合的Hopf分岔。** 增益同时作用于孤子和辐射场。辐射场与孤子模的耦合可以产生Hopf分岔，导致谱空间中出现极限环——其时间平均的投影表现为双峰。

**候选替代机制3：有限N效应导致的准周期轨道。** 在有限N（N~100）下，孤子气体的碰撞动力学可能产生长寿命的准周期集体模——其η投影的时间平均出现多峰。这不是稳态，而是遍历性破缺的瞬态——与A博士的"淬火瞬态"气质一致，但机制不同（准周期轨道 vs 几何投影）。

**这些替代机制的共同点：** 它们都比投影几何复杂得多，涉及真实的动力学不稳定性或非线性效应。Ockham剃刀倾向于投影几何——但它必须通过数值检验。

## §8 结论与行动建议

### 8.1 理论层面的结论

1. **投影双峰是纯几何效应**：如果增益有ξ依赖性（频率选择性），η投影自然产生多峰。这不需要任何非线性分岔机制、相变、或新物理。这是二维→一维投影的平凡数学推论。
