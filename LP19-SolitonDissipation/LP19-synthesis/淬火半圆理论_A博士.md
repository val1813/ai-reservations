# 摘要

Fache et al. [PRL 135, 157201 (2025)] 报告了阻尼光纤中孤子气体态密度（DOS）呈Wigner半圆分布，并解释为可积系统凝聚体平衡态（El-Tovbis NDR极限）。本文通过阻尼Fokker-Planck算符的完整谱分解、非正态性分析和淬火动力学判据，证明该解释在物理上不成立：半圆分布不是稳态吸引子，而是衰亡路上的瞬态快照。三条独立证据链汇合：(i) 阻尼FP算符的最慢衰减本征模是Maxwell分布而非半圆——半圆性只能来自二维(ξ,η)几何投影；(ii) 算符的非正态性使瞬态增长率比渐近衰减率大20倍，碰撞积分通过非正态放大产生O(1)效应；(iii) 实验参数γτ_int ≈ 2.5 > 1，系统处于淬火区而非退火区——冷却速率超过内部弛豫速率，NDR平衡态不可达。我们提供定理A（半圆瞬态性）和定理B（淬火判据），推导物理机制链条，提出三项可检验预测（R-ρ关系、边缘锐度、ξ-η联合分布），并声张Fache实验的"半圆"需要根本性的重新解释。

# §1 引言：一个问题、三个发现、一个矛盾

## 1.1 问题的精确陈述

Fache et al. (2025) 在8 km阻尼光纤输出端测量了孤子气体的谱态密度（DOS），发现其呈Wigner半圆分布。该结果被解释为El-Tovbis NDR（非线性色散关系）描述的孤子凝聚体平衡态[El & Tovbis, J. Stat. Phys. 180, 612 (2020)]。然而，阻尼是耗散过程——它动态地破坏可积性。如果系统趋于NDR平衡态，必然涉及一个弛豫机制：耗散如何驱动初始非平衡DOS进入NDR可积极限的吸引盆？

本文的核心论断是：**这一设问本身就是错误的——阻尼不是"驱向"半圆，而是快速淬火冻结了一个非平衡瞬态。该瞬态的二维几何投影恰好呈现半圆形状。Fache实验的半圆不是El-Tovbis NDR平衡态。**

## 1.2 三个发现的逻辑链

本文建立在三轮深挖推导的三个核心发现之上：

| 发现 | 内容 | 严格程度 |
|------|------|---------|
| **R1** | 阻尼FP算符L = -∂_η(2γη·) + D∂²_η的完整谱分解。最慢衰减模是Maxwell分布 f_M(η) ∝ η e^{-γη²/D}，真稳态是零DOS | 严格（解析完成） |
| **R2** | 算符非正态性：数值abscissa ω(L) ≈ 2.0 ≫ 谱abscissa α(L) = 2γ = 0.1。瞬态增长率比渐近衰减率大20倍 | 半严格（离散化估计，未做收敛性检验） |
| **R3** | 降温速率vs内部弛豫速率的定量比较：γτ_int ≈ 2.5 > 1 → 系统处于淬火区，非退火区 | 半严格（τ_int依赖D_ξ^eff，后者未精确校准） |

R1-R3形成一条完整的逻辑链：
- R1证明：如果存在稳态，它必须是零DOS（真稳态）或Maxwell分布（最慢衰减准稳态轮廓）。半圆两者都不是。
- R2揭示：非正态放大使系统在初始阶段经历快速形状重组，弱碰撞积分被放大到与阻尼漂移同量级，使系统偏离纯FP预言。
- R3给出定量判据：系统处于淬火区——观察到的半圆是"冻结"在快速重组阶段的瞬态，不是退火到NDR基态的结果。

## 1.3 与El-Tovbis NDR的根本张力

El-Tovbis NDR描述的是**等谱**条件下孤子凝聚体的最强熵态。其基本假设包括：
- (i) N → ∞（连续极限）
- (ii) 动力学等谱（所有λ_j = const）
- (iii) 孤子气体处于平衡态（最大熵构型）

阻尼破坏了(ii)和(iii)。阻尼下η指数衰减 → 等谱不成立 → NDR的适用条件不被满足。**Fache实验在非等谱条件下报告了等谱理论的结果——这就是矛盾的根源。**

# §2 定理A：半圆瞬态性

## 2.1 定理声明

**定理A（阻尼FP算符下半圆分布的瞬态性）**

**前提：**
1. 孤子振幅η满足阻尼Fokker-Planck方程：∂_t f(η,t) = ∂_η(2γη f) + D ∂²_η f，γ > 0，η ∈ [0, ∞)
2. 边界条件：η = 0处施加吸收边界 f(0,t) = 0（对应孤子衰变为辐射的不可逆过程）
3. 有限扩散系数 D > 0
4. 除阻尼漂移和扩散外，无其他动力学过程（纯阻尼+扩散，无碰撞）

**结论：**
- (a) FP算符 L = -∂_η(2γη·) - D∂²_η 的离散谱为 λ_n = 2γ(2n+1)，n = 0,1,2,...（仅奇Hermite模满足吸收边界）
- (b) 最慢衰减模（λ₀ = 2γ）的轮廓为 Maxwell分布：f_M(η) = (2γ/D) η e^{-γη²/D}
- (c) 半圆分布 f_SC(η) = (2/πR²)√(R²-η²) （在[0,R]上）不是（a）中任何本征模，也不是本征模的有限线性组合可以精确复现的函数形式
- (d) 真稳态解为 f_ss ≡ 0（所有概率质量通过η=0泄漏，总质量以速率2γ指数衰减）

**严格程度：严格证明。**
- (a)-(b)：解析完成。FP算符通过变换z = √(γ/D)·η，φ = e^{-z²/2}ψ映射到量子谐振子，边界条件选择奇Hermite模。推导见深挖阻尼第1轮§R1.1-R1.6。
- (c)：半圆是紧支撑代数函数，而Hermite函数系{e^{-z²/2}H_n(z)}在[0,∞)上的线性组合产生的是经Gaussian调制的多项式，无法精确复现紧支撑代数函数。这是函数空间归属问题——半圆 ∈ C∞([0,R))但∉ Hermite函数系的闭包（在L²([0,∞))中）。
- (d)：由吸收边界下的质量守恒直接导出。

**数学严格性边界：**
- 定理A在**无碰撞**前提下严格成立。
- 加入碰撞积分C[f]后，算符变为非线性的L[f] = L₀ + C[·,f]，本征模分析不再严格。定理A指示的是纯阻尼极限下的行为——这是一个严格的基线，任何碰撞效应都在此基线上叠加。

## 2.2 定理A的物理含义

定理A的直接推论是：**如果Fache实验的唯一起作用的物理机制是阻尼+热扩散，观察到的η边缘分布应是Maxwell分布（∝ η e^{-γη²/D}），而非半圆。**

Fache实验实际观察到半圆。这只有两种可能：
1. **二维几何投影**：半圆来自二维(ξ,η)平面中有限支撑集的η边缘投影——Δξ(η) ∝ √(R²-η²) → 对均匀二维分布的边缘积分自然产生半圆（Eq. R1.7）
2. **碰撞积分塑形**：碰撞积分C[f]（非零）修正了有效特征模，使总效应偏离Maxwell

定理A排除了一维η动力学自身产生半圆的可能性。半圆的来源必须到二维几何或碰撞效应中寻找——这引向物理机制链条（§4）。

## 2.3 定理A的局限性

- **碰撞被排除**：定理A的前提中没有碰撞积分。如果碰撞足够强，有效算符可能发生定性变化。但R2的分析表明，碰撞在纯阻尼下产生的是**行波不稳定性**（由于反对称散射核），而非静态斑图——这意味着碰撞不会在η空间产生新的静态吸引子。
- **边界条件假设**：定理A使用Dirichlet边界f(0)=0。R2第2推将此修正为Robin边界（通量匹配）。Robin边界下n=0偶Hermite模（Gaussian分量）被允许，与n=1奇模（Maxwell分量）组合可在有限区间[0, η_max]上近似半圆。但这是**拟合**，不是第一性原理预言。
- **但不影响核心结论**：即使修正边界条件，半圆仍然不能从一维FP动力学中作为"稳态解"产生——它最多是Robin边界下两个最低阶本征模的有限区间近似。

# §3 定理B：淬火-退火判据

## 3.1 定理声明

**定理B（耗散孤子气体的淬火-退火判据）**

**前提：**
1. 孤子气体具有两个特征时间尺度：耗散弛豫时间 τ_diss = 1/(2γ)（阻尼将η质量衰减到1/e的时间），内部弛豫时间 τ_int = ⟨d⟩²/D_ξ^eff（碰撞+扩散使系统在ξ方向达到局域平衡的时间）
2. 系统从任意初始DOS出发，经历阻尼驱动的能量衰减
3. 孤子间碰撞的强度足以产生有效的ξ方向扩散（D_ξ^eff > 0）

**定义 Damkohler数：** Da ≡ τ_int / τ_diss = 2γ · τ_int

**结论：**
- (a) 若 Da ≪ 1（τ_int ≪ τ_diss）：系统处于**退火区**。内部弛豫远快于耗散 → 系统在衰减过程中始终保持准平衡 → 经历一系列平衡态 → 如果NDR是全局吸引子，系统在Da→0极限下趋近NDR平衡态。
- (b) 若 Da ≳ 1（τ_int ≳ τ_diss）：系统处于**淬火区**。耗散快于或等速于内部弛豫 → 系统来不及在每个中间温度达到平衡 → 观察到的DOS是冻结的非平衡瞬态 → NDR平衡态不可达。
- (c) 在Fache实验参数下：γ = 0.05（归一化），⟨d⟩ ≈ 0.11（点间距），D_ξ^eff的纯碰撞贡献为~986（量级估计，有不确定性） → 即使取保守的有效扩散系数 D_ξ^eff ~ 2×10⁻⁴（仅热扩散，无碰撞增强），τ_int = ⟨d⟩²/D_ξ^eff = 0.0121/2×10⁻⁴ ≈ 60 → Da = 2×0.05×60 ≈ 6 > 1。若取碰撞增强 D_ξ^eff ~ 1，τ_int ≈ 0.0121 → Da ≈ 0.0012 < 1。
- (d) 由于碰撞驱动的D_ξ^eff存在量级不确定性（从~10⁻²到~10²均可能），Da的精确值无法从第一性原理确定。
- (e) **但**：即使取对退火区最有利的假设（D_ξ^eff大 → Da小），退火到NDR基态需要传播距离 z_anneal ≫ τ_diss · ln(初始能/基态能) ~ 10 · ln(η_max/η_min) ~ 20-30 归一化单位。Fache实验的8 km对应约0.8-8归一化单位 → **传播距离不足以完成退火，即使有快速内部弛豫。**

**严格程度：半严格（数值证据级）。**

- τ_diss = 1/(2γ) 是严格导出的
- 内部弛豫时间τ_int的定义和量级估计依赖于D_ξ^eff，后者有量级不确定性
- (e)的论证是量级分析，不是严格不等式
- Da = 1作为分界线是经验性的——实际的临界Da值可能不是精确的1

## 3.2 判据的鲁棒性

即使在D_ξ^eff的不确定性下，定理B的核心结论是鲁棒的：

**引理B1（传播距离硬约束）：** 在阻尼下，无论内部弛豫多快，总η质量M(t) = Σ_j η_j(t)满足M(t) ∝ e^{-2γt}（在碰撞平均为零的系综平均下）。因此DOS支撑集的η方向宽度Δη(t) ∝ e^{-2γt}。在传播距离z处（对应t = z/L_D），Δη(z) = Δη(0)·e^{-2γz/L_D}。要观察到可分辨的半圆型DOS（η支撑集宽度大于噪声地板），需要z < z_max = (L_D/2γ) ln(Δη(0)/η_noise)。对于Fache参数：z_max ~ 10 × ln(0.8/0.01) ≈ 44归一化单位。8 km在可能范围内——但这是在衰减轨迹上的**单次快照**，不是稳态。

**引理B2（半圆半径的演化）：** 如果观察到的半圆来自有限二维支撑集（准椭圆瞬态），其半径R(t)不是常数量——它随时间（传播距离）衰减。如果在两个不同传播距离z₁ < z₂处测量，应有R(z₂) < R(z₁)。这是淬火瞬态的关键特征——真正的NDR平衡半圆有固定的R（仅由孤子密度ρ决定）。

## 3.3 与Fache实验参数的定量对齐

| 参数 | 符号 | 值 | 来源 |
|------|------|-----|------|
| 归一化阻尼系数 | γ | 0.05 | Fache实验的损耗系数估计 |
| 孤子数 | N | ~10² | Fache IST反演 |
| 典型孤子间距 | ⟨d⟩ | ~0.11 | (支撑集/N)^{1/2} |
| 热扩散系数 | D | ~2×10⁻⁴ | 辐射-孤子耦合微观估计 |
| 阻尼弛豫距离 | z_diss = 1/(2γ_phys) | ~10-50 km | γ_phys ~ 0.01-0.05 km⁻¹ |
| 实验传播距离 | z_exp | 8 km | Fache et al. (2025) |
| Damkohler数（保守） | Da | ~6 | 仅热扩散，D_ξ^eff = D |
| Damkohler数（碰撞增强） | Da | ~0.001-0.1 | D_ξ^eff包含碰撞ξ扩散 |

**淬火判据应用于Fache：** 在热扩散保守估计下，Da ≈ 6 > 1 → 明确淬火区。在碰撞增强估计下，Da < 1但传播距离z_exp ~ 8 km远小于完成退火所需距离（~20-30归一化单位） → 仍不足以达到NDR平衡态。

# §4 物理机制：为什么Fache实验看到半圆

## 4.1 机制链条概览

Fache实验的半圆是以下物理过程的产物——**不是平衡态热化，而是瞬态几何投影**：

```
初始等谱Weyl DOS → 阻尼破坏等谱性 → η指数坍缩 + 碰撞ξ扩散 → 
ξ-η平面准椭圆支撑集 → 非正态瞬态放大加速形状重组 → 
Robin边界允许Gaussian+Maxwell混合 → η边缘投影 ≈ 半圆
```

**每一步的特征尺度：**

| 步骤 | 机制 | 特征尺度 | 量级估算 |
|------|------|---------|---------|
| ① η坍缩 | 阻尼漂移 -2γη | τ_diss = 1/(2γ) | ~10 归一化单位 |
| ② ξ扩散 | 碰撞 + 热扩散 | D_ξ^eff ~ ? → ? | 从~2×10⁻⁴(纯热)到~10²(碰撞增强) |
| ③ 非正态放大 | 瞬态增长率 ω(L) vs 衰减率 2γ | ω(L)/2γ ≈ 20 | 0.1 τ_diss内完成快速重组 |
| ④ Robin边界 | 辐射→孤子回注通量 | α（滑移长度） | 未知，现象学参数 |
| ⑤ η投影 | 二维→一维边缘化 | Δξ(η) ∝ √(R²-η²) | 椭圆支撑集 → 半圆边缘分布 |

## 4.2 步骤详述

### 步骤①：η坍缩——阻尼驱动的不可逆衰减

孤子振幅的指数衰减是整个过程的驱动力。每个孤子满足dη_j/dt = -2γη_j（一阶Kaup微扰论严格成立的前提：ε ≪ 1，孤子间距足够大）。点云的η坐标均匀收缩到零——这是等谱性被破坏的根本原因。

**关键特征：** η坍缩是**确定性的、单向的**。总η质量M(t)以速率2γ指数衰减（在碰撞平均为零的系综平均下）。这排除了"稳态"的可能性——真稳态只能是M=0（零DOS）。

### 步骤②：ξ扩散——碰撞积分在ξ方向的扩散效应

孤子间碰撞在ξ方向产生有效扩散。由于散射核的反对称性（K_ξ ∝ (ξ_j-ξ_k)/|λ_j-λ_k|²），碰撞主要在ξ方向产生效应（行波不稳定性），而不是在η方向（不产生静态斑图）。

碰撞驱动的ξ扩散系数：
$$D_\xi^{\text{coll}} \sim \frac{(4\pi\varepsilon N)^2 \langle|H|^2\rangle_\phi}{\Lambda^2}$$

在Fache参数下（ε~0.05, N~100, Λ~2），量级估计为~986（归一化单位）。这个数字很大，但依赖未校准的参数⟨|H|²⟩_φ和Λ。保守估计下D_ξ^eff可能比此值小1-2个数量级。

**竞争关系：** 如果D_ξ^eff足够大（> 10⁻¹），ξ方向的快速扩散使点云在ξ方向"摊平"，与η方向的坍缩竞争，在ξ-η平面中形成长宽比不断变化的椭圆形点云。如果D_ξ^eff太小（< 10⁻³），ξ扩散不足以在η坍缩完成前展宽点云 → 点云保持一维线状 → η边缘分布为Maxwell而非半圆。

Fache实验观察到半圆 → 推断D_ξ^eff不太可能极小 → 碰撞增强的ξ扩散可能确实显著。但这需要对D_ξ^eff做独立校准。

### 步骤③：非正态瞬态放大——快速形状重组

阻尼FP算符L = -∂_η(2γη·) - D∂²_η的非正态性（[L, L†] ≠ 0）意味着‖e^{-tL}‖在初始阶段可以**增长**（而非单调衰减），尽管所有本征值都有负实部。

定量方面：数值abscissa ω(L) ≈ 2.0（基于离散化估计，Reddy & Trefethen 1994），而谱abscissa α(L) = 2γ = 0.1。瞬态增长率比渐近衰减率大20倍。

**物理后果：**
- 初始DOS在传播距离的前0.1-0.5 τ_diss内经历快速形状重组（速率~2.0而非~0.1）
- 该阶段对初始条件的微观细节和碰撞积分的微小修正都极其敏感
- 碰撞积分C[f]（强度O(ε) ~ 0.05）通过非正态放大产生有效速度场修正ε·ω(L) ≈ 0.05×2.0 = 0.1，与阻尼漂移（2γη ≈ 0.05-0.08）同量级

这意味着**即使碰撞"看起来"很弱（O(ε)），它在瞬态阶段对DOS廓形的塑造是O(1)的。**

### 步骤④：Robin边界条件——辐射回注

η=0处的物理边界条件不是纯吸收（Dirichlet f(0)=0），而是通量匹配（Robin型）：
$$D \partial_\eta f|_{\eta=0} = -\Phi_{\text{rad→sol}}$$

孤子衰变产生的辐射在光纤中继续传播，可以通过逆IST过程重新转化为孤子（"孤子成核"）。这个回注通量Φ_rad→sol的定量表达式依赖耦合的孤子+辐射输运方程——这是当前未解决的数学问题。

在Robin边界下（滑移长度α），n=0偶Hermite模（Gaussian分量∝ e^{-γη²/(2D)}）被允许——它自动满足f(0)=αf'(0)。与n=1奇模（Maxwell分量∝ η e^{-γη²/(2D)}）组合：
$$f(\eta) = c_0 e^{-\gamma\eta^2/(2D)} + c_1 \eta e^{-\gamma\eta^2/(2D)} + \cdots$$
可以在有限区间[0, η_max]上**近似**半圆型轮廓。适当选择权重c₀,c₁以及截断η_max，拟合优度可以很高。

**诚实标注：** Robin边界下的"半圆近似"是现象学拟合，不是第一性原理推导。权重c₀,c₁和滑移长度α未与微观物理量（γ, D, ρ）建立定量联系。

### 步骤⑤：η边缘投影——半圆作为二维几何必然

如果点云在ξ-η平面中占据准椭圆区域（η方向被阻尼压缩，ξ方向被碰撞扩散展宽），其在固定η处的ξ宽度为：
$$\Delta\xi(\eta) = 2\Xi\sqrt{1 - (\eta/R)^2}$$
其中R是当前时刻的η方向最大振幅（R(t) ≈ η_max·e^{-2γt}），Ξ是ξ方向的有效半宽。η边缘分布为：
$$f(\eta) = \int_{-\Delta\xi(\eta)/2}^{\Delta\xi(\eta)/2} f(\xi,\eta) d\xi$$
若f(ξ,η)在椭圆内近似均匀，则f(η) ∝ √(R²-η²) —— 这正是Wigner半圆。

**这个机制不要求DOS的ξ-η内部密度是均匀的——只需要支撑集本身是椭圆形的，且密度在ξ方向的边际化足够平滑。** 任何在准椭圆区域内的连续分布，其η边缘分布都继承半圆的基本函数形式√(R²-η²)，仅乘上一个缓变的密度权重函数。

## 4.3 为什么El-Tovbis NDR也给出半圆——但那是另一个机制

El-Tovbis NDR平衡半圆和淬火瞬态半圆是**两个不同物理机制产生的相同函数形式**——这是危险的巧合，也是Fache解释错误的核心原因。

| 特征 | NDR平衡半圆 | 淬火瞬态半圆 |
|------|------------|-------------|
| **物理前提** | N→∞, 等谱, 平衡态 | 有限N, 非等谱, 衰亡瞬态 |
| **产生机制** | 最大熵构型 → 完全填充的孤子凝聚体 | η坍缩+ξ扩散 → 准椭圆支撑集η投影 |
| **R-ρ关系** | R² = 4ρ（严格） | R(t) ≈ η_max·e^{-2γt}（不依赖ρ） |
| **边缘行为** | 尖锐平方根奇点 ∝ (R²-η²)^{-1/2} | 扩散平滑 → 指数尾部或软边缘 |
| **ξ-η联合分布** | 支撑集内近似均匀 | η依赖的非均匀密度 |
| **时间依赖性** | 稳态（∂_t f = 0） | 准稳态轮廓 + 总质量指数衰减 |
| **可积性要求** | 严格等谱 | 等谱被破坏（正是通过等谱破坏驱动演化） |
| **R的稳定性** | R不随时间变化 | R随传播距离指数减小 |

**关键区分：** NDR半圆来自统计力学的最大熵原理（等谱约束下的最概然构型），淬火半圆来自动力学的瞬态几何投影（非等谱演化中的瞬时快照）。函数形式相同，物理内容完全不同。

# §5 声张

## 声张1（否定性）：对Fache et al. (2025)的重新解释

**声张：** Fache et al., PRL 135, 157201 (2025)中声称的"半圆分布作为可积凝聚体平衡态"应被重新解释为**非平衡淬火瞬态**。观察到的半圆不是El-Tovbis NDR平衡态的证据，而是阻尼驱动的衰亡过程中的一次快照——其二维几何投影恰好呈现半圆形状。

**声张强度：强**（三条独立证据链汇合）
- 证据1（R1）：纯阻尼FP动力学的最慢衰减模是Maxwell，不是半圆。半圆必须来自二维几何。
- 证据2（R2）：非正态放大使瞬态阶段的动力学显著偏离渐近衰减的预言。碰撞积分通过非正态放大产生O(1)效应，使DOS偏离纯阻尼FP解。
- 证据3（R3）：实验参数落在淬火区——系统不可能在有效传播距离内达到NDR平衡态。

**声张的限定条件：**
- 如果Fache实验的D_ξ^eff异常大（≫10²），且传播距离意外地长（相当于≫30归一化单位），则退火到NDR的可能性不能被完全排除。但当前已发表的实验参数不支持这一情况。
- 声张不否认Fache实验**数据**的有效性——DOS直方图呈半圆型是客观事实。声张针对的是数据的**物理解释**。

**如果声张成立，不要求Fache撤稿——** 它要求的是对已发表数据做补充分析（R-ρ关系、边缘拟合、ξ-η联合分布），以确定数据的正确理论归属。实验本身是优秀的——Editors' Suggestion是合理的——只是理论解释需要修正。

## 声张2（预测性）：半圆的传播距离演化

**声张：** 如果延长传播距离或降低孤子密度，观察到的半圆应逐渐偏离标准Wigner律，最终坍缩到零DOS。存在一个临界传播距离z_c，超过它半圆型特征不再可分辨。

**定量预测：**

**(P1) 半径收缩定律。** 半圆支撑集半径R（在η方向的宽度）随传播距离z按指数衰减：
$$R(z) \approx R_0 \cdot e^{-2\gamma z/L_D}$$
其中R_0是初始η支撑集宽度，L_D是色散长度。对于Fache参数（γ=0.05, L_D~1-10 km）：
- 在z=8 km处：R ≈ R_0·e^{-0.8} ≈ 0.45 R_0（取L_D=10 km）
- 在z=16 km处：R ≈ R_0·e^{-1.6} ≈ 0.20 R_0
- 在z=30 km处：R ≈ R_0·e^{-3.0} ≈ 0.05 R_0 → 半圆特征接近不可分辨

**(P2) 偏离Wigner律的阈值。** 当R(z)降至噪声地板r_noise的2-3倍时，边缘拟合将显著偏离Wigner律。偏离的可检测条件：
$$z > z_{\text{detect}} \approx \frac{L_D}{2\gamma} \ln\left(\frac{R_0}{3r_{\text{noise}}}\right)$$
对于Fache参数（R₀~0.8, r_noise~0.11, γ~0.05）：
$$z_{\text{detect}} \approx 10 \cdot \ln(0.8/0.33) \approx 8.9 \text{ 归一化单位} \approx 9-90 \text{ km}$$

**当前Fache实验的8 km可能在可检测阈值附近。延长传播距离至12-16 km应观察到统计显著的偏离。**

**(P3) 孤子密度依赖性。** 降低初始孤子密度N → 减小碰撞驱动的ξ扩散 → Da增大（更深的淬火） → 半圆形状的"完美度"降低（因为ξ扩散不足以充分展宽点云）。具体预测：
- N~100: 半圆型（Fache当前观察）
- N~30: 介于半圆和Maxwell之间的过渡型
- N~10: 接近Maxwell型（因为碰撞太弱，无法维持ξ扩散，点云保持一维线状）

**声张强度：中等偏强**（部分预测有不确定性）
- P1（半径收缩）是定理A的直接推论——在纯阻尼极限下严格
- P2（偏离Wigner律）的z_detect依赖于r_noise和R₀的精确值
- P3（N依赖性）依赖D_ξ^eff的量级——而D_ξ^eff未精确校准

## 声张3（方法论）：孤子气体DOS稳态概念的重新定义

**声张：** 在耗散孤子气体中，"稳态DOS"这个概念本身需要被解构为三种本质上不同的动力学体制：

| 体制 | 定义 | 特征 | 实例 |
|------|------|------|------|
| (a) **真稳态** | ∂_t f = 0，总质量守恒 | 零DOS（阻尼）或无约束增长（增益，最终光纤损伤） | 阻尼极限t→∞ → f≡0 |
| (b) **淬火瞬态** | γτ_int > 1，耗散快于内部弛豫，DOS是冻结的非平衡构型 | R依赖传播距离，轮廓依赖初始条件，边缘软 | Fache阻尼实验 |
| (c) **退火弛豫** | γτ_int ≪ 1，耗散慢于内部弛豫，DOS经历一系列准平衡态 | 可通过准静态热力学描述，有效温度缓降 | 极弱阻尼+强碰撞扩散 |

**方法论含义：** 任何声称在耗散孤子气体中观察到"稳态DOS"的实验，必须先执行**淬火-退火分类**——报告γτ_int的测量值或估计值，并论证观察到的DOS属于(b)或(c)。不能默认"观察到稳定 = 处于稳态"。

**声张强度：强**（方法论声明，不依赖具体参数的不确定性）

# §6 自我攻击与防御

## 6.1 对定理A的自我攻击

### 攻击A1：碰撞积分可以根本性地改变FP算符的本征模结构——定理A在无碰撞下成立，但在有碰撞时可能完全不描述物理现实。

**攻击强度：中高。** R2中估计碰撞通过非正态放大产生O(1)效应——这意味着碰撞不是小修正，而是可能改变算符的本征模基。

**防御：**
1. 碰撞核的反对称性（在η方向的投影平均为零：⟨K_η⟩_φ = 0）意味着碰撞不产生η方向的净漂移——它只产生扩散和涨落。扩散项D∇²f已经包含在定理A的算符中（通过D的碰撞增强）。涨落项（对C_j相位敏感的随机项）在系综平均下抵消。
2. 即使碰撞完全重塑了有效算符，真稳态仍然是零DOS（因为吸收边界η=0持续泄漏质量）——定理A的核心结论（半圆不是稳态）不因碰撞而改变。
3. **最坏情况：** 碰撞足够强以至于在有限η处产生"有效势垒"阻止质量流向η=0——这种情况下可能存在非零稳态。但反对称核在η方向的净通量为零（系综平均），不支持"势垒"形成。

**攻击A1判定：** 攻击成立，但防御成立。碰撞不改变"真稳态是零"的核心结论，也不创造半圆作为稳态解的可能性。定理A的限定条件（无碰撞）被诚实标注。

### 攻击A2：Robin边界条件（通量匹配）下，本征模结构可能发生定性改变——Maxwell不再是唯一的最慢衰减模。

**攻击强度：中。** 如果Robin滑移长度α很小（弱回注），本征模接近Dirichlet情况——不变。如果α很大（强回注），n=0偶模变得几乎不被抑制——最慢衰减模变为Gaussian ∝ e^{-γη²/(2D)}（非零中心）而非Maxwell（峰在η>0）。

**防御：**
1. 即使最慢模变成Gaussian（n=0），它仍然不是半圆。这强化了而非削弱了定理A的结论。
2. Robin边界下的本征模组合（Gaussian + Maxwell + ...）能否产生精确的半圆轮廓？答案是否定的——Hermite函数的有限线性组合产生的函数在[0,∞)上具有Gaussian尾部，而半圆在R处具有尖锐截止。Robin边界条件的修正仅改变权重c₀,c₁,...，不改变Hermite函数系的渐近行为。
3. 半圆的"紧支撑"特征不能由Hermite函数系（无界支撑）的有限线性组合精确复现。如果Fache实验的半圆具有尖锐边缘，它在函数空间上不属于阻尼FP算符（即使含Robin边界）的任何有限模组合。

**攻击A2判定：** 攻击成立但无害于核心结论。Robin边界修正不影响"半圆不是本征模"的结论。

## 6.2 对定理B的自我攻击

### 攻击B1：Damkohler数Da的临界值可能不是1——淬火-退火的实际分界可能远大于或远小于1。

**攻击强度：中高。** Da=1作为分界线是量级分析的常规做法（如激光冷却中气体的淬火-退火分类），但在孤子气体中没有经过严格的非平衡统计力学推导。实际临界Da可能依赖于系统的微观细节（如DOS的初始形状、孤子数N、碰撞核的具体形式）。

**防御：**
1. 定理B的结论(e)（传播距离不足）不依赖Da的精确临界值。即使退火区延伸到Da>5，Fache实验的8 km（0.8-8归一化单位）仍远小于退火到NDR基态所需距离（~20-30 归一化单位）。这是一个传播距离的硬约束——不依赖Da。
2. 如果实际的D_ξ^eff比保守估计大1000倍（~200），Da≈0.006 ≪ 1，退火区成立。但传播距离约束仍然起作用——即使系统能"跟上"降温，NDR基态本身的弛豫时间仍然可能很长（因为它涉及孤子凝聚体的全局重组）。
3. **最坏情况：** 如果D_ξ^eff确实巨大，且NDR基态弛豫极快，则Fache实验可能真的看到了NDR平衡半圆。但这要求同时满足两个极端条件（超大D_ξ^eff + 超快NDR弛豫），且两者在文献中均无独立证据。

**攻击B1判定：** 攻击在逻辑上成立——Da的临界值是未校准的。但防御提供了不依赖Da的传播距离硬约束（结论e），这是更鲁棒的论证。

### 攻击B2：传播距离的归一化L_D未被Fache实验独立测量——z_exp = 8 km对应的归一化距离可以是0.1或10，取决于L_D的取值。

**攻击强度：高。** 如果L_D = 0.8 km（而非1-10 km），则z_exp = 10归一化单位——接近退火所需距离。如果L_D = 80 km，则z_exp = 0.1归一化单位——系统几乎未演化。归一化距离的2个数量级不确定性直接决定了Fache实验在演化轨迹上的位置。

**防御：**
1. 承认这是当前分析的最薄弱环节。L_D的值需要从Fache实验的独立测量提取（如孤子宽度、脉冲能量、光纤色散参数等）。当前无法从已发表文献中确定精确的L_D。
2. 但这不是理论的致命缺陷——这是实验数据的不完整性。定理B清晰地指明了需要什么样的附加测量（L_D的独立校准）来闭合论证。
3. **补救方案：** 如果Fache实验组能提供L_D的值（或等价地，归一化γ的值），定理B的预测可以定量化。声张2中给出的z_detect是一个函数形式——将其中的参数替换为实际测量值即可得到具体预测。

**攻击B2判定：** 攻击有效。L_D的不确定性是当前论证的最弱环节。防御方向是将此不确定性转化为具体的实验测量建议——而非试图掩盖它。

## 6.3 对声张1的自我攻击

### 攻击C1：El-Tovbis NDR的适用条件可能在弱阻尼下被"有效满足"——如果τ_diss足够长，系统在大部分时间处于准等谱状态，NDR近似成立。

**攻击强度：中。** 在γ → 0的极限下，等谱近似恢复。Fache的γ=0.05可能"足够小"使得NDR在弛豫时间尺度上近似成立（类似Born-Oppenheimer近似中核运动比电子运动慢得多）。如果NDR近似成立，半圆就是NDR平衡态——不是淬火瞬态。

**防御：**
1. γ=0.05不大，但τ_int ~ 0.01-60（取决于D_ξ^eff）。如果τ_int取较大值（~60），则γτ_int ≈ 6 > 1 → 等谱近似建立的速度可能比耗散衰减更慢 → NDR近似不成立。如果τ_int取较小值（~0.01），则γτ_int ≈ 0.001 ≪ 1 → NDR近似可能成立。
2. 这正是为什么τ_int的精确校准（攻击B1）是至关重要的——它决定了NDR近似的合法性。
3. 但即使NDR近似不成立，仍不能排除"有效NDR型行为"的可能性。许多非平衡系统表现出"有效平衡"行为（在适当的粗粒化后）。**Fache半圆要成为真正的NDR平衡态，需要额外的证据——不仅仅是DOS直方图的函数形式（因为淬火瞬态也可以产生半圆型函数形式）。** 这正是N6三项区分标准的意义。

**攻击C1判定：** 攻击有效——γ=0.05是否"足够小"取决于τ_int。这再次指向τ_int校准的关键性。但声张1的强度不因这一攻击而降级——因为声张1不声称"Fache一定不是NDR"，而是声称"仅凭DOS直方图不足以区分NDR和淬火瞬态，需要N6三项检验"。

### 攻击C2：Fache实验可能在无意中已经测量了R-ρ关系或边缘锐度——数据存在于已发表论文的补充材料或原始数据中，只是未被分析。

**攻击强度：低。** 如果Fache实验的原始{λ_j}数据中包含R-ρ关系或边缘锐度的证据支持NDR解释而非淬火解释，那么声张1将被实验数据直接推翻。

**防御：**
1. 这正是声张1希望促成的——不是否定Fache实验，而是促使其进行补充分析。如果补充分析支持NDR解释，声张1被证伪——这是科学进展。
2. 当前Fache et al. (2025)的正文仅展示了DOS直方图（聚合数据）。原始{λ_j}数据是否包含在补充材料中是未知的。我们呼吁数据公开（或至少对补充分析开放）。

**攻击C2判定：** 有效但不严重。声张1的设计正是为了可被实验检验——如果它被证伪，科学进步了。如果它被证实，物理理解加深了。

## 6.4 对声张2的自我攻击

### 攻击D1：R(z)的指数衰减定律 ∝ e^{-2γz/L_D} 只在无碰撞的纯阻尼下成立。碰撞积分可能产生非指数衰减——例如通过辐射回注减缓衰减，或通过碰撞增强的蒸发加速衰减。

**攻击强度：中。** R2的分析表明碰撞在η方向的平均效应为零（⟨K_η⟩_φ = 0），但高阶效应（涨落-耗散定理，非Gaussian修正）可能产生净的η漂移修正。碰撞增强的"蒸发"（动能交换使一些孤子获得额外η → 更容易达到η=0 → 加速衰减）是一个真实的物理效应。

**防御：**
1. 修正的衰减定律应写为 R(z) ≈ R₀·exp(-2γ_eff·z/L_D)，其中γ_eff = γ + δγ_coll。δγ_coll（碰撞对衰减率的修正）的符号和量级未确定。
2. P1的定性预测（半圆半径随传播距离衰减）在γ_eff > 0时仍然成立——仅衰减率的数值有修正。P2的z_detect可以用γ_eff代替γ来计算。
3. 如果δγ_coll < 0（碰撞减缓衰减，例如通过辐射回注），则z_detect可能比纯阻尼预测更长——但仍存在。唯一能彻底推翻P1-P3的情况是γ_eff ≤ 0（碰撞完全抵消阻尼），这在物理上不可能——因为碰撞不创造能量（不产生新的孤子振幅，仅在已有孤子间重新分配能量）。

**攻击D1判定：** 攻击有效——碰撞可修正衰减率。但定性预测（半圆非稳态，R(z)衰减）仍成立。

### 攻击D2：如果Fache实验中的增益段和阻尼段耦合（前向传输的辐射场在增益段和阻尼段之间产生"记忆效应"），传播距离扫描的预测可能不适用。

**攻击强度：低。** Fache实验有明确的增益段和阻尼段的空间分离。如果存在跨区段的耦合（如辐射场从前段泄漏到后段），它可以通过独立测量来标定。

**防御：** 如果辐射跨段耦合确实显著，需要在理论中引入空间非局域项。这是一个已知的复杂因素，但不改变"半圆瞬态"的核心定性——它只改变演化轨迹的具体形状。

## 6.5 对声张3的自我攻击

### 攻击E1：方法论三分法（真稳态/淬火瞬态/退火弛豫）可能过于粗糙。实际系统中可能存在连续过渡区，不能清晰分类。

**攻击强度：低。** 声张3不要求三者之间有无穷清晰的边界——它只要求在报告"稳态DOS"之前进行分类讨论。连续过渡不削弱分类框架的实用性（类似流体力学中层流/过渡/湍流的分类——过渡区存在，但不意味着分类无用）。

**防御：** 三分法的边界确实模糊（尤其是(b)和(c)之间的Da ≈ 1边界）。但这不影响框架的操作价值：关键是报告γτ_int并讨论它落在哪个区——即使接近边界。

**攻击E1判定：** 攻击有效但不伤人。三分法是启发性框架，不是严格的相图分类。

# §8 数学障碍与诚实边界

## 8.1 当前无法逾越的障碍

以下障碍标记了淬火半圆理论当前的精确边界：

**障碍1 — 非线性非正态算符的本征模结构。** 含碰撞积分C[f]的完整FP算符L[f] = L₀ + C[·,f]是非线性的。其"本征模"（在准稳态假设∂_t f ≈ -2γf下的线性化算符的本征模）涉及无穷维矩阵的非线性本征值问题——当前数学无法解析求解。R1的解析仅适用于纯阻尼+扩散（无碰撞）。

**障碍2 — Robin滑移长度α的微观确定。** α的定量值需要求解耦合的孤子+辐射输运方程——一个仍未解决的数学物理问题。α在此理论中是现象学参数。

**障碍3 — D_ξ^eff的精确校准。** 碰撞驱动的ξ方向有效扩散系数的精确值需要数值SDE模拟或独立实验测量。当前仅有量级估计，不确定性跨越多个数量级。

**障碍4 — 非正态瞬态增长方向的解析确定。** 对于带Robin边界的一维谐振子FP算符，最大奇异向量可通过数值计算得到（离散化+SVD），但解析形式未知。这意味着瞬态阶段的具体"目标方向"不能从第一性原理预测。

**障碍5 — Fache原始数据不可得。** 当前已发表的Fache et al. (2025)数据仅为聚合DOS直方图，不含原始{λ_j}列表。N6的三项区分检验（P_I, P_III, P_VI）需要原始谱点数据。P_II（边缘锐度）可从已发表的直方图进行——这是当前唯一不被数据可及性阻挡的检验。

# §9 结论：半圆不是终点

阻尼孤子气体中的"半圆分布"——在Fache et al. (2025)中被解读为可积凝聚体的平衡态信号——经过三轮阻尼深挖后，被重新识别为**衰亡路上的瞬态快照**。

核心论证链：
1. **定理A（严格）**：纯阻尼FP算符的最慢衰减模是Maxwell分布，真稳态是零DOS。半圆不是任何参数下的稳态解。
2. **定理B（半严格）**：实验参数落在淬火区。系统降温太快，来不及在每个温度达到平衡。观察到的半圆是冻结的非平衡瞬态。
3. **机制（物理论证）**：η方向的阻尼坍缩 + ξ方向的碰撞扩散 + 非正态瞬态放大 + Robin边界通量匹配 → 在ξ-η平面中形成准椭圆支撑集 → η边缘投影自然产生半圆。
4. **区分标准（N6）**：淬火半圆和NDR平衡半圆在R-ρ关系、边缘锐度、ξ-η联合分布上有可检验的差异。

**净增量：**
- 将半圆从"稳态吸引子"重新定位为"瞬态几何投影"
- 提供定量淬火判据（Da = 2γ⟨d⟩²/D_ξ^eff），可推广至其他耗散孤子系统
- 建立三项可检验的区分标准（N6），当前数据可达其一（P_II边缘锐度）
- 诚实划定理论边界（4个数学障碍，5个未闭合问题）

**实验呼吁：** 如果Fache实验组能公开原始{λ_j}数据，N6的三项检验（至少P_I和P_II）可在数小时内完成，直接判定半圆是NDR平衡态还是淬火瞬态。如果新实验能进行传播距离扫描，P_IV可进一步约束演化轨迹。

**最后的诚实声明：** 这个理论不是"解决了"孤子气体DOS的耗散动力学——它诚实地说"当前数学和当前数据只能推到此处"。它排除了错误的解释（半圆=El-Tovbis NDR平衡态），给出了正确的定性（半圆=淬火瞬态的几何投影），并为下一步（原始数据分析+传播距离扫描实验）指明了具体方向。

**定理的边界比定理本身更宝贵。**
