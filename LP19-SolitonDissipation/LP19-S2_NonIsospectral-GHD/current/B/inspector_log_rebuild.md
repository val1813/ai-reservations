## 专项审查一：非厄米趋肤效应 → 多峰形成 (§2.3)

### 用户指令要求的两个维度

#### 维度A: 量纲自洽性

**声称的"有效非厄米哈密顿量"（行246-248）：**
```
H_eff(λ) = H_0(λ) + iΓ(λ)
dλ/dτ = -∂_{λ*} V_eff(λ)
```

**量纲逐项检查：**

| 量 | 量纲（归一化NLS单位） | 分析 |
|----|----------------------|------|
| H_0(λ) — ZS算子 | [1]（归一化后，∂_x和Q均无量纲） | ✓ |
| Γ(λ) — 增益编码 | [1]（增益系数γ归一化后无量纲） | ✓ |
| iΓ(λ) — 反厄米微扰 | [1] — 与H_0量纲一致 | ✓ H_eff = H_0 + iΓ量纲自洽 |
| V_eff(λ) — 有效"势" | [1]（若H_eff被视为"哈密顿量"则V_eff是其特征值或标量函数） | ⚠️ **V_eff的具体定义未给出** |
| dλ/dτ | [λ]/[τ] = [1]/[1] = [1]（λ无量纲化后，τ是演化参数） | ✓ |
| ∂_{λ*} V_eff | [V_eff]/[λ*] = [1]/[1] = [1] | ✓ |

**量纲审查判决：** 形式自洽。但存在一个**隐藏的量纲缺口**：V_eff(λ)的具体定义未给出。是非厄米"势能面"？是H_eff的特征值？还是某个构造的标量函数？没有V_eff的定义，量纲自洽性只是形式上的——任何无量纲函数都满足。

#### 维度B: 方向自洽性

**论证链的逐环节方向检查：**

**环节1（行246-248）：** "H_eff(λ) = H_0(λ) + iΓ(λ)" → "dλ/dτ = -∂_{λ*} V_eff"

| 方向检查 | 判定 | 理由 |
|---------|------|------|
| 从H_eff到V_eff的映射 | 🔴 **方向断裂** | H_eff是非厄米算子，其特征值一般是复数。V_eff作为实标量"势函数"的定义在非厄米语境中需要额外构造（如H_eff的奇异值？H_eff†H_eff的特征值？）。B博士不提供此构造。 |
| 梯度流方向 | 🟡 **定性合理** | 如果V_eff在增益极大处有极小值，则梯度流dλ/dτ = -∂_{λ*} V_eff确实将特征值推向增益极大处。方向正确：增益→Im(λ)增加。 |
| 从梯度流到多峰 | 🟡 **方向正确但冗余** | 论证链：Γ(λ)在Re(λ)的两处有局部极大 → V_eff有两处局部极小 → 特征值向两处聚集 → DOS双峰。方向自洽。但这种简单论证不需要"非厄米趋肤效应"的任何概念——它只是"ξ依赖的增益造成η分布分离"。 |

| P_new4: 临界区闪烁 | [启发式→可检验] | 🟡 同上+依赖双稳态势函数的存在性（未经证明）。 | ❌ 定性 |
| P_new5: 2D DOS单连通 | [推测→可检验] | 🟢 可检验。这是六个预测中最强、最诚实的。如果2D IST数据（若存在）显示单连通DOS支撑集→投影双峰机制被证实。 | 🟢 定性但可检验 |
| P_new6: TUR约束 | [推测→可检验] | 🔴 对N~100可能完全是空洞的。 | ❌ 非约束 |

**审查结论：六个"可检验的定量预测"中，零个是真正定量的。** P_new5是最有价值且最可检验的预测。P_new1本质上与P_new5相同（都是投影双峰机制的不同侧面）。P_new2-4全部依赖未量化的g_c。P_new6在N~100下无约束力。

### 针对用户两个专项问题的最终回答

**问题1: 非厄米趋肤效应→多峰形成的论证是否量纲/方向自洽？**

**回答：量纲形式上自洽，方向存在三个实质断裂点。**

1. V_eff的定义缺失使量纲自洽仅是形式上的。
2. 方向断裂：(a) H_eff→V_eff映射未建立；(b) 空间skin vs 谱聚集混淆；(c) winding number等拓扑声称零兑现。
3. **更关键的是：多峰形成不需要NHSE。** §5.4的投影双峰机制（ξ依赖增益→η分离→η投影多峰）不需要NHSE的任何概念，且更诚实、更可检验。NHSE在本文中是过度包装——核心物理（ξ依赖增益产生η空间分离）是一个几何投影效应，不需要非厄米拓扑语言。

**问题2: NDR绝热微扰的适用条件是否被定量验证？**

**回答：零定量验证。**

绝热假设需要验证的全部关键量——τ_relax（弛豫到NDR流形的速率）、τ_drift（沿NDR流形的漂移速率）、时间尺度分离比τ_drift/τ_relax、NDR流形的法向稳定性（Lyapunov指数）、吸引盆大小、σ(z)的量级（决定Fredholm类型）、ε的量级（决定漂移速度）——**无一被量化**。

B博士在攻击I1中承认："我不知道增益/阻尼是否满足这个条件。"引用的Cao et al. (2024)间接支撑存在系统差异和翻译缺口。

这意味着整个§1框架的"地基"——绝热假设——站姿是：[推测]而非[推导]。如果绝热假设被证伪（法向漂移不比切向漂移慢一个量级），§1的结构性地基开裂，NDR只能描述ε=0极限——失去对Fache实验（ε≠0）的解释力。

### 本轮的最高价值产出（降序排列）

1. **NDR核的正确识别**（log|(z-w̄)/(z-w)|替代log|z-w|）——修复了前轮的地基错误。
2. **投影双峰机制**（§5.4）——最简单、最诚实、最可检验的多峰解释。
3. **诚实性标注体系**（[推导]/[推测]/[启发式]/[开放问题]四级分层）——本轮的元方法论贡献。
4. **GHD失败诊断和边界条件不对称性**（资产①②）——独立于任何正模型的坚实产出。

### 下一轮建议

如果存在下一轮重建，优先级排序：

1. **定量评估绝热假设。** 计算或数值估计τ_relax和τ_drift在Fache实验参数下的量级。这是使§1从[推测]升级为[推导]的必要条件。
2. **数值验证投影双峰。** 对已知EDFA增益谱，在NDR框架下求解形变Γ上的DOS→检查η投影是否自然产生双峰→与Fache数据比对。这是一周内可完成的高ROI验证。
3. **放弃NHSE的过度声称。** §2.3降级为"启发式类比"，将多峰机制统一到§5.4的投影效应下。删除未兑现的winding number等拓扑声称。
4. **删除或显式计算TUR约束。** 当前形式下TUR对N~100无约束力。要么显式计算证明有约束力，要么降级为"原则性陈述"。
5. **量化σ(z)和1/N修正。** 这两个是NDR从N=∞到N~100的桥梁参数。缺少它们→框架无法产出定量预测。
