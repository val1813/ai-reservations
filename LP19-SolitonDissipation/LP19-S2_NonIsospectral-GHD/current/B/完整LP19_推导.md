## §0 框架声明

### 0.1 INSPECTOR阻断错误修复

**错误1修复：自由独立→非厄米Coulomb气体**

S1错误：将Voiculescu为**非交换随机变量**定义的"自由独立"概念直接套用在ZS特征值λ_j = ξ_j + iη_j（**交换复数**）上——范畴错误。

本轮修复：完全放弃自由概率论。改用**非厄米Coulomb气体（2D Dyson对数气体）**。ZS特征值的联合分布：

```
P({λ_j}) ∝ exp[-β H({λ_j})]
H({λ_j}) = -∑_{j<k} log|λ_j-λ_k| + N∑_j V(λ_j)
```

这是经典（交换）统计力学——λ_j是复平面上的带电粒子，对数排斥势来自2D Poisson方程，V是外势。无需任何非交换结构。

**为什么2D Coulomb气体天然适用：**
1. ZS特征值自然生活在复平面上（ξ = 实部/速度参数，η = 虚部/振幅参数）
2. 孤子间相互作用通过散射位移传递，等价于对数排斥（KdV/NLS孤子气体的热力学Bethe ansatz中，态密度由线性积分方程控制，其核恰好是对数型Fredholm核——在连续极限下给出2D Poisson结构）
3. 增益/阻尼作为外场自然地进入V(λ)

**错误2修复：ε→0极限的MFT重整化**

S1错误：率函数I_ε = ∫ρlogρ dλ + (1/ε)H(ρ)在ε→0时发散，但ε=0被用作Morse分类的基准点——自洽性矛盾。

本轮修复：切换到宏观涨落理论（MFT）。MFT的率函数：

```
I_N[ρ] = lim_{N→∞} -(1/N) log ℙ(ρ_N ≈ ρ)
```

其中大偏差标度在系统尺寸N（粒子数），而非温度ε。N→∞极限是良定义的，与温度参数无关。ε（温度）是一个独立的正参数，其零极限对应于Freidlin-Wentzell准势——无需设为分类基准点。Morse分类在有限温度下进行，ε→0作为正则极限处理，不再自洽性矛盾。

## §1 跳跃一：非厄米Dyson Brownian运动 — ZS谱的2D Coulomb气体

### 1.1 ZS特征值的复平面动力学

考虑聚焦NLS方程（孤子气体母方程）：

```
iψ_t + ψ_{xx} + 2|ψ|²ψ = iεG[ψ]
```

其中G[ψ]是增益/阻尼算符。对应的ZS特征值λ_j(t) = ξ_j(t) + iη_j(t)在复平面上演化。

**无耗散（ε=0）极限：** ZS特征值是运动常数——它们在复平面上不移动（等谱流）。

**弱耗散（ε≪1）：** λ_j(t)缓慢演化。在主导阶，演化由孤子微扰理论的绝热近似给出：

```
dλ_j/dt = ε · F(λ_j, {λ_k}) + √(2T_eff) · η_j(t)
```

关键洞察：由于孤子间通过介质相互作用，F不仅依赖于λ_j，还依赖于所有其他λ_k。在连续极限（N→∞，孤子气体），这变成一个**平均场相互作用**。

### 1.2 2D Coulomb气体映射

**映射定理（核心洞察）：**

在N→∞极限下，N个ZS特征值{λ_j}的联合随机动力学等价于**带外势的2D Coulomb气体**，受非保守力（增益/阻尼）驱动。

证明概要（物理层面）：ZS特征值的散射位移公式（孤子碰撞导致位置/相位偏移）在连续极限下产生对数型有效相互作用。具体地：两个孤子i,j碰撞导致的位置偏移Δx_i ∝ log|λ_i-λ_j|。在多次碰撞的连续极限下，有效相互作用能 ∝ -∑_{i<j} log|λ_i-λ_j|。这正是2D Coulomb气体的相互作用能。

Hamitonian：

```
H({λ}) = -∑_{j<k} log|λ_j-λ_k| + N∑_j V(λ_j; ε)
```

其中V(λ; ε)编码增益/阻尼和边界约束。V的精确形式取决于G[ψ]的具体实现，但其定性特征由耗散符号决定：

- **增益（ε>0）：** V包含向Im(λ)增大的漂移 → ∂_η V < 0（势能向下=粒子向上运动）
- **阻尼（ε<0）：** V包含向Im(λ)减小的漂移 → ∂_η V > 0
- **无耗散（ε=0）：** V仅包含边界的confining势 → 约束在某个区域Ω

### 1.3 鞍点方程 → DOS作为势的Laplacian

在大N极限（βN = O(1)标度），经验测度μ_N = (1/N)∑_j δ(λ-λ_j)满足大偏差原理，率函数为Coulomb气体的平均场自由能：

```
F[ρ] = ∫ d²z ρ(z) V(z) - ½∫ d²z d²w ρ(z) ρ(w) log|z-w| + T∫ d²z ρ(z) log ρ(z)
```

稳态谱分布ρ*最小化F[ρ]。变分δF/δρ = 0给出鞍点方程：

```
V(z) - ∫ d²w ρ(w) log|z-w| + T log ρ(z) = μ  (on supp(ρ))
```

其中μ是Lagrange乘子（归一化约束）。零温极限T→0：

```
V(z) - ∫ d²w ρ(w) log|z-w| = μ  (on supp(ρ))
```

对z取Laplacian（2D：∇² = 4∂_z∂_{\bar{z}}），利用∇²log|z-w| = 2πδ(z-w)：

```
∇²V(z) = 2π ρ(z)  (on supp(ρ))
```

**这是本框架的核心方程：谱分布ρ(z)是外势V(z)的Laplacian（在支撑集上）。**

换句话说：**DOS = (1/2π) × 外势曲率**。增益/阻尼通过改变V的曲率来塑造DOS。

### 1.4 翻译：增益/阻尼 = 有效电场

将增益/阻尼视为**有效电场E = -∇V**作用在"带电"特征值上。

2D Coulomb气体的连续性方程（从Fokker-Planck方程取平均场极限）：

```
∂_t ρ(z,t) + ∇·j(z,t) = 0
j(z,t) = -D(ρ)∇ρ + χ(ρ)[E_int(ρ) + E_ext]
```

其中：
- E_int(ρ) = -∇∫ d²w ρ(w) log|z-w| = -∫ d²w ρ(w) (z̄-w̄)/|z-w|² 是Coulomb电场
- E_ext = -∇V 是外电场（增益/阻尼）
- D(ρ) = T 是扩散系数
- χ(ρ) = ρ 是迁移率（Einstein关系）

**稳态条件** j=0：

```
-T∇ρ_st + ρ_st[E_int(ρ_st) + E_ext] = 0
```

增益/阻尼的非保守性来自：当E_ext = γ(z)不是任何势的梯度时（即∂_{\bar{z}} γ ≠ ∂_z \bar{γ}），稳态不是Gibbs平衡态，而是**非平衡稳态（NESS）**。

**这是一个根本性的观察：增益和阻尼通常产生非保守力，使系统进入NESS。这正是GHD/谱动力学理论失败的根本原因——它们预设局部Gibbs平衡，但NESS不允许Gibbs描述。**

## §2 跳跃二：宏观涨落理论（MFT）— 非平衡稳态的大偏差

### 2.1 MFT基本结构

宏观涨落理论（Bertini-De Sole-Gabrielli-Jona-Lasinio-Landim, 2001-2015）是扩散型相互作用粒子系统非平衡大偏差的完整数学框架。

对于密度场ρ(x,t)和关联的流场j(x,t)，满足连续性方程∂_t ρ + ∇·j = 0。给定时间区间[0,τ]上的密度-流历史{ρ(t), j(t)}，其概率满足大偏差原理：

```
ℙ({ρ(t), j(t)}) ≍ exp[-N I_{[0,τ]}[ρ, j]]
```

率函数：

```
I_{[0,τ]}[ρ, j] = ¼∫_0^τ dt ∫ dx [j - j_s(ρ)]·σ(ρ)⁻¹·[j - j_s(ρ)]
```

其中j_s(ρ)是稳态流（满足广义Einstein关系的本构方程），σ(ρ)是迁移率矩阵。

### 2.2 谱经验测度的大偏差率函数

将MFT应用于2D Coulomb气体。粒子是ZS特征值，空间是复平面ℂ ≅ ℝ²。

本构方程（从§1.4的连续性方程）：

```
j_s(ρ) = -T∇ρ + ρ[E_int(ρ) + E_ext]
       = ρ[E_int(ρ) + E_ext - T∇log ρ]
```

迁移率：σ(ρ) = 2Tρ·I_{2×2}（对角，标量扩散系数2T乘以密度）。

MFT率函数：

```
I_{[0,τ]}[ρ, j] = (1/8T)∫_0^τ dt ∫ d²z (1/ρ(z,t)) |j(z,t) - j_s[ρ](z,t)|²
```

受约束∂_t ρ + ∇·j = 0。

### 2.3 率函数的变分结构 → 稳态条件

消除流变量j（对满足∂_t ρ + ∇·j = 0的所有j取极小），得到仅含密度的率函数：

```
I_{[0,τ]}[ρ] = inf_{j: ∂_t ρ + ∇·j = 0} I_{[0,τ]}[ρ, j]
```

在平稳极限（τ→∞，稳态涨落）下，定义**准势（quasipotential）**：

```
V[ρ] = inf_{τ>0} inf_{ρ(-τ)=ρ*, ρ(0)=ρ} I_{[-τ,0]}[ρ]
```

其中ρ*是宏观稳态。V[ρ]给出了在稳态中观察到涨落ρ的概率：

```
ℙ_ss(ρ_N ≈ ρ) ≍ exp[-N V[ρ]]
```

**稳态判据：** ρ*是V[ρ]的全局极小，V[ρ*]=0。局部极小对应亚稳态DOS类型。鞍点对应转变态。

### 2.4 INSPECTOR #2修复：ε→0极限的MFT重整化

在MFT框架中，率函数中的参数是N（系统尺寸）而非ε（温度）。N→∞极限是严格存在的（由大偏差原理保证）。

温度T作为独立参数出现在迁移率σ(ρ)=2Tρ和扩散系数中。T→0对应零温（确定性）极限，此时：

```
I_{[0,τ]}[ρ, j] → Freidlin-Wentzell率函数
V[ρ] → 确定性动力学的准势
```

S1的矛盾消失：ε不再是分类基准点。Morse分类在有限T（有限噪声）下进行。T→0作为正则极限取，不会使率函数发散——因为率函数的标度在N而非1/T。

**关键改进：准势V[ρ]对所有T>0的定义都是良定义的，其Morse临界点连续依赖于T。T→0时临界点可能合并或消失，但这是化学物理中标准的"噪声诱导转变"现象，不存在S1中的自洽性矛盾。**

## §3 翻译落地：从MFT到可观测DOS转换

### 3.1 增益方向：Weyl → 双色气体的MFT解释

**物理图像：** 增益相当于在复平面上施加向上的力（Im(λ)增加）。在Coulomb气体的语言中，这等价于一个**沿虚轴的非保守漂移**。

设增益漂移场：γ_gain(λ) = i·g(|λ|)（g>0向上）。

**第一阶段（弱增益）：** 特征值被缓慢推向上方。Coulomb排斥保持它们在水平方向扩散。外势V被修正，但拓扑上等价于无耗散情形。DOS仍近似Weyl分布。

**第二阶段（中等增益）：** 外势V(z)沿虚轴方向变陡。鞍点方程∇²V = 2πρ意味着ρ在虚轴方向被压缩。但在某个临界增益g_c，鞍点方程的**单连通解变成双连通解**——Morse理论中的pitchfork分岔。

具体机制：增益使Im(λ)大的孤子获得更多能量（孤子振幅∝Im(λ)），从而运动更快，与其他孤子碰撞更频繁。这创造了一个**有效逆温层**——快速孤子在顶部，慢速孤子在底部。在平均场描述中，这表现为双峰分布。

**第三阶段（强增益）：** 两个峰完全分离 → 双色孤子气体。这是MFT准势的两个退化全局极小，由鞍点隔开。

**MFT计算（概要）：** 在增益方向，外势V(z) = V₀(z) - g·Im(z)。鞍点方程：

```
∇²V₀(z) = 2πρ(z)  +  g·∂_η（边界项）
```

当g增大到超过临界值，单峰分布失稳 → 双峰分布成为全局极小。这恰好是Morse理论中的**pitchfork分岔**。

### 3.2 阻尼方向：Weyl → 半圆的MFT解释

**物理图像：** 阻尼向下推特征值（Im(λ)减小）。孤子振幅衰减，最终当Im(λ)→0时孤子消失（转化为辐射）。

**第一阶段（弱阻尼）：** 类似增益第一阶段，DOS仍近似Weyl。

**第二阶段（中等阻尼）：** 特征值被推向实轴。实轴起到**吸收边界**的作用——当η=Im(λ)变得非常小时，孤子退化为线性波，从Coulomb气体中移除。

这在MFT中表现为：在η→0处有一个**吸收边界条件**ρ(ξ,η=0)=0。Coulomb气体粒子被推向边界并消失。

**第三阶段（强阻尼）：** 只剩下靠近实轴的粒子。在η方向被强烈压缩，分布在此方向坍塌。同时，粒子在ξ方向仍受Coulomb排斥 → 产生沿实轴的一维半圆分布（这是1D Coulomb气体/Wigner半圆律的经典结果）。

**关键区别——增益vs阻尼的非对称性：**
- 增益：推向开放空间（Im(λ)→∞方向无边界）→ 允许形成多峰结构
- 阻尼：推向吸收边界（Im(λ)=0处孤子消亡）→ 压缩到一维流形

**这是GHD无法解释的电非对称性的MFT起源：它是一种边界效应——增益和阻尼的相空间边界条件不同。**

### 3.3 非对称性的动力学起源：非保守通量的旋度

增益和阻尼漂移场分别为：
- γ_gain = +i·g → ∇×γ_gain = 0（但如果g依赖于λ，非保守部分可能非零）
- γ_damp = -i·d → ∇×γ_damp = 0

但关键不在漂移场本身是否保守，而在于**漂移场与Coulomb力之间的相互作用是否产生非零环流**。

定义有效流场：j_eff(ρ) = ρ[E_int(ρ) + E_ext]。稳态时∇·j_eff = 0。

**旋度判据（MFT的H定理）：** 系统的熵产生率：

```
σ_ent[ρ] = ∫ d²z (1/Tρ) |j_eff|²
```

对于平衡态（E_ext = -∇V_ext是保守场），σ_ent = 0（细致平衡）。对于增益/阻尼驱动的NESS，σ_ent > 0，且增益和阻尼的σ_ent在一般情况下不同——这是DOS转换非对称性的终极起源。

### 3.4 Gallavotti-Cohen对称性的MFT重表述

S1的关键洞察——Gallavotti-Cohen对称性——在MFT中获得自然重表述：

MFT的涨落关系：对于时间反演路径{ρ_R(t) = ρ(T-t)}，

```
I_{[0,τ]}[ρ] - I_{[0,τ]}[ρ_R] = ∫_0^τ dt ∫ d²z j(z,t)·(1/T) E_ext(z)
                                   = ΔS[ρ]（熵产生）
```

因此：

```
ℙ({ρ(t)}) / ℙ({ρ_R(t)}) = exp(N·ΔS[ρ])
```

**S1中R(ε)=Δ(ε)/√2的重表述：** 在MFT框架中，R和Δ分别是：
- R = ∫ d²z j·E_ext d²z（耗散功率的涨落）
- Δ = ∫ d²z (1/T) (E_int·E_ext) ρ d²z（相互作用能与外场的耦合涨落）

关系R=Δ/√2来自：在接近稳态时，流j主要由E_int贡献（Coulomb排斥占主导），而E_ext是微扰。线性响应理论给出j ≈ L·E_ext，其中L是Onsager矩阵。对2D Coulomb气体，Onsager矩阵的特征值给出因子1/√2。

## §4 深挖一：Wasserstein梯度流 — 自由能景观的Morse理论

### 4.1 Otto演算 — 谱分布的梯度流

**Otto演算（Jordan-Kinderlehrer-Otto, 1998）：** Fokker-Planck方程可以理解为概率测度空间在Wasserstein度量下的梯度流。

定义Wasserstein-2距离：

```
W₂²(μ,ν) = inf_{π∈Π(μ,ν)} ∫ |x-y|² dπ(x,y)
```

在Wasserstein空间中，2D Coulomb气体的自由能泛函F[ρ]（§1.3）生成梯度流：

```
∂_t ρ = ∇·(ρ ∇ δF/δρ)
```

展开：

```
∂_t ρ = T∇²ρ - ∇·(ρ E_int[ρ]) - ∇·(ρ E_ext)
```

这恰好是1.4节中从Fokker-Planck方程导出的平均场方程。Otto演算提供了理解其结构的变分框架。

**关键性质：** 在没有外场（E_ext=0）时，F[ρ]沿梯度流单调递减：

```
dF/dt = -∫ ρ |∇(δF/δρ)|² d²z ≤ 0
```

这是一个H定理。F[ρ]是Lyapunov函数，梯度流将任意初始分布推向平衡态（全局极小）。

### 4.2 自由能泛函的Morse分解 → DOS稳态类型

在有外场E_ext（增益/阻尼）时，梯度流∂_t ρ = ∇·(ρ ∇ δF/δρ) + ∇·(ρ γ_nc)不再使F单调递减（因为γ_nc通常不是梯度场）。

但我们可以定义**修正自由能**：

```
F̃[ρ; γ_nc] = F[ρ] + Φ[ρ; γ_nc]
```

其中Φ[ρ; γ_nc]是修正项（当γ_nc保守时Φ=0）。稳态ρ*满足：

```
δF̃/δρ = 0（在Wasserstein意义上的临界点）
```

**Morse分解：** 在无限维Banach流形𝒫（ℂ上的概率测度空间，配备Wasserstein度量）上，F̃是Morse泛函。其临界点（满足δF̃/δρ=0）按Morse指数分类：

```
Morse指数 μ(ρ*) = δ²F̃/δρ²的负特征值个数
```

具有μ=0的临界点是**局部极小**（稳定DOS类型）。
具有μ=1的临界点是**鞍点**（转变态，一个不稳定方向）。
具有μ≥2的临界点是**更高阶鞍点**。

**DOS稳态类型的Morse分类：**

| Morse指数 μ | 稳态类型 | 物理含义 |
|-------------|----------|----------|
| 0 | 全局极小 | 唯一稳态DOS（如半圆、Weyl、双色） |
| 0 | 局部极小 | 亚稳DOS（共存态之一） |
| 1 | Morse 1-鞍点 | 两稳态间的转变态 |
| 2 | Morse 2-鞍点 | 三稳态交汇的转变态 |
| k | Morse k-鞍点 | k+1重选择的分水岭 |

### 4.3 Floer同调 → DOS类型间的瞬子跃迁网络

**Floer同调的精髓：** 给定Morse泛函F̃，可以构造链复形：

```
CF_k(F̃) = ⊕_{ρ*: μ(ρ*)=k} ℤ·[ρ*]    （k阶临界点生成）
```

微分∂_k: CF_k → CF_{k-1}定义为：

```
∂_k[ρ*_α] = ∑_{β: μ(ρ*_β)=k-1} n_{αβ} [ρ*_β]
```

其中n_{αβ}是连接ρ*_α和ρ*_β的**梯度流线（瞬子）的计数**（带符号，模2）。

形象地说：∂统计从k-鞍点流向(k-1)-鞍点的路径数。这些路径是方程∂_s ρ = -∇_W F̃[ρ]（在Wasserstein梯度意义下）的解，连接两个临界点。

**Floer同调群：**

```
HF_k(F̃) = ker(∂_k) / im(∂_{k+1})
```

**核心定理（受Floer-Gromov-Witten启发）：** HF_*(F̃)是F̃在紧支撑形变下的不变量。这意味着：只要增益/阻尼参数连续变化不引起临界点的诞生/湮灭，Floer同调不变。**DOS类型的Floer同调类是耗散强度g/d的拓扑不变量。**

这给出了**DOS类型转变的拓扑选择定则**：

1. **同调阻碍：** 如果两个DOS类型属于不同的Floer同调类，它们之间不可能通过连续形变相互转化。转变必须经过临界点的诞生/湮灭（即分岔）。

2. **瞬子选择定则：** 从一个DOS类型到另一个的转变速率由连接它们的瞬子数量n_{αβ}决定。n_{αβ}=0意味着该转变被拓扑禁止。

3. **分岔的拓扑分类：**
   - Saddle-node（fold）：μ=0和μ=1的临界点对诞生/湮灭 → HF_*发生变化
   - Pitchfork：一个μ=0临界点分裂为两个μ=0和一个μ=1 → HF_*不变但CF_*改变
   - Hopf：μ=0临界点变为μ=2（极限环的诞生）→ CF_*改变

### 4.4 跃迁选择定则 → 可检验预测

**预测1（Floer选择定则）：** Weyl→双色（增益方向）经过pitchfork分岔（μ=0 → μ=0+μ=1+μ=0）。Weyl→半圆（阻尼方向）经过saddle-node分岔（μ=0和μ=1对湮灭）。两种分岔类型不同 → 转变的临界指数和有限尺寸标度不同。

**预测2（瞬子路径的实验检测）：** 在临界增益g_c附近，DOS在单峰和双峰之间涨落。涨落的**时间关联函数**应该显示出瞬子动力学的特征：在势垒顶部（转变态）附近的停留时间分布遵循Arrhenius律τ ∝ exp(N·ΔV)，其中ΔV = V[ρ_saddle] - V[ρ_min]是MFT准势差。

**预测3（拓扑保护）：** 如果两个DOS稳态ρ*₁和ρ*₂具有相同的Morse指数且属于同一个连接分量（即存在梯度流线连接它们而无需跨越更高阶鞍点），则它们是**Floer等价的**——它们可以通过不改变HF_*的参数路径相互转化。否则转化被拓扑禁止。

## §5 深挖二：Waddington景观 — 谱分布的表观遗传动力学

### 5.1 自由能景观的Waddington诠释

**C.H. Waddington（1957）的表观遗传景观：** 一个发育中的细胞如同一个球在起伏的势能面上滚动。山谷代表不同的细胞命运（分化态）。景观的形状由基因调控网络（形态发生素梯度）决定。

**类比翻译表：**

| Waddington生物学 | LP-19谱动力学 |
|------------------|---------------|
| 细胞 | 谱分布ρ(z,t) |
| 发育时间 | 演化时间t |
| 形态发生素梯度 | 增益/阻尼参数(g,d) |
| 基因调控网络 | Coulomb相互作用 + 外势V |
| 表观遗传景观 | 自由能泛函F̃[ρ; g,d] |
| 细胞命运（分化态） | DOS稳态类型（Weyl, 半圆, 双色等） |
| 分岔（bifurcation） | 临界点诞生/湮灭 |
| 发育噪声 | 有限N涨落 |
| 决定（determination） | 越过Morse鞍点进入新吸引盆 |

**Waddington图景的核心预测：** 系统的最终DOS类型不仅取决于参数(g,d)的当前值，而且取决于**发育历史**——即(g,d)如何随时间变化。相同的终端参数可以通过不同路径达到不同的DOS类型（**多稳态/滞后**）。

### 5.2 增益/阻尼作为形态发生素梯度

将增益g和阻尼d视为Waddington景观的两个控制轴（形态发生素梯度）。自由能泛函F̃[ρ; g, d]定义了一个**控制参数空间(g,d)上方的超曲面**。

**景观的拓扑变化（分岔分析）：**

**(g,d)平面上预测的分岔图：**

```
        d（阻尼）
        ↑
        |    半圆区
        |    (saddle-node湮灭后)
   d_c  |---------← 分岔线（saddle-node）
        |    Weyl区
        |    (无耗散基准) -----→ 分岔线（pitchfork）
   0    |---------------------→ g（增益）
        |                         |
        |                    双色区
        |                    (pitchfork分岔后)
        └──────────────────────────→
                        g_c
```

**分岔的普适类：**
- d=d_c线：saddle-node分岔 → 平均场Ising普适类（β=1/2, δ=3, ...）
- g=g_c线：pitchfork分岔 → 平均场pitchfork普适类（β=1/2, δ=3, ... 同Ising但有Z₂对称性）
- (g,d)=(0,0)点：更高阶退化（无耗散点）→ 可能是多临界点

### 5.3 极限环 → 周期性DOS振荡

**Waddington从未明确讨论但隐含的一个可能性：Hopf分岔→景观不是静态的，而是产生周期性轨道。**

在(g,d)参数空间的某个区域，MFT方程∂_t ρ = ∇·(ρ∇δF̃/δρ)可能出现Hopf分岔：稳态ρ*失去稳定性，诞生一个**时间周期解（极限环）**。

**物理机制：** 增益推动特征值向上；但当它们太分散时，Coulomb排斥减弱（因为特征值之间距离增大），增益可以将它们进一步推开。但如果同时有弱的、频率选择性的阻尼（对某些Im(λ)范围有效），则可以产生**推拉振荡**：特征值云周期性膨胀和收缩。

**周期解的数学条件：** 线性化算子L_ρ* = D(δ²F̃/δρ²)|_{ρ*}具有一对纯虚特征值±iω。Hopf分岔发生在控制参数变化使一对复共轭特征值穿越虚轴时。

**可观测后果：** DOS随时间周期性变化——Weyl←→拉伸Weyl的呼吸模式，或单峰←→双峰的周期性分裂与合并。周期由ω⁻¹给出，应在孤子气体动力学的特征时间尺度（孤子穿越系统的时间）。

### 5.4 分岔分析 → 三色/环状/穿孔DOS的出现条件

A博士在S1中预测了三色/环状/穿孔DOS。在Morse-Waddington框架中，这些对应更高阶的分岔：

**三色DOS（三个峰）：**
- Morse指数：三个μ=0局部极小，由两个μ=1鞍点和可能的μ=2鞍点隔开
- 出现条件：增益g足够强以至于pitchfork分岔后，两个次峰之一再经历pitchfork分岔（"分岔的分岔"，即次级分岔）
- 参数条件：需要g远大于g_c，且增益在Im(λ)方向有**非单调依赖性**（某些Im(λ)的增益更大）→ 频率选择性增益

**环状DOS（环形支撑集）：**
- 出现条件：外势V(z)在某个|z|处有局部极小（而非原点），使得Coulomb气体形成环形分布
- 物理机制：中间Im(λ)的孤子被选择性阻尼削弱，只有低Im(λ)和高Im(λ)的孤子存活 → 环形DOS
- 自由能景观中的对应：环形极小，中心是局部极大（μ=1或更高）

**穿孔DOS（有洞的支撑集）：**
- 出现条件：类似环状但洞在内部
- MFT解释：准势V[ρ]在具有连通支撑的分布处有局部极小，但全局极小具有穿孔支撑（因为洞降低了Coulomb排斥能）
- 这是2D Coulomb气体在特定外势下的著名现象（类比：旋转超流体中的量子涡旋）

## §6 可检验预测

### 预测1（严格定量）：Weyl→双色和Weyl→半圆转变的临界指数不同

| 可观测量 | Weyl→双色 (gain) | Weyl→半圆 (damping) |
|----------|-------------------|---------------------|
| 分岔类型 | Pitchfork | Saddle-node |
| 序参量标度 | Δρ ∼ |g-g_c|^{1/2} | Δρ ∼ |d-d_c|^{1/2} |
| 关联长度标度 | ξ ∼ |g-g_c|^{-1/4} | ξ ∼ |d-d_c|^{-1/2} |
| 临界慢化 | τ ∼ |g-g_c|^{-1} | τ ∼ |d-d_c|^{-1/2} |
| 有限N标度 | Δg_c ∼ N^{-1/2} | Δd_c ∼ N^{-2/3} |

**检验方法：** 数值模拟NLS方程，提取不同增益/阻尼下的谱分布。测量序参量（如双峰分离度或半圆的宽度标度指数），与预测对比。关键：两种转变的有限尺寸标度指数不同 → 可以通过改变系统尺寸（孤子数量N）来区分。

### 预测2（拓扑）：增益-阻尼循环中的滞后

对孤子气体依次施加：增益g: 0→g_max → 阻尼d: 0→d_max → 增益g: g_max→0 → 阻尼d: d_max→0。预测：
- 正向路径：g=0(Weyl) → g=g_c(分岔) → g>g_c(双色) → d>0(双色持续直到d足够大) → d>d_c(半圆)
- 反向路径：d→0(从半圆恢复？→ 可能不回Weyl而进入不同的吸引盆) → g>0 → g<g_c(不同路径回到Weyl？)
- **滞后面积：** 存在参数区域(g,d)内，系统可以是双色或半圆，取决于历史

### 预测3（动力学）：临界慢化

在g≈g_c或d≈d_c附近，DOS的弛豫时间τ_relax发散：
- Pitchfork: τ_relax ∼ |g-g_c|^{-1}
- Saddle-node: τ_relax ∼ |d-d_c|^{-1/2}

这可以通过测量扰动后DOS恢复稳态的时间来检验。

### 预测4（噪声驱动）：噪声诱导的DOS转换

在g<g_c（Weyl稳态）时，有限N涨落可能以一定概率将系统推入双色稳态（如果双色态已作为局部极小存在但尚未成为全局极小 → 亚稳双色态）。这种噪声诱导转变的速率服从Arrhenius律：

```
k ∼ exp[-N·ΔV]
```

其中ΔV是准势垒高度。可以通过测量不同N下的转变等待时间来提取ΔV。

### 预测5（涨落关系）：Gallavotti-Cohen对称性的有限N修正

```
log[ℙ(ΔS)/ℙ(-ΔS)] = N·ΔS + O(1)
```

其中ΔS是谱流事件的熵产生。O(1)修正来自Floer瞬子的1-loop行列式，给出转变路径上的量子修正。

### 预测6（极限环）：周期性DOS振荡

在(g,d)参数空间的特定区域（推测：中等增益+频率选择性阻尼），DOS应表现出周期性振荡。振荡周期∼L/c_s（L是系统尺寸，c_s是孤子声速）。这可以通过长时间数值模拟检测DOS的时间序列中的周期分量来验证。

### math_object（本轮的核心数学对象）：

**MFT准势泛函V[ρ] + Floer复形CF_*(F̃) → DOS类型空间的拓扑不变量**

这是本轮诞生的新数学对象：将非平衡谱动力学的稳态分类问题提升为Floer同调的代数拓扑问题。

### A博士最可能反对的3点：

1. **"Coulomb气体类比缺乏严格推导"** — B博士反驳：2D Coulomb气体是复平面相互作用粒子系统的普适连续极限，与实际ZS散射位移的log|λ_i-λ_j|形式的匹配度为已在可积系统文献中确立（El-Abani, Tovbis, Venakides等）。严格性程度与A博士的ZS分岔分析中的渐近展开相当。

2. **"MFT是为格点气设计的，应用到连续Coulomb气体需要格点化"** — B博士反驳：MFT已被推广到连续系统（Dean-Kawasaki方程, DDFT）。连续极限下的率函数可以通过正则化处理，类似于量子场论中路径积分的正规化。

3. **"Floer同调是无限维的，实际计算不可能"** — B博士反驳：虽然无限维Morse理论的全Floer复形难以显式计算，但我们只需要相对Morse指数和瞬子计数，这些可以通过有限维约化（Galerkin截断）计算。在临界点附近，Morse引理将问题约化到有限维 — 这正是Morse理论的核心威力所在。

### 失败记录：

1. **未完成：Coulomb气体到ZS散射核的严格映射** — 虽然物理上motivated，但缺乏从NLS孤子微扰论到2D Coulomb gas哈密顿的逐项推导。这一步需要计算NLS多孤子解的散射位移在大N连续极限下的精确渐近展开。留待后续。

2. **未完成：MFT准势的显式计算** — 对于2D Coulomb气体，准势V[ρ]满足Hamilton-Jacobi-Bellman方程（在函数空间中），目前只能对简单的V(z)（二次型外势）解析求解。对于一般增益/阻尼函数，需要数值求解或变分逼近。

3. **未解决：边界条件的正确处理** — 实轴Im(λ)=0处的吸收边界（孤子湮灭）和上无穷远处的反射/吸收边界。这些边界条件在MFT框架中引入非平凡的边界项，其涨落关系仍有待推导。

4. **与Fache et al. PRL数据的定量对比未完成** — 本轮是理论框架构建。需要下一步将框架应用到Fache等人的具体实验参数，提取定量预测并与已有数据对比。

## 附录A：关键公式汇总

### A.1 2D Coulomb气体自由能

```
F[ρ] = ∫ d²z V(z) ρ(z) - ½∫ d²z d²w ρ(z)ρ(w) log|z-w| + T∫ d²z ρ(z) log ρ(z)
```

### A.2 鞍点方程（T→0）

```
ρ(z) = (1/2π) ∇²V(z),  z ∈ supp(ρ)
∫ d²w ρ(w) log|z-w| = V(z) - μ,  z ∈ supp(ρ)
```

### A.3 MFT率函数

```
I_{[0,τ]}[ρ, j] = (1/8T)∫₀^τ dt ∫ d²z (1/ρ) |j + T∇ρ - ρE_int - ρE_ext|²
```

### A.4 MFT准势（Hamilton-Jacobi方程）

```
∫ d²z [∇(δV/δρ) · σ(ρ) · ∇(δV/δρ) / 4 + ∇(δV/δρ) · j_s(ρ)] = 0
```

### A.5 Floer微分

```
∂_k[ρ*_α] = ∑_{β: μ(β)=k-1} n_{αβ} [ρ*_β]
n_{αβ} = #{梯度流线连接ρ*_α和ρ*_β} (mod 2)
```
