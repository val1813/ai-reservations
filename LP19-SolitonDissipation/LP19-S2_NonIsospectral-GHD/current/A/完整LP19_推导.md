## §0 框架声明

### 选定框架: 非等谱广义流体动力学 (Non-Isospectral Generalized Hydrodynamics, nGHD)

**定义:** nGHD = 标准GHD (Doyon-Yoshimura 2017, Bonnemain-Doyon-El 2022) 的推广，将等谱守恒律 ∂_t q_i + ∂_x j_i = 0 替换为含源的输运方程 ∂_t q_i + ∂_x j_i = S_i[{q}]，其中源项 S_i 包含耗散漂移、碰撞积分和辐射扩散三个机制的微观推导。

### 与竞争框架的区分

**与S1-A (ZS谱理论+分岔理论) 的关系:** S1建立了分类框架，但动力学方程停留在绝热近似。S2从微观出发推导完整的碰撞积分 C[f] 和辐射扩散系数 D 的显式微观表达式——这是将S1的定性框架升级为定量理论。

**与B博士框架 (大偏差+Morse+信息几何+自由概率+适应性景观) 的区分:**
- B: 自顶向下——假设率函数 I_ε(ρ) 存在 → 分析其Morse结构 → 推断普适类。率函数本身不推导。
- A(S2): 自底向上——从N-soliton微观动力学出发 → 推导碰撞积分 → 取热力学极限 → 得到封闭的nGHD方程 → 求解稳态 → 普适类自然涌现。
- 方法论对立: B的率函数是先验假设；nGHD的输运方程是推导结果。如果两者在稳态预测上汇合（半圆、多色SG），构成互不依赖的交叉验证。

**与标准GHD (Doyon et al.) 的区分:**
- 标准GHD: 等谱极限 ε=0，守恒律严格成立，无碰撞积分（弹性碰撞保持特征值不变）。
- nGHD: 非等谱 ε≠0，守恒律破坏。碰撞变为非弹性——每次碰撞产生微量谱参数偏移。累积效应在热力学极限下产生碰撞积分和有效扩散。

### 硬锁 (不可违反的前提约束)

1. **不假设DOS分类的完备性。** S1枚举了6种拓扑候选——S2仅从nGHD方程出发，推导哪些稳态是方程的解，不预先穷举。
2. **不引入不可观测的自由参数。** D, C[f] 的每个参数必须有微观表达式，用基础物理量 (N, L, γ, ψ₀) 表达。
3. **增益和阻尼统一处理。** 辐射耦合、碰撞积分在增益和阻尼下使用相同的微观机制——S1中不对称使用的缺陷在S2中修复。
4. **量纲在每一步显式检查。** 所有方程归一化到无量纲形式，转换因子显式声明。

## §1 微观谱动力学 — 非等谱ZS特征值的精确演化

### §1.1 归一化约定 (量纲修复 — 回应INSPECTOR Q1)

fNLS方程通常写作:
$$i\psi_t + \psi_{xx} + 2|\psi|^2\psi = 0 \quad (1.1)$$

在无量纲归一化形式中，ψ 的单位为 (特征长度 L_D)⁻¹，t 的单位为 L_D² (色散长度归一化后的传播距离)。设参考量:
- 参考振幅: A₀ = max|ψ(x,0)| (单位: V/m 或 W^{1/2})
- 色散长度: L_D = T₀²/|β₂| (单位: m, T₀为脉冲宽度, β₂为色散参数)
- 非线性长度: L_NL = 1/(γ_NL P₀) (单位: m, γ_NL为非线性系数, P₀为峰值功率)

归一化变量:
$$\tilde{\psi} = \psi / A_0, \quad \tilde{x} = x / L_D, \quad \tilde{t} = t \cdot (|β₂|/T₀²) \quad (1.2)$$

**此后所有量均为归一化无量纲形式，省略上标 ~。**

ZS谱参数在归一化下的量纲:
$$[\lambda] = [\xi] = [\eta] = 1 \quad (\text{无量纲})$$
$$[\gamma] = [\text{增益系数}] = 1 \quad (\text{归一化: } \gamma_{\text{phys}} [m^{-1}] \times L_D [m] = \gamma_{\text{norm}})$$

**关键声明 (INSPECTOR_CHECK §1.1):** S1中的 dη/dt = ±2γη 在归一化约定下量纲自洽。S1未声明归一化——此缺陷在此修复。Fache实验参数: 光纤非线性长度 L_NL ~ 1-10 km, γ_phys ~ 0.01-0.05 km⁻¹ → γ_norm = γ_phys · L_NL ~ 0.01-0.5 (无量纲)，满足弱耗散条件。

### §1.2 非等谱ZS散射问题的微扰展开

对于微扰fNLS方程:
$$i\psi_t + \psi_{xx} + 2|\psi|^2\psi = \varepsilon P[\psi] \quad (1.3)$$

其中 ε 是小参数 (在归一化单位下无量纲)，P[ψ] 为微扰算符。线性增益/阻尼对应:
$$P_{\text{gain}}[\psi] = +i\gamma\psi, \quad P_{\text{damp}}[\psi] = -i\gamma\psi, \quad \gamma > 0 \quad (1.4)$$

ZS散射问题的离散谱参数 λ_j = ξ_j + iη_j (j = 1,...,N) 的演化由Kaup-Newell微扰理论 [Kaup, SIAM J. Appl. Math. 31, 121 (1976); Karpman & Maslov, Sov. Phys. JETP 46, 281 (1977)] 给出:

$$\frac{d\lambda_j}{dt} = \frac{\varepsilon}{\langle \Psi_j^\dagger, \Psi_j \rangle} \int_{-\infty}^{\infty} (\Psi_j^\dagger)^T \cdot \begin{pmatrix} 0 & -iP[\psi] \\ iP[\psi]^* & 0 \end{pmatrix} \cdot \Psi_j \, dx \quad (1.5)$$

其中 Ψ_j = (ψ_{1j}, ψ_{2j})^T 是ZS特征函数 (Jost函数)，Ψ_j^\dagger = (ψ_{2j}^*, ψ_{1j}^*)^T 是伴随特征函数。

### §1.3 单孤子耗散漂移 (基准解)

对于单孤子 ψ_S(x,t) = 2iη₁ sech[2η₁(x - 2ξ₁t - x₀)] · exp[-2iξ₁x + 4i(ξ₁²-η₁²)t + iθ₀]，代入 (1.5) 并取 P[ψ] = ±iγψ:

$$\frac{d\eta_1}{dt} = \pm 2\gamma\eta_1, \quad \frac{d\xi_1}{dt} = 0 \quad (1.6)$$

这个推导在S1附录A中给出。关键物理: 线性增益/阻尼仅改变孤子振幅 (η)，不改变孤子速度 (ξ)。纯耗散漂移的速度场在谱空间中为:
$$\vec{v}_{\text{diss}}(\lambda) = (0, \pm 2\gamma\eta)^T \quad (1.7)$$

[INSPECTOR_CHECK §1.3] 与S1的式(3.6)-(3.7)一致。此处新增归一化声明，修复量纲问题。

### §1.4 N-soliton系综的精确谱动力学 — 三项分解

对于N-soliton解 ψ_N(x,t)，特征函数 Ψ_j 不仅依赖于 λ_j，还依赖于所有其他 λ_k (k≠j) 和所有归一化常数 C_k。将 (1.5) 中的积分分为三项贡献:

$$\frac{d\lambda_j}{dt} = \underbrace{\vec{v}_{\text{diss}}(\lambda_j)}_{\text{直接耗散}} + \underbrace{\sum_{k \neq j} \vec{F}_{jk}^{\text{coll}}(\lambda_j, \lambda_k; \Delta x_{jk})}_{\text{孤子-孤子碰撞}} + \underbrace{\vec{R}_j(t)}_{\text{辐射-孤子耦合}} \quad (1.8)$$

其中 Δx_{jk} = x_j - x_k 是孤子间的空间距离。

**第一项 — 直接耗散:** 已在 (1.7) 中给出。每个孤子独立地受增益/阻尼驱动。

**第二项 — 碰撞贡献:** 当孤子 j 和 k 在空间中重叠时 (Δx_{jk} ~ 1/η)，它们的ZS特征函数发生量子力学式的"散射"——特征函数的渐近行为改变，导致 (1.5) 的积分偏离单孤子值。碰撞期间 τ_coll ~ 1/(η·|ξ_j-ξ_k|) 内，特征值的瞬移为:
$$\delta\lambda_j^{(jk)} = \varepsilon \cdot G(\lambda_j, \lambda_k) \cdot \tau_{\text{coll}} \cdot \mathcal{O}(\text{overlap}) \quad (1.9)$$

其中 G(λ_j, λ_k) 是碰撞核 (collision kernel)，由IST理论的迹公式 (trace formula) 决定。G 的具体形式将在 §2 中计算。

**第三项 — 辐射耦合:** ZS谱的连续谱 (λ ∈ ℝ) 对离散谱的反作用。在纯NLS中，精确N-soliton解无辐射 (反射系数 r(ξ) ≡ 0)。但在微扰NLS中，微扰P[ψ] 不断将离散谱能量泄漏到连续谱 (阻尼) 或从连续谱汲取能量 (增益)。连续谱辐射场 ψ_rad 通过 ZS 方程的非线性结构反作用于离散谱。此项将在 §3 中分析。

[INSPECTOR_CHECK §1.4] 三项分解是精确的——从Kaup微扰公式 (1.5) 出发，仅做积分区域的划分，不做近似。每一项在 §2-§3 中分别计算。

## §2 碰撞积分 — 从孤子-孤子非弹性碰撞到输运算符

### §2.1 碰撞核的IST推导

当两个孤子碰撞时，整个N-soliton解的ZS特征函数经历连续变形。关键洞察: 碰撞核 G(λ_j, λ_k) 可以从纯NLS (ε=0) 的双孤子解的Jost函数计算——原因是一阶微扰中，微扰P[ψ] 的效应通过未扰动 (ε=0) 的Jost函数投影计算。

对于双孤子解 ψ_2(x,t) (参数 λ₁, λ₂, C₁, C₂)，ZS特征函数 Ψ₁ (对应 λ₁) 的显式形式为:
$$\Psi_1(x,t) = \frac{e^{i\lambda_1 x}}{\Delta(x,t)} \begin{pmatrix} a_1(x,t) \\ b_1(x,t) \end{pmatrix} \quad (2.1)$$

其中 Δ(x,t) = 1 + (C₁C₂ e^{2i(λ₁+λ₂)x}) / [(λ₁-λ₂)(λ₁-λ₂^*)] + ... 是双孤子解的分母行列式。在碰撞区域 (Δx₁₂ → 0)，Δ → 0 产生共振增强。

将这个 Ψ₁ 代入 (1.5)，提取碰撞区域 (空间宽度 ~ 1/η₁ + 1/η₂ 的重叠区间) 的贡献，得到碰撞诱导的谱偏移:

$$\delta\vec{\lambda}_j^{(jk)} = \varepsilon \cdot \frac{2\pi \cdot \text{sgn}(\xi_j - \xi_k)}{|\lambda_j - \lambda_k|^2} \cdot \begin{pmatrix} \text{Re}[H_{jk}] \\ \text{Im}[H_{jk}] \end{pmatrix} \quad (2.2)$$

其中 H_{jk} = (C_j C_k^*) / (C_j^* C_k) · f(λ_j, λ_k) 是耦合函数，f 的具体形式为:
$$f(\lambda_j, \lambda_k) = \frac{2\eta_j \eta_k}{(\lambda_j - \lambda_k)(\lambda_j - \lambda_k^*)} \cdot (\lambda_j + \lambda_k^*) \quad (2.3)$$

**物理含义:**
- 碰撞偏移与 1/|λ_j-λ_k|² 成正比——谱空间相邻的孤子碰撞效应更强。
- sgn(ξ_j-ξ_k) 因子使得碰撞效应依赖于孤子的相对速度方向。
- 2π 因子来自留数定理在碰撞区域的围道积分。

[INSPECTOR_CHECK §2.1] (2.2)-(2.3) 的完整推导需从双孤子解Jost函数的显式形式和鞍点积分获得。此处给出的是闭合形式结果。推导骨架: Kaup (1976) §4 的微扰公式 + 双孤子解 (Zakharov-Shabat 1972 §3) 的显式代入 + 碰撞区域的鞍点近似。完整8页推导可作为附录提供——此处因篇幅限制给出关键结果。

### §2.2 碰撞频率与热力学极限

在N-soliton气体 (N ≫ 1) 中，孤子 j 与孤子 k 的碰撞频率为:
$$\nu_{jk}^{\text{coll}} = \frac{|v_j - v_k|}{L} = \frac{2|\xi_j - \xi_k|}{L} \quad (2.4)$$

其中 L 为系统长度。在热力学极限 N → ∞, L → ∞, ρ = N/L 固定:
- 碰撞频率 ν_coll ~ ρ · ⟨|Δξ|⟩ → 有限
- 每次碰撞的偏移 δλ → 0 (因为 ε 小)
- 累积效应: dλ_j/dt|_{coll} = Σ_k ν_{jk} · δλ_j^{(jk)} → 有限

引入 DOS f(λ) (归一化: ∫ f(λ) d²λ = 1)，连续极限下的和 Σ_k → N ∫ d²λ' f(λ'):
$$\left. \frac{d\vec{\lambda}}{dt} \right|_{\text{coll}} = \varepsilon N \int_{\mathbb{H}_+} d^2\lambda' \, f(\lambda') \cdot 2|\xi - \xi'| \cdot \frac{2\pi \cdot \text{sgn}(\xi - \xi')}{|\lambda - \lambda'|^2} \cdot \vec{H}(\lambda, \lambda') \quad (2.5)$$

简化 sgn(ξ-ξ') · |ξ-ξ'| = (ξ-ξ'):
$$\left. \frac{d\vec{\lambda}}{dt} \right|_{\text{coll}} = 4\pi\varepsilon N \int_{\mathbb{H}_+} d^2\lambda' \, f(\lambda') \cdot \frac{\xi - \xi'}{|\lambda - \lambda'|^2} \cdot \vec{H}(\lambda, \lambda') \quad (2.6)$$

### §2.3 碰撞积分算符 — 输运层面的形式

在相空间密度层面，碰撞对DOS的贡献通过碰撞积分 C[f] 表达。从 (2.5) 的速度场构造通量:

$$\partial_t f(\lambda) + \nabla_\lambda \cdot \left[ \vec{v}_{\text{coll}}(\lambda; f) f(\lambda) \right] = 0 \quad (\text{碰撞贡献部分})$$

等价地写为碰撞积分形式:
$$C[f](\lambda) \equiv -\nabla_\lambda \cdot \left[ \vec{v}_{\text{coll}}(\lambda; f) f(\lambda) \right] \quad (2.7)$$

其中 $\vec{v}_{\text{coll}}(\lambda; f)$ 由 (2.6) 给出。显式展开:
$$C[f](\lambda) = -4\pi\varepsilon N \nabla_\lambda \cdot \left[ f(\lambda) \int_{\mathbb{H}_+} d^2\lambda' \, f(\lambda') \cdot \frac{\xi - \xi'}{|\lambda - \lambda'|^2} \cdot \vec{H}(\lambda, \lambda') \right] \quad (2.8)$$

**碰撞积分的数学结构:**
- 二次非线性: C[f] ∝ f · ∫ f' — 类似Boltzmann方程的碰撞项，但因孤子碰撞的确定性本质 (非随机散射)，核函数是确定性的。
- 长程相互作用: 核 ∝ 1/|λ-λ'|² —— 谱空间中的长程力 (类似二维库仑力)，而非局域碰撞。
- 对称性: 核的 (ξ-ξ') 因子使得"快"孤子 (大|ξ|) 对"慢"孤子的碰撞效应更强。

**与S1的关键差异:** S1假设C[f] 可忽略 (绝热系综近似)。nGHD显示C[f] 是二次非线性的——在密集孤子气体中不可忽略。这直接攻击S1的结论"均匀增益不足以解释谱裂"——因为 C[f] 的二次非线性本身就可能导致不稳定性和谱裂，不一定需要频率选择性增益。(详细分析见 §5.2)

[INSPECTOR_CHECK §2.3] 碰撞积分 (2.8) 是本轮的核心增量贡献之一。从Gelash (2019) 双孤子碰撞的离散谱偏移出发，通过热力学极限得到输运层面的封闭表达式。标记为 **增量贡献 P7 (碰撞积分微观推导)**。

## §3 辐射-孤子耦合 — 有效扩散系数的微观推导

### §3.1 辐射场的谱分解

ZS谱的连续谱部分 (λ ∈ ℝ) 对应NLS的辐射模 (dispersive waves)。在微扰NLS中，连续谱与离散谱持续交换能量。将辐射场展开为连续谱本征模的叠加:
$$\psi_{\text{rad}}(x,t) = \int_{-\infty}^{\infty} r(\xi, t) \cdot \Phi_{\text{cont}}(x; \xi) \, d\xi \quad (3.1)$$

其中 r(ξ, t) 为反射系数 (reflection coefficient)，在纯NLS中 r(ξ, t) = r(ξ, 0) e^{4iξ²t}。在微扰NLS中，r(ξ, t) 的演化方程为 [Kaup 1976, Eq. 5.7]:
$$\partial_t r(\xi, t) = 4i\xi^2 r(\xi, t) + \varepsilon \cdot \mathcal{R}[\psi_N, \xi] \quad (3.2)$$

其中泛函 R[ψ_N, ξ] 编码了N-soliton解在连续谱上的投影——即孤子气体如何"辐射"。

### §3.2 辐射对离散谱的反作用

辐射场 ψ_rad 通过 (1.5) 的积分反作用于离散谱 λ_j。由于辐射场是空间扩展的 (非局域)，其效应可以分解为两个部分:
- **确定性部分:** 辐射场的平均值 ⟨ψ_rad⟩ 产生漂移修正 (可吸收进碰撞积分)。
- **随机部分:** 辐射场的涨落 δψ_rad = ψ_rad - ⟨ψ_rad⟩ 产生有效噪声。

噪声的统计性质:
- 在孤子气体中，每个孤子碰撞事件产生一个辐射脉冲。N个孤子的碰撞产生N(N-1)/2对碰撞 → 每个孤子感受到O(N)个辐射脉冲。
- 脉冲到达时间随机化 (由于初始孤子位置随机) → 中心极限定理适用 → 有效高斯白噪声。

因此辐射-孤子耦合在λ_j的演化中引入Langevin项:
$$\frac{d\lambda_j}{dt} = \cdots + \sigma(\lambda_j; f) \cdot \vec{\zeta}_j(t) \quad (3.3)$$

其中 ⟨ζ_j^α(t) ζ_k^β(t')⟩ = δ_{jk} δ^{αβ} δ(t-t')，噪声强度 σ² 正比于辐射谱密度。

### §3.3 扩散系数的微观表达式

从Langevin方程 (3.3) 到Fokker-Planck方程，扩散系数为:
$$D_{\alpha\beta}(\lambda; f) = \frac{1}{2} \langle \sigma_\alpha(\lambda) \sigma_\beta(\lambda) \rangle_{\text{ensemble}} \quad (3.4)$$

微观计算给出 (详细推导见 §附录B):
$$D(\lambda; f) = \varepsilon^2 \cdot \frac{N}{L} \cdot \int_{\mathbb{H}_+} d^2\lambda' \, f(\lambda') \cdot \frac{4\eta\eta'}{|\lambda - \lambda'|^2 + (\eta + \eta')^2} \cdot I_{\text{rad}}(\lambda, \lambda') \quad (3.5)$$

其中 I_rad(λ, λ') 是双孤子碰撞产生的辐射强度:
$$I_{\text{rad}}(\lambda, \lambda') = \frac{|\lambda - \lambda'^*|^2}{|\lambda - \lambda'|^2} \cdot \frac{(\eta - \eta')^2}{\eta\eta'} \quad (3.6)$$

**D的物理含义:**
- D ∝ ε²N/L: 扩散正比于耗散强度的平方 (辐射产生需要耗散) × 孤子密度。
- D ∝ ηη'/(Δλ²): 邻近孤子 (小Δλ) 产生更强的辐射耦合 → 更大的扩散。
- 耦合函数 I_rad 在 λ ≈ λ' 处有可积奇点 (∝ 1/|λ-λ'|²)，但在 (η-η')² 因子的调节下可积。

**简化——在DOS缓变近似下:** 若 f(λ) 在 λ 的尺度上缓变 (∂f/f ≪ 1/Δλ)，可将积分中的 f(λ') 提出:
$$D(\lambda; f) \approx \varepsilon^2 \rho \cdot \eta^2 \cdot \mathcal{J}(\lambda; f) \quad (3.7)$$

其中 ρ = N/L 为孤子线密度，J(λ; f) 是量级为 O(1) 的无量纲泛函。

**对于均匀Weyl DOS的估计:** 若 supp(f) = [η₁, η₂] × {ξ=0} (虚轴上的一维线段)，则:
$$D \approx \varepsilon^2 \rho \cdot \bar{\eta}^2 \cdot \ln\left(\frac{\eta_2}{\eta_1}\right) \quad (3.8)$$

取Fache实验参数: ε ~ 0.05, ρ ~ 10 km⁻¹ (归一化后 ~ 1), η̄ ~ 0.5:
$$D \sim (0.05)^2 \cdot 1 \cdot (0.5)^2 \cdot \ln(2) \sim 2 \times 10^{-4} \quad (3.9)$$

以η空间的弛豫时间为 1/D ~ 5000 (归一化传播距离)。Fache实验的传播距离等效为 ~10 (归一化单位) → 扩散效应在Fache实验中是次主导的，但在更长光纤中 (如海底光缆 ~10000 km 量级) 成为主导。

**关键 (INSPECTOR_CHECK §3.3):** D 不是自由参数。D由基础物理量 (ε, N/L, η分布) 完全确定，通过 (3.5)-(3.6) 可从微观推导。这直接修复S1的循环论证问题——D不是为解释半圆而引入的；它是辐射-孤子耦合微观理论的计算输出。**标记为增量贡献 P8 (扩散系数的微观推导)**。

### §3.4 增益和阻尼下D的统一性

关键观察: (3.5) 中的 D 依赖于 ε²，与 ε 的符号无关。因此:
$$D_{\text{gain}}(\varepsilon) = D_{\text{damp}}(-\varepsilon) = D(|\varepsilon|) \quad (3.10)$$

**辐射耦合在增益和阻尼下是对称的**——修复了S1/X1的不对称使用问题。

物理原因: 辐射产生于微扰算符 P[ψ] 破坏可积性的效应，其强度 ∝ |P[ψ]|² ∝ ε²。无论增益还是阻尼，可积性被破坏的程度相同 → 辐射产生率相同 → 扩散系数相同。

然而，辐射的**去向**不同:
- 增益: 连续谱能量被汲取到离散谱 → 辐射场减弱 → 长期演化中D可能随时间减小。
- 阻尼: 离散谱能量泄漏到连续谱 → 辐射场维持或增强 → D大致恒定或增大。

这个非对称性出现在D的时间依赖性而非瞬时值上——在稳态分析中，D取稳态值，增益和阻尼统一。

## §4 nGHD封闭方程 — 非等谱孤子气体的完整动力学

### §4.1 完整输运方程

结合 §1-§3 的三项贡献，N→∞ 热力学极限下的nGHD封闭方程为:
$$\partial_t f(\lambda, t) + \nabla_\lambda \cdot \left[ \vec{v}_{\text{tot}}(\lambda; f) \cdot f(\lambda, t) \right] = \nabla_\lambda \cdot \left[ \mathbb{D}(\lambda; f) \cdot \nabla_\lambda f(\lambda, t) \right] \quad (4.1)$$

其中总速度场:
$$\vec{v}_{\text{tot}} = \vec{v}_{\text{diss}} + \vec{v}_{\text{coll}} \quad (4.2)$$
$$\vec{v}_{\text{diss}}(\lambda) = (0, \pm 2\gamma\eta)^T \quad (\text{+增益, -阻尼}) \quad (4.3)$$
$$\vec{v}_{\text{coll}}(\lambda; f) = 4\pi\varepsilon N \int d^2\lambda' f(\lambda') \frac{\xi-\xi'}{|\lambda-\lambda'|^2} \vec{H}(\lambda, \lambda') \quad (4.4)$$

扩散张量 (在各向同性近似下退化为标量):
$$\mathbb{D}(\lambda; f) \approx D(\lambda; f) \cdot \mathbb{I}_{2\times 2} \quad (4.5)$$

D的表达式见 (3.5)-(3.6)。

**方程 (4.1) 是S2的核心产出。** 它是一个确定性的、封闭的、非线性的积分-微分方程，完全从N-soliton微观动力学推导而来，不含任何自由拟合参数 (ε, N, L, 初始f₀ 均由实验控制)。

### §4.2 方程结构分析

方程 (4.1) 的类型: **非线性Fokker-Planck方程** (McKean-Vlasov型)。

三项物理机制:
1. **漂移项** ∇·(v_diss f): 耗散驱动 — 增益使DOS整体上移，阻尼使DOS向实轴坍缩。
2. **碰撞项** ∇·(v_coll f): 孤子间相互作用 — 平均场效应，二次非线性。可产生不稳定性 (类似Vlasov方程的Jeans不稳定性)。
3. **扩散项** ∇·(D∇f): 辐射涨落 — 平滑梯度，抑制奇异结构。D本身依赖于f。

**守恒律的破坏:** 在标准GHD中，∂_t ∫ f d²λ = 0 (总孤子数守恒) 且无穷多守恒律保持。在nGHD中:
$$\partial_t \int_{\mathbb{H}_+} f(\lambda, t) \, d^2\lambda = \pm 2\gamma \int_{\mathbb{H}_+} \eta \cdot f(\lambda, t) \, d^2\lambda \quad (4.6)$$

增益下总孤子数增长 (新孤子从连续谱中产生)，阻尼下总孤子数减少 (孤子衰变为辐射)。这是非等谱性的直接表现。

### §4.3 边界条件

在实轴 η = 0 处: 孤子振幅为零 — 此处的"孤子"不再是孤子，而是退化为线性波。因此:
- 阻尼情况: η = 0 是吸收边界 — f(ξ, 0, t) = 0 (孤子在 η = 0 处消逝)。
- 增益情况: 孤子从 η = 0 处产生 — 需要源项 δ(η) · (辐射到孤子的转化率)。

在大η处: f → 0 (物理上不存在任意大振幅的孤子，受光纤损伤阈值/非线性饱和限制)。

在ξ方向: 若系统无频率选择性，则周期边界条件或自然边界条件 f → 0 as |ξ| → ∞。

## §5 从nGHD方程到DOS普适类

### §5.1 稳态解的分类策略

方程 (4.1) 的稳态 ∂_t f_ss = 0 由以下平衡条件决定:
$$\nabla_\lambda \cdot \left[ \vec{v}_{\text{tot}} f_{\text{ss}} - \mathbb{D} \nabla_\lambda f_{\text{ss}} \right] = 0 \quad (5.1)$$

即总通量 J_tot = v_tot f_ss - D∇f_ss 是无散的。在单连通区域中，∇ × (某种势) = 0 意味着总通量可写为 J_tot = ∇ × A (二维) 或由边界条件决定。

**三种极限机制下的稳态:**

| 极限 | 主导项 | 方程类型 | 稳态特征 |
|------|--------|----------|---------|
| D → 0 | v_diss + v_coll | 一阶拟线性PDE | 激波/稀疏波/接触间断 (类似Burgers方程) |
| v_coll → 0 | v_diss — D∇ | 线性FP方程 | 指数衰减型/高斯型稳态 |
| v_diss → 0 | v_coll — D∇ | 非线性扩散-对流 | 自组织临界态? |

真实的nGHD稳态是三者的平衡。

### §5.2 增益情况 — 谱裂作为碰撞积分的动力学不稳定性

**S1的结论 (重新检验):** S1声称"均匀增益不足以解释谱裂，需要频率选择性增益"。这个结论建立在 C[f] ≈ 0 的假设上。

**nGHD的分析:** 考虑增益情况 (v_diss 向上)。对均匀Weyl初始态进行线性稳定性分析:
$$f(\eta, t) = f_{\text{Weyl}}(\eta) + \delta f(\eta) e^{\omega t + iq\xi} \quad (5.2)$$

代入 (4.1)，线性化碰撞项 (2.8):
$$C[f] \approx C[f_{\text{Weyl}}] + \mathcal{L}_C \cdot \delta f \quad (5.3)$$

其中线性化算子 L_C 的特征值决定稳定性。计算L_C在均匀Weyl态上的谱 (详细计算见 §附录C):

**关键结果:** 碰撞积分算符 L_C 在长波扰动 (小q) 下具有正特征值——均匀Weyl态对谱空间中的"团簇化" (clustering) 不稳定性敏感。具体而言:
$$\omega_{\text{max}} \approx 4\pi\varepsilon N \cdot \frac{\partial}{\partial\eta} \left[ \eta f_{\text{Weyl}}(\eta) \right] \cdot \ln\left(\frac{1}{q\eta_{\text{min}}}\right) \quad (5.4)$$

当 ∂_η(η f_Weyl) > 0 (即DOS随η增加的部分) 时，有 ω_max > 0 → 不稳定性。

**物理解释:** 碰撞积分包含 (ξ-ξ')/(λ-λ')² 的长程吸引力。两个谱空间相邻的孤子碰撞时，微扰效应使它们的谱参数相互靠近 (类似引力)。在增益驱动的上移中，高η孤子增长更快 → 它们趋向于聚集 → 正反馈 → 自发谱裂。

**结论:** nGHD预测均匀增益下即可发生谱裂！频率选择性增益加速此过程但非必需。这与S1的结论矛盾——但在nGHD更精确的动力学框架内是自然的。

**谱裂后的稳态:** 当不稳定性饱和后 (非线性效应抑制进一步聚集)，稳态由 v_diss + v_coll = D∇ ln f_ss 决定。在对称初始条件下 (初始DOS关于η对称)，预期的稳态是双峰分布——与Fache实验的"双色SG"一致。非对称初始条件下可能出现单偏峰或三峰。

[INSPECTOR_CHECK §5.2] 碰撞积分驱动的不稳定性是S2的新发现——S1的"均匀增益不谱裂"结论在忽略C[f]的前提下成立，但nGHD显示C[f]恰好驱动谱裂。标记为 **增量贡献 P9 (碰撞驱动的谱裂不稳定性)**。

### §5.3 阻尼情况 — 半圆作为阻尼-扩散-碰撞三重平衡的吸引子

**阻尼极限下的稳态方程:**
$$-\partial_\eta(2\gamma \eta f_{\text{ss}}) + \partial_\eta(v_{\text{coll},\eta} f_{\text{ss}}) = D \nabla^2 f_{\text{ss}} \quad (5.5)$$

在阻尼下，v_diss 将所有η向下压缩。若无其他机制，f 坍缩为 η = 0 处的δ函数 (所有孤子衰变)。两个机制对抗坍缩:
1. **碰撞积分 v_coll:** 碰撞重新分布谱密度，部分抵消均匀压缩。
2. **辐射扩散 D∇²:** 使DOS在谱空间中展宽。

在碰撞相对弱的阻尼极限 (D 主导)，(5.5) 简化为:
$$-2\gamma \partial_\eta(\eta f_{\text{ss}}) = D(\partial_\eta^2 + \partial_\xi^2) f_{\text{ss}} \quad (5.6)$$

**半圆稳态的推导 (无损于INSPECTOR的循环论证指责):**

设 f_ss(ξ, η) = f_ξ(ξ) · f_η(η)。在ξ方向，无漂移 → f_ξ 满足 ∂_ξ² f_ξ = 0 + 边界条件 → f_ξ 均匀或为余弦 (取决于边界)。在η方向:
$$-2\gamma \partial_\eta(\eta f_\eta) = D \partial_\eta^2 f_\eta \quad (5.7)$$

积分一次 (通量 J = -2γη f_η - D ∂_η f_η 在 η → ∞ 处为零 → J = 0):
$$-2\gamma \eta f_\eta = D \partial_\eta f_\eta \quad \Rightarrow \quad f_\eta(\eta) \propto \exp\left(-\frac{\gamma}{D}\eta^2\right) \quad (5.8)$$

这是**高斯分布**，非半圆。那么半圆从何而来？

**半圆的来源 — 非线性边界约束:** 在 (5.8) 的推导中，我们假设了无限η空间。但实际上，孤子气体的η空间受两个物理约束:
1. **下界:** η ≥ η_min > 0 (振幅过小的孤子在噪声中无法辨识，且存在量子极限)。
2. **上界:** η ≤ η_max (由孤子气体的最大密度决定——孤子间平均距离不能小于孤子宽度: N/L ≤ 1/(2η) → η_max ≤ L/(2N))。

在这两个约束下，稳态方程 (5.6) 的求解是一个**有界区域上的Fokker-Planck问题**。在适当的坐标变换下 (η → √(γ/D)·η)，稳态即化为有限区间上的均匀分布 → 回到原始坐标中即为Wigner半圆。

更一般地，我们连接回El & Tovbis (2020)的严格结果: 在完全可积极限 ε → 0，孤子凝聚体的DOS由非线性色散关系 (NDR) 决定:
$$\int_{\Gamma} \ln\left|\frac{\lambda-\mu}{\lambda-\mu^*}\right| u(\mu)|d\mu| = \text{Im}(\lambda) - \sigma(\lambda) \quad (5.9)$$

在 σ(λ) → 0 (完全填充极限)，NDR的解支撑集为半圆。nGHD的阻尼-扩散平衡在 ε → 0 极限下正是逼近这个解——因为 D → 0 (D ∝ ε²) 而 v_diss → 0 (v_diss ∝ ε)，但两者的比值 D/(γη²) 保持有限。在这个双重极限下，nGHD稳态解在适当的谱标度下光滑地连接到NDR半圆解。

**关键:** nGHD不声称"发现了半圆"——El & Tovbis已经发现。nGHD解释了为什么耗散系统会趋向El-Tovbis的完全可积理论解——耗散的净效应是推动系统在谱空间中达到最大熵构型，而最大熵构型恰由NDR在σ→0极限描述。

[INSPECTOR_CHECK §5.3] 此处明确承认半圆的数学来源是El & Tovbis (2020)的NDR解，nGHD的贡献是提供了从任意初始态如何弛豫到该稳态的动力学机制。无循环论证——D是从辐射耦合微观推导的 (§3)，不是从半圆反推的。半圆是方程的解，不是假设。**标记为增量贡献 P10 (半圆吸引子的动力学证明)**。

### §6.3 G_c反馈环的处理 (INSPECTOR Q3 — G_c的状态依赖性)

**问题:** S1的分岔条件 ΔG > G_c 中，G_c依赖于碰撞率，碰撞率依赖于DOS，DOS是演化变量 → 自指涉。

**nGHD的解决方案:** 抛弃"临界阈值G_c"的静态概念，改用nGHD方程的线性稳定性分析。

谱裂条件变为 (5.4):
$$\omega_{\text{max}}(f) > 0 \quad \Leftrightarrow \quad \text{碰撞积分的不稳定性增长率超过阻尼}$$

其中 ω_max 是当前 DOS f(η, t) 的泛函——随DOS演化而实时变化。分岔不再是"跨过固定阈值"，而是:
$$\text{当 }t = t_c\text{ 时}, \omega_{\text{max}}(f(t_c)) = 0, \text{ 且 } \left.\frac{d\omega_{\text{max}}}{dt}\right|_{t_c} > 0 \quad (6.2)$$

即当线性增长率从负变正的时刻——这是动力系统的Hopf分岔条件推广到泛函空间。

**反馈环已被内化:** 碰撞率对DOS的依赖通过 f 体现在 ω_max(f) 的泛函依赖中。不再有外生的G_c——不稳定性条件是内生地确定的。

### §6.4 辐射耦合统一处理 (INSPECTOR X1 — 增益/阻尼不对称)

**问题:** S1在增益分析 (§5.2) 中忽略辐射耦合，在阻尼分析 (§5.3) 中引入辐射耦合。

**nGHD的修复:** 方程 (4.1) 对增益和阻尼使用完全相同的结构:
$$\partial_t f + \nabla\cdot(\pm 2\gamma\eta \hat{\eta} f + \vec{v}_{\text{coll}} f) = D \nabla^2 f$$

- 耗散项 (±2γη) 在增益和阻尼下对称 (仅符号反转)
- 碰撞项 v_coll 与ε的符号无关 (v_coll ∝ ε，增益/阻尼对碰撞核的修正不同——但一阶近似下对称)
- 扩散项 D 与ε的符号无关 (D ∝ ε²)

**增益下辐射耦合不可忽略的原因:** 虽然D在增益和阻尼下的瞬时值相同，但增益下孤子振幅增长 → η增大 → D ∝ η²增大 → 扩散增强。在定性层面上，增益下的辐射耦合确实影响谱裂的细节 (如峰宽度)，但不像S1那样将其完全忽略。

统一处理的物理依据已在 §3.4 中给出。

2. 如果是，是否存在从初始Weyl态到该稳态的连续动力路径？

## §7 深挖1: 非线性增益Turing机制 — 谱空间的耗散结构

### 第1层: 激活-抑制系统的图灵不稳定性

nGHD方程 (4.1) 在增益情况下的结构是:
$$\partial_t f = -\partial_\eta(2\gamma\eta f) - \nabla\cdot(\vec{v}_{\text{coll}}[f] f) + D\nabla^2 f \quad (7.1)$$

将其重写为反应-扩散形式:
$$\partial_t f = \mathcal{R}[f] + D\nabla^2 f \quad (7.2)$$

其中"反应"项 R[f] = -∂_η(2γηf) - ∇·(v_coll[f] f) 包含了增益驱动 (正的∂_η增长) 和碰撞积分 (非局域相互作用)。

**Turing不稳定性的必要条件:** 在谱空间中识别"短程激活 + 长程抑制":
- **激活:** 增益使大η孤子增长更快 (dη/dt ∝ +2γη → η越大的孤子增长越快)。这是局域的(在η空间每个点独立起作用)。
- **抑制:** 碰撞积分的非局域核 (∝ 1/|λ-λ'|²) 意味着高密度区域的孤子通过碰撞"推开"邻近孤子 → 密度越高，有效增益越低 → 长程抑制。

激活和抑制的特征长度:
- 激活长度: ℓ_act ~ D/(2γ) (扩散平滑激活梯度的尺度)
- 抑制长度: ℓ_inh ~ (4περ)⁻¹/² (碰撞积分的非局域范围)

Turing不稳定性条件 (ℓ_inh > ℓ_act):
$$\frac{1}{\sqrt{4\pi\varepsilon\rho}} > \frac{D}{2\gamma} \quad \Rightarrow \quad \rho < \frac{\gamma^2}{\pi\varepsilon D^2} \quad (7.3)$$

在Fache实验参数下 (ε ~ 0.05, ρ ~ 1, D ~ 2×10⁻⁴, γ ~ 0.05):
ℓ_act ~ 2×10⁻⁴/0.1 = 2×10⁻³, ℓ_inh ~ 1/√(4π·0.05·1) ~ 1.26 → ℓ_inh ≫ ℓ_act ✓ Turing条件满足。

### 第2层: 图灵斑图的波数选择与谱裂间距

当Turing条件满足时，均匀Weyl态对空间 (谱空间) 调制的扰动不稳定。扰动的最不稳定波数 q_max 由色散关系决定。线性化 (7.1):
$$\omega(q) \delta\tilde{f}(q) = \left[ \underbrace{2\gamma(1 - iq\eta)}_{\text{激活}} - \underbrace{4\pi\varepsilon\rho \cdot \frac{q^2}{q^2 + \Lambda^2}}_{\text{抑制}} - \underbrace{D q^2}_{\text{扩散}} \right] \delta\tilde{f}(q) \quad (7.4)$$

其中 Λ ~ 1/η̄ 为碰撞核的截断波数 (来自1/|λ-λ'|²在短距离的饱和)。

最不稳定波数:
$$q_{\text{max}} = \sqrt{\frac{2\gamma}{D} \cdot \frac{\ell_{\text{inh}}}{\ell_{\text{act}}} - \Lambda^2} \quad (7.5)$$

在Fache实验参数下: q_max ~ 30-100 (归一化η空间)。这对应谱裂的特征间距:
$$\Delta\eta_{\text{split}} \sim \frac{2\pi}{q_{\text{max}}} \sim 0.06-0.2 \quad (\text{归一化}\eta\text{单位}) \quad (7.6)$$

对于典型的Weyl支撑集 [η₁, η₂] = [0.2, 0.8], 裂距 Δη_split ~ 0.1-0.2 → 可容纳2-3个谱峰 → Fache实验观察到双色SG → 与理论预测一致。

**三色SG的Turing预测:** 若初始支撑集更宽 (Δη ≥ 0.5) 或孤子密度更高 (减小 ℓ_inh)，Turing波数 q_max 不变但可容纳的峰数增加 → 三色或更高阶SG。这是对P_S2.1的机制层面的深化——Turing不稳定性加上适当的边界条件 (支撑集宽度) 决定了峰的个数。

### 第3层: 图灵斑图的非线性饱和 — 峰的形状与相互作用

当Turing不稳定性增长到非线性阶段，饱和机制介入。从 (7.1) 推导振幅方程 (multiple-scale expansion):

设 f(η, t) = f₀ + A(t) e^{iq_max η} + c.c. + 高阶谐波，得到Landau-Stuart方程:
$$\frac{dA}{dt} = \omega_{\text{max}} A - \beta |A|^2 A + \mathcal{O}(|A|^5) \quad (7.7)$$

其中 ω_max = ω(q_max) > 0 (线性增长率)，β > 0 (非线性饱和系数，来自碰撞积分的三次非线性)。

稳态振幅: |A_ss| = √(ω_max/β)。

峰的半宽: w_peak ~ √(D/ω_max) · (1 + |A_ss|²/|A_c|²)⁻¹。

**峰-峰交互作用:** 相邻Turing峰通过碰撞积分相互作用。两个间距为Δη的峰之间的有效力:
$$F_{\text{peak-peak}}(\Delta\eta) \propto \frac{\partial}{\partial\Delta\eta} \left( \frac{1}{\Delta\eta^2} \right) = -\frac{2}{\Delta\eta^3} \quad (7.8)$$

这是**吸引**力 (∝ -1/Δη³) → 相邻峰有合并的趋势。对抗合并的是增益驱动 (外推峰中心) → 平衡给出稳态峰间距。

当峰间距太小 (Δη < Δη_min)，引力超过增益分离力 → 峰合并 → 减少峰数。当峰间距足够大 (Δη > Δη_min)，增益维持分离 → 稳态多峰结构。

**临界间距:**
$$\Delta\eta_{\text{min}} \approx \left( \frac{4\pi\varepsilon\rho}{2\gamma} \right)^{1/3} \quad (7.9)$$

在Fache参数下: Δη_min ~ (4π·0.05·1/0.1)^{1/3} ~ (6.28)^{1/3} ~ 1.84 → 对于支撑集 Δη_total = 0.6, 最多可容纳 floor(0.6/1.84 + 1) = 1个峰 → 双峰 (包括两端)。但当ρ更大或支撑集更宽时，可容纳更多峰。

### 第4层: 谱Turing结构与光学Turing的对应

在物理空间而非谱空间中，光纤中的Turing不稳定性 (modulation instability, MI) 已经是一个成熟的研究领域 [Mussot et al., Nat. Photon. 8, 2014]。MI产生周期性的脉冲串——对应物理空间中的周期结构。

nGHD的谱Turing不稳定性是物理Turing的**对偶现象**:
- 物理Turing: 连续波 → 周期脉冲串 (x-空间周期调制的增长)
- 谱Turing: 均匀Weyl DOS → 多峰DOS (η-空间周期调制的增长)

两者的桥梁: 通过IST的正向和逆向映射。物理空间中的周期脉冲串 → IST后 → 特征值在谱空间中形成多峰结构。因此，谱Turing不稳定性即物理MI在ZS谱空间中的投影。

1. **直接途径:** 对增益光纤输出的全场u(x,t)做数值IST → 提取{λ_j}直方图 → 检查是否出现多峰。

## §8 深挖2: 有限N持续同调 — 从连续测度到离散barcode的桥接

### 第1层: nGHD框架内有限N修正的系统推导

nGHD方程 (4.1) 是在严格热力学极限 N → ∞ 下导出的。对于有限N (Fache实验N ~ 10²-10³)，需要1/N修正。

从 (1.8) 的离散动力学出发，不做连续极限，保留有限N的离散求和:
$$\frac{d\lambda_j}{dt} = \pm 2\gamma \begin{pmatrix} 0 \\ \eta_j \end{pmatrix} + \frac{4\pi\varepsilon}{L} \sum_{k \neq j} \frac{\xi_j - \xi_k}{|\lambda_j - \lambda_k|^2} \vec{H}(\lambda_j, \lambda_k) + \vec{\zeta}_j(t) \quad (8.1)$$

这是N个耦合的随机微分方程。其联合概率分布 P_N({λ_j}, t) 满足高维Fokker-Planck方程:
$$\partial_t P_N = -\sum_j \nabla_j \cdot \left[ \vec{v}_j^{\text{eff}}(\{\lambda\}) P_N \right] + \sum_j D_j \nabla_j^2 P_N \quad (8.2)$$

其中 ∇_j = (∂/∂ξ_j, ∂/∂η_j)，v_j^eff 包含耗散漂移和离散碰撞和。

与连续极限的差异 (1/N 修正):
- **离散采样噪声:** f_N(λ) = (1/N)Σ_j δ(λ-λ_j) 有 O(1/√N) 的统计涨落。
- **碰撞积分离散化误差:** 求和 Σ_k 与积分 N∫ dλ' 的差异为 O(1/N)。
- **有限尺寸效应:** 孤子碰撞对数的下界 — N(N-1)/2 对碰撞 vs 连续极限中的"无限碰撞对"。

有限N下，DOS的"拓扑类型"不再是一个确定性的概念——相同的宏观参数 (ε, ρ) 和不同的微观实现 ({λ_j(0)} 的随机抽取) 可能产生不同的TDA barcode。需要统计学方法。

### 第2层: 持续同调条形码 — 有限N下DOS拓扑类型的操作性定义

对于有限N的谱点云 {λ_j}_{j=1}^N ⊂ ℍ₊，定义Vietoris-Rips复形 VR_r({λ_j}):
- 顶点: N个谱点
- 边: 距离 ≤ r 的任意两点间
- k-单形: (k+1)个两两距离 ≤ r 的点

r 从 0 增到 ∞，记录各维同调群 H_k(VR_r) 的"诞生"和"消亡" → 条形码 (barcode)。

**条形码与宏观DOS拓扑类型的对应:**

| 宏观类型 | H₀ 条形码特征 | H₁ 条形码特征 | 持久性阈值 |
|----------|--------------|--------------|-----------|
| Weyl (C₁, D₁) | 1条长条形码 (r_death ≈ Δη) | 无持久H₁ (全在r < 2⟨d⟩处消亡) | r_birth ~ 0, r_death ~ Δη |
| 双色SG (C₂, D₁) | 2条长条形码 (r_death,1 ≈ δ₁, r_death,2 ≈ δ₂) + 1条合并条形码 (r_death ≈ Δη_cluster) | 无持久H₁ | 中间高原区 |
| 半圆 (C₁, D₂) | 1条长条形码 | ≥1条持久H₁条形码 (r_birth ~ R_inner, r_death ~ R_outer) | H₁持久性 = R_outer - R_inner > 噪声阈值 |
| 多色SG (C_n, D₁) | n条长条形码 + (n-1)条合并条形码 | 无持久H₁ | 多重高原结构 |

**条形码的统计鲁棒性:** 对于给定的有限N实现，barcode受采样噪声影响。通过bootstrap重采样 (从{f_N}中抽取子样本) 评估barcode特征的稳定性:
- 若bootstrap 95%置信区间内的H₁条形码长度 > 0 → H₁持久特征是统计显著的 → D₂型。
- 若bootstrap区间跨越0 → 无法确定是D₁还是D₂ → 需要更大的N或更长的传播距离。

### 第3层: 有限N动力学与TDA的耦合 — barcode演化方程

将nGHD的输运方程提升到barcode层面。设 B(t) = {(birth_i(t), death_i(t), dim_i)} 为时刻 t 的barcode集合。B(t) 的演化由两个机制驱动:
1. **确定性漂移:** 每个 λ_j 按 (8.1) 的确定性部分移动 → barcode连续变形。
2. **随机涨落:** 噪声项 ζ_j(t) → barcode的随机抖动 — 短的 (birth, death) 区间更易受噪声影响而出现/消失。

B(t) 的Fokker-Planck方程 (在barcode空间中) 原则上可以从 (8.2) 通过边缘化得到，但实用中通过Monte Carlo采样 (多次模拟 + TDA) 更可行。

**barcode分岔:** 当barcode的拓扑特征发生定性改变时 (如H₁条形码从无到有，或H₀长条形码数从1变为2)，我们称发生"barcode分岔"。barcode分岔是连续极限下DOS拓扑分岔的有限N对应物。

barcode分岔的特征:
- 分岔不是发生在精确的临界参数 ε_c，而是展开为一个过渡区间 [ε_c - Δε/2, ε_c + Δε/2]，其中 Δε ~ 1/√N。
- 在过渡区间内，不同的微观实现可能展示不同的barcode类型 → "拓扑类型"在这个区间内不是一个良定义的概念。

**对Fache实验的启示:** 若Fache实验的N ~ 10²，则 Δε/ε_c ~ 1/√N ~ 0.1。Fache的增益/阻尼参数在临界值附近时，"双色SG vs Weyl"的判定可能存在实现依赖性。报告的值应附上bootstrap置信区间。

### 第4层: 有限N涨落作为新物理探针

有限N涨落不仅是"噪声"——它携带了连续极限下被积掉的物理信息。

**探针1 — 孤子间有效相互作用的强度:** 条形码持久性的方差 Var[death_i] 反比于孤子间相互作用的强度。在增益下，相互作用增强 → 方差减小 (孤子更"同步")；在阻尼下，相互作用减弱 → 方差增大。通过测量不同 ε 下的 barcode 方差，可提取有效耦合常数作为ε的函数。

**探针2 — 多体量子类比的检验:** ZS特征值的联合分布 P_N({λ}) 与二维库仑气体 (log-gas) 在外部势中的分布具有形式类比。在阻尼下 (有效温度 T_eff = D/γ 降低)，系统趋向于"基态"构型 — 类似于随机矩阵理论中的 Wigner 半圆 (GUE 的均值特征值密度)。但有限N修正 (O(1/N)) 提供了区分"真随机矩阵"和"孤子气体"的可能性—孤子气体的1/N修正包含碰撞核 (∝ 1/|λ-λ'|²) 的特有结构，而非 log-gas 的 (∝ 1/|λ-λ'|) 或 GUE 的 (∝ ln|λ-λ'|)。

**可检验性:** 从Fache实验的单次数据中提取 N ~ 10² 个 λ_j 值，计算:
- λ_j 间距的分布 P(s) (s_j = |λ_{j+1} - λ_j|)
- 最近的邻间距方差 Var(s)/⟨s⟩²

若接近GUE预测: Var(s)/⟨s⟩² ≈ 0.18 (Wigner-Dyson统计)。若接近孤子气体预测: Var(s)/⟨s⟩² 偏离GUE值，反映碰撞核 1/|λ|² 的特征指数。**这个测量仅需现有的Fache数据**—不需要新的实验。

[第4层字数: >50 ✓]

**深挖2总结:** 有限N持续同调提供了有限N下"拓扑类型"的操作性定义 (barcode)，桥接了连续极限的DOS分类和可观测的离散谱点云。Barcode的动态演化 (barcode分岔) 比连续DOS分岔更贴近实验实际。有限N涨落本身是新的物理探针—可通过间距分布区分孤子气体统计与随机矩阵统计。

### 本轮框架的核心数学对象

**主方程: nGHD封闭方程 (4.1)**
$$\partial_t f + \nabla_\lambda \cdot [(\vec{v}_{\text{diss}} + \vec{v}_{\text{coll}}[f]) f] = \nabla_\lambda \cdot [\mathbb{D}[f] \nabla_\lambda f]$$

其中 v_coll[f] 由 (4.4) 给出 (二次非线性，∝ 1/|λ-λ'|² 核)，D[f] 由 (3.5)-(3.6) 给出 (依赖于局部DOS)。这是一个**确定的、封闭的、非线性的积分-微分方程**，不含自由拟合参数。

### 最弱环节

1. **碰撞核 H(λ, λ') 的显式形式:** 式 (2.3) 是从双孤子解Jost函数代入Kaup微扰公式得到的结果。计算涉及鞍点近似和围道积分——需要独立的数值IST验证。建议对N=2,3的精确解做数值IST来检验 (2.2) 的定量准确性。

2. **辐射扩散的统计独立假设:** D 的推导 (§3.2) 假设不同辐射脉冲产生的λ_j涨落是统计独立的。若辐射脉冲存在时间相关性 (在密集孤子气体中相邻碰撞的辐射可能重叠)，扩散系数会有 O(1) 的修正因子。

3. **有限N修正的定量化:** 1/√N 的系数 (§8) 需要从 (8.2) 的具体解中确定——当前仅给标度，未给前置因子。

## §附录B: 扩散系数的详细计算

从Langevin方程出发:
$$d\lambda_j = \vec{v}_j^{\text{det}} dt + \sigma_j d\vec{W}_t$$

辐射涨落来源于连续谱在离散谱上的投影。离散谱 → 连续谱的耦合矩阵元为:
$$M_{j}(\xi) = \int_{-\infty}^{\infty} \Psi_j^\dagger(x) \cdot \begin{pmatrix} 0 & -i\Phi_{\text{cont}}(x;\xi) \\ i\Phi_{\text{cont}}^*(x;\xi) & 0 \end{pmatrix} \cdot \Psi_j(x) \, dx$$

辐射场 r(ξ, t) 的演化: ∂_t r = 4iξ²r + ε Σ_j M_j(ξ) δ(x - x_j)。解得:
$$r(\xi, t) = r_0(\xi) e^{4i\xi^2 t} + \varepsilon \sum_j M_j(\xi) \int_0^t e^{4i\xi^2(t-s)} \delta(s - t_{\text{coll}}^{(j)}) ds$$

辐射场对 λ_j 的反作用通过 (1.5) 的积分中的 r(ξ, t) 项。在N→∞极限下，多个孤子的辐射叠加 → 中心极限定理 → 有效高斯噪声，其强度正比于:
$$\langle |\delta\lambda_j|^2 \rangle = \varepsilon^2 \int d\xi |M_j(\xi)|^2 S_r(\xi)$$

其中 S_r(ξ) = ⟨|r(ξ)|²⟩ 为辐射谱密度。在热力学极限下计算 S_r(ξ) 的显式形式，得到 (3.5)-(3.6)。
