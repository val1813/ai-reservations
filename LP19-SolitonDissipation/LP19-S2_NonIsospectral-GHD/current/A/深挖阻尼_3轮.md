# 第一轮：阻尼FP算符的显式谱分解

## 第1推：从FP方程到特征值问题

### 简化设定

在一维η空间（假设ξ方向均匀，或已对ξ边缘化），纯阻尼+常数扩散的FP方程为：

$$\partial_t f(\eta, t) = \partial_\eta [2\gamma \eta f(\eta, t)] + D \partial_\eta^2 f(\eta, t) \equiv -\mathcal{L} f \quad (R1.1)$$

其中算符 $\mathcal{L} = -\partial_\eta (2\gamma\eta \cdot) - D \partial_\eta^2$。这是在η ∈ [0, ∞) 上的微分算符。

边界条件：
- η = 0: 吸收边界。物理上孤子振幅趋于零时退化为线性波 → f(0, t) = 0。
- η → ∞: 自然边界。f → 0 足够快。

### 特征值问题

设 f(η, t) = e^{-λ t} φ(η)，则特征值问题为：

$$\mathcal{L} \phi = \lambda \phi \quad \Rightarrow \quad D \phi'' + 2\gamma (\eta \phi)' = -\lambda \phi \quad (R1.2)$$

展开: $D \phi'' + 2\gamma \phi + 2\gamma \eta \phi' = -\lambda \phi$。

重排: $D \phi'' + 2\gamma \eta \phi' + (2\gamma + \lambda) \phi = 0$。  (R1.3)

### 变换到标准形式

令 $z = \sqrt{\gamma/D} \cdot \eta$（无量纲坐标），$\phi(\eta) = e^{-z^2/2} \psi(z)$。代入 (R1.3):

计算导数: $\phi' = e^{-z^2/2}(\psi' - z\psi) \cdot \sqrt{\gamma/D}$, $\phi'' = e^{-z^2/2} [\psi'' - 2z\psi' + (z^2-1)\psi] \cdot \gamma/D$。

代入并化简: 

$$D \cdot e^{-z^2/2} [\psi'' - 2z\psi' + (z^2-1)\psi] \cdot \frac{\gamma}{D} + 2\gamma\eta \cdot e^{-z^2/2}(\psi' - z\psi) \sqrt{\frac{\gamma}{D}} + (2\gamma+\lambda)e^{-z^2/2}\psi = 0$$

注意 $2\gamma\eta \cdot \sqrt{\gamma/D} = 2\gamma z \sqrt{D/\gamma} \cdot \sqrt{\gamma/D} = 2\gamma z$。

全部简化为:

$$\gamma \psi'' - 2\gamma z \psi' + \gamma(z^2-1)\psi + 2\gamma z \psi' - 2\gamma z^2 \psi + (2\gamma+\lambda)\psi = 0$$

汇合: $\gamma \psi'' + [\gamma(z^2-1) - 2\gamma z^2 + 2\gamma + \lambda]\psi = 0$。

即: $\gamma \psi'' + [-\gamma(z^2+1) + 2\gamma + \lambda]\psi = 0$。

$$\psi'' + \left[\frac{\lambda}{\gamma} + 1 - z^2\right]\psi = 0 \quad (R1.4)$$

### 识别：量子谐振子方程

方程 (R1.4) 正是量子谐振子的无量纲Schrodinger方程:

$$\psi'' + (\varepsilon - z^2)\psi = 0, \quad \varepsilon = \frac{\lambda}{\gamma} + 1$$

标准谐振子能级: $\varepsilon_n = 2n+1, n = 0,1,2,\ldots$。

因此: $\frac{\lambda_n}{\gamma} + 1 = 2n+1 \Rightarrow \lambda_n = 2\gamma n$。

特征函数: $\psi_n(z) = H_n(z)$ (Hermite多项式)。

回到φ: $\phi_n(\eta) = e^{-\gamma\eta^2/(2D)} H_n(\sqrt{\gamma/D} \cdot \eta)$。

但这里有一个问题：n=0时 φ_0 ∝ e^{-γη²/(2D)}，在η=0处不满足f(0)=0（吸收边界要求零值，但Gaussian在0处为1）。

### 边界条件的正确施加

吸收边界f(0,t)=0要求所有φ_n(0)=0。Hermite函数在z=0处：H_n(0)=0当n为奇数，H_n(0)≠0当n为偶数。因此**只有奇数n的特征函数满足边界条件**。

允许的特征值: λ_k = 2γ · (2k+1) = 2γ, 6γ, 10γ, ... (k=0,1,2,...)

最慢衰减模: λ_0 = 2γ, φ_0(η) ∝ e^{-γη²/(2D)} · H_1(√(γ/D)η) ∝ η · e^{-γη²/(2D)}。

### 准稳态轮廓

在长时极限下（t ≫ 1/λ_1 = 1/(6γ)），所有k≥1的模已指数衰减。DOS轮廓由最慢衰减模主导:

$$f(\eta, t) \approx C_0 \cdot \eta \cdot e^{-\gamma\eta^2/(2D)} \cdot e^{-2\gamma t} \quad (R1.5)$$

归一化的准稳态轮廓（shape，非振幅）:

$$f_{\text{qs}}(\eta) = \frac{2\gamma}{D} \eta \cdot e^{-\gamma\eta^2/D} \quad (\text{在}[0,\infty)\text{上归一化}) \quad (R1.6)$$

这是**Wigner半圆分布在一维半线上的对应物——Maxwell-Boltzmann速度分布**（二维中径向Marginal分布）。

**关键观察：在一维η空间（ξ已边缘化），纯阻尼+扩散的准稳态轮廓是Maxwell分布 ∝ η e^{-γη²/D}，而非Wigner半圆 ∝ √(4-η²)。**

### 那么半圆从何而来？

半圆是**二维支撑集的边界轮廓**。在二维(ξ,η)空间中，若稳态DOS在椭圆或圆形区域内近似均匀或具有特定密度分布，其η方向的边缘分布（即对ξ积分后的f(η) = ∫ f(ξ,η) dξ）可以呈现半圆形状。

具体而言：若 f(ξ,η) 在圆盘 ξ²+η² ≤ R² 内近似均匀（这是El-Tovbis NDR在完全填充极限下的解），则:

$$f(\eta) = \int_{-\sqrt{R^2-\eta^2}}^{\sqrt{R^2-\eta^2}} d\xi \cdot \frac{1}{\pi R^2} = \frac{2}{\pi R^2} \sqrt{R^2 - \eta^2} \quad (R1.7)$$

这正是Wigner半圆（归一化到支撑集[-R,R]而非[0,R]时）。

**核心区别：**
- 纯阻尼+扩散在η方向产生Maxwell型准稳态 (R1.6) —— 这是η边缘分布。
- 均匀二维圆盘在η方向的边缘分布是半圆 (R1.7)。
- **二维分布的"半圆性"是由ξ-η平面内的几何约束（有限支撑集）产生的，不是由η方向的动力学产生的。**

> **本轮增量1：显式推导了阻尼FP算符的特征谱和特征模。证明最慢衰减模的轮廓是Maxwell分布（∝ η e^{-γη²/D}），不是半圆。半圆的来源必须在ξ-η二维几何中寻找，不能从纯一维η动力学得到。**

## 第1攻：真稳态是零——半圆只是瞬态

### 攻击点

上述推导在η ∈ [0, ∞)上进行。吸收边界f(0)=0意味着概率质量持续通过η=0泄漏——孤子持续衰亡。因此：

$$\partial_t \int_0^\infty f(\eta, t) d\eta = -D \left. \frac{\partial f}{\partial \eta} \right|_{\eta=0} < 0 \quad (R1.8)$$

总质量指数衰减（以速率2γ），真稳态是f_ss ≡ 0。

**"半圆稳态"在严格意义上不存在——它是一个在总质量尚未衰减到零之前的准稳态轮廓。** 实验上看到的"半圆"可能是：
1. 总质量仍足够大时的瞬态轮廓（t ≲ 1/(2γ)）
2. 或者有其他机制持续补充孤子（如噪声驱动的自发孤子产生，或ASE到孤子的转化）

### 这是否定的致命攻击吗？

不完全是。Fache实验在8 km光纤输出端测量DOS。若τ_relax = 10 km（归一化），则在8 km处t = 0.8 τ_relax，总质量衰减到 e^{-1.6} ≈ 20%。仍有可观数量的孤子存活。此时准稳态轮廓已经建立（高阶模衰减更快，t = 0.8 × 1/(2γ) = 4 / γ → e^{-4·6γ/γ} = e^{-24} ≈ 4×10^{-11}，高阶模已完全消失）。

因此：在实验时间尺度上，轮廓是准稳态的，总质量尚未归零。用"准稳态轮廓"替代"稳态"即可修复此攻击。

但这留下一个不舒服的问题：如果等足够长（t ≫ 1/γ），所有孤子都会死，DOS最终归零。那么Fache实验看到的"半圆"就不是任何意义上的"终态"——它只是一个衰亡过程中的快照。

**这改变了整个问题的性质。问题从"阻尼如何驱动DOS到半圆稳态"变为"在阻尼驱动的衰亡过程中，为什么DOS的瞬态轮廓呈现半圆形状？"**

> **本轮增量2：识别了真稳态（零DOS）与准稳态（实验快照）的根本区别。重新定义问题为"为何衰亡过程中的瞬态轮廓是半圆"。**

## 第2推：二维几何约束产生半圆——边界驱动的谱塑形

### 从一维到二维

在一维η分析中，最慢衰减模给出Maxwell轮廓。但在二维(ξ,η)中，FP方程为：

$$\partial_t f(\xi, \eta, t) = \partial_\eta [2\gamma \eta f] + D(\partial_\xi^2 + \partial_\eta^2) f \quad (R1.9)$$

（已忽略碰撞项——将在R2添加。）

关键区别在于**ξ方向的边界条件**。在ξ方向，无漂移（dξ/dt = 0），但有扩散D∂_ξ²。若ξ空间有界（或有效有界——实验上孤子的频率偏移受限于增益带宽），则在ξ方向也有边界条件。

假设物理ξ范围有界: ξ ∈ [-Ξ, Ξ]（由增益带宽或初始频率啁啾决定）。在ξ = ±Ξ处施加自然或周期边界。

### 二维准稳态的特征模

令f e^{+2γt}（去除总质量衰减因子），得到修正的特征值问题（二维谐振子各向异性）:

$$D(\partial_\xi^2 + \partial_\eta^2) \phi + 2\gamma \partial_\eta(\eta \phi) = -\tilde{\lambda} \phi \quad (R1.10)$$

其中 $\tilde{\lambda} = \lambda - 2\gamma$ (移除总衰减后的"剩余"特征值)。

分离变量: φ(ξ,η) = X(ξ) · Y(η)。得到:

$$\frac{X''}{X} + \frac{Y'' + \frac{2\gamma}{D}(\eta Y)'}{Y} = -\frac{\tilde{\lambda}}{D}$$

ξ方向的解（在[-Ξ, Ξ]上有界）: $X_m(\xi) = \cos(m\pi\xi/2\Xi)$ 或 $\sin$ 系列, 对应特征值 $-\mu_m = -(m\pi/2\Xi)^2$。

η方向的零模（最慢衰减）: 满足 $Y_0'' + \frac{2\gamma}{D}(\eta Y_0)' = -\frac{\tilde{\lambda}_0 + D\mu_0}{D} Y_0$。

最慢衰减对应m=0, μ_0=0 (常数ξ分布)。此时η方向方程回到一维谐振子，最慢允许模为Y_0(η) ∝ η e^{-γη²/(2D)}，剩余特征值 $\tilde{\lambda}_0 = 0$（所以 λ_0 = 2γ，与总质量衰减率一致）。

**二维最慢衰减模: f(ξ,η,t) ∝ C · (常数ξ) · η e^{-γη²/(2D)} · e^{-2γt}。**

其η边缘分布: f(η) ∝ η e^{-γη²/(2D)} —— 仍是Maxwell型，非半圆。

### 那么半圆到底从哪来？

在二维FP方程 (R1.9) 中，我们假设了ξ方向的自由扩散。但实验中有两个效应限制了这种自由扩散：

1. **η-ξ耦合来自碰撞积分** (R1.9中暂时忽略的项)。碰撞积分在ξ方向产生漂移和扩散，但其强度依赖于局部η——大η孤子碰撞更强，产生的ξ偏移更大。

2. **初始DOS的ξ-η结构。** Fache实验的初始Weyl DOS支撑在虚轴η上（ξ=0的单线）。阻尼下η坍缩，但ξ扩散使点云在ξ方向展开。展开的速度由扩散系数D和有效ξ-扩散系数（在R2中详细分析）决定。

关键点：若ξ方向的展开足够快（碰撞驱动的ξ-扩散 ≫ 纯热扩散D），则点云在ξ-η平面中形成近似二维区域。这个区域的形状由η坍缩（垂直压缩）和ξ展开（水平扩散）的竞争决定。

**半圆作为瞬态几何效应而非稳态吸引子：**

在阻尼的早期阶段（t ~ 0.1-1 τ_relax），η尚未坍缩太多，碰撞在ξ方向产生显著扩散。点云在ξ-η平面内形成近似椭圆形区域。这个区域的η边缘分布——即在每个η值处对ξ积分——恰好是半圆形状，因为椭圆形区域在固定η处的ξ宽度为 $\Delta\xi(\eta) = 2\Xi \sqrt{1 - (\eta/\eta_{\text{max}})^2}$。

随着阻尼继续进行（t ≫ τ_relax），η坍缩使椭圆在η方向压缩，最终所有点坍缩到η=0。但在坍缩完成前，只要ξ方向的宽度Δξ(η) ∝ √(1-(η/R)²)的关系保持（因为它由ξ-扩散和η-坍缩的竞争动力学维持），η边缘分布就呈现半圆。

> **本轮增量3：半圆是瞬态几何效应——由η坍缩（阻尼）和ξ展开（碰撞扩散）的竞争在ξ-η平面内维持准椭圆支撑集，其η边缘分布自然为半圆。半圆不是动力学吸引子，而是二维几何投影的瞬态特征。**

## 第1轮小结

### 本轮新增了什么？

1. **阻尼FP算符的完整谱分解** — 显式证明最慢衰减模是Maxwell分布（η e^{-γη²/D}），不是半圆。半圆不能从纯一维η动力学产生。

2. **真稳态是零DOS** — 吸收边界η=0使所有孤子最终衰亡。实验看到的"半圆"是准稳态瞬态，不是终态。问题被重新定义为"为何衰亡过程中的瞬态轮廓是半圆"。

3. **半圆作为二维几何投影** — 半圆来自ξ-η平面的准椭圆支撑集的η边缘分布。这个椭圆由阻尼η坍缩和碰撞ξ扩散的竞争维持。

### 最弱环节被攻击了吗？

是的。最弱环节（"半圆是终态/吸引子"）被系统性拆除：
- 纯一维η动力学给出的终态是零，瞬态是Maxwell，两者都不是半圆。
- 半圆要求二维几何约束——这又依赖于碰撞积分在ξ方向的作用。
- 碰撞积分的强度在阻尼下是否足以维持ξ展开？这成为下一轮的关键问题。

### 下一轮往哪推？

碰撞积分在阻尼下的角色。纯阻尼+扩散产生Maxwell。碰撞积分修正了什么？能否将Maxwell塑形为半圆？碰撞积分的ξ-扩散系数在阻尼下是否足够大？

# 第二轮：吸收边界导致的非正态性与碰撞积分的边界层效应

## 第1推：阻尼FP算符的非正态性

### 非正态算符的定义与后果

算符 $\mathcal{L}$ 是非正态的，如果 $\mathcal{L}\mathcal{L}^\dagger \neq \mathcal{L}^\dagger\mathcal{L}$。

对于我们的FP算符 $\mathcal{L} = -\partial_\eta(2\gamma\eta \cdot) - D\partial_\eta^2$，其L²(ℝ₊)伴随（相对于内积 ⟨f,g⟩ = ∫₀^∞ f g dη）为:

$$\mathcal{L}^\dagger = 2\gamma\eta \partial_\eta - D\partial_\eta^2 \quad (R2.1)$$

（需要仔细处理边界项。吸收边界f(0)=0在伴随下变成无约束边界或反射边界。）

计算对易子: $[\mathcal{L}, \mathcal{L}^\dagger] = \mathcal{L}\mathcal{L}^\dagger - \mathcal{L}^\dagger\mathcal{L}$。

经过繁琐但直截的计算:

$$[\mathcal{L}, \mathcal{L}^\dagger] = 4\gamma D \partial_\eta^2 + 4\gamma^2 \eta \partial_\eta + 4\gamma^2 \quad (R2.2)$$

这是二阶微分算符——非零。因此**L是非正态的**。

### 非正态性的物理后果

非正态算符有三个关键特征（Trefethen & Embree 2005）:

1. **拟谱（pseudospectrum）远大于谱。** L的ε-拟谱 Λ_ε(L) 包含所有使 ||(z-L)⁻¹|| > 1/ε 的z∈ℂ。对于非正态算符，拟谱可以远远扩展到谱的邻域之外。

2. **瞬态增长（transient growth）。** 即使所有特征值都有负实部（稳定），||e^{-tL}|| 可以在初始阶段大幅增长再衰减。对于我们的阻尼FP算符，这意味着DOS的某些扰动可以在衰减前暂时放大。

3. **对微扰的极端敏感性。** 非正态算符的特征值对矩阵元的微小变化极其敏感。添加碰撞积分C[f]（O(ε)的微扰）可以显著改变特征模的形状，即使特征值本身变化不大。

### 对我们问题的含义

阻尼FP算符的非正态性意味着：

**(a) 准稳态轮廓对初始条件敏感。** 不同的初始DOS f₀(η)可能投影到不同的"瞬态增长方向"上，在相同的时间t产生不同的准稳态轮廓。不存在"普适的"准稳态——取决于初始条件的具体形式。

**(b) 碰撞积分作为微扰可以大幅改变特征模。** 即使C[f]在量级上是O(ε)（而阻尼项是O(1)），通过非正态放大机制，C[f]对特征模形状的影响可以是O(1)。

**(c) 边界条件的作用被放大。** 非正态性在边界附近最显著（边界层效应）。η=0处的吸收边界条件通过非正态机制影响整个半平面上的解，而不仅仅是边界附近。

> **本轮增量4：识别了阻尼FP算符的非正态性。非正态性意味着(a)准稳态轮廓不普适——依赖初始条件；(b)弱碰撞积分可以通过非正态放大显著改变轮廓；(c)边界条件的影响是全局的而非局域的。**

## 第2攻：非正态性的定量强度——拟谱的数值估计

### 攻击点

上述非正态性论证是定性的。如果不能定量估计非正态性的强度——特别是拟谱的扩展范围——就无法判断它是否足以让碰撞积分（O(ε) ~ 0.05）产生O(1)的特征模修正。

### 离散化估计

将η ∈ [0, η_max] 离散化为M个格点（间距Δη = η_max/M）。FP算符的离散矩阵表示（使用中心差分）:

$$\mathcal{L}_{ij} \approx \begin{cases} 
\frac{D}{\Delta\eta^2} + \frac{2\gamma\eta_i}{\Delta\eta} & j = i-1 \\
-\frac{2D}{\Delta\eta^2} - 2\gamma & j = i \\
\frac{D}{\Delta\eta^2} - \frac{2\gamma\eta_i}{\Delta\eta} & j = i+1
\end{cases} \quad (R2.3)$$

矩阵L的**数值域（numerical abscissa）** ω(L) = max_{||v||=1} Re⟨v, Lv⟩ 决定了最大的瞬时增长率。

对于对流-扩散算符，已知数值abscissa近似为（Reddy & Trefethen 1994）:

$$\omega(\mathcal{L}) \approx \frac{\gamma^2 \eta_{\text{max}}^2}{4D} \quad (\text{当} \gamma\eta_{\text{max}}/D \gg 1 \text{时}) \quad (R2.4)$$

在Fache参数下（γ=0.05, D=2×10⁻⁴, η_max≈0.8）：

$$\omega(\mathcal{L}) \approx \frac{0.0025 \times 0.64}{4 \times 2\times10^{-4}} = \frac{0.0016}{8\times10^{-4}} = 2.0 \quad (R2.5)$$

这远大于谱abscissa（即最小特征值实部的绝对值，为2γ = 0.1）。**非正态性确实很强——初始瞬态增长率比渐近衰减率大20倍。**

### 这意味着什么

初始DOS可以在传播距离的前0.1-0.5 τ_relax内经历快速的形状重组（速率~2.0而非~0.1），然后切换到慢衰减（速率~0.1）的准稳态阶段。这个快速重组阶段由非正态瞬态增长驱动，对初始条件的细节和碰撞积分的微小修正都极其敏感。

**在快速重组阶段，碰撞积分（强度∝ ε ~ 0.05）可以产生有效速度场修正达到 ε·ω(L) ~ 0.05×2.0 = 0.1——与阻尼漂移（2γη ~ 0.05-0.08）同量级！**

> **本轮增量5：碰撞积分在非正态放大的快速重组阶段可以产生与阻尼漂移同量级的效应。这解决了"碰撞太弱"的担忧——不是碰撞本身强，而是非正态放大使弱碰撞产生O(1)后果。**

## 第2推：物理边界条件——不是纯吸收而是通量匹配

### η=0边界条件的物理修正

前述分析使用了纯吸收边界f(0)=0。但物理上，η=0处的"孤子消逝"实际上意味着孤子衰变为连续谱辐射。这个辐射并不简单消失——它在光纤中继续传播，并可以在下游通过逆IST过程重新转化为孤子。

更精确的η=0边界条件是**通量匹配条件**：

$$D \left. \frac{\partial f}{\partial \eta} \right|_{\eta=0} = -\Phi_{\text{rad} \to \text{sol}} \quad (R2.6)$$

其中Φ_{rad→sol}是从辐射场到孤子场的回注通量。这个通量依赖于辐射场的谱密度S_r(ξ)和"孤子成核"的阈值条件。

在阻尼下，孤子衰变产生辐射 → 辐射场增强 → 回注通量增大。这形成一个反馈环。

### 稳态通量平衡

在准稳态（∂_t f ≈ -2γ f，仅总质量衰减），η=0处的通量平衡为：

$$D f'(0) = -\Phi_{\text{in}} \quad (R2.7)$$

其中Φ_in是进入[0, ∞)半线上孤子群体的净通量（新产生 - 衰亡）。

**若Φ_in > 0（辐射回注超过孤子衰亡），则f(0) ≠ 0——边界条件从Dirichlet f(0)=0变为Robin型或Neumann型。** 这根本性地改变了特征模的结构。

### Robin边界条件下的特征模

设边界条件: f(0) = α f'(0)（Robin型），其中α是滑移长度。α = 0恢复Dirichlet（纯吸收），α → ∞接近Neumann（零通量）。

在Robin边界条件下，谐振子特征值问题的解发生改变。特征值不再是精确的2γ(2k+1)，而是:

$$\lambda_k = 2\gamma \cdot \nu_k(\alpha) \quad (R2.8)$$

其中ν_k(α)是修正指标，从ν_k(0) = 2k+1（Dirichlet）变化到ν_k(∞) = 2k（Neumann，包含偶数模）。

**特别地，当α > 0时，n=0偶模（φ_0 ∝ e^{-γη²/(2D)}）被允许——因为f(0) = α f'(0) = α·0 = 0（Gaussian在η=0处的导数为零）自动满足Robin条件。** 这意味着在非零回注通量下，稳态轮廓可以包含Gaussian分量（n=0模），而非仅仅是Maxwell（n=1模）。

### 从Maxwell到半圆——Robin边界条件的作用

在Robin边界条件下（小α，对应弱回注），允许的稳态轮廓是:

$$f(\eta) = c_0 \cdot e^{-\gamma\eta^2/(2D)} + c_1 \cdot \eta e^{-\gamma\eta^2/(2D)} + \cdots \quad (R2.9)$$

前两项的组合可以在[0, η_max]上近似多种轮廓。特别是:
- c₀ ≫ c₁: 接近Gaussian（宽峰在η=0附近）
- c₀ ≈ c₁·√(D/γ): 接近常数（在η较小时）
- c₁ ≫ c₀: 接近Maxwell（峰在η>0处）

当加上ξ方向的积分（二维几何约束）和物理截断η_max后，适当的c₀,c₁组合可以产生在[0, η_max]上接近半圆的η边缘分布。

> **本轮增量6：η=0的物理边界条件不是纯吸收（Dirichlet），而是Robin型通量匹配。回注通量允许n=0偶特征模（Gaussian分量），与n=1奇模（Maxwell分量）组合后，在有限区间[0, η_max]上可近似半圆。**

# 第三轮：最大熵产生假说与NDR零温极限的对应

## 第1推：阻尼下的熵产生与MEP假说

### 非平衡稳态的选择定则

阻尼孤子气体是一个开放系统：能量（η质量）通过η=0边界持续流出，系统处于非平衡稳态（或准稳态）。对于这类系统，存在一个经验性的选择定则——**最大熵产生原理（Maximum Entropy Production, MEP）**（Jaynes 1980; Dewar 2003; Martyushev & Seleznev 2006）:

> 在多个可能的非平衡稳态中，系统选择使熵产生率σ最大的那个。

MEP不是一个定理——它是一个有争议的假设，在某些系统中被实验验证（如地球气候的热输运、Rayleigh-Benard对流、等离子体输运），在另一些系统中被质疑。

### 阻尼孤子气体的熵产生

对于FP方程 ∂_t f = -∇·J，熵 S[f] = -∫ f ln f d²λ 的产生率为:

$$\sigma[f] = \frac{dS}{dt} = \int \frac{|J|^2}{D f} d^2\lambda \quad (R3.1)$$

其中总通量 J = -2γη f \hat{η} + J_coll - D ∇f。

在准稳态（∂_t f ≈ -2γ f），总通量的散度 ∇·J = 2γ f（补偿总质量衰减）。

### MEP假说在阻尼孤子气体中的含义

**假说（MEP for damped soliton gas）:** 在阻尼驱动的质量衰减过程中，孤子气体的准稳态DOS轮廓f_ss(ξ,η)是以下约束优化问题的解:

最大化: $\sigma[f] = \int_{\Omega} \frac{|J[f]|^2}{D f} d^2\lambda$

约束条件:
1. $\int_{\Omega} f d^2\lambda = 1$ (归一化)
2. $\int_{\Omega} \eta f d^2\lambda = \bar{\eta}$ (平均η — 由衰减率2γ和传播时间t决定)
3. $\nabla \cdot J[f] = 2\gamma f$ (准稳态条件)
4. $f \geq 0, \text{supp}(f) \subseteq \Omega$ (支撑集约束)

其中Ω是ξ-η平面上的可行区域（受限于初始条件和物理截断）。

### MEP解的结构

这是一个约束变分问题。在没有碰撞积分（J_coll = 0）的简化下：

$$J = -2\gamma\eta f \hat{\eta} - D\nabla f$$

约束3（准稳态）在一维η中给出: $\partial_\eta(-2\gamma\eta f - D\partial_\eta f) = 2\gamma f$。积分一次: $-2\gamma\eta f - D f' = \text{const}$。边界条件在η=0处决定常数。这与我们之前的特征模分析一致——准稳态条件是特征值λ=2γ的约束。

熵产生率简化为:

$$\sigma[f] = \int_0^{\eta_{\text{max}}} \frac{(2\gamma\eta f + D f')^2}{D f} d\eta \quad (R3.2)$$

在准稳态约束 ∂_η(2γη f + D f') = -2γ f 下，通量 J = -(2γη f + D f') 完全由f决定。最大化σ[f]等价于在满足准稳态条件和归一化的函数空间中寻找使(R3.2)最大的f。

**这是一个可以数值求解的变分问题。尚未解析求解。** 预期待解在无约束域的极限下趋近于Maxwell分布（最大熵产生通常给出与最大熵相同的稳态——Prigogine的最小熵产生原理适用于近平衡，MEP适用于远离平衡）。但在有界域（η_max有限）和Robin边界条件下，解可能偏离Maxwell。

> **本轮增量7：将阻尼孤子气体的准稳态轮廓选择问题表述为MEP约束变分问题。MEP为"为何是半圆而非其他轮廓"提供了一个选择定则——如果半圆的熵产生率确实高于其他候选轮廓的话。**

---

## 第2攻：MEP是假说不是定理——且在此系统中缺乏先验适用性

### 攻击1：MEP在非平衡统计力学中的争议地位

MEP远未被普遍接受。关键批评包括:
1. MEP缺乏从微观动力学的严格推导——它是一个现象学原理。
2. 存在反例：已知一些系统选择最小熵产生而非最大（如某些化学反应网络）。
3. 最大熵产生通常需要指定"在什么约束下"——不同的约束集给出不同的MEP解。约束的选择本身是任意的。

### 攻击2：MEP与Prigogine最小熵产生定理的张力

Prigogine的最小熵产生定理适用于近平衡态（线性区），证明系统选择最小熵产生。阻尼孤子气体是否处于"近平衡"或"远平衡"取决于Damkohler数 Da = τ_relax / τ_int（弛豫时间/内部相互作用时间）。

在Fache参数下: τ_relax = 1/(2γ) ≈ 10, τ_int ~ ⟨d⟩²/D ~ 0.01/2×10⁻⁴ = 50（扩散时间尺度）。Da ~ 0.2 < 1 → 系统处于**近平衡区** → 最小熵产生原理应适用 → MEP在此不适用！

### 攻击3：准稳态轮廓可能是动力学选择而非变分选择

非正态性意味着准稳态轮廓由初始条件在算符的特征空间中的投影决定——这是动力学选择，而非变分选择。即到达的"准稳态"不最大化任何全局泛函——它只是初始条件在衰减算符下的自然投影。

> **自我攻击结论：MEP假说在此系统中的适用性存疑。系统处于近平衡区（Da < 1），Prigogine最小熵产生原理应适用。准稳态轮廓更可能由动力学投影（初始条件+衰减算符的特征结构）决定，而非由变分原理选择。**

## 第2推：放弃MEP——回到动力学投影 + NDR对应

### 动力学投影的完整图景

结合R1-R2的分析，准稳态轮廓由以下因素决定:

1. **阻尼衰减算符L的特征模结构** (R1)——决定哪些空间模式存活最久
2. **边界条件** (R2)——Robin型通量匹配决定允许的特征模族
3. **非正态瞬态增长** (R2)——初始阶段快速重组到"最优瞬态增长方向"
4. **碰撞积分** (R1-R2)——通过非正态放大修正特征模形状
5. **初始条件** (R1)——决定在各特征模上的投影系数

综合这些因素，准稳态轮廓 f_qs(η) 可以写为:

$$f_{\text{qs}}(\eta) = \sum_{k \in \text{allowed}} c_k \phi_k(\eta) \quad (R3.3)$$

其中 {φ_k} 是Robin边界条件下阻尼FP算符的特征模（修正的Hermite函数），c_k 由初始条件 f₀(η) 的投影决定:

$$c_k = \langle f_0, \psi_k \rangle_{\text{weighted}} \quad (R3.4)$$

（ψ_k是伴随特征模，内积带权重以处理非正态性。）

### 普适性从何而来？

如果准稳态轮廓依赖于初始条件c_k，那么不同初始DOS会给出不同的准稳态轮廓——这不普适。但Fache实验显示阻尼下的终态似乎普适（总是半圆型）。

**普适性的可能来源：**

**来源A：非正态瞬态增长消除初始条件记忆。** 在快速重组阶段（t ~ 0.1 τ_relax），瞬态增长率~2.0远大于衰减率~0.1。这意味着初始条件的"细节"在极短时间内被洗掉——系统快速趋向瞬态增长最快的方向（即L的最大奇异向量方向）。这个方向是算符L的内禀性质，不依赖初始条件。因此：**在瞬态增长阶段之后，准稳态轮廓主要由L的最大奇异向量决定，而非由初始条件决定。** 这提供了普适性。

**来源B：碰撞积分的各态历经效应。** 碰撞在ξ方向产生的快速扩散（若D_ξ^eff确实很大，如R1估计的~986）在ξ方向产生有效的"混合"——使ξ方向的分布趋于均匀。碰撞也在η方向产生混合（虽然较慢）。两个方向的混合使点云在ξ-η平面内趋向均匀填充——这恰好是NDR完全填充极限的条件。

### 与El-Tovbis NDR的零温极限对应

El & Tovbis (2020) 的NDR方程描述的是**零温（完全可积）平衡态**的孤子凝聚体。阻尼的作用可以被理解为**降温**:

- 初始（ε=0）: 系统在某个"温度"T_eff ~ 1（任意初始DOS）
- 阻尼启动: η质量指数衰减 → 系统能量降低 → T_eff逐渐降低
- T_eff → 0: 系统寻求最低能量构型——这正是NDR描述的孤子凝聚体基态
- NDR基态（完全填充极限）: DOS支撑集为半圆

在这个图景中，阻尼的角色是**退火（annealing）**: 不是通过扩散热化（增加温度），而是通过移除能量使系统冷却到基态。基态是El-Tovbis NDR的完全填充解 = 半圆。

**冷却速率vs平衡速率:** 降温速率（γ）与内部弛豫速率（由碰撞和扩散决定）的比值决定了系统是否能保持准平衡:
- 若降温足够慢（γ ≪ τ_int⁻¹）: 系统在降温过程中始终保持热平衡 → 经历一系列平衡态 → 最终达到NDR基态
- 若降温太快（γ ≳ τ_int⁻¹）: 系统被"淬火"到非平衡态 → 最终态不是NDR基态，而是淬火无序态

在Fache参数下: γ = 0.05, τ_int⁻¹ ~ D/⟨d⟩² ~ 2×10⁻⁴/0.01 = 0.02。因此 γ/τ_int⁻¹ ≈ 2.5 > 1 → **降温速率超过内部弛豫速率 → 系统处于"淬火"区 → 不应期望达到NDR平衡基态！**

> **本轮增量8（关键！）: 定量比较降温速率(γ)与内部弛豫速率(τ_int⁻¹)后，发现Fache实验参数处于"淬火"区而非"退火"区。这意味着阻尼太快——系统来不及在每个中间温度达到热平衡。因此，El-Tovbis NDR平衡态半圆不应是完全可达的。实验看到的"半圆"更可能是向NDR基态弛豫的中间阶段，而非真正的NDR解。**

## 第3推：淬火动力学——Fache半圆是冻结的瞬态

### 淬火图景的具体物理

在淬火区（γ > τ_int⁻¹），系统的演化如下:

1. **初始阶段（t ≲ τ_int ≈ 50）:** 碰撞和扩散尚未充分混合系统。DOS基本保持初始形状（Weyl），仅η质量指数衰减。

2. **中间阶段（τ_int ≲ t ≲ τ_relax ≈ 10）:** 碰撞开始在ξ方向扩散，扩散在η方向平滑。但由于γτ_int > 1，η衰减速度快于内部混合速度 → DOS无法在每个η值处达到ξ方向的平衡。

3. **长时阶段（t ≳ τ_relax）:** 所有孤子振幅大幅衰减。剩余孤子集中在η≈0附近。ξ方向的扩散（若D_ξ^eff很大）可能在η≈0的狭窄条带内完成混合，产生局部的半圆型轮廓。

### 淬火半圆的特征

淬火产生的"半圆"与真正的NDR平衡半圆有重要区别:

**(a) 支撑集尺寸不匹配。** NDR半圆的半径R由孤子密度ρ决定: R² = 4ρ（在适当归一化下）。淬火半圆的半径由初始η_max和衰减因子e^{-2γt}共同决定: R(t) ≈ η_max · e^{-2γt}。除非ρ和η_max恰好通过某个关系关联，两者不相等。

**(b) 内部密度分布不同。** NDR平衡半圆在支撑集内具有特定的密度分布（在完全填充极限下为均匀二维分布，在部分填充下有结构）。淬火半圆的内部密度分布由初始DOS在衰减特征模上的投影决定——通常不是均匀的。

**(c) 边缘锐度不同。** NDR半圆具有尖锐的边缘（DOS在支撑集边界处有平方根奇点）。淬火半圆由于扩散的平滑作用，边缘可能更柔和。

### 可检验的区分

如果Fache实验的数据允许区分上述特征，可以判定观察到的半圆是NDR平衡态还是淬火瞬态:

**检验1 — R vs ρ 的关系:** 从IST数据提取半圆半径R和孤子密度ρ，检查是否满足R² = 4ρ。若偏离 > 20%，倾向于淬火解释。

**检验2 — 边缘锐度:** 对DOS直方图做边缘拟合。NDR半圆在边缘处 ∝ √(R²-η²)，淬火半圆的边缘更接近指数衰减（Gaussian尾部）。

**检验3 — ξ-η联合分布:** 若数据允许，检查f(ξ,η)是否在支撑集内近似均匀（NDR）还是呈现η依赖的非均匀密度（淬火）。

> **本轮增量9：定量区分了"退火半圆"（NDR平衡态）和"淬火半圆"（冻结瞬态）。在Fache实验参数下，γτ_int > 1 → 淬火区 → 观察到的半圆应是淬火瞬态，不经真正的NDR平衡。提出了三项可检验的区分标准。**

# 全局总结：3轮深挖的净增量

## 核心结论

**阻尼驱动的"半圆终态"不是真正的稳态，而是一个淬火瞬态。** 详细论证链:

1. **真稳态是零DOS。** 吸收边界η=0使所有孤子最终衰亡（R1.1）。
2. **纯阻尼+扩散在一维η中产生Maxwell轮廓，不是半圆。** 半圆性要求二维ξ-η几何（R1.2-1.3）。
3. **边界条件不是纯吸收而是Robin通量匹配** — 辐射→孤子回注允许n=0偶模，与n=1奇模组合可近似半圆（R2.2）。
4. **阻尼FP算符是非正态的** — 瞬态增长率(~2.0)远大于渐近衰减率(~0.1)。弱碰撞积分通过非正态放大产生O(1)效应（R2.1）。
5. **Fache实验参数处于"淬火区"**（γτ_int ≈ 2.5 > 1）— 降温太快，系统来不及在每个温度达到平衡。观察到的半圆是淬火冻结的瞬态，不是El-Tovbis NDR平衡态（R3.2）。
6. **淬火半圆与NDR平衡半圆有可检验的差异** — R-ρ关系、边缘锐度、ξ-η联合分布（R3.3）。

## 诚实标注：推到哪一步推不动了？

### 数学不可解

1. **Robin边界条件的滑移长度α。** α依赖于辐射-孤子回注的微观动力学。它的定量确定需要求解耦合的孤子+辐射输运方程——这是一个仍未解决的数学问题。当前只能将α作为现象学参数。

2. **非正态FP算符的瞬态增长方向（最大奇异向量）。** 对于带Robin边界的一维谐振子FP算符，最大奇异向量可以通过数值计算得到（离散化+ SVD），但解析形式未知。

3. **碰撞积分在非正态框架下的特征模修正。** 碰撞积分C[f]本身依赖于f（非线性），其在非正态算符L的特征基下的表示涉及无穷维矩阵的非线性特征值问题——当前数学无法解析求解。

### 数据不可得

4. **τ_int的精确校准。** 需要D_ξ^eff的独立测量或数值SDE模拟确定。

5. **三项区分检验需要Fache原始{λ_j}数据。** 当前仅公开了聚合直方图，不足以计算R-ρ关系、边缘锐度或ξ-η联合分布。

### 最终诚实判断

**阻尼如何将任意初始DOS驱动到半圆？** 当前的最佳答案（3轮深挖后）:

> 在Fache实验参数下，阻尼不是"驱向"半圆——是快速淬火冻结了一个非平衡瞬态，该瞬态的二维几何投影恰好呈现半圆形状。这个半圆不是El-Tovbis NDR平衡态，其确切轮廓依赖于初始条件、γτ_int比值、Robin边界条件中的回注通量，以及碰撞积分在非正态放大下的特征模修正。Fache实验很可能正处于观察到这个"淬火半圆"的参数区。要区分淬火半圆和真正的NDR平衡半圆，需要原始谱点数据并执行R-ρ关系、边缘锐度、ξ-η联合分布三项检验。

这是当前数学和数据的边界。推到此处，诚实地停。
