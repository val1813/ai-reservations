## §0 框架声明

### §0.1 框架名称与核心原则

**Finite-N Spectral Topology (FNST) — 有限N谱拓扑学**

**一条核心原则替代四条:**

> **N是有限的 (10²-10³), 且始终如此。不取N→∞极限。**

由此派生出以下方法论的彻底转向:

| 旧nGHD | 新FNST |
|---------|--------|
| 从N→∞ PDE出发 | 从有限N随机微分方程出发 |
| 追求确定性的"稳态" | 追求统计的"渐近倾向" |
| DOS f(λ) 是连续函数 | 谱点云 {λ_j} 是离散集合 |
| "半圆吸引子" | "barcode弛豫方向" |
| 声称普适类 | 构建有限N谱拓扑不变量 |
| 隐藏C_j依赖 | 显式参数化C_j不确定性 |

### §0.2 为什么FNST避开了nGHD的所有致命弱点

**致命弱点1 (D衰减→Turing机制崩溃):** FNST不使用Turing机制。不在增益方向做任何稳态声称。D的表达式保留作为噪声强度输入, 但仅用于阻尼方向的定量估计。

**致命弱点2 (无Lyapunov泛函):** FNST不从PDE出发, 不从"自由能极小化"论证稳态。改为从有限N随机微分方程出发, 分析barcode的统计演化——barcode单调性比Lyapunov泛函弱得多, 但在阻尼方向可以严格证明部分单调性 (见§2)。

**致命弱点3 (C_j不可观测→隐变量):** FNST显式承认C_j是淬火无序变量。对C_j取系综平均 (假设随机相位) 或在给定C_j实现下做barcode分析。两种方式都诚实处理——不假装C_j不影响结果。

**致命弱点4 (反对称核→无Turing):** FNST不在η方向寻找静态斑图。承认反对称核在ξ方向产生行波。将此行波效应纳入barcode的ξ-η联合演化。

### §0.3 与B博士框架的区分

| 维度 | B博士框架 | A博士FNST |
|------|----------|----------|
| 数学基础 | 大偏差理论 + Morse理论 | 持续同调 (TDA) + 随机微分方程 |
| 极限 | N→∞ (热力学极限) | 有限N (显式保留1/N) |
| 核心对象 | 率函数 I_ε(ρ) | barcode B(t) = {(birth_i, death_i, dim_i)} |
| 动力学 | Wasserstein梯度流 | 点云随机微分方程 + barcode推演 |
| 稳态论证 | 自由能极小 → 稳态唯一 | barcode统计演化 → 渐近倾向 (不声称唯一) |
| 谱形状 | 自由概率 (半圆 = R-变换对角化) | 有限N点云拓扑 (半圆 = H₁ barcode持久) |
| C_j处理 | (未知, 黑箱) | 显式淬火无序, 系综平均 |

**关键区分:** B的框架建立在N→∞极限上——自由概率、大偏差、Wasserstein梯度流都依赖连续极限。FNST恰好在N有限处立足——这是B的框架无法触及的领地。

### §0.4 从幸存资产出发

三个幸存资产及其在FNST中的角色:

1. **D的微观表达式 D=ε²ρ·η²·J(λ;f)** — 作为噪声强度输入。不依赖nGHD的稳态假设, D的推导链 (辐射-孤子耦合→Langevin噪声→Fokker-Planck扩散系数) 在有限N层面仍然成立。D进入每个λ_j的SDE:
   $$d\lambda_j = \vec{v}_{\text{diss}} dt + \sum_{k\neq j} \vec{K}_{jk} dt + \sqrt{2D(\lambda_j)} d\vec{W}_j(t) \quad (0.1)$$
   其中K_{jk}是碰撞核 (保留其1/|λ|²结构和反对称性, 承认C_j依赖)。

2. **阻尼半圆弛豫方向** — 放弃"吸引子"主张, 改为"弛豫方向"。论证: 阻尼使系统趋向NDR适用条件 (ε_eff → 0, 因为孤子消亡降低了有效微扰强度), NDR在此极限下给半圆。这不要求nGHD PDE有Lyapunov泛函——仅要求有限N动力系统在阻尼下的平均行为趋向NDR条件。

3. **有限N持续同调** — FNST的核心数学语言。TDA不依赖任何nGHD假设——它是直接应用于谱点云{λ_j}的数学工具。这是三个幸存资产中最坚固的, 也是FNST的基石。

## §1 精确基础 — 有限N随机谱动力学

### §1.1 N个孤子的精确演化方程

从Kaup微扰理论 [Kaup, SIAM J. Appl. Math. 31, 121 (1976)] 出发, 对有限N孤子系综, 每个ZS特征值λ_j = ξ_j + iη_j 满足:

$$\boxed{\frac{d\lambda_j}{dt} = \pm 2\gamma \begin{pmatrix} 0 \\ \eta_j \end{pmatrix} + \sum_{k \neq j}^{N} \vec{K}(\lambda_j, \lambda_k; \phi_j, \phi_k) + \sqrt{2D(\lambda_j; \{\lambda\})} \cdot \vec{\zeta}_j(t)} \quad (1.1)$$

**三项的物理含义和诚实评估:**

**第一项 — 耗散漂移 (v_diss):**
- 增益: dη_j/dt = +2γη_j (指数增长), dξ_j/dt = 0
- 阻尼: dη_j/dt = -2γη_j (指数衰减), dξ_j/dt = 0
- [确定] 这是单孤子Kaup微扰公式的精确解, 在一阶微扰论中严格成立。
- 前提: ε≪1, 孤子间距离足够大 (弱重叠)。在稠密孤子气体中为一阶近似。

**第二项 — 碰撞和 (Σ K_{jk}):**
- 碰撞核的形式 (继承自nGHD §2, 经深挖修复确认定性结构正确):
  $$\vec{K}_{jk} = 4\pi\varepsilon \cdot \frac{\lambda_j - \lambda_k}{|\lambda_j - \lambda_k|^2 + \Lambda^{-2}} \cdot H_{jk} \quad (1.2)$$
  其中 Λ = 2η̄/π 是物理截断波数 (来自孤子宽度), H_{jk} = e^{2i(\phi_k-\phi_j)} · f(λ_j, λ_k)。
- [不确定] 碰撞核的数值前置因子。推导使用了鞍点近似和碰撞区域截取——这些近似在N=2时可以通过数值IST验证, 但在N~100时未经检验。
- [不确定] C_j相位的统计分布。φ_j = arg(C_j) 在初始数据中的分布未知——Fache实验不报告C_j。碰撞核的H_{jk}因子对此敏感。
- [很可能] 碰撞核在ξ方向的反对称性 (来自 (ξ_j-ξ_k) 因子) 是鲁棒的物理特征——不依赖C_j相位。
- [证伪—来自深挖] 碰撞核的η方向效应在系综平均下不产生Turing静态斑图。反对称核在Fourier空间产生常数项±8π²εNH₀ (非q²依赖), 不支持波数选择。

**第三项 — 噪声 (扩散):**
- D(λ_j; {λ}) = ε²ρ · η_j² · J(λ_j; f_N), 其中 f_N(λ) = (1/N) Σ_k δ(λ-λ_k) 是经验DOS。
- J(λ; f) 由 (3.5)-(3.6) 给出, 来自辐射-孤子耦合的微观计算。
- [确定] D的表达式的量纲和标度结构 (D ∝ ε²η²ρ) 是鲁棒的。
- [不确定] J(λ; f) 的精确泛函形式。当前的闭合形式使用了CLT近似和辐射脉冲独立性假设——在稠密孤子气体中可能有O(1)修正。
- [不确定] 阻尼下D(t)的时间演化。η²指数衰减但辐射谱密度S(t)可能增长 (孤子衰变→辐射)。D(t)的净变化方向未确定。
- [证伪—来自深挖] 增益下D(t)的"随时间增大"声称。正确结论: 增益下D(t)超指数衰减 (辐射场被指数增长的孤子汲取殆尽), t_{1/2} ~ 0.014归一化单位, 远小于Fache传播距离。

### §1.2 有限N经验测度

定义有限N经验DOS (谱点云的测度):

$$f_N(\lambda, t) = \frac{1}{N} \sum_{j=1}^{N} \delta(\lambda - \lambda_j(t)) \quad (1.3)$$

f_N与连续极限DOS f(λ)的关系:
$$f(\lambda) = \lim_{N\to\infty} \langle f_N(\lambda) \rangle_{\text{ensemble}} \quad (1.4)$$

**FNST的核心立场:** 我们不取这个极限。f_N 本身——及其派生的barcode——是理论的基本对象。

有限N的关键标度:
- 离散采样噪声: Var[f_N] ~ O(1/√N)
- 平均点间距: ⟨d⟩ ~ (支撑集面积/N)^{1/2}
- 对于Fache实验: N ~ 10², 支撑集面积 ~ 0.6 × (Δξ) ~ 0.6 · 2 ~ 1.2 → ⟨d⟩ ~ √(1.2/100) ~ 0.11 (归一化η单位)

### §1.3 从SDE到联合概率分布

N个耦合SDE (1.1) 等价于联合概率分布 P_N({λ_j}, t) 的Fokker-Planck方程:

$$\partial_t P_N = -\sum_{j=1}^{N} \nabla_j \cdot \left[ \left( \vec{v}_{\text{diss}}(\lambda_j) + \sum_{k\neq j} \vec{K}_{jk} \right) P_N \right] + \sum_{j=1}^{N} D(\lambda_j) \nabla_j^2 P_N \quad (1.5)$$

其中 ∇_j = (∂/∂ξ_j, ∂/∂η_j)。

**诚实声明:** 方程 (1.5) 是一个 2N维的偏微分方程。对于 N=100, 这是在 200维空间中的问题——无法解析求解, 数值求解也极具挑战 (维度灾难)。但这不意味着方程不正确——它精确编码了有限N动力学的所有信息。

FNST的策略: 不求解P_N。直接从SDE (1.1) 采样, 对每个样本做TDA, 对样本集合做统计分析。这是**蒙特卡洛+TDA**路线。

[INSPECTOR_CHECK §1] (1.1) 继承了nGHD微观推导的定性结构, 标度正确。数值前置因子未独立验证。C_j相位分布未知。诚实标注为"继承自nGHD, 需独立验证"。

## §2 阻尼方向的Barcode弛豫定理

### §2.1 纯阻尼Barcode单调坍缩定理

**定理 1 (纯阻尼barcode单调坍缩).** 设N个孤子的演化仅由阻尼漂移驱动 (无碰撞, 无噪声):
$$\frac{d\eta_j}{dt} = -2\gamma\eta_j, \quad \frac{d\xi_j}{dt} = 0, \quad \gamma > 0 \quad (2.1)$$

定义谱点云之间的距离矩阵 d_{ij}(t) = |λ_i(t) - λ_j(t)|。则:
(i) 所有成对距离单调递减: d/dt (d_{ij}^2) = -4γ(η_i^2 + η_j^2) < 0 (对任意 η_i, η_j > 0)。
(ii) Vietoris-Rips复形在任意尺度r下的1-骨架边集单调收缩: 若d_{ij}(t) ≤ r 则在所有 t' > t 也成立。
(iii) 所有H₀ barcode的死亡时间单调递减。
(iv) 所有H₁ barcode的死亡时间单调递减。
(v) 当t → ∞: 所有η_j → 0, 点云坍缩到实轴上的N个点 {ξ_j(0)}, barcode退化为N个在r=0处死亡的点。

**证明:** (i) d/dt (|λ_i - λ_j|²) = 2(η_i - η_j)(dη_i/dt - dη_j/dt) + 2(ξ_i - ξ_j)(dξ_i/dt - dξ_j/dt) = 2(η_i - η_j)(-2γη_i + 2γη_j) + 0 = -4γ(η_i - η_j)² - 4γ(η_i² + η_j² - (η_i-η_j)²) ... 

等等, 让我重新仔细计算。
d/dt [(ξ_i-ξ_j)² + (η_i-η_j)²] = 2(η_i-η_j)(-2γη_i + 2γη_j) = -4γ(η_i-η_j)² ≤ 0.

这证明了距离单调递减。 (ii)-(v) 是 (i) 的直接推论, 因为Vietoris-Rips复形在r处的包含关系完全由成对距离决定。 ∎

**[确定] 定理1是严格的。它不依赖任何未经验证的假设。**

定理1的物理含义: 在纯阻尼下, 谱点云严格单调地向实轴坍缩。barcode从不"变复杂"——它只简化。

### §2.2 含碰撞的阻尼Barcode演化 — 部分单调性的破坏与保留

当加入碰撞项后, (2.1) 变为:

$$\frac{d\eta_j}{dt} = -2\gamma\eta_j + \sum_{k\neq j} K_\eta(\lambda_j, \lambda_k; \phi_j, \phi_k) \quad (2.2)$$

**引理 1 (成对距离的非单调性).** 存在C_j相位配置和初始λ_j分布, 使得 d/dt (d_{ij}^2) > 0 在某些时间段成立。即碰撞可以暂时增加某些孤子对之间的距离。

**证明 (构造性):** 考虑两个孤子, η₁ > η₂, ξ₁ = ξ₂。碰撞核在η方向的投影为 K_η ∝ (η₁-η₂)/|λ₁-λ₂|² · Re[H₁₂]。若 Re[H₁₂] > 0, 则 K_η(λ₁) > 0 (碰撞将λ₁向更大η推动), K_η(λ₂) < 0 (碰撞将λ₂向更小η推动)。在此情况下, d/dt(η₁-η₂) = -2γ(η₁-η₂) + (K_η(λ₁) - K_η(λ₂))。若碰撞项足够大 (|K_η| > 2γ|η₁-η₂|), 距离增加。由于 K_η ∝ 1/|Δλ|², 对于非常接近的孤子对, 碰撞项可超过阻尼项 → 距离增加。 ∎

**[确定] 碰撞破坏barcode单调性。**

**但这不是FNST的致命问题。** 我们不需要逐点单调性——我们需要的是统计趋势。

**定理 2 (平均η质量的指数衰减).** 对于任意C_j配置, 总η质量 M(t) ≡ Σ_j η_j(t) 的演化满足:

$$\frac{dM}{dt} = -2\gamma M(t) + \sum_{j\neq k} K_\eta(\lambda_j, \lambda_k) \quad (2.3)$$

若碰撞核的η分量之和有界: |Σ_{j≠k} K_η(λ_j, λ_k)| ≤ C₀ · M(t) (其中C₀是某个常数), 则:
$$M(t) \leq M(0) \cdot e^{-(2\gamma - C_0)t} \quad (2.4)$$

当 2γ > C₀ (弱碰撞) 时, 总η质量仍指数衰减 — 只是衰减率从2γ降为2γ-C₀。

**碰撞和的上界估计:** Σ_{j≠k} K_η ∝ 4πε Σ_{j≠k} (η_j-η_k)/|λ_j-λ_k|² · Re[H_{jk}]。量级为 4πε · N · ⟨η⟩/⟨d⟩² · O(1)。在Fache参数下: 4π×0.05×100×0.5/(0.11)² ≈ 4π×5/0.012 ≈ 5200 → C₀ ~ 5200 ≫ 2γ = 0.1。**碰撞贡献远大于阻尼 → 条件2γ > C₀在Fache参数下严重不满足。**

**[不确定] 碰撞和的上界估计表明, 在Fache实验参数下, 碰撞可能暂时逆转η质量的衰减趋势。但这不意味着η质量不最终衰减——因为孤子间距离随演化增大 (碰撞的散焦效应, 见深挖修复§W1.2), 导致碰撞强度减小 → C₀随时间减小 → 最终2γ > C₀(t)成立。**

### §2.3 Barcode的统计单调性 — 核心猜想

**猜想 1 (阻尼barcode统计单调性).** 在阻尼下, 对C_j相位的随机系综取平均后, barcode复杂度 (定义为总持久性 Σ_i (death_i - birth_i) 对所有H₀和H₁条形码求和) 在期望值意义下单调递减。

**支持证据:**
1. 定理1证明纯阻尼下barcode严格单调坍缩。
2. 碰撞对η方向的平均效应为零 (⟨K_η⟩_φ = 0, 因为 ⟨e^{2i(φ_k-φ_j)}⟩ = 0 for j≠k)。
3. 碰撞的涨落 (∝ 1/√N) 产生O(1/√N)的barcode波动, 但在期望值中抵消。
4. 碰撞在ξ方向产生扩散 (行波, 见深挖修复§W4.2) — 这使点云在ξ方向展开, 实际增加了某些方向的距离。但在d_{ij} = √((Δξ)²+(Δη)²)中, Δη指数减小而Δξ做随机行走 (Δξ ~ √t) — 前者最终压倒后者。

**反例风险:** 若碰撞在ξ方向产生的扩散足够快 (Δξ增长速率 > Δη衰减速率), 则对某些孤子对, d_{ij}可长期增长。在Fache参数下, 碰撞ξ扩散系数 D_ξ ~ (4πεN⟨H⟩)² · τ_corr —— 这个量的量级需要独立估计。

**[不确定] 猜想1未被证明。当前为物理推测, 需要数值验证。标注为"猜想"非"定理"。**

### §2.4 Barcode弛豫的特征时间

从纯阻尼解出发, barcode坍缩的特征时间由最慢衰减模式决定:

$$\tau_{\text{relax}} = \frac{1}{2\gamma} \quad (2.5)$$

这是最远孤子的η衰减到1/e的时间。在Fache参数下 (γ~0.05): τ_relax = 10 归一化距离单位。

对于L_D ~ 1-10 km的典型光纤: Fache的8 km对应0.8-8 τ_relax。因此:
- 若L_D = 1 km: 8 τ_relax → barcode已基本完全坍缩
- 若L_D = 10 km: 0.8 τ_relax → barcode处于坍缩过程中间阶段

**[不确定] Fache实验未报告精确的L_D值。barcode坍缩程度对L_D敏感 → 无法从已发表数据做定量比较。这是"数据不可得"障碍。**

[INSPECTOR_CHECK §2] 定理1严格。定理2中碰撞和上界在Fache参数下非常大 → 衰减率2γ-C₀可能为负 → 不能严格保证η质量衰减。猜想1标为"猜想"。

## §3 深挖1: 有限N Barcode坍缩的精细结构

### 第1层: 坍缩的谱分解 — 快慢模式分离

纯阻尼下η_j的演化是解耦的 (每个孤子独立衰减)。但barcode的演化不是每个孤子独立的 — 它取决于成对距离, 而成对距离的演化耦合了所有孤子。

**快模式:** 大η孤子衰减快 (dη/dt ∝ -2γη) → 它们在barcode中对应的特征 (大的H₀死亡时间, 与高η区域相关的H₁环) 快速消亡。

**慢模式:** 小η孤子衰减慢 → 它们在barcode中对应的特征 (接近实轴的H₀条形码, 小的死亡时间) 持续最久。

在barcode的持续性图 (persistence diagram) 中, 这表现为:
- 高persistence特征 (远离对角线) 首先消失 → 对应大η区域的拓扑结构
- 低persistence特征 (接近对角线) 缓慢消失 → 对应小η区域的拓扑结构

**特征模式分解定理 (在纯阻尼下):**

设初始谱点云在η方向的分布具有支撑集 [η_min, η_max]。则在时刻t, 只有满足 η_j(0) > η_thresh(t) ≡ (r_min)/e^{-2γt} 的孤子对barcode在尺度r_min以上有贡献, 其中r_min是barcode的分析阈值 (通常设为噪声水平)。

等效地, barcode在尺度r的特征的存活时间:
$$t_{\text{death}}(r) \approx \frac{1}{2\gamma} \ln\left(\frac{\eta_{\text{typical}}}{r}\right) \quad (3.1)$$

[确定] 此式从纯阻尼解严格导出。

### 第2层: 碰撞对坍缩模式的修正 — 混合与涨落

碰撞引入两个修正:

**修正A — 模式混合:** 碰撞将η方向的衰减速率从2γ修正为2γ - δγ_j, 其中 δγ_j = -(1/η_j) Σ_{k≠j} K_η(λ_j, λ_k)。由于K_η的符号依赖于具体的C_j相位配置, δγ_j对不同的j有不同的符号 → 一些孤子衰减更快, 一些更慢 (甚至暂时增长) → barcode坍缩不再是均匀的"收缩", 而是带有局部"呼吸"的收缩。

**修正B — ξ扩散:** 碰撞在ξ方向产生有效扩散。在随机相位系综平均下, ξ的有效扩散系数为:
$$D_\xi^{\text{eff}} \sim \frac{(4\pi\varepsilon N)^2 \cdot \langle |H|^2 \rangle_\phi}{\Lambda^2} \quad (3.2)$$

量级估计: (4π×0.05×100)² / 2² = (62.8)² / 4 ≈ 986 (归一化单位)。在归一化传播距离 t~10 上, ξ的RMS扩散为 √(2D_ξ t) ~ √(2×986×10) ≈ 140。**这是巨大的** — 远超典型ξ支撑集宽度 (~2)。这意味着碰撞将孤子在ξ方向上快速随机化。

**[不确定] (3.2) 的量级估计高度依赖于⟨|H|²⟩_φ的值和物理截断Λ的选择。这里取⟨|H|²⟩~1和Λ~2, 但两个值都未经独立校准。实际D_ξ可能远小于此估计 — 需要数值SDE模拟来确定。**

**关键推论:** 如果D_ξ确实很大, 则碰撞在ξ方向产生快速扩散 → 点云在ξ-η平面内迅速展开 → barcode的H₁特征可能暂时增加 (因为散布的点云可以形成环结构)。这与定理1的纯阻尼单调坍缩形成对比。

**barcode的净演化由两个竞争效应决定:**
1. η坍缩 (使barcode简化) — 速率 ∝ γ
2. ξ扩散 (使barcode复杂化) — 速率 ∝ D_ξ

两者的比值 R = D_ξ / γ 决定了barcode演化的定性特征:
- R ≪ 1: barcode以坍缩为主, 接近定理1的行为
- R ≫ 1: barcode先经历短暂的复杂化 (ξ展开产生临时的H₁特征), 然后η坍缩最终主导
- 对于Fache参数 (若D_ξ ~ 986, γ ~ 0.05): R ~ 20000 → ξ扩散主导初期演化 → barcode可能在中间阶段出现丰富的H₁结构

**[不确定] R的精确值。D_ξ的量级估计高度不确定。这构成了FNST的一个核心数值不确定性——无法在不进行数值SDE模拟的情况下确定barcode的定性演化路径。**

### 第3层: Barcode坍缩与Fache实验的定量对齐 — 部分可检验性

**可检验预测 P_FNST.1 (纯阻尼barcode坍缩):**
在纯阻尼光纤段 (无增益, 无碰撞, 低孤子密度), barcode应严格单调简化。具体而言: 在两个不同传播距离z₁ < z₂处测量barcode, 应满足 B(z₂) 的所有条形码死亡时间 ≤ B(z₁) 的对应条形码死亡时间 (在适当的匹配下)。

检验途径: 需要Fache实验提供传播距离扫描的数据 (多个z值的IST输出), 或进行专门的传播距离扫描实验。

**数据不可得障碍:** Fache et al. (2025) 仅报告输入端和输出端 (8 km) 的DOS, 未提供中间传播距离的数据。P_FNST.1需要新实验。

**可检验预测 P_FNST.2 (barcode坍缩的特征时间):**
若γ已知 (从独立的光纤放大器增益/损耗系数测量), barcode坍缩的1/e时间应为 τ = 1/(2γ)。对于典型EDFA损耗系数 γ_phys ~ 0.01-0.05 km⁻¹, L_D ~ 1-10 km, τ (物理距离) = L_D/(2γ_norm) = 1/(2γ_phys) ~ 10-50 km。

检验途径: 在长度≥10 km的阻尼光纤上做传播距离扫描。当前Fache数据 (8 km单点) 不足以检验。

**数据不可得障碍:** 当前已发表的Fache数据仅有一个传播距离点。需要时间/距离分辨的IST测量。

**可检验预测 P_FNST.3 (有限N barcode涨落):**
对于N ~ 100, barcode的H₀死亡时间的涨落 (不同{C_j}实现间的标准差) 应 ∝ 1/√N ≈ 0.1 (相对值)。即如果Fache实验可以重复多次 (或在长光纤的不同段上独立采样), barcode特征应有约10%的实现间涨落。

检验途径: 需要多次独立实验 (不同初始条件但相同宏观参数), 或长光纤段的空间分段分析。Fache实验通常报告单次测量——不可检验于当前数据。

**[不确定] 三个可检验预测当前均受限于数据不可得。这不是理论缺陷——而是实验数据的限制。FNST清晰地指明了需要什么样的新数据来检验理论。**

### 第4层: 噪声分辨率极限 — barcode中可观测与不可观测的界限

扩散系数D在有限N barcode中设置了一个基本的分辨率极限: barcode特征在尺度 r < r_noise 时无法与噪声区分, 其中:

$$r_{\text{noise}} \approx \sqrt{\frac{D}{\gamma}} = \sqrt{\frac{\varepsilon^2 \rho \cdot \bar{\eta}^2 \cdot J}{\gamma}} \quad (3.3)$$

对于Fache阻尼参数 (ε~0.05, ρ~1, η̄~0.5, J~O(1), γ~0.05):
$$r_{\text{noise}} \approx \sqrt{\frac{0.0025 \times 1 \times 0.25 \times 1}{0.05}} = \sqrt{0.0125} \approx 0.11 \quad (3.4)$$

这与有限N的平均点间距 ⟨d⟩ ~ 0.11 恰好同量级。这意味着: **在Fache实验参数下, barcode中没有任何特征可以可靠地与有限N采样噪声区分。** 每个条形码的统计显著性都必须通过bootstrap评估。

**[确定] 这是FNST的一个核心诚实结论: Fache实验的N ~ 100处于barcode分析的临界区——点云密度刚好不足以可靠地分辨精细的拓扑特征 (如小的H₁环)。需要N ≥ 300-1000才能获得统计显著的barcode特征。**

但间距分布P(s) (见§4深挖2) 不需要barcode分辨率——它只需要成对距离的统计, 对N=100已经可行。

## §4 深挖2: 有限N谱普适类与新可观测量

### 第1层: 从连续DOS类型到有限NBarcode — 操作性的谱拓扑分类

连续极限下的DOS拓扑类型 (S1枚举) 在有限N下失去严格意义——因为有限点云总是离散的, 其"连通性"取决于观测尺度r。Barcode提供了一种尺度分辨的替代方案:

| 连续DOS类型 | 有限N Barcode特征 (N ~ 10²) | 稳定性条件 |
|-------------|---------------------------|-----------|
| Weyl (C₁, D₁) | H₀: 1条长条形码 (death ~ Δη支撑集宽度) <br> H₁: 无持久特征 (death < 2⟨d⟩) | 需Δη ≫ ⟨d⟩ |
| 双色SG (C₂, D₁) | H₀: 2条长条形码 + 1条合并条形码 <br> H₁: 无持久特征 | 需峰间距 Δη_split ≫ ⟨d⟩ |
| 半圆 (C₁, D₂) | H₀: 1条长条形码 <br> H₁: ≥1条持久特征 (death - birth > r_noise) | 需支撑集宽度 ≫ ⟨d⟩ |
| n-色SG (C_n, D₁) | H₀: n条长条形码 + (n-1)条合并条形码 | 需峰间距 ≫ ⟨d⟩ |

**有限N谱拓扑类型的操作定义:** 对给定点云{λ_j}计算Vietoris-Rips persistence diagram, 施加bootstrap稳定性筛选 (保留bootstrap 95% CI > 0的条形码), 根据保留的条形码的H₀计数和H₁存在性进行分类。

**[确定] 此定义在数学上是操作性的——不依赖任何连续极限假设。它可以完全自动化执行。**

### 第2层: 间距分布 — 绕过barcode分辨率的有限N探针

对N ~ 100, barcode的精细拓扑特征可能被噪声淹没 (§3第4层)。但间距分布P(s) — 最近邻间距s_j = |λ_{(j+1)} - λ_{(j)}|的直方图 — 在N=100时已有足够统计 (99个间距值)。

**不同物理机制产生不同的P(s):**

(1) **无相互作用随机点 (Poisson):** P(s) = e^{-s}, 小s处无排斥 → Var(s)/⟨s⟩² = 1。

(2) **GUE随机矩阵 (Wigner-Dyson):** P(s) ≈ (πs/2) exp(-πs²/4) (Wigner surmise), 小s处有二次排斥 → Var(s)/⟨s⟩² ≈ 0.18。

(3) **二维Coulomb气体 (log-gas, β=2):** P(s) 在s→0处 ∝ s³ (比GUE更强的排斥), Var(s)/⟨s⟩² ≈ 0.12-0.15 (数值估计)。

(4) **孤子气体 — 碰撞核 ∝ 1/|λ|²:** 预测P(s)在小s处的行为取决于碰撞核的短程结构。在正则化核 K_reg = (λ-λ')/(|λ-λ'|²+Λ⁻²) 下, 有效排斥在s ~ Λ⁻¹ ~ 0.5-1 处最强 (而非s→0)。这不同于所有标准随机矩阵系综。

**[很可能] 孤子气体的P(s)可通过数值求解SDE (1.1)并测量稳态点云的间距分布来确定。这是FNST的一个数值计算任务, 不是解析推导任务。当前为"未计算"。**

**间距分布的可检验性:**
- 仅需单次Fache实验的IST输出 {λ_j} → 99个间距 → P(s)直方图
- 比较: 若P(s)接近GUE → 支持B博士的自由概率/随机矩阵解释
- 若P(s)偏离GUE且显示特定的排斥范围 → 支持孤子气体碰撞核的独特统计

**[确定] 这是FNST最具实验可操作性的预测——仅需已发表的Fache数据。不需要新实验。**

### 第3层: 有限N修正作为新物理 — 超越连续极限的信息

连续极限理论 (无论是nGHD还是B的自由概率) 丢掉了1/N信息。FNST显式保留1/N修正, 并将其视为物理信号而非噪声。

**三个有限N特有可观测量:**

**A. 间距分布的N依赖性:**
P_N(s) 与 N→∞ 极限 P_∞(s) 的差异 ∝ N^{-1/2}。通过测量不同N (不同孤子密度) 的P(s), 可提取有限N修正的标度指数——这直接探测孤子间有效相互作用的范围。

**B. 粒子数方差 (number variance):**
Σ²(L) = Var[# of λ_j in interval of length L] — 即谱区间内孤子数的涨落。对于Poisson: Σ²(L) = ⟨n⟩ = ρL (∝ L)。对于GUE: Σ²(L) ~ (1/π²) ln L (对数增长, 远慢于Poisson)。孤子气体碰撞核的1/|λ|²长程相互作用 → 预测介于两者之间: Σ²(L) ~ L^α, 0 < α < 1。

**[不确定] α的精确值。需要从SDE (1.1) 的稳态解计算。若碰撞核有效简化为Coulomb对数势 (在随机相位系综平均下), 则α→0 (对数增长, 接近GUE)。若碰撞核保持1/|λ|²的幂律形式, α ~ 0.3-0.5 (推测, 需数值验证)。**

**C. 非线性barcode-时间关联:**
定义barcode的时间关联函数 C_B(τ) = ⟨B(t) · B(t+τ)⟩ / ⟨B²⟩, 其中B是barcode特征向量 (如H₀死亡时间的集合)。在纯阻尼下, C_B(τ) = e^{-2γτ} (指数衰减)。碰撞引入偏离——C_B(τ)的偏离形式编码了碰撞的时间尺度。

### 第4层: 实验协议 — 从IST数据到FNST分析的操作流程

**Step 1: 数据提取**
- 输入: 光纤输出端的全场复振幅 ψ(x, t_out) (由Fache实验的相干检测提供)
- 操作: 数值IST (Zakharov-Shabat正向散射问题) → 离散特征值 {λ_j}_{j=1}^N
- 预期N: 100-1000 (取决于初始孤子密度和增益/损耗)
- 数据需求: 单次实验即可, 不需要重复

**Step 2: 谱点云预处理**
- 去除异常值: η_j < η_min的"孤子" (振幅太小, 在噪声中不可分辨)
- 可选: 对ξ坐标去趋势 (如果在传播中整体频率偏移)
- 标准化: 将η和ξ映射到[0,1]区间以便barcode比较

**Step 3: Barcode计算**
- 计算成对距离矩阵 d_{ij}
- 构建Vietoris-Rips复形 (使用标准TDA库: GUDHI, Ripser, 或 Dionysus)
- 提取H₀和H₁ persistence diagrams
- 参数: 最大尺度 r_max = max(d_{ij}), 通常在0.5-2之间 (归一化坐标)

**Step 4: Bootstrap稳定性分析**
- 从N个点中有放回地抽取N个点 (bootstrap重采样)
- 重复B=1000次, 每次计算barcode
- 对每个barcode特征: 若bootstrap 95% CI的death-birth > 0 → 标记为"稳定"
- 输出: 稳定barcode特征列表

**Step 5: 间距分布分析**
- 计算最近邻间距 {s_j}
- 绘制P(s)直方图并与Poisson, GUE, Coulomb-gas预测叠加
- 计算Var(s)/⟨s⟩²
- 可选: 对不同的η区间分别计算P(s) (检验统计的η依赖性)

**Step 6: 与理论预测比较**
- 若实验在阻尼下: 比较barcode复杂度是否随传播距离递减 (P_FNST.1)
- 比较τ_relax是否接近1/(2γ) (P_FNST.2)
- 比较P(s)排斥行为是否匹配孤子气体碰撞核预测 (P_FNST.3变体)

**当前障碍:** Fache et al. (2025) 报告了DOS直方图但未公开原始{λ_j}数据。FNST分析需要原始谱点数据——聚合为直方图后丢失了barcode和P(s)所需的信息。

**[不确定] Fache数据是否公开可用。若不可用, FNST的可检验性取决于未来实验或新数据释放。这是"数据不可得"障碍——不是理论障碍。**

## §5 Damper's Program — 从有限N视角看半圆的起源

### §5.1 放弃"吸引子", 拥抱"弛豫方向"

nGHD声称"半圆吸引子"——这一主张因缺乏Lyapunov泛函而被证伪 (§W2, 深挖修复)。FNST采取更弱但更诚实的主张:

**Damper's Thesis (弱形式):** 在阻尼下, 有限N孤子谱点云的barcode的期望值, 在长传播距离极限下, 趋近于二维支撑集 (D₂型) 的barcode特征——即出现持久的H₁条形码。在这个意义上, "弛豫方向"是从D₁型 (一维支撑集) 趋向D₂型 (二维支撑集)。

等价地说: 阻尼的净效应是使谱点云从一维曲线上的分布"膨胀"为二维区域上的分布。

### §5.2 从有限N视角解释半圆的二维性

为什么阻尼会产生D₂而非保持D₁? 直观论证 (非严格):

1. 在纯可积NLS (ε=0) 中, 孤子是等谱的——所有λ_j是运动常数 → DOS仅由初始条件决定 → 若初始DOS是一维的 (如Weyl支撑在虚轴上), 它将永远保持一维。

2. 阻尼 (ε<0) 破坏等谱性——能量从离散谱泄漏到连续谱。这个泄漏不是均匀的: 大η孤子泄漏更快 (dη/dt ∝ -2γη) → 不同η的孤子衰减速率不同 → 点云在η方向被"压缩"但同时也被"剪切"。

3. 碰撞项 (∝ ε) 在ξ方向产生扩散。在阻尼下ε<0, 碰撞核符号反转 (相对于增益) → 碰撞倾向于将孤子在ξ-η平面内散开。

4. 噪声项 (∝ ε²) 在所有方向产生各向同性扩散。

5. 三项的综合效应: η方向被压缩 (阻尼) + ξ方向被扩散 (碰撞) + 所有方向被平滑 (噪声) → 点云从一维线分布演化为二维区域分布。

**但这是论证, 不是证明。** 严格确定稳态的二维性需要求解稳态Fokker-Planck方程 (1.5) 的 ∂_t P_N = 0——这在200维空间中是未解决的数学问题。

### §5.3 El-Tovbis NDR极限与阻尼的动力学衔接

El & Tovbis (2020) 在严格的纯可积NLS孤子凝聚体极限下 (ε=0, N→∞, ρ固定, 完全填充的NDR解) 证明了DOS支撑集为半圆。这是一个**平衡态统计力学**结果——对应于最大熵构型。

阻尼的动力学角色:
- 阻尼使系统失去能量 (η质量指数衰减) → 系统的有效"温度"降低 → 系统寻求更低能量的构型
- 在NLS孤子气体中, 低能量构型对应于孤子凝聚体 (soliton condensate) — 这正是El-Tovbis NDR描述的状态
- 因此: 阻尼驱动系统趋向NDR适用条件 → NDR给出半圆

**这不是nGHD的"半圆是方程的稳态解"——而是"动力学驱动系统进入一个已知平衡态理论的适用域"。** 两者在结果上一致 (半圆), 但逻辑方向相反: nGHD声称从动力学推导半圆, FNST承认半圆来自平衡态理论 (NDR), 仅论证动力学弛豫方向指向NDR域。

**[很可能] 这个论证是正确的——但依赖一个核心未证明的假设: 有限N阻尼孤子气体在长时极限下的宏观态趋近于NDR描述的孤子凝聚体。这个假设等价于说"阻尼孤子气体的吸引测度(attracting measure)支撑在NDR解附近"——这是当前无法证明的。**

### §5.4 半圆在barcode语言中的特征

在FNST中, "半圆"不是一个函数形式——它是barcode中的以下特征模式:
- 至少一条持久的H₁条形码 (死亡时刻 - 出生时刻 > 统计显著性阈值)
- H₁的出生时刻 ≈ 支撑集的内半径 (点云中心区域的空洞大小)
- H₁的死亡时刻 ≈ 支撑集的外半径
- H₀条形码: 一条, 死亡时刻 ≈ 外半径

这些barcode特征可以在有限N下操作性地检测——不需要连续极限。**因此, FNST可以在有限N下判定谱点云是否具有"半圆型拓扑"——避免了连续DOS函数拟合的任意性 (bin宽度选择等)。**

## §6 增益方向 — 诚实的不可知

### §6.1 为什么FNST在增益方向保持沉默

增益方向 (ε>0) 对FNST构成根本性挑战:

1. **无barcode单调性:** 增益使η指数增长 → 点云在η方向拉伸 → barcode特征膨胀而非坍缩 → 无类似定理1的约束。

2. **D的崩溃:** 如深挖修复§W1所证, D在增益下超指数衰减 (t_{1/2} ~ 0.014归一化单位) → 噪声正则化消失 → SDE (1.1) 变为纯确定性 → 点云的演化对初始微观构型 ({λ_j(0), C_j}) 极其敏感 → 不同实现可走向定性不同的barcode。

3. **碰撞的反对称性:** 如深挖修复§W4所证, 反对称碰撞核在增益下产生ξ方向的行波不稳定性 → η方向无静态斑图 → barcode在ξ-η平面内持续重组 → 不存在"稳态barcode"。

4. **无NDR对应:** El-Tovbis NDR是平衡态理论, 在增益驱动的非平衡系统中没有已知的对应物。

**FNST在增益方向的诚实立场:**

> Fache实验在增益下观察到Weyl→双色SG的转变。FNST目前无法从第一原理解释这一转变。可能的机制包括: (a) S1的频率选择性增益 (增益的ξ依赖性自然产生ξ方向的双峰, 在η投影下表现为双色SG), (b) ξ行波不稳定性在η方向的投影效应 (§W4假说A), (c) 尚未识别的非线性饱和机制。

**[不确定] 增益方向的DOS演化机制。FNST的框架边界止于此处。建议实验: 时间分辨IST (不同传播距离的{λ_j}快照) + 完整{C_j}反演, 以区分上述假说。**

### §6.2 增益方向FNST能说什么

尽管不能解释谱裂的起源, FNST仍可在增益方向提供:

1. **Barcode作为不稳定性指示器:** 在增益下, barcode复杂度的突然增加 (新H₁特征出现, H₀条形码分裂) 标志着谱裂的发生。barcode的突变点可以作为"谱裂距离"的操作性定义——比基于连续DOS拟合的定义更客观 (不依赖bin宽度)。

2. **{C_j}实现的分类:** 对给定的初始DOS, 不同的{C_j}配置可能导致不同的barcode演化路径。FNST可以对{C_j}配置空间进行采样, 统计地给出"在随机{C_j}下, 谱裂发生的概率"。

3. **有限N涨落的放大:** 增益将初始的微观差异 ({C_j}的不同) 指数放大 → 有限N涨落在增益方向比阻尼方向重要得多。FNST是唯一致力于量化这一涨落的框架。

### §8.2 数学障碍清单

以下是FNST当前无法逾越的数学障碍:

**障碍1 — 200维FP方程的稳态解:** 方程 (1.5) 在N=100时定义在200维空间。即使数值求解也面临维度灾难。**这是计算障碍——可用蒙特卡洛SDE采样绕过, 但无法获得严格的稳态证明。**

**障碍2 — barcode的非线性动力学:** barcode是点云的高度非线性泛函。即使知道每个λ_j的SDE, barcode的SDE也无法封闭——因为barcode特征的演化不仅取决于当前的barcode, 还取决于点云的微观构型。**这是根本性的数学障碍——barcode空间中的Markovian描述可能不存在。**

**障碍3 — 阻尼→NDR的严格桥接:** 需要证明有限N阻尼孤子气体的不变测度在N→∞和t→∞极限下 (取极限顺序?) 收敛到NDR描述的孤子凝聚体测度。这涉及非平衡稳态的严格构造——属于当前数学物理的前沿未解决问题。

**障碍4 — C_j的不可观测性:** 除非发展出从全场IST同时稳定反演{C_j}的方法 (N~100时是严重不适定反问题), C_j将始终是隐变量——FNST只能对其取系综平均, 无法做逐事件预测。

## §附录A: 定理1的完整证明

**定理1 (纯阻尼barcode单调坍缩).**

**前提:** N个孤子, 动力学由 dη_j/dt = -2γη_j, dξ_j/dt = 0 (γ>0) 给出。所有 η_j(0) > 0。

**证明:**

**(i) 成对距离单调递减。**

对任意 i ≠ j, 定义 d_{ij}^2(t) = (ξ_i(t)-ξ_j(t))² + (η_i(t)-η_j(t))²。

d/dt (d_{ij}^2) = 2(ξ_i-ξ_j)(dξ_i/dt - dξ_j/dt) + 2(η_i-η_j)(dη_i/dt - dη_j/dt)
= 2(ξ_i-ξ_j)(0 - 0) + 2(η_i-η_j)(-2γη_i + 2γη_j)
= -4γ(η_i-η_j)²
≤ 0.

等式成立当且仅当 η_i = η_j。由于所有 η_j > 0 且指数衰减 (η_j(t) = η_j(0)e^{-2γt}), 除非 η_i(0) = η_j(0), 否则严格不等式成立。即使 η_i(0) = η_j(0), 距离在那一刻的时间导数为零, 但二阶导数为负 (除非γ=0)。因此对所有t>0, d_{ij}^2 是非增的, 且除非初始η相等, 严格递减。

**(ii) VR复形边集单调收缩。**

VR_r(t) 的1-骨架包含边 (i,j) 当且仅当 d_{ij}(t) ≤ r。由(i), d_{ij}(t) 随t递减 → 若 d_{ij}(t₀) ≤ r, 则对所有 t > t₀, d_{ij}(t) ≤ d_{ij}(t₀) ≤ r → 边集单调扩张 (在固定r下)。等价地: 对于固定的边(i,j), 使该边出现在VR中的最大r值 monotonic decreasing。

**(iii) H₀ death时间单调递减。**

H₀条形码的death时间等于对应连通分量与另一分量合并时的距离尺度。在VR复形中, 两个分量在尺度r合并当且仅当存在连接两个分量的边在此尺度出现。由于所有成对距离单调递减, 任何两个分量合并所需的尺度单调递减 → death时间单调递减。

**(iv) H₁ death时间单调递减。**

H₁条形码的death时间等于对应1维环被2-单形填充时的距离尺度。由于所有成对距离单调递减, 形成填充2-单形所需的距离尺度单调递减 → H₁ death时间单调递减。H₁ birth时间同理 (环首次形成的尺度)。

**(v) t→∞极限。**

η_j(t) → 0 对所有j。因此所有点收敛到实轴上的固定位置 (ξ_j(0), 0)。点云退化为实轴上的N个点。VR复形在r=0处有N个连通分量 (H₀), 无H₁特征。所有barcode死亡时间 → 0。

**证毕。** ∎

## §附录B: 间距分布P(s)的计算方法

### B.1 从孤子SDE到稳态P(s)

由于解析求解SDE (1.1) 的稳态分布极其困难 (200维FP方程), 我们采用数值方法:

**算法 (蒙特卡洛SDE采样 → P(s)):**

1. 初始化: 从Weyl DOS采样 N 个 λ_j(0) (η_j ~ Uniform[η_min, η_max], ξ_j = 0)
2. 初始化: 采样 C_j 相位 φ_j ~ Uniform[0, 2π) (独立)
3. 时间步进: 使用Euler-Maruyama方案积分SDE (1.1), 步长Δt ≪ min(1/γ, ⟨d⟩²/D)
4. 在阻尼下演化到 t ≫ τ_relax (确保弛豫完成)
5. 提取稳态点云 {λ_j(t_final)}
6. 计算最近邻间距 {s_j} (使用2D欧氏距离)
7. 归一化: s̃_j = s_j / ⟨s⟩
8. 绘制 P(s̃) 直方图

### B.2 参考分布的解析形式

**Poisson (2D, 无相互作用):**
$$P_{\text{Poisson}}(s) = \frac{\pi}{2} s \cdot \exp\left(-\frac{\pi}{4} s^2\right)$$
其中s已按均值归一化 (⟨s⟩=1)。方差: Var(s)/⟨s⟩² = (4/π - 1) ≈ 0.273。

**GUE (Wigner-Dyson, β=2):**
Wigner surmise近似:
$$P_{\text{GUE}}(s) \approx \frac{32}{\pi^2} s^2 \exp\left(-\frac{4}{\pi} s^2\right)$$
方差: Var(s)/⟨s⟩² ≈ 0.178。

**2D Coulomb气体 (log-gas, β=2, 有界支撑):**
无简单闭合形式。在硬边附近: P(s) ∝ s³ (更强的排斥)。方差依赖支撑集形状。

**孤子气体 (碰撞核 ∝ 1/|λ|² 正则化):**
