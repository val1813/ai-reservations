# Phase 1 — B博士攻击报告：非可分离势最坏情形

---

⚡ **本Phase推进了什么** ⚡

本报告对非可分离势 `V(x,y)=V₀cos(2π(β_x·x+β_y·y))` 实施3条攻击链，逐条检验LP1-补9的"数论保护"(L_max < ∞)是否能推广到此情形。总体结论：**数论保护在非可分离势中显著弱化，在最坏情形下完全崩溃**。关键原因是：非可分离势的WPL条件（一个线性方程）比可分离势的条件（两个方程同时满足）本质上更容易满足。物理上合理的β值仅能提供多项式保护（L_max更大但有限），而Liouville β可制造任意长的WPL，完全摧毁保护。

⚡ **最关键的跨域连接** ⚡

**数论的逼近理论与凝聚态物理的WPL之间建立刚性桥梁**：WPL宽度由`‖β_x·x+β_y·y - 1/4‖`的逼近速率控制，这正好是数论中线性形式的非齐次Diophantine逼近问题。**跨域核心发现**：WPL的长度界限完全由β_x/β_y的Diophantine类型决定，而不是β_x和β_y各自的类型。

⚡ **预测 vs 实际** ⚡

- **预测**：β_x=β_y=黄金比例时，非可分离势的WPL可能产生无限长延展通道
- **实际**：物理β下WPL长度有限（但比可分离情形大），只有Liouville β才产生无限通道
- **预测**：Štrkalj给出了WPL精确长度上界可拿来直接比较
- **实际**：Štrkalj未给出严格解析界，仅做了数值演示；他研究的势也与LP1真正非可分离情形不同

## 攻击1：构造最坏情形——Liouville β对

### 1.1 攻击思路

对于非可分离势 `V(x,y) = V₀ cos(2π(β_x·x + β_y·y))`，势能为零的条件为：

```
cos(2π(β_x·x + β_y·y)) ≈ 0
⟺ β_x·x + β_y·y ≈ (2n+1)/4 mod 1
```

**核心便宜**：这是一个方程，只需一个条件。与可分离势 `V₀[cos(2πβ_x·x) + cos(2πβ_y·y)]` 需要 `cos(2πβ_x·x)≈0 AND cos(2πβ_y·y)≈0` 两个同时条件不同。

攻击策略：选择 β 使得逼近误差 `‖β·S - 1/4‖` （其中 S = x+y）极其迅速地趋于零，从而制造任意长的WPL。

### 1.2 Liouville数构造

**定义**：β 是 Liouville 数 ⇔ 对任意 n，存在整数 p,q 使得
```
|β - p/q| < q^{-n}
```
标准例子：Liouville常数 `L = Σ 10^{-k!} = 0.110001...`

**对WPL的影响**（设 β_x = β_y = L）：

WPL条件：`L·(x+y) ≈ 1/4 mod 1`。令 S = x+y，逼近误差为：

| 距离S | Liouville逼近 | 有效势幅 | 物理意义 |
|--------|--------------|---------|---------|
| S₀ ~ 10 | `|L·S₀ - 1/4| ~ 10^{-1}` | `~V₀·10^{-1}` | 弱调制 |
| S₁ ~ 10² | `|L·S₁ - 1/4| ~ 10^{-4}` | `~V₀·10^{-4}` | 极弱 |
| Sₙ ~ 10^{n-1} | `|L·Sₙ - 1/4| ~ 10^{-(n-1)!}` | `~V₀·10^{-(n-1)!}` | 超指数衰减 |

**WPL宽度**：垂直于WPL方向的宽度 ≈ `V₀·|L·S - 1/4|/√(2L²) = O(|L·S - 1/4|/L)`。

对于 Liouville L，在距离 S 处，WPL宽度 `~ V₀·S^{-n}`（对任意 n 成立）。这意味着在任何有限距离内，WPL宽度可以制成 < ξ_perc。

**重要**：WPL本身是一条无限的斜线（方向=(1,-1)）。所有在斜线附近的格点都有低势能。因此WPL为无限长，且其"宽度"（垂直于线的有效势降）随距离超多项式衰减。

### 1.3 物理的β vs 最坏情形的β

| β类型 | 例子 | 逼近指数 μ | WPL宽度衰减 | L_max |
|-------|------|-----------|------------|-------|
| 二次无理数 | φ=(1+√5)/2, 1/√2 | μ=2 | `~1/‖(x,y)‖` | 有限(~1/ε) |
| 代数无理数 | φ/√2 (度4) | μ=2 | `~1/‖(x,y)‖^{1+δ}` | 有限(~1/ε^{1/(1+δ)}) |
| Liouville数 | Σ10^{-k!} | μ=∞ | `~1/‖(x,y)‖^n` 任意n | **无限** |

**反驳检验**：
- 反对："β在实验中通常是黄金比例等二次无理数，Liouville数不物理"
- 反击：该攻击并非要求实验必须使用Liouville β，而是证明"数论保护"（L_max < ∞）的证明依赖于β的Diophantine类型。如果β是Liouville数，证明失效。论文必须标注此限制。
- 更深层反击：大多数数论保护证明（如LP1-补9）只要求β是Diophantine数（即μ<∞）。但Liouville数并非Diophantine，证明不覆盖此情形。虽然实验中不用Liouville β，但定理的表述中必须注明此前提条件。

### 1.4 攻击1结论

```
评分：7/10（严格数学上有效，但需标注物理相关性前提）

成功机制：选择 β_x=β_y=L（Liouville常数）→ WPL条件 L·(x+y)≈1/4 
→ ‖L·S-1/4‖ < S^{-n} 对任意 n → WPL宽度超多项式衰减
→ L_max = ∞（数论保护完全失效）

限制：实验中不实际使用Liouville β → 攻击是"数学可能性"而非"物理威胁"
      但定理必须注明此限制条件
```

## 攻击2：联合Diophantine逼近 vs 独立逼近

### 2.1 攻击思路

即使 β_x 和 β_y 各自都是 badly approximable（即 ‖kβ_x‖ > c₁/k, ‖kβ_y‖ > c₂/k），它们的联合形式 `β_x·x + β_y·y` 的逼近质量可能更差吗？

### 2.2 线性形式的Diophantine逼近理论

**Schmidt定理（定理框架）**：线性形式 `L(x,y) = β_x·x + β_y·y` 在整数点逼近的性质由 β_x/β_y 的Diophantine类型决定。

**核心关系**：
```
‖β_x·x + β_y·y‖ 的逼近精度 ⇔ 比率 r = β_x/β_y 的逼近质量
```

**具体对应**：

| r的类型 | ‖β_x·x+β_y·y‖ 的下界 | 例子 |
|--------|----------------------|------|
| badly approximable (有界连分数系数) | `≥ c/‖(x,y)‖` | r=φ |
| 代数无理数 (Roth定理) | `≥ c/‖(x,y)‖^{1+ε}` | r=φ/√2 |
| Liouville | 任意多项式衰减 | r=L |

### 2.3 关键洞察：独立b.a.不保证联合b.a.

**最坏情形构造**：选择 `β_x=φ（黄金比例，b.a.），β_y=√2（b.a.）`，则：

- `‖kβ_x‖ ≥ c₁/k` ✓ （β_x个人逼近良好）
- `‖kβ_y‖ ≥ c₂/k` ✓ （β_y个人逼近良好）
- `r=φ/√2` 是4次代数数，Roth定理给出：对任意 ε>0, `‖r·x + y···` ... 

更准确地说，对于线性形式 `‖β_x·x + β_y·y‖`：

由Schmidt丢番图逼近理论（Schmidt subspace theorem及相关结果），如果 r = β_x/β_y 是2次无理数（即b.a.），则：
```
‖β_x·x + β_y·y‖ ≥ c/‖(x,y)‖
```
如果 r 是代数无理数（次数 ≥ 3），则Roth定理给出（对任意 ε>0）：
```
‖β_x·x + β_y·y‖ ≥ c(ε)/‖(x,y)‖^{1+ε}
```

对于WPL宽度 W 沿方向 (β_y, -β_x) 传播距离 L 后：
```
W(L) = min_{‖(x,y)‖~L, β_x·x+β_y·y≈1/4} |cos(2π(β_x·x+β_y·y))|
     ~ V₀ · min_{‖(x,y)‖~L} ‖β_x·x+β_y·y - 1/4‖
```

### 2.4 Littlewood猜想与本问题的区别

Littlewood猜想：
```
liminf_{q→∞} q·‖qα‖·‖qβ‖ = 0   对任意α,β
```
Einsiedler-Katok-Lindenstrauss (2006) 证明例外集Hausdorff维数0。

**关键区别**：
- **Littlewood**：‖qα‖ 和 ‖qβ‖ 同时小（$q \|q\alpha\| \cdot \|q\beta\|$）
- **本问题**：线性形式 ‖β_x·x+β_y·y‖ 单个数小

Littlewood猜想对WPL的影响是**间接的**：它没有直接告诉我们线性形式的逼近质量。但EKL的结果暗示，对于"几乎所有"β对，联合逼近不比独立逼逼近更好（即不会更差）。

### 2.5 攻击2结论

```
评分：5/10（揭示了结构差异，但数论基础不足以构造彻底突破）

成功机制：揭示非可分离势只需1个条件（vs 可分离势需2个条件）→ 
        本质优势。联合逼近不比独立逼近更差（Littlewood/EKL），
        但条件数减少本身就是巨大优势。

限制：对于代数无理数β，线性形式的逼近指数最多是2+ε，
     WPL宽度仍然是多项式衰减。多项式衰减意味着L_max有限
     （但可能比可分离情形大一个常数因子）。

硬发现：物理β（二次无理数）下非可分离WPL宽度 ~ c/|x|
        vs 可分离WPL在同样的x距离以外的宽度 ~ c₁c₂/|x|² 
        → 非可分离情形的L_max大约是可分离的(c/ε)倍
```

## 攻击3：Štrkalj文献精确结论

### 3.1 文献定位

经过搜索确认，原始任务中提到的"Štrkalj et al. (2022)"很可能指：

**"Coexistence of localization and transport in many-body two-dimensional Aubry-André models"**
- Authors: Antonio Štrkalj, Elmer V. H. Doggen, Claudio Castelnovo
- Phys. Rev. B **106**, 184209 (2022)
- arXiv: [2204.05198](https://arxiv.org/abs/2204.05198)

另有关联论文：Johnstone, Öhberg & Duncan, "Barriers to Macroscopic Superfluidity and Insulation in a 2D Aubry-André Model", J. Phys. B **55**, 125302 (2022)。

### 3.2 Štrkalj模型的严格定义

Štrkalj定义了两个模型：

**Separable (S) 模型**：
```
U^S(x,y) = W[cos(2πβx) + cos(2πβy)]
```
- 可分解为 x 和 y 独立势之和
- WPL出现在对角线方向（cos(2πβx)≈0 与 cos(2πβy)≈0 同时满足的非平凡解）

**Nonseparable (NS) 模型**：
```
U^NS(x,y) = 2W cos(2πβx) cos(2πβy) 
          = W[cos(2πβ(x+y)) + cos(2πβ(x-y))]
```
- 因子化为两个独立余弦的积
- 在旋转坐标(x+y, x-y)下实际**可分离**
- **不是**LP1的真正非可分离形式 `V₀cos(2π(β_x·x+β_y·y))`
- WPL出现在水平/垂直方向（cos(2πβx)≈0 或 cos(2πβy)≈0）
- 使用 β = 2/(1+√5) ≈ 0.618（黄金比例的倒数）

**LP1真正非可分离势**（本研究目标）：
```
V(x,y) = V₀ · cos(2π(β_x·x + β_y·y))
```
- 不能在任意坐标下因子化
- WPL为斜线
- 未被Štrkalj研究

### 3.3 Štrkalj论文的核心WPL结论

从搜索中提取的精确引述：

> **"In the thermodynamic limit, it is always possible to find WPLs with arbitrarily small values of the potential even when W is extremely large."**

此结论的重要性：

1. **不存在显式边界** — Štrkalj未给出WPL长度的解析上界。他的结论是存在性陈述而非定量bound。
2. **WPL无限长** — 在热力学极限下，WPL贯穿整个系统。
3. **物理机制** — 对于U^NS模型，固定y后势能为 `2W cos(2πβy)·cos(2πβx)`。若 βy 接近 (2k+1)/4，则 `cos(2πβy) ≈ 0`，整行(x方向)势能被压制。
4. **β的类型** — 使用黄金比例（二次无理数，badly approximable），**并非Liouville数**。即便如此，WPL仍然存在并支撑长程输运。

### 3.4 与LP1真正非可分离势的对比

| 特征 | Štrkalj NS模型 | LP1真正非可分离势 |
|------|---------------|-------------------|
| 势形式 | `2W cos(2πβx)cos(2πβy)` | `V₀cos(2π(β_x·x+β_y·y))` |
| 本质 | 旋转可分离 | 真实非可分离 |
| WPL方向 | 水平/垂直 | 斜线（‖(β_x,β_y)） |
| WPL来源 | 单余弦为零 | 线性组合靠近1/4 |
| 文献结果 | 存在性，数值 | **缺失**（本研究的任务） |
| WPL长度 | 系统尺度（无限） | **待定** |
| 数论依赖 | 一个β的逼近 | β_x/β_y比率的逼近 |

### 3.5 攻击3结论

```
评分：8/10（提供了重要的已知威胁证据，但需适配到LP1形式）

直接结论：
- Štrkalj发现即使在"旋转可分离"势中，WPL也在无限系统中支撑输运
- Štrkalj未给出WPL宽度/长度的严格数论上界
- Štrkalj的势与LP1真正非可分离势不同 → 其结论不能直接套用
- **但**：Štrkalj的结果暗示更糟糕的可能性——他的模型已有结构保护
  （乘积形式需要两个余弦同时小才有整行压制），而LP1的非可分离势
  只有一个条件（线性组合 ≈ 1/4）→ 理论上WPL更容易出现
- Johnstone et al. (2022) 发现弱调制线可以含 <1% 的格点就支撑
  逾渗输运 → WPL的"质量"不需要大，只要有连通性

对LP1的威胁等级：中高
```

|------|----------|-------------|-------|--------------|------|

## 威胁评估报告

### 三条攻击链综合判断

```
未解决问题（Open Questions）：
┌────────────────────────────────────────────────────────────────┐
│ Q1: 物理β（二次无理数）下，非可分离势的L_max精确是多少？     │
│     是 ~1/ε（与可分离相同常数），还是 ~C/ε（C>1）？         │
│     这需要对线性形式的Diophantine常数做精确估计。            │
│                                                                │
│ Q2: β_x≠β_y且均为二次无理数时，比率r=β_x/β_y的Diophantine   │

│     但Roth定理保证逼近指数≤2+ε→仍为多项式保护。             │
│                                                                │
│ Q3: Štrkalj的乘积势2W cos(2πβx)cos(2πβy)有"额外的保护"     │
│     （需要两个余弦之一接近零），LP1真正非可分离势呢？        │
│     猜想：LP1真正非可分离势的WPL比Štrkalj更容易出现。        │

│                                                                │
│ Q4: 李雅普诺夫指数λ(E)在WPL上如何变化？                      │
│     WPL上局域长度是否发散？这决定是否能支撑延展态。           │
└────────────────────────────────────────────────────────────────┘

已确定结论（Established）：
┌────────────────────────────────────────────────────────────────┐
│ C1: 非可分离势的WPL条件（一个线性方程）比可分离势的          │
│     （两个方程）本质上更容易满足 → 数论保护弱化。             │
│                                                                │
│ C2: WPL的宽度由β_x/β_y比率（而非单个β）的Diophantine类型     │

红队评分：7/10
说明：攻击成功揭示了结构弱点（一条件 vs 二条件），    
      对物理情形（β=二次无理数）的攻击是"弱化而非摧毁"，
      对极限情形（β=Liouville数）的攻击是"理论摧毁"。
      论文可在标注条件后安全使用数论保护结论。
```

### 对Phase 2的建议

1. **定量计算**：Phase 2应估算物理β下非可分离WPL的具体宽度，与ξ_perc比较
2. **β_x≠β_y**：重点研究β_x和β_y为不同二次无理数的情形，比率r的Diophantine类型未知
3. **Štrkalj适配**：将Štrkalj的结论适配到LP1势形式，检查是否存在隐藏保护
4. **最坏情形构造指南**：在论文中明确写出保护需要β满足的条件（Diophantine条件）
