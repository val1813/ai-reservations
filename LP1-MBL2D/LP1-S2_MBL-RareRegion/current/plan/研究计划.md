# 研究计划 — MBL-RareRegion v1

## 北极星

**命题：** 随机无序中罕见热区是否在热力学极限形成逾渗网络？

**驱动矛盾：**
- 命题A（逾渗）：2D随机无序中罕见热区密度足以在热力学极限形成逾渗网络，为雪崩提供全局连通路径
- 命题B（不逾渗）：强无序MBL参数域中罕见热区密度指数衰减，远低于2D逾渗阈值
- 为什么不能同时为真：同一系统同一参数域不能既逾渗又不逾渗

## 三步推进

### Phase 1：罕见区域分布表征（框架搭建+文献整合）

**目标：** 用极端值统计计算2D随机势中尺寸L区域的概率密度P(L,W,σ)，与准周期势对比

**具体操作：**
1. 综述1D→2D罕见区域统计的文献基础
2. 推导P_random(L,W) = ? 考虑格点势能相关性
3. 推导准周期势P_QP(L,W) = ? 基于Diophantine逼近
4. 数值：在24×24和更大格点上直接统计罕见区域分布（经典计算）

**产出：** P_random(L,W)和P_QP(L,W)的解析+数值对比

### Phase 2：逾渗阈值计算（核心计算）

**目标：** 用连续逾渗理论计算罕见热区形成逾渗网络所需的临界无序强度W_perc

**具体操作：**
1. 定义罕见热区→有效半径r_eff(L)的映射
2. 用连续逾渗理论计算临界密度n_c
3. 将P(L,W)分布代入，求解W_perc
4. 判断MBL参数域(W≈10-20t)是否在W_perc之上

**产出：** W_perc的定量值 + 是否与MBL参数域重叠

### Phase 3：与S1雪崩理论联合（交叉验证）

**目标：** 将逾渗分析结果输入LP1-S1的雪崩传播模型

**具体操作：**
1. 如果逾渗网络存在→雪崩沿逾渗路径传播→MBL总被摧毁
2. 如果不存在逾渗→雪崩仅局部传播→自限性由S1决定
3. 产出现有实验数据在两种假设下的似然度比较

**产出：** 随机无序中2D MBL稳定性的完整判定

## 理论框架

- 2D连续逾渗理论：n_c ≈ 1.128/(πr²)
- 极端值统计：2D Gaussian随机场的罕见涨落
- 罕见区域定义：连续L个格点上W_i < W_c
- 准周期对比：Aubry-André 2D的Diophantine性质
