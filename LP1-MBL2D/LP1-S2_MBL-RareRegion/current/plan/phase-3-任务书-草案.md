# Phase 3 任务书（草案）— 与S1雪崩模型联合分析

**状态：** 草案 — 待Phase 2完成 + LP1-S1进展确认后最终化
**依赖：** Phase 2 η(W,ξ)相图 + LP1-S1雪崩自限性结论

## 关键物理问题

Phase 2预期确认：罕见热区在W≤10t范围内**几何逾渗**（η≫1.128）
Phase 3必须回答：几何逾渗是否必然导致MBL被摧毁？

两种可能：
- **路径A：逾渗→雪崩→全局热化→MBL摧毁**（逾渗是充分条件）
- **路径B：逾渗不一定导致MBL摧毁**（雪崩自限性或边界局域化阻止全局热化）

## 决策树

```
Phase 2: η(W,ξ) ≫ 1.128 对 W < W_perc
    │
    ├── LP1-S1结论：雪崩自限（finite L_c）
    │   → 需要比较：percolating cluster size vs L_c
    │   → 若 S_max > L_c: 逾渗网络触发雪崩 → MBL摧毁
    │   → 若 S_max < L_c: 即使逾渗，雪崩也被自限 → MBL稳定
    │
    ├── LP1-S1结论：雪崩总逾渗（L_c → ∞）
    │   → 任何罕见热区都触发雪崩 → 逾渗不必要
    │   → 结论：2D随机MBL在热力学极限下总被摧毁
    │
    └── LP1-S1未完成
        → Phase 3仅做条件分析：假设两种S1结论，分别讨论
```

## 三步推进

### Phase 3-A：逾渗团簇尺寸 vs 雪崩临界尺寸
- 取Phase 2的S_max(W,ξ,N)统计
- 比较与LP1-S1的L_c(W)（雪崩临界气泡尺寸）
- 如果S_max(W→∞) > L_c：逾渗网络中的最大团簇超过临界尺寸 → 雪崩必然发生
- 如果S_max < L_c：即使逾渗，每个团簇都不够大 → 雪崩被抑制

### Phase 3-B：雪崩在逾渗网络上的传播
- 逾渗网络 ≠ 单个大团簇 → 考虑团簇间hopping
- 两个sub-critical团簇通过共振耦合 → 有效合并为超临界团簇
- 逾渗网络中的"弱连接"是否足以传递雪崩？

### Phase 3-C：对冷原子实验的综合预测
- 结合S1+S2结论：
  - 若两个子命题都支持MBL破坏 → 预测随机MBL实验中交叉点持续漂移
  - 若S1自限+S2逾渗 → 预测中间无序强度有MBL窗口
  - 若都支持MBL稳定 → 预测准周期和随机都稳定（与实验矛盾）
