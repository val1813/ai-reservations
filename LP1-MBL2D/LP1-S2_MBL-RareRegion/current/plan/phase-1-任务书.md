## A任务（博士A — 主推导）

**攻击目标：** 从极端值统计第一性原理推导P_random(L,W)

**具体操作：**
1. 定义2D随机势模型：格点i的势能ε_i ~ i.i.d. 或 Gaussian相关
2. 定义罕见区域：连续L×L个格点上所有ε_i < ε_c (ε_c为单粒子局域化阈值)
3. 计算P(L)：i.i.d.情况下P(L) = [F(ε_c)]^{L²}，其中F为ε_i的CDF
4. 推广到相关势能：ε_i = ∑_j K(i-j) η_j，其中K为相关核，η_j i.i.d.
5. 计算相关情况下的联合CDF：P(L) = P(所有L²个格点ε_i < ε_c)
6. 大L渐近：用极端值理论给出尾部行为
7. 准周期对比：Aubry-André势 V(r) = V_0 cos(2πβ·r + φ) 的极值统计

**产出：** P_random(L,W)和P_QP(L,W)的解析推导 + 数值验证方案

## B任务（博士B — 独立推导）

**攻击目标：** 从连续逾渗+随机几何角度独立推导罕见区域分布

**具体操作：**
1. 将罕见区域视为2D平面上随机分布的"热化盘"
2. 从势能空间转换到几何空间：势能阈值ε_c → 有效半径r_eff
3. 计算热化盘的数密度n(W)作为无序强度W的函数
4. 用连续逾渗理论判断n(W)是否超过n_c
5. 对比A的格点离散方法：连续近似在什么条件下有效？

**产出：** 连续几何方法给出的罕见热区密度n(W) + 与A的格点方法对比
