## 北极星与答案

**问题：** 随机无序中罕见热区是否在热力学极限形成逾渗网络？

**答案：** 是。在单粒子ε<W_c二值化判据下，逾渗阈值W_perc≈30-50t，远高于实验MBL域(W≈5-20t)。在MBL相关参数范围内，热区确定逾渗。

**但这引出了更深刻的问题：** 既然单粒子逾渗总是成立，2D MBL为什么在实验中仍然稳定？答案必须来自多体效应——雪崩自限性或边界局域化。

## 核心发现（按K条目）

### Phase 1 — 解析框架

- **K1.1**: 2D IID二值场中最大全热方块的Poisson稀有事件分布：P_random(L,W) = exp(-N_s² p_th^{L²}) − exp(-N_s² p_th^{(L+1)²})
- **K1.7** ★: 高斯相关GRF在有限阈值u处的有效极值指数θ_eff(u,ξ)≪1。对u=3, ξ=2: θ_eff≈0.20（格点计算保守下界），罕见热区比IID大~2.2倍
- **K1.8** ★: 修正后逾渗参数η_eff=η_IID/θ_eff≫1.128

### Phase 1 Fix — 技术错误修复

- θ=1的渐近声明被撤回。有限阈值处Gaussian核的强最近邻相关(ρ≈0.88)产生显著聚类
- 修复后核心结论从Proposition B（不逾渗）翻转为Proposition A（逾渗）

### Phase 2 — 数值验证

- **K2.1**: 数值模拟确认单粒子逾渗阈值W_perc≈30-50t（N≤100, ξ∈[1,3], 200realizations）
- **K2.2**: ξ增加团簇尺寸~70%但不显著改变W_perc
- **K2.3**: 单粒子逾渗在实验MBL域(W≈5-20t)平凡成立→2D MBL稳定性必然来自多体效应

## 方法论贡献

1. **有限阈值θ_eff框架** — 区分渐近极限(u→∞)与物理阈值(u~2-3)的极值指数计算
2. **格点vs连续的双轨分析** — 格子离散方法（保守下界）与连续excursion set方法（上界）
3. **解析+数值交叉验证** — 解析预测与数值模拟定性一致，定量差异（格点/连续因子~4）已识别

## 对LP-1长命题的贡献

**推进了障碍"静态罕见热区几何"：** S2的结论为S3联合分析提供了关键输入。具体地：

1. **几何逾渗在W≤30t总是成立** → S3需要回答的核心问题变为：既然几何逾渗成立，雪崩自限性(S1)能否阻止全局热化？
2. **如果S1发现雪崩自限(L_c有限)** → 需要比较逾渗团簇尺寸S_max与L_c → 这是S3的关键计算
3. **如果S1发现雪崩总逾渗(L_c→∞)** → 单粒子逾渗+雪崩 → 2D随机MBL必然被摧毁 → 与冷原子实验(arXiv:2508.20699)中随机MBL交叉点漂移观测定性一致

## 开放问题

1. **单粒子判据的系统误差** — 二值化ε<W_c忽略共振辅助退局域(F1)，多体判据下W_perc将显著降低
2. **格点vs连续N_clump因子~4** — 哪个更接近物理真实？需要量子动力学模拟验证
3. **实验可检验预测** — 需要从逾渗+雪崩联合模型推导可被冷原子实验直接测量的观测量
