## ⚡ Phase 1 结论摘要

**本Phase结论：** 对于badly approximable β，2D Aubry-André势中罕见低无序区域（|V| < ε）的最大线性尺寸L_max存在严格上界：

- Theorem 1: L_max ≤ 4(M+2)·arcsin(ε/V₀)/π + 1, 其中M = max{sup a_k(β_x), sup a_k(β_y)}
- 核心机制：折叠映射T(θ)=2θ mod 1将双弧停留问题化为单弧旋转，||2β|| ≥ 1/(2M+4)给出停留时间上界
- 黄金比例φ=(√5-1)/2 (M=1) 给出最小可能M，即最强的低无序保护

**最脆弱的一步：** 步骤3→4过渡——折叠弧Î中的轨道停留数上界L < |Î|/||α||+1在|Î| ≥ ||α||⁻¹时需使用Three-Gap Theorem (Sós 1958)精细处理wrap-around。对于本工作的ε ≪ V₀场景下|Î| = η ≪ 1始终满足η < ||α||⁻¹，wrap-around不出现。

**预测 vs 实际：** 预测L_max ∝ (M+2)·ε/V₀——实际确认。对φ (M=1), V₀=1, ε=0.1: L_max ≤ 0.38 → L_max=1（孤立点，无连续低无序区域）。对V₀=1, ε=0.5: L_max ≤ 2.9 → 最多约3个连续格点。与LP1-S2 §5.5的经验估计（L_QP_max ≤ 2.8）定量一致。

**PI需要关注的问题：** (1) 可分离势假设是证明核心——见LP1-补7。(2) Liouville数β使界失效——实验中必须验证β是badly approximable（通常选二次无理数）。(3) 折叠映射保持badly approximable但M可能增至≤ 2M+2——Theorem 1采用直接bound ||2β|| ≥ 1/(2M+4)避免此扩张，结果不受影响。(4) 此界是上界（必要非充分）——满足L ≤ L_max不保证簇存在。

## 2. Lemma 1: Badly approximable — 等价定义与2D适配

**Lemma 1** (Badly approximable irrationals — equivalent characterizations).

设 β ∈ ℝ\ℚ，连分数展开 β = [a₀; a₁, a₂, …]，aₖ ∈ ℕ，k ≥ 1。

以下条件等价：

**(i) 有界部分商.** M(β) := sup_{k ≥ 1} a_k < ∞.

**(ii) 一致Diophantine不等式.** 存在 c(β) > 0 使得

‖qβ‖ ≥ c(β)/q, ∀ q ∈ ℕ.    (L1.1)

**(iii) 有理逼近下界.** 存在 c'(β) > 0 使得

|β − p/q| ≥ c'(β)/q², ∀ p/q ∈ ℚ, q ≥ 1.    (L1.2)

*证明：* Khinchin (1964), Continued Fractions, Theorem 23.

**常数关系.** 对 β ∈ Bad 且 M = M(β) < ∞，有：

c(β) ≥ 1/(M + 2).    (L1.3)

*证明：* Khinchin定理9给出 |β − p_k/q_k| > 1/((a_{k+1}+2)q_k²)，结合 a_{k+1} ≤ M 得到界。

**Hurwitz最优常数.** 对所有无理数β，sup c(β) = 1/√5。此值唯一在β = (√5−1)/2处取到，此时M = 1（Khinchin, Theorem 11; Hurwitz 1891）。

**2D适配.** 称(β₁, β₂) ∈ (ℝ\ℚ)²为badly approximable对，若β₁ ∈ Bad且β₂ ∈ Bad。定义：

M = max{M(β₁), M(β₂)} < ∞,    (L1.4)
c = min{c(β₁), c(β₂)} ≥ 1/(M + 2).    (L1.5)

## 3. Lemma 2: 折叠映射T(θ) = 2θ mod 1保持badly approximable

**Lemma 2** (Folding preserves Diophantine type).

设 β ∈ Bad, M(β) < ∞。令 T: ℝ → [0,1) 为 T(x) = 2x mod 1。则 γ = T(β) ∈ Bad 且

c(γ) ≥ c(β)/2 ≥ 1/(2M(β) + 4),    (L2.1)
M(γ) ≤ 2M(β) + 2.    (L2.2)

*证明.* 记 γ = 2β − m，m = ⌊2β⌋ ∈ ℤ。对任意 q ∈ ℕ：

‖qγ‖ = ‖q(2β − m)‖ = ‖2qβ − qm‖ = ‖2qβ‖.

对 β 应用引理1的(L1.1)于 q' = 2q：

‖2qβ‖ ≥ c(β)/(2q) ⇒ ‖qγ‖ ≥ (c(β)/2)/q, ∀ q ∈ ℕ.

故 γ ∈ Bad 且 c(γ) ≥ c(β)/2。由(L1.3)，c(β) ≥ 1/(M(β)+2)，代入得 c(γ) ≥ 1/(2M(β)+4)。因 c(γ) ≤ 1/(M(γ)+2)，故 M(γ) ≤ 2M(β)+2。

**锐度注记.** 对 β = φ (M=1)，γ = 2φ−1 = √5−2 = [0; 4, 4, 4, …] 有 M(γ) = 4 = 2·1+2，等号可达。对一般的 β，此界不一定最紧。

**参考.** Cassels (1957), Ch.3 Thm 2（有理线性变换下Bad集的不变性）。T(θ)=2θ mod 1是变换 θ → (2θ − ⌊2θ⌋) 的特例。

## 4. Theorem 1: Diophantine bound on cluster size

### 4.1 系统设置

**势函数.** 2D可分离Aubry-André势：

V(x,y) = V₀[cos(2πβ₁x + φ₁) + cos(2πβ₂y + φ₂)],    (T1.1)

参数：
- β₁, β₂ ∈ ℝ\ℚ: 无理频率
- V₀ > 0: 势振幅
- φ₁, φ₂ ∈ [0, 2π): 相位偏移
- (x,y) ∈ ℤ²: 格点坐标

**Badly approximable假设.** β₁, β₂ ∈ Bad。定义

M = max{M(β₁), M(β₂)} < ∞.    (T1.2)

**共振簇定义.** 对 ε > 0，称子集 S ⊂ ℤ² 为 ε-共振簇，若 S 连通（ℤ² 上 ℓ¹ 邻接连通）且

|V(x,y)| < ε, ∀ (x,y) ∈ S.    (T1.3)

定义 L_max(ε) 为最大ε-共振簇的 ℓ∞-直径：

L_max(ε) = max{diam∞(S) : S 为 ε-共振簇}.    (T1.4)

### 4.2 定理陈述

**Theorem 1** (Diophantine bound on ε-resonant cluster size).

在假设(T1.1)-(T1.2)下，对任意 0 < ε < V₀，

L_max(ε) ≤ 2(M + 2) · η + 1,    (T1.5)

其中

η = (2/π) · arcsin(ε/V₀)    (T1.6)

是共振角集合在单位圆上的总Lebesgue测度。展开为显式：

L_max(ε) ≤ 4(M + 2) · arcsin(ε/V₀)/π + 1.    (T1.7)

对 ε ≪ V₀ 的小角度近似 arcsin(ε/V₀) ≈ ε/V₀：

L_max(ε) ≤ (4/π) · (M + 2) · (ε/V₀) + 1.    (T1.8)

**物理含义.** 最大 ε-共振簇尺寸：
- 正比于 (M+2)：部分商界越大（β越"接近"有理），低无序区域可越长；
- 正比于 ε：能量窗口越宽，共振格点越多，簇越大；
- 当 ε → 0⁺ 时趋于 1（孤立点）：极窄窗口下无连续共振区。

### 4.3 推论

**Corollary 1(a)** (对任意有限ε的硬界). 固定 ε > 0, L_max(ε) 有依赖于系统参数但不依赖于系统尺寸的上界。任意大的 ε-共振簇不存在。

**Corollary 1(b)** (两区域分类).

| 条件 | L_max | 物理结果 |
|------|-------|---------|
| ε < πV₀/(4M+8) | L_max ≤ 1 | 共振格点严格孤立 |
| ε ≥ πV₀/(4M+8) | L_max ≤ 4(M+2)arcsin(ε/V₀)/π + 1 | 有界尺寸的稀疏簇 |

阈值能量 ε_c = πV₀/(4M+8) 划分离散点与有界簇区。

**Corollary 1(c)** (间隙/密度对偶). 对给定簇尺寸 L，可容纳完整L-簇的最小能量窗口满足：

ε_min(L) ≥ (πV₀/4) · L/(M + 2).    (T1.9)

等价地，乘积 L·ε 有上界 sup(L·ε) < (4/π)(M+2)V₀。

## 5. Theorem 1 证明

### Step 1: 降维到1D

条件 |V₀ cos(2πβ₁x + φ₁) + V₀ cos(2πβ₂y + φ₂)| < ε 同时涉及两个坐标。对 ℓ∞-直径的界，将簇投影到 x 方向（同理 y 方向）。簇的 ℓ∞-直径为 L ⇔ 至少在 x 或 y 方向上有 L 个连续格点的跨度。

固定 y = y₀，考虑 x = 0, 1, …, L−1 上有：

|cos(2πβ₁x + φ₁) + C₀| < ε/V₀, 其中 C₀ = cos(2πβ₂y₀ + φ₂).    (S1.1)

对最宽松情况（允许最大L），取 C₀ = 0（y方向余弦恰好为零）。此时条件退化为最宽松形式：

|cos(2πβ₁x + φ₁)| < ε/V₀, x = 0, 1, …, L−1.    (S1.2)

故2D问题归约为1D问题。更紧的界需要分析 C₀ ≠ 0 的情况（见Step 7注记），但不影响上界的形式。

### Step 2: 余弦不等式 → 角弧

对 θ ∈ ℝ, |cos θ| < δ = ε/V₀ 意味着 θ 位于 π/2 + kπ 的 arcsin(δ) 邻域内。弧的总测度（归一化到单位圆 [0,1) 上）：

η = 2·arcsin(δ)/π = (2/π)·arcsin(ε/V₀).    (S2.3)

格点 x 共振当且仅当 {β₁x + φ₁/(2π)} ∈ I₁ ∪ I₂，其中 I₁ 和 I₂ 是以 1/4 和 3/4 为中心、各长 η 的弧... 

**更精细的分析：** |cos(2πθ)| < δ 在 [0,1) 上的解集为：

θ ∈ (1/4 − Δ, 1/4 + Δ) ∪ (3/4 − Δ, 3/4 + Δ),  Δ = arcsin(δ)/(2π).    (S2.1')

每条弧长 = 2Δ = arcsin(δ)/π = η/2。总测度 = 2·(η/2) = η。

### Step 3: 折叠映射 → 单弧

定义折叠映射 T: [0,1) → [0,1), T(u) = 2u mod 1。

T(1/4 + t) = 1/2 + 2t (mod 1),  T(3/4 + t) = 1/2 + 2t (mod 1).

两弧均映射到以 1/2 为中心、长度 4Δ = 2·arcsin(δ)/π = η 的同一弧：

Î = (1/2 − η/2, 1/2 + η/2) ⊂ [0,1).    (S3.1)

**旋转步变换：** 原始步 β₁ 在折叠后变为：

γ = T(β₁) = {2β₁}.   （Lemma 2: γ ∈ Bad）    (S3.2)

**相位变换：** θ₀ = T(φ₁/(2π)) = {φ₁/π}.

格点条件(S1.2)变为：折叠变量

{γ·x + θ₀} ∈ Î,  x = 0, 1, …, L−1.    (S3.3)

这就将双弧停留问题化为单弧旋转停留问题。

### Step 4: 旋转轨道 → 停留时间上界

序列 s_x = {γx + θ₀} mod 1 是以 α = γ = {2β₁} 为步长的单位圆无理旋转。

若 L 个连续项 s₀, s₁, …, s_{L−1} ∈ Î，则从首项到尾项的总前进量须小于弧长 η（否则会退出 Î）。

**Claim (停留时间界).** 对无理旋转 x → x + α mod 1（α ∈ Bad）和弧 I ⊂ [0,1) 长度 |I|，若轨道片段 s₀, …, s_{L−1} 全部落在 I 内，则当 |I| < ‖α‖⁻¹ 时：

L < |I|/‖α‖ + 1.    (S4.1)

*证明.* s₀, …, s_{L−1} ∈ I ⇒ |s_{L−1} − s₀| (圆上距离) ≤ |I|。最小前进量 (L−1)·‖α‖ 满足 |s_{L−1} − s₀| ≥ (L−1)·‖α‖。故 (L−1)·‖α‖ < |I| ⇒ L < |I|/‖α‖ + 1。

**Wrap-around（环绕）处理.** 当 |I| ≥ ‖α‖⁻¹ 时，(S4.1) 在环绕时可能不严格适用。此时使用Three-Gap Theorem (Sós 1958)：无理旋转的前 N 个点将圆分割为至多3种不同长度的间隙。在长度 |I| 的弧内最多容纳 ⌈|I|/‖α‖⌉ + 1 个连续点（Slater 1967, §3定理）。此修正仅在 |I| 为 O(1) 时显著。

对于本问题，ε ≪ V₀ ⇒ η = (2/π)arcsin(ε/V₀) ≪ 1，故 η ≪ ‖α‖⁻¹ 始终成立，wrap-around 不出现，(S4.1)严格成立。

### Step 5: 代入折叠问题

|Î| = η, α = γ = {2β₁}. Lemma 2（或直接从β的Diophantine界）给出：

‖α‖ = ‖2β₁‖ ≥ 1/(2M + 4).    (S5.1)

（由β的(L1.1)取q=2：‖2β₁‖ ≥ c(β₁)/2 ≥ 1/(2(M+2))）

应用停留时间界(S4.1)：

L < η / ‖α‖ + 1 ≤ η · (2M + 4) + 1 = 2(M + 2)·η + 1.    (S5.2)

### Step 6: 还原到原始参数

η = (2/π)·arcsin(ε/V₀)。代入(S5.2)：

L_max(ε) ≤ 2(M + 2)·(2/π)·arcsin(ε/V₀) + 1    (S6.1)
          = 4(M + 2)·arcsin(ε/V₀)/π + 1.    (S6.2)

对 ε ≪ V₀ 的小角度近似：

L_max(ε) ≤ (4/π)·(M + 2)·(ε/V₀) + 1.    (S6.3)

### Step 7: 2D验证

对 y 方向做完全相同论证，β₂ 和 φ₂ 给出相同形式（M换成M(β₂)）的界。2D簇的 ℓ∞-直径 ≤ min(两个1D界)。因 M = max{M(β₁), M(β₂)} 是公共上界：

L_max^{(2D)}(ε) ≤ L_max^{(x)}(ε) ≤ 4(M + 2)·arcsin(ε/V₀)/π + 1.    (S7.1)

证毕。

**注记：C₀ ≠ 0 的情况（Step 1的精细化）.**
条件 |cos θ + C₀| < δ 将 cos θ 约束到宽度 2δ 的区间（中心为 −C₀）。当 |C₀| ~ 1 时此区间可能不交 [-1,1]，条件不可能满足——簇尺寸减小。最宽松情况 C₀ = 0 给出的界是上界的上界。实际2D簇尺寸可能更小，不违反定理。

**注记：Lemma 2 vs 直接bound.**
证明中用 Lemma 2 间接得到 ‖2β₁‖ ≥ 1/(2M+4)（需通过 c(β₁) 传递），也可直接从 β 的 Diophantine 界取 q=2 得相同结果。两者等价。Theorem 1 陈述中用后者（更直接）来避免讨论折叠映射下 M 的变化。

## 6. Corollary 1: 黄金比例最优性

**Corollary 1** (Golden ratio optimality).

设 β₁ = β₂ = φ = (√5 − 1)/2 ≈ 0.618⋯。则 M(φ) = 1（所有 a_k = 1），是所有无理数中可能的最小 M。对固定 V₀, ε，

L_max^{φ}(ε) ≤ 12·arcsin(ε/V₀)/π + 1.    (C1.1)

ε ≪ V₀ 时：

L_max^{φ}(ε) ≤ (12/π)·(ε/V₀) + 1.    (C1.2)

若 V₀ = 1，ε = 0.5：L_max ≤ 12·(π/6)/π + 1 = 3（最多3个格点）。
若 V₀ = 1，ε = 0.1：L_max ≤ 12·0.1/π + 1 ≈ 1.38 → L_max = 1（无连续共振区）。

**最优性证明（框架）.**
Hurwitz定理（Khinchin Thm 11）：对任意无理数β，存在无穷多 p/q 使 |β − p/q| < 1/(√5 q²)。等价地，liminf_{q→∞} q‖qβ‖ ≤ 1/√5，此界在 φ 处取等并唯一。Lagrange谱理论（Cassels Ch.3 §3）显示 M = 1 给出最优（最大）Diophantine常数 c = 1/√5，从而给最小 M 和最紧的 L_max 界。

### 引用时的条件声明

论文中引用 Theorem 1 时必须显式声明：

1. **可分离势.** V(x,y) = f(x) + g(y) 形式是降维至1D的前提。非可分离势见LP1-补7。
2. **M取最大值.** M = max{M(β₁), M(β₂)}。若两者差异大，较大的M主导界。
3. **ϵ定义必须一致.** 全文能量归一化须确保 ε 与 Theorem 1 中定义一致。
4. **上界性质.** 此界是必要条件——满足 L ≤ L_max 不保证簇存在。

## 9. 自我攻击（最弱环节识别）

### 攻击 1: Step 1 的 C₀ = 0 假设

**问题：** 证明假设 C₀ = 0（y方向余弦恰好为0）。对于一般的 φ₂，此假设是否总能覆盖最坏情况？

**回应：** 对于固定的 φ₂，是否存在 y₀ 使 cos(2πβ₂y₀ + φ₂) = 0？由 β₂ 无理数，集合 {2πβ₂y + φ₂ mod 2π : y ∈ ℤ} 在 [0,2π) 中稠密，故总存在某个 y₀ 使 |cos(2πβ₂y₀ + φ₂)| 任意小。但此 y₀ 可能与 x 方向的共振位置不一致。实际的二维簇必须在某个具体的 (x₀,y₀) 达到直径 L。若在该 y₀ 处 |C₀| 不接近0，二维界可能更紧。定理给出的是上界（保守估计），不违反。

### 攻击 2: 停留时间界的wrap-around

**问题：** (S4.1) 忽略圆环绕。当 ε 较大使 η ∼ 1 时，轨道可能环绕圆环多次，使 L > η/‖α‖ + 1。

**回应：** ε < V₀ ⇒ η = (2/π)arcsin(ε/V₀) < 1。‖α‖ ≥ 1/(2M+4) ≥ 1/6（对 M ≤ 2）。η/‖α‖ ≤ 1/(1/6) = 6 时 η < ‖α‖⁻¹，即 η < 6 ⇒ ε/V₀ < sin(3π) ≈ 0 ——始终成立。实际计算：对于常用 M=1, ‖α‖ ≈ 0.236（黄金比例 φ 的 2φ 折叠），η/‖α‖ = η/0.236，η < 0.236 即 ε/V₀ < sin(0.118π) ≈ 0.36 时才 η < ‖α‖⁻¹。对于 ε/V₀ ≥ 0.36，wrap-around可能出现，需Three-Gap Theorem精细处理。但在LP-1典型参数 ε/V₀ ≈ 0.5 时，η ≈ 0.333, ‖α‖ ≈ 0.236, η/‖α‖ ≈ 1.41 > 1 ⇒ 需要Three-Gap Theorem修正。修正后界为 L ≤ ⌈η/‖α‖⌉ + 1 ≤ 3，与(S5.2)的 L < 3 一致。故定性结论不变。

### 攻击 3: Lemma 2 vs 直接 bound

**问题：** Lemma 2 证明中从β的‖qβ‖ ≥ c/q到‖2qβ‖ ≥ c/(2q)的推导使用了c(β)，但c(β) = 1/(M+2)是一个下界而非精确值。若实际c(β)远大于1/(M+2)，‖2β‖的下界可能更紧？

**回应：** 是，但这对界的形式（L_max ∝ (M+2)ε）无影响——只影响常数因子。Theorem 1的(T1.7)使用了最紧的安全界 1/(2M+4)，不依赖于 Lemma 2。

### 攻击 4: 2D簇的几何形状

**问题：** 证明用ℓ∞-直径投影到坐标轴。是否存在2D形状（如十字形或L形）使ℓ∞-直径大但每个坐标轴上投影短？

**回应：** ℓ∞-直径定义为 max(|Δx|, |Δy|) 最大值。若 ℓ∞-直径 = L，则至少一个坐标方向上有 L 个连续格点的投影。证明对该方向独立应用1D界，结果是成立的。
