# 总结 — LP1-补9 Diophantine

## 最终结论

结论类型：有边界。

LP1 论文中的 Diophantine 分类应写成严格定理：

`badly approximable` `iff` 连分数部分商有界。

在可分离 2D 准周期势下，低无序区域最大线性尺寸满足

`L_max^(2D) <= C * (M+1) / ε`

黄金比例对应 `M=1`，给出最强保护。

## 重要修正

1. 不再使用“折叠映射保持同一常数”这一不稳链条。
2. `Theorem 1` 只写上界，不写成精确等号。
3. 可分离势、`β_x/β_y` 线性无关、`ε` 归一化必须在正文显式标明。
