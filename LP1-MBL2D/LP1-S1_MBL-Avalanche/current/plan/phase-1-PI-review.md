## 核心矛盾分析

### A的结论
ETH费米黄金规则 → 单格点热化率Γ_j ~ g²/W（不依赖L）→ 雪崩永不停止（DRH不稳定性）→ 2D MBL不存在（除非渗流瓶颈提供额外抑制）

### B的结论
Fock空间路径计数 → 整层协同翻转的有效耦合有限 → 存在L_c ~ g^{-2/3} → 雪崩自限 → 2D MBL稳定

### 矛盾根源

**A和B描述的是不同的物理过程：**

| | A的模型 | B的模型 |
|--|---------|---------|
| 过程 | 逐格点热化（串行） | 整层协同翻转（并行） |
| 机制 | ETH浴的费米黄金规则 | Fock空间高阶微扰论 |
| 结果 | Γ~g²/W（恒定） | Γ~(ng)^{2n}（衰减） |
| 物理图像 | 热区作为理想浴，逐个吸收边界格点 | 整层必须同时翻转才算"热化" |

**关键问题：哪个过程是物理现实？**

### PI判定

**A的模型是正确的物理图像。** 原因：

1. 热化是一个**顺序过程**，不需要整层同时翻转。第一个格点被热化后，它加入热区，增强热区热化下一个格点的能力。

2. B的"整层协同翻转"对应的是一个**非物理约束**——要求所有壳层格点在同一个量子跃迁中同时改变状态。实际上没有物理机制要求这种协同性。

3. 但A的结论（DRH不稳定性→MBL不存在）也不是最终答案，因为它忽略了：
   - 无序的空间不均匀性（渗流效应）
   - 热区扩展过程中遇到的强无序瓶颈
   - 有限尺寸效应

**然而，B的能级间距修正(g_eff=ng)揭示了一个重要物理：** 当壳层格点数n增大时，有效耦合增强。这个效应在A的ETH框架中已经被自动包含（ETH矩阵元×态密度恰好给出L无关的结果），但B的推导让我们看到了为什么——两个效应（矩阵元减小×态密度增大）恰好抵消。

## 统一图像

**正确的物理图像是A的逐格点热化，但需要加入B发现的几何效应：**

1. 单格点热化率：Γ_single ~ g²/W（A的结果，正确）
2. 整层热化时间：τ_layer ~ (W/g²)·ln(4L)（A的Eden生长，正确）
3. 雪崩传播速度：dR/dt ~ g²/(WR)（扩散式，A的结果）
4. 自限机制：**不来自Fock空间路径数的竞争**（B的框架不适用于串行过程），而来自：
   - 渗流瓶颈（A的Step 3.5）
   - 或：DRH论证严格成立→2D MBL不存在

**Phase 2的核心问题：DRH不稳定性是否有漏洞？渗流瓶颈是否足以稳定MBL？**
