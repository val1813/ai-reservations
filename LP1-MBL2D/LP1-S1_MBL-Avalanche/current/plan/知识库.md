## 本课题K条目

### Phase 1 产出

- **K1.1** (✅L2): ETH费米黄金规则给出单格点热化率Γ_j ~ g²/W_j，不依赖于热区大小L。物理原因：ETH矩阵元~e^{-S}与态密度~e^{S}恰好抵消。[A Phase 1]

- **K1.2** (✅L2): 2D雪崩传播在均匀无序中为扩散式R(t)~√(g²t/W)，无指数自限。这是De Roeck-Huveneers (2017)不稳定性论证的核心。[A Phase 1]

- **K1.3** (❌已废弃): Fock空间路径计数给出L_c~g^{-2/3}。PI判定整层协同翻转为非物理约束——实际热化是串行过程。[B Phase 1; PI审核废弃]

- **K1.4** (✅L2): 物理过程是串行热化（逐格点ETH热化），A的ETH框架是正确基础。[PI审核]

- **K1.5** (✅L2): 2D MBL的稳定性不能来自Fock空间路径数竞争，必须来自其他效应。[PI审核]

### Phase 2 产出

- **K2.1** (✅L2): Luitz边界局域化在2D中失效——维度效应(z_in>z_out)压制。2D边格点有z_in=3, z_out=1，内部耦合的维度优势压制边界局域化。[A Phase 2]

- **K2.2** (✅L2): ETH有限尺寸修正在2D中可忽略。修正~1/√(2^{L²})，对L=4已为1/256，衰减太快。[A Phase 2]

- **K2.3** (⚠️L1): Griffiths自限窗口极窄(W_local>0.7W_c)，且存在自洽性问题——该窗口内热区本身接近MBL转变。[A Phase 2]

- **K2.4** (✅L2): DRH雪崩论证在2D中比1D更robust。维度优势(体积~L², 边界~L)系统性压制所有1D中有效的自限机制。[A Phase 2]

- **K2.5** (✅L2): 2D雪崩传播相图含4区域：MBL稳定(p_block>p_c) / 临界(p≈p_c, R~t^{0.35}) / Griffiths(R~(ln t)^2) / DRH扩散(R~√t)。由p_block vs p_c=0.593控制。[B Phase 2]

- **K2.6** (✅L2): 强无序极限下R~(ln t)^{1/ψ}（ψ≈1/2），来自Fisher IRFP物理。MBL热化映射到2D随机横场Ising模型。[B Phase 2]

- **K2.7** (⚠️L1): 渗流临界线（box distribution）g_c²~0.407/ln(0.407W_max)→0当W_max→∞。强无序总是MBL。[B Phase 2]

- **K2.8** (⚠️→K3.1解决): 量子隧穿(soft percolation)的影响——Phase 3证明可忽略。[B Phase 2→Phase 3]
