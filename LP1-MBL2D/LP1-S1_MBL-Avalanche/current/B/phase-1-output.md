# B博士 Phase 1 作业 — MBL-Avalanche v1

## Fock空间图论路径分析：2D量子系统雪崩自限性

---

⚡ **本Phase推进了什么：** 证明2D Fock空间中存在有限临界气泡尺度L_c ~ g^{-2/3}，雪崩在L < L_c时自限。2D比1D更脆弱（几何因子c~8使L_c更小），但所有有限维度中MBL相在微扰论框架内稳定。

⚡ **最关键的跨域连接：** 图论中超立方体的测地线计数 + 信息论中有噪信道的容量衰减 → 约束Fock空间热化率。能级间距的尺度依赖性（g_eff = ng）是决定性修正。

⚡ **预测 vs 实际：** 预测路径数可能以exp(L²)增长打破自限 → 实际推导表明有效路径数受限于边界面积(~L)，增长为(2L+1)!~exp(2L ln L)。但能级间距修正将g替换为ng，使临界尺度从g^{-2}降至g^{-2/3}。

⚡ **卡在哪里：** (1) 能级间距的自洽性（热化过程中间距动态变化）；(2) 与A博士的ETH费米黄金规则结果存在表面矛盾（需要统一两种图像）。

## §0 声张强度声明

**原始声张：** 无条件成立（对所有满足基本假设的2D无序量子系统）

**修正后声张：** 有条件成立
- 条件1：微扰论有效（g ≪ 1，强无序/弱跃迁）
- 条件2：忽略稀有区域的关联效应（Griffiths效应）
- 条件3：Fock空间中路径相位随机（无系统性相干增强）
- 条件4：不考虑共振级联（共振不形成宏观连通簇）

## §1 结论预测

**推导前预测：**
- 路径数增长：N_path ~ exp(αL^δ)，预测δ=1（边界决定）
- 局域化抑制：每条路径权重~g^{cL^γ}，预测γ=1（路径长度~L）
- 竞争结果：δ=γ=1 → 需要精确系数比较 → 预测自限（基于1D类比）

**最可能出错的步骤：** 能量分母的处理——是~W（所有同阶）还是~W/n（能级间距）

## §2 强制撞墙

### 攻击1：路径数(2L+1)!可能高估
**攻击：** 假设所有排列都是独立有效路径，但物理约束（局域性、能量守恒）应大幅削减。
**防御：** 能量约束对最短路径不构成限制（每步能量变化~W/n ≪ W）。局域性在2D中不是瓶颈（branching factor~4L² ≫ n/e）。量子干涉不改变平均速率。

### 攻击2：非最短路径可能主导
**攻击：** 更长路径数量指数更多，可能总贡献更大。
**防御：** 长度l的路径贡献~(zg)^l。当g<1/z时更长路径指数衰减。

### 攻击3：共振捷径
**攻击：** Fock空间共振逾渗簇可能提供短路径。
**防御：** 在强无序下(W≫W_c)共振逾渗阈值未达到。但这是最危险的攻击——结论从"无条件"降级为"条件性"。

## §3 推导正文

### §3.1 Fock空间图构建

2D方格上N=L²个自旋-1/2系统：
- 节点集：|V| = 2^{L²}，每个节点=一个计算基矢
- 边集：两节点相连 ↔ 仅在一对相邻格点自旋上不同
- 连通度：z ≈ 2L²

### §3.2 热化构型定义与Fock空间距离

从"L²格点热态"到"(L+1)²格点热态"：
- 新增格点数：(L+1)²-L² = 2L+1（壳层）
- 最小路径长度：d_min = 2L+1

### §3.3 路径计数

到达固定终态的最短路径数：N_fixed ~ (2L+1)!
- 原因：壳层2L+1个格点的纳入顺序任意（每个都有热区邻居）
- 约束检验：能量约束不限制最短路径（步长W/n ≪ 带宽W）

### §3.4 单条路径振幅

|A_p| ~ g^{2L+1}（标准微扰论，每步贡献因子g）

### §3.5 能级间距修正（关键步骤）

**标准估计的问题：** 每步能量分母不是~W，而是~δ=W/n（n个格点的能级间距）。

修正后单条路径振幅：
|A_p| ~ (V/δ)^n = (nV/W)^n = (ng)^n

定义有效耦合：g_eff(n) = n·g

**物理含义：** 更大的壳层→更密的能级→更强的有效耦合→更容易热化

### §3.6 总热化率

ln Γ ~ n[ln(2n/e) - 2|ln(ng)|]
     = n[ln(2n/e) - 2|ln g| + 2ln n]
     = n[3ln n + (ln2-1) - 2|ln g|]

### §3.7 自限条件与临界尺度

自限：3ln n < 2|ln g| - (ln2-1)

临界尺度（n = 2L_c+1 ≈ 2L_c）：

**L_c ~ g^{-2/3}/c**

其中c~8是2D几何因子（壳层格点数=cL而非2L+1的精确值）。

### §3.8 与1D对比

| 维度 | 壳层格点数 | L_c标度 | g=0.1时L_c |
|------|-----------|---------|-----------|
| 1D | 2（端点） | g^{-2/3} | ~4.6 |
| 2D | ~8L | g^{-2/3}/8 | ~0.6 |
| 3D | ~6L² | g^{-2/5} | ~2.5 |

**2D比1D更脆弱：** 几何因子c~8使L_c减小8倍。物理原因：壳层更大→能级更密→有效耦合更强→更小的热区就能触发雪崩。

### §3.9 维度推广

一般d维：L_c^{(d)} ~ g^{-2/(2d-1)} · (geometric factor)^{-1}

所有有限维度中L_c有限 → **MBL相在微扰论框架内对所有d稳定**。

## §末 声张强度对比与新增卡点

### 声张强度对比

§0声明的目标声张：无条件成立——Fock空间连通度exp(αL)无法补偿局域化抑制g^{-βL²}
本Phase实际结论：有条件成立——存在L_c ~ g^{-2/3}，但需要微扰论有效+无共振逾渗

对比结果：**实际结论比目标声张弱**
- 从"无条件"降级为"有条件"（需排除共振逾渗）
- 但核心结论成立：雪崩自限，L_c有限
- 意外发现：L_c的标度不是g^{-2}（裸估计）而是g^{-2/3}（能级间距修正后）

### 预测 vs 实际

- 预测：δ=1, γ=1（路径数和路径长度同阶增长）→ 自限
- 实际：确认自限，但L_c标度被能级间距效应修正
- 一致性：定性一致，定量有修正

### 新增卡点

**卡点B1：能级间距自洽性**
- 问题：热化过程中部分格点退局域化，间距动态变化
- 影响：可能使L_c进一步减小（正反馈）
- 状态：需自洽求解

**卡点B2：与A博士ETH结果的表面矛盾**
- 问题：A发现Γ_single~g²/W（L无关），B发现Γ~(ng)^{2n}（L依赖）
- 可能解释：两者描述不同物理过程——A描述单格点被ETH浴热化，B描述整层协同翻转的Fock空间路径
- 状态：需要Phase 2统一

**卡点B3：Griffiths效应**
- 问题：稀有弱无序区域形成天然大热区(L>L_c)，概率~e^{-αL^d}
- 影响：不破坏MBL相存在性（零测集），但导致亚指数弛豫
- 状态：已知开放问题

**卡点B4：g=0.1时2D的L_c<1**
- 问题：数值估计L_c~0.6<1，意味着g=0.1对2D不够强局域化
- 影响：需要g≲0.01才能使2D MBL稳定
- 状态：与实验/数值观察一致（2D MBL需要更强无序）
