# MBL-Avalanche

**课题：** LP1-S1 2D雪崩不稳定性是否自限？
**长命题：** LP-1 2D MBL热力学稳定性
**认领日期：** 2026-05-31
**状态：** 初始化

## 北极星

2D量子雪崩不稳定性是否自限——是否存在有限临界气泡尺寸L_c，使得小于L_c的罕见热区无法触发系统级雪崩？

## 驱动矛盾

- **命题A（雪崩自限）：** 热化前沿在2D中以对数速度传播，存在有限临界气泡尺寸L_c使得L < L_c的罕见热区无法触发系统级雪崩。MBL在强无序下稳定。
- **命题B（雪崩总是逾渗）：** 2D中量子雪崩传播的临界尺寸发散（L_c → ∞），任何有限密度罕见热区最终都能触发全局热化。MBL在热力学极限下总是被摧毁。

## 与LP1-S2的关系

S2已证明：单粒子ε<W_c判据下罕见热区在W≤30t确定逾渗。因此S1的结论决定了2D MBL的命运：
- 若S1成立（L_c有限）→ 即使几何逾渗成立，雪崩被自限 → 2D MBL可能稳定
- 若S1证伪（L_c→∞）→ 几何逾渗+无限雪崩 → 2D随机MBL必然被摧毁
