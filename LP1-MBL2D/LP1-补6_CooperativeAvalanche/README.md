# LP1-补6：排除"多小区域协同启动雪崩"

**所属长命题：** LP-1 2D MBL热力学稳定性
**来源：** 院长审计 — MBL-Quasiperiodic K3.3
**状态：** 进行中
**认领日期：** 2026-06-01

## 驱动矛盾

- **命题A（现有结论）：** 单区域L_max < ξ_perc则雪崩无法启动 → 准周期MBL稳定
- **命题B（可能漏洞）：** 多个相邻小区域（各尺寸<L_max）可通过协同耦合集体充当等效超临界热种子
- **为什么不能同时为真：** 若协同效应存在，即使每个单独区域都亚临界，集体效应仍可触发系统级雪崩 → "数论保护的稳定性"结论可能被推翻

## 关键约束（继承自S1/S2/S3）

- 雪崩自限条件：p_block > p_c ≈ 0.593（S1）
- 准周期势中 L_max ≤ (M+2)/ε（S3 v1结论，已被文献先发）
- 单区域触发阈值：Γ_single > Γ_threshold（S1 ETH-FGR框架）
- 多体隧穿率随距离指数衰减：Γ(d) ~ g² exp(-d/ζ)（De Roeck-Huveneers 2017）
