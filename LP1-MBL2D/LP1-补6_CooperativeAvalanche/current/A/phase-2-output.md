# A博士 Phase 2 作业 — CooperativeAvalanche 边界修复

## 目标

修复 AUDITOR 指出的三个阻断点：

1. `zeta` 参数不一致。
2. WPL 通道的定量定位。
3. 串行级联与同时协同的边界。

## 结论

### A2.1 `zeta` 统一

Phase 1 中 `zeta=1` 与 `zeta=2-3` 不是互相矛盾，而是不同用途：

- `zeta=1`：强局域体区的典型估计，用于展示参考参数。
- `zeta=2-3`：保守上界，用于审查最不利传播。

因此主结论必须使用保守形式：

`C_max <= 1 + 6 exp(-d_min / zeta_eff)`

并在正文中只声称：只要 `C_max << Gamma_threshold / Gamma_single(L_max)`，协同不会改变亚临界结论。

### A2.2 WPL 边界

WPL 可能增大 `zeta_eff`，但其对本题的最坏影响是把

`exp(-d_min/zeta_eff)`

推近 1。此时

`C_WPL <= 1 + z <= 7`

仍是 O(1) 增强，不随区域数 `k` 增长。WPL 不能恢复一阶 FGR 交叉项，也不能把二阶协同变成 `O(k)` 或 `O(k^2)` 的增强。

因此 WPL 对“同时协同”问题的结论是：

**有边界安全：WPL 最多把协同增强因子推到约 7，但不改变 `k` 饱和结构。**

不能声称：

**WPL 永远不参与任何热化。**

这属于串行/单区域尾巴问题，而不是同时协同问题。

### A2.3 串行级联边界

串行级联的物理结构是：

`R_1 -> R_2 -> ... -> R_k`

每一步只有一个邻近区域被激活。它绕开了“多个区域同时跃迁”的 FGR 正交性论证，因此不应作为本题已排除的对象。

本题可写成：

**排除的是并行/同时协同雪崩：多个亚临界区域通过共同矩阵元或共同共振一次性把热化率推过阈值。**

本题不能写成：

**排除所有多区域传播机制。**

串行级联应作为 LP1 论文 caveat，与 Griffiths 尾巴和 WPL 单区域延展效应一起处理。

## A侧最终表述

对 badly approximable `beta`、可分离 2D AA 势、单区域严格亚临界且讨论对象限定为“同时协同”时：

`Gamma_coop <= (sum_j Gamma_j) [1 + 6 exp(-d_min/zeta_eff)]`

即使取 WPL 最坏边界 `zeta_eff -> infinity`，协同增强也只到 `<=7`，不足以抵消 LP1 中阻塞/隧穿阈值的指数余量。

结论类型：有边界。
