## 北极星命题

**驱动矛盾：**
- 命题A（单区域充分）：L_max < ξ_perc ⇒ 任何单个亚临界区域的ETH耦合不足以触发系统级雪崩。多区域协同的附加效应因隧穿率Γ(d) ∝ exp(-d/ζ)的距离指数衰减而可忽略。
- 命题B（协同可能致命）：k个尺寸<L_max的亚临界区域在空间上以间距d排列，其协同耦合Γ_coop(k,d)可能超过单区域触发阈值，即使每个单独区域都是亚临界的。准周期势的确定性结构可能系统性地产生此类协同配置。

**关键量定义：**
- Γ_single(L)：尺寸L的单一低无序区域的热化率
- Γ_coop(k, d₁₂, ..., d_{k-1,k})：k个区域在给定间距下的协同热化率
- Γ_threshold：触发系统级雪崩所需的临界热化率
- 协同安全条件：max_{所有可能配置} Γ_coop < Γ_threshold

## Phase规划

### Phase 1：协同雪崩的数学模型 + 最坏情况估计

**目标：** 建立k个亚临界区域协同触发雪崩的定量判据，给出协同效应的上界估计。

**A任务（正规推导）：**
- 扩展S1的ETH-FGR框架：单区域Γ₁ = g²ρ(E)/W → k区域协同Γ_k
- 关键物理：k个区域的激发态是否通过多体共振形成集体模式？
- 计算协同耦合强度作为区域数k、间距d、单区域尺寸L的函数
- 确定Γ_coop(k,d) / Γ_single 的最大增强因子

**B任务（跨域突击）：**
- 从经典逾渗理论：k-核逾渗（k-core percolation）中协同效应的阈值条件
- 从量子信息：多体纠缠在空间分离区域间的建立速率（Lieb-Robinson界约束）
- 从随机矩阵理论：k个亚临界模式的avoided crossing统计 → 协同共振概率

### Phase 2：准周期势中协同配置的统计

**目标：** 计算准周期势中k个小区域空间分布的特征间距，判断协同是否在统计上可能。

### Phase 3：协同安全条件 + 黄金比例检验

**目标：** 给出L_max < f(ξ_perc, d_min)的显式条件，检验badly approximable β是否满足。

4. 随机矩阵理论：avoided crossing统计
