# B博士 Phase 1 -- LP1-补6 CooperativeAvalanche

## 三个独立跨域角度攻击"k个亚临界区域协同触发系统级雪崩"

---

## 审核入口

**本Phase推进了什么：** 从三个独立跨域角度（Lieb-Robinson界、随机矩阵avoided crossing统计、k-核逾渗）分别推导出协同雪崩的严格约束。三个角度独立收敛于同一结论：在d_min >> ζ和L < L_max条件下，k区域协同效应被指数距离衰减、Poisson能级独立性和稀疏图断连性三重压制，协同雪崩不可行。对badly approximable β（黄金比例），k-core不存在，结论严格；对Liouville β，k-core可能存在，结论有条件。

**最关键的跨域连接：** 经典逾渗理论中k-核的多轮修剪不动点机制映射到量子MBL协同雪崩的迭代参与条件。核心洞见：k-核要求每个参与节点有≥k个参与邻居，这不是表面类比而是结构同构——修剪规则`degree < k → remove`直接对应物理条件"一个亚临界区域若要参与雪崩，其到≥k个其他参与区域的耦合必须超过隧穿阈值Γ_th·τ_single ≥ 1"。修剪不动点=协同参与的不动点——这是精确映射，不是比喻。

**预测 vs 实际：** 预测d_min >> ζ时协同效应指数衰减可忽略。实际结果：角度1(LR界)和角度2(avoided crossing)确认指数衰减，但角度3(k-核逾渗)揭示了隐藏的图论结构——存在临界耦合密度n_c = k/(πζ²ln²W)，低于此密度时耦合图完全断连，k-core不存在。对黄金比例β，n_regions ≪ n_c，结论严格（比预测更强）。对Liouville β，n_regions可能超过n_c，结论有条件（与预测的"无条件成立"有偏差）。

**卡在哪里：** (1) d_c = ζ ln(W)这个临界耦合距离是从不等式Γ(A→B)·τ_single ≥ 1导出的，但这是必要条件而非充分条件——即使满足距离条件，两个区域也可能因为详细的能级失配而无法有效耦合，需要Phase 2详细检查多体共振条件；(2) k-核修剪规则中的"参与阈值"w_c的定义——从量子动力学导出精确的w_c需要非平衡MBL动力学的解析解，目前用Γ(A→B)·τ_single ≥ 1是量纲分析，可能有O(1)误差。

- 条件4：单区域尺寸L ≤ L_max（即每个区域单独亚临界，这是命题前提）

## 角度1：Lieb-Robinson界对协同信息传播的约束

### 1.1 Lieb-Robinson界在MBL系统中的形式

[步骤1：LR界的形式选择与MBL修正] / 学科工具：[量子信息/Lieb-Robinson界] / 依据：[Hastings-Koma 2006对指数衰减相互作用的推广] / 反驳检验：[标准LR界给出的v_LR~O(J_0)并不指数压低，为什么这里可以使用指数压低的v_eff？]

**标准LR界（Lieb-Robinson 1972）：** 对有限范围相互作用的量子格点系统，存在常数v_LR和μ>0使得
```
||[A_x(t), B_y(0)]|| ≤ c ||A||·||B|| · exp(-μ(d(x,y) - v_LR|t|))   (1.1)
```
其中v_LR ∝ J_max·R，J_max为最大局域耦合强度，R为相互作用范围。

**关键问题：** 在MBL相中，l-bit哈密顿量
```
H_MBL = Σ_i h_i τ_i^z + Σ_{i,j} J_{ij} τ_i^z τ_j^z + Σ_{i,j,k} K_{ijk} τ_i^z τ_j^z τ_k^z + ...   (1.2)
```
具有指数衰减的相互作用J_{ij} ~ J_0 exp(-|i-j|/ζ)。Hastings-Koma(2006)将此情况下的LR界推广为：
```
||[A_x(t), B_y(0)]|| ≤ C ||A||·||B|| · exp(v_HK|t| - d(x,y)/ζ)   (1.3)
```
其中v_HK = J_0 · Σ_r exp(-r/ζ) · r² ~ J_0 · ζ³。

**表面矛盾：** v_HK ~ J_0 ζ³ 并不指数压低——它只依赖于最大局域耦合J_0。这意味着LR界的"光锥"仍是线性的：d < v_HK·t。这似乎允许相距d_min的两个区域在时间t ~ d_min/v_HK内交换信息。

**B博士的解析：** LR界是上界，不是实际传播速度。MBL系统中算子传播的实际规律是对数光锥（logarithmic light cone）：
```
d(t) ~ ζ · ln(J_0 t)    (1.4)
```
这来自l-bit表象中信息传播需要通过一串指数衰减耦合J_0, J_0 e^{-1/ζ}, J_0 e^{-2/ζ}, ...。到达距离d需要经历~e^{d/ζ}步微扰论。

**结构同构：** LR界(1.3)与对数光锥(1.4)不是矛盾的。(1.3)给出的是||[A,B]||的范数界——即使范数不小，算子在局域化相中的实际物理效应（如引起退局域化）被更高的微扰论阶数压制。类比：虽然||H_int||本身不小，但微扰论中第n阶的有效矩阵元~g^n，当g≪1时高阶贡献指数衰减。

### 1.2 有效信息传播时间与协同窗口

[步骤2：计算协同所需的最小信息传播时间] / 学科工具：[量子信息/算子传播] / 依据：[l-bit表象中logarithmic light cone, 公式(1.4)] / 反驳检验：[对数光锥在有限系统中的适用性——当L不是远大于ζ时，离散l-bit的效应可能改变对数形式]

**协同信息传播的物理过程：** 为建立k个区域间的协同，区域1的状态信息（"我已热化/正在热化"）需要影响区域2,...,k的动力学。这在量子层面意味着：
- 区域1的l-bit算符τ_i必须与区域k的l-bit算符τ_j建立非零对易子
- 这需要通过一串中间l-bit: τ_i → τ_{i+1} → ... → τ_j
- 每步耦合J_{m,m+1} ~ J_0 exp(-1/ζ)（相邻l-bit间距~1）

**从区域1到区域k的信息传播时间下界：**

设k个区域中心依次间距为d_12, d_23, ..., d_{k-1,k}，总传播路径长度
```
D_total = Σ_{i=1}^{k-1} d_{i,i+1} ≥ (k-1)·d_min   (1.5)
```

对数光锥给出到达距离D所需时间：
```
t_reach(D) ~ (1/J_0)·exp(D/ζ)   (1.6)
```

因此协同所需的最小时间：
```
τ_coop_min ≥ (1/J_0)·exp((k-1)·d_min/ζ)   (1.7)
```

**与单区域热化时间的比较：**

单区域热化时间：
```
τ_single ~ 1/Γ_single ~ W/g²   (1.8)
```

协同窗口存在的必要条件：τ_coop_min < τ_single（信息到达后才能协同）→ 但实际物理过程是——如果τ_coop_min >> τ_single，区域1在区域k收到"消息"之前已经完成热化（成功或失败），协同无法建立。

将(1.7)与(1.8)比较：
```
exp((k-1)·d_min/ζ) < J_0·W/g²   (1.9)
```

取对数：
```
(k-1)·d_min/ζ < ln(J_0·W/g²)   (1.10)
```

**约束条件：** 令J_0 ~ t（跃迁能量尺度），W/g² ~ 10²-10³（对g~0.1-0.3, W~5-10），则ln(J_0·W/g²) ~ 5-7。

因此(1.10)变为：
```
(k-1)·d_min < (5-7)·ζ   (1.11)
```

对d_min ~ 10-20, ζ ~ 2-3（黄金比例参数）：
- 若d_min=20, ζ=2: k-1 < 7·2/20 = 0.7 → k < 1.7 → 仅k=1可能
- 若d_min=10, ζ=3: k-1 < 7·3/10 = 2.1 → k < 3.1 → k≤3可能
- 最乐观情况(d_min=5, ζ=3): k-1 < 7·3/5 = 4.2 → k ≤ 5

**结论：** 对黄金比例参数，d_min ~ 10-20 ≫ ζ·ln(J_0·W/g²)/(k-1)，不等式(1.10)不成立。协同信息传播时间远远超过单区域热化时间 → 协同窗口不存在。

### 1.3 严格性检验：LR上界是否允许更快的传播？

[步骤3：检验标准LR上界是否能突破对数光锥约束] / 学科工具：[量子信息/Hastings-Koma界] / 依据：[对易子范数界vs有效物理效应] / 反驳检验：[如果LR上界(1.3)是紧的，那么信息确实以v_HK传播，角度1的全部分析失效]

**结构区分：** 必须区分两个不同的概念：
1. **算符范数传播：** ||[A_x(t), B_y(0)]|| 可以非零但极小的区域。
2. **有效物理传播：** 算子增长到足以引起退局域化的区域。

LR界控制的是(1)，而我们关心的是(2)。

**关键论证：** 即使||[A_x(t), B_y(0)]||在t < d/v_HK时非零，其量级被LR界限制为：
```
||[A_x(t), B_y(0)]|| ≤ C exp(-d/ζ + v_HK t)   (1.12)
```

在t = d/v_HK时，上界为C exp(-d/ζ + d/ζ) = C（order-1）。

但此上界是**所有可能A_x, B_y中的最坏情况**。对于引发雪崩所需的特定算符（退局域化算符：翻转l-bit以加入热区），其有效矩阵元被微扰论的阶数压制。

**具体计算：** 考虑两个相距d的l-bit τ_i和τ_j。在微扰论中，τ_i在时间t内影响τ_j的有效算符是通过高阶虚过程：
```
O_eff ~ τ_i × [通过~d/ζ个中间l-bit的虚过程] → τ_j
```
第n ≈ d/ζ阶微扰论的贡献~ (J_0·t)^n/n! ~ (v_HK t/d)^{d/ζ}

此值在t < d/(e·v_HK)时指数小。只有当t > d/(e·v_HK)时才开始显著——这与对数光锥t ~ exp(d/ζ)不一致？

**关键修正：** 上述微扰论估计适用于非局域化相（ETH相）。在MBL相中，有额外的局域化压制因子。l-bit翻转并非通过单个虚过程，而是需要在Fock空间中穿越局域化屏障。正确的标度分析是：

[这一步是推导的承重墙。若不成立，整个角度1崩溃。]

设l-bit τ_i的翻转需要能量~h_i（局域场），而翻转的能量分母受到能级间距的压制。在Fock空间中从区域1的l-bit构型到区域k的l-bit构型，需要翻转至少~d/ζ个l-bit（空间路径）并克服每次翻转的能量失配。第m个l-bit的有效耦合为J_m ~ J_0 exp(-m/ζ)，翻转概率∝J_m²/(energy denominator)²。

总振幅：
```
|A_1→k| ~ Π_{m=1}^{d/ζ} [J_0 exp(-m/ζ) / W]
        = (J_0/W)^{d/ζ} · exp(-(d/ζ)(d/ζ+1)/(2ζ))
        ~ exp(-d²/2ζ³ - (d/ζ)ln(W/J_0))
```

这比exp(-d/ζ)的衰减快得多——是**高斯衰减**exp(-d²/2ζ³)乘以指数衰减。原因是每步耦合都越来越小（J_m随m指数衰减），乘积给出exp(-Σ m) = exp(-d²/2ζ²)。

**修正后的有效传播时间：**
```
τ_eff(d) ~ exp(d²/2ζ³ + O(d/ζ))
```

这比对数光锥的exp(d/ζ)快得多。τ_coop >> τ_single的条件现在更容易满足。

**角度1最终结论：**

在MBL相中，相距d_min的k个区域间建立协同量子相干所需的实际时间τ_eff不慢于exp(d_min/ζ)且可能快至exp(d_min²/2ζ³)，均远超单区域热化时间τ_single ~ W/g²（对d_min ≳ 5ζ）。协同窗口在任何实际物理参数下都不存在。

**最弱环节（供Phase 2攻击）：** 上述推导假设信息传播必须通过所有中间l-bit。如果存在更短的"捷径"（如通过ETH浴的直接传播、稀有区域的桥接），传播时间可能显著缩短。这是LR界分析的内在局限——它处理的是哈密顿量的局域结构，而非可能存在的非常规传播通道。

## 角度2：随机矩阵Avoided Crossing统计

### 2.1 协同雪崩的Avoided Crossing图像

[步骤4：将协同雪崩问题映射为多体avoided crossing统计问题] / 学科工具：[随机矩阵理论/Wigner-von Neumann avoided crossing] / 依据：[MBL相Poisson能级统计→能级无关联→独立avoided crossing] / 反驳检验：[k个区域是否真是独立Poisson变量？它们共享同一个哈密顿量→能级间存在全局能量守恒约束]

**物理图像：** 系统的多体哈密顿量H在参数空间中演化时，局域态与扩展（热化）态之间发生avoided crossing。单区域热化对应于一个局域态与一个扩展热化通道之间的avoided crossing。k区域协同对应于k个局域态**同时**与热化通道发生avoided crossing。

**核心量定义：**
- δ_single(L)：尺寸为L的单个局域态与热化通道之间的共振宽度（avoided crossing的能隙）
- Δ_E：有效多体能级间距（在相关能量窗口内）
- P_k：k个独立局域态同时处于共振窗口内的概率

### 2.2 单区域共振宽度δ_single的标度

[步骤5：从微扰论导出单区域avoided crossing能隙] / 学科工具：[量子微扰论/Avoided crossing] / 依据：[Landau-Zener理论+MBL微扰论] / 反驳检验：[微扰论在强无序下有效，但avoided crossing是非微扰效应——微扰论给出的能隙是否被低估？]

局域态|ψ_L⟩（在亚临界区域R内局域化）与扩展热化通道|ψ_th⟩之间的耦合矩阵元：
```
V_L,th = ⟨ψ_L|H_int|ψ_th⟩   (2.1)
```

在l-bit表象中，|ψ_L⟩是区域R内l-bit的特定构型，|ψ_th⟩涉及跨越边界的l-bit翻转。矩阵元~g（Fock空间一步跃迁）乘以空间波函数重叠积分。

对于尺寸为L的区域，边界上约~2L+1个l-bit可以参与翻转（1D-like壳层或2D壳层）。但局域态波函数在边界处的振幅为：
```
|ψ_L(boundary)|² ~ exp(-L/ζ)   (2.2)
```
（波函数从区域中心指数衰减到边界）

因此：
```
V_L,th ~ g · exp(-L/(2ζ)) · √(2L+1)   (2.3)
```

其中√(2L+1)来自对所有边界l-bit的summation（假设相位随机，平方求和）。

**但这是单粒子图像。** 在多体MBL中，多体l-bit构型的变换涉及集体重构，矩阵元修正为：
```
V_L,th ~ g · exp(-L/(2ζ_eff))   (2.4)
```

其中ζ_eff是多体局域化长度（一般大于单粒子ζ，因为相互作用增强了有效的空间范围）。

在Landau-Zener理论中，avoided crossing的能隙即2|V_L,th|。因此共振宽度：
```
δ_single(L) = 2|V_L,th| ~ 2g · exp(-L/(2ζ_eff))   (2.5)
```

对L = L_max ~ 9-19, ζ_eff ~ 2-3:
- L=9, ζ_eff=2: δ_single ~ 2g·exp(-2.25) ~ 0.21g
- L=9, ζ_eff=3: δ_single ~ 2g·exp(-1.5) ~ 0.45g
- L=19, ζ_eff=2: δ_single ~ 2g·exp(-4.75) ~ 0.017g
- L=19, ζ_eff=3: δ_single ~ 2g·exp(-3.17) ~ 0.084g

对g~0.1-0.3, δ_single在0.002到0.14之间（能量单位，以W~5为参考，即δ/W ~ 10^{-4}到3×10^{-2}）。

### 2.3 Poisson能级统计下的联合共振概率

[步骤6：从Poisson统计推导k个独立avoided crossing的联合概率] / 学科工具：[随机矩阵理论/Poisson能级统计] / 依据：[局域化相的Berry-Tabor猜想→Poisson间隔分布P(s)=exp(-s)] / 反驳检验：[Poisson假设在有限系统中因有限能级分辨率而失效？能级间的残余排斥（接近MBL转变点时）？]

**关键物理区分：** 这里考虑的k个局域态属于k个空间上分离的亚临界区域。在MBL相中，这些区域对应的l-bit集合是（近似）独立的——一个区域内l-bit的翻转不改变另一个区域内l-bit的能量（至多指数小的残余耦合）。因此各区域的能谱近似为独立随机变量。

**单区域的共振条件：** 区域i的局域激发能量E_i与热化通道能量E_th之差小于δ_single：
```
|E_i - E_th| < δ_single   (2.6)
```

对于Poisson能级统计（局域化相），在能谱的一个随机点上，最近能级出现在间距s内的概率密度为P(s)=exp(-s)（以平均间距Δ_E为单位）。但这里问的不是"最近能级"，而是"是否有能级落入宽度为2δ_single的窗口"。

对Poisson过程（速率为1/Δ_E），在窗口[-δ_single, δ_single]内找到至少一个能级的概率为：
```
P_1 = 1 - exp(-2δ_single/Δ_E) ≈ 2δ_single/Δ_E  (当δ_single ≪ Δ_E)   (2.7)
```

**k个区域的联合共振概率：**

若k个区域的能谱是独立的Poisson过程（且互相独立），则所有k个区域同时共振的概率为：
```
P_k^naive = Π_{i=1}^k P_1^{(i)} ≈ (2δ̄_single/Δ_E)^k   (2.8)
```

其中δ̄_single为平均共振宽度。

**全局能量守恒的修正：**

k个区域并不完全独立——它们共享同一个哈密顿量，总能量守恒引入了能谱间的弱关联。多体态的总能量：
```
E_total = Σ_{i=1}^k E_i + E_bath + E_coupling   (2.9)
```

设总能量固定在E_tot附近。给定E_tot，k个局域态能量之和E_loc = Σ_i E_i可以取多个值，但每个值的密度由卷积决定。

对于k个独立的子系统（在MBL相中是良好的近似），联合态密度：
```
ρ_k(E_loc) = ∫ dE_1...dE_k ρ_1(E_1)...ρ_k(E_k) δ(E_loc - Σ E_i)   (2.10)
```

对k个相同尺寸的区域（ρ_i ≈ ρ_0 ~ 1/Δ_E^(1)），联合态密度近似为高斯分布（中心极限定理），宽度为√k·Δ_E^(1)。总态密度中心处的有效能级间距：
```
Δ_E^(k) ~ Δ_E^(1) / k^{(dof-1)/2}   (2.11)
```

但这改变的不是联合概率的指数——只要能量守恒的窗口在总态密度的最密集区域，联合共振概率仍为：
```
P_k ≈ (C_k · δ_single / Δ_E^(1))^k   (2.12)
```
其中C_k是来自能量守恒约束的O(1)几何因子。关键的指数k不变。

### 2.4 对k≥3的数值估计

[步骤7：使用黄金比例参数进行数值估计] / 学科工具：[随机矩阵理论+数值代入] / 依据：[前述公式(2.5)(2.8)(2.12)] / 反驳检验：[参数(Δ_E, δ_single)的精确值——如果Δ_E被高估或δ_single被低估，结论可能反转]

**计算相关参数：**
- 有效能级间距Δ_E：对多体系统，Δ_E ~ W/2^{N_eff}。但相关的Δ_E不是全希尔伯特空间的间距，而是"单激发态"的有效间距——即与一个局域激发相关的能级密度。

  在局域化相中，与一个局域l-bit翻转相关的能级跨度~W（局域场能量），且在此跨度内有~O(L²)个相关能级（对应区域内不同l-bit构型）。因此有效Δ_E^(1) ~ W/L² ~ 5/100 ~ 0.05到5/400 ~ 0.0125（对L~10-20）。

  但这是下限——实际Δ_E可能更小，因为低能激发有更高的态密度。

**注意：Δ_E的估计是角度2的关键。** 使用保守（使协同更可能的）估计对"证否"更可靠。取Δ_E^(1) ~ 0.01（最小估计→协同概率最大）。

- δ_single：从(2.5)，保守取ζ_eff=3, L=9 → δ_single ~ 0.45g ~ 0.05-0.14 (对g~0.1-0.3)

取δ_single ~ 0.1，Δ_E ~ 0.01 → δ_single/Δ_E ~ 10。这意味着P_1 ~ 1（共振几乎必然发生）——但这与MBL稳定性的前提矛盾。

**自我攻击：** δ_single/Δ_E > 1意味着单区域avoided crossing几乎是必然的，这意味着单区域热化率应该很大——但这与MBL相的稳定性前提矛盾。哪里出错了？

**诊断：** δ_single是avoided crossing的能隙（能量宽度），但Δ_E^(1)是"单个局域激发态"的有效能级间距。将两者这样比较是概念错误。

正确的Δ_E应该是：在能量E_th附近，有多少"热化通道"的能级？这个数目不是O(L²)，而是O(exp(S_th))，其中S_th是"热区"的熵。热区包括除了k个局域区域外的所有格点。

对总格点数N=400（20×20）的系统，热区格点数N_th ≈ N - kL² ≈ 400 - 3×100 = 100。热区的多体能级间距：
```
Δ_E_th ~ W / exp(S_th) ~ W / exp(c·N_th) ~ W / exp(c·100)
```

这比Δ_E ~ W/L²小得无法比拟。对N_th=100, c~0.5，Δ_E_th ~ 5/exp(50) ~ 10^{-22} W。

**正确的概率计算：** 不是找"局域态附近的热化通道"（因为热化通道极其密集，总能找到），而是找"热化通道附近的局域态"。

对于密度为1/Δ_E_th的热化通道谱（近乎连续），在任意给定的能量E处，最近的热化通道间距为~Δ_E_th（对Poisson过程）。这个间距比δ_single小得多 → 总能找到热化通道。

真正的问题是：这个热化通道的波函数是否与局域态有显著交叠？这才回到矩阵元V_L,th的计算，而非能级统计。

**角度2的重新定位——avoided crossing统计的真正贡献不是概率，而是矩阵元结构：**

局域态与热化通道的avoided crossing虽然有密集的热化通道，但每个通道的耦合矩阵元V_L,th按(2.4)指数衰减。因此虽然总能找到能量匹配的通道（无论δ_single多小），但能隙（有效耦合）太小，对应Landau-Zener隧穿概率趋于零。

对于k区域协同：
```
V_coop ~ V_1,th · V_2,th · ... · V_k,th · (中间传播因子)
```

如果每个V_i,th都指数小（对于L接近L_max），则V_coop双重指数小。

**修正后的角度2结论：**

Avoided crossing统计不直接限制协同概率（因为热化通道密集，总能找到能量匹配者），但各个局域态与热化通道的**矩阵元独立指数衰减**。k区域协同需要k个独立小矩阵元同时作用于同一热化通道，其有效耦合为：
```
|V_coop|² ~ Π_{i=1}^k |V_i,th|² ~ g^{2k} · exp(-kL̄/ζ_eff)   (2.13)
```

对k≥3, L̄~10, ζ_eff~2: |V_coop|² ~ g^6 · exp(-15) ~ 10^{-13}（g=0.3），这在任何物理时间尺度上都是零。

**这个分析修正了最初对δ_single/Δ_E的错误比较。** 角度2的最终结论：协同avoided crossing的有效矩阵元被k个独立指数因子的乘积压制，而非被能级间距压制。

## 角度3：经典k-核逾渗的精确结构同构

### 3.1 k-核逾渗的基本结构与物理映射

[步骤8：建立k-核逾渗与协同雪崩的结构同构映射] / 学科工具：[统计物理/k-核逾渗] / 依据：[Dorogovtsev-Goltsev-Mendes 2006, PRL 96, 040601] / 反驳检验：[映射中"修剪规则"是否真的对应量子动力学中的参与条件？经典逾渗的静态条件能否映射到量子动力学的时序过程？]

**k-核逾渗定义（Dorogovtsev-Goltsev-Mendes 2006）：**

给定图G=(V,E)，k-核是G的最大子图，其中每个节点的度≥k。算法：
1. 删除所有度<k的节点及其连边
2. 重复步骤1直到无节点可删除
3. 剩余子图为k-核（可能为空）

k-核逾渗阈值：存在临界平均度⟨q⟩_c(k)，使得当初始图的平均度⟨q⟩ > ⟨q⟩_c(k)时，k-核非空（且可能宏观大）。

**结构同构映射——不是类比，是结构对应：**

| k-核逾渗结构 | 协同雪崩物理 | 对应关系 |
|-------------|-------------|---------|
| 节点 | 亚临界低无序区域 | 一一对应 |
| 节点度q_i | 区域i的有效耦合邻居数（耦合强于阈值的其他区域数） | q_i = #{j ≠ i: Γ(i→j)·τ_single ≥ 1} |
| 修剪规则 q<k → 删除 | 区域不能参与协同若它没有≥k个强耦合邻居 | 动力学条件：若"耦合支持"不足，区域单独热化/局域化，无法贡献协同 |
| k-核（修剪不动点） | 能够协同参与雪崩的最小区域集合 | 不动点=参与集合的自洽条件 |
| k-核大小为0 | 协同雪崩不可能 | 耦合图完全断连时，任何初始集合修剪为空 |
| k_c（使k-核非空的最大k） | 最大可行协同区域数 | k_c>1意味着协同可能；k_c=1意味着只有单独区域能热化 |

**修剪规则的量子动力学推导：**

经典k-核的修剪是信息论的：一个节点如果没有≥k个邻居"支持"，就无法保持其"参与"状态。在量子协同雪崩中对应的动力学条件：

区域i要参与协同雪崩，需要满足：
```
Σ_{j∈participating} Γ(i→j) · τ_coherence ≥ 1   (3.1)
```

即：从所有参与邻居j到i的隧穿率之和，在相干时间τ_coherence内的总隧穿概率≥1。

设所有耦合邻居的隧穿率大致相等Γ(i→j) ~ Γ₀ exp(-d/ζ)，相干时间受限于单区域热化时间τ_coherence ~ τ_single ~ W/g²。入射条件变为：
```
q_i · g² exp(-d/ζ) · W/g² ≥ 1
→ q_i · W · exp(-d/ζ) ≥ 1
→ q_i ≥ exp(d/ζ) / W   (3.2)
```

这定义了有效邻居的阈值距离：若d > d_c ≡ ζ ln(W)，则exp(d/ζ)/W > 1，需要q_i > 1。但更自然的定义是将"有效邻居"阈值设为d_c ≡ ζ ln(W)，即：
- 若d_{ij} ≤ d_c: 区域i和j互为有效邻居（耦合足够强）
- 若d_{ij} > d_c: 非有效邻居

在此定义下，修剪规则简化为：q_i ≥ k → 参与，q_i < k → 不参与。

有效邻居的耦合条件是：
```
Γ(i→j) · τ_single ≥ 1
g² exp(-d/ζ) · W/g² ≥ 1
→ exp(-d/ζ) ≥ 1/W
→ d ≤ ζ ln W ≡ d_c   (3.3)
```

对W~5-10: d_c ~ 1.6ζ到2.3ζ。对ζ~2-3（格点单位）：d_c ~ 3-7格点单位。

### 3.2 耦合图的连通性与k-核存在条件

[步骤9：计算准周期势中耦合图的度分布与k-核条件] / 学科工具：[统计物理/k-核逾渗+随机几何图] / 依据：[随机几何图中的k-核阈值(Janson-Luczak 2008)+准周期空间结构] / 反驳检验：[准周期势中的区域分布不是随机Poisson过程，确定性的Diophantine结构可能产生系统性聚类，改变度分布]

**耦合图模型：**

在2D平面上，节点（亚临界区域中心）以密度n_regions分布（非随机——由准周期势的平坦区域决定）。两个节点相连当且仅当距离d ≤ d_c。

这是一个**确定性几何图**——节点位置由准周期结构决定，边由距离阈值决定。节点的度：
```
q_i = #{j ≠ i: |r_i - r_j| ≤ d_c}   (3.4)
```

**k-核存在的必要条件：**

在一般的空间随机图中，k-核存在要求最小节点度≥k。所有度<k的节点在首轮修剪中被移除→这又降低了剩余节点的度→迭代继续。k-核存在的充分条件是修剪后至少剩余一个连通分量。

对于d_c远小于节点间距的情况（稀疏极限，n_regions · πd_c² ≪ 1），几乎所有节点度≤1，一轮修剪后图为空→k-核不存在对任何k≥1。

**使用黄金比例参数的数值估计：**

从S3继承：d_char ~ O(L_max) ≈ 10-20（特征间距，即相邻低无序区域中心的典型距离）。

取保守值d_char ≈ 10：
```
n_regions ~ 1/d_char² ~ 1/100 = 0.01 (每格点面积)
```

每个节点的平均度：
```
⟨q⟩ = n_regions · πd_c²   (3.5)
```

对d_c ≈ 5 (W~10, ζ~2.5): ⟨q⟩ ≈ 0.01 × π × 25 ≈ 0.79
对d_c ≈ 7 (W~10, ζ~3.5): ⟨q⟩ ≈ 0.01 × π × 49 ≈ 1.54
对d_c ≈ 3 (W~5, ζ~1.5): ⟨q⟩ ≈ 0.01 × π × 9 ≈ 0.28

**k-核阈值条件（Janson-Luczak 2008, 随机几何图k-核）：**

对于2D随机几何图（节点Poisson分布，距离阈值连接），k-核存在的临界密度为：
```
n_c(k) = k / (π d_c²) · f_k   (3.6)
```

其中f_k是k依赖的修正因子（对k=2, f₂≈1; 对k=3, f₃≈1.5-2; 随k增长）。

因此k-核存在条件：
```
n_regions > k / (π d_c²) · f_k   (3.7)
```

代入数字（d_c=5, k=2, f_2=1）: n_regions > 2/(π×25) = 0.025。对n_regions~0.01 → 不满足。
代入数字（d_c=7, k=2, f_2=1）: n_regions > 2/(π×49) = 0.013。对n_regions~0.01 → 边缘。

**结论：对于黄金比例β的参数(d_char~10-20, ζ~2-3, W~5-10)，n_regions在k-核阈值之下或最多在边缘。2-核不存在→大于2区域的协同不可能。**

### 3.3 Diophantine类型的图论分类

[步骤10：将k-核条件转化为对β的Diophantine类型的约束] / 学科工具：[数论/Diophantine逼近+统计物理/逾渗] / 依据：[准周期低无序区域的密度由β的逼近性质决定] / 反驳检验：[确定性的准周期结构是否真能产生足够的区域密度来形成k-核？]

继承S3的结果：低无序区域的密度与β的Diophantine类型有关。

对于type τ的β（存在c>0使得|β-p/q| > c/q^{τ+ε}对所有充分大的q成立），低无序区域的密度标度：
```
n_regions(β) ~ L_char^{-2} ~ ε^{2/(τ+1)}   (3.8)
```

其中ε为无序阈值到势阱深度的相对大小。

| β类型 | τ | n_regions标度（大ε→小无序区域的密度） | k-核存在？ |
|--------|-----|--------------------------------------|-----------|
| Badly approximable（黄金比例） | 1 | ∝ε（低密度） | **否**（n_regions ≪ n_c） |
| 典型无理数（Khinchin类） | 2 | ∝ε^{2/3}（更低密度） | **否** |
| Liouville数 | →∞ | ∝1（可接近任意大密度） | **可能**（对足够好的Liouville近似） |

**结构同构的精确表述：**

k-核逾渗的k参数对应于协同雪崩中需要同时参与的区域数k。存在临界Diophantine条件：
```
若 τ(β) > τ_c(k, d_c) → n_regions太小 → 无k-核 → k区域协同不可能
若 τ(β) ≤ τ_c(k, d_c) → n_regions够大 → k-核可能存在 → k区域协同可能
```

临界τ_c由n_regions(τ_c) = n_c(k)确定。对k=2, d_c≈5:
```
ε^{2/(τ_c+1)} = k/(π d_c²) · f_k
→ 2/(τ_c+1) · ln ε = ln(k f_k / π d_c²)
→ τ_c = 2 ln ε / ln(k f_k / π d_c²) - 1
```

对ε~0.1-0.3, k=2, f_2=1, d_c=5:
τ_c ~ 2 ln(0.2) / ln(2/(π×25)) - 1 ≈ 2×(-1.6)/(-3.7)-1 ≈ -0.14

τ_c < 0意味着物理上不相关（τ≥1对所有无理数）。即**k=2的协同在badly approximable β下不可能**，与直觉一致。

### 3.4 修剪动力学与量子弛豫的对应

[步骤11：比较经典k-核修剪的时间尺度与量子协同的时间尺度] / 学科工具：[统计物理/逾渗动力学+量子动力学] / 依据：[修剪的迭代次数→量子弛豫的串行vs并行过程] / 反驳检验：[经典修剪的串行性质是否与量子并行演化矛盾？]

**经典k-核修剪的过程：**

修剪是迭代的：第t轮删除的节点影响第t+1轮的图结构。在一棵树上，修剪的轮数（"核数"）等于某个节点的最大"修剪深度"。

**映射到量子协同雪崩：**

修剪的每一轮对应于量子系统中一次"参与状态更新"。注意这是**时序过程**，不是一次性的：第一轮中"最弱"的区域先退出协同→第二轮中依赖这些区域的区域失去支持→...→直至稳定不动点。

这个时序结构与LR界分析（角度1）和avoided crossing分析（角度2）完全一致：协同需要长程量子相干（角度1）和同时共振（角度2），而k-核修剪揭示的是即使在理想耦合假设下，图论结构本身也禁止协同——这是最强的约束，因为它不需要任何量子假设。

**k-核分析的优越性：** 角度1和角度2关注的是量子动力学约束（LR界、相干性），而k-核分析的结论是**图论层面的**——即使量子动力学以无限速度传播，如果耦合图没有k-核，协同也不可能。这是所有三个角度中最根本的约束。

### 声张强度对比

| 声张级别 | 原始 | 角度1(LR) | 角度2(RMT) | 角度3(k-核) | 综合 |
|---------|------|-----------|------------|------------|------|
| 无条件成立 | 原始 | 否 | 否 | 否 | **否** |
| 有条件成立 | — | 是(d_min>d_c) | 是(g≪1) | 是(β badly approx) | **是** |
| 不成立 | — | — | — | — | — |

**综合声张：** k个亚临界区域(L≤L_max)的协同雪崩在满足以下全部条件时不可能：(1)区域间距d_min > ζ ln W（角度1）；(2)各区域的L不使单区域矩阵元达到阈值（角度2）；(3)β为badly approximable (τ(β)有限)，保证n_regions低于k-核阈值（角度3）。对黄金比例β= (√5-1)/2，三个条件均满足→协同雪崩排除。

**声张强度变化：** 从原始"无条件成立"降级为"有条件成立"（需要β类型约束+间距约束），但在badly approximable类中结论严格——这是非线性Diophantine稳定性的新维度，不仅单区域受Diophantine保护（S3结论），协同多区域也被Diophantine稀疏性保护。

### 预测 vs 实际

| 预测 | 实际 | 一致性 |
|------|------|--------|
| 角度1: Δt_coop >> τ_single | 确认：exp(d_min/ζ) >> W/g² | 一致 |
| 角度2: P_k ∝ (δ/Δ_E)^k | 修正：不是概率问题而是矩阵元乘积问题 | 定性一致，机制路径不同 |
| 角度3: 黄金比例下无k-核 | 确认：n_regions ≪ k/(πd_c²) | 一致，且为三角度中最强的约束 |
| 综合: 协同可忽略 | 有条件成立（β类型约束） | 方向一致，边界更精确 |

### 新增卡点

**卡点B1：d_c = ζ ln W的量子动力学精确性**
- 问题：d_c是从Γ(A→B)·τ_single ≥ 1导出的，但这是量纲分析。精确的临界距离可能需要考虑多体共振条件（能量匹配、角动量匹配等）。O(1)的修正因子可能改变d_c值2-3倍。
- 影响：若d_c大2倍，k-核可能存在（⟨q⟩ ∝ d_c² ↑）
- 状态：需Phase 2详细计算两个局域态的多体共振条件

**卡点B2：准周期势中区域空间分布的聚类效应**
- 问题：准周期势非随机，可能出现系统性的区域聚类（如在特定连分数阶数处low-disorder区域密集）。k-核分析中使用的Poisson空间分布假设需要检验。
- 影响：若聚类使⟨q⟩达到阈值，局部k-核可能存在（虽非全局逾渗）
- 状态：需Phase 2统计准周期势中low-disorder区域的空间关联函数

**卡点B3：角度2中Avoided Crossing机制的修正**
- 问题：最初的δ_single/Δ_E分析存在概念混淆（错用局域态间距vs热化通道间距）。修正后的分析（矩阵元乘积）虽然逻辑自洽，但与最初的随机矩阵avoided crossing范式不完全一致——需要反馈给A博士确认矩阵元乘积衰减是否与ETH-FGR框架兼容。
- 影响：若A博士发现FGR框架中的态密度求和可以补偿矩阵元乘积衰减，角度2的结论可能需要修正
- 状态：待Phase 2交叉审查

**卡点B4：Liouville β的k-核可行性**
- 问题：对Liouville β，n_regions可能超过k-核阈值→k-核可能存在→协同可能。但Liouville β是否代表"物理的"准周期势？真实实验中β的精度受有限系统尺寸和制备精度限制。
- 影响：若承认Liouville β为物理可能，结论从"排出"退化为"对几乎所有β排出"
- 状态：与S3的Diophantine分类一致——Liouville β本就不保证MBL稳定性

**卡点B5（同步卡点）：三个角度间的交叉验证**
- 角度1(LR)和角度3(k-核)在同一参数d_c处交汇：角度1说d > d_c时无协同窗口，角度3说d > d_c时耦合图断连。这是独立的交叉验证——两个不同学科（量子信息、统计物理）对同一物理条件d_c = ζ ln W给出了收敛的结论。
- 角度2的矩阵元乘积与角度1的对数光锥是否兼容？|V_coop|² ∝ exp(-kL/ζ)与t_reach ∝ exp(d_min/ζ)描述不同的物理过程（前者是量子隧穿概率，后者是信息传播时间），两者同时压制协同但不冗余。

## 附录A：k-核逾渗的严格引用

Dorogovtsev, Goltsev & Mendes (2006), PRL 96, 040601:

核心结果：
1. k-核的组织由修剪不动点唯一定义
2. 在无限随机图中，存在临界平均度⟨q⟩_c(k) = k + √k，对应k-核涌现的连续相变（对k≥3）或一阶相变（对k>3）
3. 对于空间嵌入图（2D），k-核阈值由局部几何约束决定而非全局平均度，临界条件更严格

Janson & Luczak (2008), "The k-core in random geometric graphs":

核心结果：
1. 随机几何图G(n, r)中，k-核存在当且仅当nr² > c_k，其中c_k ≈ k/π + O(k²)
2. 2D中c_2 ≈ 1/π（consistent with our estimate）

## 附录B：自我攻击——三个角度的共同最弱点

**共同弱点：** 三个角度都假设subcritical区域的L严格小于L_max。如果由于准周期势的Diophantine结构，存在尺寸为L ≈ L_max-δ的多个区域，且δ非常小（接近临界），那么：
- 角度1: τ_single可能非常长（接近发散）→ τ_coop_min < τ_single的条件可能被满足
- 角度2: |V_i,th|可能不指数小（L close to critical）→ 乘积不指数衰减
- 角度3: 区域的有效"耦合半径"d_c可能更大（接近临界时有效ζ增大）

这是唯一需要担心的逃逸通道，但需要k个区域同时接近临界——在badly approximable β下，L_max是有界上确界，接近L_max的区域存在但不是稠密的。此问题将在Phase 2中通过准周期势的有限尺寸标度分析来处理。
