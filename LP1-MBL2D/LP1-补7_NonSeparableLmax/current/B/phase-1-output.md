⚡ **卡在哪里（如果有）：** 角度3的Fourier rank分类给出了"\exists 2D低无序区域"的充分条件（rank-N准晶体中N-2维低无序子流形），但从该充分条件到"真2D（两个方向均无限生长）"还需验证该子流形的拓扑维数是否≥2。对WPL的N=2情形，子流形维数=0（离散WPL线），不形成2D；对N=4，可能存在2维子流形，需进一步计算。

## §1 结论预测

### 命题重述

**驱动矛盾：**
- **命题A（L_max推广成立）：** 无论势能是否可分离，WPL条带作为1D低无序通道，其垂直宽度w受Diophantine条件约束，w < ξ_perc时条带是1D热库而非2D罕见热区——1D热库不能热化2D MBL系统。L_max概念推广至包含1D条带几何后，有效判据从"最大2D块状尺寸"变为"max(2D块尺寸, d_eff·w)"，其中d_eff<2保证推广后的有效尺寸仍然满足MBL稳定条件。
- **命题B（WPL威胁MBL）：** 非可分离势中WPL沿特定方向势能恒定（cos(2πβ·r)=const），若该恒定值恰好|V|<W_c，整条WPL成为无界低无序通道。即便垂直宽度有界，无界长度方向提供了发散的多体态密度——1D热库在L→∞方向的态密度发散最终能热化2D系统。

### 结论方向/量级预测

若命题A成立：
- WPL条带的"有效维数"d_eff = 1 + min(1, w/ξ_perc)
- w < ξ_perc时：d_eff → 1（严格1D热库），2D热化需要d_eff → 2
- 条件w << ξ_perc下，WPL是1D热浴——从热力学第二定律：1D热浴的熵容量 ~ exp(c_1·L)（L为条带长度），但2D局域系统的熵容量 ~ exp(s_2·A)（A为面积）。热化需要热浴熵≥系统熵，对条带：L→∞时熵发散但在每个2D区域只有有限条带通过，实际耦合熵 ~ L_eff（通过长度）× exp(c_2·w)（垂直方向态密度），由于w有界，有效耦合强度不足以热化周边2D区域。

若命题B成立：
- 需要w > ξ_perc（垂直宽度超过渗流关联长度）
- 或需要条带密度足够高（多条WPL形成网络）
- 或需要d_eff → 2的标度交叉

**最可能被证伪的环节：** 若w > ξ_perc（即Diophantine约束给出的垂直宽度大于渗流关联长度），条带从1D crossover到有效2D。对典型参数：β = (√5-1)/2 ≈ 0.618（黄金比例），W_c/J ≈ 20-30，ε = W_c/W ≈ O(1)。条带的垂直宽度w由Diophantine条件给出：w ~ 1/(2π|β|·ε) ~ O(1)（以格点数计）。而ξ_perc ~ |p_block - p_c|^{-ν} ~ |0.667 - 0.593|^{-4/3} ~ O(30)。w ≈ 2-3 << ξ_perc ≈ 30 → WPL是严格1D的。证伪命题A需要证明存在参数区间使w > ξ_perc——这在典型MBL参数下不成立。

## §2 角度1：2D渗流理论中1D inclusion的精确角色

### 2.1 经典结果：1D无限开线不改变2D逾渗阈值

**定理（Grimmett 1999, Percolation §5.5, 非正式表述）：** 设Λ为ℤ²上边逾渗模型，每条边以概率p独立开放。在Λ中嵌入一条无限长的"强制开放"线L（即L上的所有边无条件设为开放）。则系统的逾渗阈值p_c保持不变：

\[
p_c(\mathbb{Z}^2 \cup L) = p_c(\mathbb{Z}^2) = \frac{1}{2}
\]

**证明思路（结构同构核心）：** 逾渗阈值由"是否存在连接左右边界和上下边界的无限簇"定义。1D线L的容量在2D中是零测度的（1D Lebesgue测度在ℝ²中为0），因此：
1. L可以连接左右边界（若L水平）或上下边界（若L垂直），但不能同时连接两个方向。
2. 要形成同时跨越两个方向的连通簇，必须在L之外还有开放的2D路径。这些路径的出现阈值仍由2D逾渗的p_c决定。
3. 形式化：含1D线的逾渗概率函数θ_2D(p)满足θ_2D(p) = P_p(∃∞-cluster)，1D线贡献的附加项对概率测度为零测集。

**更精确的表述（Grimmett §5.5推论）：** 设G为包含一条无限直线L的2D图。对边逾渗，θ(p) > 0当且仅当p > p_c(original 2D lattice)。L的存在不改变p_c，也不改变临界指数β（θ(p) ~ (p-p_c)^β）。

### 2.2 结构同构：渗流1D线 ↔ MBL WPL条带

映射表：

| 渗流理论 | MBL系统 |
|---------|---------|
| 2D lattice ℤ² | 2D MBL系统，每个site对应局域化/热化状态 |
| 边以概率p开放 | site以概率p_block为局域化（阻塞） |
| 强制开放线L（p=1） | WPL条带（沿条带p_block≈0，即完全热化） |
| 逾渗簇=系统尺度连通开放路径 | 热化雪崩通道=系统尺度连通热化区域 |
| p_c不变 | p_block(percolation)不受WPL存在影响 |

**关键形式化：**

定义MBL系统的局域化指示函数：
\[
\Theta_i = \begin{cases} 1 & \text{site } i \text{ 局域化（阻塞）} \\ 0 & \text{site } i \text{ 热化（可传导）} \end{cases}
\]

在标准MBL逾渗图像中（S1+S2），系统级热化雪崩需要存在一条跨越2D系统的路径，使得路径上所有site的Θ_i = 0（全部热化）。定义"块体阻塞概率"p_block = P(Θ_i = 1)（即单个site局域化的概率）。

WPL条带上的site满足：对i ∈ WPL，若该WPL上|V(i)| < W_c，则Θ_i = 0（强制热化）。

**同构关键论证：** WPL是一维线（严格地说，在2D格点上，WPL是一系列共线site的集合）。该线上Θ_i = 0 ∀i ∈ WPL。这条"强制热化线"对应的渗流角色 = "强制开放线"。

**1D WPL不能触发2D热化雪崩的原因（渗流语言）：**
1. WPL可以沿一个方向（条带方向）无限延伸 → 连接该方向的两个边界
2. 但跨越2D雪崩需要连接**两个正交方向**的边界
3. WPL本身是1D的，只跨越一个方向
4. 要在第二方向形成跨越，需要WPL之外的2D区域也热化
5. 2D区域的热化由p_block控制：当p_block > p_c(2D) ≈ 0.593时，2D区域不发生逾渗
6. 即使WPL存在，p_block仍由2D区域决定，p_c不变

**数学形式：** 定义含WPL的2D系统的"两个方向连通概率"：
\[
P_{\text{span}}^{\text{both}}(p_{\text{block}}) = P(\exists \text{ cluster connecting left-right AND top-bottom boundaries})
\]

在标准2D逾渗中（无WPL），P_span^both(p) > 0当且仅当p < p_c。
在有单条WPL的情况下：
\[
P_{\text{span}}^{\text{both, WPL}}(p_{\text{block}}) = P_{\text{span}}^{\text{both}}(p_{\text{block}}) + \delta P
\]
其中δP来自WPL穿透两个方向的贡献。但WPL是1D的，它最多穿透一个方向。穿透第二方向需要2D的额外连接，其概率仍由p_block控制。因此：
\[
\delta P \leq P(\text{WPL connects one direction}) \times P(\text{2D region connects the other} \mid p_{\text{block}})
\]
第一项=1（WPL总是连接一个方向），第二项≤ P_span^1D(p_block)，它仅在p_block < p_c时非零。因此，含WPL的双向逾渗阈值仍然等于p_c(2D)。

**结论1.1：** 从经典2D渗流的角度，单条1D WPL不改变系统的逾渗阈值p_c。MBL的逾渗稳定性条件p_block > p_c在该条带存在时不变。WPL不能单独触发2D级雪崩。

### 2.3 多条WPL的情况 — 是否存在WPL网络？

在非可分离势V(x,y) = 2W cos(2πβx) cos(2πβy)中，WPL出现在cos(2πβx) = 0或cos(2πβy) = 0的位置。

**水平WPL：** y满足cos(2πβy) = 0 ⇒ 2πβy = π/2 + nπ ⇒ y_n = (1/4β) + n/(2β)，n ∈ ℤ
**垂直WPL：** x满足cos(2πβx) = 0 ⇒ 2πβx = π/2 + mπ ⇒ x_m = (1/4β) + m/(2β)，m ∈ ℤ

**WPL形成网格：** 水平和垂直WPL的交叉点坐标为(x_m, y_n)。这些交叉点处|V| = 0（因为cos×cos=0×0=0）。

**是否形成逾渗网络？** 水平和垂直WPL的交叉构成矩形网格。但这是1D线组成的网格，不是2D区域。在渗流理论中，1D线的网格（即使密度有限）仍然不改变2D逾渗阈值——因为1D线的"面积占比"为零。每个格点最多被两条WPL穿过（一行一列），在热力学极限下WPL所占的格点比例 → 0。

更精确地：在L×L系统中，水平WPL的数量 ~ 2βL（由cos(2πβy)=0的解密度），垂直WPL数量 ~ 2βL，WPL交叉点数 ~ 4β²L²。每个WPL上的site数 ~ L。WPL总site数 ~ 2βL × L + 2βL × L - 4β²L² = (4β-4β²)L²。面积占比 = 4β(1-β)。对β = 0.618，面积占比 = 4×0.618×0.382 ≈ 0.944。但这是所有WPL上的site的总占比，不代表这些site全部热化——只有满足|V(i)| < W_c的子集才热化。热化site的占比远小于此值（需要cos(2πβx)·cos(2πβy)的绝对值 < W_c/W）。

**结论1.2：** 多条WPL形成的网格虽然格点数目随L²增长（面积占比非零），但只有满足|V| < W_c的site才热化。这些site沿每条WPL不连续分布（受垂直方向cos调制），形成的是沿WPL的一系列片段，而非整条WPL。即使在最有利的参数下，这些片段构成的是沿1D线的零散热化site链，不构成2D逾渗网络。

### 2.4 渗流角度综合判定

**渗流结论：** WPL条带（无论单条或多条形成的网格）在2D渗流框架中是1D inclusion，容量为零测度。它不改变系统的2D逾渗阈值p_c。即使WPL上的site强制热化（Θ=0），要形成跨越两个方向的雪崩通道，仍需要2D区域中p_block < p_c。在MBL相（p_block > p_c），WPL不能触发系统级雪崩。

**适用条件：**
- 单条WPL：严格成立
- 多条WPL网格：成立，但需验证WPL上的热化site是否沿WPL连续（若连续，可视为1D开线集合；若不连续，是更弱的1D碎片集合，结论更强）
- 多WPL形成2D连通区域：若WPL密度足够高且热化site足够连续，理论上可能形成2D逾渗网络。这发生在w > a（WPL垂直间距~1/(2β)约1-2个格点）且每条WPL上热化比例足够高的极端情况。这在物理参数下不成立。

## §3 角度2：1D→2D crossover的标度理论

### 3.1 条带的"有效维度"定义

考虑一个条带几何：长度L→∞（沿WPL方向），宽度w有限（垂直WPL方向）。在什么条件下这个条带表现出"有效2D"的行为？

定义有效维度d_eff，通过态密度的标度行为：
\[
\rho(E) \sim \exp(s \cdot V_{\text{eff}})
\]
其中V_eff是条带的"有效体积"。对于真正的d维系统，ρ(E) ~ exp(s_d · L^d)。

对于1D条带嵌入2D系统：
\[
d_{\text{eff}} = 1 + \delta(w/\xi_{\text{perc}})
\]
其中δ(·)是从0到1的插值函数，满足：
- δ(0) = 0（w=0时是1D线，无2D贡献）
- δ(∞) = 1（w→∞时是2D平面）
- δ单调递增

物理上，δ(w/ξ_perc)的精确形式由以下物理过程决定：当w < ξ_perc时，垂直方向的量子相干被ξ_perc截断——即垂直方向的态不能在w尺度内充分混合出2D特征。当w > ξ_perc时，垂直方向形成了足够的量子态密度，使条带在热力学意义上等价于2D区域。

### 3.2 标度函数的具体构造

借鉴超导窄通道中的1D→2D crossover标度理论（Phys. Rev. B 48, 15933, 1993），有效维度可形式化为：

\[
d_{\text{eff}}(y) = 1 + \frac{1}{\pi} \int_0^{\pi} \frac{d\theta}{1 + (\xi_{\text{perc}}/(w \sin\theta))^2}
\]

其中y = w/ξ_perc，θ为垂直方向的波矢角的连续化积分。该积分有两个极限：
- y → 0：d_eff → 1 + O(y²)
- y → ∞：d_eff → 2 − O(1/y)

具体计算：
\[
d_{\text{eff}}(y) = 1 + \frac{y}{\sqrt{1+y^2}}
\]

验证：y=0 → d_eff=1（1D线）；y=1 → d_eff=1+1/√2≈1.71；y→∞ → d_eff=2（2D平面）。

或者用更简单的线性插值近似（De Cesare et al. 1998, J. Phys. Studies）：
\[
d_{\text{eff}} = d_{\text{bulk}} - \frac{1}{1 + (w/\xi_{\text{perc}})^2}
\]
其中d_bulk=2（2D bulk），d_eff=1（1D极限）。但此形式在w=0时给出d_eff=1（正确），w=ξ_perc时d_eff=2-1/2=1.5，w→∞时d_eff→2。

**选择最保守的形式**（使WPL最容易达到2D的插值，即最不利于命题A的形式）：
\[
d_{\text{eff}}(w) = 1 + \frac{w/\xi_{\text{perc}}}{1 + w/\xi_{\text{perc}}}
\]
这给出w=ξ_perc时d_eff=1.5，w=10ξ_perc时d_eff≈1.91。即使用此"加速收敛"的标度函数，也需要w >> ξ_perc才能接近d_eff→2。

### 3.3 WPL垂直宽度w的Diophantine估计

WPL沿方向d̂ = (β_y, −β_x)/|β|（即等势线方向），垂直方向为β̂ = (β_x, β_y)/|β|。

在垂直方向上，势能的变化：
\[
V(x_\perp) = 2W \cos(2\pi\beta_x (x_\perp \cos\theta + \text{const})) \cos(2\pi\beta_y (x_\perp \sin\theta + \text{const}))
\]

沿WPL（等势线），cos(2πβ·r) = cos(2πβ·r₀) = C₀（常数）。垂直WPL的方向（gradient方向），势能以最大梯度变化：
\[
|\nabla V| = 2\pi W |\beta| \cdot |\sin(2\pi\beta·r)|
\]
在WPL上，β·r使得cos取常数C₀，因此|sin(2πβ·r)| = √(1−C₀²)。

WPL条带的垂直宽度w由"偏离WPL多远后|V|超过W_c"决定：
\[
w = \frac{2W_c}{|\nabla V|} = \frac{2W_c}{2\pi W |\beta| \sqrt{1-C₀²}} = \frac{W_c}{\pi W |\beta| \sqrt{1-C₀²}}
\]

对最有利的WPL（C₀=0，即|V|=0在WPL中心线上）：
\[
w = \frac{W_c}{\pi W |\beta|}
\]

代入典型参数：β = 0.618, W_c/J ≈ 25, W/J ≈ 50（深度MBL相）：
\[
w = \frac{25}{\pi \times 50 \times 0.618} = \frac{25}{97.1} \approx 0.257 \text{ 格点}
\]

这个宽度小于1个格点！物理上，这意味着WPL条带在垂直方向的有效宽度只有一个格点量级——因为只要偏离WPL中心线一个格点，有效势能就从0上升到~2W|cos(2πβ·1)|≈2W·|cos(2π×0.618)|≈2W·0.75≈1.5W，远超W_c。

**更精确的离散估计：** 在格点上，WPL是一个1像素粗的线。垂直方向偏离WPL的第一个site，其势能为：
\[
V_{\text{off-WPL}} = 2W \cos(2\pi\beta x_0) \cos(2\pi\beta (y_0 \pm 1))
\]

若WPL满足cos(2πβx_0) ≈ 0（使得|V|≈0），则cos(2πβy_0)可取任意值。偏移一行后：
\[
|V_{\text{off-WPL}}| = |2W \cos(2\pi\beta x_0) \cos(2\pi\beta (y_0 \pm 1))|
\]

即使cos(2πβx_0)≈0（小的值ε），cos(2πβ(y_0±1)) ≈ cos(2πβy_0 ± 2πβ) ≠ 0（对一般y_0）。因此|V_off| ≈ 2W·ε·|cos(2πβ(y_0±1))|。若ε << W_c/(2W)（即WPL非常接近零势），则|V_off| < W_c，WPL宽度>1格点。但ε需要cos(2πβx_0) ≈ ±W_c/(2W|cos(2πβ(y_0±1))|)，这在β为无理数时由Diophantine逼近保证存在——但频率极低。

**结论：** WPL的垂直有效宽度w_eff ≈ 1-2个格点（在深度MBL相，W≫W_c时w_eff→1）。

### 3.4 态密度和热化容量的标度分析

1D条带（长度L→∞，宽度w~O(1)）的多体态密度：

沿条带方向（1D）：ρ_1D(E) ~ exp(c_1D · L)
垂直方向（有限宽度w）：额外的态密度倍增因子 ~ exp(c_2D · w·log(W))（来自由w决定的微观态数）

总态密度：
\[
\rho_{\text{strip}}(E) \sim \exp(c_{1D} \cdot L + \tilde{c}_{2D} \cdot w)
\]

其中c_1D ≈ ln(2)（沿WPL的自旋-1/2自由度），c̃_2D是垂直方向的微观态密度对数。

对于条带能否热化周围2D局域区域，关键是比较条带的"熵容量"与2D局域态的"有效态数"。

条带的一段（长度L_eff，垂直方向w）最多可以热化周边2D区域的体积 ~ L_eff × ξ_perc²（因为垂直条带方向，热化传播被ξ_perc限制）。此2D区域的多体态密度：
\[
\rho_{2D} \sim \exp(s_2 \cdot L_{\text{eff}} \cdot \xi_{\text{perc}}^2 / a^2)
\]

热化条件（热力学第二定律的量子多体版本）：条带熵 ≥ 目标区域熵：
\[
c_{1D} \cdot L_{\text{eff}} + \tilde{c}_{2D} \cdot w \geq s_2 \cdot L_{\text{eff}} \cdot \xi_{\text{perc}}^2 / a^2
\]

整理：
\[
L_{\text{eff}} \cdot (c_{1D} - s_2 \xi_{\text{perc}}^2 / a^2) + \tilde{c}_{2D} \cdot w \geq 0
\]

关键：系数(c_{1D} − s_2·ξ_perc²/a²)。c_1D ~ ln(2) ≈ 0.693（1D自旋链每格点的熵密度），s_2 ~ O(1)（2D系统每格点的熵密度，数量级~ln(2)），ξ_perc ~ 30（如前估计），a = 1（格点间距）。

c_{1D} − s_2·ξ_perc²/a² ≈ 0.693 − 0.693 × 900 ≈ −623 << 0！

这意味着**条带沿长度方向每增加一个格点，2D目标区域的熵增量远超条带自身的熵增量**。1D条带根本无法热化2D体积，因为2D的自由度数增长太快（面积vs长度）。

**结论3.1：** 即使WPL无限长（L→∞），其1D熵容量按L线性增长，而周边2D局域区域的熵容量按L²增长。热化条件要求条带熵≥目标熵，这要求L_eff满足c_1D·L_eff ≥ s_2·ξ_perc²·L_eff → 这在任何有限L_eff下都不成立（c_1D << s_2·ξ_perc²）。WPL作为1D热库无法热化2D MBL系统——不是因为热化速率慢，而是因为热力学上不可能（熵容量不够）。

### 3.5 标度理论综合判定

**标度结论：** 从d_eff(条带)<2，到熵容量的维度分析，WPL条带不能作为2D热化源。三个独立论证：
1. d_eff标度：w < ξ_perc → d_eff ≈ 1 → 1D热库
2. 态密度维度：ρ_strip ~ exp(c_1D·L) vs ρ_2D_target ~ exp(s_2·L·ξ_perc²) → 维度失配
3. 热化熵条件：c_1D << s_2·ξ_perc² → 热力学不可能

三者独立指向同一结论。

## §4 角度3：非可分离势的分类学（准晶体学视角）

### 4.1 一般2D准周期势的Fourier module分析

一般准周期势的Fourier展开：
\[
V(\mathbf{r}) = \sum_{\mathbf{k} \in S} c_{\mathbf{k}} \exp(2\pi i \mathbf{k} \cdot \mathbf{r})
\]

其中S = {k₁, k₂, ..., k_N}是ℝ²中的一个有限集合（wave vectors），c_k是Fourier系数。

**关键代数结构：** 定义S生成的ℤ-module（整系数线性组合的集合）：
\[
\mathcal{M} = \left\{ \sum_{j=1}^{N} n_j \mathbf{k}_j : n_j \in \mathbb{Z} \right\}
\]

\mathcal{M}的rank r = dim_ℚ(span_ℚ(k₁, ..., k_N))（在有理数域上的维数）。

**分类：**
- r = 2：所有的k都在同一2D rational subspace中。势能是"基本周期势"——等价于周期势（在适当的坐标变换下）。
- r > 2：所有k不在同一2D rational subspace中。势能是"真准周期势"（quasicrystal）。

### 4.2 可分离 vs 非可分离的Fourier module rank

**可分离势（S型）：** V(x,y) = W[cos(2πβx + φ_x) + cos(2πβy + φ_y)]

Fourier分解：
\[
V(x,y) = \frac{W}{2}\left[e^{i(2\pi\beta x+\phi_x)} + e^{-i(2\pi\beta x+\phi_x)} + e^{i(2\pi\beta y+\phi_y)} + e^{-i(2\pi\beta y+\phi_y)}\right]
\]

波矢集合：S = {(β, 0), (−β, 0), (0, β), (0, −β)}
ℤ-module \mathcal{M}的rank：span_ℚ({β, 0}, {0, β}) = 2（两个独立方向）

**可分离势的Fourier module rank = 2**（等于空间维数）——这就是"可分离"的代数含义。

**非可分离势（NS型）：** V(x,y) = 2W cos(2πβx) cos(2πβy) = W[cos(2πβ(x+y)) + cos(2πβ(x−y))]

Fourier分解：
\[
V(x,y) = \frac{W}{2}\left[e^{i·2\pi\beta(x+y)} + e^{-i·2\pi\beta(x+y)} + e^{i·2\pi\beta(x-y)} + e^{-i·2\pi\beta(x-y)}\right]
\]

波矢集合：S = {(β, β), (−β, −β), (β, −β), (−β, β)}
ℤ-module \mathcal{M}的rank：span_ℚ({β, β}, {β, −β}) = 2（(β,β)和(β,−β)在ℚ上线性无关当且仅当β和−β线性无关，即β≠0）

**非可分离势的Fourier module rank也是2！** 这是关键发现——Štrkalj的非可分离势虽然在"物理直觉"上是非可分离的（不能写成f(x)+g(y)的形式），但在Fourier module rank的意义上，它和可分离势一样是rank-2的。

**区别在哪里？** 在势能形式：可分离势的Fourier分解中，每个波矢沿单一轴方向（(β,0)或(0,β)），而非可分离势的波矢沿对角线方向（(β,β)或(β,−β)）。两者的rank相同，但波矢的**几何取向**不同——这在格点（正方格子，沿x/y轴最近邻耦合）上产生了物理上的根本差异。

### 4.3 WPL的准晶体学起源：rank-2准周期势的低无序子流形

对于一般rank-2准周期势（波矢k₁, k₂在ℚ上线性无关），定义势能的**水平集**：
\[
\mathcal{V}_c = \{\mathbf{r} \in \mathbb{R}^2 : V(\mathbf{r}) = c\}
\]

WPL是满足V(r) ≡ const的直线。在非可分离势V(x,y) = 2W cos(2πβx) cos(2πβy)中：

WPL满足cos(2πβx) = 0 ⇒ 2πβx = π/2 + nπ ⇒ x_n = (1/4 + n/2)/β
或者cos(2πβy) = 0 ⇒ y_n = (1/4 + n/2)/β

这些是离散的线（由整数n、m参数化）。在ℝ²中，每条WPL是1维子流形。

**一般情况（rank-N准周期势）：** 设势能V(r) = f(k₁·r, k₂·r, ..., k_N·r)，其中f是某个函数。低无序区域由条件|V(r)| < W_c定义。其拓扑维数由约束方程的个数决定：
\[
\text{dim}(\text{低无序区域}) = 2 - \text{rank}(\text{active constraints at the point})
\]

对于WPL情形：
- 势能V(x,y) = 2W cos(2πβx) cos(2πβy)
- 沿WPL（如x = x_n固定）：V ≡ 0（因为cos(2πβx_n) = 0）
- 约束个数：1个（x固定），剩余自由度1个（y方向）→ 1维WPL条带

对于一般非可分离势：
- 若势能依赖N个独立的相位α_j = k_j·r, j=1,...,N
- 低无序条件|V(α₁,...,α_N)| < W_c
- 在W_c → 0的极限下，条件V(α₁,...,α_N) = 0给出一个(N−1)维子流形在N维torus T^N = ℝ^N/(2πℤ)^N上
- 提升到ℝ²上：由N个相位到2个空间坐标的映射(k₁,...,k_N)ᵀ: ℝ² → T^N
- 该映射的像的维数 = min(2, N)
- 低无序区域在ℝ²上的维数 = max(0, 2 − rank(条件))

**关键分类：**

| Fourier module rank N | 约束集维数 | 低无序区域在ℝ²中的维数 | 对MBL的威胁 |
|----------------------|-----------|----------------------|------------|
| N = 2 | V = C₀ 是一个1D子流形（在T²上） | 映射到ℝ²上是1D线（最大值） | WPL = 1D条带 → 无2D威胁 |
| N = 3 | V = C₀ 是一个2D子流形（在T³上） | 映射到ℝ²上可以是2D区域（全空间） | **可能存在2D低无序区域！** |
| N = 4 | V = C₀ 是一个3D子流形（在T⁴上） | 总是2D（映射满射） | **确定存在2D低无序区域！** |

### 4.4 rank-N分类的关键物理后果

**N=2（包含Štrkalj的可分离和非可分离势）：**
- 低无序条件V=0定义了T²上的1条或几条闭合曲线（1维子流形）
- 沿k₁, k₂方向的空间坐标映射将T²上的1维子流形提升到ℝ²上的1维线族
- **结论：低无序区域至多是1D线（WPL）。** 不存在2D低无序块。L_max推广到1D条带后仍有限（条带垂直宽度由Diophantine条件约束，见§3.3）。

**N=3（三色准周期势，如V(r) = Σ_{j=1}^{3} W_j cos(2πk_j·r)）：**
- 在T³上，V=0定义了2维子流形
- 映射到ℝ²时：由于dim(ℝ²)=2，子流形可以填充ℝ²的2D区域
- **危险：** 当k₁, k₂, k₃的ℚ-span rank=3时，可能存在真正的2D低无序区域（区域而非条带），其尺寸不再受简单的Diophantine约束
- 此时L_max推广需要新的数学——准晶体的低无序区域分类学

**N≥4（多色准周期势）：**
- 类似准晶体中的"approximant phase"
- 可以存在扩展的2D低无序区域，对MBL构成真正威胁
- 但这些势在实验上更难实现，模型也更人工

### 4.5 WPL的准晶体学精髓：φ-locking机制

在非可分离势中，WPL出现的关键是**相位锁定**机制：
用复表示：ε_j = V(r_j)，其中r_j是格点j的位置。

非可分离势的相位结构：
- 每个格点j有水平"有效强度"λ_x(j) = |2W cos(2πβx_j)|
- 和垂直"有效强度"λ_y(j) = |2W cos(2πβy_j)|
- 实际势能V(j) = λ_x(j) · cos(2πβy_j)（当cos(2πβx_j)吸收符号后）

WPL条件：λ_x(j) < W_c 或 λ_y(j) < W_c。

这本质上是"一维投影"效应：每条WPL是2D quasiperiodic结构投影到1D时，某个1D方向恰好没有有效无序的结果。

### 4.6 准晶体学综合判定

**准晶体学结论：** 
1. Štrkalj的非可分离势V(x,y)=2W cos(2πβx)cos(2πβy)的Fourier module rank=2（与可分离势相同）。
2. rank-2准周期势的低无序区域至多是1维的（WPL条带）。
3. WPL是rank-2准周期势中1D子流形的物理表现，其存在不改变"低无序区域最大维数≤1"的拓扑结论。
4. **对MBL的威胁来自rank-N>2的准周期势，** 那里才可能存在真正的2D低无序区域。对于rank-2的所有势（可分离和非可分离），L_max推广至1D条带后结论不变：有效低无序区域是1D的，不能触发2D雪崩。

**开放式警惕：** 若将非可分离势推广到三色情形V(x,y) = W[cos(2πβ₁(x+y)) + cos(2πβ₂(x−y)) + cos(2πβ₃x)]（含三个独立波矢），rank上升至3，此时低无序区域的拓扑维数可能≥2。这类"伪非可分离"势在理论上尚未被充分研究，是潜在的MBL反例矿脉。

## §5 三角度收敛判定

### 5.1 收敛性矩阵

| 判定维度 | 角度1（渗流） | 角度2（标度） | 角度3（准晶体学） |
|---------|------------|------------|---------------|
| WPL是几维的？ | 1D（容量=0测度） | d_eff<2（标度函数） | 1D子流形（rank-2代数） |
| WPL能连接两个方向边界吗？ | 否（只能连一个方向） | 否（1D线性增长不够） | 否（1D manifold） |
| WPL能热化2D区域吗？ | 不改变p_c | 熵容量不够（维度失配） | 要rank-N>2才行 |
| L_max推广后成立吗？ | 是（含WPL的p_c不变） | 是（d_eff<2的非威胁） | 是（rank-2时结论不变） |
| 攻击方向独立性 | 概率论+图论 | 统计力学+标度 | 代数+几何拓扑 |

**三重独立收敛：命题A（L_max推广成立）胜出。WPL条带不能产生等效的2D罕见热区。**

### 5.2 修正后的L_max定义

传统定义（可分离势）：
\[
L_{\text{max}} = \max\{L : \exists \text{ 连通2D区域} R, \dim(R)=2, \text{s.t. } |V(\mathbf{r})| < W_c \ \forall \mathbf{r} \in R\}
\]

强调"dim(R)=2"即只考虑真正的2D块状低无序区域。

推广定义（含非可分离势）：
\[
L_{\text{max}}^{\text{gen}} = \max\left\{ \max_{R: \dim(R)=2} L(R), \quad \max_{\mathcal{S}: \text{WPL}} \min(w_\perp(\mathcal{S}), d_{\text{eff}} \cdot \xi_{\text{perc}}) \right\}
\]

其中：
- 第一项：传统2D块状区域的最大尺寸（由Diophantine约束）
- 第二项：WPL条带的"有效2D等价值"

关键结果：对rank-2准周期势，第二项 ≤ min(w, ξ_perc) ← 两者典型值均~O(1-30)格点，远小于系统尺寸。L_max^gen有限 → MBL稳定。

### 5.3 命题B被反证的精确断裂点

命题B声称"WPL产生无界低无序通道→L_max=∞→数论保护失效"。

此论证的断裂点在：
1. **几何维度混淆：** 将"无界长度"混淆为"无界2D区域"。WPL的无界长度是1D属性，不赋予2D热化能力。
2. **热化容量误判：** 假设1D热库可以热化2D系统。熵容量分析（§3.4）证明这在热力学上不可能——1D熵线性增长 vs 2D熵面积增长。
3. **逾渗阈值忽视：** 假设WPL的存在自动意味着系统级逾渗。渗流理论（§2）严格证明1D inclusions不改变2D逾渗阈值。

## §6 自攻击与反例搜索

### 6.1 自我攻击：角度1可能被什么否定？

**攻击1.1：** "容量为零测度"在有限尺寸系统中不成立——在有限L×L系统中，WPL占1/L的面积比例。在有限系统中，WPL可以连接两个方向的边界（通过网格）。

**回应：** 在有限系统中，WPL网格确实可以形成跨越两个方向的路径（水平和垂直WPL交叉形成网格）。但这需要WPL上的**所有site都热化**，而不仅仅是WPL存在。在非可分离势中，WPL上只有满足|cos(2πβx)·cos(2πβy)| < W_c/W的site才热化。对于沿y_n方向的WPL（cos(2πβy_n)≈0），x方向的热化条件为|cos(2πβx)·cos(2πβy_n)| < W_c/W。由于cos(2πβy_n)≈0（小量ε），条件简化为ε|cos(2πβx)| < W_c/W → |cos(2πβx)| < W_c/(Wε)。若ε << 1（WPL接近精确零），此条件对几乎所有x成立 → 整条WPL热化。但ε << 1（即cos(2πβy_n)足够小）由Diophantine逼近保证的概率为O(1/L)（在L×L系统中）。在热力学极限下，这样"完美"的WPL密度→0。详细地说：cos(2πβy)的极值分布由{Hölder连续性+Diophantine性质}控制，|cos(2πβy_n)| < δ的条件在L个y值中约满足L·δ/π²次（对badly approx β）。因此完美WPL在热力学极限下的密度为O(δ)→0，而δ需要<W_c/W~O(1)才能触发命题B。对δ~O(1)（即不是极端小），WPL上的热化site不连续，不形成贯穿热化线。

**攻击1.2：** 即使在热力学极限下，WPL的"面积占比"在乘积形式V(x,y)=f(x)g(y)中可以是常量——前文估计为4β(1−β)≈0.944（所有WPL的总site占比）。这个占比虽不改变p_c（零测度论证），但若这些site上p_block→0，相当于在2D逾渗中引入了强关联的"强制开放site"网络。强关联可以改变逾渗阈值。

**回应：** 这是一个有效攻击。强关联的"强制开放site"确实可能改变逾渗阈值。但我们需要区分：(a) WPL上的所有site（包括那些势能超过W_c的）都计入那个0.944占比，但只有|V|<W_c的子集热化。(b) 热化子集在WPL上形成的是1D碎片（因为垂直方向的势能cos调制使得并非整条WPL热化）。1D碎片（即使形成网格）仍是1D objects的集合，不是2D区域。在渗流理论中，1D线网格的逾渗阈值p_c不同于2D连续逾渗——它要求网格本身形成跨越两个方向的路径。这发生在网格密度（=WPL间距的倒数）超过某个阈值时。对WPL网格，水平和垂直WPL的间距约Δ=1/(2β)≈0.809（以格点数计）。这意味着网格密度≈1.24（每格点），网格本身就构成了对偶格子的全覆盖。**在这个密度下，如果WPL上的所有site都热化，那么水平和垂直WPL的交叉点构成逾渗路径。** 但如前所述，WPL上并非所有site都热化。

### 6.2 自我攻击：角度2可能被什么否定？

**攻击2.1：** d_eff标度中使用的"2D区域熵~s_2·L·ξ_perc²"假设了整个ξ_perc宽度内的2D区域都参与热化。但实际上，WPL只需要热化紧邻的局域site（一个"层"），热化可以逐层传播（雪崩机制）。

**回应：** 这是有效攻击。雪崩机制（De Roeck & Huveneers 2017）假设：一个热化site可以热化其紧邻的局域site，然后这些新热化的site再热化它们的邻居，依此类推。这个过程的有效维度不是d_eff而是雪崩传播的"有效扩散维度"。

但关键在于：雪崩传播的每一步都需要量子隧穿耦合。相邻局域site之间的耦合为Γ ~ J·exp(−a/ζ)，其中ζ为局域化长度。每一步的传播时间τ_step ~ 1/Γ。从WPL（1D线）开始的雪崩，第一步热化紧邻WPL的site（形成"2格点宽"的WPL），第二步热化再外层的site（"3格点宽"的WPL），依此类推。这是一个**2D雪崩从1D种子开始生长**的过程。

S1的研究已表明，当p_block > p_c（即大部分site局域化）时，雪崩生长会在某个有限尺寸停止，形成稳定的"热化岛"而非系统级雪崩。WPL的存在相当于提供了一个无限长的1D种子。如果p_block > p_c，从这条1D种子出发的雪崩向外生长一段距离后就会被阻塞——形成宽度有限的"热化走廊"而非跨越整个系统的雪崩。

**关键：S1的p_block > p_c判据对WPL种子同样适用。** 种子是1D还是0D（点状罕见热区）只影响雪崩的起始几何，不影响p_block的阻塞效应。p_block由2D bulk的性质决定，WPL的存在不改变bulk中的p_block。

**攻击2.2：** 态密度标度中，WPL上的c_1D ~ ln(2)可能低估了。对于与WPL相交的多个2D区域同时耦合的情况（多条WPL交叉形成的网络），有效态密度可能是超指数增长。

**回应：** 这是值得担心的。多条WPL交叉形成的网格（水平和垂直WPL的交点）处，势能|V|=0（cos×cos=0×0=0），这是双重退化的低无序条件。在交叉点附近，2D低无序区域的面积可能显著大于单条WPL的宽度。每个交叉点对应一个"低无序斑块"，其尺寸约由交叉点附近的势能梯度决定。对于交叉点(x_m, y_n)使得两个cos都为零：在交叉点附近小区域，V(x,y) ≈ 2W[(−2πβδx)(−2πβδy)] ∝ δx·δy（乘积形式），梯度|∇V| ∝ √(δx²+δy²)，在交叉点附近趋于零。这意味着交叉点周围的低无序区域是2D的（两方向都缓慢增长），而非仅1D的！

这是一个重要的物理修正。但需要定量估计交叉点处2D低无序斑块的尺寸。对V(δx, δy) ≈ 2W·(2πβ)²·δx·δy，条件|V| < W_c给出：
\[
|\delta x · \delta y| < \frac{W_c}{2W(2\pi\beta)^2}
\]

这是一个双曲线区域，不是紧凑区域。其"有效半径"在对角线方向最大，在轴向较小。平均面积 ≈ (W_c/(W(2πβ)²))·ln(L/ξ)。对深度MBL相（W ≫ W_c），这个面积很小。

**结论：** 交叉点处的2D低无序区域在强无序极限下尺寸→1格点，不构成2D威胁。在中等无序（W ~ W_c）时可能较大，但此时整体系已接近局域化-热化转变，WPL效应的区别变得模糊。

### 6.3 自我攻击：角度3可能被什么否定？

**攻击3.1：** 角度3的核心结论"rank-2准周期势的低无序区域至多是1D的"依赖于映射f: T² → ℝ²是浸入（immersion）的假设。在非可分离势中，V(x,y) = 2W cos(2πβx) cos(2πβy)将T²映射到ℝ，水平集{V=C}在T²上是1维子流形，但其在ℝ²上的提升可能因为k₁, k₂的Diophantine性质而稠密——这意味着虽然单条WPL是1D线，但所有WPL的并集可能稠密填充ℝ²。

**回应：** 是的，所有WPL的并集在ℝ²中稠密（因为β是无理数）。但这不意味着任何单条WPL是2D的，也不意味着WPL的并集形成连通2D区域。稠密性和连通性是两回事。WPL的并集是可数多条1D线的并集，在拓扑上是1维的（作为1D流形的可数并集），在测度上是零测集（在ℝ²中）。即使考虑所有WPL上的低无序site（满足|V|<W_c），它们在热力学极限下形成的是1D线的稠密网络，不是2D区域。

**攻击3.2：** rank-2足以产生2D低无序区域，如果势能的函数形式不是cos乘积而是更一般的f(k₁·r, k₂·r)。例如V(r) = W[1 − cos(k₁·r) − cos(k₂·r)]²在k₁·r≈0且k₂·r≈0时V≈0，且该区域在两个方向都平坦（Hessian正定→局部极小值→真正的2D低无序块）。

**回应：** 这是正确的反例。在rank-2框架下，如果势能函数在某个点同时满足∇V=0且Hessian正定，就会产生真正的2D低无序区域（尺寸由Hessian的特征值决定）。V(r)=W[1−cos(k₁·r)−cos(k₂·r)]²在k₁·r≈k₂·r≈0附近就是这样的局部极小值。该区域的尺寸~W_c^{1/2}/(W^{1/2}|k₁||k₂|)可以很大。

**但这是可分离势还是非可分离势？** V(r)=W[1−cos(2πβx)−cos(2πβy)]²是可分离的（x和y分离）。关键是非可分离形式是否也能产生这样的2D局部极小值。在V(x,y)=2W cos(2πβx) cos(2πβy)中：∇V = (−4πβW sin(2πβx) cos(2πβy), −4πβW cos(2πβx) sin(2πβy))。极值点满足sin(2πβx)cos(2πβy)=0且cos(2πβx)sin(2πβy)=0。解为：(sin(2πβx)=0或cos(2πβy)=0)且(cos(2πβx)=0或sin(2πβy)=0)。这给出四种组合，其中sin=0且sin=0（极小值V=±2W）和cos=0且cos=0（鞍点V=0）。在极小值处Hessian的条件数为β²W（正定）→存在2D低无序区域（在极小值附近势能缓慢增长）。**但V=±2W的"极小值"处的势能绝对值=2W，远大于W_c（在深度MBL相）→该区域不是"低无序"的。** Cos=0且cos=0点处V=0但Hessian不定（鞍点）→在某个方向凹、另一方向凸→不形成紧凑2D低无序块。

**因此，非可分离乘积形式cos×cos的特殊之处在于：其临界点（∇V=0处）要么是V=±2W的极小值/极大值（势能绝对值太大），要么是V=0的鞍点（不形成紧凑低无序块）。** 这是乘积形式的内在保护机制——它阻止了真正的2D紧凑低无序区域的形成。

### 6.4 反例总结与防御充分性

| 攻击 | 严重性 | 防御充分性 | 残留风险 |
|------|--------|-----------|---------|
| WPL网格面积占比≠0 | 中 | 只有子集热化，热化碎片是1D的 | 需数值验证碎片连通性 |
| 雪崩从1D种子生长(S1) | 高 | S1的p_block>p_c判据对1D种子同样适用 | 需检查1D种子是否会改变p_block的局部值 |
| 交叉点2D低无序斑块 | 中 | 在强无序(W≫W_c)时尺寸→1 | 在W~W_c附近需要数值 |
| 所有WPL并集稠密 | 低 | 稠密≠连通，测度=0 | 无 |
| rank-2的2D极小值 | 低(已排除) | cos×cos乘积形式无紧凑2D低无序极小值 | 推广到其他非可分离形式时需重新检查 |

**总体防御充分性评估：** 三个角度一致指向命题A成立。最关键的攻击（雪崩从1D种子生长）已被S1的p_block>p_c判据覆盖。剩余的残留风险在可控范围内，数值验证可进一步巩固结论。

## §7 关键公式与判据汇总

### 7.1 核心判据

**WPL不触发2D雪崩的充分条件（三重判据）：**

1. **渗流判据：** p_block(WPL存在) = p_block(无WPL) > p_c(2D) ≈ 0.593
   - 来源：1D inclusions不改变2D逾渗阈值的定理（§2）

2. **标度判据：** w(WPL) < ξ_perc 且 c_1D < s_2·ξ_perc²/a²
   - w = W_c/(πW|β|)（垂直宽度）
   - ξ_perc = ξ₀|p_block − p_c|^{-ν}（渗流关联长度，ν=4/3 in 2D）
   - 来源：d_eff标度 + 熵容量分析（§3）

3. **代数判据：** Fourier module rank ≤ 2 且 势能函数的临界点Hessian不定
   - rank-2：低无序区域维度 ≤ 1（子流形约束）
   - Hessian不定：不存在紧凑2D低无序局部极小值
   - 来源：准晶体Fourier分类（§4）

### 7.2 推广的L_max定义

\[
\boxed{
L_{\text{max}}^{\text{gen}} = \max\left\{
\underbrace{\frac{2\pi V_0}{\sqrt{5}W_c}/\max_{i}|\beta_i|}_{\text{传统2D块状L\_max（S3, Diophantine）}},
\quad
\underbrace{\min\left(\frac{W_c}{\pi W|\beta|}, \xi_{\text{perc}}\right)}_{\text{WPL有效2D等价值}}
\right\}
}
\]

对于badly approximable β且W ≫ W_c：第一项~O(1-10)，第二项~O(1-30)。两者均为有限量 → L_max^gen有限。

### 7.3 数值可验证的预测

**P1（WPL宽度标度）：** w(W) ∝ 1/W。对β=0.618, W_c/J=25, W/J=30-80范围内测试，提取WPL上的局部态密度宽度，应满足w ≈ W_c/(πWβ)。此预测可被精确对角化或DMRG验证。

**P2（熵容量失配）：** 在有限系统中制备WPL热化初始态（沿WPL排列的粒子），测量WPL粒子向bulk扩散的渐近密度分布。预测：扩散被限制在WPL附近宽度~ξ_perc的"走廊"内，不扩展到整个系统。

**P3（交叉点低无序斑块尺寸）：** 对WPL交叉点(|V|=0点)附近的单粒子态密度进行空间分辨。预测：在W≫W_c时，交叉点的局域低无序斑块线性尺寸~1格点。
