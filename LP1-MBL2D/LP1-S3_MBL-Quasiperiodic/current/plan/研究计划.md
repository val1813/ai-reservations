## 北极星命题

**驱动矛盾：**
- 命题A（真正消除）：2D Aubry-André势V(r)=V_0[cos(2πβ_x·x)+cos(2πβ_y·y)]中，Diophantine条件约束势能涨落→不存在任意大的低无序区域→p_block=1（或等效地L_max有限且<L_c）→雪崩永远无法启动→2D准周期MBL严格稳定。
- 命题B（仅推迟漂移）：连分数逼近p_n/q_n→β使得在尺度~q_n处出现"近周期"区域，有效无序极低→罕见热区尺寸可达~q_n→若q_n > L_c则雪崩可启动→准周期MBL仅在L < q_n时稳定。

**关键约束（来自S1）：**
- 雪崩自限条件：p_block > p_c ≈ 0.593
- 阻塞定义：格点j的热化时间τ_j > τ_threshold
- 对准周期势：τ_j = W_j/g²，其中W_j = V_0|cos(2πβ·r_j + φ)|

## Phase规划

### Phase 1：准周期势中罕见热区的数学表征

**目标：** 计算2D Aubry-André势中连续低无序区域（|V(r_i)| < W_c对所有i∈区域）的最大尺寸L_max(β,V_0,W_c)。

**A任务：**
- 将问题形式化：在2D格子上，V(x,y) = V_0[cos(2πβ_x·x + φ_x) + cos(2πβ_y·y + φ_y)]
- "低无序区域"定义：连续L×L区域内所有格点满足|V(r_i)| < W_c
- 单格点概率：P(|V| < W_c) = (2/π)arcsin(W_c/2V_0)（对2D可分离AA势）[2D充分条件分解，保守估计；1D精确公式为 (2/π)arcsin(W_c/V₀)]
- 关键：格点之间不独立！V(r_i)和V(r_j)的相关性由β的Diophantine性质决定
- 计算L_max：最大的L使得存在L×L区域满足条件

**B任务：**
- 从数论角度：连分数逼近β ≈ p_n/q_n，误差|β - p_n/q_n| < 1/q_n²
- 在尺度q_n处，cos(2πβ·k)对k=0,1,...,q_n-1近似周期→势能近似重复
- 若某个周期内有低无序段，则在尺度q_n处该段被"复制"→有效罕见区域尺寸~q_n
- 关键问题：这种"复制"是否产生真正的连续低无序区域？

**产出：**
- L_max(β)的解析表达式（或上界/下界）
- 与β的Diophantine指数μ的关系
- 黄金比例β=(√5-1)/2（最差Diophantine逼近）vs Liouville数（最好逼近）的对比

### Phase 2：准周期p_block的计算

**目标：** 将Phase 1的L_max代入S1的渗流框架，计算准周期势中的有效p_block。
