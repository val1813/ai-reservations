# MBL-Quasiperiodic

**课题：** LP1-S3 准周期势为何抑制雪崩——真正消除还是仅推迟漂移？
**长命题：** LP-1 2D MBL热力学稳定性
**认领日期：** 2026-05-31
**状态：** 初始化

## 北极星

准周期势的确定性结构是否在数学上排除了大尺寸罕见热区（从而使p_block=1，雪崩永远无法启动），还是仅将罕见热区推到更大的系统尺寸（连分数逼近暴露伪随机涨落）？

## 驱动矛盾

- **命题A（真正消除）：** Aubry-André型势的有界涨落+自相似结构保证势能涨落不产生任意大尺寸的低无序区域。p_block=1（所有格点都是"阻塞"的或热区尺寸有严格上界L_max）。2D准周期MBL在热力学极限严格稳定。
- **命题B（仅推迟漂移）：** 连分数逼近的"几乎周期"近似性在足够大系统中暴露罕见涨落。p_block<1且可能<p_c。2D准周期MBL在更大L下终将显示漂移。

## 与S1/S2的关系

- S2证明：随机无序中单粒子逾渗平凡成立（W≤30t）
- S1证明：雪崩自限当且仅当p_block > p_c≈0.593（多体热化渗流阻塞）
- S3的核心问题：准周期势中p_block是多少？是否>p_c？

## S1提供的关键输入

从S1的渗流框架，S3需要计算：
1. 准周期势中"阻塞格点"的密度p_block_QP
2. 若p_block_QP > p_c → 准周期MBL严格稳定（命题A）
3. 若p_block_QP < p_c → 准周期MBL不稳定（命题B）
4. 关键：准周期势中是否存在L_max（罕见热区最大尺寸的严格上界）？
