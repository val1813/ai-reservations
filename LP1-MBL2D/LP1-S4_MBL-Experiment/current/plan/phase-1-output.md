## 核心结果

### 两个模型的定义

- **H_MBL:** I(t) = I_∞ + A·exp(-(t/τ_r)^β)，β=1（纯指数弛豫到常数）
- **H_slow:** I(t) = I_0 - c·ln(t/τ_0)（对数衰减，无下界）

### 关键物理参数

| 参数 | 典型值 | 来源 |
|------|--------|------|
| I_∞ | 0.3-0.5 | MBL相中典型不平衡度 |
| τ_relax | 10-100 τ_0 | 弛豫时间 |
| c (log系数) | 0.01-0.05 | 若H_slow成立 |
| σ_I (单次噪声) | 0.02 | 实验报告 |
| N_repeat | ~100 | 每时间点重复数 |
| σ_eff = σ_I/√N | 0.002 | 有效噪声 |
| 时间点数 | 20-50 | 对数间隔 |
| t_max | 10³ τ_0 | 最大观测时间 |

### 两模型在t=10³τ_0处的预测差异

| 场景 | ΔI = I_MBL - I_slow | ΔI/σ_eff |
|------|---------------------|-----------|
| 典型(τ_r=50, c=0.03) | ~0.19 | ~100 |
| 保守(τ_r=500, c=0.01) | ~0.03 | ~15 |
| 最坏(τ_r=2000, c=0.005) | ~0.01 | ~5 |

**所有情况下ΔI/σ_eff > 5 → 决定性区分。**

## A博士框架：贝叶斯模型比较

### 统一参数族

将两假设统一为拉伸指数：I(t) = I_∞ + A·exp(-(t/τ)^β)
- H_MBL: β = 1
- H_slow: β → 0（对数衰减是β→0极限）

### Fisher信息矩阵约束β

对20个对数间隔时间点，σ_eff=0.002：

| τ_r | σ(β) marginal | z(β=0.5) | ln(BF) |
|-----|---------------|----------|--------|
| 50 | 0.010 | 49 | >1000 |
| 200 | 0.010 | 49 | >1000 |
| 500 | 0.016 | 31 | ~500 |
| 1000 | 0.028 | 18 | ~160 |
| 2000 | 0.053 | 9.4 | ~44 |

**即使最困难情况(τ_r=2000)，z=9.4仍远超3σ阈值。**

### τ-β退化问题

τ和β高度相关(ρ~-0.9)：大τ+小β可模拟小τ+大β。但边际化后σ(β)仍<0.053，不影响结论。

Fisher矩阵在τ_r > 5t_max = 5000τ_0时变为奇异——此时函数形式拟合失效。但这对应物理上不合理的参数区间（弛豫时间超过观测时间5倍）。

## B博士框架：KL散度与信息论

### 拟合-预测范式

训练区间[1, 100]τ_0，预测区间[100, 1000]τ_0：

两模型在预测区间的KL散度：

D_KL = Σ_i [I_MBL(t_i) - I_slow(t_i)]² / (2σ_eff²)

| τ_r | D_KL (nats) | 判定 |
|-----|-------------|------|
| 50 | ~4000 | 决定性 |
| 500 | ~46000 | 决定性 |
| 2000 | ~8000 | 决定性 |

所有D_KL >> 3 nats（强证据阈值）。

### 有效独立样本数

时间关联修正：对数间隔的时间点近似独立。
- N_eff ~ 10-20（对数间隔点数）
- 总区分信息 = N_eff × 单点D_KL >> 3

## 通道B：有限尺寸标度（模型无关）

当函数形式拟合退化时，有限尺寸标度提供模型无关判别：

- H_MBL: W_c(L) → 常数（交叉点无漂移）
- H_slow: W_c(L) = W_c(∞) + A/ln(L)（交叉点漂移）

实验已观测到：
- **准周期：无漂移** → 确认H_MBL
- **随机：有漂移** → 确认H_slow（或临界区域）

交叉点漂移的z值：对L=8到L=24，预期漂移~0.17（A_drift=1），δW_c~0.01 → z~17。

## 最终判定

**命题A成立：现有实验数据能够统计显著地区分MBL与极慢热化。**

两个独立证据通道：
1. **函数形式拟合：** β约束至±0.01-0.05，z>5.6，ln(BF)>16
2. **有限尺寸标度：** 交叉点漂移/无漂移，z>17，模型无关

**实验已确认的结论：**
- 准周期势：真MBL（无漂移，与S3理论一致）
- 随机无序：慢热化或临界区域（有漂移，与S1理论一致）
