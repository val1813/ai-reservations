# MBL-Experiment

**课题：** LP1-S4 现有冷原子实验数据能否统计显著地区分MBL与极慢热化？
**长命题：** LP-1 2D MBL热力学稳定性
**认领日期：** 2026-05-31
**状态：** 初始化

## 北极星

现有冷原子2D MBL实验数据（arXiv:2508.20699，576格点，~10³隧穿时间）是否含有足够信息统计显著地区分"真正的MBL"（不平衡度趋于非零常数）与"极慢热化"（不平衡度以log缓慢衰减）？

## 驱动矛盾

- **命题A（实验可区分）：** 现有数据含有足够信息，统计显著地区分MBL与极慢热化。
- **命题B（实验不可区分）：** 当前系统尺寸和演化时间不足以区分——log衰减在现有时间窗口内与常数不可区分。

## 与S1-S3的关系

S1-S3已给出完整理论框架：
- S1: 随机无序中p_block>p_c时MBL操作性稳定，传播方程已知
- S3: 准周期势中MBL严格稳定，无漂移

S4的任务：用S1-S3的理论预测作为先验，对实验数据做贝叶斯模型比较。

## 关键输入

从S1的渗流框架：
- H_MBL: 不平衡度I(t) → I_∞ > 0（常数渐近）
- H_slow: 不平衡度I(t) ~ I_0 - c·ln(t)（对数衰减）
- H_critical: I(t) ~ t^{-α}，α≈0.35（渗流临界动力学）

从S3的Diophantine框架：
- 准周期势：I(t) → I_∞（严格，无衰减）
- 随机无序(强)：I(t) → I_∞（操作性，exp(5L)时间内无衰减）
