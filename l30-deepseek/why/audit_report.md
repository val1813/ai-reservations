## 一、FATAL 级问题

### F1：演化方程不能产生声称的宇宙学（数值证伪）

**发现过程：** 数值求解了四种通量模型（paper原始、micro、linear、entropic），初始条件 q≈1 + 局部涨落。

**数值结果：**
- 所有模型中 mean(q) 精确守恒（到机器精度）
- 局部涨落向外**扩散**（q_center 增加，向背景值均衡）
- 系统趋近于均匀均衡态 q = mean(q0)，而非 q→0
- 5000步（远超所需）后无任何模型出现死锁

**数学解释：** 演化方程 Δq = -Δ²q/q² 是守恒型非线性扩散方程。连续性方程 ∂_t q = -∇·J 保证 ∫q dx = 常数。扩散只重新分配 q，不创造或消灭它。

**对论文叙事的影响：**
- 箭头图 q=1 → q→0 是错的：演化方程仅将 q 均匀化，不降低它
- 大爆炸→死锁的循环不能仅由演化方程驱动
- 全局死锁必须依赖演化方程**之外**的机制：自发占据事件（公理1）逐次降低 mean(q)

**修复方向：**
1. 明确区分两个过程：(a) 演化方程 = 信息均匀化（扩散），(b) 自发占据 = 缓慢增加总占据数
2. 自发占据率决定了从 q=1 到 q=0 的宇宙学时间尺度：τ_cosmic ~ N / P(spontaneous)
3. 演化方程决定的是均匀化时间尺度：τ_homogenize ~ L²/D(q)
4. 论文必须显式地将自发占据作为演化方程中的一个源项

**诚实程度：** 这是一个真实的数学错误。论文误以为自己的方程驱动 q→0，实际上它驱动 q→常数。必须正面承认并修复。

### F2：信息守恒与不可逆性的未解决矛盾

**问题：** S1 证明信息精确守恒（f 是双射），S2 证明熵持续增加（ΔS > 0）。在缺乏粗粒化框架的情况下，这两个命题在逻辑上不兼容。

**文献支持：**
- Urbina & Rica (2016)：在 Q2R 可逆细胞自动机中，粗粒化主方程 f_{t+1} = W⁺f_t 打破了过去-未来对称性
- Cover (1991)：对离散 Markov 链，Shannon 熵非递减 ⇔ 转移矩阵双随机
- Lindgren (2015)：粗粒化熵产生 = 信息从宏观流向微观尺度
- Zurek (1989)：物理熵 = H + K，微观守恒（H+K 不变），宏观 H 增加而 K 减少

**修复方案：** 引入显式的微观-宏观分层。

**微层（细胞态 s ∈ {0,1}^N）：**
- 动力学 f: s→s' 是双射（信息守恒定理成立）
- 物理熵 S_phys = H(s) + K(s) 守恒（Zurek 公式）

**宏层（q-场）：**
- q = (未占用细胞数)/N，是微观态的粗粒化投影
- 转移矩阵 W_qq' 是双随机的（因 f 是双射）
- 由 Cover 定理：宏熵 H(q) 非递减
- 粗粒化熵产生率 = 信息从 H（Shannon）流向 K（算法信息复杂度）

**对论文的改动：**
- S1 增加一节说明信息守恒是微观定理
- S2 增加一节说明熵增是宏观 emergent 现象
- 新增一个小节明确粗粒化映射和 Cover 定理的应用
- 清晰标注：微观可逆 + 宏观不可逆不是矛盾，是粗粒化的必然结果

**诚实程度：** 这个矛盾是真实的，但可以严格解决。统计力学用同样的方式解决了 150 年。

### F3：1/q² 因子不是从公理唯一推导的

**问题：** 渗透压 ansatz Π ∝ (1-q)/q 不是从三条公理推导的。多种合理假设给出不同函数形式：

| 模型 | 通量 J | 扩散系数 D(q) | 来源 |
|------|--------|--------------|------|
| paper | ∇q/q² | 1/q² | 渗透压类比 |
| micro | q(1-q)∇q | q(1-q) | 微观转移概率 |
| linear | ∇q | 1 | 熵力+常数迁移率 |
| entropic | ∇q/[q(1-q)] | 1/[q(1-q)] | 熵力+常数迁移率 |

**数值结果：** 所有模型都产生扩散行为，但定量特征不同：
- paper: q→0 时扩散加速（最快均匀化）
- micro: q→0 和 q→1 时扩散减速（两端冻结）
- linear: 均匀扩散（不依赖 q）
- entropic: q→0 和 q→1 时扩散急剧加速（两端最快）

**公理约束了什么？** 公理 3 只约束方向（从低 q 到高 q），不约束速率。公理 1+2 约束每步最多转移 1 比特（上界），不约束实际速率。

**修复方案 A（推荐）：** 诚实承认 D(q) 的函数形式需要额外假设。将渗透压模型作为一种有物理动机的选择，而非唯一推导。
- 保留 1/q² 作为主要模型（因为它的行为最有趣：经典极限加速 → 快速死锁）
- 增加一节讨论函数形式的敏感性
- 将"无自由参数"改为"自由参数最少的模型"

**修复方案 B：** 从微观转移概率严格推导 D(q)。
- 这需要指定更新规则（同步/异步、转移概率函数）
- 不同更新规则给出不同 D(q)
- 选择在额外合理假设（如最大并行性）下的最优形式

**诚实程度：** 1/q² 因子目前是一个有物理动机的选择，不是一个定理。必须诚实标注。

## 二、SEVERE 级问题

### S1：κ=1 推导中的优化原则是循环的

**问题（审稿人 A 发现）：** κ<1 的排除依赖于"容量消耗 > 容量转移 → 违反信息守恒"。但信息守恒定理（S1）只证明了 ∑s_i 不变，没有提到"容量消耗"这个概念。

**修复方案：** 放弃"容量消耗"论证，改用时间单位校准论证。

**新推导：**
1. 公理 1+2：细胞是二元的。状态翻转（0↔1）= 1 比特信息变化
2. 定义基本时间单位 τ 为一个细胞完成一次状态翻转所需的时间
3. 在时间 τ 内，一个细胞边界最多传输 1 比特（因为边界细胞最多翻转一次）
4. 因此 κ_max = 1 bit/τ/boundary
5. 我们工作在 τ=1 的自然单位制中，因此 κ=1

**这不是自由参数——这是单位制选择。** 就像在相对论中设 c=1，我们在 DGF 中设基本时间单位 = 一个细胞翻转。物理内容在无量纲结构中。

**对论文的改动：** 重写 S3，避免"容量消耗"的循环论证。

### S2：大爆炸概率主文 vs SM 矛盾

**主文 Section V：** P(spontaneous occupation) = 1/2^N（指定微态的概率）
**SM S9：** P(first occupation) ≈ 1/2 per step（至少一个细胞被占据的概率）

两者差了 ~2^N 倍。这是真实的写作矛盾，必须统一。

**修复方案：** 
- 主文的 1/2^N 是**特定微态**被选中的概率（所有 2^N 个微态等概率）
- SM 的 1/2 是**至少一个细胞自发占据**的概率（每个细胞独立以概率 1/2 占据）
- 两者测量不同的东西。SM 的版本是"大爆炸发生"的正确概率
- 主文应修正为使用 SM 的概率模型，并清楚地解释假设（最大熵先验）

### S3：最近邻证明的框架不一致

**问题（审稿人 A 发现）：** S1 用抽象状态映射（f: {0,1}^N → {0,1}^N），S5 用空间化直觉（"信息在传输中不在任何细胞中"）。两个框架不兼容。

**修复方案：** 在抽象映射框架内重新写 S5。

**新证明思路：**
1. 定义信息图 G = (V, E)，其中 V 是细胞集合，E 初始未指定
2. 状态转移 f: {0,1}^N → {0,1}^N 必须可分解为局部操作
3. 局部性意味着细胞 i 的新状态仅依赖于局部邻域 N(i) 内细胞的状态
4. 公理 2（有限容量）+ 公理 1（可区分性）→ 每个局部操作最多涉及一个相邻细胞对
5. 因此信息图上的边定义了"相邻"关系，转移只能沿边发生
6. 这是信息图拓扑的定义，而非空间上的限制

### S4：连续极限中的维度错误

**问题（审稿人 B 隐式，我的量化分析）：** 

论文写：∂_t q = -t_p · ∂_x² q / q²

正确推导：
Δq_i/t_p = -l² ∂_x² q / (t_p · q²)  [左边=Δq/Δt，右边=Δ²q/(q²Δt)]
∂_t q = -(l²/t_p) · ∂_x² q / q² = -(l·c) · ∂_x² q / q²

因为 l²/t_p = l²/(l/c) = l·c，而 t_p = l/c ≠ l²/t_p。

**修复：** 纠正维度分析。连续方程为：
$$\partial_t q = -(l \cdot c) \cdot \frac{\partial_x^2 q}{q^2}$$

### S5：强制重置机制是 deus ex machina

**问题（审稿人 C 发现）：** q=0 死锁时，公理1 说自发占据概率非零，公理2 说不能超 1 比特。SM S10 说"唯一解决方案是强制细胞重置"，但这不是从公理推导的——这是为了避免公理冲突而引入的外部机制。

**修复方案：**
1. 承认在 q=0 时，公理 1 和公理 2 之间存在真实的张力
2. 提出：在 q→0 极限下，演化方程（加上自发占据源项）的渐近行为自然会触发重置
3. 重置的具体机制是一个开放问题，而不是一个推导出的定理
4. 将"循环闭合"从"定理"降级为"模型预测"或"假设"

**或者：** 展示在 q→0 时，1/q² 扩散系数发散意味着系统在有限时间内达到 q=0。在 q=0 处，方程奇异的。这可以自然解释为"重置"——不需要外部机制，奇点本身就是边界。

## 三、MODERATE 级问题

### M1：质量的推导是循环的

SM S8 承认需要 m_p = √(ℏc/G) 来将信息密度转换为 SI 质量密度。但 m_p 包含 G，而 G 是通过测量质量定义的。循环：质量 → G → m_p → 质量。

**修复方案：** 诚实呈现为维度分析而非推导。
- 质量 ∝ 锁定信息密度（比例关系）
- 比例常数的数值由实验确定（如同标准模型中所有耦合常数）
- 不声称"推导出质量的值"
- 声称"质量的概念从锁定信息的操作定义中涌现"

## 五、数值模拟发现汇总

### 演化方程的行为（所有模型通用）：

1. **守恒性：** ∫q dx 精确守恒。演化方程不能创造或消灭信息容量。
2. **扩散性：** 局部涨落向外扩散并均匀化。中心 q 向背景值收敛。
3. **稳定性：** q=1 是稳定不动点（∇²q=0 → ∂_t q=0）。微小的自发占据产生 ∇²q≠0，触发扩散。
4. **无死锁：** 没有任何模型在有限时间（5000步）内从 q≈1 到达 q≈0。

### 对宇宙学叙事的含义：

正确的叙事应该是：
1. q=1 真空 → 自发占据事件 → 局部 q<1，∇²q≠0
2. 演化方程将信息均匀化（扩散波以速度 c 传播）
3. 均匀化后的 q = 1 - k/N（k 为累积的自发占据数）
4. 更多自发占据事件 → k 增加 → 全局 q 逐步降低
5. 经过 ~N 个自发事件（宇宙学时间），q→0
6. q=0 死锁 → [重置机制] → q=1 → 新循环

**关键区别：** 扩散不驱动死锁——它确保信息在死锁到来之前是均匀的。自发占据驱动死锁。

## 七、诚实评估

**这篇论文的核心洞察（信息约束 → 动力学结构）有价值吗？** 有。这仍然是值得做的工作。

**声称的强度与证据匹配吗？** 不匹配。"无自由参数"、"唯一确定"、"不可为其他"都是过度声称。

**哪些部分是正确的？**
1. 信息守恒定理（S1）——正确
2. 熵驱动的流动方向（S2）——正确
3. 细胞自动机框架（公理→离散规则）——有物理动机
4. 信息论熵与物理熵的连接——有文献支持

**哪些部分是错误的？**
1. 演化方程驱动 q→0 的声称——被数值证伪
2. 渗透压 ansatz 是唯一推导的声称——过度声称
3. "无自由参数"——c, ℏ, G 仍是输入

**修复后能达到什么水平？**
- 作为一篇信息论框架论文，解释宇宙学特征如何从信息约束中涌现——可行
- 作为一篇声称"证明物理定律必然如此"的论文——不可行，证据远不够
