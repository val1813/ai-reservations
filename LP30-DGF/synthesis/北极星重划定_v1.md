# 北极星重划定 v1

## 触发原因

桌面稿 `D:\桌面\decoherence_framework.md` 已从 v1.2 的“宏观本体残缺/大爆炸后空间信息丢失”改为 v1.4 的“干涉重新分配/质量上界 `2m_p/pi`”。旧命题已在 GATE -1 失败；新版本的可救点是出现了一个清晰可证伪量：

```text
m_max = 2 m_p / pi ≈ 14 microgram
```

但 v1.4 内部仍有一个必须先修的代数冲突。

## 致命代数冲突

v1.4 同时使用：

```text
I = (m/m_p)^2
m = (2m_p/pi) sin(pi sqrt(I)/2)
```

若两者都当成精确定义，令 `x=m/m_p`，得到：

```text
x = (2/pi) sin(pi x/2)
```

数值快检：

| x | `(2/pi)sin(pi x/2)-x` |
|---:|---:|
| 0.1 | -0.0004107 |
| 0.5 | -0.04984 |
| 0.637 | -0.10110 |
| 1.0 | -0.36338 |

正质量区间没有给出 `x=2/pi` 的自洽解；`14 microgram` 不能从这个闭环推出。原因不是小数误差，而是定义循环。

## 修正原则

必须把 `I` 从“质量的定义”中解耦。

新基础变量：

```text
q ∈ [0,1]          干涉坐标 / 读取饱和度
I_q = q^2          干涉信息密度
m(q) = (2m_p/pi) sin(pi q/2)
```

低质量极限：

```text
q << 1:
m(q) ≈ m_p q
I_M ≡ (m/m_p)^2 ≈ q^2 = I_q
```

因此：

- `I=(m/m_p)^2` 只能作为低质量校准或实验反推量；
- 全域精确定义应为 `I_q=q^2`；
- `m_max=2m_p/pi` 来自 `q→1`，不是来自 `I=(m/m_p)^2` 的闭环。

## 重新划定的北极星

> DGF-N4: 若存在一个独立于质量定义的干涉坐标 `q∈[0,1]`，且质量是干涉残余 `m(q)=(2m_p/pi)sin(pi q/2)`，则标准低质量关系 `m≈m_p q` 只是小 `q` 极限；大 `q` 区域预言可证伪的相干质量上界 `m_max=2m_p/pi≈14 microgram`，并要求 GUP 退相干核由同一个 `q` 的涨落驱动。

状态：已转化为定义修正。

解决方式：

- 废止全域 `I=(m/m_p)^2`。
- 引入独立干涉坐标 `q`。
- 保留 `I_M=(m/m_p)^2` 只作为低质量可观测校准。

剩余检验：

- INSPECTOR 必须检查 `m(q)` 的量纲、极限和单调性。
- A/B 必须评估 `q` 是否有可观测定义，不能只当符号。

### 开放问题2：GUP链与欧拉链统一

状态：已转化为桥接假设。


要点：

- GUP-Lindblad 形式已有先发模板，尤其是 fluctuating minimal length / deformation parameter 导出的 Lindblad 退相干。
- DGF 不能声称这条链全新；新意只能在于 `q` 同时控制 `m(q)` 与 `beta` 涨落。
- “零自由参数”当前不能保留，除非能从 `q` 的几何涨落推出 `D_q=2t_p` 或等价归一化。

下一轮 AB 必须攻击：

### 开放问题3：粒子质量谱

状态：已降级为外部本征值问题。

严格结论：

- DGF 的 `m(q)` 只提供“干涉坐标到质量”的映射。
- 它不能单独预言电子、质子、夸克的 `q_i`。
- 粒子质量谱必须来自另一个算符或边界条件：


若找不到 `Q` 的动力学定义，质量谱问题不能声称已解决。
