# 知识库

## K1: DGF-N4 定义修正

全域 `I=(m/m_p)^2` 与精确正弦质量式不相容。必须改为独立干涉坐标：

```text
q ∈ [0,1]
I_q = q^2
m(q) = (2m_p/pi) sin(pi q/2)
```

`I_M=(m/m_p)^2` 只保留为低质量校准。

## K2: 13.85 microgram 边界

使用 `m_p≈21.76 microgram`：

```text
2m_p/pi ≈ 13.85 microgram
```

该数值经 INSPECTOR 通过。

## K3: 当前阻断

- 非实 `q_inv` 不是可观测，必须转化为 visibility 异常或模型失配判据。
- q 必须独立于质量可测，否则 DGF-N4 是重参数化。
- GUP-Lindblad 链已有先发，DGF 必须证明同一 q 驱动 `beta(t)`。

## K4: Round 2 统计化重写

非实 `q_inv` 不是物理可观测。正确说法：

```text
m > 2m_p/pi
=> constrained DGF model q∈[0,1], m(q) has no mass-map solution
=> use likelihood/model comparison, not imaginary q
```

## K5: q readout 新阻断

`q_visibility` 可从 visibility/Wigner interference amplitude 作为独立读出候选，但它不自动等于 `q_DGF_mass`。Round 3 必须写桥接假设：

```text
q_visibility = q_DGF_mass
```

或承认 DGF-N4 降级为经验统计模型。

## K6: Round 3 后最稳形态

DGF-N4 当前不能作为“质量上界理论”收官，只能作为约束统计模型：

```text
M0 = environment/null
M1 = DGF constrained latent-q model
```

核心开放问题：

- M1 逐点 `q_i` 过拟合。
- `q_visibility=q_DGF_mass` 是桥接假设。
- 需要真实数据 LLR 表。

## K7: DGF-N4 证伪-降级

DGF-N4 不得收官为质量上界或宏观残缺证明。终审结论是：

```text
DGF-N4 = constrained statistical ansatz, not established physical mechanism
```

致命原因是逐点 `q_i` 过拟合与未证明 `q_visibility=q_DGF_mass` 桥接。强制挽救轮修复了部分形式问题，但没有落地外部 `q_DGF_mass` observable，也没有闭合低秩/图模型 penalty。

## K8: DGF-N5 新北极星

DGF-N5 的核心是跨表征不变量/不可辨识性原则：

```text
物理机制必须在冻结逐点自由度、预注册复杂度、并跨至少两个独立表征后仍保持。
```

DGF-N6/DGF-N8 与 DGF-N5 同分，但按 Re-escalation 来源和深度优先，DGF-N5 作为当前北极星；DGF-N6/DGF-N8 是其 Round 1 子攻击面。
