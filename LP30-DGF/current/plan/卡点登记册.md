# 卡点登记册

## Open-C1: M1 逐点 q_i 过拟合

来源：INSPECTOR A Round 3

问题：`q_i` 对每个数据点自由时，DGF constrained model 会变成高弹性经验拟合器。

必须修复：

- 固定外部 prior，或
- 层级/动力学平滑约束，或
- Bayes evidence / AIC/BIC / 交叉验证惩罚，或
- 禁止逐点自由，改成少参数结构 `q(t;theta)`。

状态：阻断 DGF-N4 强命题，非阻断降级结案；DGF-N4 已证伪-降级。作为 DGF-N5 的继承警告：禁止恢复逐点自由 `q_i`。

## Open-C2: q_visibility 与 q_DGF_mass 桥接未成立

来源：INSPECTOR A Round 3

问题：`q_visibility=q_DGF_mass` 是额外桥接假设，不是由 likelihood 推出。

状态：阻断 DGF-N4 强命题，非阻断降级结案；DGF-N4 已证伪-降级。转化为新方向 DGF-N6：独立 `q_DGF_mass` observable 可得性。

## Open-C3: B 路线 log 量纲错误

来源：INSPECTOR B Round 3

问题：`x_i=log(M_cal_i)` 量纲错误，应为 `log(M_cal_i/M_ref)`。

状态：强制挽救轮已修复为 `log(M_cal/M_ref)` 或 `log(M_cal/13.85 microgram)`；对 DGF-N4 原路径关闭。

## Open-C4: q 独立性仍是检验计划

来源：INSPECTOR B Round 3

问题：`X_m/X_q`、投影矩阵、rank 阈值、bootstrap/null 未完全定义。

状态：阻断 DGF-N4 强命题，非阻断降级结案；DGF-N4 已证伪-降级。转化为 DGF-N7 的预注册 rank/projection/null 检验。

## Open-C5: 最小 LLR 表不完整

来源：INSPECTOR A Round 3

问题：缺 M0 residual/chi2、DGF prior penalty、logL_env、logL_DGF、LLR 完整表。

状态：阻断 DGF-N4 强命题，非阻断降级结案；DGF-N4 已证伪-降级。DGF-N4f 若后续启动，必须补全此表。

## Open-C6: REVIEWER 致命一击

来源：REVIEWER Round 3

问题：M1 的逐点自由 `q_i` 加上未证明的 `q_visibility=q_DGF_mass` 桥接，使 DGF 模型同时获得过拟合能力和伪物理解释；因此 LLR 不能被解释为 DGF 物理机制的证据。

状态：DGF-N4 强命题证伪-降级后关闭；作为历史断点保留。

修复门槛：

- 固定或层级化 `q`；
- 预注册 null/M1 参数数目；
- 给惩罚化 likelihood 或 out-of-sample 预测；
- 独立证明 visibility-q 与 mass-q 桥接；
- 补全 LLR 表、bootstrap/null、rank 判据。

## Open-C7: DGF-N5 需要定义跨表征不变量

来源：强制挽救轮降级后的新北极星

问题：DGF-N5 不能直接继承 DGF-N4 的质量边界；必须把“跨表征不变量/不可辨识性原则”写成可失败判据。最低要求：

- 明确两种以上独立表征，例如 visibility readout、质量代理、环境通道或信息几何坐标；
- 预注册不变量候选，例如 endpoint rank、projection residual、Fisher-Rao/Hellinger 距离结构；
- 冻结逐点 `q_i` 后仍能跨样本复现；
- 与环境 null、仪器漂移 null、后验低秩拟合 null 比较。

状态：开放阻断；DGF-N5 Round 1 必须正面处理。
