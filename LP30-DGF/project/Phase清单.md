## Phase启动

```
[✅] 🪪 贡献者身份（第一个执行，整个课题只问一次）：
      PI必须问用户："你的 ORCID iD 是什么？（orcid.org 免费注册）GitHub 用户名？"
      用户回答了 → 记录到 当前状态.md，后续所有 JSON 自动填入
      用户跳过了 → 标注"匿名贡献者"，GATE 7 时再问一次
      格式：{"orcid": "0000-0002-XXXX-XXXX", "github": "xxx", "name": "可选"}
[✅] ⛔ GATE -1: 核心矛盾结构验证（第一个执行，通过才能继续）

    三问必须全部为YES：

    Q-1.1: 命题A是否有独立实验/观测证据支持为真？
    Q-1.2: 命题B是否有独立实验/观测证据支持为真？
    Q-1.3: 命题A和命题B在逻辑上是否不能同时为真？

    例(通过): 狭义相对论 — A伽利略相对性+B麦克斯韦光速不变→矛盾
    例(不通过): LP-22 — "MIR极限可能是错的"→PRB Rapid Comm

[✅] 读 项目/北极星队列.md → 确认当前北极星+优先级分数
[✅] 写 当前状态.md（含轮次计数+前置检查）
[✅] 写 研究计划.md（如果不存在的轮次）
[✅] AHA检查: 连续5轮无AHA？→触发AHA访客
```

## 每轮交作业

```
[✅] INSPECTOR — 用Agent工具启动独立INSPECTOR，传入A推导文件
      （INSPECTOR 内部优先用 `validation/validate.py` 做机械检查，AI 注意力留给语义判断）
[✅] INSPECTOR — 用Agent工具启动独立INSPECTOR，传入B推导文件
[✅] 读INSPECTOR结果 → 有阻断/警告？→记录到"本轮已知错误"，传入下一轮A/B的上下文
      ⛔ 阻断: A/B必须在下一轮产出中显式修正，INSPECTOR重检修正部分
      ⚠️ 警告: A/B在下一轮产出中标注处理方式（修正/解释/搁置）
      不单独开修正轮。修正+新内容合并为下一轮产出。
[✅] A博士Round 1: 检查 文献库.md 存在？先发检索完成？反例栏已填充？
      （§-1四组搜索是A博士的活，不是PI的。见A_AGENT.md）
[✅] ⛔ R1先发拦截（LP27教训：等REVIEWER到R3才查先发=三轮可能白跑）：
      PI用WebSearch独立搜索核心声张关键词（不依赖A博士的§-1结果）。
      搜索词必须包含：核心结论的普通语言翻译 + "2023 2024 2025"
      找到高度重合的论文 → ⛔ 立即暂停，评估差异性：
        完全重合 → 课题击毙，记录"先发阻断"
        部分重合 → 标注差异化空间，继续但降低声张范围
        无重合 → 通过，继续
      ⚠️ 此步骤不依赖 paper-search-mcp。即使用 WebSearch 也要做。
[✅] PI综合推导（读A+B的roundN.json→汇合判断→写synthesis/）
      同时生成下一轮上下文摘要（≤300字）：最坚固结论+致命弱点+必须修正的阻断
      下一轮AB只收这个摘要，不读完整历史（PI.md §6）
[✅] ⛔ 突破方向检查：本轮离真正的理论突破更近了吗？还是只是更正确了？
      PI必须显式回答：如果本轮发现为真，能改变多少论文的结论？能打开几个新方向？
      只是一个边际贡献 → 标注"⚠️ 突破潜力不足"，下一轮AB必须被明确告知"优先寻找更大声张"
      指向一个真正的突破 → 标注"🔥 突破潜力"，提升该方向在北极星矩阵中的突破潜力分
[✅] ⛔ AHA检查：本轮有新洞察吗？PI必须显式回答：
      A博士本轮有意外发现？B博士有跨学科连接？两者独立汇合到同一新方向？
      有任何一个 → 立即触发AHA访客（research-group/AHA.md），不等保底。
      连续2轮无任何AHA → 触发AHA访客（保底机制）。
      有AHA → 注册到 项目/北极星队列.md 新候选区。
[✅] ⛔ Q6.3/Q6.4: INSPECTOR报告有声张缩水/替代解释警告？→更新声张保真度
[✅] 重算 项目/北极星队列.md 所有条目的矩阵分数（PI.md §1公式）
[✅] 检查矩阵 → 有更高分候选？→触发切换（PI.md 切换规则）
[✅] 检查队列饥荒 → 活跃条目<2？→从候选池补货（PI.md 队列饥荒）
[✅] 更新 知识库.md（新增K条目）
[✅] ⛔ 恶意审稿人检查：当前轮次N≥3 且 N是3的倍数（第3、6、9…轮）？
      是→用Agent工具启动REVIEWER（research-group/REVIEWER.md），传入当前所有核心结论
           REVIEWER以恶意审稿人立场攻击 → 有致命指控？→记录到卡点登记册 → 下一轮AB必须回应
      否→跳过此检查
[✅] 更新 当前状态.md（轮次+1，更新前置检查框）
[✅] ⛔ 检查停止条件：触发硬停止？or N≥3轮？
      N<3 且未硬停止 → 继续下一轮（回到"AB探索"）
      N≥3 或已硬停止 → 进入"北极星收尾"
```
