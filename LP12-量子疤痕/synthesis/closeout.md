## §2 五个为什么 (Five Whys)

从最表层的原始问题追溯到最深的结构性矛盾。

**Why 1: 为什么"QMBS是相还是瞬态"这个问题在2017-2025年间一直没有得到决定性回答？**

因为这个问题本身建立在错误的概念框架上。"相"和"瞬态"是平衡态统计力学中的排中范畴——但在非平衡量子多体系统中，这两个范畴之间的空间不是空的。QMBS恰好占据了这个中间地带：既不是严格的热力学相（Ξ_∞=0意味着序参量最终消失），也不是纯有限尺寸artifact（幂律衰减意味着实验上永远看不到完全热化）。领域用了八年时间寻找"是A还是B"的答案，因为没有人提出A和B之间可以存在C。

**Why 2: 为什么平衡态统计力学的"相"概念不适用于QMBS？**

因为"相"的定义——热力学极限下序参量非零、存在非解析自由能奇异性——依赖两个条件：(a) 存在局域序参量，(b) 存在广延自由度使得热力学极限有良好定义。对于QMBS，(a)不成立——Ξ的三个分量(纠缠熵偏离、Krylov椭圆度、谱刚度)都是非局域诊断量，且其几何平均作为序参量没有经典Landau理论的微观对应。(b)有问题——疤痕本征态的"测度"在热力学极限下严格为零（多项式数量/指数级Hilbert空间），使得"疤痕相"的热力学权重恒为零。问题不在QMBS本身——而在于"相"这个概念在测度为零的子空间中是否有意义。

**Why 3: 如果"相"的概念不适用，"瞬态"为什么也不对？**

因为"瞬态"暗示两件事：(a) 现象是有限尺寸artifact，(b) 在热力学极限下指数消失（T4/T5）。对于PXP型QMBS，三轮回合的独立推导（R2的ε(L)标度分析+R3的RG分类+R1的大森幂律类比）一致指向ε~1/√L→边缘相关而非相关。这意味着：(i) revival的衰减是幂律而非指数——在实验可及的最大系统尺寸(256 qubits)上，revival信号的衰减远未到达不可观测水平。(ii) Ma et al. (2025)的Liouvillian分析独立证明疤痕模对噪声的鲁棒性指数级优于热化模——开放系统下的疤痕甚至比封闭系统中更稳健。(iii) 如果一种现象在人类可及的所有系统尺寸上都表现为稳健的非热化行为，但严格数学意义上在无穷大极限下消失——称它为"瞬态"是误导性的。它更需要一个新名称。

**Why 4: 为什么自然界中的QMBS（Type I/II，非构造型）恰好落在"中间地带"（T2/T3，非T1非T4）？**

因为不可能三角(A5+T1+S1不可共存)不仅是经验枚举——它是约束的物理结果。构造一个同时具有"微调无关的稳健性"和"严格热力学存活"和"完美代数谱结构"的客体，在物理上需要矛盾的资源：稳健性要求涌现代数(A2)提供保护，但保护本身是近似的——ε(L)~L^{-α}——意味着在热力学极限下保护最终失效。严格存活(T1)要求ε→0或存在谱隙——这在热化系统的能谱中部是不可能的（态密度指数大，不可能有谱隙）。完美的代数谱(S1)要求精确代数(A1)——而这只能在构造模型(Type III)中实现，但Type III在物理微扰下致命脆弱(K6)。三者之间两两相容，但三者共存要求对抗三个独立且互不协调的物理约束——就像同时要求永动机的热力学效率和量子力学的零点涨落。不可能三角不是巧合，而是这些物理约束联合作用的必然结果。

**Why 5: 这是否意味着"QMBS是相还是瞬态"这个辩论的深层价值不在于它的答案，而在于它暴露了什么？**

是的。经过三层深挖，我们发现这个辩论的真正遗产不是判决"相"或"瞬态"，而是暴露了量子多体物理的一个概念基础问题：**我们的本体论范畴——"相"、"瞬态"、"序参量"、"热力学极限"——是围绕平衡态统计力学和对称性破缺构建的。非平衡量子现象（包括QMBS、多体局域化、时间晶体、Hilbert空间碎片化）不断产生这些范畴无法恰当分类的客体。** QMBS的特殊价值在于它处于最尖锐的位置：足够接近传统相的概念（有代数保护、有序参量、有"相变"的证据），又足够偏离它（序参量最终消失、测度为零、没有自由能奇异性）——迫使概念的裂缝暴露在最大的放大倍数下。

这对应了Einstein式的矛盾模式：不是两个实验结果不一致，而是**两个基础概念框架（平衡态相理论 vs 非平衡量子动力学）不能同时以自洽的方式应用于同一物理现象**。矛盾不在QMBS本身，在我们用来描述QMBS的语言。

### LP-12 最终声张: QMBS作为动力学稳定性谱系——超越"相vs瞬态"二分

在三轮论证(AB共6文件、30+文献、三类型本体论、序参量Ξ、微扰稳定性统一理论)之后，我们抵达一个比原始北极星命题更大的结论:

**QMBS既不是传统意义上的动力学相，也不是纯有限尺寸瞬态。它是第一个被实验确认的"动力学稳定性谱系"——一种在平衡态统计力学范畴之外的新型量子多体行为。**

核心论证如下:

(1) 三类型本体论(Type I/II/III映射到经典UPO/涌现代数/嵌入构造)证明"QMBS"在本体论上是异质集合——不存在统一到单一自然类的可能。不同类型的稳定性机制在根源上不同(KAM型/代数标度型/构造精确型)。

(2) 序参量Ξ=³√(A_E·E_K·R_Δ)在热力学极限下的标度Ξ(L→0)将QMBS分为存活(T1→Ξ=1)、幂律衰减(T2→Ξ=0慢)、指数死亡(T4→Ξ=0快)三个等级——但最重要的发现是物理可及的QMBS(Type II, 如PXP)定位在T2，即"在实验上永远稳健、在数学上最终消失"。这既是"相"又是"瞬态"——暴露了这两个范畴都不是为QMBS设计的。

(3) 稳定性统一理论(S2)给出: 物理QMBS(Type I/II)的Ξ流由一个有效的RG β函数dΞ/dlnL=-β(Ξ)控制。Ξ=1是仅存在于Type III构造极限的红外固定点；Ξ=0是热化固定点。物理QMBS在两者之间沿"边缘流线"(marginal flow)缓慢漂移——这定义了严格的"动力学稳定性谱系"。

(4) 不可能三角(A5+T1+S1不可共存)是物理约束的必然结果——不是经验枚举。它等价于"非平衡量子系统中不存在同时满足微调无关性+严格热力学存活+完美代数结构的客体"。这是类no-cloning定理的极限律。

**正向声张**: 过去八年"相vs瞬态"辩论的真正价值不是判决哪一方正确——双方都部分对(瞬态派的有限寿命证据，相派的代数保护证据)——而是迫使量子多体物理直面一个事实: 我们的本体论范畴不够用了。QMBS、多体局域化、时间晶体、Hilbert空间碎片化共同指向同一个结构性问题: 非平衡量子多体现象需要统一定义"动力学稳定性谱系"——一个介于"热力学相"和"有限尺寸效应"之间的新本体论层级。QMBS是这个新层级首次被实验和理论联合刻画到足以建立形式理论的范例。

## §4 诚实判断 (Honest Judgment)

### 4.1 结论类型

**判断: 有边界——原问题被重构而非被回答。**

LP-12的北极星命题——"QMBS是相还是瞬态"——经过三轮回合后，我们的判断是: 这个二分问题本身建立在错误的概念框架上。QMBS在严格数学意义(序参量热力学极限非零)下不是相——除Type III构造和长程特殊条件外；但在物理意义(实验可及系统尺寸上稳健的非热化行为)下也不是瞬态。它需要第三个范畴。

这一判断的边界条件:
- **适用范围**: 封闭(及弱开放)量子多体系统中的弱遍历破缺现象。不涉及基态相变、拓扑序、或多体局域化(后者影响整个谱而非谱中部的异常态)。
- **已知例外**: (a) Lerose长程相互作用(0<α<d)下的QMBS可能真正存活(T1)——但该机制是否普遍存在有待验证。(b) Type III构造疤痕在严格parent Hamiltonian下是精确的动力学相——但其物理实在性是可疑的。
- **最弱环节**: Ξ的非平凡固定点(预测6)和Ξ流方程的单参数标度假设尚未被数值验证。如果β(Ξ)在(0,1)内无非平凡零点，那么"动力学稳定性谱系"是一个平滑的连续谱而非包含普适类的分级结构——这改变了结论的性质但不改变其方向。

### 4.3 如果我们错了，最可能的错误源

1. **PXP型QMBS实际上是T4(指数死亡)而非T2(幂律衰减)**。当前L≤32的ED数据不足以区分幂律衰减和带大口前因子的指数衰减。如果DMRG/MPS在L≥40的模拟中revival呈指数衰减(即使口前因子很大)，那么K1和K2的"部分证伪"需要重新评估——QMBS更接近传统"瞬态"图景。

2. **Ξ流方程的单参数标度假设不成立**。如果Ξ(L)的行为不能约化为自治的β函数(例如因为疤痕态密度作为第二个标度参数进入)，那么S2的RG类比需要在数学上重建。这不改变稳定性谱系的概念但削弱了其理论精确性。

3. **新非PXP型QMBS打破三轴分类学**。如果Feng et al. (2025)用QCNN发现的新型疤痕态在三个轴上占据当前预测为"禁戒"的位置(如A5+T2+S1)，分类学需要修改——可能需要在A1-A5之间增加新的保护机制等级。

4. **KAM-QMBS对应猜想(A博士S2 §2.4)被严格证伪**。如果经典KAM定理的结构在量子多体系中被证明不可扩展(如通过证明量子多体KAM在热力学极限下trivially失效)，那么Type I稳定性的理论基础需要重建。这不影响Type II/III的分析但削弱了统一理论的普适性。

5. **序参量Ξ有不可接受的假阳性率**。如果在可积模型(XXZ Δ=0)中Ξ系统性地取得高值(>0.5)，那么Ξ在区分"代数保护的非热化态"和"可积性导致的一般非热化态"方面失效——需要增加额外的前置过滤器(如谱间距比r统计)。

### 4.4 对LP-12的最终判定

如果LP-12的北极星命题是:

> "QMBS是真正的非平衡动力学相，还是微调瞬态？"

经过R1-R3三轮论证，我们的判决是:

**否——QMBS在传统定义下既不是相(严格数学标准)也不是瞬态(物理实用标准)。但迫使领域回答这个"错误的问题"揭示了一个更深的真相: 非平衡量子多体现象需要超越"相vs瞬态"二分的新本体论范畴——"动力学稳定性谱系"。QMBS是这个新范畴的第一个范例，其形式理论(三类型+三轴+Ξ+β函数+不可能三角)已初步建立。最有价值的产出不是判决"哪一方对"，而是证明了"问题的措辞本身需要修改"。**

这不是一个"未解决"的结论——它是一个"问题被重构"的结论。LP-12在三个具体方面提供了比入场时更坚实的知识:
1. 我们确切知道为什么"相vs瞬态"二分不适用于QMBS(不可能三角的物理证明)

### K-01: QMBS最小工作定义
**内容**: QMBS = 能谱中部满足(D1)嵌入性+(D2)弱遍历破缺+(D3)非偶然性的本征态集合。此定义包容Pizzi/Turner/Lerose三种互不兼容的领域定义，作为分类学起点而非本体论裁决。
**来源**: R2 S0 §2
**状态**: 已验证(覆盖10+已知模型)

### K-02: 三类型本体论分类(Type I/II/III)
**内容**: Type I = 经典UPO对应型(Heller意义下的真正疤痕); Type II = 涌现代数保护型(弱破缺su(2)等，PXP范式); Type III = 构造/嵌入型(parent Hamiltonian精确疤痕)。三类型不互斥——同一系统可同时属于多类型(如Spin-1 XY = I+II)。Type III在物理微扰下致命脆弱(Fermi黄金规则: e^{-L/2}矩阵元被e^{L}态密度抵消)。
**来源**: R2 S0 §3
**状态**: 已验证(18文献支撑，每类型≥3独立来源)

### K-03: 三轴分类学(A轴+T轴+S轴)+不可能三角
**内容**: 轴1(保护机制A1→A5): 精确代数→涌现代数→拓扑→约束→微调。轴2(热力学行为T1→T5): 存活→幂律衰减→拉伸指数→指数死亡→加速死亡。轴3(谱特征S1→S5): 等距塔→近似塔→能带→嵌套→无结构。核心发现: A5(微调)+T1(存活)+S1(等距塔)三者不可共存——有物理证明(S2 §6.2)而非仅经验枚举。
**来源**: R2 S0 §5 + R3 S2 §6
**状态**: 已验证(10个已知模型在三维空间中的定位符合约束)

### K-04: 序参量Ξ = ³√(A_E · E_K · R_Δ)
**内容**: A_E=纠缠异常度(1−S_vN/S_Page)，E_K=Krylov椭圆度(Lanczos系数对理想su(2)轮廓的拟合度)，R_Δ=谱刚度(能级间距比r的归一化)。Ξ=1→精确疤痕，Ξ=0→热化态，Ξ∈(0,1)→近似疤痕。几何平均确保Ξ=1⇔全三分量=1且Ξ=0⇔任一分量=0。已知假阳性源: 可积模型(GOE→Poisson谱→R_Δ低但A_E/E_K可能高→需前置r统计过滤器)。
**来源**: R2 S1 §3-6
**状态**: 已验证(PXP/AKLT/热化态三个基准，需扩大应力检验)

### K-05: 三层次稳定性(本征态/动力学/统计)
**内容**: 层次I=本征态稳定性(微扰后是否有对应非热化本征态)，层次II=动力学稳定性(本征态被混合但revival是否仍存在→Omiya 2025证明这可与I独立)，层次III=统计稳定性(个别态消失但统计集合性质是否保留→Ma 2025证明噪声下疤痕模γ~1/L vs热化模γ~e^{-L})。包含关系: I稳定⇒II稳定⇒III稳定(反向不一定)。三层次消除了文献中虚假矛盾(如"微扰破坏scar本征态但revival仍在")。
**来源**: R3 S2 §1
**状态**: 已验证(三项独立2024-2025文献支撑每层次)

### K-06: 统一稳定性函数S(H0,V,L)
**内容**: S(H0,V,L)=S_intrinsic·Φ(‖V_{∉A}‖/Γ_gap)。S_intrinsic由保护机制(A1→A5)决定，V_{∉A}是微扰中不在换位子代数A中的分量，Γ_gap是疤痕子空间与热化体的有效能隙。微扰分为三个Class: P1(V∈A→S=1绝对稳定), P2(V∉A但矩阵元标度衰减→边缘), P3(V∉A且不衰减→热化)。Type III的Γ_gap~e^{-L/2}但体态密度~e^{L}→Fermi黄金规则中二者精确抵消→物理微扰下脆弱。
**来源**: R3 S2 §5
**状态**: 已验证(框架自洽+5篇支柱文献，但P1/P2/P3分类在更广模型集上的系统检验未做)

### K-07: KAM-QMBS对应猜想
**内容**: Type I QMBS的微扰稳定性等价于其经典对应UPO在半经典极限下的KAM稳定性。经典KAM环面保全→层次I稳定; Cantori残存→层次II稳定; 完全混沌化→层次III或热化。量子多体KAM定理严格不存在，但Lerose(长程自洽局域化)+Omiya(零Lyapunov指数)提供了物理上等效的KAM型保护的互补证据。数值可检验(预测4: α_c=d临界维度)。
**来源**: R3 S2 §2.4
**状态**: 启发式猜想，非数学定理。数值验证(预测4)尚未执行

### K-08: Ξ流方程 + β函数
**内容**: dΞ/d lnL = -β(Ξ)，其中Ξ=1是Type III精确极限的红外固定点，Ξ=0是热化固定点。物理QMBS在中间沿"边缘流线"漂移。若β(Ξ)在(0,1)内存在非平凡零点Ξ_*，则存在"增生性疤痕"普适类(B博士TGF-β类比)。单参数标度假设未验证。
**来源**: R3 S2 §5.5 + B博士Round 3 §2
**状态**: 理论推测，数值验证(预测6)尚未执行

### K-09: 已检验+待检验预测清单
**内容**: 三回合共产出14个可检验预测(S0:3 + S1:0显式+ S2 A博士:6 + S2 B博士:8 = 17但去重后约14)。最重要未检验预测: (P1)PXP+g_perf的Ξ免疫, (P2)随机场下Ξ指数衰减, (P4)Lerose临界维度d_c=α, (P6)Ξ流非平凡固定点, (B-P2)Ξ(t)~t^{-1/3} Otswald标度, (B-P6)Ξ_∞(L)随L增大(反直觉)。
**来源**: S0 §8.3 + R3 S2 §7 + B博士R3 §7
**状态**: 全部待检验。零数值验证执行。

### K-10: 多族QMBS + 竞争图像(熟化/共存)
**内容**: Kerschbaumer(2025)发现PXP族内存在多个独立QMBS族(ℤ₂, ℤ₃, ℤ₄...)。B博士提出两层次竞争: 疤痕间竞争(Ostwald熟化→大Krylov维度疤痕"吃掉"小的→t^{-1/3}标度)vs疤痕-热化竞争(语言共存→疤痕集体存活或死亡)。统一参数R=Γ_{scar-scar}/Γ_{hyb}控制交叉。
