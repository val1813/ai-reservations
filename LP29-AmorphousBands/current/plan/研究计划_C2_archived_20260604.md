# 研究计划

## C2 Round 1 目标

当前北极星: LP29-C2 graph metrics 是否只是 Srivastava orbital-overlap metric 的重参数化。

1. A 路线: 用 Srivastava 2019 的 orbital-overlap integral 建立 baseline，明确它需要的结构输入、输出 effective mass/transport proxy 的方式，以及是否可从现有 Jankousky/Aliano/Furubayashi 数据构造同样品表。
2. B 路线: 构造与 orbital-overlap 不等价的 graph spectral residual features，包括 `lambda_2`、spectral radius、high-betweenness damage、degree-preserving rewired controls，并给出可检验 residual protocol。
3. INSPECTOR 重点: 防止 graph metrics 与 orbital-overlap 变量同义反复；防止 external label 泄漏；防止 synthetic benchmark 被当作物理验证。
4. 最小落地: 至少产出 C2 join schema，列出每列 provenance，并确定第一批可填数据来自 Srivastava PDF、Jankousky PDF/SI、B1 synthetic 还是手工 digitization。

## Round 1 目标

先判定 LP29 是否只是普通 mobility-edge/band-edge conduction 的再包装。

## A博士任务

1. 建立参数表: `m*≈0.2m0`、`μ=10-40 cm2/Vs`、`n=10^20-10^21 cm^-3`、`ΔE≈0.25 eV`、`l=1-3 nm`。
2. 计算 `tau = μm*/e`、`k_F=(3π^2n)^(1/3)`、`v_F=ℏk_F/m*`、`l=v_F tau`、`k_F l`。
3. 搜索并记录先发/反例: a-ZTO mobility edge、Robertson s-like conduction band、amorphous semiconductor band-edge conduction。

## B博士任务

1. 把 a-In2O3 抽象成金属 s 轨道有效 hopping 图。
2. 给出可 1-2 周实现的网络指标: giant component、平均度数、In-In 距离分布、O-O 缺陷比例。
3. 形成至少两个可证伪预测: 谱函数 ridge 展宽/IPR/level statistics 与网络阈值的同步关系。

## PI综合标准

- 若 `k_F l >> 1` 且文献已完整解释，则 LP29 降级为方法复核。
- 若 `k_F l ~ 1` 但仍 band-like，则保留 LP29-S2，主攻 Ioffe-Regel 边界附近的结构阈值。
- 若 B 的网络阈值不能产生比 A 更强的判别预测，则暂停该题。
