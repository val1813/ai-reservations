# LP29 Re-escalation PI 综合

## 被杀死的声张

1. 原声张: 非晶 band-like transport 需要 graph/In-s connectivity 作为新机制。被 Jankousky 2026、Srivastava 2019、percolation/disorder prior art，以及无 same-sample external-label 数据共同击穿。
2. 原声张: 非晶 band-like transport 本身是新现象，或“周期性不是必要条件”是新结论。被既有 mobility-edge、band-conduction 和 effective-band 文献击穿。
3. 原声张: LP29 graph metrics 已验证优于 mobility-edge/Ioffe-Regel controls。被 REVIEWER 的非循环同样品外部标签缺失指控击穿。

## A/B 独立草案汇合

A 与 B 独立给出互补但同向的更大声张:

> mobility edge、Ioffe-Regel、percolation、In-s graph connectivity 不是竞争机制，而是同一无序传播算子在动量空间、实空间图谱、输运统计和信息保真度上的不同投影；真正可检验的问题是这些投影的临界面是否在同一样品外部标签上同步。

## PI 判定

Re-escalation 成功产生可注册的新候选，但未产生已验证结论。

该声张比原 LP29 更大: 它从 a-In2O3 单系统判据之争上升为“无序介质中可传播谱的多投影临界性”问题。它也更危险: 若同一样品中 graph Laplacian/spectral-radius 临界点、IPR delocalization、Drude weight onset、Hall/optical tau 残差拐点不同步，则该大声张失败。

## 可检验预言

- 锁定 carrier density、onsite variance、linewidth convention、Hall-factor convention、finite-size/batch controls 后，graph spectral features (`lambda_2`, spectral radius, high-betweenness damage) 应预测 mobility-edge/Ioffe-Regel residuals。
- 高介数 conductive edges 的 targeted weakening 对 residual Drude/Hall/Wannier/spectral labels 的损失应大于 matched random weakening。
- Srivastava orbital-overlap baseline 加入后，若 LP29 graph metrics 的残差预测消失，则新候选降级为 overlap metric 的重参数化。

## 后续约束

新候选只能登记为待 AB 验证，不得当作 LP29 结论。当前 LP29 仍保持 protocol + synthetic benchmark 状态，真实外部标签缺失仍是致命执行卡点。
