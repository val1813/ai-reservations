# LP29-C2T contradiction deepening

Date: 2026-06-04

## Surface contradiction

Can graph spectral metrics add residual predictive power beyond a Srivastava-style orbital-overlap baseline?

## Deeper contradiction

The real contradiction is between:

- A: A material comparison can start once plausible graph, overlap, and label columns exist.
- B: A material comparison cannot start until row identity, label provenance, structure provenance, graph convention, baseline normalization, independent controls, and forbidden-control audit all close before label inspection.

## Deepest form

`prediction-first validation` versus `provenance-first validation`.

C2T resolves this for the current project by forcing provenance-first validation. Until a row passes `C2T_row_audit_template_v1.csv`, regression, residualization, and graph-vs-overlap comparison remain blocked.
