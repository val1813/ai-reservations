# LP29 GATE 降级前置 PI 判定

## 问题

当前北极星是否被推翻，是否必须触发 PI.md §2 条件B的强制挽救轮？

## 判定

否。当前可保留的北极星是 measurement-comparison protocol，不是“graph 新机制已成立”。REVIEWER 的 fatal 指控击穿的是机制级/发表级声张，而不是给出了反例证明 protocol 不可执行或物理上必错。

## 理由

- 已被推翻: “非晶 band-like transport 是 LP29 新机制发现”“graph metrics 已经验证优于 mobility-edge controls”“周期性非必要是新结论”。
- 未被推翻: “在同一样品、非循环 external-label 数据上比较 mobility-edge/Ioffe-Regel controls 与 graph/connectivity metrics 的残差预测力”。
- REVIEWER 明确给出 escape route: 产出 locked same-sample table 并运行预声明 residual comparison。这说明当前状态是 evidence gap / protocol-development，不是反例打穿。
- Re-escalation 已注册 LP29-R1 更大候选，但它是待验证候选，不替代当前事实状态。

## 结果

不触发强制挽救轮；不执行降级为“证伪-降级”。继续进入“矛盾深挖”。
