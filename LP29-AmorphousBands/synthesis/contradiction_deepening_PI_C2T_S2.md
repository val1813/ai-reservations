# LP29-C2T-S2 contradiction deepening

Date: 2026-06-04

## Surface Contradiction

A: Reported Srivastava `OI_norm` / effective-mass context is sufficient baseline context.

B: Reported context cannot be used as a reproduced exact `O_s` baseline without executable provenance.

## Five Whys

1. Why did S2 block exact reproduction?

Because the reported scalar does not include the source row/page, structure identity, pair construction, raw overlap sum, normalization rule, same-structure mapping, or executor trace needed to replay `O_s`.

2. Why are those missing fields not just metadata?

Because changing the structure, pair cutoff/list, weighting kernel, or normalization can produce a different overlap quantity while retaining the same narrative label.

3. Why does a different overlap quantity matter?

Because graph-vs-overlap validation asks whether two mechanisms explain the same material object. Without same-structure identity, the comparison is not between competing explanations of one object.

4. Why is same-object identity not guaranteed by citation?

Because a citation anchors a reported result, not the executable equivalence class of the observable. The observable identity is fixed only by the complete calculation path.

5. Why is this a deeper contradiction rather than a local data gap?

Because it separates two incompatible principles:

- Principle A: a literature-reported descriptor can be treated as a reusable scalar baseline when its label and DOI are known.
- Principle B: a computed material descriptor is an admissible baseline only when its observable identity is fixed by provenance and replay.

Both cannot be true for exact baseline validation.

## Deep Contradiction

The core conflict is not "can we find Srivastava SI?" It is:

> descriptor-as-label vs descriptor-as-reproducible-observable.

If descriptor-as-label is accepted, reported `OI_norm` can be used immediately but exact graph-vs-overlap residual validation becomes evidence-leaky. If descriptor-as-reproducible-observable is required, S2 blocks now but preserves the possibility of a real future comparison.

## Boundary

The deepest current answer is unknown provenance identity, not impossibility. S2 therefore closes as a negative admissibility result and a positive observable-identity requirement.
