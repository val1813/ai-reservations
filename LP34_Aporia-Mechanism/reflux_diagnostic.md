# Reflux Diagnostic — 信息回流诊断公式 v1.0

**一句话:** 如果你的理论声称基本单元像qubit一样运作（|0⟩→|1⟩最多一次），那么信息回流不能超过这个公式给的上界。超了→理论不满足"最多一次"假设→要么改理论，要么放弃假设。

---

## 公式

```
                    ⎧ N_S · q_S      1 - q_E ⎫
P_reflux  ≤  min  ⎨ ───────── ,  ───────── ⎬
                    ⎩ N_E · q_E        q_E   ⎭
```

**变量定义（全部可操作测量，不依赖DGF）：**

| 变量 | 含义 | 如何测量 |
|------|------|---------|
| N_S | 系统qubit数 | 数出来 |
| N_E | 环境qubit数 | 数出来 |
| n₀^S | 系统|0⟩态数 | 指针基population测量（σ_z tomography） |
| n₀^E | 环境|0⟩态数 | 同上 |
| n_reflux | 回流qubit数 | 追踪哪些S-qubit经历了\|0⟩→\|1⟩→\|0⟩ |
| n_forward | 前向转移数 | 追踪哪些S-qubit经历了\|0⟩→\|1⟩ |
| q_S | n₀^S / N_S | 系统未确定比例 |
| q_E | n₀^E / N_E | 环境未确定比例 |
| P_reflux | n_reflux / n_forward | 回流概率 |

---

## 怎么用

### 步骤1：准备
- 选系统S（N_S个qubit）和环境E（N_E个qubit）
- 初始化：全部在\|0⟩（或记录初始q_S, q_E）
- 让前向转移发生（让S和E按你的理论互动）

### 步骤2：测量
- 对S和E做指针基population测量
- 数n₀^S, n₀^E（\|0⟩态的数量）
- 追踪每个S-qubit：哪些经历了\|0⟩→\|1⟩（前向），哪些又回来了（回流）

### 步骤3：代入公式
- 算q_S, q_E, P_reflux
- 算上界 B = min(N_S·q_S/(N_E·q_E), (1-q_E)/q_E)
- 如果P_reflux ≤ B → ✅ 通过
- 如果P_reflux > B → ❌ 不通过

---

## 不通过意味什么

**不通过 ≠ 理论错了。** 不通过 = 理论不满足"每个bit最多toggle一次"这个前提。

可能原因：
1. 信息载体不是bit（可能是qutrit或连续变量）→ 公式不适用，跳过
2. 有效环境容量比你数出来的N_E小 → 你多数了
3. 系统-环境耦合容许多次toggle → 理论的动力学超出了"一次toggle"模型
4. 理论真的有问题——信息在系统中无界回流

**为什么这不是"排除"而是"诊断"：** 不通过不杀理论——但强制回答："你的理论的基本信息载体到底是不是bit？如果不是——它是什么？"

---

## 为什么公式成立（不依赖动态DAG）

这是**鸽子洞原理**，不是动力学推导。

N_E个环境bit，每个最多从\|0⟩→\|1⟩一次。环境总接收容量 = N_E·q_E。

回流需要：环境bit（已经是\|1⟩）→ 作为源 → 逆转系统bit（\|1⟩→\|0⟩）。这等价于"已归档的bit作为新信息的源发出"。

**两个上界，取更紧的那个：**

**上界1（接收端约束）：** 回流目标=系统S中仍是\|0⟩的bit（数量=N_S·q_S）。回流源=环境E中已变为\|1⟩的bit（数量=N_E·(1-q_E)）。每次回流消耗一个S-\|0⟩和一个E-\|1⟩。所以：n_reflux ≤ min(N_S·q_S, N_E·(1-q_E))。除以总容量N_E·q_E得第一项。

**上界2（发送端约束）：** 同上逻辑的对称形式。得第二项(1-q_E)/q_E。

**不依赖：** 时间的顺序、哪个事件先发生、图是静态还是动态、因果结构的具体形式。

**只依赖：** 每个bit最多toggle一次 + 计数正确。

## 工作示例

### 例1：N_S = N_E = 10, q_S = 0.3, q_E = 0.5

```
B = min(10×0.3/(10×0.5), (1-0.5)/0.5)
  = min(0.3/0.5, 0.5/0.5)
  = min(0.6, 1.0)
  = 0.6

容许P_reflux ≤ 0.6
你测出0.3 → ✅ 通过
你测出0.8 → ❌ 不通过（回流超过容量上限）
```

### 例2：N_S = 1, N_E = 100, q_S = 0.5, q_E = 0.9

```
B = min(1×0.5/(100×0.9), (1-0.9)/0.9)
  = min(0.5/90, 0.1/0.9)
  = min(0.0056, 0.111)
  = 0.0056

容许P_reflux ≤ 0.56%
大环境 → 回流几乎不可能 → 物理合理
```

### 例3：N_S = N_E = 5, q_S = 0.8, q_E = 0.2

```
B = min(5×0.8/(5×0.2), (1-0.2)/0.2)
  = min(0.8/0.2, 0.8/0.2)
  = min(4.0, 4.0)
  = 4.0

但P_reflux是概率 ≤ 1，所以实际约束=1.0（平凡——没有排除力）
环境已经高度确定(q_E=0.2) → 回流源充裕 → 界不约束
```

---

## 三点诚实标注

1. **公式本身不依赖DGF框架。** 它是鸽子洞原理——只要接受"每个bit最多toggle一次"，公式自动成立。你不必相信格点、q场、或信息容量是引力的起源。

2. **"最多一次"是前提不是结论。** 如果你的理论中bit可以toggle多次——公式不适用，不是理论错了。

3. **操作可测性依赖指针基选择。** 公式假设你有一个优选基（"哪个态是\|0⟩"可以被操作定义）。如果你的理论没有优选基——q_S/q_E不能被操作定义——公式不可用。这不是工具的问题——是理论的信息结构未定义。
