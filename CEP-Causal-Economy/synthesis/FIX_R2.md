### NF1: 加速度符号错误 —— a = -(c²/2)∇q（非 +(c²/2)∇q）

**审稿指控**: FIX_R1 L127写为 a = (c²/2)∇q，但正确推导应为 a = -(c²/2)∇q。粒子被推离引力源而非吸引。

**严重性**: FATAL (NEW) — 代数错误而非符号约定问题。

#### NF1.1 错误定位与追溯

FIX_R1 L125-129:
> $$\mathbf{a} = -\nabla\Phi = \frac{c^2}{2}\nabla q$$

代数检验：
- 定义: Φ = -(c²/2)(1-q)
- ∇Φ = ∇[-(c²/2)(1-q)] = -(c²/2) · (-∇q) = +(c²/2)∇q
- a = -∇Φ = -(c²/2)∇q

FIX_R1漏掉了外层负号：从 -∇Φ 到 +(c²/2)∇q 需要 Φ = +(c²/2)(1-q)，不是 Φ = -(c²/2)(1-q)。

追溯链：
- 原始A R2 §2.3已含此错误（a = -∇Φ = (c²/2)∇q）
- R1审稿M2指出Φ↔q对应是假设而非推导，但未发现符号错误
- FIX_R1修复后错误依然存在
- **三轮审查（R1+R2+FIX_R1）均未发现此代数错误**

#### NF1.2 修正推导

**正确的推导链**（统一使用q=空置比例，q=1真空，q=0最大信息密度）:

引力势对应:
$$\Phi(r) = -\frac{c^2}{2}(1 - q(r))$$

验证真空极限: q→1 ⇒ Φ→0 ✓
验证视界极限: q→0 ⇒ Φ→-c²/2（有限负值，在量子截断ε处正则化）

梯度:
$$\nabla\Phi = -\frac{c^2}{2} \cdot (-\nabla q) = \frac{c^2}{2}\nabla q$$

**正确加速度**:
$$\boxed{\mathbf{a} = -\nabla\Phi = -\frac{c^2}{2}\nabla q}$$

#### NF1.3 Schwarzschild验证

使用 q(r) = 1 - r_s/r（空置比例）:
$$\nabla q = \frac{r_s}{r^2}\hat{r}$$

$$\mathbf{a} = -\frac{c^2}{2} \cdot \frac{r_s}{r^2}\hat{r} = -\frac{c^2}{2} \cdot \frac{2GM}{c^2 r^2}\hat{r} = -\frac{GM}{r^2}\hat{r}$$

加速度指向 **-r̂** 方向（指向质量源）——粒子被质量源吸引。这正是引力的正确方向。

#### NF1.4 物理诠释验证（修正后）

修正前的错误公式: a = +(c²/2)∇q = +(GM/r²)r̂ → 粒子被推离质量源（排斥）

修正后: a = -(c²/2)∇q = -(GM/r²)r̂ → 粒子被拉向质量源（吸引）

物理方向一致性:
- ∇q 指向 **+r̂**（远离质量源，q增加，信息密度降低）

### NF2: τ的量纲不一致 —— ln 2 (bits/nats) ≠ t_P (秒)

**审稿指控**: FIX_R1中τ同时被赋予三个互不一致的值: (1) ln 2 ≈ 0.693（bit成本），(2) t_P = 5.39×10⁻⁴⁴ s（时间），(3) 1（自然单位）。量纲互不兼容，不能在同一求和中混用。

**严重性**: FATAL (NEW) — C[G]的三项求和依赖量纲一致性。

#### NF2.1 问题精确描述

C[G]定义:
$$\mathcal{C}[G] = \sum_i s(q_i) + \sum_{(i,j)} I(i:j) + \tau \cdot |E|$$

s(q_i)和I(i:j)的量纲是信息量（bits或nats，无量纲）。因此 τ·|E| 必须也是信息量，τ的量纲必须是**每边的信息成本**（[bits/edge]或[nats/edge]，无量纲）。

但FIX_R1三处给出了τ的互不一致值：

| 位置 | 值 | 量纲 | 用途 |
|------|-----|------|------|
| L254 (d_crit) | ln 2 ≈ 0.693 | 无量纲 (nats) | C[G]成本计算 |
| L352 (参数清单) | t_P = 5.39×10⁻⁴⁴ s | 时间 [s] | 参数物理值 |
| L366 (导出声称) | 1 | 无量纲 (自然单位) | 理论解释 |

ln 2 ≠ 1 ≠ 5.39×10⁻⁴⁴ s。数值不等，量纲不兼容。

#### NF2.2 修正方案: 区分两个独立物理量

CEP涉及**两个不同的"τ-like"量**，必须用不同符号区分：

**τ_edge** (边缘信息成本):
$$\boxed{\tau_{\text{edge}} \equiv \text{每条因果边的最小描述成本（单位: bits或nats，无量纲）}}$$

- 用于C[G]定义: C[G] = Σs + ΣI + τ_edge · |E|
- 值（在自然对数约定下）: τ_edge = ln 2 ≈ 0.693（nats）
- 值（在bit约定下）: τ_edge = 1（bit）
- **物理来源**: 一条最大熵边（q = 1/2时 s(1/2) = ln 2 nats = 1 bit）的熵成本，代表"指定一条边存在与否"所需的最小信息量

**τ_P** (Planck时间):
$$\boxed{\tau_P \equiv t_P = \sqrt{\frac{\hbar G}{c^5}} \approx 5.39 \times 10^{-44} \text{ s}}$$

- 用于电报方程: τ₀ ∂²_t q + ∂_t q = D_eff ∇²q，其中弛豫时间τ₀ = μ/η具有时间量纲
- τ_P是因果格点中**单条边对应的最短物理时间**
- **不直接出现在C[G]的数值计算中**

#### NF2.3 两个τ量的物理连接

τ_edge和τ_P通过**因果互信息生成率**γ₀连接:

在Planck尺度的离散因果格点上:
- 每个Planck体积包含一个二元自由度（'0'=空置，'1'=占用）
- 相邻自由度之间的因果边以速率 γ₀ = c/ℓ_P = 1/t_P ≈ 1.855×10⁴³ Hz 更新
- 在均衡态（q=1/2），每条边的互信息饱和至1 bit
- 因此**每条边的固定信息成本 τ_edge = 1 bit（或 ln 2 nats）**对应于**物理时间 τ_P = t_P 内的一次因果交互**

形式化:
$$\boxed{\tau_{\text{edge}} = \tau_P \cdot \gamma_0 \cdot \frac{k_B}{\hbar} \cdot \ln 2}$$

其中 γ₀ = c/ℓ_P = 1/t_P 是因果格点上的关系生成率。

验证量纲:
- τ_P [s] · γ₀ [1/s] · (k_B/ħ) [1/(K·s)]... 

实际上更简洁的处理方式:

**在自然单位制（c = ħ = G = k_B = 1）中**: τ_P = 1, τ_edge = ln 2 (nats) 或 1 (bit)。在自然单位中两者均为1量级但不等同。

**在SI单位中**: τ_edge和τ_P具有不同量纲且数值不等。在C[G]中**必须使用τ_edge**（无量纲信息量），在电报方程中**必须使用具有时间量纲的弛豫时间τ₀**（其值量级为τ_P但通过μ/η确定）。

**推导起点**: 宏观互信息I_macro由微观互信息I_micro通过数据加工不等式决定。

考虑两个微观节点a,b被粗粒化为宏观节点A,B。在粗粒化过程中:
- 微观状态: a ∈ {0,1} (空置/占用), b ∈ {0,1}
- 宏观状态: A ∈ {0,1} (粗粒化后的空置/占用状态), B ∈ {0,1}

粗粒化映射 f: {0,1}² → {0,1}（将两个微观bit映射为一个宏观bit）:
$$f(x_1, x_2) = \begin{cases} 0 & \text{if } x_1 = 0 \text{ and } x_2 = 0 \text{ (两个都空置)} \\ 1 & \text{otherwise (至少一个占用)} \end{cases}$$

在占用概率为 1-q（每微观节点独立）下:
$$P(A=0) = q^2, \quad P(A=1) = 1 - q^2$$

因此宏观空置比例 q_(2) = q²。但之前用的是 q_(2) = 2q - q² = 1 - (1-q)²——这对应"至少一个占用⇒宏观占用"的OR规则。两者一致: q_(2) = 1 - (1-q)² = 2q - q²。

但宏观q不直接决定I_macro。I(A:B)取决于A和B的联合分布，而联合分布取决于微观互信息的粗粒化。

**关键计算 — 均场近似下的r_I**:

在均场近似（微观节点独立给定其占用状态，q为全局参数）:

- 在饱和极限: I_micro ≈ ln 2（1 bit）
- 或者更一般地: I_micro = f_I(q)，其中f_I随q变化

粗粒化后，宏观节点A包涵两个微观节点(a₁,a₂)，宏观节点B包涵(b₁,b₂):
- A和B之间的互信息等于通过粗粒化映射传递的微观互信息
- 由数据加工不等式: I(A:B) ≤ min(I(a₁:b₁), I(a₁:b₂), I(a₂:b₁), I(a₂:b₂))

$$I_{\text{macro}}(q) = I_{\text{micro}}(q_{(2)}) \cdot [1 - p_{\text{loss}}(q)]$$

其中 p_loss(q) 是粗粒化导致的信息丢失概率。

其中分子2q(1-q)是"一个占用一个空置"的概率（信息部分丢失），分母1-q²是A=1的概率（归一化），η∈[0,1]是该情况下的平均信息丢失率。

### NM4: κ的符号矛盾 —— 统一约定

**审稿指控**: F1推导中κ = -M₀ < 0（梯度流约定），但F4校准中κ = c³/(8πG) > 0（Newton校准）。符号矛盾未解决。

**F4.1 参数校准** (FIX_R1 L352):

- **结论: κ > 0**

**矛盾的物理后果**: 如果κ > 0（与校准一致），则 J = -κ ∇q/q = -(κ/q)∇q，通量指向 -∇q 方向。反之如果κ < 0（与梯度流一致），则 J = |κ| ∇q/q，通量指向 +∇q 方向。

#### NM4.2 矛盾的根源

根源在于梯度流推导中选择的**信息流动方向约定**。

在CEP的梯度流框架中:
$$\partial_t q = -\eta \frac{\delta\mathcal{C}}{\delta q}$$

当δC/δq > 0（降低q可减少C[G]）时，∂_t q < 0（q减小）——系统朝降低C[G]的方向演化。这是标准梯度下降。

通量由连续性方程 ∂_t q + ∇·J = 0 决定。在稳态下（∂_t q = 0），∇·J = 0。

但在非平衡态下，通量J的符号取决于信息流的**物理方向**:
- 如果信息（占用）自然从高密度区流向低密度区: J ∝ -∇q（扩散型）
- 如果信息从低密度区流向高密度区: J ∝ +∇q（反扩散型——需要外部驱动）

CEP的物理图像: q场在信息化学势 μ = δC/δq ≈ ln((1-q)/q) 驱动下，信息从高势区流向低势区。在q≪1极限: μ ≈ -ln q。∇μ = -∇q/q。通量沿-∇μ方向（化学势降低的方向）:

$$J \propto -M_0 \nabla\mu = -M_0 (-\nabla q/q) = M_0 \nabla q/q$$

这给出J指向+∇q方向——信息从高密度(q小)流向低密度(q大)。这是**正确的物理方向**: 信息倾向于从"拥挤区"溢出到"空旷区"。

现在，标准信息通量约定（如DGF）使用的是:
$$J = -\kappa \frac{\nabla q}{q}$$

这给出J指向-∇q方向——信息**流向**高密度区。哪个是正确的？

#### NM4.3 解决: 明确信息流动的方向约定

信息流动有两种等价的描述:

**视角A**: q = 空置比例（CEP当前约定）
- 高信息密度 = 低q = 大部分细胞被占用
- 信息从占用区"溢出"到空置区 = 信息从低q流向高q = J · ∇q > 0
- 因此: J ∝ +∇q

**视角B**: q = 占用比例（替选约定）
- 高信息密度 = 高q = 大部分细胞被占用
- 信息从占用区"溢出"到空置区 = 信息从高q流向低q = J · ∇q < 0
- 因此: J ∝ -∇q

DGF使用视角B（q=占用比例——但FIX_R1将其统一为空置比例）。CEP的客观通量（J的物理大小和方向，而非其与q梯度的相对符号）在两种视角下相同。

#### NM4.4 统一解决方案

**统一约定**: 在空置比例q下，通量定义采用"信息释放为正"的约定:

$$\boxed{J = +\kappa \frac{\nabla q}{q} = +\kappa \nabla \ln q}$$

其中 **κ > 0**（标准正mobility）。

正号表示: 通量方向与信息释放方向一致——信息从拥挤的高占用区（低q）流向空旷的低占用区（高q），即 J 平行于 ∇q。

在q = 1 - r_s/r的Schwarzschild背景下:
$$\nabla q = \frac{r_s}{r^2}\hat{r} \quad (\text{指向外})$$
$$J = +\kappa \frac{r_s}{r^2} \cdot \frac{1}{1 - r_s/r}\hat{r} = +\kappa \frac{r_s}{r(r - r_s)}\hat{r}$$

J指向外（从视界处的最大信息密度向外释放信息）——物理正确。

与FIX_R1 F1.2关系的修正:

原公式: J = -κ ∇q/q（隐含κ<0使J指向正确方向）
新公式: J = +κ ∇q/q（κ>0，正号显式表示信息释放方向）

**数值相等性**: 在两种约定下，J的物理值相同:
- 旧约定: J_old = -(-|M₀|) ∇q/q = +|M₀| ∇q/q
- 新约定: J_new = +κ ∇q/q（κ = |M₀|）
- J_old = J_new ✓

#### NM4.5 通量符号的全文档统一

| 公式 | 旧约定 (FIX_R1) | 新约定 (FIX_R2) |
|------|----------------|----------------|
| 通量定义 | J = -κ ∇q/q（κ<0隐含） | J = +κ ∇q/q（κ>0显式） |

| Schwarzschild J | −κ·r_s/(r(r−r_s))·r̂ = +|κ|·...·r̂（向外） | +κ·r_s/(r(r−r_s))·r̂（向外） |

**验证**: Newton极限下通量应给出正确的引力加速度。

在弱场极限（q→1, ∇q ≪ 1）:
$$J = +\kappa \frac{\nabla q}{q} \approx +\kappa \nabla q$$

通量给出了一个与∇q成正比的流。在宏观对应下，物质对该信息通量的响应产生加速度 a ∝ -J（粒子逆信息流方向加速——信息从高密度区向外流，粒子被"吸入"高密度区）。

$$d_{\text{crit}} = \frac{\sum_v (k_v - 1)}{\sum_v k_v} \cdot \frac{m^2 - 1}{m - 1} \cdot \frac{\tau_{\text{edge}}}{\tau_{\text{edge}} + \bar{I}}$$

(m²-1)/(m-1) = m+1。因此 d_crit ∝ m+1 ∝ max_e I_e。
