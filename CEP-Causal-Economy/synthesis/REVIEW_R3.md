### 步骤1: C[G] 变分 → δC/δq

**审计 — 此处存在两个未声明的近似**:

$$\frac{\delta}{\delta q_k}\sum_{(i,j)} I(i:j) = \sum_{j \in \mathcal{N}(k)} \frac{\partial I(k:j)}{\partial q_k}$$

**(b) 边成本项的忽略**: τ_edge|E| 项对 q 的变分贡献。在固定图拓扑下，此项为零（|E| 不依赖 q）。但 C[G] 最小化应在**图拓扑也可变**的空间中进行——此时 |E| 依赖于节点状态分布，δ|E|/δq ≠ 0。文档假设图拓扑固定，但未声明。

**评级**: MAJOR —— 变分推导仅保留了 C[G] 三项中的一项（节点熵），其他两项的贡献被无声忽略。虽然"节点熵主导"在 q≪1 极限下可能是好的近似，但缺少定量论证。

### 步骤2: 通量 J 的推导

**公式** (FIX_R2 NM4 修正后):
$$\partial_t q = -\eta \frac{\delta\mathcal{C}}{\delta q} \quad \text{(梯度下降)}$$
$$J = -M_0 \nabla\left(\frac{\delta\mathcal{C}}{\delta q}\right) \quad \text{(梯度流框架)}$$

代入 δC/δq ≈ ln((1-q)/q):
$$J = -M_0 \nabla\left(\ln\frac{1-q}{q}\right) = -M_0 \left(-\frac{\nabla q}{1-q} - \frac{\nabla q}{q}\right) = M_0 \frac{\nabla q}{q(1-q)}$$

在 q≪1 极限:
$$J_1 = M_0 \frac{\nabla q}{q}$$

**FIX_R2 NM4 统一约定** (κ = M₀ > 0):
$$\boxed{J = +\kappa \frac{\nabla q}{q} = +\kappa \nabla \ln q}$$

**审计**:

**(a) 梯度流框架的适用条件**: J = -M₀ ∇(δC/δq) 假设信息流由化学势梯度 δC/δq 驱动，且输运系数 M₀ 为常数。这在近平衡态（∇q 小）下成立，但在 q→0（高信息密度梯度）时，M₀ 可能本身依赖 q。文档未讨论 M₀ 的常数性假设。

**(b) 从梯度下降到通量的衔接**: ∂_t q = -η(δC/δq) 是**均匀松弛**方程（无空间梯度）。要得到通量 J，需引入连续性方程 ∂_t q + ∇·J = 0，并识别 J ∝ -∇(δC/δq)。但 ∂_t q = -η(δC/δq)（无散度项）和 ∂_t q + ∇·J = 0 的联立要求 η(δC/δq) = ∇·J。在梯度流框架中，这对应 J = -M₀ ∇(δC/δq) 且 M₀ 与 η 有特定关系。文档未显式建立此关系。

**(c) q→1 极限的过渡**: 文档在通量推导中使用 q≪1 极限（J₁ = M₀ ∇q/q），但在 q→1 极限给出 J₂ ≈ -M₀ ∇q（FIX_R1 F1.2 L92）。这两个极限形式差异显著，且过渡区域（q ≈ 0.3-0.7，恰为因果相变附近）未被处理。在相变区域，通量形式可能既非 J₁ 亦非 J₂——这是 CMB I_ℓ 预言的关键区域。

**评级**: MAJOR —— 通量推导的三个技术步骤（梯度流框架的常数性假设、η→M₀ 的衔接、q≈0.5 过渡区域的处理）缺少数学闭合。

### 步骤3: 连续极限 → 电报方程

**Onsager 方程** (FIX_R1 M1.1):
$$\mu \partial_t^2 q + \eta \partial_t q = \xi \frac{\nabla^2 q}{q^2} - \xi \frac{|\nabla q|^2}{q^3} - s'(q)$$

**线性化** (q = q₀ + δq):
$$\mu \partial_t^2(\delta q) + \eta \partial_t(\delta q) = \frac{\xi}{q_0^2} \nabla^2(\delta q) + \alpha^2 \delta q$$
其中 α² = -s''(q₀) = 1/(q₀(1-q₀))

**最终电报方程** (除以 η 后):
$$\tau_0 \partial_t^2 q + \partial_t q = D_{\text{eff}} \nabla^2 q$$

**审计 —— 发现致命遗漏: 质量项的无声消除**:

线性化方程 (除以 η) 的完整形式应为:
$$\tau_0 \partial_t^2(\delta q) + \partial_t(\delta q) = D_{\text{eff}} \nabla^2(\delta q) + \frac{\alpha^2}{\eta} \delta q$$

最后一项 (α²/η)δq 是**质量项**（或等效地，一个恢复力项）。FIX_R1 和 FIX_R2 的最终电报方程中**此项被无声删除**。

**物理后果**:
- 完整方程的静态极限 (∂_t → 0): D_eff ∇²(δq) + (α²/η)δq = 0 → ∇²(δq) + m² δq = 0，其中 m² = α²/(η D_eff)
- 这是 screened Poisson / Yukawa 方程，解为 δq ∝ e^{-mr}/r 而非 δq ∝ 1/r
- **Newton 引力恢复（1/r 势）要求 m = 0**，即要求 α²/η = 0

**质量项何时可忽略？**

$$m^2 = \frac{\alpha^2}{\eta D_{\text{eff}}} = \frac{1}{q_0(1-q_0)} \cdot \frac{1}{\eta} \cdot \frac{\eta q_0^2}{\xi} = \frac{q_0}{\xi(1-q_0)}$$

筛选长度: $$\lambda = \frac{1}{m} = \sqrt{\frac{\xi(1-q_0)}{q_0}}$$

- q₀ → 1 (真空，Newton 恢复所需): λ → 0。**质量项在真空中发散** —— 确切地说，筛选长度趋于零，screened Poisson 与 Laplace 的区别在真空极限下最大化。
- q₀ → 0 (奇点): λ → ∞。质量项可忽略。
- q₀ = 0.5: λ = √ξ。质量项是否可忽略取决于 ξ 的具体值。

**这是一个结构性矛盾**: Newton 引力恢复需要 q₀ ≈ 1（真空）区域的静态解，但正是在 q₀ → 1 处，线性化方程的质量项发散，使 Laplace 近似（∇²q = 0）失效。CEP 能在 Schwarzschild 背景下恢复 1/r 势，是因为该推导跳过了线性化步骤，直接求解了**完整非线性**方程的静态极限——但文档声称的电报方程→静态极限→Newton 的推导链在线性化版本中存在缺口。

**评级**: **FATAL (NEW)** —— 这是 R1 和 R2 审稿均未发现的结构性数学缺口。线性化电报方程的质量项被无声消除，而保留它将改变静态极限的方程类型（Laplace → Screened Poisson），阻止 Newton 引力的恢复。

**精确表述**:
> 电报方程"τ₀ ∂²_t q + ∂_t q = D_eff ∇²q"仅在 α²/η ≪ D_eff/L²（筛选长度远大于系统尺度）的条件下成立。对于真空背景（q₀≈1），此条件不成立（λ→0）。CEP 文档从未注明此条件或论证其在所涉物理场景中的成立性。

## 第二部分：三个指定交叉检查

### 交叉检查 1: NF1 加速度符号

**命题**: a = -(c²/2)∇q → 代入 q(r) = 1 - 2GM/(c²r) → a = -(GM/r²)r̂

**验算**:
$$\Phi(r) = -\frac{c^2}{2}(1 - q(r))$$

$$\nabla\Phi = -\frac{c^2}{2}(-\nabla q) = \frac{c^2}{2}\nabla q$$

$$\mathbf{a} = -\nabla\Phi = -\frac{c^2}{2}\nabla q$$

代入 q(r) = 1 - r_s/r, r_s = 2GM/c²:
$$\nabla q = \frac{d}{dr}\left(1 - \frac{r_s}{r}\right)\hat{r} = \frac{r_s}{r^2}\hat{r} = \frac{2GM}{c^2 r^2}\hat{r}$$

$$\mathbf{a} = -\frac{c^2}{2} \cdot \frac{2GM}{c^2 r^2}\hat{r} = -\frac{GM}{r^2}\hat{r}$$

**结论**: ✓ 数学正确。加速度指向 -r̂（朝向质量源），与引力吸引性质一致。

**物理诠释自洽性**: ∇q = +(r_s/r²)r̂ 指向外（远离质量源方向，q 增加，信息密度降低）。a = -(c²/2)∇q 指向内（朝向质量源，q 减小，信息密度增加）。"粒子被信息密集区吸引"的诠释自洽 ✓。

**但需注意**: NF1 修复后的 J 符号（NM4 修正: J = +κ∇q/q）与 a 的方向**相反**（J 向外，a 向内）。FIX_R2 NM4.5 将此解释为 a ∝ -J（"粒子逆信息流方向加速"），并声明ακ/q = c²/2 在弱场下自洽。但 α 从未在 CEP 框架内独立导出——它是由 a = -(c²/2)∇q 和 J = +κ∇q/q 联立求解出的"对应系数"，而非推导结果。这是 M2（Newton 重言式）问题的通量版本。

### N3.1: 线性化电报方程中质量项的无声消除 [FATAL — NEW]

已在第一部分步骤3中详述。此处给出简洁摘要:

**问题**: 完整线性化 Onsager 方程为:
$$\tau_0 \partial_t^2(\delta q) + \partial_t(\delta q) = D_{\text{eff}} \nabla^2(\delta q) + \frac{\alpha^2}{\eta} \delta q$$

最后一项 (α²/η)δq 在 FIX_R1 和 FIX_R2 的最终电报方程中被消除。**文档中无任何关于此消除的声明、论证或条件说明。**

**后果**: 保留质量项后，静态极限从 ∇²q = 0 (Laplace) 变为 ∇²q + m²q = 0 (Screened Poisson)，其中 m² = q₀/(ξ(1-q₀))。对 q₀→1（真空），m → ∞（筛选长度 → 0），Newton 引力恢复完全失效。

**缓解因素**: 真实 Schwarzschild 背景的 q(r) 是空间变化的——不存在全局 q₀。完整的非线性 Onsager 方程的静态极限可能给出与线性化+删质量项不同的结果。但 FIX_R2 从未区分这两种推导路径，也从未讨论线性化质量项消除的适用范围。

**建议修复**: 
1. 显式说明质量项被消除的物理条件（如 α²/η ≪ D_eff/L²，即筛选长度远大于系统尺度）
2. 验证此条件在 Schwarzschild 背景下成立（或在哪些区域成立）
3. 或直接使用完整非线性方程的静态极限进行 Newton 恢复，绕过线性化

### N3.3: r_I(q) 在 q→0 时超过 1 —— 推导的物理不自洽 [MAJOR — NEW]

**位置**: FIX_R2 NM2.2 L422-428

**r_I(q) 公式**:
$$r_I(q) = \frac{s(2q - q^2)}{s(q)} \cdot \left[1 - \frac{2q(1-q)}{1 - q^2} \cdot \eta\right]$$

**数值表** (η = 0.5):

| q | s(q) | s(2q-q²) | p_loss | r_I(q) |
|---|------|----------|--------|--------|
| 0.1 | 0.325 | 0.398 | 0.09 | **1.11** |

r_I(0.1) = 1.11 > 1。FIX_R2 注: "r_I 在 q 极小时可 >1（粗粒化后互信息反增，因 q_(2) > q 时 s 更大）——在相变分析中取 r_I ≤ 1。"

**审计**:
- 数据加工不等式（DPI）要求 I(A:B) ≤ I(a:b)，即 r_I ≤ 1。r_I > 1 意味着粗粒化**创造**了信息——违反信息论基本原理。
- FIX_R2 将此归因于 "q_(2) > q 时 s 更大" —— 但 s(q) 是边缘熵而非互信息！r_I 的公式用了边缘熵比值 s(2q-q²)/s(q) 作为互信息比值 I_macro/I_micro 的代理——这两个量没有理由相等。边缘熵 s(q) 和互信息 I(a:b) 是不同量。
- "在相变分析中取 r_I ≤ 1" 是 ad hoc 截断——无物理理由。

**根源**: r_I(q) 的"推导"用边缘熵 s(q) 来近似互信息 I_micro(q)（假设"饱和极限 I = ln 2"或"更一般地 I = s(q)"）。但 I(i:j) = s(q) 仅在特定条件下成立（如两个节点完美相关且边缘分布为 q），这不是 CEP 的一般情况。

**评级**: MAJOR —— r_I(q) 的推导在数学上混淆了边缘熵和互信息，在物理上（r_I > 1）违反数据加工不等式，需 ad hoc 截断修复。

## 第五部分：隐式极限交换检查

### L1: 先取连续极限再变分 vs 先变分再取连续极限

**CEP 路径**: 先变分（δC/δq 在离散图上）→ 通量 J（离散图上）→ 连续极限 → 电报方程

**替选路径**: 先连续极限（C[G] → 泛函积分）→ 变分（δ/δq(x) 在连续空间上）→ 场方程

**审计**: 两条路径是否交换（commute）取决于离散图到连续体的极限交换条件。CEP 选择"先变分再连续"的路径。但变分 δC/δq 涉及图拓扑——在连续极限中，图拓扑被假定为规则格点。如果最优图 G* 的拓扑在离散层面是非规则的（这是 C[G] 最小化的自然结果），则"先变分"给出的最优条件包含图拓扑项，而"先连续"将这些拓扑项 smooth out 了。

**具体担忧**: 在离散图上:
$$\frac{\delta\mathcal{C}}{\delta q_i} = s'(q_i) + \sum_{j \in \mathcal{N}(i)} \frac{\partial I(i:j)}{\partial q_i} + \tau_{\text{edge}} \frac{\partial |E|}{\partial q_i}$$

第三项（图拓扑对 q 的依赖）在连续极限中消失（因假设固定格点拓扑）。但 C[G] 最小化应在**可变拓扑**上进行——此时 δ|E|/δq_i ≠ 0（节点状态影响边存在性）。在连续极限中丢失的正是这个拓扑反馈项。

**评级**: MAJOR —— 先变分再连续的路径选择隐含地假设了固定拓扑，而固定拓扑与 C[G] 最小化的精神（图拓扑也参与最小化）存在张力。两路径的差异在连续极限中表现为遗失的"拓扑反馈项"。

### L2: 先取静态极限再连续 vs 先连续再取静态极限

**CEP 路径**: 连续极限（电报方程）→ 静态极限（∇²q = 0）

**替选路径**: 离散动力学静态极限 → 离散 Laplace 方程 → 连续极限

**审计**: 对于规则格点上的线性动力学，两路径交换（扩散/电报算子在连续极限与静态极限下交换）。但 CEP 的电报方程含非线性项，且线性化质量项的存在（见 N3.1）使得静态极限和连续极限的交换性取决于质量项的 scaling:
$$m^2 = \frac{q_0}{\xi(1-q_0)}$$

在连续极限中，ξ 可能依赖于格点间距 a，从而 m 依赖于 a。两极限的交换需要显式验证，但文档未进行。

**评级**: MINOR —— 对于规则格点和合理 scaling，大概率交换。但质量项的存在增加了非平凡性。

| T_c(z) 宇宙学 (原 F5) | FIX_R2 NM3 推荐删除——实际上已放弃 |
| 参数自由度 (原 F4) | FIX_R2 NM6 诚实重估为 5 个事实自由参数 vs DGF 的 3-5 个——CEP 不具显著参数经济优势 |

### 三交叉检查中暴露的深层结构性问题

经过三轮审查（R1 → FIX_R1 → R2 → FIX_R2 → R3），以下模式浮现:

1. **推导链中存在两个"对应缺口"**: Φ = -(c²/2)(1-q) 和 a ∝ -J。两者都是将信息论量（q, J）映射到引力论量（Φ, a）的关键步骤，但都不是从 C[G] 变分推导的。它们是**物理对应**（经验识别）而非**数学推论**。

2. **线性化和连续极限中的系统性近似未受控**: 
   - 质量项消除（N3.1）
   - 格点间距遗失（N3.6）
   - 互信息项在变分中忽略（C0.1）
   - 拓扑反馈项遗失（L1）
   
   每个近似单独可能合理，但四个未受控近似的累积效果未知。

3. **CEP 最吸引人的"刚性预言"持续软化**:
   - R1: 声称 CMB I_ℓ 刚性、奇点发散指数刚性、w(z) 刚性
   - FIX_R1: w(z) 降级（F5），声称 CMB I_ℓ 和奇点发散仍刚性
   - R2: CMB I_ℓ 因相变退化失去刚性（NM2）
   - FIX_R2: 重新评级——仅 2 个刚性预言（奇点发散指数、远场无毛定理）
   - R3: 线性化问题（N3.1）影响 Newton 恢复 → 奇点发散指数的推导路径也受波及

## 最终裁决

### 裁决: **Reject**

### 一句话理由

第三轮数学审计发现了一个新致命问题（线性化电报方程中质量项的无声消除——N3.1），以及 9 个新重要问题（N3.2-N3.6, C0.1-C0.3, L1），证明 CEP 的核心推导链在连续极限→电报方程→静态极限→Newton 引力这一关键段落中存在未解决的数学缺口。

### R3 特有的拒稿理由（独立于 R1/R2 理由）

即使 R1 和 R2 的所有问题被完美修复（NF1 符号、NF2 量纲、NF3 候选表等），N3.1 单独构成新的拒稿理由：

> 线性化的 Onsager 方程含质量项 (α²/η)δq，该项在最终电报方程中被无声消除。保留此项将把静态极限方程从 ∇²q = 0 (Laplace) 变为 ∇²q + m²q = 0 (Screened Poisson)，阻止 Newton 引力恢复——因为 1/r 势仅由 Laplace 方程产生，而非 Screened Poisson 方程。在真空背景（q₀→1）下，筛选长度 λ→0，质量项最大化——恰在 Newton 恢复最需要的区域。此缺口位于 CEP 推导链的最核心环节（连续动力学→引力涌现），其修复不是"加一个条件"可解决的——需要重新审视线性化策略、背景选择、以及 Newton 恢复的整个推导路径。

### 对作者的建议

如果作者决定继续发展 CEP 框架（不针对 PRL/PRD 投稿，而是作为长期研究项目），最高优先级行动为:

1. **闭合 N3.1**（质量项）—— 这是当前最严重的数学缺口。选项: (a) 证明在 Schwarzschild 背景下 α²/η ≪ D_eff/L²（给出 L 的具体估计），(b) 直接从非线性 Onsager 方程推导静态极限而不线性化，(c) 展示完整方程（含质量项）的静态解仍可匹配 Newton 极限。

2. **计算 μ, η, ξ**（FIX_R2 声称"可计算但未计算"的三个参数）—— 这三个参数的实际计算是验证 CEP 参数经济性声称的唯一途径。

3. **构建最小格点模型数值模拟** —— 在可控的 2D/3D 离散格点上实现 C[G] 最小化，验证容量边界、因果相变、通量形式等核心声称是否在数值上成立。解析推导在三轮审稿中持续暴露未受控近似——数值验证是唯一可靠的确证路径。
