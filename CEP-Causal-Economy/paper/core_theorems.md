## 公理C0: C[G]最小化

**陈述**: 自然界在所有物理上可实现的因果图G = (V, E)中，选择算法信息含量C[G]最小的那个：

$$G^* = \arg\min_{G \in \mathcal{G}_K} \mathcal{C}[G]$$

其中香农代理C[G]定义为：

$$\mathcal{C}[G] = \sum_{i \in V} s(q_i) + \sum_{(i,j) \in E} I(i:j) + \tau_{\text{edge}} \cdot |E|$$

- 第一项: 节点熵之和，s(q) = -q ln q - (1-q) ln(1-q)，q ∈ (0,1)为节点"空置"比例
- 第二项: 边互信息之和，I(i:j)为节点i和j之间的因果互信息
- 第三项: 边存在本身的固定描述成本，τ_edge = ln 2 nats（≈ 0.693，或 1 bit）
- G_K: Kolmogorov结构函数定义的观测兼容图类（满足K-S间隙有界）

**前提假设**:
- PN1 (均质性): 大尺度q场平滑——条件性假设（依赖Planck时期初始条件正则性）
- PN2 (稀疏性): 平均节点度d̄ = O(1)——从C0可推导（FIX_R3 N3.5, 70%完成度）
- PN3 (局域性): 因果边仅连邻近节点——从互信息衰减+C[G]最小化可推导

**关键诚实标注**: Kolmogorov复杂度K(G)的不可计算性（图灵停机问题推论）使得C0的精神（K(G)最小化）与其操作性实现（C[G]最小化）之间存在**结构性间隙**——K-S等价性间隙。香农代理C[G]在"物理自然"图类上的有界性（PN2+PN3确保O(N^(1-1/d))上界）是当前可提供的最强论证，但不构成严格的数学等价性证明。所有定理在香农代理框架内严格成立。

## 定理1: 容量边界定理 —— C[G]最小化 → 每条微观边 ≤ 1 bit

### 精确陈述

> **定理 1 (容量边界)**. 设 G* = argmin_{G∈G_K} C[G] 为观测约束下的最小成本因果图。在G*的微观Planck格点表示上，每条基本因果边的互信息满足：
>
> $$I(i:j) \leq \ln 2 \text{ nats} = 1 \text{ bit}$$
>
> 此上界由Planck格点上二元自由度的物理本性保证，并由C[G]最小化下的边际成本/收益分析加强。

### 证明思路

**Step 1: 物理上界**. 在Planck尺度的离散因果格点上，每个基本自由度是二元的（空置/占用）。两个二元变量之间的互信息最大值由Holevo界限定为1 bit/qubit → I(i:j) ≤ ln 2 nats。

**Step 2: C[G]最小化加强**. 假设存在一条微观边承载 I > 1 bit。对于任何组合方案将这条"肥边"拆分为k条基本边（每条≤ 1 bit），C[G]的比较：

- 拆分前: C_before = ... + I (>1 bit) + τ_edge
- 拆分后: C_after = ... + ΣI_k (≤ k bits, 但ΣI_k ≥ I - δ) + k·τ_edge

由于τ_edge > 0，拆分总是增加边成本项（k·τ_edge > τ_edge）。但信息保持要求k ≥ ⌈I/ln 2⌉。在C[G]最小化下，如果I > τ_edge，合并优于拆分；但微观尺度上I_max = ln 2 = τ_edge，两者恰好平衡——这是C0自洽的数学体现。

**Step 3: 宏观肥边的非反例性**. 粗粒化图（宏观有效理论）中可能出现I > 1 bit的"肥边"——这些肥边是多个微观边粗粒化的产物。容量边界定理的判定对象是微观G*（C[G]最小化的直接解），粗粒化图不是G*。因此宏观肥边不构成定理反例。

**Step 4: 度条件**. 容量边界要求图的平均度d̄满足：
$$d_{\text{crit}} = \frac{\sum_v (k_v-1)}{\sum_v k_v} \cdot (m+1) \cdot \frac{\tau_{\text{edge}}}{\tau_{\text{edge}} + \bar{I}}$$

对于微观G*（m = 1, 所有边≤ 1 bit），在3+1维因果格点上典型d̄ ≈ 6-10 ≫ d_crit ≈ 2，条件轻松满足。

### 前提假设

- 因果格点存在于Planck尺度（a = ℓ_P）
- 每个格点承载一个二元自由度
- 图的平均度d̄ > 2（3+1维格点自动满足）
- 极稀疏图（d̄ ≤ d_crit）降级为猜想

### 适用范围

- **微观层面**: 严格成立——Planck格点+二元自由度+物理学上界+Holevo界
- **宏观层面**: 定理不直接适用于粗粒化图（但粗粒化图中的肥边是微观边聚合的产物，与定理相容）
- **强场区域**(q ≪ 1): 不变——边的比特容量不受q值影响

### 与DGF的关系

DGF将此作为**公理A2**: "每条因果边承载至多1 bit的互信息。" CEP将其降级为**定理**——从C0推导+Planck格点物理上界。这是CEP公理经济性的具体体现：CEP用1条公理(C0)完成了DGF用3+条公理才覆盖的逻辑空间。

### 诚实标注

- 容量边界的微观版本（Planck格点层面）是严格的——三轮审计（R1-R3）无任何挑战
- 宏观适用性依赖粗粒化映射的保真度——连续极限中的信息丢失标注为开放问题
- 极稀疏图（d̄ ≤ 2）的情况当前为猜想——在物理时空中极少见，不作为可检验预言的障碍

## 定理2: 通量定理 —— C[G]变分 → 香农通量 J ∝ +κ ∇q/q

### 精确陈述

> **定理 2 (香农通量定理)**. C[G]对空置比例q的泛函变分产生信息化学势 μ = δC/δq ≈ s'(q) = ln((1-q)/q)。在Onsager梯度流框架下，此化学势驱动信息通量：
>
> $$J = +\kappa \frac{\nabla q}{q} = +\kappa \nabla \ln q \quad (\kappa > 0)$$
>
> 其中 κ = c³/(8πG) > 0 通过Newton引力校准确定。正号约定表示信息从高密度区（低q）向外释放到低密度区（高q）。

### 证明思路

**Step 1: 化学势的变分推导**. C[G]对q_k的泛函变分包含三项：

$$\frac{\delta\mathcal{C}}{\delta q_k} = s'(q_k) + \sum_{j \in \mathcal{N}(k)} \frac{\partial I(k:j)}{\partial q_k} + \tau_{\text{edge}} \frac{\partial |E|}{\partial q_k}$$

在弱关联均衡态附近（χ²d_k ≪ 1），互信息项贡献为O(χ²)小量，边成本项在固定图拓扑下为零。节点熵项主导变分：

$$\frac{\delta\mathcal{C}}{\delta q_k} \approx s'(q_k) = \ln\frac{1-q_k}{q_k}$$

**Step 2: Onsager梯度流**. 信息动力学由Onsager变分原理描述：

$$\mathcal{O} = \int d^dx \left[-\frac{\delta\mathcal{C}}{\delta q} \partial_t q + \frac{\eta}{2}(\partial_t q)^2\right]$$

最小化δO/δ(∂_t q) = 0给出梯度下降：∂_t q = η^{-1} δC/δq。

通量通过连续性方程 ∂_t q + ∇·J = 0 引入，在局域输运近似下：

$$J = -M_0 \nabla\left(\frac{\delta\mathcal{C}}{\delta q}\right)$$

其中M₀ = κ = a²/η（FIX_R3 C0.2: η→M₀衔接闭合）。

**Step 3: 显式通量形式**. 代入化学势：

$$\frac{\delta\mathcal{C}}{\delta q} \approx \ln\frac{1-q}{q}$$

$$\nabla\left(\frac{\delta\mathcal{C}}{\delta q}\right) = -\frac{\nabla q}{q(1-q)}$$

因此在q ≪ 1极限（高信息密度区域）:
$$J = -M_0 \left(-\frac{\nabla q}{q}\right) = +M_0 \frac{\nabla q}{q} = +\kappa \frac{\nabla q}{q}$$

完整通量形式（含q≈0.5过渡区域）: J = κ ∇q/(q(1-q))，在q∈(0,1)上连续可微，q≈0.5处不产生奇异性。

**Step 4: κ的Newton校准**. 在弱场极限(q→1)下，通量J ≈ κ∇q。要求测试粒子加速度 a = -(c²/2)∇q（从测地线变分推导）与 a ∝ -J 自洽，给出比例系数 α_{aJ} = c²q/(2κ)。通过Newton匹配（a = -GM/r², q = 1 - r_s/r）确定：

$$\kappa = \frac{c^3}{8\pi G}$$

### 前提假设

- 弱关联均衡态（χ²d_k ≪ 1）——在CEP稳态附近成立
- 固定图拓扑（∂|E|/∂q_k = 0）——连续极限下合法（FIX_R3 L1）
- 局域输运（M(x,x') = M₀ δ(x-x')）——由PN3支持
- Newton校准的物理合法性——κ的值由观测确定，非理论推导

### 适用范围

- **q ≪ 1区域**: 通量形式 J ∝ ∇q/q 严格——互信息项贡献被包含且形式不变
- **q ≈ 0.5区域**: 完整形式 J = κ∇q/(q(1-q)) — 连续可微，无奇异性
- **q → 1区域**: 通量退化为扩散形式 J ≈ -κ∇q — 真空极限下的行为
- **饱和极限**(χ→1): 通量函数形式不变——仅mobility系数通过d_k因子重标定

### 与DGF的关系

DGF的通量形式为 J = -ξ(q)∇q，其中ξ(q)是**自由函数**。CEP将ξ(q)的自由函数空间替换为单一确定形式 ∇q/q——消除了整个函数空间的自由度。这是CEP相对于DGF最核心的定性参数经济性优势。

### 诚实标注

- 通量推导假设mobility M₀为常数——在强场(q ≪ 1)下M₀可能依赖q，标注为"近平衡近似"
- 完整通量形式J ∝ ∇q/(q(1-q))在q≈0.5处与极限形式∇q/q差异可测——但此差异不影响任何当前CEP预言
- 边成本项 ∂|E|/∂q_k 在可变拓扑下非零——代表图拓扑对信息密度的反馈，当前标注为开放问题（FIX_R3 L1）
- κ的值（c³/(8πG)）通过Newton校准确定——是现象学输入而非第一原理推导

## 定理3: 涌现引力定理 —— 通量+对应+f(q)R → 修正Einstein方程

### 精确陈述

> **定理 3 (涌现引力定理)**. CEP的信息通量动力学通过两个物理对应和一个耦合ansatz导出了修正Einstein场方程：
>
> $$G_{\mu\nu} = 8\pi G_{\text{eff}}(q) T_{\mu\nu} + \Delta G_{\mu\nu}[q]$$
>
> 其中:
> - G_eff(q) = G(q+ε)（真空极限恢复标准GR: G_eff(1) = G）
> - ΔG_μν[q] = (q+ε)^{-1}(g_μν□q - ∇_μ∇_νq) - 2(q+ε)^{-2}(g_μν|∇q|² - ∇_μq∇_νq)
> - 对应1: Φ ↔ q（引力势与空置比的线性对应: Φ = -(c²/2)(1-q)）
> - 对应2: r_s ↔ 2GM/c²（Schwarzschild半径识别——来自GR而非CEP推导）
> - Ansatz: f(q) = 1/(16πG(q+ε))（满足五条约束的最简候选形式）

### 证明思路

**Step 1: 测试粒子加速度的测地线推导**（FIX_R3 N3.2）. 测试粒子在q场中的最小耦合作用量：

$$S_{\text{particle}} = -mc\int ds + \alpha_0 \int q\, ds$$

变分给出修正测地线方程。在弱场静态极限下：

$$m\mathbf{a} = \alpha_0 \nabla q$$

通过Newton匹配确定耦合常数 α₀ = -mc²/2，因此：

$$\mathbf{a} = -\frac{c^2}{2}\nabla q$$

**Step 2: a ∝ -J 的导出**. 从通量定义 J = +κ∇q/q 和加速度公式：

$$\mathbf{a} = -\frac{c^2}{2}\nabla q = -\frac{c^2 q}{2\kappa} J$$

在弱场(q→1)下: a ≈ -(c²/(2κ))J。粒子加速度与信息通量**反平行**——粒子逆信息流方向运动（信息向外释放，粒子被向内吸引）。引力吸引作为"逆信息流运动"的物理图像。

**Step 3: 电报方程与Newton恢复的联系**. 通量J和连续性方程导出信息场的电报方程（完整线性化形式）：

$$\tau_0 \partial_t^2(\delta q) + \partial_t(\delta q) = D_{\text{eff}} \nabla^2(\delta q) + \frac{\alpha^2}{\eta} \delta q$$

在正确包含格点间距a后（FIX_R3 N3.6），筛选长度λ ~ 10光年。在太阳系尺度(L ≪ λ)上质量项可忽略，静态极限还原Laplace方程 ∇²q = 0 → q(r) = 1 - r_s/r → Newton势 Φ = -GM/r。

**Step 4: f(q)R耦合的构造**. CEP引力作用量仅包含单一的f(q)R项（替换范式——非附加于1/(16πG)）：

$$S_{\text{CEP}} = \int d^4x \sqrt{-g} \, f(q) \, R + S_{\text{matter}}$$

f(q)满足五条约束（空真极限、物理可观测量有限、量纲正确、单调性、场方程正则性），最简候选 A': f(q) = 1/(16πG(q+ε))。

对度规变分导出修正Einstein场方程（完整形式如上）。

**Step 5: 真空极限验证**. q → 1, ∇q → 0 时: G_eff → G, ΔG_μν → 0 — 标准GR完整恢复。

### 前提假设

- **对应1 (Φ↔q)**: 引力势与空置比例的线性对应——从C[G]变分+q场最小耦合作用量+Newton匹配确定（非独立假设——N3.2已将其升级为推导）
- **对应2 (r_s识别)**: Schwarzschild半径 = 2GM/c² —— 从GR接受的现象学输入（CEP不声称推导r_s）
- **Ansatz (f(q)形式)**: A'为满足五条约束的最简候选——非唯一（替代形式C', G同样满足约束）
- **替换范式**: f(q)R替代（非附加于）标准1/(16πG)R —— 此选择由约束(i) f(1)=1/(16πG)强制

### 适用范围

- **弱场太阳系尺度**: Newton引力完整恢复（λ ~ 10光年 ≫ 太阳系尺度）——条件性但经验充分
- **强场(r ~ r_s)**: ΔG_μν[q] 修正项在q→ε处以1/ε²增强——CEP预言Planck尺度量子引力修正
- **真空渐近区(r ≫ r_s)**: 标准GR行为恢复——修正项以∇q → 0消失
- **宇宙学尺度**: 质量项Yukawa修正可能产生可观测偏离（λ ~ L_galaxy）——需非线性处理
