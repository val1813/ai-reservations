## 0. 执行摘要

因果图的DGF (Discrete Graph Framework) 框架预言了一个精确的量子-经典过渡机制：因果环数量 b₁ 和 Cartan 参数 c 共同决定 Gram 矩阵的谱结构，进而决定系统态被环境区分的程度。当 Gram 矩阵的非对角元指数衰减至零 (|G_ab|→0)，Gram 趋近于单位矩阵 (秩≈d)，环境获得完美的 which-path 信息 — 系统退相干为经典。当 Cartan 参数处于 Clifford 点 (c=π/2)，|G_ab|≡1 始终成立，Gram=全1矩阵 (秩=1)，环境完全无法区分系统态 — 量子相干得以保留。

**核心数值结果 (c=0.5, vertex-sharing chain):**
- μ_measured = -0.836/ring vs μ_analytic = -0.835/ring (偏差 0.2%)
- b₁=8: rank_eff → d (全秩), mean|G_ab| → 0 (环境完美区分所有系统态)
- c=π/2 (Clifford): rank_eff ≡ 1 对所有 b₁ (量子相干保留)

**文献定位:** 没有先前的实验测量过量子信道的 Gram 矩阵谱、超导 qubit 上的 QCMI 或 Betti 数与退相干速率的联系。IBM Nighthawk (2026年1月) 的原生4-循环方形晶格使实验可行。

## 1. 光谱视角：为什么频率→谱是正确的语言

### 1.1 从旋转频率到频率谱

纯量子态在 Hilbert 空间中以确定的频率旋转。一个孤立 qubit 在 Bloch 球面上以 Rabi 频率 Ω 进动——这对应一个尖锐的谱线，一条线。当系统与环境耦合，这个尖锐频率被展宽：不同的环境配置对系统产生不同的相移，叠加起来形成连续的频率分布。

**Gram 矩阵精确编码了这个频率谱：**

考虑一个系统-环境整体处于纯态 |Ψ_SE⟩。对系统基 {|a⟩}，环境相对态为 |E_a⟩ = ⟨a|Ψ_SE⟩。Gram 矩阵定义为：

```
G[a,b] = ⟨E_a|E_b⟩
```

G 是一个 d×d 的半正定 Hermitian 矩阵，其对角元恒为 1 (归一化)，非对角元 |G[a,b]| ≤ 1 衡量环境对系统态 |a⟩ 和 |b⟩ 的区分能力。

**G 的本征值谱 {λᵢ} 正是量子信道的频率谱：**
- λᵢ 是信道对不同"频率模式"的透射率
- 有效秩 rank_eff = (Σλᵢ)²/(Σλᵢ²) = 1/Σpᵢ² 是可分辨频率的数量
- rank_eff = 1: 仅一个频率模式 — 环境完全不能区分系统态 — 量子
- rank_eff = d: 所有频率模式等权 — 环境完美区分所有系统态 — 经典

### 1.2 谱连续化的信息论含义

从量子到经典的过渡在谱语言中极其自然：**经典世界 = Gram 谱绝对连续 (全秩)**，**量子世界 = Gram 谱离散简并 (秩=1)**。

这个视角统一了多个已知的物理概念：
- **Khinchin 定理:** 热力学极限下离散功率谱 → 绝对连续谱
- **ETH (本征态热化假说):** 能量本征态在局域观测下不可区分 — 频率分辨率的丢失
- **Wigner-Dyson 统计:** 量子混沌系统的刚性谱 — 能级排斥消灭简并 → 频率分辨率的丢失
- **Zurek 的 einselection:** 指针态 = Gram→I 过渡中存活的本征值所对应的系统态

DGF 的增量是：**提供了谱连续化的微观驱动机制 — 因果环。每个因果环是一个"频率展宽器"，b₁ 个环累积展宽 Gram 谱从 δ-函数状 (量子) 到平坦 (经典)。**

## 2. 修正机制：Gram → I，而非 Gram → J

### 2.1 叙事修正

原始命题"Gram 矩阵秩随 b₁ 坍缩至 1"在方向上是错误的。正确的图像是：

| Cartan 参数 | Gram 极限 | 有效秩 | 环境区分能力 | 物理状态 |
|:-----------:|----------|:------:|:-----------:|:-------:|
| c = π/2 (Clifford) | **J** (全1矩阵) | 1 | 零 (所有态同印记) | **量子** |
| c = 0.5 (非Clifford) | **I** (单位矩阵) | d | 完美 (每态独有印记) | **经典** |
| c = π/4 (CNOT) | 中间态 | ~d/2 | 部分 | 过渡区 |

**物理直觉:** 每个因果环是一个"信息筛子"。对于非 Clifford Cartan 角，环 r 对环境产生的印记由系统态决定。b₁ 个环后，不同系统态的环境印记趋近于正交，Gram 矩阵趋近于单位矩阵，环境获得完美的 which-path 信息 → 退相干完成。

### 2.2 数值证据

以下数据来自 `verify_p0_gram_rank.py`，vertex-sharing chain 拓扑，p=0.5：

**c = 0.5 (非Clifford, 强退相干):**

|:--:|:-----:|:--------:|:-----------:|------|
| 1 | 4 | 2.29 | 5.2×10⁻¹ | 部分区分 |
| 2 | 8 | 3.04 | 2.7×10⁻¹ | 区分增强 |
| 3 | 16 | 4.27 | 1.3×10⁻¹ | 显著退相干 |
| 4 | 32 | 6.84 | 5.6×10⁻² | 接近经典 |
| 5 | 64 | 12.4 | 2.2×10⁻² | 强退相干 |

关键观测：
1. rank_eff 随 b₁ **增长** (不是坍缩!)，趋近于 d_sys
2. mean|G_ab| 随 b₁ **指数衰减**，验证 |G_ab| = exp(μ·b₁)

|:--:|:-----:|:--------:|:-----------:|
| 1 | 4 | 1.00 | 1.00 |
| 4 | 32 | 1.00 | 1.00 |
| 8 | 512 | 1.00 | 1.00 |

rank_eff ≡ 1 对所有 b₁ 精确成立——量子相干完全保留，无论环数多少。

### 2.3 解析公式

对于 vertex-sharing chain 拓扑，Gram 矩阵的非对角元有精确的乘积形式：

```
G[a,b] = ∏ⱼ₌₀^{b₁-1} [p·exp(icΔⱼ) + (1-p)·exp(-icΔⱼ)]²
```

其中 Δⱼ = (s_Qⱼᵃ + s_{Qⱼ₊₁}ᵃ) - (s_Qⱼᵇ + s_{Qⱼ₊₁}ᵇ)，sᵢ ∈ {±1}。

每个环贡献一个因子，两个环境 qubit 各贡献相同因子（故平方）。因子绝对值 ≤1：
- |因子| = 1 当 c·Δ ∈ πℤ (Clifford 或 Δ=0)
- |因子| < 1 对所有其他情况

**每环退相干率 μ：**

```
Δ 分布: {-4, -2, 0, 2, 4} 概率 {1/16, 4/16, 6/16, 4/16, 1/16}

μ(c,p) = 2 · Σ_prob(Δ) · ln|p·exp(icΔ) + (1-p)·exp(-icΔ)|
```

数值结果 (p=0.5):
- μ(c=0.5) = -0.8354/ring (解析) vs -0.836/ring (实测) — 偏差 0.2%
- μ(c=π/4) = -1.886/ring (最大退相干效率)
- μ(c=π/2) = 0 (Clifford, 零退相干)
- μ(c=π/8) = -0.249/ring (弱退相干)

**指数衰减律:**

```
⟨|G_ab|⟩ = exp(μ · b₁)  (a ≠ b)
```

对于非 Clifford 的 Cartan 角 (μ<0)，非对角元随 b₁ 指数衰减至零。宏观物体 b₁ ~ 10²³ → ⟨|G_ab|⟩ ~ exp(-10²³) ~ 0 ← 完全经典。

### 2.4 为什么原始叙事错了

原始"Gram 秩坍缩至 1"的错误根源在于混淆了两个不同的极限：

- **秩→1 (Gram=J):** 环境对所有系统态产生相同的印记 → 无法区分 → **量子相干保留** ← 这是 Clifford 情况
- **秩→d (Gram=I):** 环境对每个系统态产生唯一的正交印记 → 完美区分 → **经典退相干** ← 这是非 Clifford 情况

原始直觉"秩坍缩=信息丢失=经典"将秩的高低与信息量的高低错误关联。正确关联是：

```
秩低 (Gram=J) = 环境信息含量低 = 量子 (无退相干)
秩高 (Gram=I) = 环境信息含量高 = 经典 (完全退相干)
```

**校验公式:** 环境可获取的关于系统的 Holevo 信息 = log₂(d) - S(G/d)，其中 S 是 von Neumann 熵。Gram=J → S(G/d)=log₂(d) → Holevo=0 → 环境零信息 → 量子。Gram=I → S(G/d)=0 → Holevo=log₂(d) → 环境满信息 → 经典。

## 3. 序参量：C = 1 - rank_eff / d_sys

### 3.1 经典性参数定义

定义 **经典性序参量 (Classicality Parameter):**

```
C(b₁, c, p) = 1 - rank_eff(G) / d_sys
```

物理含义：
- **C = 0:** 有效秩=Hilbert 空间维度 → Gram=I → 环境完美区分所有系统态 → **完全经典**
- **C = 1:** 有效秩=1 → Gram=J → 环境无法区分任何系统态 → **完全量子**
- **C ∈ (0,1):** 过渡区 — 环境部分区分系统态

### 3.2 C 对 b₁ 的依赖

数值数据揭示了 C(b₁) 的标度行为：

**c = π/2 (Clifford):**
```
C(b₁) = 1 - 1/d_sys → 1  (d_sys → ∞)
```
对所有 b₁，rank_eff = 1 精确成立。量子相稳定，与环数无关。

**c = 0.5 (非Clifford):**
```
C(b₁) ≈ exp(γ·b₁)  → 0  (指数趋近)
```
其中 γ ≈ |μ| 从非对角元衰减率导出。`verify_p0_gram_rank.py` 测量值:
- γ_rank = 0.835 (±0.001) 从 ln(rank_eff-1) vs b₁ 拟合
- γ_offdiag = 0.836 (±0.001) 从 ln|G_ab| vs b₁ 拟合
- 两者一致，与 μ_analytic = -0.835 匹配

**c = π/4 (CNOT):**
```
C(b₁) → 0  (较慢衰减)
```
rank_eff ≈ d/2，G 近似于块对角结构——CNOT 只产生部分退相干，环境只能区分"计算基内"和"计算基间"的系统态。

### 3.3 相图

(c, b₁) 参数空间中的量子-经典相图：

```
        c=0        c=π/8       c=π/4       c=0.5       c=π/2
        (弱耦合)    (T门)       (CNOT)      (强退相干)   (Clifford)
b₁=1     Q          Q            Q/C         Q/C          Q
b₁=2     Q          Q            C           C            Q
b₁=4     Q          Q/C          C           C            Q
b₁=8     Q          C            C           C            Q
b₁→∞     Q          C            C           C            Q

Q = 量子 (C≈1), C = 经典 (C≈0), Q/C = 过渡区
```

**关键特征:**
1. Clifford 线 (c=π/2): 对所有 b₁ 保持量子 — **集体 Clifford 保护**
2. 弱耦合极限 (c→0): 对所有 b₁ 保持量子 — 因果环耦合太弱，无法产生显著印记
3. 非 Clifford 大 b₁: 必然经典 — **经典世界是因果拓扑的数学必然**
4. 中间区域 (c=π/4, 中等 b₁): 可调的量子-经典过渡 — 实验可及

## 4. 与已知物理的连接

### 4.1 Khinchin 定理与谱连续化

Khinchin 的经典结果: 对于一大类平稳随机过程，在热力学极限下，功率谱从离散线谱过渡到绝对连续谱。这正是 Gram 谱的行为——每个因果环贡献一个离散的频率分量 (相位因子 exp(icΔ))，b₁ 个环的叠加使谱从几个离散本征值连续化到整个 d 维空间。

DGF 将这个数学定理物理化：**b₁ 是控制参数，Cartan 参数 c 决定每个环的展宽效率 μ。热力学极限 b₁→∞ ⇒ 谱连续化 ⇒ 经典。**

### 4.2 本征态热化假说 (ETH)

ETH 声称: 在量子混沌系统中，能量本征态在局域观测下不可区分——约化密度矩阵的非对角元在能量本征基下指数衰减。ETH 的物理内容是 Gram 矩阵在能量基下的非对角衰减，但 ETH 从未提供这个衰减的微观机制。

DGF 的连接: **因果环提供 ETH 的动力学起源。** 每个能量本征态的 Gram 元由该态参与的因果环数量和环的 Cartan 参数决定。混沌系统天然具有大量复杂的因果环 → Gram 非对角快速衰减 → ETH 成立。可积系统因果环结构简单 → Gram 衰减慢 → ETH 破缺。

### 4.3 Wigner-Dyson 能级统计

量子混沌系统的 Wigner-Dyson 谱——刚性、能级排斥——对应于 Gram 谱中简并的消除。DGF 视角: 能级排斥是因果环对能量本征态的 Gram 非对角衰减在能谱上的投影。环数越多的系统，能级排斥越强，谱刚性越高。

可检验预言: **Betti 数 b₁ 与能级排斥参数 β 之间存在单调关系。** 更大 b₁ 的量子多体系统应展示更接近 Wigner-Dyson (β=1,2,4) 的能级统计。

### 4.4 Zurek 的 Einselection

Zurek 的 einselection 范式: 环境诱导超选择定则，选出"指针态"——那些在环境监控下保持对角相干性的态。DGF 提供了 einselection 的微观机制和定量计算:

- **指针态 = Gram 矩阵在 Gram→I 过渡中保持大对角元 (小非对角泄漏) 的系统基**
- 指针基由 Cartan 轴方向决定 — CFOL 定理的前身
- 指针态的"稳健性"由该基下 Gram 非对角衰减率 μ 量化
- **DGF 的增量:** 不依赖环境谱密度的现象学参数，而是从因果拓扑直接计算 einselection 速率

### 4.5 因果环退相干放大器与 Wall #9 的统一

Wall #9 给出了集体退相干概率:

```
D_global = 1 - [cos²(4c)]^{b₁}
```

退相干放大器给出 Gram 非对角衰减:

```
⟨|G_ab|⟩ = exp(μ(c)·b₁)
```

两者是同一现象的互补视角:
- **Wall #9:** 可观测量视角 — 退相干概率 D_global
- **退相干放大器:** 信息视角 — Gram 矩阵非对角元衰减 → 环境信息获取

数量级一致性: 对于 c=0.5，D_global(b₁=4) ≈ 1-10⁻⁴ ≈ 1, ⟨|G_ab|⟩(b₁=4) ≈ 0.04 → 0。两者均表明 b₁=4 已接近经典极限。

### 4.6 DGF 与 Jacobson (1995) 的关系

Jacobson 的 "热力学→Einstein 方程" 使用 Bekenstein-Hawking 熵 S=A/4ℓ_P² 作为输入。DGF 不推翻这个范式，而是为之提供微观基础：

```
DGF: S_BH = η₀ · b₁_horizon · ⟨|c|²⟩
     = A · η₀/(α·ℓ_P²) · ⟨|c|²⟩
     = A/(4ℓ_P²)  当 ⟨|c|²⟩/α = 1/(4η₀) = 2ln2
```

Jacobson 的输入 (BH 熵) 在 DGF 中成为输出: 视界熵来源于穿越视界的因果环累积的 QCMI。

## 5. 实验路线图

### 5.1 平台：IBM Nighthawk (2026年1月)

IBM Quantum Nighthawk 处理器 (120 qubit, 方形晶格) 是当前验证 DGF P0 预测的最合适平台:

**关键优势:**
- 方形晶格具有原生 4-循环 (plaquette) — 无需 SWAP 门即可构建因果环
- 120 qubit → 可构建 b₁=1..4 的环网络，在量子硬件上直接测量 Gram 矩阵
- 之前的尝试失败是因为缺乏原生 4-循环，SWAP 开销淹没了信号

### 5.2 协议：经典阴影 (Classical Shadow)

**方案:** 使用随机 Pauli 测量 (classical shadow) 协议测量 Gram 矩阵谱:

1. **态准备:** 在系统 qubit (Q₀..Q_{b₁}) 上准备最大纠缠态或选定计算基态
2. **环编码:** 通过 CNOT + 单 qubit 旋转在方形晶格的 plaquette 上编码 Cartan 参数为 c 的因果环
3. **经典阴影:** 在每个系统 qubit 上施加随机 Pauli 门 → 测量 → 经典后处理重建 Gram 矩阵
4. **谱分析:** 对重建的 Gram 矩阵对角化 → 本征值谱 → rank_eff, C(b₁)

**资源估计 (b₁=4, d_sys=32):**
- 需要 ~2000-5000 个经典阴影快照
- 每个快照: ~20-50 个双 qubit 门 (环编码) + 单 qubit 旋转 + 测量
- 总门数: ~10⁵-10⁶，在 Nighthawk 的退相干时间 (~100μs) 内可行
- 误差缓解: 零噪声外推 (ZNE) + 读出误差缓解 (REM)

### 5.3 关键观测量

| 观测量 | 定义 | 预言 | 零假设 (标准QM) |
|--------|------|------|----------------|
| rank_eff(b₁) | 1/Σ(λᵢ/Σλⱼ)² | 随 b₁ 增长 → d (c≠π/2) | 与 b₁ 无关 |
| ⟨\|G_ab\|⟩(b₁) | 非对角元均值 | 指数衰减 exp(μ·b₁) | ≈ 常数 |
| C(b₁) | 1-rank_eff/d | 指数衰减 → 0 (c≠π/2) | ≡ 0 (纯量子) |
| μ(c) | d(ln\|G\|)/db₁ | c=0.5: ≈ -0.835 | 0 (无退相干) |
| Clifford 保护 | C vs b₁ at c=π/2 | C ≡ 1 (全b₁) | C ≡ 0 |

**最重要的单一测量:** rank_eff/d_sys vs b₁ 对 c=0.5 和 c=π/2 的对比。如果 c=π/2 保持 rank_eff≈1 而 c=0.5 的 rank_eff 随 b₁ 显著增长，这构成 DGF 的定性确认。

## 6. 开放问题

### 6.1 Δ 关联在连通拓扑中

当前 vertex-sharing 分析假设不同环的 Δⱼ 是统计独立的。在更复杂的连通拓扑中 (边共享、2D 网格)，相邻环共享系统 qubit → Δⱼ 存在关联 → 有效 μ 可能偏离独立环乘积预期。

`gram_spectrum_2d.py` 的采样结果表明 2D 网格的 μ 在 vertex-sharing (-0.835) 和 edge-disjoint 之间，但精确的关联修正函数尚未解析推导。

**子命题 S0:** 推导连通拓扑中 Δ 关联的协方差矩阵，给出修正后的 μ_eff(b₁, topology)。

### 6.2 非 Cartan 对齐轴

当前所有结果假定所有 Cartan 轴对齐于同一方向 (n̂ⱼ = ẑ ∀j)。LP41-LP42 的 Ghost Zero 工作表明非对齐轴产生丰富的 QCMI 景观，包括幽灵零点 (QCMI=0 但非 Clifford)。

Gram 矩阵在非对齐轴情形的行为是开放问题: 非交换相位 (不同 σ_{n̂ⱼ} 不对易) 能否产生不同于指数衰减的谱结构？

**子命题 S1:** 在 B_{|E|}(S²) 辫群上计算 Gram 谱对轴配置的依赖，寻找非指数衰减的可能区域。

### 6.3 Γ₀ — 环执行速率

所有退相干速率以"每环"为单位 (μ/ring)。转换为物理时间需要环执行速率 Γ₀ (Hz) — 即单位时间内一个因果环完成的次数。

`T1_reconstruction.md` 中将 Γ₀ 关联到环境的不可约退相干率 γ_E。对于超导 qubit，估计 Γ₀ ~ 10⁶-10⁸ Hz；对于原子系统，Γ₀ ~ 10¹²-10¹⁵ Hz。但这些估计有数量级不确定性。

**子命题 S2:** 从底层物理 (qubit 门时间 / 原子跃迁速率) 推导 Γ₀ 的第一原理值，使 DGF 时间预言可转换为 SI 单位。

### 6.4 引力退相干的连接

Pikovski 等人 (2015) 和 Boettcher 等人 (2025) 提出了引力诱导退相干的替代机制 (时间膨胀导致的可区分性)。DGF 的因果环退相干放大器提供了一个正交的视角: 引力场本身由大量因果环组成 (b₁_grav ∝ M)，这些环通过 QCMI 累积产生退相干。

开放问题: DGF 的退相干速率在弱引力场中是否重现 Pikovski 的预言？两者是竞争机制还是同一底层动力学的不同侧面？

**子命题 S3:** 比较 DGF 退相干公式 τ_dec = 1/(|μ|·Γ₀·b₁) 与引力退相干时间 τ_grav = ħ/(k_B T ΔΦ²)，在可观测范围内寻找区分两者的实验特征。

### 6.5 退相干放大器的物理极限

当前退相干放大器公式 τ_dec = 1/(|μ(c,p)| · Γ₀ · b₁_active) 在极限 b₁→∞ 产生 τ_dec→0 (瞬时退相干)。物理上存在下限:
- 环执行速率 Γ₀ 不能超过 Planck 频率 (t_P⁻¹ ~ 10⁴³ Hz)
- 环间通信速率受光速限制

**子命题 S4:** 推导 DGF 框架内退相干速率的上限 (最小退相干时间)，与黑洞信息丢失悖论建立联系。

## 7. 结论

DGF 框架提供了量子-经典过渡的一个数学上精确、数值上可验证的机制：

1. **因果环是退相干的微观引擎。** 每个非 Clifford 因果环使 Gram 矩阵的非对角元乘以一个 <1 的因子，累积效应使 Gram→I (环境完美区分系统态)。

2. **Gram 矩阵的谱 (本征值分布) 是量子-经典过渡的完备描述。** rank_eff = 1⇔量子 (环境零信息)，rank_eff = d⇔经典 (环境满信息)。

3. **Cartan 参数 c 控制退相干效率 μ(c)。** c=π/2 (Clifford): μ=0, 量子受保护。c=π/4: 最大效率 μ=-1.886/ring。c=0.5: 中等效率 μ=-0.835/ring。

4. **经典世界不需要特殊初始条件或微调参数。** 只需要：(a) 世界由因果环组成，(b) Cartan 参数不全在 Clifford 点，(c) 宏观物体有大量环 → 经典世界是数学上的必然。

5. **实验验证在 IBM Nighthawk 上是可行的。** b₁=1..4 的环网络，经典阴影协议，关键观测量 rank_eff/d_sys vs b₁。

### 诚实边界

- Δ 关联在连通拓扑中的修正函数尚未解析推导
