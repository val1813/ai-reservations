## 攻击1：公设独立性 — 四公设实际是1+3装饰 [FATAL]

### 1.1 P4逻辑上包含P2

P2定义：每环Gram衰减 G→G·exp(μ)，经过b₁_eff个独立环后 G→G·exp(μ·b₁_eff)

P4定义：dτ/dt = q = exp(μ·b₁_eff)

**P4就是P2应用于"整个系统"并重新命名为"时间膨胀"。** 数学上：
- P2说：b₁_eff个环 → Gram矩阵衰减因子 exp(μ·b₁_eff)
- P4说：b₁_eff个环 → 固有时间比例因子 exp(μ·b₁_eff)

两者是同一个指数，同一个μ，同一个b₁_eff。P4没有引入任何新的数学结构——它只是给P2的衰减因子换了一个物理标签（从"量子相干度"换成"固有时间比例"）。

**P4蕴含P2的核心内容**（至少就引力预言而言，你只需要指数衰减因子，不需要Gram矩阵的全部结构）。反之，**P2不蕴含P4**（因为Gram矩阵衰减和固有时流逝之间没有逻辑必然性——这是P4额外添加的物理解释跳跃）。所以P2和P4不是独立的——它们构成一个"定义+解释"对，不是两个独立公设。

### 1.2 P3的"推导"被事后手工修正

P3声称：图Laplacian → Laplace-Beltrami → 空间度规。但源文件揭示：

- **agent_A_metric.md §1.6**: 共形因子推导给出 Ω² = q⁻¹，即空间度规 γ_ij = q⁻¹δ_ij（对应b=1）。
- **parameterization.md**: 明确列出核心张力——"b=1给出正确的1PN束缚能，b=2给出正确的光偏折。两者不等价。"
- **g00_derivation.md §3**: 注意到这个矛盾，然后通过"转换到面积半径坐标"将空间部分从q⁻¹调整为q⁻²。但这涉及坐标变换R = r·q⁻¹，该变换本身**依赖q场**——这是一个条件性的、非平凡的修正，不是"图Laplacian自动给出q⁻²"。

**作者自己的诚实评估（parameterization.md末尾）**: "b=2不是从图推导的——是被等价原理+各向同性+Newtonian极限联合强制的。"

**THE_TRUTH.md**: "因果图→Weyl几何...不是Riemann几何。两个独立几何结构不能塞进一个Riemann度规里。"

因此，P3的实际内容是："图Laplacian给出Weyl-integrable几何（Ω²=q⁻¹），然后我们手动选择b=2以满足光偏折观测。"这不是从图推导度规——这是用图动机装饰一个经验选择。

### 1.3 实际的公设结构是1+3

核心公设只有**一个**：**存在标量场q = exp(μ·b₁_eff)，其物理诠释为dτ/dt = q**（即P4）。

P1定义了b₁（纯数学定义，不是物理假设——任何图都有第一Betti数）。
P2定义了μ(c)（同样是数学定义——给了Gram矩阵就有的形式分解）。
P3的"推导"结论是Ω²=q⁻¹，但实际使用的度规是Ω²=q⁻²。

**等效陈述**: 如果作者将整个框架压缩为"假定dτ/dt = q，其中q = exp(-GM/rc²)由RG流可加性推导"，所有可观测预言完全不变。P1-P3增加的不是逻辑约束，而是叙事装饰。

密封性检验：找一个只满足P4但不满足P1-P3的理论，和DGF比较预言。你能找到——任何具有指数耦合的标量-张量理论（q = exp(αφ)）给出相同的PPN结构和类似的2PN偏离（只是具体数值取决于α）。P1-P3不改变这个等价类。

**定级: FATAL。四公设结构是叙事膨胀，不是逻辑进步。DGF在引力端是一个单公设理论（P4），其余三个公设提供动机而非推导约束。**

## 攻击2：α=4π是推导还是校准？[SEVERE]

### 2.1 表面叙述

A_dr_dtau_derivation.md声称：
1. κ = n_rings·σ_ring/(4π)（环耦合常数的微观定义）
2. σ_ring = α·ℓ_P²（环截面，α=O(1)几何因子）
3. |μ|·κ = G/c²（从牛顿极限要求）
4. ∴ α/(4π) · G/c² = G/c² → α = 4π

**作者将此呈现为"推导"**: α=4π不是自由参数，而是从Planck尺度环几何自然得出的。

### 2.2 实际发生了什么

步骤1-2定义α为一个未知几何因子。步骤3要求匹配牛顿引力。步骤4解出α=4π。**这是校准，不是推导。**

关键证据：作者自己在诚实评估（CA3）中写道：
> "从匹配牛顿极限反推出α=4π。这是'推导'还是'校准'的灰色地带。严格地说，α应该从因果环的微观几何（Cartan参数c、环的顶点度数、图的局部曲率）计算出来，不依赖宏观引力。**这是尚未完成的关键计算。**"

如果α不能从微观图论独立计算，那么匹配牛顿极限只是用另一个名字（σ_ring = 4πℓ_P²）表达了同一个经验事实（G是已知常数）。

### 2.3 等效参数计数

LP43状态：α=1（dτ=q·dt中的指数），b=2（g_ij = q^{-b}中的指数）→ 2个校准参数

四公设状态：
- α=4π → 1个"几何"参数（声称是推导的，实际是校准的）
- b=2 → 仍然是经验选择（从Cassini γ=1）
- μ(c) → 未确定（不同粒子不同μ，违反弱等效原理的风险）
- d=3 → "涌现"但依赖共形平坦假设
- 指数函数形式exp(μ·b₁_eff) → 未经独立检验
- dτ = q·dt中的线性系数 → 假设为1

**实际自由选择数量 ≥ 4。声称"压缩到1个参数"是误导性的。**

### 2.4 更深的循环性

μ·κ = G/c² 这个等式。其中μ来自P2（Gram衰减率），κ来自环微观几何。如果μ(c)因粒子种类而异（电子vs夸克vs中微子有不同的Cartan角c），那么κ必须反比于μ来保持乘积恒定。但κ的定义（n_rings·σ_ring/(4π)）涉及n_rings（每单位质量的环数），它本身假设了N_rings(m_p) ∝ m_p。

**整个结构是：用牛顿常数G确定μκ的乘积，再通过假设N_rings∝m_p将这个乘积分配给μ和κ各自。这个假设等价于弱等效原理——但DGF声称要解释引力，现在却需要预设WEP来使理论自洽。**

**定级: SEVERE。α=4π是反向工程校准，不是推导。自由参数数量没有减少，只是换了一个更隐蔽的位置。**

## 攻击5：P4的独立证伪性 [SEVERE]

### 5.1 指数形式的来源

P4: dτ/dt = exp(μ·b₁_eff)

为什么是指数？A_dr_dtau_derivation.md §3.2的论证：
1. 每环Gram衰减：G → G·exp(μ)
2. b₁_eff个独立环：G → G·exp(μ·b₁_eff)
3. 量子信道开放度q = Gram相干残留比例 = exp(μ·b₁_eff)
4. dτ ∝ q

**第3步到第4步是未被论证的跳跃。** Gram矩阵元G_ab = ⟨ψ_a|ψ_b⟩度量的是两个计算基态之间的重叠。为什么这个重叠比例应该等于固有时间流逝比例？

### 5.2 替代函数形式

假设真实的物理关系是 dτ/dt = f(μ·b₁_eff)，其中f(0)=1, f'(0)=1（恢复牛顿极限）。

候选：
- f(x) = exp(x)（DGF选择）
- f(x) = 1 + x + x²/2 + x³/6 + ...（泰勒级数，前几项和exp相同）
- f(x) = 1/(1-x)（不同的2PN行为）
- f(x) = cosh(x)（偶数项不同）
- f(x) = (1+x/n)^n（对有限n，与exp在O(x²)就有差别）

**所有这些函数在弱场极限（x≪1时f≈1+x）下都恢复相同的牛顿极限。** 差异出现在2PN阶（x³项及更高）。

目前的引力实验（太阳系+双脉冲星）只约束1PN。没有任何观测能区分exp(x)和1+x+x²/2在太阳系尺度。

**因此：P4的指数函数形式在太阳系尺度上是不可证伪的。** 它只在2PN（GW）处可证伪——但2PN处EXPONENTIAL FORM ITSELF从未被独立检验。如果未来GW数据偏离DGF的2PN预言，作者可以（而且无疑会）说"指数形式需要修正"而不是"P4被证伪"。

### 5.3 不可证伪性与特设性免疫

这正是PRD降级文档警告的风险：
> "The remaining PRD-level risk is that the framework may still lack a hard, normalization-independent discriminator."

如果理论中唯一可检验的预言（2PN GW）来自一个其函数形式从未被独立确定的假设，那么这个预言不能用来证伪理论——它只能用来拟合数据。**每当预言失败，函数形式就可以被修正。** 这是一个"不可证伪"的经典特征。

**定级: SEVERE。P4的指数函数形式在1PN不可证伪，在2PN可以随时被修正。缺乏硬化判别器是该理论作为"理论"的根本弱点。**

## 攻击6：Clifford引力不可见——数学套套逻辑 [MODERATE]

### 6.1 "预言"的内容

P2说Clifford门（c=π/2）有μ=0。P4说dτ/dt = exp(0·b₁_eff) = 1。因此：纯Clifford门构成的时钟不感受引力时间膨胀。

### 6.2 为什么它是套套逻辑

"μ=0 → q=1 → dτ=dt"只是定义的展开。如果μ=0，那么根据P4，自然有dτ=dt。这不是需要从理论推导出来的"惊人预言"——它是P4定义的直接推论。

类比：牛顿第二定律F=ma"预言"了零外力下加速度为零。这不是预言——这是定义的逻辑推论。

### 6.3 不可实现前提下的不可检验"预言"

更关键的是：这个"预言"以"存在纯Clifford门构成的物理时钟"为前提。但是：
- 物理相互作用的Cartan角由标准模型固定，不可调谐到Clifford值
- 没有已知的物理系统（原子钟、脉冲星、量子电路）是纯Clifford的
- 即使构造出量子电路Clifford时钟，其Cartan角在电路层面是Clifford的，但构成电路的物理材料（电子、原子核）仍然通过非Clifford相互作用耦合到引力

EMBER_REKINDLER对K3的评估："ALIVE — but trivial... this is a restatement of 'dephasing in the computational basis doesn't affect computational basis states.'"

**定级: MODERATE。这个"预言"是数学恒等式，不是物理预言。它不可检验（前提不可实现），即使可检验也是定义的展开而非理论的胜利。**

## 攻击7：对标量-张量理论的映射 [SEVERE]

### 7.1 DGF作为标量-张量理论

DGF度规：
$$ds^2 = -q^2 dt^2 + q^{-2} (dr^2 + r^2 d\Omega^2), \quad q = e^{-GM/rc^2}$$

在弱场极限：g₀₀ ≈ -(1-2GM/r)，gᵢⱼ ≈ (1+2GM/r)δᵢⱼ。

### 7.2 Brans-Dicke对应

标准Brans-Dicke理论（Jordan框架，无势）的PPN参数：
- γ = (1+ω)/(2+ω)
- DGF要求γ=1 → ω→∞
- ω→∞时，标量场变为非动力学 → 理论严格归约为GR
- GR没有2PN偏离

**这产生一个尖锐的非自洽性：**
1. DGF声称γ=1（与Cassini一致）
2. 在标准标量-张量参数化中，γ=1需要ω→∞
3. ω→∞意味着标量场无动力学 → 无2PN偏离
4. 但DGF声称有2PN偏离（~4%或-22.5%，取决于看哪个文件）

### 7.3 可能的外交辞令

DGF可能不是Brans-Dicke理论（后者的标量场动力学由标准动能项决定）。DGF的标量场q可能有更奇异的动能项，允许γ=1同时保持2PN动力学。

**但作者从未写出DGF的作用量。** 没有作用量，就无法：
- 检验场方程的自洽性
- 确定标量场自由度的传播速度（必须等于c以避免因果违反）
- 检验是否满足Ostrogradsky稳定性（鬼场问题）
- 与其他标量-张量理论进行系统比较

### 7.4 必须回答的问题

如果DGF是标量-张量理论（看起来必然是，因为它有共形因子q），那么：
1. 写出作用量S[g, q, matter]
2. 从中推导场方程
3. 证明球对称静态解是q = exp(-GM/rc²)且g₀₀=-q², gᵢⱼ=q⁻²
4. 推导q的传播速度
5. 证明理论在ω→∞极限下不平凡地归约为GR（保留2PN动力学）

**这些步骤都没有完成。** 没有作用量，DGF不是一个理论——它是一个度规ansatz。

**定级: SEVERE。DGF未写出作用量。声称γ=1+2PN偏离在标准标量-张量理论中是不自洽的（γ=1→ω→∞→无偏离）。作者必须展示DGF如何逃避这个约束。**
