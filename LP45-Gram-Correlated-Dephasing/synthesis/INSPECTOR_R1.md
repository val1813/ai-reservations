### 1. 量纲/单位

**A博士:**

- TVD ∈ [0,1]，所有报告值通过 ✓

- **问题:** c_z clip步骤 (line 148: `c_z = np.maximum(c_z, 0.0)`) 会抹掉本该为零的微小负值。对于正确模型，WH变换后c_z应为G矩阵的特征值，Gram矩阵对称非负定，c_z应天然≥0。代码中clip后需重归一化（line 150: `c_z /= np.sum(c_z)`），这导致原本Σc_z=1的精确数学性质被clip破坏后又被重归一化修复。在c=0.5时clip影响可忽略（负值仅来自浮点噪声~10^{-16}），但在c接近π/4时可能有物理上为零的c_z被clip到0后重归一化略微改变其他c_z。当前c=0.5测试下可接受。

**B博士:**
- c_z通过WH变换后**未clip负值也未重归一化**。理论上有微小浮点噪声，但B博士代码依赖c_z的绝对值做熵计算(`cz_pos = np.abs(c_z) + 1e-15`)，对负值有保护。

- **校验通过**（量纲层面），但数值正确性见第2节。

**综合判定:** 量纲/单位层面无严重错误，归一化处理各有瑕疵但不影响c=0.5下的定性结论。

#### 4.2 f(1,1)手工推导验证

对于(x_r, x_{r+1}) = (1,1):
- s_r^a = (-1)^{a_r}, s_{r+1}^a = (-1)^{a_{r+1}}
- s_r^b = -s_r^a, s_{r+1}^b = -s_{r+1}^a
- Δ_r = (s_r^a + s_{r+1}^a) - (s_r^b + s_{r+1}^b) = 2(s_r^a + s_{r+1}^a)
- 若a_r = a_{r+1}: Δ_r = ±4, cos²(c·4) = cos²(2) ≈ 0.1732
- 若a_r ≠ a_{r+1}: Δ_r = 0, cos²(0) = 1.0
- 背景平均: f(1,1) = 0.5×0.1732 + 0.5×1.0 = 0.5866

**确认: A博士的f(1,1)=0.5866是精确的背景平均值。B博士的f(1,1)=cos(4c)²=0.1732是错误的。**

### 6. 替代解释

#### 6.1 U形ρ(w)是最近邻模型的通用特征，非Gram特有

独立验证确认: **任何**满足f(1,1)·f(0,0) > f(0,1)·f(1,0)的1D最近邻MRF都产生U形ρ(w)曲线。这是Ising铁磁条件(相邻对齐受偏爱)的必然结果。

| 模型 | f(1,1) | ρ(1) | ρ(6) | U形? |
|------|--------|------|------|------|
| Gram (c=0.5) | 0.587 | 0.63 | 4.28 | 是 |
| 泛型NN (α=0.292, β=0.4) | 0.4 | 0.68 | 3.68 | 是 |
| 泛型NN (α=0.292, β=0.8) | 0.8 | 0.44 | 5.77 | 是 |

**结论:** U形ρ(w)是1D拓扑+最近邻耦合的通用特征，NOT Gram特有的cos²(c·Δ)结构。Gram的特殊贡献在于通过c参数和因果环拓扑(b1)给出了α, β的具体值，但这个定性模式不具特异性。

#### 6.2 "75% higher logical error rate"可被更高p_eff解释

若使用位置相关的单qubit p_i(内部0.457而非统一0.354)的i.i.d.基线:
- i.i.d.高权重概率显著增加(p^6: 0.354^6→约0.004 对 0.457^6→约0.009)
- ρ(6)从4.28降至约1.54（差64%）

这意味着A博士报告的"75% higher"中有相当一部分来自i.i.d.基线低估了单qubit错误率。Gram特有的关联增强效应比报告值小。

**可验证预测:** 若设计实验在n个qubit上施加Gram关联退相位，用位置相关的i.i.d.模型作零假设，可区分"简单位置相关"与"Gram关联结构"两种解释。

## 阻断项（必须修正）

### BLOCK-1: B博士的G(x)函数错误 [致命]
**文件:** `compute_angles.py`, line 81-88
**问题:** (x_r, x_{r+1}) = (1,1)时错误地将|Δ_r|固定为4，忽略了背景依赖性(a_r=a_{r+1}时|Δ_r|=4，a_r≠a_{r+1}时|Δ_r|=0)。正确背景平均为f(1,1) = 0.5·cos(4c)² + 0.5·1.0 = 0.5866，而非cos(4c)² = 0.1732。
**影响:** B博士所有数值结果(Angle 2/3/4/6的c_z、KL、Chernoff、SVD值)均基于错误数据。差异量级(TVD=0.098)与Gram-vs-iid差异(TVD=0.2)同量级，结论不可靠。
**修正:** 使用与A博士一致的背景平均方法: `avg_factor = 0.5 * np.cos(4*c)**2 + 0.5 * 1.0` for (1,1) patterns。

### BLOCK-2: i.i.d.基线不统一 [严重]
**问题:** A博士用p_eff(边界qubit边际)=0.354匹配i.i.d.；B博士用c_0匹配，得p≈0.41。这是两个不同的i.i.d.模型，产生的TVD/KL/Chernoff值无法直接比较。
**影响:** 无法判断"Gram vs i.i.d."差异中有多少来自Gram特殊关联、多少来自基线选择。
**修正:** 统一到至少两种i.i.d.基线(a)匹配平均单qubit错误率，(b)匹配位置相关单qubit错误率。报告两种基线下的差异。

### BLOCK-3: p_eff = 0.354037 "constant" 声张误导 [严重]
**文件:** `cz_structure_report.md`, Section 2.1
**问题:** p_eff仅对qubit 0（边界qubit）成立。内部qubit的Z错误概率为0.457389（高29%）。声明"CONSTANT determined solely by c, independent of n"在技术上是p_boundary的恒常性，但文脉暗示所有qubit统一。

**修正:** 明确区分p_boundary=0.354(恒定)和p_interior=0.457(恒定)。使用位置相关i.i.d.作为更公平的基线。

## 警告项（建议修正）

### WARN-1: U形ρ(w)的非特异性
A博士报告将U形ρ(w)作为Gram关联的特征指纹。但独立验证表明，任何满足f(1,1)·f(0,0) > f(0,1)·f(1,0)的1D最近邻MRF都产生U形曲线。应将此声明修正为"Gram关联产生特定数值的U形分布"而非"Gram特有的U形分布"。

### WARN-2: "75% higher logical error rate" 基于简化模型
该数字来自P(w ≥ ceil(d/2))的权重阈值近似，不是实际表面码+MWPM解码器的仿真结果。在学术发表中，应明确标注为"简化权重阈值模型的上界估计"。

### WARN-3: "exact 1D Ising" 应注明folded限定
A博士在第6.5节正确指出了folded近似与完整Gram通道的区别(G[a,a⊕x]依赖于a, σ~0.24)。但执行摘要和正文多处使用"exact"描述，应在每次出现时注明"for the background-averaged (Pauli-twirled) channel"。

### WARN-4: B博士的ξ/KL≈0.25不是发现
两个对易Pauli-Z通道的量子Chernoff距离自然小于经典KL散度（因为它们共享本征基，最优测量是经典的）。这不是Gram特有的性质，不是发现，不应作为贡献点。

### WARN-5: B博士的"Bond dimension 2"不是发现
任何1D最近邻MRF的MPS bond dimension天然为2。这是拓扑平凡性，不是Gram关联的特殊性质。在PRA投稿中应标记为"验证已知结构"而非"新发现"。

### WARN-6: c_z clip+重归一化的数值安全性
A博士代码中clip负值后重归一化在c=0.5时安全，但在c接近π/4时（某些c_z精确为零）会导致重归一化改变其他c_z的值。建议改为仅clip小于-1e-15的负值(报错)，保留0附近的值不动，然后用总和非1的相对偏差判断是否需重归一化。
