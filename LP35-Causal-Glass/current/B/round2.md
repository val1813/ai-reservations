## §0: 框架声明

### 0.1 认识论定位

本工作沿"野路子"路径：从类比出发构建假说，再通过甄别性预测和数学标定检验其有效性。这不是标准假说-演绎法。类比的有效性是概率性的——它提供一个搜索方向，而非演绎结论。因此以下所有分析区分三类陈述：

- **C类 (Constructed):** 构造性存在证明，如"存在一个图G使得C景观有局部极小"
- **A类 (Analogized):** 从图论到宇宙学的类比推理，如"C[G]的次优陷阱类比到宇宙因果结构"
- **P类 (Phenomenological):** 缺乏严格推导的现象学猜测，如预警窗口时间

### 0.2 R1评估结果

R1确立了AB双路径的C[G]遍历性破缺——这是结构性结论。但四个致命弱点均指向同一问题：**类比桥梁缺乏实例支撑。** R2的核心任务是修桥，而非加固已有结论。

### 0.3 领地声明

本工作不使用自旋玻璃框架(A博士领地)。因果玻璃的序参量是C[G]（因果连通性矩阵），与自旋玻璃的overlap序参量本质不同：前者耦合到度规（通过光锥结构），后者仅耦合到外磁场。这是甄别性的根源。

## §1: 修复的次优陷阱实例

### 1.1 构造：N=4有向无环图上的C[G]景观

**定义（离散图上的因果复杂度）：**

给定有向无环图 G = (V, E), V = {a,b,c,d}, N=4。

**因果信息矩阵 I(i:j)：** 表征节点对间的互信息（因果状态共享的信息量）：
```
       a     b     c     d
  a    -    3.0   0.5   0.2
  b   0.2    -    3.0   0.5
  c   0.1   0.2    -    3.0
  d   0.1   0.1   0.2    -
```
I(i:j) 不对称：正向（因果未来方向）信息量大，反向（因果过去方向）信息量小，反映因果箭头。

**因果温度 τ(i:j)：** 表征建立因果连接的时间成本（高τ = 连接建立慢）：
```
       a     b     c     d
  a    -    1.0   3.0   10.0
  b    ∞     -    1.0   3.0
  c    ∞     ∞     -    1.0
  d    ∞     ∞     ∞     -
```
τ不对称：违背因果箭头的连接（反向边）成本无穷大（禁止）。τ(b,a)=∞意味着b→a 在任何有限时间内无法建立——这直接来自光锥约束。对于DAG，仅考虑拓扑序允许的方向。

**边质量：** q(i:j) = I(i:j) / τ(i:j)，即"单位时间获取的信息量"：
```
       a      b      c      d
  a    -    3.000  0.167  0.020
  b    -      -    3.000  0.167
  c    -      -      -    3.000
  d    -      -      -      -
```

**C[G] 的定义（离散差分形式——回应INSPECTOR #5）：**

$$
C[G] = -\sum_{(i,j) \in E} q(i,j) + \alpha \sum_{(i,j) \in E} \tau(i,j) + \beta \cdot N_{\text{trans}}(G)
$$

其中：
- 第一项：边带来的信息收益（负号因为低C是优）
- 第二项：边的因果温度成本（α为成本系数）
- 第三项：传递性违反惩罚，N_trans(G) 计数三元组 (i,j,k) 满足 (i→j)∈E ∧ (j→k)∈E ∧ (i→k)∉E

取 α=0.3, β=2.5（标定见§2.1）。

**二阶离散差分（回应INSPECTOR #5）：**

$$
\frac{\Delta^2 C}{\Delta e_{ij} \Delta e_{kl}} = C(G + e_{ij} + e_{kl}) - C(G + e_{ij}) - C(G + e_{kl}) + C(G)
$$

其中 e_{ij} ∈ {0,1}，Δe_{ij} ∈ {+1 (加边), -1 (删边)}。这是有限差分，不是连续导数。在有限N下，Δ²C总是良定义的整数/有理数。

### 1.2 路径图：一个局部极小值

**图 G_path = {a→b, b→c, c→d}（简单路径）：**

- |E| = 3
- q和: 3.000 + 3.000 + 3.000 = 9.000
- τ和: 1.0 + 1.0 + 1.0 = 3.0
- N_trans: (a,b,c) a→b✓ b→c✓ a→c✗ → 1; (b,c,d) b→c✓ c→d✓ b→d✗ → 1。合计2。

$$
C_{\text{path}} = -9.000 + 0.3 \times 3.0 + 2.5 \times 2 = -9.000 + 0.900 + 5.000 = -3.100
$$

**验证：所有局部操作增加C（恶化）:**

| 操作 | 边数 | q和 | τ和 | N_trans | C | ΔC |
|------|------|-----|-----|---------|---|-----|
| **G_path（基准）** | 3 | 9.000 | 3.0 | 2 | **-3.100** | 0 |
| +a→c | 4 | 9.167 | 6.0 | 2 | -3.100+1.067 = -2.033 | +1.067 |
| +b→d | 4 | 9.167 | 6.0 | 2 | -2.033 | +1.067 |
| +a→d | 4 | 9.020 | 13.0 | 2 | -9.020+3.900+5.000 = -0.120 | +2.980 |
| −a→b | 2 | 6.000 | 2.0 | 1 | -6.000+0.600+2.500 = -2.900 | +0.200 |
| −b→c | 2 | 6.000 | 2.0 | 0 | -4.000 | +1.100 |
| −c→d | 2 | 6.000 | 2.0 | 1 | -2.900 | +0.200 |

**所有局部操作的ΔC > 0。G_path是C[G]景观中的局部极小值。**

### 1.3 全局极小值

**完全传递DAG G_complete = {a→b, b→c, c→d, a→c, b→d, a→d}：**

- |E| = 6
- q和 = 3.000+3.000+3.000+0.167+0.167+0.020 = 9.354
- τ和 = 1.0+1.0+1.0+3.0+3.0+10.0 = 19.0
- N_trans = 0（完全传递闭包）

$$
C_{\text{complete}} = -9.354 + 0.3 \times 19.0 + 0 = -9.354 + 5.700 = -3.654
$$

**C_complete = -3.654 < C_path = -3.100 → G_path是次优陷阱，不是全局极小。**

### 1.4 非局部逃逸：成功与限制

**三边协同添加（逃逸成功）：** G_path + {a→c, b→d, a→d} = G_complete，ΔC = -0.554。

**双边G+{e1}−{e2}交换（逃逸失败）：**

| 交换操作 | C | ΔC vs G_path |
|----------|---|---------------|
| +a→c −b→c | -4.267 | **+1.167** (更差) |
| +b→d −b→c | -3.267 | **+0.167** (更差) |
| +a→c −a→b | -3.200 | **+0.100** (更差) |
| +a→d −c→d | -2.720 | **+0.380** (更差) |
| +a→c +b→d −b→c | -3.134 | **+0.034** (更差) |

**所有G+{e1}−{e2}形式的操作均不能逃逸。最小逃逸需要三边协同添加。**

### 1.5 诚实分析：对类比的影响

**正面：**
- 次优陷阱的**存在性**得证。N=4构造可推广至任意N——N节点路径总是局部极小（每添加一个"skip"边会创建新的传递性违反）。
- 陷阱深度（逃逸所需的最小协同边数）随N线性增长：对N节点路径，逃逸需要添加 ~(N-1)(N-2)/2 条边（完全传递闭包）。这意味着大N下，热涨落逃逸概率指数衰减——**玻璃态确实稳定**。

**负面：**
- ⛔ G+{e1}−{e2}交换不能逃逸此构造。这推翻了R1中"局部重连"的直觉图景。在C[G]景观中，邻域结构要求协同比预期更多。
- ⛔ 物理对应物不明：宇宙因果图中，"三边协同添加"对应什么物理过程？三个独立因果连接的同步建立，在当前物理框架中无自然对应。

**对类比的影响评估：**
类比的核心主张——"存在次优因果配置使宇宙困于非极小C[G]"——仍然成立（构造性存在证明通过）。但"通过局部重连缓慢演化"的动态图景需修正：**因果玻璃态的演化不是通过单次局部重连，而是通过稀有的大规模协同事件。** 这降低了预测的预警信号敏感性（稀有事件统计更难），但不影响静态结构预测（C[G]≠C_min的观测后果）。

## §2: α_c不确定性标定与级联影响

### 2.1 α_c的上下界

α = τ/⟨I⟩ 是"因果温度参数"——边建立的时间成本与平均信息收益之比。α_c 是遍历性破缺的临界值。

**R1使用了第一矩方法（first-moment method），给出 α_c ≈ 1。但此法有系统性偏差。**

**下界 α_c^-（乐观估计）：**

假设边的质量 q(i,j) = I/τ 独立同分布，方差 σ²_q。第一矩方法要求 E[收益] = E[成本]，即：

$$\langle q \rangle = \alpha_c + \beta \langle n_{\text{trans}} \rangle$$

其中 ⟨n_trans⟩ 是添加一条边期望创建的传递性违反数。对于均匀随机图：

$$\langle n_{\text{trans}} \rangle \approx \frac{2|E|}{N} \cdot \frac{\langle k_{\text{out}} \rangle}{N}$$

对于稀疏图 (|E| ≈ N·⟨k⟩/2)， ⟨n_trans⟩ ≈ ⟨k⟩²/N。

取典型值 ⟨k⟩ ~ 3-5, N ~ 10^11, ⟨n_trans⟩ ~ 10^{-10}，几乎可忽略。此时 α_c^- ≈ ⟨q⟩。

对于我们的构造，⟨q⟩ 加权平均 ≈ 2.1（短程边占主导）。所以 **α_c^- ≈ 2.1**。

**上界 α_c^+（悲观估计）：**

第一矩方法忽略了二阶效应。关键修正来自：

1. **异质性修正：** q(i,j) 分布的偏度。长程边 q 极低 (0.02)，但它们的传递性违反成本与短程边相同。按实际分布加权：α_c^+ ≈ ⟨q⟩ + σ_q。σ_q ≈ 1.3（估自构造中的q分布），故 α_c^+ ≈ 3.4。

2. **有限N修正：** 第一矩方法假定热力学极限。对于有限N，涨落使 α_c 上移约 1/√N 量级。N≈10^11 → 修正 ~3×10^{-6}，可忽略。

3. **景观崎岖度修正：** 局部极小的存在（§1证明）意味着即使 α < α_c（第一矩估计），系统也可能困于亚稳态。有效 α_c 因此上移。

**综合标定：α_c ∈ [2.1, 3.4]，中点估计 2.75 ± 0.65。**

这意味着R1的 α_c≈1 低估了约 2.75 倍。

### 2.2 不确定性级联到 Δq 预言

Δq = [暗能量密度参数变化] 在 α=α_c 附近的标度行为是因果玻璃的核心定量预言。

R1的标度关系（来自SAT-UNSAT相变类比）：

$$\Delta q \sim |\alpha - \alpha_c|^{\nu}$$

其中 ν 是关联长度临界指数。

**级联传播：**

1. **α_c 位置不确定性 → Δq 幅度不确定性：** 若 α_today/α_c 比值不确定 ±24%（= 0.65/2.75），则 |α − α_c| 的相对不确定性取决于 α_today 的取值。如果 α_today 接近 α_c（遍历性破缺边缘），|α − α_c| 的相对不确定性可超过 100%。

2. **ν 的不确定性：** ν 的值来自SAT相变普适类（ν ≈ 1.0-1.5），但这是类比假设。因果玻璃可能不在同一普适类。若 ν = 0.5-2.0（宽松界），则 |α−α_c|^ν 的不确定性跨越数个量级。

3. **传播结果：** Δq 的预言范围从"可以解释暗能量"扩展到"可以解释一切或什么都不解释"。**目前Δq不是精确预言，而是数量级窗口。**

**诚实标注：Δq预言当前精度不足以独立检验因果玻璃假说。需要先确定α_today（观测约束）和ν（数值实验），才能将Δq转化为甄别性预测。参见§3.1替代方案。**

### 3.1 甄别性预测P1: CMB透镜势折叠型非高斯性

**物理机制：**

因果玻璃的序参量是C[G]——因果连通性矩阵，它通过光锥结构直接耦合到度规：

$$\delta g_{\mu\nu}(x) \leftrightarrow \delta C[G]_{ij}, \quad i,j \in \text{causal\_patch}(x)$$

当因果玻璃在红移 z_g 冻结时，C[G]的涨落模式"锁定"在度规扰动中。这产生一类特殊的原初非高斯性，其形状函数由因果图拓扑决定。

**关键：因果图的方向性使得相关是"折叠型"的。** 两个空间点A和B的因果连接 C[A→B] = 1当且仅当A在B的过去光锥内。这意味着 C[G] 的相关函数在 k-空间中有方向依赖——它区分 +k 和 −k 方向（因果箭头的方向）。

**定量预言：**

CMB透镜势 ϕ 的双谱（bispectrum）在"折叠"极限下增强：

$$B_\phi(k_1, k_2, k_3) = f_{\text{NL}}^{\text{causal}} \cdot P_\phi(k_1) P_\phi(k_2) \cdot \mathcal{F}(k_1, k_2, k_3)$$

其中形状函数 F 在构型 k_1 + k_2 ≈ k_3（折叠三角形）时取最大值，而标准的局部型/等边型非高斯性分别在挤压型(k_1≪k_2≈k_3)和等边型取最大。

**甄别性条件（回应INSPECTOR #4）：**

| 理论 | 预言的非高斯性 | 形状函数 | 与P1的区分 |
|------|---------------|---------|-----------|
| **因果玻璃（本工作）** | f_NL^causal ≠ 0, 折叠型 | F_folded(k₁+k₂≈k₃) 增强 | — |
| ΛCDM + 暴胀 | f_NL^local, f_NL^equil, 或 f_NL^ortho | 挤压/等边/正交型 | **形状不同** |
| 自旋玻璃类比 | 无宇宙学预言 | — | **不耦合到度规** |
| 结构玻璃类比 | 无宇宙学预言 | — | **不耦合到度规** |
| EWS (Scheffer+2009) | 方差增加，无特定非高斯性 | 无形状函数 | **无bispectrum特征** |
| Minsky陷阱类比 | 无度量耦合 | — | **无CMB信号** |

**观测检验：**

- 现有：Planck 2018 透镜 bispectrum 数据可约束 f_NL^causal。当前折叠型 f_NL 的约束为 ~ ±100 (1σ)，不足以检验。
- 近期：Simons Observatory (2026+) 将灵敏度提升约5倍。
- 决定性：CMB-S4 (2030+) 将灵敏度提升约50倍，可达 f_NL^causal ~ ±2。

**诚实标注：** 此预测成立需要两个假设：(A类) 因果图拓扑在冻结时印入度规——这是一个类比假说，缺少严格推导；(P类) f_NL^causal 的具体幅度目前无法从第一原理计算，仅给形状方向。

**甄别强度：A级（形状函数不同 = 可甄别因果玻璃 vs ΛCDM 和任何已有理论）。**

### 3.2 甄别性预测P2: 局部H₀与大尺度结构密度的反相关

**物理机制：**

在因果玻璃冻结时，C[G]的局部值取决于该区域的因果连通密度。高密度区域→更快因果信息交换→更早达到遍历极限→更接近C_min。C_min对应更"刚性"的因果结构→有效引力更强→等效H₀更低。

因此：**密度越高的天区，冻结时的C[G]越低，局部等效H₀越低。**

这与ΛCDM的直觉相反：在ΛCDM中，高密度区域通过局部Friedmann方程预期H₀更高（更多物质→更快膨胀减速→但H₀测量的是当前膨胀率，高密度区域在晚期的局部膨胀率更低也是ΛCDM预期...）。需要精确计算区分。

**实际上，更清晰的甄别：** 因果玻璃预言的H₀-密度相关具有**时间依赖性**，因为C[G]的冻结发生在特定红移 z_g。ΛCDM的H₀-密度相关来自非线性结构形成，具有不同的红移演化。

**甄别性：**

| 理论 | H₀-δ相关 | 红移演化 |
|------|---------|---------|
| 因果玻璃 | 负相关，只在 z < z_g 出现 | 随z增加而减弱，z=z_g消失 |
| ΛCDM | 正/负取决于尺度 | 平滑演化，无突变 |
| 其他玻璃 | 不可能有此耦合 | — |

**观察检验：** 宇宙流 (cosmic flows) 数据 + 超新星 H₀ 局部测量。当前不确定度太大。需要 ~10³ 个独立局部H₀测量（LSST时代）。

**甄别强度：B级（需要未来数据，且需排除系统误差）。**

### 3.3 预测P3: 宇宙因果连通性的"冻结纹理"

**仅甄别玻璃 vs 非玻璃，不能甄别因果玻璃 vs 其他玻璃。诚实标注。**

C[G]偏离最大熵的观测特征：宇宙大尺度结构中存在"欠连通区域"（voids的因果隔离度异常高）和"过连通区域"（filaments的因果捷径异常多）。这种"冻结纹理"不随时间演化（自z_g以来）。

甄别性不足(Honest Label): 任何遍历破缺机制都会产生冻结纹理。此预测不能区分因果玻璃和其他导致遍历破缺的玻璃。

## §4: NK重新论证

### 4.1 R1的NK估计回顾与批判

R1使用了N≈10^11（因果独立区域数）和K_eff≈100（每节点有效连接数），套用NK适应性景观的崎岖度估计。

**问题1—N=10^11的来源不透明：**

可能来源：
1. 可观测宇宙共动体积 / 复合时期声视界体积 ≈ (14000 Mpc / 0.15 Mpc)³ ≈ 8×10^14
2. CMB天空的独立2D区域数 ≈ 4π / (θ_horizon)² ≈ 4π / (1°/π×180)² ≈ 4×10^4
3. 大尺度结构中 ~10^11 M_⊙ 的晕数量

这已不是"推导"而是"挑数字"。没有唯一确定的N。

**问题2—K_eff≈100无推导：**

NK模型中K是上位效应（epistasis）参数——一个等位基因与其他K个等位基因有非加性相互作用。在因果图中，K应对应"一个节点直接因果连接的节点数"，即入度+出度。

对于宇宙因果图，一个因果斑块的K由光锥结构决定：在Hubble时间内，一个斑块可与体积~(c/H)³内的所有其他斑块因果连接。斑块密度 ≈ H³ → 每个Hubble体积内有O(1)个斑块。因此 K_eff ~ 几个到几十个，而非精确的100。

**NK模型与C[G]图拓扑的根本不匹配：**

NK景观假设：
- 每个基因座有2个等位基因（二值）
- K个上位相互作用是均匀随机的
- 适应性是N个二值变量的函数

C[G]图的不同之处：
- 每个可能的边 e_{ij} 是二值的（存在/不存在），但这不是N个"基因座"，而是N(N-1)个
- 相互作用由传递性约束确定——不是随机的，是高阶结构化的
- C[G]的"适应性"涉及全局量（连通性、传递性），而非局部贡献的和

### 4.2 放弃NK，改用因果图专用崎岖度度量

**新方案：传递性闭包距离 (Transitive Closure Distance, TCD)**

定义 G 的完全传递闭包 G^T（所有传递三元组的直接边补全）。TCD(G) = G与G^T的边集合对称差的大小：

$$\text{TCD}(G) = |E(G) \triangle E(G^T)|$$

对于路径图，TCD = 3（缺 {(a,c),(b,d),(a,d)}，无多余边）。
对于完全传递DAG，TCD = 0。

**景观崎岖度由TCD的自相关函数刻画：**

$$\rho(\delta) = \text{Corr}[\text{TCD}(G), \text{TCD}(G')]$$

其中 G 和 G' 相差 δ 个随机边变更。

在路径图邻近（δ=1局部操作），所有方向都使TCD增加或不变——局部极小。在随机图邻近，TCD变化方差大——崎岖。

**因果图的"有效崎岖度"K_eff^causal：**

通过TCD自相关函数的衰减长度定义：

$$K_{\text{eff}}^{\text{causal}} \sim \frac{\partial \rho}{\partial \delta}\bigg|_{\delta=0}$$

物理上：K_eff^causal ~ 每条边的变更平均影响多少个其他边的传递性状态。在因果图中，对于节点i→j的边变更，平均影响 ~ (|in(i)| + |out(j)|) 个三元组。对均匀图，~ 2⟨k⟩。对稀疏宇宙因果图，⟨k⟩ ~ 几个，所以 **K_eff^causal ~ 5-15**，而非100。

**N的替代方案：不取单一N，使用标度论证。**

核心量不是N本身，而是因果地平线内的独立模式数 N_modes ~ (τ_universe / τ_Planck)^(d/2)。对于d=3空间维+因果约束（每个方向的模式减半）：N_modes ~ (10^61)^(3/4) ~ 10^46。但这是全量子引力域——在经典因果图层面，相关的是**类光分离的因果斑块数** N_causal ~ (H_0^{-1} / λ_c)^3，其中λ_c是因果玻璃的微观截断尺度假说参数，而非已知物理量。

**结论：NK框架不适用于因果玻璃问题。TCD度量 + 标度论证为更合适的崎岖度描述。但λ_c（微观截断）目前是自由参数。这不是一个可标定的理论。**

## §5: 深挖（≥2层）

### 5.1 第一层：因果温度的物理本质

**问题：** 图论模型中的"因果温度"T_causal = ⟨τ⟩ 在物理上是什么？

**分析：**

在图模型中，τ(i:j)是建立因果连接的时间成本。高τ意味着长距离（大空间间隔）的因果连接需要更长时间建立——这天然来自光速有限性：τ(i:j) ∝ d(i,j)/c。

但"因果温度"作为⟨τ⟩的物理意义不明。可能性：

1. **τ ≡ 宇宙年龄：** 宇宙年龄限制了最长因果连接的长度。年龄↑ → 可建立的因果连接↑ → 系统在C[G]景观中可探索的区域↑。这与"退火"图景一致：早期宇宙（高因果温度→短τ→易遍历）→晚期宇宙（低因果温度→长τ→难遍历→可能冻结）。

2. **τ ≡ Hubble时间 H^{-1}：** 膨胀速率决定了因果地平线。H^{-1}↑ (慢膨胀) → 更多因果接触 → 更低有效温度。暗能量主导时期H几乎恒定 → 因果温度恒定 → 冻结是否发生取决于α相对于α_c的位置。

3. **τ ≡ 熵密度倒数：** 热力学温度通过决定粒子相互作用率间接影响因果连接的建立速率。但这是间接耦合。

**问题深化：** 如果τ = 宇宙年龄，那么今天τ_today ~ 13.8 Gyr。⟨I⟩（平均因果信息）的物理对应是什么？在经典图景中，两个空间区域的"因果信息"I(i:j) ∝ 它们共享的初始条件 + 已交换的信号。I(i:j)在宇宙学中不守恒——它随时间增长（更多信号交换）。

这意味着**α = τ/⟨I⟩是时变的**——早期宇宙α小（遍历），晚期宇宙α大（可能冻结）。冻结条件 α(t) > α_c 定义了冻结时刻t_g。

**未解决的问题：** t_g是否已过去，还是未来？如果是过去，冻结发生在何时？这决定了观测特征。如果冻结在复合时期(CMB)，则CMB应携带冻结印记。如果冻结在暗能量主导时期(late time)，则Δq与暗能量的关系是动态的而非静态的。

### 5.2 第二层：因果重排的微观机制与引力耦合

**问题：** 在C[G]景观中，一个"边变更" e_{ij}: 0→1 对应什么物理过程？

**分析：**

在宇宙学中，两个空间区域i和j的因果连接 C[i→j] 从0变为1意味着：i的过去光锥中发生的事件可以影响j的未来光锥中的观测。这发生在**信号首次能从i传到j**的时刻。

在膨胀宇宙中，这是动态的：随宇宙膨胀，原初因果不连接的区域逐渐进入彼此的视界。**类空间隔变为类时间隔。** 这个过程是**不可逆的**（因果连接一旦建立就不会断开，至少在经典广义相对论中）。

这意味着：

1. **边的添加是单调的：** e_{ij} 只能从 0→1，不能从 1→0。C[G]景观只在"加边"方向可探索——这是一个**定向景观(directed landscape)**，而非无向景观。

2. **因此，"局部极小"可能根本不存在：** 如果图只能通过加边演化（类空间隔→类时间隔），那景观中"上行"（ΔC>0）的区域是不可达的。系统只在可达的"下行"方向移动。

3. **玻璃冻结需要另一种机制：** 不是系统"困在"局部极小，而是**加边速率低于遍历所需速率**——系统在景观中缓慢下行，但永远赶不上不断扩张的景观。这类似于**淬火(quench)**而非冷却(annealing)。

**这是对类比的根本性修正：**

因果玻璃不是"系统在固定景观中找不到全局极小"，而是**"景观本身的扩张速度超过系统探索速度"**。

定义 **扩张率** γ_expand：每单位宇宙时间内，新进入视界的因果连接对数。γ_expand ∝ d(horizon_volume)/dt。

定义 **探索率** γ_explore：系统在可达C[G]配置中向下移动的最大速率。γ_explore ∝ 1/⟨τ⟩ ≈ H（每Hubble时间可探索的配置数）。

**新冻结判据：**

$$\gamma_{\text{explore}} < \gamma_{\text{expand}} \quad \Rightarrow \quad \text{因果玻璃冻结}$$

这对应于膨胀加速时期（暗能量主导）：新视界进入速率超过系统调整因果结构的速率。

**推论：** 如果这是正确图景，因果玻璃冻结天然与暗能量加速膨胀耦合——不是Δq导致暗能量，而是**暗能量（加速膨胀）导致因果玻璃冻结**。

### 5.3 第三层（自发深挖）：图灵-Wigner 定理类比——因果箭头作为选择规则

**一个推测性洞见：**

一个DAG中，边的方向不是任意的——因果箭头禁止e_{ji}如果e_{ij}已存在（否则形成循环悖论）。这类似于量子力学中的 **Wigner定理**：对称变换必须是么正的或反么正的——不是所有数学可能的变换都被物理允许。

在C[G]景观中，"禁止反向边"是一个硬选择规则，类似于超选择定则(superselection rule)。这个选择规则极大地约束了可达配置空间：对于N个节点，2^{N(N-1)}个有向图中，只有约 2^{N(N-1)/2} 个是DAG（无环约束）——可达空间缩小了指数因子。

**这暗示因果玻璃与自旋玻璃有本质不同的普适类：** 选择规则的存在改变了景观的拓扑（景观是"定向"的），临界行为必然不同。α_c 和 ν 的值需要重新计算——不能借用标准自旋玻璃或SAT的结果。
