## Q1: 反转是否解决了 D1（方向矛盾）？

### 原始 D1 的核心

```
原假设需要: Φ_q 上升（遍历→冻结）→ w: -1 → phantom → -1
推导实际给出: Φ_q 下降（冻结→遍历）→ 方向与假设相反
```

### 反转的解决方案

反转接受 Φ_q = 2(辐射) → 1.5(物质) → 0(DE) 的下降方向，并重新分配物理意义：

| Φ_q 值 | 原假设解读 | 反转解读 |
|--------|----------|---------|
| > 1 (高z) | 遍历, w≈-1 | **冻死**, w 被锁在 -1 |
| ~ 1 (z~0.8) | 冻结开始 | **解冻开始**, 应力释放 |
| < 1 (低z) | 冻结, phantom | **自由弛豫**, w→-1 |

### 方向自洽性检查

Φ_q 下降 = 冻结程度**降低**。反转叙事：
- Φ_q=2 → 深度冻结
- Φ_q=1.5 → 中度冻结
- Φ_q≈1 → 解冻
- Φ_q→0 → 自由弛豫

叙事方向与 Φ_q 演化方向一致：系统从"更冻结"到"更不冻结"。**D1 在形式层面已解决。**

### 但有一个微妙问题

反转后的 Φ_q(z) 精确计算（ΛCDM, Ω_m=0.315）：

| z | Φ_q | 反转叙事 |
|---|------|---------|
| 10 | 1.50 | 深度冻结 |
| 2.04 | 1.39 | 冻结 |
| 1.46 | 1.31 | 冻结 |
| **0.87** | **1.13** | **DESI phantom dip** |
| **0.80** | **1.00** | **Φ_q=1 穿越** |
| 0.50 | 0.91 | 弛豫 |
| 0.10 | 0.57 | 近平衡 |

**关键发现: phantom dip (z=0.87) 发生在 Φ_q=1.13 > 1，即穿越 Φ_q=1 (z=0.80) 之前。**

这意味着反转叙事中的"解冻开始"实际上发生在 phantom dip **之后**（z=0.80 < z=0.87）。Phantom dip 出现在系统**仍处于冻结态**（Φ_q > 1）但接近过渡区的位置。这在物理上并非不可能——接近玻璃转变时，系统已具备部分活动能力，可以开始释放应力——但它要求叙事从"解冻产生 phantom"调整为"接近解冻时应力预释放产生 phantom"。

**裁决: D1 方向矛盾已解决，但反转的简单三部曲（冻结→解冻→弛豫）与 Φ_q(z) 数值存在相位差：phantom 出现在 Φ_q=1.13（冻结区），而非 Φ_q<1（解冻区）。这个 Δz ≈ 0.07（z=0.87 → z=0.80）的偏移需要解释。**

## Q2: "w=-1 是冻死的状态，不是平衡态"——这个区分可操作吗？

### 认识论结构

两个不同物理状态产生相同的观测值 w=-1：

| | 冻死 (frozen dead) | 平衡 (equilibrium) |
|---|---|---|
| w 值 | -1 | -1 |
| 物理原因 | 因果图被锁死，无法偏离 | 因果图已遍历，已找到最小值 |
| Φ_q 条件 | Φ_q > 1 | Φ_q < 1 (或系统已充分弛豫) |
| 扰动响应 | 解冻时爆发式释放 | 扰动后指数回归 |
| 唯一可观测差异 | 解冻瞬态（phantom dip） | 受扰动后的弛豫轨迹 |

### 可操作性的三个障碍

**障碍 1: 缺乏独立探针。** 我们只有一个宇宙，只经历一次 Φ_q 穿越。无法通过重复实验区分"冻死→解冻"和"平衡→被扰动"。两者都预言 w 在特定红移偏离 -1，然后回归。"冻死"声称这偏离是应力释放，"平衡"声称是外部扰动——在仅有 w(z) 数据的情况下，无法裁决。

**障碍 2: 冻死态无独立可观测签名。** 如果高 z 的 w=-1 是"冻死"的，那么在冻死期间应该存在某种不同于平衡态的观测特征——否则"冻死"是不可证伪的标签。候选独立探针：(a) 密度扰动增长率 fσ₈(z) ——如果因果图被冻住，结构增长应不同于平衡态；(b) ISW 效应——如果引力势的演化受冻死因果结构影响；(c) 非高斯性——冻死的因果图可能产生不同于平衡态的非高斯信号。**这些在反转假设中均未涉及。**

**障碍 3: 当前数据不足以区分。** DESI 在高 z bin (z=1.46, 2.04) 的误差棒为 ±0.77 和 ±0.74，w 与 -1 在 1-2σ 内一致。这意味着高 z 数据既不能确认也不能排除 w 偏离 -1——"冻死"和"平衡"都在误差范围内。没有数据压力迫使我们在两者之间选择。

### 可操作的路径

如果要使这个区分可操作，需要：
1. 从因果图动力学推导冻死态的结构增长方程，给出 fσ₈(z) 的预测（不同于平衡态 ΛCDM）
2. 预测冻死态的 ISW 信号幅度
3. 给出解冻前（z > 0.87）和弛豫后（z < 0.3）的非高斯性差异

**裁决: 当前不可操作。** "冻死 w=-1" vs "平衡 w=-1" 在没有独立探针的情况下是哲学区分而非科学区分。反转假设需要通过冻死态对非 w(z) 观测量的可检验影响来操作系统化这个区分。在实现这一点之前，声称"高 z 的 w=-1 是冻死态"的保真度为叙事级。

## Q3: 与 DESI 数据对接

### 3.1 Φ_q(z) 精确值

使用 ΛCDM (Ω_m=0.315, Ω_Λ=0.685)：

```
Φ_q(z) = |dH/dt|/H² = (3/2)·Ω_m(1+z)³ / [Ω_m(1+z)³ + Ω_Λ]
```

| z | Φ_q | 物理含义 |
|---|------|---------|
| 10 | 1.498 | 辐射残余后，Φ_q 几乎平顶在 1.5 |
| 2.04 | 1.392 | DESI 高 z bin，仍深度冻结 |
| 1.46 | 1.309 | DESI 高 z bin，冻结 |
| **0.87** | **1.126** | **DESI phantom dip 位置** |
| 0.80 | 1.000 | **Φ_q = 1 穿越点** |
| 0.50 | 0.912 | 已进入弛豫区 |
| 0.10 | 0.570 | 深度弛豫 |
| 0 | 0.473 | 当前 |

### 3.2 Phantom dip 与解冻点的相位差

```
Φ_q = 1 穿越: z = 0.80
DESI phantom dip: z = 0.87
红移差: Δz = 0.07
```

反转假设原文声称"解冻发生在 Φ_q~1 时"，并暗示解冻信号应出现在 z~0.7。精确计算给出 Φ_q=1 在 z=0.80（非 0.7），而 phantom 在 z=0.87。

**时间差估计:** z=0.80 对应宇宙年龄约 7.5 Gyr, z=0.87 对应约 7.1 Gyr（粗略估计）。Δz=0.07 对应约 0.4 Gyr 的时间差。

### 3.3 这个相位差是否在误差范围内？

**如果将其解释为弛豫延迟:** phantom dip 发生在 Φ_q=1.13（冻结区），表明 stress release 在玻璃转变点**之前**已开始。这在物理上合理：接近 Tg 时，玻璃已有部分弛豫能力。Δz=0.07（~0.4 Gyr）是 causal graph 弛豫时间的量度。这个时间尺度比 H₀^(-1) ≈ 14 Gyr 短约 1.5 个数量级——对于一个接近玻璃转变的系统，这并非不合理的弛豫时间。

**但如果将其视为预测:** 反转假设没有在 phantom dip 被观测到之前预测 z_dip = 0.87。它现在说"Φ_q=1 在 z~0.7 → 解冻在 z~0.7 → phantom 在 z~0.87 → 有 0.17 的延迟"。这不是预测——这是将已知观测 retro-dict 为"符合"。

### 3.4 关键检验

反转假设当前的"对接"属于 curve-fitting（将已知数据点标记为"符合"），而非 prediction（在数据出现前预测具体数值）。升级为预测需要：

**(a) 预测 phantom dip 的幅度。** 反转说"解冻应力释放"，但没有给出 w_min 的值。既然 w_min = -1.48 ± 0.21（DESI），反转是否能从应力积累模型推导出 w_min ≈ -1.5？

**(b) 预测 dip 的宽度。** 如果 Δz=0.07 是弛豫延迟，那么 dip 的全宽（FWHM）应该与同一弛豫时间相关。Δz_width ≈ 2 × Δz_delay ≈ 0.14？DESI 的分 bin 精度能检验这一点吗？

**(c) 预测 dip 的形状。** 玻璃应力释放通常具有 stretched-exponential 形式（Kohlrausch-Williams-Watts）。如果 w(z) 在 dip 附近的形状可以用 stretched exponential 拟合且指数与玻璃理论预测一致，这是非平凡的检验——但目前不存在。

**裁决: 数据对接停留在 post-hoc 层面。** 反转假设与 DESI 数据不矛盾（Φ_q=1.13 at phantom dip 在物理上可以解释为接近解冻的应力预释放），但没有做出任何可以独立检验的定量预测。Δz = 0.07 (从 Φ_q=1 到 phantom) 是合理的时间延迟，但这不能替代一个 ex ante 预测。

## Q4: 应力积累机制

### 4.1 "应力"是什么？

在玻璃物理中，应力是指系统被冻结在非平衡构型中产生的机械应变。对于 causal graph，"应力"必须有明确定义。候选：

**候选 A: 图论应力。** Causal graph 的邻接矩阵 A_ij 与"平衡构型" A*_ij 之间的差异，量化为某个矩阵范数 ||A - A*||。当 Φ_q > 1 时，graph 无法及时更新 → A 偏离 A* → ||A - A*|| 增长 = "应力积累"。

**候选 B: 有效作用量应力。** Causal graph 有一个有效作用量 S[G]。平衡构型使 S 最小化。冻结期间，G 不能弛豫到最小 → ∂S/∂G ≠ 0 → 存在一个"广义力"（梯度）→ 这就是应力。

**候选 C: 信息论应力。** Causal graph 的互信息结构在冻结期间偏离平衡 → 信息自由能 F = U - TS_entropy 未最小化 → ∂F/∂G 为应力。

**反转假设没有指定是哪一个。** "应力"是一个占位词（placeholder），等待物理解释。

### 4.2 为什么冻结期积累应力？

这个问题的前提本身需要更仔细的审视。

在标准玻璃中，应力积累是因为系统从高温（平衡态）被快速冷却（quench）到低温。冷却速度超过弛豫速度 → 系统在温度下降过程中无法在每个温度都达到平衡 → 在低温下被困在高能构型 → 应力。

在 causal glass 中，类比是：
- 早期宇宙（辐射/物质期）：膨胀快（H 大），Φ_q > 1，causal graph 跟不上膨胀 → graph 的构型偏离平衡 → "应力"
- 但关键在于：**膨胀驱动的是构型空间的扩张（新节点和边的加入），而非构型的弛豫。** 如果膨胀只是往 graph 上添加新节点，而旧节点间的连接不变，那么"应力"到底积累在哪里？

应力积累需要一个"平衡构型"作为参考。在标准宇宙学中，如果 causal graph 的平衡构型就是 FLRW 度规对应的因果结构（每个时刻的粒子视界），那么 Φ_q > 1 期间 graph 没有偏离平衡——它只是无法探索自己已有的结构。偏离平衡意味着 graph 的某些部分与 FLRW 因果结构不一致。这种不一致从何而来？

**反转假设没有说明"平衡构型"是什么，也没有说明"偏离平衡"如何产生。**

### 4.3 为什么应力释放产生 phantom 而非 quintessence？

这是最关键的物理符号问题。

Phantom (w < -1) 意味着 p < -ρ ——有效压力比负能量密度更负。Quintessence (w > -1) 意味着 p > -ρ ——有效压力比负能量密度更接近零。

在 causal graph 框架中，有效暗能量的能量-动量来自 graph 的"非平衡应力"。设：
```
ρ_eff = ρ_Λ + δρ(stress)
p_eff = -ρ_Λ + δp(stress)
```

Phantom 条件：w < -1 → p_eff < -ρ_eff → -ρ_Λ + δp < -ρ_Λ - δρ → δp < -δρ

即：**应力的压力贡献（δp）必须是负的，且幅度大于能量密度贡献（δρ）。**

玻璃物理学中应力释放没有明确的符号指向 phantom。实际上：
- 在粘弹性材料中，应力释放使材料从"更像固体"变为"更像液体"——能量密度和压力的变化符号取决于具体模型
- 在宇宙学尺度上，没有已知的对应关系将"graph 应力"映射到 w 的符号

**反转假设对此没有提供任何推导或论证。** "stress release → phantom"是一个符号假设，等价于在模型中放入一个自由参数并将其设为负值。

### 4.4 玻璃类比可能反了

在真实玻璃中：
- **Quench（降温）:** 产生残余应力（因为不同部分收缩率不同）
- **Anneal（升温/解冻）:** 应力**单调弛豫**——系统向平衡态移动，应力随时间减少
- **应力 overshoot:** 发生在**剪切变形**时（给玻璃一个突然的外力），而非解冻时

反转假设的"解冻 → 应力释放 → phantom overshoot"对应的是**剪切 overshoot** 的物理情景，而非**退火（annealing）**的物理情景。但反转假设描述的恰恰是退火（系统从冻结状态进入弛豫状态）。

如果类比正确，退火解冻应该产生 w 的**单调弛豫**——从某个非平衡值单调回到 -1，而非先越过 -1 再回来 (phantom dip)。Dip 需要的正是那个"先越过"——这在退火玻璃中不常见，在受剪切的玻璃中常见。

**裁决: 应力积累机制存在三个缺口。(1) "应力"缺乏物理定义——是图论量、作用量梯度、还是信息论量？(2) 积累机制不清晰——膨胀添加节点 vs 图偏离平衡的关系未建立。(3) phantom 符号缺乏论证——退火解冻类比预测的是单调弛豫而非 overshoot，overshoot 需要类似剪切的机制。这三个缺口使"应力积累→phantom dip"目前是一个定性类比，而非物理论证。**

## Q5: 内部自洽——AG 证伪与解冻机制

### 5.1 AG 证伪的精确含义

AG 证伪: N_coop 在指数中抵消 → τ_α ≈ τ_0 ≈ t_P (微观时间) → **热激活不能产生冻结，也不能解冻。**

"不能解冻"的含义：如果系统因为 quench 而冻结，那么单纯靠热涨落（等待系统 randomly fluctuate 到低能构型）需要的时间是 τ_α ~ t_P × exp(N_coop × barrier)。即使 N_coop 不抵消（AG 证伪说它抵消了），对于宏观系统这也是天文数字。即使假定 N_coop 很小，热激活弛豫时间仍远大于宇宙年龄。

### 5.2 解冻机制是否依赖热激活？

反转假设的解冻机制是：
```
Φ_q 从 >1 降到 <1 → tau_explore < tau_expand → causal graph 可以追赶上膨胀 → 系统解冻
```

这**不是**热激活。这是**淬火条件的解除**。

类比：一个玻璃在液氮温度（77K）下被冻住。你把它从液氮中拿出来，放在室温（300K）下。玻璃解冻是因为环境温度高于 Tg，不是因为热涨落 randomly 帮它翻越了势垒。同样，causal graph 解冻是因为 Φ_q 下降到 < 1（膨胀不再比探索快），不是因为某个热过程激活了它。

### 5.3 是否矛盾？

不矛盾。AG 说"你不能通过加热来解冻这个玻璃"（热激活不可行）。反转说"解冻不是因为加热——是因为室温本身就高于 Tg"（淬火条件解除了）。

两个命题的逻辑关系：
- AG: 热激活不可行 → 如果解冻需要热激活，解冻不可能
- 反转: 解冻不需要热激活 → 解冻可能

前提不同，结论相容。

### 5.4 但有一个深层的紧张关系

如果解冻的机制是"Φ_q < 1 → causal graph 有足够时间探索构型空间"，那么解冻后 graph 的弛豫（向平衡态移动）是由什么驱动的？

AG 说微观热激活太慢。但如果没有热激活，单个 graph 节点如何"知道"要改变它的连接？纯 GR 决定的因果结构（光锥相交）是确定性的——给定度规，因果结构完全确定。哪来的"弛豫"？

这触及了 causal graph 理论的核心：**如果 causal graph 完全由 GR 度规决定（给定度规→唯一的因果结构），那么 graph 没有"自由度"可以弛豫。它总是已经在其"平衡"构型上——平衡由度规定义。**

"弛豫"的概念要求 graph 有独立于度规的自由度——即 graph 的构型不完全由度规决定，而是有自身的动力学（可能是量子涨落、或 graph 的离散性质、或非局域效应）。只有在这种情况下，graph 才能"偏离平衡"并"弛豫"。

**反转假设未明确 causal graph 的自由度来源。** 如果 graph 完全由度规决定（标准 GR），那么 Φ_q 可以 > 1 或 < 1，但 graph 永远不会"偏离平衡"——它总是在给定的度规下就是它自己。只有在 graph 有独立动力学（独立于度规的额外自由度）的情况下，"冻结"和"弛豫"才有意义。

这一深层问题超出了 Q5 的范围，但它连接着整个 LP35 项目的基础：causal graph 到底是什么？它的自由度从哪里来？

### 5.5 对 Q5 的裁决

**形式自洽。** AG 证伪针对热激活，反转的解冻机制（Φ_q 下降 → 淬火停止）不是热激活。两者不矛盾。

**但有一项未解决的结构性紧张：** 如果 causal graph 由 GR 度规唯一决定，则 graph 无独立自由度，无"弛豫"可言。如果 graph 有独立自由度（必需的，否则整个 causal glass 概念无意义），那么这些自由度的微观弛豫机制（驱动节点改边的物理过程）仍未指定——而 AG 证伪已排除了热激活作为候选。**如果是这样，graph 的弛豫需要非热、非 GR 的机制——反转假设未提供。**

#### 声张 1: "w=-1 在高 z 是冻住而非平衡"

| 维度 | 评估 |
|------|------|
| 可检验性 | **不可检验**（无独立探针，见 Q2） |
| 是否比原假设增加解释力 | 否——将"需要解释 w≈-1"替换为"需要解释为什么冻住恰好产生 w=-1" |
| 对数据的要求 | 高 z w 偏离 -1 会证伪"平衡"，但不证伪"冻住" |
| 保真度 | **叙事级** — 在没有独立探针前，这是解释框架而非科学声张 |

#### 声张 2: "恰好一次解冻产生 phantom dip"

| 维度 | 评估 |
|------|------|
| 可检验性 | **可检验** — 如果发现第二个 phantom dip 或发现 dip 是 quintessence 而非 phantom，声张被证伪 |
| 结构唯一性 | Φ_q(z) 在宇宙历史中只有一次从 >1 到 <1 的穿越 → "恰好一次"是 Φ_q(z) 的结构推论，不是独立预言 |
| 对幅度的预测 | **无** — 未预测 dip 有多深 |
| 保真度 | **中等** — "恰好一次"来自 Φ_q(z) 的数学结构（单一穿越），确实比其他可以产生零次或多次穿越的模型更紧。但幅度和形状完全自由，降低了甄别力 |

#### 声张 3: "低 z 弛豫回 -1"

| 维度 | 评估 |
|------|------|
| 可检验性 | **弱可检验** — ΛCDM、w_a=0 的 CPL、冻结 quintessence 等都预言同样行为 |
| 甄别力 | **零** — 这是许多模型的共同预言，不能区分它们 |
| 保真度 | **共享预言级** — 不是反转假设独有的声张 |

#### 声张 4: "与所有场模型的区分"（来自反转假设的表格）

| 逆转表格条目 | 是否真正的优势？ |
|-------------|:---:|
| w≈-1 @ 高z "自然冻住" | 否——将"为什么势恰好平"替换为"为什么冻住恰好 w=-1"，均需假设 |
| phantom dip "解冻应力释放" | 否——将"特殊耦合"替换为"应力释放"，均为未推导的新物理 |
| w→-1 @ 低z "自由弛豫" | 否——将"吸引子"替换为"弛豫"，均为假设 |
| 恰好一个 dip "必然" | **是** — 这是 genuine 的结构优势。Φ_q = 1/n 只有一个从 >1 到 <1 的穿越 → 只有一个解冻事件 → 正好一个 dip。场模型可以产生零个（单调）、一个（恰好调参）、或多个（振荡）dip，但反转假设恰好一个不依赖参数调选 |

### 声张保真度总评

| 声张 | 保真度 | 说明 |
|------|:---:|------|
| "冻住"vs"平衡"区分 | 0.10 | 叙事翻译，不可检验 |
| 恰好一次解冻 | 0.40 | 结构推论，非独立预言 |
| 低 z 弛豫回 -1 | 0.05 | 多模型共享 |
| 排他性区分表 | 0.15 | 三个条目是修辞等价替换，一个 genuine |

**唯一 genuine 的声张: "恰好一个 phantom dip" 是反转假设的结构特征——因为它来自 Φ_q = 1/n 只有一次 >1→<1 穿越。这是可证伪的（发现第二个 dip 则证伪），且不是 ad hoc 参数调选。**

但这条声张的力度有限：它只说"恰好一个"，不说 dip 的幅度、宽度、精确位置、或形状。一个理论只说"应该有一个 dip"而 dip 已经观测到了，这不算成功的预言——这是成功的 retro-diction。

## 综合判定

### 缺口汇总

| # | 缺口 | 严重性 | 独立？ |
|---|------|:---:|:---:|
| I1 | **"冻死"vs"平衡"不可操作** — 无独立探针区分两者 | ⚠️ 严重 | 是 |
| I2 | **Phantom dip 在 Φ_q=1.13（冻结区）而非 Φ_q<1（解冻区）** — 简单三部曲需要修正 | ⚠️ 严重 | 是 |
| I3 | **Δz=0.07 相位差** — 可解释为弛豫延迟但不能替代 ex ante 预测 | ⚠️ 严重 | 否 (依赖 I2) |
| I4 | **应力缺乏物理定义** — 是图论量、作用量梯度还是信息量？ | ⛔ 致命 | 是 |
| I5 | **Phantom 符号无推导** — 退火类比预测单调弛豫而非 overshoot | ⛔ 致命 | 是 |
| I6 | **Causal graph 自由度来源未指定** — 如果 graph = GR 因果结构，无弛豫可言 | ⛔ 致命 | 是 |
| I7 | **幅度/宽度/形状无预测** — 反转定性框架不含定量预言 | ⚠️ 严重 | 否 (依赖 I4-I6) |

### D1 的状态

**D1（方向矛盾）已被反转解决。** 这是反转假设的主要贡献——它接受 tau_explore = 1/H 推导的 Φ_q(z) 方向，并在此基础上重建了一个方向自洽的叙事。

但解决 D1 的代价是引入了新的、更深的缺口（I4-I6）。D1 是逻辑/数学层面的矛盾——可以直接通过重定义来解决。I4-I6 是物理层面的缺口——需要新的物理内容来填充。

### 最致命的发现: I4 + I5 + I6 构成三重缺口

- **I4:** "应力"是占位词，没有物理定义
- **I5:** Phantom 的符号方向与退火玻璃类比的方向相反
- **I6:** Causal graph 的自由度来源——"graph 独立于度规的动力学"——是整个 causal glass 概念的前提，但仍未指定

这三个缺口是**物理内容**层面的缺失（而非逻辑/数据层面的矛盾）。逻辑矛盾（D1）可以通过重定义修复，但物理内容的缺失需要新增的物理假设。

### 反转假设 vs 原假设: 比较

| 维度 | 原假设 (Quench Freeze) | 反转假设 (Freeze-Thaw-Relax) |
|------|----------------------|---------------------------|
| Φ_q 方向自洽 | ❌ D1 致命矛盾 | ✅ 方向自洽 |
| 与高 z 数据 (w≈-1) | ❌ 预测 w 偏离 -1（遍历相） | ✅ 预测 w ≈ -1（冻死相） |
| 与 DESI phantom dip | ❌ 预测 DE 期遍历 (w→-1)，与数据矛盾 | ✅ phantom 被解释为应力释放（但 Φ_q=1.13，在穿越前） |
| 与低 z 回归 | ✅ 预测弛豫回 -1 | ✅ 预测弛豫回 -1 |
| 物理机制 | Quench 冻结 + 应力残余 | 冻死 + 解冻应力释放 |
| 未解释的前提 | tau_explore 定义、应力→w 映射 | 应力定义、应力→phantom 符号、graph 自由度 |
| 自由参数 | tau_explore (O(1)×1/H)、应力耦合 | 同左 + 弛豫时间、dip 幅度 |
| 可证伪性 | 中（Φ_q 方向 + dip 存在性） | 低（方向已与数据对齐，仅 dip 存在性可检验） |

**反转假设在方向自洽性上优于原假设——这是一个真实的进展。** 但是，它通过引入更模糊的物理概念（"冻死"/"应力积累"）来修复方向矛盾，降低了总体的可证伪性。

### 反转假设的真实状态

反转假设目前是**一个方向正确的定性框架**，而非一个可检验的科学理论。它回答了一个问题（"Φ_q 方向怎么解释？"）但引入了三个更深的问题（"应力是什么？"、"为什么 phantom？"、"graph 自由度哪里来？"）。

它的核心强度——"恰好一个 phantom dip"是 Φ_q(z) 的结构推论——是 genuine 的。但仅凭这一条不足以将框架升级为理论。

## 建议

### 立即可做

1. **精确定义"应力"。** 从 causal graph 的数学结构（邻接矩阵、拉普拉斯矩阵、互信息）中选一个量，定义应力为该量的某种泛函，计算其在膨胀宇宙中的演化。

2. **修正 phantom dip 的相位。** 精确声明：phantom dip 发生在 Φ_q ≈ 1.1-1.2（接近但尚未穿越玻璃转变），而非 Φ_q < 1。这比"简单三部曲"更精确，且对 Δz 不敏感（因为它不声称 phantom 在穿越点）。

3. **声明 AG 证伪与解冻是不同机制。** 明确写："AG 证伪排除了热激活解冻。本工作中的解冻是非热的——它源于 Φ_q 下降到 1 以下，即淬火条件的解除。解冻后 graph 的弛豫由 causal graph 自身的动力学驱动，不依赖热涨落。"

### 短期（下一轮迭代）

4. **推导 phantom 的符号。** 从 stress 的物理解释（图论/作用量/信息论）出发，推导 δp 和 δρ 的符号关系。不要让符号是一个自由选择。

5. **预测 dip 的形状。** 如果应力释放遵循玻璃物理的 stretched exponential（KWW 函数），那么 w(z) 在 dip 附近应该有特定的函数形式。与 DESI 分 bin 数据拟合检验。

6. **寻找独立探针。** 冻死态 causal graph 对 fσ₈(z) 和 ISW 的预测是什么？如果有一个不同于 ΛCDM 的预测，这就是"冻死 vs 平衡"的可操作区分。

### 中期（如果推进 LP35）

7. **指定 causal graph 的独立自由度。** 如果 graph 完全由度规决定，就没有玻璃物理。graph 需要独立于度规的自由度——这些自由度的物理本质是什么？量子几何涨落？离散因果集的非唯一性？全息原理的 bulk 自由度？

8. **从 N 体 causal graph 模拟检验。** 建立一个 toy causal graph（N=10^3-10^4 节点），在膨胀度规下演化，观测是否出现冻结-解冻-弛豫行为。如果数值模拟证伪这个行为，理论可以提前排除。
