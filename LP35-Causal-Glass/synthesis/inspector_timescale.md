## Q1: 量纲校对

### 1.1 "时间跑得比物质快"能否量纲化?

假设的核心陈述:"时间跑得比物质快了"。要量纲化这个陈述, 需要定义两个时间尺度:

| 时间尺度 | 候选定义 | 量纲 |
|---------|---------|------|
| τ_expand | 1/H(z) — Hubble膨胀时标 | [T] |
| τ_structure | ? — 因果连接跨越给定共动尺度的时标 | [T] |

**τ_expand 有标准定义:** τ_expand = 1/H(z)。在 z≈0.7, H(z) ≈ H_0·√(Ω_m(1+z)³ + Ω_Λ) ≈ 100 km/s/Mpc, τ_expand ≈ 10 Gyr。

**τ_structure 从未被定义。** 假设文件全文没有给出 τ_structure 的量化公式。可能的候选包括:

(a) τ_structure = λ_J / c_s — 金斯尺度上的声波穿越时间  
(b) τ_structure = R_c / c — 因果连接半径的光行时间  
(c) τ_structure = t_dyn = 1/√(Gρ) — 引力塌缩动力学时标  
(d) τ_structure = "因果图生长速率"的倒数 — 该速率从未被定义

因为 τ_structure 没有定量定义, **R = τ_structure / τ_expand 的数值无法计算。** "时间跑得比物质快"这句话对应 R > 1 (膨胀比因果传播更快), 但不能被检验, 因为没有 τ_structure 的数值。

### 1.2 量纲闭合的最低要求

要闭合量纲, 假设需要:
1. 给出 τ_structure 的具体公式
2. 展示在 z > z_t 时 τ_structure < τ_expand (因果追得上膨胀)
3. 展示在 z < z_t 时 τ_structure > τ_expand (因果被甩开)
4. 证明交叉点恰好在 z ≈ z_t (减速→加速转折)

**当前状态: 量纲链在第1步断裂。** τ_structure 的物理定义缺失, 后续步骤无法进行。

### 1.3 与 SFR 假设的量纲对比

| | w-SFR 曲率假设 | 时间尺度假设 |
|---|---|---|
| 核心量 | d²SFR/dz² 有明确定义 | τ_structure 无定义 |
| 耦合常数 | γ = (w+1)/(d²SFR/dz²) 可计算 | 无可比量纲参数 |
| 量纲自洽 | γ 量纲 = yr·Mpc³/M_sun (自洽但非普适) | 无闭合 | 
| 可定量检验 | 是 (虽然失败了) | **否** (尚未量化) |

**裁决: 量纲未闭合。** 时间尺度假设目前停留在比喻层面 ("时间跑得比物质快"), 距离可量化物理假设还差一个关键步骤: τ_structure 的物理定义。在此闭合之前, 所有后续讨论 (方向、量级、可证伪性) 都无法定量进行。

## Q2: 方向校对

### 2.1 转折点 vs phantom dip 的 Δz

| 事件 | 红移 | 来源 |
|------|------|------|
| 减速→加速转折 (ΛCDM) | z ≈ 0.67 | q(z)=0, Ω_m=0.3, Ω_Λ=0.7, w=-1 |
| 假设声称的转折点 | z ≈ 0.7 | TIMESCALE_HYPOTHESIS.md |
| DESI phantom dip bin中心 | z = 0.87 | DESI DR2 bin 2, 覆盖 [0.6, 1.1] |

**Δz 分析:** 转折点 (z≈0.67) 与 phantom dip bin中心 (z≈0.87) 的差值为 Δz ≈ 0.20。但关键点是: DESI bin 2 覆盖 z ∈ [0.6, 1.1], 宽度 Δz_bin = 0.5。**z≈0.67 完全落在 bin 2 内部。** 因此当前的 bin 分辨率无法区分"phantom dip 在 z=0.67" 和 "phantom dip 在 z=0.87"——两者都在同一个 bin 里。

**Δz = 0.20 是否构成方向矛盾? 否。** 在当前 4-bin 分辨率下, 这个 Δz 远小于 bin 宽度, 不能区分。这不是方向矛盾, 是**时间分辨率不足**。

### 2.2 时间差分析

在 ΛCDM 中:
- z=0.67 → t ≈ 7.4 Gyr (宇宙年龄 ~6.4 Gyr)
- z=0.87 → t ≈ 6.3 Gyr (宇宙年龄 ~7.5 Gyr)
- Δt ≈ 1.1 Gyr

如果 phantom dip 确实发生在 z≈0.87 而非 z≈0.67, 意味着在"转折"后约 1.1 Gyr 才观测到"应力释放"。这段时间是"因果图冻结→应力累积→应力释放"的弛豫时间。**这个弛豫时间的存在本身不是矛盾。** 但假设需要澄清: phantom dip 到底是转折瞬间的应力释放, 还是转折后 1 Gyr 的弛豫过程? 前者要求在 z≈0.67 处看到信号, 后者允许延迟。

### 2.3 因果链逐步方向检查

假设提出的因果链:
```
因果结构追不上膨胀 → 膨胀加速 → 因果图冻结 → phantom dip (w < -1)
```

**Step 1: "时间跑得比物质快" → 膨胀加速**

方向问题: "时间跑得比物质快" (τ_structure > τ_expand) 意味着因果传播慢于膨胀。但膨胀是否加速取决于 ä 的符号, 而 ä 由弗里德曼方程决定:
```
ä/a = -4πG/3 (ρ + 3p)
```
加速 (ä > 0) 要求 ρ + 3p < 0, 即 p < -ρ/3。这是由物质成分的状态方程决定的, 不是由"时间是否跑得比物质快"决定的。

**因果方向被颠倒。** 在 GR 中, 是物质成分 (ρ, p) 决定膨胀行为 (ä), 膨胀行为决定因果结构 (光锥)。不是"时间跑得快→膨胀加速", 而是"暗能量主导→膨胀加速→因果结构被拉伸"。假设声称的因果箭头与 GR 的因果箭头相反。

**Step 2: 膨胀加速 → 因果图冻结**

在 GR 中, 因果结构由度规决定。膨胀加速意味着粒子视界和事件视界的演化模式改变——这是对的: 在加速膨胀宇宙中, 事件视界趋于常数 (de Sitter 视界), 意味着不存在可以跨越视界的新因果连接。但这是**度规演化的后果**, 不是独立的"因果图冻结"过程。两者是一回事, 不是因果关系。

**Step 3: 因果图冻结 → phantom dip (w < -1)**

这是整条链中最关键、最缺乏论证的一步。为什么因果图冻结应该产生 w < -1 (phantom) 而不是 w > -1 (quintessence)?

可能的论证:
- (a) "应力释放" = 积累的"因果张力"转化为有效负压 → w < -1
- (b) 因果连接断裂 → 信息丢失 → 能量非守恒 → 有效 w < -1
- (c) 类比: 冻结=相变潜热释放 → 暗能量密度暂时增加 → w < -1

**三种论证都没有被定量化, 都是定性类比。** 没有任何方程从"因果图冻结"推导出 Δw ≈ -0.5 的符号、方向和量级。

更严重的是: 在 SFR 假设中, phantom 信号与退相干减速 (负曲率) 相联系。在时间尺度假设中, phantom 信号与因果关系被甩开相联系。**两个假设赋予 phantom 信号完全不同的物理原因, 且各自声称"解释了"同一个 DESI phantom dip。** 一个数据点不能同时被两个互斥的机制解释——这是 INSPECTOR F2 (积分vs曲率矛盾) 在更高层面的重现。

**裁决: 方向链存在两个结构性问题。** (a) 因果箭头与 GR 颠倒: 假设声称因果结构驱动膨胀, 但 GR 中是膨胀 (由物质成分决定) 驱动因果结构。除非假设在超越 GR 的框架中运作 (但未声明), 否则因果方向错误。(b) "因果图冻结 → phantom" 的符号方向未被推导——为什么是 phantom (w < -1) 而不是 quintessence (w > -1)?

## Q3: 循环论证

### 3.1 转折点 z_t 的 ΛCDM 依赖性

假设明确使用 z≈0.7 作为"循环点"。这个值从 ΛCDM 计算:
```
z_t = (2Ω_Λ/Ω_m)^{1/3} - 1 ≈ (2×0.7/0.3)^{1/3} - 1 ≈ 0.67
```
这依赖于:
- Ω_m = 0.3, Ω_Λ = 0.7 (from Planck, 假设 w=-1)
- w = -1 (ΛCDM 假设)

### 3.2 w ≠ -1 时 z_t 的改变

如果 w ≠ -1 (如假设所声称), 减速参数:
```
q(z) = [Ω_m(1+z)³ + Ω_DE(1+3w)(1+z)^{3(1+w)}] / [2E²(z)]
```

对于常数 w = -1.2 (phantom):
```
z_t: Ω_m(1+z_t)³ = - (1+3w) Ω_DE (1+z_t)^{3(1+w)}
     = - (1 - 3.6) Ω_DE (1+z_t)^{-0.6}
     = 2.6 Ω_DE (1+z_t)^{-0.6}
(1+z_t)^{3.6} = 2.6 × 0.7/0.3 = 6.067
z_t = 1.651 - 1 = 0.651
```

**循环偏倚: Δz_t ≈ 0.02 (w=-1 → w=-1.2)。** 数值上很小。

但更深层的循环在于: **Ω_m 和 Ω_Λ 的值本身是从假定 w=-1 的 CMB+BAO+SNe 联合分析中约束的。** 如果真实 w(z) ≠ -1 (尤其是 phantom 在 z~0.87), Ω_m 和 Ω_Λ 的约束会系统性偏移。典型效应:
- 如果 w < -1 在 z~0.5-1, CMB 距离标度改变 → Ω_m 约束变化 ~0.02-0.05
- z_t 变化 ~0.05-0.10

**z_t 的不确定性 (来自宇宙学参数不确定性, ~0.05-0.10) 大于循环偏倚 (~0.02)。** 循环本身不致命, 但存在一个更微妙的问题:

### 3.3 隐藏的循环: z_t 作为"物理转折点"

假设声称 z≈0.7 是"宇宙运行方式的质的改变"。但如果 z_t 本身是 ΛCDM 参数 (Ω_m, Ω_Λ, w=-1) 的人为制品, 那么声称一个从 ΛCDM 计算出来的红移是"物理转折点"就是循环的。

**类比:** 假设声称"地球温度在 100°C 发生相变"——但 100°C 是水在 1atm 下的沸点, 是人为定义的。如果温度刻度本身依赖于水的性质, 声称 100°C 是"物理转折点"就是循环的。

**在本例中:** z_t ≈ 0.67 是 ΛCDM 参数 (Ω_m=0.3, Ω_Λ=0.7, w=-1) 的导出量。这个值没有独立的物理意义——它仅仅是 ä(z_t)=0 的根。在非 ΛCDM 宇宙学中 (如假设所主张), z_t 可能完全不同。**用 w=-1 的参数推导出的转折点去解释 w≠-1 的信号, 构成循环论证。**

但循环的严重性是**轻度** (非致命), 因为:
1. 数值偏倚小 (Δz_t ~ 0.02-0.10)
2. z_t 的不确定性 (来自参数不确定性) 大于循环偏倚
3. 可以通过迭代自洽修正 (用拟合出的 w(z) 重算 z_t)

**裁决: 轻度循环存在但非致命。** 假设将 z≈0.7 (从 ΛCDM 导出) 作为"物理转折点"使用时, 必须诚实标注 z_t 的 ΛCDM 依赖性, 并通过迭代自洽 (用拟合 w(z) 反推 z_t) 检验收敛性。如果迭代后 z_t 移动超过参数不确定性 (~0.1), 循环偏倚严重。

## Q4: 量级鸿沟

### 4.1 INSPECTOR F3 重现: 能量预算

在 SFR 假设中, INSPECTOR F3 致命鸿沟是: 恒星形成能量 / 暗能量密度 ≈ 10^(-4) → 需要 10^3-10^4 放大才能产生 Δw ≈ 0.5 的 phantom 信号。

**时间尺度假设是否遭遇同一鸿沟?**

时间尺度假设的"驱动源"不是恒星能量, 而是"膨胀本身"。膨胀的动能/势能密度是 O(ρ_c) ——即暗能量密度本身的量级。因此, 不像 SFR 假设那样存在 10^4 的能量预算缺口。

**但这并不意味着量级问题消失。** 新问题变为:

**"因果图冻结"释放的能量有多大?**

因果图是抽象的信息/几何结构。它携带能量吗?
- 如果携带, 能量密度是多少? 为什么恰好是 O(ρ_DE)?
- 如果不携带, "应力释放"如何产生 O(ρ_DE) 的 phantom 信号?

在 GR 中, 能动张量 T_μν 的每个分量都有明确的物理来源 (物质、辐射、标量场等)。"因果图应力"不在 T_μν 的标准成分之列。要产生 Δw ≈ -0.5 的 phantom 信号, "因果图应力"必须对应 ΔT_μν ~ 0.5 × ρ_DE × diag(-1, w, w, w)。这意味着因果图必须有约 ρ_c/2 的有效能量密度——与所有重子物质的总和相当。

**这是 F3 的时间尺度版本: 因果图如果携带足以产生 phantom 信号的能量密度 (~0.5 ρ_c), 为什么在其他天体物理观测中从未被直接探测到?**

### 4.2 放大机制需求

如果因果图不携带 O(ρ_c) 的能量 (更合理的假设), 那么从"因果结构改变"到"w偏离-1"需要一个放大机制:

```
因果结构改变的能量密度 / ρ_DE = ε << 1
观测到的 Δw ≈ 0.5 → 需要放大因子 ≈ 0.5/ε
```

ε 是多少? 因果结构的"能量"是什么? 在量子信息理论中, 信息的能量下限由兰道尔极限给出: kT ln 2 ≈ 10^(-21) J/bit at T=2.7K。但这是热力学信息, 不直接适用于宇宙学因果结构。

**结论: 量级鸿沟在时间尺度假设中以不同形式重现。** 虽然不像 SFR 假设那样有明确的可计算缺口 (恒星形成能量 vs DE 能量), 但存在更大的不确定性: 因果图的"能量"完全没有定义, 因此无法评估从"因果图冻结"到"w偏离-1"的转换效率。这比 SFR 假设更严重——SFR 至少有一个可计算的能量预算 (虽然太小), 时间尺度假设连能量预算都未曾定义。

### 4.3 尺度鸿沟: SFR 版重现

时间尺度假设面临与 SFR 假设相同的尺度跨度问题:

```
微观: 因果连接的断裂 ~ 单个光锥尺度 (c/H)
宏观: 暗能量行为 ~ Hubble 尺度 (c/H_0)
```

虽然两者尺度相近 (~Hubble 尺度), 但"因果连接断裂"是如何从单个光锥事件聚合成全局的 w(z) 变化的? 需要某种均化/平均机制——该机制未被指定。

**裁决: 量级鸿沟未闭合。** 时间尺度假设将 F3 从"恒星能量→DE效应"转置为"因果图应力→DE效应", 但未解答能量来源问题。因果图是否有能量密度? 如果有, 为何未被其他观测探测? 如果没有, 如何产生 O(ρ_c) 的 phantom 信号? 这些问题在当前文本中连提都没提。

### 声张 3: "不是暗能量在变, 是时空运行方式在变"

**原声张保真度: 0.10/1.0**

在 GR 框架内, "暗能量演化" 和 "时空运行方式改变" 通过爱因斯坦方程等价:
```
G_μν = 8πG T_μν
```
- 左边改变 (几何/时空运行方式) ↔ 右边改变 (有效 T_μν, 包括 DE)
- 观测上, 两者都表现为 a(t) 或 w(z) 的修改
- **在 GR 中不可区分**

如果假设声称两者可区分, 必须:
(a) 指定超越 GR 的框架 (如因果集合理论、Horava-Lifshitz 等), **或**  
(b) 给出在 GR 内可通过非宇宙学观测 (如局部引力实验、等效原理检验) 区分两者的方法

当前文本两者都没有。因此这个区分是**不可操作的形而上学**——即使用所有未来观测也无法区分——满足波普尔的"不可证伪"标准。

**诚实等价声明:** 删除"不是暗能量在变, 是时空运行方式在变"作为物理声张。重新表述为"本假设给出了 w(z) 演化的新物理动机 (因果滞后), 而非常规的标量场动力学动机。但两种动机在 GR 内给出观测上等价的 w(z) 预言, 区分需依赖理论动机的自然性/简洁性评判。"

## 额外: 内部自洽

### E1: "时空运行方式改变" vs "暗能量状态方程改变" 是否可操作?

**答案: 在 GR 框架内, 不可操作, 不可区分。**

证明:
```
GR 场方程: G_μν(g) = 8πG T_μν(matter)

"时空运行方式改变" ≡ F(G_μν) ≠ 0 (修改左边)
                        ≡ G_μν = 8πG [T_μν(matter) + T_μν^eff] (右边加有效项)

"暗能量状态方程改变" ≡ T_μν^DE 的 p/ρ 比变化 (修改右边 DE 部分)
                        ≡ G_μν = 8πG [T_μν(matter) + T_μν^DE(w(z))] 

两者在观测上等价, 因为:
T_μν^eff(w_eff) = T_μν^DE(w(z))
→ 产生相同的 a(t), H(z), D_L(z), 增长因子 fσ_8(z)
→ 所有宇宙学观测量完全相同
```

**对假设的影响:** 假设的核心 distinction ("不是暗能量在变, 是时空运行方式在变") 在 GR 内没有操作意义。如果假设要维持这个 distinction, 必须:

1. 明确声明超越 GR 的框架 (如 causal set theory, dynamical triangulation 等)
2. 推导出在该框架中可观测、在 GR+DE 中不可观测的独特信号
3. 证明该信号在可预见的实验中可检验

**当前状态: 以上三项均未完成。** 核心 distinction 是形而上学的, 不是物理的。

### E2: "因果结构" 在 GR 中是否独立于度规?

假设说"因果结构无法跟上宇宙膨胀"。在 GR 中:
- 因果结构 = 光锥 = 度规 g_μν 的 null 超曲面
- 膨胀 = 度规的时变部分 a(t)
- 前者由后者**定义**——不能说"光锥跟不上度规", 因为光锥就是度规的一部分

**"因果结构被膨胀甩开" 这个陈述在 GR 内是范畴错误 (category error)。** 这就像说"影子跟不上人"——但影子**就是**人挡光产生的, 不是独立于人的实体。

除非在超越 GR 的框架中, 因果结构是比度规更基本的本体 (如因果集合理论中, 因果序 > 度规), 这个陈述才可能具有物理意义。但在该框架中, 假设必须使用该框架的语言重新表述——不能混用 GR 的 w(z) (它假设 GR 成立, 从 a(t) 反推) 和非 GR 的本体论。

### E3: 时间尺度假设与 SFR 假设的共存问题

LP35 项目中同时存在:
- **SFR 假设:** phantom dip 由 SFR 曲率 (d²SFR/dz²) 驱动——退相干速率变化
- **时间尺度假设:** phantom dip 由"因果图冻结"驱动——时间-物质脱耦
- **统一假设:** phantom dip 由退相干进度 q(z) 驱动——SFR 积分

**三个假设赋予同一观测 (DESI phantom dip) 三个互斥的物理原因:**
- SFR 曲率假设: 退相干**加速度** → phantom  
- 统一假设: 退相干**进度** → phantom  
- 时间尺度假设: 因果**冻结** → phantom

INSPECTOR 在 w-SFR 审查中已发现前两个在 z=1.46 和 z=2.04 处符号矛盾 (F2)。时间尺度假设引入了第三个互斥机制——但它比前两个更严重地缺乏量化。

**项目必须明确: 三个假设中哪一个是主导机制?** 不能同时声称 (a) w+1 ∝ d²SFR/dz², (b) w+1 ∝ ∫SFR, (c) w 由"因果冻结"驱动——这是三选一, 不是三者兼有。

### E4: "不可逆相变"的可检验性

假设声称 z≈0.7 的因果图冻结是"不可逆相变"。不可逆意味着: 在 z<0.7 的宇宙中, 无法恢复 z>0.7 时的因果图生长状态。

这产生一个潜在的可检验后果: **在 z<0.7 的宇宙中, 新形成的结构应该表现出与 z>0.7 时期不同的因果连接模式。** 假设的"下一步"部分提到了这个方向 (星系因果连接度的统计差异、宇宙网连接性的不连续)。但:

1. "因果连接度"未被操作化定义——如何测量一个星系的"因果连接度"?
2. 宇宙网连接性在 z~0.7 处的"不连续"——什么统计量? 两点相关函数? 最小生成树? 什么显著性水平?
3. 这些检验没有被具体化到可以执行的程度

**这是假设中最有前景的可检验方向——但当前仅仅是方向, 不是可执行的检验设计。**

## 最终判定

**时间尺度交叉假设不能以当前形式存活。**

三个致命缺口 (FT1-FT3) 各自足以阻止假设进入定量检验阶段:

1. **FT1 (τ_structure 无定义):** "时间跑得比物质快" 是一句有启发性的比喻, 不是物理假设。τ_structure 的物理定义缺失使得整个假设无法闭合量纲——这是比 SFR 假设的 F2 (符号矛盾) 更基础的失败: SFR 假设至少是可检验的 (虽然检验结果否定它), 时间尺度假设尚不可检验。

2. **FT2 (范畴错误):** 在 GR 内, 因果结构就是度规。不能说"因果结构跟不上度规"——这是范畴错误, 相当于说"影子跟不上人"。假设要么在 GR 内重新表述 (放弃"因果结构"作为独立实体的语言), 要么明确迁移到超越 GR 的本体论 (如因果集合理论), 并提供该框架中的可检验预言。

3. **FT3 (不可区分):** 核心 distinction ("不是暗能量在变, 是时空在变") 在 GR 内不可操作。波普尔标准: 不可证伪的 distinction 不是科学 distinction。

**与 SFR 假设的对比:**

| 维度 | w-SFR 曲率假设 | 时间尺度假设 |
|------|:---:|:---:|
| 量纲闭合 | ✅ (可计算, 有自洽问题但可检验) | ❌ (τ_structure 未定义) |
| 数据检验 | ❌ (z=0.87 符号矛盾, F1 致命) | ⛔ (尚未达到可检验阶段) |
| 物理自洽 | ⚠️ (循环论证+能量鸿沟) | ❌ (范畴错误+因果方向颠倒) |
| 可证伪预言 | ✅ (有定量预言, 虽然被否定) | ❌ (定性方向, 无阈值) |
| 状态 | **被数据否定** | **尚不可检验** |

两个假设各自在不同维度失败。时间尺度假设的物理直觉 ("减速→加速转折有物理后果") 可能留存, 但需要:
1. 在 GR 内重新表述 (放弃"因果结构作为独立实体")
2. 用标准 GR 语言: "在 ä=0 穿越点附近, 度规的二阶时间导数改变符号, 这意味着[某可观测量]应有[某特征]"
3. 给出该特征的定量预测

**如果项目坚持推进时间尺度方向, 最低修复路径:**
1. **放弃"时间跑得比物质快"** — 替换为 GR 内可表述的物理: "在 ä 改变符号的穿越点, 类时 Killing 矢量不再存在 → 能量守恒的积分形式失效 → [后果]"
2. **定义可量化替代量** — 例如: 粒子视界半径 r_ph(z) 与 Hubble 半径 r_H(z) 的比值演化, 在 z≈0.7 附近的特征
3. **推导 Δw 的符号** — 从 GR + 具体机制推导 w < -1 (phantom) 而非 w > -1 (quintessence)
4. **定量预言** — 给出 w(z) 在 z≈0.7 特征的振幅、宽度, 以及证伪阈值
5. **与 SFR/统一假设切割** — 明确声明时间尺度机制是**替代**而非**补充**前两个假设
