## Q1. 量纲校对

### Q1.1 C[G] = Σs(q_i) + ΣI(i:j) + τ|E|

- `s(q)` = Shannon entropy, 量纲: **nat** (信息量单位)
- `I(i:j)` = 互信息, 量纲: **nat**
- `τ|E|`: τ 是边代价正则化参数。若 τ|E| 与 nat 相加，τ 的量纲必须是 **nat/边**，|E| 是无量纲计数 → τ|E| 量纲为 nat。
- C[G] 总体的量纲: **nat**. 一致性成立。 ✅

**但有一个隐藏问题:** τ 的量纲 [nat/边] 意味着每增加一条边，信息成本增加 τ nat。τ 的数值从未给出，文档仅称其为"正则化参数"。若 τ 的量级与 s(q) 或 I 可比，则 C[G] 景观的结构可能由 τ 主导而非 s(q)。文档未讨论这一点。

### Q1.2 T_c = ⟨δq²⟩·H_ii

- `δq`: q ∈ [0,1] 是无量纲概率型变量 → ⟨δq²⟩ **无量纲**
- `H_ii` = ∂²C/∂q_i²: C 量纲 [nat], q 无量纲 → H_ii 量纲 **[nat]**
- ∴ T_c 量纲: **nat** (信息温度). 一致性成立。 ✅

**注意:** 文档在 §5.1 表中标注 T_c 的量纲为 "nat (信息温度)"，正确。但在 §2.3 的 Langevin 方程中，D_c (扩散常数) 和 μ (迁移率) 的量纲未被明确给出。若 T_c^{bare} = D_c/⟨μ⟩ (Einstein 关系)，需确认 D_c 和 μ 的量纲一致性。μ = c²/[γ₀(1-q)]，其中 c² 和 γ₀ 的量纲未定义。 ⚠️

### Q1.3 Γ_{i→j} = γ₀[(1-q_i)q_j - χ_{ij}/4]

**此公式在文档中不存在。** 经全文搜索确认: `Γ_{i→j}`、`χ_{ij}` 均未出现在 round1.md 中。

文档中出现的逃逸率公式是 Kramers 形式:
```
Γ_esc = √(H_min |H_barrier|)/(2πγ) · exp(-ΔC/T_c)
```
对该公式的量纲分析:
- H_min, H_barrier: 量纲 [nat] (Hessian 行列式 [nat]^N)
- γ: 阻尼系数，量纲 [时间]^{-1}
- √(H_min|H_barrier|)/(2πγ): 量纲取决于 Hessian 行列式 → 对 N=1, [nat]/[时间]^{-1} = [nat·时间] → 有问题

**问题:** Kramers 公式中的 Hessian 行列式在标准统计力学中有 [能量] 量纲。当 C[G] 量纲为 [nat] 而非 [能量] 时，H 的量纲也是 [nat]，导致 prefactor 的物理含义模糊。文档未讨论这一替换的量纲后果。 ⚠️

### Q1.4 τ_esc = τ₀ exp(ΔC/T_c)

- `ΔC`: 量纲 [nat]
- `T_c`: 量纲 [nat]
- `ΔC/T_c`: **无量纲** ✅
- `τ₀`: 量纲 [时间]
- `τ_esc`: 量纲 [时间] ✅

### Q1.5 Σ = ½Δq^T H Δq

- `Δq`: 无量纲
- `H`: 量纲 [nat]
- `Σ`: 量纲 **[nat]** ✅

但文档在 §3.4 写道 "Σ的量纲: [信息²/节点]"——这是**错误的**。若 Δq 无量纲、H 量纲为 nat (不是 nat/节点)，则 Σ 量纲为 nat，不是 nat²/节点。文档自身对量纲的表述前后不一致。 ⚠️

### Q1.6 超越函数自变量

- `s(q) = -q ln q - (1-q) ln(1-q)`: q 无量纲 → ln(无量纲) 合法 ✅
- `exp(-ΔC/T_c)`: ΔC/T_c 无量纲 ✅
- `ln(t_universe/τ₀)`: 时间比无量纲 ✅

## Q2. 符号/方向校对

### Q2.1 ∂(Δq)/∂t = -H·Δq → Δq 随时间减小?

方程 (§3.3): `d(Δq)/dt = -H|_{q_dyn} · Δq`

若 q_dyn 处于 C[G] 的局部极小值，则 H 在该点正定 → 所有本征值 λ_i > 0。此时 `-H·Δq` 指向与 Δq 相反的方向 → Δq 指数衰减至零。**方向正确。** ✅

但文档同时也说 "在冻结态，衰减速率极慢 (τ_relax > t_universe)" (§3.3)。这依赖于 λ_min 的具体数值，而 λ_min 未计算——仅说 λ_min ~ -4 在中心（这不是极小值点），在边界 λ → -∞。在极小值处 λ_min 应为正值但可能很小。**λ_min 的具体估计缺失。** ⚠️

### Q2.2 T_c/T_g ≪ 1 → 遍历性破缺 → 方向?

Arrhenius 公式: `τ_esc = τ₀ exp(ΔC/T_c)`. 当 T_c < T_g (即 T_c/T_g < 1)，τ_esc > t_universe → 系统在宇宙年龄内无法翻越势垒 → 遍历性破缺。**方向正确。** ✅

### Q2.3 s''(q) = -1/(q(1-q)) < 0 → 凹性 → 边界最优?

严格凹函数在有界闭集 [0,1] 上的最小值必然在边界 {0, 1}。**方向正确。** ✅

但文档将此性质用于单个节点 (对角元 s(q_i))。C[G] 包含耦合项 I(i:j)，可能产生内部极小值（即使 s 是凹的，如果 I(i:j) 的凸性足够强）。文档在 §1.3 承认这一点但未给出耦合能克服凹性的定量条件。 ⚠️

### Q2.4 DESI w₀>-1, w_a<0 → w(z) 从 phantom 到 quintessence → 与老化动力学方向一致性?

文档推理链:
1. 早期 Δq 大 → Σ 大 → ρ_DE 大
2. 当前 Δq 减小中 → Σ 减小 → ρ_DE 减小
3. ρ_DE 减小 ↔ w > -1 (quintessence)
4. 早期 ρ_DE 更大↔ 可能 w < -1 (phantom)

**问题:** 第 1-2 步说的是 ρ_DE 单调递减（Δq 持续减小），这意味着 w > -1 **始终成立**（quintessence 全程）。但 DESI 结果表明 w 从 phantom (w<-1) **穿越** 到 quintessence (w>-1)——这意味着 ρ_DE 先增后减。这是**定性方向相反**。

文档试图用 "因果结构快速形成期" vs "缓慢弛豫期" 来绕过这一问题，但未给出 Δq 从增长变为衰减的动力学转折机制。这不是严格的方向一致性——是一个需要额外假设的补救论证。 ⛔

**极限验证:** 取 w → -1 极限: Causal Glass 在 w = -1 (ΛCDM) 时，Δq = 0 (遍历态，无冻结应力)。但文档声称当前 w > -1（Δq > 0 且衰减中）。w = -1 极限意味着 Causal Glass 不存在可观测效应 → 理论退化为不可证伪。 ⚠️

## Q3. 循环论证校对

### Q3.1 T_c 估计中的循环

T_c 估计链 (§2.3):
```
CMB δρ/ρ ~ 10^{-5}
  → ⟨δq²⟩ ≈ (10^{-5})² = 10^{-10}    [输入1]
  → 假设 q ~ δq_struct ~ 10^{-5}       [输入2 — 同一数据!]
  → H_ii ≈ 1/q ≈ 10^5                [从输入2推导]
  → T_c ≈ 10^{-10} × 10^5 = 10^{-5}  [输出]
```

然后文档在 §5.1 中将输出 Δq ≈ 10^{-5} 与输入 δρ/ρ ≈ 10^{-5} 等同，声称 "Δq (冻结应力) ~ 10^{-5} (≈ δq_struct)"。

**这是循环论证:** 输入 (CMB 扰动幅度) 经过一次乘法恒等变换 (×⟨δq⟩×H⁻¹×H = ×1，若 H ∝ 1/⟨δq⟩) 后作为输出呈现。若 H_ii ≈ 1/q 且 q ≈ δq，则 T_c ≈ δq（量级上）。T_c ≈ 10^{-5} 不是独立推导——它等价于假设 q ≈ δq_struct。

更关键的是: **T_c ≈ 10^{-5} 是"深度玻璃相"结论的核心输入** (§4.5)。如果 T_c 是被循环论证污染的，整个 §4.5-4.6 的定量结论将被污染。

⛔ **阻断:** T_c 的估计构成形式上的循环论证。输入 δq~10^{-5}，输出 T_c~10^{-5}~δq，且 Δq 也被设为 ~10^{-5}。三个量被强制等同。

### Q3.2 τ₀ 的选择是否独立于要证明的结论?

§4.4 使用了多个 τ₀ 选择 (t_P, QCD 时间, 星系动力学时间)。关键问题是 τ₀ 是否为自由参数:

- 若选 τ₀ = t_P: T_g(微观) = 0.0049
- 若选 τ₀ = 10^{15}s: T_g(星系) = 1500

文档声称 "每个尺度对应不同的 τ₀ 和 N_coop"。但在标准 Kramers 理论中，τ₀ 是微观尝试频率的倒数——应使用系统的最短时间尺度 (t_P 或类似)，而非宏观尺度 τ₀。文档的 "多层级 τ₀" 将宏观重组时间与微观尝试频率混为一谈。

**这不是完全的循环论证，但是一种参数滑动:** 任何 T_c 值都能通过选择合适的 τ₀ 使 T_c/T_g ≪ 1 成立。例如，若实际 T_c ≈ 1 (非玻璃态)，只需选择 τ₀ ~ t_universe (即选择了某个 "层级") 就能得到 T_g ≈ 0 → T_c/T_g ≫ 1 → 遍历态。结论取决于 τ₀ 的选择，而非独立于它。

⚠️ **警告:** τ₀ 的选择不是独立的——缺乏物理原则来挑选正确的层级，使得 T_c/T_g ≪ 1 的结论部分依赖于参数选择。

### Q3.3 "深度玻璃相"结论是否预设了 T_c ≪ T_g?

文档程序: 先估计 T_c (§2.3) → 再估计 T_g (§4.4) → 比较 (§4.5) → 结论。

形式上 T_c 和 T_g 是独立估计的（T_c 用 CMB 涨落+FDT，T_g 用势垒+Arrhenius）。但有一个隐藏循环:

T_c 估计中使用了 q ~ 10^{-5}（接近边界），但这本身预设了系统已经在边界附近——即已经处于玻璃态（q 不处于中心的 1/2）。若系统处于遍历态（q ≈ 1/2），H_ii ≈ 4，T_c ≈ 4×10^{-10}——反而更小。

但若取 q ≈ 1/2（遍历态假设），T_c 更小 → T_c/T_g 更小 → 遍历性破缺更强。这不会改变定性结论，所以不是循环论证——只是估计中的前提选择不够独立。

⚠️ **警告:** q ~ 10^{-5} 的选择虽不直接循环，但隐含了对系统状态的假设。

| T_c≪T_g 前提预设 | ⚠️ q~10^{-5} 隐含玻璃态假设 |

## Q4. 量级鸿沟标记

### Q4.1 T_c ≈ 10^{-5} vs T_g ≈ 0.005 → 比值 2×10^{-3}

比值 2×10^{-3} 本身在物理中并非巨大鸿沟（三个数量级）。但在 Arrhenius 框架中:
- exp(ΔC/T_c) = exp(0.693/10^{-5}) ≈ 10^{30096}
- exp(ΔC/T_g) = exp(0.693/0.005) ≈ 10^{60}
- t_universe/τ₀ ≈ 10^{61} (τ₀=t_P)

比较: exp(ΔC/T_c) = 10^{30096} ≫ 10^{61} → 逃逸时间比宇宙年龄长 10^{30035} 倍。

**这是一个量级鸿沟，但不是 "T_c vs T_g 的鸿沟"——而是 Arrhenius 因子本身的鸿沟。** 如果 exp(0.693/10^{-5}) ≈ 10^{30096}，系统在任何可观测时间尺度上应该完全静止——但宇宙并非如此（星系形成、结构演化持续进行）。

⛔ **阻断:** exp(ΔC/T_c) ≈ 10^{30096} 的物理含义是系统绝对冻结——与可观测宇宙的动力学矛盾。要么 T_c 被低估了数千个数量级，要么 C[G] 景观势垒模型不适用于描述宇宙动力学。

### Q4.2 T_c ≈ 10^{-5} vs T_g(星系) ≈ 1.5×10³ → 比值 ~10^{-8}

这个比值基于 τ₀(星系) = 10^{15}s。但如 Q3.2 分析，星系动力学时间不应当作 Kramers 微观尝试频率。使用微观 τ₀ 时，T_g 对所有尺度是同一个值 (~0.005)，不存在多层级鸿沟。

⚠️ **警告:** T_g(星系) ≈ 1.5×10³ 的物理含义被混淆——这不是真正意义上的 "玻璃转变温度"，而是将宏观重组时间硬塞入 Arrhenius 公式的结果。

### Q4.3 Δq ≈ 10^{-5} 而单节点势垒 ΔC ≈ 0.693 → 比值 ~10^{-5}

Δq 是序参量（无量纲），ΔC 是势垒（nat）。两者量纲不同，直接比值无意义。但若将 Δq 解释为 "系统偏离全局最优的幅度"，10^{-5} 量级意味着偏离极小——在单节点势垒 0.693 nat 面前几乎可忽略。

**这是合理的:** 接近边界的系统（q ≈ ε）偏离边界的幅度 ε 与势垒 ln(1/ε) 之比可以是小的。无矛盾。 ✅

### Q4.4 DESI w₀ ≈ -0.80 偏离 ΛCDM w=-1 的 3.1σ

3.1σ 在粒子物理标准（5σ）下不是 "发现" 级别。在宇宙学中 3σ 信号经常随着更多数据而消退。文档引用的 Yun Wang 独立分析仅发现 1.2-1.9σ。

⚠️ **警告:** 3.1σ 是一个有争议的信号。如果 DESI 后续数据（DR3/DR4）将显著性降低到 <2σ，则 Causal Glass 与 DESI 的 "定性一致" 将失去数据支撑。

### Q4.5 κ 耦合常数完全未知

文档 §3.4 和 §5.3 承认 κ 完全未知。所有定量暗能量预测（ρ_DE = κΣ, w(z) 形式等）都线性依赖 κ。

**后果:** 当前所有 "暗能量预测" 只是标度关系 ρ_DE ∝ Σ ∝ T_c·Δq，而非数值预测。T_c ≈ 10^{-5} 的估计即便正确，也无法给出 ρ_DE 的具体数值——仅给出 "非零且缓慢演化" 的定性陈述。

⛔ **阻断:** κ 未知使 Causal Glass 在暗能量定量预测上不产生可检验的数字。w(z) 的 "老化标度形式" 也因缺乏 κ 而无具体的偏离幅度。

## Q5. 声张缩水 + 替代解释 + 落地检查

### Q5.1 声张1: "C[G]景观遍历性破缺在所有尺度上稳健成立"

**声张的证明力评估:**

支撑证据:
- T_c/T_g ≪ 1 在所有 τ₀ 选择下成立
- Arrhenius 指数 exp(ΔC/T_c) ≫ ln(t/τ₀) 以大裕度成立

弱化因素:
1. T_c 估计循环论证 (Q3.1) → T_c ≈ 10^{-5} 不是独立量
2. 若 T_c 实际为 O(10^{-3})（接近 T_g 微观），遍历性破缺仍是定性成立的，但 "深度" 级别减弱
3. τ₀ 选择缺乏物理原则 (Q3.2) → 不同 τ₀ 给不同 T_g

**净评估:** 遍历性破缺的定性结论（T_c < T_g）可能稳健（因为 Arrhenius 指数对 T_c 不敏感——只要 T_c 不是极端大，指数就天文大）。但 "所有尺度上" 的声称被混乱的多层级 τ₀ 分析削弱——实际上只有微观 T_g ≈ 0.005 是物理上合理的。 ⚠️

### Q5.2 声张2: "DESI DR2与Causal Glass定性一致"

**声张缩水分析:**

DESI 的核心结果是 w₀ > -1, w_a < 0 → w(z) 穿越 -1。Causal Glass 声称 "定性一致"，理由: w(z) 的方向（从早期 phantom 到当前 quintessence）与因果玻璃老化方向一致。

**但以下模型同样有此 "定性一致":**
- 任何 quintom 模型（双场暗能量，w 可穿越 -1）
- 修改引力的 f(R) 模型中的特定参数区
- 实质上任何 w(z) ≠ 常数 的暗能量模型，只要 w 随时间演化

**反过来说:** 如果 DESI 发现 w₀ < -1, w_a > 0 (从 quintessence 到 phantom)，Causal Glass 是否也能找到 "定性一致" 的解释？很可能——只需翻转 Δq 演化方向的符号推演。

"w 不是常数" 是 DESI 的核心声张，"穿越 -1" 是更具体的声张。Causal Glass 的 "一致性" 仅限于 "w 不是常数" 的一般性层面，而非对穿越方向的具体预测。

⛔ **阻断:** "定性一致" 构成声张缩水——该陈述与几乎所有动态暗能量模型一致，不构成对 Causal Glass 的独特支持。

### Q5.3 落地计算检查

**落地计算 A (§1.2): 景观几何**
- s(1/2) = ln 2 ≈ 0.693 nat: **真实计算** ✅
- 单节点势垒 = ln 2: **真实计算** ✅
- Hessian 对角元 H_{ii} = -1/(q(1-q)) + 耦合项: **形式推导，未数值化** ⚠️
- 谱密度: 仅定性讨论 ⚠️

评级: **部分落地** — s(q) 相关计算是落地，Hessian 和谱密度不是。

**落地计算 B (§2.3): T_c 估计**
- 三个涨落源的量级: 量子 10^{-61}, 视界 10^{-60}, 结构 10^{-5}: **量级比对，非计算**
- T_c = ⟨δq²⟩·H_{ii}: **带循环论证的估算，非独立计算**
- T_c ≈ 10^{-5}: **数量级猜测**，不是可计算预言

- 数值表: ln(t/τ₀) 的计算正确 ✅

### Q5.4 替代解释

**更简单的替代方案: ΛCDM + 已知物理**
