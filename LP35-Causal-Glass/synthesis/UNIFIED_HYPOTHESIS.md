## 一句话

**宇宙的演化 = 一个巨大的、尚未完成的量子退相干过程。我们现在看到的一切异常——DESI phantom dip、JWST早期大星系、CMB大尺度异常——都是同一个过程在不同时期的表现。**

## 假设的核心

### 公理级假设 (只有2条)

**A1: 信息容量有界。** 宇宙的状态可以用有限信息描述。不存在"无限精度"的物理量。

**A2: 因果不可逆。** 信息一旦被记录（退相干），就不能被完美擦除。|0⟩→|1⟩是单向的。

### 从公理到观测的唯一桥梁

**退相干进度 q(t) = 尚未被记录的量子信息比例。**

- q=1: 全量子（暴胀刚结束时）
- q=1/2: 半量子半经典
- q→0: 全经典（热寂）

**关键假设: 宇宙退相干速率 ∝ 宇宙恒星形成率 (SFR)。**

理由: 恒星形成 = 气体云塌缩 = 引力将量子叠加态投影到经典密度场 = 大规模determination事件。SFR是宇宙中最大的结构化过程——没有什么比恒星形成产生更多的退相干。

### 从SFR(z)到w(z)的定量链

```
SFR(z)  ──→  dq/dt = -α·SFR(z)  ──→  q(z)  ──→  w(z) = -1 + β·q(z)
  ↑                    ↑                    ↑              ↑
 观测已知           退相干速率        退相干进度      暗能量EOS
(独立测量)         ∝结构形成率       =∫SFR dt       =冷冻残留应力
```

这不是自由参数拟合。SFR(z)由独立于宇宙学的天文观测确定（UV光度函数、IR光度函数、GRB等）。q(z)和w(z)之间只有一个比例常数。

## 解释三个异常

### 异常1: DESI phantom dip at z~1

**观测:** w(z)在z~1处phantom最深(w≈-1.48)，低z为quintessence(w≈-0.84)。

**解释:** z~1是宇宙SFR的峰值(z~1-2，即"宇宙正午")。此时退相干速率最大，|0⟩态被最快消耗。当SFR冲过峰值后下降时，退相干速率突然降低——但之前积累的"退相干应力"（已被记录但尚未弛豫的信息）需要释放。这个释放就是phantom dip。

```
精确预言: w(z)的二阶导数 d²w/dz² 在SFR峰值红移处改变符号
         SFR峰值红移 ≈ 1.5-2 (根据不同测量)
         → d²w/dz² 应该在 z ≈ 1-1.5 处改变符号
         → 如果SFR峰值在z≈2，w拐点应在z~1-2之间
```

### 异常2: JWST "太早太大"星系 at z≥10

**观测:** z~10-14处星系质量比ΛCDM预测大10-100倍。

**解释:** 早期宇宙q大→量子相干强→引力塌缩被量子纠缠增强→结构形成效率远超纯经典引力。这不是"暗物质太多"或"恒星形成效率太高"——是**量子相干让引力比经典广义相对论更强**。

```
定量预言: 结构形成增强因子 ∝ q(z)
         q(z=10) ≈ 0.3-0.5 (大部分|0⟩尚未消耗)
         → 有效引力 ≈ G × (1 + q)  (增强了30-50%)
         → 结合非线性塌缩的指数敏感性
         → 星系质量增强10-100×（与JWST观测一致）
```

### 异常3: CMB大尺度异常 (l<30)

**观测:** 低l功率缺失、冷斑、半球不对称、宇称不对称。

**解释:** 如果这不是本轮宇宙的第一个循环——上一轮循环退相干完成时(P_reflux→0)，在最大尺度上留下了"化石"结构。这些结构在本轮暴胀中没有被完全抹平（因为它们的尺度大于暴胀视界）。

```
定量预言: 化石结构的角尺度 l_fossil ≈ 180°/θ_fossil
         θ_fossil ≈ (上一轮循环视界) / (本轮CMB距离)
         → 如果上一轮循环在z_cycle(~1)处结束
         → l_fossil ≈ 10-20（与观测异常范围精确重合）
```

## 唯一甄别性预测

**核心预言的精确表述:**

> w(z)的演化形状由宇宙恒星形成历史SFR(z)唯一决定：
> w(z) = -1 + β·∫_z^∞ α·SFR(z')·|dt/dz'|·dz'
> 其中SFR(z)由独立天文观测确定，α和β是两个普适常数。

**关键检验:**

取SFR(z)的独立测量（Madau & Dickinson 2014或其他），计算q(z) = ∫_∞^z SFR(z') dz'（归一化），然后拟合w(z) = -1 + β·q(z)。如果拟合优度显著优于CPL(w0,wa)和ΛCDM(w=-1)，则假设通过。

**现在就能做的检验:**

DESI DR2的binned w(z)数据 + Madau-Dickinson SFR(z)拟合式 → 检验w(z)与∫SFR(z')dz'的线性关系。

这不需要等Euclid。不需要新仪器。现在就做。

## 诚实声明

1. **α和β尚未从第一原理推导。** α(q-SFR耦合)和β(q-w映射)目前是拟合参数。第一原理推导需要量子引力中的退相干理论。

2. **SFR(z)本身有观测不确定性。** 不同测量给出的SFR峰值红移在1.5-3之间，峰值幅度相差~2-3倍。这会传播到w(z)预言中。

3. **循环假设(异常3)是最推测性的部分。** "上一轮循环化石"需要暴胀没有完全抹平最大尺度上的结构——这与标准暴胀的"无毛定理"有潜在矛盾。

4. **如果SFR-w关系被排除，假设的核心(退相干=SFR)需要修正——但退相干=结构形成的定性框架留存。**

5. **本假设不解释为什么宇宙开始于量子态。** 那是暴胀/量子引力的问题，超出当前范围。
