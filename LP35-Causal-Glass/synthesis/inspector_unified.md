## Q1: 统一性声称是否可检验？

**"五派不矛盾"——这个声称怎么证伪？**

### 1.1 精确重构声称

文档声称：

> "五派不是五个互斥的'暗能量是什么'的答案。他们是同一个因果图相变在五个不同观测窗口的五种有效描述。"

这意味着：不存在一组观测数据能同时支持 Quintom 而排除弯曲，或同时支持 IDE 而排除 Horndeski——因为它们在物理上等价，只是"投影"不同。

### 1.2 互斥性检验：Quintom vs 弯曲

**Quintom 的核心前提：** 暗能量状态方程 w(z) **确实穿越**了 -1（phantom crossing）。这是 Quintom 存在的理由——单个标量场（quintessence w > -1 或 phantom w < -1）不能穿越 -1，需要双场（一个 phantom + 一个 quintessence）才能实现平滑穿越。

**弯曲派（Dinda 等）的核心前提：** w(z) **从未穿越** -1。表观 phantom crossing 是错误假设 Omega_k = 0 的人为产物。当宇宙有非零曲率时，同样的距离数据用 w = -1 + Omega_k != 0 就可以拟合，不需要 phantom crossing。

**这两个声称在物理上互斥：**
- Quintom: w(z) 有真实的 phantom crossing（w < -1 在某个红移区间）
- 弯曲: w(z) 恒为 -1（严格的 Lambda），phantom crossing 是拟合假象

**互斥性不可调和。** 不存在一个物理框架能让"真实 phantom crossing"和"phantom crossing 是假象"同时为真。这是排中律问题：要么 w 穿越 -1，要么不穿越。两者不能同时正确。

### 1.3 UNIFIED_FRAMEWORK 的处理方式

文档将弯曲派放在表格最后一行，标注为"all z"区间，描述为"Omega_k != 0 = Phi_q 的几何投影；表观 phantom crossing 来自平坦假设"。

**这个处理是范畴错误。** 弯曲派的声称是**认识论**的（"你看到 phantom crossing 是因为你假设了错误的几何"），而 Quintom 的声称是**本体论**的（"phantom crossing 是真实存在的物质场行为"）。把它们并置为"同一现象的不同投影"时，框架暗中否定了弯曲派的核心论断（phantom crossing 是假的），却声称"五派不矛盾"。

实际上框架自己的立场——Phi_q 穿越 1 产生 phantom 行为——本身就站了 Quintom 的队而否定了弯曲派。这不是统一，是选边后假装没有选边。

### 1.4 证伪方案：互斥参数区域

要让"统一性"成为可检验的声称，框架需要明确：
- 在什么参数区域内，Quintom 和弯曲给出互斥的预测？
- 在这些区域内，Phi_q 框架做出什么预测？站在哪一边？
- 如果数据支持弯曲（Omega_k != 0 + w = -1 拟合优于 phantom crossing），框架是否被证伪？还是可以"弯曲只是在另一个窗口"？

**当前状态：证伪条件未指定。** 文档声称"可检验"（"w(z)的形状应由 Phi_q 唯一决定，不依赖模型选择"），但没有给出任何会使统一声称被否定的观测结果。这是一个不可证伪的统一声称——波普尔意义上的伪科学风险。

### 1.5 更基本的逻辑问题

五个学派各自声称自己是暗能量的"正确"解释。UNIFIED_FRAMEWORK 说"你们都对"。但这回避了一个问题：**如果五派是同一现象的不同投影，为什么它们的形式差异如此之大？**

- Quintom: 双标量场，拉氏量含动能耦合
- IDE: 暗能量与暗物质之间有非引力相互作用
- Horndeski: 最一般的单标量场-张量理论，含二阶场方程
- 真空相变：暗能量来自真空态的一级相变
- 弯曲：暗能量不存在，是几何假设错误

这些不是"不同投影"——它们是不相容的物理出发点（标量场 vs 相互作用 vs 修正引力 vs 相变 vs 几何重解释）。把它们说成"同一现象"类似于说"地心说和日心说是同一现象的不同投影"——在某些极限下两者都可以拟合数据，但它们的物理本体论不可调和。

### Q1 裁决

**统一性声称在当前形式下不可证伪，因为：**
1. 证伪条件未指定——没有任何观测会迫使框架承认"五派不是同一个现象"
2. Quintom vs 弯曲的排中律矛盾（w 是否真的穿越 -1）被框架用修辞并置掩盖而非解决
3. 五个学派的本体论互斥性（标量场 vs 修正引力 vs 几何重解释）被"不同投影"的隐喻回避
4. "不矛盾"不等于"统一"——两个理论可以都对（在不同极限），但这需要推导出各自的适用范围，而非仅仅画一张表

**要使声称可检验，最低要求：**
- 明确证伪条件："如果观测显示 [X]，则统一框架被证伪"
- 解决 Quintom vs 弯曲的排中律矛盾：框架是否预测 w 真实穿越 -1？
- 推导（而非断言）一个理论到另一个理论的映射极限

## Q2: Phi_q 作为序参量是否独立于 LambdaCDM？

**Phi_q = |dH/dt|/H^2 完全由 LambdaCDM 的 H(z) 决定。如果 H(z) 是 LambdaCDM 的，那 Phi_q 就是 LambdaCDM 的导出量——不是"新物理"。**

### 2.1 Phi_q 对 LambdaCDM 的依附性

在标准 LambdaCDM 中（w = -1）：

```
H^2(z) = H_0^2 [Omega_m(1+z)^3 + Omega_Lambda]

dH/dt = H × dz/dt × dH/dz = H × [-H(1+z)] × [3 H_0^2 Omega_m(1+z)^2 / (2H)]

Phi_q = |dH/dt| / H^2
      = |H × [-H(1+z)] × [3 H_0^2 Omega_m(1+z)^2 / (2H)]| / H^2
      = (3/2) × H_0^2 Omega_m(1+z)^3 / H^2(z)
      = (3/2) × Omega_m(1+z)^3 / [Omega_m(1+z)^3 + Omega_Lambda]
```

**Phi_q(z) 是 Omega_m 和 Omega_Lambda 的纯函数。** 它不包含任何"新物理"——它是 LambdaCDM 的参数化 H(z) 的代数组合。

### 2.2 循环论证：用 w=-1 的 H(z) 解释 w != -1

这是更深的循环。文档使用 LambdaCDM（假设 w=-1）计算 Phi_q(z)，然后声称 Phi_q 的演化"解释"了 DESI 观测到的 w 偏离 -1。

**循环结构：**
1. 假设 w = -1 → 确定 Omega_m, Omega_Lambda → 计算 H(z) → 计算 Phi_q(z)
2. 发现 Phi_q(z) 在某些红移穿越 1 → 声称这"解释"了观测到的 w(z) 偏离 -1
3. 但 w(z) != -1 意味着步骤 1 的假设（w = -1）是错的 → H(z) 应该不同于 LambdaCDM → Phi_q(z) 也会不同

**如果 w != -1 (如 DESI 所暗示)，Phi_q(z) 会变多少？**

对于常数 w = -0.9 (quintessence):
```
H^2(z) = H_0^2 [Omega_m(1+z)^3 + Omega_DE(1+z)^{3(1+w)}]
        = H_0^2 [0.3(1+z)^3 + 0.7(1+z)^{0.3}]

Phi_q(z) 会与 w=-1 时不同。
```

但更关键的是：**如果 w(z) 不是常数**（如框架自身所主张），那么 H(z) 由 w(z) 的历史决定：
```
H^2(z) = H_0^2 [Omega_m(1+z)^3 + Omega_DE exp(3 int_0^z (1+w(z'))/(1+z') dz')]
```

Phi_q(z) 又由 dH/dt 决定。这意味着 Phi_q 依赖于 w(z)，而框架声称 w(z) 由 Phi_q 决定——这构成一个需要自洽求解的耦合系统，而非"Phi_q 从 LambdaCDM 计算然后推出 w(z)"的单向推导。

**当前框架没有进行自洽求解。** 它使用的是 LambdaCDM（w=-1）的 H(z)，暗含 w=-1 的假设，却声称解释了 w!=-1 的观测。

### 2.3 "无自由参数"的假象

文档声称 Phi_q "从 H(z) 直接算，不加自由参数"。这在技术上是真的（如果接受 LambdaCDM 的 H(z)），但掩盖了一个事实：

**Phi_q 继承了 LambdaCDM 的所有自由参数。** H_0, Omega_m, Omega_Lambda 的每一个不确定性都直接传播到 Phi_q(z)。这些参数本身是从假定 w=-1 的数据分析中得到的。

当框架声称"Phi_q 解释了 w(z) 的演化"时，它实际上在说"LambdaCDM 的参数（通过 Phi_q）与 LambdaCDM 的偏离（w!=-1）相关"。这不是"无参数新物理"——这是 LambdaCDM 的参数化自相关。

### 2.4 如果真的不用 LambdaCDM 呢？

假设框架朝另一个方向发展：Phi_q 从第一原理（因果图动力学）计算，不依赖 H(z)。那么 Phi_q 必须从 causal graph 的微观参数（节点数 N、搜索效率 c、平均度等）推导。

**但 inspect_tau_derive.md 已经证明：tau_explore 的定义中包含了 c（因果图搜索效率），而 c 未标定。** Phi_q = tau_explore / tau_expand = c/(N_c) × 1/H × H = c/(N_c)，依赖于未标定参数。只有当我们选择 tau_explore = 1/H（即设 c/N_c = 1）时，Phi_q 才退化为 |dH/dt|/H^2。

**选择 tau_explore = 1/H 等价于选择 Phi_q 完全由 LambdaCDM 决定。** 这是框架的隐藏自由——通过设定 c/N_c = 1，它将自己锚定在 LambdaCDM 上，然后声称 LambdaCDM 导出的 Phi_q 解释了 LambdaCDM 的偏离。

### Q2 裁决

**Phi_q 不是独立于 LambdaCDM 的序参量。它是 LambdaCDM 参数化 H(z) 的导出量 + 一个隐藏假设（tau_explore = 1/H，即 c = N_c）。**

- 如果接受 tau_explore = 1/H，则 Phi_q = (3/2) Omega_m(1+z)^3 / [Omega_m(1+z)^3 + Omega_Lambda]，这是 Omega_m, Omega_Lambda（在 w=-1 假设下约束的）的纯函数
- 这等价于说"LambdaCDM 的减速参数 q(z) 相关于 w(z) 的偏离"——有趣，但不是新物理
- 更严重的是：这构成循环——用 w=-1 的 H(z) 计算 Phi_q，声称 Phi_q 解释 w!=-1

**最低修复要求：**
- 自洽计算：假设 w(z) = -1 + f(Phi_q(z))，与修正的 H(z) 自洽联立求解
- 展示自洽解与 LambdaCDM 解的差异量级
- 或者：放弃 Phi_q 从 H(z) 计算，改为从因果图微观参数第一原理计算（需要标定 c, l_c, N_c）

## Q3: 映射是双向的还是单向的？

**声称"五派的参数在 Phi_q 框架中有自洽的映射"。这个映射是什么？**

### 3.1 精确检查：存在什么映射？

文档没有给出任何一个具体的映射公式。只有一张表格将每个学派映射到一个"有效区间"和一句"在 Phi_q 框架中的对应"的定性描述。

**这不是映射。这是分类。** 分类是把对象放进盒子（"Quintom 属于 Phi_q ~ 1 这个区间"）。映射是给出一个函数 f: Parameter_space_A -> Parameter_space_B（"Quintom 的 phantom-quintessence 耦合常数 epsilon 与 Phi_q 的关系是 epsilon = ..."）。

### 3.2 五派的参数空间

让我列出每一派至少有哪些关键参数，以及需要的映射：

| 学派 | 关键参数 | 需要映射 | 当前状态 |
|------|---------|---------|:---:|
| Quintom | V(phi_phantom, phi_quintessence), 动能耦合 epsilon, 场质量 m_phi | epsilon, m_phi -> Phi_q(z) | ❌ 不存在 |
| IDE | 耦合常数 xi, 势 V(phi) | xi -> Phi_q(z) | ❌ 不存在 |
| Horndeski | G_2, G_3, G_4, G_5 (phi, X) 四个任意函数 | 函数族 -> Phi_q(z) 区间 | ❌ 不存在 |
| 真空相变 | 相变温度 T_c, 潜热 L, 成核率 Gamma | T_c, L -> Phi_q(z) | ❌ 不存在 |
| 弯曲 | Omega_k | Omega_k -> Phi_q(z) | ❌ 不存在 |

**没有一行映射被给出。** 表格中的"有效区间"栏（如 Quintom: z~0.5-1.5）不是映射——它是描述 Quintom 通常被用来拟合的数据的红移范围。

### 3.3 单向分类 vs 双向映射

**单向分类（当前框架实际做的）：**
```
"Quintom 在 Phi_q ~ 1 处运作"
```
这只需要知道 Quintom 模型通常被用在 z~0.5-1.5 的数据上，而 Phi_q(z) 在那个红移区间恰好接近 1。

**双向映射（框架声称的）：**
```
给定 Phi_q 在红移 z 处的值 → 唯一确定 Quintom 势函数 V(phi_phantom, phi_quintessence) 的泛函形式
给定 Quintom 的势参数 → 唯一确定 Phi_q(z) 的行为
```

后者要求两者在数学上有等价关系。当前框架没有提供任何等价关系。

### 3.4 为什么这不是"真统一"

真统一需要展示：在适当的取极限下，每一个理论都可以从其他理论推导出来。例如：
- 取 IDE 的耦合常数 xi -> 0 → 恢复 Quintom 的某些极限
- 取 Horndeski 的 G_4 = 1/(16 pi G), G_5 = 0 → 恢复标准 GR
- 取 Horndeski 中的特定 G_2, G_3 → 恢复 Quintom 的有效描述

这是暗能量文献中已有的工作（如 Gleyzes et al. 2015 展示 Horndeski 如何在适当极限下包含 Quintom 和 IDE）。UNIFIED_FRAMEWORK 没有引用任何这类等价性工作，也没有提供新的等价性推导。

### 3.5 "贴标签" vs "统一"的区分

当前框架做的事等价于：
1. 画一条 Phi_q(z) 曲线（LambdaCDM 的）
2. 标记曲线上 Phi_q ≈ 1 的区域
3. 注意到五个学派的模型被用来拟合该红移区间的数据
4. 声称"五派是同一个相变的不同投影"

第 3 步到第 4 步的跳跃没有逻辑支撑。每个暗能量模型都被设计来拟合 z~0-2 的数据（因为那是 SNIa 的覆盖范围）。**任何暗能量模型都可以被放进 Phi_q 框架的这个区间——包括 CPL, wCDM, BA 等不在五派之列的模型。** 这意味着"被 Phi_q 框架分类"不是五派的特权——是所有暗能量模型的共性。

**贴标签的充要条件是"在 Phi_q ~ 1 附近运作"。所有拟合 z~1 数据的暗能量模型都满足这个条件。因此这个条件没有甄别力——它不区分五派彼此，也不区分五派和其他模型。**

### Q3 裁决

**映射不存在。框架做的是分类而非统一——给定一个学派，告诉你在 Phi_q 的哪个区间能找到它。这不是"五派等价"的证明，是"五派都在 z~1 附近活动"的重新描述。**

**双向映射是统一性的必要条件。** 如果框架不能提供从 Quintom 参数到 Phi_q 的函数，或者从 Phi_q 到 Horndeski G 函数的函数，那么声称的"统一"缺乏数学基础。

**当前状态：框架将五个学派的名称贴在 Phi_q 曲线的一个小区域上，然后宣布他们是"同一现象"。这是贴标签（labeling），不是统一（unification）。**

## Q4: 与现有统一框架的关系

**宇宙学中已存在用 w0-wa 平面统一分类暗能量模型的框架。Phi_q 框架与 w0-wa 分类的关系是什么？**

### 4.1 w0-wa 分类框架

Caldwell & Linder (2005) 提出了暗能量模型的 thawing/freezing 分类——这是暗能量文献中最具影响力的统一分类方案：

- **Thawing:** w 从 -1 起步（高 z），然后"解冻"偏离到 w > -1（低 z）。标量场在平坦势中被 Hubble 摩擦冻结，Hubble 摩擦减弱时开始滚动。
- **Freezing:** w 从 w > -1（高 z）开始，向 w = -1（低 z）"冻结"。标量场在陡峭势中追踪背景，暗能量主导后冻结。

这个分类覆盖了 Quintom、Quintessence、Phantom 和其他标量场暗能量模型。随后被扩展到包含 phantom crossing 的模型。

**关键点：w0-wa 分类框架也是参数化不可知的——它不假设特定的标量场模型，而是基于演化行为的拓扑分类。**

### 4.2 Phi_q 与 w0-wa 的关系

UNIFIED_FRAMEWORK 从未提及 w0-wa 分类。这是一个严重的遗漏，因为：

1. **w0-wa 是 Phi_q 的直接竞争对手。** 两者都声称提供暗能量演化的统一描述框架。如果 Phi_q 不能证明它比 w0-wa 更好（或至少是 w0-wa 的推广），它没有存在的理由。

2. **Phi_q 可以映射到 w0-wa 平面。** 如果 w(z) = -1 + f(Phi_q(z))，那么对于任意 f，可以在 w0-wa 参数空间中画出一条轨迹。不同学派的模型在 w0-wa 平面中有不同的典型区域（thawing 在左上，freezing 在右下）。Phi_q 框架能将五派映射到 w0-wa 平面中的不同区域吗？这会是"统一"的独立检验。

3. **Phi_q 可能只是 w0-wa 的重新参数化。** 如果 w(z) = -1 + beta * (Phi_q(z) - Phi_q_0)，那么 w0 = -1 + beta*(Phi_q(0)-Phi_q_0)，wa = beta * d(Phi_q)/dz|_{z=0}。这是一个线性投影——Phi_q 框架只是 CPL 参数化的一个特定（更紧的）子空间。如果是这样，框架应该明确声明，并且将"预测力"归因于这个子空间的紧致性，而非 Phi_q 的物理意义。

### 4.3 Phi_q 框架声称的优势 vs w0-wa

文档声称 Phi_q 框架的优势包括：
- "从 H(z) 直接算，不加自由参数"

但 w0-wa 也是两参数框架。Phi_q 声称"无自由参数"是通过将自由隐藏在 LambdaCDM 参数（Omega_m, Omega_Lambda）中实现的——这些参数本身有误差棒，它们的约束依赖于 w=-1 的假设。

相比之下，w0-wa 框架诚实得多：它承认 w(z) 的演化有自由参数（w0, wa），然后从数据约束它们。Phi_q 框架声称"无参数"但实际依赖的参数（Omega_m, Omega_Lambda, H_0, c, N_c）更多。

### 4.4 遗漏的文献

除了 w0-wa 分类，还有其他的统一/分类尝试，文档均未提及：
- Amendola et al. (2013) 的统一暗能量参数化
- Linder (2015) 的扩展 thawing/freezing
- 在 Horndeski 框架中统一标量-张量理论的 EFT 方法（Gleyzes et al. 2015, Bellini & Sawicki 2014）

这些现有工作要么提供了数学上的等价类（EFT 方法将 Horndeski 统一为 4+1 个时间函数），要么提供了可检验的分类方案（thawing/freezing 被 DETF 和 Euclid 科学白皮书采用）。Phi_q 框架不引用、不对比、不超越这些工作。

### Q4 裁决

**Phi_q 框架与 w0-wa 分类框架的关系完全未处理。这是文献缺口——框架声称自己是"统一框架"但没有与暗能量文献中最主要的统一分类框架比较。**

1. Phi_q 是 w0-wa 的替代、补充、还是特定子空间？

## Q5: 声张保真度

**"五派是同一现象的不同投影"——这是一个很强的声称。它要求证明五派在数学上等价（在适当极限下可以互推）。当前框架做到这一步了吗？**

### 5.1 声张的完整分解

UNIFIED_FRAMEWORK 做出了以下核心声称：

| # | 声张 | 保真度 | 诚实等价 |
|---|------|:---:|------|
| 1 | "五派是同一个因果图相变在不同 Phi_q 区间的有效描述" | 0.05 | "五派的模型都与 Phi_q ~ 1 区间的数据相关"（相关性，非等价性） |
| 2 | "Phi_q = |dH/dt|/H^2 是统一的序参量" | 0.15 | "Phi_q 是 LambdaCDM 派生参数（依赖于 Omega_m, Omega_Lambda），定性上与 z~0.5-1 数据行为相关" |
| 3 | "五派不矛盾" | 0.10 | "五派并非在所有方面都逻辑互斥"（弱化到一个近于无信息量的陈述） |
| 4 | "Phantom crossing 不需要新的物质成分" | 0.20 | "观测到的 phantom behavior 在本框架中由 Phi_q 穿越 1 解释"（但这依赖 Phi_q 从 w=-1 计算 + phantom 在 Phi_q=1.13>1 的事实） |
| 5 | "可检验"（w(z) 由 Phi_q 唯一决定） | 0.10 | "一个在定性上可关联但缺乏定量预言、证伪阈值、和自洽计算的陈述" |
| 6 | "五派的参数在 Phi_q 框架中有自洽的映射" | 0.00 | **没有任何映射被给出。这是一个空白声张。** |

**平均保真度: 0.10/1.0**

### 5.2 从"相关"到"等价"的跳跃

框架做的每一步推理的结构：

```
观测: 五派都在 z~0.5-1.5 区间拟合 DESI 数据
框架: z~0.5-1.5 正好是 Phi_q ~ 1 的区间
结论: 五派是同一个 Phi_q 相变的不同投影
```

这是"相关 = 因果 = 等价"的三级跳跃。每一步都需要论证：

**跳跃 1: 相关 = 因果**
五派在 Phi_q ~ 1 的区间运作，是因为 Phi_q 驱动了它们描述的物理，还是因为那个红移区间恰好是 SNIa+BAO 数据最丰富的区间？如果各派模型被设计来拟合 z~0-2 的数据（事实如此），它们自然会聚集在数据覆盖范围（z~0.2-1.5）——也就是 Phi_q ~ 0.5-1.3 的区间。这不是 Phi_q 物理吸引子，是数据覆盖的 artifact。

**跳跃 2: 因果 = 等价**
即使接受 Phi_q 驱动了暗能量行为（命题 A），从"同一个驱动力产生不同现象"推不出"不同现象是同一个现象的不同投影"。重力驱动了所有物体的运动——这不能得出"抛物线和椭圆轨道是同一现象的不同投影"的结论。

**跳跃 3 (隐式的): Phi_q 框架 = 五派之间的等价关系**
即使五派在某极限下等价（在数学物理中这需要证明），证明五派等价需要推导五派之间的对偶或极限关系——这是高度非平凡的理论物理工作。统一框架没有完成任何一步这样的推导。

### 5.3 关键反例：如果框架是对的，应该能看到什么？

波普尔检验：如果统一框架是真的，我们应该观测到什么？

框架的回答是："w(z) 的形状应由 Phi_q 唯一决定，不依赖模型选择"。但这等价于说"如果我们的理论是对的，数据应该符合我们的理论"——这不是证伪条件，这是理论的正面定义。

**真正的证伪检验：**
- 如果发现一个模型（如某个特定参数的 Horndeski 理论）的预测不能被映射到 Phi_q 框架中的任何参数组合 → 统一框架被证伪
- 如果从 Phi_q 框架推导出的 w(z) 形状与当前所有五派的预测都不同 → 框架超越五派，可以独立检验
- 如果 Phi_q 框架预测了一个所有五派都未预测但在后续数据中出现的特征 → 框架不仅是"统一"，而是有新增预测能力

当前框架没有提供任何这样的检验。

### 5.4 与 LP35 项目内部历史的矛盾

UNIFIED_FRAMEWORK 声称"五派彼此不矛盾"。但 LP35 项目自身的终点——新北极星——是：

> "Lambda = 因果冻结的残留应力——不是真空能量，是因果图定向扩张的必然遗迹。"

这与五派的**每一个**都不相容。五派都假设暗能量是某种可演化物质成分（场、相互作用、引力修正），而新北极星断言暗能量是因果滞后——不是"成分"而是"关系"。这两者在物理本体论层面互斥。

UNIFIED_FRAMEWORK 试图说"新北极星包含五派作为特例"——但这相当于说"关系本体论包含了物质本体论"。这是范畴层级混淆。

### 5.5 "框架"应该做什么 vs 实际做了什么

一个真正的统一框架（如麦克斯韦方程统一电和磁、弱电统一理论统一电磁和弱力、弦论试图统一所有力）需要：
1. **一个公理或方程组** 在特定极限下退化到各被统一理论的方程
2. **一个映射或对偶** 连接之前被认为独立的物理实体
3. **一个新增预测** 在被统一理论各自的适用范围之外，统一框架给出不同（且正确）的预测

UNIFIED_FRAMEWORK：
1. 没有公理或方程组——只有 Phi_q 的一个定义和一张表
2. 没有映射——声称存在但不提供
3. 没有新增预测——w(z) 的"预测"是 LambdaCDM H(z) 的重新表述 + 自由参数 beta

**这不是统一框架。这是一个分类方案——且是一个仅用一个维度（Phi_q 值）的分类方案。**

### Q5 裁决

**声张保真度极低。** "五派是同一现象的不同投影"在当前文档中没有任何数学支撑。文档最多证明了五派的适用红移区间与 Phi_q ~ 1 区域重叠——这是一个平凡的地理观察（co-location），不是理论统一（unification）。

**框架做的（48 行）与框架声称的（统一五个不相容的暗能量学派）之间的鸿沟是量级差距——不是"差一点就完成了"而是"几乎还没开始"。**
