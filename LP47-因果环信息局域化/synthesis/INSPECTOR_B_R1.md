## Q1. 量纲校对

### F1: m_eff = -ℏ/(c² · Re(λ_dominant))

```
左侧: [m_eff] = kg
右侧: [ℏ] = J·s = kg·m²·s⁻¹
      [c²] = m²/s²
      [Re(λ)] = s⁻¹
      [ℏ/(c²·Re(λ))] = (kg·m²·s⁻¹) / (m²/s²) / (s⁻¹)
                      = (kg·m²·s⁻¹) · (s²/m²) · s
                      = kg·s²
```

**判定: 量纲错误。** 右侧得 kg·s²，不是 kg。公式中 Re(λ) 的位置反了。

正确形式应为 **m_eff = -ℏ·Re(λ_dominant)/c²**:
```
[ℏ·Re(λ)/c²] = (kg·m²·s⁻¹)·(s⁻¹) / (m²/s²) = (kg·m²·s⁻²)/(m²/s²) = kg ✓
```

### F2: 1 + L(s) = 0

L(s) 无量纲。等式两侧无量纲。**通过。**

### F3: ∫₀^∞ ln|S(jω)| dω = π Σ Re(p_i)

```
左侧: ln|S| 无量纲，dω 单位 rad/s → 左侧单位 rad/s = s⁻¹
右侧: π 无量纲，Re(p_i) 单位 s⁻¹ → 右侧单位 s⁻¹
```

量纲匹配。**通过。**

### F4: S(s) + T(s) = 1

两侧均无量纲。**通过。**

### F5: αI(L₊) + βI(L₋) + γI(L₀) = 0

所有项无量纲（Laurent 多项式取值）。**通过。**

### F6: Γ₁/Γ₂ = I_{C1}(e^γ) / I_{C2}(e^γ)

```
γ: 退极化率，s⁻¹
e^γ: e^(s⁻¹) → **量纲错误！** 指数自变量必须无量纲。
```

正确形式应为 e^{-γ·τ₀}（τ₀ 为参考时间）或 e^{-γ/ω₀}（ω₀ 为参考频率）。**阻断级错误。**

### exp, sin, log 自变量检查

- ln|S(jω)|: S 无量纲 → ln 自变量无量纲 ✓
- e^γ: γ 有量纲 s⁻¹ → **阻断级错误** ✗
- cos(φ_total): φ_total 为相位角，无量纲 ✓

**Q1 结论**: F1 量纲错误（λ 位置反了），F6 指数自变量有量纲。其余通过。

## Q2. 符号/方向校对

### F1: m_eff ∝ -1/Re(λ_dominant)

λ_dominant < 0（稳定系统）→ Re(λ) < 0 → -1/Re(λ) > 0 → m_eff > 0。
质量为正，物理上合理。**符号正确。**

### Bode 积分符号

∫₀^∞ ln|S(jω)| dω = π Σ Re(p_i)

RHP 极点: Re(p_i) > 0 → 右侧 > 0 → 左侧积分 > 0。
S = 1/(1+L)，|L|≫1 时 |S|≈1/|L|，ln|S| < 0；需 |S|>1 区域补偿。
符合经典 Bode 积分结论。**符号正确。**

### φ_total → π 发散方向

文中声称 m_eff ∝ 1/|φ_total - π|，在 φ_total → π 时发散。
但实际工作公式 m_eff/m₀ ≈ 1/(1-γ·cos(φ_total)) 在 φ_total=π 时:
```
cos(π) = -1
m_eff/m₀ = 1/(1-γ·(-1)) = 1/(1+γ)
γ=0.5 → m_eff/m₀ = 1/1.5 ≈ 0.67
```

**质量减小了 33%，而非发散！** 定性趋势与公式定量结果矛盾。

更严重的是，修正 F1 量纲错误后:
```
m_eff = -ℏ·Re(λ)/c² ∝ -Re(λ)
```
而 φ_total→π 时闭环极点靠近虚轴，Re(λ)→0⁻，所以 m_eff→0（质量消失），而非发散。
**发散的方向完全反了。**

**Q2 结论**: 符号方向本身（正负号）正确，但物理趋势（φ→π 的行为）与公式预测矛盾。φ→π 时按修正后的公式质量应趋于零，而非发散。

## Q4. 量级鸿沟标记

### m_eff ≈ 1.17e-36 kg（文件声称值） vs 电子质量 9.11e-31 kg

比值: 1.17e-36 / 9.11e-31 ≈ 1.3×10⁻⁶，约 6 个数量级差距。

**修正后数值**: 若修正 F1 公式为 m_eff = -ℏ·Re(λ)/c²，λ=-1e15 → m_eff = 1.17e-36 kg（巧合地与文件声称值一致，但公式不同）。仍比电子轻 6 个数量级。

1.17e-36 kg ≈ 0.66 eV/c²，落在中微子质量量级。在量子比特系统中，这是否对应可观测的能量尺度？fluxonium 典型能级间距 ~GHz ≈ 4 μeV，远小于 0.66 eV。所以"等效质量"对应的能量尺度与超导量子比特的能量尺度不匹配。**需解释 m_eff 与系统能标的对应关系。**

### fluxonium 预言 (γ~0.5)

```
φ_total = 0.9π → m_eff/m₀ ≈ 1/(1-0.5·cos(0.9π)) ≈ 0.68
```

32% 的质量移动在实验上可观测（频移 ~32% 远超典型 Rabi 频率分辨率 ~0.1%），**但效应是减小而非增大**，且不展示声称的"发散"行为。γ=0.5 时公式 1/(1+γ·cos(φ)) 的最大变化范围是 [1/(1+0.5), 1/(1-0.5)] = [0.67, 2.0]，即质量最多翻倍，不会发散。

**Q4 结论**: 32% 频移可观测（实验灵敏度通过），但(a)效应是减小非发散，(b)m_eff 的绝对尺度与量子比特能标存在 5-6 个数量级鸿沟需解释。

## Q5. 代数验算

### F1 数值验算

**文件公式** m_eff = -ℏ/(c²·Re(λ)):
```
ℏ = 1.054571817×10⁻³⁴ J·s
c² = 8.987551787×10¹⁶ m²/s²
Re(λ) = -1×10¹⁵ s⁻¹

分母 = 8.9876×10¹⁶ × (-1×10¹⁵) = -8.9876×10³¹ m²/s³
m_eff = -1.0546×10⁻³⁴ / (-8.9876×10³¹) = 1.173×10⁻⁶⁶ kg
```

**文件声称 1.17×10⁻³⁶ kg → 差 30 个数量级！阻断级数值错误。**

**修正公式** m_eff = -ℏ·Re(λ)/c²:
```
分子 = -1.0546×10⁻³⁴ × (-1×10¹⁵) = 1.0546×10⁻¹⁹ kg·m²·s⁻²
分母 = 8.9876×10¹⁶ m²/s²
m_eff = 1.0546×10⁻¹⁹ / 8.9876×10¹⁶ = 1.173×10⁻³⁶ kg
```

修正公式给出文件声称的数值 **1.17×10⁻³⁶ kg**。确认: **公式写错了（λ 在分母而非分子），但数值是按正确公式算的。写入的公式与计算使用的公式不一致。**

### F3 数值验算

```
输入: p₁=1.0, n=1
右侧: π × 1.0 = π ≈ 3.1416 rad/s
```

声称输出 "∫ln|S| dω = π"。**通过。**（对于单 RHP 极点 s=1 的一阶系统，确实 ∫₀^∞ ln|1/(1+1/(s-1))| dω = π。）

### F4: S+T=1 代数恒等式

```
S(s) = 1/(1+L(s))
T(s) = L(s)/(1+L(s))  [或 T(s) = 1 - S(s)]
S+T = (1+L)/(1+L) = 1 ✓
```

在量子语境中的对应: S 为"信息自由流动比例"，T 为"信息被锁比例"。但这一映射的前提是 S 和 T 可以解释为概率/比例——这要求 |S|² + |T|² = 1（量子概率守恒），而非 S+T=1（经典信号守恒）。**经典信号守恒 S+T=1 ≠ 量子概率守恒 |S|²+|T|²=1。** 这个映射需要额外论证。

### F6: I_{C1}(e^γ) / I_{C2}(e^γ)

如 Q1 所述，e^γ 量纲错误。即使在修正量纲后，Jones 多项式的变量 t 与退极化率 γ 之间的函数形式（t = e^{-γ τ₀}）需要从 Khovanov 同调的谱序列中推导，而非假定。

**Q5 结论**: F1 公式与数值矛盾（公式写反但数值正确），需修正公式形式。F6 指数量纲错误。F4 的 S+T=1 ↔ 量子信息守恒映射存在经典-量子错配。

### 6.4 替代解释

B 博士的核心主张："反馈控制 → 有效惯性 → 质量"。更简单的替代解释:

1. **经典控制论的平凡对应**: 闭环极点决定响应速度是控制论的本科内容。将"响应慢"重新命名为"质量大"只是一次术语重贴标签（relabeling），没有新增物理内容。任何带负反馈的动力系统（恒温器、巡航控制、PID 控制器）都表现出"有效惯性"——这不需要量子信息。

2. **有效质量 vs 引力质量**: 凝聚态物理中早已有"有效质量"概念（能带论中的 m* = ℏ²/(∂²E/∂k²)），它是色散关系的曲率，与反馈控制无关。B 博士需要解释他的 m_eff 与能带有效质量的区别，以及为何前者的机制（反馈环）应被视为质量起源。

3. **扭结-噪声对应**: C3 声称"因果扭结不变量决定保真度衰减率之比"。更简单的解释: 不同线路分解有不同的门数和电路深度，噪声敏感度自然不同——这是一个门计数问题，而非拓扑不变量问题。除非能证明比值对具有相同门数但不同拓扑的线路也成立，否则拓扑解释是多余的。
