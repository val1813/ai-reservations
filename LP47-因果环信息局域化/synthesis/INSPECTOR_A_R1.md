## Q2. 符号/方向校对

### 2a. "QCMI修正项 c·ε·log(1/ε)" — ε→0 符号验证

- 文本声张 (findings 第7行): `QCMI(θ,ε) ≈ QCMI_pure(θ) - c·ε·log(1/ε)`
- F1 具体形式: `QCMI[θ,ε] = θ²ln(1/θ)(1 - ε/θ² + O(ε))`
- F1 展开: `θ²ln(1/θ) - ε·ln(1/θ)` — 修正项为 `-ε·ln(1/θ)` 而非 `-c·ε·log(1/ε)`

**❌ 内部不一致**: 文本声称修正项为 `-c·ε·log(1/ε)`，但F1实际给出 `-ε·ln(1/θ)`。二者函数形式不同:
- `ln(1/θ)` 仅依赖θ
- `ln(1/ε)` 仅依赖ε
- 调和需 `c = ln(1/θ)/ln(1/ε)`，但c被声明为"取决于环境谱"（常数，与θ无关）— 自相矛盾。

数值验证 (θ=0.05):
| ε | F1修正: -ε·ln(1/θ) | 文本修正(c=1): -ε·ln(1/ε) | 比值 |
|---|---------------------|--------------------------|------|
| 0.0001 | -3.00×10⁻⁴ | -9.21×10⁻⁴ | 3.07× |
| 0.001 | -3.00×10⁻³ | -6.91×10⁻³ | 2.31× |
| 0.01 | -3.00×10⁻² | -4.61×10⁻² | 1.54× |

## Q5. 代数验算

### 5a. 逐步展开

**F1展开** (已验证):
```
QCMI[θ,ε] = θ²ln(1/θ)(1 - ε/θ² + O(ε))
           = θ²ln(1/θ) - ε·ln(1/θ) + O(εθ²ln(1/θ))
```
展开正确 ✅。但微扰参数组织有问题：ε/θ²作为展开参数要求ε ≪ θ²，这在物理上是很强的约束。

**F5代数恒等式** (已验证):
```
I_ring = Σ_j I(j:j+1|rest) = n × θ²ln(1/θ)/n + ...
       = θ²ln(1/θ) + ...
```
n/n抵消 → 恒等于θ²ln(1/θ)。**这是一个代数恒等式而非物理结果**: n × (X/n) = X 平凡成立。F5的物理内容为零（除非"..."中的项是非平凡的）。写成 `n·θ²·ln(1/θ)/n` 是**记号冗余**。

**F8迹守恒** (SymPy验证):
```
Tr(ρ_S) = (1-θ²) + θ²(cos²φ + sin²φ) = (1-θ²) + θ² = 1 ✅
```
迹守恒严格成立，不依赖于θ≪1的微扰假设。

### 5b. 极限退化 (SymPy符号验证)

| 极限 | 公式 | 预期 | 实际 | 判定 |
|------|------|------|------|------|
| θ→0 | θ²ln(1/θ) | 0 | 0 ✅ | 通过 |
| ε→0 | F1 | θ²ln(1/θ) | θ²ln(1/θ) ✅ | 通过 |
| n→∞ (固定k) | F3 | 0 | k×θ²ln(1/θ)/n→0 ✅ | 通过 |
| θ→0 | ξ=1/θ | ∞ | ∞ ✅ | 通过 |
| φ=0 | F6 | G_∥ | G_∥ ✅ | 通过 |
| φ=π/2 | F6 | G_⊥ | G_⊥ ✅ | 通过 |
| n→∞ (对跖k=n/2) | F3 | **声称0** | **θ²ln(1/θ)/2 ≠ 0** | ⚠️ 声张错误 |

**关键退化检查 — n→∞ 对跖点**: 
C2文本和F3极限均声称"n→∞: QCMI→0"。但对跖点k=⌊n/2⌋时，f(n,⌊n/2⌋) → 1/2，QCMI → θ²ln(1/θ)/2 ≠ 0。**声张与自身公式矛盾**。

**Q5判定**: 发现1个阻断级错误（n→∞对跖点退化失败）+ 1个警告级记号问题（F5代数恒等式）+ F1微扰展开在ε>θ²时失效（已在Q2标记）。

### 6.4 替代解释

是否存在更简单的替代解释？

1. **QCMI标度θ²ln(1/θ)**: 此标度形式可理解为二阶微扰展开的必然结果:
   - 任何在θ=0解析的f(θ)若f(0)=0且f'(0)=0（Clifford点QCMI=0为一阶稳定点），则f(θ)~½f''(0)θ²
   - θ²ln(1/θ)中的对数因子来自于Clifford点附近态密度的van Hove奇点
   - → 标度形式可能是**一般的二阶展开+态密度效应**，不必然蕴含因果环的特殊物理

2. **1/n稀释因子**: 可等价表述为"QCMI在平移对称环上均匀分布"
   - f(n,k)=min(k,n-k)/n 等价于图论中环上最短路径归一化距离
   - → 不需要因果环的量子信息"锁定"机制来解释

3. **κ_GHZ=0**: 已知GHZ态在相位旋转下是Clifford → Cartan生成元产生的是平凡的相位 → QCMI=0
   - 这可能仅反映GHZ态的对称性，而非因果环的特殊结构
   - → 需要验证非GHZ的非Clifford态（如W态）的行为

**替代解释严重性**: 中等。θ²ln(1/θ)标度不需要因果环框架即可导出一阶近似，QCMI稀释可能有更简单的图论解释。
