## 第二步：墙分类

- **Type C（工具缺）**: 需要外部工具/实验/数学方法目前不具备

## 第三步：墙的精确表述

### W1: A/B对跖QCMI符号矛盾 [Type A]

**精确位置**:
- A博士 `round3.json` C2 numerical_test: n=5 cluster H-mix k=2: α = **-0.1582** → ΔQCMI(θ=0.10) = -0.1582 × 0.01 × ln(10) = **-0.00364 bits** (负值)
- B博士 `round3.json` F3 numerical_test: n=5 k=2 (antipodal): QCMI_anti = **+0.029 ± 0.005 bits** (正值)

**为何这是墙**:
A和B描述的是同一物理场景——n=5 cluster环，对跖分划(k=2)，非Clifford微扰，测量QCMI偏离。A的精确对角化预测负值，B的CS编织框架预测正值。这不是"近似汇合后的小分歧"——这是符号级别的直接矛盾。

**伪造的汇合**: PI_R3声称"A和B独立预言...n≥5环上QCMI标度与n近似无关"，但未检查具体分划的符号一致性。A和B"汇合"的是他们都发现了θ²ln(1/θ)函数形式——但这形式在A的某些分划上系数为负，在B的对应分划上为正。函数形式的相似性是表面的；系数符号的矛盾是实质的。

**不可绕过的理由**: 量子线路实验测量QCMI会给出确定符号。如果μ*符号实验上为正，A博士框架被排除（至少对于对跖分划）。如果为负，B博士CS映射在该分划上被排除。不可能通过参数调整同时修复两边。

### W2: A博士公式-数值内部不自洽 [Type A]

**精确位置**:
- A博士 C5 F3R3公式: `ΔQCMI = 0.244 × θ² × ln(1/θ) - 0.004 × θ²`
- 代入θ=0.10: 0.244 × 0.01 × 2.3026 - 0.00004 = **0.00558 bits**
- 同一C5 numerical_test报告: `delta_qcmi_at_010 = 0.02407 bits`
- **差值因子: 4.31**

**为何这是墙**:
公式和数值结果出自同一个claim C5，声称R²=0.9999的"验证"。如果公式是对数值结果的拟合，则公式系数0.244不可能通过最小二乘产生24×10⁻³的拟合值——公式与数据之间的残差超过了公式预测值本身的4倍。如果数值结果是对公式的验证，则24×10⁻³不可能是0.244×θ²×ln(1/θ)在θ=0.10处的求值。

可能的具体原因（不做推导，仅枚举逻辑可能性）:
1. 公式中"θ"的参数化与numerical_test中的θ不一致（如公式θ=实际混合角/π）
2. 公式书写错误——实际拟合得到的α不是0.244而是~1.05
3. numerical_test字段报告了不同物理量（如ΔQCMI含基线 vs 纯偏离）
4. 数值计算使用了不同对数底

**无论原因为何，当前状态是自相矛盾的——无法从给定公式和参数重现报告的数值。**

### W3: n-依赖性结构矛盾 [Type A]

**精确位置**:
- A博士 C5声明: "α≈0.244, 标度n-不变" (independent of n for n≥5)。n=5,6,7 k=1时α≈0.244确认。
- B博士 F3: QCMI_anti ∝ f(n,k) = min(k,n-k)/n → 随n系统变化。对n=5(k=2): f=0.4, n=6(k=3): f=0.5, n=7(k=3): f=0.429。

**逻辑矛盾的具体形式**:
- A说: ΔQCMI(n≥5, k=1) = 0.244 × θ²ln(1/θ)，与n无关
- B说: ΔQCMI(n, k=1) ∝ f(n,k)=1/n → n=5时f=0.2, n=6时f=0.167, n=7时f=0.143——明显n依赖

A和B不能同时对。如果A对，B的连接数→稀释因子映射在相邻分划上被排除。如果B对，A的"n不变"发现是数值假象（可能在k=1时因基线I₀=1主导而掩盖了稀释效应）。

**为何双方均声称与对方汇合**: PI_R3和A/B都聚焦于k=对跖点的行为（f≈1/2, n依赖性弱），忽略了k=1（相邻分划）上的结构性分歧——1/n vs 常数——是质的而非量的差异。

## 第四步：破墙策略（仅Type A）

### W1破墙策略: A/B符号矛盾

**策略1: 盲法交叉验证——强制独立计算同一基准问题**

指定一个精确场景，A和B分别提交数值而不看对方结果:
- 系统: n=5 cluster环
- 微扰: H-mix, θ=0.10
- 分划: A={0}, C={2}, B={1,3,4}（对跖）
- 输出: QCMI(θ=0), QCMI(θ=0.10), ΔQCMI = QCMI(0.10) - QCMI(0)（带符号）
- 计算方法: A用精确对角化，B用CS映射

PI在收到双方结果前裁定: 若符号一致 → 寻找W1的其他原因（如我误读了符号约定）。若符号相反 → W1确认为真墙，至少一个框架错误。

**策略2: 符号约定逐层追踪**

A博士的α和B博士的QCMI_anti可能使用不同的基线扣除约定:
- A的ΔQCMI = QCMI(θ) - QCMI(0)。如果QCMI(0)cluster对跖=0（图态性质），则α的符号直接对应QCMI(θ)的符号。
- B的QCMI_anti报告的可能是QCMI(θ)的绝对值而非ΔQCMI。
- 要求A明确报告QCMI(θ=0.10)的原始值（不减去基线），要求B同样。比较原始值。

**策略3: 第三方独立验证——量子模拟器**

使用qiskit Aer的statevector_simulator或equivalent，对n=5 cluster环+H-mix θ=0.10直接计算:
- 构造|ψ⟩ = cos(πθ/2)|C₅⟩ + sin(πθ/2)H₀|C₅⟩
- 计算ρ₀ = Tr_{1,2,3,4}|ψ⟩⟨ψ|, ρ₂ = Tr_{0,1,3,4}|ψ⟩⟨ψ|, ρ₀₂ = Tr_{1,3,4}|ψ⟩⟨ψ|
- 计算S(ρ₀), S(ρ₂), S(ρ₀₂) → QCMI(0:2|1,3,4) = S(ρ₀) + S(ρ₂) - S(ρ₀₂) - S(ρ₀₁₂₃₄)
- S(ρ₀₁₂₃₄) = 0（纯态）→ QCMI = S(ρ₀)+S(ρ₂)-S(ρ₀₂)

此计算不依赖A或B的任何框架假设，给出独立仲裁值。

**策略4: 如果符号矛盾被证实——裁决性分析**

如果第三方验证确认A和B的符号确实相反:
- 追踪A的符号来源: 从原始熵值S(ρ₀), S(ρ₂), S(ρ₀₂)的数值，逐项验证减法结果
- 追踪B的符号来源: 从Kauffman括号⟨L_AC⟩的模到-log|⟨L_AC⟩|，验证Jones多项式代入后的符号
- 确定哪一方的符号链中存在显式错误（如丢失绝对值、对数符号约定不一致等）

### W2破墙策略: A博士公式-数值不自洽

**策略1: 强制公式-数值一致性审计**

要求A博士对C5执行以下审计并提交原始数据:
- 列出θ∈[0.005, 0.20]扫描中每一个θ点的原始熵值: S(ρ₀), S(ρ₁), S(ρ₀₁)
- 列出每一步减法得到的原始QCMI值
- 列出每一步的ΔQCMI = QCMI(θ) - QCMI(0)
- 标注最小二乘拟合使用的自变量(θ²ln(1/θ))和因变量(ΔQCMI)
- 报告拟合输出的α和β（含标准误差），以及拟合曲线上θ=0.10处的预测值
- 对照numerical_test中delta_qcmi_at_010=0.02407的来源

如果审计不能重现报告值，则C5的numerical_test不可信——所有基于此的声张（α=0.244, R²=0.9999, 标度确认）悬空。

**策略2: θ参数化一致性检查**

A博士的H-mix定义为: |ψ⟩ = cos(πθ/2)|C⟩ + sin(πθ/2)H₀|C⟩

可能的问题:
- 公式中的"θ"是原始参数（cos/sin的参数），numerical_test中的"θ"是实际混合角a=sin(πθ/2)
- 在小θ下a≈πθ/2≈1.571θ，a²≈2.467θ² → 如果公式中的θ实际是a，则α_effective = 0.244 × 2.467 = 0.602
- 重新计算: 0.602 × 0.01 × 2.303 = 0.01386。仍然不是0.02407。
- 若公式中的θ进一步被定义为sin(πθ/2)本身而非≈πθ/2: θ=0.10 → 实际a=sin(π×0.10/2)=sin(0.1571)=0.1564。a²=0.02447。0.244×0.02447×ln(1/0.1564)=0.244×0.02447×1.855=0.01107。仍不是0.02407。

结论: θ参数化的差异不能解释4.31倍差距。问题更深层。

**策略3: 公式形式检验**

可能numerical_test的0.02407是拟合到了不同的函数形式:
- 如果实际拟合是ΔQCMI = α × θ²（无ln因子）: α = 0.02407/0.01 = 2.407 → R²会劣于含ln的形式
- 如果实际拟合是ΔQCMI = α × θ² × ln(1/θ) + γ × θ（含一阶项）: 需要重新拟合
- 可能性: numerical_test的0.02407可能是QCMI原始值（含基线I₀=0），而非ΔQCMI偏离

要求A博士在回应中明确: delta_qcmi_at_010是ΔQCMI还是QCMI原始值。

### W3破墙策略: n-依赖性结构矛盾

**策略1: 强制双方对同一{n,k}扫描提交预测**

指定扫描范围，A和B独立提交:
- n ∈ {5, 6, 7}（当前A有数值的范围）
- k ∈ {1, 2, 3}（覆盖相邻、中间、对跖）
- θ ∈ {0.05, 0.10, 0.15}
- 态: cluster环 + H-mix微扰（A）或R_x(θ)微扰（B）

比较矩阵: 对每个(n,k,θ)三元组，计算|ΔQCMI_A - ΔQCMI_B|/|ΔQCMI_A + ΔQCMI_B|。如果比值超过0.5（系统差异大于统计涨落），该点标记为矛盾点。统计矛盾点占总网格的比例。如果>30% → 汇合为假。

**策略2: 聚焦k=1（相邻分划）的n标度**

k=1是A和B分歧最剧烈的分划:
- A: ΔQCMI(n,k=1) = 0.244 × θ²ln(1/θ) — n不变
- B: ΔQCMI(n,k=1) ∝ f=1/n → n=5时0.2, n=6时0.167, n=7时0.143

如果A的精确对角化已覆盖n=5,6,7 k=1: 直接从A的报告数据中提取ΔQCMI(n, θ=0.10, k=1)并检查是否真的n不变。如果ΔQCMI(5)≈ΔQCMI(6)≈ΔQCMI(7) → B的1/n稀释因子在相邻分划上被排除。如果ΔQCMI随n递减 → A的"n不变"是k=1处的假象（可能因为基线I₀=1主导，A实际上拟合的是基线而非偏离）。

注意: A的C2 numerical_test在k=1时n=5,6,7全部给出α≈0.244 — 这似乎支持A。但需要检查: A的QCMI(θ=0)的cluster k=1基线是否为1 bit。如果是，则ΔQCMI=0.0056 bits叠加在1 bit基线上——测量1.0056 vs 1.0000的差异在10^5 shots下勉强可达。B的1/n稀释因子会给出n=5:0.2×..., n=6:0.167×..., n=7:0.143×...——差异在ΔQCMI的30%量级。A的数据精度(α_error=0.0001对应ΔQCMI误差~0.000002 bits)是否真的达到了区分30%ΔQCMI差异所需的精度？

**策略3: 区分"n不变"的两种含义**

A说的"n不变"= α(θ²ln(1/θ)系数)不随n变化
B说的"n依赖"= QCMI总绝对值随n变化（因为f因子作用在整体上）

可能两者在讨论不同层级的量:
- 如果B的QCMI = I₀ + α_B(n) × θ²ln(1/θ)，其中α_B(n) ∝ f(n,k)
- 而A的QCMI = I₀ + α_A × θ²ln(1/θ)，其中α_A不依赖n

则需要在同一公式框架下比较: 将A的数值代入B的公式形式（含f因子），检查拟合优度是否显著劣于A的n不变形式。这需要一个统计模型选择检验（如AIC比较）——可以被客观执行而不依赖任何一方的框架偏好。

### W4破墙策略: B博士校准基础废弃

**策略1: 拆除C_phys=3.68——重新校准到独立数据**

B博士R3 F3 assumption A5已承认此问题: "R3修正：若A博士R3提供n=5的精确对角化结果，使用n=5数据重新校准以消除对R2 α估计的依赖。"

执行:
- 取A博士R3 n=5 cluster对跖k=2的原始QCMI(θ)数据（精确对角化结果）
- B博士用A的数据重新拟合C_phys
- 比较新C_phys与3.68的差异
- 如果差异超过20% → B的现有全部数值预言(F3)需重新计算
- 如果差异超过50% → B的CS映射中连接数系数12π²可能也存在问题

**策略2: 从第一原理计算C_phys——消除经验校准**

不通过校准任何数据来确定C_phys，而是:
- 从Kontsevich积分的弦图权重系统显式计算连接数阶的系数
