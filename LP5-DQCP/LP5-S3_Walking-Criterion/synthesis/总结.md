## 北极星

推导BKT伪连续行为（walking / Nordic walking / 复固定点湮灭）的充分条件分类学，给出可被数值/实验独立检验的判据。

## 结论类型：有边界

**边界性质：** 完整分类学已建立，但walking类型的具体实现取决于β函数系数{c_{4k+1}}的动力学（需要FRG/格点MCRG计算，超出纯理论推导范围）。

## 核心结论

### 1. Walking行为由Thom奇点理论统一分类

A博士（RG/复CFT）和B博士（动力系统分岔理论）独立收敛到同一个数学结构：**β函数的退化奇点按Thom-Arnold的A_μ系列分类。**

- **A_k类（不动点退化）：** β(g*) = β'(g*) = ... = β^{(k-1)}(g*) = 0, β^{(k)}(g*) ≠ 0。物理机制：复固定点对湮灭后的"幽灵"效应。k=1→GRZ walking。
- **B_k类（极值退化）：** β(g†) ≠ 0, β'(g†) = ... = β^{(k)}(g†) = 0。物理机制：β函数的"结构性平坦"。k=2→Nordic walking (Hawashin 2025)。
- **新型预测：** D类（闪烁walking，双稳态+噪声驱动Kramers逃逸）、L类（对数周期walking，复零点螺旋趋近实轴）、G类（全局平坦walking）。

### 2. DQCP中walking的充分条件（精确系数判据）

**Type I (GRZ):** 在β(g) = g·B(g⁴)框架下，三参数截断B(u) = c₁ + c₅u + c₉u²：
- 条件：0 < c₁ - c₅²/(4c₉) ≪ min(|c₁|,|c₅|,|c₉|), c₉ > 0, c₅ < 0
- 尺度分离：Λ_UV/Λ_IR ~ exp(π/(4u_*√(c₉ε)))
- 余维数：1

**Type II (Nordic):** 需要c₁₃ ≠ 0：
- N1: B(u_*) + 4u_*B'(u_*) ≈ 0
- N2: 5B'(u_*) + 4u_*B''(u_*) ≈ 0（INSPECTOR修正后）
- 余维数：2
- 尺度分离：exp(Δg/β₀)（线性，非BKT指数型）

### 3. 6项可检验判据

| 判据 | 方法 | 区分能力 |
|------|------|---------|
| C1: ν_eff漂移 | 有限尺寸标度中ν_eff(L)的漂移方向和速度 | walking vs真连续 |
| C2: ξ_max饱和 | 外推L→∞时的关联长度上限 | 确认walking存在 |
| C3: T(ε)标度指数 | 测量T ∝ ε^{-α}中的α | 唯一确定walking类型(A₁/A₂/B₂/...) |
| C4: β(g)重构 | 从格点数据直接重构β函数形状 | 区分GRZ vs Nordic vs 全局平坦 |
| C5: 涨落放大 | Var[g]在walking区间的异常增大 | 独立于复CFT框架的walking信号 |
| C6: 复零点距离 | δ = min\|Im(g*)\| 解析延拓 | A类walking的解析诊断 |

## 对LP-5长命题的贡献

S3'的完成闭合了LP-5的最后一个子命题。核心贡献：

1. **理论层：** 为S4的{Q,C}=0 → β(g)动力学提供了分类学框架——walking不是一种而是多种机制，对应β函数的不同退化类型。
2. **方法论层：** 提供了区分walking子类型的6项判据，可直接用于实验DQCP候选材料（如SrCu₂(BO₃)₂）和数值模拟（J-Q模型QMC）的walking行为诊断。
3. **预测层：** 预测了三种新型walking（Type D/L/G），为后续研究提供了方向。

## 与S4/S2R/S3R的协同

- **S4 ({Q,C}=0):** 提供"舞台"（β函数的代数结构约束）。S3'回答"在舞台上可以上演什么戏"（walking类型分类）。
- **S2R (SO5诊断):** SO5 δ_SO5饱和行为可以用来区分A类还是B类walking——如果δ_SO5随L饱和（暗示L > ξ_walk），则支持A类（固定点湮灭）。
- **S3R (NMR诊断):** dη/dP的测量如果支持η_eff随压力系统变化，可以用C3（标度指数法）确定walking的具体类型。

## 已知局限

1. β''(g)的一个代数错误已被INSPECTOR发现并修正（不影响分类学框架）
2. 三参数截断的可靠性依赖于高阶系数被自然性压低的假设（未被验证）
3. Nordic walking在DQCP中的"自然性"（是否需要微调）依赖于系数{c_{4k+1}}的RG流——需要FRG计算
4. Type D/L/G的物理实现条件在DQCP中尚未被量化
