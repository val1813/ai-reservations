# 知识库 — LP5-S3' Walking条件判据

## 继承知识（来自LP-5已完成的子命题）

### K4.1 (S4) ⚠️L1: {Q,C}=0 → β(g) = Σ_{k=1}^∞ c_{4k+1} g^{4k+1}
所有偶次项消失，所有系数为实数。该β函数在实轴上可以有零点（实不动点），也可以没有零点（walking情形），取决于系数{c_{4k+1}}的具体值。对称性不强制任何一边。

### K4.2 (S4) ⚠️L1: SU(2) J-Q的弱一阶性来自β函数动力学
β(g)在实轴上无零点 → walking/伪临界行为。这不是对称性强制的，而是模型特定的动力学事实。SU(N≥8)可能有实不动点（真连续DQCP）。

### K1.1 (S1) ⚠️L1: EE诊断需要L ≥ ξ/3
纠缠熵对数修正系数b的区分能力受系统尺寸严格限制。对ξ ~ 10²-10³的DQCP，需要L ~ 150-500——当前QMC能力边界。

### K2'.1 (S2') ⚠️L1: Takahashi (L=1024) ~4σ确认SU(2)弱一阶
ν_t ≈ 0.63 vs SO(5) CFT ν ≤ 0.452。关联长度ξ ∈ (448, 1024)。

### K2R.1 (S2R) ⚠️L1: SO(5)涌现对称性δ_SO5诊断
连续DQCP：δ_SO5(L) ∝ L^{-0.884} → 0。弱一阶：δ_SO5(L)饱和到δ_0 > 0。L_min ≈ 80-150（优于EE的L_min ≈ 100-333）。

### K3R.1 (S3R) ⚠️L1: NMR 1/T₁诊断受限于Δ ≪ T_min
弱一阶的能隙Δ ~ 0.01-50 mK，实验最低温度T_min ~ 30-70 mK → 无法直接观测激活行为。dη/dP方案概念可行但需3-10倍精度提升。

## 本课题新增知识

### K_S3'.1 ⚠️L1 (2026-06-02): Walking统一分类学
Walking行为分为A_k（不动点退化，β≈0）和B_k（极值退化，β≈const≠0）两大互补类。统一于Thom奇点理论的A_μ系列。A类来自复固定点湮灭后的"幽灵"效应，B类来自β函数结构性平坦。新型walking类型预测：D类（闪烁walking，双稳态+噪声驱动）、L类（对数周期walking，复零点螺旋趋近实轴）、G类（全局平坦walking，非局部机制）。
[math_object: Thom catastrophe A_μ series; β(g) degeneracy classification]

### K_S3'.2 ⚠️L1 (2026-06-02): Type I (GRZ) walking充分条件
DQCP的β(g) = g·B(g⁴)下：B(u)在u_* > 0处局部极小值ε ≪ 1。系数条件：0 < c₁ - c₅²/(4c₉) ≪ min(|c₁|,|c₅|,|c₉|), c₉ > 0, c₅ < 0。尺度分离Λ_UV/Λ_IR ~ exp(π/(4u_*√(c₉ε)))。BKT型本质奇点。
[math_object: exp(π/(4u_*√(c₉ε))); saddle-node ghost]

### K_S3'.3 ⚠️L1 (2026-06-02): Type II (Nordic) walking充分条件
β'(g_†) ≈ 0 且 β''(g_†) ≈ 0同时成立，但β(g_†) ≠ 0。要求c₁₃ ≠ 0（四次截断）。余维数2——比GRZ更严格。尺度分离为线性exp(Δg/β₀)而非BKT指数型。在DQCP中Nordic walking对L=10²-10³范围内的标度行为"伪装"能力弱于GRZ walking。
[math_object: β'(g)=β''(g)=0 with β≠0; codimension-2 degeneracy]

### K_S3'.4 ⚠️L1 (2026-06-02): 标度指数诊断法
测量通过时间T(ε) ∝ ε^{-α}的标度指数α可唯一确定walking类型：α=1/2→A₁(GRZ), α=2/3→A₂/B₂(Nordic), α=3/4→A₃/B₃。区分A_k vs B_k：检查β_min是否可调谐到零（A类可，B类不可）。
[math_object: T(ε) ∝ ε^{-k/(k+1)} scaling law]

### K_S3'.5 ⚠️L1 (2026-06-02): 6项综合可检验判据
C1: ν_eff(L)漂移方向+速度。C2: ξ_max饱和值。C3: T(ε)标度指数。C4: β(g)格点直接重构。C5: 涨落放大因子Var[g]异常。C6: 复零点距离δ = min|Im(g*)|。覆盖数值模拟(QMC/MCRG)和实验观测。
[math_object: 6-fold criterion suite for walking detection]

### K_S3'.6 (2026-06-02): INSPECTOR发现
A博士β''(g)推导有代数错误（系数16→20修正）。正确的β''(g) = 4g³[5B'(u)+4uB''(u)]。不影响分类学框架，但N2条件需修正为5B'(u_*)+4u_*B''(u_*)≈0。
