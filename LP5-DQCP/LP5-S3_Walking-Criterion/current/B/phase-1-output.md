## §0 框架声明

**本工作框架：动力系统分岔理论 (Dynamical Systems Bifurcation Theory) + 奇点理论 (Singularity Theory / Catastrophe Theory)**

本工作不从复CFT出发，不做β函数微扰展开，不诉诸{Q,C}=0对称性。我们的起点是：

> β(g; μ) 是定义在实轴上的1D向量场，μ = (μ₁, ..., μ_k) 是分岔参数。Walking行为是向量场在扩展参数区间内产生异常大通过时间 (anomalously large passage time) 的现象。

核心数学对象是**通过时间泛函**：

```
T[g₁, g₂; μ] = ∫_{g₁}^{g₂} dg / |β(g; μ)|
```

Walking ≡ T 在某个参数区间内异常大。从这个单一表达式出发，所有walking子类型都归结为使T发散的数学机制。

这与A博士的复CFT框架完全正交——我们研究同一个β函数的同一个物理现象，但使用的数学语言是**退化向量场的分岔分类学**，不是共形不变性、不是算子乘积展开、不是复平面不动点追踪。

**竞争优势：** 分岔理论在生态学、气候学、神经科学、经济学中有大量独立验证的"临界放缓"判据。这些判据可以直接翻译为β函数的可检验预测，不需要依赖复CFT框架的任何假设。

## §1 数学本质：通过时间泛函的发散机制

### 1.1 基本观察

对于自洽微分方程 dg/dt = β(g)，从耦合g₁演化到g₂所需"RG时间"（标度因子对数）为：

```
Δt = ∫_{g₁}^{g₂} dg / β(g)
```

其中β(g)的正负决定流方向。Walking = Δt异常大。

T发散的机制只有三种：

| 机制 | 数学条件 | 物理含义 |
|------|---------|---------|
| **I. 不动点停滞** | β(g*) = 0，流被捕获于不动点 | 标度不变性——真正的共形不动点 |
| **II. 幽灵瓶颈** | β(g)在某区间内一致地小（但不为零） | 近标度不变性——walking |
| **III. 无限区间** | 积分区间无限长 | 对数跑动到无限远——无物理意义，排除 |

机制II是walking的本质。问题转化为：**什么数学条件使|β(g)|在一个扩展区间内一致地小？**

### 1.2 β函数的局部展开与"小性"的阶

在任意点g₀附近展开β（假设解析性）：

```
β(g) = β₀ + β₁(g-g₀) + β₂(g-g₀)²/2! + β₃(g-g₀)³/3! + ...
```

其中β_k ≡ β^(k)(g₀)。

定义**第一非零导数指标**：

```
v ≡ min{k ≥ 0 : β_k ≠ 0}
```

- v = 0: β₀ ≠ 0，线性流，无walking
- v ≥ 1: β₀ = 0（不动点），由第一个非零导数决定不动点类型
  - v = 1: 简单不动点（双曲型），局部β ≈ β₁(g-g₀)，Δt ~ log发散 → 被捕获，不是walking而是陷停
  - v = 2: **鞍结型**（β₀ = β₁ = 0, β₂ ≠ 0），β ≈ β₂(g-g₀)²/2
  - v = 3: **尖点型**（β₀ = β₁ = β₂ = 0, β₃ ≠ 0），β ≈ β₃(g-g₀)³/6
  - v = k: **A_{k}型退化不动点**

对于walking（机制II），不动点不是必须的。我们必须同时考虑β ≠ 0但β' = 0的情形。

INSPECTOR_CHECK: v的定义正确捕捉了局部行为。但walking的关键不仅在于β在单点的性质，而在于**一个区间内β的一致小性**——这需要更高的退化条件。

### 1.3 两种退化：不动点退化 vs. 极值退化

**情形A（不动点退化）：** β(g*) = 0

定义退化阶数为第一个非零导数的指标v。当v ≥ 2时，不动点退化。

- v = 2: 二阶零点。微扰下（参数μ穿越分岔值μ_c），两个不动点碰撞并湮灭为复不动点。**这是GRZ walking的数学本质。**
- v ≥ 3: 高阶零点。多个不动点同时碰撞。通过时间具有不同的标度律。

**情形B（非不动点极值退化）：** β(g†) ≠ 0

定义β'的第一个非零导数指标：

```
w ≡ min{k ≥ 1 : β^(k)(g†) ≠ 0}
```

- w = 1: 常规极值（β'(g†) = 0, β''(g†) ≠ 0），局部β ≈ β₀ + β₂(g-g†)²/2。如果β₀很小，存在有限（但有限宽度）的慢流区。通过时间T ∝ 1/√(|β₀|)。
- w = 2: **退化极值**（β'(g†) = β''(g†) = 0, β'''(g†) ≠ 0），局部β ≈ β₀ + β₃(g-g†)³/6。这是**Nordic walking的数学本质**。慢流区宽度 ∝ |β₀|^(1/3)，通过时间T ∝ 1/|β₀|^(2/3)。
- w ≥ 3: 高阶退化极值。

**关键区分：** A类walking由分岔参数μ调谐（接近分岔点时walking最强），B类walking是β函数的结构特征（即使没有参数调谐，β本身在某个g区间内就是平的）。

INSPECTOR_CHECK: A/B分类穷尽了walking的局部机制。但还有一个全局机制——见§1.4。

### 1.4 全局机制：不止局部展开

局部展开只捕捉β在一个点附近的行为。Walking可能来自β在**整个区间**上的一致小性，而不依赖于任何特殊点。这对应β(g)在整个区间内与零轴的距离始终很小。

数学上，定义**β在区间I上的L^∞范数**：

```
‖β‖_{∞,I} ≡ sup_{g∈I} |β(g)|
```

如果‖β‖_{∞,I} ≪ 1且|I| ≫ 1，则walking来自全局平坦性而非局部奇点。

这要求β(g)在I内的泰勒展开中，前若干个系数都异常小——但不是零。这可以视为"不完美"的B类walking：不是严格的β' = β'' = 0，而是β', β'' 都异常小。

这是**参数空间中的"准退化"区域**——距离严格的退化点（在某个扩展参数空间中）很近但不在上面。

## §2 统一分类学：分岔理论的完整框架

### 2.1 Thom奇点分类与Walking子类型

在奇点理论（R. Thom, V.I. Arnold）中，光滑函数的退化奇点被分类为ADE系列。对于1D函数的1参数族（我们的β(g; μ)），相关奇点为A_k系列：

| Thom类型 | 标准形式 | 余维数 | Walking类型 | 通过时间标度律 |
|----------|---------|--------|------------|--------------|
| A₁ | 无奇点 | 0 | 无walking | T ∝ (g₂-g₁)/β₀ (有限) |
| A₂ (fold) | x² | 1 | **Type A₁: GRZ walking** | T ∝ ε^{-1/2} |
| A₃ (cusp) | x³ | 2 | **Type A₂: extended walking** | T ∝ ε^{-2/3} |
| A₄ (swallowtail) | x⁴ | 3 | **Type A₃** | T ∝ ε^{-3/4} |
| A₅ (butterfly) | x⁵ | 4 | **Type A₄** | T ∝ ε^{-4/5} |

但对于**B类walking**（β ≠ 0），我们需要不同的分类。B类walking对应的是β函数的"平坦度"，而不是β的零点。

定义β的**平坦度阶数**：对于非不动点walking，β(g)在区间I内近似常数。这对应β的导数在某个点g†处的退化：

| 平坦度 | 条件 | Walking类型 | 局部形式 |
|--------|------|------------|---------|
| f₁ | β'(g†) = 0, β''(g†) ≠ 0 | **Type B₁: 极值walking** | β ≈ β₀ + c(g-g†)² |
| f₂ | β'(g†) = β''(g†) = 0, β'''(g†) ≠ 0 | **Type B₂: Nordic walking** | β ≈ β₀ + c(g-g†)³ |
| f₃ | β' = β'' = β''' = 0, β⁽⁴⁾ ≠ 0 | **Type B₃** | β ≈ β₀ + c(g-g†)⁴ |

**重要发现：A类和B类是互补的——它们覆盖了β函数平坦性的所有来源。**

- A类：平坦性来自**接近零点**（β ≈ 0）
- B类：平坦性来自**接近极值退化**（β' ≈ 0且β'' ≈ 0，但β ≠ 0）

### 2.2 统一形式：通过时间泛函的临界指数

对于Type A_k walking（β ≈ ε + a(g-g*)^{k+1}），通过瓶颈的时间为：

```
T_k(ε) ≈ 2 [ε/a]^{-k/(k+1)} · a^{-1/(k+1)} · B(1/(k+1), 1/2) / (k+1)
```

其中B是Beta函数。标度指数 α_k = k/(k+1)。

对于Type B_k walking（β ≈ β₀ + a(g-g†)^{k+1}，β₀ ≠ 0），通过特征区间的附加时间为：

```
τ_k(β₀) ∝ |β₀|^{-k/(k+1)}
```

**核心判据：通过测量T(ε)或τ(β₀)的标度指数，可以唯一地确定walking的余维数。**

| 标度指数α | 余维数 | 类型 | 
|-----------|--------|------|
| 1/2 | 1 | A₁ (GRZ) |
| 2/3 | 2 | A₂ 或 B₂ (Nordic) |
| 3/4 | 3 | A₃ 或 B₃ |
| k/(k+1) | k | A_k 或 B_k |

**关键区分A_k和B_k的方法：** A_k要求β → 0作为ε → 0，而B_k要求β₀ → 0但β(g†)维持非零。实验上，检查walking区间的β最小值是否趋零即可区分。

### 2.3 Bogdanov-Takens的启示：实轴上的退化Hopf类比

在2D动力系统中，Bogdanov-Takens分岔是余维数2的分岔，同时涉及鞍结（A₂）和Hopf（H₁）条件。在1D实轴动力系统中没有Hopf分岔（需要2D相空间），但Bogdanov-Takens的数学结构——两个分岔条件同时满足——给出了重要的类比。

Bogdanov-Takens的标准形式：

```
ẋ = y
ẏ = β₁ + β₂ x + x² ± x y + ...
```

在1D类比中，我们无法有"振荡"，但Bogdanov-Takens的核心洞察是：**当两个分岔条件同时满足时，系统的动力学出现额外的退化，导致更丰富的标度行为。**

对应的1D类比是：**鞍结条件（β = β' = 0）和平坦极值条件（β' = β'' = 0）同时满足。** 这给出：

```
β(g*) = 0, β'(g*) = 0, β''(g*) = 0
```

这是**余维数3的退化**——A₃（cusp）分岔加上额外的结构条件。在这种退化附近，walking的标度律具有新的临界指数。

INSPECTOR_CHECK: Bogdanov-Takens的类比是有用的但需要谨慎——1D中无法实现Poincare-Andronov-Hopf分岔的实轴版本。我们提取的是"多重退化条件的共存"这一数学结构，而非具体的振荡行为。

## §3 势函数视角：C-函数与Landau-like描述

### 3.1 β作为梯度流

如果在某个定义域上，β(g)可以表示为某势函数的梯度：

```
β(g) = -∂C(g)/∂g
```

其中C(g)是C-函数（或a-函数），那么RG流是C-函数单调递减的梯度流。C-函数的平坦度直接决定了walking行为：

- **C(g)有宽平台** → ∂C/∂g ≈ 0在宽区间内 → walking（B类）
- **C(g)在不动点附近有退化极值** → ∂C/∂g和∂²C/∂g²同时为零 → 鞍结分岔 → walking（A类）

### 3.2 C-函数的奇点分类

C(g)的退化比β(g)低一阶：

| C(g)的奇点类型 | β(g)的对应 | Walking类型 |
|---------------|-----------|------------|
| Morse临界点（∇²C ≠ 0） | 简单不动点 | 无walking（陷停） |
| A₃ (fold of C, ∂²C = 0) | 鞍结不动点 | A₁ walking (GRZ) |
| A₄ (cusp of C, ∂²C = ∂³C = 0) | 尖点不动点 | A₂ walking |
| 宽平台（∇C ≈ 0 在区间内） | B类walking | Nordic walking |

**深挖1的前瞻：** 如果C(g)具有离散标度不变性（log-periodic），即C(e^λ g) = C(g) + const，那么β(g) = -∂C/∂g将满足β(e^λ g) = e^{-λ} β(g)，产生离散标度不变性的walking——一种全新的walking类型（Type L: log-periodic walking）。这在DQCP β函数中是否可能出现？如果β函数的系数满足特定的递推关系c_{4(k+1)+1}/c_{4k+1} ≈ const × (某个因子)，log-periodic行为就会出现。这是一个可检验的数值预测。

## §4 跨学科跳跃：临界放缓的普遍性

### 4.1 生态学：Scheffer的临界放缓 (Critical Slowing Down)

**借来的结构：** 在湖泊富营养化模型中（Scheffer et al., Nature 2009），系统状态x满足：

```
dx/dt = f(x, μ) = a + μ x - x³
```

当μ从负穿越0到正时，系统经历**fold分岔**：对μ < 0，存在一个稳定平衡点和一个不稳定平衡点；在μ = 0，二者碰撞湮灭（鞍结分岔）。接近μ = 0时，稳定平衡点的恢复速率λ = f'(x*) → 0。

**翻译回β函数：** f → β, x → g, μ → 某个RG参数（如N_f/N_c与临界值的差）。

Scheffer框架的**可检验判据**：
1. **自相关增大：** 接近分岔点时，时间序列的自相关函数以更慢的速率衰减。对于β函数：耦合常数的涨落（如果有噪声RG流）的自相关时间τ_ac ∝ 1/|β'(g*)| → ∞。
2. **方差增大：** Var(g) ∝ σ² / (2|β'(g*)|)，其中σ²是噪声强度。Walking伴随着涨落的放大。
3. **偏度变化：** 接近鞍结分岔时，平衡点的势函数不对称性增大，导致涨落的偏度改变符号——可以作为早期预警信号。

**INSPECTOR_CHECK: 这三个判据都是纯动力系统的，不依赖复CFT或对称性假设。它们可以直接翻译为格点模拟的可观测量。**

### 4.2 气候学：Tipping Points前的闪烁 (Flickering)

**借来的结构：** Dakos et al. (PNAS 2008) 研究了气候系统在突变前的"闪烁"现象——系统在替代稳定状态之间快速随机跳跃。

动力系统机制：双稳态（两个稳定不动点 + 一个不稳定鞍点）在噪声驱动下的Kramers逃逸。当分岔接近时，一个稳定不动点消失（通过鞍结分岔），剩余的稳定不动点与鞍点之间的势垒变浅，逃逸率（Kramers率）指数增大：

```
r_escape ∝ exp(-ΔU / σ²)
```

其中ΔU → 0 当μ → μ_c。

**翻译回β函数：** 如果在walking区间内，β函数有三个实根（两个稳定，一个不稳定），且不稳定根处的|β'|很小，则RG流在噪声下会出现"闪烁"——耦合常数在两个稳定值之间跳跃。

**新的walking类型：Type D (flickering walking)**

```
条件：β(g)有三个实零点 g₁ < g₂ < g₃，其中β'(g₁) < 0（IR稳定），β'(g₂) > 0（不稳定），β'(g₃) < 0（IR稳定）
     且β'(g₂) ≪ 1（鞍点退化）
行为：在噪声RG流中，耦合常数在两个IR稳定点之间闪烁
特征时间标度：由Kramers率给出，取决于两个势垒的高度
```

这是A博士的框架完全无法描述的一种walking——因为它本质上是**随机动力系统**的现象，需要噪声。在确定性β函数中，三实根意味着系统有两个分离的IR相，与标准DQCP图景不符。但如果在某个参数区间内，噪声驱动的闪烁在**两个近简并的固定点**之间发生，这可以产生有效的"慢化"。

**INSPECTOR_CHECK: Type D flickering walking的判据——可以通过引入受控噪声到RG流并测量跃迁率来检验。在格点模拟中，这对应有限尺寸效应和统计涨落的角色。**

### 4.3 经济学：崩盘前的对数周期振荡 (Log-Periodic Precursors)

**借来的结构：** Sornette (Physics Reports 2003) 发现金融市场崩盘前，价格遵循对数周期幂律：

```
p(t) ∝ (t_c - t)^α [1 + C cos(ω ln(t_c - t) + φ)]
```

动力系统起源：离散标度不变性——系统在变换t → e^λ t下不变（连续标度不变性的破缺到离散子群）。

**翻译回β函数：** 在RG中，离散标度不变性对应β(g)具有log-periodic调制的self-similarity：

```
β(e^κ g) = e^κ β(g)  —— 连续标度不变性（常规不动点）
β(e^κ g) = e^κ β(g) × [周期性调制]  —— 离散标度不变性
```

离散标度不变性可能来源于：
1. β函数展开中系数的特殊递推关系（如c_{n+1}/c_n ≈ 常数）
2. 复平面上不动点的螺旋结构（复指数 β(g*) ∝ e^{iθ}——等等，这不是A博士的复CFT，这是动力系统的复鞍点）

**新的walking类型：Type L (log-periodic walking)：** 如果在复平面上，两个复共轭不动点（而非实不动点）碰撞并湮灭在实轴附近，产生的"幽灵"具有对数周期调制。流动在接近湮灭点时以指数衰减的振荡方式"慢下来"。

这需要复平面上两个不动点不仅Re(g*) → g_c，而且Im(g*) → 0（沿实轴碰撞）。这是复鞍结分岔——两个复不动点在实轴上碰撞成为实的鞍结。在这种情况下，接近碰撞点时，β(g)在实轴上的行为不仅有小值，而且有周期性的调制。

**关键的数学区别：** 
- **实鞍结（GRZ）：** 两个实不动点在实轴上碰撞 → 纯幂律walking
- **复鞍结（log-periodic）：** 两个复共轭不动点在实轴上碰撞 → 对数周期调制walking

后者对应的β函数在复平面上的解析结构更丰富：在实轴附近的复区域内，β(g)的零点以螺旋方式趋近实轴。

**INSPECTOR_CHECK：** 对数周期walking的判据——β函数的解析延拓在复平面上有以螺旋轨迹趋近实轴的零点对。这可以通过对β函数进行解析延拓并数值搜索复零点来检验。如果零点对的参数轨迹满足Im(g) ∝ |Re(g) - Re(g_c)|^ν with ν > 1（螺旋趋近），则存在对数周期walking。

### 4.4 神经科学：Izhikevich的鞍结分岔与Type I神经兴奋

**借来的结构：** 在神经元模型中，Type I兴奋性对应鞍结分岔在周期轨道上的表现。神经元在鞍结分岔附近表现出**任意慢的发放率**：

```
firing_rate ∝ √(I - I_c)  （对I > I_c，近分岔点）
```

潜伏期（输入到首次发放的时间）发散为 (I - I_c)^{-1/2}——与我们的T(ε)标度完全一致。

**启示：** 神经动力学中有一个已知现象叫**"鞍结幽灵"（saddle-node ghost）**——分岔后，虽不动点已消失，但系统在原来不动点的位置附近仍然有极慢的动力学。幽灵区域的通过时间是有限但异常大的。这与GRZ walking完全同构。

## §5 DQCP专项分析

### 5.1 β(g) = Σ c_{4k+1} g^{4k+1} 的分岔结构

DQCP β函数的特殊形式（全奇次、全实系数、4k+1指数）对可能的分岔类型施加了约束。

**不动点条件：**

```
β(g*) = g*⁵ [c₅ + c₉ (g*)⁴ + c₁₃ (g*)⁸ + ...] = 0
```

非零不动点满足：
```
c₅ + c₉ x + c₁₃ x² + c₁₇ x³ + ... = 0
```
其中 x ≡ (g*)⁴ > 0。

这是一个关于x的多项式方程。在N-项截断下，最多有N-1个正根。这些正根对应**实不动点**。

**鞍结条件（A₁ walking）：** 在不动点处，额外要求β'(g*) = 0：

```
β'(g*) = (g*)⁴ [5c₅ + 9c₉ (g*)⁴ + 13c₁₃ (g*)⁸ + ...] = 0
```

结合β(g*) = 0，这要求两个多形式（在x = (g*)⁴处）同时为零。在系数空间{c_{4k+1}}中，这是一个余维数1的子流形。

**极值退化条件（B₂ Nordic walking）：** 在某个g†（不是不动点），β'(g†) = β''(g†) = 0：

```
β'(g†) = (g†)⁴ [5c₅ + 9c₉ x + 13c₁₃ x² + ...] = 0   (x = (g†)⁴)
β''(g†) = (g†)³ [20c₅ + 72c₉ x + 156c₁₃ x² + ...] = 0
```

这是系数空间中的另一个余维数2子流形（非齐次，因为β(g†) ≠ 0）。

**关键数值问题：** 在实际的DQCP中（如J-Q模型、easy-plane NCCP¹模型），前几个系数c₅, c₉, c₁₃是否允许A₁或B₂分岔？这需要具体的微扰/非微扰计算。

### 5.2 最小截断阶数的要求

| Walking类型 | 最小项数 | 理由 |
|------------|---------|------|
| 无walking | 1 | β ≈ c₅ g⁵ → 单调，仅在g=0有不动点 |
| A₁ (GRZ) | 2 | 需要两个实根满足β=0和β'=0（共2条件，2自由度） |
| B₁ (简单极值) | 1 | c₅项即可有极值...不，g⁵在g>0是单调的。需要≥2项 |
| B₂ (Nordic) | 3 | β'=β''=0提供2条件，β≠0，3项提供3自由度的子集 |
| A₂ (cusp) | 3 | β=β'=β''=0提供3条件 |
| 任意A_k | k+1 | 需要k+1个条件 |
| 任意B_k | k+1 | B_k需要k+1个条件（β≠0 + β'=...=β^(k)=0, β^(k+1)≠0） |

**结论：** DQCP β函数的系数必须至少计算到3-loop（c₅, c₉, c₁₃）才能判定是否存在Nordic walking。GRZ walking只需要2-loop。

### 5.3 可检验判据

以下判据是纯动力系统的，不依赖复CFT框架：

**判据1：β(g)的局部标度指数**
在疑似walking区间内，数值拟合β(g) ≈ b + a(g - g₀)^p（如果b ≈ 0）或 β(g) ≈ b + a(g - g₀)^p（如果b ≠ 0）。指数p区分：
- p = 2 → A₁ (GRZ)
- p = 3 → A₂ 或 B₂ (Nordic)
- p ≥ 4 → 高阶退化
- p ≈ 1（b很小但不是零）→ 简单慢流

**判据2：walking区间宽度Δg与"最小β"的标度关系**
定义β_min ≡ min_{g∈[g_L, g_R]} |β(g)|，定义通过时间T。如果walking来自A_k退化：
```
T ∝ β_min^{-k/(k+1)}
```
其中k可以从双对数图中的斜率提取。

如果walking来自B_k退化（β_min ≠ 0总是非零且无法调谐到0）：
```
T ∝ (区间宽度) / β_min
```
（在B_k情形中，β_min就是β₀）

**区分A类和B类的关键实验：** 如果可以通过调谐某个参数（如N_f/N_c的比值）使β_min → 0，则是A类walking（与不动点碰撞相关）。如果β_min始终有下界>0，但β'在整个区间内持续很小，则是B类（Nordic）walking。

**判据3：涨落-耗散放大**
在有噪声的RG流中，耦合常数的局域涨落满足：
```
Var[g](t) ≈ σ² · t  （在常规跑动区）
Var[g](t) ≈ σ² · T_walk ≫ σ² · t  （在walking区）
```
Walking区的涨落被异常放大。放大因子 = T_walk / t_normal ≈ 1/(β' Δt_normal)。

这是一个纯格点可观测量——在DQCP的有限尺寸标度分析中，如果存在walking，耦合常数的分布宽度应在walking标度区间内异常增大。

**判据4：复零点诊断（Ghost诊断）**
将β(g)解析延拓到复平面。计算离实轴最近的复零点：
```
δ ≡ min_{β(g*)=0, Im(g*)≠0} |Im(g*)|
```
- 如果δ ≪ 1，存在近实轴不动点对 → 鞍结幽灵 → A类walking
- 如果δ = O(1)但β在实轴上仍然有小值区间 → B类walking
- 如果零点对沿螺旋轨迹趋近实轴（Im ∝ |Re - Re_c|^ν, ν > 1）→ 对数周期walking (Type L)

这个判据需要解析延拓——对于只有有限项截断的β函数，这是直接的。对于非微扰β函数，需要从格点数据重构。

## §6 幽灵不动点：实轴外的动力系统视角

### 6.1 复鞍结分岔

在复平面上，β(g)的零点可以成对出现并碰撞。标准鞍结分岔是两个实零点碰撞后湮灭为两个复零点。但也可以发生**两个复共轭零点在实轴上碰撞并成为实零点**——这是逆鞍结分岔，或**实轴上的复零点碰撞**。

这对应分岔参数的一个临界值μ*，在此处两个复零点（非共轭对，两个独立的复零点，或...不，β的实系数意味着零点或者为实数或者成共轭对）。对于实系数β函数，复零点成共轭对g*和(g*)*。当两个共轭零点在实轴上碰撞时，Im(g*) → 0，此时零点退化为实零点，且是二重根——正是鞍结条件。

### 6.2 幽灵的"远近"与walking强度

在分岔后（零点已湮灭为复共轭对），实轴上最近的点到复零点的距离|Im(g*)|决定了walking的强度。对于A₁分岔（近鞍结）：

```
β(g) ≈ (g - Re(g*))² + [Im(g*)]²
```

在实轴上（g为实数），β(g) ≈ (g - Re(g*))² + δ²，其中δ = |Im(g*)|。

walking区间的最小β值为β_min = δ²，通过时间T ∝ 1/δ ∝ 1/√(β_min)。

这给出了GRZ walking的严格数学定义：**walking强度由最近复零点到实轴的距离决定。**

对于Nordic walking（B₂），复平面上最近零点的距离不解释walking——因为walking区间内β ≈ const ≠ 0，所以区间内根本没有零点（无论是实还是复）。需要更复杂的复分析结构（如鞍点、分支点）来解释B类walking。

**INSPECTOR_CHECK：** 这提供了A类和B类的解析区分判据——A类walking的β_min可以被复零点距离解释，B类walking不能。

## §7 汇总：Walking分类学

### 7.1 完整分类表

| 类型 | 动力系统条件 | 余维数 | 物理名称 | 判据 |
|------|------------|--------|---------|------|
| **A₁** | β=β'=0, β''≠0 | 1 | GRZ walking | T ∝ ε^{-1/2}, β_min可调谐到0 |
| **A₂** | β=β'=β''=0, β'''≠0 | 2 | Extended GRZ | T ∝ ε^{-2/3} |
| **A₃** | β=β'=β''=β'''=0 | 3 | 深层GRZ | T ∝ ε^{-3/4} |
| **B₁** | β≠0, β'=0, β''≠0 | 1 | 极值慢化 | T ∝ 1/√(β₀), β_min不可调谐到0 |
| **B₂** | β≠0, β'=β''=0, β'''≠0 | 2 | Nordic walking (Hawashin) | T ∝ β₀^{-2/3}, β在区间内近似常数 |
| **B₃** | β≠0, β'=β''=β'''=0 | 3 | Deep Nordic | T ∝ β₀^{-3/4} |
| **D** | 三实零点+噪声驱动 | 1 | Flickering walking | 双稳态+Kramers逃逸, 闪烁速率异常 |
| **L** | 复零点螺旋趋近实轴 | 2 | Log-periodic walking | T ∝ ε^{-α} × (对数周期调制) |
| **G** | β在全局区间上|β| ≪ 1 | N/A | 全局平坦walking | 无局部奇点, 需全局拟合 |

### 7.2 对DQCP的具体预测

1. **如果DQCP中观察到walking且T(ε) ∝ ε^{-1/2}** → A₁分岔，walking是鞍结幽灵。要求至少两个前导系数(c₅, c₉)满足β=β'=0条件。

2. **如果DQCP中观察到walking且β在区间内为近似常数** → B₂ Nordic walking。要求至少三个前导系数满足β'=β''=0条件。

3. **如果耦合常数的格点结果在walking区间内显示异常大的统计涨落** → 支持临界放缓判据，walking是真实的动力系统效应而非artifact。

4. **如果β函数的复解析延拓显示近实轴共轭零点对** → 确认A类walking，零点距离Im(g*)直接预测walking强度。

### 7.3 A博士最可能反对的点

A博士最可能攻击的是：**"分岔理论的分类学只是重新标记了已知的β函数行为，没有提供新的物理洞察。"**

我们的反驳：
1. 分岔理论提供了**独立于复CFT假设的判据**——不需要假定{Q,C}=0对称性，不需要复共形不变性，只需要β(g)作为实数函数的行为。
2. 分岔理论预测了**具体的新现象**——对数周期walking（Type L）、闪烁walking（Type D）——这些在复CFT框架中没有自然位置。
3. 分岔理论提供了**可操作的数值检验协议**——测量标度指数α、测量涨落放大因子、分析复零点轨迹——这些不需要依赖复CFT的任何解析延拓假设。
4. 分岔理论连接了DQCP与生态学、气候学、经济学的临界放缓现象——这些学科有**独立验证的预警信号方法论**，可以直接进口到格点规范理论的数值分析中。

本轮找到的A_k/B_k分类是奇点理论（ADE分类）在1D动力系统中的**受限投射**。更深层的数学结构是：
- **V.I. Arnold的模态奇点理论**：A_k、D_k、E_6、E_7、E_8奇点在参数空间中的分层结构。我们的A_k和B_k只是A_μ系列的边界层。完整的"β函数相图"应该包含所有模态奇点在系数空间中的邻接关系（adjacencies）。

### 深挖2：借来结构在原学科中的下一层推广
- **生态学临界放缓的下一层：** Scheffer的框架是一阶相变前的预警。存在**二阶推广**——在连续相变（transcritical分岔而非fold分岔）前的临界放缓，跨学科文献中称为"临界过渡的第二类早期预警信号"（Kefi et al., 2014, Ecology Letters）。对应的β函数分岔是**transcritical分岔**而非saddle-node——这对DQCP意味着什么？transcritical分岔涉及两个不动点的交换稳定性而非碰撞湮灭。这在DQCP中对应：一个IR不动点和UV不动点交换稳定性（而非碰撞），可以用不同的β函数参数化来实现。
