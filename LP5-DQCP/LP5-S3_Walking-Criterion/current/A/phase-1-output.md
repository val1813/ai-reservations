## §1 变量约化：从β(g)到B(u)

### §1.1 基本结构

S4的结论K4.1：{Q,C}=0对称性 → β(g)仅含g^{4k+1}次幂，所有系数为实数。

定义辅助变量：
$$u \equiv g^4 \geq 0 \quad (\text{对于实耦合 } g \in \mathbb{R})$$

则β函数可因式分解为：
$$\boxed{\beta(g) = g \cdot B(u), \quad B(u) = c_1 + c_5 u + c_9 u^2 + c_{13} u^3 + \cdots}$$

其中所有系数c_{4k+1} ∈ ℝ。

### §1.2 不动点结构

实不动点g*满足β(g*) = 0：

1. **平凡不动点**: g* = 0（Gaussian不动点），总是存在。
2. **非平凡不动点**: B(u*) = 0，其中u* = (g*)⁴ > 0。

因此，非平凡实不动点的存在等价于B(u)在正实轴上有零点。

### §1.3 稳定性分析

在非平凡不动点g* ≠ 0处：
$$\beta'(g^*) = \left.\frac{d}{dg}[g B(g^4)]\right|_{g=g^*} = B(u^*) + 4u^* B'(u^*) = 4u^* B'(u^*)$$

因为B(u*) = 0。由于u* > 0（实g*），稳定性由B'(u*)的符号决定：
- B'(u*) > 0 → β'(g*) > 0 → IR稳定（Wilson-Fisher型）
- B'(u*) < 0 → β'(g*) < 0 → UV稳定（红外自由型）

**关键观察**: 在S4的β函数形式下，非平凡实不动点的稳定性完全由B(u)在零点处的斜率决定，而非由β(g)自身的导数符号。这是一大类QFT中不常见的结构——通常β'(g*)的符号决定了不动点的稳定性类型，但此处它约化为一个更简单的判据。

> **INSPECTOR_CHECK §1**: B(u)的定义域为u ≥ 0（因为u = g⁴），零点必须在正半轴上。复固定点对应B(u)的复零点映射回g = u^{1/4}，产生四个g值（若u是复数，其四个四次方根均匀分布在复平面上）。

## §2 最小非平凡截断：B(u) = c₁ + c₅u + c₉u²

### §2.1 为什么三参数是最小非平凡截断

B(u) = c₁ + c₅u: 一个正实根（若-c₁/c₅ > 0）。不存在根的对湮灭——无法描述walking。

B(u) = c₁ + c₅u + c₉u²: 可有两个实根、一个重根、或无实根。**两个实根可以对湮灭并变为复共轭对**——这是walking行为的最简原型。

### §2.2 根的分类

二次方程B(u) = c₉u² + c₅u + c₁ = 0的解：
$$u_\pm = \frac{-c_5 \pm \sqrt{\Delta}}{2c_9}, \quad \Delta \equiv c_5^2 - 4c_1c_9$$

| 参数区 | Δ符号 | 根的性质 | 实不动点 |
|--------|-------|---------|---------|
| Δ > 0 | + | 两个实根 | 若u_± > 0则存在 |
| Δ = 0 | 0 | 重根 | 若-c₅/(2c₉) > 0则存在（合并） |
| Δ < 0 | - | 复共轭对 | 无 |

### §2.3 实不动点存在的完整条件

不仅需要实根（Δ ≥ 0），还需要正根（u_± > 0）。分类如下：

**情况A: 两个正实根 → 两个非平凡实不动点对（±|g*|对称）**
- 条件: Δ > 0, u₋ > 0, u₊ > 0
- 等价于: c₅² > 4c₁c₉, c₁/c₉ > 0, -c₅/c₉ > 0
- 即: c₁, c₉同号; c₅, c₉异号

**情况B: 一个正实根 → 一个非平凡实不动点对**
- 条件: Δ > 0, u₋ < 0 < u₊（一正一负根，负根无物理意义）
- 等价于: c₁/c₉ < 0

**情况C: 无正实根 → 无非平凡实不动点**
- 条件: Δ < 0, 或 Δ ≥ 0但两根均为负
- 即: c₅² < 4c₁c₉（两根为复共轭对）

### §2.4 固定点湮灭的临界曲面

湮灭发生在Δ = 0且合并根为正时：
$$\boxed{c_5^2 = 4c_1c_9, \quad u_* = -\frac{c_5}{2c_9} > 0}$$

在参数空间{c₁, c₅, c₉}中，这是一个二维曲面（一个方程约束），将"有实不动点"区与"无实不动点"区分开。

**在此曲面附近展开**: 定义距离参数
$$\varepsilon \equiv c_1 - \frac{c_5^2}{4c_9}$$

则B(u)可重写为：
$$B(u) = c_9\left(u + \frac{c_5}{2c_9}\right)^2 + \varepsilon = c_9(u - u_*)^2 + \varepsilon$$

其中u_* = -c₅/(2c₉) > 0。

- ε < 0: Δ > 0，两个正实根（若u_* > 0）→ 存在实不动点
- ε = 0: Δ = 0，重根 → 不动点合并（湮灭点）
- ε > 0: Δ < 0，复共轭对 → 无实不动点，walking可能

> **INSPECTOR_CHECK §2**: u_* > 0要求c₅与c₉异号。若c₅与c₉同号，则合并点在负半轴（无物理意义），相应的"复固定点"的g值可以全是复数。对于DQCP，我们关心的是u_* > 0的情况，因为这对应物理耦合区间内的walking。

## §3 Walking的充分条件（Type I: GRZ标准walking）

### §3.1 近湮灭区的β函数结构

当ε > 0（即刚越过湮灭曲面，无实不动点）且ε ≪ 1时：
$$B(u) = c_9(u - u_*)^2 + \varepsilon, \quad c_9 > 0, \quad \varepsilon \ll 1$$

对应的β函数：
$$\beta(g) = g\left[c_9(g^4 - u_*)^2 + \varepsilon\right]$$

在g_walk ≡ u_*^{1/4}附近（即g⁴ ≈ u_*），β(g)达到其局部最小值：
$$\beta_{\min} \approx g_{\text{walk}} \cdot \varepsilon = u_*^{1/4} \varepsilon$$

### §3.2 Walking尺度分离

RG流方程：d(ln μ) = dg/β(g)。从UV标度Λ_UV到IR标度Λ_IR的RG"时间"为：
$$\ln\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} = \int_{g_{\text{IR}}}^{g_{\text{UV}}} \frac{dg}{\beta(g)}$$

换元到u = g⁴：dg = du/(4g³) = du/(4u^{3/4})，β = u^{1/4}B(u)，所以：
$$\frac{dg}{\beta(g)} = \frac{du}{4u^{3/4} \cdot u^{1/4} B(u)} = \frac{du}{4u B(u)}$$

因此：
$$\boxed{\ln\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} = \int_{u_{\text{IR}}}^{u_{\text{UV}}} \frac{du}{4u B(u)}}$$

在u ≈ u_*附近，被积函数由B(u)最小值附近的区域主导。展开B(u) ≈ ε + c₉(u-u_*)²：
$$\ln\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} \approx \frac{1}{4u_*} \int_{-\infty}^{\infty} \frac{du}{\varepsilon + c_9(u-u_*)^2} = \frac{1}{4u_*} \cdot \frac{\pi}{\sqrt{c_9\varepsilon}}$$

（积分限扩展到±∞是合理的，因为远离u_*处1/B(u)迅速衰减。）

最终得到**BKT型尺度分离**：
$$\boxed{\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} \sim \exp\left(\frac{\pi}{4u_*\sqrt{c_9\varepsilon}}\right)}$$

### §3.3 有效GRZ参数

与GRZ标准形式β(λ) = -y - λ²（walking尺度~exp(π/√y)）比较，定义等效y参数：
$$\boxed{y_{\text{eff}} \equiv 16 u_*^2 c_9 \varepsilon}$$

则Λ_UV/Λ_IR ~ exp(π/√{y_eff})。注意y_eff与原始β函数系数的关系：
$$y_{\text{eff}} = 16\left(\frac{-c_5}{2c_9}\right)^2 c_9 \left(c_1 - \frac{c_5^2}{4c_9}\right) = \frac{4c_5^2}{c_9}\left(c_1 - \frac{c_5^2}{4c_9}\right)$$
$$= \frac{4c_1 c_5^2}{c_9} - \frac{c_5^4}{c_9^2}$$

### §3.4 Type I Walking的充分条件（以系数表述）

**Theorem I (GRZ类Walking).** 若存在正数u_* > 0使得：
1. B(u_*) = ε > 0（无实零点，B在u_*处为正值）
2. B'(u_*) = 0（u_*是B的局部极小值点）
3. B''(u_*) > 0（极小值而非极大值或拐点）
4. ε ≪ 1（近湮灭条件）
5. c₉ > 0（确保极小值点的二阶导为正）

则系统在g_walk = u_*^{1/4}附近表现出BKT型walking行为，尺度分离为Λ_UV/Λ_IR ~ exp(π/(4u_*√{c₉ε}))。

**以{c_{4k+1}}系数的直接表述**（三参数截断下）：
$$0 < c_1 - \frac{c_5^2}{4c_9} \ll \min(|c_1|, |c_5|, |c_9|), \quad c_9 > 0, \quad c_5 < 0$$

即c₁略大于c₅²/(4c₉)——系统刚好处在固定点湮灭曲面的"无实不动点"一侧。

> **INSPECTOR_CHECK §3**: 条件c₅ < 0源自在u_* > 0的要求。若c₅ > 0且c₉ < 0，则B(u)是开口向下的抛物线，其极值点为极小值（因为c₉ < 0 → 开口向下 → 顶点为极大值而非极小值）。在此情况下，B(u)可以有两个正实根（若极大值>0且两端→-∞），walking不发生。因此Type I walking的非平凡条件是c₉ > 0且c₅ < 0。

## §4 推广到高阶截断：多重固定点对与增强walking

### §4.1 B(u) = c₁ + c₅u + c₉u² + c₁₃u³：双最小值结构

当包含四次项（k=3, c₁₃项）时，B(u)是三次多项式，可有两种定性不同的行为：

**情况1: 分离的极值点。** 两个不同的局部极小值，各自可产生独立的walking区域。

**情况2: 合并的极值点。** B'(u) = 0在相邻两点有解，B''(u)在中间某点过零。

### §4.2 多重固定点湮灭与增强尺度分离

Faedo et al. (2021)的多cFP对框架可直接应用于此。若B(u)有两个接近的局部极小值，且两者都接近零：
$$B(u) \approx c_{\text{eff}}\left[(u - u_1)^2 + \varepsilon_1\right]\left[(u - u_2)^2 + \varepsilon_2\right]$$

当两个极小值都逼近零（ε₁, ε₂ → 0⁺），且它们之间的间距δ ≡ |u₁ - u₂|也是小量时，walking积分增强：

$$\ln\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} \sim \begin{cases}
\frac{\pi}{4u_1\sqrt{c\varepsilon_1}} + \frac{\pi}{4u_2\sqrt{c\varepsilon_2}} & \delta \gg \sqrt{\varepsilon_{1,2}} \quad \text{(独立walking)} \\[8pt]
\frac{\pi}{4u_*}\frac{1}{\delta^2\varepsilon + \varepsilon^3} & \delta \sim \varepsilon \quad \text{(增强walking, O}(\varepsilon^{-3})) \\[8pt]
\frac{\pi}{4u_*}\frac{1}{2\varepsilon^3} & \delta \ll \varepsilon \quad \text{(最大增强)}
\end{cases}$$

**增强walking的充分条件**: c₁, c₅, c₉, c₁₃满足B(u)有两个接近的局部极小值，且极小值都接近零。这需要：
$$B'(u_1) = B'(u_2) = 0, \quad B(u_1) \approx B(u_2) \approx 0, \quad |u_1 - u_2| \ll 1$$

在参数空间中，这是余维数更高的曲面（更多微调条件），但产生的尺度分离呈指数增强——可解释数值观测到的极长伪临界区间。

> **INSPECTOR_CHECK §4**: 增强walking（O(ε^{-3})而非O(ε^{-1/2})）在参数空间中的测度极小，但从贝叶斯角度看，如果理论先验使系统"自然"地位于多FP对附近（例如由于接近某个高对称点），则增强walking可能是通用的而非微调的。

## §5 Type II: Nordic Walking（鞍点碰撞）

### §5.1 Nordic walking的代数定义

Hawashin et al. (2025)的Nordic walking特征：β(g) ≈ const ≠ 0在一段扩展的g范围内恒定。在B(u)语言中，这意味着B(u) ≈ const/u^{1/4}在一段u范围内——或更直接地，β(g)本身接近常数。

β(g) ≈ const在g的扩展范围内成立当且仅当：
$$\beta'(g) \approx 0, \quad \beta''(g) \approx 0 \quad \text{在同一个} g_{\text{walk}} \text{处}$$

这比GRZ walking的条件（仅需β(g) ≈ 0）更强。计算β的导数：
$$\beta(g) = g B(g^4)$$
$$\beta'(g) = B(g^4) + 4g^4 B'(g^4) = B(u) + 4u B'(u)$$
$$\beta''(g) = \frac{d}{dg}[B(u) + 4u B'(u)] = 4g^3 B'(u) + 4\frac{d}{dg}[u B'(u)]$$
$$= 4g^3[B'(u) + B'(u) + u B''(u)] \cdot (\text{加上来自} dg^3/dg \text{的项})$$

更精确地：
$$\beta''(g) = 12g^3 B'(u) + 16g^7 B''(u) + 4g^3 u B''(u) = 4g^3[3B'(u) + B'(u) + 4u B''(u) + u B''(u)]$$

整理：
$$\beta'(g) = B(u) + 4u B'(u)$$
$$\beta''(g) = 12 g^3 B'(u) + 4 g^3 [B'(u) + 4u B''(u)] = 4g^3[4B'(u) + 4u B''(u)] = 16 g^3[B'(u) + u B''(u)]$$

### §5.2 Nordic walking条件（以B(u)表述）

在g_walk = u_*^{1/4}处同时满足β'(g_walk) ≈ 0和β''(g_walk) ≈ 0：

**条件N1**: B(u_*) + 4u_* B'(u_*) ≈ 0
**条件N2**: B'(u_*) + u_* B''(u_*) ≈ 0

这两条件同时成立时，β(g)在g_walk附近表现为：
$$\beta(g) \approx \beta(g_{\text{walk}}) + \frac{1}{6}\beta'''(g_{\text{walk}})(g - g_{\text{walk}})^3 + \cdots$$

即β(g)在g_walk附近是局部三次的而非二次的——这产生了比GRZ walking更平坦的β函数形状。

### §5.3 Nordic walking的最小实现

至少需要B(u)的三次截断（即c₁₃ ≠ 0）才能同时满足N1和N2。在B(u) = c₁ + c₅u + c₉u² + c₁₃u³中：

N2: B'(u_*) + u_* B''(u_*) = 0
→ (c₅ + 2c₉u_* + 3c₁₃u_*²) + u_*(2c₉ + 6c₁₃u_*) = 0
→ c₅ + 4c₉u_* + 9c₁₃u_*² = 0

N1: B(u_*) + 4u_* B'(u_*) = 0
→ (c₁ + c₅u_* + c₉u_*² + c₁₃u_*³) + 4u_*(c₅ + 2c₉u_* + 3c₁₃u_*²) = 0
→ c₁ + 5c₅u_* + 9c₉u_*² + 13c₁₃u_*³ = 0

这两个方程同时解出u_*和系数之间的关系。特别地，从N2解出u_*（取正根）：
$$u_* = \frac{-4c_9 \pm \sqrt{16c_9^2 - 36c_5c_{13}}}{18c_{13}}$$

代入N1得到系数间的一个约束关系。

### §5.4 Nordic walking的尺度分离

在Nordic regime，β(g) ≈ β₀（非零常数）在宽度Δg的区间内：
$$\Delta \ln \Lambda \approx \frac{\Delta g}{\beta_0}$$

这是**线性**（power-law）而非指数尺度的分离。设β₀ ~ η且Δg ~ O(1)（自然宽度）：
$$\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} \sim \exp\left(\frac{1}{\eta}\right)$$

注意此处η进入的是指数中的线性项（1/η），而非GRZ的1/√ε。因此，要达到相同的尺度分离，Nordic walking需要比GRZ walking更小的η。反过来，对于给定的η大小，Nordic walking产生的尺度分离远小于GRZ walking。

**这有一个重要推论**: Nordic walking在数值模拟中比GRZ walking更容易被"识破"——即更容易在可达到的系统尺寸内看到偏离标度行为。如果DQCP在L ~ 10²-10³范围内表现出鲁棒的标度行为，那么它更可能是GRZ型而非Nordic型walking。

> **INSPECTOR_CHECK §5**: N1和N2的同时满足是余维数2的条件。这意味着在一般的参数空间中，Nordic walking是比GRZ walking（余维数1）更精细的微调。Hawashin et al.声称Nordic walking"不需要微调"——这一声称需要仔细审视。在FRG流中，β函数的形状本身由RG动力学决定（而非外部参数），因此可能"自然地"演化到接近Nordic条件。但从β函数的系数{c_{4k+1}}的角度看，Nordic walking对系数施加的约束确实比GRZ walking更严格。

## §6 奇异点理论与Walking分类学

### §6.1 Catastrophe理论映射

Walking行为的分类有一个优雅的数学结构：它等价于B(u)（视为u的函数）的**奇点理论**（catastrophe theory）分类。

考虑B(u) = Σ_{k=0}^∞ c_{4k+1} u^k在某个u₀ > 0附近。通过平移和缩放，B(u)可化为标准形（normal form）：

| 奇点类型 | 标准形 | 余维数 | Walking类型 | 尺度分离 |
|---------|--------|--------|-----------|---------|
| **A₂ (Fold)** | u² + ε | 1 | Type I (GRZ) | exp(c/√ε) |
| **A₃ (Cusp)** | u³ + au + b | 2 | Type II (Nordic) | exp(c/|b|^{2/3}) |
| **A₄ (Swallowtail)** | u⁴ + au² + bu + c | 3 | Type III (增强) | exp(c/|ε|^{3/4}) |
| **A₅ (Butterfly)** | u⁵ + au³ + bu² + cu + d | 4 | Type IV | exp(c/|ε|^{4/5}) |

A₂对应B(u)的局部极小值接近零（一个控制参数ε）。A₃对应B(u)的拐点附近β'≈β''≈0（两个控制参数a,b）。高阶奇点对应更多系数的同时微调。

### §6.2 通用性（Genericity）论证

在一般参数空间中（没有任何额外对称性或约束），A₂（fold）是**通用**（generic）的：在参数空间的一个余维数1的曲面上，系统表现出walking行为。A₃（cusp）是余维数2的，在无保护的参数扫描中**不会**被遇到——除非有某种动力学机制使系统自然地流向cusp点。

**这一观察与Hawashin et al.的FRG结果的关系**: FRG流方程的自洽性可能将系统驱动到cusp点附近。这是因为FRG的β函数本身是RG流的产物——在流动过程中，{c_{4k+1}}系数本身是跑动的。如果RG流将系数驱动到满足A₃条件配置的附近，那么Nordic walking可以是"自然"的而非微调的。但这是动力学问题而非运动学问题——不能单从β函数的代数结构推出，需要计算{dc_{4k+1}/d(ln μ)}。

### §6.3 与S4结论的自洽性

S4的β(g) = g·B(g⁴)结构本身是运动学约束（来自{Q,C}=0）。在这个运动学舞台上，动力学（系数{c_{4k+1}}的具体值）决定了是否出现walking以及walking的类型。这与S4的核心结论一致："对称性提供舞台，β函数的零点分布提供剧本。"

> **INSPECTOR_CHECK §6**: 奇点理论分类的前提是B(u)在u₀附近充分光滑（C^∞）。对于从QFT计算出的β函数，这通常成立（微扰β函数是解析的，非微扰β函数至少是C^∞的）。但对强耦合区域（如DQCP的d=3），微扰β函数的收敛半径有限，奇点分析需要在适当的变量变换（如将g映射到某个更好的参数）下进行。

## §7 Walking与"正常"弱一阶的边界

### §7.1 Walking退化为普通一阶的条件

一个自然的问题是：在什么条件下，B(u)的"近零"结构崩溃，walking退化为普通的（非伪临界的）弱一阶相变？

普通弱一阶的特征：B(u) > 0处处成立，且B(u)的最小值B_min ~ O(1)（在自然单位下）。此时：
$$\ln\frac{\Lambda_{\text{UV}}}{\Lambda_{\text{IR}}} \sim \int \frac{du}{4u B(u)} \sim O(1)$$

即仅有一个数量级左右的尺度分离——没有扩展的标度区间。

**退化条件**: B_min ≳ 1（在适当的无量纲化下）。等价于：
$$\varepsilon \equiv c_1 - \frac{c_5^2}{4c_9} \gtrsim 1$$

即系统离湮灭曲面"足够远"。

### §7.2 可观测的跨接（Crossover）标度

Walking和普通弱一阶之间没有尖锐边界——存在连续的跨接。可定义跨接标度Λ_cross：在此标度以下，系统表现出近似标度不变性（walking）；在此标度以上，系统表现出明显的一阶行为。

$$\Lambda_{\text{cross}} \sim \Lambda_{\text{UV}} \exp\left(-\frac{\pi}{4u_*\sqrt{c_9\varepsilon}}\right)$$

当Λ_cross远大于任何实验/数值可达标度时，系统在所有实际目的下表现为伪连续的。当Λ_cross在可达标度范围内时，可通过跨接行为区分walking和真连续。

## §8 可检验判据

### §8.1 判据C1: ν_eff的系统尺寸漂移

**判据**: 若从有限尺寸标度提取的有效关联长度指数ν_eff(L)随ln(L)系统性漂移，且漂移方向为ν_eff增大，则为Type I walking的正面证据。

**推导**: 在walking区域，有效关联长度ξ_eff ~ exp(π/√{y_eff})。对于有限尺寸L，有效指数为：
$$\nu_{\text{eff}}(L) \equiv \frac{d\ln\xi_{\text{eff}}}{d\ln|T-T_c|} \approx \nu_* + \frac{c}{\ln(L/L_0)}$$

其中ν_*是复不动点决定的渐近值，c > 0是O(1)常数。因此ν_eff(L)应随L增大而**增大**（向∞漂移——因为BKT型相变的ν = ∞），且漂移速度~1/ln(L)（非常缓慢）。

**具体预测**: 对于SU(2) J-Q DQCP，若在当前QMC可达的L范围（≤256）内ν ≈ 0.49(4)且随L缓慢增大，则与Type I walking一致。

### §8.2 判据C2: 关联长度上限

**判据**: 若walking是Type I (GRZ)，则关联长度在T → T_c时饱和于有限值ξ_max，而非发散。且ξ_max与一阶能隙Δ的关系为ξ_max ∝ Δ^{-1/d}（而非连续相变的ξ ∝ |T-T_c|^{-ν}）。

**推导**: 在有限的ε > 0下，即使T精确等于T_c，系统也达不到真正的标度不变性。最大关联长度为：
$$\xi_{\max} \sim a \exp\left(\frac{\pi}{4u_*\sqrt{c_9\varepsilon}}\right)$$

其中a是晶格常数。对于DQCP，若ξ_max < 10³（在L ≤ 256模拟中不可区分于真发散），则为walking的正面证据。若QMC在L > 10³下仍看不到ξ饱和，则Type I walking的ε极小而尺度分离极大——与真连续在实践上不可区分。

### §8.3 判据C3: Lee-Yang零点虚部标度

**判据**: 复参数平面上配分函数的Lee-Yang零点虚部Im(z_L)在热力学极限下的标度行为可区分walking类型。

**推导**: 对于Type I walking（BKT型），LY零点虚部在L → ∞时以极慢的速度趋于零：
$$|\text{Im}(z_L)| \sim \exp\left(-\frac{c}{\sqrt{\varepsilon}}\right) \cdot L^{-d}$$

而非walking的一阶相变：|Im(z_L)| ~ L^{-d}（快速趋于零）。
真连续相变：|Im(z_L)| ~ L^{-(d+z)/ν}（以幂律趋于零，但LY零点在实轴上不存在）。

**数值实现**: 测量LY零点在复参数平面上的分布，外推L → ∞。若Im(z_∞)在误差范围内为零但趋近速度远慢于L^{-d}，则为walking的强证据。

### §8.4 判据C4: β函数从格点数据的直接重构

**判据**: 从QMC数据（Binder累积量或其导数）直接重构有效β函数。若重构的β(g)在扩展的g区间内|β(g)| ≪ 1（接近零），则为GRZ walking。若β(g) ≈ const ≠ 0在扩展区间内，则为Nordic walking。

**方法**: 利用RG流的格点实现——测量不同键耦合强度下的Binder累积量U(L, g)，利用曲线交叉法提取β函数的离散近似：
$$\beta_{\text{eff}}(g; L) \approx \frac{\partial U}{\partial \ln L}\bigg|_{g}$$

外推L → ∞得到连续极限β(g)。

### §8.5 判据C5: 纠缠熵的次 leading修正

**判据**: 在walking regime中，纠缠熵的面积律次leading项（拓扑纠缠熵或对数修正）表现出与真连续相变不同的标度。

**推导**: 在walking中，由于缺少真正的共形不变性，纠缠熵的通用对数修正项（在2+1D CFT中为常数，无对数发散）可能被walking诱导的有效长程关联所修改。具体预测需要针对具体模型的CFT数据计算，但定性上，walking应产生比真连续更弱的对数修正（因为有效中心电荷较小）。

> **INSPECTOR_CHECK §8**: 判据C4需要L足够大才能可靠重构β函数。当前QMC可达的L ≤ 256可能处于walking的"伪标度"区间内，重构的β(g)可能在误差范围内与零一致——这本身是walking的特征。区分walking与真连续需要证明β(g)不是精确为零而是在某个极小尺度下偏离零。

## §9 深挖：本轮结论的深层后果

### §9.1 深挖1: 下一层后果（至少两层）

**Layer 1 — 结构层**: B(u)的奇点类型不仅决定了walking的尺度分离形式，还决定了有限温度下的热力学标度函数。具体地：

- **A₂ (Type I)**: 自由能密度f_sing ~ exp(-c/|t|^{1/2})（BKT本质奇点），比热仅显示宽峰而非幂律发散。
- **A₃ (Type II)**: f_sing ~ |t|^{2 - α_eff}，其中α_eff由β₀和B(u)的三次系数决定，可以取连续变化的值。
- **A₄+ (Type III+)**: 更复杂的标度函数，可能展示多个跨接标度。

这意味着**仅通过测量比热的标度行为，就可以区分walking类型**——不需要直接测量β函数。热力学测量通常比RG流的格点重构更容易实现。

**Layer 2 — 分类学的预测力**: 如果walking行为的分类完全由奇点理论决定，那么可能的walking类型是**有限的且可穷举的**。在最多四个参数的截断下（c₁, c₅, c₉, c₁₃），只有A₂, A₃, A₄, A₅, D₄, D₅等有限种奇点类型可能出现。这提供了一个"walking分类表"——任何具体的DQCP实现必须落入表中某一项。

**Layer 3 — 跨系统预测**: 如果DQCP的walking是Type I（BKT型），那么所有处于同一普适类的弱一阶相变（如SU(N)自旋系统、某些阻挫磁体、甚至高能物理中的共形窗口边缘）应表现出相同的walking类型。如果不同系统表现出不同的walking类型（有的GRZ型、有的Nordic型），则说明存在超出{Q,C}=0对称性的更精细分类——可能是由于不同系统的c_{4k+1}系数被不同的微观机制锁定在不同的奇点附近。

### §9.2 深挖2: 最脆弱的前提

**最脆弱前提: 三参数截断（或有限参数截断）的物理可靠性。**

本推导的核心操作是将无限级数B(u) = Σ c_{4k+1} u^k截断到有限项（三项或四项），然后在截断的B(u)上分析walking条件。这一操作依赖以下假设：

**假设F**: 在walking发生的u = u_*附近，高阶项（k ≥ 3即c₁₃及更高）的贡献可以忽略。

**假设F可能失败的原因**:
1. **若walking发生在u_* ~ O(1)**（即g_walk ~ O(1)），则B(u)的级数展开可能收敛缓慢或发散，所有阶贡献相当。此时截断分析定性错误。
2. **即使u_* ≪ 1**，若c₁₃/c₉, c₁₇/c₉等比值不是小量（即高阶系数不被自然性压低的），则高阶项同样重要。
3. **QFT的β函数级数通常是渐近的而非收敛的**——存在一个最优截断阶数。若walking的ε小于最优截断误差，则截断分析的预言不可靠。

**如何检验假设F**:
- 在Eq.(1)中保留c₁₃项，检查c₁₃的效应是否修正walking判据在O(1)级别。如果是，则三参数截断不够。
- 使用Borel重求和或共形映射改进级数收敛性。
- 若可能，通过FRG或格点MCRG直接计算B(u)的非微扰形式，检查walking区域是否确实由前三项主导。

**假设F成立的有利论证**:
- 若{Q,C}=0对称性迫使c_{4k+1} ~ 1/(k!)（或某个更快的衰减），则B(u)是整函数，截断是可靠的。
- 若walking发生在接近湮灭点处（ε ≪ 1），则u_*附近的B(u)主要由最低阶非零导数决定（奇点理论的普适性），高阶项仅修正奇点位置而非奇点类型。

**结论**: 假设F是本轮推导中最脆弱的一步，但它**可以在子命题内部自我检验**——通过在截断中包含更高阶项并检查收敛性。这也是Phase 2的优先任务。
