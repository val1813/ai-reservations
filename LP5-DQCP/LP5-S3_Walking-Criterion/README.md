# LP5-S3' — Walking 行为的条件判据

> 所属长命题：LP-5 DQCP（真正连续还是弱一阶？）
> 类型：理论推导（纯分析，无需GPU）
> 创建：2026-06-02
> SOP版本：v3.7 + v4.0 突击队模式

## 北极星

基于 S4 的 β(g) = Σ c_{4k+1} g^{4k+1}（{Q,C}=0 对称性约束）框架，推导 BKT 伪连续行为（walking / Nordic walking）出现的充分条件。

给出可被数值/实验检验的判据：「若系统X的β函数满足条件Y → 伪连续walking行为必然出现，特征为Z」

## 已有前置结论（来自 LP-5 其他子命题）

- **S1 (EE):** EE对数修正不能鲁棒区分连续/弱一阶DQCP
- **S4 (Complex):** {Q,C}=0 → β(g) = Σ c_{4k+1} g^{4k+1}（全实系数）→ 实不动点不被对称性禁止。SU(2)弱一阶来自β函数动力学（实轴上无零点），非对称性强制。
- **S2' (Joint):** Takahashi (L=1024) 独立确认 SU(2) J-Q DQCP = 弱一阶
- **S2R (SO5):** SO(5)涌现对称性诊断在L=1024可区分连续/弱一阶（信号比~10²）
- **S3R (NMR):** NMR 1/T₁ 诊断受限于Δ ≪ T_min，但dη/dP方案概念可行
