# 可观测性检验 — DQCP-Complex v1

> 每个理论声张必须对应可观测的检验方案
> 不可观测的声张→标记为"不可检验"，降级为解释而非命题

---

## 检验方案

### T1: Running exponent漂移率 vs γ
- **理论声张：** Δ(γ)在γ_c处趋于零→真正连续
- **可观测量：** running exponent 1/ν(L) = d ln ξ / d ln L，外推到L→∞
- **检验方式：** 对每个γ值做有限尺寸标度，拟合d[1/ν(L)]/d(1/L)的渐近值
- **判断标准：** 若存在γ_c使得lim_{L→∞} d[1/ν]/d(1/L) = 0 → 真正连续
- **可行性：** 高 — QMC可达尺寸(~L=64-128)足够做初步标度分析

### T2: 标度维数 vs 幺正界限
- **理论声张：** 非厄米连续相变由非幺正CFT描述→标度维数可能低于幺正界限或为复数
- **可观测量：** 关联函数G(r) ~ r^{-2Δ}在临界点的指数衰减
- **检验方式：** QMC计算等时关联函数，提取Δ_ϕ(γ)
- **判断标准：** 若Δ_ϕ < 0.5 或呈现振荡衰减（Im(Δ)≠0）→非幺正CFT
- **可行性：** 中 — 需大系统+精确关联函数测量

### T3: 非厄米特有的信号
- **理论声张：** 若"连续化"来自非厄米性本身（例外点、NHSE等）而非复CFT→应出现非厄米特有的信号
- **可观测量：** (a) 动力学性质的方向依赖性（NHSE特征），(b) 能谱的例外点简并，(c) 复本征值谱的拓扑结构
- **检验方式：** 检查能谱在复平面的分布、非平衡动力学
- **判断标准：** 若出现NHSE特有方向性输运或例外点→"连续化"是非厄米效应，非复CFT固定点物理实现
- **可行性：** 中低 — 需额外分析工具
