## 本Phase突击任务

### 任务1（优先）：在已知物理系统中寻找BL Class 11的实例

搜索哪些已知量子多体系统属于BL Class 11（赝厄米复对称类）：
- 搜索："pseudo-Hermitian quantum many-body system Class 11"
- 搜索："complex symmetric Hamiltonian condensed matter"
- 搜索："PT-symmetric quantum spin system critical phenomena"
- 关注：非厄米SSH模型、非厄米Hubbard模型、非厄米Kitaev链、非厄米横场Ising模型等

对每个找到的Class 11系统，判断其临界行为是：
(a) 真正连续（→P3-A的反例）
(b) 伪连续/BKT型（→支持P3-A）
(c) 弱一阶
(d) 未知

### 任务2：搜索BL分类与临界行为关系的已有研究

- 搜索："Bernard-LeClair classification universality class"
- 搜索："non-Hermitian random matrix theory critical exponents universality"
- 搜索："38-fold way quantum criticality"
- 关键问题：是否有任何已有文献讨论"对称类→相变类型"的映射？BL分类是否已经隐含了对临界行为的约束？

### 任务3：攻击P3-A的对称性→伪连续逻辑链

P3-A声称：
"Class 11对称性 → 强制复共轭不动点对 → BKT伪连续"

攻击这个逻辑链的每一环：
- 环节1：对称性是否真的强制复不动点对？还是仅在某些参数区域？
- 环节2：复不动点对是否一定导致BKT型伪连续？有无例外（如复不动点对但一阶特征幂律衰减而非指数衰减）？
- 环节3：BKT伪连续是否排斥真正连续？两者能否共存于同一相图的不同区域？
