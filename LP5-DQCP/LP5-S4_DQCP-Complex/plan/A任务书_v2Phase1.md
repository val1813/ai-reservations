## Part 1：本Phase正规推导任务

### 推导目标（可证伪）

**P3: 从BL Class 11对称性推导β-函数的一般形式，判定复共轭不动点对是否被对称性强制的**

从Bernard-LeClair第11类的两个对称性出发：
- 复对称性 C: H → c H^T c†, c=I, ε_c=+1 → H^T = H
- 赝厄米性 Q: H → q H† q†, q=R_x(π), ε_qc=+1 → ηHη⁻¹=H†

推导这些对称性对低能有效作用量S_eff[ϕ]和β-函数β(g)的约束。

**具体目标：**
1. 写出Class 11对称性对有效作用量的一般约束（哪些项被允许/禁止）
2. 推导β(g)在对称性约束下的最一般形式（到三阶）
3. 分析该β-函数允许的不动点类型：实不动点、复共轭对、共存？
4. 判定：复共轭不动点对是被对称性强制的，还是在特定参数选择下可以避免？
5. 若对称性强制的→P3-A成立（伪连续是BL Class 11普适特征）
6. 若对称性不强制的→识别允许真连续固定点的参数条件

### 声张强度声明
□ 有条件成立，条件是：低能有效理论由CP¹类作用量描述（CP¹ + 涌现U(1)规范场），且非厄米微扰不改变对称性类别
