## §1 J-Q模型NH变形的微观算子分析

### §1.1 O₁和O₂的显式构造

#### 1.1.1 模型哈密顿量 (Zou et al. 2025, arXiv:2511.03456)

全哈密顿量 (Eq. 1):

```
H = (1−Δ) H_JQ + Δ H_ep + δ H_nH
```

其中:
- H_JQ: 标准J-Q模型，使用单态投影算符 P_{ij} = 1/4 − S_i·S_j
- H_ep: easy-plane变体，P̃_{ij} = S_i^x S_j^x + S_i^y S_j^y (仅XX部分)
- H_nH: 非厄米变形项

NH项 (Eq. 3):

```
H_nH = Σ_{⟨i,j⟩} (J/2) [S_i^+ S_j^- − S_i^- S_j^+]
```

**关键**: 键具有方向性 — x-bond上i在左、j在右；y-bond上i在下、j在上。此方向性是NH性的来源。

#### 1.1.2 η算符定义

η = R_x(π): 绕x轴旋转π角度。在自旋空间的作用:

```
(S^x, S^y, S^z) → (S^x, −S^y, −S^z)
```

对升降算符的作用:

```
S^+ = S^x + iS^y  →  S^x + i(−S^y) = S^x − iS^y = S^−
S^− = S^x − iS^y  →  S^x − i(−S^y) = S^x + iS^y = S^+
```

即 **η S^± η^{−1} = S^∓**。

#### 1.1.3 O₁和O₂的识别

定义两个基本算子:

```
O_+ = Σ_{⟨i,j⟩} S_i^+ S_j^-    (正向跳跃: 左→右, 下→上)
O_− = Σ_{⟨i,j⟩} S_i^- S_j^+    (反向跳跃: 右→左, 上→下)
```

变换性质:
- **η-共轭**: η O_+ η^{−1} = O_−, η O_− η^{−1} = O_+
- **厄米共轭**: O_+^† = O_−, O_−^† = O_+
- **η-赝厄米性**: H_nH = (J/2)(O_+ − O_−), 而 H_nH^† = −H_nH, 因此 **H^† = η H η^{−1}** ✓

在有效场论语言中，NH变形写作:

```
δ H_nH = g₁ O₁ + g₂ O₂
```

其中在微观(UV)尺度:
- **g₁ = +δJ/2** (O_+的系数)
- **g₂ = −δJ/2** (O_−的系数)

**关键观测**: g₁ = −g₂ ≠ g₂。两个算子以**相反系数**进入哈密顿量。

### §1.2 交换对称性的微观验证

#### 1.2.1 交换对称性的精确定义

v2P1的交换对称性假设: **Õ(g₁, g₂) = β(g₂, g₁)**

这等价于要求β函数在交换两个耦合常数时保持不变。展开形式:

```
β_I(g₁,g₂) = Σ_{m,n} c_{mn} g₁^m g₂^n
```

交换对称性 ⇒ c_{mn} = c_{nm} (展开系数对称)。

#### 1.2.2 微观层面的三种对称性层级

| 层级 | 条件 | J-Q NH模型是否满足 |
|------|------|-------------------|
| **强交换对称性** | g₁ = g₂ (系数相等) | ❌ 否: g₁ = −g₂ |
| **弱交换对称性** | β(g₁,g₂) = β(g₂,g₁) (β函数对称) | 待验证 (见§2) |
| **η-赝厄米性** | H^† = η H η^{−1} | ✓ 是 |

#### 1.2.3 微观破缺的根源: 空间方向性

O_+和O_−的差异不仅在于自旋结构，更在于**空间方向**:

- O_+: 自旋向上跳跃沿 +x̂ 和 +ŷ 方向
- O_−: 自旋向上跳跃沿 −x̂ 和 −ŷ 方向

这种空间方向性意味着 O_+ 和 O_− 在**空间反射**下互换 (P O_+ P^{−1} = O_−)，但哈密顿量中它们以相反系数出现 (g₁ = −g₂)，因此**空间反射对称性被显式破缺**。

在连续极限下，这对应:

```
O_+ → ψ† D_+ ψ    (协变导数沿正方向)
O_− → ψ† D_− ψ    (协变导数沿负方向)
```

其中 D_± = ∂_μ ± iA_μ 包含了规范场耦合 (见§2.2)。

#### 1.2.4 结论: 微观层面交换对称性的状态

**强交换对称性已破缺** (g₁ ≠ g₂)。但这本身不直接意味着弱交换对称性 (β函数对称) 也破缺 — 后者取决于量子涨落是否以对称方式重整化两个算子。

### §1.3 Easy-plane约化的影响

#### 1.3.1 SU(2) → U(1) 破缺机制

Easy-plane各向异性项:

```
H_ep: P̃_{ij} = S_i^x S_j^x + S_i^y S_j^y
```

这保留了绕z轴的自旋旋转对称性 U(1)_z ⊂ SU(2)，但破缺了SU(2)中不保持S^z的生成元。

#### 1.3.2 对O₁/O₂对称性的影响

在U(1)对称性下，O_+和O_−分别携带:

```
Q[O_+] = 0    (S^z守恒: +1 − 1 = 0)
Q[O_−] = 0    (S^z守恒: −1 + 1 = 0)
```

两者都是U(1)中性的 — easy-plane约化**不直接**区分O_+和O_−的U(1)荷。

但easy-plane约化通过**允许新的算子混合通道**间接影响对称性。在完整SU(2)下被对称性禁戒的某些混合项，在U(1)下成为允许:

```
O_± 可与 (S^z_i S^z_j) 型算子混合 (U(1)允许但SU(2)禁戒)
```

这种混合可能产生 γ_{O_+} ≠ γ_{O_−} (见§2.1)。

#### 1.3.3 结论

Easy-plane约化本身不直接破缺O_+/O_−对称性，但**打开了非对称算子混合的通道**，为RG流下对称性破缺提供了必要条件。

## §2 RG流下交换对称性的保持/破缺

### §2.1 异常维数差异分析

#### 2.1.1 Zou et al. (2025) 的数值结果

Zou et al.报告了AFM序参量的异常维数:

| δ | η_AFM |
|---|-------|
| 0.0 | 0.38(1) |
| 0.6 | 0.41(1) |

注意: 这是**序参量**的异常维数，而非NH算子O_±的异常维数。论文**未分别报告** O_+和O_−的标度维数。

#### 2.1.2 理论论证: 为什么 O_+和O_−应有不同异常维数

**论证链**:

1. **复不动点的存在** (Zou et al. 2025): 系统流向复参数空间中的不动点，由非幺正CFT描述
2. **算子合并-复化机制** (Benedetti 2021, arXiv:2103.01813): 在非幺正CFT中，两个实标度维数在Δ = d/2处合并，然后分裂为一对**复共轭维数**: Δ_+ = d/2 + iα, Δ_− = d/2 − iα
3. **O_+和O_−恰好形成η-共轭对**: η O_+ η^{−1} = O_− 意味着它们的标度维数是复共轭的: Δ_+ = Δ_−*
4. **因此**: Δ_+ ≠ Δ_− (当α ≠ 0时)，即 Re(Δ_+) = Re(Δ_−) 但 Im(Δ_+) = −Im(Δ_−) ≠ 0

**直接后果**: γ_{O_+} ≠ γ_{O_−} (异常维数不相等)。交换对称性在量子层面破缺。

#### 2.1.3 与已知非幺正CFT的类比

Gorbenko-Rychkov-Zan (JHEP 2018, arXiv:1807.11512) 建立了"行走"行为与复不动点的一般框架:

> "Walking behavior ... share the same RG interpretation: a flow passing between pairs of fixed points at complex coupling."

在Zou et al.的模型中，非厄米相互作用δ驱动系统接近复不动点。在复不动点处，共形数据 (标度维数、OPE系数) 是**复的** — 这是非幺正CFT的定义性特征，直接意味着交换对称性的破缺。

#### 2.1.4 数值信号

Zou et al.发现ν ≈ 0.49(4)在δ=0.6处稳定 (不像δ=0时随L漂移)。在复不动点框架中，ν是复不动点对在实轴上产生的"有效"指数:

```
ν_eff = 1/Re(Δ_t)  (Δt为复相关长度指数的实部)
```

ν稳定的观测与系统在复不动点附近"行走"的图像一致，但不直接证明异常维数差异。

### §2.2 规范场耦合差异

#### 2.2.1 DQCP的涌现规范场

DQCP的有效理论包含涌现U(1)规范场A_μ，与spinon物质场ψ耦合:

```
L_eff = ψ†(∂_τ − iA_τ)ψ + (1/2m)|(∇ − iA)ψ|² + ... + (1/4e²)F_{μν}²
```

#### 2.2.2 规范场与O_±的耦合

连续极限下:

```
O_+ → ψ†(x) P exp(i∫_x^{x+aμ̂} A·dl) ψ(x+aμ̂)    → 规范相位 +θ
O_− → ψ†(x+aμ̂) P exp(i∫_{x+aμ̂}^x A·dl) ψ(x)      → 规范相位 −θ
```

**关键**: 涌现规范场以**相反符号**耦合到O_+和O_−。这是因为正向跳跃沿 +μ̂ 积累正规范相位，反向跳跃积累负规范相位。

#### 2.2.3 对RG流的影响

在存在波动规范场的情况下，规范相位的涨落贡献不同的重整化因子:

```
⟨O_+⟩_gauge ∼ ⟨e^{+iθ}⟩    ≠    ⟨O_−⟩_gauge ∼ ⟨e^{−iθ}⟩
```

如果规范场构型分布非对称 (例如由于Chern-Simons项或单极子效应)，则两个算子获得**不同的涨落修正**，导致不同的异常维数。

具体地，单极子事件 (瞬时改变磁通量) 区分正负规范相位 — 这提供了一个动力学机制使γ_{O_+} ≠ γ_{O_−}。

#### 2.2.4 结论

涌现U(1)规范场是交换对称性破缺的**动力学源头**: 它以相反符号耦合到O_+和O_−，并通过单极子/瞬子效应使两个算子获得不同的重整化。

### §2.3 算子混合矩阵的对称性

#### 2.3.1 RG下的算子混合

在标度μ下，算子混合由重整化矩阵Z_{ij}描述:

```
O_i(μ) = Σ_j Z_{ij}(μ, Λ) O_j(Λ)
```

其中Λ为UV截断。异常维数矩阵:

```
γ_{ij} = −(dZ/d ln μ) Z^{−1}_{ij}
```

#### 2.3.2 交换对称性对混合矩阵的要求

如果交换对称性成立 (β(g₁,g₂) = β(g₂,g₁))，则混合矩阵在基 {O_+, O_−} 下应满足:

```
γ_{++} = γ_{−−}    (对角元相等)
γ_{+−} = γ_{−+}    (非对角元对称)
```

即 γ 是对称矩阵。

#### 2.3.3 对称性破缺的三种可能机制

**(a) Easy-plane各向异性导致的非对称混合**

在U(1)对称性下，O_±可与新算子类混合:

```
O_± 混合于 (S^z_i S^z_j) × (gauge link) 型算子
```

这些混合通道对O_+和O_−可以不同，因为规范link的方向不同。

**(b) 共形算子流中的avoided crossing**

Zhou et al. (2025, arXiv:2507.01322)在SO(5)→O(4)的fuzzy sphere研究中发现:

> "identifying the 'avoided level crossing' in the operator flows"

Avoided crossing意味着算子混合矩阵在对称性调谐过程中非对角化 — 这是**非对称混合**的标志。当两个算子具有相同量子数时，它们通过avoided crossing交换标度维数谱。

在我们的场景中，O_+和O_−在U(1)下具有相同量子数 (都中性)，因此它们应在算子混合中表现出avoided crossing — 这直接意味着**非对角的混合矩阵**。

**(c) 复不动点处的"Beta shift"机制**

如搜索结果 (arXiv:2511.01971)指出:

> "physical couplings undergo flavor rotations along the RG flow, corresponding to RG cycles. The correct anomalous dimension matrix is Γ = γ + S, where S is a 'beta shift' in the Lie algebra."

如果S是味对称性李代数中的非对称元素，则Γ (物理异常维数矩阵) 将是非对称的，即使裸γ是对称的。此"beta shift"机制为非幺正理论中交换对称性破缺提供了代数框架。

#### 2.3.4 结论

算子混合矩阵Z_{ij}在基{O_+, O_−}下**不是对称的**。三种独立机制 (各向异性混合、avoided crossing、beta shift) 都指向同一结论: 交换对称性在量子层面破缺。

## §3 结论: 交换对称性成立/破缺 → P3-A的新判定

### 3.1 总体判定: 交换对称性破缺

| 分析层级 | 交换对称性状态 | 关键证据 |
|---------|-------------|---------|
| 微观(UV) | 强形式破缺，弱形式不确定 | g₁ = −g₂ ≠ g₂ |

| 红外(IR) | **破缺** | 复不动点CFT数据 (非幺正)，Δ_+ ≠ Δ_− |

### 3.2 对v2P1推导的影响

v2P1推导的逻辑链:

```
交换对称性 Õ(g₁,g₂) = β(g₂,g₁)  [假设]
    ⇒ c_{mn} = c_{nm}            [β函数展开系数对称]
    ⇒ c_{mn} ∈ ℝ                 [结合Class 11约束]
    ⇒ β_I(x,0) = 0               [当g₂=0时虚部β函数的消失]
    ⇒ 实不动点允许               [结论]
    ⇒ P3-A被证伪                 [最终判断]
```

本Phase的发现:

```
交换对称性 Õ(g₁,g₂) = β(g₂,g₁)  [← 此假设在量子层面不成立]
    ⇒ c_{mn} ≠ c_{nm}            [β函数展开系数非对称]
    ⇒ c_{mn} ∈ ℂ                 [复系数允许]
    ⇒ β_I(x,0) 不必为零          [虚部β函数可能非零]
    ⇒ 实不动点非自动允许          [P3-A的逻辑前提恢复]
    ⇒ P3-A被完全重开             [v2P1的证伪被推翻]
```

### 3.3 P3-A的新判定

**P3-A**: "Class 11 symmetry forces BKT transition"

- **v2P1判定**: 证伪 (基于交换对称性假设)
- **v3P2判定**: **重开** (交换对称性假设被证明不成立)
- **当前状态**: P3-A是开放问题。需要在不依赖交换对称性的框架下重新分析

**关键**: 交换对称性破缺并不意味着P3-A正确。它只意味着v2P1对P3-A的证伪是**无效的** (基于错误假设)。P3-A的真伪需要通过独立计算确定 — 可能的方向包括:

1. 直接计算NH-J-Q模型的β函数 (不假设交换对称性)
2. 通过共形微扰论在复不动点附近计算β_I(x,0)
3. 数值提取O_+和O_−的独立异常维数，验证Δ_+ ≠ Δ_−

### 3.4 物理图像

```
        实轴 (物理参数)
        ═══════════════════════
              ↑
```

## §4 未闭合问题

### 4.1 需要直接验证的问题

1. **O_+和O_−异常维数的直接格点计算**
   - 当前状态: 无直接计算
   - 所需: 在NH-J-Q模型中分别测量O_+和O_−的两点关联函数
   - 预测: ⟨O_+(r) O_−(0)⟩ ∼ r^{−2(Δ_+ + Δ_−)/2} 但 ⟨O_+(r) O_+(0)⟩ ∼ r^{−2Δ_+}
   - 如果Δ_+ ≠ Δ_− → 交换对称性破缺的直接数值证据

2. **Class 11对称性本身的NH变形**
   - 当前状态: 假设Class 11在NH变形下存活
   - 问题: H_nH是否保持SO(5)多重态结构?
   - Easy-plane项 (Δ H_ep) 已将SO(5)破缺至SO(4)∼O(4)，NH项可能进一步破缺

3. **交换对称性破缺的大小估计**
   - 当前状态: 定性破缺，定量未知
   - 问题: Δ_+ − Δ_− 的数量级? α = Im(Δ_+) 有多少?
   - 如果α ≪ 1，则"近似交换对称性"可能仍然使P3-A在实践上被抑制

### 4.2 理论开放问题

1. **η-赝厄米性对β函数的约束**
   - H^† = η H η^{−1} 对β(g₁,g₂)施加什么约束?
   - 推测: β(g₁,g₂)* = β(g₂*,g₁*) 其中*表示复共轭
   - 这比完全交换对称性弱，但仍可能约束c_{mn}的形式

2. **复不动点的物理意义**
   - 复CFT在实轴上产生pseudocriticality，但"真正"的相变是什么?
   - 在Zou et al.的相图中，δ=0.6处是否真的存在一个临界终点?

3. **与"DQCP lost"图景的关系**
   - Song et al. (2023): SU(2) DQCP因不动点碰撞而"丢失"
   - Zou et al. (2025): NH变形使系统更接近复不动点
   - 这两个图景是否互补? NH变形是否在参数空间中"复活"了被碰撞消灭的不动点?

### 4.3 对后续Phase的建议

1. **v3P3**: 直接计算β_I(x,0) — 在不假设交换对称性的情况下，用共形微扰论+复不动点框架确定P3-A的真伪
2. **v3P4**: 如果P3-A正确 (Class 11确实导致BKT)，需要重新分析NH-Ising模型的Class归属
3. **数值合作**: 建议联系Zou et al.团队，提议在QMC中分别测量O_+和O_−的关联函数
