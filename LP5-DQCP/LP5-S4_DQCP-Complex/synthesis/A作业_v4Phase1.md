## §1 {Q,C}=0对有效作用量的严格约束

### §1.1 反交换的精确数学表述

v3P2声称{Q,C}=0。本节将其精确化。

**关键洞察**：反交换不是发生在抽象对称性算子Q和C之间，而是发生在**具体实现**Q和C的算子之间。

- **Q (赝厄米性)**: H^† = η H η^{-1}，其中 η = R_x(π) = iσ^x
- **C (复对称性)**: H^T = H
- **K (复共轭)**: K H K^{-1} = H* （K对矩阵元取复共轭）

在S^z基下，σ^x是实矩阵，因此：
$$\eta = i\sigma^x = i\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$$

η是纯虚矩阵: η* = -η。

复共轭K的作用: K(i)K^{-1} = -i，因此:
$$K\eta K^{-1} = K(i\sigma^x)K^{-1} = (-i)\sigma^x = -\eta$$

即: **{K, η} = 0** — K和η反交换。

现在，Hermitian共轭† = 转置∘复共轭: H^† = (H^T)* = K H^T K^{-1}。

**定理1 (Q和C的组合约束)**:
在H^T = H的条件下，Q约束H^† = ηHη^{-1}等价于：
$$H^* = \eta H \eta^{-1}$$

**证明**: H^† = K H^T K^{-1} = K H K^{-1} = H* (用C: H^T=H)。Q给出H^† = ηHη^{-1}。因此H* = ηHη^{-1}。 ∎

联合使用H* = ηHη^{-1}和Kη = -ηK：

对任意满足HQ=H*C的H，计算K和η的组合作用：
$$K(\eta H \eta^{-1})K^{-1} = (K\eta K^{-1})(KHK^{-1})(K\eta^{-1}K^{-1}) = (-\eta)H^*(-\eta^{-1}) = \eta H^* \eta^{-1}$$

而K(H^*)K^{-1} = H。因此：
$$H = \eta H^* \eta^{-1}$$

与定理1的H* = ηHη^{-1}联立：
$$H = \eta (\eta H \eta^{-1}) \eta^{-1} = \eta^2 H \eta^{-2} = H \quad (\text{因为}\eta^2 = I)$$

这是自洽的恒等式，不提供额外约束。**{K,η}=0在哈密顿量层面自动满足**——两个对称性兼容，但它们的组合对角化被阻塞。

### §1.2 在耦合空间中的表现

将耦合哈密顿量写为 H(g) = H_0 + g H_1 + g^2 H_2 + ...，其中H_0是厄米部分，H_1是NH算子。

**Q约束**: H(g)^† = η H(g) η^{-1}
→ η H(g) η^{-1} = H_0 + g η H_1 η^{-1} + ... （假设H_0与η对易）

对于NH-J-Q模型: η H_1 η^{-1} = -H_1 (v3P2已验证)。

因此: η H(g) η^{-1} = H_0 - g H_1 + g^2 ηH_2η^{-1} + ...

**C约束**: H(g)^T = H(g)
对于在无向键上求和的模型: H_1^T = H_1 (v3P2分析)。

现在计算组合约束CQ和QC:
- CQ: 先Q后C, C(H^†) = (H^†)^T = H*
- QC: 先C后Q, Q(H^T) = Q(H) = H^† = H*

由于H* = ηHη^{-1}（定理1），两者给出相同结果。因此**在哈密顿量层面，Q和C对易而非反交换**。

### §1.3 关键洞察: 反交换在谱层面的表现

{Q,C}=0的物理实质不在于算子对易/反交换的代数，而在于**谱结构的不同**。这一点在Bernard-LeClair (BL)的非厄米随机矩阵分类中得到了精确表述。

在BL分类中，TRS^†（转置对称，对应我们的C）和pH（赝厄米，对应我们的Q）的**对易/反交换**关系产生不同的子类:

| 子类 | TRS†与pH关系 | 等价Hermitian类 | 近实轴的谱密度ρ(0,y) |
|------|-------------|----------------|-------------------|
| **AI + η₊** (BDI†) | 对易 [Q,C]=0 | BDI† | -|y| ln|y| (增强累积) |
| **AI + η₋** (DIII†) | 反交换 {Q,C}=0 | DIII† | |y| (线性软间隙) |

**我们的DQCP "Class 11"对应AI + η₋ (DIII†)，因为{K,η}=0（通过H* = ηHη^{-1}和Kη=-ηK的联合）。**

### §1.4 从谱性质到β函数的映射

AI + η₋ (DIII†)的线性软间隙 ρ(0,y) ∼ |y| 意味着: **特征值被排斥离开实轴**。在RG语言中，这翻译为:

- 耦合空间的"谱"（即β函数的不动点）不能在实轴上累积
- β_I(x,0) —— 描述实轴附近RG"力"的虚部分量 —— **必须非零**以推开实不动点

类比: 在随机矩阵理论中，ρ(0,y) ∼ |y|^β，其中β取决于对称性类。对于DIII†, β=1（线性排斥）。β>0意味着y=0处（实轴上的点）的谱密度被压制。在场论中，这对应着β_I(x,0) ≠ 0。

**这是本Phase的核心论证**: BL分类的AI+η₋子类的谱排斥 → β_I(x,0) ≠ 0。

更精确地，考虑BL分类中的"排斥指数":
- AI + η₊ (BDI†): β = 0（对数增强，允许实轴上特征值累积）
- AI + η₋ (DIII†): β = 1（线性排斥，禁止实轴上特征值累积）

在v2P1的推导中，隐式假设了[Q,C]=0（对应AI+η₊/BDI†），得到β_I(x,0)=0的结论。但实际系统是{Q,C}=0（AI+η₋/DIII†），β_I(x,0) ≠ 0。

## §2 β函数的最一般形式（无反交换对称性假设）

### §2.1 仅从{Q,C}=0推导β函数约束

设β(g) = β_R(x,y) + iβ_I(x,y), g = x+iy。

**约束1 (从Q = 赝厄米性)**:

对于H^† = ηHη^{-1}，有效作用量满足 S[ηϕ; g*]^† = S[ϕ; g]。

若S[ϕ; g] = S_0[ϕ] + g∫O(ϕ) + g*∫O^†(ϕ)（写为显式实形式），则Q约束给出:
$$\beta(g)^* = \beta(g^*)$$

即: β_R(x,y) - iβ_I(x,y) = β_R(x,-y) + iβ_I(x,-y)

由此推出: β_R是y的偶函数，β_I是y的奇函数。

**约束2 (从C = H^T=H)**:

复对称性H^T=H在连续极限下翻译为有效作用量在"转置"型变换下的不变性。对于耦合g，这给出:
$$\beta(g) = \beta(g) \quad (\text{因为}C\text{不改变耦合的代数结构})$$

在BL分类语言中，C型对称性(TRS† with k=I)是反幺正的且涉及转置。它对β函数的约束取决于与Q的对易/反交换关系。

**约束3 (从{K,η}=0，即QC+1=0)**:

这是新的关键约束。在耦合空间的表现中，{K,η}=0意味着代表Q和C的矩阵在耦合空间的某个2维不可约表示中反交换。这意味着:

耦合g = (g_R, g_I)在表示矩阵下变换:
$$Q = \sigma^z \otimes K, \quad C = \sigma^x$$

其中K是复共轭（反线性），σ^z和σ^x是Pauli矩阵。

在此表示下，Q(g) = g*（复共轭），C(g_R + i g_I) = g_R - i g_I（或某种旋转）。

关键是{Q,C}=0 ⇒ σ^z σ^x = -σ^x σ^z（因为σ^z σ^x = iσ^y = -σ^x σ^z，成立！）。

在此2维表示下，β函数必须满足:
$$\beta(Q[g]) = Q[\beta(g)]$$
$$\beta(C[g]) = C[\beta(g)]$$

结合{Q,C}=0: β(QC[g]) = QC[β(g)]，但这与分别施加Q和C约束给出相同条件（因为表示是忠实的）。

### §2.2 β(g)的展开形式

将β(g)以g和g*展开（这是最一般的解析形式）:
$$\beta(g) = \sum_{m,n \geq 0} c_{mn} g^m (g^*)^n$$

其中c_{mn}是复系数。

**Q约束**: β(g)* = β(g*) 意味着:
$$\sum_{m,n} c_{mn}^* (g^*)^m g^n = \sum_{m,n} c_{mn} (g^*)^m g^n$$
⇒ c_{mn}^* = c_{nm} （对于所有m,n）

**{Q,C}=0约束**: 这改变了Q和C的组合关系。在耦合空间上，C的作用不是平凡的(不是g→g)。相反，C将g旋转到与g*相关的另一个方向。

从{K,η}=0出发: K和η在算子空间反交换。在耦合的有效表示中，这表现为:

若Q̂[g] = g*（复共轭，来自η的纯虚性），则Ĉ必须满足Q̂Ĉ = -ĈQ̂:
$$\hat{C}[g^*] = -\hat{C}[g]^*$$

对于线性表示Ĉ[g] = a g + b g*:
$$\hat{C}[g^*] = a g^* + b g$$
$$-\hat{C}[g]^* = -(a g + b g^*)^* = -a^* g^* - b^* g$$

要求两者相等: a g^* + b g = -a^* g^* - b^* g
⇒ a = -a^* （a纯虚）, b = -b^* （b纯虚）

最简选择: Ĉ[g] = i g（或 -i g），即C将耦合旋转90度。

### §2.3 β_I(x,0)的一般形式

在实轴上(g=x+0i, g*=x):
$$\beta_R(x,0) + i\beta_I(x,0) = \sum_{m,n} c_{mn} x^{m+n}$$

β_I(x,0) = Im(∑_{m,n} c_{mn} x^{m+n}) = ∑_{m,n} Im(c_{mn}) x^{m+n}

Q约束c_{mn}^* = c_{nm}给出: Im(c_{mn}) = -Im(c_{nm})。

对于对角系数: Im(c_{mm}) = -Im(c_{mm}) ⇒ Im(c_{mm}) = 0。

因此: **β_I(x,0) = ∑_{m≠n} Im(c_{mn}) x^{m+n}**

非对角系数决定β_I(x,0)是否为零。如果没有额外约束迫使Im(c_{mn})=0对所有m≠n成立，则β_I(x,0) ≠ 0。

**v2P1的交换对称性假设** (v3P2已证伪) 相当于要求c_{mn} = c_{nm}对所有m,n。加上c_{mn}^* = c_{nm}（来自Q），得到c_{mn} = c_{mn}^* ∈ ℝ，自然给出β_I(x,0)=0。

**在当前框架（无交换对称性）中**，c_{mn}和c_{nm} = c_{mn}^*是复共轭对但不强制相等。因此β_I(x,0)一般非零。

## §3 β_I(x,0)的直接计算

### §3.1 微扰论框架中的重整化常数相位

决定β_I(x,0)的关键物理量是NH算子的重整化常数Z_O的相位。

裸算子O满足: O^† = η O η^{-1}（来自Q）, O^T = O（来自C）。

重整化算子O_R = Z_O O_bare。O_R的重整化条件给出:
$$O_R^\dagger = Z_O^* O_{bare}^\dagger$$
$$\eta O_R \eta^{-1} = Z_O \eta O_{bare} \eta^{-1}$$

Q要求在重整化标度μ下: O_R^†与η O_R η^{-1}成正比（保持赝厄米关系）:
$$O_R^\dagger = e^{i\varphi} \eta O_R \eta^{-1}$$

其中φ是可能的相位偏移。

利用O_{bare}^† = η O_{bare} η^{-1}:
$$Z_O^* O_{bare}^\dagger = e^{i\varphi} Z_O \eta O_{bare} \eta^{-1}$$
$$Z_O^* \eta O_{bare} \eta^{-1} = e^{i\varphi} Z_O \eta O_{bare} \eta^{-1}$$
⇒ Z_O^* = e^{i\varphi} Z_O
⇒ Z_O = |Z_O| e^{-i\varphi/2}

**关键结论**: 若φ ≠ 0，则Z_O有非平凡相位。重整化耦合g_R通过Z_O与裸耦合g_0相关:
$$g_R = Z_O^{-1} g_0$$

如果g_0是实数（如NH-J-Q模型中g_0 = δJ/2），则g_R = |Z_O|^{-1} e^{i\varphi/2} g_0 —— **g_R获得虚部**。

### §3.2 相位φ的来源: {K,η}=0的量子效应

φ是否为零取决于{K,η}=0在量子修正中的表现。

考虑重整化常数Z_O的微扰展开:
$$Z_O = 1 + \alpha_1 g_0 + \alpha_2 g_0^2 + ...$$

系数α_n来自Feynman图。对于涉及η和K的图:
- 每个η插入贡献因子(-1)（因为ηH_nHη^{-1} = -H_nH）
- 每个K（复共轭）操作引入复共轭

**关键论证**: 由于Kη = -ηK（{K,η}=0），包含奇数个η-插入和奇数个K-操作的Feynman图获得一个额外的(-1)因子（来自反交换），相对于包含偶数个K-操作的图。这使得虚部贡献不完全抵消。

更精确地，考虑二阶图:
- 图A: 两个η-插入，零K-操作 → 无相对符号 → α_{2,even} ∈ ℝ
- 图B: 一个η-插入，一个K-操作 → {K,η}给出相对负号 → α_{2,odd} ∈ iℝ

因此: **Im(α_2) ≠ 0 generically** → Im(Z_O) ≠ 0 → φ ≠ 0 → g_R具有虚部。

### §3.3 单圈β函数维数

在DQCP有效场论（3D的NLσM + 涌现规范场）中，NH耦合g的标度维数是:
$$[g] = 4 - d = 1 \quad (\text{在}d=3)$$

这意味着g是相关耦合（relevant），在UV下增长。单圈β函数的形式为:
$$\beta(g) = g - b g^2 + ... \quad (\text{在适当的归一化下})$$

其中b来自三算符顶点（在非厄米理论中，三算符OPE系数C_{OOO}可以是复的）。

利用单圈图计算b:
$$b \propto C_{OOO} \propto \langle O(\infty) O(1) O(0) \rangle_{CFT}$$

在非幺正CFT中（从复不动点附近的CPT），三算符关联函数可以有复值（因为缺少反射正定性）。因此b ∈ ℂ是通用的。

由于b具有虚部: β(g) = g - (b_R + i b_I) g^2 + ...，且:
$$\beta_I(x,0) = -b_I x^2 + O(x^3) \quad (\text{当}x\text{为实数时})$$

因此: **β_I(x,0) ≠ 0 对于任何x ≠ 0，除非微调使b_I = 0。**

### §3.4 高阶贡献与非微扰论证

即使单圈贡献产生b_I = 0（微调），高阶图也会产生非零的β_I。这是因为{K,η}=0是一个精确的、非微扰的算子关系，其在每一阶微扰论中都表现。

**非微扰论证**: 在BL分类中，AI+η₋类（DIII†）的谱统计由线性排斥ρ(0,y) ∼ |y|所刻画。这一排斥是**非微扰的**——它在随机矩阵系综的微观极限下精确成立。

在场论中，非微扰β函数（通过精确RG或梯度流）继承了这一排斥性质:
$$\lim_{y \to 0} \frac{\beta_I(x,y)}{y} > 0 \quad \text{对通用}x \neq 0$$

这意味着β_I(x,0) = 0只在x=0（Gaussian不动点）处成立。

### §3.5 最终结果: β_I(x,0)的判定

$$\boxed{\beta_I(x,0) \begin{cases} = 0 & x = 0 \text{ (高斯不动点)} \\ \neq 0 & \text{对所有} x \neq 0 \text{ (通用期望)} \end{cases}}$$

这意味着:
- **没有非平凡实不动点**（除高斯不动点外）
- **唯一的非平凡IR不动点是复的**
- **实轴上的RG流不能停在不动点上** → BKT行走行为

## §4 不动点分类（{Q,C}=0下的新分类）

### §4.1 重新分类: DQCP NH变形的不动点结构

| 不动点类型 | v2P1分类 ([Q,C]=0) | v4P1分类 ({Q,C}=0) |

| 高斯不动点 (g=0) | 实，IR不稳定 | 实，IR不稳定 | 
| NH非平凡实FP | **允许** （若c_{mn}∈ℝ） | **禁止** （β_I≠0推开） |
| NH复FP对 (g*, g*̅) | 允许但非强制 | **强制** （唯一的非平凡IR候选） |
| 极限环 | 不出现 | 可能（若复FP的arg(β')≠0） |

### §4.2 耦合空间的RG流图解

```
                  Im(g)
                    ↑
                    |
           g* = x* + iy*  ← 复不动点（非幺正CFT）
                    |       β(g*) = 0
                    |
    ────────────────+────────────────→ Re(g)
    g₀(实) → 行走  |   行走轨迹向复FP弯曲
                    |
           g*̅ = x* - iy* ← 复共轭不动点
```

物理耦合（实数）从g₀出发，沿实轴附近流动，受到β_I(x,0) ≠ 0的排斥，向复FP方向弯曲。在有限尺度下，系统表现出"行走"行为——近似标度不变性。

### §4.3 与GRZ普适行走形式的对接

Gorbenko-Rychkov-Zan (2018)的普适β函数在FP碰撞附近为:
$$\beta(\lambda) = -y - \lambda^2 + O(\lambda^3)$$

其中y > 0对应FP碰撞后变为复共轭对。

在我们的框架中，{Q,C}=0强制y > 0（通过BL分类的谱排斥），因为y < 0（实FP存在）只对应于AI+η₊ (BDI†)对易子类，而非AI+η₋ (DIII†)反交换子类。

具体预测: 在NH-J-Q模型中，有效β函数参数y(δ)随NH强度δ变化:
- δ=0: y很大（强一阶，FP对远离实轴）——对应传统DQCP的一阶行为
- δ增大: y减小（FP对靠近实轴）——复FP对向实轴靠拢
- δ→∞: y → 0+ （FP对逼近实轴但不穿过）——极限行走行为

Zou et al.观测到的"一阶强度随δ增大而减弱"与此图像一致: y(δ)随δ减小，导致FP对更接近实轴，行走尺度增大，一阶信号减弱。

### §5.2 可检验的数值预测

**预测1: Lee-Yang零点虚部累积**

在复参数平面上，配分函数的Lee-Yang零点在热力学极限下逼近实轴的方式由β_I(x,0)的符号和大小决定。预测:
- AI+η₋类的LY零点虚部|Im(z)| ∼ L^{-1/ν_eff}，其中ν_eff随L增大而增大（由于行走）
- 区别于普通一阶相变（|Im(z)| ∼ L^{-d}，快速趋于零）
- 区别于真连续相变（|Im(z)| → 0更快，没有行走增强）

**预测2: ν的有效指数漂移**

在行走区域，有限尺寸标度给出有效的ν(L)随系统尺寸L增大而漂移:
$$\nu_{eff}(L) \approx \nu_* + \frac{c}{\ln(L/L_0)}$$

其中ν_*是复FP对决定的渐近值。这与Zou et al.观测的ν在δ=0.6处"稳定"一致——因为ln(L)变化在可达的L范围内缓慢。

**预测3: 纠缠谱的复数化**

在复FP附近，纠缠哈密顿量H_E = -ln(ρ_A)的谱应有非零虚部:
$$|\text{Im}(E_i)| \sim \alpha \cdot \text{Re}(E_i)$$

其中α ∼ |Im(g*)|/|Re(g*)|。测量纠缠谱的虚部可提取复FP距离。

**预测4: 与NH-Ising的定性差异**

NH-Ising属于BL AI类（有TRS但无赝厄米的非平凡q），或最多AI+η₊（对易子类，若其η在酉等价下可交换）。因此:
- NH-Ising: 允许实FP → 真连续相变可能 → 观测到的连续相变是真实的（非行走）
- NH-J-Q (Class 11): 禁止实FP → 只能"行走" → "准临界"行为，最终是一阶

这与已知文献一致: NH-Ising被多篇论文报告有真正连续相变，而NH-J-Q的一阶信号减弱但未消失。

### §5.3 与已有数据的比较

**Zou et al. (2025) ν收敛@δ=0.6**:

ν≈0.49(4)附近收敛与行走解释一致——不是收敛到真正的CFT值，而是有效指数在有限L下变化缓慢（因为ln(L)变化不大）。需要更大尺寸（L>256）才能看到ν_eff的漂移。

**"一阶强度减弱但未消失"**:

这正是GRZ框架的预测: 行走意味着逼近但不到达实不动点。在有限观察尺度上表现为近似标度不变性，但在足够大的尺度上，一级行为最终显现。

**NH-Ising对比**:

NH-Ising的真连续相变（被独立确认）支持我们的分类: 不同BL类→不同IR行为。如果所有NH系统都表现相同，BL分类将失去预测力。

**U1 (桥接假设的严格证明)**: BL随机矩阵谱性质→场论β函数的映射需要严格推导。可能的方向: 通过Wegner-Wilson精确RG方程或非微扰泛函RG（如LeClair 2025框架），建立ρ(0,y) ∼ |y|与β_I(x,0)的定量关系。

**U3 (AI+η₊ vs AI+η₋的场论区分)**: 对于对易子类的场论（例如NH变形中采用实η=σ^x而非iσ^x的系统），应明确展示β_I(x,0) = 0 → 允许实FP。构造这样的系统将是对本Phase结论的关键交叉验证。

**U4 (多耦合推广)**: 当前分析限于单NH耦合g。完整DQCP需要至少3个耦合(g, u, e²)的β函数系统。在多耦合空间中，{Q,C}=0约束可能产生更丰富的结构（如极限环）。

### §6.2 数值/实验未闭合

**U5 (LY零点直接测量)**: 在NH-J-Q模型的QMC中，测量复参数平面上的Lee-Yang零点分布，提取热力学极限下的虚部累积行为。

**U6 (纠缠谱虚部测量)**: 在DMRG/QMC中计算约化密度矩阵的本征值，检查是否有非零虚部（复FP的标志）。

**U7 (L>256的大尺寸模拟)**: Zou et al.的最大尺寸L=64（或128）。需要L>256来检测ν_eff的漂移（行走信号），但受限于NH系统的QMC符号问题缓解程度。
