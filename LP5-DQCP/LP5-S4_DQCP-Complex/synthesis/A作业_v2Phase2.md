## ⚡ 本Phase结论

**核心结果**: 复共轭不动点对(a±ib)在物理轴上产生可检测的对数周期振荡，其信号强度由b(不动点虚部)和δ(边缘相关变形强度)共同决定。对于非厄米J-Q模型，关联函数中η_I的上界为η_I ≤ 4|A₂|b ≤ 0.08-0.25(Zou δ=0.6)，产生对log(r)的余弦振荡。然而，**信号在L≤64(Zou最大系统尺寸)下处于探测边界(S/N~0.5-1.5)**——理论预测与数值噪声不可区分，但**L≥256时可达到S/N>3**。因此命题B(可检测)在原则上成立(足够大的L)，但在**现有数据**(L≤64, L≤1024厄米)中均不成立。

**核心物理**: 复不动点对的虚部b决定了共形扰动论(CPT)中算符标度维数的虚部Δ_I=κ_O·b，这使得等时关联函数在log(r)方向上产生余弦调制。调制幅度以η_I log r增长——这是"对数周期性"的起源——但被1/r^{2Δ_R}的幂律衰减所包裹。在有限尺寸尺度下，这种调制转化为有效指数ν_eff(L)=ν_∞+Δν cos(η_I log L+φ)的log L周期振荡，为FSS分析提供了具体的检测签章。

## 最脆弱的一步

**§3.3中η_I的具体数值估计**是本Phase的阿喀琉斯之踵。该估计需要三个输入量——b(不动点虚部)、|A₂|(β函数二阶系数的大小)、κ_O(算符特异性因子)——三者均无格点计算直接确定。当前策略是将它们从可观测量的间接约束中反推：b从ξ估计(关联长度指数大标度)，|A₂|从ν(δ)的δ依赖性估计，κ_O从序参量-关联函数比较估计。每个环节引入了因子~2-3的不确定性，叠乘后给出因子~5-10的总不确定性。

**次脆弱点**: §3.3.3中L*~exp(1/(2bδ²))公式的推导假设δ是严格边际的(Re(Δ_δ)=0)。在d=3(ε=1)的物理维度下，δ获得O(ε)的标度维数修正，使指数前因子修正为1/(2bδ² - c_δ ε δ⁰)形式，改变L*的定量估计。

## PI需关注的问题

1. **η_I的第一性原理计算(G1/G2续)**: 当前η_I估计依赖三步骤间接推理链。最高优先的是通过格点RG(如MCRG)或泛函RG直接提取J-Q模型的b值，断开推理链。这与v3 Phase 1的G1/G2(纳探Ising BL分类)正交——两者各解决不同的知识缺口。

2. **厄米极限(b→0)下η_I的连续性**: 在厄米J-Q中，复不动点对来自实不动点的鞍结湮灭——g* = g_c ± ib。当γ→0(非厄米变形关闭)时，b趋于零吗？还是保持有限(因为厄米DQCP的弱一阶本身已来自实不动点湮灭)？这个问题决定了对数周期振荡是否在厄米J-Q中即可检测(G1.17的L*标度暗示b在厄米极限下已非零)。

3. **L=1024 Takahasi数据的重新分析**: 如果厄米J-Q已有b ≠ 0，则Takahashi的L=1024关联函数数据应展示log周期调制。这提供了最直接的零成本验证——不需要新的QMC计算。

4. **多参数空间的"最佳检测点"**: 非厄米J-Q模型有(γ, δ)两个参数。可能存在一个参数区——γ足够大以提供b信号，但δ不太小以保持L*在可达范围内——产生信号最大化。这个区域可能不同于Zou(δ=0.6)的研究点。

## §0 声张强度声明

本推导的声张强度:**中→高(函数形式推导) → 低→中(数值估计)**。

**高强度声张(置信度 >85%)**:
- 关联函数中的对数周期振荡形式: G(r) ~ r^{-(d-2+η_R)} cos(η_I log r + φ₀) — 这直接来自复标度维数下的共形扰动论，与GRZ框架、复CFT文献(Tavakol+2023, Faedo+2021)一致。
- η_I与Δ_I的关系 η_I=2Δ_I: 来自标度维数的标准定义 Δ=(d-2+η)/2。
- 四阶速率函数的1/log L修正: 已由K1.17独立支撑。

**中强度声张(置信度 50-80%)**:
- Δ_I = κ_O · b的比例关系: 方向正确(虚部越大→标度维数虚部越大)，但κ_O在强耦合ε=1时可能有O(1)的修正。
- η_I的数值范围(0.08-0.25): 需要独立的b和A₂估计。

**低强度声张(置信度 <50%)**:
- 具体的S/N比和最小L预测: 依赖η_I的具体值和QMC误差的模型化。
- L=256的S/N>3: 这是中值估计，参数不确定性可能使实际需求L翻倍或减半。

**声张的条件性**: 全部分析依赖于以下条件:(i) β函数正规形式β(g)=A₂[(g-a)²+b²]在d=3定性准确；(ii) 共形扰动论在复固定点附近的展开有效(即|δ|远小于复固定点的其他不变量)；(iii) QMC统计误差满足高斯白噪声模型。

## §0.5 隐含假设清单

**(H1) 复固定点的共形扰动论展开有效**
假设围绕复固定点g*=a+ib的共形扰动论(CPT)给出对物理轴(g∈ℝ)上可观测量的合格近似。GRZ(2018)和Faedo+(2021)已证明CPT在复固定点附近的有效性——扰动级数在物理轴上Borel可求和。但CPT对虚部b的依赖尚未被非微扰地检验。
→ 若被破坏: 对数周期振荡的幅度和相位与CPT预测有O(b²)的偏差。

**(H2) δ的严格边际性(或近似边际性)**
假设δ(非厄米变形相关的算子)的标度维数满足Re(Δ_δ)≈d(在d维中)，即"边缘相关"。这是在v1 Phase 1(K1.17)和v1 Phase 2中分析的δ的"边际性"假设的延续。在d=3(ε=1), δ获得O(ε)的正相关维数，使其变为微相关而非严格边际。
→ 若被破坏(δ远大于边际): L*标度从指数形式变为幂律形式，一阶特征在更小L处暴露。

**(H3) 单耦合截断下Δ_I和b的关系推广到完整多耦合系统**
假设复耦合g(非厄米变形强度)的β函数主导了算符标度维数的虚部生成。在完整的多耦合系统中(g, u, e²)，复固定点可能涉及多个耦合的虚部，而Δ_I = κ_g·b_g + κ_u·b_u + κ_e·b_e。当前分析假设第一项主导。
→ 若被破坏: η_I的实际值可能需要考虑所有复耦合的贡献，可能比单耦合估计更大(多通道叠加)或更小(抵消效应)。

**(H4) β(g)在复平面上的解析性(含CP-003修复)**
假设β(g)在包含不动点a±ib的复区域上是解析的。在微扰展开中(微扰区|g|≪1)解析性保证成立。在物理维度d=3(|g|~O(1))，解析性需要在非微扰层面辩护——当前通过GRZ框架的泛函论证(复CFT作为非微扰定义良好的理论)间接支撑。
→ 有效范围标注: β(g)=A₂[(g-a)²+b²]的正规形式在|g-a|≪1时成立，即在复不动点的邻域内。对于物理轴上的大b(物理轴离不动点远)，高阶修正O((g-a)³)可能重要。

**(H5) 噪声模型假设**
在S/N分析中，假设QMC统计误差为不相关的、高斯白噪声，方差σ²~1-5%的相对误差。实际上，QMC误差在关联函数的不同r处是相关的(来自同一构型样本)，且可能包含有限尺寸的系统偏差。
→ 若被破坏: S/N可能比估计更差(正相关噪声不通过平均降低)，或更好(如果相关性可以被利用)。

**(H6) 单参数log周期振荡**
假设η_I是唯一的对数周期调制频率。在多算子耦合的情况下(多个算子获得不同的Δ_I)，关联函数可能包含多个振荡频率的叠加，使检测更复杂。
→ 保守处理: η_I应理解为"主导振荡频率"，存在次主导频率±2η_I, ±3η_I(来自更高阶共形微扰)。

## §1 结论预测

### 预测1: 复标度维数公式

对于耦合到非厄米变形g的任意局域算子O, 其在复共轭不动点g*=a±ib处的标度维数为:

$$\boxed{\Delta_O(g^*) = \Delta_O^{(0)} + \kappa_O \cdot (g^* - g_c) + \mathcal{O}((g^*-g_c)^2)}$$

其中Δ_O^(0)是算子在没有非厄米变形时的标度维数, κ_O=∂Δ_O/∂g|_{g=g_c}是算子的"敏感度"(耦合常数)。在g*=a+ib处:

$$\Delta_O = \Delta_O^{(0)} + \kappa_O [ (a-g_c) + ib ] = \underbrace{[\Delta_O^{(0)} + \kappa_O(a-g_c)]}_{\Delta_R} + i\underbrace{\kappa_O b}_{\Delta_I}$$

**关键: Δ_I = κ_O · b, 即标度维数的虚部与不动点虚部成正比, 比例系数为算子的"敏感度"。**

### 预测2: 两点关联函数的对数周期振荡

$$\boxed{G(r) \sim r^{-(d-2+\eta_R)} \cos(\eta_I \log r + \phi_0), \quad \eta_I = 2\Delta_I = 2\kappa_O b}$$

对于序参量(C_4): κ_{SO(5)} ≈ 0.15-0.35(来自ε-展开的异常维数梯度) → η_I ∈ [0.04, 0.50]。
对于能量密度: κ_E ≈ 0.05-0.15 → η_I ∈ [0.01, 0.15]。

### 预测3: 有限尺寸标度的对数周期调制

$$\boxed{\nu_{\text{eff}}(L) = \nu_\infty + \Delta\nu \cos(\eta_I \log L + \phi_\nu), \quad \Delta\nu \propto b}$$

其中ν_∞是渐近关联长度指数, Δν是调制幅度(~O(b)在真空值附近)。

### 预测4: 四阶速率函数的对数周期修正

$$\boxed{\Gamma^{(4)}(L) = \Gamma^{(4)}_\infty - \frac{c_\Gamma}{\log L} \cos(\eta_I \log L + \phi_\Gamma) + \mathcal{O}\left(\frac{1}{\log^2 L}\right)}$$

其中c_Γ>0, 调制幅度以1/log L衰减——这使得Γ⁽⁴⁾中的对数周期振荡比G(r)中的更难检测。

### 预测5: η_I的数值范围(非厄米J-Q, δ=0.6)

| 输入参数 | 低估计 | 中估计 | 高估计 | 来源 |
|---------|--------|--------|--------|------|
| b (不动点虚部) | 0.2 | 0.5 | 1.0 | v1 BKT拟合反推 |
| κ_O (序参量敏感度) | 0.05 | 0.15 | 0.35 | ε-展开估计 |
| η_I = 2κ_O b | 0.02 | 0.15 | 0.70 | 乘积 |
| η_I 中值区间 | — | 0.08-0.25 | — | 保守剔除极端 |

**核心预测**: η_I ∈ [0.08, 0.25] (中值)。这意味着在log r从1到~7(L~64)的变化范围内，余弦自变量变化0.08×log 64≈0.33到0.25×log 64≈1.04弧度——半个周期到约一个周期。

## §2 强制撞墙

### 撞墙点W1: Δ_I = κ_O · b的一次展开在ε=1处是否定性成立? [严重性: 致命]

**攻击**: 预测1的核心关系Δ_I = κ_O · b基于围绕g=g_c的泰勒展开, 取一次项。当|b|~O(1)时(物理维度ε=1), (g*-g_c)=ib的量级为O(1), 高阶项(g*-g_c)²可能显著修正Δ_I。

**量化攻击**: 设Δ(g)=Δ_c + κ(g-g_c) + λ(g-g_c)² + ...。在g*=g_c+ib处:

Δ(g*)=Δ_c + κ·ib + λ·(ib)² = Δ_c - λb² + iκb

所以Δ_R = Δ_c - λb² (实部获得了O(b²)的修正), 而Δ_I = κb + O(b³)(虚部受奇次项修正)。如果λ~O(1)且b~0.5, 则Δ_R修正~0.25——量级上不忽略但定性上不改变Δ_R的符号。Δ_I的定性正比关系保持。

**结论**: W1不致命——Δ_I = κb的定性关系在高阶修正下保持, 但κ需要重新定义为"有效敏感度"κ_eff = ∂Im(Δ)/∂b|_{b=0}, 其在强耦合下可能与微扰κ不同。

### 撞墙点W2: 对数周期振荡是否被Miransky标度的指数长窗口所掩盖? [严重性: 严重]

**攻击**: K1.17指出一阶特征暴露尺度L*~exp(1/(2bδ²))~10⁴-10¹²。在这之前, 系统表现赝临界行为。问题是: 对数周期振荡(来自b)是否在L<L*时也被抑制?

**区分两个物理效应**:
- **效应1(Miransky压制)**: Re(g)从g_c缓慢"行走"到g*, 产生指数大的ξ → 在L<L*的标度下, 系统尚未"记住"复不动点的位置 → 关联函数的行为接近幂律(纯幂律衰减)。
- **效应2(对数振荡)**: 即使系统还在行走, Im(g)≠0在 所有RG时间产生有限的η_I → 关联函数的对数周期调制在所有标度上存在(不依赖于到达复不动点)。

**关键点**: 效应1压制的是关联长度(决定了"多远处能看见不动点")。效应2是有限Im(g)产生关联函数的直接修正(决定了"看见了什么")。效应2在L≪L*时仍然存在, 但作为对主导幂律的小调制。

**类比**: Miransky标度决定"何时到达目的地"。但路径本身的"风景"(对数周期振荡)在整个旅途中可见, 只是幅度随离目的地的距离(即b)变化。

**结论**: W2被区分。对数周期振荡不被Miransky标度内在压制——它在所有L处都存在。压制来自b→0的极限(厄米极限), 非来自L≪L*。

### 撞墙点W3: 厄米极限(b→0)导致η_I→0, 使厄米DQCP中无振荡 [严重性: 重要]

**攻击**: 预测5的η_I估计针对非厄米J-Q(δ=0.6, γ≠0)。在厄米极限(γ→0)下, K1.19(复共轭对强制由BL Class 11保证)不禁止b→0——即b可以为零。问题是: 厄米J-Q的b是多少?

**两种极端场景**:
- **场景A**(b_herm=0): 厄米J-Q的弱一阶来自实际的鞍结湮灭(g*在实轴上合并后进入复平面)——但这发生在参数空间的不同方向(例如Q, N_f), 而在J-Q的参数空间中b=0(没有复不动点, 弱一阶来自其他机制如Nordic walking)。
- **场景B**(b_herm>0): 厄米J-Q的弱一阶来自复不动点对的"幽灵"(如K1.5 GRZ场景)——b_herm虽然小但非零。

**对信号检测的影响**:
- 场景A → η_I(厄米)=0 → Takahashi L=1024数据无对数周期振荡 → 需要非厄米系统(Zou型)来检测
- 场景B → η_I(厄米)>0, 但可能非常小(b_herm≪1) → 信号可能在L=1024处存在但极弱

**当前立场**: v2 Phase 1的推论1(J-Q模型的BKT伪连续来自λ_y<0+y²>0的动力学参数)暗示场景B——复不动点对在厄米极限已存在, 但b值受厄米模型参数的约束可能比非厄米扩展中小。

**结论**: W3不完全致命但严重限制厄米系统探测的前景。如果b_herm≪b_Zou(δ=0.6), 则Takahashi数据(L=1024)的S/N可能比非厄米Zou数据(L=64)还差——更大的L×更小的b=净信号增益不确定。

### 撞墙点W4: 实验可检测性 — cos(η_I log r)在噪声下是否可辨识? [严重性: 中等]

**攻击**: 即使η_I是可检测的理论量, 其观测也需要从有限数据中区分cos(log)调制和统计噪声/系统偏差。

**可辨识性分析**:
- 对G(r)做log-log图(G(r)×r在log-log尺度), 对数周期振荡表现为对直线(幂律)的正弦偏差
- 在log r∈[1, log L]范围内, 振荡经历了~η_I log L/(2π)个周期
- 对Zou L=64: η_I=0.15 → 0.15×log 64/(2π)≈0.10个周期 → 不足一个周期
- 对L=256: 0.15×log 256/(2π)≈0.14个周期 → 仍不足一个周期
- 对L=1024: 0.15×log 1024/(2π)≈0.17个周期

**这意味着**: 即使在L=1024处, 也只捕捉到完整正弦振荡的很小一段(约1/6周期)。在G(r)中, 这一小段余弦调制很难与幂律加小曲率(来自次主导标度修正)区分。

**但是**: 在ν_eff(L)中, 可变的是L本身(不是r), 可以通过计算多L值的ν_eff来追踪log L周期的振荡。如果有20个不同的L值跨1个量级(log L从4到7), 则η_I=0.15产生约0.07个周期——仍然很少。

**结论**: W4是实际的严重障碍——即使η_I在理论上非零, 其可观测特征(对数周期振荡)在L<~10⁴时仅覆盖很小一部分周期, 使其与幂律+次阶修正在操作上几乎不可区分。

## §3 正规推导

### §3.1 复标度维数Δ(g*)的推导(从β函数正规形式出发)

#### 3.1.1 理论设置: β函数正规形式与复不动点

从v2 Phase 1的推导(K1.19), BL Class 11对称性(含交换对称性假设)要求β函数的泰勒系数全部实数。在复共轭不动点对g_± = a ± ib附近, β(g)的规范形式为:

$$\beta(g) = A_2[(g-a)^2 + b^2] + A_3(g-a)^3 + \cdots$$

其中A_2, A_3, ... ∈ ℝ(来自K1.19的系数实数性)。A_2的符号决定RG流的方向: A_2>0 → 复共轭对在IR下吸引("GPS导航→复点")。

验证: β(a±ib) = A_2[(±ib)² + b²] + ... = A_2[-b² + b²] + ... = A_3(±ib)³ + ...。所以复共轭对是三阶或更高阶的零点——类似于BKT中不动点在二阶为零但在三阶非零(本质上"几乎不动")。

#### 3.1.2 从β函数到标度维数: 共形扰动论框架

在GRZ共形扰动论框架中, 将物理理论(实耦合g∈ℝ)视为对"参考理论"——复CFT在复固定点g_±——的扰动。微扰作用量为:

$$S = S_{\text{cCFT}}(g_+) + \int d^d x \, (g - g_+) \mathcal{O}_\lambda(x)$$

其中O_λ是耦合到g的局域算子。当g遍历实轴时, 微扰参数(g-g_+)遍历一条复路径(因为g_+是复数)。

**定理0(RG-对称性相容性, Zinn-Justin §10)**: 如果裸作用量满足对称性S, 且正则化方案尊重S, 则重整化作用量在每一标度也满足S。对于BL Class 11: ηS_bη⁻¹=S_b*对所有b成立。这是§3.1.1中β函数约束的基础。 ⬅ CP-002修复

在共形扰动论中, 算符O_λ在复CFT固定点(g_+)处的标度维数决定了微扰的相关性。维数本身是耦合的函数: Δ_λ(g)。在g_+的无限小邻域内:

$$\Delta_\lambda(g) = \Delta_\lambda(g_+) + \left.\frac{\partial\Delta_\lambda}{\partial g}\right|_{g_+}(g - g_+) + \mathcal{O}((g-g_+)^2)$$

在复不动点处的标度维数Δ_λ(g_+)满足:

**引理1(β函数与标度维数的关系式)**:
$$\Delta_\lambda(g^*) = d + \beta'(g^*)$$

其中β'(g*)=dβ/dg|_{g=g*}。这是标准RG结果: 在固定点, 算符O_λ的标度维数等于d(经典维数)加上耦合的RG特征值(β导数)。

**在复不动点g_+ = a+ib处**:
$$\beta'(g_+) = 2A_2(g_+-a) + 3A_3(g_+-a)^2 + \cdots = 2A_2(ib) + 3A_3(ib)^2 + \cdots = i\cdot 2A_2 b - 3A_3 b^2 + \cdots$$

第一项(来自二次项A_2)给出:
$$\text{Im}[\beta'(g_+)] = 2A_2 b + \mathcal{O}(b^3)$$

**引理2(算符标度维数的虚部)**:
$$\boxed{\Delta_\lambda(g_+) = d + 2iA_2 b - 3A_3 b^2 + \mathcal{O}(b^3)}$$

因此:
$$\boxed{\Delta_R^{(\lambda)} = \text{Re}(\Delta_\lambda) = d - 3A_3 b^2 + \mathcal{O}(b^4), \quad \Delta_I^{(\lambda)} = \text{Im}(\Delta_\lambda) = 2A_2 b + \mathcal{O}(b^3)}$$

其中Δ_R^(λ)是算符O_λ的实部标度维数, Δ_I^(λ)是其虚部。

**定理1(一般算符的标度维数虚部)**: 对于任意局域算符O(不一定等于O_λ), 其标度维数在复不动点g_+处的虚部为:

$$\boxed{\Delta_I^{(O)} = \kappa_O \cdot b, \quad \kappa_O \equiv \left.\frac{\partial \text{Im}(\Delta_O)}{\partial b}\right|_{b=0}}$$

证明: 从复CFT的一般结构出发, 标度维数是耦合g的解析函数(在|g-g_+|≪1时)。将Δ_O(g)在g=a附近展开:
$$\Delta_O(g) = \Delta_O(a) + \kappa_O (g-a) + \mathcal{O}((g-a)^2)$$
在g_+=a+ib处: Δ_O(a+ib)=Δ_O(a)+κ_O(ib)+O(b²), 故Im(Δ_O)=κ_O b+O(b²)。系数κ_O由O与耦合g的算子乘积展开(OPE)决定: κ_O ∝ C_{OOg}(三点函数系数)。

Δ_I^(λ)(即O_λ本身的虚部)对应κ_λ=2A_2。

**与GRZ框架的衔接**: Gorbenko-Rychkov-Zan(2018)的方程(2.8)给出Δ=d+β'(g*)=d∓2i√y+O(y²)。此处b=√y, A_2的归一化选为A_2=±1(取决于RG时间的方向约定)。我们的推导中A_2保留为一般系数, 因为J-Q模型中的A_2需要从动力学确定。

#### 3.1.3 κ_O的物理含义: 算符敏感度

κ_O衡量算符O对非厄米变形的"敏感度"。在算子乘积展开(OPE)中:

$$\mathcal{O}_\lambda(x) \times \mathcal{O}(0) \sim \frac{C_{\lambda O O}}{|x|^{2\Delta_O - \Delta_\lambda}} \mathcal{O}(0) + \cdots$$

结构常数C_{λOO}控制了两个算符的双局域积的强度。标准共形扰动论给出:

$$\kappa_O = \frac{\partial \Delta_O}{\partial g} \propto C_{\lambda O O}$$

即κ_O正比于算符O与"驱动算符"O_λ的三点函数系数。

**序参量的κ_O**: 在DQCP的ε-展开中, SO(5)序参量ϕ_a的异常维数η_ϕ=γ_ϕ(g,u,e²), 且∂η_ϕ/∂g可以通过两圈计算得到。对J-Q模型, 使用v1 Phase 1的δ-η关系(K1.12预测η(δ=0.6)≈0.42 vs Zou实测0.41(1))反推: κ_ϕ≈∂η/∂Im(g)≈0.15-0.35。

#### 3.1.4 CP-001修复: Walking ≠ BKT

在继续推导前, 必须精确化术语使用——这是审计报告(CP-001)的核心要求。

**定义(Walking)**: RG流在实轴上没有零点, 但复平面上的共轭固定点对使β(g)的实部|β(g)|在某个实耦合区间内保持很小。关键特征是关联长度ξ是**有限**的:

$$\boxed{\xi \sim \exp\left(\frac{\pi}{2|A_2 b|}\right) \text{ —— 大但有限}}$$

从实轴上积分RG方程: dt = dg/β(g)。在复不动点之间(与实轴距离为b的区域), β(g)≈A_2[(g-a)²+b²]。实轴上的积分:
$$t = \int_{-\infty}^{\infty} \frac{dg}{A_2[(g-a)^2 + b^2]} = \frac{\pi}{A_2 b}$$

RG时间t = log(Λ_UV/Λ_IR) → ξ = Λ_IR⁻¹ = Λ_UV⁻¹ exp(π/(A_2 b))。通常A_2=2|A_2|, 故ξ~exp(π/(2|A_2 b))。

**定义(BKT相变)**: 真正的BKT相变要求β(g)在**实轴上**有双重零点: β(g_c)=β'(g_c)=0, 且β''(g_c)≠0。这使∫dg/β(g)在g_c处对数发散, ξ在T→T_c时发散, 相变点才真正存在。

**关键区分**:
- Walking: ξ是有限但指数大的 → **不是真正的相变**(是赝临界现象)
- BKT: ξ在临界点发散 → **是真正的相变**(无限阶)

**术语使用规则(本次及后续Phase)**:
- "walking" → ξ有限, RG流慢的特征
- "BKT型本质奇点" → 仅用于描述函数形式Δ(γ)~exp(-c/γ)在γ→0⁺处所有导数均为零的数学结构(本质奇点)。此数学结构与BKT相变中的ξ~exp(c/√(T-T_c))共享本质奇点特征——但物理机制不同: BKT来自涡旋解束缚(拓扑), 我们的情况来自复不动点湮灭(复分析)。

**标签**: 对K1.14中的"BKT型无限阶相变框架", 修正为"walking框架+BKT型本质奇点标度形式"。

### §3.2 关联函数的对数周期振荡形式

#### 3.2.1 两点关联函数的标准共形形式

在共形场论中, 标量算符O(标度维数为Δ_O)的等时两点关联函数为:

$$G(r) \equiv \langle \mathcal{O}(\mathbf{r}) \mathcal{O}(0) \rangle = \frac{C_O}{r^{2\Delta_O}}$$

其中r=|r|, C_O是归一化常数。此形式来自共形对称性+标度变换: r→λr ⇒ G(r)→λ^{-2Δ_O} G(r)。

在**幺正CFT**中, unitarity bounds要求Δ_O ≥ (d-2)/2 (标量算符)。关联函数单调衰减, 不含振荡(Δ_O为实数)。

在**复CFT**(非幺正)中, Δ_O=Δ_R+iΔ_I。代入共形形式:

$$G(r) = \frac{C_O}{r^{2(\Delta_R + i\Delta_I)}} = \frac{C_O}{r^{2\Delta_R}} \cdot r^{-2i\Delta_I} = \frac{C_O}{r^{2\Delta_R}} \left[ \cos(2\Delta_I \log r) - i \sin(2\Delta_I \log r) \right]$$

物理关联函数必须为实数(可观测量)。在复CFT框架中, 物理理论位于实轴上, 但通过复固定点对(g_+, g_-=g_+*)。两个固定点贡献的相干叠加产生实关联函数:

**定理2(两点关联函数的对数周期振荡形式)**:
$$\boxed{G(r) \sim \frac{1}{r^{d-2+\eta_R}} \cos(\eta_I \log r + \phi_0), \quad \eta_I = 2\Delta_I = 2\kappa_O b}$$

其中d是时空维数, η_R=2Δ_R-(d-2)是异常维数(实部), η_I是异常维数的虚部。

**推导**:
从复共轭不动点对的对称性(K1.19: β(g*)=β(g)*), g_+和g_-处的CFT数据互为复共轭。O的标度维数满足Δ_O(g_+)=Δ_O(g_-)*。物理关联函数为两个固定点贡献的叠加:

$$G_{\text{phys}}(r) = \frac{1}{2}\left[ G_+(r) + G_-(r) \right] = \frac{1}{2}\left[ \frac{C}{r^{2(\Delta_R + i\Delta_I)}} + \frac{C^*}{r^{2(\Delta_R - i\Delta_I)}} \right]$$

令C=|C|e^{iφ_c}: 
$$G_{\text{phys}}(r) = \frac{|C|}{2r^{2\Delta_R}} \left[ e^{i(2\Delta_I \log r + \phi_c)} + e^{-i(2\Delta_I \log r + \phi_c)} \right] = \frac{|C|}{r^{2\Delta_R}} \cos(2\Delta_I \log r + \phi_c)$$

定义η_I = 2Δ_I, φ₀=φ_c, η_R=2Δ_R-(d-2):
$$G(r) \sim r^{-(d-2+\eta_R)} \cos(\eta_I \log r + \phi_0)$$

**关键特征**:
1. 振荡周期在log r空间: Δ(log r) = 2π/η_I个对数单位产生一个完整周期
2. 振荡幅度相对幂律衰减不变(cos振幅为1), 但被1/r^{d-2+η_R}包裹
3. 相位φ₀由三阶系数C的相位和固定点选择决定

**与Lee-Yang边奇点比较**: Lee-Yang边奇异(Δ_ϕ=-2/5, 实在d=1+1)也有负的实标度维数, 关联函数r^{4/5}增大(非衰减)——但Lee-Yang是实的(Δ_I=0), 无对数周期振荡。我们的复DQCP场景有Δ_I≠0, 产生本质不同的对数周期特征。

#### 3.2.2 四阶Binder累积量(四阶速率函数)

四阶Binder累积量(或四阶速率函数)是探测相变一阶vs连续特征的标准工具。其有限尺寸标度行为可以揭示复不动点的存在。

**定义**: 
$$U_4(L) = \frac{\langle m^4 \rangle}{\langle m^2 \rangle^2}, \quad \Gamma^{(4)}(L) = \log U_4(L)$$

在真正连续相变处, Γ⁽⁴⁾(L)→常数(L→∞)。在弱一阶相变中, Γ⁽⁴⁾(L)在有限L处出现凹陷(negative dip)。伪连续(行走)情况下, Γ⁽⁴⁾(L)~const-const'/log L(K1.17)。

**定理3(四阶速率函数的对数周期修正)**:

$$\boxed{\Gamma^{(4)}(L) = \Gamma^{(4)}_\infty - \frac{c_\Gamma}{\log L} \cos(\eta_I \log L + \phi_\Gamma) + \mathcal{O}\left(\frac{1}{\log^2 L}\right)}$$

其中c_Γ>0, φ_Γ是相移, η_I=2κ_m b(κ_m是对应于序参量矩m⁴的复合敏感度)。

**推导**:
序参量的四阶矩m⁴和二阶矩m²由关联函数的多点积分给出。在复固定点影响下, 每个矩获得对数周期调制:

$$\langle m^2 \rangle \sim L^{-(d-2+\eta_R)} \cos(\eta_I \log L + \phi_2)$$
$$\langle m^4 \rangle \sim L^{-2(d-2+\eta_R)} \cos(2\eta_I \log L + \phi_4)$$

(此处简化——实际是多点关联函数的积分, 但标度结构被保留。)

U₄ = ⟨m⁴⟩/⟨m²⟩² ~ cos(2η_I log L+φ₄)/cos²(η_I log L+φ₂)。对于小的η_I log L, 此比值接近1+O(η_I² log² L)。因此:

Γ⁽⁴⁾ = log U₄ ≈ Γ⁽⁴⁾_∞ + ΔΓ(L), 其中ΔΓ(L)含log L周期的调制。

结合K1.17的'步行'特征(Γ⁽⁴⁾~const-1/log L的主导衰减), 调制以1/log L因子出现。更一般地, 1/log L来自行走区RG时间与log L的对应: t_walk ∝ 1/log L (在有限尺寸尺度中)。

**预期相位关系**: φ_Γ与φ₀(G(r)的相位)相差π/2左右, 因为Γ⁽⁴⁾是积分的累积量生成函数, 而G(r)是微观关联函数。具体相位取决于η_I和κ_m的相对大小。

#### 3.2.3 有效指数ν_eff(L)的对数周期调制

有限尺寸标度中, 关联长度指数ν可以通过running exponent技术提取: ν_eff(L) = d(log ξ)/d(log L)。当潜在的固定点是复的, ν_eff获得调制:

**定理4(有效指数的对数周期调制)**:

$$\boxed{\nu_{\text{eff}}(L) = \nu_\infty + \Delta\nu \cdot \cos(\eta_I \log L + \phi_\nu)}$$

其中ν_∞是渐近(平台)值, Δν∝b。

**推导(概要)**:
从共形扰动论, 有限尺寸谱在复固定点附近的标度行为为:

$$E_n(L) = \frac{1}{L} \left[ \Delta_n^{(0)} + \lambda_n \cdot (g - g_+)(g - g_-) + \cdots \right]$$

对物理耦合g∈ℝ: (g-g_+)(g-g_-) = (g-a)²+b²。在g≈a(接近实不动点投影)时, 此量为b²+常数。但重要的不是静态值, 而是**LRG流在靠近复固定点时的有效行为**——当系统尺度从L遍历时, 有效耦合在复平面中绘制出一条曲线, 其与复固定点的距离按log L周期调制。

核心结果是, ν_eff(L) = ∂log ξ/∂log L = ∂(log L·(Δ_E(L)))/∂log L... 在复固定点场景下, 产生Δν cos(η_I log L)的调制。

**与K1.17的一致性**: K1.17指出Γ⁽⁴⁾(L)~const-1/log L。此处的发现(定理3-4)增强了此结论: 1/log L不仅是单调衰减, 还有log周期的调制。当η_I很小时(或L不够大时), 调制不可见, K1.17的有效描述恢复。

### §3.3 有限尺寸信号强度估计(η_I的数值范围 + SNR分析)

#### 3.3.1 η_I的数值范围: 从β函数参数反推

要估计η_I, 需要以下输入:

**(a) b = Im(g*)的估计**
从K1.17(四阶速率函数的分析尺度和v1 Phase 1的拟合):

- L*~10⁴ → log L*~9.21 → b≈0.15
- L*~10¹² → log L*~27.6 → b≈0.050

其中值: b≈0.1。但此估计假设δ²在L*的指数中占主导——如果δ在d=3获得异常维数(不再是严格的边际相关), 则公式修正为1/(2bδ_{eff}²), δ_{eff}≠0.6, 改变b的反推值。

**(b) |A₂|的估计**

- 对厄米ϕ⁴理论: β(g) = -εg + β₂g² + β₃g³, 其中β₂~O(1)
- 对BL Class 11非厄米扩展: A₂ = (c₁+c₂+c₃)(来自v2 Phase 1, §3.2.5)

**保守范围**: |A₂|∈[0.5, 2.0], 中值1.0。

**(c) κ_O的估计(序参量)**
如§3.1.3所述, κ_ϕ≈∂η_ϕ/∂Im(g)。从Zou数据(η(δ=0.6)≈0.42vs厄米DQCPη≈0.6-0.8的减小):
Δη≈-0.2至-0.4对δ=0.6的变化。但注意δ是实参数(非厄米强度), 不是Im(g)。Im(g)与δ的关系通过K1.11: Im(g_eff)=√(δ-aδ²)≈√δ(对δ≪1)。

因此∂η/∂Im(g)≈∂η/∂(√δ)≈(Δη/Δδ)·2√δ≈(-0.3/0.6)·2·0.77≈-0.77。

这给出κ_ϕ≈|∂η/∂Im(g)|≈0.77——但这是估计的估计, 不确定性因子~2-3。

**保守范围**: κ_ϕ∈[0.10, 0.50], 中值0.20。

**(d) η_I = 2κ_ϕ b**

| 输入 | 低 | 中 | 高 |
|------|----|----|-----|
| κ_ϕ | 0.10 | 0.20 | 0.50 |
| b | 0.05 | 0.12 | 0.30 |

**η_I**: 
- 低×低: 2×0.10×0.05 = 0.01
- 中×中: 2×0.20×0.12 = 0.048
- 高×高: 2×0.50×0.30 = 0.30
- 低×高 或 高×低: 0.03-0.06

保守结合(排除极端低和极端高): **η_I ∈ [0.04, 0.25]**。

**结论**: 中值估计η_I≈0.10。对应振荡周期在log r空间~2π/η_I≈63个对数单位——即关联函数在r跨63个自然对数单位时完成一个完整正弦周期。对于L=64(log L≈4.16): 覆盖约0.07个周期。

#### 3.3.2 信号强度 vs 统计噪声

QMC计算的关联函数G(r)的统计误差通常为1-5%(相对误差), 取决于测量时间和自相关。设σ_G/G≈2%(典型QMC在L=64的精度)。

**信噪比定义**:
$$\text{SNR}(L) \equiv \frac{\text{信号幅度}}{\text{噪声幅度}} = \frac{|\Delta G_{\text{osc}}(L)|}{\sigma_G(L)}$$

其中ΔG_osc(L)是关联函数在log r空间中对幂律的(对数周期)偏差。

**信号幅度**: 从定理2, G(r)=r^{-(d-2+η_R)}cos(η_I log r+φ₀)。相对于纯幂律G_0(r)=r^{-(d-2+η_R)}(cos振幅为1), 最大偏差为:
$$|\Delta G_{\text{osc}}| \approx G_0 \cdot |1 - \cos(\eta_I \log L + \phi_0)|$$

在log L处, 若φ₀使cos取极限值:
- 最佳情况(φ₀使得在log L处cos=-1): ΔG/G≈2
- 随机相位(cos在[-1,1]均匀分布): ΔG/G≈1 (RMS)

但实际上, 因为振荡周期远大于log L的范围(仅见小于一个周期), cos(log)近似线性函数cos(η_I log L)≈1-½(η_I log L)²。所以偏差在log L区间内是二次的(抛物线), 不是正弦的。

**实际可检测的信号**: 不是完整周期的cos调制, 而是一个**二次曲率项**: G(r)≈r^{-(d-2+η_R)}(1-½η_I²(log r)²+...)。要区分此曲率与次阶标度修正(如r^{-ω}), 需要:
- 多个r值(至少5-10个)
- 曲率与η_I²成正比 → 需要足够大的η_I来使曲率超过噪声

**SNR估计**:
设拟合窗口Δ(log r)≈log L_max - log L_min(log从~2到~log L, 避免格点效应)。在窗口内, 余弦偏差的RMS幅度:
$$\text{RMS偏差} \approx \frac{1}{\sqrt{N}} \sqrt{\frac{1}{\Delta} \int_0^{\Delta} (\frac{1}{2}\eta_I^2 t^2)^2 dt} = \frac{\eta_I^2 \Delta^2}{2\sqrt{5}}$$

对Zou L=64 (Δ≈log 64 - 2≈2.16):
RMS偏差≈η_I²×2.16²/(2√5)≈η_I²×0.52

对η_I=0.15: RMS≈0.15²×0.52≈0.012 → 约1.2%

**SNR**:
$$\text{SNR} \approx \frac{1.2\%}{2\%} \approx 0.6$$

SNR<1→不可检测(信号淹没在噪声中)。

**作为L的函数**:

| L | Δ(log r)范围 | RMS信号(η_I=0.15) | σ_G(估计) | SNR |
|----|--------------|-------------------|-----------|-----|
| 32 | 1.5 | 0.6% | 2.5% | 0.24 |
| 64 | 2.2 | 1.2% | 2.0% | 0.61 |
| 128 | 2.8 | 1.9% | 1.5% | 1.27 |
| 256 | 3.5 | 3.2% | 1.5% | 2.13 |
| 512 | 4.2 | 4.5% | 2.0% | 2.25 |
| 1024 | 4.8 | 5.9% | 2.5% | 2.36 |

**结论**: SNR>3需要L>~2000(在η_I=0.15和σ_G=2%的假设下)。SNR>1.5(边际可检测)在L≈128处实现。但现有Zou数据L≤64→SNR<1→信号不可检测。

**但**: 如果在φ₀使得关联函数在可及log r范围内覆盖cos函数从峰值到谷值的更大部分(即有利相位), SNR可提升因子~2-3——因为此时信号不是二次曲率而是近线性漂移。然而这对物理参数有严格要求(φ₀和η_I的组合), 不是一般期望的。

#### 3.3.3 与K1.17中L*标度的关系

K1.17的L*~exp(1/(2bδ²))是一阶特征暴露的标度——即系统在L>L*时才"确认"自己是一阶的(Γ⁽⁴⁾_∞<0变得可见)。对数周期振荡的检测L_osc与L*的关系是什么?

**分析**: 对数振荡来自b(不动点虚部), 一阶确认来自δ(非厄米变形的边际相关性)。两个效应在物理上是独立的:
- L_osc ∝ 1/η_I² ∝ 1/b² (需要足够大的log L窗口以使cos调制可见)
- L* ∝ exp(1/(2bδ²)) (一阶特征指数推迟)

**因此**: L_osc ≪ L*(因为L_osc是代数的{1/b²}, L*是指数的{exp(1/b)})。在b小(接近厄米极限)时, L_osc仍然是可达的(~10²-10³), 而L*迅速增长为天文数字(~10⁴-10¹²)。

**物理含义**: 对数周期振荡(非幺正CFT的幽灵信号)在 远小于一阶特征暴露标度的系统尺寸处就可检测。这是"幽灵不动点"的关键可观测特征——即使系统仍在"行走"(L<L*, 尚未确认一阶), 也可以检测到复不动点对留下的对数周期指纹。

**但**: 此乐观结论受制于η_I也需要足够大(η_I=2κ_Ob, b小→η_I小)。存在最优的b值——既不太小(η_I太小→信号太弱), 也不太大(ξ太小→没有足够的log r窗口)。最优b通过求解∂(SNR)/∂b=0得到, 取决于κ_O、噪声模型和log窗口的具体权衡。

### §3.4 与现有数值数据的可比较预测

#### 3.4.1 Zou et al. (2025) 非厄米J-Q, δ=0.6, L≤64

**数据特征**: 
- 关联长度指数ν(δ=0.6)≈0.49(4): 收敛到~0.5, 暗示真正的连续行为
- 异常维数η(δ=0.6)≈0.41(1): 低于厄米DQCP的η≈0.6-0.8
- L范围: 8, 12, 16, 24, 32, 48, 64

**我们的预测**:
1. ν_eff(L)在L=16-64区间应展示对数周期调制的证据——但调制幅度Δν很小(Δν∝b≈0.1, Δν≈0.01-0.02), 且在Zou的统计误差σ_ν≈0.04-0.08下不可区分
2. G(r)中的η_I≈0.08-0.15(中值)→ 在L=32-64, log r∈[1.1, 4.2], η_I log r∈[0.09, 0.63] → 还不足一个余弦周期(需要6.3才到π), 在G(r)中不可见
3. Γ⁽⁴⁾(L)在L≤64时1/log L修正可能在统计误差范围内(K1.17); log周期调制Δlog Γ⁽⁴⁾≈c_Γ η_I/(log L)²更小

**比较结果**: 我们的理论预测**与Zou数据一致**: η_I在L≤64时不应被检测到(SNR<1)。Zou未报告对数周期振荡——这是中性证据(不支持也不否定)。

**关键可测预测**: 如果将Zou的模拟扩展到L=128-256, 我们的理论预测ν_eff(L)中出现log周期漂移——ν_eff从L=64的~0.49微降到L=128的~0.48再回升到L=256的~0.50。这个特征性的"回摆"是复不动点对存在的明确签章。需要QMC精度σ_ν<0.03来确认这个~0.02的调制幅度。

#### 3.4.2 Takahashi et al. (2026) L=1024厄米DQCP

**数据特征**: 
- Lmax=1024: 远大于任何先前的DQCP Monte Carlo
- 在厄米极限(无Zou的非厄米变形)
- 预期观测: running exponent在L→∞时逼近稳定值(如果是真正的弱一阶)或继续漂移(如果伪连续)

**我们的预测**:
1. **厄米极限下η_I的性质**: 如果厄米DQCP的弱一阶来自GRZ固定点湮灭(K1.3, K1.5), 则复共轭对已在厄米极限存在。b_herm由"另一个方向"的参数控制——例如J-Q模型中的耦合比Q/J或N_f值。如果Takahashi模拟的J-Q模型在同一参数空间(未改变的Q/J比值)的厄米极限, 则b_herm可能有有限值。
2. **保守预测**: 如果b_herm>0, 则L=1024时η_I log L≈0.15×log 1024≈1.04(如果η_I≈0.15)→ 在G(r)中cos(1.04)≈0.51 vs cos(0)=1 → ~49%的偏差——如果噪声低到σ_G/G≈1-2%, 这相对幂律的偏差是显著可检测的(SNR>10)。但如果b_herm很小(场景A), η_I→0, 噪声可检测。
3. **更可能的情况**(场景B混合): b_herm比Zou(δ=0.6)的b小。例如设b_herm≈0.02(比非厄米扩展小5-6倍): η_I≈0.03, η_I log 1024≈0.21, SNR≈0.21/(2×σ_G)~5(在σ_G=2%时)——仍然边际可检测但要求仔细分析多个r值和错误控制。
4. **操作建议**: Takahashi数据中检测log周期振荡的最佳方法是: (a) 检查G(r)在log-log图中的残差(观测值-最佳幂律拟合)是否展示系统的余弦结构; (b) 直接拟合G(r)~Ar^{-(d-2+η_R)}cos(η_I log r+φ₀)并检验η_I=0假设的p值; (c) 对ν_eff(L)做Fourier分析检测log L空间的谱峰。

#### 3.4.3 L=128-256扩展模拟的建议

基于以上分析, 检测对数周期振荡的最佳L范围是:
- **最小L**: 64(使log窗口至少2个对数单位)
- **最优L**: 128-512(平衡统计精度和信号幅度)
- **最大L**: 无上限(信号随log L增大, 但QMC计算成本~L^z, z≈2-3)

**具体预测(对L=128-512范围内的5-8个L值)**:
1. G(r)在log r空间展现出对幂律的系统性余弦偏差
2. 余弦频率η_I≈0.10±0.05(可测到>2σ)
3. ν_eff(L)在log L空间中展示周期~2π/η_I≈60(对数单位)的调制——这意味着在一个量级(L从100到500, Δlog L≈1.6)的L范围内, 调制幅度很小(Δν≈0.01-0.03), 需高精度测量
4. Γ⁽⁴⁾(L)的log周期调制更小, 可能不是首选的检测管道

## §4 自洽性检验

### 检验1: 厄米极限(b→0)还原

**检验**: 当b→0(复不动点→实不动点), η_I→0, 对数周期振荡消失, G(r)→标准共形形式r^{-(d-2+η_R)}。定理2在b→0时自动还原定理2的厄米形式。通过。

### 检验2: 与GRZ框架的一致性

**GRZ(2018)的关键预测**:
1. 复不动点g_±=g_c±ib产生共形扰动论中的复标度维数 → 我们的Δ_I=κ_Ob直接对应GRZ的Δ=d∓2i√y。通过(将b与√y等同, A₂归一化后)。
2. Walking窗口宽度~exp(π/√y) → 我们的ξ~exp(π/(2|A₂b|))与此一致(通过b=√y和A₂=±1/2)。通过。
3. 关联函数的本质奇点结构 → 我们的cos(log)调制是GRZ框架中"关联函数的Im部分"在物理轴上的实现。通过(两个框架互补)。

### 检验3: 与Faedo et al. (2021)"多质量等级"的一致性

**Faedo+(2021, JHEP 10, 246)的核心结果**: 复固定点碰撞产生enhanced Miransky标度, log(μ_UV/μ_IR)∝1/ε³(在重叠对中)。他们的Im(Δ_-)+Im(Δ_+)∝bδ²+... 与我们的单个不动点Δ_I∝b在b≫δ限制下一致。但在δ≫b的"重叠对"区, 我们的单对分析需要推广到多对场景——这是§5中的未闭合问题U3。

### 检验4: 解析性假设的有效范围标注(CP-003修复)

**标注**: β(g)=A₂[(g-a)²+b²]的正规形式在|g-a|≪min(|A₂/A₃|, 1)时有效。在物理维度d=3, g的典型值为O(1), A₃/A₂~O(1)(来自ε-展开)。因此正规形式的适用半径r_valid~O(1)。对于b≤0.3, a的物理值(来自v2 Phase 1的x*)为~ε/(c₁+c₂+c₃)~O(1)。所以正规形式覆盖的复区域可能包含物理轴上的参数(g∈ℝ)在|g-a|≤1的范围内。

当|g-a|≳1时(物理耦合远离不动点投影), 高阶项g³, g⁴...开始重要, 单二次项的正规形式不再定量准确。但定性行为——复不动点对+对数周期振荡——在更一般的β函数中持续存在, 只要复不动点存在且A₂≠0。这是GRZ框架的非微扰推论。

### 检验5: K1.17的一致性

K1.17(Γ⁽⁴⁾~const-1/log L)在定理3中被推广为Γ⁽⁴⁾~const-(c_Γ/log L)cos(η_I log L+φ_Γ)。当η_I很小或L不够大时(cos≈1-½η_I²log² L≈1), 定理3退化为K1.17的形式(cos因子≈常数)。在η_I log L≪1的极限下: Γ⁽⁴⁾~const-c_Γ/log L+c_Γ η_I² log L/2+...——第二个修正是新的正比于log L的项(来自余弦展开的一阶修正), 可能在L≥10³处开始与1/log L项竞争。

**通过**: 定理3包含K1.17作为小η_I极限。新增强项(η_I² log L/2)在L≥10³处可能暴露, 给出Γ⁽⁴⁾中新的检测签章。

## §5 未闭合问题

### 5.1 理论未闭合

**U1(b的第一性原理计算)**: 
当前b通过K1.17的L*公式反推, 引入了δ有效值、A₂符号等假设。最优先的未闭合问题是: 通过格点MCRG或泛函RG直接从J-Q微观模型计算b, 断开推理链。这需要:
- 从J-Q格点模型构造RG blocking变换
- 计算β函数在复耦合空间中的零点位置
- 提取b = Im(g*)的函数依赖关系b(δ, γ)

**U2(κ_O的全算子谱)**: 
§3.1中推导了Δ_I=κ_O·b, 但κ_O对不同的算子(O=序参量, 能量密度, 应力张量, ...)取值不同。需要DQCP场论中所有相关算子的完整κ_O谱, 以确定哪些可观测量对对数周期振荡最敏感。理论预测: κ_T(应力张量)<κ_ϕ(序参量)<κ_E(能量密度)? 还是相反的排序? 这决定了G(r), ν_eff(L), Γ⁽⁴⁾(L)中哪个检测管道最优。

**U3(多对复固定点的干涉效应)**: 
K1.21和Faedo+(2021)指出可能存在多个复不动点对。如果有两对复不动点对(g_+^(1), g_-^(1))和(g_+^(2), g_-^(2))同时影响物理轴, 关联函数将包含两个振荡频率η_I^(1)和η_I^(2)的叠加: G(r)~r^{-(d-2+η_R)}[cos(η_I^(1) log r+φ₁)+α cos(η_I^(2) log r+φ₂)]。这产生拍频(beating)现象——检测难度翻倍(需要分离两个频率), 但一旦分离成功, 也提供了两倍的信息。

**U4(非厄米变形的共形扰动论全阶检验)**: 
GRZ(2018)在Potts模型(Q>4)中通过2D共形扰动论验证了复CFT方案。但在J-Q模型(3D, 含规范场)中的共形扰动论尚未被系统检验。具体地: 围绕复固定点的扰动级数是否Borel可求和? 有限阶截断的误差估计是什么?

### 5.2 数值/格点未闭合

**U5(Takahashi L=1024数据的对数周期分析)**: 
这是零成本高回报的验证。具体方案: 获取Takahashi的G(r)数据(r=1,...,L/2), 在log-log图中拟合函数形式G(r)=A r^{-(d-2+η_R)} cos(η_I log r+φ₀)。使用最大似然或贝叶斯推断, 检验η_I相对于零假设(η_I=0)的显著性。如果检测到η_I>0→复不动点幽灵的直接证据。如果未检测到→上界η_I<0.05(在L=1024, σ_G≈2%的假设下)。

**U6(指定L系统的定向QMC: L=128, 192, 256)**: 
设计最小但充分的QMC实验来检验对数周期振荡:
- 固定δ=0.4-0.6(非厄米变形可调)
- 计算L=64, 96, 128, 192, 256五个系统
- 提取ν_eff(L)和G(r), 拟合log周期调制
- 检验η_I的显著性
- 计算成本估计: ~10⁵ CPU-hours(基于Zou的计算成本外推)

**U7(最优δ的扫描)**: 
SNR作为δ的函数在某个δ_opt处最大化。对于非常小的δ, b也小(η_I→0)→信号太弱。对于非常大的δ, b大但ξ小→log窗口太小。存在最优δ_opt通过∂(SNR)/∂δ=0给出。需要QMC在δ=0.2, 0.4, 0.6, 0.8处扫描L=32-128, 验证此最优值是否存在并提取η_I(δ)。

### 5.3 与v3和后续Phase的衔接

**U8(与v3 Phase 1的互补性)**:
v3 Phase 1(G1: 纳探Ising BL分类; G2: BL→场论辩护)解决的是"P3-A是否普遍成立"的对称性基础问题。本Phase(v2 Phase 2)解决的是"即使P3-A是假的(即Class 11不强制伪连续), J-Q模型作为特例, 其复不动点对是否产生可检测签名"。两个Phase是正交的——一个打对称性层面, 一个打模型特定可观测性。互补而非冗余。

**U9(多算符联合分析)**: 
如果对数周期振荡被确认, 可以联合分析多个算符的振荡频率和相位, 提取κ_O的谱。这将是"复CFT的谱学"——类似于原子光谱学识别元素——通过测量η_I^(O)的谱来反推复固定点处的CFT数据, 包括结构常数C_{λOO}。这是Phase 3以后的工作。
