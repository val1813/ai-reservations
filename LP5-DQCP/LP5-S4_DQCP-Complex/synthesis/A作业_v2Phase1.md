## ⚡ 本Phase结论

**核心结果**: BL Class 11 对称性**强制**β-函数的全阶展开系数满足厄米约束 $c_{mn}=c_{nm}^*$，在交换对称性成立时所有系数退化为**实数**。由此：(i) 非实不动点必然以复共轭对形式出现(配对性强制)；(ii) 实不动点(y=0)在任何阶都是β(g)=0的合法解(因为 $\beta_I(x,0)\equiv 0$)，对称性**不禁止**真正的连续相变。

**因此: P3-A(伪连续性是BL Class 11的普遍特征)被否定。** 复共轭不动点对的出现是模型特定的动力学结果——取决于实不动点在虚部方向上的稳定性特征值 $\lambda_y$ 的符号，以及非厄米变形算子的η-等价类(对角 vs 非对角)。

| 结论项 | 判定 | 论证位置 |
|--------|------|----------|
| 复共轭对**配对性** | 对称性强制的 | §3.5 定理1 |
| 复共轭对**存在性** | 模型特定的 | §3.5 定理2 |
| J-Q模型的BKT伪连续性 | 模型特定的动力学 | §3.5 推论1 |
| 真正连续DQCP的可能性 | 对称性允许 | §3.5 推论2 |

## 最脆弱的一步

**§3.3中"交换对称性 $\tilde{\beta}(g_1,g_2) = \beta(g_2,g_1)$"的假设**是本推导的阿喀琉斯之踵。此假设要求非厄米变形算子对 $(O_1, O_2)$ 在有效作用量中以完全对称的方式出现——相同规范场耦合、相同异常维数。若 $O_1$ 和 $O_2$ 在UV完成中有不对称的耦合(例如其中一个涉及拓扑项而另一个不涉及)，则交换对称性被破坏，$c_{mn}$ 可为复数，单个复不动点(非共轭对)成为可能。

**次脆弱点**: η=R_x(π) 在强耦合下的重正化。η定义为格点旋转变换，在场论极限下是刚性全局变换。若非厄米变形在IR下引发η的"流动"(即η变为标度依赖的 $\eta(\mu)$)，则 $\beta(g^*)=\beta(g)^*$ 的推导需要修正。在当前微扰框架内此效应不存在，但在强耦合DQCP区域($\varepsilon=1$)不可忽略。

## PI需关注的问题

1. **算子谱的η-分类(最优先)**: J-Q模型的非厄米变形属于类型N(η-非对角)。是否存在自然的类型D变形(η-对角)在格点上可实现? 这需要DQCP场论中所有相关算子的O(3)×η表示论分析。

2. **实不动点稳定性的符号问题**: λ_y的符号决定了实不动点是完全吸引子还是鞍点。在物理维度d=3($\varepsilon=1$)下，高圈修正是否可能改变λ_y的符号? 这需要具体的多圈计算。

3. **η的重正化**: 在非微扰层面，η=R_x(π)是否保持为精确的刚性对称性? 还是会在强耦合下获得异常维数? 这是开放的理论问题，影响全阶论证的有效性。

4. **规范场混合效应**: 完整DQCP包含规范场耦合e²。规范场-物质混合β函数系统可能产生仅在本推导的单耦合截断中不可见的新不动点结构。

## §0 声张强度声明

本推导的声张强度:**高(数学推导) → 中(物理诠释) → 低(数值预测)**。

**高强度声张(置信度 > 90%)**:
- β函数系数的厄米约束 $c_{mn}=c_{nm}^*$: 严格的对称性论证，在交换对称性和赝厄米性同时成立的条件下对所有阶有效。
- 非实不动点的复共轭成对性: 系数的实数性直接导致这一结果。
- 实不动点的存在性: $\beta_I(x,0)\equiv 0$ 是精确的(来自 $f_2$ 的y-奇性)，不受微扰阶数影响。

**中强度声张(置信度 60-80%)**:
- 实不动点的稳定性分类(λ_y符号): 单圈计算在ε=1时定性可靠，但符号可能被高圈修正翻转。
- 复共轭不动点对的存在条件(y²>0): 同样依赖微扰系数的具体值。

**低强度声张(置信度 < 50%)**:
- 具体的数值预测(如J-Q模型中λ_y的精确值): 需要完整的RG计算，本推导仅给出符号分析框架。
- 格点实现的具体建议: 场论分析→格点模型之间存在UV-IR映射的不确定性。

v1的边界型定理(J-Q模型的DQCP不是真正连续的)在此**不被推翻**——该结论是针对J-Q模型的特定声明。本推导扩展了视野: J-Q模型的BKT伪连续性是"模型特定的偶然性"而非BL Class 11的必然结果。

## §0.5 隐含假设清单

本推导基于以下隐含假设。每一条都是潜在的攻击面，标注了"若被破坏→对结论的影响"。

**(H1) 正则化方案尊重BL Class 11对称性**
假设维数正规化(d=4-ε)在复耦合下保持赝厄米性。维数正规化在复d下的解析结构(Γ函数的极点结构)在有限阶保持对称性，非微扰验证缺失。
→ 若被破坏: β函数系数在有限阶可获得小的虚部修正，不影响定性结论但定量改变不动点位置。

**(H2) 有效作用量的局域性**
假设非厄米变形不引入非局域算子。DQCP的规范场可产生幂律非局域性(Chern-Simons型)，但BL Class 11变形作用于物质场而非规范场。
→ 若被破坏: β函数需改为泛函RG形式，当前多项式展开失效。

**(H3) O₁和O₂的交换对称性**
假设 $\eta O_1 \eta^{-1} = O_2$ 且 $\eta^2=I$，且两个算子在有效作用量中对称耦合。这是本推导最关键的技术假设。
→ 若被破坏: $c_{mn}$ 可为复数，复不动点不必成共轭对出现，整个推导框架需修正。

**(H4) 微扰展开的定性可靠性**
假设ε-展开在ε=1定性正确。已知DQCP的ε-展开收敛慢(Borel不可求和性)，但不动点的存在性和稳定性符号通常在定性上保持。
→ 若被破坏: 需要非微扰方法(共形微扰论/泛函RG/格点)交叉验证。

**(H5) 无动态对称性破缺**
假设BL Class 11对称性在IR下不被自发破缺。若η在IR下被自发破缺(类似于铁磁体中自旋旋转对称性的破缺)，则长程有效理论具有不同的对称性。
→ 若被破坏: IR不动点分类完全改变，当前分析仅适用于UV→IR的中间标度区。

**(H6) η=R_x(π)的标度不变性**
假设格点定义的旋转变换在场论极限下保持为刚性全局变换，不随标度演化。
→ 若被破坏: 需引入η(μ)的RG方程，β函数约束式修正为 $\beta_{\eta(g)}(g) = \beta(g)^*$。

## §1 结论预测

### 预测1: β函数的最一般形式

在一阶微扰论(单圈)下，BL Class 11对称性约束的DQCP有效作用量中，单一复耦合g(非厄米变形强度)的β函数最一般形式为:

$$\boxed{\beta(g) = -\varepsilon g + c_1 g^2 + c_2 |g|^2 + c_3 (g^*)^2 + \mathcal{O}(g^3)}$$

其中 **$c_1, c_2, c_3 \in \mathbb{R}$** (全部为实数)。

**与厄米理论的本质区别**:
- 厄米 $\phi^4$ 理论: $\beta(g) = -\varepsilon g + c g^2$ (唯一二次项，g是实数)
- BL Class 11非厄米理论: 出现三个独立的二次项，分别对应 $g^2$, $|g|^2$, $(g^*)^2$。这反映了非厄米变形引入了新的算子通道(η-交换对)。

### 预测2: 不动点分类

β(g)=0的解在复g平面上分为三类:

| 类型 | 定义 | 存在条件 | 物理意义 |
|------|------|----------|----------|
| **类型G** | g*=0 | 总是存在 | 高斯不动点(自由理论) |
| **类型R** | Im(g*)=0, Re(g*)≠0 | $c_1+c_2+c_3 \neq 0$ (通用) | 真正的连续相变(如果IR稳定) |
| **类型C** | Im(g*)≠0 | $y^2 > 0$ (模型特定) | BKT型伪连续相变(如果主导RG流) |

**关键预测**: 类型R(实不动点)是**对称性允许**的。其是否物理(即是否在IR下稳定)取决于稳定性特征值 $\lambda_y$ 的符号。

### 预测3: P3-A vs P3-B 判定

**P3-A(复共轭对由BL Class 11对称性强制的)**: **被否定**。

论证链:
1. $\beta_I(x,0) \equiv 0$ 对所有x和所有阶成立(来自系数实数和 $f_2$ 的y-奇性)
2. 因此 $y=0$ 总是 $\beta(g)=0$ 的可能解
3. 实不动点存在性的唯一条件是 $f_1(x,0)=0$ 有非零实数解——这是通用成立的(单圈下 $x^* = \varepsilon/(c_1+c_2+c_3)$)
4. 对称性不强制 $y \neq 0$，不强制复共轭对的存在

**P3-B(复共轭对是模型特定的)**: **被肯定，带条件**。

对于J-Q模型: 非厄米变形算子属于类型N($\eta O_1 \eta^{-1}=O_2 \neq O_1$)，且动力学参数使 $\lambda_y < 0$ (实不动点是鞍点)，复共轭对在 $y^2 > 0$ 的参数区出现。这是J-Q模型的特定结果。

对于一般的BL Class 11系统: 可通过选择类型D算子(η-对角)或调节参数使 $\lambda_y > 0$，实现真正连续的相变。

## §2 强制撞墙(主动寻找推导中最可能失败的地方)

### 撞墙点W1: 交换对称性假设的合理性 [严重性: 致命]

**攻击**: §3.3的证明依赖 $\tilde{\beta}(g_1,g_2) = \beta(g_2,g_1)$。此式来自"同时交换 $O_1 \leftrightarrow O_2$ 和 $g_1 \leftrightarrow g_2$ 保持作用量不变"。

**攻击面**:
1. **规范场耦合不对称**: 若 $O_1$ 涉及与规范场的直接耦合而 $O_2$ 不涉及(或耦合常数不同)，交换对称性被破坏。
2. **工程维数差异**: 若 $O_1$ 和 $O_2$ 获得不同的异常维数(例如由于手征对称性)，则低能有效作用量中的对称性在量子层面被破坏。
3. **格点实现中的不对称**: J-Q模型的格点非厄米变形可能对应连续极限下 $O_1$ 和 $O_2$ 的不同线性组合，破坏精确的交换对称性。

**如果交换对称性被破坏**: 最一般的约束退化为 $c_{mn} = c_{nm}^*$ (厄米性约束)，系数可为复数。此时:
- 实不动点仍存在($\beta_I(x,0)=0$ 不再恒成立——不，即使系数为复数，只要 $c_{mn}=c_{nm}^*$ 仍成立... 让我重新检查)

实际上，即使没有交换对称性，仅从赝厄米性出发: $\beta_2(g_1,g_2) = \beta_1(g_1,g_2)^*$ (来自 $g_2=g_1^*$ 在所有标度成立)。结合 $\beta_2(g_1,g_2)$ 与 $\beta_1(g_2,g_1)$ 的独立关系(来自算子交换)...如果没有交换对称性，$\beta_2$ 和 $\beta_1$ 是独立函数，仅通过 $g_2=g_1^*$ 关联。

在此情况下: $\beta_1(g,g^*)^* = \beta_2(g,g^*)$。不动点方程是 $\beta_1=0$ (此时自动 $\beta_2=0$)。$\beta_1(g,g^*)$ 的展开系数 $c_{mn}$ **不受** $c_{mn}=c_{nm}^*$ 约束——它们可以是任意复数。

$\beta_1(g,g^*) = -\varepsilon g + \sum c_{mn} g^m (g^*)^n$，其中 $c_{mn} \in \mathbb{C}$ (任意)。

分解 $g=x+iy$:
$$f_1(x,y) = \text{Re}(\beta_1), \quad f_2(x,y) = \text{Im}(\beta_1)$$

$f_2(x,0)$ 不再恒为零! 因为 $c_{mn}$ 的虚部贡献在y=0时不一定抵消。

这意味着实不动点(y=0)不再自动是解——$f_2(x,0)=0$ 变成一个独立的约束方程。可能出现**没有实数解的β函数**，即所有不动点都天然是复的——这反而会**强化P3-A**!

**结论**: 交换对称性是否成立是决定P3-A命运的关键枢纽。如果成立(本推导的默认假设)→ P3-A被否定。如果不成立→ P3-A可能被肯定(取决于$c_{mn}$虚部的具体值)。

### 撞墙点W2: 用实数系数的多项式方程产生复不动点的逻辑一致性 [严重性: 中等]

**攻击**: 如果所有系数都是实数，$\beta(g)=0$ 等价于二元实方程组 $f_1(x,y)=0, f_2(x,y)=0$。$f_2$ 的y-奇性保证了 $(x,y)$ 是解 ⇒ $(x,-y)$ 也是解(复共轭对)。但 $f_2(x,0)=0$ 自动成立意味着实轴上的每一点都满足"一半"的不动点方程——这暗示实不动点"太容易"存在。

**攻击面**: 虽然 $y=0$ 满足 $f_2=0$，但 $f_1(x,0)=0$ 是独立条件。可能出现:
- $f_1(x,0)=0$ 无正实数解(例如所有系数同号) → 无物理的实不动点(高斯点除外)
- $f_1(x,0)=0$ 的解在微扰区外($x \gg 1$) → 微扰论不可靠
- 实不动点存在但是UV不动点(在IR下排斥) → 不描述长程物理

**具体检验**: 对于J-Q模型，$f_1(x,0)=0$ 确实有解(这是厄米极限下的DQCP不动点)。但该解是鞍点而非完全吸引子，导致RG流向复方向。

### 撞墙点W3: 单耦合截断的有效性 [严重性: 中等]

**攻击**: 完整DQCP包含至少三个相关耦合: 四次耦合u、规范耦合e²、非厄米变形g。本推导将u和e²的影响"吸收"进g的β函数系数 $c_i(u^*, e^{2*})$。但u和e²的固定点值本身依赖于g——这是一个耦合的方程组。

**攻击面**: 完整的双耦合(或三耦合)系统可能有:
- 混合的复不动点(所有耦合都为复数)
- 部分复不动点(例如g为复数但u, e²为实数)
- 新的分岔类型(如Hopf分岔→极限环RG流)

**GRZ框架的启示**: GRZ的"固定点湮灭"场景涉及两个实不动点(u_*, u_±)随参数变化而合并。在我们的非厄米扩展中，这是投影到g=0超曲面上的行为。完整的3D耦合空间可能有更丰富的拓扑结构。

### 撞墙点W4: 非微扰瞬子效应 [严重性: 低(在微扰框架内)]

**攻击**: DQCP的U(1)规范场在d=3支持瞬子(monopole)构型，它们驱动禁闭和VBS序。非厄米变形可能改变瞬子的作用量和统计权重，从而改变IR物理。

**攻击面**: 瞬子效应通常以 $\exp(-c/e^2)$ 的形式出现，在微扰β函数中不可见。如果非厄米变形使瞬子作用量变为复数(复的瞬子权重)，可能出现新的非微扰现象(如瞬子-反瞬子振荡)。

**当前处理**: 此效应不在本推导的范围内(纯微扰β函数分析)。PI应注意这是可能的"未知未知"。

## §3 正规推导

### §3.1 对称性对有效作用量的约束

#### 3.1.1 BL Class 11 的定义与算子代数

从v1知识库(K1.16)和Bernard-LeClair(2002)的分类:

**定义1(复对称性C)**: 哈密顿量满足 $H^T = H$ (在计算基下)。等价于存在反幺正算子C使得 $C H C^{-1} = H$，其中 $C^2 = +1$ (因为 $c=I$, $\varepsilon_c=+1$)。

**定义2(赝厄米性Q)**: 存在厄米可逆算子 $\eta$ 使得 $\eta H \eta^{-1} = H^\dagger$。对于BL Class 11，$\eta = R_x(\pi)$ (绕x轴的π旋转)，且 $\varepsilon_{qc}=+1$。

**代数结构**: 两个对称性满足:
$$C^2 = +1, \quad \eta^2 = I \text{ (对于O(3)矢量表示)} $$
$$C \eta^T C^{-1} \eta^{-1} = \varepsilon_{qc} I = +I \quad \text{(相容性条件)}$$

对于 $C=I$ (转置操作): $\eta I^T \eta^{-1} I^\dagger = \eta \eta^{-1} = I$。自动满足。

#### 3.1.2 有效作用量的一般形式

在连续极限下，DQCP的场变量为:
- O(3)矢量序参量 $\mathbf{n} = (n_1, n_2, n_3)$
- 涌现的非紧致U(1)规范场 $A_\mu$

有效作用量(欧几里得):
$$S_{\text{eff}} = \int d^d x \, \mathcal{L}_{\text{eff}}[\mathbf{n}, A_\mu]$$

拉氏量分解:
$$\mathcal{L}_{\text{eff}} = \mathcal{L}_{\text{kin}} + \mathcal{L}_{\text{DQCP}} + \mathcal{L}_{\text{NH}}$$

其中:
- $\mathcal{L}_{\text{kin}} = \frac{1}{2}(\partial_\mu \mathbf{n})^2 + \frac{1}{4e^2} F_{\mu\nu}^2$: 动能项
- $\mathcal{L}_{\text{DQCP}} = \frac{r}{2}\mathbf{n}^2 + u (\mathbf{n}^2)^2 + \cdots$: 标准DQCP相互作用(厄米部分)
- $\mathcal{L}_{\text{NH}}$: 非厄米变形(需要与BL Class 11兼容)

#### 3.1.3 算子谱的η-分类

**引理1**: 在η=R_x(π)作用下，O(3)矢量变换为:
$$\eta: (n_1, n_2, n_3) \to (n_1, -n_2, -n_3)$$

引入复场: $\psi = n_2 + i n_3$, $\bar{\psi} = n_2 - i n_3$, $\sigma = n_1$。

η作用下:
$$\eta: \psi \to -\psi, \quad \bar{\psi} \to -\bar{\psi}, \quad \sigma \to \sigma$$

**引理2(算子η-分类)**: 任何由基本场构造的局域算子 $O$ 在η作用下满足:
$$\eta O \eta^{-1} = \zeta_O O'$$
其中 $\zeta_O = \pm 1$，$O'$ 是另一个局域算子(可能与 $O$ 相同)。

定义两类算子:
- **类型D(对角类)**: $\eta O \eta^{-1} = \pm O$。算子映射到自身(允许符号变化)。
- **类型N(非对角类)**: $\eta O \eta^{-1} = O'$ 且 $O' \neq \pm O$。算子映射到不同的算子。

由于 $\eta^2 = I$，类型N算子自然形成对 $(O, O')$。

**引理3(赝厄米性对耦合常数的约束)**:

有效作用量写为 $S_{\text{eff}} = S_0 + \sum_i g_i \int O_i$。赝厄米性要求:
$$\eta S_{\text{eff}} \eta^{-1} = S_{\text{eff}}^*$$

其中 $S_{\text{eff}}^*$ 是复共轭作用量(对复耦合常数取复共轭)。

对于类型D算子:
$$\eta \left(g O\right) \eta^{-1} = g (\pm O) = \pm g O$$
要求 $\pm g O = g^* O$，故:
- 若 $O$ 是η-偶($\zeta_O=+1$): $g = g^*$ → $g \in \mathbb{R}$
- 若 $O$ 是η-奇($\zeta_O=-1$): $-g = g^*$ → $g \in i\mathbb{R}$ (纯虚数)

对于类型N算子对 $(O_1, O_2)$:
$$\eta \left(g_1 O_1 + g_2 O_2\right) \eta^{-1} = g_1 O_2 + g_2 O_1 = g_1^* O_2 + g_2^* O_1$$
要求: $g_1 = g_2^*$ 且 $g_2 = g_1^*$。

**因此: 仅在类型N算子对存在时，有效作用量才包含真正复的耦合常数(实部和虚部均非零)**。

#### 3.1.4 非厄米变形的最一般参数化

结合以上，最一般的BL Class 11兼容的非厄米变形为:
$$\mathcal{L}_{\text{NH}} = \sum_{i \in \text{type-D}} g_i^{(d)} O_i^{(d)} + \sum_{(i,j) \in \text{type-N pairs}} \left(g_{ij} O_i + g_{ij}^* O_j\right)$$

其中:
- $g_i^{(d)} \in \mathbb{R}$ 或 $i\mathbb{R}$ (取决于 $\zeta_O$)
- $g_{ij} \in \mathbb{C}$ (任意复数)
- 第二项求和覆盖所有类型N算子对

**J-Q模型的特殊情况**: J-Q模型的非厄米变形属于类型N。对应的微观算符在η下映射到另一个算符。因此:
$$\mathcal{L}_{\text{NH}}^{\text{J-Q}} = \gamma M + \gamma^* M^\prime, \quad \eta M \eta^{-1} = M^\prime, \quad \gamma \in \mathbb{C}$$

其中 $\gamma$ 是复的变形参数，$M$ 和 $M^\prime$ 是场论中对应的局域算子。这是v1中"复有效耦合"的对称性起源。

### §3.2 从对称性到β函数约束: 形式推导

#### 3.2.1 重整化群与对称性的相容性

考虑威尔逊重整化群: 积分掉高能动量壳层($\Lambda/b < |k| < \Lambda$)产生有效作用量 $S_b$:
$$e^{-S_b[\phi_{<}]} = \int \mathcal{D}\phi_{>} \, e^{-S[\phi_{<} + \phi_{>}]}$$

**定理0(RG-对称性相容性)**: 如果裸作用量 $S$ 满足对称性 $\mathcal{S}$ (即 $\mathcal{S}(S) = S$)，且正则化方案尊重 $\mathcal{S}$，则重整化作用量 $S_b$ 在每一标度 $b$ 也满足 $\mathcal{S}$。

证明: 这是标准结果。正则化(动量截断)与空间旋转对易(因为η是空间旋转)，维数正规化也与全局对称性对易。

**应用到BL Class 11**: 对于每个标度 $b$:
$$\eta S_b \eta^{-1} = S_b^*$$
$$C S_b C^{-1} = S_b$$

#### 3.2.2 单对类型N算子的β函数约束

考虑一对类型N算子 $(O_1, O_2)$，耦合常数为 $(g_1, g_2)$。根据§3.1.3:
$$g_2 = g_1^* \quad \text{(赝厄米性约束)}$$

此约束在所有标度下成立: $g_2(b) = g_1(b)^*$ 对所有 $b$。

定义: $g(b) \equiv g_1(b)$。则 $g_2(b) = g(b)^*$。

β函数:
$$\beta(g, g^*) \equiv \frac{dg}{d\ln b} = \beta_1(g_1, g_2)\big|_{g_2=g^*}$$
$$\tilde{\beta}(g, g^*) \equiv \frac{dg^*}{d\ln b} = \beta_2(g_1, g_2)\big|_{g_2=g^*}$$

由于 $g_2 = g_1^*$ 在所有标度成立: $\tilde{\beta}(g, g^*) = \beta(g, g^*)^*$。

#### 3.2.3 交换对称性

**关键假设(交换对称性)**: 算子对 $(O_1, O_2)$ 在有效作用量中对称出现——同时交换 $O_1 \leftrightarrow O_2$ 和 $g_1 \leftrightarrow g_2$ 保持作用量不变。

在此假设下:
$$\beta_2(g_1, g_2) = \beta_1(g_2, g_1)$$

即: $O_2$ 耦合的β函数可以通过交换 $O_1$ 和 $O_2$ 的角色从 $O_1$ 的β函数得到。

**合并约束**:
$$\tilde{\beta}(g_1, g_2) = \beta_1(g_2, g_1)$$

代入 $g_2 = g^*$:
$$\beta(g, g^*)^* = \beta(g^*, g)$$

这是**核心约束方程(C)**。

#### 3.2.4 泰勒展开与系数约束

将 $\beta(g, g^*)$ 展开为 $g$ 和 $g^*$ 的双重幂级数(适用于微扰区域 $|g| \ll 1$):
$$\beta(g, g^*) = -\varepsilon g + \sum_{m+n \geq 2} c_{mn} \, g^m (g^*)^n$$

其中 $\varepsilon = 4-d$ (在维数正规化中)，$c_{mn} \in \mathbb{C}$。

将约束 $\beta(g, g^*)^* = \beta(g^*, g)$ 代入:

左端: $\beta(g, g^*)^* = -\varepsilon g^* + \sum_{m,n} c_{mn}^* (g^*)^m g^n = -\varepsilon g^* + \sum_{m,n} c_{nm}^* g^n (g^*)^m$

右端: $\beta(g^*, g) = -\varepsilon g^* + \sum_{m,n} c_{mn} (g^*)^m g^n = -\varepsilon g^* + \sum_{m,n} c_{mn} g^n (g^*)^m$

比较 $g^n (g^*)^m$ 的系数:
$$\boxed{c_{mn} = c_{nm}^* \quad \forall m,n \geq 0}$$

**定理1(系数厄米性约束)**: 在交换对称性假设下，β函数的泰勒系数矩阵 $\{c_{mn}\}$ 是厄米的(在交换指标的意义上)。

**系1**: $c_{nn} \in \mathbb{R}$ (对角系数为实数)。

**系2**: $c_{mn}$ 和 $c_{nm}$ 互为复共轭。

**系3(强化)**: 如果理论具有额外的宇称对称性使得 $m \leftrightarrow n$ 非对称贡献消失(或如果$O_1$和$O_2$的动力学完全对称)，则 $c_{mn} = c_{nm}$，结合厄米性约束 → **所有 $c_{mn} \in \mathbb{R}$**。

**J-Q模型的情况**: 交换对称性成立($O_1$ 和 $O_2$ 是η-共轭对，且理论在交换下不变)，且无额外的宇称破坏。因此**J-Q模型的所有β函数系数为实数**。

#### 3.2.5 最一般形式(到三阶)

$$
\boxed{\beta(g, g^*) = -\varepsilon g + c_1 g^2 + c_2 |g|^2 + c_3 (g^*)^2 + d_1 g^3 + d_2 g^2 g^* + d_3 g (g^*)^2 + d_4 (g^*)^3 + \mathcal{O}(g^4)}
$$

其中所有系数 $\{c_1,c_2,c_3,d_1,d_2,d_3,d_4\} \subset \mathbb{R}$。

重命名对应关系: $c_1=c_{20}$, $c_2=c_{11}$, $c_3=c_{02}$, $d_1=d_{30}$, $d_2=d_{21}$, $d_3=d_{12}$, $d_4=d_{03}$。

#### 3.2.6 实部和虚部分解

令 $g = x + iy$ ($x,y \in \mathbb{R}$)，将β分解为实部和虚部:
$$\beta(g) = f_1(x,y) + i f_2(x,y)$$

其中 $f_1 = \text{Re}(\beta)$, $f_2 = \text{Im}(\beta)$。

**到三阶显式**:

计算各项:
- $g = x+iy$
- $g^* = x-iy$
- $g^2 = x^2-y^2 + 2ixy$
- $(g^*)^2 = x^2-y^2 - 2ixy$
- $|g|^2 = x^2+y^2$
- $g^3 = (x^3-3xy^2) + i(3x^2y-y^3)$
- $(g^*)^3 = (x^3-3xy^2) - i(3x^2y-y^3)$
- $g^2 g^* = (x^2+y^2)(x+iy) = x(x^2+y^2) + iy(x^2+y^2)$
- $g (g^*)^2 = (x^2+y^2)(x-iy) = x(x^2+y^2) - iy(x^2+y^2)$

代入:
$$f_1(x,y) = -\varepsilon x + (c_1+c_3)(x^2-y^2) + c_2(x^2+y^2) + (d_1+d_4)(x^3-3xy^2) + (d_2+d_3)x(x^2+y^2) + \mathcal{O}((x^2+y^2)^2)$$

$$f_2(x,y) = -\varepsilon y + 2(c_1-c_3)xy + (d_1-d_4)(3x^2y-y^3) + (d_2-d_3)y(x^2+y^2) + \mathcal{O}((x^2+y^2)^2)$$

**关键对称性**:
$$\boxed{f_1(x,-y) = f_1(x,y) \quad \text{(y的偶函数)}}$$
$$\boxed{f_2(x,-y) = -f_2(x,y) \quad \text{(y的奇函数)}}$$

**全阶推广**:

对于任意 $m,n \geq 0$，贡献项为:
$$c_{mn}(g^m(g^*)^n + g^n(g^*)^m)$$

(此处利用了 $c_{mn}=c_{nm}$ ∈ ℝ，合并了对称项。)

记 $S_{mn} = g^m(g^*)^n + g^n(g^*)^m$:
$$S_{mn} = (x+iy)^m(x-iy)^n + (x+iy)^n(x-iy)^m$$

展开: 令 $r = \sqrt{x^2+y^2}$, $e^{i\theta} = (x+iy)/r$。
$$S_{mn} = r^{m+n}\left[e^{i(m-n)\theta} + e^{-i(m-n)\theta}\right] = 2r^{m+n} \cos((m-n)\theta)$$

当 $m=n$: $S_{nn} = 2r^{2n}$ → 纯实，y-偶。
当 $m \neq n$: $\cos((m-n)\theta)$ 展开为 $x/r$ 和 $y/r$ 的多项式。由于 $\cos(k\theta)$ 是 $\cos\theta$ 的切比雪夫多项式，而 $\cos\theta = x/r$, $\sin\theta = y/r$:
- $\cos(k\theta)$ 是 $x/r$ 的偶/奇函数(取决于k的奇偶性)，但对 $y/r$ 总是偶函数(因为 $\cos(k\theta) = \cos(-k\theta)$，而 $y \to -y$ 对应 $\theta \to -\theta$)
- 因此 $\text{Re}(S_{mn})$ 是y的偶函数，$\text{Im}(S_{mn})$ 是y的奇函数(对于 $m \neq n$, $S_{mn}$ 的虚部来自 $\sin((m-n)\theta)$ 的贡献，而 $\sin$ 是奇函数)

**定理2(y-奇偶性)**: 在系数全部实数的条件下，对所有阶:
$$f_1(x,-y) = f_1(x,y), \quad f_2(x,-y) = -f_2(x,y), \quad f_2(x,0) \equiv 0$$

### §3.3 不动点分类与稳定性分析

#### 3.3.1 不动点方程

不动点 $g^* = x^* + iy^*$ 满足:
$$f_1(x^*, y^*) = 0, \quad f_2(x^*, y^*) = 0$$

**引理4**: $y=0$ 自动满足 $f_2=0$ (来自定理2)。因此实轴上的每一点满足"一半"的不动点方程。

#### 3.3.2 三类不动点的形式分析

**类型G: 高斯不动点**
$$g^* = 0 \quad \text{总是解}$$

稳定性: 线性化给出 $\partial\beta/\partial g|_{g=0} = -\varepsilon$, $\partial\beta/\partial g^*|_{g=0} = 0$。稳定性矩阵的特征值为 $(-\varepsilon, -\varepsilon)$。对于 $d<4$ ($\varepsilon>0$): IR不稳定(高斯不动点是UV不动点)。

**类型R: 实不动点**
$$y^* = 0, \quad x^* \neq 0: f_1(x^*, 0) = 0$$

单圈方程:
$$-\varepsilon x + (c_1+c_2+c_3)x^2 + \mathcal{O}(x^3) = 0$$

非平凡解:
$$x^* = \frac{\varepsilon}{c_1+c_2+c_3} + \mathcal{O}(\varepsilon^2)$$

存在条件: $c_1+c_2+c_3 \neq 0$。在微扰理论中，这是通用成立的(非零条件对应 $\phi^4$ 项的相互作用系数)。

物理条件: $x^* > 0$ (对于正的四次耦合，确保真空稳定性)。这要求 $c_1+c_2+c_3$ 与 $\varepsilon$ 同号。

**类型C: 复共轭不动点对**
$$y^* \neq 0$$

从 $f_2=0$ 和 $y \neq 0$:
$$-\varepsilon + 2(c_1-c_3)x + (d_1-d_4)(3x^2 - y^2) + (d_2-d_3)(x^2+y^2) + \cdots = 0$$

单圈下:
$$-\varepsilon + 2(c_1-c_3)x = 0 \quad \Rightarrow \quad x^* = \frac{\varepsilon}{2(c_1-c_3)}$$

存在条件: $c_1 \neq c_3$。如果 $c_1 = c_3$，则 $f_2 = -\varepsilon y + \mathcal{O}(y^3)$，单圈下无非平凡 $y \neq 0$ 解。

代入 $f_1=0$:
$$-\varepsilon x^* + (c_1+c_3)((x^*)^2 - y^2) + c_2((x^*)^2 + y^2) = 0$$

代入 $x^* = \varepsilon/(2(c_1-c_3))$:
$$-\frac{\varepsilon^2}{2(c_1-c_3)} + (c_1+c_3)\frac{\varepsilon^2}{4(c_1-c_3)^2} + c_2\frac{\varepsilon^2}{4(c_1-c_3)^2} - (c_1+c_3)y^2 + c_2 y^2 = 0$$

$$y^2(c_1+c_3-c_2) = \frac{\varepsilon^2}{4(c_1-c_3)^2}\left(2(c_1-c_3) + c_1 + c_3 + c_2 - 2(c_1+c_3)\right)$$

简化:
$$y^2(c_1+c_3-c_2) = \frac{\varepsilon^2}{4(c_1-c_3)^2}\left(c_2 - 2c_3\right)$$

$$\boxed{y^2 = \frac{\varepsilon^2(c_2 - 2c_3)}{4(c_1-c_3)^2(c_1+c_3-c_2)}}$$

**复不动点对的存在条件**: $y^2 > 0$，即:
$$\frac{c_2 - 2c_3}{c_1+c_3-c_2} > 0$$

(假设分母不为零。)

**引理5**: 类型C不动点**必然成对出现**: 若 $(x^*, y^*)$ 是解，则 $(x^*, -y^*)$ 也是解(来自定理2)。这对应 $g^* = x^*+iy^*$ 和 $\bar{g}^* = x^*-iy^*$——复共轭不动点对。

#### 3.3.3 稳定性分析: 实不动点

在不动点处，RG流方程为:
$$\frac{d}{d\ln b}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} f_1(x,y) \\ f_2(x,y) \end{pmatrix}$$

线性稳定性由雅可比矩阵给出:
$$M_{ij} = \begin{pmatrix} \partial_x f_1 & \partial_y f_1 \\ \partial_x f_2 & \partial_y f_2 \end{pmatrix}_{(x^*, y^*)}$$

**实不动点 $(x^*, 0)$**:

利用y-奇偶性(定理2):
- $\partial_y f_1|_{y=0} = 0$ (偶函数在y=0处的y-导数为零)
- $\partial_x f_2|_{y=0} = \partial_x(0) = 0$ (因为 $f_2(x,0)\equiv 0$，其x-导数也恒为零)

因此稳定性矩阵**对角化**:
$$M_R = \begin{pmatrix} \lambda_x & 0 \\ 0 & \lambda_y \end{pmatrix}$$

其中:
$$\lambda_x = \frac{\partial f_1}{\partial x}\bigg|_{(x^*,0)} = -\varepsilon + 2x^*(c_1+c_2+c_3) + 3(x^*)^2(d_1+d_2+d_3+d_4) + \cdots$$

$$\lambda_y = \frac{\partial f_2}{\partial y}\bigg|_{(x^*,0)} = -\varepsilon + 2x^*(c_1-c_3) + (x^*)^2(3(d_1-d_4) + (d_2-d_3)) + \cdots$$

单圈下，代入 $x^* = \varepsilon/(c_1+c_2+c_3)$:
$$\lambda_x = -\varepsilon + 2\varepsilon = \varepsilon > 0 \quad (\text{IR吸引在x方向})$$
$$\lambda_y = -\varepsilon + 2\varepsilon\frac{c_1-c_3}{c_1+c_2+c_3}$$

$$\boxed{\lambda_y = \varepsilon\left(-1 + \frac{2(c_1-c_3)}{c_1+c_2+c_3}\right) + \mathcal{O}(\varepsilon^2)}$$

**实不动点的稳定性分类**:

| 条件 | λ_y 符号 | 稳定性 | 物理 |
|------|----------|--------|------|
| $\frac{2(c_1-c_3)}{c_1+c_2+c_3} > 1$ | λ_y > 0 | **完全吸引子** | 真正的连续相变 |
| $\frac{2(c_1-c_3)}{c_1+c_2+c_3} < 1$ | λ_y < 0 | **鞍点**(x方向吸引,y方向排斥) | BKT型伪连续 |
| $\frac{2(c_1-c_3)}{c_1+c_2+c_3} = 1$ | λ_y = 0 | **退化**(需要高圈分析) | 可能是BKT相变的精确边界 |

等价条件(单圈):
$$\lambda_y > 0 \iff c_1 - 3c_3 - c_2 > 0$$
$$\lambda_y < 0 \iff c_1 - 3c_3 - c_2 < 0$$

#### 3.3.4 复共轭不动点对的稳定性

在类型C不动点 $(x^*, y^*)$ 处($y^* \neq 0$)，稳定性矩阵非对角:
$$M_C = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

其中:
$$a = \partial_x f_1, \quad b = \partial_y f_1 = 2y^*[-(c_1+c_3) + c_2 + \cdots] + \mathcal{O}(y^3)$$
$$c = \partial_x f_2 = 2y^*[c_1-c_3 + \cdots] + \mathcal{O}(y^3)$$
$$d = \partial_y f_2 = -\varepsilon + 2x^*(c_1-c_3) + \cdots$$

特征值:
$$\lambda_\pm = \frac{a+d}{2} \pm \frac{1}{2}\sqrt{(a-d)^2 + 4bc}$$

当 $y^*$ 很小时($y^* \ll 1$，即复不动点靠近实轴):
- $b, c \propto y^*$ → 小量
- $a \approx \lambda_x$, $d \approx \lambda_y$ (接近实不动点的稳定性特征值)
- $(a-d)^2 + 4bc \approx \lambda_x^2 + \lambda_y^2 - 2\lambda_x\lambda_y + \mathcal{O}(y^2) = (\lambda_x-\lambda_y)^2 + \mathcal{O}(y^2)$

特征值:
$$\lambda_\pm \approx \frac{\lambda_x+\lambda_y}{2} \pm \frac{|\lambda_x-\lambda_y|}{2} + \mathcal{O}(y^2)$$

对于鞍点实不动点($\lambda_y < 0 < \lambda_x$): $\lambda_+ \approx \lambda_x > 0$, $\lambda_- \approx \lambda_y < 0$。

这意味着靠近实轴的复共轭对**也是鞍点**，但获得 $\mathcal{O}(y^2)$ 的修正。一正一负特征值意味着RG流沿一个方向趋向不动点，沿另一个方向离开——这产生**螺旋流**(spiral flow)，如Vander Linden et al. (2025)所观察到的。

螺旋流的周期:
$$\omega \approx \sqrt{-bc} \propto y^*$$

当 $y^* \to 0$ 时(临界点)，螺旋周期趋于无穷——这是BKT型"行走"行为的RG解释。

### §3.4 与GRZ复CFT框架的衔接

#### 3.4.1 GRZ固定点湮灭与本推导的关系

GRZ(Gorbenko-Rychkov-Zan 2018)考虑的场景: 随控制参数变化，两个实不动点合并然后湮灭为复共轭对。正规形式(saddle-node分岔):
$$\beta_\alpha(x) = (x-x_c)^2 + (\alpha_c - \alpha)$$

本推导考虑的是不同的分岔类型: 复平面上的叉式(pitchfork)分岔。

**两个框架的映射**:

将GRZ场景视为本推导框架在 $y=0$ 超平面上的投影。GRZ中的"控制参数" $\alpha$ 对应本推导中的某个系数组合(例如 $c_1+c_2+c_3$ 的符号或大小)。当该组合越过临界值时，实不动点对合并(在GRZ框架中)或实不动点失去一个方向的稳定性(在本推导框架中)。

**关键区别**:
- GRZ: 复共轭对是**唯一**的IR目标(实不动点已湮灭)
- 本推导: 复共轭对和实不动点可以**共存**。选择哪个作为IR目标取决于RG流的初始条件和稳定性结构

#### 3.4.2 行走行为的两种微观起源

两种产生"行走"(walking) RG流的微观机制:

1. **GRZ机制**: 复共轭对是唯一的复平面吸引子，但非常靠近实轴。实RG流被迫在两个复不动点之间缓慢通过 → 标度不变的"行走"区。

2. **BL Class 11机制**: 实不动点是鞍点(λ_y<0)。RG流在实轴附近被排斥到复方向，然后在复共轭对附近螺旋 → 行走 + 螺旋振荡。

这两种机制在"行走"的宏观现象学上是相似的(指数大的关联长度)，但微观分岔类型不同。J-Q模型可能同时经历了两种机制。

### §3.5 判定定理

**定理3(配对性强制定理)**:
在BL Class 11对称性下(含交换对称性假设):
(i) 如果 $g^* \notin \mathbb{R}$ 是不动点，则其复共轭 $\bar{g}^*$ 也是不动点。
(ii) 复共轭不动点对具有相同的稳定性特征值(λ_±成复共轭对或均为相同实数)。

证明: (i) 来自定理2: $f_1(x,-y)=f_1(x,y)$, $f_2(x,-y)=-f_2(x,y)$。若 $(x^*,y^*)$ 满足 $f_1=f_2=0$，则 $(x^*,-y^*)$ 也满足。
(ii) 来自稳定性矩阵在 $(x,y) \to (x,-y)$ 下的变换性质: $M(x,-y)$ 的特征多项式与 $M(x,y)$ 的复共轭相同。

**定理4(非强制性定理)**:
BL Class 11对称性**不强制**所有非平凡不动点为复数。实不动点($y=0$)在任何阶都是β(g)=0的合法解。

证明: $f_2(x,0) \equiv 0$ 对所有 $x$ 对所有阶成立(定理2)。因此不动点条件退化为单一实方程 $f_1(x,0)=0$，这是一个实系数一元多项式方程，至少有一个非零实数解(在高斯不动点之外，取决于系数)。

**推论1(J-Q模型)**:
J-Q模型的BKT伪连续性来自 $\lambda_y < 0$ (实不动点为鞍点)和 $y^2 > 0$ (复共轭对存在)的特定动力学参数组合。这不是BL Class 11对称性的普遍强制特征。

**推论2(真正连续相变的可能性)**:
存在BL Class 11兼容的参数区($c_1, c_2, c_3$值的特定范围)满足 $\lambda_y > 0$，此时实不动点是完全吸引的IR不动点，系统展示真正的连续相变。是否存在具体的格点模型落入此参数区是一个开放的设计问题。

### §3.6 数值例证: J-Q模型的参数区

基于v1知识库(K1.11, K1.17)对J-Q模型的分析，其β函数系数满足:

$$c_1 > 0, \quad c_2 > 0, \quad c_3 > 0, \quad c_1 > c_3$$

(这些符号来自非厄米变形的正性条件和η-交换算子对的动力学。)

在此参数区:
$$x^* = \frac{\varepsilon}{c_1+c_2+c_3} > 0 \quad \text{(实数正不动点存在)}$$
$$\lambda_y = \varepsilon\left(-1 + \frac{2(c_1-c_3)}{c_1+c_2+c_3}\right)$$

由于 $c_1-c_3 > 0$ 但通常 $c_1-c_3 \ll c_1+c_2+c_3$ (因为非厄米变形导致的 $c_1$ 和 $c_3$ 的差异较小):
$$\lambda_y \approx \varepsilon(-1 + \text{小正数}) < 0$$

**实不动点是鞍点** → RG流在虚部方向被排斥 → 流向复共轭对(如果 $y^2 > 0$)。

对于 $y^2$:
$$y^2 = \frac{\varepsilon^2(c_2 - 2c_3)}{4(c_1-c_3)^2(c_1+c_3-c_2)}$$

J-Q模型的参数满足 $c_2 > 2c_3$ 和 $c_1+c_3 > c_2$ → $y^2 > 0$ → **复共轭对存在**。

这定量解释了v1的发现: BKT伪连续性 $(y^*)^2 \propto \varepsilon^2 \propto (4-d)^2$ 在 $d=3$ ($\varepsilon=1$) 时表现显著，给出了 $\text{Im}(g^*) \sim \mathcal{O}(1)$ 且关联长度 $\xi \sim \exp(\pi/(2|A_2 b|))$。

## §4 自洽性检验

### 检验1: 厄米极限的还原

**检验**: 取厄米极限——非厄米变形消失，$g \to 0$ (即回到标准DQCP)。

在此极限下:
- $g \to 0$: β函数在原点附近的行为完全由 $-\varepsilon g$ 项主导
- 高斯不动点(g=0)的稳定性由ε的符号决定
- 标准DQCP的β函数(在u-e²空间中)不受非厄米变形影响

**结论**: 通过。非厄米β函数在厄米极限下不与标准DQCP的RG流冲突。

### 检验2: 与LeClair(2025)伪厄米标量场论的对比

**LeClair(2025, arXiv:2504.09327)的主要结果**:
- 4D伪厄米标量场论 → 临界线(不动点的1维流形) → 循环RG流
- β函数具有对偶性 $g \to 1/g$
- 1圈结构在更高圈持续

**本推导的对应**:
- 临界线对应 $c_1=c_3$ 且 $c_2=0$ 的特殊情况:
  - $f_2(x,y) = -\varepsilon y + 2(c_1-c_3)xy + \cdots = -\varepsilon y + 0 + \cdots →$ 在单圈下 $f_2 \equiv -\varepsilon y$
  - 不动点条件: $-\varepsilon y = 0 \Rightarrow y=0$ (实不动点)或需高圈项 → y方向解除约束
  - 若高圈项为零，则任何y都满足 $f_2=0$(只要 $f_1(x,y)=0$)，形成不动点的1维流形(临界线)
- 循环RG流: 对应复不动点附近的螺旋流(本推导的一般特征)
- 对偶性 $g \to 1/g$: 不在BL Class 11对称性中——是LeClair模型中额外的全局对称性(可能与S-对偶性有关)

**差异说明**: LeClair的模型具有额外的SU(2)→U(1)破缺和对偶性，产生比BL Class 11单独约束更丰富的结构。这是兼容的——BL Class 11是最小对称集，额外对称性可进一步约束β函数。

**结论**: 通过。两个框架在重叠区域一致。

### 检验3: 与Mostafazadeh赝厄密谱定理的相容性

**Mostafazadeh定理**: 对于满足 $\eta H \eta^{-1} = H^\dagger$ 的赝厄密哈密顿量，本征值要么是实数，要么以复共轭对出现。

**对本推导的含义**: 此定理确保RG变换后理论的谱(即定态的能量本征值)满足复共轭配对。这独立于β函数分析，为§3.5的配对性强制定理提供了非微扰层面的支撑。

**结论**: 通过。配对性强制定理与谱定理一致。差异在于: 谱定理作用于哈密顿量本征值(能量)，配对性强制定理作用于RG不动点(耦合常数)。两者都是赝厄密性的结果，但在不同层面(动力学 vs. RG流)。

### 检验4: 高圈修正的稳定性

**检验**: §3.2-§3.3的单圈分析是否在高圈下定性保持?

**论证**:
1. 系数实数性($c_{mn} \in \mathbb{R}$)对**所有阶**成立(定理1和系3)——这是对称性约束，不受微扰阶数影响
2. y-奇偶性($f_2(x,-y)=-f_2(x,y)$, $f_2(x,0)=0$)对**所有阶**成立(定理2)——同样是对称性约束
3. 实不动点的存在性对**所有阶**保持——$f_2(x,0)=0$ 全阶成立
4. λ_y的符号**可能**被高圈修正翻转——这是唯一可能被高圈改变的结果

**具体地**: 两圈和三圈的贡献在物理维度ε=1时与单圈贡献可比(这是ε-展开的收敛性问题)。但符号翻转要求高圈贡献与单圈贡献反号且量级更大——这在DQCP的ε-展开中是可能的(Faedo et al. 2021指出高圈修正可达30-50%)。

**结论**: 定性框架对所有阶成立，定量预测(λ_y的具体符号和大小)需要在ε=1处慎重对待。

## §5 未闭合问题

### 5.1 理论未闭合

**U1(算子谱的完整η-分类)**: 
对于DQCP场论(O(3)矢量 + U(1)规范场)，需要系统分类所有标度维数 Δ ≤ 3 的局域算子在 η=R_x(π) 下的变换性质。目标: 列出所有类型N算子对和类型D算子。这是设计"真正连续"BL Class 11变形的先决条件。

**U2(交换对称性的完整微观论证)**: 
§3.3假设了O₁和O₂的交换对称性。需从J-Q模型的微观哈密顿量出发，在连续极限下严格证明此对称性(或证明其破缺)。这需要:
- 格点算子的显式形式
- 低能投影: 格点算子 → 连续场论算子
- 证明η O₁ η⁻¹ = O₂ 在量子层面保持

**U3(完整的多耦合β函数系统)**:
将单耦合截断推广到包含物质四次耦合u和规范耦合e²的完整系统:
$$\beta_u = -\varepsilon_u u + \cdots + \text{与g的混合项}$$
$$\beta_{e^2} = -\varepsilon_A e^2 + \cdots$$
$$\beta_g = -\varepsilon_g g + \cdots + \text{与u和e²的混合项}$$

目标: 在三维耦合空间中分类所有不动点类型及其分岔。

**U4(非微扰效应: 瞬子和禁闭)**:
U(1)规范场在d=3的瞬子(monopole)效应可能改变IR不动点结构。非厄米变形是否使瞬子作用量复杂化? 复瞬子权重如何影响RG流?

**U5(η的重正化)**:
在强耦合区域(ε=1), η=R_x(π) 是否保持为精确的刚性对称性? 或者它获得了异常维数，变为标度依赖的 η(μ)? 如果是后者，β函数约束式如何修正?

### 5.2 数值/格点未闭合

**U6(J-Q模型的β函数系数的具体值)**:
需要格点计算(例如有限尺寸标度或MCRG)提取J-Q模型的 $c_1$, $c_2$, $c_3$。这将:
- 验证 $\lambda_y < 0$ 的预测
- 定量确定 $y^*$ (复不动点的虚部)
- 与v1的BKT拟合参数交叉验证

**U7(构造类型D的BL Class 11格点模型)**:
设计一个非厄米变形，其连续极限对应于类型D算子(η-对角)。例如:
- 选择变形算子 $M = \sum_i (S_i^z)^2$ (η-偶) → 耦合常数为实数
- 或 $M = \sum_i S_i^x S_{i+1}^y - S_i^y S_{i+1}^x$ (η-奇, Dzyaloshinskii-Moriya型) → 耦合常数为纯虚数

这样的模型在BL Class 11对称性下不引入类型N算子对，因此不强制产生复共轭不动点对。实不动点(如果稳定)将描述真正的连续相变。

**U8(张量网络/DMRG检验)**:
对提议的格点模型进行非厄米张量网络模拟，验证不动点类型和临界指数的实数性。

### 5.3 与v1的衔接

**U9(v1边界的精确位置)**:
v1证明了"J-Q模型的非厄米变形下DQCP不是真正连续的"。本推导将此边界精确化为:
- 边界条件: $c_1 - 3c_3 - c_2 = 0$ (λ_y = 0)
- J-Q模型满足 $c_1 - 3c_3 - c_2 < 0$ → λ_y < 0 → 在边界的"伪连续"一侧
- 如果存在模型满足 $c_1 - 3c_3 - c_2 > 0$ → λ_y > 0 → 在边界的"真正连续"一侧

**U10(v2下一步: 构造反例)**:
下一个任务是寻找(或构造)一个满足 $c_1 - 3c_3 - c_2 > 0$ 的BL Class 11格点模型。这可能需要对J-Q模型进行修改——例如改变非厄米变形的具体形式，或引入额外的对称性保护。

## 附录A: 与GRZ复CFT框架的详细对比

### A.1 分岔类型的形式化对比

**GRZ场景(saddle-node分岔)**:
$$\beta_\alpha(x) = (x-x_c)^2 + (\alpha_c - \alpha), \quad x \in \mathbb{R}$$

- α < α_c: 两个实不动点 $x_\pm = x_c \pm \sqrt{\alpha_c-\alpha}$
- α = α_c: 一个退化实不动点 $x_c$
- α > α_c: 无实不动点，复共轭对 $x_\pm = x_c \pm i\sqrt{\alpha-\alpha_c}$

**本推导场景(平面上的叉式分岔)**:
$$f_1(x,y) = 0, \quad f_2(x,y) = y \cdot h(x,y) = 0$$

- y=0 分支: 总是存在(实不动点)，稳定性由λ_y决定
- y≠0 分支: 当 $h(x,0)$ 改变符号时出现/消失(通过叉式分岔)

**数学分类**:
- GRZ: saddle-node分岔 → 余维数1(需要一个参数调节)
- 本推导: pitchfork分岔(对称破缺型) → 余维数1，但y→-y对称性是"内置的"

### A.2 物理诠释的对比表

| 特征 | GRZ场景 | 本推导的BL Class 11场景 |
|------|---------|------------------------|
| 实不动点的命运 | 合并后湮灭 | 持续存在(或变为鞍点) |
| 复共轭对的起源 | "幽灵"实不动点 | y≠0分支的开启 |
| 行走行为的驱动 | 唯一IR目标靠近实轴 | 鞍点排斥 + 复吸引子 |
| 控制参数 | 全局参数($Q$, $N_f$) | 非厄米变形强度 + 算子选择 |
| 真正的连续相变是否可能 | 在分岔点后不可能 | 在λ_y>0区可能 |
| 螺旋RG流 | 不适用(1维流) | 适用(2维流在复平面上) |

### A.3 统一视角

两个框架可以统一在更一般的二维分岔理论中。考虑双参数族:
$$F(x,y;\alpha,\beta) = \begin{pmatrix} (x^2-y^2-\alpha) + \beta x \\ 2xy + \beta y \end{pmatrix}$$

- β = 0: 纯GRZ型(saddle-node在x方向)
- α = 0, β ≠ 0: 纯BL Class 11型(pitchfork在y方向)
- α ≠ 0, β ≠ 0: 混合型 → 最一般的DQCP非厄米变形可能落在此区

这个统一框架值得在v2后续工作中深入研究。
