# DQCP-Entanglement

> 课题：纠缠熵异常对数修正能否鲁棒区分真正连续DQCP与弱一阶赝临界？
> 所属长命题：LP-5（DQCP：真正连续还是弱一阶？）
> 子命题：LP5-S1
> 状态：进行中 — Phase 0（初始化）
> 创建日期：2026-06-01

## 长命题背景

退禁闭量子临界点（DQCP）是超越Landau-Ginzburg-Wilson范式的量子相变理论。
核心问题：Néel-VBS相变是真正的连续相变（涌现SO(5) CFT），还是被有限尺寸效应掩盖的弱一阶相变？

## 本课题目标

系统评估纠缠熵异常对数修正作为DQCP诊断工具的鲁棒性。
核心冲突：Song et al. (2025) 声称EE对数修正确认涌现SO(5) CFT；
D'Emidio-Sandvik (2024) 挑战称弱一阶赝临界可产生类似信号。
