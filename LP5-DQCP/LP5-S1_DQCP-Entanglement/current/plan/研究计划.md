# 研究计划 — DQCP-Entanglement v1

## 长命题背景（LP-5）

**长命题：** 退禁闭量子临界点（DQCP）是真正的连续相变（超越LGW范式，涌现SO(5)幺正CFT），还是被有限尺寸效应掩盖的弱一阶相变（伪临界，固定点湮灭→复CFT）？

**物理系统：** 正方晶格J-Q模型（Néel → VBS相变），以及SU(N)推广（SU(2)证据偏B，SU(N≥8)证据偏A）

## 子命题 LP5-S1

**命题表述：** 纠缠熵（EE）异常对数修正能否作为DQCP性质的鲁棒诊断工具——即能否在有限尺寸数值数据中统计显著地区分"真正连续CFT的对数修正"与"弱一阶赝临界的伪对数行为"？

### 驱动矛盾（文献验证后修订版）

**实际文献格局（Phase 0检索确认）：**
多组独立QMC研究（Deng+Liu PRL 2024、D'Emidio+Sandvik 2024、Song Science Advances 2025、Takahashi 2024）达成共识：SU(2) J-Q模型的DQCP是弱一阶相变。EE对数修正来自SO(5)→O(4)自发破缺的4个Goldstone模（N_G=4），而非CFT的共形不变性。

**修订后的核心矛盾：**

**命题A（Goldstone模解释 — Deng/Liu + Liu/Zhou/Yan）：**
EE对数修正的系数指示N_G=4个Goldstone模→涌现SO(5)在热力学极限下自发破缺到O(4)→相变是弱一阶的。对数修正是SSB的可靠诊断标志。

**命题B（方法论怀疑 — 本课题立场）：**
当前EE对数修正作为诊断工具的可靠性未经系统量化。不同提取方案（Deng的smooth boundary扣除 vs D'Emidio的corner subtraction vs Song的有限尺寸标度）给出不同数值但未交叉比较。在缺乏盲测和统计功效分析的情况下，领域可能过早收敛到共识。

**为什么不能同时为真：**
如果不同EE提取方案在统计误差范围内一致→诊断工具鲁棒→共识可信。如果方案间的差异超出统计误差→诊断工具不够鲁棒→"共识"可能是方法论共谋（所有方法共享未声明的假设）。

**为什么至今未解（障碍链）：**
1. 不同组的原始QMC数据未公开共享→无法在统一框架下再分析
2. EE提取的方案依赖性从未被系统量化（这是本课题的核心贡献点）
3. 区分"Goldstone模对数"与"复CFT伪对数"需要尚未设计的判决实验
4. 合成数据方法（已知ground truth的EE生成）尚未应用于此问题

### 三步推进

#### Phase 1：文献整合 + 理论框架搭建

**目标：** 建立EE对数修正的完整理论分类学——在CFT、弱一阶、伪临界三种情形下的所有已知解析/数值结果。

**具体任务：**
1. 汇编所有J-Q模型EE数值计算文献（Song 2025, D'Emidio-Sandvik 2024, Sandvik-Zhao 2020, 及相关工作）
2. 从CFT理论推导EE对数修正的精确形式（包括有限尺寸修正、边界效应）
3. 从弱一阶理论推导伪对数行为的参数依赖（ξ/L比值下的有效对数项）
4. 建立"可混淆性矩阵"：在什么(ξ, L, 精度)参数范围内，两种假设不可区分？

**产出：**
- 文献库（带反例栏）
- EE对数修正的理论分类学
- 可混淆性矩阵（初步）

**Phase价值分类：** [核心] — 直接推进北极星命题的基础

#### Phase 2：核心分析 — 量化诊断鲁棒性

**目标：** 在统一的统计框架下，量化EE对数修正作为"连续vs弱一阶"诊断工具的统计功效和假阳性率。

**具体任务：**
1. 构造两类假设的合成EE数据生成器：
   - H₁（真CFT）：S_EE = (c/6)log(L) + b + O(1/L)，c来自SO(5) CFT
   - H₂（弱一阶）：S_EE = (c_eff(L,ξ)/6)log(L) + b(L,ξ)，c_eff在有限L下接近SO(5)值
2. 在典型QMC可达尺寸（L=8-64）和精度下，计算：
   - 贝叶斯因子 BF(H₁ vs H₂) 作为L的函数
   - 区分所需的最小系统尺寸L_min
   - 对QMC系统误差的敏感性
3. 重新分析已发表数据：在统一框架下评估Song 2025和D'Emidio-Sandvik 2024的结论各自需要的假设

**产出：**
- EE对数修正诊断的统计功效曲线
- 区分的L_min估计
- 已发表数据的统一再分析

**Phase价值分类：** [核心] — 直接回答北极星问题

#### Phase 3：判据设计 + 盲测建议

**目标：** 设计一个可执行、预注册的判决方案，使领域能够客观地决定EE对数修正是否解决了DQCP争议。

**具体任务：**
1. 设计判决标准：在什么条件下，EE对数修正可以声称"确认"连续DQCP？
2. 给出盲测方案：如何在不预设结论的情况下收集/分析EE数据
3. 推广检验：同样的方法论是否适用于其他DQCP候选系统（Kagome, triangular lattice等）？
4. 若EE不足以单独判决→设计EE与其他可观测量（Binder cumulant, correlation length ratio）的联合诊断

**产出：**
- 预注册风格的判决方案
- 盲测协议
- 联合诊断矩阵（如需要）

**Phase价值分类：** [核心] — 为领域提供可操作的方法论

### 预期产出对长命题的影响

- **若EE对数修正确实鲁棒**（当前L下b=2的提取对拟合方案/数据选择稳健）→ 确认N_G=4 Goldstone模→确认SO(5)→O(4) SSB存在→支持弱一阶共识的基础牢固
- **若EE对数修正不鲁棒**（不同方案给出不一致的b或b表现出L依赖性）→ 共识的方法论基础需重新审视→可能需要L>>ξ才能真正的判决（L_max≥300+）
- **若揭示II vs III在L<<ξ下的不可区分性**（这是GATE 2/3的核心发现）→ 为领域提供了关键的"我们知道我们不知道什么"地图→方法论贡献
