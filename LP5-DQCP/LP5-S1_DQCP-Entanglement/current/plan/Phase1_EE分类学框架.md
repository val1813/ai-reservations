## 1. EE标度形式的完整分类学

### 1.1 基本设定

考虑d=2空间维度（2+1D时空）的量子多体系统。子系统A为L×L/2矩形（光滑边界，无尖角）。纠缠熵的标度形式为：

S_EE(L) = a L + b log(L) + c + O(1/L)

物理量身份证Q1-Q2详细定义了各参数。

### 1.2 情形I：真正连续CFT（ξ = ∞，光滑边界）

**标度形式：**
S_EE(L) = a L + γ + O(1/L)

**关键特征：**
- b = 0（无对数修正）
- 光滑边界不产生对数项
- 对数项仅在有尖角时出现：S_corner = a L + s(θ) log(L) + O(1)

**物理机制：**
CFT的纠缠结构由应力张量关联函数完全确定。光滑边界下，边界曲率引入的次领头贡献是O(1)而非O(log L)。

**在J-Q模型中的应用：**
如果DQCP是真正连续的涌现SO(5) CFT，光滑边界EE不应有对数项。但可能有附加的Goldstone贡献（见情形II）。

### 1.3 情形II：自发对称性破缺 — Goldstone模（ξ = ∞）

**标度形式：**
S_EE(L) = a L + (N_G/2) log(L) + c + O(1/L)

**关键特征：**
- b = N_G/2（正的确定对数修正）
- N_G = 破缺生成元数
- 即使光滑边界也存在对数项（区别于CFT）
- 对数项来源：Goldstone模的零模涨落（Anderson塔状态）

**N_G的确定：**
- SO(N)→O(N-1)：N_G = dim SO(N) - dim O(N-1) = N(N-1)/2 - (N-1)(N-2)/2 = N-1
- SO(5)→O(4)：N_G = 10 - 6 = 4 → b = 2
- SO(3)→O(2)：N_G = 3 - 1 = 2 → b = 1

**在J-Q模型中的应用：**
Deng et al. (PRL 2024) 测量到b对应N_G=4→SO(5)→O(4)→DQCP是弱一阶的（有SSB即非连续）。

### 1.4 情形III：弱一阶 — 有限ξ（真正SSB存在）

**标度形式（修正后）：**
S_EE(L) = a L + (N_G/2) · G(L/ξ) · log(L) + c + O(1/L)

其中G(x)为光滑crossover函数：
- G(x) → 1 当 x → 0（L << ξ：Goldstone模充分激发→b_eff → N_G/2）
- G(x) → 0 当 x → ∞，且衰减为exp(-x)（Goldstone模获得质量间隙~1/ξ→指数抑制，非饱和为常数）

**修正说明（GATE 2 reviewer发现）：** 原公式使用log(min(L,ξ))在L=ξ处不可导（min函数引入非物理扭折）。修正为G(L/ξ)·log(L)，在L>>ξ时G→0指数衰减→对数项完全消失，恢复面积律。当L>>ξ时，S_EE → aL + c' + O(exp(-L/ξ))，非 aL + (N_G/2)log(ξ) + c（饱和为常数）。

**在J-Q模型中的应用：**
这是当前共识场景。ξ估计为~10³晶格常数。当前QMC可达L~48-96→远小于ξ→b_eff≈2（N_G=4）。

### 1.5 情形IV：伪临界 — 无真正SSB

**标度形式：**
S_EE(L) = a L + b_eff(L; ξ, ω) log(L) + c + O(1/L)

其中ω为一阶强度参数（如潜热/界面张力）。

b_eff(L; ξ, ω) 不是普适常数：
- 在L << ξ时可能接近N_G/2但非精确等于
- 没有真正SSB，但有限L下传递体态的低能激发谱"看起来像"Goldstone模
- b_eff是L和ξ的连续函数，非crossover的阶跃行为

**与情形III的本质区别：**
- 情形III：真正SSB存在→b_eff → N_G/2（普适）当 L << ξ
- 情形IV：无真正SSB→b_eff(L)连续漂移，无饱和平台

### 1.6 情形V：复CFT / 行走耦合（固定点湮灭）

**标度形式（参考Gorbenko-Rychkov-Zan 2018, arXiv:1807.11512）：**
S_EE(L) = a L + b_eff(L) log(L) + c + O(1)

其中b_eff(L)本身为L的缓变（对数尺度行走）函数：
b_eff(L) ~ b₀ / (1 + α log(L/Λ))

固定点湮灭→耦合常数行走→有效对数修正系数在log L尺度上缓慢衰减。不同于情形III的指数衰减（exp(-L/ξ)），复CFT的"行走"在log L中体现——EE用L=10和L=100看到不同的b_eff值。

**⚠️ 标注：** EE的复CFT标度形式目前尚无严格第一性原理推导。Gorbenko-Rychkov-Zan (2018)推导了walking耦合对关联函数的影响，但向EE的映射是本课题的猜想性推广。更精确的推导需要从复共形数据的纠缠第一定律出发。该情形的状态标记为"理论猜想"而非"已确立结果"。

**关键特征（如果log-周期振荡存在）：**
- b_eff(L)的缓慢衰减（log-而非指数-尺度）
- 若虚部产生振荡：b_eff(L) ≈ Re[b] + A sin(Ω log(L) + φ)，但振幅A和频率Ω的关系未被严格推导
- 在ξ>>L时b_eff近似常数→与情形II/III不可区分

**当前评估：数据不足以排除此情形。若Im[Δ] ~ 0.1-0.5→在L=8-64范围内可能仅有~1个振荡周期→完全不可检测。**

### 1.6 情形VI：拟合伪迹（b ≠ 0但物理上没有对数项）[GATE 3 B博士贡献]

**标度形式（真实物理）：**
S_EE(L) = a L + c + d/L + e/L² + ... （无对数项）

**标度形式（错误的拟合提取）：**
在有限L范围（如L∈[8,48]）内，log(L)函数可被c' + d'/L近似（相关性r² > 0.98）。用三参数拟合S = aL + b log L + c在有限且无正交化设计的L集合上，即使真实b=0，也可提取出统计显著的b ≠ 0。

**检验方案（来自B博士）：** 将该拟合方案应用于J-Q模型的深VBS相（Q/J大，ξ小）→若也提取出b ≠ 0→方案有偏。

**关键特征：**
- 提取的b对拟合区间[L_min, L_max]系统性依赖
- Bootstrap重采样显示b分布多模态或不稳定
- 增加高阶修正项（1/L, 1/L²）后b值大幅变化
- log L和1/L在L∈[8,48]上的非正交性是根源

**对DQCP文献的威胁：** 低概率但需排除——需要对照组实验。

### 1.7 情形VII：规范场边缘模（无SSB但有b ≠ 0）[GATE 3 B博士贡献]

**标度形式：**
S_EE(L) = a L + b_gauge log(L) + c + O(1)

在涌现规范理论中，Hilbert空间非简单A⊗B张量积。规范不变性强制在纠缠边界上引入"边缘模"自由度→独立于Goldstone模的对数修正。

**关键特征（区别于情形II）：**
- b_gauge不随Rényi指数n变化（Goldstone贡献有n依赖性）
- b_gauge对边界条件/通量插入敏感
- b_gauge不与任何SSB关联→在完全无SSB的退禁闭理论中仍存在

**对DQCP共识的威胁：** 若b=2部分来自b_gauge→N_G < 4→SO(5)破缺模式被高估。

### 1.8 情形VIII：近边缘算子（log²修正）[GATE 3 B博士贡献]

**标度形式：**
S_EE(L) = a L + b log L + b' log² L + c + O(1)

若DQCP的monopole算子的标度维数Δ_mon ≈ 3（近边缘）→产生log²修正。

**关键特征：** log²(L)项是定性标志；b_eff(L)在可达L范围内变化O(1)量；在有限L数据中，log²项可被误读为常数b的漂移。

**对DQCP文献的威胁：** 当前所有三组仅拟合log(L)项，未搜索log²(L)——若有→拟合b系统性依赖L范围。

## 2. 三种提取方案的映射与差异

### 2.1 方案A：尖角扣除法（D'Emidio-Sandvik 2024）

**基本思想：**
1. 同时测量光滑边界和含尖角(45°倾斜切割)子系统的EE
2. 光滑边界的EE = aL + (N_G/2) log(L)（Goldstone贡献）
3. 含尖角的EE = aL + s(θ) log(L) + (N_G/2) log(L)（尖角+Goldstone贡献）
4. 扣除：ΔS = S_corner(L) - S_smooth(L) = s(θ) log(L)

**提取量：** s(θ)——尖角的普适贡献（与Goldstone贡献分离）

**优点：**
- 原则上消除了N_G的依赖
- 若s(θ)匹配SO(5) CFT预测→支持涌现SO(5)

**缺点：**
- 假设两个子系统几何的Goldstone贡献完全相同
  - ⚠️ **潜在漏洞：** 如果倾斜切割改变了二分区适应VBS涨落的方式（D'Emidio自己承认！），则Goldstone贡献可能不同
- 尖角角度固定为45°，不可调——无法检验角度普适性
- 扣除放大了相对统计误差

### 2.2 方案B：光滑边界扣除（Deng-Liu-Guo-Lin 2024）

**基本思想：**
1. 仅使用光滑边界EE（避免尖角复杂性）
2. 拟合 S(L) = aL + b log(L) + c
3. 提取b → N_G = 2b

**提取量：** b = N_G/2——Goldstone模数

**优点：**
- 直接计数Goldstone模，物理意义清晰
- 几何简单，不涉及尖角的额外假设

**缺点：**
- 需要精确扣除面积律项(aL)——a的拟合与b的拟合共线
- 拟合区间(L_min, L_max)的选择影响b的值
- 在小L下，O(1/L)修正可能与log(L)混淆

### 2.3 方案C：有限尺寸标度（Song et al. 2025）

**基本思想：**
1. 对多N值（N=2,3,...,10）计算EE
2. 提取每个N的b(N)
3. 找b(N)从"反常"（非零）过渡到"共形"（零或极小值）的N_c

**提取量：** b(N)作为N的函数→临界N_c

**优点：**
- 利用N作为控制参数，系统性最强
- 若N_c≈7-8处有明确过渡→大N下DQCP可能真正连续

**缺点：**
- 每个N需要独立的QMC计算（计算代价极高）
- 有限尺寸伪标度：ξ(N)随N增大→在相同L下，大N的数据可能在L << ξ(N)区域→看到的"共形"可能只是伪标度
- 无法独立验证b(N)的非零值来自Goldstone模还是尖角贡献

## 3. 可混淆性矩阵

### 3.1 定义

**可混淆性：** 给定两个理论场景H₁和H₂，在实验/数值数据(D, ΔD)下，BF(H₁ vs H₂) < 3的概率（即数据无法偏好任何一个假设）。

可混淆性 = P(BF < 3 | H₁ true, (L_max, σ_stat))

### 3.2 二维混淆空间（补充完整版）

C(5,2)=10个两两混淆对中，以下6对最关键：

#### 混淆对0（最重要！）：真正连续SSB (II) vs 弱一阶 (III) — L<<ξ区间的不可区分性

**关键问题：** 如果所有可达到的L都 << ξ（当前QMC: L_max≈48-96, ξ估计≈10²-10³），情形II(ξ=∞, b=N_G/2常数)和情形III(ξ>>L, b_eff≈N_G/2在L<<ξ)在EE上的预测完全相同。

**量化：**
当L_max/ξ < 0.1时：
- II: b(L) = N_G/2 = 2（严格常数）
- III: b_eff(L) = N_G/2 · G(L/ξ) ≈ 2 · (1 - O(L/ξ)²) ≈ 1.96-1.99（近乎常数）
- 差异Δb ≈ (N_G/2) · (L/ξ)² ~ 0.01-0.04 << σ_b ~ 0.1

**结论：L<<ξ时，没有任何EE测量可以区分"ξ=∞的真连续DQCP"和"ξ>>L的弱一阶"。Deng et al.和Song et al.的所有诊断在此条件下不能声称"确认弱一阶"——它们只确认了N_G=4的Goldstone模存在性（即SSB的存在），但不回答"SSB发生在连续相变中还是弱一阶共存区中"。**

**解锁条件：** L_max ⪆ ξ/3 → 需要L_max ≈ 300+。

#### 混淆对1：真正SSB+Goldstone (情形II/III) vs 伪临界无SSB (情形IV)

**关键区分量：** b_eff(L)对L的依赖性
- 情形II/III：b_eff→N_G/2常数平台（L << ξ时）
- 情形IV：b_eff(L)连续漂移，无平台

**混淆条件：** 如果σ_b（log系数提取的统计误差）大于平台和漂移之间的差异→混淆

**量化：**
设情形III：b_eff(L) = 2.0 ± 0.1（统计）
情形IV：b_eff(L)从1.5漂移到2.0在L=16-64（伪标度漂移Δb≈0.5/log(L)≈0.1-0.15）

若σ_b ≈ 0.1-0.15→在L_max=64时，两个情形的b值差~0-0.5→在1-3σ边缘→需要L≥128或σ_b≤0.05才能3σ区分

**结论：当前QMC数据(L≤64, σ_b≈0.05-0.1)最多给出~1.5-2σ的暗示，不足以声称"确认"。**

#### 混淆对2：Goldstone模 (情形III) vs 复CFT振荡 (情形V)

**关键区分量：** 对数修正的振荡特征
- 情形III：b_eff单调趋于N_G/2
- 情形V：b_eff(L)有log-周期振荡

**混淆条件：** 如果振荡幅度A << σ_b→不可检测

**量化：**
复CFT预测：A ~ O(1) × Im[Δ]（Δ为湮灭固定点之间的复标度维数差）
若Im[Δ] ~ 0.1-0.5（典型固定点湮灭参数）→ A ~ 0.05-0.25
若σ_b ≈ 0.1→振荡在1-2σ水平→不可检测

**结论：在L=8-64范围内可能仅有~1个振荡周期→无法区分。**

## 4. 当前数据和方法的诊断能力评估

### 4.1 Deng-Liu-Guo-Lin (PRL 2024) 的诊断声张

**声张：** 光滑边界EE对数修正→N_G=4→SO(5)→O(4)→弱一阶

**验证状态：**
| 验证项 | 状态 | 证据强度 |
|--------|------|---------|
| 对数项存在性（b ≠ 0） | ✅ 已验证 | >5σ（对数vs常数的BF很大） |
| b = 2（N_G = 4） | ⚠️ 部分验证 | b的统计误差~0.1→b=2在~20σ内（好）但b=3/2或b=5/2也可在3-5σ？ |
| SSB vs 伪临界的区分 | ⚠️ 未充分验证 | 未检查b_eff(L)的平台性（需要多于3个L的数据点） |
| 排除复CFT | ❌ 未验证 | 未搜索振荡特征 |

### 4.2 Song et al. (Sci. Adv. 2025) 的诊断声张

**声张：** N < N_c≈7-8反常对数→非共形；N ≥ N_c 共形行为

**验证状态：**
| 验证项 | 状态 | 证据强度 |
|--------|------|---------|
| N依赖的b(N)变化 | ✅ 已验证 | b(N)系统性随N减小 |
| N_c≈7-8处有定性过渡 | ⚠️ 部分验证 | 过渡是crossover还是sharp？样本点N=2,3,...,10→在N=7-8处只有1-2个点 |
| 大N下排除伪标度 | ❌ 未验证 | 大N的ξ(N)可能>>L→看到的"共形"可能是L<<ξ效应 |

### 4.3 未闭合的跨方案交叉验证

**核心漏洞：** 三个方案从未在同一数据集上比较过。

如果三个方案给出不一致的b值→诊断工具不鲁棒→"共识"可能是方法论共谋。

**需要的数据：** 同一QMC系综的原始EE数据，用三种方案分别提取b→比较。

## 5. Phase 1 结论与Phase 2输入

### 5.1 理论框架确立

✅ 建立了五种情形的完整EE标度分类学（I-V）
✅ 映射了三种提取方案到分类学
✅ 构建了可混淆性矩阵
✅ 识别了当前诊断的四个未闭合漏洞

### 5.2 关键发现

1. **对数项存在性不是问题：** 四组独立确认log(L)项存在，BF很强。争议不在于"有没有log"，而在于"log意味着什么"。

2. **核心诊断漏洞：b_eff(L)的平台性未被检验。** 如果b_eff在不同L下不是常数而是漂移→伪临界；如果是平台→真正SSB。当前文献每个方案只给出单一b值（拟合所有L），未分L提取。

3. **三个方案在概念上等价但数值上可能不同：** 方案A的扣除假设漏洞最大（Zhu et al. PRL 2026证实了二分区几何敏感性）。方案B最直接但受a-b共线影响。方案C最系统但计算代价最高。

4. **复CFT尚未被排除：** 振荡特征可能需要L≥128才能检测，当前数据完全无法排除此场景。

### 5.3 Phase 2 输入

Phase 2的量化分析需要：
- 合成数据生成器（所有五种情形）
- 在L=8-128, σ_b=0.02-0.15参数范围内计算区分能力
- 贝叶斯因子曲线 BF(L_max) 作为系统尺寸的函数
