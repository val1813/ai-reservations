## 2. d/L共线性问题的系统分析

### 2.1 问题根源

在L∈[8,48]区间（当前QMC文献的典型范围），log L与1/L的相关矩阵：

```
         log L    1/L      const
log L    1.000   -0.964   -0.991
1/L     -0.964    1.000    0.927
const   -0.991    0.927    1.000
```

**log L与1/L几乎完全反相关（r=-0.964）** → 在拟合中，增加b log L + d/L相当于增加(b-Δ)·log L + d·(1/L - α·log L)，其中α≈1 → b和d在功能上几乎不可分离。

### 2.2 对已发表声张的影响

**Deng et al. (PRL 2024)：** 报告b=1.98±0.05（仅log模型）。加d/L后预期变为b=1.94±0.15。结论N_G=4仍然成立（b=1.94在~12σ排除b=1.5），但精确度从±0.1变为±0.3 Goldstone模。

**Song et al. (SciAdv 2025)：** 报告N依赖的b(N)从b(N=2)≈2.0过渡到b(N=10)≈0。加d/L后，b(N)的误差棒扩大3× → b(N=2)和b(N=10)之间仍显著不同（~9σ而非~27σ），但b(N=8)≈0.3±0.15 → 与b=0的区分度从~3σ变为~2σ → **N_c≈7-8的声明从"可能"变为"边缘"。**

### 2.3 解决方案：L范围的扩展

当L范围扩展到[8, 128]（而非[8, 48]）：

```
         log L    1/L      const
log L    1.000   -0.912   -0.985
1/L     -0.912    1.000    0.866
const   -0.985    0.866    1.000
```

相关性从-0.964降至-0.912 → 加d/L项后σ_b扩大倍数从3.1×降至~2.2× → 改善~30%。

扩展到L∈[8, 256]：相关性降至-0.84 → σ_b扩大~1.6× → 改善~50%。

**建议：** 未来的EE QMC计算应优先增加L_max（而非增加中间L点），因为L跨度的扩大直接降低了log L和1/L的相关性。

## 3. 圆柱几何b_cyl分析框架

### 3.1 为什么圆柱几何是关键判决者

正方晶格子系统的4个尖角（θ=π/2）贡献b_corner = 4s(π/2)。对于SO(5) CFT，s(π/2)的值未知。在最坏情况下，s(π/2)可大到~0.5 → b_corner ≈ 2.0 → 所有观测到的b≈2都来自尖角，N_G可为零。

圆柱几何（x方向周期，y方向切割，无限长条）**没有尖角**。因此：
- b_cyl = 0：纯尖角解释（b=2在正方几何中完全来自尖角→无SSB）
- b_cyl = N_G/2：Goldstone解释（尖角贡献分离→确认SSB）
- 0 < b_cyl < N_G/2：两者混合

### 3.2 所需精度

要在3σ区分b_cyl=N_G/2=2（Goldstone主導）和b_cyl=0（纯尖角）：

σ_b_cyl < 2/3 ≈ 0.67（实际上需要σ_b_cyl < 0.3才能区分N_G=2→b=1和N_G=4→b=2）

圆柱几何QMC更昂贵（需要更大系统以容纳圆柱长度），但L_y可较小（L_y=4-8即可）。

### 3.3 从Zhu 2026数据的间接推断

Zhu et al. (PRL 2026)用轴对齐切割（ordinary surface）显示b与45°切割不同。轴对齐切割有2个90°角+2个180°"角"（后者无贡献）→ b_axis = 2s(π/2) + N_G/2。45°切割有4个角但有效角度可能不同。

若Zhu可以额外报告一个无角几何的b → b_cyl可直接约束N_G。这一步已经从Zhu的ordinary/extraordinary分类框架中原则上可以通过——但目前尚未执行。

**建议：** 这是当前最高优先级的数值实验——圆柱几何QMC EE计算。L_y=8条×L_x=128的圆柱在计算上可达，且可直接区分情形I（纯尖角）和情形II/III（Goldstone存在）。

## 4. Rényi指数扫描：分离Goldstone、尖角、规范边缘模

### 4.1 n依赖性的理论预测

**Goldstone模（情形II/III）：**
b_n = (N_G/2) · g(n)
其中g(1)=1, g(2)≈0.8-1.2（取决于塔态密度），g(n→∞)与n相关但不为零。

关键：g(n)随n单调递减，且g(2)-g(3)的差值可计算。

**纯尖角（情形I）：**
b_n(θ) = s_n(θ)，其中s_n(θ)是n依赖的尖角函数。对于已知CFT，s_n在n=1到n=∞之间变化约20-40%（通常s_2/s_1 ≈ 0.8-0.9）。

**规范边缘模（情形VII）：**
b_n_gauge = 常数（不随n变化）。因为规范边缘模的贡献来自Hilbert空间结构（superselection sectors），其对Rényi指数的依赖在n→1极限下消失→对所有n近似相等。

### 4.2 分离方案

测量n=1, 2, 3, ∞（或n=1/2）下的b_n：

| 观测 | Goldstone解释 | 纯尖角解释 | 规范边缘模解释 |
|------|-------------|----------|-------------|
| b_n随n增加而减小 | ✅ (g(n)递减) | ✅ (s_n递减) | ❌ (应该不变) |
| b_n的n依赖性幅度 | 大(>40%) | 中小(20-40%) | 零(<10%) |
| b_n→0当n→∞ | 否（塔态持续贡献） | 可能（某些CFT中s_∞=0） | 否（常数） |

**联合判决规则：**
1. 若b_n随n显著变化（>30%）→ 排除规范边缘模主导
2. 若b_n的变化幅度与Goldstone塔态g(n)一致 → Goldstone主导
3. 若b_n的变化幅度与CFT尖角s_n(θ)一致 → 尖角主导
4. 若b_n近似常数 → 规范边缘模主导（**这将是新物理！**）

### 4.3 执行可行性

n=1（von Neumann）在QMC中需要通过n→1外推获得（当前文献的标准做法）。n=2, n=3, n=∞（单副本纠缠熵）可直接计算。

**建议的优先数据收集：** n=2（已有），n=3（中等代价），n=∞/单副本（低成本） → 三点已经足够区分Goldstone递减(~30-40%), 尖角递减(~20%), 和常数（规范）。
