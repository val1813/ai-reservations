# 可观测性检验 — DQCP-Entanglement v1

> 对每个关键子命题结论，检查其物理可观测性和可检验性

## 本课题的可观测性评估

### 直接可观测性

**EE对数修正** — ❌ 不可直接实验观测
- 纠缠熵在凝聚态实验中无法直接测量（需要全量子态层析）
- 但在数值计算（QMC）中可精确计算
- 本课题的核心结论仅适用于数值诊断领域

### 间接可检验性

**通过可观测量的约束：**
1. **自旋关联函数** — ✅ 可被中子散射实验测量
   - CFT预测特定的动量-能量标度→可在实验中检验
   - 若EE对数值验证确认连续DQCP→该预测获得间接实验支持

2. **Binder累积量** — ✅ 可数值计算
   - 临界点Binder累积量的普适值与EE对数修正独立
   - 联合使用多个诊断可交叉验证

3. **VBS序参量分布** — ✅ 可数值计算
   - 一阶相变：双峰分布
   - 连续相变：单峰（临界）分布
   - 但弱一阶在有限L下也接近单峰→同样有诊断鲁棒性问题

### 方法论层面

本课题的性质：**数值方法论研究** — 评估诊断工具本身的质量
- 结论本身不需要实验验证
- 结论的应用（指导未来的数值研究）是可操作的
- 产出：统计判据 + 盲测协议 → 领域可立即使用
