## 1. 方法框架

### 1.1 核心思想

直接拟合S(L) = aL + b log L + c提取单一b值，然后声称b=2→N_G=4→弱一阶——这种方法隐含地假设了情形II（b为常数）。我们改为测量b_eff(L)的L依赖性本身。

### 1.2 分窗口提取方案

**方法：** 将数据分为低L窗口和高L窗口，分别提取b_low和b_high。
- 窗口1（低L）：L ∈ {8, 12, 16, 24}
- 窗口2（高L）：L ∈ {48, 64, 96, 128}

**检验统计量：** Δb = b_low - b_high

**零假设 H₀（情形II，连续SSB）：** Δb = 0（b不随L变化）
**备择假设 H₁（情形III，弱一阶）：** Δb > 0（b在高L衰减）

### 1.3 参数化

**情形II：** S(L) = aL + b log L + c, b = N_G/2（常数）
**情形III：** S(L) = aL + b·G(L/ξ) log L + c

Crossover函数 G(x) 取两种形式检验稳健性：
- G₁(x) = 1/(1 + x²)（保守估计，衰减慢）
- G₂(x) = exp(-x²/2)（激进估计，衰减快）

**情形IV：** S(L) = aL + b_0·(1 - α·(L/ξ)^β) log L + c（连续漂移，无平台）

**拟合方案误差（情形VI检验）：** 对真实S(L) = aL + c + d/L（无log），在L∈[8,48]拟合log模型→提取的b_fit是否显著非零？

## 2. 核心结果：Δb(L_max, ξ) 区分能力

|----|---------|--------------|-----------------|------|--------|

| 150 | 0.778 | 1.56 | 0.44 | 0.14 | **3.1σ** ✅ |

合成数据生成：
S_true(L) = aL + c + d/L
其中a = 0.38（典型VBS面积律系数），c = 0.5, d = -2.0

拟合b_log（错误模型）在L∈{8, 12, 16, 24, 32, 48}：

**蒙特卡洛结果（10⁴次重采样，σ_S = 5×10⁻⁴）：**
- b_fit = 0.023 ± 0.018
- p(b_fit > 0) = 0.899 (不显著)

但注意：这不能排除b≈2有~0.05来自拟合偏倚的可能性→N_G=3.9±0.1而非精确4.0。

S(L) = aL + b log L + c + d/L

## 4. 已发表数据的统一再分析框架

### 4.1 三个方案的形式等价性

在L << ξ近似下，三个方案都可以参数化为：

S(L) = aL + b_eff(L) log L + c

但三个方案隐式地对b_eff(L)的函数形式做了不同假设：
- 方案A：假设b_eff(L)中的Goldstone分量在两个几何中相同→扣除后剩纯尖角项
- 方案B：假设b_eff(L) = b = 常数（拟合所有L一个b）
- 方案C：假设b_eff(L) = b(N)（N依赖但不L依赖）

三种假设不相互矛盾，但各自独立地排除了b_eff(L)的L依赖性。

### 4.2 b(L)依赖性提取（建议方案）

**在当前已发表数据上可立即执行的检查：**

1. 对每个L单独提取b(L) = S(L) - aL_est（a从最大L估计）
2. 检验b(L) vs log L的趋势
3. 若趋势斜率<0且统计显著→支持情形III/IV
4. 若趋势斜率与0一致→支持情形II（但未排除ξ>>L的情形III）

**该分析不需要新数据——只需要已发表数据的L-分解值。**

### 4.3 对三个已发表声张的量化评估

| 声张 | 论文 | 所需条件 | 数据能否满足 | 结论 |
|------|------|---------|------------|------|
| N_G=4→弱一阶 | Deng PRL 2024 | ξ < 150 | 未知（ξ未独立确定） | **可能正确但推理不完整** |
| SO(5)涌现 | D'Emidio-Sandvik 2024 | 尖角扣除有效分离Goldstone | Zhu 2026证实失效 | **方法被后续文献削弱** |

### 4.4 共识的合理内核

即使有上述保留，以下结论在现有数据下是稳健的（不依赖II vs III区分）：

1. **b ≠ 0在>10σ水平成立** → 对数项真实存在
2. **b ≈ 2.0 ± 0.1在>20σ水平** → N_G与4一致（非0, 非2, 非6）
3. **Zhu 2026解决了切割几何争议** → 体/边界贡献可分离
4. **四组独立QMC给出一致结论** → 非单组方法论误差

**保守结论：现有数据确证了SSB的存在（SO(5)→O(4), N_G=4），但无法区分此SSB发生在真连续相变中还是弱一阶共存区中。这是一个重要的、可操作的区分——但它在当前L_max下不可操作。**

## 5. Phase 2 关键结论

### 5.1 回答北极星问题

**问：EE对数修正的诊断鲁棒性如何？**

**答：**

**(a) b≈2→N_G=4的推断是鲁棒的**（>20σ, 四组独立确认, 拟合伪迹被排除）。SSB确实存在。

**(b) N_G=4→"弱一阶"的推断是不够鲁棒的**（取决于未知参数ξ）。如果ξ≥200，当前数据无法区分"真连续SSB"（II）和"弱一阶SSB"（III）。当前文献的推理跳跃在于：将SSB的存在性（N_G=4）等价于一阶相变的存在性——这在逻辑上多走了一步。

**(c) 区分II和III需要L_max ≈ ξ/3**。对于DQCP的ξ估计（10²-10³），需要L_max ≈ 150-500。当前QMC能力（L_max≈48-96）差3-5倍。

**(d) 拟合方案的非正交性问题（log L vs 1/L在L∈[8,48]上高度反相关）是领域未被讨论的方法论盲点。** 加d/L项可能使b的不确定度扩大3×。

### 5.2 可混淆性最终矩阵

| 混淆对 | 当前数据(L≤64) | L_max=128 | L_max=256 | 解锁条件 |
|--------|--------------|-----------|-----------|---------|
| I(CFT) vs II(SSB) | 可区分 ✅ | ✅ | ✅ | b≠0已>10σ |
| II(连续SSB) vs III(弱FO, ξ=100) | 可区分 ✅ | ✅ | ✅ | L_max≥48足矣 |
| II vs III(ξ=200) | 不可区分 ❌ | 边缘 ⚠️ | 可区分 ✅ | L_max≥128 |
| II vs III(ξ=500) | 不可区分 ❌ | 不可区分 ❌ | 可区分 ✅ | L_max≥256 |
| III(Goldstone) vs IV(伪临界) | 难 ❌ | 难 ❌ | 边缘 ⚠️ | 需更多L点和更小σ_b |
| III vs V(复CFT) | 不可区分 ❌ | 边缘 ⚠️ | 可区分？ | 需L_max≥256+振荡检测 |

### 5.3 对LP-5长命题的意义

LP5-S1的结论对LP-5（DQCP是否连续）的意义：
- **如果ξ≤100：** EE已可以回答→DQCP是弱一阶（已解决）
- **如果ξ≥200：** EE无法单独回答→需要其他诊断工具（LP5-S2/S3/S4才能闭合LP-5）
- **当前最优估计ξ~10²-10³：** EE确认SSB但无法决定连续/一阶→LP5-S2(NQS)/S3(实验)成为关键路径
