# 物理量身份证 — DQCP-Entanglement v1

> 每个关键物理量的精确定义、数学结构、计算方法和可观测性

## Q1: 纠缠熵 S_EE

**定义：** 子系统A的von Neumann纠缠熵 S_EE(A) = -Tr(ρ_A ln ρ_A)，其中ρ_A = Tr_Ā(|ψ⟩⟨ψ|)。

**数学结构：** 对于d=2空间维度（2+1D时空），纠缠熵 S_EE = a L + b log(L) + c + O(1/L)。
- 面积律项（∝L，d=2下为子系统周长）是非普适的
- 对数修正的系数b是普适特征（在CFT中有物理意义）
- ⚠️ 注意：d=2空间维度主导项是aL（周长），不是aL²（L²在3+1D才出现）

**在本课题中的计算方式：**
- QMC: 非平衡抽样→Rényi熵 S_n → n→1外推→von Neumann熵→有限尺寸标度提取对数修正
- 理论: 从CFT推导c的预期值（SO(5) CFT→特定c值）

**可观测性：** 间接——仅在数值计算中可测量（QMC），无直接实验探针（但可通过动力学结构因子等间接约束）

## Q2: 对数修正系数 b

**定义：** S_EE(L) = aL + b log(L) + c + ... 中的对数修正系数b。

**数学结构：**
- CFT光滑边界: b = 0
- CFT含尖角: b = Σ s(θ_i)，s(θ)为尖角函数
- SSB+Goldstone: b = N_G/2（即使光滑边界也有对数）
- 弱一阶: b_eff(ξ,L)非普适常数，依赖ξ/L
- 复CFT/行走: b_eff(L)为L的缓变函数

**在本课题中的计算方式：**
- 有限尺寸标度拟合：对多个L提取对数项→外推热力学极限下的c
- 贝叶斯推断：比较H₁(c=常数) vs H₂(c_eff依赖L)

**物理约束：** c ≥ 0（由熵的单调性），c_eff(L→∞) 对弱一阶→0（因为对数项在真正长程下消失）

## Q3: 相关长度 ξ

**定义：** 关联函数的指数衰减长度，ξ = -lim_{|r|→∞} |r|/log(G(r))。

**数学结构：**
- 连续相变: ξ ~ |g-g_c|^{-ν}，临界点发散
- 弱一阶: ξ有限但很大，ξ_max ~ exp(const/|g-g_c|) 或幂律截断

**在本课题中的计算方式：** 从QMC自旋关联函数提取，或从EE的标度分析反推。

## Q4: 贝叶斯因子 BF

**定义：** BF_{12} = P(Data | H₁) / P(Data | H₂)，两假设的相对证据。

**解读：** BF > 10 → H₁的强证据；BF < 0.1 → H₂的强证据；0.33 < BF < 3 → 无法区分。

**在本课题中的计算方式：** 基于合成EE数据的似然函数 + 先验 → 后验 → BF。
