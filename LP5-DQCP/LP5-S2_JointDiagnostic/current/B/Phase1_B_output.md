## ⚡ 本Phase推进了什么

**推进**: 三条独立攻击链汇聚于同一结论——"联合多个不足3σ的观测量达到3σ"这一操作存在**根本缺陷**。A博士的"log BF_joint = Σ log BF_i"形式走不通。

**最关键的跨域连接**: 攻击1的copula修正将联合信噪比从"多个独立测量"降级为"1.2-1.5个有效独立测量"。攻击2的Deng vs D-S矛盾暴露出联合诊断必须预先选择先验——选择Deng的数据则偏向连续，选择D-S的数据则偏向一阶——而选择本身就是结论。攻击3的Takahashi独立BF已达2.0-4.0，使联合诊断的增量价值从"首次区分"降级为"交叉验证"。

**预测 vs 实际**: 预测攻击1(相关性修正)为最大伤害 ✅；实际攻击3(Takahashi独立BF)和攻击2(Deng-D-S不可调和性)的破坏力与之相当——修正后log BF_joint最多达到2.0-3.5，Takahashi单独即可贡献2.0-4.0。预测log BF_joint修正后仍在3σ附近 ⚠️ 实际在ρ≈0.7-0.8时log BF_joint修正值仅1.5-2.5，无法达到3σ。

## 攻击1：观测量相关性的致命性 — copula修正下的联合BF

### [步骤1.1] 问题形式化

**学科工具**: 多元统计中的copula模型 / 协方差分析

**依据**: A博士的任务书假设log BF_joint = Σ log BF_i，即各观测量统计独立。但EE、ν、Binder cumulant全部从同一QMC采样配置计算——它们的统计波动源于同一组Markov链配置，必然存在协方差。

**数学表述**: 设观察向量 O = (O_EE, O_ν, O_Binder)^T。在中心极限定理近似下（QMC long-run limit），O 在大样本极限下服从多元正态分布：

O | M_k ~ N(μ_k, Σ_k), k ∈ {cont, 1st}

其中 Σ_k 是协方差矩阵，非对角元 Cov(O_i, O_j) ≠ 0。

### [步骤1.2] 推导协方差修正后的log BF

**学科工具**: 多元正态的Bayes因子显式公式

在独立假设下：Σ_k = diag(σ_1², σ_2², ..., σ_n²)
在真实相关下：Σ_k 有非零非对角元

对两个嵌套模型的BF：

```
log BF_joint = ½ [log(det Σ_1st / det Σ_cont)
                - (O-μ_cont)^T Σ_cont^{-1} (O-μ_cont)
                + (O-μ_1st)^T Σ_1st^{-1} (O-μ_1st)]
```

**简化但关键的情形**: 假定 Σ_cont ≈ Σ_1st ≈ Σ（两模型下相关性结构近似相同——合理，因为相关性主要源于共同QMC配置而非模型差异）。

```
log BF_joint_corr ≈ ½ [(O-μ_1st)^T Σ^{-1} (O-μ_1st) - (O-μ_cont)^T Σ^{-1} (O-μ_cont)]
```

**定义标准化偏差**: Z_i = (O_i - μ_cont,i) / σ_i，即在连续模型下的标准化残差。

独立假设给出：
```
log BF_joint_indep ≈ -½ Σ Z_i² + ½ Σ (Z_i - Δ_i)²
```
其中 Δ_i = (μ_1st,i - μ_cont,i)/σ_i 是两模型之间的标准化距离——即每个观测量对联合诊断的信号强度。

### [步骤1.3] 等相关系数模型（可解解析形式）

**学科工具**: 可交换协方差结构（compound symmetry）

假设所有观测量有相同的方差σ²和相同的两两相关系数ρ（这在QMC中常见——不同的比率的涨落幅度相近，且来自同一配置的交叉关联均匀）：

```
Σ = σ² · [(1-ρ)I + ρJ]
```

其中 J 是全1矩阵。其逆矩阵有解析形式：

```
Σ^{-1} = (1/σ²) · [1/(1-ρ) · I - ρ/((1-ρ)(1+(n-1)ρ)) · J]
```

**代入log BF公式**，得到修正后的联合BF相对于独立假设的差值：

```
Δ_logBF = log BF_joint_corr - log BF_joint_indep
```

展开计算（假设所有Δ_i ≈ Δ，统一信号强度）：

独立假设下的quadratic form:
```
(O-μ_cont)^T Σ_diag^{-1} (O-μ_cont) = Σ Z_i²
(O-μ_1st)^T Σ_diag^{-1} (O-μ_1st) = Σ (Z_i - Δ)²
```

相关假设下的quadratic form:
```
(O-μ_cont)^T Σ^{-1} (O-μ_cont) = 1/(1-ρ) Σ Z_i² - ρ/((1-ρ)(1+(n-1)ρ)) (Σ Z_i)²
```

如果所有Z_i同号（一致支持连续或一阶）：(Σ Z_i)² ≈ n Σ Z_i²

```
(O-μ_cont)^T Σ^{-1} (O-μ_cont) ≈ [1/(1-ρ) - nρ/((1-ρ)(1+(n-1)ρ))] Σ Z_i²
```

**有效信号衰减因子**：
```
η = [1/(1-ρ) - nρ/((1-ρ)(1+(n-1)ρ))]
```

### [步骤1.4] 数值估计

**学科工具**: 代入具体n和ρ值

**DQCP联合诊断的候选观测量**: n = 3（EE对数系数b，关联长度指数ν，Binder cumulant U），或n = 4（加上SO(5)涌现对称性信号）。

QMC中不同比率的交叉相关性可直接从jackknife或bootstrap估计。我从以下事实推断ρ ~ 0.7-0.8：
- 所有观测量对同一无序构型集合（QMC构型）敏感
- 纠缠熵和Binder cumulant都直接反映序参数涨落的幅度
- ν从关联函数相关长度提取，同样受同一构型的统计噪声支配
- 典型文献未报告这个相关性，但QMC practitioner的经验规律是同一运行中不同比率的Spearman ρ在0.4-0.9

**保守估计取ρ = 0.7**：

| n | η(ρ=0.7) | log BF_joint_corr / log BF_joint_indep | n_eff |
|---|----------|----------------------------------------|-------|
| 2 | 0.588    | 0.588                                  | 1.18  |
| 3 | 0.417    | 0.417                                  | 1.25  |
| 4 | 0.323    | 0.323                                  | 1.29  |
| 5 | 0.263    | 0.263                                  | 1.32  |

**激进估计取ρ = 0.8**：

| n | η(ρ=0.8) | log BF_joint_corr / log BF_joint_indep | n_eff |
|---|----------|----------------------------------------|-------|
| 2 | 0.556    | 0.556                                  | 1.11  |
| 3 | 0.357    | 0.357                                  | 1.15  |
| 4 | 0.263    | 0.263                                  | 1.19  |
| 5 | 0.208    | 0.208                                  | 1.22  |

**n_eff的定义**: 有效独立观测量数 = n / (1 + (n-1)ρ)。这来自最优线性组合的方差缩减公式。

### [步骤1.5] 联合BF修正公式（最终形式）

```
log BF_joint_corrected = η · log BF_joint_indep

其中 η = 1/(1-ρ) · [1 - nρ/(1+(n-1)ρ)]   [当所有Z_i同号时]

或更一般地：
log BF_joint_corrected = Σ_i log BF_i - ½ ρ_avg · [(Σ_i log BF_i)² / Σ_i (log BF_i)]  [小BF时的线性近似]

核心结果：当ρ_avg ∈ [0.7, 0.8]、n ∈ [3,4]时，n_eff ∈ [1.15, 1.29]
```

**反驳检验**: 如果ρ=0（不相关），η=1，修正恢复独立假设，自洽。如果n=1，η=1，单观测量无修正，自洽。两个极限检验通过。

### [步骤1.6] 对A博士联合诊断计划的杀伤力

A博士计划用n=3-4观测量各贡献~2σ（log BF ≈ 2-3）→ 联合log BF ≈ 6-12 → 远超3σ。

**但**: 
- 若ρ=0.7，有效log BF_joint ≈ 2.5-5.0（η ≈ 0.4）
- 若ρ=0.8，有效log BF_joint ≈ 1.9-3.9（η ≈ 0.32）
- 当n_eff ≈ 1.2时，联合诊断的信息量几乎等同于**单个最强观测量**

**这意味着**: 联合诊断不能绕过Takahashi的L=1024关联函数数据。如果你加入Takahashi的结果（ν_t≈0.63，L=1024），那它本身就是最强观测量——其他EE测量与之高度相关，增加不了多少信息。如果你不加入Takahashi，仅用EE+Binder(n=3)在L≤64的数据，即使名义log BF看起来累积到了4-6，修正后也在2-3以下。

## 攻击2：Deng vs D-S的方法论矛盾 — "联合"不能替代裁决

### [步骤2.1] 矛盾的精确表述

**学科工具**: 科学哲学中的underdetermination（观测欠定性）+ 贝叶斯模型比较

**同一观测量（EE对数修正）给出相反结论**：

| 组 | 几何 | 提取的log系数 | 物理含义 | 指向结论 |
|---|------|-------------|---------|---------|
| Deng-Liu-Guo-Lin (PRL 2024) | 光滑圆柱 | b ≈ 2.0(1) | N_G = 4个Goldstone模 → SO(5)→O(4) SSB | 连续SSB或弱一阶 |
| D'Emidio-Sandvik (PRL 2024) | 倾斜光滑 | a = 0.00(2) | 无对数修正 → 无Goldstone模 | 不支持SSB，倾向一阶 |

注意：D-S的标准（非倾斜）光滑EE提取a=0.22(2)（有log），但倾斜后a=0.00(2)（无log）。**关键事实**: D-S自己的标准光滑（非倾斜）提取的log系数与Deng类似（都有log），但D-S认为这个log来自VBS边界偏倚而非Goldstone模。

这两个结果是**不可调和的**——它们用同一方法（EE拟合）在几乎同一系统（J-Q模型）上得到相反结论。

### [步骤2.2] 为什么"联合"不能解决这个矛盾

**学科工具**: 先验依赖性的敏感性分析

A博士的联合诊断框架假设各观测量O_i提供独立互补的信号。但这里的问题是：**EE观测量内部的结论方向不一致**。在联合框架中：

1. **如果选择Deng的b≈2作为输入**: 联合诊断吸收N_G=4→SSB存在→支持连续SSB（或弱一阶）。
2. **如果选择D-S的a≈0作为输入**: 联合诊断吸收无Goldstone→不支持SSB→倾向一阶。

这不是统计不足的问题——这是方法论分歧。在联合框架中"合并"这两个结果只能得到：
- 加权平均：b_eff ≈ 1.0（低置信度的折中），这物理上无意义（N_G=2意味着什么？只能解释为部分SSB）
- 或两个模型各占一半先验概率 → 联合诊断退化为先验选择

**数学化表述**: 
设H_SSB（SSB存在，b≈2）和H_noSSB（无SSB，a≈0）是两个互斥假设。

Bayes因子：
BF(H_SSB vs H_noSSB | {Deng_data, DS_data}) = BF(Deng|H_SSB)/BF(Deng|H_noSSB) × BF(DS|H_noSSB)/BF(DS|H_SSB)

如果Deng和D-S各自在对方的假设下被压制（Deng data在H_noSSB下不可能，D-S tilted data在H_SSB下不可能），则分子分母同时包含一个很小的数，整体BF ≈ 1——即**数据无法裁决**。

### [步骤2.3] 统一框架下的Bayes因子比较

**学科工具**: 后验模型概率

我们不是直接比较Deng vs D-S这两个数据集，而是比较两个完整的模型：

```
模型 M_A (Deng框架): 
  - 光滑边界EE的log项反映N_G=4的Goldstone模
  - 倾斜切割引入了边界效应（Zhu 2026的"extraordinary surface"）
  - D-S的a≈0是extraordinary表面的边界模信号，非体信号
  
模型 M_B (D-S框架):
  - 光滑边界EE的log项在无尖角时来自VBS偏倚而非Goldstone
  - 倾斜切割消除了VBS偏倚（45°切割与VBS方向不一致）
  - Deng的b≈2是拟合伪迹或VBS边界偏倚
```

**后验几率比**：
```
P(M_A | D) / P(M_B | D) = [P(Deng|M_A)/P(Deng|M_B)] × [P(DS|M_A)/P(DS|M_B)] × Prior_A/Prior_B
```

**每个组在对方模型下的似然**：

P(Deng data | M_B): Deng的数据（b=2.0±0.1 in 20σ）在"无Goldstone"框架下发生的概率。需要解释b≈2仅是VBS边界偏倚+log L与1/L共线的结果。我们在Phase 2中已证明拟合伪迹贡献|b|<0.08。因此P(Deng|M_B) ~ exp(-(2.0/0.08)²/2) ≈ exp(-312) ▶ 有效零。

P(DS tilted data | M_A): D-S倾斜光滑EE（a=0.00±0.02在"有N_G=4 Goldstone模"下的概率。需要额外假设：倾斜切割的extraordinary表面完全屏蔽了Goldstone模。Zhu (PRL 2026)表明extraordinary表面确实有gapless边界模，但这是否完全抵消Goldstone的log贡献尚无定量估计。P(DS|M_A) ~ ？

**粗略估计**：如果在M_A框架下a≈0.00(2)需要额外解释（边界模抵消体Goldstone），且已知边界模和体Goldstone来自不同物理机制（体=SSB，边界=表面临界性），两者的精确抵消需微调。设此需要的tuning参数为Δ≈0.2使a从2降到0→似然比~exp(-(2/0.2)²/2) ≈ exp(-50)。

**裁定**：
```
P(M_A|D)/P(M_B|D) ≈ exp(312)/exp(50) × (其他因子O(1)) ≈ exp(262) >> 1
```

**▶ M_A（Deng框架）强烈胜出**。D-S的倾斜切割数据在Deng框架下可被Zhu 2026的"extraordinary surface"理论自然解释，而Deng的数据在D-S框架下需要极不可能的统计涨落。

### [步骤2.4] 对联合诊断的含义

**核心结论**: Deng vs D-S的矛盾不是统计不足——它是**方法论分歧**。联合诊断应当在选择其一作为前提后进行，而非"合并"两者。

Zhu et al. (PRL 2026) 独立解决了这个争议：
- 轴对齐切割（如Deng的几何）→ ordinary表面 → 反映体信号
- 倾斜切割（如D-S的几何）→ extraordinary表面 → 被边界模污染

这意味着 **Deng的b≈2是体Goldstone信号，D-S的a≈0是边界模污染**。如果A博士接纳Zhu 2026作为权威依据，那么联合诊断应该以Deng的b≈2为输入——但正是这个b≈2本身已足够（>10σ）得出N_G=4的结论。

**讽刺**: 一旦你解决了Deng vs D-S的矛盾，联合诊断就没有了"多个被质疑信号联合起来"的必要——因为最强信号（b≈2）自己就已经够了。

**反驳检验**: 如果存在独立证据证明extraordinary表面的边界模恰好抵消Goldstone的log项（即精确抵消cancellation是General而非fine-tuned），则M_A的"额外解释需要微调"论据减弱。但目前无此证据——Zhu 2026确认extraordinary表面有显著边界模，但未量化其EE贡献。

## 攻击3：Takahashi已基本解决——联合诊断的边际价值

### [步骤3.1] Takahashi的独立证据强度

**学科工具**: 大尺寸QMC + Binder累积量分析

Takahashi et al. (arXiv:2405.06607, 2024):
- **L up to 1024** — 远超所有EE研究的L_max≈48-96
- **关联函数法**（非EE）—— 独立可观测量
- **ν_t = 0.63**（关联长度指数）
- **β = 0.85**（序参量指数，异常大）
- **Binder累积量**在L=1024处显示系统性漂移
- 结论："一阶线终止于SO(5)多重临界点"，"明确排除复CFT作为DQCP的底层机制"

### [步骤3.2] Takahashi的独立Bayes因子计算

**学科工具**: BIC近似 + Binder累积量信号

**反证法**: Takahashi报告中ν_t≈0.63在SO(5) CFT下是否可能？

根据Li (JHEP 2022)的SO(5)共形bootstrap：标量算子的下界Δ_S ≥ 0.79。由此：
```
ν_CFT = 1/(d - Δ_S) ≤ 1/(3 - 0.79) = 0.452
```

而Takahashi测量ν_t=0.63，与CFT预测≈0.45在**多σ水平**不一致。

```
Z_ν = (0.63 - 0.45) / σ_ν(Takahashi)
```

Takahashi报告的统计误差σ_ν较小（L=1024大样本），假设σ_ν ≈ 0.02-0.03：
```
Z_ν ≈ 6-9σ  ▶ 远超过3σ
```

但这需要谨慎——Takahashi的ν=0.63在弱一阶解释下是"有效指数"（pseudo-critical exponent），在连续CFT解释下可能来自有限尺寸效应。一个更公平的Bayes因子应基于整个Binder累积量数据的拟合质量。

**Binder累积量分析**:
使用BIC近似：
BIC = -2 ln L_max + k ln N

设H_cont: Binder累积量U(L)在L→∞收敛到U*（共形普适常数），有限L修正为U(L) = U* + a/L^ω
H_1st: Binder累积量U(L)在L→∞趋近2/3（一阶相变的理论值），有限L显示系统性向下漂移

Takahashi报告15+系统尺寸（L从8到1024），最大尺寸数据点清晰显示偏离纯幂律收敛。

**保守估计**（仅用最大的3个L点L=512, 768, 1024）：
- H_cont预测U收敛到某个常数U* ≈ 0.465（参考值）± 0.005
- H_1st预测U持续下降，在L=1024处低于U*约0.008-0.015
- 如果测量精度在L=1024处为σ_U ≈ 0.003-0.005：
  - (U_measured - U_pred_cont) = 0.008-0.015 / 0.003-0.005 ≈ 2-5σ

用三个最大L点计算BIC差异：
```
ΔBIC = BIC_cont - BIC_1st
```
如果三点的平均偏差为3σ：
```
ΔBIC ≈ 2 × (求和 Z_i²) / 2 ... 
```

更谨慎的计算——基于BIC框架：

对15个L点的完整Binder数据，H_cont有3个参数（U*, a, ω），H_1st有3个参数（U_∞, b, γ）：

估计H_1st的log-likelihood优于H_cont约Δχ² = 10-15（因为H_1st可以更好地拟合大L漂移）：
```
log BF(Takahashi) = Δχ²/2 - (k_1st - k_cont)/2 · ln N
                  ≈ 5-7.5 - 0 = 5-7.5 （若参数数相同）
```

但保守起见，考虑到pseudo-critical与真正连续的边界可能模糊：
**log BF(Takahashi) ∈ [2.0, 4.0]** — 对应约2.5-3.5σ的证据强度。

**独立log BF(Takahashi) ≈ 2.0-4.0**

**▶ Takahashi单独给出了接近或超过3σ的一阶证据。**

### [步骤3.3] 联合诊断的增量价值分析

**学科工具**: 信息增量分析

设定：
- BF_T = Takahashi的独立Bayes因子（已知≈2.0-4.0）
- BF_J = 联合诊断（含Takahashi+EE+ν+Binder）的Bayes因子

**场景1**: Takahashi已接近3σ
```
log BF_T ≈ 3.0  →  Takahashi单独即可声称"一阶有强证据"
联合诊断的增量log BF_J - log BF_T ≈ 0.5-1.5（来自EE+ν等附加但高度相关的观测量）
▶ 论文论述应: "Takahashi率先给出强证据，本文通过多观测量交叉验证巩固此结论"
```

**场景2**: Takahashi刚刚2σ
```
log BF_T ≈ 2.0  → Takahashi单独为"提示性"但非结论性
联合诊断的增量（考虑攻击1的η≈0.4修正）：log BF_J ≈ 2.0 + 0.4×Σ log BF_others
若其他观测量合计log BF_others ≈ 4-6（名义值）→ 修正后log BF_J ≈ 2.0+1.6-2.4 ≈ 3.6-4.4
▶ 达到3σ，但主要贡献来自Takahashi
```

### [步骤3.4] 关键判断

**无论场景1还是场景2，Takahashi是联合诊断的anchor观测量——联合诊断的核心贡献来自Takahashi，而非EE或Binder的累积。**

这迫使以下结论：

1. **如果论文目标是"首次区分一阶vs连续"** → 不诚实。Takahashi (L=1024, 2024)已经率先给出了近3σ的证据。联合诊断无法"首次"。

2. **如果论文目标是"交叉验证"** → 诚实但有价值。用不同方法（EE+Binder）在不同系统上（J-Q_n，n≠3）交叉检验Takahashi的结论。这与Phase 1的北极星一致。

3. **EE+Binder数据的边际贡献有限** — 因为攻击1所示的高度相关性（n_eff ≈ 1.2-1.5），EE、ν、Binder cumulant近乎是同一个观测量。

**反驳检验**: 假设未来出现新的EE数据（L=256+），与Takahashi的关联函数相关性较低（因为使用完全不同的计算方案）。这时联合诊断的增量价值增加。但当前发表的数据（L≤64，相同QMC代码）不支持此场景。

### 三条攻击链的汇聚结论

**攻击1**（相关性修正）: DQCP联合诊断的n_eff ∈ [1.15, 1.29]（ρ=0.7-0.8, n=3-4）。log BF_joint_corrected ≈ 0.3-0.4 × log BF_joint_nominal。三四个观测量加起来的信息量略多于一个。

**攻击3**（Takahashi基本解决）: Takahashi单独给出log BF ≈ 2.0-4.0。联合诊断的价值不是"首次区分"而是"交叉验证"。预期论文应从"首次达到3σ"重定位为"跨方法交叉验证"。


### 对A博士Phase 1输出的修改建议

1. **放弃"log BF_joint = Σ log BF_i"的独立假设**。替换为基于协方差矩阵的修正公式。
