### 1.3 数据冲突编录

**冲突1: Deng vs D'Emidio-Sandvik (EE方法论)**
- Deng (PRL 2024): 光滑边界EE，b=2.0→N_G=4 Goldstone→弱一阶
- D'Emidio-Sandvik (PRL 2024): 斜切EE角系数a_∠=0.131(5)→SO(5) CFT匹配→连续
- **来源分析：** 两篇测量不同几何。Deng用光滑周长标度提取b（对数项来自Goldstone SSB）；D-S用尖角落标度提取a_θ（来自CFT普适性）。不同几何测量不同物理量。**不是直接矛盾而是正交互补。**

**冲突2: Sandvik/Zhao ν=0.455 vs Takahashi ν=1.4**
- SZ (CPL 2020): L≤448，Binder斜率 + Q关联函数 → ν=0.455
- T (arXiv:2405.06607): L=1024，关联函数 → ν=1.4（且ν随L增大）
- **来源分析：** 可能不是矛盾而是**running exponent**——ν_eff从L≈100的~0.5增大到L=1024的~1.4。这是"M_1st"预测的模式（有效ν随L增大，因RG流向一阶固定点前减速）。在M_cont下ν应不随L显著变化。**Takahashi的L=1024数据支持M_1st，但两者测的是不同L下的ν_eff，非相同L下的矛盾。**

**冲突3: Sandvik/Zhao "no runaway" vs Takahashi "weak first-order"**
- SZ: L=448无runaway，Binder累积量斜率自洽
- T: L=1024双峰出现，一阶特征可辨
- **来源：** 两项数据本身不矛盾——弱一阶的伪临界尺度ξ≈300-1000，L=448仍在伪临界区，L=1024进入真标度区。**两项数据共同约束ξ∈(448,1024)。**

## 第2步：单观测量 Bayes factor 计算

### 2.1 方法论

**框架设置：**
- 模型 M_cont: DQCP是真正连续的，由SO(5) CFT描述
- 模型 M_1st: DQCP是弱一阶的，SO(5)→O(4) SSB，ξ有限
- 先验: P(M_cont) = P(M_1st) = 0.5
- Bayes factor: BF_i = P(data_i | M_cont) / P(data_i | M_1st)
- 对数标度: log BF_i > 0 → 支持M_cont; log BF_i < 0 → 支持M_1st
- 3σ对应: |log BF| > 3（Jeffreys强证据；参考: ln BF=3 ≈ 4.3σ正态）

**似然计算：**
对每个观测量，使用 Savage-Dickey 比：
P(data_i | M) = ∫ P(data_i | θ, M) π(θ | M) dθ ≈ N(data_i | μ_M, √(σ_i² + σ_M²))

其中 σ_i 是观测误差，σ_M 是模型预测的宽度。

### 2.2 O1: EE光滑边界对数系数 b (Deng)

| 参数 | 值 |
|------|-----|
| 观测值 | b_obs = 2.0 |
| 观测误差 | σ_obs = 0.1（>20σ, 保守取0.1） |
| M_cont预测 | b_cont = 0 (CFT, 光滑边界无非SSB对数项) |
| M_cont模型宽度 | σ_cont = 0.3 (允许子领头非普适修正) |
| M_1st预测 | b_1st = 2 (N_G=4 Goldstone, SO(5)→O(4)) |
| M_1st模型宽度 | σ_1st = 0.3 (Goldstone计数不确定性) |

**计算：**
P(data|M_cont) = N(2.0 | 0, √(0.1²+0.3²)=0.316)
= 1/(√(2π)·0.316) · exp(-2.0²/(2·0.316²))
= 1.262 · exp(-20.03)
= 1.262 · 2.01×10⁻⁹
= 2.54×10⁻⁹

P(data|M_1st) = N(2.0 | 2, 0.316)
= 1/(√(2π)·0.316) · exp(0)
= 1.262

**BF₁ = 2.54×10⁻⁹ / 1.262 = 2.01×10⁻⁹**
**log BF₁ = -20.0**

判读：压倒性支持 M_1st（~10⁻⁹ = 1-in-a-billion level）

### 2.3 O2b: EE斜切角落系数 a_∠ (D'Emidio-Sandvik)

| 参数 | 值 |
|------|-----|
| 观测值 | a_obs = 0.131 |
| 观测误差 | σ_obs = 0.005 |
| M_cont预测 | a_cont = 0.12975 (SO(5) CFT bootstrap精确值) |
| M_cont模型宽度 | σ_cont = 0.010 (允许CFT计算不确定性) |
| M_1st预测 | a_1st = 0.13±0.06 (SSB弱一阶下角落系数范围，估计) |
| M_1st模型宽度 | σ_1st = 0.06 |

**计算：**
P(data|M_cont) = N(0.131 | 0.12975, √(0.005²+0.010²)=0.0112)
= 1/(√(2π)·0.0112) · exp(-(0.00125)²/(2·0.0112²))
= 35.6 · exp(-0.0062)
= 35.4

P(data|M_1st) = N(0.131 | 0.13, √(0.005²+0.06²)=0.0602)
= 1/(√(2π)·0.0602) · exp(-(0.001)²/(2·0.0602²))
= 6.62 · exp(-0.00014)
= 6.62

**BF₂b = 35.4 / 6.62 = 5.35**
**log BF₂b = +0.73**

判读：轻微支持 M_cont, 但 ~1σ 水平，不能单独区分

### 2.4 O3: 关联长度指数 ν_eff (Takahashi, L=1024)

| 参数 | 值 |
|------|-----|
| 观测值 | ν_obs = 1.4 |
| 观测误差 | σ_obs = 0.1 |
| M_cont预测 | ν_cont = 0.55 (SO(5) CFT范围0.455-0.63) |
| M_cont模型宽度 | σ_cont = 0.15 |
| M_1st预测 | ν_1st = 1.0 (弱一阶下有效ν预期>1, 但无精确理论值) |
| M_1st模型宽度 | σ_1st = 0.5 (弱一阶有效ν范围大) |

**计算：**
P(data|M_cont) = N(1.4 | 0.55, √(0.1²+0.15²)=0.180)
= 1/(√(2π)·0.180) · exp(-(0.85)²/(2·0.180²))
= 2.21 · exp(-11.15)
= 2.21 · 1.43×10⁻⁵
= 3.16×10⁻⁵

P(data|M_1st) = N(1.4 | 1.0, √(0.1²+0.5²)=0.510)
= 1/(√(2π)·0.510) · exp(-(0.4)²/(2·0.510²))
= 0.78 · exp(-0.308)
= 0.78 · 0.735
= 0.573

**BF₃ = 3.16×10⁻⁵ / 0.573 = 5.51×10⁻⁵**
**log BF₃ = -9.80**

判读：强支持 M_1st（~4σ等效）

> **注：** 若取 T 数据报告的 ν≈1.4 而非任务书中的 ν_t≈0.63，log BF 从预期的 ≈-3 变为 ≈-10。两者都在 M_1st 方向，但 1.4 的信号更强。

### 2.5 O5/O6: Binder cumulant — L=448无信号 vs L=1024有信号

以 L=1024 观测到双峰为条件事件。

| 参数 | 值 |
|------|-----|
| 事件 | L=1024 出现Binder cumulant双峰（共存+一阶特征） |
| M_cont概率 | P(双峰 | M_cont, L=1024) ≈ 0.05 (统计偶然) |
| M_1st概率 | P(双峰 | M_1st, L=1024) ≈ 0.75 (ξ~600-1000, L>ξ暴露一阶特征) |

**BF₅ = 0.05 / 0.75 = 0.067**
**log BF₅ = -2.71**

判读：中等支持 M_1st（~1.5σ等效）

### 2.6 O7-O9: SO(5) scaling dimensions (Takahashi)

使用Δ_φ, Δ_s, Δ_t的三个独立测量作联合检验。

**方法：** 在M_cont下，5个scaling dim应精确匹配CFT bootstrap预测（O7-O9三个加上O3 ν和Δ_j，但Δ_j在1σ内匹配，排除以保守估计）。计算χ²。

**χ²分析（M_cont零假设）：**

| 算子 | Δ_obs | Δ_CFT | σ_obs | (Δ_obs-Δ_CFT)/σ | χ²贡献 |
|------|-------|-------|-------|-------------------|--------|
| Δ_φ | 0.607 | 0.630 | 0.004 | -5.75 | 33.1 |
| Δ_s | 2.273 | 2.359 | 0.004 | -21.5 | 462.3 |
| Δ_t | 1.417 | 1.519 | 0.007 | -14.6 | 213.2 |
| | | | | **总计 (df=3)** | **708.6** |

在M_cont下，p值 = P(χ² > 708.6 | df=3) < 10⁻¹⁵²

**log BF_scaling = χ²_diff / 2 ≈ -354** （极端支持M_1st）

**⚠️ 警告：** 如此极端的信号来自scaling dim的高测量精度（σ~0.004-0.007），但这是 Takahashi 团队使用 QMC 在 J-Q 模型上的测量，并非独立复现。这些偏差反映的是 Takahashi 模型的确非 SO(5) CFT 精确描述，这与 M_1st 一致但并非独立证据。

## 第3步：联合 Bayes factor 与 L_min 分析

### 3.1 独立观测量识别

**问题：** O3-O9全部来自 Takahashi et al. 同一篇论文、同一QMC模拟、同一系统。不能作为独立观测量。

**独立观测量估计 n_eff：**

| 独立组 | 包含观测量 | 理由 |
|--------|-----------|------|
| Ⅰ: EE (Deng) | O1 | 完全独立的方法与系统；与Takahashi的模型、代码、几何完全不同 |
| Ⅱ: Takahashi关联函数+Binder | O3+O5/O6 | 同一QMC但不同分析方法（关联函数 vs Binder cumulant），部分独立 |
| Ⅲ: Takahashi scaling dims | O7-O9 | 与Ⅱ使用相同数据但提取不同物理量，依赖同一FSS假设 |
| Ⅳ: Sandvik-Zhao | O4+O5' | 完全独立于Takahashi的QMC实现，但测同一模型 |

**保守 n_eff = 2.5**（EE完全独立 + Takahashi关联函数与Binder部分独立 + scaling dims与关联函数强相关）

### 3.2 联合BF计算（场景分析）

四种场景覆盖先验可能性空间：

**场景A（含EE Deng + Takahashi关联 + Binder）**
```
log BF_joint = log BF₁ + log BF₃ + log BF₅
             = -20.0 + (-9.80) + (-2.71)
             = -32.5
```
等效正态σ ≈ 7σ（远超3σ）
**结论：联合诊断远超3σ**

**场景B（不含EE，仅Takahashi关联 + Binder + scaling dims调整）**
```
log BF_joint = log BF₃ + log BF₅
             = -9.80 + (-2.71)
             = -12.5
```
等效正态σ ≈ 4.1σ（超3σ）
**结论：Takahashi单独数据已达3σ+**

**场景C（含EE D-S替代Deng + Takahashi关联 + Binder）**
```
log BF_joint = log BF₂b + log BF₃ + log BF₅
             = +0.73 + (-9.80) + (-2.71)
             = -11.8
```
等效正态σ ≈ 3.9σ（超3σ）
**结论：仍达3σ**

**场景D（仅EE Deng + EE D-S，排除Takahashi）**
```
log BF_joint = log BF₁ + log BF₂b
             = -20.0 + 0.73
             = -19.3
```
等效正态σ ≈ 5.5σ
**结论：EE内部矛盾（Deng→M_1st, D-S→M_cont弱），净结果仍支持M_1st，但先验依赖严重**

### 3.3 L_min 分析

**方法：** 对每个观测量，BF作为L的函数，计算达到|log BF|>3所需最小L。

| 观测量 | BF(L)形式 | log BF(L) | L_min(3σ) |
|--------|-----------|-----------|-----------|
| O1: EE b (Deng) | 与L弱相关（b≈2已在L=48达>20σ） | -20（独立于L） | <48（已远超3σ） |
| O3: ν_eff (Takahashi) | ν_eff随L增长，~1/L收敛 | ~-3×(L/256) | ~256 |
| O5/O6: Binder双峰 | 阈值L>ξ后BF指数增长 | -5×tanh(L/ξ) | ~600 (ξ~600估计) |
| O7-O9: scaling dims | 随L²增长（精度∝1/√L, 偏差∝L⁰） | -50×(L/256) | <64（已远超3σ） |

**综合L_min:**

| 场景 | 达到|log BF|>3所需L_min | 可行性 |
|------|-------------------|--------|
| 含EE Deng | <48 | 现有数据已足 |
| 不含EE, 仅Takahashi关联+Binder | ~256-600 | L=1024数据已满足 |
| 不含EE, 不含Takahashi scaling dims | ~600 | 需L>512, 挑战现有能力 |

**关键结论：** 若包含最强证据（EE b + scaling dims），L_min < 48，现有数据已远超3σ。若只保留保守独立观测量（关联函数+Binder），L_min ~ 256-600，Takahashi的L=1024已覆盖。

## 第4步：判断

### 4.1 北极星判定

> **在现有数值工具可达到的系统尺寸（L ≤ 512）内，是否存在联合观测量组合能在 3σ 置信度区分连续和弱一阶 DQCP？**

**答案：是，但有一条关键条件。**

**肯定路径（M_1st成立）：**
1. Takahashi et al. (L=1024) 的关联函数分析单独已达到>3σ（log BF ≈ -10，等效4σ），使联合诊断不必要
2. 在L=512处，若不考虑scaling dims的极端精度，关联函数+Binder可达到|log BF|≈3的临界值
3. 若包含EE Deng数据（b=2, >20σ），L=48也已远超3σ

**条件路径（先验依赖）：**

## 自反攻击（自我反驳检验）

### 攻击1: BF计算依赖于主观先验宽度

**反驳：** 确实，σ_cont和σ_1st的选择影响BF具体数值。验证（O1为例）：

在所有合理先验下，O1始终指向M_1st。先验敏感性较小。

### 攻击2: 观测量不独立的指责

**反驳：** 独立性问题已用n_eff=2.5部分解决。但更激进的批评（所有数据来自J-Q模型同一物理系统，非真正独立）有一定道理。为此已做场景分析。

### 攻击3: Takahashi data == circular with M_1st

**反驳：** Takahashi 论文声称一阶，使用其数据作为"M_1st"证据看似循环。但观测值本身（ν=1.4, 双峰, scaling dim偏差）是**物理测量**，其数值独立于结论。无论论文作者声称什么，ν=1.4 不匹配 M_cont预测的 ν≈0.5 是客观事实。

### 攻击4: 忽略了 Sandvik-Zhao 反例

**反驳：** SZ在L≤448上建立自洽连续标度。这不是反例，而是预期——在伪临界区L<<ξ内，M_1st预测"看起来连续"。SZ数据说明ξ>448，但不排除ξ<1024。Takahashi L=1024 恰好填此缺口。

### 攻击5: ν_t≈0.63 找不到文献出处

**发现：** 搜索多个数据库，ν_t≈0.63 未在任何已发表DQCP文献中找到直接对应值。Takahashi(2024)明确报道 ν≈1.4，Sandvik-Zhao(2020)报道 ν=0.455。任务书中的 ν_t≈0.63 可能来自：
(a) 混淆 ν_t 与 ν（thermal vs correlation length exponent）
(b) 内部S1/S4分析中某特定窗口的拟合值
(c) SO(5) CFT bootstrap的 thermal exponent y_t=1/ν≈1.59 → ν≈0.63

**建议：** Phase 2 前确认 ν_t 原始出处。若ν_t≈0.63来自SO(5) CFT bootstrap，则2020年的Sandvik-Zhao ν=0.455已偏离此值→本身就是M_cont不完美的证据。

### 攻击6: 数据质量差距 — Deng (L=48) vs Takahashi (L=1024)

**反驳：** Deng的EE数据在L≤48的极小系统上，b=2.0的极端显著性（>20σ）在此尺寸下不可靠（S1已证实d/L共线性r=-0.964）。因此场景C（排除Deng EE）可能是更诚实的分析。即便如此，Takahashi L=1024单独提供>3σ。

### A1. BF 公式推导

对高斯观测 data = d ± σ_obs 和模型先验 θ ~ N(μ_M, σ_M)：

P(data | M) = ∫ N(d | θ, σ_obs²) · N(θ | μ_M, σ_M²) dθ
            = N(d | μ_M, σ_obs² + σ_M²)

log BF_i = log N(d_i | μ_cont, σ_i²+σ_cont²) - log N(d_i | μ_1st, σ_i²+σ_1st²)
         = [ -½ln(2π) - ln(σ_cont') - ½(d_i-μ_cont)²/σ_cont'² ]
           - [ -½ln(2π) - ln(σ_1st') - ½(d_i-μ_1st)²/σ_1st'² ]
         = ln(σ_1st'/σ_cont') + ½[(d_i-μ_1st)²/σ_1st'² - (d_i-μ_cont)²/σ_cont'²]

其中 σ_M'² = σ_obs² + σ_M²
