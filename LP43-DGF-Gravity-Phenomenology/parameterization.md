## 跨学科突破口

### 突破口1：光和物质耦合到不同的有效度规

已知物理先例：
- 声学度规（Unruh 1981）：声子在流动介质中看到有效Lorentz度规
- 电磁场在介质中：Fermat原理 → 有效折射率度规
- 电子流体：电子和声子有不同的有效质量张量
- 自旋霍尔效应：自旋向上/向下的电子看到不同的有效规范场

DGF的可能机制：
- **光（无质量，q=1信道）→ 耦合到因果图本身的null cone → 见b=2**
- **物质（有质量，部分退相干）→ 耦合到扩散过程 → 见b=1**

如果是这样，等价原理在DGF中被修改：光和物质的自由落体不同。
这在强场下会有可观测效应。中子是检验物质自由落体的理想探针。

### 突破口2：扩散方程定义了共形类，光锥定义了度规

图Laplacian → div(q grad) → 扩散算符 → 共形类（b=1）
因果边 → 光锥 → 度规的signature和null structure → 固定共形因子（b=2？）

两者的组合唯一确定度规。但两者给出不同的b值——它们在度规中矛盾。

除非：度规不是由扩散算符唯一确定的。扩散算符确定的是g^{ij}（逆度规）和√g的组合，而因果边确定的是null cone。在GR中这两者由同一个度规统一。在DGF中它们可能指涉度规的不同方面。

### 突破口3：等价原理强制b=2

等价原理说：局域物理与引力无关。这意味着局部度规必须是Minkowski。

对于DGF度规g_{00} = -q², g_{ij} = q^{-b}δ_{ij}：
在局域惯性系中（坐标变换消除一阶导数），度规必须是 η_{μν}。
这要求：g_{00}和g_{ij}的"相对标度"在q变化下保持一致。

具体地：考虑从点x到临近点x+dx的坐标变换。
局域度规 = η + O(dx²)。一阶项必须消除。
这要求 g_{00}'(0) = g_{ij}'(0) = 0（在合适的坐标下）。
但这只在b=2时成立（因为需要平衡(q²)'和(q^{-b})'的标度）。

让我验证：在Riemann法坐标下，度规展开为：
g_{μν} = η_{μν} + (1/3)R_{μανβ} x^α x^β + ...

这个展开对任意度规成立。对DGF度规：
R_{0i0j} = ...依赖q和它的导数。
如果b≠2，度规的"各向同性"被破坏——空间更"软"或更"硬"于时间。

这可能是一个物理选择原理：**等价原理+各向同性 → b=2。**

### 突破口4：最大熵原理选b

对于给定的质量分布M（即给定的q场剖面），不同的b值产生不同的度规，不同的度规产生不同的时空曲率，不同的曲率影响q的分布（通过RG流）。

自洽条件：q(r)必须同时满足：
(a) 场方程 □(ln q) = 4πGρ/c²（产生q=exp(-GM/rc²)）
(b) 度规决定了□算符的形式

如果度规依赖于b，□算符也依赖于b。自洽性可能选择特定的b值。
让b=2使得□(ln q)和标准Poisson方程一致（在面积半径坐标下）。

## 最诚实的结论

**b=2不是从图推导的——是被等价原理+各向同性+Newtonian极限联合强制的。**

DGF的独特贡献不是推导b=2，而是推导了q=exp(-GM/rc²)。
度规形式由对称性原理决定，q场剖面由信息论决定。
两者结合 = GR（在弱场下）+ DGF的量子信息解释。

这就是"突破口"：**承认度规由对称性决定，q场由信息论决定。
DGF是GR的微观基础（统计力学←→热力学），不是GR的替代品。**
