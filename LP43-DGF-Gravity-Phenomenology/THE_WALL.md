# 墙：时间与空间在因果图上有不同的q标度

## 墙的物理本质

因果图提供了**两个独立的算符**，它们的连续极限给出度规的不同分量：

```
图结构          连续极限                 给出的度规分量
────────       ────────                ────────────
图Laplacian    div(q grad)            g_{ij} ~ q^{-1}  (空间)
因果路径计数   weighted path sum      g_{00} ~ -q²     (时间)
```

**这两个算符的q标度不同：空间~q^{-1}，时间~q²。**

## 为什么这是墙

在Riemann/Weyl几何中，度规是一个**统一的张量**g_{μν}。它的所有分量必须通过相同的规则从底层结构导出。你不能对空间用一个规则，对时间用另一个规则——那样得到的不是度规，是拼图。

具体地：任何从底层结构导出度规的方案，都必须解释**为什么时间分量的q指数是+2，而空间分量的q指数是-1（或-2）**。这两个数字的比值q^{3}（或q^{4}）不是小量——在太阳表面是(1-2×10^{-6})³≈1-6×10^{-6}，在中子星表面是(0.85)³≈0.61。它是O(1)的物理效应。

## 之前的"解决方案"为什么失败

我们尝试过：
1. **Weyl规范变换修复空间部分** — 但规范变换必须同时作用于时间和空间，会破坏g_{00}
2. **声称空间部分来自面积半径变换** — 但面积半径的定义本身依赖度规，循环论证
3. **声称4条路径收敛到同一个度规** — Agent A的四条路径收敛到g=q^{-1}η（时间和空间q标度相同），不是最终度规g=diag(-q², q^{-2}, q^{-2}, q^{-2})

## 墙的精确表述

> **因果图上的空间扩散和因果传播是两种不同的物理过程，它们的连续极限给出不同的q标度。将这些不同的q标度统一到单个度规张量中，需要额外的物理原理。目前DGF框架没有提供这个原理。**

等价地：图Laplacian给出的是空间部分的**扩散度规**。因果路径给出的是时间部分的**传播度规**。在GR中，这两个度规是同一个（g_{μν}）。在DGF中，它们天然不同——而DGF尚未解释它们为什么应该相同。

## 可能攻击方向

**方向A：接受差异**
度规天然就是各向异性的（空间q^{-1}，时间q²）。在弱场极限下（q≈1），这个各向异性消失，恢复GR。在强场下，它给出不同于GR的预言。
- 代价：PPN γ变成0.5（被太阳系排除）。需要一个机制让γ在太阳系尺度上恢复为1。

**方向B：重新解释图Laplacian的结果**
图Laplacian给出的不是g_{ij}，而是g^{ij}（逆度规）。如果是g^{ij}=q δ^{ij}，则g_{ij}=q^{-1}δ_{ij}——结果相同。

**方向C：因果路径也给空间信息**
因果路径计数不仅确定时间标度，也包含了空间信息——因为路径在空间中有分支。不同的空间方向有不同的路径权重。这或许可以同时确定g_{00}和g_{ij}。
- 这需要将因果路径计数从1+1D推广到3+1D，并提取空间度规。

**方向D：放弃从图推导度规，改为从熵推导度规**
不直接从图算符读度规，而是从DGF熵S[q]通过热力学（Jacobson 1995型的论证）推导爱因斯坦方程。
- 这避开了"图算符→度规"的直接映射问题。

**方向E：接受q标度不同是物理的，寻找更大几何框架**
也许DGF的有效几何不是Riemann/Weyl，而是Finsler或双度规理论。时间和空间的不同q标度反映了因果图的根本不对称性（有向边→时间方向 vs 无向边→空间方向）。

## 建议

方向E最诚实——它不试图"修复"差异，而是问：**如果这个差异是真实的物理，它意味着什么几何？**
