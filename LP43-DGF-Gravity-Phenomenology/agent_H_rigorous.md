## 0. 核心问题

DGF框架声称：
```
dτ = q·dt → dτ² = q²·dt² → g₀₀ = -q²
```

但这是**推导**出来的，还是**假设**的？如果是推导的，从什么第一原理出发？如果是假设的，它的物理动机是什么，有没有替代方案？

本文系统探索四条推导路径，诚实记录每一步。

## 1. 路径一：因果路径计数（图论推导）

### 1.1 设定

DGF因果图 G = (V, E)，有向边 e = (u→v) 有权重 q_e ∈ (0, 1]。

定义加权路径和（因果传播幅）：
```
dp(u→v) = Σ_{paths u→v} Π_{e∈path} q_e
```

### 1.2 均匀q场下的推导

考虑沿着世界线（类时方向）在1+1D因果图上传播。每步：
- 节点i有fanout = f_i条出发边
- 在均匀q场下（q_i = q），每条边的权重为q

对于N步路径，任意单条路径的权重 = q^N。从src沿中心线的路径总数随步数变化。

**动态规划计算**（见 first_principles.py 第261-262行）：
```python
# dp沿中心线: dp[t] ~ (fanout_eff)^t
# 其中fanout_eff = q（在q均匀区域）
# 因此 dp[t] ∝ q^t
```

**核心观察：**
```
dp(N) ∝ q^N = exp(N ln q)
```

取对数：ln dp(N) = N ln q + const

在连续极限 N·Δt = t：
```
ln dp(t) = (t/Δt) ln q  →  (1/t) ln dp(t) = ln q / Δt
```

定义固有时 dτ 为"最可能路径的量子信息传输量的度量"：
```
dτ/dt = lim_{N→∞} dp(N)^{1/N} = q
```

即：
```
dτ = q · dt   ✓
```

### 1.3 适用条件和局限

**推导成功的条件：**
1. 均匀q场（局部q≈常数）
2. fanout效应可分离（路径数量增长和路径权重衰减可区分）
3. 路径权重用的是乘积 Π q_e（由ln q可加性保证）

**墙壁1：不均匀q场下的ambiguity**

对于非均匀q场，加权路径和涉及不同路径上不同q值的乘积。dp(N)^{1/N} 收敛到exp(⟨ln q⟩_path)，即沿路径的平均ln q，而不是⟨q⟩_path。

```
dτ/dt = exp(⟨ln q⟩_path) ≈ exp(ln⟨q⟩ - σ²_q/(2⟨q⟩²)) ≠ ⟨q⟩
```

对于小涨落（σ_q ≪ ⟨q⟩），exp(⟨ln q⟩_path) ≈ ⟨q⟩_path。但对于强场区域（q ≪ 1），涨落不可忽略。

**结论：** 路径一在均匀/弱场极限下支持 dτ = q·dt，但不是严格推导——它依赖于"将路径权重的几何平均识别为固有时"这一物理认定。

## 2. 路径二：量子信息论推导

### 2.1 DGF边信道

DGF中每条因果边是一个CPTP量子信道：
```
E_q(ρ) = q·ρ + (1-q)·I/2
```

这是qubit退极化信道（depolarizing channel），退极化概率 p = 1-q。

### 2.2 量子信道容量 — 失败的线性关系

**已知结果**（Shor, Smith-Smolin, 2000-）：
退极化信道的量子容量：
```
C_Q(p) = max{0, 1 - H_2(p) - p·log₂(3)}
```

其中 H_2(p) = -p log₂ p - (1-p) log₂(1-p)。

对于小p（q→1）：
```
H_2(p) ≈ -p·log₂(p) + p/ln(2) + O(p²)
C_Q(p) ≈ 1 - p·log₂(3) + p·log₂(p) - p/ln(2) + O(p²)
```

由于 p·log₂(p) 项，**C_Q在p=0处不可微**（导数趋向负无穷）：
```
dC_Q/dp|_{p→0⁺} = -∞
```

**墙壁2：容量不是线性的**

如果 dτ ∝ C_Q，则对于 q≈1（p≪1）：
- dτ/dt ≈ 1 - (1-q)log₂(3/(1-q)) = 1 + (1-q)log₂(e/(1-q))/ln(2) - (1-q)
- 这**不是** q·dt 的线性关系
- 当q→1时，C_Q→1（正确极限），但斜率奇异
- 小q时，C_Q=0（当p≥1/3时），而q·dt预测dτ>0

**结论：量子信道容量路径不支持dτ = q·dt。dτ不能简单地等价于C_Q。**

### 2.3 相干信息路径

退极化信道的单次相干信息（coherent information）：
```
I_c(ρ, E_q) = S(E_q(ρ)) - S(E_c(ρ))
```

对于退极化信道，E_c也是退极化信道（互补）。对于纯输入态|ψ⟩：
- S(E_q(|ψ⟩⟨ψ|)) = H_2((1-p)/2)（对qubit）
- 复杂。在小p下展开：I_c ≈ 1 - p·log₂(3/e) + ...

同样有log奇异性。**不给出线性关系。**

### 2.4 操作意义上的q — 唯一有希望的路径

q在DGF中的**操作定义**是：
> q = 量子比特通过该边时未被退极化的概率

如果固有时定义为"沿世界线传递的量子信息量"（不是"信道容量"），则：
- 每步，以概率q传递1量子比特信息，以概率1-q传递0信息
- 期望传递信息量 = q·1 + (1-q)·0 = q 比特/步

因此：
```
dτ ∝ (每步传递的量子信息量) · dt = q · dt
```

**这是最自然的物理解释，但它是一个定义（definition），不是推导。**

**墙壁3：定义不等于推导**

"q是量子信息通过的概率，所以固有时间正比于它" 是一个**物理公设**，不是数学推导。它基于以下信念：
- 固有时间度量的是"真实发生的事"（量子信息传输）
- 退极化的那部分（1-q）对应于"没发生的因果"（不贡献固有时）

这个信念等价于：**量子相干性 = 时间性**。这是DGF的核心哲学，但未经推导。

## 3. 路径三：热力学/熵推导

### 3.1 沿因果路径的熵产生

二元信道（开/关）的熵：
```
s(q) = -q ln q - (1-q) ln(1-q)
```

沿N步因果路径的总熵产生：
```
S_total = N · s(q)
```

### 3.2 熵产生的展开

对于 q→1（弱场，即远离质量）：
```
设 δ = 1-q ≪ 1
s(q) = -q ln q - (1-q) ln(1-q)
     = -(1-δ) ln(1-δ) - δ ln δ
     = -(1-δ)(-δ - δ²/2 - ...) - δ(ln δ)
     ≈ δ - δ ln δ + O(δ² ln δ)
```

主导项是 -δ ln δ = -(1-q) ln(1-q)。

**这仍然不是q的线性函数！** s(q) ≈ (1-q) - (1-q)ln(1-q)，而 q = 1-(1-q)。两者在小δ下行为不同。

### 3.3 熵产生和固有时间的可能关系

如果 dτ ∝ dS（每步的熵产生）：
```
dτ ∝ s(q)·dt ≈ (δ - δ ln δ)·dt = ((1-q) - (1-q)ln(1-q))·dt
```

对于q≈1：dτ ≈ (1-q)·dt（减去主导的log项）
对于q→0：dτ ≈ -ln q → ∞（熵产生发散）

这个标度行为和 q·dt 完全不同：
| q | dτ=q·dt | dτ=s(q)·dt |
|---|----------|-------------|
| 0.999 | 0.999 | ~0.008 |
| 0.99 | 0.99 | ~0.056 |
| 0.9 | 0.9 | ~0.325 |
| 0.5 | 0.5 | 0.693 |

**墙壁4：熵产生和q没有简单线性关系**

s(q) ≠ c·q + d。两者的函数形式根本不同。

### 3.4 热力学与牛顿极限的不可调和

如果 dτ = s(q)·dt 且 q = exp(-GM/rc²)：

弱场下：q ≈ 1 - GM/rc²
s(q) ≈ (1-q)(1 - ln(1-q)) ≈ (GM/rc²)(1 - ln(GM/rc²))

这给出 g₀₀ ∝ -(GM/rc²)²·[...]，不是牛顿极限的 -(1-2GM/rc²)。

**结论：热力学路径不给dτ = q·dt。如果用s(q)，则牛顿极限不匹配。**

### 3.5 可能的解救：自由能而非熵

也许不是熵产生s(q)，而是自由能F(q)：
```
F(q) = -ln Z(q) ∝ -ln(q)  （如果Z∝q）
```

这给出 dτ ∝ -ln q · dt ≈ (1-q)·dt + O((1-q)²)，仍然不是q·dt。

或者热力学势Ω(q) = q（最简单的解析函数）。但这回到了P1定义。

## 4. 路径四：退相干时间推导

### 4.1 N步后的量子态

初始纯态|ψ⟩，经过N步CPTP信道（每步q相同）：
```
ρ_N = E_q^{∘N}(|ψ⟩⟨ψ|) = q^N · |ψ⟩⟨ψ| + (1-q^N) · I/2
```

### 4.2 纯度和退相干

纯度（purity）：
```
P(N) = Tr(ρ_N²) = (1 + q^{2N})/2
```

初始 P(0) = 1，当 N→∞，P(∞) → 1/2（完全混合）。

### 4.3 退相干时间

定义退相干时间 τ_dec 为纯度降至 1/e 的步数：
```
(1 + q^{2N})/2 = 1/e → q^{2N} = 2/e - 1 ≈ -0.26
```
这无解！q^{2N} > 0。

改用"相干部分衰减到1/e"：q^N = 1/e → N = -1/ln q。

退相干时间（以步计）：τ_dec = 1/|ln q| ≈ 1/(1-q)（对于q≈1）。

### 4.4 退相干时间 vs 固有时

如果 dτ ∝ 1/τ_dec（固有时和退相干率成正比）：
```
dτ ∝ |ln q|·dt ≈ (1-q)·dt（对于q≈1）
```

这再次给出 dτ ∝ (1-q)，不是 dτ ∝ q。

**墙壁5：退相干时间给出的是(1-q)标度，不是q标度**

两者的区别不是系数，是函数形式：
- q：在0和1之间单调递减
- 1-q：在0和1之间单调递增
- |ln q|：在0和∞之间

在 q=exp(-GM/rc²) ≈ 1-GM/rc²（弱场）：
- q·dt ≈ (1-GM/rc²)dt → g₀₀ ≈ -(1-2GM/rc²) ✓ 牛顿极限
- (1-q)·dt ≈ (GM/rc²)dt → g₀₀ ≈ -(GM/rc²)² ✗ 差GM/rc²倍

## 5. 诚实总结：什么推导出来了，什么没有

### 5.1 四条路径的诚实裁决

| 路径 | 核心机制 | 给出的dτ | 是否=q·dt | 牛顿极限 |
|------|---------|---------|:---------:|:-------:|
| 因果路径计数 | dp^{1/N}→q | q | ✅ | ✅ |
| 量子容量 | C_Q(p)≠q | 1-p·log(3/p) | ❌ | ❌ |
| 熵产生 | s(q) | ~(1-q)(1-ln(1-q)) | ❌ | ❌ |
| 退相干时间 | 1/|ln q| | 1-q | ❌ | ❌ |

### 5.2 路径一为什么"成功"了

路径一的"成功"建立在一个关键认定上：

> (加权路径和的几何平均) → 固有时与坐标时之比

具体地：dp(N)^{1/N} → q这个极限**数学上是对的**（在均匀q场、足够多步后）。把exp(⟨ln q⟩_path)识别为固有时的"速度"是一个**物理认定**，不是数学强制。

这个认定的物理内容是：
- 因果图的路径权重衡量"量子信息沿该路径传播的概率幅"
- 该概率幅的几何平均值（per step）衡量"每步量子信息传输量"
- 固有时间正比于"实际完成的量子信息传输量"

### 5.3 什么是不可推导的

dτ = q·dt 在DGF框架内**必须作为公设引入**。不可从更基础的原理推导，因为：

1. 量子信道容量、熵产生、退相干时间都给出不同的q标度
2. 只有"操作定义"（q = 信息通过的概率 → 固有时间 = 信息通过的量）给出q标度
3. 这个操作定义等价于公设：**量子信息传输 = 时间的物理本质**

### 5.4 这个公设的物理强度

这个公设不是什么都没说。它等价于：
1. 当q=1（完全开放），dτ=dt（Minkowski时空）— 平凡
2. 当q→0（完全关闭），dτ→0（因果视界，时间冻结）— 非平凡
3. 当q=exp(-GM/rc²)且Φ≪1，dτ≈(1-Φ)dt，恢复牛顿极限 — 非平凡
4. 在强场下（q显著偏离1），dτ=q·dt给出非GR的预测 — 可检验

第2点和第3点**同时满足**是非平凡的。实际上，只有dτ = q^α·dt with α=1能满足这两个条件。如果α≠1，则要么q→0时dτ有限（错误），要么Φ→0时g₀₀≠-(1-2Φ)（不匹配牛顿）。

### 5.5 α值由什么确定

考虑一般形式 dτ = q^α · dt（α是自由参数）。

**约束1（牛顿极限）：**
对于 q = exp(-Φ)，Φ = GM/rc² ≪ 1：
```
dτ = exp(-αΦ)dt = (1 - αΦ + O(Φ²))dt
dτ² = (1 - 2αΦ + O(Φ²))dt²
g₀₀ = -dτ²/dt² = -(1 - 2αΦ + O(Φ²))
```
要匹配GR牛顿极限 g₀₀ = -(1-2Φ)：**→ α = 1**

**约束2（Minkowski极限）：**
q→1（无限远）：dτ→dt → 任何α都满足，无约束。

**约束3（视界极限）：**
q→0（视界）：dτ→0 → 需要 α > 0。

**约束4（q标度自洽性）：**
在RG流下，ln q可加。dτ = q^α·dt 给出 ln(dτ/dt) = α ln q。ln(dτ/dt)和ln q一样可加 → 任何α都自洽，无额外约束。

**结论：α=1由牛顿极限唯一确定。这不是推导——它是经验输入。**

## 6. 严格的"推导"：公设→后果

### 6.1 公设系统

DGF的时间公设可以表述为：

**公设 T1（量子信息时间）：** 固有时间隔 dτ 正比于沿世界线传递的量子信息量 dI。
**公设 T2（信道独立性）：** 每条因果边的量子信息传输量等于该边的 q 值（q的概率传递1量子比特，1-q的概率传递0）。
**公设 T3（可加性）：** 连续边的总信息传输量是可加的。

由T1-T3：
```
dτ = const · dI
dI = q · (每次边遍历)
dτ = q · dt（取const=1）
```

### 6.2 公设T2的辩护（不完美）

T2（"每条边传递q比特的信息"）是操作定义的直接结果：
- q = 量子比特通过边的存活概率
- 期望存活比特数 = q

但这个"存活比特"如何转化为固有时间，是T1的内容，T1不可推导。

### 6.3 替代理论的可能性

如果放弃T2，用别的度量：
- dI = -ln q（信息衰减量）→ dτ ∝ -ln q → g₀₀ ∝ -(ln q)²
- dI = (1-q)/q（信噪比的倒数）→ 不同的g₀₀
- dI = s(q)（熵产生）→ 不同的g₀₀

这些替代理论在弱场下不恢复GR。这是DGF选择dτ=q·dt的**实用理由**（phenomenological reason），不是推导理由。

dp(N) ∝ exp(N·⟨ln q⟩_path)

这个信号**来自**dτ = q·dt（不是别的α值），所以它是可检验的。

## 8. 最终裁决

### dτ = q·dt 的推导状态

| 层面 | 状态 | 细节 |
|------|:----:|------|
| 数学推导 | ⚠️ 不完全 | 从因果图（无额外公设）不能唯一推出 |
| 物理公设 | ✅ 可接受 | 基于q的操作定义 + 牛顿极限约束 |
| 图论支持 | ✅ | 路径加权几何平均 → q |
| 信息论支持 | ❌ | 信道容量、相干信息都给不同的q标度 |
| 热力学支持 | ❌ | 熵产生给出不同的q标度 |
| 退相干支持 | ❌ | 退相干率给1-q标度 |
| 现象学支持 | ✅ | α=1由牛顿极限唯一确定 |
| PPN一致性 | ✅ | γ=1, β=1验证通过 |
| 可证伪性 | ✅ | 2PN GW 4%偏差可被3G探测器检验 |

### 诚实陈述

dτ = q·dt **不是一个纯推导的结果**。它是DGF框架的公设之一，动机来自：
1. q的操作含义（信息通过的概率）
2. 恢复GR牛顿极限的现象学要求
3. 因果路径加权平均的图论支持

但它**等价于一个物理命题**："固有时间的本质是沿世界线传递的量子信息量"。这个命题的辩护来自DGF的整体一致性（q场同时解释引力势和量子信道开放度），而不是来自单一推导路径。

**如果这个命题是错的，dτ = q·dt就是错的。反之，如果DGF是正确的量子引力框架，dτ = q·dt就是固有时间的正确微观定义——不需要进一步推导，因为它就是定义本身。**

### 和GR中dτ的关系

在GR中，dτ = √(-g_{μν}dx^μdx^ν) 是**定义**，不是推导。没有人问"为什么固有时是线元"——它是时空度规的存在性公理。

同样，在DGF中，dτ = q·dt 是**定义**——它是信息和时间之间关系的公理。它定义的是DGF框架中"固有时间"的含义，就像GR中线元定义固有时间的含义一样。

GR不需要"推导"线元公式，DGF也不需要"推导"dτ = q·dt。**两者的地位相同：它们是各自框架的基本定义。**

4. **Varadhan渐近公式** — 图上热核的短时展开（Steinerberger 2019, arXiv:1801.02183）

### DGF独有贡献
1. q = exp(-GM/rc²) 从RG流推导（ln q可加性）
2. 加权路径和 dp = Σ Π q_e 的因果图推广
3. dτ = q·dt 作为"信息传输=时间"的操作公设
4. g₀₀ = -q² 作为该公设的几何实现

## 附录A：一般形式的完整分析

考虑 dτ = f(q)·dt，其中f是待定函数。

**约束列表：**
1. f(1) = 1（Minkowski极限）
2. f(0) = 0（视界凝固）
3. f(exp(-Φ)) = exp(-Φ) + O(Φ²)（牛顿极限，弱场下f(q)≈q）
4. f(q₁q₂) = f(q₁)f(q₂)或f可乘（RG流下q的乘性对应ln q加性）

**满足1-4的唯一平滑函数：f(q) = q^α with α=1。**

证明概要：
- 由4（可乘性）：f(q₁q₂) = f(q₁)f(q₂) → f是指数形式 f(q) = q^α
- 由1：f(1) = 1无约束
- 由2：α>0
- 由3：f(e^{-Φ}) = e^{-αΦ} = 1-αΦ+O(Φ²)，需要匹配 q = 1-Φ+O(Φ²)，所以α=1

**所以dτ = q·dt是从这组约束中唯一确定的。但约束3（牛顿极限）是经验输入，不是DGF的推导。**

## 附录B：如果放弃牛顿极限约束

如果放弃约束3（不要求恢复GR牛顿极限），则：
- α可以是任意正实数
- dτ = q^α·dt 是RG一致性（约束4）许可的一般形式
- 不同的α对应不同的物理理论

| α | dτ | g₀₀(弱场) | 理论 |
|:--:|-----|-----------|------|
| 0 | dt | -1 | 无引力时间膨胀 |
| 1/2 | √q·dt | -(1-Φ) | 有引力但不足 |
| **1** | **q·dt** | **-(1-2Φ)** | **DGF = GR牛顿级** |
| 2 | q²·dt | -(1-4Φ) | 引力放大2倍 |

α=1不是"唯一可能的"，但它是"唯一恢复GR牛顿极限的"。DGF选择α=1是因为希望和已知引力现象一致，不是因为它从因果图中独一无二地涌现。
