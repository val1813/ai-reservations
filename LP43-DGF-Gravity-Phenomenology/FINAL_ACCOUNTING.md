# DGF 最终参数清算

**日期:** 2026-06-10

## 全部参数

| 参数 | 含义 | 固定方式 | 地位 |
|:--:|------|------|:--:|
| G | 引力常数 | 实验 | 外部（和GR共享） |
| α=1 | dτ = q^α·dt | 固有时间可加性 | **框架内部推导** |
| b=2 | g_{ij} = q^{-b} | Cassini γ=1 | 外部经验输入 |

## α=1推导（非循环）

1. 因果图上世界线 = 边的序列
2. 固有时间是边贡献的和：dτ_total = Σ dτ_i
3. 每条边贡献只依赖该边的q：dτ_i = f(q_i)·dt_i
4. 对常数q穿越两条边：f(q)·2dt = 2·f(q)·dt ✓ — 任何f都满足
5. 对不同q穿越两条边：f(q₁)dt₁ + f(q₂)dt₂ ≠ 没有自然的"合并"方式除非f(q)∝q
6. 更严格的论证：考虑两条平行世界线，一条q=a，一条q=b，各自穿越N步
   固有时间比 τ_a/τ_b = f(a)/f(b) 必须和步数N无关（尺度不变性）
   如果f(q)不是线性函数，比值取决于N → 物理不自洽
7. **f(q) ∝ q 是唯一的尺度不变选择 → α=1**

这不是循环——没有引用Newtonian极限。是图结构本身的要求。

## b=2：无法推导

尝试了所有路径，全部失败。b=2由太阳系光偏折（Cassini, |γ-1|<2.3×10^{-5}）固定。

## 和GR的关系

DGF从因果图+固有时间可加性给出：
- α=1: dτ = q·dt
- q = exp(-GM/rc²): 从RG流推导
- 空间度规由对称性（等价原理+各向同性）+ 经验γ=1固定b=2

这个框架不需要用GR的概念来推导——它用因果图自己的语言。
GR的弱场极限（Newtonian）从框架涌现，没有外部校准。

**DGF的经验输入 = G（和GR共享）+ γ=1（Cassini）。GR的经验输入 = G。**
比GR多用一个经验参数（γ），但给出了GR没有的2PN预言。
