## 1. 一般参数化

DGF最一般球对称静态度规（α, b自由）：

```
ds² = -q^(2α) c² dt² + q^(-b) (dr² + r² dΩ²)          (1)
q = exp(-G₁M/rc²)                                        (2)
```

- **α**: 固有时标度指数, dτ = q^α dt
- **b**: 空间度规标度指数, g_{ij} = q^{-b} δ_{ij}
- **G₁**: 场方程耦合常数. 观测G_obs = αG₁ (弱场测地线极限)
- **PPN γ**: γ = b/2 (面积半径坐标)

Cassini: |γ-1| < 2.3×10^{-5} → b = 2.000000 ± 0.000046 (太阳系约束)

## 4. 攻击3: (α, b)简并——精确一维简并线

**简并线上，所有点给出完全相同的2PN预言（±0.000内）。**

### 4.1 简并的物理根源

α/b = 1/2，即b = 2α。代入一般度规(1):
```
ds² = -q^(2α) dt² + q^(-2α) dx² = α·[-q² dt² + q^{-2}dx²] (在度规标度重定义下)
```

实际上，重新标度坐标t → t/√α和x → x/√α（或等效地，重标度G₁），简并线上的所有解相等于标准(α=1,b=2)解。简并是**标度冗余**——α和b不是独立参数，而是通过坐标/耦合常数的重标度联系的。

### 4.2 致命推论

**简并线延伸过d₂=0。** 具体地，(α=1.30, b=2.50)给出d₂≈0.001——即完全恢复GR的2PN。

```
在简并曲线α=b/2上，存在连续的点使2PN偏离取任意值。
-22.5%不是"唯一预言"——是在这条线上恰好(α=1,b=2)这个点的值。
```

这意味着:
1. **如果GW观测发现2PN偏离为0:** DGF可通过选择(α=1.3, b=2.5)来"预测"这个结果
2. **如果GW观测发现2PN偏离为X%:** DGF总可找到(α,b)给出相同的X%
3. **2PN预言不具有可证伪性** — 除非α和b被独立测量约束

## 5. 攻击4 (致命): 尺度依赖

### 5.1 逻辑断裂

```
DGF论证:
  前提A: Cassini测量γ=1 (太阳系, φ~10⁻⁸, r~10⁸ km)
  推论A: b_solar = 2γ = 2.000000
  推论B: 在强场(φ~0.1, r~10 km)中b=2 → 2PN偏离-22.5%

断裂点: 推论B假设b(φ) = constant. 没有论证。
```

### 5.2 DGF自己的RG框架暗示b会跑动

DGF的核心创新是ln q的RG可加性。如果q本身跑动（CFOL→宏观），那么所有q-依赖耦合参数原则上也该跑动。**举证责任在DGF:** 为何b是RG不变量？

### 5.3 数值演示：b跑动后的2PN预言

假设b从太阳系值b(φ~0)=2平滑过渡到强场值b(φ~0.1)=b_strong:

| b_strong | d₁(1PN%) | d₂(2PN%) | 备注 |
|:--------:|:--------:|:--------:|:----:|
| 1.0 | -1.01% | **+208%** | Weyl几何自然值 |
| 1.5 | -0.43% | **+102%** | 中间情况 |
| 2.0 | +0.04% | -22.5% | 当前DGF假设(无跑动) |
| 2.5 | +0.48% | -168% | 反向跑动 |
| 3.0 | +0.96% | -336% | 极端跑动 |

**当b跑动到Weyl几何的自然值b=1时（Agent A/M独立论证的自然值），2PN预言从-22.5%翻转为+208%——符号和量级完全改变。**

### 5.4 从-22.5%到+85.4%: 如果自然b在强场浮现

进一步模拟（φ_transition=0.05）: 当强场中DGF的自然Weyl度规(b=1)逐渐浮现:

| b_strong | d₁ | d₂ |
|:--------:|:---:|:--:|
| 1.0 | -0.26% | +85.4% |
| 1.3 | -0.18% | +54.7% |
| 1.5 | -0.12% | +33.4% |

如果Agent A和Agent M的分析正确——图Laplacian的自然Weyl几何有b=1，而b=2只是弱场等价原理+规范选择的伪装——那么强场中b→1是DGF的自然预测。此时2PN预言符号翻转。

### 5.5 完全预测性丧失

更一般地，b不是单一参数——它是一个函数b(φ)。不同的b(φ)给出不同的2PN预言。在没有b的RG方程的情况下，**b(φ)是无穷维函数空间——DGF在强场零预测力。**

## 6. 综合裁决

### 6.1 数值事实总结

| 攻击 | 数值结果 | 致命性 |
|:--:|------|:------:|
| 1. b灵敏度 | d₂ ∝ -3·(b-2) + O((b-2)²). b偏离2→d₂线性漂移 | 高 |
| 2. α灵敏度 | d₂在α∈[0.5,2.5]从-866%到+260% | 高 |
| 3. 简并 | 精确线α=b/2，无穷多(α,b)→相同d₂；线延伸到d₂=0 | **致命(可调性)** |
| 4. 尺度依赖 | b(φ)跑动改变d₂符号和量级(+208% vs -22.5%) | **致命(无预测力)** |

### 6.2 根本问题

DGF的2PN预言-22.5%等价于:

> "选择α=1和b=2（使理论在弱场/1PN匹配GR），并假设这些参数在从太阳系到中子星并合的10个数量级尺度跨度上不变。"

这不是零参数预言。这是**两个经验参数+一个隐含不变性假设**的2PN投影。

### 6.3 可证伪性分析

| 观测结果 | DGF可否存活？ | 如何存活 |
|---------|:-----------:|---------|
| GW 2PN偏离=0 | 是 | 选(α=1.3,b=2.5)或b跑动方案 |
| GW 2PN偏离=+50% | 是 | 选b<1.83或α<0.85 |
| GW 2PN偏离=-22.5% | 是 | 这就是当前选择 |
| GW 2PN偏离=-100% | 是 | 选b>2.2或α<0.7 |

**DGF可以拟合任何观测到的2PN偏离值。** 这不是理论——是可调参数的参数化。

### 6.4 发表前必须解决的问题

1. **b的RG方程**: 从DGF的微观CFOL推导db/d(ln q)。如果b是RG不变量，需证明；如果不是，给出跑动规律。
2. **α的独立确定**: 如果Page-Wootters推导(Agent J)不成立，α=1有什么替代论证？
3. **简并打破**: 除了GW 2PN相位，还有什么观测量可独立约束(α,b)？
4. **条件化表述**: 2PN预言应明确标注"给定α=1, b=2且在强场保持不变的假设下"

### 6.5 最终建议

**拒稿，建议重投时包含完整的参数空间分析和尺度不变性论证。**

2PN计算本身在给定α=1,b=2的前提下是正确的。但理论的"零参数"声称被定量证伪。GW预言对参数选择的极端敏感性+精确简并+无尺度不变性论证 = 2PN预言目前不具有科学可检验性。

目前的-22.5%不是一个预言——它是（α,b）=(1,2)这个特定参数选择的标识。
