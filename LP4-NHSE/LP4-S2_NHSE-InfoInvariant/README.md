# LP4-S2 NHSE-InfoInvariant

北极星问题：

还是只能描述动力学输运，不能区分拓扑与非拓扑方向性效应？

驱动矛盾：
A. 方向性信息流是拓扑结构的可观测编码，可推广到多体 sector 并满足不变量性质。
B. QLIF 只是动力学诊断量，缺乏量子化、微扰稳定和相变跳变，不能作为拓扑分类量。
