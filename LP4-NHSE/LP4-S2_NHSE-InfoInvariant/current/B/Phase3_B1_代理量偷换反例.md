# Phase 3 B1：代理量偷换反例

## 目标
证明我们之前的数值代理量不能冒充原始 QLIF。

## 1. 观测量不同
原始 QLIF 依赖 von Neumann entropy 的差分。
代理量依赖的是输运/中心位移/符号标签。

两者不是同一个可观测量。

## 2. 冻结机制不同
原始 QLIF 的冻结是“去掉 B 的因果影响”。
我们的代理量把 freeze 实现为删跨边界项、去相干、clamped-source。
这只是一个工程定义，不等于原文定义。

## 3. 结论不同
代理量可以给出：
- 高填充正负分段
- freeze-dependent 翻符
- 边界敏感性

但这些不能自动转译为原始 QLIF 的性质。

## 4. 关键反例
即使 DRDD 显示清楚分段，只要它不能写回熵流定义，
就不能宣称“原始 QLIF 被证伪”或“原始 QLIF 不变量成立”。

## 5. B侧裁决
Phase 2 的结论应被严格重命名为：
`DRDD` 的失败/成功，而不是原始 QLIF 的最终裁决。

## 6. 下一步
把原始 QLIF 的重新计算列为新任务，别再把代理量和原始量混在一起。
