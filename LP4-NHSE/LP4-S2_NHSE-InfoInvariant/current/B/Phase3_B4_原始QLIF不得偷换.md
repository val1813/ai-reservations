# Phase 3 B4：原始 QLIF 不得偷换

## 裁决
原始 QLIF 不得被当前 DR-NHDD 结果替代。

## 理由
- 原始 QLIF 是 entropy-flow
- DR-NHDD 是 transport/directionality proxy
- 两者的 freeze 操作和可观测量都不同

## 若继续原始 QLIF
必须重开：
- 新任务
- 新 A/B
- 新数值脚本
- 新 GATE

## B侧建议
当前项目不要继续无限延伸。
