# Phase 1 B 反证框架：动力学量不等于拓扑不变量

## 1. 反证目标
只要找到任意一个稳定反例，就不能把 QLIF 直接称为 sector-independent 拓扑不变量。

## 2. 反证链
### 反例 A：初态替换
若在同一 Hamiltonian 和同一 sector 下，`T_N` 随初态改变符号或零点，则它不是拓扑不变量。

### 反例 B：冻结规则替换
若不同的冻结实现方式给出不同 `T_N`，说明该量依赖建模约定，而非拓扑本体。

### 反例 C：边界替换
若 OBC 与 PBC 下 `Delta T_N` 的结构不同且无统一 bulk 极限，则它更像边界动力学诊断。

### 反例 D：sector 迁移
若 `nu_Q(N)` 随 sector 变化没有结构性平台，而是连续漂移，则不能叫 sector-independent。

## 3. 你必须击穿的 A 侧说法
A 必须证明：
- `freeze` 不会引入人为偏置
- 离散化不是取符号游戏
- `nu_Q` 在 bulk 极限与谱结构绑定

否则 A 只是把动态响应包装成拓扑语言。

## 4. B侧当前判断
当前证据更支持“QLIF 是 NHSE 的方向性动力学探针”，而不是“QLIF 本身就是不变量”。
