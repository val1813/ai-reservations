# 可观测性检验

## 目标
把 QLIF 从“方向性量”压到“可检验的不变量候选”。

## 输入
- HN-Hubbard 模型
- 固定粒子数 sector
- 不同边界条件：OBC / PBC
- 不同初态：局域、扩展、随机纯态、混合态

## 观测量
1. `T_N(X -> Y)`
2. `T_N(Y -> X)`
3. `Delta T_N = T_N(X -> Y) - T_N(Y -> X)`
4. 对 sector 的变化率 `d Delta T_N / dN`

## 判据
- 若 `Delta T_N` 连续依赖初态和时间窗，则是动力学量
- 若 `Delta T_N` 在 bulk 极限稳定并在谱/点隙闭合处跳变，才有不变量候选资格
- 若只在 OBC 显著，则要警惕边界伪信号

## Phase 1 输出
一个最小可计算定义 + 一组最小反例测试
