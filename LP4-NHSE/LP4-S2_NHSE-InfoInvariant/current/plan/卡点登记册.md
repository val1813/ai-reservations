# 卡点登记册

## 卡点 #1
卡点：QLIF 的多体 Fock 空间定义尚未落地。
影响：Phase 1 无法进入数值验证。
状态：已关闭
建议：已完成，见 Phase 1A-1。

## 卡点 #2
卡点：sector 的划分规则未统一。
影响：无法比较不同 sector 的 QLIF。
状态：已关闭
建议：已完成，见 Phase 1A-1 / 1A-6。

## 卡点 #3
卡点：不变量判据可能只得到动力学量。
影响：B 侧可能成立。
状态：已关闭
建议：已完成，见 Phase 1A-4 / 1A-10。

## 卡点 #4
卡点：freeze 操作在 HN-Hubbard 中尚未写成显式算符。
影响：QLIF 无法进入可计算阶段。
状态：已关闭
建议：已完成，见 Phase 1A-2 / 1B-2。

## 卡点 #5
卡点：`Delta T_N` 目前是连续实数，缺乏自然量子化。
影响：不能称为拓扑不变量。
状态：已关闭
建议：已完成，见 Phase 1A-7 / 1B-7 与 Phase 2A-5 / 2B-5。

## 卡点 #6
卡点：freeze 规则差异在 NHSE 的 OBC 情况下可能是 `O(1)`。
影响：若成立，则 QLIF 无法成为 freeze-rule independent 的拓扑不变量。
状态：已关闭
建议：已完成，见 Phase 1A-5 / 1B-5。

## 卡点 #7
卡点：sector 扫描可能没有平台，只表现为随机翻转。
影响：若成立，则 QLIF 不能称为 sector-independent 拓扑不变量。
状态：已关闭
建议：已完成，见 Phase 1A-7 / 1B-7。

## 卡点 #8
卡点：平台可能是有限尺寸或采样分辨率假象。
影响：若成立，则即便看见平台也不能直接宣称不变量。
状态：已关闭
建议：已完成，见 Phase 1A-8 / 1B-8。

## 卡点 #9
卡点：平台宽度 `W(L)` 可能随 `L` 收缩到 0。
影响：若成立，则 QLIF 不能作为 bulk 不变量候选。
状态：已关闭
建议：已完成，见 Phase 1A-8 / 1B-8 与 Phase 2A-4 / 2B-4。

## 卡点 #10
卡点：平台中心 `rho*(L)` 可能不共用或无法绑定到 bulk 谱结构变化。
影响：若成立，则平台只是经验诊断，不是拓扑不变量。
状态：已关闭
建议：已完成，结论是平台中心不足以支撑原始不变量命题。

## 卡点 #11
卡点：Phase 2 初裁已显示翻符点，说明三重门槛未通过。
影响：QLIF 目前不能被提升为拓扑不变量。
状态：已关闭
建议：已完成，结论已转入 DR-NHDD 分类。

## 卡点 #12
卡点：L=10 扩展后，翻符主要集中在高填充率区间。
影响：若这是占据数效应，则不支持 sector-independent 不变量。
状态：已关闭
建议：已完成，见 Phase 2A-3 / 2B-3。

## 卡点 #13
卡点：如果把 QLIF 改写成填充率分段诊断量，原始“不变量”命题就失败了。
影响：原题不能收官为“已证实不变量”，只能收官为“失败但得到新对象”。
状态：已关闭
建议：已完成，已命名 DR-NHDD。

## 卡点 #14
卡点：需要把新对象单独命名并固定边界。
影响：若命名不清，失败结论会被偷换成“隐式成立”。
状态：已关闭
建议：已完成，固定称呼为 `density-resolved non-Hermitian directionality diagnostic (DR-NHDD)`。

## 卡点 #15
卡点：收官后仍保留“进行中”会让原题失败与新对象成立的边界再次漂移。
影响：候选池与当前状态可能重新出现口径不一致。
状态：已关闭
建议：已完成，统一改为已收官与另开 `LP4-S2b_Entropy-QLIF`。
