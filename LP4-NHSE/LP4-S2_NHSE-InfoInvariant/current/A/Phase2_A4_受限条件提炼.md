# Phase 2 A4：受限条件提炼

## 结果摘要
当前数据形成一个清晰的填充率分段：
- 低填充率区：`rho <= 0.7` 左右大多为正号
- 过渡区：`rho = 0.75` 附近出现 freeze-dependent 翻符
- 高填充率区：`rho >= 0.8` 基本稳定为负号

## A侧解释
这说明 QLIF 不是全局不变量，但它可能是一个“填充率相变探针”：
- 低填充和高填充属于不同方向性相
- `rho≈0.75` 可能是过渡层

## 受限成立条件
若一定要保留某种不变量式说法，只能是：
1. 只在低填充率区给出正向方向标签
2. 只在高填充率区给出负向方向标签
3. 将 `rho≈0.75` 视为过渡带，而不是不变量区

但这会把“sector-independent 不变量”改写成“填充率分段的方向性诊断量”。

## A侧当前结论
QLIF 的最佳表述应该改为：
`density-resolved directionality diagnostic`

而不是：
`sector-independent topological invariant`
