# Phase 1 A 初始推导：多体 QLIF 定义

## 目标
给出一个最小可计算定义，使 QLIF 可以作用在多体 Fock sector 上。

## 定义域
取固定粒子数 sector：
`H_N = span{|n_1,...,n_L>, sum_j n_j=N}`。

对任意方向切分 `X -> Y`，把 `X` 取为左侧子区、`Y` 取为右侧子区。方向性信息流不能只依赖单点密度，而应依赖 sector 内概率流或互信息变化。

## 候选定义
令 `rho_N(t)` 为 sector `N` 中的密度矩阵或条件态。定义子区互信息：

`I_N(X:Y,t)=S(rho_X)+S(rho_Y)-S(rho_XY)`

候选方向性 QLIF：

`T_N(X -> Y)=d I_N(X:Y,t)/dt |_{only X varied}`

其中 “only X varied” 必须由 Liouvillian 或有效非厄米生成元中的方向性分量来定义，而不能由任意坐标选择给出。

## 第一处脆弱点
这个定义天然是动力学量，因为它依赖：
- 初态 `rho_N(0)`
- 时间窗口
- 切分方式
- 归一化规则

所以它还不是拓扑不变量。要成为拓扑不变量，至少需要构造：

`nu_Q(N)=lim_{L->infty} sign[ T_N(L -> R)-T_N(R -> L) ]`

并证明它满足：
1. 对局域微扰稳定
2. 在点隙或谱隙闭合处跳变
3. 对初态类别不敏感
4. 对 sector 的变化具有可解释结构，而不是任意漂移

## 与 LP4-S1 的连接
LP4-S1 表明方向性反转可能来自非局域 Lindblad 结构，也可能被有限尺寸 OBC 放大。因此本课题不能把 `T_N` 的符号反转直接解释为拓扑跳变，必须先区分 bulk 与 finite-size。

## A侧当前结论
Phase 1 的正向定义可以启动，但当前只得到“候选信息流诊断量”，尚未得到“不变量”。
