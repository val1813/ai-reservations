# Phase 1 A7：固定填充率平台判据

## 目标
判断 `nu_Q(N)` 是否能在固定填充率 `rho=N/L` 下形成稳定平台。

## 1. 平台定义
对固定 `rho`，考察不同链长 `L` 下的标签：

`nu_Q^f(L, rho)`，其中 `f ∈ {h,d,c}`

若存在某个 `rho` 区间，使得随着 `L` 增大：

`nu_Q^h = nu_Q^d = nu_Q^c = const`

则称其为平台。

## 2. 平台必须满足的条件
1. 对 `L` 增大不漂移
2. 对 `rho` 小扰动不翻转
3. 对初态类别不翻转
4. 对边界条件切换有明确解释

## 3. 平台与不变量的区别
平台不是自动的不变量，但它是必要信号：
- 有平台：才可能继续谈 sector-independent 分类
- 无平台：只能说是多体动力学响应

## 4. A侧判定
若 `nu_Q` 在固定 `rho` 下出现平台，说明它可能对应 bulk 的离散标签。
若平台不存在，但方向性仍存在，则它只是诊断量。

## 5. A侧当前观点
平台是本课题的最后门槛之一。
没有平台，不应再用“拓扑不变量”措辞。

## 6. 下一步
让 B 侧专门攻击“平台”本身，检查它是否只是有限尺寸假象。
