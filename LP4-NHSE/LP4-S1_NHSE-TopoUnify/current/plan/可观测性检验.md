# 可观测性检验 — NHSE-TopoUnify v1

> 每个关键理论量必须回答：如何在实验（或数值）中测量它？
> "不可观测量"不能作为任何知识库条目的唯一依据

---

## O1：H_eff(γ)的本征谱
- **可观测性：** ✅ 直接数值可计算（精确对角化）
- **实验对应：** 共振荧光谱 / 传输测量（单粒子Green函数谱）
- **限制：** 实验上H_eff不是直接可观测量（它是条件演化生成元）
  → 但本课题v1是纯理论推导，数值验证即可

## O2：ν(γ) winding number
- **可观测性：** ⚠️ 间接可观
- **数值方法：** 复平面上H_eff(k,γ)轨迹的绕数（直接计算）
- **实验对应：** 波包质心的chiral运动方向（动力学判据）→ 与ν(γ)的对应关系需验证
- **限制：** 波包动力学可能受非拓扑效应（无序/非线性）污染

## O3：D(γ) 趋肤方向
- **可观测性：** ✅ 直接可观
- **数值方法：** OBC对角化 → 所有本征态的概率密度分布 → 质心统计
- **实验对应：** 光晶格中冷原子密度分布 / 电路网络中的阻抗分布 / 光子晶体中的光场分布
- **限制：** 实验精度需区分边界效应与体趋肤效应

## O4：γ_c 临界测量强度
- **可观测性：** ⚠️ 需要参数扫描
- **数值方法：** ν(γ)在γ∈[0,1]上的扫描 → 定位跳变点
- **实验对应：** 变化测量强度（量子反馈控制的增益）→ 观察趋肤方向翻转
- **限制：** 实验上γ的连续调谐可能不trivial（测量强度通常是实验设定的离散值）

## 核心检验策略
本课题为纯理论推导。可观测性检验的要点是：如果理论预测D(γ)在γ_c翻转→这个预测在原则上可被光晶格/电路网络实验验证→理论有实验意义。
