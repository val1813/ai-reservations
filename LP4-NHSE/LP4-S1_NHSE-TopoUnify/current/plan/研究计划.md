# 研究计划 — NHSE-TopoUnify v1

## 北极星
Lindbladian拓扑与postselected拓扑是否存在包含两者为极限的母框架？

## 院长战略背景
- **院长评级：** B
- **理由：** 问题重要但AB验证分数偏低（A:1, B:2），核心矛盾尖锐度不如LP-1/LP-3。A博士指出原始互斥性假设过强（sector-resolved coexistence已被证实），需额外假设使矛盾尖锐化。
- **发表目标：** Physical Review B / Physical Review Research
- **院长建议：** 优先级低于LP-3。注意：本课题必须在初始Phase就回应A:1评分暴露的尖锐度不足问题。

## 驱动矛盾（精确化，回应A:1）

**不可共存的尖锐矛盾：**

命题A（Lindbladian点隙拓扑）：开放量子系统由Lindblad主方程dρ/dt = -i[H,ρ] + Σ(L_μ ρ L_μ† - ½{L_μ†L_μ, ρ})描述。等效非厄米哈密顿量H_eff = H - i/2 Σ L_μ†L_μ的点隙拓扑不变量→决定NHSE趋肤方向为D_L。

命题B（Postselected非Bloch拓扑）：条件演化|ψ(t)⟩ = e^{-iH_eff t}|ψ(0)⟩/||·||的动力学由非Bloch能带理论描述→广义Brillouin区拓扑不变量→决定NHSE趋肤方向为D_P。

**arXiv:2507.07187核心发现：D_L和D_P可以相反。** 同一物理系统（相同H、相同L_μ、相同参数），两种框架给出相反的趋肤方向预测。

为什么不能同时为真：若两者都声称自己是"正确"的拓扑分类→同一实验系统只能有一个趋肤方向→至少一个框架的"正确性"声张需要限定条件。

**本课题核心问题：** 是否存在一个以测量强度γ（或等效参数）为连续变量的母框架H(γ)，使得γ→0恢复Lindbladian拓扑、γ→∞恢复postselected拓扑，且D(γ)在某个临界γ_c发生相变（或连续演化）？

**来源：**
- arXiv:2507.07187 — Lindbladian point-gap vs postselected non-Bloch NHSE方向冲突
- arXiv:2110.13164 — 多体NHSE的Liouvillian能谱理论
- arXiv:2309.07894 — 非厄米趋肤效应的动力学判据
- Dartmouth 2026 (Kawabata et al.) — Pseudo-Hermitian QM框架

## 合法性确认（三问）

**Q1: 驱动矛盾能写成"命题A vs 命题B，不能同时为真"？**
→ **是。** arXiv:2507.07187明确显示Lindbladian点隙拓扑和postselected非Bloch拓扑可给出相反趋肤方向。两者不能同时是"完整"描述——D_L ≠ D_P意味着实验上只能观察到一个方向。

**Q2: 解决后谁的工作会改变？**
→ 非厄米拓扑分类的整个社区。具体来说：Kawabata-Sato (2019)的点隙拓扑分类、Okuma-Sato (2023)的非Bloch能带理论、Bergholtz-Budich (2021)的多体NHSE综述。若母框架存在→拓扑不变量需在γ参数空间重新定义。若母框架不存在→需为Lindbladian和postselected划定各自的合法域。

**Q3: 是技术推广还是新结构介入？**
→ **新结构介入。** 连续插值母框架H(γ)是一个新的数学对象——它既不是Lindbladian也不是postselected哈密顿量，而是包含两者为极限的参数化族。这需要定义γ依赖的拓扑不变量ν(γ)，以及ν(γ)在γ∈[0,1]上是否保持量子化/在何处跳变。

## 研究路径

### Phase 1（核心 — 本Phase）：连续插值框架搭建 + 1D简化模型分析
**目标：** 在最小模型中建立Lindbladian→postselected的连续插值，计算拓扑不变量ν(γ)的演化。

**具体方案：**
1. 从Lindblad主方程出发，定义γ参数化族：
   - γ=0：标准Lindblad演化（trace-preserving, 量子跳跃完整保留）
   - γ∈(0,1)：量子轨迹的弱postselection（以概率γ丢弃量子跳跃轨迹）
   - γ=1：纯postselected演化（只保留无条件量子跳跃的轨迹→等效非厄米哈密顿量演化）
2. 在1D Hatano-Nelson模型+Lindblad耗散（单粒子损失L=√γ_c c_j）中：
   - 计算H_eff(γ) = H_HN - i/2 Σ L_μ†L_μ(γ) 其中耗散强度依赖于γ
   - 计算ν(γ) = winding number of H_eff(γ) around point gap
   - 判定ν(γ)是否在某个γ_c发生跳变（相变）还是连续变化
3. 若发现相变→表征相变点γ_c的普适性质
   若连续变化→寻找ν(γ)的统一数学形式（γ参数化的winding number）

**产出：** ν(γ)的解析表达式（或数值证据）+ 相变/连续演化的判定

### Phase 2：统一不变量数学形式 + 扩展到2D/多带
**目标：** 将Phase 1的发现形式化为统一的拓扑不变量框架。

### Phase 3：数值验证 + 多体效应
**目标：** 在HN-Hubbard模型中验证相位图，检查相互作用对γ_c的影响。

## 风险

### 自毁风险（从候选池继承）：中
- 若连续插值在数学上trivial（只是耗散强度的标度变换，无新物理）→ 课题无实质贡献
- 若γ参数化在1D HN模型中的ν(γ)恒为常数（即无相变，两个极限拓扑相同）→ 矛盾需要更复杂的模型才能显现

### 修复路径（已在候选池中）
- 原始互斥假设过强（A:1）→ Phase 1必须首先验证：在最小1D HN+耗散模型中，Lindbladian和postselected是否真的给出不同趋肤方向？若否→矛盾本身不成立→课题证伪轻量化
- 若1D模型不够→升级到2D或考虑量子跳跃关联

### 最脆弱的地方
- arXiv:2507.07187的方向冲突是否在所有参数域成立，还是仅在特定极限？
- 连续插值的参数化方案是否是唯一的？不同的插值路径可能给出不同的ν(γ)演化
