## Active

### 卡点P1.1 — 均匀耗散只产生"存在性"相变，不产生"方向反转"
- **打开Phase：** 1 (A博士)
- **类型：** Active
- **尝试路径：** 1D HN + 均匀耗散 → 椭圆分析 → ν(γ) = 0↔+1
- **卡在何处：** 全局虚常数-iΓ(γ)只移动参考点（改变ν的0/非0状态），不改变椭圆绕行方向→无法产生ν符号翻转。要复现arXiv:2507.07187的相反趋肤方向，需要H_eff获得k依赖的虚部（非均匀耗散）或考虑Liouvillian超算子的完整谱（多体Fock空间）。
- **当前状态：** Active → 方向a: 非均匀耗散模型（边界增强耗散）→ Phase 2可攻打

### 卡点P1.2 — 维度失配：Z(2N维) vs H_eff(N维)
- **打开Phase：** 1 (B博士 L1)
- **类型：** Active
- **尝试路径：** 第三量子化→2N维Nambu矩阵 vs 单粒子H_eff→N维Hilbert矩阵
- **卡在何处：** 两个矩阵的winding number定义在不同向量丛上。ν_Z基于K_I(C_0(H_−))，ν_H基于K_I(C_0(C))。两个C*-代数不同构→K群不同→不变量不可直接比较。需要找到嵌入M_N(C)↪M_{2N}(C)的自然方式，或在更大的统一代数中定义ν。
- **当前状态：** Active → 方向b: Stinespring膨胀→母空间H_S⊗H_E → Phase 2可攻打

### 卡点P1.3 — 分类表失配：10类 vs 38类
- **打开Phase：** 1 (B博士 L2)
- **类型：** Active
- **尝试路径：** Lie-McGinley-Cooper十重方式 vs Kawabata-Sato 38类
- **卡在何处：** 28/38类对CPTP系统不可达。若postselected H_eff在这28类中，γ参数化必在某γ_c违反Im(λ)≤0。即使类A（无对称性）两个端点都在十重方式内，CPTP的半平面约束仍改变K理论底空间。
- **当前状态：** Active — 与P1.2密切相关，可联合攻打

### 卡点P1.4 — AIII类中CPTP强制ν=0
- **打开Phase：** 1 (B博士 L3)
- **类型：** Active
- **尝试路径：** CPTP Im(λ)≤0 + AIII手征对称性 → 全实谱 → ν_Z≡0
- **卡在何处：** 而postselected AIII H_eff可有ν_H≠0。γ参数化无法在不打破对称性或CPTP兼容性的前提下连接。这是P1.3的尖锐特例。
- **当前状态：** Active — 可用于检验任何候选母框架（若母框架能解决AIII矛盾→强证据）

## 卡点关联分析

P1.1（实用层面）和 P1.2-P1.4（结构层面）构成互补：
- P1.1指出在N维H_eff内前进需要非均匀耗散
- P1.2-P1.4指出N维H_eff本身不足以承载完整的统一

**瓶颈判断：** P1.2是根本性卡点——如果维度失配不解决，其他所有卡点的解决方案都可能只是特例。

## BLINDSPOT卡点

### 卡点B1 — γ物理定义缺失（BLOCK级别）
- **打开Phase：** 1 (BLINDSPOT via C4检查点)
- **类型：** Active — BLOCK，必须修复
- **卡在何处：** H_eff(k,γ) = H_HN(k) - i(γ_diss/2)(1-γ)中γ无物理来源。若γ为人为插值参数→无物理新奇性；若γ为实验参数→需引用实验实现（Wiseman-Milburn量子轨迹框架）。
- **当前状态：** Phase 2 A博士任务中修复——γ=量子轨迹postselection效率η（量子光学可调谐参数）

### 卡点B2 — 隐藏t_L>t_R假设

- **类型：** Deferred — 低优先级，已融入K1.1修正（ν=sign(t_L-t_R)）
- **当前状态：** 已修正，退化极限t_L=t_R已标注
