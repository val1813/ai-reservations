# 物理量身份证 — NHSE-TopoUnify v1

> 每个物理量必须有：定义、数学类型、值域、在什么条件下定义良好、被什么近似影响

---

## 量1：H_eff(γ) — γ参数化的等效非厄米哈密顿量
- **定义：** H_eff(γ) = H - i/2 Σ_μ L_μ†L_μ · f(γ)，其中f(γ)是插值函数
  - f(0) = 1（完整Lindbladian，包含所有量子跳跃的反作用）
  - f(1) = 1但演化方式改变（postselected：无量子跳跃轨迹的条件期望）
- **数学类型：** 非厄米算符 ∈ B(H)，dim = N×N（N为Hilbert空间维数）
- **值域：** 复平面上N个点（本征值）
- **定义良好条件：** H自伴、L_μ有界（或适当正规化）
- **近似影响：** Born-Markov近似（Lindblad推导的前提）→ 强耦合/非马尔可夫域失效
- **math_object：** non-Hermitian_operator_1pFamily(γ∈[0,1])

## 量2：ν(γ) — γ依赖的拓扑不变量
- **定义：** ν(γ) = (1/2πi) ∮_{BZ} dk ∂_k ln det[H_eff(k,γ) - E_ref]
  - 对1D系统，这是点隙winding number
  - 参考能量E_ref取在点隙内
- **数学类型：** Z值（整数）
- **值域：** Z
- **定义良好条件：** H_eff(k,γ)在BZ上非奇异（即点隙存在，det[H_eff - E_ref] ≠ 0 ∀k）
- **近似影响：** 数值离散化误差、有限尺寸效应
- **math_object：** winding_number_1pFamily(Z, γ∈[0,1])

## 量3：D(γ) — γ依赖的趋肤方向
- **定义：** D(γ) = sgn[∑_n |ψ_n(γ)|² · n - N/2]（质心偏移方向）
  - 所有本征态的平均质心相对于系统中心的偏移符号
- **数学类型：** {-1, 0, +1}（离散）
- **值域：** {-1（左趋肤）, 0（无趋肤）, +1（右趋肤）}
- **定义良好条件：** OBC本征态全部局域化于边界（NHSE条件满足）
- **近似影响：** 有限尺寸→个别本征态可能在边界间振荡
- **math_object：** skin_direction_discriminant(γ)

## 量4：γ_c — 临界测量强度（若相变存在）
- **定义：** ν(γ)发生跳变的最小γ值，或D(γ)翻转的γ值
- **数学类型：** 实数 ∈ [0,1]
- **值域：** [0,1]（若存在）或 ∅（若无相变）
- **定义良好条件：** 相变是一级的（ν跳变）→γ_c良定；若连续交叉→需定义阈值
- **近似影响：** 有限尺寸圆滑化（finite-size rounding）
- **math_object：** critical_point_or_empty(1pFamily)

## 量5：Δ_LR — Lindbladian与postselected的趋肤方向差
- **定义：** Δ_LR = D(γ=0) - D(γ=1)（方向差的量化）
- **数学类型：** {-2, -1, 0, +1, +2}
- **值域：** {-2, -1, 0, +1, +2}
- **定义良好条件：** 需要OBC对角化+NHSE存在
- **近似影响：** 必须确保γ=0和γ=1的D都是干净测量的
- **math_object：** direction_difference(γ=0, γ=1)
