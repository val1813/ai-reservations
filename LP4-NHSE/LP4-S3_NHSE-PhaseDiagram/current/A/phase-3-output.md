# A博士 Phase 3 — 完整相图草案

## 推荐相图标题

`multi-layer NHSE survival/suppression map in Hatano-Nelson-Hubbard`

## 主图结构

### Panel 1: Structure layer

- 显示 `M=0/1/mix`
- 标出局域耗散 no-go 区
- 标出非局域 jump 条件线

### Panel 2: Diagnostic layer

- 显示 `R_low / R_cross / R_high`
- 标出 DR-NHDD 的分段正负区
- 标出 `rho≈0.75` 的过渡带

### Panel 3: Caveat layer

- 标出 OBC 有限尺寸区
- 标出物理实现约束区
- 标出原始 QLIF 未重算区

## 结论句

1. LP4-S1 给出结构层母框架。
2. LP4-S2 给出诊断层分段对象 DR-NHDD。
3. 两者合起来只能得到多层级边界图，不能得到单一 sector-independent 拓扑不变量。

## 可投稿表述

**NHSE 的存活/抑制边界在 HN-Hubbard 中是一个三层对象：结构层由母框架控制，诊断层由 DR-NHDD 控制，边界层由 finite-size 与实现约束控制。**

这张图是完整的，但不是统一不变量图。
