# B博士 Phase 3 — 收官反证

## 最终反证

如果作者试图把 LP4-S3 写成“统一拓扑相图”，会遭遇三类不可消去冲突：

1. 结构层需要母框架，诊断层却不具备不变量性质。
2. DR-NHDD 的分段依赖 sector / freeze / boundary，不可全局量化。
3. 有限尺寸 OBC 的方向反转窗口不能直接当 bulk phase boundary。

## 结论

LP4-S3 不是统一拓扑相图，而是多层级生存/抑制地图。

## 论文边界

可以写：

- `structural layer`
- `diagnostic layer`
- `boundary caveat layer`

不能写：

- 单一 `sector-independent topological invariant`
- 全局统一 `phase diagram by one number`

## 收官判定

Phase 3 通过，项目可收官为有边界。
