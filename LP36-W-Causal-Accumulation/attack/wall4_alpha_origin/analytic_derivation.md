## 执行摘要

对齐Rxx(θ)环的QCMI在小θ下有以下解析结构:

$$\boxed{\text{QCMI}(\theta) = A \cdot \theta^2 \cdot \log\frac{1}{\theta} + B \cdot \theta^2 + C \cdot \theta^4 + O(\theta^4\log\theta, \theta^6)}$$

其中:
- **A = d_R · c₂**（d_R = 参考系统维数对熵的贡献，c₂ = θ²级扰动下新生非零特征值系数）
- **log(1/θ)项来自von Neumann熵在特征值λ∝θ²→0时的对数奇异性**
- 有效标度指数: α_eff = 2 − 1/log(1/θ) ≈ 1.81 at θ=π/512

CCQ定理声称QCMI=O(θ⁴)是错误的——错误源在§3.2，将"BCH交叉项消去"与"QCMI无O(θ²)贡献"混为一谈。

## 第0步: CCQ定理的精确漏洞定位

### 0.1 CCQ的推理链

CCQ定理 (commutativity_theorem.md §3.2-3.4) 的论证步骤:

**步骤1** (正确): 所有Rxx(θ)门的Cartan Hamiltonians对易
```
[H^(1), H^(2)] = [H^(1), H^(3)] = ... = 0
```
因为所有Hamiltonians都正比于σ_x⊗σ_x（在不同qubit对上），共享qubit时用相同的σ_x算子（σ_x与自身对易），不共享qubit时算子作用在不同子空间（也对易）。

**步骤2** (正确): BCH展开中无非相邻边的交叉项
```
log(U_4 U_3 U_2 U_1) = i(H^(1)+H^(2)+H^(3)+H^(4)) + 0 + O(|c|³)
```
对易子[H^(1), H^(3)] = [H^(2), H^(4)] = 0保证二阶BCH项中环特有的非相邻边对易子为零。

**步骤3** (错误 — 漏洞在此): 声称"环没有引入任何树中不存在的算子结构"，因此QCMI_cycle ≤ QCMI_tree + O(|c|⁴)。

**步骤4** (错误): 声称"QCMI_aligned ≥ p(1-p)/(4 ln 2) Σ|c|⁴"，即QCMI仅在O(|c|⁴)阶非零。

### 0.2 漏洞的精确本质

**漏洞在步骤3到步骤4的跳跃:** CCQ混淆了两个不同的概念——

| 概念 | 定义 | 对齐轴时的行为 |
|------|------|---------------|
| BCH交叉项（非相邻边对易子） | 来自[H^(1), H^(3)]等非零对易子，在U=exp(iH_tot)中产生非Cartan型新算子 | **确实为零** ✓ |
| 单边O(θ)项通过乘积产生的O(θ²)项 | 来自每个门独立的-i(θ/2)σ_x⊗σ_x项，在四个门的乘积中产生的二阶项 | **非零** ✗ (CCQ忽略了此项) |

**关键点:** 即使BCH展开没有交叉项，总酉算子的O(θ²)展开仍包含**同一边两次出现**的项（h_i² ∝ I）和**相邻边乘积**的项（h_i h_j，因共享E qubit而简并）。这些项在环境投影后产生O(θ²)的Kraus算子偏差，从而产生O(θ²)的QCMI。

### 0.3 物理论证

每条Rxx(θ)边独立地在Q-E qubit对之间产生O(θ)的纠缠生成。四条边串联后，每条边的O(θ)纠缠独立地对总纠缠有贡献。**QCMI ∝ (每个门贡献的纠缠)² ∝ θ²**（因为von Neumann熵在纯态附近是特征值的二次函数）。

CCQ的"O(|c|⁴)"相当于声称四个门的O(θ)贡献之间存在destructive interference使净O(θ²)贡献为零。但实验数据直接反驳了这一点——不存在这样的完美相消。

### 0.4 数学验证

将各边展开:
$$u_i(\theta) = \exp(-i\theta/2 \cdot \sigma_x \otimes \sigma_x) = I - i\frac{\theta}{2} h_i - \frac{\theta^2}{8} I + O(\theta^3)$$

其中h_i是σ_x⊗σ_x在边i上的4-qubit嵌入。

乘积展开到O(θ²):
$$U = \prod_{i=1}^4 \left(I - i\frac{\theta}{2}h_i - \frac{\theta^2}{8}I\right) + O(\theta^3)$$
$$= I - i\frac{\theta}{2}\sum_i h_i - \frac{\theta^2}{2}I - \frac{\theta^2}{4}\sum_{i<j} h_i h_j + O(\theta^3)$$

**关键观察:** -iθ/2 Σ h_i 项非零。它包含Q_a, Q_b, E1, E2上的σ_x算子。当U作用在初始RQE态上并部分求迹E后，此项在ρ_RQ中产生O(θ²)的扰动——这正是QCMI=O(θ²)的来源。

CCQ错误地认为h_i之间可能"相消"，但h_i作用在**不同qubit对上**（边1在Q_a-E1, 边2在E1-Q_b, 等），它们是线性独立的16×16矩阵，不存在相消。相消只可能发生在BCH对易子层面——但对易子为零，相消问题根本不存在。

## 第1步: 精确对角化 — Rxx环结构的完整本征分解

### 1.1 总酉算子的精确形式

4-qubit空间(H_Qa ⊗ H_E1 ⊗ H_Qb ⊗ H_E2)中，4条Rxx边嵌为:

$$\begin{aligned}
H^{(1)} &= -\frac{\theta}{2} \cdot \sigma_x \otimes \sigma_x \otimes I \otimes I \\
H^{(2)} &= -\frac{\theta}{2} \cdot I \otimes \sigma_x \otimes \sigma_x \otimes I \\
H^{(3)} &= -\frac{\theta}{2} \cdot I \otimes I \otimes \sigma_x \otimes \sigma_x \\
H^{(4)} &= -\frac{\theta}{2} \cdot \sigma_x \otimes I \otimes I \otimes \sigma_x
\end{aligned}$$

所有H^(i)两两对易 ⇒ 总酉:
$$U = \exp\left(i\sum_{i=1}^4 H^{(i)}\right) = \exp\left(-\frac{i\theta}{2} \hat{S}\right)$$

其中:
$$\boxed{\hat{S} = \sigma_x^{Q_a}\sigma_x^{E_1} + \sigma_x^{E_1}\sigma_x^{Q_b} + \sigma_x^{Q_b}\sigma_x^{E_2} + \sigma_x^{E_2}\sigma_x^{Q_a}}$$

### 1.2 σ_x本征基对角化

在σ_x的本征基|+⟩, |-⟩下（σ_x|+⟩=|+⟩, σ_x|-⟩=-|-⟩），用本征值s_i ∈ {+1, -1}标记每个qubit。

在此基下，总酉是对角的:
$$U|s_1, s_2, s_3, s_4\rangle = e^{-i\theta S/2} |s_1, s_2, s_3, s_4\rangle$$

其中:
$$\boxed{S(s_1, s_2, s_3, s_4) = s_1 s_2 + s_2 s_3 + s_3 s_4 + s_4 s_1}$$

### 1.3 关键因式分解

$$\boxed{S = (s_1 + s_3)(s_2 + s_4)}$$

证: (s₁+s₃)(s₂+s₄) = s₁s₂ + s₁s₄ + s₃s₂ + s₃s₄ = s₁s₂ + s₄s₁ + s₂s₃ + s₃s₄ = S。 ∎

由于s_i ∈ {±1}:
- s₁+s₃ ∈ {-2, 0, +2}
- s₂+s₄ ∈ {-2, 0, +2}
- S ∈ {-4, 0, +4}

### 1.4 本征空间结构

| S值 | 条件 | 简并度 | U的本征值 | 物理意义 |
|:---:|------|:-----:|----------|---------|
| +4 | s₁=s₃ 且 s₂=s₄ | 4 | e^{-2iθ} | Q-E完全同相 |
| -4 | s₁=s₃ 且 s₂=-s₄ | 4 | e^{+2iθ} | Q-E反相 |
| 0 | s₁=-s₃ 或 s₂=-s₄ | 8 | 1 | 无净相位累积 |

**投影算子表示:**
$$U = e^{-2i\theta} \Pi_{+4} + e^{+2i\theta} \Pi_{-4} + \Pi_0$$

其中投影算子作用于4-qubit σ_x本征基:
$$\begin{aligned}
\Pi_{+4} &= \frac{1}{4}(I + \sigma_x^{Q_a}\sigma_x^{Q_b})(I + \sigma_x^{E_1}\sigma_x^{E_2}) \\
\Pi_{-4} &= \frac{1}{4}(I + \sigma_x^{Q_a}\sigma_x^{Q_b})(I - \sigma_x^{E_1}\sigma_x^{E_2}) \\
\Pi_0 &= I - \Pi_{+4} - \Pi_{-4}
\end{aligned}$$

验证: Tr(Π_{+4}) = 4, Tr(Π_{-4}) = 4, Tr(Π_0) = 8。 ✓

**小θ展开:**
$$U = I - 2i\theta(\Pi_{+4} - \Pi_{-4}) - 2\theta^2(\Pi_{+4} + \Pi_{-4}) + O(\theta^3)$$

注意: Π_{+4} - Π_{-4} = (1/2)(I + σ_x^{Q_a}σ_x^{Q_b})σ_x^{E_1}σ_x^{E_2}

## 第2步: QCMI的微扰展开 (途经Choi态)

### 2.1 初始态和演化

4节点环, Buscemi混合态环境 γ = p|0⟩⟨0| + (1-p)|1⟩⟨1|:

初始R-Q纠缠态:
$$\rho_{RQ}^{\text{init}} = |\Phi^+\rangle\langle\Phi^+|_{R_a Q_a} \otimes |\Phi^+\rangle\langle\Phi^+|_{R_b Q_b}$$

初始环境态: ρ_E^{init} = γ ⊗ γ (两个E qubit各在混合态)

完整初态: ρ_RQE^{init} = ρ_RQ^{init} ⊗ ρ_E^{init}

演化: ρ'_RQE = (I_R ⊗ U_QE) ρ_RQE^{init} (I_R ⊗ U_QE^†)

### 2.2 简化: QCMI = S(ρ_RQ)

实验数据§7确认: S(QE)和S(RQE)对所有θ = 3.762582和1.762582（常数）。这是因为U是酉的且在QE上作用，保所有RQE的本征值。

在此设置下:
$$\boxed{\text{QCMI} = S(\rho_{RQ}) = -\text{Tr}[\rho_{RQ} \log_2 \rho_{RQ}]}$$

ρ_RQ = Tr_E[ρ'_RQE]。

### 2.3 θ展开

展开ρ_RQ(θ) = ρ_RQ^(0) + θ·ρ_RQ^(1) + θ²·ρ_RQ^(2) + θ³·ρ_RQ^(3) + θ⁴·ρ_RQ^(4) + O(θ⁵)

**θ=0:** ρ_RQ^(0) = |Φ⁺⟩⟨Φ⁺|⊗|Φ⁺⟩⟨Φ⁺| — 纯态, 本征值 {1, 0, 0, ..., 0}, S=0。

**O(θ):** ρ_RQ^(1)来自U的O(θ)项。此项反厄米:
$$\rho_{RQ}^{(1)} = -i\text{Tr}_E\left[\frac{\hat{S}}{2}, \rho_{RQE}^{\text{init}}\right]$$

对于纯RQ初态, 反厄米扰动ρ_RQ^(1)不改变ρ_RQ的本征值到O(θ)——仅旋转本征矢量。因此S(ρ_RQ)无O(θ)贡献。 ✓ (QCMI在θ→0时→0, 一致)

**O(θ²):** 本征值首次偏离。ρ_RQ^(2)包含:
1. 来自(U的O(θ))(U†的O(θ)) = (θ²/4)Ŝ ρ Ŝ 的项
2. 来自(U的O(θ²))(U†的O(0)) + h.c. 的项

$$\rho_{RQ}^{(2)} = \text{Tr}_E\left[\frac{\hat{S}}{2} \rho_{RQE}^{\text{init}} \frac{\hat{S}}{2} - \frac{1}{2}\{\frac{\hat{S}^2}{4}, \rho_{RQE}^{\text{init}}\}\right]$$

### 2.4 Ŝ在RQ-E分解中的作用

Ŝ = σ_x^{Q_a}σ_x^{E_1} + σ_x^{E_1}σ_x^{Q_b} + σ_x^{Q_b}σ_x^{E_2} + σ_x^{E_2}σ_x^{Q_a}

重新组织:
$$\hat{S} = \sigma_x^{Q_a} \otimes (\sigma_x^{E_1} + \sigma_x^{E_2}) + \sigma_x^{Q_b} \otimes (\sigma_x^{E_1} + \sigma_x^{E_2})$$

这是关键结构: **Q_a和Q_b以相同方式耦合到E1和E2。** Ŝ对Q_a和Q_b完全对称。

定义E的集体算子:
$$X_E = \sigma_x^{E_1} + \sigma_x^{E_2}$$

则:
$$\hat{S} = (\sigma_x^{Q_a} + \sigma_x^{Q_b}) \otimes X_E$$

**注意:** 此处⊗是通俗记号——Ŝ实际在4-qubit空间中是4个Pauli串之和, 不是严格的(2-qubit)⊗(2-qubit)乘积。但在σ_x本征基中, Ŝ的本征值确实分解为(s₁+s₃)(s₂+s₄)，验证了此结构。

### 2.5 ρ_RQ^(2)的显式计算

ρ_RQ^{init} = |Φ⁺⟩⟨Φ⁺|_{R_a Q_a} ⊗ |Φ⁺⟩⟨Φ⁺|_{R_b Q_b}

环境态 ρ_E = γ ⊗ γ, γ = p|0⟩⟨0| + (1-p)|1⟩⟨1|

计算Tr_E[Ŝ ρ_RQE^{init} Ŝ]:

Ŝ = Σ_{q∈{a,b}} Σ_{e∈{1,2}} σ_x^{Q_q} σ_x^{E_e}

Ŝ ρ_RQE^{init} Ŝ = Σ_{q,q'} Σ_{e,e'} σ_x^{Q_q} σ_x^{Q_{q'}} |Φ⁺⟩⟨Φ⁺| ⊗ σ_x^{E_e} ρ_E σ_x^{E_{e'}}

对E求迹:
Tr_E[σ_x^{E_e} ρ_E σ_x^{E_{e'}}]:
- 若e=e': Tr[σ_x γ σ_x γ] = Tr[σ_x γ σ_x]·Tr[γ] (另一E qubit给Tr[γ]=1)
  = Tr[γ σ_x γ σ_x] (循环排列, dim=2)
  在计算基下: γ = diag(p, 1-p), σ_x = [[0,1],[1,0]]
  σ_x γ σ_x = [[1-p, 0], [0, p]]
  Tr[γ σ_x γ σ_x] = p(1-p) + (1-p)p = 2p(1-p)

  等等, 让我仔细计算。
  γ = p|0⟩⟨0| + (1-p)|1⟩⟨1|
  σ_x|0⟩ = |1⟩, σ_x|1⟩ = |0⟩
  σ_x γ σ_x = p|1⟩⟨1| + (1-p)|0⟩⟨0| = (1-p)|0⟩⟨0| + p|1⟩⟨1|
  γ σ_x γ σ_x = [p|0⟩⟨0|+(1-p)|1⟩⟨1|] · [(1-p)|0⟩⟨0|+p|1⟩⟨1|]
  = p(1-p)|0⟩⟨0| + (1-p)p|1⟩⟨1| = p(1-p)·I
  Tr[γ σ_x γ σ_x] = 2p(1-p)

- 若e≠e' (e在E1上, e'在E2上): 
  Tr[σ_x γ]·Tr[γ σ_x] = Tr[σ_x γ]·Tr[σ_x γ] (因为Tr[γ σ_x]=Tr[σ_x γ])
  Tr[σ_x γ] = Tr[σ_x · diag(p,1-p)] = 0 (σ_x无对角元)

所以:
Tr_E[σ_x^{E_e} ρ_E σ_x^{E_{e'}}] = 2p(1-p) · δ_{e,e'} · (另一E qubit的tr=1)

ρ_RQ^{(2)}的Ŝ ρ Ŝ部分 = (θ²/4) Σ_{q,q'} σ_x^{Q_q} |Φ⁺⟩⟨Φ⁺| σ_x^{Q_{q'}} · 2p(1-p) Σ_e 1

= (θ²/4) · 2p(1-p) · 2 · Σ_{q,q'} σ_x^{Q_q} |Φ⁺⟩⟨Φ⁺| σ_x^{Q_{q'}}

= θ² · p(1-p) · Σ_{q,q'∈{a,b}} σ_x^{Q_q} |Φ⁺⟩⟨Φ⁺|_{RQ} σ_x^{Q_{q'}}

类似地, Ŝ² ρ + ρ Ŝ² 部分...
Ŝ² = (σ_x^{Q_a} + σ_x^{Q_b})² ⊗ (σ_x^{E_1} + σ_x^{E_2})²

(σ_x^{Q_a} + σ_x^{Q_b})² = (σ_x^{Q_a})² + (σ_x^{Q_b})² + 2σ_x^{Q_a}σ_x^{Q_b} = 2I + 2σ_x^{Q_a}σ_x^{Q_b}
(σ_x^{E_1} + σ_x^{E_2})² = 2I + 2σ_x^{E_1}σ_x^{E_2}

Ŝ² = (2I_Q + 2σ_x^{Q_a}σ_x^{Q_b}) ⊗ (2I_E + 2σ_x^{E_1}σ_x^{E_2})

Tr_E[Ŝ² ρ_E] / 4:
Tr_E[(2I_Q + 2σ_x^{Q_a}σ_x^{Q_b}) · (2I_E + 2σ_x^{E_1}σ_x^{E_2}) · (ρ_RQ ⊗ ρ_E)] / 4

在E上的迹: Tr_E[2I_E + 2σ_x^{E_1}σ_x^{E_2}] = 2Tr[I]·Tr[I] + 2Tr[σ_x]·Tr[σ_x] = 2·4 + 2·0 = 8

(因为Tr_{E1}[I]=2, Tr_{E2}[I]=2; Tr[σ_x]=0)

所以Tr_E[Ŝ²]/4 = (1/4)(2I_Q + 2σ_x^{Q_a}σ_x^{Q_b})·8 = 4I_Q + 4σ_x^{Q_a}σ_x^{Q_b}

最终:
$$\boxed{\rho_{RQ}^{(2)} = p(1-p) \cdot \sum_{q,q'\in\{a,b\}} \sigma_x^{Q_q} |\Phi^+\rangle\langle\Phi^+|_{RQ} \sigma_x^{Q_{q'}} - (I_Q + \sigma_x^{Q_a}\sigma_x^{Q_b}) |\Phi^+\rangle\langle\Phi^+|_{RQ}}$$

注意p(1-p)因子出现——这是Buscemi混合环境的直接后果。对p=0.7, p(1-p)=0.21。

### 2.6 ρ_RQ^(2)的本征分析

在RQ = R_a Q_a ⊗ R_b Q_b = ℂ⁴ ⊗ ℂ⁴ 空间中（16×16矩阵），初始态 |Φ⁺⟩⟨Φ⁺|⊗|Φ⁺⟩⟨Φ⁺| 是4-qubit纯态。

设 |Ω⟩ = |Φ⁺⟩_{R_a Q_a} ⊗ |Φ⁺⟩_{R_b Q_b}。则:
ρ_RQ^(2) = p(1-p)[(σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩⟨Ω|(σ_x^{Q_a}+σ_x^{Q_b})] - [I_Q + σ_x^{Q_a}σ_x^{Q_b}]|Ω⟩⟨Ω|

不, 等号右侧不止这些项——还有对易子/反对易子的另一半。让我重算。

正确的展开:
ρ_RQ(θ) = Tr_E[U ρ_RQE^{init} U†]

U = I - i(θ/2)Ŝ - (θ²/8)Ŝ² + O(θ³)

U ρ U† = ρ - i(θ/2)[Ŝ, ρ] + (θ²/4)Ŝ ρ Ŝ - (θ²/8){Ŝ², ρ} + O(θ³)

对E求迹:
ρ_RQ(θ) = ρ_RQ(0) - i(θ/2)Tr_E[Ŝ, ρ_RQE^{init}] + (θ²/4)Tr_E[Ŝ ρ Ŝ] - (θ²/8)Tr_E{Ŝ², ρ} + O(θ³)

O(θ)项: Tr_E[Ŝ ρ_RQE^{init}] (需分析此项是否为零)

Ŝ = (σ_x^{Q_a}+σ_x^{Q_b})·X_E^{coll} 其中X_E^{coll} = σ_x^{E_1}+σ_x^{E_2} (不是严格的张量积, 是Pauli串之和)

Tr_E[Ŝ ρ_RQE] = Tr_E[(σ_x^{Q_a}+σ_x^{Q_b})X_E^{coll} · |Ω⟩⟨Ω| ⊗ ρ_E]
= (σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩⟨Ω| · Tr[X_E^{coll} ρ_E]

Tr[X_E^{coll} ρ_E] = Tr[σ_x^{E1} γ]Tr[γ] + Tr[γ]Tr[σ_x^{E2} γ] = 0+0 = 0 (因为Tr[σ_x γ]=0)

所以O(θ)项为零。 ✓

O(θ²)项 第一部分:
Tr_E[Ŝ ρ Ŝ] = Tr_E[(σ_x^{Q_a}+σ_x^{Q_b})X_E^{coll} |Ω⟩⟨Ω|⊗ρ_E X_E^{coll}(σ_x^{Q_a}+σ_x^{Q_b})]

在E空间:
Tr_E[X_E^{coll} ρ_E X_E^{coll}] = Tr_E[(σ_x^{E1}+σ_x^{E2}) (γ⊗γ) (σ_x^{E1}+σ_x^{E2})]
= Tr[σ_x^{E1}γσ_x^{E1}]Tr[γ] + Tr[σ_x^{E2}γσ_x^{E2}]Tr[γ] + Tr[σ_x^{E1}γ]Tr[γσ_x^{E2}] + Tr[σ_x^{E2}γ]Tr[γσ_x^{E1}]

前两项: Tr[σ_x γ σ_x]·Tr[γ] = 2p(1-p)·1 = 2p(1-p) (每个E qubit各一份)
后两项: Tr[σ_x γ]·Tr[σ_x γ] = 0·0 = 0

所以Tr_E[X_E^{coll} ρ_E X_E^{coll}] = 2p(1-p) + 2p(1-p) = 4p(1-p)

因此:
(θ²/4) Tr_E[Ŝ ρ Ŝ] = (θ²/4) · 4p(1-p) · (σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩⟨Ω|(σ_x^{Q_a}+σ_x^{Q_b})
= θ² p(1-p) · (σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩⟨Ω|(σ_x^{Q_a}+σ_x^{Q_b})

  所以(θ²/4) Tr_E[ŜρŜ]的非平凡部分 (与|Ω⟩⟨Ω|不成比例的部分) 为:
  (±θ²/4) · [p(1-p)·2·(σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩⟨Ω|(σ_x^{Q_a}+σ_x^{Q_b}) + ...  非p(1-p)的项]

  这变得很复杂。让我换一种更简洁的方法。

## 第2步 (重述): 简洁的Choi态本征扰动方法

### 2A. 从U的本征结构直接求QCMI

前面得到U在σ_x本征基下是对角的:
U|s₁,s₂,s₃,s₄⟩ = e^{-iθ S/2}|s₁,s₂,s₃,s₄⟩, S = (s₁+s₃)(s₂+s₄)

QCMI = S(ρ_RQ)。关键观察: R和Q最初处于两个Bell态|Φ⁺⟩。经过U演化后, Q部分经历了一个映射, R保持不动。

ρ_RQ(θ) = (I_R ⊗ Φ_θ)(|Φ⁺⟩⟨Φ⁺|_{R_a Q_a} ⊗ |Φ⁺⟩⟨Φ⁺|_{R_b Q_b})

其中Φ_θ是Q上的量子信道 (Q_a, Q_b加上E环境后取迹):
Φ_θ(ρ_Q) = Tr_E[U_QE (ρ_Q ⊗ ρ_E) U_QE^†]

### 2B. Choi-Jamiolkowski同构

使用标准的Choi态方法: QCMI = S(J(Φ_θ)/d_Q), 其中J(Φ_θ) = (I⊗Φ_θ)(|Φ⁺⟩⟨Φ⁺|_{QQ'})。

在Q=Q_a Q_b 2-qubit系统中, d_Q = 4。

Choi态 J = (I_{Q'} ⊗ Φ_θ)(|Φ⁺⟩⟨Φ⁺|_{Q'Q}) 是 4×4 = 16维矩阵。

实际上, 更简单: 使用实验事实 QCMI = S(ρ_RQ)。

ρ_RQ(θ) = ρ_RQ(0) + θ²ρ_RQ^(2) + θ⁴ρ_RQ^(4) + O(θ⁶)

ρ_RQ(0)是纯态, 秩1, 本征值{1, 0, ..., 0}。

在小θ下, 本征值扰动公式给出:

$$\lambda_0(\theta) = 1 - c_2 \theta^2 + O(\theta^4)$$
$$\lambda_i(\theta) = d_i \theta^2 + O(\theta^4), \quad i = 1, ..., 15$$

其中c₂ = Σ_i d_i (迹守恒)。

熵:
$$S = -\lambda_0 \log_2 \lambda_0 - \sum_{i=1}^{15} \lambda_i \log_2 \lambda_i$$

展开:
$$-\lambda_0 \log_2 \lambda_0 = -(1-c_2\theta^2)\log_2(1-c_2\theta^2) = \frac{1}{\ln 2}\left(c_2\theta^2 - \frac{c_2^2}{2}\theta^4 + O(\theta^6)\right)$$

$$-\sum_i \lambda_i \log_2 \lambda_i = -\sum_i d_i\theta^2 \log_2(d_i\theta^2) = -\frac{\theta^2}{\ln 2}\sum_i d_i(\ln d_i + 2\ln\theta)$$
$$= \frac{1}{\ln 2}\left(-2c_2\theta^2\ln\theta - \theta^2\sum_i d_i\ln d_i\right)$$

总和:
$$\boxed{S = \frac{1}{\ln 2}\left(c_2\theta^2(1-2\ln\theta) - \theta^2\sum_i d_i\ln d_i - \frac{c_2^2}{2}\theta^4 + O(\theta^4\ln\theta)\right)}$$

### 2C. 对数项的出现 — 核心洞察

QCMI的主导项包含 **θ² log(1/θ)**:

$$\boxed{\text{QCMI} = \frac{2c_2}{\ln 2} \cdot \theta^2 \cdot \ln\frac{1}{\theta} + \frac{1}{\ln 2}\left(c_2 - \sum_i d_i\ln d_i\right) \cdot \theta^2 + O(\theta^4)}$$

换算到log₂:
$$\boxed{\text{QCMI} = 2c_2 \cdot \theta^2 \cdot \log_2\frac{1}{\theta} + \left(c_2 - \frac{\sum_i d_i\ln d_i}{\ln 2}\right) \cdot \theta^2 + O(\theta^4)}$$

物理上: 新生特征值 λ_i = d_i θ²。每个新生特征值对熵的贡献是 -d_i θ² log₂(d_i θ²) = -2d_i θ² log₂ θ - d_i θ² log₂ d_i。其中 **-2d_i θ² log₂ θ** 这项在θ→0时比θ²发散得慢(log), 但在有限θ下不可忽略。它就是α<2的原因。

### 2D. d_i系数的确定 — 对称性分析

ρ_RQ(0) = |Φ⁺⟩⟨Φ⁺|_{R_a Q_a} ⊗ |Φ⁺⟩⟨Φ⁺|_{R_b Q_b}

这个态在以下变换下不变:
- R_a ↔ R_b 同时 Q_a ↔ Q_b (交换对称性)
- 每个Bell对内部的局域酉对称性

扰动 Ŝ = σ_x^{Q_a}⊗(σ_x^{E1}+σ_x^{E2}) + σ_x^{Q_b}⊗(σ_x^{E1}+σ_x^{E2}) 在 Q_a↔Q_b交换下对称。

ρ_RQ^(2)作用在RQ的2-qubit子空间(Q_a, Q_b, 以及与R的纠缠)上。在计算基下, 初态|Ω⟩在RQ空间的展开:

|Φ⁺⟩_{R_a Q_a} ⊗ |Φ⁺⟩_{R_b Q_b} = (1/2)(|0000⟩ + |0011⟩ + |1100⟩ + |1111⟩)_{R_a Q_a R_b Q_b}

σ_x^{Q_a}作用: 翻转Q_a, 产生|0⟩_{Q_a}↔|1⟩_{Q_a}。
σ_x^{Q_a}|Ω⟩ = (1/2)(|0100⟩ + |0111⟩ + |1000⟩ + |1011⟩)

σ_x^{Q_b}类似。

由此, (σ_x^{Q_a}+σ_x^{Q_b})|Ω⟩ 产生的态在RQ的16维Hilbert空间中具有特定结构。通过与|Ω⟩和σ_x^{Q_a}σ_x^{Q_b}|Ω⟩正交化, 可以确定d_i。

**关键数值:** 由实验数据提取。使用两个最小θ值:
- θ₁ = 0.00613592, QCMI₁ = 6.076×10⁻⁴
- θ₂ = 0.01227185, QCMI₂ = 2.129×10⁻³

拟合 QCMI = A θ² log(1/θ) + B θ²:

令 y(θ) = QCMI/θ² = A log(1/θ) + B

| θ | QCMI/θ² | log(1/θ) |
|---|---------|----------|
| 0.00613592 | 16.14 | 5.094 |
| 0.01227185 | 14.14 | 4.401 |
| 0.02454369 | 12.14 | 3.708 |

线性拟合: 斜率 A ≈ (16.14-12.14)/(5.094-3.708) = 4.00/1.386 = **2.886** bits
截距 B ≈ 16.14 - 2.886×5.094 = **1.44** bits

验证: 对θ=0.01227185: A×4.401+B = 2.886×4.401+1.44 = 12.70+1.44 = 14.14 ✓

所以:
$$\boxed{\text{QCMI} \approx 2.886 \cdot \theta^2 \cdot \log_2\frac{1}{\theta} + 1.44 \cdot \theta^2}$$

对应到c₂和d_i:
A = 2c₂ = 2.886 ⇒ **c₂ ≈ 1.443** (在自然对数下A_nat = 2c₂_nat ⇒ c₂_nat = (2.886/2)×ln 2 ≈ 1.443×0.693 = 1.000)

c₂ = 1.443 bits 或 c₂_nat ≈ 1.000。

B = c₂ - Σ_i d_i log₂ d_i = 1.44

⇒ Σ_i d_i log₂ d_i = c₂ - B = 1.443 - 1.44 = 0.003 ≈ 0。

**物理含义:** d_i log₂ d_i的和几乎为零, 说明新生特征值分布非常特殊——可能仅有一个非零d (d≈c₂=1.443), 其log₂ d在某种抵消下恰好≈0 (即d≈1)。这意味着 QCMI ≈ 2c₂ θ² log₂(1/θ) 在主导阶几乎纯净。

## 第3步: θ⁴系数的物理起源

### 3.1 负的θ⁴贡献

熵展开中的θ⁴项有两个来源:

**来源1:** 主导特征值的二阶展开
$$-\lambda_0 \log_2 \lambda_0 = \frac{1}{\ln 2}(c_2\theta^2 - \frac{c_2^2}{2}\theta^4 + c_4\theta^4 + ...)$$
-c₂²/2项来自log(1-c₂θ²)展开的θ⁴阶: -(1-x)(-x-x²/2)中x=c₂θ²+c₄θ⁴:
= (1-c₂θ²-c₄θ⁴)(c₂θ²+c₄θ⁴ + c₂²θ⁴/2 + ...)
= c₂θ² + (c₄ + c₂²/2 - c₂²)θ⁴ = c₂θ² + (c₄ - c₂²/2)θ⁴

**来源2:** 新生特征值修正
λ_i = d_i θ² + e_i θ⁴
-λ_i log λ_i 的θ⁴阶: -(d_iθ²+e_iθ⁴)(log d_i + 2log θ + e_iθ²/d_i)
= ... -e_i θ⁴ (log d_i + 2 log θ) - d_i θ² (e_iθ²/d_i)

### 3.2 净θ⁴系数

$$\boxed{C_4 = \frac{1}{\ln 2}\left(c_4 - \frac{c_2^2}{2} - \sum_i e_i(\ln d_i + 1)\right)}$$

关键: -c₂²/2项给出**负贡献**, 量级约为 -(1.44)²/(2 ln 2) ≈ -1.50 (以θ⁴为单位)。

如果c₄项（来自四阶微扰的本征值移动）不能完全抵消这-c₂²/2, 则C₄ < 0。

**负C₄的物理后果:** 在有效幂律展开中:
QCMI = A θ² log(1/θ) + B θ² + C₄ θ⁴

QCMI = θ²[A log(1/θ) + B + C₄ θ² + ...]

有效指数:
$$\alpha_{\text{eff}} = \frac{d\ln\text{QCMI}}{d\ln\theta} = 2 + \frac{-A + 2C_4\theta^2}{A\log(1/\theta) + B + C_4\theta^2}$$

对小数θ: α_eff ≈ 2 - 1/log(1/θ) (log项主导)

包含C₄修正:
$$\alpha_{\text{eff}} = 2 - \frac{1}{\log(1/\theta)} + \frac{2C_4\theta^2}{A\log(1/\theta)} + O(1/\log^2)$$

如果C₄ < 0 (熵展开中-c₂²/2的主导负贡献), 则C₄项进一步使α_eff降低——**解释为什么α收敛到1.81而非更接近2。**

### 3.3 C₄的符号论证

-c₂²/(2 ln 2)来自log(1-x)展开中x²/2项。此项严格负。
c₄项来自四阶微扰ρ_RQ^(4)对主导特征值λ₀(θ)的修正。

ρ_RQ^(4)包含:
1. U中O(θ⁴)项 (来自cos(θ/2)展开的θ⁴/384项)
2. U中O(θ²)×O(θ²)交叉贡献 (Ŝ²项的组合)
3. U中O(θ)×O(θ³)项

所有正性条件 (ρ需保持半正定) 约束c₄。但一般情况下c₄ > 0 (四阶扰动使ρ更"混合", 降低主导特征值)。量级上c₄ ∼ O(c₂²), 所以c₄ − c₂²/2 的符号取决于两者的具体值。

对于本问题: |c₄ − c₂²/2| ∼ O(c₂²) ∼ 1 bit·θ⁴。实验显示有效α→1.81而非更接近2, 这需要C₄显著为负。

**定量估计:** 从α=1.809 at θ=0.006136:
用公式 α = 2 − 1/ln(1/θ) + 修正:
1/ln(1/θ)=1/5.094=0.196, 所以log项给出α≈1.804。
实验α=1.809, 差+0.005。如果C₄<0, 这项应使α更低。+0.005的差异可能来自B项(非log的θ²项)和数值舍入。

实际上, 对于θ=0.0245: α=1.739, 用log项: 1/ln(1/0.0245)=1/3.709=0.270, 2−0.270=1.730。实验α=1.739, 差+0.009。
对于θ=0.0123: 1/ln(81.5)=1/4.401=0.227, 2−0.227=1.773。下一实验点α=1.779。

这些差异很小(~0.005-0.009), 说明**log修正是主导机制**, C₄的贡献是次主导的。

## 第5步: CCQ错误的根本原因 — 总结

### 5.1 错误分类

| CCQ声称 | 事实 | 错误类型 |
|---------|------|---------|
| [H^(1), H^(3)]=0 (对齐轴) | 正确 ✓ | — |
| BCH无交叉项 | 正确 ✓ | — |
| ⇒ QCMI=O(\|c\|⁴) | 错误 ✗ | 概念混淆 |
| ⇒ QCMI/Sigma\|c\|²→0 | 错误 ✗ (实际→∞) | 推理跳跃 |

### 5.2 概念混淆的数学本质

CCQ将两个不同层级的"O(|c|²)"混为一谈:

1. **层A (BCH层):** BCH展开中的二阶项 [H^(i), H^(j)] 产生非Cartan算子。对齐轴时此项为零。✓
2. **层B (QCMI层):** QCMI的O(|c|²)贡献来自每个酉算子的独立一阶项在密度矩阵中产生的二阶扰动。此项**不依赖BCH交叉项**。CCQ忽略了它。✗

层B的数学结构:
$$\rho(\theta) = \rho_0 - i\frac{\theta}{2}[\hat{S}, \rho_0] + \frac{\theta^2}{4}\hat{S}\rho_0\hat{S} - \frac{\theta^2}{8}\{\hat{S}^2, \rho_0\} + O(\theta^3)$$

O(θ²)项中:
- Ŝρ₀Ŝ项 (正贡献): 来自每个边的一阶项通过"平方"产生
- {Ŝ², ρ₀}项 (负贡献): 来自每个边的二阶项

净O(θ²)贡献非零⇔QCMI=O(θ²)⇔CCQ的O(θ⁴)声称被推翻。

### 5.3 物理直觉

每条Rxx(θ)边独立地在Q和E qubit之间产生O(θ)的纠缠。这些纠缠**加性累积**而非相消干涉(因为每条边连接不同的qubit对)。QCMI ∝ (总生成纠缠)² ∝ θ²。

CCQ错误地预期存在相消干涉将O(θ²)消除。但实际上这需要不同边的纠缠生成算子之间存在特定的代数关系——而这种关系在对齐轴时恰好不存在(所有算子对易, 相消需要反厄米部分的对易子非零)。

**讽刺:** CCQ声称对易⇒O(|c|⁴), 但实际上是对易性本身意味着BCH项消失, 而BCH项消失意味着没有"相消"机制能将O(θ²)提升到O(θ⁴)。相消来自非对易在BCH中产生的负交叉项。对易时这些项为零, 每个边独立贡献的全O(θ²)保留。

## 第6步: 完整解析表达式

### 6.1 最终表达式

$$\boxed{\text{QCMI}_{\text{aligned Rxx}}(\theta) = 2c_2 \cdot \theta^2 \cdot \log_2\frac{1}{\theta} + b \cdot \theta^2 + c \cdot \theta^4 + O(\theta^4\log\theta, \theta^6)}$$

其中:
- c₂ = Σ_i d_i (新生特征值的θ²系数之和) ≈ 1.44 bits
- b = c₂ - Σ_i d_i log₂ d_i ≈ 1.44 bits (数值上d_i log d_i ≈ 0)
- c < 0 (来自-c₂²/(2 ln 2)主导的负θ⁴贡献)

### 6.2 转换为Cartan系数

将θ替换为Cartan系数 |c| = θ/2 (每个Rxx(θ)边的Cartan向量模):

每个边的Cartan向量: c^(i) = (θ/2, 0, 0), |c^(i)|² = θ²/4。

$$\text{QCMI} = 2c_2 \cdot 4|c|^2 \cdot \log_2\frac{1}{2|c|} + 4b \cdot |c|^2 + 16c \cdot |c|^4 + ...$$

$$= 8c_2 \cdot |c|^2 \cdot \log_2\frac{1}{|c|} + (4b - 8c_2\log_2 2) \cdot |c|^2 + 16c \cdot |c|^4 + ...$$

$$= 8c_2 \cdot |c|^2 \cdot \log_2\frac{1}{|c|} + (4b - 8c_2) \cdot |c|^2 + 16c \cdot |c|^4 + ...$$

### 6.3 与CCQ定理(III)的比较

CCQ定理(III)给出轴**不**对齐时的bonus:
I ≥ η₀ + [p(1-p)/(2 ln 2)]·|c|⁴·(sin²θ_a + sin²θ_b)

当θ_a=θ_b=0 (对齐), bonus=0 ⇒ I ≥ η₀ = 0.180 bits (与|c|无关, 是一个空下界)。

我们的推导给出对齐时:
I ≈ 2.89 θ² log₂(1/θ) + 1.44 θ² = 11.56 |c|² log₂(1/(2|c|)) + 5.76 |c|²

对于小的|c|, 此项远大于η₀=0.180 bits, 说明CCQ的对齐下界η₀在参数化上极其宽松(对单个边非对易时才紧)。

### 6.4 与失配bonus的统一

可以将对齐QCMI和失配bonus统一写为:

$$\boxed{\text{QCMI} = \underbrace{c_2^{\text{aligned}} \cdot \theta^2 \cdot \log\frac{1}{\theta}}_{\text{对齐log项}} + \underbrace{c_0^{\text{aligned}} \cdot \theta^2}_{\text{对齐非log项}} + \underbrace{\frac{p(1-p)}{2\ln 2} \cdot |c|^4 \cdot \sum_v \sin^2\theta_v}_{\text{失配bonus (CCQ定理III)}} + O(\theta^4)}$$

对齐配置下sin²θ_v=0, 失配bonus消失, 但对齐log项和θ²项保留——**这就是CCQ遗漏的贡献。**

## 第7步: 自攻击

### SA-1: log(1/θ)修正在| c|→∞时是否发散? 🔴🔴

**攻击:** 若QCMI ∝ θ² log(1/θ), 则θ→0时log(1/θ)→∞。但QCMI有上限(S(RQ)max = S(R)+S(Q) = 4 bits)。在什么θ范围内log形式成立?

**回应:** log形式的有效性受限于:
1. QCMI << 4 bits (log是在小S展开下推导的)
2. θ足够小使得微扰展开收敛 (θ << π)

对θ = π/512, QCMI = 6×10⁻⁴ << 4 bits。对θ = π/2, QCMI = 1 bit, log形式已不适用(有效指数为负)。

log修正在"中间θ"区域(π/128到π/16, QCMI从0.007到0.2 bits)精确成立。在此区域, QCMI << 上限, log(1/θ)从~3.7到~5.1, 变化显著。

### SA-2: c₂对p=0.7的依赖性 🔴🔴

**攻击:** 以上分析固定p=0.7。c₂如何依赖p(1-p)?

**回应:** 从§2.5的推导, ŜρŜ项中的p(1-p)因子来自Tr[γσ_xγσ_x] = 2p(1-p)。因此c₂ ∝ p(1-p)。

对p=0.7: p(1-p) = 0.21
对p=0.5: p(1-p) = 0.25, c₂应提升19%。

**可验证预测:** 对p=0.5重做θ扫描, QCMI应系统性地高于p=0.7 (对所有θ), 但log(1/θ)的泛函形式保持不变。

### SA-3: 为什么QCMI/θ²发散? 🔴🔴🔴

**攻击:** 若QCMI ∝ θ² log(1/θ), 则QCMI/θ² ∝ log(1/θ) → ∞。但这违反QCMI ≤ 4 bits的上限吗?

**回应:** 不违反。θ→0时θ² log(1/θ) → 0 (因为θ²比log(1/θ)更快地趋于0)。但比值QCMI/θ² ∝ log(1/θ)确实发散。这不矛盾——只是说明在任意小的θ下, 每单位θ²产生的QCMI随θ减小而增大。

物理上: 这是因为von Neumann熵在纯态附近有-S ∼ λ log λ ∼ θ² log(1/θ²)的非解析性。这使QCMI在小θ下比θ²稍微"更大"(多一个log因子), 导致每单位| c|²的QCMI效率发散。**这是对齐轴配置的根本特征, 也是CCQ的"suppression"机制完全错误的原因。**

### SA-4: 四阶BCH项是否可能在对齐轴时产生非平凡贡献? 🔴🔴

**攻击:** commutativity_theorem.md SA-2只分析了三阶BCH项。四阶项在对齐时是否可能产生非Cartan结构?

**回应:** 四阶BCH项涉及嵌套对易子如[H^(1), [H^(2), [H^(3), H^(4)]]]。由于所有H^(i)对易, 所有嵌套对易子为零。四阶项也可以通过对角化吸收进Cartan核心。

真正重要的是: BCH只控制log(U)的结构。QCMI不直接依赖log(U)——它依赖U作用在特定态上产生的密度矩阵变化。这包括U中Ŝ², Ŝ⁴等Cartan项, 它们在QCMI中产生非零贡献。

## §8 证明链总结

```
Rxx(θ) = exp(-iθ/2 σ_x⊗σ_x) — 所有边相同
    ↓
[H^(i), H^(j)] = 0 ∀i,j → BCH无交叉项 ✓
    ↓
    ├─ CCQ从此推出 QCMI=O(θ⁴) ← **错误跳跃**
    │
    └─ 正确的推理:
        U = exp(-iθ/2·Ŝ), Ŝ = Σ_i h_i
            ↓
        ρ_RQ(θ) = ρ_RQ(0) + θ²ρ^(2) + θ⁴ρ^(4) + ...
            ↓
        ρ_RQ(0) 纯态, S=0
        ρ^(2) ≠ 0 → 特征值 λ_i = d_i θ² (新生) + λ_0 = 1-c₂θ²
            ↓
        S = -Σ λ_i log λ_i = c₂θ² - Σ d_iθ² log(d_iθ²) + ...
            ↓
        新生特征值产生 -2c₂ θ² log θ 项
            ↓
        QCMI = A·θ²·log(1/θ) + B·θ² + C·θ⁴ + ...
            ↓
        α_eff = 2 - 1/log(1/θ) + O(1/log²) ≈ 1.81 at θ=π/512
            ↓
        CCQ的 O(θ⁴) 声称被推翻 ∎
```
