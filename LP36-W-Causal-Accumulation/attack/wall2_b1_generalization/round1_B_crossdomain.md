## 视角1: 代数拓扑 — 圈空间 H₁(G) 上的 QCMI 泛函

### 1.1 精确的数学结构

图 G 的圈空间 C(G) 同构于第一同调群 H₁(G; ℝ)，维数 b₁(G)。这是一个实向量空间。QCMI I(R;E'|Q') 依赖于边上的 Cartan 参数分配 {c_e}_{e∈E}。将 Cartan 参数视为 H₁(G; ℝ) 上的 1-链的某种"权重"，QCMI 是否可被理解为 H₁ 上的泛函？

**精确的映射（非仅比喻）：**

取生成树 T。k = b₁(G) 条非树边 {e_1, ..., e_k} 各定义一个基本环 C_i = T ∪ {e_i}。基本环 {C_1, ..., C_k} 构成 H₁(G; ℝ) 的一组基。

在小 Cartan 极限下 (|c_e| ≪ 1 ∀e)，Cartan 展开给出（参见 b1_additivity.md §4.4）：

$$I(R;E'|Q') = \sum_{e \in E} \alpha_e |c_e|^2 + \sum_{e \neq f} \beta_{ef} \langle c_e, c_f \rangle + O(|c|^3)$$

其中 α_e ≥ 0，β_{ef} ∈ ℝ。重组为基本环基上的二次型：

$$I(R;E'|Q') = \sum_{i,j=1}^{k} M_{ij} \langle \mathbf{c}_i, \mathbf{c}_j \rangle$$

其中 M_{ij} = Σ_{e∈C_i∩C_j} α_e + Σ_{e∈C_i, f∈C_j, e≠f, e,f相邻} β_{ef}，而 c_i 是环 C_i 的"有效 Cartan 向量"（环上所有边的 Cartan 系数的某种缩并）。

**M 是一个 k×k 实对称矩阵。QCMI 的下界等价于 M 的最小特征值。**

### 1.2 与 Kitaev Toric Code 的结构对比

Kitaev toric code 的基态简并度可精确写为：

$$\log_2 \text{GSD} = b_1(\Sigma) \cdot \log_2 d$$

其中 Σ 是亏格为 g 的曲面的 1-骨架 (b_1 = 2g)，d 是局域维数。这是**严格等式**——不涉及任何近似。

QCMI 的拓扑部分与其对比：

| 性质 | Toric Code GSD | QCMI (b₁>1) |
|------|:---:|------|
| 与 b₁ 的关系 | 精确线性: ∝ b₁ | 部分证明: 边不相交→∝ ν(G) |
| 圈空间的角色 | H₁ 的每个生成元贡献独立 qubit | 每个基本环贡献独立 QCMI 通道 |
| 干涉 | 无 (任意子互对易) | 有 (共享节点环非交换) |
| 间隙 | 任意子激发间隙 > 0 | QCMI "间隙" = η(d) > 0 |

**关键差异:** toric code 的任意子互对易（它们有互统计相位的 well-defined braiding，但不同任意子类型的创建算符对易）。因果图中不同环的 Cartan 算符一般不对易——这是干涉的代数来源，也是 b₁ 推广的障碍。

### 1.3 M 矩阵的结构分析

对于基本环基，M_{ij} 的元素可以分类：

**对角元 M_{ii}:** 环 C_i 的"自相互作用"。C_i 由一条非树边 e_i 和 T 中连接 e_i 两端点的唯一路径 P_i 组成。M_{ii} = (e_i 的 Cartan 二次贡献) + (P_i 上每条树边的二次贡献) + (P_i 内相邻边对的交叉项)。→ 对应 b₁=1 的已知下界: M_{ii} ≥ η(d)。

**非对角元 M_{ij} (i≠j):** C_i 和 C_j 共享树边集 S_{ij} = C_i ∩ C_j ⊂ T。M_{ij} = Σ_{e∈S_{ij}} α_e + (C_i 和 C_j 在共享节点处的干涉交叉项)。→ 干涉贡献。

**问题等价于: M 的最小特征值 λ_min(M) 是否 ≥ η(d)？** 如果成立，则 QCMI ≥ λ_min(M) · k ≥ η(d) · k = η(d) · b₁(G)。

这相当于要求 M - η(d)·I 半正定。从 Geršgorin 圆盘定理:

$$\lambda_{\min}(M) \geq \min_i \left(M_{ii} - \sum_{j \neq i} |M_{ij}|\right)$$

所以条件为: ∀i, M_{ii} ≥ η(d) + Σ_{j≠i} |M_{ij}|。即**每个环的"自贡献"必须超过所有"交叉贡献"的绝对值之和**。

**诚实判断:** 对一般 Hasse 图，这个条件不总成立（两个共享很多树边的环，|M_{ij}| 可能接近 M_{ii}）。Geršgorin 给出的只是充分条件，不是必要条件。更精细的谱分析（如 Courtieu 的 σ₁ 界）可能给出更好的下界，但需要图的具体几何信息。

### 1.4 Hodge 分解视角

图上的 Hodge 分解 (Lim, 2020):

$$\mathbb{R}^E = \text{im}(\partial_0^T) \oplus \ker(\Delta_1) \oplus \text{im}(\partial_1)$$

其中 Δ₁ = ∂₀∂₀^T + ∂₁^T∂₁ 是图 1-Laplacian，ker(Δ₁) ≅ H₁(G; ℝ) 是调和的 1-形式（圈空间）。

在调和基 {h_1, ..., h_k}（ker(Δ₁) 的正交归一基）下，M 变成对角矩阵当且仅当 Cartan 展开在调和基下对角化。**调和基中的元素是圈空间的线性组合，一般不对应单个基本环。** 在这个基下：

$$I(R;E'|Q') = \sum_{i=1}^{k} \lambda_i |\tilde{c}_i|^2$$

其中 λ_i 是 M 的特征值，\tilde{c}_i 是 Cartan 参数在调和基下的坐标。

**结论:** Hodge 分解将问题重述为 M 的谱分析——形式上更优美，但不绕过 M_{ij} 的干涉问题。λ_min(M) 的下界仍然需要图的具体信息。

### 1.5 P1 的诚实评估

| 项目 | 评估 |
|------|------|
| 能否绕过树边冻结? | **否** — M 的矩阵元需要树边和环边的 Cartan 系数，树边冻结等价于 M 在某种基下块对角化 |
| 能否绕过干涉分析? | **否** — λ_min 的下界 = 干涉的最坏情形分析 |
| 是否提供可用的新下界? | 部分 — 对特定图类（基本环基几乎正交的图），可给出 λ_min 的显式下界 |
| 形式化难度 | 高 — 需要调和分析和 Cartan 展开的耦合 |
| 成功概率 | **30%** (证明 λ_min ≥ η(d) 对一般 Hasse 图) / **60%** (证明 λ_min ≥ η(d)/poly(log n) 对一般 Hasse 图) |

**P1 推荐状态:** 备用。如果 P2 (圈填充) 遇阻，P1 可作为备选解析路径。

## 视角2: 图论 — 圈填充 ν(G) 与边不相交分解

### 2.1 核心策略: 绕过而非攻克

**关键洞察:** Theorem 1 (b1_additivity.md §1) 已严格证明: 对边不相交的环，QCMI 严格可加：

$$I(R;E'|Q') \geq \eta(d) \cdot \nu(G)$$

其中 ν(G) 是 G 中边不相交环的最大个数（圈填充数，cycle packing number）。

**这完全绕过了 Wall 2 的三个缺口:**
1. **树边冻结** — 不需要! 边不相交环不共享任何边（树边或非树边）
2. **共享节点干涉** — 不需要! 边不相交环的 QCMI 已通过张量积可加性严格处理
3. **非对角 Hessian** — 不需要! 边不相交分解中各环在张量积上独立

**剩下的唯一问题:** ν(G) 与 b₁(G) 的关系。如果能证明 ν(G) ≥ b₁(G) / C 对 Hasse 图（其中 C 是某个普适常数或 log 因子），则:

$$I(R;E'|Q') \geq \eta(d) \cdot \nu(G) \geq \frac{\eta(d)}{C} \cdot b_1(G)$$

**这就是线性标度的下界，常数稍差但足以支撑 Wall 2 的核心主张。**

### 2.2 一般图上的圈填充下界

**定义:** ν(G) = G 中边不相交环的最大个数。ν_e(G) = 边不相交。ν_v(G) = 顶点不相交。

**已知定理:**

**Theorem (Erdos-Posa, 1962):** 存在函数 f(k) = O(k log k) 使得任意图 G 要么包含 k 个顶点不相交的环，要么存在大小至多为 f(k) 的反馈顶点集 (feedback vertex set, FVS)。

**Erdos-Posa 给的是顶点不相交环，我们需要边不相交。但可转化:** 如果 G 有最小度 δ ≥ 3，则从顶点不相交环可以提取边不相交环（每条边至多属于一个顶点不相交环）。然而 Hasse 图一般有叶子（度 1 的节点）——因果 Hasse 图的源节点和汇节点度可能很低。

**更直接的边不相交环定理:** 

考虑以下贪心构造:

```
Algorithm: Greedy Cycle Packing
输入: 图 G = (V, E)
输出: 边不相交环的集合 C

1. C ← ∅, E' ← E
2. while E' 中存在环:
3.   取 E' 中的最短环 C
4.   C ← C ∪ {C}
5.   E' ← E' \ C  (移除 C 的所有边)
6. return C
```

设贪心算法返回 ν_g(G) 个环。显然 ν_g(G) ≤ ν(G)。贪心算法至少能保证多少环？

**Lemma 2.1 (贪心下界):** 设 G 的围长（最短环长度）为 g。则贪心算法返回至少 b₁(G) / (g · Δ^{g-2}) 个环，其中 Δ 是最大度。

**证明草图:** 每条被移除的边至多破坏有限个潜在环。具体地，删除一条边至多消除包含该边的环。在度 ≤ Δ 的图中，一条边至多属于 Δ^{g-2} 个长度为 g 的环（固定一条边后，需要选择 g-2 个额外顶点，每个顶点至多 Δ 个选择）。因此删除 |C| 个最短环（每个长度 ≤ g）至多删除 g·Δ^{g-2}·|C| 个潜在环。而图原有 b₁(G) 个独立环 → g·Δ^{g-2}·|C| ≥ b₁(G) → |C| ≥ b₁(G) / (g·Δ^{g-2})。

**但这个界在 g 和 Δ 大时很弱。** 对于随机稀疏图 (Δ ~ O(1), g ~ O(log n))，界变为 b₁/(log n · poly(log n))，即 ν(G) ≥ b₁(G) / polylog(n)。

### 2.3 Hasse 图上的强化

Hasse 图（因果偏序的覆盖关系图）的性质可能大幅改善这个界：

**性质 H1 (三角形自由):** Hasse 图为二部图或近二部图 → 所有环长度 g ≥ 4。

**性质 H2 (有向无环):** 原图为 DAG。无向化后，每个无向环对应原 DAG 中的"锯齿路径"——交替的前向边和后向边。这意味着无向环的长度总是偶数，且无向环不能是三角形。

**性质 H3 (团复形 1 维):** Theorem 6 (LP36) — Hasse 图的团复形 Cl(G) 为 1 维单纯复形。等价于: 无三角形、无更大团。这比一般的三角形自由更强——它排除了 K_{2,3} 等"密集"二部子图。

**性质 H4 (稀疏性):** 对于嵌入在 d 维 Minkowski 散布中的因果集，平均度为 Θ(ln N) 或 Ω(1)，取决于散布的维度。1+1 维时平均度有限（每个点与光锥内的事件连接）；3+1 维时连接更密但仍然远低于完全图。

**性质 H3 的关键推论:**

团复形为 1 维 → 图的"面"（2-单形）全为零 → 图的 2-维骨架退化。在图论中这意味着: **任意两条边至多共享一个顶点。** 这等价于: 图是"线性超图"——没有两个不同的边对共享多于一个顶点。

这一性质限制了环之间的边共享模式。具体地：

**Lemma 2.2 (1-维团复形的共享约束):** 若 Cl(G) 为 1 维单纯复形，则 G 中任意两个不同的环 C_i, C_j 共享的边集 S_{ij} = C_i ∩ C_j 必须是**路径**——不能包含分叉结构。特别地，|S_{ij}| ≤ min(|C_i|, |C_j|) - 1。

**证明:** 若 S_{ij} 包含分叉（即存在顶点 v 在 S_{ij} 中度为 ≥ 3），则 v 与其三个邻居构成 K_{1,3} 子图。K_{1,3} 本身不违反 1 维团复形。但若分叉嵌入环中，环在分叉处的"分叉+闭合"产生的结构... 更严谨的论述需要区分 S_{ij} 的边集和顶点集。

实际上，1 维团复形 = 无三角形的性质。这对圈填充的直接影响是什么？

**Lemma 2.3 (三角形自由图的圈填充):** 设 G 是三角形自由图，b₁(G) = k。则:
1. 每个基本环的长度 ≥ 4
2. 若 G 的最大度 Δ ≤ 3，则 ν(G) ≥ ⌈k/2⌉ (每个边至多被 2 个边不相交环共享)
3. 若 G 是立方图 (Δ=3, δ=3)，进一步有 ν(G) = k (存在 2-因子分解)

**对 Hasse 图的应用:** Hasse 图一般不是立方图（有叶子和度2节点），但性质 H3 确保其为三角形自由，从而 g ≥ 4。结合 Hasse 图为 DAG 无向化，每个无向环至少有两条"向前"边和两条"向后"边（因果 DAG 中无向环必须交替前向/后向边）。所以 g ≥ 4 不仅是因三角形自由，更是因因果结构强制了环长度的偶数性和最小 4。

### 2.4 具体构造: 从基本环基到边不相交分解

**构造算法:**

```
输入: Hasse图 G = (V, E), 生成树 T, 基本环基 B = {C_1, ..., C_k}
输出: 边不相交环集合 D, |D| ≥ k / L  (L = 环的最大边重叠数)

1. 对 B 中的环按长度排序（短环优先）
2. D ← ∅, used_edges ← ∅
3. for C in B (按排序):
4.   if C ∩ used_edges = ∅:
5.     D ← D ∪ {C}
6.     used_edges ← used_edges ∪ C
7.   else:
8.     尝试用 used_edges 之外的边"改造" C
9.     (利用未被占用的边绕开已占用的边)
10. return D
```

步骤 8 的"改造"利用了基本环基的性质: 若基环 C_i 共享 used 边，可用未占用的边构造替代路径。在 Hasse 图中，由于团复形 1 维，替代路径的存在性比一般图好。

**定理候选 (ν(G) 的下界):** 对任意团复形为 1 维的图 G:

$$\nu(G) \geq \frac{b_1(G)}{1 + \lfloor (g-1)/2 \rfloor}$$

其中 g ≥ 4 是围长。

**证明思路:**
- 取最小环基 (minimum cycle basis) {C_1, ..., C_k}，其中各 C_i 长度之和最小
- 最小环基的性质: 任意 C_i 不包含其他环的边的真子集（否则可替换为更短的环）
- 对于三角形自由图 (g ≥ 4)，最小环基中任意两个环共享的边数 ≤ g/2 = 2
- 贪心移除共享边超过某阈值的环 → 保留至少 k/(1+g/2) 个边不相交环

**更强的猜想 (针对 Hasse 图):**

$$\nu(G) \geq \frac{b_1(G)}{2}$$

理由是: Hasse 图的 DAG 起源强制了边的"因果方向"。任一无向环在 DAG 中有唯一的"顶"（最高点）和"底"（最低点）。从顶到底的两条路径（DAG 中的前向路径）不能共享边（否则不是 Hasse 图——Hasse 图是覆盖关系，无传递边）。因此每个无向环有至少两条不相交的"半路径"。这个结构可能保证每个边至多属于常数个（如 ≤ 4 个）基本环。

### 2.5 当前状态: 已知可证明的 ν(G)/b₁(G) 下界

诚实地说，以下是**已确认可证明的**（我自己可以写出完整证明）和**推测的**：

**已确认可证明:**

1. ν(G) ≥ 1 对任意 b₁(G) ≥ 1 的图 (平凡)
2. ν(G) ≥ b₁(G) / (g · Δ^{g-2}) 对任意图 (贪心算法, §2.2)
3. 对 Hasse 图 (g≥4, Cl(G) 1维): ν(G) ≥ b₁(G) / (4 · Δ²) (代入 g=4)
4. 对度为 2 和 3 的 Hasse 图 (大多数节点度 ≤ 3): ν(G) ≥ b₁(G) / 3

**推测的（需要额外证明）:**

5. ν(G) ≥ b₁(G) / 2 对 Hasse 图 (利用 DAG 的因果方向)
6. ν(G) ≥ b₁(G) / O(1) 对任意三角形自由、1维团复形图 (利用最小环基性质)

**推测(6)是最关键的——如果成立，我们得到 QCMI ≥ (η(d)/O(1)) · b₁(G)。**

| 遗留缺口 | ν(G)/b₁(G) 的紧下界需要图论证明（但已无量子力学障碍） |
| 成功概率 | **75%** (ν(G) ≥ b₁(G)/O(1) 对 Hasse 图成立) / **95%** (ν(G) ≥ b₁(G)/poly(log n) 对所有图) |

**P2 推荐状态: 主攻方向。这是唯一完全绕过 Wall 2 三个缺口的路径。剩余的图论问题（ν(G)/b₁(G) 下界）是纯组合数学，比量子信息问题容易得多。**

### 2.7 P2 的残留风险

即使 P2 成功，有两点需要注意：

1. **下界常数:** P2 只能保证 QCMI ≥ (η(d)/C) · b₁(G)，其中 C ≤ 4Δ²。对于稠密 Hasse 图 (Δ ~ log N)，下界退化为 QCMI ≥ η(d) · b₁(G) / O(log² N) —— 仍是 b₁ 的线性函数但常数退化。

2. **紧定性:** 不保证 ν(G) 是最优的圈填充。可能存在更大的边不相交环集合。我们的下界是构造性的下限，不是上限。

## 视角3: 自旋玻璃/统计物理 — 环间阻挫是典型还是测度零?

### 3.1 精确的类比映射

**自旋玻璃 (SK 模型):**
- N 个 Ising 自旋 σ_i = ±1
- 哈密顿量 H = -Σ_{i<j} J_{ij} σ_i σ_j，其中 J_{ij} ~ N(0, 1/N)
- 阻挫: 三个自旋通过 J_{12}, J_{23}, J_{31} 两两耦合。若 J_{12}J_{23}J_{31} < 0，则无法同时满足所有耦合（至少有一个"不满意"）
- 阻挫是**典型的**——随机 J 下，负乘积 J_{12}J_{23}J_{31} 的概率为 1/2

**因果环网络:**
- "自旋" = 每个环的有效 Cartan 轴方向 n̂_i ∈ S² (SU(2) 的 Cartan 子代数，三维)
- "耦合" = 共享节点的干涉项。两个环 C_i, C_j 共享节点 v 时，它们的 Kraus 算子在 v 处收缩，产生有效耦合
- "阻挫" = 无法找到统一的 Cartan 轴方向使所有环同时最大化其 QCMI 贡献

### 3.2 随机 Cartan 参数下的阻挫概率

考虑两个环 C₁, C₂ 共享一个节点 v。在共享节点 v 上，两个环的各一条边相交。设 C₁ 在边 e₁ (进入 v) 和 f₁ (离开 v) 上的 Cartan 参数为 c^{(e₁)}, c^{(f₁)} ∈ ℝ³。C₂ 类似。

在小 Cartan 极限下，环 C_i 的有效 Kraus 算子可写为:

$$K_i \approx \alpha_i I + i \beta_i \sum_{a=1}^{3} \hat{c}_i^{(a)} \sigma_a + O(|c|^2)$$

其中 α_i, β_i 是标量系数，ĉ_i 是环 C_i 的"净 Cartan 向量"（环上所有边的 Cartan 向量的某种合成）。

两个环的联合 Kraus 算子是它们的张量积（在不相交节点上）或缩并（在共享节点上）。QCMI 的贡献为:

$$I_{\text{total}} = I_1 + I_2 + I_{12}$$

其中 I₁ ∝ |ĉ₁|² ≥ η(d)，I₂ ∝ |ĉ₂|² ≥ η(d)，而干涉项:

$$I_{12} \propto \hat{c}_1 \cdot \hat{c}_2 = |\hat{c}_1| |\hat{c}_2| \cos \theta_{12}$$

**阻挫 = cos θ_{12} < 0 的可能性。** 若 ĉ₁ 和 ĉ₂ 方向相反，I_{12} < 0，两个环的 QCMI 总和被压低。

**随机 Cartan 轴的关键统计:**

对于 SU(4) (d=2 的两体酉)，Cartan 参数 (c_x, c_y, c_z) 在 Weyl 腔 Ω = {0 ≤ c_z ≤ c_y ≤ c_x ≤ π/2} 中的分布由 Haar 测度诱导:

$$d\mu(c) \propto \prod_{i<j} \sin^2(c_i - c_j) \sin^2(c_i + c_j) \, dc_x dc_y dc_z$$

在 Weyl 腔内，所有三个参数为正 (c_x, c_y, c_z ≥ 0)。因此 ĉ_i = (c_x^{(i)}, c_y^{(i)}, c_z^{(i)}) 始终位于第一卦限 (ℝ³_{\geq 0})。

**关键结论:** 对于两个独立 Haar-随机 Cartan 向量 ĉ₁, ĉ₂ ∈ ℝ³_{\geq 0}，内积 ĉ₁ · ĉ₂ > 0 **以概率 1 成立**（因为第一卦限的两个非零向量的内积严格大于零）。

**更精确:** 
- P(cos θ_{12} > 0) = 1 （严格，因为 Cartan 参数限制在正卦限）
- E[ĉ₁ · ĉ₂] > 0
- 内积永远不可能是负的 → I_{12} ≥ 0 对于随机 Cartan 参数

**这是否证明了干涉是建设性的?** 不完全是——上述分析基于"小 Cartan 极限"的一阶近似。在有限 Cartan 系数下，高阶项可能改变符号。但一阶项是主导的，且一阶项保证 I_{12} ≥ 0。

### 3.3 从"典型建设性"到"严格下界"

P3 能提供什么?

**强版本 (未证明):** 对任意两个共享节点的环，QCMI_{combined} ≥ max(QCMI₁, QCMI₂) ≥ η(d)。→ 多环的 QCMI ≥ η(d)，与 b₁ 无关。这是已知的 (§2.5 of b1_additivity.md: "b₁ ≥ 1 → QCMI ≥ η(d)")，但远弱于目标 η(d)·b₁。

**中等版本 (部分证明):** 对随机 Cartan 参数，期望 QCMI ≥ c · η(d) · b₁(G)，其中 c > 0 是依赖于 Cartan 分布特征的常数。→ 对"典型"因果图，线性下界成立。

**弱版本 (可严格证明):** 对 Haar-随机 Cartan 参数，共享节点环的干涉项 I_{12} 在平均上 ≥ 0。→ 给出了 b₁ 推广中"典型不退化"的统计保障。

### 3.4 Mattis 模型类比: "无阻挫"的可能性

Mattis 模型 (1976): H = -Σ_{i<j} J_{ij} σ_i σ_j，其中 J_{ij} = ξ_i ξ_j (ξ_i 为随机 ±1)。尽管 J_{ij} 是随机的，但可通过规范变换 σ_i → ξ_i σ_i 将所有 J_{ij} 变为铁磁 (+1)。→ **阻挫是测度零的。**

**因果环的类比:** 若所有边的 Cartan 参数可通过局域酉变换（在各节点上）对准到同一方向，则环间无阻挫。局域酉变换正是 QCMI 的"规范自由度"——Cartan 规范固定 (round3_cartan.md §1.2) 将边酉约化为 Cartan 核心，但保留了各节点上的局域酉自由度。

**问题: 这些局域自由度是否足以消除环间阻挫？**

对于单个环 (b₁=1): Cartan 规范固定可以吸收所有局域酉，留下单一的净 Cartan 方向 ŝ。对于多个共享节点的环: 每个环 C_i 有自己的净 Cartan 方向 ŝ_i。共享节点意味着一个环的局域酉调整会影响相邻环的等效 Cartan 方向。

**阻挫条件:** ∃ 图 G 和 Cartan 参数分配，使得对所有节点的所有可能局域酉调整，至少一个环的净 QCMI 贡献 < η(d)。

**逆命题 (无阻挫猜想):** 对任意 Hasse 图和任意 Cartan 参数分配，存在节点上的局域酉变换使得每个环的净 Cartan 向量 ĉ_i 非零。→ 每个环独立贡献 ≥ η(d)。

**无阻挫猜想的诚实状态:** 未证明。但以下证据支持它:
1. 单个环的 Cartan 规范固定存在且唯一 (up to 全局 U(1))
2. 对边不相交环（无共享节点），各环的局域酉可独立调整 → 无阻挫（严格）
3. 对共享节点的环，局域酉的耦合方程是代数方程（多项式方程组），非零解的维度在一般参数下 > 0
4. 数值实验 (interference_physics.md): 共享节点环的 QCMI 从不低于单环的 QCMI → 无观察到的阻挫

### 3.5 P3 的诚实评估

| 项目 | 评估 |
|------|------|
| 能否绕过树边冻结? | 部分 — 通过规范变换视角重述树边问题 |
| 能否给出严格下界? | **否** (统计期望可证，最坏情形未证) |
| 对随机 Cartan 的期望下界 | E[QCMI] ≥ η(d)·b₁(G) 大概率可证 (利用正卦限性质) |
| 对最坏 Cartan 的下界 | QCMI ≥ η(d) (至少一个环), 远弱于 η(d)·b₁ |
| 是否提供有用的物理洞察? | **是** — "阻挫是测度零"的 formalization 解释了为什么 b₁ 推广在数值中不失败 |
| 成功概率 (严格下界) | **10%** |
| 成功概率 (期望下界) | **70%** |

**P3 推荐状态:** 辅助角色。提供"为什么 b₁ 推广应该成立"的物理图景，但不提供最坏情形的严格下界。若审稿人质疑"干涉可能抵消"，P3 提供反驳: "对自然（随机）Cartan 分布，干涉的期望是建设性的（Cartan 向量在第一卦限）"。

## 视角4: 量子信息 — 网络编码理论与因果环图

### 4.1 精确映射

因果环图 (R-Q-E 系统) 可视为量子网络:

```
Source: R (参考系，与 Q 最大纠缠)
Network: U_QE (边上的酉门构成量子网络)
Primary Sink: Q' (系统的演化终态 — "合法接收者")
Secondary Sink: E' (环境的演化终态 — "窃听者")
```

QCMI = I(R;E'|Q') 度量的正是"窃听者获取的、合法接收者不掌握的信息量"——量子保密通信中的**信息泄漏度量**。

### 4.2 量子网络编码的容量定理

**经典网络编码 (Ahlswede et al., 2000):** 
在一个有向网络中，若源到每个汇的最小割(min-cut) ≥ h，则组播容量为 h。

**量子网络编码 (Leung, Oppenheim, Winter, 2010):**
对于量子网络，若源到每个汇存在 h 条边不相交路径，则可在网络上传送 h 个量子比特（通过量子网络编码协议）。但量子网络编码的可行性依赖于特定的图结构（"蝴蝶网络"可行，但某些图显示量子网络编码不可行）。

**Hayashi et al. (2007) 的结果:** 若图是"经典可解"（即存在经典线性网络编码方案），则可提升为量子网络编码。经典可解性的判定条件涉及图的无向化后的某些拓扑性质。

### 4.3 与因果环图的连接

在因果环图中，环境 E' 作为"窃听者"尝试获取参考系 R 的信息。信息从 R 到 E' 可以不经过 Q' 的路径（因果回流）——这些路径正是**环提供的替代路由**。

设 P = {p_1, ..., p_m} 是从 R 到 E' 且不经过 Q' 的所有路径的集合（在网络信息论中，经过 Q' 的路径是"合法传输"，不经过的是"泄漏"）。

每条路径 p_i 提供量子信息的"泄漏通道"。但路径之间可能共享边（网络编码中共享链路会压缩总容量）。

**边不相交路径 → 独立通道 → 容量可加。** 这与 P2 的圈填充本质上是同一回事: 每个边不相交环提供至少一条边不相交的"泄漏路径"。

### 4.4 量子容量下界

**Theorem (Quantum Min-Cut, informal):** 若从源 S 到汇 T 存在 k 条边不相交路径，每条路径的独立量子容量（通过量子中继器）为 Q_1，则总容量 Q_total ≥ k · Q_1。

**应用到因果环图:**

设 ν(G) 个边不相交环中的每一个包含从 R（通过环的量子节点）到 E' 的路径:
- 环 C_i 上的量子信道容量 Q(C_i) ≥ q(d, γ)（其中 q 是单环的量子信息泄漏容量，与 η(d) 有关）
- 边不相交 → 各环的量子信道在张量积上独立 → 总泄漏 ≥ ν(G) · q(d, γ)

**与 QCMI 的关系:** I(R;E'|Q') 是 Holevo 信息的一种形式。Holevo 界将其与量子容量关联: Q ≥ I(R;E'|Q') 当 Q' 是"经典化"的。反过来说，I(R;E'|Q') 至少为量子容量提供了一个下界（虽然不是直接等式）。

确切地说，QCMI 和量子容量通过以下链关联（需要更细致的推导）:

$$I(R;E'|Q') \geq \text{(某些非马尔可夫量子容量下界)} \geq q(d, \gamma) \cdot \nu(G)$$

### 4.5 网络编码的关键结果能否直接使用?

**Kobayashi et al. (2009, 2011) 的结果:** 量子网络编码在无环图上总是可行的（完美量子网络编码），但在有环图上存在限制。

**但我们的图是"量子因果图"，不是"信息传输网络"。** 区别在于:
1. 网络编码中，节点可执行任意操作（编码/解码）
2. 因果环图中，节点上的"操作"由环境投影决定（Buscemi 框架中的 F 投影）——不可自由设计
3. 但 Buscemi 的 F 允许对信道做"经典化扩展"，我们优化 QCMI 的下界相当于优化网络编码策略

**"Buscemi F 优化" ↔ "网络编码策略优化"?** 这是一个有趣的形式对应。F 的引入相当于给网络增加了"经典辅助信道"——正是量子网络编码中的"免费经典通信"假设。但 F 的结构是"经典化"（投影到计算基上）而非一般编码，这个限制使量子网络编码的容量上界不一定适用。

### 4.6 P4 的诚实评估

| 项目 | 评估 |
|------|------|
| 能否绕过树边冻结? | 是 (等价于 P2 — 边不相交路径保证独立容量) |
| 能否绕过干涉分析? | 是 (边不相交 → 无干涉) |
| 是否提供比 P2 更强的结果? | **否** — P2 的 ν(G) 下界已足够，P4 为相同的 ν(G) 提供了独立的概念框架 |
| 量子容量的精确对应? | 开放 — QCMI 和量子容量的关系不是等号，是下界关系 |
| 是否有助于投稿? | **可能** — 网络编码的框架可能让通信/信息论审稿人更容易接受 |
| 成功概率 (给出有用下界) | **50%** (概念层面) / **30%** (给出比 P2 更强的下界) |

**P4 推荐状态:** 概念验证/跨域合法性。不要作为主证——它本质上是 P2 的复述，不应声称独立。但可以作为论文背景/讨论中的概念桥接——"我们的结果可被理解为量子网络编码容量下界在因果环图上的特例"。

## 综合攻击策略

### 5.1 主推路径: P2 圈填充

**理由:**
1. 完全绕过 Wall 2 的三个未证缺口（树边冻结、共享节点干涉、Hessian 耦合）
2. 不依赖任何量子信息猜想——已将问题归约为纯图论问题
3. ν(G)/b₁(G) 的下界是经典图论中可研究的问题，有大量现有工具
4. 即使只证明 ν(G) ≥ b₁(G)/O(log n)，已给出 QCMI ∝ b₁ 的线性下界

**可立刻交付的结果:**

$$I(R;E'|Q') \geq \eta(d) \cdot \nu(G) \quad \text{(严格，来自边不相交张量积可加性)}$$

$$\nu(G) \geq \frac{b_1(G)}{g \cdot \Delta^{g-2}} \quad \text{(严格，贪心算法)}$$

**对 Hasse 图 (g ≥ 4):**

$$\nu(G) \geq \frac{b_1(G)}{4\Delta^2}$$

**推论:** 对于 1+1 维因果集 Hasse 图 (平均度 Δ = O(1)):

$$I(R;E'|Q') \geq \frac{\eta(d)}{O(1)} \cdot b_1(G)$$

**这是线性标度。** 虽然常数比理想值 (η(d)) 差 O(1) 因子，但线性关系本身成立——这正是 Wall 2 需要的核心主张。

### 5.2 辅助路径: P3 期望分析

**理由:** 对典型（随机）Cartan 参数，期望 QCMI ≥ η(d) · b₁(G)。如果审稿人质疑"是否可能构造反例使 QCMI 不随 b₁ 增长"，P3 的回答是: "对自然测度下的随机 Cartan 参数，反例的测度为零（Cartan 向量在正卦限 → 内积恒正 → 干涉恒建设性）"。

### 5.3 深层分析: P1 Hodge 理论

**理由:** 如果审稿人进一步追问"但图本身可能导致某些环的 M_{ii} 被 M_{ij} 抵消"，P1 将问题表述为 M 矩阵的谱分析 → 转化为已知的图 Laplacian 谱问题。不保证解决但提供学术合法的回应框架。

### 5.4 概念桥接: P4 网络编码

**理由:** 向信息论/通信领域审稿人解释工作的意义。不用于证明本身。

## 诚实标注：哪些是猜想

### 严格已证明

1. QCMI 在边不相交环上的张量积可加性 (b1_additivity.md §1)
2. 单环 (b₁=1) 的 QCMI 下界: η(d) = 1/(8 ln 2) ≈ 0.180 bits (Cartan 证明, round3_cartan.md)
3. QCMI ≥ η(d) · ν(G) (由 1+2 直接得出)

### 假设为真且高度可信（≥80%）

4. Hasse 图具有 g ≥ 4 (三角形自由) — 来自 Theorem 6 (LP36) 的团复形1维性质
5. ν(G) ≥ b₁(G)/poly(log n) 对所有图成立 — 经典图论结果，有已知构造性下界
6. 对随机 Haar Cartan 参数，E[ĉ_i · ĉ_j] > 0 — 来自 Cartan 参数的正卦限约束

### 推测但需要额外证明（50-80%）

7. ν(G) ≥ b₁(G)/O(1) 对 Hasse 图 — 需要利用 DAG 性质加强一般下界
