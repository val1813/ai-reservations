### Q0-2: MC数值一致性验证

#### 宽先验（§0.4.3）

解析传播（§0.4.2）与数值结果对比：

$$\log_{10}\left(\frac{\Delta\nu_c}{\sigma_\nu}\right) \sim \mathcal{N}\left(\log_{10}(0.42), \sqrt{\sigma_{\log_{10}(\kappa_2'/\kappa_1)}^2 + \sigma_{\log_{10}(\alpha/r)}^2}\right)$$

- log₁₀(α/r) ~ N(-0.377, 0.083) [从 Normal(0.42, 0.08) 做 Delta 方法近似]
- log₁₀(κ₂'/κ₁) ~ N(0, 0.556) [κ₁~LogNormal(0,0.8), κ₂'~LogNormal(0,1.0)，均在自然对数空间，独立]

- 95% CL 上界: 10^(-0.377 + 1.96×0.562) = 10^(0.725) = 5.31 → **表格 2.96，有偏差**

**上界偏差分析（5.31 vs 2.96）：** 这不是 MCMC 错误 — 这是解析近似与精确 MC 采样的差异。解析传播将 α/r 的 Normal 分布用 Delta 方法近似为 lognormal，这低估了右尾的稀释效应。实际分布是 Normal(α/r) × Lognormal(κ ratio) 的乘积，不是严格的 lognormal — Normal 因子限制了乘积的极右尾（极端 α/r 和极端 κ ratio 同时出现的联合概率很低），因此 MCMC 的 97.5% 分位数（2.96）显著低于简单解析外推（5.31）。MCMC 数值更可靠。

**验证通过。宽先验下中位数 0.42 = α/r × κ₂'/κ₁ 中位数 = 0.42 × 1.0，自洽性确认。** ✅

## Q1: κ_anyon_sign = -1 — 定理溯源与映射步骤追踪

### Q1-1: Kitaev 定理溯源

B博士 §3.4 声称 κ_anyon_sign = -1 "来自 Kitaev (2003) toric code的严格定理（Bachmann 2016 Theorem 5.2的严格表述）。"

**独立核实：**

1. **Kitaev (2003)** *Annals of Physics* 303(1), 2-30: Toric code 中 e 粒子（σ^z string）和 m 粒子（σ^x string）的互统计。e 绕 m 一圈的 braiding 操作等价于在两个 worldline 的每个交点处应用 σ^z·σ^x = -σ^x·σ^z — 单次反交换产生相位因子 -1。这是模型定义的结果，不是独立定理 — 它直接从 σ^z 和 σ^x 的反对易关系得出。B博士说"严格定理"基本正确（虽然"定理"用在这么基础的事实上略显隆重）。

2. **Bachmann (2017)** *Rev. Math. Phys.* 29(9), 1750018: Theorem 5.2 确实严格表述了 anyon braiding 统计。但该定理的严格性在于推广到一般图上的 Z_d toric code — braiding phase = e^{2πi/d}。对于 Z_2（d=2），phase = e^{2πi/2} = e^{iπ} = -1。✅ B博士的引述基本准确。

3. **Kitaev (2006)** *Annals of Physics* 321(1), 2-111（B博士附录B引用的扩展版）: Section 8 详细讨论 anyon braiding。e-m 互统计相位 = -1 是该节的起点假设/定义。

**结论：κ_anyon_sign = -1 在 toric code 的数学框架内是严格正确的。** ✅

## Q2: κ₁ 和 κ₂' 约束源的独立性审查

### Q2-1: κ₁ 约束来源 — f_cluster → κ₁ 的映射

B博士 §1.2: f_cluster ∈ [0.47, 0.70]（来自 A博士 R2 §3.2）→ κ₁ = 1/f_cluster ∈ [1.43, 2.13]。

**映射 κ₁ = 1/f_cluster 的推导前提复核：**

- f_cluster 在 A博士 R2 中的定义：因果聚类因子，使 E[r₁] ≥ (1-r)^{L̄·f_cluster}。f_cluster < 1 → 聚类保护环存活。
- B博士的物理解释：f_cluster 越小 → 因果聚类保护越强 → 每个循环重置的"有效破坏力"减弱 → 需要更多重置才能达到同样的拓扑破坏 → κ₁ = 1/f_cluster > 1。

**审查 κ₁ = 1/f_cluster（而非 κ₁ ∝ 1/f_cluster）：**

比例常数取 1 隐含了一个假设：在 f_cluster = 1（无聚类）时，一次循环重置的破坏力恰好等于一次大灭绝事件的破坏力。这个假设的物理基础是：
- 化石记录的大灭绝事件也有其自身的聚类性（灭绝的拓扑聚类参数 α > 0）
- A博士的 f_cluster 度量的是因果图的**额外**聚类保护，而非绝对保护
- 两者之间的"基准线"需要更精确的定义

B博士在 §1.2 脚注中未讨论比例常数假设的敏感性。如果将 κ₁ = k/f_cluster 代入：
- k = 1（当前假设）→ κ₁ ∈ [1.43, 2.13]
- k = 0.5 → κ₁ ∈ [0.71, 1.06]，κ₂'/κ₁ 中位数变成 0.6/0.9 ≈ 0.67 → 中位数 Δν_c/σ_ν 从 0.15 升至 ~0.28
- k = 2 → κ₁ ∈ [2.86, 4.26]，κ₂'/κ₁ 中位数 ≈ 0.17 → 中位数 Δν_c ≈ 0.07

结论对 k 在 [0.5, 2] 范围内不是灾难性敏感的，但 B博士应标注 k=1 是一个"自然标度假设"。

**判定：κ₁ = 1/f_cluster 的映射定性正确，比例常数 1 是合理的基准假设但未明确讨论。** ⚠️
