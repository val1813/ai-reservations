### Q5问题详情

**❌ Q5-1: 定理3下界在r→0极限下的上溢 (§3.2, L385)**

公式: E[r_1] ≥ (1-r)^L̄_typ · (1 + δ_clustering)

当 r → 0 (无节点删除)时：
- (1-r)^L̄_typ → 1
- E[r_1] ≥ 1 + δ_clustering, 其中 δ_clustering > 0
- 这意味着 E[r_1] > 1

但根据定义(定义2, L285): r_i(n) = b_i(G_{n+1}^init)/b_i(G_n^final) ∈ [0, 1]。如果原图所有环都存活(无节点删除)，r₁ = 1，不能超过1。

**问题根源:** (1+δ_clustering)增强因子在r→0时应趋近于1/（1-r)^L̄_typ的饱和修正，而非一个独立的乘法因子。更正确的形式可能是：

```
E[r_1] ≥ (1-r)^{L̄_typ · (1 - δ')}   其中 δ' ∈ (0,1) 编码因果聚类对有效环长的缩减
```

或者增加一个显式的上界饱和：
```
E[r_1] ≥ min(1, (1-r)^{L̄_typ} · (1 + δ_clustering))
```

**修正建议:** 将公式改写为 E[r_1] ≥ (1-r)^{L̄_typ · f_cluster}，其中 f_cluster ∈ (0,1] 是因果聚类因子（f_cluster < 1对应增强存活，因为有效环长缩减），并且 f_cluster → 1 当 r → 0（无增强时退化到独立假设）。

**严重性:** 公式在r→0边缘情况下违反定义域。在r ≫ 0的实际物理情况下（重置确实发生），1+δ项可能仍然< 1/(1-r)^L̄_typ，因此中心结果（b₁存活率被因果聚类增强）不受影响。但公式需要修正以在r→0边界时保持自洽。

**等级:** ❌ 阻断（公式在边缘情况下违反自身定义，需修正）

**❌ Q5-2: 稳态解符号错误 (§7.3, L643)**

原文: 
```
若 g(b₁) = g_0 + g_1·b₁ 且 δ ≡ 1 - r_eff < g_0，则：
b₁* = (g_0 - δ)/g_1 > 0
```

**详细代数验算:**

递推方程为 db₁/dn = g(b₁)·b₁ - δ·b₁，其中 δ = 1 - r_eff。

稳态条件: db₁/dn = 0 ⟹ g(b₁*)·b₁* = δ·b₁*

对于 b₁* ≠ 0: g(b₁*) = δ

代入 g(b₁) = g₀ + g₁·b₁:

g₀ + g₁·b₁* = δ

⟹ b₁* = (δ - g₀) / g₁

而文档写的是 b₁* = (g₀ - δ) / g₁。**符号相反。**

**验证:** 代入原文的 b₁* = (g₀ - δ)/g₁ 到稳态条件:
- g(b₁*) = g₀ + g₁·(g₀ - δ)/g₁ = 2g₀ - δ
- 稳态要求 g(b₁*) = δ → 2g₀ - δ = δ → g₀ = δ
- 但原文声称条件为 δ < g₀ — 矛盾。

代入修正后的 b₁* = (δ - g₀)/g₁:
- g(b₁*) = g₀ + g₁·(δ - g₀)/g₁ = g₀ + δ - g₀ = δ ✓
- 稳态b₁* > 0 需要 (δ - g₀)/g₁ > 0
- 若 g₁ > 0: 需要 δ > g₀，即衰减率 > 基线生长率
- **这意味着:** 当衰减超过基线生长时，b₁仍有正稳态（由超线性生长补偿），而非原文声称的"衰减<生长时才有正稳态"

**连锁影响:** §7.4的稳定性分析也受影响。原文声称:
```
d/db₁[...]_{b₁*} = g₁·b₁* > 0  → 稳态不稳定
```

完整导数展开（使用修正后的b₁* = (δ - g₀)/g₁）:
d/db₁ [g₀·b₁ + g₁·b₁² - δ·b₁] = g₀ + 2g₁·b₁ - δ

在b₁* = (δ - g₀)/g₁处:
= g₀ + 2g₁·(δ - g₀)/g₁ - δ
= g₀ + 2δ - 2g₀ - δ
= δ - g₀

稳定性判定:
- 若 δ > g₀ (b₁* > 0): 导数 = δ - g₀ > 0 → 不稳定（与原文定性结论一致）
- 若 δ < g₀: b₁* < 0 (非物理) → 不存在物理稳态，b₁持续增长

原文的不稳定性结论（定性）恰好正确，但符号错误导致了b₁*存在的**物理条件反转**: 原文说g₀ > δ时存在正稳态，而正确推导显示δ > g₀时才存在正稳态。这是一个实质性的物理差异。

**修正建议:**
- L643: b₁* = (g₀ - δ)/g₁ → b₁* = (δ - g₀)/g₁
- 条件 δ < g₀ → δ > g₀ (当g₁ > 0时)
- L655: d/db₁[...]_{b₁*} = g₁·b₁* → = δ - g₀
- L657-659: 物理解释需修正——"衰减超过基线生长时才有物理正稳态"而非"生长超过衰减时"

**等级:** ❌ 阻断（符号错误，影响稳态存在条件这一核心推论）

---

**⚠️ Q5-3: ε_n公式中γ的数值行为 (§3.3)**

进行显式数值验算:

给定 γ ∈ (0,1], ε₀ = 10⁻⁵:
- b₁^(n) = 10, b₁^ref = 100: ε_n = 10⁻⁵ × (0.1)^γ
  - γ=1: ε_n = 10⁻⁶ 
  - γ=0.5: ε_n = 10⁻⁵ × 0.316 ≈ 3.2×10⁻⁶
  - γ=0.1: ε_n = 10⁻⁵ × 0.794 ≈ 7.9×10⁻⁶
- b₁^(n) = 100, b₁^ref = 10: ε_n = 10⁻⁵ × 10^γ
  - γ=1: ε_n = 10⁻⁴
  - γ=0.5: ε_n ≈ 3.2×10⁻⁵
  - γ=0.1: ε_n ≈ 1.3×10⁻⁵

当 γ → 0+ 时，ε_n → ε₀(常数)，b₁的任何变化都不影响ε_n → 理论丧失预言能力。
当 γ = 1 时，ε_n的变化幅度最大(10倍)，但仍然在一个数量级内。

**结论:** 公式代数正确，但γ是纯自由参数，其不确定性使预言1-3的数值范围(15-40%抑制等)无法从理论推导——这些范围是"估读"而非计算。

**等级:** ⚠️ 警告（公式代数正确但参数缺失）

### 阻断项清单 (必须修正才能进入下一轮)

#### ❌ 阻断1: 定理3下界公式在r→0时违反定义域 (Q5-1, §3.2 L385)

**错误:** E[r_1] ≥ (1-r)^L̄_typ · (1+δ_clustering) 在r→0时给出E[r_1] > 1，但r_1 ∈ [0,1]按定义。

**修正建议:**
```
E[r_1] ≥ (1-r)^{L̄_typ · f_cluster}
```
其中 f_cluster ∈ (0,1] 为因果聚类因子。f_cluster < 1 对应环上节点联合存活的正相关性缩短了"有效环长"。当 r → 0 时，f_cluster → 1，退化到独立假设极限。

或等价地，显式增加上界饱和:
```
E[r_1] = min(1, (1-r)^{L̄_typ · f_cluster})
```

#### ❌ 阻断2: 稳态解符号错误 (Q5-2, §7.3 L643)

**错误:** b₁* = (g₀-δ)/g₁ 应为 b₁* = (δ-g₀)/g₁

**修正内容:**
- L643: `b₁* = (g_0 - δ)/g_1` → `b₁* = (δ - g_0)/g_1`
- L643条件: `δ < g_0` → `δ > g_0` (当g₁ > 0时, 对应正稳态)

- L657-659的物理解释需修正：正稳态存在当且仅当衰减率超过基线生长率(δ > g₀)，由超线性生长(g₁>0)补偿
