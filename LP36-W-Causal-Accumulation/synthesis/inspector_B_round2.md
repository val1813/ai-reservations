## Q2. 符号/方向校对

### Q2-1: PD 存活比例公式在 λ>μ 和 λ<μ 下的行为

**修正后的 PD(T) = (e^{(λ-μ)T} - 1)/(λ-μ)：**

- **λ > μ（超临界）：** λ-μ > 0 → e^{(λ-μ)T} → ∞ → PD(T) → ∞。随着时间推移，累积 PD 指数级增长。✅ **正确。** 这对应"螺旋上升"。

- **λ < μ（亚临界）：** λ-μ < 0 → e^{(λ-μ)T} → 0 → PD(T) → -1/(λ-μ) = 1/(μ-λ)（有限正常数）。✅ **正确。** 即使死亡主导，已灭绝谱系在存活期间仍贡献有限的分支长度。

- **λ = μ（临界）：** PD(T) = T（L'Hopital 极限）。✅ **正确。**

**渐近行为与物理直觉对照：**
- R1 公式 `(1-e^{-(λ-μ)T})/(λ-μ)` 在 λ<μ 时发散至 ∞ → ❌
- R2 公式 `(e^{(λ-μ)T}-1)/(λ-μ)` 在 λ<μ 时趋于有限常数 → ✅
- R1 文字描述"PD 指数衰减到零" → 来自条件期望，非无条件期望
- R2 注明区分无条件 vs 条件期望 → ✅ 诚实的限定

**判定：** ✅ 通过。R1 的 BLOCK-2（公式行为与文字描述矛盾）已修复。符号修正正确（e^{(λ-μ)T} 而非 e^{-(λ-μ)T}）。

### Q2-2: Δν_c/σ_ν 的 Monte Carlo 传播方向

**这是本轮最严重的计算级问题。**

§1.3.1 声称：

$$\frac{\Delta\nu_c}{\sigma_\nu} = \frac{\kappa_2'}{\kappa_1} \cdot \frac{r}{\alpha}$$

其中 r/α ≈ 2.38（来自 Vamosi & Wilson 2008 的 α/r ≈ 0.42 取倒数）。

然后用 Monte Carlo 计算（§1.3.2），得出：
- 中位数：**0.56**
- 95% CL：[0.06, 4.92]

**数值一致性检查：**

如果公式为 Δν_c/σ_ν = (κ₂'/κ₁) · (r/α)，且 κ₂'/κ₁ 具有中位数 1.0（两个 LogNormal(μ=0, ...) 之比），r/α 的中位数为 2.38（Normal 分布均值=中位数），则乘积中位数应 ≈ 2.38。**但 MC 给出 0.56。偏差因子约 4.25。**

如果公式实为 Δν_c/σ_ν = (κ₂'/κ₁) · (α/r)，α/r ≈ 0.42，则乘积中位数 ≈ 0.42（与 0.56 接近但不等）。

**推导追溯：**

链式推导：
1. τ_PD = α/r（化石衰减时间，§1.1.2）
2. τ_b₁ = κ₁ · τ_PD = κ₁ · α/r（因果图衰减时间，§1.1.2）
3. Δν_c/σ_ν = κ₂' / τ_b₁ = κ₂' / (κ₁ · α/r)（§1.2.4）

由此：Δν_c/σ_ν = (κ₂'/κ₁) · (r/α)。✅ 推导逻辑链一致。

但 MC 结果与 (κ₂'/κ₁) · (r/α) 式中位数 2.38 偏离约 4 倍，与 (κ₂'/κ₁) · (α/r) 式中位数 0.42 偏离约 33%。

**可能原因：**
1. §1.3.1 的公式 Δν_c/σ_ν = (κ₂'/κ₁) · (r/α) 有误（应为 (κ₂'/κ₁) · (α/r) 或其他形式）
2. MC 实现中使用的分布参数与文中宣称的不同
3. 推导链中的 τ_PD 到 r/α 映射方向有误

**0.56 > 0.42（R1 数值）的方向：** 如果修正为引入 κ₁, κ₂' 不确定性后，中位数从 0.42 升至 0.56，方向是合理的（LogNormal 右偏使乘积中位数 > 简单乘积）。但不解决公式一致性问题。

**不确定性是否稀释了声张？** [0.06, 4.92] 跨两个数量级——**是的，严重稀释。** 在 95% 置信度下，Δν_c/σ_ν 可能取值从 0.06（接近零——W 信号不可检测）到 4.92（远超任何已知 CMB Betti 特征）。这个范围太宽以至于**任何 Planck 测量值都能"符合"预测**——这使该预测在实际上不可证伪。B 博士称这是"预测的诚实化"而非"弱化"，但诚实化如果导致不可证伪，等于放弃了科学检验力。

**判定：** ❌ **阻断** — §1.3.1 的公式 Δν_c/σ_ν = (κ₂'/κ₁) · (r/α) 与 Monte Carlo 结果（中位数 0.56）在数值上不一致。需要：①核实公式推导；②如果公式正确，修正 MC；③如果 MC 正确，修正公式；④无论哪种情况，解释中位数从 0.42 到目标值的移动。同时 ⚠️ 警告 — 95% CL [0.06, 4.92] 过宽，使该预测实际上不可证伪。

### Q2-3: Toric code 的 b₁ → g 映射在一般因果图上的有效性

B 博士声称：
- 对于可定向曲面：b₁ = 2g → dim(S_G) = d^{2g}
- 将因果图团复形类比为"亏格 g 的曲面"

**标准数学事实核对：**
- 对于闭可定向曲面 Σ_g：b₁ = 2g。✅ 正确。
- 对于一般单纯复形 K：b₁ ≠ 2g（因为 g 未定义；Euler 示性数 χ = b₀ - b₁ + b₂ - ... 不遵循 χ = 2 - 2g）。

因果图的团复形 Cl(G) 是一个**一般单纯复形**，不一定是曲面三角剖分。一般单纯复形的"亏格"需要定义为最小可嵌入曲面的亏格（图亏格），它与 b₁ 的关系是：
$$g_{\text{graph}} \geq \lceil (b_1 - n + 1)/2 \rceil$$
而非 g = b₁/2。

**因此：** dim(S_G) = d^{b₁} 在一般图上成立（Padmanabhan et al. 2020 在特定条件下证明了这一点），但**翻译回亏格语言（g = b₁/2）在一般因果图团复形上不一定成立**。B 博士在 §4.1 的自我攻击中部分承认了这一点（"因果图不需要嵌入曲面"），但 §2 和 §3 的核心声张仍依赖 `g = b₁/2` 映射。

**判定：** ⚠️ 警告。`g = b₁/2` 仅在因果图团复形同伦等价于闭可定向曲面时成立——这是未证明的强假设。

## Q3. 循环论证校对

### Q3-1: Toric code "独立验证" A 博士的 β₁ 结论

B 博士 §2.1 声称：

> "这不是'类比'。两个系统具有精确的数学结构同构：两者都声称某个拓扑不变量（b₁）在某种扰动（重置/局域算符）下存活。"

> "凝聚态物理的整个拓扑序框架——通过完全不同的物理和数学路径——抵达了完全相同的结论。"

**分析：**

1. **Toric code 为何 b₁ 特殊：** Toric code 的 GSD = d^{b₁} 来自该模型的具体构造——顶点算符 A_v 约束了 b₀（所有顶点在基态中），面算符 B_f 约束了 b₂（所有面在基态中），剩余自由度恰为 b₁ 个。这不是"b₁ 天然特殊"的证明，而是**特定 Hamiltonian 构造的结果**。

2. **A 博士为何 b₁ 特殊：** A 博士的方案 C 重置算子 → b₀ 因碎片化不可靠，b₂ 在高密度下平凡，b₁ 存活。这是**特定重置机制**的结果。

3. **两者是否"独立"？** 是的——物理系统不同（凝聚态格点模型 vs 因果图演化），数学路径不同（稳定子形式 vs 图同调+重置算子）。但两者都**选择性地关注 b₁** 而忽略其他 Betti 数——这种"选择性"在 toric code 中来自构造，在 DGF 中来自重置动力学。这不是"不同路径抵达同一结论"，而是"两个不同系统各自关注了 b₁"。

4. **是否存在循环？** 不严格循环（B 博士没有用 A 博士的结论推导 toric code 结果）。但存在**确认偏差**：B 博士从 toric code 工具箱中提取了"b₁ 是特殊不变量"这一事实，而忽略了同样存在于拓扑序文献中的其他可能（如 fracton 相中 b₂ 可以是拓扑保护的、或 bilayer 系统中高维拓扑序）。

**判定：** ⚠️ 警告。Toric code 类比不是循环论证，但"独立验证"的声张过度。Toric code 和 DGF 分别因各自的特殊构造/机制而关注 b₁——它们的一致性是"巧合"而非"独立验证"。声张应降级为："Toric code 提供了 b₁ 在另一物理系统中扮演核心角色的先例——但两者机制不同。"

## Q4. 量级鸿沟标记

### Q4-1: Toric code（2D 格点模型）→ 因果图（3D+ DAG）

**鸿沟性质：**

| Toric Code | DGF 因果图 |
|:---|:---|
| 定义域：2D 闭可定向曲面上的格点 | 定义域：d+1 维时空中嵌入的有向无环图 |
| 同调维数：最多 b₀, b₁, b₂ | 同调维数：b₀, b₁, b₂, ..., b_d（团复形维数可达 d+1） |
| 基态简并度来源：1-循环（绕洞的 Wilson 环） | "W 状态空间维数"来源：因果环（1-循环）的存活/不存活 |
| 拓扑保护机制：局域算符矩阵元在基态间为零 | 保护机制：因果聚类+重置的选择性保留 |

**维度差造成的量级问题：**

在 2D 曲面上的 toric code，b₂ = 1（曲面本身是一个 2-循环），GSD 不依赖 b₂。在 3D 团复形（对应 3+1 维因果图）中，可能存在非平凡的 b₂（空腔）甚至 b₃。如果推广 toric code 到 3D（如 3D gauge theory），GSD 不仅依赖 b₁，还依赖 b₂：
$$\dim(\mathcal{S}_G) = d^{b_1} \cdot d^{b_2}$$

**B 博士未讨论 b₂ 在 3D 推广中的角色。** 如果因果图团复形有非平凡 b₂（围绕因果"空腔"的 2-循环），那么 W 状态空间维数还应包含 d^{b₂} 项——这会直接影响 g_eff 的预测。

B 博士在 §4.1 中对此的回应（"因果图本身是一个抽象图...b₁ 来自它的组合结构"）回避了关键问题：**toric code 是格点模型，定义在曲面上**——两者 Hilbert 空间结构根本不同。将"曲面上的稳定子码"推广到"抽象图上的拓扑记忆"需要：①定义图上的局部 Hilbert 空间（每个节点？每条边？）；②定义类似 A_v, B_f 的"因果稳定子"；③证明基态简并度仍 = d^{b₁}。

Padmanabhan et al. (2020) 在特定条件下证明了 GSD scales with b₁ on general graphs——但那些条件（frustration-free Hamiltonian, 特定图结构）不一定被因果图满足。

**判定：** ⚠️ 警告。2D→3D+ 维度鸿沟未桥接。Toric code 结果是 2D 拓扑序的定理——外推到更高维的因果图需要明确的推广论证（目前缺失）。

### Q4-2: dim(W) = d^{b₁} 的物理含义

如果 b₁ ~ 10-100（A 博士估计）且 d = 2（二进制因果"电荷"）：
$$\dim(\mathcal{W}) = 2^{b_1} \in [2^{10}, 2^{100}] = [10^3, 10^{30}]$$

**物理含义模糊之处：**

1. **Hilbert 空间 vs 状态空间：** Toric code 的 dim(S_G) 是量子基态简并度（Hilbert 空间维数）。DGF 的 dim(W) 是什么？W 是经典的"信息存储"还是量子的？如果是经典的，{0,1}^{b₁} 是一个有 2^{b₁} 个元素的集合——这是古典信息容量，非 Hilbert 空间维数。

2. **10³⁰ 个状态的物理意义：** 如果 W 可以区分 10³⁰ 个不同的因果历史，这远远超过了可观测宇宙中的物理可实现状态数（~10¹²⁰ 的 Bekenstein 界限）。不必然是问题——信息可以是"潜在地"存储的拓扑自由度——但需要讨论。

3. **观测后果：** 如果 dim(W) 巨大，W 的"强度"（CMB 中的拓扑印记）应随 b₁ 快速增长。但 g_eff ~ O(1) 的预测意味着只有 ~1-2 个"大尺度因果环"投射到 CMB——与 b₁ ~ 10-100 形成反差。这意味着**绝大多数因果环在 CMB 中是"暗"的（无观测印记）**。这是需要解释的。

**判定：** ⚠️ 警告。dim(W) = d^{b₁} 公式给出了巨大数值但无物理解释。从 b₁ ~ 10-100 到 g_eff ~ 1 的缩减（"只有大尺度环投射"）是一个 ad hoc 假设——需要定量论证。

### Q4-3: g_eff = 1.0 ± 0.5 的量级

g_eff ≈ 1 意味着 CMB 的 β₁ 在 ν≈0 处比 ΛCDM 预期高出约一倍。

**与已知 CMB 异常的对比：**
- Pranav et al. (2019): β₀ 在 3-7° 尺度上有 3-4σ 异常（A 博士引用的）。他们报告的主要是 β₀（连通分量）的异常，β₁ 的数据没有明确给出。

g_eff ≈ 1（100% 增强）是一个非常大的信号——如果存在，不应该只被 Pranav et al. "隐含地"看到。这产生了一个紧张：如果信号这么强，为什么不是明确的 5σ+ 发现？

**判定：** ⚠️ 警告。g_eff = 1.0 ± 0.5 的 100% 增强量级与现有文献中 β₁ 异常的不显著性存在紧张。需要解释为什么如此大的信号尚未被明确报告。

## Q5. 代数验算

### Q5-1: PD(T) = (e^{(λ-μ)T} - 1)/(λ-μ) —— 是 Nee et al. (1994) 的原始形式吗？

**答案：不是。**

Nee et al. (1994) 的核心结果是关于**重构生灭过程**（reconstructed birth-death process）的——从现存物种的系统发生树倒推演化速率。他们的关键结果是 branching times 的分布公式和从现有数据同时估计 λ 和 μ 的方法。

PD(T) = (e^{(λ-μ)T} - 1)/(λ-μ) 是标准生灭过程的累积种群大小的期望积分——**这是一个教科书结果**，不是 Nee et al. 独有的。它给出的是**无条件期望**（包括已灭绝谱系的贡献），而 Nee et al. 关注的是**条件期望**（条件于存活到当前）。

B 博士在 §0.2 和附录 B 的注记中诚实地承认了这一点。公式本身在数学上是正确的（对于无条件生灭过程），但标记为"Nee et al. (1994)"的引用是**不准确的**——Nee et al. 没有给出这个特定公式。

**判定：** ⚠️ 警告。公式代数正确，但引用归属不准确。应注明公式来自标准生灭过程理论（如 Kendall 1948, Harris 1963）而非 Nee et al. (1994)。

---

### Q5-2: g_eff = 1.0 ± 0.5 的推导来源

**§3.2.1 的推导链：**

1. 假设因果图有 b₁^{large-scale} 个大尺度环
2. 推测 b₁^{large-scale} ≈ 2（环面拓扑）
3. 推测 β₁^ΛCDM(ν=0) ≈ 2-5（"Feldbrugge et al. 2019" 口头引用）
4. g_eff = b₁^{excess} / β₁^ΛCDM ≈ 2 / [2,5] = [0.4, 1.0]
5. 中点：1.0 ± 0.5

**这 5 步中，仅有第 3 步有文献支持（且未给出精确引用）。第 1-2 步是纯粹假设。**

具体问题：
- **为什么大尺度因果环恰好是 2 个？** 因为"环面拓扑有 b₁=2"——但为什么因果图该是环面拓扑？为什么不是球面（b₁=0）或双环面（b₁=4）？
- **为什么 β₁^ΛCDM(ν=0) ≈ 2-5？** Feldbrugge et al. (2019) 的解析公式依赖于平滑尺度和阈值范围的具体选择。没有给出精确数值和引用行号。
- **为什么中点取 1.0 而非 0.7？** [0.4, 1.0] 的中点应该是 0.7，但 B 博士取了 1.0。将范围扩展到 ±0.5 给出 [0.5, 1.5]——这个扩展的物理理由未说明。

**g_eff 的"整数性"声张其实来自二选一：** 要么 b₁^{large-scale} = 2（环面，g_eff≈1），要么 b₁^{large-scale} = 0（球面，g_eff≈0）。没有任何推导排除 b₁^{large-scale} = 4, 6, ...（高亏格曲面），也没有推导为什么必然是整数（如果只有部分环投射到 CMB，g_eff 可能是任何实数）。

**判定：** ⚠️ 警告。g_eff = 1.0 不是从 toric code 推导出来的——它是从"假设因果图具有环面拓扑"推出的。这是一个**参数选择**（假设 b₁^{large-scale}=2）而非推导。整数性声张（"准整数量子化"）依赖于这个未证明的假设。

三个名义参数退化为一个有效参数 → **不存在过拟合问题**（如果有 3 个参数拟合 1 个输出，那会是过拟合）。但存在另一个问题：

## Q6. 声张缩水/替代解释检查

### Q6-1: g_eff "应该是整数/半整数"声张的强度

**声张（§3.1, §3.3）：**

> "如果 toric code 类比成立，g_eff 应该接近一个整数或半整数。"

> "g_eff ≈ 1 是整数——不是连续参数——在连续统中随机出现整数的概率是测度零"

**强度分析：**

1. **整数性的前提：** Toric code 中 g 是整数（亏格），GSD = d^{2g}。翻译到 CMB：g_eff = (β₁^obs/β₁^ΛCDM - 1)。要使 g_eff 为整数，需要：
   - β₁^excess = β₁^obs - β₁^ΛCDM 是偶数（因为 b₁^{excess} = 2g）
   - β₁^ΛCDM 恰好是某个参考值使得比率减一为整数
   
   这两个条件都需要成立。B 博士**假设了 b₁^{excess} = 2**（正好对应 g=1），但这推不出"g_eff 应该是整数"——只能推出"如果 b₁^{excess} = 2 而 β₁^ΛCDM 取特定值，则 g_eff ≈ 1"。

2. **整数声称的脆弱性：** 如果 β₁^ΛCDM(ν=0) 取 3 而非 2，且 b₁^{excess} = 2（环面），则 g_eff = 2/3 ≈ 0.67——不是整数。β₁^ΛCDM 是连续函数（依赖于平滑尺度、掩膜、ν 范围的选择）——**它不是一个固定的"参考整数"**。

3. **B 博士自己的分析显示非整数可能性：** §3.3 中讨论了 g_eff = 0.50 ± 0.10 和 g_eff = 1.20 ± 0.40 的情况——这些都不是严格的整数。所以"半整数"只是一个**事后合理化**（0.5 = 半整数因为 b₁^{excess} = 1 对应一个环）。

**核心问题：** g_eff 的整数性声张依赖于未证明的假设"因果图团复形同伦等价于闭可定向曲面"。对于一般因果图团复形，b₁ 可以取任何非负整数，g_eff 可以是任何实数。

**判定：** ⚠️ 警告。整数性声张在一般因果图上不成立——它仅在因果图团复形恰好是曲面三角剖分的特殊情况下有效。B 博士将"如果是环面则 g_eff≈1"包装为"g_eff 应该是整数"，这是声张膨胀。"测度零"论证（连续参数随机取整数的概率为零）在这里是**倒因为果**——g 为整数是因为亏格定义就是整数，而非因为发现 g≈1 就说明它有特殊意义。
