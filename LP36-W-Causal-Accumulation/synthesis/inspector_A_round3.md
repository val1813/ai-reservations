## Q5-1: R2阻断#1修复验证 — 二次方程通解符号

### 修正公式

A博士的修正公式 (R3 §P0-1.3):

$$\boxed{b_1^* = \frac{b + \sqrt{b^2 + 4r_1(1+g_1)r_0 g_0}}{2r_1(1+g_1)}, \quad b = r_0(1+g_1) - 1 - r_1 g_0}$$

### 代数溯源验证

标准二次方程 a(b₁*)² + b·b₁* + c = 0:
- a = -r₁(1+g₁) < 0 (因 r₁ > 0, g₁ > -1)
- b = r₀(1+g₁) - 1 - r₁g₀
- c = r₀g₀ > 0

通解: b₁* = [-b ± √(b² - 4ac)] / (2a)

代入 a = -r₁(1+g₁):
- 分母: 2a = -2r₁(1+g₁) < 0
- 判别式: b² - 4ac = b² - 4(-r₁(1+g₁))(r₀g₀) = b² + 4r₁(1+g₁)r₀g₀

取 + 号: b₁* = [-b + √(b²+4r₁(1+g₁)r₀g₀)] / [-2r₁(1+g₁)] = [b - √(...)] / [2r₁(1+g₁)] → 负根
取 - 号: b₁* = [-b - √(b²+4r₁(1+g₁)r₀g₀)] / [-2r₁(1+g₁)] = [b + √(...)] / [2r₁(1+g₁)] → 正根

由于分母 > 0，正根对应 b + √(正数) > 0 → 物理可达。A博士的修正公式选正根，正确。

### 递推关系

从二次方程反推递推: b₁^(n+1) = b₁^(n) + a·(b₁^(n))² + b·b₁^(n) + c
展开: b₁^(n+1) = r₀(1+g₁)·b₁^(n) - r₁g₀·b₁^(n) - r₁(1+g₁)·(b₁^(n))² + r₀g₀

## 新推导审查: 定理6 — b₂在因果Hasse图团复形中恒为零

### 定理陈述

设G为有限因果集的Hasse图(传递约化DAG)，Cl(G)为其团复形。则 b₂(Cl(G)) = 0。

### 证明核实

A博士的证明链:
1. Cl(G)中2维单形对应G中无向化后的三角形(3-团)
2. Hasse图中，3节点形成三角形当且仅当它们两两有Hasse边
3. 但偏序集的Hasse图是**无三角形**的: 若{a,b,c}两两有Hasse边，则它们必全序 (传递性强制a<b<c或c<b<a)。此时a-c的Hasse边因b为中间节点而被移除 (传递约化)
4. 因此Cl(G)不含2维单形 → 退化为1维复形 → H₂(Cl(G)) ≡ 0 → b₂ = rank(H₂) = 0

### 团复形三角形条件分析 (检查用户提出的反例问题)

**问题:** "在图不是完全传递的一般情况下，是否有反例（3节点形成非传递三角形→团复形中含2维面）？"

**分析:** Hasse图是偏序集的传递约化，不是"一般图"。偏序集天然具有传递性——这不是附加假设，而是因果集的定义。关键区分:

1. **在偏序集中:** 若 a ≺ b 且 b ≺ c (Hasse边)，则 a < c (偏序传递性)。但 a ≺ c 作为Hasse边被移除 (因为b在中间)。因此 {a,b,c} 不能全为Hassee边。

2. **非传递三角形的构造尝试:**
   - a ≺ b, a ≺ c, b和c不可比 → 边集 {a-b, a-c}，无b-c边 → 非三角形
   - a ≺ b, c ≺ b, a和c不可比 → 边集 {a-b, c-b}，无a-c边 → 非三角形
   - a ≺ b, b ≺ c, a和c不可比 → 但传递性强制 a < c，矛盾 → 不存在

3. **结论:** 在偏序集的Hasse图中，不存在任何三个节点构成无向三角形。这是偏序理论的已知结论 (Hasse diagrams are triangle-free)。

### b₂>0的条件 (仅在全因果DAG或其他同调下)

A博士正确列举了b₂可能非零的三种情况:
- **情况A (全因果DAG):** 含传递边，三角形可存在。但高密度极限下复形contractible
- **情况B (有向团复形):** 有向同调可能产生非零b₂
- **情况C (路径同调):** Grigor'yan等的路径同调框架下可能非零

**定理6的局限:** 定理的结论 "b₂≡0" 依赖于两个选择:
1. 使用Hasse图 (而非全DAG) 作为因果结构的图表示
2. 使用团复形同调 (而非路径同调) 作为拓扑不变量

A博士在§P1-2.4和§P1-2.5中已显式标注这些局限。

### dim(W) = d^{b₁} 推导

基于b₂≡0: dim(W) = d^{b₁} (不需b₂项)。与B博士的2D toric code类比一致 (2D toric code中b₂=0 → dim = d^{b₁})。

```
b₁^(n+1) = b₁^(n) + a·(b₁^(n))² + b·b₁^(n) + c
a = -r₁(1+g₁),  b = r₀(1+g₁)-1-r₁g₀,  c = r₀g₀
```
