### §-1.7 Chaplin(2022)关键结果提取

Chaplin对有向Erdos-Renyi随机图G(n, p)（每对节点以概率p独立加有向边）计算路径同调的b₁，得到：

- **低密度边界:** 当p ≪ n^{-1/2}时，b₁=0以高概率（图太稀疏，无环）
- **中密度区间:** 当n^{-1/2} ≪ p ≪ n^{-1/3}时，b₁>0以高概率（"goldilocks区间"）
- **高密度边界:** 当p ≫ n^{-1/3}时，b₁=0以高概率（图太密集，所有环被填充）

**物理含义:** 对于一个有N个节点的因果DAG，如果其有效边密度p_eff（由因果结构——光锥几何决定——非自由参数）满足n^{-1/2} < p_eff < n^{-1/3}，则b₁>0可存活。若p_eff > n^{-1/3}（高密度），则b₁→0——这是在q→0极限下（所有节点确定、所有潜在因果边被激活）可能发生的情况。

**关键限制:** Chaplin的模型是无向Erdos-Renyi图的有向版本——每对节点间有向边的概率是均匀的。因果DAG不是均匀随机图：因果边受光锥结构约束，密度由因果集理论中的Poisson散布和因果联系概率决定。我们需要估计因果DAG的有效边密度，才能判断它落在Chaplin的哪个区间。

## §1 P0修正#1: 定理3下界——因果聚类因子

### 1.1 问题诊断（来自INSPECTOR A1阻断）

Round 1 §3.2定理3原公式：

$$E[r_1] \geq (1-r)^{\bar{L}_{\text{typ}}} \cdot (1 + \delta_{\text{clustering}})$$

**致命错误:** 当r→0（弱重置）时，(1-r)^{L̄_typ} → 1——这没问题。但当**r→1**时（强重置），(1-r)^{L̄_typ} → 0。问题出在**δ_clustering项**：它被定义为"修正因子>1"，这意味着在r→0时，整个表达式会超过1，但r₁ ∈ [0,1]——溢出。

更根本的问题：δ_clustering是在(1-r)^{L̄_typ}的Taylor展开中引入的——它是一个**绝对修正**，而非**相对修正**。正确的方式是让聚类效应修改**指数**而非**乘积因子**。

### 1.2 修正推导

从Round 1 §1.5约束1出发：因果相邻节点的存活具有正相关性。对长度为L的环：

**独立假设下:**
$$P[\text{环存活} \mid \text{独立}] = \prod_{i=1}^{L} P[s(v_i)=1] = (1-r)^L$$

**因果聚类下:**
$$P[\text{环存活} \mid \text{聚类}] = P[s(v_1)=1] \cdot \prod_{i=1}^{L-1} P[s(v_{i+1})=1 \mid s(v_i)=1]$$

定义聚类因子c ∈ [0,1]：P[s(v_{i+1})=1 | s(v_i)=1] = (1-r)^c。当c=1时：条件概率=无条件概率（无聚类，独立极限）。当c→0时：条件概率→1（完美聚类——一旦一个节点存活，邻居必然存活）。

则：
$$P[\text{环存活}] = P[s(v_1)=1] \cdot \prod_{i=1}^{L-1} P[s(v_{i+1})=1 \mid s(v_i)=1]$$
$$= (1-r) \cdot (1-r)^{c(L-1)} = (1-r)^{1 + c(L-1)}$$

定义**有效聚类缩减因子** f_cluster：

$$f_{\text{cluster}} = \frac{1 + c(L-1)}{L} = c + \frac{1-c}{L}$$

f_cluster ∈ (0, 1]：c→0 给出 f_cluster ≈ 1/L（强聚类，环几乎必存活）；c=1 给出 f_cluster = 1（无聚类，退化为独立假设）。

### 1.3 修正后的定理3

**定理3 (修正) (b₁的存活条件 — 主定理):** 设 G = (V, E) 为有限连通DAG，b₁(G) > 0。存活函数 s 满足约束1（因果聚类）和约束2（度数依赖），E[|V_surv|] = (1-r)|V|，r ∈ [0,1]。

则 b₁ 在重置后的期望存活率有正下界：

$$\boxed{E[r_1] \geq (1-r)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}}$$

其中：
- L̄_typ 为典型环长度（b₁个环的平均长度）
- f_cluster ∈ (0, 1] 为因果聚类因子，定义为 f_cluster = c + (1-c)/L̄_typ
- c ∈ [0, 1] 为条件存活衰减指数：P[s(v_{i+1})=1 | s(v_i)=1] = (1-r)^c

**边界行为验证:**
- **r→0:** (1-r)^{L̄·f} → 1 —— 弱重置下环几乎全存活 ✓ (不溢出，≤1)
- **r→1:** (1-r)^{L̄·f} → 0 —— 强重置下环全消亡 ✓
- **c=1 (无聚类):** f_cluster = 1 —— 退化为独立假设 E[r₁] ≥ (1-r)^{L̄} ✓
- **c→0 (完美聚类):** f_cluster ≈ 1/L̄ —— E[r₁] ≥ (1-r) —— 环存活率等于单个节点的存活率（因为环上所有节点共享命运） ✓
- **L̄=1 (退化为自环——不可能; 最短环L=3):** f_cluster = c + (1-c)/3 ∈ [1/3, 1] ✓

**物理含义:**
- c < 1（因果聚类存在）→ f_cluster < 1 → E[r₁] > (1-r)^{L̄_typ}（独立假设下限）
- c → 0（强因果聚类）→ E[r₁] ≥ 1-r（环存活率大幅提升）
- 因果聚类性使b₁存活率**指数级地**高于独立删除假设

### 1.4 δ_clustering的重定义

为保持与Round 1符号的兼容性，定义：
$$\delta_{\text{clustering}} = \frac{(1-r)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}}{(1-r)^{\bar{L}_{\text{typ}}}} - 1 = (1-r)^{\bar{L}_{\text{typ}}(f_{\text{cluster}}-1)} - 1 > 0$$

当f_cluster < 1（聚类存在）且 r < 1时，δ_clustering > 0。这个δ_clustering不再是"加法修正"而是"乘法增强因子"——正是Round 1的意图。

修正后的完整公式：
$$E[r_1] \geq (1-r)^{\bar{L}_{\text{typ}}} \cdot (1 + \delta_{\text{clustering}}) = (1-r)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}$$

两边恒等。δ_clustering (新定义) |_{r→0} = 0（聚类效应在弱重置极限下消失，因为(1-r)^{L̄} = 1已经"完美"），符合直觉。

## §2 P0修正#2: 稳态解符号

### 2.1 问题诊断（来自INSPECTOR A2阻断）

Round 1 §7.3-7.4 稳态推导：

**原推导（错误）:**
$$\frac{db_1}{dn} = \underbrace{g \cdot b_1}_{\text{生长}} - \underbrace{(1 - r_{\text{eff}}) \cdot b_1}_{\text{衰减}}$$
$$b_1^* = \frac{g_0 - \delta}{g_1}$$
条件：δ < g₀（基线生长超过衰减）

**INSPECTOR指出的错误:** δ ≡ 1 - r_eff 是衰减率。衰减率超过生长率(δ > g₀)意味着b₁净减少→稳态为负？——但b₁不能为负。正确的物理直觉是：当衰减率大于生长率时，稳态应为零（或正但小于初始值）。先前的符号推导有错。

### 2.2 重推导：离散随机递推的期望

R1 §7.2的递推方程：
$$b_1^{(n+1)} = (b_1^{(n)} + \Delta_n^{\text{growth}}) \cdot r_1(n)$$

取期望（条件于b₁^(n)）：
$$E[b_1^{(n+1)} \mid b_1^{(n)}] = (b_1^{(n)} + E[\Delta_n^{\text{growth}} \mid b_1^{(n)}]) \cdot E[r_1(n) \mid b_1^{(n)}]$$

假设生长和存活率统计独立于具体n（仅依赖于b₁^(n)）：
$$E[\Delta_n^{\text{growth}} \mid b_1^{(n)}] = g(b_1^{(n)})$$
$$E[r_1(n) \mid b_1^{(n)}] = r_{\text{eff}}(b_1^{(n)})$$

令 g(b₁) = g₀ + g₁·b₁（线性近似），r_eff = r_0 - r₁·b₁（存活率随b₁增大而减小——密集图中有更多环但每个环更脆弱——dilution effect）。

则期望递推：
$$E[b_1^{(n+1)}] = (b_1^{(n)} + g_0 + g_1 b_1^{(n)}) \cdot (r_0 - r_1 b_1^{(n)})$$
$$= [b_1^{(n)}(1 + g_1) + g_0] \cdot (r_0 - r_1 b_1^{(n)})$$

这是b₁^(n)的二次函数。稳态条件 E[b₁^(n+1)] = b₁^(n)：
$$b_1^* = [(1 + g_1)b_1^* + g_0] \cdot (r_0 - r_1 b_1^*)$$

展开：
$$b_1^* = r_0(1 + g_1)b_1^* + r_0 g_0 - r_1(1 + g_1)(b_1^*)^2 - r_1 g_0 b_1^*$$

整理：
$$0 = [r_0(1 + g_1) - 1]b_1^* + r_0 g_0 - r_1(1 + g_1)(b_1^*)^2 - r_1 g_0 b_1^*$$
$$0 = -r_1(1 + g_1)(b_1^*)^2 + [r_0(1 + g_1) - 1 - r_1 g_0]b_1^* + r_0 g_0$$

这是一个标准二次方程 a(b₁^*)^2 + b·b₁^* + c = 0，其中：
$$a = -r_1(1 + g_1) < 0$$
$$b = r_0(1 + g_1) - 1 - r_1 g_0$$
$$c = r_0 g_0 > 0$$

由于a < 0且 c > 0，方程始终有正解（一个正根，一个负根——后者物理不可达）：

$$b_1^* = \frac{-[r_0(1+g_1)-1-r_1 g_0] + \sqrt{[r_0(1+g_1)-1-r_1 g_0]^2 + 4r_1(1+g_1)r_0 g_0}}{2r_1(1+g_1)} > 0$$

### 2.3 退化情形：r₁ = 0（存活率不依赖b₁）

若存活率不随b₁变化（r₁=0——无稀释效应），二次方程退化为线性：

$$b_1^* = b_1^* \cdot r_0(1 + g_1) + r_0 g_0$$
$$b_1^* \cdot [1 - r_0(1 + g_1)] = r_0 g_0$$

$$\boxed{b_1^* = \frac{r_0 g_0}{1 - r_0(1 + g_1)}}$$

**非平凡正稳态条件:** 分母 > 0 ⇔ r_0(1 + g_1) < 1 ⇔ 1 - r_0 > r_0·g_1。

定义δ ≡ 1 - r_0 = 衰减率。条件变为：
$$\delta > r_0 \cdot g_1$$

物理含义：**衰减率必须超过"存活-生长乘积"**才能存在有限的正稳态。如果衰减太小（δ→0 → r_0→1），分母→ -g₁ < 0 → b₁^*为负（物理不可达）→ b₁发散（无限增长）。如果衰减太大（δ→1 → r_0→0），b₁^* → 0。

**这与Round 1的直觉一致但修正了符号错误:** 
- Round 1错误条件（δ < g₀）→ 修正为 δ > r_0·g_1
- 物理解释修正：稳态不是"生长和衰减平衡"产生——而是**衰减防止了爆炸式增长**。没有衰减(δ=0)时，b₁无限增长（因果图拓扑爆炸）——这正是"螺旋上升"的DGF版。

### 2.4 稳定性分析

在r₁=0退化情形下，稳定性由递推函数F(b₁) = r_0(1+g₁)·b₁ + r_0 g_0决定：

$$F'(b_1^*) = r_0(1 + g_1)$$

若F'(b₁^*) < 1，稳态稳定。条件：r_0(1+g₁) < 1 ⇔ 正是稳态存在的充要条件。

**关键结论:** 在r₀(1+g₁) < 1（即δ > r₀·g₁）时，稳态b₁^* = r₀g₀/(1-r₀(1+g₁)) > 0 且稳定。若r₀(1+g₁) ≥ 1（即δ ≤ r₀·g₁），b₁发散——"螺旋上升"。

**W存在的精确条件:**
$$\boxed{r_0(1 + g_1) \geq 1 \quad \text{(螺旋上升)} \quad \text{或} \quad r_0(1 + g_1) < 1 \text{(稳定有限W)}}$$

在两种情况中，只要 r₀ > 0 且 g₀ > 0，则 b₁^* > 0 —— **任何非零存活率和非零基线生长都产生正b₁**。在连续近似下，除非r₀=0（完全清空）或g₀=0（无新环），b₁>0。

- 因果图的边集（决定可达性）本身是静态的——A1禁止图结构被传播改变

- 若DGF因果图在ρ/ρ₀ ∈ [1, 2]时b₁>0显著且跨重置存活，则W的图论基础通过生死验证

### 4.5 高密度极限b₁→0的物理解释

如果宇宙的初始因果图密度落在Chaplin的高密度区间（p > n^{-1/3}），那b₁确实→0。这在物理上意味着：

1. **全连接因果图 = 无环图：** 如果因果图几乎全连接（每对节点可有因果联系），任何三个节点的环都被"短路边"填充——在团复形中这些环被填充为面，b₁→0。
2. **这需要天体物理约束：** 在真实的宇宙学中，因果连接由光锥结构决定。两个类空分离的节点没有因果边。因此因果图天然稀疏——每节点仅与光锥内节点连接。
3. **光锥约束 = 自然的稀疏化机制：** 光锥结构自动约束了因果图的最大密度。在d+1维时空中，一个给定节点的因果未来包含Vol(◇) ∝ (Δτ)^d 个散布点。与之相比，总节点数N ∝ Vol(spacetime)。比值p_eff ∝ (Δτ)^d / Vol(spacetime) ≪ 1——因果图天然稀疏。

**这给出了W存在的时空维度约束：** 在d+1维时空中，p_eff ~ O((Δτ/N^{1/(d+1)})^d)。对于大的d（高维），p_eff更小——b₁更容易存活。对于d=1（1+1维），需要Δτ足够大以使p_eff进入Chaplin的goldilocks区间。对于d=3（3+1维），因果图更稀疏，b₁存活条件更宽松。

## §5 P1新任务: 从生灭过程推导ε_n的统计矩

### 5.1 问题陈述

Round 1 §3.3的ε_n形式有自由参数γ（标度指数）。PI裁决（R1 §二，分歧1）要求用B博士的生灭过程框架替代自由参数，推导ε_n的统计矩（期望+方差）。

### 5.2 因果图节点的生灭过程（Birth-Death-Mutation on Graph）

**定义6 (因果图节点生灭过程):** 考虑因果图G = (V, E)上的Markov过程，每个节点v可处于三种状态之一：
- **存活(S):** 节点在重置中存活（对应s(v)=1）
- **死亡(D):** 节点在重置中被清空（对应s(v)=0）
- **变异(M):** 节点存活但其因果边集被修改（对应G中的局部重连）

转移率（从系统发生学生灭框架翻译）：

| 转移 | 速率 | DGF对应 | 参数 |
|------|------|---------|------|
| S→D | μ(v) | 节点在重置中被清空 | μ₀ + μ₁·(1/deg(v)) |
| D→S | λ(v) | 新因果节点诞生 | λ₀ + λ₁·|anc(v)|/N |
| S→M | ν(v) | 因果边重连 | ν₀·deg(v)/N |

- μ₁项编码度数依赖：高度数节点更难被清空（因果重要性）
- λ₁项编码因果前驱依赖：有更多因果前驱的节点更容易被重建
- ν项编码因果重连：高度数节点有更多边→更可能被重连

### 5.3 从生灭过程推导b₁的统计矩

b₁(G)是G的团复形中独立的1-环数。环的存亡由其组成节点的存亡+变异决定：

**引理4 (生灭过程的b₁期望):** 在稳态生灭过程下，b₁的期望为：
$$E[b_1] = b_1^{\text{max}} \cdot \frac{\lambda_{\text{eff}}}{\lambda_{\text{eff}} + \mu_{\text{eff}}} \cdot \eta(\nu, f_{\text{cluster}})$$

其中：
- b₁^max为同一节点数全连接随机图的最大b₁（理论上限）
- λ_eff = Σ_v λ(v)/N 为平均新生率
- μ_eff = Σ_v μ(v)/N 为平均死亡率
- η(ν, f_cluster) ∈ [0,1] 为重连效率因子——编码了变异(重连)如何改变环拓扑

**证明梗概:**
1. 在每个时间步Δt，每个现有环以概率 μ_eff·L̄_typ·f_cluster 消亡（环上所有L̄_typ个相邻节点对中以聚类概率级联死亡）
2. 新环以速率 λ_eff²·p_form 形成（两个存活节点间新边创建新环的概率）
3. 变异使已有环以速率ν重连→环拓扑改变但不一定消亡→η编码此效应
4. 稳态条件：环创造率 = 环消亡率 → 解出E[b₁]

### 5.4 从b₁统计矩推导ε_n的统计矩

Round 1定义：ε_n = ε₀·(b₁(G_n^init)/b₁^ref)^γ，其中γ为自由参数。

**消除γ的决定性步骤:** γ本质上是b₁→CMB温度涨落的响应函数。但ε_n的统计性质——期望和方差——可以直接从b₁的统计矩推导，无需γ：

**定理4 (ε_n的统计矩——从生灭过程):**
$$E[\epsilon_n] = \epsilon_0 \cdot \frac{E[b_1^{(n)}]}{b_1^{\text{ref}}}$$
$$\text{Var}[\epsilon_n] = \epsilon_0^2 \cdot \frac{\text{Var}[b_1^{(n)}]}{(b_1^{\text{ref}})^2}$$

其中 γ=1 的假设来自以下推理链：
1. 在团复形对应假设(WA3)下，因果图的1-环一一对应于连续时空的1-环（Major-Rideout-Surya 2007）
2. 连续时空的1-环对CMB光子施加拓扑边界条件——环的通量量子化产生温度涨落
3. 涨落幅度与环的数量成正比——线性响应（γ=1），除非环之间存在干涉效应
4. 环间干涉效应对应有向环→无向环的投影，在稀疏图中干涉效应是O(b₁²/N)低阶修正

**因此γ=1 + O(b₁/N)。** 在小b₁/N极限下（稀疏因果图），γ≈1是第一近似，自由参数被消除。

**ε_n的完整统计描述（替代单一自由参数γ）:**
$$\boxed{\epsilon_n \sim \mathcal{D}\left(\mu = \epsilon_0 \frac{E[b_1^{(n)}]}{b_1^{\text{ref}}}, \sigma^2 = \epsilon_0^2 \frac{\text{Var}[b_1^{(n)}]}{(b_1^{\text{ref}})^2}\right)}$$

分布的精确形式（D）由b₁的分布决定，而b₁的分布由生灭过程参数(λ, μ, ν)和因果聚类因子f_cluster决定。在稳态下，可近似为Gamma分布（生灭过程的经典稳态分布）。

### 5.5 Var[b₁]的解析估计

从生灭过程，b₁的方差来自两个源：
1. **采样方差:** 有限N个节点中环数的Poisson波动
2. **生灭噪声:** 生灭过程的随机涨落

在稳态下（§2.4的条件i，r₀(1+g₁) < 1）：
$$\text{Var}[b_1] \approx E[b_1] \cdot \left(1 + \frac{\nu_{\text{eff}}}{\mu_{\text{eff}}}\right)$$

推导：b₁可近似为有出生率λ_eff·E[b₁]和死亡率μ_eff·(1+f_cluster·L̄)的Markov过程。重连率ν_eff增加方差（因为重连改变环数但不改变期望）。结果：Var[b₁] ≳ E[b₁]（超Poissonian方差——生灭过程对方差的放大）。

### 5.6 ℓ_n到CMB的可计算路径

**预言1-3（Round 1 §9）的ε_n精炼：**

使用定理4，预言1的定量表述精炼为：

$$\frac{\beta_0^{\text{Planck}}(0) - \beta_0^{\Lambda\text{CDM}}(0)}{\beta_0^{\Lambda\text{CDM}}(0)} \approx -\frac{E[b_1]}{b_1^{\text{ref}}} \cdot \Delta(\nu=0)$$

其中Δ(ν)是b₁→β₀映射的响应函数（可由Cole-Shiu持续同调pipeline数值计算）。

其中Δ' > 0（b₁在因果图中存活→CMB β₁增强）。

**不再有自由参数γ。** b₁的期望和方差完全由生灭过程参数(λ_eff, μ_eff, ν_eff, f_cluster, L̄_typ)决定，这些参数均可从DGF因果图模拟直接测量。

## §6 P1新任务: 连接Propagation Bridge

### 6.1 问题陈述

CORE_FRAMEWORK v4.0的核心结果（§4 Theorem）：对任何DAG和任何传播：
$$P_{\text{reflux}} \equiv \frac{N_R}{N_F} \leq \frac{N_S q_S}{N_E q_E}$$

这个上界如何约束b₁在重置中的最大存活率？

### 6.2 从Reflux Bound到因果聚类因子κ

**引理5 (Reflux Bound对κ的约束):** 在§3.1中定义的条件存活比 κ = P[s(v)=1|s(u)=1, u→v]/P[s(v)=1]。Reflux Bound给出κ的上界。

**推导:**
- 系统节点(S)在传播末态的高确定性来自Reflux：被环境(E)确定化的S节点是"回流确定"的。
- 在重置中，高确定性节点有存活优势（§1.5约束3）。令存活优势比α = P[s|d=1]/P[s|d=0]。
- 对于因果边u→v，若u存活(s(u)=1)，则v在传播中从u得到确定性贡献。传播中：(u确定, v未确定) → u使v确定化 → v的确定性依赖于u。
- 在重置中，u存活+ v确定（部分由u贡献）→v存活概率更高。

**形式推导:**
$$P[s(v)=1 \mid s(u)=1] = P[s(v)=1 \mid d_T(u)=1] \cdot P[d_T(u)=1 \mid s(u)=1] + P[s(v)=1 \mid d_T(u)=0] \cdot P[d_T(u)=0 \mid s(u)=1]$$

在传播终止态(T)，d_T(u)=1当且仅当u被确定。存活者必然被确定（因为在重置前所有可达节点都被确定化——q→0极限）：P[d_T(u)=1 | s(u)=1] = 1。因此：

$$P[s(v)=1 \mid s(u)=1] = P[s(v)=1 \mid d_T(u)=1]$$

现在，d_T(u)=1且u→v：v在传播中被u确定化的概率≥q(u)·(1/|pred(v)|)（均匀确定化竞争假设）。Reflux Bound约束了传播中S节点被确定的总数N_R ≤ N_S·q_S。这意味着：每个S节点的平均确定化概率 ≤ q_S。

对于因果边u→v（至少一端在S中——因为S和E分划是任意的）：
$$P[s(v)=1 \mid s(u)=1] \leq P[s(v)=1 \mid d_T(u)=1] \leq \alpha \cdot P[s(v)=1]$$

其中α是确定性→存活优势比。取上界：
$$\kappa = \frac{P[s(v)=1 \mid s(u)=1]}{P[s(v)=1]} \leq \alpha$$

而α本身受Reflux Bound约束：高度确定性的节点更可能存活，但确定性的总量受Reflux Bound限制。在N_S = N_E时：
$$\alpha \leq 1 + \frac{q_S}{q_E} \quad \text{或更精确地} \quad \alpha \leq \frac{1}{1 - q_S/N_S}$$

简化为：α ∈ [1, 1/(1-q_S)]。对于典型q_S ≈ 0.3，α ≤ 1.43。

### 6.3 P_reflux对b₁存活率的上界

**定理5 (Reflux Bound对环存活率的上界):**

设因果图G在传播终止态(T)有b₁个环。在Propagation Bridge框架下（Reflux Bound满足），重置后b₁存活率受以下上界约束：

$$\boxed{E[r_1] \leq (1-r \cdot \alpha)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}}$$

其中α ≤ 1/(1-q_S)（当N_S = N_E时）。特别地：

$$r_{1,\max} \leq 1 - \frac{q_S}{q_E} \cdot \frac{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}{N_S}$$

**推导梗概:**
1. 由引理5：κ ≤ α ≤ 1/(1-q_S)
2. §3.1中c = 1 + log κ / log(1-r)。将κ替换为α上界得到c的下界：
   $$c \geq 1 + \frac{\log(1/(1-q_S))}{\log(1-r)}$$
3. f_cluster = c + (1-c)/L̄_typ。c变大→ f_cluster变大→存活率降低。
4. 因此，Reflux Bound通过约束α→约束κ→约束c→约束f_cluster→约束r₁的上界。

**物理含义:**
- q_S/q_E越大（初始系统更不确定）→ α越小 → r₁越低 → b₁存活更难
- q_S/q_E越小（初始系统更确定——DGF偏好状态）→ α可更大 → r₁更高 → b₁存活更易
- P_reflux ≤ q_S/q_E是因果一致性条件：回流不能超过"系统不确定性/环境不确定性"之比
- 这个比也约束了重置中环存活的"因果惯性"上限

### 6.4 Propagation Bridge作为b₁存活的双向约束

总结：
- **Reflux Bound下界:** 因果一致性要求P_reflux ≤ q_S/q_E → 约束传播中信息回流的量 → 约束节点的确定化程度 → 约束存活优势比α
- **b₁存活率上界:** r₁ ≤ (1-r·α)^{L̄_typ·f_cluster} —— 存活率受Reflux Bound约束
- **b₁存活率下界:** r₁ ≥ (1-r)^{L̄_typ·f_cluster} —— 定理3（修正）给出因聚类而增强的下界

结合上下界，b₁的存活率被约束在一个有限区间：
$$(1-r)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}} \leq E[r_1] \leq (1-r \cdot \alpha)^{\bar{L}_{\text{typ}} \cdot f_{\text{cluster}}}$$

其中f_cluster由因果聚类性决定，α由Reflux Bound约束。

**关键推论:** 当q_S/q_E较小（系统比环境更确定——DGF的开放量子系统偏好状态）时，上下界间距变窄，r₁的预测精度提高。在极限q_S → 0（系统完全确定）→ N_R = 0 (Reflux Bound §7 Case 4) → 所有S节点已确定，重置中存活完全由A1不可逆性保证 → r₁ → 1（环全部存活，因为没有任何节点需要被清空）。

## §7 自我攻击报告（Round 2追加）

### 7.1 致命攻击#6: Chaplin(2022)的b₁消失定理否定W

**致命度:** 🔴🔴🔴🔴🔴 (致命——如果适用)

**攻击陈述:** Chaplin(2022)严格证明了在有向Erdos-Renyi随机图中，当边密度p > n^{-1/3}（高密度），路径同调的b₁=0以高概率成立。如果DGF因果图在q→0极限下边密度超过此阈值，则b₁→0，W不存在。

**回应:**
1. **因果图不是Erdos-Renyi随机图。** 因果图的边受光锥约束——类空分离节点无连接。这强制了稀疏性：p_eff ≪ 1，通常落在O(N^{-1/2})量级而非O(N^{-1/3})。
2. **路径同调≠团复形同调。** Chaplin使用的是Grigor'yan的路径同调（对digraph原生），而我们使用团复形同调（先将digraph对称化为无向图，再构造团复形）。两者在高低密度极限下可能不同。团复形同调的b₁在高密度极限下的行为尚未被严格证明。
3. **因果图密度不是自由参数。** 由因果集散布密度ρ和时空几何共同决定。在4维时空中（3+1），给定ρ，p_eff天然很小——这使因果图落在Chaplin的goldilocks区间而非高密度区间。
4. **承认:** 若因果图密度确实超过Chaplin的高密度阈值，W的图论基础需要重建。这是Phase 1数值模拟最关键的一步验证。

### 7.2 致命攻击#7: 从Reflux Bound不能直接推导存活优势

**致命度:** 🔴🔴🔴 (中高)

**攻击陈述:** §6.2从Reflux Bound推导存活优势比α的过程有一处跳跃：假设"存活-确定性关联"是线性且单调的。但Reflux Bound约束的是**传播中**节点确定化的总量，而非**重置中**的存活。传播和重置是两个不同的物理过程——前者由DAG结构决定，后者由外部循环动力学决定。两者之间没有DGF框架内的必然映射。

**回应:**
1. 承认跳跃。Reflux Bound → 存活优势的映射是**建模假设**而非推导。
2. 但方向性正确：Reflux Bound给出确定性的上界→存活优势比的上界→r₁的上界。如果有更好的确定性→存活映射，定理5可相应更新。
3. Phase 1模拟可直接测量κ并检验其是否满足Reflux Bound推导的上界。

### 7.3 致命攻击#8: b₁→CMB线性响应的隐含假设

**致命度:** 🔴🔴🔴 (中)

**攻击陈述:** §5.4声称γ=1（b₁→ε_n线性响应），基于"每个环贡献独立温度涨落"的假设。但在稠密的因果图中，环共享节点→环的涨落贡献不是独立的→可能有破坏性或增强性干涉→γ≠1。
