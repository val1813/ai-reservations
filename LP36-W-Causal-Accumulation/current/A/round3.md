## §P0-1 阻断修正: §2.2二次方程通解符号

### P0-1.1 错误定位

Round 2 §2.2 (line 281) 给出的稳态解通式:

```
b₁* = [ -[r₀(1+g₁)-1-r₁g₀] + √([r₀(1+g₁)-1-r₁g₀]² + 4r₁(1+g₁)r₀g₀) ] / [2r₁(1+g₁)]
```

令 b = r₀(1+g₁) - 1 - r₁g₀，文档公式等价于 b₁* = [-b + √(b² + 4r₁(1+g₁)r₀g₀)] / [2r₁(1+g₁)]。

### P0-1.2 代数溯源

二次方程 a(b₁*)² + b·b₁* + c = 0:
- a = -r₁(1+g₁) < 0
- b = r₀(1+g₁) - 1 - r₁g₀
- c = r₀g₀ > 0

标准解: b₁* = [-b ± √(b² - 4ac)] / (2a)

代入 a = -r₁(1+g₁):
- 分母 2a = -2r₁(1+g₁) < 0
- -4ac = -4(-r₁(1+g₁))(r₀g₀) = +4r₁(1+g₁)r₀g₀
- b² - 4ac = b² + 4r₁(1+g₁)r₀g₀

取+号: b₁* = [-b + √(b² + 4r₁(1+g₁)r₀g₀)] / [-2r₁(1+g₁)]
      = [b - √(b² + 4r₁(1+g₁)r₀g₀)] / [2r₁(1+g₁)]  → (1)

取-号: b₁* = [-b - √(b² + 4r₁(1+g₁)r₀g₀)] / [-2r₁(1+g₁)]
      = [b + √(b² + 4r₁(1+g₁)r₀g₀)] / [2r₁(1+g₁)]  → (2)

根的判别: 由于分母 > 0，根(1)分子为 b - √(b²+正数) < 0 → 负根(物理不可达)；根(2)分子为 b + √(b²+正数) > 0 → 正根(物理可达)。

文档将(2)的分母正号化时，分子错误保留了`-b`而非转换为`+b`。正确公式应为根(2)。

### P1-1.1 INSPECTOR指出的原区间问题

### P1-1.2 理论框架: Chaplin双相变应用于因果图

Chaplin(2022/2024)对有向ER随机图G(n,p)的路径同调b₁:

- **稀疏区:** p ≪ n^{-1/2} → b₁=0 w.h.p. (无环)
- **Goldilocks区:** n^{-1/2} ≲ p ≲ n^{-1/3} → b₁>0 w.h.p. (环丰富)
- **密集区:** p ≫ n^{-1/3} → b₁=0 w.h.p. (环被填充)

**关键区分:** 我们使用团复形同调而非路径同调，因果图非ER随机图。Chaplin阈值作为参考基准，非严格判据。但交叉验证仍是必要的——若因果图p_eff远低于Chaplin稀疏阈值，b₁以高概率为零不依赖于同调定义的具体选择。

### P1-1.3 d̄标度分析 (关键瓶颈)

p_eff = d̄_eff / N，其中d̄_eff是因果图的平均度数。问题: d̄_eff如何随N标度？

**选项A: Hasse图标度 (因果集的标准最简表示)**

因果Hasse图只保留"最近因果邻居"边(传递约化)。在d+1维Minkowski时空中:
- 1+1维: d̄_Hasse ~ O(N^{1/2}) (每个节点的因果未来/过去维数~1)
- 3+1维: d̄_Hasse ~ O(N^{1/3}) (~O(log N) 在部分文献中)

**选项B: 全因果DAG标度**

保留所有因果连接(含传递边): d̄_full ~ O(ρ·Vol(◇)) ~ O(N) (在Δτ覆盖全时域时)

**本文采用选项A(Hasse图)为基准**，理由:
- 团复形定义(§2.1)基于无向化后的边集。若包含所有传递边，团复形中大量三角形会填充环→b₁被系统性低估
- Hasse图的团复形保留了因果结构的"骨架"拓扑——与Major-Rideout-Surya(2007)的Alexandroff拓扑对应
- 全因果DAG的团复形在高密度极限下几乎必然是contractible的(b₁→0)

对于N=1000, 1+1维Hasse图: d̄_Hasse(N=1000) ≈ √1000 ≈ 31.6 @ ρ/ρ₀=1.0。

d̄(ρ/ρ₀=x) ∝ ρ ∝ x → d̄(x) ≈ 31.6·x。

p_eff(x) = d̄(x) / N ≈ 0.0316·x。

### P1-1.5 因果图密度是否"自然"落入Goldilocks区间？

**论证链:**

1. **光锥几何的自然稀疏性:** 在d+1维时空中，Hasse图的边只存在于类时分离且无中间节点的点对之间。对于Poisson散布的因果集，Hasse度数 d̄ ~ N^{1/d} / (d+1)^{1/d}（在1+1维中 d̄ ~ N^{1/2}）。这天然地将p_eff约束在O(N^{1/d - 1}) ≪ 1的水平——因果图天然稀疏。

2. **Dimension dependence:** 在3+1维时空中，d̄_Hasse ~ N^{1/3} → p_eff ~ N^{-2/3}。对N=10^6: p_eff ~ 10^{-4}，远低于Chaplin n^{-1/2}≈10^{-3}。这意味着在3+1维中，因果图密度天然低于Chaplin低边界→b₁→0！

3. **1+1维的特殊性:** 仅在1+1维(或2+1维，d̄~N^{1/2})中，Hasse图密度恰好落在Goldilocks边缘。在3+1维中，因果图过于稀疏。

4. **但这不否定W:** 原因有二:
   (a) Chaplin阈值适用于ER随机有向图的**路径同调**，非因果Hasse图的**团复形同调**。因果Hasse图具有ER随机图不具备的结构特征——光锥几何约束导致"钻石"拓扑(§P1-2.3)——这些在低密度下仍可产生b₁。
   (b) 在早期宇宙中(有效维数降低)，因果图的有效维度可能接近2+1或1+1，此时密度落入Goldilocks区间。

**结论:** 因果光锥几何在1+1和2+1维中"自然"将Hasse图密度推入Goldilocks边缘——不是参数精调，而是维度-几何约束的结果。在3+1维中，需要**非Hasse图表示**或**团复形同调的特殊性质**来救b₁。

### P1-1.6 维度标度对Chaplin阈值的影响

Chaplin的阈值 n^{-1/2} 和 n^{-1/3} 是针对**有向ER随机图**的**路径同调**推导的。对于因果Hasse图的团复形同调:

- 因果图不是ER随机图: 边存在与否由光锥几何决定，生成空间关联
- 团复形同调≠路径同调: 团复形中b₁来自未被三角形填充的无向环
- 在Hasse图中，"钻石"结构天然产生b₁: A→B, A→C, B→D, C→D → 无向4-环在团复形中未被填充(因为B-C无边、A-D无边)

**因此Chaplin阈值对因果Hasse图团复形的适用性尚需独立验证。** 标记为Phase 1模拟的关键检验项。

## §P1-2 b₂在3D因果图中的角色

### P1-2.1 问题精确陈述

INSPECTOR和PI均指出: R2的b₂分析(定理2, "b₂以高概率恒为零")基于2D团复形(三角形是最高单形)，但若考虑**3D团复形**(四面体及以上)，b₂可能非平凡。B博士的dim(W)=d^{b₁}公式是否遗漏b₂项？

### P1-2.2 3D因果图中b₂的团复形条件

在团复形Cl(G)中，b₂计数2维空腔——即被2维面(faces)包围但不被3维单形(四面体)填充的区域。

**b₂>0的必要条件:**
1. 存在至少4个节点两两之间有边 → 形成四面体的1-骨架(完全图K₄)
2. 这4个节点在团复形中形成2维面(三角形)，但不形成3维单形——即四面体内部**不被**团复形包含

条件2在因果Hasse图中几乎不可能满足: 若4节点两两有边(在Hasse图中)，则它们是全序的(因果传递性强制全序→所有三角形被传边填充)。但Hasse图**去除**了传递边，因此Hasse图中不存在K₄子图——四个节点两两Hasse连接意味着某些连接必定是传递的(被去除)。

### P1-2.3 因果Hasse图中b₂的结构性为零

**定理6 (因果Hasse图b₂的平凡性):** 设G为有限因果集的Hasse图(传递约化DAG)，Cl(G)为其团复形。若G不含任何空间超曲面上的类空4-团(即4个互相无因果关系的节点各自通过因果路径连接)，则 b₂(Cl(G)) = 0。

**证明梗概:**
1. Cl(G)中的2维单形对应G中无向化后的三角形(3-团)
2. 在Hasse图中，3个节点形成三角形当且仅当它们不全序(若全序→传递边被移除→至少缺一条边)
3. 不全序的3节点子图: 至少有一对类空分离节点无边→在无向化后也无边→不形成三角形
4. 因此Hasse图的无向化**不含三角形** → Cl(G)是1维复形(仅顶点+边) → H₂(Cl(G)) ≡ 0
5. b₂ = rank(H₂) = 0 █

**物理直觉:** 在Hasse图中，三角形的三个边要求三个节点两两有边。但因果传递性意味着若A→B→C，则A和C也被B的因果路径关联——但Hasse边A→C不存在(B在中间)。因此Hasse图中不存在所有三对都有边的三角形→团复形退化为1维→b₂≡0。

### P1-2.4 什么情况下b₂可能非零？

b₂>0需要超越Hasse图的表示:

**情况A: 全因果DAG(含传递边):**
若使用全因果DAG(包含所有传递边)，三角形可以存在(A→B, B→C, A→C全部保留)。此时:
- Cl(G)包含2维单形(三角形)→可能有b₂
- 但在高密度极限下Cl(G)是contractible的→b₂→0
- 在中间密度下b₂可能非零

**情况B: 有向团复形(directed clique complex):**
不用无向化，直接在DAG上构造有向单纯复形。有向同调可能在Hasse图上也非零。

**情况C: 路径同调(Path Homology):**
Grigor'yan等人的路径同调对digraph有天然定义。在Hasse图上路径同调可能产生非平凡b₁和b₂。

### P1-2.5 b₂的物理含义 (若存在)

| b₂来源 | 物理含义 | CMB签名 | 可检性 |
|--------|---------|---------|:--:|
| **情况A (全DAG)** | 因果空腔: 被因果边完全包裹但不被任何团结构填充的时空区域 | CMB上β₂(ν)增强——对应2D环面型拓扑特征 | 困难(需3D持续同调) |

**在可预见的Planck数据分析中，b₂的可探测性极低。** 原因:
1. Cl(G)的Hasse图表示下b₂≡0(定理6)→无信号可探测

3. β₂(ν)在Aurich-Steiner(2024)中已被计算——在Planck数据中与高斯一致(无异常)

### P1-2.6 dim(W)=d^{b₁}·c^{b₂}？——否，不需要b₂项

基于定理6(b₂≡0在物理相关的Hasse图表示下):

$$\boxed{\dim(W) = d^{\,b_1} \quad \text{(b₂不对W状态空间有贡献)}}$$

**论证:**
1. 在因果Hasse图中(团复形同调，1维复形极限)，b₂=0本质的，非偶然
2. b₁统计分布完全决定W的信息容量——生灭过程框架(§5, R2)只需b₁
3. 若未来发现全DAG或路径同调框架下b₂>0，c^{b₂}因子可添加为dim(W)的乘性修正——但当前无物理理由认为b₂>0

**理论一致性检验:**
- B博士的toric code类比: dim(S_G)=d^{b₁} 来自2D toric code (b₂=0在2D中)。若类比推广到3D toric code，会有b₂项的贡献。但3D toric code的基态简并度公式为 d^{b₁+b₂} (点状激发+环状激发各自贡献独立自由度)
- 若将因果图类比为3D toric code，则 dim(W) = d^{b₁+b₂}。但在Hasse图团复形中b₂=0 → 退化到 dim(W)=d^{b₁}
- **汇合点:** 两个独立框架在b₂=0的极限下一致支持dim(W)=d^{b₁}

## §P5 因果图光锥约束→Goldilocks的"自然性"

### P5.1 核心问题

PI要求确认: "因果图光锥约束是否仍然'自然'将密度推入Goldilocks区间?"

### P5.2 分析

修正后的Goldilocks下界为ρ/ρ₀≥1.0。在1+1维Minkowski时空中:

1. **Hasse图的度标度:** d̄_Hasse ~ N^{1/2} → p_eff ~ N^{-1/2}
2. **Chaplin低边界:** p_low = N^{-1/2}
3. **巧合:** p_eff ≈ p_low (恰好匹配)

在2+1维中: d̄_Hasse ~ N^{2/3} → p_eff ~ N^{-1/3}。Chaplin低边界N^{-1/2}。对于N=10^6: p_eff~0.01, p_low~0.001 → p_eff > p_low → 进入Goldilocks。

在3+1维中: d̄_Hasse ~ N^{3/4}或N^{1/3}(文献分歧) → p_eff ~ N^{-1/4}或N^{-2/3}。前一种情况下p_eff > N^{-1/2}→落入Goldilocks。后一种情况下p_eff < N^{-1/2}→低于。

**结论:** 在2+1维及更低的时空中，光锥几何**自然**将Hasse图密度推入或接近Goldilocks区间——不是参数调谐，而是维度-几何约束。在3+1维中，取决于Hasse度的精确标度律，可能需要其他机制(如局部密度增强、早期宇宙有效维度降低)。

### P5.3 对Planck检验的含义

若W信号存在(β₁增强)，其**强度**可作为宇宙早期有效维度的探针:
- 强β₁增强 → 早期有效维度低(1+1或2+1) → 与某些量子引力方案一致
- 弱β₁增强 → 早期有效维度3+1 → W仅微弱存活
- 无β₁增强 → W=∅ 或 因果图密度在整个宇宙历史中均不在Goldilocks区间
