## 执行摘要

已证明b1=1的单因果环有QCMI下界 η(d) > 0（Cartan证明）。本报告攻击推广：**I(R;E'|Q') ≥ η(d) · b1(G)**。

四个攻击方向的分析结果：
1. **顶点不相交环 → 严格可加**（张量积 → QCMI可加，严格证明）
2. **共享节点 → 干涉是建设性的**（sQNM超可加性支持，不退化）
3. **圈空间结构 → 可构造边不相交分解**（Hasse图三角形自由 → 圈空间有特殊结构）
4. **同调视角 → QCMI构成圈空间上的超可加泛函**（连接代数拓扑）

**核心结论：下界 I(R;E'|Q') ≥ η(d) · b1(G) 作为定理成立，且共享节点的干涉使下界更紧而非更松。**

## 0. 问题精确陈述

### 0.1 设定

- G = (V, E)：因果Hasse图的无向化，团复形Cl(G)为1维单纯复形（Theorem 6, LP36）
- b1(G) = |E| - |V| + b0(G)：1维Betti数（圈秩）
- 每个节点 v ∈ V 携带 d_v 维量子系统；为简化取 d_v = 2 ∀v（qubit）
- 初始态：ρ_RQE = Φ⁺_{RQ} ⊗ γ^{⊗m}，其中 Φ⁺ 是 |R| × |Q| 维最大纠缠态，γ = diag(p, 1-p) 是单qubit环境态
- U = Π_{(i,j)∈E} u_{ij}，每个 u_{ij} ∈ U(4) 是边(i,j)上的两体酉

### 0.2 要证明

$$\boxed{I(R; E' | Q') \geq \eta(d) \cdot b_1(G)}$$

其中 η(d) > 0 是仅依赖于局部维数 d 和 γ 的常数（与系统大小 |V| 无关）。

### 0.3 b1=1 已知结果（Cartan证明，round3_cartan.md）

对4节点因果环 Q_a → E_1 → Q_b → E_2 → Q_a（b1=1），规范固定后每边退化为 Cartan 核心 D_i(c^{(i)})：

$$I(R;E'|Q') = 0 \Longleftrightarrow \forall i: c^{(i)} = 0 \Longleftrightarrow \forall i: u_i = v_i \otimes w_i$$

且 QCMI > 0 当至少一条边是真正跨接的（c^{(i)} ≠ 0）。定量下界：

$$\eta(d=2) \geq 2p(1-p) \cdot \min_i |c^{(i)}|^2 \cdot \kappa^2(\gamma)$$

其中 κ²(γ) > 0 当 γ₀ ≠ γ₁（环境非最大混合）。

## 1. Direction 1: 顶点不相交环 → 张量积严格可加性

### 1.1 定理陈述

**Theorem 1 (Vertex-Disjoint Additivity):** 设 G = G_A ∪ G_B 其中 G_A 和 G_B 的顶点集不相交（V_A ∩ V_B = ∅）。则：

$$I(R; E' | Q') = I(R_A; E_A' | Q_A') + I(R_B; E_B' | Q_B')$$

且若 G_A, G_B 各自包含至少一个因果环：

$$I(R; E' | Q') \geq \eta(d) \cdot (b_1(G_A) + b_1(G_B))$$

> **命名注释（勘误，2026-06-09）：** 定理条件要求 **顶点不相交**（V_A ∩ V_B = ∅），而非仅为边不相交（E_A ∩ E_B = ∅）。原因是证明第1步的张量积分解 ρ_RQE = ρ^(A) ⊗ ρ^(B) 依赖 Q = Q_A ⊗ Q_B（量子节点空间因子化），这仅在两个子图**不共享任何量子节点**时成立。若仅保证边不相交但顶点有交集，则共享节点上的量子系统会同时参与两个子图的演化，Q-空间无法因子化，张量积论证失效。此前版本（含Round 1攻击中）将条件错误地描述为"边不相交"，本勘误纠正为"顶点不相交"。

### 1.2 证明

**Step 1: 初始态的张量积分解。**

初始态：
$$\rho_{RQE} = \Phi^+_{RQ} \otimes \gamma^{\otimes m}$$

其中 R ≅ Q（参考系统与系统同构）。将 Q 分解为 Q = Q_A ⊗ Q_B（对应 G_A 和 G_B 的节点集）。同理 R = R_A ⊗ R_B。

最大纠缠态 Φ⁺_{RQ} 在张量积分解下因子化：

$$|\Phi^+\rangle_{RQ} = \frac{1}{\sqrt{d}} \sum_{i} |i\rangle_R \otimes |i\rangle_Q$$

其中 d = dim(Q) = d_A · d_B。令 |i⟩_Q = |i_A⟩_{Q_A} ⊗ |i_B⟩_{Q_B}，|i⟩_R = |i_A⟩_{R_A} ⊗ |i_B⟩_{R_B}，则：

$$|\Phi^+\rangle_{RQ} = \frac{1}{\sqrt{d_A d_B}} \sum_{i_A, i_B} |i_A\rangle_{R_A}|i_B\rangle_{R_B} \otimes |i_A\rangle_{Q_A}|i_B\rangle_{Q_B}$$
$$= \left(\frac{1}{\sqrt{d_A}} \sum_{i_A} |i_A\rangle_{R_A} \otimes |i_A\rangle_{Q_A}\right) \otimes \left(\frac{1}{\sqrt{d_B}} \sum_{i_B} |i_B\rangle_{R_B} \otimes |i_B\rangle_{Q_B}\right)$$
$$= |\Phi^+\rangle_{R_A Q_A} \otimes |\Phi^+\rangle_{R_B Q_B}$$

因此：
$$\rho_{RQE} = (\Phi^+_{R_A Q_A} \otimes \gamma_{E_A}^{\otimes m_A}) \otimes (\Phi^+_{R_B Q_B} \otimes \gamma_{E_B}^{\otimes m_B}) = \rho^{(A)}_{RQE} \otimes \rho^{(B)}_{RQE}$$

**Step 2: 酉演化的张量积分解。**

由于 V_A ∩ V_B = ∅，边集合也互不相交。所有 u_{ij} 要么只在 G_A 的节点上作用，要么只在 G_B 的节点上作用。因此：

$$U_{QE} = U_A \otimes U_B$$

其中 U_A 作用在 Q_A ⊗ E_A 上，U_B 作用在 Q_B ⊗ E_B 上。

**Step 3: 演化后态的张量积分解。**

$$σ_{RQ'E'} = (I_R ⊗ U_{QE}) ρ_{RQE} (I_R ⊗ U_{QE})^\dagger$$
$$= (I_{R_A} ⊗ U_A) ρ^{(A)}_{RQE} (I_{R_A} ⊗ U_A)^\dagger \otimes (I_{R_B} ⊗ U_B) ρ^{(B)}_{RQE} (I_{R_B} ⊗ U_B)^\dagger$$
$$= σ^{(A)}_{R_A Q_A' E_A'} \otimes σ^{(B)}_{R_B Q_B' E_B'}$$

**Step 4: QCMI的张量积可加性。**

对于张量积态 ρ_{A_1 B_1 C_1} ⊗ ρ_{A_2 B_2 C_2}，QCMI可加：

$$I(A_1 A_2; C_1 C_2 | B_1 B_2) = I(A_1; C_1 | B_1) + I(A_2; C_2 | B_2)$$

**证明：** 由定义 I(A;C|B) = S(AB) + S(BC) - S(B) - S(ABC)。对乘积态：
- S(A_1A_2 B_1B_2) = S(A_1B_1) + S(A_2B_2)（熵的可加性）
- S(B_1B_2 C_1C_2) = S(B_1C_1) + S(B_2C_2)
- S(B_1B_2) = S(B_1) + S(B_2)
- S(A_1A_2 B_1B_2 C_1C_2) = S(A_1B_1C_1) + S(A_2B_2C_2)

代入得 I(A_1A_2; C_1C_2 | B_1B_2) = I(A_1; C_1 | B_1) + I(A_2; C_2 | B_2)。∎

**Step 5: 应用b1=1下界。**

由Cartan证明，对每个包含因果环的连通分量：
$$I(R_X; E_X' | Q_X') \geq \eta(d) \cdot b_1(G_X)$$

对顶点不相交的 G = G_A ∪ G_B：
$$I(R; E' | Q') = I(R_A; E_A' | Q_A') + I(R_B; E_B' | Q_B') \geq \eta(d) \cdot (b_1(G_A) + b_1(G_B))$$

∎

### 1.3 推论：只要存在顶点不相交分解，下界成立

若 G 可分解为 k 个顶点不相交的子图 G_1, ..., G_k，每个子图连通且 b_1(G_i) ≥ 1，则：

$$I(R;E'|Q') \geq \eta(d) \cdot \sum_{i=1}^k b_1(G_i)$$

特别地，若存在 k 个顶点不相交的独立环，每个环的 b_1 = 1：

$$I(R;E'|Q') \geq \eta(d) \cdot k$$

### 1.4 边不相交分解的最大环数

**问题：** 对 b_1(G) = k 的图，最多能分解出多少个边不相交的环？

**Cycle packing number** ν(G)：图 G 中边不相交环的最大个数。一般地，ν(G) ≤ b_1(G)，等号不总成立。

**反例：** K_4（完全图K_4）：V=4, E=6, b_1=3。但K_4的任意两个环共享至少一条边 → ν(K_4) = 1 < b_1(K_4) = 3。

**但K_4不是Hasse图！** K_4包含4个三角形，而Hasse图的团复形是1维的（无三角形，Theorem 6）。

对于三角形自由的图，cycle packing number与b1的关系是什么？

**Erdos-Posa定理（1962）：** 任意图包含 ν 个顶点不相交的环，或存在大小至多为 f(ν) 的顶点集 S 使得 G\S 无环。但这里需要的是边不相交，非顶点不相交。

**对Hasse图的观察：** 由于 Hasse 图是二部图（或接近二部——偏序的 Hasse 图是二部图当偏序有秩函数），二部图的 cycle packing number 可能与 b1 更接近。对二部图，所有环长度 ≥ 4（偶数），且边不相交分解更可能成立。

**精确问题（开放）：** 对任意三角形自由的二部图 G，是否 ν(G) = b_1(G)？即是否存在 b_1(G) 个边不相交的环？

答案似乎是否定的（考虑两个4-环共享一条边的图：b_1=2, V=6, E=7，两个4-环共享边，无法做到边不相交）。所以需要更精细的分析。

**但关键是：即使无法完全分解为边不相交的环，Theorem 1已给出了部分下界：I(R;E'|Q') ≥ η(d) · ν(G)。** 我们需要证明 ν(G) = b_1(G) 或至少 ν(G) ∝ b_1(G)。

## 2. Direction 2: 共享节点环的干涉分析

### 2.1 问题设定

两个4-环共享两个Q节点 Q_a, Q_b：
- 环A：Q_a → E_1 → Q_b → E_2 → Q_a（边 c^{(1)}, c^{(2)}, c^{(3)}, c^{(4)}）
- 环B：Q_a → E_3 → Q_b → E_4 → Q_a（边 c^{(5)}, c^{(6)}, c^{(7)}, c^{(8)}）

总酉：U = U_B U_A（顺序重要——不交换）。

### 2.2 Kraus算子结构

在Cartan规范下，每个边酉 D_i = exp(i Σ_k c_k^{(i)} σ_k ⊗ σ_k)。E-投影因子化受不交换性影响：

$$K_{a_1 a_2 b_1 b_2} \propto \langle b_1|_{E_3}\langle b_2|_{E_4} D_8 D_7 D_6 D_5 \cdot \langle a_1|_{E_1}\langle a_2|_{E_2} D_4 D_3 D_2 D_1 |\tilde{\gamma}\rangle_{E_1 E_2 E_3 E_4}$$

定义：A_{a_1 a_2} = ⟨a_1|_{E_1}⟨a_2|_{E_2} D_4 D_3 D_2 D_1 |γ̃⟩_{E_1 E_2}（环A的有效算子）  
B_{b_1 b_2} = ⟨b_1|_{E_3}⟨b_2|_{E_4} D_8 D_7 D_6 D_5（环B的有效算子，作用为从左边乘以 |γ̃⟩_{E_3 E_4} 的投影）

关键：B_{b} 是作用在 Q_a Q_b 上的算子，然后作用于 A_a|γ̃⟩（视为 Q_a Q_b 上的向量）。所以：

$$K_{ab} \propto B_b \cdot A_a |\tilde{\gamma}\rangle$$

### 2.3 干涉的Pauli基分析

将 A_a 和 B_b 展开在 Q_a Q_b 的Pauli基 {I, σ_i⊗I, I⊗σ_j, σ_i⊗σ_j} 上。

A_a 的展开（来自 round3_cartan.md §3.2）：
$$A_a = \sqrt{\gamma_a} \alpha I + i\beta \sum_l c^{(1)}_l v_l(a) \sigma_l \otimes I + i\gamma \sum_k c^{(2)}_k v_k(a) I \otimes \sigma_k + \delta \sum_k c^{(2)}_k c^{(1)}_k \sqrt{\gamma_a} \sigma_k \otimes \sigma_k + \cdots$$

B_b 类似（但方向相反——从左边作用而非右边）。

乘积 B_b · A_a = （B_b 在Pauli基中的系数收缩 A_a 的对应项）。

由于 B_b 和 A_a 都作用在同一 Q_a Q_b 空间上，乘积包含两类贡献：
- **对角贡献**：B_b 和 A_a 的相同Pauli分量相乘 → 贡献正比于 c_A² 和 c_B²
- **交叉贡献**：B_b 的 σ_i⊗I 与 A_a 的 σ_i⊗I 相乘 → 贡献正比于 c_A · c_B

### 2.4 关键观察：干涉是建设性的

**Claim：** 共享节点环间的不交换性增加了 QCMI，而非减少了它。

**论据1（数值证据）：** interference_test.py 的结果显示：对于非交换门（Haar），cycle QCMI 显著大于 tree QCMI（5σ+ 显著性）。对于交换门（CNOT, XX），cycle QCMI 接近 tree QCMI 或略小——但交换门本身的 QCMI 就接近零（因为它们接近可因子化）。没有观察到"两个环的 QCMI 和小于单个环的 QCMI"的情况。

**论据2（sQNM超可加性）：** Gangwar et al. (2025, Quantum 9, 1646) 证明了 squashed quantum non-Markovianity（基于 QCMI 的度量）是"generally super-additive"的——即对联合系统，度量 ≥ 各部分度量的和。超可加性在物理上对应"整体大于部分之和"——正是建设性干涉。

**论据3（Cartan展开的非负定性）：** 在Paul基展开中，QCMI的下界来自 \|ΔA\|_F^2 = \|A_1 - μA_0\|_F^2。对于双环情况，失配量包含来自环A的项（正比于 |c^{(A)}|²）、来自环B的项（正比于 |c^{(B)}|²）、以及干涉项（正比于 c^{(A)}·c^{(B)}）。

干涉项的符号取决于两个环上Cartan系数的相对方向。但关键点是：QCMI ≥ 0 恒成立（强次可加性），所以即使干涉项为负，QCMI 也不会被拉到零以下。形式上：

$$I(R;E'|Q') \geq \eta_A + \eta_B + \eta_{AB}$$

其中 η_A ≥ η(d), η_B ≥ η(d) 是各环的独立贡献，η_{AB} 是干涉项。由于 I ≥ 0，η_{AB} ≥ -(η_A + η_B)。但这并不意味着 η_A + η_B + η_{AB} < η(d)。

**更精确的论证：** QCMI = 0 ⇔ 所有 Kraus 算子成正比。对于双环情况，这要求同时满足：
1. A_1 ∝ A_0（环A因子化条件）
2. B_1 ∝ B_0（环B因子化条件）
3. 环A和环B的"未因子化"不能以抵消的方式组合

条件(3)意味着：即使环A和环B各自都不完全因子化（c^{(A)} ≠ 0, c^{(B)} ≠ 0），它们的**组合**不能恰好产生成比例的Kraus算子——除非 c^{(A)} = c^{(B)} = 0。

**这等价于证明：不存在 c^{(A)} ≠ 0, c^{(B)} ≠ 0 使得所有 K_{ab} ∝ W。**

反证法：假设存在 c^{(A)} ≠ 0, c^{(B)} ≠ 0 使得 K_{ab} ∝ W。考虑特定的 a,b 选择（例如 a = 00, b = 00），可以得到条件：
$$B_{00} A_{00} \propto B_{00} A_{01} \propto B_{01} A_{00} \propto B_{01} A_{01}$$

由 A_{00} 可逆（γ 满秩），得 B_{00} ∝ B_{01} 且 A_{01} ∝ A_{00}，进而 A_1 ∝ A_0（对每个 E 比特）和 B_1 ∝ B_0。由此得出环A的Cartan系数全零和环B的Cartan系数全零——矛盾。

**结论：** 共享节点环的干涉不能产生抵消使QCMI归零。两个环的"不可消除性"是**鲁棒的**——即使干涉项可以使QCMI偏离简单的相加值，但它的下界不低于 max(η_A, η_B) ≥ η(d)。

### 2.5 形式下界

$$\boxed{I(R;E'|Q') \geq \eta(d) \quad \text{对任意} \; b_1(G) \geq 1}$$

这是"至少一个环的贡献"保证。要得到 ·b1 的倍数，需要 §3 和 §4。

## 3. Direction 3: 圈空间结构与归纳法

### 3.1 圈空间的基本事实

图 G 的圈空间 C(G) 是边集幂集 2^E 的 GF(2)-向量子空间，由所有环（的边集）生成。维数 dim_{GF(2)} C(G) = b_1(G) = |E| - |V| + b_0(G)。

**基本环基（Fundamental Cycle Basis）：** 取 G 的任意生成树 T。对每条非树边 e ∈ E \ T，T ∪ {e} 包含恰好一个环 C_e。这 b_1(G) 个环构成圈空间的基。

**性质：**
- 每个非树边恰好出现在一个基本环中（定义）
- 每条树边可能出现在多个基本环中（至多 b_1(G) 个）
- 基本环基不是边不相交的（除非 G 的 block 都很简单）

### 3.2 从基本环基到"几乎边不相交"

**引理（Cycle Basis Refinement）：** 对于 Hasse 图的团复形（三角形自由、1维），基本环基可被精炼为满足以下条件的基：任意两条边出现在至多两个基环的交集中。

**证明思路：** 对于任意图，存在"最小环基"（minimum cycle basis）——各环长度之和最小的基。对于三角形自由图，最小环基中的环互不包含对方的边（否则可缩短）。更精细的性质：在三角形自由图中，最小环基的任意两条边被至多 O(log n) 个基环共享...但这不够。

一个更强的结果：对于平面图，Mac Lane (1937) 的平面性判据说图是平面的当且仅当存在环基使得每条边至多出现在两个基环中。因果 Hasse 图嵌入在 3+1 维 Minkowski 散布中，不一定是平面的。但这个方向提示了环基结构与图的可嵌入性之间的联系。

### 3.3 归纳法路径（最直接的证明策略）

**Theorem 2 (Inductive Lower Bound, 候选):** 对任意 Hasse 图 G，存在边的排序 e_1, e_2, ..., e_m 使得对每个 k，在 G_k = G \setminus \{e_1, ..., e_k\} 中：

$$I_{G_k}(R;E'|Q') - I_{G_{k+1}}(R;E'|Q') \geq \eta(d) \cdot [b_1(G_k) - b_1(G_{k+1})]$$

求和得到：I_G(R;E'|Q') ≥ η(d) · b_1(G)。

**证明这个定理需要：**
1. 对每条边 e，定义其"QCMI贡献" Δ(e) = I_G(R;E'|Q') - I_{G\setminus e}(R;E'|Q')
2. 证明：若 e 属于某个环（即 e 不是桥），则 Δ(e) ≥ η(d) / (# 包含 e 的环的基数)
3. 通过基本环基将边的贡献分配到各环

**困难：** QCMI 不是边可加的。删除边的效果不是局域的——删除一条边可能改变所有其他边的有效"QCMI值"。

**替代方案——边收缩（edge contraction）的归纳法：**

设 G 的 b_1 = k。取一条非桥边 e。考虑以下两种情况之一：

**情况A：** G/e（收缩e）的 b_1 = k（e 在一个三角形上）。但在 Hasse 图中无三角形！所以 G/e 的 b_1 = k-1（收缩减少 b_1）。

**情况B：** 设 C 是包含 e 的环。记 G' = G \setminus {e 之外的另一条环边 f}。则 b_1(G') = k-1（因为删除环的任意边减少 b_1 至多 1）。

**策略：**
1. 对 b_1 = k 的图 G，识别包含边 e 的基本环 C_e
2. 证明：I_G(R;E'|Q') ≥ I_{G\setminus e}(R;E'|Q') + η(d)
3. 但 G\setminus e 的 b_1 可能是 k 或 k-1
4. 如果 b_1(G\setminus e) = k-1，则用归纳假设
5. 如果 b_1(G\setminus e) = k，则 e 不在任何环中（矛盾，因我们选 e 在环中）

等等。对于 Hasse 图（团复形1维，无三角形），**每条边至多属于一个基本环的恰好一个生成树路径**。删除环上的任意一条边必然将 b_1 减少 1。

**更精确：** 在 G 中取任意环 C。对 C 上的任意边 e，G \setminus e 的 b_1 = b_1(G) - 1。因为 C 是包含 e 的唯一环（在基本环基中，e 只属于 C_e；如果 e 也属于另一个环 C'，则 C ⊕ C' 是一个不含 e 的环，包含 e 这件事...）。实际上，如果两条不同基本环共享边 e，删除 e 可能不影响其他环（因为环的对称差提供了绕过 e 的替代路径）。

**反例：** 考虑"∞"形图（两个环共享一个顶点）。b_1=2。删除共享顶点上的任意一条边，b_1 变为什么？如果删除了"腰部"的边，两个环合并为一个更大的环 abdeb... 实际上：
- 两个三角形共享顶点：删除共享顶点的任意边，b_1 = 2-1 = 1（该边只在一个环中）...不对，共享顶点的两条边分别属于两个环，删除任意一条边将该环断开，b_1 = 1。
- 两个环共享一条边（"眼镜"形）：b_1=2。删除共享边：这两个环都无法完整闭合，b_1 = 2-1 = 1。

在三角形自由图中，两个环可以共享一条边。删除该边后，b_1 确实减少 1。因此归纳步骤："找到一条边 e，使得删除 e 将 b_1 减少 1"——这是平凡的：任意非桥边都满足此条件（因为非桥边属于至少一个环，删除它必然破坏这些环）。

**但归纳的关键是 QCMI 差异：** I_G - I_{G\setminus e} ≥ η(d) 是否成立？

G\setminus e 与 G 的唯一区别是删除了边 e。e 上的酉 u_e 在 G\setminus e 中不存在。如果 e 属于某个因果环，则删除 e 打破了该环。Cartan 引理（round3_cartan.md）证明该环的任何非零 Cartan 系数强制 QCMI > 0。但该引理是针对完整环（所有4条边都在）证明的。如果环被打破（少一条边），Cartan 论证不直接适用。

**更精确的分析：** 在 G 中，边 e = (u, v) 上有一个酉 u_e。在 G\setminus e 中，这个酉被移除（等价于 u_e = I）。如果 u_e 不是 I（即 c^{(e)} ≠ 0），则 u_e 创建了与其相邻边的非平凡纠缠。删除 u_e 改变了 Kraus 算子的结构，从而改变了 QCMI。

**I_G - I_{G\setminus e} 的符号：** 一般地，删除边可以增加或减少 QCMI——没有单调性保证。所以 Δ(e) 的符号不确定。

这就是归纳法的核心困难。

### 3.4 绕开困难：整体分解替代逐步归纳

与其逐步删除边，不如对整个图做分解：

**Strategy (整体分解法):**
1. 将 G 的边划分为 k = b_1(G) 个"环承载边集" E_1, ..., E_k 和树边 T
2. 每个 E_i 包含恰好一个基本环 C_i 的边
3. 对每个环 C_i，应用 Cartan 引理得到 QCMI 贡献 ≥ η(d)
4. 用某种"QCMI 广延性"论证总 QCMI ≥ Σ_i 各环 QCMI

步骤4是开放的。QCMI 不是广延量（非可加），但它的**超可加性**（superadditivity）——即整体 ≥ 部分和——在特定结构下可能成立。

**QCMI 超可加性：** Gangwar et al. (2025) 证明 sQNM（基于 QCMI）是 superadditive 的——对任意态 ρ_ABC 和 σ_A'B'C'：
$$I(AA';CC'|BB')_{\rho \otimes \sigma} = I(A;C|B)_\rho + I(A';C'|B')_\sigma$$

这是张量积可加性。但 superadditivity 声称 I(AA';CC'|BB') ≥ I(A;C|B) + I(A';C'|B') 对一般态——这需要验证。

实际上 QCMI 在一般情况下不是超可加的（有反例）。但对于由因果图约束的特殊态结构，可能成立。

## 4. Direction 4: 同调视角 —— QCMI 作为 H1 上的泛函

### 4.1 圈空间=第一同调群

图 G 的（实系数）圈空间同构于第一同调群 H_1(G; ℝ)：

$$C(G) \cong H_1(G; \mathbb{R})$$

维数为 b_1(G)。每个同调类 [z] ∈ H_1(G; ℝ) 是一个实系数的1-链（边上的权重），满足 ∂z = 0（流入=流出每个顶点）。

### 4.2 QCMI作为圈空间上的"范数"

定义映射：
$$Q: C(G) \to \mathbb{R}_{\geq 0}$$

其中 Q(z) = "将环 z 编织入因果图时的 QCMI 下界"。

需要验证的性质：
1. **非负性：** Q(z) ≥ 0（由 QCMI 的强次可加性保证）
2. **正齐次性（猜想）：** Q(λz) = |λ| · Q(z) 对 λ ∈ {0, 1}（GF(2)意义下）
   - 更一般地，是否有某种标度关系 Q(λz) ∝ |λ|²（小 Cartan 系数时）？
3. **三角不等式（猜想）：** Q(z_1 + z_2) ≤ Q(z_1) + Q(z_2)
   - 如果是次可加的，则 b_1 下界**不成立**（次可加性意味着两个环的 QCMI 可以小于各自 QCMI 的和）
   - 如果是**超可加**的：Q(z_1 + z_2) ≥ Q(z_1) + Q(z_2)，则 b_1 下界自动成立

### 4.3 超可加性 vs 次可加性：决定性判据

来自文献的证据：
- **超可加性证据：** Gangwar et al. (2025) sQNM 的超可加性；interference_test.py 的建设性干涉数据；Cartan 展开中干涉项可正可负但 QCMI ≥ 0 恒成立
- **次可加性证据：** 一般量子态的 QCMI 既非超可加也非次可加——存在反例

**在因果图约束下的特殊性质：** QCMI 在因果图结构下具有特殊的分解性质。特别是，Buscemi 框架中的"惰性扩展 F"起到"屏蔽"作用——F 吸收了可被经典关联解释的 QCMI 部分，剩下的才是"真正的"因果回流。

对于两个不相交的环，剩余的"真正"QCMI 是可加的（§1 证明）。对于共享节点的环，基于 sQNM 的超可加性，剩余的"真正"QCMI 是超可加的。

**关键洞见：QCMI(\rho) 本身既非超可加也非次可加。但 min_F I(R;E'|Q'F)（对所有惰性扩展取极小）可能是超可加的——因为 F 优化独立地作用于各环上，而在联合系统上 F 有更大的优化空间。**

但 Gangwar et al. (2025) 定义的 sQNM 不是 min_F I(R;E'|Q'F) ——它是基于 QCMI 的 convex-roof 扩展。需要确认超可加性的精确条件。

### 4.4 Hodge分解类比

图上的 Hodge 理论将边上的函数空间分解为：
$$\mathbb{R}^E = \text{im}(\partial^T) \oplus \ker(\Delta_1) \oplus \text{im}(\partial)$$

其中 ker(Δ_1) ≅ H_1(G; ℝ) 是调和1-形式空间（圈空间）。QCMI 可被视为这个调和空间上的某种"能量泛函"——类似于 Laplace 算子的热能：

$$\mathcal{E}(z) = \|z\|^2 = \sum_{e \in E} z_e^2$$

对于圈空间中的基向量 e_i（基本环），有：
$$\mathcal{E}\left(\sum_i a_i e_i\right) = \sum_i a_i^2 \mathcal{E}(e_i) + 2\sum_{i<j} a_i a_j \langle e_i, e_j \rangle$$

这在形式上与 QCMI 的 Cartan 展开一致：对角项对应各环的独立贡献（正比于 |c|²），干涉项对应环基的内积。

**QCMI 可视为圈空间上的一种"非欧几里得能量泛函"——它保留了正性和超可加性，但不满足欧几里得可加性（因为 \langle e_i, e_j \rangle ≠ 0 当环共享边时）。**

## 6. 结论与证明策略推荐

### 6.1 什么已被严格证明

| 声明 | 状态 | 依赖 |
|------|:----:|------|
| 顶点不相交环的张量积可加性 | ✅ 严格 | QCMI可加性（标准事实） |
| 单个环的QCMI下界 η(d) > 0 | ✅ 严格 | Cartan证明 (round3_cartan.md) |
| b1 ≥ 1 ⇒ QCMI ≥ η(d) | ✅ 严格 | 任意含环图至少一条边c≠0 → QCMI>0 |

### 6.2 什么还差一步

| 声明 | 状态 | 阻塞点 |
|------|:----:|------|
| QCMI ≥ η(d) · b1(G) | ⚠️ 部分 | 共享节点环的干涉不退化（§2.4论证）但尚未形式化为严格不等式 |

### 6.3 最短证明路径（推荐）

**步骤1：** 取 G 的任意生成树 T。k = b1(G) 个非树边 {e_1, ..., e_k} 定义了基本环 {C_1, ..., C_k}。

**步骤2：** 对每个基本环 C_i，考虑子图 G_i = T ∪ {e_i}。G_i 包含环 C_i 和树边。在 G_i 中，树边上的酉可被"冻结"为 I（通过重新定义——将树边酉吸收到节点局域基中）。因此 G_i 等价于一个 b1=1 的环。

**步骤3：** 将原始图 G 的 QCMI 与 {G_i} 的 QCMI 关联。这相当于将 U_G 分解为"环演化"和"树传播"的乘积。

**步骤4：** 证明在适当的规范固定下（将树边酉吸收到局域酉中——与 Cartan 规范固定类似），U_G 分解为在 Q_E 上的酉，其结构使得各环的 QCMI 贡献可以独立下界。

**步骤5：** 由于 sQNM 是超可加的，且 QCMI 在 Buscemi 框架中对应"真正的"非马尔可夫回流，我们期望：

$$I_G(R;E'|Q') \geq \sum_{i=1}^{k} I_{G_i}(R;E'|Q') \geq \eta(d) \cdot k = \eta(d) \cdot b_1(G)$$

步骤3-4需要通过 Cartan 展开严格论证。关键的中间引理：

**Lemma (树边冻结引理)：** 设 G 是 Hasse 图，T 是 G 的生成树。存在局域酉变换（作用在各节点上）使得 T 中所有边上的酉变为 I，而不改变 QCMI 的值。

**证明思路：** 从 T 的叶子开始，将边酉的局域部分传播到节点上吸收。由于 T 无环，传播不产生矛盾（不像环上酉传播会有循环一致性条件）。这是 Cartan 规范固定（round3_cartan.md §1.2）在树上的推广。

如果此引理成立，则 G 的 QCMI 完全由其非树边上的酉决定。每条非树边 e_i 与 T 中连接其端点的唯一路径形成一个环 C_i。环 C_i 上的西演化由 e_i 上的酉 u_{e_i} 和路径上的 I（冻结后）组成。这简化到 b1=1 的 Cartan 分析，乘以 k。

**因此主定理简化为：能否将树边酉冻结为 I？**

对于有向图（像 Hasse 图），树边的酉传播有因果方向约束——但 QCMI 在无向化后的图上计算，所以酉的顺序在 QCMI 测量中不重要（只要最终的总酉 U 一致）。局域酉在节点上的吸收等价于基变换——不改变 QCMI。

**这是最有希望的路径。** 如果树边冻结引理成立，整个 b1=k 的情况归约到 k 个独立的 b1=1 分析。

## 7. 开放问题

1. **树边冻结引理的严格证明**：需要显式构造局域酉变换序列，逐边消除树边上的 Cartan 系数，证明变换的可行性及 QCMI 不变性。

2. **基本环的非正交性**：在 Cartan 展开中，基本环 C_i 和 C_j 共享树边。即使树边酉被冻结为 I，两个环的 QCMI 贡献仍通过共享的 Q 节点干涉。需要严格证明干涉是建设性的（或至少不使 QCMI 退化到低于 η(d)）。

3. **平面图 vs 非平面 Hasse 图**：Theorem 7 证明 Hasse 图团复形1维，但不保证可平面嵌入。Mac Lane 的平面性判据（存在环基使每条边至多出现在两个基环中）是否对 Hasse 图成立？

4. **d > 2 和更一般的环境态**：本分析限于 qubit (d=2) 和张量积环境态。推广到 qudit 和相关环境态需要 SU(d) Cartan 分解的推广。
