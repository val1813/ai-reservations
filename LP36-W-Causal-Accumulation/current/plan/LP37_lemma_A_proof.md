# Lemma A: 单因果环的QCMI不可消除性 — 证明框架

**PI合成 (B博士框架 + 补充)**

---

## Step 1: 精确恒等式（B博士）

由QMI守恒和链式法则，对初始态ρ_RQE = Φ⁺_RQ ⊗ γ_E：

$$I(R; E' | Q') = I(R; Q'E') - I(R; Q') = I(R; QE) - I(R; Q') = 2\log_2 d_R - I(R; Q')$$

因为初始RQ是纯态（Φ⁺），I(R;QE) = I(R;Q) + I(R;E|Q) = 2log₂d_R + 0 = 4（对两个Bell对）。

因此：
$$\boxed{I(R; E' | Q') = 4 - I(R; Q')}$$

**推论**：QCMI = 0 ⇔ I(R;Q') = 4 ⇔ R和Q'之间达到最大量子互信息。

---

## Step 2: 互补信道视角

将U_QE视为从Q到Q'的量子信道N（E是环境，初始态γ_E）。

纯化视角：引入F纯化γ_E，|ψ_γ⟩_EF = Σₖ √λₖ |k⟩_E|k⟩_F。

等距扩张 V: H_Q → H_Q' ⊗ H_E' ⊗ H_F：
$$V|φ⟩_Q = U_{QE} (|φ⟩_Q ⊗ |ψ_γ⟩_{EF})$$

信道：N(ρ_Q) = Tr_E'F[Vρ_QV†]
互补信道：N^c(ρ_Q) = Tr_Q'[Vρ_QV†]

对于最大纠缠输入Φ⁺_RQ：
- ρ_RQ' = (I_R ⊗ N)(Φ⁺_RQ) 是N的Choi态
- ρ_RE'F = (I_R ⊗ N^c)(Φ⁺_RQ) 是N^c的Choi态

由全态纯性：S(RQ') = S(E'F)（互补性）

I(R;Q') = S(R) + S(Q') - S(RQ') = 2log₂d_R + S(Q') - S(E'F)

最大可能：I(R;Q') ≤ 2log₂d_R + S(Q') ≤ 4（当d_R=4, d_Q=4）

**等号成立条件**：
(i) S(Q') = 2（Q'最大混态，即N是保迹的等距映射）
(ii) S(E'F) = 0（互补输出纯态，即N^c的输出独立于R）

条件(ii)等价于：N^c是"常值信道"——对任意输入ρ_Q，输出相同态。

---

## Step 3: Kraus算子条件

环境初态γ_E = γ⊗γ，其中γ = diag(p, 1-p)。Kraus算子：
$$K_{ab} = \sqrt{p_a p_b} \cdot {}_{E}\langle ab| U |ψ_γ\rangle_{EF}$$

但更简单：直接在计算基上展开U。
$$U = U_4 U_3 U_2 U_1$$
其中U₁ = U_{Q_aE₁}⊗I_{Q_bE₂}，U₂ = U_{E₁Q_b}⊗I_{Q_aE₂}，
U₃ = U_{Q_aE₂}⊗I_{Q_bE₁}，U₄ = U_{Q_bE₂}⊗I_{Q_aE₁}。

互补信道N^c输出纯态的条件：
$$(I_R ⊗ N^c)(Φ⁺_{RQ}) = \text{纯态}$$

这要求K_{ab}都正比于同一个等距映射（所有Kraus算子有相同的像空间）。

即：存在等距映射W: H_Q → H_E'F和复数λ_{ab}使得对所有a,b ∈ {0,1}：
$$K_{ab} = λ_{ab} · W$$

等价地：比例 K_{ab}/K_{00}（作为从Q到E'F的线性映射）与(a,b)无关。

---

## Step 4: 环拓扑的约束

U₁ = U_{Q_aE₁}⊗I：引入Q_a-E₁关联。
$$\langle a|_{E_1} U_1 |0\rangle_{E_1}... \text{依赖于} U_1 \text{的结构}$$

关键：U₁的矩阵元⟨a|⟨q'| U₁ |q⟩|0⟩编码了Q_a→E₁的信息转移。

经过完整的环U = U₄U₃U₂U₁后，⟨ab|_E U的形式是：

$$\langle b|_{E_2} \langle a|_{E_1} U = \sum_{q_a', q_b'} \text{[路径和]}$$

其中"路径和"包含两项贡献——来自环的两条不同路径：
1. Q_a → E₁ → Q_b → E₂
2. Q_a → E₂ → ...（如果存在）

**环拓扑的关键**：E₁和E₂各自与Q_a和Q_b以不同顺序耦合。具体地：
- U₁: Q_a与E₁纠缠
- U₂: 纠缠从E₁转移到Q_b
- U₃: Q_a（已被U₁改变）与E₂纠缠
- U₄: Q_b（已被U₂改变）与E₂纠缠

步骤U₃和U₁都涉及Q_a——但Q_a在U₁后已被改变。这种"共享节点"创建了依赖关系。

---

## Step 5: 证明QCMI > 0（核心引理）

**引理（环因子化阻碍）**：
若U = U₄U₃U₂U₁（每个U_i是作用在一条Q-E边上的2-qubit酉），且对所有a,b，算子⟨ab|_E U: H_Q → H_Q'都正比于同一个等距映射，则每个U_i必须是单qubit局域酉的乘积：U_i = V_i^Q ⊗ W_i^E。

**证明**：

设所有⟨ab|_E U正比于W。取两个不同E₁基矢a≠a'：
⟨a|_E₁⟨b|_E₂ U ∝ ⟨a'|_E₁⟨b|_E₂ U (对固定b)

展开U = U₄U₃U₂U₁：
⟨a|_E₁⟨b|_E₂ U₄U₃U₂U₁ = ⟨b|_E₂ U₄ · ⟨a|_E₁ U₃ U₂ U₁

等式⟨a|_E₁[...] ∝ ⟨a'|_E₁[...]意味着：插入E₁=|a⟩和E₁=|a'⟩后，得到的Q→Q'算子只差一个常数因子。

由于U₃和U₄不涉及E₁（U₃=Q_aE₂, U₄=Q_bE₂），我们有：
⟨a|_E₁ U = ⟨b|_E₂ U₄ · ⟨a|_E₁ U₃U₂U₁

当a变化时，⟨a|_E₁ U₃U₂U₁的比值不依赖a→这意味着U₂U₁在E₁自由度上的作用是"可因子化"的。具体地：
⟨a|_E₁ U₂U₁ = ⟨a|_E₁ U₂ · U₁（因为U₁包含E₁）

U₂ = U_{E₁Q_b}⊗I，所以⟨a|_E₁ U₂是作用在Q_b上的算子，取决于a。当a变化时，⟨a|_E₁ U₂不同。要使得⟨a|_E₁ U₃U₂U₁都正比，U₁必须"足够平凡"——具体地，U₁必须将不同E₁基矢映射到不产生Q空间差异的态。

通过迭代应用这个推理到所有四条边，得出每个U_i必须分解为U_i = V_i ⊗ W_i。

形式上：如果任何U_i产生Q-E纠缠（即它不是局域酉的乘积），则存在某个a,b使得⟨ab|_E U / ⟨00|_E U不是常数（依赖于Q输入态）。这违反了Kraus算子成正比的条件。□

**推论**：若至少一个U_i是"真正跨接"的（不是V⊗W形式），则QCMI > 0。

## Step 6: 定量下界

对于真正跨接的酉，需要量化"不能完全恢复"的程度。

**方法**：使用Fawzi-Renner的近似恢复定理。

设Δ = min_{所有等距信道} ||N - N_iso||⋄（钻石距离）。

Fawzi-Renner给出：I(R;Q') ≤ 4 - c·Δ²，其中c是普适常数。
因此：I(R;E'|Q') = 4 - I(R;Q') ≥ c·Δ² > 0。

**环境混合度的角色**：γ的纯度Tr(γ²)控制Kraus算子之间的"初始距离"。
η ∝ (1 - Tr(γ²)) · δ_cycle

其中δ_cycle是环拓扑的"几何激活因子"——环上酉不能同时被对角化的程度。

对于Haar随机酉：⟨δ_cycle⟩ ≈ 0.83（从数值η≈0.35和1-Tr(γ²)=0.42反推）。
最坏情况（对抗性选择的酉）：仍严格大于零（由环的代数结构保证）。
