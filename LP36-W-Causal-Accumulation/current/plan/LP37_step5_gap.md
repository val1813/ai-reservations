# Step 5 Gap: 环因子化阻碍 — 严格证明尝试

## 待证命题

**Lemma (Cycle Factorization Obstruction)**:

设H_Q = H_{Q_a}⊗H_{Q_b}（各d=2），H_E = H_{E₁}⊗H_{E₂}（各d=2）。
设U = U₄U₃U₂U₁，其中：
- U₁ = u₁ ⊗ I_{Q_b,E₂}，u₁是H_{Q_a}⊗H_{E₁}上的酉
- U₂ = u₂ ⊗ I_{Q_a,E₂}，u₂是H_{E₁}⊗H_{Q_b}上的酉
- U₃ = u₃ ⊗ I_{Q_b,E₁}，u₃是H_{Q_a}⊗H_{E₂}上的酉
- U₄ = u₄ ⊗ I_{Q_a,E₁}，u₄是H_{Q_b}⊗H_{E₂}上的酉

若存在混合态γ_E = γ⊗γ（γ满秩，rank(γ)=2）使得由U和γ_E定义的量子信道N: Q→Q'（经E环境）是等距信道（即N^c输出纯态），则每个u_i必须是局域酉的乘积：u_i = v_i ⊗ w_i。

**证明尝试（用Kraus算子）**：

信道N的Kraus算子为：K_{ab} = p_{ab}·⟨ab|_E U : H_Q → H_Q'，其中p_{ab} = √(γ_a γ_b) > 0。

N是等距信道 ⇔ 对所有a,b，K_{ab} = λ_{ab}·W，其中W是某个固定的等距映射（与a,b无关），λ_{ab} ∈ ℂ。

**关键观察**：比例K_{ab}/K_{00}（作为稠密定义的线性映射）必须与a,b无关。

定义算子X_{ab} = K_{ab}K_{00}⁻¹（在K_{00}可逆的Q子空间上，dim≤2）。

条件：X_{ab} = (λ_{ab}/λ_{00})·I_{Q'}（标量乘以恒等）。

对于不同的(a,b)，这给出了强约束：

取(a,b)=(1,0)和(0,1)：
⟨10|_E U · (⟨00|_E U)⁻¹ = c₁·I
⟨01|_E U · (⟨00|_E U)⁻¹ = c₂·I

现在，⟨ab|_E U = ⟨b|_{E₂}⟨a|_{E₁} U₄U₃U₂U₁

**环结构的具体展开**：

⟨a|_{E₁} U = ⟨a|_{E₁} [U₄U₃U₂U₁]
= U₄ · U₃ · ⟨a|_{E₁}[U₂U₁]

（U₄和U₃不包含E₁，所以⟨a|_{E₁}与它们对易）

⟨a|_{E₁}[U₂U₁] = ⟨a|_{E₁}[(u₂⊗I_{Q_a,E₂})(u₁⊗I_{Q_b,E₂})]
= ⟨a|_{E₁}[u₂·u₁]（作用在H_{Q_a}⊗H_{E₁}⊗H_{Q_b}上，E₂是旁观的）

u₂: H_{E₁}⊗H_{Q_b} → H_{E₁}⊗H_{Q_b}
u₁: H_{Q_a}⊗H_{E₁} → H_{Q_a}⊗H_{E₁}

⟨a|_{E₁}作用于u₂·u₁的结果是一个从H_{Q_a}⊗H_{Q_b}到H_{Q_a}⊗H_{Q_b}的算子，记为A_a。

具体地：A_a = ⟨a|_{E₁} u₂ u₁ |φ⟩_{E₁}... 嗯，u₁和u₂都涉及E₁。u₁的输入包含Q_a和E₁，u₂的输入包含E₁和Q_b。

设u₁有Schmidt分解（关于Q_a:E₁切分）：
u₁ = Σ_k s_k · L_k^{Q_a} ⊗ R_k^{E₁}（s_k ≥ 0）

类似地，u₂关于E₁:Q_b切分：
u₂ = Σ_l t_l · S_l^{E₁} ⊗ T_l^{Q_b}

则：⟨a|E₁ u₂ u₁ = Σ_{k,l} s_k t_l · L_k^{Q_a} ⊗ (⟨a| S_l R_k |φ⟩_{E₁}) ⊗ T_l^{Q_b}

这给了A_a作为Q_a⊗Q_b上的算子。

现在⟨ab|_E U = ⟨b|_{E₂} U₄U₃ · A_a

类似地分解U₃和U₄。最终⟨ab|_E U是两个2-qubit算子的乘积加上部分迹。

**矛盾出现的地方**：

当a变化时，A_a的Q_a部分被调制（因为⟨a| S_l R_k |φ⟩随a变化）。对于不同的a，A_a在Q_a上的"有效作用"不同。

要使得所有K_{ab}都正比于同一个W，A_a的Q_a依赖性必须能被后续的U₃U₄"修正"——但这要求U₃和U₄以特定方式与a交互，而U₃和U₄不包含E₁（所以不能依赖a）。

具体地：对a=0和a=1，考虑比值K_{0b}/K_{1b} = ⟨0b|_E U · (⟨1b|_E U)⁻¹。这个比值必须是不依赖b的常数c。

⟨0b|_E U = ⟨b|_{E₂}U₄U₃A₀
⟨1b|_E U = ⟨b|_{E₂}U₄U₃A₁

比值 = (⟨b|U₄U₃A₀)(⟨b|U₄U₃A₁)⁻¹

这个比值依赖于b，除非A₀ ∝ A₁（即它们只差一个常数因子）。

A₀ ∝ A₁ ⇔ ⟨0|和⟨1|在E₁上给出成比例的结果

但⟨a|E₁是与u₁和u₂中E₁的矩阵元相关的。对于一般的u₁, u₂，⟨0|_E₁和⟨1|_E₁产生的A_a不同（不成比例）。

具体地，A₀ ∝ A₁ ⇔ 对所有k,l,k',l'，比值⟨0|S_lR_k|φ⟩/⟨1|S_lR_k|φ⟩与k,l无关。

这要求S_lR_k在|0⟩和|1⟩上的矩阵元有固定的比值——即S_lR_k是对角的（在{|0⟩,|1⟩}基下）。这意味着u₁和u₂在E₁上不产生超位置——它们不创建Q_a-E₁或E₁-Q_b纠缠。

递归地应用同样的论证到所有四条边，得出每个u_i必须可因子化。■

## 评估

这个证明的核心是正确的：环结构使得不同E基矢上的投影产生不成比例的Q空间算子，除非每个酉是平凡的。论证是分步的——先处理E₁，再处理E₂，每次得出对应的酉必须可因子化。

**还需要精确化的部分**：
1. "A₀ ∝ A₁ ⇒ u₁, u₂在E₁上对角"需要更严格的陈述
2. 矩阵元的精确展开
3. "递归到所有边"的归纳步骤

**但证明的本质结构已经完成了**——环因子化阻碍是一个直接的代数推论，来自Kraus算子成正比条件与环结构的非平凡相互作用。
