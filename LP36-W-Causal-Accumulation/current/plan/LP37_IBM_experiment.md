# LP37 IBM量子计算机实验方案

**目标**: 在5-qubit IBM量子处理器上验证因果环的QCMI下界。
**核心预言**: 4节点因果环上的非可因子化酉演化产生QCMI>0，且符号由门的干涉类型决定。

---

## 一、量子电路设计

### 1.1 量子比特分配（5 qubits）

```
q0 (R_a/Q_a): 参考/系统A，通过CNOT与q1初始化Bell对后转为系统
q1 (Q_b):    系统B，通过CNOT与q0配对
q2 (E_1):    环境1
q3 (E_2):    环境2
q4 (measure): 辅助测量比特（可选，用于QCMI估计）
```

**技巧**: q0扮演双重角色——先作为R_a与q1制备Bell对，再作为Q_a参与循环。避免了6比特需求。

### 1.2 初始态制备

```
Step 0: 所有比特初始化为 |0⟩
Step 1: H(q0); CNOT(q0, q1)  → |Φ⁺⟩_{q0,q1} (R_a与Q_a的Bell对)
Step 2: 对E_1和E_2制备混合态:
        方法A（纯环境）: 保持|00⟩  → 最简单，预期QCMI≠0
        方法B（混合环境）: 与另一个Bell对纠缠后抛弃一个比特
```

**实际采用方法A**: E_1=E_2=|0⟩。对应CNOT环的已知基线QCMI=1。

### 1.3 因果环酉演化（4个CNOT门）

```
Step 3: CNOT(q0, q2)  // U1: Q_a → E_1 (q0=控制, q2=目标)
Step 4: CNOT(q1, q2)  // U2: Q_b → E_1 (q1=控制, q2=目标)
Step 5: CNOT(q1, q3)  // U3: Q_b → E_2
Step 6: CNOT(q0, q3)  // U4: Q_a → E_2
```

门序列深度=4。全部是CNOT（IBM原生门）。

### 1.4 干涉对比实验

**实验A（置换/经典）**: 上述CNOT环。预期QCMI>0（非对易CNOT的相长干涉，但CNOT在同基下可能是对易的...我们需要测试）。

**实验B（相位型）**: 将CNOT替换为CRz(π/2)或Rzz(π/2)门。预期QCMI<cycle QCMI（相消干涉）。

**实验C（纠缠型）**: 将CNOT替换为√SWAP（通过CNOT+单比特门实现）。预期QCMI>CNOT环（相长干涉）。

**实验D（对照）**: 单链Q_a→E_1→Q_b→E_2（去掉第4个门，即Step 6）。这是b1=0的对照。

### 1.5 可因子化对照

```
实验E（可因子化=QCMI应=0）:
所有CNOT替换为Identity → 期望QCMI=0
或: CNOT替换为H⊗H（可因子化但非平凡）→ 期望QCMI=0
```

## 二、QCMI测量

### 2.1 直接测量方案

QCMI = 4 - I(R;Q') = 4 - [S(R) + S(Q') - S(RQ')]

R=q0, Q'=q0和q1在门序列后的态。需要测量:
- ρ_R: 对q0做量子态层析（单比特，3个Pauli基×2^1=2个投影→共6次测量）
- ρ_Q': 对q0,q1做双比特量子态层析（2比特，3^2=9个基组合×4个投影→共36次测量）
- ρ_RQ': 同上（因为R=Q_a=q0，RQ'就是Q'）

**简化**: S(R)可以从初始Bell对直接计算=S(I/2)=1。只需测量S(Q')和S(RQ')（其中RQ'=q0,q1联合态）。

实际上，q0既是R又是Q_a。在初始Bell对|Φ⁺⟩_{q0,q1}之后，q0和q1的最大纠缠态使得S(q0)=1, S(q0,q1)=0。在循环酉演化后，S(q0,q1)会增长。

### 2.2 简化：用纯度代替熵

QCMI的真实值需要von Neumann熵（困难）。用**纯度代理**:

$$\tilde{QCMI} = \text{Tr}[\rho_{q0,q1}^2] - \text{Tr}[\rho_{q0}^2]$$

- 初始: ρ_{q0,q1}纯(Tr=1), ρ_{q0}=I/2(Tr=1/2) → QCMĨ = 1 - 0.5 = 0.5
- CNOT环后: ρ_{q0,q1}非纯(Tr<1) → QCMĨ增加

这个代理量可以用随机测量(Clifford randomized benchmarking)或直接做量子态层析测量。

### 2.3 最简方案: SWAP测试估计纯度

用**Hilbert-Schmidt SWAP测试**直接测量纯度:

```
电路加一个辅助比特q4:
- 制备两个拷贝的ρ_{q0,q1}
- 用q4控制两拷贝间的SWAP
- 测量q4的⟨Z⟩ → 正比于Tr[ρ²]
```

这需要量子比特重置和经典控制（IBM支持）。

### 2.4 对于5比特设备的实际可行方案

在ibm_sherbrooke或等价设备上:

**方案A: 量子态层析** (最直接)
- 门序列: 16个CNOT + 初始化(2个单比特门) = 深度~18
- 层析: 重复电路9次（3^2个Pauli组合），每次4096 shots
- 总时间: ~9×4096×(门时间+读出时间) ≈ 几分钟
- 从层析重建的密度矩阵计算S(Q')和S(RQ')

**方案B: 随机基准测试** (最稳健)
- 用Clifford随机化测量纯度
- 5比特设备上可行，文献有成熟协议

## 三、预期的可观测信号

### 3.1 定性预言

| 实验 | 门类型 | b1 | 预期QCMI |
|------|--------|:--:|:--:|
| A | CNOT环 | 1 | >0 (~1 bit) |
| B | Rzz(π/2)环 | 1 | < 实验A QCMI |
| C | √SWAP环 | 1 | > 实验A QCMI |
| D | CNOT链(b1=0) | 0 | ≈0 |
| E | 可因子化(I或可分解门) | 1 | ≈0 |

### 3.2 定量预言

对CNOT环+初始|00⟩_E:
- I(R;Q') = 3 → QCMI = 4 - 3 = 1
- S(q0,q1) = 1（实验应测到混合度为0.5的密度矩阵）

对链(b1=0, 3条CNOT):
- I(R;Q') → 4 → QCMI → 0
- S(q0,q1) → 0（RQ'纯）

### 3.3 可量化的信号对比

**最强的判别信号**: 比较实验A（b1=1环）和实验D（b1=0链）的Tr[ρ_{q0,q1}²]。
- 环: 纯度 < 1（混合态，QCMI>0）
- 链: 纯度 ≈ 1（纯态，QCMI≈0）

这两个值的差异是模型独立且不依赖熵估计精度的。

## 四、设备需求

| 参数 | 需求 | IBM开放设备状态 |
|------|------|:--:|
| 量子比特数 | 4(最小)或5(推荐) | ✅ (127+ qubit设备) |
| 连通性 | q0-q1-q2-q3需环状 | ✅ (heavy-hex支持，需SWAP) |
| 门保真度 | CNOT > 99% | ✅ (~99.5%) |
| 读出保真度 | > 98% | ✅ (~99%) |
| 电路深度 | ~20（含层析） | ✅ (相干时间~300μs) |

**推荐设备**: ibm_sherbrooke (127 qubits) 或 ibm_brisbane
**估算运行时间**: 30分钟（含不同实验条件的测量循环）

## 五、预期成果

如果实验成功:

1. **首次实验验证**: 因果拓扑约束量子非马尔可夫性
2. **可发表的定量比较**: CNOT环QCMI实验值 vs 理论预言1.0 bit
3. **干涉仪行为**: Rzz环的QCMI压低和√SWAP环的QCMI增强
4. **b1依赖性**: 链(b1=0)vs环(b1=1)的纯净度差异

这将是**第一个在量子硬件上实现的因果拓扑效应**——连接了代数拓扑、量子信息和实验物理。
