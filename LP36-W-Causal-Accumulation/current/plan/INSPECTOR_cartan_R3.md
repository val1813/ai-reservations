## FOCUS-1 (决定性): 系数结构 `coeff_l^(a) ∝ c^(1)_l · v_l(a)`

### 判定: 结论正确, 证明有缺口 [C-GAP-1]

### 1.1 Lemma 0 (闭型公式) 的验证

B博士在SA-2中自我承认Lemma 0错误。数值确认:

| c = (c_x, c_y, c_z) | |c| | H^2 = |c|^2 I? | 闭型D正确? |
|---|---|---|---|---|
| (0.3, 0, 0) | 0.300 | ✓ | ✓ (diff=1e-16) |
| (0, 0.3, 0) | 0.300 | ✓ | ✓ |
| (0, 0, 0.3) | 0.300 | ✓ | ✓ |
| (0.3, 0.4, 0) | 0.500 | ✗ | ✗ (diff=0.12) |
| (0.3, 0, 0.4) | 0.500 | ✗ | ✗ (diff=0.12) |
| (0.3, 0.4, 0.5) | 0.707 | ✗ | ✗ (diff=0.32) |

**根因:** H = Σ c_k σ_k⊗σ_k 在魔基中对角化, 但对角元为 (c_x+c_y+c_z, -c_x+c_y-c_z, c_x-c_y-c_z, -c_x-c_y+c_z)。四个对角元一般不相等 → H^2 不正比于 I。仅当至多一个 c_k 非零时 H^2 = |c|^2 I。

### 1.2 σ_l⊗I 扇区系数结构: 数值验证

**关键正发现:** 对20组随机 (c1, c2), `coeff_l^(1)/coeff_l^(0)` 在所有 l=x,y,z 上精确匹配 `v_l(1)/v_l(0)` (精度 < 1e-10)。

这意味着系数结构为:
```
coeff_l^(a) = G_l(c1, c2) · v_l(a)
```
其中 G_l(c1, c2) 对 a=0 和 a=1 是同一个函数。此结构即使在 Lemma 0 错误的情况下依然成立。

**关键负发现:** G_l(c1, c2) **不是** 简单的 `iβ · c^(1)_l`。数值验证:
- 当 c1_x = 0 但 c1_y, c1_z ≠ 0 时, XI (σ_x⊗I) 系数 **非零**
- 例如 c1=(0, 0.3, 0.3), c2=(0.5, 0.3, 0.2) 时: XI=0.0393 (来自 σ_yσ_z = iσ_x 的BCH交叉项)
- G_x, G_y, G_z 对应不同的 l 取不同值 (相对差异约 41%)

**这对证明的意义:** B博士在§3.4的推理:
```
c^(1)_l · v_l(1) = μ · c^(1)_l · v_l(0)  ⇒  c^(1)_l · (v_l(1) - μ v_l(0)) = 0
```
应该修正为:
```
G_l(c1,c2) · v_l(1) = μ · G_l(c1,c2) · v_l(0)  ⇒  G_l(c1,c2) · (v_l(1) - μ v_l(0)) = 0
```

由于 v_l(1) - μ v_l(0) ≠ 0, 得到 G_l(c1,c2) = 0 (对所有 l)。但这**不直接推出** c^(1)_l = 0 —— G_l 可以因为不同 c1 分量的高阶BCH交叉项相互抵消而为零。

### 1.3 系统搜索: G_l = 0 的非平凡解

数值优化找到了**大量** G_l=0 的非平凡解 (σ_l⊗I 扇区完全消失, |c1|>0, |c2|>0)。例如:
- c1=(1.51, 1.65, 1.54), c2=(1.57, -3.14, -0.25): σI扇区=0, |c1|=2.71
- c1=(2.67, 0.93, -0.81), c2=(2.87, 1.57, -3.14): σI扇区=0, |c1|=2.94
- 等等 (30/30次优化运行都找到了非平凡解)

**但是:** 对于这些 G_l=0 的点, **完整条件** A_1 = μA_0 **不满足** (‖A_1-μA_0‖_max ≈ 0.5-1.0)。

这说明: I⊗σ_k 扇区和其他扇区施加了独立于 σ_l⊗I 扇区的约束, 而这些约束**阻止**了非零Cartan系数同时满足所有扇区条件。

### 1.4 决定性测试: 完整条件 A_1 = μA_0

**系统搜索结果:**
- 100次随机采样 (c_k ∈ [0, π/4]): **无**非平凡解
- 216次特殊值组合 (c_k ∈ {0, π/4, π/2, π, 3π/2, 2π}): 仅在 Cartan系数为 0 或 π 的整数倍时 A_1=μA_0
- 100次全局优化 (从随机初值梯度下降): **无**非平凡解 (所有收敛到 |c1|+|c2| < 0.01 或 c_k 为 π/2 倍数)

**π/2 解的物理地位:** c_k = π/2 时, D = exp(i·π/2·σ_k⊗σ_k) = i·σ_k⊗σ_k, 这是**因子化**的酉 (可写为单qubit酉的张量积)。在Cartan分解的Weyl群作用下, π/2 ≡ 0 (模规范等价)。这些不是反例。

**Canonical域 [0, π/4] 内:** 唯一解是 c1 = c2 = (0,0,0)。这与B博士的定理结论一致。

### 判定: ✅ PASS (严格正确)

### 2.1 比率计算验证

B博士的 v_k(a) 表格 (Appendix B):

| | a=0 | a=1 | 比值 r_k |
|---|-----|-----|----------|
| k=x | √γ₁ | √γ₀ | √(γ₀/γ₁) = s |
| k=y | i√γ₁ | -i√γ₀ | -√(γ₀/γ₁) = -s |

- ⟨0|σ_x|γ̃⟩ = ⟨0|σ_x(√γ₀|0⟩+√γ₁|1⟩) = ⟨0|(√γ₁|0⟩+√γ₀|1⟩) = √γ₁ ✓
- ⟨1|σ_x|γ̃⟩ = ⟨1|(√γ₁|0⟩+√γ₀|1⟩) = √γ₀ ✓
- ⟨0|σ_y|γ̃⟩ = ⟨0|(-i√γ₁|0⟩+i√γ₀|1⟩?) 

verify: σ_y|0⟩ = i|1⟩, σ_y|1⟩ = -i|0⟩
⟨0|σ_y|γ̃⟩ = ⟨0|(i√γ₁|1⟩ - i√γ₀|0⟩) = -i√γ₀? No.

重新计算: σ_y = [[0,-i],[i,0]]
⟨0|σ_y = [0,-i], |γ̃⟩ = [√γ₀, √γ₁]^T
⟨0|σ_y|γ̃⟩ = -i√γ₁ ✓ (B博士的 i√γ₁... 有符号争议但比值不变)

检查: v_y(0) = ⟨0|σ_y|γ̃⟩ = -i√γ₁ vs B博士的 i√γ₁
但 v_y(1) = ⟨1|σ_y|γ̃⟩ = i√γ₀ vs B博士的 -i√γ₀

比值 v_y(1)/v_y(0) = (i√γ₀)/(-i√γ₁) = -√(γ₀/γ₁) = -s ✓ (相同)

### 2.2 比率互异验证

对 γ₀≠γ₁ (s≠1):
- r_x = s
- r_y = -s  
- r_z = -1/s
- μ = 1/s (来自 I⊗I 扇区匹配)

六个两两比较:
```
r_x ≠ r_y:  s ≠ -s (s>0) ✓
r_x ≠ r_z:  s ≠ -1/s (s≠1) ✓
r_x ≠ μ:    s ≠ 1/s (s≠1) ✓
r_y ≠ r_z:  -s ≠ -1/s (s≠1) ✓
r_y ≠ μ:    -s ≠ 1/s (总成立, 符号相反) ✓
r_z ≠ μ:    -1/s ≠ 1/s (总成立, 符号相反) ✓
```

**全部六个比率两两互不相同。** ✓

### 2.3 比率论证的核心作用

在修正后的系数结构 `coeff_l^(a) = G_l(c1,c2) · v_l(a)` 下:
```
coeff_l^(1) = μ · coeff_l^(0) ⇒ G_l · v_l(1) = μ · G_l · v_l(0)
⇒ G_l · (v_l(1) - μ v_l(0)) = 0
```

由于 v_l(1) ≠ μ v_l(0) (比率互异), 必须有 G_l = 0。这是**严格的**——不依赖 c^(1)_l 的简单比例。

问题转移到: G_l(c1,c2) = 0 ∀l 在规范域中是否强制 c^(1) = c^(2) = 0? 这回到 [C-GAP-1]。

## FOCUS-3: 规范固定

### 判定: ✅ PASS (论证合法)

### 3.1 局域酉吸收与QCMI不变性

B博士声称"QCMI在局域酉变换下不变, 因为局域酉不产生Q-E纠缠"。需要区分:

1. **Q上的局域酉:** QCMI = S(ρ_RQ) + S(ρ_Q) - S(ρ_R) - S(ρ_{RQ})... 局域酉变换保持von Neumann熵不变 → QCMI不变 ✓
2. **E上的局域酉:** 环境态的局域基变换不影响偏迹 → QCMI不变 (偏迹对E算子的循环性) ✓
3. **跨边传播:** L_1^{Q_a} 传播到 u_3 的输入端时, 被吸收进 u_3 的右局域酉因子 R_3^{Q_a}。这是**酉等价变换**——Q_a 的局域基变换被推迟到下一个2-qubit门, 而该门的 Cartan 核心在局域酉相似变换下不变 (模 Weyl 群)。✓

### 3.2 Cartan核心是否被改变?

关键检查: 局域酉的传播是否改变了 Cartan 核心 D_i 的**形式** (而非仅是局域因子)?

Cartan分解: u = (L⊗L') · D · (R⊗R')。局域酉传播过程:
```
u_3' = (L_3⊗L_3') · D_3 · (R_3⊗R_3') · (L_1^{Q_a}⊗I)
     = (L_3⊗L_3') · D_3 · (R_3 L_1^{Q_a} ⊗ R_3')
     = (L_3⊗L_3') · D_3 · (R_3'^{Q_a} ⊗ R_3'^{E_2})
```

然后 R_3'^{Q_a} = R_3 L_1^{Q_a} 被吸收到规范固定中。D_3 **不变**——因为局域酉只修改了 R 因子, 而 Cartan 核心 D 不受左右局域酉的影响 (这是 Cartan 分解的定义性质)。

### 3.3 结论

规范固定合法。QCMI 精确不变, Cartan 核心形式不变, 局域酉仅改变规范固定过程中被消除的 L/R 因子。这是量子信息中 KAK 分解的标准用法。
