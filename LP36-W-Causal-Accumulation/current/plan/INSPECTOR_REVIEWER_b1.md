## 第一部分: INSPECTOR 检查

### INSPECTOR-1: 边不相交 → 酉因子化 — 共享Q节点问题

**文档声称 (Case 1 Step 1):**
"边不相交 → 每个环作用于不重叠的QE子系统上"

**检查结果: 部分真，有重大限定条件未声明**

边不相交环确实作用在不重叠的**边集**上（这是"边不相交"的定义）。但是否作用在不重叠的**QE子系统**上，取决于图的节点结构：

- **情况A (顶点不相交环):** 两个环的 V 集完全不相交 → 各环的 Q 节点集和 E 节点集均不相交 → QE 子系统完全不重叠 → Step 1 成立。
- **情况B (边不相交但共享Q节点):** 两个环共享一个 Q 节点（例如两条不同的环路径经过同一个 Q 节点）但边不相交。此时两个环作用在**重叠的 Q 子系统**上（共享的 Q 节点是两者共用的 Hilbert 空间）。Step 1 声称"不重叠的 QE 子系统"失败。

**共享 Q 节点 + 边不相交的图论可能性:**

考虑一个"8字"形图变体：两个环仅通过一个 Q 节点相连，没有共享边。设 Q_a 是共享节点，环A = Q_a → E₁ → Q_b → E₂ → Q_a，环B = Q_a → E₃ → Q_c → E₄ → Q_a。两个环的边集 E_A = {Q_a-E₁, E₁-Q_b, Q_b-E₂, E₂-Q_a} 和 E_B = {Q_a-E₃, E₃-Q_c, Q_c-E₄, E₄-Q_a} 不相交。但它们共享 Q_a 节点 → 初始态中 Q_a 的 Hilbert 空间是两者共用的 → ρ_{RQE} 不能分解为张量积。

**结论: Case 1 的"可严格证明"仅适用于顶点不相交环（V_A ∩ V_B = ∅），不适用于边不相交但共享 Q 节点的环。** 文档使用"边不相交"一词，但证明实际上需要"顶点集不相交"（这是 b1_additivity.md Theorem 1 的精确前提条件）。文档没有区分这两种情况，构成过度声张。

**判定: WARNING** — 证明步骤的可用范围比声张的窄。

### INSPECTOR-2: QCMI 张量积可加性 — "数值精确验证"的检查

**文档声称:**
"QCMI张量积可加性: 两独立副本QCMI = 2×单副本 [数值精确验证]"

**检查结果: 数值验证范围极其有限，不支撑一般性声张**

从 available 数据追溯：

1. **b1_additivity.md §5.1 (b1_scaling.py):** 2Cycle 的 QCMI 列为 "?" — 未测量。b₁=3 的 QCMI = 1.8509（干涉仪成果记录 §B），但单个环的 QCMI 值没有在相同的 b₁=1 设定下独立测量以比较。

2. **已有的 b₁=1 数值数据 (干涉仪成果记录 §A):** 不同门类型的 QCMI_cycle 从 0.7355 (wHaar 0.06) 到 3.2387 (Haar full)，跨度 ~4.4 倍。在 b₁=1 中没有单一的基准值可以乘 2 或 3 来检验可加性。

3. **"两独立副本 QCMI = 2×单副本"的数值证据来源不明。** 经过对所有已读文件（cold_audit_data.md, 干涉仪成果记录, b1_additivity.md, b1_scaling.py 表格）的交叉检索，没有找到"同一图的两个独立副本的 QCMI 等于 2×单个副本"的数值记录。声张的"数值精确验证"可能指的是 QMI 的张量积可加性（标准事实）而非因果环 QCMI 的可加性——名称混淆。

4. **b1_additivity.md §1.2 Step 4 的 QCMI 可加性证明** 是对乘积态的标准推导，在数学上是严格的（对原始 I(A;C|B)，非对 min_F 版本）。这不需要数值验证。

**结论:** "QCMI张量积可加性"作为定理声明可以通过标准推导严格成立（对原始 QCMI，非 squashed 版本）。但"数值精确验证"的引用无法在现有数据中定位。更重要的是，**声张没有区分原始 QCMI 和 Buscemi squashed N_sq**——两者的张量积行为不同。

**判定: WARNING** — 证明正确（对原始 QCMI），但数值验证引用无法追溯。squashed 版本的推广未处理。

### INSPECTOR-3: Case 1 Step 4 — "QCMI在张量积上可加（熵可加性 + 酉因子化保证）". 这是否正确？

**这是整个审查的核心问题。需要区分两个不同的量:**

**量A: 原始条件互信息 I(R;E'|Q')**
- 对乘积态 ρ = ρ₁ ⊗ ρ₂，可加性成立：I(R₁R₂;E₁'E₂'|Q₁'Q₂') = I(R₁;E₁'|Q₁') + I(R₂;E₂'|Q₂')
- 证明: 由 CMI 定义和熵在张量积上的可加性 — 标准量子信息结果
- b1_additivity.md §1.2 Step 4 给出的推导正确
- **判定: 正确。** 

**量B: Squashed non-Markovianity N_sq = min_F I(R;E'|Q'F)**
- Buscemi 框架的"惰性扩展 F"极小化是关键操作
- 对乘积态: N_sq(ρ₁⊗ρ₂) = min_F I(R₁R₂;E₁'E₂'|Q₁'Q₂'F)
- **问题:** min 在 F 上取，而 F 可以是作用在整个联合系统上的任意量子信道。联合优化一般来说允许比分别优化各自系统更小的值（因为 F 可以产生子系统之间的量子关联来"解释掉"部分 QCMI）。
- 因此: N_sq(ρ₁⊗ρ₂) ≠ N_sq(ρ₁) + N_sq(ρ₂) 在一般情况下不成立
- Gangwar et al. (2025) 声称 sQNM 是超可加的 (N_sq ≥ sum)，但这是不等号方向（整体 ≥ 部分和），不是等式

**结论:**

- **对原始 I(R;E'|Q'):** Step 4 正确。张量积态上 CMI 严格可加。
- **对 Buscemi N_sq:** Step 4 不正确（如果文档隐含地指 N_sq）。需要额外的超可加性论证（Gangwar 2025），且即使超可加性成立，也只能得到 N_sq ≥ Σ N_sq_i，而非等式。
- **LP37_b1_generalization.md 的模糊性:** 文档通篇使用"QCMI"，未区分原始 CMI 和 squashed 版本。Case 1 证明使用的可加性只对原始 CMI 成立。如果最终目标是证明 N_sq ≥ k·η（而不是原始 I(R;E'|Q') ≥ k·η），则证明链断裂——η 本身是从 Fawzi-Renner 导出的原始 CMI 下界，而 N_sq ≤ 原始 CMI（因为 min_F 减小值），所以原始 CMI 的下界不自动传递到 N_sq。

**判定: BLOCK** — 对原始 CMI 正确，但对 N_sq（Buscemi 框架的核心量）的可加性是一个未解决的开放问题，或至少需要额外的超可加性论证。文档未做此区分。

### INSPECTOR-4: 保守下界 QCMI ≥ η — 为什么不能所有环同时相消到零？

**文档声称 (Case 2):**
"保守下界: QCMI ≥ η（最坏情况：所有环相消干涉，只剩单环贡献）"

**检查结果: 逻辑上成立但物理内容极度稀薄**

**逻辑链路:**
1. b₁(G) ≥ 1 → G 包含至少一个环 C
2. 环 C 的边上的酉演化（如果有任何一条边的 Cartan 系数非零）→ QCMI > 0
3. QCMI ≥ η(d) 是单环的下界（假设 Cartan 系数 ≥ 某个最小值）
4. 其他环的存在不能使 QCMI 降到 η(d) 以下——因为 QCMI ≥ 0（强次可加性）且额外环只能增加或保持 QCMI

**但第4步有微妙之处:** 额外环的干涉是否可以**减少**总 QCMI？干涉仪实验数据显示 bonus 可以为负（对易门: 环 QCMI < 树 QCMI）。但 η 是"至少一个环"的贡献，不是相对于树的 bonus。

**更精确的论证:** 即使所有 k 个环的干涉相消，QCMI 仍 ≥ 某个单环的最小贡献。这成立的必要条件是：QCMI 作为"环贡献之和"不能互相抵消到零。b1_additivity.md §2.4 给出了反证法：如果所有 k 个环的 QCMI 总贡献为零，则所有 Kraus 算子成正比 → 所有 Cartan 系数为零 → 所有酉可因子化 → 无真正因果回流。

**但是这个反证法——**
- 对 b₁=2 (两个共享节点环) 有 sketch（b1_additivity.md §2.4）
- 对 b₁=k 的一般推广需要归纳（b1_additivity.md §2.4 末尾标注"从 2 环推广到 k 环是直接但技术上繁琐的归纳"）
- **未给出严格归纳证明**

**结论:** η 作为下界在逻辑上是安全的（如果没有一个环产生 QCMI，那就根本没有因果环——矛盾）。但这个下界之所以安全，正是因为它的保底性极高和物理内容稀薄。它等价于说"如果一个图有环，QCMI ≥ 某个正数"——这已经在 b₁=1 的 CFOL 中被证明。b₁>1 情形下声称 QCMI ≥ η 并没有增加任何新信息，因为 b₁=1 已经保证了这一点。

**判定: PASS (逻辑上安全)** — 但物理内容稀薄。见 REVIEWER-3。

## 第二部分: REVIEWER 攻击

### REVIEWER-1: 边不相交环的"严格证明"是空洞的

**攻击陈述:**
证明声称"QCMI在张量积上可加"，但 squashed NM 定义中的 min_F 是否在张量积上可加是一个已知的开放问题。

**攻击分析:**

**第一层: 原始 CMI 可加性。** 边不相交环（顶点集不相交）→ ρ_RQE 和 U_QE 都因子化为张量积 → σ_RQ'E' 是乘积态 → 原始 I(R;E'|Q') 在乘积态上可加。这部分是正确的。b1_additivity.md §1.2 给出的证明完全有效。

**第二层: Buscemi N_sq = min_F I(R;E'|Q'F)。** 这是关键。即使原始 CMI 可加，N_sq 的可加性不自动成立。具体地：

```
N_sq(σ₁⊗σ₂) = min_F I(R₁R₂; E₁'E₂' | Q₁'Q₂'F)

而 N_sq(σ₁) + N_sq(σ₂) = min_{F₁} I(R₁; E₁' | Q₁'F₁) + min_{F₂} I(R₂; E₂' | Q₂'F₂)
```

令 F* = argmin_F I(R₁R₂; E₁'E₂' | Q₁'Q₂'F)。定义 F₁ = Tr₂ ○ F* ○ (· ⊗ |0⟩⟨0|₂)（将 F* 限制到子系统1）和类似的 F₂。一般来说 I(R₁R₂; E₁'E₂' | Q₁'Q₂'F*) ≠ I(R₁; E₁' | Q₁'F₁) + I(R₂; E₂' | Q₂'F₂)，因为 F* 可能在两子系统之间产生关联。

**N_sq 的可加性是否成立？** 据我所知，squashed entanglement (Christandl-Winter 2004) 的张量积可加性是一个已解决的开放问题——squashed entanglement 被证明在张量积上可加。但 squashed non-Markovianity (Gangwar et al. 2025) 的相应性质是否成立，文献中尚不明确。作者引用 Gangwar 的超可加性，但超可加性给出的是 N_sq ≥ sum，而非 N_sq = sum。对于下界目的，N_sq ≥ Σ N_sq_i ≥ k·η 是足够的（超可加性方向正确）。但需要确认：
- Gangwar 的超可加性是否适用于这个具体的因果图设定
- 超可加性是否已被严格证明（vs 仅是"generally" true）

**第三层: 如果作者实际使用的是原始 CMI 而非 N_sq。** 重新检查：LP37_b1_generalization.md 通篇使用 "QCMI"，未出现 "N_sq"。CFOL 的证明使用的也是原始 I(R;E'|Q')。如果是原始 CMI——那么 η 下界适用，可加性成立，Case 1 证明严格。如果是 N_sq——则存在上述 gap。

**攻击有效性评估:** 需要作者澄清他们声称的"QCMI"究竟是原始 CMI 还是 Buscemi squashed N_sq。如果是原始 CMI，则攻击无效。如果是 N_sq，则攻击有效——N_sq 的张量积可加性不能从原始 CMI 的可加性自动推出。

同时注意：如果作者的目标量是原始 CMI（非 squashed），那么这个量本身不是 Buscemi 的"真正非马尔可夫性"度量——因为原始 CMI 包含了可以被经典关联（惰性扩展 F）屏蔽的部分。这意味着定理声称的"因果拓扑强制非马尔可夫性"对应的量是原始 CMI 而非 N_sq，从而需要澄清物理诠释。

**判定: WARNING** — 核心概念（QCMI vs N_sq vs 原始 CMI）定义模糊。如果澄清为原始 CMI 则可加性成立；如果隐含指 N_sq 则存在 gap。

### REVIEWER-2: 共享节点环 — QCMI ~1.7-1.8× 而非 2× → b₁ 作为控制参数是误导性的

**攻击陈述:**
"QCMI ~1.7-1.8× 而非 2×" 说明 QCMI 不是 b₁ 的线性函数。b₁ 作为 QCMI 的控制参数是误导性的。

**攻击分析:**

共享节点环的数值数据显示 QCMI(2cycle) / QCMI(1cycle) ≈ 1.7-1.8（来自 b1_additivity.md §2.1 和干涉仪成果记录）。

线性标度假说预测比值为 2×。观察到 ~1.7-1.8×：
- 偏差: 10-15% 低于线性预测
- 可能解释: 共享节点干涉（相消或相长）
- 文档的推理: "相消干涉 → QCMI < kη（压低）"——即偏差朝向正确的方向

**攻击是否成立取决于文档的最终声张:**

1. 如果文档声称 QCMI = η·b₁（等式）——则 1.7-1.8× ≠ 2× 是反例。攻击成立。
2. 如果文档声称 QCMI ≥ η·b₁（下界）——则 1.7-1.8× ≥ 1× (单个 η) 且可能 ≥ 2× η（如果 1.7η > 2η... 等等，1.7 > 2 是矛盾。所以 1.7-1.8× 的参照物是什么？）
3. 数值数据: b₁=1 的 QCMI = 1.0609, b₁=3 的 QCMI = 1.8509 (干涉仪成果记录 §B)。比值 = 1.75。η₀ = 0.180。η₀ × b₁(3) = 0.54。实验 1.85 ≫ 0.54——下界满足但极度宽松。

**核心问题:** 文档在 Case 2 中说 "QCMI(2cycle) ≈ 1.7-1.8 × QCMI(1cycle)" 然后将其归类为"线性标度的数值支持"和"共享节点干涉压低"。但 1.7-1.8× 这个数据——
- 如果 b₁=1 的 QCMI 本身高度依赖门类型（从 0.74 到 3.24，4.4 倍范围），那 1.7 倍什么？
- 共享节点图的 b₁=3 的 QCMI 期望如果是 3×η₀ = 0.54，那 1.85 是 3.4 倍——"线性标度"的脆弱性在此暴露

**攻击的核心力度:** 将 QCMI 表述为 b₁ 的线性函数（即使作为下界），同时提供的数据显示的是另一回事——1.7-1.8× 而非 2× 表明的是偏离线性，而非支持线性。将"偏离线性"作为"共享节点干涉压低"来框架化是正确的物理，但最终结果就是：**b₁ 不是 QCMI 的唯一或主要决定因素。** 门类型（Cartan 系数大小和方向）对 QCMI 的影响远大于 b₁。

**判定: WARNING (对文档) / 攻击 PARTIALLY VALID** — b₁ 作为"控制参数"确实是误导性的，但文档的正确角色是将 b₁ 作为"拓扑下界"参数（保底界），而非"标度假说"。文档的语言模糊了这两者的区别。

### REVIEWER-3: 一般图的保守界 — "QCMI ≥ η" 是平凡的

**攻击陈述:**
η 是 b₁=1 的界。对于 b₁>1 的图，声称 QCMI ≥ η 仅仅说"至少和一个环一样大"——这是平凡的，不构成新的物理内容。

**攻击分析:**

b₁=1 的 CFOL 已经严格证明了: 任意包含至少一个非平凡因果环的图上 QCMI > 0，且有下界 η₀ = 1/(8 ln 2)。

如果一个 b₁=k > 1 的图，其中一个环有非零 Cartan 系数，那 QCMI ≥ η 直接从 b₁=1 的 CFOL 推出——不需要 b₁ 推广的任何新证明。声称 QCMI ≥ η 对 b₁>1 图"成立"，在物理上没有添加任何超出 b₁=1 已知结果的信息。

文档中的"一般情况: η ≤ QCMI ≤ 4"——
- 下界 η 是从 b₁=1 继承的，无新内容
- 上界 4 来自 dim(R) = 4 (两对 Bell 对)，CMI 的最大可能值。这也是平凡的——I(R;E'|Q') = 4 - I(R;Q') ≤ 4 因为 I(R;Q') ≥ 0

**声称"一般图的部分结果"是误导性的，因为它暗示保守界有某种非平凡内容，而实际上它只是 b₁=1 定理对 b₁>1 图的直接特例（b₁>1 图当然包含至少一个环）。**

**判定: WARNING** — 攻击有效。QCMI ≥ η 对 b₁>1 图不是新结果——它是 CFOL (b₁=1) 的直接推论。文档不应将此包装为 b₁ 推广的"部分结果"。

### REVIEWER-4: b₁=3 数据 — 线性标度的数值支持是空洞的

**攻击陈述:**
b₁=3: QCMI=1.8509。η₀·b₁ = 0.180×3 = 0.54。实际 QCMI 是下界的 3.4 倍。任何下界 ≤ 实际值的函数都可以声称"线性标度"。

**攻击分析:**

数值数据 (干涉仪成果记录 §B):
```
tree 3E 4edges       b₁=0   QCMI=0.8546
cycle 2E 4edges      b₁=1   QCMI=1.0609
2cycle 4E 8edges     b₁=3   QCMI=1.8509
```

从 b₁=0 到 b₁=1: ΔQCMI = 1.0609 - 0.8546 = 0.2063 (per b₁)
从 b₁=1 到 b₁=3: ΔQCMI = 1.8509 - 1.0609 = 0.7900 (per 2 more b₁ = 0.395 per b₁)

"per b₁" 在 b₁=1 增量为 0.21，在 b₁=3 增量为 0.40——不一致。

如果取 η₀=0.180: 
- η₀·1 = 0.180 vs 实测 b₁=1 的 QCMI = 1.0609 (5.9x 宽松)
- η₀·3 = 0.540 vs 实测 b₁=3 的 QCMI = 1.8509 (3.4x 宽松)

**关键观察:** 任何满足 0 < η₀ ≤ 0.54 的值都可以声称是 b₁=3 数据的"下界"。在这个范围内有无限多种可能的函数形式。选择"与 b₁ 成线性"作为函数形式，没有任何来自数据的支持——数据本身在这方面是静默的。

**数据对线性标度的检验力:**
- 仅有 3 个数据点 (b₁ ∈ {0, 1, 3})
- 没有 b₁=2 的独立数据
- b₁=1 和 b₁=3 之间只有 2 个自由度
- 不能区分线性 vs 平方根 vs 对数 vs 饱和函数
- 加上门类型依赖，QCMI 在 b₁ 之外的变化幅度 (~4.4x) 远大于 b₁ 自身的变化 (~1.7x from 1 to 3)

**攻击的精确性:** 声称"线性标度的数值支持"是对 data 与 hypothesis 关系的严重误述。数据没有检验线性标度——它们仅检验了"QCMI ≥ η₀·b₁"作为一个数学不等式（因为 η₀ 足够小，数据自动满足）。

**判定: WARNING (对 Case 2 的"线性标度数值支持"声称)** — 攻击有效。现有数据不足以支持或反对线性标度假说——数据只是满足一个极度保守的下界。

### Case 1: 边不相交环 ("可严格证明")

**最终判定 Case 1: WARNING**

- 但声张为"可严格证明"时，未明确以下限定：(a) 需要顶点不相交而非仅边不相交；(b) 需要澄清 QCMI 是原始 CMI 还是 N_sq；(c) 对于 N_sq 需要额外的超可加性论证。

### 最低修复要求 (使 Case 1 升级到 PASS)

1. **明确"QCMI"的操作定义:** 声明本文使用的是原始条件互信息 I(R;E'|Q') 还是 Buscemi squashed N_sq = min_F I(R;E'|Q'F)。两者有不同的可加性行为。
   - 如选择原始 CMI: 可加性正确，但需说明这个量不是 Buscemi 的"真正非马尔可夫性"（未被 F 筛选）
   - 如选择 N_sq: 需要额外的超可加性论证 (Gangwar 2025 引用)，且下界方向为 ≥ 而非 =

2. **将 Case 1 的前提从"边不相交"收紧为"顶点集不相交":** 这是 b1_additivity.md Theorem 1 的原有前提，文档不应放松。

3. **移除或大幅修正 Case 2 中的"线性标度数值支持":** 替换为"数据与下界 QCMI ≥ η·b₁ 一致，但不能区分线性标度与其他单调函数形式"。

### 对比隔壁组声张的到位率

LP37_b1_generalization.md §7 "与隔壁组的关系" 列出三个贡献:
1. "边不相交环的严格推广" — **部分到位** (在澄清前提后成立)
