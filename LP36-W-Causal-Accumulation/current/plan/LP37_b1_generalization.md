## 推广路径

### Case 1: 边不相交环 (可证)

**引理**: 若b₁(G)=k且k个环两两边不相交，则QCMI ≥ k·η。

**证明**:
1. 边不相交 → 每个环作用于不重叠的QE子系统上
2. 初始态是这些子系统的张量积
3. 酉演化因子化: U = ⊗_{i=1}^k U_{C_i}
4. QCMI在张量积上可加（熵可加性 + 酉因子化保证）
5. 每个环贡献≥η → 总和≥kη

**可证性**: 严格。步骤1-3是图论事实，步骤4是量子信息标准结果，步骤5用CFOL。

### Case 2: 共享节点的环 (需要界)

**情形**: 两个环共享Q节点（如2cycle实验: b₁=3, 两环共享Q_a和Q_b）

**已知**: 数值上QCMI(2cycle) ≈ 1.7-1.8 × QCMI(1cycle)，而非2×。

**原因**: 共享节点处发生干涉——环1和环2在共享节点(Q_a, Q_b)处交换信息。耦合方式取决于门类型:
- 对易门: 相消干涉 → QCMI < kη（压低）
- 非对易门: 相长干涉 → QCMI更接近kη

**保守下界**: QCMI ≥ η（最坏情况：所有环相消干涉，只剩单环贡献）

**改进下界**: QCMI ≥ η·⌊b₁/2⌋（如果b₁个环可以配对为边不相交对）

### Case 3: 一般图 (部分结果)

对于任意连通图G:
- b₁(G) = |E| - |V| + 1
- 选择一棵生成树T（|V|-1条边）
- 剩余b₁条边 = 弦(chords)，每条弦定义一个独立环
- 环可能共享树边(T的边)，但不共享弦

**可证的**:
- 若将每个环视为独立b₁=1分析，忽略环间干涉 → QCMI ≥ η
- 若环为边不相交 → QCMI ≥ b₁·η
- 一般情况: η ≤ QCMI ≤ 4（上界由d_R决定）

## 论文中应声张的定理

**Theorem (b₁ generalization, conservative):**
设G为因果Hasse图，b₁(G)≥1。若G包含至少一个非可因子化环，则
$$N_{sq} \geq \eta(d) = \frac{1}{8\ln 2} \approx 0.180 \text{ bits}$$

**Theorem (b₁ generalization, edge-disjoint):**
若G包含k个边不相交的非可因子化环，则
$$N_{sq} \geq k \cdot \eta(d)$$

**Conjecture (b₁ linear scaling):**
对任意图G，N_sq ≥ η(d)·b₁(G)。（数值支持但证明不完备——共享节点环的干涉界待解析推导）
