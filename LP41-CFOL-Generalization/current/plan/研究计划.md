> 日期: 2026-06-10

---

## 目标

从单因果环 (b₁=1, d=2) 推广到任意因果图 G，Betti 数 b₁(G) ≥ 1，在乘积初态 + Cartan 轴对齐假设下，确定 QCMI=0 的充要条件。

## 驱动问题

单环定理：QCMI=0 ⟺ cⱼ∈(π/2)ℤ 对所有边酉成立。
多环网络：这个 iff 条件是否保持？QCMI(b₁) 的标度行为是什么？

## 三个子任务

### Task 1: b₁=2,3,4,5 QCMI 数值扫描 (2天)
- 扩展 cfol_scan2.py 到多环因果图
- 两种情况: 边不相交环 + 共享节点环
- 提取 QCMI(b₁) 标度指数 α: QCMI ~ η₀·b₁^α
- 关键输出: α 的数值估计 + 不确定性区间

### Task 2: 树边冻结引理全局证明 (理论)
- 当前证明仅在小 |c| 极限成立 (隐函数定理)
- 目标: 推广到任意 |c|
- 可能工具: Hasse 图结构 (三角形自由、二部性) 消除 Jacobian 退化
- 备选: sQNM 超可加性路径

### Task 3: 共享节点干涉理论分析
- 两个环共享节点时 QCMI ~ 1.7× 而非 2×
- 这个压低是否随 b₁ 增大而累积？
- 最佳情况: 干涉有界 → lim QCMI/b₁ = const > 0
- 最坏情况: 干涉累积 → QCMI/b₁ → 0
