# Structure Randomizer — 论文结构随机化引擎

## 核心思想

人类写作的统计特征是高方差。AI写作的特征是低方差（一切趋向均值）。

**解法：在AI写/改每一段之前，先用随机数生成该段的全部结构约束，AI必须严格按约束写。**
随机数范围基于真人作者（Segal等）的实测分布。

**关键流程：先为全文所有段落一次性生成全部参数 → 检验全局约束（方差、不重复等）→ 不通过则整体重新生成 → 通过后再开始逐段写。**

## 参数体系（10维）

每个段落生成10个参数：

```
[S, T, P, K, W, E, D, C, R, V]
```

| # | 参数 | 含义 | 取值范围 | 说明 |
|---|------|------|---------|------|
| 1 | S | 句子数 | 2-12 | 段落长度 |
| 2 | T | 段落模板 | 1-6 | 叙事结构编号 |
| 3 | P | 开头方式 | 1-5 | 首句句式 |
| 4 | K | 短句数(≤8词) | 0-3 | 打破句长均匀 |
| 5 | W | 平均词数/句 | 10-28 | 句长中心 |
| 6 | E | 结尾方式 | 1-4 | 段落如何收束 |
| 7 | D | 信息密度 | 1-3 | H/M/L三级 |
| 8 | C | 连接词数 | 0-2 | 本段允许的连接词 |
| 9 | R | 引用密度 | 0-4 | 本段cite数量 |
| 10 | V | 语气色彩 | 1-4 | 客观/评价/承认不确定/推测 |

### 参数详细编码

**T: 段落模板**
| 编号 | 模板 | 说明 |
|------|------|------|
| 1 | assertion-first | 先给结论再展开 |
| 2 | evidence-first | 先给数据/引用再归纳 |
| 3 | narrative | 按时间/因果顺序叙述，不显式总结 |
| 4 | compare-judge | 对比两者给判断 |
| 5 | causal-chain | A→B→C推导 |
| 6 | abrupt-end | 论证后直接停 |

**P: 开头方式**
| 编号 | 方式 | 权重 |
|------|------|------|
| 1 | 主语直接开 | 37% |
| 2 | 介词/状语开 | 22% |
| 3 | While/However让步开 | 18% |
| 4 | 引用他人开 | 12% |
| 5 | It is/被动开 | 11% |

**E: 结尾方式**
| 编号 | 方式 | 权重 |
|------|------|------|
| 1 | 直接停止 | 40% |
| 2 | 前瞻指针 | 25% |
| 3 | 含义陈述 | 20% |
| 4 | 开放/不确定结尾 | 15% |

**D: 信息密度**
| 编号 | 级别 | 含义 |
|------|------|------|
| 1 | H(高) | 每句有技术内容，密集信息 |
| 2 | M(中) | 有解释/过渡/评论性内容 |
| 3 | L(低) | 1-2句过渡或meta-commentary |

**C: 连接词预算**
| 值 | 含义 |
|----|------|
| 0 | 本段零连接词，纯逻辑承接 |
| 1 | 最多用1个（However/While/Yet等） |
| 2 | 最多用2个 |

**R: 引用密度**
| 值 | 含义 |
|----|------|
| 0 | 本段无引用 |
| 1-2 | 少量引用 |
| 3-4 | 文献综述密集段 |

**V: 语气色彩**
| 编号 | 色彩 | 说明 | 全文限制 |
|------|------|------|---------|
| 1 | 客观陈述 | 标准学术 | 无限制 |
| 2 | 评价/判断 | "strikingly general" / "missing rich physics" | 全文≤4次 |
| 3 | 承认不确定 | "we do not have..." / "remains unclear" | 全文≥2次 |
| 4 | 推测/speculation | "may warrant..." / "is suggestive but..." | 全文1-2次 |

## 全局约束（生成后必须校验）

生成全文所有段落参数后，检验以下约束。不通过则**整体重新生成**（不是修补）：

### 方差约束
| 指标 | 要求 | 原因 |
|------|------|------|
| S值标准差 | > 2.5 | 段落长度必须不均匀 |
| W值标准差 | > 4.0 | 句长中心必须波动 |
| S最大-S最小 | ≥ 6 | 必须有极短和极长段共存 |
| W最大-W最小 | ≥ 10 | 必须有简洁段和复杂段 |

### 不重复约束
| 规则 | 要求 | 原因 |
|------|------|------|
| 相邻T不同 | T[i] ≠ T[i+1] | 打破模板重复 |
| 相邻D不同连续H≤2 | 不超过2段连续H | 密度必须波动 |
| 连续3段S差<2禁止 | ∀i: max(S[i:i+3])-min(S[i:i+3]) ≥ 3 | 段落长度必须变化 |
| 连续3段W差<3禁止 | ∀i: max(W[i:i+3])-min(W[i:i+3]) ≥ 4 | 句长必须变化 |
| T值无一值占>35% | 每种T最多占总段落35% | 防止某模板主导 |
| E=3全文≤3次 | 含义陈述结尾不超过3段 | AI最爱的结尾 |
| V=1不超过70% | 客观陈述不超过70%段落 | 必须有评价/不确定 |

### AI Pattern自动检测
| 检测规则 | 触发条件 | 自动修正 |
|----------|---------|---------|
| Pattern B风险 | T=3且E=3（问句+即答） | E强制改为1或4 |
| Pattern D风险 | 连续3段T相同 | 中间段T重新随机 |
| Pattern E风险 | 连续3段D=1(全高密度) | 中间段D改为2或3 |
| 对称风险 | section内所有S值差<2 | 随机选1段S改为min-2或max+3 |
| 全文连接词超标 | C总和>段落数×0.8 | 随机选30%的C=1段改为C=0 |

## Section级预设

不同section的参数分布不同：

### Introduction
```
N_para: 3-5
S分布: 偏大（5-10为主，允许1段≤3句的过渡）
D模式: 从[H,M,H,L]或[M,H,M,H,L]中随机选
R分布: 前60%段落R=2-4（文献重），后40%段落R=0-1
V分布: V=1为主，最后一段可V=2
禁止: 最后一段不用T=3(不以问句结构结尾)
```

### Theorem/Proof
```
固定格式，不参与随机化。
Theorem: S=1-2, T=1, P=1, K=0, E=1, D=1, C=0, V=1
Proof: S=2-4, T=5, P=1, K=0, E=1, D=1, C=0, V=1
仅"评价段"参与随机化。
```

### Results/Data sections
```
N_para: 2-4
S分布: 中等（3-7为主）
D模式: [H,L,H]或[H,M,H]
K: 每段至少K=1（数据句倾向短）
V: 允许V=3(承认不确定)出现1次
```

### Discussion
```
N_para: 3-5
S分布: 高方差（有2句段也有9句段）
D模式: [M,H,H,L]或[H,M,H,M]
V分布: 必须包含≥1个V=3和≥1个V=4
C: 允许稍多（每段C≤2）
E: 至少1段E=4（开放结尾）
```

### Conclusion
```
N_para: 1-2
S分布: 3-5
T: T=6(abrupt)或T=1(assertion)
E: E=1(直接停)或E=4(开放)，禁止E=3
D: H
V: V=1或V=2
禁止: 不得使用T=5(causal)——防止逐条重述
```

## 词数预算系统

### 输入：目标期刊的词数限制

| 期刊 | 正文词数限制 | Abstract | 说明 |
|------|-------------|----------|------|
| PRL | ~3500 (含refs) → 正文约2000-2500 | ≤120 | 最严格 |
| PRR | 无硬限 → 建议3000-4000 | ≤150 | 宽松 |
| PRX | 无硬限 → 建议4000-6000 | ≤150 | 长文 |
| Nature Physics | ~3000正文 | ≤150 | 中等 |
| NeurIPS/ICML | ~8页≈4000-5000正文 | ≤200 | 按页算 |

用户在开始前指定目标期刊（或直接给正文词数上限 `W_total`）如投稿上述示例未列明的期刊，请按上述规范确保适应后续要求。

### Section词数预算分配

正文总词数 `W_total` 按以下比例分配到各section（可根据论文类型微调）：

**理论/计算类论文（如本文）：**

| Section | 比例 | PRL(2200词) | PRR(3500词) |
|---------|------|-------------|-------------|
| Introduction | 18-22% | ~440 | ~700 |
| Model | 10-14% | ~264 | ~420 |
| Theorem/Proof | 8-12% | ~220 | ~350 |
| Results/Data | 15-20% | ~385 | ~612 |
| Mechanism | 12-16% | ~308 | ~490 |
| Design Rules | 15-20% | ~385 | ~612 |
| Classification + Comparison | 8-12% | ~220 | ~350 |
| Experiment Predictions | 8-12% | ~220 | ~350 |
| Discussion | 8-12% | ~220 | ~350 |
| Conclusion | 3-5% | ~88 | ~140 |

每个section的预算记为 `W_sec`。

### 从预算到段落参数

每个section内的段落参数生成受预算约束：

```
Section预算 W_sec = Σ(S_i × W_i) + Σ(F_i × 8)
                     各段          冗余句(约8词/句)
```

**约束求解流程：**

1. 先随机 N_para（段落数）
2. 对每段随机 S_i，然后计算 W_i_target = W_sec / Σ(S_i) （均分预算）
3. 在 W_i_target ± 30% 范围内随机 W_i（引入波动）
4. 计算实际总词数 Σ(S_i × W_i)
5. 如果与 W_sec 偏差 > 15%：调整最长段的S或W（不整体重新生成）
6. 如果偏差 ≤ 15%：接受

**PRL的特殊缩放规则：**
- S的取值范围从[2-12]缩小到[2-8]（短文不适合超长段落）
- W的取值范围从[10-28]缩小到[10-24]（短文句子偏简洁）
- N_para的范围对应缩小（Discussion可能只有2段而不是4段）
- K(短句数)保持不变（比例上短句更密集=更"人类"）

**PRX/长文的缩放：**
- S的取值范围扩大到[2-14]（允许超长技术段）
- Discussion可以有5-6段
- F(冗余句)的配额增大（长文有更多空间放低效句）

### 缩放系数

所有段落参数生成后，计算全文预估词数：

```
W_estimated = Σ(S_i × W_i) for all paragraphs
```

如果 `W_estimated / W_total` 不在 [0.85, 1.10] 范围内：

```
scale = W_total / W_estimated
```

对每段的W乘以scale（保持S不变，因为句子数是结构特征，句子长度是弹性的）：

```
W_i_adjusted = round(W_i × scale)
clamp(W_i_adjusted, 8, 32)  # 不要缩放到不合理范围
```

缩放后重新校验全局约束。

## 无周期性检查

全局约束通过后，额外检查参数序列的周期性。如果任何参数呈现周期≤4的重复pattern，标记REJECT：

```
对每个参数X ∈ {S, T, W, D, V}:
  对周期 p ∈ {2, 3, 4}:
    检查序列 X[0], X[1], ..., X[n] 是否满足 X[i] ≈ X[i+p] 对>60%的i成立
    如果是：REJECT，重新生成
```

**具体检测：**
- S=[3,7,3,7,3,7] → 周期2，REJECT
- T=[1,2,3,1,2,3] → 周期3，REJECT
- W=[12,25,12,25] → 周期2，REJECT
- D=[H,L,H,L,H,L] → 周期2，REJECT

**允许的"伪周期"：** 如果只有1个参数呈弱周期（60-70%匹配），且其他参数无周期，可以PASS（完全无周期也不自然）。

## 执行流程

### Step 1: 确定section列表和各section段落数

```
Introduction: N=4
Model: N=2 (+ 固定equation段)
Theorem: N=3 (theorem+proof+scope, scope参与随机)
Results: N=3
Mechanism: N=4
Design Rules: N=6 (含多个subsection)
Classification: N=2
Discussion: N=4
Conclusion: N=1
---
Total: ~29 paragraphs (典型6页PRL/PRR论文)
```

### Step 2: 为所有29段一次性生成参数

对每段生成[S,T,P,K,W,E,D,C,R,V]，然后检验全局约束。不通过→整体重新生成。

### Step 4: 按Blueprint逐段写

每段严格遵守10个参数。弹性范围：
- S: ±1句
- W: ±3词
- K: 精确（0就是0，2就是2）
- T/P/E/D/C/R/V: 精确

如果科学内容与约束冲突（例如S=2但需解释复杂概念），标注偏差原因后可超出，但同section内偏差不超过1段。

## 补充参数（针对实测残留AI问题）

基于GPTZero实际检测反馈，以下4个额外参数解决现有10维体系的盲区：

```
[S, T, P, K, W, E, D, C, R, V, F, B, L, H]
```

| # | 参数 | 含义 | 取值 | 解决的问题 |
|---|------|------|------|-----------|
| 11 | F | 冗余句数 | 0-2 | 问题1:密度均匀。F=1表示本段必须有1句"重复前句意思"或"纯过渡无信息"的句子 |
| 12 | B | 逻辑断裂 | 0/1 | 问题2:连接太完美。B=1表示本段与上一段之间不加任何过渡，直接跳入新话题 |
| 13 | L | 列举限制 | 0-3 | 问题3:穷举结构。L=0禁止列举;L=2表示最多列举2项(即使有5项也只举2个) |
| 14 | H | 段内句长标准差 | S/L/H | 问题6:句长band窄。S=标准差<5词,L=5-10词,H=>10词(段内必须有极短和极长句共存) |

### F: 冗余句配额

| 值 | 含义 | 怎么写 |
|----|------|--------|
| 0 | 每句都有信息（AI默认模式） | 正常写 |
| 1 | 必须有1句"低效"句 | 重述前面的结论换个说法、或加一句"put differently..."、或重复数据用不同措辞 |
| 2 | 必须有2句"低效"句 | 多一句context/背景/不直接推进论证的评论 |

**全文约束：F=0的段落不超过60%。** 人类文本大约40%的句子是"低信息密度"的。

### B: 逻辑断裂点

| 值 | 含义 |
|----|------|
| 0 | 与上一段有逻辑承接（正常） |
| 1 | 与上一段无过渡直接跳入（模拟人类"思路跳跃"） |

**全文约束：B=1至少出现2次，最多4次。** 分布在section之间的过渡处。

效果：检测器遇到突然跳转时perplexity会spike（因为上一段结尾无法预测下一段开头）。

### L: 列举限制

| 值 | 含义 |
|----|------|
| 0 | 本段禁止任何"A, B, C, and D"结构 |
| 1 | 最多列举1项（"temperatures"而不是"temperatures, spacings, and densities"） |
| 2 | 最多2项 |
| 3 | 最多3项（正常学术写作上限） |

**全文约束：L=0至少占30%段落。** 强制用其他方式表达范围（如"regardless of parameters"代替穷举）。

**关键规则：同一信息在全文中只穷举一次。** 如果Abstract已经说了"29 configurations spanning N=3-6, three spacings, five bath speeds..."，正文中再提时用"the full parameter sweep"一笔带过。

### H: 段内句长标准差

| 值 | 含义 | 具体要求 |
|----|------|---------|
| S(小) | 句长均匀（全段句子都差不多长） | 段内max-min < 10词 |
| L(大) | 句长中等波动 | 段内max-min = 10-20词 |
| H(极大) | 段内必须有极短和极长共存 | 段内max-min > 20词（如一句6词+一句35词） |

**全文约束：H=S不超过30%, H=H至少20%。**

这个参数和K（短句数量）配合：K控制短句的数量，H控制整段的句长分散程度。

## 对仗禁止规则（不是参数，是全局checker）

生成全文后，扫描以下pattern并标记为REJECT：

1. **"Not X; it is Y"结构** — 全文最多出现1次。第2次出现时该段REJECT重写。
2. **分号对仗** — "Star does A; Chain does B; Cyclic does C" — 全文最多1次。
3. **相同sentence frame重复** — 如果连续2句用了相同的主语-谓语结构（"X shows... Y shows..."），标记为REJECT。
4. **"spanning A, B, C, and D"穷举** — 全文最多1次（放在Abstract或Methods，不要重复）。

## 不确定性表达细分（V=3的子类）

V=3（承认不确定）不能都用同一种写法，否则被识别为套路。细分为：

| 子类 | 写法 | 例子 |
|------|------|------|
| 3a | 数据层面的不确定 | "The data suggest X but the sample size is limited to..." |
| 3b | 机制层面的不确定 | "We cannot explain why the optimum is at 0.02 rather than..." |
| 3c | 范围层面的不确定 | "Whether this holds beyond N=7 we have not tested." |
| 3d | 隐式不确定（不说"uncertain"） | "The connection to biological systems is formal at best." |

**规则：全文V=3的2-3次使用，必须来自不同子类。禁止连续两次用同一种hedging方式。**

**绝对禁止的hedging措辞（已被GPTZero学会识别）：**
- "We should be candid about..."
- "It remains an open question whether..."
- "We leave this for future work."
- "Further investigation is warranted."

```
│  Step 3: structure-randomizer 生成Blueprint  │
│  - 为restructured_draft的每段生成14维参数    │
│  - 全局约束校验（不通过则重新生成）           │
│  - 输出：blueprint.md                       │
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  Step 4: 按Blueprint逐段重写                 │
│  - 每段严格服从14维参数                      │
│  - 特别注意F(冗余)、B(断裂)、L(列举)、H(句长) │
│  - 输出：final_draft.tex                    │
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  Step 5: 验证                               │
│  - deep-humanize Phase 3 质量检查            │
│  - 对仗禁止规则扫描                         │
│  - 导出md → 用户做GPTZero检测               │
│  - 如果>15%：回到Step 3重新生成Blueprint     │
└─────────────────────────────────────────────┘
```

**为什么这个顺序最优：**

1. **先写后改**（不是边写边约束）— 因为科学内容优先。先保证内容正确，再调结构。
2. **先结构后统计**（deep-humanize在randomizer前）— 因为结构调整（删roadmap、合并section）会改变段落数量和组织，在此之后再生成参数才有意义。
3. **Blueprint是在最终段落结构确定后才生成的** — 不是写之前猜有多少段，而是看到实际段落后为每段分配约束。
4. **逐段重写而非全文重写** — 每段独立服从自己的参数，段与段之间的差异自然产生高方差。

## 关键理念

**structure-randomizer不是写作工具，是统计约束生成器。** 它不写任何正文，只生成数字。正文由AI按数字写。这样分离了"内容决策"和"统计控制"两个层面：
- 内容由Step 1-2决定（人类/AI的研究判断）
- 统计由Step 3的随机数决定（不由AI的语言习惯决定）

**检测器本质上是在做统计假设检验：H0=人写, H1=AI写。** 我们的目标不是让文本"看起来像人写的"（这是换词/加短句的思路），而是让文本的统计量落在人类分布内（这是randomizer的思路）。参数的随机性确保了统计量的方差足够大，全局约束确保了方差不会大到不自然。

## 不参与随机化的内容

| 类型 | 原因 |
|------|------|
| Theorem/Proof正文 | 数学固定格式 |
| Equation引入句 | "The correction is:" 固定 |
| Figure/Table caption | 另有格式 |
| itemize/enumerate内容 | 列表格式固定 |
| Abstract | 另有字数限制，单独处理 |

## Abstract的特殊处理

Abstract不用10维参数，而是用3维：
- **L**: 总词数（PRR: 100-150, PRL: 100-120）
- **N**: 句子数（4-7）
- **Break**: 在第几句后有一个"转折"（通常第2-3句，从背景转到本文贡献）

## 紧急简化版（2分钟）

如果来不及做完整Blueprint，只为以下5个高危位置生成参数：
1. Introduction最后一段: [S, T, E]
2. Discussion第一段: [S, T, V]
3. Discussion最后一段: [S, T, V, E]
4. Conclusion: [S, T, E]
5. 最长的那个Results subsection: [S, T, D]

这5个位置是GPTZero检测率贡献最大的点。

SM和Cover Letter的去AI方法
SM（补充材料）
SM的特点是：大量公式/表格，文字段落少但高度模板化。14维参数中只有部分适用。
适用的维度： S、T、K、W、E、D、C、V（8维，去掉R引用密度和P开头方式）
SM专用section预设：
Derivation/Proof sections:
  → 不参与随机化（同主文Theorem/Proof）
  
Parameter Tables:
  → 不参与随机化
  
文字说明段（每个subsection的引言/过渡/结论段）:
  N_para通常只有1-3段，按以下约束生成：
  
  S: 2-6（SM段落比正文短）
  T: 禁止T=3(narrative)和T=5(causal chain)，只用T=1/2/4/6
  D: [H, L] 或 [H, M]，不允许连续两段H
  V: 至少1处V=3（承认局限/近似条件）
  E: 禁止E=3（含义陈述）——SM不需要反复声明意义
  C: 每段C≤1
  F: 至少30%段落F=1（允许有一句"this is consistent with the main text result"这类低信息句）
  L: 各subsection的穷举列举不重复正文中已经穷举过的
SM最常触发AI的pattern：

每个subsection都以"In this section, we derive..."开头 → B=1，强制跳入，不加引言句
每个derivation结尾都说"which completes the proof" → E强制用E=1（直接停）
Parameters table前后的说明文字完全对称 → 让各subsection说明段长度不等，允许某节只有1句


Cover Letter
Cover letter篇幅短（300-500词），结构半固定，不能做结构重组，只做句子层面的统计控制。
Cover Letter专用3维轻量参数：
每句话生成3个参数：[W_sentence, V_sentence, Break]

W_sentence: 该句词数
  分布目标：不均匀，要有≤8词的短句和≥30词的长句共存
  禁止：连续3句词数差<5词

V_sentence: 该句语气
  1=客观陈述（默认）
  2=作者判断（"We believe..." / "In our view..."）
  3=承认局限（"We recognize that..."）
  全文：V=2至少2句，V=3至少1句

Break: 句间是否有逻辑断裂
  0=正常承接
  1=上句和下句话题突然切换（全文最多1次）
Cover letter高危pattern及修复：
Pattern触发原因修复Contribution list三条完全等长平行对称一条1句，一条3句，一条2句，长度刻意不等"This paper presents X, Y, and Z"穷举只点最核心1个，其余用"among other results"带过最后一句"We hope this work will..."AI完美收尾改成一个具体期待或直接停，不用hope句式"We are confident that..."AI自我评价删掉或改成"The data suggest..."
Cover letter不参与随机化的部分：

称呼行、日期、署名
期刊名/编辑名的引用句
声明无利益冲突的标准句
