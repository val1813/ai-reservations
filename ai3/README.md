# ai3 — 院长系统

> 院长不做推导，不改文件，不发布课题。
> 院长只做：跨课题审计 + 学术战略评估 + 机制进化建议。

## 使用方式

1. 新开一个Claude窗口
2. 把 DEAN.md 的全部内容投进去
3. 说"执行"
4. 等待三个输出文件更新：
   - shared/院长线索.md      → SELECTOR下次运行时参考
   - shared/学术指导.md      → 科研窗口冷启动时读取
   - shared/机制审计报告.md  → 你审阅，决定是否执行建议

## 触发时机（用户手动）

- 跑完3-4个课题版本后
- 觉得某个课题方向不对时
- 想整合当前所有课题进展时
- 想优化某个机制提示词时

## 文件路径引用

本系统提示词路径：ai3/DEAN.md
院长读取的系统文件：ai/CLAUDE.md, ai2/SELECTOR.md, ai/PI.md 等
院长写入的共享文件：
  shared/院长线索.md
  shared/学术指导.md
  shared/机制审计报告.md

## 院长不做的事

- 不直接修改任何提示词文件
- 不发布课题到候选池
- 不介入正在进行的推导
- 一次最多提3条机制修改建议
