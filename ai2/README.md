# ai2 — 中央选题系统 v2.0

> 这个目录只做一件事：产出高质量北极星候选池。
> 不做科研推进，不做版本迭代，不做知识库管理。

## 核心架构（v2.0）

```
长命题（L1-L6多策略搜索）← paper-search-mcp 驱动
  │
  ├── L7分解 → 子命题（即短命题）← 主产出路径
  │
  └── 独立短命题仅通过"网关"例外放行
      （AB≥5/6 + 基础原理 + 不可归入任何长命题）
```

## 依赖

- **paper-search-mcp**（C:/Users/15488/paper-search-mcp）：学术搜索主引擎，L1/L3/L4/L5/L6依赖
- **WebSearch**：非学术内容兜底（奖项公告等）
- **WebFetch**：具体URL全文抓取

## 目录结构

```
ai2/
  SELECTOR.md        ← 核心提示词（v2.0），直接投给新窗口
  README.md          ← 本文件

shared/              ← 和科研窗口共享的目录
  北极星候选池.md    ← SELECTOR的输出，科研窗口的输入
  知识库汇总.md      ← 科研窗口定期写入，SELECTOR S6读取（可选）
```

## v2.0 核心变更

1. **长命题优先**：L1-L6六条策略搜索重大开放问题
2. **短命题=子命题**：默认情况下短命题来自长命题分解
3. **独立短命题网关**：极少数例外（AB≥5/6 + 影响宽度=基础原理）
4. **旧S1-S6降级**：仅作为网关后备

## 使用方式

1. 新开一个Claude窗口
2. 把 SELECTOR.md 的全部内容投进去
3. 说"执行"
4. 等待输出写入 shared/北极星候选池.md
5. 科研窗口从候选池读取长命题→认领子命题→推进

## 触发时机

- 科研窗口候选池耗尽时（长命题<1个）
- 距上次运行超过7天
- 你手动触发
- 长命题90天无推进→自动难度重评估

## 长命题策略速查

| 策略 | 来源 | 优先级 |
|------|------|--------|
| L1 | 综述开放问题挖掘（Rep. Prog. Phys., Rev. Mod. Phys.等） | 第一 |
| L2 | 奖项动机分析（Nobel, Wolf, Breakthrough等） | 第二 |
| L3 | 跨领域共识裂谷（hep-th vs cond-mat等） | 兜底 |
| L4 | 20年+持续未解问题 | 兜底 |
| L5 | 实验-理论对峙 | 兜底 |
| L6 | 计算复杂性壁垒 | 兜底 |
| L7 | 长命题分解引擎（通用） | 第二阶段 |

## 不需要持续运行
SELECTOR是按需工具，不是常驻进程。
