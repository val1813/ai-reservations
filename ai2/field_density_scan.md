# 领域密度扫描

⛔ 执行前必须确认 paper-search-mcp 可用。

LP-8的教训：MIPT领域在2023-2025年极度饱和，导致推导两个Phase后才发现重复造轮子。
领域密度扫描把发现前置到SELECTOR阶段。

⚠️ 搜索工具优先级：
  1. paper-search-mcp → 主工具
  2. web_search → 仅当paper-search-mcp无结果时降级
  禁止跳过 paper-search-mcp。

---

## 执行步骤（对每个通过第一阶段的长命题）

### 步骤A — 密度探测（4组搜索）

**组1（时间密度）：**
```
paper-search-mcp: "[长命题核心关键词] 2022 2023 2024 2025 2026"
paper-search-mcp: "[长命题核心关键词] arXiv recent"
↓ 无结果 → web_search: "[核心关键词] arXiv 2024 2025"
```

**组2（直接结论覆盖）：**
```
paper-search-mcp: "[长命题核心声张关键词] review open problem"
paper-search-mcp: "[长命题核心声张] solved resolved 2023 2024 2025"
↓ 无结果 → web_search: "[核心声张] solved 2024"
```

**组3（子命题级覆盖，对每个拟分解的子命题方向）：**
```
paper-search-mcp: "[子命题方向关键词] 2023 2024 2025"
paper-search-mcp: "[子命题方向关键词] no-go disproof impossibility"
↓ 无结果 → web_search: "[子命题方向] 2024 2025"
```

**组4（结论层翻译搜索，防框架盲区）：**
```
把长命题核心声张翻译成普通物理语言（不依赖本课题框架的描述）
paper-search-mcp: "[翻译后的普通描述] 2022 2023 2024 2025"
paper-search-mcp: "[翻译后的普通描述] no-go failure limit"
↓ 无结果 → web_search: "[普通描述] recent"
```

---

### 步骤B — 密度判定

统计4组搜索命中的2022年后高度相关论文总数 N：

| N | 状态 | 处置 |
|---|------|------|
| N ≤ 4篇 | ✅ 低饱和风险 | 正常进入L7分解 |
| 5 ≤ N ≤ 9篇 | ⚠️ 中饱和风险 | 进入L7分解，但必须先完成步骤C（空白定位） |
| N ≥ 10篇 | 🔴 高饱和风险 | ⛔ 暂停分解，必须先完成步骤C（空白定位） |

**低饱和标注：** `领域密度：低（N≤4篇，2022-2026），适合原创推进`

**中饱和标注：** `领域密度：中（N篇，2022-2026），已定位空白：[见步骤C输出]`

**高饱和处置：**
- 步骤C无法定位任何可操作空白 → 标记为"高饱和暂存"，不进入活跃候选池
- 步骤C定位到可操作空白 → 仅以该空白为核心分解

---

### 步骤C — 空白定位（中/高饱和风险时必须执行）

目标：在密集发表的领域里找出现有文献都没有正面回答的具体问题。

1. 列出已被覆盖的方向（来自步骤A的命中文献，每篇一句话总结核心结论）
2. 对每个拟分解的子命题方向，检查是否已被步骤A命中：
   - 已被命中（结论相同或高度重合）→ 标记 `⛔ 已覆盖`
   - 未被命中，或只做了定性分析无定量结果 → 标记 `✅ 潜在空白`
   - 命中文献声称解决但论证有缺口 → 标记 `⚠️ 争议空白`
3. 输出空白清单：

```
| 子命题方向 | 覆盖状态 | 最近先发（如有） | 差异化操作空间 |
|-----------|---------|----------------|-------------|
| ...       | ...     | ...            | ...         |
```

4. 判定：
   - 所有方向 `⛔ 已覆盖` → 长命题整体暂存，不进活跃候选池
   - 有 ≥1 个 `✅ 潜在空白` → 仅以这些空白为核心分解

---

### 步骤D — 写入候选池条目的"领域密度"字段

```
领域密度：[低/中/高]
2022-2026年相关论文数：[N]篇
饱和风险：[低/中/高]
已定位空白：[步骤C输出的✅/⚠️方向]
覆盖方向（不分解）：[步骤C的⛔方向列表]
```

---

## S1候选的特殊规则

S1候选的领域密度判定阈值放宽：高饱和不阻断，仅标注 `⚠️高饱和但差异化`。
