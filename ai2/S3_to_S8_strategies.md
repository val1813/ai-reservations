# S3–S8 Fallback Strategies for Research Topic Selection

These strategies are executed only when S1 (北极星优先矩阵) and S2 (实验-理论张力)
do not yield enough candidates to populate the candidate pool. Each strategy is
self-contained: search method, extraction logic, cross-validation, and a hard
self-filter gate. All strategies use **paper-search-mcp** as primary search tool,
with **WebSearch** as degraded fallback (annotate output when degraded).

The unifying principle across all six strategies is the L0 gate: the core tension
must be expressible as "proposition A and proposition B cannot both be true," and
at least one sub-proposition must be testable within 2 weeks using existing public
data or reproducible code.

---

## 策略 S3：综述开放问题挖掘（优先级第一）

### 原理

顶级综述期刊（RoMP, RPP, Nature Reviews Physics 等）由领域权威撰写，在总结
已有成果的同时，惯例性地在结论部分列出 "open problems"。这些列表经过作者
（通常是该领域多年的思想领袖）的筛选，质量远高于任意论文的 "future work" 段。
从综述中挖掘的开放问题天然具有跨子领域的影响力和充分的前期论证。

### 搜索方式（两步走）

**第1步 — 用 paper-search-mcp 搜索综述论文：**

```
paper-search-mcp: "Reports on Progress in Physics" review 2023 2024 2025
paper-search-mcp: "Reviews of Modern Physics" condensed matter 2023 2024 2025
paper-search-mcp: "Annual Review of Condensed Matter Physics" 2024 2025
paper-search-mcp: "Nature Reviews Physics" 2024 2025
paper-search-mcp: "Physics Reports" review 2024 2025
```

对每个命中结果，先用 read 工具提取全文，聚焦结论/展望章节。若全文不可及，
则读摘要 + introduction 中 "we highlight several open questions" 类段落。

**第2步 — 提取开放问题：**

在每篇找到的综述中，搜索显式标注：
```
paper-search-mcp: "open problem" OR "open question" OR "unsolved" OR "outstanding" [领域关键词]
paper-search-mcp: "remains to be understood" OR "critical gap" OR "key challenge" [领域关键词]
```

### 交叉引用验证

至少用 paper-search-mcp 找 **3 篇来自不同通讯作者** 的综述确认同一问题。
同一通讯作者的多篇综述只计为 1 个独立来源。若问题只在一篇综述中出现或所有
提及均来自同一研究脉络，则退回第 1 步扩大搜索。

### 构造核心矛盾

从综述中提取的开放问题通常以单命题形式出现（"X 的机制未知"），需主动重构为
A-vs-B 对立。方法：找到该问题下两个互斥但各有证据支持的主流解释，将它们对
立。若综述中只列出一种可能解释，则搜索该解释的反对论文构造对立面。

### 自过滤（全部通过才输出）

- [ ] 至少 3 篇独立综述（不同通讯作者）提及？
- [ ] 核心矛盾可写成 "A vs B，不能同时为真"？
- [ ] 可分解为 ≥3 个逻辑依赖子命题？
- [ ] 近 2 年（2024-2026）有新的进展使问题比以前更可打？
- [ ] 无单一大型合作组（>5 个机构）系统推进？（LHC/ITER 级 → 放弃）
- [ ] 解决它不只影响一个课题组，而是至少两个子领域的共识？
- [ ] 不是纯基础设施瓶颈？（反例：暗物质探测 → 探测器灵敏度）
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据 2 周内检验（全部依赖未实现工具 → ⚠️ 降两级）

### 失败模式（常见误判）

- **假共识**：多篇综述提及同一问题，但均引用同一篇原始论文 → 退回第 1 步
- **假开放**：综述标注为 "open"，但近 2 年已有论文宣称解决 → 检查引用该综述的后续论文
- **过于宽泛**："高温超导机理" 类不可分解的问题 → 拒绝，要求指定子问题

## 策略 S4：奖项动机分析（优先级第二）

### 原理

重大物理学奖项（Nobel, Wolf, Breakthrough, Dirac, Buckley）的颁奖理由精确描述了
"已解决的问题"。这些问题的解决必然开启了新的前沿 — 那些颁奖后暴露出来的
后继问题天然具有 "被顶尖物理学家认证为重要 + 已有前期突破可依托" 的双重优势。
逆向阅读颁奖理由，从 "已知的已知" 推演 "已知的未知"，是最高效的问题发现路径。

### 搜索方式（两步走）

**第1步 — WebSearch 获取奖项信息：**

```
WebSearch: "Nobel Prize physics [年份] motivation prize lecture"
WebSearch: "Wolf Prize physics [年份] laureate motivation"
WebSearch: "Breakthrough Prize fundamental physics [年份] citation"
WebSearch: "Dirac Medal ICTP [年份] laureate"
WebSearch: "Buckley Prize physics [年份] citation"
```

年份优先级：首选 2015-2023（颁奖后有足够时间暴露后继问题）。更早的奖项需
额外验证问题是否仍然开放（可能已被后续突破解决）。

**第2步 — paper-search-mcp 验证遗留问题：**

对每个奖项 → 读颁奖理由中 "已解决" 的问题 → 倒推该领域 "仍未解决" 的核心问题。

操作步骤：
1. 提取颁奖理由中的核心成就（如 "for the discovery of X in Y system"）
2. 问：X 的发现开放了什么问题？哪些后续问题在颁奖后仍无人解决？
3. 验证搜索：
```
paper-search-mcp: "[问题]" review "open problem" → 确认 ≥2 篇独立综述标记
```

### 自过滤（全部通过才输出）

- [ ] 问题确实存在于 ≥3 个独立来源（颁奖理由 + 至少 2 篇独立综述）？
- [ ] 可写成 "A vs B，不能同时为真"？
- [ ] 可分解为 ≥3 个逻辑依赖子命题？
- [ ] 非 "需要下一代实验设施" 类基础设施问题？
- [ ] 近 5 年有新工具/方法使问题的某些子命题变得可打？
- [ ] 问题在颁奖后是否有 ≥2 篇独立论文尝试并失败？
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据 2 周内检验

### 失败模式（常见误判）

- **问题已死**：颁奖后该领域被新范式取代，不再是活跃研究 → 拒绝
- **荣誉回溯问题**：奖项颁发过晚（20+ 年后），问题可能已被遗忘而非活跃 → 拒绝
- **纯技术奖**：奖项是表彰仪器/算法开发而非物理发现 → 降级，仅当可转为物理问题时保留

## 策略 S5：跨领域共识裂谷（兜底）

### 原理

不同子领域对同一物理系统的研究使用不同的方法论、假设和近似。当两个子领域的
**高引综述** 对同一问题给出互斥结论时，这通常不是一方简单错误，而是双方的
核心假设存在深层的不可调和。这类 "共识裂谷" 是最高质量的科研候选池来源：
双方都有大量文献和声誉背书，裂谷本身定义了精确的可检验问题。

### 搜索方式

找到两个不同子领域对同一物理问题的 **相反结论**。

**候选领域对（基于历史裂谷的高发区域）：**

| 领域 1 | 领域 2 | 典型裂谷 |
|---|---|---|
| hep-th | cond-mat | 全息对偶的适用范围；纠缠熵的物理解释 |
| quant-ph | cond-mat.str-el | 量子相变中的退相干效应 |
| cond-mat.stat-mech | cond-mat.str-el | MBL 的存在性与稳定性 |
| gr-qc | cond-mat | 黑洞信息 vs 量子多体热化 |
| physics | math-ph | 量子场论的严格基础问题 |

**搜索方法（paper-search-mcp）：**

对每对领域，分别搜索：
```
paper-search-mcp: "[领域1] review [物理系统]" → 提取核心主张
paper-search-mcp: "[领域2] review [物理系统]" → 提取核心主张
```

比较双方结论。若发现互斥主张，进入交叉验证。

### 构造示例

- **命题 A（领域 1）**: "2D 无序系统在 T→0 时总是局域化的"
- **命题 B（领域 2）**: "2D MBL 在强无序 + 准周期势下是稳定的"
- **为什么不能同时为真**: 标度理论的无序平均假设 vs 准周期势的非平均性质
  — 如果命题 A 对，命题 B 中的系统不可能存在；如果命题 B 对，标度理论需要修正

### 自过滤（全部通过才输出）

- [ ] 两边都有 ≥2 篇独立论文支持各自立场？
- [ ] 分歧已存在 ≥5 年仍未解决？
- [ ] 分歧关于物理而不是术语/语义？（验证：用两边框架计算同一可观测量的值 → 数值不同）
- [ ] 可分解为 ≥3 个逻辑依赖子命题？
- [ ] 至少有一个子命题现在就可以打？
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据 2 周内检验

### 失败模式（常见误判）

- **语义分歧**：两边用不同的词说同一件事 → 计算同一可观测量，数值一致即拒绝
- **异步共识**：一方已在近 2 年接受另一方的结论 → 检查最近引用网络
- **假对立**：两边研究的是不同参数区，无直接冲突 → 拒绝

## 策略 S6：20 年+ 持续未解问题（兜底）

### 原理

某些物理学问题已持续被列为 "open problem" 超过 20 年。这类问题的存在本身就
表明它们不是普通的 "尚未解决" — 而是嵌入了深层概念困难。关键在于区分
"因实验不可及而搁置" 与 "因理论工具不足而搁置"：前者仍需等待下一代设施，
后者则可能因为近 5 年出现的新工具（机器学习势函数、张量网络、NQS、符号计算
进步等）而变得可打。

### 搜索方式

找到在 ≥3 篇综述中 **持续被列为 open problem 超过 20 年** 的问题。
特别关注：搁置原因在过去是 "工具不足"，但近 5 年工具已出现。

**搜索技术（paper-search-mcp）：**

```
paper-search-mcp: "remains an open problem" [领域关键词]
paper-search-mcp: "despite" "years of effort" [领域关键词]
paper-search-mcp: "has resisted theoretical explanation" [领域关键词]
paper-search-mcp: "still unsolved" OR "remains unresolved" [领域关键词] review
```

**交叉验证：**
1. 用 2000-2005 年的旧综述 vs 2023-2025 年的新综述 → 同一问题是否持续出现 ≥20 年？
2. 若同一问题在跨度 ≥20 年的 ≥3 篇综述中被列为 "open"，则通过第一步
3. 追溯旧综述中的搁置原因 — 是 "无法实验测量" 还是 "理论无法计算"？
4. 若是前者 → 降级或拒绝；若是后者 → 检查近 5 年是否出现了新计算工具

**新工具的典型类别（非穷举）：**
- 机器学习力场 / 神经网络变分蒙特卡洛（NQS）
- 张量网络方法（DMRG 的扩展、PEPS 收缩算法进步）
- 量子计算模拟器（Clifford 电路的高效经典模拟）
- 符号计算与自动化定理证明

### 筛选标准

- [ ] ≥3 篇覆盖 ≥20 年跨度的独立综述共同标记？
- [ ] 搁置原因不是 "实验上不可及"？
- [ ] 近 5 年出现了 20 年前不存在的工具？
- [ ] 可分解为 ≥3 个依赖子命题？
- [ ] 分解后的至少 1 个子命题可用新工具直接攻打？
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据 2 周内检验

### 失败模式（常见误判）

- **僵尸问题**：20+ 年未解因为被证明无解或不重要，而非技术困难 → 检查近 5 年引用是否归零
- **实验瓶颈伪理论问题**：根源是实验精度不足，理论本身无矛盾 → 拒绝
- **新工具不适用**：新工具（如 ML）在形式上可应用但物理上无洞察 → 拒绝

## 策略 S7：实验-理论对峙（兜底）

### 原理

物理学进步的一个核心驱动力是实验与理论的不匹配。当一个现象被 ≥2 个独立
实验组确认但理论 ≥5 年无法解释（类型 A），或理论明确预测存在某种效应但
≥5 年无实验确认（类型 B）时，对峙本身就构成了高质量的研究对象。不同于
S2 的 "实验-理论张力"（聚焦于具体参数矛盾），S7 关注的是更宏观的 "现象-理论"
对峙。

### 搜索方式

找满足以下 **任意一种情形** 的现象：

| 类型 | 方向 | 条件 | 示例 |
|---|---|---|---|
| **类型 A** | 实验 → 理论 | ≥2 个独立实验组确认某现象，理论 ≥5 年无法解释 | 铜氧化物赝能隙相的起源 |
| **类型 B** | 理论 → 实验 | 理论明确预测某效应，≥5 年无实验确认 | 马约拉纳零模的确证 |

**搜索技术（paper-search-mcp）：**

类型 A — 寻找实验中报告异常的论文：
```
paper-search-mcp: "unexpected" OR "anomalous" OR "puzzle" [领域] experiment 2023 2024 2025
paper-search-mcp: "surprising" OR "not understood" OR "cannot be explained" [领域] 2023 2024 2025
```

类型 B — 寻找理论预测中标注 "尚未观测到" 的论文：
```
paper-search-mcp: "predicted" "has not been observed" [领域] 2024 2025
paper-search-mcp: "awaits experimental confirmation" OR "remains to be detected" [领域]
```

### 交叉验证（按类型）

**类型 A：**
1. 确认 ≥2 个独立实验组（不同通讯作者、不同装置）报告了同一异常 → 排除单一系统误差
2. 搜索该异常的理论论文 — 需 ≥3 篇来自不同课题组的理论尝试并失败
3. 若只有 1-2 篇理论论文尝试 → 可能是被忽视的 niche 问题而非共识对峙 → 拒绝

**类型 B：**
1. 确认理论预测明确且可证伪（有具体的实验信号、截面、能量范围）
2. 搜索实验论文 — 需 ≥2 个独立实验组在预测参数区内搜索并报告 null result
3. 若只有 1 组实验搜索 → 可能是实验覆盖不足 → 拒绝

### 自过滤（全部通过才输出）

- [ ] 实验端：≥2 个独立实验组确认同一现象？（否则可能只是系统误差）
- [ ] 理论端：≥3 篇来自不同课题组的理论论文尝试并失败？
- [ ] 差异 ≥3σ（实验）或理论预测明确可证伪（理论）？
- [ ] 不是基础设施瓶颈？
- [ ] 可分解为 ≥3 个依赖子命题？
- [ ] 至少 1 个子命题只用现有公开数据 + 理论推导即可推进？
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据 2 周内检验

### 失败模式（常见误判）

- **系统误差误判为异常**：1 组报告的 "异常" 被第二组以更高精度否定 → 检查是否有反驳论文
- **理论预测不可证伪**：理论预测 "某种效应" 但未给出具体信号 → 拒绝
- **null result = 实验失败**：实验未观测到可能因灵敏度不足而非理论错误 → 区分 "未探测到" vs "探测了但没发现"

## 策略 S8：计算复杂性壁垒（兜底）

### 原理

某些量子多体问题被正式证明或强数值证据表明经典计算不可解（NP-hard、#P-hard、
符号问题等）。然而，"整体不可解" 并不意味着所有子问题都不可解。通过将问题
分解为经典可解和经典不可解的子命题，可以在当前计算资源内推进，同时为未来的
量子计算提供明确的目标问题（"量子优势的物理应用"）。

### 搜索方式

找已被证明经典计算不足以解决的问题，但某些**子问题在当前计算能力内可解**。

**搜索技术（paper-search-mcp）：**

```
paper-search-mcp: "computational complexity" "NP-hard" OR "#P-hard" quantum many-body
paper-search-mcp: "exponential wall" OR "sign problem" quantum Monte Carlo
paper-search-mcp: "classically intractable" quantum simulation 2024 2025
paper-search-mcp: "computational bottleneck" OR "exponentially hard" [领域]
```

**分解方法：**
1. 识别问题的计算瓶颈 — 哪一步是指数级的？
2. 将瓶颈前后的步骤分离 — 瓶颈前/后的子问题可能是经典可解的
3. 对瓶颈本身 — 是否有物理近似可将指数复杂度降至多项式？
4. 识别哪些子问题可用 NQS、张量网络、或近期算法突破解决

### 目标

问题整体经典不可解，但可分解为 **经典可解 + 经典不可解** 子问题。

**例：** 2D 阻挫量子磁体基态
- **整体问题**：任意 2D 阻挫海森堡模型的基态 → #P-hard，经典不可解
- **(S1) 解析约束**：对称性 + 约束条件给出基态必须满足的不等式 → 经典可解（解析推导）
- **(S2) NQS 绕开**：用神经网络量子态变分求解特定参数区的基态 → 经典近似（可控误差）
- **(S3) 系统误差**：量化 S2 的变分误差 vs 精确对角化在小尺寸上的差距 → 经典可解（数据分析）

### 自过滤（全部通过才输出）

- [ ] 有正式证明或强数值证据表明经典计算不可解？
- [ ] 可分解为经典可解 + 经典不可解的子问题？
- [ ] 至少 2 个子命题在现有计算资源内可操作？
- [ ] 子命题的解决为量子计算提供 "目标问题"？
- [ ] ⛔ **可检验性底线**: ≥1 个子命题可用现有公开数据/可复现代码 2 周内检验

### 失败模式（常见误判）

- **假 NP-hard**：论文声称 NP-hard 但只适用于非物理参数区 → 检查证明的假设是否在物理区成立
- **不可分解**：问题整体指数级且无任何子步骤可分离 → 拒绝
- **已解**：近期算法突破已在经典计算机上有效解决 → 检查最新 benchmark

## 工具降级策略

⛔ **执行前必须确认 paper-search-mcp 可用。** 不可用 → WebSearch 兜底，产出中标注降级。

| 层级 | 工具 | 何时使用 |
|---|---|---|

## 策略执行顺序

仅在前序策略产出不足时，才依次执行后续策略。每次执行完一个策略后，将新
候选加入候选池，检查池大小是否达到目标（默认 ≥5 个候选），达到则停止。

```
S1 (北极星优先矩阵) ──→ 产出候选池
  │ 不足
  ▼
S2 (实验-理论张力) ──→ 补充候选
  │ 不足
  ▼
S3 (综述开放问题) ──→ 补充候选       ← 优先级第一 fallback
  │ 不足
  ▼
S4 (奖项动机) ──→ 补充候选           ← 优先级第二 fallback
  │ 不足
  ▼
S5 (跨领域裂谷) ──→ 补充候选         ← 兜底层
  │ 不足
  ▼
S6 (20年未解) ──→ 补充候选
  │ 不足
  ▼
S7 (实验-理论对峙) ──→ 补充候选
  │ 不足
  ▼
S8 (计算复杂性) ──→ 补充候选
```

## 跨策略通用规则

1. **L0 硬约束**：任何候选的最终核心矛盾必须可写成 "A vs B, 不能同时为真"
2. **子命题依赖链**：每个候选必须能分解为 ≥3 个逻辑依赖子命题（S1→S2→S3）
3. **可检验性底线**：≥1 个子命题必须在 2 周内可用现有公开数据/代码检验
4. **反共识独立性**：候选两端的支持者必须来自不同通讯作者、不同课题组
5. **非基础设施**：拒绝 "等待下一代探测器/加速器/望远镜" 类问题
6. **交叉验证强制**：任何单一来源的断言必须被 ≥2 个独立来源确认
