# S1 — 隐藏假设挖掘（最高优先级）

> 状态：最高优先级。S1找到≥1个有效候选 → 直接进入第二阶段，跳过S2-S8。
> 来源：SELECTOR v1.1 拆分，原位于 SELECTOR.md v1.0 行132-236。

## 策略 S1：隐藏假设挖掘（最高优先级）

```
核心逻辑：不搜索"已知的开放问题"，搜索"所有人默认成立但从未被显式检验的前提"。
这是最接近爱因斯坦1905模式的路径：同时性的绝对性不是"开放问题"——它是所有人都同意的默认前提。
迈克耳孙-莫雷的零结果在洛伦兹-庞加莱框架里"已有解释"（长度收缩），从L0角度会被过滤。
爱因斯坦做的是质疑前提本身，而不是在现有框架里修补。

S1与S2-L6的本质区别：
  S2-L6搜索： "什么是未解决的？" → 已知的未知 → 增量谜题
  S1搜索：   "什么是所有人都同意的——而且可能错了？" → 未知的未知 → 范式突破
```

### 搜索方式（三步走）

#### 第1步 — 识别目标子领域

不是全物理学漫无目的搜索。选择一个具体的子领域，该领域应满足：
  □ 有一个核心观测结果被广泛接受
  □ 该结果的解释依赖一个或多个隐藏假设
  □ 该领域有公开可用的数据集

**候选子领域模板（每次SELECTOR执行时任选1-3个，不穷举）：**

```
模板A — ΛCDM宇宙学：
  隐藏假设候选：
    · "CMB光子到达探测器时携带的是经典统计信息"
    · "宇宙在≥100 Mpc尺度上统计均匀"（宇宙学原理）
    · "FLRW度规在所有尺度上有效"
    · "哈勃常数是一个单一数值而非尺度依赖量"
    · "初始扰动是绝热的且完全高斯"

模板B — 凝聚态强关联：
  隐藏假设候选：
    · "费米液体理论是关联电子系统的正确低能描述"
    · "电阻率饱和意味着Ioffe-Regel极限已达"
    · "线性T电阻率必然意味着非费米液体"
    · "超导能隙对称性由配对机制唯一决定"

模板C — 量子基础/量子引力：
  隐藏假设候选：
    · "时空在普朗克尺度以下是光滑的"
    · "量子测量问题的退相干解释中，环境自由度可以无限细分"
    · "黑洞信息恢复意味着AdS/CFT在平直时空中也成立"
    · "暴涨产生的原初扰动是完全经典的今天"

模板D — 粒子物理/天文：
  隐藏假设候选：
    · "暗物质是单一组分而非多组分"
    · "中微子质量层级是正常的"
    · "哈勃张力的解必然在晚期或早期物理中二选一"
    · "超新星绝对光度不随红移演化"
```

执行时：从模板中选1-3个最可能与"选题线索"或知识图谱孤儿节点共振的子领域。

#### 第2步 — 系统地提取隐藏假设

对选中的子领域，执行以下操作：

```
a) 读该领域最近2-3篇高引综述（用paper-search-mcp找到），提取：
   - 综述中作为"已知事实"陈述但未提供引用的声明
   - 用"it is generally accepted that..." "as is well known..."等句式引入的陈述
   - 在Introduction中被一笔带过、没有定量论证的前提

b) 对该领域的标准教科书级处理方法，追问：
   - 这个处理的第一步做什么？这一步依赖什么前提？
   - 如果这个前提不成立，后面的所有推导是否仍然有效？
   - 有没有论文曾经显式检验过这个前提——不是作为副产品，而是作为主要目标？

c) 对该领域的核心数据集，追问：
   - 数据分析的第一步做了什么假设？（如：高斯性、统计各向同性、噪声模型）
   - 如果放弃这个假设，第一条需要修改的代码行是什么？
   - 有没有人用不同的假设重分析过同一数据？
```

#### 第3步 — 构造可检验的隐藏假设否定命题

对每个候选的隐藏假设H：

```
  □ 写出H的精确否定 ¬H（一句话，必须是可操作的）
  □ 推导：如果¬H为真，在现有公开数据中会产生什么具体的、可量化的观测差异？
  □ 估算：这个差异的量级是多少？是否≥3σ可检测？
  □ 检查：这个差异是否已经被现有分析的"系统误差预算"所吸收？
  □ 构造"A vs B"：命题A = "H成立 + 标准解释"，命题B = "¬H成立 + 新解释"

只有通过以上五个检查的隐藏假设才能进入候选池。
```

### 自过滤（全部通过才输出）

```
  □ 该假设被≥80%的该领域论文隐性依赖（不是某篇论文的特有假设）
  □ 该假设从未被作为主要目标独立检验过（不是"有人提过但被否定了"）
    ⚠️ 验证方法：paper-search-mcp搜索"[假设的精确否定] test measurement"→应返回空或无关
  □ 该假设的否定（¬H）有≥1个可观测后果，且该后果可用现有公开数据检验
    不需要新实验、不需要新望远镜、不需要更大对撞机
  □ 该可观测后果的量级≥2σ（在现有数据精度下可分辨）
  □ 检验过程可以在1-2周内完成（不需要大规模数值模拟）
  □ 如果¬H成立 → 至少改变该子领域≥30%论文的结论或解释框架
  □ 如果¬H不成立 → 产出该假设的第一个显式定量检验（本身有发表价值）
  □ ⛔ 可检验性底线：¬H的可观测后果必须能用至少一种现有公开数据集的
    标准分析流程在≤2周内检验。无法用现有数据检验→不可输出。
    检验路径必须具体到：数据集名称 / 物理量 / 预期偏差方向 / 显著性估算。
```

### 有效长命题定义（S1产出）

S1不要求"≥3个独立文献来源标记为开放问题"——因为隐藏假设恰恰是没人标记的。
替代标准：

```
  1. 可精确化为"命题A（H成立）vs 命题B（¬H成立），两者不能同时为真"
  2. 命题B的量级估算通过（≥2σ可检测，有具体数值估算）
  3. 可分解为≥2个有逻辑依赖关系的子命题
     （不是"这个问题有2个方面"，而是"A解决后才能打B"的串行依赖）
  4. 检验用现有公开数据，不需要新实验，1-2周内可完成
  5. 非纯哲学/诠释学问题（必须是物理量层面可区分的）
  6. 命题B的观测后果不被现有系统误差预算完全吸收
     （必须证明该后果≥2σ超出系统误差估计范围）
  7. 领域密度扫描：高饱和（≥10篇）不阻断，仅标注"⚠️高饱和但差异化"
```

### 领域密度扫描（S1放宽）

```
S1产出进入领域密度扫描（与S2-L6相同，但领域密度判定阈值放宽：
  因为隐藏假设检验本身就有发表价值（无论¬H是否成立），
  高饱和风险（≥10篇）不阻断，仅标注"⚠️高饱和但差异化：检验隐藏假设H而非已有方向"）

S1候选跳过L7分解。
  原因：S1的隐藏假设¬H的问题空间未知，
  PI无法预先识别障碍链和子命题依赖关系。
  子命题在A/B自由探索后自底向上涌现。

S1候选在候选池中的条目格式：
  子命题进度：写"待探索涌现"（不是"0/N"）
  关键路径下一步：写"启动v1.0突击队探索"
  依赖图：写"无（自底向上涌现）"
```
