# P3.5: Competitive Benchmark — 同期录用论文PK

> 角色: 竞争情报分析。用目标期刊最新录用的论文做标杆,对比我们的稿件。
> 核心问题: 审稿人看到我们的稿件时,会和最近录用的论文比较。我们够强吗?
> 输入: Phase 3格式化后的稿件 + 目标期刊
> 输出: 竞争力评估报告 + 优化建议

---

## §1 搜索对手

用 paper-search-mcp 搜索目标期刊**最新录用/发表**的论文:

```
搜索1 (最新发表):
  paper-search-mcp: "[目标期刊] 2026" → 按日期排序,取最近3篇
搜索2 (同类主题):
  paper-search-mcp: "[期刊] [稿件核心关键词] 2025 2026" → 取最近3篇
搜索3 (编辑推荐/亮点):
  WebSearch: "[目标期刊] editors' suggestion highlight 2026" → 取最近2篇
```

从搜索结果中选3篇最有可比性的:
- 优先: 同子领域 + 研究方法相似
- 其次: 同期刊 + 最近发表(2026>2025)
- 保证: 3篇都是正常审稿录用的(非邀请综述/评论)

---

## §2 多维度对比

对每篇对手论文 + 我们的稿件,逐项打分(1-5):

### 维度表

| # | 维度 | 权重 | 评分标准 |
|---|------|------|---------|
| 1 | **问题重要性** | ×3 | 5=改变领域共识 4=解决长期争议 3=有价值的增量 2=边际贡献 1=不重要 |
| 2 | **证据强度** | ×3 | 5=多种独立验证+数据+推导 4=一种验证+强推导 3=理论推导为主 2=定性论证 1=猜测 |
| 3 | **叙事质量** | ×2 | 5=非本领域也能理解其重要性 4=逻辑清晰动机明确 3=标准学术叙事 2=动机弱结构散 1=难读 |
| 4 | **新颖性** | ×2 | 5=全新视角改变理解 4=显著改进现有方法 3=已知方向新推进 2=微小改进 1=已有重复 |
| 5 | **受众广度** | ×1 | 5=影响≥3个子领域 4=影响2个子领域 3=影响本领域 2=影响本子领域 1=只影响本课题组 |
| 6 | **技术深度** | ×1 | 5=方法本身是贡献 4=方法巧妙 3=标准方法 2=方法有缺陷 1=方法不成立 |

### 综合分 = Σ(评分 × 权重) / Σ权重

---

## §3 裁决

```
我们的综合分 vs 3篇对手的平均分:

  我们 > 对手均分 ×1.1  → ✅ 竞争力充足,进入Phase 4
  我们 ≈ 对手均分(±10%) → ⚠️ 边缘。看分项:
                            - 叙事弱? → 优化叙事后重新对比
                            - 证据弱? → 补数据/推导后重新对比
                            - 问题重要性弱? → ⛔ 硬问题。考虑降级期刊
  我们 < 对手均分 ×0.9  → 🛑 竞争力不足。必须优化后重新PK。
                            最多重跑2次。2次后仍不达标→降级目标期刊。
```

---

## §4 差距诊断与优化建议

如果我们的分数落后,按维度诊断:

### 问题重要性弱 → 最难修复

```
可能原因:
  - 选题本身是边际问题 → 这是选题层面的缺陷,不是写作能修的
  - 选题重要但叙事没传达出来 → 优化Introduction,强化motivation
  - 期刊不匹配(如PRL投了太窄的问题) → 考虑换目标期刊

优化: 重写Introduction,用对手论文的叙事手法重构motivation。
      如果问题本身不够重要→坦诚降级期刊,不浪费时间优化。
```

### 证据强度弱 → 可修复

```
可能原因:
  - 实验数据不够 → 补数据或降级声称
  - 推导不完整 → 补推导
  - 只有理论无验证 → ⛔ 这是致命伤。考虑补数值实验

优化: 回到Phase 2,针对性补强后再跑P3.5。
```

### 叙事质量弱 → 最可修复

```
可能原因:
  - motivation不够清晰 → 学习对手论文的叙事结构
  - 结构不符合期刊惯例 → 按对手论文的结构重组
  - 过度技术化,外行读不懂 → 加概念示意图,改写Introduction

优化: 读3篇对手论文→提取每篇的叙事模板→选择最有效的→改写我们的稿件。
      改写后重新PK。不通过不进入Phase 4。
```

### 新颖性弱 → 需重新定位

```
可能原因:
  - 与已有工作区分度不够 → 强化"我们做了什么不同的事"的叙述
  - 方法/视角的新颖性没被强调 → 在Abstract和Introduction中重新定位

优化: 重写Abstract,清晰区分"前人做了什么"和"我们做了什么不同的"。
      如果客观上区分度确实不够→考虑换投稿策略(短报vs长文)。
```

---

## §5 叙事优化捷径

如果主要是叙事弱,可以快速优化而不回到Phase 2:

```
1. 读3篇对手论文的Introduction第一段→提取"hook"模式
2. 读3篇对手论文的Abstract→提取结构模板
3. 用最强的模板重写我们的Introduction和Abstract
4. 重跑P3.5对比

循环: 重写→PK→不够→再重写→再PK (最多3次)
```

## §7 硬规则

```
⛔ 必须用 paper-search-mcp 搜索。不可用→WebSearch兜底。
⛔ 3篇对手必须来自目标期刊。不跨期刊比较。
⛔ 最多重跑2次。2次后仍不达标→必须降级目标期刊或接受现状。
⛔ 如果问题重要性<对手均分×0.7→直接建议降级。不浪费优化时间。
⛔ 本Phase在Phase 3之后、Phase 4之前执行。
   如果触发内容修改→修改后必须重新跑Phase 4(randomizer)。
```
