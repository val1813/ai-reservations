# Nature Physics 投稿格式

## 基本参数
- 正文词数: ~3000词 (含正文+方法,不含摘要+参考文献)
- Abstract: ≤150词
- 参考文献: 通常30-50篇
- 图表: 通常4-6个,最多10个display items

## Section结构
- 正文(连续叙述,无section标题)
- Methods(独立section,在正文后)
- Data Availability
- Code Availability
- Acknowledgements
- Author Contributions
- Competing Interests

## 引用格式
- 序号上标: ¹, ²⁻⁴
- 按出现顺序编号
- Nature引用风格

## 图表
- 高分辨率,专业品质
- 图字体清晰可读
- 图表标题简洁

## Cover Letter要求 (重要!)
- triage公式: 一句话finding + 一句novelty + 一句cross-disciplinary significance
- 解释为什么适合Nature Physics (广泛跨领域影响)
- 不能超过1页

## 常见拒稿原因
1. 编辑初审(desk rejection): 缺乏广泛跨领域影响
2. 方法学贡献不足以发Nature系列
3. 故事不完整(重要结论依赖未完成实验)

## 特色要求
- 强调跨领域可读性(非本子领域专家也能理解重要性)
- Methods要足够详细使同行可复现
- 鼓励包含数据和代码可获取性声明
