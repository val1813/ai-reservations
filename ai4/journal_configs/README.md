# Journal Configs

每个文件包含目标期刊的完整格式要求。AI4的Phase 3 (P3_format.md) 会读取对应文件。

## 已有配置

| 文件 | 期刊 | 类型 |
|------|------|------|
| `PRL.md` | Physical Review Letters | 快报·高影响力 |
| `PRD.md` | Physical Review D | 长文·理论物理 |
| `PRX.md` | Physical Review X | 旗舰·突破性 |
| `Nature_Physics.md` | Nature Physics | 综合·跨领域 |

## 添加新期刊

1. 复制任一现有文件
2. 搜索期刊官网投稿指南 → 修改参数
3. 文件名: `[期刊简称].md`

## 通用模板

```
# [期刊全名] 投稿格式

## 基本参数
- 正文词数: [硬限制或建议范围]
- Abstract: ≤[N]词
- 参考文献: [限制或建议]

## Section结构
- [列出要求或惯例]

## 引用格式
- [具体格式]

## 图表
- [分辨率/格式要求]

## Cover Letter
- [特殊要求]

## 常见拒稿原因
- [3-5条]
```
