## Q1: 验证E4修复 -- 对易子量纲

### 修复内容

Eq (4.15): `b_Lindblad = JΓ(f_R − f_L) / (Γ² + 4J²)`

### 量纲分析

| 量 | 量纲 |
|----|------|
| b = Im(C₁₂) | 无量纲 (关联函数) |
| J (hopping) | [1/时间] |
| Γ (热库耦合) | [1/时间] |
| f_L, f_R (Fermi-Dirac占据) | 无量纲 |

- 分子: JΓ = [1/时间²]
- 分母: Γ² + 4J² = [1/时间²]
- 比值: 无量纲

**判定: ✅ 通过。** 分子和分母量纲一致，结果无量纲。

### 极限行为

- **J = 0** (无hopping): b = 0。无hopping则无相干传输，C₁₂ = 0 物理合理。✅
- **Γ = 0** (无热库耦合): b = 0。无驱动则无NESS，关联矩阵退化为平庸。✅
- **Γ → ∞** (强噪声极限): b ∼ J(f_R−f_L)/Γ → 0。强噪声压制量子相干。✅

### 对易子展开验证

展开 `-i[h, C]` 对L=2系统 (h = [[0, -J], [-J, 0]]):

- 对角元: `[-ih, C]₁₁ = 2J·Im(C₁₂)`, `[-ih, C]₂₂ = -2J·Im(C₁₂)`
- 非对角元: `[-ih, C]₁₂ = iJ(C₂₂ − C₁₁)`

所有系数均为J (hopping参数)，而非Γ (热库耦合)。**前版本E4将J误标为Γ的错误已完全修复。** ✅

### Q1结论: ✅ 阻断已消除
