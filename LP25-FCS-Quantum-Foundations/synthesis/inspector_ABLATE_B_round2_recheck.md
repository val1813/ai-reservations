## Q1: E1修复 — §3.2 |C₁₂|² ↔ Var[A_w] 映射

### 1A: |C₁₂|² = |Im(C₁₂)|² 是否是有效的二阶相干度量？

**判定: ✅ 通过**

- **纯态对照:** 对ρ=|ψ⟩⟨ψ|, |ρ_{ij}|²是相干强度的标准二阶度量。文档中C_{ij}=⟨c_i^†c_j⟩_NESS扮演了同构角色——非对角元C₁₂的模方量度site 1↔2间的量子相干强度。
- **L=2数值:** C₁₂ = i·(−0.2), |C₁₂|² = 0.04 ≠ 0, 物理上有区分力。对比: 旧算符c₁^†c₂c₁^†c₂恒为零, |C₁₂|²提供了非平凡的替代。
- **Frobenius范数上下文:** ‖C‖_F² = ΣC_{ii}² + Σ_{i≠j}|C_{ij}|², 非对角部分|C_{ij}|²与对角占据数正交独立——这正是二阶相干度量的标准结构。

**微瑕 (非阻断):** Wick分解论证(行361)说"四费米子关联⟨c₁^†c₂c₂^†c₁⟩分解为两个二阶关联的乘积，自然给出|C₁₂|²"。严格推导为:
```
⟨c₁^†c₂c₂^†c₁⟩ = |C₁₂|² + ⟨n₁⟩⟨1−n₂⟩  (≠ |C₁₂|²)
```
两项均非零, 但文档措辞暗示四费米子关联恰好等于|C₁₂|², 这在数学上不精确。|C₁₂|²作为C₁₂C₂₁的独立定义是成立的——只是不应声称它"来自"四费米子关联的Wick分解(后者还含n₁(1−n₂)项)。

**→ 建议:** 将行361改为"|C₁₂|² = C₁₂ C₂₁ = ⟨c₁^†c₂⟩⟨c₂^†c₁⟩ = |C₁₂|² (二阶关联乘积的直接定义)", 删除与四费米子关联的混淆性连接。

### 1B: |C₁₂|²是否在Born规则下被抹掉？

**判定: ✅ 通过**

Born规则的对角投影操作: B: C_{ij} → δ_{ij}C_{ii}。在此映射下:
- 对角元C₁₁, C₂₂保留
- 非对角元C₁₂, C₂₁ → 0
- |C₁₂|² = C₁₂·C₂₁ → 0·0 = 0

文档行384-385对此有精确陈述:"|C_{ij}|²在Born规则的|·|²投影下变为零（因为Born规则丢弃所有非对角元→Im(C_{ij})信息完全丢失→|Im(C_{ij})|²无法从Born规则的概率分布中恢复）"。——判决正确。

### 1C: Var[A_w]↔|C₁₂|²是否有正确的量纲？

**判定: ✅ 通过 (附带警告)**

- A_w = ⟨ψ_f|A|ψ_i⟩/⟨ψ_f|ψ_i⟩, 分子分母均为复内积, 量纲相同 → A_w无量纲
- Var[A_w]量纲 = A_w²量纲 = 无量纲²
- |C₁₂|² = |⟨c_i^†c_j⟩|², c_i^†c_j是粒子数型算符(无量纲) → |C₁₂|²无量纲
- 量纲匹配 ✓

**警告 (非阻断):** 文档中Var[A_w]的定义不够严格(行370, 376)。在弱测量文献中, Var[A_w]通常指⟨A²⟩_w − (⟨A⟩_w)² (弱值A²的弱值减A_w的平方), 或指指针分布的方差Var[x] = σ² + g²Var_w[A]。文档未指定Var[A_w]的精确操作定义, 导致|C₁₂|²↔Var[A_w]的映射停留在类比层面而非严格推导层面。

**→ 建议:** 在§3.2中显式定义Var[A_w] = ⟨A²⟩_w − (⟨A⟩_w)², 并给出一阶的证明(或声明为推测性映射, 待数值验证)。

### Q1 总判定: ✅ 通过 (1个微瑕, 1个警告, 均非阻断)
