```
J = [∂r/∂t  ∂r/∂φ₀]  （2列，3行）
```

## Q3. 循环论证校对 — True Envelope 定义是否正确应用

### Q3.1 定义链追踪

**起点**：§1.4 从 Bruce & Giblin (1992)、Struik (1988)、Pei et al. (2019) 文献中提炼的严格定义：

> True envelope 充要条件：∂r/∂t × ∂r/∂λ = 0

**应用**：§2 将此定义代入螺旋族计算，得出叉积 = (−v cos Φ, −v sin Φ, 0)。

**结论**：§2.4 解方程组 → v ≠ 0 时无解 → envelope = ∅。

### Q3.2 循环论证判定

循环论证的典型模式是：
- 假设结论成立 → 推导中间步骤 → "证明"结论成立

本推导的逻辑流为：
1. 取公认定义（文献来源）作为判据
2. 对具体对象计算判据的左侧
3. 判断右侧条件是否成立
4. 结论：条件不成立 → envelope 不存在

这是**标准的三段论应用**：大前提（定义）→ 小前提（计算）→ 结论。不存在循环。

### Q3.3 定义自身的一致性

需要检查的潜在隐蔽循环点：

**潜在风险 1**：定义中是否预设了 "envelope 存在"？

检查定义：∂r/∂t × ∂r/∂λ = 0 是**充要条件**。它只是一个方程，不预设解的存在性。解集为空也是定义允许的合法结果。通过。

**潜在风险 2**：维度分析（§1.4 "2 参数 − 2 独立约束 = 0D 特征点 → 1D envelope locus"）是否预设了 envelope 存在？

这就是泛维数分析（generic dimension count）。2 参数 − 2 约束 = 0 余维 → 预期解集为 0 维点集（当解存在且约束相互独立时）。这是一个预期（expectation），不是证明（proof）。随后 §2 的具体计算显示约束**不一致**（cos Φ = 0 且 sin Φ = 0 矛盾），因此实际解集为空。这恰是维数分析的退化情形，**文档正确处理了从 generic expectation 到 specific computation 的过渡**。通过。

**潜在风险 3**：§5.2 的 Minkowski 版本是否等价于原始定义？

§5.2 用分量比例条件 ∂_t r^μ = α ∂_λ r^μ 替代了叉积。在 ℝ³ 中，叉积为零 ⇔ 两向量线性相关，这是等价的。在 ℝ³·¹ 中，分量比例条件是更强的条件（更严格的闵氏协变推广）。文档指出条件更严格 → 结论更坚固。**这不是循环，而是加强**。通过。

### Q3.4 循环论证判定结果

**无循环论证。** 定义被正确、非循环地应用。维数分析的 generic vs specific 过渡处理得当。

> 其所有 2×2 子式为：det₁₂ = 0, det₁₃ = −v cos Φ, det₂₃ = −v sin Φ

> 其所有 2×2 子式为：det₁₂ = 0, det₁₃ = **v sin Φ**, det₂₃ = **−v cos Φ**

修正不影响"当 v ≠ 0 时，det₁₃ 和 det₂₃ 不可能同时为零"的判断（等价于 sin²Φ + cos²Φ = 1），亦不改变"映射 everywhere immersive"的结论。但建议修正以保持推导精度。
