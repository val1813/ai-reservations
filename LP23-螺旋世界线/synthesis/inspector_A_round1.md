## Q3. 循环论证校对

### 3.1 独立验证路径分析
文档声称对 κ 和 τ 进行了"双重独立验证"：

**路径 A**: do Carmo 螺旋专用公式
- κ = a/(a²+b²) → ω²/(ω²+v²)
- τ = b/(a²+b²) → vω/(ω²+v²)

**路径 B**: 通用参数公式（三重积法）
- κ = \|r'×r''\|/\|r'\|³ → 直接计算 → ω²/(ω²+v²)
- τ = [r',r'',r''']/\|r'×r''\|² → 直接计算 → vω/(ω²+v²)

**路径 C**: Frenet 微分公式
- τ = -dB/ds · N → 直接计算 → vω/(ω²+v²)

| 路径对 | 独立性 | 判定 |
|--------|--------|------|
| A vs B | do Carmo 螺旋公式是其 §1.5 的**特定案例**（预推导结果），而三重积公式是其 §1.5 的**通用公式**（需对特定曲线计算）。两者使用不同的数学机制——A 依赖已知螺线分类，B 依赖行列式展开。 | ✅ 独立 |
| B vs C | B 使用标量三重积 det(r',r'',r''') 的代数定义，C 使用 Frenet-Serret 微分方程 τ = -dB/ds·N ——两者从不同公理出发（代数 vs 微分），数值一致意味着 Frenet 框架的自洽性被验证。 | ✅ 独立 |

### 3.2 "验证/检验"类操作审查
| 操作 | 是否只是恢复输入假设? | 判定 |
|------|------------------------|------|

| do Carmo 一致性检查 | 对比两个独立推导的数值结果 | ✅ 无循环问题 |

## Q5. 代数验算

### 5a. 关键代数步骤展开

**叉积 r' × r''**:
```
r' = (-ωs, ωc, v)
r'' = (-ω²c, -ω²s, 0)

det| i    j    k   |
   | -ωs  ωc   v   |
   | -ω²c -ω²s 0   |

i: ωc·0 - v·(-ω²s) = vω²s
j: -[(-ωs)·0 - v·(-ω²c)] = -vω²c
k: (-ωs)(-ω²s) - (ωc)(-ω²c) = ω³(s²+c²) = ω³

→ (vω²s, -vω²c, ω³)  ✅ 与原文一致
```

**叉积 T × N (副法向量 B)**:
```
T = (-ωs, ωc, v)/√(ω²+v²)
N = (-c, -s, 0)

det| i    j    k   |
   | -ωs  ωc   v   |
   | -c   -s   0   |

i: ωc·0 - v·(-s) = vs
j: -[(-ωs)·0 - v·(-c)] = -vc
k: (-ωs)(-s) - (ωc)(-c) = ω(s²+c²) = ω

B = (v sin ωt, -v cos ωt, ω)/√(ω²+v²)  ✅ 与原文一致
```

**三重积 [r', r'', r''']**:
```
r''' = (ω³s, -ω³c, 0)

det| -ωs   ωc    v |
   | -ω²c  -ω²s  0 |
   | ω³s   -ω³c  0 |

按第三列展开:
= v · det| -ω²c  -ω²s |
         | ω³s   -ω³c |

= v·[(-ω²c)(-ω³c) - (-ω²s)(ω³s)]
= v·[ω⁵c² + ω⁵s²]
= vω⁵  ✅ 与原文一致

τ = vω⁵/[ω⁴(ω²+v²)] = vω/(ω²+v²)  ✅
```

**二次方程判别式**:
```
r² + 2ωr + (ω²+v²-c²) = 0

Δ = (2ω)² - 4·1·(ω²+v²-c²)
  = 4ω² - 4ω² - 4v² + 4c²
  = 4(c²-v²)  ✅ 与原文一致

r = [-2ω ± √(4(c²-v²))]/2 = -ω ± √(c²-v²)  ✅
```

### 5b. 极限退化验证

**v = 0 (纯圆)**:
- κ = ω²/ω² = 1 → 曲率 1/R, R=1 ✅
- τ = 0 → 平面曲线扭矩为 0 ✅
- det(g) = -c² → Lorentz 型 ✅
- ds² = (ω²-c²)dt² + 2ω dt dφ₀ + dφ₀² → 包含类时和类空方向 ✅

**v = c (光速推进)**:
- κ = ω²/(ω²+c²) → 有限非零 ✅
- τ = cω/(ω²+c²) → 有限非零 ✅
- det(g) = 0 → 退化 ✅
- ds² = (ωdt + dφ₀)² → 完全平方，1 个零方向 ✅
- 零方向 dφ₀/dt = -ω → 代入嵌入得 X^μ = (t, cos(const), sin(const), ct) → ds² = -c²+c² = 0 ✅

**ω → 0 (无旋转)**:
- κ = 0 → 直线 ✅
- τ = 0 → 直线无扭矩 ✅
- r(t, φ₀) = (cos φ₀, sin φ₀, vt) → 圆柱面 (ω=0 时族参数 φ₀ 仍扫出圆) ✅
