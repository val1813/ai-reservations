## Round 1 新增

### K001: 螺旋Frenet参数（A博士§1）
- κ = ω²/(ω²+v²), τ = vω/(ω²+v²), τ/κ = v/ω
- v=c时κ,τ有限非零——Frenet标架在欧氏空间中完好，奇异性仅在Minkowski嵌入中出现
- 来源: do Carmo (1976) + 三重积双重验证
- 置信度: 高（INSPECTOR代数验算通过）

### K002: 螺旋族Swept Surface诱导度规（A博士§2）
- ds² = (ω²+v²-c²)dt² + 2ω dt dφ₀ + dφ₀²
- det(g) = v²-c²（不含ω！）
- 因果结构由纵波速度v单独决定
- 置信度: 高

### K003: 包络面≠光锥面（A博士§3，¬H原始形式证伪）
- 维度不匹配（2D vs 3D）
- 拓扑不匹配（S¹ vs S²）
- 几何不匹配（null cylinder vs null cone）
- v=c时det(g)=0但曲面是零圆柱面而非光锥面
- 置信度: 极高（INSPECTOR独立确认三项匹配均成立）

### K004: v=c时零圆柱面的零生成子（A博士§3.4）
- ds² = (ω dt + dφ₀)² → 完全平方
- 零方向: dφ₀/dt = -ω
- 零生成子: 空间固定的类光直线 x=cos(φ₀⁰), y=sin(φ₀⁰), z=ct
- 置信度: 高

### K005: Swept Surface ≠ True Envelope（A博士§5.4）
- 当前计算的是族参数扫出的曲面，非严格包络
- 真正的包络需切触条件 ∂r/∂φ₀ 与曲面法向正交
- 如果true envelope存在且不同，§2-§3结论可能需修正
- 置信度: 待验证（Struik 1988, Bruce & Giblin 1992）

### K006: DNA拓扑↔Chern-Weil同构（B博士跳跃A）
- Lk=Tw+Wr ↔ c₁ = (1/2π)∫F
- Linking number ↔ 第一Chern数（整数量子化）
- Twist ↔ 局部联络A的积分 → 量子相位
- Writhe ↔ 底空间曲率 → 引力贡献
- 弱点: 4维时空中linking number定义需推广
- 置信度: 中（同构在3维严格，4维推广待验证）

### K007: 5维KK度规与Compton波长（B博士跳跃D）
- ds²_{(5)} = η_{μν}dx^μdx^ν + ℓ²(dχ + (ω/ℓ)dt)²
- 5维光锥条件 → ℓ = ℏ/(mc) = ƛ_C（推导非假设）
- 类时4维运动+相位演化=5维类光
- 置信度: 中（INSPECTOR确认量纲，需验证多粒子推广）

### K008: 节点=物质源（B博士跳跃D推论D1）
- Ψ=0处F_{μν}≠0（相位奇点 → 非平凡曲率）
- 波函数节点在5维几何中产生引力曲率
- 物质的存在=波函数有节点
- 置信度: 低（推测性，等定量估算）

### K009: 等距能谱→类光包络（B博士跳跃B）
- 等距能谱 → Dirichlet核 → 完美revival → 包络面退化（类光）
- 非谐能谱 → 模糊revival → 包络面类时
- 质量 = 能谱非谐性（m>0 ↔ α>0）
- 置信度: 中（同构的"包络面"空间对应不严格）

### K010: INSPECTOR阻断—B博士预测A1算术错误
- 地球表面Δφ: 2×10⁻⁸ rad → 应为 ~10⁻⁴ rad
- 中子星表面Δφ: 6×10³ rad → 应为 ~10⁶ rad
- 误差来源: L/λ指数相乘时少加3个数量级
- 修正后地球场景可能已进入可测范围
- 置信度: 高（INSPECTOR独立验算确认）
