## 北极星命题（¬H形式）

**隐藏假设 H**: 量子相位演化（希尔伯特空间的酉演化 e^(-iHt/ℏ)）和相对论因果结构（洛伦兹流形的光锥 ds²=0）是两个独立的基本结构，仅在狄拉克方程"共存"而非"统一"。

**否定命题 ¬H**: e^(iθ) 是唯一的几何基元——量子相位演化就是螺旋在时间轴上的推进，相对论光锥就是螺旋族的包络面，引力就是螺旋轴的弯曲。三者是同一几何的三个投影。

## 本轮聚焦：S1 — 平坦时空螺旋包络≡光锥的微分几何证明

这是整个框架的**生死关口**。在启动复杂的GR计算之前，必须先确认在平坦时空中螺旋族的包络面是否严格等于光锥面。

### 具体计算任务

**给A博士（学院派）：**
1. 参数化螺旋族: x(t,φ₀) = cos(ωt+φ₀), y(t,φ₀) = sin(ωt+φ₀), z(t,φ₀) = vt
   - 其中 φ₀ ∈ [0,2π) 是螺旋族的初始相位参数
2. 计算单条螺旋的Frenet曲率κ和挠率τ
3. 计算螺旋族的包络面方程
4. 证明：当 v = c 时，包络面满足 ds² = dx²+dy²+dz²-c²dt² = 0
5. 如果 v ≠ c：包络面的ds²符号是什么？是否类空/类光/类时？

**给B博士（野路子）：**
1. 从其他学科找"螺旋族包络"的同构结构
2. 特别关注：DNA双螺旋的拓扑约束、音乐的泛音列包络、建筑学的拱结构包络
3. 尝试找到"包络面≡光锥"在另一个学科中的对应现象
4. 提出"如果这个同构成立，最奇怪的预测是什么"
