暗能量状态方程 w(z) 如何修改局域 Hubble 参数的径向分布？
Friedmann 方程中暗能量的贡献：
H²(z) = H₀² [ Ω_m(1+z)³ + Ω_r(1+z)⁴ + Ω_DE × f_DE(z) ]

其中 f_DE(z) = exp[ 3∫₀ᶻ (1 + w(z'))/(1+z') dz' ]

对 w = -1（Λ）：f_DE(z) = 1（常数）
对 w(z) = w₀ + w_a × z/(1+z)（Chevallier-Polarski-Linder, CPL）：
f_DE(z) = (1+z)^{3(1+w₀+w_a)} × exp(-3w_a × z/(1+z))
把 z 转换成共动距离 r（在平坦宇宙中）：
r = c ∫₀ᶻ dz'/H(z') ← 隐式关系，z = z(r)

局域 Hubble 参数作为径向位置的函数：
H(r) = H(z(r)) ← 这是全息加权积分的被积函数

对距离阶梯范围（z ≲ 0.1，r ≲ 300 Mpc）：
z ≈ H₀ r / c（Hubble定律线性近似）
→ H(r) ≈ H₀ × [1 + (dH/dz)|_{z=0} × (H₀r/c) + ...]

关键导数：
(1/H₀)(dH/dz)|_{z=0} = ½[3Ω_m + 4Ω_r + 3(1+w₀)Ω_DE]
≈ ½[3×0.31 + 3(1+w₀)×0.69]
= ½[0.93 + 2.07(1+w₀)]
对 w₀=-1（Λ）：= ½[0.93 + 0] = 0.465 ≡ q₀ （减速参数的绝对值）
对 w₀=-0.9： = ½[0.93 + 0.207] = 0.569
关键：w₀ ≠ -1 使 H(r) 的径向梯度更陡。
梯度越陡，小屏（R_ladder）和大屏（R_CMB）的加权平均差越大。
这是暗能量贡献额外 δ_H 的机制。
第一步：全息加权平均的 w(z) 修正

把 H(r) 展开到一阶，计算加权平均的修正
H(r) = H₀ × [1 + q₀(w₀) × H₀r/c + O(r²)]

其中 q₀(w₀) = ½[Ω_m + (1+3w₀)Ω_DE] + Ω_r（精确到一阶）
= ½[0.31 + (1+3w₀)×0.69]

全息加权平均（高斯权重 exp(−r²/R²)）：

H₀^{obs}(R) = ∫₀ᴿ H(r) e^{-r²/R²} r² dr / ∫₀ᴿ e^{-r²/R²} r² dr
（3D球对称，体积元 4πr²dr）

线性项的贡献：
⟨H₀r/c⟩_R = H₀/c × ∫₀ᴿ r × e^{-r²/R²} r² dr / ∫₀ᴿ e^{-r²/R²} r² dr
= H₀/c × ⟨r⟩_R

计算 ⟨r⟩_R（3D高斯平均）：
∫₀^∞ r³ e^{-r²/R²} dr = R⁴/2
∫₀^∞ r² e^{-r²/R²} dr = √π R³/4
⟨r⟩_R = (R⁴/2) / (√π R³/4) = 2R/√π ≈ 1.128 R

所以：H₀^{obs}(R) = H₀ × [1 + q₀(w₀) × 1.128 H₀R/c]

差值（两个视界之间）：
ΔH₀^{DE} = H₀^{obs}(R_ladder) − H₀^{obs}(R_CMB)
= H₀ × q₀(w₀) × 1.128 × H₀/c × (R_ladder − R_CMB)
< 0 （R_CMB >> R_ladder，CMB测量值更高？）
方向错了。
线性梯度效应让 H₀^{obs}(R_CMB) > H₀^{obs}(R_ladder)——
因为大屏平均了更大 z 处（H 更大）的贡献。
但观测上是 H₀(ladder) > H₀(CMB)，方向相反。

这意味着：均匀暗能量的径向梯度贡献的方向错误。
需要加入局域不均匀性——空洞效应和暗能量的相互作用。
