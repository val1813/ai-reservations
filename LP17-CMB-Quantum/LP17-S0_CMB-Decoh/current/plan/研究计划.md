# LP17-S0 研究计划

## 北极星（来源：LP-17）
CMB的H₀=67.4是一个经典测量还是被早期宇宙的量子相干性污染的混合信号？

## 核心假设（掀桌子的）
CMB光子到达探测器时携带的是宇宙在z=1100处的经典统计信息。
如果膨胀期间的量子涨落在最大尺度上（ℓ<30）退相干不完全，Planck的H₀就不是"经典宇宙的H₀"而是"经典+量子残余的混合H₀"。

## S0 上游假设检验
**命题：** 移除ℓ<30→重跑ΛCDM MCMC→H₀是否移动？
**工具：** CAMB + emcee + Planck 2018 binned TT数据
**判定标准：** H₀移动>1σ → 支持假说；移动<0.5σ → null结果

## S0实验设计
1. 用Planck 2018最佳拟合参数生成合成Cℓ数据（含宇宙学方差+仪器噪声）
2. 全数据MCMC → 获取baseline H₀约束
3. ℓ≥30截断MCMC → 获取截断H₀约束
4. 比较：ΔH₀ = H₀(ℓ≥30) - H₀(full)
5. 如果ΔH₀ > 1σ且方向朝SH0ES(72.7)：支持量子退相干假说
