## 二、关键洞察：BAO 和 CMB 不是"球对称全息屏"

### 2.1 全息屏的几何结构

Cepheid/SNIa 距离阶梯：观测者周围的球对称体积 → 各向同性全息屏 ✓
```
全息屏 = 半径为 R_ladder 的球面
信息分布 = 球对称（空洞近似球对称）
加权核 = exp(−r²/R²) ✓
```

BAO：声学峰是 ~150 Mpc 的标准尺，沿视线方向的投影 → 高度各向异性核
```
BAO 约束的是：∫₀^{z_BAO} dz/H(z) × [声学尺的角尺度]
这不是球对称体积内的加权平均
这是沿一个窄锥体的视线积分
```

CMB：声学峰在 z=1100，角尺度 ~1° → 这是一个特定共动尺度的测量
```
CMB 约束的是：r_s(z_drag) / D_A(z_rec)
= [声学视界在 z~1060 的物理尺度] / [到 z=1100 的角径距离]
这也是视线积分，不是球对称屏
```

### 2.2 修正：引入核函数 K(R, method)

不同方法不是简单的"不同半径的球对称全息屏"——它们有不同的几何核函数：

```
H₀^{obs}(method) = ∫₀^∞ H₀(R) × K_method(R) dR / ∫₀^∞ K_method(R) dR
```

而不是：
```
H₀^{obs}(method) = H₀(R_method)  ← 这是简化版，BAO不符合的原因
```

**距离阶梯的核函数（球对称）：**
```
K_ladder(R) = exp(−R²/R_ladder²)  [高斯权重，近似成立]
```

**BAO 的核函数（视线锥，非球对称）：**
```
K_BAO(R) = ∫ dΩ dχ δ_D(χ − χ_BAO(Ω)) × [BAO 尺度匹配权重]
```
BAO 沿视线方向积分 D_A(z) 和 H(z)，其"有效全息屏"不是球面，是两个窄锥的交集（声学峰在角度空间的投影）。

**CMB 的核函数（二维角功率谱）：**
```
K_CMB(R) = 不是体积内的加权平均
= 而是最后散射面上二维角功率谱的 Fisher 信息分布
= 主要由 ℓ ~ 200-1500 的声学峰贡献
= 对应共动尺度 ~ 10-150 Mpc（在 z=1100 处）
```

### 2.3 关键修正：BAO 和 CMB 测的不是"体积加权 H₀"

BAO 和 CMB **不直接测量 H₀**。它们测量的是距离-红移关系中的组合参数，H₀ 是通过参数拟合间接推断的。

具体来说：
- **BAO**：在红移 z 处测量 D_H(z)/r_d 和 D_M(z)/r_d，其中 r_d 是声学视界。H₀ 通过 r_d ∝ 1/H₀ 进入。
- **CMB**：测量 θ_s = r_s/D_A，其中 r_s 是声学视界，D_A 是角径距离。H₀ 通过 D_A 中的积分进入。

这两种方法的"H₀ 灵敏度"不是对局域膨胀率的直接加权——它们是对**宇宙膨胀历史的积分泛函**的约束。

## 三、修正方案：直接比较膨胀率泛函

与其把每个测量映射到一个"有效 R"再比较 H₀(R)，不如直接在膨胀率泛函的层面比较：

### 3.1 定义膨胀率泛函

```
H₀^{obs}[method] = H₀^{true} × ∫₀^∞ w_method(r) × [H(r)/H₀^{true}] dr
```

其中 w_method(r) 是方法特有的权重函数，由该方法的 Fisher 信息矩阵决定：

```
w_method(r) = ∂(方法观测量)/∂H(r) × [噪声权重]
```

### 3.2 Cepheid/SNIa 的权重函数

SNIa 直接测量光度距离：
```
d_L(z) = (1+z) × ∫₀ᶻ dz'/H(z')
```
H₀ 通过 H(z) = H₀ × E(z) 的整体归一化进入。

在局域（z ≪ 1）：H(z) ≈ H₀，所以 SNIa 的 ∂(d_L)/∂H₀ ∝ 1/H₀²。
权重集中在小 z（~0.01-0.1），对应 r ~ 40-400 Mpc。
→ 球对称近似合理。全息屏半径 ~300 Mpc。✓

### 3.3 BAO 的权重函数

BAO 测量 α_∥(z) = D_H(z)/r_d 和 α_⊥(z) = D_M(z)/r_d。

```
∂α_∥/∂H₀ = −D_H(z)/r_d × ∂ln(r_d)/∂H₀ + ∂D_H/∂H₀ / r_d
           = −D_H/r_d × (1/H₀) + (−1/H₀²) × 1/r_d
```

第一项是 r_d 的 H₀ 依赖性（r_d ∝ 1/H₀），第二项是 H(z) ∝ H₀ 的直接贡献。

BAO 的权重函数**不是对 H(r) 的加权**，而是对**不同 z 处 H(z) 和 r_d 的联合约束**。

这是 BAO 不适合直接映射到"全息屏半径 R"的根本原因。

### 3.4 CMB 的权重函数

CMB 测量：
- ω_b, ω_c（物理密度）：与 H₀ 通过 Ω_b = ω_b/h² 退化
- θ_s = r_s/D_A：声学峰位置，H₀ 通过 D_A(z_rec) 的积分进入
- τ（再电离光深）：与 H₀ 通过 A_s e^{-2τ} 退化

CMB 对 H₀ 的约束来自**参数退化**，不是"测量一个全息屏内的平均膨胀率"。

## 四、把 BAO 偏离纳入框架

### 4.1 BAO 的有效"R"不是 1-2 Gpc

BAO 的体积权重分布：
- DESI 2024 使用 0.1 < z < 2.1 的 BAO 峰
- 共动距离：z=0.1 → 380 Mpc，z=2.1 → 5.7 Gpc
- 但 BAO 的 H₀ 灵敏度在 z~0.3-0.5 处达到峰值（DESI 最精确的 BAO bin）

BAO 对 H₀ 的约束来自：
1. r_d（声学视界）的标定：r_d ~ 147 Mpc（由 CMB 的 ω_b, ω_c 决定）
2. α_∥, α_⊥ 在多个 z bin 的联合约束
3. H₀ 通过 H(z) = H₀ × E(z; Ω_m, Ω_Λ) 的整体归一化进入

BAO 的"有效 H₀ 测量区域" ≈ **声学视界尺度的体积内**（~150 Mpc 共动），不是 ~1-2 Gpc。

```
R_eff(BAO) ≈ r_d ~ 150 Mpc  ← 这是 BAO 标定的物理尺度
```

而不是视线距离 ~2 Gpc。

### 4.2 修正后的标度关系预测

用 R_eff(BAO) ~ 150 Mpc（而不是 1-2 Gpc）重算：

```
r_eff/R = 250/√(250² + 150²) = 250/291.5 = 0.857

H₀(BAO) = 67.4 × [1 + 0.111 × 0.857]
        = 67.4 × 1.095
        = 73.8 km/s/Mpc
```

这比观测值 68.7 高了 5.1 km/s/Mpc——**方向错了**！

说明 R_eff(BAO) ~ 150 Mpc 也不对。BAO 的声学尺度 r_d 标定了**物理距离**，但 r_d 本身由早期宇宙（z~1060）的物理决定——它不"测量"局域 H₀，它是**局域 H₀ 测量的一个输入**。

### 4.3 真正的修正：BAO 的 H₀ 不是"全息加权平均"

BAO 对 H₀ 的约束来自**倒推**：

```
1. 测量 α_∥(z), α_⊥(z) → 在每个 z bin 约束 D_H(z) 和 D_M(z)
2. 用 CMB 标定的 r_d (~147 Mpc) → 将无量纲距离转为物理距离
3. 从 D_M(z) ∝ ∫₀ᶻ dz/H(z) 提取 H₀
```

步骤 2 是关键的：**BAO 的 H₀ 依赖于 CMB 给出的 r_d**。BAO 本身只测量无量纲距离比——H₀ 必须从 r_d(z_CMB) 和 D(z_BAO) 的比值中提取。

如果 r_d 在全息框架中也受截断效应影响（z=1060 的 drag epoch 对应一个更小的视界），那么：

```
H₀(BAO) = 从 BAO 无量纲距离 + CMB 声学视界 → 提取的 H₀
```

这里 CMB 声学视界 = r_d(z=1060) = 由 z=1060 时刻的视界尺寸决定
z=1060 时的哈勃半径：H⁻¹(z=1060) ≈ 0.05 Mpc（物理坐标）
z=1060 时的粒子视界（到那个时刻能因果接触的最大距离）：~0.2 Mpc（物理）

对应的共动尺度：r_d ~ 0.2 × (1+1060) ≈ 212 Mpc（共动）

这个值比局域空洞（250 Mpc 共动空洞半径）小，但量级相近。

**关键**：BAO 使用的声学视界 r_d 是在 z=1060 时刻标定的——那是一个完全不同的全息屏。它的半径极小（物理 ~0.2 Mpc），温度为 T ~ 3000 K（不是今天的 2.7 K），全息屏的比特容量完全不同。

## 五、真正的方向：不是 H₀(R)，而是多屏一致性条件

### 5.1 放弃"H₀ 是 R 的单变量函数"的思路

前面的标度检验有个隐藏的假设：存在一个"真实宇宙平均 H₀^{true}"，所有测量都是对这个值在不同全息屏上的加权平均。

但这个假设本身是错的：**在分层的宇宙中，不存在单一的"真实 H₀"**。H₀ 是 FLRW 度规的均匀各向同性近似下的参数——它假定宇宙在测量尺度上均匀。当测量尺度小于均匀性尺度时，FLRW 近似本身就不成立，H₀ 的定义就依赖于测量尺度。

**全息截断框架的正确表述：**

```
不是：H₀(R) = 真实 H₀ + 全息偏差

而是：在不同的因果钻石内，FLRW 度规的有效参数 H₀^{eff} 不同。
      这不是"测量偏差"，这是不同因果域有不同有效度规参数的必然结果。
```

### 5.2 多屏一致性条件

定义：在因果钻石 D(R) 内，有效 FLRW 参数 H₀^{eff}(R) 由屏上信息的全息加权平均决定。

一致性条件：当两个钻石相交时，交集区域的有效参数必须一致。

这给出了一个非平凡的约束：
```
∂H₀^{eff}(R)/∂R = −δ_H × [r_void² / (r_void² + R²)^(3/2)]
```
（这是 H₀(R) 对 R 的导数，从 r_eff/R 的形式直接求导）

在 R = r_void 处：导数取最大值 ~ −δ_H/(2r_void)。
在 R → ∞：导数 → −δ_H × r_void²/R³ → 快速下降到零。

这意味着：**H₀ 的有效值在 R ~ r_void 附近变化最快**——超过空洞边界后，新增的体积几乎不贡献 δ_H。

### 5.3 重新解释观测数据

| 测量方法 | 支配物理尺度 | 有效 H₀ 的含义 |
|----------|-------------|---------------|
| Maser (7 Mpc) | 空洞内 | 空洞内部的 H |
| TRGB (10 Mpc) | 空洞内 | ≈ 同上 |
| Cepheid (40-300 Mpc) | 跨越空洞边界 | 从空洞内过渡到空洞外 |
| SBF (100 Mpc) | 空洞内 | ≈ 空洞内部的 H |
| H0LiCOW (~Gpc) | 远大于空洞 | 接近宇宙平均，但受视线结构影响 |
| BAO (~150 Mpc 声学尺度) | ≈ 空洞尺度 | 声学视界标定——这个尺度独立于空洞 |
| CMB (全天空) | 最大因果钻石 | 宇宙学平均 |

BAO 的特殊性现在清楚了：**它的声学尺度 r_d ~ 150 Mpc 碰巧与局域空洞半径 r_void ~ 250 Mpc 在同一个量级**。BAO 既不完全在空洞内（像 Maser），也不完全在空洞外（像 CMB）。它是"跨边界"的探针。

这是之前标度检验中 BAO 偏离的根本原因——BAO 不是 H₀(R) 上的一个点，它是两个不同尺度（r_d 和检测体积）的联合约束。
