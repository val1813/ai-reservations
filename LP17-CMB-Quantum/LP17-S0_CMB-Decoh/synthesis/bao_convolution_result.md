## 一、BAO 的 H₀ 如何被约束

BAO 测量无量纲距离比：

```
α_⊥(z) = D_M(z) / r_d
α_∥(z) = D_H(z) / r_d = c / [H(z) × r_d]
```

其中：
- D_M(z) = c ∫₀ᶻ dz'/H(z')：共动角径距离
- r_d ≈ 147 Mpc：z~1060 处的声学视界（物理尺度，由 CMB 的 ω_b, ω_c 固定）

H₀ 通过两个途径进入：
1. H(z) = H₀ × E(z; Ω_m, Ω_Λ)，支配 D_M 和 D_H
2. r_d 本身含 H₀（r_d 的物理值由早期宇宙的声学物理决定，与晚期 H₀ 无关——它由 CMB 独立标定）

当 r_d 由 CMB 给定后，BAO 对 H₀ 的约束完全来自**视线积分 D_M(z)** 对 H₀ 的灵敏度。

## 三、视线积分的修正

角径距离被空洞修改：

```
D_M(z) = c ∫₀ᶻ dz'/H(z')
       = c ∫₀ᶻ dz' / [H₀^{true} × E(z') × (1 + δ_H × exp(−χ(z')²/r_void²))]
```

对 δ_H ≪ 1，展开到一阶：

```
D_M(z) ≈ c/H₀^{true} × [∫₀ᶻ dz'/E(z') − δ_H × ∫₀ᶻ dz'/E(z') × exp(−χ(z')²/r_void²)]
       = D_M^{ΛCDM}(z) − ΔD_M(z)
```

修正项 ΔD_M：

```
ΔD_M(z) = c/H₀^{true} × δ_H × ∫₀ᶻ dz'/E(z') × exp(−χ(z')²/r_void²)
```

换积分变量 z → χ（共动距离）：

```
dχ = c dz / [H₀^{true} × E(z)]
→ dz/E(z) = H₀^{true}/c × dχ

ΔD_M(z_BAO) = c/H₀^{true} × δ_H × H₀^{true}/c × ∫₀^{χ_BAO} dχ × exp(−χ²/r_void²)
            = δ_H × ∫₀^{χ_BAO} dχ exp(−χ²/r_void²)
            = δ_H × (√π/2) × r_void × erf(χ_BAO/r_void)
```

对 χ_BAO ≫ r_void（BAO 红移 z~0.38 → χ~1500 Mpc ≫ 250 Mpc）：
erf(χ_BAO/r_void) ≈ 1

```
ΔD_M = δ_H × (√π/2) × r_void
     = 0.111 × 0.8862 × 250 Mpc
     = 24.6 Mpc
```

修正量与红移无关（只要 χ_BAO ≫ r_void）——这是一个**常数距离偏移**。

## 四、H₀ 约束的修正

BAO 测量 α_⊥ = D_M(z) / r_d。

```
D_M^{obs}(z) = D_M^{ΛCDM}(z) − 24.6 Mpc

其中 D_M^{ΛCDM}(z) ∝ 1/H₀^{fit}
```

BAO 拟合中，H₀^{fit} 调整使 D_M(z) ∝ 1/H₀^{fit} 匹配实测的 α_⊥ × r_d^{CMB}：

```
α_⊥^{obs} × r_d^{CMB} = D_M^{ΛCDM}(z; H₀^{fit}) − 24.6 Mpc
[D_M^{ΛCDM}(z; H₀^{true})] × (H₀^{true}/H₀^{fit}) − 24.6 Mpc
= D_M^{true}(z) × (H₀^{true}/H₀^{fit}) − 24.6 Mpc
```

设 D_M^{true}(z) = c/H₀^{true} × d(z)（无量纲距离 d(z)）：

```
α_⊥^{obs} × r_d^{CMB} = c/H₀^{fit} × d(z) − 24.6 Mpc
```

真实物理距离（无空洞修正）：
```
α_⊥^{obs} × r_d^{CMB} = c/H₀^{true} × d(z)
```

等号两边相等：
```
c/H₀^{true} × d(z) = c/H₀^{fit} × d(z) − 24.6 Mpc
1/H₀^{fit} − 1/H₀^{true} = 24.6 Mpc / (c × d(z))
H₀^{fit} = H₀^{true} / [1 − 24.6 Mpc × H₀^{true} / (c × d(z))]
```

对 z=0.38（DESI 最精确 BAO bin）：
- d(0.38) = ∫₀^{0.38} dz'/E(z')，用 Ω_m=0.31, Ω_Λ=0.69
- 数值积分：d(0.38) ≈ 0.362

```
H₀^{true} / c × 24.6 Mpc = 24.6 / 4330 = 0.00568

H₀^{fit} = 67.4 / [1 − 0.00568/0.362]
         = 67.4 / [1 − 0.0157]
         = 67.4 / 0.9843
         = 68.5 km/s/Mpc
```
