## 估算一：Zurek退相干时标

**问题：** 超视界模式在哈勃时间内能退相干完全吗？

**Zurek公式：** τ_D / τ_H ≈ (λ_th / Δx)² × (N_env)⁻¹

**代入数值：**

```
λ_th = ħc / k_B T_CMB
     = (1.055×10⁻³⁴ × 3×10⁸) / (1.38×10⁻²³ × 2.725)
     ≈ 8.4 × 10⁻³ m ≈ 8.4 mm

Δx (ℓ=2) = 2π × d_H / 2 ≈ 40 Gpc ≈ 1.2×10²⁷ m

(λ_th / Δx)² = (8.4×10⁻³ / 1.2×10²⁷)² ≈ 5×10⁻⁵⁹

N_env = (l_H / l_P)² = 10¹²³  （Bekenstein-Hawking视界熵）
```

**结果：**
```
τ_D / τ_H ≈ 5×10⁻⁵⁹ / 10¹²³ ≈ 10⁻¹⁸²
```

**结论：** 退相干比哈勃时间快182个数量级。标准Zurek机制下，量子相干性在宇宙极早期已被完全抹除。假说要成立，需要N_env不是视界熵的某个截断值。

## 估算二：Unruh温度修正

**问题：** 宇宙学加速膨胀是否产生可观测的Unruh热噪声？

**代入数值：**

```
a = |q| × H₀ × c （q ≈ -0.55, ΛCDM减速参数）
  = 0.55 × 2.18×10⁻¹⁸ s⁻¹ × 3×10⁸ m/s

**结果：**

```

**结论：** 即使乘以H₀灵敏度δH₀/H₀~1%，Unruh修正对H₀的贡献~10⁻³⁰ km/s/Mpc。要让这个机制产生~5 km/s/Mpc的效应，需要31个数量级的放大——不存在已知物理机制。

## 估算三：量子Fisher信息界

**问题：** Planck的H₀精度是否已超越量子Cramér-Rao下界？

**代入数值：**

```
CMB有效模式数：N_modes = Σ_{ℓ=2}^{2500} (2ℓ+1) ≈ 6.25×10⁶
经典Fisher极限：δH₀_min ~ H₀ / √N_modes ~ 67.36 / 2500 ≈ 0.027 km/s/Mpc
Planck实测：δH₀ ≈ 0.54 km/s/Mpc
比率：0.54 / 0.027 ≈ 20×
测量效率：η = (0.027/0.54)² ≈ 1/400 ≈ 0.25%
```

**结论：** Planck精度离经典Fisher极限还差20倍，瓶颈是参数退化（H₀-τ-As链），不是量子测量效应。量子Fisher界更加宽松，未被违反也未被接近。

## 未被关闭的路：N_eff(ℓ) 截断机制

整个Zurek估算崩塌的唯一位置：**N_env ~ 10¹²³**。

这个数字来自Bekenstein-Hawking熵 S_BH = A/(4l_P²)，它假设视界以最大密度存储信息。但如果换一个前提：

> **超视界模式在退出视界时，有效可接触的环境自由度数 N_eff 不是全部视界熵，而是受到某个截断的有限数。**

那么：

```
τ_D / τ_H ≈ (λ_th/Δx)² × (N_eff)⁻¹

要使 τ_D/τ_H ~ 1（退相干不完全）：
N_eff < (λ_th/Δx)² = 5×10⁻⁵⁹
```

需要的N_eff极其微小——但关键不在于这个具体数字，而在于：

1. **de Sitter热力学中，N_env(ℓ)的ℓ依赖性来自哪里？**
   - 候选1：每个ℓ模式在退出视界时，接触的环境自由度 ≠ 全部视界自由度，而是与模式"波长/视界半径"比有关的某个函数
   - 候选2：全息原理暗示bulk自由度 < 边界自由度——模式只与因果接触的边界区域耦合
   - 候选3：dS/CFT对应中，超视界模式的环境 = 未来无穷远边界上的CFT自由度，其有效秩随ℓ减小

2. **如果N_eff(ℓ) ~ ℓ^p（p>0），低ℓ模式自然退相干更慢**

3. **这是LP17值得打的S2**：从de Sitter热力学/全息原理/CFT对应的第一性原理，推导N_eff(ℓ)的函数形式
