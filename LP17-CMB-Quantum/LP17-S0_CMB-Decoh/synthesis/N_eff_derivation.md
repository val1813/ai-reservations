# N_eff(ℓ) 推导：超视界模式的有限有效环境自由度

## 第一步：Zurek 估算用错了 N_env

原估算：
```
τ_D/τ_H ≈ (λ_th/Δx)² × N_env⁻¹
        ≈ 5×10⁻⁵⁹ / 10¹²³ ≈ 10⁻¹⁸²
```

这里犯了一个关键错误：**把全视界熵当作单个模式的环境自由度数**。

视界熵 S_BH = A/(4l_P²) ~ 10¹²² 计数的是**整个视界球面上所有 Planck 面元的自由度总和**。一个单独的傅里叶模式 Y_ℓm 不可能与整个视界的全部自由度都耦合——它只与它因果接触的那部分耦合。

**修正**：N_env → N_eff(ℓ) = 模式 ℓ 在视界穿越时有效耦合的环境自由度数。

## 第二步：单个模式承载的熵

在 de Sitter 空间中，考虑一个无质量标量场（作为曲率扰动 ζ 的类比）。模式展开：

```
φ(x,η) = ∫ d³k/(2π)³ [a_k φ_k(η) e^{ik·x} + h.c.]
```

每个模式 k 是一个独立的量子谐振子。当模式穿越视界时（k = aH），它从量子涨落转变为经典扰动。

关键问题：穿越视界时，**单个模式从视界"提取"了多少信息存储容量？**

---

### 2.1 Bekenstein 界应用于单模式

Bekenstein 界：一个半径为 R、能量为 E 的物理系统，其熵的上界是

```
S ≤ 2π R E / (ħc)
```

对穿越视界的模式 k（此时 λ_phys = 2π/H）：
- 系统的有效半径：R ~ H⁻¹（模式此时正好填满视界体积）
- 模式的能量：E_k = ħω_k = ħ × ck/a = ħcH（穿越时 k = aH）

代入：
```
S_max(k) = 2π × H⁻¹ × ħcH / (ħc) = 2π ~ O(1)
```

**这是核心结果：单个穿越视界的模式，其 Bekenstein 熵上界是 O(1)。**

每个模式承载的信息量约等于 1 比特（或更准确地说，一个谐振子基态的信息量），而不是 10¹²² 比特。

---

### 2.2 一致性检验：所有模式的熵之和

de Sitter 空间中，穿越视界的总模式数（考虑 k 从 0 到 UV 截断）：

```
N_modes ~ ∫₀^{k_max} d³k V/(2π)³
        ~ (4π/3 H⁻³) × (H³)/(6π²)    [k_max ~ H, 体积 ~ H⁻³]
        ~ 2/(9π) ≈ 0.07
```

等等——这个数不对。视界体积内只有不到一个模式？这说明计算有问题。

**修正**：在 curved spacetime 中，模式的正确计数要考虑所有的角动量 ℓ。在静态 de Sitter 坐标中：

```
总模式数 = Σ_{ℓ=0}^∞ (2ℓ+1) ≈ Λ²
```

其中 Λ 是 UV 截断。物理截断是 Λ ~ M_Pl/H（普朗克尺度下的角动量截断）。

```
N_total ≈ Σ_{ℓ=0}^{M_Pl/H} (2ℓ+1) ≈ (M_Pl/H)²
```

每个模式承载熵 S_per_mode ~ O(1)，总熵：

```
S_total ~ (M_Pl/H)² × O(1) ~ (M_Pl/H)² = S_dS ✅
```

与 de Sitter 熵一致。这验证了"每模式 O(1) 比特"的假设。

## 第三步：N_eff(ℓ) 的 ℓ 依赖性

### 3.1 一个模式与多少环境自由度耦合？

模式 ℓ 在穿越视界时，其特征角尺度为 Δθ ≈ π/ℓ。在其因果钻石（causal diamond）内部，它可以与角尺度 ≤ π/ℓ 的其他模式交换信息。

**有效环境自由度 = 模式 ℓ 的因果钻石内可以"塞进"多少独立的环境模式。**

模式 ℓ 的因果钻石：
- 空间跨度：~ H⁻¹（视界尺度）
- 角跨度：Δθ ≈ π/ℓ
- 四维体积中的量子态数目受到全息界面的约束

**全息约束**：因果钻石的边界面积约束了其内部的最大熵：

```
S_causal(ℓ) = A_boundary(ℓ) / (4l_P²)
```

模式的因果钻石的边界面积：
- 模式的角跨度在视界上对应一个"斑块"，面积 ≈ (H⁻¹)² × (π/ℓ)² = π²/(ℓ² H²)

等等——ℓ 越大，斑块越小，面积越小 → N_eff 越小。这与直觉相反！

让我重新思考。问题出在：**模式 ℓ 是球谐函数 Y_ℓm——它不是局域在视界某个斑块上的，而是覆盖整个视界球面的**。

---

### 3.2 修正：模式 ℓ 的非局域性

Y_ℓm(θ,φ) 覆盖整个球面，有 ℓ 条节线。它在**动量空间**是局域的（角动量 ℓ），但在**位置空间**是非局域的。

这意味着模式 ℓ 可以同时与整个视界上的自由度耦合——但耦合的**分辨率**受限于 ℓ。

**类比**：一个光学模式（望远镜的角分辨率 ~ λ/D），能分辨的最小角尺度是 π/ℓ。视界上比 π/ℓ 更小的结构对这个模式来说是"模糊的"——不能作为独立的环境自由度被模式感知。

因此：

```
N_eff(ℓ) = 视界上角尺度 ≥ π/ℓ 的独立 Planck 面元数
```

视界总 Planck 面元数：N_total = A/(4l_P²) = π/(H²l_P²)

角尺度 ≥ π/ℓ 对应面积 ≥ (π/ℓ)² × H⁻² = π²/(ℓ² H²)

这一尺度以上的 Planck 面元可以分组为"有效像素"：
- 每个有效像素大小 = (π/ℓ)² × H⁻²
- 每个有效像素包含的 Planck 面元数 = (π/ℓ)² / l_P²

视界球面上有 ℓ² 个这样大小的独立像素（覆盖 4π 立体角，每个像素 Ω ≈ (π/ℓ)²）：

```
N_pixels(ℓ) ≈ 4π / (π/ℓ)² ≈ 4ℓ²/π ≈ ℓ²
```

但这不是 Planck 面元数——每个像素内有 N_Planck_per_pixel = (π/ℓ)²/(H²l_P²)。

现在关键来了：**模式 ℓ 能分辨的，是这些 ℓ² 个"粗粒化像素"的集体行为，不是像素内 10¹²⁰ 个 Planck 面元的独立行为。**

因为模式 ℓ 的角分辨率有限，像素内的 Planck 面元在模式看来是**简并的**——它们的行为被平均化了。有效环境变量数 = 像素数 = ℓ²。

```
N_eff(ℓ) ≈ ℓ²
```

## 第六步：重做场空间的退相干估算

曲率扰动 ζ 的每个傅里叶模式是一个量子谐振子：

```
H_k = ½|ζ̇_k|² + ½ω_k²|ζ_k|²

基态波函数宽度（场空间）：

```
Δζ_0(k) = √(ħ/(2 ω_k V))
```

其中 V 是正则化体积。对超视界模式（k ≪ aH，ω_k → 0），模式被"冻结"——它成为一个零频模式（"quantum squeezed state"）。

两个相干态 |α⟩ 和 |β⟩ 在场空间中分离 Δζ = |α-β| × Δζ_0。

曲率扰动的振幅 P_ζ(k) = A_s (k/k_pivot)^{n_s-1} 给出了相干态参数 |α|² ~ P_ζ(k) × V × k³/(2π²) ~ A_s/(2π²) × V k³。

**退相干速率**（来自 inflaton 自相互作用的 3 点耦合，耦合常数 ~ √ε H/M_Pl）：

```
Γ_dec(k) ≈ (Δζ)² × (H/M_Pl)² × H
         ≈ A_s × (H/M_Pl)² × H
         ≈ (2.1×10⁻⁹) × (H/M_Pl)² × H
```

取 H_inf ~ 10¹³ GeV，H/M_Pl ~ 10⁻⁵：
```
Γ_dec ≈ 2.1×10⁻⁹ × 10⁻¹⁰ × H = 2.1×10⁻¹⁹ × H

τ_dec ≈ 5×10¹⁸ × H⁻¹ ≫ H⁻¹（远超哈勃时间！）

**这是关键反转：曲率扰动从 inflaton 自相互作用得到的退相干速率，比哈勃速率慢 19 个数量级。**

这意味着超视界模式在穿越视界后的几十个 e-fold 内，原则上可以保持量子相干性！

## 第七步：N_eff(ℓ) 整合环境筛选效应

现在引入环境筛选：

对于模式 ℓ，在穿越视界时，它的有效环境变量数 N_eff(ℓ) ≈ ℓ²。但并非所有 ℓ² 个"像素"都同等参与退相干——只有那些与模式 ℓ 有三点相互作用的像素才贡献退相干。

在 de Sitter 空间的动量守恒下（共形对称性），模式 ℓ₁, ℓ₂, ℓ₃ 的三点耦合只有在它们能形成闭合三角形时才非零（角动量选择定则）：

```
|ℓ₁ - ℓ₂| ≤ ℓ₃ ≤ ℓ₁ + ℓ₂
```

对目标模式 ℓ₁ = ℓ，与之耦合的环境模式 ℓ₂, ℓ₃ 必须满足此条件。这意味着 Low-ℓ 模式能耦合的环境模式数量**比 ℓ² 更少**：

```
N_eff^{(3)}(ℓ) ≈ Σ_{ℓ₂=0}^{ℓ_max} Σ_{ℓ₃=|ℓ-ℓ₂|}^{ℓ+ℓ₂} 1
               ≈ ∫₀^{ℓ_max} dℓ₂ (min(ℓ+ℓ₂, ℓ_max) - |ℓ-ℓ₂|)
               ≈ ℓ × ℓ_max   （对 ℓ ≪ ℓ_max）
```

其中 ℓ_max ~ M_Pl/H（UV 截断）。

所以来自**三点耦合的**有效环境自由度是：

```
N_eff(ℓ) ≈ ℓ × ℓ_max  （三点相互作用）
         ≈ ℓ²         （通用接触，无选择定则时）
```

**取最小的非平凡路径（三点耦合）**：

```
N_eff(ℓ) = ℓ × ℓ_max ~ ℓ × (M_Pl/H) ~ ℓ × 10⁵  （取 H ~ 10¹³ GeV）
```

数值：
- ℓ=2：N_eff ≈ 2×10⁵
- ℓ=30：N_eff ≈ 3×10⁶

## 第十步：如果要有 ℓ≈30 的阈值，需要什么？

要产生 τ_D(ℓ) ~ τ_H（不完全退相干）只在 ℓ < 30 出现，需要：

```
N_eff(ℓ) 在 ℓ ~ 30 处有一个陡峭的截断。
```

可能的理论来源：
1. **dS/CFT 中边界算子谱的 gap**：如果 dS 的 CFT 对偶有一个 Δ_min 的共形维数 gap，对应 ℓ_min ~ Δ_min，低于此 ℓ 的 bulk 模式在边界上没有对应的算子——它们不能与环境耦合。
2. **全息噪声谱的拐点**：Hogan 等人的因果量子相干模型预言，角相关在 Θ > 75°（ℓ < ~15）处突变为零——这暗示 N_eff 在 ℓ ~ 15-20 处确实有一个陡峭下降。
3. **视界穿越物理的 IR 截断**：如果 inflation 持续的总 e-fold 数是有限的（不是无限的 de Sitter），最小 k 的模式（最低 ℓ）在 inflation 开始时还没有进入量子真空——它们根本不存在量子涨落。

**路径 3 是最干净的物理**——它不依赖 dS/CFT 的推测性，只依赖"inflation 的有限时长"这一个假设。

**N_eff(ℓ) 本身来自标准 de Sitter 量子场论就是 ℓ 依赖的（∝ ℓ），但不够陡峭，不能在 ℓ≈30 产生定性阈值。**
