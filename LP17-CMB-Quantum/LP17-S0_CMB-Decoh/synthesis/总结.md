## 二、关键发现（可复用资产）

### 2.1 退相干时标（正确，但不可观测）

```

τ_dec ≈ 5×10¹⁸ H⁻¹ ≫ H⁻¹
```

退相干在视界穿越时冻结。物理正确，但ε×e^{-2r}~10⁻⁶⁸的双指数压制使效应无法观测。

### 2.2 N_eff(ℓ) 推导

```
N_eff(ℓ) = ℓ × ℓ_max ≈ ℓ × 10⁵（角动量选择定则，3点耦合）
```

正确但不产生ℓ≈30阈值。阈值需要inflation IR截断（独立方向）。

### 2.3 CMB低ℓ-背景几何纠缠熵

```
S_ent = Σ_{ℓ=2}^{30} (2ℓ+1) × n̄_ℓ × log₂(1/n̄_ℓ) ≈ 10⁻³ bits
```

首次计算。Page-Wootters机制对H₀贡献 ≤ 0.01 km/s/Mpc。

### 2.4 全息截断S曲线（被数据证伪）

```
H₀(R) = H₀^{true} × [1 + δ_H × (r_void/√(r_void²+R²))³]
```

Pantheon+ 1587 SNe全样本分段z_max分析：
- z=0.02: H₀=71.4±0.7
- z=0.50: H₀=73.2±0.2
- z=2.00: H₀=73.3±0.2
- Spearman ρ = +0.911（微弱上升，与下降S曲线方向相反）

**全息截断框架被Pantheon+数据干净证伪。**

### 2.5 Hubble张力的真实结构

数据揭示的不是连续S曲线，而是台阶式跳跃：
- SNIa（所有z）：H₀ ≈ 73
- BAO（z~0.38）：H₀ ≈ 68.7
- CMB（z~1100）：H₀ ≈ 67.4

跳跃发生在不同探针之间，不在单个探针的不同红移之间。
