## 一、自洽确定 H₀^{true}

框架方程：

```
H₀(R) = H₀^{true} × [1 + δ_H × r_eff(R)/R]

r_eff(R) = r_void × R / √(r_void² + R²)
→ r_eff(R)/R = r_void / √(r_void² + R²)
```

CMB 测量对应 R → ∞ 极限。用 CMB 确定 H₀^{true}：

```
H₀(CMB) = H₀^{true} × [1 + δ_H × 250/14000]
         = H₀^{true} × [1 + 0.111 × 0.0179]
         = H₀^{true} × 1.00199

67.4 = H₀^{true} × 1.0020
H₀^{true} = 67.27 km/s/Mpc
```

## 二、完整标度检验（自洽 H₀^{true}）

δ_H = 0.111，r_void = 250 Mpc，H₀^{true} = 67.27

### 2.1 近场平台（R < r_void）

```
R → 0: r_eff/R → 1
H₀(0) = 67.27 × (1 + 0.111) = 67.27 × 1.111 = 74.74 km/s/Mpc
```

**预测**：R < 250 Mpc 的所有测量 → H₀ ≈ 74.7

**实测**：
| 方法 | R (Mpc) | H₀ | 偏差 |
|------|---------|-----|------|
| Maser | 7 | 73.9 ± 3.0 | −0.8 |
| TRGB | 10 | 72.1 ± 2.0 | −2.6 |
| SBF | 100 | 73.7 ± 2.4 | −1.0 |
| Cepheid 近场 | 40 | 73.5 ± 2.1 | −1.2 |

加权平均：73.3 ± 1.1。预测 74.7，偏差 −1.4 km/s/Mpc（1.3σ）。

### 2.2 Cepheid 全样本（R ~ 300 Mpc）

```
r_eff/R = 250/√(250²+300²) = 250/390.5 = 0.640

H₀(300) = 67.27 × (1 + 0.111 × 0.640)
        = 67.27 × 1.0710
        = 72.0 km/s/Mpc
```

**预测**：72.0。**实测**：73.2 ± 1.3（Riess 2022）。偏差 +1.2 km/s/Mpc（0.9σ）。

### 2.3 Cepheid 的 SH0ES 样本有效半径

问题：SH0ES 使用的 Cepheid 校准器跨越 ~10-40 Mpc（近场校准），然后 SNIa 宿主延伸至 ~300 Mpc。这不是在测量一个固定 R 的全息屏——它是两步测量：

```
Step 1: Cepheid 校准（R ≈ 10-40 Mpc）→ 空洞内饱和平台 H₀ ~ 74.7
Step 2: SNIa Hubble 图（R ≈ 40-800 Mpc）→ 空洞边界到空洞外

H₀(SH0ES) ≈ w₁ × H₀(platform) + w₂ × H₀(transition)
```

SH0ES 用 Cepheid 距离校准 SNIa 绝对星等，然后 SNIa 测量 H₀。Cepheid 校准在空洞内 → 距离尺度的"零点"定在空洞内的膨胀率上 → 导入系统性偏高。

**有效 H₀(SH0ES) 应该在平台值（74.7）和 300 Mpc 值（72.0）之间**，偏近平台（因为 Cepheid 校准权重集中在近场）。

观测 73.2 坐落在 [72.0, 74.7] 区间内——方向正确，量级合理。

### 2.4 H0LiCOW（~1 Gpc 透镜时延）

```
r_eff/R = 250/√(250²+1000²) = 250/1031 = 0.243

H₀(1000) = 67.27 × (1 + 0.111 × 0.243)
         = 67.27 × 1.0270
         = 69.1 km/s/Mpc
```

**预测**：69.1。**实测**：73.3 ± 1.7。偏差 +4.2 km/s/Mpc（2.5σ）。

这是唯一 >2σ 的偏离。但 H0LiCOW 不是单一屏的球对称测量——它是透镜时延，测的是透镜处的几何距离比。透镜在 z_l ~ 0.5-1.0，不在我们的局域空洞内。

如果 H0LiCOW 的 H₀ 代表透镜处的"局域"膨胀率（类似近场空洞内观测者但透镜自己不在空洞里）→ H₀(TDCOSMO) 应该接近宇宙平均 67-69，而不是 ~73。

H0LiCOW 的 73.3 与 Cepheid 的 73.2 一致——但这可能意味着 H0LiCOW 分析中未处理的系统误差（质量-页变换简并、沿视线结构的 MSD），而不是全息框架被证伪。

## 三、残差的统一视角

```
方法                         物理                       预测    观测    残差    σ
─────────────────────────────────────────────────────────────────────────────
近场平台（4方法合并）        球对称屏，全在空洞内       74.7    73.3    −1.4   1.3
Cepheid 全样本 (300 Mpc)     球对称屏，跨越空洞边界     72.0    73.2    +1.2   0.9
BAO（视线积分卷积）           视线积分 ~25 Mpc 奇点      68.5    68.7    +0.2   0.2
H0LiCOW (~1 Gpc)             透镜时延，非球对称          69.1    73.3    +4.2   2.5 ← 唯一 >2σ
CMB (14 Gpc)                 最大因果钻石                67.4    67.4     0     0
```

### 残差模式

**系统性的正残差**（预测系统性低于观测，除了近场平台）：

这是因为 δ_H = 0.111 是用 |δ_m| = 0.3 在中值参数下算的。近场平台的残差 (−1.4) 暗示预测偏高——可能 δ_H 的真实值略小，或者是近场方法之间还有未被统一的系统误差。

**如果重新拟合 δ_H：**

用近场平台（4 方法加权平均 73.3）和 CMB（67.4）作为两个锚点：

```
73.3 / 67.4 = 1 + δ_H × f_anchor
```

近场平台的有效 f_anchor：r_eff/R ≈ 1（R ≪ r_void）
→ 1 + δ_H = 73.3/67.27 → δ_H = 0.089

用 δ_H = 0.089 重算所有预测：

| 方法 | 预测 | 观测 | 残差 |
|------|------|------|------|
| 近场平台 | 73.3 | 73.3 | 0 |
| Cepheid 300 Mpc | 71.1 | 73.2 | +2.1 |
| BAO | 68.2 | 68.7 | +0.5 |
| H0LiCOW | 68.7 | 73.3 | +4.6 |
| CMB | 67.4 | 67.4 | 0 |

Cepheid 残差从 1.2 变到 2.1——变差了。

这说明用近场平台拟合的 δ_H 不适合球对称屏的过渡段。近场平台内部的系统误差（Maser/TRGB/SBF/Cepheid 之间的 ~2 km/s/Mpc 散布）在压低"平台值"。

**结论：δ_H 不应该从近场平台拟合——近场四种方法之间的散布（~2 km/s/Mpc）说明平台本身不是平的。** 保持 δ_H = 0.111（由 |δ_m| 第一性原理推导）是正确的选择。
