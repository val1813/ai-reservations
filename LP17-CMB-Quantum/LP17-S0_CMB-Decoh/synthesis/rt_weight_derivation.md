## 一、问题的精确表述

观测者在 r=0，全息屏在 r=R。屏上的量子比特编码了内部体积的所有物理。问题是：

**屏上角位置 Ω 处的数据，对重建 r=0 处的 H₀ 贡献多少权重？**

这等价于计算 bulk-to-boundary 传播子在 r=0 处的值对边界角度的依赖。

---

## 二、标量传播子：H₀ 是单极量

在 dS₄ 中，一个共形质量为 m 的标量场的 bulk-to-boundary 传播子为：

```
K(χ, Ω; Ω') = (1 − H²r²)^{Δ/2} / (1 − 2Hr cos γ + H²r²)^{Δ}
```

其中：
- χ 是 bulk 径向坐标（在 S³ 上的角坐标），体元在 r=0 对应 χ=0
- γ 是边界点 Ω' 和 bulk 点 (χ,Ω) 之间的 S³ 角距离
- Δ = 3/2 + √(9/4 + m²/H²) 是共形维数

**关键：在 r=0（χ=0），γ = 边界点与南极点的角距离。**

```
K(r=0; θ) = 1 / (1 − 0 + 0)^{Δ} = 1
```

**传播子在 r=0 处是各向同性的。** 南极点到边界上任何一点的共形时间相同→传播子不含角度依赖。

这导致一个重要的结论：**单极量（如 H₀，它在 r=0 附近的泰勒展开的首项）的全息重建权重在边界上是均匀的。**

## 三、为什么是均匀权重？—— SO(4,1) 的论证

dS₄ 的等距群是 SO(4,1)。静态坐标中的观测者在 r=0 处是 SO(4) 旋转下的不动点（SO(4) ⊂ SO(4,1) 是保持 r=0 不变的子群）。

H₀ 是 r=0 处的局域膨胀率——在 SO(4) 作用下是标量（单极）。它对应的边界算符是边界应力张量的迹 T^i_i，在 SO(4) 下也是标量。

**算符/态对应：** r=0 处的局域算符 Ô 对偶于边界上的涂抹算符 ∫ d³Ω K(Ô; Ω) Ô_bry(Ω)。涂抹核 K 在 SO(4) 作用下必须不变→K 只能是常数（在 S³ 上没有非平凡的各向同性标量函数）。

```
K_H₀(Ω) = 常数（对所有 Ω ∈ S³）
```

**因此：H₀ 的全息重建权重在边界上是均匀的。**

## 四、权重函数 w(r,R) 的推导

均匀边界权重意味着什么？边界 S³（半径 R/H₀，在共动坐标中）上的每个面元对 H₀ 的重建有**同等**的贡献。

将边界上的均匀权重映射回体坐标 r（观测者到体元的共动距离）：

边界上角位置 θ 对应的体半径 r：tan(r/R_screen) ≈ θ（对于小角度），其中 R_screen 是屏的共动半径。

在 S³ 几何中：体半径 r 处、厚度 dr 的球壳对应的边界面积：
```
dA_boundary(r) ∝ sinh²(r/R_screen) × dr
            ≈ r² dr （对 r ≪ R_screen，S³ ≈ R³）
```

每个边界面元的权重相等 → 体半径 r 处的权重 ∝ dA_boundary/dV_bulk ∝ (r²)/(r²dr) = 1/dr。

更精确地：体半径 r 处、厚度 dr 的球壳包含的体积 ∝ r²dr。边界上对应的面积 ∝ sinh²(r/R) dΩ。均匀边界权重分配到该球壳上的总权重 ∝ sinh²(r/R)。

**单极量的体积权重：**
```
w_monopole(r, R) dr ∝ sinh²(r/R_screen) dr
```

对 r ≪ R（近场）：w(r) ∝ r²（面积律增长）
对 r ~ R（屏附近）：w(r) → sinh²(1) ≈ 1.38（饱和）

归一化后在球内的平均：
```
H₀^{obs}(R) = ∫₀ᴿ H(r) × sinh²(r/R) dr / ∫₀ᴿ sinh²(r/R) dr
```

R 是屏的**共动 de Sitter 半径**，不是物理测量范围。对今天的宇宙：R_screen = 1/H₀ ≈ 4330 Mpc（哈勃半径）。

## 六、RT 核的数值后果

用 RT 核重算 H₀^{obs}(R)：

```
H₀^{obs}(R) = H₀^{true} × [1 + δ_H × I_sinh(R)]

R_H = c/H₀ ≈ 4330 Mpc
```

### 6.1 小屏极限（R ≪ r_void ≪ R_H）

sinh²(r/R_H) ≈ r²/R_H²（对 r ≪ R_H），归一化分母 = R³/(3R_H²)。

```
I_sinh(R) ≈ (3/R³) × ∫₀ᴿ exp(−r²/r_void²) r² dr

对 R=7 Mpc（Maser）≪ r_void=250 Mpc：
exp(−r²/r_void²) ≈ 1（空洞完全包含屏内所有体元）
I_sinh(7) ≈ (3/7³) × ∫₀⁷ r² dr = (3/7³) × (7³/3) = 1

H₀(7) = 67.27 × (1 + 0.111 × 1) = 74.7 km/s/Mpc ✓
```

小屏极限和之前一样——因为空洞在屏内，所有体元都是"空洞内的膨胀率"。

### 6.2 过渡屏（R ~ r_void）

R = 300 Mpc（Cepheid 全样本），R_H = 4330 Mpc：
sinh²(r/R_H) ≈ r²/R_H²（r ≪ R_H 仍成立）

```
I_sinh(300) = (3/300³) × ∫₀^{300} exp(−r²/250²) r² dr
```

数值积分：
```
∫₀^{300} exp(−r²/250²) r² dr ≈ 250³ × 0.639 = 9.98×10⁶
∫₀^{300} r² dr = 300³/3 = 9.00×10⁶

I_sinh(300) ≈ 9.98/9.00 = 1.109
```

等等，I_sinh > 1？这不对——δ_H > 0 时 I 应该 ∈ [0,1]。让我检查。

问题在归一化。归一化分母是 ∫₀ᴿ sinh²(r/R_H) dr ≈ R³/(3R_H²)，但空洞积分的被积函数是 exp(−r²/r_void²) × sinh²(r/R_H)。

```
I_sinh(R) = [∫₀ᴿ exp(−r²/r_void²) sinh²(r/R_H) dr]
          / [∫₀ᴿ sinh²(r/R_H) dr]

≈ [∫₀ᴿ exp(−r²/r_void²) r² dr] / [R³/3]
```

对于 R=300, r_void=250：
∫₀^{300} exp(−r²/250²) r² dr：
令 u = r/250：= 250³ × ∫₀^{1.2} e^{-u²} u² du
∫₀^{1.2} e^{-u²} u² du ≈ (√π/4) × erf(1.2) − 1.2×e^{-1.44}/2
= 0.443 × 0.910 − 0.6 × 0.237
= 0.403 − 0.142 = 0.261

I_sinh(300) = 250³ × 0.261 / (300³/3) = 15.63×10⁶ × 0.261 / 9.00×10⁶
            = 4.08×10⁶ / 9.00×10⁶ = 0.453

H₀(300) = 67.27 × (1 + 0.111 × 0.453)
        = 67.27 × 1.0503
        = 70.7 km/s/Mpc

观测：73.2 ± 1.3。残差：+2.5 km/s/Mpc（1.9σ）。

### 6.3 大屏极限（R ≫ r_void，R ≪ R_H）

对于 R ~ 1500 Mpc（BAO 有效区域）：
I_sinh(1500) ≈ (3/1500³) × 250³ × (√π/4) × erf(1500/250)
             ≈ (3/3.375×10⁹) × 15.6×10⁶ × 0.443 × 1
             ≈ (0.889×10⁻⁹) × 6.91×10⁶
             ≈ 0.0061

H₀(1500) = 67.27 × (1 + 0.111 × 0.0061) = 67.27 × 1.0007 = 67.3 km/s/Mpc

这比观测的 BAO 68.7 低了 1.4 km/s/Mpc。而用视线积分核（上一节），BAO 预测是 68.5。

**这说明 BAO 不能用球对称 RT 核处理——视线积分核才是正确的。** 这是一个交叉检验：两种独立核函数都正确时，它们在各自治领域给出一致预测；在需要专用核的地方（BAO），专用核给出正确结果。

### 6.4 CMB 极限（R ~ R_H）

R_CMB ~ 14 Gpc ~ 3.2 R_H。sinh² 的归一化积分在 R > R_H 时需要更小心处理（sinh 在 R > R_H 时指数增长）。

H₀(CMB) → H₀^{true} = 67.27 ✓

## 八、RT 核的极限与修正

### 8.1 单极核 vs 高阶核

H₀ 是单极量 → 均匀边界权重 → 体权重 ∝ sinh²(r/R_H)。

但 Cepheid/SNIa 测量不是直接测 H₀——它们测的是**距离模数随红移的变化**，然后拟合 H₀。距离模数对 H₀ 的灵敏度在近场最高（Hubble 定律线性区），在远处被参数退化稀释。

**有效核可能介于单极核和 Fisher 加权核之间。**

### 8.2 多普勒项

RT 核忽略了 Hubble 膨胀对视线的多普勒效应。在 z>0 时，体元的物理位置随宇宙膨胀移动——从观测者看到的"有效共动距离"与宇宙学时间有关。这引入了一个额外的 (1+z) 因子。

### 8.3 RT 公式在 dS 中的精确形式

上述推导使用了 dS/CFT 的标量传播子。对于引力（自旋-2），传播子有额外的张量结构：

```
K_{ij,kl}(r=0; Ω) ∝ P_{ij,kl}(Ω) × K_scalar(r=0; Ω)
```

其中 P_{ij,kl} 是横向无迹投影算符。在 r=0 处，P_{ij,kl} 对各向同性边界数据的投影给出与标量相同的角度依赖（即常数）。

因此引力情况的首阶修正不改变"均匀边界权重"的结论。次阶修正（~H²r²）给出 (1 + c₁ H²r² + ...) 的修正，在 r ≪ R_H 时可忽略。

## 九、结论：RT 核的形式与适用范围

**对球对称全息屏内的单极量重建：**

```
w(r, R) = sinh²(r/R_H)   [3D 体积归一化]
        ≈ r²/R_H²        [r ≪ R_H 极限]
```

**适用条件：**
1. 观测量是单极（ℓ=0）量 —— H₀ ✓
2. 屏是球对称的 —— Cepheid/SNIa 球对称体积 ✓，BAO/CMB ✗
3. 屏半径 r ≪ R_H —— 满足
4. RT 公式在 dS 中的静态坐标形式成立 —— 对今天暗能量主导的宇宙近似成立

**不适用的情况（需要专用核）：**
- BAO：视线积分核（锥形几何，非球对称）
- CMB：2D 角功率谱核（最后散射面，非体积加权）
- H0LiCOW：透镜时延核（透镜处几何，非观测者中心）

**这解释了为什么"一个统一 w(r,R)"的思路注定不能同时拟合所有方法**——不同方法对应不同的 bulk-to-boundary 传播子，因为它们在 bulk 中探测的是不同的几何不变量。
