## S6.2 q场方程的完整来源追溯

### S6.2.1 原始图动力学（第一性原理层面）

DGF v3 §VI.1的原始方程（在信息邻接图上）：

$$\tau_i \frac{dq_i}{d\lambda} = \sum_{j\sim i} \kappa_{ij}(q_j - q_i) - U'(q_i) + \eta_i$$

审计判断：**此方程是信息论的，不是时空的。** qᵢ是细胞占有率的局部平均，λ是序数更新参数，κᵢⱼ是邻接刚度，U(q)是局部容量代价，ηᵢ是源。这符合创始原则——没有预设时空。**未发现违规。**

### S6.2.2 到连续极限的过渡

DGF v3将图动力学过渡为连续变分原理：

$$S[q] = \int d^3x\left[s_{\text{bin}}(q) + \frac{\mathfrak{l}^2}{2}(\nabla q)^2 - \frac{\rho}{\rho_0}q\right]$$

审计判断：**从图到连续体的过渡引入了两个未推导的假设：**
1. s_bin(q)作为"局部容量代价"U(q)在连续极限下的形式 — 这是**选择**，不是定理
2. (∇q)²项作为邻接扩散的连续极限 — 这在数学上是标准的（图Laplacian→连续Laplacian），但**连续极限的well-definedness依赖于"图有光滑3D连续极限"的假设**（Gap 6，DGF自己标注为open）

**此处已有两个推定点：d=3未严格证明（Gap 1, 60%置信度），连续极限的存在性未严格证明（Gap 6, open）。q场的整个连续形式站在这两个未闭合的gap上。**

### S6.2.3 变分→q场方程

$$\frac{\delta S}{\delta q} = s'_{\text{bin}}(q) - \mathfrak{l}^2\nabla^2 q - \frac{\rho}{\rho_0} = 0$$

其中 s'_bin(q) = d/dq[-q ln q - (1-q) ln(1-q)] = ln((1-q)/q)

得到：
$$\mathfrak{l}^2\nabla^2 q = \ln\frac{1-q}{q} - \frac{\rho}{\rho_0}$$

（符号约定：DGF v3的方程有+ρ/ρ₀ − ln((1−q)/q)，与这里差一个全局负号，对应S[q]中q→-q重新标记。这不影响真空固定点的分析。）

**真空固定点（ρ=0, ∇²q=0）：**
$$\ln\frac{1-q}{q} = 0 \quad\Rightarrow\quad q = \frac{1}{2}$$

审计判断：**给定s_bin(q) = -q ln q - (1-q) ln(1-q)，真空固定点q=1/2是代数必然——没有自由度。** 关键在熵函数本身。

## S6.3 对称二元熵：必然还是选择？

### S6.3.1 信息论依据

二元Shannon熵 S₂(p,1-p) = -p ln p - (1-p) ln(1-p) 在信息论中是唯一的满足以下公理的二元熵：
- 连续性
- 在p=1/2处最大化
- 对独立系统的可加性
- 可扩展性

**如果q和1-q是二元系统的两个概率，那么S_bin是唯一的熵函数选择。这是Khinchin-Shannon唯一性定理。**

### S6.3.2 但在DGF中，q是什么？

q是**可访问相干分数**——细胞系综上可访问状态的比例。1-q是归档比例。

关键问题：**q和1-q是否是概率意义上的两个对称结果？**

在标准Shannon框架中，两个结果的熵对称性的前提是：
- **先验等概率**：如果没有额外信息，两个结果应被视为等可能
- **相位空间等体积**：两个结果的微观态数量相同

但在DGF物理中：
- 假设3声明溢出是**不可逆的**：信息从可访问态流向归档态是单向的
- 归档态和可访问态在物理上是**不对称的**：归档态的微观简并度可能不同于可访问态
- 这种不对称性恰好是假设3（不可逆性）要求熵泛函捕捉的物理

**因此，对称二元熵S_bin(q)隐含地假设了溢出是对称可逆的——恰恰与假设3矛盾。**

### S6.3.3 对称性假设的精确位置

DGF v3在§VI.1中写"s_bin(q)"，但没有给出s_bin的精确定义。在整个论文中，s_bin的唯一出现就是在变分原理中。从推导结果反推，s_bin就是对称二元熵。

**这个选择在DGF v3中没有经过论证。** 论文没有讨论为什么选择对称形式，没有讨论不对称推广的可能性，也没有讨论这个选择是否被三假设强制。

## S6.4 不对称推广的完整目录

### S6.4.1 类型I：统计权重不对称

$$S_{\kappa}(q) = -q\ln q - \kappa(1-q)\ln(1-q), \quad \kappa > 0, \kappa \neq 1$$

物理含义：归档态的统计权重是可访问态的κ倍。每个归档细胞在相空间中有κ倍于可访问细胞的配置数。

平衡条件（真空）：
$$\frac{\delta S_{\kappa}}{\delta q} = \ln\frac{1-q}{q} + (1-\kappa)[\ln(1-q) + 1] = 0$$

即：
$$\frac{(1-q)^{\kappa}}{q} = e^{1-\kappa}$$

数值：
- κ=1: q_eq = 1/2（恢复DGF v3）
- κ=2: q_eq ≈ 0.557
- κ=5: q_eq ≈ 0.666
- κ=10: q_eq ≈ 0.768
- κ=0.5: q_eq ≈ 0.443
- κ=0.1: q_eq ≈ 0.267

**与三假设的兼容性：**
- Assumption 1（信息存在）：兼容 ✓
- Assumption 2（容量有界）：兼容 ✓（κ不影响容量上界）
- Assumption 3（溢出不可逆）：**κ捕捉了不可逆性的统计表现** — 这正是假设3要求在熵函数中体现的不对称性 ✓

**裁决：S_κ与三假设完全兼容，κ>1时有明确的物理依据（不可逆溢出→归档态统计权重更大）。**

### S6.4.2 类型II：q依赖先验

$$S_{q_0}(q) = -q\ln\frac{q}{q_0} - (1-q)\ln\frac{1-q}{1-q_0}$$

这是相对熵（Kullback-Leibler散度）形式，其中q_0是先验可访问分数。

平衡：q_eq = q_0（由定义，真空趋向先验）。

物理含义：如果宇宙的"自然状态"有先验可访问分数q_0，平衡态就是q_0。

**与三假设兼容性：** 兼容，但引入了新参数q_0。q_0不能从三假设推导——它是附加假设。

### S6.4.3 类型III：Tsallis熵

$$S_{\alpha}^T(q) = \frac{q^{\alpha} + (1-q)^{\alpha} - 1}{1-\alpha}, \quad \alpha > 0, \alpha \neq 1$$

极限α→1恢复Shannon熵。

平衡：$\alpha q^{\alpha-1} - \alpha(1-q)^{\alpha-1} = 0$ → q = 1/2（对所有α！）

**关键发现：Tsallis熵（对称形式）的所有阶都保持q=1/2平衡！** 对称性是Tsallis函数形式的内在属性，与Shannon一样。

**与三假设兼容性：** 数学上兼容，但违反可加性（Tsallis是非广延熵），而可加性是DGF变分原理暗含的假设。不推荐。

### S6.4.4 类型IV：Rényi熵

$$S_{\alpha}^R(q) = \frac{1}{1-\alpha}\ln[q^{\alpha} + (1-q)^{\alpha}]$$

平衡：$\frac{\alpha q^{\alpha-1} - \alpha(1-q)^{\alpha-1}}{q^{\alpha} + (1-q)^{\alpha}} = 0$ → q = 1/2（对所有α！）

与Tsallis一样，对称Rényi熵也保持q=1/2平衡。

### S6.4.5 类型V：带势的非对称熵

最一般形式：
$$S(q) = -q\ln q - \kappa(1-q)\ln(1-q) + V(q)$$

其中V(q)是额外的信息势（如：V(q) = λq(1-q)表示可访问-归档界面张力）。

平衡：$\ln\frac{1-q}{q} + (1-\kappa)[\ln(1-q)+1] + V'(q) = 0$

**与三假设兼容性：** 兼容，但V(q)必须来自信息论第一性原理（不能含有时空预设）。

## S6.5 确定性裁决

### 核心问题：q_∞ = 1/2是强制的吗？

**裁决：[CONDITIONAL] — 条件性成立，不是必然性成立。**

q_∞ = 1/2的成立条件是：

| 条件 | 状态 | 备注 |
|------|:----:|------|
| C1: s_bin = 对称Shannon二元熵 | ❓ 未被推导 | DGF v3直接选择，未论证 |
| C2: 连续极限well-defined | ❓ 开放问题 | Gap 6 (open) |
| C3: d=3 continuum limit | ❓ 60%置信度 | Gap 1 |
| C4: 可访问/归档的统计对称性 | ❌ 与假设3矛盾 | 溢出不可逆 → 不对称 |

**条件C4是最致命的：对称Shannon熵隐含地假设可访问和归档统计等价，而假设3（溢出不可逆）恰恰要求它们在物理上不对称。这是DGF v3框架的内在张力。**

### 裁决详情

**q_∞ = 1/2 不是DGF三假设的必然推论。** 它是DGF v3中一个特定的、未经充分论证的熵泛函选择的产物。三假设中的任何一条都不强制对称二元熵——假设3（不可逆性）更是积极地指向不对称形式。

**最小推广：** S_κ(q) = -q ln q - κ(1-q) ln(1-q) with κ ≠ 1.
- κ是归档态相对于可访问态的统计权重
- κ > 1 有明确的物理动机（不可逆溢出 → 归档态微观简并度更大）
- 引入κ不违反任何一条创始假设
- κ=1恢复DGF v3，因此S_κ是DGF v3的严格推广（非替代）

### 不对称熵的物理动机

为什么κ > 1是物理上合理的：

1. **不可逆性意味着退化方向性。** 信息溢出→归档的过程是熵增过程。在统计力学中，熵增方向对应于微观态数增加的方向。归档态（信息已被"锁定"）应有更多的微观实现方式——正如高温态比低温态有更多微观态。

2. **每个归档细胞储存的信息来自多个可访问细胞。** 归档过程是"多对一"映射：多个量子叠加的细胞退相干后将信息写入同一（或少数）归档细胞。这使得归档态的统计权重天然大于单一可访问态。

3. **从量子达尔文主义角度看：** 同一个退相干事件的信息被冗余广播到多个环境自由度。这些冗余拷贝共享同一份归档信息 — 有效降低了归档态的独立度数，但增加了每个归档态的简并度（多个环境拷贝对应同一归档位）。

**因此κ > 1（归档态权重更大）不是ad hoc假设——它是不可逆信息流动的统计力学后果。**

### 具体推荐

**对DGF框架：**
- 将S_κ(q)作为q场方程的一般形式，保留κ为待定参数
- 真空固定点：q_eq(κ) = 满足 (1-q)^κ/q = e^{1-κ} 的解
- DGF v3对应κ=1的特殊情况
- 承认κ不能从三假设唯一确定，需要额外原则或观测校准

**对LP39：**
- 如果κ可以取>1的值，q_∞可能显著偏离1/2
- 例如κ=10 → q_∞≈0.77 → 恢复R1中q_∞≈O(1)的可能性
- 但这意味着引入了一个新参数——框架失去了一部分预言力
- 必须在"少参数"和"物理合理性"之间权衡

# S4: q→0的物理可实现性

## S4.1 问题重构

P2（黑洞信息）需要q→0区域来实现"因果玻璃态"——所有信息被归档，因果通道完全封锁。R1中A博士和B博士都假设了黑洞内部q→0，但两个Inspector都标注了此假设未证明。

本节的使命：在离散细胞计数+渗流框架下，严格检验q→0区域是否可以在物理上实现。如果不能，诚实报告P2的处境。

## S4.2 离散细胞计数形式化

### S4.2.1 定义

DGF中每个Planck细胞处于两种状态之一：
- **可访问态（量子）**：f_c ≈ q_∞（局部平衡值），信息可通过因果图传输
- **归档态（经典）**：f_c → 1，信息被锁定在该细胞中，不可通过因果图传输

每个被占据（归档）的细胞对周围q场施加O(1)的源强度。M个粒子=每个粒子贡献约1个归档细胞的源。

### S4.2.2 渗流判据

对于体积V中的N_tot = V/ℓ³个细胞，被占据的细胞数N_occ来自粒子的归档贡献。占领分数：

$$f_{\text{occ}} = \frac{N_{\text{occ}}}{N_{\text{tot}}}$$

在3D立方格子上，已知的站点渗流阈值为f_c ≈ 0.3116。当f_occ ≥ f_c时，被占据细胞形成一个宏观连接团——**渗流转变**——此时归档细胞网络贯穿整个体积，有效q→0（所有因果路径被渗流团阻断）。

## S4.3 天体物理对象的f_occ计算

## S4.4 渗流不可能性的物理原因

离散细胞计数失败的根本原因：**ℓ³太小了。** ℓ ≈ 2.26 ℓ_P ≈ 3.6×10⁻³⁵ m → ℓ³ ≈ 5×10⁻¹⁰⁴ m³。即使整个可观宇宙（~10⁸⁰ m³）也只有~10¹⁸⁴个细胞。已知的量子粒子数~10⁸⁰（Eddington数）。f_occ_max ~ 10⁸⁰/10¹⁸⁴ ≈ 10⁻¹⁰⁴。

无论密度多大，**只要粒子数远小于细胞数，渗流就不可能。** 而ℓ³是DGF框架固定的，无法调大。

### S4.4.1 能否用"被占据细胞"的不同定义？

**方案A：粒子的归档"尾巴"**
一个粒子不仅占据一个细胞——它的归档场（质量→归档信息）影响周围的细胞，降低其q值。

但这回到了连续q场方程：q(r) = q_∞ - (M/4πm₀)(ℓ/r)。在粒子表面r~10⁻¹⁵ m处：M/m₀ ≈ 1.67×10⁻²⁷/9.62×10⁻⁹ ≈ 1.74×10⁻¹⁹。q-deficit ≈ 10⁻¹⁹ × ℓ/10⁻¹⁵ ≈ 10⁻³⁹。远不足以驱动q→0。

**方案B：RG增强（DGF Appendix B Path 1）**
如果粗粒化增强了有效刚度，长程q梯度可能被放大。但这是speculative，没有定量推导。

**方案C：因果图拓扑堵塞（b₁驱动）**
即使ρ/ρ₀不够大，如果视界因果图的b₁密度足够高，纯信息论效应（因果拥堵）可能等效于q→0。这是PI synthesis提出的替代方案。

可行性评估：在2D视界面上，b₁密度是面积/ℓ²量级。对于太阳质量黑洞（A~10⁷⁷ ℓ_P² ~ 10⁷⁶ ℓ²），b₁~10⁷⁶。这些环相互嵌套和交叉，可能产生"因果拥堵"——信息在多环网络上传播时，路径长度和阻塞概率指数增长，等效于q→0。

但是，这需要定义"因果拥堵→有效q"的定量映射。当前框架中没有这样的映射。

**方案D：Planck星（ρ ~ ρ₀）**
如果存在Planck密度的天体（ρ ~ ρ₀ ~ 10⁹⁶ kg/m³），f_occ ≈ 1 → 渗流平凡成立 → q→0。

但Planck星在标准物理中不存在。DGF可以"预言"它们——但这是建构（定义q→0区域=Planck星），不是推导。

## S4.5 诚实结论

**q→0区域在已知天体物理对象中不可实现。**

具体来说：
1. **离散细胞计数+渗流**：已知最大密度（中子星）的f_occ ~ 10⁻⁵⁹，比渗流阈值f_c≈0.31低了59个数量级。这不是"接近但不达标"——这是彻底的不可能。
2. **连续q场方程**：驱动q→0需要ρ/ρ₀ ≳ O(1)，而已知最高密度（中子星核心）ρ/ρ₀ ≲ 10⁻⁷⁸。
3. **因果图拓扑替代方案**：概念上有趣但缺乏定量形式化——目前是猜想，不是理论。

**可行的理论出口（所有都需要新假设）：**
- Planck星：假设存在Planck密度的天体→平凡地实现q→0（但这是重命名问题，不是解决问题）
- 太初黑洞：假设早期宇宙有任意高密度的区域→可能实现q→0（但需要q从1降到0的动力学，与DGF的q演化方向矛盾）
- 因果拓扑拥堵：假设足够密集的因果环可以不依赖物质密度而独立抑制q——需要新的形式化

### S4.6 这对P2意味着什么

如果q→0区域在物理上不可实现，那么P2（黑洞信息悖论的DGF解释）面临以下局面：

**存活的：**
- b₁→S_BH面积律的推导**不依赖q→0**。它只依赖视界因果图的b₁^{ind} ∝ A/ℓ²，而这是任意q梯度界面（不仅是q→0界面）的性质。
- S_BH = k_B · η₀ · g · b₁^{ind} 的逻辑链在任意q界面上成立，只要界面有足够陡的q梯度。

**死亡的：**
- "因果玻璃态"作为信息锁机制的物理解释（信息归档后因果不可达）在没有q→0时缺乏具体的物理实现。
- DGF对"信息不灭但因果不可达"的定性叙事失去载体——如果q从未真正达到0，"不可达"只是程度的差异（很难访问）而非种类的差异（原则上不可访问）。

**修正方案（降级）：**
P2的黑洞信息解释可以重新表述为：黑洞视界不是q=0区域，而是**q的陡峭梯度层**，在该层中q从~1/2（外部）下降到某个极小值q_min（内部）。信息"被困"不是因为q=0的绝对封锁，而是因为：
1. 视界因果图的b₁环拓扑结构使信息被"路由锁定"
2. q_min虽然>0，但足够小使得FP漂移v(q_min)=Γ/q_min的溢出速率远超霍金蒸发速率——信息在蒸发时间内无法逃逸

这避免了q→0的可实现性问题，代价是失去了"绝对归档"的简洁性。取而代之的是一个更复杂的"部分归档+拓扑路由锁定"机制。

**诚实判断：P2存活，但机制需要从"q→0因果玻璃"降级为"q≪1因果路由锁+慢逃逸"。定量上b₁→S_BH面积律不受影响。**

# S5: g因子的独立计算

## S5.1 g的定义和分解

从P2的b₁→S_BH链：

$$S_{\text{BH}} = k_B \cdot b_1^{\text{ind}}(\partial\Sigma_{\text{BH}}) \cdot \eta_0 \cdot g$$

其中b₁^{ind}是视界因果图上顶点不相交独立环的数量（圈填数ν(H_∂)）。

对于面积为A的二维视界：
$$b_1^{\text{ind}} = \frac{A}{\alpha_g \mathfrak{l}^2}$$

其中α_g是**每个独立因果环的平均面积**（以ℓ²为单位）。α_g是因果图拓扑的几何性质。

代入Bekenstein-Hawking S_BH = k_B·A/(4l_P²)：

$$\frac{A}{4l_P^2} = \frac{A}{\alpha_g \mathfrak{l}^2} \cdot \eta_0 \cdot g$$

$$\Rightarrow g = \frac{\alpha_g}{4\eta_0} \cdot \frac{\mathfrak{l}^2}{l_P^2}$$

## S5.2 各因子的独立状态

### η₀ = 1/(8 ln 2) ≈ 0.180

**状态：[严格] — 独立已知。**

来自LP38-S1：QCMI_tree与单环QCMI的差值下界。数学证明不依赖DGF的任何参数。η₀是DGF三常数中唯一真正独立推导的常数。

### ℓ²/l_P²

**状态：[依赖q_∞] — 非独立。**

从DGF v3 §VI.3：G = (πq_∞/8)(c³ℓ²/ħ)，结合G = ℓ_P²c³/ħ：

$$\frac{\mathfrak{l}^2}{l_P^2} = \frac{8}{\pi q_\infty}$$

在q_∞=1/2下：ℓ²/l_P² = 16/π ≈ 5.09

如果q_∞≠1/2（如S6所示可能），ℓ²/l_P²相应变化。对于κ=10（q_∞≈0.77）：ℓ²/l_P² ≈ 3.3。

**这意味着g依赖于尚未确定的q_∞——g不能独立于q_∞被计算。**

### α_g = 每个独立因果环平均占据的ℓ²面积

**状态：[未计算] — 需要因果图拓扑理论。**

α_g的性质：
- α_g ≥ 1：一个独立环至少需要3个节点（三角形），最小面积~O(1)ℓ²
- 对于2D规则晶格，b₁ = A/ℓ²（每个面元一个独立环）→ α_g = 1
- 对于随机因果图，环可以重叠节点但仍保持同调独立性→ α_g可以 < 1？
- 但实际上b₁^{ind}计数的是顶点不相交环（圈填数），所以环不能重叠——α_g必定 ≥ O(1)

精确计算α_g需要：
1. 视界因果图的统计系综定义
2. 该系综上的圈填问题解
3. 连续极限下的标度

这些都是未解决的图论问题。

## S5.3 能否从因果图Laplacian谱独立计算g？

### S5.3.1 理论路径

因果图G = (V, E)上的图Laplacian L = D - A（D为度矩阵，A为邻接矩阵）。b₁ = |E| - |V| + 1（对连通图）。

对于嵌入在2D曲面上的大图，b₁ ∝ A/ℓ²是面积律的必然推论（欧拉示性数）。但独立圈数（圈填数ν）与b₁的关系是：

$$b_1^{\text{ind}} = \nu(G) \leq b_1$$

圈填数ν(G)是图G的最大顶点不相交圈数。对于2D网格，ν(G) ≈ A/(kℓ²)其中k取决于网格类型（正方k=4, 三角k=2, 六角k=6）。

**关键困难：** ν(G)不仅取决于图的拓扑(b₁)，还取决于图的"几何"——节点如何在2D曲面上分布。两个b₁相同的图可以有截然不同的ν（如果一个是长链状，一个是团状）。

### S5.3.2 视界因果图的特殊性

视界因果图不是任意图——它是由信息流方向约束的有向图：
- 边方向反映信息溢出方向（从高q到低q）
- 在视界面上，q梯度主要沿径向→边主要沿方位角方向
- 这使得视界因果图近似是"方位角环+径向边的组合"

对于这种结构的图，ν(G)可能逼近b₁（每个方位角环对应一个独立圈）→ α_g ≈ O(1)。但精确值需要模拟。

### S5.3.3 Laplacian谱方法

图的Laplacian谱{λ_i}编码了图的全部拓扑信息。b₁ = #{零特征值} - 1 = #{λ_i = 0} - 1。圈填数ν与谱隙λ_2的关系是已知的（ν ≤ λ_2的某个函数），但不等价。

对于随机正则图，ν(G)的期望值已知（Bollobás, 2001），但视界因果图不是随机的——它具有由q梯度决定的特殊结构。

## S5.4 数值评估

以q_∞=1/2（DGF v3）为例：
- ℓ²/l_P² = 16/π ≈ 5.093
- η₀ = 0.1803
- g ≈ 7（从S_BH校准）

→ α_g = 4η₀g · l_P²/ℓ² = 4 × 0.1803 × 7 ÷ 5.093 ≈ 0.99

α_g ≈ 0.99 ≈ O(1)。这在物理上是合理的（每个独立环约占1个ℓ²的面积），说明DGF的标度假定内部自洽。

以κ=0.5（q_∞≈0.443）：
- ℓ²/l_P² = 8/(π×0.443) ≈ 5.74
- α_g = 4 × 0.1803 × 7 ÷ 5.74 ≈ 0.88 —— 仍在O(1)范围

以κ=2（q_∞≈0.557）：
- ℓ²/l_P² = 8/(π×0.557) ≈ 4.57
- α_g = 4 × 0.1803 × 7 ÷ 4.57 ≈ 1.10 —— 仍在O(1)范围

**结论：g≈7与α_g~O(1)在广泛的q_∞范围内自洽。g对q_∞的具体值不敏感——因为ℓ²/l_P²和从S_BH反推的g联动调整。**

## S5.5 诚实结论

**g因子不能从第一性原理独立计算。** 当前状态：

1. g是从S_BH = A/(4l_P²)反推的校准参数——不是推导结果。
2. 将g分解为α_g, η₀, ℓ²/l_P²后，只有η₀是独立推导的；ℓ²/l_P²依赖q_∞；α_g是未解决的图论问题。
3. 好消息：g≈7意味着α_g≈O(1)，这在物理上是合理的且对所有合理的q_∞值都稳健——这是非平凡的内部自洽检验。
4. 坏消息：我们目前无法区分"g≈7是偶然的"（校准的副产品）还是"g≈7是必然的"（因果图拓扑的深层属性）。

**具体出路（按可行性排序）：**

1. **数值模拟**（最可行，6-12个月）：在2D随机因果图上做圈填数计算的Monte Carlo模拟→数值确定α_g→用η₀和q_∞计算g→与7比较。这是新物理还是已知物理的测试。

2. **图论证明**（困难，开放问题）：证明在信息流方向约束下，2D曲面上顶点不相交圈的最大数量满足ν(G) = A/(α_g ℓ²)且α_g有特定的值。

3. **接受校准**（当前状态）：承认g是校准参数，不在LP39中声称其可推导性。这降低了框架的预言力（增加一个参数→需要其他观测来检验框架），但诚实。

**对P2的影响：** b₁→S_BH面积律的**标度关系**（S ∝ A）不依赖g的具体值——它来自b₁ ∝ A的拓扑必然。g只影响**归一化系数**（S = A/(4l_P²) vs S = k·A/ℓ²）。面积律的结构完整性不受g校准状态的影响。
