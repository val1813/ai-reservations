## 三步推进

### Phase 1: 二能级原子+真空电磁场（解析计算）

精确计算：
1. Weisskopf-Wigner自发辐射中Im(C₁₂)的衰减
2. 真空电磁场接收的量子态
3. 验证：d(Im从原子流出)/dt + d(Im被场接收)/dt = 0

**验算（强制）：**
- 量纲：[Im(C₁₂)]无量纲，[dIm/dt]=[时间⁻¹]，[Γ]=[时间⁻¹] → 一致
- Γ→0极限 → Im(C₁₂)常数为初始值 → 恢复幺正演化
- t→∞极限 → Im(C₁₂)→0 → 完全退相干，与Weisskopf-Wigner一致

### Phase 2: 热库（多模环境）

推广到有限温度热库：Im(C₁₂)流出速率是否仍然等于环境接收速率？
- T=0 → 回到Phase 1
- T>0 → 热涨落是否引入额外的Im(C₁₂)损失？

### Phase 3: 判断

- 若全局层面Ĵ=0在所有开放系统中成立 → S1存活 → 解锁S2（视界处的断裂）
- 若发现Ĵ≠0的物理来源 → 记录，分析是否需要新物理
