# LP25-S2 准备 | 视界处的 Im(C₁₂) 断裂

> S1验证：标准开放系统中Ĵ=0自动成立（全局幺正演化→信息守恒）。
> S2要问：当接收者因果断连（视界），Im(C₁₂)的去向还能被追踪吗？

## 1. 设置：Rindler视界

### 1.1 物理图景

二能级原子在均匀加速（加速度a），等效于静止在Rindler视界附近。原子自发辐射的光子可能：
- 路径A：向外传播，被惯性观测者（Minkowski真空中的探测器）接收
- 路径B：向内传播，穿越Rindler视界，进入因果断连区域

Minkowski观测者（可访问全局）vs Rindler观测者（只能访问Rindler楔形区）。

### 1.2 关键区分

| 观测者 | 可访问区域 | 能回收的Im(C₁₂) |
|--------|----------|----------------|
| Minkowski（全局） | 全时空 | 全部（路径A+B） |
| Rindler（加速） | 右Rindler楔形 | 仅路径A |

**全局观测者→Ĵ=0（S1结果）。Rindler观测者→部分Im(C₁₂)落入视界→？**

## 2. Unruh效应的Im(C₁₂)版本

### 2.1 标准Unruh效应

Minkowski真空 |0_M⟩ 在Rindler观测者看来是热态：
ρ_R = Tr_L |0_M⟩⟨0_M| = (1/Z) exp(-2πH_R/a)

其中 H_R 是Rindler Hamiltonian（boost生成元），T_U = a/(2π)。

### 2.2 对Im(C₁₂)的影响

考虑Minkowski真空中的二能级探测器。

在Minkowski观测者看来：全局纯态，无信息丢失→Ĵ=0。

在Rindler观测者看来：
- 探测器+右Rindler楔形构成了"系统+环境"
- 左Rindler楔形（因果断连）= 不可访问的接收者
- 落入左楔形的Im(C₁₂) = 从Rindler观测者视角"真正丢失"的信息

**Rindler观测者的Ĵ_R ≠ 0，因为部分Im(C₁₂)的去向永远无法被确认。**

## 3. 定量估计

### 3.1 分割比

Minkowski真空中的场模分解为Rindler左(L)和右(R)模：
b_k = (1/√(1-e^(-2πω/a))) (a_R,k - e^(-πω/a) a†_L,-k)

原子辐射的光子以概率 p_R 进入右楔形，以概率 p_L 进入左楔形。

在低频极限（ω ≪ a）：p_L/p_R ≈ 1（左右对称）
在高频极限（ω ≫ a）：p_L/p_R ≈ e^(-2πω/a) → 0（几乎全部进入右楔形）

### 3.2 Im(C₁₂)的分割

进入左楔形（因果断连）的Im(C₁₂)比例：
f_lost(ω) = e^(-πω/a) / (1 + e^(-πω/a))（来自Bogoliubov系数的模方比）

**Rindler观测者的Ĵ ≠ 0，丢失比例 = f_lost(ω)。**

## 4. 验算

### 验算1：a→0极限
a→0（无加速，惯性观测者）→ f_lost → 0 → 回归全局观测者→Ĵ=0 ✓

### 验算2：a→∞极限
a→∞（无限加速）→ f_lost → 1/2（左右完全对称）→ 一半信息丢失 ✓
（符合直觉：无限加速的观测者只能看到一半时空）

### 验算3：与Unruh温度一致
f_lost(ω) 的形式与Unruh热谱的Bose因子一致：热辐射中"不可见"的部分 = 视界后的部分。

## 5. S2的核心声称（待AB验证）

**Ĵ≠0在视界处是真实的物理断裂——不是"选择不观测"导致的局部幻觉。** 关键区分：

- S1（二能级+真空）：原则上可做全场测量→Ĵ=0是物理事实
- S2（视界）：原则上不可做全场测量（因果断连）→Ĵ≠0是物理事实

S1的"断裂是幻觉"和S2的"断裂是真实的"之间的界限 = 接收者是否因果可达。

## 6. 诚实边界

本推导仍用标准QFT在弯曲时空（Rindler楔形），没有使用量子引力。在Rindler视界的情况下，标准QFT已经足够——视界只是坐标奇点，不是曲率奇点。

黑洞视界（曲率非零）需要更完整的处理（S3候选）。
