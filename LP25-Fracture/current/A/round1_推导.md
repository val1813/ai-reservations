# LP25-S1 Round1 | Im(C₁₂)追踪：二能级原子+真空电磁场

## §0 框架声明

**框架：** 标准量子光学，Weisskopf-Wigner 自发辐射理论。不假设任何新物理。

**计算对象：** 二能级原子 |g⟩, |e⟩ + 真空电磁场（连续谱模式）。追踪密度矩阵非对角元 C₁₂ = ⟨g|ρ|e⟩ 的虚部 Im(C₁₂) 在辐射过程中的去向。

## 1. 系统设置

### 1.1 哈密顿量

H = H_atom + H_field + H_int

H_atom = (ℏω₀/2) σ_z
H_field = Σ_k ℏω_k a†_k a_k
H_int = Σ_k (g_k σ_+ a_k + g_k* σ_- a†_k)

初始态：|ψ(0)⟩ = (α|g⟩ + β|e⟩) ⊗ |0⟩_field

### 1.2 Weisskopf-Wigner 解

在单激发子空间中，任意时刻态为：
|ψ(t)⟩ = [α|g⟩ + β e^(-Γt/2) e^(-iω₀t) |e⟩] ⊗ |0⟩ + Σ_k c_k(t) |g⟩ ⊗ |1_k⟩

其中 Γ 是自发辐射速率：
Γ = (ω₀³ |d|²)/(3πε₀ℏc³) （电偶极跃迁）

## 2. Im(C₁₂) 的演化

### 2.1 系统密度矩阵

对场取迹后的原子密度矩阵（在基 {|g⟩, |e⟩} 中）：

ρ_atom(t) = [ρ_gg  ρ_ge; ρ_eg  ρ_ee]

ρ_ee(t) = |β|² e^(-Γt)
ρ_gg(t) = 1 - |β|² e^(-Γt)
ρ_eg(t) = α*β e^(-Γt/2) e^(-iω₀t)
ρ_ge(t) = ρ_eg*(t)

### 2.2 Im(C₁₂) 的显式

C₁₂(t) ≡ ρ_ge(t) = α β* e^(-Γt/2) e^(iω₀t)

Im(C₁₂(t)) = e^(-Γt/2) [Im(α β*) cos(ω₀t) + Re(α β*) sin(ω₀t)]

### 2.3 Im(C₁₂) 流出速率

d Im(C₁₂)/dt = -(Γ/2) Im(C₁₂) + ω₀ e^(-Γt/2) [Re(α β*) cos(ω₀t) - Im(α β*) sin(ω₀t)]

第一项 -(Γ/2) Im(C₁₂)：衰减包络——虚部以速率 Γ/2 指数衰减。
第二项 ~ ω₀：Larmor 进动——虚部在 g-e 之间振荡。

**虚部流出系统的特征速率 = Γ/2（包络衰减）。**

## 3. 环境（真空场）接收的 Im(C₁₂)

### 3.1 全系统纯态演化

原子+场的联合态始终是纯态（全局幺正演化）：
|ψ(t)⟩⟨ψ(t)| 始终是纯态投影算符。

### 3.2 场的接收

场模的激发振幅 c_k(t) 携带了原子丢失的量子信息。在 Weisskopf-Wigner 近似下：

c_k(t) = -i g_k* β ∫₀^t e^(-Γτ/2) e^(i(ω_k-ω₀)τ) dτ

对 k 求和得到场的单光子波包：
|1_photon(t)⟩ = Σ_k c_k(t) |1_k⟩

### 3.3 量子信息守恒

原子+场的联合 von Neumann 熵 S(ρ_atom+field) = 0（始终纯态）。

原子熵 S(ρ_atom) = -λ₁ ln λ₁ - λ₂ ln λ₂
场熵 S(ρ_field) = S(ρ_atom)（纠缠熵相等）

场完全接收了原子通过非对角元衰减释放的量子信息。
