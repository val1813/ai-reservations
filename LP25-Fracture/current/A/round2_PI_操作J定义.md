# LP25-S2 | 操作Ĵ的定义与平坦时空计算

> AB Round1 共同发现：Ĵ_mat=0（数学），但Ĵ_op需要精确定义。
> 本文件给出操作Ĵ的量化定义，并计算平坦时空中Ĵ_op(t)。

---

## 1. 操作Ĵ的定义

### 1.1 问题

数学Ĵ_mat = S(ρ_total) - S(ρ_initial) = 0（幺正性保证）。

但物理观测者不能访问全 Hilbert 空间。观测者 O 的因果可达域 D_O 限制了可回收的信息。

### 1.2 定义

```
Ĵ_op(O, t) ≡ I_initial - I_recoverable(O, t)
```

其中：
- I_initial = Im(C₁₂(0)) + S_vN(ρ_atom(0))：初始时原子的量子信息总量
- I_recoverable(O, t)：在时间 t 内，观测者 O 通过对其因果可达域 D_O(t) 中所有场模执行最优联合测量，可提取的量子信息量

**关键性质：**
- Ĵ_op ≥ Ĵ_mat = 0（操作损失≥数学损失）
- Ĵ_op = 0 当且仅当 D_O(t) 包含所有携带 Im(C₁₂) 的场模

## 2. 平坦时空中的 Ĵ_op(t)

### 2.1 设置

二能级原子在原点，t=0 开始自发辐射。观测者 O 在距离 R 处，探测器带宽 Ω_BW。

光锥约束：t < R/c 时，观测者因果不可达 → 任何场模信息不可回收。

### 2.2 可回收场模

在时间 t，原子辐射的光子波包以光速向外传播。波包的空间范围 ≈ c·Γ⁻¹（Γ 是自发辐射速率）。

观测者在时间 t 可访问的场模 = 光锥内部 + 波包范围内的模。

### 2.3 Ĵ_op(t) 的估计

简化模型：Im(C₁₂) 均匀分布在辐射光子波包的频谱中（Lorentzian 线型，宽度 Γ）。

观测者在时间 t 可回收的 Im(C₁₂) 比例：
```
f_recoverable(t) ≈ min(1, (t - R/c) · Γ)  [t > R/c]
                   = 0                      [t ≤ R/c]
```

操作Ĵ：
```
Ĵ_op(t) = (1 - f_recoverable(t)) × I_initial
```

### 2.4 数值

取典型原子参数：Γ = 10⁸ s⁻¹（电偶极跃迁），R = 1 m。

- t_RTO = R/c = 3.3 × 10⁻⁹ s
- 在 t = t_RTO + Γ⁻¹ = 3.3 × 10⁻⁹ + 10⁻⁸ ≈ 1.33 × 10⁻⁸ s 后：f_recoverable ≈ 1

**Ĵ_op → 0 在 ~13 ns 内。**

对于任何宏观距离 R，恢复时间 ~ R/c + 1/Γ。在实验室尺度（R ~ 1m），恢复几乎是瞬时的（相对于 Γ⁻¹）。

### 2.5 验算

极限 R → ∞：Ĵ_op → I_initial（永远不可回收）→ 等效于视界 ✓
极限 R → 0：Ĵ_op → 0（瞬时回收）→ 回归 Ĵ_mat ✓
极限 Γ → 0：波包无限宽 → Ĵ_op → 0 对所有有限 R ✓

---

## 3. 关键结论

**平坦时空中 Ĵ_op(t) → 0 在有限时间内。** 操作损失是暂时的，不是永久的。

**视界处 Ĵ_op(t) → 常数 > 0。** 操作损失是永久的——落入视界的场模永远在观测者因果可达域之外。

这个区分是 LP25 的核心：
- S1（平坦）：Ĵ_mat = 0, Ĵ_op(t) → 0（操作损失暂时，可以等）
- S2（视界）：Ĵ_mat = 0, Ĵ_op(t) → Ĵ_op(∞) > 0（操作损失永久，等不到）

**Ĵ_op(∞) ≠ 0 是视界的操作签名。**
