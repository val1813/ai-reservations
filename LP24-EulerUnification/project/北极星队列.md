## 当前北极星（LP24-S1）

**命题：** 复线丛 L→M 上的 Hermitian 度量保持条件 d h(ψ,ψ) = 0（即 |e^(iθ)|² = 1 的微分形式），同时生成量子幺正演化（纤维方向）和时空度规兼容性 ∇g = 0（底流形方向）。两个理论不是"被统一"，而是同一个纤维丛约束的两个投影。

**来源：** 对话.txt + Claude.pdf 欧拉公式统一框架，规避 LP23-S1（固定半径螺旋→已证伪）和 LP7（单一方程→已证伪）的致命缺陷。

**核心驱动矛盾：**

- 命题A：量子力学的幺正性 |ψ|² = 1 和广义相对论的度规兼容性 ∇_μ g_αβ = 0 是两个独立的基本原理，互不推导。
- 命题B：两者都是同一个复线丛 Hermitian 度量保持条件 d h(ψ,ψ) = 0 在不同投影方向上的表现，可以互推。
- 二者不能同时为真。若 B 成立，则 QM 和 GR 共享同一个几何根源。

**最小数学对象：** 复线丛 π: L → M，结构群 U(1)，Hermitian 度量 h，联络 D，曲率 F = dA。约束：d h(ψ,ψ) = h(Dψ,ψ) + h(ψ,Dψ) = 0。

**第一计算（S1，即可开始）：**
1. 在平坦 Minkowski 时空 M⁴ 上定义平凡复线丛 L = M × ℂ
2. Hermitian 度量 h(ψ,ψ) = ψ*ψ = |ψ|²
3. 联络 D_μ = ∂_μ - (i/ℏ) A_μ，其中 A_μ = (V, A) 为电磁4-势
4. 沿时间方向：d_t h(ψ,ψ) = h(D_t ψ, ψ) + h(ψ, D_t ψ) = 0
5. 展开 → ψ* (∂_t - iV/ℏ) ψ + ψ (∂_t + iV/ℏ) ψ* = 0
6. 令 ψ = e^(iS/ℏ)，代入 → ∂_t S + V + (ℏ²/2m)(∇S)² = 0（Hamilton-Jacobi + 量子修正）
7. 取 ℏ→0 极限 → 经典 Hamilton-Jacobi 方程
8. 保留 ℏ 项 → Schrödinger 方程 iℏ ∂_t ψ = H ψ

**验证标准：** S1 必须产出标准 Schrödinger 方程，且额外项可被解释为规范选择。若产出非标准项→进入深挖判断是规范artifact还是新物理。
