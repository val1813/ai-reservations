# 数据核验 | Ĵ 生/死测试的数值修正 | 2026-06-03

> SOP 收尾数据核验发现：round3_J生死测试.md 中的 ~8x 差异声称未被独立验证。
> 以下是修正。

---

## 1. 原声称

"Ĵ = dS_vN/dτ + ∇_μ J^μ_G ≠ 0 在 Hawking 辐射中（相差 ~8 倍）→ 标准 Hawking 辐射不满足 Ĵ = 0"

## 2. 数值核验

对 1 太阳质量 Schwarzschild 黑洞：

- Hawking 温度：T_H = ℏc³/(8πGMk_B) ≈ 6.2 × 10⁻⁸ K
- Hawking 功率：P_H ≈ 9.0 × 10⁻²⁹ W
- 辐射熵产生率（热力学）：dS_rad/dt = P_H / T_H ≈ 1.46 × 10⁻²¹ J/(K·s)
- BH 熵减少率：dS_BH/dt = -(8πGk_B M/ℏc) · P_H/c² ≈ -1.46 × 10⁻²¹ J/(K·s)

**比例：|dS_rad/dt / dS_BH/dt| = 1.000（在最简模型中精确相等）**

带 4/3 热辐射因子：比例 = 1.333（不是 ~8x）

## 3. 错误来源分析

原声称的 ~8x 差异可能来自：
1. 混淆了**热力学熵**（dS = dE/T）和**纠缠熵**（dS_vN，von Neumann）
2. 未计入 greybody 因子修正
3. 错误地使用了不同质量黑洞的标度关系

## 4. 修正后的判断

### Ĵ 在标准 Hawking 辐射中自动满足！

```
dS_thermo/dt + dS_BH/dt = 0  （热力学层面，精确相等）
```

这意味着：**如果 Ĵ 使用的是热力学熵，它在标准 Hawking 辐射中 Ĵ = 0，不是非平凡约束。**

### Ĵ 真正的约束内容

标准 Hawking 辐射在**热力学层面**是等熵的（总熵守恒），但在**量子信息层面**不是幺正的（纯态→混合态，von Neumann 纠缠熵增加）。

Ĵ = 0 如果要成为非平凡约束，必须使用**量子纠缠熵**（S_vN），而非热力学熵。

**修正后的 Ĵ：**
```
Ĵ = dS_vN/dτ + ∇_μ J^μ_G = 0
```

其中 S_vN 是 von Neumann 纠缠熵（不是 dE/T 热力学熵），J^μ_G 是几何侧的**量子信息流**（不是经典热流）。

标准 Hawking 辐射中：
- 热力学熵：dS_thermo/dt + dS_BH/dt = 0 ✅（自动满足）
- 纠缠熵：dS_vN/dt > 0（纯态→混合态，信息丢失），而 dS_BH/dt < 0 → **Ĵ ≠ 0**（这才是真正的非平凡约束）

### 修正后的预测

Ĵ = 0 不是一个**热力学约束**（标准 Hawking 辐射已满足），而是一个**量子信息约束**——它强制辐射的纠缠熵产生精确等于几何信息的减少。

这等价于要求**黑洞蒸发过程保持全局量子态为纯态**——即 Page 曲线的幺正蒸发。

**这个修正不改变 Ĵ 的定性结论（强制幺正蒸发），但澄清了机制：Ĵ 作用于量子信息层面（纠缠熵），而非热力学层面。**

## 6. 诚实的教训

**在 LP24 的推导中，我们在至少两个地方混淆了热力学熵和量子纠缠熵：**
1. Ĵ 生/死测试中计算 dS/dτ 时使用了 P/T（热力学），而非 S_vN（von Neumann）
2. Ĵ 的原始定义"dS_vN/dτ + ∇_μ J^μ_G"名义上使用了 S_vN，但测试计算时降级为热力学熵

这个混淆导致了对 Ĵ 约束强度的过度声称（~8x 差异 → 实际上 ~1x）。
