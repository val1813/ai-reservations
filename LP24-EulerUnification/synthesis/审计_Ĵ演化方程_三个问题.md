# 审计 | Ĵ(t) 演化方程的三个问题 | 2026-06-03

> 用户审计发现三个定义混淆和推导缺陷。
> 以下逐条确认，然后剥离出真正站得住的部分。

## 问题一：I_out 混用 Im(C₁₂) 流量和 von Neumann 熵流量

**审计：成立。**

文档中：
- 2.1 节 I_out 被定义为"逃逸辐射中携带的 Im(C₁₂) 总量"
- 3.1 节 Ĵ = 0 被写为 dI_out/dt = -dS_BH/dt，其中 dS_BH/dt 是 Bekenstein-Hawking 熵的导数（标量、实数）
- 但推导过程中，I_out 的维度被暗中替换成了熵的维度

**混淆的本质：** Im(C₁₂) 是复数（有相位），S_vN 是实数（无相位）。用 S_vN 的流动来代理 Im(C₁₂) 的流动，等于用 Born 规则工具（已抹掉虚部）去计算虚部效应。这是消融审计第二条的精确实例。

**后果：** Ĵ = dI_out/dt + dS_BH/dt 这个方程的左边（Im(C₁₂) 流）和右边（熵流）不在同一个数学空间里。等号本身没有良好定义。

**修正：** 需要分别定义：
- I_Im = ∫ dω dω' Im(ρ_rad(ω, ω'; t))（虚部流量，保留相位）
- S_vN = -Tr(ρ ln ρ)（熵，已丢弃相位）

两者不能放在同一个等式里，除非给出 Im→S 的映射关系——而这个映射本身就是 Born 规则（|·|²），正是我们试图推导的东西。

## 问题二：dS_BH/dt 不能作为"Im(C₁₂) 的几何接收器"

**审计：成立。**

S_BH = A/(4ℓ_Planck²) 是一个实数——它是面积除以 Planck 面积的纯数字。它没有任何复数结构，没有任何相位，没有任何非对角元。

声称"几何通过视界面积的减小来接收 Im(C₁₂)"需要：
1. 视界面积的每个 Planck 单元可以编码一个复数的相位信息
2. 面积变化 dA/dt 精确对应虚部信息的接收速率

假设(1)在全息原理中有一定支撑（'t Hooft, Susskind），但(2)没有推导。文档直接把 dS_BH/dt 写进 Ĵ 的定义里，等于假设了结论。

**这是消融审计第三条的精确实例：** Jacobson 热力学推导只涉及能量和熵（实数），不涉及任何相位或相干信息。用 Jacobson 框架来构建 Ĵ 的几何侧，几何侧天然就是"盲视虚部"的。

**修正：** 几何侧接收 Im(C₁₂) 的能力必须用**不依赖 Bekenstein-Hawking 熵**的量来表达。可能的候选：
- 视界的量子纠缠熵（需要完整的量子引力计算）
- 视界附近真空涨落的相位关联函数
- 但目前没有已知工具可以不用 S_BH 来精确计算这个量

## 问题三：I_out(M) = (4πGk_B/ℏc)(M₀² - M²) 是 Ĵ = 0 的重述，不是独立预言

**审计：成立。**

推导路径：
1. 假设 Ĵ = 0
2. 积分 dI_out/dM = -dS_BH/dM
3. 得到 I_out(M) 的公式

这是正确的推导，但预言的强度在于：**如果 Ĵ = 0，则 I_out 必须如此。** 这等价于说"如果 A 成立，则 B 成立"——它在逻辑上是重言式。

一个真正强的预言应该有**两条独立路径**汇聚到同一个数值：
- 路径1：从 Ĵ = 0 推导 I_out
- 路径2：从完全不同的物理原理（例如：全息对偶、量子纠错、纠缠楔）独立计算 I_out
- 如果两个路径给出的数值一致 → 强预言
- 如果只有路径1 → 这是"如果 Ĵ = 0 成立"的后件，不是对 Ĵ = 0 本身的检验

**修正：** 需要一条不依赖 Ĵ = 0 的独立计算路径。例如：从 AdS/CFT 全息对偶中计算边界 CFT 的 Im(C₁₂) 恢复速率，看是否与 Ĵ = 0 的预言一致。

## 剥离后：什么真正站得住

剔除以上三个问题后，以下部分是**无依赖的**：

### 成立的内核

1. **C_J(ω, Δω) 预言**（4.3 节）：
   - 如果 Im(C₁₂) 存在于辐射中，不同频率模式之间的密度-密度关联函数会有非对角贡献
   - 标准热辐射中，这个非对角贡献为零
   - 非零的 C_J 是 Im(C₁₂) 存在的直接证据
   - **这个预言不需要 S_BH、不需要 I_out 的精确定义、不需要 Ĵ = 0 的假设**
   - 它只需要一件事：存在一种测量，能捕捉辐射中不同频率模式的相位关联

2. **定性结构**：
   - Born 规则 = |·|² = 丢弃虚部
   - 断裂 = Im(C₁₂) 的去向没有被因果可访问的接收者追踪
   - 视界 = 接收者因果不可达的特例
   - 这个结构是概念性的，不依赖任何具体计算

### 需要撤回的

1. ~~I_out(M) = (4πGk_B/ℏc)(M₀² - M²)~~ — 纯 Ĵ = 0 重述，非独立预言
2. ~~Ĵ = dI_out/dt + dS_BH/dt~~ — 左边（复数流量）和右边（实数熵）不在同一数学空间
3. ~~dS_BH/dt 作为 Im(C₁₂) 接收速率~~ — 没有推导，只有断言

## 审计后状态

推导的内核缩小了，但更坚固了。剩下的是一件东西：

**C_J(ω, Δω) ≠ 0 —— 辐射中不同频率模式之间存在相位关联。**

这是可检验的。它不需要 Born 规则以外的熵定义，不需要 Bekenstein-Hawking 熵的争议性角色，不需要 Ĵ = 0 作为假设。它只需要：如果 Im(C₁₂) 在辐射中存活，它会在密度-密度关联函数中留下非对角的交叉峰。找到这个峰 = 找到 Im(C₁₂) 的证据。
