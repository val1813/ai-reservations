# 研究计划 | LP24-S1

## 命题

**复线丛 Hermitian 度量保持条件 d h(ψ,ψ) = 0 在平坦时空中严格推导出 Schrödinger 方程。**

具体地：在平凡复线丛 L = M⁴ × ℂ 上（M⁴ 为 Minkowski 时空），Hermitian 度量 h(ψ,ψ) = ψ*ψ，联络 D_μ = ∂_μ - (i/ℏ) A_μ。约束 d_t h(ψ,ψ) = 0（沿时间方向的度量保持）经过展开，精确产出：
1. iℏ ∂_t ψ = H ψ（Schrödinger 方程，ℏ 阶保留）
2. ∂_t S + V + (1/2m)(∇S)² = 0（Hamilton-Jacobi 方程，ℏ→0 极限）

## 三步推进

### Phase 1（数学验证，当前）
从 d h(ψ,ψ) = 0 出发，逐行推导出 Schrödinger 方程。验证：
- 推导的每一步是否严格（无跳步）
- 是否引入了未声明的额外假设
- 最终方程是否与标准 Schrödinger 方程完全一致
- ℏ 在推导中扮演什么角色（是外加参数还是几何必然）

### Phase 2（A/B 对抗验证）
- A博士：学院派验证——是否所有步骤在微分几何中严格成立？联络形式是否最一般？
- B博士：跨域攻击——这个约束在其他纤维丛（如 SU(2), SU(3)）上会产出什么？是否只有 U(1) 能产出 Schrödinger？

### Phase 3（综合判断）
- 如果 S1 成立且 Schrödinger 方程被严格导出 → S1 存活 → 解锁 S2（弯曲时空 → Einstein）
- 如果推导有漏洞但可修复 → 深挖，修正后重试
- 如果根本性失败 → 降级，记录失败原因

## 关键风险

1. **同义反复风险**：d h(ψ,ψ) = 0 可能只是 Schrödinger 方程的几何重述，而非推导（需要验证逻辑方向）
2. **联络选择任意性**：D_μ = ∂_μ - (i/ℏ)A_μ 中 ℏ 的手动引入可能是额外假设而非几何必然
3. **时间方向特殊性**：为什么是 d_t 而不是 d_μ？是否需要优先选定类时矢量场？

## 预期产出

- 成立：从纯几何约束推导出 Schrödinger 方程的完整链条，ℏ 作为联络的规范固定出现
- 证伪：d h(ψ,ψ) = 0 等价于 Schrödinger 方程（同义反复）→ 无新增信息
- 有边界：在 U(1) 平凡丛上成立，但在非平凡丛或弯曲时空需要修正
