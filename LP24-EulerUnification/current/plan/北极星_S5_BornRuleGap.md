## 命题

**Born 规则的 P(a) = |⟨a|ψ⟩|² 和 Schrödinger 方程的 iℏ∂_t|ψ⟩ = H|ψ⟩ 不是两个独立的基本公设。它们是同一个 Hermitian 度量 h(·,·) 在 U(1) 纤维丛上两种互补投影。两者之间的"断裂"不是逻辑矛盾，而是 U(1) 纤维本身的几何表达——该纤维正是 Born 规则投影掉而 Schrödinger 演化保留的相位自由度。**

断裂不是被"消除"的——它是被理解为几何必然的。

## 核心驱动矛盾（L0级：Einstein式"两个基本原理不能同时为真"）

- **命题A**：Born 规则是量子力学中不可推导的独立公设，它与 Schrödinger 方程之间存在无法弥合的断裂（这是2026年物理学界的共识）。
- **命题B**：Born 规则的 |·|² 和 Schrödinger 演化的 |ψ|²=1 是同一个 Hermitian 度量 h 的不同应用，它们的一致性由纤维丛的度量兼容条件 D h = 0 强制保证。断裂是 U(1) 纤维——一个几何必然，非逻辑缺陷。
- **二者不能同时为真。** 若 B 成立，则 Born 规则-Schrödinger 断裂被"愈合"——不是通过推导一个从另一个，而是通过识别两者共享的几何起源。

## 最小数学对象

1. **射影 Hilbert 空间** P(H) = {rays in H}（物理态的真实空间）
2. **U(1) 主丛** π: S(H) → P(H)，其中 S(H) = {ψ ∈ H : ⟨ψ|ψ⟩ = 1}（单位球面）
3. **Hermitian 度量** h(φ, ψ) = ⟨φ|ψ⟩（丛上的自然 Hermitian 结构）
4. **联络** D（由 h 和辛结构唯一确定的 Berry-Simon 联络）
5. **度量兼容条件** D h = 0（强制平行移动保内积）

## S5.2 推导路线（核心）

```
起点：射影 Hilbert 空间 P(H) 上的 U(1) 主丛
  |
  v
物理态 = ray [ψ] ∈ P(H)
波函数 = 代表元 |ψ⟩ ∈ S(H)（纤维上的一个点）
  |
  v
Hermitian 度量 h 有两个自然应用：
  (i)  自度量：h(ψ, ψ) = ⟨ψ|ψ⟩ = |ψ|² — 这是 Schrödinger 守恒量
  (ii) 交叉度量：h(ψ, P_a ψ) = ⟨ψ|P_a|ψ⟩ = |⟨a|ψ⟩|² — 这是 Born 概率
  |
  v
D h = 0（度量兼容联络）→
  对 (i)：平行移动保 |ψ|² → 幺正演化 → Schrödinger 方程
  对 (ii)：投影到子空间保正定性 → Kolmogorov 概率公理 → Born 规则
  |
  v
"断裂"的几何本质：
  Born 规则的 |·|² 作用于 base space 投影（射影 Hilbert 空间上的 Fubini-Study 度量）
  Schrödinger 的 |·|² 作用于 fiber 方向（U(1) 相位自由度）
  两者是同一个 h 的不同分量 → "断裂" = fiber 方向 = 相位 = e^(iθ) 的 θ
  |
  v
结论：Born 规则和 Schrödinger 方程不是两个独立公设。
      它们共享 h 作为唯一几何输入。断裂是几何结构的一部分，不是缺陷。
```

## 验证标准（生/死测试）

**生死测试1（几何一致性）：** h(ψ, P_a ψ) = |⟨a|ψ⟩|² 是否自然满足 Kolmogorov 概率公理？
- 正定性：h(ψ, P_a ψ) = ⟨ψ|P_a|ψ⟩ ≥ 0（P_a 正半定）✅
- 归一性：Σ_a h(ψ, P_a ψ) = ⟨ψ|Σ_a P_a|ψ⟩ = ⟨ψ|I|ψ⟩ = 1（完备性）✅
- 可加性：对正交投影自动满足 ✅

**生死测试2（唯一性）：** h(·, P_a ·) 是否是 P(H) 上唯一满足 D h = 0 兼容的概率测度？
- Gleason 定理：是（在 dim ≥ 3 时唯一）
- 但我们给出了 Gleason 定理的几何解释：它等价于"在 P(H) 的 U(1) 丛上存在唯一的度量兼容联络"

**生死测试3（与先发的区分）：** 是否有任何文献明确声称：Born 规则 = Hermitian 度量 h 对投影算符的作用？
