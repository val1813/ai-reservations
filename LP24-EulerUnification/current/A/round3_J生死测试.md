## 2. 量子熵流 dS_vN/dτ

### 2.1 静态时空中的量子场

在静态时空中，Killing 矢量 ∂_t 允许能量的正频/负频分解。Boulware 真空 |B⟩ 在无穷远处看来是空的（无粒子），但在视界附近发散。

Hartle-Hawking 真空 |H⟩ 在视界和无穷远处都是热平衡态（T = κ/2π = 1/8πGM），但需要热库。Unruh 真空 |U⟩ 在视界处有 outgoing 辐射通量。

### 2.2 选择真空

对于静态观测者，自然的真空是 Boulware 真空 |B⟩。但 Boulware 真空在 r → 2GM 处发散，需要 UV 截断。

另一个选择是 Unruh 真空 |U⟩（描述蒸发的黑洞）。在 |U⟩ 中：
- 视界附近有 outgoing 热通量（Hawking 辐射）
- 无穷远处有净能流

### 2.3 von Neumann 熵流

对无质量标量场，在 1+1 维截面上（s-波近似），Boulware 真空的纠缠熵：
S_vN(r₀) ≈ (1/6) ln(L/ε) + (1/12) ln(1 - 2GM/r₀)

其中 L 是红外截断（系统尺寸），ε 是 UV 截断。

对于静态观测者：dS_vN/dτ = 0（Boulware 真空是 Killing 不变的 → 时间平移对称性下熵不变）。

**在标准 QFT + Schwarzschild + Boulware 真空中：dS_vN/dτ = 0。**

### 2.4 如果使用 Unruh 真空

Unruh 真空有 outgoing 通量：
dS_vN/dτ = (1/1920π G² M²) × (1 - 2GM/r₀)⁻¹/²

这个量很小（对太阳质量黑洞 ~ 10⁻⁷⁷），但非零。

## 3. 几何熵流 ∇_μ J^μ_G

### 3.1 Jacobson 的几何熵

从 Jacobson (1995)：局域 Rindler 视界的熵变化率由能量-动量通量决定：
∇_μ J^μ_G = (2π/ℏ) T_μν k^μ k^ν

其中 k^μ 是局域 Rindler 视界的切矢量（近似的类光 Killing 矢量）。

### 3.2 Schwarzschild 中的计算

对于静态观测者在 r₀：
- 局域 Rindler 加速度 a = GM/(r₀² √(1 - 2GM/r₀))
- Unruh 温度 T_U = ℏ a / 2π k_B
- 净能量通量：Hawking 辐射在 r₀ 处的能流 ≈ (ℏ/30720π G² M²) × (2GM/r₀²)

几何熵流：
∇_μ J^μ_G ≈ (2π/ℏ) × (ℏ/30720π G² M²) × (1 - 2GM/r₀)⁻¹
= (1/15360 G² M²) × (1 - 2GM/r₀)⁻¹

### 3.3 Boulware 真空

在 Boulware 真空中，无穷远处的观测者看不到粒子，视界处的应力-能量为零。因此：
∇_μ J^μ_G = 0（无净能流穿过局域 Rindler 视界）。

## 5. 生/死判决

### 5.1 判决

**Ĵ ≠ 0 在标准 Hawking 辐射（Unruh 真空 + Schwarzschild）中。**

这意味着：
- 如果 Ĵ = 0 是一个严格的约束，那么标准 Schwarzschild + Unruh 真空+ Hawking 辐射**不满足这个约束**

### 5.2 这意味着什么

如果 Ĵ = 0 是基本的（来自总空间 D h = 0），那么：
1. **标准 Hawking 辐射谱被修正。** Ĵ = 0 要求量子熵产生率精确等于几何熵减少率——这等价于要求黑洞蒸发是严格幺正的（Page 曲线），而非热辐射。
2. **修正量级：** 偏离标准 Hawking 辐射约 10⁻¹ 量级（dS_vN/dτ 和 ∇_μ J^μ_G 相差 ~8 倍），这意味着 Ĵ = 0 约束的非平凡性很强。

### 5.3 Ĵ 约束的物理内容

Ĵ = 0 等价于声明：**量子信息和几何信息在每一点、每一时刻精确守恒。** 标准 Hawking 辐射违反这个条件（量子熵增加 > 几何熵减少），因此被排除。

修正后的辐射谱必须满足：
