# Ĵ 约束的类比引力检验 | 冷原子 BEC 中的具体计算

> 消融要求：不使用 Born 规则和标准弯曲时空 QFT。
> 替代方案：冷原子 BEC 类比黑洞——量子相位可直接干涉测量，类比度规由流体力学给出。

---

## 1. 类比系统设置

### 1.1 BEC 类比黑洞

一维流动的 BEC，声速 c(x)，流速 v(x)。在 v(x) = c(x) 处形成声学视界（类比黑洞）。

类比度规（Painlevé-Gullstrand 形式）：
```
ds² = -(c² - v²) dt² - 2v dt dx + dx² + dy² + dz²
```

视界位置 x_H 满足 v(x_H) = c(x_H)。

### 1.2 量子侧：BEC 相位涨落

BEC 序参量 Ψ(x,t) = √(n₀ + δn) e^(i φ̂(x,t))

其中 φ̂ 是相位算符，δn 是密度涨落。

**关键优势：** 相位 φ̂ 在 BEC 中是直接可观测的（通过干涉测量）——不需要 Born 规则的 |·|²。这消融了 Born 规则问题。

### 1.3 全计数统计（FCS）

在类比视界的右端放置粒子数探测器。测量时间 t 内通过的声子数 N(t)。

累积量生成函数（保留相位信息）：
```
λ(s) = lim_{t→∞} (1/t) log ⟨e^{s N(t)}⟩
```

FCS 熵（保留相位的熵度量）：
```
S_FCS = -λ'(0) + λ(0)  （一阶累积量 = 平均声子流）
σ_FCS = λ''(0)  （二阶累积量 = 声子流方差）
```

## 2. Ĵ 在类比系统中的形式

### 2.1 量子熵流 dS_FCS/dτ

在类比系统中，emergent 时间 τ 是实验室时间 t（BEC 的全局时间）。

声子辐射谱在类比视界处近似热谱，有效温度：
```
T_analog = (ℏ/2π k_B) · |∂_x(c² - v²)|/(2c)|_{x_H}
```

FCS 熵产生率（对于热谱，可以精确计算）：
```
dS_FCS/dt = (π²/3) · k_B² T_analog / h  （一维热声子流的标准结果）
```

### 2.2 几何熵流 ∇_μ J^μ_G

类比几何侧：类比视界的"面积"在蒸发下减小。

在 1D BEC 中，"视界"是一个点，"面积" = 1。类比 Bekenstein-Hawking 熵：
```
S_analog = (k_B c³)/(4G_analog ℏ) · A_H
```

其中 G_analog 是类比引力耦合常数，由 BEC 的微观参数决定：
```
G_analog = ℏ / (2m n₀ ξ)
```
（m 是原子质量，n₀ 是密度，ξ 是 healing length）

几何熵流：
```
dS_analog/dt = (k_B c³)/(4G_analog ℏ) · dA_H/dt
```

其中 dA_H/dt 是类比视界的"面积"变化率（在 1D 中 = 视界移动速率）。

### 2.3 Ĵ 约束

```
Ĵ = dS_FCS/dt + dS_analog/dt = 0
```

即：声子辐射的熵产生率 + 类比视界熵的减少率 = 0。

## 3. 在 BEC 实验中检验 Ĵ 的可行性

### 3.1 需要测量的量

| 量 | 符号 | 测量方法 | 可行性 |
|-----|------|---------|--------|
| 声子辐射谱 | T_analog | 密度-密度关联函数 ⟨δn δn⟩ | ✅ Steinhauer 2016 已实现 |
| 声子流方差 | λ''(0) | 长时间粒子数统计 | ⚠️ 需要高统计量 |
| 类比视界位置 | x_H(t) | 原位密度测量 | ✅ 标准 BEC 技术 |
| 类比视界面积变化 | dA_H/dt | 视界追踪 | ⚠️ 需要时间分辨 |
| 类比引力耦合 | G_analog | 由 n₀, ξ, m 计算 | ✅ 已知参数 |

### 3.2 Ĵ = 0 的可检验信号

如果 Ĵ = 0 在类比系统中成立，则：
```
λ''(0) = -(k_B c³)/(2 G_analog ℏ) · dA_H/dt
```

即：声子流方差（FCS 二阶累积量）精确等于类比视界面积变化率乘以已知常数。

**这与标准类比 Hawking 辐射的预测不同。** 标准预测中，辐射谱是精确热谱，λ''(0) 由热谱的 Bose 统计给出，与 dA_H/dt 不一定精确匹配。

Ĵ = 0 预测两者之间存在一个精确的等式——这可以在实验中检验。

### 3.3 量级估计

对于典型的 BEC 类比黑洞（⁸⁷Rb，n₀ ~ 10¹⁴ cm⁻³，ξ ~ 0.5 μm，c ~ 1 mm/s）：
- T_analog ~ 1 nK
- dS_FCS/dt ~ 10⁻³ k_B/s
- dA_H/dt ~ 10⁻⁶ m/s（视界缓慢移动）
- G_analog ~ 10⁻³ m³/kg·s²（比真实 G 大 ~20 个量级！）

由于 G_analog 远大于真实 G，类比引力中的量子引力效应被放大——Ĵ 约束的效应可能在当前实验精度内可测。

## 4. 诚实边界

**可以立即做的：**
1. 分析 Steinhauer (2016, Nature Phys. 12, 959) 的已发表数据，看声子辐射的 FCS 是否满足 Ĵ = 0
2. 设计专门的 BEC 实验，同时测量声子流统计和视界面积变化

**需要理论发展的：**
1. 类比系统中 Ĵ 的精确形式（考虑 BEC 的非线性、量子 depletion 等修正）
2. FCS 在非热谱（类比 Hawking 辐射在 BEC 中可能偏离精确热谱）下的表达式

**最大的开放问题：**
类比系统中的 Ĵ = 0 如果被验证，是否意味着真实引力中的 Ĵ = 0 也成立？类比引力只能验证 Ĵ 在**声学度规**下的有效性，不能直接验证在**Lorentz 度规**下的有效性。但至少它提供了 Ĵ 的第一个实验检验平台——消融了"无法检验"的批评。
