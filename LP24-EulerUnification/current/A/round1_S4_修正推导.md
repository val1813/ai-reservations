# LP24 修正推导 | 从 Schrödinger 到约束方程 —— Wheeler-DeWitt 视角

> B博士的攻击揭示了根本问题：如果统一量子力学和广义相对论，
> 基本方程不可能是 Schrödinger 方程（需要外部时间），

> 本文件重新推导统一框架。

## 0. 问题的重新定位

### 0.1 S1-S3 推导的根本缺陷

S1 试图从 |e^(iθ)|² = 1 + 平行移动 → Schrödinger 方程。
S2 将其推广到弯曲时空。
S3 尝试用 Wick 转动统一两者。

**致命缺陷（B博士 + 自我攻击共识）：** 
1. |e^(iθ)|² = 1 只保证幺正性，不决定动力学形式
2. A_μ = p_μ/ℏ 是循环论证（假设了自由粒子来"推导"自由 Schrödinger）
3. Wheeler-DeWitt 方程 Ĥ|Ψ⟩ = 0 是量子引力的基本方程——它没有外部时间，与 Schrödinger 结构上不兼容

### 0.2 但是...也许 Wheeler-DeWitt 正是答案

Wheeler-DeWitt 方程是约束方程。|e^(iθ)|² = 1 也是约束。
**两个约束方程具有相同的数学结构：都描述在某个空间上的"零集"。**

在 Wheeler-DeWitt 中：物理态是约束面 Ĥ|Ψ⟩ = 0 上的态。
在 |e^(iθ)|² = 1 中：物理态是单位圆 |ψ|² = 1 上的态。

**核心假设（修正版）：统一公式不是 Schrödinger 方程，而是一个更一般的约束方程。Schrödinger 方程和 Einstein 方程都是这个约束方程在不同规范固定（foliation/section choice）下的投影。**

## 1. 约束几何框架

### 1.1 从演化方程到约束方程

Schrödinger: iℏ ∂_t ψ = Ĥ ψ
⟹ 定义约束 C_S = iℏ ∂_t - Ĥ
⟹ Schrödinger ⇔ C_S |ψ⟩ = 0

Einstein: G_μν - 8πG T_μν = 0
⟹ 定义约束 C_E^μν = G_μν - 8πG T_μν
⟹ Einstein ⇔ C_E^μν = 0

Wheeler-DeWitt: Ĥ |Ψ⟩ = 0
⟹ 这是约束 C_WDW = Ĥ（总 Hamiltonian 约束）

**观察：所有三个基本方程都可以写成"某算符作用在某对象上 = 0"的形式。**

### 1.2 统一约束猜想的数学形式

设 E 为总空间（复线丛的全空间），E 上的截面构成物理态空间。
在 E 上定义**统一约束算符** Ĉ：

```
Ĉ Ψ = 0
```

其中：
- Ψ 是总空间上的"波函数"（取值于 E 的泛函）
- Ĉ 是包含所有生成元的约束算符

当 Ĉ 作用在纤维方向（U(1) 生成元）：ħ Ψ = 0 → 量子约束
当 Ĉ 作用在底流形方向（diffeomorphism 生成元）：Ĥ_μ Ψ = 0 → 引力约束

### 1.3 Ĉ 的具体形式

统一约束 Ĉ 由以下生成元组成：

**纤维方向（量子，Abel）：**
- Ĥ_0 Ψ = 0（U(1) 生成元约束）→ 在适当规范固定后 → Schrödinger 方程

**底流形方向（引力，非 Abel）：**
- Ĥ_μ Ψ = 0（微分同胚约束，μ = 0,1,2,3）
- 其中 Ĥ_0 是 Hamiltonian 约束（Wheeler-DeWitt）
- Ĥ_i 是动量约束（空间微分同胚）

**交叉方向（量子-引力耦合）：**
- Ĵ_μ Ψ = 0（量子电流守恒 → 协变能量-动量守恒 ∇_μ T^μν = 0）

在约束面上：
- Ĥ_0 = 0 保证时间重参数化不变性（引力侧的时间是 emergent）
- Ĥ_i = 0 保证空间微分同胚不变性
- ħ_0 = 0 保证 U(1) 相位不变性（量子幺正性）

### 1.4 统一约束代数

约束之间的 Poisson 括号（或对易子）应闭合：

[Ĥ_μ, Ĥ_ν] = f_μν^α Ĥ_α + g_μν^αβ Ĵ_αβ + ...（结构函数，非 Abel）
[Ĥ_μ, ħ_0] = 0（量子相位约束与微分同胚对易）
[ħ_0, ħ_0] = 0（Abel）

如果约束代数闭合，则 Ĉ Ψ = 0 是自洽的约束系统。
这正是 Dirac 约束量化框架的标准形式。

## 2. 从约束到"演化"——规范固定与 emergent 时间

### 2.1 为什么我们看到了 Schrödinger 方程

在约束系统 Ĉ Ψ = 0 中，没有先验的时间参数。时间是通过**规范固定**引入的：

1. 选择类时矢量场 n^μ（观测者世界线）
2. 将 Hamiltonian 约束 Ĥ_0 分解为：Ĥ_0 = iℏ ∂_τ + H_matter
3. 约束 Ĥ_0 Ψ = 0 → iℏ ∂_τ Ψ = -H_matter Ψ → Schrödinger 型方程

这里 τ 是沿 n^μ 的**emergent 时间**——它不是基本的，而是规范固定的产物。

### 2.2 三个极限

**极限1：Minkowski + 无引力**
选择惯性观测者 n^μ = (1,0,0,0)，平坦时空。
Ĥ_i 约束平凡满足（全局惯性系中动量守恒）。
Ĥ_0 Ψ = 0 → iℏ ∂_t Ψ = H Ψ → 标准 Schrödinger 方程。

**极限2：弯曲时空 + 经典引力**
度规 g_μν 是经典的。Ĥ_μ 约束给出 Einstein 方程（通过 Jacobson 热力学或变分原理）。
Ψ 在经典背景上演化：iℏ D_t Ψ = H Ψ（弯曲时空 Schrödinger/Klein-Gordon/Dirac）。

**极限3：完全量子引力**
没有经典时空，没有外部时间。Ĥ_0 Ψ = 0 是 Wheeler-DeWitt 方程。
"演化"通过自由度之间的关联来定义——Page-Wootters 机制或类似方案。

## 3. |e^(iθ)|² = 1 在约束框架中的角色

### 3.1 重新定位：不是生成器，是选择器

|e^(iθ)|² = 1 不是"推导"物理的起点。它是**选择物理态空间的约束**。

具体地：
- 在 Ĉ Ψ = 0 的所有解中，|e^(iθ)|² = 1 选择那些在 U(1) 纤维上保持幺正性的解
- 这等价于要求 ħ_0 约束是**第一类约束**（first-class constraint）——它生成规范变换（U(1) 相位旋转），且与其他约束对易

### 3.2 "0 和 1"的约束诠释

在欧拉恒等式 e^(iπ) + 1 = 0 中：
- **"1"** = 幺正性约束 |ψ|² = 1 → 物理态在单位圆上
- **"0"** = 约束方程 Ĉ Ψ = 0 → 物理态在约束面上

两者的统一：物理态是**单位圆 ∩ 约束面**上的点。

在纤维丛语言中：
- "1" 选择纤维上的截面（纤维 = U(1) 圆，|ψ|² = 1 选的是圆上的点）
- "0" 选择底流形上的截面（底流形 = 相空间约束面，Ĉ = 0 选的是约束面上的点）

总物理态空间 = 纤维方向单位圆 × 底流形方向约束面 = 一个**联合约束流形**。

## 4. 统一公式——最终版

### 4.1 公式

```
Ĉ Ψ = 0  subject to  |Ψ|²_E = 1
```

其中：
- Ĉ = {Ĥ_μ, ħ_0} 是总空间 E（U(1) → E → M）上的约束算符集合
- ħ_0 是 U(1) 生成元（相位旋转约束）
- Ĥ_μ = {Ĥ_0, Ĥ_i} 是微分同胚生成元（Hamiltonian + 动量约束）
- |Ψ|²_E = 1 是总空间上的 Hermitian 范数约束
- Ψ 是总空间上的波函数泛函

### 4.2 约束代数的物理内容

| 约束 | 生成对称性 | 物理后果 |
|------|----------|---------|
| ħ_0 Ψ = 0 | U(1) 相位旋转 | 幺正性，概率守恒 |
| Ĥ_0 Ψ = 0 | 时间重参数化 | "时间" emergent，Wheeler-DeWitt |
| Ĥ_i Ψ = 0 | 空间微分同胚 | 动量守恒，空间几何 emergent |
| |Ψ|²_E = 1 | Hermitian 度量保持 | 总概率 = 1，纤维的紧性 |

### 4.3 规范固定 → 已知物理

**规范固定1（实验室坐标系）：**
- 选择 ∂_t 作为演化方向
- Ĥ_0 Ψ = 0 → iℏ ∂_t ψ = H ψ（Schrödinger，含引力的 emergent 势）

**规范固定2（共动坐标系 + 经典极限）：**
- 取 ℏ → 0，G → 0（或大尺度）
- Ĥ_i Ψ = 0 → ∇_μ T^μν = 0（能量-动量守恒）
- + Jacobson 热力学 → G_μν = 8πG T_μν（Einstein 方程）

**规范固定3（完全协变，无规范固定）：**
- Ĉ Ψ = 0（全部约束同时施加）
- Wheeler-DeWitt 方程 + 动量约束 + U(1) 约束
- 这是量子引力的完整描述

## 5. 与欧拉公式的最终连接

欧拉公式：**e^(iθ) = cos θ + i sin θ**

在这个统一框架中：
- **e^(iθ)** = U(1) 群元素 = 纤维方向的约束生成元
- **θ** = 约束面上的参数（emergent 时间/相位）
- **cos θ + i sin θ** = 约束的分解：
  - cos θ → "实部" → 可观测量（在约束面上投影到配置空间）
  - sin θ → "虚部" → 量子相位（纤维上的 U(1) 位置）
- **|e^(iθ)| = 1** = 总约束 |Ψ|²_E = 1
- **e^(iπ) + 1 = 0** = 约束在 π 相位处的特殊值：
  - 约束方程 Ĉ Ψ = 0（"0"）
  - 幺正约束 |Ψ|² = 1（"1"）
  - 在 θ = π 处两个约束在同一个方程中交汇

**公式的核心：Ĉ Ψ = 0 且 |Ψ|²_E = 1。这是从欧拉公式出发的量子力学-广义相对论统一约束方程。**
