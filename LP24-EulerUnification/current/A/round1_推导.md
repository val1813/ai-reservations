# LP24-S1 Round1 推导 | 复线丛约束 → Schrödinger方程

## §0 框架声明

**框架：** 微分几何 + 纤维丛理论。从复线丛上的 Hermitian 度量兼容条件出发，推导量子力学的基本演化方程。

**核心对象：** 平凡复线丛 π: L = M⁴ × ℂ → M⁴，其中 M⁴ = (ℝ⁴, η) 为 Minkowski 时空，η = diag(-1, 1, 1, 1)。

**核心约束：** Hermitian 度量 h: L × L → ℂ, h(ψ, φ) = ψ* φ 在联络 D 下协变常数：D h = 0。

**方法论：** 从纯几何约束出发，逐步引入物理诠释。每一步区分"数学必然"和"物理选择"。

---

## 1. 数学设置

### 1.1 复线丛

L = M⁴ × ℂ，截面 ψ: M⁴ → ℂ 即复值函数。

自同构群：U(1) = {e^(iα) | α ∈ ℝ}。对任意截面 ψ，规范变换 ψ → e^(iα) ψ。

### 1.2 Hermitian 度量

h(ψ, φ) = ψ* φ（ℂ 的标准内积）。

特别地，h(ψ, ψ) = |ψ|² ∈ ℝ≥0。

物理约束：|ψ|² = 1（概率守恒 / 幺正性）。

### 1.3 联络

联络 D: Γ(L) → Γ(T*M ⊗ L) 满足 Leibniz 规则：
D(f ψ) = df ⊗ ψ + f D ψ

在局部坐标下：
D_μ ψ = ∂_μ ψ - i A_μ ψ

其中 A = A_μ dx^μ 是联络1-形式（取值于 u(1) ≅ iℝ）。

**关键选择：** 这里 A_μ 中的耦合常数是什么？标准 Yang-Mills 理论中写 D_μ = ∂_μ - i g A_μ，其中 g 是耦合常数。量子力学中自然单位下写 D_μ = ∂_μ - (i/ℏ) A_μ。

**暂时不固定 ℏ 的位置。** 写 D_μ = ∂_μ - i κ A_μ，其中 κ 待定。

### 1.4 曲率

F = dA = ½ F_μν dx^μ ∧ dx^ν, F_μν = ∂_μ A_ν - ∂_ν A_μ

曲率编码联络的非平凡 holonomy：
holonomy_γ = exp(i κ ∮_γ A)

## 2. 度量兼容条件 D h = 0

### 2.1 一般形式

对任意两个截面 ψ, φ：
d[h(ψ, φ)] = h(D ψ, φ) + h(ψ, D φ)

这是联络与 Hermitian 度量兼容的定义。

### 2.2 对单截面的约束

取 φ = ψ，且约束 h(ψ, ψ) = |ψ|² = 1（常数）：
d(1) = 0 = h(D ψ, ψ) + h(ψ, D ψ)

展开：
0 = (D_μ ψ)* ψ + ψ* (D_μ ψ)
  = (∂_μ ψ* + i κ A_μ ψ*) ψ + ψ* (∂_μ ψ - i κ A_μ ψ)
  = ψ ∂_μ ψ* + ψ* ∂_μ ψ + i κ A_μ |ψ|² - i κ A_μ |ψ|²
  = ψ ∂_μ ψ* + ψ* ∂_μ ψ
  = ∂_μ |ψ|²

**结论1：** D h = 0 当 |ψ|² = 1 时自动满足。联络项 A_μ 的贡献恰好抵消，不产生额外约束。

**重要：** 这意味着 D h = 0 本身不固定 A_μ 的值。它只保证 U(1) 联络与 Hermitian 度量兼容——即 A_μ 是实值（u(1) 值）。这是任何 U(1) 规范理论的标准结果。

### 2.3 这意味着什么

D h = 0 的作用是**选择**兼容的联络（即 A_μ ∈ ℝ），而不是**决定**联络的具体形式。它保证平行移动保内积：
h(ψ_γ(1), φ_γ(1)) = h(ψ_γ(0), φ_γ(0))

即沿任意曲线平行移动时，内积不变。这是幺正性的几何表达。

## 3. 平行移动 → 演化方程

### 3.1 时间方向的平行移动

沿类时矢量场 ∂_t 的平行移动方程：
D_t ψ = 0

即：
∂_t ψ - i κ A_0 ψ = 0
⟹ ∂_t ψ = i κ A_0 ψ

这是一个一阶微分方程。其解为：
ψ(t) = ψ(0) · exp(i κ ∫_0^t A_0(s) ds)

### 3.2 与 Schrödinger 方程的比较

Schrödinger 方程：
iℏ ∂_t ψ = H ψ
⟹ ∂_t ψ = -(i/ℏ) H ψ

对比 ∂_t ψ = i κ A_0 ψ，我们需要：
i κ A_0 = -(i/ℏ) H
⟹ κ A_0 = -H/ℏ

选择 κ = 1/ℏ 且 A_0 = -H：
D_t = ∂_t - i(-H)/ℏ = ∂_t + i H/ℏ

则 D_t ψ = 0 → ∂_t ψ = -i H/ℏ ψ → iℏ ∂_t ψ = H ψ ✓

**关键观察：** Schrödinger 方程等价于声明"量子态沿时间方向按 U(1) 联络 D_t = ∂_t + i H/ℏ 平行移动"。

### 3.3 联络的物理诠释

A_0 = -H → 时间分量是负的 Hamiltonian。
A_i = P_i → 空间分量是动量算符（生成空间平移）。

合起来：A_μ = (-H, P⃗) = -P_μ，即负的能量-动量四矢量。

曲率 F_μν = ∂_μ A_ν - ∂_ν A_μ 编码了能量的非完整性和动量的旋度。

## 4. 从 |e^(iθ)|² = 1 到联络的确定

### 4.1 回到欧拉公式

令 ψ = e^(iθ)，其中 θ = θ(x) 是时空函数。

|ψ|² = |e^(iθ)|² = 1 自动满足。

D_μ ψ = ∂_μ ψ - i κ A_μ ψ
       = i (∂_μ θ) e^(iθ) - i κ A_μ e^(iθ)
       = i (∂_μ θ - κ A_μ) e^(iθ)

平行移动 D_μ ψ = 0 要求：
∂_μ θ = κ A_μ

### 4.2 物理识别

在量子力学中，波函数的相位是 θ = -S/ℏ（费曼路径积分中 e^(iS/ℏ) = e^(-iθ) 当 θ = -S/ℏ... 实际上仔细看，薛定谔方程解 ψ = e^(-iEt/ℏ)，所以 θ = -Et/ℏ = -S/ℏ）。

∂_μ θ = -∂_μ S / ℏ = κ A_μ

若取 κ = -1/ℏ，则 A_μ = ∂_μ S。

这意味着：**联络 A_μ 是作用量 S 的梯度。** 在经典极限下，p_μ = ∂_μ S，所以 A_μ = p_μ。

曲率 F_μν = ∂_μ A_ν - ∂_ν A_μ = ∂_μ ∂_ν S - ∂_ν ∂_μ S = 0。

**关键结论：** 在平凡丛且波函数为纯相位 e^(iθ) 时，联络是纯规范（曲率为零）。非平凡物理（非零曲率）出现在波函数有振幅调制时。

### 4.3 一般波函数

一般地，ψ = R e^(iθ)，其中 R = |ψ|，θ 为相位。

D_μ ψ = (∂_μ R + i R ∂_μ θ - i κ A_μ R) e^(iθ)

平行移动 D_t ψ = 0 给出两个方程：
实部：∂_t R = -κ A_0 R（振幅演化）... 等等，A_0 是实的，所以实部应该是 ∂_t R = 0？让我仔细算。

D_t ψ = [∂_t R + i R ∂_t θ - i κ A_0 R] e^(iθ) = 0
⟹ ∂_t R + i R(∂_t θ - κ A_0) = 0

实部和虚部分别为零：
∂_t R = 0
∂_t θ = κ A_0

所以纯相位演化（|ψ| = 常数 = R → ∂_t R = 0）是 D_t ψ = 0 的必然结果。

**重要：** D_t ψ = 0（沿时间平行移动）只允许纯相位旋转，不允许振幅变化。这与幺正演化一致。

但 Schrödinger 方程的波函数一般有空间依赖的振幅！所以 D_t ψ = 0 不够——我们需要完整的含空间部分的演化。

## 5. 完整的演化方程

### 5.1 从纤维到全时空

D_t ψ = 0 只描述了沿时间方向的平行移动。完整的量子演化应该在所有时空方向上由联络决定。

**关键推广：** 量子态 ψ 沿其世界线（类时曲线 γ）平行移动：
D_γ̇ ψ = 0

在局部惯性系中 γ̇ = ∂_t，则回到 D_t ψ = 0。

但 ψ 还需要满足空间方向的约束。完整的 covariant 条件是：

γ^μ D_μ ψ = 0  [沿世界线]

其中 γ^μ = dx^μ/dτ。

### 5.2 非相对论极限

在非相对论极限下，γ^μ ≈ (1, v⃗/c)，|v⃗| ≪ c。

D_t ψ + (v⃗/c) · D⃗ ψ ≈ 0

主导项 D_t ψ = 0 给出 iℏ ∂_t ψ = H ψ。

空间部分的 D⃗ ψ 贡献动能的量子算符：
D⃗ = ∇⃗ - (i/ℏ) p⃗

对于自由粒子，p⃗ → -iℏ ∇⃗，则 D⃗ = ∇⃗ + ∇⃗ = 2∇⃗... 这不对。

让我重新来。动量算符 p̂ = -iℏ ∇。联络的空间分量应该是 A_i = p_i（经典动量）。

D_i ψ = ∂_i ψ - (i/ℏ) p_i ψ

对于自由粒子在动量表象中，p_i 是乘性算符。在位置表象中需要更仔细的处理。

### 5.3 回到 Schrödinger 方程的完整推导

我们从作用量出发。自由粒子的作用量：
S = ∫ (p·dx - H dt)
∂_t S = -H,   ∂_i S = p_i

波函数 ψ = e^(iS/ℏ)（费曼路径积分的半经典极限）。

注意：这里的符号约定：标准量子力学中 ψ ~ e^(i(p·x - Et)/ℏ) = e^(iS/ℏ)。

所以：θ = S/ℏ，ψ = e^(iθ)。

D_μ ψ = i (∂_μ θ - κ A_μ) e^(iθ)

选 κ = 1/ℏ，A_μ = (H, -p_i) = (能量，负动量)...

实际上，让我用标准的 +--- 号差。在 Minkowski 时空中：
p_μ = (E/c, p⃗)，p^μ = η^(μν) p_ν = (E/c, -p⃗)
A_μ = (φ/c, A⃗)（电磁4-势）

对于量子力学（不含电磁），我们需要的是"物质波"的联络：
A_μ → p_μ / ℏ = (E/ℏc, p⃗/ℏ)

则：D_μ ψ = ∂_μ ψ - i (p_μ/ℏ) ψ

时间分量：D_t ψ = ∂_t ψ - i (E/ℏc) ψ... 等等，单位不对。

让我简化，使用自然单位 c = 1, ℏ = 1 先推导，最后恢复 ℏ。

使用 c = 1：
D_μ ψ = ∂_μ ψ - i p_μ ψ

时间分量（μ = 0）：D_0 ψ = ∂_t ψ - i E ψ
空间分量（μ = i）：D_i ψ = ∂_i ψ - i p_i ψ

平行移动 D_0 ψ = 0 → ∂_t ψ = i E ψ → -i ∂_t ψ = E ψ

恢复 ℏ：-iℏ ∂_t ψ = E ψ → iℏ ∂_t ψ = -E ψ

而 Hamiltonian H = E（对自由粒子 H = p²/2m + V），所以：
iℏ ∂_t ψ = H ψ ✓

现在空间部分：D_i ψ = 0 → ∂_i ψ = i p_i ψ → -i ∂_i ψ = p_i ψ

这正是动量算符的本征方程！p̂_i ψ = -iℏ ∂_i ψ = p_i ψ。

### 5.4 联络与算符的对应

完整的联络 D_μ = ∂_μ - (i/ℏ) p_μ 中：
- p_0 = -H（能量-动量四矢量的时间分量，在 +--- 号差下 p_0 = -E/c）
  ... 实际上在 η = diag(-1,1,1,1) 下，p_0 = -E（c=1）
  
  那么 D_0 = ∂_0 - (i/ℏ)(-H) = ∂_t + (i/ℏ) H
  D_0 ψ = 0 → ∂_t ψ = -(i/ℏ) H ψ → iℏ ∂_t ψ = H ψ ✓

- p_i = 经典动量
  D_i = ∂_i - (i/ℏ) p_i
  D_i ψ = 0 → ∂_i ψ = (i/ℏ) p_i ψ → -iℏ ∂_i ψ = p_i ψ ✓

**结论2：** 平行移动方程 D_μ ψ = 0 同时给出了：
- 时间方向：Schrödinger 方程
- 空间方向：动量本征方程

两者都是同一个几何条件（沿世界线的平行移动）的不同分量。

## 6. |e^(iθ)|² = 1 的深层作用

### 6.1 它不是什么

|e^(iθ)|² = 1 本身不"推导" Schrödinger 方程。它是幺正性的表达——一个约束，而非动力学。

### 6.2 它是什么

|e^(iθ)|² = 1 做了三件事：

**(a) 选择了几何对象。** 
它声明物理态在 U(1) 丛的单位圆上。这使复线丛成为自然的几何框架。

**(b) 约束了联络类型。**
D h = 0 要求联络与 Hermitian 度量兼容 → A_μ 是实值1-形式（u(1) 值）。这排除了非幺正演化。

**(c) 固定了平行移动的几何意义。**
在 U(1) 丛上，平行移动 = 相位旋转。沿闭合路径的 holonomy = 几何相位（Berry 相位 / Aharonov-Bohm 相位 / 动力学相位）。

### 6.3 动力学从哪来

动力学的具体形式（即 A_μ 的取值）来自：
1. **对称性：** 时间平移不变性 → A_0 与 Hamiltonian 的关系
2. **对应原理：** ℏ→0 极限 → 经典 Hamilton-Jacobi 方程
3. **路径积分：** Holonomy = e^(iS/ℏ) → A_μ = ∂_μ S / ℏ（半经典）

所以完整的逻辑链是：
|e^(iθ)|² = 1 → U(1) 丛框架 → 幺正联络 D → 平行移动方程 Dψ = 0
    ↓
对称性 + 对应原理 + 路径积分
    ↓
A_μ 的物理识别（能量-动量）
    ↓
Schrödinger 方程 + 动量本征方程

## 7. 诚实边界

**这部分是推导而非定义：**
- 平行移动 D_μ ψ = 0 → Schrödinger 方程（步骤5.3-5.4）是直接的数学蕴含，只需识别 p_0 = -H。

**这部分是物理输入而非几何必然：**
- A_μ = p_μ/ℏ（联络 = 能量-动量/ℏ）是物理识别，来自对应原理和路径积分，不能纯粹从 |e^(iθ)|² = 1 推导。

**这部分尚未解决：**
- 弯曲时空中 D_μ ψ = 0 如何修改（S2 的任务）
- Wick 转动如何精确地使 SO(1,3) 和 U(1) 统一（S3 的任务）

## 8. 第一轮核心结论

1. **|e^(iθ)|² = 1 本身不产生动力学，它产生几何框架。** 它选择 U(1) 复线丛并约束联络为幺正。

2. **Schrödinger 方程 = 沿时间方向的平行移动。** D_0 ψ = 0 ⇔ iℏ ∂_t ψ = H ψ。这不是巧合——Schrödinger 方程就是时间平移生成元在 U(1) 丛上的联络分量。

3. **动量本征方程 = 沿空间方向的平行移动。** D_i ψ = 0 ⇔ -iℏ ∂_i ψ = p_i ψ。同一个几何条件的不同分量。

4. **完整理论只需要一个方程：** 四维联络的平行移动 D_μ ψ = 0。Schrödinger 方程和动量本征方程是这个方程在时间/空间方向上的投影。

5. **欧拉公式的角色：** e^(iθ) 是 U(1) 群元素的参数化。|e^(iθ)|² = 1 是群流形上的约束。整个量子力学的幺正演化就是这个约束 + 联络的几何后果。
