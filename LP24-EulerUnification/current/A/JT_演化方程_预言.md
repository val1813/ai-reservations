# Ĵ(t) 演化方程与可检验预言 | 黑洞蒸发

> 目标：写出 Ĵ(t) 的具体演化方程，导出与标准 Hawking 辐射不同的数值预言。

---

## 1. Ĵ 在视界处的精确定义

### 1.1 设置

Schwarzschild 黑洞，初始质量 M₀。Hawking 蒸发，质量 M(t) 随时间减小。

**量子侧：** Hawking 辐射中的 Im(C₁₂) 流出速率。
每个辐射量子以纠缠对的形式产生：一个粒子逃逸到无穷远（out），一个粒子落入视界（in）。逃逸粒子携带的 Im(C₁₂) 信息 = 它与落入粒子的纠缠。

**几何侧：** 视界面积的几何信息编码能力。
Bekenstein-Hawking 熵 S_BH(t) = A(t)/(4ℓ_Planck²) = 4πGM(t)²/(ℏc/G)。

### 1.2 Ĵ 的显式形式

```
Ĵ(t) = dI_out/dt + dI_geo/dt
```

其中：
- I_out = 逃逸辐射中携带的 Im(C₁₂) 总量（量子侧虚部流出）
- I_geo = 视界面积编码的信息容量（几何侧虚部接收）

**Ĵ = 0 ⇔ dI_out/dt = -dI_geo/dt**

## 2. 标准 Hawking 辐射中的 Ĵ(t)

### 2.1 纯热辐射

如果 Hawking 辐射是精确热谱：
- 辐射密度矩阵 ρ_rad 在能量本征基下是对角的
- 所有非对角元为零 → Im(C₁₂) = 0
- dI_out/dt = 0（热辐射不携带 Im(C₁₂) 信息）

但视界面积在减小：
- dI_geo/dt = dS_BH/dt = -(8πGk_B M/ℏc) · |dM/dt| / k_B ≠ 0

**在纯热辐射中：Ĵ(t) = 0 + (非零) ≠ 0**

Ĵ ≠ 0 → 断裂存在 → 信息在视界处真正丢失。

### 2.2 Page 曲线中的 Ĵ(t)

Page (1993) 提出黑洞蒸发分为两个阶段：

**阶段 I（t < t_Page）：** 辐射携带极少的 Im(C₁₂)（约 exp(-S_BH/2)），近似热谱。
**阶段 II（t > t_Page）：** 辐射开始释放之前积累的 Im(C₁₂)，信息开始恢复。

在 Ĵ 框架中，Page 曲线对应：
- 阶段 I：Ĵ ≈ dI_geo/dt ≠ 0（Im(C₁₂) 在视界处积累，未流出）
- 阶段 II：Ĵ → 0（积累的 Im(C₁₂) 开始通过辐射释放）

## 3. Ĵ = 0 的演化方程

### 3.1 约束条件

Ĵ = 0 → dI_out/dt = -dI_geo/dt 在任何时刻 t 成立。

dI_geo/dt = dS_BH/dt = (1/T_H) · dM/dt（黑洞热力学第一定律的熵形式）

其中 T_H(t) = ℏc³/(8πGM(t)k_B)，dM/dt = -α/M(t)²（α 是包含 greybody 因子的辐射效率参数）。

```
dI_geo/dt = -(8πGk_B/ℏc) · M(t) · (α/M(t)²)
          = -(8πGk_Bα/ℏc) · 1/M(t)
```

### 3.2 Ĵ = 0 对辐射的约束

Ĵ = 0 要求：
```
dI_out/dt = (8πGk_Bα/ℏc) · 1/M(t)
```

即：**逃逸辐射中 Im(C₁₂) 的流出速率必须等于 8πGk_Bα/(ℏcM(t))。**

### 3.3 辐射谱的修正

纯热辐射（dI_out/dt = 0）不满足这个约束。

最小修正：在热辐射的每个频率模式上，添加一个 Im(C₁₂) 分量，使得总流出速率满足约束。

对于频率为 ω 的模式，热辐射的平均光子数为：
```
n̄(ω, t) = 1 / (exp(ℏω/k_B T_H(t)) - 1)
```

Im(C₁₂) 最低阶修正来自相邻频率模式之间的相干（ω 和 ω + Δω）。模式间的纠缠产生非对角密度矩阵元。

约束 Ĵ = 0 要求每个模式对的 Im(C₁₂) 不为零，其大小满足：
```
Σ_{ω, ω'} Im(ρω,ω') = (8πGk_Bα/ℏc) · 1/M(t) · Δt
```

在连续极限下：
```
∫ dω dω' Im(ρ(ω, ω')) = (8πGk_Bα/ℏc) · 1/M(t)
```

## 4. 可检验预言

### 4.1 预言1：Hawking 辐射的最小非热性

Ĵ = 0 要求 Hawking 辐射**不能**是精确热谱——它必须包含至少 (8πGk_Bα/ℏcM(t)) 的 Im(C₁₂) 通量。

**定量预言：** 辐射密度矩阵在频率空间的非对角元必须满足：
```
|ρ(ω, ω+Δω)| ≥ (8πGα/ℏc²M(t)) · (Δω/ω²) · f(ω/T_H)
```
其中 f(x) 是量级为 1 的普适函数，由 Ĵ = 0 约束确定。

**可检验性：** 这个预言在真实天体物理黑洞上无法检验（效应太小）。但在**类比引力系统**中，G 被 G_analog ≫ G 替代，效应被放大 ~10²⁰ 倍。

### 4.2 预言2：Page 时间的修正

标准 Page 时间：t_Page ≈ (G²M₀³)/(ℏc⁴)（量级估计）

在 Ĵ = 0 约束下，Im(C₁₂) 的积累-释放转换不是突然的。转变发生在：
```
t_transition = t_Page · (1 - δ)
```
其中 δ ≈ (ℓ_Planck/λ_thermal)²（辐射热波长与 Planck 尺度的比值平方）

**定量：** 对于 M₀ = 1 M_⊙，δ ≈ 10⁻⁷⁶（不可观测）。对于 Planck 质量黑洞（M₀ ≈ 10⁻⁸ kg），δ ≈ 10⁻²（可能在类比系统中可测）。

### 4.3 预言3：类比 BEC 黑洞中 Ĵ = 0 的具体信号

这是目前最可行的检验。

在 BEC 类比黑洞中（Steinhauer 2016 型实验）：
- 类比 Hawking 温度 T_analog ≈ 1 nK
- 类比 Planck 尺度 ℓ_analog ≈ ξ（healing length ≈ 0.5 μm）
- G_analog ≈ ℏ/(2m n₀ ξ) ≫ G_real

Ĵ = 0 预言：类比 Hawking 辐射中，频率 ω 和 ω+Δω 模式之间的互关联（cross-correlation）函数必须满足：

```
⟨a†(ω) a(ω+Δω)⟩ = n̄(ω) δ(Δω) + C_J(ω, Δω)
```

其中 C_J(ω, Δω) 是 Ĵ = 0 强制要求的非对角修正项，形式为：
```
C_J(ω, Δω) = (8πG_analog k_B α/ℏc) · (1/M_analog(t)) · F(ω/ω_max, Δω/ω)
```

M_analog(t) 是类比黑洞的"质量"（由 BEC 密度和流速决定），F 是形状函数。

**关键：** C_J ≠ 0 意味着不同频率的辐射模式之间存在相位相干——这在标准类比 Hawking 辐射的预测中为零（热辐射的不同频率模式是独立的）。

**实验信号：** 测量辐射的密度-密度关联函数 ⟨δn(ω) δn(ω+Δω)⟩。如果 C_J ≠ 0，则在 ω ≠ ω' 处应出现非零的交叉关联峰。标准热辐射预测此峰值为零。

## 5. Ĵ(t) 演化方程（最终形式）

```
Ĵ(t) = d/dt [∫₀^t dt' ∫ dω dω' Im(ρ_rad(ω,ω';t'))] + dS_BH/dt

Ĵ = 0 ⇒ ∫ dω dω' Im(ρ_rad(ω,ω';t)) = -dS_BH/dt
                                   = (8πGk_Bα/ℏc) · 1/M(t)
```

简化形式（用黑洞质量参数化）：
```
Ĵ(M) = dI_out/dM · dM/dt + dS_BH/dM · dM/dt
     = (dI_out/dM + dS_BH/dM) · (-α/M²)

Ĵ = 0 ⇒ dI_out/dM = -dS_BH/dM = 8πGk_B/ℏc · M
```

积分：
```
I_out(M) = ∫_M^{M₀} (8πGk_B/ℏc) · M' dM'
         = (4πGk_B/ℏc) · (M₀² - M²)
```

**这是 Ĵ = 0 的核心预言：当黑洞质量从 M₀ 蒸发到 M 时，逃逸辐射必须携带精确地 I_out(M) = (4πGk_B/ℏc)(M₀² - M²) 的 Im(C₁₂) 信息。**

对比标准 Hawking 辐射：
- 阶段 I（t < t_Page）：标准辐射 I_out ≈ 0（热辐射）；Ĵ = 0 要求 I_out > 0
- 阶段 II（t > t_Page）：标准辐射 I_out 逐渐增长到 ≈ S_BH(0)；Ĵ = 0 要求提前开始

## 6. 诚实边界

**已完成的：**
- Ĵ(t) 的显式演化方程

**突破与否的判断标准：**
如果有人在类比 BEC 实验中测量了 C_J(ω, Δω)，发现了非零的交叉关联峰，且峰值符合 Ĵ = 0 的预言——这就是突破。在那之前，Ĵ = 0 是一个"清晰的、非平凡的、可被否定的命题"，但这篇论文还没有被实验写出来。
