## §0.5 前置三问（已联网搜索）

> ⚠️ S1/S2教训：同长命题已两次重复造轮子；2D Clifford MIPT是成熟课题。先查再推。

**Q1. 核心前提？有无否定文献？**
核心前提="2D存在 p_c>0 + 确定指数 + 三序参量共享"。
- 存在性前提**已被强力证实**，无否定文献：2007.02970 (Turkeshi-Fazio-Dalmonte, PRB 102 014315, 2020, **含勘误**) 在(2+1)D Clifford给出确定 p_c 与 ν（见Q2）。2210.11957 ((d+1)D stabilizer, d=1,2,3) 进一步把 d=2,3 都做了。**命题B（无干净MIPT/被掩盖）没有文献支持**——L=48至512的有限尺度标度排除了 p_c→0。
- **唯一活跃的否定向文献是关于"类身份"而非"存在性"**：2502.13211 (2025, "Unveiling a Hidden Percolation Transition in Monitored Clifford Circuits") 用ZX-calculus主张Clifford MPT"本质是伪装的经典渗流"，**直接顶撞**2007.02970的"与3D渗流不相容"。这是必须裁决的真冲突（见§末）。

**Q2. 有无先发已做 p_c^{2D} + 临界指数？（"2D MIPT critical exponent","2+1d measurement transition"）**
**有，决定性地有。此题"存在性+指数"已发表，低新颖度。**
- **2007.02970 (PRB 102 014315 + Erratum)**：(2+1)D Clifford混合电路。**勘误后定值**（原文用ℝ上SVD算rank错误，勘误改用𝔽₂上Gauss消元）：
  - rank-1测量：**p_c=0.54(1), ν=0.67(1)**
  - rank-2测量：**p_c=0.84(1), ν=0.68(1)**
  - 两个ν互相一致(~2%)→单一普适类；与**3D渗流 ν_perc=0.87(1)**相比**差约30%**→**明确属不同普适类**。还报告临界点对面积律有**乘性对数修正**。
- **2012.03857 (PRB 104 155111, 2021)**：2D Clifford的**体指数**与渗流匹配，但**纠缠团簇/表面指数**大幅偏离表面渗流→"任何到渗流的几何映射破缺"。即"体像渗流、表面不像"。
- **2210.11957**：(d+1)D稳定子，d=1,2,3，称转变共形且"接近但不同于"(d+1)维渗流。
- **2110.02988**：严格证明Clifford monitored电路**仅在 d→∞（大局域Hilbert空间）极限**才是渗流；有限qubit (d=2) 不是渗流。
- 1D锚点：1+1D Clifford ν≈1.3，体指数接近2D渗流 4/3≈1.333 但有表面差异。
- 3D渗流锚点：ν=0.8764(12)（1302.0421，1/ν=1.1410(15)反推）；p_c(bond)=0.24881, p_c(site)=0.31161。
**结论：造轮子风险极高。存在性与指数是2020-2021已结案的成熟结果。B的增量必须落在"类身份机制"与"三序参量裁决"，不在"再算一遍p_c"。**

**Q3. A最可能哪步叙事退让？**
A用"(2+1)D=3D渗流映射"同时论**存在性**与**普适类**。最可能的退让/裂缝：A会**默认渗流映射既给存在又给类**，但文献铁证 ν=0.67≠0.876。A极可能在"映射到3D stat-mech模型（保证存在）"与"映射到3D**渗流**（错误的类）"之间**滑动叙事**——用渗流的直觉立存在性，却回避自己的ν与渗流矛盾。第二处退让：判三序参量"同构(S1 K1.0)"会把"共享p_c/ν"**夸大**为"同构（所有指数相同）"，并默认无噪声结论可延拓到有噪声。

## §2 苏格拉底问题（挑战A，前三⭐见§末汇合）

1. ⭐ **存在性与类身份的解耦**：A用"(2+1)D=3D渗流"既论存在又定类。但若是3D渗流，ν应=0.876；文献铁证ν=0.67(1)（差30%）。A的存在性论证究竟依赖"映射到**某个**有限温有序3D stat-mech模型（Q→1 replica磁体，足以保证 p_c>0）"还是依赖"映射到**渗流**（已被数值排除的类）"？若是后者，存在性论证建立在错误的类上。请A把"存在性所需的映射强度"与"类身份所需的映射强度"分开陈述。
2. ⭐ **"同构"的越界**：A判三序参量"同构(S1 K1.0)"。同一CFT中算符纠缠、态纠缠熵、相干信息是**不同的primary算符**（不同replica边界条件），共享ξ→共享ν与p_c，但**β/标度维一般不同**。A的"同构"是指"共享临界点"还是"全部指数相同"？后者有反例吗？
3. ⭐ **命题B的非数值排除**：A如何在不依赖有限尺度数值（即使L=512也无法严格排除带对数修正的p_c→0）的前提下，给出 p_c>0 的**刚性下界**？A是否援引QEC阈值定理？若纯靠数值，B可代命题B反击"有限尺寸赝标度"。
4. **隐藏渗流冲突**：2502.13211(2025,ZX-calculus)主张Clifford MPT"是伪装的经典渗流"，与A引用的2007.02970"不相容于3D渗流"正面冲突。A如何裁决？（B假说：前者是特殊门集/measurement-only的可解子类→精确渗流；后者是generic随机Clifford→近渗流但不同CFT。）
5. **维度趋势的一致性**：1D ν≈1.3、2D ν≈0.67、3D ν更小（2210.11957）。这条单调下降趋势若外推到 d→∞ 应趋于mean-field。A的渗流图像能否解释**ν随d单调下降且不收敛到任一维度的渗流值**？
6. **乘性对数修正**：2007.02970报告临界点面积律有乘性log修正。A的stat-mech映射是否预言此log？它是上临界维 d_c 的信号还是边界CFT效应？
7. **噪声脆弱性（接S2）**：A的三序参量"共享"是在无噪声下。S2交付的K-C4 conflict（2512.18783主张coding与entanglement共享）——A是否承认该共享在加噪声后破缺（编码阈值≠纠缠阈值，Nishimori线）？若承认，则"共享"是无噪声极限的偶然，不应作为普遍结论上交LP-8综合。

## §N 独立推导

### N1. 存在性：QEC阈值定理给维度无关下界（核心独立论证）

- **描述**：证明 2D 体积律相是稳定的、p_c^{2D}>0 不被有限尺寸掩盖。
- **框架工具**：编码论 / 量子纠错阈值定理（**非**stat-mech、**非**数值）。
- **依据/推导**：
  1. monitored circuit 在固定测量记录下是一个量子信道 𝓔_p；体积律相中，初态信息被编码进系统、与参考比特R纠缠，相干信息 I_c(R⟩Q)=S(Q)−S(RQ)>0（可解码）。
  2. 体积律相 = 有限码率 k/N>0、码距 d_code 随系统线性尺度发散的量子纠错码（随机稳定子码）。在2D，纠缠面是1维（周长~L），码距随 L 增长。
  3. 有限密度 p 的投影测量 = 有限率擦除/退相干噪声作用在该码上。
  4. **阈值定理**（Aharonov-Ben-Or / Gottesman；对随机码即percolation-of-errors下界）：存在 p_c>0 使 p<p_c 时逻辑信息以指数小失败率被保护、I_c 保持 extensive；p>p_c 时码距不足，信息丢失。该阈值是**维度无关的存在性陈述**（任意 d≥1 局域码都有正阈值）。
  5. **维度单调**：2D每点配位数与纠缠面 (~L^{d-1}=L) 都大于1D (~L^0)，冗余更高→可纠正更高擦除率→**p_c^{2D}>p_c^{1D}**。文献 0.54≫0.16 定量吻合。
- **最易错处**：阈值定理严格保证的是**编码/纯化**转变 p_c^{code}>0，**未必**自动等于**纠缠**(体积↔面积)转变 p_c^{ent}。在Clifford/stabilizer里两者重合（N3论证），但若generic情形分离，本论证只锁住编码转变的存在。故存在性结论的**最稳健形式**是："2D存在 p_c^{code}>0 的可解码相变"，纠缠转变的重合需N3补强。**不可**把阈值定理直接当成纠缠转变的证明——这是最常见越界。

### N2. 普适类：3D渗流基准的bootstrap式证伪 + Rényi扇区分离

- **描述**：独立判定2D MIPT是否=3D渗流，并解释"体像渗流、表面不像"。
- **框架工具**：3D渗流外部基准(ν=0.8764(12)) + 共形bootstrap刚性 + replica扇区分析。
- **依据/推导**：
  1. **证伪检验**：若同类，von Neumann ν必=0.876。文献 ν=0.67(1)，偏离30%，远超误差棒。bootstrap角度：3D渗流(Q→1 Potts连通性)的标度维谱已被bootstrap/MC精确钉死；ν=0.67对应的算符谱与之不兼容→**证伪"=3D渗流"**。
  2. **机制（B独有，调和两派）**：渗流描述的是**几何连通性**=**零Rényi熵 S_0=log(最小割)**扇区（Q→1 Potts）。冯诺依曼熵 S_1 是 replica指标 **n→1** 的极限，对应**不同的**不动点（replica对称磁体的n→1，非Q→1 Potts）。
     - 1D：n→1 与 Q→1 两不动点**偶然近简并**（ν_S1≈1.3 ≈ ν_perc=4/3≈1.333），故"1D体像渗流"。
     - 高维(2D,3D)：简并**解除**，S_1的真ν≈0.67 远离 S_0/渗流的0.876。
  3. **直接调和文献冲突**：2502.13211"隐藏渗流"(ZX网络的最小割/连通结构)= **S_0扇区**；2007.02970"不同ν"= **S_1扇区**。**两者不矛盾，描述不同Rényi n。** 2012.03857"体(指数)像渗流、团簇/表面指数偏离"= 体最小割(S_0)像渗流、von Neumann标度(S_1)不像，同一图像。
  4. **mean-field上界**：2110.02988证Clifford→渗流仅在 d→∞；有限qubit偏离。ν(d)单调下降(1.3→0.67→更小)正是从1D强涨落流向高维、但每个有限d都**不**落在该维渗流值上的表现。
- **最易错处**：(a) 不可把"体指数接近渗流"误读为"普适类是渗流"——体ν与团簇/表面指数是**不同**算符，必须分扇区。(b) ν≈0.67 数值上接近3D XY (ν=0.6717)，**切勿**因此误判为O(2)类——MIPT是非幺正replica n→1不动点，与幺正O(2) CFT无关，数值巧合不是类身份。(c) bootstrap对**非幺正**CFT(replica极限)约束弱，证伪"=渗流"稳健，但"它到底是哪个CFT"bootstrap尚不能正面钉死——只能说"非渗流"，不能说"已知某CFT"。

### N3. 三序参量：信道-Choi态replica判据

- **描述**：无噪声2D下，算符纠缠、态纠缠熵、相干信息是否探测同一临界点。
- **框架工具**：信道→Choi态映射 + 同一replica配分函数不同边界条件。
- **依据/推导**：
  1. 三者都是**同一** monitored channel 𝓔_p 的泛函：
     - 态纠缠熵 = 输出态在区域A的熵（replica：环面边界条件下的twist算符）。
     - 算符纠缠 = 信道的**Choi态**的纠缠熵（把信道当态，输入-输出双拷贝）。
     - 相干信息 = 参考比特R与系统的I_c（replica：R-Q边界条件）。
  2. 三者在replica语言中是**同一体不动点**上的不同**边界条件/twist算符**。体关联长度ξ(p)由体不动点单一决定→**三者共享同一 ξ发散、同一 p_c、同一 ν**。
  3. **无噪声关键**：无噪声时演化是unital/可逆+投影，Choi态与物理态的体临界由同一磁体控制→共享成立。这与2512.18783(coding与entanglement共享)、2601.14185(localizable entanglement与S_E、并发度同一p_c≈0.16, ν=1.31, 1+1D)的实证一致。
  4. **"共享≠同构"**：共享的是体ξ→ν与p_c。但三个是不同twist/边界算符→**算符标度维(β-like)一般不同**。"同构(S1 K1.0)"若指全部指数相同，证据不足。
- **最易错处**：(a) **无噪声**是硬前提。加噪声→物理态变混态，相干信息阈值移到**Nishimori线**，与纠缠阈值**分离**（编码转变≠纠缠转变）。把无噪声"共享"延拓到有噪声是S2级错误。(b) 算符纠缠的Choi态在测量-only或强测量下可能由不同子领头项主导，需确认其领头奇异性确由同一体不动点而非边界效应给出。
