## 五条拒稿理由 + severity

**R1（severity: 致命/fatal）— C1 存在性 100% 先发，零新颖度。**
2007.02970 + 2210.11957 + 2012.03857 已完整确立。作为"结论"上交即造轮子。Nature Physics 不接受复述他人 2020 年已发表的存在性。

**R2（severity: 高）— C2"干净增量"声张坍塌。**
三序参量共享 p_c/ν 是标准 BCC stat-mech 推论(Jian-You-Vasseur-Ludwig)+Gullans-Huse 纯化=纠缠图景；2D 的 coding=entanglement 重合已由 **2308.13384** 先发。C2 既无新机制也无新 2D 实证，且作证的 2512.18783 系误引(噪声框架、非该三序参量、非无噪声)。这是被审材料自我标定的"唯一干净增量"，而它不成立——直接动摇全文存在价值。

**R3（severity: 高）— 普适类无任何解决，仅复述已知冲突。**
0.38/0.67/0.83/0.88/0.90 的协议依赖谱(2107.03393/2407.18340/2007.02970/2210.11957)是领域**已知**的活跃争论。被审材料不提供新数值(自承 L≫48 算力缺失)、不提供新判据，仅"登记"冲突。复述未决问题不是贡献。

**R4（severity: 中）— B 的"QEC 阈值定理刚性下界"过度声张。**
B 称用阈值定理给 p_c>0 的"维度无关刚性下界"以免疫有限尺寸反击。实则这是**物理层面论证**而非对该随机 Clifford 系综的严格定理(无显式常数、无对随机稳定子码+有限率测量=擦除的严格映射)；且 B 自承它只锁住 coding 转变、不锁纠缠转变。把物理论证表述为"rigid bound"是方法学越界。

**R5（severity: 中）— 唯一潜在新意(B 的 Rényi 扇区分离机制)是未验证假说。**
B 用 "S_0 最小割扇区像渗流 / S_1 冯诺依曼扇区独立 CFT" 调和 2502.13211(隐藏渗流) vs 2007.02970(不同 ν)。这是全文唯一可能的概念贡献，但**纯假说、无数值支撑**(知识库标 🔶 待验证)。作为发表主张证据不足；恶意审稿：要么补 L≫48 数值证实扇区分离，要么删。

## 建议：拒稿（Reject）

- **降为大修(Major)的唯一路径**：(i) 彻底撤回 C1、C2 作为增量主张，全文重定位为"文献冲突裁决 note + 防造轮子记录"；(ii) 实际执行 L≫48、多协议/多对称性统一 ν 测量以判 0.38–0.90 谱是有限尺寸假象还是真协议依赖，并数值检验 R5 的 Rényi 扇区分离。

## ④ 结案类型是否成立？是否误判？

被审材料的结案类型自述 = "存在性重复造轮子 + 三序参量共享真增量 + 普适类待数值"。

**裁定：结案类型部分误判，须修正后方成立。**
- "存在性=重复造轮子" → ✅ 正确，已诚实降为引用基线。
- "三序参量共享=真增量" → ❌ **误判**。如 REVIEWER R2/C2 裁定，被 2308.13384+标准 stat-mech 先发，且作证 2512.18783 误引。这是结案类型中唯一的硬伤。
