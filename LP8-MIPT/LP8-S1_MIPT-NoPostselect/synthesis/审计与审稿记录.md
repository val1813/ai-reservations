## 五条拒稿理由

### 1. 核心假设的最简反例（具体可计算）—— C1 编码可恢复性 ⇎ 纠缠相变同点

C1 宣称"编码论可恢复性充要条件 + 随机码重量枚举"可独立给出与纠缠相变同一的 p_c≈0.159。最简反例：随机稳定子码的**可恢复性阈值由量子哈希界/容量给出**（对 depolarizing-like 噪声，可纠错率 R=1−2H(p) 由香农熵决定，阈值落在 p\*≈0.11 量级），而 1+1D MIPT 的纠缠相变 p_c≈0.16 由 Potts/渗流型自由度的临界点给出——**二者是不同泛函的零点，数值上无理由相等**。即"recoverability threshold = entanglement transition point"在一般噪声模型下可显式算出反例（哈希界阈值 ≠ 渗流阈值 ≠ 0.159）。除非作者证明所用映射恰好把容量阈值规范化到纠缠 p_c，否则 C1 的"独立重证给出同一数"是巧合或循环。**[严重]**
作者需证明：在其特定测量—编码字典下，随机码重量枚举给出的可恢复性阈值**恒等于**纠缠相变 p_c（含误差棒重叠的显式数值），而非仅"同为一个相变"的定性陈述。

### 2. 推导链最薄弱一步 —— "不靠 GH" 的 JYVL 路线实为循环 + Rényi-2→n→1 跃迁

C1 称用 JYVL（Jian–You–Vasseur–Ludwig）畴壁自由能映射"独立"于 Gullans-Huse。但 **JYVL 统计力学映射本身建立在 replica/Potts 框架之上，其 n→1 极限的纯化—纠缠对偶正是 GH 同期建立并相互印证的结构**——用 JYVL 证 purification=entanglement，等于换符号重述 GH 的同一前提，非独立。更致命的薄弱步：随机码重量枚举的"集中"只能控住 **二阶矩（Rényi-2 / 平均纯度）**，而 learnability/informational power 是 **n→1（von Neumann）量**；从 Rényi-2 集中跳到 n→1 忠实，缺少对 replica 解析延拓的控制（2307.15011 自身也只算到 Rényi-2 版本互信息，对 n→1 是 conjecture）。**这一跃迁未被证明，是全链最可疑处。[致命]**
作者需证明：(i) JYVL 路线不预设 GH 已建立的 n→1 对偶（给出不依赖该对偶的独立输入）；(ii) Rényi-2 集中如何严格延拓到 n→1，或承认 C1/C2 仅在 Rényi-2 层成立而非 von Neumann learnability。

### 3. 与已有文献的冲突 —— C2/C3 已被 2307.15011 与 2504.08888 发表

C2（learnability=entanglement 同 p_c）与 C3（结构化情形分离：U(1) sharpening、贝叶斯次优、弱测、反馈）与现有文献**正面重叠而非冲突，构成新颖性致命冲突**：2307.15011 已陈述 informational power 转变"in correspondence with the MIPT"且"transitions coincide"，并已在第 VII 节把 U(1) learnability 归于 charge-sharpening（即 C3 的 U(1) 项）；2504.08888 已证 sharpening 与 learnability 在 Bayes 最优处重合、Bayes 非最优处分离（即 C3 的"贝叶斯次优解码器依赖"项）。适用条件核查：两文均覆盖"无对称 Clifford/Haar、n→1/解码框架"，**条件完全适用，不可降级**。本课题在 C2/C3 上无超出二者的物理增量。**[致命]**
作者需证明：C2/C3 中存在 2307.15011 与 2504.08888 均未给出的**具体新结论**（新的临界点、新的指数、新的分离机制），而非同一结论的换语言复述。

### 4. 数值合理性质疑 —— p_c≈0.159、ν≈1.28 的精度被夸大

独立量级核对：1+1D MIPT 的公认值为 Haar p_c=0.17(1)（Zabalo/Gullans 等），Clifford brick-wall 约 p_c≈0.16，ν≈1.3(2)；且**该相变非渗流类**（渗流 ν=4/3≈1.333 仅在 d→∞ 局域维极限成立），故 ν≈1.28 与 4/3 有别本身合理。问题在于：公开误差棒为 p_c=0.16(1)、ν=1.3(2)，**第三位有效数字（0.159、1.28）超出现有数值确定度**，把约定相关（测量约定、brick-wall 相位）的量报到三位是过度精确。若 C2 进一步主张 learnability 与 entanglement **共享同一 ν**，需注意二者是同一临界点上的**不同观测量**，样本复杂度发散指数未必等于纠缠关联长度指数。**[轻微]**（若 C2 强主张共享 ν 则升至中等）
作者需证明：所报 p_c/ν 的误差棒，以及 learnability 序参量的发散指数确与纠缠 ν 相同（而非仅同 p_c）。

### 5. 最近似的已有工作（逐句比较）—— 2307.15011 + 2504.08888，新颖性边际

最近邻工作为 **2307.15011**。逐句比较：

差异仅为：本课题(a)用 JYVL+编码语言重证（方法替换，见第2条已质疑其独立性）；(b)对 Wang 2502.13408 弛豫判据作淬火/退火澄清（C4）；(c)提出"重合判据"元框架（C5，为前两文之整合）。其中**唯一相对实在的增量是 C4 的批判性细读**——指出弛豫主序参量是淬火型 S_{L/2}(t)、"无后选择"仅源自 Clifford 经典可模拟（与 2502.13408 摘要"eliminate it completely with trackable classical simulation"一致）。但需注意 C4 内部张力：摘要明言"消除"来自经典可模拟，而 C4 称"需 cross-correlation 才消除"，二者归因不一致，C4 自身需自洽。综合：物理新颖性边际，属评论/综合而非原创发现。**[严重]**
作者需证明：相对 2307.15011 与 2504.08888，本课题给出**至少一个可被实验或数值证伪的新预言**；并消除 C4 中"消除后选择=经典可模拟"与"=cross-correlation"的归因矛盾。
