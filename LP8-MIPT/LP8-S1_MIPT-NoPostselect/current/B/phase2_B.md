### N1. 监测电路 = 随机码，可恢复性的组合充要条件（地基，非进口相变）

**描述：** t步、L qubit、测量率p的无对称随机Clifford/Haar监测电路，等价于把 k 个逻辑qubit（参考R，k可取1或∝L）编码进物理qubit的**随机stabilizer码**（Clifford情形精确；Haar情形取其stabilizer骨架/二阶矩等价）。测量集 ℳ = 这一轨迹实际测掉的Pauli群。

**工具：** 2402.00145 Thm 2 的可恢复性充要条件（**纯线性代数/stabilizer事实，不含相变断言**）：逻辑信息k全保留 ⟺ `ℳ∩ℒ⊆𝒮`（被测群不含非平凡逻辑算符），等价 Choi态 `I(A:R)=2k`。

**依据（不跳步）：**
1. Choi态把码映射 ↔ 一个纯态 |Ω⟩_{A,R}，A=物理输出，R=参考。测量ℳ作用后，R保留的互信息 I(A:R) 精确等于"未被测掉的逻辑维数"×2。这是**stabilizer群的交集计数**，可手算，无需任何动力学假设。
2. 故"R是否可恢复"被还原为一个**组合问题**：随机演化生成的逻辑算符群 ℒ_t，与随机测量集 ℳ 的交，是否落在 stabilizer 𝒮 内。
3. 这一步**完全没有用Gullans-Huse**：我没说"纯化相变=纠缠相变"，我只说"可恢复性=逻辑算符是否被测群覆盖"，这是定义级的代数恒等。

**最可能出错处：** Haar（非Clifford）情形无精确stabilizer描述。处理：用二阶矩（purity/第二Rényi）的统计力学骨架——但这会滑向A的领域。B的纪律：**只对Clifford做精确组合论证，对Haar只声明"重量枚举集中同样成立（典型逻辑算符重量∝L）"并标为外推，不写Haar的replica配分函数。** 这是B推导的诚实边界。

### N2. 码距谱：定义台阶 vs 渐变判据

**描述：** 定义随机监测码在时刻t、测量率p下的**码距谱** d_r(p)：保护 r 个逻辑qubit（rank-r逻辑子空间）所需的最小测量"距离"，等价地，**典型逻辑算符重量分布** P_t(w) = 演化生成的逻辑算符中重量为w者的占比。可恢复性由"测量集ℳ是否击中某个逻辑算符"决定，而击中概率随逻辑算符重量w单调（重量越大越易被随机单qubit测量击中）。

**工具：** 重量枚举多项式 + 随机测量的击中概率 1-(1-p_eff)^w（重量w的逻辑算符在测量率下存活概率）。

**判据形式化（B原创，K1/BS-1的可操作核心）：**
- 定义**单qubit可恢复阈值** p_c^(1)：保护**最易丢的那一个**逻辑方向（最小重量逻辑算符 w_min）所能承受的最大p。
- 定义**extensive可恢复阈值** p_c^(ext)：保护**∝L个**逻辑方向（即体积律码率）所能承受的最大p。
- **台阶判据（⇒重合）：** 若码距谱在阈值附近**集中**——所有逻辑方向的重量都 ∝L（w_min/L → 常数>0，且重量分布宽度/L → 0）——则 p_c^(1)=p_c^(ext)，可恢复性谱是 r 的台阶函数（要么全保护、要么全丢）。**purification（rank-1）阈值=entanglement（extensive）阈值。**
- **渐变判据（⇒分离）：** 若存在一族**低重量**逻辑算符（w_min = O(1) 或 o(L)，如守恒荷的局域算符），它们先被测掉而bulk逻辑仍存活，则 p_c^(1) < p_c^(ext)，谱是渐变，**purification先于entanglement消失 ⇒ 分离**。

**依据：** 可恢复性=逻辑算符未被ℳ覆盖。最小重量逻辑算符最先被覆盖 ⇒ 它定义 p_c^(1)。extensive码率要求几乎所有逻辑算符存活 ⇒ 由典型（重量分布主体）算符定义 p_c^(ext)。两者重合 ⟺ 最小重量与典型重量同标度（皆∝L）。

**最可能出错处：** "击中概率随重量单调"假设了测量是**单qubit、各方向等概率**的。若测量沿固定基（如全Z），则只有逻辑算符的**Z分量重量**相关，X型逻辑算符可能对Z测量"隐形"。这正是测量基各向异性问题，N3专门处理——**不能假设掉。**

### N3. 无对称下码距谱是台阶：重量枚举集中（BS-1承重墙）

**描述：** 证明在无对称（无守恒量）随机Clifford监测电路中，体积律相内码距谱集中于 ∝L，无低重量逻辑算符存活，故 p_c^(1)=p_c^(ext)。**这是Phase1 N3第3步"全有全无可恢复性"从假设升级为论证的地方。**

**工具：** 随机stabilizer码的逻辑算符重量枚举的**典型性/集中**（不是Gullans-Huse纯化数值，是码的重量枚举矩计算）；测量基各向异性的Clifford协变处理。

**依据（不跳步）：**

1. **体积律相 = 随机码以有限码率编码、码距 ∝L。** 在体积律相（p<p_c^ent），半链纠缠 ∝L 意味着Choi态 I(A:R)~2k 以 k∝L 保留。由N1组合事实，这要求"随机演化生成的逻辑算符群 ℒ_t 几乎不与任何低重量Pauli相交"——即码距 d=min重量(非平凡逻辑算符) ∝L。这是体积律的**等价重述**，未引入新假设。

2. **重量枚举集中（核心）：** 对随机Clifford码，长度L、维数k的码，其重量枚举 A(w)=#{重量w的逻辑算符} 的期望由MacWilliams型恒等式给出，且对**Haar-random稳定子码**，重量分布**集中**在 w ≈ L(1-2^{-?})·常数 附近，相对涨落 ~1/√L。关键事实（可独立验证、非相变断言）：随机码的最小距离 d 以高概率满足 d/L → δ(k/L) > 0（Gilbert-Varshamov型，量子版GV界对随机stabilizer码饱和）。**即：随机码典型地无低重量逻辑算符。** 这是编码论的标准集中结果，与purification相变无关。

3. **从集中到台阶：** 既然所有非平凡逻辑算符重量 ∈ [δL(1±o(1))]，则在随机单qubit测量率p下，逻辑算符存活概率 (1-p)^{w} 对所有逻辑方向**同标度** e^{-pδL}。于是：
   - 当 p 使 e^{-pδL}·(逻辑算符数 2^{2k}) 的乘积跨过1（一阶矩判据：期望存活逻辑算符数从指数大跌到指数小），**所有 rank 同时跨过**——因为 rank-1（最易丢方向，重量也是δL）与 rank-extensive（典型重量δL）用的是**同一个 δL**。
   - 故 p_c^(1) 与 p_c^(ext) 由同一个指数 pδL 控制 ⇒ **重合**。可恢复性谱 r(p) 在 p_c 处从 ∝L 跳到 0：**台阶。**

4. **测量基各向异性的独立处理（不假设掉，回应Phase1自标风险）：** 投影测量沿固定基（设Z基）确实只直接覆盖逻辑算符的Z分量。问题：是否存在一族**纯X型、Z重量小**的逻辑算符，对Z测量隐形、从而有更低阈值（打开第二阈值）？
   - **Clifford协变论证：** 在随机Clifford演化下，逻辑算符群 ℒ_t 在Pauli群上的分布对**Clifford群作用近似不变**（演化本身是随机Clifford）。Clifford群把Z基均匀搅到所有Pauli方向（single-qubit Clifford含H、S，生成的轨道覆盖X/Y/Z）。因此"逻辑算符的Z分量重量"与"总重量"在随机演化下**同分布集中**——不存在系统性地把重量藏在X分量躲开Z测量的逻辑算符族。形式化：E[Z重量 | 总重量w] = w/3·(1+o(1))（Pauli三分量等概率），方差次主导。故Z测量看到的有效重量 ~w/3，仍 ∝L，**台阶结论不变，只改变 δ 的数值（δ→δ/3量级），不改变 p_c^(1)=p_c^(ext) 的重合。**
   - **这就是为什么Clifford不是"人为巧合特殊点"而是"重量枚举典型性"：** 重合不依赖Clifford的代数巧合，而依赖"随机演化把逻辑算符重量在三个Pauli方向均匀化"这一**测度集中**事实。任何把演化随机性破坏到能系统性产生低Z重量逻辑算符族的结构（=守恒量/受保护sector），才打开第二阈值。无对称随机电路没有这种结构。

5. **∴ BS-1结论：无对称下 p_c^purif(=单qubit/rank-1) = p_c^ent(=extensive)，因为码距谱在阈值附近是台阶（jump），台阶来自随机码重量枚举的集中（GV型），而非Gullans-Huse纯化数值。**

**最可能出错处（诚实标注）：**
- (a) 第2步的GV集中对**随机stabilizer码**严格，对**浅监测电路生成的码**（t~O(L)，非完全随机）只在体积律相成立——临界点附近 t→∞ 极限与 L→∞ 极限的次序会影响集中宽度。B的论证给出**体积律相内**台阶稳健，**正在 p_c 处**台阶的陡度（是真台阶还是有限宽crossover）依赖 L→∞ 收敛速度，这一点B无法仅从集中不等式判定——这是与A的FSS外推**可比对**的接口（A若给临界指数ν，台阶宽度 ~L^{-1/ν}）。

### N5. K1：各向同性判据 vs Jensen判据的形式化对接

**描述：** 把B的"信道各向同性/无受保护sector"判据与A的"Jensen gap=0/率函数共享非解析点"判据放进同一形式框架，判等价性。回答PI的K1问题②。

**工具：** rank分辨的可恢复性谱（B侧）+ Rényi指标分辨的纠缠熵临界点（A侧的可观测后果，B用它做对接而不算A的配分函数）。

**形式化对接（不跳步）：**

1. **翻译A的判据到可观测语言：** A的"Jensen gap=0"= 退火率函数与淬火率函数共享非解析点 = **所有Rényi指标n的纠缠熵临界点 p_c^(n) 重合**（n≥2退火端与n→1淬火端同点）。这是因为Jensen不等式 E[log] ≤ log E[·] 的等号 ⟺ 无涨落（自平均）⟺ 各Rényi-n配分函数同时非解析。**这个翻译是A判据的等价可观测刻画，B用它但不算 K_n(s)。**

2. **翻译B的判据：** B的"信道各向同性/无受保护sector"= 逻辑空间无低重量方向 = **rank分辨的可恢复性谱是台阶**（N4）= 单一可检测阈值 p_c^(det)，对所有rank相同。

3. **方向一：Jensen=0 ⇒ 各向同性？（A判据 ⇒ B判据）**
   - Jensen=0 ⇒ 自平均（纠缠熵涨落次主导）⇒ 重量枚举集中（无重尾）⇒ 码距谱台阶（N3）⇒ 无受保护sector ⇒ 各向同性。
   - **成立。** 自平均是集中的，集中给台阶，台阶=各向同性。∴ **Jensen=0 ⇒ 各向同性。A判据蕴含B判据。**

4. **方向二：各向同性 ⇒ Jensen=0？（B判据 ⇒ A判据）**
   - 各向同性 = 单一检测阈值 = 所有rank在同一p_c跨越 = **von Neumann（n→1）侧码距谱台阶**。
   - **但这只约束了 n→1 侧。** 它**不**保证 n≥2 退火率函数在**同一**p_c非解析。一个模型可以：rank谱在von Neumann侧是台阶（单一learnability/纠缠阈值，各向同性），**但纠缠熵分布有重尾**使得 n≥2 Rényi熵的临界点 p_c^(n≥2) ≠ p_c^(n→1)（退火被稀有大涨落主导，先非解析）。此时 **Jensen gap≠0**（退火≠淬火）却**仍各向同性（单一物理检测阈值）**。
   - **∴ 各向同性 ⇏ Jensen=0。B判据不蕴含A判据。** 反例见N6。

5. **K1判定：不等价，严格包含 {Jensen=0} ⊊ {各向同性}。**
   - A的Jensen=0是重合的**充分**条件（且更强）。
   - B的各向同性是重合的**必要**条件（且更弱）。
   - 两者在**强自平均**模型（Haar/Clifford，重量枚举集中⇒无重尾⇒Jensen自动=0）**塌缩为等价**——这就是Phase1看起来"两判据都给命题A"的原因：在Clifford基线上它们碰巧一致，但一般不一致。

**最可能出错处：** 第4步的"各向同性只约束n→1侧"依赖"learnability/purification测的是von Neumann侧（n→1）"。需确认：I(R:M)与单qubit可恢复性确实对应 n→1（线性互信息/相干信息），是的——可恢复性、相干信息、von Neumann条件熵都是 n→1 量。而"entanglement transition"在数值文献中常用 n=1 或 n=2 混用，若A用 n=2 定义纠缠阈值，则A自己的"entanglement点"就已是退火端，B需指出**A的判据对Rényi指标的选择敏感**，这本身是支持"不等价"的证据。

### N6. K1反例构造：自由费米子 / 可解树（各向同性但Jensen≠0）

**反向核对（防自打脸）：** 是否存在 Jensen=0 但各向异性（多阈值）的反例（即推翻N5方向一）？

- **保守结论：** 若A用全局S，则 {Jensen=0} 与 {各向同性} **互不蕴含**（各有反例：自由费米子是isotropy∧¬Jensen0；U(1)全局S是Jensen0∧¬isotropy）。若A用分sector量，则 {Jensen=0}⊊{各向同性}（N5）。**两种情形下都不等价**——K1判定"不等价"在任一读法下成立，仅包含关系细节依赖A的定义。
