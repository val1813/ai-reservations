### Q1. 本Phase最核心前提假设是什么？有无文献直接否定它？

**核心前提：** "无后选择判据（learnability、弛豫标度）与轨迹层纠缠相变共享同一热力学极限临界点 p_c"——即 learnability/sharpening/purification/entanglement 是同一个相变的不同投影。

**搜索结果（否定/限定该前提的文献）：**
- ✅ **支持**（无对称情形）：Gullans-Huse purification transition (arXiv:1905.05195) + Scalable probes (arXiv:1910.00020) 证明无对称随机电路中 purification 相变与 entanglement 相变同点，参考比特熵是局域序参量。informational power (arXiv:2307.15011) 明确"learnability转变与MIPT重合"。
- ⚠️ **直接否定**（结构化情形）：**arXiv:2107.10279**（U(1)电荷锐化）和 **arXiv:2405.13894**（树上电荷/自旋锐化）发现"entanglement/purification 与 sharpening 相变普遍发生在**不同**测量率"。**arXiv:2504.08888** 进一步证明 learnability=sharpening（贝叶斯最优下重合），对U(1)动力学 learnability 等于电荷锐化点 p_#（≠纠缠点）。

→ **标注"⚠️前提风险"：核心前提仅在无对称（无守恒量）情形成立；存在守恒量时被文献直接否定（learnability测到锐化/可解码阈值，非纠缠阈值）。** 这正是命题B的物理实现，且不是边角情形——对称电路中是generic。

## §N 独立推导正文

> 路线：把监测电路视为等距编码信道 R→(Q,M)；用信息互补性把learnability锁到purification（N2）；用"随机码全有全无可恢复性"论证无对称下purification=entanglement（N3）；用BBP/KS植入信号-各向同性噪声结构给出重合的充要条件（N4）；用各向异性/对称/次优解码/反馈给出分离条件（N5）；独立分析弛豫判据的真实归属（N6）；综合（N7）。每步：描述/框架工具/依据/最可能出错处。**全程不引用A的replica证明，不写"显然""类比可得"。**

### N1. 设置：监测电路 = 等距编码信道

**步骤描述：** 在1+1D、L个qubit、测量率p的监测随机电路中，取一组参考比特R（先与系统最大纠缠，|R|可取1或∝L）。把测量装置纯化（Stinespring膨胀）：每次投影测量＝系统qubit与一个环境qubit做受控耦合后读出环境。于是整段动力学是 (R⊗系统⊗环境) 上的一个**等距映射** V：初态 → 末态，其中环境的读出值构成经典记录 M，系统残余为 Q。形式上 R → (Q, M)，V 等距。

**框架工具：** 量子信道的Stinespring膨胀；等距→保熵 S(R)=S(QM)。

**依据：** 投影测量 {Π_a} 可写为 isometry V=Σ_a Π_a⊗|a⟩_E 后跟对E的读出。监测轨迹 ρ_m = Π_m U…/p_m 正是对E在基{|a⟩}测得 m 后R⊗系统的条件态。整个膨胀幺正，故 R 的初始熵在 (Q,M,E_未读) 间守恒。

**最可能出错处：** "记录M"是否包含**全部**测量结果（完整记录）还是仅最终读出——learnability假设观测者持**完整**经典记录（Kim 2025、2307.15011皆然）。若只持部分记录，下面互补性关系要改。本推导固定为完整记录。

### N2. 信息互补性：learnability 临界点 = purification 临界点

**步骤描述：** 定义 learnability 序参量 I(R:M)（参考-记录互信息，= 信息功率/信道容量，2307.15011已证三者等价）。证明：I(R:M) 的非平凡化阈值，恰是参考比特被"纯化/未纯化"的阈值，即 Gullans-Huse purification 相变点。

**框架工具：** 信息互补性（complementarity of information）：对一个把 R 送入 (Q,M) 的等距，R关于(Q)的可恢复信息与R泄漏到(M)的信息互补。数据处理不等式（DPI）。

**依据（不跳步）：**
1. 等距下 R 是纯态的一部分，其信息要么留在系统 Q、要么进入记录 M（环境未读部分对完整记录情形为空）。量化：相干信息/可恢复性满足 I(R:Q)+I(R:M) 受 2S(R) 约束，且在"R与RQM整体纯"时有精确互补 I(R:Q)+I(R:E)=2S(R)，M是E的经典读出，I(R:M)≤I(R:E)。
2. **纠缠/混合相（p<p_c^purif）：** 系统作为良好量子存储器保护R——R与Q保持纠缠，S(R|Q)小，按互补性 R泄漏到记录的 I(R:M) 被压制（→面积律式、不随时间/尺寸增长）。观测者**无法**从记录学到R ⇒ unlearnable。
3. **去纠缠/纯相（p>p_c^purif）：** 测量主导，R被快速纯化，其信息倾倒入记录 ⇒ I(R:M) 饱和到 ~2S(R)（extensive/finite）⇒ learnable。
4. 故 I(R:M) 作为p的函数，其非解析跃变点 = R的纯化行为改变点 = purification 相变点。**∴ p_c^learn = p_c^purif。**

**这一步的性质（关键自评）：** 这**接近一个恒等/同义反复**而非实质发现——learnability本就是"记录是否含R信息"，purification本就是"R信息是否被记录带走"，二者是同一物理量的两种命名。真正的实质内容全部压到下一步 N3（purification 是否 = entanglement）。（→ 苏格拉底#2、#7）

**最可能出错处：** I(R:M)=I(R:E) 仅当记录是E的**无损**经典读出（投影测量、完整记录）。弱测量/POVM下 M 是 E 的有损读出，I(R:M)<I(R:E)，互补性松弛，learnability点可能偏离purification点——这是命题B的一个入口（→ #9）。

### N3. purification 是否 = entanglement：无对称随机码论证

**步骤描述：** 论证在**无对称（无守恒量）**的1+1D随机Clifford/Haar投影电路中，purification 临界点 = 体积律→面积律 entanglement 临界点。

**框架工具：** 监测电路作为**随机量子纠错码**（Gullans-Huse"纯化=纠错"图像）；码的"可恢复性谱"。

**依据（不跳步）：**
1. 把t步监测电路看作把"逻辑信息"编码进L个物理qubit的随机码。体积律相 = 码能保护 extensive（∝L）逻辑qubit；面积律相 = 码退化、保护O(1)或更少。
2. purification 探测"是否还能保护**单个**逻辑qubit（参考R）"；entanglement（半链S的体积/面积律）探测"是否还能保护**extensive**逻辑信息"。先验地这是码距谱的两端（rank-1 vs rank-∝L）。
3. **无对称随机码的关键性质——可恢复性"全有全无"：** Haar/Clifford随机性使码无任何受保护子空间，所有逻辑方向统计等价（信道对逻辑空间各向同性）。因此"能保护一个qubit"与"能保护有限码率"在 L→∞ 同时开启/关闭——可恢复性谱在阈值处是**台阶函数**而非渐变。单qubit阈值 = extensive阈值。
4. ∴ 无对称情形 **p_c^purif = p_c^ent**。结合N2：**p_c^learn = p_c^purif = p_c^ent。** 命题A在此基线成立。

**最可能出错处（重大）：** 第3步的"各向同性→单阈值"是论证的承重墙。它要求逻辑空间上**无任何区分方向**。但即使没有显式对称，投影测量沿固定基（如Z基）进行，**测量基本身挑选了方向**——信道对"对角信息"与"相干信息"未必各向同性。若这个各向异性足够强，单qubit（取决于R与测量基的对齐）阈值可与extensive阈值分离。Clifford的特殊代数结构（测量基与Clifford群协变）可能恰好抹平这个各向异性，使Clifford成为**人为重合的特殊点**（→ #3、#4）。这是B最不确定、也最可能与A产生真实分歧之处。

### N4. BBP/Kesten-Stigum 严格化：重合的充要条件

**步骤描述：** 把learnability重述为"植入信号+噪声信道+解码器"的可检测问题，用尖峰检测阈值结构给出"rank-1阈值=extensive阈值"（即purification=entanglement）成立的充要条件。

**框架工具：** 尖峰随机矩阵的BBP相变；随机图植入模型的Kesten-Stigum（KS）阈值。

**依据（不跳步）：**
1. **植入结构：** 参考R是植入信号（"真值"）；监测演化是噪声信道，信噪比由 p（测量=抽取信号）对 1-p（幺正scrambling=各向同性噪声/把信号摊匀）之比设定。观测者从记录M做后验推断 P(R|M)。learnable=后验偏离先验（检测成功）；unlearnable=后验塌回先验。
2. **rank-1 vs extensive-rank：** purification = 检测**单个**植入方向（rank-1尖峰）；entanglement体积/面积律 = 检测**extensive秩**的植入（rank∝L）。两者各自有可检测阈值 SNR_c^(1)、SNR_c^(ext)。
3. **充要条件（B的独立判据）：** 在BBP/KS理论中，当噪声协方差**各向同性**（所有信号方向同SNR）时，所有秩的尖峰在**同一**SNR_c检测开启 ⇒ SNR_c^(1)=SNR_c^(ext) ⇒ p_c^learn=p_c^ent。当噪声**各向异性**（存在低噪声受保护方向，如守恒荷模式）时，该受保护方向有**更低**的检测阈值 ⇒ 出现一个**独立的、更早的**可检测跃迁（=锐化），与bulk纠缠阈值分离。
4. ∴ **重合 ⟺ 监测信道在逻辑空间各向同性（无受保护sector）。** 这是B给出的、与A的"Jensen gap=0"**不同形式**的充要条件。

**与A判据的关系（潜在真实分歧）：** A的退火-淬火重合判据是"率函数共享非解析点"（Jensen不等式等号）。B的判据是"信道各向同性/无受保护sector"。两者**未必等价**：可以构造Jensen gap≠0（退火淬火率函数不同）但信道仍各向同性（单一检测阈值）的情形，或反之。若A与B在"分离的充分条件"上给出不同清单，这是**真实矛盾**，应开卡点（→ §末）。

**最可能出错处：** 把量子监测信道的"噪声"直接套用经典BBP的高斯各向同性假设。量子情形的"噪声"是幺正Haar scrambling，其在算子空间的作用确实近各向同性（这支持重合），但测量沿固定基破坏严格各向同性（这支持分离）——严格化需要算子空间度量下验证各向同性，本作业仅给出结构论证，未做算子层显式计算。这是B推导的硬边界。

### N5. 分离条件：命题B在原理上何时成立

**步骤描述：** 系统列出使 p_c^learn ≠ p_c^ent 的结构化情形，逐一给出信息论机制。

**框架工具：** N4的各向异性判据 + 可解码阈值理论。

**依据（不跳步）：**
1. **守恒量/对称（最强、generic）：** U(1)/SU(2)电荷-自旋。全局荷是受保护的低噪声方向 ⇒ 独立的电荷锐化阈值 p_#（检测全局荷的KS阈值），与bulk纠缠阈值 p_c^ent 分离。learnability若以荷为目标即测到 p_#≠p_c^ent。**这是命题B的干净实现，且对称电路中是generic而非边角。** （文献证实：2107.10279、2405.13894、2504.08888-U(1)。）
2. **贝叶斯次优解码：** 观测者用错误参数解码（Bayes non-optimal）。检测阈值随解码器移动 ⇒ p_c^learn 变成**解码器依赖**，一般≠p_c^ent。这意味着 p_c^learn 作为"物理相变点"在次优下甚至不唯一良定义——命题B的最强版本（learnability不是轨迹层固有相变，是观测者-信道联合性质）。（文献：2504.08888"贝叶斯非最优展开相图"。）
3. **弱测量/有限测量强度：** N2第4步的互补性松弛（I(R:M)<I(R:E)），N4的各向同性被测量软化破坏。learnability点可连续偏离纠缠点。（文献：2504.08888 least-squares变体"不同普适类"。）
4. **反馈/吸收态：** 反馈引入通道层吸收态相变（cf. 2512.07966），这是纯通道层结构，与轨迹层纠缠无关 ⇒ 无后选择判据可能锁到吸收态相变而非MIPT——命题B"测了伴生通道层相变"的字面实现。

**最可能出错处：** 把"对称情形分离"过度推广为"无对称也分离"。N3/N4论证无对称下重合是稳健的；分离的**充分**条件是结构化（对称/次优/弱测/反馈），不是无对称基线。不能用对称情形的分离去否定无对称Clifford的重合。

### N6. 弛豫判据的真实归属（独立核实，纠正分类）

**步骤描述：** 独立确定候选池"Wang 2025弛豫判据"（已核实=arXiv:2502.13408, Wang/Liu/Li/Zhang/Yin）测的是什么、属退火还是淬火、临界点是否=p_c^ent。

**框架工具：** 序参量的quenched/annealed分类（先取轨迹内非线性泛函=淬火；先对结果平均线性量=退火）+ 动力学标度。

**依据（不跳步）：**
1. 该文弛豫的量是**半链纠缠熵 S_{L/2}**的短时非平衡弛豫：体积律初态在临界点 S∝t^{-1}（系数∝L），product态 S∝ln t，统一标度，z=1，p_c=0.15995（沿用Sierant，不提新点）。
2. S(ρ_m) 是条件态ρ_m的**非线性泛函**，对其做轨迹平均 E_m[S] 是**淬火型**——与纠缠序参量同类，**不是**退火/通道层可观测量。
3. ∴ **p_c^relax = p_c^ent 近乎按构造成立**（它就是纠缠序参量的动力学窗口），z=1。但代价是：它**不独立绕开后选择**——该文自承短时窗口仅"减少"后选择开销，需配合cross-correlation协议才"完全消除"。

**重大分类纠正（与苏格拉底记录/A预期叙事冲突）：** 苏格拉底记录§第二/三轮把弛豫判据归为"退火型/通道层"（与learnability并列为无后选择annealed观测量）。**但被引的具体弛豫判据弛豫的是淬火纠缠熵。** 二选一为真：(a) 候选池把"Wang 2025=退火弛豫判据"**误归属**——2502.13408实为淬火纠缠熵的动力学探针；或(b) 存在另一种"退火弛豫判据"（弛豫结果平均后的自关联⟨O(t)O(0)⟩，那才是通道层），但它不是被引的Wang文。**这动摇A"退火-淬火重合→三点一致"统一叙事的一个支柱**：若判据二实为淬火，则"三点一致"里有两点（relax、ent）本就是同一淬火量，真正需要论证的只有learnability一点，命题被简化但也被部分架空。（→ #1、#7）

**最可能出错处：** 只读了2502.13408的WebFetch摘要，未读全文图。若全文另有一个退火可观测量作为主判据，则本纠正需收回。建议A/PI核全文确认弛豫的主序参量。

### N7. 综合：独立判定

**框架工具：** N2–N6合并。

**判定：**
1. **1+1D无对称投影Clifford/Haar基线（PI任务书指定的核心情形）：** p_c^learn = p_c^purif = p_c^ent ≈ 0.16；p_c^relax = p_c^ent（淬火纠缠熵动力学窗口，z=1）。**命题A在此基线成立。** 机制：信息互补性（N2）+ 随机码全有全无可恢复性/信道各向同性（N3, N4）。
2. **但"重合"是模型依赖特性，非普适律。** 充要条件=信道在逻辑空间各向同性、无受保护sector（N4）。一旦：守恒量（→电荷锐化，generic分离）、贝叶斯次优解码（→learnability点解码器依赖、甚至不唯一）、弱测量、反馈（→吸收态通道层相变），则 p_c^learn 脱离 p_c^ent，**命题B在原理上成立**：learnability实测的是信道层可解码/锐化阈值，与轨迹层纠缠几何是**概念上不同的两个阈值**，仅在各向同性基线数值重合。
3. **投影Clifford疑为人为重合的特殊点（开放）：** N3第4步指出测量基各向异性可能在非Clifford下破坏重合；Clifford的群协变结构可能恰好抹平它。故"Clifford基线重合"不能naive外推为"判据普适忠实"。
4. **无后选择主张的操作性结论：** learnability（I(R:M)）是真正无后选择的（记录是经典数据）；但弛豫判据（2502.13408）弛豫淬火纠缠熵，单独**不**绕开后选择，需cross-correlation。故"两种无后选择判据"的前提对判据二需收紧。

**一句话：** 命题A对指定基线成立，但其成立是"无守恒量+各向同性信道"的条件性结果；命题B所担忧的"无后选择判据测的是通道层可解码/锐化阈值而非轨迹层纠缠"在原理上正确，并在任何结构化（对称/次优/弱测/反馈）情形下显式发生——所以"后选择问题被真正绕开且判据普适忠实"是**过强**的陈述。
