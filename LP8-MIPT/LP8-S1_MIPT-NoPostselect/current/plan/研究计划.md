# 研究计划 — MIPT-NoPostselect (LP8-S1) v1

## 北极星（来自候选池 LP8-S1）
无后选择MIPT实验判据——learnability transition 和 弛豫动力学标度 哪种更鲁棒？两种判据在实际噪声下是否一致？热力学极限 L→∞ 下是否收敛到同一临界点？

## 驱动矛盾
**命题A（两判据等价）：** learnability transition 临界点 p_c^learn 与 弛豫标度临界点 p_c^relax 在 L→∞ 极限下收敛到同一个 MIPT 临界点 p_c，且二者都是 MIPT 在通道层面（channel level）的无后选择投影——因此 MIPT 在实验上可及，命题"MIPT是真相变"获得操作性支撑。

**命题B（两判据非等价/各自探测不同物理）：** learnability transition 探测的是"测量记录对初态信息的可学习性"（与量子通道的解码能力相关），弛豫标度探测的是"序参量/自关联的动力学衰减"——二者在有限尺寸交叉，但 L→∞ 下外推到不同 p_c，或其中之一根本不收敛到轨迹层面的纠缠相变点。若如此，"无后选择判据"只是探测了某个伴生的通道层相变（如吸收态/纯化相变），而非 MIPT 本身 → 后选择问题未被真正绕开。

> 两者不能同时为真：若 p_c^learn = p_c^relax = p_c^entanglement（轨迹层），命题A胜；若三者在 L→∞ 分离，命题B胜，且分离方式精确刻画了"无后选择判据到底测了什么"。

## 合法性确认（三问）
1. 命题A vs 命题B，不能同时为真？→ **是**（临界点在热力学极限是收敛到同一点还是分离，是二值事实）。
2. 解决后谁的工作会改变？→ MIPT实验组（Google/IBM超导处理器、离子阱组）选择哪种无后选择协议；MIPT理论组对"learnability=MIPT"等式的信心；量子纠错-MIPT映射社区（S6依赖此结论）。
3. 新结构介入还是技术推广？→ **新结构介入**：把"判据一致性"重述为"通道层可观测量 vs 轨迹层纠缠序"的对偶关系，引入信息论/统计推断的判别结构，而非单纯加大数值规模。

## 关键路径地位
LP8-S1 是 LP-8 依赖图的根节点之一（与S2并列）。S3、S5依赖S1；综合推导触发条件 "S1+S2+S4" 含S1。S1结论直接决定后续子命题的前提（"无后选择判据可信"是否成立）。

## 研究路径（候选池三步 + SOP细化，待苏格拉底命题确定后修订）
### Phase 1：两判据在 L→∞ 的一致性（无噪声基线）
- 在 1D 随机 Clifford 电路上同时定义/计算 learnability order parameter 与 弛豫标度量。
- 有限尺寸标度（FSS）外推 p_c^learn(L→∞) 与 p_c^relax(L→∞)。
- 判定：两临界点是否在误差棒内一致？与已知 Clifford MIPT 临界点 p_c≈0.16（1+1D, projective）是否一致？
- 产出：两种判据在 L→∞ 下的一致性/分歧（K条目）。

### Phase 2：实噪声模型下的判据鲁棒性
- 引入读取错误 + 门错误（depolarizing）模型。
- 确定每种判据的噪声容忍度上限 p_noise^max（判据信号在何噪声强度下被洗掉）。
- 关键张力：噪声会引入"纯化相变/吸收态"伴生效应——判据测到的是 MIPT 还是噪声诱导的伴生相变？
- 产出：实际量子硬件上可行的判据选择 + 噪声阈值。

### Phase 3：推广到非 Clifford（Haar随机幺正 + 弱测量）
- 检验 Clifford 特殊性（Clifford 的额外结构是否使某判据人为地更好）。
- 产出：普适结论（判据推荐是否独立于电路系综）。

## 风险
- 自毁/重复造轮子风险：**中**。learnability transition 与 弛豫标度都是 2024-2025 新结果，"两者一致性"很可能已有组在做 → GATE 0 先发查重是第一优先级硬门。
- 最脆弱假设：FSS 外推在 MIPT 中以慢收敛和强 logarithmic corrections 著称，"L→∞ 一致"的判定对外推方案敏感（最可能的叙事退让位置）。
- 工具可达性：1D Clifford 电路经典可模拟（stabilizer formalism, L≥1000 可行），不需要 GPU 集群；非 Clifford 部分受限于 ED/张量网络规模，Phase 3 可能降级为定性。
