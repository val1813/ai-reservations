### 第〇步：查重（攻击前 / 强制）

逐条检索结论是否已发表。检索证据如下。

**C1（1D噪声下 p_noise^c = 0，任意有限退相干率把体积律洗成面积律）**
⛔ **重复造轮子警告**：arXiv:2401.16631（*Noise-induced phase transitions in hybrid quantum circuits*, v2, 2024-09）原文摘要逐字写道："an infinitesimal size-independent noise probability can lead to the disappearance of measurement-induced entanglement phase transition and the emergence of a single area-law phase." 这与 C1 的核心论断（任意有限/无穷小、尺寸无关噪声 → 单一面积律 → p_c=0）**字面等价**。更严重的是：该文把 "size-independent noise → single area-law" 当作 **α=0 的既有基线（prior work）**并引用更早文献，意味着 C1 在 2024 年初已是"教科书背景"，而非待证命题。arXiv:2212.03901（*Universal KPZ scaling in noisy hybrid quantum circuits*）亦覆盖噪声摧毁 MIPT 的同一物理。**C1 已被发表相同结论。** 作者声称的"两独立框架汇合"（树 Markov b→1 Kesten-Stigum + 1D 非 expander 擦除阈值）仅是**推导路线**，并不改变结论的非新颖性。

**C2（2D / D≤2 被动监测电路 p_c^{coh}(passive)=0，需工程化纠错）**
⛔ **重复造轮子警告**：arXiv:2510.12743（Wei, Nelson, Rajakumar, Cruz, Gorshkov 等，*Measurement-induced entanglement in noisy 2D random Clifford circuits*, 2025）原文："in the presence of single-qubit depolarizing noise at any constant rate p>0, we find that the operator entanglement S_op obeys an area law" 及结论句 "constant local noise destroys long-range, volume-law measurement-induced entanglement in 2D random Clifford circuits." 这正是 C2 的 2D 被动情形 p_c=0。叠加 arXiv:2408.16267（*Coherent Information Phase Transition in a Noisy Quantum Circuit*）：相干信息转变仅在引入 quantum-enhanced（ancilla 扩张）主动操作时存在于有限 q，被动情形坍塌——即 C2 的"需工程化纠错"。**C2 的两半（被动死 + 需主动）分别被 2510.12743 与 2408.16267 覆盖。**

**C3（可记录性二分：recorded Born → syndrome → 解码器 → exp(L) 被动保护 vs 退相干 → 记录丢失 → DPI 不可逆 → 需主动 QEC）**
判定：**实质覆盖，框架未独立成文（边际）**。arXiv:2503.10308（*Mixed-state learnability transitions in monitored noisy quantum dynamics*, 2025）明确区分 recorded measurements（作为 Kraus 算符）与 lost outcomes/noise（作为 channel），并对比"保留记录的观测者可解码/学习" vs "记录散失入环境"，含 decoding-vs-learning 区分与多阈值分离。recorded-outcome = emergent error-correcting code 是 Choi–Bao–Qi–Altman / Gullans–Huse 标准结论；"记录丢失→DPI→需主动 QEC"是混合态信息论的标准推理。**C3 的物理内容已被发表**；其"本质不同两类转变"的二分**措辞**作为独立 headline 尚未见单篇明述，但属已知事实的重新打包，不构成 Nature Physics 级增量。

**C4（2D 序参量串行分离 p_c^{算符纠缠}=0 < p_c^{态纠缠熵} ≲ p_c^{相干信息}）**
判定：**部分覆盖 + 表述不达标**。p_c^{算符纠缠}=0 已由 2510.12743 给出（即 C2 的重复）。但 2510.12743 **未声称**三阈值之间的"序分离"——其原文确认"未比较 operator-entanglement 与 entanglement-entropy / MIE 的不同阈值"。故"显式三阈值排序"本身未被单篇发表，是本课题**仅存的潜在增量**；然而它完全由已发表碎片拼装，且用 "≲" 与"后两者可能重合"表述，定量与定性均不确定，达不到独立结论强度。

**查重综合结论：未通过。C1、C2 已发表相同结论（重复造轮子）。C3、C4 是仅存增量候选，但 C3 物理内容已被覆盖、C4 表述不达标。**

### 五条拒稿理由

**1.（severity：致命）核心假设最简反例 — "有限维噪声鲁棒 MIPT"的整个出发点被单行反例击穿**
命题 A 赖以成立的唯一正例是树状/无限配位电路。最简反例：取任意 1D brick-wall 监测电路叠加任意 p>0 单比特去极化。arXiv:2401.16631 已证此情形塌为单一面积律（p_c=0）。树之所以"鲁棒"仅因其分支比 b>1 提供 expander 式信息冗余（Kesten–Stigum），这是无限维 mean-field 特征而非有限维物理。换言之，作者的正例与待证命题（有限维）属不同普适类，正例对命题 A 零证据力。课题的全部"鲁棒性"信号来自一个与目标维度无关的人为构造。**作者需证明**：存在某个有限维（D<∞）局域电路，在 p>0 下保有体积律/内禀转变，且其机制不可约化为 expander/mean-field——否则命题 A 无任何有限维支撑。

**2.（severity：致命）推导链最薄弱一步 — C5 把"有限阈值"等同于已知 QEC 阈值，自我抽空新意**
C5 明言"有限阈值恒需工程化主动纠错（=已知 QEC 阈值物理）"。这一步同时是逻辑闭环与自杀：若被动情形 p_c=0（C1/C2），而唯一有限阈值来自主动 QEC，且该阈值"=已知 QEC 阈值物理"，则本课题在物理上**没有产生任何新阈值、新普适类或新机制**——它复述了"QEC 码有纠错阈值"这一 20 年前已知事实。推导链最薄弱处不是某个不等式，而是**结论本身不含新物理**：从 C1→C5 的全部内容可被压缩为"监测 MIPT 在噪声下退化为标准混合态 QEC 解码问题"。**作者需证明**：所谓"工程化阈值"在数值或普适类上**区别于**已知 toric/surface code 阈值，否则结论无独立科学贡献。

**3.（severity：致命）与文献直接冲突 / 被既有工作覆盖**
C1 与 arXiv:2401.16631、arXiv:2212.03901 字面冲突（它们已先发表同一结论，故 C1 非新）。C2 与 arXiv:2510.12743（2D operator entanglement 在 any p>0 面积律）及 arXiv:2408.16267（相干信息需主动 QE 操作）直接重叠。C3 与 arXiv:2503.10308（recorded-vs-lost 区分、learnability/decoding 转变）重叠。此外 arXiv:2406.14109（*Protect MIPT from Noise*）给出**相反取向**的可发表结论：通过 quantum-enhanced 操作 MIPT **可被保护**，说明"噪声下 MIPT 命运"本身已是被充分研究、结论多样的成熟课题。本课题既未提供新证据推翻 2406.14109 的保护机制，又复述了 2401.16631 的破坏机制。**作者需证明**：相对上述 6 篇，本课题给出至少一个它们均未给出的、可证伪的定量陈述。

**4.（severity：严重）数值合理性 — 阈值数字要么是标准已知值，要么未经辩护**
审稿要点中 p_c^{coh} 工程化阈值"~10.9% toric"与"50% 擦除"：50% 擦除阈值恰为方格 toric code 的擦除/键渗流阈值（p_c=0.5），是教科书已知值；10.9% 落在去极化下 surface code 解码阈值（视解码器约 10–19%，Nishimori 点约 18.9%）的区间内但需指明解码器与噪声模型，且无论取何值，**它都是已知 QEC 阈值**。这恰恰坐实理由 2：课题"预测"的有限阈值就是已知阈值。若作者反而声称得到一个**不同于**已知 QEC 阈值的数，则需完整的数值收敛（系统尺寸标度、临界指数 ν、数据坍缩）支撑——结论列表中无任何此类数据。**作者需证明**：报告阈值的数值来源、误差棒与有限尺寸标度，并说明它为何不是平凡复述 QEC 已知阈值。

**5.（severity：严重）最近似已有工作逐句比较 — 新颖性净值接近零**
逐句比较：① "1D 任意有限噪声 → 面积律 / p_c=0" ≡ arXiv:2401.16631 摘要原句。② "2D constant noise → operator entanglement area law / 破坏长程 MIE" ≡ arXiv:2510.12743 结论句。③ "相干信息转变需主动 quantum-enhanced 操作" ≡ arXiv:2408.16267。④ "recorded vs lost-to-environment 的解码/学习二分" ≡ arXiv:2503.10308。⑤ "噪声下 MIPT 可被工程化保护" 的对立面已由 arXiv:2406.14109 占据。五条被审结论中四条可逐句映射到 2024–2025 已发表语句，第五条（C4 三阈值排序）是碎片拼装且表述含混。**作者需证明**：以并列表格形式列出 C1–C5 每条相对最近邻论文的**净增量句**，并标注该句在何文献均未出现——若无法填满该表，应撤稿而非投稿。

### 对 C3 / C4 "真实增量"的判断
