## ⚡ PI 审核入口（30 秒摘要）

- **⚡ B 独立结论（BS-2D-1）**：2D 被动监测电路（仅 Born 测量、无主动 syndrome 前馈）在**外延噪声**下的相干信息有限阈值 **p_noise^c > 0 不是内禀的，需工程化**（主动纠错前馈，或工程化的无噪保护子系统）。被动极限下 **p_noise^c = 0（全维度 D ≤ 2）**。命题 B 在"可实现性"意义上全维度成立；只有引入工程才出现有限阈值。
- **⚡ 框架**：信道容量/退耦定理（I_c>0 ⟺ 存在恢复映射）+ Bravyi–Poulin–Terhal 2D 码距上界 d=O(√n) + 数据处理不等式（环境记录丢失不可逆）+ 擦除-渗流对应。**全程不用 RG/Nishimori**。

- **⚡ 苏格拉底问题数**：7（前三 ⭐ 见 §末）。
- **⚡ S2 增量裁定**：若按"内禀有限噪声阈值"理解，S2 = **重复造轮子**（就是 QEC 阈值定理）。真增量 = **可记录性二分（recorded 测量 vs unrecorded 退相干）+ 序参量串行分离**，这才是新普适结构。

## §0 框架声明（与 A 的不重叠性）

我从**纠错码理论**单侧独立判定，工具箱限定为：

1. **量子信道容量 / 退耦定理**：相干信息 I_c(N) = S(ρ') − S((N⊗I)|Φ⟩⟨Φ|) 的正负，等价于"是否存在恢复映射 R 使 R∘N ≈ id"（Schumacher–Nielsen，Barnum–Knill–Nielsen）。这是 I_c 的**算子定义**，不需要 RG。
2. **码距与几何上界**：Bravyi–Poulin–Terhal（arXiv:0909.5200）2D 局域稳定子码 kd² ≤ O(n)，k=O(1) 时 d=O(√n)=O(L)；逻辑算符权重 ≥ d。
3. **擦除-渗流对应**（我 Phase1 的工具延续）：surface code 擦除阈值 = 2D 键渗流阈值 = 50%（启发式擦除 + peeling 主动解码）。
4. **数据处理不等式**：泄漏到不可观测环境的信息不能被任何后续操作恢复。
5. **被动自纠错 no-go**（Bravyi–Terhal，arXiv:0810.1983；BPT 能垒论证）作为**辅助**（注意其本是热稳定性语境，我只用其"局域+低维 ⟹ 能垒有界"几何内核，不外推到热平衡）。

**与 A 的显式不重叠**：A 走 Nishimori 线 / 随机场统计力学，把噪声监测电路映成无序自旋模型，从有序相是否触及 p_noise=0 轴判定。我**完全不做这个映射**。我的判定链条若与 A 汇合，是两套独立工具的交叉验证而非循环论证。

## §0.5 前置三问（搜索结果）

**问 1：被动监测 vs 主动纠错的擦除阈值差异，是否已有文献明确区分？**
- 部分有。surface code 擦除阈值 50% 始终定义为"存在主动 peeling/匹配解码器使逻辑错误→0 的阈值"（启发式擦除，记录被擦位置）。Error Correction Zoo "monitored random-circuit code" 条目明确：监测动力学把系统投影成**随机纠错码**，protection 体现在"readout 时存在解码器"，而非演化中被动恢复。
- **未找到**直接命名"被动监测电路的擦除阈值"并与主动阈值定量对比的单篇文献 → 这正是 BS-2D-1 的空白，我下面独立填。

**问 2：surface code 的"被动极限"是什么？**
- Bravyi–Terhal（0810.1983）：D=1,2 稳定子码**不存在被动自纠错量子存储**——能垒有界，逻辑错误不随尺寸压制。
- 反例都需**工程**：dissipative toric code（2602.19288）、2D autonomous QEC（2601.20818）实现有限阈值，但都靠**工程化 Lindbladian/局域自动机**主动抽熵，不是通用 Born 测量。
- 结论：surface code 的被动极限 = 无保护，阈值 0；有限阈值恒需主动解码或工程耗散。

**问 3：2408.16267 是否加了 QE（工程化）操作？**
- **是，确证**。"quantum-enhanced operations" = 引入 ancilla + 对系统比特施 U_SA（主要取 **SWAP**），把比特态**搬入隔离的无噪 ancilla**，直到电路末尾不再触碰。这是**工程化保护子系统**，不是 Born 测量、不是 syndrome 前馈。
- 关键定量：无 QE 时"negative coherent information is expected in noisy circuits with random unitaries and measurements"——即**纯被动噪声监测 → I_c < 0（不可恢复相）**。转变发生在 q=q_noise/q_QE 的有限比值（reset q_c=0.500, depolarizing q_c=0.360, dephasing q_c=0.503，均在 p=0）。
- **且该模型是 1D**（brick-wall 链）。即便 1D（MIPT 本就存在），噪声相干信息的可恢复相**仍需 QE**。

## §N 独立推导

### N1. I_c > 0 的算子意义：存在恢复映射（非被动维持）
**描述**：澄清相干信息正负的物理含义。
**工具**：退耦定理 / BKN 充要条件。
**依据**：I_c(N) > 0（渐近、配块码）⟺ ∃ 恢复映射 R 使 R∘N ≈ id_logical。R 即"主动纠错"。
**推论**：相干信息为正本身**就是**"主动恢复会成功"的陈述。它**不**断言被动过程已经把信息恢复了——它只断言恢复**可能**。
**最易错处**："I_c>0 = 信息还在系统里" ≠ "被动动力学保住了信息"。容易把"可恢复性"（存在 R）误读成"已恢复/无需操作"。这是 S1 的答案：二者不是一回事。

### N2. 可记录性二分（本作业最核心的独立洞见）
**描述**：区分两类"误差"——recorded 测量 vs unrecorded 退相干。
**工具**：数据处理不等式 + syndrome 概念。
**依据**：
- **Born 测量**：结果被**记录**。保留记录 = 保留 syndrome = 解码器可存在。纯测量 MIPT 的被动保护正源于此（记录在手）。
- **退相干噪声**（depolarizing/dephasing/reset 耦合环境）：环境记录**丢失**。由数据处理不等式，泄漏到不可观测环境的互信息**不可逆**。
**推论**：要对抗退相干必须在 syndrome 丢失前**主动抽取**它 = 主动 syndrome 测量 = 主动 QEC。被动监测做不到，因为它记录的是自己的 Born 结果，不是退相干 syndrome。
**最易错处**：把退相干当成"另一种测量"。区别是致命的——测量记录留下，退相干记录丢失。这是 S2 的答案：MIPT 被动保护的是**recorded** 误差通道，不是 unrecorded 退相干。两个转变因误差可记录性不同而**本质不同**（直接支持我 Phase1 的序参量分离假说）。

### N3. 外延时空噪声 ⟹ 被动 p_noise^c = 0（主论证）
**描述**：固定速率 p 的退相干作用于每个时空点，证被动无有限阈值。
**工具**：BPT 距离上界 + 数据处理 + 累积论证。
**依据**：
1. 2D 局域码（监测动力学生成的瞬时随机码也受 2D 局域性约束）：d = O(√n) = O(L)（BPT 0909.5200）。逻辑算符权重 ≥ d。
2. 退相干率 p/site/step，时空体积 V：泄漏到环境的逻辑相关信息随 V 单调累积（N2，不可逆）。
3. 无主动抽取时，~d 个对齐误差即构成不可纠逻辑错误；晚期（poly/exp 时间）不可纠逻辑错误概率 → 1，对**任意 p > 0**。
4. ⟹ 被动晚期 p_noise^c = 0。
**推论**：被动 2D 监测对抗外延噪声**无内禀有限阈值**。
**最易错处**：误以为纯测量 MIPT 的 exp(L) 保护能顺带挡退相干。不能——它挡的是 recorded 测量（N2）。这是 S6 的答案：外延时空噪声 ≠ 单次块码；连续泄漏到丢失环境，被动不可逆。

### N4. 工程化如何恢复有限阈值（两条路）
**描述**：明确"工程化"指什么、为何能挽救。
**工具**：阈值定理 + 保护子系统。
**依据**：
- **路 A — 主动前馈**：测稳定子 syndrome → 经典解码 → 前馈 recovery。阈值定理给有限阈值（surface code 擦除 50% = 渗流；最优 Pauli ~10.9%；circuit-level ~1%）。在 syndrome 丢失前主动抽取，绕过 N2。
- **路 B — 工程化保护子系统**：2408.16267 的 QE = SWAP 搬入无噪 ancilla。把逻辑信息移出噪声区。无 QE → I_c < 0（§0.5 问 3 确证）。
**推论**：有限 p_noise^c 恒需路 A 或路 B，**均为工程化**。2408.16267 的"相变"是 q=q_noise/q_QE 比值相变 = **工程量相变**，非内禀噪声率相变；q_QE → 0 时可恢复相消失。
**最易错处**：把"q_c 有限"读成"内禀噪声阈值有限"。q_c 是**工程-噪声比**的临界值，不是噪声率的内禀临界值。

### N5. 擦除-渗流是否构成"内禀"反例？（自攻击 S3）
**描述**：50% 擦除阈值看似几何内禀，检验是否推翻 N3。
**工具**：渗流 + 单次 vs 外延区分。
**依据**：
- 50% = 2D 键渗流阈值，**几何内禀**——但它是"**主动 peeling/匹配解码器**成功的上界"。几何决定阈值数值，恢复仍需主动跑解码器。
- 且 50% 是**单次块码**陈述（擦一次 fraction f 再解码）。外延-时间擦除（每步擦一部分、无主动纠正）→ 信息持续泄漏 → 被动晚期仍 → 0。
**推论**：擦除阈值不构成被动反例。**几何内禀（阈值数值）≠ 可实现性内禀（被动维持）**。这是 S3 的答案，也预演了 §末与 A 的语义分歧。

### N6. BPT 引用的合法性边界（自攻击 S4）
**描述**：BPT 是热稳定性定理，限定其使用。
**依据**：我**不**外推 BPT 到热平衡。我只用两件可独立成立的事：(i) BPT-距离上界 d=O(√n)（纯组合几何，与热无关，N3 核心）；(ii) "2D 局域 + 能垒有界 ⟹ 无尺寸压制的被动保护"的几何内核，作为**辅助直觉**而非主证。主证是 N1–N3 的信道容量+数据处理链，**不依赖** BPT 热论证。
**推论**：S4 答案——合法，但我把承重放在距离界与数据处理上，BPT 自纠错 no-go 仅作旁证。

### N7. 1D → 2D 外推的合法性（自攻击 S5）
**描述**：2408.16267 是 1D，为何能支撑 2D 结论。
**依据**：方向一致且 2D 更不利。1D（MIPT 本存在的最有利情形）下噪声可恢复相**已经**需 QE 工程。BPT 距离界在 2D 给 d=O(√n)，自纠错在 D≤2 全被禁（3D 部分、4D Haah 才有）。1D 证据 + 2D 几何 no-go 同向 ⟹ D≤2 全维度被动 p_noise^c=0。
**推论**：S5 答案——1D 不是削弱而是强化；它证明连最有利维度都需工程。

## §末 汇合检验 + 苏格拉底清单

### B vs A 汇合检验

**预测：汇合（核心结论一致）。**
- A 从 Nishimori 线判：2D 噪声监测映成随机键 Ising，相干信息有限阈值对应 **Nishimori 点 ~10.9%**。这个数恰是 toric code 在**最优（最大似然）解码器**下的阈值——A 若准确，必认其为**主动解码阈值**。
- 我从码理论判：有限阈值 = 主动恢复 / 工程化；被动 = 0。
- **两套独立工具指向同一裁定** → 命题 B（可实现性意义）+ 工程逃逸通道。✅ 交叉验证成立。

**⚠️ 开卡点（语义分歧风险，必交 PI）**：
A 可能用"intrinsic to mixed state"（混合态非局域序参量，decoder-independent，存在性意义）称转变**内禀**；我用"被动可实现性"称其**需工程化**。**两者不矛盾，是 internal 二义**：
- **内禀-存在性（弱）**：转变是噪声系综/混合态的良定义性质，与解码器无关 → A 可主张为真（有限阈值）。
- **内禀-可实现性（强）**：可恢复相由被动动力学维持、无前馈/工程 → 我主张 D≤2 为假（需工程）。
- BS-2D-1 原文"内禀 vs 需工程化"= **可实现性意义** → 我的答案：**非内禀，需工程化**。混合态转变可能作为性质存在（存在性），但**实现**可恢复相需主动恢复/保护子系统。
- **卡点交 PI 裁定**：BS-2D-1 应锁定在哪个"内禀"语义？我建议锁可实现性（与"工程化"对仗的唯一自洽读法）。

### S2 真增量裁定
- 若按"内禀有限噪声阈值"理解 → **重复造轮子**（= QEC 阈值定理，surface code/Nishimori 点已知）。
- **真增量 = (a) 可记录性二分**（recorded 测量内禀转变 vs unrecorded 退相干需工程，N2）**+ (b) 序参量串行分离** p_c^{op-ent}=0 < p_c^{S-ent} ≲ p_c^{coh}。这是新普适结构，非 QEC 旧轮子。
- 建议 S2 收官聚焦 (a)(b)，**撤回**"噪声驱动有限阈值 MIPT 为新内禀相"的任何措辞。
