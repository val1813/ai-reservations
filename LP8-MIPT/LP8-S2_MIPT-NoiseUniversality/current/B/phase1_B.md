## §0 框架声明
A博士本Phase用：**电路→经典Markov映射 + RG标度维数**（树Markov b→1 + Kesten-Stigum b·θ²>1；1+1D随机场临界维RG relevant）。

- **框架I（纠错码）**：噪声下MIPT ≡ 在"每步擦除/退相干信道"上动态生成的随机稳定子码能否在 L→∞、t→∞ 保住逻辑信息。判据是**码距标度 d_code(n) 与擦除阈值**，以及"擦除解码 ↔ 码图渗流"对应。工具：BPT/局域码距上界、good/expander码线性距离、擦除阈值定理、相干信息作为基本阈值序参量（arXiv:2412.16727）。

两框架都不经过A的转移矩阵Markov链，也不做RG流方程。**重叠声明：零重叠**——A的Markov映射是把电路的统计权重映射成经典随机过程的转移核做b→1解析延拓；我框架I是信息论编码容量论证，框架II是平衡态RFIM相图，二者均不构造A那条Markov链，也不写RG β函数。

## §2 苏格拉底问题（并行记录）

**#1 / 位置:课题"树鲁棒性本质" / 类型:概念混淆**
问题：树的鲁棒性到底来自"无限分支维（mean-field）"还是"指数边界冗余（expander/good-code）"？这两者在树上**重合**，但在别处可分离——有无"有限维但仍是good-code"或"无限维但非expander"的反例图？
为什么重要：若鲁棒性本质是expander而非维度，则"降到有限维"的正确判据是**码距标度**而非空间维数d，结论框架完全不同。

**#2 / 位置:核心问题"降到有限维" / 类型:极限合法性**
问题：树→1D是连续极限吗？b→1时boundary/bulk比例从指数突降到O(1/L)，这是相变级的拓扑突变，b→1解析延拓（A的Kesten-Stigum路径）是否合法？
为什么重要：若非连续极限，A的"b→1无解⟹p_c→0"是外推假象，1D需独立论证（而非树极限）。我的两框架正是独立论证，可交叉检验A。

**#3 / 位置:F4 Imry-Ma / 类型:文献误读风险**
问题：2406.14109的Imry-Ma到底证了"2D存活"还是"2D（1+1D电路对应的2D统计模型）**无序**"？
为什么重要：我的核实=后者（原文用Imry-Ma否定2D统计模型、改走3D）。若A把F4读成"2D存活"，整个F4/F6张力是**伪张力**（建立在误读上）。这直接动摇A的2D叙事。

**#4 / 位置:序参量选择 / 类型:定义先于结论**
问题："噪声下MIPT存活"中的"它"是哪个序参量？态纠缠熵、算符纠缠、相干信息——三者在noisy mixed-state下**不等价**（纯态时才等价）。问"它是否存活"在没定序参量前是ill-posed的。
为什么重要：F4/F6矛盾的根=两文献默认了不同的"它"。这是2D增量的钥匙。

**#5 / 位置:监测 vs 非监测 / 类型:机理区分**
问题：2510.07512的1/p编码转变是**无监测**编码电路；监测电路的测量提供**syndrome信息**可纠错。监测是否把阈值从"0"抬到"有限"（Nishimori线）？
为什么重要：若监测syndrome能纠per-step擦除，则1D coh-info阈值未必严格0——需检验Nishimori-line decoding（2505.22720"flow to Nishimori"）是否在1D给有限阈值。这是对我自己1D结论的自我攻击点。

**#6 / 位置:擦除vs退相干 / 类型:噪声模型依赖**
问题：阈值结论是否依赖噪声是"擦除（heralded，知道位置）"还是"退相干/depolarizing（unheralded）"？擦除阈值(2D toric=50%)远高于depolarizing阈值。
为什么重要：树论文用depolarizing-like，擦除阈值定理用heralded擦除。若混用，定量阈值不可比。结论的maturity依赖统一噪声模型。

**#7 / 位置:有限尺寸 vs 热力学极限 / 类型:极限次序**
问题：lim_{L→∞} 和 lim_{t→∞} 次序是否可换？2510.07512显示固定深度有有限阈值、深度→∞阈值→0。MIPT稳态要求t→∞。
为什么重要："存活"在 t 先∞还是 L 先∞下答案不同；实验/数值看到的"有限阈值"可能是有限-t假象。

## §N 独立推导正文

### N.1 框架I：纠错码擦除阈值 —— 1D判定

**步骤1（设定映射）**
- 描述：体积律相 = 监测电路动态生成的随机稳定子码，把初始信息编码进 n=L 个物理比特；噪声 = 每个时间步、每站点以率 p 作用的擦除/退相干信道。MIPT存活 ⟺ 该动态码在 L→∞、深度 T→∞ 下仍有正容量（逻辑信息可恢复）。
- 框架工具：稳定子码容量 / 擦除阈值定理。
- 依据：MIPT-编码对应（Choi-Gu-Fisher类，及2510.07512/2408.16267的coh-info框架）。
- 最易错处：把"一次性擦除一段区间"（静态码capacity）误当成"每步持续擦除"（动态累积）。本问题是**后者**——稳态要承受 ∫dt 的累积擦除。

**步骤2（1D码距上界）**
- 描述：1D局域稳定子码的码距受**局域性上界**压制。对2D稳定子码有 Bravyi-Poulin-Terhal 界 k·d² ≤ O(n)；其1D类比更强：1D局域稳定子码（有限交互范围）的码距 d_code = O(1)（不随L增长）或在最好情况只能 d~O(L) 而 k~O(1)（重复码型，零率）。无1D常率good-code。
- 框架工具：BPT界、1D局域码no-go。
- 依据：BPT定理及其1D推论；1D无好LDPC码。
- 最易错处：体积律相的"码"虽是random circuit生成、非严格局域稳定子，但其**因果锥局域**（光锥速度有限）使等效局域性上界仍适用——码距被光锥宽度×可纠错半径限制。

**步骤3（每步擦除累积 ⟹ 阈值→0）**
- 描述：率 p 的擦除每步抹掉 ~pL 个物理比特位置。要在深度 T 后仍恢复，需码能纠正累积擦除分数。即便每步只 pL，监测电路的"刷新"（测量重新定域信息）只能保护 ~码距/光锥 范围。2510.07512严格结果：相干信息 I_c<0 当 T > p^{-1} log(1+1/r)。故对任意固定 p>0，∃ 有限深度 T*(p)~1/p 之后信息必失。
- 框架工具：相干信息上界（2510.07512）+ 1D无good-code。
- 依据：arXiv:2510.07512 证明 d>p^{-1}log(1+1/r) ⟹ I_c<0；1D码距不足以把 T* 推到∞。
- 最易错处：T*~1/p 看似"有限阈值 p*(T)~1/T"，但MIPT稳态要 T→∞，于是 p*→0。**必须先固定 t→∞ 再问 p**——否则得假阈值（苏#7）。

**步骤4（监测syndrome的自我攻击）**
- 描述：自攻击点——监测电路的测量是syndrome，可主动纠错，是否把阈值抬离0？映射到Nishimori线解码（2505.22720"flow to Nishimori universality with qubit loss"）。在 (1+1)D，Nishimori多临界点对应2D随机键Ising/2D±J模型——其阈值是**2D**统计模型的阈值。
- 框架工具：syndrome解码↔Nishimori线↔2D随机Ising（对1+1D电路）。
- 依据：2505.22720；Nishimori-line decoding。
- 最易错处：但2D随机场/随机键Ising在**有外加随机场**（noise本身=随机场，不只是随机键）下回到Imry-Ma：d=2是下临界维。故即便有syndrome，1+1D对应的2D-RFIM仍在临界维marginal，不撑起严格有限阈值。**syndrome把"无监测的1/p硬死"软化为"临界维marginal"，但仍是 p_c=0（或对数压低），不翻成有限阈值。**

**框架I对1D小结**：1D无good-code + 每步擦除累积 + syndrome只把硬死软化到RFIM临界维 ⟹ **p_noise^c = 0（命题B）**。

### N.2 框架II：Bethe/RFIM维度依赖 —— 1D/2D/树统一判定

**步骤5（建立平衡态类比 + 关键修正：随机场）**
- 描述：噪声下体积律存活 ⟺ spacetime图上、对称破缺场中有限"温度"（测量率p↔温度）有序相存在。**关键修正**：噪声误差位置随机 ⟹ 场是**随机场 h_i**（均值可为0，方差∝噪声率r），正确模型是 **RFIM**，非均匀场Ising。
- 框架工具：p↔T、r↔随机场方差；RFIM相图。
- 依据：Ravindranath映射(r↔h) + 随机性修正；2406.14109正文确认"noise acts as random field"。
- 最易错处：A（按摘要）可能用**均匀**场Ising直觉（均匀场任意维都破坏二级相变），但随机场的下临界维是 d_l=2，结论维度依赖完全不同。**这是B独立于A的核心分水岭。**

**步骤6（维度依赖的RFIM判据）**
- 描述：RFIM有限温有序相存在性（Imry-Ma + Aizenman-Wehr严格）：
  - **d=1**：无有限温有序（even h=0 已无，1D Ising无相变）。⟹ 1D命题B。
  - **d=2**：**下临界维**。Imry-Ma标度：畴壁能 ~ L^{d-1}=L，随机场增益 ~ L^{d/2}=L，**marginal**；Aizenman-Wehr严格证 d=2 任意 h>0 **无长程序**。⟹ 2D随机场无有限阈值（对映射到2D-RFIM的序参量）。
  - **d≥3**：随机场增益 L^{d/2} < 畴壁 L^{d-1}，**小 h 有序相存活** ⟹ 有限阈值（命题A）。
  - **Bethe(b>1)/无限维**：mean-field，随机场下仍有有序（且带约束边界更强），= Ravindranath树 r_c≈0.0225 有限。⟹ 树命题A。
- 框架工具：Imry-Ma标度、Aizenman-Wehr定理、RFIM lower critical dim。
- 依据：RFIM经典结果。
- 最易错处：spacetime维数 = 空间维 + 1。需明确**对应哪个序参量的有效统计模型**（见N.3 replica结构）——这决定了"d"取几。

**步骤7（spacetime维数对账 ⟹ 树本质）**
- 描述：
  - 1+1D监测电路 → 有效统计模型 2D → RFIM在 d_l=2 → marginal/无序 → **1D命题B**。
  - 2+1D监测电路 → 有效统计模型 3D → RFIM在 d=3 > d_l → **小噪声有序存活 → 2D命题A（对态纠缠序参量）**。
  - 树电路 → 有效∞D → mean-field RFIM恒有序 → **树命题A**。
- 框架工具：电路d → 统计模型(d+1)D。
- 依据：标准 monitored-circuit → stat-mech 维数对应（与A的RG共识但我经RFIM而非β函数）。
- 最易错处：**树≠"d=∞的连续延拓"**——树是Cayley图（无环、Hausdorff维∞、谱维有限），它的鲁棒性本质 = **(a) RFIM永在临界维之上 + (b) expander指数冗余good-code**，两描述同源。**故"树无限分支维是鲁棒性本质"——答案：YES，但精确表述是"在RFIM下临界维 d_l=2 之上"或等价"码距线性标度的good-code"，二者在树上重合。有限维（尤其d≤2 spacetime的1D，及marginal的2D）不享有此性质。**

### N.3 2D三序参量分离 —— 真增量推导

**步骤8（为何三序参量映射到不同有效模型）**
- 描述：noisy mixed-state下，三个量的replica/倍化结构不同：
  1. **态纠缠熵 S(ρ_A)**（单条轨迹纯态的纠缠）：n→1 replica极限，映射到 **(d+1)D RFIM 畴壁自由能**。2+1D电路→3D RFIM→above d_l→**有限阈值可存活（命题A候选）**。
  2. **算符纠缠 S_op**（信道/酉算符的纠缠，Choi态）：**倍化Hilbert空间**（信道=doubled system，需≥2拷贝/4 replica）。倍化使噪声在doubled replica上作为**不可被边界约束抵消的强场**（无root-leaf约束边界来钉住），对应**有效更高replica对称的场relevant** → **任意 p>0 面积律（命题B）**。这正是2510.12743的"任意p死"。
  3. **相干信息 I_c = S(ρ_Q) - S(ρ_RQ)**（编码/可恢复性）：映射到擦除-渗流/Nishimori-line解码自由能。2+1D→3D随机键/随机场Ising的Nishimori多临界点→**有限阈值（命题A候选，"真MIPT"）**。
- 框架工具：replica倍化计数 + 每个序参量的有效统计模型。
- 依据：算符纠缠需doubled circuit（standard）；I_c=erasure-percolation/Nishimori（2412.16727、2505.22720）；S=RFIM畴壁。
- 最易错处：纯态、无噪声时三者同阈值（都退回同一MIPT）；**只有noisy mixed-state才分裂**。混用文献时易把"算符纠缠死"错推成"MIPT全死"。

**步骤9（分离阈值的次序与"真MIPT"指认）**
- 描述：2D下预言 **p_c^{op} = 0 < p_c^{S} ≲ p_c^{I_c}**：
  - 算符纠缠最脆（倍化、无保护边界、场relevant）→ 阈值0。
  - 态纠缠熵居中（3D RFIM above d_l，但纯态轨迹无主动纠错，受post-selection/边界条件牵制）。
  - 相干信息最韧（syndrome主动纠错 + 3D Nishimori，擦除阈值类比2D toric=50%的高擦除容限在3D更强）→ 最高、最可能有限。
- 描述续："**真MIPT**"——对noisy mixed-state问题，**operationally meaningful的是 coherent-information/编码转变**：它判定体积律相是否真的"存了可恢复的逻辑信息"，是与"信道是否能传信息"等价的物理判据。算符纠缠是信道复杂度诊断（可被经典模拟≠信息真丢），态纠缠熵在mixed-state下被经典关联污染。**故 p_c^{I_c} 是2D"真MIPT"的阈值，且最可能 >0（命题A）。**
- 框架工具：序参量operational意义排序 + 阈值次序。
- 依据：综合2510.12743(op死)/2412.16727(I_c=擦除渗流,2D toric擦除阈值50%)/2408.16267(I_c转变)。
- 最易错处：p_c^{I_c}>0 的"有限"是否需要**工程化纠错**（2406.14109/2408.16267都加了quantum-enhanced操作）？自攻击：若generic监测电路的内禀测量syndrome不足以达Nishimori有序，则 p_c^{I_c} 也可能被压到对数小。**这是2D命题A的最大软肋**，Phase2必须用数值/严格bound区分"内禀有限"vs"需工程化"。

**步骤10（F4/F6张力的解）**
- 描述：F4(2406.14109,Imry-Ma⟹声称2D活) vs F6(2510.12743,数值⟹2D算符纠缠死)**不是矛盾**：
  - F6测的是**算符纠缠**=序参量2=倍化模型→死（命题B）。✓
  - F4实际做的是**(2+1)d电路+工程化纠错使净场=0 的态/编码转变**=序参量1/3类→3D RFIM/可活（命题A），且F4的Imry-Ma是**否定2D统计模型**、迫使升到3D。✓
  - **两者测不同序参量、不同有效维 ⟹ 张力消解 = 序参量分离**。F4不证"算符纠缠活"，F6不证"相干信息死"。
- 框架工具：序参量分离 + 有效维对账。
- 依据：上述独立核实。
- 最易错处：必须核实F4是否真在generic噪声下活、还是只在工程化零净场下活——我的核实=**后者**（条件存活）。故F4对"generic 2D命题A"的支持**弱于A可能的解读**；真正撑generic 2D命题A的是 I_c=3D-Nishimori论证（我的步骤9），尚需Phase2坐实。
