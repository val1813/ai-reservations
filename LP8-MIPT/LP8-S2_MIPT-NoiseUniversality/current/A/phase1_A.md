## §1 结论预测（符号/量级/最易错步）

1. **方向预测：** p_noise^c(1D)=0（命题B）。源于 b=1 时KS无解 + 1+1D处随机场下临界维。
2. **量级预测：** 树阈值随b的崩塌行为 θ_c=1/√b ⟹ 临界保真度 1-θ_c ~ (1-1/√b)，b→1时阈值窗口 ∝ (b-1) → 0线性闭合。对应 p_noise^c(b) ~ c·(b-1) + O((b-1)²)。
3. **2D预测：** 边际/存活（命题A），因 3D随机场Ising有有限场阈值。**但需对照2510.12743的反向证据。**
4. **最易错步：** 把"信息重构转变(coding)"与"纠缠熵转变"混为一谈。两者在无噪声MIPT重合，但**噪声下可能分离**——这是2D张力的根源，也是唯一可能的增量入口。

## §2 强制撞墙（攻击核心假设，写明为何不成立）→ 反例栏(GATE1)

**撞墙靶心：攻击"p_noise^c(1D)=0=命题B"这一本Phase主结论。** 构造命题A(1D存活)的最强辩护并检验其是否成立。

**反例候选RA-1（攻击主结论，为命题A辩护）：**
"1D体积律相由随机Clifford的scrambling保护信息，类似一个码距∝L的动态纠错码；既然码距随L增长，应有有限擦除阈值(阈值定理) ⟹ p_noise^c(1D)>0(命题A)。"

**检验/反驳：** 不成立。1D局域随机电路在深度t生成的稳定子码，其码距受**线性光锥**限制：信息在L_eff~min(vt, L)内传播，单条逻辑信息的冗余路径数=多项式(非指数)。擦除阈值定理要求**扩展性(expander)/指数冗余**(如Bethe树/LDPC好码)；1D局域几何不是expander(等周常数→0)。定量地：F5(2510.07512) Thm VI.1严格证明 d>p^{-1}log(1+1/r) 时相干信息<0，对**任意架构**成立，包括1D——常数噪声下编码相深度受限~1/p，L→∞不存活。⟹ RA-1被驳，命题A(1D)不成立，主结论(命题B)经受撞墙。

**反例候选RA-2（攻击b→1延拓，攻击H3）：**
"b→1极限可能不连续：树在任意b>1有p_noise^c>0，b=1突然=0，说明1D不是树的极限，A框架(1)的'b作连续参数'非法 ⟹ 不能用树推断1D。"

**检验：** RA-2**部分成立**——b=1确是奇异点(对应渗流/有序的下临界维)。但这**强化**而非削弱主结论：奇异退化正是"1D定性不同于树"的体现，即树鲁棒性是b>1(mean-field/expander)特例。KS阈值 θ_c=1/√b 在b→1⁺解析趋于θ_c=1(零噪声窗口)，故"阈值连续闭合到0"在阈值变量上是连续的，无矛盾。⟹ RA-2不能救命题A，反而佐证命题B的"特例"判词。

**反例候选RB-1（攻击命题B在2D的外推，为2D命题A辩护——真实存活反例）：**
"2406.14109用Imry-Ma论证2+1D电路(=3D随机场Ising)有有限阈值 ⟹ 2D命题A。但2510.12743数值称2D任意常数噪声→算符纠缠面积律(命题B)。二者矛盾——若2510.12743对，则Imry-Ma的命题A判据失效，连2D都死。"

**检验：未解。** 这是**真实的文献反例/张力**，A博士无法在本Phase单方判决。可能解释：(i)算符纠缠S_op ≠ 态纠缠熵 ≠ 编码相干信息，三者噪声阈值分离；(ii) 2510.12743的"常数per-site噪声"对应的stat-mech场强可能恒在ordered相之外。**此反例不攻击主结论(1D命题B,各序参量一致死)，但攻击"2D命题A"展望，且是唯一真实开放点。写入反例栏。**

**GATE1反例栏产出：** RA-1(驳，主结论稳)、RA-2(部分成立但佐证命题B)、RB-1(真实开放张力，仅影响2D展望)。主结论p_noise^c(1D)=0经受全部撞墙。

## §N 推导正文

### §N.1 路径1：树→经典Markov映射，b→1极限（A框架(1)）

**N.1.1 映射结构（引用禁区B0.1，不重推）。**
Ravindranath et al.(2503.05027)把树电路在测量+噪声下的信息保持动力学映射到**树上的经典Markov过程**。根上编码1 bit(或量子信息)，沿树向叶子传播，每条边经历噪声信道N，每个节点可被测量。"是否能从叶子重构根的信息"即转变序参量。这在概率论中是**树上广播/重构问题(broadcasting/reconstruction on trees)** 的标准结构。

**N.1.2 阈值=Kesten-Stigum条件（H2，标准结果）。**
设每条边的噪声信道转移矩阵第二大本征值为 θ（θ∈[0,1]，θ=1无噪声，θ↓随p_noise↑）。分支比b的树上，根信息可从无穷远叶子重构的**充分阈值(robust/census reconstruction)** 为：
```
   b · θ² > 1          (Kesten-Stigum, KS)
⟺ θ > θ_c = 1/√b
⟺ p_noise < p_noise^c(b),   其中 θ(p_noise^c)=1/√b
```
- 2态对称(Ising)信道：KS紧(Bleher-Ruiz-Zagrebnov; Evans-Kenyon-Peres-Schulman 2000)。
- 多态信道：真阈值可能 < KS(Mossel-Peres)，但**仍要求 b>1**。

物理意义：θ²是单边信息保真平方(两次用于互信息/重构判据)，b是路径冗余度。b·θ²>1 = "冗余增长率 > 噪声衰减率" = 信息在指数多路径上存活。

**N.1.3 b→1极限（核心增量计算）。**
取b→1（每节点1子，树退化为1D链）：
```
   KS条件 b·θ²>1  →  θ²>1  →  θ>1
```
对任意非平凡噪声 θ≤1，**无解**。故：
```
   p_noise^c(b=1) = 0.
```
更精细地，阈值窗口随b的闭合速率：θ_c(b)=b^{-1/2}=1-½(b-1)+O((b-1)²)。若噪声信道近临界处 θ(p_noise)≈1-κ·p_noise(线性化，κ>0信道相关常数)，则
```
   p_noise^c(b) ≈ (1-θ_c)/κ = (b-1)/(2κ) + O((b-1)²)  →  0   (b→1⁺).
```
⟹ **阈值线性闭合到零，1D无有限噪声阈值。命题B。** 树(b≥2)的有限鲁棒性正是 b>1 的指数路径冗余(expander/mean-field)所致，与苏格拉底第一/二轮(Bethe有限温有序、expander擦除阈值)结构同构。

**反驳检验：** b是否真能取连续值1<b<2？物理树b∈{2,3,...}整数。但KS判据 b·θ²=1 对实b解析，且1D链=b=1严格定义。结论"b=1处阈值=0"不依赖中间连续性，只依赖两端点(b=1链 vs b≥2树)与KS单调性。稳健。

### §N.2 路径2：1+1D MIPT不动点上噪声算符的RG标度维数（A框架(2)）

**N.2.1 stat-mech映射与噪声=随机场（H4,H7）。**
1+1D无噪声MIPT映射到2D有效统计模型（Clifford→2D渗流；Haar→2D Q→1 Potts/replica磁体，Jian-You-Vasseur-Ludwig）。体积律=有序相(DW张力有限/纠缠面积来自畴壁长度~体积)，面积律=无序相。bulk退相干噪声在此映射中=一个耦合到序参量(畴壁/自旋)的**场**。因测量结果与噪声实现随机，该场是**淬火随机场** h(x)，⟨h⟩=0, ⟨h²⟩∝p_noise。

**N.2.2 relevance判据：随机场下临界维(H5)。**
随机场扰动 ∫d^d x h(x)·O(x) 的relevance由Imry-Ma/Aizenman-Wehr严格结果给出：**短程随机场破坏连续/离散对称有序的下临界维 d_lc=2**。
- d=2(即1+1D电路)：恰在下临界维，**随机场relevant**——任意弱随机场破坏长程有序。Imry-Ma能量标度：畴(尺度R)的体场涨落 ~ R^{d/2}=R，畴壁能 ~ R^{d-1}=R；d=2两者同标度，场总赢(对数边际) ⟹ 无序。
  ```
  ⟹ Δ_noise < d=2 (relevant) ⟹ 任意p_noise>0冲离临界点 ⟹ p_noise^c(1D)=0. 命题B.
  ```
- d=3(即2+1D电路)：d>d_lc=2，**随机场irrelevant**(弱场下有序存活，3D随机场Ising有有限场阈值h_c) ⟹ p_noise^c(2D)>0。**命题A(2D)。**
- 树(d_eff→∞, mean-field)：远高于下临界维，场irrelevant，有限阈值——复现Ravindranath命题A，与路径1的b>1一致。

**N.2.3 两路径自洽。**
路径1(b·θ²=1, b=1临界)与路径2(随机场下临界维d_lc=2, d=2临界)给出**同一维度边界**：1D/链/b=1 = 下临界 ⟹ p_noise^c=0；2D/3D-stat-mech/b>1 = 超临界 ⟹ p_noise^c>0。两个独立框架(概率论广播 vs 统计场论RG)收敛于同一二值判定，互为交叉验证。

**反驳检验：** Δ_noise是否真<2？Imry-Ma是能量标度论证非严格算符维数计算。但Aizenman-Wehr定理(严格)证明 d≤2短程随机场无SSB，等价于场relevant。故判据稳健，无需显式CFT算符谱。⚠️残留：MIPT不动点是非幺正/replica n→0或Q→1的非标准CFT，Imry-Ma的"短程、能量标度"前提在此类无序临界点是否完全适用，未严格核验(卡点候选)。

### §N.3 可执行数值方案（A框架(3)，不要求实跑）

**目标：** 数值确证 p_noise^c(1D)=0，并测 p_noise^c(b)→0 的崩塌指数。

**N.3.1 1D Clifford+Pauli噪声(stabilizer可模拟)。**
- 模型：1D brick-wall随机Clifford两比特门 + 概率p_meas单比特Z投影测量 + 概率p_noise单点Pauli(去极化/dephasing)噪声。L≤1000，深度T~O(L)。CHP/Aaronson-Gottesman稳定子模拟，混合态用稳定子+destabilizer或稳定子秩跟踪。
- 序参量(混合态适配，关键)：
  (a) **编码/相干信息** I_c(R⟩S)：参考比特R与系统最大纠缠，跟踪 I_c=S(R)-S(RS) 符号(>0可纠错/编码相，<0不可)。
  (b) **纯化序参量**(Gullans-Huse)：ancilla纠缠熵 S_anc(t) 衰减率。
  (c) **算符纠缠/三分互信息** I_3（对照2510.12743）。
  **三个序参量分别测——其阈值是否分离正是2D张力的判据。**
- 扫描：(p_meas, p_noise)网格。对每点测序参量 vs L。
- **判定与预测：** 固定任意 p_noise>0，体积律/编码相窗口宽度 Δp_meas(L) 随L如何？
  - 命题B预测：窗口 → 0 当 L→∞（任意噪声下无稳定临界点），等价编码深度 d*~1/p_noise 有限(F5 Thm VI.1)。
  - 命题A(被驳)预测：窗口收敛到有限值。
  画 p_meas^c(L,p_noise) 外推 L→∞，验证窗口闭合 ⟹ p_noise^c=0。

**N.3.2 b→1插值(检验路径1)。**
- 在有限Cayley树(分支b=2,3)与"准1D"几何(b介于1与2，如周期性分支)上跑同一Clifford+噪声，测 p_noise^c(b)。
- 预测：p_noise^c(b) ~ (b-1)/(2κ) 线性闭合(N.1.3)。可外推确认 b→1 时→0。

**N.3.3 资源与可行性：** 稳定子+Pauli噪声严格高效(O(L²)/层)，L≤1000、T~L、~10²轨迹平均，单机可行。非Clifford/器件噪声谱出Phase2/3范围(声张声明)。
