# 研究计划 — LP2-B1

## 北极星
LP2-B1: 是否存在一个m*-independent的Planckian判据，能够替代α并保持S1的弱普适性结论？

## 驱动矛盾

命题A（m*污染可去耦）：存在一个对m*处方不敏感的判据，例如η/s、谱函数宽度、光学散射率或Drude权重重组后得到的无量纲量；该判据在LP2-S1的材料集上仍呈单峰/弱普适。

命题B（m*污染不可去耦）：所有候选判据都仍受m*、n、FS几何或温度窗口影响；“m*-independent”只是把处方依赖转移到别的观测量，不能给出真正更干净的普适量。

## 核心障碍

1. 候选判据之间不在同一观测层级。
2. η/s通常需要流体力学或强耦合极限，不是所有材料都可直接提取。
3. 谱函数和光电导的宽度定义依赖频率窗口与顶点修正。
4. Drude权重去耦仍可能把n或FS信息藏回去。

## 方法论

- Phase 1: 枚举候选判据并按处方依赖分级
- Phase 2: 形式化处方无关定义，找正交补
- Phase 3: 判定是否存在真正可替代α的m*-independent量

## 预期产出

- 若找到：LP-2进入更高等级的判据重写
- 若找不到：明确“m*-independent判据不可达”，但保留S1弱普适性作为经验结论
