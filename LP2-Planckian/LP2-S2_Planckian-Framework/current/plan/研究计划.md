# 研究计划 — Planckian-S2

## 北极星
LP2-S2: 各理论框架在统一数据集上的预测能力比较

哪个理论框架能最好地解释S1发现的α分布模式（弱普适μ≈1，但MATBG电子/空穴不对称+I²=50%类内变异）？特别是：为什么MFL耦合常数λ~1/π在不同QCP中近似普适？

## 驱动矛盾
命题A（普适机制）：存在单一理论框架（Kondo破坏QCP / 't Hooft anomaly / SYK），扣除材料修正后能预测α≈1，且该框架在统一数据集上的预测信息量显著高于竞争者。

命题B（多机制/运动学）：没有单一框架胜出——要么多个框架对不同材料类各自适用（α由系统参数决定，TB1/TB2/TB3），要么α≈1是运动学界限的统计选择效应（TK*），与微观机制无关。

**关键张力（来自S1）：** S1已证弱普适+强普适不成立。S2要回答的是：这个"弱普适"是某个动力学框架的预测，还是多框架的偶然交汇（运动学墙）？

## 核心障碍
1. **预测能力≠拟合优度：** 有可调参数的框架(无序强度/Stoner因子/能隙)可事后拟合任意α。必须用WAIC/LOO-CV惩罚自由参数，区分"零参数预测α=1"vs"有参数拟合"。
2. **'t Hooft anomaly不预测α数值**（已验证CX1）：该框架只固定无能隙DOF的存在，不固定散射率系数→在"α预测"维度信息量为零。
3. **SYK混沌率≠输运率**（CX2）：MSS界限是关于scrambling，与1/τ_tr的关系无严格推导。
4. **m*处方污染**（CX7）：所有框架的α预测都受m*定义模糊性影响（同材料差22倍）。
5. **数据有限**：S1的~40点数据按材料类分组后每类样本少，模型比较的统计功效受限。

## Phase 3 任务（两个互斥出口）
- A：判定α=ℏ/(τ_tr k_BT)≈1在统一QO处方下，能否化归为一个**不假设α≈1**的独立约束(候选：流体力学最小粘滞η/s、FDT、熵产生率bound)，并尝试从该约束**derive** λ~1/π。能→出口2(真约束)；不能→出口1(同义反复)。
- B：构造"同义反复判据"——形式化"选择m*使α=1"与"α=1是物理"的可分离性。任何满足Luttinger计数的m*都给α≈1=同义反复；只有物理m*给α≈1而其他给α≠1=真约束。用S1-K1.2(CeCoIn₅ 22倍)做检验石。
