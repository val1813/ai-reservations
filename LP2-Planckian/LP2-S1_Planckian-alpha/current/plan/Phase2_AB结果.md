## A博士：层次贝叶斯Meta-Analysis

### 核心结果

**1. 类别间异质性（统一QO/比热质量处方）：**
- Q_between = 3.60, df = 6, p = 0.730
- τ²_between = 0（DL估计截断为零）
- I²_between = 0%
- μ_global = 0.978 ± 0.053, 95%CI = [0.875, 1.081]

**结论：类别间方差为零。所有材料家族共享同一个全局均值。**

**2. 全局异质性：**
- Q_total = 40.14, df = 20, p = 0.005（显著）
- τ²_total = 0.037
- I²_total = 50.2%（中等）
- 95%预测区间 = [0.548, 1.395]

**结论：存在超出测量误差的真实异质性，但来自类别内部离群值（MATBG α=0.3, Fe-based α=2.2），非系统性类别间差异。**

**3. 两种m*处方对比：**
- BF(heterogeneous/universal) = 8.0 × 10⁷（决定性证据）
- QO质量 → α ≈ 1.14
- A系数质量 → α ≈ 0.08
- 比值：14倍，p = 1.0 × 10⁻⁹

**结论：两种处方在统计上完全不可调和。**

**4. GMM模型选择：**
- BIC选K=1（单峰），Akaike权重 w(K=1) = 0.78
- 单一高斯：μ = 0.97, τ_intrinsic = 0.18

**结论：无证据支持多峰分布。**

### A博士⚡审核入口

- **本Phase结论：** α的普适性是条件性的——在统一QO/Cp质量处方下成立（μ=0.97, I²_between=0%），但完全依赖于m*选择
- **最脆弱的一步：** m*赋值无模型无关方法判定
- **预测vs实际：** 预测家族间差异显著→实际家族间方差=0；异质性来自家族内部
- **PI需关注：** MATBG α=0.3是2σ离群值；核心哲学问题——如果m*有歧义，Planckian bound是物理约束还是同义反复？

## B博士：信息论独立攻击

### 核心结果

**攻击1：互信息检验**
- MI > 0（bootstrap CI排除0），但置换检验边缘（p~0.10）
- 判断：INCONCLUSIVE（统计功效不足，需N>120）

**攻击2：截断/选择效应排除**
- 观测：90%的α落在[0.7,1.5]
- 截断模型预测：仅16-34%
- KS检验拒绝截断解释（p=0.001）
- 极端值统计使预测更差（推向错误方向）
- **判断：SUPPORTS UNIVERSALITY。聚集是内禀的，不是边界效应。**

**攻击3：MATBG受控证伪**
- 同一材料内：电子侧α~1.3 vs 空穴侧α~0.3（比值4.3x）
- BF = 474（决定性证据）
- I(filling; α) = 1.0 bit（最大值）
- **判断：FALSIFIES STRONG UNIVERSALITY（α=1±0.5被证伪）**
- 但α是O(1)和α≤C~2-3（界存在）仍存活

**攻击4：m*规范自由度 / KW起源**
- A₁与m*相关：r = 0.83, p = 0.022
- A₁变化2000x，m*变化100x，α仅变化7x
- MFL推导：α = πλ，λ~1/π在QCP
- A₁不普适（p=0.015）而α是（7x压缩）
- **判断：α~1是REAL但DERIVATIVE——等价于广义KW标度**

### B博士⚡审核入口

- **本Phase推进了什么：** 排除截断解释；形式化MATBG为受控证伪；从KW推导α~1；连接MFL理论α=πλ
- **最关键跨域连接：** KW标度 + MFL自能 + 信息信道 = α~1从λ~1/π涌现
- **预测vs实际：** 截断拒绝比预期更强；MI比预期弱；MATBG确认最强
- **卡在哪里：** 为什么λ~1/π跨越不同QCP？（理论空白）

### 无直接矛盾。AB结论互补。

### 综合判断

**Phase 2核心结论（K2.1）：**

Planckian耗散系数α的普适性是**条件性的**（conditional universality）：
1. 在统一QO/比热质量处方下，α = 0.97 ± 0.05（全局均值），材料家族间方差为零
2. 但这一"普适性"等价于广义Kadowaki-Woods标度（A₁ ∝ m*），由MFL自能自然产生（α = πλ）
3. 强普适性（α = 1 ± 0.5）被MATBG受控实验证伪（BF = 474）
4. Planckian界（α ≤ C ~ 2-3）作为运动学上界存活，被强耦合扇区饱和

**对LP-2长命题核心矛盾的回答：**
- 命题A（单一机制普适）：部分成立——α≈1反映MFL自能的普适结构（λ~1/π）
- 命题B（多机制运动学截断）：部分成立——界存在，但聚集不是截断效应
- **真实答案在A和B之间：** α~1是MFL/KW标度的涌现结果，不是单一微观机制，也不是纯运动学截断

**未解决的核心问题：** 为什么不同QCP（铜氧化物/重费米子/铁基）的MFL耦合常数λ都≈1/π？这是LP2-S2需要回答的问题。
