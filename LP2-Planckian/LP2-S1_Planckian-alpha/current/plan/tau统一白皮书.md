## A. 费米液体中的标准关系

### A1. 基本定义

**单粒子寿命（自能定义）：**
1/τ_sp = -2 Im Σ(k_F, ω=0, T)

**物理准粒子寿命（Green函数极点）：**
1/τ_qp = Z · |Σ''| = Z/τ_sp
其中 Z = [1 - ∂_ω Re Σ]^{-1}，质量重整化 m*/m_b = 1/Z

**输运弛豫时间（Boltzmann方程）：**
1/τ_tr = ∫dΩ' W(θ)(1-cosθ) / ∫dΩ' W(θ)
(1-cosθ)因子压制前向散射

**Planckian时间：**
τ_P = ℏ/k_BT

### A2. 标准转换

τ_tr与τ_sp的关系：
1/τ_tr = (1/τ_sp) · <1-cosθ>_W

- 各向同性s波散射：<1-cosθ> = 1 → τ_tr = τ_sp
- 小角散射主导（FM QCP, z=3）：<1-cosθ> ~ (Δk/k_F)² ~ T^{2/3} → ρ ~ T^{5/3}

Hall散射时间：
cot θ_H = ρ_xx/ρ_xy = 1/(ω_c τ_H)
单带Drude中 τ_H = τ_tr

Drude电导率：
σ = ne²τ_tr/m*，ρ = m*/(ne²τ_tr)

**关键：Z从电阻率中消去。** ρ ∝ -Σ''(T)，与Z无关。

### A3. Hall角两寿命分离（铜氧化物）

实验事实：
- ρ_xx = ρ₀ + A₁T （1/τ_tr ∝ T）
- cot θ_H = α + βT² （1/τ_H ∝ T²）

Coleman-Schofield-Tsvelik (1996) 解释：
- Γ_tr = (Γ_f + Γ_s)/2 （算术平均，快模式主导）
- Γ_H = 2(Γ_f⁻¹ + Γ_s⁻¹)⁻¹ （调和平均，慢模式主导）

## B. 非费米液体中的修正

### B1. Z→0极限

边际费米液体(MFL)：1/Z = 1 + (2λ/π)ln(T*/T)
物理散射率：1/τ_qp|_MFL = [λ/(1+(2λ/π)ln(T*/T))] · k_BT/ℏ ≤ 1.57/ln(T*/T) · k_BT/ℏ
→ MFL自动满足Planckian界（对数亚Planckian）

### B2. 顶点修正分类

| 散射机制 | 顶点修正效果 | τ_tr vs τ_sp |
|---------|------------|-------------|
| 各向同性（接触相互作用） | 无修正 | τ_tr = τ_sp |
| 小角散射（FM QCP, z=3） | 强压制 | τ_tr ≫ τ_sp |
| 杂化涨落（带间散射） | 修正次领头阶 | τ_tr ≈ τ_sp |
| 密度波QCP（热点散射） | 冷区短路 | τ_tr ≫ τ_sp(hot) |

### B3. 杂化涨落使τ_tr = τ_sp的条件（Paul-Pépin-Norman 2013）

条件：
1. 两带质量比 α = m_c/m_f ≪ 1
2. 费米面近似匹配 q*/k_F ≪ 1
3. 相互作用为杂化涨落（带转换），非密度-密度散射
4. 临界玻色子过阻尼

物理原因：轻电子散射到重带后出射方向完全随机化（θ≈π），(1-cosθ)≈2

### B4. Z→0时τ_tr的操作意义

Z从电阻率中消去：ρ(T) ∝ -Σ''(T)
即使准粒子不存在，从Drude公式提取的"τ_tr"仍有操作意义，但不再对应准粒子物理寿命。

## C. α的操作性定义

### C1. 从DC电阻率提取 α_ρ

对 ρ = ρ₀ + A₁T：
1/τ_tr = (ne²/m*) · A₁ · T
定义 1/τ_tr = α_ρ · k_BT/ℏ：

**α_ρ = (ℏ·n·e²/m*·k_B) · A₁**

### C2. 从光电导提取 α_σ

扩展Drude模型（记忆函数形式）：
σ(ω) = (ω_pl²/4π) · 1/[Γ(ω) - iω(1+λ(ω))]
Γ(ω) = (ω_pl²/4π) · Re[1/σ(ω)]

α_σ(ω→0, T) = (ℏ/k_BT) · Γ(ω→0, T)

### C3. 从ADMR提取 α_ADMR

角度依赖磁阻直接给出动量分辨的τ_tr(k,T)：
α_ADMR(k) = (ℏ/k_BT) · 1/τ_tr(k,T)

### C4. 从Hall角提取 α_H

cot θ_H = (m*/ne²B) · 1/τ_H
若 cot θ_H = α + βT²：
α_H(T) = (ℏ·ne²B·β/m*k_B) · T （随T线性增长）

## D. 关键歧义源

### D1. 有效质量m*的选择

| 质量定义 | 物理来源 | 测量方法 | 与Z的关系 |
|---------|---------|---------|----------|
| 带质量 m_b | 裸色散ε_k | DFT | — |
| 热力学质量 m*_th | 比热γ | 比热 | m*_th/m_b = 1/Z |
| QO质量 m*_dHvA | Lifshitz-Kosevich | dHvA/SdH | ≈ m*_th |
| 光学质量 m*_opt(ω) | 1+λ(ω) | 扩展Drude | 频率依赖 |
| Mott质量 m*/m = 1/p | Mott局域化 | 熵/光学 | 非FL重整化 |

**Hartnoll-Mackenzie处方**：用重整化质量m*（QO或比热），因为物理寿命由Green函数极点决定。
**Taupin-Paschen争议**：重费米子中用A系数最大质量→α≪1；用QO质量→α≈1。

### D2. 载流子密度n的选择

| n的定义 | 物理含义 | 方法 |
|--------|---------|------|
| Luttinger count n_L | 费米面围成体积 | QO频率 |
| Hall数 n_H = 1/(eR_H) | Hall系数倒数 | Hall测量 |
| 光学谱权 n_opt | ω_pl² = 4πne²/m_b | 光学积分 |

### D3. 多带效应

σ_total = Σᵢ nᵢe²τᵢ/mᵢ*
问题：平行导电通道使提取的"平均τ"无内在物理意义
部分解决：ADMR分辨动量依赖寿命

### D4. 弹性vs非弹性散射

Planckian界仅适用于非弹性散射：1/τ_inel ≲ k_BT/ℏ
通过减去ρ₀分离，但Matthiessen规则有效性本身是假设

### D5. 电子-声子散射

T ≫ T_ph时：1/τ ≈ 2πλ_{e-ph} · k_BT/ℏ
看似超Planckian（α = 2πλ_{e-ph}），但此时声子散射准弹性，不受Planckian界约束

## E. 操作性决策树

```
1. 确定ρ(T)线性区间 → 拟合A₁
2. 确定m*来源：
   - 有dHvA → m*_dHvA（最可靠）
   - 无dHvA → 比热γ推导m*_th
   - 均无 → 光学谱权（需假设n）
3. 确定n来源：
   - 有QO → Luttinger count
   - 无 → Hall数（注意T依赖性）
4. 计算 α_ρ = (ℏne²/m*k_B)·A₁
5. 交叉验证：
   - 与光学α_σ比较
   - 检查多带效应
   - 检查弹性散射贡献
```

## F. 对meta-analysis的关键影响

**核心发现：α的数值强烈依赖于m*的选择。**

同一材料（如CeCoIn₅）：
- 用QO质量 → α ≈ 1.0 (Bruin 2013)
- 用A系数最大质量 → α ≈ 0.045 (Taupin 2022)

这意味着meta-analysis必须：
1. 对每个数据点标注m*来源
2. 分别用统一的m*处方重新计算α
3. 检验"α普适性"是否依赖于m*选择——这正是苏格拉底命题的核心
