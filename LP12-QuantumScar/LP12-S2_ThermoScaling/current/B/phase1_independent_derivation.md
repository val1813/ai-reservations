## 第一章：RMT框架——QMBS作为谱离群值

### 1.1 一般性设定

考虑一个具有局部相互作用的量子多体系统，希尔伯特空间维数 D = d^L（d为局域维数，L为系统尺寸）。

总哈密顿量：
```
H = H_0 + λ V
```
其中 H_0 包含疤痕态 |ψ_scar⟩ 作为精确本征态（如PXP模型中的Z₂态），V 为破坏疤痕的微扰项（如实验中的残差相互作用或面外磁场）。

**RMT假设**：当 L 充分大时，H 在热子空间中的投影 H_thermal 可以用Wigner-Dyson系综（GOE/GUE，取决于时间反演对称性）描述。

### 1.2 Rosenzweig-Porter系综映射

将疤痕态视为秩-1扰动：
```
H = H_WD + λ |ψ_scar⟩⟨ψ_scar|
```
其中 H_WD 为 D×D 的GOE随机矩阵。

**定理1（Rosenzweig-Porter谱统计）**：秩-1扰动 H_WD + λ |ψ_0⟩⟨ψ_0| 的谱统计由单参数决定：
```
t = λ^2 D / (2π^2 σ^2)
```
其中 σ^2 为 H_WD 对角元的方差。

证明概要（参见Guhr 1998, Haake 2010）：
- 在H_WD的本征基 {|E_n⟩} 中，扰动矩阵元为：
  V_{mn} = λ ⟨E_m|ψ_scar⟩⟨ψ_scar|E_n⟩ = λ φ_m^* φ_n
  其中 φ_n = ⟨E_n|ψ_scar⟩

- 这是一个秩-1矩阵。根据Rosenzweig-Porter理论，谱统计从Wigner-Dyson（t → ∞）过渡到Poisson（t → 0）的临界点在：
  t_c = 1 ⇒ λ^2 D / (2π^2 σ^2) = 1

- 当 t >> 1 时，扰动足够强以改变谱统计 → 疤痕态作为离群值存活
- 当 t << 1 时，扰动被热谱淹没 → 疤痕态热化消失

### 1.3 热力学极限下的关键推导

对于量子多体系统：D = d^L，因此：
```
t(L) = λ^2 d^L / (2π^2 σ^2)
```

**引理1**：对于任何固定 λ > 0（即不随 L 缩放的微扰强度），
```
lim_{L→∞} t(L) = ∞
```
证明：d^L 指数发散，λ^2 为正常数，分子指数增长 → t(L) → ∞。

**推论1**：在热力学极限下，任何固定强度的微扰都会导致 Rosenzweig-Porter 参数 t → ∞，这意味着疤痕态在谱统计层面完全融入热谱，不再作为离群值存在。

**证伪条件**：若发现某系统 t(L) 不随 L 发散，则必有以下情况之一：
- (a) λ(L) ~ d^{-L/2} 或更快衰减 → "自保护疤痕"
- (b) 系统不在GOE类中（如可积或多体局域化）
- (c) 疤痕态的参与比（IPR）异常的大的 → 非遍历但非疤痕

### 1.4 疤痕本征态的IPR分析

疤痕态 |ψ_scar⟩ 在热本征基中的展开系数 φ_n = ⟨E_n|ψ_scar⟩ 的统计性质可由Inverse Participation Ratio (IPR) 刻画：

```
IPR(ψ_scar) = Σ_n |φ_n|^4
```

**RMT预言**：对于随机向量（热态）：
```
IPR_thermal = 3/D  (GOE, 大D极限)
```
对于疤痕态（部分局域在能量空间）：
```
IPR_scar ~ D^{-τ/2}  (0 < τ < 2, 多分形)
```

**引理2**：在 Rosenzweig-Porter 模型中，瘢痕态的IPR标度为：
```
IPR_scar(L) = 
  - O(1)               当 t << 1（疤痕存活）
  - O(D^{-1/2})        当 t ~ 1（临界）
  - O(D^{-1})          当 t >> 1（热化）
```

推导（Kravtsov et al. 2015）：
```
IPR = [1 + (λ^2 D)/(2π^2 σ^2)]^{-1} + O(D^{-1})
     = [1 + t]^{-1} + O(D^{-1})
```

在TL下 t → ∞：
```
lim_{L→∞} IPR_scar(L) = 0
```

这等价于：疤痕态与热态的区分度在TL下消失 → 精确疤痕本征态不存在。

### 1.5 能级间距分布

GOE的最近邻能级间距分布：
```
P_GOE(s) = (π/2) s exp(-π s^2 / 4)
```
特征：能级排斥 → P_GOE(0) = 0

Poisson分布（可积系统）：
```
P_Poisson(s) = exp(-s)
```
特征：无排斥 → P_Poisson(0) = 1

**平均能级间距比** ⟨r⟩ 作为诊断量：
```
r_n = min(s_n, s_{n+1}) / max(s_n, s_{n+1})
⟨r⟩_GOE = 0.530 (GOE), 0.600 (GUE), 0.386 (Poisson)
```

**预言**：若疤痕态在TL下存活，它应导致附近能级的谱统计偏离GOE → ⟨r⟩ 偏离0.530。但Rosenzweig-Porter分析表明：
```
⟨r⟩(L) = ⟨r⟩_GOE + O(t^{-1}) = ⟨r⟩_GOE + O(d^{-L})
```
即 ⟨r⟩ 以指数速度收敛到GOE值 → TL下无疤痕的谱统计痕迹。

## 第二章：动力学复兴的RMT推导

### 2.1 Fidelity复兴的谱表示

量子revival fidelity：
```
F(t) = |⟨ψ(0)|ψ(t)⟩|^2 = |Σ_n |φ_n|^2 e^{-iE_n t}|^2
```

在RMT框架中，能谱 {E_n} 服从Wigner-Dyson统计，系数 {|φ_n|^2} 为疤痕态在热基中的展开。

**定理2（RMT的复兴振幅标度）**：
对于一般非可积系统，最长的复兴时间（递归时间）由能级间距的倒数给出：
```
t_revival ~ 1/Δ  (Δ为平均能级间距)
```
其中 Δ ∝ D^{-1} = d^{-L}，因此：
```
t_revival ~ d^L  →  指数级长
```

但是，这是指"完全复兴"（F(t) ~ O(1)）的时间。部分复兴（F(t) > 1/D）的时间更短。

### 2.2 部分复兴与Thouless时间

在RMT框架中，量子动力学的三个时间尺度：
1. **Thouless时间** t_th：系统"感受到"谱离散性的时间
   ```
   t_th ~ 1/Δ_Thouless ~ L^2/D_sp (扩散系统)
   ```
   对非扩散系统（如PXP），t_th ~ O(L^z)（z为动力学指数）

2. **Heisenberg时间** t_H = 2π/Δ ~ d^L：复兴的精确周期

3. **疤痕复兴时间** t_scar_revival：疤痕态部分复兴的特征时间

**关键推导**：在RMT框架中，疤痕动力学的fidelity衰减形式为：
```
F_scar(t) ≈ |Σ_n |φ_n|^2 e^{-iE_n t}|^2
         ≈ |∫ dE ρ_scar(E) e^{-iEt}|^2
```

其中 ρ_scar(E) = Σ_n |φ_n|^2 δ(E - E_n) 是疤痕态的局域态密度（LDOS）。

**引理3**：在Rosenzweig-Porter框架中，LDOS的半高全宽为：
```
Γ_scar ~ λ^2 / (2π σ^2)  (独立于L!)
```

这意味着疤痕态在能量空间的展宽是有限且与L无关的。因此：
```
F_scar(t) ~ exp(-Γ_scar t) × [振荡项]
```

乘以谱离散性导致的准周期调制：
```
F_scar(t) ~ exp(-Γ_scar t) × F_quasiperiodic(t)
```

**推论2**：
- 在 t << 1/Γ_scar 时：F(t) ≈ F_quasiperiodic(t)，可见疤痕revival
- 在 t >> 1/Γ_scar 时：F(t) → 0，疤痕revival被指数包络压制
- 复兴振幅的衰减时间：τ_dyn = 1/Γ_scar = 2πσ^2/λ^2（独立于L）

**这与A博士框架的关键分歧**：
- A博士引用Lin(2020)：τ ~ O(λ^{-1/(1+d)})，指数依赖于维度d
- B博士RMT预言：τ ~ O(λ^{-2})，与维度d无关，且不随L增长

### 2.3 预加热（Prethermalization）的RMT解释

预加热现象在RMT框架中获得自然解释：
- 短时间（t < t_th）：系统未完全遍历 → 可见疤痕revival
- 中等时间（t_th < t < t_H）：谱刚性开始显现 → 复兴振幅代数衰减
- 长时间（t ~ t_H）：完全的量子递归 → F(t) ~ 1/D

**定理3（RMT预加热时间）**：
```
t_prethermal ~ min(t_th, 1/Γ_scar)
```

对于PXP模型（d=2, Turner 2018数据）：
- t_th ~ L（因PXP为约束动力学，有效z=1）
- 1/Γ_scar ~ 1/λ^2 ≈ 常数（对给定微扰）

因此总预加热时间：
```
t_prethermal ~ min(L, 1/λ^2)
```

**预言1**：在弱微扰极限（λ << 1），t_prethermal ≈ L，线性增长而非指数。

**预言2**：当L > 1/λ^2时，t_prethermal饱和为常数1/λ^2，不再随L增长。

这是一个强可证伪预言——与Alhambra(2020)和Ma(2022)的指数增长τ~exp(cL)根本冲突。

## 第三章：量子信息论辅助约束

### 3.1 Fannes-Audenaert不等式

对于两个态 ρ 和 σ，其保真度的下界可以由迹距离约束：
```
1 - √F(ρ, σ) ≤ (1/2) ||ρ - σ||_1
```

Fannes-Audenaert不等式：
```
|S(ρ) - S(σ)| ≤ (1/2) T log(d-1) + H_2(T/2)
```
其中 T = ||ρ - σ||_1，H_2(x) = -x log x - (1-x) log(1-x)，d为有效维度。

**定理4（量子信息论的复兴上界）**：
考虑从初态 |ψ_scar⟩ 演化，任意时刻 t 的态 ρ(t)。数据处理不等式保证：
```
F(t) ≤ 2^{-S(ρ(t) || ρ_thermal)}
```
其中 S(·||·) 为相对熵，ρ_thermal 为热态。

若系统在TL下热化，则 S(ρ(t) || ρ_thermal) → 0，从而 F(t) → 1/D → 0。

**更紧的界**（使用Fannes-Audenaert）：
设初态为疤痕态，任意时间后的态为 ρ(t)。对任意子区域A（大小ℓ），有：
```
F_A(t) ≤ exp[-c ℓ·I(A:rest)]
```
其中 I(A:rest) 为互信息，在热态下 ~ O(ℓ^0)（面积律）。

### 3.2 面积律与疤痕revival矛盾

**定理5**：若疤痕revival F(t) 在TL下有下界 F(t) > ε > 0，则：
- (a) 初态必须在能量空间有O(1)的IPR
- (b) 在revival时刻，子区域熵必须满足面积律 S_A ≤ c|∂A|
- (c) 这与ETH矛盾，除非系统处于本征态或可积

证明（概念性）：
- 由Lehmann-Symanzik-Zimmermann表示，fidelity revival在revival时刻施加了绝热条件
- 面积律+非零fidelity → 系统处于非热本征态
- 但RMT谱统计 → 非热本征态密度在TL下为零

**推论3**：量子信息论框架支持RMT结论——精确疤痕态在TL下不能以O(1)密度存在。

### 3.3 信息论与RMT界面

交集：两种框架都预言精确疤痕态的TL消失。

**分歧**：
- RMT预言动力学revival的Teil时间τ ~ min(L, 1/λ^2)
- 信息论提供了更弱的上界：τ必须小于某种L的多项式函数（由Lieb-Robinson界），但不否定更长的存活

**合成**：量子信息论不能严格排除指数级长τ（因为Lieb-Robinson界只给出信息传播速度，而非递归时间），但RMT提供了更具体的标度律。

### 4.3 核心分歧分析

A博士的τ ~ exp(cL)来源于对Alhambra(2020)和Lin(2020)的解读：

```
A: τ = exp(cL)  /  推导：Alhambra(2020) "revival duration exponentially shrinks with L" + finite-size data
```

```
B: τ = min(t_th, 1/Γ_scar)  /  推导：t_th ~ L (PXP动力学指数), Γ_scar ~ λ^2/2πσ^2 (Rosenzweig-Porter)
```

**分歧根源**：
1. Alhambra(2020)的"指数缩短"是指fidelity振幅的衰减速度随L增大而增加（F(t) ~ exp(-t/τ(L))中τ(L) ~ 1/L的某种函数），而非总的递归时间
2. Lin(2020)的t* ~ O(λ^{-1/(1+d)})是基于Fermi黄金律的微扰论，与RMT的Γ_scar ~ λ^2对比：
   - Fermi黄金律（Lin）：Γ ~ λ² × LDOS(thermal states) — 依赖于热态密度
   - RMT（本工作）：Γ ~ λ²/2πσ² — 独立于L（因热态密度在能量空间光滑）
3. A博士将"疤痕态与热态耦合"的微扰结果与"疤痕态自衰减"的RMT结果混用

### 4.4 可实验区分的预测

**关键检验**：测量标准PXP模型（λ=0）的Z₂疤痕态在中等大小（L=20-40）的fidelity复兴振幅：

- A框架预言：F(L) ~ a·L^{-α}（代数衰减，趋向于0）
- B框架预言：F(L) ~ F_∞ + O(d^{-L})（趋向于大于0的常数F_∞）

为什么有此分歧？因为B框架认为在纯PXP（λ=0）中，疤痕态是严格精确本征态，TL下应该保持其精确性。A框架引用的Ma(2022)讨论的是相互作用费米子系统的双指数衰减（λ>0），但这不适用于λ=0的严格疤痕系统。

**这一分歧揭示A博士的关键错误**：将微扰情况的结论（Ma 2022, λ>0）错误外推到无微扰情况（纯PXP, λ=0）。在RMT框架中，λ=0对应于未扰动系统，疤痕态是严格精确的——TL下不存在消失问题。

## 第五章：ScarFinder(2025)反例的影响分析

### 5.1 ScarFinder反例的框架内解释

ScarFinder(2025)在PXP中发现的"TL下近乎完美revival的新轨迹"需要认真对待。在RMT框架中，可能的解释：

**解释A（RMT兼容）**：ScarFinder找到的轨迹对应于 λ_eff(L) ~ L^{-α} 的有效微扰，其中α足够大使t(L)不发散。
- 证据：PXP的动力学约束可能产生"自保护"效应，使疤痕态与其他态的去耦随L增强
- 这等价于Rosenzweig-Porter参数 t(L) = λ_eff(L)^2 d^L / (2π²σ²) 在TL下保持有界
- 必要条件：α ≥ (log d)/(2 log L) × L — 这只有在约束动力学导致λ_eff指数衰减时才可能

**解释B（突破RMT）**：PXP的约束动力学不在标准RMT类中
- PXP的动力学约束意味着Hilbert空间不是完全连通的——Fock空间图可能是分形而非完全
- 若有效连通维数 d_eff < d，则D_eff = d_eff^L，增长更慢
- 临界情况：若d_eff = 1（约束极强），则D_eff ~ L（多项式增长）→ 疤痕可存活

**解释C（有限尺寸假象）**：ScarFinder的L=32是典型的RMT有限尺寸效应，需要L>100才能看到衰减
- RMT预言：对于PXP（d=2），t(L) = λ² 2^L / (2π²σ²)
- 即使λ很弱（如λ~10^{-3}），当L > |log λ|/log 2 ≈ 10时，t(L) > 1
- 但ScarFinder的λ_eff可能远小于10^{-3}

### 5.2 三种解释的可区分性

| 解释 | 关键预言 | 验证方法 |

## 第七章：独立结论

### 7.1 定义澄清

本结论采用以下定义：

**(a) 精确疤痕本征态**：
严格满足 H|ψ_scar⟩ = E_scar|ψ_scar⟩，且|ψ_scar⟩在能量本征基中的展开在TL下保持O(1)的权重集中在有限个基矢上（即IPR不趋于0）。这对应于数学意义上的疤痕本征态存在性。

**(b) 动力学可观测revival**：
存在某时间 t^*（可能随L增长），使得初始疤痕态的fidelity F(t^*) = |⟨ψ(0)|ψ(t^*)⟩|^2 在TL下保持大于某系统无关的正常数ε > 0。这对应于操作意义上的疤痕现象可观测性。

### 7.2 终极结论

**一句话结论：QMBS在热力学极限下——精确疤痕本征态不存活，但动力学疤痕revival在操作意义上存活，前提是λ=0且系统尺寸不超出约束空间的物理限制。**

详细拆解：

1. **对精确疤痕本征态（严格定义a）**：
   - λ > 0（任何非零微扰）：**消失**（收敛于A框架，RMT t→∞）
   - λ = 0（严格保护）：**存活**（此为trivial情况——系统完全可解）
   - 现实实验（λ ≠ 0）：消失
   - **与A框架的关键差异**：A框架认为即使在λ=0近似下，精确态因"热海"诱导衰减而在TL消失。RMT框架认为λ=0时无衰减机制，精确态严格存活。

2. **对动力学可观测revival（定义b）**：
   - 纯PXP（λ=0）：存活，τ ~ ∞（精确周期性）
   - 微扰PXP（小λ）：τ ~ min(L, 1/λ²) —— **不随L指数增长**
   - **与A框架的关键分歧**：A框架τ~exp(cL)；B框架τ~min(L, 1/λ²)。这直接源于对Alhambra/Lin定理的不同解读。

3. **综合**：
   - B博士RMT框架削弱了A博士的"exp指数级长动力学存活"结论——RMT预言τ的L标度最多线性
   - 但B框架在"精确态消失"上与A框架收敛——两种完全不同的方法论指向同一结论
   - ScarFinder反例若被证实，将同时动摇两种框架的基础，暗示PXP约束系统存在超越RMT+ETH的新物理
