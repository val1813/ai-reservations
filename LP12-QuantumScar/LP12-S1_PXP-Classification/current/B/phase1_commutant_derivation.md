### 0.2 为什么两种框架回答同一个问题

驱动矛盾的核心问题是：**"PXP-α中的所有QMBS是否都可以用SU(2)谱生成代数分类？"**

这个问题具有双重性质：
- **数值方面**：需要验证所有实际存在的疤痕态是否隶属SU(2)框架——这是A博士的领域
- **代数方面**：需要推导在PXP-α的约束+对称性下，**原则上可能存在**哪些代数结构——这是B博士的领域

两种框架互相补充但互不依赖：
- 如果代数推导证明SU(2)是唯一可能的代数结构，则A博士的数值搜索只需确认具体表示形式
- 如果代数推导发现非SU(2)代数结构的可能性空间，则A博士需要找到它们（或证明它们不出现）
- 如果A博士的数值搜索发现非SU(2)候选态，则B博士的代数框架必须解释其代数来源

### 0.3 von Neumann双交换子定理的应用框架（参考：Commutant Algebras, Caltech arXiv:2209.03377）

给定哈密顿量H，其交换子（commutant）定义为：

$$C(H) = \{ A \in \mathcal{B}(\mathcal{H}) : [A, H] = 0 \}$$

von Neumann双交换子定理告诉我们：$C(C(C(H))) = C(H)$，即$C(H)$是一个von Neumann代数。这意味着$\mathcal{H}$可以分解为$C(H)$的不可约表示的直和：

$$\mathcal{H} = \bigoplus_k \mathcal{H}_k \otimes \mathcal{H}'_k$$

其中$\mathcal{H}_k$是$C(H)$的不可约表示空间，$\mathcal{H}'_k$是多重度空间。哈密顿量在这个分解下取形式：

$$H = \bigoplus_k H|_k \otimes I'_k$$

**疤痕的代数定义（在本框架中）：** 疤痕态对应那些$\mathcal{H}_k$中具有特殊性质的子空间——该子空间上的算子代数（由局部算子生成）与体统其他部分不同构，导致弱遍历性破缺。

## §1 PXP-α哈密顿量的精确代数结构分析

### 1.1 模型定义

我们在长度为$L$的一维链（周期性边界条件）上定义自旋-1/2系统。每个格点$i$具有两个态：$|\downarrow\rangle_i$（基态，无Rydberg激发）和$|\uparrow\rangle_i$（激发态，有Rydberg激发）。定义算子：

$$n_i = |\uparrow\rangle\langle\uparrow|_i = \frac{1 - \sigma_i^z}{2}$$
$$P_i = |\downarrow\rangle\langle\downarrow|_i = \frac{1 + \sigma_i^z}{2} = 1 - n_i$$
$$\sigma_i^+ = |\uparrow\rangle\langle\downarrow|_i, \quad \sigma_i^- = |\downarrow\rangle\langle\uparrow|_i, \quad \sigma_i^x = \sigma_i^+ + \sigma_i^-$$

**PXP-α哈密顿量：**

$$H_\alpha = \sum_{i=1}^L P_i^\alpha \,\sigma_i^x\, P_i^\alpha = \sum_{i=1}^L \left( \prod_{j: d(i,j) \leq \alpha,\, j \neq i} P_j \right) \sigma_i^x \left( \prod_{j: d(i,j) \leq \alpha,\, j \neq i} P_j \right)$$

其中$\alpha$是封锁半径（整数$\geq 1$），$d(i,j)$是链上的最短距离（PBC）。

**约束条件：** 对于任意格点$i$，以下算子在实际物理态上为零：

$$n_i \prod_{j: d(i,j) \leq \alpha,\, j \neq i} n_j = 0 \quad \text{（约束条件，不是算子等式）}$$

即：在任何允许的基矢中，每个封锁半径内最多有一个激发。

**约束希尔伯特空间：** $\mathcal{H}_{\text{const}} = \text{span}\{|\mathbf{s}\rangle \in \{ \downarrow, \uparrow \}^{\otimes L} : \forall i, \prod_{j: d(i,j) \leq \alpha} n_j |\mathbf{s}\rangle = 0\}$

### 1.2 对称性代数

**平移对称性（PBC）：** 定义平移算子$T$：

$$T\,\sigma_i^{\pm,z}\,T^\dagger = \sigma_{i+1}^{\pm,z}, \quad T^L = I$$

显然$[H_\alpha, T] = 0$，因为$H_\alpha$在所有格点上是均匀的。

**空间反演对称性：** 定义反演算子$I$：

$$I\,\sigma_i^{\pm,z}\,I^\dagger = \sigma_{L-i+1}^{\pm,z}, \quad I^2 = I$$

若PBC且$\alpha$使得封锁模式对称，则$[H_\alpha, I] = 0$。

**约化对称性：** $T$和$I$张成二面体群$D_L$。

### 1.3 可能存在的粒子-空穴型对称性

定义全翻转算子$C = \prod_i \sigma_i^x$，其作用为：

$$C^\dagger \sigma_i^z C = -\sigma_i^z, \quad C^\dagger \sigma_i^x C = \sigma_i^x$$

检查$C$是否为对称性：

$$C H_\alpha C^\dagger = \sum_i C P_i^\alpha C^\dagger \, C\sigma_i^x C^\dagger \, C P_i^\alpha C^\dagger = \sum_i n_i^{\alpha} \,\sigma_i^x\, n_i^{\alpha}$$

其中$n_i^{\alpha} = \prod_{j: d(i,j) \leq \alpha, j\neq i} n_j$，即全翻转将投影算子$P_j$映射为$n_j$。

由于$n_j \neq P_j$，一般情况$C H_\alpha C^\dagger \neq H_\alpha$。但可以构造**交错粒子-空穴变换**：

$$\tilde{C}_\alpha = T_{1/2} \circ C$$

其中$T_{1/2}$是半个格点的平移。对于$\alpha=1$（标准PXP），这个变换将约束条件$n_i n_{i+1}=0$映射到自身（因为交错后奇数位和偶数位的约束关系互换），在PBC且$L$为偶数时是精确对称性。

更一般地，对于任意$\alpha$，我们可以定义：

$$\Pi_\alpha = \prod_{i=1}^L \mathcal{P}_i(\alpha)$$

其中$\mathcal{P}_i(\alpha)$是格点$i$上依赖于$\alpha$模数$(\alpha+1)$的酉变换。这个算子满足$\Pi_\alpha H_\alpha \Pi_\alpha^\dagger = H_\alpha$当且仅当$\alpha+1$整除$L$（周期性边界条件下）。

**关键观察 1：** 粒子-空穴型对称性的存在性依赖于$\alpha$和$L$的算术关系。对于不满足该关系的参数，这种"交错"对称性被破坏，可能导致某些SU(2)疤痕的消失或修改。

**关键观察 2：** 即使交错粒子-空穴对称性不精确成立，$H_\alpha$在约束空间的投影可能近似具有该对称性。这会产生近似SU(2)疤痕（fidelity revival不完全但显著）。

### 1.4 局部算符代数结构

将$H_\alpha$写为局部项的求和：

$$H_\alpha = \sum_i h_i, \quad h_i = P_i^\alpha \sigma_i^x P_i^\alpha$$

每个$h_i$在$2\alpha+1$个格点上有支持。$h_i$的对易关系：

对于$|i-j| > 2\alpha+1$：
$$[h_i, h_j] = 0 \quad \text{（支持集不重叠）}$$

对于$|i-j| \leq 2\alpha+1$：
$$[h_i, h_j] \neq 0 \quad \text{（支持集重叠，对易子复杂）}$$

这是一个具有有限程相互作用的哈密顿量。其特殊性在于，每个$h_i$本身就是投影算子作用下的$\sigma_i^x$——这意味着$h_i$并不是简单的泡利算子，而是在约束空间上的投影。

**重要结构观察：** 约束条件可以通过以下算子等式表达（以$\alpha=1$为例）：

$$n_i n_{i+1} = 0 \quad \text{在约束空间上}$$

这等价于：

$$P_i + P_{i+1} - P_i P_{i+1} = I \quad \text{（在约束空间上）}$$

这个关系暗示$P_i$不是独立的投影算子——它们满足约束版本的"投影算子代数"：

$$P_i^2 = P_i$$
$$P_i P_{i+1} P_i = P_i P_{i+1} \quad \text{（从约束导出，非一般投影算子恒等式）}$$

对于一般$\alpha$，约束关系为：

$$\prod_{j: d(i,j) \leq \alpha} n_j = 0 \quad \Rightarrow \quad \sum_{\mathcal{S} \subseteq \{i-\alpha, \ldots, i+\alpha\}} (-1)^{|\mathcal{S}|} \prod_{k \in \mathcal{S}} n_k = 0 \quad \text{在约束空间上}$$

这个结构具有深刻的代数意义——它定义了约束希尔伯特空间上的一个投影算子格（operator lattice），这是后续§2和§3中不可约分解和交换子分析的基础。

## §2 约束希尔伯特空间的不可约分解

### 2.1 递归构造和维度计数

约束希尔伯特空间$\mathcal{H}_{\text{const}}(\alpha, L)$的基矢可通过转移矩阵递归构造。对于$\alpha=1$（Fibonacci约束），维度$d_L = F_{L+2}$（Fibonacci数）。对于一般$\alpha$，$d_L$满足广义Fibonacci递推：

$$d_L = d_{L-1} + d_{L-(\alpha+2)}$$

这反映了"在位置放置一个激发将阻塞接下来的$\alpha$个位置"。

**观察：** 约束空间的维度增长速度是亚指数但超多项式的——对于固定$\alpha$，$\lim_{L\to\infty} \frac{\ln d_L}{L} = \ln \lambda_\alpha$，其中$\lambda_\alpha$是特征方程$\lambda^{\alpha+2} - \lambda^{\alpha+1} - 1 = 0$的最大根（$\lambda_1 \approx 1.618$为黄金比例）。

### 2.2 平移对称性下的不可约分解

由平移算子$T$（基本对称性）诱导的分解：

$$\mathcal{H}_{\text{const}} = \bigoplus_{k=0}^{L-1} \mathcal{H}_{\text{const}}^{(k)}$$

其中$\mathcal{H}_{\text{const}}^{(k)}$是动量$k = \frac{2\pi q}{L}$（$q=0,1,\ldots,L-1$）的扇区。

**关键问题：** 在这些动量扇区内，$H_\alpha$是否进一步分解？

### 2.3 交换子$C(H_\alpha)$的初等部分

显然$T \in C(H_\alpha)$，$I \in C(H_\alpha)$。由von Neumann代数理论：

$$C(H_\alpha) \supseteq \{T, I\}'', \quad \{T, I\}' = C(\{T, I\}) = \text{二面体群}D_L\text{的群代数}$$

因此最低限度的分解为：

$$\mathcal{H}_{\text{const}} = \bigoplus_{\mu} \mathcal{H}_\mu \otimes \mathbb{C}^{m_\mu}$$

其中$\mu$标记$D_L$的不可约表示（取决于$L$的奇偶性，有维度为1和2的irrep）。

**如果$C(H_\alpha) = \{T, I\}$''（即交换子仅由对称性生成），那么上述分解就是最精细的，且$H_\alpha$在每个不可约扇区内应该是非可积的但无额外结构。**

**如果$C(H_\alpha)$更大（包含非对称性生成的算子），则存在额外的谱简并或守恒量——这为疤痕代数提供了空间。**

### 2.4 疤痕子空间的结构分析

定义已知的SU(2)疤痕子空间（以$\alpha=1$为例）：

对于$L$为偶数且PBC，褶皱态（scaffold states）$|S_k\rangle$满足$k=0,1,\ldots,\lfloor L/2 \rfloor$：
- $|S_0\rangle = |Z_2\rangle = |\downarrow\uparrow\downarrow\uparrow\ldots\rangle$（交错态）
- $|S_k\rangle \propto (S^+)^k |Z_2\rangle$，其中$S^+$是阶梯算子

这些态在动量空间：
- 对于$\alpha=1$，它们在动量$k=\pi$（交错动量）扇区内
- 它们构成一个维数为$\lfloor L/2 \rfloor+1 \sim O(L)$的子空间

**推论 2.4.1：** 疤痕子空间的维度是多项式而非指数级增长（$O(L)$ vs $O(\lambda_\alpha^L)$），这是疤痕态的标志性特征。

**推论 2.4.2：** 如果存在非SU(2)代数结构，它必须作用于一个不同（但重叠？）的子空间，且该子空间的维度必须也具有亚指数增长。

### 2.5 Krylov子空间直和分解与覆盖问题

对于每个初始态$|\psi_0\rangle \in \mathcal{H}_{\text{const}}$，Krylov子空间定义为：

$$\mathcal{K}(|\psi_0\rangle) = \text{span}\{H_\alpha^n |\psi_0\rangle : n = 0, 1, 2, \ldots\}$$

**定理（Krylov子空间覆盖）：** $\bigoplus_{|\psi_0\rangle \in \mathcal{B}} \mathcal{K}(|\psi_0\rangle) = \mathcal{H}_{\text{const}}$，其中$\mathcal{B}$是$\mathcal{H}_{\text{const}}$的任意基。

**关键问题：** 如果存在一个Krylov子空间$\mathcal{K}_\text{scar}$（由$|Z_\alpha\rangle$生成，其中$|Z_\alpha\rangle$是周期为$\alpha+1$的Néel态）是唯一的低纠缠异常子空间，那么所有疤痕态都属于这个Krylov子空间。但如果存在多个互不重叠的Krylov子空间，每个都有低纠缠态，则存在多重疤痕机制。

**B博士推导起点：** 已知PXP-α中$|Z_\alpha\rangle$生成的Krylov子空间包含SU(2)疤痕塔。是否存在其他初始态$|\psi_0\rangle \neq |Z_\alpha\rangle$，使得$\mathcal{K}(|\psi_0\rangle)$也是低纠缠的？

由交换子代数理论，如果存在$O \notin C(H_\alpha)$但$[H_\alpha, O] \approx \omega O$在某子空间上成立，则对应新的疤痕代数结构。

## §3 交换子代数推导：可能的疤痕代数结构

### 3.1 精确交换子的结构

$C(H_\alpha)$（精确交换子的完全集合）的结构可以通过以下方法推导：

考虑所有形如$\mathcal{O} = \sum_i o_i$的平移不变的**局部算子**，其中$o_i$在$R$个格点上有支持（$R$有限）。要求$[\mathcal{O}, H_\alpha] = 0$给出了一组约束方程。

对于$H_\alpha$，局部项$h_i = P_i^\alpha \sigma_i^x P_i^\alpha$的支持集长度为$r_h = 2\alpha + 1$。测试算子$o_i$的支持集长度为$r_o$。

约束方程$[\sum_i o_i, \sum_j h_j] = 0$等价于要求所有距离$d$处的非零对易子之和为零：

$$\sum_{d=0}^{r_h + r_o - 1} \sum_i [o_i, h_{i+d}] = 0$$

这给出了$o_i$张量组分的线性方程组。

**命题 3.1：** $C(H_\alpha)$至少包含以下算子：
1. 平移算子$T$
2. 空间反演算子$I$
3. 作用于$T$和$I$的任意多项式组合
4. 如果交错粒子-空穴对称性存在，其生成元$\Pi_\alpha$

**开放问题 3.1：** $C(H_\alpha)$是否包含其他局部守恒量？这需要通过上述约束方程组系统求解。

### 3.2 近似交换子与谱生成代数

QMBS的核心机制不是精确守恒量，而是**近似谱生成代数（approximate SGA）**。定义算子集$\{A_a\}$，满足：

$$[H_\alpha, A_a] = \sum_b \omega_{ab} A_b + \text{余量}$$

其中余量在目标子空间上接近零。如果$\{A_a\}$闭合成一个李代数$\mathfrak{g}$，且其在某子空间上的表示是有限维的，则产生疤痕塔。

**对于SU(2) SGA的情况：**

阶梯算子$S^\pm_\alpha$具有以下形式：

$$S^+_\alpha = \sum_i (-1)^{i} f_i(\alpha) \, P_i^\alpha \sigma_i^+ P_i^\alpha$$
$$S^-_\alpha = (S^+_\alpha)^\dagger$$
$$S^z_\alpha = \frac{1}{2} [S^+_\alpha, S^-_\alpha]$$

其中$f_i(\alpha)$是依赖于$\alpha$的相位因子（通常为$(-1)^i$交错相位）。

关键性质：$[H_\alpha, S^\pm_\alpha]$在特定Krylov子空间$\mathcal{K}(|Z_\alpha\rangle)$上是近似的阶梯算子：

$$[H_\alpha, S^\pm_\alpha] |\psi\rangle \approx \pm \omega(\alpha) S^\pm_\alpha |\psi\rangle, \quad \forall |\psi\rangle \in \mathcal{K}(|Z_\alpha\rangle)$$

且$S^z_\alpha$作用在$\mathcal{K}(|Z_\alpha\rangle)$上近似为一个好量子数（与$H_\alpha$近似对易）。

### 3.3 非SU(2)代数的可能性分析

#### 3.3.1 高秩Lie代数

考虑一组阶梯算子$\{L_a^\pm\}_{a=1}^r$（$r$为秩），满足：

$$[H_\alpha, L_a^\pm] \approx \pm \omega_a L_a^\pm \quad \text{在目标子空间上}$$

$$[L_a^+, L_b^-] \approx \delta_{ab} H_a^z \quad \text{（广义Cartan生成元）}$$

如果$r > 1$，且不同$a$的阶梯算子线性无关，则生成的李代数是秩$r$的（如$\mathfrak{su}(r+1)$、$\mathfrak{so}(2r+1)$等）。

**在PXP-α中的可实现性分析：**

① **代数约束：** 封锁约束限制了单点激发数的上限。每个"有效自由度"的局部Hilbert空间维度被约束大幅度压低。对于$\alpha=1$，每个相邻对最多一个激发，这意味着链上的有效自由度类似于Fibonacci anyon链，只有2种"电荷"（0和1）。这种低维度的局部自由度是否支持高秩李代数表示是可疑的。

② **算子构造：** 构造第二个独立的阶梯算子$L_2^+$需要找到一个在约束空间内与$S^+_\alpha$线性无关且与$[H_\alpha, \cdot]$近似对易的算子。这意味着$L_2^+$必须具有与$S^+_\alpha$不同的局域结构——可能是不同相位模式的缀饰翻转算子，或是非对角的长程算子。

③ **相位模式分析：** $S^+_\alpha$的相位模式是$(-1)^i$（交错模式）。其他可能的相位模式包括：
   - 均匀模式（$+1$）
   - 四周期模式（$i, i-1, -i, -i+1$等）
   - 更高阶谐波模式

均匀模式下构造的$\tilde{S}^+_\alpha = \sum_i P_i^\alpha \sigma_i^+ P_i^\alpha$的交换子为：

$$[H_\alpha, \tilde{S}^+_\alpha] = \sum_i [P_i^\alpha \sigma_i^x P_i^\alpha, \tilde{S}^+_\alpha]$$

由于$\sigma_i^x$（翻转算子）与$\sigma_i^+$的对易关系以及投影算子的非平凡作用，这个交换子在约束空间上一般不是近似比例关系。

**初步结论：** 高秩Lie代数在PXP-α中似乎不太可能出现，因为约束条件严重限制了局部自由度，使得多个独立阶梯算子难以同时存在。但这一结论需要以下两个条件的验证：

- (a) 在$\alpha > 1$的情况下，更长的封锁半径可能提供更大的局部自由度，从而允许更丰富的代数结构
- (b) 可能存在非局域的阶梯算子（支持集随$L$增长），绕过了局部自由度的限制

#### 3.3.2 超Lie代数

超Lie代数包含反交换关系（graded Lie algebra）。超对称疤痕（suSy scars）在约束自旋系统中是已知的。

在PXP-α中，超对称生成元$Q$和$Q^\dagger$应满足：

$$Q^2 = 0, \quad (Q^\dagger)^2 = 0$$
$$[H_\alpha, Q] \approx 0 \quad \text{（在约束空间上）}$$
$$Q Q^\dagger + Q^\dagger Q = H_\alpha \quad \text{（超对称代数）}$$

**在PXP-α中的可实现性分析：**

① PXP-α的哈密顿量本身是$\sigma_i^x$项的和，而超对称要求哈密顿量是超荷的平方。由于$\sigma_i^x$是反铁磁的翻转项而非平方形式，超对称结构在PXP-α中不太可能精确出现。

② 但在$\alpha$较大的限制下，通过重新定义超荷可能得到近似超对称。例如，在$\alpha \to \infty$极限（完全封锁，至多一个激发在整个系统中），哈密顿量退化为单粒子问题，此时超对称结构可以精确构造。

**初步结论：** 在有限$\alpha$下，超Lie代数作为精确代数不太可能出现。但在大$\alpha$极限下，近似超对称疤痕可能是存在的——但这可能已经偏离了标准PXP范式。

#### 3.3.3 Temperley-Lieb代数

Temperley-Lieb（TL）代数$\text{TL}_n(\delta)$由生成元$e_1, e_2, \ldots, e_{n-1}$定义，满足：

$$e_i^2 = \delta e_i$$
$$e_i e_{i\pm1} e_i = e_i$$
$$[e_i, e_j] = 0 \quad (|i-j| > 1)$$

TL代数在自旋链中自然出现（如Potts模型转移矩阵、XXZ模型的R矩阵）。在疤痕语境下，Wang et al. (arXiv:2403.14755) 展示了TL生成元可以构造疤痕态。

**在PXP-α中的可实现性分析：**

① **PXP约束与TL关系：** $P_i = |\downarrow\rangle\langle\downarrow|_i$本身是幂等算子（$P_i^2 = P_i$），但$P_i$并不满足TL关系：
   - $P_i P_{i\pm1} P_i \neq P_i$ 一般情况
   - $[P_i, P_j] = 0$ 对所有$i,j$（不同格点的投影算子对易），这与TL的非对易生成元不同

② **可能构造方案：** 考虑算子：

   $$e_i = P_{i-1} \sigma_i^+ \sigma_i^- P_{i+1} \quad \text{（对于$\alpha=1$）}$$

   或更一般地，$e_i = P_i^\alpha n_i P_i^\alpha$（但这不是幂等的而且与TL关系不匹配）。

③ **本质困难：** TL代数要求生成元是非对易的（相邻格点），而PXP模型中的投影算子是互相对易的（在不同格点上）。PXP中操作对易结构与TL的几何结构不匹配。然而，在Rydberg阻塞条件下的缀饰（dressed）算子可能实现TL代数的适当表示。

**具体构造尝试：** 定义$\tilde{e}_i = P_i^\alpha \sigma_i^+ \sigma_{i+1}^- P_{i+1}^\alpha + \text{h.c.}$（在$\alpha$链上最近邻的约束内跳跃）。检查：

$$\tilde{e}_i^2 = ?$$

这涉及两个缀饰跳跃算子的平方，一般情况下不会正比于$\tilde{e}_i$。

**初步结论：** PXP-α的约束结构自然产生一种投影算子代数，但该代数不等价于Temperley-Lieb代数。特定构造的算子可能满足TR关系但需要精确的参数调制（如$\alpha$相关的$\delta$参数）。纯PXP-α（仅$\sigma_i^x$项）中TL疤痕的可能性较低，但耦合长程项或添加密度-密度相互作用后，TL结构可能被引入。

#### 3.3.4 广义SGA（GZ框架）

Bhowmick & Ho (arXiv:2507.14895) 提出了广义谱生成代数（GZ-SGA）概念：阶梯算子不必满足标准SU(2)对易关系，但生成元的完整集合构成一个非紧致或非半单Lie代数。

**关键特征：** GZ-SGA中的阶梯算子$L^+$满足：

$$[H, L^+] = \omega L^+ + \text{低权重修正}$$

其中修正项在疤痕子空间上为零或可忽略。与SU(2) SGA的关键区别：修正项的结构更复杂，且阶梯算子的共轭不需要构成标准的$L^z$算子。

**在PXP-α中的可实现性分析：**

① **自然候选：** 在PXP-α中，$S^+_\alpha$与$H_\alpha$的交换子为：

$$[H_\alpha, S^+_\alpha] = \sum_{i,j} [P_j^\alpha \sigma_j^x P_j^\alpha, (-1)^i P_i^\alpha \sigma_i^+ P_i^\alpha]$$

这个双重求和包含了对角项（$i=j$）和非对角项（$i \neq j$）。对角项给出近似的阶梯关系，而非对角项是"修正"。

② GZ框架的关键洞察是：如果这些非对角修正可以在疤痕子空间上被精确求和为零（而不是近似为零），那么GZ-SGA就成立了。这要求在疤痕子空间上，非对角项的期望值满足特定的和规则。

③ **重要观察：** 非对角项的和规则依赖于疤痕态的具体结构。不同类型的疤痕态可能使不同的非对角项集为零，从而支持不同的GZ-SGA结构。

**推论 3.3.4：** GZ-SGA框架提供了在PXP-α中找到非SU(2)疤痕的最可能路径。不同于TL代数（要求新的非对易生成元）或高秩Lie代数（要求更多独立自由度），GZ-SGA可以存在于SU(2)阶梯算子被修正但保持阶梯结构的场景中。

### 3.4 交换子代数的分层结构

总结以上分析，$H_\alpha$的交换子代数具有分层结构：

```
C_exact(H_α)        ← 精确交换子（对称性生成的von Neumann代数）
    ⊂
C_approx(H_α)       ← 近似交换子（在热谱上接近零的算子，如S^z_α）
    ⊂
C_weak(H_α)         ← 弱交换子（在特定子空间上的交换子为零或可忽略）
```

**疤痕代数位于$C_weak(H_\alpha)$和$C_approx(H_\alpha)$的交界处：**

- SU(2)疤痕：$S^\pm_\alpha, S^z_\alpha \in C_weak(\mathcal{K}(|Z_\alpha\rangle))$（在Krylov子空间上是近似平衡的SGA）
- 可能的非SU(2)疤痕：需要找到$\{A_a\} \subseteq C_weak(\mathcal{K}')$，它们成群作用且生成非SU(2)李代数

## §4 与已知非SU(2)疤痕框架的结构比较

### 4.1 GZ广义SGA vs PXP-α

**GZ框架的核心机制：** 阶梯算子$L^+$的交换子包含"修正项"$\Delta L^+$，该修正项在疤痕子空间上为零但不一定在整体Hilbert空间上为零。这意味着$L^+$在疤痕子空间上表现出有效的阶梯代数，但整体李代数是非标准的。

**与PXP-α的映射：**

| GZ框架要素 | PXP-α中的对应物 |
|-----------|----------------|
| 阶梯算子$L^+$ | $S^+_\alpha = \sum_i (-1)^i P_i^\alpha \sigma_i^+ P_i^\alpha$ |
| 阶梯关系 | $[H_\alpha, S^+_\alpha] \approx \omega S^+_\alpha + \text{边界修正}$ |
| 修正项来源 | 非对角$i \neq j$项 + 投影算子的非平凡交换关系 |
| 疤痕子空间 | $\mathcal{K}(|Z_\alpha\rangle)$ |

**关键差异：** GZ框架在无约束的自旋模型（XYZ）中运作，其中阶梯算子是精确的局部算符。在PXP-α中，"原子阶梯算子"不是$\sigma_i^+$而是$P_i^\alpha \sigma_i^+ P_i^\alpha$——即已被投影算子修饰过的。这种修饰可能使阶梯结构更复杂。

**B博士判断：** GZ框架在PXP-α中原则上可以实现，但需要找到让$[H_\alpha, S^+_\alpha]$中的非对角项在某个更大子空间（不仅是$|Z_\alpha\rangle$塔）上完全消失的条件。这等价于找到$C_weak(H_\alpha)$的一个非Abel子代数。

### 4.2 Temperley-Lieb代数疤痕 vs PXP-α

**TL疤痕的核心机制：** TL生成元$e_i$满足的二次关系（$e_i^2 = \delta e_i$）和辫关系（$e_i e_{i\pm 1} e_i = e_i$）允许构建具有特殊谱性质的矩阵积算子。当哈密顿量可以用TL生成元表达时，其本征态可以通过TL表示论完全分类，部分本征态自然具有低纠缠。

**与PXP-α的对比：**

① PXP-α的$h_i = P_i^\alpha \sigma_i^x P_i^\alpha$无法写成TL生成元的简单组合。$h_i$涉及翻转算子，而TL生成元通常是对角的或只涉及投影。

② PXP约束$n_i n_{i+1} = 0$虽然与TL的幂等关系有表面上的相似性，但深层代数结构不同。

③ **一个值得探索的方向：** 是否存在基变换（受约束空间的幺正变换）将$H_\alpha$映射到一个TL可表达的哈密顿量？如果存在，则PXP-α的疤痕分类可以归约为TL表示论。

**命题 4.2（猜想）：** 对于$\alpha = 1$（标准PXP），存在一个受约束空间的非局部基变换，将$H_1$映射到XXZ模型的一个特定点（$\Delta = -1/2$附近），该点可通过TL代数求解。这个变换是弦变换（string-flip transformation）或类似构造。如果这个猜想成立，TL代数在约束空间上的表示将给出PXP疤痕的另一种分类。

### 4.3 稳定子QMBS vs PXP-α

**稳定子疤痕框架（PRL 2026-05-27）：** 用稳定子形式化定义QMBS，疤痕态是某个稳定子群的公共本征态，且该稳定子群是哈密顿量的近似对称性。

**与PXP-α的映射分析：**

① PXP-α的$|Z_\alpha\rangle$态（周期$\alpha+1$的Néel态）可以写成稳定子态：

$$|Z_\alpha\rangle = |(-1)^i\rangle \quad \text{满足} \quad \sigma_i^z \sigma_{i+1}^z |Z_\alpha\rangle = -|Z_\alpha\rangle \quad \text{（交错秩序）}$$

② 如果$|Z_\alpha\rangle$是$n$个稳定子生成元的公共本征态，且这些生成元与$H_\alpha$近似对易，则稳定子框架提供了一个自然的疤痕分类方案。

③ 稳定子框架的优势：可以系统生成大量疤痕态（通过稳定子操作），而不需要假设具体的李代数结构。

**与交换子框架的关系：** 稳定子框架本质上是交换子框架的一个特例——稳定子生成元属于$C_weak(H_\alpha)$，且它们生成的群是交换子的一个子群。

### 4.4 SPT疤痕子空间 vs PXP-α

**SPT疤痕（Matsui et al., arXiv:2512.11216）：** 拓扑序保护的疤痕子空间——疤痕态具有非平凡的对称保护拓扑序，使得它们与热态的混合受到拓扑保护。

**与PXP-α的相关性：**

① PXP-α的约束空间天然具有某种拓扑结构（不同的Rydberg激发构型之间的连通性）。可能存在用拓扑量子数标记的扇区。

② SPT疤痕需要具有非平凡边缘模或纠缠谱简并。PXP-α中是否支持这样的结构？

**初步分析：** PXP-α的约束空间的边界具有特殊的"开放边界"激发模式——在有限链的端点，约束松弛。这可能导致边缘激发模式，类似于SPT相位。如果这些边缘模式在某些能量窗口中存活且具有低纠缠，则它们可能构成SPT疤痕。

**条件：** SPT疤痕在PXP-α中出现的必要条件是约束空间的边界表现出保护性简并，且这些简并在热力学极限下不坍缩。

## §5 苏格拉底追问清单（≥8个问题）

### 针对A博士ED方法论的盲区

**Q1. 有限尺寸效应：你默认L≤16的ED结果可以推广到热力学极限。但疤痕态可能只在特定L下出现（"偶然简并"），也可能只在L超过某个阈值时才出现。你的搜索协议如何区分真正的热力学疤痕和有限尺寸artifact？特别是，如果某个候选疤痕的纠缠熵随L线性增长但斜率比热态小（弱疤痕），它在你的熵阈值判据下会被标记为热态还是疤痕态？**

**Q2. 边界条件偏置：你在PBC还是OBC下运行ED？这两个边界条件下的约束Hilbert空间结构本质不同——PBC的平移对称性产生了动量标签，OBC则破坏了平移对称性但允许更大的约束空间。如果疤痕机制依赖于边界反射（如同λ/4谐振腔），则OBC和PBC下的疤痕谱会完全不同。你的搜索协议是否覆盖了两种边界条件？如果只选其一，你是否在系统性放大某类疤痕而埋没另一类？**

**Q3. 纠缠熵作为疤痕判据的充分性：你用纠缠熵离群值筛选疤痕候选。这个筛选中存在以下问题：(a) 热态纠缠熵的方差随能级变化——在谱边缘，"热态"本身的纠缠熵就比谱中心低，容易被误标为疤痕；(b) 存在纠缠熵在热态的半高宽内但动力学表现出明显revival的"中间态"——它们是否被排除在疤痕候选之外？(c) 对于可能存在的高纠缠疤痕（如SPT疤痕，边界模贡献ln2的熵，但对尺寸依赖），你的熵阈值是否足够粗糙？**

**Q4. 能量分辨率和谱等距性：你使用谱等距性作为SU(2)塔的证据。但(a) 在小系统上，由于有限尺寸效应，谱等距性可能被破坏；(b) 如果非SU(2)代数产生的疤痕塔的能级间隔不均匀（如GZ-SGA的修正项导致能级移动），谱等距性判据会直接排除这些候选；(c) 你使用哪个能量窗口来评估等距性？谱边缘的态密度稀疏可能导致虚假的等距性信号。你的谱等距性指标对非SU(2)代数产生的非等距塔的区分能力如何？**

### 概念性问题

**Q5. "疤痕"的定义本身是否依赖动力学而非静态谱？当前疤痕的操作性定义混合了两套标准：静态标准（低纠缠态嵌入热谱）和动力学标准（fidelity revival）。这两套标准给出的疤痕集合并不等价。如果一个态在静态上具有完全热态的纠缠熵（S_vN = S_thermal），但在动力学上显示出完美的周期revival（因为该态在特定初始条件下的时间演化不遍历所有热态），它应该被算作疤痕吗？你的搜索协议使用的是哪套标准？如果使用静态标准，你是否会在协议层面排除所有"动力学疤痕但不是低纠缠疤痕"的案例？**

**Q6. "SU(2)完整性"意味着什么？如果每个已知疤痕塔都对应SU(2)的一个表示，但仍然存在非SU(2)代数生成的疤痕塔（只是恰好没有被发现），那么"SU(2)是完整的"这一声明是(B)空真（vacuously true）还是(A)实质性真（substantively true）？换言之，你需要证明的不只是"找到的疤痕都有SU(2)结构"——还包括"不可能存在非SU(2)结构的疤痕"。ED穷举法只能给出前者（所有找到的都是SU(2)），无法给出后者（不存在找不到的）。你的§1结论声明中是否区分了这两种意义上的"完整性"？**

### 反向问题

**Q7. 如果SU(2)不是唯一的，为什么至今无人发现PXP中的非SU(2)疤痕？这是反向问题中最尖锐的一个。存在两种可能性：(a) 确实不存在——PXP的约束严重限制了代数可能性，所有已知的非SU(2)疤痕机制（GZ的XYZ、TL的Potts链、SPT的拓扑相位）都依赖于PXP模型中缺失的某种要素（如长程相互作用、非对角项、多体耦合）；(b) 存在但被搜索方法系统性遗漏了——因为过去8年的搜索协议一直以SU(2)的印记（谱等距性、fidelity revival周期与阶梯关系的一致性等）作为疤痕确认的必要条件，形成了确认偏置（confirmation bias）。你如何排除(b)？具体地说，如果非SU(2)疤痕表现为不完美的fidelity revival和不规则的谱间隔，它能否通过当前文献中通行的疤痕确认流程？**

**Q8. SU(2)疤痕在PXP中具有的"特殊性"有多少来自模型约束而非普遍原理？换个表述：如果我们在PXP模型中加入小的微扰项（如$V\sum_i n_i n_{i+2}$），SU(2)疤痕是否会被破坏？如果被破坏，说明SU(2)结构不稳健，它的存在是模型的精细调节结果而非普遍代数原理。如果不被破坏，SU(2)有更深的起源。先回答哪个结果都包含重要信息：前一个结果意味着对疤痕的分类必须包含模型依赖的"环境"信息（不仅仅是代数结构），后一个结果意味着SU(2)具有鲁棒性。你的ED数值实验是否计划加入这些微扰来测试SU(2)的稳健性？如果没有，你如何区分"SU(2)是PXP-α的唯一代数结构"和"SU(2)恰好是PXP-α中所有可实现的代数结构"这两个不同层次的声明？**

**Q9. A博士的ED方法无法检测到什么类型的疤痕？**（强制问题）

**核心回答：A博士的方法无法检测到以下类型的疤痕：**

1. **动力学疤痕但静态热化态：** 如果一个态在静态具有热态的纠缠熵（S_vN在热态分布的半高宽内）和热态的期望值（所有局部算符的期望值与微正则系综一致），但在某些特定的初始条件下表现出显著的动力学revival（如Loschmidt echo在长时间后反弹）。这类"隐藏动力学疤痕"在ED静态分析中看起来完全是热态，在纠缠熵筛选阶段就被剔除。

2. **多体疤痕相干态（cat-state scars）：** 如果疤痕态是多个正交疤痕塔的非平凡叠加（如GHZ类态），其纠缠熵会很高（$S \sim \log 2$或更大），但仍可能具有非热动力学。纠缠熵筛选会排除这类态。

3. **有限尺寸不稳定但热力学极限下稳定的疤痕：** 如果某疤痕态只在大L（超过ED可达范围）下出现，或在小L下被边界效应掩盖，ED协议完全无法检测。

4. **"暗疤痕"（暗态类）：** 如果某疤痕态与哈密顿量对易（是精确本征态但不是任何局部算符的阶梯产生态），它在纠缠熵图中可能看起来是一个孤立的零熵态，容易被当作平庸的可积态（而非有趣的疤痕结构）。

5. **纠缠熵与系统大小成比例的疤痕：** 如果存在$S \sim cL$（c>0但小于热态系数）的疤痕族，这些态的熵在ED尺寸下与热态无法区分（因为ED尺寸下熵的涨落大于cL与热态S的差距）。

6. **非平衡稳态疤痕：** 在开放系统或时间周期驱动（Floquet）的PXP模型中出现的疤痕，ED不考虑时间维度。

**Q10. 如果SU(2)是完整的，那"完整性"的代数证明在哪里？** 已知的非SU(2)疤痕框架（GZ、TL、SPT）分别在XYZ模型、Potts链、对称保护拓扑相位中成功构造了非SU(2)结构。PXP-α与这些模型之间的结构差异是否大到可以证明非SU(2)结构在原则上的不可能性？这需要严格的代数论证（而非数值归纳）：从PXP-α的约束条件和对称性出发，证明弱交换子$C_weak(H_\alpha)$中非Abel子代数的所有可能闭包都是SU(2)的同构。只要这样的证明不存在，"SU(2)完整性"就是一个需要通过未来发现证伪或证实的实质性的科学假说，而非已证定理。

**附录：独立结论**

**一句话结论：** 基于交换子代数分析和von Neumann双交换子定理框架，PXP-α约束条件对局部自由度的强力限制使得SU(2)是最自然的涌现代数结构，但GZ广义SGA和Temperley-Lieb代数在PXP-α中的可实现性尚未被彻底排除——特别是对于$\alpha \geq 2$的扩展封锁半径模型，局部自由度的释放可能允许非SU(2)代数结构的生存空间。

**分类预测：**
- $\alpha = 1$（标准PXP）：SU(2)最可能是唯一的疤痕代数结构。TL代数无法自然嵌入PXP约束（投影算子对易性质与TL的非对易生成元矛盾）。GZ-SGA原则上可能但需要非对角项的和规则被精确满足。
- $\alpha = 2$（扩展封锁）：在更大的局部自由度下，GZ-SGA的生存概率显著提高。TL代数的"滑动封锁窗口"构造方案值得尝试。
- $\alpha \geq 3$：约束进一步松弛，类似大$\alpha$极限下的连续化行为，可能出现量子临界行为或近似超对称结构。

**最终判据：** "SU(2)是否完整"的判定需要同时满足两个条件——(i) A博士的ED数值穷举未发现非SU(2)候选，(ii) B博士的代数推导证明SU(2)是$C_weak(H_\alpha)$中非Abel子代数的唯一闭包。条件(ii)尚未满足——本分析表明GZ-SGA在PXP-α中的可实现性在代数层面上未被封闭。
