# 研究计划 — LP12-S1: PXP推广模型QMBS完整分类

## v1目标
建立PXP-α（α=1,2,3封锁范围）模型中QMBS的穷举分类，确定涌现SU(2)代数是否为唯一疤痕代数结构。

## Phase规划

### Phase 1 [核心]：穷举搜索协议设计 + 文献系统化
**A博士任务：** 
- 基于Kerschbaumer et al. (2025)的已知家族，设计小系统ED穷举搜索协议
- 定义"疤痕态"的操作性判据（纠缠熵离群值 + fidelity revival + 谱等距性）
- 确定PXP-α（α=1,2,3）的完整参数空间和初始态空间
- 预测：(a) SU(2)家族外是否存在非SU(2)疤痕？(b) 所有已知家族=全部疤痕还是只占子集？

**B博士任务（并行）：**
- 从交换子代数框架（Caltech 2024）出发，独立推导PXP-α中所有可能的疤痕代数结构
- 苏格拉底清单：问A博士未问的问题
- 框架声明：用von Neumann双交换子定理 + 哈密顿量对称性分析

### Phase 2 [核心]：ED数值穷举 + 代数表征
- 小系统（L≤16）ED穷举所有本征态→提取疤痕候选
- 对每个候选：测试SU(2) SGA隶属关系
- 非SU(2)候选：识别其代数结构（广义SGA？Temperley-Lieb？新代数？）

### Phase 3 [核心]：分类学构建
- 构建三类分类树：SU(2)-SGA / 广义SGA / 非SGA
- 确定分类的完备性条件
- 输出：PXP-α QMBS完整分类表
