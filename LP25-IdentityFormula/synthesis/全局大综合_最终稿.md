## 论文架构

### §1 Introduction：断裂问题 + 定理链预览

Born-Schrödinger断裂是量子力学最持久的基础悬案。Schrödinger方程可逆、幺正、保相位；Born规则不可逆、概率性、丢相位。近百年来无人精确定义断裂是什么，它的信息代价是多少，它是否可被追踪。

本文给出完整回答。我们证明：(i) 关联矩阵的实虚部构成正则共轭对（定理1），(ii) 正则共轭动力学的实数演化矩阵不可对角化→ℂ是唯一最小充分代数→量子力学的复数结构是动力学必然而非基本公设（定理2），(iii) Born规则的|·|²操作=从复相空间(C^R,C^I)到实概率轴|C|²的有损投影，Gap=丢失的相位信息（定理3），(iv) 丢失的信息由Ĵ=0守恒律追踪（定理4），(v) 两个可证伪预言支撑此框架（预言A-B）。

### §2 定理1：Gap动力学方程

从Heisenberg方程dC/dt = i[H,C]出发，C = C^R + iC^I，H为实数对称矩阵：

```
dC^R/dt = -[H, C^I]        (1a)
dC^I/dt = +[H, C^R]        (1b)
```

**验证**：85,639个随机态（基态+NESS，L=2,4,6,8），机器精度。方程在数学上等价于Heisenberg方程的重排，但物理上揭示了(C^R, C^I)构成正则共轭对——类似于经典力学的dq/dt=+∂H/∂p, dp/dt=-∂H/∂q。

**意义**：这不是新方程——它是Heisenberg方程的精确重排。新的是识别：实部和虚部的演化不是独立的，它们通过交换子结构互相生成。这个正则共轭关系是后续所有定理的物理基础。

### §3 定理2：正则共轭动力学 → 复数必然性（核心新数学）

**定理2**：设线性动力学满足dA/dt = ωB, dB/dt = -ωA（ω≠0），则ℂ是描述此动力学的唯一最小充分代数。

**证明**：

**(i)** 实数演化矩阵M = [[0,ω],[-ω,0]]，特征方程λ²+ω²=0 → λ=±iω（纯虚数）。

**(ii)** 若M在ℝ内可对角化，对角元必为本征值。但±iω∉ℝ → M在ℝ内不可对角化。(A,B)在实数描述中永久纠缠，不可分离为独立自由度。

**(iii)** 复化Z = A+iB → dZ/dt = -iωZ。单一复方程，动力学对角化。

**(iv)** 四元数ℍ有4个实维度，包含S²族2D子代数（Kuzmina-Chodorova 2016），但每个嵌入不等价→ℍ引入2个冗余自由度+S²规范族。ℂ是唯一最小充分代数：2个实维度=2个实自由度，无冗余。∎

**多体推广**：H的本征基下对角化→N个独立正则共轭对→ℂ^N = 关联的Hilbert空间扇区。

**非线性推广**：F解析→线性主导项给出相同结构→ℂ在局部被强制；混沌→ℂ必然性降级为便利性（诚实边界）。定理2适用于线性幺正动力学——恰好是标准量子力学的框架。

**历史定位**：Dirac(1930)说复数是"不可约化的"但未解释原因。de Oliveira(2023, arXiv:2308.00151)通过代数构造证明复数描述是"自然的"。Goyal-Knuth-Skilling(2009, PRA 81, 022109)从对称性+一致性推导复数算术。本文的增量：**动力学的数学不完备性**——实数演化矩阵本身不可对角化，ℂ是动力学完备性的数学出口，不是选择。

### §4 定理3：Born规则 = 相空间投影

定理2强制了复描述C = C^R + iC^I。但测量只返回实数。

Born规则的|·|²操作 = 从复平面到非负实轴的投影：
```
(C^R, C^I) → |C|² = (C^R)² + (C^I)²
```

丢失的信息 = 相位角θ = arctan(C^I/C^R) = 1维连续信息。

**Gap不是量子力学的神秘公设——它是从动力学必然的2维复相空间压缩到实验可及的1维实数轴时的几何代价。**

欧拉恒等式e^{iθ}=cosθ+i sinθ在此是精确数学结构：cosθ→C^R（保留），i sinθ→C^I（丢弃），|e^{iθ}|²=1→|C|²（投影结果）。

双缝实验的精确解读：亮纹=C^R主导（Born可测），暗纹=|ψ⟩与-|ψ⟩相消（XX世界现身），θ=π/2处=系统完全在虚轴（Born规则失效最彻底）。

### §5 定理4：Ĵ = 0追踪Gap的信息去向

被投影丢弃的Im(C₁₂)不凭空消失。定义：

```
Ĵ = dS_vN/dτ + ∇_μ J^μ_G = 0
```

- S_vN：量子von Neumann熵（需注意：这是用全计数统计的累积量生成函数λ(s)而非Born规则定义的熵计算——XX_World消融2）
- J^μ_G：几何熵流（Jacobson 1995热力学框架）

**Ĵ = 0**：信息守恒——虚部流出系统=被环境/几何接收。断裂被"追踪"而非"消除"。

**Ĵ ≠ 0**：因果断连处（黑洞视界）——虚部无处可去→Gap真实存在→Born规则有可测量偏差。

**Ĵ < 0**：反退相干——虚部回流（S3中dV/dt>0的动力系统签名）。

**关键工具批判**：标准开放量子系统工具（Lindblad/RWA）在推导第一步就通过旋转波近似丢弃了e^{i(ω₁±ω₂)t}型快振荡项——这些恰好是|ψ⟩和-|ψ⟩的干涉，携带Im(C₁₂)。物理学家用丢弃了XX的工具寻找XX。正确工具是Redfield方程（不做RWA）或全系统时间演化。

### §6 预言A：态依赖不确定性关系

**定理**：ΔC^R_mn · ΔC^I_mn ≥ ¼|⟨n_n⟩ - ⟨n_m⟩|

**推导**：Â=c†_n c_m+c†_m c_n, B̂=i(c†_n c_m-c†_m c_n) → [Â,B̂]=-2i(n̂_n-n̂_m) → Robertson → 最终形式。

**验证**：85,639态，L=2/4/6/8，基态+NEST，0违反率。等号对纯实数αβ*态精确成立（紧致性已证明）。

**物理**：平衡态(Δn=0)→下界=0→经典可达；非平衡(Δn≠0)→下界>0→量子强制。这是首个下界由非平衡宏观量（密度梯度）给出的不确定性关系。

**实验**：冷原子光晶格（^6Li+量子气体显微镜），双淬火协议（Peña Ardila 2018 PRL），精度~10^{-4}/40s。超导qubit链亦可。

### §7 预言B：C_J(ω,ω') ≠ 0

**声称**：BEC类比黑洞中，不同频率模式间存在非零相位关联。标准热辐射：⟨δn(ω)δn(ω')⟩=0（ω≠ω'）。我们的预言：C_J(ω,ω')≠0。

**函数形式**：C_J ≈ √[n̄(ω)n̄(ω')]·(δξ/ℓ)·κ²/[(ω-ω')²+κ²]，Lorentzian型，峰值在|ω-ω'|~κ。

**量级**：2-5%（Steinhauer型BEC参数），SNR~2-3。

**意义**：预言B是Ĵ≠0在实验室中的第一个可测信号。若C_J=0→预言B被否（不影响定理1-3）；若C_J≠0→Gap首次被量化→连接断裂与引力。

**消融状态**：预言B不依赖S_BH（Bekenstein-Hawking熵）、不依赖Born规则的von Neumann熵、不依赖RWA/Lindblad近似。直接从Ĵ≠0+非对角Bogoliubov系数中推导。

### §8 动力系统结构（S3遗产）

关联矩阵的Frobenius范数V=||C||²_F满足精确演化方程：
```
dV/dt = 2Σ_k [γ^RR_k (c^R_k)² + γ^II_k (c^I_k)²]
```
交叉项γ^RI和λ项精确抵消（独立验证）。γ^RR>0→dV/dt>0→反退相干→Ĵ<0。

RWA=分岔掩盖：Lindblad/RWA将Redfield相图的6种拓扑类型简化为2种（只留稳定焦点/结点），系统性删除了鞍点/结点/Hopf分岔的可能性。Ξ≡max(|γ^RI|,|γ^RR|)/|γ^II|量化RWA安全度。

### §9 Discussion：从断裂到理解

**本文证明了什么**：
1. Born-Schrödinger断裂不是量子力学的神秘公设——它是从动力学必然的复数结构投影到实数测量输出时的几何代价
2. 断裂的信息代价可以被追踪（Ĵ=0）和量化（ΔC^R·ΔC^I ≥ ¼|Δn|）
3. 断裂在特定条件下产生可测量信号（C_J≠0）

**本文没有证明什么**（诚实边界）：
- 没有"推导"Born规则（循环论证风险，Gleason 1957）
- 没有解决测量问题（为什么单次测量产生特定结果）
- Ĵ不是Dirac约束（不满足标准约束代数条件），是emergent守恒律
- C_J预言待实验验证

**与现有框架的关系**：
- 几何量子力学（Kibble 1979, Ashtekar-Schilling 1999）：我们的框架增加了动力学维度
- 复数必要性的其他论证（de Oliveira 2023, Goyal 2009, Renou 2021）：我们的论证基于动力学对角化的不完备性，路径不同
- Jacobson热力学引力（1995）：Ĵ=0是其量子推广

**开放问题**：预言B的完整BdG数值验证、预言A在强驱动极限下的推广、定理2在非幺正/非线性系统中的边界。
