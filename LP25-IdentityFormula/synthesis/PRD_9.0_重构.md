## §1-3：定理链（保持，但重新定位）

**定理1（动力学）**：dC^R/dt = -[H,C^I], dC^I/dt = +[H,C^R] — 精确恒等式
**定理2（复数必然性）**：正则共轭→ℝ不可对角化→ℂ被强制 — i不是公设
**定理3（Gap定义）**：Born规则 = ℂ→ℝ的有损投影 — Gap = Im(C)

**新定位**：这些不再只是"我们对QM的几何理解"——它们是**不等式的基础**。定理1-3定义了标准QM的结构。不等式是这个结构的一个精确的、可证伪的推论。

**如果不等式被违反 → 定理1-3中至少有一个在实验系统中不成立 → 标准QM在某处断裂。** 断裂的精确位置由违反的模式决定。

## §4：不等式 = 标准QM的必要条件

### 推导链回顾

```
标准QM假设：
  (a) 费米子反对易 {c_i, c†_j} = δ_ij
  (b) 线性幺正演化 dC/dt = i[H,C]
  (c) Wick定理/Gaussian态（方差换算 ΔC^R = ΔÂ/2）
       ↓
  对易子 [Â,B̂] = -2i(n̂_n - n̂_m)
       ↓
  Robertson → ΔC^R·ΔC^I ≥ ¼|Δn|
```

**关键**：不等式不是独立定理——它是(a)(b)(c)的合取推论。因此：

**违反不等式 → (a)或(b)或(c)至少一个不成立 → 标准QM在实验系统中被打破。**

### 违反-诊断对应表

| 违反模式 | 最可能的不成立假设 | 物理含义 | 实验系统 |
|---------|-----------------|---------|---------|
| ΔC^R·ΔC^I < ¼\|Δn\| + Δn依赖非单调 | (a) 费米子代数被修正 | 分数统计/任意子 | FQH边缘态 |
| 违反仅在强驱动下出现 | (c) Wick定理失效 | 强关联非高斯态 | 量子quench |
| 违反在所有条件下系统性出现 | (b) 演化非幺正 | 内禀退相干 | 量子引力界面 |
| C_J(ω,ω') ≠ 0（预言B） | (b)+(c) 同时失效 | 因果断连+非高斯 | BEC类比黑洞 |

## §5：三个最可能找到违反的系统（实验挑战书）

### 系统1：分数量子霍尔边缘态（80%概率，最优先）

**为什么这里最可能违反**：ν=1/3 Laughlin态的准粒子是任意子，满足分数统计。边缘态的等效理论是chiral Luttinger液体——其关联函数以幂律衰减（非指数），且交换统计被修改。

**具体预测**：
- 在ν=1/3的边缘态中，两个准粒子通道之间的关联矩阵C_mn的交换相位为e^{iπ/3}（非e^{iπ}）
- → [Â_mn, B̂_mn] = -2i(n̂_n - n̂_m) + (分数统计修正项)
- → 不等式下界被修改为 ¼|Δn + γ·sin(πν)|
- → 当ν≠1时，下界偏离标准值

**实验**：Mach-Zehnder干涉仪测量边缘态的关联相位。已有实验基础设施（Heiblum组, Weizmann）。

**违反信号**：测量到的ΔC^R·ΔC^I系统性地低于¼|Δn|在ν≠1的填充因子下。

### 系统2：强驱动费米子链中的非高斯NESS（60%概率）

**为什么这里可能违反**：在强驱动极限（C₁₁≈1, C₂₂≈0），Wick定理分解⟨c†cc†c⟩≈⟨c†c⟩⟨c†c⟩不成立——四点关联函数有不可忽略的连通部分。

**具体预测**：
- 在L=4的边界驱动XXZ链中，当fL>0.9时
- 非高斯修正 η = ⟨n₁n₂⟩ - C₁₁C₂₂ + |C₁₂|² 非零
- → ΔC^R ≠ ΔÂ/2（方差换算被修正）
- → 表观违反 ¼|Δn|

**实验**：超导qubit链（4-qubit），强微波驱动。测量全计数统计（FCS）的四阶累积量。

### 系统3：BEC类比黑洞中的非对角关联（40%概率，最大影响）

**为什么这里可能违反**：BEC声学视界处，Hawking辐射的声子对产生由非对角Bogoliubov系数描述。在因果断连处（Ĵ≠0），辐射的非对角频率关联C_J(ω,ω')≠0——而标准热辐射中此项为零。

**具体预测**：
```
C_J(ω,ω') = √[n̄(ω)n̄(ω')] · (δξ/ℓ) · κ²/[(ω-ω')²+κ²]
量级：2-5%（Steinhauer型参数）
证伪条件：测量⟨δn(ω)δn(ω')⟩（ω≠ω'），若精确为零则系统3无违反
```

**实验**：Steinhauer型BEC（Technion），或气态BEC极化子（可选平台）。测量密度-密度关联的噪声谱。

**为什么这最大胆**：如果C_J≠0被观测到，这是**量子引力效应在BEC桌面实验中的第一个信号**。这不是量子模拟——这是标准QM+GR预测为0而我们的框架预测非0的信号。

## §6：如果零违反——不等式的正面价值

如果三个系统中都没有发现违反（零结果），这不意味着不等式没用。相反：

**不等式是对标准QM有效性的最精确边界条件。** 它在三个不同方向（统计、关联、因果）上划定了标准QM的适用范围。零结果本身是重要信息——它告诉我们标准QM在那些极端条件下仍然有效，精确到~10^{-4}的水平。

这比"验证了一个定理"更有科学价值——它提供了**标准QM的失效边界的地图**，即使地图上目前只标了"安全区"。
