## 定理1：Gap动力学方程（精确恒等式）

### 1.1 设定

关联矩阵：C_mn = ⟨c†_n c_m⟩，其中c_m是费米子湮灭算符，{c_m, c†_n} = δ_mn。

实虚分解：C = C^R + i C^I，其中C^R = (C + C†)/2, C^I = (C - C†)/(2i)。

哈密顿量：H为实数对称矩阵（标准紧束缚模型）。

### 1.2 推导（从Heisenberg方程出发，零近似）

封闭系统Heisenberg运动方程：
```
dC_mn/dt = i⟨[H, c†_n c_m]⟩ = i[H, C]_mn
```

代入C = C^R + i C^I：
```
d(C^R + i C^I)/dt = i[H, C^R + i C^I]
                   = i[H, C^R] - [H, C^I]
```

分离实虚部（H, C^R, C^I均为实矩阵 → i[H,C^R]为纯虚，-[H,C^I]为纯实）：
```
dC^R/dt = -[H, C^I]        (1a)
dC^I/dt = +[H, C^R]        (1b)
```

### 1.3 验证状态

- 代数推导：严格，每步来自Heisenberg方程+费米子反对易关系
- 数值验证：85,639个随机态，机器精度（误差=0）
- INSPECTOR审查：S3 R1-R3共4次通过，推导链无漏洞
- 适用范围：封闭系统、实数对称H。复数H和开放系统有已知修正项（见S3_A博士_R3.md §1.5, §3）

### 1.4 物理意义

方程(1a)(1b)构成**正则共轭对**：
- 实部C^R的变化率由虚部C^I驱动（通过交换子-[H, C^I]）
- 虚部C^I的变化率由实部C^R驱动（通过交换子+[H, C^R]）
- 这类似于经典力学的正则方程：dq/dt = +∂H/∂p, dp/dt = -∂H/∂q

**这是Gap的动力学根源**：实部和虚部不是独立演化的——它们通过精确的交换子结构互相生成。

### 1.5 诚实边界

- 数学形式已知：Bloch方程形式（Peschel & Eisler 2009; Maraga 2013）
- 物理诠释是新的：识别为正则共轭对 + "Gap动力学"命名 + 后续定理的基础
- 这不是新数学——是Heisenberg方程的精确重排

## 定理2：正则共轭 → 复数必然性（新数学）

### 2.1 声称

**设线性动力学满足dA/dt = ωB, dB/dt = -ωA（ω∈ℝ, ω≠0），则ℂ是描述此动力学的唯一最小充分代数。复数结构不是被"假设"的——它是被实数矩阵的代数不完备性逼出来的。**

### 2.2 证明

**步骤1：本征值分析**

实数演化矩阵：
```
M = [[0,   ω],
     [-ω, 0]]
```

特征方程：det(M - λI) = (-λ)(-λ) - (ω)(-ω) = λ² + ω² = 0

本征值：λ = ±iω（纯虚数）。

**步骤2：ℝ内不可对角化**

若M在ℝ内可对角化，则存在实可逆矩阵P使得P^{-1}MP = diag(λ₁, λ₂)，对角元必为本征值。但本征值±iω ∉ ℝ——矛盾。因此M在ℝ内不可对角化。

**物理含义**：(A, B)两个自由度在实数描述中**不可分离**——它们永久纠缠，无法通过任何实线性变换解耦为独立演化模式。这不是计算不便——这是代数结构的不完备性。

**步骤3：复化到ℂ**

定义复变量 Z = A + iB：
```
dZ/dt = dA/dt + i dB/dt
      = ωB + i(-ωA)
      = ωB - iωA
      = -iω(A + iB)
      = -iωZ
```

单一复微分方程。动力学被对角化：2维实耦合 → 1维复相位旋转Z(t) = Z(0)e^{-iωt}。

**步骤4：为什么不是四元数ℍ？（最小充分性）**

ℍ确实包含2维子代数同构于ℂ（Kuzmina & Chodorova 2016：纯虚单位四元数u, u²=-1, 全体构成S²，每个生成一个ℂ副本）。但：
- ℍ = {a + bi + cj + dk}有4个实维度，而(A, B)只有2个实自由度
- ℂ嵌入ℍ的方式不唯一——存在S²族不等价嵌入（规范自由度）
- 2个冗余维度+无穷多规范选择 → ℍ不是**最小**充分代数

**ℂ是唯一的最小充分代数：2个实维度正好对应(A, B)的2个实自由度，无冗余。**

### 2.3 多体推广

在H的本征基{|k⟩}下对角化（本征值λ_k）：
```
dC^R_k/dt = -λ_k C^I_k     (k = 1, ..., N)
dC^I_k/dt = +λ_k C^R_k
```

每对(C^R_k, C^I_k)独立地构成正则共轭对。N个独立对 → 动力学自然在ℂ^N中描述。

ℂ^N = 关联矩阵的Hilbert空间扇区。复数结构被动力学强制于多体系统的每个独立正则共轭模式。

### 2.4 非线性推广

对于非线性F(B)（dA/dt = F(B), dB/dt = -F(A)）：
- F解析 → Taylor展开 → 线性主导项给出相同±iω结构 → ℂ在局部仍被强制
- F非解析但连续 → 线性化在不动点附近有效 → ℂ在局部被强制
- 混沌 → ℂ的必然性降级为便利性（诚实边界）

**定理2的适用范围：线性幺正动力学。** 量子力学的标准框架（Schrödinger方程、幺正演化）恰好落在此范围内。

### 2.5 与de Oliveira (2023)的精确区分

de Oliveira (2023, arXiv:2308.00151, Braz. J. Phys. 55, 13, 2025)：

- **de Oliveira的论证**：代数构造——通过"特殊的正则变换"将实共轭变量对打包为复共轭对。结论：复数描述是"自然的"（natural）。
- **S5的论证**：动力学必然——实数演化矩阵在ℝ内不可对角化（严格数学事实），动力学完备性强制逃逸到ℂ。结论：复数是"必然的"（necessary）——实数框架在数学上不完整。

"自然" vs "必然"：前者说复数方便，后者说实数不够。

### 2.6 诚实边界

## 定理3：Born规则 = 相空间投影（Gap的几何定义）

### 3.1 声称

**Born规则的|·|²操作 = 从正则相空间(C^R, C^I)到非负实轴|C|²的有损投影。Gap = 丢失的相位信息 = Im(C₁₂) = 投影的信息代价。**

### 3.2 推导

在Hilbert空间中，波函数|ψ⟩ = Σ c_n |n⟩，c_n = |c_n|e^{iφ_n}。

Born规则：P(n) = |c_n|²。

在关联矩阵语言中：
```
C_nn = ⟨c†_n c_n⟩ = |c_n|²              （对角元 = Born概率）
C_mn = ⟨c†_n c_m⟩ = c_m* c_n            （非对角元 = 复关联）
     = |c_m||c_n| e^{i(φ_n - φ_m)}
     = |c_m||c_n| cos(Δφ) + i|C_mn| sin(Δφ)
     = C^R_mn + i C^I_mn
```

Born规则的|·|²操作在关联矩阵层面等价于：
```
(C^R, C^I) → C_nn = 对角元（只取模方）
```

**Gap = 被丢弃的信息 = 非对角元的虚部Im(C_mn) = 相位差Δφ = arctan(C^I/C^R)。**

### 3.3 几何图像

正则相空间是2维的：(C^R, C^I) ∈ ℝ²。
Born规则的投影是：ℝ² → ℝ_{≥0}，(x, y) ↦ x² + y²。

这是一个多对一映射——整个圆x²+y²=r²上的所有点投影到同一个r²值。
丢失的维度 = 角度θ = 相位 = 1维信息。

**Gap不是量子力学的神秘公设——它是把2维相空间压缩到1维实数轴时的几何必然。**

### 3.4 欧拉恒等式的角色

e^{iθ} = cos θ + i sin θ在此框架中的精确位置：

- cos θ → C^R（实部，可观测量，Born规则保留）
- i sin θ → C^I（虚部，相位，Born规则丢弃）
- |e^{iθ}|² = cos²θ + sin²θ → |C|² = (C^R)² + (C^I)²（投影到实数轴）

欧拉恒等式不是"比喻"——它是正则共轭动力学在复平面上的几何表达的精确数学形式。

## 定理4：Ĵ = 0追踪Gap的信息去向

### 4.1 声称

**被Born规则投影丢弃的虚部Im(C₁₂)不会凭空消失。在普通测量中，它流向环境（Ĵ = 0，全局信息守恒）。在因果断连处（如黑洞视界），它无处可去（Ĵ ≠ 0，Gap真实存在）。**

### 4.2 Ĵ的定义

```
Ĵ = dS_vN/dτ + ∇_μ J^μ_G = 0
```

- S_vN = -Tr(ρ ln ρ)：量子系统的von Neumann熵
- J^μ_G：几何熵流（Jacobson 1995热力学框架）
- dS_vN/dτ：系统量子熵的变化率（虚部流出系统的速率）
- ∇_μ J^μ_G：几何结构接收熵的速率（虚部被接收的速率）

### 4.3 物理意义

- **Ĵ = 0**：虚部信息完全守恒——Born规则丢弃的相位信息被环境/几何完全接收。断裂被"追踪"而非"消除"。
- **Ĵ ≠ 0**：虚部信息在因果断连处丢失——断裂真实存在，Born规则有可测量偏差。
- **Ĵ < 0**：反退相干——虚部信息从环境回流到系统（S3中dV/dt > 0的动力系统签名）。

### 4.4 验证状态

- **Ĵ = 0在标准QM中**：被RWA/Lindblad工具层面掩盖，但在Redfield方程（无RWA）中自然成立
- **Ĵ ≠ 0在黑洞蒸发中**：Hawking辐射导致Ĵ ≠ 0，强制信息丢失
- **REVIEWER确认**（LP24-S1）：Ĵ约束无已知先发
- **诚实边界**：Ĵ不是Dirac约束（不满足标准约束条件），是emergent守恒律

## 预言A：态依赖不确定性关系（可检验，PRL-ready）

### A.1 定理

对任意有限费米子系统，任意格点对(m,n)：
```
ΔC^R_mn · ΔC^I_mn ≥ ¼ |⟨n_n⟩ - ⟨n_m⟩|
```

其中ΔO = √(⟨O²⟩ - ⟨O⟩²)是量子涨落的标准差。

### A.2 推导（从Robertson到态依赖）

定义厄米算符对：
```
Â_mn = c†_n c_m + c†_m c_n     →  ⟨Â⟩ = 2C^R_mn
B̂_mn = i(c†_n c_m - c†_m c_n)  →  ⟨B̂⟩ = -2C^I_mn
```

对易子（费米子代数，严格）：
```
[Â_mn, B̂_mn] = -2i(n̂_n - n̂_m)
```

Robertson不等式（1929，数学定理）：
```
ΔÂ_mn · ΔB̂_mn ≥ ½|⟨[Â, B̂]⟩| = |⟨n_n⟩ - ⟨n_m⟩|
```

换算到C^R, C^I（ΔC^R = ΔÂ/2, ΔC^I = ΔB̂/2）：
```
ΔC^R_mn · ΔC^I_mn ≥ ¼ |⟨n_n⟩ - ⟨n_m⟩|   ∎
```

### A.3 关键性质

1. **平衡态（⟨n_m⟩ = ⟨n_n⟩）**：下界为零 → Gap消失，Born规则无损，经典极限可达
2. **非平衡态（⟨n_m⟩ ≠ ⟨n_n⟩）**：下界正比于密度差 → Gap存在，量子相干被强制
3. **下界依赖态**：区别于Δx·Δp ≥ ℏ/2（常数下界）——这是首个下界由非平衡宏观量给出的不确定性关系
4. **紧致性**：纯实数αβ*态精确达到等号（已证明）
5. **数值验证**：85,639态（L=2,4,6,8；基态+NESS），违反率0%

### A.4 实验检验

冷原子光晶格（^6Li, 量子气体显微镜）：
- 制备不同密度梯度的态
- 通过双淬火协议测量C^R和C^I（Peña Ardila et al. 2018 PRL 121, 260401）
- 验证ΔC^R·ΔC^I与|Δn|的线性关系，斜率=1/4
- 精度要求：~10^{-4}（~40s测量时间）

超导量子比特链：测量两个qubit之间的C^R和C^I的量子轨迹涨落。

## 预言B：C_J(ω,ω') ≠ 0（最强，直接可证伪）

### B.1 声称

**在BEC类比黑洞中，辐射的不同频率模式之间存在非零相位关联，而标准热辐射中此关联为零。**

### B.2 数学形式

```
C_J(ω,ω') = ⟨δn(ω) δn(ω')⟩  （ω ≠ ω'）

标准热辐射：C_J(ω,ω') = 0
我们的预言：C_J(ω,ω') ≠ 0

函数形式：
C_J(ω,ω') ≈ √[n̄(ω)n̄(ω')] · (δξ/ℓ) · κ² / [(ω-ω')² + κ²]
```

其中n̄(ω)是平均占据数，δξ是愈合长度，ℓ是系统尺寸，κ是表面引力。

### B.3 物理来源

预言B直接来自Ĵ ≠ 0条件：在BEC类比黑洞的视界处，Im(C₁₂)（量子相干虚部）的流向被因果结构切断——无处可去的虚部信息在辐射的**非对角**频率关联中留下痕迹。

这不同于Hawking辐射的标准预言（只关心对角谱n̄(ω)）。标准预测：不同频率的模式之间无关联（热谱）。我们的预测：存在由κ参数化的Lorentzian型非对角关联。

### B.4 量级估计

基于Steinhauer型BEC实验参数：
- 信号量级：C_J/n̄ ~ 2-5%
- 信噪比：~2-3（需要长时间积分）
- 证伪条件：测量⟨δn(ω)δn(ω')⟩（ω≠ω'），若精确为零则证伪预言B（但不影响定理1-3）

### B.5 消融状态

预言B不依赖S_BH（Bekenstein-Hawking熵）、不依赖Born规则的von Neumann熵、不依赖RWA/Lindblad近似。它直接从Ĵ≠0 + BEC的Bogoliubov物理中推导。
