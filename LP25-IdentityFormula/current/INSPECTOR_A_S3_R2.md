## Q2 符号/方向校对

### 2.1 修正1: 复数H方程 — 独立重推导

**INSPECTOR独立推导**（从 Heisenberg 运动方程出发，不使用文档中间步骤）：

设定: H = Σ_{p,q} (h^R_{pq} + i h^I_{pq}) c†_p c_q, h^R 对称实, h^I 反对称实。

**(1) [H, c_m]**

[H, c_m] = Σ_{p,q} (h^R_{pq} + i h^I_{pq}) [c†_p c_q, c_m]

费米子反对易：{c_q, c_m}=0, {c†_p, c_m}=δ_{pm}
[c†_p c_q, c_m] = c†_p c_q c_m - c_m c†_p c_q
= c†_p c_q c_m - (δ_{mp} - c†_p c_m) c_q
= c†_p c_q c_m - δ_{mp} c_q + c†_p c_m c_q
= -δ_{mp} c_q    （c_m c_q = -c_q c_m 使两项抵消）

[H, c_m] = -Σ_q (h^R_{mq} + i h^I_{mq}) c_q

dc_m/dt = i[H, c_m] = **-i Σ_k h^R_{mk} c_k + Σ_k h^I_{mk} c_k** ✅ 与文档一致

**(2) [H, c†_n]**

[c†_p c_q, c†_n] = c†_p c_q c†_n - c†_n c†_p c_q
= c†_p (δ_{qn} - c†_n c_q) - c†_n c†_p c_q
= δ_{qn} c†_p - c†_p c†_n c_q - c†_n c†_p c_q
= δ_{qn} c†_p    （c†_p c†_n = -c†_n c†_p 使两项抵消）

[H, c†_n] = Σ_p (h^R_{pn} + i h^I_{pn}) c†_p

dc†_n/dt = i[H, c†_n] = i Σ_p h^R_{pn} c†_p - Σ_p h^I_{pn} c†_p

利用对称性 h^R_{pn}=h^R_{np} 和反对称性 h^I_{pn}=-h^I_{np}:
= i Σ_k h^R_{nk} c†_k + Σ_k h^I_{nk} c†_k   ✅ 与文档一致

**(3) 关联矩阵运动方程**

dC_mn/dt = ⟨(dc†_n/dt) c_m⟩ + ⟨c†_n (dc_m/dt)⟩
= i Σ_k h^R_{nk} C_{mk} + Σ_k h^I_{nk} C_{mk} - i Σ_k h^R_{mk} C_{kn} + Σ_k h^I_{mk} C_{kn}
= **i Σ_k (h^R_{nk} C_{mk} - h^R_{mk} C_{kn}) + Σ_k (h^I_{nk} C_{mk} + h^I_{mk} C_{kn})**

✅ 与文档一致（符号正确，为加号）

**(4) 矩阵形式**

h^R 部分: i(C h^R - h^R C) = **i[C, h^R]** ✅

h^I 部分:
- Σ_k h^I_{mk} C_{kn} = **(h^I C)_{mn}** ✅
- Σ_k h^I_{nk} C_{mk}: 利用 h^I_{nk} = -h^I_{kn}，得 -Σ_k C_{mk} h^I_{kn} = **-(C h^I)_{mn}**

因此 h^I 部分 = -(C h^I)_{mn} + (h^I C)_{mn} = **(h^I C - C h^I)_{mn} = -[C, h^I]_{mn}** ✅

**完整矩阵形式: dC/dt = i[C, h^R] - [C, h^I]** ✅ 与文档最终结果一致

**(5) 实-虚分解**

C = C^R + i C^I

d(C^R + i C^I)/dt = i[C^R + i C^I, h^R] - [C^R + i C^I, h^I]
= i[C^R, h^R] + i²[C^I, h^R] - [C^R, h^I] - i[C^I, h^I]
= i[C^R, h^R] - [C^I, h^R] - [C^R, h^I] - i[C^I, h^I]

分离实部虚部:

```
dC^R/dt = -[C^I, h^R] - [C^R, h^I]     ✅
dC^I/dt = +[C^R, h^R] - [C^I, h^I]     ✅
```

**对称性自洽检查**:
- C^R 应对称: -[C^I, h^R]^T = -[C^I, h^R]（✅ 对称）, -[C^R, h^I]^T = -[C^R, h^I]（✅ 对称）
- C^I 应反对称: [C^R, h^R]^T = -[C^R, h^R]（✅ 反对称）, -[C^I, h^I]^T = -(-[C^I, h^I]) = [C^I, h^I]... 等等。

更正： -[C^I, h^I] = -(C^I h^I - h^I C^I) = h^I C^I - C^I h^I。
(h^I C^I - C^I h^I)^T = (C^I)^T (h^I)^T - (h^I)^T (C^I)^T = (-C^I)(-h^I) - (-h^I)(-C^I) = C^I h^I - h^I C^I = -[C^I, h^I]。
因此 -[C^I, h^I] 自反对称（即其转置等于自身的负），✅ 反对称。

**极限退化**:
- h^I → 0: dC^R/dt = -[C^I, h^R], dC^I/dt = +[C^R, h^R] ✅ 退化为R1方程①②
- 与R1错误版的差异已正确标注在文档对比表中 ✅

#### ⚠️ 发现: 文档中间步骤"展开形式"有符号错误

#### ⚠️ 发现: "验证"旁注有代数错误

**位置**: R2行71

```
验证: [C, h^I] = C h^I - h^I C = ... = -(h^I C + C h^I)_mn
```

此"验证"声称 Σ_k (h^I_nk C_mk + h^I_mk C_kn) = -(h^I C + C h^I)_mn。

**INSPECTOR验算**: 
- 左: Σ_k (h^I_nk C_mk + h^I_mk C_kn) = -[C, h^I]_mn
