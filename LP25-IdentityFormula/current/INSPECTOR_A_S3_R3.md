## Q2: SNR≈48.5实验信标量级

### Q2.1 计算路径验证

脚本task3b搜索最优配置：
- 扫描范围：γ^RR/J∈[0.01,0.2], |γ^II|/J∈[0.02,0.15], C^R∈[0.1,0.45], C^I∈[0.05,0.3]
- 最优：γ^RR/J=0.200, |γ^II|/J=0.020, C^R=0.450, C^I=0.050
- dV/dt = 2×[6.0×0.45² + (-0.6)×0.05²] = 2×[1.2150 - 0.0015] = 2.4270 MHz

SNR计算：
- dV/dt_per_ns = 2.4270/1000 = 0.002427 ns⁻¹
- signal = 0.002427 × 200 = 0.4854
- noise = 0.01 (硬编码)
- SNR = 0.4854/0.01 = **48.54 ≈ 48.5**

**内部算术一致**。

### Q2.2 关键依赖：噪声地板0.01未经论证

`noise = 0.01` 在脚本中作为硬编码常数出现，无推导、无引用、无灵敏度分析。该值对应V=C_R²+C_I²测量中的不确定度。实际实验中噪声来源包括：

1. **态层析重建误差**：2-qubit全态层析需15个Pauli基×1000次重复=15,000次测量。每个Pauli期望值的统计误差~1/√1000≈0.032。C_R,C_I由这些期望值的线性组合重建，误差传播后约为0.02-0.05。
2. **读出保真度**：transmon单发读出保真度通常95-99%，意味着每个qubit测量有1-5%误判率。
3. **退相干**：200 ns测量窗口内qubit经历T_2退相干（典型100 μs，远长于200 ns，此点OK）。

若噪声为0.03（三倍于假设值），SNR降至~16.2。若噪声为0.05，SNR降至~9.7（低于单发检测阈值）。**0.01的假设需要论证**。

### Q2.3 文档中的SNR呈现

文档§3.3和§4.1声称4将SNR≈48.5作为确定值呈现（"单发信噪比 SNR ≈ 48.5"），未附加噪声地板假设的任何条件说明。§4.3诚实边界未提及此SNR估计的假设依赖性。**声张4在此点上过度精确**。

## Q3: dV/dt>0的49.84%比例

### Q3.1 脚本输出验证

脚本输出：
```
Total (CR, CI, gamma) configurations: 66600
Configurations with dV/dt > 0: 33195 (49.84%)
```

**与文档声称66,600和49.84%完全一致**。

### Q3.2 参数范围依赖性问题

49.84%是扫描参数的函数，而非系统的内在属性。扫描参数：
- γ^RR ∈ [0.01, 0.5]（对数均匀，15值）
- |γ^II| ∈ [0.01, 0.5]（对数均匀，15值）
- C^R, C^I ∈ [0.01, 0.5]（线性均匀，受C_R²+C_I²≤0.25约束）

这些范围是**任意选择的**，且上下限对称。实际上：
- γ^RR>0需要粒子数反转——这要求γ^RR跨越0进入正值区。γ^RR>0区域大小取决于驱动强度和系统参数，[0.01, 0.5]范围没有物理论证。
- |γ^II|范围同样未论证。

**敏感度分析缺失**：如果γ^RR范围改为[0.001, 0.5]，比率会显著下降（更多小γ^RR→更多dV/dt<0）。如果改为[0.1, 0.5]，比率会显著上升。文档将此49.84%表述为"接近一半的参数空间允许反退相干——dV/dt>0不是稀有事件"，但未说明该结论对参数范围选择的敏感性。

### Q3.3 文档措辞

文档§3.2："接近一半的参数空间允许反退相干——**dV/dt > 0不是稀有事件**。"此措辞将参数范围扫描结果呈现为系统的内在属性，而未声明范围依赖性。建议改为："在我们选择的参数范围内，49.84%产生dV/dt>0"并附加敏感度分析。

## Q6.4 (附加): 替代解释检查

### 替代1: R分布上移（NESS中位数1.547 vs GS~0.3）

**文档解释**：NESS通过Δn>0使R下界锁定在1.001——这是NESS的"标志性特征"

**替代解释**：此为上界的直接算术后果。当Δn>0时下界=¼|Δn|>0，而ΔC^R和ΔC^I的乘积在有限系统中存在上界（取决于最大占据数涨落），导致R = (乘积)/(下界)被压缩到较小的动态范围。GS中Δn可以任意接近0→下界→0→R可发散。**GS vs NESS的R分布差异完全由下界分母的行为解释，不需要引入新物理概念。**

**严重性**：**低**。文档的核心论点（R中位数差异）即使在此替代解释下也成立——NESS确实通过Δn>0约束了R。问题在于文档将"算术后果"包装为"标志性特征/签名"增加了不必要的理论层次。

### 替代2: GS比NESS更紧致

**文档解释**：纯态关联最大化→Var(B̂)最小→R最小（几何）；NESS热涨落稀释关联→C^I较小→Var(B̂)较大→R较大（信息论）

**替代解释**：这是量子力学的一般性质——对于任何固定约束下的不确定关系，纯态总是比混合态更接近饱和（纯态是Hilbert空间中的极端点，混合态是纯态的凸组合）。这不是此不等式的特殊性质，而是Robertson定理对所有量子态的普遍行为。**"GS在所有18/18 case中更紧致"是一条定理而非发现。**

**严重性**：**低**。文档在§2.2中正确识别了纯态vs混合态的几何解释。但标题"反直觉的物理"有诱导性——结果完全不反直觉，符合量子力学教科书。

### 替代3: 交叉项抵消

**文档解释**：SO(2)旋转保持R²不变，SO(1,1) boost保持(c^R)²-(c^I)²不变→两者对R²导数无贡献（群论解释，§5.2）

**替代解释**：在H的本征基下，Redfield张量自动对角化为γ^RR⊕γ^II⊕γ^RI⊕γ^IR。KK关系γ^IR=-γ^RI强制交叉部分为反对称。反对称矩阵对标量R²的导数为零（这是反对称矩阵的数学性质，不需要群论语言）。群论重新表述增加了深度但不改变逻辑。

**严重性**：**极低**。群论解释是同一事实的优雅重述，不是错误。但应注意避免将"重述"包装为"深化"。

### 替代4: dV/dt>0的反退相干签名

**文档解释**：dV/dt>0⇔Ĵ<0，是反退相干（信息从环境回流系统）的动力学签名

**替代解释**：γ^RR>0是粒子数反转条件（类似于激光/激射器中的负温度）。在此条件下dC^R/dt的耗散部分为正→C^R增长→V增长。这与标准量子光学的增益条件完全相同——**dV/dt>0不是新现象，而是标准激光增益在关联矩阵语言中的重新表达**。

**严重性**：**中**。文档将dV/dt>0描述为"反退相干"和"Ĵ<0的信息回流"，暗示了新的非平凡现象。但物理上，γ^RR>0就是"环境在实部通道中提供增益"——与激光增益介质中粒子数反转产生光子增益完全相同。文档应明确声明此联系以避免过度声张新现象。
