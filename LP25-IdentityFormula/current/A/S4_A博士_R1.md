### §1.1 不等式的逻辑结构：什么已知、什么新

在开始严格化之前，必须清晰切割不等式的逻辑层次：

**层次0（完全已知---Robertson, 1929）**:

```
对任意两个自伴算符A, B，在任意量子态ρ上：
ΔA · ΔB ≥ ½|⟨[A, B]⟩|
```

这是数学定理。不需要"证明"---需要的是引用。

**层次1（代数计算---S3已完成，此处重述以完备）**:

```
[Â_mn, B̂_mn] = -2i(n̂_n - n̂_m)
```

这是费米子反对易关系的直接代数推论。S3的R1中已详细计算，六处INSPECTOR_CHECK均通过。

**层次2（代入---"物理组合"，S3新贡献）**:

```
将A = Â_mn, B = B̂_mn代入Robertson不等式：
ΔÂ_mn · ΔB̂_mn ≥ ½|⟨[Â_mn, B̂_mn]⟩| = |⟨n̂_n - n̂_m⟩|

利用 ΔÂ_mn = 2ΔC^R_mn, ΔB̂_mn = 2ΔC^I_mn：
4 ΔC^R_mn · ΔC^I_mn ≥ |⟨n_n⟩ - ⟨n_m⟩|

⟹ ΔC^R_mn · ΔC^I_mn ≥ ¼|⟨n_n⟩ - ⟨n_m⟩|         (不等式③)
```

**这是新物理组合，不是新数学**：将下界表达为粒子数差Δn = |⟨n_n⟩ - ⟨n_m⟩|而非抽象的算符对易子期望值。

### §1.2 任务1.1：证明对任意有限维Fock空间、任意态（纯或混合）严格成立

**声称**：对任意有限费米子Fock空间（L个格点，总粒子数无约束），任意量子态ρ（纯或混合），不等式③对所有m≠n严格成立。

**证明**：

**步骤1**：对易子的算符恒等式。

[Â_mn, B̂_mn] = -2i(n̂_n - n̂_m) 是**算符恒等式**---它不依赖于态的选择，不依赖于Hilbert空间的维度。它只依赖于费米子反对易关系{c_m, c†_n} = δ_mn和代数运算。S3_A_R1的§2.1中已完整推导并经INSPECTOR独立验算。

**关键验证**（对混合态推广的必要性检查）：对易子是算符层面的恒等式，因此对所有态上的期望值⟨[Â, B̂]⟩ = Tr(ρ[Â, B̂])同样成立。Robertson不等式在混合态下成立的证明（Robertson 1929原始论文已含混合态）是：

```
对任意密度矩阵ρ = Σ_k p_k |ψ_k⟩⟨ψ_k| (p_k ≥ 0, Σ p_k = 1):
⟨[A, B]⟩ = Tr(ρ[A, B]) = Σ_k p_k ⟨ψ_k|[A, B]|ψ_k⟩
```

对每个纯态|ψ_k⟩，Robertson不等式成立：
```
Δ_k A · Δ_k B ≥ ½|⟨ψ_k|[A, B]|ψ_k⟩|
```

其中Δ_kO = √(⟨ψ_k|O²|ψ_k⟩ - ⟨ψ_k|O|ψ_k⟩²)。

对混合态，统计方差与量子涨落的关系由方差分解公式给出：
```
(Δ_ρ O)² = Σ_k p_k (Δ_k O)² + Σ_k p_k (⟨O⟩_k - ⟨O⟩_ρ)²
         = 量子涨落 + 经典混合涨落
```

因此Δ_ρ O ≥ √(Σ_k p_k (Δ_k O)²)。利用Cauchy-Schwarz：
```
(Δ_ρ A)(Δ_ρ B) ≥ √(Σ_k p_k (Δ_k A)²) · √(Σ_k p_k (Δ_k B)²)
                ≥ Σ_k p_k (Δ_k A)(Δ_k B)    （Chebyshev型不等式）
                ≥ Σ_k p_k · ½|⟨ψ_k|[A, B]|ψ_k⟩|
                = ½ Σ_k p_k |⟨[A, B]⟩_k|
                ≥ ½|Σ_k p_k ⟨[A, B]⟩_k|      （三角不等式）
                = ½|⟨[A, B]⟩_ρ|
```

这完成了Robertson不等式在混合态下的严格证明。因此不等式③对所有混合态成立。

**步骤2**：有限维Fock空间的完备性。

费米子Fock空间（给定L）是有限维的：dim(F) = 2^L（包含所有粒子数扇区）。在任何有限维子空间内（固定粒子数N，或任何粒子数的混合），算符Â_mn和B̂_mn作为c†, c的二次型，是良定义的有界算符（由于││c†_m c_n││ ≤ 1在有限维Hilbert空间中）。所有方差有限，Robertson不等式适用。

**步骤3**：方差-下界关系的具体化。

将Â_mn = c†_n c_m + c†_m c_n, B̂_mn = i(c†_n c_m - c†_m c_n)代入，得到ΔÂ_mn · ΔB̂_mn ≥ |⟨n_n - n_m⟩|，除以4得到不等式③。

**证毕**。

### §1.3 任务1.2：等号成立条件 --- 构造显式的2-mode squeezed thermal state

**声称**：存在显式构造的量子态使不等式③的等号成立，且该态是物理上可制备的。

**分析**：Robertson不等式的饱和条件（对纯态）为：
```
(Â - ⟨Â⟩)|ψ⟩ = -iλ (B̂ - ⟨B̂⟩)|ψ⟩
```
其中λ为实数。此条件要求态|ψ⟩是算符(Â_mn, B̂_mn)的"相干态"---即最小不确定态。

**构造方法**：在单粒子子空间内（L=2, N=1）显式构造。

**S3_R2修正后的正确公式回顾**：

对|ψ⟩ = α|10⟩ + β|01⟩（单粒子子空间），正确的方差公式为：
```
ΔC^R = ½√(1 - 4(Re(αβ*))²)
ΔC^I = ½√(1 - 4(Im(αβ*))²)
Δn = ||α|² - |β|²|
```

等号成立条件：ΔC^R·ΔC^I = ¼Δn。

**等号成立的态族**：

**族1：实数αβ*态（Im(αβ*) = 0）**

此时ΔC^I = ½（最大虚部涨落），ΔC^R = ½√(1 - 4|αβ|²)。不等式要求：
```
¼√(1 - 4|αβ|²) ≥ ¼||α|² - |β|²|
```
即 √(1 - 4|αβ|²) ≥ ||α|² - |β|²||。

利用|α|² + |β|² = 1，令x = |α|² ∈ [0, 1]，则|αβ|² = x(1-x)，Δn = |2x-1|。

右手边 = |2x-1|。左手边² = 1 - 4x(1-x) = 1 - 4x + 4x² = (2x-1)²。

因此左手边 = √((2x-1)²) = |2x-1| = 右手边。**等号对所有实数αβ*态精确成立。**

**结论**：所有纯实数αβ*的态（包括|α|²=0,1的Fock态和|α|²=1/2的等权叠加态），不等式③的等号**精确成立**。这验证了下界是紧致的。

**族2：纯虚数αβ*态（Re(αβ*) = 0, |α|² ≠ |β|²）**

此时ΔC^R = ½, ΔC^I = ½√(1-4|αβ|²)。类似计算给出：当|α|²≠1/2时，等号也成立（对称论证）。

**族3：一般复αβ* --- 混合态推广**

对于一般复相位αβ* = |αβ|e^{iφ}，S3_R2的数值验证显示积/下界比从1.00（等号）到约1.13。等号成立的参数条件是Re(αβ*)和Im(αβ*)之一为零且|α|²≠1/2。

**深挖1（第1层）：为什么是这些态？**

等号成立的充要条件（Robertson饱和条件）是(Â-⟨Â⟩)|ψ⟩ ∝ (B̂-⟨B̂⟩)|ψ⟩。在单粒子子空间中，Â等价于σ_x，B̂等价于σ_y。σ_x和σ_y的涨落反对称关联对应的态是：|ψ⟩位于σ_x-σ_y平面的Bloch球赤道上（即⟨σ_z⟩=0或±1，其中⟨σ_z⟩ = |α|²-|β|² = Δn符号的相反数）。当⟨σ_z⟩=±1时（即纯Fock态），两个涨落相等（Δσ_x = Δσ_y = 1），积达到Robertson下界。

**深挖1（第2层）：混合态下的等号 --- 2-mode squeezed thermal state**

对于混合态，Robertson不等式的饱和条件更复杂。我们需要ρ使得：
```
Tr(ρ[A, B]) = 2i Tr(ρ(A-⟨A⟩)(B-⟨B⟩))   (在某种意义下)
```

具体构造：考虑L=2的两模压缩热态：
```
ρ_ξ,β = S(ξ) ρ_β S†(ξ)
```
其中S(ξ) = exp(ξ c†_1 c†_2 - ξ* c_1 c_2)是两模压缩算符，ρ_β = e^{-βH}/Z是热态。

对于这个态族，关联矩阵C = Tr(ρ_ξ,β c† c)可以通过Bogoliubov变换精确计算。存在参数(ξ, β)使得对于特定格点对(1,2)，ΔC^R·ΔC^I精确达到下界¼Δn。

**具体参数条件**：在高温极限(β→0)下，热态趋近于完全混合态（C→½I），所有涨落由经典热涨落主导。在零温极限(β→∞)+压缩参数ξ优化下，纯态的等号条件恢复。中间温度存在连续的等号态族。

**诚实标注**：两模压缩热态中ΔC^R·ΔC^I=¼Δn的精确参数条件需要从Gaussian态方差公式中显式求解。给定S3_R3的Gaussian方差公式：
```
Var(Â) = 2[mean(n) - n_0 n_1 + (C^I)² - (C^R)²]
Var(B̂) = 2[mean(n) - n_0 n_1 + (C^R)² - (C^I)²]
```

等号条件ΔC^R·ΔC^I = ¼Δn变为关于n_0, n_1, C^R, C^I的非线性方程。S3_R3的NESS扫描显示R∈[1.001, 10.579]——说明等号在混合态参数空间中可以从上方任意接近（R→1.001）但不一定达到（R>1严格）。这对Gaussian NESS：等号是否可达取决于是否满足纯态条件（即关联矩阵C的特征值是否在{0,1}中——Slater行列式条件）。

**结论**：纯态中的等号精确可达（族1）；混合态中等号可以无限接近（R→1+），但严格等号仅当混合态退化为纯态时成立。这对No-Go定理的任务2有重要含义。

### §1.4 任务1.3：紧致性证明 --- 下界¼|Δn|是最优的

**证明**：使用§1.3构造的等号态族。

- Δn = |(1+d)/2 - (1-d)/2| = d
- ΔC^R = ½√(1 - (1-d²)) = ½d（由§1.3的计算）

### §1.5 任务1.4：区分"Robertson给出下界"（数学）vs"Δn是下界的物理量"（物理）

**这是S4最核心的诚实切割**。

**数学部分（完全属于Robertson, 1929）**：

Robertson定理断言：对任何自伴算符A, B，ΔA·ΔB ≥ ½|⟨[A, B]⟩|。当我们计算[Â_mn, B̂_mn] = -2i(n̂_n - n̂_m)时，我们做的是**代数计算**。没有任何新原理被引入。下界的存在性（非零当且仅当⟨n̂_n⟩≠⟨n̂_m⟩）是Robertson定理的直接推论。

**物理部分（这是我们的贡献）**：

1. **可观测量重新识别**：Â_mn和B̂_mn不是任意的自伴算符——它们是关联矩阵的"正交可观测量"（quadrature observables）。Â_mn测量关联的"实部"（同相分量），B̂_mn测量关联的"虚部"（正交相分量）。将它们识别为"关联的正交分量"是新的。

2. **下界的物理量识别**：⟨n̂_n - n̂_m⟩ = Δn_mn是格点粒子数差——这是一个**可实验测量的、经典的、非相干的量**。将其与量子相干涨落的乘积下界联系，建立了**经典可观测量（密度梯度）与量子涨落约束之间的定量桥梁**。这不是Robertson的内容——Robertson只告诉你下界是对易子期望值的一半。将下界**诠释**为密度梯度是我们的贡献。

3. **逆命题提取**（No-Go定理核心）：从"若A则B"（若ΔC^R·ΔC^I有非零下界则Δn≠0）导出其逆否命题"若非B则非A"（若Δn=0则下界=0——不等式不强制任何ΔC^R·ΔC^I为正）。这个推理在形式逻辑上是平凡的，但其**物理含义**不平凡：**密度均匀系统可以没有任何量子相干涨落**。Robertson定理没有提供这个物理论断——因为Robertson定理不区分"下界=0"和"下界>0"的物理含义。

### §2.5 深挖：No-Go定理的准确逻辑形式

**形式逻辑分析**：

不等式③的逻辑形式是：
```
∀ρ : P(ρ) ≥ Q(ρ)
```
其中P(ρ) = ΔC^R·ΔC^I, Q(ρ) = ¼|⟨n_n⟩_ρ - ⟨n_m⟩_ρ|。

**直接物理陈述**："较大"的量子相干涨落（大P）要求"较大"的密度梯度（大Q）。

**No-Go定理的精确逻辑**：

原命题的**逆否命题**：
```
Q(ρ) = 0 ⟹ P(ρ) ≥ 0
```
这不是No-Go——这是平凡的（P≥0永远成立）。

我们需要的不是逆否命题，而是**非平凡推论**：
```
Q(ρ) = 0 ⟹ inf_{ρ': Q(ρ')=Q(ρ)} P(ρ') = 0
```
即：在密度均匀的子空间中，P的下确界为零——不存在"残留量子相干"。

**第1层深挖：inf = 0 vs inf > 0**

如果inf_{Δn=0} (ΔC^R·ΔC^I) = c > 0（某个正常数），那么即使在密度均匀的系统中，量子相干涨落也被一个正下界强制——这将是一个"最小量子相干原理"。但我们已经证明inf=0（通过Fock态构造）。因此不存在这样的原理。

**第2层深挖：inf = 0的物理后果**

inf = 0意味着：在给定Δn=0的子空间中，可以找到ΔC^R·ΔC^I任意小的态。但这不意味着**所有**Δn=0的态都有小的ΔC^R·ΔC^I——基态就是反例（Δn=0但ΔC^R·ΔC^I可观）。

**这是No-Go定理的精确物理含义**：如果你制备了一个密度均匀的费米子系统，量子相干可以任意小（通过选择合适的态逼近Fock态或高温热态），但也可以任意大（通过制备纠缠基态）。**密度均匀性本身不强制也不禁止量子相干**。只有当你想**同时**具有非零量子相干和密度均匀性时，你才需要某种外部机制（如基态纠缠）来提供相干——但这不是不等式的约束，而是系统动力学的选择。

换句话说：**不等式的非平凡内容是它的正向（ΔC^R·ΔC^I≥¼|Δn|>0→量子相干被强制），而非它的反向（Δn=0→下界=0→量子相干可选）。**

**(b) 对所有格点对(m,n)积分不等式 → 是否蕴含Ĵ=0？**

**也不成立。** 不等式是对每个格点对(m,n)的局域约束的集合。对这些不等式的某类求和可能给出一个关于全局量子涨落的约束，但这与Ĵ=0（涉及时间演化和信息流）是完全不同类型的陈述。

具体来说：对不等式求和可得 Σ_{m<n} ΔC^R_mn·ΔC^I_mn ≥ ¼ Σ_{m<n} |Δn_mn|。但这不涉及时间导数或流——它是纯静态的约束。Ĵ=0是动力学的（含dS_vN/dτ）。

**(c) 违反条件是否一致？**

**这是最有成果的连接方向。**

- 不等式的违反条件：ΔC^R·ΔC^I < ¼|Δn| → 标准量子力学失效（或费米子统计被违反，或隐藏自由度）
- Ĵ=0的违反条件：Ĵ ≠ 0 → 信息在测量过程中不守恒（存在未被追踪的信息源/汇）

**关键问题**：Δn=0且ΔC^I>0是否必然导致Ĵ≠0？

**分析**：

Δn=0且ΔC^I>0意味着系统具有量子相干但密度均匀。这本身不违反不等式③（因为下界=0，不等式平凡满足）。

Ĵ≠0意味着在演化/测量过程中存在未被追踪的信息流。在Lindblad/RWA框架下，Ĵ<0（反退相干）对应于γ^RR>0（环境有效负温度）。在Redfield框架下，Ĵ≠0对应于信息在C^R↔C^I之间的不对称流动。

**表面连接**：如果Δn=0且ΔC^I>0的态在动力学中产生了非零的dS_vN/dt（例如通过非平衡环境），则Ĵ≠0。但这不是强制性的——一个Δn=0, ΔC^I>0的静态态（如基态）具有Ĵ=0（因为没有演化）。

**深层连接**：当系统被驱动出Δn=0的平衡态进入Δn>0的非平衡态时，不等式③获得非零下界。这个非平衡过程伴随着非零的dS_vN/dt和可能的Ĵ≠0。**不等式的"激活"（从下界=0到下界>0）与Ĵ偏离零可能是共生的**——两者都源于非平衡驱动。

### §4.1 实验违反的可能解释

如果实验发现 ΔC^R_mn · ΔC^I_mn < ¼|⟨n_n⟩ - ⟨n_m⟩|：

**前提检查（必须首先排除）**：
1. 方差计算是否正确区分了量子涨落和经典测量噪声？
2. Δn的测量是否精确？（有限统计下的偏差？）
3. 是否有未被计入的环境自由度贡献？

假设这些被排除后，存在三个可能性：

**(a) 标准量子力学失效**

这意味着Robertson不等式（ΔA·ΔB ≥ ½|⟨[A,B]⟩|）在实验系统中不成立。由于Robertson不等式是Hilbert空间量子力学的数学定理，这等价于说**标准量子力学的数学结构需要修正**。

可能的修正途径：
- **非线性量子力学**（Weinberg, 1989, PRL 63, 1115）：波函数的非线性演化可以改变算符的期望值结构，可能允许ΔA·ΔB低于标准下界。但这面临严重的自洽性问题（超光速通信、因果性违反等）。
- **广义概率理论**（GPT, Barrett 2007, PRA 75, 032304）：放宽Hilbert空间的量子力学公理，允许更一般的态空间和测量结构。在GPT中，"不确定性关系"不再是定理而是假设。
- **量子力学的统计诠释修正**：如果Born规则的|ψ|²被修正（例如包含小的高阶项），方差-期望值关系可能改变。

**(b) 费米子统计被违反**

这意味着反对易关系{c_m, c†_n} = δ_mn（或其在关联方差中的后果）在实验系统中不成立。可能的原因：
- **准粒子非费米子性质**：在强关联系统中，元激发可能是anyons（分数统计）或非费米液体——它们的交换统计偏离费米子。
- **有效描述失效**：如果系统的基本自由度不是费米子（而是玻色子对、自旋模型的有效费米子化映射），反对易关系在映射下可能不完全保持。
- **有限温度下的统计修正**：在极高温度或密度下，Pauli原理的有效性可能受到量子引力修正（理论推测，无实验证据）。

**(c) 隐藏自由度**

实验系统中存在未被计入的自由度，使得表观上不等式被违反，但如果在完整的（含隐藏自由度）Hilbert空间中计算，不等式仍然成立。

具体场景：
- **轨道/自旋自由度**：如果费米子有额外的内部自由度（轨道、自旋、能谷），而我们只测量了一个子空间的关联，表观的ΔC^R·ΔC^I可能包含来自其他自由度的贡献→偏差。
- **环境纠缠**：系统与环境之间的量子纠缠使得系统+环境的联合态中的方差分解不同于纯系统态。如果我们追踪掉环境（取部分迹），表观的方差可能不满足Robertson不等式（Robertson不等式在部分迹下不保持）。
- **测量反作用**：态的层析成像本身可能改变系统的关联结构（测量反作用/量子反馈），使得测量的ΔC^R·ΔC^I不是"同一态"的方差→不等式不适用。

### §4.4 深挖（第2层）：如果不等式被违反 --- 新物理的优先级

**最可能的新物理场景排名**：

**排名1（最可能，但最不"新物理"）：隐藏自由度**

原因：所有"令人惊讶"的实验结果中，被忽略的系统自由度的解释历史上占主导地位（如"超光速中微子"→光纤连接器松动；"质子半径之谜"→部分源自氢光谱的系统误差）。任何声称的QM违反都需要首先排除隐藏自由度。

**排名2（次可能，有理论动机）：环境纠缠引起的表观违反**

原因：在开放量子系统中，Robertson不等式在部分迹下不保持。随着量子技术达到更高的相干控制，系统-环境纠缠成为越来越重要的系统误差源。但这不是"新物理"——它是在已知理论框架内对表观效应的解释。

**排名3（有趣但需要极高证据）：费米子统计的微小违反**

原因：Pauli原理在非相对论量子力学中是公理——但在量子场论层面（自旋-统计定理）有更深的根源。如果自旋-统计定理有微小的违反（如在量子引力中），它应该在极端条件下（Planck尺度）出现。在桌面实验中观测到这种违反将是非凡的——需要非凡的证据。

**排名4（最不平凡，但证据门槛最高）：标准QM本身的失效**

原因：量子力学在从eV到TeV的能标上被验证到极高的精度（如Lamb移位的QED计算与实验吻合到10^{-12}）。在桌面冷原子/qubit实验中发现QM违反的概率极低——但如果有，影响将是革命性的。

**"新物理"信号的保守策略**：不将不等式③定位为"新物理的探针"（暗示它可能找到新物理），而是定位为"量子力学自洽性的新型检验"——提供一个在以前被忽视的测量通道（关联涨落×密度梯度）中验证量子力学的机会。如果检验通过→量子力学在这个新通道中获得新的验证。如果检验失败→启动隐藏自由度的系统排查→只有在该排查穷尽后才考虑新物理。

## §5 综合深挖

### §5.1 深挖1：不等式③与Bell不等式的结构对比

**第1层：数学结构的对比**

| 特征 | Bell不等式 | 不等式③ |
|------|-----------|---------|
| 类型 | 局域实在性约束 | 量子不确定性约束 |
| 数学来源 | 经典概率+局域因果 | Robertson不等式（QM内部） |
| 被谁违反？ | 被QM预测违反 | 在QM内部永远满足 |
| 违反意味着？ | QM成立，局域实在性不成立 | 标准QM可能不成立 |
| "经典极限" | Bell不等式满足←经典行为 | Δn=0←Robertson下界退化←"经典宽容" |

**关键区别**：Bell不等式是"经典世界对量子世界的约束"（QM预测其违反），而不等式③是"量子世界对自己的约束"（QM内部恒成立）。因此不等式的违反比Bell不等式的违反意味着更深的QM危机。

**第2层：违反的结构类比**

Bell不等式被违反 = "局域实在论"是错误的。
不等式③被违反 = 标准量子力学的数学结构（Hilbert空间+Robertson定理）不成立。

两者都是"否定某理论的实验窗口"——但目标不同。Bell不等式的目标是**经典直觉**（局域实在论），不等式③的目标是**量子力学的数学公理**。

**这个对比强化了S4北极星的论述**：不等式③的价值不在于它可能被违反（概率极低），而在于它提供了一个新的**概念组织框架**——Δn作为量子相干的"开关"——这个框架组织了许多已知现象并将它们置于一个统一的不等式之下。

### §5.2 深挖2：No-Go定理在量子热力学中的位置

**问题**：No-Go定理（ΔC^I>0⟹Δn≠0）是否是一个"量子热力学第四定律"级别的陈述？

**第1层分析：热力学定律的对应**

| 热力学定律 | 内容 | 可能的量子对应 |
|-----------|------|--------------|
| 第零定律 | 热平衡的传递性 | ？ |
| 第一定律 | 能量守恒 | d⟨H⟩/dt = 0（幺正演化） |
| 第二定律 | 熵增 | dS_vN/dt ≥ 0（Lindblad）, Ĵ ≥ 0? |
| 第三定律 | 绝对零度不可达 | 纯态制备的资源成本？ |
| "第四定律"? | ？ | No-Go: ΔC^I>0⟹Δn≠0? |

**第2层分析：No-Go是不是"第四定律"？**

**不合格。** 热力学定律是**普适的、模型无关的**物理原理（不依赖于微观模型的细节）。No-Go定理来自费米子反对易关系的代数结构——它依赖于费米子统计。在玻色子系统中，Â和B̂的对易关系不同，不等式形式不同，No-Go也不相同形式。

因此No-Go定理是**基于费米子统计的特定推论**，而非普适的量子力学或热力学原理。它更类似于"Pauli原理→Hund规则"这样的特定推论，而非"能量守恒"这样的普适原理。

**但它作为"量子-经典桥梁"的价值是真实的**：它提供了一个简单的判据（Δn = 0?）来判断量子涨落的约束是否退化。这在概念上类似于"温度T=0?"判断热涨落是否消失——但更为基础和数学上严格。

### §6.2 核心新增定理/声称

**定理1（No-Go，精确形式）**：
> 在有限费米子系统中，对于任意格点对(m,n)：
> (i) 正向：ΔC^R_mn·ΔC^I_mn ≥ ¼|⟨n_n⟩_ρ - ⟨n_m⟩_ρ|对所有量子态ρ成立（Robertson推论）
> (ii) 反向：inf_{ρ: ⟨n_n⟩=⟨n_m⟩} ΔC^R_mn·ΔC^I_mn = 0，且该下确界可达
> (iii) 因此：不存在"最小量子相干原理"——Δn=0的系统中ΔC^I可以连续衰减至零而不违反任何物理定律

**定理2（紧致性）**：
> 下界¼|Δn|对于给定的Δn值是最优的——存在态族（实数αβ*纯态）精确饱和不等式。

**声称3（违反判据）**：
> 如果实验发现ΔC^R·ΔC^I < ¼|Δn|，必须首先排除三种"平庸"解释：(c)隐藏自由度（最可能）、(b)费米子统计违反（次可能）、(a)标准QM失效（最不平凡）。提供了实验鉴别协议和量级估计。

### §6.3 诚实边界

1. **不等式③不是新数学定理**——它是Robertson不等式的应用。新的是：(a) 将下界表达为Δn；(b) 识别了No-Go推论；(c) 区分"经典宽容"和"量子强制"。

2. **Ĵ=0与不等式③的连接是概念层面而非推导层面**的。声称"微分形式"或"积分蕴含"在数学上不准确。

3. **No-Go定理依赖费米子统计**——不是普适的量子力学原理。

4. **混合态的等号条件**：虽然纯态中等号可达，但在真实Gaussian NESS中，等号只能从上方趋近(R→1.001+)而非精确达到。

5. **违反的条件分析假设实验违反已经发生**——在当前技术水平下，这样的违反尚未被观测到，且根据S3的85,639态数值证据，在标准QM内不应被发现。

### §6.4 最弱环节

1. **Ĵ=0的"粗粒化猜想"**（§3.4）完全没有数学支撑——是纯定性推测。
2. **No-Go定理的L>2推广**依赖于"L=2子空间嵌入"的逻辑——在多体态中，ΔC^I=0而其他关联非零的态的构造未给出显式公式。
3. **实验排除(b)和(c)的精度估计**依赖于超导qubit的参数假设——不同平台的可行精度可能显著不同。
4. **"No-Go定理"这个名称**可能过于夸大——实际上它说的是"密度梯度为零时不等式退化"，而非"某种东西被禁止"。
