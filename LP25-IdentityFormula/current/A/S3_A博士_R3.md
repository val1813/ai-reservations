## S1 任务1: NESS数值验证（最高优先级）

### S1.1 方法：L=2 Gaussian NESS解析参数化

**为什么是L=2？** L=2是唯一可以完整解析处理所有参数区域的系统。在L=2中，关联矩阵C是2×2矩阵，完全由一个复参数α = C_01和两个对角元n_0, n_1参数化：

```math
C = [[n_0, α], [α*, n_1]]
```

对于Gaussian费米子态（自由费米子的NESS必然是Gaussian的），Wick定理将四阶关联约化为二阶关联的乘积，方差可以通过关联矩阵精确计算。

**方差公式（Gaussian态，Wick定理严格推导）**：

对于Â = c†_1 c_0 + c†_0 c_1, B̂ = i(c†_1 c_0 - c†_0 c_1)（m=0, n=1记为0,1）：

```math
\begin{aligned}
\langle Â \rangle &= 2C^R \\
\langle Â^2 \rangle &= n_0 + n_1 + 2|α|^2 - 2n_0 n_1 \\
\text{Var}(Â) &= n_0 + n_1 + 2|α|^2 - 2n_0 n_1 - 4(C^R)^2 \\
&= 2\left[\frac{n_0+n_1}{2} - n_0 n_1 + (C^I)^2 - (C^R)^2\right]
\end{aligned}
```

类似地：
```math
\text{Var}(B̂) = 2\left[\frac{n_0+n_1}{2} - n_0 n_1 + (C^R)^2 - (C^I)^2\right]
```

其中α = C^R + i C^I。

**关键结构**：Var(Â) - Var(B̂) = 4[(C^I)² - (C^R)²]。实部和虚部方差的差异直接由C^R和C^I的不对称性决定。

**物理性约束**：C的特征值在[0,1]内 → |α|² ≤ min(n_0 n_1, (1-n_0)(1-n_1))。

```
--- INSPECTOR_CHECK ---
[公式] Var(Â) = 2[mean(n) - n_0n_1 + (C^I)² - (C^R)²]; Var(B̂) = 2[mean(n) - n_0n_1 + (C^R)² - (C^I)²]
[方向] Wick定理严格推导，对任何Gaussian费米子态精确成立
[数据] 与R2修正2的L=2纯态公式一致性验证通过（纯态时|α|²=n_0n_1, 退化一致）
[假设] Gaussian态（自由费米子NESS的自然性质）
```

### S2.2 深挖：为什么基态更紧致？（反直觉的物理）

**直觉预期（被数值否证）**：NESS因Δn>0而比基态（Δn=0时下界=0）"量子性更强"，所以NESS的不确定关系应该更紧。

**数值事实**：基态在相同的Δn下总是更紧致。

**第1层解释（几何）**：
基态是纯态 → 关联最大（\|α\|² = n_0 n_1, 对于自由费米子） → C^I接近最大可能值 → Var(B̂) → 0 → ΔC^I很小。
NESS是混合态 → 关联被热涨落抑制（\|α\|² < n_0 n_1） → C^I较小 → Var(B̂)较大 → ΔC^I较大。

关键是：在固定Δn时，**较小的CI反而使ΔC^I更大**（因为Var(B̂) = 2[mean(n) - n_0n_1 - (C^I)²]，CI减小→Var(B̂)增大→ΔC^I增大→乘积增大→R增大）。

**第2层解释（信息论）**：
基态：所有可用的量子关联都已被利用（最大化\|α\|）→不确定性被压缩到Robertson下界附近。NESS：热涨落引入额外的经典不确定性→关联被稀释→不确定性增大。这类似于：纯态的纠缠达到最大值，混合态的纠缠被热噪声稀释。

**这意味着"量子增强"寻找的方向需要反转**。不是"NESS中有更大的量子不确定性"——恰恰相反——**基态中量子不确定性被压缩到接近下界，NESS中热涨落使不确定性膨胀超过下界**。真正的量子特征（作为区别于热噪声的特征）是**R接近1**而非R很大。

**可检验预言**：在实验上，通过加热系统（从基态过渡到热NESS），监控R(t)的变化。如果加热过程中R增大 → 确认热涨落主导。如果加热过程中R减小 → 指示量子相干被热涨落增强（非平凡效应）。


### S2.3 "量子增强"参数区的重新定义

**原问题（R1-R2）**: 寻找"NESS中不确定性比基态显著更大的区域"。

**R3修正**: 不确定性在NESS中确实更大，但这是因为热涨落而非量子效应。真正的"量子增强"应定义为：**在相同热噪声水平下，量子系统的不确定性乘积比经典系统更接近Robertson下界**。

**操作定义**：
```math
\text{量子增强度} \equiv \frac{R_{\text{classical thermal}} - R}{R_{\text{classical thermal}} - 1}
```

其中R_classical thermal是相同(n_0, n_1)下经典热态（无量子关联，C^R=C^I=0）的R值：
```math
R_{\text{classical}}(n_0, n_1) = \frac{(n_0+n_1)/2 - n_0 n_1}{\frac{1}{4}|n_1 - n_0|}
```

对于C^R=C^I=0的经典热态，Var(Â)=Var(B̂)=2[mean(n)-n_0n_1]，ΔC^R=ΔC^I=sqrt(mean(n)-n_0n_1)/√2，乘积=(mean(n)-n_0n_1)/2。

**极端非平衡（大Δn, n_0→0, n_1→1）**：mean(n)=1/2, n_0n_1→0 → R_classical → 1（乘积→1/4, 下界→1/4）。在这个极限下，经典热态和量子基态都接近饱和——无法区分。

**最大量子增强参数区**：Δn中等（0.2-0.5），温度低（T≪J），强非平衡驱动（化学势差Δμ≫T）。此时基态R≈1.02-1.11而热态R≈1.78-2.53，量子增强度≈0.9。

### S3.1 dV/dt > 0 的反退相干条件

**精确公式**（B博士R2独立发现，INSPECTOR_B确认）：
```math
\frac{dV}{dt} = 2\sum_k \left[\gamma^{RR}_k (c^R_k)^2 + \gamma^{II}_k (c^I_k)^2\right]
```

交叉项（γ^RI, γ^IR, λ_k）**精确抵消**。

**dV/dt > 0 的充要条件**（单模，γ^II < 0为正常阻尼）：
```math
\left(\frac{C^R}{C^I}\right)^2 > \frac{|\gamma^{II}|}{\gamma^{RR}} \quad \text{且} \quad \gamma^{RR} > 0
```

**物理条件**：
- γ^RR > 0：需要模式经历粒子数反转（类似于激光的负温度），使环境对实部涨落产生增益而非损耗
- C^R/C^I足够大：实部涨落分量支配虚部

### S3.4 实验协议（5步）

**步骤1 — 制备（Preparation）**：
- L=2超导qubit链，每个qubit独立可寻址

- 具体：α ≈ √0.8, β ≈ √0.2 → C^R_01 ≈ 0.4, C^I_01 ≈ 0

**步骤2 — 驱动（Drive）**：
- 左qubit：强共振微波驱动（Rabi频率 Ω_L ≫ J），产生n_0≫n_1
- 右qubit：弱或无驱动，n_1 ≈ 0
- 驱动强度通过flux偏置线调制耦合到环境的η
- 环境由每个qubit的读出谐振腔+Purcell滤波器构成（已存在于标准transmon芯片）

**步骤3 — 测量（Measure）**：
- 在时间点 t = 0, 20, 40, ..., 1000 ns 进行全两qubit态层析成像（full 2-qubit tomography）
- 从tomography结果重建关联矩阵：
  - C^R_01(t) = ½⟨σ^x_0 σ^x_1 + σ^y_0 σ^y_1⟩（在qubit基下，通过Jordan-Wigner变换联系费米子）
  - C^I_01(t) = ½⟨σ^x_0 σ^y_1 - σ^y_0 σ^x_1⟩
- 计算 V(t) = (C^R_01)² + (C^I_01)²
- 数值微分获取 dV/dt(t) ≈ [V(t+Δt) - V(t)]/Δt

**步骤4 — 检测（Detect）**：

- 系统性偏差 dV/dt - dV/dt_Lindblad > 0 → 反退相干确认

**步骤5 — 对照（Control）**：
- 对称驱动（n_0=n_1）：Δn=0 → Robertson下界=0 → 不等式无约束力
- 预期：dV/dt < 0始终（标准退相干）

### S4.3 诚实边界：我们NOT声称的

1. **不是新不等式**：ΔC^R·ΔC^I ≥ ¼\|Δn\|是Robertson定理的推论。新的是将下界表达为可测量的粒子数差，而非发现一个新的数学不等式。

2. **不是新动力学方程**：dC/dt = i[C, h]是Heisenberg运动方程的标准推论（Peschel & Eisler 2009及此前文献均有）。新的是(i)"欧拉动力学"的概念命名和实-虚耦合的物理解释；(ii)开放系统推广中交叉项抵消的证明（B博士独立贡献）。

3. **dV/dt>0 ≠ 永动机**：反退相干（Ĵ<0）是开放量子动力学中已知的现象——当环境处于非平衡态（有效负温度）时，信息/相干可以从环境回流系统。这不违反热力学第二定律（总熵仍增加）。

4. **Δn不是严格序参量**：Δn-质量参数的类比是启发性（heuristic）的，不是严格的Landau-Ginzburg型理论。Δn本身是驱动产生的外部量，不是系统自发对称性破缺的序参量。

5. **基态R分布vs NESS R分布的对比仅在L=2解析验证**：推广到L>2需要更多数值工作。基于L=2结果的普遍性声明是有限度的。

## S5 综合深挖

### S5.1 深挖1: 不等式的量子信息含义

**问题**：为什么ΔC^R·ΔC^I ≥ ¼\|Δn\|这个看似简单的公式在已知文献中未被显式写出？

**第1层答案（技术）**：在凝聚态物理中，人们通常关心关联函数本身（⟨c†c⟩的期望值）而非其方差。方差的计算需要四点关联函数——在Gaussian态之外，这需要完整的四阶张量收缩。因此，这个不等式的"原材料"存在（Robertson定理+对易子[-2i(n̂_n-n̂_m)]），但组合起来需要动机。

**第2层答案（概念）**：这个不等式的价值不在其数学深度，而在其**物理组织能力**——它用一个简单的量（Δn，粒子数差）组织了：
- (a) 平衡态的"经典宽容"（Δn=0→下界=0→C^R和C^I可独立任意小）
- (b) 非平衡态的"量子强制"（Δn>0→至少一类涨落必须非零）
- (c) 贝尔型"量子-经典边界"（存在一类态——Δn=0的平衡态——可以经典地模拟量子关联的所有可观测量？不。Δn=0时下界为零，允许但不强制ΔC^R=ΔC^I=0。量子纠缠可以存在于Δn=0的态中，但不受此不等式的约束。）

**第3层答案（最深——与其他量子约束的关系）**：
此不等式与纠缠熵的面积律（area law）有共同的起源：两者都源于自由费米子Gaussian态中关联矩阵的谱性质。对于基态，C的谱（即占据数本征值的分布）决定了纠缠熵；同一谱通过(n_0, n_1)通过本征值分布体现。从C的谱到(n_0, n_1, C^R, C^I)的映射是高度非局域的——这解释了为什么Δn_mn可以为零（平衡）而纠缠熵非零（基态纠缠）。不等式中最重要的"缺失"是：它只约束了格点对(m,n)的局域涨落，不对系统的全局量子性（如纠缠熵、拓扑序）做任何声张。

### S5.2 深挖2: 交叉项抵消的深层代数

B博士R2独立发现：dV/dt中的幺正交叉项（λ_k项）和耗散交叉项（γ^RI, γ^IR项）同时精确抵消。本R3提供该抵消的群论解释。

**解释**：在H的本征基下，封闭系统的动力学是SO(2)旋转：d/dt [c^R_k; c^I_k] = λ_k [[0, -1]; [1, 0]] [c^R_k; c^I_k]。SO(2)保持R² = (c^R_k)² + (c^I_k)²不变。

Redfield张量的对角部分（γ^RR, γ^II）破缺SO(2)到R_+（标度变换）：R² → e^{2γ^RR t}(c^R_k)² + e^{2γ^II t}(c^I_k)²（在两种耗散率不同时）。

Redfield张量的交叉部分（γ^RI, γ^IR）：在KK关系γ^IR = -γ^RI下，这部分矩阵 [[γ^RI, 0]; [0, γ^IR]] = γ^RI [[1, 0]; [0, -1]] 是SO(1,1)（Lorentz boost）生成元。SO(1,1)保持的是(c^R)² - (c^I)²（而非(c^R)² + (c^I)²）不变。**因此SO(1,1)部分对SO(2)的不变量R²的导数没有贡献**——这解释了交叉项为何在dV/dt中精确消失。

λ_k项：来自幺正演化的SO(2)旋转保持R²不变（旋转不改变向量长度）→ 对dV/dt无贡献。

**代数本质**：dV/dt是SO(2)不变量R²的导数。幺正部分（SO(2)旋转生成元）对SO(2)不变量的作用恒为零；耗散交叉部分（SO(1,1) boost生成元）对R²的作用投影到交叉项（由KK关系强制为零）。只有对角耗散部分（标度变换）改变R²。

**这解释了为什么这个"交叉项抵消"如此普遍**——它不依赖于具体的谱密度J(ω)，只依赖于：(1) 幺正部分保持R²；(2) 耗散交叉部分被KK关系约束为SO(1,1)型。

```

[方向] 群论解释：交叉项抵消是SO(2)→R²和李代数结构的必然结果
```

### S5.3 深挖3: 为什么INS不紧致？（多体效应）

**问题**：在基态扫描中，最大R≈0.989 < 1——不等式不紧致。为什么？

**R2的深挖1**（第1层）将此归因于"多体结构（Pauli原理、关联函数的代数约束）"。R3提供更具体的机制。

**原因**：Robertson不等式的饱和条件为 (Â - ⟨Â⟩)\|ψ⟩ = -iλ (B̂ - ⟨B̂⟩)\|ψ⟩。对于多体基态，Â和B̂是作用于整个多体Hilbert空间的算符。这个条件在完整的多体Hilbert空间中要求态是Â和B̂的"相干态"——即最小不确定态。对于包含L>2个格点的多体基态\|ψ_0⟩，即使基态是单个Slater行列式（Gaussian态，关联矩阵是最简单的可能形式），Â和B̂作为多体算符并不自动满足相干态条件——因为Â涉及的是两个格点（m和n）之间的"双模压缩"型互关联，而基态的全体本性涉及所有L个格点的全局结构。

**简单地说**：Fock态\|10...0⟩中，单个格点对的关联饱和不等式（如赵态L=2）；但在多体基态中，每个格点对"分到的量子相干"少于Fock态，因为相干被分摊到L(L-1)/2个格点对上。多体态的"相干预算"是有限的——Pauli原理限制了每个格点可以参与的独立相干通道的数量。

**可检验推论**：在L→∞的热力学极限下，对于固定填充因子的基态，min_{m<n} R_mn → 0（因为相干被无限稀释）。与此相反，对于只有两个粒子占据L个格点的态（稀疏量子态），R可以保持O(1)——因为相干只在一对格点间集中。

## S7 最弱环节（诚实标注）

1. **NESS验证仅限于L=2 Gaussian态**：虽然Gaussian态覆盖了自由费米子NESS的全部参数空间，但84,400态仍只是L=2的一个有限参数扫描。向L>2推广需要更大Hilbert空间和DMFT方法——当前计算资源不足以系统扫描。

2. **dV/dt>0的实验可行性基于单模单粒子反转假设**：在真实的多模多体系统中，γ^RR可能被多个模式的平均效应稀释。需要完整的Redfield张量数值模拟确认γ^RR>0的可行性。

3. **Δn-质量参数类比是启发性（heuristic）的**：没有严格的Landau-Ginzburg型有效理论支持。Δn不是对称性自发破缺的序参量，而是外部驱动的函数。

4. **多体"相干预算"稀释机制是推测性的**：L→∞时min R → 0的推测需要大L的DMRG/量子蒙特卡洛验证。

5. **声张1的"新性"**：不等式本身是Robertson定理的推论。新的是物理情境（关联矩阵元的量子涨落 + 下界联系到粒子数差）+ 多维数值验证覆盖范围（85,625态）。
