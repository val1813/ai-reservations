## CHECK 2: 冷原子实验协议C^I测量方案可行性

### 2.1 方案逻辑重建

文档提出的方案A（TOF+噪声关联）：

```
噪声关联(HBT)  →  G^(2)(r_i,r_j) = -|C_ij|²     →  |C_ij|（幅度，无相位）
TOF成像        →  n(k) = |w̃(k)|² Σ_{i,j} e^{ik·r_ij} C_ij  →  arg(C_ij)（相位）
联合           →  C^R = |C|cos(arg), C^I = |C|sin(arg)
```

### 2.2 外部文献交叉验证

**关键发现1: 文档引用的"Bloch组2017, Nature Physics"未能在地面搜索中确证。**

- Gross & Bloch (2017) 确实存在，但是发表在 **Science** 357, 995-1001，不是 Nature Physics。这是一篇综述文章，涵盖了量子气体显微镜的通则，但**没有描述从TOF+噪声关联联合重建复C_ij的具体protocol**。
- 最接近的方法论论文是 **Pena Ardila, Heyl, Eckardt (2018)** "Measuring the single-particle density matrix for fermions and hard-core bosons in an optical lattice" (arXiv:1806.08171)。该论文提出的方案与文档描述有重要差异：使用Bloch球旋转+淬火Hamiltonian，**不依赖TOF**，完全基于单格点密度读取—这是一种更直接但需要工程化势能淬火的方法。
- 噪声关联（HBT效应）在冷原子中的经典参考文献是 **Altman, Demler, Lukin (2004) Phys. Rev. A 70, 013603** 和 **Fölling et al. (2005) Nature 434, 481**。这些工作测量的是|C_ij|²，不包含相位。

**关键发现2: TOF相位反演是一个病态逆问题。**

- TOF信号n(k)是C_ij的离散Fourier变换乘以Wannier包络|w̃(k)|²。对L×L格点，有L²个实对角元n_i和L²(L²-1)/2个复非对角元C_ij → 需要从~L²个k空间像素恢复~L⁴量级的复参数。即使有先验近似（如短程C_ij截断），反演的数值条件数随L快速恶化。
- 噪声关联给出|C_ij|²：对费米子，G^(2)(r_i,r_j) = ⟨n_i⟩⟨n_j⟩ - |C_ij|²（带负号的1/shot相关）。这确实给出幅度信息但与TOF独立——不能被"联合"来改善TOF的相位重建条件数，因为噪声关联不提供相位信息。
- 所以实际上：TOF**必须独自**恢复arg(C_ij)。噪声关联只提供交叉检查（验证|C_ij|是否与TOF反演一致），不帮助相位。

### 2.3 具体可行性评估

| 子任务 | 可行性 | 证据 |
|--------|--------|------|
| 密度n_i测量 | 高 (90%) | 量子气体显微镜已经常规做到单格点/单原子分辨 (Gross&Bloch 2017综述) |
| \|C_ij\|²测量 (HBT噪声关联) | 中高 (80%) | 已在多个实验实现(fölling 2005, Greiner 2005)；需要足够shot数 |
| TOF→arg(C_ij) 相位重建 | **中低** (50%) | TOF反演对2D系统是病态的；需要正则化；已有1D示范但2D推广未在文献中证成 |
| C^I_ij 从联合重建 | **中低** (50%) | 受限于TOF的相位精度 |
| 不等式检验统计量 | 中高 (75%) | 只要C^R/C^I有合理SNR，统计检验可行 |
| 整体方案 | **中 (65%)** | 文档标注70%偏乐观——建议降低到60-65%范围 |

### 2.4 关键遗漏：Peña Ardila 2018的替代方案

文档完全未提及 Peña Ardila, Heyl, Eckardt (2018) 的方案，该方案使用：
- 量子态旋转（淬火到特定Hamiltonian）将复C_ij的实部和虚部分别映射到布居数n_i
- 只需单格点密度读取（不需要TOF，不需要噪声关联）
- 直接得到C^R_ij和C^I_ij的数值

这个方案可能比TOF+噪声关联更实用，特别是对不等式检验需要扫描大量格点对的场景。建议B博士在R2中补充引用和讨论。

## CHECK 3: "Coherence is not free"类比与热力学定律数学结构的一致性

### 3.1 热力学类比的两个层面

文档在§1中区分了两个层面：

**层面A: 讲述层面（Fourier热传导）**：
- J_Q = -κ∇T: 温度梯度驱动热流（线性响应+因果定律）
- 平衡: ∇T=0 → J_Q=0
- 约束: σ = J_Q·∇(1/T) ≥ 0（熵产生非负，第二定律）

**层面B: 深层数学同构（信息论）**：
- 非均匀概率分布→非零信息量
- 均匀分布→最大熵→零信息
- Fisher信息不等式: Var(θ̂) ≥ 1/I(θ)

**No-Go定理的结构**：
- ΔC^R·ΔC^I ≥ ¼|Δn|: 密度差强制涨落乘积下界（运动学约束+强制不等式）
- Δn=0 → 下界=0: 均匀密度允许经典极限

### 3.2 数学结构交叉验证

首先，与量子热力学文献中真正存在的类比进行比较。从搜索返回的结果：

- **Rodríguez-Rosario et al. (arXiv:1308.1245)**: 量子相干可以在**没有温度梯度**的情况下驱动热流——这直接**违反**了"没有梯度就没有流"的类比结构。热力学中真正的Onsager量子推广是超算符层面的互易关系(𝕄_{b,a} = 𝕄_{a,b}†)，与文档中映射的J_Q↔ΔC^R·ΔC^I在数学类型上完全不同。

- **结论**: 文档的类比不是从量子热力学文献中提取的已有同构，而是B博士构造的新类比。这一点文档未声明——它暗示了物理学传统的延续性（"Fourier 1822→Onsager 1931→Prigogine 1977"），但没有警告读者这个特定类比**在量子热力学文献中找不到直接对应**。

### 3.3 逐个数学结构的对齐分析

| 数学结构 | 热力学 | No-Go定理 | 是否真正对齐？ |
|----------|--------|-----------|---------------|
| 梯度算子类型 | ∇作用于连续标量场T(r) | Δn作用于离散格点标量 | **部分对齐** — 两者都是标量空间差异，但微分vs离散差有本质区别。热力学可以通过离散化得到ΔT_n=T_n-T_{n-1}，这是技术差异不是概念差异。 |
| 响应变量类型 | J_Q(r)是矢量场（通量=通量密度×面积） | ΔC^R·ΔC^I是标量（两个涨落的乘积） | **不对齐** — 矢量vs标量。流有方向；涨落乘积没有方向。文档在§1.1中标注为"中"同构程度——承认了这一点。 |
| 守恒律 | J_Q满足连续性方程dQ/dt+∇·J_Q=0（能量守恒） | ΔC^R·ΔC^I不满足任何守恒律 | **不对齐** — No-Go约束没有守恒量。热力学的"流"背后有能量守恒；No-Go没有对应的守恒量。 |
| 约束类型 | σ = J_Q·∇(1/T) ≥ 0 — 这是**速率约束**，涉及时间导数 | ΔC^R·ΔC^I ≥ ¼\|Δn\| — 这是**瞬时约束**（不管时间演化） | **不对齐** — 热力学第二定律约束的是过程的方向（不可逆性）；No-Go不等式约束的是态空间本身的几何（与时间无关）。这是一个深刻的数学类别差异：前者是d/dt(某量)≥0；后者是f(态)≥g(态)。 |
| 驱动的因果性质 | 线性响应：J_Q=κ∇T→梯度是因，流是果。因果箭头在方程中。 | ΔC^R·ΔC^I ≥ ¼\|Δn\|→两边在同一态中同时确定，无因果箭头。 | **不对齐** — 文档在§1.3中诚实标注了这一点（"不等式是约束，不指明因果箭头"）。 |
| 平衡特征 | 平衡是attractor→系统趋近于∇T=0（τ∼L²/α扩散时间） | "经典极限"不是attractor→Δn=0时相干可以为零也可以不为零 | **不对齐** — 热力学平衡是系统的必然归宿（给定足够时间）；No-Go的"经典极限"是可选的（下界为零不强制相干为零）。这是文档§1.2的核心"逆命题"问题。 |

### 3.4 "X不是免费的"框架的物理史定位（文档§3的深挖4）

文档在深挖4中将"Coherence is not free"与其他"No-free-X"原理并列：
- 能量不免费 → 热力学第一定律
- 功不免费 → Carnot效率（第二定律）
- 信息不免费 → Landauer原理
- 确定性不免费 → 不确定性原理
- **相干不免费 → No-Go定理**

**分析**：

这个列表在修辞上是强大的——每个物理学家都熟悉这些"no-free"约束。但在数学一致性上有等级差异：

| "不免费"原理 | 数学形式 | 约束类型 |
|-------------|---------|---------|
| 能量 | ΔE = Q + W（守恒律） | 等式（记账） |
| 功 | η ≤ 1 - T_c/T_h（效率上限） | 不等式（过程效率） |
| 信息 | W ≥ kT ln 2（擦除1 bit的最小功） | 不等式（资源成本） |
| 确定性 | ΔxΔp ≥ ℏ/2 | 不等式（态空间约束） |
| **相干（本文）** | ΔC^R·ΔC^I ≥ ¼\|Δn\| | 不等式（态空间约束） |

No-Go定理在数学结构上最接近的是**不确定性原理**（都不是速率约束，不涉及守恒律，不涉及过程效率——都是态本身的结构约束）。这比"热力学第二定律"类比更诚实。**文档在§1.2中已经指出信息论是最深同构，但选举热力学为"讲述"类比——这一选举策略本身没有问题（热力学讲故事的power更强），但在数学一致性的诚实标注上可以更明确地区分"深层结构=不确定性原理家族成员"vs"修辞结构=热力学类比"。**

### 3.5 判决

| 维度 | 结果 |
|------|------|
| 类比自洽性 | **部分通过** — 类比在其宣称的层面（讲述）是自洽的 |
| 数学结构对齐 | **弱** — 6个数学结构维度中仅2个部分对齐，4个不对齐。文档意识到了大部分差异并标注 |
| 现有量子热力学文献对照 | **不通过** — 类比在文献中无直接对应，文档暗示了不存在的延续性 |
| 诚实标注 | **部分通过** — 关键差异（因果方向、矢量vs标量、速率约束vs瞬时约束）已标注；但标注集中在启发式/数学区别的通用声明上，而非逐个差异的硬性对照 |
