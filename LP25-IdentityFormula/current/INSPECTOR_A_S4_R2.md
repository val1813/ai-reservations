## 检查1: §4.3 对易子修正下界公式 —— 数学逐行验算

### 状态: FAIL（Model A 含有新的因子错误，修正不彻底）

### 1.1 Model B 验算（通过 ✓）

输入:
```
[Â, B̂]_ε = -2i(n̂_n - n̂_m) + ε_s·i(n̂_n + n̂_m)
     = i(-2Δn̂ + ε_s N̂_pair)
```

步骤:
```
⟨[Â,B̂]⟩ = i(-2Δn + ε_s N_pair)
|⟨[Â,B̂]⟩| = |2Δn - ε_s N_pair| = 2|Δn - ε_s N_pair/2|
```

```
4 ΔC^R·ΔC^I ≥ |Δn - ε_s N_pair/2|
ΔC^R·ΔC^I ≥ ¼|Δn - ε_s N_pair/2|     ✓ 与文档一致
```

**Model B 结果正确。**

### 1.2 Model A 验算（FAIL ✗）

文档声称:
```
ΔC^R·ΔC^I ≥ ½|Δn + ε_d N_pair|          (模型A下界)
```

实际验算:
```
[Â, B̂]_ε = -2i[(1+ε_d)n̂_n - (1-ε_d)n̂_m]
     = -2i[n̂_n + ε_d n̂_n - n̂_m + ε_d n̂_m]
     = -2i[Δn̂ + ε_d N̂_pair]

⟨[Â,B̂]⟩ = -2i(Δn + ε_d N_pair)
|⟨[Â,B̂]⟩| = 2|Δn + ε_d N_pair|
```

Robertson: ΔÂ·ΔB̂ ≥ ½|⟨[Â,B̂]⟩| = |Δn + ε_d N_pair|

除以4转换为 C^R, C^I:
```
4 ΔC^R·ΔC^I ≥ |Δn + ε_d N_pair|
ΔC^R·ΔC^I ≥ ¼|Δn + ε_d N_pair|         ← 正确结果
```

**文档错误**: 写成了 ½，应为 ¼。差了因子2。

**错误定位**: 文档从 |⟨[Â,B̂]⟩| = 2|Δn + ε_d N_pair| 直接跳到 ΔC^R·ΔC^I ≥ ½|Δn + ε_d N_pair|，省略了 Robertson 的 ½ 因子和算子转换的 1/4 因子两步中的一步。Robertson 给出 ½|⟨⟩| = |Δn + ε_d N_pair|，再 ÷4 应得 ¼。文档似乎把 Robertson 的 ½ 用上了（变回 |Δn + ε_d N_pair|）但忘记了 ÷4 步骤，导致最终的 ½ 既不是 Robertson 的 ½ 也不是正确的 ¼。

### 1.3 模型转换关系验算（FAIL ✗）

文档声称: ε_s = -4ε_d

实际验算——令两模型的对易子等价:
```
Model A: [Â,B̂] = -2i[Δn̂ + ε_d N̂_pair] = -2i Δn̂ - 2i ε_d N̂_pair
Model B: [Â,B̂] = -2i Δn̂ + i ε_s N̂_pair
```

第二项相等: -2i ε_d = i ε_s → **ε_s = -2ε_d** ← 正确关系

文档的 ε_s = -4ε_d 差了因子2。

验证——用正确公式代入:
```
Model B (ε_s = -2ε_d): ¼|Δn - (-2ε_d)·N_pair/2| = ¼|Δn + ε_d N_pair| = Model A ✓
```

用文档错误值验证:
```
Model B (ε_s = -4ε_d, 文档声称): ¼|Δn - (-4ε_d)·N_pair/2| = ¼|Δn + 2ε_d N_pair| ≠ ½|Δn + ε_d N_pair| ✗
```

## 检查3: "No-Go = Robertson家族第5成员" 历史声称 —— 历史考证

### 状态: CAUTION（声称是原创分类框架，但"第5成员"的计数和"4个前驱"的构成均非标准史学）

### 3.1 文档声称

> "No-Go判据是Robertson家族的第5个物理成员。"
>
> 前4个:
> 1. 位置-动量 (Heisenberg 1927)
> 2. 角动量 (Robertson 1929)
> 3. 光子数-相位 (Dirac 1927)
> 4. 能量-时间 (Mandelstam-Tamm 1945)

### 3.2 成员3（数-相位）的根本问题: Robertson不等式不适用

根据 Louisell (1963)、Susskind & Glogower (1964)、Carruthers & Nieto (1968) 的确立结论:

- **不存在满足 [N, Φ] = -i 的 Hermitian 相位算符**。原因是 N 的谱有下界（n≥0），而满足正则对易关系的算符对必须有双向无界的谱。
- Robertson 不等式的推导要求算符自伴且满足 Schwartz 不等式的域条件。在 Fock 态上，这些条件在 Dirac 的 Φ 算符下不成立——ΔN·ΔΦ = 0 形式"违反" ΔN·ΔΦ ≥ ½。
- 物理上，数-相位不确定性确实存在，但通过 Susskind-Glogower 正弦/余弦算符或 Pegg-Barnett 有限维形式化实现——这些不是 Robertson 不等式的直接应用。

**结论**: 将"数-相位"列为"Robertson 家族成员"在技术上是错误的。它不是 Robertson 不等式的实例——它根本不在 Robertson 不等式的有效应用域内。

### 3.3 "4个前驱"列表的非唯一性

Robertson 不等式(ΔA)(ΔB) ≥ ½|⟨[A,B]⟩| 是一个**模板**，任何自伴算符对 (A,B) 代入后都产生一个不等式实例。以下实例同样可以声称是"成员":

| 算符对 | 下界 | 发现者 | 为何不在文档列表中？ |
|--------|------|--------|---------------------|
| 自旋分量 S_x, S_y | ½|⟨S_z⟩| | 与角动量同构，合并或分列？ |
| 正交分量 X_1, X_2 (量子光学) | ½ | 1970s | 同样非对易 |
| 时间-频率 (信号处理) | ½ | Gabor 1946 | 经典极限 |
| Stokes 参数 S_1, S_2 (偏振) | ½|⟨S_3⟩| | SU(2)结构 |
| 粒子数差-相位差 (两模) | ½|⟨N_diff⟩| | 与本文最接近的前驱 |

**结论**: 确切的"4个前驱"计数是任意的。这个集合不是自然封闭的——Robertson 产生了无穷多个实例。声称"第5个"暗示了排他性顺序（第1→第2→第3→第4→第5），但这个顺序在文献史上不存在。

### 3.4 "家族"框架的归属

在物理学史中，不确定性原理的"家族"或"zoo"是近期科普和综述中的比喻（如 2024-2025 年 arXiv 综述），不是 Robertson 1929 年的分类。文档将"家族"作为 Robertson 本人的分类框架呈现，是时代错置。

### 3.5 更诚实的表述建议

| 当前表述 | 建议表述 |
|---------|---------|
| "Robertson家族第5个物理成员" | "Robertson不等式在量子多体关联观测量上的首个非平凡实例" |
| "前4个成员" | "标准量子力学教材中讨论的4个典型实例（位置-动量、角动量、数-相位、能量-时间）——需注意数-相位实例在数学上有已知的 caveat" |
| "PRL级声称" | 降低至"新实例声称"——数学上正确，历史上的"第5个"次序不可辩护 |

## 检查4: 七项实验测试 (T1-T7) 逻辑自洽性

### 状态: CAUTION（概念框架自洽，但存在三个逻辑裂缝和一个暗含假设）

### 4.1 判据表的逻辑结构

T1-T7 的判据表 (§3.2.1) 旨在区分三种违反场景。检查每项预测的逻辑推导:

**T1 (多Δn扫描)**: 
- (a) η-1 = const: 如果 Robertson 不等式本身不成立，修正项不依赖 Δn → const ✓
- (b) η-1 ∝ N_pair/Δn: 推导——修正下界 ~¼|Δn+ε_d N_pair|，η = (真实 ΔC^R·ΔC^I) / (¼|Δn|)，若实验精确满足修正下界则 η = |Δn+ε_d N_pair|/|Δn| = 1 + ε_d N_pair/Δn。偏差 ∝ 1/Δn → 在 Δn→小 时偏差放大 → ✓
- (c) 无系统性格局: 取决于哪个自由度被迹掉以及它的 Δn 依赖性 → **过于绝对**。隐藏自由度可能产生系统性的 Δn 依赖（如环境耦合强度可能随 Δn 增大而增大）。

**裂缝1**: (c)的预测"无系统性格局"假设隐藏自由度的效应在 Δn 变化时是随机的——但这取决于隐藏自由度是什么。如果迹掉的自旋自由度与格点占据耦合，则偏差可以与 Δn 系统性相关，产生类似(b)的模式。

**T2 (多N_pair扫描)**:
- 涉及独立调控 N_pair = ⟨n_n⟩+⟨n_m⟩ 的能力。在半填充附近改变 N_pair 意味着改变总粒子数——可能与改变 Δn 的实验操作不是独立的。**裂缝2: T1和T2在真实实验中可能不完全解耦**（文档在 §4.6 自认了此点，但判据表中仍将它们列为独立测试）。

**T5 (扩展测量)**:
- (b) 的预测: "纳入更多自由度后仍违反"。这假设费米子统计违反是**基本的**（层级3或4，§3.4）。但如果统计违反是**涌现的/有效的**（层级1或2），则扩展到更基础的微观自由度后应该**恢复**标准统计。**裂缝3: T5对(b)的预测只在基本统计违反假设下成立，与文档自认的层级1/2解释矛盾。**

### 4.2 决策树的排他性假设

决策树 (§3.2.2) 在每个分支点假设单一场景:(a)或(b)或(c)。文档在 §4.6 第4条诚实承认"三者可并存"且"决策树假设了排他性分支——这是一个逻辑张力"。此自认正确。

但附加问题: 决策树的第一个分支点(T1)将(c)放在"η-1 depends on Δn → 无法拟合 ε_d"路径上。这隐含假设(c)永远不会产生 const 对 Δn 的偏差——这违反上述裂缝1。

### 4.3 T7 (Bell/量子Fisher) 的诊断力

T7 对(a)给出"可能同时违反"，对(b)(c)给出"不一定"。这正确但不实用: "可能"和"不一定"都无法用于排除任何场景——T7在决策树中实质上是冗余的（它不能做出任何明确的排除）。

### 4.4 整体评估

T1-T7 作为**概念框架**是有效的——它将三种违反场景的形式性质转化为可检验的预测。裂缝出现在从概念到实验操作的映射中:
1. 解耦假设（T1 vs T2 独立性）
2. (c) 场景的系统性预测（不是所有隐藏自由度都产生随机偏差）
3. T5 与 §3.4 层级1/2的内在矛盾

这些裂缝不影响框架的概念价值，但意味着 T1-T7 在实际实验设计中需要逐项重新论证可操作性。
