## Q2 符号/方向校对

### 2.1 方程①②: 实虚耦合旋向

**公式**: dC^R/dt = -[C^I, h], dC^I/dt = +[C^R, h]

**极限1 (h → 0)**: 两边均为零矩阵 → C 冻结，平凡正确。 ✅
**极限2 (C^I → 0 恒定)**: dC^R/dt = 0, dC^I/dt = [C^R, h]。如果 C^R, h 对易，则 C^I 也恒定 → 一致。 ✅
**极限3 (C^R → 0 恒定)**: dC^R/dt = -[C^I, h], dC^I/dt = 0。如果 C^I, h 对易，C^R 也冻结。 ✅

**欧拉类比**: d(e^{iθ})/dt = -sinθ dθ/dt + i cosθ dθ/dt。类比到矩阵: cos→C^R, sin→C^I, dθ/dt→h。符号匹配。 ✅

**判定**: ✅ 方程①②的符号正确。

### 2.2 对易子符号: [Â_mn, B̂_mn] = -2i(n̂_n - n̂_m)

**独立代数验证** (见§5a详细展开): ✅ 符号正确。

**极限验证**:
- m=n (对角): [Â_mm, B̂_mm] = -2i(n̂_m - n̂_m) = 0。合理——对角元对应的算符是对易的。 ✅
- n̂_n = n̂_m (粒子数相等): 对易子为零。 ✅
- 交换m↔n: 对易子反号。——正确(交换操作符顺序改变符号)。 ✅

**判定**: ✅ 对易子符号正确。

### 2.3 不等式③: ΔC^R_mn · ΔC^I_mn ≥ ¼|⟨n_n⟩ - ⟨n_m⟩|

**极限1 (Δn=0)**: 下界=0 → 不等式退化为 ΔC^R·ΔC^I ≥ 0 (平凡真)。 ✅
**极限2 (Δn→大)**: 强制非零量子涨落 → 物理一致。 ✅

**判定**: ✅ 不等式方向正确。

### 2.4 §1.5 复数H方程: 符号错误 ❌

**文档声称** (§1.5行207-211):
```
dC^R/dt = -[C^I, h^R] - {C^R, h^I}
dC^I/dt = +[C^R, h^R] - {C^I, h^I}
```

**独立代数重推导**:

从 Heisenberg 方程出发 (H = Σ (h^R_jk + i h^I_jk) c†_j c_k, h^R 对称, h^I 反对称):

dc_m/dt = i[H, c_m] = -i Σ_k h^R_mk c_k + Σ_k h^I_mk c_k
dc†_n/dt = i[H, c†_n] = i Σ_k h^R_nk c†_k + Σ_k h^I_nk c†_k

dC_mn/dt = ⟨(dc†_n/dt) c_m⟩ + ⟨c†_n (dc_m/dt)⟩
= (i Σ_k h^R_nk C_mk + Σ_k h^I_nk C_mk) + (-i Σ_k h^R_mk C_kn + Σ_k h^I_mk C_kn)
= i Σ_k (h^R_nk C_mk - h^R_mk C_kn) + Σ_k (h^I_nk C_mk + h^I_mk C_kn)

**文档行203**: `- Σ_k (h^I_nk C_mk + h^I_mk C_kn)` ← 这里是 **减号**。
**正确应为**: `+ Σ_k (h^I_nk C_mk + h^I_mk C_kn)` ← **加号**。

**符号差异的根源**: 文档在 dc†_n/dt 中漏掉了一个符号翻转 (h^I 反对称导致 h^I_jn → -h^I_nj 时产生了 -(-h^I_nj) = +h^I_nj)。该步的代数是:

dc†_n/dt = i[H, c†_n] = i Σ_j (h^R_jn + i h^I_jn) c†_j
= i Σ_j h^R_jn c†_j - Σ_j h^I_jn c†_j           (i·i = -1)
= i Σ_k h^R_nk c†_k + Σ_k h^I_nk c†_k           (h^R对称: h^R_jn=h^R_nj; h^I反对称: h^I_jn=-h^I_nj, 所以 -h^I_jn = +h^I_nj)

文档中 dc†_n/dt 的结果缺少了这个 `+ Σ_k h^I_nk c†_k` 项的正号翻转。

**进一步错误: 对易子 vs 反对易子**

将上述正确结果写为矩阵形式:
dC/dt = i[C, h^R] - [C, h^I]    (全是**对易子**)

分解 C = C^R + iC^I:
dC/dt = i[C^R+iC^I, h^R] - [C^R+iC^I, h^I]
= i[C^R,h^R] + i²[C^I,h^R] - [C^R,h^I] - i[C^I,h^I]
= i[C^R,h^R] - [C^I,h^R] - [C^R,h^I] - i[C^I,h^I]

分离实部虚部:
```
dC^R/dt = -[C^I, h^R] - [C^R, h^I]     ← 正确(对易子)
dC^I/dt = +[C^R, h^R] - [C^I, h^I]     ← 正确(对易子)
```

**文档写的**:
```
dC^R/dt = -[C^I, h^R] - {C^R, h^I}     ← 错误(反对易子)
dC^I/dt = +[C^R, h^R] - {C^I, h^I}     ← 错误(反对易子)
```

文档将 **对易子 [,]** 错误地替换为 **反对易子 {,}**。这是两个不同错误的重叠:
1. 符号错误 (h^I 项的整体符号)
2. 对易子/反对易子混淆

**物理后果**:
- 对易子 [C^R, h^I] 和反对易子 {C^R, h^I} = C^R h^I + h^I C^R 在数值上完全不同。
- 对易子 [C^R, h^I] 代表保守型耦合 (类似于 Heisenberg 运动方程中的对易子结构)；
  反对易子 {C^R, h^I} 代表耗散型耦合 (类似于 Lindblad 方程中的反交换子结构)。
- 文档后续的物理讨论 (例如行215: "类似于衰减项")是基于错误的反对易子形式的。
- 如果 h^I = 0 (纯实数H)，差异消失，方程退化为正确的 ①②。因此文档的纯实数H结果不受影响。

**判定**: ❌ 符号错误 + 对易子/反对易子混淆 (§1.5)。需修正。

### §2.3 L=2 分析的深层检查

**文档声称** (行426):
```
ΔC^R₁₂ = |αβ| / √2
ΔC^I₁₂ = |αβ| / √2
```

**独立算子计算** (2位点，单粒子子空间):

状态: |ψ⟩ = α|10⟩ + β|01⟩, |α|²+|β|²=1
Â₁₂ = c†₂ c₁ + c†₁ c₂ (算符)
B̂₁₂ = i(c†₂ c₁ - c†₁ c₂) (算符)

在单粒子子空间中: Â₁₂ 交换 |10⟩↔|01⟩ (即 Pauli σ_x 在此基下), Â₁₂² = I.
在单粒子子空间中: B̂₁₂ 也类似，B̂₁₂|10⟩ = i|01⟩, B̂₁₂|01⟩ = -i|10⟩, B̂₁₂² = I.

验证: ⟨Â⟩ = ⟨ψ|Â|ψ⟩ = α*β + β*α = 2Re(α*β)
⟨Â²⟩ = ⟨ψ|I|ψ⟩ = 1 (在单粒子子空间中)
ΔÂ = √(1 - 4(Re(α*β))²)
ΔC^R = ΔÂ/2 = ½√(1 - 4(Re(α*β))²)

同理: ⟨B̂⟩ = ⟨ψ|B̂|ψ⟩ = i(α*β - β*α) = -2Im(α*β)
⟨B̂²⟩ = 1
ΔB̂ = √(1 - 4(Im(α*β))²)
ΔC^I = ΔB̂/2 = ½√(1 - 4(Im(α*β))²)

**文档公式**: ΔC^R = |αβ|/√2

**反例测试**:
- |α|=1, β=0 (Fock态 |10⟩): 文档→0。正确→ΔC^R = ½√(1-0) = ½。
  - 文档公式误差: 0 vs ½ (100% 差异)。 ❌
- α=β=1/√2 (等权叠加): 文档→1/(2√2)≈0.354。正确→Re(α*β)=½, ΔC^R=½√(1-1)=0。
  - 文档公式误差: 0.354 vs 0 (无穷大相对误差)。 ❌

**结论**: 文档的 ΔC^R = |αβ|/√2 公式在一般状态下不正确。

**对不等式验证的影响**: 文档声称 "14/14参数组合" 已验证不等式③。但用于计算 ΔC^R 和 ΔC^I 的公式是**错误的**。这可能意味着:
- (a) 外部验证脚本使用了不同的(正确的)方差定义 → 验证本身可能仍然有效；
- (b) 外部验证脚本使用了相同的错误公式 → 验证结果不可靠。

**文档无法独立判断——"用户脚本"是外部依赖。**

**对§2.3后续讨论的影响**: 
- "当|α|² = |β|² = ½时，ΔC^R·ΔC^I = 1/8" → 基于错误公式。正确值应为0 (因为 ΔC^R=0 在等权叠加态)。

## Q5 代数验算

### 5a. 逐步展开

#### 5a.1 方程①② (实数H) — 完整验算

**步骤1**: Heisenberg运动方程。
H = Σ h_jk c†_j c_k, h 实数对称。

[H, c_m] = Σ_jk h_jk [c†_j c_k, c_m]

用恒等式 [AB,C] = A{B,C} - {A,C}B (费米子):
[c†_j c_k, c_m] = c†_j{c_k, c_m} - {c†_j, c_m}c_k
= c†_j·0 - δ_jm·c_k = -δ_jm c_k

[H, c_m] = -Σ_k h_mk c_k
dc_m/dt = i[H, c_m] = -i Σ_k h_mk c_k  ✅

[H, c†_n] = Σ_jk h_jk [c†_j c_k, c†_n]
= Σ_jk h_jk (c†_j{c_k, c†_n} - {c†_j, c†_n}c_k)
= Σ_jk h_jk (δ_kn c†_j - 0) = Σ_j h_jn c†_j

h 对称 → Σ_k h_nk c†_k
dc†_n/dt = i[H, c†_n] = i Σ_k h_nk c†_k  ✅

**步骤2**: 关联矩阵运动方程。
C_mn = ⟨c†_n c_m⟩

dC_mn/dt = ⟨(dc†_n/dt)c_m⟩ + ⟨c†_n(dc_m/dt)⟩
= ⟨i Σ_k h_nk c†_k c_m⟩ + ⟨c†_n (-i Σ_k h_mk c_k)⟩
= i Σ_k h_nk ⟨c†_k c_m⟩ - i Σ_k h_mk ⟨c†_n c_k⟩

⟨c†_k c_m⟩ = C_mk (定义: C_pq = ⟨c†_q c_p⟩, 所以 k 是产生位置→列指标, m 是湮灭位置→行指标)
⟨c†_n c_k⟩ = C_kn

dC_mn/dt = i Σ_k (h_nk C_mk - h_mk C_kn)
= i Σ_k (C_mk h_kn - h_mk C_kn)    [h对称 + 数字可交换]
= i(Ch - hC)_mn = i[C, h]_mn      ✅

**步骤3**: 实-虚分解。
C = C^R + iC^I, h 实数。
d(C^R + iC^I)/dt = i[C^R + iC^I, h]
= i[C^R, h] + i²[C^I, h]
= i[C^R, h] - [C^I, h]

C^R 对称实数, C^I 反对称实数, h 对称实数。
[C^R, h] 和 [C^I, h] 均为实数矩阵。

分离实部虚部:
dC^R/dt = -[C^I, h]      (实部) ✅
dC^I/dt = [C^R, h]       (虚部÷i, 即 +[C^R, h]) ✅

**文档方程①②验证通过。** ✅

#### 5a.2 对易子 [Â_mn, B̂_mn] — 完整验算

Â_mn = c†_n c_m + c†_m c_n
B̂_mn = i(c†_n c_m - c†_m c_n)

[Â, B̂] = [c†_n c_m + c†_m c_n, i(c†_n c_m - c†_m c_n)]
= i[c†_n c_m + c†_m c_n, c†_n c_m - c†_m c_n]

展开为四项:
= i{ [c†_n c_m, c†_n c_m] － [c†_n c_m, c†_m c_n] + [c†_m c_n, c†_n c_m] － [c†_m c_n, c†_m c_n] }

项1和项4: 算符与自身对易 → 0

项2: [c†_n c_m, c†_m c_n] (m≠n)
c†_n c_m c†_m c_n - c†_m c_n c†_n c_m

c†_n c_m c†_m c_n = c†_n (1 - c†_m c_m) c_n = c†_n c_n - c†_n c†_m c_m c_n
c†_m c_n c†_n c_m = c†_m (1 - c†_n c_n) c_m = c†_m c_m - c†_m c†_n c_n c_m

c†_n c†_m = -c†_m c†_n, c_m c_n = -c_n c_m (费米子)

c†_n c†_m c_m c_n = (-c†_m c†_n)(-c_n c_m) = c†_m c†_n c_n c_m

因此四阶项抵消:
[c†_n c_m, c†_m c_n] = n̂_n - n̂_m

项3: [c†_m c_n, c†_n c_m] = -[c†_n c_m, c†_m c_n] = -(n̂_n - n̂_m) = n̂_m - n̂_n
