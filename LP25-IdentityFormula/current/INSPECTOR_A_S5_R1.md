## 检查1: M = [[0,ω],[-ω,0]] → 特征方程 λ²+ω²=0 → λ=±iω

### 独立手动验算

```
M = [[0,  ω],
     [-ω, 0]]

det(M - λI) = det([[-λ,   ω ],
                   [-ω,  -λ ]])

            = (-λ)(-λ) - (ω)(-ω)
            = λ² - (-ω²)
            = λ² + ω² = 0
```

⟹ λ² = -ω² ⟹ λ = ±√(-ω²) = ±iω  (ω ≠ 0).

### 与文档核对

文档 §1.1.2 (L65-70) 写作:
```
det(M - λI) = det([-λ    ω ])
                      [-ω  -λ ]

            = (-λ)(-λ) - (ω)(-ω)

            = λ² + ω² = 0
```

文档在 `(-λ)(-λ) - (ω)(-ω)` 后直接跳到 `λ² + ω² = 0`。详细展开: `(ω)(-ω) = -ω²`，所以 `- (ω)(-ω) = -(-ω²) = +ω²`，得到 `λ² + ω²`。结果正确，推导链完整。

### 精度改进建议（非阻塞）

建议在 L67 后补上一步:
```
= λ² - (-ω²)
```
然后再:
```
= λ² + ω² = 0
```
理由: `-(ω)(-ω) = -(-ω²) = +ω²` 这一步对非专业读者可能不是显然的，显式写出可提高透明度。当前版本结果和逻辑均正确，此建议仅涉及表达精度。

### 判据

**PASS** — 特征方程计算正确，λ² + ω² = 0 → λ = ±iω。推导链完整。

## 检查2: ℝ 不可对角化逻辑链

### 独立手动验算

**路径A** (谱论证):
若 M 在 ℝ 上可对角化，则存在实可逆矩阵 P 使 P⁻¹MP = D，D 为实对角阵。
相似矩阵有相同本征值 → D 的对角元必为 M 的本征值 → D 的对角元 = ±iω ∉ ℝ。
与 D 是实对角阵矛盾。∴ M 在 ℝ 上不可对角化。

**路径B** (本征向量论证):
在 ℝ 上寻找本征向量 v = (v₁, v₂)^T ∈ ℝ²\{0} 满足 Mv = iωv:
```
[0    ω] [v₁]   = iω [v₁]
[-ω   0] [v₂]        [v₂]

→  ω v₂ = iω v₁   →  v₂ = i v₁
   -ω v₁ = iω v₂   →  v₁ = -i v₂
```
若 v₁, v₂ ∈ ℝ 且 ω ≠ 0: v₂ = i v₁ → v₁ = 0 → v₂ = 0。λ = -iω 时: v₂ = -i v₁ → 同理无解。
ℝ²\{0} 中无本征向量 → M 在 ℝ 上不可对角化。

两条路径等价，均正确。路径A更简洁，路径B更可视。

### 与文档核对

文档 §1.1.3 (L80-103) 使用路径B，过程完整。L106-116 物理解释"不可对角化 = 自由度不可分离"准确区分了"不可对角化"和"不可解"——演化矩阵 e^{Mt} 完全存在（旋转矩阵），不可对角化仅意味着无法在 ℝ 内找到使动力学解耦的坐标变换。这个区分必要且正确。

### 判据

**PASS** — 逻辑链完整且正确。ℝ 不可对角化论证无任何漏洞。物理区分准确。

## 检查3: Z = A + iB → dZ/dt = -iωZ

### 独立手动验算

给定: dA/dt = ωB, dB/dt = -ωA.

```
Z ≡ A + iB

dZ/dt = dA/dt + i·(dB/dt)
      = ωB + i·(-ωA)
      = ωB - iωA                    (甲)

目标: dZ/dt = -iωZ.

计算右侧:
-iωZ = -iω(A + iB)
     = -iωA - i²ωB
     = -iωA - (-1)ωB
     = -iωA + ωB
     = ωB - iωA                    (乙)

(甲) = (乙)  ✓
```

扩展: Z(t) = Z(0) e^{-iωt}，对应复平面上的匀速旋转。

### 与文档核对

文档 §1.2.1 (L140-145):
```
dZ/dt = ωB + i(-ωA)
      = ωB - iωA
      = -iω(A + iB)
      = -iω Z
```

第三步 `ωB - iωA = -iω(A + iB)` 正确，因为展开右侧: `-iω(A + iB) = -iωA - i²ωB = -iωA + ωB = ωB - iωA`。✓

### 判据

**PASS** — 复化代数的每一步均正确。无误差。

## 检查4: 四元数 ℍ 的 2D 子代数——存在性、同构ℂ、非唯一性(S²)

### 问题拆解

需要验证三个子声称:
1. ℍ 中是否存在 2D 子代数？
2. 是否同构于 ℂ？
3. 是否唯一？

### 独立搜索验证

**搜索**: "quaternion algebra two-dimensional subalgebras isomorphic complex numbers non-unique"

**关键来源**: Kuzmina & Chodorová (2016), "The Group of Invertible Elements of the Algebra of Quaternions", *Acta Universitatis Palackianae Olomucensis*:
> "All two-dimensional subspaces of the algebra of quaternions, containing a unit, are 2-dimensional subalgebras isomorphic to the algebra ℂ of complex numbers."

原始结果归属 Belova。

**机制**:
- ℍ = {a + bi + cj + dk : a,b,c,d ∈ ℝ, i²=j²=k²=ijk=-1}
- 任意纯虚单位四元数 u（满足 u² = -1, Re(u) = 0, |u| = 1）生成子代数 span_ℝ{1, u} ≅ ℂ（映射: 1→1, u→i_ℂ）
- 满足 u² = -1, Re(u) = 0 的 u 全体 = S² = {(b,c,d) : b²+c²+d²=1} ⊂ ℝ³
- → 存在连续无穷多（2参数族）互不等价的 ℂ 副本，通过 SO(3) 旋转相互联系（Hopf纤维化 S³→S²）

**三个子声称的验证结果**:
1. 存在? **是** — S² 上每点对应一个。
2. 同构 ℂ? **是** — span{1,u} 的代数结构与 ℂ 完全一致 (u² = -1)。
3. 唯一? **否** — S² 是连续2参数连续统。

### 与文档核对

文档 §1.3 (L189-247) 对此进行了**诚实修正**。原始任务中的表述"ℍ不存在2维子代数"被修正为 (L219-221):

> "ℍ 有2维子代数（同构于 ℂ），但这些子代数不是唯一的——任意纯虚单位四元数 u（满足 u² = -1）生成一个 ℂ 副本 {a + bu}。ℍ 中不同的 ℂ 副本之间由 SO(3) 旋转联系。"

**冗余论证的完整链条**:
1. 系统 (A,B) 有严格 2 个实自由度 → 不可被 ℝ 容纳（1维）
2. ℂ 提供恰好 2 维 → 充分且最小
3. ℍ 的任意 2 维子代数 ≅ ℂ → 若嵌入 ℍ，必落入某个 ℂ 副本
4. 不同 ℂ 副本对应不同嵌入（选取不同的 u ∈ S²）→ 引入未受动力学约束的规范自由度
5. ℍ 的额外 2 维是纯冗余

文档 §1.3.4 (L224-228) 的表格:
| 代数 | 实维度 | 冗余自由度 | 唯一性 |
|------|--------|-----------|--------|
| ℝ    | 1      | —         | —      |
| ℂ    | 2      | 0         | ✅     |
| ℍ    | 4      | 2         | ❌ S² 规范族 |

完全正确。

### 判据

**PASS** — 子代数声称经验证全部正确。诚实修正准确且适当。冗余自由度计数正确。不唯一性 (S²) 搜索确认无误。

**关键确认**: de Oliveira 论文的 arXiv 摘要和元数据中**没有**讨论:

## 检查6: 非线性推广三类分法的自洽性

### 独立分析

文档 §1.5 (L329-398) 将非线性推广 F(B) 分为三种情形:

```
          ┌─ 情形1: F解析 ──────────→ 线性主导项强制 ℂ
          │
F(B)  ────┼─ 情形2: F非解析不可线性化 → ℝ² ≅ ℂ 恒成立，对角化不强制
          │
          └─ 情形3: F导致混沌 ──────→ ℝ² 描述已足，ℂ 仅分析工具
```

### 情形1: F 解析

**文档声称**: Taylor 展开 F(x) = Σ f_n x^n，在平衡点附近 F(x) ≈ F'(0)·x。令 ω ≡ F'(0) ≠ 0，则线性主导项 dA/dt ≈ ωB, dB/dt ≈ -ωA → 同定理2 → ℂ 主导阶强制。

**自洽性检查**:
- 解析性保证 Taylor 收敛 ✓
- 平衡点 (A=B=0) 附近的线性化是标准微扰论 ✓
- 非线性项修正可表示为复数 Fourier 级数 ✓
- 多尺度展开: Z = R(T) e^{-iωt} + ε Z₁ + ... → 主导阶复结构保留 ✓

### 情形2: F 非解析

**文档声称**: F(x) = |x| 或 sgn(x) 时，线性化 F'(0) 可能不存在或为 0。定理2线性论证不适用。但 ℝ² ≅ ℂ 作为 ℝ-向量空间恒成立。关键区分: 代数必要性 vs 对角化必要性。

**自洽性检查**:
- "ℝ² ≅ ℂ 作为实向量空间"是纯代数事实 (dim_ℝ ℝ² = dim_ℝ ℂ = 2) ✓
- 文档在 L367-372 标注了关键区分: "代数的必要性总是成立，对角化的必要性仅在 F 可线性化时成立" ✓
- 没有声称非解析情形 ℂ 被强制——诚实边界清晰 ✓

### 情形3: F 导致混沌

**文档声称**: F(x) = sin x → 摆方程，相空间仍 ℝ²，复分析可用于奇点分析和复时间延拓，但不能对角化动力学。

**自洽性检查**:
- 摆方程等混沌系统确实可在复时间域分析 ✓（标准方法——参考 Guckenheimer-Holmes 框架）
- 文档在此情形下标注 ℂ 仅为"便利性"而非"必要性" ✓

### 完整性检查

**诚实边界表** (L385-390):

| 情形 | ℂ对角化 | ℂ必要性 | 对S5北极星 |
|------|---------|---------|-----------|
| 线性 | 精确 ✓ | 数学必然 ✓ | 核心声称 ✓ |
| 解析 | 主导阶 ✓ | 主导阶必然 ✓ | 微扰论下保持 ✓ |
| 非解析 | ❌ | ℝ² 描述已足 ✓ | 声称边界 ✓ |
| 混沌 | ❌ | 复分析仅工具 ✓ | 超出声称域 ✓ |

每行自洽。文档 L381-382 明确声明北极星声称限域于线性幺正动力学。

**唯一开放问题**: L396-397 标注 F'(0)=0 的退化情形（如 F(x)=x³）计入"未完成"。文档将此标注为开放问题 (A.4, L687)，诚实。

### 判据

**PASS** — 三类分法自洽。诚实边界清晰且适当。F'(0)=0 退化情形已标注。无过度声称。
