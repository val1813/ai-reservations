## 核心定理链

### 定理1（S3/S4遗产）：正则共轭动力学方程
```
dC^R/dt = -[H, C^I]    精确，实数H
dC^I/dt = +[H, C^R]    精确，实数H
```
**地位**：Heisenberg方程的严格重排。数学形式已知（Bloch形式），物理诠释是新的。

### 定理2（NEW — S5核心）：正则共轭→复数必然性

**声称**：设线性动力学满足 dA/dt = ωB, dB/dt = -ωA（ω∈ℝ, ω≠0），则：
1. 实数演化矩阵 M = [[0,ω],[-ω,0]] 的本征值为 ±iω（纯虚数）
2. M在ℝ内不可对角化（需要i）
3. ℂ是包含此动力学的唯一最小充分代数（四元数ℍ冗余——4D描述2D系统）

**证明概要**：
- 特征方程 det(M-λI) = λ² + ω² = 0 → λ = ±iω
- 若限定在ℝ：无实本征值 → 不可对角化 → 动力学不能解耦
- 复化到ℂ：Z = A + iB → dZ/dt = -iωZ（单一复数方程，对角化）
- ℍ冗余：A+Bi+Cj+Dk有4个实自由度，但(A,B)只有2个

**含义**：**复数不是量子力学的"方便数学工具"——不引入ℂ，正则共轭动力学在数学上不完整（无法对角化、无法解耦）。ℂ是从ℝ的代数不完备性中逃逸出来的必然结构。**

### 定理3（S4遗产 + 新框架）：Born规则 = 相空间投影

正则共轭动力学强制了复数描述 Z = C^R + iC^I。但测量只返回实数。Born规则的|·|²操作 = 从复平面(Z)到非负实轴(|Z|²)的投影：
```
(C^R, C^I) → |C|² = (C^R)² + (C^I)²
```
丢失的信息 = 相位角 θ = arctan(C^I/C^R) = Gap。

**Gap不是量子力学的bug——它是从ℂ（动力学必然）投影到ℝ（测量输出）时的不可避免的信息代价。**

### 定理4（S1遗产 + S5精确定义）：Ĵ量化Gap

Ĵ = dS_vN/dτ + ∇_μ J^μ_G = 0 追踪被投影丢弃的Im(C₁₂)的去向。当Ĵ=0（信息守恒），Gap被"追踪"——它没有消失，只是转移到了环境中。当Ĵ≠0（因果断连处，如黑洞视界），Gap真实存在——被丢弃的相位信息没有接收者。
