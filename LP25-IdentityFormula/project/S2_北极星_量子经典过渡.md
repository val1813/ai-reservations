## 推导路线（7步，逐步严格）

### 第1步：路径积分 = 复平面上的向量求和

```
⟨x_f|e^(-iHt/ħ)|x_i⟩ = ∫ D[x] exp(iS[x]/ħ)

对每条路径x(t)，被积函数 exp(iS/ħ) = cos(S/ħ) + i sin(S/ħ)
这是复平面单位圆上的一个点，角度 = S/ħ
```

**关键观察**：路径积分 = 无穷多个单位向量的和，每个向量的角度 = 该路径的作用量/ħ。

### 第2步：ħ→0时为什么只有经典路径存活

当ħ很小时，S/ħ非常大。两条相邻路径x和x+δx的相位差：
```
Δ(S/ħ) = (S[x+δx] - S[x])/ħ ≈ δS/ħ
```

当δS ≠ 0时，δS/ħ → ∞（ħ→0）。这意味着：
- 相邻路径的cos(S/ħ)值在[-1,1]之间剧烈振荡
- 相邻路径的sin(S/ħ)值在[-1,1]之间剧烈振荡
- 这些振荡在路径积分中互相抵消

**唯一例外**：δS = 0的路径（经典路径及其邻近）。在这里：
- δS/ħ = 0（对所有ħ，因为δS本身为零）
- 邻近路径的cos(S/ħ)和sin(S/ħ)值几乎相同
- 它们同向叠加，不被抵消

**这就是为什么经典路径在ħ→0时"存活"——它是复平面上唯一一个邻近向量对齐的点。**

### 第3步：经典方程 = 对齐条件

δS = 0 ⇔ 欧拉-拉格朗日方程：
```
d/dt (∂L/∂ẋ) - ∂L/∂x = 0
```

这是经典力学的基本方程。从欧拉恒等式视角：**经典方程 = 复平面单位向量在路径空间中"对齐"的条件。**

### 第4步：量子修正 = 二阶变分

在经典路径附近展开S[x]：
```
S[x_cl + δx] = S[x_cl] + ½ δ²S + O(δx³)
```

其中δ²S = ∫ dt δx(t) [−∂²_t − V''(x_cl(t))] δx(t)。

路径积分（高斯近似）：
```
∫ D[δx] exp(i δ²S/2ħ) = [det(−∂²_t − V''(x_cl))/2πiħ]^{−1/2}
```

**欧拉视角**：量子修正 = cos(δ²S/2ħ)和sin(δ²S/2ħ)在非零δ²S处的贡献。领头ħ修正来自这些cos/sin的非零二阶变分积分。

### 第5步：WKB = 欧拉分解的1D版本

WKB近似：ψ(x) ≈ [p(x)]^{−1/2} exp(±i∫ p dx/ħ)

欧拉分解：
```
ψ(x) = [p(x)]^{−1/2} [cos(∫ p dx/ħ) ± i sin(∫ p dx/ħ)]
```

WKB连接公式（转折点处Airy函数行为）→ cos和sin之间的π/2相位跳变 = 欧拉恒等式在Stokes线上的行为。

### 第6步：consistent histories / 退相干的欧拉视角

退相干选择指针态（pointer states）的过程 = 环境将不同指针态的i sin θ（虚部、相干）扩散到无数自由度中。剩下的cos θ（实部、概率）构成经典概率分布。

**经典世界 = 只有cos θ存活的世界 = 虚部被环境完全吸收后的残余。**

```
量子→经典过渡的恒等式：

lim_{ħ→0} ∫D[x] e^(iS/ħ) f(x) = f(x_cl) e^(iS_cl/ħ) ∫D[δx] e^(i δ²S/2ħ)
```
