### 1.3 §2.7-2.9: dim(Y)=1 ⇒ Cartan条件 -- **WARNING** (漏解支)

**问题定位: §2.9, 方程组C1+C2 ⇒ c_y=c_z=0 (mod π)**

详细追踪:

S={0,1}情形，Cartan条件a₂=a₃=0给出:

$$\begin{aligned}
-e^{i\lambda_0} + e^{i\lambda_1} + e^{i\lambda_2} - e^{i\lambda_3} &= 0 \quad\text{(C1)}\\
e^{i\lambda_0} + e^{i\lambda_1} - e^{i\lambda_2} - e^{i\lambda_3} &= 0 \quad\text{(C2)}
\end{aligned}$$

(C1)+(C2): 2e^{iλ₁} - 2e^{iλ₃} = 0 ⇒ λ₁ ≡ λ₃ (mod 2π)
(C2)-(C1): 2e^{iλ₀} - 2e^{iλ₂} = 0 ⇒ λ₀ ≡ λ₂ (mod 2π)

代入λ表达式:
- λ₁-λ₃ = 2(c_y+c_z) ⇒ **c_y + c_z = nπ**  (n∈ℤ)
- λ₀-λ₂ = 2(c_z-c_y) ⇒ **c_z - c_y = mπ**  (m∈ℤ)

通解: c_y = (n-m)π/2, c_z = (n+m)π/2

在c_y, c_z ∈ [0,π]的Cartan参数域内，解包含:
1. **(n=0,m=0): c_y=c_z=0** ← A博士给出 ✓
2. **(n=1,m=0): c_y=c_z=π/2** ← **A博士遗漏!**
3. (n=1,m=1): c_y=0, c_z=π (等价于c_z=0 mod Weyl群)
4. (n=0,m=1): c_y=π/2, c_z=-π/2 (需映射到基本域)

**验证c_y=c_z=π/2确实满足a₂=a₃=0:**

λ₀=c_x, λ₁=-c_x+π, λ₂=c_x, λ₃=-c_x-π
a₂ = -e^{ic_x} + (-e^{-ic_x}) + e^{ic_x} - (-e^{-ic_x}) = 0 ✓
a₃ = e^{ic_x} + (-e^{-ic_x}) - e^{ic_x} - (-e^{-ic_x}) = 0 ✓

此时a₀ = 4i·sin(c_x), a₁ = 4cos(c_x)，对泛型c_x两者非零 ⇒ S={0,1}成立。

**严重性评估:** 漏支不影响测度零结论——多出的解仍在codimension≥1子簇内。但说明A博士的代数消元步骤不够完整(将``c_y = c_z (mod π)''和``c_y+c_z = 0 (mod π)''联立时跳过了c_y=c_z=π/2的情况)。

**判定: WARNING** -- 漏解支，需补充完整枚举，但不影响主线结论。

## 维度4: 新CFOL陈述检查 -- **BLOCK**

### 4.1 核心问题: §5.1(I) ``QCMI = 0 ⟺ dim(Y) ≤ 1''

**判定: UNSOUND。** ``⇔''符号在此处包含两个方向，其中反向(⇐)不正确。

#### 分析

**背景:** CFOL设定中，四节点环上的四个酉u₁,u₂,u₃,u₄均为**给定**。Y由u₁的算子Schmidt分量R_k和环境态|γ̃⟩定义。QCMI是全局量，依赖于全部四个u_i和环境态。

**(⇒)方向:** ``QCMI = 0 ⇒ dim(Y) ≤ 1''

这是CFOL反例揭示的必要条件。当QCMI=0时，通过Case I/II二分，若dim(Y)=d则必须所有u_i完全因子化，此时dim(Y)事实上由可因子化u₁确定(R_k为秩1算符)⇒dim(Y)可≤1。若dim(Y)≤d-1，则进入Case II。

**此方向严格正确。** ✓

**(⇐)方向:** ``dim(Y) ≤ 1 ⇒ QCMI = 0''

此方向声称: 只要dim(Y)≤1(仅由u₁决定的条件)，QCMI必为零，**无论u₂,u₃,u₄取何值**。

**反例思路:** 取u₁使得dim(Y)=1(例如满足c_y=c_z=0, D|γ̃⟩∝(1,±1)^T)，但取u₂为任意不兼容的酉(例如Haar随机酉)。此时u₂与u₁的块对角结构不匹配，QCMI一般>0。

**事实上，dim(Y)≤1仅为QCMI=0的必要条件，非充分条件。** QCMI=0还要求:
1. u₂的S_ℓ分量与u₁的R_k分量在算子层面兼容(块对角结构匹配)
2. u₃,u₄与u₁,u₂对称兼容
3. 具体系数满足C†D=0等正交条件(INSPECTOR v4确认)

#### 严重性

此``⇔''直接出现在新CFOL定理陈述的第一条，是**定理的核心声明**。如果以当前形式提交论文，审稿人会立刻发现反向不成立。

**判断: BLOCK。**

## 补充发现

### S1. B博士量子达尔文主义联系的数学精度

B博士将dim(Y)=d诠释为``环境充分探测系统所有自由度''，dim(Y)<d为``环境盲区''。这一联系在物理直觉层面有吸引力，但数学上:

- dim(Y) = dim(span{R_k|γ̃⟩})测量的是**算子分量在单一环境态上的作用范围**，而非环境对系统所有可能态的区分能力
- 量子达尔文主义的冗余度R_δ = E^#/F_δ^#是基于**多环境片段**的信息增殖，与我们的dim(Y)(单一环境节点+单一初态)在操作定义上不同
- 联系是**启发性类比**而非**已证等价关系**

**建议:** 论文中若提及此联系，应明确标注为``启发式对应''(heuristic correspondence)或``值得进一步研究的类比''，不应作为定理级声明。

### S2. A博士附录A.1的行列式数值系数不一致

A.1中Δ₀₁ = φ₀²-φ₁²，但§2.8表中Δ₀₁ = 1/2(φ₀²-φ₁²)($2.6没有出现Δ₀₁的显式计算，仅计算了Δ₀₂和Δ₀₃)。A.1中Δ₁₂ = 2iφ₀φ₁，而§2.8表中对应条件为φ₀²=φ₁²。

造成差异的原因是A.1用的是原始det计算(未归一化)，§2.8用的是条件简化形式。虽然零条件等价(非零因子不影响det=0的判断)，但**两处系数的差异会在后续交叉引用时造成混乱**。

**建议:** 统一归一化约定，或至少在A.1末尾显式说明:``各判别式等价于以下零条件(省略非零因子)...''

### S3. §2.4局域酉HS正交归一性的论证瑕疵

A博士写道:
> ``A P_μ C和A P_ν C的HS内积为Tr(C†P_μ†A†A P_ν C) = Tr(P_μ† P_ν) = δ_{μν}''

这个推导**假设了A†A=I和CC†=I**。A是酉算子(U(2)元素)，A†A=I成立。但循环置换Tr(P_μ† A†A P_ν C C†)需要CC†=I，即C酉。C是U(2)元素，CC†=I成立。

更仔细看: Tr(C† P_μ† A† A P_ν C)。利用迹的循环性质:
Tr(C† P_μ† A† A P_ν C) = Tr(P_μ† A† A P_ν C C†)  ← 这里需要CC†=I!
= Tr(P_μ† A† A P_ν)
= Tr(P_μ† P_ν)  ← 因为A†A=I
= δ_{μν}

但步骤中隐含使用了Tr(XY)=Tr(YX)，Tr(C† X C) = Tr(X C C†)。如果C是酉的，CC†=I，没问题。

**实际上推导正确。** 但A博士自己的表述``Tr(C†P_μ†A†A P_ν C) = Tr(P_μ† P_ν)''中间跳过了Tr(C†X C)=Tr(X)这步，容易让读者怀疑是否遗漏了CCC†。

**建议:** 补一句``由于C是酉算子，Tr(C†XC)=Tr(X)。''
