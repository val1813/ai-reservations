## 一、实验架构

### 1.1 量子电路 (8 qubits, 6 measured)

```
Qubit布局: [Qa=0, E1=1, Qb=2, E2=3, Ra=4, Rb=5, anc_E1=6, anc_E2=7]

制备阶段:
  Ra-Qa: Bell pair |Φ+> via H + CNOT
  Rb-Qb: Bell pair |Φ+> via H + CNOT
  E1: 混合态 diag(p,1-p) via ancilla纯化 (p=0.7)
  E2: 混合态 diag(p,1-p) via ancilla纯化

因果环演化:
  u1: RZZ(θ) on Qa-E1
  u2: RZZ(θ) on E1-Qb
  u3: RZZ(θ) on Qb-E2
  u4: RZZ(θ) on E2-Qa

测量: 6-qubit联合测量 [Qa, E1, Qb, E2, Ra, Rb]
```

### 1.2 RZZ(θ)门实现

Heron r2未在SamplerV2原语中暴露分数RZZ门。因此RZZ(θ)通过CZ分解实现:
```
RZZ(θ) = CX(a,b); Rz(θ,b); CX(a,b)
       = H-CZ-H on b; Rz(θ) on b; H-CZ-H on b
```
每次RZZ需要2个CZ + 4个H + 1个Rz = **每边7个单/双qubit门**。

### 1.3 传输编译惩罚

ibm_kingston采用重六角晶格（围长=6，无4-循环）。4节点环需要SWAP路由:
- 逻辑CZ计数（每个RZZ边2个CZ）× 4条边 = 8个CZ
- 路由SWAP = 额外3-6个CZ
- **总计: ~11-14个物理CZ，深度~15-25**

这是关键问题——见下文§5。

## 五、关键问题诊断

### 5.1 Bell对被破坏 — 致命问题 🔴

**所有测量中I(Ra:Qa) = 0。** 理想值应为2.0 bits。

**根因分析:**

1. **重六角SWAP开销**: 4节点环在围长=6的晶格上需要至少2次SWAP路由
2. **SWAP = 3×CZ**: 每次SWAP在Heron上分解为3个CZ门
3. **总CZ计数**: 8 (环门) + 6 (SWAP) + 2 (制备) = **~16个CZ**
4. **累计退极化**: 16 × 0.003 = ~5% → Bell对完全退极化

**证据:** P(00)≈0.35, P(11)≈0.15, P(01)≈0.34, P(10)≈0.16 — 接近均匀分布。

### 5.2 QCMI趋势反转 — 测量的是噪声而非信号 🔴

- 理论: QCMI ∝ θ²log(1/θ)，随θ减小而减小
- 实验: QCMI随θ减小而增大 (V3) 或基本恒定 (V4)
- **这表明检测到的QCMI是噪声伪影，而非因果环信号**

### 5.3 基依赖性 (V4) — 系统误差 🟡

π/4时Z基和X基QCMI差异为0.474 bits — 远超统计噪声(σ~0.015)。这表明X基测量引入了额外的系统误差（可能是H门的不完美校准或X基读出误差更高）。

## 七、桥梁到设备分析 (bridge_to_device/)

### 7.1 A_ibm_mapping.md — 理论到硬件映射

完整的transmon Hamiltonian → Cartan分解映射:
- CZ = (0, 0, π/4) — 纯ZZ Cartan轴
- RZZ(θ) = (0, 0, θ/2) — IBM Heron分数门（原生）
- CNOT = (π/4, 0, 0) — 纯XX（通过局域旋转）
- 关键约束: Heron r2 SamplerV2不支持分数RZZ(θ)门 → 必须通过CZ+Rz分解

### 阻止硬件验证的阻塞因素

1. **重六角拓扑** — 无原生4-循环，需要SWAP路由（+6-12 CZ门）
2. **SWAP破坏Bell对** — 累计~16 CZ × 0.3% → 完全退极化
3. **无分数RZZ(θ)** — SamplerV2不支持，必须通过CZ+Rz分解（每个RZZ额外+2 CZ）
4. **噪声地板** — σ_abs ≈ 0.06 bits，淹没小θ信号
