# PI修正 — b₁扫描实验正确解读

**日期:** 2026-06-09
**修正:** 之前将b₁扫描结果解读为"Wall 2被证伪"是错误的

---

## 正确解读

### 1. 树(b₁=0)的QCMI=3.078 ≠ 环拓扑无关

树上有4-5条边，每条边上的Haar随机酉在两体Q-E间产生纠缠。
这个QCMI来自**前向信息流**（Q→E→Q的前向路径），不是**环回流**。
树≠无环境影响，树=无因果回路。

**类比：** 树上的QCMI是"河流向下游的信息携带"，环上的增量是"涡流捕获的额外信息"。

### 2. 增量Δ=0.107才是环拓扑的贡献

```
tree QCMI = 3.078  ← 前向流基线
cycle QCMI = 3.185 ← 基线 + 环拓扑贡献
增量 = 0.107 bits  ← 真正的拓扑信号
```

η₀=0.180 bits在这个增量量级上是合理的下界——比增量保守但不荒谬。

### 3. 精化后的Wall 2

**原声张（太强）：** QCMI ≥ η₀ · b₁(G)
**精化声张：** QCMI ≥ QCMI_tree + η₀ · b₁^{ind}(G)

其中b₁^{ind}(G) = 顶点不相交环的最大个数。

实验证据：
| 配置 | b₁^{ind} | QCMI | 增量/基线 |
|------|:---:|------|----------|
| tree | 0 | 3.078 | 基线 |
| 单环 | 1 | 3.185 | +0.107 per ind. cycle |
| 双顶点不相交3-环 | 2 | 3.611 | ~2×增量（可加性确认） |
| 双共享节点4-环 | 1(共享) | 3.933 | 饱和（无额外独立环） |

### 4. 共享节点饱和是新发现

b₁=3和b₁=4的QCMI相同(3.933)不是bug——它是**拓扑依赖环的边际贡献为零**的物理证据。这比"b₁控制QCMI"更精确：

> "拓扑独立的因果环可加地贡献量子记忆，共享节点导致饱和。"

这是一个新结果，不是反例。
