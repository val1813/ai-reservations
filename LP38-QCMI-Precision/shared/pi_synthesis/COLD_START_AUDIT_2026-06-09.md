## 一、Wall 1: 下界不紧 — 精确诊断

### 1.1 缺口定义

当前下界: η₀ = 1/(8 ln 2) ≈ 0.180 bits
实验QCMI范围: [0.7355, 3.2387] bits (7门×N=20)
差距: 4-18×

### 1.2 下界推导链（五层）

```
Layer 0: I(R;E'|Q') ≥ -2 log₂ F²                      [Fawzi-Renner 2015, 严格]
Layer 1: -log₂ F² ≥ (1-F²)/ln 2                        [初等不等式, 严格]
Layer 2: 1-F² ≥ Δ_K/2                                   [主导阶; 非微扰待证]
Layer 3: Δ_K ≥ (γ_min/d²) · Σ|c|²                       [d=2显式; d>2待推广]
Layer 4: η₀ = γ_min/(d² ln 2)                           [代数合并, 严格]
```

保守性来源分析:
- Layer 0→1: -2 log₂ F² ≥ 2(1-F²)/ln 2，在F≈1时紧，在F≪1时极松。实验F~0.3→gap~3×
- Layer 1→2: 1-F² ≥ Δ_K/2，在非微扰域松~2×
- Layer 2→3: Δ_K ≥ (γ_min/d²)·Σ|c|²，Cartan→Kraus映射有O(1)不确定性
- 总累积: 3×2×2~12×，与观察的4-18×一致

### 1.3 可能的攻击方向

**方向W1-A: 绕过Fawzi-Renner**
直接计算QCMI利用因果环的特殊结构。Chain: QCMI = 2log₂d - I(R;Q')，后者的谱可通过Cartan参数显式计算。

**方向W1-B: 寻找饱和配置**
找到使η₀紧的极限。小Cartan极限(|c|→0)下F→1，Fawzi-Renner紧。证明: lim_{c→0} QCMI/η₀ = 1。

**方向W1-C: 紧化中间层**
Layer 2-3的常数严格化。Δ_K与F的关系不是线性的——可以在特定环结构下给出更紧的界。

**方向W1-D: 接受不紧，证明下界不可改进**
证明: 存在因果环配置序列使得QCMI任意接近η₀（η₀确实是最优下界）。

### 1.4 已有资产（不依赖新墙）

- CFOL (v4): QCMI=0 ⇔ 所有u_i可因子化
- 精确恒等式: QCMI = 2log₂d - I(R;Q')
- Cartan规范固定: 每条边退化为Cartan核心
- CNOT环解析解: QCMI = h₂((1+4p(1-p))/2)，可作为基准
- 500 Haar酉数据: |c|²分布已知

## 二、Wall 2: b₁>1 推广 — 精确诊断

### 2.1 缺口定义

**已证部分:**
- 边不相交环: QCMI严格可加 (张量积可加性)
- 小Cartan极限: 树边冻结引理成立 (隐函数定理)
- 单环b₁=1: CFOL+η₀严格

**未证部分:**
- 树边冻结引理的全局推广 (非微扰Cartan系数)
- 共享节点环的干涉界 (数值~1.7×而非2×)
- 非对角Hessian耦合在大b₁时的累积效应
- b₁>1的严格QCMI下界 (标度假说)

### 2.2 树边冻结引理的精确漏洞

**构造性vs必然性:** 引理声称存在一种规范使树边=I且QCMI不变。这是构造性的（声称存在性），不是必然性的（不声称所有配置必须如此）。

**漏洞位置:**
1. 补偿方程在d_{c_i}=0时Jacobian退化→隐函数定理不适用
2. 缩放论证(blow-up)只证明小参数下存在解，非全局
3. 自攻击#3: 某些配置中树边可能携带不可消除的贡献
4. 非对角Hessian耦合在大b₁时可能累积到不可忽略

**修复路径:**
- 路径A: 完成全局证明(用Cartan结构的特殊性消除退化)
- 路径B: 放弃全局冻结，改为上界树边贡献≤f(b₁,c)
- 路径C: 绕过树边冻结，直接用sQNM超可加性证明I≥η·b₁

### 2.3 共享节点干涉

**已知:** 双共享环QCMI~1.85 (vs 边不相交的2.0)
**未知:** 这个压低是否随b₁增大而累积？是否可能使QCMI/b₁→0？

**关键问题:** QCMI(b₁)的渐近形式——∝b₁? ∝√b₁? 趋于常数?

### 2.4 可能的攻击方向

**方向W2-A: 完成树边冻结全局证明**
利用Hasse图的特殊结构(三角形自由、二部性)消除Jacobian退化。

**方向W2-B: sQNM超可加性路径**
Gangwar et al. (2025)证明了sQNM的超可加性。直接应用此结果到多环图。

**方向W2-C: 共享节点干涉的下界**
证明共享节点干涉是建设性的(≥0)，不会破坏下界。即使不是2×而是1.7×，只要下界η·b₁成立即可。

**方向W2-D: 数值验证b₁=2,3**
用小图(6-8 qubits)的经典对角化确定QCMI(b₁)的行为。虽不能证明，但可指导解析方向。
