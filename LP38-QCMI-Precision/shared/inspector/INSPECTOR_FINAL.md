### 1.3 Case II 消去论证的技术瑕疵 [WARNING-CASE-II]

**位置:** `round1_factorization.md` Lines 445-447

**声称:**
```
Tr(C†C) + Tr(D†D) = Σ_ℓ (|c_ℓ|²+|d_ℓ|²) · Tr(T_ℓ†T_ℓ) = r₂·d
Tr(C†C) = d, Tr(D†D) = d ⇒ 2d = r₂·d ⇒ r₂ = 2
```

**漏洞:** 等式缺失了 Schmidt 权重 t_ℓ²。

正确形式:
```
Tr(C†C) = Tr(Σ_{ℓ,m} t_ℓ t_m c̄_ℓ c_m T_ℓ†T_m) = Σ_ℓ t_ℓ² |c_ℓ|² · Tr(T_ℓ†T_ℓ)
```

其中 Tr(T_ℓ†T_ℓ) = 1 (算子 Schmidt 正交归一化)。而 C†C = I 意味着 Σ_ℓ t_ℓ² |c_ℓ|² = d = 2 (取迹)。

同理 Σ_ℓ t_ℓ² |d_ℓ|² = 2。

但偏迹条件给出 Σ_ℓ t_ℓ² = d² = 4 (取 Σ_ℓ t_ℓ² S_ℓ†S_ℓ = d·I 的迹)。

验证: Σ_ℓ t_ℓ²(|c_ℓ|²+|d_ℓ|²) = Σ_ℓ t_ℓ² = 4, 同时 = Σ_ℓ t_ℓ²|c_ℓ|² + Σ_ℓ t_ℓ²|d_ℓ|² = 2+2 = 4. **自洽, 不产生矛盾。**

**严重性评估:** 声称的矛盾不成立 (因缺失 t_ℓ² 权重), 但 Case II 本身可能仍可通过其他方式排除:
1. 使用 u₁ 的酉性条件 (Σ s_k² R_k†R_k = d·I) 与 dim(Y)=1 的矛盾
2. 联合 dim(X)=dim(Y)=1 与完整 u₁†u₁=I 和 u₂†u₂=I 的交叉块联合分析
3. 数值验证已确认规范域内无 Case II 型反例

**判定:** 此瑕疵不影响 Case I (主路径) 的严格性。Case I 已覆盖 **dim(Y)=d 的所有情况**。Case II 的消去论证需要修正后才能声称完整的二分类穷举证明。当前状态: Case I 路径严格完整 (M>0 自然成立, 不依赖任何跳跃推理), Case II 消去论证的权重计算需修正。

**修复方案:** 
- 最短路径: 从 dim(Y)=1 出发, 联合 Σ s_k² R_k†R_k = d·I (u₁ 酉性) 与 Y 的定义直接推出矛盾 (两约束不能同时满足, 因前者要求 {R_k†e_i} 张成全空间, 后者限制 {R_k|γ̃⟩} 共线)
- 完整路径: 将 t_ℓ² 权重正确纳入计数, 证明 Σ t_ℓ²|c_ℓ|² = d 和 Σ|c_ℓ|² = r₂ 之间的不等式给出 r₂ ≥ d²/d = d = 2, 但对角化条件 C†C=I 和 D†D=I 与 t_ℓ²>0 产生的额外约束排除此可能性

## FOCUS-5: 三种干涉机制

**判定: PASS**

### 5.1 置换/相位/纠缠三分类

B博士 interference_physics.md 识别的三种机制:
1. **置换 (Permutation):** 环上不同边序导致的 Kraus 算子重组
2. **相位 (Phase):** 循环绕行的相位累积 (BCH 对角部分)
3. **纠缠 (Entanglement):** 非对易 Cartan 轴的 BCH 交叉项产生新非局域分量

### 5.2 与 Cartan 轴对齐/失配的对应

| 机制 | Cartan 条件 | 对 QCMI 的影响 |
|------|-----------|---------------|
| 置换 | 轴对齐, 对角 Cartan | 环可能降低 QCMI (量子 Zeno) |
| 相位 | 轴对齐, 对角 Cartan | 同置换, 可叠加 |
| 纠缠 | 轴失配, [H^(i),H^(j)]≠0 | 环增加 QCMI (正 bonus) |

分类与 Cartan 框架自洽。✓

### 5.3 SWAP/iSWAP 负 bonus

SWAP (c=(π/4,π/4,π/4)) 和 iSWAP (c=(π/4,π/4,0)) 在轴对齐环中: 所有 Cartan 核心对易 ⇒ 循环绕行 ≡ 单次绕行 × 绕行次数 ⇒ 重复投影/测量 ⇒ 量子 Zeno 效应 ⇒ QCMI 降低。Cartan 框架中为"环作为退相干加速器"(AHA #2)。
