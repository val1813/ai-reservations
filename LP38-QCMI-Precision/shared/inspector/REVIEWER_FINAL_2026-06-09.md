# PRL 审稿报告 -- 恶意审稿人 LP38 终审裁决

**稿件:** "Causal Rings and Quantum Non-Markovianity: Asymptotically Optimal Coefficient, Scaling Refinement, and the Scale-Free Origin of alpha~1.81"
**审稿人:** REVIEWER (恶意立场，PRL标准)
**审查对象:** LP38 四子命题全部成果（S1-S4），含 PI 综合、CCQ 实验、b1 扫描、alpha 解析推导
**日期:** 2026-06-09
**裁决:** **REVISE (MAJOR) -- 当前形式不可投稿**

## 0. 总评

LP38 相比 LP36 有实质性进步。CCQ 的 O(|c|^4) 声称被数值证伪，alpha~1.81 的对数修正起源被揭示，eta_0 被重新定位为"渐近最优"而非"太松"。这些都是正向的科学进展。

**但进步不等于达标。** LP38 当前形式存在五个致命级攻击点，每个单独就足以阻止 PRL 接受。此外，10 个严重级警告需要强制修正。下文逐维度详述。

与 LP36 的 REJECT 不同，本审稿人给出 REVISE -- 因为核心物理方向是正确的，不是死胡同。但问题不是在投稿后修修补补就能解决的：**P0 清单中的每一项都必须在投稿前解决。**

## TOP 5 致命攻击点

### 致命攻击 #1 [P0]: alpha 的 "解析推导" 实质上是数值拟合 -- 论文的核心公式未被第一性原理证明

**攻击点:** 论文声称给出了 QCMI(theta) 的"完整解析表达式" (PI_SYNTHESIS_WALL4_R1, §1):

$$QCMI(\theta) = \frac{\theta^2}{\ln 2}[1 + 2\ln\frac{1}{\theta}] - \frac{\theta^4}{2\ln 2} + O(\theta^6|\log\theta|)$$

但审查发现：

(a) **c_2 = 1.44 来自数值拟合，非解析推导。** A 博士 analytic_derivation.md §2D 明确写道："由实验数据提取。使用两个最小 theta 值...从实验数据提取"。c_2 是主导系数，它的值决定了 theta^2 log(1/theta) 项的系数 A = 2c_2。如果 c_2 是拟合的，整个表达式就不能称为"解析"。

(b) **rho_RQ^(2) 的显式构造从未完成。** 推导在 §2.5 中途放弃（"变得很复杂。让我换一种更简洁的方法"），转而使用基于数据拟合的 Choi 态本征扰动方法。INSPECTOR_wall4_R1 明确指出："rho_RQ^(2) 的显式构造从未被完成...c_2 是从拟合而非推导得到"。

(c) **d_i 系数未被解析确定。** §2.6 中的本征分析标注为"从实验数据提取"。Sigma d_i log d_i ~ 0 的声称是"拟合的后见之明，非推导" (INSPECTOR)。

(d) **theta^4 系数 C 仅论证了符号（C < 0），未给出解析值。** §3.2 的论证是物理直觉（"-c_2^2/2 项给出负贡献"），但 c_4 的具体值从未被计算。

**审稿人判断:** 论文声称有"完整解析表达式"，但核心系数来自数值拟合。这不是解析推导 -- 这是**物理动机的函数形式 + 2-3 参数拟合**。若投稿 PRL，审稿人会要求在 theta^2 log(1/theta) 的系数被解析确定之前，不得声称"解析结果"。当前最多是："我们提出了一个解析形式，其系数与数值数据高度一致"。

**修正要求:** 从 sigma_x 本征基和初始 Bell 态出发，显式构造 rho_RQ^(2) 的 16x16 矩阵，解析计算其本征值的 theta^2 系数 d_i 和 c_2 = Sigma d_i。这是 S4 当前 Round 2 待办中明确列出的 P1 行动（"完成 rho_RQ^(2) 显式推导"），但审稿人认为应该是 **P0** -- 没有它，"解析公式"就是拟合。

### 致命攻击 #2 [P0]: E3 矛盾 -- p(1-p) 与 p-independence 直接冲突，且未解决

**攻击点:** 这是 LP38 内部文档中**标注为最高优先级未解决问题**的矛盾（E3, PI_SYNTHESIS_WALL4_R1 §3: "E3是关键...P0"），但 PI 综合仍在矛盾未解决的情况下声称核心结论"坚实"。

具体矛盾：

- **A 博士的解析推导** (analytic_derivation.md): 在 §2.5 中反复推导出 p(1-p) 因子（来自 Tr[gamma sigma_x gamma sigma_x] = 2p(1-p)），并在 §7 SA-2 中明确预测"对 p=0.5: p(1-p)=0.25, c_2 应提升 19%"。

- **数值 Agent 的实验** (alpha_origin_results.md): 在 theta = pi/128 处实测 p = 0.3, 0.5, 0.7, 0.9，QCMI 完全相同（到 1e-12 精度），结论为"p-independent"。

**两者不能同时正确。** 如果 QCMI 真的 p-independent，那么 A 博士推导中包含 p(1-p) 因子的步骤必然有漏洞。这意味着当前形式的解析推导**不描述正确的物理** -- 它恰好在 p=0.7 时与数据拟合一致（通过拟合 c_2 的值），但在其他 p 值会预测错误。

INSPECTOR 给出了最可能的技术解释（p(1-p) 在 QCMI = S(RQ) + S(QE) - S(Q) - S(RQE) 的组合中精确相消），但**这个相消尚未被显式证明**。更严重的是，p-independence 本身仅在一个 theta 值被验证（E4 低严重性警告），不过这不是核心矛盾。

**审稿人判断:** PI 综合声称"核心科学结论坚实"，但它的"解析推导"和"数值验证"之间存在一个未解决的、P0 优先级的矛盾。如果投稿时 E3 仍未解决，审稿人会立刻抓住：推导和数值不一致，而你们找不到哪一方对 -- 这说明你们不理解自己的结果。这在 PRL 审稿中是**即决 REJECT**。

**修正要求:** 完成以下三项之一：(a) 显式证明 p(1-p) 在完整 QCMI 组合中精确相消（证明 p-independence）；(b) 找到 p-dependence 的实验证据并修正解析推导；(c) 承认当前推导不完全，将所有的 p 声明降级为有条件声明。

### 致命攻击 #3 [P0]: b_1 扫描数据显示 QCMI 几乎不随 b_1 变化 -- 核心拓扑叙事被自身数据削弱

**攻击点:** b_1 扫描实验 (b1_scan_results.md) 是 LP38 最诚实也最自我毁灭的产出。它明确得出：

- **alpha = 0.103 +/- 0.025**（QCMI vs b_1 的幂律拟合指数）
- **QCMI 仅在 b_1 从 1 增加到 4 时增长 23%**（3.18 -> 3.93）
- **树（b_1=0）已捕获单环 QCMI 的 97%**
- **3-环 vs 4-环的差异（1.76x）远大于任何 b_1 效应**
- **b_1=3 和 b_1=4 的 QCMI 逐位相同**（到 1e-15）

b1_scan_results.md §5.6 自己写道："QCMI is dominated by Cartan axis alignment rather than by topological cycle count. The b1 scaling exponent is essentially zero."

但 PI 综合和 README 将此包装为"精化为 b_1^{ind}"的"新发现"。审稿人会问：

> 如果 b_1 的效应本质上是零（alpha=0.103），那么将声明从 I >= eta_0 * b_1 "精化"为 I >= QCMI_tree + eta_0 * b_1^{ind} 有什么物理意义？你本质上是在说"QCMI ~ QCMI_tree + 一个非常小的修正"。b_1 不是控制参数 -- 它是一个几乎与被测物理无关的不变量。

**"b_1^{ind}" 的"发现"是消极的：** 它表明只有顶点完全不共享的环才线性可加。这是有趣的，但它同时意味着在大多数物理相关的图中（共享节点的环），b_1 没有预测力。

更致命的是 b_1 扫描的实验设计 confound：
- b_1=2 使用 3-环，b_1=1,3,4 使用 4-环
- 3-环 vs 4-环的 QCMI 差异为 1.76x，远大于任何 b_1 依赖
- "两个 3-环给出单个 3-环 QCMI 的 2 倍"这个唯一支持线性可加性的数据点**仅基于两个数据点**
- 报告的 30 个 trial 中，b_1 配置只有 5 个（0,1,2,3,4）-- 自由度太少

**审稿人判断:** 如果投稿的论文声称"b_1 是多环非马尔可夫性的拓扑控制参数"，审稿人会直接引用 b1_scan_results.md 中的数据来反驳。论文自身的数据表明 b_1 的效应 alpha=0.103 几乎为零。**你需要解释为什么一个指数为 0.103 的参数值得作为"控制参数"发表。**

**修正要求:** (1) 用一致的门组（相同 Cartan 统计分布）和一致环大小重新运行 b_1 扫描；(2) 加入 b_1=5,6 的配置，超越当前 6 qubit 上限使用更大的 QE 系统；(3) 如果确认 alpha ~ 0.1，诚实地将论文的叙事从"b_1 控制 QCMI"修正为"b_1 是弱控制参数，主效应来自门参数和环大小"。

### 致命攻击 #4 [P0]: CCQ 翻转问题 -- 论文建立在作者自己后来证伪的定理上

**攻击点:** CCQ 定理（对易性-量子关联定理）是 LP36/LP38 作者自己提出的内部定理（commutativity_theorem.md）。LP38 现在发现 CCQ 定理(II)（关于对齐轴 QCMI=O(|c|^4) 的声称）是错误的，并用数值实验证伪了它。

问题不在证伪本身 -- 科学上，纠正自己的错误是正确的。问题在于：

**(a) 论文架构依赖链未被审计。** CCQ 定理在 LP38 架构中的角色包括：
- 支柱 III 的基础（commutativity_theorem.md）
- eta_0 紧度分析（Round 2 A 博士的 inf=0 结论依赖 CCQ）
- Wall 3 的关键前提
- "对易性控制定理"的 O(|c|^4) 声称

PI_SYNTHESIS_FINAL 明确承认："Round 2 A 博士的 inf=0 结论依赖 CCQ 的 O(|c|^4) 声称，CCQ 证伪后 A 博士的结论失效"。但论文中**还有多少其他声称在 CCQ 修正后需要更改？** 没有人做过完整的依赖审计。

**(b) "我们证伪了自己的定理"不能作为论文贡献。** 如果投稿时说"我们之前提出的 CCQ 定理在第 II 部分有漏洞，现在我们纠正它"，审稿人会回复：纠正内部错误是正常的科研过程，但不是可发表的贡献 -- 它是你本应在内部完成的工作。PRL 想要的是新物理。

**(c) CCQ 定理剩余部分的状态不明确。** CCQ 有四个子定理。定理(II)被证伪了，定理(I)（Cartan-Abelian 对应）和定理(III)（sin^2 theta 放大）据称不受影响。但这个判断是否可靠？定理(III)的 O(|c|^4) 前置因子是否也受到了影响？p(1-p) 与 p-independence 的矛盾（致命攻击 #2）似乎与定理(III)中 p(1-p) 因子的来源有关。

**审稿人判断:** 论文当前的架构中存在一个灰色区域：哪些声称基于被证伪的 CCQ、哪些经过修正、哪些尚未审计。在投稿前，需要一份完整的 CCQ 依赖审计报告，明确标注每个声称的状态。

**修正要求:** (1) 完成全架构 CCQ 依赖审计，标注每个声称是否受 CCQ 定理(II) 证伪的影响；(2) 将论文叙事从"我们发现了 CCQ 的漏洞"改为"系统分析揭示 Cartan 对易性压制 O(theta^2) 贡献的论证中存在概念混淆"；(3) 不要在摘要或引言中以"证伪 CCQ"作为贡献点 -- 将贡献点放在正确的解析形式上。

### 致命攻击 #5 [P0]: CFOL v6 的块对角兼容性 -- 环因子化阻碍引理的强度被内在降级

**攻击点:** README 提到"CFOL v6 发现块对角形式兼容 r_i=2"。CFOL（环因子化阻碍引理）是 LP36/LP38 的基石定理，声称：

$$I(R;E'|Q') = 0 \Longleftrightarrow \forall i: u_i = v_i \otimes w_i$$

即 QCMI = 0 当且仅当每条边的酉算子是因子化的（r_i = 1, 秩-1 的算子 Schmidt 分解）。

但"兼容 r_i=2"意味着：**CFOL 允许 r_i=2 的块对角酉算子产生 QCMI=0。** 这让条件从"秩-1"放松到"秩 <= 2"。这是一个质的减弱：
- r_i=1 意味着 u_i 完全不能产生 Q-E 纠缠
- r_i=2 意味着 u_i 可以有非平凡的 Q-E 结构，只要它保持块对角形式

**审稿人判断:** 如果 CFOL 的最强形式（r_i=1）已经被放松到 r_i=2，那么整个"环因子化阻碍"的叙事被弱化了。CFOL 不再等价于"环强制非零 QCMI"的强条件，而是等价于"环强制非零 QCMI 除非酉算子满足特定块对角结构" -- 这是一个在逻辑上空间大得多的例外集合。

这也使 CFOL 与 Buscemi 2025 的先行工作更加接近 -- Buscemi 同样分析了因果回流中哪些酉结构允许信息"回流"到 Q。如果块对角酉可以避开 CFOL 的阻碍，那么 CFOL 的新颖性边界与 Buscemi 的重叠会进一步增加。

**修正要求:** 澄清 CFOL v6 中"兼容 r_i=2"的精确含义。是否意味着原 CFOL 声明需要修正（从 r_i=1 放松到 r_i=2）？如果是，在论文中明确写出来，不要藏在 README 里。

## 维度一：新颖性 -- 评分：中弱

### 1.1 Buscemi 2025 优先权问题未解决（LP36 审稿人已指出的问题）

LP36 审稿人指出 Buscemi et al. (2025, PRX Quantum 6, 020316) 已使用"完全相同的 squashed non-Markovianity 框架分析因果回流"。LP38 仍使用相同的 Buscemi 框架（混合态环境 gamma，sQNM 的 QCMI 定义），并未在现有文档中看到与 Buscemi 的明确区分。

### 1.2 CCQ 定理(I) 的 Cartan-Abelian 对应是否是新结果？

[a_i sigma_i, b_j sigma_j] 当且仅当 a 平行于 b 时为零 -- 这是 Pauli 代数的基本性质，在任何量子力学教科书中都有。将其重述为"Carten-Abelian 对应"并称之为定理是包装已知代数事实。

### 1.3 新颖性裁决

LP38 的新颖贡献（不是 LP36 的延续）包括：
- **真新颖:** CCQ 定理(II) O(|c|^4) 声称的证伪 + alpha~1.81 的对数修正起源解释
- **弱新颖:** eta_0 的"渐近最优"重新定位（但这更多是修辞而非新定理）
- **几乎零新颖:** CFOL 的 b_1 推广（因 b_1 扫描数据显示无标度行为）

**PRL 适合度评估：** 可接受一篇 PRL 快报，聚焦 S4（CCQ 修正 + alpha~1.81 的解析起源），前提是致命攻击 #1-#5 全部解决。完整四子命题对 PRL 来说贡献分散且太多未完成项。

## 维度二：技术正确性 -- 评分：部分完成

### 2.1 已完成且无误的部分

- **CFOL v4（环因子化阻碍引理）:** 对 4 节点单环的严格证明成立（INSPECTOR 已独立验证）
- **sigma_x 本征基对角化:** U 的本征结构分析正确（S = (s_1+s_3)(s_2+s_4) 因式分解）
- **QCMI = S(rho_RQ) 的简化**（在 S(QE) 和 S(RQE) 不变的条件下）正确
- **CCQ O(|c|^4) 声称的漏洞诊断:** 根本原因（BCH 层 vs QCMI 层混淆）被正确识别

### 2.2 不完整/未完成的部分

- **rho_RQ^(2) 显式构造:** 推导未完成（致命攻击 #1）
- **c_2 的解析值:** 未从第一性原理推导（致命攻击 #1）
- **p(1-p) 相消机制:** 未证明（致命攻击 #2）
- **树边冻结引理:** "局部成立"不等于"全局严格"（INSPECTOR_wall2_R1 WARN-2 确认）
- **b_1 可加性:** 仅对顶点不相交环严格；共享节点环未解决（INSPECTOR_wall2_R1 BLOCK-1）

### 2.3 技术审稿中的其他关注点

**(a) 3-环/4-环 confound:** b_1=2 使用 3-环，b_1=1,3,4 使用 4-环。3-环的 QCMI(1.806) 仅是 4-环(3.185)的 57%。这个 1.76x 差异是任何 b_1 效应的 7 倍以上。实验设计的标题如是"b_1 扫描"，但实际测的是"环大小效应"。

**(b) "渐近 alpha=2"永远无法被数值验证。** INSPECTOR_wall4_R1 指出：要观测到 alpha>1.99，需要 theta < e^{-100} ~ 10^{-43}。"渐近收敛"完全是解析论证的结果，数值实验只能提供一致性检查，永远不能独立证明。论文应诚实标注这一点。

**(c) eta_0=0.180 的 "渐近最优性" 的适用范围。** eta_0 = 1/(8 ln 2) 在 d=2, gamma 最大化混合（p=0.5）的特殊情况下导出。对于一般 d 和 p，eta 的值会改变。将其称为"普适常数"是过度声张。

## 维度三：物理意义 -- 评分：改善但仍薄弱

### 3.1 "1 纳米批评"的回应

LP36 审稿人指出 eta_0=0.180 bits 比实验数据（0.74-3.24）小 4-18 倍，等同于"人的身高 >= 1 纳米"的空洞下界。LP38 的回应是将其重新定位为"渐近最优系数"。

**这个回应是巧妙的修辞，但不改变物理。** eta_0 仍然比任何实验数据小 4-18 倍，仍然没有任何实验可以区分 eta_0=0.180 和 eta_0=0 -- 两者都远低于所有测量值。

**"渐近最优"的含义是什么？** 它意味着 "(1) 不能有更大的普适常数, (2) 但在任何有限系统中永远达不到它"。这与"光速类比"（PI_SYNTHESIS_FINAL §3）在形式上是成立的 -- 但光速可在实验中逼近（粒子速度可达到 0.9999c），而 eta_0 永远不能（QCMI 总是 >> eta_0）。这不是不可达的渐近极限 -- 这是一个物理上无关的下界。

### 3.2 alpha~1.81 的物理意义

**这个结果在物理上是清晰的、有价值的。** von Neumann 熵在纯态附近的行为是 -lambda log lambda 的非解析性，这在 theta -> 0 时自然产生 alpha = 2 - 1/ln(1/theta) 的对数修正。它不是新物理常数，而是标准量子信息论在特定极限下的行为。

但这引出另一个问题：**如果 alpha~1.81 是对数修正的平凡结果，那么论文声称的贡献到底是什么？** 是"发现 CCQ 错了"（消极贡献），还是"发现正确的标度行为"（积极贡献）？如果是后者，正确的标度行为 alpha_eff = 2 - 1/[ln(1/theta) + 1/2] 是一个标准扰动论练习 -- 审稿人会问：这个结果是否值得一篇 PRL？

### 3.3 "因果拓扑 -> 非马尔可夫性"的连接

LP36 审稿人最尖锐的批评是："真正控制 QCMI 的是门类型（Cartan 系数），不是拓扑（b_1）"。LP38 的 b_1 扫描实验（alpha=0.103）**用数据证实了这一批评**。论文没有提供反驳，而是改变叙事从"b_1 控制 QCMI"到"b_1^{ind} 有一个小效应"。

这是一个诚实的修正，但它削弱了 DGF 宣言中核心叙事的物理说服力："因果拓扑是宇宙分离经典世界和量子世界的机制"。如果 b_1 的效应是 alpha=0.103（几乎为零），那么"因果拓扑"作为分离机制的物理重要性需要被重新评估。

### 3.4 物理意义裁决

alpha~1.81 的对数修正起源是真实的、有价值的物理。但"eta_0 渐近最优"和"b_1^{ind} 精化"的物理意义薄弱，分别面临"空洞下界"和"无效控制参数"的批评。建议将论文重心转移到 S4（alpha 的起源+CCQ 修正），弱化或删除 b_1 相关的物理声称。

## 维度四：内部一致性 -- 评分：多处矛盾

### 4.1 定理/猜想边界模糊

DGF 宣言将五个支柱并列呈现。支柱 I-IV 标注为"定理"或"数值定理"，支柱 V 标注为"物理图景，部分证明"。但在叙事中，支柱 V 的"宏观极限"声称被编织进同一套叙事语言中，模糊了"已证明"和"猜想"的边界。

**"数值定理"是自相矛盾的术语。** 数值验证给出的是证据，不是证明。将数值验证称为"定理"会误导读者认为有解析证明。

### 4.2 b_1 下界公式的演进暴露叙事不稳定

LP38 的 b_1 公式经历了以下演进：
1. LP36 原始: I >= eta_0 * b_1
2. Wall 2 修正: I >= QCMI_tree + eta_0 * b_1^{ind}
3. b_1 扫描揭示: alpha=0.103（几乎无标度行为）
4. 当前叙事: "精化为 b_1^{ind} 的新发现"

如果原始声称"b_1 控制 QCMI"和修正后的声称"b_1^{ind} 有一个可忽略的小效应"出现在同一条论文线中，审稿人会注意到这个降级。建议在论文的修订历史或引言中坦诚地叙述这个演进过程，而不是将精化包装为"新发现"。

### 4.3 CCQ 定理的四个子定理状态不一致

CCQ 定理(II)被证伪了。定理(I)和(III)声称不受影响。但定理(III)（sin^2 theta 放大）的 O(|c|^4) 前置因子是否完全独立于定理(II)的推理？如果定理(III)的部分推理链与定理(II)共享（两者都使用 BCH 展开，虽然是不对易的情况），那么定理(III)的可靠性也需要独立验证。

### 4.4 "实验"标签模糊

论文中的"实验数据"全部来自经典数值模拟（完整状态向量，<= 6 qubit）。这不是实验。投稿时必须明确使用"numerical simulation"而非"experiment"。

## 维度五：可检验性 -- 评分：不可行

### 5.1 核心预测在当前量子硬件上均不可行

- **theta ~ pi/512 的 QCMI 测量:** QCMI ~ 6e-4 bits，远低于任何现有量子设备的 QCMI 分辨率
- **eta_0 = 0.180 bits 的紧度验证:** 需要 QCMI 接近 0.180 bits，这要求在极小的 Cartan 系数下操作（|c| << 1），门保真度要求远超当前技术
- **p-independence 验证:** 需要高保真度的混合态环境制备，p 值可在 [0.3, 0.9] 范围内精确控制

### 5.2 b_1 > 3 的图需要 >= 7 qubit 的 QE 系统

这在当前 NISQ 设备上勉强可达（IBM 127-qubit 设备），但 7+ qubit 的完整状态向量模拟需要 2^14 = 16384 维矩阵，过程层析的测量次数指数级增长。论文未提供多项式级的测量方案。

### 5.3 论文未诚实标注这些限制

PI 综合和 README 多次提到"实验验证"但从未讨论为什么这些"实验"实际上不可行。PRL 审稿人会要求具体的实验可执行方案，或诚实地标注"当前的预测在当前硬件上不可直接检验，需等待容错量子计算"。

## 最终裁决：REVISE (MAJOR)

**裁决理由:**

LP38 的物理方向是正确的。CCQ 的 O(|c|^4) 声称确实有错误，alpha~1.81 确实来自 von Neumann 熵在纯态附近的对数修正。这些是真科学。

但 LP38 当前有 **5 个致命级未解决问题**（P0-1 到 P0-5），每一个都足以在 PRL 审稿中触发 REJECT。此外，b_1 扫描数据（alpha=0.103）本质上削弱了论文的拓扑叙事 -- 虽然团队诚实报告了这一点，但未在叙事中充分消化其含义。

**与 LP36 的对比:** LP36 审稿人给出了 REJECT。LP38 取得了实质性进步（CCQ 证伪，alpha 起源，b_1 扫描实验），因此给出 REVISE 而非 REJECT。但这些进步尚未到达"可投稿"的状态 -- 它们完善了物理理解，但论文本身还处于"发现阶段"，尚未进入"呈现阶段"。

**建议路径:**

**路径 A（推荐 -- 最可能在 PRL 存活）:** 将论文范围收缩到 S4（CCQ 修正 + alpha~1.81 的解析起源）。这是 LP38 最强、最完整、最新颖的贡献。删除或降级 b_1 相关声称。论文结构：
1. "对齐轴下的 QCMI 标度：CCQ O(|c|^4) 声称的修正" -- 主要定理
2. QCMI = (theta^2 / ln 2)[1 + 2 ln(1/theta)] + ... -- 解析公式（完成 P0-1 后）
3. alpha_eff = 2 - 1/[ln(1/theta) + 1/2] -- 精确有效指数
4. 数值验证（标注为 numerical simulation）
5. 实验可检验性讨论（诚实的）

**路径 B（高风险的完整投稿）:** 保留全部四子命题，但解决所有 P0/P1 项。这需要 S4 Round 2 的完整执行（E3 解决，rho_RQ^(2) 完成，p-independence 多 theta 验证），加上 b_1 扫描的重新设计，加上 CCQ 依赖审计。工作量估计：2-3 周全职。

**底线:** 当前形式不可投稿。方向正确，但论文还未准备好。REVISE (MAJOR)，建议遵循路径 A。

## 附录 A：对作者可能辩护的预回应

### 辩护 1: "eta_0 是'渐近最优'的，审稿人不应再次提出'1 纳米'批评"

**预回应:** "渐近最优"是一个数学元属性 -- 它说的是"没有一个更大的常数能给有效的下界"。这在数学上是正确的，我承认。但物理学家关心的是操作意义。一个在所有实验中都被 4-18x 超越的"下界"仍然没有预测力。与其坚持"渐近最优"，不如将 eta_0 定位为"一个来自 Fawzi-Renner 框架的首阶分析下界，为未来紧化提供起点"。这更诚实，审稿人也会更接受。

### 辩护 2: "b_1^{ind} 的发现是有意义的 -- 它告诉我们只有独立环才线性可加"

**预回应:** 这是正确的方向，但你论文中的数据表明这个效应是 alpha=0.103 -- 几乎是零。你需要面对的问题是：一个指数为 0.1 的控制参数是否值得发表为"控制参数"？或者更诚实地说"b_1 是拓扑序参量的弱代理，QCMI 主要由门参数控制"？

### 辩护 3: "alpha~1.81 的 log 修正是标准扰动论 -- 但它是新颖的，因为之前没人发现 CCQ 的漏洞"

**预回应:** 这个辩护有一定道理。CCQ 漏洞的发现确实是有价值的。但你的解析推导必须完整（P0-1）-- 如果审稿人发现 c_2 是拟合的不是推导的，他们会立刻攻击。而且"发现 CCQ 错了"这个叙事在 PRL 上的新颖性有限 -- CCQ 是你自己的定理，审稿人会觉得这是你应该在内部完成的纠正工作。将重点放在"我们给出了正确的解析形式"而不是"我们发现的 CCQ 漏洞"会更有利。

### 辩护 4: "论文有大量数值证据"

**预回应:** 数值证据是支持的，但：
- b_1 扫描只有 5 个 b_1 值，其中 2 个使用不同的环大小
- p-independence 仅在一个 theta 值验证
- 所有模拟 <= 6 qubit（经典模拟极限），未展示可扩展性
- "实验"措辞误导读者以为有量子硬件实验

数值证据足以支持解析结果的置信度，但不足以替代未完成的解析推导。
