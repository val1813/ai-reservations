## 前置: 熵结构的精确定义

### 离散微观描述

N个二元细胞，每个细胞状态 s_i ∈ {0, 1}（0=空置, 1=占用）。q = (1/N) Σ_i (1-s_i) = 空置比例。

每个细胞的微观熵（在占用概率1-q下）:
```
s_cell(q) = -k_B [(1-q) ln(1-q) + q ln q]
```

总容量熵（所有细胞均占用且信息最大化时）:
```
S_capacity = k_B ln 2 · N
```

von Neumann熵（已被占用的信息）:
```
S_vN(q) = k_B · N · [-(1-q) ln(1-q) - q ln q]
```

相干熵（剩余的量子相干容量）:
```
S_coh(q) = S_capacity - S_vN(q)
         = k_B · N · [ln 2 + (1-q) ln(1-q) + q ln q]
```

### 极限行为

| q | S_vN/Nk_B | S_coh/Nk_B | 物理 |
|---|-----------|-----------|------|
| 1 | 0 | ln 2 | 纯量子，全部容量空闲 |
| 1/2 | ln 2 | 0 | 最大混合，相干容量归零 |
| →0 | ln 2 | 0 | 纯经典，全部信息已归档 |

**关键观察:** S_coh 在 q=1/2 处归零，不是 q=0。这意味着"相干容量"在最大混合态（q=1/2）时已被耗尽——即使还有一半细胞空置。q<1/2时 S_coh 如何？由公式，当 q→0，S_coh→0（两项 ln 2 消去）。所以 S_coh≥0 在 q∈[0,1] 全局成立，且在 q=0 和 q=1/2 两点为零，在 (0, 1/2) 和 (1/2, 1) 区间为正。

等等——q=1/2时 S_coh=0，这是 Shannon 熵的内在性质。物理上: 最大混合态（每个细胞等概率占用/空置）具有最大 von Neumann 熵，此时"量子相干"和"经典记录"之间没有可区分的容量剩余。一切信息都以经典概率分布的形式存在。

对于典型的物理系统（q从1弛豫到某个中间值），相干容量 S_coh 先增加后减少，在 q=1/2 处经过零点。

下面开始四个方向的推导。

## 方向1: 信息擦除热 —— DGF版 Landauer 极限

### 1.1 标准 Landauer 原理回顾

Landauer (1961): 在温度 T 的热浴中擦除 1 bit 信息，至少耗散热量:

```
ΔQ_min = k_B T ln 2
```

物理原因: 擦除 = 逻辑状态空间从 2→1（压缩），对应物理相空间减半，熵减少 k_B ln 2，必须向环境排放至少 k_B T ln 2 的热量以遵守热力学第二定律。

### 1.2 DGF 中的确定-擦除循环

考虑 DGF 格点上一个细胞的完整循环:

```
|0⟩  --[确定/写入]-->  |1⟩  --[擦除]-->  |0⟩
空置                    占用               空置
q 贡献: +1/N            q 贡献: 0          q 贡献: +1/N
```

**第1步: 写入（|0⟩→|1⟩）。** 信息从环境流入细胞。细胞被占用。局域 q 减少 Δq = -1/N。从信息流动方向看，这是"顺梯度"过程——信息自然地从高 q（低信息密度）流向低 q（高信息密度）。在 surprisal 势 Φ(q) = -ln q 下:

```
ΔΦ_write = -ln(q - 1/N) + ln(q) ≈ -1/(qN)   [对 N ≫ 1]
```

这一步**释放**自由能（信息"落下"势能梯度）。最大可提取功:

```
W_extractable = k_B T · [Φ(q) - Φ(q - 1/N)] ≈ k_B T/(qN)
```

**第2步: 擦除（|1⟩→|0⟩）。** 信息必须从细胞移出。局域 q 增加 Δq = +1/N。这是"逆梯度"过程——需要外力做功来清空细胞。所需最小功:

```
W_erase_min = k_B T · [Φ(q) - Φ(q - 1/N)] ≈ k_B T/(qN)
```

等等——这和写入释放的功一样？让我仔细验证。

Φ(q) = -ln q。细胞初始处于空置态|0⟩，它对局域 q 的贡献是 1/N（它自己是空的）。

写入前局域 q（包含此细胞）: q
写入后局域 q': q - 1/N

擦除前局域 q': q - 1/N
擦除后局域 q: q

写入过程的 surprisal 变化（从细胞角度看）:
- 写入前：此细胞是空的，其"空置事件"的 surprisal = -ln q
- 写入后：此细胞被占用，不再是空置事件的一部分
- 系统的信息势变化: ΔΦ_sys = Φ(q') · N - Φ(q) · N ≈ N · [Φ'(q) · (-1/N)] = -Φ'(q)

对 Φ = -ln q: ΔΦ_sys = 1/q

这不对——让我更系统地推导。

### 1.3 系统推导: DGF Landauer 极限

考虑包含 N 个细胞的系统 S，与环境 E 热接触（温度 T）。系统局域 q 值为 q_S。

**擦除操作:** 将 k 个细胞从占用态(|1⟩)重置为空置态(|0⟩)。

擦除前：q_before = q_S
擦除后：q_after = q_S + k/N

系统的容量熵变化:
```
ΔS_capacity = 0  [容量守恒——细胞数不变]
ΔS_vN = k_B N [S_vN(q_after) - S_vN(q_before)]
ΔS_coh = -ΔS_vN  [S_capacity 守恒]
```

对 q 的小变化 δq = k/N:
```
ΔS_vN = k_B N · [S_vN'(q) · δq]
       = k_B N · [-ln(1-q) + ln q] · k/N
       = k_B k · ln(q/(1-q))
```

对 q < 1/2（大多数物理系统）: ln(q/(1-q)) < 0，所以 ΔS_vN < 0 ——擦除**减少** von Neumann 熵。

系统熵减少意味着热量必须排入环境:
```
ΔQ_min = T · |ΔS_vN| = k_B T · k · |ln(q/(1-q))|
```

**DGF Landauer 极限:**

```
┌─────────────────────────────────────────────────┐
│ ΔQ_min(k, q) = k_B T · k · |ln(q/(1-q))|       │
│                                                 │
│ 每 bit 擦除: ΔQ_min(1, q) = k_B T · |ln(q/(1-q))| │
└─────────────────────────────────────────────────┘
```

### 1.4 与标准 Landauer 的比较

标准 Landauer: ΔQ_min = k_B T ln 2（与 q 无关的常数）。

DGF Landauer: ΔQ_min 依赖局域 q 值。

| 局域 q | ΔQ_min / (k_B T) per bit | 物理区域 | 与标准之比 |
|--------|--------------------------|---------|-----------|
| q → 1/2 | → 0 | 最大混合态附近 | → 0 |
| q = 1/3 | ln 2 ≈ 0.693 | — | = 1（恰好等于标准！） |
| q = 1/4 | ln 3 ≈ 1.099 | — | ≈ 1.585 |
| q = 1/10 | ln 9 ≈ 2.197 | — | ≈ 3.17 |
| q → 0 | → +∞ | 黑洞附近 | → ∞ |

**关键发现:**

1. **q = 1/3 时 DGF Landauer 极限恰好等于标准 k_B T ln 2。** 这是一个优美的巧合: ln((1/3)/(2/3)) = ln(1/2) = -ln 2。在室温环境（q ≈ 1/3，即约 1/3 细胞空置）中，DGF 预言与标准 Landauer 一致。

2. **q < 1/3 时 DGF 预言更大的擦除热。** 在信息密集区域（低 q），擦除一个 bit 需要付出比标准 Landauer 更大的热力学代价——因为要"逆流而上"对抗信息密度梯度。

3. **q → 0 极限: 擦除需要无限热量。** 这为"黑洞无毛"提供了热力学解释：在 q→0（容量饱和）处，任何试图"擦除"信息（使之可被外界读取）的操作都需要无限能量——因此信息不可逃逸。

4. **标准 Landauer 是 DGF Landauer 在 q = 1/3 处的特例。** 这暗示标准 Landauer 原理隐含假设了特定的环境信息密度。

### 1.5 实验检验可能性

测量超导量子比特阵列中的擦除热作为外加磁场（控制有效 q）的函数。预言: 擦除热随 q 减小而增大，在 q → 1/2 附近趋近于零。

**困难:** 需要独立测量局域 q——这本身需要 DGF 框架外的操作定义（当前框架缺口）。

### 1.6 诚实标注

| 声明 | 置信度 |
|------|--------|
| ΔQ_min ∝ |ln(q/(1-q))| 的形式 | ★★★★☆ — 从 S_vN 定义直接推出 |
| q → 0 ⇒ ΔQ_min → ∞ | ★★★★☆ — 极限行为正确 |
| q = 1/3 ⇒ ΔQ_min = k_B T ln 2 | ★★★★★ — 精确等式 |
| 实验可检验性 | ★★☆☆☆ — 需要独立 q 测量方案 |

## 方向2: 黑洞信息熵 —— DGF 容量熵 vs Bekenstein-Hawking

### 2.1 设定

DGF 静态球对称解: q(r) = e^{-GM/rc²}

"q-施瓦西半径"（q = e^{-1} ≈ 0.368）: r_q = GM/c²

（注意: 这是 GR 施瓦西半径 r_s = 2GM/c² 的一半。）

### 2.2 r < r_q 区域内的总容量熵

容量熵密度（假设 Planck 尺度的细胞，间距 a = ℓ_P = √(ħG/c³)）:

```
s_capacity = k_B ln 2 / ℓ_P^3
```

这是**每个细胞的容量**——不是实际熵，而是最大可能熵。在 DGF 中，实际 S_vN 依赖于 q(r)，但 S_capacity 是结构常数。

r < r_q 的总体积:
```
V(r_q) = (4π/3) r_q^3 = (4π/3) (GM/c²)^3
```

总容量熵:
```
S_capacity(r < r_q) = k_B ln 2 · V(r_q) / ℓ_P^3
                     = k_B ln 2 · (4π/3) (GM/c²)^3 / ℓ_P^3
```

代入 ℓ_P = √(ħG/c³):
```
S_capacity(r < r_q) = k_B ln 2 · (4π/3) (GM/c²)^3 · (c³/ħG)^{3/2}
                     = k_B ln 2 · (4π/3) · G^{3/2} M^3 / (c^{3/2} ħ^{3/2})
```

简化: 引入 Planck 质量 M_P = √(ħc/G):
```
S_capacity(r < r_q) = k_B · (4π ln 2 / 3) · (M/M_P)^3
```

### 2.3 Bekenstein-Hawking 熵

对于质量 M 的施瓦西黑洞:
```
S_BH = k_B · A / (4 ℓ_P^2)
     = k_B · 4π (2GM/c²)² / (4 ℓ_P^2)
     = k_B · 4π (GM/c²)² / ℓ_P^2
```

代入 ℓ_P:
```
S_BH = k_B · 4π (GM/c²)² · (c³/ħG)
     = k_B · 4π · G M² / (ħ c)
     = k_B · 4π · (M/M_P)^2
```

### 2.4 比值

```
R(M) ≡ S_capacity(r < r_q) / S_BH
     = [(4π ln 2 / 3) (M/M_P)^3] / [4π (M/M_P)^2]
     = (ln 2 / 3) · (M / M_P)
```

```
┌────────────────────────────────────────────┐
│ R(M) = (ln 2 / 3) · (M / M_P)             │
│                                            │
│ 对 M = M_P:   R ≈ 0.231                   │
│ 对 M = M_⊙:   R ≈ 2.1 × 10^{37}           │
│ 对 M = M_M87*: R ≈ 1.8 × 10^{47}           │
└────────────────────────────────────────────┘
```

### 2.5 物理解释

**比值 R(M) 随质量线性增长**——这是体积熵 (∝ r³) 与面积熵 (∝ r²) 对决的必然结果。

这个巨大差异有四种可能的解读:

**解读 A (朴素): DGF 容量熵和 Bekenstein-Hawking 熵度量不同的东西。**
- S_BH 是黑洞视界的**实际熵**（已占用信息）
- S_capacity 是黑洞内部区域的**最大可能容量**
- 两者量纲不同（面积 vs 体积），直接比值无物理意义

**解读 B (激进): DGF 暗示 Bekenstein-Hawking 熵低估了黑洞的信息容量。**
- 如果 DGF 的细胞模型正确，黑洞内部应该容纳 ∝ M³ 的容量
- 但广义相对论说内部不可观测——所以 Bekenstein-Hawking 是"可观测"熵而非"实际"熵
- DGF 没有硬视界——原则上所有信息都可回流（尽管概率极小）
- 因此 DGF 预言黑洞的实际信息容量远大于 S_BH

**解读 C (建设性): DGF 需要一个等效的"面积定律"。**
- 从 DGF 出发，如果信息只在边界细胞（最外层的低 q 细胞）上被外部观测者访问，则有效熵 ∝ 面积
- 需要推导: 为什么边界细胞数 ∝ r² 而非内部细胞数 ∝ r³
- 候选机制: q 场 sigmoid 前沿——边界上的 q 梯度最大，信息交换主要发生在边界

**解读 D (最诚实): S_capacity 和 S_BH 之间的比值 R(M) 是 DGF 的一个自由参数校准机会。**
- 设细胞间距 a 不是 ℓ_P 而是某个 λ·ℓ_P
- 要求 R(M_P) = 1 ⇒ a/ℓ_P = (3/ln 2)^{1/3} ≈ 1.63
- 或者要求 DGF 给出面积定律 ⇒ 信息细胞在强场下维度约化（从 3D → 2D）

### 2.6 维度约化的 DGF 论证（方向性）

在 q → 0 极限下，有效扩散系数 D(q) = κ/q → ∞。这意味着在 q 极小的区域，信息扩散极快——任何进入该区域的信息瞬间均匀化。这等效于该区域失去了空间结构——所有点瞬时连通。

一个 D(q) → ∞ 的区域在信息论上等效于一个零维对象（一个点）——所有内部结构被抹平。包围这个零维核心的是一个 q 梯度的过渡层（sigmoid 前沿），其厚度为:

```
Δr_sigmoid ≈ √(D₀ τ) 
```

其中 D₀ 是真空扩散系数，τ 是弛豫时间。这个过渡层是**二维表面**——所有与外部交换的信息都经过这个表面。因此 DGF 有可能从自身动力学推导出"有效面积定律"——信息容量虽然在体积中分布，但**可访问**容量由边界面积决定。

**这需要进一步形式化，当前为方向性推测。**

## 方向3: 量子 Darwinism 的 q 度量

### 3.1 标准量子 Darwinism 回顾

Zurek (2003-2009): 系统 S 与环境 E 相互作用。环境被划分为 N 个碎片 {F_1, ..., F_N}。从每个碎片可以部分推断系统状态。

**冗余度 R_δ:** 能给出系统状态信息（保真度 > 1-δ）的环境碎片数量。

量子 Darwinism 的核心结果: 只有指针可观察量（pointer observables）能在环境中被冗余地记录——这是经典客观性"涌现"的机制。

### 3.2 DGF 对应: q 作为冗余度的容量基础

在 DGF 中，q 决定系统有多少"自由容量"可被环境碎片占用。核心假设:

> **一个环境碎片要能编码系统状态信息，需要占用至少一个细胞。占用细胞的概率正比于系统与环境的信息交换速率，而此速率 ∝ (1-q_S)（系统已占用比例，即"经典度"）。**

更精确地: 系统 S 与一个环境碎片 F_i 的互信息 I(S:F_i) 应依赖于:
- q_S: 系统剩余量子容量（决定了还有多少信息可被"读出"）
- q_Fi: 碎片剩余量子容量（决定了碎片能编码多少信息）
- 相互作用强度（耦合常数）

### 3.3 推导 R_δ(q)

假设 N_frag 个全同环境碎片，每个有 M 个细胞，初始 q_F = 1（全部空置）。

系统 S 有 N_S 个细胞，初始 q_S ∈ (0,1)。

每次 S-F_i 相互作用:
- 从 S 传输 ΔI 信息到 F_i
- S 的占用率增加: (1-q_S) → (1-q_S) + ΔI/N_S
- F_i 的占用率增加: (1-q_Fi) → (1-q_Fi) + ΔI/M

信息传输量 ΔI 受两个因素限制:
1. S 的剩余容量: ΔI ≤ N_S · q_S（还有多少空置细胞可"释放"信息）
2. F_i 的剩余容量: ΔI ≤ M · q_Fi（碎片还能接收多少信息）

在 q_S 较小时（S 已经相当经典），每次传输的信息量小（因为 S 的大部分信息已被锁定在占用细胞中，只有剩余的量子相干可被"读取"）。

设单次相互作用传输的信息量为:
```
ΔI(q_S, q_F) = min(α · q_S · N_S,  α · q_F · M)
```

其中 α 是耦合效率（0 < α ≤ 1）。

对一个环境碎片，接收到的总信息:
```
I(S:F_i) ≈ α · min(q_S · N_S, M)   [假设 F_i 初始为空]
```

如果 M ≫ N_S（环境碎片比系统大得多），则 I(S:F_i) ≈ α · q_S · N_S。

系统信息总量: I_S = (1-q_S) · N_S（已占用的细胞编码的信息）。

一个碎片能捕获的系统信息比例:
```
f(q_S) = I(S:F_i) / I_S = α · q_S · N_S / ((1-q_S) · N_S) = α · q_S/(1-q_S)
```

当 f(q_S) < δ（碎片信息不足以 δ-推断系统状态），该碎片不算"冗余"。

**冗余度 R_δ:** 满足 f(q_S) ≥ δ 的碎片数量。如果每个碎片接收大致等量的信息:
```
R_δ ≈ min(N_frag,  I_S · (1-δ) / I(S:F_i))
     = min(N_frag,  (1-q_S) · N_S · (1-δ) / (α · q_S · N_S))
     = min(N_frag,  (1-δ)/α · (1-q_S)/q_S)
```

```
┌────────────────────────────────────────────────┐
│ R_δ(q) = min(N_frag,  C · (1-q)/q)            │
│                                                │
│ 其中 C = (1-δ)/α ≈ O(1)                       │
└────────────────────────────────────────────────┘
```

### 3.4 物理后果

| q_S | R_δ (C=1) | 物理 |
|-----|-----------|------|
| 1 | 0 | 纯量子——没有经典信息可被环境冗余记录 |
| 1/2 | 1 | 最大混合——恰好一个碎片能完整记录 |
| 1/3 | 2 | — |
| 1/10 | 9 | — |
| 0.01 | 99 | 近经典——大量环境碎片冗余记录 |
| →0 | →∞ | 纯经典——无限冗余（每个碎片都有完整拷贝） |

**关键预言:**

1. **q 越大，冗余度越小。** 这符合直觉: 量子系统（高 q）的信息难以被经典环境冗余记录——因为量子相干性不可克隆（no-cloning theorem 的 DGF 版本: 没有足够的占用细胞来"固化"量子信息的多份拷贝）。

2. **R_δ ∝ (1-q)/q。** 冗余度在 q → 1/2 附近急剧下降，在 q > 1/2 时 R_δ < 1——环境甚至不能从系统提取一个完整拷贝。这是 DGF 对"量子隐私"（quantum privacy）的解释: 量子系统天然具有信息隐私性，因为其大部分容量未被占用，环境无法锁定其状态。

3. **量子 Darwinism 的指针可观察量选择**在 DGF 中对应: 哪些细胞基矢被优先占用。这回到了细胞基优先问题（GAP-S1-1）——框架缺口，诚实标注。

### 3.5 实验方案（方向性）

**思想实验:** 一个中心自旋（系统 S, N_S 个细胞）耦合到 N_frag 个环境自旋（碎片）。通过改变 S 的初始 q_S（例如通过预退相干到不同程度的 mixedness），测量 R_δ 作为 q_S 的函数。

**测量方案:**
1. 准备 S 在不同 q_S 值的态（通过控制退相干时间）
2. 让 S 与环境碎片依次相互作用
3. 对每个碎片做量子态层析（tomography）
4. 计算从每个碎片能推断 S 初态的保真度
5. 统计保真度 > 1-δ 的碎片数量 → R_δ(q_S)

**预言:** R_δ ∝ (1-q_S)/q_S 应在实验中大致成立。偏离可能来自: 碎片间关联（非独立碎片）、有限尺寸效应（N_S, M 小）、耦合不均匀等。

## 方向4: 熵与曲率 —— 引力作为熵梯度力

### 4.1 q 场方程和静态解

DGF 静态场方程:
```
∇²(ln q) = 0
```

球对称解（弱场校准后）:
```
q(r) = e^{-GM/rc²}
```

有效引力加速度（从 DGF 定理 T6）:
```
a(r) = -c² ∇q = -c² · (GM/r²c²) · e^{-GM/rc²} · r̂
     = -(GM/r²) · e^{-GM/rc²} · r̂
```

在弱场极限 r ≫ GM/c²: a(r) ≈ -GM/r²（恢复牛顿引力）。

### 4.2 熵密度分布

von Neumann 熵密度（每个细胞的 S_vN 贡献）:
```
s_vN(r) = s_capacity · [-(1-q(r)) ln(1-q(r)) - q(r) ln q(r)] / ln 2
```

其中 s_capacity = k_B ln 2 / a³ 是容量熵密度（a 是细胞间距）。

在弱场下 q ≈ 1 - GM/rc² ≪ 1，令 ε(r) = GM/rc² ≪ 1:
```
q = e^{-ε} ≈ 1 - ε + ε²/2
1-q ≈ ε
```

```
s_vN(r) ≈ s_capacity · [-(ε) ln ε - (1-ε) ln(1-ε)] / ln 2
```

主导项: -(ε ln ε) / ln 2。在 ε ≪ 1 时，-ln ε ≫ 1，所以:
```
s_vN(r) ≈ s_capacity · ε · |ln ε| / ln 2
        = s_capacity · (GM/rc²) · ln(rc²/GM) / ln 2
```

这是对数发散的——在远处 (r → ∞)，s_vN → 0（因为 q → 1，所有细胞空置）；在近处 (r → 0)，s_vN → s_capacity（因为 q → 0，所有细胞占用，每个贡献 ln 2 熵）。

### 4.3 熵梯度

```
∇s_vN = (ds_vN/dq) · ∇q
```

其中:
```
ds_vN/dq = s_capacity · [-ln(1-q) + ln q] / ln 2
         = s_capacity · ln(q/(1-q)) / ln 2
```

对 q < 1/2（大质量附近）: ln(q/(1-q)) < 0 ⇒ ds_vN/dq < 0。

∇q 方向: q 从中心向外递增（q(0)→0, q(∞)→1），所以 ∇q 沿径向向外。

因此:
```
∇s_vN = (ds_vN/dq) · ∇q  [方向: 径向向内——因为 ds_vN/dq < 0, ∇q 向外]
```

在弱场下 (q ≈ 1, 但 q < 1):
```
ds_vN/dq ≈ s_capacity · ln(q) / ln 2 ≈ s_capacity · (-GM/rc²) / ln 2
∇q ≈ (GM/r²c²) r̂
```

所以:
```
∇s_vN ≈ -s_capacity · (GM/rc²) · (GM/r²c²) · r̂ / ln 2
      = -s_capacity · (G²M² / r³c⁴ ln 2) · r̂
```

方向: 向内（朝向大质量中心）——熵向中心递增。

### 4.4 熵梯度与引力的关系

引力加速度（DGF 定理 T6）:
```
a = -c² ∇q = -c² · (GM/r²c²) · q · r̂ = -(GM/r²) · q · r̂
```

方向: 向内。大小: |a| = GMq/r²。

熵梯度（上面推导）:
```
∇s_vN = (s_capacity/ln 2) · ln(q/(1-q)) · ∇q
```

在 q ≪ 1 极限: ln(q/(1-q)) ≈ ln q = -GM/rc²

此时:
```
∇s_vN = (s_capacity/ln 2) · (-GM/rc²) · (GM/r²c²) · q · r̂
```

而 a = -(GM/r²) · q · r̂。所以:
```
∇s_vN = (s_capacity/ln 2) · (GM/rc²) · (1/c²) · (-a)
      = (s_capacity/ln 2) · (GM/rc⁴) · a
```

或者:
```
a = (ln 2 / s_capacity) · (rc⁴/GM) · ∇s_vN
```

这不够简洁。更好的处理: 使用有效温度 T_eff。

### 4.5 熵梯度力: 热力学类比

在非平衡热力学中，熵梯度驱动扩散流。如果存在一个局域有效温度 T_eff(q)，则熵梯度产生有效力:

```
F_entropic = T_eff · ∇S
```

在 DGF 中，信息流动的驱动力是 surprisal 梯度:
```
J = -κ ∇Φ = -κ ∇(-ln q) = (κ/q) ∇q
```

信息通量 J 携带熵通量 J_S = k_B J。熵产生率:
```
σ_S = J · ∇Φ = (κ/q) |∇q|² ≥ 0
```

这是 DGF 的 H 定理弱形式。

**引力重新表述为熵梯度力:**

设试探粒子的"信息电荷"为 μ（粒子携带的信息量）。试探粒子感受的熵梯度力:

```
F = -μ T_eff ∇s_vN
```

要求这个力等于引力 F = m a = -m (GM/r²) q r̂:

```
m (GM/r²) q = μ T_eff · (ds_vN/dq) · (dq/dr)
```

代入 dq/dr = (GM/r²c²) q 和 ds_vN/dq = (s_capacity/ln 2) ln(q/(1-q)):

```
m (GM/r²) q = μ T_eff · (s_capacity/ln 2) · ln(q/(1-q)) · (GM/r²c²) q
```

消去 (GM/r²) q（两边都有）:
```
m = μ T_eff · (s_capacity/ln 2) · ln(q/(1-q)) / c²
```

解得有效温度:
```
T_eff(q) = m c² / [μ · (s_capacity/ln 2) · ln(q/(1-q))]
```

在弱场 q → 1⁻:
```
ln(q/(1-q)) ≈ ln(1/(1-q)) ≈ -ln(GM/rc²)
```

T_eff → 0（对数发散——但在弱场下 q 接近 1，温度趋于零，符合真空是冷的直觉）。

在强场 q → 0⁺:
```
ln(q/(1-q)) ≈ ln q → -∞
```

T_eff → 0（又一个对数发散——但方向相反）。在中间某个 q 值 T_eff 有最大值。

### 4.6 熵力 vs 几何引力

**DGF 熵力图像:**
- 引力不是时空几何的后果——而是信息熵梯度的表现
- 物质（高信息密度，低 q）创造熵梯度
- 试探粒子沿熵梯度"滑落"——从低熵区滑向高熵区
- 这类似于 Verlinde (2011) 的熵重力，但起源不同: Verlinde 从全息屏上的熵变推出牛顿定律，DGF 从局域 q 场的 surprisal 梯度推出

**DGF vs Verlinde 的熵引力:**

| 特征 | Verlinde (2011) | DGF (本文) |
|------|----------------|-----------|
| 熵的来源 | 全息屏上的纠缠熵 | 局域细胞的 S_vN(q) |
| 力的推导 | ΔS ∝ Δx → F = T ΔS/Δx | J = -κ∇Φ, a = -c²∇q |
| 全息假设 | 核心输入 | 非必须（但兼容） |
| 温度 | Unruh 温度 | T_eff(q) 由信息摩擦定义 |
| 自由度 | 面积 ∝ 边界自由度 | 体积 ∝ 细胞数 |

**DGF 的优势:**
- 不需要预设全息屏——熵在体元中有局域定义
- q 场的动力学方程（虽然是现象学的）描述熵如何随时间演化
- 引力加速度直接由 q 场梯度给出: a = -c²∇q

**DGF 的劣势:**
- T_eff 的物理意义不明确——是真正可测量的温度还是形式参数？
- 在 q → 1（真空）极限，T_eff → 0，熵力 → 0——如何解释真空中的引力透镜？
  - **解答**: 真空不是严格的 q=1——远处试探粒子自身也有质量（q < 1），它改变了局域 q 场
  - 但这一论证需要细化

### 4.7 一个与 GR 可区分的预言

在 DGF 的熵引力图像中，引力加速度:

```
a_DGF(r) = -(GM/r²) · e^{-GM/rc²}
```

而 GR（牛顿极限）:
```
a_GR(r) = -GM/r²
```

在 r = GM/c² 处:
- a_DGF = -(GM/r²) · e^{-1} ≈ -0.368 GM/r²
- a_GR = -GM/r²

差异因子 = e^{-GM/rc²}。在中子星表面（GM/Rc² ≈ 0.21）: 差异约 19%。这比弱场修正大得多——可能在脉冲星双星轨道衰变中产生可观测效应。

但需要先解决 DGF 的两体问题（双星动力学在 DGF 中的描述）——当前框架缺口。
