## 0. 前置说明：公平对比框架

在进入具体计算之前，必须澄清A博士S1文档中一个INSPECTOR标记的框架性问题（INSPECTOR W2/R2）。

### 0.1 封闭系统 vs 开放系统

A博士S1 §6.3将DGF的"封闭系统均衡"与Lindblad的"开放系统稳态"直接对比，声称"零温零参数差异"。这是不公平的对比。

| 对比层级 | DGF | 标准QM |
|---------|-----|--------|
| 封闭系统（qubit + 腔，无外部浴） | P(\|e⟩)均衡极限 = 1/(N_E+1) | 同样非零（Rabi振荡，时间平均 ~N_S/(N_S+N_E)） |
| 开放系统（+外部浴，T→0） | **未明确给出** | P(\|e⟩) ~ n_th = exp(-ħω/kT) → 0 |

公平对比的正确框架：
- **在封闭系统层面**：DGF和标准QM预测的P(\|e⟩)在均衡极限下**趋同**而非分歧。两者都预测总激发数K守恒时，qubit激发概率与有效态空间大小成反比。这不是"零参数差异"——这是"理论在封闭系统层面等价"。
- **若DGF要做出独立于标准QM的预测**：必须明确DGF如何处理与外部热浴的耦合（即"开放系统DGF"）。当前A1+A2框架仅处理封闭有限系统。开放系统的信息论描述尚未建立。

### 0.2 本文的范围

鉴于此框架限制，本文的定量预测分为两个层级：

**层级L1**（封闭系统，数学严格）: 在DGF细胞模型内部，给定N_S, N_E, q_S, q_E, δ, T，计算P_reflux的数值上界。这些数字在DGF模型内部是精确的（给定UMP假设）。

**层级L2**（实验对接，需要额外假设）: 将L1的数值映射到实际电路QED实验的可观测量。此映射依赖GAP-S1-2（N_S/N_E的物理估计）的解决程度。

本文诚实标注每个层级的不确定性。

## 2. N_S 和 N_E 的估计 — 多方案诚实对照

### 2.1 N_S 的估计

**系统**: 单个transmon qubit，取前两个能级 |g⟩, |e⟩。

| 方案 | 方法 | N_S | 确定性 |
|------|------|-----|--------|
| **S-I**（信息论） | N_S = log₂(d_S), d_S=2 | **1 bit** | 高（给定基选择前提） |
| **S-II**（三能级） | 包含 |f⟩: d_S=3 | **1.585 bit** | 中（|f⟩泄露是已知误差源） |
| **S-III**（连续） | Transmon连续谱，有效d_S ~ EJ/EC = 58 → log₂(58) | **5.86 bit** | 低（高能级在低温下不被布居） |

**选择**: 本文采用 **N_S = 1**（方案S-I）。理由：(1) 实验中qubit操作限定在{|g⟩,|e⟩}子空间，(2) 低温下|f⟩布居可忽略(<10^(-3))，(3) 此选择给出最保守（最可区分）的DGF预测。

### 2.2 N_E 的估计 — 多方案

这是GAP-S1-2的核心。不同方案给出的N_E可能差数个数量级。

#### 方案E-I：多qubit阵列（提案2 — 精确已知）

每个环境qubit = 1个二元细胞。若制备K=1总激发的W态（单激发均匀分布在所有qubit上）：

$$N_E = \text{（环境qubit数）} = 5, 10, 20, 50, 100$$

| N_E | P(\|e⟩) = 1/(1+N_E) | 备注 |
|-----|---------------------|------|
| 1 | 50% | 单腔模等效 |
| 10 | 9.1% | 当前商用芯片可实现 |
| 30 | 3.2% | 接近最优区分窗口 |
| 100 | 0.99% | 需中等规模芯片 |
| 300 | 0.33% | 接近残余激发本底 |
| 1000 | 0.10% | 与quasiparticle本底不可区分 |

**不确定性**: 低（如果qubit可编程）。N_E精确已知。

**诚实注**: 此方案从DGF的"细胞"抽象直接映射到物理qubit，回避了"连续模→离散细胞"的映射困难。但代价是：环境不是"自然的"谐振腔，而是一个与系统同质的人造qubit阵列。审稿人可能质疑："DGF的自然环境是qubit阵列？这和热力学环境有何关系？"

#### 方案E-II：单腔模Fock态（Jin et al.基准）

腔的Fock态 |n⟩构成环境态空间。在dispersive极限下，腔的有效希尔伯特空间截断于n_crit。

$$N_E^{\text{Fock}} = \log_2(n_{\text{max}} + 1)$$

| n_max 估计方法 | 值 | N_E |
|----------------|-----|-----|
| 临界光子数 n_crit = Δ²/(4g²) | 352 | **8.5** |
| Dispersive shift分辨率: n_max·χ > κ | ≈ 25 | **4.7** |
| 热光子数 n_th(15 mK) | ≈ 0 | **0** |

**问题**: 此方案将N_E定义为比特数，但腔是一个多能级系统（d-level而非2-level）。将d-level系统映射到log₂(d)个二元细胞在信息论上是标准的，但在DGF的"占用/未占用"框架下，Fock态|n⟩是对应的"占用n个细胞"还是"1个细胞的第n个状态"？这是GAP-S1-2的结构性模糊。

**对K=1守恒情况**: 单激发只能在qubit(|e⟩)和腔的|1⟩态之间分配。即使腔有100个Fock态，K=1只涉及其中1个。因此：
$$N_E^{\text{eff}}(K=1) = 1$$

这一结论意味着单模腔+单qubit实验中，**无法区分DGF与标准QM**（两者都预测P(|e⟩)时间平均≈50%）。

#### 方案E-III：多模腔 + 时间-带宽积

考虑多模环境（传输线、Purcell滤波器、宽带腔）。在时间T内，带宽B的连续谱可以分辨出~BT个独立频率bin。每个bin是一个可区分的"信息槽"。

$$N_E \approx B_{\text{eff}} \times T_{\text{obs}}$$

| 物理实现 | B_eff | T_obs | N_E |
|---------|--------|-------|-----|
| Purcell滤波器 (10 MHz) + qubit T1 (80 μs) | 10 MHz | 80 μs | **800** |
| Purcell滤波器 (50 MHz) + qubit T1 (80 μs) | 50 MHz | 80 μs | **4,000** |
| 宽带传输线 (1 GHz, 弱耦合) | 1 GHz | 80 μs | **80,000** |
| 高品质Purcell滤波器 (1 MHz) | 1 MHz | 80 μs | **80** |

**不确定性**: 高。带宽B_eff的选取依赖于耦合强度g(ω)的频率依赖和Purcell速率。T_obs的选取（是T1、T2、还是整个实验序列的时间？）也影响结果。

#### 方案E-IV：信息论推广 — 量子信道容量

环境作为量子信道，其经典信息容量为：
$$C = \max_{p_i, \rho_i} \left[ S\left(\sum_i p_i \mathcal{E}(\rho_i)\right) - \sum_i p_i S(\mathcal{E}(\rho_i)) \right]$$

对于纯损耗信道（腔+外部浴），容量C给出了N_E的上界。在零温极限下：
- 纯损耗信道的经典容量 ~ g_0 τ n_th(ω, T) [热光子数限制]，在T→0时 → 0
- 量子容量 ~ max(0, log₂(η/(1-η))) [由透射率η决定]

这一估计与热力学一致但在信息论层面揭示了DGF面临的根本困难：**环境在T=0时对系统可传输的经典信息为0**（因为真空态不携带可通过局域测量获取的比特）。如果N_E ≈ 0（按此估计），则DGF预测P_reflux应很大（1/(0+1)=100%），这显然是错误的。

**方案E-IV暴露了DGF的核心模糊性**: N_E是"容量的度量"还是"当前占用状态的度量"？如果N_E = 0表示环境完全"满"（无空余容量），则P_reflux应→0（根据S1定理q_E→0的回流抑制）。但T=0的真空态是"全空"的（q_E≈1按"激发数"度量）——两种度量给出相反的结果。

#### 方案汇总与推荐

| 方案 | N_E范围 | 不确定性 | 可控性 | 推荐用途 |
|------|---------|---------|--------|---------|
| E-I (qubit阵列) | 1–1000 | 极低 | 高 | **主要定量预测** |
| E-II (单模Fock) | 0–8.5 | 高 | 低 | 对比参考 |
| E-III (带宽积) | 80–80,000 | 高 | 中 | 量级估算 |
| E-IV (信道容量) | ~0 (T→0) | 极高 | 无 | 概念检验 |

**本文采用**: 以E-I为主要计算方案（N_E = 5–300），以E-III为物理实现参考。

## 3. P_reflux 数值预测

### 3.1 情形A（总激发数守恒，K=1）

**物理场景**: 系统（transmon） + 环境（N_E个qubit），总激发数K=1守恒。初始态：transmon在|e⟩，所有环境qubit在|g⟩ → k(0)=1, q_S(0)=0, q_E(0)=1。

#### 3.1.1 平稳分布

超几何分布，N_S=1, K=1：

$$P_{\text{eq}}(\text{|e⟩}) = \frac{C(1,1) \cdot C(N_E, 0)}{C(1+N_E, 1)} = \frac{1}{N_E + 1}$$

$$P_{\text{eq}}(\text{|g⟩}) = \frac{N_E}{N_E + 1}$$

#### 3.1.2 单步回流上界

从k=0 (|g⟩) 单步跃迁到k=1 (|e⟩) 的组合硬上界（不需要UMP）：

$$P(k=0 \to k=1) \leq \frac{|M_1^{(K)}|}{|M_0^{(K)}|} = \frac{C(1,1) \cdot C(N_E, 0)}{C(1,0) \cdot C(N_E, 1)} = \frac{1}{N_E}$$

#### 3.1.3 有限时间回流上界

在时间T内（以系统特征时间为单位），至少发生一次回流的上界：

$$P_{\text{reflux}}(\delta=1, T) \leq T \cdot \frac{1}{N_E}$$

当T较大时（超过混合时间），更紧的界由平稳分布直接给出：

$$P_{\text{reflux}}(\delta=1, T \gg \tau_{\text{mix}}) \approx 1 - \left(\frac{N_E}{N_E+1}\right)^{T/\tau_{\text{step}}}$$

其中τ_step ~ 1/g_eff是系统-环境耦合的特征时间。

#### 3.1.4 数值表（按N_E）

以N_S=1, K=1, δ=1, T对应实验观测窗口~

| N_E | P_eq(|e⟩) | P(0→1单步) ≤ | P_reflux(1, T=10³步) ≤ | DGF预测的观测值 |
|-----|-----------|--------------|----------------------|-----------------|
| 1 | 50% | 1.0 (平凡) | 1.0 (平凡) | 不可区分 |
| 5 | 16.7% | 0.20 | 1.0 (平凡) | 弱约束 |
| 10 | 9.1% | 0.10 | 1.0 (平凡) | 弱约束 |
| 30 | 3.23% | 0.033 | 1.0 (平凡, T=10³太大) | 需更长观测 |
| 50 | 1.96% | 0.020 | 1.0 (平凡, T=10³) | |
| 100 | 0.99% | 0.010 | ≈ 0.63 (T=100步) | **最优窗口** |
| 200 | 0.498% | 0.0050 | ≈ 0.39 (T=100) | |
| 300 | 0.332% | 0.0033 | ≈ 0.28 (T=100) | **接近本底** |
| 500 | 0.200% | 0.0020 | ≈ 0.18 (T=100) | 需大量重复 |
| 1000 | 0.0999% | 0.0010 | ≈ 0.095 (T=100) | 与准粒子本底平齐 |

**关键数值**: 
- N_E = 100: DGF预测P(|e⟩) ≈ 1.0%（均衡值），Lindblad预测P(|e⟩) ≈ 0.1%（残余准粒子本底）。差异≈10×。
- N_E = 300: DGF预测P(|e⟩) ≈ 0.33%，Lindblad≈0.1%。差异≈3.3×。

#### 3.1.5 情形A的回流抑制因子

使用A博士主不等式的容量比形式（§3.4, 组合硬界）：

$$P_{\text{reflux}} \leq T \cdot \left(\frac{q_S}{1-q_S}\right)^\delta \cdot \left(\frac{1-q_E}{q_E}\right)^\delta$$

对初始态 |g⟩ (k=0): q_S(0) = (1-0)/1 = 1。

等等——这给出了发散。因为k=0意味着q_S=1（系统全空），(q_S/(1-q_S))^1 → 1/0 → ∞。这是INSPECTOR验证5标记的**平凡界区间**。

**更正后的计算**: 使用宏态比值的精确组合形式，而非连续近似：

$$P(k=0 \to k=1) \leq \frac{C(1,1)}{C(1,0)} \cdot \frac{C(N_E, K-1)}{C(N_E, K)} = 1 \cdot \frac{C(N_E, K-1)}{C(N_E, K)}$$

对K=1:
$$= \frac{C(N_E, 0)}{C(N_E, 1)} = \frac{1}{N_E} \quad \checkmark$$

对K=2 (初始k=0, m=2... 但q_S=1仍然导致近似发散):
$$= \frac{C(N_E, 1)}{C(N_E, 2)} = \frac{N_E}{N_E(N_E-1)/2} = \frac{2}{N_E-1}$$

**教训**: A博士的(q_S/(1-q_S))^δ近似在q_S→1时退化，需回退到精确组合公式。这是INSPECTOR W1的内容，本文通过直接使用组合公式避免此问题。

### 3.2 情形B（总激发数不守恒）

对N_S=1, 无A3约束:

平稳分布（二项分布Bin(1, 1/2)）:
$$P_{\text{eq}}(\text{|e⟩}) = 1/2$$
$$P_{\text{eq}}(\text{|g⟩}) = 1/2$$

单步回流概率（从|g⟩到|e⟩）在期望下: **50%**。

这是平凡结果——与标准理论、与任何合理的双态系统模型一致。情形B对单qubit不产生任何可检验的预测。

**情形B在N_S≫1时才非平凡**（见A博士S1 §4.2数值案例: N_S=100时完全回流P≤10^(-22)）。

### 3.3 标准理论的对应预测

#### 3.3.1 零温Lindblad主方程

对于qubit-腔耦合系统，标准Lindblad主方程（零温极限，T=0）：

$$\frac{d\rho}{dt} = -i[H, \rho] + \kappa \mathcal{D}[a]\rho + \gamma_1 \mathcal{D}[\sigma_-]\rho$$

其中 $\mathcal{D}[L]\rho = L\rho L^\dagger - \frac{1}{2}\{L^\dagger L, \rho\}$。

在T=0时，涨落-耗散定理确保：
- 从|g⟩→|e⟩的自发激发率 = 0（没有热光子吸收）
- 稳态: ρ_ss = |g,0⟩⟨g,0|（qubit在基态，腔在真空）

$$P_{\text{reflux}}^{\text{Lindblad}}(T=0) = 0 \quad \text{（严格）}$$

#### 3.3.2 有限温度Lindblad

在温度T>0时，热激发概率：
$$P_{\text{th}}(\text{|e⟩}) = \frac{1}{\exp(\hbar\omega_q/k_B T) + 1}$$

| 温度T | kT/h (GHz) | P_th(|e⟩) (ω_q=4.97 GHz) |
|--------|------------|---------------------------|
| 15 mK | 0.313 | **1.3 × 10^(-7)** (= 0.000013%) |
| 35 mK | 0.729 | **1.1 × 10^(-3)** (= 0.11%) |
| 50 mK | 1.042 | **8.4 × 10^(-3)** (= 0.84%) |
| 100 mK | 2.084 | **8.5 × 10^(-2)** (= 8.5%) |
| 150 mK | 3.125 | **1.7 × 10^(-1)** (= 17%) |

#### 3.3.3 实测残余激发（非热平衡）

Jin et al. (2015)的残余激发**不是热平衡的**——它是非平衡准粒子效应：
$$P_{\text{res}}(\text{|e⟩}) \approx 0.1\% = 10^{-3}$$

这一本底在所有温度T < 35 mK下饱和，**不随温度进一步降低而减少**（只要准粒子存在）。

## 4. DGF vs 标准理论: 可区分性分析

### 4.1 可区分窗口

DGF的独特预测是在**零温极限**下，即使环境严格处于真空（T=0, 无热光子），也存在残留回流概率：

$$P_{\text{reflux}}^{\text{DGF}} \approx \frac{1}{N_E+1} \quad \text{（封闭系统均衡）}$$

而标准QM在开放系统T=0极限下给出：

$$P_{\text{reflux}}^{\text{Lindblad}} \approx 0 \quad \text{（无热光子）}$$

**但实践中**，由于非平衡准粒子产生~0.1%的残余激发本底，DGF的预测只有在此本底之上（即1/(N_E+1) > 0.1% → N_E < 1000）时才能被区分。

### 4.2 统计显著性需求

| N_E | DGF P(|e⟩) | Lindblad+本底 P(|e⟩) | 差异 ΔP | 所需重复数N (3σ) | 实验时间 (100 μs/次) |
|-----|-----------|---------------------|---------|-----------------|---------------------|
| 30 | 3.23% | 0.1% | 3.13 pp | 9.2×10³ | 0.9 秒 |
| 50 | 1.96% | 0.1% | 1.86 pp | 2.6×10⁴ | 2.6 秒 |
| 100 | 0.99% | 0.1% | 0.89 pp | 1.1×10⁵ | 11 秒 |
| 200 | 0.498% | 0.1% | 0.40 pp | 5.6×10⁵ | 56 秒 |
| 300 | 0.332% | 0.1% | 0.23 pp | 1.7×10⁶ | 170 秒 |
| 500 | 0.200% | 0.1% | 0.10 pp | 9.0×10⁶ | 15 分钟 |
| 1000 | 0.100% | 0.1% | 0 | 不可区分 | — |

> 重复数公式: N = (Z_α/ΔP)² · P(1-P) 其中 Z_0.00135 = 3 (单侧3σ), P取DGF预测值。这是保守估计，实际可能需要更多重复以消除系统误差。

**最优N_E = 30–200**，在这个区间：
- DGF预测P(|e⟩) = 0.5–3.2%
- 与Lindblad+准粒子本底的差异 = 0.2–3.1 pp
- 所需重复数: 10³–10⁶
- 实验时间: 秒到分钟量级
- **完全在当前技术能力范围内**

### 4.3 核心不可区分性问题（必须诚实面对）

**在公平对比框架（§0.1）下，上述"可区分性"分析存在根本缺陷**:

1. **封闭系统层面**: DGF的P(|e⟩) = 1/(N_E+1)是封闭系统均衡预测。标准QM在同样封闭系统（qubit + N_E个qubit，幺正演化）中也预测P(|e⟩)在长时间平均下 ≈ 1/(N_E+1)（等先验概率的热化假设/典型性）。两者在封闭系统层面**预测相同**。

2. **开放系统层面**: DGF**没有**开放系统理论。当前A1+A2框架仅处理有限封闭系统（|X|=2^N有限→f是双射→纯幺正演化）。要处理开放系统，需要：
   - 将外部浴纳入细胞模型（"超级环境"），或
   - 引入粗粒化/部分求迹操作（这超出了A1+A2公理体系）

3. **因此**: 任何声称"circuit QED实验可以区分DGF与标准QM"的陈述目前缺乏理论基础。DGF**尚未达到**能做出开放系统预测的阶段。

**这是INSPECTOR R2的完整含义**: "零温差异声称"应修正为"在DGF细胞模型内部，封闭系统均衡给出P(|e⟩)≈1/N_E，但此预测在公平的QM封闭系统框架下不构成零参数差异。实验区分需要明确DGF的开放系统理论，当前未建立。"

### A.1 封闭系统均衡分布（情形A, K守恒）

```python
import numpy as np
from scipy.special import comb

def equilibrium_P_e_hypergeometric(N_S, N_E, K):
    """超几何分布: P(系统占用=k) = C(N_S,k)·C(N_E,K−k)/C(N_S+N_E,K)"""
    k_vals = np.arange(max(0, K-N_E), min(N_S, K) + 1)
    probs = np.array([comb(N_S, k) * comb(N_E, K-k) for k in k_vals])
    probs /= comb(N_S + N_E, K)
    return k_vals, probs

def P_reflux_bound_step_A(N_S, N_E, K, k_from, delta):
    """情形A单步回流组合硬上界 (不需要UMP)"""
    k_to = k_from + delta
    if k_to > min(N_S, K):
        return 0.0
    # 组合硬界: |M_{k'}^{(K)}| / |M_k^{(K)}|
    numerator = comb(N_S, k_to) * comb(N_E, K - k_to)
    denominator = comb(N_S, k_from) * comb(N_E, K - k_from)
    return min(1.0, numerator / denominator)

# 示例: N_S=1, K=1, 从k=0到k=1
for N_E in [5, 10, 30, 100, 300, 1000]:
    k_vals, peq = equilibrium_P_e_hypergeometric(1, N_E, 1)
    p_bound = P_reflux_bound_step_A(1, N_E, 1, 0, 1)
    print(f"N_E={N_E:4d}: P_eq(|e⟩)={peq[1]:.4f}, P(0→1)≤{p_bound:.4f}")
```

### A.2 有限时间回流概率

```python
def P_reflux_finite_time(N_E, T_steps, delta=1):
    """情形A有限时间回流概率 (联合界)"""
    p_step_max = P_reflux_bound_step_A(1, N_E, 1, 0, delta)
    # 联合界
    p_union = min(1.0, T_steps * p_step_max)
    # 更紧的估计: 独立伯努利近似 (仅当T超过混合时间后成立)
    p_eq_e = 1.0 / (N_E + 1)  # 平稳下k=1的概率
    p_independent = 1.0 - (1.0 - p_eq_e)**T_steps
    return p_union, p_independent

# 示例: N_E=100, 不同T
for T in [10, 30, 100, 300, 1000]:
    pu, pi = P_reflux_finite_time(100, T)
    print(f"T={T:4d}步: P_union≤{pu:.3f}, P_independent≈{pi:.3e}")
```

### A.3 统计显著性计算

```python
def required_repetitions(p_dgf, p_null, sigma=3.0):
    """所需重复数以达到sigma显著性 (单侧Z检验)"""
    from scipy.stats import norm
    delta = p_dgf - p_null
    if delta <= 0:
        return float('inf')
    # Z = (p̂ - p_null) / sqrt(p_null*(1-p_null)/N)
    # For detection: N = (Z_alpha * sqrt(p_null*(1-p_null)) / delta)^2
    # Conservative: use p_dgf variance
    z_alpha = norm.ppf(1 - 2*norm.cdf(-sigma))  # two-sided equivalent
    # Delta method variance
    var_null = p_null * (1 - p_null)
    var_dgf = p_dgf * (1 - p_dgf)
    # Use larger variance for conservative estimate
    var = max(var_null, var_dgf)
    N = (z_alpha**2 * var) / (delta**2)
    return int(np.ceil(N))
```
