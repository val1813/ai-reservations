## 0. 开场：为什么这个问题值得诚实对待

LP31-InfoCapacity框架区分于标准量子力学的最尖锐差异点在于：

> **标准QM**: 完美隔离的系统永远幺正、永远量子。
> **DGF**: 即使完美隔离，如果系统有内部信息积累（历史记录填满细胞），q必然随时间下降，系统必然自发走向经典。

这是框架最激进的预言——也是最有区分度的。如果对，量子力学需要修正。如果错，DGF被干净地排除。

本文试图做两件事：(1) 尽可能地构建能实现这一预言的模型，(2) 诚实评估每个模型需要多少超出A1+A2的假设。

**提前坦白结论**: 在不引入显著额外假设的条件下，A1+A2**不能**推出隔离系统中的q→0。最有力的论证只能将q从1降到~1/2（从特殊初始条件弛豫到典型态），这与已知的量子多体热化（ETH）等价。要让q降到0，需要当前框架之外的物理输入。

这不是说DGF错了。这说的是："隔离自发经典化"不是A1+A2的定理——它是一个需要额外假设且目前缺乏实验支持的假说。诚实标注这一点比勉强构造一个看似成立的论证更有价值。

## 1. 问题形式化

### 1.1 隔离信息系统的定义

**隔离系统** S = (X, f) 满足：

1. **A1 (可区分性)**: f: X → X 是单射。
2. **A2 (容量有界)**: X = {0,1}^N，|X| = 2^N < ∞。
3. **隔离条件**: 没有外部细胞。S是自包含的——没有环境E与之交换信息。
4. **非平凡内部动力学**: f ≠ id（恒等映射）。系统内部有信息处理。

**关键推论（定理1a）**: 由A1+A2，f是X上的双射（置换）。

**宏观变量**:
```
q(s) = (N - Σ_i s_i) / N    (空闲细胞比例)
```

### 1.2 核心张力

T1e已经证明：A1+A2不能推出Σs_i守恒。所以在隔离系统中，q可以变化（不需要环境来改变占用数）。

但T1e也展示了：在N=2的四循环f下，占用数序列是0→1→1→2→0——q先降后升。这不是单调递减。

**根本问题**: 在双射f下，每条轨道都是闭合循环。轨道上q的时间平均等于轨道上所有状态q的等权平均。如果轨道覆盖X的相当部分（典型情况），长时间平均q=1/2（因Stirling近似——X中多数状态占用数为N/2）。

**在双射f下，q(t)→0在严格意义上是不可能的（Poincaré回复）。在概率意义上，它要求轨道将绝大部分时间花在低q态上——这需要对f的强烈约束。**

## 2. 三个候选模型

### 2.1 模型M1: 关联压缩（Correlation-Compression）—— 【最推荐的DGF特有机制】

#### 核心洞察

即使总占用Σs_i不变，**有效q也可以下降**——不是通过增加占用，而是通过产生细胞间的关联。两个完全关联的细胞只贡献1 bit的有效容量（而非2 bit）。内部信息处理产生关联→压缩有效容量→q_eff下降。

#### 形式定义

**物理细胞**: N个二元细胞。总占用可能守恒（A3成立）也可能不守恒。

**有效独立细胞数**:
```
N_eff = (可区分的正交状态数的对数) / log 2
```

在无关联的N细胞系统中，可区分状态数=2^N，N_eff=N。在全关联系统中，细胞状态完全由彼此决定：一个细胞的状态完全确定了所有其他细胞——可区分状态数只有2，N_eff=1。

**有效q**:
```
q_eff = 1 - N_eff/N
```

关联负荷（互信息总和）压缩有效容量:
```
N_eff ≈ N - (1/log 2) Σ_{i<j} I_ij    (弱关联近似)
```

其中I_ij = S(ρ_i) + S(ρ_j) - S(ρ_ij) 是细胞i,j之间的量子互信息。

#### 动力学机制

**步骤1**: 初始时，k个细胞被占用（|1⟩），N-k个空闲（|0⟩）。所有细胞相互独立。Σs_i=k, q=1-k/N, q_eff=q≈1。

**步骤2**: 内部动力学f作用于细胞对(i,j)。如果s_i≠s_j，相互作用可以产生关联。例如，局部幺正门（如CNOT + 单比特旋转）纠缠两个细胞。它们的约化态变为混合态，但联合态仍是纯的（系统总体仍是纯态）。

**步骤3**: 关联一旦产生，两个细胞的联合信息容量从2 bits降低到S(ρ_ij)/log 2 + I_ij < 2 bits（对于纠缠态可以降到1 bit——一对方共享一个ebit）。N_eff下降→q_eff下降。即使Σs_i不变。

**步骤4**: 随着更多细胞对之间产生关联，q_eff持续下降。极限q_eff→0对应所有N个细胞完全相互关联——整个系统的宏观状态完全锁定，只有一个宏观自由度。

**关键**: 关联产生不需要环境。f是双射（在X上），所以微观可逆性保持——但宏观上，关联一旦遍布系统，它们被"加密"在全局纠缠结构中，单个细胞（或少数细胞）的测量无法检测到它们。这就是为什么q_eff对局部观察者表现为下降。

#### q_eff单调性

**M1-T1（条件性单调递减）**: 若关联产生速率γ_c超过关联撤销速率γ_d，则q_eff(t)非递增。

论证：
1. 关联I_ij的rate equation: dI_ij/dt = γ_c(1 - I_ij) - γ_d I_ij。
2. 初始I_ij≈0 → dI_ij/dt ≈ γ_c > 0（关联增长）。
3. 稳态I_ij = γ_c/(γ_c + γ_d)。当γ_c ≫ γ_d时，I_ij→1。
4. q_eff = 1 - (1/N)[N - (1/log 2)ΣI_ij] = (1/(N log 2))ΣI_ij。初始q_eff≈0，极限q_eff → 1/(log 2)（如果ΣI_ij → N log 2) → 可以接近0。

**但**: rate equation是现象学的。γ_c和γ_d如何从f中导出？对于一般的生物射f，没有理由认为γ_c > γ_d。实际上，f^{-1}也是合法动力学，且其γ_c(f^{-1}) = γ_d(f), γ_d(f^{-1}) = γ_c(f)。

**为什么γ_c > γ_d可能"典型地"成立**: 类似于第二定律的论证。如果初始态是特殊的（无关联），且大多数状态有关联（高关联宏观态有更大的态空间体积），那么即使f是随机的，系统也倾向于从低关联态移向高关联态。这在T2c中已经论证过——期望转移矩阵的双随机性意味着系统向体积最大的宏观态演化。

**但这里有一个关键不同**: 对于占用数q，最大体积的宏观态在q=1/2。对于关联，最大体积的"宏观态"（给定关联结构的态）在哪？我们需要定义关联结构的粗粒化。

#### 关联的粗粒化

定义"关联剖面" C = (c_2, c_3, ..., c_N)，其中c_k = 涉及k个细胞的k体关联的平均强度。

宏观态体积Ω(C) = 给定关联剖面C的微观状态数。计算Ω(C)是非平凡的——这是量子信息几何中的一个开放问题。

**猜想**: 对于大多数自然的多体动力学，高关联剖面有更大的态空间体积（因为有更多的方式组织关联）。如果此猜想成立，则体积效应驱动系统向高关联态演化，类似于热力学第二定律。

**诚实标注**: GAP-M1.1。此猜想未被证明。关联的态空间几何远比占用数的组合数学复杂。没有已知的定理保证"关联单调增加"——即使在统计意义上。

#### 经典化时间标度

```
τ_classical ∝ N / (c · η · ω_0)
```

- N: 总细胞数
- c: 每个细胞的相互作用邻居数（c=2对于1D链，c~N对于全连接）
- η: 每次相互作用产生净关联的效率（0<η≤1）
- ω_0: 基本相互作用频率

**标度假定**:
- 需要产生~N个关联来将N_eff从N降到O(1)
- 每步产生~c·η个关联
- 总步数~N/(c·η)
- τ_classical = (步数) / ω_0 = N/(c·η·ω_0)

**极限行为**:
- **局域相互作用(c~O(1))**: τ_classical ∝ N。大系统经典化慢——与直觉相反。
- **全连接(c~N)**: τ_classical ∝ 1/η。与N无关——全连接系统几乎瞬间经典化。
- **宏观物体(c~O(1), N~10^23)**: τ_classical ~ 10^23 / ω_0。对于ω_0~10^15 Hz（光学声子），τ~10^8 s ~ 3年。这太慢了——宏观物体在远短于此的时间内就显得经典。→ 暗示环境退相干对宏观物体仍然不可替代。

### 2.2 模型M2: 内部退相干（ETH）—— 【物理上最稳固的非DGF机制】

#### 核心洞察

量子统计力学已有一个成熟机制解释隔离系统中的"自发"退相干：**特征态热化假说（ETH）**。多体量子系统在自身幺正动力学下，粗粒化观测量的非对角元衰减（退相干），对角元趋向微正则系综值。这是标准量子力学的内部效应——不需要修改QM，不需要新公理。

DGF的q可以映射为粗粒化量子性的度量——但机制是完全标准的多体量子物理。

#### 形式设置

**系统**: N个相互作用qubit（自旋-1/2），Hamiltonian:
```
H = Σ_i (h_i/2) σ^z_i + Σ_{i<j} J_{ij} (σ^x_i σ^x_j + σ^y_i σ^y_j + σ^z_i σ^z_j)
```
局域场h_i可存在无序。

**初始态**: |ψ(0)⟩ = ⊗_i |0⟩_i。所有细胞在|0⟩（空闲）。q=1。

**动力学**: |ψ(t)⟩ = e^{-iHt} |ψ(0)⟩。严格幺正（量子版A1+A2）。

**观测**: 单细胞相干性 ⟨σ^x_i(t)⟩ 和占用数 ⟨n_i(t)⟩ = ⟨(1+σ^z_i)/2⟩。

#### ETH机制

在能量本征基{|E_α⟩}中:
```
|ψ(t)⟩ = Σ_α c_α e^{-iE_α t} |E_α⟩

⟨σ^x_i(t)⟩ = Σ_{α,β} c_α* c_β e^{-i(E_β-E_α)t} ⟨E_α|σ^x_i|E_β⟩
```

ETH的核心假设（Deutsch 1991, Srednicki 1994）:
1. **对角ETH**: ⟨E_α|σ^x_i|E_α⟩ ≈ σ^x_i(E_α) — 能量本征态期望值是能量的光滑函数，等于微正则系综平均值。
2. **非对角ETH**: ⟨E_α|σ^x_i|E_β⟩ ∝ e^{-S(E)/2} f(E, ω) R_{αβ} — 非对角矩阵元指数小（被态密度抑制），且有随机相位。

**结果**: 长时间平均:
```
⟨σ^x_i⟩_∞ = Σ_α |c_α|² σ^x_i(E_α) ≈ σ^x_i_mc(⟨E⟩)
```

由于初始态|00...0⟩是σ^z_i的本征态（σ^x_i的等权叠加），σ^x_i_mc通常很小（在有限温度下热涨落使σ^x_i平均→0）。粗粒化观测器的"有效q"下降。

#### q_eq的值

初始态|00...0⟩的能量: ⟨E⟩ = -Σ_i h_i/2。

在温度T（由⟨E⟩通过E(T)=⟨E⟩决定）下:
```
⟨n_i⟩_T = 1/(1 + e^{h_i/k_B T})
```

对于h_i > 0（|0⟩是基态），在T>0时⟨n_i⟩_T < 1/2。q_eq = 1 - ⟨⟨n_i⟩⟩ > 1/2。

**要让q_eq接近0，需要h_i < 0（|1⟩是基态）或T很大**。无论哪种情况，q_eq由Hamiltonian的参数决定，而非由A1+A2的纯信息结构决定。

**关键局限**: 能量结构（Hamiltonian）决定了q_eq。纯信息框架（A1+A2）中没有能量——所以M2中的经典化程度由超出DGF公理的物理量决定。这与DGF"从信息推出经典性"的承诺存在张力。

#### 经典化时间标度

```
τ_classical ∝ ħ / J_eff · g(N)
```

其中g(N)是输运标度函数:
- g(N) ~ N²: 扩散输运（无序系统中的热化）
- g(N) ~ N: 弹道输运（干净系统中的热化）
- g(N) → ∞: 多体局域（MBL）——永不热化

**典型值**:
- N=10 qubits, J~1 MHz: τ ~ 1-100 μs
- N=100 qubits, J~1 MHz: τ ~ 100 ns - 10 ms
- MBL系统: τ → ∞

#### 与DGF的关系

M2（ETH机制）完全在标准量子力学框架内。不需要新公理、不需要修改量子力学。它是DGF自发经典化的一个具体物理实现——但悖论的是，这个"实现"恰恰证明了"隔离自发经典化"不需要DGF框架也完全可以是标准QM的现象。

**DGF的独特贡献——如果有的话——是将ETH热化解释为"信息容量耗尽"，即用q的语言重述了多体热化。这是概念框架的转变，而非物理预测的转变。**

### 2.3 模型M3: 棘轮置换（Ratchet Permutation）—— 【数学存在性证明】

#### 核心洞察

在纯数学层面，可以构造一个满足A1+A2的双射f，使得从全0态出发的轨道上，q在绝大多数时间步接近0。这证明"隔离自发经典化"的动力学在数学上存在——但代价是f必须高度非通用，对应不到任何已知的物理动力学。

#### 构造

将X = {0,1}^N按占用数分层: L_k = {s: Σs_i = k}。

定义f的循环结构:
1. **主要循环C_main**: 从全0态开始:
   - 在占用数k < N/2时: f提升占用数: L_k → L_{k+1}（或至少在k不减少的方向上）
   - 在占用数k ≥ N/2时: f主要在L_k内或向更高k移动
   - 到达全1态(k=N): f(11...1)经由一条"快速通道"返回到全0态（循环闭合）

2. **其他循环**: 剩余状态（不在C_main上的）被组织成短循环，全部位于低q区域(k ≈ N/2或更高)。这样，即使系统从C_main逃逸（由于微扰），它也陷在低q循环中。

**轨道分析**（简化版——纯提升链）:
```
全0(k=0) → L_1中某态 → L_2中某态 → ... → 全1(k=N) → 全0
```
占用数单调递增（除了最后一步的跃变）。轨道长度 = N+1。在这条轨道上，q的时间平均:
```
⟨q⟩_orbit = (1 + (N-1)/N + (N-2)/N + ... + 1/N + 0) / (N+1)
         = (1/N) · N(N+1)/(2N) / (N+1)  [近似]
         ≈ 1/2
```

即使是"提升链"，平均q也是1/2。要让平均q接近0，需要将轨道设计为: 占用数在低值(高q)时快速通过（少数步），在高值(低q)时缓慢穿越（多数步）。

**改进构造**: 将X的大部分状态（~2^N - poly(N)个）组织在低q区域（占用数在[N/2, N]之间）的循环中，只留下poly(N)个状态用于从q≈1向低q的过渡。从全0态出发的轨道: 经过O(N)步到达低q区域，然后进入一个巨大循环（长度~2^N），在这个循环中q始终很低。在这个构造下，时间平均q可以任意接近0（通过让N足够大）。

**存在性**: 对任意N≥2和任意ε>0，存在双射f: {0,1}^N→{0,1}^N和初始态s_0=(00...0)，使得在s_0的轨道上，满足q(s)≤ε的态所占比例至少为1-ε。

**证明**: 构造性——将大部分态打包在低q循环中，全0态通过一个精心设计的"桥"连接到主循环。细节在此省略（这是群论/组合学练习，不是物理）。

**物理相关性**: 零。这种f在S_{2^N}中的Haar测度为0（在2^N→∞时，这类f的"比例"趋于0）。没有任何已知或设想的物理动力学（局域相互作用、幺正演化、热化）能产生这种棘轮结构。M3是数学存在性证明，不是物理模型。

## 3. q(t)单调性的充分条件——及其A1+A2嵌入状态

### 3.1 条件C(a): 内部动力学不可逆性

**陈述**: 粗粒化转移概率满足W(q_low|q_high) ≫ W(q_high|q_low)（从量子→经典的跃迁远比反向更可能）。

**A1+A2中的状态**: 不嵌入。A1+A2只保证f是生物射。W_f(q'|q)和W_{f^{-1}}(q|q')完全对称——f和f^{-1}都是合法动力学，它们的宏观偏倚恰好相反。宏观不可逆性**不能**从A1+A2中推导——它要么是关于f的额外假设，要么来自初始条件的特殊性。

**但在统计力学中有标准解法**: 不可逆性来自初始特殊性 + 态空间体积梯度。如果系统从特殊的低熵态出发，熵（宏观态体积）更高的宏观态被典型动力学"吸引"。这在T2c中已形式化——在随机置换系综下，期望转移概率为W(q'|q) = Ω(q')/2^N，独立于q。因此系统倾向于移向体积更大（Ω更大）的宏观态。由于Ω(q)在q=1/2处最大，体积效应驱动q→1/2，而非q→0。

**结论**: C(a)仅在初始q>1/2且目标为q=1/2时有自然基础。驱动q从1/2到0需要超越A1+A2的额外偏倚。

### 3.2 条件C(b): 细胞锁定机制

**陈述**: P(s_i(t+1)=0 | s_i(t)=1) = ε ≪ 1。占用细胞以高概率保持占用。

**A1+A2中的状态**: 不嵌入。f是置换，不提供状态转移概率（除非我们引入随机f的系综平均）。ε需要额外观测来约束。

**物理正当化尝试**:
1. **能量论证**: 如果|1⟩是基态而|0⟩是激发态，自发辐射（|0⟩→|1⟩）是概率性的，逆过程需要能量输入。但这引入了超出A1+A2的能量结构。
2. **量子芝诺论证**: 如果细胞状态被其他细胞持续"观测"（通过内部相互作用），频繁的"测量"可以将细胞冻结在|1⟩。但这需要(a)定义什么构成"测量"，(b)解释为什么测量效应偏向|1⟩而非|0⟩。
3. **信息确认论证**: 一旦细胞记录了信息且该信息被其他细胞"确认"（通过某种共识协议），它进入锁定态——类似于区块链中的确认区块。但如何形式化这种"共识协议"作为双射f？

**诚实结论**: 锁定机制有直观吸引力（信息一旦写入不应轻易丢失），但目前没有从A1+A2到锁定机制的干净推导。

### 3.3 条件C(c): 相空间体积收缩

**陈述**: 宏观态体积Ω(q) = C(N, N(1-q))的梯度∂Ω/∂q在q>1/2时为负（向低q=更大体积），在q<1/2时为正（向高q=更大体积）。体积效应驱动系统趋向q=1/2（最大体积的宏观态）。

**A1+A2中的状态**: 部分嵌入。Ω(q)的组合学从A2（|X|=2^N）严格推出。在随机f系综下（T2c），系统确实在期望意义下向Ω最大的宏观态（q=1/2）移动。

**但是**: 体积效应驱动q→1/2，而非q→0。q=1/2是体积最大点；q=0是体积最小点之一。系统从q=1到q=1/2的弛豫有坚实的统计力学基础（Boltzmann的H-定理类比）。但从q=1/2到q=0没有这样的基础——那需要系统"自发"趋向极小体积的态，这违反了统计力学的所有直觉。

**推论**: DGF的"自发经典化"若被理解为q从1降到~1/2（从高度量子到"半量子"），则有坚实的统计力学基础（且等价于标准的多体热化/ETH）。若被理解为q降到0，则没有已知的物理机制支持。

## 4. 经典化时间标度 τ_classical

### 4.1 定义

τ_classical = 系统从初始量子态(q_eff≈1)演化到有效经典态(q_eff ≤ q_threshold，残余量子效应低于实验分辨率)所需的时间。

### 4.2 M1标度（关联压缩）

```
τ_classical ∝ N / (c · η · ω_0)
```

| 参数 | 含义 | 典型值（固态） |
|------|------|---------------|
| N | 细胞数 | 10^23 (1 cm^3) |
| c | 邻居数 | 6-12 (fcc/bcc) |
| η | 关联效率 | ? (自由参数) |
| ω_0 | 特征频率 | 10^13-10^15 Hz |

**问题**: 对于宏观物体(N~10^23)，τ_classical ~ 10^23/(10·η·10^14) ~ 10^8/η s。即使η=1，τ~10^8 s~3年。这远长于宏观物体实际呈现经典行为的时间尺度（<10^{-10} s）。→ 关联压缩对于宏观物体太慢。环境退相干主导。

### 4.3 M2标度（ETH热化）

```
τ_classical ∝ ħ / J_eff · g(N)
```

| N | g(N) [弹道] | g(N) [扩散] | τ (J=1 MHz, 弹道) | τ (J=1 MHz, 扩散) |
|---|-------------|-------------|-------------------|-------------------|
| 10 | 10 | 100 | 10 μs | 100 μs |
| 100 | 100 | 10^4 | 100 μs | 10 ms |
| 1000 | 1000 | 10^6 | 1 ms | 1 s |
| 10^23 | 10^23 | 10^46 | 10^17 s (~宇宙年龄) | 10^40 s |

**对于介观系统(N~10-100)**: τ_classical在微秒到毫秒量级——实验上可达。

**对于宏观物体**: τ_classical可能极长（弹道标度）或天文数字（扩散标度）——而且在实际系统中环境退相干在~10^{-40} s就已完成。自发经典化即使存在，也被完全掩盖。

### 4.4 可观测窗口

```
τ_decoherence(环境) < τ_classical(DGF自发) < τ_experiment
```

只有当自发经典化时间落在环境退相干时间与实验持续时间之间时，DGF效应才可观测。对于当前技术（超导qubit, T2~100 μs, 实验时间~1 s），可观测窗口为：

- DGF效应必须产生额外衰减γ_c ∈ [1 Hz, 10 kHz]
- 对应τ_classical ∈ [100 μs, 1 s]

| 机制 | τ_classical 预期 | 在窗口内？ |
|------|-------------------|-----------|
| M1 (关联, N=20, c=2) | ~10/ω_0 ~ 10^{-14} s (太快) 或 ~? (不确定——η未知) | 取决于η |
| M2 (ETH, N=20, J=1 MHz) | ~20 μs | **是**（在窗口边缘） |
| M2 (ETH, N=100, J=1 MHz, 扩散) | ~10 ms | **是** |

## 5. 实验方案

### 方案C: 超导Qubit链热化vs环境退相干区分实验

#### 核心思路

不追求完美隔离（技术上不可能），而是在已知残余环境耦合下，通过**标度律**区分DGF型自发经典化和标准环境退相干。

**关键鉴别器**: 标准环境退相干的衰减速率与N无关（每个qubit独立耦合到环境）。自发经典化的衰减速率依赖于N（因为内部动力学涉及多体效应）。

#### 实验设计

**系统**: 1D链上的N个transmon qubit（N=5, 10, 15, 20），可调最近邻耦合g_0。

**制备**: 所有qubit制备在|+⟩ = (|0⟩+|1⟩)/√2。初始态是完全直积态——所有细胞独立，q=1。

**隔离**: 
- 断开所有驱动线和读出线（通过滤波器/开关）
- 将qubit频率调至远离寄生模式
- 独立测量残余T1/T2（通过改变隔离条件下进行Rabi/ Ramsey测量）

**内部动力学**: 打开最近邻交换耦合g_ij = g_0（对于所有i,j = 相邻对）。系统在自身XXZ Hamiltonian下演化：
```
H = Σ_i (h_i/2) σ^z_i + g_0 Σ_{⟨i,j⟩} (σ^x_i σ^x_j + σ^y_i σ^y_j + Δ σ^z_i σ^z_j)
```

**测量**: 在时间t后，同时测量所有qubit在σ^x基上。从重复测量中，提取相干性度量：
```
C(t) = (1/N) Σ_i |⟨σ^x_i(t)⟩|
```
（⟨·⟩是量子力学期望，|·|取绝对值以消除不同qubit间可能的符号差异。）

#### 标度律鉴别

**标准退相干预测**（独立环境耦合）:
```
C(t) = C_0 exp(-γ_env t) · f_ETH(t)
```
其中f_ETH(t)是ETH热化的多体效应（对单粒子可观测量，通常是幂律衰减而非指数衰减，t^{-α}）。

在弱耦合极限γ_env→0: C(t)→1（完美隔离→永久相干）。

**自发经典化预测**:
```
C(t) = C_0 exp(-(γ_env + γ_DGF(N)) t)
```
其中γ_DGF(N)依赖于N，表征自发容量耗尽的速率。

| 模型 | γ_DGF(N) 标度 | 预测 |
|------|--------------|------|
| M1 (局域c=2) | ∝ 1/N | 衰减速率随N增大而**减小** |
| M1 (全连接) | ∝ const | 衰减速率与N无关 |
| M2 (弹道热化) | ∝ 1/N | 衰减速率随N增大而**减小** |
| M2 (扩散热化) | ∝ 1/N^2 | 衰减速率随N增大而**减小** |
| 标准退相干 | ∝ const | 衰减速率与N无关 |

**关键测试**: 对N=5和N=20测量C(t)，提取衰减速率γ(N)。如果γ(20) < γ(5)，这强烈支持内部多体机制（DGF或ETH）而非纯环境退相干。但这不能区分DGF和ETH——两者都预测N依赖性。

**区分DGF与ETH**: DGF的独特预测（如果有的话）是：即使所有内部相互作用被关闭（g_0=0），隔离足够长时间后，相干性仍会衰减（Process B——细胞自发的占用）。ETH预测：g_0=0 → 无热化 → 无退相干。但Process B的速率可能太低而无法观测（ε困境）。

#### 可行性

| 组件 | 现状 | 挑战 |
|------|------|------|
| N=20 qubit链 | 已实现 | 串扰控制 |
| 可调耦合 | 成熟 | 关断比>10^3 |
| T2~100 μs | 常规 | 进一步提高到1 ms |
| 同步读出 | 成熟 | 多路复用 |
| γ_env精确表征 | 可行 | 需在每个N值独立测量 |

**主要系统误差**: 串扰（qubit间寄生耦合）会产生N依赖的有效衰减——可能被误判为DGF效应。需要精确建模和测量串扰矩阵。

**零结果的含义**: 如果C(t)=C_0 exp(-γ_env t)对所有N成立（即排除残余衰减），则排除自发经典化（在实验灵敏度内）。这不排除DGF框架的其他部分（Process A、信息回流上限等），但确实排除了最激进的预言（Process B）。

## 6. 诚实自我攻击

### 攻击1: q→0是数学上不可能的（如果f是生物射）

如前所述，在生物射f下，轨道闭合。长时间q平均等于轨道上状态的等权平均。对于覆盖X相当部分的轨道（典型情况），平均q=1/2——因为Stirling近似表明X中占多数的状态的占用数≈N/2。

M3（棘轮置换）可以构造出存在性但需要f在置换群中测度为0——没有物理f自然属于此类。

**辩护（不完美）**: 统计力学本身也在同样的数学约束下运行。Boltzmann的H-定理面对同样的反对（Zermelo的回复悖论），并给出了同样的回答：不可逆性是实践的（回复时间远超可观测时间），而非逻辑的。但是，Boltzmann的论证驱动系统趋向**最大体积**的宏观态（熵增），而非最小体积。DGF的q→0要求系统趋向**最小体积**的宏观态——这在直觉上是反向的。

**结论**: 攻击成立。在A1+A2下，q→0不是预期行为。q→1/2才是。

### 攻击2: 区分DGF自发经典化与量子多体热化（ETH）是不可能的

M2（ETH热化）完全在标准QM框架内，且产生了与DGF在质量上相同的现象：单细胞相干性衰减、多体纠缠产生、"有效经典性"出现。唯一可能的区分是Process B（无内部相互作用时的自发的细胞占用），但此效应（a）未被观测到，（b）理论上其速率可能为零。

**如果DGF自发经典化=ETH热化，那么DGF没有增添新物理。它提供了新的语言（q, 细胞, 容量），但没有新的预测。**

**辩护（最诚实的版本）**: 这是当前情况的准确描述。DGF框架在隔离系统经典化方面最有价值的贡献可能就是概念性的——用信息容量(q)的语言统一了量子退相干和量子热化的描述。这不是一个令人满意的答案，但是诚实的。

### 攻击3: τ_classical标度的不确定性使理论不可证伪

M1（关联）给出τ ∝ N（局域）或τ ∝ 1（全连接），M2（ETH）给出τ ∝ N（弹道）或τ ∝ N^2（扩散），而MBL系统给出τ → ∞。参数η、输运机制、MBL阈值等都无法在框架内确定。一个灵活的标度假定可以通过调整这些参数来适应几乎任何实验结果。

**辩护**: 这是严肃的。实验方案C确实不能区分DGF和ETH（两者都在标准相关领域）。证伪DGF的唯一干净途径是测量非零的Process B（g_0=0时仍衰减）——而零结果不能确认DGF，只能将其推向不可观测的角落。

### 攻击4: A1+A2太弱，无法产生任何方向性的宏观动力学

A1+A2定义了信息系统的骨架，但它们允许的f范围太广——从恒等映射(所有态不动)到完全混沌的混合，从占用数保持的置换到随机置换。仅从A1+A2出发，无法预期任何特定的宏观行为。

**结论**: DGF框架需要比A1+A2更丰富的公理基础才能产生关于动力学的实质性预言。"隔离自发经典化"需要有定向性的动力学——某种形式的"时间箭头"公理。这与现有物理学面临的挑战完全相同（时间箭头从何而来？），DGF没有提供新的解答。

## 7. 总评估与建议

### 7.1 什么是严格成立的

1. **q从1弛豫到~1/2**: 有坚实的统计力学基础。初始特殊性+态空间体积→向典型宏观态弛豫→q下降（因为q=1/2是体积最大点）。这与ETH和多体热化完全一致。

2. **关联压缩有效降低信息容量**: N_eff < N当关联存在时。这是量子信息论的标准结果（纠缠压缩有效Hilbert空间维度）。可以在DGF框架内形式化。

3. **Poincaré回复时间∝exp(const·N)**: 确保了弛豫在实际时间尺度上"不可逆"。这是定理3d的直接应用。

### 7.2 什么是未成立的（关键鸿沟）

1. **q→0**: 从q=1/2到q=0没有自然的统计力学驱动力。q=0是体积最小的宏观态之一。

2. **隔离自发经典化作为A1+A2的定理**: 这是过度声称。它最多是"模型依赖的假说"。

3. **DGF自发经典化与ETH的可区分性**: 目前无已知的实验鉴别器（Process B除外，但其物理状态不确定）。

### 7.3 建议

**对于DGF框架**:
1. 将"隔离自发经典化"从"定理级声称"降级为"模型依赖的假说性延伸"，明确标注其假设。
2. 承认在可预见的未来，该假说与标准QM（ETH+环境退相干）的区分可能不可行。
3. 将宣传重点转向DGF真正严格的贡献：定理1-3（信息守恒和不可逆性）、信息回流上限（定理3b, 3d）、以及q依赖的退相干率（Process A的定量版本）。

**对于LP31课题**:
1. S2（本任务）可作为诚实的"失败记录"保留——证明了DGF最激进的预言在现有框架内不能成立。
2. 科研方向应转向可检验、不依赖Process B的预测：信息回流上限的电路QED检验（S3任务）。
