## BLOCKING 1 (致命): 量纲错误 — c不是速度

**INSPECTOR:** 原方程 ∂_t J_ij = -c²(q_i - q_j) → [c] = T⁻¹（频率），不是速度。

**修正:** 区分微观耦合常数 κ 和宏观波速 c_s。

设细胞格点间距为 a（Planck长度 ℓ_P）。

```
∂_t J_ij = -κ (q_i - q_j) - γ J_ij,    [κ] = T⁻²
```

连续极限下，图Laplacian Σ_j(q_j - q_i) → a²∇²q:

```
∂²_t q + γ ∂_t q = κ a² ∇² q
```

物理波速: **c_s² = κ a²**。

**定 κ:** κ = c²/a²，其中 c = 光速，a = ℓ_P（格点间距）。则 c_s = c。

在格点单位(a=1)下: κ = c²。但在物理单位下: κ = c²/ℓ_P² ≈ 3.5×10⁶⁹ s⁻²。

**修正后的基本方程:**

```
∂_t q_i = Σ_j J_ij                          [连续性]
∂_t J_ij = -(c²/a²)(q_i - q_j) - γ J_ij    [惯性+阻尼]
```

连续极限: **∂²_t q + γ ∂_t q = c² ∇² q** ← 波速恒为c。

## BLOCKING 2 (致命): 无源项 — 双星如何辐射

**INSPECTOR:** 方程齐次。没有源→无法描述引力波产生。

**修正:** 双星的时变q场 = 源。

两个q≈0的核以角频率Ω绕转。在距离R处（R >> 轨道尺度），q场扰动满足:

```
□(δq) + γ ∂_t(δq) = S(x,t)
```

源项 S(x,t) 来自两个核的时变q场。在远离源处，q场的四极矩 Q̈_ij 驱动辐射:

```
S(x,t) ∝ (G_DGF/c⁴) × (d²Q/dt²) / r
```

其中 G_DGF 是DGF的耦合常数（通过静态解校准: q(r) = e^{-GM/rc²} → 识別 G_DGF = G/c²）。

**线性化应变:**

在探测器处，δq/q̄（q̄≈1为真空背景）对应LIGO应变h:

```
h(t) = δq(t) / q̄ ≈ δq(t)
```

四极辐射的DGF版本（与GR的h ∝ (G/c⁴)Q̈/r结构一致，因从静态解校准了G）:

```
h(t) ∝ (G/c⁴) × (轨道频率Ω)² × (质量四极矩) / r
```

**关键:** 这不是新推导——这是从静态极限(q(r)=e^{-GM/rc²})和波动方程(□q=0)联合推出的。静态解校准了G→q的映射，波动方程给出了传播。源项的形式由这两个约束确定。

## BLOCKING 3 (致命): γ(q)无依据

**INSPECTOR:** 声称"q小→γ大"但γ在方程中是常数。

**修正:** γ 是常数——不依赖q。波-扩散交叉不是来自γ(q)，而是来自波数k。

色散关系: ω(k) = -iγ/2 ± √(c²k² - γ²/4)

交叉波数: k_cross = γ/(2c)

| 波数区 | 行为 | 物理 |
|--------|------|------|
| k < k_cross | 纯衰减（过阻尼） | 扩散——退相干/经典化 |
| k > k_cross | 阻尼振荡（欠阻尼） | 波——引力波/量子相干 |

**扩散→波的交叉由k决定，不由q决定。** 长波扩散，短波传播。

引力波（λ~10³-10⁶ m, k~10⁻³-10⁻⁶ m⁻¹）→ 短波 → 传播。
宇宙学尺度（λ~Gpc, k~10⁻²⁶ m⁻¹）→ 长波 → 扩散。

γ的值决定了k_cross的位置。如果γ极小（如γ ~ H₀ ~ 10⁻¹⁸ s⁻¹），则几乎所有可观测尺度都处于波区。

## BLOCKING 4 (警告级，非致命): 规则格点假设

**INSPECTOR:** Σ_j(q_j - q_i) = ∇²q 只在规则格点上成立。

**修正:** 不需要规则格点。只需要图Laplacian在红外极限下收敛到连续∇²。

对于**局部有限图**（每个细胞的邻居数有界），在大尺度极限下，图Laplacian的谱收敛到连续Laplacian的谱——这是谱图论的标准结果。

具体: 若细胞图G是ℤ³的"变形"（局部度数有界，存在双Lipschitz嵌入到ℝ³），则离散Laplacian L_G → ∇² + O(a²/L²)。在宏观尺度L ≫ a下，修正项可忽略。

**格点不规则性在Planck尺度——宏观物理不受影响。**

## BLOCKING 5 (警告级): 离散q vs 连续PDE

**INSPECTOR:** q ∈ {k/N}离散值，但方程用∂_t q连续导数。

**修正:** N ~ 10⁹⁰（可观测宇宙中的Planck细胞数）。连续近似的误差是O(1/N) ~ 10⁻⁹⁰——在任何可想象的精度下都无影响。

类似地：流体力学用连续方程描述离散分子(N~10²³)，误差O(10⁻¹²)。DGF的情况更好（N大67个量级）。

## WARNING修正

### W6 (Lorentz不变性): γ>0破缺Lorentz → 物理的

退相干需要优先时间方向。γ∂_t q 选定了介质的静止系。**这不是bug——这是退相干/经典化机制在起作用。** 在真空中(γ→0)，Lorentz不变性恢复。

### W7 (A2不强推J动力学): 承认

A2排除瞬时传播→要求有限传播速度。∂_t J_ij 是**最简单的因果扩展**，不是唯一推导。论文中诚实标注为"最小因果模型"。

### W10 (标量vs张量): 引力波自由度

**INSPECTOR是对的:** q是标量场→只有一个极化。GR的引力波有两个极化(h_+, h_×)。

**修正方案:** DGF的引力波不是度规扰动——它是q场密度波。LIGO测量的是q场扰动通过改变**局域时钟速率**(dτ/dt ∝ q)来影响干涉仪臂长。dτ/dt的变化等效于应变h = ΔL/L = Δq/q̄。

**DGF预言:** 只有一种极化（标量极化，呼吸模B）。
**GR预言:** 两种张量极化(+和×)。

**这是可检验的差异！** LIGO/Virgo的极化分析可以区分纯标量、纯张量和混合极化。目前的观测倾向纯张量，但标量贡献未完全排除（上限~10-20%）。

**诚实标注:** 标量vs张量极化是DGF与GR的关键分歧。如果未来的极化测量排除标量模→DGF被证伪。这是好的——框架可证伪。

## 修正后的完整方程

```
格子尺度:
∂_t q_i = Σ_{j∈nn(i)} J_ij                     (1) 连续性

∂²_t q + γ ∂_t q = c² ∇² q + S(x,t)           (3) 波动方程+源

□q = S(x,t)                                    (4) 无阻尼波动

过阻尼极限 (γ → ∞, c²/γ = D₀固定):
∂_t q = D₀ ∇² q + S/γ                          (5) DGF扩散方程

静态极限 (∂_t = 0):
c² ∇² q = -S_stat  →  ∇²(ln 1/q) = 0          (6) 引力势方程
```
