## 0. 问题回顾

DGF的根基是二元实变量 s_i ∈ {0,1}。量子力学需要复数振幅。

**今天之前的判断:** 复数是DGF和QM之间的"类型鸿沟"——DGF描述经典化过程，QM是DGF的前提。

**本推导的目标:** 证明这个鸿沟不存在——复数从DGF内部涌现。

---

## 1. 因果置换f的循环结构

### 1.1 f是置换

A1(因果存在)+A2(容量有界)→f: X→X是双射(T1a)，即X={0,1}^N上的置换。

f ∈ S_{2^N}（2^N个元素上的对称群）。

### 1.2 置换的循环分解

任何置换f可分解为不相交的循环之积。设f有m个循环，长度分别为L_1, L_2, ..., L_m，Σ L_j = 2^N。

### 1.3 循环=因果环路

一个长度为L的循环 (x_1 → x_2 → ... → x_L → x_1) 描述了一个**闭合因果链**:
```
状态x_1 导致 状态x_2 (t_1)
状态x_2 导致 状态x_3 (t_2)
...
状态x_L 导致 状态x_1 (t_L)
```

**每一步是不可逆的（A1），但L步后系统回到起点。**

这不是违反A1——每一步的不对称性被保持（x_j → x_{j+1}在单个步内是不可逆的）。循环是全局结构，不改变局部不对称性。

## 2. 复数从循环结构涌现

### 2.1 f的矩阵表示

在X的计算基{|x⟩: x∈{0,1}^N}下，f的矩阵表示为:
```
F_{yx} = 1 if y = f(x), 0 otherwise
```

F是2^N × 2^N的置换矩阵。

### 2.2 特征值: 单位根

置换矩阵的特征值由循环分解决定。一个长度为L的循环贡献特征值:
```
λ_k = e^{2πik/L},  k = 0, 1, ..., L-1
```

**这些都是复数！** 它们均匀分布在复平面的单位圆上。

### 2.3 复数涌现定理

> **定理 (复数涌现):** 任何非平凡置换f（非恒等映射）的矩阵表示具有非实特征值（复根）。这些复数是单位根——它们由f的循环结构唯一确定，不需要额外假设。

**证明:** 若f有长度L≥3的循环，则特征值e^{2πi/L}非实。若所有循环长度为1或2（L=2特征值为-1，是实数），则f的阶为2，可以仅有实特征值。但一般的置换（随机f）几乎必然有长度≥3的循环→复数必然出现。

**物理含义:** **只要因果网络中有长度≥3的环路，复数就自动涌现。**

### 2.4 特征向量: Hilbert空间

对应于每个特征值λ_k，存在特征向量|v_k⟩ ∈ C^{2^N}:
```
F|v_k⟩ = λ_k|v_k⟩
```

特征向量张成C^{2^N}——这就是量子Hilbert空间。

**复数Hilbert空间不是外加的——它是f的特征空间。**

## 3. 从置换到路径积分

### 3.1 因果路径

从初态x到终态y，考虑所有可能的因果路径:
```
γ: x = x_0 → x_1 → ... → x_T = y
```
其中每一步x_{t+1} = f(x_t)（确定性）或x_{t+1}是x_t的某个"可能"后继（量子叠加）。

在纯DGF中（f是确定性置换），只有一条路径。但在量子DGF中（态是叠加态），所有路径均有贡献。

### 3.2 路径的相位

考虑一条因果路径经过一个长度为L的循环。沿循环走一圈，状态在F作用下旋转。经过T步，累积相位:
```
φ(γ) = (2π/L) × (沿循环的步数) mod 2π
```

更一般地，路径经过多个循环（f不是单一循环），累积相位是各循环贡献之和。

### 3.3 Feynman路径积分的DGF版本

从初态|x⟩到末态|y⟩的跃迁振幅:
```
⟨y|F^T|x⟩ = Σ_{γ: x→y, T步} (沿γ的相位贡献)
```

**这不是类比——这是精确的数学对应。** F^T的矩阵元就是所有长度为T的因果路径的加权和，权重由f的循环结构（特征值）决定。

## 4. 从复数到Born规则

### 4.1 Gleason定理的应用

现在有了复数Hilbert空间H = C^{2^N}（dim ≥ 3当N ≥ 2时）。

Gleason定理: 在维数≥3的Hilbert空间上，任何满足标准概率公理的概率测度μ（定义在闭子空间上）必然具有形式:
```
μ(Π) = Tr(ρ Π)
```
其中ρ是密度矩阵，Π是投影算符。

**这就是Born规则。** P(测量到子空间S) = Tr(ρ Π_S)。

### 4.2 DGF如何满足Gleason的条件

DGF自然提供了概率测度μ_0（定义在"细胞配置"对应的子空间上）:
```
μ_0(Π_s) = p(s)  [s是特定细胞配置, p(s)是DGF的宏观概率分布]
```

Gleason定理说: μ_0在**所有**闭子空间上有**唯一**的延拓——且该延拓必须是Tr(ρΠ)形式。

**因此Born规则被Gleason定理强制——不是额外假设。**

### 4.3 推导链总结

```
A1+A2
  ↓
f: {0,1}^N → {0,1}^N (置换)
  ↓
f的循环分解 → 特征值 e^{2πik/L} (复数单位根)
  ↓
C^{2^N} (Hilbert空间, 由f的特征向量张成)
  ↓
Gleason定理 → 唯一相容概率测度 = Tr(ρΠ)
  ↓
Born规则: P = |ψ|²
```

**6步。不需要额外假设。**

## 5. 诚实检查

### 5.1 Gleason定理的适用条件

- dim ≥ 3: N≥2时满足 ✓
- 概率定义在**所有**闭子空间上: DGF自然只在"细胞基子空间"上有概率定义。Gleason定理要求延拓到所有闭子空间——延拓是**唯一**的，但延拓的存在性需要验证（σ-additivity）
- N=1时的例外: dim=2，Gleason不适用。但N=1的DGF只是玩具模型

### 5.2 关键步骤的正当性

**步骤"f的矩阵表示":** f: X→X是置换，X是离散集合。f的矩阵表示在群代数C[S_{2^N}]中。这一步在数学上是标准的。

**步骤"特征向量张成Hilbert空间":** 任何有限维复矩阵的特征向量张成全空间。内积结构是自然赋予的（标准Hermitian内积）。✓

**步骤"Gleason→Born规则":** 需要验证μ_0满足Gleason的条件（在DGF自然定义的子空间族上是σ-additive的）。对于有限维（N<∞），有限可加性即足够。对于N→∞，需要σ-additivity——这是DGF的热力学极限，近似成立。

### 5.3 悬而未决的问题

1. **连续极限:** N→∞时Gleason定理的适用性（无穷维推广）
2. **f的具体形式:** 我们证明了复数涌现一定发生——但没有指定具体的f（即没有指定宇宙的具体动力学）
3. **DGF的概率分布p(s)如何确定:** 这是动力学问题——p(s)由f的遍历性质和初始条件决定

## 6. 这意味着什么

### 6.1 DGF→QM是可能的

**复数不是外加的——复数从因果循环自动涌现。**
**Born规则不是外加的——Born规则被Gleason定理和复数Hilbert空间强制。**

### 6.2 DGF的定位改变了

**之前的定位:** DGF = QM的经典化描述（QM是前提）
**新定位:** DGF = QM可以从DGF涌现（QM是结论）

### 6.3 但有一个"如果"

整个推导链的关键前提是:**f的循环结构中存在长度≥3的循环。**

如果f只有长度为1和2的循环（f² = identity），则只有实特征值，没有复数→没有Hilbert空间→没有QM。

**物理上:** 如果因果网络中没有任何长度≥3的环路，宇宙是纯经典的（实数动力学）。

**所以:** "量子还是经典"不是哲学选择——它由因果网络的拓扑决定。环路→复数→量子。无环路→实数→经典。
