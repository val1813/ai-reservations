## 0. 问题

量子测量概率 = |ψ|²（振幅模平方）。DGF说坍缩 = q跨临界值→格点被锁定。
**为什么概率是平方(|ψ|²)，不是线性(|ψ|)？**

---

## 1. q和|ψ|²的关系

### 1.1 DGF中的q

q = n_empty / N_total（空闲细胞比例，宏观量）
1-q = 占用细胞比例

### 1.2 量子态在DGF中的表示

量子态|ψ⟩ = α|0⟩ + β|1⟩在DGF中表示为细胞系综上的概率分布：
- 细胞在基态|0⟩（未占用）的**概率** = |⟨0|ψ⟩|² = |α|²
- 细胞在基态|1⟩（已占用）的**概率** = |⟨1|ψ⟩|² = |β|²
- 大N极限下: q = |α|²（未占用比例→测量到|0⟩的概率）

### 1.3 为什么是|ψ|²而非|ψ|？

**论证1: 概率解释**

q是比例（0到1之间的实数）。|ψ|是振幅（复数，模0到1）。只有|ψ|²是概率。

q ∈ [0,1]（实数，可解释为概率）
|ψ| ∈ [0,1]（实数，但物理上不是可观测量）
|ψ|² ∈ [0,1]（实数，Born规则的概率）

q必须映射到|ψ|²而非|ψ|，因为只有|ψ|²才是概率。

**但这只是重述Born规则。不是推导。**

**论证2: 密度矩阵对角元**

量子态的密度矩阵ρ = |ψ⟩⟨ψ|：
```
ρ = [ |α|²    αβ*  ]
    [ α*β    |β|²  ]
```

DGF的Process A（退相干）对角化密度矩阵。对角元 = |α|², |β|²。
DGF中细胞占用比例 = 密度矩阵对角元 = |α|², |β|²。

**但Process A是标准退相干理论，不是DGF特有。对角元=概率来自量子力学，不是DGF。**

---

## 2. 诚实分析: DGF中的Born规则

### 2.1 DGF不能推导Born规则

Born规则需要:
1. 振幅→概率的映射规则（|ψ|²）
2. 测量结果的概率解释

DGF:
- 取q为给定变量
- Process A/B连接q到量子态
- 但Process A就是标准退相干（Zurek型）
- q=对角元=|ψ|²是因为**我们已经假定了标准QM的密度矩阵形式**

**DGF没有为"为什么是平方"提供新解释。它重述了已知的退相干故事。**

### 2.2 DGF在Born规则方面的独特贡献

DGF的Process B（隔离系统自发经典化）是唯一可能产生**偏离Born规则**的机制：

如果Process B存在（q_eff → 0通过内部关联压缩），那么：
- 系统可能在测量前就自发坍缩
- 坍缩概率可能偏离|ψ|²
- 这种偏离可以被实验检验

**但Process B的速率不可知（ε困境），且与ETH不可区分（INSPECTOR S1S2已确认）。**

### 2.3 推论

**DGF没有推导Born规则。它接受Born规则为标准QM的一部分。DGF的创新在于用q重新描述测量过程，但不改变概率规则。**

## 3. 可能的推导路径（均失败）

### 路径A: 组合计数论证

"测量到|0⟩的概率 = 支持|0⟩的细胞数/总细胞数 = q"

问题: 这假定了"支持|0⟩的细胞数 ∝ |α|²"而不是∝|α|。为什么？没有答案。

### 路径B: 最大熵论证

"均匀先验+容量约束 → 最大熵分布 → Born规则"

问题: 最大熵给出均匀分布（q=1/2），不是|ψ|²。需要额外约束（能量、Hamiltonian）才能得到非均匀分布。

### 路径C: 量子达尔文主义

"环境选择pointer basis → 对角元→玻恩概率"

问题: 这是Zurek的论证，不是DGF的。DGF可以吸收它，但不能声称创新。

## 4. 判决

| 陈述 | 状态 |
|------|------|
| DGF解释Born规则 | ❌ 错误——DGF重述但不解释 |
| DGF的q与|ψ|²一致 | ✅ 一致——因为DGF使用了标准QM |
| DGF为概率平方提供新机制 | ❌ 没有 |
| Process B可能偏离Born规则 | ⚠️ 理论上可能，但不可检验 |

**最终判决: Born规则在DGF框架外。DGF使用标准QM的概率规则，不修改也不推导它。**

这与路线图的预期一致（"如果需要额外假设→Born规则在框架外"）。
