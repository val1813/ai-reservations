## 1. 两个容量: q 和 q_eff

### 1.1 定义

**q (局域空置率):** 每个细胞独立测量为|0⟩的概率的平均
```
q = (1/N) Σ_i ⟨0|ρ_i|0⟩
```
- 在局域酉群⊗_i U_i下守恒 ✓
- 度量: 超position程度（局域的"量子性"）
- 范围: [0, 1]

**q_eff (全局有效容量):** 联合态实际占用的Hilbert空间维度
```
q_eff = 1 - log₂(dim(support(ρ))) / N
```
- 在所有酉变换下守恒（support维数是西不变的）
- 度量: 混合度/经典性（全局的"确定性"）
- 范围: [0, 1]

### 1.2 验证 — 四种典型态

| 态 | q | q_eff | dim(support) | 物理分类 |
|----|----|----|-------------|---------|
| 纯乘积态 \|+⟩⊗^N | 1/2 | **1** | 1 | 最大量子 |
| GHZ态 | 1/2 | **1** | 1 | 全局量子，局域混合 |
| 最大混合态 I/2^N | 1/2 | **0** | 2^N | 最大经典(完全不确定) |
| \|1⟩⊗^N (所有细胞占满) | **0** | **1** | 1 | 经典+确定 |
| 经典关联混合 | 1/2 | 1-log₂M/N | M | 部分经典 |

### 1.3 关键洞察: GHZ的"局域经典性"

GHZ态: q=1/2, q_eff=1。

看上去"非常量子"——但这是在全局层面。在**局域**层面，每个细胞是最大混合态(I/2)，完全没有相干性——局域上完全是经典的。

**纠缠将"量子性"从局域转移到全局。** 局域观察者看到一个经典系统(q_local=1/2 per cell, 但ρ_i=I/2→无相干)。只有全局观察者能看到量子性(q_eff=1→纯态)。

## 2. 二维相图

以(q, q_eff)为坐标:

```
q_eff
 1 │  量子相干        │  宏观叠加
   │  (产品纯态)       │  (GHZ, 猫态)
   │                   │
   │  局域经典+        │  经典统计
   │  全局量子         │  系综
 0 │  经典确定        │  最大无知
   │  (\|1⟩⊗^N)       │  (I/2^N)
   └────────────────────────── q
      0                   1
```

### 2.1 四个象限的物理

| 象限 | q | q_eff | 态例 | 物理 |
|------|----|----|------|------|
| 右下 | 高 | 低 | I/2^N | 经典无知——高熵混合态 |
| 右上 | 高 | 高 | 产品纯态, GHZ | 量子——相干+纠缠 |
| 左下 | 低 | 低 | 经典确定态+强关联 | 死寂——完全锁定 |
| 左上 | 低 | 高 | \|1⟩⊗^N(独立满细胞) | 经典确定——无关联 |

### 2.2 DGF的量子→经典路径

量子→经典对应在二维相图中从**右上→左下**的轨迹:

```
起点 (q≈1/2, q_eff≈1): 产品纯态——完全量子
  ↓ M1机制: 纠缠增长
中点 (q≈1/2, q_eff≈0): 强纠缠态——全局量子但局域混合
  ↓ Process A: 退相干
终点 (q≈0, q_eff≈0): 经典确定态——完全经典
```

**M1和Process A驱动不同的维度!**
- M1: 降低q_eff（全局维度——通过纠缠锁定）
- Process A: 降低q（局域维度——通过退相干）

## 3. M1机制的定量化

### 3.1 纠缠如何"消耗"容量

**直觉:** 纠缠使细胞之间产生约束——细胞1的状态和细胞2的状态不能独立选择。

**定量:** N个细胞, 纠缠度量E(ρ)（如纠缠熵、concurrence等）。

纠缠增长 → 约束数量增加 → 可独立访问的自由度减少 → 有效局域容量减少。

### 3.2 从纠缠到q_eff的映射

定义**总互信息**（multi-information）:
```
I_total(ρ) = Σ_i S(ρ_i) - S(ρ)
```

其中S是von Neumann熵。

I_total度量所有细胞之间的总关联（量子的+经典的）。

**局域有效容量:**
```
q_local_eff = 1 - (Σ_i S(ρ_i)) / (N ln 2)
```

对于纯态(S(ρ)=0): q_local_eff = 1 - (Σ_i S(ρ_i))/(N ln 2) = q_eff (from support dim)

对于产品纯态: S(ρ_i)=0 → q_local_eff = 1 ✓
对于GHZ: S(ρ_i)=ln 2 for all i → q_local_eff = 0 ✓✓

**这就是M1的定量表述!** 纠缠使每个细胞的约化熵增加→局域有效容量q_local_eff下降→系统在局域层面变得"经典"。

### 3.3 M1速率方程（初步）

假设细胞间纠缠以速率γ产生（每步γ对细胞建立关联）:
```
d(q_local_eff)/dt = -γ · q_local_eff
```

（局域有效容量的衰减与当前容量成正比——容量越多，可关联的"自由度"越多）

解: q_local_eff(t) = q_local_eff(0) · e^{-γt}

经典化时间: τ_classical ~ 1/γ

γ如何从A1+A2推导? 开放问题。但标度假定 γ ∝ (耦合强度) × (可用细胞对数) ∝ η · N 是合理的。

## 4. 与DGF已有定理的对接

### 4.1 S1回流定理

回流界P_reflux ≤ (q_S/(1-q_S))^δ · ((1-q_E)/q_E)^δ 中的q——应该是q还是q_eff?

**答案:** q（局域）。S1的细胞计数基于局域占用数K，不涉及全局纠缠结构。S1在经典DGF中推导——那里没有纠缠。

**但** 如果引入纠缠(q_eff < q)，则有效系统大小N_S_eff < N_S → 回流界收紧。纠缠使回流更困难——不可逆性更强。

### 4.2 T3a Kac回复时间

T3a: 回复时间 = 2^{N_S}。

在二维容量框架中: T_recurrence = 2^{N_S_eff} = 2^{N · q_eff}

纠缠(q_eff < 1) → 有效状态空间缩小 → 回复时间**缩短**——信息更容易回来。

**这与M1的"经典化"方向相反!** M1说纠缠→更经典→更不可逆。但如果回复时间缩短，信息更容易回复——这是"更可逆"，不是"更不可逆"。

**这是二维容量框架揭示的一个真实张力。** 需要进一步分析。

### 4.3 S2隔离系统

S2: 隔离系统长时间平均q=1/2。

在二维框架中: q → 1/2（组合优势）同时 q_eff → ?（未知）

如果q_eff也趋向某个值，则S2的结论需要修正——"隔离系统不会自发经典化"的证明只涉及q，不涉及q_eff。

### 5.3 底线

**DGF需要两个容量参数。** 单个q不足以刻画量子→经典的全部物理。这是对原始框架的重要扩展，不是推翻。

q控制局域相干性（退相干方向），q_eff控制全局独立性（纠缠方向）。两者共同决定了系统在二维相图中的位置。
