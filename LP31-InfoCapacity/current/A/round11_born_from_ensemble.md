# Round 11: Born规则 — 从系综和路径计数出发

**日期:** 2026-06-07
**规则:** 不用QM概念（振幅、叠加、Feynman）。只用A1+A2。
**问题:** P = |α|² 从哪来？

---

## 0. 前提: DGF有什么

A1: 因果存在。f: X→X，置换。
A2: N个二元细胞，每个s_i ∈ {0,1}，|X|=2^N。

一个"系统"不是单个细胞——是N个细胞的**系综**。N可以很大。

---

## 1. 测量 = 从系综中采样

### 1.1 什么是测量

测量 = 选一个细胞，看它是0还是1。

P(0) = （0-细胞的数量）/ N = q

**这不是Born规则，这是q的定义。** q = 系综中0-细胞的比例。

### 1.2 "量子态"是什么

在DGF中，说"一个量子比特在态|ψ⟩"意味着什么？

**意味着:** 描述这个量子比特的N个细胞的系综中，有一部分处于"支持|0⟩"的配置，另一部分处于"支持|1⟩"的配置。

设N₀个细胞支持|0⟩，N₁ = N - N₀个支持|1⟩。

**定义:** 
```
p₀ = N₀/N  (支持|0⟩的细胞比例)
p₁ = N₁/N  (支持|1⟩的细胞比例)
```

p₀ + p₁ = 1。

---

## 2. 测量概率

从系综中均匀随机选一个细胞:

```
P(0) = N₀/N = p₀
P(1) = N₁/N = p₁
```

**这就是Born规则。** P = p₀ = 系综中支持该结果的细胞比例。

---

## 3. 振幅的出现

### 3.1 为什么引入振幅

p₀和p₁是概率——实数，∈[0,1]，直接相加(p₀+p₁=1)。

但如果要描述两个系综如何**组合**（标准QM的"叠加"），直接加概率不够——因为两个系综的细胞可能重叠，可能对齐或反对齐。

需要一个量既能编码"大小"（细胞数），又能编码"方向"（细胞配置的对齐方式）。

### 3.2 振幅=带相位的系综权重

**定义:**
```
a₀ = √p₀ · e^{iθ₀}
a₁ = √p₁ · e^{iθ₁}
```

- √p₀: 编码系综的"规模"（细胞数的平方根）
- e^{iθ₀}: 编码系综的"因果历史"（配置的相位）

**振幅是衍生量——p₀才是基本的。**

### 3.3 为什么是√p

因为两个独立系综组合时，**细胞数相加**:

系综A: N₀^A = N·p₀^A 个|0⟩-细胞
系综B: N₀^B = N·p₀^B 个|0⟩-细胞

如果相位对齐: N₀^{A+B} = N₀^A + N₀^B = N(p₀^A + p₀^B)

但如果相位相反: N₀^{A+B} = |N₀^A - N₀^B| = N|p₀^A - p₀^B|

一般情况下（相位差Δθ）:
```
N₀^{A+B} = N₀^A + N₀^B + 2√(N₀^A N₀^B) cos(Δθ)
```

除以N:
```
p₀^{A+B} = p₀^A + p₀^B + 2√(p₀^A p₀^B) cos(Δθ)
```

**这正是 |a₀^A + a₀^B|² = |√p₀^A e^{iθ₀^A} + √p₀^B e^{iθ₀^B}|²**

---

## 4. 干涉的DGF推导

### 4.1 两个子系综的组合

考虑两个子系综A和B，各有N个细胞，各自有p₀^A和p₀^B。

将它们合并为一个2N细胞的系综。

每个系综的细胞有一个"配置签名"——0或1。

如果两个系综的配置签名完全相同（同相），0-细胞直接相加。
如果完全相反（反相），0-细胞抵消。
一般情况: 取决于配置签名的重叠程度。

### 4.2 重叠程度的度量

系综A的配置可以用一个N维向量表示: v^A ∈ {0,1}^N，第i个分量是细胞i的状态。

系综B同理: v^B ∈ {0,1}^N。

重叠: ⟨v^A, v^B⟩ = Σ_i v^A_i · v^B_i = 两个系综中**同时为1的细胞数**。

但我们需要的是0-细胞的重叠: Σ_i (1-v^A_i)(1-v^B_i) = N - (1-细胞总数) + 重叠。

实际上更简单: 设系综A有N₀^A个0-细胞，位置在集合S_A中（|S_A|=N₀^A）。系综B有N₀^B个0-细胞，位置在S_B中。

合并后的0-细胞数 = |S_A ∪ S_B| - |S_A ∩ S_B|... 不对，我们不是在合并位置，而是两个系综共享同一组细胞位置，它们在每个位置上的状态可以相同或不同。

**每个细胞位置i，系综A给出状态s_i^A，系综B给出状态s_i^B。**

如果两个系综在位置i上的状态对齐（都是0或都是1），则该位置对合并后的0-细胞计数贡献为:
- 若S_A(i)=0且S_B(i)=0: 两个系综的0-细胞都支持这个位置→合并后0-细胞计数贡献两个都算→其实是系综A的细胞和系综B的细胞同时占据这个位置

Hmm，实际上这需要更仔细的处理。两个系综合并时，我们有两倍的细胞（2N个），每个位置有两个细胞（一个来自A，一个来自B）。

实际物理过程: 两个系综的细胞被混合在一起，然后随机抽取。合并后的0-细胞总数 = N₀^A + N₀^B（细胞数直接相加...因为每个系综贡献自己的细胞）。所以 p₀^{A+B} = (N₀^A + N₀^B)/(2N) = (p₀^A + p₀^B)/2。

这没有干涉！干涉需要两个系综**共享同一组细胞**，不是各自有N个细胞。

### 4.3 关键修正: 叠加 = 同一组细胞的重新配置

"叠加"不是两个系综合并——而是**同一组N个细胞同时受两个"因果配置"的影响**。

每个细胞i的状态取决于两个因果配置如何组合:
- 如果两个配置在细胞i上"对齐"（同相），该细胞取配置的公共值
- 如果"反对齐"（反相），该细胞在两个值之间——不确定

**干涉 = 同一组细胞上两个因果配置的相互影响。**

在DGF中，这对应于: 该组细胞的因果历史有分支——两条不同的因果路径都影响了这组细胞。净效果取决于两条路径的相位差。

### 4.4 路径重叠的数学

N个细胞。因果路径A在n_A个因果事件后到达。因果路径B在n_B个因果事件后到达。

相位差: Δθ = 2π(n_A - n_B)/T。

两条路径在细胞i上"对齐"的条件: 细胞i在两条路径下的状态相同。

如果两条路径是同相的(Δθ=0): 它们在所有细胞上对齐→所有细胞的状态确定→无量子不确定性→经典。

如果两条路径是反相的(Δθ=π): 它们在所有细胞上反对齐→每个细胞在两个状态间→最大量子不确定性。

一般Δθ: 对齐的细胞比例 = cos²(Δθ/2) = (1+cos(Δθ))/2。

**合并后的支持|0⟩的细胞数:**
```
N₀^{eff} = N₀^A + N₀^B + 2√(N₀^A N₀^B) cos(Δθ)
```

第一项: 路径A单独贡献的0-细胞
第二项: 路径B单独贡献的0-细胞
第三项: 两条路径对齐的细胞——这些细胞同时受两条路径支持，贡献增强

**为什么是2√(N₀^A N₀^B) cos(Δθ)？**

对齐的细胞数 = N × (两条路径在随机细胞上对齐的概率)

两条路径在随机细胞i上对齐的概率:
- 对齐要求: s_i^A = s_i^B = 0（都支持|0⟩）或 s_i^A = s_i^B = 1（都支持|1⟩）
- P(对齐) = (N₀^A/N)(N₀^B/N) + (N₁^A/N)(N₁^B/N) = p₀^A p₀^B + p₁^A p₁^B

加上相位调制: 对齐的效率取决于Δθ。当Δθ=0，对齐完美（贡献最大）。当Δθ=π，对齐反转（贡献为负——细胞被"抵消"）。

cos(Δθ)编码了这种调制:
```
对齐细胞的净贡献 = N √(p₀^A p₀^B) cos(Δθ)  [交叉项]
```

加上来自A和B各自的贡献:
```
N₀^{eff} = N p₀^A + N p₀^B + 2N √(p₀^A p₀^B) cos(Δθ)
```

除以N:
```
p₀^{eff} = p₀^A + p₀^B + 2√(p₀^A p₀^B) cos(Δθ)
```

**这就是Born规则的叠加形式。** 不需要复数——p₀和Δθ是实数。

复数是这个实数公式的紧凑写法: |√p₀^A e^{iθ_A} + √p₀^B e^{iθ_B}|² = 上式。

## 5. 汇总: Born规则从A1+A2的推导

### 步骤

1. **A2** → N个二元细胞 → 系综描述
2. 系综中0-细胞的比例 = q = p₀（定义）
3. 测量 = 从系综采样 → P(0) = p₀（大数定律）
4. **A1** → 因果路径 → 路径有计数n
5. **A1+A2** → 循环性 → 相位 θ = 2πn/T
6. 两条因果路径同时影响同一组细胞 → 干涉
7. 干涉后的有效0-细胞比例: p₀^{eff} = p₀^A + p₀^B + 2√(p₀^A p₀^B) cos(Δθ)

**步骤1-3给出P=|α|²（其中|α|²=p₀是基本量）。步骤4-7给出叠加规则。**

### Born规则的完整形式

单系综: P(0) = p₀  [概率=系综比例，定义]

叠加: P(0) = p₀^A + p₀^B + 2√(p₀^A p₀^B) cos(Δθ)

用振幅写法: P(0) = |a₀^A + a₀^B|²，其中a = √p · e^{iθ}

**复数不是基本量。p₀（细胞比例）和θ（因果路径计数）是基本量。振幅a=√p e^{iθ}是衍生表示。**

---

## 6. 诚实检查

### 站得住的

- P = p₀ = 系综比例 ✓（大数定律，来自A2的N个细胞）
- 叠加公式的cos(Δθ)项 ✓（来自相位差决定路径对齐/反对齐）
- 振幅=衍生量 ✓（√p来自叠加公式的平方根结构）

### 还有gap的

- **步骤6（两条路径同时影响同一组细胞）** — 这需要"量子叠加"的概念。在纯DGF中，一组细胞如何同时受到两条因果路径的影响？
- **2√(N₀^A N₀^B)的系数2** — 来自二项式展开。√(N₀^A N₀^B)来自两条路径在细胞i上独立对齐的概率之积。这个系数的完整推导需要更多的组合分析。
- **cos(Δθ)的具体形式** — 我们用了cos但没从DGF严格推导为什么相位调制是这个函数。

### 底线

> **Born规则的核心（P=系综比例）从A1+A2直接推出——这是q的定义。叠加规则（干涉项∝cos(Δθ)）从相位差（因果路径计数差）和细胞对齐的几何推出——这个推导有gap但在正确的方向上。振幅和复数是衍生表示，不是基本量。**
