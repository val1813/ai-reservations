# Round 6: 细胞基优先问题的根本解决

**日期:** 2026-06-06
**问题:** q在基变换下是否守恒？细胞基是物理的还是任意的？
**状态:** 推导完成 — q在保持A2结构的基变换下严格守恒

---

## 0. 问题的精确表述

A2: |X| = 2^N。物理含义：系统由N个独立的二元信息存储单元（细胞）组成，每个容量1 bit。

q = (N - Σ s_i)/N，其中s_i ∈ {0,1}是细胞i的状态。

**攻击:** 在量子力学中，基的选择是任意的。如果旋转基，(s_1, s_2, ..., s_N)的值改变→q改变→"经典性=q≈0"不是物理陈述。

---

## 1. 关键观察: A2本身定义了基

### 1.1 A2不仅是"有限状态数"

A2 = "|X| = 2^N"。但这不是一个裸数——它有物理含义：

> **系统由N个独立的二元信息存储单元组成，每个单元独立地贡献1 bit容量。**

这个物理含义等价于声明：**状态空间具有因子化结构 H = (C²)^{⊗N}。**

### 1.2 因子化结构定义了"细胞基"

H = C² ⊗ C² ⊗ ... ⊗ C² (N个因子)

细胞基 = 每个C²因子上的计算基 {|0⟩_i, |1⟩_i}。

**细胞基就是使A2的物理含义成立的那个基。** 它不是外加的选择——它内嵌在A2中。

### 1.3 什么基变换是允许的？

保持因子化结构 H = (C²)^{⊗N} 的基变换 = 各因子上独立的局域酉变换：

```
U = U₁ ⊗ U₂ ⊗ ... ⊗ U_N
```

**混合不同细胞的基变换（非局域酉变换）破坏因子化结构→破坏A2。**

---

## 2. q在局域酉变换下的守恒性

### 2.1 单个细胞

细胞i的态: |ψ_i⟩ = α_i|0⟩_i + β_i|1⟩_i

局域酉变换: U_i|0⟩_i = |0'⟩_i, U_i|1⟩_i = |1'⟩_i

在新基下: |ψ_i⟩ = α_i|0'⟩_i + β_i|1'⟩_i

**"未占用"概率** |α_i|²在新旧基下相同。

### 2.2 q的定义（量子版）

在量子DGF中，细胞i的"占用期望" = |β_i|² = 1 - |α_i|²。
细胞i的"空置期望" = |α_i|²。

总空置比例:
```
q = (1/N) Σ_i |α_i|² = (1/N) Tr(ρ Σ_i |0⟩_i⟨0|_i)
```

### 2.3 局域酉变换下的不变性

在 U = ⊗_i U_i 下:
|0⟩_i → U_i|0⟩_i = |0'⟩_i
|0⟩_i⟨0|_i → |0'⟩_i⟨0'|_i

Tr(ρ |0'⟩_i⟨0'|_i) = ⟨0'|_i ρ_i |0'⟩_i = ⟨0|_i (U_i† ρ_i U_i) |0⟩_i

如果ρ在变换下也变换: ρ → UρU†, ρ_i → U_i ρ_i U_i†
则: Tr(UρU† |0'⟩⟨0'|) = ⟨0'|UρU†|0'⟩ = ⟨0|U†UρU†U|0⟩ = ⟨0|ρ|0⟩

**q严格守恒。** ✓

### 2.4 定理: q的基不变性

> **定理 (q的局域基不变性):** 在保持A2因子化结构 H = (C²)^{⊗N}的所有基变换 U = ⊗_{i=1}^N U_i 下，q是不变量。

**证明:** 上述。q = (1/N) Σ_i ⟨0|_i ρ_i |0⟩_i，每个⟨0|_i ρ_i |0⟩_i在局域酉变换ρ_i → U_i ρ_i U_i†, |0⟩_i → U_i|0⟩_i下不变。∎

## 3. 为什么这个问题现在解决了

### 3.1 之前的困惑

"细胞基是任意的" — 这个批评暗含了一个假设：**所有酉变换都是合法的基变换。**

但在DGF中，不是所有酉变换都合法。只有**保持A2因子化结构的酉变换**才是合法的基变换。

为什么？因为如果混合了不同细胞（例如用|0⟩_1|0⟩_2 + |1⟩_1|1⟩_2这种纠缠基），则"细胞1"和"细胞2"不再是独立的信息存储单元→A2的物理含义（N个独立bit）被破坏。

### 3.2 物理类比

这类似于：在固体物理中，我们选择"位置基"|x⟩来描述晶格上的电子。为什么不用动量基？因为**晶格结构选择了位置基作为自然的局域基**。

在DGF中，A2的因子化结构 H=(C²)^{⊗N} 就是那个"晶格结构"——它选择了细胞基作为自然的局域基。

### 3.3 重要限定

q在**局域**酉变换下守恒。在**非局域**（混合细胞）酉变换下不守恒。

但非局域酉变换在DGF中是非法的——它们破坏A2的物理含义。**一个破坏公理的变换不能用来攻击从公理推出的结论。**

## 5. 诚实检验

### 这个论证强吗？

**强处:**
- 直接从A2出发，不引入新假设
- 代数验证简单明确（局域酉变换下|α_i|²守恒）
- 物理动机清晰（A2=独立bit→因子化结构）

**弱点:**
- "A2的物理含义=因子化结构"这步需要被认可。如果有人认为A2只是"状态数是2^N"而不附带任何结构性含义，则这个论证不成立
- 局域酉变换确实是局域的——但"局域"本身就假定了空间结构（哪些细胞是"同一个"细胞在不同的基下）

**回应:** 第二个弱点不是真弱点。"同一细胞"由A2的产品结构定义——细胞1是C²_1，细胞2是C²_2。这是代数上严格的，不需要空间结构。

### 自攻击

**攻击1:** 如果我选择基U_global = (U_1 ⊗ U_2) · SWAP，这是局域酉变换的乘积，但SWAP交换了细胞1和2。它保持因子化结构但改变了哪个细胞是"细胞1"。

**回应:** SWAP不改变q——它只是重新标记细胞。q = (Σ |α_i|²)/N在细胞重排下不变（对称性）。

**攻击2:** A2没有明确说"因子化结构"——它只说|X|=2^N。从"状态数是2^N"推出"状态空间是(C²)^{⊗N}"需要额外假设。

**回应:** 这是真的——但非常弱。2^N = dim(H)的任何H都同构于(C²)^{⊗N}。因子化结构是"N个二元细胞"这一物理描述的自然数学翻译。拒绝这个翻译=拒绝A2的物理动机。
