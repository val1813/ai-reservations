## 0. 问题陈述

DGF的q场方程是抛物型（扩散方程）：
∂_t q = D₀ ∇²φ(q),   φ ∈ Φ

扩散方程信号瞬时传播，不能描述以c传播的引力波。

LIGO探测到引力波——时空曲率的振荡，以光速c传播。

**核心问题:** DGF能否解释引力波？如果不能，需要什么修改？

---

## 1. 抛物型PDE的传播特性

### 1.1 基本性质

方程 ∂_t q = D₀ ∇²φ(q):
- **类型:** 一阶时间导数 + 二阶空间导数 = 抛物型
- **传播速度:** 无限（瞬时传播，虽然幅度指数衰减）
- **波解:** 不存在无阻尼的行波解
- **基本解:** δ-源在t>0时散布到全空间（热核/扩散核）

### 1.2 与引力波的定性矛盾

引力波以有限速度c传播。抛物型方程不能描述此行为。

**直接结论: 一阶DGF方程无法描述引力波。**

---

## 2. 升级为双曲型：Telegraph方程

### 2.1 离散动力学的Taylor展开

微离散动力学（建模ansatz）:
q_i(t+τ₀) = q_i(t) + α Σ_{j∈nn(i)} (φ(q_j) - φ(q_i))

其中α是无量纲耦合常数，τ₀是微观步时间。

**Taylor展开（保留二阶):**
q_i(t) + τ₀ ∂_t q_i + (τ₀²/2) ∂²_t q_i + O(τ₀³) = q_i(t) + α Σ_j (φ(q_j) - φ(q_i))

消去q_i(t):
τ₀ ∂_t q + (τ₀²/2) ∂²_t q = α Σ_j (φ(q_j) - φ(q_i))

**连续极限 (a→0, τ₀→0, a/τ₀=c固定):**
Σ_j (φ(q_j) - φ(q_i)) → a² ∇²φ(q)

**代入:**
τ₀ ∂_t q + (τ₀²/2) ∂²_t q = α a² ∇²φ(q)

除以τ₀:
```
∂_t q + (τ₀/2) ∂²_t q = (α a²/τ₀) ∇²φ(q) = D₀ ∇²φ(q)
```

其中 D₀ = α a c。

### 2.2 关键特征

**这就是Telegraph方程！**
```
τ ∂²_t q + ∂_t q = D₀ ∇²φ(q),   τ = τ₀/2
```

- τ = τ₀/2 = a/(2c)：由离散时间步自然产生
- D₀ = α a c：由离散空间步和耦合常数决定
- 方程从抛物型升级为准双曲型

## 3. 波速分析

### 3.1 线性化

在背景q₀附近线性化：q = q₀ + δq

τ ∂²_t δq + ∂_t δq = D₀ φ'(q₀) ∇²δq = -D₀ |φ'(q₀)| ∇²δq

（因为φ' < 0）

### 3.2 频散关系

设δq ∝ e^{i(kx - ωt)}:
-τ ω² - iω + D₀ |φ'(q₀)| k² = 0

解:
ω = [-i ± √(-1 + 4τ D₀ |φ'(q₀)| k²)] / (2τ)

**两个传播区间:**

| 波数区间 | 条件 | ω行为 |
|---------|------|-------|
| 长波（小k） | 4τD₀|φ'|k² < 1 | ω纯虚数→扩散主导（衰减，无传播） |
| 短波（大k） | 4τD₀|φ'|k² > 1 | ω有实部→传播+衰减 |

**长波极限 (k→0):** ω ≈ -i D₀|φ'|k²（纯扩散，与一阶方程一致）
**短波极限 (k→∞):** ω ≈ ±√(D₀|φ'|/τ) k - i/(2τ)

### 3.3 传播速度

短波极限的相速度:
```
v_phase = √(D₀ |φ'(q₀)| / τ)
```

代入 D₀ = α a c 和 τ = τ₀/2 = a/(2c):
```
v_phase = √(2α c² |φ'(q₀)|) = c · √(2α |φ'(q₀)|)
```

### 3.4 波速=c的约束

要求真空(q₀→1)中引力波以c传播:
```
v_phase(q₀=1) = c · √(2α |φ'(1)|) = c
→ 2α |φ'(1)| = 1
→ α = 1/(2|φ'(1)|)
```

**对于φ(q)=1/q:** |φ'(1)| = 1 → **α = 1/2**
**对于φ(q)=-ln q:** |φ'(1)| = 1 → **α = 1/2**

在两种情况下，α=1/2是波速=c的条件。

### 3.5 q依赖的波速

对于φ(q)=1/q: v_phase(q) = c / q
对于φ(q)=-ln q: v_phase(q) = c / √q

**关键预言: 引力波在q小的区域（近大质量）传播更快。**

对φ=1/q: 在q=0.5处 v=2c — 超光速！❌

这似乎有问题。但注意：短波近似的有效条件是 4τD₀|φ'(q)|k² > 1，即k > 1/√(4τD₀|φ'(q)|) = 1/(2a)。这要求波长小于2a（两个格点间距）——在连续极限下不成立。

**实际物理波长远大于格点间距，所以在物理相关的k区间，波行为是扩散主导的。**

## 4. 物理引力波：两体合并

### 4.1 场景设定

两个大质量区域（各q≈0）相互环绕并最终合并。q场如何动态响应？

### 4.2 定性分析

合并前：两个q≈0的"核"由q≈1的区域隔开。两者各自有局域静态解。

合并过程：两个核接近，中间q场受挤压。在Telegraph方程下，局域q的变化以有限速度传播出去。

合并后：单核的q场弛豫到新的静态解。弛豫过程产生向外传播的q场扰动。

### 4.3 传播机制

在Telegraph方程框架下，q场的扰动以两种模式传播：
1. **扩散尾（低频/长波）:** 瞬时传播但幅度指数衰减。主导远场。
2. **波前（高频/短波）:** 以约c的速度传播。主导近场。

引力波探测器（LIGO）测到的是波前——高频振荡以c传播。这对应Telegraph方程的短波区间。

## 5. 诚实评估

### 5.1 已确立的

| 陈述 | 状态 |
|------|------|
| 一阶DGF方程(抛物型)不能描述引力波 | ✅ 数学事实 |
| 离散动力学的二阶Taylor项产生∂²_t q | ✅ 严格推导（给定ansatz） |
| Telegraph方程有波解 | ✅ 经典结果 |
| 波速可以校准到c | ✅ 通过选择α=1/2 |
| 二阶项不是ad-hoc | ✅ 来自离散动力学的固有结构 |

### 5.2 问题

| 问题 | 严重度 |
|------|--------|
| q依赖的波速在q小时可能超c | ⚠️ 物理波长远大于a时扩散主导，波前效应只在格点尺度显著 |
| Telegraph方程仍是现象学的 | ⚠️ 从ansatz导出，不是A1+A2定理 |
| 两体合并的定量预测缺失 | ⚠️ 需要数值模拟 |
| 引力波振幅（h ~ 10⁻²¹）的DGF对应量 | ⚠️ 未建立q↔h的映射 |

### 5.3 底线

**DGF可以"容纳"引力波**（通过保留离散动力学的二阶项→Telegraph方程），但：

1. 波的传播速度需要校准（α=1/2）——这是建模选择，不是推导
2. DGF的引力波在**长波极限（物理相关）是扩散主导的**——信号衰减极快
3. DGF不能**预测**引力波的具体波形或振幅——只能定性地"允许"波存在
4. **与LIGO观测的定量对比是不可能的**——DGF缺少数值预测能力

**引力波对DGF是一个"可以容纳但不解释"的现象**，类似于DGF对Bekenstein界的处理（Theorem 5: compatibility not derivation）。

## 6. 与问题1的协同

问题1和问题2的共同指向:
1. DGF需要**二阶时间项**才能与GR的"有限传播速度特征"对接（问题2→Telegraph方程）
2. DGF的**一阶近似**在弱场/长时间极限下有效（问题1→一阶时间膨胀匹配GR）
3. 二阶项在问题1（时间膨胀二阶）和问题2（波速）中都出现，且都在τ₀/2量级

**这构成了一个自洽图景:** DGF的一阶动力学在弱场/长时极限恢复GR的表象，二阶修正揭示与GR的本质偏离。
