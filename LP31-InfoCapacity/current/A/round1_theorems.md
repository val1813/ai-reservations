## 前置定义

### 信息系统 (Information System)

一个信息系统是一个对 S = (X, f)，其中：

- **状态空间**: X = {0,1}^N。N 个二元细胞 (cells)，每个细胞状态 s_i ∈ {0,1}。
  - 0 = 未占用 (unoccupied)
  - 1 = 已占用 (occupied)
- **动力学映射**: f: X → X，满足两个公理。

### 公理 A1: 可区分性 (Distinguishability)

```
∀s, s' ∈ X:  s ≠ s'  ⇒  f(s) ≠ f(s')
```

等价的数学表述: f 是**单射** (injective)。

物理含义: 不同的微观状态在演化后仍然不同——系统不会"混淆"两个不同的状态。信息不会丢失。

### 公理 A2: 容量有界 (Bounded Capacity)

```
|X| = 2^N < ∞
```

X 是有限集。信息系统的容量是 N bits（每个细胞携带最多 1 bit 信息）。

### 宏观变量

定义 **未占用细胞比例**:

```
q(s) = (N - Σ_i s_i) / N
```

其中 Σ_i s_i 是占用细胞的总数（Hamming 重量）。

## 定理 1: 信息守恒 (Information Conservation)

### 完整陈述

> **定理 1**: 对任何满足 A1 + A2 的信息系统 S = (X, f)：
>
> **(a)** f 是双射 (bijection)，即 f 是 X 上的置换。
>
> **(b)** 状态可区分性双向保持: s ≠ s' ⇔ f(s) ≠ f(s')。
>
> **(c)** 对 X 上的任意概率分布 p，Shannon 熵 H(p) 在 f 下守恒:
>   H(f ∘ p) = H(p)，其中 (f ∘ p)(y) = p(f⁻¹(y))。
>
> **(d)** 信息容量上界 N bits 守恒，最大熵分布为均匀分布。
>
> **(e)** 宏观变量 Σ_i s_i（总占用细胞数）**不**由 A1+A2 保证守恒。
>   需额外公理 A3（占用数守恒）。

---

### T1a: 双射性 —— 严格证明

**前提**:
1. f: X → X 是单射 (A1)
2. |X| = 2^N < ∞ (A2)

**证明**:

单射 f: X → X 将不同的输入映射到不同的输出，因此 |f(X)| = |X| = 2^N。

因为 f(X) ⊆ X 且 |f(X)| = |X| < ∞，由集合论的鸽巢原理 (Pigeonhole Principle)，f(X) = X。

因此 f 是满射 (surjective)。既单且满 ⇒ f 是双射。∎

**引用**: Dirichlet (1834), Pigeonhole Principle.

**前提清单**:
- [显式] A1 (单射)
- [显式] A2 (有限)
- [隐藏] 无

**严格性**: ★★★★★ (完全严格)

---

### T1b: 可区分性双向守恒 —— 严格证明

正向 (⇒) 即 A1。

反向 (⇐): 假设 f(s) ≠ f(s')。若 s = s'，则 f(s) = f(s')（因为 f 是函数），矛盾。因此 s ≠ s'。

等价地，由于 f 是双射 (T1a)，f⁻¹ 存在且也是双射。对 f⁻¹ 应用 A1：
若 f(s) ≠ f(s')，将 A1 应用于 f⁻¹ 得到 f⁻¹(f(s)) ≠ f⁻¹(f(s'))，即 s ≠ s'。∎

**前提清单**:
- [显式] A1
- [显式] T1a (双射性)

**严格性**: ★★★★★ (完全严格)

---

### T1c: Shannon 熵守恒 —— 严格证明

**定义**: 对 X 上的概率分布 p，Shannon 熵为:
```
H(p) = -Σ_{x∈X} p(x) log p(x)
```
（底数任意，通常取 2 使单位为 bits。）

**推前分布**: (f ∘ p)(y) = Σ_{x: f(x)=y} p(x) = p(f⁻¹(y))（因为 f 是双射，f⁻¹(y) 是唯一的）。

**证明**:
```
H(f ∘ p) = -Σ_{y∈X} (f ∘ p)(y) log (f ∘ p)(y)
         = -Σ_{y∈X} p(f⁻¹(y)) log p(f⁻¹(y))
```

作变量替换 x = f⁻¹(y)。由 T1a，f 是双射，因此 f⁻¹: X → X 是 X 上的置换。求和变换是合法的：
```
         = -Σ_{x∈X} p(x) log p(x)
         = H(p)
```
∎

**前提清单**:
- [显式] T1a (双射性，保证 f⁻¹ 是良定义的置换)
- [隐藏] 无（离散分布无需 Jacobian 修正）

**引用**: Shannon (1948), Theorem 2; Cover & Thomas (2006), §2.1.

**严格性**: ★★★★★ (完全严格)

---

### T1d: 信息容量守恒 —— 严格证明

信息容量定义为状态空间基数的对数：C(S) = log₂|X| = N bits。

由 T1a，f 是 X 上的置换，不改变 |X| = 2^N。因此 C(S) = N bits 在 f 下不变。

最大熵分布为均匀分布 u(x) = 1/|X|，H(u) = log₂|X| = N bits。
由 T1c，H(u) 守恒。

**前提清单**:
- [显式] T1a (双射性)
- [隐藏] "信息容量 = log₂|状态数|"是 Shannon 的定义性约定，不依赖系统的物理实现

**严格性**: ★★★★★ (完全严格)

---

### T1e: Σs_i 不守恒 —— 构造性反例

**声称**: 仅有 A1 + A2 **不能**推出 ∀s: Σ_i s_i = Σ_i f(s)_i。

**构造反例** (N = 2):

状态空间 X = {00, 01, 10, 11}，|X| = 4。

定义 f 为循环置换:
```
f(00) = 01   (Σs=0 → Σs=1)
f(01) = 10   (Σs=1 → Σs=1)
f(10) = 11   (Σs=1 → Σs=2)
f(11) = 00   (Σs=2 → Σs=0)
```

**验证 A1**: f 是 4-循环 ⇒ 是置换 ⇒ 是单射。✓

**验证 A2**: |X| = 4 < ∞。✓

**验证 Σs_i 不守恒**: 轨迹 (00 → 01 → 10 → 11 → 00)，占用数序列为 0 → 1 → 1 → 2 → 0，不是常数。∎

**结论**: Σs_i 守恒需要额外的物理公理:

> **公理 A3 (占用数守恒 / Occupation Number Conservation)**:
> ∀s ∈ X: Σ_i s_i = Σ_i f(s)_i。
>
> 等价表述: f 保持 Hamming 重量。在物理学中对应粒子数守恒或能量守恒。

**前提清单 (反例)**:
- [显式] 构造的 f 是置换（满足 A1）
- [显式] N=2（满足 A2）
- [隐藏] 无

**严格性**: ★★★★★ (构造性反例，完全严格)

| T1a: f 是双射 | ★★★★★ | 无 |
| T1b: 可区分性双向 | ★★★★★ | 无 |

## 定理 2: 粗粒化熵增 (Coarse-Grained Entropy Increase)

### 完整陈述

> **定理 2**: 对满足 A1+A2 的信息系统 S=(X,f)，定义粗粒化映射 π(s)=q 和宏观熵泛函 S[p]。
>
> **(a)** Gibbs 熵 S_G 守恒；宏观熵的变化等于纤维内 KL 散度的变化:
>   S[p'] - S[p] = D[ρ'] - D[ρ]。
>
> **(b) 条件性第二定律**: 若初始分布在纤维内均匀 (D[ρ]=0)，则 S[p'] ≥ S[p]。
>
> **(c)** 在随机置换系综下，期望转移概率为 π_q' = Ω(q')/2^N，
>   系统在期望意义上向高熵宏观态演化。
>
> **(d)** 大 N 下，熵减概率指数地小（涨落界）。

---

### 定义

**粗粒化映射**:
```
π: X → Q = {0, 1/N, 2/N, ..., 1}
π(s) = q = (N - Σ_i s_i) / N
```

**纤维 (Fiber)**:
```
π⁻¹(q) = {s ∈ X : π(s) = q}
Ω(q) = |π⁻¹(q)| = C(N, N(1-q))
```
其中 C(n,k) = n!/(k!(n-k)!) 是二项式系数。

**宏观熵泛函** (一个概率分布 p 在 Q 上的熵):
```
S[p] = H(p) + ⟨log Ω⟩_p
     = -Σ_q p(q) log p(q) + Σ_q p(q) log Ω(q)
```
第一项是宏观变量 q 的 Shannon 熵，第二项是平均 Boltzmann 熵（宏观态体积的对数期望）。

**Gibbs 熵** (微观分布 ρ 在 X 上的熵):
```
S_G[ρ] = -Σ_{s∈X} ρ(s) log ρ(s)
```

**纤维内 KL 散度**:
```
D[ρ] = Σ_q p(q) · D_KL(ρ(·|q) ‖ u_q)
```
其中 u_q 是纤维 π⁻¹(q) 上的均匀分布 u_q(s) = 1/Ω(q)，ρ(·|q) = ρ(s)/p(q)（s ∈ π⁻¹(q)）。

---

### T2a: 熵差恒等式 —— 严格证明

**定理**: S[p'] - S[p] = D[ρ'] - D[ρ]。

**证明**:

**步骤 1**: 将 Gibbs 熵按纤维分解。

对 s ∈ π⁻¹(q)，记 ρ(s) = p(q) · ρ(s|q)，其中 p(q) = Σ_{s∈π⁻¹(q)} ρ(s)。

```
S_G[ρ] = -Σ_q Σ_{s∈π⁻¹(q)} p(q) ρ(s|q) [log p(q) + log ρ(s|q)]
       = -Σ_q p(q) log p(q) · Σ_{s∈π⁻¹(q)} ρ(s|q)
         - Σ_q p(q) Σ_{s∈π⁻¹(q)} ρ(s|q) log ρ(s|q)
```

第一个求和: Σ_{s∈π⁻¹(q)} ρ(s|q) = 1（条件分布归一化），因此第一项 = H(p)。

第二个求和: 令 S(ρ(·|q)) = -Σ_{s∈π⁻¹(q)} ρ(s|q) log ρ(s|q) 为纤维 q 上的条件熵。

```
S_G[ρ] = H(p) + Σ_q p(q) S(ρ(·|q))
```

**步骤 2**: 将条件熵 S(ρ(·|q)) 与均匀分布关联。

```
S(ρ(·|q)) = -Σ_s ρ(s|q) log ρ(s|q)
           = -Σ_s ρ(s|q) [log u_q(s) + log(ρ(s|q)/u_q(s))]
           = -Σ_s ρ(s|q) log(1/Ω(q)) - Σ_s ρ(s|q) log(ρ(s|q)/u_q(s))
           = log Ω(q) - D_KL(ρ(·|q) ‖ u_q)
```

代入步骤 1:
```
S_G[ρ] = H(p) + Σ_q p(q) [log Ω(q) - D_KL(ρ(·|q) ‖ u_q)]
       = S[p] - D[ρ]
```

**步骤 3**: 利用 Gibbs 熵守恒。

由 T1a，f 是双射。由 T1c，对任意分布 ρ，S_G[f ∘ ρ] = S_G[ρ]。

记 ρ' = f ∘ ρ，p' 为 ρ' 的宏观分布。

```
S_G[ρ'] = S_G[ρ]
⇒ S[p'] - D[ρ'] = S[p] - D[ρ]
⇒ S[p'] - S[p] = D[ρ'] - D[ρ]
```
∎

**前提清单**:
- [显式] T1a (双射)
- [显式] T1c (熵守恒)
- [隐藏] 无（纯代数恒等式）

**引用**: Gibbs (1902), Ch.XII; 现代处理见 Cover & Thomas (2006) §2.3, 或 Balian (1991) *From Microphysics to Macrophysics*.

**严格性**: ★★★★★ (完全严格——这是一个恒等式，不等号尚未出现)

---

### T2b: 条件性第二定律 —— 严格证明

**定理**: 若 D[ρ] = 0（初始分布在每个纤维内均匀），则 S[p'] ≥ S[p]。

**证明**:

由 T2a，S[p'] - S[p] = D[ρ'] - D[ρ] = D[ρ']（因为 D[ρ] = 0）。

D[ρ'] 是 KL 散度的凸组合。KL 散度非负（Gibbs 不等式）:
```
D_KL(P ‖ Q) ≥ 0，等式当且仅当 P = Q 时成立。
```
因此 D[ρ'] ≥ 0 ⇒ S[p'] ≥ S[p]。∎

**前提清单**:
- [显式] T2a (恒等式)
- [显式] D[ρ] = 0（纤维内均匀初始化——**这是一个关于初始条件的统计假设**）
- [隐藏] 无

**引用**: Gibbs 不等式 (Cover & Thomas, Theorem 2.6.3).

**严格性**: ★★★★☆ (数学严格，但 D[ρ] = 0 的前提不是 A1+A2 的推论)

### T2c: 随机置换系综下的期望熵增 —— 证明草图

**定义**: 令 S_{2^N} 为 X 上所有置换（双射）的对称群。考虑均匀测度在 S_{2^N} 上——即 f 是从所有可能的置换中均匀随机选取的。

**引理**: 对任意固定子集 A, B ⊆ X，在随机 f 下:
```
E_f[|f(A) ∩ B|] = |A| · |B| / |X|
```
这是经典结果：大小为 |A| 的随机子集（f(A)）与固定子集 B 的交的期望大小。

**证明**: 对每个 x ∈ A，f(x) 在 X\{f(x'): x'∈A, x'≠x} 上是均匀的。但更简单: 令指示变量 I_{x∈A, f(x)∈B}。由于 f 是均匀随机置换，P(f(x)∈B) = |B|/|X|（对任何 x）。因此 E[I] = |B|/|X|。对 |A| 个 x 求和得 E[|f(A)∩B|] = |A|·|B|/|X|。∎

**期望转移概率**:

取 A = π⁻¹(q) = M_q, B = π⁻¹(q') = M_{q'}:
```
E_f[W(q'|q)] = E_f[|f(M_q) ∩ M_{q'}|] / |M_q|
             = (|M_q| · |M_{q'}| / 2^N) / |M_q|
             = |M_{q'}| / 2^N
             = Ω(q') / 2^N
```
这是关键结果：期望转移概率**独立于出发宏观态 q**，仅依赖于目标宏观态的体积比重 π_{q'} = Ω(q')/2^N。

**推论**: E_f[W] 是秩 1 矩阵，每行相同（＝稳态分布 π）。因此:
```
E_f[p'] = E_f[W p] = E_f[W] · p = π · (Σ_q p(q)) = π
```
无论初始分布 p 是什么，一步后的期望宏观分布就是稳态分布 π。

**熵的比较**: 由于 π 是 S[p] 的全局极大值点（在约束 Σ p(q)=1 下，S[p] 被最大化当 p ∝ Ω），我们有 S[π] ≥ S[p]。但 E_f[S[p']] ≥ S[p] 需要 Jensen 处理的附加论证（因为熵 S 是凹函数，E[S] ≤ S(E[·])，方向反了）。

**弱版本（但严格）**: 定义线性熵 H_lin[p] = 1 - Σ p(q)²。H_lin 关于 p 是凸函数，因此 E[H_lin[p']] ≥ H_lin[E[p']] = H_lin[π] ≥ H_lin[p]。线性熵在期望下非递减是严格成立的。

**强版本的论证（大 N）**: 当 N 大时，p' 集中在 E[p'] = π 附近（由集中不等式），Jensen 的偏差可忽略。

**引用**: Cover & Thomas (2006), Theorem 2.7.1（双随机矩阵 → H(p) 非递减）。虽然 E[W] 是双随机的（秩1矩阵，行列和均为1），但每次实现 W_f 不一定双随机。

**前提清单**:
- [显式] 随机置换系综（均匀测度在 S_{2^N} 上）——这是统计假设
- [隐藏] 强版本需大 N 或集中不等式

**严格性**: ★★★☆☆ (统计假设 + 技术性 Jensen 问题)

### T2d: 大 N 涨落界 —— 证明草图

**Stirling 近似**:
```
Ω(q) = C(N, N(1-q))
ln Ω(q) = N H₂(q) - (1/2)ln(2πN q(1-q)) + O(1/N)
```
其中 H₂(q) = -q log₂ q - (1-q) log₂(1-q) 是二元熵函数（底 2）。

**集中不等式**: 对固定 q, q'，随机变量 |f(M_q) ∩ M_{q'}| 服从超几何分布（不放回抽样）:
- 总体大小: 2^N
- 成功数: |M_{q'}|
- 抽样数: |M_q|
- 均值: μ = |M_q|·|M_{q'}|/2^N

由 Hoeffding (1963) 超几何界:
```
P(| |f(M_q)∩M_{q'}|/|M_q| - π_{q'}| > δ) ≤ 2 exp(-2|M_q| δ²)
```

当 |M_q| 足够大时（即 q 不接近 0 或 1），这个界非常紧。

**熵减概率**: 熵减 S[p'] ≤ S[p] - Nε 要求大量转移概率同时偏离期望。联合概率受限于多重 Hoeffding 界。净结果是:
```
P(S[p'] ≤ S[p] - NΔ) ≤ exp(-c(ε) N)
```
其中 c(ε) > 0 当 ε > 0。

**边界处理**: q ≈ 0 或 q ≈ 1 的纤维很小（|M_q| = C(N, 0) = 1 或 C(N, 1) = N），集中不等式退化。但对于这些边界态，熵 H₂(q) ≈ 0，熵减的空间本来也很小。它们在 N 大时对总概率的贡献指数地小。

**引用**: Hoeffding (1963); Ellis (1985) *Entropy, Large Deviations, and Statistical Mechanics*.

**前提清单**:
- [显式] N >> 1 (大 N 渐近)
- [显式] 随机系综
- [隐藏] 集中不等式仅对非退化纤维有效

**严格性**: ★★★☆☆ (数学物理级别的证明草图; 完整严格化需 ~20 页)

|--------|--------|-------------|
| T2a: 熵差恒等式 | ★★★★★ | 无 |
| T2b: 条件第二定律 | ★★★★☆ | D[ρ]=0 (初始均匀) |
| T2c: 期望熵增 | ★★★☆☆ | 随机系综 + Jensen |

**核心贡献**: T2 澄清了第二定律的逻辑结构。宏观熵 S[p] 的变化**完全等于**纤维内 KL 散度的变化。第二定律是 (A1+A2) + (纤维内均匀化假设) 的推论，而非 (A1+A2) 的纯粹演绎。这与 Boltzmann 的原始论证一致：H-定理需要 Stosszahlansatz（分子混沌假设）。

**重要诚实标注**: 如果论文声称"从 A1+A2 演绎出必然的熵增"，这在数学上是错误的。正确的表述是"从 A1+A2 可得: S[p'] - S[p] = D' - D。在标准统计力学假设 (D=0, D'≥0) 下，第二定律成立。"

## 定理 3: 容量比 → 实践不可逆性 (Capacity Ratio → Practical Irreversibility)

### 完整陈述

> **定理 3**: 将 N 个细胞划分为系统 (N_S cells) 和环境 (N_E cells)，N_S + N_E = N。
> 对满足 A1+A2 的信息系统 S=(X,f):
>
> **(a) Kac 回复时间**: 系统状态 s_S^* 的平均 Poincaré 回复时间精确为 2^{N_S}，与 N_E 无关。
>
> **(b) 宏观偏倚**: 在随机系综下，系统宏观跃迁的相对概率仅由系统自身的组合结构决定:
>   E[W(k→k')] / E[W(k'→k)] = C(N_S, k') / C(N_S, k)。
>
> **(c) 关联稀释**: 信息从系统流入环境后，在环境巨大态空间中被"稀释"。
>
> **(d) 实践不可逆性**: 对 N_S ~ 100，回复时间 2^{100} ~ 10^{30} >> 宇宙年龄。
>   在任何实际观测时间 T_obs 内，信息返回概率 P_return ≈ T_obs / 2^{N_S} ≈ 0。

### 定义

**系统-环境划分**:
```
X = X_S × X_E,  其中 X_S = {0,1}^{N_S}, X_E = {0,1}^{N_E}
|X_S| = 2^{N_S}, |X_E| = 2^{N_E}
```

**系统投影**:
```
Π_S: X → X_S,  Π_S(s, e) = s
```

**宏观占用数**:
```
系统占用: k = Σ_{i∈S} s_i ∈ {0, 1, ..., N_S}
环境占用: m = Σ_{i∈E} s_i ∈ {0, 1, ..., N_E}
总占用: K = k + m ∈ {0, 1, ..., N}
```

**系统宏态**:
```
M_k = {x ∈ X : Σ_{i∈S} x_i = k}
|M_k| = C(N_S, k) · 2^{N_E}
```

### T3a: Kac 回复时间 —— 严格证明

**定义** (Poincaré 回复时间): 对子集 A ⊆ X，A 的回复时间 τ_A: A → ℕ∪{∞} 定义为:
```
τ_A(x) = min{t ≥ 1 : f^t(x) ∈ A}
```
（首次返回 A 的时间，排除 t=0。）

**Kac 引理**: 对保测动力系统 (X, ℬ, μ, f)，其中 μ 是 f-不变概率测度，对任意可测集 A ⊆ X 满足 μ(A) > 0，有:
```
∫_A τ_A(x) dμ(x) = 1 - μ(A)
```
或等价地:
```
E_μ[τ_A | A] = 1 / μ(A)   (条件期望)
```

**应用到信息系统**:

取 μ 为 X 上的均匀计数测度: μ(B) = |B| / 2^N（对任意 B ⊆ X）。

f 是双射 (T1a) ⇒ f 保持计数测度 ⇒ μ 是 f-不变的。

取 A_{s_S^*} = {s_S^*} × X_E（所有环境配置与特定系统状态 s_S^* 的组合）:
```
μ(A_{s_S^*}) = |A_{s_S^*}| / 2^N = 2^{N_E} / 2^{N_S+N_E} = 2^{-N_S}
```

由 Kac 引理:
```
E_μ[τ_A | A] = 1 / μ(A) = 2^{N_S}
```
∎

**讨论**: 回复时间的期望精确为 2^{N_S}，不依赖于 N_E。这是一个反直觉的结果：无论环境多大或多小，系统状态的平均回复时间只由系统自身的自由度决定。

**前提清单**:
- [显式] T1a (双射性，保证 μ 的 f-不变性)
- [显式] 均匀初始测度 μ
- [隐藏] Kac 引理要求 (X, μ, f) 是保测系统——f 双射 + 均匀 μ 保证了这一点

**引用**: Kac (1947), *On the notion of recurrence in discrete stochastic processes*, Bull. AMS 53.

**严格性**: ★★★★★ (完全严格，群论+测度论)

### T3b: 系统宏观跃迁的熵偏倚 —— 严格证明

**定理**: 设 f 从 S_{2^N} 中均匀随机选取。则系统宏观态间的期望转移概率比为:
```
E_f[W(k → k')]
──────────────  =  C(N_S, k') / C(N_S, k)
E_f[W(k' → k)]
```
该比值**独立于 N_E**。

**证明**:

由 T2c 的引理:
```
E_f[W(k'|k)] = E_f[|f(M_k) ∩ M_{k'}|] / |M_k|
             = (|M_k| · |M_{k'}| / 2^N) / |M_k|
             = |M_{k'}| / 2^N
             = C(N_S, k') · 2^{N_E} / 2^{N_S + N_E}
             = C(N_S, k') / 2^{N_S}
```

注意 N_E 被约去了。因此:
```
E_f[W(k → k')]    C(N_S, k') / 2^{N_S}    C(N_S, k')
────────────── = ───────────────────── = ───────────
E_f[W(k' → k)]    C(N_S, k) / 2^{N_S}      C(N_S, k)
```
∎

**物理解释**: 在随机双射系综下，系统宏观跃迁的相对偏好完全由系统自身的组合结构决定，环境只通过总容量 2^N 影响绝对速率（速率 ∝ 2^{-N_S}）。

**前提清单**:
- [显式] 随机置换系综
- [隐藏] 绝对速率 ∼ 2^{-N_S}（对较大的 N_S，绝对跃迁速率极慢——但这不影响相对偏好）

**严格性**: ★★★★★ (组合恒等式，完全严格)

### T3c: 关联稀释 —— 证明草图

**定理** (信息流出): 设 f 满足 k-局部性（每个细胞的新状态只依赖于最多 c 个旧状态细胞）。初始时信息编码在系统的 k 个占用细胞内。t 步后，这些细胞的因果影响范围 ≤ c^t 个细胞。与环境的互信息 I(S_t; E_0) 不增长到该范围之外。

**证明草图**:

定义第 t 步受初始信息影响的细胞集 V_t。|V_0| = k。由 c-局部性:
```
|V_{t+1}| ≤ c · |V_t|
⇒ |V_t| ≤ c^t · k
```

在 t 步时，系统细胞 S_t 的状态只依赖于 V_t 中的初始状态（因果锥）。互信息 I(S_t; E_0) 的上界为:
```
I(S_t; E_0) ≤ I(S_t; V_t ∩ E_0) ≤ H(S_t) ≤ min(N_S, |V_t ∩ E_0|) · log 2
```

其中 |V_t ∩ E_0| 是 V_t 与环境初始细胞 E_0 的交集。

若 V_t ∩ E_0 = ∅（初始影响范围尚未到达环境），则系统状态仅依赖于自身初始状态，I(S_t; E_0) = 0。

一旦 V_t ∩ E_0 ≠ ∅，系统状态开始依赖环境初始状态，关联产生。

关联稀释的方向: 当 t 进一步增大，系统状态 S_t 依赖越来越多的初始细胞（包括系统和环境），单个初始细胞对 S_t 的影响被"稀释"。形式化需要互信息的下界论证。

**关键时间尺度**:
- 关联建立时间: t_est ~ log_c(N_E/k)（因果锥覆盖环境细胞的时间）
- 关联饱和时间: t_sat ~ N_E（环境所有细胞都进入因果锥）
- 对于 c=O(1) 和 N_E = 10^3，t_est ~ 10，t_sat ~ 1000

**引用**: Data Processing Inequality (Cover & Thomas §2.8); causal graph information bounds (Pearl 2009).

**前提清单**:
- [显式] c-局部性（细胞状态依赖的局域性）
- [显式] 信息初始在系统中
- [隐藏] 因果锥的分析假定 f 的依赖结构是"有向无环"的或类似的图性质

**严格性**: ★★★☆☆ (方向正确但未完全严格化；完整证明需要图论+信息论链条)

### T3d: 实践不可逆性 —— 严格论证

**定理**: 对典型 f 和 N_S ≳ 100，在任何实际观测时间 T_obs（包括宇宙年龄 ∼ 10^18 秒 ∼ 10^60 普朗克时间）内，已流入环境的信息返回系统的概率可忽略: P_return ≲ T_obs / 2^{N_S}。

**证明**:

**步骤 1: 回复时间的分布**。

由 T3a，E[τ] = 2^{N_S}。对"典型"f（具有混合性质的 f），τ 近似服从几何/指数分布（Kac 的渐近结果）:
```
P(τ > t | A) ≈ exp(-t / 2^{N_S})  对 t << 2^{2N_S}
```

**步骤 2: 观测窗口内的返回概率**。
```
P_return(T_obs) = P(τ ≤ T_obs)
                = 1 - P(τ > T_obs)
                ≈ 1 - exp(-T_obs / 2^{N_S})
                ≈ T_obs / 2^{N_S}    (对 T_obs << 2^{N_S})
```

**步骤 3: 数值评估**。

| N_S | 2^{N_S} | T_obs=10^9 | T_obs=10^60 |
|-----|---------|------------|-------------|
| 10  | 1,024   | ∼1 (100%)  | ∼1 (100%)  |
| 50  | 1.1×10^15 | ∼10^{-6} | ∼1 (100%)  |
| 100 | 1.3×10^30 | ∼10^{-21} | ∼10^{-30}  |
| 200 | 1.6×10^60 | ∼10^{-51} | ∼1 (100%)  |
| 300 | 2.0×10^90 | ∼10^{-81} | ∼10^{-30}  |

对 N_S ≥ 100，在 10^9 步内的返回概率小于 10^{-21}。即使以普朗克时间（~10^{-43} 秒）为步长，宇宙年龄内也只能完成 ~10^60 步。对 N_S ≥ 200，即使在宇宙年龄内返回概率也可忽略。

**步骤 4: 即使不使用指数近似，也有 Chebyshev 界**。

由 Markov 不等式（仅需 E[τ] = 2^{N_S}，不需要分布假设）:
```
P(τ ≤ T_obs) = P(τ ≤ T_obs) ≤ T_obs / E[τ]? 不——Markov给出上界P(τ≥a)≤E[τ]/a。

实际上: P(τ > T_obs) ≥ ? Markov不等式给出了上界，我们需要下界。
更好的方法: P(τ ≤ T_obs) ≤ 1 - (2^{N_S} - T_obs)/2^{N_S} = T_obs/2^{N_S}?
不对——对于τ是无记忆的指数分布这是对的，但对一般分布不是。
```

实际上，仅由 E[τ] = 2^{N_S} 不能推出 P(τ ≤ T_obs) ≤ T_obs/2^{N_S}。考虑反例: f = 恒等映射，则 τ(x) = 1 对所有 x（总是立即返回），但 E[τ] = 1 ≠ 2^{N_S}（Kac 引理不适用因为 μ 不是遍历的）。

对于遍历的（遍历的）f，Kac 引理结合 Birkhoff 遍历定理可给出更强的界。但对于一般的双射 f，需要遍历性或混合性假设。

**诚实标注**: 对**所有**双射 f，仅能说"存在某些初始状态，其回复时间 ≤ 2^{N_S}"（由 Kac 引理）。对"典型"f（具有较好混合性质的），大多数初始状态有指数分布的回复时间，此时上述分析成立。

**引用**: Kac (1947); Boltzmann (1896) 对 Zermelo 回复悖论的回应; Penrose (1979) *Foundations of Statistical Mechanics*, Rep. Prog. Phys. 42.

**前提清单**:
- [显式] T3a (Kac 回复时间)
- [显式] f 具有混合性（或至少遍历性）
- [显式] N_S ≥ 100（使 2^{N_S} 远超任何实际观测时间）
- [隐藏] 回复时间指数分布需要 f 具有足够强的混合性质

**严格性**: ★★★★☆ (Kac 引理严格；指数分布的假设影响数值精确度但不影响数量级结论)

### T3 补充: N_E/N_S 比率的真正作用

读者可能注意到 T3a-T3b 的结果与 N_E 无关。那么 N_E/N_S 的作用是什么？

**N_E/N_S 决定的是混合速率，而非回复时间**。

类比: 一杯热咖啡（系统，N_S ∼ 10^25 分子）放在一个房间里（环境，N_E ∼ 10^28 分子）。N_E/N_S ∼ 1000。

- Poincaré 回复时间: ∼ exp(10^25) 步（不可观测）
- 但同时: 弛豫时间（咖啡冷却到室温）∼ 10^3 秒
- N_E 越大 ⇒ 环境热容量越大 ⇒ 作为热浴越"刚性"(stiff)，不易被系统加热 ⇒ 弛豫越彻底

在大 N_E 极限下:
- 环境对系统呈现"无限热浴"行为
- 系统向平衡态的弛豫是指数的
- 一旦弛豫，系统在平衡态附近的涨落由涨落-耗散定理描述
- 回复时间虽然有限 (2^{N_S})，但远超实际时间尺度

**信息流动的不可逆性的本质**:
- 信息流入环境 → 环境态空间巨大 → 信息被"编码"在指数多个环境自由度的关联中
- 要恢复信息，需要环境自发地将这些关联"聚焦"回系统
- 这需要指数多自由度的精确协调 — 概率 ∼ exp(-const · N_E)
- 当 N_E ≫ N_S，这在实际上是不可逆的

这与 Landauer 原理的热力学不可逆性不同（那涉及能量耗散），但精神一致：不可逆性根源于大自由度环境中的"信息稀释"。

### 对LP30的反刍

LP30 的"吸引子定理"声称从 A1+A2 可推出宏观量收敛到某个"吸引子"。本工作表明:

1. **A1+A2 不保护任何特定宏观量**: T1e 的反例证明 Σs_i（或任何非平凡的宏观量）不必然守恒，更不用说收敛到吸引子。

2. **熵增是统计的，非逻辑的**: T2a 表明熵的变化 = 纤维内 KL 散度的变化。第二定律需要额外的统计假设（纤维内均匀化），不能从 A1+A2 演绎。

3. **不可逆性是实践的，非逻辑的**: T3d 表明信息可以回来（数学上），只是在任何实际时间内不会（概率上）。这与 Boltzmann 对 Zermelo 的回复正是同一论证。
