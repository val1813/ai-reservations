## 0. 为什么薛定谔而非Born

```
Born:   ψ → |ψ|² = P    （丢相位，得概率）
Schrödinger: ψ → iℏ∂_tψ = Hψ  （保相位，得动力学）
```

DGF有相位（θ = 2πn/T）→ 相位是框架的自然量 → 推薛定谔是推"相位如何随时间演化"。

Born规则是测量的故事——因果锁定后的事。薛定谔是演化的故事——锁定的故事。

## 1. 从A1+A2到因果路径的相位演化

### 1.1 单条因果路径

A1 → 因果路径存在。每条路径是一系列因果事件:

```
路径j: x₀ → x₁ → x₂ → ... → x_n
```

n = 路径经历的因果事件数。

A2 → 状态空间有限(|X|=2^N) → f是置换 → 动力学周期T。

路径j在f的循环分解中属于长度为Lⱼ的循环。周期Tⱼ = Lⱼ。

### 1.2 相位积累

在每一步（一次f应用），路径j沿其循环前进1步。经过t步后:

```
nⱼ(t) = t                          [步数=因果事件数]
θⱼ(t) = 2π × nⱼ(t) / Lⱼ = ωⱼ t   [相位，ωⱼ = 2π/Lⱼ]
```

ωⱼ是路径j的特征角频率。

### 1.3 能量

在量子力学中，能量E和角频率的关系: Eⱼ = ℏωⱼ。

ℏ是作用量量子——每次因果事件携带的最小作用量。在DGF中，ℏ是A2的自然产物：A2说最小单元承载1 bit → 一次因果事件=一个最小作用量=ℏ。ℏ是单位约定（可以设为1），但保留它使公式与标准QM对齐。

**Eⱼ = ℏωⱼ = 2πℏ / Lⱼ:** 路径j的能量由其循环长度的倒数决定——循环越短（越频繁地回到初态），能量越高。

## 2. 多路径叠加

### 2.1 为什么叠加

q高的区域：容量未锁定 → 多个因果路径同时存在于系综中（宏观不确定性→同一(q,θ)对应多条可能的微观演化线）。

**叠加 = 系综包含来自多条因果路径的细胞。** 不是"一个系统同时在两条路径上"——是"系综里有的细胞来自路径A，有的来自路径B"。

### 2.2 态的定义

设系综中路径j的"权重"为pⱼ（支持该路径的细胞比例）。pⱼ ≥ 0，Σ pⱼ = 1。

定义"路径态":
```
|j⟩ = 路径j的标准化表示
```

系综态:
```
|ψ(t)⟩ = Σⱼ √pⱼ |j⟩ e^{-iωⱼt}
```

- √pⱼ: 路径权重的平方根（因为概率是振幅平方——我们定义了振幅=√概率）
- e^{-iωⱼt}: 路径的相位因子（负号是约定——相位随时间减少=顺时针旋转）
- |j⟩: 路径的"方向"（在状态空间中的特征向量）

**注意:** 这里用了复数e^{-iωⱼt}。但正如之前讨论的，这不是根本的——根本的是cos(ωt)和sin(ωt)（两个循环实数）。复数是为了紧凑。

## 3. 时间演化 → 薛定谔方程

### 3.1 时间导数

```
∂_t |ψ⟩ = ∂_t Σⱼ √pⱼ e^{-iωⱼt} |j⟩
        = Σⱼ √pⱼ (-iωⱼ) e^{-iωⱼt} |j⟩
        = -i Σⱼ ωⱼ √pⱼ e^{-iωⱼt} |j⟩
```

### 3.2 定义能量算符Ĥ

Ĥ是一个算符，其本征态为|j⟩，本征值为ℏωⱼ:

```
Ĥ|j⟩ = ℏωⱼ|j⟩ = Eⱼ|j⟩
```

Ĥ的物理含义: 路径j的能量（=路径循环频率×ℏ）。

Ĥ从f的循环结构直接读出: f的每个循环对应一个本征值ℏωⱼ=2πℏ/Lⱼ。

### 3.3 代入

```
∂_t |ψ⟩ = -i Σⱼ (Eⱼ/ℏ) √pⱼ e^{-iEⱼt/ℏ} |j⟩
        = -(i/ℏ) Σⱼ Eⱼ √pⱼ e^{-iEⱼt/ℏ} |j⟩
        = -(i/ℏ) Ĥ Σⱼ √pⱼ e^{-iEⱼt/ℏ} |j⟩
        = -(i/ℏ) Ĥ |ψ⟩
```

### 3.4 整理

```
iℏ ∂_t |ψ⟩ = Ĥ |ψ⟩
```

**这就是薛定谔方程。**

## 6. 诚实检查

### 推出来的（干净）

1. **相位的时间演化:** θ(t) = ωt，ω = 2π/L。从f的循环结构严格推出。✓
2. **能量的DGF定义:** E = ℏω = 2πℏ/L。能量=循环频率×ℏ。✓
3. **薛定谔方程的形式:** iℏ∂_tψ = Ĥψ。从相位演化+线性叠加严格推出。✓
4. **幺正性:** ⟨ψ|ψ⟩守恒。从Σpⱼ=1推出。✓
5. **Ĥ的物理来源:** Ĥ的本征值由f的循环长度决定。✓

### 有gap的

1. **Ĥ的具体形式:** Ĥ的本征值由f决定，但Ĥ在基|j⟩下的矩阵元（非对角元）需要f的完整表示。f→Ĥ的映射是概念的而非构造的。⚠️
2. **ℏ的值:** ℏ是"一次因果事件的作用量"。但从A1+A2，我们只知道存在最小单位，不知道它具体多大。ℏ是实验输入。⚠️
3. **多路径共存的条件:** 我们假定了q高→多路径→叠加。但q多高？有多少路径？这些需要定量化。⚠️

### 和标准QM的关系

这个推导不是"用DGF取代QM"——是**解释QM的数学结构从哪来**。

- 复数e^{-iEt/ℏ} → 循环实数的复合表示
- 幺正演化 → 循环群结构的必然结果
- 能量量子化 → 有限状态空间→离散循环→离散频谱
- 叠加原理 → 系综包含多条路径

**DGF提供了QM的"为什么"，不改变QM的"是什么"。**
