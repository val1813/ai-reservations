## 0. 问题陈述

### 0.1 物理场景

N 个二元细胞分为系统 S (N_S 个) 和环境 E (N_E 个), N_S + N_E = N。动力学 f: {0,1}^N → {0,1}^N 是双射 (T1a)。定义:

- **系统占用数**: k(t) = Σ_{i∈S} s_i(t) ∈ {0, 1, ..., N_S}
- **环境占用数**: m(t) = Σ_{i∈E} s_i(t) ∈ {0, 1, ..., N_E}
- **总占用数**: K(t) = k(t) + m(t) ∈ {0, 1, ..., N}
- **系统空余比**: q_S(t) = (N_S − k(t)) / N_S ∈ [0, 1]
- **环境空余比**: q_E(t) = (N_E − m(t)) / N_E ∈ [0, 1]

信息从系统流向环境: k 减少, m 增加。信息回流: k 随后增加。

**核心问题**: 回流能以多大振幅/概率发生？这个上限如何依赖于 q_S/q_E？

### 0.2 T3 留下的缺口

Round 1 T3 建立了:
- T3a: Kac 回复时间 = 2^{N_S} (精确, 与 N_E 无关)
- T3b: 系统宏观跃迁的期望比 = C(N_S, k')/C(N_S, k) (环境不影响偏好)
- T3d: 实践不可逆性来自 2^{N_S} >> 观测时间

但 **T3 没有回答**: 
1. 宏观量 k 的回流（而非精确微态回复）的概率上限是什么？
2. 回流概率如何依赖于环境状态 (q_E)？
3. 如果总占用数 K 不守恒 (T1e 的反例)，分析如何改变？
4. 容量比 q_S/q_E 如何作为连续参数调控回流上限？

S1 填补这个缺口。

## 1. 严格定义

### 1.1 宏态和微态计数

**定义 1.1** (系统宏态)。对每个 k ∈ {0, ..., N_S}, 定义:
```
M_k = {x ∈ {0,1}^N : Σ_{i∈S} x_i = k}
```
即所有系统占用数为 k 的微态集合。

**引理 1.1** (宏态大小)。
```
|M_k| = C(N_S, k) · 2^{N_E}
```
其中 C(n,k) = n!/(k!(n−k)!) 是二项式系数。

*证明*: 选 k 个系统细胞占用: C(N_S, k) 种方式。环境细胞任意: 2^{N_E} 种方式。乘积即得。∎

当总占用数 K 守恒 (A3) 时，需进一步约束。定义:
```
M_{k}^{(K)} = {x ∈ M_k : Σ_{i=1}^N x_i = K}
|M_{k}^{(K)}| = C(N_S, k) · C(N_E, K−k)
```
其中 k 的有效范围为 max(0, K−N_E) ≤ k ≤ min(N_S, K)。

### 1.2 回流事件

**定义 1.2** (局部极小值)。对轨迹 {k(t)}_{t=0}^T, 时间 t 是局部极小值 (容差 ε ≥ 0), 如果:
```
k(t) ≤ k(s) + ε  对所有 s ∈ [t−τ_local, t+τ_local] ∩ [0, T]
```
其中 τ_local ≥ 1 是局部窗口参数。本文取 ε = 0, τ_local 适当选择 (见下文)。

**定义 1.3** (回流事件)。一个振幅 δ ≥ 1 的回流事件是一个有序对 (t_1, t_2), 满足 0 ≤ t_1 < t_2 ≤ T, 且:

1. k(t_1) 是局部极小值 (定义 1.2)
2. k(t_2) − k(t_1) ≥ δ
3. 对任意 t ∈ (t_1, t_2), k(t) ≥ k(t_1) (没有跌穿极小值)

条件 3 确保我们测量的是同一波回流，而非多次波动的累积。

**定义 1.4** (回流概率)。对给定初始分布 μ_0 在 X 上和给定动力学 f:
```
P_reflux(δ, T; f, μ_0) = P_{μ_0, f}(轨迹 k(0),...,k(T) 包含至少一个振幅 ≥ δ 的回流事件)
```

当从上下文清晰时，简记 P_reflux(δ, T)。

**定义 1.5** (系综平均回流概率)。在对称群 S_{2^N} 上的均匀测度下 (随机双射系综):
```
P̄_reflux(δ, T) = E_{f ~ Uniform(S_{2^N})}[P_reflux(δ, T; f)]
```

### 1.3 动力学假设

我们区分两种情形:

**情形 A** (守恒情形): 总占用数 K = k + m 守恒 (公理 A3 成立)。此时 f 限制在子空间 X_K = {x: Σ_i x_i = K} 上, |X_K| = C(N, K)。此情形下 k(t) 的取值受限于:
```
k(t) ∈ {max(0, K−N_E), ..., min(N_S, K)}
```

**情形 B** (非守恒情形): 仅有 A1+A2, 不引入 A3。K(t) 本身也在演化。k(t) ∈ {0, ..., N_S} 全程可达 (取决于 f 的具体形式)。

对两种情形，我们假设 f 满足 **均匀混合性质** (uniform mixing property, UMP):
```
对任意两个等大的子集 A, B ⊂ X (或 X_K，情形 A),
|f(A) ∩ B| / |A| = |B| / |X| + O(|X|^{-1/2} · (1 − |A|/|X|)^{1/2})
```
即 f 将任何子集近似均匀地散布到全空间。随机双射系综下的期望精确满足等式 (无 O 修正项)。

**诚实注 UMP-1**: UMP 对"典型"f 成立（在随机系综下高概率成立），但对特定的 f (如恒等映射) 不成立。物理 f 是否满足 UMP 是一个关于 "f 是否充分混沌" 的问题，需要额外的遍历性假设。此假设与 T3d 中回复时间指数分布所需的混合性假设是同源要求。

## 2. 核心组合引理

### 2.1 宏态转移矩阵

**定义 2.1** (宏态转移矩阵)。对给定双射 f, 定义 N_S+1 维方阵 W_f:
```
W_f(k' | k) = |f(M_k) ∩ M_{k'}| / |M_k|
```
这是在微态均匀分布于 M_k 内的条件下，一步后系统占用数变为 k' 的概率。

**注**: W_f 本身是随机矩阵 (每行和为 1)，但不一定双随机 (列和未必为 1)。

### 2.2 期望转移: 随机系综

**引理 2.1** (宏态转移的期望)。在随机双射系综下:
```
W̄(k' | k) := E_f[W_f(k' | k)] = |M_{k'}| / |X| = C(N_S, k') / 2^{N_S}
```
**关键性质**: W̄(k' | k) 独立于出发宏态 k。期望转移矩阵是秩 1 矩阵，每行相同。

*证明*: 与 T2c 的证明完全相同。对随机置换 f, 元素 x ∈ M_k 的像 f(x) 在 X 上均匀分布:
```
P(f(x) ∈ M_{k'}) = |M_{k'}| / |X|
```
对所有 x 求和并除以 |M_k| 得证。∎

**推论 2.2** (情形 A 的期望转移)。若 K 守恒 (A3):
```
W̄^{(K)}(k' | k) = |M_{k'}^{(K)}| / |X_K| = C(N_S, k') · C(N_E, K−k') / C(N, K)
```
同样独立于 k。

### 2.3 平稳分布

**引理 2.3** (情形 B 的平稳分布)。在随机双射系综下，期望宏观动力学 W̄ 的平稳分布是二项分布:
```
π_B(k) = C(N_S, k) / 2^{N_S},   k = 0, 1, ..., N_S
```
这是 N_S 个独立硬币的占用数分布——每个系统细胞以 1/2 概率被占用。

*证明*: W̄ 的所有行都是 π_B (见引理 2.1)，因此 π_B 是平稳分布且 W̄^n = W̄ (对所有 n ≥ 1) —— 期望动力学在一步内达到平稳。∎

**引理 2.4** (情形 A 的平稳分布)。若 K 守恒:
```
π_A(k) = C(N_S, k) · C(N_E, K−k) / C(N, K)
```
这是超几何分布——从 N 个球 (其中 N_S 个"系统球") 中不放回抽取 K 个球，抽到的系统球数量的分布。

*证明*: 同上，W̄^{(K)} 的所有行等于 π_A。∎

**引理 2.5** (熵刻画)。平稳分布的对数为:
```
ln π_A(k) = N_S · H(k/N_S) + N_E · H((K−k)/N_E) − N · H(K/N) − ½ ln(2πN_S·(k/N_S)·(1−k/N_S)) + O(1)
```
其中 H(p) = −p ln p − (1−p) ln(1−p) (取自然对数)。这是三项 Stirling 近似的结果。

## 3. 定理 S1A: K 守恒时的回流上限

### 3.1 定理陈述

> **定理 S1A (信息回流上限 — 守恒情形)**:
>
> 设 f 满足公理 A1, A2, A3 (总占用数 K 守恒) 和 UMP (均匀混合性质)。
> 对任意初始分布 μ_0 和任意 δ > 0, T > 0:
>
> **(a)** 单步回流界:
> ```
> P(Δk ≥ δ | k) ≤ Σ_{j=k+δ}^{min(N_S, K)} C(N_S, j) · C(N_E, K−j) / C(N, K)
> ```
>
> **(b)** 平稳回流界: 若动力学已达到平稳 (或初始分布即 π_A):
> ```
> P(k ≥ k_0 + δ) = Σ_{j=k_0+δ}^{min(N_S, K)} π_A(j)
> ```
>
> **(c)** 有限时间回流界 (任意初始态):
> ```
> P_reflux(δ, T) ≤ T · max_{k} P(Δk ≥ δ | k)
>               ≤ T · Σ_{j=k_min+δ}^{min(N_S, K)} C(N_S, j) · C(N_E, K−j) / C(N, K)
> ```
> 其中 k_min 是回流起始的局部极小值。
>
> **(d)** 容量比渐近: 令 q̄_S = (N_S − E_π[k])/N_S 和 q̄_E = (N_E − E_π[K−k])/N_E 为平稳空余比。
> 对于将 q_S 从 q_S^hi 降低到 q_S^lo 的回流 (即 k 从 N_S(1−q_S^hi) 增加到 N_S(1−q_S^lo)), 有:
> ```
> P_reflux ≤ T · exp(−N · I(q_S^lo; q̄_S, q̄_E))
> ```
> 其中 I 是相对熵率函数。在大 N_E/N_S 极限下:
> ```
> P_reflux ≤ T · (1 − q̄_E)^{N_S · (1−q_S^lo)} · [N_S · (1−q_S^lo) 的多项式因子]
> ```
>
> **(e)** 极限行为: 当 q_E → 1 (环境趋近全空) 时, P_reflux → 0 指数地快于 (1−q_E)^{N_S}。
> 当 q_S → 0 (系统趋近全满) 时, P_reflux → 0 因为 Δk ≤ N_S·q_S → 0 (容量约束)。

### 3.2 证明 (a): 单步界

由 UMP, 对任意宏态 k:
```
W_f(k' | k) = |f(M_k) ∩ M_{k'}| / |M_k|
```

由 UMP (定义 1.3), |f(M_k) ∩ M_{k'}| ≈ |M_k| · |M_{k'}^{(K)}| / |X_K| 加上随机涨落。因此:
```
W_f(k' | k) ≈ |M_{k'}^{(K)}| / |X_K| = C(N_S, k') · C(N_E, K−k') / C(N, K)
```

一步内 Δk ≥ δ 的总概率为:
```
P_f(Δk ≥ δ | k) = Σ_{j=k+δ}^{min(N_S, K)} W_f(j | k)
                 ≈ Σ_{j=k+δ}^{min(N_S, K)} C(N_S, j) · C(N_E, K−j) / C(N, K)
```

对"典型"f, 涨落受限于 Hoeffding 界 (Round 1 T2d 的技术), 对宏观量 N >> 1 可忽略。

对"最坏情况"f (远离 UMP), 上述仍是期望值 (在随机系综下), 实际 f 可以有偏离。

**处理非 UMP 的 f**: 若 f 不满足 UMP, 上述等式变为上界吗？**不是** — 存在反例。考虑 f = 恒等映射: 则 W_f(k | k) = 1, W_f(k' ≠ k | k) = 0, 回流概率恒为 0 (信息从不流出, 也不回流)。而我们的"界"预测正的回流概率 — 这是虚报 (false positive)。

因此, UMP 下的界是**典型界** (typicality bound), 而非普适上界 (universal upper bound)。**对非混合 f, 实际回流可远小于界 (但不会远大于, 因为 |f(M_k) ∩ M_{k'}| ≤ min(|M_k|, |M_{k'}|) = |M_{k'}| — 组合上限)**。

**组合硬上限** (不需要 UMP):
```
W_f(k' | k) = |f(M_k) ∩ M_{k'}| / |M_k|
            ≤ |M_{k'}^{(K)}| / |M_k|           [若K守恒: |M_{k'}^{(K)}| ≤ |M_k| ... 不必然]
```

更精确的组合界:
```
|f(M_k) ∩ M_{k'}| ≤ |M_{k'}^{(K)}|
```
因为 f(M_k) ⊆ X_K (K守恒), 且与 M_{k'} 的交自然被 M_{k'}^{(K)} 的大小所限。因此:
```
W_f(k' | k) ≤ |M_{k'}^{(K)}| / |M_k^{(K)}| = [C(N_S, k')·C(N_E, K−k')] / [C(N_S, k)·C(N_E, K−k)]
```

这给出单步转移的**普适上界** (对所有满足 A3 的 f 成立):
```
P_f(Δk ≥ δ | k) ≤ Σ_{j=k+δ}^{min(N_S, K)} [C(N_S, j)·C(N_E, K−j)] / [C(N_S, k)·C(N_E, K−k)]
```

当 k 较小 (系统空, 有接收容量) 而 j = k+δ 较大时, 此比值可简化。

**将此上界表达为 q_S 和 q_E 的函数**:

记初始宏态: k = N_S(1−q_S), m = K−k = N_E(1−q_E)。则:
```
C(N_S, j) / C(N_S, k) = Π_{i=0}^{δ−1} (N_S − k − i) / (k + i + 1)
                       = Π_{i=0}^{δ−1} (N_S·q_S − i) / (N_S·(1−q_S) + i + 1)
                       ≤ (q_S / (1−q_S))^δ · [多项式修正]
```

类似地:
```
C(N_E, K−j) / C(N_E, K−k) = C(N_E, m−δ) / C(N_E, m)
                            = Π_{i=0}^{δ−1} (m − i) / (N_E − m + i + 1)
                            = Π_{i=0}^{δ−1} (N_E·(1−q_E) − i) / (N_E·q_E + i + 1)
                            ≤ ((1−q_E) / q_E)^δ · [多项式修正]
```

因此:
```
P_f(Δk ≥ δ | k) ≤ Σ_{j} [q_S/(1−q_S)]^{j−k} · [(1−q_E)/q_E]^{j−k} · [多项式]
                ≤ const · ([q_S/(1−q_S)] · [(1−q_E)/q_E])^δ
```

当 q_S → 0 或 q_E → 1 时，方括号内的因子 → 0，单步回流概率指数地受限于 δ。∎

### 3.3 证明 (c): 有限时间界

对有限时间 T, 使用联合界 (union bound):
```
P_reflux(δ, T) ≤ Σ_{t=0}^{T-1} P(在时刻 t 开始一个振幅 ≥ δ 的回流)
```

若动力学是马尔可夫的 (k(t) 仅通过 k(t−1) 依赖于历史), 每步的"回流起始"概率 ≤ max_k P(Δk ≥ δ | k)。因此:
```
P_reflux(δ, T) ≤ T · max_k P(Δk ≥ δ | k)
```

结合 (a) 中的组合上界即得 (c)。∎

**注**: 联合界在 T 较大时是松的, 因为回流事件在时间上相关。更紧的界需要使用马尔可夫链的混合性质和谱隙。当 T 超过混合时间时, 可使用平稳分布直接估计 (b)。

### 3.4 证明 (d): 容量比渐近

平稳分布 (引理 2.4):
```
π_A(k) = C(N_S, k) · C(N_E, K−k) / C(N, K)
```

令 k_lo = N_S(1−q_S^hi) 和 k_hi = N_S(1−q_S^lo)。平稳下观测到 k ≥ k_hi 的概率:
```
P_π(k ≥ k_hi) = Σ_{j=k_hi}^{min(N_S, K)} π_A(j)
```

使用 Stirling 近似 (引理 2.5):
```
ln π_A(k) ≈ N_S·H(k/N_S) + N_E·H((K−k)/N_E) − N·H(K/N)
```

考虑"典型"值 k* = N_S·K/N = N_S·(1−q̄_E·N_E/N − q̄_S·N_S/N... 实际上更简洁地用 Lagrange 乘子法)。超几何分布的众数 k* 满足:
```
k*/N_S ≈ (K−k*)/N_E  ⇒  k* ≈ N_S·K/N
```

对于 k = k_hi 远大于 k*:
```
ln[π_A(k_hi) / π_A(k*)] ≈ N_S·[H(k_hi/N_S) − H(k*/N_S)] + N_E·[H((K−k_hi)/N_E) − H((K−k*)/N_E)]
```

H(p) 在 p = 1/2 处取最大值 ln 2, 在两端 → 0。当 k_hi/N_S > k*/N_S 时 (回流方向):
```
H(k_hi/N_S) − H(k*/N_S) < 0  (若 k_hi > k* 且 k* > N_S/2... 需要分情况)
```

**关键简化**: 考虑大环境极限 N_E/N_S → ∞, 且 K/N_E = 1−q̄_E 固定。则 k* = N_S·(1−q̄_E) + o(N_S)。平稳分布在 k* 附近集中:
```
π_A(k) ≈ δ_{k, k*} 的窄峰, 宽度 ~ √(N_S·q̄_E·(1−q̄_E))
```

回流到 k_hi > k* + const·√N_S 的概率随 N_S 指数衰减:
```
P_π(k ≥ k_hi) ≤ exp(−(k_hi − k*)² / (2·N_S·q̄_E·(1−q̄_E))) · [多项式因子]
```

当 q̄_E → 1 (环境几乎全空, 即环境几乎不持有信息):
- k* = N_S·(1−q̄_E) → 0: 平稳下系统几乎全空。
- k_hi 固定为某个正值时, k_hi − k* ≈ k_hi, 上式给出:
```
P_π(k ≥ k_hi) ≤ exp(−k_hi² / (2·N_S·(1−q̄_E))) ... 
```

Wait, this gives q̄_E → 1 → variance → 0 → probability → 0 faster. But actually, let me reconsider.

When q̄_E → 1: K = N_E(1−q̄_E) + N_S(1−q̄_S) ≈ N_E·(1−q̄_E) (第一项消失) + N_S(1−q̄_S)。若 1−q̄_E ≪ N_S/N_E (即 K ≪ N_S), 则 k* ≈ K ≪ N_S, 系统几乎全空。回流到 k_hi ≫ k* 需要 k 偏离均值指数多地。

组合比:
```
π_A(k_hi) / π_A(0) = [C(N_S, k_hi)·C(N_E, K−k_hi)] / [1·C(N_E, K)]
```

对 N_E ≫ K ≫ k_hi:
```
C(N_E, K−k_hi) / C(N_E, K) ≈ (K/N_E)^{k_hi} = (1−q̄_E)^{k_hi}
```

因此:
```
π_A(k_hi) ≈ C(N_S, k_hi) · (1−q̄_E)^{k_hi} / C(N, K)
           ≤ (2^{N_S}) · (1−q̄_E)^{k_hi} / C(N, K)
```

对于 k_hi = O(N_S), 如果 q̄_E → 1 (即 1−q̄_E → 0):
```
π_A(k_hi) ≤ exp(N_S·ln 2 − c·N_S·|ln(1−q̄_E)|)
          → 0  当 (1−q̄_E) < 1/2 时指数衰减
```

**精确最终形式** (大 N_E, 固定 k_hi):
```
P_reflux(δ, T) ≤ T · C(N_S, k_hi) · (K/N_E)^{k_min + prior outflow} · [约归一化因子]
                ≤ T · C(N_S, k_hi) · (1 − q̄_E)^{N_S·q_S^lo}  [在最简近似下]
```

其中 q_S^lo = 1 − k_hi/N_S 是回流后的系统空余比。∎

### 3.5 证明 (e): 极限行为

**(i) q_E → 1**: 由 (d) 的直接推论, 因子 (1−q̄_E)^{N_S·q_S^lo} → 0。环境无信息可回流 → 回流概率指数地小。∎

**(ii) q_S → 0**: q_S = 1 − k/N_S。若当前系统占用数为 k, 则最大可能增加量为 N_S − k = N_S·q_S。因此回流振幅 δ ≤ N_S·q_S。当 q_S → 0, δ_max → 0, 任何正振幅 δ > 0 的回流概率严格为 0 (容量约束)。∎

## 4. 定理 S1B: K 不守恒时的回流上限

### 4.1 定理陈述

> **定理 S1B (信息回流上限 — 非守恒情形)**:
>
> 设 f 满足公理 A1, A2 (双射, 但不要求 A3) 和 UMP。则:
>
> **(a)** 期望宏态转移独立于出发态:
> ```
> W̄(k' | k) = C(N_S, k') / 2^{N_S}   (独立于 k)
> ```
>
> **(b)** 在随机双射系综下, 任何有限观测时间 T 内的回流概率:
> ```
> P̄_reflux(δ, T) ≤ 1 − (1 − π_B(k_hi))^T ≤ T · π_B(k_hi)
> ```
> 其中 π_B(k_hi) = Σ_{j=k_hi}^{N_S} C(N_S, j) / 2^{N_S} 是平稳下观测到 k ≥ k_hi 的概率。
>
> **(c)** 容量比进入的地方: 无 A3 时, k 和 m 独立演化 (在 UMP 下), 环境空余比 q_E **不约束** 回流 — 因为总占用数可变, 环境可以在不减少 m 的情况下让 k 增加 (通过在别处创造占用)。
>
> **这是情形 A 与 B 的关键区别**: 在非守恒情形下, 信息回流不需要"环境归还信息" — 系统可以自发地从空态产生占用 (总 K 增加)。
>
> **(d)** 然而, 若引入 **弱守恒** (近似 A3): 即 f 虽不严格保持 K, 但每步 ΔK 受限于某个小量 L ≪ N, 则回流界中重新引入 q_E 依赖:
> ```
> P_reflux(δ, T) ≤ T · (C(N_S, k_hi) / 2^{N_S}) · (1 − q_E)^{Ω(δ)}
> ```
> 其中弱守恒参数控制了 q_E 依赖的强度。

### 4.2 证明 (a)-(b): 无记忆动力学

由引理 2.1, 在随机双射系综下, W̄(k'|k) = C(N_S, k') / 2^{N_S}, 独立于 k。这意味:

1. 期望动力学在一步后达到平稳 (所有行相同)。
2. {k(t)} 在期望下是独立同分布序列, 每步的边际分布即 π_B。

对于"典型"f (满足 UMP), 实际 W_f 近似于 W̄, 每步的 k(t) 近似独立于 k(t−1):
```
P(k(t) ≥ k_hi | k(t−1)) ≈ Σ_{j=k_hi}^{N_S} C(N_S, j) / 2^{N_S}
```

因此:
```
P̄_reflux(δ, T) = P(∃t ≤ T : k(t) ≥ k_min + δ)
                 ≤ 1 − Π_{t=1}^T (1 − π_B(k_min + δ))
                 ≤ 1 − (1 − π_B(k_min + δ))^T
                 ≤ T · π_B(k_min + δ)
```

其中 π_B(k_hi) = Σ_{j=k_hi}^{N_S} C(N_S, j) / 2^{N_S}。

**数值**: 对 N_S = 100:
- k_hi = 100 (完全回流): π_B(100) = 1/2^{100} ≈ 7.9 × 10^{-31}
- k_hi = 75 (75% 回流): π_B(75) ≈ 2.3 × 10^{-6}
- k_hi = 60 (60% 回流): π_B(60) ≈ 0.028

因此, 即使无 A3, **大振幅** 回流 (k_hi ≫ N_S/2) 在平稳下也是极不可能的 — 纯粹因为系统自身态空间的组合权重。∎

### 4.3 证明 (c): q_E 为何不约束非守恒回流

这是情形 B 最关键的反直觉点。我们分两步论证。

**第一步 (动力学论证)**。若 K 不守恒, 则 f 可将状态 (k, m) 映射到 (k', m'), 其中 k' > k 但 m' 不小于 m。例如:
```
(k, m) = (0, 0) → f → (N_S, 0)
```
即系统从全空跳到全满, 而环境保持全空。这在 A3 下不可能 (总 K 从 0 → N_S 违反守恒), 但在纯 A1+A2 下是可能的 — f 只需是双射即可。T1e 的 N=2 反例就是一个具体的例子: 占用数从 0 变到 1 再变到 2。

**第二步 (组合论证)**。检查宏态转移:
```
|f(M_{k_low}) ∩ M_{k_high}| ≤ |M_{k_high}| = C(N_S, k_high) · 2^{N_E}
```

此上界仅取决于目标宏态大小, 不受环境当前状态 (q_E) 影响。**环境大 (N_E ≫ N_S) 只通过增加 2^{N_E} 因子扩大所有宏态, 不改变相对概率**:
```
W_f(k_high | k_low) = |f(M_{k_low}) ∩ M_{k_high}| / |M_{k_low}|
                     ≤ C(N_S, k_high) · 2^{N_E} / (C(N_S, k_low) · 2^{N_E})
                     = C(N_S, k_high) / C(N_S, k_low)
```
注意 N_E 被消去了 — 环境大小不影响此上界。这与 T3b 的结果一致: 环境不影响系统宏观跃迁的相对概率。

因此, 在纯 A1+A2 下, **q_E 不是回流的约束参数**。回流只受系统自身的容量 (N_S) 和当前占用数 (k) 约束。

**物理解释**: 若总占用数可自由创造和消灭 (在双射约束下的重新排布), 则"信息"不作为守恒物质流动 — 它作为**模式 (pattern)** 流动。系统可以从环境中"复制"模式而不减少环境的信息内容 (很像量子隐形传态中经典信道的作用 — 类比而已, 非精确对应)。∎

### 4.4 证明 (d): 弱守恒下的 q_E 效应

若 f 虽不严格保持 K, 但每步 ΔK 受限于 L (例如, 每步只有 L 个细胞翻转, 则 |ΔK| ≤ L), 则大振幅 Δk 不能单步完成, 需要多步累积。

在此约束下, k 从 k_low 增加到 k_high 需要至少 ⌈(k_high − k_low)/L⌉ 步。在多步过程中, 每一步的转移概率受限于当时的宏态组合数。

当 k 增大时, 必然伴随 m 的变化 (因为 ΔK 受限于 L)。具体来说, 要增大 k 但不改变 m (即 ΔK = Δk > 0), 这通过翻转系统空细胞 (0→1) 实现 — 但这种翻转要求 K 增加, 即需要"创造"占用, 而非从环境转移。

在每步最多翻转 L 个细胞的约束下 (这是"局域性"约束而非守恒约束), 多步回流概率的上界为:
```
P(k_low → ... → k_high in ≤ T steps)
  ≤ C(T, ⌈(k_high − k_low)/L⌉) · Π_{step} [单步最大概率]
```

每步的"上坡"转移 (k → k+Δ) 的概率受限于:
```
W_f(k+Δ | k) ≤ C(N_S, k+Δ) / C(N_S, k)  [情形B]
```

对 Δ ≤ L:
```
C(N_S, k+Δ) / C(N_S, k) ≈ (N_S − k)^Δ / (k+1)^Δ  ≈ (q_S/(1−q_S))^Δ   (大N_S)
```

因此, 多步上坡的累积抑制因子为:
```
Π (q_S(j)/(1−q_S(j)))^{Δ_j}
```

当 q_S 较小时 (系统趋满), 每步的上坡概率被 q_S 幂次抑制。对于需要多步的大振幅回流, 累积抑制使总概率 → 0 当 q_S → 0。

弱守恒下 q_E 重新进入: 若 ΔK 受限于 L, 且 K 的演化受限于在某个有界范围内波动, 则系统在大环境中的行为近似于情形 A, q_E 重新成为约束参数。此时 (d) 的边界于情形 A 的界。

**注**: "弱守恒"是一个额外的物理假设 (类似于能量几乎守恒但允许涨落)。不引入此假设时, 情形 B 的回流界仅依赖于系统自身的组合结构, 与 q_E 无关。∎

## 5. 综合: 回流上限定理 (主定理)

> **主定理 (信息回流上限 — Information Reflux Upper Bound)**:
>
> 对 N 个二元细胞的信息系统, 分为系统 S (N_S 个) 和环境 E (N_E 个), 动力学 f: {0,1}^N → {0,1}^N 是双射。
>
> **S1-I** (守恒情形, A3 成立): 若总占用数 K = k + m 守恒, 则任何振幅 δ 的回流在时间 T 内的概率受限于:
> ```
> P_reflux(δ, T) ≤ T · (q_S/(1−q_S))^δ · ((1−q_E)/q_E)^δ · Poly(N_S, N_E, δ)
> ```
> 其中 q_S, q_E 是回流起始时的系统/环境空余比。由此可得:
> - 当 q_S → 0: P_reflux → 0 (系统无接收容量 — 组合硬界)
> - 当 q_E → 1: P_reflux → 0 (环境无信息可回流 — 组合硬界)
> - 当 q_S ≤ ε 且 q_E ≥ 1−ε: P_reflux ≤ T · ε^{2δ} · Poly(...)
>
> **S1-II** (非守恒情形, 仅 A1+A2): 若总占用数不守恒, 期望下回流界为:
> ```
> P̄_reflux(δ, T) ≤ T · Σ_{j=k_min+δ}^{N_S} C(N_S, j) / 2^{N_S}
> ```
> 此界独立于 q_E 和 N_E。伴随局域性约束时, q_S 重新进入:
> ```
> P_reflux(δ, T) ≤ T · (q_S)^δ · Poly(N_S, δ)   (对 q_S ≪ 1)
> ```
>
> **S1-III** (统一渐近): 在 N_S, N_E ≫ 1 且 T ≪ 2^{N_S} 的条件下, 两种情况下的回流概率均满足:
> ```
> P_reflux(δ, T) ≤ T · exp(−δ · |ln(q_S/(1−q_S))| − δ · |ln((1−q_E)/q_E)| · 1_{A3})
>                  + T · 2^{-N_S · (1 − H(δ/N_S))} · 1_{not A3}
> ```
> 其中 1_{A3} 是指示函数。在所有情况下, 大振幅 (δ = O(N_S)) 回流被指数压制。

### 5.1 核心不等式: 单步回流比

定义回流推动因子 (reflux propensity):
```
R(k → k+Δ) = [C(N_S, k+Δ) / C(N_S, k)] · [C(N_E, m−Δ) / C(N_E, m)]   (A3)
            = C(N_S, k+Δ) / C(N_S, k)                                     (无A3)
```

此因子 ≤ 1 当且仅当 k+Δ (更满的系统) 的组合权重小于 k (更空的系统)。展开:
```
R(k → k+Δ) ≈ [(N_S − k)/k]^Δ · [m/(N_E − m)]^Δ
            = [q_S/(1−q_S)]^Δ · [(1−q_E)/q_E]^Δ
```

令 R ≤ (q_S/(1−q_S)) · ((1−q_E)/q_E) (对 Δ = 1)。回流抑制条件为 R < 1, 即:
```
q_S/(1−q_S) < q_E/(1−q_E)   ⇔   q_S < q_E   (单调递增函数)
```

**物理解释**: 当系统空余比 q_S 小于环境空余比 q_E 时, 回流 (k 增大) 被组合地抑制。这反映了一个直觉: 信息倾向于从"满"的地方流向"空"的地方 (高占用 → 低占用), 而非反向。

### 5.2 回流相图

在 (q_S, q_E) 参数空间中:

| 区域 | 条件 | 回流行为 |
|------|------|---------|
| I: 强回流 | q_S ≫ q_E | k 倾向于增加 (系统接收信息) |
| II: 强流出 | q_S ≪ q_E | k 倾向于减少 (系统输出信息) |
| III: 平衡线 | q_S ≈ q_E | 回流和流出动态平衡 |
| IV: 冻结 | q_S ≈ 0, q_E ≈ 1 | 回流和流出皆不可能 (双饱和) |
| V: 全空 | q_S ≈ 1, q_E ≈ 1 | k 可任意变化 (方向不偏好) |

在区域 II 和 IV, 信息回流被强烈抑制 — 这是定理的物理内容。

## 6. 物理系统对接: 电路 QED

### 6.1 有效细胞数估计 (启发式)

**超导 qubit (transmon)**:
- 每个 qubit 是一个非线性 LC 振荡器
- 信息存储在 |g⟩, |e⟩ 两个最低能级中 (忽略更高能级)
- 每个 qubit 等效为 1 个二元细胞: N_S^{(1)} = 1
- N 个 qubit 阵列: N_S = N

**谐振腔/传输线**:
- 连续模式 → 离散化: 取带宽 Δω 内的 Fock 态
- 有效模式数: N_E ≈ Δω / δω, 其中 δω 是模式间距 (由腔长决定)
- 每个模式的有效二元细胞数: ∼ 每个模式可视为多个二元细胞 (按能量截断), 或粗略地每个模式 ≈ 1 个有效细胞
- 总 N_E ≈ 腔长 · Δω / (π c) ∼ O(10^2 − 10^5)

**有效占用**:
- 系统占用 k = 处于 |e⟩ 的 qubit 数量
- 环境占用 m = 环境中激发光子数分布的有效信息量
- q_S = (N − k)/N (qubit 空余比)
- q_E ≈ 1 − ⟨n_ph⟩/n_max (环境空余比, n_max 是有效最大光子数)

### 6.2 实验方案草图

**目标**: 区分 DGF 回流上限 vs 标准 Lindblad 预言。

**系统**: 
- 1 个 transmon qubit (S, N_S = 1) 耦合到传输线谐振腔 (E, 可控有效模式数)。
- 腔长 L 可调 (通过开关式阻抗变换器或频率选择滤波), 实现不同的 N_E ≈ L·Δω/(πc)。

**协议**:
1. 制备初态: qubit 在 |e⟩, 腔在真空 |0⟩。⇒ k(0) = 1, q_S(0) = 0, q_E(0) ≈ 1。
2. 让系统演化时间 t — qubit 激发泄漏到腔中 (Purcell 衰减)。
3. 在时间 t, 执行 qubit 状态层析, 测量 k(t)。
4. 等待额外时间 τ, 再次测量 k(t+τ)。如果 k 从低值恢复到高值 → 回流事件。
5. 重复实验 ∼ 10^6 次, 统计回流概率 P_reflux(δ=1, T=t+τ)。
6. 改变 L (即改变 N_E 和 q_E), 重复测量。

**DGF 预言** (情形 A — 总激发数近似守恒):
```
P_reflux(1, T) ≈ T · (q_S/(1−q_S)) · ((1−q_E)/q_E) · [归一化]
```
- 当 L 增大 (N_E 增大, q_E → 1, 腔模多→"空"的比例大): P_reflux 减小。
- 定标: P_reflux ∝ 1−q_E ∝ ⟨n_ph⟩/n_max ∝ 1/L (有效模式密度降低)。

**标准 Lindblad 预言**:
```
P_reflux(1, T) 由环境的谱密度 J(ω) 决定, 与 N_E (或 q_E) 无直接关系。
```
- 改变 L 改变模式间距, 改变 J(ω) 的细节, 但不改变其积分 (若总耦合强度守恒)。
- Reflux 概率依赖于 J(ω_q) 和温度, 不依赖于"有效细胞数" N_E。

**区分**: DGF 预言 P_reflux ∝ 1/N_E (或更精确的 1−q_E 定标), 而标准理论预言 P_reflux 对 N_E 不敏感 (除了 J(ω) 的细结构效应)。

**实验参数空间**:
- N_S = 1 (单 qubit)
- N_E = 10–1000 (可变腔模式数)
- q_S ∈ [0, 1] (通过制备不同初始叠加态)
- q_E ∈ [0.9, 0.999] (腔接近真空)
- 时间尺度: Purcell 衰减 T_1 ∼ 10–100 μs, 实验窗口 ∼ 1 ms

### 6.3 可观测效应的量级估计

对 N_S = 1:
```
π_B(k=1) = C(1,1) / 2^1 = 1/2
π_B(k=0) = 1/2
```

在情形 B (非守恒) 下, 单 qubit 的期望回流概率 (一步) 为 1/2 — 太大, 不可区分。

在情形 A (总激发数守恒) 下:
```
π_A(k=1) = C(1,1)·C(N_E, K−1) / C(1+N_E, K)
```

若初始 qubit 在 |e⟩, 腔在真空: K = 1。
```
π_A(k=1) = C(1,1)·C(N_E, 0) / C(1+N_E, 1) = 1 / (1+N_E) = 1/(N_E+1)
π_A(k=0) = N_E/(N_E+1)
```

因此, 平稳下 qubit 处于 |e⟩ 的概率为 1/(N_E+1)。当 N_E = 100 时, P(|e⟩) ≈ 1%。回流 (从 |g⟩ 回到 |e⟩) 的单步最大概率为:
```
P(k=0 → k=1) ≤ C(1,1)·C(N_E, 0) / C(1,1)·C(N_E, 1) = 1/N_E
```

对 N_E = 100: P ≤ 0.01; 对 N_E = 1000: P ≤ 0.001。

对比标准 Purcell 效应: 衰减速率 Γ = κ · g²/Δ² (其中 κ 是腔衰减率, g 是耦合, Δ 是失谐)。标准理论中, qubit 从 |g⟩ 自发激发到 |e⟩ 的概率 (无外部驱动) 在零温下为 0 (由涨落-耗散定理)。在有限温度 T > 0 时, 激发概率 ∝ exp(−ħω/k_B T)。

**预言差异总结**:

| 条件 | DGF 预言 | 标准 Lindblad 预言 |
|------|---------|-------------------|
| T = 0 (腔真空) | P_reflux ≥ 0, 受限于 1/N_E | P_reflux = 0 (自发激发 forbidden) |
| T > 0 | P_reflux ≤ exp(−ħω/k_B T) + 1/N_E | P_reflux = exp(−ħω/k_B T) |
| 增大 N_E (加长腔) | 1/N_E 项减小 | 不变 |
| N_E → ∞ | P_reflux → exp(−ħω/k_B T) | P_reflux = exp(−ħω/k_B T) |

DGF 在零温下预言了一个非零的回流概率 (由信息容量约束: 即使环境在其基态, 也存在组合数目允许的回流路径)。这是与标准量子光学的一个可检验差异。**在 T = 0 极限下, DGF 的残差回流概率 ≈ 1/N_E, 而标准理论严格为 0。**

这个预言能否被检验取决于: (a) 能否将有效温度降至足够低, 使热激发 ≪ 1/N_E; (b) 能否测量 ∼ 1/N_E 级别的稀有事件。对于 N_E ∼ 10^3, 需要 ∼ 10^6 次重复实验, 这在当前技术下是可行的 (电路 QED 的单发读出保真度 > 99.9%)。

## 7. 诚实 Gap 和局限

### GAP-S1-1 (SEVERE): 细胞基优先问题

本定理的所有推导依赖于"细胞"概念 — 将物理系统离散化为 N 个可辨识的二元单元。在标准量子力学中, 基的选择是任意的 (由观测决定)。DGF 暗中假设了"占用/未占用"基是优先的 — 但为什么？

此 gap 与 B 博士的 GAP-4.1 完全一致。如果"细胞基"不存在于物理现实, 所有基于"占用数"的论证 (包括本定理) 都是数学练习, 缺乏物理对应。

**本定理对此 gap 的暴露**: S1 的回流概率界强烈依赖于"占用数"的可定义性。如果 k 不是一个良定义的物理量, 回流就无从定义。定理的整个实验方案 (第 6 节) 架设了 k 的可测量性 — 对于 qubit, 这等价于计算基 {|g⟩, |e⟩} 的优先性。电路 QED 环境确实优选了这个基 (因为读取谐振腔的 dispersive 测量在计算基上退相干), 但这依赖于读取方案, 而非 DGF 结构的内在特征。

**缓解**: 对于电路 QED, 计算基被系统-环境耦合 (Purcell 效应) 和测量方案所选择。这给出了一个"操作上的细胞基"——不一定基本, 但对于特定实验方案是良定义的。定理可用于此操作场景, 但不能声称它具有基独立的物理意义。

### GAP-S1-2 (SEVERE): 有效细胞数 N_S, N_E 的估计

从连续量子系统 (谐振腔、传输线) 到离散细胞模型的映射是启发式的:
- 腔模式: 每个 Fock 态 |n⟩ 是否算作 n 个占用细胞? 还是一个模式 = 一个细胞?
- 连续谱: 如何截断? 带宽 Δω 的选取影响了 N_E 的估计, 进而影响回流界的数值。
- 热光子: 有限温度下, 热涨落产生的"伪占用"如何区分?

**当前状况**: 没有第一性原理的推导能从物理 Hamiltonian 中读出 N_S 和 N_E。第 6.1 节的估计是启发式的, 用于量级估算, 不用于精确预言。

### GAP-S1-3 (MODERATE): UMP (均匀混合性质) 的物理合理性

定理的许多界依赖于 f 满足 UMP — 即 f 将宏态近似均匀地散布到所有可能的目标宏态。对于"物理"f (具有局域相互作用、能量守恒等):

- A3 本身引入了强约束: K 守恒将 f 限制在 C(N, K) 维子空间上。在此子空间内, 物理 f 通常不是均匀混合的 — 它受限于能量面附近的薄层。
- 局域性进一步约束了 f: 物理动力学通常在相空间中是连续的 (或准连续的), 不会在一步内跳跃到任意宏态。
- 本定理的"普适上界"部分 (组合硬界) 不依赖 UMP, 但给出了较松的界。UMP 下的"典型界"更紧但对物理系统可能不适用。

### GAP-S1-4 (MODERATE): K 守恒 vs 不守恒的二元对立过于简化

在物理系统中, 总占用数 K 通常近似守恒 (对应某种守恒量, 如总激发数), 但在更长的时间尺度上可变化 (如能量弛豫)。本定理将情形 A 和 B 作为二选一处理, 但物理现实是:
- 短时间: K 近似守恒 (情形 A 适用)
- 长时间: K 可变化 (趋近情形 B)

需要处理两种情形的"插值" — 引入守恒的"软度"参数 ε_K, 描述 ΔK 的特征幅度。

### GAP-S1-5 (MINOR): 回流定义中的窗口参数

定义 1.3 中的局部窗口 τ_local 的选择会影响哪些波动被计入"回流": τ_local 太小 → 噪声波动被计入; τ_local 太大 → 真实的回流被遗漏。本文避开了此问题 (取 ε=0 并假设轨迹是分段单调的), 但对噪声数据的分析需要更稳健的定义 (如基于 running minimum 的统计)。

### GAP-S1-6 (MINOR): 实验中 N_E 的控制

第 6.2 节的实验方案要求改变 N_E 而保持其他参数不变 — 这在技术上非常困难:
- 改变腔长 L 同时改变模式间距和耦合强度 g (与电场分布相关)
- 频率选择滤波改变有效 Δω, 但同时改变 J(ω) 的采样密度
- 需要一个保持 g 和 κ 不变的"纯 N_E 变化"方案 — 这可能通过动态耦合 (tunable coupler) 实现, 但增加了实验复杂度。

## 8. 总结

### 8.1 已完成

1. **严格定义**了信息回流事件的数学结构 (定义 1.2-1.5)。
2. **建立了宏态转移的组合学** (引理 2.1-2.5): 期望转移矩阵独立于出发宏态 (秩 1 矩阵), 平稳分布分别为二项分布 (情形 B) 和超几何分布 (情形 A)。
3. **证明了两种情形下的回流上界**:
   - **情形 A** (K 守恒): P_reflux ≤ T · (q_S/(1−q_S))^δ · ((1−q_E)/q_E)^δ · Poly(...) — q_S 和 q_E 皆约束回流。
   - **情形 B** (K 不守恒): P_reflux ≤ T · Σ C(N_S, j) / 2^{N_S} — 仅 q_S (通过容量) 约束回流, q_E 无关。
4. **统一了容量比渐近**: 大 N 下, 大振幅回流被指数压制, 压制形式取决于守恒状态。
5. **给出了电路 QED 检验方案**: 通过改变有效环境大小, DGF 预言 P_reflux 随之变化 (∝ 1/N_E), 标准 Lindblad 预言不变 — 这是可检验的区分。
6. **诚实标注了 6 个 gap**: 细胞基优先 (最严重), 有效细胞数估计, UMP 物理合理性, K 守恒的二元简化, 回流定义参数, 和实验控制困难。

### 8.2 与 Round 1 的整合

S1 填补了 T3 留下的缺口:
- T3a 给出了微态回复时间 (= 2^{N_S}) — 精确但仅适用于精确微态回复。
- S1 给出了**宏态** (k) 回流的概率上界 — 适用于任何振幅 δ 的回流。
- T3a 的结果 (2^{N_S}) 是 S1 中 δ = N_S (完全回复) 且情形 B 的特例: π_B(N_S) = 1/2^{N_S}, 期望回复时间 = 2^{N_S}。一致。
- S1 的新贡献: 显示了环境状态 (q_E) 何时以及如何约束回流 (情形 A), 以及何时不约束 (情形 B)。

### 8.3 理论状态

S1 在数学上严格 (给定其假设) 但有三个物理 gap 阻碍了直接应用:
1. 细胞基优先 (影响所有基于"占用数"的陈述)
2. N_S, N_E 的物理估计 (影响定量预言)
3. UMP 在物理系统中的适用性 (影响典型界 vs 普适界)

定理提供了 DGF 框架下第二个**可检验的纯预测** (第一个是 τ ∝ ρ): 信息回流上限随有效环境容量 N_E 的定标。此预测与标准理论有零参数差异 (DGF: P_reflux 依赖于 N_E; 标准: 不依赖), 存在于可实验探索的参数区间。
