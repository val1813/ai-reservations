**日期:** 2026-06-06

## 0. 复数的真相

量子力学用复数α|0⟩+β|1⟩。但复数在这里唯一的功能是：**携带相位。**

α = |α|e^{iθ₀}。真正重要的只有：
- |α|（幅度）—实数
- θ₀（相位）—实数，在[0, 2π)上循环

**复数是循环实数的数学速记。e^{iθ}不是物理实体。**

---

## 1. 相位在DGF中的物理对应

### 1.1 相位 = 因果事件计数

一条因果路径：A→B→C→...→Z。

沿路径的每一步是一个因果事件（溢出）。路径积累的因果事件总数 = n。

相位: θ = 2π × (n mod K) / K

其中K是某个特征循环长度（因果网络的基本周期）。

**相位就是因果事件的计数，模一个周期。循环实数。**

### 1.2 相对相位 = 路径差

两条路径从同一初态到同一末态：
- 路径γ₁累积n₁个因果事件
- 路径γ₂累积n₂个因果事件

相对相位: Δθ = 2π(n₁ - n₂)/K

**相对相位就是两条路径的因果事件数之差。干涉来自这个差。**

## 2. 干涉的纯实数描述

### 2.1 双缝实验（DGF版本）

光子→屏幕有两条路径：左缝(L)和右缝(R)。

路径L: 因果事件数n_L。路径R: 因果事件数n_R。

到达屏幕上某点x的"因果强度":

```
I(x) = |A_L + A_R|²
     = |r_L·e^{iθ_L} + r_R·e^{iθ_R}|²
     = r_L² + r_R² + 2r_L r_R cos(θ_L - θ_R)
```

用纯实数:
```
I(x) = r_L² + r_R² + 2r_L r_R cos(2π(n_L - n_R)/K)
```

**不需要i。cos(Δθ)是实数。Δθ = 2πΔn/K是实数。**

### 2.2 干涉的物理

- n_L = n_R（路径因果等长）：cos(0)=1 → I = (r_L+r_R)² → 亮纹（相长干涉）
- n_L - n_R = K/2（路径因果差半周期）：cos(π)=-1 → I = (r_L-r_R)² → 暗纹（相消干涉）

**干涉 = 两条路径的因果历史匹配或不匹配。匹配→增强。不匹配→消除。**

## 3. Born规则的DGF推导

### 3.1 幅度r是什么

在DGF中，一个量子态由N个细胞的系综描述。

|ψ⟩ = α|0⟩ + β|1⟩ 的含义：
- N·|α|² 个细胞处于"支持|0⟩"的配置
- N·|β|² 个细胞处于"支持|1⟩"的配置
- 这两个子系综的相对相位由它们的因果历史差决定

**|α|²和|β|²不是神秘的概率振幅平方——它们是细胞系综中的实际比例。**

### 3.2 测量=采样

测量 = 从系综中随机选一个细胞，读取它的状态。

P(0) = (支持|0⟩的细胞数)/N = N|α|²/N = |α|²
P(1) = (支持|1⟩的细胞数)/N = N|β|²/N = |β|²

**Born规则 = 大数定律。概率 = 系综中的比例。**

### 3.3 为什么是平方

不是"概率是振幅的平方"——那个叙述暗示振幅是基本的而概率是衍生的。

**真实的顺序反了:** 比例（概率）是基本的。|α| = √(N₀/N) 是从比例算出的平方根——它是"概率的振幅表示"，引入它是为了能叠加（因为概率不能直接叠加，但振幅可以）。

**|α|² = q₀（支持|0⟩的细胞比例）。振幅|α| = √q₀是衍生量，概率q₀是基本量。**

## 4. 完整的纯实数QM表述

### 4.1 用(r, θ)代替复数

量子态: |ψ⟩ = (r₀,θ₀)|0⟩ + (r₁,θ₁)|1⟩

其中:
- r₀, r₁ ∈ [0,1], r₀² + r₁² = 1
- θ₀, θ₁ ∈ [0,2π)，循环实数

演化: (r(t),θ(t))由DGF的因果动力学决定

测量: P(0)=r₀², P(1)=r₁²（大数定律）

干涉: 两条路径叠加→ cos(Δθ)项

### 4.2 和标准QM的等价性

标准QM: α = r₀e^{iθ₀}, β = r₁e^{iθ₁}。

这是同一个物理的两种写法。复数版的数学更方便，纯实数版的物理更清晰。

**两者等价。不是"哪个对哪个错"——是"哪个在概念上更基本"。**
