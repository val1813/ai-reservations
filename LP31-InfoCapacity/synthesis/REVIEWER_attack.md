# 拒稿理由三: 可检验性缺失 (UNTESTABLE)

**严重度: FATAL**

## 3.1 三个"可检验预言"逐一审查

论文声称有三个可检验预言。逐一审查：

### 预言1: τ∝ρ（被B博士Round 2深挖）

数学上正确（在Poisson+ΔN∝V机制下），但：
- **ΔN标度不确定**: 论文假设ΔN∝V（所有Planck细胞参与叠加）。标准量子力学说只有质心自由度参与。如果ΔN~O(1)，τ∝ρ退化为τ₁/τ₂≈1——不可区分。
- **ε可及性困境**（PI_synthesis_round2.md最深发现）: 可测量窗口(ε~10^-125±5)占ε可能范围的**可忽略部分**。当前实验约束排除的ε值对应τ~0.5 ns，尚未排除的ε值对应τ≫宇宙年龄。可检验的参数空间是测度为零的。
- **依赖Process B**: 如果Process B被移除（PI_final_synthesis的建议），该预言不再属于框架。

**审稿人判定**: 该预言实践上不可检验。一个需要精细调节参数落在"可忽略"测度区间才能被检验的预言，等同于不可检验。

### 预言2: 信息回流上限 → 电路QED检验（S1）

INSPECTOR_S1S2.md标记W2 (高严重度)：
- A博士将DGF的"封闭系统均衡"与Lindblad的"开放系统稳态"直接对比——这是**不公平的对比框架**。

**审稿人判定**: 该预言在当前实验框架下无法干净检验。实验方案存在基础性的对比框架错误。

### 预言3: 隔离自发经典化（S2）

S2结论: 不是A1+A2的定理，且与ETH不可区分（B博士诚实自评）。

零个预言可以在当前或近期技术上被干净检验。Popper会说：可证伪但不可检验 = 不可证伪。

## 3.2 q不是可测量的可观测量

INSPECTOR_round1.md WARNING-6独立确认：q没有独立的测量协议。q的定义(k占用细胞数/N)要求微观地知道每个细胞的占用状态——这在实验上等同于全状态层析，对N>10在实践上不可行。

更致命的是，在细胞基优先问题(GAP-4.1)未解决的情况下，q是基依赖的量。同一个物理态在不同基下有不同的q值——一个系统可以同时是"经典的"(在某个基下q≈0)和"量子的"(在另一个基下q≈1/2)。INSPECTOR写道："Without resolving it: q is a basis-dependent quantity ... The claim 'q -> 0 implies classicality' could be basis-relative. The same system could be 'classical' in one cell basis and 'quantum' in another."

一个理论的核心参数既不可测量又不基独立——这个理论没有经验内容。

## 3.3 "可证伪但不可检验"的Popper问题

DGF的辩护路线是："我们给出了可证伪的预言——如果实验否定它们，理论被排除。因此理论是可证伪的。"

Popper的回应是明确的：一个理论只有在存在**实际可行的**证伪实验时才是有经验内容的。一个"原则上"可证伪但实践上永远不可检验的理论，在科学上等价于不可证伪的理论。

弦理论的教训在此处适用：一个理论可以产生数学上精确的预言，但如果这些预言需要的能量/精度超出了任何可预见的实验能力，它就不是经验科学。DGF的ε~10^-117精细调节问题与此直接平行。

### 作者最佳反驳
"τ∝ρ的**比值**预言是参数无关的——ε在比值中消去了。这是一个真正的、干净的、参数无关的可检验预言。同样，信息回流上限的形式（P_reflux ≤ T·(q_S/(1-q_S))^δ·((1-q_E)/q_E)^δ）独立于ε、ΔN标度、和Process B的存在——只要细胞基可以被操作性地定义。实验不需要测量q的绝对值——只需要测量P_reflux随N_E/腔长的相对变化。这是一个零参数差异的预言。"

### 审稿人反击
τ∝ρ比值虽然参数无关，但它预言的是**不同材料**间的退相干时间比值。你需要先测量gold的绝对τ，再测量silica的绝对τ，然后取比值。如果两者的绝对τ都不可测量（因为ε太小或太大），比值就不可测量。参数的消去在公式中是数学事实——但在实验室中，你无法消去还没有测量到的量。关于回流上限——INSPECTOR已经证明，在公平的封闭系统对比框架中，DGF和标准QM预测无零参数差异。你的"零参数差异"声称基于不公平的对比。

# 拒稿理由四: 内部不一致 (INTERNAL INCONSISTENCY)

**严重度: SEVERE → FATAL（累积效应）**

## 4.1 Process B的同时依赖和否定

论文不能同时：(a) 建议移除Process B以简化框架，(b) 保留依赖Process B的τ∝ρ为框架的定量预言。

作者需要做出选择：

## 4.2 情形A vs 情形B: 哪个是物理世界？

S1回流定理在两个互斥假设下给出两个不同的界：
- **情形A** (K守恒): P_reflux ≤ T·(q_S/(1-q_S))^δ·((1-q_E)/q_E)^δ — q_E约束回流。
- **情形B** (K不守恒): P_reflux ≤ T·ΣC(N_S,j)/2^{N_S} — q_E不约束回流。

这两个界在性质上不同——一个依赖环境状态，一个不依赖。哪个对应物理世界？

论文的策略是"两个都算，让读者选"。但物理世界要么有守恒量（总激发数守恒在封闭系统中近似成立），要么没有。论文没有论证：
- 现实系统中K的守恒程度（如何从系统Hamiltonian推导ΔK的特征幅度）
- 交叉时间尺度（在什么时间尺度上情形A过渡到情形B）
- 哪个情形对电路QED实验适用（第6节的设计似乎暗示情形A，但未明确论证）

保留两个互斥的情形作为"都可以"不是物理——这是数学可能性枚举，不是物理理论选择。

## 4.3 经典比特 vs 量子细胞的框架裂缝

INSPECTOR_round1.md WARNING-4: A博士的定理1-3建立在**经典**二元细胞上（X={0,1}^N, f是置换，熵是Shannon熵）。B博士的定理4-5建立在**量子**细胞上（Hilbert空间，量子测量，退相干）。

两个框架使用相同的词汇（"细胞"、"占用"、"q"），但运行在根本不同的数学结构中。A博士从未提及量子力学。B博士假设A博士的经典定理适用于量子细胞模型——但从未论证从经典比特到量子比特的桥接。

T2a的恒等式在经典信息论中严格成立，但不适用于量子语境——von Neumann熵在粗粒化下不满足同样的恒等式（因为量子测量引入额外的量子不确定性）。T3a的Kac回复时间依赖经典保测系统的结构——量子动力学（幺正演化在Hilbert空间而非相空间上）有不同的周期性和回复性质。

这不是一个小裂缝——这是论文的左半部分和右半部分运行在不兼容的数学框架上。

## 4.4 熵"第二定律"不是定律

INSPECTOR标记为BLOCKING-NEAR（接近阻断）：
- T2b证明**单步**熵不降（从D[ρ]=0的初态出发），但**不能链式迭代**——步间S可以下降（N=3数值验证：Step 1→2，S下降）。
- S[p_t] ≥ S[p_0]对所有t成立（从初态的下界），但这不是单调性——这是"永不低于初值"，不是"永不下降"。
- 将其称为"条件性第二定律"在名称上过度声称。它是一个熵下界，不是第二定律。
- INSPECTOR: "S[p] is NOT a Lyapunov function for the dynamics ... The term '第二定律' implies monotonicity, which does NOT hold here."

T2c有Jensen问题——凹熵函数使E[S[p']] ≤ S[E[p']] = S[π]，无法直接推出期望熵增。论文将此标记为技术性问题但未解决。

框架的"第二定律"论证有三个不：
1. 不能链式迭代（步间非单调）
2. 不能处理Jensen方向（凹函数反号）
3. 不能产生Clausius意义上的单调熵增

将其包装为"条件性第二定律"是对术语的滥用。

# 拒稿理由五: 与已知物理冲突 (CONFLICT WITH KNOWN PHYSICS)

**严重度: SEVERE**

## 5.1 隔离系统: 幺正性 vs 自发经典化

标准量子力学: 完美隔离的系统在Schrödinger方程下永远幺正演化。相干性永不自发丧失。

DGF v5声称: 即使完美隔离，内部信息积累导致q→0，系统自发经典化。这是DGF与标准QM最尖锐的差异点——也是框架最有区分度的预言。

DGF v6现实(S2结论): 这个声称不是定理。在A1+A2下，隔离系统的长时间平均q=1/2（Stirling），不是0。q→0需要f属于测度为0的集合（M3棘轮置换）——对应物理上不可能的精细调节。"隔离自发经典化"被降级为假说。

论文现在处于一个尴尬的位置：
- 如果它坚持隔离自发经典化（与标准QM冲突）→ 声称没有数学基础，且被作者自己的S2分析否定
- 如果它放弃隔离自发经典化 → 框架失去与标准QM的唯一区分度 → DGF等价于标准QM的新词汇

INSPECTOR在Round 1的最终判断直接点破了这一点："DGF is a conceptual framework/language for describing known physics ... Its value is hermeneutic (understanding), not predictive (new phenomena)."

## 5.2 退相干: 环境谱密度 vs 信息容量

标准退相干理论: 退相干速率由环境谱密度J(ω)和环境温度T决定——Γ = J(ω_q)·coth(ħω_q/2k_BT)。

DGF: 退相干速率由信息容量决定——Γ ∝ 1/(环境容量) ∝ 1/N_E。

这两个机制是否相容？论文从未调和：
- 如果两者是同一机制的不同描述 → DGF没有新物理
- 如果两者是不同的机制 → 当两者给出不同预言时（例如在特定J(ω)和N_E的组合下），哪个是正确的？

实验（超导qubit、陷获离子、NV中心）已经在广泛参数范围内以高精度验证了标准退相干理论。DGF需要展示其退相干机制要么(a)等价于标准理论，要么(b)在尚未探索的参数范围内给出不同的、可检验的预言。当前论文两者都没做到。

## 5.3 Malament定理和"时间=DAG"

DGF声称"时间=因果DAG"且引用Malament (1977)作为支持。但：
- Malament定理: **连续**因果结构 → 度规共形类。其前提包括流形结构、光滑性、过去/未来可区分性——这些都是DGF的**离散**DAG所不具有的。
- DGF的DAG是**离散**偏序——从离散到连续的桥接（Hauptvermutung of causal set theory）至今未被证明。
- 即使接受"时间=因果DAG"，DGF从未展示这个DAG如何产生4维洛伦兹度规——为什么是(3,1)号差而非(2,2)？为什么是4维？论文从未触及这些问题。

声称"时间从因果DAG涌现"并引用Malament定理，是对该定理范围和含义的重大误读。INSPECTOR正确地驳回了B博士的部分批评（Malament定理方向性的错误），但更深层的问题依然存在：即使Malament定理支持"因果→度规共形类"，它要求的是**连续因果结构**，不是离散DAG。

## 5.4 与Chiribella et al. 2011的关键对比

Chiribella, D'Ariano, & Perinotti (2011, PRA 84, 012311): 从5条信息论公理**严格推导**出量子理论的全部数学结构——Hilbert空间、张量积、幺正演化、Born规则。

DGF声称从2(3)条公理推导出"经典世界的涌现"——但：
- CDP: 5公理 → 完整的量子理论（充分性证明完整）
- DGF: 2(3)公理 → 经典世界的涌现（充分性证明不完整——A4a/b/c未被推导）

这是不对称的。CDP用5条公理完成了从信息到量子理论的完整推导链，每一步都是定理。DGF用2条公理声称更多（经典世界的涌现 + 时间 + 不可逆性），但需要的实际公理数量已达5+（A1, A2, A4a, A4b, A4c + 可能需要UMP/遍历性）。

声称用更少的公理推导出更多的东西，但推导链不完整——这不表明框架更强，只表明框架尚未完成其声称的推导。

### 作者最佳反驳
"隔离自发经典化并非框架的核心声称——它被S2诚实评估为假说并已降级。框架的核心是分离机制：信息有向流动+容量有限→一方困在q=0吸收边界+一方驻留在q≈1/2统计偏好。这个机制与标准QM完全相容——它不要求修正量子力学。关于退相干：DGF的容量依赖性不是一个替代标准退相干理论的竞争机制——它是一个互补的视角。就像热力学和统计力学对熵增提供了互补的解释一样，DGF和标准退相干理论可以共存。关于Malament：论文从未声称从离散DAG推导完整的洛伦兹度规——只声称因果结构是时间的基础。INSPECTOR确认这个声称在方向上是合理的。"

### 审稿人反击
如果框架的核心机制与标准QM"完全相容"，那框架的价值是什么？一个与现有理论完全相容但不产生新预言的概念框架不是物理理论——它是哲学。热力学和统计力学虽然互补，但统计力学产生了热力学不能产生的具体预言（涨落、临界指数、输运系数）。DGF产生了什么标准退相干理论不能产生的具体预言？零个——根据你自己的INSPECTOR的判断。

关于Malament：你说论文只声称"因果结构是时间的基础"——但v5论文声称的是"时间从因果DAG涌现"。两者有根本区别。"是基础"是概念声称，"从...涌现"是物理解释。论文声称的是后者，但没有提供涌现的数学机制。

# 额外攻击角度

## 额外一: 公理基础的持续膨胀——倒退而非前进

**严重度: SEVERE**

公理数量的演变：
- v5声称: A1+A2 (2条公理) 足以导出"宇宙必然如此"
- A4_analysis揭示: 实际需要A1+A2+A4a+A4b+A4c (5条假设)，且A4b和A4c仍是猜想
- 公理膨胀轨迹: 2 → 3 → 5+ （且仍在增长）

这是倒退。科学理论进步的标志是用更少的公理解释更多的现象。DGF正好相反——随着审查的深入，发现需要越来越多的公理来解释最初声称的现象。

对比：
- Euclid几何: 5条公设 → 完整平面几何
- Newton力学: 3条定律 → 经典力学
- 狭义相对论: 2条公设 → 全部运动学和动力学
- CDP 2011: 5条公理 → 完整量子理论
- DGF 2024-2026: 2(→3→5+)条公理 → 尚未完成推导链

更糟糕的是，最初的2条公理(A1+A2)被A4_analysis证明几乎空洞："A1+A2只给出有限集X={0,1}^N上的一个置换f。这个结构太弱，以至于无法定义'细胞'"。论文声称从2条"几乎空洞"的公理推导出丰富的物理——实际推导的是，这2条公理太空了所以必须在每一步暗中引入额外结构。

## 额外二: 数学vs物理的范畴错误——从离散置换到宇宙学的跳跃

**严重度: FATAL**

DGF的所有严格定理(T1-T3, S1)都在以下设定中：
- 有限集X={0,1}^N
- N个二元细胞（N的取值为数学参数，非物理量）
- f是X上的置换（纯组合对象）

论文声称的物理应用：
- 量子退相干（需要Hilbert空间、幺正演化、连续时间、无穷维环境）
- 黑洞热力学（需要弯曲时空、QFT、事件视界）
- 宇宙学（需要FLRW度规、Friedmann方程、密度涨落）
- 经典世界的涌现（需要~10^23个真实自由度、温度、能量标度）

从N个二元细胞上的置换到上述物理应用的跳跃，论文在任何地方都没有论证过。关键的桥接一步：
- 离散→连续极限：未处理
- 经典比特→量子比特：INSPECTOR WARNING-4识别但未解决
- 信息容量→时空几何：仅"暗示"从未推导
- 组合概率→物理概率：未论证为何组合计数对应物理概率

这是一个范畴错误：将有限离散数学的定理当作是关于连续量子物理的陈述。论文的保护层(层次1-4)承认了部分限制，但这不能修复根本问题——如果你所有严格定理都在层次1-2(定义性+结构性推论)，而你所有物理声称都在层次3-4(模型依赖+偶然)，那你的"定理"与你声称解释的物理现象之间没有严格的推导关系。

# 最终综合: 五条拒稿理由的协同效应

单条拒稿理由可能被逐一反驳，但五条理由的**协同效应**描绘了一篇不可发表的论文：

1. **不是新物理** (FATAL): 核心定理是已知数学的重新推导。物理内容是标准退相干+量子达尔文主义的新词汇。

2. **声称大于证据** (FATAL): 持续的声称降级轨迹+基涌现被证伪为假说而非定理+框架实际解释的结构远少于声称的。
