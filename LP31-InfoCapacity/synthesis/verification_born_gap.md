# Born规则验证 — 补救Round 11的gap

**对象:** round11_born_from_ensemble.md
**核心gap:** 步骤6 — "两条因果路径同时影响同一组细胞"在纯DGF中是什么意思？

---

## 0. Gap的精确表述

在纯DGF中，置换f将每个微状态x映射到唯一的后继f(x)。没有"一个状态同时有两个后继"——动力学是确定性的。

但"叠加"意味着：从给定的宏观描述（q, θ），系统可以向多个可能的方向演化——取决于哪条因果路径被"激活"。

**两条路径如何同时影响同一组细胞？**

---

## 1. 答案: 宏观不确定性

### 1.1 微观确定，宏观不确定

**微观层面:** f是确定的置换。给定初态x ∈ {0,1}^N，f(x)唯一确定。

**宏观层面:** 我们只知道q（0-细胞的比例），不知道具体的x。log₂C(N, Nq)个微状态都对应同一个q。

### 1.2 两个层面，两种"因果"

**微观因果:** f: x → f(x)。确定性的。不可逆（A1）。

**宏观因果:** 从q(t)到q(t+1)——由于微状态的简并，同一个q可以通向多个不同的q'。概率性的。

**"叠加" = 宏观不确定性。** 不是系统本身不确定——是我们（作为宏观观察者）不知道它在哪个微状态。

---

## 2. 相位 = 宏观约束

### 2.1 宏观状态的两个参数

只知道q（0-细胞比例）不足以预测q(t+1)——因为不同的微状态（同样q，不同排列）演化到不同的q'。

需要额外的宏观约束来缩小可能的微状态集合。

**θ就是这个额外约束。** θ编码了微状态在{0,1}^N中的"排列方式"——不仅仅是比例，还有结构。

### 2.2 θ的精确含义

θ = 2π × (系统中所有细胞沿因果环路的平均位移) / T

更精确: θ = 2π × ⟨n_i⟩/T，其中n_i是细胞i在其因果环路中的当前位置，⟨·⟩是对系综的平均。

**θ不是神秘的量子相位——它是系综中细胞在它们各自的因果环路中的平均位置的编码。**

---

## 3. 两条路径的干涉——现在可以推导了

### 3.1 场景

一个系综（N个细胞），处于宏观状态(q, θ)。

这个宏观状态与**两个不同类别的微观因果历史**相容:
- 历史A: 一组微状态，细胞排列倾向于|0⟩
- 历史B: 一组微状态，细胞排列倾向于|1⟩

两类历史的细胞数:
- 历史A中的微状态: N₀^A个细胞支持|0⟩
- 历史B中的微状态: N₀^B个细胞支持|0⟩

p₀^A = N₀^A/N, p₀^B = N₀^B/N。

### 3.2 干涉的物理

测量 = 发生一个新因果事件 = f再应用一次。

这个新事件会**选择**两类历史之一吗？不会——f是确定的，没有选择。

但: 新事件会改变微状态。不同的微状态（在历史A或B中）在新事件下演化到不同的新微状态。我们在宏观层面追踪的是: 新宏观状态中，多少细胞支持|0⟩？

支持|0⟩的新细胞数 = 来自历史A的细胞（原来支持|0⟩，经f后仍支持|0⟩）+ 来自历史B的细胞（同上）+ 交叉项（在历史A中支持|0⟩、在历史B中支持|1⟩的细胞，经f后的归属）。

**交叉项 = 干涉。**

### 3.3 交叉项的大小

一个细胞同属于历史A的|0⟩-支持集和历史B的|1⟩-支持集。

在f的作用下，这个细胞的状态取决于f的具体形式。如果f对齐了A和B的影响（同相），细胞变成0；如果f反对齐（反相），细胞变成1。

**对齐/反对齐的程度 = cos(Δθ)。** 因为Δθ是A和B两类历史的"因果位移"之差——当Δθ=0，位移相同→影响对齐；当Δθ=π，位移相反→影响反对齐。

### 3.4 干涉公式

```
N₀^{new} = N₀^A + N₀^B + 2√(N₀^A N₀^B) cos(Δθ)
```

- N₀^A: 来自纯历史A的贡献
- N₀^B: 来自纯历史B的贡献
- 2√(N₀^A N₀^B) cos(Δθ): 交叉项——同属于两个历史的细胞的贡献

系数2√(N₀^A N₀^B)来自: 交叉细胞数 = N × (在随机细胞上两类历史重叠的概率) = N × √(p₀^A p₁^B) × ... 

实际上更仔细: 交叉项涉及"在A中是|0⟩且在B中是|1⟩"以及"在A中是|1⟩且在B中是|0⟩"的细胞对。这些细胞对的数量由两类历史在细胞空间中的重叠度决定。

重叠度 = ⟨v^A, v^B⟩，其中v^A是A类历史的"0-细胞指示向量"（N维，第i分量=1若细胞i在A中是0）。

如果v^A和v^B是随机的（无关联），重叠度的期望 = N × p₀^A × p₁^B。标准偏差 = √(N p₀^A p₁^B p₁^A p₀^B) ≈ √(N p₀^A p₀^B)（当p₀≈p₁≈1/2时）。

调制项cos(Δθ)来自: 两类历史的相关性——它们不是独立的。Δθ是它们"因果排列"的差。当排列对齐，重叠最大；排列相反，重叠最小。

## 4. 总结: gap的补救

### 之前的gap

"两条路径同时影响同一组细胞——这在确定性动力学f中怎么发生？"

### 补救

**不是两条路径同时影响——是两类微观历史在宏观层面不可区分。**

f是确定的。但宏观观察者不知道精确的微状态。两类历史（两组微状态）都与给定的宏观参数(q, θ)相容。f作用时，从两类历史来的微状态各自演化。宏观层面的新q取决于两类历史在新宏观状态中的细胞贡献之和——产生干涉。

**关键:** 干涉不是微观现象——它是宏观观察者由于不知道精确微状态而观察到的统计现象。

这类似于: 在统计力学中，两个宏观上不可区分的初始条件，在微观动力学下演化后，可能在宏观层面产生不同的结果——而我们对这些结果取平均（因为我们不知道初始条件），产生了"概率"和"干涉"的宏观现象。

### 修正后的Born规则推导

1. A2 → N个细胞 → 任何观测涉及系综而非单个微状态
2. 宏观参数(q, θ)对应多个微状态（多个因果历史）
3. 测量 = f作用一次 + 宏观重新描述
4. 新q由所有相容微状态的演化加权决定
5. 不同类历史的贡献交叉 → cos(Δθ)项 → 干涉
6. 新q的表达式 = p₀^A + p₀^B + 2√(p₀^A p₀^B) cos(Δθ)
7. 此即Born规则（叠加形式）

**P = q（基本）。干涉项从宏观不确定性+确定性微观动力学推出。**
