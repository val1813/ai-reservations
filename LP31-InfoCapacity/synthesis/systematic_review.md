## 二、框架能否解释其他现象？

### 可以尝试的

**1. 暗能量（真空能量密度）**
- q_background = 1/2 → 非零真空信息密度
- 但自信息形式q_background = 1（因为D(1)=κ有限→真空稳定→q=1是自然背景）
- 两个候选通量给出不同背景值——这是框架内部的张力
- **状态: 不能解释。** 通量形式未唯一确定→背景q值未确定→真空能量未确定

**2. 暴胀**
- q→0时D→∞ → 极快扩散 → 自然暴胀期
- 当q很小时均匀化极快，"冻结"随q增大
- **状态: 定性可解释。** 定量需初始q值和ε（已放弃）

**3. 暗物质**
- q≈0但不发光的区域→有q梯度→有引力效应→类似暗物质
- 但什么机制产生不发光的q≈0区域？纯q场凝聚？
- **状态: 高度推测。** 无具体模型

**4. 量子纠缠**
- q度量相干容量。纠缠需要q>0（有空余容量）
- 但q和纠缠的具体关系未建立
- q→1: 最大纠缠能力
- q→0: 零纠缠（经典关联只能）
- **状态: 概念上可关联。** 但q是单体量，纠缠是两体量——需要推广

**5. 测量问题**
- q=0 = "测量结果被记录"——信息容量耗尽，再无叠加可能
- 不需要"观察者"——只需要容量不对称
- 这和量子达尔文主义一致但不必引入外部环境
- **状态: 概念上有趣。** 可以说"DGF为测量问题提供了信息论重述"

**6. 波函数坍缩**
- 坍缩=信息从系统流向环境→q_S下降→相干性消失
- 但坍缩的"随机结果选择"（Born规则）不能从框架推出
- **状态: 部分解释。** 机制可解释，概率测度不可解释

## 三、潜在矛盾

### 矛盾1: q的双重身份（严重性: 高）

q = 信息容量的空置比例（古典统计）
q = l1-norm of coherence（量子相干度量）

这两个定义在数学上等价，但在物理上对应不同的东西：
- 容量: "有多少空位可以存信息"——这是关于**能力**的
- 相干: "非对角元有多大"——这是关于**状态**的

一个均匀混合态 I/d: q_capacity = ? q_coherence = 0
一个Bell对: q_capacity = ? q_coherence = 1

这两个q值是否总是一致？如果不是，框架在使用哪一个？

**状态: 未解决。** 在弱耦合+指针基下可能近似一致。但一般情况需要论证。

### 矛盾2: 背景q值的不确定（严重性: 中高）

- 自信息形式 → D(1)=κ有限 → q=1真空稳定
- 渗透压形式 → D(1)=D₀有限 → q=1真空稳定
- 香农熵形式 → D(1)=∞ → q=1真空不稳定 → 背景q=1/2
- 标度不变性 → D(q)=D₀/q² → 另一选择

哪个是正确的？框架内部没有选择机制。这是一个真实的未解决分岔。

**状态: 开放。** 可能通过实验区分（不同背景q值给出不同宇宙学预言）。

### 矛盾3: 抛物型方程的因果性（严重性: 中）

抛物型PDE有无穷传播速度——信号瞬时到达任意远。

离散模型：传播速度=c（每步一个格点）
连续模型：传播速度=∞（PDE特征）

这是paradox还是近似artifact？如果是近似artifact，它的适用范围是什么？

- 在q≈1处：D(1)=κ，有限扩散→前沿速度有限→近似有效
- 在q≈0处：D(0)=∞→"瞬时"响应→连续近似在此失效→需离散描述

**状态: 部分解决。** q≈1处连续近似有效，q≈0处需离散。范围清楚但仍需诚实声明。

### 矛盾4: 信息流动方向的统计性（严重性: 低）

定理2: 熵增非单调（INSPECTOR N=3验证）
叙事: "信息从高占用流向低占用"（像定律）

叙事和数学之间的张力。叙事说"总是"，数学说"统计上大概率"。

**状态: 措辞问题。** 可以诚实修正为"统计倾向"。

## 四、框架当前的诚实边界

### 能解释的（给定A1+A2+A3+通量选择）

1. 为什么量子-经典分离存在 → 双域相共存
2. 为什么分离有方向 → 1/q非线性
3. 为什么引力方程是拉普拉斯型 → 静态极限
4. 为什么1/r衰减 → d=3的Green函数
5. 为什么不可逆性依赖尺度 → T3区分弛豫和回复
6. 为什么边界是软的 → 抛物型方程固有特征

### 不能解释的

1. c, ℏ, G的具体数值
2. 为什么d=3
3. 粒子物理/标准模型
4. 分离的具体尺度
5. 引力波（需双曲推广）
6. Born规则（量子概率）
7. 暗能量/暗物质（通量形式未唯一）
8. 暴胀的具体参数
