# DGF对称性纲领 — 从守恒律反推框架

**日期:** 2026-06-06
**核心问题:** 如果宇宙由DGF描述，它必须有哪些守恒律？这些守恒律能否从A1+A2推出？

---

## 0. 对称性-守恒律对应 (DGF版Noether)

在DGF中，动力学是置换f: X→X, X={0,1}^N。

**守恒量** = f的不变量: I(f(x)) = I(x) ∀x。

**对称性** = 保持f结构不变的X上的变换群。

离散版"Noether定理": f的每个连续对称群生成一个守恒量（f的不变量）。

**证明:** 若群G作用在X上且与f交换(g∘f = f∘g)，则G的Casimir算符（或更一般地，G在X的轨道上的特征标）是f的不变量。

但DGF没有连续群——X是离散的，f是置换。对称性是**置换群**的子群。

**离散推广:** f的每个对称群（与f交换的置换）→ 一组守恒量（f的不变量）。不变量个数 = f的循环分解中，在对称群作用下封闭的循环族数。

## 1. 宇宙已知的守恒律 → 对称性需求

### 已知守恒律（精确+近似）

| 守恒律 | 对称性 | 在DGF中的含义 |
|--------|--------|-------------|
| 能量E | 时间平移t→t+δt | f不依赖步数（f恒定） |
| 动量p | 空间平移x→x+a | f在细胞平移下不变 |
| 角动量L | 空间旋转SO(3) | f在细胞旋转置换下不变 |
| 电荷Q | U(1)规范 | f保持某种"荷"计数 |
| 重子数B | U(1)近似 | f近似保持"重子"计数 |
| CPT | CPT | f的某种离散对称 |

### 哪来的?

**能量:** 如果f在每一步是相同的（时间均匀），则存在离散时间平移对称性。在连续极限下→能量守恒。

**动量:** 如果细胞排列在规则格点上（空间均匀），f在格点平移下不变→动量守恒。

**角动量:** 如果细胞排列在3D各向同性格点上，f在SO(3)下不变→角动量守恒。

## 2. 核心分歧: 哪些来自A1+A2，哪些需要额外公理

### 层级0: A1+A2自动给出

**信息守恒（总状态可区分性守恒）:** 来自A1(单射)+A2(有限)。
- 在置换f下，不同的初态→不同的末态→信息不可摧毁
- 这是框架内唯一的"免费"守恒律

### 层级1: 从A2的因子化结构推出

**全局容量守恒:** ∫q dV = const。
- 来自连续性方程∂_t q = -∇·J (Noether型)
- 不是独立守恒律——是信息守恒在粗粒化层面的表现

**q (局域容量)在局域酉群下守恒:** 
- 来自A2的因子化H = (C²)^{⊗N}
- 今天已证明

### 层级2: 需要额外公理

**A3 (占用数守恒):** f保持Σ s_i。
- → 离散U(1)对称性
- 物理: 粒子数/荷守恒
- 从A3可以推出Born规则的某些特征（计数守恒→概率来自组合）

**A4 (格点均匀性):** f在格点的空间平移群下不变。
- → 动量守恒（连续极限）
- 物理: 空间均匀→动量守恒

**A5 (格点各向同性):** f在格点的SO(3)子群下不变。
- → 角动量守恒
- 物理: d=3 + 各向同性

**A6 (时间均匀性):** f_t = f (与t无关)。
- → 能量守恒
- 物理: 时间平移不变性

### 层级3: 可能从动力学涌现

**标度假定:** 格点间距a在低能标度下不变→标度对称性。
- 可能从f的重整化群流涌现
- 物理: G的数值被标度假定约束

**拓扑守恒:** 格点的某些全局构型在f下不变。
- 可能从f的拓扑性质涌现
- 物理: 粒子谱→拓扑孤子

## 3. 最简公理系统推测

要使DGF产生已知物理的全部守恒律，最少需要:

```
A1: f是单射
A2: |X|=2^N（因子化H=(C²)^{⊗N}）
A3: f保持Σ s_i（占用数/荷守恒）
A4: 细胞排列在3D格点上，f在3D欧几里得群下协变
A5: f不依赖于t（时间均匀）
```

**从这五个公理可能推出的:**
- A1+A2 → 信息守恒, q守恒, 全局容量守恒
- A3 → Born规则（组合计数→|ψ|²）, 电荷型守恒
- A4 → 动量+角动量守恒, d=3, 1/r势（从3D Green函数）
- A5 → 能量守恒, 引力波（时间均匀→可定义频率→波解）

**仍然缺失的:**
- G的数值（需要标度假定）
- 粒子谱（需要拓扑+量子场论）
- 暗能量（需要真空对称性破缺）
- U(1)相位的复数结构（需要...见下）

## 4. 最大的洞: 复数从哪里来?

A1+A2+A3+A4+A5都是关于**实二元变量**s_i ∈ {0,1}。

但量子力学需要**复数振幅**α|0⟩+β|1⟩, α,β∈C。

**复数结构是U(1)相位对称性的数学前提。**

在DGF中，复数从哪里来？

### 假说1: 从格点循环涌现

考虑格点上的闭合环路（循环）。沿环路行走，f施加一系列比特翻转。如果环路上的翻转形成闭合代数→这个代数的表示可能是复数的。

具体: 考虑三个细胞排列成三角形。f可能包含循环置换 (s_1,s_2,s_3) → (s_2,s_3,s_1)。这个Z_3对称性的特征值是e^{2πi/3}——复数出现了！

**格点上的环路（循环图结构）自然产生复数（单位根）。**

### 假说2: 从信息通量的"流"结构

通量J = φ(q_i)-φ(q_j)定义了格点上的"流"。如果流有涡旋结构（旋度非零），则需要复数来描述"方向"。

**流的拓扑→复结构。**

### 假说3: 从量子力学的Feynman路径积分

Feynman的路径积分公式中，相位e^{iS/ℏ}来自经典作用量S。在DGF中，"作用量"的对应物是什么？

候选: **总信息溢出量**。每一步f产生一定量的信息溢出。沿某条"路径"（一系列微观步）的累积溢出量 → 作用量类比。路径间的干涉 → 相位。

**这个方向很深但完全未开发。**

## 5. 诚实状态

### 我们现在知道了什么

1. **DGF的对称性决定了它能解释什么:** 缺失的对称性=缺失的解释力
2. **A1+A2只给出信息守恒和q守恒:** 太少了
3. **需要A3(占用数守恒)+A4(3D欧氏对称)+A5(时间均匀)才能覆盖大部分物理**
4. **复数结构(U(1)相位)是最深层的缺失——它可能从格点环路涌现**

### 我们还不知道什么

1. A4(格点几何)能否从纯信息论约束推出（因果集方向）?
2. A3(占用数守恒)能否从某种"最小信息耗散"原理推出?
3. 复数结构的涌现机制——这是DGF与标准QM之间的最深鸿沟

### 最重要的未解决问题

**不是引力波，不是暗能量，不是粒子谱。**

**是: 复数从哪来？**

没有复数→没有U(1)对称性→没有Born规则→没有量子力学。

DGF目前完全建立在实数（二元变量）上。量子力学需要复数。

**如果复数不能从DGF涌现，DGF就不能是量子力学的"基础"——它只能是量子力学的"经典极限描述"。**

这意味着: DGF不是在"推导"QM——它是在描述QM的**经典化过程**。QM本身（复数、Hilbert空间、叠加）是DGF的**前提**，不是DGF的**结论**。

**这个定位改变了一切。**
