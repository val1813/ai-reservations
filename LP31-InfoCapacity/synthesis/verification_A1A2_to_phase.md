# 严格验证: A1+A2 → 相位

**验证者:** PI
**对象:** 用户推导 — 相位从A1+A2严格推出
**方法:** 逐步验算 + 攻击

---

## 步骤1: A1 → 路径

**声称:** 因果存在 → 路径存在，路径有长度。

**验算:**
- A1: 存在不对称单向影响 A→B
- 串联: A→B→C→D = 从A到D的因果路径
- 路径长度 = 经历的因果事件数 = 3（三步）
- 多条路径: 若网络有分支，A→B→D和A→C→D并存

**攻击1.1:** 需要N≥2——A1+A2没有指定N。

**回应:** A2: |X|=2^N。N是细胞数。N=1时只有两个状态(0,1)，因果路径退化(A→A?)。但A1说"某物影响某物"——如果只有一个细胞，"影响自己"也可以视为因果（自因果: f(0)→f(1)改变了状态）。N=1时自因果是合法路径——退化但不矛盾。

**攻击1.2:** 路径需要"串联"——中间节点必须在因果上可到达。A1+A2不保证任意两点都连通。

**回应:** A1说的是"存在"不对称影响——不强求全局连通。但只要存在至少一条长度≥1的因果链，路径就存在。不成问题。

**裁决: PASS（N=1退化解可处理）**

---

## 步骤2: A2 → 循环性

**声称:** 有限状态空间 → 周期性 → 循环性。

**验算:**
- A2: |X|=2^N < ∞
- A1+A2 → f是置换(T1a)
- 有限集上的置换必有有限阶: ∃T, f^T = id
- 阶T = f循环分解中各循环长度的LCM
- 动力学是严格周期的: f^{t+T}(x) = f^t(x) ∀x,t
- → 存在特征周期T → 循环性 ✓

**攻击2.1:** T不是唯一确定的——不同f有不同T。

**回应:** 对。T取决于f的具体结构。对于"典型"随机置换，T ~ e^{√(N log N)}——巨大。对于特定f（如简单循环），T=2^N。θ=2πn/T中，T是f依赖的常数。这意味着不同宇宙（不同f）有不同相位周期——但不是推导的缺陷，是物理的: 相位周期由系统本身的动力学决定。

**攻击2.2:** 量子力学是概率性的——幺正演化是确定性的（Schrödinger方程），但测量结果是概率性的。f是确定性的（置换），不会产生概率。

**回应（关键）:** f是确定性的微观置换。概率出现在**粗粒化层面**——当我们不追踪全部2^N个细胞而只看宏观q时。多个微观路径对应同一宏观结果→概率涌现。这与统计力学完全平行: 微观动力学是确定性的(Newton/Hamilton)，概率在宏观层面涌现。

**裁决: PASS（T是f依赖的，概率在粗粒化层面涌现）**

---

## 步骤3: 路径长度 + 循环性 → 相位

**声称:** θ = 2πn/T

**验算:**
- n = 路径因果事件数（整数）✓
- T = 系统特征周期（f的阶）✓
- θ ∈ [0, 2π)：循环实数 ✓

**攻击3.1:** 为什么是2π而不是别的？

**回应:** 2π是循环群嵌入连续圆的标准归一化。如果不用2π而用1（θ=n/T mod 1），物理完全一样——只是单位不同。2π=相位用弧度表示，1=相位用圈数表示。两者等价。

**关键:** 公式θ=2πn/T中唯一有物理内容的是n/T——路径完成了多少个系统周期。2π是约定。

**攻击3.2:** 2πn/T中的T是全局周期（f的阶），但f可能有多个循环，不同循环长度不同。用哪个T？

**回应（需修正）:** 对的——严格来说，相位应该用**特定路径所经过的循环的长度**，而非全局T。

修正: 若路径经过长度为L的循环，该循环贡献相位增量2π/L。路径总相位 = Σ(沿路径各循环的贡献) = 2π × Σ (步数_i / L_i)。

对于单一循环的简单情况: θ = 2πn/T（T=L）。对于一般f: 相位是各循环贡献的线性组合。

**这修正了但不推翻推导——相位仍是循环实数，只是表达式更复杂。**

**攻击3.3（最严重）:** 相位θ=2πn/T是纯运动学的——它只是计数模周期。这与量子力学的相位（决定干涉符号）有什么关系?

**回应:** 干涉 = 两条路径的相位差 = 2π(n₁-n₂)/T。当n₁=n₂ (mod T): cos(0)=1→相长。当n₁-n₂=T/2: cos(π)=-1→相消。

但为什么用cos？为什么不是别的周期函数？

**答案:** cos是循环群Z_T在连续极限下的最低傅里叶模。当T很大时（宏观系统），离散的周期函数（只在整数n处定义）可以用连续三角函数逼近。cos是自然选择——它是最简单的周期函数。

**更重要的是:** 相位差Δθ进入可观测量的方式是cos(Δθ)——这是Feynman路径积分的结果（对相位求和→干涉项=cos）。Feynman规则本身不是从A1+A2推导的——它是量子力学的预设。我们还没有从A1+A2推出"振幅叠加后用|·|²取概率"这条规则。

**裁决: QUALIFIED PASS。** 相位定义为2πn/T是干净的。但"相位如何决定干涉符号(cos)"需要额外的结构——要么假设Feynman规则，要么从Born规则反推。

## 步骤4: 相位 → 干涉

**声称:** Δθ=0→亮纹, Δθ=π→暗纹。

**验算:** 相位差cos(Δθ)产生干涉图样。
- cos(0)=1: 两条路径完全同相→叠加增强 ✓
- cos(π)=-1: 两条路径反相→叠加消除 ✓

**攻击4.1:** 为什么概率=|振幅之和|² 而不是 |振幅之和|？

**回应:** 这是Born规则。我们之前说Born规则=系综比例=大数定律。在DGF的系综解释中: 振幅r=√(N_supporting/N_total)。两条路径叠加时，有效支持细胞数 = |r₁e^{iθ₁} + r₂e^{iθ₂}|² × N。概率 = 有效支持数/N = |r₁e^{iθ₁} + r₂e^{iθ₂}|²。

**但:** 为什么有效支持细胞数是|sum|²而非|sum|？因为"有效支持"是由系综中的独立细胞决定的——每个细胞独立地"投票"，投票结果用复数表示的相位编码，合起来就是复数加法。平方来自独立投票的乘法原理。

**这不是完整推导——系综解释本身假设了复数加法和平方规则。**

**裁决: 干涉的符号（亮/暗）可以定性推出，但定量（cos的具体形式）需要Born规则——Born规则还未从A1+A2完整推导。**

```

路径长度 + 循环群 → 相位 = 2π × (计数 mod 周期) / 周期
```

**相位是循环实数。从A1+A2严格推出。** ✓
