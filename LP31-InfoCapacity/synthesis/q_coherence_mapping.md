## 0. 问题陈述

### 0.1 DGF中q的定义（三个版本）

**版本1 (原始 — 细胞占用比)**:
```
q(s) = (N - Σ_i s_i) / N
```
s_i ∈ {0,1}: 占用(1)或未占用(0)。q→1: 全空（最大叠加容量）。q→0: 全满（经典，容量耗尽）。

问题: 基依赖。在基变换下q不守恒。同一个物理系统在不同基下可以有不同q值。

**版本2 (基独立 — 轨道熵)** [Round 3, A博士]:
```
q_f(s) = log₂|Orbit_f(s)| / N
```
基独立，只依赖动力学f的轨道结构。q→1: 轨道大小=2^N（遍历全空间）。q→0: 轨道大小=1（不动点）。

问题: 失去"容量"的直觉。在全空系统(q_orig=1)时轨道熵为0——因为全空意味着没有信息可写。

**版本3 (物理解释 — 虚部距离)** [discussion_mem2o.md 第八阶段]:
```
q = 系统离"实轴"的距离，虚部还剩多少
q→1: 单位圆上有虚部，有相位，可干涉
q→0: 坍缩到实轴，虚部消失，经典
```

## 1. 候选映射评估

### 1A. q ↔ l₁-norm of coherence（归一化版）

**定义**:
```
q_{l1}(ρ) = Σ_{i≠j} |ρ_{ij}| / Σ_{i,j} |ρ_{ij}|
```
其中分母归一化保证q ∈ [0,1]。

在指针基{|i⟩}下，ρ = Σ p_i|i⟩⟨i| + Σ_{i≠j} ρ_{ij}|i⟩⟨j|。对角部分=实的（经典概率），非对角部分=一般复的（量子相干）。

**对应DGF的物理图像**:
- 对角元 = "被占用的细胞" = 已被交互历史锁定的经典事实
- 非对角元 = "未被占用的细胞" = 仍有叠加容量的量子自由度
- q = 非对角占比 = 未占用细胞占比

**两种极限的对应**:

| 标准QM | DGF | 一致性 |
|--------|-----|--------|
| 完全退相干态 ρ=diag(p_i) | q=0 (所有细胞占用) | ✓ 完全对应 |
| 最大相干态 \|ψ⟩=(1/√d)Σ\|i⟩ | q=(d-1)/d≈1 | ✓ 大d极限对应 |
| 部分退相干 | 中间q值 | ✓ 定性对应 |

**评估**:

优点:
- 物理直觉完美匹配: 对角元="已确认的事实"↔"已占用细胞"
- 退相干就是非对角元衰减——DGF的"细胞逐渐被占用"
- 相位阻尼信道直接缩减每个非对角元: ρ_{ij}→(1-p)^{|i-j|}ρ_{ij} ——对应DGF的溢出逐步填满细胞

缺点:
- q_{l1}仍然基依赖——但这是指针基，其选择由系统-环境相互作用决定（Zurek einselection），对应DGF中A4（局部性）+溢出历史选择细胞基
- 对于d维最大相干态，q_{l1}=(d-1)/d，只在d→∞时严格为1。对于有限d，q<1 ——但DGF的q也是对于有限N未达到严格1（闲置细胞数有限）
- q_{l1}对ρ_{ij}的相位不敏感——只依赖|\ρ_{ij}|。但DGF的"虚部距离"解释暗示相位信息重要

**物理合理性评分**: ★★★★☆（最高）

### 1B. q ↔ 纯度相关量

**定义**:
```
q_purity(ρ) = (d·Tr(ρ²) - 1)/(d - 1)
```
归一化使得q=1为纯态，q=0为最大混合态。

**致命问题**:

1. **最大混合态 I/d 不是经典的**。Bell对角态ρ = (I+Σc_iσ_i⊗σ_i)/4中，即使c_i全为-1/3（低纯度），态仍有纠缠和量子关联。低纯度≠经典性。

2. **方向相反**。在DGF中，q→0意味着信息饱和——系统"满了"。但最大混合态I/d有最大von Neumann熵——信息上是最"空"的（什么都不知道）。这与DGF的直觉完全相反。

3. **具体反例**。d=4，c₁=c₂=c₃=-1/3时:
   - Tr(ρ²) = (1+1/3)/4 = 1/3
   - q_purity = (4·1/3-1)/3 = 1/9 ≈ 0.11 (接近经典？)
   - 但此态是纠缠的，有量子关联！与q→0=经典的声称冲突。

4. **DGF中q=0是基依赖的还是基独立的？** 在原定义中，q=0意味所有细胞被占用——这是一个特定的对角态（在细胞基中），不是任意对角态。纯度无法区分"哪个基中的对角态"。

**评估**: ★☆☆☆☆ — 物理上不成立。纯度≠经典性。

### 1C. q ↔ 相空间体积（Wigner负值区）

**定义**:
```
q_Wigner(ρ) = Vol({(x,p): ρ_W(x,p) < 0}) / Vol(总相空间)
```

**优点**:
- 与"虚部距离"的直觉一致: Wigner函数取负值↔有虚部（相位）
- q=0→Wigner处处非负→"经典"（在Wigner表示的意义上）
- 对退相干单调递减（在标准连续变量模型中）

**致命问题**:

1. **Gaussian squeezed states是量子态但Wigner正定**。压缩真空态是纯量子态（有压缩），但Wigner函数是Gaussian，处处非负。q_Wigner=0但态是量子的——与DGF的q→1=量子矛盾。

2. **高维系统定义困难**。Wigner函数在多模或多qubit系统中的推广不一致（离散Wigner函数有多种定义）。

3. **DGF是离散的**。q的定义在{0,1}^N上——没有相空间，没有x和p。需要额外的离散→连续桥接。

4. **不是所有非经典性都来自Wigner负值**。量子相干（在给定基中的非对角元）与Wigner负值是不同的概念。一个态可以在某个基中有相干（非对角元非零）但Wigner正定。

**评估**: ★★☆☆☆ — 物理上部分吸引但数学上不匹配DGF的离散结构。

### 1D. 推荐: l₁-norm with orbital entropy correction

**推荐映射**: 在两个层次上使用不同的映射:

**层次1 (操作层面 — 基已选定)**:
```
q(ρ) = ||ρ - diag(ρ)||_1 / ||ρ||_1 = Σ_{i≠j} |ρ_{ij}| / Σ_{i,j} |ρ_{ij}|
```
在指针基已被einselection锁定的前提下，此映射完美对应DGF的q。

**层次2 (基础层面 — 基独立)**:
```
q(ρ) = S(ρ_diag) / log₂ d    (归一化对角熵)
```
其中S(ρ_diag) = -Σ p_i log₂ p_i, p_i = ρ_{ii}。此版本基独立（对任何基都可由对角元定义），q→0意味着对角元是确定的（某一个p_k≈1，其余≈0），q→1意味着对角元均匀分布（p_i≈1/d，最大叠加容量）。

但此定义与原DGF的"未占用细胞比"直觉不完全一致。原q=1是在全空（所有细胞0）——对应层次2中p_i均匀分布，这在经典比特设定中自然成立（如果系统处于最大叠加态）。需要论证此翻译的一致性。

**两个层次的关系**: 当基由einselection选择后（DGF: 溢出历史锁定），层次1和层次2给出等价的物理信息。层次2更基础（基独立），层次1更操作（可直接测量）。

## 2. 自洽性证明

### 2a. 单调性: 退相干信道下q(ρ)非增

**声明**: 设ρ为d维量子态，Φ_p为退相干信道:
```
Φ_p(ρ) = (1-p)ρ + p diag(ρ)
```
则q_{l1}(Φ_p(ρ)) ≤ q_{l1}(ρ)。

**证明**:

对于Φ_p，非对角元变换为ρ'_{ij} = (1-p)ρ_{ij} (i≠j)，对角元不变: ρ'_{ii} = ρ_{ii}。

```
q_{l1}(Φ_p(ρ)) = Σ_{i≠j} |(1-p)ρ_{ij}| / (Σ_i |ρ_{ii}| + Σ_{i≠j} |(1-p)ρ_{ij}|)
               = (1-p) Σ_{i≠j} |ρ_{ij}| / (Σ_i |ρ_{ii}| + (1-p) Σ_{i≠j} |ρ_{ij}|)
```

令A = Σ_{i≠j} |ρ_{ij}|, B = Σ_i |ρ_{ii}|。则:
```
q(ρ) = A/(A+B)
q(Φ_p(ρ)) = (1-p)A / (B + (1-p)A) = A / (B/(1-p) + A)
```

由于1/(1-p) ≥ 1 (对于0≤p≤1)，有 B/(1-p) ≥ B，因此:
```
q(Φ_p(ρ)) = A / (B/(1-p) + A) ≤ A / (B + A) = q(ρ)
```

等号仅当p=0（无退相干）或A=0（已完全退相干）时成立。∎

**推广 — 相位阻尼信道**:
```
ρ_{ij} → (1-p)^{|i-j|} ρ_{ij}
```
类似论证可得单调性，因为每个非对角元被因子(1-p)^{|i-j|}缩减。

**与DGF的关系**: 在DGF中，"溢出事件"逐步占用细胞→q下降。在量子对应中，退相干逐步衰减非对角元→q_{l1}下降。方向一致。∎

### 2b. 吸收边界: q=0是退相干信道的吸收态

**声明**: 若ρ是对角矩阵(q=0)，则对任意退相干信道Φ，Φ(ρ)=ρ。

**证明**: 设ρ = diag(p_1, ..., p_d)。则diag(ρ) = ρ。因此:
```
Φ_p(ρ) = (1-p)ρ + p diag(ρ) = (1-p)ρ + p ρ = ρ
```
且q_{l1}(ρ) = 0, q_{l1}(Φ(ρ)) = 0。∎

**物理意义**: 一旦系统变为完全对角的（所有相干性丧失），它永远保持对角的——退相干无法被"逆转"（在没有外部反向操作的情况下）。

**与DGF的关系**: DGF声称q=0是吸收边界——一旦所有细胞被占用，信息无法被"擦除"。（但在DGF中，T1说f是双射——信息不会真正消失，只是被'锁定'在系统中。在量子对应中，完全对角态在幺正演化下可以重新获得相干——如果幺正演化包含基变换。但在DGF的涌现基图景中，某种基由动力学锁定，基变换算子的物理实施需要"外部操作"——这对应于标准QM中通过系统-环境关联恢复相干的非马尔可夫过程。）

**重要细微之处**: 在量子力学中，幺正演化U可以恢复一个完全对角态的相干性——如果U不与该基对易。例如，若ρ=diag(1,0)且U是Hadamard门，则UρU† = (1/2)(|+⟩⟨+|) 有非零非对角元。所以q=0在量子力学中不是普遍吸收态——只在退相干动力学（特定于一个基）下是吸收态。这与DGF的图景一致: q=0的吸收性质依赖于"细胞基已被锁定"（细胞基=指针基=退相干基）。

**结论**: q=0的吸收性质在DGF和标准QM中是精确对应的——两者都依赖于一个优先基的存在（einselection指针基/DGF溢出锁定的细胞基）。∎

### 2c. 与DGF的S1定理自洽

**S1定理** (DGF): 信息回流概率满足P_reflux ≤ T·(q_S/(1-q_S))^δ·((1-q_E)/q_E)^δ（情形A, K守恒）。

**标准QM对应**:

在非马尔可夫量子动力学中，"回流"对应非对角元的短暂恢复。标准非马尔可夫度量包括:
- **BLP度量** (Breuer-Laine-Piilo 2009): N(Λ) = max_{ρ₁,ρ₂} ∫_{σ>0} dt σ(t, ρ₁,ρ₂) / D(ρ₁(t),ρ₂(t))，其中σ(t) = d/dt D(ρ₁(t),ρ₂(t))是迹距离的时间导数。正σ意味着信息回流。
- **RHP度量** (Rivas-Huelga-Plenio 2010): 基于CP-divisibility的破坏程度。

**关键对比**:

| | DGF S1 | 标准QM非马尔可夫度量 |
|---|--------|---------------------|
| 数学变量 | q_S, q_E, N_S, N_E | ρ(t), Λ(t), J(ω) |
| 回流来源 | 组合容量比 | 环境谱密度+关联记忆 |
| 预言 | 回流上界由容量比决定 | 回流量由谱密度和温度决定 |
| 参数 | 仅依赖维度 | 依赖完整Hamiltonian |

**自洽性论证**:

DGF的S1和标准非马尔可夫理论给出的是**不同但互补的上界**:

1. **标准理论的上界**: 回流量受环境关联时间τ_E和系统-环境耦合强度g约束。在弱耦合极限下，回流由谱密度的低频行为决定。

2. **DGF的上界**: 回流量受容量比N_S/N_E约束。即使谱密度允许回流（例如，非马尔可夫环境），如果N_S/N_E足够小，回流的宏观表现受组合概率约束。

3. **互补性**: 
   - 标准理论: 约束回流的**速率**（多快可以回流）——由J(ω)决定
   - DGF理论: 约束回流的**容量上限**（最多能回流多少信息）——由N_S/N_E决定
   
   两者约束不同的物理量，不冲突。可以存在: 标准理论允许快速回流（谱密度支持），但DGF约束总回流幅度（容量有限）。

4. **DGF给出标准理论没有的东西**: 标准退相干理论从未从Hilbert空间维度的角度约束回流上限。标准理论关注的是动力学（谱密度），不是信息容量。DGF的维度约束是额外的——它说"即使动力学完美非马尔可夫，回流也不能超过容量比决定的界"。

**自洽性结论**: S1回流定理与标准非马尔可夫理论**互补而非等价**。两者约束回流的不同方面（速率 vs 容量）。∎

## 3. DGF与标准退相干的精确关系

### 3.1 等价的部分（DGF = 标准退相干的新词汇）

以下DGF核心声称在q↔l₁-norm映射下完全等价于标准退相干理论:

| DGF声称 | 标准QM对应 | 等价性 |
|---------|-----------|--------|
| 信息溢出→细胞占用 | 系统-环境相互作用→退相干 | **精确等价** |
| 容量耗尽→经典性 | 非对角元衰减→对角态 | **精确等价** |
| q→0是吸收边界 | 对角态在退相干下不变 | **精确等价** |
| 溢出历史锁定基 | Zurek einselection指针基 | **结构等价** |
| 环境容量大→不可逆 | 环境维度大→非对角元恢复概率低 | **定性等价** |

**INSPECTOR的判断在此被确认**: "DGF is a conceptual framework/language for describing known physics" — 在上述等价关系下，DGF确实是标准退相干的信息论重新表述。

### 3.2 不等价但有补充价值的部分

以下方面DGF提供了标准退相干**没有**提供的内容:

**A. 维度约束的回流上界 (S1)**

标准退相干理论: 回流由谱密度J(ω)决定。在欧姆环境、超欧姆环境等不同谱密度下，回流行为不同。

DGF S1: 回流有一个与谱密度无关的、纯维度约束的上界。无论J(ω)如何，P_reflux ≤ f(N_S/N_E)。

**这是新的吗？** 部分新。量子信息理论中有"量子信道容量"概念——环境维度限制了信息能从环境流回系统的量。但DGF的S1给出的具体函数形式(f(q_S, q_E))和δ参数可能不能在标准量子信息论中直接找到。需要检验: 是否可以从Holevo-Schumacher-Westmoreland定理或量子典型序列推导同样的界？

**诚实判断**: S1的维度约束上界**可能**是新的，但很可能可被量子信道容量的标准论证重新推导。即使可重新推导，DGF提供了一个更透明的视角（直接从容量比出发，不经过量子信道编码定理）。

**B. 轨道熵版本的q（基独立）**

q_f = log₂|Orbit_f(s)|/N 这种定义不依赖任何量子力学结构（不需要Hilbert空间、不需要密度矩阵、不需要谱分解）。它是一个纯粹的信息论量。

在标准QM中，没有直接对应量。最接近的是"参与的Hilbert空间维度"（participating Hilbert space dimension）——系统实际探索的态空间大小。但标准QM通常对这个量不感兴趣——它关注的是密度矩阵、可观测量、关联函数。

**这是新的吗？** 概念上是新的。操作上是否能产生新预言取决于是否能从物理Hamiltonian中计算|Orbit_f(s)|。目前没有协议（GAP-S1-2: 有效N_S/N_E "本质上不可计算"）。

**C. 分离机制的统一视角**

DGF将以下现象统一在一个叙事下:
- 量子退相干
- 经典世界的涌现
- 信息不可逆性
- 时间的涌现（因果DAG）

标准理论分别处理这些: 退相干（开放量子系统）、经典涌现（量子达尔文主义）、不可逆性（统计力学）、时间（广义相对论+量子引力）。

**这是新的吗？** 统一视角是新的——但统一性依赖"统一词汇"而非"统一机制"。"信息溢出"这个词被用于描述所有现象，但不同现象背后有不同的物理机制。命名统一≠物理统一。

**INSPECTOR**: "Its value is hermeneutic (understanding), not predictive (new phenomena)." — 这个判断在q↔l₁-norm映射下被确认。

### 3.3 诚实判断

**DGF不是新物理。DGF是标准退相干+量子达尔文主义+统计力学不可逆性的信息论重新表述。**

这个判断基于以下事实:

1. **q等价于已知可观测量的重新组合**。q_{l1}是一般量子态的一个合法可观测量（只是没人单独给它一个名字和中心地位）。给它一个独特的名字和中心地位并不创造新可观测效应。

2. **S1回流定理可能是唯一的新数学贡献**——但它依赖的维度估计（有效N_S, N_E）在物理系统中无法操作上定义（GAP-S1-2, SEVERE, "本质上不可解"）。

3. **框架的核心叙事（"溢出→基锁定→分离→不可逆"）在标准理论中已有完整对应**（"系统-环境耦合→einselection→退相干→不可逆信息流动"）。

**DGF的价值不在于新物理，而在于:**

- **教育价值**: 提供一个简单的、信息论的语言来描述复杂的退相干现象。
- **启发价值**: S1回流定理提供了一个新角度（维度约束），可能启发标准理论中对应方向的研究。

## 4. "q=虚部距离"的形式化

### 4.1 形式定义

对于d维量子系统，在指针基{|i⟩}下:

```
ρ = Σ_i p_i |i⟩⟨i| + Σ_{i≠j} ρ_{ij} |i⟩⟨j|
```

**对角投影算子**: Δ(ρ) = Σ_i ⟨i|ρ|i⟩ |i⟩⟨i| = diag(ρ_{11}, ..., ρ_{dd})

**非对角部分**: O(ρ) = ρ - Δ(ρ) = Σ_{i≠j} ρ_{ij} |i⟩⟨j|

**DGF的q的形式定义（操作版本）**:
```
q(ρ) = ||O(ρ)|| / ||ρ||
```
其中||·||是某个范数。选择迹范数(||X||_1 = Tr√(X†X)):
```
q_{tr}(ρ) = ||O(ρ)||_1 / ||ρ||_1
```
对于正的ρ (||ρ||_1 = Tr(ρ) = 1): q_{tr}(ρ) = ||ρ - Δ(ρ)||_1。

选择Hilbert-Schmidt范数(||X||_2 = √Tr(X†X)):
```
q_{hs}(ρ) = ||O(ρ)||_2 / ||ρ||_2 = √(Σ_{i≠j}|ρ_{ij}|²) / √(Σ_i p_i² + Σ_{i≠j}|ρ_{ij}|²)
```

**注意**: q_{hs}与纯度的关系: q_{hs}² = (Tr(ρ²) - Tr(Δ(ρ)²)) / Tr(ρ²) = 1 - Tr(Δ(ρ)²)/Tr(ρ²)。即q_{hs}度量的是"非对角线对纯度的贡献占比"。

### 4.2 "虚部距离"解释的数学基础

**核心观察**: 在矩阵表示中，对角元ρ_{ii} = ⟨i|ρ|i⟩ = (⟨i|ρ|i⟩)* = ρ_{ii}*必须是实数（因为它们是概率）。非对角元ρ_{ij} (i≠j)可以是复数: ρ_{ij} = |ρ_{ij}| e^{iφ_{ij}}。

对非对角元取实部和虚部:
```
ρ_{ij} = Re(ρ_{ij}) + i Im(ρ_{ij})
```

对角元: Im(ρ_{ii}) = 0（严格实数）。非对角元: Im(ρ_{ij})一般非零。

**形式对应**:
```
"系统离实轴的距离" ↔ "密度矩阵中非对角元的总复幅度"
q = (非对角复幅度的总范数) / (总范数)  
  = ||O(ρ)|| / ||ρ||
```

**极限情况**:
- q=0 (ρ全实): 所有非对角元为0 → ρ = diag(p_i) → 经典概率分布。这是在指针基中的完全退相干态。
- q→1 (ρ全复): 所有矩阵元等幅度|ρ_{ij}|≈1/d → 均匀叠加态。所有矩阵元都有虚部。

**与容量解释的一致性**:
- "容量耗尽" = 对角元"占用"了迹的容量 → p_i消耗了概率资源，非对角元没有"空间"
- "虚部距离" = 非对角元代表"相位自由度" → 对角元是"实轴投影"，非对角元是"相位"
- 两者统一: 对角元消耗的"概率容量" = 非对角元失去的"虚部空间"

用更精确的数学语言:
```
Tr(Δ(ρ)) = 1 (概率归一化，所有对角元占据全部迹)
Tr(O(ρ)) = 0 (非对角元对迹无贡献)

但 ||ρ||_1 ≠ ||Δ(ρ)||_1 + ||O(ρ)||_1 (三角不等式，一般不等)
```

### 4.3 对角容量与非对角容量的权衡

**关键不等式**:

对任意d维密度矩阵ρ，有:
```
Σ_i p_i² + Σ_{i≠j} |ρ_{ij}|² = Tr(ρ²) ≤ 1
```

这意味着: 对角元（概率）和非对角元（相干）在纯度预算中互相竞争。增加对角概率的集中度（某个p_k→1，其余→0）→ 减少可用的纯度预算给非对角元 → 非对角元被迫缩小。

这是"容量耗尽"的信息论基础:
- "容量" = 纯度预算 Tr(ρ²)
- "对角占用" = 对角纯度 Tr(Δ(ρ)²) = Σ_i p_i²
- "非对角剩余" = 非对角纯度 Tr(ρ²) - Tr(Δ(ρ)²) = Σ_{i≠j} |ρ_{ij}|²
- q_{hs}² = 非对角纯度 / 总纯度 = 剩余容量占比

**完美对应**:
```
DGF: N个细胞, k个占用, q=(N-k)/N
量子: Tr(ρ²)总容量, Tr(Δ²)对角占用, q=1-Tr(Δ²)/Tr(ρ²)
```

### 4.4 与退相干动力学的精确积分

对于标准退相干动力学（相位阻尼）:
```
dρ_{ij}/dt = -γ_{ij} ρ_{ij}  (i≠j)
dρ_{ii}/dt = 0
```
其中γ_{ij} > 0是退相干速率。

q_{hs}的时间演化:
```
dq_{hs}/dt = -(Σ_{i≠j} γ_{ij} |ρ_{ij}|²) / (Tr(ρ²)) + (Σ_{i≠j} |ρ_{ij}|²)(Σ_{i≠j} 2γ_{ij}|ρ_{ij}|²) / (Tr(ρ²))²
```

由于Tr(ρ²)随时间减小（退相干减少纯度），第一项占主导，dq_{hs}/dt ≤ 0。

当所有相位相干丧失（所有非对角元→0）时，q→0。到达q=0后，系统永远停留（因为非对角元全零，方程右边为零）。

**这就是DGF的"吸收边界"的量子力学版本。**

### 5.1 形式映射总结

### 5.2 核心问题的直接回答

**"DGF是否只是标准退相干的新词汇？"**

**是的——在数学结构上。** q ↔ l₁-norm映射揭示DGF与标准退相干在数学上是等价的。所有DGF的核心动力学（溢出→占用→q下降）都有标准退相干中的精确对应（相互作用→退相干→非对角元衰减）。

**但是——在概念统一性上，DGF增加了价值。** 正如热力学与统计力学的关系: 热力学不是"新的微观物理"，但作为宏观框架提供了统计力学不能直接给出的洞察。DGF的贡献不是新物理方程，而是:

1. **参数中心化**: 将所有退相干现象组织在一个参数q周围，提供统一的"相图"（q谱系从量子到经典）。
2. **容量视角**: 强调有限信息容量对退相干动力学的约束——这是标准理论中隐含但未被中心化的概念。
3. **S1回流上界**: 一个可能的新约束——基于纯维度考虑而非谱密度。即使可被标准方法重新推导，DGF的视角更透明。
4. **叙事统一**: 在同一个故事中连接退相干、不可逆性、经典涌现和因果结构。

### 5.3 论文定位建议

基于此映射分析，建议论文的Section V (物质-引力分离+对接) 采用以下诚实定位:

**不应该声称**:
- "DGF是标准量子力学的新基础"（映射显示等价）
- "DGF产生了标准理论没有的独特预言"（S1可被重新推导，τ∝ρ依赖已死的Process B）

**应该声称**:
- "DGF提供了一个信息论语言来精确重新表述标准退相干理论的已知结果"
- "在此重新表述中，S1回流上界作为一个新的、纯信息论的约束出现——它在标准理论中被隐含但未被显式表述"
- "q↔l₁-norm映射建立了DGF与标准量子力学的精确对接，证明了两个框架的相容性"
- "DGF的价值是启发式的和统一性的，而非竞争性的"

### 5.4 对PRD投稿的战术建议

Section V 应该写成一个**对接章节**（docking section），而非一个**比较章节**（comparison section）:

1. 开头: 诚实陈述q↔l₁-norm的形式等价。
2. 中段: 展示此等价意味着DGF与标准QM不相矛盾——DGF是标准QM的信息论外壳。
3. 关键贡献: 在等价框架内，S1回流上界作为一个新约束出现——它来自维度/容量考虑而非谱密度考虑。
4. 结论: DGF不是标准QM的替代品，而是标准QM的一个有用的信息论补充视角。

这个诚实定位会让论文**更可投稿**而非更不可投稿——因为它消除了"声称过大"的致命弱点（拒稿理由二），同时保留了S1回流上界的贡献。
