## §0 总论：为什么要做跨学科跳跃

SIT的"一阶vs二阶"争论在凝聚态物理内部已经陷入僵局：

- Charpentier (2025) 实验阵营：Θ(0)跳变 + 双探针独立确认 → 一阶
- Poboiko-Feigel'man (2024) 理论支撑：Parisi replica框架 → 双序参量 → 一阶可能
- Maniv-Zhuravlev (2025) 替代解释：CPF-puddle → 表观跳变来自逾渗非真一阶
- 历史标度数据：He-Mohanty (2001), Yazdani-Kapitulnik (1995) → 看似二阶

每一方在自己范式内自洽。僵局的根源可能不是数据不足，而是我们关于"相变阶数意味着什么"的概念工具箱太贫乏。跨学科类比的价值：每个学科用自己的语言独立遭遇过"连续vs不连续转变"的问题，它们的解决方案可能为SIT提供新的诊断维度。

以下三个跳跃共享一个数学骨架：**存在两个相互竞争的稳定态（超导/绝缘），转变的性质取决于分隔它们的势垒在热力学极限下的命运。**

### A.2 生态过渡带的核心数学：宽度标度

生态学中一个经典问题是：**两个群系(biome)之间的边界什么时候是"锐利的线"vs"渐变的带"？**

这个问题的数学形式由**反应-扩散方程**的锋面解(front solution)给出。对于植被密度f(r,t)（简化的一维模型）：

```
∂f/∂t = D ∂²f/∂r² + f(1-f)(f - f_c(P))
```

其中D是种子扩散系数（空间耦合强度），f_c(P)是依赖于降水量P的不稳定阈值。这个方程——**三阶Ginzburg-Landau形式，等价于双势阱系统**——的锋面解宽度为：

```
w_ecotone = √(D / (∂V/∂f|_{f=f*}))
```

其中V(f) = -∫ f(1-f)(f-f_c) df = -(f²/2 - 2f³/3 + f⁴/4) + f·f_c·(f/2 - f²/3 + …) 是双势阱势能。

**关键结果A.1（锋面宽度与势垒的关系）：** 当两个稳态的势能相等时（Maxwell点，f_c=0.5），锋面宽度由势垒高度ΔV_barrier = V(f_max) - V(f_min)决定：

```
w ∝ √(D / ΔV_barrier)
```

- 一阶相变的生态对应：ΔV_barrier > 0（两个稳态被有限势垒分隔）→ w有限 → 存在可观测的过渡带
- 二阶相变的生态对应：ΔV_barrier → 0（势垒在临界点消失）→ w → ∞ → 过渡带发散为整个系统 → "处处是过渡"

**反直觉洞察A.1：** 在相变点，一阶相变的过渡带宽度是**有限的**，而二阶相变的过渡带宽度是**发散的**！这恰好与直觉相反——直觉认为一阶是"突变"所以过渡带窄。但实际上：
- 一阶：两相共存区（Maxwell构造），过渡带宽度∝√(D/势垒高度)，热力学极限下保持有限
- 二阶：关联长度发散ξ→∞，临界区宽度∝L^{-1}→0（在热力学极限下），但在有限系统中跨越整个系统

### A.3 关键诊断：SIT"临界区宽度"的L标度

这直接引出一个迄今为止未在SIT文献中提出的**可测量量**：

**定义（SIT ecotone宽度）：** 对于有限尺寸L×L的系统，定义无序分辨率Δx(L) = |x_+(L) - x_-(L)|，其中x_+(L)是Θ(L) > Θ_SC/2的最大x（仍在SC侧），x_-(L)是Θ(L) < Θ_SC/2的最小x（已在绝缘侧）。则：

```
w_ecotone(L) ≡ σ_Δx(L)  [样品间Θ(x)从Θ_SC过渡到0的disorder宽度]
```

**可检验预测A.1（来自生态过渡带理论）：**
- 如果SIT是真正的二阶QPT：w_ecotone(L) ∝ L^{-1/ν} → 0（L→∞）
- 如果SIT是真正的一阶QPT：w_ecotone(L) → w_∞ > 0（有限宽度，来自两相共存disorder区间）
- 如果SIT是赝相变（crossover）：w_ecotone(L) → w_∞ ≫ 0（宽的模糊过渡）

**当前实验状态检查：** Charpentier实验中，Θ(0)的跳变发生在Δx ≈ 0.002的disorder窗口内（在归一化的disorder轴上）。这个宽度对应约2~3个样品。这个宽度是：
- 由有限样品数导致的离散化假象？还是
- 真实的物理两相共存区宽度？

**关键追问：** 如果增加disorder采样密度至Δx < 0.001，是否能看到更多的"中间Θ"样品（即ecotone内的混合态）？还是所有样品都聚类在Θ=0或Θ=Θ_SC两个值上？

### A.4 生态学更深层的类比：正反馈与滞后

沙漠化研究中的一个核心概念是**正反馈导致的双稳态与滞后**（Scheffer et al., 2001, *Nature* 413, 591）：

- 植被减少→反照率增加→地表温度升高→降水减少→植被进一步减少（正反馈环）
- 结果是：即使降水恢复到原来水平，沙漠化后的区域不会自动恢复为绿洲（滞后）

这直接映射到SIT中的**自洽屏蔽不对称性**（A₁ < A₂，SC区屏蔽Coulomb的能力强于CPG区）：

- SC被抑制→局域库珀对增多→Coulomb相互作用增强→进一步抑制SC（正反馈环）
- 结果是：即使disorder降低回临界值以下，绝缘态可能不会自动恢复为超导态（滞后）

**可检验预测A.2：** 一阶SIT应存在disorder扫描方向的滞后。如果从高disorder（绝缘态）缓慢降低disorder（例如退火），Θ的恢复曲线应不同于从低disorder增加disorder的Θ的下降曲线。在Charpentier实验中，所有测量都是在增加disorder的方向上进行的（每个样品独立制备→更无序更绝缘）。没有人做过降低disorder的实验（因为需要退火——改变样品的微观结构）。

**B博士的判断：** 滞后是区分一阶QPT和逾渗型crossover的最干净判据。如果有滞后→一阶成立。如果没有滞后→但不必然二阶（因为T=0下的量子隧穿可以消除经典滞后，但保持Θ的跳变）。CPF-puddle逾渗模型不应产生滞后——逾渗阈值是唯一的、对称的。

### A.5 苏格拉底追问（生态过渡带跳跃）

**Q-A1:** 锋面宽度的类比假设SIT的序参量Θ满足一个反应-扩散型的有效方程。这个方程在微观上是什么？从哪个微观模型可以导出关于Θ(x)（作为空间坐标和disorder的函数）的有效理论？

**Q-A2:** 生态学中，过渡带的宽度有时由"外部噪声"（降水年际变率）而非内在动力学决定。SIT的过渡带宽度是否由disorder微观构型的热力学涨落（外推T→0后消失）还是无序的淬火涨落（T=0下仍然存在）决定？如果是后者→真正的ecotone（有限宽度）；如果是前者→二阶临界区（T→0时→0）

**Q-A3:** 在生态学中，"斑块动力学"(patch dynamics, Levin 1992)描述过渡带内斑块的形成、合并和消失。如果SIT的过渡区是CPF-puddle（即斑块镶嵌），那么斑块的尺寸分布P(s) ∝ s^{-τ}是什么？逾渗理论预测τ=187/91≈2.05（二维逾渗的Fisher指数）——这在SIT的TEM/STM图像中是否可测量？

**Q-A4（最深追问）:** 沙漠化模型有一个"临界慢化"(critical slowing down)现象——接近临界降水阈值时，系统从扰动中恢复的时间发散。SIT在临界disorder附近是否应显示类似行为？即：在临界disorder附近，Θ对disorder变化的"响应时间"（或更准确地说，对电磁探针的频率依赖性）是否应发散？具体：复电导σ(ω)在临界disorder处的频率幂律指数是否有预测？

### B.2 随机k-SAT相变的核心数学结构

随机k-SAT是计算机科学中研究最透彻的相变系统之一。核心事实：

1. 对于k≥3，随机k-SAT的SAT→UNSAT相变在α_c(k)处是**一阶的**（在统计力学/复制方法的意义上——序参量（满足解的数密度的对数）在α_c处不连续跳变到0）
2. 对于k=2，相变是**二阶的**——解空间在α接近α_c时连续收缩至一点
3. 一阶性质来自**复制对称破缺(RSB)**——解空间分裂为许多不相连的团簇(clusters)，每个团簇内部解相似，团簇之间解完全不同

**结构映射B.1（k-SAT的k ↔ SIT的什么？）：**

在随机k-SAT中，k控制的是**约束的复杂度**——每个子句涉及k个变量→k越大，约束越"刚性"（每个子句排除的赋值比例=1/2^k，k越大→每个子句越弱但信息量越大→更"长程"关联）。在无序超导体中，对应的量是什么？

**候选映射：**
- **k ↔ 库珀对的空间维度/连通性**：在弱无序下，库珀对通过扩散型传播子耦合（~1/r，长程→"大k"）；在强无序下，耦合变为局域的（~e^{-r/ξ_loc}，短程→"小k"）
- **k ↔ 有效"序参量数"**：k=2的2-SAT是二阶的（类似单序参量QPT）；k≥3的k-SAT是一阶的（类似多序参量竞争QPT）。2-SAT的"单一解空间团簇"对应单序参量的连续QPT；3-SAT的"多团簇解空间"对应双序参量竞争的一阶QPT。

**洞察B.1（B博士的判断）：** k-SAT文献实际上提供了一个独立的理论参照：**"当自由度之间的约束变得足够复杂时，相变从二阶变为一阶"**。这个临界"复杂度"在k-SAT中是k=3。在SIT中，"约束复杂度"可能对应着：Coulomb相互作用的长程性+无序导致的有效维度+序参量的多分量性。

### B.3 有限N标度窗口——区分一阶vs二阶的独立方法

随机k-SAT文献中最实用的方法论贡献是**有限尺寸标度窗口中一阶vs二阶的区分**（Kirkpatrick & Selman, 1994; Monasson et al., 1999）：

对于样本量为N的系统，转变窗口在α空间中的宽度为：
- 二阶：W_N ∝ N^{-1/(νd)}（标准有限尺寸标度，ν为关联长度临界指数）
- 一阶：W_N ∝ N^{-1}（指数级窄--因为序参量跳变Δ>0在有限N下被N^{-1/2}涨落掩盖，但在控制参数空间中窗口宽度为N^{-1}量级）

直接应用于SIT——对尺寸为L的薄膜（自由度数为L²），在disorder轴上的转变窗口：
- 二阶SIT：w_L ∝ L^{-1/ν}（d=2，忽略动力学指数z）
- 一阶SIT：w_L ∝ L^{-2}（每增加一个puddle的自由度需要恰好合适的disorder来翻转它）

**关键问题B.1：** Charpentier实验中Θ(0)跳变发生在~0.002的disorder窗口内。这个宽度在L→∞极限下如何外推？如果w_L ∝ L^{-2}（一阶），当前μm尺度的样品（L~10³晶格常数）应给出w_L~10^{-6}量级→远窄于实验观测的0.002。反之如果w_L ∝ L^{-1/ν}且ν≈0.67（3D XY universality），则w_L~10^{-2}量级→与实验一致。

**这里面有一个重要张力需要进一步分析：** 实验的0.002窗口究竟是sample-to-sample disorder variance导致还是真正的有限尺寸物理？

### B.4 k-SAT的"计算硬度相图"与SIT的"实验难度相图"

随机k-SAT最著名的现象之一是**"容易-困难-容易"图样**：

- α ≪ α_c：几乎所有随机公式都是SAT的，解很容易找到（局部搜索即可）
- α ≈ α_c：最难——解空间碎片化，任何算法都需要指数时间
- α ≫ α_c：几乎所有公式都是UNSAT的，证明UNSAT容易（resolution proof短）

这个图样在物理上源于解空间在α_c附近的**复杂度发散**——团簇数和团簇间距离都发散。

**SIT中的对应现象是否存在？**

| k-SAT | SIT（推测） |
|-------|------------|
| 低α，SAT容易 | 低disorder，SC容易测量——Θ大而清晰，BCS理论完全适用 |
| α≈α_c，SAT极难 | x≈x_c，SC/CPG最难区分——样品间差异最大，热涨落影响最大 |
| 高α，UNSAT容易 | 高disorder，CPG容易测量——Θ=0，绝缘行为清晰 |
| 难度来自解空间碎片化 | 难度来自什么？puddle镶嵌结构的复杂性？ |

**可检验预测B.1：** 如果SIT在x_c处具有类似k-SAT的"最大难度"特征，那么应观测到：
1. **样品间方差在x_c处最大化**——不同样品（名义上相同disorder）的Θ应离散度最大
2. **制备条件的敏感性在x_c处最大化**——微小的制备参数波动应在x_c附近产生最大差异
3. **热循环可重复性在x_c处最差**

Charpentier实验的数据是否能检验这些预测？需要检查他们是否报告了临界disorder附近不同样品之间的Θ方差。

### B.5 苏格拉底追问（k-SAT跳跃）

**Q-B1:** 随机k-SAT中的"硬实例"对应于约束密度恰好处于相变点的公式。在SIT中，"硬样品"对应于什么？是恰好处于临界disorder的样品吗？如果是——制备这样的样品本身就是一个"hard problem"（因为disorder控制精度有限→总是会偏离x_c→落入清晰的SC或CPG→由此解释了为什么"真正的临界行为"在实验中如此罕见）

**Q-B2:** 在一个重大类比上，k-SAT和SIT似乎分道扬镳。在k-SAT中，一阶相变（k≥3）是"规则的"(generic)——几乎任何k≥3的随机公式系综都显示一阶行为。在SIT中，一阶似乎与材料细节密切相关（a-InO一阶vs a-MoGe二阶）。这种差异意味着：**k-SAT的k≥3对应的是SIT中的某种"普适类"，而非材料细节。** 这个普适类是什么？是否与无序的统计性质（高斯vs非高斯，长程vs短程相关）有关？与配对对称性（s-wave vs d-wave）有关？

**Q-B3:** 最近在随机约束满足问题的研究中，发现"连续相变"和"不连续相变"不是二元对立的——在k=2和k=3之间存在一个"混合相变"(mixed-order transition)区域（Baxter, 1982; Toninelli et al., 2006），其中序参量连续变化但其导数（如磁化率）不连续。SIT是否可能落入这个混合类？具体：超流刚度Θ在x_c处是否可能是连续的但dΘ/dx不连续（实验上表现为Θ(x)的斜率在x_c处折转）？

**Q-B4（最深追问）:** 随机k-SAT用**复制方法(replica method)** 在N→∞极限下求解。Poboiko-Feigel'man (2024)用**Parisi复制框架**处理SIT。这里的结构对应不是巧合——两个系统在同一个数学框架中被处理。那么：k-SAT文献中关于"1RSB↔一阶"的标准结果是否可以翻译为P-F框架中关于"SIT一阶"的对应定理？如果可以——那么P-F的结果实际上已经隐含在复制方法的已知数学结构中，不是SIT特有的发现。

| 金融传染(contagion) | 相位涨落的传播 | 一个puddle的涨落通过Josephson结传至邻居 |

### C.2 银行挤兑的两类模型——经典DD vs 全局博弈

**经典Diamond-Dybvig (1983)模型：** 存在两个自实现的均衡——"好"均衡（没有人挤兑，银行正常运作）和"坏"均衡（所有人挤兑，银行破产）。哪个均衡实现取决于**太阳黑子(sunspot)**——即与基本面无关的"动物精神"。两个均衡之间的切换是**一阶的、不连续的**——没有"部分挤兑"的中间态。

**全局博弈(Global Games, Morris-Shin 2003)模型：** 当储户对银行基本面有带噪声的私人信号时，多重均衡消失，被**唯一的阈值均衡**取代。存在一个临界的基本面水平θ*，当基本面低于θ*时必然发生挤兑，高于θ*时绝对不会。这个均衡是**唯一的，但仍是不连续的**——挤兑概率在θ*处从0跳到1。

这两个模型为SIT提供了两个尖锐对照：

| 模型特征 | DD模型 | 全局博弈 | SIT（待判断） |
|----------|--------|----------|--------------|
| 均衡多重性 | 是（二重） | 否（唯一） | ?? |
| 转变不连续性 | 是（跳跃） | 是（跳跃） | 实验说"是" |
| 滞后 | 是（自实现） | 否（唯一阈值） | ??（无实验数据） |
| 外部噪声角色 | 触发跳变 | 选择唯一均衡 | disorder=？ |
| 需要一个"协调者" | 否（自发） | 是（市场信号） | ?? |

**关键洞察C.1（B博士的翻译）：** 在全局博弈框架中，"带噪声的私人信号"的作用是给均衡选择提供唯一天气。在SIT中，**淬火无序(quenched disorder)** 可能是对应的"私人信号"——每个库珀对"感知"到的局域disorder略有不同（因为空间不均匀→局域无序强度有分布）。如果这个类比成立：
- 全局博弈预测：存在唯一的临界disorder阈值x_c；对x > x_c，T=0基态必然绝缘；对x < x_c，必然超导——**无两相共存区**
- 这意味着：尽管Θ在x_c处跳变（一阶不连续性），但不存在经典意义下的两相共存（→没有滞后）——这是"量子全局博弈"的一阶相变

**这完美匹配LP-15的声张边界：** "一阶但不必然有经典滞后"——因为量子涨落（T=0下的量子隧穿）可以消除经典滞后障碍但保持在x_c处的Θ跳变。

### C.3 银行间网络拓扑与Josephson网络

2008年金融危机后，经济学界大量研究**金融网络的拓扑如何影响系统性风险**（Gai & Kapadia, 2010; Acemoglu et al., 2015）。核心结果：

- **环状网络(ring network)：** 风险分散好，但一旦一处断裂→整个环断裂→全系统崩溃（"robust-yet-fragile"）
- **完全连接网络(complete graph)：** 每个银行与其他所有银行都有拆借→风险高度分散→几乎不崩溃
- **核心-边缘网络(core-periphery)：** 少数大银行互联+许多小银行连接到大银行→大银行崩溃时全系统崩溃（"too big to fail"问题）

**直接翻译为SIT中的Josephson结网络拓扑：**

- **环状网络** ↔ 弱连接超导颗粒阵列（每个颗粒只与近邻耦合）→接近逾渗阈值→极端脆弱
- **完全连接网络** ↔ 均匀超导薄膜（每对库珀对通过长程Coulomb耦合）→集体相干→鲁棒
- **核心-边缘网络** ↔ **非均匀薄膜中的puddle结构**（大puddle之间的强连接+小puddle依附于大puddle）→大puddle的相位滑移触发全局崩溃

**可检验预测C.1：** 扫描探针显微镜（STM/扫描SQUID）测得的局域超流刚度空间分布图可以用网络分析工具（介数中心性betweenness centrality, 聚类系数, 最大团簇尺寸）来**预测该样品的Θ(0)——在网络坍塌发生前定量判断这个样品是SC还是绝缘体**。如果SC→绝缘体转变对应Josephson网络中"巨分量"(giant component)的消失，则转变是一阶的吗？

网络理论中，随机图中巨分量的涌现是**连续相变**（在Erdos-Renyi图中，巨分量尺寸在p=p_c=1/N处连续地从0增长）。但在**无标度网络**中，巨分量涌现可以更陡峭。在有相互依赖的**网络的网络(network of networks)** 中，瓦解可以是**一阶的**（Buldyrev et al., 2010, *Nature* 464, 1025）。

**洞察C.2：** 如果SIT中的Josephson网络具有"网络的网络"拓扑（例如超导puddle网络+绝缘体中的Cooper对玻璃网络——两个相互依赖的网络），则根据Buldyrev的定理，整个系统的崩溃应该是一阶的。这为双序参量图像（Δ + q_EA形成两个相互依赖的"网络"）提供了来自网络科学的独立理论支持。

### C.4 金融危机传染速度——SIT动力学的前沿问题

银行挤兑的传染是**有限速度**的——恐慌通过人际网络传播，速度受限于通信和信息处理。SIT中的相滑移级联也是**有限速度**的吗？

如果SIT是一阶的且通过核化-生长(nucleation-growth)机制发生：
- 第一步：在某个薄弱puddle处核化（越过势垒→产生第一个相滑移）
- 第二步：相滑移产生的相位扰动以速度v_φ传播至邻居
- 第三步：邻居的势垒因相位扰动而降低→二次核化→……→级联

级联的总持续时间τ_cascade应该依赖于系统尺寸和势垒高度：
```
τ_cascade(L) ~ τ_nucleation + L / v_φ
```

**可检验预测C.2：** 如果SIT是通过核化-生长发生的一阶相变，则在频率依赖的电导σ(ω)中应看到一个特征频率ω* ~ 1/τ_cascade——低于此频率，系统有时在SC和绝缘态之间跳变（因为测量时间>级联时间→平均了两个态）；高于此频率，系统被"冻结"在其中一个态。这是类似1/f噪声的行为，其拐角频率反比样品尺寸。

### C.5 苏格拉底追问（银行挤兑跳跃）

**Q-C1:** 在银行挤兑文献中，政府作为"最后贷款人"(Lender of Last Resort)可以通过注入流动性阻止挤兑。在SIT中，是否有类似的外部干预？例如：一个外部的微波辐照是否可以"注入相位相干性"来阻止局部的相滑移级联？这个预测如果成立将非常惊艳——"你可以用微波把超导体'救'回来"。

**Q-C2:** 金融网络文献强调**级联失效的"相图"**——在同一网络拓扑下，冲击大小vs级联尺寸的关系可以是幂律（→自组织临界，二阶）或在某个临界冲击处跳变（→一阶）。对Josephson结网络：单个puddle的相滑移导致的级联尺寸分布P(S)是什么样的？如果P(S) ∝ S^{-τ}（幂律，无特征尺度）→自组织临界的证据；如果P(S)是双峰的（小的独立事件+偶尔的全系统事件）→一阶核化-生长的证据。

**Q-C3:** 全局博弈框架的核心数学结构是**高阶信念(higher-order beliefs)**——"我知道基本面，我知道你知道基本面，我知道你知道我知道基本面……"的无限递归。在无序超导体中，是否有对应的"高阶关联"？即：一个库珀对不仅"感知"其局域无序，还"感知"邻居如何"感知"无序……通过Josephson耦合传播的不仅是相位，还有关于相位的信息（量子纠缠→类似高阶信念）？

**Q-C4（最深追问）：** 金融危机的"黑天鹅"特征（Taleb, 2007）——极端事件在厚尾分布中比高斯分布预期频繁得多。SIT中，如果Θ的分布（在固定x下跨样品）是高斯→二阶图像；如果厚尾→暗示存在未被认知的"黑天鹅"机制（可能是一阶核化事件）。**Charpentier实验发表了不同样品间Θ的方差吗？分布的形状是什么？**

### 7.3 对LP-15现有框架的增强建议

当前LP-15的五线推理（S1-S5）都是**凝聚态物理内部的论证**——它们在学科内自洽但无法打破范式内的僵局（因为Maniv-Zhuravlev也可以用学科内论证来防御CPF-puddle模型）。

三个跨学科跳跃提供了**学科外的独立诊断**(orthogonal diagnostics)——这些诊断不依赖于Landau系数γ/√(βλ)是否>1，也不依赖于对Poboiko-Feigel'man框架的接受。它们直接诉诸：
1. 过渡区宽度的L标度（是否有有限尺寸标度数据？）
2. 滞后行为（是否做过disorder降低方向？）
3. Θ分布的峰结构（是否可以从已发表的直方图中提取？）
4. 级联统计（是否有时间分辨的相滑移观测？）

**优先级建议：**
- **诊断1（ecotone宽度标度）**：最可行，需要分析Charpentier论文中不同disorder样品的Θ(0)直方图——如果看到双峰（聚类在0和Θ_SC）→一阶；如果看到连续分布的中间值→二阶或crossover
- **诊断3（Θ分布形状）**：同数据源，不同分析方法
- **诊断2（滞后）**：需要新实验——最有区分力但也最难
- **诊断6（网络拓扑）**：需要空间分辨的Θ测量（扫描SQUID或STM）→Charpentier实验可能没有

### 7.4 最深层的元问题

三个跳跃最终都指向同一个元问题，而这个问题在SIT文献中一直没有被干净地定义：

**"两个稳定态之间的转变在什么条件下是真正的热力学相变（阶数可定义），什么条件下仅仅是有限系统中的锐利交叉(crossover)?"**

- 生态学回答：当正反馈足够强以至于存在真正的双稳态→是相变；否则是渐变
- 计算机科学回答：当N→∞时SAT概率在α_c处的导数不连续→是相变；连续→是交叉
- 经济学回答：当存在协调博弈（策略互补性足够强）→是均衡跳变；否则是平滑调整

对SIT的回答可能是：**当库珀对之间的有效相互作用（通过屏蔽的Coulomb+Josephson耦合）产生足够强的正反馈，使得SC和CPG态同时是局域自由能极小值→一阶相变；否则→二阶（如果临界涨落支配）或交叉（如果有限T模糊了转变）。**

这个回答的自然参数（"正反馈强度"）是：**Coulomb相互作用的屏蔽不对称度A₁/A₂**（SC区屏蔽能力/CPG区屏蔽能力）。当A₁≫A₂时（SC区强烈屏蔽→保护自己），正反馈强→一阶；当A₁≈A₂时→二阶Dirty Boson。

这为LP-15提供了一个新的核心诊断参数，超越了γ/√(βλ)。
