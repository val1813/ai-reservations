## 北极星收尾

```
[ ] GATE 1.5: grep A推导文件中"深挖1"和"深挖2"各≥2层？B同？
      通过→继续。不通过→A/B补深挖→INSPECTOR→GATE 1.5再来（最多2次）
[ ] Re-escalation: 声张是否比启动时更窄？→列出被杀死的声张→A/B写更大声张草案
[ ] ⛔ GATE 降级前置: 当前北极星被推翻了吗？（双路径证伪/REVIEWER致命/反例打穿）
      否→跳过此门，继续
      是→⛔ 强制挽救轮（PI.md §2，降级前必做，不得跳过）：
          发1轮AB挽救任务书（正面修复被推翻的环节，禁止本轮写"有边界/换方向"）
          → INSPECTOR校对 → 判定：
          挽救成功（命题重新成立 / Re-escalation给出更大声张）→ 当前北极星存活，不降级，回AB循环
          挽救失败（1轮后仍证伪）→ 才允许执行PI.md §2条件B降级动作（降分+强制分叉≥2方向）
      ⚠️ 只挽救1轮；条件A/矩阵切换不触发此门
[ ] 矛盾深挖: 用"五个为什么"追溯驱动矛盾→挖到基础原理层
[ ] ⛔ 子命题提取（S1候选强制执行，非S1可选）：
      S1候选的子命题不是预定义的——从A/B探索中自底向上涌现。
      PI必须从本轮A/B产出+INSPECTOR+REVIEWER中提取≥2个已浮现的子命题，
      每个写成"A vs B"格式，注册到 项目/北极星队列.md 新候选区，量化打分。
      格式：子命题1: [一句话命题] | 子命题2: [一句话命题] | ...
      如果只浮现1个→标注"子命题不足"，但该1个仍需注册。
      如果0个浮现→标注"S1探索未涌现子命题"，继续下一轮AB。
[ ] 更新 项目/北极星队列.md — 优先级矩阵重算（含新提取的子命题）
[ ] 检查优先级队列 → 有更高分候选？→触发切换
      是→暂停当前，旧状态保存，启动新北极星
      否→⛔ 进入 GATE 空转拦截（见下）
[ ] ⛔⛔⛔ GATE 空转拦截：以下三问全部为"否"时，禁止收官 ⛔⛔⛔
      Q1: 本轮是否提取到 ≥1 个子命题？
      Q2: 最近3轮是否出现过 AHA 洞察？
      Q3: B博士是否提出了可注册为新北极星的方向？
      三问全"否" → 🛑 空转警报：3轮探索未产生可追的新方向。
          强制动作（不得跳过）：
          1. 启动 AHA访客（research-group/AHA.md），传入全部三轮产出
          2. AHA访客产出后 → 再跑1轮AB（仅1轮）
          3. 1轮后回到 GATE 空转拦截重判
          4. 最多触发2次（即最多额外2轮），之后允许"有边界"收官
      至少一个"是" → 通过，进入收官
```
