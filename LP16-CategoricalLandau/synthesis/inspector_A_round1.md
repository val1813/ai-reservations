### 公式 1: 融合规则 (L237-238)

$$X \otimes X = 1,\quad X \otimes Y = Y \otimes X = Y,\quad Y \otimes Y = 1 \oplus X \oplus Y$$

**数学类型检查:**

- 左右两边对象类型一致 ✓

  - Y⊗Y: dim=4; 1⊕X⊕Y: dim=1+1+2=4 ✓ 匹配

**验证（特征标理论）:** S3 的特征标表确认: χ_sign × χ_sign = χ_trivial, χ_sign × χ_standard = χ_standard, χ_standard × χ_standard = χ_trivial + χ_sign + χ_standard. ✓

**判定:** ✓ 正确。

### 公式 2: Lagrangian 代数条件 (L203-208)

1. (A, m: A⊗A→A, η: 1→A) 是 Z(C) 中的代数对象
2. A 交换
3. A 连通: Hom(1, A) ≅ C
4. A 极大: (dim A)^2 = dim Z(C) = (dim C)^2

**数学类型检查:**

条件 3 — **符号歧义**:
- "Hom(1, A) ≅ C" 中，C 在本文上下文中已用于指代融合范畴（如 C = Rep(S3)），此处应指复数域 ℂ
- 正确的"连通"（haploid/connected）条件应为 Hom(1, A) ≅ ℂ（作为向量空间同构于复数域）
- 符号 C 的双重使用造成歧义 ⚠️

- (dim A)^2 = dim Z(C) 是 Lagrangian 条件（极大可凝聚代数）
- dim Z(C) = (dim C)^2 是 Drinfeld 中心的一般性质（定理）
- 链式写法 (dim A)^2 = dim Z(C) = (dim C)^2 正确，但将定理（第二等式）与定义条件（第一等式）并列，初学者可能误解为两个都是定义条件

**判定:** ⚠️ 条件 3 符号歧义（C vs ℂ），建议修正为 "Hom(1, A) ≅ ℂ" 并在符号表中区分。

### 方向检查 1: 命题 A vs 命题 B 的逻辑方向

**命题 A:** G(C)（可逆子范畴）的 SSB 足以描述 C 的所有物理相。

- G(Rep(S3)) = {1, X} ≅ Vec(Z2)（可逆子范畴仅含可逆对象）
