## 关键发现

### 1. 谱维度吸引子: ds* ≈ 2.5-2.8

**所有输入维度在粗粒化下流向ds≈2.5-2.8。**

- d=4 → ds急剧下降到~2.5 (远离4!)
- d=3 → ds稳定在~2.8 (接近但未精确到3)
- d=2 → ds略低于2 (~1.6)

**解读:**
- d=4的因果图在粗粒化下丢失了一个有效维度——连续极限不是4D
- d=3的因果图在粗粒化下ds≈2.8——接近3但差0.2
- 这**部分支持DGF的d=3涌现**但并非精确确认——ds≈2.6-2.8, 不是精确的3.0

### 2. b1是IR-relevant或marginal: 严重问题

**b1/N在所有维度中随N减小而增大(b1/N ~ N^+γ, γ>0)。**

这意味着:
- 独立因果环(b1)在粗粒化下不消失——它们**集中**在更少的节点上
- 大尺度上因果环密度更高——不是更光滑的连续体
- **连续极限可能不存在**——这是DGF Gap 1和Gap 6的致命问题

物理直觉: 粗粒化时, 邻接图上的环被"保留"但节点数减少→b1密度上升。因果结构在短距离上更密集——可能对应Planck尺度的"因果泡沫"。

### 3. q分布不变

q在粗粒化下几乎不变化(均值≈0.5, std小且稳定)。这与DGF v3的q_eq=1/2一致——q场在粗粒化下流向1/2。

### 4. 与DGF Gap 1的比较

| DGF Gap 1声张 | 数值证据 |
|------|------|
| d=3涌现为RG不动点 | **部分支持**: ds→2.8±0.2, 接近3但非精确 |
| b1在IR下irrelevant | **不支持**: b1/N随N减小而增大 (γ>0) |
| 连续极限well-defined | **存疑**: b1密度不降→连续极限可能不存在 |

## 诚实判断

**这个数值实验对DGF的3D涌现给出了混合信号:**

**好消息:**
- 谱维度确实流向~2.5-2.8的吸引子, 与输入维度无关
- d=4被RG流排斥(流向更低维度), d=2被轻微排斥
- 这暗示存在某种"因果图RG普适类", 其谱维度≈2.5-2.8

**坏消息:**
- ds并非精确地=3 (差~0.2-0.5)
- b1密度不降→连续极限可能没有良好定义
- 当前图生成(超立方格点+p_edge)可能太简单——真实DGF因果图可能有更复杂的拓扑

**可能的改进方向:**
1. 更好的图生成模型(随机几何图, 小世界网络, 无标度图)
2. 更好的粗粒化方案(社区检测→超节点, 而非刚性格点blocking)
3. 更大的图(N=10^4-10^6)以获得更清晰的标度行为
4. 真正的有向图Laplacian(非无向骨架)的谱分析
