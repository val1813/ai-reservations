## §0 预备事实

**F0.1** {σ_k⊗σ_k}_{k=x,y,z}两两对易：

$$[\sigma_x\otimes\sigma_x,\; \sigma_y\otimes\sigma_y] = (\sigma_x\sigma_y)\otimes(\sigma_x\sigma_y) - (\sigma_y\sigma_x)\otimes(\sigma_y\sigma_x) = (i\sigma_z)\otimes(i\sigma_z) - (-i\sigma_z)\otimes(-i\sigma_z) = 0$$

同理可证其他对易子为零。这三个算符张成SU(4)的一个**Abel子代数**。任何D(a)=exp(i Σ_k a_k σ_k⊗σ_k)的两个算符恒对易：[D(a), D(b)] = 0对所有a,b成立。

因此，旧版CFOL声称的"σ_k⊗σ_k不对易"[C-GAP-1]是**错误的**。这些算符就是Cartan子代数基，Abel性是其定义性质。

**F0.2** 4-qubit嵌入。边e的Cartan核心嵌入到全空间（张量积序：Q_a⊗E₁⊗Q_b⊗E₂）：

| 边 | Q-E对 | 嵌入生成元 (k分量) |
|----|------|-----------------|
| 1: Q_a→E₁ | (Q_a, E₁) | H₁^(k) = σ_k ⊗ σ_k ⊗ I ⊗ I |
| 2: E₁→Q_b | (E₁, Q_b) | H₂^(k) = I ⊗ σ_k ⊗ σ_k ⊗ I |
| 3: Q_b→E₂ | (Q_b, E₂) | H₃^(k) = I ⊗ I ⊗ σ_k ⊗ σ_k |
| 4: E₂→Q_a | (E₂, Q_a) | H₄^(k) = σ_k ⊗ I ⊗ I ⊗ σ_k |

**F0.3** 嵌入生成元的对易性。对k≠l：

$$[H_1^{(k)}, H_2^{(l)}] = [\sigma_k\otimes\sigma_k\otimes I\otimes I,\; I\otimes\sigma_l\otimes\sigma_l\otimes I]$$
$$= \sigma_k\otimes[\sigma_k, \sigma_l]\otimes\sigma_l\otimes I$$
$$= 2i\varepsilon_{klm}\;\sigma_k\otimes\sigma_m\otimes\sigma_l\otimes I \neq 0$$

（使用了[A⊗B⊗I⊗I, I⊗C⊗D⊗I] = A⊗[B,C]⊗D⊗I，因为I是标量算子不计入交叉项）

**这是非对易性的真正来源：不是σ_k⊗σ_k和σ_l⊗σ_l在2-qubit空间上不对易（它们对易），而是共享qubit E₁上的σ_k和σ_l不对易，产生非对角项σ_k⊗σ_m⊗σ_l⊗I。**

**F0.4** 对齐消除非对易性。当k=l（两边的Cartan轴对齐于同一Pauli方向）：
[H₁^(k), H₂^(k)] = σ_k⊗[σ_k,σ_k]⊗σ_k⊗I = 0。其余对易子同理。

$$c^{(1)}\parallel c^{(2)}\parallel c^{(3)}\parallel c^{(4)} \iff [H_i, H_j]=0\;\forall i,j$$

其中H_i = Σ_k c_k^(i) H_i^(k)。此时总酉为：

$$U = \exp\!\left(i\sum_{i=1}^4 H_i\right) = \exp\!\left(i\sum_{k} H_{\text{tot}}^{(k)}\right)$$

$$H_{\text{tot}}^{(k)} = \sum_{i=1}^4 c_k^{(i)} H_i^{(k)}$$

对齐条件下，总生成元在16×16矩阵空间中是对角的（在σ_n̂的本征基下）。

## §1 设定

**因果环：** Q_a → E₁ → Q_b → E₂ → Q_a。

**初始态：** |Φ⁺⟩_{RQ} ⊗ |γ⟩_{E₁} ⊗ |γ⟩_{E₂}，其中|Φ⁺⟩是d维最大纠缠态，|γ⟩ = √γ₀|0⟩+√γ₁|1⟩，γ₀+γ₁=1。

**酉演化：** U = u₄·u₃·u₂·u₁，其中u_i = D(c^(i))为Cartan规范固定后的边酉（F0.2嵌入）。

**QCMI：** I(R; E₁'E₂' | Q_a'Q_b')。

## §2 定理

**Theorem 1 (CFOL — Cartan版本, d=2)**

对上述4节点因果环，QCMI=0当且仅当以下两条件同时成立：

**(C-I) Cartan轴对齐。** 存在单位向量n̂ ∈ ℝ³使c^(i) = c_i n̂对所有i=1,2,3,4成立。等价地，所有边酉使用相同的Pauli基。

**(C-II) 通道比例化。** 对齐后，记总旋转角Θ = Σ_i c_i。以下两条件之一成立：
$$(a)\quad |\Theta| = n\pi\;\text{对某整数n（有效旋转平凡化）}$$
$$(b)\quad \gamma_0=\gamma_1=\tfrac{1}{2}\;\text{（环境在Cartan基下的最大混合）}$$

**Corollary 1.** 若Cartan轴不对齐（存在i,j使c^(i) ∦ c^(j)），则QCMI > 0。若对齐但Θ≠nπ且γ₀≠γ₁，则QCMI > 0。

## §3 证明

### §3.1 (C-I)+(C-II) ⟹ QCMI=0

**步骤1：生成元对易。** 由F0.4，Cartan轴对齐保证[H_i, H_j]=0对所有i,j。因此总生成元H_tot = Σ H_i = Σ_k (Σ_i c_k^(i)) H_tot^(k)，且U = exp(i H_tot)。

**步骤2：H_tot的结构。** 在σ_n̂⊗σ_n̂⊗...的4-qubit本征基{|s₁s₂s₃s₄⟩}（s_j=±1为σ_n̂的第j个qubit上的本征值）下，H_tot是对角的。

每个H_i^(n̂) = σ_n̂^(p)⊗σ_n̂^(q)在此基下贡献±1因子，具体取决于两qubit的本征值。H_tot的本征值为：

$$\lambda_{s_1s_2s_3s_4} = c_1 s_1 s_2 + c_2 s_2 s_3 + c_3 s_3 s_4 + c_4 s_4 s_1$$

其中s_j = ±1。

**步骤3：Kraus算子的显式形式。** 环境初态|γ⟩ = √γ₀|0⟩+√γ₁|1⟩。在σ_n̂本征基{|+⟩,|-⟩}下，|γ⟩ = α|+⟩+β|-⟩，其中α = ⟨+|γ⟩, β = ⟨-|γ⟩（具体值取决于n̂）。

记E₁和E₂的σ_n̂本征值分别为s₂和s₄。总酉U在环境本征基{|s₂s₄⟩_E}下是对角的。演化后态（测环境前）：

$$|\Psi\rangle = \frac{1}{\sqrt{2}}\sum_{a,b} |a\rangle_R \otimes U |a\rangle_Q|\gamma\rangle_{E1}|\gamma\rangle_{E2}$$

Kraus算子K_{s₂s₄} := ⟨s₂s₄|_E U |γ⟩_{E1}|γ⟩_{E2}。代入：

$$K_{s_2s_4} = \alpha_{s_2}\alpha_{s_4} \cdot \exp\!\left(i\sum_{s_1,s_3} \lambda_{s_1 s_2 s_3 s_4} |s_1s_3\rangle\langle s_1s_3|_Q\right)$$

其中α_s = ⟨s|γ⟩（s=±）。

**步骤4：条件(C-II)下Kraus算子成比例。**

*情形(a): Θ=nπ。* 所有H_i使用相同基n̂ → 总生成元H_tot对Q_a-Q_b子空间的作用退化为恒等算子（全局相位）。具体地，exp(i λ_{s₁s₂s₃s₄}) = exp(i Θ·f(s₁,s₂,s₃,s₄))。当Θ=nπ时，对所有(s₁,s₂,s₃,s₄)组合，exp(iΘ·f)=±1，且符号仅依赖于(s₂,s₄)（E-qubit状态），不依赖于(s₁,s₃)（Q-qubit状态）。因此K_{s₂s₄} ∝ I_Q对所有(s₂,s₄)——标量算子，秩1。QCMI=0。✓

*情形(b): γ₀=γ₁=½。* |⟨+|γ⟩|² = |⟨-|γ⟩|² = 1/2（环境在Cartan基下最大混合）。此时α₊ = α₋ = 1/√2，所有四个|α_{s₂}α_{s₄}|相等。余下的相位因子exp(i Σ_s₁s₃ λ·|s₁s₃⟩⟨s₁s₃|)在(s₂,s₄)交换下如何变化决定了K_{s₂s₄}是否成比例。直接计算表明四个K_{s₂s₄}互成标量倍——秩为1。QCMI=0。✓

### §3.2 QCMI=0 ⟹ (C-I)+(C-II)

假设QCMI=0。

**步骤1：Cartan轴必须对齐。** 反证。设存在i,j使c^(i) ∦ c^(j)。则存在k≠l使c_k^(i), c_l^(j)同时非零。H_i和H_j在共享qubit上的交叉项（F0.3）产生形如σ_k⊗σ_m⊗σ_l⊗I的非对角生成元（m由ε_{klm}选择）。此交叉项不沿任何单一Cartan方向，其指数化产生的酉演化在Q-E子系统间创建纠缠。

具体地，这种纠缠在演化后态ρ_{RE'Q'}中产生Q'-条件化的R-E'关联，违反QCMI=0的HJPW充要条件（短量子马尔可夫链要求ρ_{R,E',Q'}具有直和分解结构⊕_k ρ_{R,Q'}⊗ρ_{E'}——存在跨块相干性则分解不存在）。因此QCMI>0，与假设矛盾。故c^(1)∥c^(2)∥c^(3)∥c^(4)。∎

**步骤2：通道必须比例化。** Cartan对齐成立。H_tot如§3.1步骤2所述。K_{s₂s₄}如步骤3。QCMI=0要求所有K_{s₂s₄}（作为Q_a-Q_b空间上的算子）互成比例：

$$K_{++} \propto K_{+-} \propto K_{-+} \propto K_{--}$$

这要求在Q_a-Q_b空间上，四个对角算子（对角于σ_n̂本征基）的16个对角元（每算子4个对角元，对应|++⟩, |+-⟩, |-+⟩, |--⟩_Q）满足比例条件。

写出K_{s₂s₄}在|s₁s₃⟩_Q基下的对角元：
$$K_{s_2s_4}[s_1,s_3] = \alpha_{s_2}\alpha_{s_4} \cdot \exp(i(c_1 s_1 s_2 + c_2 s_2 s_3 + c_3 s_3 s_4 + c_4 s_4 s_1))$$

比例条件K_{s₂s₄} ∝ K_{s₂'s₄'}要求存在标量μ使K_{s₂s₄}[s₁,s₃] = μ·K_{s₂'s₄'}[s₁,s₃]对所有(s₁,s₃)。这对方程组的解给出Θ=nπ或γ₀=γ₁=½。详细推导见附录A。∎

### §3.3 (A)⟺(B) via HJPW

由Hayden-Jozsa-Petz-Winter (2004, CMP 246:359, Theorem 6)，I(A:C|B)=0 ⟺ 三体态是短量子马尔可夫链。此步为已有定理的直接引用，非CFOL原创。□

## 附录A：比例方程的详细求解

K_{s₂s₄}[s₁,s₃]的表达式见§3.2步骤2。比例条件：

$$\frac{K_{+-}[s_1,s_3]}{K_{++}[s_1,s_3]} = \frac{\alpha_+ \alpha_-}{\alpha_+^2} \cdot \exp(i\Delta_+(s_1,s_3)) = \text{const}(s_1,s_3)$$

其中Δ_+(s₁,s₃) = c₁s₁(-1) + c₂(-1)s₃ + c₃s₃(+1) + c₄(+1)s₁ - (c₁s₁(+1)+c₂(+1)s₃+c₃s₃(+1)+c₄(+1)s₁)的对应项差。

展开得Δ_+(s₁,s₃) = -2c₁s₁ - 2c₂s₃，与s₁,s₃有关除非c₁=c₂=0或...要求对所有(s₁,s₃)，exp(iΔ_+)为常数。这要求c₁+c₂+...的组合满足特定条件。逐一分析四个比值条件K_{ab}/K_{00}导出：

**解1:** Θ = Σ_i c_i = nπ。此时所有相位为全局相位，exp(iΘ·f(s))=±1不依赖于s=(s₁,s₃)。所有K_{ab} ∝ I_Q。对任意γ₀,γ₁成立。

**解2:** γ₀=γ₁=½。此时|α₊|=|α₋|，权重因子不区分通道。相位因子只在Θ≠nπ时产生非平凡算子结构，但由|α₊|=|α₋|保证四个K算子的迹范数相等→秩1条件满足。

无其他解（Θ≠nπ且γ₀≠γ₁时，四个K算子产生不等价的Q_a-Q_b作用，秩>1）。
