## 维度1: 数学正确性

### §1 CFOL Case II "修复"

**A博士的决策:** 放弃算子Schmidt路径(含GAP-1和t_ℓ²权重错误)，采纳B博士Cartan/KAK路径为主证明。

**判定: ✅ 决策正确。** 这是正确的战略选择——Cartan路径完全避开M>0构造，也不涉及t_ℓ²权重问题(GAP-1的两个根源)。算子Schmidt路径在Case II(dim(Y)=1)上的矛盾推导确实不成立(A博士自己的§1.3正确识别了这点)。

**但Cartan路径本身有未声明的缺口。**

A博士§1.2 Step 4-5给出的论证链:
```
coeff_l^(a) = i·β·c_l^(1)·v_l(a)  →  c_l^(1)·(v_l(1)-μ v_l(0))=0  →  c_l^(1)=0
```

LP36 INSPECTOR_cartan_R3.md (2026-06-08)经数值验证发现:
1. **系数结构比简单乘积复杂。** 实际结构为 `coeff_l^(a) = G_l(c1,c2)·v_l(a)`，其中G_l包含BCH交叉项(来自`[H_A, H_B]`)。仅当至多一个Cartan分量非零时，`G_l ∝ c_l^(1)`成立。
2. **比例结构正确。** `coeff_l^(1)/coeff_l^(0) = v_l(1)/v_l(0)`对所有20组随机(c1,c2)精确成立(精度<10^{-10})。这意味着G_l对a=0和a=1相同，比例论证有效——`G_l·(v_l(1)-μ v_l(0))=0 → G_l=0`。
3. **G_l=0 → c^(1)=0 是非平凡的。** INSPECTOR找到了G_l=0但|c1|>0的数值解(如c1=(2.67,0.93,-0.81),|c1|=2.94时σ_l⊗I扇区完全消失)。这些不是CFOL的反例——因为**完整条件A_1=μA_0**(含全部16个Pauli扇区)在canonical域[0,π/4]内无解。但证明需要联合所有扇区约束，而非仅σ_l⊗I扇区。

**A博士R1的问题:** §1.2将"coeff_l^(a) = i·β·c_l^(1)·v_l(a)"作为精确公式呈现，且在整个论证中未提及[ C-GAP-1]。标注为"严格"过于乐观——证明在技术层面有一个步骤(单扇区→c=0)依赖联合所有扇区约束，该步骤的严格性在现有文献中未完成。

**但需强调:** Cartan路径的数值证据极其强健(100次随机采样+216次特殊值+100次全局优化，无反例)。结论正确。问题是**证明的呈现**比**证明的实际严格性**更自信。

**严重性:** 🟡 中度。不影响结论正确性（有极强数值支撑），但影响"严格"标注的可信度。

### §3 树边冻结全局化

**Gershgorin圆盘定理应用:** 数学框架正确。分块Gershgorin定理由标准理论支持。

**逐项评估:**

### §4 共享节点干涉

**Jacobi恒等式+BCH展开:** 代数结构正确。

**引理I1(干涉项非负迹贡献):**

## 维度4: 声张缩水检查

### 核心发现: ν(G) ≠ b₁(G)

**这是本次审计最关键的结构性发现。**

| 量 | 定义 | 性质 |
|----|------|------|
| b₁(G) | 第1 Betti数 = 独立因果环数(同调类) | 图的拓扑不变量 |
| ν(G) | Cycle packing number = 边不相交环最大数 | 图论组合量 |
| 关系 | ν(G) ≤ b₁(G) | 等号不总成立 |

**具体差距示例:**
- 两个4-环共享一条边: b₁≈3, ν(G)≤2 (取决于边的具体分配)
- "8字"形(两环共享1个Q节点,0条边): b₁=2, ν(G)=2 (此例无gap)
- 对于一般Hasse图(三角形自由但可能共享多条树边路径): ν(G)可以远小于b₁(G)

### LP36声称 vs A博士R1实际证明

```
LP36目标:        I ≥ η₀ · b₁(G)   [原始声张，β)用于标题和宣传]
LP36实际证明:    I ≥ η₀           [b₁=1情形，b₁>1为猜想]
A博士R1实际证明: I ≥ η₀ · ν(G)   [严格，但ν(G) ≤ b₁(G)]
A博士R1猜想:    I ≥ η₀ · b₁(G)   [标记为T8'猜想]
```

### 这是降级还是澄清？

**两者都是。**

1. **澄清:** A博士R1首次明确区分了ν(G)和b₁(G)，将两个不同的声张放在不同的证明完成度等级上。这消除了LP36中的核心模糊性——"b₁可加性"到底是说b₁个独立环还是b₁作为同调维数？A博士的答案是: 独立环(ν(G))已证，同调维数(b₁(G))仍是猜想。**这是正确的科学澄清。**

2. **降级:** 从LP36的"I≥η₀·b₁(G)(目标定理)"→A博士R1的"I≥η₀·ν(G)(已证定理)+I≥η₀·b₁(G)(标记为猜想)"。已证定理比原始野心弱。ν(G)对复杂的Hasse图可能比b₁(G)小得多——如果b₁(G)=100但ν(G)=10(因环大量共享树边路径)，已证明的下界是10η₀而非100η₀——差一个量级。

### 标题与内容的不匹配

### F2: Gershgorin论证的隐藏循环性

§3.5使用"去耦近似"作为Newton-Kantorovich验证的前提:
> 在去耦近似下(H_{ij}≈0对i≠j，由Gershgorin对角优势保证)，方程简化为b₁个独立方程。

这里的逻辑顺序是:
1. 要证明: 对角优势 → 方程可解
2. 实际用: 如果方程可解(=去耦) → 对角优势自动满足→方程可解

"H_{ij}≈0由Gershgorin对角优势保证"是循环的——对角优势就是要被证明的，不能作为前提。实际论证路径应该是: 在小|c|限下展示‖H_{ij}‖₂≪λ_min(H_{ii})(引理G1+G2)，然后应用Gershgorin定理推出对角优势。A博士的§3.4-3.5在这两步之间的跳跃需要明确的桥接。

### F3: §7-8深挖部分的状态

§7(Hodge分解)和§8(连续极限/AdS-CFT/凝聚态)标记为推测性推广，不在本次审计的数学正确性范围内。它们相当于"展望"而非"结果"。**A博士诚实地将它们标注为推测性/前数学——符合规范。**
