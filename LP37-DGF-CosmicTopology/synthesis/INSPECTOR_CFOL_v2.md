### 3.3 F5 (致命) — 反例推翻Theorem 1的"仅当"方向

**Theorem 1声称:**
QCMI=0 ⇔ (C-I) AND (C-II)
其中 (C-II) = (Θ=nπ) OR (γ₀=γ₁=½)

**反例:**
$$c_1 = c_2 = c_3 = \pi/2,\quad c_4 = -\pi$$
$$\Theta = \pi/2 + \pi/2 + \pi/2 - \pi = \pi/2 \neq n\pi$$
$$\gamma_0 = 0.6,\;\gamma_1 = 0.4 \neq 1/2$$

- (C-I): ✓ — 所有c^(i)沿同一n̂(对齐)
- (C-II)(a): ✗ — Θ=π/2≠nπ
- (C-II)(b): ✗ — γ₀≠γ₁≠½

但**数值QCMI = 0.0000000000**。

**代数验证:** 在此参数下，Kraus算子为:
```
K_{++} ∝ diag(i, i, -i, -i) = i·(Z⊗I)
K_{+-} ∝ diag(-i, -i, i, i) = -i·(Z⊗I)
K_{-+} ∝ diag(i, i, -i, -i) = i·(Z⊗I)
K_{--} ∝ diag(-i, -i, i, i) = -i·(Z⊗I)
```
全部成比例(比例因子为±1乘以α系数)。Choi秩=1 → QCMI=0。

**此为非退化反例: 所有c_i≠0**。不是"broken loop"退化情况。边缘4的角度-π在环中仍然非平庸。

**严重性:** 定理的"仅当"方向被推翻。QCMI=0的充要条件比(C-II)更宽。

### 3.4 F7 (致命) — (C-II)(a) Θ=nπ非充分

**文档声称:** "Θ=nπ...exp(iΘ·f)=±1，且符号仅依赖于(s₂,s₄)（E-qubit状态），不依赖于(s₁,s₃)"

**反例:**
$$c_1 = c_2 = \pi/3,\quad c_3 = c_4 = \pi/6$$
$$\Theta = \pi/3 + \pi/3 + \pi/6 + \pi/6 = \pi = n\pi\;(n=1)$$

数值QCMI = 1.3997 >> 0。

**为何失败:** exp(iλ) = exp(i Σ c_i s_i s_j)不是Θ的单一函数。λ的s₁,s₃依赖性为:
λ = s₁(c₁s₂ + c₄s₄) + s₃(c₂s₂ + c₃s₄)

exp(iλ)独立于s₁的条件是exp(2i(c₁s₂ + c₄s₄)) = 1对所有s₂,s₄，这要求每个c_i是π/2的整数倍(即c_i ∈ (π/2)ℤ)。当c_i为π/3等非半整数倍时，exp(iλ)依赖于s₁,s₃，Kraus算子不成比例。

**文档的直觉错误:** 将"总Cartan和Θ=nπ"等同于"整体旋转平凡化"，但4-qubit嵌入的旋转变换不是单一SU(2)旋转——它是四个不同SU(2)子群上独立旋转的复合，总效应不由Θ单独决定。

**推论:** 即使(C-I)和(C-II)同时成立，QCMI也可能非零(除非额外的c_i离散条件满足)。定理的"if"方向(充分性)也是假的。

### 3.5 F6 (轻微) — 附录A指数标记错误

文档附录A:
```
Δ_+(s₁,s₃) = c₁s₁(-1) + c₂(-1)s₃ + c₃s₃(+1) + c₄(+1)s₁ - (...)
```

此计算中的s₂=(-1), s₄=(+1)对应K_{-+}, 而非文档声称的K_{+-}。

**应为:**
- K_{+-}/K_{++} 的相位差: -2c₃s₃ - 2c₄s₁
- K_{-+}/K_{++} 的相位差: -2c₁s₁ - 2c₂s₃

文档将后者标为前者。此错误不影响最终结论的性质(两个比率都需要为常数)，但暴露了推导的粗疏。正确的四比率条件是:

1. K_{+-}/K_{++}: exp(i(-2c₃s₃-2c₄s₁)) = const ⇒ c₃,c₄满足条件
2. K_{-+}/K_{++}: exp(i(-2c₁s₁-2c₂s₃)) = const ⇒ c₁,c₂满足条件
3. K_{--}/K_{++}: exp(i(-2c₁s₁-2c₂s₃-2c₃s₃-2c₄s₁)) = const ⇒ 1+2的联合条件
