## 审计发现 1: [F-C1] §1注记 — σ_k⊗σ_k对易公式是数学错误 (FATAL)

### 文档声称 (L28)

```
[σ_k⊗σ_k, σ_l⊗σ_l] = 2i ε_{klm} σ_m⊗σ_m ≠ 0
这些算符**互相不对易**
```

### 数学验证

直接矩阵计算 `[σ_x⊗σ_x, σ_y⊗σ_y]` 的16个矩阵元：

```
σ_xσ_y = iσ_z, σ_yσ_x = -iσ_z
(σ_x⊗σ_x)(σ_y⊗σ_y) = (iσ_z)⊗(iσ_z) = -σ_z⊗σ_z
(σ_y⊗σ_y)(σ_x⊗σ_x) = (-iσ_z)⊗(-iσ_z) = -σ_z⊗σ_z
交换子 = 0
```

**数值验证（numpy, tol=1e-15）:** 所有9对(σ_k⊗σ_k, σ_l⊗σ_l)的交换子范数均为0。

### 错误来源

文档错误地将单Pauli矩阵的交换公式 `[σ_k, σ_l] = 2i ε_{klm} σ_m` 天真地推广到张量积 `[σ_k⊗σ_k, σ_l⊗σ_l]`。正确的张量积交换公式是：

```
[σ_k⊗σ_k, σ_l⊗σ_l] = 2i δ_{kl} ε_{klm}(σ_m⊗I + I⊗σ_m)
```

当 k≠l 时 δ_{kl}=0，因此交换子恒为零。

### 后果

- σ_k⊗σ_k 算符**互相绝对对易** — 它们**是** SU(4)的极大交换子代数生成元（这是标准KAK分解的基础事实）
- 文档声称的"Cartan子代数实际由{σ_z⊗I, I⊗σ_z}张成"也是错误的 — 对2-qubit SU(4)，Cartan子代数维度为3，由{σ_x⊗σ_x, σ_y⊗σ_y, σ_z⊗σ_z}张成
- 文档对旧版本"误称为Cartan子代数"的"修正"**引入了新错误**：旧版本称σ_k⊗σ_k为Cartan子代数**是对的**，新版本的"正名"**是错的**

此错误直接毒化了§3.2 Step 1的所有推导 — 文档声称的对易性条件是建立在一个错误公式上的。

## 审计发现 2: [F-C2] §3.2 Step 1-2 — 多边酉乘积≠D(C_tot) (FATAL)

### 文档声称

§3.2 Step 2: `U = D(c^(1))D(c^(2))D(c^(3))D(c^(4)) = D(C_tot)`

### 问题

文档将4条边的Cartan核心当作作用于**同一对**量子比特，忽略它们作用于**不同**Q-E对的事实：

- 边1作用于 (Q, E₁)
- 边2作用于 (E₁, Q) — 相同对但方向相反
- 边3作用于 (Q, E₂)
- 边4作用于 (E₂, Q) — 相同对但方向相反

在3-qubit模型(Q, E₁, E₂)中，正确嵌入后的总酉为：

```
U = D_QE₂(c^(3)+c^(4)) · D_QE₁(c^(1)+c^(2))
```

其中 D_QE₁ = exp(i Σ c_k σ_k^Q⊗σ_k^E1⊗I^E2)，D_QE₂ = exp(i Σ c_k σ_k^Q⊗I^E1⊗σ_k^E2)

**数值验证（c_x=[0.5,0,0]全部平行）：**

```
||U - D(C_tot)_{QE1}|| = 3.37  (不是0!)
||U - exp(i(H1+H2+H3+H4))|| = 0.00  (这才是正确的)
```

总酉 U **不是**一个作用于单对上的 D(C_tot)。它是 4个嵌入生成元之和的指数 `exp(i Σ H_i)`，是真正的3-qubit（或4-qubit）整体算符。

### 后果

§3.2 Step 3-4的所有Kraus算子推导都基于 `U = D(C_tot)` 这个错误前提。实际的Kraus算子为：

```
K_ab = ⟨ab|_{E1,E2} U_full |γ⟩_E1|γ⟩_E2
```

其中 U_full = exp(i σ_n̂^Q ⊗ (c12 σ_n̂^E1⊗I + c34 I⊗σ_n̂^E2))，这是一个远更复杂的结构，不能约化为文档中的 `cos|C_tot|·I + i sin|C_tot|·σ_n̂⊗σ_n̂`。

## 审计发现 3: [F-C3] 嵌入生成元的对易性 — 2-qubit层vs 4-qubit层混淆

### 正确分析

**2-qubit层（单边Cartan核心内部）：**
`[a·σ⊗σ, b·σ⊗σ] = 0` 对**所有** a,b 成立。条件 c^(i)∥c^(j) 不是这些算符对易的前提。

**4-qubit嵌入层（不同边之间）：**
边1和边2共享E₁量子比特。嵌入后的生成元为：
- H₁ = σ_n̂₁^Q ⊗ σ_n̂₁^E1 ⊗ I^E2
- H₂ = σ_n̂₂^Q ⊗ σ_n̂₂^E1 ⊗ I^E2  （如Q_a≠Q_b，需要额外讨论）

数值验证：当c¹和c²均沿x轴时，`[H₁, H₂] = 0`。当c¹沿x、c²沿y时，`[H₁, H₂] = 0.72`（非零）。

**结论：** 嵌入生成元的对易性确实需要Cartan轴对齐，但原因不是文档中错误声称的2-qubit层不对易性，而是共享量子比特上的σ算符需要对齐。文档混淆了这两个分析层次，且2-qubit层的分析是数学错误的。

## 审计发现 4: [F-C4] §3.3 (-1)^(a+b)因子和本征基依赖

### 文档声称

```
K_ab = √(γ_a γ_b)[cos|C_tot|·I_Q + i(-1)^(a+b) sin|C_tot|·σ_n̂]
```

### 分析

(-1)^(a+b) 因子来自测量基 {|a⟩} 上的 σ_n̂ 本征值。当 n̂ = ẑ 且 {|a⟩} 是计算基（σ_ẑ 本征基）时，σ_ẑ|a⟩ = (-1)^a|a⟩，因子确实为 (-1)^a。扩展到两环境量子比特，得到 (-1)^(a+b)。

**但是：** 这个推导隐式假设了 n̂ = ẑ。当 n̂ 不在 z 轴上时：
1. 计算基 {|a⟩} 不再是 σ_n̂ 的本征基
2. 投影 ⟨ab| 和 σ_n̂|ab⟩ 之间的关系更复杂
3. 因子 (-1)^(a+b) 需要被替换为取决于 n̂ 与 ẑ 夹角的表达式

文档在一般陈述中使用了特例（n̂=ẑ），未声明此限制。

## 审计发现 5: [F-C5] (C1)条件 — 基依赖性问题

### 文档声称

(C1): γ₀ = γ₁ = 1/2（环境最大混合）

### 数值测试

使用正确的3-qubit模型测试QCMI=0条件（通过Kraus算子比例性判断）：

| Cartan轴 | |γ⟩ | QCMI |
|:---------|:--|:---:|
| 全∥x, c=0.5 | (|0⟩+|1⟩)/√2 = |+_x⟩ | **QCMI=0** ✓ |
| 全∥x, c=0.5 | √0.3|0⟩+√0.7|1⟩ (≠eigenstate) | QCMI>0 ✓ |
| 全∥z, c=0.5 | |0⟩ = |+_z⟩ | **QCMI=0** ✓ |
| 全∥z, c=0.5 | (|0⟩+|1⟩)/√2 (≠eigenstate) | QCMI>0 |
| 全∥y, c=0.5 | (|0⟩+i|1⟩)/√2 = |+_y⟩ | QCMI=0（经解析验证） |
| 全∥(0.3,0.4,0), c=0.5 | 适配的|+_n̂⟩ | QCMI=0（经解析验证） |

### 发现

QCMI=0 通过机制(C1)成立的**真正条件**是：|γ⟩ 必须在 σ_n̂ **本征基**下是最大混合态（即与|+_n̂⟩和|-_n̂⟩的权重相等）。

文档中的条件 "γ₀ = γ₁ = 1/2" 只有在 n̂ = ẑ（或通过宇称变换 n̂ = x̂ 且 |γ⟩ = |+_x⟩）的特殊情况下才等价于此条件。

对于一般的 n̂方向，计算基下的 "γ₀=γ₁=1/2" **不能**保证QCMI=0。正确的条件应该表述为：

```
(C1') |γ⟩ 在σ_n̂本征基下的两个权重相等
      ⇔ |⟨+_n̂|γ⟩|² = |⟨-_n̂|γ⟩|² = 1/2
```

这就要求 |γ⟩ 不能独立于 n̂ — 即 γ₀,γ₁ 的选择依赖于Cartan轴方向。在宇宙学场景中，这是一个额外的精细调节条件，CFOL定理未对此做诚实说明。

## 审计发现 8: 数值自洽性

### 文档表格验证

| 配置 | 文档预测 | 3-qubit模型验证 |
|:------|:---:|:---:|
| CNOT环（全∥z, |c_i|=π/4) | QCMI=0 | 若|C_tot|=π且γ适当 → QCMI=0 ✓ |
| XX环（全∥x, |c_i|=π/4) | QCMI=0 | 若|C_tot|=π且γ适当 → QCMI=0 ✓ |
| wHaar（随机方向） | QCMI>0 | QCMI>0 ✓ |
| γ₀≠γ₁+非π相位 | QCMI>0 | **是但不精确:** 还依赖于n̂-计算基对齐 |

### 待验证预测

"γ₀≠γ₁+非π相位 → QCMI>0" 这个预测在**定性**上是正确的 — 当两条QCMI=0路径（|C_tot|=nπ 和 γ最大化混合）都堵塞时，QCMI>0。但数值上QCMI的具体值取决于：
1. n̂与计算基的夹角
2. c^(i)的具体大小（不只是|C_tot|）
3. 两环境量子比特之间的有效相互作用（文档模型忽略了这一点）

因此"QCMI>0"的预测是真实的，但"QCMI的具体值可由|C_tot|和γ决定"的定量声称未被本文档的简化模型支持。
