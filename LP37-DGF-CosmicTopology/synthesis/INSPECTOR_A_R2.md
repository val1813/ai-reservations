## 维度2: 指数衰减论证 — 🔴🔴🔴 FATAL (k/ℓ概念混淆)

### 2.1 声称回顾

round2.md §2.2 引理 Z-Cross-2 声称:

$$\|\text{Source}_{k}^{\text{cross}}(i,j)\| \leq C \cdot 2^{-2k} \cdot 2^{-\ell_{ij}}$$

其中 ℓ_{ij} 是环C_i和C_j之间的树路径长度（以边数计）。

### 2.2 Zhou Gang原始含义

Zhou Gang的(3.18):

$$\|\text{Source}_{q,r}\| \leq C \cdot 2^{-2k}$$

其中k来自(3.15): $(q,r) = p(l/2^k, 1-l/2^k)$。k是**二进分解的参数**——它将指数(q,r)在区间[0,p]上进行2^k等分。k与任何图论距离无关。

Zhou Gang(3.18)的物理意义是: 当Source项对应的二进分解层级k增大时（即(q,r)区间划分更细时），Source范数以2^{-2k}指数衰减。这是**数值分析中的尺度收敛**，不是物理空间中的距离衰减。

### 2.3 A博士的推导审计

round2.md §2.2 "证明思路" 全文:

> "Zhou Gang的Lemma 3.3证明中，$\|\text{Source}_{q,r}\| \leq C \cdot 2^{-2k}$的推导依赖于$\|V_{q_+,\Psi} - V_{q_-,\Psi}\| \leq C \cdot 2^{-k}$。对于跨环耦合，差分$\|V_{q_+,\Psi}^{(i)} - V_{q_-,\Psi}^{(i)}\|$和$\|V_{q_+,\Psi}^{(j)} - V_{q_-,\Psi}^{(j)}\|$来自不同的Cartan参数集。在张量积结构中，跨环项的范数以乘积形式衰减。每个共享节点引入一个额外的$2^{-1}$因子（因为Cross定义中(2.6)的积分对每个子系统贡献独立的衰减因子）。$\ell_{ij}$个共享边/节点给出$2^{-\ell_{ij}}$的总衰减。"

逐句审计:

| 句子 | 审计 |
|:---|:---|
| "∥V_{q+,Ψ} - V_{q-,Ψ}∥ ≤ C·2^{-k}" | ✅ 正确。这是Zhou Gang Lemma 3.3证明的核心估计。 |
| "差分来自不同的Cartan参数集" | ⚠️ 无依据。Zhou Gang的V^{(i)}和V^{(j)}对应不同环的Cartan参数，但这一事实本身不产生任何衰减因子。 |
| "在张量积结构中，跨环项的范数以乘积形式衰减" | 🔴 **无推导。** 张量积∥A⊗B∥=∥A∥·∥B∥只说明范数是乘积形式的，不说明任何衰减。乘积可以是O(1)×O(1)=O(1)。 |
| "每个共享节点引入一个额外的2^{-1}因子" | 🔴🔴 **完全无依据。** Cross定义(2.6)的积分结构是∫ s^{-1/2}(1+s)^{-1} ẽΨ(s)Ω(s)ẽΨ(s)Ω*(s)ẽΨ(s) ds + Ψ[...]Ψ。这个积分的衰减性质由s→0和s→∞的渐近行为决定，与"共享节点数"毫无关系。 |
| "(2.6)的积分对每个子系统贡献独立的衰减因子" | 🔴🔴 **核心概念错误。** (2.6)的积分不"对每个子系统"贡献因子。(2.6)是在N×N矩阵空间上的单一积分，不是对张量积子系统的逐项积分。子系统的概念不出现在Cross定义的任何地方。 |
| "ℓ_{ij}个共享边/节点给出2^{-ℓ_{ij}}的总衰减" | 🔴🔴🔴 **完全无推导的断言。** 从前面没有任何论证能推出这个结论。 |

### 2.4 §2.3 Step 3的第二次推导尝试

round2.md §2.3 步骤3尝试了另一条路径:

> "在$D_\delta$传播链（(4.11)式）中，每个$D_\delta$操作引入额外的$\sim 1/2$因子（(3.23)式）。当交叉Source项需要经过$\ell_{ij}$步$D_\delta$传播才能到达总QCMI的求和级数时，总衰减因子为$2^{-\ell_{ij}}$。"

审计:

**这是概念混淆。** Zhou Gang的D_δ传播链(4.11)是沿二进分解层级k的传播:

```
Source_1 → (D_{-2^{-2}}) → Source_2 → (D_{-2^{-3}}) → Source_3 → ...
```

传播步骤数是k-1（从尺度1到尺度k），每一步在(4.13)的重整化下贡献~1/2。这里没有任何与图距离ℓ_{ij}相关联的步骤。

A博士将两种完全不同的"距离"混淆了:
- **二进分解层级k**: Zhou Gang框架内的尺度参数，决定(q,r)的细分数
- **图论距离ℓ_{ij}**: DGF因果图中两个环之间的边数

这两者在Zhou Gang的框架中没有任何数学联系。不存在"交叉Source项需要经过ℓ_{ij}步D_δ传播"的机制——D_δ传播步数由k决定，不由ℓ_{ij}决定。

### 2.5 判决

**引理Z-Cross-2的2^{-ℓ_{ij}}因子在Zhou Gang框架下没有推导支持。** 这是一个基于概念混淆（将二进分解层级k与图论距离ℓ_{ij}混为一谈）的虚假声称。

**后果链:**
- 引理Z-Cross-2崩塌 → Theorem Z-b₁的指数精度界崩塌 → b₁可加性"定理"的严格性崩塌 → T8'从"猜想"升级为"定理"的声称不成立
- R2最核心的声张——"T8'从猜想升级为指数精度定理"——失去了数学支撑
