## §3 证明

### §3.1 充分性 (C-I)+(C-II) ⟹ QCMI=0

**(C-I)成立。** 由F0.3，[H_i,H_j]=0。U=exp(i H_tot)，λ_{...}如F0.4。

**(C-II)(a)成立。** 设c_i = n_i·π/2，n_i∈ℤ。

K_{s₂,s₄}[s₁,s₃] = α_{s₂}α_{s₄} · exp(i(c₁s₁s₂ + c₂s₂s₃ + c₃s₃s₄ + c₄s₄s₁))

每个指数项：exp(i·c_i·s_a·s_b) = exp(i·n_i·(π/2)·s_a·s_b)。由于s_a,s_b=±1，乘积s_as_b=±1。exp(i·n_i·(π/2)·(±1)) = i^{±n_i} ∈ {±1, ±i}。

关键：对于固定的(s₂,s₄)，K_{s₂,s₄}[s₁,s₃]对(s₁,s₃)的依赖完全由exp(i(c₁s₁s₂+c₂s₂s₃+c₃s₃s₄+c₄s₄s₁))决定。

检查K_{++}和K_{+-}的比值（E₁固定+，E₂翻转）：

$$\frac{K_{++}[s_1,s_3]}{K_{+-}[s_1,s_3]} = \frac{\alpha_+^2}{\alpha_+\alpha_-} \cdot \frac{\exp(i(c_1 s_1 + c_2 s_3 + c_3 s_3 + c_4 s_1))}{\exp(i(c_1 s_1 + c_2 s_3 - c_3 s_3 - c_4 s_1))}$$
$$= \frac{\alpha_+}{\alpha_-} \cdot \exp(2i(c_3 s_3 + c_4 s_1))$$

由于c₃=n₃π/2，c₄=n₄π/2：exp(2i c₃ s₃) = i^{2n₃ s₃} = (-1)^{n₃ s₃}。s₃=±1则此因子=(-1)^{±n₃}。exp(4i c₃)=(-1)^{2n₃}=1，故exp(2i c₃·(+1)) = exp(2i c₃·(-1))（均为(-1)^{n₃}）。因子不依赖于s₃。同理c₄项不依赖于s₁。

**因此K_{++}/K_{+-} = (α₊/α₋)·(±1) = 标量，不依赖(s₁,s₃)。**

同理：
$$\frac{K_{++}}{K_{-+}} = \frac{\alpha_+}{\alpha_-} \cdot \exp(2i(c_1 s_1 + c_2 s_3)) = \text{标量}$$
$$\frac{K_{+-}}{K_{--}} = \frac{\alpha_+}{\alpha_-} \cdot \exp(2i(c_1 s_1 + c_2 s_3)) = \text{同一标量}$$

六个比值全部为标量。四个K算子在Q_a⊗Q_b空间上互成比例 → Kraus秩=1 → Choi态秩=1 → QCMI=0。∎

**(C-II)(b)成立。** |α₊|=|α₋|=1/√2。此时α₊=e^{iθ}/√2，α₋=e^{iφ}/√2，|α₊|/|α₋|=1。比值中权重因子为1（模长）。相位差e^{i(θ-φ)}在六个比值中以一致的方式出现——可通过全局相位吸收。四个K算子互成比例。QCMI=0。∎

### §3.2 必要性 QCMI=0 ⟹ (C-I)+(C-II)

**步骤1：Cartan轴必须对齐。** 假设QCMI=0。若∃i,j使c^(i)∦c^(j)，则∃k≠l使第i条边有非零k分量、第j条边有非零l分量。由F0.3，[H_i,H_j]≠0。H_tot含非Cartan生成元（形如σ_k⊗σ_m⊗σ_l⊗I，k≠l≠m），其在演化后态中产生的Q-E纠缠违反HJPW短量子马尔可夫链条件。由HJPW(2004)定理6，QCMI>0。与假设矛盾。故c^(1)∥c^(2)∥c^(3)∥c^(4)。∎

**步骤2：参数必须满足(C-II)。** Cartan对齐成立。K_{s₂,s₄}如F0.5。

QCMI=0要求K_{++}, K_{+-}, K_{-+}, K_{--}成比例。考虑比值（同§3.1的推导，对齐下对任意{c_i}成立）：

$$r_1(s_1,s_3) := \frac{K_{++}}{K_{+-}} = \frac{\alpha_+}{\alpha_-} \cdot \exp(2i(c_3 s_3 + c_4 s_1))$$
$$r_2(s_1,s_3) := \frac{K_{++}}{K_{-+}} = \frac{\alpha_+}{\alpha_-} \cdot \exp(2i(c_1 s_1 + c_2 s_3))$$

QCMI=0 ⟹ r₁(s₁,s₃)与(s₁,s₃)无关，且r₂(s₁,s₃)与(s₁,s₃)无关。

对于r₁，与s₃无关：exp(2i c₃·(+1)) = exp(2i c₃·(-1)) ⟹ exp(4i c₃)=1 ⟹ c₃∈(π/2)ℤ。
与s₁无关：exp(2i c₄·(+1)) = exp(2i c₄·(-1)) ⟹ exp(4i c₄)=1 ⟹ c₄∈(π/2)ℤ。

对于r₂，同理：c₁,c₂∈(π/2)ℤ。

因此若QCMI=0且r₁,r₂不恒常（即α₊/α₋不是恰好通过相位因子抵消非平凡(s₁,s₃)依赖性），则必须c_i∈(π/2)ℤ ∀i。此即(C-II)(a)。

若α₊/α₋的相位使r₁非平凡依赖被吸收（仅当exp(2i(c₃s₃+c₄s₁))本身不依赖(s₁,s₃)，即c₃,c₄∈(π/2)ℤ，此时r₁=α₊/α₋·(±1)，已是常数），则已落入(a)。

**(C-II)(b)作为独立的充分条件——|α₊|=|α₋|时：**

若c_i∉(π/2)ℤ对某i成立，则r₁或r₂的指数因子非平凡依赖于(s₁,s₃)。QCMI=0要求此依赖被α₊/α₋补偿——即α₊/α₋的模长和相位恰好使K_{s₂,s₄}成比例。此条件的一般参数化等价于|α₊|=|α₋|（环境在Cartan基下最大混合）。证明：若|α₊|≠|α₋|，则r₁和r₂的**模长**|α₊/α₋|≠1，四个K算子的Frobenius范数不相等→不能互成比例→QCMI>0。故QCMI=0时的非退化带(c_i∉(π/2)ℤ)要求|α₊|=|α₋|=1/√2。∎

**综上，(A)⟺(C)。** ∎

## §6 物理意义

c_i∈(π/2)ℤ意味着每条边上的Cartan旋转角是离散的——π/2的整数倍。这对应因果环上的信息传播是**量子化**的：绕环一圈，Q-qubit获得π/2整数倍的相位旋转。只有这种离散旋转才能使两条信息通道（E-qubit的两个本征态）产生可成比例的Kraus算子。

在物理上，c_i连续谱中QCMI=0是一个零测集（可数离散点+一个退化曲面γ₀=γ₁=½）。这意味着**QCMI>0是通有（generic）的**——几乎所有的Cartan参数都产生量子非马尔可夫性。因果环几乎总是"产生"量子性。这正是DGF的核心主张：因果拓扑强制量子关联。
