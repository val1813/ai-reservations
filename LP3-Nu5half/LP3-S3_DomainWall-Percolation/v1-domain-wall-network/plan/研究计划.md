# LP3-S3 研究计划：Pf/APf 域壁 Majorana 渗流能否定量产生 kappa_xy=5/2?

## 北极星

无序域壁渗流模型的定量验证：Pf/APf 域壁 Majorana 网络是否在 GaAs ν=5/2 实验参数窗口内产生 `kappa_xy=5/2 kappa_0`？

## 依赖

- LP3-S1：APf 边缘解释存在永久 tradeoff；纯边缘机制无法无代价同时匹配 `kappa_xy^total=5/2` 与分数通道张力。
- LP3-S2：Yang 映射失效强反对路径已关闭；`bulk APf + edge PHPf-like` 原则上自洽，但不是无条件证明。

## 驱动矛盾

命题 A：Pf/APf 域壁网络可以在真实无序下形成 disorder-stabilized PH-Pfaffian 热绝缘相，从而给出 `K=5/2`。

命题 B：真实参数更可能落入直接 Pf/APf 一阶转换或 class-D thermal metal，相应地 `K` 要么跳到 `7/2` 或 `3/2`，要么不量子化；`K=5/2` 只在窄参数区出现。

## 三阶段计划

### Phase 1：定量门槛整理
- 读取 Wang-Vishwanath-Halperin 1711.11557、Mross-Oreg-Stern 1711.06278、Lian-Wang 1801.10149、Zhu-Sheng-Yang 2003.02621。
- 建立最小判据：域壁可生成、域壁网络可渗流、Majorana 网络局域化而非 thermal metal、`K=5/2` plateau 可宽于实验分辨率。
- 输出参数表：`sigma_DW`、`E_dis`、`d_DW`、`xi_dis`、`rho_vortex`、`eta_inter/eta_intra`。

### Phase 2：经典/网络模拟方案
- 用二维随机场生成 Pf/APf domain mosaic，扫描 disorder correlation length 与 bias。
- 用 Chalker-Coddington / class-D network 代理量估计 thermal metal vs localized PH-Pf window。
- 不追求完整 ED，目标是判定实验参数是否落在窄窗内。

### Phase 3：与 S1/S2 合并判决
- 若 S3 可行：LP3 的最强图像变为 Pf/APf 混合网络或 domain-wall-stabilized PHPf。
- 若 S3 不可行：LP3 剩余解释主要是 S1/S2 的边缘投影/重构路径，S4 转入判决实验设计。

## 预期结论类型

大概率为“有边界”：域壁机制可在原则上产生 `K=5/2`，但真实 GaAs 参数是否足够稳定取决于域壁张力、random vortex 密度与 emergent symmetry 保护。
