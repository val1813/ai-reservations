# 知识库 — LP3-S3 DomainWall-Percolation

## K1：Wang-Vishwanath-Halperin 网络相图

**来源：** arXiv:1711.11557

- Pf/APf 域壁携带 `K=2`，可表示为 4 个同向 chiral Majorana 模。
- 弱无序且域壁昂贵时，系统更可能直接在 Pf 与 APf 间一阶样切换，`K=7/2` 或 `K=3/2`。
- 强无序下，域壁网络可能形成 thermal metal；`K` 不量子化且 `kappa_xx != 0`。
- `K=5/2` thermal insulator 只在受限参数区出现，并与 PH-Pfaffian 拓扑序绝热连接。

## K2：class-D 随机 vortex 风险

**来源：** arXiv:1711.11557

- random π-flux / vortex 会产生 Majorana zero modes。
- 有限 vortex 密度通常推动 delocalization，形成 thermal metal。
- 稳定 `K=5/2` 需要强 intra-island mixing 抬升偶数零模，同时避免 inter-island hopping 过强。

## K3：Lian-Wang emergent symmetry 阈值图

**来源：** arXiv:1801.10149

- 低能域壁可出现 emergent SO(4)，中间能区出现 U(1)xU(1)，高无序只剩 fermion parity。
- `Lambda < Lambda1`：单一 Pf/APf 转换。
- `Lambda1 < Lambda < Lambda2`：可能出现 `K=5/2` 中间相。
- `Lambda > Lambda2`：多次 1/2 跳变或 thermal metal。

## K4：Zhu-Sheng-Yang 界面张力与电场门槛

**来源：** arXiv:2003.02621

- DMRG 显示 Pf/APf 界面强 hybridization，charged modes gap out，仅中性模保留。
- 界面出现拓扑来源的 electric dipole moment，由 guiding-center Hall viscosity mismatch 决定。
- 域壁张力估计 `sigma_DW ~ 0.0017-0.0021 e^2/l_B^2`。
- 稳定域壁所需局域电场约 `E_dis >= 2.9e5 V/m`，与高迁移率 GaAs 远程掺杂无序量级接近。
- 域壁宽度/穿透长度 `d_DW >= 16 l_B`，对应 puddle 最小尺度约数百 nm。

## K5：S1/S2 接口约束

**来源：** LP3-S1, LP3-S2

- S1：纯边缘 APf 机制存在 tradeoff，无法无代价完全解释分数通道张力。
- S2：映射稳定性在平滑无序下成立，边缘 PHPf-like 信号可与 bulk APf 共存。
- 因此 S3 应检验的是“第三路径是否真实占据实验参数窗口”，而不是重复证明 edge/bulk 可解耦。
