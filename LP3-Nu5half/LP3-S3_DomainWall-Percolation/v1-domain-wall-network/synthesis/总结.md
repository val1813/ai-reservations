# 总结 — DomainWall-Percolation

## 原始北极星

LP3-S3: Pf/APf 域壁 Majorana 渗流是否在实验参数窗口内产生 `kappa_xy=5/2 kappa_0`？

## 版本历史

### v1 Phase 1
- 用 Wang-Vishwanath-Halperin 的网络模型把问题拆成三部分：域壁是否生成、是否渗流、是否局域化成 `K=5/2` 而非 thermal metal。
- 用 Zhu-Sheng-Yang 的界面张力估计把“域壁是否能存在”转成 `E_dis >= E_dis^crit` 的门槛问题；同时标注 `E_dis` 应为有效 Pf/APf bias 分量，不是裸库仑电场。
- 发现域壁长度 `d_DW >= 16 l_B` 与 GaAs 掺杂 setback 长度同阶，因此 domain wall 不是几何上无可想象的对象。

### v1 Phase 2
- 把模型压缩成三个扫描轴：`x=E_dis/E_dis^crit`、`y=xi_dis/d_DW`、`z=rho_vortex*d_DW^2`。
- 得到结论：`K=5/2` 只在“门槛附近但未进入 delocalization”的窄窗中可行。
- 弱无序更像 direct Pf/APf transition；强无序更像 thermal metal；`K=5/2` 需要中间区域且要求 `eta_intra >> eta_inter`。

## 最终结论

**结论类型：有边界。**

Pf/APf 域壁 Majorana 渗流是一个原则上成立的第三路径，但它不是对 ν=5/2 热霍尔数据的自动解释。真实实验样品若想落入 `K=5/2` thermal insulator，必须同时满足：

- 域壁能被有效无序钉扎并形成网络；
- random vortex / π-flux 密度不能太高；
- intra-island mixing 足够强，inter-island hopping 足够弱；
- 系统不能被推入 class-D thermal metal。

因此，S3 的定位是“窄窗可行、非普适可行”。

## 对 LP-3 长命题的贡献

- S1：纯边缘解释有 tradeoff 边界。
- S2：映射/边缘 gapping 在平滑无序下可稳定，但不是无条件普适。
- S3：域壁渗流是第三路径，但只在窄参数窗内成立。

三者合起来，LP3 不是单一路径胜出，而是一个三分边界图。
