# LP3-S4 研究计划：区分三种解释的判决实验方案

## 北极星

设计区分三种解释的判决实验方案：

1. 系统性偏差 / 边缘非拓扑修正
2. 边缘解耦 / bulk APf + edge PHPf-like
3. Pf/APf 域壁 Majorana 渗流

## 依赖

- LP3-S1：热输运非拓扑修正有边界，但存在永久 tradeoff。
- LP3-S2：映射稳定性在平滑无序下成立，但不等于无条件 bulk-edge 严格同一性。
- LP3-S3：域壁渗流只在窄窗内可行，强无序会推向 thermal metal。

## 核心问题

实验上怎样最小代价地区分：

- `kappa_xy=5/2` 是边缘修正造成的假象？
- `kappa_xy=5/2` 是 bulk-edge 解耦但 bulk 仍是 APf？
- `kappa_xy=5/2` 是真实域壁网络的 thermal insulator？

## 设计原则

### 原则 1：优先选有方向性的观测量
- 不能只看一个 `kappa_xy` 数值。
- 必须看它对门电压、无序强度、几何与温度窗口的响应斜率。

### 原则 2：优先选能打破简并的几何
- Hall bar / Corbino / side-gate 可调边缘势。
- bulk probe 需独立于 edge 读出，例如 STM 隧穿或局域噪声。

### 原则 3：优先选能闭合逻辑链的样品序列
- 多无序强度 wafer series。
- 同一工艺下不同 setback / disorder density。

## 三类候选实验

### E1：侧门电压扫描

目标：测试边缘势是否只改 edge，不改 bulk。

可观测量：
- `kappa_xy^total(Vg)`
- 经边缘通道分解后抽取的 `kappa_xy^frac(Vg)` 或分数通道张力
- 局域边缘电导 / 模平衡化长度

判据：
- 若协议抽取的 `kappa_xy^frac` 与 `kappa_xy^total` 同步变化，支持纯边缘 tradeoff；但必须同时报告抽取协议，避免用模型分解量循环验证模型。
- 若 `kappa_xy^total` 基本不变而边缘读出大幅变化，支持 bulk APf + edge 解耦。
- 若存在阈值式跳变并伴随噪声/涨落增强，支持域壁网络重构。

### E2：bulk probe / STM / 准粒子隧穿

目标：直接看 bulk 是否存在 Pf/APf puddle / domain wall 结构。

可观测量：
- 局域密度/电势纹理
- 准粒子隧穿谱中的 domain-wall resonance
- bulk 局域热/电响应不均匀性

判据：
- 若 bulk 纹理弱而 edge 变化强，偏向边缘解耦。
- 若 bulk 直接出现 Pf/APf puddle / domain-wall signature，支持 S3。

### E3：无序强度样品系列

目标：看 `K=5/2` 是否只存在于窄窗。

可观测量：
- `K` 随迁移率 / setback / 无序相关长度的变化
- `kappa_xx` 是否出现非零中间 metal 区
- plateau 宽度是否先扩大后缩小

判据：
- 若 `K=5/2` 只在中等无序出现，而弱/强无序都消失，支持 S3 窄窗。
- 若 `K=5/2` 对无序极其稳定，偏向 S2 的 bulk-edge 解耦。
- 若分数通道的偏差随边缘势精细可调，偏向 S1。

## 优先级排序

| 排名 | 实验 | 理由 |
|------|------|------|
| 1 | 无序强度样品系列 E3 | 最能直接区分“窄窗域壁”与“边缘普适修正” |
| 2 | 侧门电压扫描 E1 | 最能区分边缘修正与 bulk 解耦 |
| 3 | bulk probe / STM E2 | 最强但最难，只适合作为长周期终局候选 |

## 初步判断

### 支持 S1 的信号
- `kappa_xy^frac` 和 `kappa_xy^total` 近似锁定；
- 调边缘势后两个量协同变化；
- 没有明显 bulk puddle / domain-wall 纹理。

### 支持 S2 的信号
- `kappa_xy^total` 保持，而边缘投影/隧穿谱可明显改变；
- 平滑无序下映射保持，bulk 信号与 edge 信号可分离；
- bulk probe 看到 APf 特征，但 edge 有 PHPf-like readout。

### 支持 S3 的信号
- `K=5/2` 仅在中等无序窗口出现；
- `kappa_xx` 维持近零，但热边缘信号具有样品依赖阈值；
- bulk probe 能看到 Pf/APf puddle / domain-wall 结构；
- 强无序下转入 thermal metal，弱无序下回到 direct Pf/APf switching。

## 预期结论类型

**有边界。**

不存在单一实验能无歧义关闭所有解释，但三件事联合起来足够形成判决：

1. 无序样品系列定窗；
2. 侧门扫描定边缘灵敏度；
3. bulk probe 作为终局候选检查是否存在域壁网络。
