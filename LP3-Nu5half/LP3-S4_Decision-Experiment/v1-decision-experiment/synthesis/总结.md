# 总结 — Decision-Experiment

## 原始北极星

LP3-S4: 区分三种解释（系统性偏差 / 边缘解耦 / 域壁渗流）的判决实验方案。

## 版本历史

### v1 Phase 1
- 将三路解释拆成可观测量：`kappa_xy^total`、经边缘通道分解后抽取的 `kappa_xy^frac`、`kappa_xx`、门电压斜率、bulk 纹理。
- 建立最小判决树：无序样品系列、侧门扫描、bulk probe。

### v1 Phase 2
- 把判决树压缩成一页路线图。
- 明确失败判据：
  - S1 失败：协议抽取的 `kappa_xy^frac` 与 `kappa_xy^total` 不同步，且边缘势不能解释。
  - S2 失败：bulk 直接看到 Pf/APf puddle，而 edge 只是被动读出。
  - S3 失败：`K=5/2` 无窄窗，或强无序下快速进入 thermal metal。

## 最终结论

**结论类型：有边界。**

没有单一实验能无歧义区分三条路径；但三件事联合起来足够形成判决：

1. 无序样品系列先定窄窗；
2. 侧门扫描再区分边缘修正与 bulk 解耦；
3. bulk probe 作为长周期终局候选，检查是否存在域壁网络。

因此，LP3 的实验层面不应追求单点读数，而应追求“三联判决”：近期主轴是无序系列和侧门扫描，bulk probe 只作为终局候选和交叉确认。

## 对 LP-3 长命题的贡献

- S1 提供边缘 tradeoff 的边界。
- S2 提供平滑无序下映射稳定性的边界。
- S3 提供域壁窄窗可行性的边界。
- S4 把三者变成可执行的判决实验。
