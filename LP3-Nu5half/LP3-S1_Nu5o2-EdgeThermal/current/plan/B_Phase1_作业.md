# B博士 Phase 1 突击推导作业

## 【PI审核入口】

- **本Phase推进了什么：** 建立了热输运测量的信息论框架，证明κ_xy作为单标量观测在实验约束下存在信道简并——三个候选拓扑序（APf, PHPf, Pf）在测量"滤波器"通带内无法以统计置信度区分
- **最关键的跨域连接：** Shannon-Hartley信道容量定理 + Fisher信息矩阵 + Cramér-Rao下界 → 热输运测量分辨率的硬上限 + CFT微扰论（ψ_d·ψ_u隧穿Δ=1<2强relevant）
- **预测vs实际：** 预测1部分修正（纯统计SNR可能足够，但系统误差致命）；预测2确证（Majorana隧穿relevant）；预测3确证（信息瓶颈在系统误差不在统计噪声）
- **卡在哪里：** Majorana隧穿IR固定点的有效中心电荷需数值计算（DMRG/ED）；ℓ_eq定量计算需微观数值（A博士正在做）；1/f噪声系统偏置需有限元模拟

## 核心论证结构（三条独立路线交汇）

### 路线1：信息论信道容量
- 热输运测量 = 离散无记忆信道，X∈{APf, PHPf, Pf}，Y=κ_xy^measured
- 信道容量 C ≤ log₂[1 + (Δκ_xy)²/(σ²_stat + σ²_sys)]
- 在有限L、有限T下，测量算子M不是单射：∃ X₁≠X₂ : M(X₁)=M(X₂) within uncertainty
- 有限尺寸效应导致ℓ_eq依赖的κ_xy^eff漂移，产生信道简并

### 路线2：CFT微扰论（核心攻击点）
- APf边缘CFT = U(1)⊕Ising(c=1/2)⊕Ising(c=1/2)
- ψ_d·ψ_u（Majorana-Majorana隧穿）标度维度Δ=1/2+1/2=1 < 2 → **强relevant**
- RG流：dλ₂/dℓ = λ₂ > 0 → λ₂在IR发散 → 流向新固定点
- 新IR固定点的有效κ_xy可能≠1/2
- 手征对称性不保护λ₂=0（APf非PH对称）

### 路线3：信号处理——反身性危机
- 纯统计SNR~100（看似充分），但系统误差Bias_systematic/Δκ_true ~ 0.1-1
- 系统误差源：体准粒子寄生热流、边缘重构额外信道、接触非理想性
- **反身性危机：** κ_xy测量用于推断拓扑序 → 需要知道有限尺寸效应 → 需要改变L的系统实验 → 从未做过 → 现有推断逻辑不完整

## 关键判断

**对命题B的判断：**
命题B（APf的κ_xy=1/2是拓扑保护的）可能为真，但即便为真，κ_xy=5/2的测量也不能唯一推断PH-Pfaffian——因为系统误差+信道简并+多参数交叉验证缺失。

**信息不完整性定理（非正式）：**
在有限T>0、有限L<∞、有限t_meas<∞下，热输运测量区分ν=5/2候选态的信道容量存在实验参数依赖的上界，当前实验是否在可区分区仍是开放问题——且不能用κ_xy测量本身回答。
