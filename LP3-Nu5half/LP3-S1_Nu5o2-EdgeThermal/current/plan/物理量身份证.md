# 物理量身份证 — Nu5o2-EdgeThermal

> 每个物理量必须有：定义、理论框架内的数学对象类型、测量方式、与其他量的关系

## 核心物理量

### κ_xy（热霍尔电导）
- 定义：横向热流/温度梯度，κ_xy = J_Q^x / (-∂_y T)
- 理论框架：边缘模Landauer-Büttiker形式主义
- 数学对象：实数（单位κ₀ = π²k_B²T/3h）
- 拓扑值（clean极限）：κ_xy/T = c_L - c_R（左右手征中心荷之差）× κ₀/T
- 非拓扑修正来源：模间散射、热损失、边缘势重构
- 文献值：Heiblum 2023测κ_xy=5/2κ₀（ν=5/2），分数通道0.29κ₀ vs 预期0.5κ₀

### G（电导）
- 定义：纵向/横向电流/电压
- 理论框架：Landauer-Büttiker多端形式主义
- 与κ_xy关系：Wiedemann-Franz定律仅在clean极限严格成立

### ℓ_eq（边缘平衡化长度）
- 定义：边缘模达到热平衡所需的传播长度
- 决定因素：模间散射率、边缘势梯度、温度
- 关键参数：实验样品尺寸 vs ℓ_eq的相对大小

### 边缘模结构
- ν=5/2候选拓扑序的边缘模：
  - PH-Pfaffian: 下游Majorana(1/2) + 上游玻色子(1) + 下游玻色子(1) → c_L=1+1=2, c_R=1/2 → κ_xy=5/2
  - anti-Pfaffian: 上游Majorana(3/2) + 下游玻色子(1) + 下游玻色子(1) → c_L=2, c_R=3/2 → κ_xy=1/2
  - Pfaffian: 下游Majorana(1/2) + 下游玻色子(1) + 下游玻色子(1) → c_L=5/2, c_R=0 → κ_xy=5/2
