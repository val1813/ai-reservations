# 总结 — Nu5o2-Mapping

## 原始北极星

LP3-S2: anti-Pfaffian ↔ PH-Pfaffian 精确映射在有限无序下是否保持？边缘势能否选择性 gap out 玻色子模？

## 版本历史

### v1 Phase 1
- 建立 Yang 映射的 clean 极限框架：SLL PH-Pfaffian 与 LLL anti-Pfaffian 共享 Majorana 边缘模，但不共享上游中性玻色子模。
- 第一轮攻击认为无序可能破坏 Landau 能级结构、Jastrow-Pfaffian 形式和 disk 几何边界条件。
- 防守后得到关键修正：GaAs 中主导的远程平滑无序主要耦合 guiding-center，自旋回旋/Landau 级混合被 `(l_B/xi_corr)^2` 压制。

### v1 Phase 2
- 引入 fidelity metric 与 PCA 作为数值验证方案，确认“映射稳定性”可以转写为 `F_map(W)=|<Psi_SLL(W)|U|Psi_LLL(W)>|^2` 的可计算问题。
- 修正 Phase 1 对无序强度的过度乐观估计：输运散射率 `hbar/tau` 不能直接等同于多体无序展宽 `Gamma`。
- 发现真正的边界条件：平滑二体无序的映射误差可被 form-factor 小 `q` 结构压制；短程无序、三体 LL-mixing 交叉项和真实边缘几何可能绕开该压制。

### v1 Phase 3A
- 给出 ED+PCA 验证代码 `phase3a_ed_pca.py`。
- 代码实现包括 disk 几何 Fock 空间、LLL/SLL 赝势、简化无序势、Yang 映射算符、Lanczos 基态求解、`F(W)` 与 fidelity metric 输出。
- 该代码是方法学原型，不构成最终数值证据：二体矩阵元、无序模型与 SLL 投影仍为近似实现。

### v1 Phase 3B
- 将问题从“无序是否破坏映射”推进到“为什么 SLL 投影会消除上游中性玻色子模”。
- 提出机制图像：SLL form factor 的 `q^2 l_B^2` 修正通过边缘密度通道产生有效 pinning / sine-Gordon 项，从而 gap out 上游中性玻色子模；Majorana 模因电荷中性而不直接耦合密度 form factor。
- 结论等级保持 O3/O4：物理图像一致，但 sine-Gordon 项系数、临界相关性和真实边缘重构耦合仍需 ED/DMRG 或实验门电压扫描验证。

## 最终结论

**结论类型：有边界。**

Yang 映射不是“任意无序下的严格同一性”，但在实验相关的平滑远程无序窗口中具有强稳定性。单粒子 Landau 级混合受 `(l_B/xi_corr)^2` 压制，主要剩余风险来自多体相关无序、短程界面无序、LL-mixing 三体交叉项和 disk 几何推广问题。

边缘层面，SLL 投影消除上游中性玻色子模应理解为 density/form-factor 通道诱导的边缘 pinning/gapping 机制，而不是 bulk 拓扑序无条件改变。Majorana 边缘模可保留，因此“bulk anti-Pfaffian + edge PH-Pfaffian-like 信号”在原则上自洽。

## 对 LP-3 长命题的贡献

S2 关闭了“映射在真实无序中必然失效”的强反对路径，但也没有证明无条件 bulk-edge 解耦。结合 S1：

- S1 给出 APf 边缘解释热输运的永久 tradeoff 边界；
- S2 给出映射/投影路径的条件稳定性；
- LP3-S3 可以解锁，重点转向 Pf/APf 域壁渗流是否在 GaAs 参数窗口内定量产生 `kappa_xy=5/2 kappa_0`。

## 关键边界

- 平滑远程无序：映射稳定性最强。
- 短程界面无序：可能使 form-factor 小 `q` 压制失效。
- 三体 LL-mixing × 无序交叉项：当前无法解析排除，是最大理论风险。
- ED+PCA：已有原型，但还不是可引用数值结论。
- 边缘 gapping：机制合理，系数未闭合。
