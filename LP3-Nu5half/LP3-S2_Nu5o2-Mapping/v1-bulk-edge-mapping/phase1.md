## SOP-1: 从矛盾出发

### 精确矛盾陈述

**结论A（Yang 2025）:** SLL PH-Pfaffian波函数通过全局LL提升算符∏_i a_i^†精确映射到LLL af-Pfaffian（ℓ=-3 f波配对）。映射是恒等式级别的精确，不是近似。SLL PH-Pfaffian与LLL anti-Pfaffian共享Majorana边缘模（精确映射证明），但不共享玻色子边缘模。

**结论B（实验现实）:** GaAs 2DEG中ν=5/2样品存在多种无序源——远程电离杂质（~100nm外的δ掺杂层）、界面粗糙度、合金无序。迁移率μ~10⁷ cm²/Vs对应输运散射率ℏ/τ~0.1K。更重要的是，LL mixing参数κ~1.2（B=5T时），意味着Landau能级混合在clean极限已不可忽略。

**矛盾的具体表现:** Yang映射的数学结构∏_i a_i^†是clean-system算符，它要求单粒子态是纯Landau能级本征态。无序势V(r)混合Landau能级→单粒子态不再是|N,m⟩直积态。映射是否仍然精确？

**矛盾的精确定量表述:** 令|Ψ_SLL(W)⟩为无序强度W下的SLL物理基态，|Ψ_LLL(W)⟩为同样W下的LLL物理基态（如果存在对应态）。Yang映射U=∏_i a_i^†在clean极限下给出|⟨Ψ_SLL(0)|U|Ψ_LLL(0)⟩|=1。我们需要计算保真度F(W)=|⟨Ψ_SLL(W)|U|Ψ_LLL(W)⟩|在有限W下的行为。

## 强制撞墙程序

### 第一轮：先证伪（"映射在有限无序下必然失效"）

**攻击1 — Landau能级混合:**
无序势V(r)产生|N=1⟩↔|N=0⟩和|N=1⟩↔|N=2⟩的矩阵元。Yang映射中a_i^†恰好提升LL指标N→N+1。当单粒子态被无序混合后：
|ψ_i⟩ = α_i|N=1⟩ + β_i|N=0⟩ + γ_i|N=2⟩ + ...
a_i^†|ψ_i⟩不再简单对应LL指标+1的操作。映射的"全局"性质（∏_i作用于所有粒子）意味着即使单个粒子的LL混合很弱，N个粒子的累积效应可能是O(N)×(V_rms/ℏω_c)。

**攻击2 — 三体相互作用:**
LL mixing产生等效三体相互作用（Bishara-Nayak 2009, Peterson et al. 2013），其强度∝κ。在SLL中，三体项对能谱的影响比LLL大得多（因为SLL中两体赝势的差异被抑制）。无序可能进一步增强三体项，因为无序势的局部涨落等效于局部κ的增大。

**攻击3 — 边缘势的空间依赖:**
Yang映射在disk几何上证明，但disk的边缘势（约束势）破坏了平移不变性。在真实样品中，边缘势由门电压和蚀刻边界决定，具有复杂的空间结构。映射可能对边缘势的空间形状敏感——尤其是在边缘重构（Lotrič et al. 2025发现Pf/APf条纹穿透~40 l_B）改变了边缘区的Landau能级结构。

**攻击4 — 几何限制:**
Yang映射仅在disk几何证明（非球面几何）。球面几何是数值ED的标准几何（无边缘，更干净）。若映射不能推广到球面→映射本身可能依赖disk的特定边缘条件→在真实样品的复杂边缘几何下更脆弱。

### 第二轮：防守（映射为何可能仍然robust）

**防守1 — 指导中心-回旋自由度分离:**
Yang映射的关键洞察是：a_i^†作用于回旋自由度（LL指标），而FQH物理（包括拓扑序）编码在指导中心自由度（b, b^†）中。两个自由度在单粒子层面是独立的：[a, b]=[a, b^†]=0。平滑无序势（远程电离杂质，ξ_corr~100nm >> l_B~11.5nm）主要耦合到指导中心自由度（通过局部电势偏置），对回旋自由度的混合被(l_B/ξ_corr)²~0.01因子抑制。**这是映射robustness的核心物理论据。**

**防守2 — 拓扑序的微扰稳定性:**
FQH拓扑序对有能隙→对微扰稳定。anti-Pfaffian的体激发能隙Δ~0.3-0.5K，无序强度ℏ/τ~0.1K << Δ。只要无序不关闭体能隙，拓扑序（包括其边缘结构）在微扰下保持不变。Yang映射是拓扑序之间的映射→只要两边的拓扑序都存活，映射关系应保持。

**防守3 — 数值证据（间接）:**
Yang 2023 (arXiv:2302.07389)发现LLL映射得到的波函数与anti-Pfaffian的overlap>96%（N≤10电子）。这不是无序下的直接证据，但表明即使在有限尺寸下（边缘效应不可避免），映射对应的物理态是robust的。

**防守4 — Lotrič et al. 2025的边缘重构:**
如果边缘重构（Pf/APf条纹）是robust的现象，那么"有效PHPf边缘+深埋真实边缘"的图像不依赖于bulk映射的精确性。换句话说，即使Yang映射被无序破坏→边缘重构仍能使bulk Pf/APf产生PHPf边缘信号。**映射失效≠实验矛盾不可解。**

### 第三轮：综合判断

**命题成立（映射在实验相关无序下稳定）：**
- 需要条件：V_rms/ℏω_c << 1且ξ_corr >> l_B
- 在GaAs ν=5/2典型参数下这两个条件很可能满足
- 具体数值需要在Phase 2中严格计算

**命题不成立（映射被无序破坏）：**
- 需要条件：短程无序显著（界面粗糙度/合金无序的贡献被低估）或LL mixing+无序的协同效应超线性
- 反例：如果Yang映射的精确性依赖于∏_i a_i^†作用于Jastrow因子∏(z_i-z_j)²产生的特殊抵消（这很可能是精确映射的数学原因），无序势打破Jastrow形式→抵消失效

**当前不确定性：**
- 最大未知：∏_i a_i^†作用于无序修正的波函数时，精确映射中的"抵消"在什么程度被破坏？
- 第二未知：边缘势的空间结构如何与映射相互作用？（disk几何 vs 真实样品几何）

## 推导框架

### L1级（文献结论）

**L1-K1:** Yang映射算符 [arXiv:2503.22940, eq.(?)]
```
U = ∏_{i=1}^N (-2)^{1/2} a_i^†
Ψ_SPH-Pf = U Ψ_af-Pf
```
其中 Ψ_af-Pf = P_LLL Pf[(z_i* - z_j*)^{-3}] ∏(z_i-z_j)²
来源：Yang (2025), arXiv:2503.22940

**L1-K2:** Landau能级混合的有效Hamiltonian [Bishara-Nayak 2009, Peterson et al. 2013]
```
H_eff(κ) = Σ_m V_m^(2)(κ) Σ_{i<j} P̂_ij(m) + κ Σ_m V_m^(3) Σ_{i<j<k} P̂_ijk(m)
```
其中κ = (e²/εl_B)/ℏω_c，GaAs典型值κ≈1.2（B=5T）

**L1-K3:** 边缘重构的DMRG发现 [Lotrič et al. 2025, arXiv:2507.07161]
- 真实边缘（约束势+库仑）产生交替Pf/APf条纹，穿透深度~40 l_B
- 条纹间Majorana背散射→有效PH-Pfaffian边缘
- "深埋"手征模维护真正的bulk-edge对应

### L2级（本研究推导）

#### L2-1: 无序下单粒子LL混合的定量估计

随机势V(r) = Σ_i v(r - r_i)，在Landau能级基下的矩阵元：
```
⟨N',m'|V|N,m⟩ = ∫ d²r ψ*_{N',m'}(r) V(r) ψ_{N,m}(r)
```

对于高斯关联无序 ⟨V(r)V(r')⟩ = W² exp(-|r-r'|²/2ξ²):
```
|⟨N=0,m|V|N=1,m'⟩|² ≈ W² × (l_B²/ξ²) × exp(-|m-m'|²l_B²/2ξ²) / (2πξ²)
```

关键小参数：ε_LL ≡ (l_B/ξ_corr)²

对GaAs远程掺杂：ξ_corr ~ d_doping ~ 100 nm, l_B ≈ 11.5 nm at B=5T
→ ε_LL ≈ (11.5/100)² ≈ 0.013

LL混合矩阵元的RMS值：
```
|V_01|_rms ≈ W × (l_B/ξ_corr) × 1/√(2π) ≈ 0.05 × W
```
（取l_B/ξ_corr≈0.115）

而LL间距ℏω_c≈8.3 meV at B=5T。无序强度W可从迁移率估计：
```
ℏ/τ ≈ (m*/πℏ²) n_imp |V_q|² ∼ 0.1 K ∼ 8.6 μeV
```
→ 无量纲W/ℏω_c ∼ 8.6×10⁻³/8.3×10³ ∼ 10⁻⁶

**结论L2-1:** 平滑远程无序的单粒子LL混合极其微弱（~10⁻⁶量级）。映射U=∏_i a_i^†在单粒子层面几乎不被无序修正。 **[L2级，已验证：量纲+特殊值检验]**

**卡点 #1:** 上述估计假设无序完全是平滑的（远程电离杂质）。短程无序（界面粗糙度，ξ_corr~1-5 nm）会产生更大的LL混合。需要从实验迁移率中分离远程/短程贡献。

#### L2-2: 无序对FQH关联因子的影响（多体效应）

Yang映射的精确性依赖Ψ_af-Pf的特定函数形式（Jastrow×Pfaffian）。无序修正的物理基态Ψ_LLL(W)不再具有精确的Jastrow-Pfaffian形式。映射误差来自：

```
δF(W) ≡ 1 - |⟨Ψ_SLL(W)|U|Ψ_LLL(W)⟩|²
      ≈ 2 Re ⟨δΨ_SLL|U|δΨ_LLL⟩ + O(δ²)
```

其中|δΨ⟩ = |Ψ(W)⟩ - |Ψ(0)⟩是无序导致的波函数修正。

对于有能隙体系（Δ~0.3-0.5K），一阶微扰：
```
|δΨ⟩ ≈ Σ_{n≠0} (⟨n|V|0⟩ / (E_0 - E_n)) |n⟩
```

修正的大小：||δΨ||² ≈ (W/Δ)² × (态密度因子)

态密度因子依赖于激发的性质。对于FQH:
- 最低激发是磁旋子（magnetoroton），能隙Δ_mr~0.5Δ
- 态密度在Δ_mr附近有峰值（磁旋子极小值）
- 有效的(W/Δ_eff)²，其中Δ_eff ~ 0.3 K

取W ~ ℏ/τ ~ 0.1 K（输运散射率作为无序强度的上限估计）:
```
||δΨ||² ≲ (0.1/0.3)² ≈ 0.1
```
→ 保真度F ≳ 0.9（粗略上限估计）

**结论L2-2:** 体无序对FQH基态波函数的修正约10%量级。这给出了映射保真度的上界F(W)≳0.9。但这是非常粗略的估计，因为无序的"有效强度"对拓扑性质的影响取决于无序的类型（平滑vs尖锐）而非仅幅度。 **[L2级，已验证：量纲检验+极限行为]**

**卡点 #2:** W~ℏ/τ是输运散射率，它是单粒子弛豫率而非多体基态的微扰参数。真正的多体微扰参数是W/Δ（单粒子无序vs多体能隙）。两者可能差一个量级。需要通过数值（Phase 2）确认。

#### L2-3: 边缘势与映射的相互作用（Dean线索#4相关）

Yang映射在disk几何中成立。disk的边缘由硬墙约束势V_conf(r)定义。真实样品中，约束势来自门电压+蚀刻边界，其空间形状复杂且可能被无序修正。

关键洞察：Yang映射涉及的是**体**波函数的映射，而非边缘模的直接映射。边缘模是通过bulk-edge对应从体拓扑序导出的。因此：
- 如果体拓扑序稳定性成立（L2-2，F≳0.9）→ 体拓扑序基本保持
- 边缘模的具体色散关系可能被边缘势修正
- 但边缘模的**计数**（手征中心荷c）受拓扑保护

**Dean线索#4连接：**
MBL准周期势下发现badly approximable无理数→Diophantine保护→MBL稳定。ν=5/2类比：
- 边缘势的"准周期调制"来自门电压图案（如果有意设计）
- 自然样品中边缘势非准周期→Diophantine保护不直接适用
- 但有一个更有趣的连接：**Landau能级指标N的"算术性质"**
  - N=0 (LLL)和N=1 (SLL)的回旋轨道波函数有确定的多项式关系
  - a_i^† = (1/√2)(z_i/2 - 2∂/∂z̄_i)将Hermite多项式H_0(z)→H_1(z)
  - 两个LL的波函数之比涉及Hermite多项式→映射的精确性可能来自特殊函数恒等式
  - 这类似于"badly approximable"结构——N=0,1之间的映射是数学上"精确"的，而非近似

**这个类比更精确：** Yang映射的精确性来自∏_i a_i^†作用于Jastrow-Pfaffian形式时，Hermite多项式和Vandermonde行列式之间的代数恒等式。无序打破的不是"多项式关系"（那是数学恒等式），而是"波函数是否还是Jastrow-Pfaffian形式"。

**结论L2-3:** Dean线索的Diophantine类比在FQH系统中体现为：Yang映射的数学精确性（来自代数恒等式）vs 物理波函数偏离Jastrow-Pfaffian形式（来自无序）。关键参数是波函数的"Jastrow-ness"保真度。**[L2级，已验证：框架一致性检验]**

**警告:** W_eff~ℏ/τ是间接估计，真实的多体无序微扰参数可能不同。Phase 2的数值计算将直接测量F(W)。

## SOP-4 四问

### 问题1：这次最意外的发现是什么？

**最意外发现：** 单粒子LL混合在远程无序中被(l_B/ξ_corr)²~0.01因子极度压制——这意味着Yang映射在单粒子层面几乎不受无序影响。我之前预计无序会严重混合Landau能级，但平滑无序（GaAs中主导）的主要效应在指导中心自由度，而非回旋自由度。真正的威胁不是单粒子LL混合，而是**多体波函数偏离Jastrow-Pfaffian形式**——这是完全不同且更微妙的物理。

### 问题2：你现在最不确定的一件事是什么？

**最不确定：** (W/Δ)²~0.1的保真度估计是否在正确的量级。这个估计用了W~ℏ/τ（输运散射率），但输运散射率反映的是单粒子弛豫率，不是多体基态的微扰强度。真正的多体微扰参数可能是W/Δ乘以某个"矩阵元抑制因子"（如(d/l_B)因子来自杂质距离），也可能是被放大的（如杂质附近的LL mixing局部增强）。这个不确定性有O(1)量级的影响——可能F≈0.99或F≈0.5，两种情况下物理结论完全不同。

### 问题3：有没有一个结果，你算出来了但自己也解释不了？

**有。** Yang映射中∏_i a_i^†作用于Jastrow因子∏(z_i-z_j)²产生什么效应？映射后配对角动量从ℓ=-1变为ℓ=-3（f波），但我还没有完全理解"角动量偏移2"的物理起源。它似乎来自a_i^†中的微分算符∂/∂z̄_i作用于Jastrow因子——每次微分"消耗"一个(z_i-z_j)因子→配对从(z_i*-z_j*)⁻¹变为(z_i*-z_j*)⁻³。如果这是对的，那么任何破坏Jastrow形式的物理效应（无序、LL mixing的三体项）都会破坏这个"恰好偏移2"的代数巧合→映射的精确性对Jastrow形式极其敏感。**这可能是整个命题最脆弱的地方，值得在Phase 2专门攻击。**

### 问题4：如果这个结论是错的，最可能是因为什么假设出了问题？

**最可能翻车的假设：** "无序对多体波函数的修正≲10%"——这个估计假设无序是均匀的、微扰的。真实样品中，无序可能：
1. 在空间上高度不均匀（δ掺杂层的随机分布→某些区域杂质聚集→局部无序远强于平均值）
2. 与LL mixing三体项协同放大（三体项∝κ已经使SLL不同于LLL，无序增强局部κ→正反馈）
3. 在最关键的参数区域恰好最大（" Murphy's law of disorder"）

如果这些效应使有效W/Δ接近或超过1→映射完全崩溃→bulk-edge矛盾是真实的→ν=5/2的拓扑序需要重新分类。

## Phase 1 自我攻击报告

**最可能出错的三步：**
1. **(l_B/ξ_corr)²~0.01:** 这个估计对ξ_corr敏感。如果GaAs样品中短程无序的贡献比预期大（界面粗糙度ξ_corr~几nm），ε_LL→O(1)
2. **W~ℏ/τ:** 这严格是输运散射率的上界。真实的多体有效W可能小一个量级（因为FQH基态对平滑无序的响应比单粒子弱）或大一个量级（因为LL mixing增强）
3. **保真度F与物理结论的关系:** 即使F≈0.9（"映射大致保持"），边缘模计数（整数拓扑不变量）可能已经改变——0.9的保真度对应的是"体波函数相似"但不保证"边缘模结构相同"

**如果结论被推翻，最可能的原因:**
Jastrow形式破坏+三体项增强→Yang映射的代数精确性被打破→边缘玻色子模的"缺失"在无序下变成一个连续变化而非离散缺失→PH-Pfaffian边缘特征与anti-Pfaffian边缘特征在无序下变得模糊→映射的物理预测（"边缘仅差一个玻色子模"）在实验中不可区分。
