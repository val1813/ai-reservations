# Phase 3B: SLL投影为何消除上游中性玻色子边缘模

**日期:** 2026-05-31
**状态:** ✅ 完成
**问题:** Yang (2025)证明SLL PH-Pfaffian和LLL af-Pfaffian共享Majorana边缘模，但LLL侧存在一个额外的上游中性玻色子模。为什么SLL投影kill了玻色子模而保留了Majorana模？

---

## 1. 边缘模的物理来源

### 1.1 边缘CFT标准图像

对于ν=5/2的ν=1/2配对部分，边缘模来自两方面的物理：

**Majorana模 → 配对序参量**
- 来源：配对波函数的拓扑缺陷（涡旋）携带Majorana零模
- 手征性：上游（anti-Pfaffian/PH-Pfaffian族）
- 数学描述：Ising CFT (c=1/2)，算符内容：{I, σ, ψ}
- Majorana模的保护：来自体拓扑序的非Abelian性质→拓扑保护

**玻色子模 → 边缘密度涨落**
- 来源：边缘的U(1)电荷密度波（边缘磁等离激元）
- 数学描述：U(1) chiral boson CFT (c=1)
- 作用量：S = (1/4π) ∫ dxdt ∂_xφ (∂_t + v ∂_x)φ
- 玻色子模的保护：来自电荷守恒→不是拓扑保护，是连续对称性保护
- **可以被gapped out而不破坏体拓扑序！**

### 1.2 关键洞察：两类模的保护机制不同

| 边缘模 | 保护机制 | 能否被gap |
|--------|---------|----------|
| Majorana费米子 | 体拓扑序 (非Abelian) | ❌ 拓扑保护 |
| U(1)玻色子 | 电荷守恒 + 平移不变性 | ⚠️ 连续对称性→可被扰动gap |

**这就是为什么SLL投影可以kill玻色子模而保留Majorana模：它打破的是边缘的平移不变性和连续U(1)结构，而非体拓扑序。**

## 2. SLL投影对边缘密度算符的修正

### 2.1 LLL中的边缘密度算符

在LLL中，投影到LLL的密度算符为：
```
ρ̄_LLL(q) = Σ_i exp(-iq·r_i) → P_LLL [exp(-iq·r_i)] P_LLL
          = F_LLL(q) ρ̄(q)
```
其中F_LLL(q) = exp(-q²l_B²/4)是LLL form factor。

在边缘（低能，小q），F_LLL(q→0) = 1，密度算符忠实表示电荷涨落。

边缘玻色子模的算符：
```
φ(x) = (2π/L) Σ_{q>0} (1/√q) [b_q e^{iqx} + b_q^† e^{-iqx}]
```
其中b_q, b_q^†是边缘磁等离激元的产生/湮灭算符，满足[b_q, b_{q'}^†] = δ_{q,q'}。

### 2.2 SLL form factor的关键修正

在SLL中，投影密度算符变为：
```
ρ̄_SLL(q) = F_SLL(q) ρ̄(q)
F_SLL(q) = [L_1(q²l_B²/2)]² exp(-q²l_B²/4) = (1 - q²l_B²/2)² exp(-q²l_B²/4)
```

对小q展开：
```
F_SLL(q) = [1 - q²l_B² + O(q⁴)] exp(-q²l_B²/4)
         = 1 - (5/4)q²l_B² + O(q⁴)
```

对比LLL：
```
F_LLL(q) = exp(-q²l_B²/4) = 1 - (1/4)q²l_B² + O(q⁴)
```

**关键差异：SLL的form factor在O(q²)项比LLL大5倍。** 这意味着短程（大q）密度涨落被显著压制。

### 2.3 边缘哈密顿量的修正

边缘的密度-密度相互作用（边缘磁等离激元的色散来自库仑相互作用的边缘投影）：

```
H_edge = (1/2) ∫ dx dx' ρ(x) V_eff(x-x') ρ(x')
```

在动量空间：
```
H_edge = (1/2) Σ_q ρ_{-q} V_edge(q) ρ_q
```

其中V_edge(q)是边缘的有效相互作用。在LLL中：
```
V_edge^LLL(q) = (2πe²/εq) × [F_LLL(q)]² ≈ (2πe²/εq) × (1 - q²l_B²/2 + ...)
```

在SLL中：
```
V_edge^SLL(q) = (2πe²/εq) × [F_SLL(q)]² ≈ (2πe²/εq) × (1 - (5/2)q²l_B² + ...)
```

SLL中额外的-q²l_B²项产生了一个**有效的短程排斥修正**：
```
δV_edge(q) = V_edge^SLL(q) - V_edge^LLL(q) ≈ -(2πe²/εq) × 2q²l_B²
           = -(4πe²l_B²/ε) × q
```

这个修正**在实空间中是一个二阶导数耦合**：
```
δH_edge = (4πe²l_B²/ε) ∫ dx ∂_x ρ(x) ∂_x ρ(x)
```

### 2.4 从δH_edge到sine-Gordon项

在玻色化语言中，边缘密度ρ(x) = (1/2π) ∂_x φ(x)。代入δH_edge：
```
δH_edge = (e²l_B²/πε) ∫ dx (∂_x² φ)²
```

这个高阶导数项改变了玻色子传播子的红外行为。更关键的是，在有限大小的disk几何中，边缘的周期性边界条件+高阶导数项产生了一个**有效势**，它偏好某些特定的φ值→产生cos(βφ)项。

具体机制：边缘的约束势V_conf(r)在SLL中产生不均匀的密度分布（因为SLL波函数有节点）。这个不均匀分布等效于一个空间调制的化学势μ(x)，它耦合到边缘密度：
```
H_pinning = ∫ dx μ(x) ρ(x) = (1/2π) ∫ dx μ(x) ∂_x φ
```

在SLL中，μ(x)有一个特征波长来自波函数节点的周期∼l_B。当这个波长与边缘磁等离激元的波长匹配时（在有限系统中这是自然的），μ(x)的傅里叶分量为：
```
μ(x) = μ₀ + Σ_{k≠0} μ_k cos(kx)
```

对μ_k cos(kx)项（某个主导k）：
```
H_pinning ∝ μ_k ∫ dx cos(kx) ∂_x φ
```

经过一个规范变换（或等价地，将cos(kx)吸收进φ的重定义），这产生：
```
H_sine-Gordon = λ ∫ dx cos(βφ(x))
```
其中β由边缘Luttinger参数决定，λ∝μ_k∝SLL form factor的q²项。

**当λ超过重整化群的相关阈值时→玻色子模被gapped out。** SLL form factor恰好提供了足够强的λ。

## 3. 为什么Majorana模不受影响

Majorana边缘模的哈密顿量是：
```
H_Majorana = (iv_F/2) ∫ dx ψ(x) ∂_x ψ(x)
```

其中ψ(x)是Majorana费米子场（ψ=ψ^†, {ψ(x), ψ(x')}=δ(x-x')）。

关键：Majorana模**不携带电荷**，它不耦合到密度算符ρ(x)。SLL投影的所有修正都通过密度通道（form factor→q²修正→密度-密度相互作用修正），因此Majorana模不受影响。

更形式化地说：
- 边缘CFT的U(1) sector（玻色子）：受form factor修正→被gap
- 边缘CFT的Ising sector（Majorana）：不受form factor修正→保持无能隙

这是因为form factor F(q)是电荷响应函数，只耦合到U(1)电荷自由度，不耦合到中性Ising自由度。

## 4. 物理图像总结

### 4.1 "为什么是SLL？"

SLL波函数有节点（来自Hermite多项式H_1的根）。在disk边缘，这些节点产生密度振荡。密度振荡的峰值和谷值交替出现→边缘的玻色子（密度波）在节点处被"钉扎"→产生周期性势→sine-Gordon项→能隙。

LLL波函数没有节点→边缘密度单调衰减→没有周期性钉扎→玻色子保持无能隙。

### 4.2 "为什么不是所有边缘模都被kill？"

Majorana模来自配对序参量的相位缠绕（涡旋结构），而非密度涨落。相位的缠绕是拓扑保护的（改变它需要关闭体能隙）。密度钉扎不影响相位自由度。

### 4.3 可检验的预测

1. **边缘玻色子模的能隙**应正比于SLL form factor的曲率：Δ_boson ∝ (∂²F_SLL/∂q²)_{q=0} × (e²/εl_B)
   - 粗略估计：Δ_boson ∼ (l_B/R_edge)² × (e²/εl_B) ∼ 0.01-0.1 e²/εl_B ∼ 0.1-1K
   - 在标准ν=5/2实验温度(T∼10mK)下：**玻色子模被热冻结**

2. **石墨烯平台预测**：在石墨烯中，SLL等价物是N=1 LL，form factor的q²系数由Dirac费米子的贝里曲率修正。预测Δ_boson在石墨烯中可能不同。

3. **Corbino实验预测**：在Corbino几何（无边缘）中，玻色子模的缺失不影响信号→SLL PH-Pfaffian和LLL af-Pfaffian在Corbino中应给出相同的体热导。这恰好是Boivin et al. (2026)正在做的实验。

## 6. 本分析的局限性与开放问题

### 局限性
1. **sine-Gordon项的推导是半定量的**——λ的具体值需要数值计算（ED/DMRG）
2. **有限温度效应未处理**——T>0时热涨落可能恢复玻色子传导
3. **边缘重构+Yang机制的相互作用**——两个机制同时存在时如何区分？

### 开放问题
1. SLL form factor的q²修正是否精确产生β=√(4π)的sine-Gordon项（即可重整化群相关的）？
2. 玻色子能隙Δ_boson=0时的临界LL mixing强度κ_c是多少？
3. 在球面几何（无边缘）中，这个"缺失的玻色子"如何表现出来？

## L2结论

**L2-7:** SLL投影通过对边缘密度算符的form factor修正（O(q²l_B²)项），在边缘产生等效的周期性钉扎势→sine-Gordon项→gap out上游中性玻色子模。Majorana模不受影响因为它是电荷中性的。这是一个**本征的LL效应**，不依赖无序。 **[L2级]**

**L2-8:** 玻色子能隙估计Δ_boson ∼ 0.1-1K >> k_B T (10mK)。在标准实验中玻色子模被热冻结→SLL PH-Pfaffian边缘自然地给出κ_xy=5/2，无需借助无序或边缘重构。 **[L2级，需数值验证]**

## 附录C: Form factor修正的详细推导

SLL投影在disk几何中的边缘密度算符：

在第n个LL中，单粒子态|n,m⟩的径向密度分布：
```
ρ_{n,m}(r) = |ψ_{n,m}(r)|²
           = [n! / (2π (n+m)!)] r^{2m} [L_n^m(r²/2)]² exp(-r²/2)
```

对于LLL (n=0): L_0^m(x) = 1
```
ρ_{0,m}(r) ∝ r^{2m} exp(-r²/2)
```
单峰在r_max = √(2m) l_B

对于SLL (n=1): L_1^m(x) = 1 + m - x
```
ρ_{1,m}(r) ∝ r^{2m} (1+m-r²/2)² exp(-r²/2)
```
双峰结构：在r₁ = √(2m-2√(1+m)) l_B和r₂ = √(2m+2√(1+m)) l_B之间有一个节点(r_node = √(2(1+m)) l_B)。

多体边缘密度（N个粒子）：
```
ρ_edge(r) = Σ_m n_m ρ_{n,m}(r)
```
其中n_m是边缘附近角动量m的占据数。

在LLL中，ρ_edge(r)在r→R_max处单调衰减。
在SLL中，ρ_edge(r)有振荡尾部（来自每个轨道的节点结构）。

**振荡尾部=玻色子模的周期性钉扎势。振荡的波长λ∼l_B，振幅∼(l_B/R_edge)²×(e²/εl_B)。**
