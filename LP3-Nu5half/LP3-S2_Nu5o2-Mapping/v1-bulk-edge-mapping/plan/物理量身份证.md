# 物理量身份证 — LP3-S2

## 核心物理量

### 1. 映射保真度 F(W)
- **定义:** SLL PH-Pfaffian波函数与LLL anti-Pfaffian波函数在有限无序W下的重叠积分（经Landau能级投影后）
- **取值范围:** F(W)=1（clean极限精确映射）→F(W)→0（强无序下映射完全失效）
- **与可观测量关系:** F(W)与纠缠谱的能级劈裂有关 → 可间接约束

### 2. 无序强度 W
- **定义:** 随机势V(r)的RMS涨落，单位e²/εl_B
- **典型值:** GaAs ν=5/2样品中W~0.01-0.05 e²/εl_B（从迁移率反推）
- **无量纲化:** W̃ = W/Δ，Δ为ν=5/2的输运能隙~0.3-0.5K~0.01-0.02 e²/εl_B

### 3. Landau能级混合参数 κ
- **定义:** κ = (e²/εl_B)/ℏω_c = (Coulomb能)/(回旋能)
- **GaAs典型值:** κ~0.5-1.0
- **与映射关系:** LLM产生N=0↔N=1混合→映射在clean极限的精确性可能已被LLM修正

### 4. 边缘玻色子模能隙 Δ_boson(V_edge)
- **定义:** 边缘势V_edge对玻色子边缘模诱导的有效能隙
- **关键问题:** Δ_boson(V_edge)是否大于实验温度k_B T~10mK~1μeV？

### 5. 纠缠谱能级间距 δξ
- **定义:** 最低两个纠缠能级的间距（在cut已取好的情况下）
- **与映射关系:** δξ(W)-δξ(0)衡量无序对拓扑序的微扰
