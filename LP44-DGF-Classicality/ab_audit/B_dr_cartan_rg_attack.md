## 攻击1: QFT/RG理论 -- "渐近自由"类比是灾难性的概念混淆

### 1.1 DGF与QCD渐近自由在UV/IR方向上恰好相反 (致命)

**QCD渐近自由 (Gross-Wilczek-Politzer 1973):**

QCD的β函数在弱耦合极限为:
```
β(g) = -β₀ g³/(16π²) + O(g⁵)    β₀ = 11 - 2Nf/3 > 0
```
关键特征:
- β(g) < 0 在 g → 0+ 附近
- 这意味着 g 随能量标度 μ 的增大而**减小**
- UV极限 (μ→∞): g→0 (自由夸克和胶子)
- IR极限 (μ→Λ_QCD): g→∞ (禁闭, 强耦合)
- 这是 **UV固定点在 g=0 (平凡), IR方向流向强耦合**

**DGF声称 (uv_ir_cartan_flow.md:64-65):**
> "β(c)在c=π/2处为负(IR-unstable)"
> "β(c)>0近c=0→c随尺度增大而增大"

DGF描述的场景:
- β(c) > 0 在 c ≈ 0 附近
- 这意味着 c 随粗粒化尺度增大而**增大**
- UV极限 (微观): c ≈ 0 (弱耦合)
- IR极限 (宏观): c ≈ O(1) (强耦合)
- 声称"和QFT的渐近自由类比"

**致命矛盾:**

QCD渐近自由的关键是: **UV有平凡固定点 (g=0), 流向IR强耦合。** 如果DGF声称β(c)>0近c=0, 这意味着c=0是**IR-repulsive** (朝IR方向增长c) — 即c=0是**UV固定点** (朝UV方向流向c=0)。

对比:
| 理论 | UV固定点 | UV行为 | IR方向 | IR行为 |
|------|---------|--------|--------|--------|
| QCD渐近自由 | g=0 | β<0, g→0朝UV | g增大 | 禁闭 |
| DGF声称 | c≈0 (?) | β>0, c→0朝UV | c增大 | 经典性 |
| φ⁴标量场 (d<4) | g=0 | β>0 (IR attracting) | g→0 (平凡) | 非相互作用 |

**DGF的c≈0更像是φ⁴理论在d<4时的行为 (平凡的高斯固定点, 向IR流向自由理论) 而非QCD的渐近自由。但DGF声称c向IR增长到O(1) — 这与"UV固定点在c=0"矛盾: 如果c=0是UV固定点, c应该向IR减小(流向IR吸引子), 而非增大。**

实际上, DGF的声明是:
- β(c) > 0 在 c < π/4 (向IR, c增大 → 流向 π/4)
- β(c) < 0 在 c > π/4 (向IR, c减小 → 流向 π/4)

这意味着c=π/4是**IR吸引子固定点**, c=0和c=π/2是**IR排斥子**。这个流向在UV方向: 从π/4出发, 反向积分→c流向0或π/2。即c=0和c=π/2是**UV固定点**。

这与QCD的类比完全断裂:
- QCD: 一个UV固定点(g=0), 一个IR流向(强耦合)
- DGF: 两个UV固定点(c=0和c=π/2), 一个IR吸引子(c=π/4)

**这是完全不同的RG固定点结构。** 声称"和QFT的渐近自由类比"是对RG理论基本概念的错误使用。

**评分: 0 (致命)**

### 1.2 β(c)函数从未被计算 — 连函数形式都没写出来 (致命)

**QFT中的β函数计算:**

在QFT中, β函数通过微扰论逐阶计算。以QED为例:
```
β(e) = e³/(12π²) + e⁵/(32π⁴) + ...   (微扰论, 2阶+4阶)
```
这需要:
1. 一个可微扰的拉氏量/作用量
2. 正规化方案 (如MS-bar, 动量截断)
3. 重整化条件
4. 费曼图计算

**DGF中β(c)的状况:**

`intermediate_layer.md`写了一行方程式:
```
dc_eff/d(ln N) = β(c_eff)
```

然后给出了β(c)的符号分区:
```
β(c) < 0 for c > π/4
β(c) > 0 for c < π/4
c = π/4: 临界点(β=0?)
```

**但这只是手绘的符号草图, 不是计算。** 没有任何一行DGF代码计算过β(c)。`rg_flow_v2.py`中Cartan参数在RG blocking下的行为是通过简单平均 (merging edges, 取c的算术平均) 得到的 — 这不是β函数的数值测定, 这是对原始数据的降采样。

**β(c)函数形式未给出的后果:**

1. 不知道β(c)在c≈0附近的首项: 是β(c) ~ c (线性)? β(c) ~ c² (平方)? β(c) ~ -c log c (对数)? 这决定c=0是超IR-repulsive还是对数级别的。
2. 不知道β(c)在c≈π/4附近的行为: 是β(c) ≈ β'(π/4)·(c-π/4) + ...? 临界指数ν = 1/β'(π/4)决定了RG流接近固定点的速率。
3. 没有临界指数 → 无法计算关联长度标度 → 无法预测宏观上"经典性"在什么尺度上出现。

**对比: 即使是Kondo问题 (1970年代的poor man's scaling), β函数的一阶计算也是明确写出来的:**
```
β(J) = -ρ₀ J² + O(J³)
```
其中J是局域磁矩和传导电子的交换耦合, ρ₀是态密度。这个一阶计算决定了T_K = D exp(-1/ρ₀J₀) — Kondo温度 — 即微扰论失效的标度。

DGF连β(c)的首项都没有写出来。声称有RG流但没有β函数, 就像声称有运动定律但没有运动方程。

**评分: 0 (致命)**

### 1.4 RG变换不具备半群性质 — 所谓的"blocking"只是降采样 (致命)

**真正RG变换的数学要求:**

Wilson-Kadanoff RG必须满足半群性质:
```
R_{s1} ∘ R_{s2} = R_{s1+s2}
```
即连续两次RG变换 (积分掉高动量模 s1 再积分 s2) 等价于一次积分 (s1+s2)。这要求:
1. 存在一个 scale-dependent 有效作用量 S_Λ[φ]
2. RG变换通过泛函积分定义: e^{-S_{Λ'}} = ∫ Dφ_{fast} e^{-S_Λ}
3. 作用量空间中的流满足自治方程 (Polchinski/Wetterich方程)

**DGF的"RG blocking"做什么:**

```python
# rg_flow_v2.py: block_spatial函数
def block_spatial(edges, L, d=2, block_L=2):
    # 将 block_L^d 节点合并为一个有效节点
    # 有效边: 原始边连接两个不同block → 保留
    # 有效Cartan参数: 合并边的Cartan参数取算术平均
    merged_edges.append((u, v, np.mean(c_list)))
```

```python
# rg_flow.py: rg_block函数
def rg_block(graph, block=2):
    # ln q_eff = <ln q>_block (对数空间的算术平均)
    ln_q_avg = np.mean([np.log(max(qi, 1e-15)) for qi in qs])
    ng.q[b] = np.exp(ln_q_avg)
```

**这两种操作都不构成真正的RG变换:**

**(a) Cartan参数平均不是RG流:**

取Cartan参数的算术平均等价于说: "新有效边的Cartan参数 = 组成边的Cartan参数均值"。这个规则是**武断的** (ad hoc), 不是从任何微观动力学推导出来的。

在真正的RG中, 有效耦合是通过积分掉高动量模**计算**出来的, 不是通过平均原始耦合得到的。举个简单例子: 2D Ising模型的RG变换给出 K' = (1/2) ln cosh(2K), 其中K=J/kT是约化耦合。这个公式是通过精确的部分迹 (partial trace) 推导的, 不是通过平均相邻自旋的J值得到的。DGF对Cartan参数的平均等价于说 K' = ⟨K⟩_block — 这根本不是RG, 是数据平滑。

**(b) ln q取几何平均映射到exp(-Φ/c²)是循环:**

`rg_flow.py` 的 `rg_block` 函数已经**预设**了 q = exp(-M/r) (通过 `insert_mass` 手动设置)。然后在RG blocking中取 ln q 的算术平均 → 等价于取 q 的几何平均。验证 "ln q可加性" 只是确认了: 如果你预设 q 是 exp 形式, 那么在几何平均下它自然是可加的。这不是推导, 这是数学等价性检查 (INSPECTOR I-1已指出)。

**(c) 没有有效作用量:**

真正的RG跟踪的是**有效作用量** (或有效哈密顿量) 随标度的演化。在固定点, 有效作用量具有标度不变性。DGF在整个RG blocking中不计算任何作用量 — 它直接操作 q 值和 c 值。缺少作用量意味着:
- 无法判断系统是否在固定点附近
- 无法计算相关算符 (relevant/irrelevant operators)
- 无法确定普适类
- "RG流"退化为数据压缩, 不是物理演化

**(d) 半群性质未验证:**

如果取平均c是RG变换, 那么将 (2×2)×2 合并应该等价于一次性 4×4 合并。这个性质从未被验证 — 而且取算术平均不满足严格的半群性质 (除非底层耦合分布有特殊结构)。

**评分: 0 (致命)**

### 1.5 RG流动的方向与DGF两时间结构不兼容 (严重)

**问题:** 如果c在RG下流动 (假设它确实流动), c的值决定了退相干率 μ(c) 和有效信息产生率 Γ_eff(c)。那么:
- 在微观 (UV): c ≈ 0 或 c ≈ π/2 → μ(c) ≈ 0 → 几乎没有退相干
- 在宏观 (IR): c → π/4 → μ(c) 取极大值 → 最大退相干

这与DGF的两时间故事矛盾:
- DGF的两时间结构认为宏观经典性来自于 **b1 ∝ N (环数巨大)**
- 但退相干放大器 (Wall #9) 的机制是: D_global = 1 - [cos²(4c)]^{b1}
- 如果c在微观近Clifford (cos(4c) ≈ cos(2π) = 1), 即使b1=10^80, D_global ≈ 1-1^{10^80} = 0 → 无退相干
- 所以宏观退相干需要c**不在**Clifford附近

如果RG流将c从0或π/2推向π/4, 那么退相干确实在宏观尺度增强。但:

**矛盾在于:**
1. `classicality_mechanism.md` 明确说c不流动
2. `decoherence_amplifier.md` 的机制 (b1×μ) 在c不流动时仍能产生宏观退相干 (只要c的分布不全在Clifford点)
3. 所以RG流既不被数据支持, 也不被需要 — 它是个冗余假设

**但如果c确实流动:**
RG流的时间尺度是什么? 每个RG步需要多少物理时间? 如果RG流比宇宙学时间慢, 那么当前宇宙的c_eff分布应该仍然接近微观分布 — 退相干并未被RG放大。DGF从未计算RG流的时间尺度。

**评分: 1 (严重)**

### 1.6 无控制参数展开 — 微扰论不存在 (严重)

**QFT中RG可行的前提:**

微扰RG需要一个小参数 (弱耦合, 1/N展开, ε-expansion around d=4)。例如:
- QCD: 渐近自由在高能标 → 小g → 微扰论收敛
- 非线性σ模型: 2+ε expansion → ε = d-2 是小参数
- 大N展开: 1/N → 非微扰但可解

**DGF的扩张参数是什么?**

DGF的因果图没有明显的微扰展开参数:
- N (节点数) 很大 → 但大N极限不是系统的, 没有1/N展开的拓扑分类
- c 小? → c≈0是DGF声称的一个固定点, 但c的范围是[0, π], 没有理由认为小c是微扰区域
- 图是稀疏的? → 度~O(1), 不是小参数

**没有小参数 → 无法做微扰RG → β函数的任何"计算"都只能在数值上进行, 且受限于有限尺寸效应。**

DGF唯一可做的"RG"是在有限大小的格点上做数值blocking, 然后外推到无穷大。但当前数值:
- L=32 (rg_flow_v2.py): N=1024节点, 仅3-4个blocking层级
- L=10 (rg_flow.py): N=1000节点, 仅2个blocking层级
- 两者都远不足以建立标度行为 (INSPECTOR I-3, I-9)

**评分: 1 (严重)**

## 攻击2: 凝聚态物理 -- DGF的"RG"与已知强关联RG无结构相似性

### 2.1 简单平均不是RG — 对比Kondo的poor man's scaling (致命)

**Kondo问题的poor man's scaling (Anderson 1970):**

在Kondo效应中, 局域磁矩与传导电子的反铁磁交换耦合J的RG方程为:
```
dJ/d(ln D) = -ρ₀ J²
```
其中D是电子带宽的截断, ρ₀是费米面的态密度。这个方程的由来:

1. 从Anderson杂质模型 (微观哈密顿量) 出发
2. 将传导电子分为"快" (能量∈[D-δD, D]) 和"慢" (能量< D-δD)
3. 对快电子做二阶微扰, 积分掉它们
4. 得到重整化的 J_eff = J + ρ₀J² δD/D
5. 取δD→0得到微分方程

**DGF的RG blocking (rg_flow_v2.py:113-147):**

```python
def block_spatial(edges, L, d=2, block_L=2):
    for u, v, c in edges:
        bu, bv = block_idx(...), block_idx(...)
        if bu != bv:
            block_edges.append((bu, bv, c))
    # 对每个有效边的c取算术平均
    for (u, v), c_list in edge_dict.items():
        merged_edges.append((u, v, np.mean(c_list)))
```

**关键差异:**

| 维度 | Kondo poor man's scaling | DGF Cartan "RG" |
|------|--------------------------|-----------------|
| 微观哈密顿量 | Anderson模型, 明确写出 | 无 — 因果图静态 |
| 快/慢模分离 | 能量截断 D-δD < E < D | 空间坐标分块 (2×2 block) |
| 积分过程 | 二阶微扰, 费曼图 | 算术平均 `np.mean(c_list)` |
| 微分方程 | dJ/d(ln D) = -ρ₀J² | 未写出一阶微分方程 |
| 重正化来源 | 量子涨落 (快电子虚过程) | 无量子涨落 — 经典图论操作 |
| 可解极限 | ρ₀J → 0 (弱耦合) | 无小参数 |

**根本问题:**

DGF的blocking操作没有物理驱动力。在Kondo问题中, J重正化的原因是: 快电子虚跃迁改变了局域磁矩和慢电子的有效相互作用。这些虚跃迁是微观哈密顿量自然包含的量子涨落。在DGF中, 因果图是**静态结构** — 没有哈密顿量, 没有量子涨落, blocking只是空间坐标上的像素化。

**把 Cartan 参数的平均称为"RG流"就像把统计学的分组平均称为"场论" — 范畴错误。**

**评分: 0 (致命)**

### 2.2 无序系统的RG — Fisher的无限随机性固定点与DGF对比 (致命)

**Fisher (1994, PRB 50, 3799) 的无序横场Ising链RG:**

在随机横场Ising链中, RG变换是:
1. 找最大的能量标度 (最强的键 或 最强的场)
2. 消除对应的自由度 (自旋对结合成有效自旋, 或在强场下冻结)
3. 计算剩余键和场的有效值 (微扰计算, 非简单平均)
4. 重复 → 流向"无限随机性"固定点

在无限随机性固定点:
- 耦合常数的分布变得越来越宽 (对数方差→∞)
- 标度行为不是指数律, 而是活化标度: ln(1/ΔE) ~ L^ψ
- 普适类取决于对称性和无序类型

**DGF的无序性在哪里?**

DGF的因果图中Cartan参数有分布 (c_mean=0.5, c_std=0.2, rg_flow_v2.py第15行)。这是一个类似"无序"的初始条件。但DGF的RG通过平均**缩小**了分布宽度:
- 初始: c_std ~ 0.2
- Blocking后: c分布被平均 → 中心极限定理 → 有效c的方差减小 ~1/√N

这与Fisher的无限随机性固定点**方向相反** — 真正的无序系统RG通常**放大**无序 (分布变宽), 而DGF的平均操作**缩小**无序 (分布变窄)。

```
总信息率 ~ 0.045 × 10^43 × 10^80 ≈ 5×10^121 bits/s
```
这个速率意味着在Planck时间 (10^{-43} s) 内就完成了~10^78 bits的处理 — 在宇宙的**第一个时刻**就已经用掉了总量的大部分。但在~10^{60}个Planck时间的宇宙历史中, 持续的速率是 5×10^121 bits/s, 总量将达到~10^181 bits — 这是Lloyd界的10^61倍。

**这不只是18个数量级的问题 — 是在每个维度上都超出了合理范围。**

**评分: 1 (严重)**

### 4.4 "RG粗粒化解"隐藏了更大的问题 (严重)

**uv_ir_cartan_flow.md:46-50的"解":**
> "用b1_eff ~ 10^30: 总信息率 ~ 5×10^71 bits/s < Bremermann界 ✓"

**隐藏的假设:**

这个"解"假设了b1_eff 可以通过RG缩减因子从10^80降到10^30 — 即缩减了50个数量级。但:

1. **RG缩减因子从何而来?** 不是从DGF模拟中提取的 — 是选的。如果要从DGF第一原理推导, 需要展示因果图RG流如何将b1从10^80 (Planck) 降到10^30 (宏观有效)。当前模拟只有N=1000→8, b1=8001→17, 缩减因子~500, 远不及需要的10^50。

2. **缩减的方向对吗?** RG粗粒化后b1应该减小 (环被blocking合并)。但DGF的宏观经典性需要**足够大的b1** 来驱动D_global→1。如果RG把b1从10^80压到10^30, 那D_global = 1 - [cos²(4c)]^{b1_eff} 还能趋近1吗? 需要检查: 对于c=0.5, cos(4c) = cos(2) ≈ -0.416, cos²≈0.173, (0.173)^{10^30} ≈ 0 (确实趋近0) — D_global ≈ 1。所以退相干仍有效。但这里的c=0.5是特例 — 如果c在RG下也流动, 事情更复杂。

3. **b1_eff 10^30 从哪里来?** "每粒子环数~O(1)" + "宏观有效粒子数~10^30"? 但宇宙粒子数是10^80, 不是10^30。10^30对应的是什么 — 可观测宇宙的星系数量 (~10^11) × 每星系的恒星数 (~10^11) = 10^22 — 仍不对。10^30更像是**退相干所需的最小b1**的逆向估计 (使得[cos²(4×0.5)]^{b1}≪1) 而非从DGF物理算出的值。

**评分: 1 (严重)**

## 根本诊断: DGF的Cartan RG流的解剖

### 三重灾难

**1. 内部矛盾 (Self-Contradiction):**

DGF内部至少有4个互相排斥的RG叙事:
- `intermediate_layer.md`: Cartan RG流有固定点 (β函数符号分区)
- `uv_ir_cartan_flow.md`: Cartan RG流驱动c从π/2偏离 (IR-unstable)
- `classicality_mechanism.md`: 不流动, 经典性另有来源 (Wall #9)
- `rg_flow_v2.py`: 数据无清晰流向

这些文档同一天写的 (2026-06-10), 但得出了彼此排斥的结论。作者尚未决定DGF到底是RG故事还是非RG故事。

**2. 概念混淆 (Category Error):**

把 Kadanoff blocking (空间几何降采样) 当作 Wilsonian RG (泛函积分重正化) 是范畴错误。两者仅共享"粗粒化"的直觉, 但数学结构完全不同:
- Wilsonian RG: 有效作用量 �(φ, Λ) 满足 Polchinski 方程, 固定点是共形场论
- DGF "RG": 对Cartan参数取均值 + 对纯度取几何均值, 固定点未定义

**3. 物理缺失 (Missing Physics):**

- 无哈密顿量 → Bremermann界不适用, RG无能量截断
- 无作用量 → 不是量子引力, 只是几何图
- 无微扰展开 → β函数不可计算
- 无已知文献对接 → 孤立体系, 无普适类归属

### 给作者的挑战

如果DGF的Cartan RG流要存活, 请在不引入新假设的情况下:

1. **写出β(c)的首项** — 从DGF的第一原理（因果图+Cartan参数+退相干规则）计算β(c)在c→0, c→π/4, c→π/2附近的领头阶。给出具体幂次。

2. **统一四个文档的RG流方向** — 选定一个 (或废掉三个), 解释为什么矛盾的结论曾同时存在。

3. **展示RG变换的半群性质** — 证明 2×2 block 两次等价于 4×4 block 一次。如果不满足, 承认这不是RG。

4. **从因果图微观动力学推导 λ (等效牛顿常数)** — 不预设 exp(-M/r), 不手动标定G, 展示 λ 如何从 ℓ_P, Γ₀, η₀ 等DGF微观参数中出现。

5. **计算CDT-like谱维度流** — d_s(σ)的短距离 (σ→0) 和长距离 (σ→∞) 限, 并与已知量子引力预言的 d_s(UV)≈2, d_s(IR)≈4 比较。

6. **定义因果图的哈密顿量或作用量** — 使得Bremermann界的使用有意义, 且RG blocking有微观动力学基础。

7. **与至少一个凝聚态RG系统 (Kondo, MBL, 无序横场Ising) 建立定量映射** — 展示DGF的RG在什么极限下还原已知系统的标度行为。
