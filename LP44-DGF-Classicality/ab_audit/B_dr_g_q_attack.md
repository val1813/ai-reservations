## A1 [内部一致性 - 0: 致命] 三个文件,三个互斥的g(q)函数形式

### 证据

```python
# g_q_bump.py: g(q) = g_floor + A*q*(1-q)
g_bump = 0.93 + 3.0 * q * (1.0 - q)    # 5参数, 抛物线+地板

# g_q_derivation.py: g(q) = q / q_today
g_linear = q / 0.9425                    # 3参数, 纯线性

# two_time_cosmic_history.py: g(q) = 4*g_max*q*(1-q)
g_parabola = 4.0 * q * (1.0 - q)        # 2参数, 纯抛物线(过原点)
```

### 定量矛盾

| q值 | g_bump | g_linear | g_parabola | 最大/最小比 |
|-----|--------|----------|------------|------------|
| 0.01 (早期) | 0.960 | 0.011 | 0.040 | **90x** |
| 0.50 (峰值) | 1.680 | 0.531 | 1.000 | **3.2x** |
| 0.94 (今天) | 1.099 | 0.997 | 0.226 | **4.9x** |
| 0.99 (未来) | 0.960 | 1.050 | 0.040 | **26x** |

### 攻击推理

三个文件声称从"第一原理"推导g(q),但给出三个互斥的函数形式:

- **g_q_derivation.py** 声称 `g(q) = g0 * q` 是从"因果事件率 ∝ 退相干率"推导的,得线性关系
- **two_time_cosmic_history.py** 声称 `g(q) ∝ q(1-q)` 是从"退相干率 ∝ QCMI ∝ q(1-q)"推导的,得对称抛物线
- **g_q_bump.py** 把两者混合成 `g(q) = g_floor + A*q*(1-q)`,引入无推导的g_floor

**这三个形式在物理上无法同时为真。** 在q=0.01(早期宇宙),它们的g(q)值差了90倍,对应H(z)预测差90倍。这不是"近似"——这是**根本不同的物理模型**。

g_q_bump.py引入g_floor的唯一理由是**正则化**: g→0时H_meas→∞的数学发散需要手工截断。g_floor没有从任何第一原理推导,它就是一个ad-hoc帽子。它的物理解释("不可约因果事件率,真空+热涨落")没有方程支撑,没有数量级估计——就是一个数(0.93)被拟合出来使最后一行看起来好看。

**结论: DGF团队自己都不知道g(q)应该是什么函数形式。** 这是理论尚未成型的标志——不是"待修正",是"不存在"。

## A7 [引力/修正引力 - 0: 致命] Jacobson(1995)推导被两时间结构破坏

### 攻击推理

Jacobson(1995)推导Einstein方程的关键步骤:

1. 在Rindler视界上,Unruh温度 T = ħκ/(2π),其中 κ = 表面引力 = a (在local Rindler frame中的加速度)
2. 热流 δQ 通过视界 → 视界熵变 dS = δQ/T
3. 视界熵 S ∝ A (面积),即 Bekenstein-Hawking
4. 面积变分 δA ∝ 能量-动量张量 T_μν → 得到 G_μν = 8πG T_μν

**DGF的两时间结构引入了一个致命歧义:**

```
dt/dT = g(q)   [τ_intra vs τ_inter的转换因子]

Jacobson的问题:
  - Unruh温度 T = ħκ/(2π): κ中有对时间的导数。用τ_intra还是τ_inter求导?
  - 热流 δQ 是观测者在 τ_intra 中测量的,但视界熵 S = η₀·b1 定义在因果图的 τ_inter 层级
  - δQ = T dS 中,δQ和dS的时间尺度不同 → 得到的不再是 G_μν = 8πG T_μν
```

如果Unruh温度用τ_inter定义但δQ在τ_intra中测量,则:
```
δQ_measured = g(q) · δQ_true
→ G_μν = 8πG·g(q) · T_μν
```

**由此导出的不是GR,而是g(q)依赖的修正引力。** 在q≠q_today的时期,g(q)≠1,引力常数G_eff = G·g(q)随时间变化。

但是:
- G随时间变化的约束极其严格(月球激光测距、双脉冲星计时: |Ġ/G| < 10^{-13}/yr)
- g(q)在q~0.5时比q_today大~70%(bump模型), 即G_eff变化70%——完全排除

**post_ab_corrections.md 承认("DGF不替代GR时间膨胀——DGF为GR时间膨胀提供微观统计基础"),但没有解决这里的致命问题:** 如果g(q)≠1,Jacobson推导给出的就不是GR方程。要么DGF放弃g(q)≠1(放弃暗能量解释),要么DGF给出新的场方程(放弃GR)——**两者不可兼得。**

## A11 [量子基础 - 1: 严重] Page-Wootters映射: 定性类比,无数学桥接

- Cosmic time t = FLRW度规中的共动时间坐标
- Proper time τ = 随动观测者的原时 = t (对于共动观测者,两者相等)

FLRW度规: ds² = -dt² + a(t)²[dr²/(1-kr²) + r²dΩ²]

对于共动观测者(dr=dΩ=0): dτ = dt → τ_intra = τ_inter。**标准宇宙学中两者完全相等。**

DGF声称两者不同(dt/dT = g(q) ≠ 1),这意味着DGF在提议一个**非FLRW的度规结构**——但从未写出这个度规是什么。

更根本的问题: 在Page-Wootters机制中,"钟时间"和"坐标时间"的区别来自于**量子约束**(Ĥ|Ψ⟩=0, WdW方程)。DGF的τ_intra/τ_inter区别声称来自"因果事件率",但没有写出任何约束方程。这两个"两个时间"在数学结构上无共同点。
