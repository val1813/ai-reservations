#### 攻击1.1: 张量变换与Friedmann方程的不相容性

**设定:**

- τ_inter (T): "真实"宇宙时间坐标
- τ_intra (t): 测量时间坐标, 物理时钟tick的时间

**步骤1: 坐标变换**

用 dt = g dT, 度规在τ_intra坐标中:
```
ds² = -(dt/g)² + a² dΣ²
```
度规分量: g_intra_00 = -1/g², g_intra_ij = a² δ_ij

**步骤2: Einstein方程在τ_intra**

声称说 G_μν^(intra) = 8πG T_μν^(intra), 其中 G 是常数。

对 FLRW 度规 (k=0):
```
G_intra_00 = 3(H_intra² + k/a²) = 3H_intra²
```
其中 H_intra ≡ (da/dt)/a = (da/dT)/a · (dT/dt) = H_true / g(q)

**步骤3: 能量-动量张量变换**

T_μν 是 (0,2) 张量。在τ_inter坐标中 (共动观测者):
```
T_inter_00 = ρ_inter (u_inter^0 = 1, u_inter_0 = -1)
```

在τ_intra坐标中 (共动观测者: u_intra^0 = g, u_intra_0 = -1/g):
```
T_intra_00 = (ρ_intra + p_intra)·u_0·u_0 + p_intra·g_00
           = (ρ_intra + p_intra)/g² - p_intra/g²
           = ρ_intra / g²
```

同时, T_intra_00 通过张量变换:
```
T_intra_00 = (∂T/∂t)² T_inter_00 = (1/g)² ρ_inter = ρ_inter / g²
```

所以 ρ_intra = ρ_inter。能动密度是坐标标量——它不依赖于时间参数化。这是对的: 体积是几何量 (不依赖时间坐标), 粒子数密度 n ∝ 1/a³ 也是几何的。ρ = m·n = m/a³ 与时间参数化无关。

**步骤4: Friedmann方程与矛盾**

在τ_intra中, 平坦FLRW的Einstein 00分量:
```

```

代入 H_intra = H_true / g:
```
3(H_true/g)² = 8πG · ρ/g²
3H_true² / g² = 8πG · ρ/g²
3H_true² = 8πG · ρ          ← g完全抵消!
```

**g(q)在推导中完全抵消。** 对任何非奇异g(q)≠0, τ_intra中的Einstein方程精确等价于τ_inter中的Einstein方程——G不变, ρ不变, H_true由标准Friedmann方程决定。
