## 1.2 统计力学攻击: Caldeira-Leggett模型的拓扑重命名

**攻击:** DGF声称"每个因果环是一个退相干放大器，|G_ab|按∏_r cos²(cΔ_r)指数衰减"在标准自旋玻色子模型中有一个精确对应：环境谱密度J(ω)的Ohmic分量。

```
ρ(x,x',t) = ρ(x,x',0) · exp[-∫₀ᵗ dt₁∫₀ᵗ dt₂ L(t₁-t₂)(x(t₁)-x'(t₁))(x(t₂)-x'(t₂))]
```

在Ohmic环境(J(ω)∝ω)和高温极限下，退相干速率为: γ_dec = (2Mγk_BT/ħ²)(Δx)²

**DGF → Caldeira-Leggett映射:**
```
DGF参数          →  CL参数
b1 (环数)       →  N_modes (模式数)
c (Cartan参数)   →  c_i (耦合系数)
|μ|·b1          →  γ·t (退相干速率×时间)
p (环境纯度)    →  k_B T (热涨落)

```

**DGF声称独立于Caldeira-Leggett:** DGF说"DGF不替代标准退相干——它补充了标准理论缺失的自由度(b1)"(13-wall-ab-corrected.md)。这是诚实的。但问题是：b1到底是什么？如果b1对系统qubit数和环境qubit数之和，那么Caldeira-Leggett中的环境模式数N_modes就是b1的角色。DGF的"因果环"不过是把环境模式之间的相互作用重新包装成"环"。

**裁决:** ⚠️ 严重(1) — 退相干放大器的数学形式与自旋玻色子模型同构，尽管声称的微观机制不同。DGF需要证明：用因果环参数化比用谱密度J(ω)参数化能做出更多/更精确的预言。目前做不到。

# 模块3: 集体Clifford保护 (Collective Clifford Protection)

## 核心声称

**攻击:** 退相干自由子空间(DFS)的概念和构造方法在1990年代已被量子信息论完全建立。DGF的"集体Clifford保护"是DFS理论的一个特例。

**DFS理论的核心结果:**

1. **Zanardi-Rasetti (1997):** DFS存在 ⟺ 系统-环境哈密顿量有非平凡对称性。DFS中的态满足 S_α|ψ⟩ = c_α|ψ⟩ ∀系统-环境耦合算子S_α。

2. **Lidar-Chuang-Whaley (1998):** 无噪声子系统(NS)和DFS的构造方法。DFS条件是所有误差算子E_i在DFS上正比于单位算子。

3. **Knill-Laflamme (1997):** 量子纠错码的条件 ⟨i_L|E_a^†E_b|j_L⟩ = C_{ab}δ_{ij}。当C_{ab}是对角矩阵时，这是DFS条件。

**DGF的集体Clifford保护准确对应DFS理论:**
```
DGF概念                   DFS理论对应
集体|+..+⟩/|-..-⟩模式   DFS的逻辑基态|0_L⟩,|1_L⟩
4c∈πℤ保护条件           DFS的对称性条件
cos(4c)=-1               C_{ab} = diag(...) 
单qubit退相干不保护      其他自由度不在DFS中
```

**DGF的声称(collective_clifford_protection.py):** "This is NOT an engineered QEC code. It's a natural consequence of causal ring topology." 但这完全是DFS理论的重新包装。DFS不需要是"工程"的——任何有合适对称性的物理系统自动拥有DFS。DGF的"因果拓扑产生的DFS"不过是说"Cartan对齐的因果环有Z₂对称性"——这在DFS理论中就是系统-环境耦合的对称性条件。

**裁决:** ❌ 致命(0) — DGF的集体Clifford保护是DFS理论在Cartan对齐因果环上的特例应用。没有任何超出Zanardi-Rasetti(1997)和Lidar-Whaley(2003)的内容。文献未引用。

**跨域连接:** [量子信息论] × DGF = Zanardi-Rasetti DFS的因果拓扑特例

**新北极星候选:** 系统对比DGF集体保护条件和标准DFS条件(Zanardi-Rasetti, Knill-Laflamme)，找出因果拓扑框架能否产生标准DFS理论无法产生的保护模式。如果所有模式都可以在标准DFS框架内描述，DGF的增量为零。

# 模块4: T1时钟精度重建 (T1 Reconstruction)

## 核心声称
```
σ_f/f₀ ≥ √(|μ(c,p)| · γ_E · b1_active(clock) / τ_meas)
```

## 4.1 量子光学/计量学攻击: SQL和Heisenberg极限已覆盖

**攻击:** DGF声称其时钟精度极限是新的。但量子计量学已经严格推导了所有物理时钟的基本精度极限。

**标准量子极限(SQL):** 对N个独立粒子的未纠缠测量:
```
σ_f/f₀ ≥ 1/(√N · √τ_meas · ω₀)
```

**Heisenberg极限:** 对N个最大纠缠粒子的测量:
```
σ_f/f₀ ≥ 1/(N · √τ_meas · ω₀)
```

**DGF极限 vs 已知极限:**

```
DGF: σ_f/f₀ ≥ √(|μ|·γ_E·b1_active/τ_meas)

SQL: σ_f/f₀ ≥ 1/(√N·√τ_meas·ω₀)

HL: σ_f/f₀ ≥ 1/(N·√τ_meas·ω₀)
```

**参数翻译:** 如果|μ|→0(c很小,弱耦合), b1_active→1(少量活性环), γ_E→0(冷环境), DGF极限可以推至任意低。但SQL也做同样的事：增加粒子数N或降低噪声，精度任意提高。

**DGF声称的增量是什么?** T1_reconstruction.md说标准量子计量学"没有b1"、"没有μ"。但量子计量学有自己的参数化(N粒子数、T相干时间、耦合强度g)。把N改叫b1不改物理。

**具体反证:** Sr光晶格钟已达到σ_f/f₀≈10⁻¹⁸。DGF对Sr的预言极限是~10⁻²⁰(τ=1s)。两者差2个数量级。量子计量学的SQL对N=10³个原子(典型光晶格钟)给出σ_f/f₀≈1/(√10³·√1·10¹⁵)≈3×10⁻¹⁷——与当前实验一致。DGF的10⁻²⁰是更松的界，不是更紧的界——如果DGF界是"基本极限"，它应该比已实现精度更紧，而非更松。

**裁决:** ❌ 致命(0) — DGF的时钟精度"基本极限"是量子计量学中已知结果的重命名。SQL/Heisenberg极限更紧、推导更严格、和实验吻合更好。DGF极限没有增加任何新约束。更糟糕的是，T1中的c_eff、b1_active估计是后验的(从已知精度反推)，不是先验的预言。

**跨域连接:** [量子光学/计量学] × DGF = SQL/Heisenberg极限的无信息增量重命名

## 5.2 引力物理: Jacobson→Poisson的路径对比

**攻击:** LITERATURE_POSITIONING.md诚实地说"DGF不是'从信息推导引力的第一个框架'"。但Paper需要面对的事实更严峻：Jacobson(1995)、Verlinde(2011)、Padmanabhan(2002-2010)、Roupas(2020)、Singh & Friedrich(2023)都已完成或部分完成了DGF的目标。DGF是一个已经很拥挤的赛道上的后来者。

**DGF声称的独特性:**
1. b1(Betti数) — 独特参数
2. η₀=1/(8ln2) — 新常数
3. 两时间结构 — 新概念
4. QCMI→退相干映射 — 新桥梁

**攻击:**
1. b1在因果集理论(CST)中不是新概念。Sorkin(1987)就讨论了因果集的同调群。DGF的b1只是CST的Betti数在量子信息框架中的使用——跨域借用了概念。
2. η₀=1/(8ln2) — 这是Fawzi-Renner(2015)定理的4环特例乘以1/16的"环拓扑修正"。如果Fawzi-Renner没有得诺贝尔奖，η₀也不应该。
3. 两时间结构 — 没有竞争者"不等于"竞争者的框架不能产生等效预言。Boettcher(2025)的Finsler proper time可能已经包含了类似的两时间效应，只是用的是不同的数学语言。
4. QCMI→退相干映射 D_global=1-[cos²(4c)]^{b1} — 严格来说这是一个好的、可数值验证的结果。但它对Cartan对齐假设的依赖使得它不是一般性的。

**裁决:** ⚠️ 可修复(2) — 竞争对手列表很长。DGF需要明确：如果有10个理论都能恢复弱场GR，什么实验能区分它们？没有这样的实验预测，DGF就是又一个"也能推导GR"的理论。

# 最终判断

**DGF-Survivors不是一个新理论框架。它是一个已有理论的重新包装和参数化应用集。**

核心逻辑链:
```
已有结果                 DGF重新包装
HJPW(2004)        →   CFOL "定理" (推论)
Fawzi-Renner(2015) →   η₀ "基本常数" (特例×1/16)
Zanardi-Rasetti(1997) → 集体Clifford保护 (DFS特例)
Caldeira-Leggett(1983) → 退相干放大器 (参数重命名)
SQL(1994)          →  T1时钟极限 (重命名+参数化)
Jacobson(1995)     →  引力推导 (目标相同,路径更复杂)
```

**DGF的独特价值(不否定):**
1. 将因果拓扑引入量子信息论(虽然CST先做了)
2. QCMI→退相干的解析映射(Wall#9) —— 好结果
3. 转移矩阵+Perron-Frobenius的正性证明 —— 好数学
4. IBM Q硬件验证(S/N=617) —— 好实验

**DGF被严重夸大的是:**
1. η₀作为"基本常数"(它是由Fawzi-Renner系数/16得到的)
2. b1作为"新自由度的发现"(CST中Betti数早有;因果环作为退相干单元和Kitaev plaquette同构)
3. "信息→引力的新框架"(Jacobson先发30年,赛道拥挤)
4. "因果拓扑自然产生DFS"(DFS理论1997年已完成,不需要因果拓扑)

**如果DGF是一篇论文:**
- 贡献: 因果图+QCMI的参数化方法论,可用于工程化退相干控制
- 不是: 基础物理的新范式
- 建议: 放弃"框架"野心,专注"工具"定位。DGF的最好归宿是量子退相干工程的计算工具包,不是替代量子引力理论的候选者。

**奥卡姆剃刀最后一刀:**
如果一个理论的每一个核心组件都已经在另一个更成熟的理论中有等价表述，而且这些更成熟的理论的推导更短、假设更少、实验验证更多——那么这个理论就应该被奥卡姆剃刀剃掉。DGF通过了存活门槛吗？勉强。但不是作为新范式。是作为新工具。
