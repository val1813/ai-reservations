## 统一框架: τ_inter = 因果拓扑的生长时间

### 0. 定义

```
τ_intra (t): 因果环内的事件序列 → 宏观Einstein方程 (Jacobson)
τ_inter (N): 因果图的生长步数 → 微观BD作用量驱动的随机过程
```

### 1. 微观: CSG主方程 (因果集生长)

因果图C有N个元素。添加第N+1个元素的概率:

```
P(C_N → C_{N+1}) ∝ exp(-δS_BD[C_N→C_{N+1}] / η₀)
```

BD作用量: S_BD = N - a_d·N_1 + b_d·N_2 - c_d·N_3 + ...

η₀ = 1/(8ln2) 充当"信息作用量量子"——取代ħ在量子力学中的角色。

### 2. 介观: Fisher测地线 + Reflux摩擦

在N→∞连续极限下，CSG→Fisher测地线流:

```
d²ρ/dN² + Γ(ρ)(dρ/dN)² = η₀·g^{-1}·∇|c|² - γ·g^{-1}·∇S_reflux

其中:
  ρ = Gram矩阵参数化的系统-环境态
  g = Fisher信息度规
  Γ = Fisher度规的Christoffel符号
  ∇|c|² = QCMI梯度 (信息力)
  ∇S_reflux = Reflux熵势垒梯度 (摩擦力)
  γ = (ħ/2)·P_reflux·ω_ring (耗散系数)
```

### 3. 宏观: BD→Einstein涌现

BD作用量的连续极限:

```
S_BD → (1/ℓ_p⁴)∫d⁴x√-g - (ℓ²/ℓ_p⁴)∫d⁴x√-g R + O(ℓ⁴)

δS_BD = 0 → G_μν + Λg_μν = 8πG T_μν
```

这是τ_intra中的Einstein方程。不是独立假设——从τ_inter的BD动力学涌现。

### 4. 涨落定理 (Reflux界的形式化)

```
P(+ΔS, ΔN) / P(-ΔS, ΔN) = exp(ΔS_DGF / η₀)

宏观极限(N_E≫N_S): P_reflux → 0 → τ_inter不可逆

```

### 5. 关键预言: g(N) ∼ N^{-3/4}

从因果集最长链统计 (d=4):

