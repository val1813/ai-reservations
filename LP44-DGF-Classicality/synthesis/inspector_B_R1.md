## Q5. 代数验算

### Q5a-b: 逐步展开 + 极限退化

#### F1 (C1): 代数展开

```
|p·exp(i·c·Δ) + (1-p)·exp(-i·c·Δ)|²
= |p·cos(c·Δ) + i·p·sin(c·Δ) + (1-p)·cos(c·Δ) - i·(1-p)·sin(c·Δ)|²
= |cos(c·Δ) + i·(2p-1)·sin(c·Δ)|²
= cos²(c·Δ) + (2p-1)²·sin²(c·Δ)                              ← 闭式
```

极限退化:
- p→0.5: cos²(c·Δ) ✅ (最大混同=混同概率=cos²)
- p→0: cos² + sin² = 1 ✅ (完全混同)
- c→π/2, Δ=1: cos²(π/2) + (2p-1)²·sin²(π/2) = (2p-1)² ✅ (p=0.5时=0, DFS)

**F1 判定: ✅ 代数正确，极限退化一致。**

#### F2 (C1): μ 的期望定义

```
μ = E_Δ[ln|cos(c·Δ) + i·(2p-1)·sin(c·Δ)|]
  = E_Δ[½ ln(cos²(c·Δ) + (2p-1)² sin²(c·Δ))]
```

极限退化:
- c→0: μ → E[½ ln(1)] = 0 ✅
- p=0.5: μ = E[ln|cos(c·Δ)|] ≤ 0 ✅ (cos∈(0,1] ⇒ ln≤0)
- c→π/4, p=0.5: μ = E[ln|cos(π·Δ/4)|], 在 Δ→2 处 cos→0 ⇒ ln→-∞, 需正则化

⚠️ 在 c→π/4, p=0.5, Δ 分布包含 Δ=2 或 Δ→2 附近有密度时, E[ln|cos|] 积分在 cos=0 处对数发散。虽然积分本身收敛（∫ln x dx 在 0 处有限），但 μ 值对 Δ 分布的尾部极端敏感。**标记为 μ 定义中的正则化敏感性。**

**F2 判定: ⚠️ 代数结构正确，但在 c=π/4 附近 μ 对 Δ 分布尾部极度敏感。**

#### F4 (C3): N_crit 公式 —— 已在 Q2 中证明方向错误

重复验证:
- 公式: N_crit = |ln(p/(1-p))| / |μ(c, p=0.5)|
- 极限 p→0.5: 公式给出 0, limit claim 声称 ∞ — **致命矛盾** ❌
- 极限 p→1: 公式给出 →∞ (因 ln(p/(1-p))→∞), 但物理上 p→1 时每环退相干→0, 累积退相干无意义 — N_crit 定义不明

**F4 判定: ❌ 公式与 limit claims 矛盾。F4 必须重新推导。**

#### F2 numerical_test: c=0.5, p=0.5

```
μ = E[ln|cos(0.5·Δ)|]

对均匀 Δ∈[0,π]:
  μ = (1/π) ∫₀^π ln|cos(t/2)| dt
    = (2/π) ∫₀^{π/2} ln(cos u) du      [u=t/2]
    = (2/π) × (-π·ln 2 / 2)            [已知积分]
    = -ln 2 ≈ -0.693

声称范围 [-0.6, -0.3]
实际值 -0.693 ∉ [-0.6, -0.3]   → 略低于声称下界
```

⚠️ 偏差: 声称 μ∈[-0.6,-0.3], 均匀分布下 μ≈-0.693 (<-0.6)。若 Δ 非均匀分布，结果可能进入声称范围。偏差 <1 数量级，但声称范围偏乐观。

**F2 判定: ⚠️ 偏差 <1 数量级。声称范围 [-0.6,-0.3] 应将下界扩展至约 -0.7。**

### 经济学同构映射的数学基础评估

B博士声称"严格的数学同构"（C1, confidence 0.70），但实际映射关系是:

```
机制设计                → DGF
─────────────────────────────────────
Agent类型空间(离散)     → 系统态空间（可离散化）
买方先验(共同知识)      → 环境纯度 p
信息租金                → 退相干率 |μ(c,p)|
混同均衡概率            → |G_ab|² (Gram非对角元)
分离均衡                → 退相干完全 (|G_ab|²→0)
激励相容(IC)            → 退相干方向与全局目标对齐
个体理性(IR)            → |G_ab|² ≥ 0 (自动满足)
```

**关键缺口:**
1. 机制设计需要"效用函数"定义Agent偏好 — DGF无对应物（声称映射为"退相干方向"但退相干是物理必然性不是偏好）
2. 机制设计需要"策略空间" — 量子演化无选择，由哈密顿量唯一决定
3. 机制设计需要"均衡"概念 — DGF的动力学是演化，不是多Agent博弈结果

**deep_dig 的范畴论拯救方案**（Grothendieck纤维化统一）仅解决了"资源理论"的结构层面问题，但无法消除"量子系统不是理性行动者"的基本范畴错误。这个差距使得 C1 的 "严格数学同构" 声张被降级为 "结构性类比"。
