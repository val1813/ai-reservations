# R2修正 — Γ₀/γ_E标定

**日期:** 2026-06-11

## 关键发现: c=π/4处|μ|发散

mu_analytic.py数值计算:
| c (rad) | \|μ\| | sig |
|---------|:-----:|:---:|
| 0.1 (≈π/32) | 0.042 | 0.057 |
| 0.3 (≈π/10) | 0.399 | 0.466 |
| 0.5 (≈π/6.3) | 0.466 | 0.345 |

**原因:** c=π/4, Δ=±2时, cΔ=±π/2, cos(π/2)=0, ln|0|=-∞。单环可完美区分某些态对。

## 修正方案

1. **c=π/4从Γ₀/γ_E标定排除**: 发散|μ|使I_DGF/|μ|无意义
2. **用c=0.5标定**: |μ(c=0.5)|=0.466, I_DGF(π/4 v4数据)=0.739 → Γ₀=0.739/(0.466·4·1μs)=3.96e5 s⁻¹, γ_E=7692 → **Γ₀/γ_E≈51**
3. **Γ₀/γ_E≠1**: 因果环泵浦速率约为环境退相干率的50倍。"零自由参数"降为"单参数但可独立标定"

## π/4发散的物理意义

**正面:** π/4处退相干放大器效率极高(单环即可完美区分)→集体Clifford保护的条件更严格
**负面:** Γ₀/γ_E的普适性更不确定(只在远离Clifford奇点的c值有定义)

## R2排他性预言更新

因果图重连测试仍成立:
- c=π/4: DGF效应极大(|μ|发散→单环完美退相干)→ Tree vs Ring差异最大
- c远离π/4: DGF效应有限但精确可算→ Tree vs Ring差异定量可测
- **推荐c≈0.5**: |μ|=0.466, 效应可控, ratio≈1.47
