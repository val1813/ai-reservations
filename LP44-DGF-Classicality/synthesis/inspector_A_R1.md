## Q1. 量纲校对

### F1 (C1): `sqrt(|mu(c,p)|*gamma_E*b1_active/tau_meas)`

```
左端 (sigma_f/f0): [无量纲] — 频率不确定度/标称频率, 分数频率不稳定度
右端 (公式计算值):
  mu(c,p) = E[ln|...|] → [无量纲] ✓
  gamma_E            → [s^{-1}]    (环境退相干率)
  b1_active          → [无量纲]    (活跃因果环数)
  tau_meas           → [s]         (测量时间)
  sqrt(|mu|*gamma_E*b1_active/tau_meas)
    = sqrt(无量纲 * s^{-1} * 无量纲 / s)
    = sqrt(s^{-2})
    = [s^{-1}]
```

**❌ 量纲错误：F1。左端=[无量纲]，右端=[s^{-1}]。**

原因：标准量子计量学中，时钟稳定度公式为：
```
sigma_y(tau) = (1/omega_0) * sqrt(Gamma / tau)
```
其中 `omega_0` (时钟角频率, [s^{-1}]) 提供所需的量纲抵消因子。F1 缺失了 `1/omega_0` (或等价的 `1/(2*pi*f0)`) 因子。

修正建议：
```
sigma_f/f0 >= (1/omega_0) * sqrt(|mu(c,p)| * gamma_E * b1_active / tau_meas)
```
或等价地：
```
sigma_f/f0 >= (1/(2*pi*f0)) * sqrt(|mu(c,p)| * gamma_E * b1_active / tau_meas)
```
其中 `omega_0` 或 `f0` 为时钟的标称角频率/频率。

**严重程度: 致命** — 量纲错误使公式本身物理意义不成立。修正后公式结构和多数方向性结论可保留。

### F2 (C2): `abs(mu(c,p))*gamma_E*b1_active*t <= 2*S(E)`

```
左端: 无量纲 * s^{-1} * 无量纲 * s = [无量纲] ✓
右端: 2*S(E) = [bits, 无量纲]       ✓
```
✅ 通过。

### F3 (C5): `tau_dec = 1/(abs(mu(c,p))*gamma_E*b1_active) * (gamma_E/Gamma_0)`

```
右端: 1/(无量纲 * s^{-1} * 无量纲) * (s^{-1}/s^{-1}) = [s] ✓
左端: tau_dec = [s] ✓
```
✅ 通过。

### 超越函数参数检查

各公式中 exp(i*c*Delta) 的自变量 `c*Delta` 中 c 和 Delta 均为无量纲 → ✅ 所有超越函数参数无量纲。
