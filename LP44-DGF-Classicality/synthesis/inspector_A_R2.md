## Q3. 循环论证校对

### 关键检查: b1_active 定义是否真正独立于退相干测量？

**R1问题:** b1_active 没有独立于退相干测量的操作性定义 → 公式 τ_dec ∝ 1/b1_active 是同义反复（用退相干定义b1，再用b1预测退相干）。

**R2声称:** F1+F2 提供了从 Hamiltonian 交互图 + Cartan 门分类出发的独立定义，无需退相干测量。

**逐元件检查:**

| 定义元件 | 所需输入 | 是否涉及退相干测量？ | 判定 |
|------|------|:--:|:--:|
| 因果图 G=(V,E) | H_int^(ij) — 物理相互作用哈密顿量 | 否 — 纯结构量 | ✅ 独立 |
| 循环秩 b1=\|E\|-\|V\|+c | 图结构 — 纯图论计算 | 否 — 纯图论量 | ✅ 独立 |
| Clifford判定 c∈{0,π/4,π/2}³ | Cartan参数 — 门的群论分类 | 否 — 纯群论量 | ✅ 独立 |
| 非Clifford判定 | Cartan参数 ∉ Clifford集 | 否 — 纯群论量 | ✅ 独立 |
| b1_active = sum[非Clifford环] | 图结构 + 门分类 | **否 — 两个独立量的组合** | ✅ 独立 |

**结论:** b1_active 的新定义确实打破了循环。输入项（H_int + Cartan分类）均可在不测量退相干的情况下确定。✅ 循环论证墙已破。

### F3: Γ₀标定是否循环？

Γ₀ 从 `I_DGF / (|μ| * b1_active * t_cycle)` 提取：
- I_DGF = I_RaQa - I_cl: 依赖QCMI测量 → 包含退相干信息
- 但 γ_E = 1/T2 来自独立 Ramsey/Hahn echo → **不依赖DGF**

标定流程: 独立γ_E + DGF-I_DGF → 算出Γ₀ → 用于预测其他配置的退相干率。

这是 "一次标定，多次预测" 的半循环结构。标定本身依赖DGF框架，但预测能力通过标定后的外推获得。

| 操作 | 是否循环 | 判定 |
|------|:--:|:--:|
| Γ₀/γ_E在IBM Q上标定 → 预测同一设备b1=1的τ_dec | ⚠️ 同设备内外推 | 弱循环风险 |
| Γ₀/γ_E在Heron上标定 → 预测Eagle上τ_dec | 否 — 跨设备 | ✅ |
| Γ₀/γ_E在IBM Q上标定 → 预测光钟精度 | 否 — 跨系统 | ✅ |

**⚠️ 警告: F5的预测与F3的标定共用同一套LP38 IBM Q数据。** 如果C3实验使用同一Heron设备，则预测所用的Γ₀和测试数据来自同一物理系统——这是一种自洽性检验（consistency check）而非严格独立预测。跨设备/跨平台的检验才能真正确立预测能力。

```

  → Γ₀/γ_E = [I_DGF / (|μ|·b1_active·t_cycle)] / (1/T2)
```

✅ 代数步骤正确（前提成立时）。

### 5b. 极限退化

### 5c. 数值量级验证 — ⛔ 发现致命数学错误

**F5 是本次审查最严重的发现。**

文件的 F5 给出:
```
τ_dec(tree) / τ_dec(ring) = 1 + |μ(c,p)|
```

正确推导:
```
1/τ_total = 1/τ_hw + 1/τ_DGF
         = γ_E + |μ|·b1_active·Γ₀

τ_tree (b1=0): 1/τ_tree = γ_E + 0 = γ_E
τ_ring (b1=1): 1/τ_ring = γ_E + |μ|·Γ₀

比值:
τ_tree/τ_ring = (γ_E + |μ|·Γ₀) / γ_E
             = 1 + |μ|·(Γ₀/γ_E)
             = 1 + |μ|·51.1    (代入F3标定值)
```

**文件声称: 比值 = 1.47 (使用 |μ|=0.47)**
**正确值: 比值 = 1 + 0.47×51.1 = 25.0**

**偏差: 因子 ~17 (1.2 OOM) — ❌ > 1个数量级**

**根源分析:** F5 隐含假设了 Γ₀ = γ_E（即比值为1），这是R1的前提（R1 C5标记为 "最脆弱环节"）。R2 号称已将此假设替换为标定协议（F3），但 F5 的公式未同步更新——它仍然使用旧的 Γ₀=γ_E 假设。

**这是一个内部矛盾:** Polaris 使用 Γ₀ (新)，F3 标定 Γ₀/γ_E ≈ 51 (新)，但 F5 的预测公式仍基于 Γ₀=γ_E (旧)。三个公式在同一轮产出中不一致。

**对实验的影响:** 实际效应比声称的大 17 倍（25x vs 1.47x 的退相干率差异），这意味着实验比预想的容易得多——好消息，但公式仍然是错的。
