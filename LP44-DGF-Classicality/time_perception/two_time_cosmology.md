## 1. 物理图像

DGF说宇宙有两个时间维度:
- **T (τ_inter, 环间时间):** 因果环之间的"螺旋上升"方向。宇宙波函数在这个时间中演化。这是"真实"的宇宙时间。
- **t (τ_intra, 环内时间):** 因果环内部的事件偏序。我们和所有物理时钟测量的是这个时间。

两者的转换率:
```
dt/dT = f(q(T))
```

其中 q(T) 是宇宙平均纯度（因果格点的平均纯度）。

**关键物理直觉:**
- 早期宇宙: 高温高密 → 高退相干率 → 低q → f大（单位真实时间产生更多测量时间）
- 晚期宇宙: 低密真空 → 低退相干率 → 高q → f小（单位真实时间产生更少测量时间）
- 我们的时钟在宇宙学时间尺度上在**变慢** → 测量到的哈勃膨胀在**加速**

这不是新场/新流体。这是时间坐标本身的系统性漂移。

## 2. 宇宙学可观测量

真实宇宙学（在T时间中）:
```
H_T²(T) = (8πG/3) ρ(T) - k/a²
```

标准Friedmann方程，无宇宙学常数。

距离测量（光度距离、角径距离）涉及对dt的积分 → 涉及f(q):
```
d_L(z) = (1+z) ∫_0^z dz'/H_meas(z')
```

所以f(q(z))同时影响 H(z)、d_L(z)、d_A(z)、以及CMB的θ_*（声视界/角径距离比）。

## 3. 模型参数化

### 3a: q(a) — 宇宙平均纯度的演化

物理约束:
- a→0 (大爆炸): 极高密度, 完全退相干 → q→0
- a≫1 (遥远未来): 真空 → q→q_vac

最简参数化（单参数β）:
```
q(a) = q_vac · a^β / (1 + a^β)
```

此形式保证 q(0)=0, q(∞)=q_vac, 且β控制过渡的陡峭度。

对a≪1: q ∝ a^β
对a≫1: q → q_vac

### 3b: f(q) — 时间转换函数

物理约束:
- q→0: f→∞（纯退相干极限，无协调因果事件，时间流速无限慢? → dt/dT→∞?）
  - 等等。q→0时格点完全退相干→无协调事件→dt/dT→? 
  - 此时无"测量的"因果事件，dt→0。但dt是测量时间——如果无测量，dt=0。
  - 从T的角度看：dt/dT→0当q→0（无因果事件=无时间流逝的感觉）
  - 从t的角度看：dT/dt→∞当q→0（对同样的测量时间，真实时间流逝无限快）
  
- q→q_vac: f→f_vac（基准转换率，可重标定为1）

所以dt/dT应该随q增加而增加（更多协调事件→更多测量时间）:
f(0)=0, f(q_vac)=1, f单调增。

最简形式（单参数α）:
```
f(q) = (q/q_vac)^α, α > 0
```

### 3c: 自由参数总计

{DGF} 两时间模型: {q_vac, α, β} = 3个宇宙学参数
{ΛCDM}: {Ω_m, Ω_Λ, H₀} = 3个宇宙学参数（平直空间）

## 4. 有效暗能量状态方程

从观测约束反推f(q(a))的效果。

观测哈勃参数:
```
H_meas(a) = H_T(a) / f(q(a))
```

物质主导的真实宇宙（无Λ）:
```
H_T²(a) = H₀_T² · a⁻³  (Ω_m_true = 1)
```

平直空间假设下:
```
H_meas²(a) = H₀_T² · a⁻³ / f²(q(a))
```

ΛCDM对比:
```
H²_ΛCDM(a) = H₀² [Ω_m a⁻³ + (1-Ω_m)]
```

**对应关系:** 为使两时间模型在背景演化上模仿ΛCDM:
```
f²(q(a)) = a⁻³ / [Ω_m a⁻³ + (1-Ω_m)] · (H₀_T²/H₀²)
```

在z=0 (a=1): f²(q_ref) = 1 / [Ω_m] · (H₀_T²/H₀²)
取f(q_ref)=1 (重标定): H₀_T = H₀ √Ω_m

在z≫1 (a≪1): f²(q≪1) = 1/Ω_m

如果Ω_m=0.3: f(q≪1)=1/√0.3≈1.83, f(q_ref)=1
意味着: 早期宇宙的测量时间流逝是现在的1.83倍。

## 5. 可检验预言

### 5a: 有效w(z)

在ΛCDM中引入w(z)参数化暗能量状态方程:
```
H²(z) = H₀² [Ω_m(1+z)³ + (1-Ω_m)(1+z)^{3(1+w(z))}]
```

两时间模型产生等效w_eff(z):
```
w_eff(z) = -1 + (1+z)/3 · d/dz ln[f²(q(z)) · (某个函数)]
```

非单调w(z)是自然的——当q过渡最快时（βa^β/(1+a^β)²最大的位置），f变化最快，w_eff偏离-1最远，然后在高低z两端趋于-1。

**这与D5的DESI结果定性一致!**

### 5b: 增长因子

在t时间和T时间中，密度扰动的增长方程不同。线性增长因子D(a)满足:
```
在测量时间t中: D̈ + 2H_meas Ḋ - (3/2)Ω_m(a)H_meas² D = 0
```

但引力相互作用发生在T时间中（假设）。需要仔细分析这如何影响fσ₈测量。

### 5c: 红移漂移 (Redshift Drift / Sandage Test)

这是**最干净的可检验预言**。红移漂移:
```
dz/dt₀ = (1+z)H₀ - H(z)
```

在ΛCDM中，dz/dt₀的计算只涉及H(z)。在两时间模型中，dt₀（今天的测量时间间隔）和dt(z)（当时的测量时间间隔）之间的转换引入了额外效应。

具体预言数值待计算。
