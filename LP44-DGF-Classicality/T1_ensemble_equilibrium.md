# T1: 系综平衡时钟

**日期:** 2026-06-10
**模拟验证:** mutual_decoherence_clock.py

---

## 核心发现

N个粒子通过共享环境互相退相干。每个粒子保持自己的本征Cartan参数c_i。系综平均频率达到稳态——不随时间变化。

**平衡≠同步。** 粒子不趋同——它们保持本征差异。系综平均稳定。

## 物理图像

```
粒子1 (c₁) ──→ 环境qubit A ──→ 粒子2 (c₂被调制)
粒子2 (c₂) ──→ 环境qubit B ──→ 粒子1 (c₁被调制)
...
所有粒子 ──→ 环境纯度 q_env ──→ 所有c_eff被反馈

稳态: q_env恒定 ↔ 总QCMI产生率=环境弛豫率
     ⟨c_eff⟩恒定 ↔ 系综平均频率不变
     σ_c > 0    ↔ 粒子保持本征差异
```

## DGF时间定义 (修正T1)

**时钟频率 = 系综平均Cartan参数的平衡值**

```
f_clock = ⟨c_eff⟩_eq / (2π) · Γ₀
```

其中:
- ⟨c_eff⟩_eq = 系综在环境反馈下的平衡有效Cartan参数
- Γ₀ = 基本环速率 (t_P⁻¹)

**时间膨胀 = 平衡⟨c_eff⟩随q场变化**

```
f_clock(Φ₁) / f_clock(Φ₂) = ⟨c_eff(Φ₁)⟩_eq / ⟨c_eff(Φ₂)⟩_eq
```

在弱场极限: ⟨c_eff⟩_eq ∝ q ∝ exp(-Φ/c²) → f_clock ∝ exp(-Φ/c²)
dτ/dt = f_clock(Φ)/f_clock(0) = exp(-Φ/c²) ≈ 1 - Φ/c² → 重现GR

## INSPECTOR I-1 的最终解决

I-1攻击: "时钟tick=相干Rabi振荡≠退相干事件"

回应: **单个原子的跃迁是相干的。但定义"秒"的不是单个原子——是系综。系综的频率由所有原子通过共享环境的相互退相干决定。退相干不产生tick——退相干产生平衡，平衡决定系综频率。**

系综平衡频率既依赖于相干成分(c_i的本征值)也依赖于退相干成分(环境反馈调制c_eff)。两者不可分离。
