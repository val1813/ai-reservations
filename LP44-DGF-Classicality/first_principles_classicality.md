# 从第一性原理重新理解经典性

**日期:** 2026-06-10
**问题:** PR vs D_global矛盾暴露了"经典性是什么"没有从第一性原理定义清楚。

---

## 起点: DGF的两条公理

```
A1: 每个因果格点承载 ≤ 1 bit 量子信息
A2: 因果边有向, 信息沿有向边流动
```

由此导出: 因果环(b1), Cartan参数(c), QCMI(η₀|c|²), Gram矩阵。

## 重新定义: 什么是"观测者"?

在DGF中，**观测者也是一个因果图**。观测者O有b1_obs个因果环。观测者的Gram矩阵维度=2^{b1_obs+1}——这决定了O能区分多少种不同的环境状态。

**观测者的信息分辨率:** PR_obs ~ 2^{b1_obs} (最大可区分的状态数)

## 重新定义: 什么是"测量"?

测量 = 观测者O和目标系统S之间创建新的因果环(耦合边)。这些环使O的Gram矩阵获得关于S的信息。

测量后O的Gram矩阵: G_O' = G_O ⊗ G_coupling

O能"看到"的S的状态数 ≤ min(PR_obs, PR_coupling)

## 重新定义: 什么是"经典性"?

**S对O是"经典的" ⟺ O的信息分辨率足以区分S的所有相关状态:**

```
PR_obs ≥ d_S (目标系统的有效维数)
```

如果PR_obs < d_S: O只能看到S的部分信息 → S对O表现为"量子"(有不可区分的叠加态)
如果PR_obs ≥ d_S: O能看到S的全部信息 → S对O表现为"经典"(所有状态可区分)

## 这就解决了两个根本问题

### 问题1: "波函数坍缩"是什么?

坍缩不是物理过程。坍缩是观测者的有限b1导致的**信息截断**。

当b1_obs < log2(叠加态数):
- O的Gram矩阵无法容纳完整的叠加信息
- O感知到的是投影到可区分子空间的混合态
- 这就是"坍缩"

**坍缩的主观性:** 两个不同b1的观测者看同一个量子系统，会看到不同的"现实":
- b1=1的观测者(单个qubit): 能看到量子叠加
- b1=10^23的观测者(人类): 只能看到经典概率

### 问题2: PR vs D_global矛盾

PR_obs和D_global不是同一个层面的量:

- **PR_obs:** 观测者的信息容量。PR→∞意味着观测者可以分辨无限多种状态。这是观测者的属性。

- **D_global:** 目标系统集体可观测量被退相干的程度。D_global→1意味着目标系统的某个宏观自由度有了确定值。这是目标的属性。

两者不矛盾——它们属于不同的系统(观测者 vs 目标)。

"经典世界" = 经典观测者(PR_obs巨大)观察经典化的目标(D_global→1)。
"量子实验" = 经典观测者(PR_obs巨大)观察量子目标(D_global≪1)——观测者的经典性和目标的量子性可以共存。

## 三层次经典性

```
层次1: 目标退相干 (D_global → 1)
  目标系统的集体可观测量在环境中留下确定记录
  
层次2: 记录稳健性 (DFS条件 4c∈πℤ)
  环境记录存储在非局域关联中, 对局部噪声免疫

层次3: 观测者分辨率 (PR_obs ≥ d_target)
  观测者有足够的信息容量读取完整记录
```

**只有三个层次都满足时，观测者才感知到"经典现实"。**

## 可检验推论

### 推论1: 观测者分辨率极限

NISQ量子计算机(b1_obs ~ 10-100): PR_obs ~ 10^3-10^30。
足够"经典"可以读取测量结果。符合实际——量子计算机的输出是经典的。

单光子探测器(b1_obs ~ 10^5): 足够经典。

**预言:** 如果构建一个b1=1的"量子观测者"(单个qubit耦合到目标)，它"看到"的世界和人类看到的不同——对它来说，量子叠加是常态，经典确定是例外。

### 推论2: 坍缩的b1阈值

对d维量子系统，坍缩发生在 b1_obs < log2(d)。

单个qubit (d=2): b1_obs=1刚好够区分|0⟩和|1⟩，但不够区分|0⟩+|1⟩和|0⟩-|1⟩。
→ 需要b1≥2才能区分Bell基的四个态。

10-qubit系统(d=1024): 需要b1_obs≥10。
→ IBM Q的127-qubit Heron处理器(b1_obs~127)刚好够"经典地"观察所有输出态。

### 推论3: Wigner朋友悖论的DGF解

Wigner的朋友(F)在实验室测一个qubit。Wigner(W)在外面观察F+qubit。

- F的b1 ~ 10^23(人类): F看到qubit"坍缩"到|0⟩或|1⟩
- W的b1 ~ 10^23(也是人类): W看到F+qubit的整体量子态

但DGF说: F和W都是经典观测者(PR巨大)。F的测量在F的因果网络中创建了新环，新环将qubit信息泵入F的环境中。W再测量F+qubit时，W的信息分辨率不足以同时追踪F的所有内部环→W看到F"已经测过了"。

**这不是悖论——这是两个观测者的信息容量限制。**

关键是: **DGF量化了"谁是观测者"——b1就是答案。**
