## 核心发现

Gram矩阵的非对角元随环数n_rings指数衰减:

```
<|G_ab|> = exp(μ · n_rings)

μ = ⟨ln|p·e^{icΔ}+(1-p)·e^{-icΔ}|⟩_Δ

c=0.5: μ ≈ -0.47/ring  (强退相干)
c=π/2: μ = 0           (Clifford, 无退相干)
c→0:   μ → 0           (弱耦合, 无退相干)
```

对宏观物体: n_rings ~ 10^23 → <|G_ab|> ~ exp(-10^23) ~ 10^{-10^22} → 0。

Gram矩阵=单位矩阵→环境完美区分所有系统态→完全退相干→经典世界。

## 机制

```
每个因果环 = 一个信息筛子
  │
  ├─ 系统态|a⟩和|b⟩经过环r后
  │  环境态变成|φ_r(a)⟩和|φ_r(b)⟩
  │  overlap: ⟨φ_r(a)|φ_r(b)⟩ = p·e^{icΔ} + (1-p)·e^{-icΔ}
  │
  ├─ |overlap| ≤ 1 对所有Δ成立
  │  |overlap| < 1 对大多数Δ成立 (除非c∈(π/2)Z: Clifford)
  │
  └─ n_rings个环后:
     G[a,b] = ∏_r overlap_r
     |G[a,b]| = ∏_r |overlap_r| → 0 (指数衰减)
```

每个环把系统态的环境印记"拉开"一点。环数够多时，不同系统态的环境印记完全正交。

## 为什么不是所有东西都是经典的

关键: **μ依赖于Cartan参数c和delta分布。**

- 超导qubit: b1~1-10环, c被故意调到近Clifford → μ≈0 → 退相干慢
- 单个原子: b1~10^5环 (原子内部), 但c分布均匀 → μ中等 → 部分退相干
- 足球: b1~10^23, c随机分布 → μ≈-0.5 → 完全退相干

**b1和c共同决定退相干速率。** 小b1或近Clifford→量子存活。大b1且非Clifford→经典。

## 和量子计算的连接

量子纠错的基本矛盾:
- Clifford门(c=π/2): μ=0 → 不产生退相干 → 可以大量使用
- 非Clifford门(如T门, c=π/8): μ<0 → 产生退相干 → 每次使用都"经典化"一点
- 魔术态蒸馏: 用Clifford门+测量提取纯非Clifford资源 → 本质上是在对抗μ的积累

**DGF预言: 量子计算机的深度受限于非Clifford门产生的累积Gram衰减。**
修复所需的纠错开销由μ决定。
