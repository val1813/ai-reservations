## §1 卡口一：欧几里得结构的最小假设

### 1.1 出发方程

DGF框架的Level 0由以下结构定义：

```

配备Fubini-Study度规 g_FS。

**(Eq.1.2)** — Fubini-Study度规在齐次坐标 z = (z_0, ..., z_{N-1}) 下的显式形式：
```
ds²_FS = (|dz|²|z|² - |z·dz|²) / |z|⁴
```
其中各分量正定，号差为 (+,+,...,+)，即**全欧几里得**。

**(Eq.1.3)** — 对称性：CP^{N-1}的全纯等距群为 PU(N)，包含 U(N) 作为其覆盖。特别地，实的SO(2N)子群作用于齐次坐标的实部和虚部。在N足够大的极限下，局部各向同性意味着Level 0具有完整的**欧几里得对称性**：

**(Eq.1.4)** — q场在Level 0：q = 1（全空间未确定化）。所有格点处于|0⟩态。

### 1.2 文献支撑

**C2 (Greensite 1993)** 已经论证了将号差视为动力学变量的可行性。他的框架将度规推广为：
```
g_{μν} = e^a_μ η_{ab} e^b_ν,   η_{ab} = diag{e^{iθ}, 1, ..., 1}
```
其中 θ=0 对应欧几里得，θ=π 对应洛伦兹。这与我们的Level 0→Level 1转变在结构上对应：Level 0 = θ=0（欧几里得），Level 1 = θ=π（洛伦兹）。

Greensite的结论是Re[V(θ)]在θ=π时极小化，Im[V(θ)]驻定——且这一结果**仅在D=4时成立**。这为我们的声张提供了独立支撑：洛伦兹号差是动力学选择的结果。

**与Greensite的差异**：
- Greensite的θ是连续场（复标量场），我们的"θ"是离散的——要么是欧几里得（Level 0），要么是洛伦兹（Level 1），中间通过determination事件累积实现

### 1.3 卡口一的核心推导：最小假设

**(Step 1.3c)** — 最小假设清单（卡口一答案）：

### 2.2 文献中的类似问题

**(1) Hartle-Hawking无边界提案中的"从无中创生"**:

Hartle & Hawking (1983, Phys. Rev. D 28, 2960) 将宇宙的量子创生描述为从欧几里得几何（无时间）到洛伦兹几何（有时间）的转变。在他们的图景中，这一转变通过半经典近似中的"欧几里得-洛伦兹交接面"实现——不需要"外部触发"，因为量子力学允许无时间区域和时间区域在同一个路径积分中共存。

但他们的机制依赖路径积分的特定鞍点近似，且**不解释为什么交接面出现在特定位置（而非其他位置）**。

**(2) 因果集理论中的"第一个元素"**:

在因果集理论（Bombelli et al. 1987, Phys. Rev. Lett. 59, 521; Sorkin 2003, arXiv:gr-qc/0309009）中，偏序关系≺是基本关系。但标准因果集理论**不解释偏序从何而来**——它只是预设了偏序的存在。这是一个公认的缺口。

Kastner (2014, arXiv:1411.2072v1, B3) 在交易诠释下提出"时空本身仅凭借具体的事件实际化（actualized events）而存在"，这是最接近determination概念的思想。但她的"实际化"来自吸收体-发射体的对称交易，与我们的|0⟩→|1⟩不可逆不同。

**(3) 自发对称破缺中的"随机涨落"**:

标准量子场论中，对称破缺由真空涨落触发。但"涨落"预设了量子力学和时间的存在——这正是Level 0所缺乏的。我们不能在无时间的Level 0中援引"量子涨落"作为触发机制。

### 2.3 推导：第一个determination事件的可能机制

**(Step 2.3a)** — 排除不可能选项：

- ✗ **外部触发**: Level 0是全空间（无外部），无"外部"
- ✗ **量子涨落**: 预设时间演化，Level 0无时间
- ✗ **热涨落**: 预设统计力学和时间箭头
- ✗ **人为干预**: 不科学

**(Step 2.3b)** — 可能的机制候选：

**候选A: 几何自发性（Fubini-Study曲率的固有涨落）**

CP^{N-1}的FS度规有非零Ricci曲率。在有限N的情况下，CP^{N-1}的几何不是严格平滑的——它有量子几何的"纹理"（texture）。FS度规的Ricci张量为：
```
Ric_FS = N · g_FS   (CP^{N-1}是Einstein-Kähler流形)
```
曲率常数正比于N。在N有限时，是否存在一个最小曲率半径——在此之下几何概念失效？如果能证明FS度规在Planck尺度有内禀不确定性，则第一个determination事件可能由此触发。

**文献支撑**: B6 (Ambjorn & Loll 1998) 在2D量子引力中证明了空间在微观是分形的（Hausdorff维数4而非2），暗示量子几何在短距离有内禀的非光滑性。

**问题**: CP^{N-1}上的"尺度"概念尚未定义——N→∞极限下连续几何才涌现。在N有限时，"曲率半径"意味着什么？

**候选B: 容量有界假设（A2）的内禀不稳定性**

A2说每格点容量≤1 bit。如果Level 0是q=1的全|0⟩态，这意味着每个格点的信息熵为0。但A2的"≤1 bit"暗示可能有非零的最小信息容量（即1 bit的标记/地址信息）。如果格点在CP^{N-1}上的身份标记需要至少1 bit的信息来维持不可区分性（悖论性地说），则q=1的全零态在信息论意义上是不稳定的——它需要一个非零的基底熵。

**数学表述**: 每格点需要至少ε>0 bit的信息来标记其"存在但不被占用"的状态。ε→0+N→∞时系统在q=1处有一个信息论奇点（infomation-theoretic singularity）。

**候选C: 组合必然性（格点基数效应）**

如果N个格点全在|0⟩态，CP^{N-1}中只有一个点对应此构型（全零相干态）。但CP^{N-1}的几何中，这一点的邻域包含无穷多个"几乎全零但有少许|1⟩"的构型。在何种意义上系统"选择"了q=1而不是q=1-δ？

**文献支撑**: C5 (Kiefer 2009) 论证"自然边界条件"（低初始熵）可以被施加在宇宙波函数上。q=1是DGF框架中的极低熵态（minimal determination entropy = 0 bit），类似Kiefer的"低初始熵边界条件"。

**(Step 2.3c)** — 初步选择：候选B（信息论不稳定性）

在三个候选中，候选B最符合DGF框架的内在逻辑：
- A2（容量有界）本身就是DGF的假设之一，不需要引入外部概念
- 信息论奇点（q=1处的零熵）与Kiefer (2009)的低初始熵边界条件一致
- "标记存在而不被占用"正好是量子信息中qubit的vacuum定义问题的物理实现

**具体机制**（初步）：每个格点需要最少log₂(2)=1 bit来区分"被占用(|1⟩)"和"未被占用(|0⟩)"两种状态。但这1 bit的信息本身需要一个物理载体——如果全空间q=1意味着全零态，那么**这1 bit区分能力的物理基础是什么**？悖论导致q=1态的信息论自指矛盾，强制至少一个格点跃迁到|1⟩以解决此矛盾。

**问题**: 此论证有强烈的自指/哥德尔式味道。需要更精确的形式化——特别是"标记存在的1 bit"如何在CP^{N-1}的几何中体现。

## §3 卡口三：从退相干到闵可夫斯基号差

### 3.1 核心推导：大量determination如何选择洛伦兹号差

**(Step 3.1a)** — 已有结果的整合：

从C1 (Bermudez 2025)和C2 (Greensite 1993)我们知道，在连续场论框架中，洛伦兹号差作为动力学稳定点出现：

- **Greensite (1993)**: 有效势Re[V(θ)]在θ=π（洛伦兹）极小化，且这一结果仅在D=4时成立
- **Bermudez (2025)**: 曲率最小化势能的三个简并极小值（欧几里得/洛伦兹/混合）中，仅洛伦兹相支持因果传播

我们的任务是将这些连续场论结果**翻译到离散格点+determination事件的语言**。

**(Step 3.1b)** — DGF框架中的对应：

在DGF中，每个determination事件|0⟩→|1⟩产生一个**因果偏序链接**。当determination事件数量M≫1时，格点间的偏序关系形成一个因果集。

**关键映射**：
```
连续场论中的"因果传播" ⟷ DGF中的"偏序链的存在性"
连续场论中的"d'Alembert算子双曲性" ⟷ DGF中"偏序的方向一致性"
```

在欧几里得号差下，所有方向等价——偏序关系如果存在也将是各向同性的（无优先方向）。在洛伦兹号差下，存在一个优先方向（时间方向），偏序沿此方向传播。

**(Step 3.1c)** — 推导：为什么大量determination必然选择洛伦兹号差？

**引理1**（来自C1/Bermudez 2025）: 欧几里得号差不允许非平凡因果传播。在欧几里得号差下，传播子是对称的（Laplace型而非d'Alembert型），不区分过去和未来。

**引理2**（DGF定义）: determination事件的本质是|0⟩→|1⟩的不可逆跃迁。不可逆性预设了方向——即使单个determination事件的方向尚不足以定义全局时间方向。

**引理3**（统计论证）: 当M个determination事件独立发生时（M≫1），它们的方向偏序关系必须趋于一致，否则将产生矛盾（格点同时在两个不相容的偏序链中）。偏序一致性条件迫使所有determination事件对齐到一个共同的方向——这正是时间方向。

**引理4**（从B6/Ambjorn & Loll 1998）: 在2D量子引力中，欧几里得量子引力=洛伦兹量子引力+任意数量的baby universe。换言之，洛伦兹结构通过"消除闭合时间/baby universe"从欧几里得结构中提取。在DGF语言中，"baby universe"对应不与主偏序链连通的determination事件簇——它们被退相干排除。

**综合推导**:

**(Eq.3.1)** — determination事件的偏序链：
定义格点集 G，偏序关系 a≺b 表示"格点a的determination事件在因果上先于格点b的determination事件"。偏序的方向局部定义为：
```
t̂(a,b) = sign(τ(b) - τ(a))  if a≺b or b≺a
        = 0                    if a||b (spacelike)
```
其中τ是沿偏序链的序参数（不预设为连续时间）。

**(Eq.3.2)** — 偏序一致性条件：
当M足够大时，所有偏序链必须嵌入一个共同的d维闵可夫斯基时空（来自B1 Johnston 2025的因果集嵌入定理，推广到任意维数）。根据因果集理论的"haupvermutung"（基本猜想），一个足够大的因果集唯一地确定其嵌入时空的维数和号差。

**(Eq.3.3)** — 号差选择的退相干机制：
考虑Level 0的欧几里得"路径积分"（在CP^{N-1}上的FS测度）：
```

```
当determination事件引入后，偏序链约束将积分限制在满足因果一致性的构型子空间：
```
Z_1 = ∫_{CP^{N-1}} dμ_FS(z) · ∏_{a≺b} Θ(τ(b)-τ(a))
```
其中Θ是阶跃函数。这些Θ因子的累积效应等效于将欧几里得号差的权重函数替换为洛伦兹号差。

**类比文献支撑**: C4 (Hartle 2006) 在广义量子力学框架中论证了"必须有一个且只有一个时间方向"的涌现性质。我们的∏Θ因子是Hartle的广义量子力学中"退相干泛函"在离散格点版本中的实现。

**(Eq.3.4)** — 从SO(4)到SO(3,1)的对称破缺：
在Level 0，CP^{N-1}上的等距群包含SO(4)作为N→∞极限下的局部各向同性子群（Eq.1.3）。偏序链的引入打破所有方向之间的对称性——沿偏序链的方向成为时间方向(t̂)，正交方向保持欧几里得对称性SO(3)。因此：
```

### 深挖1：本轮结论的下一层后果是什么？

**第一层后果**: 如果洛伦兹号差确实通过determination事件的偏序对齐涌现，那么时间的单向性（从过去到未来）不是基本定律，而是determination事件链的**统计结果**。这意味着：
- "过去→未来"的方向在局部可能是模糊的——对于孤立的小determination事件簇，可能没有良好定义的时间方向。宇宙的极早期（first few determination events）可能没有全局时间箭头。
- 时间反演对称性在微观层面可能仍然保持，仅在大量determination的统计极限下被破缺。

**第二层后果（后果的后果）**: 如果在极早期（M≪N）存在"时间方向模糊"的阶段，这可能在CMB上留下可检测的痕迹。特别地：
- 如果早期determination事件的分布不均匀，可能会产生具有非平凡方向相关性的原初涨落——这可以用Planck/CMB-S4数据检验。
- 具体预言：在大角度尺度（低l）的CMB两点和三点关联函数中，可能存在偏离标准各向同性的微小但系统的信号。这与"宇宙在各向同性背景下的微小各向异性"（如"宇宙轴" anomaly）可能相关。

### 深挖2：本轮依赖的前提中，哪一个本身最可能也是错的？

**最可能错的前提**: **A2（每格点容量≤1 bit）中的不等式方向**。

理由：如果每格点容量严格≤1 bit，则格点只能区分两种状态（|0⟩或|1⟩）。但determination事件（|0⟩→|1⟩）作为不可逆过程，需要一个**元比特**来记录"此格点是否已经历过determination"——而这是第三个状态。A2的≤1 bit可能与determination的不可逆性在逻辑上不兼容。

替代假设: **A2'（每格点容量≤2 bit）** — 1 bit用于状态（|0⟩/|1⟩），另1 bit用于determination历史标记。这将稍微放松卡口二的约束（更容易触发第一个determination，因为信息容量更丰富），但代价是修改DGF框架的基本假设之一。

**检查A2'的后果**: 如果A2被替换为A2'，CP^{N-1}需要被替换为CP^{2^{2N}-1}（更大的量子态空间），但这改变了CP^{N-1}几何的Ricci曲率（从Ric∝N变为Ric∝2^{2N}），可能使Level 0的几何性质（如曲率奇点）在N有限时显著不同。这是一个值得在Round 2中探索的方向。
