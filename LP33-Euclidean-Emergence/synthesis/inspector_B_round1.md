## Q5. 代数验算

### Q5a. 逐步代数展开

**步骤1: Fisher定理翻译**
```
Fisher原始: d⟨w⟩/dt = V_A(w)    (w = 适应度)
B博士翻译: dρ_D/dt = κ · Var_spatial(ρ_D)   (ρ_D = determination密度)
```
- 替换: w → ρ_D, V_A(w) → κ · Var_spatial(ρ_D)
- V_A(w)（加性遗传方差）映射为Var_spatial(ρ_D)（空间方差）
- 引入额外参数κ（"遗传力"）
- ⚠️ **这不是推导，是类比映射**。Fisher定理的V_A(w)是种群中个体间适应度差异的可遗传部分，而Var_spatial(ρ_D)是空间中determination密度的方差。两者数学形式相同（都是方差），但物理含义不同。该方程应被视为**假设**而非**定理**。

**步骤2: CAP定理翻译**
```
CAP: C(一致性) ∧ A(可用性) ∧ P(分区容错) → 不可能
B翻译: 全局欧几里得对称(C) ∧ 局部洛伦兹因果(A) ∧ 未确定qubit(P) → 不可能
```
- 映射: C → 全局欧几里得对称性, A → 局部洛伦兹因果结构, P → undetermined qubit
- ⚠️ 核心问题: CAP的"C"指数据一致性（所有节点看到相同数据），B博士将其解释为"所有方向等价"（欧几里得对称）。这是两个不同的概念。解释为类比可接受，但不能声称CAP定理直接证明了物理结论。

**步骤3: Arrow定理翻译（⚠️ 本轮最需关注的问题）**
```

  个体集I, 备选方案集X, |X|≥3, |I|≥2
```

**⚠️ 严重映射问题详析**:

1. **独裁者映射错误**: Arrow原定理的结论是"存在一个独裁**个体**（qubit）"，而非"存在一个独裁**备选方案**（方向）"。B博士将结论中的独裁者从个体改为备选方案，这不是翻译而是修改。

3. **新定理需要独立证明**: 修改后的定理（Causal-Pareto + Causal-IIA + Directional-ND → 在D≥4时不可能）不等价于Arrow原定理。它是一个新的组合数学命题，需要独立证明。
