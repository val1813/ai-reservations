### Q5.2 χ_{ij} 推导完整性（§R3.4）

§R3.4 声称补全了从 Ric_FS = N·g_FS 到 χ_{ij} 的五步推导。逐步验算:

**Step 1: CP^{N-1} Einstein-Kähler 性质**

Ric_FS = N·g_FS — 标准结果。✅

**Step 2: 局部仿射坐标**

z_α (α=1,...,N-1)，z=0 对应 |ψ⟩，单激发态对应 z^{(i)}，|z^{(i)}|² = 1/N。✅

**Step 3: FS 度规二阶展开**

ds²_FS = Σ|dz_α|² - (1/N)|Σ z_α dz̄_α|² + O(|z|⁴)

这是 CP^{N-1} 上 FS 度规在仿射坐标中的标准展开。✅

**Step 4: 混合曲率张量 — ⚠️ 发现错误**

Round 3 声称:

```
R_{αβ̄γδ̄} = N · (g_{αβ̄} g_{γδ̄} + g_{αδ̄} g_{γβ̄})
```

**检查**: 对 CP^{N-1} 配备标准 FS 度规（规一化为使全纯截面曲率 ∈ [1,4]），曲率张量的标准形式为:

```
R_{αβ̄γδ̄} = g_{αβ̄} g_{γδ̄} + g_{αδ̄} g_{γβ̄}
```

**无 N 因子**。

验证: 取迹得到 Ricci 张量:
Ric_{γδ̄} = g^{αβ̄} R_{αβ̄γδ̄} = g^{αβ̄}(g_{αβ̄}g_{γδ̄} + g_{αδ̄}g_{γβ̄})
= (N-1)·g_{γδ̄} + g_{γδ̄} = N·g_{γδ̄} ✅

N 来自迹（g^{αβ̄}g_{αβ̄} = N-1），非来自曲率张量的前置因子。

Round 3 在 R_{αβ̄γδ̄} 前多加了一个 N 因子。这是**数学错误**。❌

**影响传播**: 若使用正确的 R = g⊗g + g⊗g（无 N 因子），则:
- 截面曲率 K(z^{(i)}, z^{(j)}) = 1 + |⟨z^{(i)}|z^{(j)}⟩_{FS}|²/(|z^{(i)}|²|z^{(j)}|²)
- χ_{ij} ∝ 1 + |⟨z^{(i)}|z^{(j)}⟩_{FS}|²/(|z^{(i)}|²|z^{(j)}|²)
- 非对角元 χ_{ij} ~ O(1/N)（因为随机方向内积 ~ 1/√N）
- 而非 Round 3 声称的 O(1)

**Step 5 的 χ_{ij} 结论受影响**: Round 3 声称 χ_{ij} ~ O(1)（非对角），但正确值应为 χ_{ij} ~ O(1/N)。这意味着:
- 耦合强度被高估了 N 倍
- 累积耦合能从 ~M²/N 变为 ~M²/N² —— 对对齐动力学的定量影响重大
- ρ_c 可能需要重新评估（更弱的耦合 → 需要更高的 ρ_c 才能产生对齐）

**与 Eq.R2.6 的关系**: Round 3 §R3.4.3 声称 Eq.R2.6 的 χ_{ij} ∝ (1/N)·|⟨i|j⟩_{FS}|² 需修正为 χ_{ij} ∝ N³·|⟨i|j⟩_{FS}|²。但在正确的曲率张量下，χ_{ij} ∝ |⟨z|z⟩|² = N²·|⟨i|j⟩_{FS}|² → 不含 N³。

**结论**: χ_{ij} 推导补全不完整——Step 4 的曲率张量公式有数学错误。❌⚠️
