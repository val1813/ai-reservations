## Q3. 循环论证校对

### 检查1: 因果集嵌入→洛伦兹号差 是否为循环？

**论证结构**:
1. determination 事件生成偏序 ≺
2. 偏序构成因果集 (C,≺)
3. Johnston 算法将因果集嵌入闵可夫斯基时空
4. 嵌入目标流形是闵可夫斯基的 → 号差(-,+,+,+)

**循环风险**: Johnston 算法以 d 和闵可夫斯基时空结构作为输入。算法的第一步——定义 τ(v_x,v_y) = (|interval|/ρc_d)^{1/d}——使用了亚历山德罗夫区间在d维闵可夫斯基时空中的体积公式（c_d 依赖于 d）。这意味着算法**预设**了嵌入目标是闵可夫斯基时空。算法的作用是**检验**因果集是否与闵可夫斯基因果结构一致，而非**产生**号差。

A博士在深挖1（§末）中面对了这个问题并给出回应：
- "Johnston嵌入算法的目标流形确实预设为闵可夫斯基时空"
- "faithful embeddability本身不是预设的——它是需要检验的条件"
- "关键非循环点：我们**没有**预设 M > M_c"

**PI评估**: 这个回应**部分有效但不完全**。对于"是否循环"的问题：
- 如果论点是"嵌入算法**推导出**洛伦兹号差"，则是循环（算法以洛伦兹号差为输入）。
- 如果论点是"嵌入算法**检验**因果集是否具有洛伦兹号差的结构"，则非循环。
- Round 2 的声张更接近后者（§R2.1.3 Eq.R2.4 明确说"号差是嵌入目标流形的固有属性"），但文档在多处暗示前者（如 §R2.1.2 "嵌入自动产生洛伦兹号差——不需要Wick转动"）。

⚠️ **非循环但声张需降级**: 不是经典循环论证，但"嵌入自动产生号差"的措辞容易误导。准确说法："如果因果集可被faithfully嵌入闵可夫斯基时空，则其连续极限的号差为洛伦兹。"这比"自动产生"更诚实。

### 检查2: 候选A（几何自发性）是否为循环？

**论证结构**: CP^{N-1} 正 Ricci 曲率 → 全零态有几何不确定性 Δz ~ 1/√N → 此不确定性与到单激发态的距离可比 → 自发跃迁 → 第一个 determination

**非循环**。论证从已知几何性质出发，不预设结论。✅

### 检查3: 铁磁耦合→方向对齐 是否为循环？

## Q5. 代数验算

### 5a. 核心声张逐步代数展开

#### 5a-1: 因果集嵌入路径（替代Eq.3.3）

**Round 1 问题**: ∏Θ因子声称等效于Wick转动——两者是不同类的数学操作。

**Round 2 新路径**: determination → 偏序 → 因果集 → Johnston嵌入 → 号差从嵌入目标涌现。

**逐步展开验证**:

(a) determination 事件生成偏序：|0⟩→|1⟩ 的不可逆性 → 如果 a 的 determination 通过 SRC 触发了 b 的 determination，则 a ≺ b。这在 DGF 框架内是自然的——偏序关系直接从 determination 的不可逆性 + SRC 耦合中产生。✅

(b) 偏序集合构成因果集：需要局部有限性（任意两个事件之间只有有限个事件）。对于有限格点网络（N<∞），这是自动满足的。✅

(c) Myrheim-Meyer维度估计：R/M² → Γ_d。其中 Γ_d 的值 d=2,3,4 分别为 0.5, ≈0.298, ≈0.201。这些值可以从因果集文献（Myrheim 1978, Meyer 1988, Surya 2019）验证。✅

(d) Johnston 算法描述——**实际验证**：

Round 2 §R2.1.3 将 Johnston 2025 算法描述为以下步骤：
```
1. t(e) = |{e' ∈ C : e' ≺ e}|    ← "沿最长链的步数"
2. d_s²(a,b) = [t(b)-t(a)]² - V(a,b)^{2/d}
3. 三角不等式用于推导类空距离
4. MDS 分解获得嵌入坐标
5. badness-of-fit 度量嵌入质量
```

**对比实际 Johnston 2025 论文 [arXiv:2502.09701v2, Phys. Rev. D 111, 106020]**:

实际算法步骤：
```
1. τ(v_x,v_y) = (|interval|/ρc_d)^{1/d}    ← 体积定义proper time，非最长链
2. t(v_x) = T/2 + (τ(v_1,v_x)² - τ(v_x,v_n)²)/(2T)    ← 时间坐标
3. r(v_x,v_y) = √|(t(v_x)-t(v_y))² - τ(v_x,v_y)²|    ← 因果对的空间距离
4. 三角不等式（min r(x,z)+r(y,z) over common past/future）→ 类空距离
5. MDS → 空间坐标，加上t(v_x) → 完整嵌入
```

❌ **差异1**: John 2025 **不使用最长链**作为时间坐标。论文明确说："Note that some past work has suggested the length of the longest chain as a measure of the proper time... However, we follow the volume-based approach here since it gives a better approximation with less statistical noise."

❌ **差异2**: Johnston 2025 **未使用 badness-of-fit** 作为质量度量。实际使用：sensitivity/specificity（因果关系匹配）、坐标相关性、Minkowski距离相关性、空间距离相关性。

❌ **差异3**: Johnston 2025 的空间距离公式 r(v_x,v_y) = √|(t(v_x)-t(v_y))² - τ²| 与 Round 2 的 d_s² = [t(b)-t(a)]² - V(a,b)^{2/d} 不等价。Johnston使用已计算的τ和t，而非直接从V计算。

**严重性评估**: Round 2 声称"Johnston (2025, arXiv:2502.09701v2)"但对其算法的描述在多个关键细节上与实际论文不一致。这不仅是"简化"——是**不准确定**。虽然是细节层次的差异（最长链 vs 体积-based，badness-of-fit vs 相关度），但(a) 这表明算法描述可能来自二手文献而非一手论文；(b) 最长链方法与体积方法在有限M下有显著统计差异；(c) "badness-of-fit"阈值（作为M_c的判据）在Johnston 2025中不存在。

⚠️ **Q5a警告——算法描述不准确**: Johnston 2025算法的描述与实际情况有实质性差异。这不是阻断级问题（描述的算法仍然是一个合法的因果集嵌入方法，只是不是Johnston 2025的方法），但需要诚实修正算法描述或引用正确的来源。

#### 5a-2: CP^{N-1} Kähler耦合机制

**Eq.R2.5**: |ψ_0⟩ = |0⟩^{⊗N} → |ψ_1⟩ = (1/√N) Σ_i |0...1_i...0⟩

验证：这是全对称单激发态（W态），在置换对称性下（A3）是唯一合法的单激发态。归一化：N项×(1/√N)² = N×(1/N) = 1。✅

**Eq.R2.6**: χ_ij = ∂²d_FS(X_i|ψ⟩, X_j X_i|ψ⟩) / ∂n_i ∂n_j

问题：
1. 二阶混合偏导的自变量 n_i 是切空间中的方向，但 FS 距离 d_FS 是态空间中的距离。需要证明 d_FS(X_i|ψ⟩, X_j X_i|ψ⟩) 对 n_i 和 n_j 二阶可导。
2. 通式 χ_ij ∝ (1/N)|⟨i|j⟩_FS|² 是从 Ricci 曲率标度推的——但未展示从曲率到具体耦合矩阵元的计算。论证跳过了"从 Ric_FS = N·g_FS 到 χ_ij ∝ 1/N"之间的步骤。

⚠️ **Q5a警告——耦合推导不完整**: χ_ij 的推导链有跳跃。Ric_FS = N·g_FS 是全局曲率标度，χ_ij 是局部耦合矩阵元。从全局曲率到局部耦合的具体形式需要额外计算（如 CP^{N-1} 上切空间的截面曲率分解），这部分在文档中缺失。

**Eq.R2.7**: P(v_{k+1}|v_1,...,v_k) ∝ exp(Σ χ_{i_{k+1}, i_j} · v_{k+1}·v_j)

铁磁型耦合的指数形式是标准的（如 Ising 模型的玻尔兹曼权重），但在 DGF 语境中，这个概率分布在什么"温度"下成立？指数中缺少类似 β = 1/kT 的参数。如果"量子不确定性"起温度的角色，需要一个将量子涨落转化为等效温度的桥接公式。⚠️

**Eq.R2.8**: ρ_c ~ 1/√N

平均场论证：铁磁耦合强度 J ~ 1/N，每个自旋的配位数 z ~ N → 总耦合能 N·(1/N) = O(1) → 临界温度 T_c ~ O(1) → 在固定"温度"下，临界密度 ρ_c 满足 ρ_c·z·J ~ "T" → ρ_c·N·(1/N) ~ const → ρ_c = const。这给出 α=0，而非 1/√N。

要得到 ρ_c ~ 1/√N，需要 z·J ~ 1/√N 或者有不同的标度论证。Round 2 没有提供这个论证——它只给出了结论。

⚠️ **Q5a警告——ρ_c ~ 1/√N 的推导缺失**: 平均场论证给出的实际是 ρ_c = const（α=0），与 §R2.5.1 中 α=1/4 的声称不一致，也与此处 α=1/2 不一致。ρ_c 的标度指数在文档中实际上有三个不同的值（0, 1/4, 1/2），取决于采用哪个论证。

### 专项1: ∏Θ→因果集嵌入 — 是否真正避免了等价性问题？

**Round 1 问题**: Θ因子约束积分域 ≠ Wick转动改变权重。声称两者等同是物理直觉伪装成数学推导。

**Round 2 方案**: 放弃∏Θ路径。切换为：determination → 偏序 → 因果集 → Johnston嵌入 → 号差来自嵌入目标流形。

**评估**: ✅ **等价性问题被真正避免了**——新路径根本不涉及Wick转动。路径积分框架、Θ因子、欧几里得权重函数在Round 2中都不再出现。

但新路径**产生了自己的问题**:

1. **依赖链延长**: DGF→偏序（DGF内部）→因果集（标准理论）→Johnston嵌入（2025算法）→号差（嵌入目标属性）。DGF的角色从"推导号差"变为"提供偏序起源"——这是一个更窄的声张。

2. **嵌入预设号差**: Johnston算法以Minkowski目标流形为输入。如果因果集可嵌入，则号差一致性确认；如果不可嵌入，则无有效号差。但算法的启动需要**假设**嵌入目标——这是一个"如果可嵌入，则可嵌入"的判据结构。

3. **算法描述不准确**: Round 2声称的"Johnston 2025算法"在3个技术细节上与实际情况不符（见Q5a）。

**综合判定**: 等价性问题已修复，声张已诚实降级，但新路径需要(i) 纠正算法描述，(ii) 更精确地陈述DGF在号差涌现中的角色。
