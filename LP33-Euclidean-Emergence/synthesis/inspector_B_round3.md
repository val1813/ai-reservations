### Q5c. AB框架对接的映射准确性

**§3.1 三位一体框架图**:

```
DGF核心 → 因果偏序起源
         ↙          ↘
Arrow聚合路径      因果集嵌入路径
→ 独裁方向          → Johnston嵌入
→ (-,+,+,+)        → (-,+,+,+)
         ↘          ↙
         闵可夫斯基号差
```

检查: 两条路径是否独立产生(-,+,+,+)？

- **Arrow路径**: Arrow定理 → 独裁qubit → 恰好一个优先方向 → 号差中恰好一个(-)。Arrow不指定空间维度数或号差中(+)的数量 → 不独立产生"(-,+,+,+)"，而是产生"恰好一个(-)，其余为(+)的号差"。如果D=4（来自物理约束），则为(-,+,+,+)。如果D=6，则为(-,+,+,+,+,+)。箭头应显示"恰好一个(-)号"而非完整的"(-,+,+,+）"。

- **因果集嵌入路径**: Myrheim-Meyer维度估计读出d=4 → 嵌入闵可夫斯基 → 号差自动为(-,+,+,+)。此路径产生完整号差。

⚠️ 当前图将两条路径都画为产生"(-,+,+,+)"。Arrow路径实际上只产生"恰好一个(-)"（不指定(+)的数量）。这一简化在文本中有补充说明（§1.4:"为什么D=4？...不是Arrow定理的推论"），但图中的等位表示可能引起误解。

不过，B博士在§3.2表格中正确区分了两条路径的不同贡献（A→号差的几何涌现机制，B→为什么恰好一个时间方向），图是简化示意。标记为⚠️ 图的简化可能引起误解——建议在图中Arrow路径的箭头下加注"(恰好一个(-)号, D维由因果集/实验确定)"。
