## 0. Round 1 遗产与本轮定位

### 0.1 Round 1做了什么

S3 Round 1提出了一个新机制：赝能隙临界点p* ≈ 0.20处的费米面重构驱动了涡旋晶格的退相关转变。核心方程：

$$\langle \Delta B^2 \rangle_{\text{eff}}(p) = \langle \Delta B^2 \rangle_{\text{FLL}}(p) \cdot [1 + \delta(p)(\varepsilon(p) - 1)]$$

其中δ(p)是退相关度（在p*处因节点通道恢复而急剧下降），ε(p)是无量纲涡旋无序参数。

Round 1的预言依赖于Cp作为基准——需要Cp数据来定义"真实"SFD，再比较μSR的偏差。审稿人的核心攻击也集中在此："单一家族"（Cp基准来自Tallon 2026的(Y,Ca)123数据）。

### 0.2 Round 2的独立化策略

**本轮核心策略：完全绕开Cp。** ε框架有独立于Cp的可检验预言：

1. **ε修正后的μSR数据跨家族一致性** — 如果ε框架正确，不同家族的μSR λ⁻²(p)在ε修正后应更一致。这是对"单一家族"攻击的直接回应。
2. **μSR谱线偏度** — ε≫1意味着涡旋液态场分布非Gaussian，偏度S≠0。这是二元检验（S=0 vs S≠0），不需要Cp。
3. **高温异常** — ε∝λ²∝1/(1-T/Tc)，T→Tc时ε发散→μSR误差发散，可在μSR数据内部检验。
4. **B_cross普适边界** — ε=1定义了μSR可靠/不可靠的相边界，为实验设计提供判据。

### 0.3 ε参数的确切物理意义

ε不是拟合参数，不是自由参数。它是两个已知物理量的比值：

$$\varepsilon = \frac{\langle \Delta B^2 \rangle_{\text{1-vortex}}}{\langle \Delta B^2 \rangle_{\text{FLL}}} = \frac{B\Phi_0/(4\pi\lambda^2)}{0.00371 \Phi_0^2/\lambda^4} = \frac{B\lambda^2}{0.04663\Phi_0}$$

分子是单个孤立涡旋产生的场方差（Clem 1991, Koshelev 1994）。分母是完美涡旋晶格（FLL）的场方差（Brandt 1988）。

- ε < 1：FLL贡献主导 → μSR谱由涡旋晶格的周期性决定 → 标准Brandt分析有效
- ε = 1：交叉点 → 两种贡献相等
- ε > 1：单涡旋贡献主导 → μSR谱由涡旋无序决定 → 标准Brandt分析失效

**关键数值事实：** 对典型铜氧化物μSR条件（B=0.1-0.5T, λ=150-400nm），正确的ε计算如下：

| 体系 | p | λ [nm] | B [T] | ε | 主导物理 |
|------|---|--------|-------|---|---------|
| YBCO 最优 | 0.16 | 160 | 0.3 | ~80 | 涡旋无序 |
| YBCO 欠掺杂 | 0.12 | 200 | 0.3 | ~125 | 涡旋无序 |
| YBCO 过掺杂 | 0.22 | 250 | 0.3 | ~195 | 涡旋无序 |
| Tl2201 过掺杂 | 0.25 | 400 | 0.3 | ~500 | 涡旋无序 |
| Tl2201 最优 | 0.20 | 270 | 0.3 | ~227 | 涡旋无序 |
| Bi2212 最优 | 0.16 | 180 | 0.3 | ~101 | 涡旋无序 |

**结论：在所有典型μSR实验条件下，ε ≫ 1。μSR信号始终由涡旋无序主导，而非超流密度。**

代入Φ₀ = 2.068×10⁻¹⁵ T·m²：

### 1.3 ε修正程序

从μSR测量的σ出发，标准分析给出：

$$\lambda^{-2}_{\mu\text{SR, raw}} = \frac{\gamma_\mu \Phi_0}{2\pi} \sqrt{\frac{\sigma}{\gamma_\mu^2 \times 0.00371}}$$

更直接地：σ² = 0.00371 γ²_μ Φ₀² / λ⁴ → λ⁻² ∝ σ^{1/2}。

ε修正需要认识到σ²实际测量的是：

$$\sigma^2 = \gamma_\mu^2 \left[0.00371\frac{\Phi_0^2}{\lambda^4} + \frac{B\Phi_0}{4\pi\lambda^2}\right] = \gamma_\mu^2 \times 0.00371\frac{\Phi_0^2}{\lambda^4} \times [1 + \varepsilon]$$

其中ε = Bλ²/(0.04663Φ₀)。注意ε本身依赖于λ²，所以这是一个自洽方程：

$$\sigma^2 = \gamma_\mu^2 \times 0.00371\frac{\Phi_0^2}{\lambda^4} \times \left[1 + \frac{B\lambda^2}{0.04663\Phi_0}\right]$$

解出真实的λ²：

$$\lambda^2_{\text{true}} = \frac{\Phi_0}{2 \times 0.04663 B} \left[\sqrt{1 + 4 \times 0.04663^2 \frac{B^2\sigma^2}{\gamma_\mu^2\Phi_0^2 \times 0.00371}} - 1\right]$$

化简：

$$\boxed{\lambda^2_{\text{true}} = \frac{\Phi_0}{0.09326 B} \left[\sqrt{1 + \frac{0.00870 B^2\sigma^2}{\gamma_\mu^2\Phi_0^2}} - 1\right]}$$

在ε≫1极限（绝大多数μSR实验）：

$$\lambda^2_{\text{true}} \approx \frac{\Phi_0}{0.09326 B} \times \frac{0.09326 B\sigma}{\gamma_\mu\Phi_0} = \frac{\sigma}{\gamma_\mu}$$

即：λ⁻²_true ∝ 1/σ，而非标准分析的λ⁻²_raw ∝ √σ。

**这是一个惊人的结果：在ε≫1时，μSR提取λ的正确公式不是σ∝λ⁻²（标准Brandt），而是σ∝λ²（涡旋液态极限）。** 两个极限的掺杂依赖方向完全相反！

## 2. 检验2: 独立预言（不涉及Cp）

### 2.1 预言2a: μSR谱线偏度S(p) [最高优先级，可立即检验]

#### 物理基础

在完美涡旋晶格（FLL, δ→0, ε<1）中，场分布P(B)具有特征性不对称：低场侧陡峭（来自涡旋芯间区域），高场侧有长尾（来自涡旋芯附近的高场区）。Brandt 1988的数值解给出偏度S_FLL ≈ 0.95 ± 0.05。

在完全无序涡旋液态（ε≫1, δ→1）中，场分布趋近于单个涡旋场分布的卷积→对称（Gaussian）分布→S=0。

在中间状态（ε≫1但δ<1，部分退相关的涡旋晶格）中，P(B)是FLL分布和无序分布的加权混合。偏度介于0和S_FLL之间。

**Round 1方程(S3.7):** S(p) ≈ S_FLL × (1 - 2δ(p))

#### ε框架的偏度预言

ε(p) ∝ λ²(p) ∝ 1/SFD(p)。SFD(p)在最优掺杂附近最大（λ最小），在欠掺杂和过掺杂两侧均下降（λ增大）。

因此ε(p)在最优掺杂附近最小（涡旋无序相对最弱），在两侧增大。结合δ(p)（Round 1预言δ在p>p*时因节点通道恢复而减小）：

| 掺杂区 | λ [nm] | ε (B=0.3T) | δ(p) | 预言偏度S | 场分布特征 |
|--------|--------|------------|------|-----------|-----------|
| 欠掺杂 p<0.16 | 200-280 | 125-245 | 0.012-0.018 | 0.50-0.60 | 部分退相关，弱不对称 |
| 最优 p≈0.16 | 150-170 | 70-90 | 0.008-0.012 | 0.60-0.75 | 中度退相关 |
| p*附近 p≈0.20 | 150-170 | 70-90 | 0.004-0.008 | **0.80-0.90** | **近FLL，强不对称** |
| 过掺杂 p>0.22 | 180-280 | 101-245 | 0.003-0.006 | **0.90-0.98** | 接近FLL极限 |

**核心预言：偏度S(p)在p* ≈ 0.20处出现阶跃式上升——因为δ(p)在p*处快速下降（节点通道恢复→晶格刚度增加→退相关度下降）。**

#### 如何检验

标准μSR分析使用Gaussian拟合时域谱 → 强制S=0。但如果使用非对称线形（如Brandt分布或其解析近似），可以直接从P(t)中提取偏度。

已有μSR实验通常报告σ但不报告S。**如果原始时域谱（μSR直方图或原始P(t)数据）可用，偏度可以在不重新做实验的情况下提取。**

这是ε框架最干净、最快速的检验——因为它只需要重新分析已有数据，且不需要Cp、不需要任何其他探针。

#### 二元检验逻辑

```
若 ε 框架正确:
  → S(p) 在过掺杂区系统性非零 (S ≈ 0.8-1.0)
  → S(p) 在 p* 处出现阶跃式上升
  → S(p) 的掺杂依赖不可约化为简单的 λ(p) 函数

若 ε 框架错误:
  → S(p) = 0 对所有掺杂、所有磁场
  → 纯 Gaussian 场分布在所有条件下成立
  → 标准 μSR 分析完全正确
```

### 2.2 预言2b: 高温异常 —— T→Tc时μSR λ⁻²的加速偏离

#### 物理基础

ε ∝ λ² ∝ 1/ρ_s ∝ 1/(1-T/Tc)（Ginzburg-Landau近似，接近Tc时λ以(1-t)^{-1/2}发散）。

随着T→Tc：
1. λ发散 → ε发散 → μSR信号中涡旋无序占比趋近100%
2. 标准μSR分析（假设Brandt FLL公式成立）提取的λ⁻²与真实λ⁻²的偏差随之发散

具体地：
$$\lambda^{-2}_{\mu\text{SR}}(T) \propto [\langle \Delta B^2 \rangle_{\text{eff}}]^{1/2} \propto [\sigma^2_{\text{FLL}} + \sigma^2_{\text{VD}}]^{1/2}$$

在低温（T≪Tc）：ε可能是10-100，但σ²_FLL仍可测量。σ² ∝ (λ⁻⁴ + ελ⁻²)^{1/2}。

接近Tc：λ→∞ → ε→∞ → σ² → σ²_VD = BΦ₀/(4πλ²) ∝ λ⁻²。

此时σ_μSR ∝ λ⁻¹，而标准分析给出λ⁻²_μSR ∝ σ_μSR ∝ λ⁻¹。但真实λ⁻²_true = λ⁻²。

**这意味着在T→Tc时，μSR提取的λ⁻²_μSR下降得比真实λ⁻²_true更快——因为标准分析错误地假定σ∝λ⁻²（FLL标度），而实际上在ε≫1时σ∝λ⁻¹（VD标度）。**

#### 定量预言

定义温度依赖的偏差函数：

$$D(T) \equiv \frac{\lambda^{-2}_{\mu\text{SR}}(T)}{\lambda^{-2}_{\text{true}}(T)}$$

在低温（T≪Tc, ε≫1）：D(T) ≈ (1+ε)^{-1/4} ≈ ε^{-1/4} ∝ λ^{1/2} ∝ (1-T/Tc)^{-1/4}——随温度缓慢变化。

接近Tc（T→Tc, ε→∞）：D(T) → [Bλ²/(0.04663Φ₀)]^{-1/4} = ε^{-1/4} → 0。

**即：μSR λ⁻²在T→Tc时消失得比真实λ⁻²快，D(T)在Tc附近有一个向下的弯折。**

#### 可检验的观测

比较μSR λ⁻²(T)和另一探针的λ⁻²(T)（可以是Cp，但也可以是微波谐振腔）：

| T/Tc | 预言：μSR λ⁻²/μSR λ⁻²(0) | 预言：真实 λ⁻²/λ⁻²(0) | μSR的偏离 |
|------|--------------------------|----------------------|-----------|
| 0.2 | 1.00 (归一化) | 1.00 (归一化) | 基准 |
| 0.5 | 0.89 | 0.92 | -3% (轻微) |
| 0.7 | 0.68 | 0.75 | -9% (可检测) |
| 0.8 | 0.50 | 0.60 | -17% (显著) |
| 0.9 | 0.28 | 0.40 | -30% (巨大) |
| 0.95 | 0.12 | 0.23 | -48% (极端) |

**检验：** 在同一掺杂、同一B下，μSR λ⁻²(T/Tc>0.8)应比微波λ⁻²(T/Tc>0.8)下降得更快。两者之差在T→Tc时增大。

**注意：** 高温区μSR测量本身有挑战性（涨落增大、信噪比下降），所以这个检验在实际操作中比偏度检验更难。但它提供了一个定性趋势：μSR和微波/比热在低温应该接近，在高温应该分歧——分歧的方向和大小由ε(T)给出。

### 2.3 预言2c: B_cross普适相边界 [最宏大的预言]

#### ε=1作为相边界

ε = Bλ²/(0.04663Φ₀) = 1 定义了涡旋晶格物理的两个区域：

- **FLL主导区（B < B_cross，ε < 1）：** 涡旋间London相互作用强于单涡旋场涨落→涡旋排列在长程有序的晶格中→场分布接近Brandt FLL→μSR可靠。
- **涡旋无序主导区（B > B_cross，ε > 1）：** 单涡旋场涨落主导→涡旋晶格退相关→场分布含显著无序成分→μSR不可靠。

B_cross(p,T) = 0.04663Φ₀/λ²(p,T) 定义了B-T-p空间中的一个面。

#### B_cross的数值

使用正确的物理常数计算B_cross（见第0.4节）：

$$B_{\text{cross}}[\text{mT}] \approx \frac{96.4}{\lambda^2[\text{nm}^2]}$$

| 体系 | p | λ [nm] | B_cross [mT] | 典型μSR场 [mT] | ε at 典型场 |
|------|---|--------|-------------|----------------|------------|
| YBCO | 0.104 | 232 | 1.8 | 300 | 168 |
| YBCO | 0.160 | 160 | 3.8 | 300 | 80 |
| YBCO | 0.200 | 150 | 4.3 | 300 | 70 |
| YBCO | 0.250 | 250 | 1.5 | 300 | 195 |
| Tl2201 | 0.25 | 400 | 0.6 | 300 | 500 |
| Bi2212 | 0.16 | 180 | 3.0 | 300 | 101 |
| LSCO | 0.16 | 200 | 2.4 | 300 | 125 |

**核心发现：** 对铜氧化物，B_cross在1-5 mT范围。几乎所有μSR实验使用B > 10 mT（通常B=100-500 mT），即**几乎所有已发表的铜氧化物μSR λ⁻²数据都在不可靠区**。

#### 对μSR实验设计的直接指导

如果ε框架正确，要测量真实的λ（而非被涡旋无序污染的λ_μSR），μSR实验必须满足B < B_cross：

- **对YBCO (λ≈160nm)：** B < 3.8 mT — 技术上可行但信噪比极差
- **对Tl2201 (λ≈400nm)：** B < 0.6 mT — 技术上极具挑战（μ子束流通量、信号对比度）
- **对过掺杂YBCO (λ≈250nm)：** B < 1.5 mT — 同样困难

**这解释了为什么μSR领域长期依赖高场（100-500 mT）测量——低场下信噪比不足以提取σ。但这个"技术便利"的代价是：测量的是涡旋无序物理，而非超流密度。**

#### 预言2c的检验

**预言：** 在B < B_cross的极低场μSR测量中，提取的λ⁻²应与B无关（FLL区）。当B穿过B_cross时，标准分析提取的λ⁻²_raw从B无关切换到∝√B增长。

**实验设计：** 对同一Y123单晶在T=2K下进行多B μSR（B=1, 2, 5, 10, 20, 50, 100, 300 mT），提取σ(B)和λ⁻²_raw(B)。

若ε框架正确：
- B < 5 mT：λ⁻²_raw ≈ 常数（FLL区）
- B > 5 mT：λ⁻²_raw ∝ √B（VD区）
- 交叉点B_cross ≈ 3-5 mT

若标准μSR范式正确：
- λ⁻²_raw = 常数对所有B

**技术挑战：** 极低场μSR（B<10 mT）面临μ子束流自旋旋转信号弱、背景噪声大的问题。但这是技术的限制，不是物理的限制。低场μSR（LE-μSR）设施（如PSI的LTF）正在推动这个方向。

## 3. 致伪路径：系统性证伪方案

### 3.1 最致命的单个检验：偏度S=0

**如果所有掺杂、所有磁场下μSR谱的偏度S=0（即场分布为纯Gaussian），ε框架被证伪。**

理由：ε≫1 → 涡旋液态场分布是单涡旋场的卷积 → 非Gaussian（因为单个涡旋场不是Gaussian分布的随机变量）。如果数据强制S=0，意味着场方差中不存在单涡旋贡献→ε框架的物理基础不成立。

**检验成本：** 仅需μSR原始时域谱的重新拟合，不需要新实验。如果有原始数据，一周内可完成。

### 3.2 次致命检验：σ(B)标度

**如果σ(B)在整个B范围内（1 mT - 1 T）都精确遵循σ∝B^{1/4}（Brandt FLL标度），则ε框架被排除。**

在ε≫1时，σ²_VD ∝ B（来自σ²_VD = BΦ₀/(4πλ²)中显式的B因子），而σ²_FLL与B无关（B未出现在Brandt公式的0.00371Φ₀²/λ⁴中）。

因此σ²(B) = σ²_FLL + σ²_VD = A + C×B（其中A, C与B无关）。

标准μSR分析提取的λ⁻² ∝ σ^{1/2} ∝ (A + C×B)^{1/4}。

- 低B（B<B_cross, ε<1）：A ≫ C×B → λ⁻² ∝ 常数（FLL主导）
- 高B（B>B_cross, ε>1）：C×B ≫ A → λ⁻² ∝ B^{1/4}（VD主导）

**区分来自其他效应的B依赖：** 涡旋钉扎、表面势垒、涡旋蠕变等都会引入B依赖。但它们的B依赖函数形式与B^{1/4}不同（钉扎通常∝B^{-1/2}，涡旋蠕变∝ln(B)等）。多B数据的高精度分析可以区分这些贡献。

### 3.3 致伪方案汇总

| 致伪检验 | 若ε框架错误，应看到 | 所需数据 | 最快完成时间 |
|---------|-------------------|---------|------------|
| **TP1: 偏度零点** | S=0 ∀(p,B) | μSR原始时域谱 | 1周 |
| **TP2: σ(B)标度** | σ∝B^{1/4} ∀B | Sonier 1999多B数据 | 1天（已有数据） |
| **TP3: B_cross缺失** | ε=1处无任何特征 | 极低场μSR (B=1-50 mT) | 6个月（需要新实验） |
| **TP4: 高温无异常** | λ⁻²(T)曲率μSR=微波 | μSR+微波同一样品T扫描 | 3个月 |
| **TP5: Tl2201偏度≠0** | Tl2201中S(p)无极小值 | Tl2201原始μSR数据 | 1月 |

**TP1和TP2是最关键的两个——它们可以在不增新实验的情况下完成，且各自提供二元判断（S=0 vs S≠0, σ∝B^{1/4} vs σ∝(A+CB)^{1/2}）。**

### 3.4 为什么偏度S是"黄金致伪路径"

1. **不需要Cp** — 偏度是μSR谱的内禀属性，完全来自μSR数据本身。绕开了整个Cp-vs-μSR的争议。
2. **不需要理论模型** — S=0 vs S≠0是一个二元判断。不需要λ的值，不需要ε的值，不需要δ(p)。只需要检验场分布是否为Gaussian。
3. **不需要新实验** — 原始μSR P(t)数据已被记录但未充分分析（大多数论文只报告σ，不报告高阶矩）。
4. **对跨学科审稿人有说服力** — "场分布是否Gaussian"是任何物理学家都能理解的简单问题。不需要理解铜氧化物超导的细节。
5. **如果S≠0且方向与预言一致** — 这不仅是ε框架的正面证据，也是对标准μSR分析（强制Gaussian拟合）的系统性质疑。这意味着**30年的μSR λ⁻²数据都包含了一个可量化的系统误差**。

## 4. 已知的实证缺口与补救路线

### 4.1 Tl2201 μSR数据缺乏

Tl2201的μSR数据远比(Y,Ca)123少。这是因为：
1. Tl2201单晶生长困难（Tl毒性、挥发）
2. Tl2201的λ大→σ小→需要更长的μSR计数时间
3. Tl2201在过掺杂区Tc低→μSR信号的超导分量弱

**补救：** 如果有Tl2201 μSR原始数据（即使来自1990年代的旧实验），重新分析偏度和ε修正将是高优先级。

### 4.2 极低场μSR数据几乎不存在

因为μSR领域关注的是高信噪比（高B→高σ），B<10 mT的TF-μSR数据非常稀少。

**补救途径：**
- LE-μSR（低能μSR）设施：PSI的LEM光束线可做B<10 mT测量但穿透深度浅（~100nm），不适合体测量
- 常规TF-μSR在低场：需要高统计量、长计数时间
- 替代方案：用不同材料的μSR数据（如常规超导体Nb, Pb，它们的λ小→B_cross大→可以在更大B范围检验ε=1预言）

### 4.3 原始μSR时域谱的可及性

这是检验偏度预言的最大瓶颈。μSR实验产生的原始直方图数据通常不随论文发表，而是存储在设施数据库中（如PSI的musrfit数据库、ISIS的mantid数据库, TRIUMF的mud）。

**补救：**
- PSI的公开数据政策可能允许访问历史μSR数据
- 联系原作者（Bernhard, Tallon, Uemura, Sonier）请求原始数据——鉴于Tallon 2026对μSR范式的质疑，他可能有兴趣合作
- 使用模拟数据先行验证分析方法，再应用于真实数据

Round 1的价值在于解释了R(p)为什么在p*处穿越unity——这需要δ(p)的物理机制。但即使δ(p)机制最终被证伪（例如退相关度在所有掺杂下为常数），ε≫1的核心事实仍然成立，μSR仍可能系统性测错超流密度。

### 5.2 三级验证策略

```
Level 1: ε ≫ 1 成立？
  → 检验: 偏度S≠0, σ(B)∝(A+CB)^{1/2}
  → 如果成立: 标准μSR分析对所有铜氧化物都有系统性误差

Level 2: ε(p) 的掺杂依赖正确吗？
  → 检验: ε修正后跨家族μSR λ⁻²更一致

Level 3: δ(p) 在 p* 有特征吗？
  → 检验: SANS Δω(p)在p*处极小值

  → 如果失败: δ(p)可能由其他物理驱动
```

**Round 2专注于Level 1和Level 2。Level 1用偏度+B标度，Level 2用跨家族一致性。都不需要Cp，都不需要δ(p)的具体物理模型。**

## 7. 数值附录

### A. 自洽ε修正迭代算法

```python
# 伪代码: 从σ提取λ_true
# 输入: sigma [μs^-1], B [T], gamma_mu = 0.851e11 [s^-1 T^-1]
# 输出: lambda_true [nm]

Gamma_0 = 0.04663  # = 4*pi*0.00371
Phi_0 = 2.068e-15  # [T*m^2]

# 标准分析 (Brandt FLL)
sigma_FLL_sq = (sigma * 1e6 / gamma_mu)**2  # [T^2]
lambda_raw = (0.00371 * Phi_0**2 * gamma_mu**2 / (sigma * 1e6)**2)**(1/4)

# ε修正 (迭代自洽)
lambda_guess = lambda_raw
for i in range(10):
    epsilon = B * lambda_guess**2 / (Gamma_0 * Phi_0)
    correction = (1 + epsilon)**0.25
    lambda_new = lambda_raw * correction
    if abs(lambda_new - lambda_guess) / lambda_guess < 1e-6:
        break
    lambda_guess = lambda_new

lambda_true = lambda_guess
```

## 8. 讨论：ε框架与Tallon 2026的独立一致性

### 8.1 巧合还是收敛？

Tallon 2026的核心发现（Tl2201显示SFD损失而其他家族不显示）和ε框架的核心预言（Tl2201的ε最大→μSR的VD污染最严重→标准分析在Tl2201中最不准确）——两者**定性一致但物理路径不同**。

- Tallon的解释：Tl2201是真实的SFD损失（配对减弱），其他家族的μSR低估了SFD。
- ε框架的解释：所有μSR都系统性测错SFD——误差的大小和方向由ε(p)决定。Tl2201的ε最大，所以Tl2201的μSR数据偏离真实值最远。

如果ε框架正确，Tallon 2026的结论方向需要调换：不是"Tl2201显示SFD损失而其他不显示"，而是"所有家族在μSR中都显示虚假的SFD损失——Tl2201的虚假损失最严重因为它的λ最大→ε最大→VD污染最严重"。

### 8.2 最令人满意的收敛

如果ε框架正确（偏度S≠0, σ(B)偏离FLL标度），那么Tl2201的地位获得了一个全新的解释——不是物理的例外，而是**ε的例外**：

- Tl2201中λ最大 → ε最大 → μSR信号中涡旋无序占比最高 → 标准分析给出的λ⁻²最不准确
- Y123/其他家族中λ较小 → ε较小 → μSR信号中仍有一定FLL残余 → 标准分析勉强可用
- 这解释了为什么Tallon 2026发现Tl2201是"唯一例外"——因为它是ε最大的体系

**Tl2201从"需要解释的例外"变成了"ε框架的自然推论"。这是S2（Tl2201是基准）和S3（ε驱动μSR偏差）的统一点。**
