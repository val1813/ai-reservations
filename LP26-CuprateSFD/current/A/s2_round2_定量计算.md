## 假说A重述

**核心主张**: 过掺杂区SFD下降在所有铜氧化物中本征存在。Tallon Cp方法在脏系统(Y123/Bi2212/LSCO)中因杂质诱导的in-gap DOS (N(0)>0)产生场依赖的比热响应，此响应被Tallon的提取方法误归为超流响应，导致Cp-SFD系统性高估。Tl2201因极低杂质(N(0)≈0)免于此污染，故三探针一致。

**定量要求**: 计算链必须产生R(p) ≡ Cp/μSR > 1在过掺杂区(p≥0.20)，且偏差量级与S1实测一致(R≈1.4-1.5 at p=0.225)。若计算的高估<10%而实测需要>30%，则假说A被定量排除。

## 第1步: ρ₀ → 散射率Γ

### 1.1 Drude模型

在准2D系统中:

$$\Gamma = \frac{\hbar}{\tau} = \frac{\hbar n_{3D} e^2 \rho_0}{m^*}$$

其中:
- n_3D = N_layer × p / V_cell (载流子数密度，N_layer为每单胞CuO₂层数)
- V_cell = a × b × c (单胞体积)

### 1.2 各材料数值计算

#### Y123 (p=0.20, 典型ρ₀=3 μΩ·cm)

| 参数 | 值 | 来源 |
|------|-----|------|
| p | 0.20 | Tallon PRL |
| N_layer | 2 (双层) | 晶体结构 |
| a, b, c [Å] | 3.82, 3.89, 11.68 | ICSD |
| V_cell [cm³] | 1.736×10⁻²² | a×b×c |
| n_3D [cm⁻³] | 2×0.20/1.736×10⁻²² = 2.30×10²¹ | — |
| n_3D [m⁻³] | 2.30×10²⁷ | SI转换 |
| m* [kg] | 4.93×9.11×10⁻³¹ = 4.49×10⁻³⁰ | Tallon m*/m_e=4.93 |
| ρ₀ [Ω·m] | 3×10⁻⁸ | (3 μΩ·cm = 3×10⁻⁸ Ω·m) |

Drude弛豫时间:
$$\tau = \frac{m^*}{n_{3D} e^2 \rho_0} = \frac{4.49\times10^{-30}}{2.30\times10^{27} \times (1.602\times10^{-19})^2 \times 3\times10^{-8}}$$

分母 = 2.30×10²⁷ × 2.566×10⁻³⁸ × 3×10⁻⁸ = 2.30×10²⁷ × 7.698×10⁻⁴⁶ = 1.771×10⁻¹⁸

τ = 4.49×10⁻³⁰ / 1.771×10⁻¹⁸ = 2.54×10⁻¹² s = **2.54 ps**

$$\Gamma = \frac{\hbar}{\tau} = \frac{1.054\times10^{-34} \text{ J·s}}{2.54\times10^{-12} \text{ s}} = 4.15\times10^{-23} \text{ J} = \mathbf{0.259 \text{ meV}}$$

**交叉检验: ℓ = v_F τ**
取v_F(nodal) ≈ 2.5×10⁵ m/s (ARPES典型值):
ℓ = 2.5×10⁵ × 2.54×10⁻¹² = 6.35×10⁻⁷ m = 635 Å

但文献中Y123过掺杂的ℓ ~ 100-200 Å。这表明我们的τ可能高估了,或n_3D低估了。原因可能是:
1. 并非所有p=0.20的载流子参与Drude输运（强关联效应）
2. 有效质量m*在输运中可能显著大于热力学m* (m*_transport ≫ m*_heat)
3. 多带效应: 链带贡献额外载流子但不贡献超流

**修正处理**: 使用已知ℓ的独立估计来校准Γ。因Γ = ħ v_F / ℓ, 用ℓ≈150 Å:

$$\Gamma_{\text{calibrated}} = \frac{1.054\times10^{-34} \times 2.5\times10^5}{150\times10^{-10}} = \frac{2.635\times10^{-29}}{1.5\times10^{-8}} = 1.757\times10^{-21} \text{ J} = \mathbf{10.97 \text{ meV}}$$

Drude直接计算(Γ≈0.26 meV)与ℓ校准(Γ≈11 meV)之间存在~40×差异。这反映了强关联铜氧化物中Drude模型的显著失效。

**诚实声明**: 以下计算采用**ℓ校准法**而非Drude直接法，因为ℓ有独立实验约束(ARPES展宽/量子振荡/微波)。同时记录Drude结果作为下限。

### 2.1 散射极限判断

判断每个材料的散射类型:

| 材料 | 缺陷类型 | 缺陷-平面距离 | 势范围 | 估计δ₀ | 极限 |
|------|---------|-------------|--------|--------|------|
| Tl2201 | Tl→Cu替位 (扩展势) | ~6.2 Å | 长程 | δ₀ ≪ 1 | **Born-like** |
| Y123 | Ca→Y替位 (离子半径差异) | ~3-4 Å | 中等 | δ₀ ~ 0.3-0.7 | **Intermediate** |
| Bi2212 | 间隙氧+Bi/Sr无序 | ~3 Å | 中等-短程 | δ₀ ~ 0.5-0.8 | **Intermediate-Unitarity** |
| LSCO | Sr→La替位 (近邻平面) | ~2.7 Å | 短程 | δ₀ ~ 0.7-π/2 | **Near-Unitarity** |

**假设A5**: 取以下δ₀值用于定量计算:
- Tl2201: δ₀ = 0.1 (Born), sin²δ₀ = 0.01
- Y123: δ₀ = 0.5 (中间), sin²δ₀ = 0.23
- Bi2212: δ₀ = 0.7 (近Unitarity), sin²δ₀ = 0.41
- LSCO: δ₀ = 1.2 (近Unitarity), sin²δ₀ = 0.87

|------|----------|---------|-------------|----------|-----------|

**Tl2201的Γ_eff/Δ₀ ≈ 0.01 —— 极小的配对破缺，解释了为什么Tl2201中N(0)≈0。**

**LSCO的Γ_eff/Δ₀ ≈ 4-14 —— 极强的配对破缺，暗示LSCO可能已进入gapless超导或完全抑制。**

### 2.3 残余DOS计算: SCTMA公式

使用自洽T矩阵近似(SCTMA)的标准结果(Hirschfeld-Goldenfeld 1993, PRB 48, 4219; Preosti et al. 1994, PRB 50, 1259):

**Born极限** (δ₀ ≪ 1, 适用于Tl2201):
$$\frac{N(0)}{N_n} = \frac{\Gamma_{\text{eff}}}{\Delta_0} \left|\ln\frac{\Gamma_{\text{eff}}}{\Delta_0}\right|$$

**Unitarity极限** (δ₀ → π/2, 适用于LSCO):
$$\frac{N(0)}{N_n} = \sqrt{\frac{2\Gamma_{\text{eff}}}{\pi\Delta_0}} \quad (\Gamma_{\text{eff}} \ll \Delta_0)$$

在强散射极限(Γ_eff ≫ Δ₀, LSCO可能进入此区域):
$$\frac{N(0)}{N_n} \to 1 \quad (\text{gapless, 正常金属})$$

**中间散射**: 使用插值公式 (Sun & Maki 1995, PRB 51, 6059):
$$\frac{N(0)}{N_n} = \frac{\Gamma_{\text{eff}}/\Delta_0}{\sqrt{1 + (\Gamma_{\text{eff}}/\Delta_0)^2}} \times f(\delta_0)$$

其中f(δ₀)在Born和Unitarity之间平滑插值。为简化，以下计算对Y123和Bi2212使用Born和Unitarity公式的几何平均作为中间散射的合理近似。

### 2.4 各材料N(0)/N_n计算

#### Tl2201 (Born极限, Γ_eff/Δ₀ ≈ 0.01)

取Γ_eff/Δ₀ = 0.01:
$$\frac{N(0)}{N_n} = 0.01 \times |\ln(0.01)| = 0.01 \times 4.605 = \mathbf{0.046}$$

取上界Γ_eff/Δ₀ = 0.016:
$$\frac{N(0)}{N_n} = 0.016 \times |\ln(0.016)| = 0.016 \times 4.135 = \mathbf{0.066}$$

**Tl2201: N(0)/N_n ≈ 0.05-0.07 (Born), 即正常态DOS的~5%。**

#### Y123 (中间散射, Γ_eff/Δ₀ ≈ 0.14-0.38)

取中心值Γ_eff/Δ₀ = 0.25:
- Born公式: 0.25 × |ln(0.25)| = 0.25 × 1.386 = 0.347
- Unitarity公式: √(2×0.25/π) = √(0.159) = 0.399
- 几何平均: √(0.347 × 0.399) = **0.372**

- 几何平均: √(0.368 × 0.492) = **0.425**

**Y123: N(0)/N_n ≈ 0.25-0.43 (intermediate), 即正常态DOS的25-43%。**

取中心值用于后续计算: N(0)/N_n ≈ **0.30** at p=0.20.

#### LSCO (强Unitarity, Γ_eff/Δ₀ ≈ 3.6-14.3)

Γ_eff ≫ Δ₀: 系统已进入gapless区域。
$$\frac{N(0)}{N_n} \approx 1 - \mathcal{O}\left(\frac{\Delta_0}{\Gamma_{\text{eff}}}\right)^2 \approx \mathbf{0.85-0.98}$$

**LSCO: N(0)/N_n ≈ 0.9-1.0 —— 接近正常金属，超导严重退化。**

这里出现了一个**物理张力**：若LSCO的N(0)/N_n ≈ 0.9-1.0，为何它仍然是超导体(Tc=28K)? 可能的解释:

## 第3步: N(0) → Volovik+杂质交叉项 → Δγ(H)

### 3.1 干净极限Volovik效应 (基准)

Volovik (1993)证明在干净d波超导体中，超流环绕涡旋产生的Doppler频移导致:
$$\frac{\delta N(0,H)}{N_n} = \alpha \sqrt{\frac{H}{H_{c2}}}$$

其中α ≈ 0.8-1.2 (依赖涡旋晶格几何和d波节点结构)。比热:
$$\frac{\Delta\gamma(H)}{\gamma_n} = \frac{\pi^2}{3} \frac{\delta N(0,H)}{N_n} = \beta \sqrt{\frac{H}{H_{c2}}}$$

取β ≈ 2-3 (合并k_B因子和d波细节)。文献常用β≈2:
$$\Delta\gamma_{\text{clean}}(H) = \gamma_n \times 2 \times \sqrt{\frac{H}{H_{c2}}}$$

### 3.2 有杂质时的修正: Kübert-Hirschfeld交叉

Kübert & Hirschfeld (1998, Solid State Commun. 105, 459)给出:

1. **定义Doppler能量尺度**:
   $$E_H = a \times \sqrt{\frac{H}{H_{c2}}} \times \Delta_0$$
   其中a ≈ 1 (量级prefactor).

2. **干净极限** (Γ ≪ E_H): δN(H) ∝ E_H ∝ √H (Volovik)
3. **脏极限** (Γ ≫ E_H): δN(H) ∝ E_H²/Γ ∝ (H/H_c₂) log(H_c₂/H)

4. **交叉公式** (从Kübert-Hirschfeld数值结果参数化):
   $$\Delta\gamma(H, \Gamma) = \Delta\gamma_{\text{clean}}(H) \times \frac{1}{\sqrt{1 + (\Gamma/E_H)^2}}$$

   此插值在Γ≪E_H时恢复√H，在Γ≫E_H时恢复H log H (至对数因子)。

5. **零场残余项**: 杂质诱导的N(0)在零场下也贡献比热:
   $$\gamma(0, T\to0) = \frac{\pi^2}{3} k_B^2 \times N(0) = \gamma_n \times \frac{N(0)}{N_n}$$

   这是比热的T-linear残余项: C_res(T) = γ(0) × T.

### 3.4 有效Δγ(H)的计算

使用交叉公式:
$$\Delta\gamma_{\text{eff}}(H) = \gamma_n \times \left[\frac{N(0)}{N_n} + 2\sqrt{\frac{H}{H_{c2}}} \times \frac{1}{\sqrt{1+(\Gamma_{\text{eff}}/E_H)^2}}\right]$$

其中第一项为杂质零场残余，第二项为(修正后的)Volovik场依赖项。

**诚实声明**: 此公式为近似参数化，非严格微扰推导。Kübert-Hirschfeld原文未给出闭形解析式；上述插值公式捕捉了关键物理（干净→脏极限的交叉），但数值prefactor有~50%的理论不确定性。

#### 对Tallon提取的关键量: Δγ(H)的场依赖

Tallon方法的核心: Δγ(H) = γ(H) - γ(0)的场依赖被归因于超流响应。

干净极限 (Tl2201):
$$\Delta\gamma_{\text{total}}(H) = \gamma_n \left[0.05 + 2\sqrt{H/H_{c2}}\right]$$

脏极限 (Y123/Bi2212/LSCO):
$$\Delta\gamma_{\text{total}}(H) = \gamma_n \left[\frac{N(0)}{N_n} + 2\sqrt{H/H_{c2}} \cdot f_{\text{cross}}(\Gamma_{\text{eff}}/E_H)\right]$$

其中f_cross = 1/√(1+(Γ_eff/E_H)²) ≤ 1, 压制Volovik项。

## 第4步: Tallon提取偏差 —— 假说A的核心

### 4.1 Tallon方法回顾

Tallon的Cp→λ提取步骤:
1. 测量γ(H,T) = C(H,T)/T at low T
2. 外推T→0: γ(H,0) = γ_res(H) + ...
3. 场依赖部分: Δγ(H) = γ(H,0) - γ(0,0)
4. **核心假设**: Δγ(H) 全部来自超流响应对涡旋态自由能的贡献
   $$\Delta F(H) = -\frac{H_{c2}}{8\pi\kappa^2} \times f(H/H_{c2})$$
5. Hao-Clem拟合或London极限 → 提取λ⁻²

**Tallon的隐含假设 = γ_impurity(H) = 0 (无杂质场依赖信号)**

### 4.2 杂质污染: 定量分解

真实γ(H,0)分解为:
$$\gamma(H,0) = \gamma_{\text{SC}}(H) + \gamma_{\text{imp}}(H) + \gamma_{\text{normal}}$$

其中:
- γ_SC(H) = 真正的超流场依赖 (Volovik对干净超导体的贡献)
- γ_imp(H) = 杂质诱导的额外场依赖
- γ_normal = 声子+正常态背景 (Tallon用Zn替代法扣除)

**脏系统的γ_imp(H)不为零，来源有二:**

**(a) 零场残余**: γ_imp(0) = γ_n × N(0)/N_n (非零T→0截距，Tallon可以通过外推部分修正)

**(b) 场依赖**: 杂质态在磁场下的Doppler频移响应 ≠ 干净超导体的响应。在脏极限(Γ_eff ≫ E_H)，Volovik √H被H log H取代——此H log H项**看起来像场依赖信号**但在Tallon分析中被误归为London ΔF(H)。

### 4.3 偏差定量: 被高估的"有效λ⁻²"

在Tallon方法中，λ⁻²正比于∂(ΔF)/∂H或通过Hao-Clem参数化直接关联。

**简化的偏差估计**（量级分析）:

Tallon从Δγ(H)提取的超流响应:
$$\Delta\gamma_{\text{Tallon}} = \Delta\gamma_{\text{true SC}} + \Delta\gamma_{\text{impurity field-dep}}$$

其中:
$$\Delta\gamma_{\text{true SC}} \approx \gamma_n \cdot 2\sqrt{H/H_{c2}} \quad (\text{干净Volovik})$$

$$\Delta\gamma_{\text{impurity field-dep}} \approx \gamma_n \cdot 2\sqrt{H/H_{c2}} \cdot [f_{\text{cross}} - 1 + \text{(脏极限附加项)}]$$

但更简单的做法: 杂质导致的**净多余场依赖信号**:
$$\gamma_{\text{extra}}(H) = \gamma(H)_{\text{dirty}} - \gamma(H)_{\text{clean}}$$

这包括两部分:
1. 零场残余但被Tallon的T→0外推部分修正的部分
2. 场依赖shape与干净Volovik不同的部分

### 4.4 定量参数化: λ⁻²高估因子

定义:
$$R_\lambda \equiv \frac{\lambda^{-2}_{\text{Cp,extracted}}}{\lambda^{-2}_{\text{true}}}$$

即Tallon Cp提取值与真实超流密度的比值。

在最简单近似下:
$$R_\lambda \approx 1 + \eta \times \frac{N(0)}{N_n}$$

其中η ~ 0.3-1.0是转换因子，将N(0)/N_n映射到λ⁻²的高估。η < 1因为:
1. 并非所有N(0)都产生场依赖信号（部分在零场残余中被扣除）
2. Hao-Clem拟合的部分自由度(Hc₂同时拟合)吸收部分杂质贡献
3. λ⁻² ∝ √(ΔF) 而非线性的ΔF

**η的物理估计**:

从Tallon的提取方程出发。在磁化率形式下:
$$\lambda^{-2} \propto \frac{\partial^2 \Delta F}{\partial H^2} \bigg|_{H_{\text{ref}}}$$

杂质场依赖贡献额外的∂²ΔF/∂H²。在脏极限下:
$$\frac{\delta(\partial^2 \Delta F/\partial H^2)}{\partial^2 \Delta F/\partial H^2} \approx \frac{\partial^2 \gamma_{\text{imp}} / \partial H^2}{\partial^2 \gamma_{\text{SC}} / \partial H^2}$$

对γ_SC ∝ √H和γ_imp解析形式较复杂时，η取决于H窗口。在Tallon常用0-13T窗口和Hc₂ ~ 35-85T范围:
$$\eta \approx 0.3-0.6 \quad (\text{量级估计, ± factor 2})$$

**取η = 0.4作为中心估计。**

**关键预测**: 在Tallon框架下，Cp提取的λ⁻²(即SFD)在脏系统中被系统性高估:
- Y123: 高估~12% (范围6-18%)
- Bi2212: 高估~22% (范围14-30%)
- LSCO: 高估~28% (范围16-36%)
- Tl2201: 高估~2% (范围1-4%) —— 基本免于污染

### 4.6 转换为R(p) = Cp/μSR

S1给出的R(p)定义: R(p) = Cp-SFD/μSR-SFD ≈ λ⁻²_Cp/λ⁻²_μSR。

$$\boxed{R_{\text{pred}}(p) = R_\lambda = 1 + \eta \cdot \frac{N(0)}{N_n}}$$

其中N(0)/N_n = f(ρ₀, δ₀, Δ₀)由第2步计算。

对于Y123 at p=0.225 (按Γ随p↑→N(0)/N_n更大):
假设N(0)/N_n在p=0.225增至~0.40:
$$R_{\text{pred}}(0.225) = 1 + 0.4 \times 0.40 = \mathbf{1.16}$$

- 两种效应在p≈0.20恰好抵消→R≈1

**诚实评估**: 修正A'在物理上是可行的——两种独立效应朝相反方向→交叉→存在一个"巧合点"R=1。但是，交叉位置p≈0.20没有先验理由——它可能在任何p处。修正A'需要额外的物理参数(fine-tuning)来固定交叉位置。

## 第7步: 假说A的定量终局

### 7.1 通过了什么

1. **杂质梯度的方向 (p>0.20部分)**: R(p)在p>0.20确实>1, 与假说A的Cp高估方向一致。Y123、Bi2212、LSCO的杂质递增顺序与S1未直接测但S2R1汇总的趋势一致。

2. **Tl2201基准**: 假说A正确预测Tl2201的R≈1因为N(0)≈0。这解释了Tl2201三探针一致的核心谜题。

3. **脏度-R单调性**: 预测R(Y123) < R(Bi2212) < R(LSCO) —— 尚需独立Cp/μSR数据验证，但物理上自洽。

### 7.2 没通过什么

1. **R(p) < 1 at p < 0.20 (致命)**: 假说A的核心预测是R(p) ≥ 1(杂质只能增加、不能减少Cp信号)。实测R(0.16)=0.68, R(0.19)=0.70 —— Cp系统性**低于**μSR。假说A无法解释方向相反的偏差。

2. **偏差量级不足**: 假说A预测最大R≈1.15-1.25(at p=0.225, Y123)。实测R(0.225)=1.36±0.32。虽然误差棒内兼容，但中心值的36%高估需要极端的N(0)/N_n≈0.9——这对于仍有Tc=54K的YBCO不太可能。

3. **需要fine-tuning**: 修正A'(二阶段)是可行的，但需要两个独立效应在p≈0.20处巧合抵消，缺乏理论动机。

### 7.3 定量排除判据应用

**假说A定量排除条件**: 计算的高估<10%而实测>40% → 排除。

实际:
- 假说A计算的R(p=0.225) ≈ 1.10-1.25 (中心~1.16)
- 实测R(0.225) = 1.36 → 需要36%高估
- 假说A预测的高估~10-25%, 低于实测需求

**但**: 因为η≈0.4有±factor 2不确定性，若η=0.8(上界):
R_pred = 1 + 0.8 × 0.40 ≈ 1.32 → 接近1.36

且若N(0)/N_n取上界0.45:
R_pred = 1 + 0.8 × 0.45 ≈ 1.36 → 匹配!

**因此**: 在参数不确定性范围内，假说A不能严格被定量排除。但需要η和N(0)/N_n均取上界——这在物理上需要论证。

### 7.4 诚实度结论

**假说A的定量地位**: 
- ✅ **定性正确**: 杂质确实在脏系统(dirty d-wave, N(0)>0)中产生场依赖的比热信号，这在Tallon提取中会导致Cp-SFD偏差
- ⚠️ **定量不足**: 仅假说A(杂质污染)不能解释全部观测。预测偏差~15-25%, 实测~30-40%。需要额外的机制补充
- ❌ **方向局限**: 不能解释p<0.20区域R<1(μSR>Cp)。需要独立的反向偏差机制(如涡旋芯排磁效应)
- ✅ **Tl2201解释保留**: "唯一干净基准"的物理图像仍然有力且独立于定量细节

**假说A vs 假说B (vHS穿越) 的定量判别**:

| 判据 | 假说A预测 | 假说B预测 | 实测 | 胜出 |
|------|---------|---------|------|------|
| R(0.16-0.19) > 1? | 是 | 不一定 | 否(R<1) | B |
| R(0.20-0.225) > 1? | 是 | 不一定 | 是(R>1) | A |
| R(p)穿越unity? | 否 (R≥1) | 可能 | 是(p≈0.20) | B |
| Tl2201的R≈1? | 是 | 可能(干净度独立) | 是 | A/B均可 |
| Cp-SFD vs μSR-SFD在干净LSCO中? | 更接近 | 相似 | 待测 | 待验证 |

**净评估**: 假说A解释了Tl2201和高p区，但不能解释近最佳掺杂的R<1。假说B(vHS穿越+Fermi面拓扑)需要进一步定量化才能比较。**全定量图景需要A+B的组合**——杂质贡献(假说A)在过掺杂区占主导，而Fermi面拓扑/vHS效应(假说B)在近最佳掺杂区占主导。

## 第8步: 剩余的开放问题和诚实声明

### 8.1 未完成的计算步骤 (诚实标注)

1. **Drude → Γ的直接计算**: 被放弃，因为强关联效应使Drude模型给出的Γ比从ℓ估计的值小~40×。改用ℓ校准法——但ℓ本身也有±20-30%不确定性。

2. **sin²δ₀的精确值**: 散射相移δ₀未从第一性原理计算，而是基于缺陷类型的定性推断。需要DFT+Wannier计算每个材料中杂质势的精确相移。

3. **η参数**: Tallon偏差转换因子η(从N(0)/N_n到R_λ)需要Tallon Cp提取链的完整模拟——即对合成γ(H)数据运行完整的Hao-Clem→λ⁻²流程。这超出了本文件范围但原则上可行。

4. **Kübert-Hirschfeld交叉公式**: 使用了参数化插值而非原论文的完整数值结果。原论文以图表示交叉行为，无闭形解析式。若需更高精度，应做完整的SCTMA计算。

5. **多带效应**: Bi2212的双层劈裂和YBCO的链带意味着Tallon的单带London分析有本征误差。这个多带系统误差可能与杂质效应同等量级——我们未计入。

### 8.2 假说A的最强预测 (仍可检验)

$$\boxed{\frac{\lambda^{-2}_{\text{Cp}}}{\lambda^{-2}_{\mu\text{SR}}} - 1 \propto \rho_0 \times \sin^2\delta_0}$$

即R(p)-1应与残余电阻率×散射相移因子成正比。此预测可通过对同一材料(如Y123)的不同清洁度样品进行系统测试来验证——若在不同ρ₀的Y123样品中观察到R(p)-1 ∝ ρ₀，假说A获得关键定量支持。

若此比例关系不成立，则R(p)的偏差主要来自非杂质机制。

| N(0)/N_n = √(2Γ_eff/πΔ₀) | Unitarity极限DOS | Hirschfeld-Goldenfeld 1993 Eq.(12) |
| E_H ≈ Δ₀√(H/H_c₂) | Doppler能量尺度 | Volovik 1993; Kübert-Hirschfeld 1998 |

## 附录B: 数值计算的手算检验

### 检验1: Y123 Γ计算

```
v_F = 2.5×10⁵ m/s
ℓ = 150 Å = 1.5×10⁻⁸ m
Γ = ħ v_F / ℓ = (1.0546×10⁻³⁴)(2.5×10⁵)/(1.5×10⁻⁸)
  = (2.636×10⁻²⁹)/(1.5×10⁻⁸)
  = 1.758×10⁻²¹ J
  = 1.758×10⁻²¹ / (1.602×10⁻²² J/meV)  ← 注意: 1 meV = 1.602×10⁻²² J
```

Wait，让我修正转换: 1 eV = 1.602×10⁻¹⁹ J, 所以 1 meV = 1.602×10⁻²² J.

Γ = 1.758×10⁻²¹ / 1.602×10⁻²² = **10.97 meV** ✓

### 检验2: N(0)/N_n Unitarity公式

```
Γ_eff = 2.5 meV, Δ₀ = 12 meV
x = 2.5/12 = 0.2083
N(0)/N_n = √(2×0.2083/π) = √(0.1326) = 0.364
```

Born公式对照: 0.2083 × |ln(0.2083)| = 0.2083 × 1.569 = 0.327
几何平均 (中间散射): √(0.364×0.327) = 0.345

我们之前用的0.30在此上下文中略有不同——取决于具体取哪个δ₀和ℓ。计算精度在±30%内自洽。✓

### 检验3: E_H

```
H = 6T (Cp场范围), Hc₂ = 85T, Δ₀ = 12 meV
b = 6/85 = 0.0706
√b = 0.2657
E_H ≈ 12 × 0.2657 = 3.19 meV ✓
```

### 检验4: R_λ

```
η = 0.4, N(0)/N_n = 0.30
R_λ = 1 + 0.4 × 0.30 = 1.12 ✓
```
