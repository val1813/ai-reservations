## 1. 致死检验的逻辑框架

### 1.1 核心命题

**标准Brandt分析的核心假设**（London极限，中间场区）:

$$\sigma^2(B) = \frac{0.00371 \Phi_0^2}{\lambda^4} = \text{常数} \quad (\text{与B无关})$$

**VDC修正的声称**:

$$\sigma^2(B) = \sigma^2_{\text{FLL}} + \sigma^2_{\text{VD}} = \frac{0.00371 \Phi_0^2}{\lambda^4} + \frac{\delta}{\lambda^2} B$$

其中 $\delta \propto$ 涡旋无序度，且 $\delta > 0$（无序总是增加线宽）。

### 1.2 检验逻辑

- 若 $\sigma^2(B) = \text{常数}$（在实验误差内）→ VDC被致死
- 若 $\sigma^2(B) = a + bB$ 且 $b > 0$（统计显著）→ 标准分析被否定，VDC必要性得证
- 若数据不存在或不充分 → 文献空白本身即是重要发现

### 3.1 YBCO O1样品：σ²(B)非线性

**线性拟合**: $\sigma^2(B) = a + bB$

- a = 2.10 ± 0.24 μs⁻²
- b = **-0.11 ± 0.20 μs⁻²/T**
- R² = 0.043
- **b与零一致；若b<0则与VDC预言(b>0)相反**


**线性拟合**: $\sigma^2(B) = a + bB$

- a = 1.05 ± 0.05 μs⁻²
- b = **+0.41 ± 0.05 μs⁻²/T**
- R² = 0.993
- **b > 0，方向与VDC一致！但仅3个数据点，统计力不足**

### 3.3 关键矛盾

O1和O2是同一批次的YBa2Cu3O6.95最优掺杂单晶，但:
- **O1**: σ²(B) 无明显线性趋势（或轻微负斜率）
- **O2**: σ²(B) 线性增长（b > 0）
- 两样品在0.5T附近重叠：σ²_O1(0.498T) = 2.08 vs σ²_O2(0.497T) = 1.51（相差38%！）

**这不是系统性的场依赖——这是样品间差异或拟合系统误差。**

### 3.4 NbSe2数据的推论

Sonier (1997) NbSe2数据中λ随H线性增加:
$$\lambda(H) = \lambda(0) + \alpha H, \quad \alpha > 0$$

若标准分析σ² ∝ 1/λ⁴成立：
$$\sigma^2(H) \propto \frac{1}{(\lambda_0 + \alpha H)^4} \approx \frac{1}{\lambda_0^4}\left(1 - \frac{4\alpha}{\lambda_0}H\right)$$

→ **σ²随H线性下降**，斜率 $\propto -4\alpha/\lambda_0 < 0$

这同样与VDC预言(b > 0)**方向相反**。

## 4. 为什么简单的致死检验无法直接下结论

### 4.1 已知使σ²(B)非常数的物理机制（非VDC）

| 机制 | σ²(B)行为 | 主导场区 | 文献 |
|------|----------|---------|------|
| GL涡旋芯重叠 | 近Bc2时σ²下降 | b > 0.3 | Brandt PRB 68, 054506 (2003) |
| 非线性超流响应（Doppler位移） | λ增大 → σ²下降 | 所有场 | Sonier PRL 83, 4156 (1999) |
| d波非局域效应 | λ增大 → σ²下降 | 所有场（尤低T） | Sonier PRB 76, 134518 (2007) |
| 多带超导芯态退局域化 | σ²下降（间接） | 低场 | Callaghan PRL 95, 197001 (2005) |
| 热涨落（flux-line lattice melting） | σ²下降 | 近T_c | 标准文献 |

### 4.2 效应叠加问题

观测到的σ²(B) = σ²_FLL(ideal) + Δσ²_GL + Δσ²_nonlocal + Δσ²_nonlinear + Δσ²_multiband + Δσ²_VD

其中:
- Δσ²_GL < 0（负贡献，近Bc2时显著）
- Δσ²_nonlocal < 0（负贡献）
- Δσ²_nonlinear < 0（负贡献）
- Δσ²_multiband < 0（负贡献）
- Δσ²_VD > 0（正贡献，VDC声称）

**所有已知物理机制都使σ²随B下降。只有VDC使σ²随B上升。**

这意味着VDC即使存在，也被更大的负贡献所掩盖。直接拟合σ²(B)=a+bB无法分离VDC项。

### 4.3 实验数据的根本性局限

从Sonier数据可以看出，**C参数（Brandt公式中的比例常数）本身就随场变化**:

| H [T] | C_O1 | C_O2 |
|-------|------|------|
| 0.1-0.2 | 1.94-1.95 | 1.195 |
| 0.5 | 1.835 | 1.485 |
| 1.5 | 1.784 | 1.833 |
| 1.95 | 2.275 | — |

C的变化范围：O1从1.625到2.275（变化34%），O2从1.195到1.833（变化53%）。

**如果C是物理常数（Brandt London极限值），它不应随场变化。C的变化本身就说明标准分析框架内的模型假设不闭合。**

## 5. 最重要的发现：μSR社区从未执行过这个检验

### 5.1 "检验缺失"的三层证据

**第一层**: Landau & Keller (Physica C 466, 131, 2007) 明确指出:
> "Brandt [PRB 68, 054506 (2003)]的数值计算...可以作为分析μSR数据的可靠且强大的工具。这些计算在实践中几乎从未被用于此类分析。"

——来自μSR社区内部的公开批评，发表于Physica C。

**第二层**: 所有找到的多场μSR论文都:
- 测量了σ(B)或λ(B)
- 将场依赖性归因于物理的λ(B)（非局域/非线性效应）
- **从未检验模型的内部自洽性**：如果用B-无关的λ代入，σ²(B)是否符合Brandt 2003预言？

**第三层**: 标准μSR数据分析协议:
1. 在一个场下测量σ(T)
2. 用Brandt公式提取λ(T)：$\lambda^{-2} = \sqrt{\sigma^2 - \sigma_N^2}/C$
3. 将λ(T)与理论比较（d波/s波/两能隙...）
4. **从不检验第2步的B-独立性假设**

### 5.2 这是一个根本性的方法论缺陷

μSR社区的分析链：
```
σ(B) → [假设σ² ∝ 1/λ⁴, C = 常数] → λ(B) → "λ随场变化！→ 非局域效应/非线性响应"
```

**但从未有人反过来检验**:
```
λ(0) [由Meissner态独立测定] → Brandt 2003完整计算 → σ_pred(B) → 与σ_meas(B)比较
```

如果λ已知（通过微波腔谐振、红外光谱等Meissner态测量），Brandt 2003的计算给出明确的σ²(B)预言。实测σ²(B)与预言的差异就是**模型误差**，至少部分来自VDC。

## 6. 设计决定性最小实验

### 6.1 实验核心思想

**固定λ（Meissner态独立测定）→ 检验σ²(B)是否等于Brandt 2003预言值。**

不依赖模型从σ提取λ——而是用独立已知的λ预言σ，再与实测比较。

### 6.2 靶材选择：Nb（铌）

选择Nb的理由：
- **s波、单带**：无非局域d波效应，无非线性Doppler位移
- **λ已精确已知**: λ(0) ≈ 39 nm（伦敦穿透深度），通过各种Meissner态方法反复验证
- **κ ≈ 1**：Brandt 2003的GL计算对低κ最精确（GL理论在此区域最可靠）
- **Bc2 ≈ 0.3 T**：实验在低场即可，不需要高场谱仪
- **Tc = 9.2 K**: 容易达到的低温

### 6.3 实验设计

| 参数 | 值 | 理由 |
|------|-----|------|
| 样品 | Nb单晶，RRR > 1000 | 高纯度，最小钉扎 |
| 温度 | T = 2.0 K | T/Tc = 0.22，热涨落可忽略 |
| 磁场 | B = 0.05, 0.10, 0.15, 0.20 T | 覆盖London区（0.13/κ²< b < 0.3），4个场点足够线性拟合 |
| 每场计数 | 30×10⁶ 事件 | ~30分钟/场 @ 连续束流 |
| 总束流时间 | ~2小时 | 现代μSR设施的典型分配 |
| 数据分析 | 用Brandt 2003迭代法（非简化London公式）拟合P(t) | 消除分析模型系统误差 |

### 6.4 预言值

**标准Brandt预言**（London极限，σ² = 常数）:

对于Nb：λ = 39 nm, Φ₀ = 2.068×10⁻¹⁵ Wb

$$\langle \Delta B^2 \rangle = 0.00371 \frac{\Phi_0^2}{\lambda^4} \approx 0.0062 \text{ T}^2$$

转化为μSR参数：
$$\sigma = \frac{\gamma_\mu}{\sqrt{2}} \sqrt{\langle \Delta B^2 \rangle}$$

其中γ_μ = 851.6 Mrad/s/T.

**VDC预言**（λ = 常数的前提下）:

$$\sigma^2(B) = \sigma^2_{\text{London}} + \frac{\gamma_\mu^2}{2} \cdot \delta \cdot \frac{B}{\lambda^2}$$

取典型VDC参数δ ≈ 0.05-0.15（基于Nb中已知的弱钉扎），在B = 0.05-0.20 T范围:

| 场 [T] | σ²_London（标准） | σ²_VD（δ=0.10, 加性项） | 总σ²（VDC） |
|---------|-------------------|------------------------|-------------|
| 0.05 | σ₀² | +0.01 σ₀² | 1.01 σ₀² |
| 0.10 | σ₀² | +0.02 σ₀² | 1.02 σ₀² |
| 0.15 | σ₀² | +0.03 σ₀² | 1.03 σ₀² |
| 0.20 | σ₀² | +0.04 σ₀² | 1.04 σ₀² |

**注意**: 上述为示意性估计。精确预言需要δ的具体值。但检验逻辑对δ的具体值不敏感——**任何统计显著的σ²(B)线性增长（在London区）都是标准分析的否定**。

### 6.5 判决力分析

**情景A**: σ²(B) = 常数（在±1%内）→ **VDC被致死**。标准Brandt分析获得迄今为止最干净的实验验证。

**情景B**: σ²(B) = a + bB, b显著≠0（在±1%精度可检）→ **标准Brandt分析被否决**。VDC（或类似机制）被证实。

**情景C**: σ²(B) 非线性但非单调 → **Brandt 2003的完整GL计算尚未完全描述真实涡旋晶格**。需要进一步理论发展。

### 6.6 为什么这个实验从未被做过

Nb是μSR中研究最多的超导体之一（>100篇论文）。但令人震惊的是：

1. μSR实验总是为了**提取λ**（通过σ），而非**检验σ²(B)公式本身**
2. 标准操作是在**一个场**下测σ(T)，用Brandt公式得λ(T)
3. 即使在同一论文中改变磁场，目的也是将λ(H→0)外推，而非检验公式
4. 从未有人在已知λ（Meissner态）的情况下检验：$\sigma^2_{meas}(B) \stackrel{?}{=} \sigma^2_{Brandt}(B; \lambda_{Meissner})$

**μSR社区对Brandt公式的态度是使用者而非检验者。**

## 7. 判决

### 7.1 致死检验的直接结论

**致死检验无法在现有已发表数据上得出确定性结论。**

原因：
1. 存在多场μSR数据（Sonier博士论文，~10个场点），且σ²(B)确实随B变化
2. 但σ²(B)的变化**方向与VDC预言相反**（多数数据显示σ²下降而非上升）
3. 这种下降可被多种已知物理机制解释（非局域效应、非线性响应、GL芯重叠），无需VDC
4. VDC的正贡献即使存在，也被更大的负贡献所掩盖
5. 现有数据**不足以分离VDC信号**

### 7.2 但这不是VDC的胜利——这是标准分析的方法论失败

**关键发现**: μSR社区**从未**对Brandt公式的B-独立性执行过严格检验。

在标准分析框架下，如果σ²(B) = C/λ(B)⁴，那么C应与B无关。Sonier的数据显示**C随B系统性变化（高达34-53%）**——这在标准分析框架内是**内部矛盾**。

μSR社区的处理方式：
- C随B变化 → 被归入λ(B)的变化 → "λ随场变化" → 发表新物理
- **从未有人考虑**: C的变化可能意味着**公式本身就少了项**（如VDC项）

### 7.3 致死检验的修正策略

直接检验VDC（通过σ²(B)=a+bB）在现有数据上不可行，因为：
- 信号b×B太小（VDC贡献可能<5%）
- 背景太大（非局域/非线性效应贡献>20%）
- 两者方向相反

**正确的策略是三步法**:
1. **Step 1**: 用Meissner态独立测定λ（微波、红外等）
2. **Step 2**: 用Brandt 2003完整GL计算预言σ²(B)
3. **Step 3**: 比较σ²_meas(B) - σ²_Brandt2003(B) → 残差

如果残差 = 常数 → √(Brandt 2003完整, VDC不需要)
如果残差 ∝ B → √(VDC被证实)
如果残差 ∝ -B → √(非局域效应占主导，VDC被压制)

**设计的Nb实验（第6节）就是这个策略的最小实现。**
