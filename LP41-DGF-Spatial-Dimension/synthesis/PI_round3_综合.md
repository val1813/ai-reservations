## 为什么不同？——互补而非矛盾

两个推导描述的是**同一物理系统的不同区域**：

- **B博士（Liouville）**: 临界点 ρ_K ≈ θ_c 处，环世界面融合为单张Liouville随机曲面。KPZ约束d_eff ∈ [3.21, 3.83]。这是**临界d_eff**——相变刚发生时。
- **A博士（CFT网络）**: 深度超临界区 ρ_K ≫ θ_c 处，环网络体积填充，d_w → 1。d_eff → 3 + c(b₁)。这是**饱和d_eff**——充分激活后。

**统一图像**:
```
d_eff(b₁, ρ_K)
  │
  │                    ┌─ A博士: d_eff → 3+c(b₁) (饱和)
  │                 ╱
  │              ╱
  │           ╱  B博士: d_eff ≈ d_H(c)-1 (临界)
  │        ╱
  │     ╱
  │  ╱
3 ─┴─────────────────────────── ρ_K
  0    θ_c                      ≫ θ_c
```

这是一个**可检验的区别**：在同一个b₁系统上，扫描ρ_K从θ_c到远大于θ_c，d_eff应该从B博士的值连续过渡到A博士的值。
