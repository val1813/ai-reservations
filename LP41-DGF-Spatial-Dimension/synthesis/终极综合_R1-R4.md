## 完整理论链路

```
量子电路过程 C
  → Qubit连通图 G_conn
    → Betti数 b₁ = |E| - |V| + C  [规范不变量 ✅]

b₁ → Temperley-Lieb代数 → Virasoro CFT
  → c(b₁) = 1 - 6/((b₁+2)(b₁+3))  [双框架验证 ✅]
    → 离散谱: {1/2, 7/10, 4/5, 6/7, 25/28, ...}

c(b₁) → 有效空间维度 d_eff(b₁, ρ_K):
  近临界(ρ_K≈θ_c): d_eff = d_H(c)-1 ∈ [3.21, 3.83]  [KPZ/Liouville]
  超临界(ρ_K≫θ_c): d_eff = 3+c(b₁) ∈ [3.50, 4.00)  [耦合CFT网络]
  统一交叉: d_eff = 3 + Δ_KPZ(b₁)e^{-αx} + c(b₁)·[min(x/x_sat,1)]^β

d_eff → 纠缠熵标度: S(L) ∝ L^(d_eff-1)  [可检验]
```

## 物理图像

> 因果环=空间中的"量子隧道"。少数几条隧道不改变空间的宏观维度——它们只是捷径，空间感觉还是3D的。但隧道多了，连成一张跨越整个空间的网络后，空间开始"膨胀"——熵不再是面积律（3D特征），而是向体积律（4D特征）过渡。有效维度由隧道的数量（b₁）和密度（ρ_K）共同决定。多到无穷时，空间接近但永远达不到4D——量子效应天然限制了维度的最大增量。
