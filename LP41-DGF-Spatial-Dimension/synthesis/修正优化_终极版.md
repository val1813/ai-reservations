## 优化后的理论框架

### 三层面架构（修正⚠️-9, ⚠️-1）

DGF不是一条线性推导链，而是三个独立层面的映射。每个层面对应不同的数学框架和可观测量。

```
层面1: 图拓扑 (Graph Topology)
  b₁ = |E| - |V| + C  (G_conn连通图的Betti数, Wall α已破: b₁是规范不变量)
    ↓ [b₁→TL代数映射, 核心假设, 双视角平行推导]
  
层面2: 代数/共形场论 (Algebraic/CFT)
  c(b₁) = 1 - 6/((b₁+2)(b₁+3))  — Virasoro酉极小模型中心电荷
  γ(b₁) = ln(√((b₁+2)/2)/sin(π/(b₁+2)))  — 拓扑纠缠熵 (SU(2)_{b₁} MTC)
  
  注意: c(b₁)和γ(b₁)来自不同数学构造
  - c(b₁): GKO陪集 SU(2)_{b₁}×SU(2)₁/SU(2)_{b₁+1} → Virasoro极小模型
  - γ(b₁): SU(2)_{b₁} Chern-Simons → 模张量范畴 → Verlinde公式
  - 两者在b₁=2处交叉验证: c=7/10 (Tricritical Ising), γ=ln2 (Z₂ toric code)
    ↓ [c→d_eff映射, 两个互补机制]
  
层面3: 有效维度 (Effective Dimension)
  尚未有唯一公式。两个互补机制给出不同视角:
  
  机制A (CFT网络堆叠): 
    d_eff^ent(b₁, ρ_K≫θ_c) ≈ 3 + c(b₁)  — 纠缠标度指数
    物理: b₁个具有c(b₁) CFT的世界面在深度超临界区独立堆叠
    范围: d_eff ∈ [3.5, 4.0), b₁→∞时→4.0
    ⚠️ 这是启发式推导，非严格证明
  
  机制B (Liouville随机曲面):
    d_eff^Liouv(b₁) = d_H(c(b₁)) - 1  — KPZ/Watabiki Hausdorff维数
    物理: b₁个世界面在近临界区相干融合为单张Liouville随机曲面
    范围: d_eff ∈ [3.21, 3.83), b₁→∞时→3.828
    ⚠️ Watabiki公式并非唯一(Hausdorff维数有竞争公式, ±5-10%)
    ⚠️ KPZ框架应用于嵌入3D空间的世界面，前提条件待验证
    ⚠️ 连续极限下d_eff→3? (Wall δ)
  
  两种机制的差异 (~0.3 at b₁=1) 是可检验的:
    测量ρ_K刚超过θ_c时的d_eff → 若≈3.21 → 支持Liouville
    测量ρ_K≫θ_c时的d_eff → 若≈3.50 → 支持CFT网络
```

### 完整核心链路（已知+假设标注）

```
✅ 规范不变量 (Wall α已破):
   b₁(G_conn) = |E| - |V| + C, 在门调度下严格不变
   
⚠️ 核心假设 (双视角平行推导, 非独立验证):
   b₁ → TL代数参数 δ = 2cos(π/(b₁+2))
   两条路径共享此假设:
   - 路径A(量子信息): b₁→Lindblad慢模→有效自由度→圈气体→c
   - 路径B(纽结/TQFT): b₁→辫群B_{2b₁+1}→Hecke代数→TL代数→RSOS→c
   
✅ 标准数学 (Koo-Saleur 1994, GKO 1986):
   TL代数 → Virasoro极小模型 M(b₁+2, b₁+3)
   c(b₁) = 1 - 6/((b₁+2)(b₁+3))
   
⚠️ 互补机制 (非统一):
   机制A: d_eff^ent ≈ 3 + c(b₁)  [启发式, 须数值验证]
   机制B: d_eff^Liouv = d_H(c)-1  [KPZ前提待验证, 连续极限待解决]
```

**诚实标注**:
- c(b₁): 解析推导, 依赖核心假设b₁→TL。数学上自洽。未经数值验证。
- γ(TEE): 解析推导, 来自SU(2)_{b₁} MTC。b₁=2处与Z₂ toric code交叉验证。未经数值验证。
- d_eff^Liouv: 半解析。依赖Watabiki公式(KPZ框架)。连续极限待解决(Wall δ)。竞争公式差异±5-10%。
- d_eff^ent: 启发式。耦合CFT类比。未经数值验证。
- **两者关系**: 描述不同ρ_K区域(近临界 vs 深度超临界)，非矛盾而是互补。B-R4的"统一插值公式"含3个自由参数→降级为现象学假说。

### 诚实状态

**已知**:
- c(b₁) = 1 - 6/((b₁+2)(b₁+3)) 是数学上自洽的解析公式
- b₁是规范不变量 (G_conn连通图的Betti数)
- c(b₁)→d_eff存在两个互补机制, 给出不同的数值区间
- 两个机制在b₁=1处差异~0.3, 可数值裁决

**未知**:
- b₁→TL代数映射是核心假设, 未被数值验证
- 哪个机制(或两者皆非)描述真实的d_eff
- KPZ/Watabiki框架对嵌入3D空间的世界面是否适用
- 连续极限下d_eff是否→3 (Wall δ)
- 所有12个可检验预言均未执行
