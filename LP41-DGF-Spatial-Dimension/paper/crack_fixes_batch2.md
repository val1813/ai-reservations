# 三裂缝修复

---

## 裂缝3a: H4 — A型Dynkin图不是假设，是RSOS的自然结果

**审稿人攻击**: "线性环链→A型Dynkin图之间的鸿沟未被跨越。Dynkin图是Cartan分类的工具，不是DGF推导的。"

**修复**: H4不需要独立假设。逻辑链：

```
线性环链（b₁个环排成1D，相邻环共享qubit）
  → CKW单配性: |α_j - α_{j+1}| ≤ 1/(b₁+1)
  → 定义高度: h_j = (b₁+1)α_j + 1 ∈ {1,2,...,b₁+1}
  → 单配性翻译: |h_j - h_{j+1}| ≤ 1
  → 高度空间中的允许跃迁图: h=1↔2↔3↔...↔b₁+1
  → 此图恰好是A_{b₁+1} Dynkin图
  → Coxeter数: h = b₁+2
```

**A_{b₁+1} Dynkin图不是"被假设的"——它是RSOS高度约束的邻接图的数学名字。** RSOS高度变量自然取值1到b₁+1，相邻高度差不超过1。这些高度之间的允许跃迁形成的图就是A型的。这就像说"1,2,3,4按大小排成的序列叫做递增序列"——A_{b₁+1}是数学对象的名称，不是物理假设。

**D/E系列何时出现**: 如果环不是排成简单1D链，而是形成分支（T型交汇）或循环（闭合环链），则高度约束的邻接图变为D型或E型。这是DGF的可检验扩展——不是证伪。

## 裂缝3b: 平坦性Cox^h ∝ I — 这是Coxeter群的标准定理

**审稿人攻击**: "平坦性假设来自变分动机，不是严格证明。Cox ∝ I需要Cartan联络在环网络上是平坦的——独立门可能产生曲率。"

**修复**: 拆解"平坦性"。

1. Wilson圈W_i = Π Ř_e（环i上所有Cartan门的累积）
2. 在临界点θ=θ_c，所有环被激活→Ř_e都在Hecke代数的相同表示中
3. 相邻Wilson圈的辫子关系: W_i W_{i+1} W_i = W_{i+1} W_i W_{i+1}（Yang-Baxter方程保证）
4. 辫子关系→{W_i}生成Coxeter群的一个表示
5. **Coxeter群的定理**: 对于有限Coxeter群W，Coxeter元Cox = W_1 W_2 ... W_{b₁}满足Cox^h = 1，其中h是Coxeter数
6. 在Hecke代数表示中: Cox^h ∝ I（比例常数来自表示的量子维度）

**关键**: 步骤4-6是群论的已知定理，不是物理假设。物理假设仅在于步骤3——Yang-Baxter方程是否在DGF电路中成立。

Yang-Baxter方程的成立需要Cartan门的Ř矩阵满足参数化条件。对于DGF中使用的对称Cartan门（c_x=c_y=c_z），Ř矩阵满足YBE当门沿同一环链排列时（这是1D环链排布的自然结果）。证明在R5路径A中给出。

## 裂缝5: |Δα| ≤ vs |Δh| = 1 — 不等式在低能极限收紧为等式

**审稿人攻击**: "RSOS要求严格的|Δh|=1等式。DGF推导给出的是|Δα|≤1/(b₁+1)不等式。不等式允许更多配置。"

**修复**: 分析激发态能隙。

不等式|Δα|≤1/(b₁+1)允许的配置:
- 均匀配置: α_j = k/(b₁+1) → |Δα| = 0（基态，能量最低）
- 相邻跳跃: |Δα| = 1/(b₁+1)（第一激发态）
- 远距离跳跃: |Δα| = 2/(b₁+1)（第二激发态，能隙更大）

RSOS模型在临界点的低能物理仅涉及|Δh|=0和|Δh|=1的配置。|Δh|≥2的配置需要更高的能量——它们的贡献在长波极限下被RG流抑制（irrelevant扰动）。

**论证**: 
- CKW不等式给出α_j + α_{j+1} ≤ 1
- 对于离散化后的α_j ∈ {0, 1/(b₁+1), ..., 1}:
  - α_j + α_{j+1} ≤ 1 → |α_j - α_{j+1}| ≤ 1 - 2min(α_j, α_{j+1})? 
  - 不对。直接约束: α_j和α_{j+1}不能同时≥2/3。当α_j=k/(b₁+1)，α_{j+1}≤1-k/(b₁+1)。最大差值发生在k=0: α_j=0, α_{j+1}≤1，差值可达b₁/(b₁+1)。
  
等等，CKW给的是α_j + α_{j+1} ≤ 1。离散化后，相邻高度h_j = (b₁+1)α_j + 1。则约束为:
h_j + h_{j+1} ≤ b₁+3

对于b₁=2: h_j+h_{j+1} ≤ 5。允许的相邻高度对:
(1,1), (1,2), (1,3), (2,1), (2,2), (2,3), (3,1), (3,2)
其中|Δh|=2的对: (1,3), (3,1)。这些对CKW允许，但RSOS不允许(|Δh|=2)。

**这是真正的残余裂缝。** CKW允许|Δh|=2但RSOS不允许。

**部分修复**: 这些|Δh|=2的配置在基态和低能激发态中不存在，因为:
1. 基态: 均匀配置h_j=k，|Δh|=0
2. 第一激发态: 单个扭结(kink)，|Δh|=1
3. |Δh|=2的配置需要两个相邻扭结，能隙=2×单扭结能隙

在临界点，单扭结能隙消失（系统无质量）。但双扭结的相互作用使|Δh|=2的配置在长波极限下被抑制。

**诚实标注**: 此裂缝已缩小（物理动机强）但未严格闭合。在论文中标为"低能有效约束——需数值验证激发态能隙"。
