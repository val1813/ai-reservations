# DGF CMB分析: 北半球异常→b₁不对称→d_eff调制

## 已知观测 (Pranav & Buchert 2023, arXiv:2308.10738)

CMB同调分析发现:
- 北半球(尤其第一象限): >3.5σ偏离统计各向同性
- 南半球: 与标准模型一致
- 异常集中在θ≈5°尺度
- "同调谱"揭示的偏差不能用前景污染或系统误差解释

## DGF映射

```
CMB最后散射面的密度场 → 局部Betti数 b₁(θ, φ)
  → c(b₁) = 1 - 6/((b₁+2)(b₁+3))
  → d_eff(b₁) = 3 + c(b₁)  (超临界/饱和极限)
  → H_eff = H_ΛCDM × (d_eff/3)^{1/2}  (Friedmann修正)
  → δT/T ∝ (d_eff - 3)  (温度调制)
```
