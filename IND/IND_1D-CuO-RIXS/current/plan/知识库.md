# 知识库 — 1D-CuO-RIXS v1

## Ba₂CuO₃₊δ基本物理
- 1D铜氧化物链结构（CuO链）
- 强关联：U/t ~ 8-10（Mott绝缘体）
- 超交换J ~ 250-300 meV（Cu-O-Cu 180°键）
- 氧空位δ ~ 0.1-0.2（引入随机性）

## 2-旋子激发（two-spinon）
- 1D海森堡链的基本激发：自旋子（spinon）
- 2-旋子连续谱：ω(q) ∈ [π/2 J|sin q|, πJ|sin q|]
- BZ边界（q=π）：2-旋子能量上界 = πJ ≈ 800-940 meV
- BZ边界下界 = π/2 J ≈ 400-470 meV

## RIXS实验事实
- Ba₂CuO₃₊δ中BZ边界2-旋子能量被软化~30-50%
- 软化量：从预期~300meV降至~150-200meV
- 实验组解释：1带Hubbard模型失效→需要多轨道/非局域相互作用

## 无序效应（Ma-Dasgupta-Fisher随机单态RG）
- 1D随机交换海森堡链：H = Σ J_i S_i·S_{i+1}，J_i随机
- Ma-Dasgupta-Fisher (1979)：强无序RG→随机单态相
- 有效能标Ω随RG流降低：Ω ~ Ω_0 exp(-c√L)
- 动力学结构因子S(q,ω)在随机单态相中有特征的ω^{-1+1/z}行为

## 电子-声子耦合(EPC)
- Holstein-Hubbard模型：H_Hubbard + g Σ n_i(a_i + a_i†)
- EPC修正RIXS响应：声子边带+磁激发重整化
- 同组2021 Science：EPC解释了部分RIXS偏离
