### §1 撞墙四攻击

**攻击1（端点退化的 log 发散）**：u=0 处 p=0，ln p=−∞。  
反击：被积函数 σ = sin(2u)·|ln cot u|，u→0+ 时 sin(2u) ≈ 2u，|ln cot u| ≈ −ln u，故 σ ≈ −2u ln u → 0。**log 发散被一阶零点 sin(2u) 吃掉**。同理 u=π/2−，σ→0。端点连续延拓到 [0, π/2] 闭区间。

**攻击2（ε(u) 路径相关性）**：取 ε(u)=u^a，a∈{1, 2, 4}。  
反击：核心恒等式 σ^ε(u) = (1−ε) sin(2u) · |ln(q^ε/p^ε)|。在 u∈(0,π/4)：
- q^ε > p^ε > 0 严格成立（对任何 ε∈[0,1)）
- 关键单调性：q^ε/p^ε ≤ q/p（添加 ε/2 到分子分母同时使比值趋向 1，证：((1−ε)q+ε/2)p < q((1−ε)p+ε/2) ⇔ (ε/2)p < (ε/2)q ⇔ p<q ✓）
- 故 |ln(q^ε/p^ε)| ≤ |ln(q/p)| = 2|ln cot u|
- σ^ε(u) ≤ sin(2u)·2|ln cot u| = σ⁰(u)，**无论 ε(u) 路径如何**

**攻击3（DCT 主控函数不可积）**：怀疑 σ⁰ ∉ L¹(0,π/2)。  
反击：σ⁰(u) ≤ 2u·|ln tan u|·2 = 4u·|ln tan u|（区间(0,π/4)）。在 u→0+，tan u ≈ u，σ⁰ ≈ −4u ln u；∫₀^δ |u ln u|du = [δ²(2 ln δ−1)/4 − ...]，δ→0 有限。在 u=π/4 处 σ⁰=0。区间 (π/4, π/2) 由 u→π/2−u 对称。**M(u):=σ⁰(u) 即是 L¹ 主控函数**，∥M∥₁ = 2 ln 2 < ∞。

**攻击4（边界熵 S_q^ε(0), S_q^ε(π/2) 不收敛到 0）**：ε→0 时 (ε/2) ln(ε/2) 是否真趋零。  
反击：lim_{x→0+} x ln x = 0（标准结果，由 L'Hôpital 或 Lebesgue 积分论）。S_q^ε(0) = h₂(ε/2) = −(1−ε/2) ln(1−ε/2) − (ε/2) ln(ε/2)。两项均 → 0。同理 u=π/2 端点。**边界贡献 O(ε ln ε) → 0**。

四攻击全部反击成功 → R0 通道开放。

### §D 推导（D1–D5）

**D1（构造 σ^ε 显式形式）**  
依据：H3, H5, 链式法则。  
由 q^ε(u) = (1−ε) cos²u + ε/2，dq^ε/du = −(1−ε) sin(2u)。  
dS_q^ε/du = (−ln q^ε + ln p^ε) · dq^ε/du = (1−ε) sin(2u) · ln(q^ε/p^ε)。  
在 (0,π/4) 取正，在 (π/4, π/2) 取负，π/4 处过零。  
σ^ε(u) := |dS_q^ε/du| = (1−ε) sin(2u) · |ln(q^ε/p^ε)|。

**D2（pointwise 极限）**  
依据：q^ε → q, p^ε → p 在 ε→0+ 是平滑收敛（多项式映射），ln 在 (0,1) 上连续。  
对 u ∈ (0,π/2)\{π/4}：σ^ε(u) → sin(2u)·|ln(q/p)| = sin(2u)·2|ln cot u| = σ⁰(u)。  
在 u=π/4：σ^ε = 0 = σ⁰。  
在端点 u∈{0, π/2}：σ⁰ 由 lim 给出 0；σ^ε 在 u=0 也 = 0 (sin(0)=0 主导)。  
**pointwise 在 [0,π/2] 全收敛**。

**D3（L¹ 主控）**  
依据：§1 攻击2 的单调性引理 + §1 攻击3 的可积性。  
∀ε(u) ∈ [0, 1/2]: σ^{ε(u)}(u) ≤ σ⁰(u)，且 σ⁰ ∈ L¹(0,π/2) with ∥σ⁰∥₁ = 2 ln 2。

**D4（DCT 应用）**  
依据：A4 Lebesgue 控制收敛定理 + D2 + D3。  
对任意 ε(u) → 0 的可测路径（ess sup ε(u) → 0 即可，更弱条件 ε(u) → 0 a.e. 也成立）：  
lim_{ε→0} ∫₀^{π/2} σ^{ε(u)}(u) du = ∫₀^{π/2} σ⁰(u) du = 2 ln 2。  
**严格等号，路径无关**。

**D5（与原积分公式对照）**  
依据：fundamental theorem of calculus 应用于分段单调。  
∫₀^{π/2} σ⁰(u) du = ∫₀^{π/4} dS_q + ∫_{π/4}^{π/2} (−dS_q) = 2·S_q(π/4) − S_q(0) − S_q(π/2) = 2 ln 2 − 0 − 0 = 2 ln 2 ✓  
正则化版本：2·S_q^ε(π/4) − S_q^ε(0) − S_q^ε(π/2) = 2 ln 2 − 2·h₂(ε/2)。  
ε→0+ 时 h₂(ε/2) → 0，**收敛速率 O(ε|ln ε|)**。

### §K 关键引理（关闭 C[v8-3]）

**K-A0（ε-Bogoliubov DCT 收敛引理）**  
设 ρ_B(u), u∈[0,π/2] 为 Bogoliubov 退化 2-bit 约化态，其熵导数 σ⁰(u)=2 sin(2u)·|ln cot u| ∈ L¹(0,π/2) 且 ∥σ⁰∥₁=2 ln 2。  
对任何可测路径 ε:[0,π/2]→[0,1/2] 满足 ε(u)→0（在 a.e. 或 ess sup 意义下）：  
- (i) σ^{ε(u)}(u) ≤ σ⁰(u) for a.e. u（单调性引理）  
- (ii) σ^{ε(u)}(u) → σ⁰(u) pointwise a.e.  
- (iii) 由 Lebesgue DCT：lim ∫ σ^{ε(u)} du = ∫ σ⁰ du = 2 ln 2  

**推论**：N_I^{(S)} = 2 ln 2 是路径独立的精确值，ε-正则化方案不引入歧义。
