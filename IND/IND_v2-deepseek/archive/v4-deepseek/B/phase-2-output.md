## B1: 相对熵候选的物理检验

### B1.1 Class I物理图景验证

**Σ_rel = dS/dt 在Class I中意味着什么？**

H*∝I → 无能量等级 → 无热流。系统从非平衡初态弛豫时：
- 没有"热"进出系统（dQ_S=0）
- 所有不可逆性来自系统内部混合化（dS/dt）
- Σ_rel = dS/dt 精确捕捉了这个过程

**物理解释**: qubit在σ_x⊗B+Gaussian bath中弛豫时，bath不断翻转qubit但不偏好任何能量方向。系统的演化是纯混合化——从任何初态向最大混态I/2弛豫。熵产生=熵增加，"热力学力"是"偏离最大混态的程度"而非"能量差"。

**检验**: 超导qubit实验——制备非平衡初态（如|0⟩⟨0|纯态），让其在强耦合σ_x通道下弛豫。测量ρ_S(t)（量子态层析），计算S(t)=−Tr[ρ_S log ρ_S]。预测：Σ_rel(t)=dS/dt与从全系统能量平衡推算的"真实熵产生"一致，而Σ_std(t)=dS/dt−β·d⟨H_S⟩/dt会给出错误结果（可能为负）。

### B1.2 Class II/III中的行为

H*非平凡时，ρ_S^eq=e^{−βH*}/Z*≠I/d。Σ_rel = dS/dt − β·Tr[ρ̇_S H*] 捕捉了：
1. 系统混合化（dS/dt项）
2. 能量弛豫→热流（−β·Tr[ρ̇_S H*]项）

**物理检验**: transmon qubit (Class II, E_C≈300MHz, 三个能级) + σ_x⊗B耦合。H*在Class II中非平凡（[H*,H_S]≠0），ρ_S^eq≠I/d。Σ_rel应同时包含混合化和能量弛豫的贡献。

## B2: 可证伪预测

### 预测1（v4 smoking gun — Class I符号差异）

**预测**: 在Class I（qubit+σ_x⊗B+Gaussian bath）中，对同一非平衡过程：
```
Σ_rel(t) = dS/dt ≥ 0                   (正确熵产生)
Σ_std(t) = dS/dt − β·d⟨H_S⟩/dt         (标准公式)
```
Σ_rel(t)恒≥0（相对熵单调性），但Σ_std(t)可取任意符号。

**证伪条件**: 如果测量显示Σ_rel(t) < 0（在Markovian极限下），候选1被否证。

**实验**: 超导qubit+强σ_x耦合（flux qubit或transmon with σ_x drive）。同时通过量子态层析测ρ_S(t)，计算dS/dt和d⟨H_S⟩/dt，比较Σ_rel与Σ_std。

### 预测2（弱耦合过渡）

**预测**: α从0逐渐增大时，Σ_std从与Σ_rel一致逐渐偏离。偏离量：
```
Σ_std − Σ_rel = β·d⟨H_S⟩/dt − 2β·Tr[ρ̇_S H*]
```
在Class I中：= β·d⟨H_S⟩/dt。

在α²≪1时偏离为O(α²)，在α~0.3时达到可测量水平。

**证伪**: 如果α→0时Σ_rel不连续过渡到Σ_std，候选1被否证。

### 预测3（Layer (a)规范不变性）

**预测**: Σ_rel在Rivas H†替换H*下保持不变（A5-C2已证明）。实验上：无论使用哪种规范固定方案计算ρ_S^eq，只要满足detailed balance条件，Σ_rel相同。

## B3: Q3 — 物理价值

### 如果v4-K5正确（Σ_rel是正确规范不变熵产生）

**排除了什么？**
1. tr(ρ̇_S δH)在强耦合下作为熵产生核心量的合法性——被Σ_rel正式取代
2. Talkner-Hänggi熵产生公式在Class I中给出错误诊断的路径——被修正为Σ_rel=dS/dt
3. Layer (c)规范歧义——被Spohn(1978)的相对熵公式解决（旧公式的新物理含义）

**打开了什么？**
1. **从ρ_S可计算强耦合熵产生**：不需要bath信息（不需要ρ_B或全系统演化），仅需ρ_S(t)和H*（或H†），在当前NISQ实验中可行
2. **Class I作为校准基准**：任何声称的"强耦合熵产生公式"必须通过Class I测试（给出dS/dt）
3. **与Colla-Breuer最小耗散的对接**：Σ_rel在traceless Lindblad固定（Layer b）下与Colla的热流定义一致→三层规范(a)(b)(c)的完整统一方案
4. **实验量子热力学的路线图**：
   - 步骤1: 表征H*（通过平衡态测量或谱学）
   - 步骤2: 固定Layer (a)——用Rivas条件得到H†
   - 步骤3: 固定Layer (b)——用Colla-Breuer traceless Lindblad得到K_S(t)
   - 步骤4: 计算Σ_rel(t) = dS/dt − β·Tr[ρ̇_S H†]（从ρ_S(t)和H†）
   - 步骤5: 验证Σ_rel(t) ≥ 0（第二定律检验）+ Σ_rel(t) = 全系统熵产生（自洽性检验）

**物理价值**: 将Spohn (1978)的旧公式重新解释为强耦合量子热力学的"正确"系统级熵产生。公式本身不新——新的是它的使用语境（强耦合）、测试基准（Class I压力测试）、以及它在三层规范问题中的位置（Layer c解）。

**与Rivas et al.的关系**: Rivas解决"应该用哪个H*？"（Layer a），v4解决"tr(ρ̇_S δH)应该被解释为什么？"（Layer c）。答案：不应被解释为熵产生——Σ_rel才是。两个工作互补且无冲突：使用Rivas的H†作为Layer (a)输入，使用v4的Σ_rel(H†)作为Layer (c)输出。

### 如果v4-K5被否证（所有候选失败）

**转为no-go定理**:
> 不存在从ρ_S(t)可计算且满足所有物理约束的系统级规范不变熵产生。系统-bath分割在强耦合下失去热力学合法性——只有全系统熵产生Σ_tot是良定义的。

**物理价值**: 不亚于建设性方案。排除了一条看似自然但实际不通的路径，定义了量子热力学中"系统级描述"的边界。
