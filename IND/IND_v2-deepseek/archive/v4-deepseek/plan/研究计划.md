# 研究计划 — v4-deepseek

## 北极星
**强耦合量子热力学中"熵产生"的规范不变定义——在H*平凡化极限下重建tr(ρ̇_S δH)的热力学意义，或将其降级为规范人工制品**

## 驱动矛盾

**命题A (v3-K10, linked-cluster定理)**：Gaussian bath + qubit → H*精确∝I，有效Hamiltonian平凡——无能量等级，无法定义基于H*的热流方向。

**命题B (强耦合热力学标准框架, Talkner-Hänggi 2020)**：强耦合下系统内能应使用H*定义：U_S = tr(ρ_S H*)，热流应基于此内能的变化。H*∝I → U_S = const·tr(ρ_S) = const → dU_S/dt = 0 → 无热力学内容。

**精确矛盾**：
- tr(ρ̇_S δH) 在标准框架中被解释为熵产生率的核心组成
- 但在H*∝I时，δH = H_S − cI，tr(ρ̇_S δH) = tr(ρ̇_S H_S) = d⟨H_S⟩/dt
- d⟨H_S⟩/dt是裸系统能量的变化率——在弱耦合下这是正确的热流，但在强耦合下这不是
- **K12声称的"ρ̇_S符号自由"可能是规范自由度而非物理熵产生**

换言之：v3证明了H*∝I + ρ̇_S符号自由。但这两个结论合在一起意味着：被解释为"熵产生"的量tr(ρ̇_S δH)在H*∝I极限下退化为裸系统能量的变化率——而裸系统能量在强耦合下不被认为是正确的热力学内能。**v3的K10-K13链可能自我削弱了tr(ρ̇_S δH)的热力学合法性。**

## 可观测性锚点

可测量的量：在Class I (qubit+σ_x⊗B)中，⟨H_S⟩的变化率 vs 实际热流（需要浴侧测量或全系统能量平衡）
当前测量精度：超导量子比特实验中⟨σ_z⟩的连续弱测量可达SNR~1 (2024)
效应量级：H*与H_S的差异∝α²（~0.1 at α=0.3），在强耦合下可分辨
相差数量级：O4为主（理论框架层面），但有通往O3的路径（超导qubit实验可测⟨H_S⟩变化率 vs 浴能量变化）

定位：[x] O4为主（理论框架+规范分析） [x] 有通往O3的路径（超导量子比特实验可区分d⟨H_S⟩/dt和实际热流） [x] O5可能性（如结论为"tr(ρ̇_S δH)应被降级为规范人工制品"，构成否定性结论——但有建设性替代方案）
