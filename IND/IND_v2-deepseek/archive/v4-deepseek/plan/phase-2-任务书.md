# Phase 2 任务书：规范不变熵产生 Σ_S^{(gauge)} 的构造与Class I基准检验

**类型：B（推导——候选构造+基准检验+下选）**

## 前期成果禁区确认
本Phase不重复建立：H*∝I (v3-K10) + tr(ρ̇_S δH)退化 (v4-K1) + 规范歧义分类学 (v4-K3) + Rivas Intrinsic HMF在Class I中平凡 (v4-K2)

本Phase新增：**构造至少一个通过Class I基准检验的候选Σ_S^{(gauge)}，或证明所有候选都失败（no-go）。**

## 驱动矛盾
**命题A (v4-K1/K4)**：Class I中tr(ρ̇_S δH)应被降级为规范人工制品——不是熵产生。
**命题B (热力学必要性)**：即使tr(ρ̇_S δH)不是熵产生，系统+bath联合系统仍产生熵。需要一个从ρ_S可访问的量正确量度系统级熵产生。
**核心问题**：如果tr(ρ̇_S δH)不是答案，什么才是？

**Class I基准约束**（候选Σ_S^{(gauge)}必须满足）：
1. Σ_S^{(gauge)} = 0 当 ρ_S = ρ_S^eq ∝ I（平衡）
2. Σ_S^{(gauge)} ≥ 0 对CPTP演化（第二定律，Markovian极限）
3. Σ_S^{(gauge)} = dS(ρ_S)/dt 在Class I中（dQ_S/dt=0→正确熵产生=熵变化率）
4. Σ_S^{(gauge)} → 标准tr(ρ̇_S δH)公式在弱耦合α→0（连续性）
5. Σ_S^{(gauge)} 在Class II/III中给出非平凡结果（非退化）

## 北极星距离检查（B类Phase强制）
当前北极星：强耦合下熵产生规范不变定义——重建或降级tr(ρ̇_S δH)
本Phase推进：v4-K4完成"降级"→Phase 2推进"重建"。若候选构造成功→北极星达成（有规范不变的替代量）。若所有候选失败→北极星以no-go定理形式达成。

## 声张与可证伪预测
**核心声张**：相对熵熵产生 Σ_rel = −d/dt S(ρ_S(t)||ρ_S^eq) 是Layer (c)规范歧义的正确解决方案——在Class I中= dS/dt（正确），在Class II/III中恢复非平凡热力学内容，在弱耦合极限连续过渡到标准公式。

**可证伪预测**：
- 预测1: Class I中Σ_rel(t) = dS/dt ≥ 0恒成立，但tr(ρ̇_S δH)可取任意符号——两者之差 = −β·d⟨H_S⟩/dt（可正可负）
- 预测2: α→0时Σ_rel → dS/dt − β·tr(ρ̇_S H_S)（标准公式）——α²阶连续过渡
- 预测3: 对traceless Lindblad算子（Colla-Breuer固定），Σ_rel与Colla的热流定义一致
- 检验方式: 超导qubit实验测dS/dt和d⟨H_S⟩/dt，验证Σ_rel=dS/dt ≠ tr(ρ̇_S δH)/T
- 证伪条件: 如果Σ_rel在Class I可<0（违反相对熵单调性），或α→0时偏离标准公式非连续

## 博士A任务（候选构造+形式检验）

### A1. 候选1: 相对熵熵产生（Spohn 1978）
```
Σ_rel(t) = −d/dt|_{s=t} S(ρ_S(s) || ρ_S^eq(t))
```
其中S(ρ||σ) = tr[ρ(log ρ − log σ)], ρ_S^eq(t) = e^{−βH*}/Z*。

**Class I检验**（H*∝I → ρ_S^eq = I/d）：
```
S(ρ_S || I/d) = tr[ρ_S(log ρ_S + log d)] = −S(ρ_S) + log d
Σ_rel = −d/dt S(ρ_S||I/d) = dS(ρ_S)/dt
```
✅ 约束3 (=dS/dt)。✅ 约束2 (相对熵单调性保证≥0)。✅ 约束1 (平衡时ρ_S=I/d, S(ρ_S||I/d)=0)。

**弱耦合连续性**：α→0 → H*→H_S → ρ_S^eq→e^{−βH_S}/Z_S → Σ_rel → dS/dt + β·tr(ρ̇_S H_S) − β·dF_S/dt = dS/dt − β·tr(ρ̇_S H_S)（对等温过程dF_S/dt=β⁻¹·tr(ρ̇_S log ρ_S^eq) = −tr(ρ̇_S H_S)）。标准公式恢复。✅ 约束4。

**一般证明**（Breuer-Petruccione 2002 §3.4）：对GKLS生成子L满足L[ρ_S^eq]=0的Markovian演化：
```
Σ_rel = tr[L[ρ_S](log ρ_S^eq − log ρ_S)] ≥ 0
```
不等号来自相对熵在CPTP映射下的单调性。

### A2. 候选2: 浴侧熵产生
```
Σ_bath = −dI(S:B)/dt + ΔS_bath
```
其中I(S:B) = S(ρ_S) + S(ρ_B) − S(ρ_tot)。

**优点**：从全系统出发不依赖H*。**缺点**：需ρ_B信息——实验不可直接访问。**Class I检验**：需具体模型计算。

### A3. 候选3: 全系统熵产生（基准）
```
Σ_tot = dS(ρ_tot)/dt + β·Φ_B
```
其中Φ_B = 进入bath的能流。**用途**：基准——任何候选Σ_S^{(gauge)}应 ≤ Σ_tot。

### A4. 候选4: 几何/量子Fisher信息
使用斜信息 I_α(ρ, H*)。
**Class I**: H*∝I → I_α(ρ, cI) = 0 ∀ρ。完全退化——若Class I中真正无熵产生(dQ_S=0)，退化是正确的。但在Class II中需验证非退化。

### A5. 候选对比矩阵
| 候选 | 约束1(平衡) | 约束2(≥0) | 约束3(Class I) | 约束4(弱耦合) | 约束5(Class II) | ρ_S可计算 |
|------|-----------|---------|---------------|-------------|---------------|----------|
| 1. 相对熵 | ✅ | ✅(单调性) | ✅(=dS/dt) | 待验证 | 待验证 | ✅ |
| 2. 浴侧 | 待验证 | ✅ | 待验证 | 待验证 | 待验证 | ❌(需ρ_B) |
| 3. 全系统 | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| 4. 几何 | ⚠️(I_α=0) | ✅ | ⚠️(退化) | 待验证 | 待验证 | ✅ |

**初步下选**：候选1（相对熵）最有希望。候选3（全系统）正确但不可操作——作为理论基准。候选4在Class I中退化需要理解为"正确退化"。

### A6. 卡点
- 预期卡点1: Σ_rel在非Markovian演化下可能<0——Phase 2先限制在Markovian极限
- 预期卡点2: Σ_rel需要ρ_S^eq——H*非平凡时ρ_S^eq依赖H*，Layer (a)规范歧义需要先用Rivas固定

## 博士B任务（物理检验+可证伪预测+Q3）

### B1. 相对熵候选的物理检验
- **Class I物理图景**: ρ_S^eq∝I → "远离平衡"=偏离最大混态 → Σ_rel = dS/dt = 系统混合速率。与"无能量等级→无热流→所有不可逆性=混合"一致。
- **Class II物理图景**: ρ_S^eq∝e^{−βH*}非平凡 → Σ_rel = dS/dt + β·tr(ρ̇_S H*) − β·dF_S/dt。混合+能量弛豫+自由能变化。
- **弱耦合过渡**: α→0 → 连续→标准公式。

### B2. 可证伪预测
**预测1（smoking gun）**: Class I中Σ_rel = dS/dt ≥ 0但tr(ρ̇_S δH)=d⟨H_S⟩/dt可取任意符号。两者之差=−β·d⟨H_S⟩/dt——实验上通过同时测dS/dt和d⟨H_S⟩/dt区分。
**预测2**: α→0时Σ_rel连续过渡到标准公式。
**预测3**: 联合使用Rivas Intrinsic HMF（固定Layer a） + Σ_rel（解决Layer c）→ Class II/III中完整的规范不变热力学。

### B3. Q3
**如果Σ_rel是正确的规范不变熵产生**：
- **排除了什么**: 排除了tr(ρ̇_S δH)在强耦合下作为熵产生的合法性（形式化v4-K4否定性结论）
- **打开了什么**: 提供了一个从ρ_S(t)可计算且无需bath信息的规范不变熵产生——可在当前NISQ实验中直接测量
- **物理价值**: 将Spohn (1978)的旧公式重新解释为强耦合量子热力学的"正确"系统级熵产生——旧公式的新物理意义

**如果Σ_rel也失败（例如在Class II中<0或退化）**：
- **转为no-go定理**: 不存在从ρ_S(t)单独可计算的系统级规范不变熵产生。系统-bath分割在强耦合下失去热力学合法性——只有全系统熵产生是良定义的。
- **物理价值**: 不亚于建设性方案——排除了一条看似自然的路径，定义了热力学在开放系统中的边界。
