## 博士A任务（数学结构侧：四点T_τ函数的完整计算）

### §N.1 T_τ四点关联函数的配对结构
对X = α∫₀^β dτ σ_x(τ)⊗B(τ)，Gaussian bath下：
```
⟨T_τ X⁴⟩_c = 0  (Gaussian bath — all cumulants beyond 2 vanish)
```
但H*涉及⟨T_τ e^{-X}⟩的完整展开，四点贡献来自**ln展开的二次项**：
```
ln⟨T_τ e^{-X}⟩ = ⟨T_τ e^{-X}−1⟩ − ½⟨(T_τ e^{-X}−1)²⟩ + ⅓⟨(T_τ e^{-X}−1)³⟩ − ...
```
展开到α⁴需要：⟨T_τ X²⟩(α²项) + ⟨T_τ X⁴⟩/12 − ⟨T_τ X²⟩²/8 (α⁴项)

**关键计算1**：计算⟨T_τ X⁴⟩中来自Wick定理三项的T_τ排序结构。
对Gaussian bath的Wick定理：
⟨T_τ[B(τ₁)B(τ₂)B(τ₃)B(τ₄)]⟩ = G₁₂G₃₄ + G₁₃G₂₄ + G₁₄G₂₃

系统算符的T_τ排序取决于τ₁,τ₂,τ₃,τ₄的排序。24个排序区域各有不同的算符乘积。

**关键计算2**：[⟨T_τ X²⟩]²的算符结构。注意这是两个算符的乘积（不是标量乘积）——不同τ区域的T_τ排序在乘积中如何组合？

### §N.2 σ_z分量的奇偶性分析（核心突破点）
α²计算中σ_z消去的本质原因：T_τ[σ_x(τ₁)σ_x(τ₂)]的σ_z系数是sgn(τ₁−τ₂)·sinh(ω₀|τ₁₂|)，在τ₁↔τ₂下反称→与偶函数G(|τ₁₂|)的乘积积分为零。

α⁴计算中：四点T_τ[σ_x(τ₁)σ_x(τ₂)σ_x(τ₃)σ_x(τ₄)]的σ_z系数涉及更复杂的对称性。对不同的Wick配对通道：
- 通道(12)(34)：被积函数的τ₁,τ₂对称性与α²类似→可能仍为零
- 通道(13)(24)和(14)(23)：跨越配对改变对称性→可能是σ_z分量的首次非零来源

**关键计算3**：显式计算通道(13)(24)的四点T_τ排序积分，判断σ_z分量是否非零。

### §N.3 [⟨T_τ X²⟩]²的算符乘法（决定性步骤）
⟨T_τ X²⟩是系统空间的算符。其平方[⟨T_τ X²⟩]² = ⟨T_τ X²⟩·⟨T_τ X²⟩。

由于⟨T_τ X²⟩ ∝ I（α²阶结论），[⟨T_τ X²⟩]² ∝ I² = I——平凡。

因此⟨T_τ X⁴⟩/12 − [⟨T_τ X²⟩]²/8中，第二项也是平凡的。非平凡结构只能来自⟨T_τ X⁴⟩。
