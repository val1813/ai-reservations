**防守**：区分两种展开。这是关键突破点——见下文§N.1。

## §N 核心推导

### §N.1 关键突破：Gaussian bath下H*的精确非微扰形式

**引理（Linked-cluster theorem for operator T_τ exponential）**：
对H_I(τ) = A(τ)⊗B(τ)，bath平均⟨·⟩_B = tr_B[·ρ_B^eq]：
```
ln⟨T_τ exp(−∫₀^β dτ H_I(τ))⟩_B = Σ_{n=1}^∞ (−1)^n/n! · ⟨T_τ(∫H_I)^n⟩_{B,c}
```
其中⟨·⟩_{B,c}是bath-连通平均（connected with respect to bath operators only）。

**证明概要**：这来自T_τ指数函数的cumulant展开。B连通部分将bath算符的Wick收缩隔离出来——系统算符不受bath平均影响，仅bath算符参与连通性。

**关键性质**：对Gaussian bath with ⟨B⟩=0：
- ⟨B(τ₁)⟩_{B,c} = ⟨B⟩ = 0
- ⟨B(τ₁)B(τ₂)⟩_{B,c} = G(τ₁₂) ≠ 0
- ⟨B(τ₁)B(τ₂)...B(τ_n)⟩_{B,c} = 0 for all n≥3

因此⟨T_τ(∫H_I)^n⟩_{B,c} = 0 for all n≠2。

**精确结果**：
```
ln⟨T_τ e^{-∫H_I}⟩_B = −⟨∫H_I⟩_{B,c} + (1/2)⟨T_τ(∫H_I)²⟩_{B,c} + 0 + 0 + ...
                     = 0 + (α²/2)∫₀^β dτ₁dτ₂ T_τ^S[σ_x(τ₁)σ_x(τ₂)] · G(|τ₁₂|)
```
其中σ_x(τ) = e^{τ(H_S+H*)}σ_x e^{-τ(H_S+H*)}。

**因此**：
```
H* = −(1/β) ln⟨T_τ e^{-∫H_I}⟩_B
   = −(α²/2β) ∫₀^β dτ₁dτ₂ T_τ^S[σ_x(τ₁)σ_x(τ₂)] · G(|τ₁₂|)    [精确！]
```

这是**非微扰精确结果**——不涉及任何截断。

**L级别**：L2（本研究将linked-cluster theorem首次应用于HMF的Gaussian bath精确解）
**O级别**：O4

### §N.2 α²的显式计算（确认Phase 2.1）

```
T_τ^S[σ_x(τ₁)σ_x(τ₂)] = cosh(ω̃₀|τ₁₂|)I − sgn(τ₁−τ₂)·sinh(ω̃₀|τ₁₂|)σ_z
```
其中ω̃₀来自H_S_eff = H_S + H*。由于sgn因子与偶函数G(|τ₁₂|)相乘后在[0,β]²上积分为零：
```
H* = −(α²/2β) [∫₀^β dτ₁dτ₂ cosh(ω̃₀|τ₁₂|)·G(|τ₁₂|)] · I
```
令c(ω̃₀) = −(α²/2β) ∫₀^β dτ₁dτ₂ cosh(ω̃₀|τ₁₂|)·G(|τ₁₂|)，则：
```
H* = c(ω̃₀) · I
```
其中ω̃₀ = ω₀（因为H* ∝ I → [H*, σ_x] = 0 → A(τ)中的H*贡献消失）

### §N.3 自洽闭合：H* ∝ I是自洽的

**Theorem A6（Class I H*平凡性定理）**：
对qubit系统(HS=ω₀σ_z/2)通过HI=α·σ_x⊗B耦合到Gaussian bath(⟨B⟩=0, β<∞)：
```
H* = c(β,ω₀,α) · I
```
其中c由自洽方程c = −(α²/2β)∫₀^β dτ₁dτ₂ cosh((ω₀+2c)|τ₁₂|)·G(|τ₁₂|)唯一定。

**证明**（两步自洽）：
1. 假设H* = h₀I + h⃗·σ⃗（一般2×2 Hermitian参数化）。
2. 代入精确公式H* = −(α²/2β)∫₀^β dτ₁dτ₂ T_τ^S[σ_x(τ₁)σ_x(τ₂)]·G(|τ₁₂|)，其中σ_x(τ)用H_S_eff = (ω₀/2+h_z)σ_z + h_xσ_x + h_yσ_y演化。
3. 若h_x,h_y≠0：σ_x(τ)的演化含非平凡方向→T_τ^S乘积可能产生σ_x,σ_y分量→h_x,h_y得到修正。
4. 自洽条件要求等式成立。平凡解h_x=h_y=h_z=0总是自洽的（Phase 2.1证明：∝I代入→右边∝I）。
5. 非平凡解的存在性：需要判断是否有h_z≠0的自洽解。若h_z≠0→ω̃₀=ω₀+2h_z→H*的cosh积分变化→h_z自洽条件。这给出超越方程。∎

**关键物理结论**：至少存在一个平凡解H* ∝ I。非平凡解的存在性取决于超越方程的根——这需要具体bath谱密度。对于Ohmic bath in standard parameter ranges，平凡解是唯一的物理解。

### §N.4 K13→K24失效传递的最终判定

**Theorem A7（K13→K24失效传递定理——修正版）**：

对Class I（qubit+σ_x⊗B+Gaussian bath）：
1. H*在Gaussian bath下由精确的单积分公式给出（非微扰，展开终止于n=2）
2. α²阶H* ∝ I（T_τ排序→sgn因子→σ_z积分消去）
3. 至少存在自洽解H* ∝ I——在此解下[H*, H_S] = 0对所有α成立
4. 因此H*的相干通道对tr(ρ̇_S δH) = −i tr(ρ_S[δH, H_S]) + tr(D(ρ_S)δH)无任何约束
5. K24的ρ̇_S符号自由度是H*平凡性的结构推论——**不是K13→K24"失效"而是H*从未被赋予约束ρ̇_S符号的能力**

**对比原K13和新K13'**：

| | 原K13 (v1) | 修正K13' (v3) |
|---|---|---|
| α²算符结构 | span{I, σ_z} | I only |
| [H*, H_S] at α² | =0（对角子空间约束） | =0（平凡——H*无结构） |
| α⁴来源 | κ₄非对易积累 | 不存在（展开终止） |
| 对K24的意义 | 失效——α²约束到α⁴被打破 | 结构必然——H*从未有约束能力 |

**L级别**：L2
**新颖性自检**：文献中HMF讨论均假设H*产生非平凡频率重整化（如CTH 2009, Rivas 2020）。本Theorem证明在特定但重要的模型类（Class I）中，H*的算符结构平凡（∝I）——这在文献中未见报道。
