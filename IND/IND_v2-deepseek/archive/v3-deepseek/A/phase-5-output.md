## §1 强制撞墙

### 攻击1：Class I的σ_x²=I特性是否掩盖了真正的物理？

承认。σ_x²=I使所有偶数乘积∈span{I,σ_z}——这是Pauli代数的特殊性质。对一般d>2系统，A²≠I→不保证对角性。Phase 5的任务是量化"偏离对角性"作为A(τ)代数结构的函数。

### 攻击2：Class II中[H*,H_S]≠0是否意味着HMF确实有物理内容？

是的——Class II中H*可以获得非平凡算符结构（频率重整化、本征基旋转等）。这正是Class I作为"控制案例"的价值：定量对比Class I(无H*结构)和Class II(有H*结构)来识别HMF效应的真正来源。

## §N 核心推导

### §N.1 一般A的α²阶H*结构

对H_S = Σ_i E_i|i⟩⟨i|（有限维，无简并），A = Σ_{ij} A_{ij}|i⟩⟨j|（A_{ji}=A_{ij}^* for Hermitian），bath耦合H_I = α·A⊗B，Gaussian bath。

α²阶H*（精确，linked-cluster）：
```
H*^(2) = −(α²/2β) ∫₀^β dτ₁dτ₂ A(τ₁)A(τ₂) · G(|τ₁₂|)
```
其中A(τ) = e^{τH_S}A e^{-τH_S} = Σ_{ij} A_{ij} e^{τ(E_i−E_j)} |i⟩⟨j|

```
A(τ₁)A(τ₂) = Σ_{il} [Σ_j A_{ij}A_{jl} e^{τ₁(E_i−E_j)+τ₂(E_j−E_l)}] |i⟩⟨l|
```

对于i=l（对角元）：系数 = Σ_j |A_{ij}|² e^{(E_i−E_j)(τ₁−τ₂)}
对于i≠l（非对角元）：系数 = Σ_j A_{ij}A_{jl} e^{τ₁(E_i−E_j)+τ₂(E_j−E_l)}

### §N.2 对角元（频率重整化）

对角元对H*的贡献按|i⟩⟨i|：
```
H*^(2)_{ii} = −(α²/2β) Σ_j |A_{ij}|² ∫₀^β dτ₁dτ₂ e^{(E_i−E_j)(τ₁−τ₂)} G(|τ₁₂|)
```

τ₁,τ₂积分：令s=τ₁−τ₂。对偶函数G：∫₀^β dτ₁dτ₂ e^{ΔE·s} G(|s|) = β ∫_{-β}^{β} ds (1−|s|/β) e^{ΔE·s} G(|s|)

被积函数含cosh(ΔE·s)G(|s|)（偶部分）+ sinh(ΔE·s)·（sgn奇部分→积分零）。

对角贡献→非零（来自cosh项）。这给出频率重整化（本征值移位）——Class I中cosh(ω₀s)项也非零，但贡献到I而非σ_z（因为qubit只有两个能级，对角元差对应σ_z，但Class I的特殊性在于能级对称使得对角元差为零）。

对一般d>2系统：H*^(2)对角部分给出非平凡的能级重整化≠常数移位。

### §N.3 非对角元（[H*,H_S]≠0的来源）

对i≠l：
```
H*^(2)_{il} = −(α²/2β) Σ_j A_{ij}A_{jl} ∫₀^β dτ₁dτ₂ e^{τ₁(E_i−E_j)+τ₂(E_j−E_l)} G(|τ₁₂|)
```

令u=(τ₁+τ₂)/2, s=τ₁−τ₂：
τ₁(E_i−E_j)+τ₂(E_j−E_l) = u(E_i−E_l) + s(E_i+E_l−2E_j)/2

积分：
```
I_il = ∫₀^β dτ₁dτ₂ e^{uΔ_{il}+s·E_{ijl}} G(|s|)
```
其中Δ_il = E_i−E_l, 2E_{ijl} = 2E_j−E_i−E_l（"离壳度"）。

u积分：∫₀^β du e^{uΔ_{il}} = β sinc(iβΔ_{il}/2) e^{βΔ_{il}/2}（有限→非零一般）

s积分：∫_{-∞}^{∞} ds e^{s·E_{ijl}} G(|s|)（β→∞近似） = J(E_{ijl})/(1−e^{-βE_{ijl}})（涨落-耗散定理）

**关键**：非对角元一般非零，除非所有j都满足A_{ij}A_{jl}=0（Theorem A5的充分条件——A不连接i和l通过任何中间态j）。

### §N.4 Class II的[H*,H_S]量级

```
||[H*, H_S]|| ∼ α² · max_{i≠l} |E_i−E_l| · |H*^(2)_{il}|
```

对典型的多能级系统（如transmon的3-5能级）：|E_i−E_l| ∼ ω₀∼GHz，A_{ij}A_{jl} ∼ O(1)，G(|τ₁₂|)积分∼O(β⁻¹)。因此：

||[H*, H_S]|| ∼ α²ω₀（在马尔可夫耦合参数下）

对α=0.3, ω₀=5GHz×2π：||[H*,H_S]|| ∼ 2π×0.5GHz。非平凡——与H_S自身(2π×2.5GHz)同量级！

### §N.5 Class分类

**Class I** (d=2, A²∝I): [H*,H_S]=0对所有α——H*∝I。频率重整化=0（除常数移位）。

**Class IIa** (d=2, A²∝̸I, e.g., A=σ_x+εσ_z): [H*,H_S]≠0在α²阶——来自A的非对角分量不能形成封闭代数。量级∼α²ε。

**Class IIb** (d>2, 简并能级): 简并子空间内A可自由连接→对角性在简并子空间内保持。跨简并子空间的连接产生[H*,H_S]≠0——量级与能级间距成比例。

**Class III** (d>2, 无简并, 通用A): [H*,H_S]≠0在α²阶——量级由最强的跨能级连接决定。
