## §0 交叉验算

### A的核心声称
1. LGKS耗散允许tr(ρ̇_S δH)取任意符号——对σ_x,σ_y,σ_z方向均成立
2. Jensen"失效"是因为其在强耦合下前提（TPM/Crooks）不适用，非Jensen本身错误

### 独立验证：用纯dephasing极限

H_S=ω₀σ_z/2, H_I=σ_z⊗B。耗散有精确解（纯dephasing，无能量弛豫）：
```
D(ρ_S) = γ_dephase(t)(σ_zρ_Sσ_z − ρ_S)
```

tr(D(ρ_S)σ_z) = 0（σ_z·σ_z·σ_z − σ_z ∝ I − I = 0）

但tr(D(ρ_S)σ_x) = −2γ_dephase·x。令x>0 → 负号；x<0 → 正号。✓ 符号自由。

与A一致。

### 替代验算：增益-损耗方程

将Pauli基下的方程重写为增益-损耗形式：
```
∂_t p₀ = −γ₊ p₀ + γ₋ p₁
∂_t p₁ = +γ₊ p₀ − γ₋ p₁
∂_t ρ₀₁ = −(iω₀ + Γ_⊥)ρ₀₁
```

其中p₀=ρ₀₀, p₁=ρ₁₁, ρ₀₁=(x−iy)/2是相干项。

对任意初始条件，∂_t p₀的符号由γ₊p₀−γ₋p₁的符号决定→可取正负。热化方向约束的是p₀→p₀^eq=γ₋/(γ₊+γ₋)的全局趋势，而非每个时刻的导数符号。

## §1 强制撞墙

### 物理攻击1：∂_t S(ρ_S||ρ_S^eq) ≥ 0 是否约束了∂_t tr(ρ_S δH)的符号？

**攻击**：S(ρ_S||ρ_S^eq) = tr(ρ_S ln ρ_S) − tr(ρ_S ln ρ_S^eq)。∂_t S = tr(∂_t ρ_S(ln ρ_S − ln ρ_S^eq))。这约束了∂_t ρ_S在"ln ρ_S方向"的投影符号，而不约束任意δH方向的投影。

以ρ_S = ½(I + zσ_z)为例：
ln ρ_S − ln ρ_S^eq = ½ln((1+z)/(1−z))σ_z + βω₀σ_z/2 + const

∂_t S ≥ 0只约束∂_t z的符号（当z≠z_eq时）——**不约束∂_t x或∂_t y的符号**。

而δH ∝ σ_x时，tr(ρ̇_S δH) ∝ −ω₀y + Γ_⊥x/2——涉及x和y，不被∂_t S ≥ 0约束。

✓ 攻击偏——第二定律只约束z分量，x-y平面的符号完全自由。

### 物理攻击2：实验上能否观测到tr(ρ̇_S δH)的符号反转？

**攻击**：∂_t ρ_S不能直接测量——只能通过态层析+有限差分近似→符号反转的信号可能被测量噪声淹没。

**防守**：不需要测量∂_t ρ_S。Theorem A8可直接检验：
1. 制备初态x>0,y=0→测量d⟨σ_x⟩/dt的符号→应为正
2. 制备初态x<0,y=0→测量d⟨σ_x⟩/dt的符号→应为负
3. 通过态层析测量x(t)在两个初态下的演化方向即可

## §N 物理分析

### 符号自由度的相空间结构

Theorem A8给出三维相空间(x,y,z)中的符号结构：
- δH=σ_x：符号边界是直线y = (Γ_⊥/2ω₀)x
- δH=σ_y：符号边界是直线x = −(Γ_⊥/2ω₀)y
- δH=σ_z：符号边界是平面z = z_eq

对于物理参数Γ_⊥/ω₀∼0.1-0.3（弱到中等耦合），符号边界接近坐标轴。

### 与K24的精确关系

K24(v1)的ρ̇_S符号自由度定理说"tr[ρ̇_S δH]可取任意符号"。Theorem A8给出了精确条件：

**对任意符号s=±1**，存在Bloch球内的点(x,y,z)使tr(ρ̇_S δH)具有该符号——只要δH不是恒等算符的倍数。具体构造如上§N.4。

**不可取任意符号的情形**：
- 若δH ∝ I → tr(ρ̇_S δH) ≡ 0（迹守恒）
- 若ρ_S = ρ_S^eq → tr(ρ̇_S δH) = 0对所有δH（平衡态不动点）
- 若限制在z=z_eq平面上→δH=σ_z投影符号为零

## §P 声张与可证伪预测

### 核心声张
D(ρ_S)在LGKS形式下不约束tr(ρ̇_S δH)的符号——相干项(−i[H_S,ρ_S])和耗散项(D(ρ_S))共同提供完整的符号自由度。

### 预测值
对transmon qubit (ω₀/2π=5GHz, T=50mK, α=0.3, Ohmic bath)：
- Γ_⊥ ≈ 2π×50MHz（估算）
- 符号反转时间：τ_rev ≈ 2π/ω₀ ≈ 0.2ns（相干驱动）
- 信号幅度：|tr(ρ̇_S σ_x)| ≈ ω₀/2 ≈ 2π×2.5GHz (最大，取x=0,y=1)

### 检验条件
Circuit QED：制备|+x⟩→Ramsey干涉测量→提取d⟨σ_x⟩/dt vs ⟨σ_y⟩

### 检验时间线

### 证伪条件
若在所有制备态下d⟨σ_x⟩/dt的符号都相同（始终正或始终负）→符号自由度被隐式约束→Theorem A8被否证
