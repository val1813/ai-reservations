# Phase 1 任务书 — v7-Gauge

**类型：A（分析+形式论对比）**

## 驱动矛盾精确表述

命题A (Colla-Breuer 2022/2024): 最小耗散原理（要求Lindblad算子无迹Tr[L_k]=0）唯一确定TCL主方程∂_t ρ_S = −i[K_S(t), ρ_S] + D(ρ_S)中K_S(t)与D的分解。声称无剩余规范自由度。

命题B (Rivas, González & Chakraborty 2025): HMF存在规范自由度H*→H*+cI。需额外物理条件⟨∂_β H†⟩_eq=0来唯一固定。声称此为"唯一"固定——暗示其他固定方案（包括CB的最小耗散）可能不等价。

精确矛盾: CB和Rivas使用不同的数学原理（超算子范数最小化 vs 温度导数期望值为零）声称解决同一问题家族（强耦合热力学量的唯一分解）。若K_S^{CB}≠H_S†^{Rivas}，至少一个声称的"唯一性"是错误的。若K_S^{CB}=H_S†^{Rivas}，规范歧义被消解——两个变分原理等价。

## 本Phase目标（可证伪）

**判定Colla-Breuer K_S(t)与Rivas H_S†的数学关系：等价（同一物理量的不同推导）、互补（不同规范固定条件作用于不同层级）、还是冲突（至少一个声称错误）。**

证伪条件：若严格证明CB的"无剩余规范自由度"和Rivas的"至少一类规范自由度"可在同一数学框架内统一（不同层级/不同物理量），则两者不冲突——此时v7的"矛盾"被消解为互补性认识。

## 原始假设列表（供博士B独立使用）

**A1**: TCL主方程∂_t ρ_S = L_t(ρ_S) = −i[K_S(t), ρ_S] + D(ρ_S)，其中K_S†=K_S
**A2**: K_S(t)的规范变换：K_S→K_S+κ(t)I不改变ρ_S(t)的演化（仅改变全局相位）
**A3**: CB最小耗散条件：Tr[L_k]=0对所有Lindblad算子→等价于最小化||D||_{HS}
**A4**: Rivas温度导数条件：⟨∂_β H†⟩_eq = 0 → ∂_β(Tr[ρ_S^eq H†]) = Tr[ρ_S^eq H† ∂_β ln ρ_S^eq]
**A5**: H†的一般形式：H† = H_S + λ(β)(H*−H_S)，其中λ(β)由规范条件确定
**A6**: 两者的物理量域不同——K_S(t)是实时动力学量（TCL生成子的Hermitian部分），H†是平衡态热力学量（修正的HMF）
**A7**: 在稳态极限t→∞，K_S(∞)描述渐近动力学；H†描述平衡热力学——两者可能相关但不必须相等

**关键假设需验证**：
- A6的域区分是否使CB和Rivas的比较成为"苹果vs橙子"？还是两者在适当的极限下应给出相同结果？
- CB的Tr[L_k]=0是动力学规范固定（实时），Rivas的⟨∂_β H†⟩=0是热力学规范固定（虚时）——不同域的不同规范条件可以共存而不冲突？
