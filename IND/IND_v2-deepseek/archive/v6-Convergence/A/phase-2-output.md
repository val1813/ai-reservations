## §1 强制撞墙

### 攻击1（最强攻击）：H*_eff(t)没有唯一数学定义

**攻击内容**：静态H*由虚时路径积分唯一定义。实时动力学中，不存在公认的"有效瞬时哈密顿量"定义。"绝热瞬时浴态"是一种选择，但其他选择（非平衡Green函数/投影算符/时间平均H*）给出不同的H*_eff(t)→偏离∝I的判据依赖于定义。

**防御**：承认。H*_eff(t)的定义选择本身就是v6的物理内容之一——不同定义的等价/不等价对应不同的物理测量方案。本Phase的目标是提供至少一个操作上有意义的定义并分析其行为，而非声称唯一性。

**状态**：未闭合——定义多元性是原则性问题，不是推导错误。见§N.1。

### 攻击2：有限N修正太小，无法观测

**攻击内容**：∂_t H*_eff的偏离量级∼α⁴/N。对N=100, α=0.5: ∼6×10⁻⁴ω₀。对N=15, α=0.5: ∼4×10⁻³ω₀。即使N=15，偏离也只有0.4%——在数值精度和实验精度以下。

**防御**：部分承认。偏离在N≳20时确实不可观测。但有两个场景偏离可放大：
1. 累积效应：在长时间极限，∂_t H*的小偏离累积→H*_eff(t)与H*_static的积分差可累积到∼α²/N·(t/τ_th)
2. 非高斯放大：n=3 cumulant贡献∼α³/N在α~0.5时可与n=2修正∼α²/N竞争

**状态**：需要更精确的量级估计。见§N.2。

### 攻击3：v5-K6实际不依赖∂_t H*=0

**攻击内容**：v5-K6使用∂_t H*=0作为前提——但H*仅在C_coup = ⟨H_S+H_I−H*⟩的定义中出现。如果C_coup的定义直接使用静态H*（而非动力学H*_eff），则∂_t H*=0在平衡态严格成立，v5-K6不需动力学修正。

**防御**：这取决于C_coup在实时动力学中如何定义。如果C_coup用静态H*定义（在平衡态计算），则∂_t H*=0恒成立——v5-K6在实时动力学中是精确的（前提成立）。如果C_coup需用瞬时浴态重新定义，则∂_t H*可能非零。

**此攻击可能闭合整个v6北极星**——如果v5-K6使用静态H*定义且不依赖动力学H*_eff，则v5-K6在所有条件下精确，v6动力学修正不存在。见§N.3。

## §N 核心推导

### §N.1 H*_eff(t)的形式定义：三种候选

**候选(a) — 绝热瞬时浴态**：
```
H*_eff(t) ≡ −(1/β) ln Tr_B[e^{-β(H_S+H_B+H_I)} ρ_B^{inst}(t)]
```
其中ρ_B^{inst}(t)是"瞬时浴态"——在时间t截断系统-浴耦合后浴弛豫到的平衡态。操作上：
ρ_B^{inst}(t) ≡ Tr_S[U(t,0)ρ_tot(0)U†(t,0)]|_{H_I=0 after t}

问题：如何截断H_I？绝热截断→ρ_B^{inst}的物理意义模糊。

**候选(b) — 非平衡响应函数法**：
定义有效浴温度T_eff(t)和有效浴谱密度J_eff(ω; t)：
```
⟨B(t₁)B(t₂)⟩_{sym} = ∫₀^∞ dω J_eff(ω; t) coth(βω/2) cos(ω(t₁−t₂))
```
从实时两点关联函数反推J_eff(ω; t)→代入静态H*公式→H*_eff(t)。

问题：J_eff(ω; t)的定义需要时间窗口平均（时间平移对称性破缺）。

**候选(c) — 粗粒化时间平均**：
```
H̄*(t; Δt) ≡ (1/Δt)∫_{t−Δt/2}^{t+Δt/2} dt' H*_static|ρ_B(t')
```
对时间窗口Δt做平均。Δt选择：τ_corr ≪ Δt ≪ τ_th。

此候选操作上最清晰——H̄*在Δt内近似常数→∂_t H̄*≈0在Δt尺度上成立。

**本Phase采用候选(c)**——粗粒化时间平均的物理意义最明确（对应热力学测量的有限时间分辨率），且数学上最可控。

### §N.2 有限N浴偏离的领头阶估计

采用候选(c)，H̄*(t; Δt)的偏离来自ρ_B(t)在[t-Δt/2, t+Δt/2]内的变化。

**n=2贡献（Gaussian部分）**：
```
δH̄*^(2)(t) = −(α²/2β)∫dτ₁dτ₂ σ_x(τ₁)σ_x(τ₂) · [⟨T_τ B(τ₁)B(τ₂)⟩_{ρ̄_B(t)} − ⟨T_τ B(τ₁)B(τ₂)⟩_{ρ_B^eq}]
```

浴两点关联函数的变化来自ρ_B(t)偏离平衡。量级：
```
∥δ⟨BB⟩∥ ∼ (α²/N) · ∥⟨BB⟩_eq∥
```
（系统回馈能量∼α²ω₀，浴N个模各分α²/N）

因此：
```
∥δH̄*^(2)∥/∥H*∥ ∼ α²/N
```

**n=3贡献（非Gaussian部分）**——v6的新物理：
```
δH̄*^(3)(t) = +(α³/3!β)∫dτ₁dτ₂dτ₃ T_τ^S[σ_x(τ₁)σ_x(τ₂)σ_x(τ₃)] · ⟨T_τ B(τ₁)B(τ₂)B(τ₃)⟩_{c, ρ̄_B(t)}
```

Gaussian浴的三阶cumulant初始为零，但在实时演化中产生（浴被系统驱动→非平衡→非Gaussian）。

生长方程（Nakajima-Zwanzig投影到三阶cumulant子空间）：
```
d/dt κ₃(t) = −γ₃·κ₃(t) + α³·S₃(t)/N
```
其中γ₃∼ω_c是三阶cumulant的弛豫率，S₃(t)是源项。

平衡值：κ₃^eq ∼ α³/(Nω_c)

在t→∞极限（浴回归平衡但系统可能未平衡）：
```
∥δH̄*^(3)∥/∥H*∥ ∼ α³/N · 1/ω_c ∼ α³/(Nω_c)
```

对于Ohmic bath ω_c≫ω₀：
- α=0.5, N=15, ω_c=10ω₀: ∼8×10⁻⁴
- α=0.5, N=4, ω_c=10ω₀: ∼3×10⁻³

**n=3贡献在α~0.5, N=4时与n=2修正同量级→在v2-Bath的不合法浴区域(N=4)，非高斯修正不可忽略。**

### §N.3 §1攻击3的裁决：v5-K6是否需要动力学修正？

**重新审查v5-K6的推导**：

v5-K6: Σ_S = d/dt I(S:B) + β·dC_coup/dt − Σ_B^{internal}

其中C_coup = ⟨H_S+H_I−H*⟩。

**关键问题**：C_coup中的H*是静态H*（平衡态定义）还是动力学H*_eff(t)？

回顾v5-K6推导（v5-P5）：C_coup的引入来自能量守恒d⟨H_S+H_I⟩/dt + d⟨H_B⟩/dt = 0。分解：
d⟨H_S+H_I⟩/dt = d⟨H*⟩/dt + dC_coup/dt

∂_t H*=0保证d⟨H*⟩/dt = Tr[ρ̇_S H*]（H*无显式时间依赖）→ 这是**静态H***的恒等式。

**如果C_coup和H*都使用静态（平衡态）定义**：
- H*由虚时路径积分唯一定义——对所有α精确∝I
- ∂_t H*=0对所有平衡态严格成立
- C_coup = ⟨H_S+H_I−H*⟩中的H*是静态的→C_coup的变化仅来自ρ_S(t)的演化
- v5-K6在实时演化中精确——**不需要任何动力学H*_eff修正**

**如果C_coup使用动力学H*_eff(t)定义**：
- H*_eff(t)随时间变化→∂_t H*_eff≠0→d⟨H*_eff⟩/dt = Tr[ρ̇_S H*_eff] + ⟨∂_t H*_eff⟩
- 第二项破坏v5-K6的恒等式形式
- 修正：Σ_S = d/dt I(S:B) + β·dC_coup/dt − Σ_B^{internal} + β·⟨∂_t H*_eff⟩

**裁决**：v5-K6的原始推导使用静态H*（平衡定义）。在此定义下，∂_t H*=0对所有时间严格成立（H*不依赖时间——它只在平衡态定义）。因此v5-K6在实时动力学中**精确成立**，不依赖动力学H*_eff。

**但**：C_coup = ⟨H_S+H_I−H*⟩是一个**混合量**——H_S+H_I是实时算符，H*是平衡态构造。它的热力学解释"耦合能失配"假设H*是"系统+交互的有效能量"。这个解释在实时动力学中是否需要动力学H*_eff来保持物理一致性？这是一个**解释学问题**而非恒等式精度问题。

### §N.4 Nakagawa记忆核→spin-boson的精确映射

Nakagawa (2026)的记忆核：K_N(t−τ) ∝ (t−τ)^{α−1} E_{α,α}(−λ^α(t−τ)^α)
- α=1: E_{1,1}(−x)=e^{-x}→指数衰减Markovian
- α<1: Mittag-Leffler→幂律尾部+振荡→信息回流

spin-boson的记忆核（Nakajima-Zwanzig投影）：
```
K_SB(t) = α²·⟨[H_I, e^{-iQLQt}[H_I, ·]]⟩_B
```
对Ohmic bath J(ω)∝ω（带Drude截断ω_c）：
- t ≪ 1/ω_c: K_SB(t)∼常数
- 1/ω_c ≪ t ≪ 1/α²ω₀: K_SB(t)∼1/t²
- t ≫ 1/α²ω₀: K_SB(t)∼e^{-α²ω₀t}

**Ohmic bath的记忆核是指数衰减的——不展现Mittag-Leffler行为。Nakagawa的α≈1/2相边界不适用于Ohmic spin-boson。**

对sub-Ohmic bath J(ω)∝ω^s (s<1)：
- t ≫ 1/ω_c: K_SB(t)∼1/t^{1+s}
- 当s=1/2: K_SB(t)∼1/t^{3/2}——Mittag-Leffler型幂律尾部出现
- Nakagawa的α≈1/2对应分数阶导数的阶→spin-boson中对应s≈1/2

**映射表**：
| Nakagawa | spin-boson Class I | 
|----------|-------------------|
| 分数阶α | 浴谱指数s |
| α≈1/2 相边界 | s≈1/2 sub-Ohmic |
| Mittag-Leffler核 | K(t)∼1/t^{1+s} 幂律 |
| 信息回流相 | 非马尔可夫振荡区 |

**关键结论**：Nakagawa的α≈1/2边界对于Ohmic Class I (s=1)不可达→信息回流通过其他机制（v5-K4已覆盖的非马尔可夫振荡）。Nakagawa对v6的意义在于：如果Class I推广到sub-Ohmic浴(s<1)，H*∝I的动力学失效可能在s≈1/2处最显著。

### §N.5 v6北极星的最终精确化

经过Phase 1+2分析，v6结论如下：

**v6-K1（Phase 1）**：静态H*∝I对所有α精确成立（结构必然）。B验证通过。

**v6-K2（本Phase，新）**：v5-K6的∂_t H*=0前提使用静态H*定义→对所有平衡态严格成立。v5-K6恒等式在实时动力学中精确——不需要动力学H*_eff修正。C_coup的热力学解释（"耦合能失配"）在实时动力学中保持有效（因为H*的静态定义本身是合法的）。

**v6-K3（本Phase，新）**：有限N浴中，δH_eff的领头阶偏离来自：(a) n=2 Gaussian修正∼α²/N；(b) n=3非Gaussian修正∼α³/(Nω_c)。对N≥15（v2-K5热力学浴判据），两修正均<1%→v5-K6的精度在物理参数范围内不受影响。对N=4（v2不合法浴），两修正可能可观测但此时浴本身不可靠。

**v6-K4（本Phase，新）**：Nakagawa α≈1/2信息回流相边界映射到spin-boson sub-Ohmic浴(s≈1/2)，不适用于Ohmic Class I (s=1)。对Ohmic bath，信息回流通过非马尔可夫振荡（v5-K4）而非Mittag-Leffler记忆核实现。

**v6总体结论**：
1. 导航员候选1的原始北极星（linked-cluster收敛半径）被静态分析闭合→H*∝I在所有α严格
2. 动力学H*_eff偏离在物理参数范围内（N≥15, Ohmic bath）不可观测→v5-K6恒等式稳健
3. v6的产出是**防御性安全网**而非**新物理发现**——证明了v3-v5结论链在什么条件下稳健，而非发现了新的限制域
4. 唯一可能产生可观测偏离的场景：sub-Ohmic浴(s≈1/2) + 极小浴(N≤8)→这是v6可能的延伸方向但超出Class I定义
