## §1 强制撞墙

### 攻击1（最强攻击）：cumulant终止≠收敛——算子T_τ排序下Wick定理是否幸存？

**攻击内容**：v3-K10声称⟨B(τ₁)...B(τ_n)⟩_{B,c}=0 for n≥3是Gaussian bath的"代数恒等式"。这是对的——对于**标量**Gaussian随机变量。但H*公式涉及的是算子值T_τ指数：
```
ln⟨T_τ e^{-∫₀^β dτ A(τ)⊗B(τ)}⟩_B
```
其中A(τ) = α·e^{τ(H_S+H*)}σ_x e^{-τ(H_S+H*)}。T_τ排序在系统算符上作用，而浴平均⟨·⟩_B作用在浴算符上。关键在于：T_τ排序和浴平均是否交换？

T_τ排序对全算符（系统⊗浴）作用。展开后：
```
⟨T_τ(∫H_I)^n⟩_B = α^n ∫dτ₁...dτ_n ⟨T_τ[A(τ₁)B(τ₁)...A(τ_n)B(τ_n)]⟩_B
```
T_τ将系统算符和浴算符**交错排序**——但浴平均只作用在浴算符上，不改变排序。因此：
```
⟨T_τ[A(τ₁)B(τ₁)...A(τ_n)B(τ_n)]⟩_B = T_τ^S[A(τ₁)...A(τ_n)] · ⟨T_τ^B[B(τ₁)...B(τ_n)]⟩_B
```
其中T_τ^S仅排序系统算符，T_τ^B仅排序浴算符。浴算符在T_τ^B下的n点关联函数仍遵守Wick定理——因为T_τ^B[B(τ₁)...B(τ_n)]仅是B(τ_i)的排序乘积，B(τ_i)是浴算符的线性组合（Gaussian）。

**防御**：此攻击无效。T_τ因子化为T_τ^S⊗T_τ^B是因为系统算符和浴算符在任意τ对易（它们作用在不同Hilbert空间）。浴部分的T_τ^B排序不改变其Gaussian统计性质——Wick定理对T_τ^B排序的浴算符乘积同样成立。

**状态**：攻击1闭合。cumulant终止于n=2对算子T_τ同样严格。

### 攻击2（致命级）：自洽方程分岔——H*∝I是否是唯一解？

**攻击内容**：v3-K10的Theorem A6承认非平凡自洽解的存在性取决于超越方程。但v3仅给出"对Ohmic bath in standard parameter ranges，平凡解是唯一物理解"的定性判断——并未证明唯一性。

重写自洽方程。设H* = h₀I + h_zσ_z（Δ=ω₀/2，假设h_x=h_y=0因对称性）：
```
H_S_eff = (Δ+h_z)σ_z + h₀I
```
σ_x(τ) = e^{τH_S_eff} σ_x e^{-τH_S_eff} = cosh(2(Δ+h_z)τ)·σ_x − i sinh(2(Δ+h_z)τ)·σ_y

T_τ^S[σ_x(τ₁)σ_x(τ₂)] = θ(τ₁−τ₂)σ_x(τ₁)σ_x(τ₂) + θ(τ₂−τ₁)σ_x(τ₂)σ_x(τ₁)
= cosh(2(Δ+h_z)(τ₁−τ₂))·I − i sinh(2(Δ+h_z)|τ₁₂|)·sgn(τ₁−τ₂)σ_z

代入H*公式：
```
H* = −(α²/2β)∫₀^β dτ₁dτ₂ [cosh(2(Δ+h_z)|τ₁₂|)·I − i sinh(2(Δ+h_z)|τ₁₂|)·sgn(τ₁−τ₂)σ_z] · G(|τ₁₂|)
```

sgn因子×偶函数G = 奇函数，在[0,β]²上积分为零 → σ_z项消失。

因此：
```
h₀ = −(α²/2β)∫₀^β dτ₁dτ₂ cosh(2(Δ+h_z)|τ₁₂|)·G(|τ₁₂|)
h_z = 0  [自洽解]
```

**自洽方程(h_z)**：
h_z必须从σ_z分量给出，但σ_z分量被sgn奇偶性消去。这意味着h_z=0是恒等式的推论——σ_z分量在积分中恒为零，不管h_z取什么值。

等等——这实际上证明了h_z=0是**强制的**（forced），不仅是自洽的。因为：
- H*的σ_z分量来自T_τ^S中sgn(τ₁−τ₂)sinh项×G
- sgn是奇函数，G(|τ₁₂|)是偶函数（只依赖于|τ₁₂|）
- 乘积在[0,β]²上积分为零——这是对称性的结果，不依赖于h_z的值

**同理**，σ_x和σ_y分量也不出现——因为T_τ^S[σ_x(τ₁)σ_x(τ₂)]在Pauli基展开中只有I和σ_z（σ_x²=I的代数结果）。

**因此**：H*∝I不仅是一个自洽解——它是**所有自洽解的共同形式**。h_z的超越方程恒为零→H*的算符结构完全由T_τ^S的代数对称性（σ_x²=I + 积分对称性）确定，与耦合强度α无关。

**防御**：此攻击被T_τ^S的代数对称性闭合——H*∝I是强制的，不是"自洽选择"。

**状态**：攻击2闭合。自洽分岔不存在。但有一个微妙之处——

### 攻击3（深层攻击）：σ_x²=I的特殊性——Class I定义本身保证了终止？

**攻击内容**：v3-K10的关键步骤使用σ_x²=I来化简T_τ^S[σ_x(τ₁)σ_x(τ₂)]的算符结构。但对一般系统算符A（非对合），T_τ^S[A(τ₁)A(τ₂)]可包含A²,A³,...项，其系数是H_S_eff的非平凡函数→浴平均后产生非平凡算符结构。这意味着H*∝I是**qubit+σ_x耦合的特殊结果**，而非Gaussian bath的一般性质。

换言之：H*∝I的"普适性"受限于Class I的定义——qubit的σ_x²=I封闭性。这是"Class I的定义保证了H*∝I"而非"H*∝I是Gaussian bath的普遍性质"。

**防御**：承认。但这对v6北极星有特殊意义：
- v3-K10的"非微扰精确"声张只对Class I成立——这已经被v3的Class I/II/III分类所承认（K14）

**此攻击指向真正的问题核心**，见§N.2。

## §N 核心推导

### §N.1 精确区分：三种"收敛性"概念

v3-K10的"非微扰精确"声张涉及三个不同的数学概念，必须精确区分：

**概念1 — cumulant终止**（Gaussian代数事实）：
⟨B(τ₁)...B(τ_n)⟩_{B,c} = 0 for n≥3
这是Gaussian分布的定义性质。在H*定义中，浴平均仅在**裸浴平衡态**ρ_B=e^{-βH_B}/Z_B上执行。B(τ)是裸浴演化e^{τH_B}Be^{-τH_B}——不涉及系统-浴耦合。因此裸浴算符的统计是Gaussian的，cumulant终止是精确的。
→ **此概念不产生任何收敛性限制。**

**概念2 — 自洽方程的结构**（H*的非线性自洽条件）：
H* = −(1/β)ln⟨T_τ e^{-∫H_I}⟩_B
其中H_I(τ)=α·e^{τ(H_S+H*)}σ_x e^{-τ(H_S+H*)}⊗B(τ)。H*在指数内→这是关于H*的隐式方程。自洽闭合需要证明解的存在性+唯一性。
→ **v3证明了H*∝I是自洽解。§1攻击2证明H*∝I是强制的（积分的奇偶对称性使σ_z分量恒为零）。**

**概念3 — 浴Gaussian性在耦合下的稳定性**（有限N修正+回馈作用）：
这是v6的核心问题。H*的定义使用裸浴平均⟨·⟩_B——这不涉及动力学演化，不涉及回馈作用。因此在H*的定义层面，Gaussian性是严格的。

**但是**：H*出现的地方不只定义——在v5-K6的动力学恒等式Σ_S=d/dt I(S:B)+β·dC_coup/dt−Σ_B^{internal}中，H*通过∂_t H*=0进入。这是**实时动力学**中的条件。在实时动力学中：
- 浴状态在系统-浴相互作用下演化——不再是裸平衡态
- 浴算符在实时演化下的关联函数可能偏离Gaussian形式
- Nakagawa的Mittag-Leffler记忆核正是实时动力学中非指数衰减的表现

**关键洞察**：H*∝I在**定义层面**对所有α精确成立（Gaussian bath的代数必然+σ_x²=I的代数封闭性）。但在**动力学层面**（v5-K6使用∂_t H*=0的地方），H*∝I的成立需要额外的条件：动力学演化不产生非平凡H*修正。

### §N.2 真正的边界：静态H* vs 动力学H*

v3-K10的H*∝I是关于**静态（虚时/平衡）** H*的结论：
```
e^{-βH*} ≡ ⟨T_τ e^{-∫₀^β dτ H_I(τ)}⟩_B （平衡定义）
```
这个定义中，H*由裸浴平衡态的虚时路径积分给出。浴算符的统计是裸的、Gaussian的。H*∝I的证明不涉及任何动力学假设。

**但v5-K6使用∂_t H*=0作为动力学恒等式的前提**。∂_t H*=0意味着H*在实时演化中不变。如果实时演化改变了H*的有效形式（例如通过浴的非平衡响应），则∂_t H*=0可能在有限时间后失效。

这给出了v6北极星的精确化：

```
静态H*: H*∝I 对所有α精确成立（v3-K10完整）
动力学H*_eff: 实时演化中有效H*是否偏离∝I？
  偏离机制1：浴非平衡→有效浴关联函数非Gaussian→H*_eff的cumulant展开不再终止于n=2
  偏离机制2：Nakagawa信息回流→浴记忆核的Mittag-Leffler尾部→有效H*获得频率依赖
```

**§N.2.1 偏离机制1的形式化**：

在实时演化中，浴的关联函数变为：
```
C(t,t') = ⟨B(t)B(t')⟩_{ρ_B(t)} ≠ ⟨B(t)B(t')⟩_{ρ_B^eq}
```
其中ρ_B(t)是浴在时间t的约化态（非平衡）。非平衡浴关联函数一般不具有时间平移不变性，且高阶cumulant可能非零。

H*_eff(t)可通过瞬时浴态定义（绝热近似）：
```
e^{-βH*_eff(t)} ≡ Tr_B[e^{-β(H_S+H_B+H_I)}]|_{ρ_B=ρ_B(t)}
```
若ρ_B(t)偏离Gaussian→H*_eff(t)可能偏离∝I。

量级估计：浴偏离Gaussian的程度∼O(α²/N)（系统回馈能量∼α²ω₀，浴自由度N，每自由度扰动∼α²/N）。对N=∞（连续浴），偏离为零。对有限N：
- α=0.2, N=100: 偏离∼4×10⁻⁴
- α=0.5, N=100: 偏离∼2.5×10⁻³
- α=0.5, N=15 (v2-K5 N_c): 偏离∼1.7×10⁻²

**§N.2.2 偏离机制2：Nakagawa记忆核映射**：

Nakagawa (2026)的分数阶模型给出记忆核的Mittag-Leffler形式：
```
K(t−τ) ∝ (t−τ)^{α−1} E_{α,α}(−λ^α(t−τ)^α)
```
其中E_{α,β}是Mittag-Leffler函数。α是分数阶导数的阶。

当α>1/2时，Mittag-Leffler函数从单调衰减转为振荡衰减——信息回流相出现。

将此映射到spin-boson Class I：
- spin-boson的记忆核由 bath spectral density J(ω)决定
- Ohmic bath: J(ω)∝ω → K(t)∝1/t²（指数截断后）
- Sub-Ohmic bath (s<1): J(ω)∝ω^s → K(t)∝1/t^{1+s}（Mittag-Leffler型尾部）

Class I的Gaussian bath（Ohmic型）的记忆核是指数衰减的（有Drude截断ω_c）——不是Mittag-Leffler型。因此Nakagawa的α≈1/2相边界**不直接适用于Ohmic spin-boson Class I**。

**但是**：若截断ω_c足够大（ω_c≫ω₀），记忆核在intermediate time scale (1/ω_c ≪ t ≪ 1/α²ω₀)呈现幂律尾部∼1/t²（Ohmic）或∼1/t^{1+s}（sub-Ohmic）→在sub-Ohmic case中可呈现Mittag-Leffler行为。

**关键结论**：Nakagawa的α≈1/2边界更可能与**sub-Ohmic bath**（而非Ohmic Class I）相关。这缩小了v6的检验范围。

### §N.3 H*∝I有效域的形式判据

基于以上分析，H*∝I的有效域边界由以下三个条件之一的首个违反定义：

**条件1 — 静态定义层**（总是成立）：
浴Gaussian性在H*定义中是严格的（裸浴平均）→H*∝I对静态平衡H*在所有α下成立。
→ **不需要收敛半径。**

**条件2 — 浴非平衡层**（有限N修正）：
ρ_B(t)偏离Gaussian性的程度∼α²/N。当α²/N ≳ ε（ε是H*测量的精度阈值）时，H*_eff可观测地偏离∝I。
→ α_c ∼ √(N·ε)。对于N=100, ε=0.01: α_c ∼ 1（超出物理范围）
→ 对于N=15, ε=0.01: α_c ∼ 0.39（在物理范围内！）
→ **这连接v2-Bath的N_c≈15判据——有限浴尺寸下H*∝I在α≳0.4时可能失效。**

**条件3 — 记忆核结构层**（sub-Ohmic bath）：
若bath spectral density J(ω)∝ω^s (s<1)，记忆核有幂律尾部→Mittag-Leffler行为出现在α≈1/2。
→ 对Ohmic bath (s=1)，此层不激活。
