### 攻击记录

**C1(v5) 攻击记录：**
| 轮次 | 攻击方向 | 失败位置 | Phase |
|------|---------|---------|-------|
| 1 | SSA边界法：用强次可加性I(A:B)≤I(A:BC)约束I(S:B)变化率 | SSA给出静态边界∥I(S:B)_t−I(S:B)_0∥≤2∥ρ_tot−ρ_S⊗ρ_B∥，无法转为d/dt的界 | P2 |
| 2 | Class I替代法：利用v5-K3 Σ_S=d/dt I(S:B)，将I(S:B)计算转为Σ_S计算 | 循环——Σ_S本身定义依赖dS_S/dt需Lindblad动力学的ρ̇_S，但Lindblad需要明确H* | P2 |
| 3 | 层析重构法：从ρ_S(t)时序测量重建I(S:B) | I(S:B)=S(ρ_S)+S(ρ_B)−S(ρ_tot)，S(ρ_B)和S(ρ_tot)无法从ρ_S单独重构——缺失浴侧信息 | P3 |
| **最小失败证据** | d/dt I(S:B)=dS_S/dt+dS_B/dt，dS_B/dt=β·dQ_B/dt需浴可观测量⟨H_B⟩和⟨H_I⟩，这些在v4框架中不可达。Class I中dQ_S/dt=0但dS_B/dt≠0一般（交互能量流动）。 | | |

**C2(v5) 攻击记录：**
| 轮次 | 攻击方向 | 失败位置 | Phase |
|------|---------|---------|-------|
| 1 | TCL生成子法：时间卷积less投影算符技术恢复Markovian形式 | TCL生成子K(t)在强耦合(α>0.1)含记忆核积分，仅在τ_corr≪τ_th时截断为Lindblad形式。α~0.4时τ_corr/τ_th~α²~0.16不满足严格分离 | P1 |
| 2 | Class I特殊结构法：H*∝I→无能量交换→Lindblad形式可能恢复 | H*∝I确保dQ_S/dt=0但不约束耗散子D(ρ_S)的代数结构。D(ρ_S)仍可含非Lindblad记忆项（非马尔可夫浴响应） | P2 |
| 3 | 数值反例搜索：spin-boson ED (N=4-8, α=0.4)拟合ρ_S(t)与最近Lindblad生成子 | N=4: Lindblad拟合残差~5-10%(α=0.2)增至~20-30%(α=0.4)。N=8:残差减小但仍~10-15%。有限N效应混杂→无法分离数值有限性与原理性非Lindblad | P3 |
| **最小失败证据** | TCL K(t)的Lindblad截断条件等价于Born-Markov近似——这正是v5-K1诊断的"因子化前提进入处"。Class I的H*∝I只简并能项，不简化耗散项。ED数据：α=0.4时残差>10%，但有限N混淆解读。 | | |

**C3(v5) 攻击记录：**
| 轮次 | 攻击方向 | 失败位置 | Phase |
|------|---------|---------|-------|
| 1 | SSA单调性法：I(S:B)_t在CPTP映射下单调→数据处理不等式 | 全系统幺正演化在S上诱导的不是CPTP映射而是CP映射（需初始因子化才是CPTP）。无因子化前提时，I(S:B)_t可增可减——v5-P3已发现非马尔可夫瞬时减小的物理机制（信息回流） | P3 |
| 2 | Lieb-Ruskai证明改编：用Lieb-Ruskai对凹性证明互信息在特定条件下的单调性 | LR证明依赖Stinespring扩张→CPTP，同样需要初始因子化。无法绕过 | P3 |
