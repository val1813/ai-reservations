## §0 交叉验算（定理2的边界条件）

对v5-K3（Σ_S^{(gauge)} = d/dt I(S:B)）进行压力测试——此恒等式在非马尔可夫域是否仍严格成立？

恒等式的推导仅依赖三个前提：
1. 幺正演化（dS_tot/dt = 0）— 总是成立
2. 浴局域平衡（dS_B/dt = β·dQ_B/dt）— 大浴极限
3. Class I（H*∝I → dQ_S/dt = Tr[ρ̇_S H*] = 0）

**这三个前提都不依赖马尔可夫近似。** 因此定理2在非马尔可夫域同样严格成立。

新问题变成：如果Σ_S^{(gauge)} = d/dt I(S:B)是恒等式，且I(S:B)在非马尔可夫演化下可减小，那么Σ_S^{(gauge)}可为负——我们接受还是修正？

## §N 核心分析

### §N.1 Class I中I(S:B)的非马尔可夫动力学

全系统幺正演化：ρ_tot(t) = e^{-iH_tot t} ρ_tot(0) e^{iH_tot t}

I(S:B)_t = S(ρ_S(t)) + S(ρ_B(t)) − S(ρ_tot(0)) [S(ρ_tot)守恒]

d/dt I(S:B) = d/dt S(ρ_S) + d/dt S(ρ_B)

在Class I中：
- dQ_S/dt = 0 → dS_B/dt = β·dQ_B/dt = −β·dQ_S/dt = 0（浴局域平衡）
- ∴ d/dt I(S:B) = d/dt S(ρ_S)

所以I(S:B)的单调性完全等价于S(ρ_S)的单调性！

**S(ρ_S)在非马尔可夫演化下可以减小吗？**

可以。这是量子信息回流的标志：系统向浴"借出"的信息可以"收回"——表现为ρ_S变得更纯（熵减小）。已知例子：
- Spin-boson model at α > 0.3, low T: S(ρ_S) shows damped oscillations
- 物理机制：系统-浴纠缠的暂时解除 → ρ_S纯度暂时恢复

**关键参数**：
- 振荡时间尺度：τ_osc ∼ 2π/ω₀（裸系统Rabi周期）
- 衰减时间尺度：τ_decay ∼ 1/(α²J(ω₀))（浴诱导弛豫）
- 当τ_osc < τ_decay时（强耦合/低温），可观测到多个振荡周期

**结论**：在Class I非马尔可夫域（α ≳ 0.3, βω₀ ≳ 1），I(S:B)可瞬时减小 → Σ_S^{(gauge)}可瞬时为负。

### §N.2 连接Strasberg-Esposito信息回流框架

Strasberg & Esposito (2019, PRE 99, 012120)建立了非马尔可夫熵产生的一般框架：

Σ_total(t) = dS_S/dt − β·J_Q(t) + I_flow(t)

其中I_flow(t)是"信息回流项"——度量从浴回流到系统的信息速率。

在Class I中（v4框架）：
- Σ_S^{(gauge)} = dS_S/dt − β·Tr[ρ̇_S H*] = dS_S/dt（H*∝I）
- 瞬时Σ_S^{(gauge)} = dS_S/dt可正可负

在Strasberg-Esposito框架中：
- Σ_total(t) = dS_S/dt − β·J_Q(t) + I_flow(t)
- J_Q = −d⟨H*⟩/dt = 0（Class I, HMF定义）
- ∴ Σ_total(t) = dS_S/dt + I_flow(t)

**识别**：v4的Σ_S^{(gauge)} = dS_S/dt = Σ_total(t) − I_flow(t)

这个等式揭示了一个深层结构：v4的Σ_S^{(gauge)}在Class I中度量的是"净熵产生减去信息回流"。当信息从浴回流到系统时（I_flow > 0），Σ_S^{(gauge)} < 0 ——这不是第二定律违反，而是信息回流在v4公式中被计为"负熵产生"。

**这意味着v4-K5有一个概念性漏洞**：Σ_S^{(gauge)} ≥ 0在非马尔可夫域不是严格的——它混淆了"真正的熵产生"和"信息回流"。在马尔可夫域（I_flow = 0），两者等价（Σ_S^{(gauge)} = Σ_total ≥ 0）。

### §N.3 修正方案：时间尺度限定

**修正的v4-K5**：

```
Σ_S^{(gauge)}(t) = d/dt I(S:B)_t  [严格恒等式，所有时间尺度]

Σ_S^{(gauge)}(t) ≥ 0 for t ≫ τ_B  [马尔可夫/长时间极限]
  其中τ_B = 浴关联时间 ∼ 1/ω_c

Σ̄_S^{(gauge)}(Δt) ≡ (1/Δt)∫₀^{Δt} Σ_S^{(gauge)}(τ) dτ ≥ 0 for Δt ≫ τ_B
  [时间平均的熵产生非负]
```

**这是v4-K5的正确表述**：≥0不是逐点的（instantaneous），而是时间平均的（coarse-grained）。热力学测量总是时间平均的，所以这个修正在物理上是适当的。
