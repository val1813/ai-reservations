## §1 强制撞墙

**攻击1 — 如果d_free≥1是平凡的（任何2D系统都有1维ρ̇自由度），这有什么新意？**

K24的2D构造反例（δH=diag(1,0), ρ̇_S=diag(±c,∓c)）确实不需要K13——它对任意非简并δH都成立。K13的贡献不是"发现d_free≥1"，而是**解释为什么d_free在强耦合下不会被代数性压低**。在没有K13的情况下，你可能期望强耦合的δH（来自H*−H_S）获得非对角分量，从而破坏共享本征基→d_free虽然存在但在物理上被混合到非对角通道。K13证明：不，在α²阶，δH严格对角→符号自由度不被混合。

**攻击2 — 这对Jensen-σ gap的证明增加了什么？**

K24的证明（3次否定性裁判确认）不依赖K13。但K24的证明只说"存在合法的ρ̇_S"，没说"这些ρ̇_S在物理上可达"。K13的贡献是：在对角基下，ṗ_n的动力学只由对角耗散决定（因为酉部分−i[H_S,ρ_S]在对角基下只产生相位旋转，不改变ṗ_n）。这意味着ṗ_n的符号自由度在动力学上是可达的——不只是数学存在，而且在真实演化中可以被访问。

**攻击3 — 如果δH的本征值h₁=h₂（简并），d_free的维度是否更高？**

简并情况：δH∝I → tr[ρ̇_S δH]=0对所有合法ρ̇_S。这是K24定理的退化情况——Jensen bound给出δH的信息（符号/量级），但tr[ρ̇_S δH]=0恒成立，Jensen的信息完全不影响σ。d_free在简并情况下是d_eff²−1（所有保迹厄米ρ̇_S），更大。

## §N 核心分析

### §N.1 κ₂对角基的形式化

由K13：对高斯bath+线性σ_x⊗B+β<∞：
H*(2) = H_S + δE·σ_z（仅含∝I和∝σ_z项）

其中δE = −(β/2)·κ₂中I和σ_z的系数。

在α²阶：δH = H* − H_S = δE·σ_z（忽略O(α⁴)）

δH与H_S = (ω₀/2)σ_z精确对易→共享本征基：
{|↑⟩, |↓⟩}（σ_z的本征态）

在此基下：δH = diag(δE, −δE)

### §N.2 ρ̇_S在对角基下的符号自由度

ρ_S在{|↑⟩,|↓⟩}基下的最一般形式：
ρ_S = [[p, γ], [γ*, 1−p]]（p∈[0,1], |γ|²≤p(1−p)）

ρ̇_S = [[ṗ, γ̇], [γ̇*, −ṗ]]（tr[ρ̇_S]=0自动满足）

ρ̇_S的合法性条件：
1. 厄米性：自动满足
2. 保迹：ṗ + (−ṗ) = 0 ✓
3. 保正定：对充分小的δt，ρ_S+δt·ρ̇_S≥0要求ṗ的约束来自p和1−p的边界

在物理区域内部（0<p<1）：ṗ可取任意实数（正或负）。

tr[ρ̇_S δH] = ṗ·δE + (−ṗ)·(−δE) = 2ṗ·δE

对非零δE（非简并系统）：符号仅由ṗ的符号决定——而ṗ可取任意实数值。

**结论**：在κ₂对角基下，Jensen bound提供的δH信息（δE的值和符号）完全不约束tr[ρ̇_S δH]的符号。ρ̇_S的自由度d_free=1就是在δH本征基下的ṗ。

### §N.3 对角自由度的维度

对d_eff-维系统（非简并H_S）：
δH与H_S共享本征基→δH=diag(h₁,...,h_N)，Σh_i待定。

ρ̇_S在对角基下的对角元：ṗ₁,...,ṗ_N，满足Σṗ_i=0。
独立自由度：d_free = N−1。

tr[ρ̇_S δH] = Σṗ_i·h_i。给定{ṗ_i}的N−1维空间，可以遍历ℝ中任意值（除非所有h_i相等→退化→tr=0恒成立）。

对TLS（d_eff=2）：d_free=1——这正是K24构造所用的维度。

### §N.4 K13→K24失效传递的精确陈述

**Proposition（κ₂-σ gap结构定理）**：

在K13的条件下（高斯bath+线性σ_x⊗B+β<∞），α²阶成立：

(i) κ₂对角性保证δH与H_S共享本征基，ρ̇_S在共享基下的对角符号自由度为d_eff−1维。

(ii) 在d_eff−1维的ṗ空间中，tr[ρ̇_S δH]可取任意实数值。

(iii) 因此，Jensen/PB提供的任何关于δH符号或量级的信息，在进入σ^{HMF}的修正项时，被d_eff−1维的ρ̇_S符号自由度完全屏蔽。

(iv) 这个屏蔽机制在α⁴阶被破坏——当κ₄产生H*的非对角分量时，δH不再与H_S共享本征基，ṗ的自由度被混合到非对角通道，符号自由度的有效维度降低。

**定理的界限**：本Proposition不依赖K24（ρ̇_S符号自由度定理），而是为K24提供了"为什么不可避免"的代数解释——κ₂对角性恰恰是K24生效的代数前提。
