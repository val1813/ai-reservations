# 知识库 — Beta-Ta-ShotNoise v1

## β-Ta基本物理
- β-Ta：体心四方(A15)结构的亚稳相，高电阻率ρ~150-200 μΩ·cm
- Ioffe-Regel参数：k_F l ≈ 1-3（接近Mott-Ioffe-Regel极限）
- 无量子临界点（与标准奇怪金属不同）
- 无磁性（排除Kondo效应）
- T_c(超导) ≈ 0.5-0.7 K（α-Ta的T_c≈4.5K，β-Ta更低）

## 散粒噪声基础
- Fano因子F = S_I/(2eI)，其中S_I是电流噪声功率谱密度
- 泊松极限（独立电子隧穿）：F = 1
- 扩散导体（费米液体）：F = 1/3
- 热电子regime：F ≈ √3/4 ≈ 0.43
- 超导体（Cooper对，电荷2e）：F = 2/3（相对于2e载流子）或F_eff = 1/3×2 = 2/3

## 实验事实（候选池描述）
- β-Ta纳米线中F ≈ 0.03-0.16
- 远低于FL所有预测分支（最低为扩散极限F=1/3）
- F值聚簇在FL值的2/4/6/8倍（需统计验证）
- 排除：跳跃输运（无长度依赖）、电子-声子散射（耦合常数差两个数量级）、单粒子局域化（ρ不发散）

## 理论框架
- 弱局域化(WL)：量子干涉修正电导σ→σ+δσ_WL，对散粒噪声的影响未被系统计算
- 随机矩阵理论(RMT)：在Ioffe-Regel极限的散粒噪声预测不完整
- SYK/奇怪金属：Sachdev对YbRh₂Si₂中F≈1/6的解释→β-Ta更低的F是否同一机制？
- 配对玻色型激发：若载流子电荷为ne（n=2,4,6,8），F_eff = F_single/n
