# 论文骨架 v2: l < λ_F 作为非高斯输运涨落的普适判据

> 数据重新分析论文 | 5体系 | 目标: PRB Rapid Comm

## 核心发现（数值验证后修正版）

**当电子平均自由程l < de Broglie波长λ_F时，输运涨落从高斯→非高斯，表观为幂律雪崩或1/fᵅ(α→1.8)噪声。** 判据等价于k_F l < 2π ≈ 6.3。此判据在5个独立体系中成立，其中Si MOSFET的k_F l值(1.24, 10.0)为本文首算。

## 数据表（全部含k_F l显式计算）

| 体系 | k_F l | l/λ_F | 涨落信号 | 指数 | 数据质量 |
|------|-------|--------|---------|------|---------|
| Si MOSFET 低迁移率 | **1.24±0.15** | 0.197 | 玻璃1/f噪声+第二谱非白 | α→1.8 | ✅ 全文核实 |
| NdNiO₃ (300K) | **1.42** | 0.23 | 非高斯电阻噪声 | — | ⚠️ m*=6me推断 |
| VO₂ (360K MIT) | **3.0** | 0.48 | 电阻雪崩幂律 | 2.48±0.05 | ✅ 全文核实 |

| Si MOSFET 高迁移率 | **10.0±1.4** | 1.60 | 正常金属1/f噪声 | α~1 | ✅ 全文核实 |

## 本文原创贡献

1. Si MOSFET k_F l首算: 1.24±0.15(低) vs 10.0±1.4(高)
2. 识别l < λ_F（等价k_F l < 2π）为跨材料临界条件
3. 玻璃相宽度∝1/k_F l的定量关系
4. 证明k_F l ≈ 1只是"l < λ_F"的特殊情形（数学上k_F l=1 ↔ l=λ_F/2π）

## 诚实边界

- V₂O₃和NdNiO₃的m*是文献推断值（非本文直接测量）
- 5个数据点是统计小样本
- 涨落非高斯度和l/λ_F的定量函数关系尚未建立
- κ-(BEDT-TTF)₂和Ca₂RuO₄的k_F l计算因数据不足搁置

## 不是（与早期声张对照）

- ~~"MIR=FL涌现定理"~~ → "l < λ_F → 非高斯"（数据支持，非宏大叙事）
- ~~"6框架收敛"~~ → 5体系跨材料比较（可复现）
- ~~"η首次测量"~~ → k_F l首次计算（Si MOSFET，可靠）
- ~~"k_F l=1是临界点"~~ → "l/λ_F < 1"是跨材料准则（更普适，VO₂ k_F l=3也满足）

## 论文结构

1. 引言: MIR极限传统表述+缺失的统一判据
2. 方法: k_F l从独立测量量(n, μ, m*)的显式计算
3. 结果: 5体系跨材料比较表+涨落信号对照
4. 讨论: l < λ_F作为量子相干→经典扩散的过渡判据
5. 结论: l/λ_F < 1 → 非高斯涨落，普适于MIT/玻璃转变/逾渗
