# B博士 Round 1 推导

> 框架: 大偏差理论 + 信息论 + 动力系统
> 日期: 2026-06-03

## 核心发现

QSL-Boltzmann矛盾是表观矛盾 — PI预攻错误地将ΔE替换为ZΔE₀。
纠正后QSL与¬H不再矛盾。新发现: 信息论约束 Z·(Γ/W₀) ≤ const 提供第三种输运极限。

## 三个跳跃

### 跳跃1: 大偏差→输运极限
- TUR下界可被重正化（取决于熵产生标度指数α）
- 运动学下界是绝对的（晶格常数a固定）
- P1: k_F l_dc/k_F l_opt ∝ Z^(2-α)

### 跳跃2: 信息论→QSL-Boltzmann
- PI预攻错误: 只考虑相干信道Fisher信息，忽略非相干贡献
- 纠正: 总F_Q = ZΓ² + (1-Z)W₀² + 交叉项
- 当Z→0, Γ≤2W₀（与Z无关！）—QSL与¬H无矛盾
- P2: Z·(Γ/W₀) ≤ 0.25（信息论权衡）

### 跳跃3: 动力系统→MIR结构稳定性
- MIR是异宿连接(heteroclinic connection)，余维度≥1
- 在关联扰动下分裂→MIR极限模糊化
- P3: (k_F l)_crit = 1 + c₁(U/U_c-1) + c₂(U/U_c-1)²

## 深挖

深挖1: 三跳共享凸分析对偶性—Young-Fenchel不等式是统一数学结构
深挖2: MFT(宏观涨落理论)→Einstein关系在非FL中破缺，破缺程度∝(1-Z)

## 奇怪预测

SP1: "反MIR区"—Z→0但Γ有限的系统是好的量子信道
SP2: QCP附近k_F l的临界值发散（异宿连接拉伸）
