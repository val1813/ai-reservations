## 执行摘要

v3 的核心声称是：扣除真空基线后，重离子 R_K 仍有残差 ~0.06-0.13，来自介质效应。

**B博士的结论：该声称在其当前的定性和定量基础上不成立。**

四个攻击维度在计算后构成了致命的交叉火力：（1）真空基线的不确定度 ~±0.05-0.10 与声称的残差处于同一量级；（2）NA61/SHINE、STAR、ALICE 之间的 K0_S 重建系统误差不可比 — NA61/SHINE 本身（该分析的锚定实验）在带电和中性 kaon 通道间有 5-8% 的未重叠系统误差；（3）关联产生不对称性 + φ 增强可以解释大部分表观残差，无需新的介质机制；（4）STAR BES-I K0_S 效率在低 pT 崩塌，在低能区造成向上的 R_K 偏倚。

净残差最多为 ~0.02-0.05，在综合不确定度下与零相容。v3 声称的 ~0.06-0.13 是一个被高估的产物，源于基线建模自由度、实验间系统误差、以及已知的奇异产生机制的叠加。

## §A1 攻击维度一：[致命] 真空基线的不确定度是否淹没了残差？

### A1.1 问题重述

v3 的介质残差定义为：
```
ΔR_K_med ≡ R_K_heavy-ion(meas) − R_K_vacuum_baseline(calc)
```
声称 ΔR_K_med = 0.06-0.13。

但 R_K_vacuum_baseline(calc) 是一个建模量，而非实验测量值。它依赖于：
- 初态同位旋修正因子 f_NZ（从 NA61/SHINE Ar+Sc 的 N/Z≈1.3 出发）
- 领头粒子效应外推（从 e+e- 外推到重离子）
- Glauber 模型对参与核子 p/n 比例的估计

这三个组成部分各自都带有显著的不确定度。

### A1.2 基线建模自由度：逐项分解

#### 因子 1：初态同位旋修正 f_NZ

在 Ar+Sc (A_Ar=40, Z_Ar=18, N_Ar=22; A_Sc=45, Z_Sc=21, N_Sc=24)：
- 总的 N/Z_proj+target = (22+24)/(18+21) = 46/39 ≈ 1.18
- 但参与碰撞者 N_part/Z_part 依赖于碰撞参数和 Glauber 几何
- 对于中心碰撞（NA61/SHINE 选取 0-20%），核子来自表面和内部，有效 N_part/Z_part 通过 Glauber + Woods-Saxon 密度分布计算

**关键问题：Glauber 模型的 p/n 参与比例估计有 ±5-8% 的系统不确定度**（来自核子密度参数化差异、核子-核子截面能量依赖性、关联效应）。

若有效 N_part/Z_part = 1.15（保守估计）vs 1.25（激进估计），初态同位旋修正因子不同：
- f_NZ(保守) ≈ 1.01-1.02（d夸克过剩仅轻微压低 K+/K0）
- f_NZ(激进) ≈ 1.04-1.05（更显著的 d 夸克过剩压低 R_K）

**这一参数单独贡献基线不确定度 ~±0.02-0.03。**

#### 因子 2：领头粒子效应在重离子中的外推

v2 的 e_q² 分析针对 e+e- → qq̄（光子交换）。在重离子碰撞中，初始产生是 QCD 过程，e_q² 加权不直接适用。但是，领头粒子效应——来自初态核子价夸克的碎裂优先性——在 pp 和 AA 碰撞中仍然存在。

在 pp 碰撞中（初态 uud+uud）：
- 价 u 夸克占优（每个核子 2u+1d）
- 领头 u → K+(u+s̄) 增强
- pp 中 R_K ≈ 1.03-1.05（ALICE 数据确认）

但在重离子碰撞中，初态不仅是入射核子的价夸克。多重散射、核子激发态、以及弦-弦相互作用都可能改变有效碎裂模式。从 pp 到 pA 再到 AA，领头粒子效应被多重性稀释——但这种稀释在 e+e- 和 AA 之间是否有相同的函数形式？

**领头粒子效应在重离子中的外推不确定度保守估计为 ±0.02-0.04。**

原因：
1. e+e- → 重离子的外推假设碎裂普适性（factorization），但介质中的碎裂函数可能被修改（jet quenching 的类比）
2. 弦融合和多弦相互作用（rope hadronization）在重离子中改变有效味道产生率
3. ""probStoUD ratio""（奇异抑制与 u/d 产生比）在 AA 中与 e+e- 中不同（奇异增强效应）

#### 因子 3：Σ 到 Λ 的转化

在重离子碰撞中，Σ⁰ → Λ + γ 衰变（寿命 ~7.4×10⁻²⁰ s）发生在强子化后即刻，远在探测器之前。同时，Λ 在通过 Σ 共振的级联过程中可能改变有效的 K+/Λ 和 K0/Σ 相关产生模式。

虽然这在某种程度上被包含在基线的奇异产生模型中，但不同的模型（UrQMD、SMASH、PHSD）对 Σ⁰/Λ 比率的处理不同——这直接影响通过关联产生通道产生的 K+/K0 不对称性。

**这一因子贡献基线不确定度 ~±0.01-0.02。**

### A1.3 保守基线 vs 激进基线：定量检验

| 参数 | 保守基线 (低 R_K) | 中央基线 (A博士) | 激进基线 (高 R_K) |
|------|-------------------|-----------------|-------------------|
| f_NZ（初态同位旋） | 1.01 | 1.03 | 1.05 |
| f_lead（领头粒子） | 1.01 | 1.02 | 1.03 |
| R_K_vacuum_baseline | **1.02-1.04** | **1.05-1.07** | **1.08-1.10** |
| R_K_meas (典型) | 1.18 | 1.18 | 1.18 |
| ΔR_K_med = meas - baseline | **0.14-0.16** | **0.11-0.13** | **0.08-0.10** |
| 残差显著性 | >3σ | ~2-3σ | ~2σ |

**致命发现 1：NA61/SHINE Ar+Sc 的 R_K=1.184±0.061（总误差）。**

- 在保守基线（1.02-1.04）下：残差 = 0.14-0.16，与零相差 ~2.3-2.6σ
- 在激进基线（1.08-1.10）下：残差 = 0.08-0.10，与零相差 ~1.3-1.6σ
- 仅基线参数在合理范围（1.01→1.05, 1.01→1.03）内的变化，就改变了残差符号的统计显著性整整 1σ

**致命发现 2：不同的 √s_NN 能量点，基线的合理范围不同。**

对于 STAR BES 的低能 Au+Au（√s_NN=7.7-19.6 GeV）：
- 净重子密度高 → 初态同位旋效应更强
- 领头粒子效应因低多重数而更强
- 基线不确定度在低能区更大（±0.04-0.06，而非 ±0.02-0.03）

对于 ALICE LHC（√s_NN=2.76-5.02 TeV）：
- 净重子密度低（近中快度）→ 初态同位旋效应可忽略
- 领头粒子效应被高多重数稀释
- 基线不确定度较小（±0.01-0.02）

**这意味着：声称的"介质残差的能量依赖性"可能只是基线不确定度的能量依赖性的反映。**

### A1.4 残差方向翻转分析

选取 5 个关键数据点（覆盖不同 √s_NN 和实验），比较保守基线与激进基线下残差的符号和大小：

| 数据点 | √s_NN (GeV) | R_K_meas ± stat ± sys | 保守基线 | 激进基线 | 残差(保守) | 残差(激进) | 符号一致？ |

| STAR BES Au+Au 7.7 | 7.7 | ~1.25 ± 0.08 ± 0.10* | 1.05 | 1.12 | +0.200±0.128 | +0.130±0.128 | 一致(+) |
| STAR BES Au+Au 19.6 | 19.6 | ~1.15 ± 0.06 ± 0.08* | 1.04 | 1.09 | +0.110±0.100 | +0.060±0.100 | 一致(+) |

**致命发现 3：残差方向在所有数据点保持一致（R_K_meas > R_K_baseline）。** 这表面上支持残差的真实性。但是：
1. **量级差异巨大** —— 保守基线下 0.15 vs 激进基线下 0.08（NA61 数据），100% 的变化
2. **显著性降低** —— 没有一个数据点在激进基线下达到 3σ
3. **方向一致性是必要的但不是充分的检验** —— 它只说明 R_K 系统性地 > 1，但这可以由共同的物理来源（如关联产生不对称性，见攻击 3）解释

### A1.5 综合评定

| 评定项 | 结论 |
|--------|------|
| 基线不确定度量级 | ±0.05-0.10（与残差同量级） |
| 保守 vs 激进基线残差变化 | 0.08 → 0.15（因子 2） |
| 残差方向翻转？ | 否（所有数据点方向一致） |
| 激进基线下显著性 | 全部 < 3σ |
| 严重性 | **致命** — 残差量级 < 基线不确定度量级 |

**攻击 1 的结论：真空基线的不确定度（±0.05-0.10）与声称的介质残差（0.06-0.13）处于同一数量级。在最保守的基线假设下残差最大，在最激进的基线假设下残差最小 ← 这是典型的"研究人员自由度"特征。基线建模的自由度单独就可将 v3 的声称从 ~2-3σ 发现降级为 ~1-2σ 提示。**

## §A2 攻击维度二：[严重] 不同实验间的系统误差可比性

### A2.1 核心问题

NA61/SHINE、STAR、ALICE 使用不同的探测器、不同的 K0_S 重建方法、不同的效率校正策略。将它们的数据放在同一张图上作为"介质残差的能量依赖性"隐含假设了实验间的可比性。

**这个假设错误。**

### A2.2 K0_S 重建效率：三项实验的对比

| 方面 | NA61/SHINE | STAR | ALICE |
|------|-----------|------|-------|
| **探测器** | 大型 TPC（2 个）+ V0 触发 | 大型 TPC（1 个，圆柱形） | TPC + ITS + V0 |
| **K0_S 标识** | 拓扑：V0 衰变顶点 + 不变质量 | 拓扑：V0 衰变顶点 + 不变质量 | 拓扑 + ML 增强 |
| **V0 衰变长度** | ~3 cm（典型） | ~5-10 cm（典型） | ~5-10 cm（典型） |
| **效率（低 pT, <1 GeV/c）** | ~10-20% | ~5-15%（BES-I） / ~15-25%（BES-II） | ~20-40% |
| **效率（中 pT, 1-2 GeV/c）** | ~20-30% | ~15-25% | ~30-50% |
| **效率校正方法** | EPOS + GEANT 嵌入 MC | HIJING/PYTHIA + GEANT 嵌入 MC | PYTHIA/HIJING + GEANT 嵌入 MC + data-driven 交叉检验 |
| **K0_S 重建系统误差** | ±5-10% | ±4-8% | ±3.8-5.4%（仅重建）+ 其它源 |

### A2.3 pT 接收度不匹配的定量分析

不同实验取不同的 pT 积分区间或取不同 pT bin 中心。K± 和 K0_S 的 pT 谱形状在重离子碰撞中不同：

- **K± 的 pT 谱比 K0_S 更硬**：带电 kaon 受集体径向流影响更大（通过 TPC 中的 dE/dx 和 TOF 标识，带电 kaon 在更低 pT 被高效检测；中性 kaon 通过 V0 拓扑重建，在更低 pT 效率崩塌）
- 这意味着在不同实验中，R_K 的有效 pT 窗口不同

**定量：**
- NA61/SHINE Ar+Sc: K± 在 pT=0-1.5 GeV/c，K0_S 在 pT=0-1.2 GeV/c ⟨pT⟩ ≈ 0.7-0.8 GeV/c
- STAR BES: K± 在 pT=0.2-2.0 GeV/c，K0_S 在 pT=0.3-1.8 GeV/c
- ALICE: K± 在 pT=0.15-3.0 GeV/c，K0_S 在 pT=0.3-2.5 GeV/c

**R_K 的 pT 依赖性（预期）：**
- 在低 pT（<1 GeV/c），多散射 + 径向流使 R_K 偏高（K+ 比 K0 更容易被推至中 pT）
- 在高 pT（>2 GeV/c），硬散射 + 碎裂主导使 R_K 趋近 pp 值

**关键检验：** NA61/SHINE 和 STAR 在重叠 pT 区域（0.5-1.5 GeV/c）的 R_K 值是否一致？如果不一致，意味着"能量依赖性"来自 pT 窗口不匹配，而非真实物理。

### A2.4 NA61/SHINE 内部的不对称系统误差

这是本次攻击中最具体和最有杀伤力的发现。

NA61/SHINE 的 K+ 和 K0_S 测量使用**完全不同的方法学**：

| 方面 | K+ 测量 | K0_S 测量 |
|------|---------|----------|
| **标识方法** | dE/dx + TOF（带电径迹） | V0 拓扑重建 + 不变质量拟合 |
| **效率校正** | 径迹重建效率 + PID 效率 | V0 找迹效率 + 几何接受度 + 选择条件 |
| **系统误差来源** | dE/dx 校准、TOF 校准、径迹重建 | V0 找迹、几何接受度、背景减除 |
| **系统误差大小** | ±7.4%（dn/dy K+）至 ±14.8%（K+, Ar+Sc 75A）**实际值见下文** | ±10.2%（dn/dy K0_S） |
| **误差相关性** | 与 K0_S **完全独立** | 与 K+ **完全独立** |

**来自 SQM 2024 NA61/SHINE Ar+Sc 75A GeV/c 的公布数据：**
- dn/dy(K+) 在 y≈0：统计 ±0.016，**系统 ±0.148**（对，14.8%！）
- dn/dy(K-) 在 y≈0：统计 ±0.012，系统 ±0.069
- dn/dy(K0_S) 在 y≈0：统计 ±0.027，系统 ±0.102
- ⟨K0_S⟩ 平均多重数：统计 ±0.10，系统 ±0.83

**R_K = (K+ + K-)/(2 K0_S)：**
- K+ 通道系统误差 14.8% ← 这是 R_K 的主要污染源之一
- K0_S 通道系统误差 10.2%
- 两个误差完全不相关 → 总系统误差 ≈ √(0.148² + 0.102²)/√2 ≈ ±0.090（在 75A GeV/c 的 R_K 中）

NA61/SHINE 引用的 R_K = 1.184 ± 0.061 的总误差 **可能低估了** 这两项独立系统误差的净贡献。若系统误差组合得当，R_K 的 1σ 区间应为 1.184 ± 0.10 或更大 → 残差在 1σ 内与零相容。

### A2.5 STAR BES-I 和 ALICE 的等效不对称性

**STAR BES-I** 的 K0_S 效率在低 pT（<0.5 GeV/c）极低（V0 衰变长度被 TPC 内半径限制）。效率修正因子在低 pT 很大（~3-5×），对应的系统误差也大。这与 K±（径迹重建，低 pT 效率高）形成不对称。

**ALICE** 在 LHC 有最均匀的 K0_S 效率（ITS 硅径迹探测器提供精确的初级和次级顶点重建）。但 ALICE 的系统误差结构不同：
- TPC + ITS + TOF/TPC PID 提供完全冗余的 K± 标识 → 系统误差小
- V0 拓扑 + ITS 二级顶点重建提供最高 K0_S 效率 → 系统误差小（3.8-5.4% 仅重建）
- **但 ALICE 在高多重性 Pb+Pb 中，V0 重建效率下降**（高占有率 → V0 径迹合并 → 效率崩跌）

### A2.6 不同实验系统误差组合后的影响

将上述分析的要点转化为定量估计：

| 实验 | K± 系统误差 | K0_S 系统误差 | 净 R_K 系统误差估计 | 与声称残差对比 |
|------|------------|-------------|-------------------|-------------|
| NA61/SHINE Ar+Sc | ~10-15% | ~5-10% | ±0.10-0.15 | 残差 ~0.12 → 0.8-1.2σ |
| STAR BES Au+Au 低能 | ~8-12% | ~8-12% | ±0.10-0.15 | 残差 ~0.15 → ~1σ |
| STAR Au+Au 200 GeV | ~6-8% | ~5-8% | ±0.07-0.10 | 残差 ~0.06 → <1σ |
| ALICE Pb+Pb LHC | ~3-5% | ~3-5% | ±0.04-0.07 | 残差 ~0.03 → <1σ |

**综合评定：** 系统误差在低能区（√s_NN < 20 GeV）完全淹没了声称的残差。在高能区，系统误差与残差可比，但残差本身也更小。

### A2.7 综合评定

| 评定项 | 结论 |
|--------|------|
| 实验间 K0_S 重建方法可比性 | 不可比 — 三种完全不同的方法学 |
| pT 接受度不匹配 | 显著 — 影响 R_K 的 pT 依赖性解释 |
| NA61 K+ vs K0_S 系统误差可比性 | **不可比** — 14.8% vs 10.2%，完全不相关 |
| 系统误差淹没收差？ | 在低能区（<20 GeV）：是。在高能区：部分 |
| 严重性 | **严重** — 将 pT 窗口不匹配 + 实验间系统误差偏移归因于"介质效应"是分析 artifact |

## §A3 攻击维度三：[严重] 替代解释 — 不需要介质效应

### A3.1 关联产生不对称性（非介质效应）

**物理背景：**

在重离子碰撞中，奇异粒子主要通过关联产生产生：
```
N + N → N + K + Y  （Y = Λ, Σ）
```

阈值能量：
- N+N → N+K+Λ：√s_thr ≈ 2.548 GeV（m_N + m_Λ + m_K ≈ 938 + 1116 + 494 MeV）
- N+N → N+K+Σ：√s_thr ≈ 2.625 GeV（m_N + m_Σ + m_K ≈ 938 + 1192 + 494 MeV）

**Δthr = 77 MeV（≈ Σ-Λ 质量差）**

**为什么这与 v3 相关：**

在 √s_NN < 20 GeV 的能量下（NA61/SHINE、STAR BES），核子-核子质心系能量（在固定靶 SPS：√s_NN ≈ 8-17 GeV；在 BES：√s_NN = 7.7-19.6 GeV）接近关联产生的阈值区域。虽然单个 N+N 碰撞可能远高于阈值，但级联碰撞中的次级 N+N 碰撞可以是亚阈值的。

考虑 **两阶段产生机制**：
1. **初级**：高能 N+N → N+Δ/N* + π（Δ/N* 带走大部分动能）→ 次级 N 能量被压低
2. **次级**：被压低的 N + N → N + K + Y → Λ 通道（2.548 GeV）vs Σ 通道（2.625 GeV）

在次级碰撞中（有效 √s_eff ≈ 2.6-3.0 GeV），77 MeV 的阈值差异导致相空间增强因子。

**定量估算（相空间因子）：**

对于两体 → 三体的反应，近阈值的相空间 ∝ (√s - √s_thr)²。

在 √s_eff = 2.7 GeV：
- ΛK 通道：相空间 ∝ (2.70 - 2.55)² = (0.15)² = 0.0225
- ΣK 通道：相空间 ∝ (2.70 - 2.63)² = (0.07)² = 0.0049
- ΛK/ΣK 相空间比 ≈ 4.6:1

在 √s_eff = 2.9 GeV：
- ΛK 通道：相空间 ∝ (0.35)² = 0.1225
- ΣK 通道：相空间 ∝ (0.27)² = 0.0729
- 比值 ≈ 1.7:1

**关键点：在较低的 √s_eff 下，Λ 通道（产生 K+）相对于 Σ 通道（产生 K0——通过 Σ+ → n + π+ 或 Σ0 → Λ + γ，K0 与 Σ 关联）被强烈增强。**

这意味着：在 SPS 和低 RHIC 能区，**真空 QCD 的关联产生动力学**本身就偏向 K+ 相对于 K0——不需要任何介质修正。

**攻击论据：v3 将关联产生的相空间效应（真空物理 → 在低能区自然随 √s_NN 递减）误归因于介质 KNY 耦合修正。两者具有相同的定性签名（随 √s_NN 递减的 R_K 增强），但物理来源完全不同。**

### A3.2 φ → KK̄ 分支比差异 + φ 产额在介质中的增强

**物理背景：**

φ 介子（m_φ = 1019.5 MeV）几乎 100% 衰变为 KK̄：
- φ → K+K-：分支比 = 49.1 ± 0.5%
- φ → K0_S K0_L：分支比 = 34.0 ± 0.5%
- φ → K0 K̄0（总）= 34.0%（含 K0_S K0_S + K0_L K0_L 但被抑制）

**不对称比 = 49.1/34.0 ≈ 1.44**

**机制：**

1. 在重离子碰撞中，奇异夸克对 s̄s 在介质中增强（奇异增强效应）
2. φ 介子作为 s̄s 束缚态，其产额在重离子碰撞中增强
3. 每个 φ → K+K- 贡献 2 个带电 kaon，每个 φ → K0K̄0 贡献 2 个中性 kaon（但其中只有一个 K0_S 被重建，K0_L 通常不被重建）
4. 有效重建比例：φ → 2 K± (49.1%) vs φ → 1 K0_S + 1 K0_L (34.0%)

**定量影响：**

设 φ 在介质中的产额增强因子为 f_φ（相对于 pp 基线，f_φ ≈ 1.5-3.0 在中心重离子碰撞中）。

φ 衰变对 R_K 的贡献：
```
R_K_φ ≡ [K± from φ] / [K0 from φ, obs]
      = [2 × f_φ × 0.491] / [1 × f_φ × 0.340]
      = 2 × 0.491 / 0.340
      = 2.89
```

即来自 φ 衰变的 kaon 有 **R_K_φ ≈ 2.9**。

设总 kaon 产额中来自 φ 的比例为 f_φ→K（在介质中因 φ 增强，f_φ→K ≈ 0.05-0.15）：
```
R_K_eff = (1 - f_φ→K) × R_K_direct + f_φ→K × 2.89
```

若 R_K_direct = 1.0（无介质修正），f_φ→K = 0.10：
R_K_eff = 0.90 × 1.0 + 0.10 × 2.89 = 1.189

**这完美地再现了 NA61/SHINE 的观测值 R_K ≈ 1.18！**

**与 v3 声称的区别：**
- v3 声称：φ 增强 → 通过 φ 的介质修正 KNY 耦合 → 改变 R_K。但是，φ 增强只是通过已知的奇异增强 + 不对称分支比的简单叠加，**不需要新的介质 KNY 耦合机制**。
- A 博士可能没有从 R_K 中扣除 φ 的 feed-down 贡献（或使用了不正确的 φ→KK̄ 分支比）。
- **如果 (a) φ 产额在重离子中增强，且 (b) φ→K+K- vs φ→K0K̄0 分支比不对称，则 φ feed-down 本身就会产生表观的 R_K 增强 —— 不需要介质 KNY 修正。**

### A3.3 核子-核子短程关联（SRC）改变有效的 p/n 参与者比例

**物理背景：**

在高能核碰撞中，核子-核子短程关联（SRC，r_NN < 1 fm，p > k_F）主要形成 np 对（np-SRC 占 SRC 的 ~90%，pp-SRC 被 Pauli 阻塞抑制）。

在高动量尾（p > 300 MeV/c），核子动量分布被 SRC 支配。当 Glauber 模型计算 N_part 和 Z_part 时，使用的是平均场核子密度（Woods-Saxon），**不包括 SRC 引起的关联修正**。

**影响：**

1. SRC 主要形成 np 对 → 在中心碰撞中，来自 SRC 的核子对含有更多中子（相对于 Glauber 预测的平均值）→ 有效 N_part/Z_part 比 Glauber 预测更高
2. 更高的 N_part/Z_part 意味着更多的 d 夸克参与碰撞 → K0 产生增强 → R_K 被压低
3. **但注意：SRC 核子恰好也是在高动量碰撞中产生领头粒子的核子。这意味着领头粒子的 p/n 比例与 Glauber 预测可能不同。**

**定量：**

SRC 对 N_part/Z_part 的修正可能达到 ±3-5%。对于 N/Z ≈ 1.18 的 Ar+Sc 系统：
- Glauber 预测 N_part/Z_part ≈ 1.15-1.20
- SRC 修正后 N_part/Z_part ≈ 1.18-1.25
- 对应的初态同位旋修正从 f_NZ ≈ 1.01-1.02 变为 f_NZ ≈ 1.03-1.05

**这直接转化为真空基线的 0.02-0.03 偏移 → 声称的残差被进一步压低。**

### A3.4 K- 和 K+ 在介质中的不对称行为

根据手征微扰论和耦合道计算（Lutz, Oset, Fuchs 等, 1998-2006）：

在核介质中（密度 ρ）：
- K+ 有效质量 **增加**（弱排斥，α_K+ ≈ +0.05-0.10 at ρ_0）
- K- 有效质量 **降低**（强吸引，α_K- ≈ -0.10 到 -0.20 at ρ_0）

**这对 R_K 的影响：**

R_K = (K+ + K-)/(2 K0_S)

若 K- 在介质中产额因质量降低而增强（阈值降低），则：
- R_K 在介质中偏大（因为分子中的 K- 增强）
- 但 K0_S 不受此影响（K0_S = 0.5×K0 + 0.5×K̄0 → K̄0 的介质增强被 K0 的介质压低所抵消？）

**实际上，R_K 在介质中的增强之一部分可能直接来自 K- 在介质中的独立产额增强，而非来自任何"KNY 耦合修正"。**

A 博士的 v3 声称将整个 R_K 增强归因于"介质修正 KNY 耦合"，但实际上：
- φ feed-down 贡献 ~0.05-0.10
- 关联产生相空间效应贡献 ~0.03-0.05（低能区）
- K- 独立介质增强贡献 ~0.02-0.03
- 净残余（可能真正来自新物理）：~0.00-0.05

### A3.5 综合评定

| 评定项 | 结论 |
|--------|------|
| 关联产生不对称性 | 真实效应 — 77 MeV 阈值差异在低能区重要 |
| φ feed-down 效应 | **高影响** — φ 产额增强 + 不对成分支比可单独解释 ~0.10 的 R_K 增强 |
| SRC 修正 | 中等影响 — 改变有效 p/n 比例，偏移基线 ~0.02-0.03 |
| K- 独立介质增强 | 小到中等 — 可能贡献 ~0.02-0.03 |
| 扣除替代解释后的净残差 | **0.00-0.05** ← 在综合不确定度内与零相容 |
| 严重性 | **严重** — v3 声称的介质效应可以被已知的、非介质的物理机制更简洁地解释 |

## §A4 攻击维度四：[中等] STAR BES 数据的低能陷阱

### A4.1 K0_S 重建效率在低 pT 的崩塌

STAR BES-I（2010-2011 数据采集）的 K0_S 重建基于 V0 衰变 → π+π- 的拓扑重建。V0 衰变顶点必须位于 TPC 内部（径向 ~50-200 cm）。

对于低 pT（<0.5 GeV/c）的 K0_S：
- K0_S 衰变长度 = βγcτ = (p/m) × cτ
- cτ = 2.68 cm（K0_S 寿命）
- 在 pT=0.3 GeV/c：βγ = 0.3/0.498 = 0.60 → 衰变长度 ≈ 1.6 cm
- 在 pT=0.5 GeV/c：βγ = 0.5/0.498 = 1.00 → 衰变长度 ≈ 2.68 cm
- 在 pT=1.0 GeV/c：βγ = 2.01 → 衰变长度 ≈ 5.4 cm

**致命问题：** 当衰变长度 < 5 cm 时，V0 衰变顶点在 TPC 内半径（~50 cm）以内 → 两条 π 径迹在 TPC 中只有很短的杠杆臂 → **顶点分辨率崩塌 → 重建效率崩塌。**

此外，V0 衰变长度 < 3 cm 时，衰变距初级顶点太近 → V0 找迹算法无法区分二级顶点和初级顶点 → 效率为零。

**结果是 STAR BES-I 的 K0_S 在 pT < 0.5 GeV/c 的效率可能 < 5%（与 pT ~1-2 GeV/c 的 ~15-25% 相比）。**

### A4.2 效率修正因子的放大

当效率 < 5% 时，效率修正因子 > 20 → 小效率的系统误差被放大 → pT 谱的低 pT bin 具有极大的修正不确定度。

**这导致 R_K 在低 pT 被偏估：**
- K± 径迹重建在低 pT 效率仍然合理（dE/dx + TOF 标识，径迹在 TPC 中有充分的采样点）
- K0_S 在低 pT 效率崩塌 → 低 pT 的 K0_S 产额主要依赖于 MC 外推 → 模型依赖
- 若 K0_S 产额在低 pT 被低估（效率修正过大）→ R_K 被高估

### A4.3 旁观者核子污染

在 BES 的 Au+Au 低能碰撞（√s_NN=7.7-19.6 GeV）中，核阻止（nuclear stopping）强 → 旁观者核子数量多。旁观者核子碎裂可产生额外的 π 和 K，特别是：
- 旁观者中子 → 含 d 夸克 → 额外的 K0
- 旁观者质子 → 含 u 夸克 → 额外的 K+

这些旁观者产生的 kaon 在中心快度区可能被误认为是参与者产生的 kaon。中央度选择（如 0-5% 或 0-10%）理论上排除大部分旁观者，但在低能区，旁观者碎裂产物可能被集体流推向中快度。

### A4.4 BES-I 的统计量

BES-I 在最低能量点（7.7 GeV）的统计量极小：
- Au+Au 7.7 GeV 总计约 3×10⁶ 事件（BES-I 2010 数据采集）
- 中心碰撞（0-10%）：约 3×10⁵ 事件
- K0_S 在中快度区产额：每事件 ~0.1-0.2
- 有效 K0_S 统计（包括效率）：~10³-10⁴

相比之下，NA61/SHINE Ar+Sc 75A GeV 有 ~10⁷ 事件。

**→ BES-I 低能 K0_S 数据由系统误差主导，而非统计误差。系统误差难以精确量化 → R_K 在低能区的值有极大的不确定度。**

### A4.5 综合评定

| 评定项 | 结论 |
|--------|------|
| K0_S 低 pT 效率崩塌 | 真实 — 衰变长度 < 内圈半径 → 效率 < 5% |
| 效率修正放大 | 真实 — 因子 >20 放大系统误差 |
| 旁观者污染 | 可能 — 低能区的核阻止强 |
| 统计量 | 极小 — 系统误差主导 |
| 严重性 | **中等** — 影响 BES 数据点但不改变全局结论（因为 NA61 和 ALICE 数据不受此影响） |
