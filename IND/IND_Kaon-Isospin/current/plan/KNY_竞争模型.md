# Phase 2 预研：KNY耦合不对称性的符号竞争 — 产生增强 vs 吸收压制

**撰写：PI（独立推导，不依赖A/B数据）**
**日期：2026-05-31**
**状态：v3 Phase 2 核心理论准备**

---

## §0 动机：v1 M1 的符号问题

v1 A博士§6.3 提出了"M1: KNY耦合不对称性经多散射放大→R_K>1"的机制。但仔细检查发现，**吸收截面的符号是反的：g_KNΛ > g_KNΣ → σ_abs(K+) > σ_abs(K0) → K+吸收更多 → R_K减小，而非增大。**

这意味着M1在v1的简单形式下不能解释R_K>1。需要在同一框架内引入**产生端的KNY不对称性**，它与吸收端竞争，产生净效应。

---

## §1 产生端 vs 吸收端

### §1.1 产生端：关联产生 N+N → N+K+Y

在重离子碰撞中，K介子的一个重要来源是关联产生：
```
N + N → N + K+ + Λ    [Λ道, 耦合 g_KNΛ, 阈值 2.548 GeV]
N + N → N + K0 + Σ    [Σ道, 耦合 g_KNΣ, 阈值 2.625 GeV]
```

**两个不对称性源：**
1. **耦合不对称性：** g_KNΛ/g_KNΣ ≈ 3.6-5.4 → Λ道截面 > Σ道截面 → 更多K+产生
2. **阈值不对称性：** Λ道阈值低77 MeV → 在近阈能区（√s_NN~5-10 GeV）相空间更大 → 更多K+

两者同向 → **产生端明确增强K+** → R_K_production > 1。

### §1.2 吸收端：K介子-核子散射 K+N → π+Y

```
K+ + N → π + Λ     [吸收, 耦合 g_KNΛ]
K0 + N → π + Σ     [吸收, 耦合 g_KNΣ]
```

耦合不对称性 → σ_abs(K+) > σ_abs(K0) → K+被吸收更多 → **吸收端压制K+** → R_K_absorption < 1。

### §1.3 弹性散射端

```
K+ + N → K+ + N    [弹性, 耦合 g_KNΛ]
K0 + N → K0 + N    [弹性, 耦合 g_KNΣ]
```

弹性散射不改变K介子数量，但改变pT分布。大截面→更易散射到低pT→可能低于探测阈值→等效"损失"。**弹性散射也压制K+（与吸收同向）。**

## §2 竞争模型

### §2.1 净R_K偏移

定义：
- f_prod(√s_NN)：通过关联产生产生的K介子占比
- f_scat(√s_NN, centrality)：经历≥1次散射的K介子占比
- A_prod = σ(NN→NKΛ)/σ(NN→NKΣ) - 1 > 0：产生不对称性
- A_abs(centrality)：吸收+弹性散射导致的存活不对称性 < 0（压制K+）

```
ΔR_K = f_prod × A_prod + f_scat × A_abs × (1 - survival_correction)
```

关键：f_prod 和 f_scat 随 √s_NN 有不同的标度行为。

### §2.2 √s_NN 依赖性

**近阈区（√s_NN ≈ 2-5 GeV，如 HADES、FAIR-CBM）：**
- f_prod 大（关联产生是K介子的主要来源，直接弦碎裂产生受限于相空间）
- f_scat 中（系统小，散射次数少）
- → 产生端主导 → ΔR_K > 0，可能很大（0.15-0.30）

**SPS 能区（√s_NN ≈ 5-17 GeV，如 NA61/SHINE、NA49）：**
- f_prod 减弱（弦碎裂开始贡献更多K介子）
- f_scat 增大（系统更大，散射次数增加）
- → 产生和吸收竞争 → ΔR_K ≈ 0.05-0.15（净为正，产生仍略占优）

**RHIC 能区（√s_NN ≈ 20-200 GeV，如 STAR BES）：**
- f_prod 进一步减弱
- f_scat 达到最大（系统最大，但温度更高→散射截面可能减小）
- → 产生≈吸收 → ΔR_K ≈ 0-0.05

**LHC 能区（√s_NN ≈ 200-5000 GeV，如 ALICE）：**
- f_prod 很小（K介子主要来自弦碎裂，关联产生占比低）
- f_scat 小（高温→散射截面减小，且K介子化学平衡降低了存活差异）
- → 两端都弱 → ΔR_K ≈ 0-0.03

### §2.3 中心度依赖性

**边缘碰撞（大b，小N_part）：**
- 系统小→散射次数少→吸收端弱
- 产生端不变（关联产生发生在初态NN碰撞中，正比于N_coll）
- → 产生端主导 → ΔR_K > 0

**中心碰撞（小b，大N_part）：**
- 系统大→散射次数多→吸收端强
- 产生端也增强（更多NN碰撞），但线性增长vs指数增长？
- → 竞争结果取决于具体的密度和尺寸

**预测：ΔR_K 应在边缘碰撞中更大（产生端主导），在中心碰撞中可能减小甚至翻转。**

### §2.4 pT 依赖性

**低pT（< 0.5 GeV/c）：**
- K介子经历更多散射（速度慢，在介质中停留时间长）
- 弹性散射效应大→吸收端主导→ΔR_K可能为负或小正值
- K0_S重建效率低→实验系统误差大

**中pT（0.5-2 GeV/c）：**
- 散射适中
- 产生端和吸收端竞争→净效应取决于√s_NN
- 实验精度最高

**高pT（> 2 GeV/c）：**
- 来自硬散射+碎裂→关联产生占比低→产生端弱
- 高能K介子逃离快→吸收端也弱
- → ΔR_K → 0

**预测：ΔR_K 应在中pT区最大（产生端有效+吸收端未完全主导），在高pT区趋于零。**

## §3 定量化需求

### §3.1 需要的输入

| 参数 | 符号 | 当前约束 | 需要 |
|------|------|---------|------|
| 关联产生K介子占比 | f_prod(√s_NN) | 无系统编译 | 从pp→K+Y数据和传输模型提取 |
| 散射K介子占比 | f_scat(√s_NN, cent) | GiBUU/UrQMD有计算 | 从传输模型提取 |
| 产生不对称性 | A_prod | g_KNΛ/g_KNΣ≈5 → σ∝g⁴≈625 | 需实验约束（σ(NN→NKΛ)/σ(NN→NKΣ)的实测值） |
| 吸收不对称性 | A_abs | Δσ_abs≈5 mb at 0.5 GeV/c | 同上 |
| 弹性散射pT重分布 | — | 模型依赖 | 传输模型输出 |

### §3.2 简化可检验预测

不依赖完整模型，以下关系可直接检验：

1. **ΔR_K(边缘碰撞) > ΔR_K(中心碰撞)** — 若成立→支持产生端vs吸收端竞争
2. **ΔR_K(低√s_NN) > ΔR_K(高√s_NN)** — 若成立→支持f_prod的√s递减
3. **ΔR_K(中pT) > ΔR_K(高pT)** — 若成立→支持关联产生（而非碎裂）作为主要来源
4. **ΔR_K(Au+Au) > ΔR_K(Cu+Cu) 在同一√s_NN** — 若成立→系统大小依赖性

## §4 与其他机制的区分

### §4.1 与夸克重组（G&R, M2）的区分

G&R夸克重组机制的核心预测：
- ΔR_K依赖于强子化温度T_chem和重子化学势μ_B
- pp vs AA有明确的阈值行为（QGP形成）
- ΔR_K应与T_chem关联，而非与系统大小

KNY竞争模型（M1改进版）的核心预测：
- ΔR_K依赖于ρ_B × ⟨N_scat⟩
- 大小系统有连续过渡（无阈值）
- ΔR_K应与系统大小和中心度强关联

**区分性观测量：** 在相同T_chem但不同系统大小的碰撞中（如Xe+Xe vs Pb+Pb at similar √s_NN），M1预测ΔR_K(XeXe) < ΔR_K(PbPb)，而M2预测ΔR_K相似。

### §4.2 与φ增强+分支比（替代解释）的区分

φ→KK̄分支比不对称性（K+K-/K0K̄0=1.44）→更多φ→更多K+/K0不对称。

**区分性观测量：** 若ΔR_K与φ/K比值正关联→φ增强贡献。若ΔR_K与φ/K无关联→φ增强非主因。

### §4.3 与关联产生阈值效应（纯运动学，非耦合不对称）的区分

即使g_KNΛ=g_KNΣ（无耦合不对称），77 MeV的阈值差异也会导致产生不对称性。

**区分性观测量：** 阈值效应随√s_NN迅速消失（∝~1/√s_NN），而耦合不对称性∝g⁴差异在远高于阈值的能区仍有残存。如果ΔR_K在高√s_NN也持续（∝常数而非∝1/√s_NN），支持耦合不对称。

## §5 结论

### v3 Phase 2的核心理论贡献

**将v1的简单"M1: KNY耦合→R_K>1"修正为"M1': KNY耦合不对称性在产生端和吸收端的符号竞争"——这是一个更完整、更可检验的理论框架。**

关键洞察：
1. KNY耦合不对称性在产生端增强R_K（正号）
2. 同一耦合不对称性在吸收端压制R_K（负号）
3. 净效应取决于√s_NN、中心度和pT——可预测的模式
4. 这些预测可用现有数据直接检验

### 无论检验结果如何

- 若产生端主导得到支持 → R_K成为KNΛ/KNΣ产生截面的间接探针
- 若吸收端主导得到支持 → R_K成为K介子-核子散射截面的间接探针
- 若竞争模型被排除 → 转向夸克重组(M2)或φ增强(替代解释)

**R_K在v3中被重新定位为"强子介质中KN相互作用的探针"（而非对称性破缺信号）。**
