## §2 阈值不对称性（纯运动学）

### 精确阈值计算（PDG 2022质量）

```
N+N → N+K+Λ: m_N + m_K+ + m_Λ = 938.272 + 493.677 + 1115.683 = 2547.632 MeV
N+N → N+K0+Σ+: m_N + m_K0 + m_Σ+ = 938.272 + 497.614 + 1189.37 = 2625.256 MeV
Δm_threshold = 2625.256 - 2547.632 = 77.6 MeV
```

### s波相空间因子

近阈s波截面：σ ∝ p*/s ∝ √(s - (m1+m2)²)/s

Λ道和Σ道的相空间比：
```
R_phase(√s) ≡ p*_Λ / p*_Σ = √(s - s_Λ) / √(s - s_Σ)
```
其中 s_Λ = (2.548)² = 6.492 GeV², s_Σ = (2.625)² = 6.890 GeV²

## §3 耦合不对称性（动力学）

### 截面比估计

Λ道（I=0 KN散射）和Σ道（I=1 KN散射）的耦合常数比：g_KNΛ/g_KNΣ ≈ 3.6-5.4 (v1 §6.2)

在Born近似下σ ∝ g⁴ → 截面比 ≈ 170-850。
但实际截面受幺正性约束、共振饱和和运动学压制。

从实验数据（K+N散射）：
- σ(K+p→K+p) ≈ 10-15 mb at p_lab ~ 0.5-1 GeV/c
- σ(K+n→K0p)（电荷交换，耦合到Σ）≈ 3-5 mb
- 实际截面比 ≈ 3-5（远小于g⁴估计）

对于关联产生 N+N→N+K+Y（非KN散射但通过相同顶点耦合）：
- 没有直接的pp→pK+Λ和pp→pK0Σ+截面测量在同一能量
- 从近阈产生数据：σ(pp→pK+Λ)在T_p≈2-3 GeV为~1-10 μb量级
- σ(pp→pK0Σ+)尚无精确测量（K0Σ+末态重建困难）
- 粗略估计截面比≈2-5（耦合差异被幺正性和运动学缩放）

## §6 关键不确定性

A_prod（耦合不对称性）是最大的不确定度来源。迫切需要：
1. pp→pK+Λ和pp→pK0Σ+截面在同一能量的直接测量比
2. 或从KN散射相移分析中更精确地提取g_KNΛ/g_KNΣ
3. 传输模型中关联产生截面的实际参数化（当前使用什么值？）

**若A_prod≈1-2（最保守的耦合不对称估计），ΔR_K_assoc在SPS≈0.05-0.30——仍可覆盖观测残差。**
