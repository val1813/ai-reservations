## §1 DRO 定义

$$
R_{\text{double}} \equiv \frac{(K^+/\pi^+)}{(K^-/\pi^-)} \Bigg/ \frac{(K^0_S/\pi^+)}{(K^0_S/\pi^-)}
$$

其中所有产额在同一运动学区间（y, pT）测量。

## §2 物理动机

在电荷共轭对称性（CP）和π介子同位旋对称性（π+≈π-）下：
- 若P(u)/P(d)=1且所有同位旋破缺效应可忽略：R_double = 1
- 若P(u)/P(d)≠1：R_double偏离1，偏离量在领头阶正比于(ρ_ud - 1)

**核心优势：** DRO消除了e_q²加权、探测器接受度、π介子归一化等公共系统误差——这些正是v2识别的主要混淆因素。

## §3 数学推导

### §3.1 符号

在给定运动学区间内：
- K+产额 = N(K+) = A_K × ε_K+ × P(u)σ(u→K+) × L
- K0_S产额 = N(K0_S) = A_K × ε_K0 × P(d)σ(d→K0) × L × 1/2

其中A_K是接受度，ε是效率，σ是产生截面，L是积分亮度。

π介子类似。

### §3.2 DRO的抵消性质

分子第一部分：(K+/π+) ∝ P(u)σ(u→K+)/σ(u→π+)
分子第二部分：(K-/π-) ∝ P(ū)σ(ū→K-)/σ(ū→π-)。在CP下P(ū)=P(u)，σ(ū→K-)=σ(u→K+)，σ(ū→π-)=σ(u→π+) → 分子 = 1。

分母第一部分：(K0_S/π+) ∝ P(d)σ(d→K0)/σ(u→π+) × (1/2)
分母第二部分：(K0_S/π-) ∝ P(d̄)σ(d̄→K̄0)/σ(ū→π-) × (1/2)

在CP和同位旋极限下：P(d)=P(d̄)，σ(d→K0)=σ(d̄→K̄0)，分母 = 1。

**因此 R_double = P(u)/P(d) = ρ_ud（领头阶）。**

### §3.3 修正项

在非理想情况下，以下效应破坏精确抵消：

1. **π+/π- ≠ 1的微小差异**（来自m_d≠m_u导致的π±质量差异~4.6 MeV，和电荷相关的探测器效应）
   → 预期偏差 < 0.5%

2. **K+/K-的CP破缺**（标准模型CPV在K介子系统中~0.3%，在产生层面更小）
   → 预期偏差 < 0.1%

3. **π±的电荷不对称性在重离子中**（来自初态同位旋，量级~1-2%）
   → 预期偏差 ~1-2%（在远离边缘快度的中心快度区）

4. **K*→Kπ馈入的差异**
   → 在DRO中大部分抵消（K*三重态在同位旋对称下馈入对称）

**综合修正：领头阶DRO ≈ ρ_ud，次领头阶修正 < 3-5%（在中心快度区）。**

## §4 灵敏度估计

### §4.1 统计误差

DRO的统计误差由4个比值（每个都是泊松/负二项计数比）的误差传播决定。

对NA61/SHINE Ar+Sc 0-20%（典型统计量）：
- N(K+) ~ 5000-10000 per bin
- N(K0_S) ~ 2000-5000 per bin（V0重建效率更低）
- N(π+) ~ 50000-100000 per bin
- N(π-) ~ 50000-100000 per bin

统计误差（独立泊松近似，含NBD过离散修正k≈10-15）：
```
σ(R_double)/R_double ≈ √[1/N(K+) + 1/N(π+) + 1/N(K-) + 1/N(π-) + 1/N(K0_S)×2 + 1/N(π+)+1/N(π-)] × √(1 + μ/k)
```

代入数字：对μ_K≈5000, μ_π≈50000, k≈12:
```
σ_stat(relative) ≈ √[4/5000 + 4/50000] × √(1 + 5000/12)
                  ≈ √[0.0008 + 0.00008] × √(417)
                  ≈ 0.030 × 20.4
                  ≈ 0.61  ← 太大！
```

**问题：NBD过离散因子√(1+μ/k)对K介子的贡献巨大。** 这是因为逐事件K多重数涨落大（NBD而非泊松）。

### §4.2 事件内关联的抵消

但DRO的统计误差在事件层级计算时，分子和分母的NBD涨落高度关联（都正比于总多重数）→ 部分抵消。

**精确计算需要逐事件模拟。** 粗略估计：抵消后有效NBD因子从~20降至~2-3（因为4个比值共享事件多重数涨落）。

修正后：
```
σ_stat(relative) ≈ 0.030 × √(3) ≈ 0.052
```

即**DRO的统计精度 ≈ ±5%**（单中心度bin，NA61/SHINE统计量）。

### §4.3 系统误差

DRO的系统误差远小于单个K/π比值的系统误差，因为：
- 探测器接受度（A_K, A_π）：分子和分母中抵消
- 效率修正（ε_K, ε_π）：大部分抵消
- 馈入修正：部分抵消

残余系统误差估计：
- π+/π-不对称（来自电荷相关探测器效应）：±1-2%
- K0_S/K±相对效率修正：±2-3%（主导残差）
- 馈入修正残余：±1%
- **总系统误差：±3-4%**

### §4.4 灵敏度

合并统计+系统误差：
```
σ(R_double) ≈ ±0.06 (6%)
```

若ρ_ud偏离1的量级为δ ≡ ρ_ud - 1：
- 5σ发现 → δ > 0.30（需要ρ_ud > 1.30或< 0.70）
- 3σ证据 → δ > 0.18
- 排除|δ|<0.10（95% CL）→ 可以实现（±0.06 × 1.96 ≈ ±0.12）

**结论：在NA61/SHINE统计量下，DRO可以排除|ρ_ud-1|>0.12（95% CL）。若ALICE Pb+Pb的高统计量可用，精度可提升至±0.03-0.04。**
