# 研究计划 — Kaon-Isospin v3

> 版本：v3 | 初始化：2026-05-31
> 来源：v2 Type C 重定向 — e_q² 稀释证伪了真空 P(u)/P(d) 能量依赖性，揭示出真正的介质效应信号

## 北极星

**重离子碰撞中 R_K 的介质增强机制 — 真空基线（P(u)/P(d)=1 + e_q²稀释）已被v2确立，重离子中 R_K>1 的残差来自什么介质效应？**

v1 发现了 R_K 异常。v2 证明真空中一切正常（P(u)/P(d)=1，K±/K0_S 能量依赖性 = e_q² 稀释）。v3 追问：既然真空中没有异常，重离子中的异常信号（经真空基线修正后仍余 ~0.07-0.13，~2-3σ）从何而来？

## 驱动矛盾

**命题A（真空基线 + 初态修正）：** e+e- 数据 + e_q² 稀释 → P(u)/P(d)=1 在真空中普适。pp 碰撞中 R_K≈1.03（与初态同位旋+领头粒子效应一致）。重离子碰撞中，扣除相同的初态修正后，若无非平庸的介质效应，R_K 应与 pp 相当或更接近1（介质中更高温→领头粒子效应更稀释）。

- 支持：v2 Phase 1+2 的 e_q² 分析；ALICE pp 数据 R_K≈1.03；标准输运模型在 ρ_ud=1 下预测 R_K≈1.03

**命题B（重离子实验）：** NA61/SHINE Ar+Sc R_K=1.184±0.061。扣除修正后的真空基线（~1.05-1.12，含初态同位旋+领头粒子）→残差 0.06-0.13。STAR Au+Au 200 GeV 的 R_K≈1.03（残差更小）。ALICE Pb+Pb 2.76 TeV 的 R_K≈1.06（残差≈0.03-0.06）。

- 支持：NA61/SHINE (PRD 2024)；STAR (PRC 2009)；ALICE (PRC 2015)；ISO-BREAK 25 世界数据

**为什么不能同时为真：** 如果真空碎裂 P(u)/P(d)=1 且初态修正不足以解释残差，则重离子碰撞中存在额外的介质效应系统性地增强 K+/K0。该效应在低 √s_NN（高 μ_B、中等 T）显著，在高 √s_NN（低 μ_B、高 T）减弱或消失——与已知介质效应（手征对称性恢复、奇异增强等）的能标依赖性一致。

## 北极星合法性确认（三问）

1. 驱动矛盾能写成"命题A vs 命题B，不能同时为真"？→ **是**（修正后的真空基线预测 vs 重离子残差）
2. 解决后谁的工作会改变？→ 强子输运模型开发者（需纳入介质修正的 KNY 耦合）、重离子唯象学（R_K 作为介质探针的新角色）、NA61/SHINE 合作组（显著性重评估）
3. 是技术推广还是新结构介入？→ **新结构介入**（从"对称性破缺信号"重构为"强子介质中 KNY 耦合不对称性的定量探针"）

## 研究路径

### Phase 1: 介质残差的系统提取

**目标：** 对所有可用重离子实验，用 v2 建立的修正真空基线，提取 R_K 的介质残差 ΔR_K_med ≡ R_K_obs - R_K_vacuum_baseline。

**数据源：**
- NA61/SHINE: p+Pb, Ar+Sc, 多能量点 (√s_NN=5-17 GeV)
- STAR: Au+Au, Cu+Cu, √s_NN=7.7-200 GeV (BES-I+II)
- ALICE: Pb+Pb, Xe+Xe, √s_NN=2.76-5.02 TeV

**方法：**
1. 对每个碰撞系统/能量/中心度，用 v2 的 e_q² 修正框架计算真空基线
2. 考虑初态同位旋修正（N/Z 比例）
3. 提取 ΔR_K_med 及其误差
4. 绘制 ΔR_K_med 作为 √s_NN、系统大小、中心度的函数

**产出：** 完整的 ΔR_K_med(√s_NN, A, centrality) 数据表

### Phase 2: 候选介质机制的定量检验

**候选机制（经 v1/v2 过滤后存活的）：**

- **M1: KNY 耦合不对称性的介质放大**（v1 A 博士 §6.2-6.3）
  - g_KNΛ/g_KNΣ≈3.6-5.4 在真空中
  - 介质中每次 K+N 散射 → K+ 和 K0 的存活/产生不对称
  - 多散射累积 → 净 R_K 偏移
  - **预测：** ΔR_K_med ∝ ρ_B × ⟨N_scat⟩（重子密度 × 散射次数）
  - **可检验：** 在低 √s_NN（高 μ_B）应更大；中心碰撞应 > 边缘碰撞

- **M2: 夸克重组机制**（Giacosa & Rohrmoser, EPJC 2025）
  - u/d 夸克重组为 K 介子的概率在 QGP 强子化边界处受到介质修正
  - **预测：** ΔR_K_med 敏感于强子化温度 T_chem 和重子化学势 μ_B
  - **可检验：** ΔR_K_med 应与 T_chem 或 μ_B 标度，而非与 ρ_B × N_scat

- **M3: 介质中奇异增强修正**（γ_s 在介质中 ≠ 真空）
  - 介质中奇异夸克产生增强（γ_s^medium > γ_s^vacuum≈0.217）
  - 但 K+ 和 K0 都含一个 s 夸克 → γ_s 变化对 R_K 无净效应（一级）
  - 二级效应：γ_s 变化改变 K*/φ 馈入比例 → 间接影响 R_K
  - **预测：** ΔR_K_med 应与 γ_s 增强因子弱相关
  - **可检验：** 比较 R_K 异常与 φ/K 比值异常（后者独立测量 γ_s 增强）

- **M4: K*/φ 介质修正的次级效应**
  - K*→Kπ 和 φ→KK̄ 在介质中的修正
  - K*+ 和 K*0 的介质宽度/质量差异 → 馈入不对称性
  - **预测：** ΔR_K_med 依赖于共振态的介质修正（T 和 ρ_B 依赖）
  - **可检验：** 比较 R_K 与 K*/K、φ/K 比值的关联

**产出：** 每种机制对 ΔR_K_med(√s_NN, centrality) 的定量预测 vs 数据，排除不可能机制。

### Phase 3: 合成 — R_K 作为强子介质探针

**目标：** 若 M1（KNY 耦合）被确认为主导机制 → R_K 成为 KNΛ/KNΣ 耦合常数介质值的间接探针。
若 M2（夸克重组）主导 → R_K 成为强子化边界条件的约束。
若 M1+M2 混合 → 设计可区分两者的实验（如 pT 依赖的差分 R_K）。

**产出：** 无论哪种情况，R_K 被重新定位为介质物理探针（而非对称性破缺信号）——这是 v3 的核心重新框架化。

## 关键风险

1. 残差太小（0.06-0.13）且系统误差可能相当 → 无法区分候选机制 → 结论仅限于"残差存在但不显著"
2. M1-M4 在现有数据精度下简并 → 无法唯一确定主导机制
3. NA61/SHINE 系统误差（尤其是 K0_S 重建效率）可能贡献与残差相当的偏差
4. 传输模型合作是实现 M1 定量检验的前提——不可达（需外部合作）
