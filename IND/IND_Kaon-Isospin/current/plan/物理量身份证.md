# 物理量身份证 — Kaon-Isospin v2

> 版本：v2 | 更新：2026-05-30

## ρ_ud ≡ P(u)/P(d)

**定义：** 弦碎裂中从QCD真空产生u夸克-反夸克对相对于d夸克-反夸克对的概率权重比。

**操作型定义：** 在e+e-→轻味(uds)强子事例中，扣除b/c衰变馈入和共振衰变馈入后，K±和K0产额比的一级近似等于ρ_ud：
```
ρ_ud ≈ (K+ + K-)/(2 K0_S) × f_correction
```
其中f_correction考虑φ→KK̄分支比差异、K*馈入的微小同位旋破缺等。

## v2目标值

全能量区间（3-209 GeV）的e+e-直接测量值，误差<±0.05 per point。

## 标度律参数

ρ_ud(s) = 1 + A × (s/1 GeV²)^(-α)
v1初步值：α = 0.6 ± 0.2, A ≈ 2.0-3.0

## 辅助观测量

- **s/u产生比 γ_s = P(s)/P(u)：** 独立检验弦张力κ的能量依赖性
- **K*/K比值：** 检验介质对共振态馈入的影响
- **双比值 R_double：** [(K+/π+)/(K-/π-)] / [(K0/π+)/(anti-K0/π-)]，减少传输模型依赖
