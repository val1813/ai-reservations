## v3 核心物理问题

### 重离子中 R_K 的介质残差

**v2 确立的真空基线：** e+e- + e_q² 稀释 → P(u)/P(d)=1 真空中普适。K±/K0_S(√s) 的全部能量依赖性来自已知 QED。

**v3 核心问题：** 扣除真空基线后，重离子碰撞中 R_K>1 的残差 ΔR_K_med ≡ R_K_obs - R_K_baseline 是否真实？若真实，来自什么介质效应？

### 修正真空基线的构建

**pp 碰撞基线**（最小介质效应参考）：
- 初态同位旋效应：质子 = uud → 2u+1d → 领头 u→K+ 增强
- ALICE pp 7 TeV: R_K≈1.03±0.04
- STAR pp 200 GeV: R_K≈1.02±0.05
- 合并 pp 基线：R_K^pp ≈ 1.025±0.020

**pA 碰撞基线**（冷核效应）：
- NA61/SHINE p+Pb: 初态 N/Z 修正 + Cronin 效应 + 冷核介质修正
- 若仅有初态同位旋而无热介质效应：R_K^pA ≈ R_K^pp × (N/Z 修正) ≈ 1.02-1.03

**AA 碰撞基线**（需扣除初态+领头粒子）：
- 对 NA61/SHINE Ar+Sc (√s_NN≈5-17 GeV)：
  - 初态 p/n 修正（Ar: N/Z=22/18=1.22, 但参与者区域不同）
  - 领头粒子效应（~1.02-1.03，与 pp 类似但受径向流修正）
  - 合理基线：R_K^baseline(Ar+Sc) ≈ 1.05-1.12
- 对 RHIC/LHC 能量：基线应更接近 1.0（领头粒子在高多重数下稀释）

### 候选介质机制

#### M1: KNY 耦合不对称性的介质放大（v1 遗产，核心候选）

**物理：** g_KNΛ/g_KNΣ≈3.6-5.4（真空 SU(3) 手征值）。
在介质中每次 K+N → K+N 散射：
- K+ 通过 Λ 道：K+ + n → K+ + n (弹性)，K+ + N → π + Λ (吸收)
- K0 通过 Σ 道：K0 + p → K0 + p (弹性)，K0 + N → π + Σ (吸收)
- 耦合不对称 → K+ 和 K0 的散射/存活概率不同
- 多散射累积（N_scat≈4-8 次 at SPS）→ 净 R_K 偏移

**可检验预测：**
1. ΔR_K_med ∝ ρ_B × ⟨N_scat⟩（重子密度 × 散射次数）
2. 中心碰撞 > 边缘碰撞（ρ_B 更大）
3. 低 √s_NN > 高 √s_NN（μ_B 更大 → ρ_B 更大）
4. 低 pT 区 > 高 pT 区（低 pT K 介子经历更多散射）
5. 应与 K*/K 比值关联（K* 再生反应用相同耦合常数）

#### M2: 夸克重组（Giacosa & Rohrmoser, EPJC 2025）

**物理：** QGP 强子化边界处，u/d 夸克通过重组形成 K 介子。重组概率受介质中 u/d 夸克的有效质量和密度影响。

**可检验预测：**
1. ΔR_K_med 主要依赖于 T_chem 和 μ_B（而非 ρ_B × N_scat）
2. pp 和 AA 应有明显差异（QGP 形成阈值）
3. 对 π 介子同位旋比值应有次级效应（G&R 预测 p/n~1.2, Σ+/Σ-~1.4）

#### M3: γ_s 介质增强的次级效应

**物理：** 介质中奇异产生增强但 K+ 和 K0 都需要 s 夸克 → 一级无效应。
但 γ_s 增强 → 更多 φ/K* → 共振馈入比例变化 → 间接影响 R_K。

**可检验预测：**
1. ΔR_K_med 应与 φ/K 比值弱相关
2. 效应量级 ≤ 3-5%（馈入比例的变动 × 分支比不对称性）

#### M4: K*/φ 介质修正

**物理：** K*→Kπ 和 φ→KK̄ 在介质中的宽度/分支比修正。
K*+ 和 K*0 的介质宽度可能不同（耦合常数不同 → 与 M1 共享物理基础）。

**可检验预测：**
1. ΔR_K_med 与 K*/K 比值变化关联（K* 再生→K 影响 R_K）
2. 效应集中在低 pT（K* 衰变产物 pT 较低）
