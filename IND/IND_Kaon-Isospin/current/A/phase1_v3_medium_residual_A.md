## §2 pp基线的构建

### 2.1 pp参考R_K值

| 实验 | √s (GeV) | R_K (pp) | 来源 |
|------|---------|----------|------|
| ALICE pp 7 TeV | 7000 | 1.03 ± 0.04 | 任务书约定值 |
| STAR pp 200 GeV | 200 | ≈1.02 ± 0.06 | K0S dN/dy=0.128±0.010, K± dN/dy来自STAR systematic measurements (PRC 79, 034909) |
| ISO-BREAK 25评估 | 全部 | 与1相容 | "p+p data may be consistent with obeying isospin symmetry" |

**合并pp基线：R_K(pp) = 1.025 ± 0.020**（采用任务书给定值，囊括ALICE和STAR的pp数据）

### 2.2 pp基线的物理含义

pp碰撞中：
- 无显著热介质效应（末态粒子密度低，强子相寿命短）
- 初态同位旋效应：每个碰撞核子对提供2u+1d价夸克→轻度的u夸克优势
- 领头粒子效应：u夸克→K+增强，但随着√s升高被高多重数稀释
- ALICE和STAR的pp数据与R_K≈1一致→领头效应在pp中已接近被稀释

**关键认识：R_K(pp) ≈ 1.025不是"真空K+/K0比值"，而是pp碰撞中初态同位旋+残余领头效应的净效果。**

### 2.3 pA基线（冷核效应检验）

NA61/SHINE p+Pb数据检索结果：**p+Pb碰撞的K+/K0_S比值尚未公开发表**。NA61/SHINE的p+Pb程序主要关注Kaon/pion ratio和onset of deconfinement，但K0_S到K±的交叉比较尚未完成。

**结论：冷核效应贡献目前无法从数据约束。将其作为系统误差源纳入基线不确定度。**

## §3 AA基线构建

### 3.1 基线模型

对每个AA碰撞系统，构建无介质效应的R_K预期值：

```
R_K_baseline(√s_NN, N/Z) = R_K(pp) × f_iso(N/Z) × f_lead(√s_NN) × f_cold(√s_NN)
```

其中：
- R_K(pp) = 1.025 ± 0.020：pp参考基线
- f_iso(N/Z)：基于参与者N/Z比例的初态同位旋修正
- f_lead(√s_NN)：领头粒子效应随√s_NN的稀释因子
- f_cold(√s_NN)：冷核效应（暂设为1.00，因pA数据不可用）

### 3.2 参与者N/Z比例

| 碰撞系统 | 核子N/Z | 参与者N/Z（估计） | 注释 |
|---------|---------|------------------|------|
| Ar+KCl | Ar:22/18=1.22, K:20/17=1.18 | 1.20 | Ar的N≈Z，KCl接近 |
| Ar+Sc | Ar:22/18=1.22, Sc:25/21=1.19 | 1.21 | 最接近N=Z的AA系统 |
| Au+Au | 118/79=1.494 | 1.49 | 富中子 |
| Pb+Pb | 126/82=1.537 | 1.54 | 最富中子 |
| Pb+Au | 混合 | 1.52 | |

### 3.3 两种基线的参数化

**保守基线（最小修正 = 最大残差）：**

假设初态同位旋和领头粒子效应都极小：
- f_iso_cons = 1.01 ± 0.01（与N/Z无关的微小修正）
- f_lead_cons = 1.005 ± 0.005（与√s无关的微小修正）
- f_cold_cons = 1.00

→ R_K_baseline_cons = 1.025 × 1.01 × 1.005 = **1.030 ± 0.020**（常数，不依赖于√s或N/Z）

**激进基线（最大修正 = 最小残差，但仍在v2合成框架内）：**

假设显著的初态同位旋效应和领头粒子效应：
- f_iso_agg(N/Z) = 1 + α × (N/Z - 1)，其中α = 0.06 ± 0.02
  - 物理动机：中子过剩→更多d夸克→K0_S相对增强→R_K降低
  - 但质子束的u夸克过剩效应可能反向→净效应依赖于Npart
  - 取α>0对应f_iso>1（与v1/v2方向一致：初态u夸克优势增强R_K）
- f_lead_agg(√s) = 1 + 0.07 × exp[-(√s - 2.6) / 8]
  - 物理动机：低√s时领头粒子效应强（高r值），高√s时被稀释
  - 在√s=2.6时贡献+0.07，在√s=91时贡献≈0
- f_cold_agg(√s) = 1.00 ± 0.02（pA数据缺失，将冷核效应归入系统误差）

→ R_K_baseline_agg(√s, N/Z) = 1.025 × f_iso_agg × f_lead_agg

**σ_ΔR = sqrt(σ_obs² + σ_baseline²)，Nσ = ΔR / σ_ΔR**

### 4.2 关键发现

#### (a) 保守基线下的残差

- **14/15个非LHC数据点显示ΔR_K_med > 0**（即所有SPS和RHIC能量）
- 峰值出现在62.4 GeV（ΔR=+0.247）和2.6 GeV（ΔR=+0.218），但这两个点也是误差最大的
- NA61/SHINE 11.9 GeV：ΔR=+0.154±0.065，**2.4σ**（这是最佳测量）
- NA61/SHINE 8.8 GeV：ΔR=+0.085±0.047，1.8σ
- LHC两点（2760和5020）ΔR为负（与零相容）

#### (b) 激进基线下的残差

- **激进基线将SPS区域的残差削减了约30-50%**
- NA61/SHINE 11.9 GeV：ΔR从+0.154降至+0.125，显著性从2.4σ降至**1.9σ**
- NA61/SHINE 8.8 GeV：ΔR从+0.085降至+0.043，显著性从1.8σ降至0.9σ
- 低能HADES点：ΔR从+0.22降至+0.14，显著性从1.4σ降至0.9σ
- STAR 62.4 GeV仍然是最大残差（+0.221），但这点本身可疑

#### (c) 残差的能量依赖性

```
保守基线 ΔR_K_med vs √s_NN:
√s    2.6    7.6-8.8  11.5-11.9  17.3-19.6  27-39  62.4  200  2760-5020
ΔR   +0.22  +0.09~+0.15  +0.14~+0.15  +0.13~+0.18  +0.11~+0.13  +0.25  +0.13  -0.04~-0.03
```

**能量演化模式：**
1. 从2.6到~8 GeV：残差似乎上升（HADES→NA49/STAR）
2. SPS平台（~8-17 GeV）：残差约+0.08到+0.18，变化平缓
3. RHIC平台（~20-200 GeV）：残差约+0.11到+0.25，62.4 GeV异常高
4. **LHC（≥2.76 TeV）：ΔR转变为负或与零相容** ← 这是最清晰的信号之一

激进基线下的模式类似，但整体下移约0.02-0.05。

### 4.3 全局显著性分析

**保守基线下的加权平均残差（排除LHC两点）：**

13个非LHC数据点：Σ(w_i × ΔR_i) / Σ(w_i)，权重w_i = 1/σ_ΔR_i²

```
加权平均: ΔR_K_med(保守) ≈ +0.146 ± 0.022 (stat)
全局显著性: ~6.6σ
```

但此数值包含：
- 数据点间相关性（K0_S效率修正使用相同方法的部分实验→协方差非零）
- STAR 62.4 GeV的可疑高值拉高平均
- 未对"look-elsewhere effect"做修正（我们已经知道R_K>1所以这不是盲分析）

**排除STAR 62.4 GeV后的12点加权平均：**
```
加权平均: ΔR_K_med(保守) ≈ +0.140 ± 0.022 (stat)
全局显著性: ~6.3σ
```

**激进基线下的加权平均（排除LHC，排除STAR 62.4）：**
```
加权平均: ΔR_K_med(激进) ≈ +0.093 ± 0.022
全局显著性: ~4.2σ
```

### 4.4 显著性层级

| 基线 | 全样本 | 排除LHC | 排除62.4&LHC | 仅NA61 11.9 |
|------|--------|---------|-------------|-------------|
| 保守 | ~5.9σ | ~6.6σ | ~6.3σ | 2.4σ |
| 激进 | ~4.0σ | ~4.6σ | ~4.2σ | 1.9σ |

**解读：保守基线下残差全局显著性约6σ。但这不是"发现"——保守基线故意最小化已知效应，因此残差包括：**
1. 真实的介质效应（我们寻找的信号）
2. 初态同位旋效应（我们故意未充分修正的部分）
3. 领头粒子效应（同上）
4. 冷核效应（同上）
5. K*/φ馈入在AA和pp中的差异
6. K0_S效率修正的系统偏差

激进基线下残差约4σ。更贴近真实，但仍有相当部分来自未建模的系统效应。

### 5.3 未解决的关键问题

**Q1: 为什么LHC的R_K=1而RHIC/SPS的R_K>1？**
- 三种可能：
  (a) LHC的介质产生机制与低能不同（径向流、部分子相寿命等）→ 介质效应在高能消失
  (b) LHC的领头粒子效应完全被稀释→R_K→1是真空基线本身的极限
  (c) LHC的系统误差被低估→真实R_K可能略>1但被10%误差掩盖

- 若(a)成立：介质效应在~100 GeV量级关闭→支持相变/临界点解释
- 若(b)成立：SPS的R_K>1完全来自领头粒子效应→无介质信号
- 若(c)成立：需要更好的LHC K0_S测量

**Q2: STAR 62.4 GeV的R_K=1.277是真实信号还是统计/系统波动？**
- 若是真实信号：指示在~60 GeV附近可能存在额外产生机制（e.g., 临界点附近的关联长度发散）
- 若是波动：排除后数据呈单调下降趋势→削弱介质效应的证据

**Q3: ΔR_K_med对中心度的依赖如何？**
- 目前大部分数据只有单个中心度bin
- 若介质效应存在，应随中心度（Npart）增加而增强
- ALICE有高统计量的多中心度K0_S数据→可提取R_K(centrality)

## §6 能量依赖性拟合与模型推测

### 6.1 ΔR_K_med对√s的拟合

**保守基线残差（排除LHC）：**

采用简单参数化：ΔR_K_med = A × exp(-(√s - 2.6)/τ) + C

对13个非LHC数据点（含62.4 GeV可疑点）：
```
A = 0.145 ± 0.035
τ = 18.4 ± 12.6 GeV  （指数衰减尺度）
C = 0.103 ± 0.025     （高能渐进值 — 但LHC数据暗示C应→0或为负）
χ²/ndf ≈ 8.2/10
```

**排除62.4 GeV的拟合（12点）：**
```
A = 0.110 ± 0.028
τ = 12.8 ± 8.5 GeV
C = 0.101 ± 0.022
χ²/ndf ≈ 5.6/9
```

**解读：**
- τ ≈ 10-20 GeV表明残差在SPS-RHIC过渡区衰减，与领头粒子效应的时间-能量标度（~1/⟨N_ch⟩）粗略一致
- 但LHC的负残差与C≈0.1的预测矛盾→τ必须更小，或拟合须包含高能截止
- 需要更好的能量依赖模型

### 6.2 与v2框架的一致性检验

v2合成主张：R_K_baseline(Ar+Sc, 11.9 GeV) = 1.05-1.12 → ΔR_K_med(NA61) ≈ 0.06-0.13。

我们的激进基线给出R_K_baseline=1.059, ΔR=+0.125±0.066 → 与v2的上限一致。

若v2"激进基线"取更极端值（R_K_baseline=1.12），则ΔR=1.184-1.12=0.064±0.061→**1.0σ**，残差在统计上不显著。这意味着在最激进的修正假设下，介质信号可以完全被解释掉。

### 6.3 介质效应的物理图像（若残差真实）

若ΔR_K_med > 0真实且来自热介质：
1. **手征对称性部分恢复**：u和d夸克的有效质量在介质中不同→碎裂函数修正
2. **化学势效应**：净重子密度→(μ_B > 0) → u和d夸克化学势差异→K+/K0产额不对称
3. **径向流+再生散射**：K+和K0的强子截面不同（K+N有束缚态，K0N截面不同）→微分流和再生效应
4. **K*再生**：K*(892)衰变→Kπ，介质中K*再生可改变K+/K0表观比值

能量依赖性为介质解释提供约束：
- 若来自相变/临界点：预期在特征能量处出现峰结构
- 若来自μ_B效应：预期随√s单调递减（μ_B随√s降低）
- 若来自径向流+散射：预期在高中心度增强（Phase 2待查）
- 若不在LHC出现：排除纯温度驱动的解释

## §8 核心结论

### 8.1 数值结论

**表5: 核心结果汇总**

| 指标 | 保守基线 | 激进基线 |
|------|---------|---------|
| NA61/SHINE 11.9 GeV ΔR | +0.154 ± 0.065 (2.4σ) | +0.125 ± 0.066 (1.9σ) |
| 加权平均ΔR（非LHC，排除62.4） | +0.140 ± 0.022 (~6.3σ) | +0.093 ± 0.022 (~4.2σ) |
| LHC R_K | 1.0（与无介质效应一致） | 1.0（与无介质效应一致） |
| STAR 62.4 GeV | 可疑（R_K=1.277，最大残差） | 可疑（同上） |

### 8.2 物理解读

1. **R_K > 1在SPS/RHIC能量是稳健的实验事实** — NA61 NA49 STAR CERES多个实验一致
2. **保守基线下残差约+0.14，全局~6σ** — 但这包括未建模的系统效应
3. **激进基线下残差约+0.09，全局~4σ** — 更接近真实物理信号，但仍包含模型不确定
4. **环境转变：LHC的R_K≈1** — 介质效应（若存在）在TeV尺度消失或领头粒子效应完全稀释
5. **残差的最保守解读：** ΔR_K_med的可能范围是[0, +0.15]，中心值约+0.06-0.13，取决于基线选择
6. **不能排除"全残差来自同位旋+领头+冷核效应"**（激进基线+额外系统效应→ΔR≈0）

### 8.3 对v3北极星的约束

若介质残差ΔR_K_med的真实值在0.06-0.13（对应NA61/SHINE 11.9 GeV）：
- 残差量级远小于原始R_K-1=0.184的表观异常
- 有效的"介质信号"仅为表观信号的30-70%
- v3的介质机制需解释的量级仅为~0.06-0.13，而非~0.18

**这是v3 Phase 1的核心定量产出：将问题从"R_K超过QCD预测18%"重新标定为"R_K超过真空基线6-15%"**
