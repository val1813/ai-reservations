## 四、核心矛盾：谱偏差方向（K1.5）

```
A博士（§3.3）：Dirac QSL的1/r^4 → Fourier域1/q软奇点 → 低q主导 → 窄频带
                谱偏差（低频优先）→ 可能偏向无能隙QSL
                反证：gapped态的指数衰减 → 宽频带 → 高频分量更多

B博士（§5.2）：NTK大特征值 = 短程指数衰减模 = gapped态特征 → 优先学习
                NTK小特征值 = 长程代数衰减模 = gapless态特征 → 延后学习
                在固定训练下 → 无能隙态永远"落后" → 偏向有能隙

PI裁决：这是一个符号矛盾，理论无法裁决。
        两个论证都有道理但使用了不同的"频率"概念：
        - A用物理傅里叶频率（q空间），1/q奇点确为低q
        - B用NTK特征值频率（函数空间），短程指数模确为大特征值
        这两个"频率"概念之间的关系不是平凡的——需要数值测试裁决。
```
