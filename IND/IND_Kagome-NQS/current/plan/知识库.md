# 知识库 — Kagome-NQS v1

> 初始化日期：2026-05-30

## 核心概念

### Kagome海森堡反铁磁体
- 晶格：Kagome晶格（角共享三角形网络）
- 哈密顿量：H = J Σ_{⟨i,j⟩} S_i·S_j，S=1/2，J>0（反铁磁）
- 几何受挫：三角形结构阻止Néel序
- 30年悬案：基态是无能隙Dirac QSL还是有能隙Z2/手性QSL？

### Transformer神经网络量子态（arXiv:2602.02665）
- 空间注意力机制：捕获2D量子关联
- 自回归结构：O(N)标度，优势在于2D系统
- 已在有序磁体三角晶格上验证
- 未在无能隙QSL系统上验证

### VMC+Gutzwiller方法
- 变分蒙特卡洛：构造试探波函数
- Gutzwiller投影：从费米子平均场态投影到物理自旋态
- 系统性偏向：VMC能量最小化偏向无能隙态

### 圆柱DMRG方法
- 密度矩阵重整化群在圆柱几何上
- 有限宽度圆柱→外推2D
- 系统性偏向：圆柱几何可让无能隙态"看起来有能隙"（Ferrari et al. 2024）

## Phase 1 产出（2026-05-30）

### A博士结论
- **有条件通过**：可行性取决于λ≫L + ε_NQS<0.005J + 谱偏差可控
- **意外发现**：谱偏差可能偏向无能隙（与初始直觉相反，1/q奇点低q主导）
- **新增瓶颈**：NK1(谱偏差方向不确定), NK2(λ学习动力学), NK3(人工界面纠缠污染)
- **产物**：4个通过判据(P1-P4) + 4个失败判据(F1-F4) + 3个假阳性源分析

### B博士结论
- **不应使用**：Transformer NQS系统性偏向有能隙态，不可修复
- **4维攻击**：拓扑简并梯度盲区(§2) + 注意力-anyonic代数失配(§3) + J1-J2→Kagome零信息迁移(§4) + 三层锁定偏差(§5)
- **失败概率预测**：~60%纠缠熵面积律, ~25%关联截断, ~10%能量平台, ~5%通过

### A/B独立确认的一致风险（高置信度）
1. 自回归人工边界破坏纠缠结构
2. J1-J2验证对Kagome不提供充分保证
3. 注意力机制缺少QSL拓扑结构的天然表示能力

### A/B直接矛盾
- K1.5：谱偏差方向 — A说偏无能隙（物理q空间分析）vs B说偏有能隙（NTK特征值分析）
