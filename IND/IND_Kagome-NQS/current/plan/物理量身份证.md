# 物理量身份证 — Kagome-NQS v1

> 所有可观测量的统一定义和数学表征

## 核心物理量

### Δ_s(L) — 有限尺寸自旋能隙
- 定义：Δ_s(L) = E_1(L) - E_0(L)，其中E_0为基态能量，E_1为第一激发态（S=1 triplet）
- 标度假设：无能隙→Δ_s(L) ∝ 1/L；有能隙→Δ_s(L) → Δ_s(∞) > 0
- 来源：Transformer NQS变分能量+excited state方法

### ⟨S(0)·S(r)⟩ — 自旋-自旋关联函数
- 定义：等时自旋关联，空间距离r
- 用途：区分QSL类型（Dirac QSL→代数衰减~1/r^4；gapped→指数衰减）
- 来源：Transformer NQS采样⟨ψ|S(0)·S(r)|ψ⟩/⟨ψ|ψ⟩

### S_vN(L_A) — von Neumann纠缠熵
- 定义：S_vN = -Tr(ρ_A ln ρ_A)，ρ_A为子区域A的约化密度矩阵
- 面积律vs对数修正：无能隙QSL→S~aL-γ+...；有能隙→S~aL+...
- 来源：Transformer自回归结构允许高效纠缠熵计算

### S(q) — 自旋结构因子
- 定义：S(q) = (1/N) Σ_{i,j} e^{iq·(r_i-r_j)} ⟨S_i·S_j⟩
- 用途：Dirac QSL→pinch-point奇点；gapped QSL→光滑分布
- 来源：关联函数Fourier变换
