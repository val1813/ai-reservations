### §3 推导正文

#### Step 1：共存相对称性分析

KD+CAF共存相的对称性破缺：
- SU(2)_spin → U(1)_z（CAF序，Néel矢量在xy平面）
- U(1)_valley → Z₃（KD序）

Goldstone定理计数：
- CAF破缺SU(2)→U(1)：2个破缺生成元 → 但Zeeman场显式破缺SU(2)只保留U(1)_z
- CAF的Néel矢量自发破缺U(1)_z → 1个Goldstone模（面内旋转）
- KD破缺离散对称性 → 无Goldstone模（赝Goldstone有能隙，K1.1）

依据：Goldstone定理标准应用。
反驳检验：U(1)_z是否真的被自发破缺？是——Néel矢量在xy平面选择了特定方向。

#### Step 2：CAF基态经典构型

双子格自旋哈密顿量：
H = J Σ S_i·S_j - gμ_B B Σ S_i^z

CAF基态（canting角θ）：
- S_A = S(sinθ, 0, cosθ)
- S_B = S(-sinθ, 0, cosθ)

平衡条件：cosθ = E_Z/(2zJS)，其中z=2（蜂窝格配位数），E_Z = gμ_BB

#### Step 3：自旋波能隙——Holstein-Primakoff展开

标准反铁磁自旋波理论（Anderson 1952）给出面内模色散：

ω_k^(in) = √(A_k² - B_k²)

其中：
- A_k = zJS(1 - cos²θ·γ_k) + E_Z cosθ
- B_k = zJS sin²θ·γ_k

在k→0（γ_k→1）：

A_0 - B_0 = E_Z²/(2zJS)
A_0 + B_0 = 2zJS sin²θ + E_Z²/(2zJS)

**面内自旋波能隙：**

Δ_sw = ω_0^(in) = √[(A_0+B_0)(A_0-B_0)]

在弱Zeeman极限（E_Z << 2zJS，即θ≈π/2）：

**Δ_sw = E_Z = gμ_BB**

这是精确结果——面内自旋波能隙等于Zeeman能，与交换能J无关。

依据：Kittel 1951, Anderson 1952的反铁磁自旋波标准结果。
反驳检验：结果是否依赖J？不依赖——在弱Zeeman极限下Δ_sw = E_Z是精确的。这使结论对KD-CAF耦合的J重整化完全鲁棒。

#### Step 4：KD-CAF序参量耦合

最低阶耦合项（Landau理论）：L_coupling = λ|Φ_KD|²|N|²

这是双线性耦合，修改交换能标J→J_eff = J + λ|Φ_KD|²/S²，但不改变能隙的定性结论。

关键：Δ_sw = E_Z不依赖J → 对λ的值完全不敏感。

线性耦合（Φ_KD·N_α）需要自旋-轨道耦合连接谷和自旋空间。石墨烯SOC极弱（~μeV），可忽略。

#### Step 5：数值估算

| 参数 | 数值 |
|------|------|
| g | 2 |
| μ_B | 58 μeV/T |
| B | 10 T |
| E_Z = gμ_BB | **1160 μeV = 1.16 meV** |
| k_BT (20mK) | 1.7 μeV |
| k_BT (4K) | 340 μeV |

**能隙比较：**

| 温度 | Δ_sw/k_BT | n_B | 热冻结？ |
|------|-----------|-----|---------|
| 20 mK | 680 | e^{-680} ≈ 0 | ✓✓✓ |
| 4 K | 3.4 | 0.03 | ✓ |
| 13 K | 1.0 | 0.58 | ✗ |

**特征温度：** T*_sw = E_Z/k_B = 1.16 meV / 86 μeV/K ≈ 13.5 K

#### Step 6：裁决

**在实验温度T=20mK下：**
- KD赝Goldstone能隙：m_gap ≈ 40-400 μeV → m_gap/k_BT ≈ 24-235 → 热冻结 ✓
- CAF面内自旋波能隙：Δ_sw = 1160 μeV → Δ_sw/k_BT ≈ 680 → 热冻结 ✓✓✓
- CAF面外自旋波：~20-80 meV → 完全冻结 ✓✓✓

**结论：共存相中所有集体模在T=20mK下均被热冻结。κ≈0的解释不依赖于基态是纯KD还是KD+CAF共存——两种情形下热输运均为零。**

**K1.3卡点解决：** B博士Attack 3的核心论点（共存相中CAF自旋波无能隙→κ≠0）被Zeeman能隙机制完全回应。Δ_sw = E_Z是精确结果，不依赖模型参数。

#### Step 7：实验预测

1. **温度依赖：** 两个特征温度
   - T*_KD = m_gap/k_B ≈ 0.5-5 K（KD谷子激活）
   - T*_sw = E_Z/k_B ≈ 13.5 K（CAF自旋波激活）
   - 预测：κ(T)应有两步恢复——先在T*_KD处部分恢复（谷子），再在T*_sw处完全恢复（自旋波）

2. **磁场依赖：**
   - Δ_sw = gμ_BB ∝ B（线性）
   - m_gap ∝ B^{3/2}
   - 预测：降低B时，KD能隙先消失（B^{3/2}下降更快），自旋波能隙后消失

3. **区分纯KD vs 共存相：**
   - 纯KD：κ(T)只有一个激活温度T*_KD
   - 共存相：κ(T)有两个激活温度（T*_KD和T*_sw）
   - 判决：精细温度扫描0.1-20K，寻找双激活行为
