# Phase 1 跨域突击推导 — B博士攻击链

> **北极星攻击目标：** "KD赝Goldstone=κ≈0解决方案"论证链
> **突击策略：** 四路并行攻击，寻找最可能被忽视的替代解释或逻辑漏洞
> **日期：** 2026-05-30

---

## 本Phase推进了什么 + 最关键的跨域连接 + 预测 vs 实际 + 卡在哪里

**推进了什么：** 完成对KD+赝Goldstone论证链的四维攻击，识别出两个高严重性漏洞（共存序、无序局域化）和两个中等严重性脆弱点（逻辑循环、新颖性压缩）。

**最关键的跨域连接：** Das-Kaul-Murthy (PRL 2022) 证明KD+CAF共存相在放松超短程假设后**泛型出现** —— 这是凝聚态多体理论对粒子物理类比论证的致命反例。即使KD赝Goldstone有能隙，共存CAF的自旋波Goldstone模仍可携带热量。κ≈0不能仅靠KD赝Goldstone解释。

**预测 vs 实际：** 预测四个方向均有可攻击面。实际上，Attack 3（共存序）和Attack 1（无序局域化）的严重程度超出初始预期——前者被2022年PRL严格证明，后者被2024年两篇Nature Physics实验论文的作者明确标记为待解决方向。Attack 2和4为中等，不致命但压缩新颖性空间。

**卡在哪里：** 不卡。突击完成。阻塞因子在A轨道（GOR关系量化推导的数值精度），不在B轨道。B轨道的结论可独立推进：如果Attack 3不能合理解答，整个project的"排他性解释"框架需要修改为"部分解释+共存序不可忽略"。

## §1 结论预测

**综合判定：KD+赝Goldstone=κ≈0解决方案面临两个高位阻塞和一个结构性问题。**

1. **Attack 3（共存序）— 严重性 HIGH：** Das-Kaul-Murthy (2022) 和 Stefanidis-Villadiego (2023) 的严格多体计算表明，在实验相关的相互作用参数范围内，KD与CAF**共存**而非互相排斥。若共存成立，KD赝Goldstone有能隙≠所有集体模均有能隙——CAF自旋波Goldstone仍可携带热量。仅靠"KD赝Goldstone有能隙"不能解释κ≈0，除非额外论证CAF自旋波也被某种机制压制。

2. **Attack 1（无序局域化）— 严重性 HIGH：** ν=0态载流子完全耗尽，体系处于量子霍尔绝缘区。若无序导致的Anderson局域化长度ξ_loc < 热输运探测长度，则任何体集体模（无论有能隙还是无能隙）都因载流子局域化而无法传导热量。κ≈0可能是"ν=0载流子耗尽+无序局域化"的通用特征，而非任何特定相的"证据"。2024年两篇Nature Physics实验论文的作者已将此标记为待解决的开放问题。

3. **Attack 2（逻辑循环）— 严重性 MEDIUM：** 赝Goldstone能隙计算依赖的有效晶格破缺强度在强磁场(B~10T)下的值，尚无独立于热输运的实验测定。若LL mixing压制三角翘曲效应1-2个数量级，m_gap计算退化为"拟合"而非"预测"。

4. **Attack 4（新颖性压缩）— 严重性 MEDIUM：** 目前无已发表论文用赝Goldstone+GOR关系解释石墨烯ν=0 κ≈0，概念层面新颖性保留。但赝Goldstone是凝聚态成熟概念（He-3、铜氧化物、铁基超导），2024 Nature Physics论文明确呼吁"进一步理论探索"——窗口正在收窄。

**结论：项目不自毁，但论证链需要从"排他性解释"降级为"部分解释+竞争机制不可排除"。**

## §2 攻击1：CAF+无序局域化的竞争解释

### 2.1 攻击命题

**核心主张：** κ≈0不是"特定相的证据"而是"ν=0态载流子完全耗尽的通用特征"——任何相(F/CAF/KD/FSP)在ν=0有足够无序时都会给出κ≈0，因为根本没有扩展态载流子来传导热量。

### 2.2 推导

#### Step 1：ν=0态的载流子状态

```
学科工具：量子霍尔物理、Landau能级填充
```

在垂直磁场B~10T下，石墨烯的n=0 Landau能级具有4重简并（2自旋×2谷）。ν=0意味着n=0 LL被精确半填充——2个子能级被占据，2个空置。在单粒子图像中，费米能级位于LL中心。

关键事实：
- 在LL中心附近，态密度中不存在单粒子能隙
- 体能隙来自多体交换相互作用——这是量子霍尔铁磁态的本质
- 但在有显著无序时，LL展宽导致费米能级处存在有限态密度——体系进入量子霍尔临界区或Anderson局域区

**依据：** 石墨烯ν=0态的量子霍尔临界电导率σ_xx ≈ 1.4 e²/h（在中等无序强度W ~ 0.3-2下测量），独立于B和W，表明在ν=0处LL中心存在扩展态。但在强无序(W > 2.5)或极低无序极限(W → 0)下，所有态均局域化。

**反驳检验：** 如果ν=0处存在扩展态（量子霍尔临界点），载流子并非"完全耗尽"。但这依赖于无序强度在"Goldilocks区域"——不太强也不太弱。实际样品的无序强度是否恰好落在此区域？需要实验表征。

#### Step 2：Anderson局域化对集体模热输运的压制

```
学科工具：Anderson局域化理论、无序系统中集体激发的输运
```

集体模（自旋波、谷子）携带热量的机制依赖其与载流子的耦合：集体模通过与剩余载流子的散射传递能量。如果所有载流子被局域化——即波函数在空间上指数衰减exp(-r/ξ_loc)——则集体模与载流子的耦合被切断。

关键量化问题：
- ν=0态的局域化长度ξ_loc是多少？
- 热输运探测的特征长度L_T是多少？

在石墨烯中，ξ_loc ~ λ × exp(πσ_sc/G_0)，其中λ为平均自由程，σ_sc为半经典电导率。在ν=0附近：
- λ ~ l_B ~ √(ħ/eB) ~ 8 nm (B=10T)
- σ_sc在ν=0处发散（LL中心）→ ξ_loc可远大于样品尺寸（~μm）在弱无序极限
- 但在强无序极限下(W > 2.5)，ξ_loc可降至nm级

**依据：** Lherbier et al., PRL 100, 036803 (2008); Ostrovsky et al., PRB 74, 235443 (2006)

**关键不确定性：** 实际石墨烯样品的无序强度对应的ξ_loc尚未被直接测量。这为双向论证留下了空间：
- 若ξ_loc >> L_sample，则体集体模可以输运热量 → κ≈0确实需要相特异解释
- 若ξ_loc < L_thermal_probe，则任何相的体集体模均无法输运热量 → κ≈0是通用特征

#### Step 3：为什么CAF相的无能隙自旋波预测有限κ——以及为什么这个预测可能在真实样品中失效

```
学科工具：有序无序竞争、QH铁磁体中的自旋波输运
```

Pientka et al. (2017) 预测CAF相的自旋波Goldstone模应携带有限热量。但这个预测做了两个关键假设：
1. 集体模可以通过与扩展态载流子的耦合有效输运能量
2. 无序对集体模的散射可以忽略

在真实样品中，两个假设都可能失效：
- 若载流子在ν=0被局域化，集体模失去了能量输运的"介质"
- 无序不仅局域化载流子，还通过随机势涨落散射集体模——自旋波在无序介质中的输运长度可能远短于纯系统

**依据：** 2024年两篇Nature Physics论文（A. Assouline et al., Nature Physics 20, 1927-1932, 2024; Kumar et al., Nature Physics 20, 1941-1947, 2024）在单层和双层石墨烯中均观察到**零**体热输运，与Pientka预测矛盾。作者明确将"无序效应"标记为待解决方向。

#### Step 4：竞争解释的完整表述

```
κ≈0 = 载流子局域化(Anderson) + 集体模输运通道关闭
```

而非：
```
κ≈0 = KD赝Goldstone有能隙 → KD被确认
```

关键区别：第一种解释不依赖ν=0的具体相——无论基态是F、CAF、KD还是FSP，只要载流子被充分局域化，κ≈0就会发生。第二种解释假设κ≈0是KD相的特异信号。

### 2.3 攻击评估

| 维度 | 评估 |
|------|------|
| 严重性 | **HIGH** — 如果κ≈0是通用特征而非相特异信号，则整个"通过热输运区分相"的逻辑基石动摇 |
| 可验证性 | 中 — 需要独立测量ξ_loc（如扫描隧道谱的态密度空间关联），实际操作困难 |
| 对项目影响 | 不致命但压缩解释力 — 项目需增加"无序局域化不可排除"的声明 |
| 与Attack 3的关系 | 互补 — 无序局域化解释κ≈0的所有相，共存序攻击KD排他性 |

## §3 攻击2：赝Goldstone能隙的逻辑循环

### 3.1 攻击命题

**核心主张：** 赝Goldstone能隙m_gap的计算依赖"有效晶格破缺强度"作为输入参数。如果此参数不能从独立于热输运的实验测定，m_gap计算退化为"调参拟合"而非"第一性原理预测"。

### 3.2 推导

#### Step 1：GOR类比中需要的外部参数

```
学科工具：手征微扰论类比、格点规范理论
```

类比QCD的GOR关系：
```
m_π² f_π² = (m_u + m_d) ⟨q̄q⟩
```

石墨烯KD的赝Goldstone谷子质量：
```
m_gap² f_KD² = (Γ_lattice) ⟨O_KD⟩
```

其中：
- f_KD：KD刚度（类比π介子衰变常数，可由HF理论估算）
- ⟨O_KD⟩：KD凝聚（类比手征凝聚，由多体基态决定）
- **Γ_lattice：晶格破缺强度**——这是核心自由参数

Γ_lattice从何而来？
1. 三角翘曲强度：γ_3/γ_0 ≈ 0.1（零场ARPES测量）
2. Umklapp散射振幅：U_G ~ γ_3 × (a/l_B)² × f(B)
3. 多体波函数在磁场下的重整化因子

#### Step 2：磁场对晶格破缺的压制效应

```
学科工具：Landau能级混合理论、磁场重整化群
```

三角翘曲γ_3在紧束缚模型中是B=0下的能带参数。在B~10T的强磁场下，电子波函数被压缩到Landau能级中：

**关键物理过程：**
- 三角翘曲在k空间的效应尺度为Δk ~ γ_3/(ħv_F) ~ 0.01 Å⁻¹
- 在B=10T下，LL波函数在k空间的展宽为Δk_LL ~ 1/l_B ~ 0.01 Å⁻¹
- 两者量级相当 → LL波函数**平均化**了三角翘曲效应

更严重的是，LL mixing（不同LL之间的虚拟跃迁）通过交换相互作用重整化了有效U(1)_v破缺。在强磁场下，LL间距ħω_c ~ 35 meV (B=10T)，而特征库仑能e²/(εl_B) ~ 70 meV → LL mixing参数κ_LL ~ e²/(εl_B)/ħω_c ~ 2 → **LL mixing不是小量**。

**依据：** 石墨烯中LL mixing的κ_LL ~ 2意味着微扰展开失败——需要非微扰处理。现有HF计算（Kharitonov 2012）虽然考虑了LL mixing对HF耦合常数的重整化，但未专门计算LL mixing对三角翘曲等效破缺强度的压制因子。

**量化估计：**
```
Γ_lattice^eff = Γ_lattice^bare × R(B)
R(B) ~ exp(-(l_B/a)² × f(κ_LL)) 或 R(B) ~ 1/(1 + c·κ_LL²)
```
在B=10T，l_B/a ≈ (8 nm)/(0.246 nm) ≈ 32 → 压制因子可能为O(10⁻¹)到O(10⁻²)。

如果Γ_lattice^eff比裸值小1-2个数量级，m_gap可能从~μeV量级（与实验温度可比）下降到~neV量级（远低于实验温度）。

#### Step 3：逻辑循环的诊断

```
学科工具：科学哲学——预测vs拟合的区分标准
```

一个计算是"预测"还是"拟合"的判定标准：
1. **所有输入参数是否可从独立实验（非被预测量）确定？**
2. **参数值是否有独特的、先于计算确定的数值？**

对于m_gap计算：
- Γ_lattice^bare（零场三角翘曲）✓ 可从ARPES独立确定
- R(B)（磁场压制因子）✗ 无可用的独立实验测定
- f_KD（KD刚度）✓ 可从HF理论独立计算（虽然模型依赖）
- ⟨O_KD⟩（KD凝聚）✓ 可从HF自洽解获得

**问题在R(B)：** 如果R(B)没有独立于热输运的实验测定，则：
- 若用R(B)去拟合κ≈0 → 得到m_gap > k_B T → 声称"解释了实验"
- 但实际上R(B)是**被调参**以产生m_gap > k_B T的——这是循环论证

#### Step 4：可能的独立约束

**可能性：** 
- STM谱的局域态密度展宽：可约束LL mixing对态密度的重整化
- 激子凝聚的激子能隙：在相近条件下（B~10T，hBN封装）已有激子能隙测量
- Shubnikov-de Haas振荡的温度阻尼：可约束有效质量和LL展宽

**问题：** 这些间接约束的精度是否足以将R(B)确定到因子2以内？如果R(B)的不确定度跨2个数量级，m_gap的不确定度跨1个数量级——涵盖从"m_gap < k_B T（KD被排除）"到"m_gap > k_B T（KD解释κ≈0）"的整个范围。

### 3.3 攻击评估

| 维度 | 评估 |
|------|------|
| 严重性 | **MEDIUM** — 不否定机制存在，但削弱"预测"声明的强度 |
| 可修复性 | 部分可修复——明确声明R(B)的不确定度范围，给出m_gap的上限和下限，而非单值"预测" |
| 对项目影响 | 可管理——转"精确预测"为"带误差棒的估计范围"即可化解 |

## §4 攻击3：KD相实验确认是否排他？

### 4.1 攻击命题

**核心主张：** Yazdani STM观测到的Kekulé键序不能排除CAF共存。已有严格多体计算表明KD+CAF共存相泛型存在。若共存成立，仅靠KD赝Goldstone有能隙不能解释κ≈0——必须同时压制CAF的自旋波Goldstone模。

### 4.2 推导

#### Step 1：Kharitonov相图的局限——为什么纯KD相可能不存在

```
学科工具：Hartree-Fock相图、对称性分析、超越超短程相互作用
```

Kharitonov (2012) 的HF相图基于一个关键简化：所有谷间和各内的HF耦合常数被设为相等（仅由超短程δ函数相互作用参数u_⊥决定）。在这个简化下，四个相(F/CAF/KD/FSP)占据互不相交的参数区域——它们是**互斥**的。

但这个简化在物理上不自然：
- 真实石墨烯中的库仑相互作用是长程的V(r)=e²/(εr)
- 在磁场中，LL波函数的有限展宽~l_B产生了一个自然截断
- 不同对称通道的HF耦合常数g_μ,H和g_μ,F（μ=0,x,y,z）通常**不相等**

**关键文献：Das, Kaul & Murthy, PRL 128, 106803 (2022)**
核心发现：放松g_μ,H = g_μ,F的超短程假设后，**CAF+BO(Kekulé键序)共存相泛型(generically)出现在纯CAF和纯KD之间的参数区域**。

```
相图演变（参数空间：g_z/g_⊥ vs g_xy/g_⊥）：
Kharitonov (2012):   F | CAF | KD | FSP  （四面边界分明）
Das et al. (2022):   F | CAF | CAF+KD | KD | FSP  （共存区插入）
```

**依据：** Das et al.使用两种互补方法验证——连续模型（6个HF耦合常数）和格点模型（每个磁通量子格点），两种方法均给出共存相。

**物理直觉：** 共存相之所以可能，是因为CAF（自旋通道的序）和KD（谷通道的序）涉及不同的对称性破缺方向——SU(2)_spin和U(1)_valley是不同的对称群。当HF耦合常数不相等时，两个序可以**同时凝聚**而不完全互相排斥。

#### Step 2：共存相的集体激发谱

```
学科工具：对称性自发破缺→Goldstone定理计数
```

在纯KD相中：
- 自发破缺：U(1)_v → Z_3
- Goldstone模计数：1（谷子/valleyron）
- 能隙来源：晶格显式破缺U(1)_v → Z_3 → 赝Goldstone，m_gap ≠ 0

在CAF+KD共存相中：
- 自发破缺：SU(2)_spin → U(1)_spin（CAF序）+ U(1)_v → Z_3（KD序）
- Goldstone模计数：1（自旋波/CAF）+ 1（谷子/KD）= **2个模**
- KD的谷子：被晶格破缺赋予能隙 → 赝Goldstone，m_gap ≠ 0
- CAF的自旋波：SU(2)→U(1)自发破缺的**真Goldstone** → **m_spinwave = 0**（在无Zeeman场极限）

**关键点：** 在共存相中，CAF自旋波在纯对称性自发破缺的意义上是**严格无能隙**的（忽略可忽略的Zeeman能E_Z ~ 0.1 μeV/T × 10T ~ 1 μeV，这在T~20mK下可能部分冻结，但在更高温度下不冻结）。

#### Step 3：共存相的实验证据

```
学科工具：STM vs 输运实验的表观矛盾→共存的自然解决方案
```

**表观矛盾：**
- 早期输运（热激活电导的温度依赖）→ 暗示CAF相（自旋能隙E_Z ~ 1 μeV与数据一致）
- Yazdani STM (2022) → 直接成像Kekulé键序 → 确认KD序参量 ≠ 0

**Das et al. (2022) 的解决方案：** 两者都对——共存相同时具有CAF磁性序和Kekulé键序。STM对键序敏感（实空间成像），输运对自旋激发敏感（热激活）。

**进一步支持：** Stefanidis & Villadiego (PRB 108, 235137, 2023) 在有有限范围相互作用+Zeeman+谷势的系统中发现了更丰富的共存相图，包括KD-AF（Kekulé-反铁磁）和E-KD-AF（纠缠-Kekulé-反铁磁）相，其中自旋和谷自由度**量子纠缠**。

#### Step 4：为什么这攻击了"KD赝Goldstone=κ≈0"论证

**项目声称的结构：**
```
KD相 → 赝Goldstone有能隙 → 无能隙集体模 → κ≈0 → KD被确认 ✓
```

**攻击后的结构：**
```
KD+CAF共存相 → KD赝Goldstone有能隙 ✓ + CAF自旋波无能隙 ✗ → 仍有无能隙集体模 → κ≈0未被解释
```

**需要额外论证（项目中缺失的）：**
1. 要么证明在实验条件下，共存相不出现（需要独立约束HF耦合常数）
2. 要么证明CAF的自旋波在共存相中也被某种机制赋予能隙
3. 要么证明CAF自旋波虽然在体中有无能隙，但被无序充分压制（回到Attack 1）

**选项(2)的可能机制：**
- 共存相中KD序参量与CAF序参量的耦合可能通过高阶相互作用混合自旋波和谷子
- 如果自旋-谷纠缠（Stefanidis-Villadiego 2023的E-KD-AF相），两个模可能杂交
- 但这导致杂交后的两个模中至少一个保持无能隙（Goldstone定理对联合破缺仍适用）——除非杂交产生了额外的显式破缺

**选项(3)与Attack 1的融合：** 如果无序局域化同时压制CAF自旋波和KD谷子的热输运，那么κ≈0的解释退回到无序解释——这意味着KD赝Goldstone不是κ≈0的必要条件。

### 4.3 攻击评估

| 维度 | 评估 |
|------|------|
| 严重性 | **HIGH** — 已有发表的严格多体计算证明共存相泛型存在。这是四个攻击中最硬的证据 |
| 反驳空间 | 有限 —— 需论证实验参数落在纯KD区而非共存区。但这需要对HF耦合常数的独立约束，目前实验尚未提供 |
| 对项目影响 | **需要修改核心论证** —— "排他性解释"降级为"部分解释"，需声明CAF共存不可排除 |
| 论文中的处理 | 可在Discussion中承认共存可能性，将项目的贡献重新定位为"量化KD模的赝Goldstone能隙"而非"证明κ≈0排他性地指向KD" |

## §5 攻击4：已知理论工作的覆盖度

### 5.1 攻击命题

**核心主张：** 需要查清是否已有工作用赝Goldstone机制解释过石墨烯ν=0 κ≈0。若已有，本项目的新颖性被压缩到"GOR定量类比"而非"赝Goldstone概念的应用"。

### 5.2 推导

#### Step 1：文献搜索

```
学科工具：文献检索 — arXiv, PRL, PRB, Nature系列
```

**搜索策略：**
1. "pseudo-Goldstone" + "graphene" + "ν=0" → 无直接命中
2. "valleyron" + "gap" + "thermal" + "graphene" → 零命中
3. "GOR relation" + "graphene" → 无命中（GOR用于QCD领域）
4. "pseudo-Goldstone" + "quantum Hall" + "graphene" → 零星提及，未系统展开

**关键发现：**
- Pientka et al. (2017) 讨论了ν=0态各相的集体模对热输运的贡献，但**未使用"赝Goldstone"概念**——他们似乎在连续极限下处理所有集体模（即假定U(1)_v精确成立），未考虑晶格破缺赋予的能隙
- 2024年两篇Nature Physics实验论文在结论中都明确写道"需要进一步的理论研究来解释观察到的κ≈0"→ 间接表明尚无被接受的解释

#### Step 2：赝Goldstone在凝聚态中的先例

```
学科工具：凝聚态物理学史 — 赝Goldstone概念的应用谱系
```

赝Goldstone作为概念在凝聚态中是**成熟且广泛应用的**：

| 体系 | 自发破缺 | 显式破缺 | 赝Goldstone模 | 时期 |
|------|---------|---------|-------------|------|
| He-3 A相 | SO(3)_spin × SO(3)_orbital | 偶极相互作用 | 自旋-轨道波 | 1970s |
| 铜氧化物超导体 | U(1)_charge | 层间Josephson耦合 | 相位模(Leggett模) | 1990s |
| 铁基超导体 | SU(2)_spin | 自旋-轨道耦合 | 自旋波能隙 | 2000s |
| 石墨烯KD | U(1)_valley | 三角翘曲+Umklapp | 谷子(valleyron) | 本项目 |

**关键区别：** 在上述所有体系中，"存在赝Goldstone模"这一事实在本项目之前就已被提出。本项目的新颖性不在于"发现赝Goldstone概念"而在于：
1. **定量类比GOR关系**：将QCD的m_π² ∝ m_q关系系统地翻译为m_gap² ∝ Γ_lattice
2. **定量裁决实验**：用推导出的m_gap与k_B T比较来裁决κ≈0的解释

#### Step 3：新颖性空间的精确定位

**新颖层级：**
```
Level 0: "赝Goldstone在凝聚态中存在" → 1960s已知 → 0新颖性
Level 1: "石墨烯KD有赝Goldstone" → 隐含在Kharitonov 2012分类和连续极限讨论中 → 低新颖性
Level 2: "本赝Goldstone能隙在ν=0态的大小足以解释κ≈0" → 未被系统论证过 → 中等新颖性
Level 3: "GOR关系的QCD→石墨烯定量类比给出m_gap的解析表达式" → 未被提出过 → 高新颖性
```

**压缩风险评估：**
- Level 1的声称会被审稿人质疑为"显然"（obvious to practitioners）——任何知道U(1)_v仅在连续极限成立的凝聚态物理学家都会认识到KD模是赝Goldstone
- Level 2的声称需要Level 3的定量计算支撑——否则只是定性陈述
- Level 3是本项目的核心新颖性承载层——必须被突出和保护

**窗口收窄风险：** 2024年Nature Physics论文明确呼吁"需要进一步理论解释κ≈0，包括赝Goldstone效应"。这在学术界是明确的信号——可能已有其他组在开展类似工作。

#### Step 4：差异化策略

**本项目应明确声明：**
```
已知：U(1)_v在晶格上被破缺 → KD模不是严格Goldstone（定性，community knowledge）
新颖：使用GOR关系的定量类比计算m_gap → 与k_B T比较裁决实验（定量，本项目独有）
```

**需要防护：** 如果在arXiv上搜到任何preprint提出"pseudo-Goldstone valleyron gap explains κ≈0"，无论是否使用GOR类比，都需：
1. 引用并承认
2. 差异化：强调GOR定量关系提供了他们的工作未能提供的可检验预测（m_gap对外部参数的函数依赖）

## §6 结论对比

### 6.1 四个攻击的严重性排序

| 排名 | 攻击 | 严重性 | 核心发现 |
|------|------|--------|---------|
| **1** | Attack 3: 共存序 | **HIGH** | Das-Kaul-Murthy (PRL 2022) 严格证明KD+CAF共存泛型存在。KD赝Goldstone有能隙 ≠ 所有模均有能隙 |
| **2** | Attack 1: 无序局域化 | **HIGH** | ν=0载流子耗尽+Anderson局域化可压制所有相的体热输运。κ≈0可能是通用特征而非相特异信号。2024 Nature Physics作者确认此为开放问题 |
| **3** | Attack 2: 逻辑循环 | **MEDIUM** | 磁场压制因子R(B)无独立实验测定。m_gap计算带系统性不确定度，可能跨越"排除KD"到"解释κ≈0"的全范围 |
| **4** | Attack 4: 新颖性 | **MEDIUM** | 赝Goldstone概念本身非新颖。真正新颖性在GOR定量类比。2024年窗口收窄风险 |

### 6.2 对北极星的裁决

**原始北极星：** "KD赝Goldstone能隙解释石墨烯ν=0 κ≈0"

**裁决：**
- 项目**不自杀**。KD赝Goldstone有能隙这个物理陈述本身是正确的（U(1)_v确实被晶格破缺）。
- 但"因此解释κ≈0"的排他性推理**需要修正**：
  1. 必须承认CAF共存的可能性（Attack 3），在此情形下额外的CAF自旋波仍是无能隙的
  2. 必须承认无序局域化作为竞争解释（Attack 1），在此情形下κ≈0不需要任何相特异机制
- **修正后的定位：** "如果ν=0基态为纯KD相，其赝Goldstone能隙提供κ≈0的一个**可能解释**。本工作通过GOR定量类比给出m_gap的解析估计，为未来实验（更高温度/更低磁场下的热导测量）提供可检验预测。"

### 6.3 与A轨道的关系

A轨道（GOR定量类比推导m_gap）的数值结果将决定：
- 若m_gap > k_B T → "KD赝Goldstone是κ≈0的可行解释之一"（需附带Attack 3的CAF共存声明）
- 若m_gap < k_B T → "KD不能在纯相假设下解释κ≈0" → 此时Attack 1（无序局域化）成为主要候选解释

**B轨道向A轨道的移交：**
- A在推导m_gap时需标注R(B)（LL mixing压制因子）的不确定度范围
- A在讨论中需引用Das-Kaul-Murthy (2022)共存相结果
- A在预测中需包含"若共存相成立→高温区应有CAF自旋波贡献，热导恢复的阈值温度应更低"的可区分实验预言

### 6.4 卡点更新

无新增阻塞卡点。B轨道突击完成。建议PI交叉审核后将以下卡点升为HIGH：
- Attack 3（共存序）→ 新增卡点 K1.3：KD+CAF共存相下CAF自旋波热输运
- Attack 1（无序局域化）→ 新增卡点 K1.4：无序局域化作为κ≈0的竞争通用解释
