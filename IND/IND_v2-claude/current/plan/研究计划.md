# 研究计划 — v1-strong-coupling-second-law

## 北极星
强耦合开放系统的"平衡态 passivity flip"（判据 [H*,H_S]≠0）与 Gibbs 态 β-混合的"Jensen 二阶迹距离标度"（系数 C_λ∝Var(O_λ)，α=2 普适）是否由同一个二阶凸性结构支配？若是，能否导出一个不依赖微观细节的强耦合熵产生/可提取功普适下界，并验证它在弱耦合退化为 Clausius 不等式。

> 永不更改。两种结局都合法：同源→正面普适修正；本质不同→否定性边界。追矛盾不追闭环。

## 驱动矛盾
**命题A**（BATH-v2-K14 + v2-K7 + v3-K14）：
强耦合平衡态可提取功的符号（passivity flip：ε_bare>0 而 ε_HMF=0）由对易子 [H*,H_S] 决定；[H*,H_S]=0 充分保证 bare/HMF passivity 一致，≠0 是 flip 的必要条件。‖[H*,H_S]‖ 被解释为"本征态 mismatch 的全局度量"。这是一个**算符对易性**度量。

**命题B**（SCHWARZ-v4-K2 + v6-K1）：
Gibbs 态对参数 λ 的二阶迹距离响应由共轭算符方差决定，C_λ = (β²/4)·⟨|[O_λ-⟨O_λ⟩]² - Var(O_λ)|⟩，指数 α=2 源于 Jensen 凸性，与代数维数/KMS 结构无关（普适）。这是一个**涨落（方差）**度量。

**矛盾精确化**：
A 与 B 都刻画 Gibbs 态在"二阶扰动"下的响应——
- A 的扰动来源：系统 H_S 与 mean-force 修正 H* 的不对易（环境不可分离）。
- B 的扰动来源：逆温 β 或参数 λ 的有限展宽（系综混合）。

两者表面上用**不同对象**（对易子 vs 方差）度量同一类二阶效应。设
  Δ_A := ‖[H*, H_S]‖（A 的核心量）
  Δ_B := Var(O_λ)（B 的核心量，O_λ 为 λ 的共轭算符）

矛盾的两种解：
  (i) 存在映射使 Δ_A 与 Δ_B 是同一个二阶 Hessian（自由能/相对熵的二阶导）的两种投影
      → flip 判据与 Jensen 系数同源 → 可导出强耦合熵产生普适下界 σ ≥ f(Δ)，弱耦合退化为 Clausius。
  (ii) 二者本质不同（对易子含相位信息，方差只含模）
      → 否定性结论：划清"强耦合 passivity"与"系综涨落普适性"两个普适性的适用边界。

## 可观测性锚点（步骤5）
- 可测量的量：强耦合开放量子系统的可提取功符号（ergotropy/passivity）+ 熵产生率。
- 当前测量精度：超导磁通量子比特强耦合热输运（2024 实验已观测，热功率超前一量级）；量热法分辨率 ~10⁻²¹ J 级。
- 我们效应量级：flip 是可提取功符号的 O(1) 效应（ε_bare>0 vs ε_HMF=0，BATH-v2-K14）；二阶系数 C_λ 在有限尺寸临界点 ~L^{2/ν}（SCHWARZ-v5-K2），有限维 α=2 已是 O1（SCHWARZ-v4-K1）。
- 相差数量级：工程化强耦合系统内可及（耦合强度 α~0.3-0.4 时 ‖[H*,H_S]‖/‖H_S‖≈0.127, BATH-v2-K13）。
- 定位：[x] O1/O2 目标（passivity 符号可测，二阶系数可数值验证）  [ ] O4/O5 为主

## 课题类型路线
