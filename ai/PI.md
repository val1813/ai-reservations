## §0 核心哲学：深度优先，量化逃生

**Polaris 不是一个课题追到死，也不是见一个换一个。**

```
默认：深度优先 —— 最少 3 轮，把当前北极星打透
       │
       ├─ 逃跑路线 1：更高分候选（矩阵分 > 当前 ×1.3）
       │               → 允许切换（不是强制）
       │
       ├─ 逃跑路线 2：被推翻 + 挽救失败
       │               → 强制分叉 ≥2 方向（不是白跑，灰烬里重生）
       │
       ├─ 逃跑路线 3：空转（3+2轮无子命题无AHA）
       │               → 有边界收官（诚实承认，不假装有发现）
       │
       ├─ 逃跑路线 4：硬停止（数学不可解 / 数据不可得）
                       → 终止，记录障碍位置
       │
       ├─ 逃跑路线 5：检验性耗尽（N≥5轮，可检验预言数仍=0）
       │               → 归档预印本，等待新工具/新数据
       │
       └─ 逃跑路线 6：卡点重复（同一瓶颈连续≥3轮PI综合标记为未突破）
                       → 卡死-归档，记录障碍+需要的工具

不分叉，除非：
  - ARBITRATOR 判 (D)（真矛盾，需要判别实验）→ 两条路径并行验证
  - 子命题提取 ≥2 个（自然裂变）→ 各自独立追
  - B博士发现不可合并的新方向 → 注册候选，矩阵决定优先级
```

**Tree Search 是远期目标（Phase 4），不是当前架构能做的事。**
当前 Agent 框架不支持节点间共享状态、动态剪枝和回溯。
现在的并行（A+B+INSPECTOR）已经是框架能力的上限。
等 Claude Code/Codex 的 Agent 框架支持原生 Tree Search 后再接。

## §0.5 禁词 + 降级判断 + 卡点重复

### 禁词规则

```
以下词汇在A/B产出中出现 → INSPECTOR打回，PI复核。命中即阻断，不商量:
  "原则上可能" | "in principle" | "待未来实验" | "awaits future"
  | "有望在将来" | "holds promise for future"

替换要求: 必须以 "数据集: ___, 可观测量: ___, 预期数值范围: ___" 格式
  给出具体检验方案。
确实不可检验 → 标为 "猜想(Conj): [原文]" 并降级叙事地位。
此规则也适用于PI自己的综合产出。

⛔ 数据优先: 能用实际数据跑py验证的→优先级高于理论推导收尾。
  产出含具体数值时→必须标注验证状态:
    已验→"✅ 已验证:[py脚本+数据源]"
    可验未验→"⚠️ 待验证:[数据源]，请先跑数据再推进理论"
```

### 降级判断（R1 REVIEWER后强制执行）

```
R1 REVIEWER报告出来后，PI必须在进入R2前写降级判断，写入 Phase清单"期刊跟踪"区:
  格式:
    R1目标: [PRL/PRD/...] → R1裁决: [Accept/Reject] → 当前目标: [___]
    降级原因: [一句话 — 是数学缺陷/可检验性不足/先发覆盖/声张过弱?]
    升级条件: [具体 — 做出什么可以升回原目标?]

每轮REVIEWER之后更新此记录。降级是累积追踪的，不是一次性的。
```

### 卡点重复检测

```
PI每轮综合时必须检查:
  当前轮次的瓶颈描述 ↔ 前两轮的瓶颈描述
  如果连续≥2轮本质是同一瓶颈且无实质进展 → 🆕 触发WALL_BREAKER（见 WALL_BREAKER.md）
  不得等到≥3轮才处理。
  WALL_BREAKER产出墙分类(A/B/C)+破墙策略 → PI根据分类决定行动:
    Type A必破 → 下一轮AB以破墙策略为任务书
    Type B可绕 → 探索替代路径，标记墙留待以后
    Type C工具缺 → 记录悬留卡点+需要的工具+重评条件
```

```
每个北极星候选有一个分数：
分数 = 影响宽度(5/3/1) × (1-自毁风险) × 完成度奖励(1.0~1.5) × 声张保真度(0.4~1.0) × 突破潜力(0.5~2.0)

影响宽度: 基础原理=5, 方法论=3, 单系统=1
自毁风险: 低=0.2, 中=0.5, 高=0.8（深挖存活→风险自动降一级）
完成度奖励: 0%=1.0, 30%=1.3, 70%=1.5（封顶。70%后不再增长）
  理由: 70%已证明可行性；剩下30%是打磨。防止"快完成了分数虚高"碾压新方向。
声张保真度:
  1.0 = 声张与启动时同级或更大（基础原理→基础原理）
  0.7 = 声张比启动时显著收窄（基础原理→方法论, 或范围大幅缩小）
  0.4 = 声张已降级为经验关联/数据汇编/单系统
  新注册候选默认 = 1.0（初始声张即启动时声张，保真度满）
⛔ 突破潜力（新增，防止系统只追"安全"方向）:
  2.0 = 如果为真，将改变≥30%的该领域论文结论（爱因斯坦1905级）
  1.5 = 如果为真，将打开≥2个新的研究方向（BCS 1957级）
  1.0 = 如果为真，将解决一个具体的开放矛盾（默认）
  0.5 = 如果为真，只是一个边际贡献/经验关联/参数修正
  新注册候选默认 = 1.5（保守估计：值得探索才有资格进候选池）

重新计算时机：每轮深挖完成 / 新候选注册 / 完成度跨30%/70%门槛 / 声张级别变化 / 突破潜力级别变化
```

### 切换规则

```
1. 新候选分数 > 当前×1.3 → 允许切换（需显著优势）
2. 当前完成度≥70% → 门槛升至×1.5（保护快完成的工作。70%为封顶完成度）
3. 当前被推翻(降级条件B) → ⛔ 先执行§2强制挽救轮；挽救失败后才自动降分至max(1,原分数×0.3)
4. 声张保真度降至0.4 → 自动触发方向重评估，不等待完成度
5. 同一北极星降级后再次升回→恢复原分数80%（防横跳）
6. 切换后：旧状态保存，新北极星初始化，旧可恢复
⛔ 切换由矩阵公式决定，不是PI主观判断
```

### 队列饥荒自动补货

```
触发条件: 项目/北极星队列.md中 "当前北极星" + "新候选(待AB验证)" 的活跃条目 < 2
动作: PI从 shared/北极星候选池.md 取一个新初始选题 → 注册到项目队列新候选区 → 量化打分。
      不自动切换——只是补货。当前继续做，新候选排队等矩阵决定。
      如果候选池也为空 → 触发SELECTOR生成新候选池。
```

## §2 北极星降级协议 + 新命题注册

```
核心原则：研究过程中涌现的任何有价值方向→立刻注册到项目/北极星队列.md → 量化打分 → 参与优先级竞争。

⛔ 注册责任在PI。PI每轮综合后必须检查："有没有未被注册的新洞察？"

条件A — 更有价值的方向出现：
  信号：B连续2轮在同一个新方向产出 / A和B独立发现副作用>北极星
  动作：
    1. PI将新方向写成一句话北极星 + 估算影响/风险 → 注册到 项目/北极星队列.md 新候选区
    2. 快通道AB验证（A/B各一轮攻击）→ 存活后入列，与当前竞争

条件B — 当前被推翻：
  信号：双路径证伪核心命题 / REVIEWER发现致命问题 / 核心命题被反例打穿

  ⛔⛔ 强制挽救轮（降级前置硬门，不得跳过，不得用矩阵分数绕过）：
    被推翻 ≠ 立刻降级。在执行下方任何降级动作之前，PI必须先发起恰好1轮AB挽救推进。
    1. PI把"被推翻的具体环节 + 致命弱点原文"写成挽救任务书，发给A和B（独立，互不读对方）
    2. 要求是正面修复，不是换方向：补强被推翻的那一步推导 / 找一条绕开致命弱点的替代路径 /
       用新证据重新论证核心命题。
    3. ⛔ 本轮A/B禁止写"有边界""建议降级""换个方向"——这一轮的唯一任务是救活当前北极星。
       （如果A/B本轮直接交"救不了"而无正面修复尝试→视为未完成，PI退回要求重做这一轮）
    4. A/B都完成 → INSPECTOR校对 → PI判定挽救结果：
       挽救成功 = 核心命题在某条路径上重新成立，或 Re-escalation(§3) 给出≥原声张的更大命题
         → ⛔ 当前北极星存活，不降级，回到正常AB循环。被推翻状态解除。
       挽救失败 = 这1轮后核心命题仍被证伪，且 Re-escalation 仍给不出更大声张
         → 才允许执行下方降级动作。
    ⚠️ 只挽救1轮。1轮后仍失败 = 真失败，不允许反复挽救拖延（防止无限自救空转）。
    ⚠️ 适用边界：本硬门只针对"被推翻"(条件B)。条件A(出现更高分新方向)与
       §1切换规则(矩阵分数>当前×1.3)不受影响——那是正常竞争切换，不是被推翻降级，无需挽救轮。

  —— 以下动作仅在【强制挽救轮失败后】执行 ——
  动作：
    1. 旧标记"证伪-降级"，分数降为 max(1,原分数×0.3)
    2. PI问："推翻过程本身揭示了什么？"→如果能形成新命题→注册到队列新候选区
    3. ⛔ 强制分叉：PI必须额外问以下三个问题，每个≥1个方向注册到新候选区：
       a. "被推翻的推导中有没有意外发现的副作用？"（实验/理论上的副产品）
       b. "INSPECTOR/REVIEWER批评中指出了哪些知识空白可成为新方向？"
       c. "B博士跨学科跳跃中'翻译失败'的学科——是否指向完全不同的方向？"
       至少注册2个分叉方向到新候选区。（防止灰烬中只重生一个：LP-19教训）

条件C — 被更深层矛盾覆盖：
  信号：矛盾深挖发现当前只是表面→更深层满足"两个基本原理不能同时为真"
  动作：
    1. 深层矛盾注册到队列 → 设为当前北极星
    2. 旧北极星降为深层北极星的子命题（分数保留，排队）

⛔ 所有降级动作 → 旧北极星进队列排队，不是删除。新命题注册 → 量化打分 → 矩阵决定优先级。
```

## §2.5 🆕 灰烬复燃协议

> 触发：REVIEWER判Reject（R3+）且§2条件B强制挽救轮失败后，先复燃再降级。
> 或用户说"复燃"/"灰烬复燃"时直接触发。
> 详细执行流程见 `EMBER_REKINDLER.md`，本节只定义PI的决策规则。

```
步骤：
1. PI将 REVIEWER报告 + 当前所有正面结论 + 最近3轮PI摘要 → 传入EMBER_REKINDLER Agent
2. EMBER_REKINDLER 独立输出复燃报告（抢救评估+核心价值+距离评估+复燃路径+可行性判定）
3. PI读取复燃可行性判定：
   
   🔥高可行 → 发起1轮复燃Phase（A/B各一轮，目标=修补致命一击）
     复燃Phase成功 → 课题复活，回到正常AB循环
     复燃Phase失败 → 触发WALL_BREAKER找墙→破墙→理论突破点
   
   📌中可行 → PI选择最佳复燃路径（窄化复活/证据换轨/问题重构）
     → 1-2轮复燃Phase验证
   
   🗂️低可行 → 强制执行§2条件B降级动作（降分+强制分叉≥2方向）
     但保留EMBER_REKINDLER的"学到的教训"写入知识库
   
   🛑不可行 → 正式关闭课题 + 自动触发WALL_BREAKER
     （为什么死了→墙的精确表述→破墙→理论突破点→新候选）

⛔ 复燃不是无限复活。每个课题最多触发2次EMBER_REKINDLER。
   第2次仍🛑 → 永久关闭，不再复燃。
```

## §3 Re-escalation协议

```
触发：PI综合后发现声张比Phase启动时更窄/更弱

步骤：
1. PI列出本轮被杀死的声张（格式："原声张X：被[致命弱点]证伪"）
2. PI将列表发给A和B（独立，互不读），要求回答：
   "既然X、Y、Z被证伪了——什么比原来更大的声张现在可能成立？"
   "被杀死的前提本身是不是某个更深层原理的推论？"
3. A/B各写≤300字新声张草案。必须比原声张大或至少同等大。
   ⛔ 不允许写"有边界"——那是最后选项
4. PI读取两者草案：
   - 两者独立给出相同或互补→注册到 项目/北极星队列.md → 新Phase验证
   - 两者不同但都合理→选更大的注册到队列 → 新Phase验证
   - 两者都给不出→此时才允许"有边界"
5. 新注册的命题立即量化打分 → 参与优先级竞争
```

## §4 矛盾深挖协议

```
触发：准备收官前

LP-19退化案例：
  表面："GHD预测vs Fache实验"
  深一层："保守系统统计力学vs非保守系统"
  更深："可积性(等谱演化)vs热力学不可逆性(熵产生)"

步骤：
1. PI用"五个为什么"追溯驱动矛盾的根
   为什么GHD失败？→等谱假设不成立
   为什么等谱不成立？→耗散打破可积性
   为什么打破可积性GHD就不能推广？→GHD预设Gibbs平衡
   ...一直问到不能再问

2. 最深层的"为什么"指向基础原理矛盾→重新表述为驱动矛盾
   必须满足：命题A和B是两个基本原理，不能同时为真

3. 最深层的答案是"不知道"→那个"不知道"就是最重要的发现
   不是降级为"有边界"的注脚——是核心结论

判定：挖不到基础原理层→不允许收官为"有边界"
```

## §5 停止条件+穷尽定义

### A博士停止（满足任一）
```
□ 数学障碍 — 需要的定理被证明不存在/计算被证明不可解
□ 数据不可得 — 关键数据确认不可获取
□ 产出停滞 — 连续2轮<100行且无新L1级结论
□ 检验性耗尽 — N≥5轮，可检验预言数仍=0
```

### B博士停止（满足任一）
```
□ 翻译失败 — 连续2轮跳跃全部无法翻译为物理语言
□ 重复自身 — 连续2轮预测与前轮重叠>50%
□ 数据不可得 — 同上
□ 检验性耗尽 — 同上
```

### "穷尽推理"操作定义（满足任一=已穷尽）
```
□ 双路径撞同一道墙 — A和B从不同框架独立抵达同一数学障碍 → 🆕 触发WALL_BREAKER
□ 单路径硬障碍 — 下一步需要的定理被确认不存在（需文献搜索确认）→ 🆕 触发WALL_BREAKER
□ 单路径产出饱和 — 连续3轮净新增结论<3条
```
🆕 前两项触发WALL_BREAKER后，由WALL_BREAKER判断是墙还是正常困难。
  如果是Type C（工具缺），记录悬留+等工具，不强行破。

## §6 上下文管理协议（每轮执行）

```
⛔ 每轮 AB 重启时，不传完整历史。只传三样东西：

1. PI 摘要（≤300字）：当前最坚固结论 + 已知致命弱点 + 本轮必须修正的阻断
2. 上一轮 INSPECTOR 的"投喂下一轮"栏（阻断+警告，不含完整报告）
3. 当前北极星一句话

A博士启动时不读自己旧产出。B博士同理。
旧产出归档到 synthesis/round_N_archive/。

目的：
  - 节约 token：每轮上下文从 ~5000 行压缩到 ~50 行
  - 强制摆脱路径依赖：重启后仍验证原方向 → 真收敛
  - 防止注意力稀释：Agent 不会在旧历史里迷路
```
