# REVIEWER Round 3

Verdict: **REJECT**

## 1. Five fatal attack points

1. **The object is still a protocol, not a result.**  
   Round 3 only proves a prospective fenced workflow is imaginable. It does not produce a real same-sample or matched-specimen packet that can already discriminate or preserve `R_oe`. That leaves the north star unanswered.

2. **The claimed identifiability hinges on same-source pollution assumptions that are not yet audited.**  
   Both A and B admit the hard bottleneck is whether `B_min` can stay independent of the fitted `qz/c-axis/matrix-element` state used for `P_oe`. Until PI independently audits that separation, the state machine is just a guarded speculation layer.

3. **The thresholds are protocol theater unless grounded in facility reality.**  
   `N=24`, `N=48`, `36 complete blinded rows`, `4 batches`, `3 labs`, and leave-one-batch/lab-out validation are presented as gates, but no live facility record shows they are jointly achievable for this packet class. They are constraints, not evidence.

4. **The firewall can still collapse into post-hoc row triage.**  
   "Green/yellow/red" classification is useful only if blind custody, row inclusion, censoring, and `U_miss` are frozen before output reveal. Right now the live procedure is described, not demonstrated. That is enough for a protocol memo, not enough for a claim-bearing technical advance.

5. **The package does not yet beat existing nickelate literature on substance.**  
   It rewraps known ingredients: oxygen stoichiometry sensitivity, pressure dependence, bilayer/interlayer coupling, and odd/even spin-response structure. The packet adds governance and audit language, but no new physical mechanism or measurement primitive.

## 2. Fiction / first-to-publish risk and claims PI must verify

No external paper matching the exact `P_oe + B_min + row firewall + R_oe` packet was found in the searches I ran. That is an inference from the searches, not proof of absence.

PI must independently verify these concrete claims before reuse:

- the packet has not been pre-empted by an overlooked preprint or dissertation on the same row-level identifiability problem;
- `B_min` can be constructed without importing the same fitted state that defines `P_oe`;
- the same-sample or sibling tolerances are actually met by a real facility, not just by protocol text;
- the `N=48/36` decision-grade gate is physically reachable for this material system;
- any cited analogy from bilayer nickelate pressure/oxygen work is not being overstretched into a row-level independence claim.

## 3. Is this still just protocol packaging?

Yes. As written, it is mostly a sealed-protocol wrapper around existing nickelate facts. It does not yet establish a theory advance or a technical breakthrough because the decisive step, a real audited packet with pre-output independence, is missing.

## 4. Salvageable version and minimum salvage condition

**Salvageable version:** a narrowly scoped prospective protocol note that claims only feasibility of a blinded row packet, not `R_oe` adjudication.  
**Minimum salvage condition:** one audited pilot with immutable raw archive, independent `P_oe`/`B_min` extraction, frozen censoring and `U_miss`, and at least one real same-sample or formally sistered row passing the pre-registered firewall.

## 5. Final judgment

**REJECT**

The cleanest reason is simple: this is not yet a claim-bearing packet, only a disciplined plan for possibly building one.
