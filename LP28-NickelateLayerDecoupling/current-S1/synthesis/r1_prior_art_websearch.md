# LP28-S1 R1 Prior-Art WebSearch

Date: 2026-06-04

## Core Claim Checked

`I_phi` is not a validated predictor. The only possible novelty in LP28-S1 is a non-circular pre-registration / zero-leakage protocol that computes an input-side phase-bus readiness index before bulk superconducting output is inspected.

## WebSearch Results

1. arXiv:2605.18524, "Interlayer electronic coherence links magnetism and superconductivity in Ruddlesden-Popper nickelates" confirms that interlayer coherence is already being framed as a key organizing parameter for RP nickelate magnetism and superconductivity. It reports crystallographic-axis-resolved transport and argues stronger interlayer coherence is favorable for superconductivity. This blocks any novelty claim that simply equates interlayer coherence with superconductivity.

2. Search results for `dz2-pz-dz2` / interlayer hybridization confirm active 2026 prior-art around oxygen-mediated `dz2-pz-dz2` hybridization enabling superconductivity in bilayer nickelates. This blocks any novelty claim that the orbital channel itself is new.

3. Searches for PRL 136, 216501 / La4Ni3O10 / c-axis conductivity reinforce the LP28 boundary: static DW and c-axis suppression are relevant input context, but cannot by themselves validate bulk superconductivity or validate `I_phi`.

## PI Decision

No complete prior-art collision found for a frozen, zero-leakage `I_phi` pre-registration packet. However, the physical mechanism space is heavily covered. LP28-S1 must remain a methodology/protocol claim:

- allowed: "pre-registered input-side audit candidate"
- forbidden: "validated predictor", "new interlayer-coherence mechanism", "dz2 hybridization discovery"
