# Re-escalation 综合

## 被杀死的声张

1. interlayer coherence 是 LP28 首创。
2. dz2 / dz2-pz-dz2 hybridization 是 LP28 新机制。
3. pressure suppresses DW -> superconductivity 是充分链条。
4. `I_phi` 是已验证 predictor。
5. zero resistance 可单独证明 bulk superconductivity。

## 可保留但收窄的声张

LP28 不是已验证机制，而是可杀死的实验路线：same-sample recovery-ordering protocol。

## Re-escalated Claim

> 镍酸盐高温超导的材料设计顺序可能错了：不应先“压低 DW / 搜索 Tc”，而应先筛选是否存在可恢复的 orbital phase bus，再判断 local pairing reservoir 是否能升级为 independent bulk phase output。

## 三门控路线

1. **Pairing reservoir:** 材料必须保留可用的 local pairing / fluctuation environment。
2. **Recoverable phase bus:** dz2/apical-O/dz2 或等价 orbital bridge 必须能在压力、应变、化学或泵浦下恢复输入侧相位传输。
3. **Independent bulk output:** 必须用 shielding/Meissner/vortex/THz/Josephson 独立验证 bulk phase stiffness；zero resistance 只辅助。

## 边界

- `I_phi` 只是预注册 input-side metric，不是已证 predictor。
- DW disappearance 不是充分条件。
- 贡献不是命名 interlayer coherence，而是把材料筛选流程改成可证伪的 actuator-sensor-output protocol。

## 收尾判定

当前北极星没有被推翻，但必须降格为：

**有突破潜力的待验证实验协议 / 技术路线，而非已完成理论机制。**
