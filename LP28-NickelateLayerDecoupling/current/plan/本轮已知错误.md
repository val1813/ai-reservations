# 本轮已知错误 / 警告

## Round 1

### A博士 INSPECTOR 警告

1. `D` 判据中的 `epsilon` 正则项任意性较强，不能作为硬量化判据。
2. `S = Delta_DW_static/(t_perp_eff + epsilon)` 中 `t_perp_eff` 能标来源不足。
3. 压力替代解释未显式排除：压力可同时改变带宽、结构畸变、disorder、载流子浓度和轨道能级。
4. 当前落地计算主要使用 ambient-pressure anisotropy；需要压力依赖的 rho_c/rho_ab 或 c-axis Drude weight 才能真正判别 pressure-SC 路径。

### B博士 INSPECTOR 警告

1. `Lambda = hbar*t_perp_eff/(k_B*T + hbar*Gamma_DW)` 只有在 `t_perp_eff` 明确为速率时量纲成立；Round 2 必须固定单位约定。
2. `epsilon_c` 应变符号未定义；若继续使用 P4，必须声明压缩为正还是负。
3. `Lambda` 若由 rho_c/rho_ab 反推，再用 rho_c/rho_ab 验证，会有循环论证风险；Round 2 必须区分输入代理与外部验证。
4. 替代解释不足：压力直接带宽效应、散射各向异性/结构畴、共同第三变量都要纳入判据。
5. P2-P4 落地阈值偏弱，需要压力范围、时间尺度、Meissner/shielding fraction 阈值、Delta sigma_c/Delta sigma_ab 下限或应变量级。

### PI 先发拦截

1. `arXiv:2605.18524` 已提出 interlayer electronic coherence 作为 RP 镍酸盐 magnetism/superconductivity 的组织参数。
2. `arXiv:2604.14701` 已提出 bilayer nickelates 中 coherent dz2-pz-dz2 interlayer hybridization enables superconductivity，并且 static spin order 被抑制。
3. LP28 不得声称 interlayer coherence 组织参数首创；必须收窄为 trilayer La4Ni3O10 的 static DW layer-decoupling 与 pressure superconductivity 因果排序判据。
