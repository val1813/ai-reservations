# 卡点登记册

## Round 3 REVIEWER 卡点

### R3-C1: `I_phi` 不能被写成已验证 predictor

**严重性:** fatal if overstated  
**内容:** 若把 `I_phi = E_z2*C_phi/(kBT+hbar Gamma_phi+E_floor)` 当成已经成立的 predictor，而没有同一样品 pressure-axis 先验输入测量与独立 bulk output 验证，则 fatal。  
**处理:** LP28 当前只保留为待验证 protocol / engineering roadmap，不称为已验证机制。

### R3-C2: DW 消失不是充分条件

**严重性:** serious/fatal if sufficiency claimed  
**内容:** tetragonal La4Ni3O10 没有 ambient DW transition 也没有 superconductivity，反驳“无DW/解除decoupling自动得到SC”的单因果链。  
**处理:** protocol 只要求 `I_phi` recovery + independent `B_bulk` output + controls；不声称 DW disappearance suffices。

### R3-C3: 先发压缩新颖性

**严重性:** serious  
**内容:** interlayer coherence、dz2-pz-dz2 hybridization、Pr4Ni3O10 dz2 incoherence 已有先发。  
**处理:** 新颖性收窄到 trilayer static-DW layer-decoupling 的 same-sample recovery-ordering protocol。

### R3-C4: 阈值标定仍半定量

**严重性:** warning/serious  
**内容:** `E0`、`E_floor`、`Gamma_phi` 单位、`tracks more strongly` 统计指标需要预注册。  
**处理:** 收尾输出必须列为实验协议必需项，不能列为已校准理论常数。
