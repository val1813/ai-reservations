# 研究计划

## Round 1 任务

## 目标校准

本项目目的不是写论文，也不是裁判“DW 对/错”或“谁先发”。优先级改为：

1. 找到可带来实际理论突破的机制变量。
2. 找到能指导材料设计、压力/应变/泵浦调控或器件路线的科技进步杠杆。
3. 只有当判据服务于上述两点时，才继续细化判据。

对 LP28 而言，当前最有价值的突破候选不是“证明 DW 是抑制器”，而是：

> RP 镍酸盐的可工程化变量可能是 dz2-mediated interlayer phase quorum：通过压力、应变、化学替换或非平衡泵浦恢复层间相干，同时保留有利的 pairing fluctuations。

**A博士:**  
从镍酸盐文献内部出发，核查 DW、dz2 轨道、interlayer coherence、pressure superconductivity 四者的因果链。目标是写出最保守的 A vs B 判据，并列出可立即验证的已发表数据。

**B博士:**  
从跨领域角度攻击“DW 是超导前体”这一直觉，寻找类似“静态有序杀死相干、涨落帮助配对”的机制类比。目标是提出可观测判据，而不是解释性散文。

**INSPECTOR:**  
Round 1 后检查量纲、逻辑循环、替代解释、先发风险和可检验性。

## 最小可验证判据草案

1. 压力下 Tc 是否随 rho_c/rho_ab 的降低而上升，而不是仅随 DW gap 关闭而上升？
2. 同一材料系列中，静态 DW 强度与 c-axis Drude weight 是否反相关？
3. dz2 nonbonding/bonding weight 的重分布是否比 SDW order parameter 更能预测 superconducting dome？
4. 若 DW 涨落是胶水，是否存在“静态 DW 已弱化但涨落仍强、interlayer coherence 已恢复”的最佳窗口？
