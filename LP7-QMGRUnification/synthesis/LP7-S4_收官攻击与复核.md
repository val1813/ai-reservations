# LP7-S4 收官攻击与复核

日期：2026-06-01

## 结论先行

S4 结论维持为：**有边界**。

复核后没有发现足以推翻 Phase 1 的致命漏洞，但也没有证据支持把 S4 升格为“已解决黑洞信息悖论”或“已推出统一公式”。

## 复核对象

S4 的核心命题是：

> 黑洞信息悖论可被压缩为四假设判据 `J_BH={Hawking_thermal, Complete_evaporation, Unitarity, No_new_entropy_rule}`；任何统一公式都必须说明如何恢复 Page curve，并交代改写了哪条假设。

## 收官标准攻击

### 1. 最小矛盾是否成立

成立，但只到判据层，不到终局层。

- `Hawking_thermal` 代表半经典近热辐射与单调增熵。
- `Complete_evaporation` 排除了 remnant / baby universe 作为信息账本。
- `Unitarity` 要求最终纯态。
- `No_new_entropy_rule` 排除了 island / QES / replica wormhole 之类新熵规则。

这四者不可同真，作为筛选器是够的。

### 2. island 路线是否足以“解决”

不够。

它能恢复 Page curve，但代价是改写细粒度熵规则并引入新的 gravitational saddle。它更像“修正计算规则后得到一致结果”，不是“无代价终结悖论”。

### 3. 其他路线是否可并入主结论

不应并入主结论。

- `remnant` 和 `baby universe` 改的是 `Complete_evaporation`。
- `stimulated emission` 改的是 `Hawking_thermal` 的信息通道解释。
- `firewall / complementarity / ER=EPR` 改的是低能 EFT、视界平滑性或观测者一致性。
- `no-paradox` 路线本质上是重述问题，不是消除信息账本要求。

这些路线可以作为替代分支，但不能替代 S4 的主判据。

### 4. 收官风险点

S4 最大风险不是“判据错了”，而是“判据太强”。

它把黑洞信息悖论压成了统一公式的必要条件，但没有从这里直接推出统一公式本体。因此 S4 只能作为强引力筛选器，而不是统一理论本身。

## 最终裁决

S4 通过收官审稿，但收口必须保守：

> 黑洞信息悖论是 LP7 的强引力筛选器；任何统一公式都必须交代 Page curve，并说明它修改了 `J_BH` 的哪一项。

## 子命题拆分

- S4-a：四假设判据 `J_BH`
- S4-b：Page curve vs Hawking curve
- S4-c：island / replica wormhole 的地位
- S4-d：替代路线分类
- S4-e：S4 对统一公式的约束边界

## 归档建议

S4 可视为收官完成，后续进入 S5 统一公式候选判据矩阵，不再重复扩写黑洞信息悖论本身。
