# LP7 中间层确认

## 结论

`J_unify` 作为单一“统一公式”是假的；作为“候选统一公式的接口判据”是真的。

## 为什么是假的

六块矩阵混在一起时，实际在比较六种不同对象：

1. 分支源项
2. 媒介非经典性
3. 混合动力学代价
4. 熵规则 / Page curve
5. detector response
6. 参考系一致性

它们不是同一层级的物理量，不能强行压成一个方程。

## 中间层是什么

中间层是一个**操作性通道层**：

```text
I[T] = (Φ_source, Φ_mediator, Φ_noise, Φ_entropy, Φ_obs, Φ_frame)
```

它的任务不是给出终极理论，而是把候选理论投影到统一的可观测接口。

## 与 LP7 子题的对应

| 子题 | 中间层对象 |
|---|---|
| S1 | `Φ_source` |
| S2 | `Φ_mediator` |
| S3 | `Φ_noise` |
| S4 | `Φ_entropy` |
| S6 | `Φ_obs` |
| S5 | `I[T]` 的准入判据 |

## 真正可用的式子

不是

`J_unify[T] = 单个统一方程`

而是

`J_unify[T] = penalty(I[T] 不满足 U1-U5/U6)`

也就是说，`J_unify` 是中间层接口的约束函数，不是终极物理方程。

## 结论类型

**有边界。**

LP7 目前能确认的是：统一公式候选必须经过中间层通道映射，才能被比较和筛选。该中间层不是单一动力学，而是 source / mediator / noise / entropy / observable / frame 的接口层。
