## 验算 1：S1 源项分歧（Page-Geilker 最小模型）

### 待验算公式

```
|ψ⟩ = (|L⟩ + |R⟩)/√2
Φ_sc = (Φ_L + Φ_R)/2
Φ_run = Φ_L or Φ_R
ΔΦ_branch = Φ_run - Φ_sc = ±(Φ_L - Φ_R)/2
```

### 独立推导

从二分支态出发：
```
⟨ρ⟩ = ⟨ψ|ρ|ψ⟩ = (1/2)(⟨L|+⟨R|)ρ(|L⟩+|R⟩)
```
若⟨L|ρ|R⟩ ≈ 0（宏观分支近似正交），则：
```
⟨ρ⟩ ≈ (1/2)(⟨L|ρ|L⟩ + ⟨R|ρ|R⟩) = (ρ_L + ρ_R)/2
```
因此：
```
Φ_sc = -G∫d³x' ⟨ρ(x')⟩/|x-x'| = (Φ_L + Φ_R)/2
```

单次运行的分支势：
```
Φ_run ∈ {Φ_L, Φ_R}
ΔΦ = ±(Φ_L - Φ_R)/2
```

### 验算结论
✅ **通过。** 代数推导正确。二分支正交近似在宏观极限下成立。核心结论（Page-Geilker排除的是naive expectation-source，不是所有classical gravity）逻辑自洽。

## 验算 2：S4 黑洞信息四假设不可同真

### 待验算判据

```
J_BH = {Hawking_thermal, Complete_evaporation, Unitarity, No_new_entropy_rule}
```

四者不可同真论证：
1. Hawking_thermal → 辐射近热谱，纠缠熵单调增
2. Complete_evaporation → 黑洞完全蒸发，无remnant
3. Unitarity → 终态纯态，S_final = 0
4. No_new_entropy_rule → 不接受island/QES/细粒度熵修正

矛盾推导：
- (1)+(2) ⇒ S_rad(t → ∞) 持续增长，终态混态
- (3) ⇒ S_rad(t → ∞) = 0
- (1)+(2) 与 (3) 矛盾，除非引入 (4) 的否定（即接受新的熵规则）

### 独立推导

标准Hawking计算中，早期辐射与晚期辐射的纠缠熵：
```
S_rad(t) ≈ min(S_BH(t), S_BH(0) - S_BH(t))  [早期，无island]
S_rad(t) ≈ min(S_BH(t), S_BH(0))  [晚期，有island，Page curve恢复]
```

无island时S_rad单调增→混态终态→违反Unitarity。
有island时S_rad先增后降→纯态终态→满足Unitarity，但引入了新熵规则（QES, island formula）。

### 验算结论
✅ **通过。** 四假设不可同真的逻辑正确。J_BH作为必要条件筛选器有效，但不能作为充分条件。

## 验算 3：S6 因果集传播子距离

### 待验算公式

```
J_obs^CS[D,J] = dist_delta(D^T(K_i - K_j)J, Im M_cross)
```

### 独立分析

D是detector配置向量，J是源配置向量，K_i是第i种传播子构造的矩阵表示。

dist_delta度量的是：两种传播子构造在给定detector-源配置下的响应差异，与共同零空间（Im M_cross）的投影距离。

### 验算结论
✅ **通过（有条件）。** 公式在形式上合法。但依赖：
- v13 A推导未完成，K_i矩阵的数值实现（特别是K_K = exp(L)）未交叉验证
- dist_delta的度量性质（对称性、三角不等式）未证明
- 降为L3，等待v13的GATE 3闭合后方可升级

## 验算 4：S7 总块矩阵结构
