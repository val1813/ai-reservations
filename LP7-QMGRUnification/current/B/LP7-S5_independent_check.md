# LP7-S5 — B 独立检查

## 0. 独立性声明

我只使用任务书，不读取 A 的 `LP7-S5_phase1.md`。

## 1. 最小候选要求

一个统一公式候选不能只满足单一边界。它至少要同时说明：

- 量子测量单次分支怎么进源项；
- 如果有纠缠见证，中介层级怎么描述；
- 如果允许经典-量子混合，代价是什么；
- 若进入黑洞/强引力区，Page curve 怎么恢复。

## 2. 文献与边界映射

### LP7-S1 侧

naive expectation-source 半经典方程已经被边界化，因此候选不能把 ensemble `<T>` 当作 run-by-run 实际源项。

### LP7-S2 侧

BMV 只能推出媒介非经典于特定可观测结构假设下，不能自动推出标准量子时空。

### LP7-S3 侧

deterministic hybrid closure 风险高；存活路线要付出 stochasticity / CP-TP / diffusion 代价。

### LP7-S4 侧

黑洞信息悖论要求候选恢复 Page curve，或者明确修改 `J_BH` 四假设中的一项。

## 3. 对 A 预期结论的攻击

若 A 把“统一公式候选”定义得太宽，就会把大量局部修补误收进来。
若 A 定义得太窄，就可能排除真正同时覆盖实验室侧和强引力侧的理论。

我支持的边界是：

- 只恢复一侧的，不算统一候选；
- 既不解释测量边界也不解释 Page curve 的，不算统一候选；
- 能同时跨过四条边界图谱的，才算候选。

## 4. 结论类型

结论类型：**有边界**。

理由：

统一公式候选必须至少兼容 LP7-S1 至 LP7-S4 的四条边界图谱。任何只在单一子命题内成功的方案都只是局部修补，不配直接升格为统一公式。
