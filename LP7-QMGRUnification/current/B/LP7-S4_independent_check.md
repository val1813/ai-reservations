# LP7-S4 — B 独立检查

生成时间：2026-06-01

## 0. 独立性声明

我只依据 S4 任务书与列出的黑洞信息悖论文献锚点判断，不读取 A 输出。

## 1. 四假设矩阵

`J_BH = {Hawking_thermal, Complete_evaporation, Unitarity, No_new_entropy_rule}`

这四个假设不能同时成立。

最短链条：

1. Hawking 半经典计算把辐射近似成热，辐射熵上升。
2. 若黑洞完全蒸发且无 remnant/baby universe，则没有额外账本保存信息。
3. 若量子力学幺正，则纯态形成的黑洞最终辐射应恢复纯性。
4. 若还坚持不引入 islands / QES / replica wormholes 等新熵规则，则外部 Hawking 计算无法恢复 Page curve。

因此至少要改动一项。

## 2. 路线分类

| 路线 | 修改的假设 | B 判断 |
|---|---|---|
| island / replica wormhole | `No_new_entropy_rule` | 主流解决方向；通过广义熵和新 saddle 恢复 Page curve |
| remnant | `Complete_evaporation` | 信息留在残余自由度，但有稳定性/无限种类问题 |
| baby universe | `Complete_evaporation` 或外部 Hilbert space | 信息进入外部不可见 sector |
| stimulated emission | `Hawking_thermal` | 替代路线；除非完整恢复 Page curve，否则不升主线 |
| complementarity / firewall / ER=EPR | 低能 EFT、视界平滑性或观测者描述 | 二级矛盾分支 |
| “无悖论”路线 | 拒绝前提组合 | 必须仍说明 Page curve 或信息账本 |

## 3. 对 A 的攻击

1. `J_BH` 四假设作为最小矛盾是合理的。
2. island route 确实通过修改细粒度熵规则恢复 Page curve。
3. stimulated emission 不应自动升级为主路线，除非它完整恢复 Page curve 并给出统一信息账本。
4. S4 应收口为“有边界”，不是“已解决”或“证伪”。

## 4. 结论类型

**有边界。**

黑洞信息悖论是 LP7 的强引力筛选器：任何统一公式必须说明如何恢复 Page curve，并交代它放弃或改写 `J_BH` 四假设中的哪一条。

## 5. 待 PI 处理问题

1. S4 的核心表述是否固定为“统一公式必须恢复 Page curve”。
2. stimulated emission 是否应列入主路线还是反例栏。
3. firewall/complementarity/ER=EPR 是否单列为二级矛盾。
