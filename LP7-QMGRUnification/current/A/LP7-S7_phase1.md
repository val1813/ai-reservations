# LP7-S7 Phase 1 — A 正规推导

生成时间：2026-06-01

## 0. 输入边界

本 Phase 只合并 LP7-S1 至 LP7-S6 的边界结果，不提出新物理公式。

不声称：

- 统一公式已经找到；
- `J_obs^CS` 已经闭合全部观测问题；
- `J_frame` 已经被证明是必需且充分的第六门槛。

## 1. 总块矩阵定义

定义候选统一公式的总判据矩阵：

`J_total = (J_PG, J_BMV, J_hybrid, J_BH, J_obs, J_frame)`

其中：

- `J_PG`：测量源项边界；
- `J_BMV`：媒介非经典边界；
- `J_hybrid`：混合动力学边界；
- `J_BH`：Page curve / 黑洞信息边界；
- `J_obs`：detector-response / observable 层；
- `J_frame`：reference-frame 一致性与描述帧闭合。

前五项来自 S1-S5，`J_obs` 由 S6 提供实现模板，`J_frame` 来自 S5 待仲裁问题。

## 2. 为什么不是单个公式

若把所有问题压成一个标量方程，通常会丢掉两类信息：

1. 哪个边界被修补；
2. 哪个边界只是被投影掉了。

因此 S7 的最小正确形式不是 `F=0`，而是块矩阵：

`J_total[T] = 0`

这里 `T` 代表候选理论，`0` 表示每个块都必须通过对应判据。

## 3. `J_frame` 的地位

`J_frame` 不是重复项。

原因是：

- S1-S4 主要比较的是源项、媒介、动力学与信息账本；
- S6 证明了 observable 模板可以被构造成 `J_obs^CS`；
- 但只要没有说明帧变换下的观测一致性，局部 detector-response 可能被坐标/描述帧重参数化掩盖。

因此：

- 对纯局域边界修补，`J_frame` 可作为附加维；
- 对声称“统一”的候选，`J_frame` 应视为准入稳定性条件。

## 4. 块结构判定

| 候选类型 | J_PG | J_BMV | J_hybrid | J_BH | J_obs | J_frame | 结论 |
|---|---|---|---|---|---|---|---|
| 单侧修补 | 过一块 | 否 | 否 | 否 | 部分 | 部分 | 排除 |
| 双侧修补 | 过两块 | 部分 | 部分 | 部分 | 中 | 部分 | 半候选 |
| 观测模块化候选 | 部分 | 部分 | 部分 | 部分 | 是 | 部分 | 仍不够 |
| 总候选 | 是 | 是 | 是 | 是 | 是 | 是/可证稳 | 仅此类进入 LP7 总候选 |

## 5. 对 S6 的定位

S6 的 `J_obs^CS = dist_delta(D^T(K_i-K_j)J, Im M_cross)` 是 `J_obs` 的实现模块。

它的功能是把不同理论路线投影到 detector response 层；它不是总候选本体。

## 6. 结论类型

结论类型：**有边界**。

核心结论：

LP7 的统一公式候选应写成块矩阵 `J_total`，而不是单个传播子或单一方程。`J_frame` 目前应保留为准入稳定性条件：它对声称“统一”的候选是重要的，但还不足以单独证明新物理。S6 的因果集实现只构成 `J_obs` 模块，不构成总候选。
