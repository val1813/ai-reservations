# 研究计划 — v13-propagator-babel

## 北极星

在 5种已知因果集传播子构造之间，建立**有限ρ层面可区分、连续统极限层面给出选择原则**的判据矩阵 J_ij[detector, observable]，并通过统一sprinkling数值实验显示哪些构造在哪些观测下collapse、哪些保持generic差异。

| 编号 | 构造 | 公式 | 来源 | v12状态 |

## 驱动矛盾

**命题A**（Kastrati-Hinrichsen 2026, PRD 113, 065003）：K_K = exp(L) 是因果集上正确的massless推迟传播子，连续统极限收敛到 □⁻¹。

**命题B**（Boguñá-Krioukov 2025, arXiv:2506.18745）：ℬ⁻¹ 是因果集上正确的massive Green函数，ℬ→□局域收敛保证 ℬ⁻¹→(□+m²)⁻¹。

**不可同真**（HEALTH修正后版本）：在统一UDW detector框架下，若同一detector配置 c 下 J_ij(c)≠0，则两构造不可同真；若∀c, J_ij(c)=0，则i,j在该框架下等价。**对K_ℬ的连续统极限结论附加"在K49预解式收敛成立的条件下"标签**。

两篇PRD级期刊均声明各自构造在连续统极限正确，均未引用对方，均无判据。客观矛盾确立。

## 技术路线

### Phase 0：文献固化+5构造统一接口
- 收集5篇核心文献（Shuman/Dowker-Glaser/BBL/BK/Kastrati）
- 定义统一接口 K_i(sprinkling, m, α_i; **kwargs) → N×N 矩阵
- 验证5种构造在退化极限（m→0或m→∞）的行为对照表

### Phase 1：5种构造形式比较+解析支撑集分析
- 比较5种构造的因果支撑（仅因果对/含类空对）
- 输出 K^(i) 的解析表达式表（统一记号 a_i, ρ, l, m, α_i）
- 识别 K^(i)-K^(j) 的leading order结构（哪些项可被参数空间吸收）

### Phase 2：统一sprinkling数值矩阵
- d=2，N=50/100/200 sprinkling
- 同sprinkling上同时计算 K_path, K_BDG, K_BBL, K_ℬ, K_K
- 5×5 ΔK_ij = K^(i) - K^(j) 矩阵的Frobenius范数+谱
- 判据矩阵 J_ij[D, J] 数值评估

### Phase 3：选择原则刻画
- 扫描（D, J）detector配置空间，识别 J_ij=0 的子流形
- 物理诠释：哪些观测对应哪类detector？
- 输出"分层选择原则"或"无共同response core"否定结论

### Phase 4：v13收官（审稿人攻击+AUDITOR+NAVIGATOR）
