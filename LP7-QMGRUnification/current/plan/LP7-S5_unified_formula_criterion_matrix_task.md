# LP7-S5 任务书：统一公式候选的判据矩阵

生成时间：2026-06-01

## 所属长命题

LP7：量子力学-广义相对论冲突到统一公式。

## 子命题定位

LP7-S5 不负责提出玄学统一公式。
它只负责定义：

> 候选统一公式必须满足哪些最小公理、可观测判据与边界条件，才配进入 LP7 的“候选公式”集合。

## 驱动矛盾

命题 A（无约束拼装）：

任何看起来能同时写下量子与引力的公式都可视为候选，只要形式上能相容若干极限。

命题 B（LP7 边界图谱）：

候选统一公式若不能同时恢复 Page-Geilker 边界、BMV 媒介非经典边界、hybrid dynamics 的分层边界，以及黑洞 Page curve 判据，则它只是拼装，不是统一公式。

不可同真条件：

若一个公式在四条边界图谱里漏掉任意一条，就不能被归入 LP7 的“统一公式候选”。

## 已知输入边界

- LP7-S1：naive expectation-source 半经典方程被边界化。
- LP7-S2：BMV 支持媒介非经典，但不能自动推出标准量子时空。
- LP7-S3：经典-量子混合动力学不能写成全局 no-go，只能写成 deterministic / stochastic / model-restricted 分层边界。
- LP7-S4：黑洞信息悖论要求候选理论恢复 Page curve，并说明它修改了 `J_BH` 四假设中的哪一条。

## 判据矩阵

定义 `J_unify` 为候选统一公式的最小判据向量：

| 维度 | 判据 | 需要满足什么 | 对应 LP7 子题 |
|---|---|---|---|
| U1 | 测量一致性 | 不能把未塌缩 ensemble `<T>` 直接当作每次实验实际经典度规源项 | S1 |
| U2 | 媒介非经典边界 | 若有纠缠生成，必须说明媒介非经典性的层级，但不能自动推出标准量子时空 | S2 |
| U3 | 混合动力学边界 | deterministic naive closure 不能同时保局域性、正性、无超光速信号与低噪声；若存活，必须是 stochastic / CP-TP / trade-off 形式 | S3 |
| U4 | Page curve | 任何强引力统一候选都必须恢复 Page curve，或明确修改 `J_BH` 四假设中的哪一条 | S4 |
| U5 | 观测可分性 | 候选公式必须给出 detector-response 或等价可观测量，而不是仅有形式化写法 | S1/S2/S3/S4 |

## 反例栏

| 反例/风险 | 来源 | 影响 |
|---|---|---|
| 只恢复某一个子命题 | LP7-S1/S2/S3/S4 | 不足以成为统一公式候选 |
| 只写出量子-经典混合而不说明熵/信息 | S3/S4 | 不能解释强引力统一侧 |
| 只给 Page curve 而不说明测量与媒介边界 | S1/S2 | 不能解释实验室侧 |
| 仅有形式兼容极限，没有可观测判据 | 全局 | 直接排除 |

## 本 Phase 任务

### P1：候选最小公理表

把候选统一公式必须满足的条件压成 4 组：

1. 测量与源项公理
2. 媒介与纠缠公理
3. 混合动力学公理
4. 熵与信息公理

### P2：统一判据矩阵

定义 `J_unify[candidate]`：

| 候选类型 | U1 | U2 | U3 | U4 | U5 | 结论 |
|---|---|---|---|---|---|---|

先填定性值。

### P3：候选分层

至少区分三类：

1. 仅为局部边界修补的候选
2. 只解释实验室侧的候选
3. 真正同时覆盖强引力与实验室侧的候选

### P4：结论类型

LP7-S5 允许的结论：

- 已解决
- 有边界
- 证伪
- 不可达

当前预期：**有边界**。
