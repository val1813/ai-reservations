# LP7-S8 任务书：帧一致性边界

生成时间：2026-06-01

## 题目

LP7-S8：帧一致性边界。

## 目标

攻击并裁定 `J_frame` 在 LP7 总块矩阵中的地位：

> 它究竟是一个真正独立的准入维，还是只是 `J_obs` / 协变性 / 可操作可比性 的重命名。

## 北极星

S8 不负责再发明新的统一公式。

它只负责判断：

1. `J_frame` 是否与 `J_obs` 有实质区别；
2. `J_frame` 是否应从“稳定性门槛”升级为硬门槛；
3. 如果它不独立，应如何并回总块矩阵而不丢失信息。

## 驱动矛盾

命题 A（帧可并入观测）：

只要 detector-response 被定义得足够好，帧一致性就已经包含在 `J_obs` 里，不需要单列 `J_frame`。

命题 B（统一候选需要帧稳定性）：

若不同描述帧下同一候选理论的可观测判据不稳定，则它不能算统一公式候选；`J_frame` 必须独立保留。

不可同真条件：

若 `J_frame` 只是 `J_obs` 的同义重复，则不应单列；若它提供额外结构，则必须保留。

## 已知输入

- S5：统一公式候选必须通过 U1-U5 五道门槛。
- S6：因果集 `J_obs^CS` 只是 `J_obs` 的实现模块。
- S7：`J_total=(J_PG,J_BMV,J_hybrid,J_BH,J_obs,J_frame)`，其中 `J_frame` 暂列稳定性门槛。

## 最小验证

1. `J_frame` 是否可由 `J_obs` 完全吸收。
2. 帧一致性是否只是可比性/协变性的另一种说法。
3. 若保留 `J_frame`，应如何定义其最小内容。
4. `J_frame` 是否足以单独拒绝某类候选理论。
