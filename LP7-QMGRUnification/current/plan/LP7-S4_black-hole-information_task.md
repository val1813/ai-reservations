# LP7-S4 任务书：黑洞信息悖论作为强引力统一判据

生成时间：2026-06-01

## 题目

黑洞信息悖论作为强引力统一判据。

## 目标

判断信息守恒、半经典 Hawking 辐射和广义协变/低能有效场论能否形成 LP7 的独立强引力矛盾。

## 北极星

不要把 S4 写成“黑洞信息悖论尚未解决，所以统一公式存在”。本子命题只做判据分层：

> 半经典 Hawking 计算给出持续增长的辐射熵；量子力学 unitarity 要求 Page curve；island/replica wormhole 等路线能恢复 Page curve，但引入新的广义熵/非平凡引力路径积分 saddle。S4 的任务是判断：真正不可同真的是哪组假设，而不是重复描述悖论。

## 驱动矛盾

命题 A（半经典外部 Hawking 计算）：

黑洞蒸发产生近热辐射；若辐射态始终近似热，外部辐射 von Neumann 熵随时间单调增长。

命题 B（量子力学 unitarity）：

若黑洞由纯态形成并完全蒸发，最终外部辐射整体应为纯态；辐射熵应在 Page time 后下降，形成 Page curve。

不可同真条件：

若同时坚持：

1. 外部半经典 Hawking 计算对蒸发全程有效；
2. 黑洞完全蒸发且无 remnant/baby universe；
3. 量子力学 unitary；
4. 辐射细粒度熵就是 Hawking 近热熵；

则四者不可同真。

## 最小验证

定义一个四假设判据：

`J_BH = {Hawking_thermal, Complete_evaporation, Unitarity, No_new_entropy_rule}`

S4 只要证明：

- 四者不可同真；
- island/replica wormhole 通过修改 `No_new_entropy_rule` 解决 Page curve；
- 其他路线通过改写其他假设解决；

即完成 Phase 1。

## 任务拆解

### P1：四假设矩阵

列出每条解决路线放弃了哪一条假设。

### P2：Page curve 判据

对比：

- Hawking curve：`S_rad(t)` 单调增长；
- Page curve：`S_rad(t)` 先增后降，晚期趋近 0 或饱和值。

### P3：island route 的地位

判断 island/replica wormhole 是“解决悖论”还是“引入新的熵规则/路径积分 saddle”，避免过度声张。

### P4：S4 对 LP7 的贡献

明确 S4 是否给出“统一公式”的方向，还是只给出强引力判据。

## 预期结论

有边界。

S4 的价值不是发现一个无人知道的矛盾，而是把黑洞信息悖论转成 LP7 的强引力筛选器：任何统一公式必须说明它如何得到 Page curve，以及它放弃/修改了 `J_BH` 的哪条假设。
