# LP7-S7 任务书：总候选块矩阵与帧一致性

生成时间：2026-06-01

## 题目

LP7-S7：总候选块矩阵与帧一致性。

## 目标

把 LP7-S1 至 LP7-S6 的结果合并成统一公式候选的总块矩阵，并判断是否需要把 reference-frame consistency 单列为第六门槛。

## 北极星

S7 不负责发明新公式。

它只负责判断：

> 候选统一公式是否应写成一个块矩阵 `J_total`，其中每个块对应一条已收束的边界图谱；以及 `J_frame` 是否只是可选附加维，还是必须并入准入条件。

## 驱动矛盾

命题 A（单公式幻想）：

一个统一公式只要形式统一，就不必显式区分测量、媒介、混合动力学、强引力信息账本和观测帧。

命题 B（LP7 总图谱）：

若一个候选不能同时说明 `J_PG, J_BMV, J_hybrid, J_BH, J_obs`，并在必要时处理 `J_frame`，它就只是局部修补，不是总候选。

不可同真条件：

若候选公式只覆盖其中任一块而没有块间协调机制，则不能进入 LP7 总候选。

## 已知输入

- S1：Page-Geilker 边界化 naive expectation-source。
- S2：BMV 只证明媒介非经典，不能直接推出量子时空。
- S3：hybrid dynamics 只能写成分层边界。
- S4：黑洞信息悖论要求恢复 Page curve 或显式改写 `J_BH`。
- S5：统一公式候选必须通过 U1-U5 五道门槛。
- S6：因果集 `J_ij[D,J]` 只能作为 `J_obs` 的实现模块。

## 最小验证

1. 统一候选是否应写成块矩阵而不是单个传播子。
2. `J_frame` 是否必须并入准入条件。
3. S6 的 `J_obs^CS` 是否只是 `J_obs` 的一个实现，而非总候选本体。
4. 总块矩阵是否会把局部修补误收为统一公式。
